# 考點精華

章節頁「考點地圖」每一塊上方的條列重點，一章一個 `.md` 檔，檔名自訂（英文小寫與 `-`）。

```markdown
---
chapter: 精神-Ch08雙相情緒障礙症病人的護理
---

## 雙相情緒障礙症

- 躁症發作：情緒**高昂或易怒**持續**至少 1 週**……

### 躁症病人護理措施：環境安全、生理需求、活動安排

- ……
```

| 規則 | 說明 |
|---|---|
| `chapter` | 章節全名，也就是題本檔案的 `#` 標題 |
| `##` | 必須是本章的 H2，文字要和題本完全相同 |
| `###` | 只能寫題數達獨立門檻的 H3（H2 ≥ 40 題且該 H3 ≥ 15 題），其餘寫在 H2 底下 |
| 內容 | 只能用條列，每塊最多 5 條；每條是一句可以直接出題的話 |
| 語法 | 行內的粗體、斜體可用；完整說明與連結放知識頁 |

哪些 H2、H3 可以寫，以及各自的題數，都在 `src/data/knowledge/chapter-outline.json`。寫錯標題時，`pnpm knowledge:build` 會失敗並指出位置。

## 什麼時候寫

一章的每個有題目的 H2 都有知識頁對照之後（建置時會印出「N 章全部涵蓋」），章節頁就會預設顯示考點地圖。這時補上這一章的考點精華，地圖才完整。還沒寫的章節，地圖上會顯示「考點精華整理中」。

原本題本的筆記卡在全部章節切換完成前都保留，使用者可以用「題目」「卡片」檢視看到。
