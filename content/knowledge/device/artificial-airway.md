**人工氣道**是插進呼吸道、讓氣體通過的管子：**氣管內管**經口或鼻穿過聲帶進入氣管，**氣切管**從頸部氣管前壁直接放入。兩者的**套囊**把氣管密封，才能接呼吸器給正壓，也減少口腔分泌物流進肺部。接上呼吸器後的照護見 [[mechanical-ventilation]]，抽痰見 [[airway-clearance#suctioning]]

## 重點摘要 {#summary}

- 氣管內管：管尖在**隆凸上約 3–5 cm**；經口插入深度約**女性 21 cm、男性 23 cm**(門齒刻度)
- 插太深 → 進**右主支氣管**(較短、寬、直) → **左側呼吸音減弱**、左肺塌陷
- 確認位置：**聽兩側呼吸音**與上腹部、看**胸廓對稱起伏**、**潮氣末二氧化碳**(EtCO₂(End-tidal carbon dioxide) 是 0 ＝插到食道)、**胸部 X 光**
- **套囊壓**約 **20–30 cmH₂O**：太高壓迫氣管黏膜造成缺血、狹窄；太低會漏氣與吸入
- 經**鼻**插管：管子較長、較細 → **呼吸功較大**；**顱底骨折禁用**
- **氣切**：長期使用呼吸器(插管超過約 1–2 週)、上呼吸道阻塞、全喉切除(永久)；比氣管內管舒適、好抽痰、呼吸阻力小
- 氣切床旁備**管芯**、**同尺寸與小一號的備用氣切管**、甦醒球；造口約 1 週才成熟，之前滑脫先由口插管
- **甦醒球**：接氧氣 **12–15 L/min** 與儲氧袋、E-C 手法讓面罩密合、擠到**胸部起伏**即可，不要擠扁

### 國考常考點 {#exam-points}

- 評估氣管內管位置最適當：**聽診雙側呼吸音**(不是膚色、呼吸速率或套囊氣量)
- 插管後**左側呼吸音減弱、右側正常** → 管子插到**右主支氣管**
- 錯誤敘述：成人經口插入深度 **25–27 公分**(實際約 21–23 公分)；插管過程血氧降到 80% 要停止、給 100% 氧氣 3–5 分鐘再試(國考答案)
- 頭顱骨骨折**不適合**經鼻插管；經鼻插管病人的**呼吸功較大**(正確)；插管時**不可快速擠壓**甦醒球；EtCO₂ 為 **0** 代表**位置錯誤**
- 錯誤：維持套囊壓 **35 mmHg** 預防滑脫(太高)
- 錯誤：使用氣切或氣管內管的病人**灌食前先把氣囊放氣**(會增加吸入)
- **3% 雙氧水**可去除氣管內管、氣切管的血漬與痰痂，見 [[asepsis-sterilization]]
- 甦醒球：氧氣流速 **12–15 L/min**；面罩**尖端對鼻樑**、寬端對下巴；**不要把球囊完全壓扁**；SpO₂(Peripheral oxygen saturation) 95% 不需要使用
- 甲狀腺、副甲狀腺術後床旁備**氣切包、氣管內管、喉頭鏡**，見 [[parathyroid-disorders]]
- 全喉切除後的永久氣切造口見 [[head-neck-cancers#laryngectomy-care]]

## 是什麼與原理 {#principle}

![氣管內管與氣切管的位置：氣管內管經口穿過聲帶，套囊在聲帶下方的氣管內、管尖在隆凸上約 3–5 cm；氣切管從頸部氣管前壁直接進入氣管，不經過聲帶](/knowledge-images/artificial-airway.svg)

| | 氣管內管 | 氣切管 |
|---|---|---|
| 進入路徑 | 經口(最常見)或經鼻 → 穿過**聲帶** → 氣管 | 頸部**氣管前壁**造口 → 氣管，不經過聲帶 |
| 用在 | 急救、手術麻醉、短期呼吸器 | **長期**呼吸器、上呼吸道阻塞、清痰困難、全喉切除 |
| 優點 | 快速建立呼吸道 | 較舒適、可減少鎮靜、好抽痰與口腔照護、呼吸阻力小、喉部傷害少 |
| 能否說話 | 不能(管子在聲帶間) | 套囊放氣並接說話瓣膜時可以 |
| 構造 | 管身(刻度)、套囊、指示氣球、接頭 | 外管、**內管**(可取出清洗)、**管芯**(放置時用)、頸板、套囊、指示氣球 |

1. 套囊與指示氣球：用空針從指示氣球打氣讓套囊膨脹；指示氣球鼓起表示套囊有氣
2. 尺寸以**內徑**(mm)表示；ICU Book 依身高建議成人約 7–8 號，但沒有證據顯示尺寸影響預後
3. 氣切時機：預期插管超過 2 週的病人適合氣切；常見做法是插管約 1 週後若下週仍難以拔管就考慮(ICU Book 5e，Ch28)
4. 經皮擴張式氣切可在床旁做，已是主要方式；**環甲膜切開術**只用在緊急打開呼吸道
5. 口咽、鼻咽人工氣道：短暫防止舌頭後倒阻塞
   1. **口咽人工氣道**：只用在**沒有作嘔反射**的病人；長度約**嘴角到耳垂(或下顎角)**
   2. **鼻咽人工氣道**：清醒、有作嘔反射的病人也能用；長度約**鼻尖到耳垂**；顱底骨折避免使用

## 插管與確認位置 {#intubation}

1. 準備：甦醒球接氧氣、抽吸設備、喉頭鏡(檢查燈亮)、不同尺寸的管子、管芯、空針、固定帶、EtCO₂ 偵測器；依醫囑給鎮靜與肌肉鬆弛劑
2. 插管前給 100% 氧氣(預給氧)；過程中監測 SpO₂，血氧明顯下降就暫停、重新給氧
3. **環狀軟骨加壓(Sellick 手法)**：國考書寫可防止胃內容物逆流；AHA 指引在心跳停止急救**不建議常規使用**(可能妨礙通氣與插管)
4. 確認位置
   1. **聽診**：兩側腋下與胸前呼吸音對稱、上腹部聽不到氣過水聲
   2. **胸廓**兩側對稱起伏、管內有霧氣
   3. **潮氣末二氧化碳**：有持續的 CO₂ 波形＝在氣管內；**EtCO₂ 為 0 ＝插到食道**；AHA 建議用**連續波形二氧化碳監測**確認並持續監測管路位置
   4. **胸部 X 光**：管尖在隆凸上約 3–5 cm(約第 4–5 胸椎上方)；頭頸前屈或後仰會讓管尖移動約 2 cm(ICU Book 5e)
5. 記錄並標記**門齒的刻度**：女性約 21 cm、男性約 23 cm(ICU Book 5e 建議不要超過這個深度，避免滑入右主支氣管)
6. 經鼻插管：管子較長、較細 → 呼吸阻力與**呼吸功較大**、易鼻竇炎；**顱底骨折**、鼻部外傷、凝血異常禁用

## 護理重點 {#nursing}

1. 固定與預防非計畫性拔管
   1. 用固定帶或膠布固定，**每班核對門齒刻度**，翻身、移動時一人扶住管子
   2. 咬管時放牙墊
   3. 評估躁動與疼痛，依醫囑適度鎮靜；約束只在必要時並定時鬆開
   4. 自拔或滑脫：評估呼吸，必要時用**甦醒球**給氧並立即通知醫師
2. **套囊壓**
   1. 用套囊壓力計測量，維持約 **20–30 cmH₂O**；低於 20 cmH₂O 與 VAP 增加有關(來源：[Alzahrani 等，BMC Anesthesiol 2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4607016/)，引述 VAP 預防指引)
   2. ICU Book 5e：套囊壓**不超過 25 mmHg**(約 34 cmH₂O)，超過會壓迫氣管黏膜微血管造成缺血
   3. 太高：氣管黏膜壞死、**氣管狹窄**、**氣管食道瘻管**；太低：漏氣(聽到咕嚕聲、可以發聲)、吸入
   4. 漏氣時先看指示氣球：氣球有氣多半是密合不良(管子位置)，氣球沒氣可能是活瓣或套囊破損
   5. 管灌時**不需要把套囊放氣**，放氣反而增加吸入；灌食時床頭抬高 30–45 度
3. 濕化：人工氣道繞過鼻腔，吸入氣體要**加溫加濕**，避免痰液黏稠、痰栓
4. 口腔照護：定時清潔口腔、移動管子位置預防口角壓傷；抽除口腔與套囊上方分泌物
5. 溝通：用字卡、白板、手勢；先告知再處置
6. 抽痰：無菌技術、只在需要時抽，見 [[airway-clearance#suctioning]]

## 氣切照護 {#tracheostomy}

1. 床旁必備：**管芯**、**同尺寸與小一號的備用氣切管**、甦醒球、抽痰設備、氧氣
2. 氣切口護理
   1. 每天至少一次或敷料濕髒時，以無菌技術清潔造口周圍、更換 Y 型紗布
   2. 觀察造口紅腫、分泌物、出血與**皮下氣腫**
   3. 內管依產品與院內規範取出清洗或更換；血漬痰痂可用 3% 雙氧水去除，再用生理食鹽水沖淨
3. 更換氣切綁帶：**兩人執行**，一人扶住頸板；鬆緊度約可放入 1 指
4. 加溫加濕：氣切面罩或人工鼻
5. **意外脫管**：造口約 1 週才成熟；未成熟前滑出，盲目重插容易插入假道 → 先**由口插管**再處理氣切(ICU Book 5e)；造口成熟後用管芯協助重新放入，並通知醫師
6. 說話：套囊放氣後接**說話瓣膜**才能說話；放氣前先抽口腔與套囊上方分泌物
7. 居家照護：居家護理可提供氣切、鼻胃管、尿管照護(見 [[home-care-discharge-planning#home-nurse-role]]、[[long-term-care#home-based]])
8. 全喉切除後的造口是**永久**的，和鼻子不再相通，嗅覺喪失，見 [[head-neck-cancers#laryngectomy-care]]

## 甦醒球(手壓式甦醒球面罩) {#bag-valve-mask}

1. 用在：呼吸停止、呼吸不足、插管前給氧、抽痰前後、呼吸器故障或脫管時
2. 組裝：接**氧氣 12–15 L/min** 並接**儲氧袋**，才能提供高濃度氧氣
3. 面罩：**尖端對準鼻樑**、寬端對準下巴；用 **E-C 手法**(拇指與食指成 C 壓住面罩，其餘三指成 E 托起下顎)讓面罩密合並打開呼吸道
4. 擠壓：每口約 **1 秒**、擠到**看見胸部起伏**即可；**不要把球囊完全壓扁**，過量通氣會造成胃脹氣、嘔吐吸入，並增加胸內壓
5. 有人工氣道時直接接在氣管內管或氣切管上
6. 新生兒胎便吸入的處置見第 16 輪產科新生兒

## 警示與併發症 {#complications}

| 狀況 | 可能原因 | 處理 |
|---|---|---|
| 單側呼吸音減弱 | 管子插太深(右主支氣管)、氣胸、痰栓 | 核對刻度、通知醫師調整，照 X 光 |
| 突然缺氧、呼吸器高壓 | **痰栓阻塞**、咬管、扭折 | 抽痰；無法通過抽痰管時以甦醒球給氧並通知醫師 |
| 漏氣、可以發聲 | 套囊漏氣、管子往外滑 | 測套囊壓、核對刻度 |
| 非計畫性拔管 | 躁動、固定不良 | 評估呼吸，甦醒球給氧，通知醫師 |
| 氣切口出血、皮下氣腫 | 術後早期、管子移位 | 通知醫師 |

1. 長期併發症：喉部潰瘍與水腫(插管超過 12 小時的病人過半有喉部損傷)、聲帶麻痺、**氣管狹窄**(多在拔除氣切管後 6 個月內出現)、氣管軟化、氣管食道瘻管(ICU Book 5e)
2. 拔管後喘鳴音與脫離見 [[mechanical-ventilation#weaning]]
