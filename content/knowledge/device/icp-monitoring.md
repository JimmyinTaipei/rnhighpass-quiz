**顱內壓監測**用在重度頭部外傷、腦出血、腦瘤術後與水腦等顱內壓可能升高、又難以靠神經學檢查評估的病人。最常用的是**腦室外引流(EVD)**：從頭頂把導管放進**側腦室**，接上壓力傳感器與引流袋，可以**同時測量顱內壓與引流腦脊髓液**。顱內壓升高的表現與治療見 [[increased-icp]]，腦室與腦脊髓液的解剖見 [[brain-anatomy#csf-flow]]

## 重點摘要 {#summary}

- 腦室外引流可**測顱內壓**也可**引流腦脊髓液**降壓，是準確度最高的方式；腦實質光纖監測器只能測壓
- **零點**對齊**外耳道(耳屏)**，相當於腦內的**室間孔**(foramen of Monro)；不是鼻尖、眼睛或第四腦室
- **病人改變姿勢、床頭高度時零點位置會改變**，要重新對齊
- 顱內壓正常 **5–15 mmHg**；**> 20–22 mmHg** 要處理；CPP 目標約 60–70 mmHg
- 引流要**慢慢、少量**，依醫囑設定滴注腔高度；**不可短時間大量引流**(會造成腦室塌陷、硬膜下出血或往上的腦疝脫)
- 咳嗽、解便、移動時**暫不判讀**；**搬動、翻身、改變床頭前先關閉**引流，完成後重新對零再打開
- 系統**密閉、無菌**；觀察引流量、顏色(正常清澈)、穿刺處滲漏與**感染**(發燒、混濁、頸部僵硬)

### 國考常考點 {#exam-points}

- 成人腦室外引流的零點對齊**外耳道**(不是鼻尖)；病人改變姿勢時要**重新核對零點**；咳嗽、解便、移動時**暫不測量**；可用來監測顱內壓及引流腦脊髓液
- 體外零點等同腦室內的**室間孔**；**調整床頭會改變**零點位置；要觀察插管處滲漏與發炎；可適度引流腦脊髓液降壓
- 顱內壓監測的體外零點是**室間孔**，**不是第四腦室**
- 頭部外傷術後放置顱內壓監測：ICP 最好 **< 20 mmHg**、CPP **不得低於 50 mmHg**(考題答案)、用 mannitol 時收縮壓 ≥ 90 mmHg；**不可短時大量引流**
- 兒童腦室外引流：**可配合測量顱內壓**；零點不是眼睛高度、不是嚴禁抬高床頭；**需要時可以關閉**；收集瓶是**密閉**系統，不是半開放

## 是什麼與原理 {#principle}

| 種類 | 位置 | 優點 | 缺點 |
|---|---|---|---|
| **腦室外引流(EVD)** | **側腦室**(多在右側、非優勢半球) | **最準確**；**可引流腦脊髓液降壓**；可重新校零 | 腦室小或移位時不好放；**感染**(腦室炎)、出血、阻塞 |
| 腦實質監測器(光纖或微型傳感器) | 腦實質內 | 放置容易、感染少 | **不能引流**；放入後**不能重新校零**，久了數值漂移 |
| 硬膜下、硬膜外監測器 | 腦表面 | 侵入性較小 | 準確度較差，現在少用 |
| 腰椎引流 | 腰椎蜘蛛膜下腔 | 處理腦脊髓液漏 | **顱內壓升高時禁用**(腦疝脫) |

- 腦室外引流是暫時的；需要長期分流時改成**腦室腹膜分流**(V-P shunt，見兒科水腦)
- 單位：1 mmHg ≈ 1.36 cmH₂O；監視器顯示 mmHg，引流高度常用 cmH₂O

### 零點 {#zero-reference}

- 外耳道(**耳屏**)的高度相當於腦內的**室間孔**，以此當作壓力的**零點**(來源：[BANN Benchmark 6](https://bann.org.uk/wp-content/uploads/2023/12/Benchmark-6-Cerebrospinal-Fluid-Management-3rd-Ed.pdf))
- 用**水平儀或雷射水平器**把傳感器與滴注腔刻度的 0 對齊耳屏，比目測準確(同上來源)
- **病人的床頭高度、姿勢改變後**，耳屏的高度也變了 → **重新對零**；否則引流量與顱內壓數值都會錯

## 適應症 {#indications}

1. 重度頭部外傷(GCS 3–8)且電腦斷層異常(來源：[Brain Trauma Foundation 第 4 版指引](https://doi.org/10.1227/NEU.0000000000001432))
2. 腦出血或蜘蛛膜下腔出血合併**急性水腦**
3. 腦瘤術後、顱內感染造成的腦脊髓液阻塞
4. 分流管感染時先移除分流管，暫時改用腦室外引流(兒童常見)
5. 禁忌：凝血功能異常、穿刺處感染

## 看懂螢幕與數值 {#reading}

![顱內壓波形：正常時 P1 最高，順應性下降時 P2 高於 P1](/knowledge-images/icp-waveform.svg)

| 項目 | 正常或目標範圍 | 異常代表什麼 |
|---|---|---|
| **顱內壓(ICP)** | 成人 **5–15 mmHg**(兒童更低) | 持續 **> 20 mmHg**(重度頭部外傷以 **> 22 mmHg** 開始治療)：顱內壓升高 |
| **腦灌流壓(CPP)** | **60–70 mmHg**(重度頭部外傷)；國考常寫 ≥ 50–70 | 太低 → 腦缺血；太高 → 增加呼吸窘迫等併發症 |
| 顱內壓波形 | 三個小峰 **P1 > P2 > P3**，隨心跳起伏 | **P2 高於 P1**：腦**順應性下降**(代償快用完)；波形變平：管路阻塞、氣泡或導管移位 |
| Lundberg A 波(高原波) | 不應出現 | ICP 突然升到 50–100 mmHg、持續 5–20 分鐘：嚴重順應性下降，要立即處理 |
| 引流量 | 依醫囑上限(成人腦脊髓液每天約製造 500 mL，約每小時 20 mL) | 突然很多：滴注腔太低或病人抬高；突然沒有：阻塞、關閉、腦室塌陷 |
| 腦脊髓液外觀 | **清澈無色** | 血色加深：再出血；**混濁**：感染；黃色：舊出血 |

- 計算：CPP = MAP − ICP(例子見 [[increased-icp#pathophysiology]])
- **咳嗽、用力、抽痰、移動時顱內壓會暫時升高**，要在病人安靜時判讀

## 護理重點 {#nursing}

1. **評估**
   1. 每小時(或依醫囑)記錄 ICP、CPP、波形，配合意識、瞳孔與生命徵象
   2. 引流量、顏色與清澈度；滴注腔設定的高度
   3. 穿刺處：滲漏、出血、紅腫；敷料保持乾燥
   4. 感染徵象：發燒、腦脊髓液混濁、頸部僵硬、意識變差
2. **高度與零點**
   1. 依醫囑設定滴注腔高度(例如耳屏上方若干 cmH₂O)：**越高引流越少、越低引流越多**
   2. 病人**改變姿勢或床頭高度**後，**重新對齊零點**
   3. 床頭通常抬高 15–30 度(依醫囑)，**不需要完全平躺**
3. **關閉與打開**
   1. **搬動、翻身、抽痰、改變床頭、外出檢查前先關閉**引流(依各院規範的順序)，避免瞬間大量引流
   2. 完成後重新對零，再依醫囑打開；記錄關閉時間，關閉期間密切觀察顱內壓與意識
4. **引流速度**
   1. **慢慢、少量**引流；**不可短時間大量引流**
   2. 過度引流 → 腦室塌陷、硬膜下血腫、動脈瘤再出血，或往上的腦疝脫
5. **無菌與密閉**
   1. 系統保持**密閉**，不隨意斷開；倒引流液、採檢時嚴格無菌
   2. 收集袋滿了依規定更換；管路不可扭折、拉扯，固定好避免滑脫
6. **兒童**：解釋並保護管路(約束時鬆緊適當)，避免哭鬧使顱內壓升高；家長協助安撫

## 警示與併發症 {#alarms}

| 警示或併發症 | 可能原因 | 處理 |
|---|---|---|
| 顱內壓持續升高 | 腦水腫、血腫擴大、引流阻塞 | 檢查管路與零點、通知醫師；依醫囑引流、給 mannitol 等(見 [[increased-icp#treatment]]) |
| 引流突然停止、波形變平 | 管路扭折、血塊阻塞、關閉未打開、導管移位 | 檢查管路與開關；**不可自行沖洗**導管，通知醫師 |
| 引流量突然增加 | 滴注腔太低、病人坐起而未關閉 | 立即關閉或調整高度、重新對零，通知醫師 |
| 腦脊髓液變紅 | 再出血 | 通知醫師、評估意識與瞳孔 |
| 腦脊髓液混濁、發燒 | **腦室炎** | 採檢、通知醫師；檢視無菌技術 |
| 導管滑脫 | 拉扯、固定不良 | **立即關閉並以無菌敷料覆蓋**穿刺處，通知醫師 |

:::warning[立即處理]
意識下降、單側瞳孔放大、顱內壓持續 > 20 mmHg、引流液大量鮮紅、導管滑脫時，立即通知醫師
:::
