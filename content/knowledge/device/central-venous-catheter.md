**中心靜脈導管(Central venous catheter, CVC)**從內頸、鎖骨下或股靜脈（或手臂的周邊靜脈，即 PICC）放入，尖端停在**上腔靜脈靠近右心房**。用途有三：量**中心靜脈壓(Central venous pressure, CVP)**評估血量與右心功能、給刺激性藥物或升壓劑與全靜脈營養、周邊打不上時的輸液通路。CVP 的生理見 [[blood-vessels#cvp]]；休克時的判讀見 [[shock#assessment]]；癌症病人的人工血管(Port-A)見 [[cancer#vascular-access]]；全靜脈營養見 [[enteral-parenteral-nutrition]]

## 重點摘要 {#summary}

- CVP ≈ **右心房壓**，代表**右心前負荷**與回心血量；頸靜脈壓也反映右心房壓（內外上冊書頁 765）
- 正常約 **4–12 cmH₂O**（或 3–10 mmHg）；1 mmHg ≈ 1.36 cmH₂O（內外上冊書頁 765–766）
- 零點：**右腋中線與第 4 肋間交點**（右心房高度）；每次同一姿勢量、做記號（內外科護理技術書頁 200）
- **低**：血量不足（大出血、脫水、燒傷早期）、血管擴張的休克；**高**：輸液過多、**右心衰竭**、心因性休克、**心包膜填塞**、張力性氣胸、肺高壓
- 多管腔導管用**遠端管腔(distal)**量；量時暫停其他管腔的輸液幫浦（內外科護理技術書頁 205）
- 咳嗽、用力、疼痛、管路扭折、正壓呼吸 → 數值**假性上升**；呼吸器病人在**吐氣末**讀
- 感染預防：手部衛生、**最大無菌面防護**、**chlorhexidine** 消毒、**避免股靜脈**、**每天評估是否還需要**(CDC 2011)
- 敷料：透明敷料 **7 天**、紗布 **2 天**換一次，濕、髒、鬆脫立刻換；輸液管路約 **72 小時**換（CDC 2011；內外科護理技術書頁 204–206）
- 空氣栓塞：置入與拔除時病人**平躺或頭低**、**閉氣或吐氣**；發生時**左側臥＋頭低腳高**、給 100% 氧氣

### 國考常考點 {#exam-points}

- 中心靜脈壓與頸靜脈壓都**反映右心房壓**；中心靜脈導管量的是**右心房**壓力（不是左心）
- CVP 2 cmH₂O 合併出血、心跳快 → **低血容積**
- CVP 升高的原因：心肌梗塞、二尖瓣逆流（右心後來受影響）、**心包膜填塞**；**敗血性休克**（血管擴張）CVP **不會**上升
- 大面積燒傷 48 小時內 CVP **下降**（血漿外漏），不是升高
- 敗血症輸液目標：舊版 Surviving Sepsis 用 CVP 8–12 mmHg；收縮壓 < 80 才是最需要調整輸液的指標
- 空氣栓塞的表現：呼吸困難、發紺、**血壓下降、脈快而弱**、胸痛、意識改變；處置：**左側臥、頭低腳高**
- 置入中心靜脈導管是**醫囑性（非獨立）**措施；護理師負責協助、維護與觀察

## 是什麼與原理 {#principle}

| 項目 | 內容 |
|---|---|
| 置入部位 | **內頸靜脈**、**鎖骨下靜脈**（感染較低，但氣胸風險較高）、**股靜脈**（感染與血栓較多，成人盡量避免）、手臂周邊靜脈(PICC) |
| 尖端位置 | 上腔靜脈與右心房交界附近；置入後**照胸部 X 光**確認位置並排除氣胸 |
| 管腔 | 單、雙、三管腔；三管腔分近端、中間、**遠端**，遠端用來量 CVP |
| 種類 | 短期非隧道式（ICU 用）、PICC、隧道式(Hickman)、全植入式(Port-A) |

部位與感染風險依 CDC 2011；管腔與 X 光確認依內外科護理技術書頁 197–199

- 用途
   1. 監測 CVP，作為輸液的參考
   2. 給**升壓劑**、刺激性或起疱性藥物、高濃度電解質（外滲風險低）
   3. **全靜脈營養(TPN)**
   4. 周邊血管難打、需要長期輸液
- 一般中心靜脈導管不常規用來輸血（管徑細、易阻塞）（內外科護理技術書頁 206）；**大量快速輸液**反而用**短而粗的周邊管路**較快（見 [[shock#hypovolemic]]）

## 測量中心靜脈壓 {#cvp}

### 步驟 {#cvp-steps}

以水柱測壓計為例，依內外科護理技術書頁 200–201 重新整理

| 步驟 | 做法 | 原因 |
|---|---|---|
| 1 姿勢 | **平躺**、移除枕頭；無法平躺就固定同一角度並記錄 | 每次姿勢相同才能比較 |
| 2 找零點 | **右腋中線＋第 4 肋間**，貼十字膠布 | 與右心房同高 |
| 3 對零 | 用水平儀（或拉直接管目測）讓測壓計 0 點對準記號 | 零點偏高讀數偏低，偏低則讀數偏高 |
| 4 充液 | 三路活塞關向病人端，讓輸液流進測壓計到約 20–25 cm | 不可過高弄濕上方濾器 |
| 5 測壓 | 活塞關向輸液端，讓測壓計通病人端，水柱下降 | 液面對應右心房壓 |
| 6 讀值 | 水柱**不再下降**、隨**呼吸輕微起伏**時，視線平液面**凹處**讀 | 起伏表示管路通暢 |
| 7 恢復 | 活塞關向測壓計端，恢復原滴速；記錄並告知醫師 | |

- 電子式：導管接**壓力轉換器**，轉換器同樣對準右心房高度並歸零，螢幕顯示波形與數值（內外上冊書頁 765）
- 呼吸器病人：盡量在**吐氣末**讀；不能脫離呼吸器時記錄使用狀況，之後都用同一方式（內外科護理技術書頁 205）
- 假性升高：疼痛、用力、咳嗽、躁動、管路扭折或血塊阻塞、PEEP

### 判讀 {#cvp-interpretation}

| CVP | 常見原因 | 處置方向 |
|---|---|---|
| **低**(< 4 cmH₂O) | 出血、脫水、燒傷早期、利尿過度；神經性、敗血性、過敏性休克的血管擴張 | 依醫囑加快輸液、找出血或體液流失原因 |
| **高**(> 12–15 cmH₂O) | 輸液過多、**右心衰竭**、心因性休克、**心包膜填塞**、**張力性氣胸**、肺栓塞、肺高壓、三尖瓣疾病 | 減慢輸液、通知醫師；評估呼吸音、頸靜脈、水腫 |

依內外上冊書頁 765 與內外科護理技術書頁 205–206 重新整理

- 單一數值意義有限，要看**趨勢**並配合血壓、心跳、尿量、呼吸音
- 2021 Surviving Sepsis 不再建議用 CVP 單獨指引輸液，改看動態指標與乳酸（見 [[sepsis#hour-1-bundle]]）

## 協助置入 {#insertion}

內外科護理技術書頁 197–199、205

1. 確認同意書、凝血功能與過敏史；解釋過程
2. 姿勢：內頸或鎖骨下靜脈置入時**平躺、頭低腳高**、頭轉向對側，使靜脈擴張並減少空氣進入
3. 協助醫師**最大無菌面防護**（帽子、口罩、無菌衣、無菌手套、全身大洞巾）
4. 穿刺時請病人在適當時機**閉氣**，避免空氣栓塞
5. 接上輸液後把點滴瓶放低確認**回血**，再沖回並調整滴速
6. 縫合固定、消毒、透明敷料覆蓋，註明日期與**導管刻度（深度）**
7. **照胸部 X 光**確認位置、排除氣胸
8. 置入後幾小時內監測生命徵象、出血、呼吸困難、皮下氣腫

- 置入併發症：**氣胸**、血胸、出血與血腫、誤穿動脈、心律不整（導絲刺激心臟）、**空氣栓塞**、心臟穿孔造成**心包膜填塞**（內外科護理技術書頁 205）

## 日常護理 {#nursing}

### 傷口與敷料 {#dressing}

| 項目 | 做法 |
|---|---|
| 觀察 | 每天看穿刺處紅、腫、熱、痛、分泌物；有感染徵象告知醫師，評估是否移除 |
| 消毒 | **2% chlorhexidine**（含酒精）由內往外，直徑至少 5 公分；等**自然乾** |
| 透明敷料 | 方便觀察，**7 天**換一次 |
| 紗布 | 出汗多、滲血時用，**2 天**換一次 |
| 立即更換 | 敷料濕、髒、鬆脫 |
| 記錄 | 換藥日期、導管外露長度或刻度 |
| 滑脫 | **不可推回**；記錄外露長度並告知醫師 |
| 抗生素藥膏 | 不常規使用 |

依內外科護理技術書頁 203–204 與 CDC 2011 重新整理

### 預防中心導管相關血流感染 {#clabsi}

中心導管相關血流感染(Central line-associated bloodstream infection, CLABSI)常用**組合式照護(bundle)**預防

1. **手部衛生**
2. 置入時**最大無菌面防護**
3. **chlorhexidine** 皮膚消毒
4. 成人**避免股靜脈**
5. **每天評估導管是否還需要**，不需要就盡快移除

CDC 2011；台灣醫院感染管制的組合式照護同此原則（待核對疾管署原文）

- 由導管給藥或輸液前，用含酒精消毒液**用力擦拭注射帽或接頭**（內外科護理技術書頁 206）
- 不需定期更換導管；輸液管路約 **72 小時（3 天）**換一次，輸血或脂肪乳劑的管路要較快換(CDC 2011)
- 疑似導管感染：抽周邊與導管血液培養，依醫囑移除導管並送導管尖端培養（見 [[culture-and-sensitivity]]）

## 空氣栓塞 {#air-embolism}

- 原因：置入或拔除時空氣從導管或穿刺道吸入、接頭鬆脫、輸液管路未排氣
- 表現：突然**呼吸困難**、發紺、胸痛、**血壓下降、脈快而弱**、意識改變；可能聽到心前區「水車」雜音（待核對）
- 處置
   1. 立刻夾住或封閉導管入口
   2. **左側臥＋頭低腳高**（Durant 姿勢），讓空氣留在右心房上方，不進入肺動脈
   3. 給 **100% 氧氣**、通知醫師、監測生命徵象
- 預防：管路排氣完全、接頭鎖緊；置入與拔除時病人**平躺或頭低**、做**閉氣或吐氣**動作

## 拔除導管 {#removal}

1. 病人**平躺或頭稍低**；拔內頸或鎖骨下導管時請病人**閉氣**(Valsalva)或在吐氣時拔
2. 拔出後立刻**加壓止血**，再用**密封敷料**（如凡士林紗布加透明敷料）覆蓋，避免空氣從穿刺道進入
3. 檢查導管尖端完整；依醫囑送尖端培養
4. 拔除後平躺約 30 分鐘並觀察呼吸（待核對）

## 肺動脈導管(Swan-Ganz) {#pulmonary-artery-catheter}

- 從內頸、鎖骨下或股靜脈放入，**氣球充氣**後隨血流漂經右心房、右心室到**肺動脈**（內外上冊書頁 766）
- 氣球在肺動脈分支卡住時量到**肺動脈楔壓(PCWP)**，反映**左心房壓與左心室舒張末期壓**，評估**左心功能**；量完**立刻放氣**，以免肺梗塞
- 也能量 CVP、肺動脈壓、心輸出量（熱稀釋法）、混合靜脈血氧飽和度

| 項目 | 正常值 |
|---|---|
| 右心房壓(CVP) | 4–12 cmH₂O(3–10 mmHg) |
| 肺動脈壓 | 收縮 15–30、舒張 8–15 mmHg |
| **肺動脈楔壓(PCWP)** | **4–12 mmHg** |
| 心輸出量 | 4–8 L/min |
| 心臟指數 | 2.5–4 L/min/m² |
| 混合靜脈血氧飽和度 | 68–78% |

內外上冊書頁 766 表 10-5

- PCWP **上升**：左心衰竭、**心因性休克**、二尖瓣狹窄、**心因性肺水腫**；ARDS 是非心因性，舊診斷標準要 PCWP ≤ 18 mmHg（見 [[ards-respiratory-failure]]）
- 氣球充氣量約 **0.8–1.5 mL**、慢慢打；打氣後波形沒變化可能是氣球沒卡住，不一定破；懷疑破裂就停止充氣並通知醫師（內外上冊書頁 768）

## 警示與併發症 {#alarms}

| 狀況 | 可能原因 | 處理 |
|---|---|---|
| 水柱不動、沒有呼吸起伏 | 管路阻塞、扭折、尖端貼壁 | 檢查管路；不可用力沖；告知醫師 |
| CVP 突然升高 | 咳嗽、躁動、零點偏低、心包膜填塞、張力性氣胸 | 重新對零、安靜後再量；配合病人狀況判讀 |
| 穿刺處紅腫、發燒 | 導管感染 | 告知醫師、血液培養、評估移除 |
| 手臂或頸部腫脹 | 導管相關血栓 | 告知醫師、超音波 |
| 突然呼吸困難、低血壓 | 空氣栓塞、氣胸 | 左側臥頭低、給氧、通知醫師 |
| 導管外露變長 | 滑脫 | 不推回，記錄並告知醫師 |
