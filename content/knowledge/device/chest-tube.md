**胸管**是從肋間放進肋膜腔的引流管，接上**水下密閉引流系統**，把肋膜腔裡的空氣、血、膿或液體排出，重建肋膜腔負壓，讓肺重新擴張。用在氣胸、血胸、膿胸、大量肋膜積水與胸腔、心臟手術後；疾病本身見 [[pleural-chest-trauma]]，肺切除術後照護見 [[lung-cancer#postop]]

## 重點摘要 {#summary}

- 目的：排出肋膜腔的**空氣**（氣胸）或**液體、血、膿**，讓肺再擴張
- 放置位置：排氣放**前胸第 2 肋間、鎖骨中線**（空氣往上）；排液放**腋中線較低的肋間**（液體往下）
- **水封**：長管沒入水面下約 **2 cm**，空氣只能出、不能回到肋膜腔
- **液面隨呼吸起伏**＝管路通暢；自發呼吸時**吸氣上升、吐氣下降**，正壓呼吸器相反；不再起伏＝肺已擴張或管路阻塞
- **氣泡**：水封瓶冒泡代表空氣從肋膜腔排出；術後或氣胸剛接上時可以有，**持續大量冒泡**要從病人端往瓶子端**找漏氣處**
- 抽吸控制瓶的**水深決定負壓**（常見 −20 cmH₂O），接抽吸時這瓶**持續緩和冒泡**才正常
- 引流瓶**直立、低於胸部**；**不常規夾管、不常規擠壓**；**冒泡中的胸管絕對不可夾**
- 拔管：**深吸氣後閉氣**（或吐氣末）時拔出，立即用**凡士林紗布**密封

### 國考常考點 {#exam-points}

- 水封瓶長玻管液面**隨呼吸上下移動** → **胸管引流功能正常**
- 氣胸剛接上胸管：長玻管在液面下 **2–3 公分**、液面**吸氣上升、呼氣下降**都是正常；國考答案把**水封瓶連續性氣泡**列為**不正常**
- 胸腔術後水封瓶出現**大量氣泡** → **檢查引流系統有無漏氣處**（不是擠胸管、不是降低抽吸、不是不用處理）
- 水封瓶**持續小量氣泡** → **檢查各部位連接是否密合**
- 負壓引流時，抽吸控制瓶應**持續性抽吸**（持續緩和冒泡）
- 錯誤做法：水封瓶持續冒泡是正常、**夾緊管路**減少壓力、**每天更換**瓶內蒸餾水、**間歇夾住**避免過度引流、**限制病人活動**、**每班夾管**、**每 2 小時擠壓胸管**
- 拔胸管：病人**深吸氣後閉氣**；拔管前**先給止痛劑**；拔管後**無菌凡士林紗布**覆蓋；「液面隨呼吸浮動表示可以拔管」是**錯**的
- 肺葉切除後兩支胸管：**前胸第 2 肋間引流空氣**、**腋中線第 8–9 肋間引流液體**
- 左全肺切除術後：最適當的是**鼓勵咳嗽與深呼吸**；全肺切除通常不接一般水下引流，不需確認水封功能
- 肺葉切除後傷口周圍皮膚像**海綿、有爆裂音** → **皮下氣腫**
- 冠狀動脈繞道術後胸管引流 **200 mL/hr** → 要**立即通知醫師**
- 輸出量要包含**胸腔引流液量**
- 換胸管傷口敷料：戴無菌手套後雙手保持在**腰部以上**、視線範圍內；非無菌物品離無菌區至少 **1–2 吋**（國考答案）

## 是什麼與原理 {#principle}

![三瓶式胸腔水下引流：① 收集瓶接住引流液；② 水封瓶長管沒入水面下約 2 cm，空氣只能出不能回；③ 抽吸控制瓶以長管沒入的水深決定負壓，再接抽吸源](/knowledge-images/chest-drainage-systems.svg)

1. 構造：胸管 → 連接管 → 引流瓶（現在多是一體成型的三格式拋棄式引流箱，原理和三瓶相同）
2. 三瓶各自的功能

| 瓶 | 功能 | 觀察重點 |
|---|---|---|
| ① **收集瓶** | 接住血、膿、肋膜液；進氣管不碰液面，液體再多也不會增加阻力 | 量、顏色、性狀；標記時間與液面 |
| ② **水封瓶** | 長管沒入水面下約 2 cm，形成**單向活瓣**：肋膜腔壓力高於 2 cmH₂O 時空氣排出，吸氣時水擋住空氣回流 | **液面波動**、**氣泡** |
| ③ **抽吸控制瓶** | 一根長管通大氣、沒入水中；**水深＝最大負壓**，抽吸再強也只會讓空氣從長管冒泡進來 | 水位（蒸發要補）、持續緩和冒泡 |

3. 單瓶、雙瓶、三瓶的比較

![單瓶式與雙瓶式：單瓶式的水封瓶同時收集引流液，液面會越來越高；雙瓶式把引流液留在收集瓶，水封深度固定](/knowledge-images/chest-drainage-1-2-bottle.svg)

| | 單瓶式 | 雙瓶式 | 三瓶式 |
|---|---|---|---|
| 組成 | **水封瓶**（同時收集） | **收集瓶＋水封瓶** | 收集瓶＋水封瓶＋**抽吸控制瓶** |
| 引流動力 | 重力＋呼吸 | 重力＋呼吸 | 可加**負壓抽吸**，水深控制壓力 |
| 優點 | 構造最簡單、便宜 | 水封深度**固定**，可量較多引流液 | 能穩定控制負壓；引流量大或持續漏氣時用 |
| 缺點 | 引流液一多，液面升高、**長管沒入變深 → 排氣阻力變大**；引流液和水混在一起不好計量 | 沒有負壓控制 | 構造較複雜；抽吸瓶的水會蒸發要補 |
| 適合 | **單純氣胸**、引流液很少 | 有中等量液體 | 液體多、需要抽吸 |

- 來源：Zisis C 等，[Chest drainage systems in use](https://pmc.ncbi.nlm.nih.gov/articles/PMC4356865/)，Ann Transl Med 2015;3(3):43
- 現在醫院多用一體成型的拋棄式引流箱，分格就是三瓶式，不接抽吸時也可當作雙瓶式使用
4. 數值來源：水封約 2 cm、抽吸常設 −20 cmH₂O（ICU Book 5e，Ch28）；文獻建議抽吸 10–20 cmH₂O（NHS Borders 胸管照護指引，依 BTS）；台灣衛教單張寫長管沒入 2–3 公分（[長庚小兒胸管衛教](https://webapp.cgmh.org.tw/article/document/art_atch/00253-20200617-091621.pdf)）

:::basics[為什麼液面會隨呼吸起伏？]
胸管尖端在肋膜腔，水封瓶長管裡的水柱等於肋膜腔壓力的「壓力計」。自發呼吸吸氣時肋膜腔負壓變大，把水柱往上吸；吐氣時負壓變小，水柱下降。用正壓呼吸器時，吸氣是把氣體推進去，肋膜腔壓力上升，所以方向相反。肺完全擴張貼住胸管開口，或管路阻塞、扭折時，波動就會消失。肋膜腔壓力見 [[ventilation-mechanics#pressures]]
:::

5. 抽吸不是必要：多數氣胸只接水封就夠；ICU Book 5e 指出抽吸會增加跨肺壓、讓瘻管漏氣更多，持續漏氣時可考慮關掉抽吸；**接不接抽吸、壓力多少以醫囑為準**

## 適應症 {#indications}

1. 氣胸（有症狀、量大、使用呼吸器、張力性氣胸針刺減壓後）
2. 血胸、氣血胸
3. 膿胸、複雜的肺炎旁積液
4. 大量或反覆的肋膜積水、乳糜胸
5. 胸腔手術（肺葉切除、胸腔鏡）、心臟手術後
6. 位置

| 目的 | 位置 | 道理 |
|---|---|---|
| 排**空氣** | **前胸第 2 肋間、鎖骨中線**，管尖朝上 | 空氣較輕，聚在肋膜腔上方 |
| 排**液體** | **腋中線**較低的肋間（肺切除術後常放第 8–9 肋間），管尖朝下 | 液體較重，沉到下方 |
| 一般放置 | 腋下「安全三角」第 4–5 肋間、腋中線附近 | 避開大血管、乳房與肌肉；BTS 與 ICU Book 都以此為主 |

- 現在一般氣胸與積水多用**小管徑**胸管；血胸、膿胸可能需要較粗的管子(BTS 2023)
- 全肺切除術：通常**不接一般水下引流**或夾住、只依醫囑短暫開放，讓空腔慢慢被液體填滿、縱膈腔維持在中線，見 [[lung-cancer#chest-tubes]]

## 看懂引流系統 {#reading}

| 觀察 | 正常 | 異常代表什麼 |
|---|---|---|
| 水封瓶**液面波動** | 隨呼吸上下起伏（自發呼吸吸氣上升、吐氣下降） | **不再起伏**：肺已完全擴張，或管路**扭折、阻塞、壓到**、管尖移位；先檢查管路，再由醫師以 X 光確認 |
| 水封瓶**氣泡** | 氣胸或術後早期，咳嗽、吐氣時間歇冒泡 | **持續大量冒泡**：肺持續漏氣（支氣管肋膜瘻管）或**系統漏氣**（接頭鬆脫、管子破損、傷口處漏氣）；本來沒冒泡、突然冒泡也要查 |
| 抽吸控制瓶 | 有接抽吸時**持續緩和冒泡**；水位維持醫囑高度 | 不冒泡：抽吸沒開或壓力太低；**劇烈冒泡**：抽吸開太大，只增加噪音與水分蒸發，不會增加負壓 |
| 收集瓶 | 術後先為**血性**，逐漸變淡紅、淡黃；量逐漸減少 | **突然大量鮮紅**、變混濁或有膿；量突然歸零要查是否阻塞 |

- 心臟手術後胸管引流 **200 mL/hr** 屬於要立即通知醫師的出血量（國考答案；實際通報值依院內規範）

## 護理重點 {#nursing}

1. 評估
   1. 呼吸：呼吸型態、SpO₂(Peripheral oxygen saturation)、兩側呼吸音、胸廓起伏
   2. 引流系統：**液面波動**、**氣泡**、引流液量與顏色（每班或依醫囑記錄，標記液面與時間，算進**輸出量**）
   3. 插管處：敷料、滲液、紅腫、**皮下氣腫**（按壓有捻髮音，標記範圍觀察是否擴大）
   4. 疼痛：插管處疼痛會讓病人不敢深呼吸
2. 維持密閉與通暢
   1. 所有**接頭緊密**、用膠布加強；管路**不扭折、不壓到、不垂成 U 形積液**
   2. 引流瓶**保持直立**、放在地上或掛在床緣，**低於胸部**（台北慈濟單張寫低於胸腔 45–60 公分）；下床時瓶子**不高過腰部**，避免引流液逆流
   3. 引流瓶**不需要每天換水**，更換依產品與醫囑
3. **夾管**
   1. **不常規夾管**；**冒泡中的胸管絕對不可夾**，會讓空氣積在肋膜腔造成**張力性氣胸**（NHS Borders 指引）
   2. 搬運、下床、做檢查時**不夾管**，保持瓶子低於胸部即可
   3. 只在短暫情況依規範夾：找漏氣處時由近胸端往瓶端逐段短暫夾住、更換引流瓶、醫師決定的拔管前試夾；夾管期間**密切觀察呼吸**
4. **擠壓胸管**
   1. **不常規擠壓或捋管**：捋管(stripping)會在肋膜腔造成很大的負壓，傷害組織
   2. 有血塊阻塞（常見於心臟手術後）時，依醫囑與院內規範輕柔擠壓
5. 促進肺擴張
   1. **深呼吸**、**誘發性肺量計**、有效咳嗽（咳嗽前坐起、**用枕頭按住傷口**），見 [[restrictive-lung-diseases#atelectasis]]
   2. 咳嗽前先**止痛**，讓病人敢深呼吸
   3. **早期下床**；**半坐臥**
   4. 術側**肩膀與手臂運動**，預防冰凍肩
6. 傷口：依無菌技術換藥，見 [[asepsis-sterilization]]；胸管用縫線與膠布固定，避免拉扯
7. 抽吸：依醫囑設定抽吸控制瓶水位或乾式調壓旋鈕；水蒸發要補到醫囑高度

## 拔除胸管 {#removal}

1. 時機：由醫師評估
   1. 引流液減少（台北慈濟單張寫**每日 < 200 mL**；NHS Borders 寫 < 150 mL／24 小時）
   2. **不再漏氣**（水封瓶不冒泡），咳嗽時也不冒泡
   3. **胸部 X 光**顯示肺已擴張
   4. 液面不再波動**不等於**可以拔管，可能是阻塞
2. 拔管前：**先給止痛劑**；向病人說明並**練習呼吸方式**；準備**凡士林紗布**與敷料
3. 拔管時
   1. 請病人**深吸氣後閉氣**（像 Valsalva 一樣用力憋住），醫師迅速拔出；也有指引寫**吐氣末**拔出(NHS Borders)
   2. 目的：拔出瞬間胸內壓高於大氣，**空氣不會被吸進肋膜腔**
   3. 立即用**無菌凡士林紗布**＋紗布密封傷口
4. 拔管後
   1. 觀察**呼吸困難、胸痛、SpO₂ 下降、呼吸音減弱**（再發氣胸）、皮下氣腫、傷口滲液
   2. 依醫囑照**胸部 X 光**
   3. 傷口約 1 週拆線，有紅腫熱痛、分泌物要回診（長庚衛教）

## 胸腔手術術後 {#thoracic-surgery}

1. 常見手術：**肺葉切除**、楔形切除、**全肺切除**、胸腔鏡手術(VATS)
2. 術前：**肺功能檢查**評估切除後剩下的肺功能是否足夠；戒菸、練習深呼吸、誘發性肺量計與手臂運動
3. 術後重點：胸管照護、止痛、肺部擴張、早期活動；姿勢與兩支胸管位置見 [[lung-cancer#postop]]

| 手術 | 姿勢 | 胸管 |
|---|---|---|
| 肺葉切除 | **半坐臥**，可平躺或**臥向健側**；不要長時間壓著患側 | 通常兩支（上排氣、下排液），接水下引流 |
| 全肺切除 | 半坐臥、平躺或稍側向**手術側**；**避免完全臥向健側** | 通常**不接一般水下引流**，避免縱膈腔移位 |

4. 併發症：出血、**持續漏氣**、**皮下氣腫**、肺擴張不全、肺炎、心律不整；全肺切除後要**控制輸液量**（容易肺水腫）、觀察**氣管位置**（縱膈腔移位）

## 警示與併發症 {#alarms}

| 狀況 | 可能原因 | 處理 |
|---|---|---|
| 引流瓶**傾倒** | 碰撞 | 立即**扶正**；請病人深呼吸幾次；觀察呼吸；通知護理師與醫師評估是否換瓶 |
| **連接管脫開或破損** | 拉扯、接頭鬆 | 立即**反折或夾住胸端管路**（長庚衛教），或依院內規範把胸端管路**插入無菌水中**暫時形成水封；換新的引流系統，通知醫師 |
| **胸管從胸壁滑脫** | 固定不良、拉扯 | 立即用**無菌敷料蓋住傷口**（貼三邊或依規範），觀察張力性氣胸徵象，通知醫師 |
| 持續大量冒泡 | 肺漏氣或系統漏氣 | 由近胸端往瓶端逐段**短暫夾住**找漏氣處；夾到胸端就停止冒泡＝漏在病人體內，通知醫師 |
| 液面不再波動、引流突然停止 | 肺已擴張、阻塞、扭折、管尖移位 | 檢查管路；評估呼吸音；通知醫師 |
| 皮下氣腫擴大 | 漏氣量超過引流量、管路阻塞或移位 | 標記範圍、評估呼吸道；通知醫師 |
| 引流大量鮮紅 | 出血 | 監測生命徵象、記錄每小時量；**立即通知醫師** |

:::warning[立即處理]
突然呼吸困難、SpO₂ 下降、患側呼吸音消失、氣管偏移、頸靜脈怒張或低血壓，要想到**張力性氣胸**（尤其胸管被夾住、阻塞或滑脫後）：立即通知醫師，打開不當的夾子、準備針刺減壓與重新放置胸管，見 [[pleural-chest-trauma#tension-pneumothorax]]
:::
