藥物撐不住心臟時，可以用機械裝置暫時幫忙：**主動脈內氣球幫浦(Intra-aortic balloon pump, IABP)**減輕左心室負擔、增加冠狀動脈血流；**葉克膜(Extracorporeal membrane oxygenation, ECMO)**直接在體外替血液加氧，必要時連循環一起接手；**心室輔助器(Ventricular assist device, VAD)**是較長期的人工幫浦。它們都是**橋梁**，讓心肺休息，等待恢復、手術或心臟移植。心因性休克見 [[shock#cardiogenic]]；心衰竭見 [[heart-failure]]；急性心肌梗塞見 [[coronary-artery-disease]]

## 重點摘要 {#summary}

- IABP 由**股動脈**放入，氣球位在**降主動脈**（左鎖骨下動脈開口下方、腎動脈上方）（內外上冊書頁 868）
- **舒張期充氣**（主動脈瓣關閉時） → 把血推回升主動脈 → **冠狀動脈與腦部灌流增加**（內外上冊書頁 868）
- **收縮期前放氣** → 主動脈內壓下降 → **後負荷下降**、心輸出量增加、心肌耗氧減少
- IABP 適用：**心因性休克**、急性心肌梗塞併發症、藥物無效的心衰竭、等待手術（內外上冊書頁 449、868）
- IABP 護理：**患肢伸直**、床頭不超過約 30 度、**比較兩側**足背脈搏與循環、看**左手橈動脈**與**尿量**（氣球往上或往下移位）、依醫囑給 heparin（內外上冊書頁 873）
- ECMO：**VV** 只取代**肺**（嚴重呼吸衰竭）；**VA** 同時支持**心與肺**（心因性休克、心跳停止）（內外上冊書頁 869 Box 10-9）
- ECMO 需**全身肝素化**，監測 aPTT；併發症：**出血**、**溶血**、栓塞、感染、插管側肢體缺血；只做短期使用（內外上冊書頁 869）

### 國考常考點 {#exam-points}

- IABP 可以**增加冠狀動脈血流**並**降低後負荷**（正確敘述）
- IABP 氣球是**心臟舒張時充氣**；「收縮時充氣以降低前負荷」是**錯**的
- IABP 護理最適當：**比較患肢與健肢**的末梢脈搏、血循、感覺；**患肢不可屈曲**；**需要 heparin** 預防血栓
- 心因性休克：**IABP 是重要治療方式之一**；電毯加溫是錯的

## 主動脈內氣球幫浦(IABP) {#iabp}

### 原理 {#iabp-principle}

| 時相 | 氣球 | 效果 |
|---|---|---|
| **舒張期**（主動脈瓣關閉、重搏切跡時） | **充氣**（用氦氣） | 主動脈舒張壓上升 → **冠狀動脈灌流**與腦血流增加 → 心肌供氧增加 |
| **收縮期**（主動脈瓣打開前一刻） | **放氣** | 主動脈內壓突然下降 → 左心室打出去的阻力（**後負荷**）下降 → 心輸出量增加、心肌耗氧減少 |

內外上冊書頁 868 的概念重新整理；充放氣以心電圖或動脈壓波形觸發

- 一句話：**舒張期充氣、加灌流；收縮期放氣、減負荷**
- 反搏比例 1 : 1 表示每次心跳都輔助；脫離時逐步降到 1 : 2、1 : 3（待核對）
- 嚴重主動脈瓣閉鎖不全、主動脈剝離、嚴重周邊動脈疾病不適合使用（待核對）

### 護理重點 {#iabp-nursing}

| 項目 | 做法 | 原因 |
|---|---|---|
| 姿勢 | **患肢伸直**，不屈髖；床頭約 **≤ 30 度**；翻身時整個身體一起翻 | 避免導管折到或移位 |
| 肢體循環 | 定時**比較兩側**足背與脛後動脈脈搏、膚色、溫度、感覺、活動 | 股動脈插管可能造成下肢缺血 |
| 左手橈動脈 | 定時摸左手脈搏 | 氣球**往上移位**會擋住左鎖骨下動脈 |
| 尿量 | 每小時記錄 | 氣球**往下移位**會擋住腎動脈 → 尿量突然減少 |
| 抗凝 | 依醫囑給 **heparin**，監測 aPTT、血小板 | 預防血栓；注意出血 |
| 出血 | 觀察穿刺處、牙齦、尿液、腸胃道出血 | 抗凝加上血小板被破壞 |
| 血行動力 | 監測動脈壓波形、心跳節律、心輸出量、意識 | 確認輔助有效；心律不整會影響觸發 |
| 感染 | 無菌換藥 | 侵入性大管路 |

依內外上冊書頁 873 與 ICU Book 重新整理；床頭角度與移位觀察為一般重症護理原則（待核對）

- 書上寫 IABP 病人維持 MAP 約 60–80 mmHg、拔除後穿刺處加壓並觀察約 24 小時（內外上冊書頁 873）；實際目標與加壓方式依醫囑與院內規範

### 併發症與警示 {#iabp-complications}

| 狀況 | 表現 | 處理 |
|---|---|---|
| **下肢缺血** | 患肢冰冷、蒼白、脈搏變弱、疼痛、麻木 | 立即通知醫師 |
| **氣球破裂** | 管路內出現**血色斑點或血液**、氦氣漏失警示 | **立即停機**、通知醫師，準備移除 |
| 氣球移位 | 左手脈搏消失（往上）、尿量驟減（往下） | 通知醫師、照 X 光確認位置 |
| 出血、血小板減少 | 穿刺處滲血、瘀斑 | 監測凝血與血小板、加壓止血 |
| 感染 | 發燒、穿刺處紅腫 | 培養、無菌照護 |

依 ICU Book 整理（待核對）

## 葉克膜(ECMO) {#ecmo}

### VV 與 VA {#ecmo-types}

| 項目 | **VV-ECMO**（靜脈 → 靜脈） | **VA-ECMO**（靜脈 → 動脈） |
|---|---|---|
| 血流路徑 | 從大靜脈引出 → 氧合器 → 打回**靜脈** | 從大靜脈引出 → 氧合器 → 打回**動脈**（常用股動脈） |
| 支持 | **只換肺**（氣體交換），循環仍靠病人自己的心臟 | **心與肺都支持** |
| 適用 | 嚴重呼吸衰竭、ARDS（見 [[ards-respiratory-failure]]） | **心因性休克**、心肌炎、心臟手術後無法脫離體外循環、心跳停止時的**體外心肺復甦(ECPR)** |
| 好處 | 讓肺休息，降低呼吸器高壓造成的傷害 | 減少強心劑劑量，讓心臟休息 |

內外上冊書頁 869 Box 10-9 的概念重新整理

- 2025 AHA：ECPR 需要高度專業團隊與資源；心跳停止後頑固性心因性休克可考慮臨時機械循環支持；低體溫造成心跳停止可用 ECLS 回溫（2025 AHA 摘要；另見 [[emergency-nursing#hypothermia]]）

### 護理重點 {#ecmo-nursing}

1. **抗凝**：整套管路需肝素化，依醫囑監測 **aPTT**（或 ACT）、血小板、血紅素（內外上冊書頁 869）
2. **出血觀察**：插管處、手術傷口、腸胃道、尿液、顱內出血（意識、瞳孔）；避免不必要的穿刺與肌肉注射
3. **管路安全**：固定牢靠、不可扭折或拉扯；翻身時至少兩人並由專人顧管路；管路保持密閉、無菌（內外上冊書頁 869）
4. **肢體循環**：股動脈插管側下肢缺血風險高，定時比較兩側脈搏、顏色、溫度
5. **溶血**：觀察茶色尿、血漿游離血紅素上升（內外上冊書頁 869）
6. **血行動力與氧合**：流量、轉速、動脈血液氣體分析、乳酸；VA-ECMO 病人的動脈波形可能很平（脈搏壓小）
7. **感染**：無菌換藥、每日評估管路
8. **體溫**：體外循環會讓病人體溫下降，必要時用機器加溫
9. 家屬支持：說明目的與「橋梁」性質，協助面對不確定的預後

- ECMO 有出血、溶血、栓塞、感染等風險，只適合**緊急、暫時性**使用（書上寫盡量 < 14 天）；需要長期支持就考慮 VAD 或心臟移植（內外上冊書頁 869）

## 心室輔助器(VAD) {#vad}

- 把心房或心室的血引到幫浦再打到動脈，替心臟作功；最常用**左心室輔助器(LVAD)**（內外上冊書頁 869）
- 用途：等待心臟移植的橋梁，或不能移植者的長期治療
- LVAD 是連續性血流，病人可能**摸不到脈搏、量不到一般血壓**；2025 AHA：LVAD 病人無反應且灌流不良時應開始胸部按壓（2025 AHA 摘要）
