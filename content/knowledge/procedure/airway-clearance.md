**呼吸道清潔技術**幫助病人把痰排出來，維持呼吸道通暢、預防肺擴張不全與肺炎。病人自己能咳時先用**深呼吸、有效咳嗽、誘發性肺量計**；痰多又黏時加上**噴霧治療**與**胸腔物理治療**（姿位引流、叩擊、震顫）；自己咳不出來或有人工氣道時才**抽痰**。呼吸音的評估見 [[respiratory-assessment#breath-sounds]]，人工氣道見 [[artificial-airway]]

## 重點摘要 {#summary}

- 抽痰**只在需要時**（聽到痰音、看到分泌物、SpO₂(Peripheral oxygen saturation) 下降、呼吸器高壓或鋸齒波形），不定時常規抽
- 抽前後**給氧**、**人工氣道用無菌技術**、**插入時不抽吸**、邊旋轉邊抽出、**每次 ≤ 15 秒**
- **不常規滴生理食鹽水**；抽痰管外徑小於人工氣道內徑的一半（成人與兒童）
- 抽痰中**最重要的是監測血氧**與心跳；結束後聽呼吸音評值
- 胸腔物理治療順序：**噴霧** → **姿位引流** → **叩擊、震顫** → **咳嗽或抽痰**
- 時間：**飯前 1 小時或飯後 1–2 小時**；**上葉先引流，再下葉**
- 姿位引流靠**重力**：患部在上，下葉引流要頭低腳高
- 叩擊：手**弓成杯狀**、隔一層布、每個部位約 1–2 分鐘；避開脊椎、胸骨、腎臟、乳房；有出血傾向、肋骨骨折、顱內壓高時不做

### 國考常考點 {#exam-points}

- 抽氣切病人的痰時最重要：**評估血氧變化**
- 抽痰管要在**沒有抽吸壓力**下放到抽吸部位（正確）；每小時常規抽痰、嬰兒壓力 110–130 mmHg 都是錯的
- 氣切抽痰：壓力 120–150 mmHg、抽前給氧 30–60 秒、抽完聽呼吸音都適當；**抽痰管插入 15–20 公分**不適當（太深）
- 兒童抽痰：抽前後**給氧**避免缺氧（正確）；嬰幼兒壓力 110–120 mmHg、抽 12–15 秒、**抽前滴生理食鹽水**都是錯的；早產兒每次抽吸約 **6–8 秒**（國考答案）
- 早產兒氣管內管抽吸：抽痰管約 **5–8 Fr**（正確）；鼻→口→氣管內管的順序、一次 20 秒、壓力「不可超過 60 mmHg」都是錯的
- 有氣管內管的嬰兒，抽痰順序「氣管內管→口腔→鼻腔」本身符合原則（先人工氣道再口鼻；同一條管子**不可從口鼻再進入人工氣道**），但 110-2_OP_063 該題官方答案是「無抽吸壓力下放入抽痰管」
- 人工氣道抽痰屬**外科無菌**技術
- **姿位引流**是利用**重力**讓分泌物流到大支氣管
- 姿位引流較不適當的時間：**飯後半小時**（適合：早上睡醒、睡前、飯前 1 小時）
- 胸腔物理治療包括**呼吸運動與呼吸肌訓練**；不是先叩擊再噴霧、不是飯前飯後 1 小時內、上下葉都要引流時**不是先下葉**
- 叩擊：擺好姿位引流姿勢**後**、在引流期間配合進行（國考選項「姿位引流後執行」算對）、手指併攏弓成杯狀、每部位 1–2 分鐘；**直接拍在裸露皮膚**不適當；每部位 10–15 分鐘太久；有出血危險不叩擊
- 下葉痰多：**頭低腳高**姿位叩擊；脊椎突出處**不可**加強叩擊
- 先噴霧，再姿位引流與叩擊（正確）；左肺上葉前節要**仰臥**、叩擊鎖骨與乳頭之間
- 下葉上段（背段）：**俯臥**（國考答案：俯臥、頭放低 15 度）
- 小型噴霧器：藥杯與噴霧器**每次用完清洗晾乾**（說「每天清洗一次」是錯的）；氣流 6–8 L/min、噴霧器保持直立
- 蒸氣吸入目的：以蒸氣把熱用在呼吸道、**濕潤黏膜、稀釋分泌物**（不是提高血氧、不是給藥鬆弛支氣管）
- 灌食後不要立即拍背抽痰
- 定量吸入器(MDI)與乾粉吸入器的用法見 [[asthma-drugs#mdi-steps]]

## 深呼吸、有效咳嗽與誘發性肺量計 {#breathing-cough}

1. **深呼吸**：鼻子慢慢吸到最飽、停幾秒，再噘嘴慢慢吐；撐開肺泡、預防肺擴張不全
2. **有效咳嗽**
   1. 坐起、身體稍前傾
   2. 深吸氣數次，最後一次吸飽後**閉氣**，再連續用力咳 2–3 聲
   3. 手術病人**用枕頭或手按住傷口**、咳嗽前先止痛
   4. **哈氣咳嗽**（張口快速呵氣）較不累，適合 COPD 與術後病人，見 [[copd#breathing-exercises]]
3. **誘發性肺量計**
   1. 坐起，含住吹嘴，**慢慢深吸**讓浮球（或指示器）上升，吸到最大後**閉氣數秒**再吐
   2. 清醒時每小時做數次（依醫囑），記錄可達到的容量
   3. 目的：持續最大吸氣 → 撐開肺泡、預防術後**肺擴張不全**與肺炎，見 [[restrictive-lung-diseases#atelectasis]]
   4. 幼兒可用吹泡泡、吹紙風車代替（長庚兒童胸管衛教）
4. 足夠水分讓痰變稀（心衰竭、腎衰竭要限水者依醫囑）；早期下床

## 噴霧與蒸氣吸入 {#aerosol}

1. **小型噴霧器**（噴射式）
   1. 藥物與生理食鹽水放入藥杯，接氧氣或壓縮空氣（國考書：6–8 L/min）
   2. 噴霧器**保持直立**，產生約 2–5 µm 的微粒才能到達下呼吸道
   3. 病人坐起，用咬嘴或面罩，**慢而深**地呼吸，直到藥杯沒有霧氣
   4. 用完**每次清洗、晾乾**，個人專用；吸類固醇後漱口
2. **超音波噴霧器**：顆粒細、量大；底部水槽依產品加水（國考：不是加生理食鹽水）
3. **蒸氣吸入**：把熱以蒸氣方式用在呼吸道，**濕潤黏膜、稀釋分泌物**；注意燙傷；噴霧瓶依規範更換溶液
4. 噴霧治療在胸腔物理治療**之前**做，先讓支氣管擴張、痰變稀
5. 定量吸入器、乾粉吸入器與吸藥輔助器見 [[asthma-drugs#inhalers]]

## 胸腔物理治療 {#chest-physiotherapy}

1. 內容：**姿位引流**、**叩擊**、**震顫**、咳嗽訓練，以及**呼吸運動與呼吸肌訓練**
2. 適應症：痰多且黏、咳不出來（支氣管擴張症、囊性纖維化、肺炎、細支氣管炎、長期臥床）
3. 時間：**飯前 1 小時或飯後 1–2 小時**（避免嘔吐、吸入）；早上起床（整夜痰積聚）、睡前
4. 順序：**噴霧** → **姿位引流** → **叩擊、震顫** → **咳嗽或抽痰**；**上葉先、下葉後**
5. 禁忌與暫停
   1. **顱內壓升高**、顱腦或眼睛手術後（不可頭低）
   2. **出血傾向**、咳血、血小板低、抗凝血治療
   3. 肋骨骨折、脊椎不穩、骨質疏鬆嚴重、胸部傷口
   4. 未處理的氣胸、肺栓塞、血行動力不穩
   5. 過程中出現呼吸窘迫、發紺、躁動 → **立即停止**

### 姿位引流 {#postural-drainage}

1. 原理：利用**重力**，讓要引流的肺段在上、支氣管朝下，分泌物流到大支氣管再咳出
2. 原則：痰在哪個肺段，就讓那個肺段在**最高處**；**上葉**多採坐姿或平躺，**下葉**採**頭低腳高**
3. 常見姿位

| 肺段 | 姿勢 | 叩擊部位 |
|---|---|---|
| 上葉尖段 | 坐起（稍向前或向後靠） | 鎖骨上方與肩胛骨上方 |
| 上葉**前段** | **仰臥平躺** | **鎖骨與乳頭之間** |
| 上葉後段 | 坐起身體前傾，或俯臥 | 肩胛骨上背部 |
| 右中葉、左舌葉 | 側臥向健側再往後轉約 1/4，臀部墊高（頭低） | 腋前、乳頭外側 |
| 下葉**上段（背段）** | **俯臥**，腹部墊枕（國考答案：俯臥頭放低 15 度） | 肩胛骨下緣的背部 |
| 下葉外側基底段 | **側臥向健側**（患側在上），**頭低腳高** | 下胸側面 |
| 下葉後基底段 | **俯臥頭低腳高** | 下背部肋骨處 |
| 下葉前基底段 | 仰臥頭低腳高 | 下胸前外側 |

- 角度與每個姿位的時間依病人耐受與院內規範；嬰兒可抱在照顧者腿上調整姿勢
- 右側腋下聽到爆裂音的嬰兒：**左側臥、臀部墊高**引流（國考答案）

### 叩擊與震顫 {#percussion-vibration}

1. **叩擊**
   1. 手指併攏、**手掌弓成杯狀**，手腕放鬆，有節奏地拍（聲音是空洞的「啵啵」聲）
   2. 隔**一層薄布或病人服**，不直接拍裸露皮膚
   3. 每個部位約 **1–2 分鐘**（國考答案），依病人耐受增減
   4. 避開**脊椎**、**胸骨**、**腎臟**、乳房、骨突處與傷口
   5. 嬰兒可用面罩或專用叩擊杯
2. **震顫**：手掌平貼胸壁，在病人**吐氣時**快速細微震動，幫助痰往上移動
3. 叩擊後鼓勵**深呼吸、咳嗽**，或抽痰；評估呼吸音、痰的量與性狀

## 抽痰 {#suctioning}

### 目的與適應症 {#suction-indications}

1. 目的：移除病人無法自行咳出的分泌物，維持呼吸道通暢、改善換氣
2. 什麼時候抽（AARC 2022：**只在需要時**，不定時常規抽）
   1. 聽到**粗糙痰音**、喉嚨有咕嚕聲、看得到分泌物
   2. **SpO₂ 下降**、呼吸費力、躁動
   3. 呼吸器**高壓警報**、流量波形**鋸齒狀**，見 [[mechanical-ventilation#reading]]
   4. 要收集痰液檢體（氣切病人用抽痰取痰）

### 用物 {#suction-equipment}

1. 抽吸機或牆上抽吸、壓力錶、集痰瓶
2. **無菌抽痰管**：外徑**小於人工氣道內徑的 50%**（新生兒 < 70%）(AARC 2022)
3. 無菌手套（人工氣道抽痰）、無菌生理食鹽水或無菌水（沖管用）
4. 氧氣、**甦醒球**、脈衝式血氧計
5. 密閉式抽痰系統（呼吸器病人可用；開放式與密閉式都安全有效）

### 步驟 {#suction-steps}

| 步驟 | 理由 |
|---|---|
| 1. 評估是否需要抽（呼吸音、SpO₂、分泌物）；說明過程 | 避免不必要的抽痰與傷害 |
| 2. 洗手、半坐臥（無禁忌時）；裝好監測 | 方便咳嗽與觀察 |
| 3. 調整抽吸壓力（見下表），確認抽吸功能 | 壓力太大會傷黏膜、造成肺塌陷 |
| 4. **抽前給氧**（提高氧濃度約 30–60 秒，國考書；AARC 2022 建議兒童與成人抽前給氧） | 預防抽痰造成的低血氧 |
| 5. 戴**無菌手套**，慣用手保持無菌拿抽痰管 | 人工氣道直通下呼吸道，屬外科無菌 |
| 6. **不按壓控制口（沒有抽吸）**下放入抽痰管；優先用**淺抽**（到人工氣道末端），淺抽無效才深抽 | 放管時抽吸會傷黏膜、吸走肺內氣體 |
| 7. 按住控制口，**邊旋轉邊往外抽出** | 均勻抽除、減少黏膜損傷 |
| 8. 每次抽吸**不超過 15 秒**(AARC 2022)；兒童越小越短 | 時間越長越缺氧 |
| 9. **抽後再給氧**，讓病人休息、血氧回升再抽下一次 | 恢復氧合 |
| 10. 先抽**人工氣道**，再抽口鼻；**抽過口鼻的管子不可再進人工氣道** | 由乾淨到髒，避免把口腔細菌帶進肺 |
| 11. 用無菌水沖洗連接管；丟棄抽痰管與手套 | 感染控制 |
| 12. **評值**：聽診呼吸音、SpO₂、心跳、痰的量色質；記錄 | 確認效果與副作用 |

1. 抽吸壓力

| 對象 | 壓力 | 來源 |
|---|---|---|
| 成人 | **< 200 mmHg**；國考書常用 **120–150 mmHg** | AARC 2022；國考答案 |
| 兒童、新生兒 | **< 120 mmHg**；年紀越小越低 | AARC 2022 |
| 國考判為錯誤 | 嬰幼兒 110–120 或 110–130 mmHg（太高） | 國考答案 |

2. **不常規滴生理食鹽水**：AARC 2022 建議一般避免；滴入會造成血氧下降、心律不整、把細菌沖到下呼吸道
3. 口鼻抽痰（沒有人工氣道）
   1. 經鼻抽吸前先估長度（約鼻尖到耳垂）；鼻腔出血、顱底骨折禁用經鼻
   2. **新生兒先抽口、再抽鼻**（抽鼻會刺激吸氣，把口中分泌物吸進肺）
   3. 早產兒呼吸暫停警報響時先**輕拍、輕揉背部刺激**，不是先抽吸，見 [[ards-respiratory-failure#neonatal-rds]]

### 併發症 {#suction-complications}

| 併發症 | 徵象 | 預防與處理 |
|---|---|---|
| **低血氧** | SpO₂ 下降、發紺、躁動 | 抽前後給氧、縮短時間、只在需要時抽；**持續監測血氧** |
| 心律不整、**心跳變慢** | 刺激迷走神經 | 監測心跳；變慢時停止抽吸並給氧 |
| 黏膜損傷、出血 | 痰帶血絲 | 壓力不要太大、放管時不抽吸、淺抽 |
| 肺擴張不全 | 呼吸音減弱 | 抽痰管不要太粗、時間不要太長 |
| 支氣管痙攣 | 喘鳴音 | 停止、依醫囑給支氣管擴張劑 |
| **顱內壓上升** | 頭部外傷病人 ICP 上升 | 縮短時間、事前給氧，見 [[increased-icp]] |
| 感染 | 發燒、痰變濃 | 無菌技術、手部衛生 |

:::warning[注意]
抽痰中 SpO₂ 明顯下降或心跳變慢，要**立即停止**、接回氧氣或用甦醒球給 100% 氧；抽痰管無法通過人工氣道時，可能是痰栓或管子扭折，要立即通知醫師
:::

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 每小時固定抽一次痰 | 評估後需要才抽 | 不必要的抽痰增加缺氧、黏膜損傷與感染 |
| 放管時就開始抽 | 放管時不抽，抽出時才抽 | 減少黏膜損傷與肺內氣體被吸走 |
| 痰黏就先滴生理食鹽水 | 加強濕化、補充水分；不常規滴入 | 滴入會降低血氧、把細菌帶進肺 |
| 先抽口鼻，再用同一條管子抽氣管內管 | 先人工氣道，再口鼻；換管不重複使用 | 避免把口腔細菌帶進下呼吸道 |
| 飯後馬上做姿位引流與叩擊 | 飯前 1 小時或飯後 1–2 小時 | 頭低姿勢與震動會引起嘔吐、吸入 |
| 叩擊直接拍皮膚、拍脊椎 | 隔一層布、避開脊椎胸骨腎臟 | 避免皮膚不適與受傷 |
