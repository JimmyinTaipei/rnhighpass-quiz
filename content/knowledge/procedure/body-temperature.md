**體溫**是產熱與散熱平衡的結果，由**下視丘**像恆溫器一樣調節，核心溫度維持在約 37 ℃。體溫是最常量的生命徵象，也是感染、脫水、甲狀腺疾病與休克的早期線索。本頁整理體溫的調節與影響因素、各種測量方法、發燒的分期型態與護理、熱傷害與低體溫；冷熱療法的應用見第 10 輪，脈搏與血壓見 [[pulse-blood-pressure]]

## 重點摘要 {#summary}

- 體溫中樞在**下視丘**(負回饋)；肝臟是溫度**最高**的器官
- 主要散熱器官是**皮膚**；常溫下**輻射**最多(約 60%)，其次蒸發、對流、傳導；環境溫度高於體溫時只剩**蒸發**有效
- 各部位：**肛溫 > 口溫 ≈ 耳溫 > 腋溫**；一天中**清晨 4–6 點最低、傍晚 4–8 點最高**，差約 0.5–1 ℃
- 排卵後**黃體素**使基礎體溫**上升約 0.3–0.6 ℃**；甲狀腺素、運動、進食、壓力、吸菸使體溫升高；老人體溫較低
- 發燒(> 38 ℃)三期：**畏寒期**(設定點上升，**蒼白冰冷、寒顫**、心跳呼吸加快)→ **極熱期**(潮紅發燙、口渴、尿少)→ **退熱期**(**流汗**、可能脫水)
- 體溫每升 1 ℃，**代謝率約增 13%**、**脈搏約增 8–10 次**
- 發燒護理：寒顫時**保暖**、發熱時減衣；室溫約 **20–24 ℃**；無限水者每天喝 **3,000 mL** 以上；高熱量高蛋白、清淡、少量多餐；口腔護理；臥床休息
- 熱衰竭：**大量流汗、蒼白濕冷**、脈快弱、血壓低、體溫 < 40 ℃、**意識清楚**；中暑：**> 40 ℃、皮膚紅熱乾**、**意識改變**
- 低體溫(< 35 ℃)：代謝、脈搏、呼吸、血壓、**尿量下降**、嗜睡；**漸進回溫**，不可快速加溫

### 國考常考點 {#exam-points}

- 身體溫度最高的部位：**肝臟**
- 人體主要的散熱途徑：**皮膚**；主要的散熱方式：**皮膚輻射**
- 散熱原理：減少被蓋、身體伸展、皮膚血管擴張 → **輻射**；冰枕、涼蓆、暖暖包 → **傳導**；**調整空調**、電扇 → **對流**；流汗、溫水拭浴、**運動後呼吸變快** → **蒸發**
- 新陳代謝增加會使體溫**上升**(說會下降是錯的)
- 體溫 36.2 → 37.2 ℃：代謝率約增加 **13%**
- 黃體素增加 → 基礎體溫**上升 0.3–0.6 ℃**；吸菸、甲狀腺素使體溫升高；一天變動約 0.5–1 ℃(不是 2.5 ℃)
- **脫水**會造成體溫過高；大出血、營養不良、酒精中毒使體溫降低
- 發燒初期：**心跳加快**、**呼吸加快**、**皮膚蒼白**；皮膚發燙是極熱期
- 發燒型態：**恆常熱**＝一直高於正常、一天溫差 < 1 ℃(例：耳溫維持 38.5–39.5 ℃)；**弛張熱**＝溫差 > 1 ℃但**不會降到正常**；**間歇熱**＝一天內在高燒與正常之間；**回歸熱**＝發燒幾天、正常幾天交替(**術後傷口感染**、瘧疾、登革熱)
- 發燒護理不適當：室溫調到 27–28 ℃、高燒時**鼓勵下床活動**、高醣高脂低蛋白飲食、**請很多家屬陪伴**；**腎衰竭**發燒病人**不可**建議每天喝 3,000 mL
- 低於 39 ℃ 的發燒一般不傷身；術後常見發燒；**寒顫時保暖**
- 熱衰竭(路跑後大量流汗、蒼白濕冷、血壓低、脈快弱)：平躺、**抬高下肢**，不要墊高頭
- 低體溫：**尿量減少**(不是增加)、嗜睡、脈搏呼吸變慢、血壓下降；**不可快速加溫**；可給溫的靜脈輸液；33 ℃ 以下會失去意識
- 耳溫：成人**往上往後拉**、**3 歲以下往下往後**；**耳垢過多影響數值**；耳道發炎不用；每次換耳套；耳溫高於腋溫、**低於肛溫**
- 嬰兒肛溫插入 **0.5–1 吋**(2 吋太深)；測體溫是**內科無菌**
- 80 歲耳溫 37.9 ℃：老人耳溫**容易受環境溫度影響**；老人體溫較低，這個數值已偏高
- 昏迷臥床老人懷疑測得不準：同時重複測量**採最高值**
- 不需要每 4 小時量體溫：**電腦斷層檢查後**(發燒、病危、術後第二天都要)

## 體溫調節 {#regulation}

1. **核心溫度**：身體深部(腦、肝、內臟)，保持約 37 ℃，**肝臟最高**
2. **體表溫度**：皮膚與脂肪層，隨環境變化
3. 負回饋迴路
   1. **感覺接受器**：主要在皮膚，**冷覺接受器比熱覺多**(對冷較敏感)
   2. **控制中樞**：**下視丘**，設定點約 37 ℃，也偵測流經腦部的血液溫度
   3. **反應器**：血管、汗腺、骨骼肌

| 體溫偏高時(促進散熱) | 體溫偏低時(增加產熱、減少散熱) |
|---|---|
| 皮膚血管**擴張** | 皮膚血管**收縮** |
| **流汗**增加 | 流汗減少或停止 |
| 減少肌肉活動與代謝 | **顫抖**、增加代謝 |
| 呼吸變淺快 | 分泌腎上腺素、甲狀腺素 |

4. 行為調節：加減衣物、找陰涼處、開冷暖氣

### 散熱方式 {#heat-loss}

| 方式 | 原理 | 例子 |
|---|---|---|
| **輻射** | 不需要介質，熱以紅外線散出；常溫下最多(約 60%) | 減少被蓋、**身體伸展**增加表面積、皮膚血管擴張 |
| **傳導** | 直接**接觸**較冷或較熱的物體 | **冰枕**、睡**涼蓆**、**暖暖包**、熱水袋 |
| **對流** | 流動的**空氣或水**帶走熱 | **調整空調**、電風扇、空氣流通 |
| **蒸發** | 水分由液體變氣體帶走熱 | **流汗**、**溫水拭浴**、**呼吸**時的水分散失(無感性散失) |

- 主要散熱器官：**皮膚**(約 85–90%)；其餘經呼吸、排尿排便
- 環境溫度**高於**體溫時，輻射、傳導、對流反而吸熱，只剩**蒸發**能散熱

## 影響體溫的因素 {#factors}

1. **年齡**：嬰幼兒調節中樞未成熟、體表面積大 → 易受環境影響；**老人**皮下脂肪少、代謝低、對溫度不敏感 → **體溫較低**
2. **晝夜節律**：一天變動約 **0.5–1 ℃**；**清晨 4–6 點最低**、**傍晚 4–8 點最高**
3. **荷爾蒙**
   1. **甲狀腺素**、生長激素、腎上腺素 → 代謝增加、體溫**升高**(甲狀腺低下 → 體溫低)
   2. **黃體素**：**排卵後**上升，基礎體溫**升高約 0.3–0.6 ℃**，維持到月經前；可用**基礎體溫**判斷排卵，見 [[sex-hormones]]
   3. 女性體溫通常比男性高；更年期熱潮紅
4. **運動、進食**：代謝增加 → 升高；**飢餓**時下降
5. **環境**：溫度、對流、穿著
6. **壓力、情緒**：交感神經興奮 → 升高
7. **吸菸**：吸入熱煙，口溫偏高
8. **酒精**：感覺發熱，實際上血管擴張 → **體溫下降**；酒精中毒易低體溫
9. **疾病**
   1. **感染**：白血球釋放內生性致熱原 → 下視丘產生**前列腺素 E2** → **設定點上升**
   2. 其他升高：**脫水**(散熱減少)、過敏、癌症、梗塞、顱內壓上升
   3. 降低：**大出血**、敗血性休克末期、**營養不良**、甲狀腺低下
10. 藥物：退燒藥降低設定點；部分抗生素引起藥物熱

## 正常體溫與測量 {#measurement}

1. 正常體溫約 **36–37 ℃**；各部位高低：**肛溫 > 口溫 ≈ 耳溫(顳溫) > 腋溫**(口溫與肛溫約差 0.5 ℃)
2. 正常範圍(課本，成人 11–65 歲)：口溫約 36.4–37.6 ℃、肛溫約 37–38.1 ℃、腋溫約 35.2–36.9 ℃、耳溫約 35.9–37.6 ℃；**65 歲以上各部位都較低**
3. 各種測量方法

| 部位 | 做法 | 不適用(禁忌) |
|---|---|---|
| **口溫** | 舌下熱袋，閉口、不咬；**剛抽菸、吃冷熱食要等 15–30 分鐘** | **6 歲以下**、口鼻手術、張口呼吸、咳嗽鼻塞、**意識不清**、不合作、抽搐病史、**用氧中**、顏面麻痺 |
| **腋溫** | 擦乾腋下、夾緊 | 腋下傷口、出汗多、肩傷夾不緊 |
| **肛溫** | 潤滑、側臥；國考：成人插入約 1.5 吋、**嬰兒 0.5–1 吋** | 直腸手術、腹瀉、痔瘡、心臟病(刺激迷走神經)、新生兒少用 |
| **耳溫** | 套新耳套；**3 歲以上與成人耳廓往上往後拉**、**3 歲以下往下往後拉** | 耳道發炎、耳部手術、**耳垢多**(影響數值) |
| 額溫 | 距額頭 3–6 cm；易受環境影響 | **只能做初步篩檢** |
| 顳溫 | 掃過顳動脈 | 前額或顳部皮膚受損、流汗 |

4. 儀器
   1. **耳溫槍**：測耳膜的紅外線熱輻射；耳膜與下視丘血流同源 → 接近核心溫度；住院病人可用個人耳套；定期校正
   2. **電子體溫計**：口、腋、肛都可用，嗶聲表示完成
   3. 準確度：耳溫槍、電子體溫計 > 水銀 > 拋棄式 > 感溫貼片
   4. **水銀體溫計**已禁止使用(課本：環保署 2012 年起)，國考仍可能出現
5. 測量原則
   1. 測體溫屬**內科無菌**(清潔技術)，體溫計個人專用或用護套
   2. 一般住院每天固定時間量；**發燒、病危、術後初期**(術後 72 小時內)每 4 小時或更密集
   3. 吃退燒藥後約 **1 小時**再量一次並記錄
   4. 懷疑數值不準時重量；同時重複測量取**最高值**
   5. 老人體溫基準較低、耳溫易受環境影響 → 37.5 ℃ 以上就要注意，比較病人自己的平常值

## 發燒 {#fever}

1. 定義：體溫 > **38 ℃**(課本)；COVID-19 期間指揮中心用耳溫 ≥ 38 ℃、額溫 ≥ 37.5 ℃
2. 機轉：致熱原 → 前列腺素 E2 → 下視丘**設定點上升**，身體以為自己太冷而產熱
3. 分級(肛溫，課本)：低度 38.1–39 ℃、中度 39.1–40 ℃、高燒 40.1–41.1 ℃、體溫過高 > 41.1 ℃
4. 體溫每升 **1 ℃**：基礎代謝率約增 **13%**、脈搏約增 **8–10 次／分**

### 發燒分期 {#fever-stages}

| 分期 | 發生什麼 | 表現 |
|---|---|---|
| **畏寒期**(發作期、發冷期) | 設定點上升，體溫低於新設定點 → 保熱產熱 | **寒顫**、**皮膚蒼白乾冷**、甲床發紺、**心跳加快**、**呼吸加快加深**、口渴 |
| **極熱期**(高熱期) | 體溫到達設定點並維持 | **皮膚潮紅發燙**、口渴、頭痛、**尿少**、黏膜乾裂、倦怠、食慾差；高燒時譫妄 |
| **退熱期** | 設定點恢復，體溫高於設定點 → 散熱 | **大量流汗**、皮膚潮濕；**漸退**(2–3 天到一週，好轉)或**驟降**(24 小時內，注意**脫水**、休克) |

![發燒三期：設定點上升、維持、下降與體溫曲線](/knowledge-images/fever-stages.svg)

### 發燒型態 {#fever-patterns}

| 型態 | 定義 | 常見疾病 |
|---|---|---|
| **恆常熱**(稽留熱) | 一直高於正常，**一天溫差 < 1 ℃** | 傷寒、病毒性肺炎 |
| **弛張熱** | 一直高於正常，**溫差 > 1 ℃**，**不會降到正常** | 敗血症、肺結核、風濕熱 |
| **間歇熱** | 一天內**高燒與正常交替** | 敗血症、膿瘍、心內膜炎、瘧疾、淋巴瘤 |
| **回歸熱**(復發熱) | **發燒數天、正常數天**交替 | **術後傷口感染**、登革熱、瘧疾 |

### 發燒的護理 {#fever-care}

1. 環境
   1. 室溫約 **20–24 ℃**(課本 20–23.9 ℃)，安靜、通風；不要調高到 27–28 ℃
   2. 限制訪客，讓病人休息；**不要很多人陪**(室溫上升、感染、干擾休息)
2. 依分期處理
   1. **畏寒期**：**加蓋被子、保暖**，不急著冰敷
   2. **極熱期**：減少衣物被蓋、寬鬆棉質衣服；冰枕、溫水拭浴(依醫囑；步驟見 [[heat-cold-therapy#cold-methods]])
   3. **退熱期**：擦乾汗、更換衣物床單、補充水分
3. 水分：無限水者每天 **3,000 mL** 以上；**心衰竭、腎衰竭**病人**依醫囑限水**
4. 飲食：**高熱量、高蛋白、高維生素**、**低脂**、清淡流質或半流質、少量多餐
5. **口腔護理**：口乾、唇裂、舌苔
6. **臥床休息**，減少耗氧；高燒急性期**不鼓勵下床活動**
7. 監測：生命徵象、輸出入量、脫水徵象、CBC 與培養報告；退燒藥後 1 小時再量
8. 降溫(依醫囑，課本兒科常規)：37.5–38 ℃ 水枕、38–38.5 ℃ 冰枕、38.5–39.5 ℃ 退燒栓劑、39.5 ℃ 以上退燒藥加溫水拭浴
9. 原則：發燒是對抗感染的防禦反應，重點是**治療原因並讓病人舒適**，不是把數字壓下來

## 熱傷害 {#heat-illness}

| 項目 | **熱衰竭** | **中暑** |
|---|---|---|
| 原因 | 大量流汗，**水分與鈉流失** | 體溫調節中樞**失效** |
| 體溫 | 上升但**通常 < 40 ℃** | **> 40 ℃** |
| 皮膚 | **蒼白、濕冷**、大量出汗 | **紅、熱、乾**(可能無汗) |
| 意識 | **清楚**(頭暈、虛弱、頭痛、噁心) | **意識改變**、譫妄、抽搐、昏迷 |
| 循環 | 脈搏**快而弱**、**血壓下降** | 心跳快，嚴重時休克 |
| 處理 | 移到陰涼處、**平躺、抬高下肢**、鬆衣、清醒時喝水 | **立即降溫**(目標快速降到 39 ℃ 以下)、送醫，危及生命 |

- 熱痙攣：電解質流失造成肌肉抽筋，體溫與血壓通常不變
- 熱衰竭時頭部**不墊高**(減少腦部血流)
- 燒燙傷與環境傷害的機轉見 [[environmental-injury#heat-injury]]

## 低體溫 {#hypothermia}

1. 定義：**核心溫度 < 35 ℃**；高危險：老人、遊民、酒醉、溺水、大出血、敗血症
2. 分級(課本)

| 程度 | 溫度 | 表現 | 護理 |
|---|---|---|---|
| 輕度 | **32–35 ℃** | **發抖**、皮膚**蒼白冰冷**、代謝與脈搏呼吸先**增加**、血壓上升、反應變慢 | 換掉濕衣、保持乾燥、喝溫熱飲料、主動活動 |
| 中度 | 28–32 ℃ | 脈搏與心輸出量**減少**、呼吸**變慢**、反射變差、顫抖減少、瞳孔放大、**心律不整**；< 32 ℃ 心跳停止風險上升 | 監測心臟(**頸動脈測 1 分鐘**)、隔絕寒冷、**加溫輸液**(生理食鹽水優於林格氏液)、熱毯放**胸部、鼠蹊、腋下**等軀幹 |
| 重度 | < 28 ℃ | 無反射、昏迷、低血壓、心搏過緩、心律不整，可能死亡 | 急救 |

3. 共通表現：代謝下降 → **脈搏、呼吸、血壓下降**；腎血流減少 → **尿量減少**；**嗜睡**、意識模糊(約 33 ℃ 以下可能失去意識)
4. 回溫原則
   1. **漸進回溫**，**不可快速加溫**
   2. 原因：周邊血管突然擴張 → 血壓驟降(回溫休克)、冷血回流核心 → 核心溫度**再下降**(after drop)、心律不整
   3. 先暖軀幹，不先暖四肢；不用溫水沐浴、小型化學暖暖包(易燙傷)
   4. 依醫囑給**溫的靜脈輸液**與溫暖潮濕的氧氣
5. 凍瘡：離開寒冷、脫濕衣、患處泡溫水(從 10–15 ℃ 開始)、**不摩擦按摩**、不用烤燈
6. 新生兒體溫散失與保暖見第 16 輪

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 發燒病人一發抖就冰敷 | 畏寒期先保暖，到極熱期再散熱 | 設定點還在上升，冰敷只會更冷更抖 |
| 發燒一律多喝水 3,000 mL | 心衰竭、腎衰竭依醫囑限水 | 體液過多、肺水腫 |
| 冷氣是傳導散熱 | 空調是對流 | 靠流動的空氣帶走熱 |
| 低體溫要用熱水快速泡暖 | 漸進回溫、先暖軀幹 | 回溫休克、核心溫度再下降 |
| 2 歲量耳溫往上往後拉 | 3 歲以下往下往後 | 幼兒耳道方向不同 |
| 老人耳溫 37.9 ℃ 算正常 | 已偏高，要評估感染 | 老人基準體溫較低、發燒不明顯 |
| 熱衰竭讓病人坐起頭墊高 | 平躺抬高下肢 | 增加回心血量與腦部灌流 |
