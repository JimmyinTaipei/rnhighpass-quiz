腸道功能正常但無法由口進食時，用**管灌**（腸道營養）；腸道不能用或要禁食較久時，用**靜脈營養**。本頁整理**途徑選擇**、**鼻胃管的置入與位置確認**、**灌食方法與步驟**、**胃殘餘量的判斷**、**合併症**、**鼻胃管護理與拔除**、**兒童管灌**與**全靜脈營養(TPN, total parenteral nutrition)／周邊靜脈營養(PPN, peripheral parenteral nutrition)**。營養評估與治療飲食見 [[nutrition-assessment-diets]]，鼻胃管給藥見 [[non-parenteral-medication#ng-tube-medication]]，中心靜脈的原則見 [[iv-therapy#nutrition-routes]]

## 重點摘要 {#summary}

- 途徑：**腸道能用就用腸道**；短期用鼻胃管、長期（約 4–6 週以上）或吸入風險高改**胃造瘻或空腸造瘻**；腸道不能用 → **短期 PPN、長期 TPN**
- 置入：**坐或半坐臥**（不能坐起：**床頭稍抬高、右側臥**）；取下活動假牙；**水溶性潤滑劑**（不用凡士林）潤滑前端 5–10 cm；成人長度約 **45–55 cm**（鼻尖 → 耳垂 → 劍突）；到咽部時**頭前屈並吞嚥**；嗆咳、發紺就拔出
- 位置確認（課本）：**反抽胃液並測 pH**（最可靠）、打 10–20 mL 空氣聽診、管端放水中看有沒有連續氣泡；**現行指引以 X 光為準、床邊 pH ≤ 5.5、不建議打空氣聽診**
- 灌食：坐或半坐臥；配方 **37.8–40.5 ℃**；先灌約 20 mL 溫開水；空針高於胃 **30–45 cm**；每次 **250–350 mL、不超過 500 mL**、**至少 15–20 分鐘**；藥物與營養品**間隔 30 分鐘**
- **反抽**：每次灌食前做；殘餘量**超過上次灌食量一半或多於 100 mL** → 暫停 1–2 小時再評估；正常胃液**打回**；**咖啡色或紅色不打回**，記錄並報告
- 灌後再灌 **20–30 mL 溫開水**（清管、防發酵與阻塞）；**維持坐或半坐臥至少 30 分鐘**；翻身拍痰抽痰後休息 30 分鐘再灌
- 腹瀉最常見原因是**灌太快、濃度（滲透壓）太高** → **減速、稀釋、改連續灌食**；配方開封冷藏 **24 小時**內用完
- **TPN**：高張溶液走**中心靜脈**、外科無菌；開始 40–60 mL/h 慢慢加；監測血糖；**24 小時內輸完**、脂肪 12 小時內；**專用管路**不抽血給藥；**不可突然停**（低血糖），先接 10% 葡萄糖

### 國考常考點 {#exam-points}

- 鼻胃管置入：無法坐起者**微抬高床頭右側臥**(106-2_makeup_FA_046)；不必開暗燈；假牙要取下；左側臥、外科無菌、凡士林都是錯的(107-2_FA_048)
- 成人鼻胃管刻度 **70 cm** 表示位置錯誤（113-1_FA_027；一般 45–55 cm）
- 抽出液 **pH 6.5** 表示不在胃內，要調整深度(107-2_FA_048)
- 插管後**不可立即灌食**（休息 15–20 分鐘）；拔管時**深吸氣後閉氣**、平順快速拔出(109-2_FA_047)
- 灌食前反抽、**胃液再推回**(105-2_FA_047)；甘油潤滑、把殘餘抽掉丟棄都是錯的
- 每 2 小時灌食 250 mL，下一次反抽有 150 mL：**暫停並與醫師討論**(110-2_FA_050)；反抽 150 mL **咖啡色**的不可打回(112-1_FA_045)
- 嬰兒每餐 150 mL，反抽 50 mL：**打回再灌 100 mL**(106-1_OP_072)；早產兒口胃管反抽**大於灌食量一半**應暫停(112-2_OP_051)
- 灌食速度：**至少 15–20 分鐘**；每次至少 500 mL 是錯的(107-1_FA_049)；10 分鐘內完成、空針與胃等高都是錯的；**灌完再灌 20 mL 溫開水**(105-1_FA_047)
- 灌食後加溫開水的目的：**避免食物在管內發酵**(110-1_FA_047)；「刺激胃液分泌」是灌食**前**溫開水的作用(113-3_FA_029)；空針高度 30–45 cm、配方 42 ℃ 要先降溫
- 配方開封冷藏 24 小時內用完、每次 ≤ 500 mL、藥物與營養品間隔 30 分鐘；「**提高濃度以減少胃容量**」是錯的(111-2_FA_045)
- 腹瀉：**減慢灌食速度**(112-2_FA_045)、**稀釋配方再漸增**(109-1_FA_054)；灌太快會腹瀉(111-1_FA_045)
- 腦外傷術後一個月意識不清長期臥床：**鼻胃管灌食**(110-2_FA_008)
- 鼻胃管護理：**更換膠布時管子不轉動、固定在原處**、流感病人的棉枝丟**感染性垃圾**（115-2_FA_031 答 C）；課本技術寫每日旋轉 45 度
- 兒童：管灌出現**嘔吐、腹脹、呼吸暫停立即停止**(108-1_OP_078)；灌後**右側半坐臥、頭抬高 30 度**(113-2_OP_045)；早產兒口胃管灌食**速度要慢**(105-2_OP_071)
- TPN：輸注初期**先慢後快**（115-2_FA_030 說先快是錯的）；脂肪製劑滴完 8 小時後才驗三酸甘油酯；管路**不給藥不抽血**；TPN 管路要 **24 小時**更換（111-1_FA_044 說 72 小時是錯的）；配方來不及送到可用 **10% 葡萄糖**；空氣栓塞採**頭低左側臥**
- PPN 用等張製劑；TPN 監測血糖、可用頸靜脈；每袋**不超過 24 小時**（110-1_FA_050 說 48 小時是錯的）

## 途徑選擇 {#routes}

| 途徑 | 適合 |
|---|---|
| 由口進食 | 最自然、最安全，見 [[nutrition-assessment-diets#oral-feeding]] |
| **鼻胃管** | 吞嚥困難、意識不清但腸胃功能正常；可較長期 |
| 口胃管 | 短期；**鼻中膈彎曲、無硬腭**、新生兒與早產兒 |
| 食道造瘻 | 頭頸部手術 |
| **胃造瘻**（含 PEG, percutaneous endoscopic gastrostomy） | 食道阻塞、長期管灌（中風、頭頸癌）；減少鼻胃管的吸入、自拔，外觀較好 |
| 空腸造瘻、鼻腸管 | 幽門以上需長期治療（胃部手術、食道瘻管）、**吸入風險高** |
| **周邊靜脈營養(PPN)** | 預期靜脈營養 **< 10 天**；等張（葡萄糖 < 10%、胺基酸 < 3%）、滲透壓 < 600 mOsm/L；最長約 2 週（靜脈炎） |
| **中央靜脈營養(TPN)** | 腸道失去功能或預期禁食 **> 7–14 天**；高張，經 CVC(central venous catheter)、PICC(peripherally inserted central catheter)或人工血管 |

課本流程（引鄭金賓 2004）：腸道能用嗎？→ 能 → 吸收正常用一般配方、不正常用元素配方 → 預計 4–6 週以上用造瘻，否則鼻胃管 → 吸入風險高改十二指腸或空腸；腸道不能用 → 短期 PPN、長期 TPN

## 鼻胃管置入 {#ng-insertion}

| 步驟 | 做法 | 原理 |
|---|---|---|
| 1. 準備 | 核對醫囑、解釋、評估鼻孔與鼻部病史；**內科無菌**；光線充足 | 選對口徑與鼻孔 |
| 2. 姿勢 | **坐或半坐臥**（先搖床尾再搖床頭）；不能坐起者**床頭稍抬高、右側臥** | 減少吸入；右側臥依解剖較易進胃 |
| 3. 假牙 | **取下活動假牙** | 防吞入 |
| 4. 量長度 | 成人**鼻尖 → 耳垂 → 劍突**(NEX)約 **45–55 cm** 並做記號；到十二指腸或空腸再加 20–30 cm | 確定到胃的長度 |
| 5. 潤滑 | **水溶性潤滑劑**或 2% xylocaine jelly 潤滑前端 5–10 cm；**不用凡士林等油性**；要做胃液細胞學檢查改用生理食鹽水 | 油性誤入氣管會造成吸入性肺炎 |
| 6. 插入 | 管子沿鼻底輕推；到咽部時請病人**頭前屈並吞嚥**（可小口喝水），配合吞嚥推進到記號 | 頭前屈使會厭軟骨蓋住氣管，管子進食道 |
| 7. 異常 | **持續嗆咳、發紺、管子從口中出來 → 立即拔出**；作嘔時頭偏一側、休息再插；鼻出血先停止並壓迫止血 | 可能誤入氣管 |
| 8. 確認位置 | 見下節 | — |
| 9. 固定 | 塞住管口（不建議反折）；人字形或架橋式布膠固定在鼻樑，不緊貼鼻孔；多餘管子盤繞以別針固定在衣服 | 防滑脫與鼻翼壓傷 |
| 10. 休息 | **插管後休息 15–20 分鐘再灌食** | 讓噁心反射緩和 |
| 11. 記錄 | 時間、管子種類與尺寸、刻度、胃內容物、反應 | — |

### 位置確認 {#placement-verification}

| | 課本與國考 | 現行建議 |
|---|---|---|
| 反抽胃液 | **反抽看到胃內容物**並用酸鹼試紙測，**最精確**；**pH 6.5 表示不在胃內** | **床邊首選**：抽吸液 **pH ≤ 5.5** 才算在胃內；用制酸劑、剛灌牛奶會使 pH 偏高 |
| 打空氣聽診 | 打入約 10–20 mL 空氣，在胃部聽到咕嚕聲，再把空氣抽回 | **不建議**（whoosh test 不可靠） |
| 管端放水中 | 沒有連續氣泡表示不在氣管 | 不建議 |
| X 光 | 課本：臨床少用 | **黃金標準**；首次置入或 pH 判讀不確定時使用 |
| 其他 | 管端放耳邊不應聽到呼吸聲；每次灌食前檢查刻度 | 每次灌食與給藥前都要確認刻度與位置 |

:::warning[新舊說法]
國考答案仍接受打空氣聽診與水中氣泡法；英國 NHS(National Health Service)等國外指引已明確不建議，國內也有醫院改以 pH 為主、X 光為輔（整理見來源包 fundamentals-b.md）。作答依國考，臨床依院內規範
:::

## 灌食 {#tube-feeding}

### 灌食方法 {#feeding-methods}

| 方法 | 做法 | 量與時間 | 適合 |
|---|---|---|---|
| **批式**(bolus) | 灌食空針靠重力流入 | 一天分 3–6 次，每次約 **250–350 mL、≤ 500 mL**；**至少 15–20 分鐘** | 消化與胃排空良好者 |
| 間歇性 | 吊掛灌食袋或空針重力 | 一天分 4–6 次，每次 20–60 分鐘 | 不耐批式、鼻腸管或空腸造瘻、長期禁食後轉灌食 |
| **連續性** | 灌食袋或**灌食幫浦**定速 | 從 **20–50 mL/h** 開始，約每 4 小時加 25 mL/h；每天 8–24 小時；**全程床頭抬高** | 重症、不耐批式、空腸造瘻、長期禁食後開始 |
| 循環性 | 白天由口、晚上管灌補足 | — | 過渡期 |

### 批式灌食步驟 {#bolus-steps}

| 步驟 | 做法 | 原理 |
|---|---|---|
| 1. 核對 | 醫囑與飲食單、配方名稱濃度效期 | — |
| 2. 姿勢 | **坐或半坐臥**；不能坐則**右側臥**（床頭抬高） | 防吸入、利胃排空 |
| 3. 確認位置 | 檢查刻度與膠布；反折管子接空針 | 防空氣進入 |
| 4. **反抽** | 觀察殘餘量與性狀；**正常胃液打回** | 確認位置、評估消化；胃液含電解質 |
| 5. 判斷 | 殘餘量**超過上次灌食量一半或 > 100 mL** → **暫停 1–2 小時**再評估；< 50 mL 表示消化良好；**咖啡色或紅色不打回**、記錄並報告 | 胃排空延遲易嘔吐吸入；咖啡色可能是出血 |
| 6. 先灌溫開水 | 約 **20 mL** | 確認通暢、潤濕管壁、刺激胃液分泌 |
| 7. 灌食 | 配方 **37.8–40.5 ℃**；空針高於胃 **30–45 cm**、手指控制流速；開水快流完前反折再倒配方；**至少 15–20 分鐘** | 太高太快會嘔吐、腹痛、腹瀉；太冷會腹瀉 |
| 8. 藥物 | 磨粉加水溶解後分開灌；**藥物與營養品間隔 30 分鐘**、中西藥間隔 1 小時；**不把藥加進配方** | 交互作用、阻塞 |
| 9. 灌後溫開水 | **20–30 mL** | **清除管內食物、避免發酵**、防阻塞、避免高張性脫水 |
| 10. 收尾 | 塞管口、盤管；**維持坐或半坐臥至少 30 分鐘** | 防逆流吸入 |
| 11. 記錄 | 殘餘量、配方種類與量、時間、反應 | — |

1. 首次灌食 150–250 mL，每 8–12 小時增加 30–60 mL，到達需要量
2. 清潔身體或換尿布在**灌食前或灌食 1 小時後**；**翻身、拍背、抽痰後休息 30 分鐘**再灌；氣管內管或氣切者灌食前先抽痰並確認氣囊
3. 灌食中**持續咳嗽、嘔吐、發紺 → 立即停止**並通知醫師
4. 配方沖泡或開封後室溫不超過 1 小時；剩餘**加註時間冷藏、24 小時內用完**
5. 灌食後抬高床頭 30–60 分鐘，**2 小時內避免抽痰**（國考 112-1_FA_045 正確選項）

### 合併症 {#complications}

| 問題 | 常見原因 | 處理與預防 |
|---|---|---|
| **腹瀉** | **灌食太快、濃度或滲透壓太高**（主因）、配方太冷、乳糖不耐、汙染 | **減速、稀釋後漸增濃度、改連續灌食**；配方 37.8–40.5 ℃；無乳糖配方；衛生 |
| 腹脹、嘔吐 | 太快、灌入空氣、配方太冷、量太多 | 減速；反折管子防空氣；評估殘餘量 |
| **吸入**（最嚴重） | 頭未抬高、殘餘量多、昏迷無作嘔反射、管子移位 | 灌食時與灌後 30–60 分鐘**床頭 30–45 度**；連續灌食全程抬高；每次確認刻度；高風險改連續或腸道灌食 |
| 高張性脫水 | 高張或高蛋白配方、水分不足（昏迷、嬰兒不會喊渴） | 補水、記錄輸出入 |
| 阻塞 | 藥物或配方沉澱、沖洗不足 | 溶解藥物；灌後至少 30 mL 溫水沖管 |
| 便秘 | 水分或纖維不足 | 加水、含纖配方 |

## 鼻胃管護理與拔除 {#ng-care}

1. 護理（課本技術 12-3）：一手固定管子、一手撕舊膠布；**生理食鹽水棉棒**清潔鼻孔與管壁分泌物，必要時**丙酮**去除膠痕；濕紙巾擦鼻樑並看皮膚；**每日將管子旋轉 45 度**避免壓迫同一處鼻黏膜，確認刻度後換位置貼新膠布；休息 30 分鐘再灌食；做口腔護理
2. 國考 115-2_FA_031 的正確選項是「**換膠布時管子勿轉動、固定於原處**」與「棉枝丟感染性垃圾」（流感病人）；與課本「每日旋轉 45 度」不同，作答以題目為準
3. 不用酒精清潔鼻腔；流感急性期仍要做鼻胃管護理
4. 拔除：反折（夾住）管子；請病人**深吸氣後閉氣**，平順快速拔出；之後口腔與鼻腔清潔、觀察吞嚥（國考 114-2_FA_028 給 A、D 兩個答案）

::questions{ids="115-2_FA_031,114-2_FA_028"}

## 兒童與早產兒的管灌 {#pediatric}

1. 長度：兒童可用**雙眉間到劍突**、雙眉間到劍突與肚臍中點、或**鼻尖 → 耳垂 → 劍突與肚臍中點**（課本）；口胃管從嘴角量；「鼻尖到耳垂直線距離」不夠
2. 確認：不能只靠「沒有咳嗽、發紺」判斷沒進氣管；水中出現氣泡表示在氣管
3. 灌食：**速度要慢**（早產兒約 5 mL 每 5–10 分鐘）、重力流入；總量要**扣掉打回的殘餘量**（每餐 150 mL、反抽 50 mL 打回 → 再灌 100 mL）；殘餘量**大於灌食量一半**暫停
4. 灌食中出現**嘔吐、腹脹、呼吸暫停、發紺**立即停止
5. 灌後**右側臥或右側半坐臥、頭抬高約 30 度**（利胃排空、防吸入）；可給**安撫奶嘴**滿足吸吮並促進消化
6. 早產兒配方奶熱量高於母乳**不是**優先以配方奶的理由(112-2_OP_051)；高危險新生兒的營養留產兒輪

## 靜脈營養 {#parenteral-nutrition}

| 項目 | 重點 | 原理 |
|---|---|---|
| 組成 | 胺基酸、葡萄糖、脂肪乳劑、電解質、維生素、微量元素；TPN 約 20–25% 葡萄糖、3.5–5% 胺基酸 | 高張需走大血管 |
| 途徑 | **中央靜脈**（內頸、外頸、鎖骨下、股靜脈）、PICC、人工血管；**放置後照胸部 X 光**確認位置再輸注 | 防誤入與氣胸 |
| 無菌 | **外科無菌**；瓶口雙重消毒（碘酊＋酒精）；過濾器；溶液冷藏、用前 2 小時回溫並檢查混濁裂縫 | 高糖溶液易滋菌 → 敗血症 |
| 速度 | 用**輸液幫浦**連續 24 小時；**初期 40–60 mL/h**，慢慢增加 | 防高血糖、肺水腫、體液過量 |
| 時限 | 每袋 **24 小時內**輸完；**脂肪製劑 12 小時內**；脂肪滴完 **8 小時後**才抽三酸甘油酯 | 防汙染；脂血干擾檢驗 |
| 管路 | **專用單一管路**：不抽血、不輸血、不給藥、不量中心靜脈壓；含脂肪的輸液管**每 24 小時更換** | 減少感染與交互作用 |
| 監測 | **血糖約每 4 小時**、每日體重、輸出入、電解質 | 高血糖或低血糖 |
| 敷料 | 紗布至少每 2 天、透明敷料每 7 天換，髒濕鬆脫立即換（課本引衛福部） | 防導管感染 |
| 中斷 | 配方來不及送到 → **10% 葡萄糖**接續 | 防反彈性低血糖 |
| 停止 | **逐漸減量**，腸道由清流質開始進展 | 胰島素分泌需要時間調整 |

1. 合併症：**空氣栓塞**（立即夾管、**頭低左側臥**）、導管感染與菌血症、**高血糖**、停太快的低血糖
2. 不明原因發燒或注射部位紅腫：可能要拔導管並做尖端與血液培養，見 [[sepsis]]
3. 中心靜脈導管的照護與輸液併發症見 [[iv-therapy]]；短腸症候群病人常需長期 TPN

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 用凡士林潤滑鼻胃管 | 水溶性潤滑劑 | 油性誤入氣管會吸入性肺炎 |
| 不能坐起者左側臥插管 | 右側臥 | 依解剖較易入胃 |
| 插好立刻灌食 | 休息 15–20 分鐘 | 噁心反射 |
| 把反抽的胃液丟掉 | 正常胃液打回 | 保留電解質 |
| 咖啡色反抽物打回 | 不打回、報告 | 可能出血 |
| 每次至少 500 mL、10 分鐘灌完 | ≤ 500 mL、至少 15–20 分鐘 | 腹脹、腹瀉、嘔吐 |
| 提高配方濃度減少容量 | 濃度過高會腹瀉、脫水 | 滲透壓 |
| 灌後溫開水是刺激胃液分泌 | 是清管、防發酵 | 灌前的水才有刺激作用 |
| TPN 先快後慢 | 先慢後快 | 防高血糖 |
| TPN 管路可順便抽血給藥 | 專用 | 感染與交互作用 |
| TPN 每袋可掛 48 小時 | 24 小時內 | 汙染風險 |
