**入院**與**出院**是病人住院經驗的頭尾，國考考的多是**護理人員該做與不該做的事**：入院先觀察、怎麼辨識病人、誰開飲食、貴重物品怎麼處理；出院計畫**何時開始、誰擬訂**；出院方式的名稱；出院後的**終期消毒**。後半是**靜脈採血**的步驟與**溶血**原因，以及全血球計數的正常值。尿液、糞便、痰液、血液培養與動脈血的採檢細節分別見 [[urinalysis#nursing]]、[[culture-and-sensitivity]]、[[airway-clearance]]、[[abg#nursing]]；居家照護與出院準備服務見 [[home-care-discharge-planning#discharge-planning]]

## 重點摘要 {#summary}

- 入院：**自我介紹、觀察病人**是第一個動作；建立**身高、體重、生命徵象**；護理評估與病史在**入院 24 小時內**完成，不必在當班全部做完
- 辨識病人：**手圈＋姓名**，**不可以床號稱呼或辨識**
- **治療飲食由醫師開立**，護理人員不能開；檢體也是依醫囑收集，不是自己主動決定
- 貴重物品：請**家屬帶回**；必須代管時列清單、病人簽名；不是護理人員主動保管
- 入院焦慮：同理不斷發問是對未知的恐懼；**檢查治療前詳細解說**、**徵求病人意見增加控制感**；**不必減少家屬探視**
- 出院計畫：**入院就開始**；**以病人為中心**，**病人、照護者、醫師、護理師與團隊共同擬訂**；教病人與家屬自己做照護（含傷口照護）
- 出院方式：**同意出院 MBD**、**自動出院 AAD**（違反醫囑，要簽自動出院書）、轉院、死亡
- 出院後病人單位：**終期消毒**，不是無菌消毒
- 靜脈採血：**不從輸液或輸血的肢體抽**；止血帶在抽血處**上方 5–10 cm**；針頭**斜面向上**、**15–30 度**；**頭靜脈、肘正中靜脈、貴要靜脈**常用；抽完**按壓不按揉**；有抗凝劑的試管**輕輕倒轉混勻**，不用力搖
- 禁食：**血糖、血脂（膽固醇、三酸甘油酯、低密度脂蛋白 LDL，low-density lipoprotein）** 等生化檢查要禁食 6–8 小時；**全血球計數 CBC(complete blood count)不用禁食**

### 國考常考點 {#exam-points}

- 入院最適當：**身體評估與詢問病史**(115-2_FA_033)；「開立治療飲食」不屬於護理範圍（106-1_FA_051、115-2_FA_033）；「主動收集檢體送檢」「介紹相同疾病病友」都不適當
- **自我介紹與觀察是最先的護理活動**＋**建立身高體重生命徵象**(110-2_FA_051)；「當班內完成全部評估」「主動保管貴重物品」錯
- 「提醒病人住院不習慣可轉院」最不適宜(112-1_FA_053)
- 「立即戴手圈並**以床號辨識**」錯(105-1_FA_055)
- 入院焦慮：「**減少家屬探視**」不適當(106-1_FA_050)
- 出院計畫：**以病人為中心＋病人、照護者與團隊共同擬訂**(114-2_FA_032)；「醫師開出院醫囑當天才開始」「避免病人家屬自己做傷口照護」錯；「恢復期才開始」「只有生理技能」「只由專業團隊自擬」錯，正確是**以病人為中心，提供居家及轉介照護機構的需求**(106-2_makeup_FA_056)
- 出院後病人單位做「**無菌消毒**」錯(106-1_FA_052)
- 醫師同意出院 → **MBD**，病人自己另去他院不改變原醫院的出院方式(112-2_FA_052)
- 靜脈採血：「從輸液管路抽」錯（115-2_FA_034、114-1_FA_015、110-2_FA_053）；**頭靜脈與貴要靜脈最常抽**(115-2_FA_034)；「斜面向下 45 度」錯；「邊按揉邊加壓」錯；「止血帶綁上方 2–3 cm」錯；**有抗凝劑試管要輕搖**(110-2_FA_053)；「成人用 27 號針」「以手搧風加速酒精揮發」「快速注入並充分搖晃」錯(114-1_FA_015)
- 不需禁食：**CBC**(108-1_FA_053)；血糖、膽固醇要禁食(114-1_FA_035)
- 溶血原因：**試管有水、針頭太細、劇烈搖晃**（112-2_FA_051、105-2_FA_023）；**沿管壁緩緩注入**與**較粗的針頭**不會溶血
- CBC 異常：**血小板 80×10⁴/mm³**（115-1_FA_035，正常 15–40×10⁴）；**白血球 125,000/mm³**（105-1_FA_051，正常 5,000–10,000）
- 精液：**取精後室溫、1–2 小時內送檢**（108-2_OP_039，依國考；課本本章未寫）

## 入院 {#admission}

### 入院時的心理反應 {#admission-psychology}

- 常見：焦慮、寂寞、害怕（對未知、對檢查治療）、失去隱私、身體心像改變、失去控制感、罪惡感
- 護理
  1. 同理病人一直發問是對未知的恐懼，耐心回答
  2. 每項檢查與治療**事先說明**
  3. 讓病人參與決定、**徵求病人意見**，增加控制感（例如讓絕對臥床的孕婦自己用電動床、適度布置環境）
  4. 家屬是支持來源，**不用刻意減少探視**
- 來源：實用基本護理學下冊 p.520–523

::questions{ids="106-1_FA_050"}

### 病房護理人員的職責 {#admission-duties}

| 時機 | 要做的事 |
|---|---|
| 入院前 | 準備病人單位與需要的設備 |
| 迎接 | **自我介紹**、**觀察病人**（外觀、意識、呼吸）；核對**手圈**與姓名，**不用床號**稱呼 |
| 基本資料 | 量**身高、體重、生命徵象**；入院時間在體溫單上記錄（做法見 [[documentation-orders#tpr-sheet]]） |
| 評估 | 身體評估、詢問病史；護理評估在**入院 24 小時內**完成，隱私問題可等建立信任後再問 |
| 醫囑 | 依醫囑執行飲食、檢查與檢體收集；**飲食由醫師開立** |
| 環境介紹 | 病室設施、叫人鈴、作息、探病規定 |
| 財物 | 貴重物品請**家屬帶回**；代管時列清單、病人簽名；**昏迷**病人的財物由護理長或值班護理人員清點暫管，並由**護理人員以外的兩位證人**簽名 |

- 不適宜的做法：提醒病人「住不習慣可以轉院」、介紹「可能得相同病」的病友、主動收集沒有醫囑的檢體
- 入院同意書等文件見 [[medical-records-consent]]
- 來源：同書 p.524–526

## 轉出與出院 {#discharge}

### 出院方式 {#discharge-types}

| 方式 | 說明 |
|---|---|
| **同意出院 MBD**(may be discharged) | 醫師評估可以出院並開醫囑 |
| **自動出院 AAD**(against advice discharge) | 病人或家屬違反醫師建議要求出院，要**簽自動出院書** |
| 轉院(referral) | 轉到其他醫院或照護機構繼續治療 |
| 死亡 | 臨終與死後護理見 [[end-of-life-care]] |

- 醫師已同意出院，病人自己再去他院要求住院 → 對原醫院仍是 **MBD**
- 轉出（轉床、轉科）：通知接收單位、整理病歷與藥物、護送並交班
- 來源：同書 p.527–529

::questions{ids="112-2_FA_052"}

### 出院計畫 {#discharge-planning}

1. 時機：**病人入院時就開始**，不是醫師開出院醫囑當天，也不是等到恢復期
2. 原則：**以病人為中心**、確保**持續性照護**；由**病人、照護者、醫師、護理師與其他團隊**共同擬訂
3. 內容：生理照護技能之外，也包括居家環境、**社區資源**與**轉介照護機構**；教病人與家屬**自己做**傷口照護等技術
4. 出院衛教可用 **METHOD** 記
   1. M(medication)：按時服藥、注意副作用
   2. E(environment)：居家環境安排
   3. T(treatment)：返家後要繼續的治療與照護技術
   4. H(health teaching)：衛教，含危險徵象
   5. O(outpatient referral)：回診與轉介
   6. D(diet)：飲食
- 長照與出院準備服務的制度面見 [[home-care-discharge-planning#discharge-planning]]
- 來源：同書 p.530

::questions{ids="114-2_FA_032,106-2_makeup_FA_056,106-1_FA_052"}

### 出院後病人單位的處理 {#terminal-disinfection}

- 做**終期消毒**(terminal disinfection)，清潔消毒床單位與用物，**不是無菌消毒**
- 一般病室：清潔人員以消毒液（如 1–5% lysol 或 500 ppm 漂白水）擦拭病床、桌椅、牆壁與地板，**吹晾 30 分鐘**
- 傳染病病室：清理前先以**紫外線照射 30 分鐘**，處理者採隔離技術，擦拭後**吹晾 12–24 小時**再鋪床；隔離原則見 [[infection-control]]
- 傳染病病室的布單與病人衣物放入**紅色**或標示「傳染性」的汙物袋送洗；毛毯、床褥、枕頭以紫外線照射 30 分鐘或日曬 6–8 小時（不是黑色塑膠袋隔絕空氣 48 小時）
- 來源：同書 p.531–532

::questions{ids="113-3_FA_032"}

## 檢體收集 {#specimens}

### 原則與常見檢體 {#specimen-principles}

1. 依醫囑收集；核對病人、檢驗單與容器標籤
2. 採檢前向病人說明目的與方法，需要禁食的事先告知
3. 尿液（常規、培養、24 小時尿）的收集見 [[urinalysis#nursing]]
4. 痰液：清晨起床漱口後深咳；細節見 [[airway-clearance]]
5. 糞便潛血（化學法）：檢查前 3 天不吃大量魚、肉、內臟、含鐵食物與鐵劑，以免偽陽性；也避免大量維生素 C，以免偽陰性；女性先確認是否在經期（來源：同書 p.536）
6. 血液培養：**使用抗生素前**採檢，見 [[culture-and-sensitivity]]
7. 動脈血液氣體分析：先做 Allen 試驗、檢體放冰水立即送，見 [[abg#nursing]]
8. 精液：取精後**室溫保存、1–2 小時內送檢**，不冰、不加溫；不可用一般保險套收集（依國考 108-2_OP_039，課本本章未寫）

::questions{ids="108-2_OP_039"}

### 全血球計數正常值 {#cbc-values}

| 項目 | 正常範圍（課本） |
|---|---|
| 紅血球 | 男 4.5–6.0×10⁶/mm³；女 4.0–5.0×10⁶/mm³ |
| 白血球 | 5,000–10,000/mm³ |
| 血小板 | 15–40×10⁴/mm³ |
| 血紅素 | 男 14–17 g/dL；女 12–16 g/dL |

- 各醫院參考值略有不同；臨床意義見 [[complete-blood-count#reference-range]]
- 來源：同書 p.538

## 靜脈採血 {#venipuncture}

### 步驟 {#venipuncture-steps}

1. 準備
   1. 生化檢查（血糖、膽固醇、三酸甘油酯、LDL）**禁食 6–8 小時**；**CBC 不用禁食**
   2. 用物列 **22G** 針頭（來源：同書技術 18-6 p.556）；太細的針易溶血
2. 選血管
   1. 常用**頭靜脈、肘正中靜脈、貴要靜脈**
   2. **不可從正在輸液或輸血的肢體或管路抽**（會稀釋檢體、結果不準）
3. 穿刺
   1. 止血帶綁在抽血處**上方 5–10 cm**
   2. 消毒後**待酒精自然乾**，不搧風、不吹（酒精未乾會溶血）
   3. 針頭**斜面向上**，與皮膚呈 **15–30 度**進針
4. 抽完
   1. 先鬆止血帶再拔針
   2. 以乾棉球**按壓 2–5 分鐘**，**不要按揉**（會造成血腫）
   3. 普通針筒：**沿試管壁緩緩注入**（國考 114-1_FA_035「沿管壁 45 度注入」為正確）；真空試管靠負壓自己吸，不用加壓
   4. 有抗凝劑的試管**輕輕倒轉混勻**，不可用力搖
5. 真空採血管有建議的採血順序（血液培養瓶先，含抗凝劑的管子依類別排在後），依醫院規定
- 來源：同書技術 18-6 p.556–561

::questions{ids="115-2_FA_034,114-1_FA_015,114-1_FA_035,110-2_FA_053,108-1_FA_053"}

### 溶血的原因 {#hemolysis}

| 會溶血 | 不會溶血 |
|---|---|
| 試管內有**水分** | 沿試管壁**緩緩注入** |
| 針頭**太細**、抽太用力 | 用較粗的針頭 |
| **劇烈搖晃**檢體 | 輕輕倒轉混勻 |
| 血液注入**太快、太用力**、沒沿管壁 | |
| **止血帶綁太久** | |
| 消毒的**酒精未乾**就穿刺 | |

- 來源：同書 p.561

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 |

| 護理人員主動保管貴重物品 | 請家屬帶回 |
| 入院當班完成所有評估 | 入院 24 小時內 |
| 減少家屬探視讓病人休息 | 家屬是支持來源 |
