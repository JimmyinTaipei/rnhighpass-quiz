排尿要靠**膀胱逼尿肌收縮、尿道內外括約肌放鬆**，任何一環出問題就會尿不出來（尿瀦留）或忍不住（尿失禁）。本頁整理**排尿反射**、**排尿異常的名詞**、**尿瀦留與誘尿**、**尿失禁的護理**、**預防泌尿道感染**、**膀胱訓練**與**導尿、膀胱灌洗、膀胱滴藥**的技術。泌尿道構造見 [[kidney-urinary-physiology]]，尿液檢查見 [[urinalysis]]、檢體留取見 [[urinalysis#nursing]]，尿失禁六型、藥物與手術見 [[urologic-disorders#incontinence]]，導尿管相關泌尿道感染見 [[urinary-tract-infection#cauti]]

## 重點摘要 {#summary}

- 排尿反射：膀胱約 **250–300 mL**（幼兒 50–100 mL）產生尿意 → 薦髓 **S2–S4** → 逼尿肌收縮、**尿道內括約肌**（不隨意）放鬆；**尿道外括約肌**（骨骼肌）受意志控制
- 名詞：多尿 > 2,500 mL／天；**少尿 < 400–500 mL／天**；**閉尿（無尿）24 小時 < 100 mL**；夜尿每晚起來 ≥ 2 次
- 正常**餘尿 < 50 mL**；**產後 4 小時、術後 6–8 小時**內要能自解
- 尿瀦留：恥骨上可摸到膀胱、**叩診濁音**；產後膀胱脹會把**子宮推高偏右**
- 誘尿：**聽流水聲**、**手握冰塊**、膀胱上熱敷（**要醫囑**）、**溫水坐浴**、**溫水沖會陰**、**順時鐘**輕揉膀胱、女性坐姿男性站姿
- 尿失禁：**壓力性**（咳嗽、大笑、打噴嚏漏 < 50 mL → **凱格爾運動**）；**急迫性**（突然強烈尿意 → **膀胱訓練**、晚上少喝、避免咖啡茶酒）；失能相關（來不及到廁所 → 定時如廁）
- 導尿管：成人**男 16–18 Fr、女 14–16 Fr、兒童 8–10 Fr**，以能引流的**最小號**為原則；泌尿道手術或出血要灌洗才用 **≥ 18 Fr、三路**
- 插入深度男 **20 cm**、女 **5 cm**；水球打 **5–10 mL 無菌蒸餾水**；單次導尿一次 **≤ 500 mL**
- 存留導尿管女性固定**大腿內側**、男性**下腹部或大腿前側**；集尿袋**低於膀胱**；尿袋沒尿先**檢查管路通暢**

### 國考常考點 {#exam-points}

- 正常成人**餘尿 < 50 mL**(110-1_FA_037)
- 尿瀦留原因：**膀胱出口阻塞、支配膀胱的神經損傷**(109-1_FA_013)；產後尿瀦留：**子宮底偏右**；叩診恥骨上是濁音不是鼓音(110-1_OP_025)
- 誘尿：足部熱敷**不適當**(114-3_FA_021)；**冷水沖會陰**錯，要溫水(108-1_FA_031)；聽流水聲、會陰沖洗、溫水坐浴可以，**逆時鐘**揉膀胱錯(106-1_FA_030)；雙手骨折術後未解尿，獨立性護理功能是**按摩恥骨上方**（導尿與熱敷要醫囑、手握冰塊做不到）(108-2_FA_040)
- 尿液有**膽紅素** → **阻塞性黃疸**（112-2_FA_030、106-1_FA_031）
- 壓力性尿失禁：大笑咳嗽漏尿（110-1_FA_034、108-1_FA_032）；**增加茶或可可**不適當(114-3_FA_020)；「中年婦女正常不要在意」不適當(109-1_FA_034)；增加括約肌張力的是**凱格爾運動**(107-2_FA_035)
- 凱格爾運動是**增加**骨盆底肌張力，「降低膀胱肌肉張力」錯(114-2_OP_014)；孕婦頻尿漏尿「白天減少喝水」不適當(112-3_OP_003)
- 間歇導尿用於留無菌尿、測餘尿、術後尿瀦留；**不用於尿失禁**(114-2_FA_021)
- 導尿管大小：泌尿道手術膀胱灌洗用 **≥ 18 Fr**（115-1_FA_022、113-1_FA_021）；兒童 **8–10 Fr**；「成人一般用 20 Fr」錯(110-2_FA_004)；「選能引流的**最大號**」錯，要最小號(106-2_makeup_FA_040)
- 材質：放置一週以上用**矽膠**(106-2_makeup_FA_039)；「塑膠導尿管可放 1 個月」錯(113-1_FA_021)
- 三路導尿管三腔：**固定（水球）、引流尿液、灌注溶液**，沒有排氣腔(112-1_FA_029)
- 水球：一般 **5–10 mL**、用**無菌蒸餾水**(108-2_FA_004)；打水時痛要先**抽出液體**再把管子推進約 2 cm
- 女性存留導尿：先鋪洞巾再消毒、潤滑 5–7 cm、打 5–10 mL 蒸餾水；**固定在下腹部是錯的**，女性固定**大腿內側**（114-2_FA_011、109-2_FA_038）
- 女性消毒順序：**遠側小陰唇 → 近側小陰唇 → 中間尿道口**，由上往下(109-2_FA_038)
- 單次導尿一次不超過 **500 mL**（課本）；16 小時未解尿導尿時「一次導出所有尿液」不適當(106-2_FA_036)
- 尿袋 3 小時沒尿：先**檢查導尿系統通暢**(113-2_FA_022)
- 小量膀胱灌洗每次 **30 mL** 來回灌洗(108-2_FA_005)；連續灌洗要**三路**導尿管

## 排尿的生理 {#physiology}

1. 腎臟每天製造約 **1,200–1,500 mL** 尿液；輸尿管靠蠕動把尿送到膀胱
2. 膀胱
   1. 位於恥骨聯合後方；肌肉層是平滑肌，叫**逼尿肌**
   2. 成人一般存 300–500 mL，最多可撐到 1,000–2,000 mL
   3. 約 **250 mL** 有輕度尿意；約 300 mL 引發排尿反射
3. 尿道
   1. **內括約肌**：在尿道內口，真正控制膀胱出口，**不隨意**
   2. **外括約肌**：骨骼肌，**可隨意**關閉
   3. 女性尿道長約 **3.8–5 cm**，男性約 **16–20 cm**；女性尿道短 → 較易泌尿道感染
4. 排尿反射：膀胱壓力上升 → **S2–S4** 排尿中樞 → 傳到大腦；可以排時，逼尿肌節律收縮、內外括約肌放鬆；不宜排時外括約肌收縮忍住
5. 嬰兒排尿是反射，約 **3 歲**後才能自我控制
- 來源：實用基本護理學下冊 p.366–368、376

## 評估 {#assessment}

### 排尿異常的名詞 {#voiding-problems}

| 名詞 | 定義 | 常見原因 |
|---|---|---|
| 多尿 | 每天 **> 2,500 mL** | 喝多、咖啡酒精；糖尿病、腎小管再吸收差、利尿劑、ADH（antidiuretic hormone，抗利尿激素）不足 |
| **少尿** | 每天 **< 400–500 mL** | 喝少、出汗多；脫水、腎功能差、泌尿道阻塞 |
| **閉尿**（無尿） | 腎臟不製造尿液，**24 小時 < 100 mL** | 休克、燒傷、嚴重心衰竭、腎盂結石、藥物中毒 |
| 頻尿 | 排尿次數多 | 神經障礙、膀胱刺激、懷孕子宮壓迫 |
| 排尿困難 | 排尿困難或疼痛、燒灼感 | 阻塞、膀胱或尿道感染 |
| 遺尿 | 夜間尿失禁，兒童最常見 | 多為發展、心理、睡眠因素，只有約一成是神經或泌尿疾病 |
| 夜尿 | 每晚起床解尿 **≥ 2 次** | 腎濃縮能力下降、膀胱炎、前列腺肥大 |
| **尿瀦留** | 腎功能正常，但尿留在膀胱排不出 | 見下節 |

- 來源：同書 p.369–371

### 身體檢查與尿液 {#exam-urine}

1. 皮膚：水腫、**尿霜**（慢性腎衰竭的白色粉狀結晶，會癢有味，要常洗澡）
2. 膀胱：正常在恥骨聯合上**摸不到**；摸得到表示可能尿瀦留，再用**叩診**評估脹的程度（脹滿處是**濁音**）
3. 尿液常規：正常 24 小時 1,200–1,500 mL、淡黃清澈、pH 4.5–8.0、比重 1.010–1.030；**尿中出現膽紅素 → 阻塞性黃疸或肝炎**
4. 尿液顏色見 [[urinalysis#color]]；尿液、尿培養與 24 小時尿液檢體留取見 [[urinalysis#nursing]]
- 來源：同書 p.372–374

### 影響排尿的因素 {#factors}

| 因素 | 影響 |
|---|---|
| 年齡 | 老人膀胱張力差易頻尿；男性老人前列腺肥大易尿瀦留；懷孕影響排尿型態 |
| 液體與飲食 | 喝得多尿多；**咖啡、茶、酒精**利尿 |
| 心理與環境 | 沒有隱私、害羞 → 尿瀦留；焦慮 → 頻尿 |
| 藥物 | 利尿劑增加尿量；**膽鹼性藥物**刺激逼尿肌收縮；止痛與鎮靜劑抑制反射 → 尿瀦留；atropine 等抗膽鹼藥 → 尿瀦留 |
| 手術與麻醉 | 麻醉與止痛劑抑制感覺與運動反射；傷口水腫與疼痛 → **術後尿瀦留** |
| 神經與活動 | 脊髓損傷、中風；被約束或行動不便來不及如廁 → 失禁或瀦留 |

- 來源：同書 p.376–377

## 尿瀦留與誘尿 {#retention}

### 原因與分類 {#retention-causes}

1. 分類：暫時性（導尿可解除）、完全性（完全解不出）、**溢出性**（只能解 25–50 mL，解完膀胱還是脹）
2. 原因
   1. **神經性**：膀胱神經末梢受損、**脊髓損傷**、膀胱撐太久失去張力、尿道痙攣
   2. **膀胱出口阻塞**：前列腺肥大、結石
   3. 液體攝取太少，逼尿肌適應慢慢增加的尿量
   4. 心理：沒有隱私、怕痛、害羞
   5. 麻醉、會陰手術與水腫、藥物(atropine)
3. 「腎臟濃縮能力降低」「膀胱過度刺激」不是尿瀦留的原因（前者會多尿，後者會頻尿）
- 來源：同書 p.371

::questions{ids="109-1_FA_013,110-1_FA_037"}

### 產後尿瀦留的判斷 {#postpartum-retention}

- 產後膀胱脹滿會把子宮推高並**偏向右側**，影響子宮收縮；首要措施是**協助如廁解尿**
- 叩診恥骨聯合上方脹滿處是**濁音**，聽診下腹部不會有囉音
- 產後 4 小時內要自解；產後膀胱評估與產褥期照護留產科輪
- 來源：同書 p.379（產後 4 小時）；國考 110-1_OP_025

::questions{ids="110-1_OP_025"}

### 誘尿方法 {#stimulate-voiding}

| 方法 | 原理與要點 |
|---|---|
| **聽流水聲** | 類似排尿聲，反射到大腦 |
| **手握冰塊** | 末梢神經敏感，冷刺激反射到大腦皮質（不是足部熱敷） |
| 膀胱部位熱敷 | 熱水袋或濕熱敷，**需要醫囑** |
| **溫水坐浴** | 放鬆尿道括約肌 |
| **會陰沖洗** | 用**溫水**，不用冷水 |
| 局部按摩 | **順時鐘**輕揉膀胱；或雙手沿輸尿管向內向下呈 V 字按摩恥骨上方、壓膀胱；身體前傾增加腹壓 |
| 改變姿勢 | 女性坐姿、男性站姿 |
| 其他 | 提供隱私、溫暖便盆、放鬆情緒；無禁忌時至少喝 1,500 mL |

- 誘尿無效 → **依醫囑導尿**；也可依醫囑用膽鹼性藥物（bethanechol、neostigmine）刺激膀胱收縮，見 [[cholinergic-drugs]]
- 護理師可**獨立執行**的是不需醫囑的方法（聽水聲、按摩恥骨上方、溫水沖會陰、坐浴等）；導尿與局部熱敷要醫囑
- 來源：同書 p.379–381

## 尿失禁 {#incontinence}

| 類型 | 發生了什麼 | 護理重點 |
|---|---|---|
| **壓力性** | **骨盆底肌肉無力**，彎腰、提重物、快走、**咳嗽、大笑、打噴嚏**時腹壓上升，漏出 **< 50 mL**；約占尿失禁一半 | 避免增加腹壓的動作、**減重**；**凱格爾運動**每天 3 次、持續約 6 個月；起床與有尿意立刻解，鬧鐘提醒從每 2 小時開始；護墊尿布 |
| **急迫性** | 突然強烈尿意，來不及就漏 | **膀胱訓練**；床邊便盆椅、照明、呼叫鈴、好穿脫的衣服；白天分次喝，**晚上 7 點後限水**；**避免咖啡、茶、酒**；途中想尿時停下深呼吸 |
| 失能相關 | 泌尿系統正常，但來不及到廁所 | 依生活型態**定時如廁**、排在尿急之前；成功時鼓勵 |

- 所有類型都要做**皮膚護理**、保持乾燥，並照顧心理：**不能說「中年婦女正常，不要在意」**，要評估停經、肥胖、多產等危險因子並教導
- 急迫性、滿溢性、反射性等完整分類與藥物、手術見 [[urologic-disorders#incontinence]]
- 來源：同書 p.372、381–382

::questions{ids="110-1_FA_034,108-1_FA_032,114-3_FA_020,109-1_FA_034"}

### 凱格爾運動 {#kegel}

1. 重複**收縮再放鬆**會陰與骨盆底肌肉，**增強**骨盆底肌與尿道括約肌張力
2. 用在**壓力性尿失禁**；產後可從第一天開始，坐、站、躺都能做
3. 是增加肌肉張力，不是降低膀胱肌肉張力
4. 次數與每次收縮秒數見 [[urologic-disorders#incontinence-treatment]]
5. 孕婦頻尿漏尿：凱格爾運動、保持會陰乾燥、托腹帶減腹壓、不憋尿；**不要白天減少喝水**
- 來源：同書 p.381；產科部分依國考 114-2_OP_014、112-3_OP_003

## 預防泌尿道感染 {#uti-prevention}

1. 每天約 **2,000–3,000 mL** 液體，稀釋尿液、自然沖洗尿道
2. 白天至少每 **2 小時**解一次、夜間 1–2 次；**性行為前後解尿**
3. 酸化尿液：小紅莓汁、維生素 C；柑橘類果汁會使尿液偏鹼（現行證據見 [[urinary-tract-infection#urine-acidification]]）
4. 穿**棉質**、不要太緊的內褲
5. 女性便後與尿後**由前往後**擦
6. 以**淋浴**代替盆浴
7. 有症狀立刻就醫
- 來源：同書 p.382–383

## 膀胱訓練 {#bladder-training}

- 目的：恢復隨意控制排尿、**增加膀胱容量**、把排尿間隔拉長到約 **3–4 小時**
- 適用：頻尿、**急迫性尿失禁**、膀胱過動、脊髓損傷的排尿障礙

1. **按時如廁**：起床立刻解；白天與傍晚每 **30 分鐘到 2 小時**提醒一次，逐漸拉長；睡前解一次
2. **液體**：每天至少 **1,500–2,500 mL**（每小時約 100–150 mL），集中在**早上 7 點到晚上 7 點**，晚飯後少喝
3. 教誘尿：手掌交疊壓恥骨上方、憋氣、向前彎腰增加腹壓
4. **夾管訓練**（準備拔尿管）：拔管前 **24 小時**開始夾住尿管，每 **2–3 小時**打開 5 分鐘（喝得多就縮短到 1–2 小時）；**晚上打開**不影響睡眠；**用利尿劑者不夾管**（防膀胱過脹）
5. 有耐心、給予心理支持
- 來源：同書 p.383；拔管後 6–8 小時內要自解（技術 15-5 p.420）

## 導尿 {#catheterization}

### 單次與存留導尿的用途 {#catheter-indications}

| 方法 | 用途 |
|---|---|
| **單次導尿**（間歇導尿）：單路導尿管，導完就拔 | 減輕膀胱脹痛（尿瀦留）；取**無菌尿液**培養或月經期取乾淨尿液；**測餘尿**（解完立刻導）；膀胱滴藥或灌洗前排空 |
| **存留導尿**（留置導尿）：二路或三路 | 無法自解；膀胱、肛門、會陰術後避免傷口感染；**保護失禁病人皮膚**、預防壓力性損傷；膀胱減壓；**監測尿量** |

- 尿失禁一般**不用間歇導尿**解決(114-2_FA_021)
- 來源：同書 p.384

::questions{ids="114-2_FA_021"}

### 導尿管的選擇 {#catheter-selection}

| 項目 | 選擇 |
|---|---|
| 種類 | **單路**：只導尿；**二路**：導尿＋水球固定；**三路**：導尿＋水球＋**灌洗或給藥**（沒有排氣腔） |
| 大小 | 號碼越大管徑越大（Fr 是 French 單位，1 Fr＝1/3 mm）；成人**男 16–18 Fr、女 14–16 Fr**，**兒童 8–10 Fr**；以能維持引流的**最小號**為原則；只有**泌尿道手術、出血需要引流或灌洗**才用 **≥ 18 Fr** |
| 材質 | **乳膠**：便宜、易過敏、會變硬，約 1–2 週換；**矽膠**：軟、不易結垢、細菌不易附著，適合**長期**，約 1 個月換 |

- 國考對成人一般大小的寫法不一：106-2 補考以「成人 12–16 Fr」為正確敘述、110-2 以「成人一般用 20 Fr」為錯；課本是男 16–18、女 14–16 Fr，作答時 20 Fr 以上一定是錯的
- 塑膠導尿管不能放 1 個月
- 來源：同書 p.384–385、表 15-3

### 導尿的數字 {#catheter-numbers}

| 項目 | 男性 | 女性 |
|---|---|---|
| 潤滑長度 | 17.5–20 cm | **5–7 cm** |
| 插入深度 | **約 20 cm** | **約 5 cm** |
| 姿勢 | 平躺 | 屈膝仰臥（必要時側臥） |
| 存留導尿管固定 | **下腹部**或大腿前側 | **大腿內側** |

- 水球：用 10 mL 空針抽**無菌蒸餾水**，打 **5–10 mL**；需要壓迫止血（如前列腺術後）才打 20–30 mL
- 單次導尿一次**不超過 500 mL**，避免膀胱快速減壓引起休克或血管破裂
- 用**水溶性**潤滑劑，不用凡士林；消毒不用含碘酒的溶液
- 來源：同書 p.384–386、表 15-4 p.391、技術 15-4、15-5

### 女性導尿步驟 {#female-steps}

| 步驟 | 要點 |
|---|---|
| 核對、解釋、會陰沖洗 | 減少尿道口周圍細菌 |
| 屈膝仰臥，拆開導尿包鋪在兩腿之間 | 紙包巾拉到臀下，手不越過無菌區 |
| 倒優碘與生理食鹽水、戴無菌手套 | 不使用碘酒 |
| 潤滑導尿管前端 **5–7 cm** | 水溶性潤滑劑 |
| **先鋪洞巾**，對準尿道口 | 手包在洞巾角內，防碰到大腿 |
| 非慣用手拇指與食指**分開小陰唇並固定**到尿流出為止 | 露出尿道口 |
| 消毒：**遠側小陰唇 → 近側小陰唇 → 中間尿道口**，**由上往下**，每支棉棒只用一次；再用生理食鹽水棉棒同法擦 | 先遠後近避免跨越已消毒處；由上往下 |
| 請病人張口深呼吸，插入停一下，括約肌放鬆再插到約 **5 cm** | 要取無菌尿時留中段尿約 8–10 mL |
| 存留導尿：見尿流出後再插入約 2.5–5 cm 才打水球，**輕拉確認固定，再推回約 2 cm** | 防水球壓膀胱頸一直有尿意 |
| 連接蓄尿袋，固定在**大腿內側**，留足夠長度 | 避免拉扯 |

- 男性：握陰莖成 **60–90 度**、包皮往後推，由尿道口**向外環形**消毒龜頭；插入約 **20 cm**
- 打水球時病人喊痛 → 水球卡在尿道：**先抽出液體**，再把導尿管推進約 2 cm 後重打；不可先往外拉
- 漏尿時**不要加大水球**（過大會膀胱痙攣、損傷膀胱頸）；先找原因（放置不當、腹壓、牽扯、便秘、尿道鬆弛、逼尿肌過度收縮）
- 來源：同書技術 15-4 p.406–412、15-5 p.413–418、p.386–387

### 存留導尿管的照護 {#indwelling-care}

1. 嚴格無菌；每天約 **3,000 mL** 液體、尿量維持 2,000 mL 以上
2. **導尿管護理**每天一次、**會陰沖洗每天兩次**（分泌物多就增加）
   1. 優碘棉棒消毒陰唇與尿道口，再由**尿道口往外**環形消毒導尿管約 10 cm，再用生理食鹽水擦一次
   2. 每次換到另一側不同位置重新固定，避免皮膚破損
3. 保持**密閉與通暢**：不扭折、不壓到、不拉扯；**尿袋沒尿先檢查管路是否通暢**，再考慮其他原因
4. 蓄尿袋
   1. 每 **8 小時**或滿 **1/2–2/3** 就倒
   2. 開口隨時關閉
   3. 下床活動時固定在腿上或手提，**一定低於膀胱**（防逆流）
5. 導尿管滑出尿道口要換新的
6. 更換：課本寫一般**每週**換導尿管與蓄尿袋（依材質）；現行感染管制建議**不必固定天數更換**，阻塞、滲漏或感染時才換，見 [[urinary-tract-infection#catheter-care]]
7. 盡量縮短留置天數（留越久越容易感染、膀胱失去張力）
8. 發燒、膀胱痛、尿量減少、混濁、血尿、惡臭 → 可能感染，通知醫師
9. 拔除：先倒尿、用空針**抽空水球**、深呼吸時輕輕拔出；拔管後 **6–8 小時**內要自解
- 來源：同書 p.386–387、技術 15-5 p.418–420

## 膀胱灌洗 {#bladder-irrigation}

1. 目的：沖出血塊、結石碎片、膿；維持引流通暢；用藥治療；降低感染
2. 方法
   1. **連續性膀胱灌洗**(CBI, continuous bladder irrigation)：用**三路導尿管**，灌洗液經點滴套接灌洗腔，由引流腔流出
   2. **小量（簡易）膀胱灌洗**：50 mL 空針接導尿管，每次灌入 **30–50 mL** 再抽出，來回灌洗；導尿管不通時先用這個方法
3. 數字
   1. 溫度 **37.8–41 ℃**；前列腺手術後常用**冰的生理食鹽水**止血
   2. 灌洗液面高出膀胱約 **75–90 cm**
   3. 總量 1,000–5,000 mL，每次灌入**不超過 300 mL**
   4. 出血多、鮮紅時開大流速；出血少時每分鐘 60–120 滴
4. 溶液：**生理食鹽水最常用**（等張不刺激）；灌洗液與管路每天換
5. 不可灌入空氣；記錄輸入與流出量（真正尿量＝流出量－灌入量）；大量出血或膀胱痙攣通知醫師
6. TURP（transurethral resection of the prostate，經尿道前列腺切除術）術後灌洗與 TUR 症候群見 [[urologic-disorders]]
- 來源：同書 p.388、技術 15-6 p.421–423

::questions{ids="108-2_FA_005"}

## 膀胱滴藥 {#bladder-instillation}

1. 把少量無菌藥液滴入膀胱：治療膀胱炎、分開粘連、改變尿液性質
2. 先導尿或灌洗排空膀胱；嚴格無菌
3. 藥物高度約 10–13 cm；一次 **15–30 mL**、不超過 30 mL（太多會想解出來）
4. 停留時間依醫囑，期間不讓病人排尿
5. 膀胱癌的膀胱灌注化療見 [[urologic-disorders]]
- 來源：同書 p.389

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 正常餘尿 < 100–200 mL | < 50 mL | 課本標準 |
| 誘尿用冷水沖會陰、足部熱敷 | 溫水沖會陰、手握冰塊 | 溫水放鬆、手部末梢最敏感 |
| 逆時鐘揉膀胱 | 順時鐘 | 課本做法 |
| 尿瀦留叩診鼓音 | 濁音 | 膀胱裡是液體 |
| 壓力性尿失禁多喝茶、可可 | 避免咖啡因 | 利尿、刺激膀胱 |
| 尿失禁是中年婦女正常現象 | 評估原因、教凱格爾運動 | 可以治療與改善 |
| 導尿管越粗越好 | 能引流的最小號 | 減少尿道損傷 |
| 塑膠管可放 1 個月 | 矽膠約 1 個月 | 乳膠 1–2 週 |
| 水球打生理食鹽水 | 無菌蒸餾水 | 課本做法與國考答案 |
| 水球打水痛就先把管子往外拉 | 先抽出液體，再推進約 2 cm | 水球卡在尿道 |
| 漏尿就把水球加到 30 mL | 找原因 | 水球過大會膀胱痙攣 |
| 女性尿管固定在下腹部 | 女性大腿內側；男性下腹部 | 配合尿道走向 |
| 單次導尿一次放乾淨 | 一次 ≤ 500 mL | 防休克 |
| 三路導尿管有一腔排氣 | 固定、引流、灌洗 | 沒有排氣腔 |
| 連續膀胱灌洗用雙腔導尿管 | 三路導尿管 | 需要灌洗腔 |
