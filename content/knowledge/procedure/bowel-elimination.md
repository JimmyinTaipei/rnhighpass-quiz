腸道排泄的護理是基本護理的大章，國考集中在**糞便性狀代表什麼**、**便秘與糞便嵌塞的處理**、**腹瀉與失禁的護理**，以及**灌腸**的種類、溶液量、溫度、高度、肛管大小與插入深度。本頁依這個順序整理。腸造口的觀察、換袋與灌洗見 [[colorectal-cancer#ostomy]]，傳染性腹瀉的病原與處置見 [[infectious-diarrhea]]，肛門栓劑的步驟見 [[non-parenteral-medication]]，糞便檢體留取留到出入院與檢體頁

## 重點摘要 {#summary}

- 大腸運動三種：**結腸袋攪拌運動**（把食糜推到下一個結腸袋）、**蠕動**（慢）、**質塊運動**（大蠕動，**一天只有幾次、多在飯後**）；**胃結腸反射在早餐後最強**，最適合排便
- 排便反射：直腸壁被撐開 → **S2–S4** 排便中樞 → 副交感使直腸收縮、**肛門內括約肌**（平滑肌、不隨意）放鬆；大腦允許時**肛門外括約肌**（橫紋肌、隨意）放鬆才排出
- 糞便顏色：**灰白（陶土）色＝膽汁進不了腸道**（膽道阻塞）或鋇劑；**黑色＝上消化道出血、鐵劑、豬肝**；**鮮紅＝下消化道出血**；**鉛筆狀**＝直腸腫瘤壓迫；**黏液便**＝腸道發炎或感染
- 便秘護理：每天液體 **2,000–2,500 mL**、高纖、**早餐後定時排便**、**蹲姿**、**由右往左**順結腸按摩、運動；**不要養成定期灌腸或每天吃瀉藥**
- **糞便嵌塞**：肛門滲出少量糞水、一直有便意 → **先做肛門指診**；最有效的是**指挖**（先塗含局部麻醉的潤滑劑），挖除時注意**迷走神經反應**（心悸、頭暈就停）；糞石卡在直腸不靠灌腸
- 腹瀉：首要目標是**避免體液電解質失衡**；肛周皮膚溫水洗、塗氧化鋅
- 灌腸**左側臥**（降結腸、乙狀結腸在左）；不能左側臥時可俯臥墊高臀部或屈膝仰臥；**腸阻塞用膝胸臥**
- **禁忌**：不明原因腹痛、急性闌尾炎、安胎、疼痛性嚴重痔瘡、直腸狹窄或潰瘍；顱內壓高者只用甘油球、不做大量灌腸

### 國考常考點 {#exam-points}

- 食糜被推到下一個結腸袋＝**結腸袋攪拌運動**(115-2_FA_019)；質塊運動「每小時出現數次」是錯的，一天只有幾次(106-2_makeup_FA_051)；胃結腸反射**早餐後**最強(109-1_FA_041)；「肛門括約肌**收縮**引起排便」是錯的，要**放鬆**(105-1_FA_035)
- 正常糞便有**脂肪、膽紅素、鈣磷、剝落的死菌**，**沒有紅血球**(112-1_FA_031)；扁平、鉛筆狀不是正常(111-1_FA_031)
- 伐氏操作：**胸內壓上升、心輸出量減少**(107-2_FA_044)；心肌梗塞急性期用便盆：**先溫暖便盆**，不教伐氏、不下床(108-1_FA_033)
- 顏色：膽結石合併總膽管阻塞 → **灰白色**(108-1_MS_013)；上消化道出血、鐵劑 → **黑色**（106-2_FA_033、105-2_FA_034、107-2_FA_028）；下消化道出血 → **紅色**(106-2_FA_039)；**直腸出血不會是黑便**(111-2_FA_032)；黏液便 → 疑似**腸道感染**(112-2_FA_031)
- 腹瀉時腸音**增加**(107-2_FA_029)；「叩診鼓音表示腸蠕動良好」是錯的(106-2_OP_023)
- 大腸鏡：檢查前要**服瀉劑或清潔灌腸**(111-1_FA_032)；姿勢是**左側臥或膝胸臥**，不是右側臥
- 便秘：成人液體 **2,000–2,500 mL**、**小紅莓汁**可刺激腸蠕動、按摩**由右往左**(112-2_FA_032)；**定期灌腸**、**每天睡前吃瀉藥**都不適當（107-2_FA_032、106-2_FA_031、105-2_MS_010）
- 糞便嵌塞：滲糞水、有便意 → **肛門指診**(109-1_FA_032)；指挖前塗**局部麻醉潤滑劑**；挖除引起**迷走神經**反應、心悸要停、直腸糞石不靠灌腸(109-1_FA_035)
- 輕度大便失禁應減少**咖啡**(106-2_makeup_MS_014)
- 禁忌：不明腹痛、闌尾炎、安胎、嚴重痔瘡（108-1_FA_036、112-3_FA_017、110-2_FA_043）；**長期導尿、結腸造口不是禁忌**；骨折臥床多日未解便腹脹**適合**灌腸；下腹劇痛一週未解便**不可立刻灌腸**(108-1_FA_034)
- 姿勢：一般**左側臥**，髖關節受傷可屈膝仰臥，**腸阻塞膝胸臥**(107-1_FA_031)，「老年人採坐式」錯(105-1_FA_037)
- 肛管：成人大量 **22–24 Fr**(111-2_FA_029)、兒童 **14–18 Fr**(110-1_FA_036)；插入**成人 7.5–10 cm**（107-1_FA_034、111-1_FA_029）
- 溫度：溶液太冷會使**肛門括約肌痙攣**(106-1_FA_035)
- 清潔灌腸最常用**生理食鹽水**(112-2_FA_029)；**嬰幼兒用生理食鹽水**防電解質失衡(107-2_FA_034)
- 灌腸中輕微腹痛：**暫停或放慢**，痛消失再繼續（106-2_FA_032、105-2_FA_035）；插管時**張口哈氣**是為了減輕腹壓(106-2_makeup_FA_036)
- 保留灌腸：90–180 mL、**37.8–41 ℃**、慢慢灌、保留 **30 分鐘以上**(105-1_FA_038)；**麻醉劑**可用保留灌腸給(114-1_FA_020)
- 甘油灌腸：90–180 mL、甘油＋水、忍 5–10 分鐘(105-1_FA_033)
- 結腸灌洗：可降低體內**氨**、不是用來減輕痔瘡痛(113-1_FA_020)；液面高 **45–60 cm**，「高於 70 cm」錯(105-2_FA_036)
- 兒童灌腸：用生理食鹽水、右側臥錯、肛管 14 Fr 插 7.5 cm 對(106-1_OP_073)；大量灌腸溶液 **30–36 ℃ 太低**、左側臥右膝屈曲、用遊戲說明(114-1_OP_047)

## 大腸的構造與排便 {#physiology}

### 構造 {#anatomy}

1. 大腸順序：**盲腸**（含迴盲瓣、闌尾） → 升結腸 → 橫結腸 → 降結腸 → **乙狀結腸** → 直腸 → 肛門
2. 迴盲瓣平時關閉，防止結腸內容物逆流回小腸
3. 直腸平時是空的，要排便時才有糞便停留
4. 肛門兩個括約肌
   1. **內括約肌**：平滑肌、自主神經支配、**不隨意**
   2. **外括約肌**：橫紋肌、**隨意**控制

### 功能 {#functions}

| 功能 | 重點 |
|---|---|
| 吸收 | **最主要**：吸收大量水分與電解質；蠕動太快 → 水樣便，太慢 → 乾硬便秘 |
| 保護 | 杯狀細胞分泌黏液，潤滑糞便、保護腸壁 |
| 分泌 | 吸收鈉氯、分泌碳酸氫根與鉀；結腸功能異常會造成電解質失衡 |
| 排泄 | 排出廢物與氣體 |

- 來源：實用基本護理學下冊 p.343–344

### 大腸的運動 {#motility}

| 運動 | 做什麼 | 重點 |
|---|---|---|
| **結腸袋攪拌運動** | 環肌與縱肌收縮，把食糜推到**下一個結腸袋** | 混合、吸收水分 |
| 蠕動 | 把內容物往前推 | 很慢，一次只推一點 |
| **質塊運動**（大蠕動） | 把糞便一次推到直腸 | **一天只有幾次、多在飯後**；由**胃結腸反射**與**十二指腸結腸反射**引發 |

- **胃結腸反射**：食物進胃 → 副交感興奮 → 結腸蠕動；**早餐後最強**
- 十二指腸結腸反射：飯後約 30 分鐘食糜進十二指腸 → 便意
- 來源：同書 p.344–346

::questions{ids="115-2_FA_019,106-2_makeup_FA_051,109-1_FA_041"}

### 排便反射 {#defecation-reflex}

1. 糞便進直腸 → 直腸壁被撐開、壓力上升
2. 訊息到薦髓 **S2–S4** 排便中樞
   1. 副交感：降結腸、乙狀結腸、直腸收縮，**肛門內括約肌放鬆**（不隨意）
   2. 傳到大腦：時間地點合適 → **外括約肌放鬆**排出；不合適 → 外括約肌收縮、忍住
3. 排便是括約肌**放鬆**，不是收縮
4. **伐氏操作**(Valsalva maneuver)：閉住聲門用力憋氣 → **胸內壓與腹內壓上升** → 靜脈回流減少、**心輸出量下降**，用力時血壓上升
   1. **心血管疾病、顱內壓上升、老人**等不宜用力憋氣（可能暈厥、中風、心肌梗塞）
   2. 這類病人用軟便劑，避免用力
- 來源：同書 p.346–347

## 評估 {#assessment}

### 健康史與身體檢查 {#history-exam}

1. 健康史：平常排便次數與時間、糞便性狀與改變、腹部肛門疾病與手術、有無造口、飲食與液體、運動、藥物、家族大腸癌史、情緒、誰能協助
2. 腹部檢查順序：**視、聽、叩、觸**（觸診放最後，以免刺激蠕動影響聽診）
   1. 聽診：用膜面聽**四個象限**；**腹瀉時腸音增加**；國考把正常腸音寫成每分鐘 5–34 次(106-2_OP_023)
   2. 叩診：評估腹脹程度與腹水；**鼓音代表有氣體**，不代表蠕動好
   3. 觸診：乙狀結腸有糞便積聚時可摸到圓形硬塊
3. 肛門直腸：看有無痔瘡、發炎，再指診有無腫塊
- 來源：同書 p.347–348

### 糞便性狀 {#stool-characteristics}

| 項目 | 正常 | 異常與可能原因 |
|---|---|---|
| 顏色 | 嬰兒黃色、成人棕色 | **灰白色**（陶土色）：**膽道阻塞**沒有膽汁、鋇劑檢查後<br>**黑色**（柏油便）：**上消化道出血**（胃潰瘍、食道靜脈曲張）、**鐵劑**、吃**豬肝**等內臟或深綠色蔬菜<br>**紅色**：**下消化道出血**（直腸）、甜菜<br>綠色或橘色：腸道感染、藥物 |
| 硬度 | 成形、軟 | 乾硬：脫水、蠕動慢（低纖、少動、濫用瀉劑）；水樣：蠕動快 |
| 形狀 | 圓柱狀，直徑約 2.5 cm | **扁平、鉛筆狀、細線狀**：**直腸腫瘤**擠壓腸腔 |
| 氣味 | 依食物與菌叢 | 腐臭：感染或出血；酸臭：醣類或脂肪吸收不良；嚴重腐肉臭：晚期大腸癌 |
| 成分 | 少量粗渣、**剝落的死菌與上皮細胞**、**脂肪**、**膽紅素**、**鈣磷等無機物**、蛋白質 | **黏液**：腸道發炎或感染；膿：細菌感染；**血液**：出血；大量脂肪：吸收不良；寄生蟲 |
| 量與次數 | 每天約 100–400 g；成人每天 1 次到每週 2–3 次；喝母乳的嬰兒每天 4–6 次 | — |

- 正常糞便**沒有紅血球**；潛血陽性要想到大腸腫瘤
- 來源：同書 p.348–349

### 檢查 {#diagnostic-tests}

1. 腹部 X 光與鋇劑攝影：鋇劑可能留在結腸使糞便變硬，檢查後要注意**便秘或嵌塞**
2. 大腸鏡等下消化道內視鏡
   1. 檢查前約 **3 天低渣飲食**、前一天午夜後禁食，依醫囑**服清腸藥**；當天還沒解乾淨可再**清潔灌腸**
   2. 檢查時**膝胸臥或左側臥**；會灌空氣撐開腸道，可能有便意
   3. 檢查後觀察**發燒、出血、腹脹、腹痛**
3. 糞便潛血與篩檢見 [[colorectal-cancer#screening]]
- 來源：同書 p.350–351

### 影響排便的因素 {#factors}

| 因素 | 影響 |
|---|---|
| 年齡 | 老人腸蠕動變慢易便秘；幼兒完成排便訓練前，直腸一受刺激就排 |
| 飲食與液體 | 高纖與足夠水分使糞便成形、刺激蠕動；液體太少 → 便秘 |
| 活動 | 長期臥床、少動 → 便秘 |
| 心理 | 壓力焦慮可致腹瀉；憂鬱與緊張使蠕動減少 |
| 習慣與環境 | 定時排便習慣、隱私、如廁姿勢（習慣蹲姿的人坐著不易解） |
| 藥物 | **鐵劑**使糞便變黑變硬；**鴉片類止痛劑**便秘；**抗生素**腹瀉；含鎂制酸劑腹瀉、含鋁便秘；全身麻醉減少蠕動 |
| 檢查與手術 | 鋇劑；腹部手術後**麻痺性腸阻塞**約 24–48 小時，蠕動恢復才進食；會陰或腹部傷口痛而不敢用力 |
| 其他 | 痔瘡疼痛不敢解 → 便秘 → 痔瘡更嚴重；懷孕末期子宮壓迫直腸；臨終常排便失禁 |

- 來源：同書 p.351–353

## 便秘 {#constipation}

- 便秘：每週排便少於 3 次、糞便乾硬、用力、排不乾淨；**感受性便秘**是自己認定要每天解，因而濫用瀉劑、灌腸或栓劑（課本護理診斷定義 p.424）
- 來源：同書 p.354–355

| 措施 | 做法 |
|---|---|
| 評估 | 找出原因（飲食、活動、藥物、習慣） |
| 飲食 | 增加纖維：蔬菜、水果、全穀類 |
| 液體 | 無禁忌時每天 **2,000–2,500 mL**；梅子汁、檸檬汁、橘子汁、**小紅莓汁**能刺激蠕動、軟便（避免過多含糖飲料） |
| 運動 | 散步、騎車、游泳；腹肌等長收縮（心臟病人不做）、屈膝到胸增加腹壓 |
| 定時排便 | 利用**胃結腸反射**，**早餐後**最好；固定時間如廁 |
| 環境與情緒 | 提供隱私、放鬆 |
| 姿勢與按摩 | **蹲姿**最好；**由右往左**順著結腸方向按摩腹部；臥床者床頭抬高成高坐臥、身體前傾；**髖關節置換**術後不可彎超過 90 度、要加高馬桶座、上身不前傾 |
| 皮膚 | 排便前在肛門塗潤滑劑，避免硬便撕裂 |
| 腸道療法 | 依醫囑用瀉劑、栓劑或灌腸；**不是**每天定時灌腸或天天吃瀉藥 |

- 栓劑常用 bisacodyl(Dulcolax)，直接刺激直腸引起蠕動；步驟見 [[non-parenteral-medication]]
- 產後便秘、痔瘡術後照護與瀉劑藥理留給產科與消化系統那兩輪

::questions{ids="112-2_FA_032,107-2_FA_032,106-2_FA_031,105-2_MS_010,108-1_FA_033"}

### 糞便嵌塞 {#fecal-impaction}

1. 原因：便秘沒有解除，糞便久留直腸，水分一直被吸收而變得堅硬
2. 表現：**肛門流出少量糞水**（容易被誤認為腹瀉）、一直想解便、直腸痛、腹脹、噁心嘔吐、血壓上升
3. 處理
   1. 懷疑時先做**肛門指診**確認，不要直接給止瀉劑或停軟便藥
   2. **指挖**最有效：先塗**含局部麻醉成分的潤滑劑**
   3. 指挖會刺激**迷走神經**：病人頭暈、心悸、**心跳變慢**時**立刻停止**
   4. 糞石卡在直腸不易被溶液軟化，**不靠灌腸**
- 來源：同書 p.355

::questions{ids="109-1_FA_032,109-1_FA_035"}

## 腹瀉 {#diarrhea}

1. 評估原因：飲食、生活習慣、排便史
2. **最重要**：避免**體液電解質失衡**（由口或靜脈補水分、鈉、鉀）
3. 急性期減少進食量，減少刺激
4. 皮膚：便後用軟衛生紙或溫水清洗，塗潤滑油或**氧化鋅軟膏**
5. 依醫囑止瀉劑；活動時防頭暈跌倒
- 來源：同書 p.356
- 傳染性腹瀉的隔離與口服補液見 [[infectious-diarrhea]]

## 排便失禁與排便訓練 {#bowel-incontinence}

1. 皮膚：保持皮膚、床單、衣服**清潔乾燥**
2. 排便訓練
   1. 評估平常型態，失禁時記錄次數，找原因
   2. 選固定時間；在那之前**半小時**給軟便劑或栓劑
   3. 排便前喝熱飲或冷果汁
   4. 定時協助如廁，給隱私，每次約 **15–20 分鐘**
   5. 坐馬桶時上身前傾、雙手壓腹部
   6. 足夠液體與纖維；能力範圍內活動、骨盆肌肉訓練
3. 身體心像：表現好給予讚美；弄髒床單時**不要表現嫌惡**、不批評
4. 飲食：避免刺激腸道的**咖啡**等(106-2_makeup_MS_014)
- 來源：同書 p.356–357

::questions{ids="106-2_makeup_MS_014"}

## 灌腸 {#enema}

### 目的與種類 {#enema-types}

- 定義：把溶液灌入直腸或結腸，使腸道膨脹、刺激黏膜，以清潔下腸道或給藥、營養
- 目的：**清潔腸道與協助排便**、給藥、供給營養、協助診斷（鋇劑）

| 分類 | 種類 | 量 | 重點 |
|---|---|---|---|
| 依量 | **大量灌腸** | 成人 **750–1,000 mL**；青少年 500–750；學齡 300–500；幼兒 250–350；嬰兒 150–250 | 肥皂水、生理食鹽水、清潔、診斷性 |
| | **小量灌腸** | **不超過 240 mL** | 甘油、安撫、驅風、興奮劑等 |
| 依保留時間 | **非保留** | 大量 | 在腸內只停 **5–10 分鐘**就排出；解便秘、清腸、排氣 |
| | **保留** | **90–180 mL**，流速很慢 | 讓腸道不脹、不引起便意，保留吸收；可給油劑（軟化糞便）、水分、**麻醉劑或鎮靜劑**（給藥前約 1 小時先清潔灌腸） |

- 保留時間：課本寫保留灌腸 **15–30 分鐘**、甘油灌腸忍便意 15–30 分鐘、大量灌腸忍 5–10 分鐘；國考 105-1_FA_038 以「保留 30 分鐘以上」為正確、105-1_FA_033 以甘油灌腸「忍 5–10 分鐘」為正確，**作答依國考**

| 依作用 | 目的 | 溶液重點 |
|---|---|---|
| **清潔灌腸** | 軟化糞便解便秘；檢查或手術前清腸；排寄生蟲 | **0.2% 肥皂水**（先加水再加肥皂凍，避免起泡）；**生理食鹽水**等張不刺激，**最常用**；清水是低張，大量灌入會稀釋血液、造成電解質失衡 |
| 甘油灌腸 | 軟化糞便；直腸或會陰術後 | **甘油：水＝1：1**，約 90–180 mL；油類不用加熱太高 |
| 驅風灌腸 | 排氣、減輕腹脹 | 「1-2-3 灌腸」：50% 硫酸鎂 30、甘油 60、水 90 mL |
| 收斂灌腸 | 止血、腸組織收縮 | 明礬水或冰水，緩慢灌入，不必保留 |
| 驅蟲灌腸 | 排寄生蟲 | 保留 15–30 分鐘，排出後檢查糞便 |
| 診斷性灌腸 | 下消化道攝影 | 硫酸鋇；前晚瀉劑、當天清潔灌腸 |
| 安撫灌腸 | 保護腸黏膜、減輕刺激 | 澱粉液 |
| 營養、鎮靜劑、興奮劑灌腸 | 不能口服時給營養或藥 | 全身作用；鎮靜劑給前 1 小時先清潔灌腸 |

- 配 0.2% 肥皂水 1,000 mL：10% 肥皂凍 × X＝0.2% × 1,000 → **X＝20 mL**（2% 肥皂凍則取 100 mL）
- 來源：同書 p.357–360

::questions{ids="112-2_FA_029,107-2_FA_034,114-1_FA_020,105-1_FA_038,105-1_FA_033"}

### 數字總表 {#enema-numbers}

| 項目 | 大量灌腸（非保留） | 小量灌腸 | 保留灌腸 | 結腸灌洗 |
|---|---|---|---|---|
| 溶液量 | 成人 750–1,000 mL | ≤ 240 mL | 90–180 mL | 每次約 500 mL，總量依目的，灌到回流液清澈 |
| 溫度 | 成人 **41–43 ℃**；兒童約 37.8 ℃ | 37.8–41 ℃ | **37.8–41 ℃**（不超過 41 ℃） | 41–43 ℃ |
| 液面到肛門高度 | 成人 **45–60 cm**；兒童 37.5–45 cm | **15–20 cm** | 低壓、慢慢灌 | **45–60 cm** |
| 速度 | 慢慢灌，防腸痙攣 | 慢 | 很慢 | 每分鐘 **100–150 mL** |

| 肛管 | 大小 | 插入深度 |
|---|---|---|
| 成人 | **22–24 Fr**（依體型） | **7.5–10 cm** |
| 兒童 | **14–18 Fr** | **5–7.5 cm** |
| 嬰兒 | 10 Fr | 2.5–3.75 cm |

- 肛管潤滑前端 **5–10 cm**；凡士林不要塗太多以免堵住管孔
- 溫度太高：腹腔血管擴張使腦部與心臟供血不足而**昏厥**，也會傷腸黏膜；**太低：肛門括約肌痙攣**；保留灌腸溫度高於體溫會刺激蠕動而排出
- 6 歲以下幼兒常一邊灌一邊流出，一次只灌少量、壓力不可大
- 嬰幼兒清潔灌腸用**生理食鹽水**，不用清水或肥皂水（電解質失衡）
- 來源：同書 p.361–362、表 15-4、15-5 p.391

### 姿勢與禁忌 {#enema-position}

1. 姿勢
   1. **左側臥**、右膝彎曲：降結腸與乙狀結腸在下方，溶液靠重力流入
   2. 無法左側臥：**俯臥墊高臀部**或**屈膝仰臥**（髖關節受傷、產婦臨產）
   3. **腸阻塞：膝胸臥**
   4. 不採坐姿灌腸（溶液進不去）
2. **禁忌**
   1. **不明原因腹痛**（可能是闌尾炎或穿孔，灌腸會加重）
   2. **急性闌尾炎**
   3. **產科安胎**（刺激子宮收縮）
   4. **疼痛性嚴重痔瘡**
   5. 直腸狹窄或潰瘍
   6. **顱內壓上升**：適時用甘油球防便秘用力，**不做大量灌腸**
3. 不是禁忌：長期留置導尿、結腸造口、骨折臥床便秘
- 來源：同書 p.361–362

::questions{ids="107-1_FA_031,105-1_FA_037,108-1_FA_036,112-3_FA_017,110-2_FA_043,108-1_FA_034"}

### 大量灌腸的步驟 {#large-volume-steps}

| 步驟 | 要點 |
|---|---|
| 核對、解釋、問是否需要便盆 | 減少不安 |
| 備溶液 | 0.2% 肥皂水或生理食鹽水 1,000 mL，水溫計量 41–43 ℃ |
| 準備病人 | 拉床簾、浴毯；**左側臥、右腳彎**，臀部靠床緣；臀下墊防水中單 |
| 掛灌腸筒 | 液面到肛門 **45–60 cm** |
| 潤滑、排氣 | 戴手套，凡士林潤滑肛管前端 5–10 cm；先放少量溶液到彎盆排出空氣（防腹脹） |
| 插管 | 撥開臀部，請病人**張口哈氣或說「啊」**（放鬆腹肌、**減輕腹壓**），輕輕插入成人 **7.5–10 cm** |
| 灌入 | 打開管夾慢慢流入；**腹痛或很想解：降低流速或暫停**，痛消失再繼續 |
| 拔管 | 快流完時關管夾（防空氣進入），衛生紙壓肛門拔出 |
| 保留 | 請病人盡量忍 **5–10 分鐘**再解 |
| 記錄 | 時間、溶液與量、排出物性狀、效果與反應；體溫單大便欄：解 1 次寫 **1/E**、2 次 **2/E**、沒解 **0/E** |

- 持續劇烈腹痛、腹脹 → 可能**腸穿孔**，立刻停止並通知醫師
- 來源：同書技術 15-1 p.392–396、注意事項 p.361–362

::questions{ids="106-2_FA_032,105-2_FA_035,106-2_makeup_FA_036"}

### 小量灌腸 {#small-volume}

1. 甘油灌腸：甘油 60 mL＋水 60 mL，**37.8–41 ℃**；用灌腸空針接肛管，液面離肛門約 **15–20 cm**（太高會流太快、刺激排便）
2. **可棄式灌腸器**（如市售灌腸液）：管身潤滑後插入肛門約 **7.5–10 cm**，慢慢擠；**擠完不要鬆手**，拔出肛門後才放開（避免吸回）；潤滑的是插入的管身，不是接合處
3. **甘油球**（約 20 mL）：拿掉蓋套直接插入擠完，同樣拔出後才鬆手
4. 灌完後一樣**左側臥**、請病人哈氣放鬆；不舒服就停，不要「忍到灌完」
- 來源：同書技術 15-2 p.397–401

::questions{ids="111-1_FA_029"}

### 兒童灌腸 {#pediatric-enema}

1. 用遊戲、故事或娃娃示範說明目的與過程
2. 溶液用**生理食鹽水**；量依年齡（學齡 300–500 mL）
3. **左側臥、右膝屈曲**；肛管 **14–18 Fr**、插 **5–7.5 cm**
4. 大量灌腸溫度不能太低（30–36 ℃ 太低）；國考 114-1_OP_047 以此為不適當
5. 出現臉色蒼白、冒冷汗、心跳加快 → **停止並通知醫師**
- 來源：同書 p.357、361–362；兒科灌腸細節留產兒輪

::questions{ids="106-1_OP_073,114-1_OP_047"}

## 結腸灌洗 {#colonic-irrigation}

1. 定義：在**低壓**下把大量溶液灌入結腸，再從另一條管流出，不留在腸內；比灌腸徹底
2. 目的：術前或檢查前**徹底清腸**；**稀釋毒素**（如降低肝昏迷病人的**血氨**）、排氣；供給體液；減輕局部發炎
3. 溶液：清潔用清水、生理食鹽水；另有治療痢疾、去黏膜、供給體液的配方
4. 數字：**41–43 ℃**、液面到肛門 **45–60 cm**、每分鐘 **100–150 mL**、每次約 500 mL，回流完再灌下一次，清潔目的灌到**回流液和灌入液一樣清**
5. 姿勢同灌腸，**左側臥**
6. 禁忌：肛門括約肌鬆弛且有痔瘡疼痛、腸道或肛門附近惡性腫瘤或發炎傷口、腸道發炎或腸結核、腸息肉、一般情況差或昏迷
7. **乙狀結腸造口灌洗**：基護課本寫清水約 41 ℃、高度 45–60 cm、約 10 分鐘內灌完；[[colorectal-cancer#irrigation]] 整理的是溫開水約 37–38 ℃、灌洗袋約與肩同高，兩處數字不同，作答看題目情境
- 來源：同書 p.363–364、技術 15-3 p.402–405

::questions{ids="113-1_FA_020,105-2_FA_036"}

## 腸造口的位置 {#stoma-sites}

::figure{src="/knowledge-images/servier-stoma-sites.svg" labels="stoma-sites" alt="大腸與造口位置：越靠近迴腸，排出物越稀；越靠近乙狀結腸，越成形"}

| 造口 | 排出物 | 照護重點 |
|---|---|---|
| **迴腸造口** | 液狀、量多、含消化酶 | 刺激皮膚；記錄引流量、補充水分電解質；不灌洗 |
| 升結腸造口 | 液狀到半液狀、不規則 | 增加水分；不灌洗 |
| 橫結腸造口 | 半成形、不規則 | 需要造口袋 |
| 降結腸、**乙狀結腸造口** | **成形便** | 可做**灌洗**建立規律排便 |

- 規則：**造口越靠近小腸，排出物越稀**、對皮膚越刺激
- 造口顏色正常**玫瑰紅、濕潤**；**蒼白、暗紫或發黑**要立刻就醫；糞便達造口袋 **1/3–1/2** 就倒；換底座在空腹或飯前；周圍皮膚用溫水清潔、不消毒（屏東醫院〈腸造口照護〉衛教單張）
- 底座開口比造口大多少：屏東醫院衛教單張寫 0.1–0.2 cm，[[colorectal-cancer#pouching]] 整理的是 0.2–0.3 cm；原則都是不壓迫造口、也不露出太多皮膚
- 觀察、換袋、灌洗、飲食的完整內容見 [[colorectal-cancer#ostomy]]

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 質塊運動每小時數次 | 一天幾次、多在飯後 | 由胃結腸反射引發 |
| 肛門括約肌收縮引起排便 | 括約肌放鬆才排出 | 外括約肌收縮是忍住 |
| 直腸出血是黑便 | 黑便來自上消化道 | 血經過胃酸與消化才變黑 |
| 叩診鼓音表示蠕動好 | 鼓音代表有氣 | 蠕動要用聽診 |
| 便秘每天定時灌腸或吃瀉藥 | 飲食、水分、運動、定時排便 | 會依賴、破壞排便反射 |
| 按摩由左往右 | 由右往左順結腸 | 升 → 橫 → 降結腸 |
| 糞便嵌塞先灌腸或給止瀉劑 | 先肛門指診，再指挖 | 糞水是溢出，不是腹瀉 |
| 灌腸採右側臥或坐姿 | 左側臥；腸阻塞膝胸臥 | 順著降結腸方向 |
| 灌腸腹痛就加快灌完 | 暫停或放慢 | 腸痙攣 |
| 嬰幼兒用清水灌腸 | 生理食鹽水 | 低張液會造成電解質失衡 |
| 結腸灌洗液面高 70 cm 以上 | 45–60 cm | 低壓灌洗 |
| 不明腹痛先灌腸 | 先評估，禁灌腸 | 可能闌尾炎或穿孔 |
