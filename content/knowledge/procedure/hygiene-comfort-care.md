身體清潔是最基本的舒適照護：去除汙物與微生物、預防感染、促進循環，也是護理師近距離評估皮膚與口腔的機會。本頁整理**口腔護理與假牙**、**協助更衣**(有點滴或患肢時的順序)、**床上沐浴與洗頭**、**背部按摩四種手法**、**指甲與足部護理**、**會陰沖洗**。翻身與臥位見 [[positioning-body-mechanics]]，壓力性損傷的預防見 [[pressure-injury]]，手部衛生與隔離見 [[infection-control]]

## 重點摘要 {#summary}

- 清潔的目的：滿足基本需要、**減少感染源**、增進舒適、建立護病關係、**順便評估**皮膚與口腔
- 口腔清潔溶液：**溫開水、生理食鹽水**適用所有人(生理食鹽水沒有殺菌力)；稀釋**水性優碘**可殺菌；**nystatin** 治念珠菌；**xylocaine 麻醉劑溶液**在飯前減輕潰瘍疼痛；課本註明 **1% 雙氧水**(傷牙肉)與**蘇打水**(燒灼感)已不建議使用
- 特殊口腔護理：意識不清者**側臥**防吸入；**鼻胃管灌食後 30 分鐘內不做**(避免嘔吐)；用壓舌板包紗布清舌苔
- 活動假牙：**戴前先泡水潤濕**；**睡前取下**放假牙盒(防變形、防誤吞)；**不用熱水、牙膏、肥皂**；硬橡皮材質泡水保存
- 更衣：雙手正常 → **先脫近側、先穿遠側**；有點滴或患肢 → **先脫健側、後脫患側；先穿患側、後穿健側**(口訣：患側後脫先穿)
- 床上擦澡：水溫約 **41–43 ℃**；由**遠心端往近心端**(促進靜脈回流)；**50% 酒精**使皮膚變硬、清涼，但**老人、皮膚乾燥、過敏者不宜**
- 背部按摩：**按撫法**用在開始與結束；**揉捏法**用在臀部、肩頸等多肉處；**重擦法**用在骨突、足踝、指節；**敲擊法**老人、虛弱、背部有病者禁用
- 會陰沖洗：屈膝仰臥或截石臥姿；水溫 **41–43 ℃**、量約 300–500 mL；**壺嘴朝床尾**；由**中間(尿道口、陰道口)往外**，每支棉棒**由上往下一次**、不來回

### 國考常考點 {#exam-points}

- 化療口腔潰瘍疼痛：用**麻醉劑溶液(xylocaine)漱口**減輕進食疼痛(112-3_FA_022)；適合口腔潰瘍的溶液是**生理食鹽水＋麻醉劑溶液**，檸檬水與雙氧水不適合(112-1_FA_034)
- 重症病人預防口腔感染：**稀釋水性優碘**(107-1_FA_033)；鼻胃管病人口腔護理可用溫開水、新鮮檸檬水、茶葉水(106-2_makeup_FA_047)
- 「鼻胃管灌食完**立即**做口腔護理」是錯的(106-2_makeup_FA_034)；意識清楚者不需要用托舌鉗固定舌頭；夜間熟睡不必每 2 小時叫醒做口腔護理
- 假牙：**置入前先以水濕潤**(113-1_FA_022、115-1_FA_020)；不可 24 小時配戴、不泡熱水；橡膠牙托泡水保存，不是乾燥保存
- 老人預防齲齒：牙線、塗氟、減少醣類；**植牙不是預防方法**(111-2_MS_016)
- 右手點滴：**右手後脫、先穿**(110-1_FA_027)；左前臂點滴：**先脫右側、先穿左側**(109-2_FA_034)；右手受傷：先脫左手(108-1_FA_035)
- 擦澡：兩手正常時先脫**靠近護理師側**衣袖(109-1_FA_033)；由近心端往遠心端是錯的；老人沐浴後**擦乳液**防乾燥，不用 50% 酒精(109-2_FA_036、107-1_FA_030)
- 中風病人家屬堅持多穿衣服、病人冒汗：**乾毛巾擦乾、內衣潮濕就換**，不強制減衣也不用爽身粉(109-2_FA_037)
- 背部按摩開始與結束用**按撫法**(110-1_FA_033、109-1_FA_012)；骨突、足踝、指節用**重擦法**(105-2_FA_031)；老人**不適用敲擊法**(110-2_FA_041、111-2_FA_033)
- 足部按摩禁忌：**深部靜脈栓塞、皮膚潰瘍、瘀斑(出血傾向)**；皮膚乾燥不是禁忌(115-2_FA_022)；下肢冰冷穿**透氣保暖襪**，不用熱水袋、暖暖包、泡熱水(106-2_makeup_FA_035)
- 會陰沖洗：**壺嘴朝床頭**是錯的(107-2_FA_030)；棉棒**來回擦拭**是錯的(106-1_FA_034)；有導尿管時順序**先中間尿道口與陰道口、再小陰唇、大陰唇**，導尿管置入處也要清潔(111-2_FA_035)
- 膠帶造成的皮膚損傷好發在**嬰幼兒與水腫**病人；移除時壓住邊緣皮膚、**低角度順毛方向**慢慢撕，不是垂直快速(112-1_MS_046)

## 清潔的目的與評估 {#purpose}

1. 目的(課本上冊 307)
   1. 滿足洗頭、刷牙、洗澡等基本需要
   2. 減少感染源(皮膚是第一道防線)
   3. 增進舒適、促進循環與放鬆
   4. 增進護病關係
   5. 評估皮膚、口腔、骨突處受壓情形，見 [[pressure-injury#sites]]
2. 執行前評估：病情是否穩定、管路與傷口位置、室溫、隱私；能自理者從旁協助，鼓勵家屬參與
3. 實證補充(課本 314)：重複使用的臉盆在 48 小時內就會殘留 MRSA(methicillin-resistant *Staphylococcus aureus*，抗藥性金黃色葡萄球菌)等細菌；加護病房改用**含 2% CHG(chlorhexidine gluconate)的拋棄式擦澡巾**可減少感染

## 口腔護理 {#oral-care}

### 口腔評估與種類 {#oral-assessment}

1. 評估：嘴唇、舌頭、牙齦、牙齒、黏膜完整與溼潤度、異味、唾液；念珠菌感染會有**白色斑點**
2. 一般口腔護理：能自己刷牙者從旁協助；**先用牙線、再刷牙**；牙線以 C 型貼著牙面上下移動
3. 特殊口腔護理：昏迷、禁食、插管、口腔疾病或無法自行刷牙者；經口氣管內管病人做好口腔護理可減少 VAP(ventilator-associated pneumonia，呼吸器相關肺炎)，見 [[mechanical-ventilation]]

### 口腔清潔溶液 {#oral-solutions}

依課本表 7-1 整理(上冊 309)

| 溶液 | 用途與特點 |
|---|---|
| 溫開水 | 最基本，所有病人(含嬰兒、老人)都可用 |
| 生理食鹽水 | 安全方便；**沒有殺菌效果**；有無潰瘍都能用 |
| 茶葉水、新鮮檸檬水(不可用罐頭)、甘草水 | 依喜好，保持口腔清新 |
| 新鮮鳳梨汁 | 去除舌苔 |
| 水性優碘(aqua beta-iodine) | 殺菌；**要稀釋**(課本 1：15)，例如咽喉腫痛 |
| nystatin(Mycostatin) | 口腔念珠菌、黴菌感染 |
| 麻醉劑溶液(xylocaine) | 潰瘍或疼痛時，**飯前或清潔前**使用減輕疼痛 |
| 0.1–0.2% chlorhexidine | 抑菌漱口水 |
| ~~1% 雙氧水(H₂O₂)~~ | 以前用來清血漬、痰液，**會損傷牙肉，現已不建議**(課本註) |
| ~~1% 蘇打水(NaHCO₃)~~ | 溶解黏液，但有燒灼感，**臨床已不使用**(課本註) |

:::warning[雙氧水與蘇打水]
舊考題可能把雙氧水當成「除口臭、清血痂」的答案；課本第 9 版已註明不建議。化療口腔黏膜炎見 [[cancer-treatment-toxicities]]
:::

### 特殊口腔護理的要點 {#special-oral-care}

| 要點 | 做法 | 原理 |
|---|---|---|
| 時機 | 不在飯後立即做；**鼻胃管灌食後 30 分鐘內不做** | 刺激咽部易嘔吐、吸入 |
| 姿勢 | 坐姿或側臥；**意識不清者側臥**、頭偏一側 | 分泌物由口角流出，防吸入 |
| 清舌苔 | 壓舌板包紗布或棉棒沾溶液，由內往外 | 減少菌落與異味 |
| 嘴唇 | 塗潤滑劑 | 防乾裂 |
| 意識清楚者 | 不需托舌鉗固定舌頭；可自己漱口者讓他自己漱 | 尊重與舒適 |

### 假牙護理 {#dentures}

1. 固定式假牙：和真牙一樣清潔
2. 活動假牙(課本 311–312)
   1. 三餐飯後取出清潔再戴回
   2. **戴前先泡水潤濕**，減少摩擦
   3. **睡前取下**放進假牙盒，不可戴著睡(防變形、防睡夢中誤吞)
   4. 睡前用假牙清潔錠浸泡約 15 分鐘後沖淨，不要泡一整夜
   5. **不用熱水、牙膏、肥皂**清洗(變形、刮傷)
   6. 保存：**硬橡皮牙托泡水**；合成樹脂牙托放乾燥容器(課本)
3. 老人預防齲齒：牙線、刷牙、塗氟、減少醣類；植牙是治療缺牙，不是預防齲齒

## 協助更衣 {#dressing}

1. 雙手健全：**先脫近護理師側、再脫遠側**；穿衣**先穿遠側、再穿近側**(課本上冊 320)
2. 肢體受傷或有靜脈輸液(IV)：**先脫健側、再脫患側或 IV 側；先穿患側或 IV 側、再穿健側**
   1. 脫：先關緊輸液控制鈕 → 脫健側袖 → 患側袖退出注射部位 → 點滴瓶連管路**穿過衣袖**再掛回
   2. 穿：點滴瓶連管路先穿過患側衣袖 → 穿患側 → 穿健側 → 掛回點滴並**重新調整滴速**
3. 無法脫衣(骨折、燒傷)：沿縫線剪開
4. 新入院病人脫下的衣物檢查有無昆蟲；衣物交家屬或送洗，不可丟地上

| 情境 | 脫 | 穿 |
|---|---|---|
| 右手點滴 | 先左、後右 | 先右、後左 |
| 左前臂點滴 | 先右、後左 | 先左、後右 |
| 右手受傷 | 先左、後右 | 先右、後左 |
| 左腿受傷(褲子) | 先右腿、後左腿 | 先左腿、後右腿 |

## 床上沐浴、皮膚與頭髮護理 {#bathing}

### 床上擦澡 {#bed-bath}

| 項目 | 做法 | 原理 |
|---|---|---|
| 環境 | 關窗、調室溫、拉床簾、只暴露擦拭部位 | 防受涼、保護隱私 |
| 水溫 | 約 41–43 ℃，水冷了就換 | 舒適、促進循環 |
| 順序 | 由上而下、由清潔到汙染；眼睛**由內眥往外眥**，每擦一眼換毛巾一角 | 避免交互汙染 |
| 四肢方向 | 由**遠心端往近心端** | 促進靜脈回流 |
| 肥皂 | 溫和不刺激；放射治療部位用中性肥皂 | 乳化去汙；減少刺激 |
| 乳液 | 擦完塗乳液，**老人與皮膚乾燥者尤其需要**；放射治療部位不擦 | 防乾燥 |
| 50% 酒精 | 使表皮角質變硬、增加抗壓力與清涼感；**老人、皮膚乾燥、過敏者不宜** | 酒精會使皮膚更乾 |

1. 臥床癱瘓、有汗臭的老人：肥皂與清水擦澡、床上洗頭、會陰護理；**不用 50% 酒精按摩**
2. 冒汗、衣物過多：**乾毛巾擦乾、內層衣物潮濕就換**；用爽身粉吸汗或電扇吹不是最好的處理
3. 鼠蹊與皮膚皺褶：擦乾即可，嬰兒油與爽身粉同時塗會結塊

::questions{ids="109-2_FA_036,109-1_FA_033,107-1_FA_030,109-2_FA_037"}

### 膠帶與醫療黏膠的皮膚損傷 {#adhesive}

1. 醫療黏膠相關皮膚損傷(MARSI, medical adhesive-related skin injury)：撕除膠帶造成表皮剝離、張力性水泡、浸潤
2. 高危險群：**嬰幼兒**(表皮薄)、**水腫**、老人、長期用類固醇者
3. 移除：一手壓住邊緣皮膚，另一手把膠帶**往回折、貼近皮膚(低角度)順著毛髮方向慢慢撕**；不垂直快速撕，不逆毛
4. 黏貼前不塗優碘增加黏性；必要時用皮膚保護膜

::questions{ids="112-1_MS_046"}

### 床上洗頭與梳髮 {#hair-care}

1. 先確認沒有禁忌(例如**顱內壓升高**)
2. 室溫約 22–27 ℃；用**指腹**搓洗，不用指甲
3. 頭頸部放射治療者不用洗髮精，改中性肥皂或清水
4. 吹乾時手擋在頭與吹風機之間，避免燙傷
5. 梳髮**從髮尾開始**；打結可用 50% 酒精潤滑；不用鐵梳

## 背部護理 {#back-care}

1. 目的：促進循環、放鬆肌肉、減輕疼痛與焦慮、改善睡眠，預防長期臥床的皮膚合併症
2. 不適合按摩：按摩處有傷口、發炎、感染；發燒、出血；腫瘤部位；**空腹或剛吃飽**；骨折、背部手術；**已發紅的骨突處**(見 [[pressure-injury#prevention]])
3. 姿勢：側臥、俯臥或坐姿；先溫毛巾清潔背部，乳液潤滑雙手，先把手貼在背上幾秒詢問力道

| 手法 | 做法 | 用在 |
|---|---|---|
| **按撫法**(stroking) | 雙手從尾骶骨沿脊椎兩側緩慢往上到肩膀、手臂，再沿脊椎回到尾骶 | **開始與結束**；老人可用 |
| **揉捏法**(kneading) | 拇指與四指成鉗狀把肌肉捏起 | **臀部、肩頸背、四肢**等多肉處 |
| **重擦法**(friction) | 拇指沿脊椎兩側旋轉按壓 | **骨突處、足踝、指節** |
| **敲擊法**(tapotement) | 手指張開以小指側敲擊 | **老人、身體虛弱、背部有疾病者禁用** |

::questions{ids="111-2_FA_033,110-2_FA_041,110-1_FA_033,109-1_FA_012,105-2_FA_031"}

## 指甲與足部護理 {#nail-foot-care}

1. 修剪前泡 38–41 ℃ 溫水 10–20 分鐘軟化；**足部紅腫或水泡不浸泡**
2. **手指甲剪成圓弧、腳趾甲剪平**，避免嵌甲；肉刺剪除後消毒，平時把甲上皮往後推
3. 灰指甲(黴菌感染)戴手套處理
4. 足部按摩禁忌(課本 322)：腫瘤或放射治療部位、**深部靜脈栓塞**、傳染性皮膚炎、急性發炎紅腫熱痛、**血小板過低(< 50,000)或出血傾向**(瘀斑)、皮膚潰瘍；**皮膚乾燥不是禁忌**，反而要擦乳液
5. 糖尿病足部：每天檢查有無紅、破皮、分泌物；**趾縫保持乾燥、不擦乳液**；**不泡熱水、不用熱水袋、暖暖包或電毯**(神經病變感覺遲鈍易燙傷)；穿透氣保暖襪；糖尿病足見 [[diabetes]]
6. 末梢冰冷：穿保暖襪；熱水袋、暖暖包、泡熱水都可能燙傷，見 [[patient-safety-environment#injury-types]]

## 會陰護理與會陰沖洗 {#perineal-care}

1. 對象：太虛弱、長期臥床、**留置導尿管**、產後婦女、月經期臥床者
2. 用物與溶液：溫水、生理食鹽水、1% 水性優碘等；量約 **300–500 mL**、水溫 **41–43 ℃**(課本上冊 324)
3. 姿勢：**屈膝仰臥**或膀胱截石臥姿；臀下墊橡皮中單與看護墊

| 步驟 | 做法 | 原理 |
|---|---|---|
| 1. 說明與隱私 | 取得同意、拉床簾、適當覆蓋；男護理師尤其要先取得同意 | 尊重 |
| 2. 擺位 | 屈膝仰臥、雙腿外展 | 暴露會陰 |
| 3. 試水溫 | 先沖大腿內側讓病人感覺 | 避免燙或冷 |
| 4. 壺嘴方向 | **壺嘴朝床尾**，由上往下沖 | 避免液體流入陰道與尿道 |
| 5. 擦拭順序 | **先中間(尿道口、陰道口)→ 遠側小陰唇 → 近側小陰唇 → 遠側大陰唇 → 近側大陰唇** | 由清潔區到較汙染區 |
| 6. 棉棒 | 每支**由上往下擦一次就丟**，不來回 | 避免把肛門細菌帶到尿道 |
| 7. 導尿管 | 尿道口與導尿管置入處也要清潔，由尿道口往外擦管路 | 預防導尿管相關感染 |
| 8. 結束 | 乾毛巾輕拍擦乾；產後墊棉墊；保持床單乾燥 | 防浸潤與感染 |

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 鼻胃管灌食後立刻做口腔護理 | 等 30 分鐘以上 | 刺激咽部易嘔吐吸入 |
| 雙氧水除口臭 | 課本已不建議 | 損傷牙齦黏膜 |
| 假牙泡熱水消毒、戴整天 | 冷水或清潔錠、睡前取下 | 變形、誤吞 |
| 右手點滴先脫右手 | 先脫健側(左)、先穿患側(右) | 減少拉扯針頭 |
| 擦澡由近心端往遠心端 | 遠心端往近心端 | 促進靜脈回流 |
| 老人背部按摩用敲擊法、50% 酒精 | 按撫、揉捏、重擦；擦乳液 | 老人皮膚薄而乾 |
| 會陰沖洗壺嘴朝床頭、棉棒來回擦 | 朝床尾、由上往下一次 | 防逆流與交互汙染 |
| 糖尿病腳冷用熱水袋 | 穿保暖襪 | 感覺遲鈍易燙傷 |
