**繃帶**用來固定敷料、支托患部、限制活動、加壓止血與減輕腫脹。國考考點很集中：**由遠心端往近心端包**、**每圈覆蓋前一圈 1/2–2/3**、**先環形定帶**、**哪裡不能結帶**、**各種包紮法用在哪裡**、**三角巾懸臂帶的角度**，以及**包紮後的血循評估**。本頁最後附傷口的分類與評估（課本第 19 章）；傷口癒合的病理見 [[inflammation-repair#repair]]，壓力性損傷見 [[pressure-injury]]，石膏照護見 [[activity-immobility#cast-care]]，傷口培養的採檢見 [[culture-and-sensitivity#other-specimens]]

## 重點摘要 {#summary}

- 目的：**固定敷料**、**限制關節活動**、**支托**、**減輕腫脹**、**固定骨折夾板**、**加壓止血**、矯正畸形、**保暖**（法蘭絨）；**不是**為了增加關節活動度或促進血液循環（彈性繃帶包下肢促進的是**靜脈回流**）
- **彈性繃帶**：截肢殘肢、關節扭傷加壓、股骨骨折術後下肢（促進靜脈回流防鬱積）、加壓止血減腫脹；太緊易影響血循
- 包紮前：**先清潔傷口、蓋無菌敷料**；骨突處與皮膚皺摺墊棉墊；**抬高肢體**；保持功能位置；繃帶要乾淨乾燥（濕的乾了會縮緊）
- 包紮時：包紮者站在**前方或側方**；**先環形定帶 2–3 圈**；**遠心端 → 近心端**（逆人體循環方向，促進靜脈回流）；**每圈覆蓋前一圈 1/2–2/3**；壓力均勻；**露出肢體末梢**
- **不可結帶**：骨突與**關節**處、**傷口或發炎處**、**肢體內側**、易摩擦與受壓處；定帶與結帶在**粗細均勻處**（可在外側，如上臂）
- 包紮後：**抬高患肢 15–30 分鐘**；**20 分鐘後**做完整血循評估，之後**每 2–4 小時**一次；發紺、冰冷、腫脹、刺痛、麻木、脈搏消失 → **鬆開重包**；受包紮肢體做**等長運動**
- 三角巾懸臂帶：**手腕高於手肘 10–12 cm**、肘彎**小於 90 度**、**手心朝內（拇指朝上）**、手腕不下垂、露出手指

### 國考常考點 {#exam-points}

- 目的：**加壓止血、固定傷口、保暖**(114-3_FA_031)；彈性繃帶最常用於**加壓止血、減輕腫脹**(112-2_FA_050)；股骨頭骨折術後下肢包彈性繃帶是為了**促進血液回流、防止鬱積**(110-2_FA_010)；截肢後減腫止血用**彈性繃帶**(111-1_FA_050)
- 方向：「**順人體循環方向**」「**由近心端往遠心端**」都是錯的（112-3_FA_031、108-1_FA_048、110-1_FA_043、111-1_FA_049、106-1_FA_047、112-1_FA_049）
- 覆蓋 **1/2–2/3**(111-1_FA_049)；「1/4–1/3」錯(106-1_FA_047)；**第一步以環形包紮定帶**（106-1_FA_047、108-1_FA_048）；「用緩螺旋定帶」錯；包紮者站在前方或側方
- 結帶：「於**關節處**結帶」錯(111-1_FA_049)；可在**上臂**結帶，不在傷口、關節、易受壓處(110-1_FA_044)；植皮後小腿包紮「結帶在小腿前方（骨突的脛骨上）」錯(108-2_FA_049)；「可將結帶固定於**肢體內側**」錯
- 包紮後患肢刺痛、麻木 → **立即重新包紮**(112-1_FA_049)；膝關節置換後彈性繃帶處腫痛 → **檢查是否綁太緊**(106-2_makeup_FA_045)
- 包紮後「**每 30 分鐘**評估末梢血循」被列為錯誤選項（111-2_FA_049，課本是 20 分鐘後評估一次，之後每 2–4 小時）
- 四肢包紮前要**抬高**，不是放低（106-1_FA_048、111-2_FA_050）
- 包紮法：**急螺旋**固定**夾板**（112-1_FA_050、106-1_FA_048）；**螺旋回反**用於粗細不均的肢體；**回反摺形**用於殘肢與末端；**人字形**用於拇指、肩、髖、鼠蹊；腳踝壓傷用 **8 字形**(111-2_FA_050)；踝扭傷二度用**彈性繃帶 8 字形**(105-2_FA_046)；鎖骨骨折用**八字繃帶**(110-2_MS_077)
- 膝上截肢殘肢：**回反摺形包紮，再以環形定帶（收尾）**(114-1_FA_028)；膝下截肢包彈性繃帶前先**清潔傷口換無菌敷料**(105-1_FA_049)
- 懸臂帶：**手腕高於手肘 10–12 cm**（113-2_FA_027、106-1_FA_048）；肘彎**小於 90 度**、手腕高於肘(113-1_FA_030)；「左拇指朝下」「肘彎小於 60 度」錯(105-1_FA_046)；支托石膏手臂**腕關節微高於肘關節**(105-1_FA_046)；「肘關節 > 90 度」「手掌心朝外」「底邊朝向患側」都錯

## 繃帶的種類 {#types}

### 捲軸繃帶的材質 {#materials}

| 材質 | 特點 | 用在 |
|---|---|---|
| **彈性繃帶** | 服貼、能**加壓支撐**；太緊會影響血循；自黏彈性繃帶不黏皮膚、不需繃帶扣 | **截肢殘肢**、固定關節敷料、**扭傷加壓**並抬高、**股骨骨折術後下肢**（促進靜脈回流） |
| **紗布繃帶** | 透氣、輕軟、防浸潤；無伸縮性 | **固定傷口敷料**、包紮手指手臂等細的部位；最常用；約束手腕時先墊棉墊 |
| 棉布繃帶 | 厚密、可重複用、不透氣 | 支托、限制活動、**固定夾板** |
| 法蘭絨繃帶 | 厚軟、**保暖** | 風濕或痛風的關節 |
| 石膏繃帶 | 固定後不鬆、不透氣 | 骨折與矯正畸形，不當一般繃帶用 |

- 窄的用在手、小腿等細的部位；寬的用在大腿、軀幹
- **套入式繃帶**：管狀、伸縮好、不需別針，用於**顏面、頭顱、關節**等不易用捲軸的部位；彈性網狀繃帶固定敷料；用過一次彈性變差
- 來源：實用基本護理學下冊 p.437–440、表 16-2

### 三角巾與束帶 {#triangle-binders}

1. 三角巾：3 呎正方布對角裁成兩條；可做**懸臂帶**支撐上石膏的手臂、包頭部手足敷料，也可摺成**褶帶繃帶**
2. 束帶：支撐較大部位（胸、腹、乳房）或固定特殊部位敷料
   1. **單丁字帶**：固定**女性**會陰部敷料；**雙丁字帶**：固定**男性**生殖器敷料
   2. **四頭帶**：固定頭後部、前額、下頷、鼻部等突出部位的敷料
   3. **多頭帶**：固定大範圍胸腹敷料或支托腹部；**排氣、引流、排惡露由上往下包**，**支托孕婦腹部或固定術後傷口由下往上包**；包好注意是否太緊造成呼吸困難
   4. **束腹帶**：腹部手術、剖腹產後支托腹部、減輕傷口痛
- 來源：同書 p.441–442、技術 16-3 p.462–466

## 包紮的原則 {#principles}

### 評估：末梢血循與皮膚 {#assessment}

| 項目 | 正常 |
|---|---|
| 顏色(color) | 紅潤，無蒼白發紺 |
| 溫度(temperature) | 溫暖 |
| 活動(motion) | 手指腳趾能自由活動 |
| 感覺(sensation) | 有感覺，無緊繃、麻木、刺痛 |
| 水腫 | 無凹陷性水腫 |
| 脈搏 | 兩側末梢脈搏強度相同 |
| **蒼白試驗**(blanching test) | 壓指甲床放開，**3 秒內**恢復紅潤 |

- 皮膚：有無摩擦破損、乾燥脫皮
- 來源：同書 p.442–443

### 包紮前、中、後 {#before-during-after}

| 時機 | 要點 |
|---|---|
| **包紮前** | 選大小適當、乾淨乾燥、無皺摺的繃帶；先觀察膚色作比較；有傷口**先清潔並蓋無菌敷料**；**骨突處、腋下等皺摺處先墊棉墊**；保持功能位置並支托；四肢**先抬高** 15–30 分鐘 |
| **包紮時** | 站在**前方或側方**；**環形定帶 2–3 圈**；**遠心端 → 近心端**；雙手交替持捲；每圈**覆蓋 1/2–2/3**；彈性繃帶壓力會累積，不要拉太緊；**露出末梢**；結帶避開禁忌處 |
| **包紮後** | **抬高患肢 15–30 分鐘**；**20 分鐘後**完整評估血循，正常則**每 2–4 小時**評估；教病人與家屬看血循不良徵象；包紮肢體做**等長運動**，未包紮關節做全關節運動；皮膚護理；**定期更換**繃帶 |

- **不可結帶的位置**：①骨突與**關節**處；②**傷口或發炎**處；③**肢體內側**；④易摩擦與**受壓**處
- 結帶方法：尾端剪開打**平結**、膠布、繃帶扣或安全別針
- 出現**發紺、冰冷、腫脹、刺痛、麻木、脈搏消失** → 太緊，**鬆開重新包紮**
- 病人抱怨彈性繃帶包紮處腫痛 → 先**檢查是否綁太緊**，不是只給止痛或安眠藥
- 來源：同書 p.443–445、技術 16-1

## 各種包紮法 {#techniques}

| 包紮法 | 做法 | 用在 |
|---|---|---|
| **環形** | 同一處重複環繞 | **定帶與結帶**；手指、手腕等細的部位 |
| **急螺旋** | 斜行往上，**每圈之間有空隙** | **固定夾板**（如嬰幼兒點滴夾板） |
| 緩螺旋 | 斜行往上，每圈覆蓋 1/2–2/3 | 粗細一致的部位：手指、前臂 |
| **螺旋回反形** | 繞到上端往下反摺再覆蓋 | **粗細不均**的部位：前臂、大腿、小腿 |
| **8 字形** | 在關節上下交叉呈 8 字 | **固定關節敷料**（肘、膝、腕、**踝**）、**限制關節活動**；腳踝扭傷 |
| **人字形** | 與 8 字形類似，上下交替呈人字 | **拇指**、**肩部**、髖部、**鼠蹊部**、大腿 |
| **回反摺形** | 上端定帶後來回覆蓋末端，最後**再以環形包紮**收尾 | **截肢殘肢**、**末端肢體**（頭頂、手指） |

- 八字繃帶也用來固定**鎖骨骨折**
- 踝關節韌帶二度撕裂要制動兩週 → **彈性繃帶**＋**8 字形**
- 截肢殘肢 → **回反摺形**，最後環形固定；包紮前先清潔傷口、換無菌敷料
- 來源：同書技術 16-1 p.447–454

## 三角巾懸臂帶 {#arm-sling}

1. 支撐傷側前臂，**手腕略高於手肘 10–12 cm**，手腕與手肘成直線、不下垂
2. 肘關節**略向上彎，角度小於 90 度**（不是大於 90 度或自然下垂）
3. **手心朝內、患側拇指朝上**
4. 頂角放在**患側肘彎**；底邊（最長邊）**朝向健側**
5. 內側角放在**健側**肩上；外側角越過患側前臂繞到肩頸旁與內側角打結；肘部頂角反摺固定
6. **露出手指**以觀察血循
- 打結的位置：課本寫外側角繞到**健側肩膀頸旁**打結；國考 113-1_FA_030 以「**右（患）側肩上打平結**」為正確答案；兩者不同，作答依題目選項
- 手的方向：課本是**手心朝內、拇指朝上**；113-1_FA_030 正確選項寫「手掌朝上」，113-2_FA_027「手掌心朝外」是錯的
- 來源：同書技術 16-2 p.455–459

## 傷口的分類與評估 {#wounds}

### 分類 {#wound-classification}

| 依據 | 分類 |
|---|---|
| 癒合時間 | **急性傷口**：突然發生、照護後能自行癒合；**慢性傷口**：超過 **4–6 週**未依預期癒合（壓力性損傷、靜脈性潰瘍） |
| 完整性 | **開放性**：切割傷（邊緣整齊）、撕裂傷（不規則）、刺傷（口小但深，易厭氧菌感染）、穿透傷、擦傷；**封閉性**：挫傷（瘀斑、血腫）、拉傷（肌肉肌腱）、扭傷（韌帶） |
| 感染 | 感染性（紅腫化膿、延遲癒合）；清潔性 |
| 深淺 | **部分皮層**（表皮或部分真皮，可再生、少留疤）；**全皮層**（到皮下甚至肌肉骨骼，以疤痕修復） |
| 顏色 | **紅色**：肉芽健康，保護避免摩擦；**黃色或黃綠**：腐肉或感染，要清潔；**黑色**：壞死結痂，要**清創** |

- 來源：同書第 19 章 p.569–572

### 癒合與評估 {#wound-healing}

1. 癒合三期：**發炎期**（約前 4 天，止血、白血球清除病原、紅腫熱） → **纖維增生期**（約 10 天到 4 週，纖維母細胞與新生血管） → **重塑期**（數月到數年，膠原重排、疤痕變軟變淡）
2. 評估順序：先看**全身**（出血量、生命徵象），穩定後才評估傷口
   1. 主觀：怎麼受傷、何時、環境汙染程度、致傷物、病史
   2. 客觀：**長（頭到腳方向）、寬、深**（無菌棉棒探入）、鐘面方向描述孔道；滲出物、周圍組織
   3. 心理：焦慮、害怕、自責、私密部位的**困窘**、對日常生活的衝擊
3. **感染徵象**：傷口邊緣紅腫發亮、持續有分泌物、熱痛、**受傷 3–7 天後發燒**；淋巴結腫大或紅色條紋表示擴散；可用無菌棉棒做傷口培養
4. 引流液正常變化：**鮮紅血性 → 粉紅 → 透明漿液**，量漸少；變多、變濃濁、黃綠色 → 疑似感染
5. 影響癒合：年齡、營養（**蛋白質、維生素 C、鋅**）、體液電解質、**抽菸**、糖尿病、肝病、惡性腫瘤、壓力、免疫、類固醇
- 細胞層次的修復與一期、二期癒合見 [[inflammation-repair#healing-phases]]

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 |
|---|---|
| 順人體循環方向、由近心端往遠心端包 | 遠心端往近心端（逆循環） |
| 每圈覆蓋 1/4–1/3 | 1/2–2/3 |
| 以緩螺旋定帶 | 環形定帶 |
| 結帶在關節、傷口或肢體內側 | 在粗細均勻處（如上臂外側） |
| 包紮四肢前先放低 | 先抬高 |
| 包紮後麻木刺痛是正常的 | 太緊，鬆開重包 |
| 彈性繃帶是為了促進動脈血循 | 加壓止血、減腫、促進靜脈回流 |
| 夾板用回反摺形固定 | 急螺旋 |
| 殘肢用人字形 | 回反摺形，最後環形固定 |
| 懸臂帶肘關節大於 90 度、手心朝外 | 小於 90 度、手心朝內、腕高於肘 10–12 cm |
| 三角巾底邊朝向患側 | 朝向健側 |
