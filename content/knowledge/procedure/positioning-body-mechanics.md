適當的臥位能讓病人舒適、維持肢體**功能性位置**、預防關節攣縮與壓力性損傷，也是許多檢查與治療的前提。本頁整理**翻身擺位原則**、**五種一般臥位**、**六種檢查臥位**、**支托物**與護理人員**省力又不受傷的身體力學**。各臥位的受壓部位與壓力性損傷預防見 [[pressure-injury#sites]]，長期臥床的全身影響與全關節運動見 [[activity-immobility]]，約束見 [[patient-safety-environment#restraint]]

## 重點摘要 {#summary}

- 擺位原則：**頭、頸、脊椎成一直線**；各關節**微彎**避免肌肉緊張；空隙處用軟枕支托；手握小捲軸防垂腕
- 翻身：長期臥床無禁忌者**至少每 2 小時**；翻身前床頭搖平、移開枕頭、雙手交叉胸前；**把病人翻向自己**；疑脊椎損傷用**圓滾木翻身**；偏癱者盡量不翻向患側
- 搬移病人往床頭：**先把病人稍微抬起**，不直接拖拉 → 減少**剪力**
- 身體力學：**雙腳分開(與肩同寬)加大底面積**、**彎膝降低重心**、背部挺直、**用大肌肉**(腿、肩)不用小肌肉(腰背、手腕)、**靠近病人**、床高約在護理師**腰部**、**滑動或拉動比抬舉省力**
- 仰臥：**膝膕下不墊枕**(壓迫膕動脈與膕靜脈)，改墊小腿使足跟懸空；粗隆捲軸由**腰到膝**放大腿外側防**髖外旋**；足托板**高於腳趾**、踝 **90 度**防垂足
- 俯臥：口鼻分泌物引流、ARDS(acute respiratory distress syndrome，急性呼吸窘迫症候群)、截肢後**預防髖關節攣縮**；不適合顱內壓高、孕婦、胸腹部手術
- 坐臥姿：低坐 15–30 度、半坐 30–45 度、坐臥 45–60 度、高坐 60–90 度；呼吸困難、流鼻血用高坐臥並前傾
- 檢查臥位：**辛氏**(3/4 俯臥：口鼻引流、肛門檢查、灌腸、放鬆背肌)、**膝胸**(矯正胎位、產後子宮復原、子宮後傾經痛)、**屈膝仰臥**(會陰沖洗、導尿)、**垂頭仰臥**(休克、大出血、不可長期)、**截石**(陰道、子宮頸、生產)、**截刀式**(痔瘡手術、**胸部受壓**)

### 國考常考點 {#exam-points}

- 翻身擺位**保持頭、頸與脊椎一直線**(115-1_FA_019)；肢體重疊、凹陷處懸空、抓握肢體都是錯的
- 各種臥姿**關節應微彎曲**(113-3_FA_023)；睡氣墊床仍要翻身；癱瘓者不是只能平躺
- 側臥時**上側的髖與膝比下側彎曲**(113-2_FA_023)；側臥要加強**肩部與髖部**皮膚護理(114-2_FA_019)；臥床病人每 4 小時翻身、膝膕墊枕都是錯的
- 仰臥可用**粗隆捲軸預防髖關節外旋**(111-1_FA_036、113-3_FA_008)；膝膕墊枕、頭頸與脊柱呈 15 度、足托板讓足背伸展都是錯的
- 預防髖外旋的支托物：**砂袋、粗隆捲軸**(112-1_FA_036)；氣墊床與床上護架不是
- 足托板：保持足背屈、足底靠板、踝 90 度；「**底板比腳趾低**」是錯的(112-2_FA_036)
- 床上護架用於燒傷、石膏未乾，避免被蓋接觸患部；**不是用來固定姿勢**(111-2_FA_036)
- 砂袋可加壓止血、固定腕部防垂腕、固定足部防外翻；「預防術後**髖關節屈曲**」是錯的(107-1_FA_029)
- 由床尾往床頭移動先**稍微抬起**：目的是**減少剪力**(107-1_FA_046)
- 身體力學：降低重心＋用大肌肉群(109-2_FA_035)；降低重心＋雙腳分開(106-1_FA_032)；**使用手臂肌肉比手腕肌肉不易疲勞**(112-3_FA_020 說「手臂比手腕易疲勞」是錯的)；床高約在**腰部**(107-1_FA_045)
- 「多用舉高方式移動病人」不適宜(112-1_FA_033)；「重心遠離病人」不適當(115-1_FA_031)；**滑動方式**可預防背部受傷、省力(111-1_FA_003、106-2_makeup_FA_004)
- 截刀式臥姿：**痔瘡切除**(112-2_FA_034)、要注意**胸部受壓**(114-3_FA_019)
- 辛氏臥姿可**放鬆**背部肌肉，「加強背部肌肉張力」是錯的(111-1_FA_035)；昏迷口鼻分泌物多翻身採**辛氏臥姿**(107-2_FA_047)
- 意識不清者口鼻分泌物引流**不適合仰臥**(108-2_FA_039)；**俯臥可預防髖關節攣縮**(114-1_FA_019)
- 長期仰臥未預防：髖關節**外旋**(111-2_FA_046)

## 翻身擺位原則 {#turning}

| 原則 | 做法 | 原理 |
|---|---|---|
| 脊柱對齊 | 頭、頸、脊椎成一直線 | 維持功能性位置，避免頸椎與腰椎受力 |
| 關節微彎 | 各關節保持輕度屈曲，空隙處以軟枕支托 | 避免肌肉過度緊張與攣縮 |
| 手部 | 手中握小捲軸 | 預防腕與手指屈曲攣縮(垂腕) |
| 髖部 | **腰到膝**放粗隆捲軸 | 預防髖關節**外旋** |
| 疑脊椎損傷或脊椎術後 | **圓滾木翻身**(兩人以上同時抓肩與臀的翻身單) | 保持脊椎不扭轉 |
| 翻身前 | 床頭搖平、移開枕頭、雙手交叉胸前、確認管路長度 | 防壓手、防管路滑脫 |
| 翻身方向 | 要翻向右側，護理師先走到病人右側，把病人**翻向自己** | 病人不會從床邊跌落 |
| 移動方式 | 用翻身單抬起再移動，**不拖拉** | 減少**剪力**與摩擦 |
| 頻率 | 無禁忌至少**每 2 小時**；**進食前後避免** | 解除受壓；防嘔吐 |
| 偏癱 | 盡量不翻向患側，無法避免時定時看循環 | 患側感覺差、易受傷 |

## 一般臥位 {#general-positions}

| 臥位 | 擺法 | 適用 | 注意 |
|---|---|---|---|
| **站姿** | 頭頸脊柱一直線、雙腳與肩同寬、膝微彎 | 胸部 X 光、身體評估 | 肌少症者小心跌倒 |
| **仰臥**(supine) | 平躺，頸後、腰下空隙墊枕；粗隆捲軸(腰到膝)；足托板；**小腿下墊軟枕**、膝膕下不墊 | 腹部檢查、手術；腰椎穿刺後與脊髓麻醉後平躺(課本 6–8 小時) | 受壓：枕骨、肩胛、手肘、**薦骨、足跟**；膝膕墊枕壓迫膕血管 |
| **俯臥**(prone) | 頭轉一側；面向側手臂彎曲置頭旁、另一手伸直；小腿下墊小枕 | 口鼻分泌物引流、ARDS 俯臥通氣、脊椎與部分髖部手術、**截肢後防髖攣縮** | 受壓：臉頰、耳、下巴、肩峰、乳房、髂骨嵴、膝、足背；禁忌：顱內壓高、孕婦、胸腹部手術或開放傷口、臉部外傷、血行動力不穩；俯臥前 2 小時不灌食 |
| **側臥**(lateral) | 頭下墊枕、兩膝間夾枕、胸前抱枕；上側髖膝比下側彎曲 | 口鼻分泌物引流、肛門檢查、灌腸與塞劑 | 受壓：耳、肩峰、**大粗隆(髖部)**、膝內外側、踝 |
| **坐臥**(Fowler) | 床頭抬高：低坐 15–30、半坐 30–45、坐臥 45–60、高坐 60–90 度 | 休息最常用；**呼吸困難、心衰竭**；流鼻血(高坐、頭前傾)；**灌食與進食**防吸入；胸腹部引流；顱內壓高(低半坐) | 半坐臥受壓：**肩胛、坐骨結節、薦骨**、足跟；先搖高床尾再搖床頭防下滑 |

1. ARDS 俯臥通氣：課本引研究，PaO₂/FiO₂ < 150 mmHg 者每天俯臥**至少 16 小時**可降低死亡率，詳見 [[ards-respiratory-failure]]
2. 課本提到氣圈、橡膠圈會使壓力集中，不建議使用；改用減壓床墊或氣墊床

## 常見檢查與治療臥位 {#exam-positions}

| 臥位 | 擺法 | 適用 | 受壓與注意 |
|---|---|---|---|
| **辛氏臥姿**(Sims') | **3/4 俯臥**：側趴，胸腹下墊枕、上側腿彎曲在前 | **意識不清口鼻分泌物引流**、肛門檢查、**灌腸**；可**放鬆背部肌肉** | 受壓側臉、耳、肩、髖、膝內側、踝外側 |
| **膝胸臥姿**(knee-chest) | 趴在硬床面，兩膝彎曲靠近胸部，大腿與小腿垂直、與肩同寬，雙手放頭兩側 | **矯正胎位**、產後促子宮復原、**改善子宮後傾的經痛**、腸阻塞灌腸、肛門檢查 | **意識不清者不可用**；受壓臉、耳、肩、膝 |
| **屈膝仰臥**(dorsal recumbent) | 仰臥、屈膝、腳踏床面 | **會陰沖洗、導尿**、肛門與陰部檢查 | 保護隱私 |
| **垂頭仰臥**(Trendelenburg) | 仰臥、**頭低腳高** | **休克、大出血**(增加靜脈回流)、下腹部手術、姿位引流 | **不可長期**；頭下不放枕；長期反而使橫膈受壓 |
| **膀胱截石術臥姿**(lithotomy) | 仰臥、雙腳放腳架、臀部靠檢查臺邊緣 | **會陰、陰道、子宮頸**、前列腺與膀胱檢查、**生產**、陰道灌洗 | 覆蓋毛巾保護隱私 |
| **截刀式臥姿**(jackknife) | 上半身趴在檢查臺、雙腳在地面、臀部最高 | 肛門直腸檢查與手術、**痔瘡切除** | 受壓臉、耳、**胸部**；注意呼吸 |

1. 姿位引流的垂頭姿勢見 [[airway-clearance]]；休克見 [[edema-shock]]
2. 膝胸臥姿與子宮後傾、產後子宮復舊屬產科，產兒輪再補

## 支托物 {#support-devices}

| 支托物 | 用途 | 使用要點 |
|---|---|---|
| **床上桌** | 呼吸困難時伏趴、用餐 | — |
| **足托板** | 預防**垂足**與足部外旋 | 高度**高於腳趾**；**踝 90 度**、足底靠板；看受壓處有無發紅 |
| **床上支架(床上護架)** | 撐起被蓋，**避免被蓋接觸患部** | 燒傷、腫脹部位、**石膏未乾**；不是用來固定姿勢 |
| **砂袋** | 心導管等檢查後**加壓止血**；固定腕部**防垂腕**；固定足部**防垂足、外翻**；放大腿外側防髖外旋 | 不是用來預防髖屈曲 |
| **粗隆捲軸** | 預防**髖關節外旋**(或外展) | 大毛巾捲成長條，**由腰到膝**放大腿外側 |
| 肘與足跟保護器 | 減輕肘、足跟的壓力與摩擦 | 預防足跟潰瘍 |
| 手捲軸 | 預防腕與手指攣縮 | 偏癱、昏迷者 |
| 各式軟枕 | 支托身體空隙 | 小枕放空隙；**不放膝膕下** |

## 身體力學與安全搬移 {#body-mechanics}

| 原則 | 做法 | 原理 |
|---|---|---|
| 加大底面積 | **雙腳分開與肩同寬**、一腳在前 | 底面積越大越穩 |
| 降低重心 | **彎曲膝與髖**代替彎腰 | 重心越低越穩、保護腰椎 |
| 背部挺直 | 保持脊柱自然曲線 | 避免下背痛 |
| 用大肌肉 | 用腿部、臀部與**肩部**的力量，不用腰背、手腕等小肌肉 | 大肌肉較不易疲勞 |
| 靠近病人 | 把病人移近自己、面對移動方向 | 重心垂直線落在底面積內，省力 |
| 床高 | 調到約護理師**腰部**(課本：腰部至髖關節高度) | 不必彎腰 |
| 滑動優先 | 用中單、轉移板以**滑動或拉動**取代抬舉 | 抬舉要對抗重力最費力 |
| 量力而為 | 體重重者找他人或用輔具 | 減少職業傷害 |

1. 搬移前評估意識、呼吸、管路；單人移動時**對側床欄拉起**
2. 協助下床先**坐床緣 1–2 分鐘**，預防姿位性低血壓，見 [[hypotension]]
3. 護理人員下背痛與職業危害見 [[occupational-health-nursing]]

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 膝膕下墊枕避免下滑 | 墊小腿，膝膕下不墊 | 壓迫膕血管、易靜脈栓塞 |
| 足托板比腳趾低 | 比腳趾高、踝 90 度 | 被蓋才不會壓腳趾成垂足 |
| 臥床病人每 4 小時翻身 | 至少每 2 小時 | 壓力 2 小時以上就可能造成缺血 |
| 用小肌肉、縮小底面積 | 用大肌肉、雙腳分開 | 省力穩定 |
| 多用舉高方式移動 | 多用滑動、拉動 | 抬舉要對抗重力 |
| 辛氏臥姿可加強背肌張力 | 可放鬆背肌 | 3/4 俯臥背部不受力 |
| 垂頭仰臥可長期使用 | 短期急救用 | 腹腔器官壓迫橫膈、腦部充血 |
