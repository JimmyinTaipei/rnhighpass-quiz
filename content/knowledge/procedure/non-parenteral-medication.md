注射以外的給藥途徑：**口服**最方便、最安全，也最常用；**舌下、口頰**經口腔黏膜快速吸收；**栓劑**給不能口服或要局部作用的人；**吸入**直接作用在呼吸道；**滴入**用在眼、耳、鼻；**經皮貼片**維持穩定濃度。共通的核對與醫囑原則見 [[medication-administration-principles]]，注射見 [[injections]]

## 重點摘要 {#summary}

- 口服要**看著病人吞下**；病人不在不放床旁桌
- 不給口服：**禁食**、**持續或劇烈嘔吐**、**吞嚥困難**、**昏迷或意識不清**、拒服 → 先不給、通知醫師（護理師不能自己改途徑）
- **咳嗽糖漿最後吃**、吃完 **30 分鐘內不喝水**；**油類藥（蓖麻油）冰過再吃**
- **液態鐵劑**加水稀釋、**用吸管**、喝完**漱口**；配**維生素 C** 吸收較好，不配茶和牛奶
- 嬰兒餵藥：**抱起或半坐臥**，藥從**頰側**慢慢滴；不混在奶裡
- **肛門栓劑**：**左側臥**、張口深呼吸放鬆、推過**內括約肌**、貼直腸壁（**避開糞團**）、塞完**壓住肛門**並**忍 15–30 分鐘**
- **點眼藥**：滴在**下結膜囊**、不碰眼、壓鼻淚管；**先水劑後藥膏**、間隔 5 分鐘
- **滴耳藥**：藥溫接近體溫；**3 歲以下耳朵往下往後拉**，3 歲以上與成人**往上往後拉**

### 國考常考點 {#exam-points}

- 肛門栓劑吸收的部位是**直腸黏膜**
- 給栓劑：**左側臥**（右側臥、屈膝仰臥都錯）；深呼吸放鬆，**不要閉氣**；不可用棉枝推；**摸到糞便要避開**（讓藥貼直腸黏膜），或依醫囑先清除
- 成人塞入深度：國考答案 **約 6.4–7.6 cm（2.5–3 吋）**、「約 7 cm」正確；成人塞到 10 cm、只塞 2 cm 都被判錯
- 塞完**用衛生紙壓住肛門到沒有便意**、保持原姿勢 15 分鐘、**保留 15–30 分鐘**；不要立即下床解便；**栓劑前端可塗潤滑劑**
- 「宜於飯後 1 小時塞入以利用胃結腸反射」是錯的
- 給藥前病人**腹絞痛、冒冷汗**：**立即停止**、看生命徵象（不是請病人忍耐）
- **栓劑放冰箱**保存
- 嘔吐、腹瀉、發燒又意識混亂：**先不給口服藥、立即聯絡醫師**
- 咳嗽糖漿**最後服用**；喝了不馬上喝水
- 油類藥物（蓖麻油）**先冰再吃**；液態鐵劑**要**加水稀釋（說「勿稀釋」是錯的）
- 嬰兒餵藥：用拇指**輕壓下巴**讓嘴張開，藥從**頰側**滴入；**不躺著餵**、不從口腔正中央滴、不快速灌
- 藥粉溶在少量水裡，用餵藥器滴入（對）；每次 5 mL（太多）、壓下巴躺著灌、藥丸放舌尖（錯）
- 小劑量用**空針**量，刻度對準**針心前端黑色橡膠圈上緣**；藥杯讀液面**凹面最低處**
- 口頰溶片(Painkyl)：用前**潤濕口腔兩頰**；貼在頰內側，不是舌下
- 鐵劑：**動物性（血基質）鐵比植物性好吸收**；配維生素 C；液態鐵用吸管、喝完漱口；鐵劑注射後不按摩、觀察過敏

## 口服給藥 {#oral}

1. 優點：方便、便宜、安全，可自己在家吃
2. 缺點：味道差、胃腸刺激、牙齒染色、吸收量較難預估、作用較慢
3. **不適合口服**：**禁食**、**持續或劇烈嘔吐**、**吞嚥困難**、**昏迷或意識不清**、拒服
   1. 處理：**先不給**，評估後**通知醫師**改劑型或途徑
   2. 護理師**不能自行**把口服改成注射
4. 服藥時間
   1. 促進食慾、消化的藥：飯前
   2. 刺激胃的藥：飯後
   3. 見 [[medication-administration-principles#dose-factors]]
5. 配什麼喝
   1. 錠劑、膠囊配溫開水（太燙會讓膠囊或腸衣提早溶）
   2. 軟便劑、抗生素、解熱鎮痛藥、降尿酸藥：多喝水
   3. **咳嗽糖漿**、胃乳：**不配水**，**最後吃**，**30 分鐘內不喝水**（讓藥覆蓋咽喉或胃黏膜）
   4. 兩種以上液劑分開藥杯
6. 特殊藥物
   1. **液態鐵劑、碘劑**：會讓牙齒染色 → **稀釋、用吸管**、吃完**漱口**
   2. **油類藥物**（蓖麻油）：**先冰過**或先含冰塊，減少油膩與異味
   3. **舌下錠**（硝化甘油，NTG, nitroglycerin）：放舌下不吞、不嚼；2–5 分鐘起作用；**坐著含**（怕頭暈跌倒）；沒改善隔 5 分鐘再含，最多 3 顆，見 [[nitrates]]
   4. **口頰溶片**（Painkyl，fentanyl）：先**潤濕兩頰**，貼在頰內側輕壓約 5 秒；溶完前不吃東西，貼上 5 分鐘後可以喝液體（課本）
   5. Mycostatin 口服懸液治口腔念珠菌：含在口中約 5 分鐘再吞
7. **鐵劑**
   1. 空腹吸收最好，但刺激胃 → 可**隨餐**或飯後減少不適（吸收會減少，不是增加）
   2. 配**維生素 C**（柳橙汁）吸收較好；**不配茶、牛奶、制酸劑**
   3. **動物性（血基質）鐵**比植物性好吸收
   4. 糞便會變黑，事先說明
   5. 鐵劑注射見 [[injections#z-track]]
8. 藥物與食物的交互作用見 [[medication-administration-principles#drug-effects]]

### 兒童口服給藥 {#pediatric-oral}

1. 姿勢：**抱起或半坐臥**，不躺著餵（嗆到、吸入）
2. 嬰兒
   1. 藥粉溶在**少量水**，用**餵藥器、滴管或去針頭空針**
   2. 用拇指**輕壓下巴**讓嘴張開，從**頰側**慢慢滴，配合吞嚥
   3. 每次量很少（約 0.5–1 mL），**不從口腔正中央滴**（會嗆、會吐）
   4. **不混在母奶或配方奶裡**（會討厭喝奶，也不知道吃了多少）
3. 幼兒：可加少量糖漿或果醬調味；給選擇（用杯子還是湯匙），不強迫躺下灌
4. 吞藥丸：放在**舌根**較好吞，不放舌尖
5. 量藥
   1. 小於 5 mL 用**空針**；刻度對準**針心前端黑色橡膠圈的上緣**
   2. 藥杯：眼睛平視，讀液面**凹面最低處**
   3. 劑量計算：10 kg × 0.25 mL/kg＝2.5 mL

### 鼻胃管給藥 {#ng-tube-medication}

- 鼻胃管放置、位置確認與灌食見 [[enteral-parenteral-nutrition]]

1. 藥磨粉溶在溫水，或用**液劑、懸浮劑**
2. 給藥前後各用約 20–30 mL 溫開水沖管
3. **不可磨粉**：持續性錠劑、**腸衣錠**、舌下錠、口含錠、軟膠囊、會膨脹的緩瀉劑
4. 不確定時問藥師；鼻胃管位置與灌食技術見 [[enteral-parenteral-nutrition#ng-insertion]]

## 栓劑給藥 {#suppository}

### 肛門栓劑 {#rectal}

| 步驟 | 理由 |
|---|---|
| 1. **給藥前評估**：腹部、腸蠕動、最近排便；有原因不明的腹痛、腸阻塞時不給 | 避免掩蓋急腹症 |
| 2. 解釋、拉圍簾；**左側臥**、上腳彎曲（Sims 姿勢） | 順著直腸與乙狀結腸往左的走向 |
| 3. 戴手套，栓劑前端塗**潤滑劑** | 減少摩擦 |
| 4. 請病人**張口深呼吸或哈氣**放鬆，**不要閉氣** | 閉氣會使腹壓上升、括約肌收縮 |
| 5. 用食指把栓劑推過**肛門內括約肌**，**貼著直腸壁** | 推不夠深會被擠出；貼黏膜才吸收 |
| 6. **摸到糞團要避開**，讓藥接觸直腸黏膜（必要時依醫囑先小量灌腸清除） | 塞進糞便裡無效 |
| 7. 塞完用衛生紙**壓住肛門**數分鐘，到便意消失 | 防止滑出 |
| 8. 保持**左側臥約 15 分鐘**；軟便栓劑盡量**忍 15–30 分鐘**再解 | 等藥融化吸收、發揮作用 |
| 9. 過程中**腹絞痛、冒冷汗、頭暈** → **立即停止**、量生命徵象、通知醫師 | 可能是迷走神經反應或急腹症 |

1. 吸收：靠**直腸黏膜**微血管，可部分避開肝臟首渡效應；比口服快
2. 深度
   1. 國考答案：成人約 **6.4–7.6 cm（2.5–3 吋）**、「約 7 cm」為正確敘述
   2. 課本概念圖寫「約 2–4 公分」（引 Lowry 2016），與國考答案不同；**考試以國考答案為準**
   3. 原則：推過內括約肌就好，太深會不舒服
3. 軟便栓劑（Bisacodyl，Dulcolax）的時間
   1. 課本：**飯前約 30 分鐘**塞，配合飯後的胃結腸反射
   2. 國考判錯：「飯後 1 小時塞入」
4. 不可用棉枝推、不可在給藥前閉氣
5. **保存在冰箱**（會遇熱融化）；乳膏型不用冰
6. 醫囑「Dulcolax 2# Supp q4h prn」＝栓劑 2 顆、需要時隔 4 小時給一次

### 陰道栓劑 {#vaginal}

1. 用途：陰道感染（念珠菌）、萎縮性陰道炎的荷爾蒙乳膏
2. 姿勢：**屈膝仰臥**
3. 戴手套推入陰道約 5 cm（課本概念圖）；乳膏用塗藥管
4. 給藥後**平躺約 15 分鐘**；睡前給藥較不會流出，可墊護墊

## 吸入法 {#inhalation}

1. 經呼吸道黏膜吸收，作用快（僅次於靜脈），適合氣喘急性發作
2. 乾吸入：定量吸入器(MDI, metered-dose inhaler)、乾粉吸入器、笑氣麻醉；步驟見 [[asthma-drugs#mdi-steps]]
3. 濕吸入：**蒸氣吸入、噴霧治療**
   1. 床頭抬高 30–45 度或坐著，**慢而深**地吸
   2. **飯前 1 小時或飯後 2 小時**做，避免噁心嘔吐
   3. 噴霧後接**姿位引流與叩擊**，排痰效果最好
   4. 手持噴霧器**每次用完洗淨晾乾**；長期噴霧瓶的無菌蒸餾水**每天換**
   5. 詳見 [[airway-clearance#aerosol]]

## 滴入法 {#instillation}

1. 開封後的眼藥水、滴劑**最多用 1 個月**
2. 懸浮液使用前搖勻

### 眼 {#eye}

| 步驟 | 理由 |
|---|---|
| 1. 洗手；眼睛有分泌物先由**內眥往外眥**擦乾淨 | 不把髒東西帶進淚管 |
| 2. 頭稍後仰、眼睛往上看 | 減少眨眼、避開角膜 |
| 3. 把**下眼瞼往下拉成囊袋**，滴在**下結膜囊**（下穹窿） | **不滴在角膜上**（刺激、受損） |
| 4. 瓶口**不碰眼睛和睫毛**；眼藥是**外科無菌** | 避免污染整瓶 |
| 5. 滴完輕閉眼（不用力擠），**輕壓內眥鼻淚管 1–2 分鐘** | 減少藥流進鼻咽、被全身吸收 |
| 6. 兩種以上：**間隔 5 分鐘**；**先水劑（懸浮液）、後藥膏** | 藥膏油性會擋住後面的水劑 |
| 7. 藥膏擠成一條，從**內眥往外眥**擠在下結膜囊 | — |
| 8. 眼睛感染時一眼一瓶 | 避免交互感染 |

### 耳 {#ear}

1. 藥瓶先握在掌心**回溫到接近體溫**（太冷會頭暈、噁心）
2. **患側朝上**側臥
3. 拉直耳道
   1. **3 歲以下**：耳廓**往下往後**拉
   2. **3 歲以上與成人**：耳廓**往上往後**拉
4. 沿耳道壁滴入，不直接滴向鼓膜；輕壓耳屏
5. 保持姿勢 **5–10 分鐘**；兩耳都要點時，隔約 10 分鐘再換邊

### 鼻 {#nose}

1. 清潔技術；先擤鼻涕
2. **頭往後仰**，滴管不碰鼻黏膜
3. 滴完保持仰臥約 **10 分鐘**

## 經皮給藥 {#transdermal}

1. 藥物從貼片經皮膚**緩慢持續吸收**，血中濃度穩定
2. **Fentanyl 貼片**(Durogesic)
   1. 貼在**平坦、毛少、乾淨乾燥**的皮膚（胸、背、上臂）
   2. 用**掌心壓緊約 30 秒**
   3. 約 **72 小時**換一次，**換位置貼**
   4. **不泡熱水澡、不熱敷、不用電毯**（熱會加快吸收 → 過量）
   5. 出現**呼吸抑制**：撕下貼片、就醫；見 [[opioids#fentanyl-patch]]
3. 硝化甘油貼片、荷爾蒙貼片：每天固定時間更換、換部位
4. 副作用：皮膚過敏、噁心、便秘、嗜睡

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 病人一直吐，等吐完再吃藥 | 先不給，通知醫師 | 吸收不確定、嗆入風險 |
| 咳嗽糖漿配溫水喝 | 最後吃、30 分鐘內不喝水 | 沖掉咽喉黏膜上的藥 |
| 鐵劑原液直接喝 | 稀釋、吸管、漱口 | 牙齒染色、刺激 |
| 栓劑時請病人閉氣用力 | 張口深呼吸放鬆 | 閉氣使括約肌收縮、腹壓上升 |
| 栓劑塞進糞便裡 | 避開糞團貼直腸壁 | 藥無法吸收 |
| 塞完馬上去廁所 | 壓住肛門、忍 15–30 分鐘 | 藥還沒作用 |
| 眼藥直接滴在黑眼珠 | 滴在下結膜囊 | 刺激角膜、眨眼流失 |
| 先點藥膏再點眼藥水 | 先水後膏，隔 5 分鐘 | 藥膏阻擋水劑吸收 |
| 2 歲小孩點耳藥往上往後拉 | 3 歲以下往下往後 | 嬰幼兒耳道較直、朝上 |
