冷熱療法利用**能量的轉移**改變局部或全身的溫度，以止血、止痛、消腫、退燒或促進循環與癒合。效果與危險都取決於**溫度、時間、面積、乾或濕**與病人本身。本頁整理**生理效應**、**交感性反應與反彈現象**、**影響因素**、**適應症與禁忌症**、**各種用冷用熱方式的溫度與時間**，以及**燙傷與凍傷的預防**。發燒與體溫調節見 [[body-temperature]]，燒燙傷的深度與熱傷害見 [[environmental-injury#heat-injury]]，疼痛的非藥物處置見 [[pain-management#non-pharmacologic]]

## 重點摘要 {#summary}

- **用冷**：血管收縮、微血管通透性下降、**血液黏稠度增加**（助凝血）、代謝與白血球活性降低、**神經傳導變慢**（止痛）、心臟負擔減少 → **止血、止痛、消腫、使炎症局部化、退燒**
- **用熱**：血管擴張、**通透性增加**、**黏稠度降低**、代謝與耗氧增加、淋巴與白血球活動增加、**肌肉放鬆**、組織含氧增加 → **促進循環、減輕充血腫脹、加速炎症與化膿、止痛、保暖**；心臟負擔增加
- 冷熱共同作用：**減輕充血與腫脹**、止痛
- **交感性反應**：右手熱敷，左手血管也擴張；前額或頸後冰敷可使**鼻黏膜**血管收縮（鼻出血冰敷前額）
- **反彈現象**：熱超過約 30–45 分鐘血管反而收縮；冷低於 15 ℃ 超過約 1 小時血管反而擴張（皮膚發紅） → **冷熱以 20–30 分鐘為限**、重複使用**間隔 30–60 分鐘**；使用中**每 5 分鐘**檢查
- 能量轉移：**傳導**（冰枕、熱水袋、拭浴、坐浴）、**對流**（電扇、空調）、**輻射**（烤燈、紅外線、日光；脫掉過厚衣物）、**蒸發**（拭浴、出汗）
- 濕比乾**效果好但更危險**（水的傳導與滲透力比空氣好）；乾熱溫度需**比濕熱高**；**乾的不會浸潤皮膚**、溫度維持較久；濕的較易體液流失與燙傷
- 溫度：熱水袋與電熱墊成人 **46.1–51.7 ℃**、**老人幼兒、循環障礙、意識不清 40.5–46.1 ℃**（約低 5 ℃）；濕熱敷與溫水浸泡 **40.5–43 ℃**；溫水坐浴清潔 37.8–40.5、促進循環 40.5–46.1 ℃；**溫水拭浴 27–37 ℃**；冰枕與濕冷敷約 **15 ℃**
- **扭傷**：**24–48 小時內冷敷**（止血消腫），**之後熱敷**（促進吸收）
- 用冷或用熱**都需要醫囑**

### 國考常考點 {#exam-points}

- 熱的效應：**降低血液黏稠度**(114-3_FA_013)；**增加微血管通透性**利修復（115-1_FA_014，扭傷 3 天後熱敷）；血管擴張、增加組織氧量、減輕疼痛(108-1_FA_026)；減緩充血腫脹、增加淋巴流動與白血球(109-2_FA_028)
- 冷的效應：減輕腫脹、降低代謝、減輕疼痛(110-1_FA_023)；冰敷前額止鼻血是**收縮淺層血管使血流變慢**(110-2_FA_031)；冰敷位置是**前額**(106-2_FA_026)
- 冷熱共同作用：**減緩充血和腫脹**(107-2_FA_024)
- 熱敷超過 45 分鐘血管收縮＝**反彈現象**(113-1_FA_014)；冷敷 30 分鐘後皮膚發紅＝反彈現象(111-1_FA_028)；零下 5 ℃ 賞雪 1 小時臉紅＝反彈現象(109-2_FA_026)；右手熱敷左手也擴張＝**交感性反應**(106-2_FA_022)
- 泡溫泉頭暈：**血管擴張、頭部血流減少**(106-1_FA_023)
- 輻射：**紅外線、烤燈**(112-2_FA_026)；發燒時**移除過厚衣物被蓋**依輻射原理（105-1_FA_040；課本表 11-1 把它放在傳導，作答依國考）；溫水拭浴＝**蒸發＋傳導**(110-1_FA_030)
- 反射區：胸前區對心臟；**胸後區對肺不是心臟**(109-2_FA_025)
- 濕的傳導與滲透比空氣好，**濕冷熱效果好但危險也較高**(108-1_FA_029)；「濕熱溫度比乾熱高」是錯的(107-2_FA_023)；乾冷乾熱**不會造成皮膚浸潤**(106-2_FA_025)；乾的不受蒸發影響、濕的穿透力佳(105-1_FA_030)
- 耐受性：**面積越大耐受力越低**(114-3_FA_014)；**手掌比頸部耐受力高**（106-1_FA_027 說手掌較低是錯的）
- 時間：冰敷每次 **20–30 分鐘**(107-1_FA_024)；重複使用**間隔 30–60 分鐘**(112-2_FA_027)；冷敷時有涼感可繼續，麻木、藍斑、疼痛要停(113-1_FA_017)
- 用冷：冰袋冰枕**不直接接觸皮膚**、**冰領用於甲狀腺術後**(114-1_FA_018)；冰枕**要排出空氣**、使用後**每 5 分鐘**看皮膚，冰枕加水不是為了延長時間、使用要有醫囑(106-2_makeup_FA_023)；低溫毯墊絨布是保護皮膚不是增加傳導(111-1_FA_027)；低溫毯開始每 5 分鐘、穩定後每 15 分鐘量生命徵象，**每 30–60 分鐘翻身**；直接接觸皮膚與發抖照用都是錯的(113-1_FA_016)
- 溫水拭浴：水溫 **27–37 ℃**(111-2_FA_028)；**輕拍**、**腋下手心腹股溝多停留數秒**（112-2_FA_028、106-2_makeup_FA_029）；**頭冰枕、足熱水袋**（頭放熱水袋是錯的）
- 熱水袋：一般 **50 ℃**(105-2_FA_002)；**意識不清者 40.5–46.1 ℃**(109-2_FA_008)；90 歲瘦弱老人乾熱**比成人低 5 ℃**(107-1_FA_023)；熱水袋**不能**安全用於老人與嬰幼兒(110-1_FA_025)；熱水袋熱敷膀胱誘尿**需醫囑**(110-2_FA_005)
- 電熱墊：皮膚**擦乾**、**不放身體下**(108-1_FA_028)；**不可用安全別針固定**(115-2_FA_014)
- 烤燈：25 W 距離 **14–18 吋**(114-2_FA_006)；每次 **15–20 分鐘**(111-1_FA_026)；嬰兒紅臀用**烤燈**(105-2_FA_027)；烤燈距嬰兒臀部 25–30 cm 太近(105-1_OP_028)
- 濕熱敷溫度 50.5–63 ℃ 是錯的（應 40.5–43 ℃）(113-3_FA_018)；濕熱法：**溫水坐浴、石蠟浴、溫水浸泡**(108-2_FA_003)
- 坐浴：產後痔瘡**水溫 50 ℃ 錯**(108-1_FA_022)；坐浴時頭暈要停止、躺下，「保持足部低於心臟」錯(106-2_FA_028)；**解尿疼痛**不是坐浴適應症(115-2_FA_020)；便秘痔瘡凸出疼痛用**溫水坐浴**(110-2_FA_033)
- 適合熱敷：**慢性下背痛**（115-2_FA_015、107-1_FA_020）、**3 天前扭傷**(110-1_FA_029)；不明腹痛、持續出血、牙齦發炎不適合
- 扭傷：**1–2 天內冷敷、之後熱敷**、冷敷止痛是降低神經傳導(105-1_FA_029)；**48 小時後熱敷促進循環**（114-2_FA_016、106-2_FA_027）；**挫傷立即熱敷是錯的**(106-2_MS_018)
- 熱水袋不能用來減緩懷孕宮縮(111-2_FA_026)
- 冷療局部傷害：麻木、僵硬、疼痛；**出汗不是**(112-1_FA_021)；冷的全身合併症：心跳停止、體液失衡、水腫；**皮膚發紅疼痛不是**(106-2_makeup_FA_028)；熱的全身症狀不是心跳停止(113-2_FA_014)
- 不適合局部冷療：**開放性傷口**(105-2_FA_024)；所有冷熱設備直接接觸皮膚是錯的（113-1_FA_015、108-2_FA_006）；嬰幼兒與老人要特別小心

## 生理機轉 {#mechanisms}

### 能量的轉移 {#energy-transfer}

| 方式 | 原理 | 例子 |
|---|---|---|
| **傳導** | 直接接觸，熱由高溫傳到低溫 | 冰枕、熱水袋、電熱墊、冷熱敷、溫水拭浴、坐浴、泡溫泉、睡涼蓆 |
| **對流** | 靠流動的空氣或液體帶走熱 | 電扇、空調、開窗通風 |
| **輻射** | 電磁波傳熱、不需接觸；人體約 70% 的熱由皮膚輻射散失 | 日光、**烤燈、紅外線燈**、電暖器；**移除過厚衣物被蓋**（國考歸輻射） |
| **蒸發** | 液體變成氣體帶走熱 | 出汗、呼吸、**溫水拭浴、酒精拭浴** |
| 轉換 | 電能或聲波轉成熱 | 超音波熱療、電暖器 |

1. 溫水拭浴同時用**傳導**（溫水接觸皮膚）與**蒸發**（水分揮發）
2. 揮發快的溶液（酒精）比清水作用快

### 溫度接受器與神經傳導 {#receptors}

1. **冷接受器**在真皮上層、數量約是熱接受器的 8–10 倍 → **皮膚對冷較敏感**
2. **熱接受器**在真皮下層、靠近疼痛接受器 → 深層受熱容易痛、燙傷
3. 皮膚可忍受約 **15–45 ℃**，超過就刺激疼痛接受器
4. **溫度接受器的適應**：接觸幾秒後感覺變淡 → 病人覺得「不燙了」不代表安全，不能讓病人自己調高溫度
5. 溫度訊息經外側脊髓視丘徑到**下視丘**；極冷極熱時經**脊髓反射**立刻縮手

### 局部（原發性）反應 {#local-effects}

| 項目 | 用熱 | 用冷 |
|---|---|---|
| 代謝 | 基礎代謝率、酵素活性、耗氧**增加** | **降低**（延緩細胞死亡） |
| 血管 | **擴張**，血流與營養、氧氣、白血球增加 | **收縮**，血流減少 |
| 微血管通透性 | **增加** | **降低** |
| 血液黏稠度 | **降低**（凝血變差） | **增加**（有助凝血） |
| 血壓與心臟 | 舒張壓下降；心臟負擔增加 | 血壓上升；心臟負擔減少 |
| 淋巴與白血球 | 流動與活動增加 → **加速炎症、化膿** | 減少 → **減緩炎症、使炎症局部化** |
| 皮膚 | 出汗、發紅 | 汗腺分泌減少、淡灰藍色、雞皮疙瘩 |
| 肌肉 | 結締組織伸展性增加、**骨骼肌放鬆**、減輕痙攣、增加關節活動 | 伸展性減少、顫抖 |
| 神經 | 傳導加快、鎮靜感覺神經（止痛） | **傳導變慢**、麻痺痛覺接受器（局部麻醉） |
| 體溫 | 上升 | 下降 |

### 繼發性反應：交感性反應與反彈現象 {#secondary-effects}

1. **交感性反應**(consensual response)：冷熱用在一處，**其他部位也出現同樣的血管反應**，但較弱、較短；例如右手熱敷時左手血管也擴張
2. 局部冷熱的**反射區**（課本表 11-3）

| 用冷熱的部位 | 影響的器官 |
|---|---|
| 頭、頸、臉、手、足 | 腦 |
| **頸後、前額** | **鼻黏膜**（鼻出血冰敷前額或頸後） |
| 頸 | 咽、喉 |
| **胸前區** | **心臟** |
| 胸前、**胸後** | **肺** |
| 前胸右下、左下 | 肝、脾 |
| 上腹部、腹部 | 胃、腸 |
| 後腰部 | 腎 |
| 後腰到薦骨、下腹部、腹股溝、大腿內側 | 骨盆腔器官 |

3. **反彈現象**(rebound phenomenon)：超過最大效果的時間後出現**相反反應**
   1. 熱：約 20–30 分鐘血管擴張到最大；**超過 30–45 分鐘**反而充血、血管收縮 → 散熱差、燙傷
   2. 冷：皮膚約 15 ℃ 時收縮最大；**低於 15 ℃ 超過 1 小時**反而擴張 → 皮膚發紅
   3. 所以冷熱治療**以 20–30 分鐘為限**
4. 全身反應
   1. 大範圍用熱（泡溫泉、熱水浴）：周邊血管擴張、**頭部與深部器官血流減少** → 頭暈、昏厥；心衰竭與動脈硬化者更危險
   2. 大範圍用冷：血液移向深部器官，保護核心體溫

## 影響冷熱效用的因素 {#factors}

| 因素 | 說明 |
|---|---|
| **乾或濕** | 水的傳導與滲透力比空氣好 → **濕的效果較好也較危險**；要達同樣效果，**乾熱溫度要比濕熱高**、乾冷要比濕冷低 |
| 溫度 | 乾熱成人 46.1–51.7 ℃，**幼兒、老人、循環障礙、譫妄或意識不清 40.5–46.1 ℃（低約 5 ℃）**；濕熱以 46 ℃ 為限 |
| 部位 | **手掌、腳底皮膚厚、耐受力高**、效果差；**頸、手腕內側、前臂內側、會陰皮膚薄、敏感**、效果好；血液循環好的部位效果好；深層對熱比冷敏感 |
| 時間 | 越久耐受力越高、敏感度越低 → 容易不知不覺受傷 |
| **面積** | **面積越大效果越明顯，但耐受力越低、危險越大** |
| 個別差異 | **嬰幼兒**（調節中樞未成熟）、**老人**（感覺遲鈍、血管硬化）較危險；女性較敏感；**感覺障礙、意識不清、循環障礙（糖尿病、周邊血管病）**、瘦者、水腫、體內有金屬 |

| | 濕冷熱 | 乾冷熱 |
|---|---|---|
| 優點 | 減少乾燥、軟化滲出物；較舒服；**穿透力佳** | **不會浸潤皮膚**；**不受蒸發影響、溫度維持久**；不會無感性失水 |
| 缺點 | 久用**皮膚浸潤**；**蒸發快、容易變冷**；傳導快**易凍傷、燙傷**；體液流失 | 穿透力差；皮膚乾燥 |

## 適應症與禁忌症 {#indications}

### 用冷 {#cold-indications}

| 目的 | 機轉 | 適應症 |
|---|---|---|
| 降溫 | 冰枕使腦溫下降約 0.9 ℃ | 發燒 |
| **止血** | 淺層血管收縮、血流慢、黏稠度增加 | **扁桃腺切除、鼻出血**、皮下出血（24 小時內） |
| **止痛** | 神經傳導變慢、提高疼痛閾值（約 5–12 分鐘起效） | 急性外傷 |
| **消腫** | 通透性降低 | **扭傷 24–48 小時內**、拉傷、骨折 |
| 使炎症局部化 | 血流與白血球活性降低 | **靜脈炎**、牙髓炎 |
| 抑制代謝 | 低溫療法延緩細胞死亡 | 心臟或腦部手術、心跳停止後 |
| 降低破壞酶活性 | — | 類風濕性關節炎**急性發作期** |

用冷的禁忌：**開放性傷口**、循環障礙（雷諾氏病）、貧血、休克、局部缺血、**頭部外傷或手術**、胃部不適、類風濕性關節炎**緩解期**、對冷過敏、**哺乳婦女脹奶**（抑制乳汁）、意識不清與感覺障礙

### 用熱 {#heat-indications}

| 目的 | 適應症 |
|---|---|
| 保暖升溫 | 早產兒、休克或虛弱者、寒顫 |
| **減輕充血腫脹** | **扭傷 24–48 小時後** |
| **止痛、肌肉放鬆** | **下背痛**、關節僵硬、攣縮、經痛 |
| 加速炎症與化膿 | 炎症晚期 |
| 促進傷口癒合 | 傷口恢復期 |
| 促進舒適與排泄 | 睡前熱飲、誘尿 |

用熱的禁忌：**受傷 24–48 小時內**、**非炎症性水腫**、**持續出血**與出血性疾病、循環障礙（心衰竭、糖尿病、周邊血管病）、**頭部**、**急性炎症**（牙齒、耳朵）、**不明原因腹痛**（闌尾炎會破裂）、睪丸、**局部惡性腫瘤**、體內**金屬**（節律器、人工關節）、皮膚病與發紅水泡、**孕婦腹部**、意識不清與感覺障礙

### 扭傷與軟組織損傷 {#sprain}

1. 急性期（**24–48 小時內**）：**冰敷**每次 20–30 分鐘、休息、彈性繃帶加壓、抬高（PRICE：protection 保護、rest 休息、ice 冰敷、compression 加壓、elevation 抬高）；X 光先排除骨折
2. **48 小時後**、出血腫脹停止：**熱敷**促進循環、吸收瘀血與滲液
3. 挫傷不可立即熱敷；也不要整天泡冷水
4. 冷敷止痛是降低神經傳導；熱敷止痛是肌肉放鬆、促進循環

## 用冷的方式 {#cold-methods}

| 方式 | 溫度 | 時間 | 重點 |
|---|---|---|---|
| **冰枕** | 約 15 ℃ | 20–30 分鐘，重複間隔 30–60 分鐘 | 裝 1/2–2/3 碎冰並**加少許水讓冰塊銳角融化**（不是延長時間）；**排出空氣**再夾緊（空氣會加速融化、妨礙傳導）；倒提檢查漏水；**毛巾包裹不直接接觸皮膚**；退燒用時 **30 分鐘後量體溫** |
| **冰領** | 同冰枕 | 同上 | 細長適合頸部：**甲狀腺、扁桃腺術後**止血止痛消腫 |
| 冰寶（凝膠冰袋） | 冷凍 | — | 用布包裹，不直接接觸皮膚 |
| **低溫毯** | 依控制器 | — | 心臟、腦部手術降代謝；**不直接接觸皮膚**：薄塗乳液或礦物油增加傳導、**墊棉毯保護皮膚並使冷均勻**；生命徵象開始**每 5 分鐘**、穩定後**每 15 分鐘**；**每 30–60 分鐘翻身**；**避免發抖**（發抖會產熱、升溫）；有電器或金屬植入物禁用 |
| **溫水拭浴** | **27–37 ℃**（約 32 ℃） | **25–30 分鐘** | 用於 **39 ℃ 以上**；**足部熱水袋、頭部冰枕**（防寒顫、防腦充血）；**輕拍**不摩擦（摩擦會產熱）；**腋下、肘彎、手心、腹股溝、膝窩多停留數秒**；**頭、臉、前胸不擦**；寒顫就停止並保暖；**30 分鐘後量體溫** |
| 酒精拭浴 | 30–35% 酒精 | — | 降溫快但刺激、乾燥、噁心，**臨床少用**；老人、小孩、循環障礙不宜 |
| **濕冷敷** | 約 15 ℃ 冰水 | 約 20 分鐘 | 止血、消腫、止痛；有傷口用無菌技術 |
| 冰敷 | 布包冰塊 | 20–30 分鐘 | **扭傷 24–48 小時內** |
| 冷水浸泡 | — | — | 適合四肢大範圍；注意保暖防寒顫 |

1. 發燒時課本引國健署：適度發燒可提升免疫力，41 ℃ 以下不會直接傷害腦；**補充水分最優先**，冰枕與拭浴主要是**促進舒適**，見 [[body-temperature#fever-care]]
2. 幼兒發燒常以**溫水泡澡**取代拭浴

## 用熱的方式 {#heat-methods}

| 方式 | 溫度 | 時間 | 重點 |
|---|---|---|---|
| **熱水袋**（乾熱） | 成人 **46.1–51.7 ℃**；**老幼、循環障礙、意識不清 40.5–46.1 ℃** | 20–30 分鐘 | 排出空氣、檢查漏水、**套布套**不直接接觸；老人與嬰幼兒**不是可以放心使用** |
| **電熱墊**（乾熱） | 中溫 46.1–51.7 ℃，不用高溫 | 20–30 分鐘 | **皮膚擦乾**、套絨布套防電擊；**不壓在身體下**（散熱差）；**不用安全別針**（損壞電線、電擊）；與濕敷併用要隔防水物 |
| **烤燈、紅外線**（乾熱，**輻射**） | 依瓦數調距離：**25 W 14–18 吋(35–45 cm)**、40 W 18–24 吋、**60 W 24–30 吋** | **15–20 分鐘** | 嬰兒**紅臀**、會陰傷口、植皮供皮區；先清潔擦乾；不觸摸燈泡、不蓋布；**每 5 分鐘**看皮膚 |
| 熱敷墊(Aqua K pad) | 約 40.5 ℃ | 10–15 分鐘（無合併症可 20–30） | 管路勿扭結、套絨布套 |
| **濕熱敷** | **40.5–43 ℃** | 20–30 分鐘 | 常換敷布維持溫度；可先塗**凡士林**防燙傷；傷口與眼部用無菌技術 |
| **溫水浸泡** | 40.5–43 ℃ | 10–30 分鐘 | 糖尿病足潰瘍、燒傷擴創；加熱水前**先移出肢體**並攪勻 |
| **溫水坐浴** | 清潔 **37.8–40.5 ℃**；促進循環 **40.5–46.1 ℃** | **20–25 分鐘** | 會陰與肛門手術、**痔瘡**、產後會陰傷口、會陰發炎、經痛、**尿滯留**；臀部完全浸入；頭暈或虛弱就停止並協助平躺；**不明原因腹痛禁用** |
| 石蠟浴 | 溶化後冷到約 51.7 ℃ 使用 | 20–30 分鐘 | 慢性**類風濕性關節炎**、全身硬化症的手腳僵痛 |

1. 濕熱法：**濕熱敷、溫水浸泡、溫水坐浴、石蠟浴**；乾熱法：熱水袋、電熱墊、烤燈
2. 坐浴溶液：溫水；10–50% 硫酸鎂（痔瘡、收斂）；1：4,000 高錳酸鉀；1：100 優碘（會陰傷口）
3. 嬰兒紅臀：勤換尿布、清水清洗、氧化鋅、**烤燈保持距離**，見 [[hygiene-comfort-care]]
4. 坐浴與會陰護理在產後的應用留產兒輪

## 注意事項 {#precautions}

| 階段 | 做法 | 原理 |
|---|---|---|
| 使用前 | **確認醫囑**（用冷用熱都要）；說明目的、溫度、時間、正常感覺與該通知的症狀；評估皮膚、循環、感覺、意識 | 避免傷害 |
| 時間 | 依醫囑；**無醫囑以 20 分鐘為限**；重複使用**休息 30–60 分鐘** | 防反彈與傷害 |
| 觀察 | **每 5 分鐘**看設備與皮膚 | 溫度接受器會適應，病人自覺不可靠 |
| 用熱 | 觀察發紅、疼痛、水泡；**病人不可自行調高溫度** | 防燙傷 |
| 用冷 | 降溫時**輕拍不摩擦**；其他部位保暖 | 防產熱與寒顫 |
| 用後 | 擦乾皮膚、避免吹風 | 防著涼 |
| 無菌 | 傷口與眼部用無菌技術 | 防感染 |

## 合併症：燙傷與凍傷 {#complications}

| | 用冷 | 用熱 |
|---|---|---|
| 局部 | **蒼白、藍色斑點、僵硬、麻木**、疼痛、水泡 → **凍傷** | **發紅、敏感、疼痛、水泡** → **燙傷**；通透性增加使水腫加重 |
| 全身 | **心跳停止、體液失衡、水腫** | 頭暈、昏厥（大範圍用熱） |

1. 冷敷時只有「涼的感覺」可以繼續；出現**麻木、藍斑、疼痛、僵硬**就停止
2. 高危險群：嬰幼兒、老人、糖尿病與周邊血管病、感覺或意識障礙、瘦者 → 溫度降低、時間縮短、更常觀察
3. 燒燙傷的深度分類見 [[environmental-injury#burn-depth]]；病房的燙傷預防見 [[patient-safety-environment#injury-types]]
4. 溺水低體溫(29 ℃)的復溫：加溫濕氧、溫熱輸液與灌洗，**加溫速度不宜過快**，見 [[body-temperature#hypothermia]]

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 熱使血液黏稠度增加 | 熱使黏稠度降低；冷使其增加 | 冷有助凝血、熱使出血加劇 |
| 濕熱溫度要比乾熱高 | 乾熱要比濕熱高 | 水的傳導較好 |
| 冷熱敷越久越有效 | 20–30 分鐘為限 | 反彈現象 |
| 冷熱設備直接貼皮膚效果最好 | 包布或套套子 | 防凍傷、燙傷 |
| 溫水拭浴頭放熱水袋 | 頭冰枕、足熱水袋 | 防腦充血與寒顫 |
| 扭傷先熱敷再冷敷 | 先冷（24–48 小時）後熱 | 急性期熱會加重出血腫脹 |
| 電熱墊用別針固定 | 不可用別針 | 電擊與損壞 |
| 坐浴水溫 50 ℃ | 37.8–46.1 ℃ | 會陰皮膚薄易燙傷 |
| 手掌比頸部更怕燙 | 頸部較敏感 | 手掌皮膚厚 |
