**注射**是把無菌藥液經針頭打進組織或血管，吸收快、劑量準，適合急症、不能口服或需要局部作用（皮膚試驗）的情況，但會痛、有感染與針扎風險，而且一旦打進去就收不回來。依深度分為**皮內、皮下、肌肉、靜脈**四種。給藥共通原則（三讀五對、醫囑、劑量計算）見 [[medication-administration-principles]]；靜脈輸液與留置針見 [[iv-therapy]]

## 重點摘要 {#summary}

- 全程**外科無菌**；針頭 **G 越大越細**；用過的針**不回套**，直接丟針頭收集筒
- 消毒：**75% 酒精**由中心**往外環狀**消毒約 5–8 公分（2–3 吋），**等乾**再打
- 角度：**肌肉 90 度**、**皮下 45–60 度**（胰島素空針或捏起皮膚 90 度）、**皮內 5–15 度**、**靜脈 15–30 度**
- 量：**肌肉**一般 1–3 mL、成人最多 **5 mL**、兒童 **2 mL**；**皮下 ≤ 1.5 mL**；**皮內 0.1 mL**
- 部位：**腹臀肌**最安全（血管神經少，消瘦者也適用）；**2 歲以下用股外側肌**；**背臀肌靠近坐骨神經**；三角肌量小
- 肌肉注射「**快進、慢推、快出**」；反抽**有回血 → 拔出、丟棄，重新備藥另找部位**
- **Z 字形**加**預留氣泡**：鐵劑等刺激性、會染色的藥；**停 10 秒再拔、不揉**
- 皮下**胰島素、肝素**：**不回抽、不揉**，部位**輪替**
- 皮內：**斜面朝上**、不回抽、打出小水泡、**不按壓不揉**，用無色消毒液

### 國考常考點 {#exam-points}

- 長期臥床消瘦、BMI（body mass index，身體質量指數）低、營養不良的病人肌肉注射首選**腹臀肌**
- 術後肌肉注射止痛藥，**背臀區不是首選**（靠近坐骨神經）
- 背臀肌四分法最上方的假想線通過**髂骨嵴**（下方是臀弧線）
- 兒童：**上臂三角肌**吸收最快，適合學齡兒童預防注射；0–2 歲用**股外側肌**（不是股內側肌）；腹臀肌要會走路後
- 股四頭肌外側（股外側肌）可做肌肉注射；**股三角的內側邊界是內收長肌**，不是股四頭肌
- 肌肉注射：**快速進針**減輕疼痛；放鬆肌肉；皮膚繃緊 **90 度**；75% 酒精、由內往外消毒約 3 吋；推藥要慢
- 反抽有回血：**拔出針頭、重新備藥、另找部位**（不是只換針頭或調深度）
- 腎上腺素 IM：0.3 mg ＝ 1 mg/mL 抽 **0.3 mL**；國考答案：IM 進針後**要反抽**（不反抽是錯的）；打完可按摩
- 鐵劑：**Z 字形深部肌肉注射**、**抽藥後換針頭**、**停 5–10 秒再拔**；**不可揉**、不可立即拔針
- 胰島素：皮下、**部位輪換**、**不揉**；1/2 吋針頭用 90 度（不是 45 度）；消毒由中間往外環狀約 3 吋
- 肝素：**不肌肉注射**、**不回抽**、**不按摩**、監測 **aPTT**
- Vial 抽藥：倒轉藥瓶、針頭斜面**在液面下**抽，抽完雙手**水平**拔針；粉劑**用手掌搓滾**溶解，不用力搖；先換針頭再排氣；核對藥瓶與藥牌是**第二讀**
- Ampicillin 500 mg vial 加 5 mL，要 250 mg：打入 **2.5 mL 空氣**、抽 **2.5 mL**
- 6–7 個月嬰兒打針：**握住肢體、儘快完成**；母親留在旁邊；不用語言要求或事後獎勵

## 注射共通原則 {#principles}

1. 優點：吸收快、劑量準，昏迷、禁食、嘔吐者也能給
2. 缺點：疼痛與焦慮（暈針）、組織傷害與感染、費時費用高、**針扎**
3. 用物
   1. **針頭**：號數用 G(gauge)表示，**號數越大越細**；越粗通常越長
   2. **空針**：0.5–20 mL；胰島素用**胰島素專用空針**（針頭一體成形，單位刻度）
   3. **安瓿**(ampoule)：玻璃細頸、折斷後抽，多為液劑
   4. **藥瓿**(vial)：橡皮蓋，多為粉劑，加稀釋液溶解
   5. 消毒：75% 酒精棉片；靜脈留置另用優碘或 2% chlorhexidine
4. 原則
   1. 從備藥到注射都是**外科無菌**
   2. 注射前**解釋**、評估過敏史；病人過度焦慮、胸悶頭暈時暫停，通知醫師
   3. 幼兒、意識不清者經家屬同意可適當固定
   4. 選部位：健康、無紅腫、硬結、疤痕；**經常注射要輪替**
   5. 消毒由中心往外環狀，**待酒精乾**才打（才有殺菌效果、也比較不痛）
   6. **兩種藥分開空針、分開部位**，相距 1–2 吋
   7. 有**出血傾向**：選較細針頭，注射後**加壓**較久
   8. 進針前請病人深呼吸，轉移注意力
5. **安全針具**：醫療法第 56 條要求醫療機構提供安全針具；用過的針頭**不回套**，直接放入硬殼針頭收集筒（必要時單手回套）

## 抽藥 {#drawing-up}

| 步驟 | 理由 |
|---|---|
| 1. 第一讀、第二讀（抽藥前）核對 | 三讀五對見 [[medication-administration-principles#three-reads]] |
| 2. **安瓿**：輕彈讓藥液回到瓶身 → 消毒頸部 → 墊酒精棉片折斷 → 針頭伸入液面下抽 | 避免割傷、避免抽入玻璃屑與空氣 |
| 3. **藥瓿**：消毒橡皮蓋 → 打入稀釋液 → **放掌心搓滾**溶解 | **用力搖會起泡**，劑量看不準 |
| 4. 抽藥前打入**和要抽的量相等的空氣** | 維持瓶內壓力平衡，好抽也不會噴出 |
| 5. 倒轉藥瓶，針頭斜面在**液面下**抽到醫囑劑量；抽完**雙手水平**拔出 | 避免抽到空氣、針頭彎曲或刺傷手 |
| 6. **更換新針頭**後再排氣 | 刺過橡皮蓋的針頭會鈍，增加疼痛；也避免刺激性藥物殘留在針外 |
| 7. 排氣：針頭朝上，排到針尖出現一小滴 | 不打入空氣 |
| 8. 稀釋後無色透明的藥**立即貼標籤**；第三讀 | 避免拿錯 |

Ampicillin 500 mg/vial 加 5 mL 稀釋＝100 mg/mL；要 250 mg → 抽 2.5 mL，抽前打入 **2.5 mL 空氣**(109-1_FA_023)

### 注射部位 {#im-sites}

::figure{src="/knowledge-images/im-injection-sites.jpg" labels="im-injection-sites" alt="四個肌肉注射部位：左上三角肌、右上腹臀肌、左下背臀肌、右下股外側肌"}

- 圖中腹臀肌的手勢只示意注射位置；正確定位是手掌根放在大粗隆、食指指向髂前上棘、中指沿髂嵴張開，打在兩指之間的 V 字中央（見下表）

| 部位 | 定位 | 適合 | 注意 |
|---|---|---|---|
| **上臂三角肌** | **肩峰突下約三橫指**(2.5–5 cm)；手插腰讓肌肉隆起 | 小量（約 0.5–1 mL）、**疫苗**、學齡兒童與成人；**吸收最快** | 肌肉小；避開上臂下段（**橈神經、肱動脈**） |
| **腹臀肌**（臀中肌、臀小肌） | 手掌根放在**股骨大粗隆**，食指放**髂前上棘**、中指沿**髂嵴**張開成 **V 字**，打在 V 字中央 | **最安全**：大血管與神經少；**消瘦、長期臥床、兒童**也適用；成人首選 | 側臥、注射側在上微屈 |
| **背臀肌**（臀大肌） | 四分法：上界**髂嵴**、下界**臀弧線**，分四象限取**外上象限**；或髂後上棘到大粗隆連線的外上方 | 肌肉大，可打較大量或油劑 | **靠近坐骨神經**與臀上動脈；**3 歲以下、瘦弱者不用**；國外已少用 |
| **股外側肌** | **大粗隆到膝**分三等份，取**中段外側** | **2 歲以下嬰幼兒首選**；部位好找 | 打完避免劇烈活動；不是股內側（有大血管神經） |

- 股外側肌屬於股四頭肌；股直肌在大腿前面中線，成人較痛，少用
- 國外指引多建議成人**優先腹臀肌**；課本與國考四個部位都考，並列優缺點

### 步驟 {#im-steps}

| 步驟 | 理由 |
|---|---|
| 1. 兩種方式確認病人（請病人說全名，不用「你是 OOO 嗎」）；解釋、評估過敏史 | 意識恍惚者會順口答是 |
| 2. 選部位、擺姿勢，只露出注射部位、拉圍簾 | 放鬆肌肉、保護隱私 |
| 3. 75% 酒精由內往外環狀消毒約 5–8 cm，**等乾** | 殺菌、減少刺痛 |
| 4. 非持針手**繃緊皮膚**，請病人深呼吸、**放鬆肌肉** | 肌肉緊繃更痛、阻力大 |
| 5. **90 度快速進針**，約針長 1/2–2/3 | 快進減少痛；留一段在外，斷針時好取 |
| 6. 固定針筒，**反抽**看有無回血（國考答案） | 避免打進血管 |
| 7. 無回血 → **緩慢推藥**（約 10 秒／mL） | 讓組織慢慢撐開，減少疼痛 |
| 8. 酒精棉片壓住，**快速拔針**；針頭**不回套** | 快出減少痛；防針扎 |
| 9. 一般藥物可揉按 30–60 秒促進吸收；**鐵劑、Z 字形注射不揉** | — |
| 10. 觀察反應、記錄藥物與部位 | — |

1. **回抽有回血**：表示針在血管內 → **拔出**、整支（藥與空針）**丟棄**、**重新備藥**、**另找部位**；不是調整深度、也不是只換針頭（藥液已混血）
2. 回抽的新舊說法
   1. 課本與國考：肌肉注射進針後要反抽，「不需反抽」被判錯(112-2_FA_020)
   2. 美國 CDC(Centers for Disease Control and Prevention)／ACIP(Advisory Committee on Immunization Practices)：**疫苗**肌肉注射**不需要回抽**（建議部位沒有大血管，回抽會更痛）
   3. 考試照國考答案；臨床依院內規範
3. 兒童：成人「快進慢推快出」；**兒童快速推完**，縮短掙扎與疼痛

### Z 字形注射與預留氣泡法 {#z-track}

1. **Z 字形注射**(Z-track)
   1. 用途：**刺激性強、會讓皮膚染色**的藥，例：**鐵劑**(Imferon)
   2. 做法：非持針手把皮膚**往一側拉開** 2.5–3.5 cm → 90 度進針、反抽、慢推 → **停約 10 秒** → 拔針後才**放開皮膚**
   3. 原理：皮膚彈回後，針道變成 Z 形，把藥封在肌肉內，不會沿針道滲到皮下
   4. **抽藥後換新針頭**（針外殘留的鐵劑會刺激、染色皮下）
   5. 打完**不揉**
2. **預留氣泡法**(Air-lock)
   1. 抽完藥留約 **0.2 mL 空氣**在針筒內，針頭朝下注射，空氣最後推入
   2. 空氣把針頭內殘留的藥推進肌肉、封住針道
   3. 常和 Z 字形一起用；鐵劑、部分疫苗

### 併發症 {#im-complications}

| 併發症 | 原因 | 預防 |
|---|---|---|
| 局部紅腫痛、硬結 | 刺激性藥物、反覆同一部位 | 輪替部位、Z 字形 |
| 感染、膿瘍 | 無菌技術破壞 | 外科無菌、消毒待乾 |
| **神經損傷** | 背臀肌傷到**坐骨神經**、三角肌下段傷到**橈神經** | 正確定位、優先腹臀肌 |
| 血腫 | 刺到血管 | 反抽、出血傾向者細針並加壓 |
| 骨膜炎 | 太深、太瘦 | 消瘦者選腹臀肌、調整針長 |

## 皮下注射 {#subcutaneous}

1. 位置：皮下脂肪組織，血管少，**吸收比肌肉慢、比口服快**
2. 量：**不超過 1.5 mL**；適合少量、刺激性小的藥
3. 部位：**上臂後外側**、**腹部**（肋緣下到髂嵴，避開肚臍周圍約 5 cm）、**大腿前外側**、肩胛骨下、臀部
4. 角度：一般針 **45–60 度**；**胰島素空針或筆針（短針）90 度**；瘦的人**捏起皮膚**再打
5. 打完**不揉**，輕壓到不出血即可（揉會讓吸收太快、造成血腫）
6. **胰島素**
   1. 用**胰島素專用空針或注射筆**，高警訊藥物，核對劑量
   2. **不回抽、不揉**；**部位輪替**（同部位間隔 1–2 cm 以上），避免脂肪增生或萎縮
   3. 注射部位與劑量要**記錄**
   4. 打完提醒**進食**、避免立即劇烈運動，預防低血糖
   5. 吸收速度與混合抽藥見 [[insulin#injection-sites]]、[[insulin#mixing]]
7. **肝素**(heparin)與低分子量肝素
   1. **皮下或靜脈**，**不肌肉注射**（肌肉血管多 → 血腫）
   2. **不回抽、不按摩**，打在腹部
   3. 監測 **aPTT**(heparin)，見 [[anticoagulants#sc-injection]]

## 皮內注射與皮膚試驗 {#intradermal}

1. 位置：表皮與真皮之間；用於**過敏試驗**、**結核菌素試驗**、**卡介苗**
2. 部位：皮膚薄、顏色淡、毛少的地方，例：**前臂中段內側**、三角肌外側、鎖骨下、肩胛骨下
3. 做法
   1. 0.5–1 mL 空針或胰島素空針，**斜面朝上**
   2. **5–15 度**進針，斜面剛好沒入皮內後**平行推進**，看得到針的輪廓
   3. **不回抽**，緩慢推入 **0.1 mL**，形成直徑約 0.8–1 cm 的**小水泡**
   4. 拔針後**不按壓、不揉**（水泡消失會影響判讀）
   5. **不要用有顏色的消毒液**（影響判讀）
4. **青黴素皮膚試驗**(Penicillin skin test, PST)（課本）
   1. 皮內打入稀釋的青黴素約 100 單位
   2. **15–20 分鐘**後由醫師判讀
   3. 陽性：紅腫、周圍不規則紅暈，直徑 > 1.5 cm，或比對照側大 0.3 cm 以上 → 不可用青黴素類
   4. 嚴重過敏時急救用 **1:1,000 腎上腺素**，見 [[anaphylaxis#epinephrine]]
5. **結核菌素試驗**（Tuberculin skin test, TST；PPD）
   1. 皮內 0.1 mL，**48–72 小時**看**硬結**（不是紅暈）大小
   2. 課本：接種過卡介苗者 **≥ 10 mm** 為陽性；未接種、免疫功能不全或用免疫抑制劑者 **≥ 5 mm** 為陽性
   3. 結核感染的其他檢驗見 [[tuberculosis#infection-tests]]

## 靜脈注射 {#intravenous}

1. 小量推注叫 **IV push**（一般 ≤ 20 mL）；大量滴注見 [[iv-therapy]]
2. 藥物直接進入血液，**作用最快**，不良反應也來得最快 → 核對要更嚴謹
3. **油劑、懸浮劑不可靜脈注射**（栓塞）
4. 部位：表淺可見的靜脈，**由遠端往近端**選；不用動靜脈瘻管側、乳房切除側、循環不良或硬化的血管
5. 做法：血管上方約 6–8 cm 綁止血帶 → 消毒 → 斜面朝上、**15–30 度**順著血管進針 → 見回血再平推約 1 mm → **鬆止血帶** → 緩慢推藥
6. 法規：靜脈注射屬醫療業務，依醫師法第 28 條，護理人員要**在醫師指示下**或**臨時急救**時才可執行（課本）
7. 需要反覆推藥時用留置針接注射帽或 T 型接管，減少重複穿刺
8. 併發症：浸潤、靜脈炎、血腫、感染、空氣栓塞，見 [[iv-therapy#complications]]

## 兒童注射 {#pediatric-injection}

1. 部位：**嬰幼兒（2 歲以下）用股外側肌**；會走路後臀肌發達才用腹臀肌；學齡兒童可用三角肌
2. 量：每處 ≤ 2 mL
3. 嬰兒（6–7 個月）：還聽不懂「不要動」或「打完給獎勵」→ **固定好肢體、儘快完成**；**母親留在旁邊**安撫
4. 學齡前：簡單說明、可用玩偶示範；打完給擁抱或貼紙
5. 推藥要快，縮短疼痛與掙扎時間

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 皮下注射都打 45 度 | 短針（胰島素）90 度，瘦的人捏起再打 | 角度依針長與皮下厚度 |
| 回抽有血，把針退一點再打 | 拔出、丟棄、重新備藥、換部位 | 藥液已混血、針可能還在血管 |
| 打完胰島素揉一揉 | 不揉 | 吸收變快 → 低血糖 |
| 肝素打屁股 | 皮下打腹部，或靜脈；不肌肉注射 | 肌肉內血腫 |
| 鐵劑打完馬上拔針、揉一揉 | 停 10 秒、不揉 | 藥液沿針道滲出，皮膚染色 |
| 粉劑用力搖勻 | 掌心搓滾 | 起泡、劑量不準 |
| 抽藥後直接用同一支針打 | 換新針頭 | 針頭變鈍、外面沾藥 |
| 消瘦病人選背臀肌 | 選腹臀肌 | 背臀肌易傷坐骨神經 |
| 皮內注射後按揉 | 不按不揉 | 影響判讀 |
