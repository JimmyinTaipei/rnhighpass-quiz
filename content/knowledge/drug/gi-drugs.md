消化系統用藥依作用可分成：抑制或中和胃酸、保護黏膜、止吐與促進蠕動、瀉劑與止瀉劑、肝病用藥(lactulose)與發炎性腸道疾病用藥。疾病本身見 [[upper-gi-disorders]]，幽門螺旋桿菌除菌組合見 [[helicobacter-pylori#treatment]]，便秘與灌腸護理見 [[bowel-elimination#constipation]]

## 重點摘要 {#summary}

- 胃酸分泌靠壁細胞的 **H⁺/K⁺-ATPase(質子幫浦)**，受**組織胺(H2)、乙醯膽鹼、胃泌素**刺激；**PPI** 抑制最後一步，作用最強
- **PPI**：**餐前 30–60 分鐘**服用；長期使用可能減少**鈣**、鎂、B12 吸收(骨折風險)；omeprazole 可能降低 **clopidogrel** 的活化
- **H2 阻斷劑**：cimetidine、famotidine；**cimetidine 抑制 CYP450**、抗雄性素(**男性女乳**)、經腎排除要**監測腎功能**；**H1 阻斷劑不治潰瘍**
- **制酸劑**：**鎂 → 腹瀉**、**鋁 → 便秘**(也會結合其他藥物)；腎衰竭避免含鎂製劑
- **Sucralfate**：**酸性(低 pH)**環境下形成黏膠覆蓋潰瘍；**Misoprostol**：前列腺素 E1 類似物，**預防 NSAID／aspirin 潰瘍**，**孕婦禁用**
- **鉍劑**：舌頭與**糞便變黑**；bismuth subsalicylate 可治**旅行者腹瀉**
- 止吐：**5-HT3 拮抗劑**(ondansetron、palonosetron)治**化療嘔吐**；**D2 拮抗劑**(metoclopramide、prochlorperazine)；**dexamethasone** 常合併使用；NK1 拮抗劑 aprepitant 用於延遲性嘔吐
- 瀉劑：**容積性**(需多喝水)、**滲透性**(lactulose、鎂鹽)、**刺激性**(bisacodyl、senna、**蓖麻油**)、軟便劑(docusate)、潤滑劑(礦物油)、**lubiprostone**(活化氯離子通道)
- 止瀉：**loperamide**(作用在腸道的類鴉片，不進入中樞；不用於感染或中毒性腹瀉)
- **Lactulose**：被腸道細菌分解成酸、**酸化糞便**，把氨變成銨離子留在腸道排出，並有輕瀉作用 → 治療**肝性腦病變**

### 國考常考點 {#exam-points}

- 消化性潰瘍用藥的目的：中和胃酸、減少胃酸分泌、保護黏膜；**不是促進胃排空**
- 消化性潰瘍用藥**不包括 H1 拮抗劑**；包括制酸劑、PPI、H2 拮抗劑、黏膜保護劑、前列腺素製劑
- Cimetidine 是 **H2 受體拮抗劑**；會**抑制** CYP450(「增加 CYP450 活性」是錯的)；長期使用男性女乳；使用時要**監測腎功能**
- 有抑制 CYP450 作用的抗潰瘍藥是 **cimetidine**(nizatidine、ranitidine 沒有明顯抑制)
- PPI **可以**用於 aspirin 造成的消化性潰瘍；飯前 30–60 分鐘服用；可能減少鈣吸收、增加骨折；可能降低 clopidogrel 效果
- 燒傷病人靜脈給 H2 阻斷劑是**預防壓力性潰瘍**
- 制酸劑中容易造成**腹瀉**的是**氫氧化鎂**；氫氧化鋁會降低 **levothyroxine** 吸收
- Sucralfate 需要在**低 pH(酸性)**環境活化(「需要高 pH」是錯的)，與黏膜上帶正電的蛋白質結合
- 前列腺素致效劑、可**預防 aspirin／止痛藥造成的潰瘍**：**misoprostol**
- 幽門桿菌三合一療法：PPI＋**clarithromycin**＋**amoxicillin**(不含 erythromycin)
- **Ondansetron** 用於**化療引起的嘔吐**，是強力止吐劑；有心臟病病人化療嘔吐選 **palonosetron**
- 經由**抑制多巴胺受體**止吐、用於化療嘔吐：**prochlorperazine**；拮抗 D2 的促動劑：**domperidone**
- 常與 metoclopramide 合併增強止吐的是 **dexamethasone**
- 刺激性瀉劑：**castor oil、senna、bisacodyl**；鴉片類便秘常用 **senna＋docusate**
- 活化**氯離子通道**治療慢性便秘：**lubiprostone**
- 神經損傷長期臥床病人較適合**刺激性輕瀉劑**
- Loperamide：**類鴉片**、增加腸道**分節收縮**、抑制大腸平滑肌蠕動並減少 acetylcholine 釋出；**不影響中樞**、**不適合中毒性腹瀉**；屬於抑制腸胃蠕動的止瀉藥(antimotility)
- 降低腸道水分分泌、治療與預防**旅行者腹瀉**：**bismuth subsalicylate**
- Lactulose：**酸化糞便減少氨吸收**、產生輕瀉作用；肝性腦病變要**預防便秘**、不用利尿劑排氨
- 食道靜脈曲張用藥：vasopressin、**octreotide(Sandostatin)**、**propranolol**；**furosemide 不是**
- ERCP 導管不易進入總膽管時讓歐迪氏括約肌鬆弛：國考答案是 **MgSO₄(硫酸鎂)**，不是 atropine、Buscopan 或 Xylocaine
- 輕度潰瘍性結腸炎第一線：**mesalamine(5-ASA)**；**famotidine 不治 IBD**

## 胃酸分泌與藥物作用點 {#acid-secretion}

| 刺激壁細胞的訊號 | 受體 | 阻斷的藥 |
|---|---|---|
| 組織胺(類腸嗜鉻細胞) | **H2** | **H2 阻斷劑** |
| 乙醯膽鹼(迷走神經) | M3 | 抗膽鹼藥(少用) |
| 胃泌素 | CCK2 | — |
| 最後共同路徑：**H⁺/K⁺-ATPase** 把 H⁺ 打進胃腔 | — | **PPI** |

- 胃腺細胞與胃液分泌調節見 [[gi-anatomy-physiology#gastric-glands]]

## 消化性潰瘍用藥 {#peptic-ulcer-drugs}

### 質子幫浦抑制劑(PPI) {#ppi}

- 藥物：omeprazole、esomeprazole、lansoprazole、pantoprazole、rabeprazole
- 機轉：不可逆抑制壁細胞的 **H⁺/K⁺-ATPase**，抑酸最強、作用最久；在酸性環境活化，所以要**餐前 30–60 分鐘**空腹服用(ACG 2022)
- 用途：胃食道逆流、消化性潰瘍、**NSAID／aspirin 潰瘍的治療與預防**、幽門螺旋桿菌除菌、上消化道出血、壓力性潰瘍預防
- 長期副作用：**鈣、鎂、維生素 B12 吸收減少**(骨折風險)、困難梭狀桿菌腸炎與肺炎風險
- 交互作用：omeprazole、esomeprazole 抑制 CYP2C19，**降低 clopidogrel 的抗血小板作用**(見 [[antiplatelets]])

### H2 受體拮抗劑 {#h2}

- 藥物：**cimetidine**、famotidine、nizatidine、ranitidine(美國 FDA 2020 年因 NDMA 雜質要求撤市)
- 機轉：競爭性拮抗壁細胞的 **H2 受體**，減少胃酸；夜間胃酸抑制效果好
- **Cimetidine** 特點
   1. **抑制肝臟 CYP450** → warfarin、theophylline、phenytoin 濃度上升
   2. 抗雄性素作用 → **男性女乳**、性功能障礙
   3. 主要經**腎臟排除** → 腎功能不好要減量、**監測腎功能**；老人可能意識混亂
- 其他 H2 阻斷劑(famotidine、nizatidine)幾乎沒有 CYP450 抑制作用
- **H1 阻斷劑**(抗過敏藥)**對胃酸沒有作用**，不用於潰瘍(見 [[antihistamines-autacoids]])

### 制酸劑 {#antacids}

| 制酸劑 | 副作用與注意事項 |
|---|---|
| **氫氧化鎂**(胃乳、氧化鎂) | **腹瀉**；腎衰竭會**高血鎂**，要避免 |
| **氫氧化鋁** | **便秘**、低血磷；會結合其他藥(**levothyroxine**、tetracycline、quinolone、鐵劑)，要間隔服用 |
| 碳酸鈣 | 便秘、胃酸反彈、高血鈣 |
| 碳酸氫鈉 | 全身性鹼中毒、鈉負荷 |

- 鋁鎂合併使用可互相抵銷便秘與腹瀉；與其他藥物至少間隔 1–2 小時
- 腎衰竭病人補鐵不要和制酸劑一起吃(會降低鐵吸收)

### 黏膜保護劑與前列腺素 {#mucosal-protectants}

- **Sucralfate**：在**酸性環境**聚合成黏膠，與潰瘍處**帶正電的蛋白質**結合形成保護層；要**飯前空腹**吃；和 PPI、H2 阻斷劑、制酸劑併用會降低效果；副作用便秘(含鋁)；不能預防 aspirin 造成的潰瘍
- **Misoprostol**：**前列腺素 E1 類似物**，減少胃酸、增加黏液與碳酸氫鹽；**預防與治療 NSAID／aspirin 造成的潰瘍**；副作用腹瀉、腹痛；會引起子宮收縮，**孕婦禁用**
- **鉍劑**：覆蓋潰瘍、抑制幽門螺旋桿菌(四合一療法的成分)；**舌頭與糞便變黑**

## 止吐劑與腸胃促動劑 {#antiemetics}

| 類別 | 藥物 | 用途與重點 |
|---|---|---|
| **5-HT3 拮抗劑** | **ondansetron**、granisetron、**palonosetron** | **化療與術後嘔吐**的強力止吐劑；palonosetron 作用時間長、心臟影響較小；副作用頭痛、便秘、QT 延長 |
| **D2 拮抗劑** | **metoclopramide**、**prochlorperazine**、domperidone | 抑制延腦化學受器激發區；metoclopramide 會進入中樞 → **錐體外徑症狀**，domperidone 較少進入中樞 |
| NK1 拮抗劑 | **aprepitant** | 化療**延遲性**嘔吐，常合併 5-HT3 拮抗劑與 dexamethasone |
| 類固醇 | **dexamethasone** | 增強其他止吐藥(常與 metoclopramide 或 5-HT3 拮抗劑合用) |
| 抗組織胺、抗膽鹼 | meclizine、dimenhydrinate、**scopolamine** | **動暈症** |

| 腸胃促動劑 | 機轉 |
|---|---|
| metoclopramide、**domperidone** | **拮抗 D2** 受體，促進胃排空 |
| erythromycin | 刺激 motilin 受體 |
| bethanechol | 蕈毒鹼受體致效劑(見 [[cholinergic-drugs]]) |
| neostigmine | 抑制膽鹼酯酶 |
| prucalopride | 5-HT4 致效劑，治慢性便秘 |

- 止吐劑通常在**飯前**或化療前給，不是飯後立即
- 化療噁心嘔吐的護理見 [[cancer-treatment-toxicities]]

## 瀉劑 {#laxatives}

| 類別 | 藥物 | 機轉 | 注意事項 |
|---|---|---|---|
| **容積性** | psyllium、**methylcellulose** | 吸水膨脹增加糞便體積 | 最溫和、適合長期；**要喝足量水**，否則可能阻塞；臥床、水分攝取不足者不適合 |
| **滲透性** | **lactulose**、PEG、**鎂鹽**(氧化鎂、**magnesium citrate**)、甘油栓劑 | 把水留在腸道 | 鎂鹽腎衰竭避免；lactulose 會脹氣 |
| **刺激性** | **bisacodyl(Dulcolax)**、**senna**、**castor oil(蓖麻油)** | 刺激腸神經叢增加蠕動 | 可能腹絞痛；bisacodyl 腸溶錠**不可咬碎**、不與制酸劑或牛奶同服；長期使用依賴；**鴉片類便秘**常用 senna＋軟便劑 |
| **軟便劑** | **docusate** | 降低表面張力讓水分進入糞便 | 預防用力解便(心臟病、術後、痔瘡) |
| 潤滑性 | **mineral oil(礦物油)** | 潤滑腸道 | 減少**脂溶性維生素**吸收；吸入會造成類脂性肺炎 |
| 氯離子通道活化劑 | **lubiprostone** | 活化氯離子通道，增加腸液分泌 | 慢性便秘、便秘型腸躁症 |

- 神經損傷長期臥床病人(神經性腸道)：國考答案選**刺激性輕瀉劑**(容積性需要大量水分與活動)
- 給藥時病人說腹瀉嚴重：**暫停給藥、報告醫師**
- 塞劑的給法(左側臥、深度、留置時間)見 [[non-parenteral-medication]]；便秘護理與灌腸見 [[bowel-elimination#constipation]]

## 止瀉劑 {#antidiarrheals}

| 藥物 | 機轉與重點 |
|---|---|
| **Loperamide** | 作用在腸道的**類鴉片(μ 受體)**：抑制大腸蠕動、減少 acetylcholine 釋出、增加**分節收縮**與肛門括約肌張力；一般劑量**不進入中樞**；**不用於細菌性、血便或中毒性腹瀉**(會讓病原留在腸道) |
| Diphenoxylate＋atropine | 類鴉片，加 atropine 防止濫用 |
| **Bismuth subsalicylate** | 減少腸道水分分泌、抗菌；治療與預防**旅行者腹瀉**；糞便變黑；含水楊酸，兒童與 aspirin 過敏者小心 |
| 吸附劑(kaolin-pectin) | 吸附毒素與水分；會吸附其他藥物，要間隔服用、**不與食物同服** |

- 腹瀉的護理與補液見 [[bowel-elimination#diarrhea]]、[[infectious-diarrhea]]

## 肝病用藥：lactulose 與靜脈曲張藥物 {#liver-drugs}

- **Lactulose**：人工雙醣，小腸不吸收，到大腸被細菌分解成乳酸等 → **酸化糞便**，把 NH₃ 變成 NH₄⁺ 留在腸道排出；滲透性輕瀉讓含氮物質快點排掉
   1. 用於**肝性腦病變**，調整到**每天 2–3 次軟便**(ACG 2026)
   2. 護理：**預防便秘**；不用利尿劑排氨；觀察腹瀉與脫水、低血鉀
   3. 急性明顯肝性腦病變可合併 **rifaximin**(腸道不吸收的抗生素，減少產氨細菌)
- 食道靜脈曲張(詳細見 [[liver-cirrhosis#varices]])
   1. 急性出血：**vasopressin**(血管收縮，出血停止後**逐漸減量**)、**octreotide(Sandostatin)**、terlipressin
   2. 預防出血：**非選擇性 β 阻斷劑**(propranolol、carvedilol)降低門脈壓
   3. **Furosemide 不是**靜脈曲張用藥(是腹水利尿劑)
- 檢查用藥：ERCP 導管不易進入總膽管時，國考答案用 **MgSO₄(硫酸鎂)** 鬆弛歐迪氏括約肌(112-1_MS_010)；Buscopan 等抗膽鹼解痙劑是減少腸胃蠕動(見 [[cholinergic-drugs]])，Xylocaine 是咽喉局部麻醉；臨床上各醫院做法不同(待核對)

## 發炎性腸道疾病用藥 {#ibd-drugs}

| 類別 | 藥物 | 用途 |
|---|---|---|
| **5-ASA** | **mesalamine**、sulfasalazine | **輕度到中度潰瘍性結腸炎第一線**、維持緩解 |
| 類固醇 | prednisolone、budesonide | 急性發作誘導緩解，不長期使用 |
| 免疫調節劑 | azathioprine、**methotrexate** | 減少類固醇用量 |
| 生物製劑 | **infliximab**(抗 TNF-α)、vedolizumab、**natalizumab**(抗整合素，PML 風險) | 中重度；ACG 2025 建議中重度 Crohn 病早期使用 |
| 小分子 | **tofacitinib**(JAK 抑制劑) | 中重度潰瘍性結腸炎 |

- **Famotidine(H2 阻斷劑)不治 IBD**；疾病本身見 [[lower-gi-disorders#ibd]]；生物製劑見 [[monoclonal-antibodies]]
