## 重點摘要 {#summary}

- 直接放鬆**血管平滑肌**(不經由自主神經受體或 RAAS):hydralazine、minoxidil 主要擴張**小動脈**;nitroprusside **動靜脈都擴張**。
- **Hydralazine**:孕期急性重度高血壓用藥;副作用**反射性心搏過速、鈉水滯留、類狼瘡症候群**。
- **Minoxidil**:最強的口服血管擴張劑,用於頑固型高血壓;副作用**多毛症**、嚴重水腫、心包膜積液。
- **Nitroprusside**:**高血壓急症**靜脈滴注,數秒起效、停藥 1–2 分鐘消失;**避光**;注意**氰化物與硫氰酸鹽中毒**;**孕婦禁用**。
- 口服者常需併用 **β 阻斷劑(抵銷心搏過速)+ 利尿劑(抵銷水鈉滯留)**。

## 作用機轉 {#mechanism}

| 藥物 | 作用 | 擴張部位 |
|---|---|---|
| **Hydralazine** | 機轉未完全明瞭(影響平滑肌細胞內鈣離子釋放) | **小動脈**為主 |
| **Minoxidil** | 活性代謝物打開 **ATP 敏感性鉀通道** → 平滑肌過極化、放鬆 | **小動脈** |
| **Nitroprusside** | 在血中釋放 **一氧化氮(NO)** → 活化鳥苷酸環化酶、cGMP ↑ → 平滑肌放鬆 | **小動脈 + 靜脈**(後負荷與前負荷都下降) |
| Diazoxide | 打開鉀通道;同時抑制胰島素釋放 | 小動脈 |

**只擴張小動脈的後果**(hydralazine、minoxidil):血壓下降 → 壓力感受器反射(見 [[blood-pressure-regulation#baroreceptor]])→ **交感興奮(反射性心搏過速、心輸出量 ↑、心肌耗氧 ↑)** 與 **腎素分泌 ↑ → 鈉水滯留**。所以單用效果會被代償抵銷,且可能誘發心絞痛——這就是要「三合一」併用 β 阻斷劑與利尿劑的原因。

Nitroprusside 分子含 5 個**氰根(CN⁻)**:釋放 NO 時氰根也被釋出,由肝臟的 rhodanese 酵素利用硫(thiosulfate)轉成**硫氰酸鹽(thiocyanate)**,再由腎臟排出。劑量高或時間長時,硫來源耗盡 → **氰化物中毒**;腎衰竭時排不掉 → **硫氰酸鹽中毒**。

## 代表藥物 {#agents}

| 藥物 | 劑型 | 特色 |
|---|---|---|
| **Hydralazine**(Apresoline) | 口服、靜脈/肌肉注射 | 孕期重度高血壓(靜脈);口服與硝酸鹽(isosorbide dinitrate)合用於 HFrEF(無法使用 ACEI/ARB/ARNI 者) |
| **Minoxidil**(Loniten;外用 Regaine) | 口服;外用液 | 頑固型高血壓;**外用治療雄性禿**(利用多毛副作用) |
| **Nitroprusside**(Nipride) | **只能連續靜脈滴注** | 高血壓急症;作用最快也最短 |
| Diazoxide | 靜脈(舊)、口服 | 過去用於高血壓危象;口服用於胰島素瘤等**低血糖**(會升高血糖) |

## 適應症 {#indications}

- **頑固型高血壓**:hydralazine、minoxidil 作為多藥併用後的附加藥(2025 AHA/ACC:無法使用 MRA 時的選項之一,COR 2a);2022 台灣指引與 2025 AHA/ACC 指引均非第一線;口服使用時要**併用利尿劑與 β 阻斷劑**,minoxidil 需併用**環利尿劑**(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e152、e176)(見 [[hypertension]])。
- **妊娠急性重度高血壓**(收縮壓 ≥ 160 或舒張壓 ≥ 110 mmHg,**15 分鐘內複測確認**):**靜脈/肌肉注射 hydralazine**(5 mg,之後每 20–40 分鐘 5–10 mg IV,累積最多 20 mg)、靜脈 labetalol、口服速效 nifedipine 為第一線;目標是在 **30–60 分鐘內**降到 < 160/110,但不要降太低以免影響胎盤血流(監測胎心音)(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e171、e175;劑量僅供參考,以醫囑為準)。hydralazine 劑量較高或太頻繁時,母親低血壓、頭痛與胎心音異常較其他藥常見。2022 台灣指引則以靜脈 labetalol 或 nicardipine 加硫酸鎂為孕期高血壓危象首選(來源:[2022 台灣高血壓治療指引](https://doi.org/10.6515/ACS.202205_38%283%29.20220321A),p.293)。
- **高血壓急症**(有急性標的器官傷害,例如高血壓腦病變、急性肺水腫、主動脈剝離):**nitroprusside** 以及 nicardipine、labetalol、esmolol、clevidipine 等靜脈藥物。一般原則(2025 AHA/ACC):**第 1 小時收縮壓下降不超過 25%**,若穩定之後 2–6 小時降到 **< 160/100 mmHg**,再於 24–48 小時內謹慎降到收縮壓 **130–140**;有強制性狀況(如急性主動脈症候群)時第 1 小時收縮壓 < 140,**主動脈剝離**則 < 120(Table 27:20 分鐘內達到,先給 esmolol/labetalol 再給血管擴張劑);子癇前症/子癇需快速降壓;**嗜鉻細胞瘤危象**需儘快降壓,但**不必**在第 1 小時內壓到 < 120 或 < 140(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e180–e181、e183)。2025 AHA/ACC 認為 hydralazine 起效與作用時間難預測,**不適合**作為多數急症病人的第一線靜脈藥(同上來源,p.e182)。
- **急性心衰竭/急性肺水腫合併高血壓**:nitroprusside 同時降前、後負荷(見 [[heart-failure]])。
- **HFrEF**:hydralazine + isosorbide dinitrate(見 [[nitrates]])。

### 常見靜脈降壓藥比較 {#iv-agents}

| 藥物 | 類別 | 起效 / 作用時間 | 重點 |
|---|---|---|---|
| **Nitroprusside** | NO 供給者 | 數秒 / **停藥 1–2 分鐘消失** | 最快最短;避光;氰化物毒性 |
| Nicardipine | DHP 類 CCB | 5–15 分鐘 / 數小時 | 見 [[calcium-channel-blockers]] |
| Labetalol | α1 + β 阻斷 | 5–10 分鐘 / 3–6 小時 | 孕婦可用;氣喘、心搏過緩避免(見 [[beta-blockers]]) |
| Esmolol | β1 阻斷 | 1–2 分鐘 / 10–30 分鐘 | 主動脈剝離、手術中 |
| Hydralazine | 直接血管擴張 | 10–30 分鐘 / 2–4 小時 | 孕婦;效果較難預測,一般急症不作首選 |
| Nitroglycerin | 硝酸鹽 | 2–5 分鐘 / 5–10 分鐘 | 急性冠心症、肺水腫(見 [[nitrates]]) |
| Fenoldopam | 多巴胺 D1 致效劑 | 5–15 分鐘 / 30–60 分鐘 | 台灣少用;青光眼、顱內壓升高、亞硫酸鹽過敏禁用 |
| Clevidipine | DHP 類 CCB | 數分鐘 / 超短效 | 肺水腫、急性腎損傷、圍手術期可用;對大豆、蛋過敏禁用 |
| Phentolamine | 非選擇性 α 阻斷 | 靜脈推注 | 兒茶酚胺過多(嗜鉻細胞瘤、古柯鹼、clonidine 戒斷) |

2025 AHA/ACC 依共病建議的靜脈藥:主動脈剝離 esmolol、labetalol;急性肺水腫 clevidipine、nitroglycerin、nitroprusside(**β 阻斷劑禁用**);急性冠心症 esmolol、labetalol、nicardipine、nitroglycerin;子癇前症/子癇 hydralazine、labetalol、nicardipine、nifedipine(**ACEI、ARB、腎素抑制劑、nitroprusside 禁用**);嗜鉻細胞瘤 clevidipine、nicardipine、phentolamine(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e182–e183)。起效時間為概略值;劑量僅供參考,以醫囑為準。

## 副作用與禁忌 {#adverse-effects}

### Hydralazine {#hydralazine-ae}

| 副作用 | 說明 |
|---|---|
| **反射性心搏過速**、心悸、**心絞痛** | 冠心病者小心;併用 β 阻斷劑 |
| 頭痛、臉潮紅 | 血管擴張 |
| 鈉水滯留、水腫 | 併用利尿劑 |
| **藥物誘發類狼瘡症候群** | 長期、高劑量(> 200 mg/天)、**慢乙醯化者**(acetylator)較常見(2025 AHA/ACC:高劑量時較常見)(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e152);關節痛、發燒、皮疹、漿膜炎、**抗組織蛋白抗體(anti-histone)陽性**,停藥可恢復 |
| 周邊神經炎 | 干擾維生素 B6(pyridoxine),可補充 |

**小心**:冠心病、僧帽瓣疾病、主動脈剝離(反射性心搏過速會加重)。

### Minoxidil {#minoxidil-ae}

| 副作用 | 說明 |
|---|---|
| **多毛症**(hypertrichosis) | 臉、手臂、背部毛髮增生;約八成長期使用者出現,停藥後數月消退;女性困擾大 |
| 嚴重**鈉水滯留、水腫** | 常需**環利尿劑**(見 [[loop-diuretics]]) |
| 反射性心搏過速、心絞痛 | 必須併用 β 阻斷劑 |
| **心包膜積液**、心包填塞 | 少見但嚴重(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e152) |

**禁忌**:嗜鉻細胞瘤。

### Nitroprusside {#nitroprusside-ae}

| 副作用 | 說明 |
|---|---|
| **低血壓** | 過量或滴速過快;停藥後 1–2 分鐘內回升 |
| **氰化物中毒** | 滴速 **≥ 3 µg/kg/min 和/或使用 ≥ 3 天**時風險上升(2025 AHA/ACC;部分仿單以 > 2 µg/kg/min 為警戒),肝功能差、CKD、硫不足時更易發生(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e182);表現:**代謝性酸中毒、乳酸上升**、靜脈血氧過高(組織無法利用氧)、意識改變、心律不整、**對藥物耐受(需要的劑量越來越高)**;處置:**停用 nitroprusside**,給 **sodium thiosulfate** 或 **hydroxocobalamin**(維生素 B12 的一種)(同上來源;亞硝酸鹽亦可) |
| **硫氰酸鹽中毒** | **腎功能不良**(肌酸酐 > 3)、使用數天以上(同上來源);耳鳴、視力模糊、**譫妄、意識混亂**、肌肉抽搐、癲癇;可測血中濃度,必要時透析 |
| 反射性心搏過速、頭痛、噁心、冒汗 | 血壓下降過快 |
| 甲狀腺功能低下 | 硫氰酸鹽抑制碘攝取(長期) |

**禁忌/小心**:**懷孕**(可通過胎盤造成胎兒氰化物中毒;2025 AHA/ACC COR 3:有害)、**急性腦血管疾病**(死亡率上升,除非沒有其他藥可用)、代償性高血壓(如主動脈縮窄、動靜脈分流)、嚴重肝腎功能不良、Leber 視神經病變、維生素 B12 缺乏;顱內壓上升者小心(腦血管擴張);老人需較低劑量(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e171、e174、e182)。

## 交互作用 {#interactions}

- 其他降壓藥、麻醉藥、利尿劑、酒精:加成低血壓。
- **PDE5 抑制劑**(sildenafil)+ nitroprusside(NO 供給者):嚴重低血壓,避免。
- NSAIDs:減弱 hydralazine、minoxidil 降壓效果、加重水鈉滯留。
- Hydralazine、minoxidil 常**刻意**與 β 阻斷劑和利尿劑合用。

## 護理重點與衛教 {#nursing}

### Nitroprusside {#nitroprusside-nursing}

- **避光**:藥液遇光分解(釋出氰化物、藥效降低)→ **以不透光錫箔紙或遮光袋包住點滴瓶(袋)與輸液管**;稀釋後藥液呈淡褐色屬正常,若變成**藍色、綠色或深紅色**表示已分解,**丟棄**。
- 只用 D5W 稀釋,**單獨一條管路**,不可與其他藥物混合或從此管路推藥。
- 一定使用**輸液幫浦**,從低劑量開始依血壓逐步調整(2025 AHA/ACC 表列:起始 0.3–0.5 µg/kg/min,每 5 分鐘加 0.5,最高 10 µg/kg/min,時間越短越好;僅供參考,以醫囑為準);藥效強,建議以**動脈導管**持續監測血壓,避免過度下降(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e182)。
- 避免血壓降太快、太多(見上方高血壓急症降壓速度);出現低血壓先減速或暫停,因半衰期極短,很快就回升。
- 監測**動脈血氣體與乳酸**(代謝性酸中毒)、意識、腎功能;使用超過 2–3 天或腎功能不良者監測**硫氰酸鹽**濃度。
- 儘量短期使用,血壓穩定後轉口服藥。

### Hydralazine {#hydralazine-nursing}

- 給藥前後量血壓與**心跳**;注意胸痛、心悸。
- 孕婦靜脈給藥:每 5–20 分鐘測血壓、持續胎心音監測,避免母親低血壓影響胎盤灌流。
- 長期口服:衛教類狼瘡症狀(關節痛、發燒、皮疹),必要時檢測抗核抗體;隨餐服用可增加吸收且較穩定。

### Minoxidil {#minoxidil-nursing}

- **每日量體重**、觀察水腫;體重數天內增加 > 1–2 公斤、呼吸困難、胸痛(心包膜積液)立即回診。
- 事先告知**多毛症**(可除毛,停藥後會慢慢消退),避免病人自行停藥。
- 與 β 阻斷劑、利尿劑一起規則服用。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **輸注 nitroprusside(Nipride)需以不透光錫箔紙包住點滴瓶及輸液管**(nitroglycerin 不需避光包覆,但要用非 PVC 管路)。
- 緊急降壓藥中**作用時間最短 → nitroprusside**(停藥 1–2 分鐘消失);毒性:**氰化物、硫氰酸鹽**。
- **長期服用 minoxidil → 多毛症**;注射 **diazoxide** 可治療高血壓危象(舊用法)。
- **Hydralazine**:孕婦可用的降壓藥(孕婦禁用的是 captopril);會造成**反射性心搏過速**;長期使用**類狼瘡**。
- 單純小動脈擴張劑要併用 β 阻斷劑 + 利尿劑。
:::
