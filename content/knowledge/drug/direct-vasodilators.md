## 重點摘要 {#summary}

- 直接放鬆**血管平滑肌**(不經由自主神經受體或 RAAS):hydralazine、minoxidil 主要擴張**小動脈**;nitroprusside **動靜脈都擴張**。
- **Hydralazine**:孕期急性重度高血壓用藥;副作用**反射性心搏過速、鈉水滯留、類狼瘡症候群**。
- **Minoxidil**:最強的口服血管擴張劑,用於頑固型高血壓;副作用**多毛症**、嚴重水腫、心包膜積液。
- **Nitroprusside**:**高血壓急症**靜脈滴注,數秒起效、停藥 1–2 分鐘消失;**避光**;注意**氰化物與硫氰酸鹽中毒**。
- 口服者常需併用 **β 阻斷劑(抵銷心搏過速)+ 利尿劑(抵銷水鈉滯留)**。

## 作用機轉 {#mechanism}

| 藥物 | 作用 | 擴張部位 |
|---|---|---|
| **Hydralazine** | 機轉未完全明瞭(影響平滑肌細胞內鈣離子釋放) | **小動脈**為主 |
| **Minoxidil** | 活性代謝物打開 **ATP 敏感性鉀通道** → 平滑肌過極化、放鬆 | **小動脈** |
| **Nitroprusside** | 在血中釋放 **一氧化氮(NO)** → 活化鳥苷酸環化酶、cGMP ↑ → 平滑肌放鬆 | **小動脈 + 靜脈**(後負荷與前負荷都下降) |
| Diazoxide | 打開鉀通道;同時抑制胰島素釋放 | 小動脈 |

**只擴張小動脈的後果**(hydralazine、minoxidil):血壓下降 → 壓力感受器反射(見 [[blood-pressure-regulation#baroreceptor]])→ **交感興奮(反射性心搏過速、心輸出量 ↑、心肌耗氧 ↑)** 與 **腎素分泌 ↑ → 鈉水滯留**。所以單用效果會被代償抵銷,且可能誘發心絞痛——這就是要「三合一」併用 β 阻斷劑與利尿劑的原因。

Nitroprusside 分子含 5 個**氰根(CN⁻)**:釋放 NO 時氰根也被釋出,由肝臟的 rhodanese 酵素利用硫(thiosulfate)轉成**硫氰酸鹽(thiocyanate)**,再由腎臟排出。劑量高或時間長時,硫來源耗盡 → **氰化物中毒**;腎衰竭時排不掉 → **硫氰酸鹽中毒**。

## 代表藥物 {#agents}

| 藥物 | 劑型 | 特色 |
|---|---|---|
| **Hydralazine**(Apresoline) | 口服、靜脈/肌肉注射 | 孕期重度高血壓(靜脈);口服與硝酸鹽(isosorbide dinitrate)合用於 HFrEF(無法使用 ACEI/ARB/ARNI 者) |
| **Minoxidil**(Loniten;外用 Regaine) | 口服;外用液 | 頑固型高血壓;**外用治療雄性禿**(利用多毛副作用) |
| **Nitroprusside**(Nipride) | **只能連續靜脈滴注** | 高血壓急症;作用最快也最短 |
| Diazoxide | 靜脈(舊)、口服 | 過去用於高血壓危象;口服用於胰島素瘤等**低血糖**(會升高血糖) |

## 適應症 {#indications}

- **頑固型高血壓**:hydralazine、minoxidil 作為多藥併用後的附加藥;2022 台灣指引與 2025 AHA/ACC 指引均非第一線(見 [[hypertension]])。
- **妊娠急性重度高血壓**(收縮壓 ≥ 160 或舒張壓 ≥ 110 mmHg 持續 15 分鐘以上):**靜脈 hydralazine**、靜脈 labetalol、口服速效 nifedipine 為第一線;目標是 15–60 分鐘內降下來,但不要降太低以免影響胎盤血流(監測胎心音)。
- **高血壓急症**(有急性標的器官傷害,例如高血壓腦病變、急性肺水腫、主動脈剝離):**nitroprusside** 以及 nicardipine、labetalol、esmolol、clevidipine 等靜脈藥物。一般原則(2025 AHA/ACC):**第 1 小時收縮壓下降不超過 25%**,之後 2–6 小時降到約 160/100 mmHg,24–48 小時再逐步正常化;**主動脈剝離**、嚴重子癲前症/子癇、嗜鉻細胞瘤危象則要更快更低(主動脈剝離 20 分鐘內收縮壓 < 120 mmHg)。
- **急性心衰竭/急性肺水腫合併高血壓**:nitroprusside 同時降前、後負荷(見 [[heart-failure]])。
- **HFrEF**:hydralazine + isosorbide dinitrate(見 [[nitrates]])。

### 常見靜脈降壓藥比較 {#iv-agents}

| 藥物 | 類別 | 起效 / 作用時間 | 重點 |
|---|---|---|---|
| **Nitroprusside** | NO 供給者 | 數秒 / **停藥 1–2 分鐘消失** | 最快最短;避光;氰化物毒性 |
| Nicardipine | DHP 類 CCB | 5–15 分鐘 / 數小時 | 見 [[calcium-channel-blockers]] |
| Labetalol | α1 + β 阻斷 | 5–10 分鐘 / 3–6 小時 | 孕婦可用;氣喘、心搏過緩避免(見 [[beta-blockers]]) |
| Esmolol | β1 阻斷 | 1–2 分鐘 / 10–30 分鐘 | 主動脈剝離、手術中 |
| Hydralazine | 直接血管擴張 | 10–20 分鐘 / 1–4 小時以上 | 孕婦;效果較難預測 |
| Nitroglycerin | 硝酸鹽 | 2–5 分鐘 / 5–10 分鐘 | 急性冠心症、肺水腫(見 [[nitrates]]) |
| Fenoldopam | 多巴胺 D1 致效劑 | 5–15 分鐘 / 30–60 分鐘 | 台灣少用 |

## 副作用與禁忌 {#adverse-effects}

### Hydralazine {#hydralazine-ae}

| 副作用 | 說明 |
|---|---|
| **反射性心搏過速**、心悸、**心絞痛** | 冠心病者小心;併用 β 阻斷劑 |
| 頭痛、臉潮紅 | 血管擴張 |
| 鈉水滯留、水腫 | 併用利尿劑 |
| **藥物誘發類狼瘡症候群** | 長期、高劑量(> 200 mg/天)、**慢乙醯化者**(acetylator)較常見;關節痛、發燒、皮疹、漿膜炎、**抗組織蛋白抗體(anti-histone)陽性**,停藥可恢復 |
| 周邊神經炎 | 干擾維生素 B6(pyridoxine),可補充 |

**小心**:冠心病、僧帽瓣疾病、主動脈剝離(反射性心搏過速會加重)。

### Minoxidil {#minoxidil-ae}

| 副作用 | 說明 |
|---|---|
| **多毛症**(hypertrichosis) | 臉、手臂、背部毛髮增生;約八成長期使用者出現,停藥後數月消退;女性困擾大 |
| 嚴重**鈉水滯留、水腫** | 常需**環利尿劑**(見 [[loop-diuretics]]) |
| 反射性心搏過速、心絞痛 | 必須併用 β 阻斷劑 |
| **心包膜積液**、心包填塞 | 少見但嚴重 |

**禁忌**:嗜鉻細胞瘤。

### Nitroprusside {#nitroprusside-ae}

| 副作用 | 說明 |
|---|---|
| **低血壓** | 過量或滴速過快;停藥後 1–2 分鐘內回升 |
| **氰化物中毒** | 高劑量(> 2 µg/kg/min)、長時間、肝功能差、硫不足時;表現:**代謝性酸中毒、乳酸上升**、靜脈血氧過高(組織無法利用氧)、意識改變、心律不整、**對藥物耐受(需要的劑量越來越高)**;解毒劑:**hydroxocobalamin**、**sodium thiosulfate**(亞硝酸鹽亦可) |
| **硫氰酸鹽中毒** | **腎功能不良**、使用數天以上;耳鳴、視力模糊、**譫妄、意識混亂**、肌肉抽搐、癲癇;可測血中濃度,必要時透析 |
| 反射性心搏過速、頭痛、噁心、冒汗 | 血壓下降過快 |
| 甲狀腺功能低下 | 硫氰酸鹽抑制碘攝取(長期) |

**禁忌/小心**:代償性高血壓(如主動脈縮窄、動靜脈分流)、嚴重肝腎功能不良、Leber 視神經病變、維生素 B12 缺乏;顱內壓上升者小心(腦血管擴張)。

## 交互作用 {#interactions}

- 其他降壓藥、麻醉藥、利尿劑、酒精:加成低血壓。
- **PDE5 抑制劑**(sildenafil)+ nitroprusside(NO 供給者):嚴重低血壓,避免。
- NSAIDs:減弱 hydralazine、minoxidil 降壓效果、加重水鈉滯留。
- Hydralazine、minoxidil 常**刻意**與 β 阻斷劑和利尿劑合用。

## 護理重點與衛教 {#nursing}

### Nitroprusside {#nitroprusside-nursing}

- **避光**:藥液遇光分解(釋出氰化物、藥效降低)→ **以不透光錫箔紙或遮光袋包住點滴瓶(袋)與輸液管**;稀釋後藥液呈淡褐色屬正常,若變成**藍色、綠色或深紅色**表示已分解,**丟棄**。
- 只用 D5W 稀釋,**單獨一條管路**,不可與其他藥物混合或從此管路推藥。
- 一定使用**輸液幫浦**,從低劑量開始依血壓逐步調整;**持續監測血壓**(通常放動脈導管,滴定初期每 1–5 分鐘)。
- 避免血壓降太快、太多(見上方高血壓急症降壓速度);出現低血壓先減速或暫停,因半衰期極短,很快就回升。
- 監測**動脈血氣體與乳酸**(代謝性酸中毒)、意識、腎功能;使用超過 2–3 天或腎功能不良者監測**硫氰酸鹽**濃度。
- 儘量短期使用,血壓穩定後轉口服藥。

### Hydralazine {#hydralazine-nursing}

- 給藥前後量血壓與**心跳**;注意胸痛、心悸。
- 孕婦靜脈給藥:每 5–20 分鐘測血壓、持續胎心音監測,避免母親低血壓影響胎盤灌流。
- 長期口服:衛教類狼瘡症狀(關節痛、發燒、皮疹),必要時檢測抗核抗體;隨餐服用可增加吸收且較穩定。

### Minoxidil {#minoxidil-nursing}

- **每日量體重**、觀察水腫;體重數天內增加 > 1–2 公斤、呼吸困難、胸痛(心包膜積液)立即回診。
- 事先告知**多毛症**(可除毛,停藥後會慢慢消退),避免病人自行停藥。
- 與 β 阻斷劑、利尿劑一起規則服用。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **輸注 nitroprusside(Nipride)需以不透光錫箔紙包住點滴瓶及輸液管**(nitroglycerin 不需避光包覆,但要用非 PVC 管路)。
- 緊急降壓藥中**作用時間最短 → nitroprusside**(停藥 1–2 分鐘消失);毒性:**氰化物、硫氰酸鹽**。
- **長期服用 minoxidil → 多毛症**;注射 **diazoxide** 可治療高血壓危象(舊用法)。
- **Hydralazine**:孕婦可用的降壓藥(孕婦禁用的是 captopril);會造成**反射性心搏過速**;長期使用**類狼瘡**。
- 單純小動脈擴張劑要併用 β 阻斷劑 + 利尿劑。
:::
