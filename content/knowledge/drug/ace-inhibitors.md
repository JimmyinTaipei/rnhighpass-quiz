## 重點摘要 {#summary}

- 抑制**血管收縮素轉換酶**(ACE)→ **Angiotensin II ↓、醛固酮 ↓**,同時 **bradykinin 分解 ↓(濃度 ↑)** → 血管擴張、排鈉。
- 用途:高血壓第一線、**心衰竭(HFrEF)**、心肌梗塞後、**糖尿病/慢性腎臟病合併蛋白尿(腎臟保護)**。
- 副作用:**乾咳**、**血管性水腫**、**高血鉀**、首劑低血壓、腎功能暫時下降。
- 禁忌:**懷孕**、曾發生血管性水腫、**雙側腎動脈狹窄**;不可與 ARB/aliskiren 合併。
- 護理:追蹤血壓、**血鉀、肌酸酐**;避免鉀補充劑與代鹽;育齡女性須避孕。

## 作用機轉 {#mechanism}

腎素把肝臟製造的血管張力素原(angiotensinogen)切成 angiotensin I,再由主要位於**肺臟微血管內皮**的 ACE 轉成 **angiotensin II**(生理見 [[blood-pressure-regulation#raas]])。ACEI 阻斷這一步:

| 結果 | 效應 |
|---|---|
| Angiotensin II ↓ | 小動脈與靜脈擴張 → 周邊阻力(後負荷)與前負荷下降;交感活性 ↓;抑制心臟與血管重塑(remodeling) |
| **醛固酮 ↓** | 排鈉排水 ↑、**保鉀**(血鉀上升) |
| **Bradykinin ↑** | ACE 同時是分解 bradykinin 的酵素(kininase II);bradykinin 堆積 → 額外的血管擴張,但也造成**乾咳、血管性水腫** |
| 腎絲球出球小動脈擴張 | 腎絲球內壓 ↓ → **蛋白尿 ↓**、延緩腎病變;代價是 GFR 會小幅下降 |

- 與 ARB 的差別:ARB 在受體端阻斷,**不影響 bradykinin**,所以乾咳少(見 [[arb#mechanism]])。
- 與 aliskiren 的差別:aliskiren 是**直接腎素抑制劑**,阻斷 angiotensinogen → angiotensin I。
- 長期使用可能出現「醛固酮逃脫」(aldosterone escape):醛固酮又慢慢回升,這是心衰竭要再加 MRA(見 [[potassium-sparing-diuretics]])的原因之一。

各類降壓藥作用位置總覽見 [[blood-pressure-regulation#drug-sites]]。

## 代表藥物 {#agents}

字尾 **-pril**。

| 藥物 | 特色 |
|---|---|
| **Captopril**(Capoten) | 最早的 ACEI;作用快、半衰期短,**一天 2–3 次**;食物降低吸收,**飯前 1 小時空腹**服用;含硫氫基(-SH),味覺改變、皮疹、白血球減少較常見;舊時用於高血壓急迫症舌下/口服 |
| **Enalapril** | 前驅藥(prodrug),經肝臟活化成 enalaprilat;enalaprilat 有靜脈劑型 |
| **Lisinopril** | 非前驅藥、不經肝代謝,原型由腎排除;一天一次 |
| Ramipril、Perindopril、Imidapril、Fosinopril | 一天一次;有心血管保護試驗證據(ramipril、perindopril) |

除 captopril、lisinopril 外,多數為前驅藥;除 fosinopril 等少數外主要經腎排除,**腎功能差需調整劑量**。

## 適應症 {#indications}

- **高血壓**:2022 台灣指引與 2025 AHA/ACC 指引都列為第一線藥物(與 ARB、CCB、thiazide 類並列);特別適合合併**糖尿病、慢性腎臟病(有蛋白尿)、心衰竭、心肌梗塞後**者(見 [[hypertension]])。
- **心衰竭(HFrEF)**:降低死亡與住院;現行指引優先使用 ARNI,無法使用時用 ACEI(或 ARB)(見 [[heart-failure]]、[[arni]])。
- **急性心肌梗塞後**,特別是 LVEF ≤ 40%、前壁梗塞、合併高血壓或糖尿病者:抑制心室重塑。
- **糖尿病腎病變、慢性腎臟病合併白蛋白尿**:降低蛋白尿([[uacr]])、延緩腎功能惡化——這是「糖尿病高血壓病人首選 ACEI/ARB」的依據。

:::tip[為什麼糖尿病合併高血壓常選 ACEI]
ACEI 降低腎絲球內壓、減少蛋白尿,且**不影響血糖與血脂**;相對地非選擇性 β 阻斷劑會遮蔽低血糖症狀,thiazide 高劑量可能升高血糖。
:::

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 機轉/說明與處置 |
|---|---|
| **乾咳** | 最常見(約 5–20%);**bradykinin 與 substance P 堆積**刺激呼吸道;持續性、無痰、夜間明顯;與劑量無關,**止咳藥效果差**,停藥後 1–4 週消失 → **改用 ARB** |
| **血管性水腫**(angioedema) | 少見但可致命;bradykinin 使血管通透性 ↑ → 嘴唇、舌頭、臉、喉頭腫脹,可阻塞呼吸道;可發生在用藥數年後;**立即停藥、評估呼吸道**,必要時插管;腎上腺素、抗組織胺與類固醇效果有限(不是組織胺引起)。曾發生者**終身禁用** ACEI |
| **高血鉀** | 醛固酮 ↓ → 腎臟排鉀減少;腎功能差、糖尿病、老人、併用保鉀利尿劑/鉀補充劑/NSAID 時風險高(見 [[potassium]]) |
| **首劑低血壓** | 開始用藥或加量時,特別是**已用利尿劑、脫水、低血鈉、心衰竭**者(RAAS 被高度活化);由低劑量開始、首劑後臥床觀察 |
| 腎功能下降 | 出球小動脈擴張 → GFR 小幅下降,**肌酸酐上升 < 30% 屬可接受**;上升更多要找原因(脫水、腎動脈狹窄) |
| 味覺改變、皮疹、白血球減少 | 多見於 captopril |
| **胎兒毒性** | 懷孕中後期影響胎兒腎臟 → 胎兒腎衰竭、**羊水過少**、顱骨發育不全、肺發育不全、生長遲滯甚至死亡 |

**禁忌**

- **懷孕**(發現懷孕立即停藥改藥);育齡女性須衛教避孕並告知計畫懷孕。
- 曾因 ACEI 或遺傳性血管性水腫發作者。
- **雙側腎動脈狹窄**(或獨腎的腎動脈狹窄):此時腎絲球過濾靠 angiotensin II 收縮出球小動脈維持,阻斷後會**急性腎衰竭**。
- 高血鉀。
- 與 **ARB 或 aliskiren 合併**(糖尿病或腎病者禁用 aliskiren 併用);與 **ARNI 需間隔 36 小時**。

## 交互作用 {#interactions}

| 併用 | 結果 |
|---|---|
| 保鉀利尿劑(spironolactone、amiloride)、鉀補充劑、**低鈉鹽/代鹽**(含 KCl)、trimethoprim、heparin | **高血鉀** |
| **ARB、aliskiren**(雙重 RAAS 阻斷) | 高血鉀、低血壓、急性腎損傷,且沒有額外好處 → 不併用 |
| **Sacubitril/valsartan**(ARNI) | 血管性水腫 → 由 ACEI 換成 ARNI 需**停 ACEI 36 小時**後才開始 |
| **NSAIDs** | 降壓效果減弱;與利尿劑三者合用(triple whammy)易急性腎損傷 |
| 利尿劑 | 加成降壓;首劑低血壓風險 ↑(可先減利尿劑劑量) |
| **鋰鹽** | 鋰排除減少 → **血鋰上升、鋰中毒** |
| 胰島素、口服降血糖藥 | ACEI 可能增加胰島素敏感性,偶有低血糖 |

## 護理重點與衛教 {#nursing}

- **給藥前量血壓**;首劑或加量後觀察姿勢性低血壓,起身動作放慢。
- 開始用藥或加量後 1–2 週**抽血追蹤血鉀與肌酸酐**,之後定期追蹤。
- 飲食:一般**不需額外補鉀**,避免高鉀代鹽、鉀補充劑;腎功能差者限制高鉀食物(香蕉、柳丁、楊桃另有神經毒素)。
- Captopril 飯前 1 小時空腹服用;其他多數不受食物影響。
- 出現**嘴唇、舌頭、臉部腫脹或吞嚥、呼吸困難**時停藥並立即就醫。
- 乾咳是常見副作用,不要自行停藥,回診與醫師討論改 ARB。
- 育齡女性:避孕;發現懷孕立即回診換藥。
- 腹瀉、嘔吐、脫水時(sick day)依醫囑暫停 ACEI,避免急性腎損傷與低血壓。
- 不自行服用 NSAIDs 止痛藥。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 機轉:「抑制 angiotensin I 轉換成 angiotensin II」→ captopril 等 **-pril**;**Angiotensin II 與醛固酮都下降**,**bradykinin 增加**(「減少 bradykinin 濃度」是錯的)。
- ACEI 用於心衰竭:降低血管阻力、減少鈉水滯留、抑制交感活性;**losartan 不是 ACEI**(是 ARB)。
- **乾咳**是 ACEI(captopril)的典型副作用——bradykinin 堆積。
- ACEI 造成**高血鉀**,不是低血鉀;ACEI 與醛固酮拮抗劑都是高血鉀的原因。
- 慢性腎臟病/糖尿病:ACEI **可減少蛋白尿**,是糖尿病高血壓病人較適合的藥。
- **孕婦禁用** captopril(ACEI 與 ARB 皆禁);孕期可用 labetalol、nifedipine、methyldopa、hydralazine。
- ACEI 會使**血鋰濃度上升**(與 NSAIDs、thiazide 同)。
- 腎素抑制劑是 **aliskiren**,不是 ACEI。
:::
