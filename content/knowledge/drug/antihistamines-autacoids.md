**自泌素(autacoids)**是細胞局部製造、在**附近**作用、**半衰期很短**的生理活性物質，包括**組織胺、血清胺(5-HT)、前列腺素與白三烯、緩激肽**等。藥理學把「抗組織胺」與這些物質的藥物放在一起。這一頁依序說明組織胺受體、**H1 拮抗劑(抗過敏用藥)**、**前列腺素與白三烯相關藥物**，以及**血清胺相關藥物**

## 重點摘要 {#summary}

- **H1 拮抗劑**用於**過敏性鼻炎、蕁麻疹、動暈症、搔癢**；**第一代**鎮靜與抗膽鹼作用明顯，**第二代**較少鎮靜(見 [[cholinergic-drugs#antimuscarinics]])
- **H1 拮抗劑不能治療**：**胃潰瘍**(要用 H2 拮抗劑或質子幫浦抑制劑)、**心絞痛**
- **前列腺素與凝血脂素**由**花生四烯酸經 COX** 合成；**aspirin、NSAID** 抑制 COX；**celecoxib** 選擇抑制 **COX-2**
- **白三烯**造成**支氣管收縮**；**montelukast** 等阻斷其受體，詳見呼吸道用藥
- **triptan** 激動 **5-HT1B／1D** 治療偏頭痛；**麥角生物鹼**收縮血管並引起子宮收縮

### 國考常考點 {#exam-points}

- **Fexofenadine、loratadine** **較不嗜睡**：**不易通過血腦障壁**
- **Diphenhydramine**：口服吸收良好，**會通過血腦障壁**(有中樞作用，鎮靜)，可改善過敏、蕁麻疹、**動暈症**，也有**抗膽鹼**作用
- 第一代 H1 拮抗劑的副作用：**嗜睡、口乾、視力模糊、尿滯留、便秘**；**青光眼、攝護腺肥大、老年人慎用**
- **H1 拮抗劑的用途**：過敏、**動暈症(暈車暈船)**、噁心嘔吐、失眠；**不是**心絞痛、胃潰瘍
- **低劑量 aspirin** 抑制**血小板的凝血脂素 A2(TXA2)**，減少血栓；**TXA2** 使血管收縮與血小板聚集
- **Celecoxib** 抑制 **COX-2**，減少**前列腺素**合成，胃腸出血較少
- **PGE1(alprostadil)**：維持**動脈導管**開放，用於**導管依賴型先天性心臟病**(例如大血管轉位)，**副作用呼吸暫停**要監測；**PGE2(dinoprostone)陰道栓劑**用於**子宮頸成熟與引產**，要監測**子宮收縮**
- **Alprostadil** 也用於男性**勃起功能障礙**；**Epoprostenol(PGI2)** 用於**肺動脈高壓**
- **麥角生物鹼(ergotamine)**：血管收縮、**引起子宮收縮**，偏頭痛治療；**sumatriptan** 是 **5-HT1B／1D 激動劑**
- **Lorcaserin** 刺激 **5-HT2C** 受體抑制食慾(已因安全疑慮退出美國市場)

## 組織胺 {#histamine}

### 來源與受體 {#histamine-receptors}

1. 由**組胺酸**經**組胺酸脫羧酶**合成，主要儲存在**肥大細胞與嗜鹼性球**的顆粒；也存在於**胃的腸嗜鉻樣細胞**與神經元
2. 受體

| 受體 | 位置 | 主要作用 | 藥物 |
|---|---|---|---|
| **H1** | 血管內皮與平滑肌、支氣管與腸道平滑肌、感覺神經、**中樞神經** | **血管擴張與通透性上升**(風疹塊、水腫、低血壓)、**支氣管與腸道平滑肌收縮**、**搔癢**、中樞維持**覺醒** | **H1 拮抗劑**(抗過敏用藥) |
| **H2** | **胃壁細胞**、心臟 | **增加胃酸分泌**、心跳加快 | **H2 拮抗劑**(cimetidine、famotidine 等，消化道用藥) |
| **H3** | 中樞神經突觸前 | 調節組織胺釋出 | — |
| **H4** | 免疫細胞 | 趨化 | — |

3. 過敏反應的組織胺作用由 **H1** 主導，所以治療用 **H1 拮抗劑**，見 [[hypersensitivity-reactions#type-1]]
4. 組織胺**不能**被 H1 拮抗劑阻斷的作用：**H2 引起的胃酸分泌**

## H1 拮抗劑(抗組織胺) {#h1-blockers}

**H1 拮抗劑**實際上是**反向激動劑**，穩定受體的不活化型，阻止組織胺作用；**不阻止組織胺釋出**，所以**預防**比發作後使用效果好。

### 第一代與第二代 {#generations}

| | **第一代** | **第二代** |
|---|---|---|
| 藥物 | **diphenhydramine**、**chlorpheniramine**、**brompheniramine**、**hydroxyzine**、**promethazine**、**dimenhydrinate**、**cyproheptadine** | **loratadine**、**desloratadine**、**cetirizine**、**levocetirizine**、**fexofenadine**、ebastine、bilastine |
| 血腦障壁 | **容易通過** | **較難通過**(**fexofenadine 最少**) |
| 鎮靜 | **明顯**(**嗜睡、注意力與反應變差**) | **輕微**(**cetirizine 稍多**) |
| **抗膽鹼作用** | **明顯**(口乾、便秘、尿滯留、視力模糊、心搏過速) | **少** |
| 作用時間 | 較短(4–6 小時，需多次給藥) | 較長(約 **12–24 小時**，每日一次) |
| 選擇性 | 也阻斷毒蕈鹼、α、血清胺受體 | **對 H1 選擇性高** |

1. **terfenadine、astemizole**(早期第二代)因**QT 延長與尖端扭轉型心室頻脈**已退出市場，說明第二代藥物仍要留意心臟副作用與藥物交互作用
2. 臨床選擇
   1. **過敏性鼻炎、慢性蕁麻疹**：**第二代為首選**
   2. **老年人**：避免第一代(跌倒、意識混亂、尿滯留)
   3. **嚴重過敏反應**(過敏性休克)：**主藥是腎上腺素**，抗組織胺只處理殘餘搔癢與蕁麻疹，見 [[anaphylaxis]]

### 治療用途 {#h1-uses}

| 用途 | 說明 |
|---|---|
| **過敏性鼻炎、結膜炎** | 打噴嚏、流鼻水、搔癢，對鼻塞較差，見 [[allergic-rhinitis]] |
| **蕁麻疹、搔癢** | 蕁麻疹的**第一線**，見 [[urticaria-angioedema]] |
| **動暈症、暈車暈船** | **第一代**(diphenhydramine、dimenhydrinate、promethazine)因為**抗膽鹼與中樞作用**；**預防**效果好，要**出發前先服用** |
| **噁心嘔吐、眩暈** | promethazine 等，有止吐效果 |
| **失眠、鎮靜** | 第一代(diphenhydramine、hydroxyzine)短期用於**助眠與焦慮**，不建議長期使用 |
| **輔助** | 過敏性休克後殘餘症狀、輸血過敏反應的預防或治療 |

**H1 拮抗劑不適用**：
1. **胃潰瘍、胃酸過多**：那是 **H2 拮抗劑**與質子幫浦抑制劑的適應症
2. **心絞痛**：與組織胺無關
3. **氣喘急性發作**：效果不佳，不能取代支氣管擴張劑

### 不良反應與護理 {#h1-nursing}

1. **嗜睡**：**服藥期間不要開車、操作機械**、**避免酒精與其他中樞抑制劑**(增強鎮靜)
2. **抗膽鹼作用**：**口乾**(多喝水、無糖口香糖)、**便秘**、**尿滯留**、**視力模糊**、**心搏過速**；**青光眼(尤其閉鎖角)、攝護腺肥大、氣喘**慎用
3. **老年人**：易**意識混亂與跌倒**，避免第一代
4. **皮膚試驗前**要**停用**抗組織胺(會抑制風疹塊反應)，見 [[hypersensitivity-reactions#testing]]
5. **過量**：**鎮靜、抗膽鹼症候群**(口乾、散瞳、發燒、激動)，兒童特別容易
6. **懷孕與哺乳**：依醫囑，優先選擇資料較充分的藥物

## 肥大細胞穩定劑 {#mast-cell-stabilizers}

1. **Cromolyn(色甘酸鈉)**：穩定肥大細胞膜，**抑制去顆粒**，**預防用**，**不能治療急性發作**
2. 用於過敏性鼻炎、過敏性結膜炎、輕度氣喘的預防；**要在接觸過敏原前規則使用**
3. 其他呼吸道用藥(β2 促進劑、茶鹼、類固醇、白三烯拮抗劑等)見 [[asthma-drugs]]

## 前列腺素與白三烯 {#eicosanoids}

### 合成與作用 {#eicosanoid-synthesis}

1. **磷脂質**經**磷脂酶 A2** 釋出**花生四烯酸**，之後兩條路：
   1. **環氧合酶(COX)**路徑 → **前列腺素(PGE2、PGF2α、PGI2)**與**凝血脂素 A2(TXA2)**
   2. **脂氧合酶(5-LOX)**路徑 → **白三烯**(LTB4 趨化、**LTC4／D4／E4** 為半胱胺醯白三烯，**造成支氣管收縮與通透性上升**)
2. 主要作用

| 物質 | 主要作用 |
|---|---|
| **PGE2** | 發炎、發燒、疼痛敏感化；**子宮頸成熟**；保護**胃黏膜**；**維持動脈導管開放** |
| **PGI2(前列環素)** | **血管擴張**、**抑制血小板聚集** |
| **TXA2** | **血管收縮**、**血小板聚集**(與 PGI2 作用相反) |
| **PGF2α** | **子宮平滑肌收縮**、降眼壓(青光眼) |
| **LTC4／D4／E4** | **支氣管收縮**、血管通透性上升(氣喘) |
| **LTB4** | **趨化**嗜中性球 |

3. **NSAID 與 aspirin** 抑制 COX(因此減少 PGE2 與 TXA2)，見 [[nsaids-acetaminophen]]；**aspirin 低劑量**主要抑制血小板 **TXA2**，見 [[antiplatelets]]
4. **Celecoxib** 選擇性抑制 **COX-2**
5. **阿斯匹靈誘發氣喘**：COX 被抑制後，花生四烯酸偏向 **5-LOX** 路徑，**白三烯增加**

### 前列腺素類藥物 {#prostaglandin-drugs}

| 藥物 | 類型 | 用途與重點 |
|---|---|---|
| **Alprostadil**(PGE1) | 注射 | **維持動脈導管開放**：用於**導管依賴型先天性心臟病**(例如**大血管轉位**、肺動脈閉鎖等)，**副作用呼吸暫停、發燒、低血壓**，需**監測呼吸**；**海綿體注射**用於**勃起功能障礙** |
| **Misoprostol**(PGE1 類似物) | 口服 | **預防 NSAID 引起的胃潰瘍**；**懷孕婦女禁用**(會引起子宮收縮) |
| **Dinoprostone**(PGE2) | 陰道栓劑、凝膠 | **子宮頸成熟與引產**；使用後要**監測子宮收縮與胎心**，**過度收縮**要處理 |
| **Carboprost**(PGF2α 衍生物) | 肌肉注射 | **產後出血**(子宮收縮乏力)；氣喘者慎用 |
| **Epoprostenol**(PGI2) | 靜脈輸注 | **肺動脈高壓**，半衰期極短，**不可中斷** |
| **Latanoprost**(PGF2α 類似物) | 眼藥水 | **青光眼降眼壓** |

1. **NSAID(例如 indomethacin、ibuprofen)**用於**關閉動脈導管**(早產兒開放性動脈導管)；**PGE1 則是打開**，兩者作用相反
2. 與 NSAID、aspirin 的作用與副作用相反，所以**PGE 與 NSAID 不是同類藥物**

## 血清胺(5-HT)相關藥物 {#serotonin-drugs}

1. **血清胺**作用於多種 5-HT 受體：**5-HT1B／1D**(腦血管收縮)、**5-HT2A**(血管與平滑肌、致幻)、**5-HT2C**(食慾抑制)、**5-HT3**(嘔吐中樞與腸道，**化療引起嘔吐**)、**5-HT4**(腸道蠕動)
2. 藥物

| 藥物 | 受體與作用 | 重點 |
|---|---|---|
| **Sumatriptan**(triptan) | **5-HT1B／1D 激動劑**，使腦血管收縮、抑制神經發炎 | **偏頭痛急性發作**；**冠心病、高血壓未控制者禁用**(血管收縮) |
| **麥角生物鹼**(ergotamine) | 5-HT、α 與多巴胺受體的部分激動 | **血管收縮**(偏頭痛、**不可與 CYP3A4 抑制劑併用**)、**子宮收縮**(產後出血)；**過量造成肢體缺血(麥角中毒)**，**孕婦禁用** |
| **Ondansetron** | **5-HT3 拮抗劑** | 化療與術後**噁心嘔吐**；**QT 延長**，見消化與腫瘤護理 |
| **Lorcaserin** | **5-HT2C 激動劑** | 抑制食慾減重(已退出美國市場) |
| **SSRI** | 抑制**血清胺再回收** | 憂鬱與焦慮，見 [[antidepressants]]；**血清胺症候群**要警覺 |

## 緩激肽 {#bradykinin}

1. 緩激肽使**血管擴張、通透性上升、疼痛**
2. **ACE 抑制劑**阻止緩激肽分解，造成**乾咳**與**血管性水腫**([[ace-inhibitors]]、[[urticaria-angioedema#acei]])
3. **icatibant** 阻斷緩激肽受體，用於**遺傳性血管性水腫**
