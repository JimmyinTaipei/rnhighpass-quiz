## 重點摘要 {#summary}

- 阻斷 **L 型鈣離子通道** → 血管平滑肌放鬆(**DHP 類**,如 nifedipine、amlodipine),或同時抑制心臟傳導與收縮(**非 DHP 類**:verapamil、diltiazem)。
- 用途:高血壓第一線、心絞痛(**變異型心絞痛首選**)、非 DHP 類用於心房顫動心率控制與 PSVT;nifedipine 也用於妊娠高血壓與安胎。
- DHP 副作用:**頭痛、臉潮紅、反射性心搏過速、下肢水腫、牙齦增生**;非 DHP:**心搏過緩、房室傳導阻滯、便秘**。
- **葡萄柚汁**抑制代謝使血中濃度上升;verapamil/diltiazem **與 β 阻斷劑併用**易嚴重心搏過緩。
- 長效劑型不可咬碎;非 DHP 類避免用於 HFrEF。

## 作用機轉 {#mechanism}

血管平滑肌與心肌收縮都需要鈣離子經 **L 型鈣通道**進入細胞;竇房結與房室結的去極化(動作電位第 0 期)也主要靠鈣離子內流(見 [[cardiac-output#conduction]])。CCB 阻斷這些通道:

| 作用部位 | 效果 | 哪一類為主 |
|---|---|---|
| **小動脈平滑肌** | 血管擴張 → 周邊阻力(後負荷)↓、血壓 ↓;冠狀動脈擴張、**解除痙攣** | DHP(對血管選擇性高) |
| 心肌 | 收縮力 ↓(負收縮) → 耗氧 ↓ | 非 DHP |
| 竇房結、**房室結** | 心跳變慢、房室傳導變慢 → 控制心室速率 | 非 DHP(verapamil > diltiazem) |

- CCB 主要擴張**動脈**,對靜脈影響小,因此姿勢性低血壓較少,但**微血管前小動脈擴張**會讓液體滲到組織 → 下肢水腫。
- DHP 類快速降壓 → 壓力感受器反射(見 [[blood-pressure-regulation#baroreceptor]])→ **反射性心搏過速**;短效 nifedipine 最明顯,amlodipine 等長效者較少。
- 心肌耗氧量 ↓(後負荷 ↓;非 DHP 另有心跳 ↓、收縮力 ↓)→ 抗心絞痛(見 [[coronary-circulation#oxygen-demand]])。

## 代表藥物 {#agents}

### Dihydropyridine 類(DHP,-dipine) {#dhp}

| 藥物 | 特色 |
|---|---|
| **Nifedipine**(Adalat) | 短效膠囊作用快、反射性心搏過速明顯;**長效錠**(GITS/OROS/XL)一天一次,**不可咬碎或剝半**;妊娠高血壓與**安胎**(抑制子宮收縮) |
| **Amlodipine**(Norvasc) | 半衰期 30–50 小時,一天一次,作用平穩;下肢水腫常見 |
| Felodipine | 受**葡萄柚汁**影響最大 |
| **Nicardipine**(Perdipine) | **靜脈滴注**,用於高血壓急症、急性中風與術後血壓控制 |
| **Nimodipine** | 容易進入腦部;**蜘蛛網膜下腔出血後預防腦血管痙攣**(不是一般降壓藥) |
| Clevidipine | 超短效靜脈劑型(台灣較少) |

### 非 DHP 類 {#non-dhp}

| 藥物 | 特色 |
|---|---|
| **Verapamil**(Isoptin) | 對心臟作用最強;PSVT、心房顫動心率控制;**便秘最明顯**;會提高 digoxin 濃度 |
| **Diltiazem**(Herbesser) | 介於兩者之間;心絞痛、心房顫動心率控制(有靜脈劑型) |

## 適應症 {#indications}

- **高血壓**:第一線(2022 台灣指引、2025 AHA/ACC 指引,使用**長效** DHP);老人、單純收縮期高血壓效果好;常與 ACEI/ARB 做成複方(見 [[hypertension]])。
- **心絞痛**:穩定型心絞痛(β 阻斷劑無法使用或效果不足時);**變異型(Prinzmetal)心絞痛——冠狀動脈痙攣——首選 CCB**(β 阻斷劑可能讓 α 受體作用相對增強而加重痙攣)(見 [[coronary-artery-disease]])。
- **心律不整**(verapamil、diltiazem):PSVT 終止與預防、心房顫動/撲動的心室速率控制。
- **妊娠高血壓**:口服 nifedipine 與 labetalol 並列第一線;也可用於急性重度高血壓。
- **安胎**:nifedipine(Adalat)抑制子宮平滑肌收縮(屬 CCB,不是 α 或 β 阻斷劑)。
- **蜘蛛網膜下腔出血**:nimodipine。
- 其他:雷諾氏現象(DHP)。

:::warning[短效 nifedipine 舌下給藥]
國考題仍出現「nifedipine S.L. STAT」「nifedipine SL Q6H PRN」的給藥判讀(SL = 舌下含服;Q6H PRN = 需要時給、兩次至少間隔 6 小時)。但臨床上**短效 nifedipine 舌下/咬破給藥可能使血壓驟降,引發中風或心肌缺血**,現行指引不建議用於高血壓急迫症,急性冠心症也應避免。作答依題意,臨床依醫囑並密切監測血壓。
:::

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 機轉/說明 | 哪一類 |
|---|---|---|
| **頭痛、臉潮紅、頭暈** | 血管擴張 | DHP |
| **反射性心搏過速**、心悸 | 血壓驟降 → 壓力感受器反射;可能誘發心絞痛 | DHP(短效 nifedipine 最明顯) |
| **下肢(腳踝)水腫** | 小動脈擴張、微血管靜水壓 ↑;**不是鈉水滯留,利尿劑效果差**,併用 ACEI/ARB 或減量可改善 | DHP(劑量相關) |
| **牙齦增生** | nifedipine 最常見;加強口腔衛生、定期看牙 | DHP |
| **心搏過緩、房室傳導阻滯** | 抑制竇房結與房室結 | 非 DHP |
| 心衰竭惡化 | 負收縮作用 | 非 DHP |
| **便秘** | 抑制腸道平滑肌收縮 | 非 DHP(**verapamil 最明顯**),DHP 也可發生 |
| 低血壓 | 過量或併用其他降壓藥 | 兩類 |

**禁忌或避免**

- 非 DHP:**HFrEF**、病竇症候群、**二度以上房室傳導阻滯**(未裝節律器)、低血壓、心房顫動合併 **WPW 症候群**(加速旁路傳導)。
- 短效 nifedipine:急性心肌梗塞、不穩定型心絞痛(反射性心搏過速增加耗氧)。
- DHP 在 HFrEF:amlodipine、felodipine 可安全用於降壓,但對心衰竭無益。

## 交互作用 {#interactions}

| 併用 | 結果 |
|---|---|
| **葡萄柚(汁)** | 抑制腸道與肝臟 **CYP3A4** → CCB 血中濃度 ↑ → 低血壓、心搏過速/過緩;felodipine、nifedipine 最明顯,amlodipine 較小。效果可持續 24 小時以上,**服藥期間避免食用**,不是間隔幾小時就好 |
| **β 阻斷劑 + verapamil/diltiazem** | 雙重抑制竇房結與房室結 → **嚴重心搏過緩、房室傳導阻滯、心衰竭**;靜脈同時給藥尤其危險。DHP 與 β 阻斷劑則是好組合(β 阻斷劑抵銷反射性心搏過速) |
| **Digoxin + verapamil** | Digoxin 濃度 ↑ 加上房室結抑制 → 毛地黃中毒、心搏過緩(見 [[digoxin]]) |
| CYP3A4 抑制劑(clarithromycin、azole 抗黴菌藥、HIV 蛋白酶抑制劑) | CCB 濃度 ↑ |
| CYP3A4 誘導劑(rifampin、carbamazepine、phenytoin) | CCB 濃度 ↓ |
| Verapamil/diltiazem 抑制 CYP3A4 | 使 simvastatin(肌肉病變)、cyclosporine 等濃度 ↑ |
| **硫酸鎂 + nifedipine** | 孕婦同時使用可能加成低血壓與神經肌肉阻斷,需監測 |
| 其他降壓藥、硝酸鹽、酒精 | 加成低血壓 |

## 護理重點與衛教 {#nursing}

- **給藥前量血壓與脈搏**;非 DHP 類量心尖脈,心跳 < 50–60 次/分或出現房室阻滯依醫囑暫停並通知醫師。
- **長效/緩釋錠整顆吞服,不可咬碎、剝半或打開**;緩釋錠外殼可能在糞便中看到(藥已釋出),不必緊張。
- 每天固定時間服用;因檢查禁食(NPO)錯過每日一次的降壓藥,**恢復進食、生命徵象穩定後依醫囑補給**。
- **避免葡萄柚與葡萄柚汁**(也包括柚類、酸橙等含 furanocoumarin 的水果)。
- 觀察下肢水腫(每日體重、腳踝),與心衰竭水腫區分:CCB 水腫不伴隨體重快速上升、呼吸困難或頸靜脈怒張。
- 刷牙用軟毛牙刷、牙線,定期看牙醫(牙齦增生)。
- 便秘:多喝水、高纖飲食、活動;必要時用軟便劑。
- 起身慢;頭痛、潮紅多在用藥初期,會漸改善。
- 靜脈 nicardipine:輸液幫浦給藥、密切監測血壓(急性期不可降太快,見 [[hypertension]])、注意靜脈炎,輸注部位要常更換。
- 孕婦用 nifedipine 安胎或降壓:監測母親血壓、心跳與胎心音。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **Adalat = nifedipine = 鈣離子阻斷劑**(不是 α 阻斷劑),可降壓、安胎、用於妊娠高血壓;**孕婦可用**,禁用的是 captopril 等 ACEI。
- **葡萄柚汁會干擾 CCB 在肝臟的代謝**(CYP3A4)→ 濃度上升。
- **CCB 會造成便秘**(與鐵劑、鴉片類並列)。
- Amlodipine、prazosin、hydralazine 都可能**反射性心搏過速**;atenolol 不會(反而心搏過緩)。
- 冠心病降低心肌耗氧量的藥:β 阻斷劑、硝酸鹽、**CCB**;低劑量 aspirin 是抗血小板,不降低耗氧。
- Verapamil 可治療 PSVT;verapamil/diltiazem **與 β 阻斷劑併用 → 心搏過緩、傳導阻滯**。
- 醫囑判讀:**S.L. = 舌下含服**;SL Q6H PRN if SBP > 170 = 收縮壓 > 170 時給一次,再次給藥至少間隔 6 小時。
- 變異型心絞痛(冠狀動脈痙攣)首選 CCB;nimodipine 用於蜘蛛網膜下腔出血。
:::
