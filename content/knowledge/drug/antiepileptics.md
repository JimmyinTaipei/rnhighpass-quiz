**抗癲癇藥**（新名稱是抗發作藥物）用來減少神經元的異常同步放電，預防癲癇發作。多數病人要長期甚至終身服藥，所以護理重點在**規律服藥、監測血中濃度與副作用、不可自行停藥**。癲癇的分類、發作時的照護與熱性痙攣之後在 G 組癲癇頁整理；精神科用的情緒穩定劑（valproate、carbamazepine、lamotrigine）見 [[mood-stabilizers]]

## 重點摘要 {#summary}

- 作用機轉：**阻斷電位門控 Na⁺ 通道**（phenytoin、carbamazepine、lamotrigine）、**阻斷 T 型 Ca²⁺ 通道**(ethosuximide)、**增強 GABA**（benzodiazepine、phenobarbital、valproate）、結合 **SV2A**(levetiracetam)、**減少麩胺酸作用**（topiramate、perampanel）；**不作用在正腎上腺素受體**
- **Phenytoin(Dilantin)**：治療濃度 **10–20 mcg/mL**；副作用**牙齦增生**、多毛、眼球震顫、複視、運動失調、皮疹(SJS)、骨質疏鬆；靜脈只能用**生理食鹽水**稀釋、**慢速**推注
- **Carbamazepine**：Na⁺ 通道，治療**局部發作**與**三叉神經痛**；台灣人用藥前檢驗 **HLA-B\*1502**，預防史蒂芬強生症候群
- **Valproate**：廣效；肝毒性、胰臟炎、血小板低下、體重增加、**致畸胎（神經管缺陷）**
- **Ethosuximide**：**只用在失神發作**（T 型 Ca²⁺ 通道）
- 用藥原則：**單一藥物、從低劑量開始**慢慢加；**規律服藥**，不是快發作時才吃；**不可自行停藥**（會誘發**癲癇重積狀態**）；**2–3 年沒有發作且腦波正常**才考慮**慢慢減量**
- 定期監測**血中藥物濃度、肝功能、血球**
- **癲癇重積狀態**：發作持續 **5 分鐘以上**、或兩次發作之間意識沒有恢復；第一線用 **benzodiazepine**

### 國考常考點 {#exam-points}

- 抗癲癇藥的機轉：離子通道、阻斷麩胺酸受體、增強 GABA；**阻斷正腎上腺素受體不是**
- **Carbamazepine** 主要作用在 **Na⁺ 通道**，治療局部（部分）發作
- **Ethosuximide** 治療失神發作的機轉：抑制 **T 型鈣離子通道**
- 結構類似 GABA：**gabapentin**；與 **SV2A** 親和力最高：**levetiracetam**
- **Dilantin 血清治療濃度 10–20 mcg/mL**（5–10、50–100、80–100 都是錯的）
- Dilantin **牙齦增生**是常見副作用 → 良好口腔衛生、**軟毛牙刷按摩牙齦**、定期看牙醫
- Dilantin 靜脈輸注**不可用葡萄糖溶液**稀釋、**不可快速推注**；常見副作用不是血液惡病質與心律不整
- Phenytoin 的副作用：牙齦增生、複視、SJS；**體重增加不是**
- 長期服用 Dilantin 是**骨質疏鬆**的危險因子
- **Primidone(Mysoline)**可能**嗜睡**；acetazolamide(Diamox)**不會**造成夜盲
- 發作後或快發作時才吃藥是錯的；**多種低劑量合併並不比較好**，先單一藥物再慢慢加量
- 停藥：**2–3 年內沒有發作、神經學與腦波檢查正常**，才考慮**慢慢減量**；**懷孕不可立即停藥**
- 兒童：發作控制了**也不能暫停**服藥；**不需與牛奶一起吃**；phenobarbital 要定時回診抽血**監測血中濃度**，6 週沒發作不能停藥
- 長期服用要定期檢查**血中濃度、肝功能、血球**；**心肺功能不是**常規項目
- Depakine 要定期監測血中濃度；**生酮飲食是高脂肪、極低醣**，不是低脂肪
- 癲癇重積狀態的誘因：**自行停藥、感染、飲酒**（運動不是）
- 強直陣攣發作：**強直期**全身僵直、牙關緊閉、雙腳伸直，之後才是陣攣期（順序不能顛倒）
- 女性癲癇病人仍可懷孕；發作時病人意識不清**不需要試圖喚醒**；台灣癲癇病人**不是一律不能考駕照**

## 作用機轉 {#mechanism}

| 機轉 | 藥物 | 說明 |
|---|---|---|
| 阻斷**電位門控 Na⁺ 通道** | **Phenytoin**、**carbamazepine**、oxcarbazepine、**lamotrigine**、lacosamide；valproate 與 topiramate 也有部分作用 | 延長 Na⁺ 通道失活，減少**高頻反覆放電** |
| 阻斷 **T 型 Ca²⁺ 通道** | **Ethosuximide**、valproate | 抑制視丘的節律性放電，治療**失神發作** |
| 結合 Ca²⁺ 通道 **α2δ 次單元** | **Gabapentin**、pregabalin | 減少興奮性神經傳遞物質釋放；**結構類似 GABA**，但不作用在 GABA 受體；也治療神經痛 |
| 增強 **GABA-A** 受體 | **Benzodiazepine**（增加 Cl⁻ 通道開啟**次數**）、**phenobarbital**、primidone（延長開啟**時間**） | Cl⁻ 內流 → 過極化 |
| 增加 GABA 量 | Valproate、vigabatrin（抑制 GABA 分解）、tiagabine（抑制回收） | |
| 結合突觸小泡蛋白 **SV2A** | **Levetiracetam**、brivaracetam | 調節神經傳遞物質釋放 |
| 減少**麩胺酸**作用 | Topiramate(AMPA)、perampanel(AMPA)、felbamate(NMDA) | |
| 抑制碳酸酐酶 | Acetazolamide、topiramate | 輔助用藥 |

- 膜電位與 Na⁺ 通道的基礎見 [[neuron-synapse#action-potential]]；GABA 與麩胺酸見 [[neuron-synapse#neurotransmitters]]

## 依發作類型選藥 {#drug-choice}

| 發作類型（舊稱） | 常用藥 | 注意 |
|---|---|---|
| 局部發作（部分發作；有意識障礙的舊稱複雜性部分發作，常源自顳葉） | Carbamazepine、oxcarbazepine、lamotrigine、levetiracetam、phenytoin | |
| 全身強直陣攣發作（大發作） | Valproate、lamotrigine、levetiracetam | |
| **失神發作**（小發作） | **Ethosuximide**、valproate、lamotrigine | **Carbamazepine、phenytoin 可能使失神與肌躍發作惡化** |
| 肌躍發作 | Valproate、levetiracetam | |
| 嬰兒點頭痙攣 | ACTH、vigabatrin | |
| **癲癇重積狀態** | Benzodiazepine → fosphenytoin、valproate 或 levetiracetam | 見下方 |

- 2025 年 ILAE 新分類把發作分成**局部、全身、不明、無法分類**四大類，以「意識」是否受影響細分；國考仍常用大發作、小發作、部分發作等舊稱（來源：[ILAE 2025 發作分類](https://www.ilae.org/updated-classification-epileptic-seizures-2025)）

## 代表藥物 {#agents}

### Phenytoin(Dilantin) {#phenytoin}

- **治療濃度 10–20 mcg/mL**（教科書參考值）；**飽和動力學**：劑量稍微增加，血中濃度就可能**不成比例地大幅上升**
- 濃度過高的表現依序大致是：**眼球震顫** → **運動失調**、複視、口齒不清 → 嗜睡、意識混亂
- **長期副作用**
  1. **牙齦增生**（兒童與青少年常見）→ 良好口腔衛生、**軟毛牙刷按摩牙齦**、定期看牙醫
  2. **多毛**、面部粗糙、痤瘡
  3. **皮疹**，嚴重時**史蒂芬強生症候群**(SJS)與毒性表皮溶解症
  4. **骨質軟化與骨質疏鬆**（加速維生素 D 代謝）→ 補充維生素 D 與鈣
  5. **葉酸缺乏**、巨球性貧血
  6. 致畸胎（胎兒乙內醯脲症候群）
- **靜脈給藥**
  1. **只能用生理食鹽水**稀釋與沖管，**葡萄糖溶液會產生沉澱**
  2. **慢速推注**：成人**每分鐘不超過 50 mg**（兒童依體重更慢），太快會**低血壓、心律不整**，要監測心電圖與血壓
  3. 鹼性強、刺激血管，外滲會組織壞死（紫手套症候群）；**不可肌肉注射**
  4. Fosphenytoin 是前驅藥，可以用葡萄糖稀釋、推注較快、刺激性較小
- 口服懸浮液要搖勻；與管灌飲食同時給會**降低吸收**，依醫囑錯開時間
- 肝臟酵素誘導劑：降低口服避孕藥、warfarin 等藥物的濃度

### 其他常用藥 {#other-agents}

| 藥物 | 主要用途 | 重點副作用與注意事項 |
|---|---|---|
| **Carbamazepine**(Tegretol) | 局部發作、**三叉神經痛**、雙極性疾患 | **HLA-B\*1502** 陽性者容易發生 SJS，台灣用藥前**先驗基因**（健保給付篩檢後 SJS 明顯減少）（來源：[Chen 等，NEJM 2011](https://doi.org/10.1056/NEJMoa1009717)）；**再生不良性貧血、白血球低下**、**低血鈉**(SIADH)、複視、頭暈；自我誘導代謝；治療濃度約 4–12 mcg/mL（教科書參考值） |
| Oxcarbazepine | 局部發作 | **低血鈉**比 carbamazepine 更常見 |
| **Valproate**(Depakine) | 廣效：全身與局部發作、失神、肌躍；雙極性疾患 | **肝毒性**（兩歲以下、多藥合併者風險高）、**胰臟炎**、**血小板低下**、顫抖、掉髮、**體重增加**、高血氨；**致畸胎風險最高**（神經管缺陷），有生育可能的女性盡量避免；治療濃度約 50–100 mcg/mL（教科書參考值） |
| **Phenobarbital**(Luminal) | 新生兒痙攣、重積狀態、全身發作 | **嗜睡**、認知變慢；**兒童可能反常過動**；長效、要**監測血中濃度**；突然停藥會戒斷發作 |
| **Primidone**(Mysoline) | 局部與全身發作、本態性顫抖 | 在體內轉成 phenobarbital → **嗜睡**、頭暈 |
| **Ethosuximide** | **只用於失神發作** | 腸胃不適、嗜睡、頭痛 |
| **Lamotrigine** | 局部與全身發作、雙極性憂鬱 | **皮疹與 SJS**，要**很慢地加量**；與 valproate 併用時濃度上升 |
| **Levetiracetam**(Keppra) | 局部與全身發作 | 交互作用少；**易怒、情緒與行為改變** |
| Gabapentin、pregabalin | 局部發作輔助、**神經病變痛** | 嗜睡、頭暈、水腫、體重增加 |
| Topiramate | 局部與全身發作、偏頭痛預防 | 體重減輕、**腎結石**、思考變慢、**急性閉角型青光眼**、代謝性酸中毒、少汗 |
| Acetazolamide(Diamox) | 輔助用藥（月經性癲癇）、青光眼 | 手腳麻刺感、多尿、腎結石、代謝性酸中毒 |
| Benzodiazepine | **重積狀態**第一線、急性發作 | 呼吸抑制、嗜睡（見 [[anxiolytics-hypnotics]]） |

## 用藥原則與護理 {#nursing}

1. **單一藥物、低劑量開始**，慢慢加到發作被控制或出現副作用為止；多種藥合併只用在單一藥物控制不好時，交互作用與副作用都會增加
2. **規律、準時服藥**，維持穩定血中濃度；不是快發作或發作後才吃
3. **不可自行停藥或減量**：突然停藥是**癲癇重積狀態**最常見的誘因之一
4. **停藥**：通常要 **2–3 年以上沒有發作**、神經學與**腦波檢查正常**，由醫師評估後**數週到數月慢慢減量**
5. **定期檢查**：**血中藥物濃度**（phenytoin、phenobarbital、valproate、carbamazepine）、**肝功能**、**全血球計數**、血鈉；心肺功能不是常規項目
6. 避免誘發因子：**睡眠不足、飲酒**、壓力、感染發燒、閃光（光敏感者）；酒精也會增加藥物的鎮靜作用
7. 一般以水吞服，**不需要配牛奶**；與食物或管灌飲食的時間依各藥說明
8. 戴醫療識別手環；剛開始服藥或調藥時注意嗜睡，避免開車與危險工作
9. **懷孕**
   1. 女性癲癇病人**仍可懷孕**，但最好**事先計畫**，由醫師調整成風險較低的藥物
   2. **懷孕後不可自行立即停藥**：發作本身對母親與胎兒的危險更大
   3. 懷孕前與懷孕期間補充**葉酸**；valproate 的神經管缺陷風險最高
   4. 酵素誘導型的藥（carbamazepine、phenytoin、phenobarbital、topiramate 高劑量）會降低口服避孕藥效果
10. **兒童**
    1. 發作控制了也不能自行暫停，鼓勵維持**正常生活與上學**
    2. **生酮飲食**：**高脂肪、極低醣、適量蛋白質**，以酮體當腦的能量來源，用於藥物難治型癲癇
11. 駕照：台灣癲癇病人**不是一律不能考照**，檢具醫師開立「**最近 2 年以上未發作**」的診斷證明書即可申請（來源：[道路交通安全規則第 64 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0040013&flno=64)）

## 癲癇重積狀態 {#status-epilepticus}

- **定義**：發作持續 **5 分鐘以上**，或反覆發作、**兩次之間意識沒有恢復**（5 分鐘後自行停止的機會變小，持續 30 分鐘以上可能造成永久腦傷）
- **常見誘因**：**自行停藥**或漏藥、**感染**與發燒、**飲酒**或酒精戒斷、睡眠不足、腦部病變、低血糖與電解質異常
- **處置流程**（來源：[美國癲癇學會 2016 指引](https://aesnet.org/clinical-care/clinical-guidance/guideline-prolonged-seizures)）
  1. **0–5 分鐘 穩定期**：維持呼吸道、給氧、監測生命徵象與心電圖、驗**血糖**（低血糖給葡萄糖；成人先給 thiamine）、建立靜脈管路
  2. **5–20 分鐘 第一線**：**benzodiazepine**，例如**靜脈 lorazepam**、靜脈 diazepam，沒有靜脈管路時**肌肉注射 midazolam**（劑量依醫囑）
  3. **20–40 分鐘 第二線**：仍在發作時給 **fosphenytoin**、**valproate** 或 **levetiracetam** 靜脈注射
  4. **40 分鐘以後**：轉入加護病房，麻醉劑量的 midazolam、propofol 或 pentobarbital，持續腦波監測
- 強直陣攣發作的過程：先**強直期**（全身僵直、牙關緊閉、雙腳伸直、呼吸暫停、發紺）→ **陣攣期**（規律抽動）→ 發作後期（意識混亂、嗜睡）
