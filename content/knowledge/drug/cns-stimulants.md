**中樞神經興奮劑**提高腦內的興奮性神經傳導，國考最常考的是 ADHD 用藥 **methylphenidate(利他能)** 的分類、機轉、服藥時間與副作用，以及**咖啡因**的作用標的。ADHD 的診斷與非藥物處置見 [[adhd]]；安非他命、古柯鹼等被濫用的興奮劑見 [[substance-use-disorders#stimulants]]

## 重點摘要 {#summary}

- 機轉：**methylphenidate** 阻斷多巴胺與正腎上腺素的再回收並促進釋放；**amphetamine** 主要促進釋放；兩者都增加前額葉的**多巴胺與正腎上腺素**
- 用途：**ADHD 第一線**、猝睡症；**atomoxetine** 是**非興奮劑**、濫用風險低，起效較慢
- 副作用：**食慾不振**、**體重減輕與生長遲緩**、**失眠**、頭痛腹痛、**心跳加快、血壓上升**；可能加重抽動
- 護理：**早上或早餐後**給藥，長效劑型一天一次；**不可在傍晚或夜間**服用；監測身高、體重、心跳、血壓；methylphenidate 在台灣列**第三級管制藥品**
- **咖啡因**：**腺苷受體拮抗劑**，也抑制**磷酸雙酯酶**；茶鹼同類，但**不能**治療 ADHD

### 國考常考點 {#exam-points}

- methylphenidate(Ritalin)屬**中樞神經興奮劑**，不是情緒穩定劑、抗癲癇或抗憂鬱劑
- methylphenidate 可**促進多巴胺釋放**；常見副作用是**心跳加快與血壓升高**(不是血壓降低)、**食慾不振**、失眠
- **服藥時間**：早上或早餐後，**不是傍晚至夜間**；寒暑假或放假時**可經醫師評估暫停**(藥物假期)，不是「每 2 個月固定停一次」，也不是「絕對不能停」
- **atomoxetine、dextroamphetamine、methylphenidate** 都可治療 ADHD；**theophylline 不行**
- **咖啡因**的作用標的是**腺苷(adenosine)受體**；也是**磷酸雙酯酶(PDE)抑制劑**
- ADHD 主要與**多巴胺與正腎上腺素**功能異常有關，不是血清素

## 作用機轉 {#mechanism}

1. ADHD 與前額葉的**多巴胺、正腎上腺素**訊號不足有關，影響專注、計畫與抑制衝動
2. **methylphenidate**
   1. 阻斷多巴胺與正腎上腺素轉運體，減少**再回收**
   2. 也促進多巴胺釋放
   3. 結果是突觸內兩者濃度上升，改善專注力，減少過動與衝動
3. **amphetamine 類**：主要促進多巴胺與正腎上腺素**釋放**，也抑制再回收
4. **atomoxetine**：選擇性**正腎上腺素再回收抑制劑**，不直接增加紋狀體的多巴胺，所以**濫用風險低**
5. **咖啡因等甲基黃嘌呤**
   1. **拮抗腺苷受體**：腺苷本身會使人想睡，阻斷它就產生提神效果
   2. 抑制**磷酸雙酯酶**，使細胞內 cAMP 上升，產生支氣管擴張、強心與利尿等作用
   3. **theophylline(茶鹼)** 機轉類似，主要用於氣喘，見 [[asthma-drugs]]

## 代表藥物 {#agents}

| 藥物 | 類別 | 特點 |
|---|---|---|
| **methylphenidate 短效**(利他能 Ritalin) | 興奮劑 | 作用約 3–4 小時，每天需服 2–3 次；起效快 |
| **methylphenidate 長效**(利長能 Ritalin LA、專思達 Concerta) | 興奮劑 | 每天早上一次，作用約 8–12 小時；**不可磨碎或嚼碎** |
| **amphetamine 類**(dextroamphetamine、lisdexamfetamine) | 興奮劑 | 國外常用；台灣的可及性待核對 |
| **atomoxetine**(思銳 Strattera) | 非興奮劑 | 正腎上腺素再回收抑制劑；需數週才完全見效；適合合併抽動、焦慮或擔心濫用者；注意食慾下降、腸胃不適，以及青少年**自殺意念**的警語 |
| guanfacine、clonidine | α2 促效劑 | 非興奮劑的選擇，可能嗜睡、低血壓 |
| **modafinil** | 促醒劑 | 用於猝睡症與白天過度嗜睡，作用機轉與傳統興奮劑不同 |
| **咖啡因** | 甲基黃嘌呤 | 提神；早產兒呼吸暫停也會使用；過量導致心悸、焦慮、失眠 |

1. 藥物作用時間為約略值，依品項與劑型不同，待核對仿單
2. 抗精神病藥(如 risperidone)用於自閉症的激躁與攻擊，不屬於本類，見 [[antipsychotics]]

## 適應症 {#indications}

1. **注意力不足過動症(ADHD)**：學齡兒童、青少年與成人
2. **猝睡症**
3. 興奮劑**不能提升智力**，也**不是**用來治療自閉症的核心症狀；自閉症合併過動時可在評估後使用
4. 食慾抑制劑(如曾上市的 lorcaserin，為 5-HT2C 受體**促效劑**)不是本類的 ADHD 用藥，國考偶爾在本章出現

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 說明與處置 |
|---|---|
| **食慾不振、體重減輕** | 最常見；**飯後**服藥，在藥效減弱時(早餐、晚餐、睡前點心)補充營養 |
| **生長遲緩** | 長期使用可能影響身高體重，定期記錄**生長曲線**；必要時經醫師評估實施**藥物假期** |
| **失眠** | 避免下午晚些與傍晚服藥 |
| **心血管** | **心跳加快、血壓上升**；用藥前評估心臟病史，定期量心跳血壓 |
| 頭痛、腹痛、易怒、情緒低落 | 藥效消退時可能出現反彈 |
| **抽動** | 可能誘發或加重抽動(妥瑞氏症)，要觀察 |
| **濫用與依賴** | 興奮劑有濫用風險；台灣管制等級：**methylphenidate 第三級**、**amphetamine 與 lisdexamfetamine 第二級**、**modafinil 第四級**、**atomoxetine 不列管**；不可轉給他人 |

1. 禁忌與慎用：嚴重心血管疾病、甲狀腺機能亢進、青光眼、正在使用 **MAOI**(14 天內)、物質濫用史
2. 過量：激動、心搏過速、高血壓、高體溫、抽搐

## 護理重點與衛教 {#nursing}

### 給藥與觀察 {#nursing-administration}

1. **早上**或**早餐後**給藥；短效劑型的第二劑在中午，避免下午晚些服用
2. 長效錠整顆吞服，不可剝半或嚼碎
3. 用藥前與用藥期間記錄**身高、體重、心跳、血壓**
4. 觀察食慾、睡眠、情緒、抽動，以及學校表現的改變(老師的回饋很重要)
5. 管制藥品要**依規定保存與記錄**

### 衛教 {#nursing-education}

1. 藥物是**改善症狀**的工具，要合併行為治療、親職教育與學校協助
2. 依醫囑服藥，**不可自行加量或停藥**；寒暑假是否暫停由醫師評估
3. 營養：早餐吃夠，藥效消退後補充餐點
4. 避免大量含咖啡因的飲料，會加重失眠與心悸
5. 出現胸痛、心悸、昏厥、嚴重情緒變化或自殺念頭，立即就醫
6. 藥物妥善保管，避免被他人取用或濫用
