## 重點摘要 {#summary}

- **強心劑(inotrope)** 增加收縮力與心輸出量:**dobutamine(β₁)**、**milrinone(PDE3 抑制)**;**升壓劑(vasopressor)** 收縮血管升高血壓:**norepinephrine(α₁ 為主)**、epinephrine、vasopressin;**dopamine 依劑量**兼具兩者。
- 用於**心因性休克**、低灌流的急性心衰竭、休克與低血壓、心跳停止後照護;**只能短期使用**,不改善長期存活。
- 副作用:**心搏過速、心律不整**、心肌缺氧;升壓劑外滲會**組織壞死** → 以 **phentolamine** 局部浸潤。
- 護理:**中心靜脈、專用管路、輸液幫浦**、依血壓逐步調整、不可 bolus 或突然停藥;先矯正低血容積。

## 作用機轉 {#mechanism}

心輸出量 = 心跳 × 心搏量;血壓 ≈ 心輸出量 × 周邊血管阻力(見 [[cardiac-output#determinants]]、[[blood-pressure-regulation#determinants]])。這類藥物依作用的受體決定它是「強心」還是「升壓」(受體見 [[blood-pressure-regulation#autonomic-receptors]]):

| 受體 | 位置 | 被刺激時 |
|---|---|---|
| **β₁** | 心臟 | 收縮力↑、心跳↑、傳導↑ → 心輸出量↑(也增加耗氧與心律不整) |
| **β₂** | 血管、支氣管 | 血管擴張、支氣管擴張 |
| **α₁** | 周邊血管 | **血管收縮** → 阻力↑、血壓↑(器官與肢端灌流可能↓) |
| **D₁(多巴胺)** | 腎、腸繫膜血管 | 血管擴張 |

- **cAMP 是共同終點**:β₁ 促效劑增加 cAMP 的**生成**;**milrinone 抑制第三型磷酸二酯酶(PDE3)**,減少 cAMP 的**分解** → 心肌收縮力增加,**血管平滑肌 cAMP 增加則血管擴張**(「強心 + 擴血管」= inodilator)。因為不經過 β 受體,**正在使用 β 阻斷劑的病人仍有效**。
- Levosimendan:**鈣敏感劑**,增加肌鈣蛋白對鈣的敏感度並打開血管 K-ATP 通道,也是 inodilator。

## 代表藥物 {#agents}

### Dopamine(劑量依賴效應) {#dopamine}

| 劑量(mcg/kg/min) | 主要受體 | 效果 |
|---|---|---|
| **低劑量 < 3(約 0.5–2;教科書數值,僅供參考)** | 多巴胺受體 | 腎、腸繫膜血管擴張 → **腎血流與尿量增加**(但研究證實**沒有腎臟保護作用**,已不建議為此使用) |
| **中劑量 3–10(約 5–10)** | **β₁** | **收縮力↑、心輸出量↑**、心跳↑;國考:6 mcg/kg/min 的目的 → **增加心肌收縮力** |
| **高劑量 > 10** | **α₁** | **周邊血管收縮**、血壓↑;腎與肢端灌流下降 |

- 劑量間有重疊、個體差異大;中劑量同時增加心輸出量與部分血管阻力。
- 心律不整比 norepinephrine 多;**心因性休克時 dopamine 的死亡率高於 norepinephrine**(SOAP II 次分析)→ 已不是休克首選升壓劑。
- 心因性休克時 dopamine 的心律不整較多、死亡率傾向較高,ESC 建議升壓劑以 **norepinephrine 為首選**(來源:[2026 ESC 心衰竭指引](https://doi.org/10.1093/eurheartj/ehag100) p.50)。
- 仍用於:**症狀性心搏過緩**(atropine 無效時)的替代藥,劑量 **5–20 mcg/kg/min**,依反應調整、慢慢減量(來源:[2025 AHA 成人心搏過緩流程圖](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines/algorithms))。
- 與鹼性溶液(**碳酸氫鈉**)不相容。

### Dobutamine {#dobutamine}

- 主要作用 **β₁**(少許 β₂、α₁)→ **增加收縮力與心輸出量**,血壓通常不升甚至略降(β₂ 擴張血管)。
- 用於**低心輸出量/低灌流的急性心衰竭、心因性休克**(合併升壓劑)、心臟術後;也用於**藥物負荷心臟超音波**。
- 劑量 2–20 mcg/kg/min;副作用:心搏過速、心室早期收縮、心肌缺氧、低血鉀;連續 48–72 小時後會**耐受**。
- 使用 β 阻斷劑的病人效果差,改考慮 milrinone。

### Milrinone {#milrinone}

- **PDE3 抑制劑** → 強心 + 血管擴張(降低前後負荷、肺血管阻力)。
- 0.125–0.75 mcg/kg/min(可有負荷劑量,但常省略以免低血壓);**經腎排除**,腎功能差要減量。
- 副作用:**低血壓**、**心律不整**(長期使用增加死亡)、血小板減少(較舊的 amrinone 明顯)。
- 與 **furosemide 同管會沉澱**,要分開管路。

### Norepinephrine(Levophed®) {#norepinephrine}

- **α₁ 為主 + 少許 β₁** → 強力血管收縮、血壓升高,心跳變化不大。
- **敗血性休克首選**升壓劑;**心因性休克合併低血壓**時也偏好 norepinephrine 而非 dopamine。
- 常用 0.05–0.5 mcg/kg/min(成人約從 2–4 mcg/min 起始,依目標血壓調整;教科書參考值,本機指引未列劑量,僅供參考,以醫囑為準);過量導致肢端、腸道、腎臟缺血。

### Epinephrine(Bosmin®) {#epinephrine}

- **α + β₁ + β₂** 全部作用:低劑量以 β 為主(強心、支氣管擴張),高劑量 α 作用明顯(血管收縮)。
- **心跳停止**:1 mg IV/IO,**每 3–5 分鐘**;不可電擊心律(asystole/PEA)儘早給(來源:[2025 AHA 成人心跳停止流程圖](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines/algorithms))。
- **過敏性休克**:0.5 mg(1 mg/mL)**肌肉注射**大腿前外側(成人),必要時 5–15 分鐘重複。
- **症狀性心搏過緩**:持續輸注 **2–10 mcg/min**(atropine 無效時,與 dopamine 同為選項)(同上來源)。
- 休克輸注 0.01–0.5 mcg/kg/min;副作用:心搏過速、心律不整、高血糖、乳酸上升。

### Vasopressin 與其他 {#others}

- **Vasopressin**:作用於血管 V1 受體收縮血管,敗血性休克時作為 norepinephrine 的**加成藥**(約 0.03 U/min);心跳停止時可考慮,但不比 epinephrine 好。
- **Phenylephrine**:純 α₁,反射性心跳變慢;麻醉誘發低血壓常用。
- **Levosimendan**:鈣敏感劑,急性失代償心衰竭、使用 β 阻斷劑者。

## 適應症 {#indications}

### 心因性休克與急性心衰竭 {#cardiogenic-shock}

心因性休克 = 心臟幫浦衰竭 → 心輸出量不足、**低血壓(收縮壓 < 90 mmHg)、組織灌流不足**(意識改變、四肢濕冷、少尿、乳酸上升),中心靜脈壓/肺微血管楔壓**上升**(見 [[hypotension]]、[[heart-failure]])。

- **2022 AHA/ACC/HFSA**:心因性休克應給予**靜脈強心劑及/或升壓劑**維持器官灌流(Class 1),藥物無效時考慮**機械循環輔助**(IABP、Impella、ECMO)。
- **2026 ESC**:收縮壓 < 90 mmHg 且有低灌流、標準治療(含輸液試驗)無效時,可考慮強心劑(不常規使用);低血壓需升壓劑時**norepinephrine 優先於 dopamine 或 epinephrine**(epinephrine 在心肌梗塞休克試驗中頑固性休克較多)(來源:[2026 ESC 心衰竭指引](https://doi.org/10.1093/eurheartj/ehag100) p.50–51)。
- **2025 ACC/AHA 急性冠心症指引**:急性心肌梗塞合併心因性休克,**不建議常規使用 IABP 或 VA-ECMO**(無存活好處);嚴重者可考慮微軸流幫浦(Impella)(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309) p.46)。
- 沒有低血壓或低灌流的心衰竭**不應常規使用強心劑**(增加心律不整與死亡);長期門診輸注僅作為**心臟移植/左心室輔助器的過渡**或安寧緩和。
- 常見組合:**norepinephrine(維持血壓)+ dobutamine(增加心輸出量)**;必要時加機械循環輔助。

### 其他休克與心跳停止後照護 {#other-shock}

- **低血容積性休克**:首要是**補充體液/輸血**;升壓劑只作為補液後仍低血壓的輔助(國考選項「dopamine 可治療低血容積性休克」視為正確,前提是已補液)。
- 敗血性休克:輸液後 norepinephrine 為首選,MAP 目標 ≥ 65 mmHg。
- 過敏性休克:epinephrine IM 為第一線。
- **2025 AHA ACLS 心跳停止後照護(ROSC 後)**:以輸液及升壓劑維持 **MAP ≥ 65 mmHg**(2025 流程圖只列 MAP 目標;2020 版另寫「收縮壓 ≥ 90 mmHg」)(來源:[2025 AHA 心跳停止後照護流程圖](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines/algorithms));同時找出並治療可逆原因(Hs & Ts)。
- **2025 AHA ACLS 心搏過緩**:atropine 1 mg IV,每 3–5 分鐘,總量 3 mg;無效時**經皮心律調節**或 **dopamine 5–20 mcg/kg/min**、**epinephrine 2–10 mcg/min** 輸注(來源:[2025 AHA 成人心搏過緩流程圖](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines/algorithms);僅供參考,以醫囑為準)。

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 說明與處置 |
|---|---|
| **心搏過速、心律不整** | 所有 β 促效劑與 milrinone;持續心電圖監測,新發生心律不整時通報 |
| 心肌缺氧、心絞痛 | 耗氧增加,冠心病者小心 |
| **組織缺血** | 高劑量血管收縮 → 手指腳趾發黑、腸缺血、少尿 |
| **外滲 → 組織壞死** | norepinephrine、dopamine、epinephrine、vasopressin;見下方處理 |
| 低血壓 | milrinone、dobutamine(血管擴張) |
| 高血糖、低血鉀、乳酸上升 | epinephrine |
| 高血壓 | 劑量過高;依目標血壓下調 |

**禁忌/注意**:**低血容積未矯正前**先補液;嗜鉻細胞瘤(升壓劑);肥厚性阻塞性心肌病變(強心劑加重阻塞);快速心律不整。

### 外滲處理 {#extravasation}

1. **立即停止輸注**,不要拔針,先從留置針**回抽**殘餘藥液。
2. 抬高患肢、**不要熱敷**(冷熱敷依機構規範;不宜加壓按摩)。
3. 依醫囑以 **phentolamine(α 阻斷劑)5–10 mg 稀釋於 10–15 mL 生理食鹽水**,在外滲區**皮下多點浸潤**,最好在 **12 小時內**;無法取得時可用外用 nitroglycerin 或 terbutaline 浸潤(依醫囑)。
4. 另找**其他肢體、最好中心靜脈**重新建立管路;標示範圍、拍照、持續評估膚色、微血管充填、疼痛、感覺。
5. 填寫異常事件通報。

## 交互作用 {#interactions}

| 併用藥物 | 結果 |
|---|---|
| **β 阻斷劑** | 削弱 dobutamine、dopamine 的強心作用(milrinone 不受影響);非選擇性 β 阻斷劑 + epinephrine → 無對抗的 α 作用 → 嚴重高血壓 |
| **MAO 抑制劑**、三環抗憂鬱劑 | 增強升壓作用 → 高血壓危象;dopamine 劑量需大幅減少 |
| 吸入性麻醉劑(halothane)、digoxin | 心律不整 |
| α 阻斷劑(phentolamine) | 拮抗血管收縮(外滲解毒原理) |
| **碳酸氫鈉等鹼性溶液** | 使兒茶酚胺類失去活性 → 不可同管 |
| Furosemide | 與 milrinone 同管沉澱 |
| Oxytocin、麥角鹼 | 加成血管收縮 |

## 護理重點與衛教 {#nursing}

### 給藥 {#administration}

- **一定使用輸液幫浦**,以 mcg/kg/min 或 mcg/min 計算;醫囑須包含**濃度、劑量(速率)與調整目標**,不完整時**與醫師確認**。
- 高警訊藥物:**雙人核對**藥名、濃度、體重、速率;管路**標示**藥名與濃度。
- 升壓劑以**中心靜脈導管**給予最安全;緊急時可短期使用周邊**大條、近端(肘前以上)靜脈**,每小時檢查注射部位。
- **專用管路/管腔**:不要從這條管路推其他藥或 bolus 沖管(會一次推進大量升壓劑);更換針筒/輸液袋時用「雙幫浦交接」避免中斷。
- **逐步調整**:依血壓、MAP、心跳、尿量調整;**停藥要逐漸減量**,不可突然停止(反彈性低血壓)。
- 給升壓劑前先評估並**矯正低血容積**。
- 光敏感:dopamine、norepinephrine 溶液變色(粉紅、棕色)不可使用。

### 劑量計算範例 {#calculation}

醫囑「Dopamine(200 mg/5 mL/amp)4 amp in NS 500 mL, IV drip, pump」:

- 總藥量 = 200 × 4 = **800 mg**(不是 1000 mg);濃度 = 800 mg ÷ 500 mL = **1.6 mg/mL(1600 mcg/mL)**。
- 醫囑**沒有寫速率/劑量**(mcg/kg/min)→ **醫囑不完整,需與醫師確認**。
- 若體重 60 kg、要 5 mcg/kg/min:5 × 60 = 300 mcg/min = 18,000 mcg/h ÷ 1600 = **11.25 mL/h**。

### 監測 {#monitoring}

- **持續心電圖**、血壓(休克時常用**動脈導管**)、心跳、SpO₂;調整劑量時每 5–15 分鐘量血壓。
- **灌流指標**:意識(GCS)、皮膚溫度與顏色、微血管充填、**每小時尿量**(成人 ≥ 0.5 mL/kg/h)、乳酸。
- 評估改善:**意識進步**(例如 GCS E3V3M5 → E3V5M6)是灌流改善的好指標;「必須靠 dopamine 才維持收縮壓 90 mmHg」、「尿量 28 mL/h(65 kg)」都**不代表改善**。
- 心因性休克病人**不要用電毯等加溫**(周邊血管擴張、回心血量下降);維持正常體溫即可。
- 監測 K⁺、Mg²⁺(心律不整)、血糖(epinephrine)、肢端缺血、注射部位。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **Dopamine 劑量**:低劑量(< 3)→ **增加腎血流量**;中劑量(3–10,如 **6**)→ **增加心肌收縮力**;高劑量(> 10)→ **末梢血管收縮**。「初時應以高劑量」「中劑量使血管收縮」「高劑量增加收縮力」都錯。
- **Dobutamine** 主要作用於 **β₁** 受體 → 增加收縮力與心輸出量,用於急性鬱血性心衰竭與心因性休克;它**不具 β₂ 選擇性**(與 terbutaline、salbutamol 區別)。
- **Milrinone** = **第三型磷酸二酯酶(PDE3)抑制劑**,強心 + 擴張血管,長期使用引發心律不整。
- 低血壓治療:**β₁「拮抗劑」會降低心輸出量**(錯誤選項);α₁ 促效劑增加周邊阻力;中劑量 dopamine 可同時增加心輸出量與阻力。
- Dopamine 800 mg 計算、醫囑缺速率要確認。
- 心因性休克:dobutamine 增加收縮力、利尿劑降前負荷、**嗎啡也會降低前後負荷**、NTG 擴張血管減輕負荷;**IABP** 增加冠狀動脈血流、降低後負荷;**不使用電毯加溫**。
- 升壓劑外滲 → **phentolamine** 局部浸潤。
:::
