## 重點摘要 {#summary}

- **NSAIDs** 抑制**環氧化酶**(COX)，減少**前列腺素**生成 → **解熱、止痛、抗發炎**；非選擇性 NSAIDs 同時抑制血小板(**aspirin 為不可逆**)。
- 前列腺素也在**保護胃黏膜、維持腎血流**，所以 NSAIDs 的主要副作用是**消化性潰瘍與出血、腎功能下降、水鈉滯留**，並增加**心血管**風險。
- **COX-2 選擇性抑制劑**(celecoxib)：**腸胃出血較少**、**不抑制血小板**，但心血管風險仍在。
- **Aspirin**：兒童病毒感染時用 → **雷氏症候群**；**登革熱、血友病、出血傾向**禁用；過量 → **耳鳴**、呼吸性鹼中毒加上代謝性酸中毒。
- **Acetaminophen**：解熱止痛，**幾乎沒有抗發炎作用**，**不傷胃、不影響血小板**；過量造成**肝壞死**，解毒劑 **N-acetylcysteine**。成人每日一般不超過 **3–4 g**，肝病、酗酒、老人更低。

## 作用機轉 {#mechanism}

| 酵素 | 正常角色 | 被抑制的結果 |
|---|---|---|
| **COX-1**(持續存在) | 胃黏膜保護(黏液、碳酸氫根、血流)、**血小板 thromboxane A2**(凝集)、腎血流 | **胃潰瘍出血**、**抗血小板**(出血時間延長)、腎功能下降 |
| **COX-2**(發炎時誘發) | 發炎部位的前列腺素 → 紅、腫、熱、痛、發燒 | **抗發炎、止痛、解熱** |

- 非選擇性 NSAIDs 同時抑制 COX-1 與 COX-2；**celecoxib** 選擇性抑制 COX-2。
- **Aspirin** 以**乙醯化**不可逆抑制 COX → 血小板在其壽命(約 **7–10 天**)內都無法凝集，所以**手術前約 7 天停藥**(依醫囑)；其他 NSAIDs 是**可逆**的。
- **Acetaminophen** 主要作用在**中樞**，周邊抗發炎作用很弱。
- 疼痛生理見 [[pain-management#nociception]]。

## 代表藥物 {#agents}

| 類別 | 藥物 | 重點 |
|---|---|---|
| **水楊酸類** | **Aspirin** | 低劑量抗血小板(見 [[antiplatelets]])；止痛解熱與抗發炎需較高劑量 |
| 丙酸類 | **Ibuprofen**、naproxen | 常用止痛退燒；ibuprofen 可用於 6 個月以上兒童 |
| 醋酸類 | **Diclofenac**(Voltaren)、**indomethacin**、ketorolac | indomethacin 用於**痛風**急性發作、**早產兒開放性動脈導管**；ketorolac 注射劑作用強，限短期(約 5 天)使用 |
| 其他 | Mefenamic acid(Ponstan) | 經痛 |
| **COX-2 抑制劑** | **Celecoxib**(Celebrex)、etoricoxib | **出血與腸胃潰瘍較少**；**不抑制血小板**；心血管風險；對磺胺類過敏者避免 celecoxib |
| **解熱鎮痛劑** | **Acetaminophen**(普拿疼、Tinten、paracetamol) | 不是 NSAIDs；**兒童、孕婦、消化性潰瘍、出血傾向**時首選的解熱止痛藥 |

## 適應症 {#indications}

- 輕度到中度疼痛(止痛階梯第一階，見 [[pain-management#ladder]])；**骨轉移痛**、術後、經痛、牙痛、頭痛。
- **發炎性疾病**：**類風濕性關節炎**(NSAIDs 為第一線症狀治療)、退化性關節炎、**痛風**急性發作、僵直性脊椎炎。
- 發燒。
- Aspirin 的特殊用途：**心肌梗塞與中風的預防**(低劑量)、**川崎病**(急性期高劑量、之後低劑量)。

### Aspirin 的劑量與作用 {#aspirin-dose}

| 作用 | 劑量 |
|---|---|
| **抗血小板** | 最低(每天約 75–100 mg) |
| 止痛、解熱 | 中等(每次 325–650 mg) |
| **抗發炎** | **最高**(每天數公克) |

- 「aspirin 的藥理作用」包括**止痛、解熱、抗發炎、抗血小板**；它**不是止血藥**(反而延長出血)。

## 副作用 {#adverse-effects}

### 腸胃道 {#gi}

- **消化性潰瘍、出血、穿孔**：老人、有潰瘍病史、併用類固醇或抗凝血藥、高劑量長期使用風險最高。
- 預防與治療：**飯後**服用、用最低有效劑量與最短時間；高風險者併用**氫離子幫浦阻斷劑**或 **misoprostol**(前列腺素 E1 類似物，**直接補回被抑制的前列腺素**，對 NSAIDs 引起的潰瘍最有針對性；**孕婦禁用**，會引起子宮收縮)，或改用 COX-2 抑制劑。
- 解黑便、吐咖啡色物、上腹痛要立即就醫。

### 腎臟 {#renal}

- 前列腺素維持腎血流；抑制後可能造成**急性腎損傷**，尤其在**脫水、心衰竭、肝硬化、原本腎功能不佳、老人**，或併用利尿劑與 ACEI、ARB 時。
- **水鈉滯留、水腫、高血鉀**、血壓上升；會**減弱利尿劑與降血壓藥**的效果。
- **止痛劑腎病**：長期大量使用止痛藥 → **腎乳頭壞死與慢性腎小管間質性腎炎**。
- 與鋰鹽併用會使**鋰濃度上升**(見 [[lithium-level#high]])。

### 心血管 {#cardiovascular}

- 非選擇性 NSAIDs 與 COX-2 抑制劑都會增加**心肌梗塞、中風、心衰竭惡化**的風險(aspirin 除外)(來源：[UpToDate](https://www.uptodate.com/contents/nonselective-nsaids-overview-of-adverse-effects))。
- 心衰竭、冠心病、控制不佳的高血壓病人避免長期使用。

### 出血 {#bleeding}

- 非選擇性 NSAIDs 抑制血小板，**延長出血時間**；**COX-2 抑制劑不會**(血小板只有 COX-1)。
- 出血風險高的情況要**避免 aspirin 與 NSAIDs**：**血友病**、**再生不良性貧血**等血小板低下、**登革熱**(尤其出血性登革熱)、化療後血小板低下、手術前後、使用抗凝血藥。
- 白血球低下的癌症病人發燒時也**避免用 NSAIDs 退燒**：可能遮蔽發燒、增加出血。

### 其他 {#other-effects}

- **Aspirin 誘發的氣喘**(阿斯匹靈過敏三合症：氣喘、鼻息肉、對 aspirin 敏感)：非選擇性 NSAIDs 都可能誘發支氣管痙攣。
- 過敏、皮疹，罕見 **Stevens-Johnson 症候群**。
- **懷孕**：懷孕 **20 週以後避免**(可能使胎兒腎功能受影響、羊水過少)；**第三孕期**可能使胎兒**動脈導管提早關閉**(來源：[FDA 2020](https://www.fda.gov/drugs/drug-safety-and-availability/fda-recommends-avoiding-use-nsaids-pregnancy-20-weeks-or-later-because-they-can-result-low-amniotic))。
- 可能延緩骨折癒合(證據有限)。

## Aspirin 的特殊問題 {#aspirin}

### 雷氏症候群 {#reye-syndrome}

- **兒童與青少年**在**病毒感染**(**流感、水痘**)期間服用 aspirin 後，可能發生**急性腦病變與肝臟脂肪浸潤**。
- 表現：病毒感染恢復期突然**持續嘔吐**、嗜睡、意識改變、抽搐；**血氨上升、肝指數上升、低血糖**。
- 預防：**18 歲以下退燒止痛避免 aspirin**，改用 acetaminophen 或 ibuprofen。
- 例外：**川崎病**需要高劑量 aspirin，治療期間若接觸流感或水痘要告知醫師，並依建議接種流感疫苗。

### 水楊酸中毒 {#salicylate-toxicity}

- 早期：**耳鳴**、聽力下降、噁心**嘔吐**、頭暈。
- 酸鹼：先刺激呼吸中樞造成**呼吸性鹼中毒**，之後出現**代謝性酸中毒**；**不會**造成代謝性鹼中毒。
- 嚴重：**發燒**、意識混亂、**幻覺**、抽搐、肺水腫。
- 處理：活性碳、**鹼化尿液**(碳酸氫鈉)促進排出，嚴重時血液透析。

### Aspirin 的交互作用 {#aspirin-interactions}

- **Ibuprofen 會干擾 aspirin 的抗血小板作用**(占住血小板 COX 的位置)：需要長期服用低劑量 aspirin 的人，應避免規則併用 ibuprofen，或錯開服藥時間。
- **Warfarin**：併用增加**出血**風險(抗血小板作用加上腸胃出血，部分 NSAIDs 會把 warfarin 從蛋白質上置換下來)。
- Methotrexate：減少排除 → 毒性增加。
- 降低 probenecid 的排尿酸作用；低劑量 aspirin 會**升高尿酸**。
- **G-6-PD 缺乏症**：高劑量 aspirin 可能誘發**溶血**。

## Acetaminophen {#acetaminophen}

| 項目 | 重點 |
|---|---|
| 作用 | **解熱、止痛**；抗發炎作用**很弱**；**不傷胃、不影響血小板、不會雷氏症候群** |
| 用途 | 輕中度疼痛、發燒；**兒童、孕婦**首選；扁桃腺切除術後按時服用 |
| 每日上限 | 成人一般 **3–4 g**；**有肝病、長期喝酒、營養不良、老人**要更低(約 2–3 g)(來源：[UpToDate](https://www.uptodate.com/contents/cancer-pain-management-with-opioids-optimizing-analgesia)) |
| **過量** | 代謝物 NAPQI 耗盡**麩胱甘肽** → **肝細胞壞死**；早期可能只有噁心，**1–3 天後**才出現肝衰竭 |
| 解毒劑 | **N-acetylcysteine**(NAC)，愈早給愈好(8 小時內最有效) |
| 注意 | 許多**綜合感冒藥、止痛複方**都含 acetaminophen，要**計算總量** |

- 例：醫囑 acetaminophen 500 mg QID(每天 2 g)在安全範圍內；給藥前應先了解病人有無**肝臟病史**、飲酒習慣。
- 長期大量使用也和**止痛劑腎病**有關。

## 護理重點 {#nursing}

- 給藥前評估：**消化性潰瘍、出血傾向、腎功能、心衰竭、氣喘**、懷孕週數、是否使用抗凝血藥或鋰鹽。
- NSAIDs **飯後或與食物、牛奶一起**服用；不要空腹；觀察**黑便、吐血、腹痛**。
- 監測腎功能、血壓、水腫、體重；老人盡量短期使用。
- 手術或拔牙前告知醫師正在使用 aspirin 或 NSAIDs。
- 兒童退燒止痛**不用 aspirin**；使用 acetaminophen 或 ibuprofen 要依**體重**計算劑量。
- 衛教不要同時吃多種含 acetaminophen 或多種 NSAIDs 的藥。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- NSAIDs 抑制 **COX**，減少**前列腺素**；**celecoxib** 阻斷前列腺素生合成、**出血機會最低**、**不會**抑制血小板凝集。
- Aspirin：**抗發炎所需劑量最高**；**不是止血藥**；與 **warfarin** 併用增加危險；**ibuprofen** 會減弱其抗血栓作用；副作用有嘔吐、**耳鳴**、幻覺，**不會代謝性鹼中毒**。
- **雷氏症候群**：兒童病毒感染後用 aspirin；**登革熱、血友病、鐮狀細胞貧血的疼痛**都不用 aspirin；**川崎病**例外使用高劑量 aspirin。
- 長期止痛藥 → **止痛劑腎病**(腎小管與間質壞死)。
- NSAIDs 引起的胃潰瘍 → **misoprostol**。
- **Acetaminophen**：用藥前了解**肝臟病史**；扁桃腺切除術後**按時**服用；它**不是** NSAIDs。
:::
