## 重點摘要 {#summary}

- 競爭性阻斷 **β 腎上腺素受體**:β1(心臟)→ 心跳、收縮力、房室傳導 ↓,**腎素分泌 ↓**;非選擇性者也阻斷 β2(支氣管、血管、肝醣分解)。
- 用途:高血壓、**心絞痛**(降低耗氧)、**心肌梗塞後**、**HFrEF**(carvedilol、bisoprolol、metoprolol succinate,**低劑量開始慢慢加**)、心律不整、甲狀腺風暴、食道靜脈曲張、偏頭痛預防、青光眼(timolol)。
- 副作用:**心搏過緩**、房室傳導阻滯、低血壓、疲倦、**支氣管痙攣**、**遮蔽低血糖症狀**。
- **氣喘禁用非選擇性**(如 propranolol);**不可驟停**(反彈性心搏過速、心絞痛、心肌梗塞)。
- 給藥前**量心尖脈一分鐘**,< 60 次/分(依醫囑,常用 50–60)暫停並通知醫師。

## 作用機轉 {#mechanism}

交感神經釋放的正腎上腺素/腎上腺素作用在 β 受體(受體分布見 [[blood-pressure-regulation#autonomic-receptors]]):

| 受體 | 位置 | 被阻斷的結果 |
|---|---|---|
| **β1** | 心肌、竇房結、房室結 | 心跳 ↓(負變時)、收縮力 ↓(負變力)、房室傳導 ↓ → 心輸出量與**心肌耗氧 ↓** |
| **β1** | 腎臟近腎絲球細胞 | **腎素分泌 ↓** → RAAS 被抑制 |
| **β2** | 支氣管平滑肌 | **支氣管收縮**(氣喘、COPD 惡化) |
| β2 | 肝臟、骨骼肌 | 肝醣分解與糖質新生 ↓ → 低血糖恢復變慢 |
| β2 | 骨骼肌血管 | 血管擴張作用消失 → 手腳冰冷 |
| β2 | 睫狀體 | **房水生成 ↓** → 眼壓 ↓(timolol) |

- **降壓機轉**:心輸出量 ↓ + 腎素 ↓ + 中樞交感流出 ↓;第一次給藥不會馬上降壓,需數天到數週。
- **抗心絞痛**:主要是**降低心肌耗氧**(心跳、收縮力、血壓 ↓),心跳變慢使舒張期變長 → 冠狀動脈灌流時間增加;β 阻斷劑**不是**靠擴張血管(見 [[coronary-circulation#oxygen-demand]])。
- **抗心律不整(Class II)**:抑制交感刺激下竇房結**第 4 期去極化**速率 → 自律性 ↓;延長房室結不反應期(見 [[cardiac-output#conduction]])。
- **心衰竭**:長期阻斷過度的交感活化 → 逆轉心室重塑、改善 LVEF、降低死亡與猝死;但**負收縮作用**使急性期可能先變差,所以要「低劑量、慢慢加」。
- 拮抗劑不活化受體,重複給藥**不會造成受體去敏感化**;相反地長期使用使 β 受體數目**上調(up-regulation)**,這就是驟停後反彈的原因。

## 代表藥物 {#agents}

字尾 **-olol**(α+β 阻斷者為 -alol / -ilol)。

### 依選擇性分類 {#classification}

| 類別 | 藥物 | 重點 |
|---|---|---|
| **β1 選擇性(心臟選擇性)** | **Atenolol**(Tenormin)、**Metoprolol**(Betaloc)、**Bisoprolol**(Concor)、**Esmolol**、Betaxolol、Acebutolol、Nebivolol | 支氣管影響較小,但**高劑量時選擇性會消失**;記憶:A–M 開頭多為 β1 選擇性 |
| **非選擇性(β1 + β2)** | **Propranolol**(Inderal)、**Nadolol**、**Timolol**、Pindolol、Sotalol | 氣喘、COPD 禁用或避免 |
| **α1 + β 阻斷** | **Labetalol**(Trandate)、**Carvedilol**(Dilatrend) | 另有 α1 阻斷 → 血管擴張;較易姿勢性低血壓 |
| **內在擬交感活性**(ISA) | **Pindolol**、Acebutolol | 本身有部分致效作用 → 休息時心跳下降較少;**不用於心肌梗塞後與心衰竭** |

### 個別藥物特色 {#individual-agents}

| 藥物 | 特色 |
|---|---|
| **Propranolol** | 非選擇性、**脂溶性高、可通過血腦障壁**(惡夢、失眠、憂鬱、疲倦);用途最廣:甲狀腺風暴、門脈高壓/食道靜脈曲張、偏頭痛預防、本態性顫抖、表演焦慮、抗精神病藥引起的**靜坐不能**、嬰兒血管瘤、法洛氏四重症缺氧發作 |
| **Atenolol** | β1 選擇性、**水溶性**、腎臟排除;中樞副作用少 |
| **Metoprolol** | β1 選擇性;**succinate 緩釋劑型**用於心衰竭,tartrate 為短效 |
| **Bisoprolol** | β1 選擇性高;心衰竭實證藥 |
| **Carvedilol** | α1 + 非選擇性 β;心衰竭實證藥;與食物併服減少姿勢性低血壓 |
| Nebivolol | β1 選擇性並促進 NO 釋放擴張血管;2025 AHA/ACC 指出它較少造成勃起功能障礙(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e151、e181) |
| **Labetalol** | α1 + 非選擇性 β;口服與靜脈;**妊娠高血壓第一線**、**高血壓急症** |
| **Esmolol** | β1 選擇性、**超短效**(半衰期約 9 分鐘,被紅血球酯酶分解);只能靜脈滴注,用於手術中/急性心搏過速、主動脈剝離 |
| **Nadolol** | 非選擇性、水溶性、**半衰期最長**(約 20–24 小時),腎排除;食道靜脈曲張 |
| **Timolol** | 非選擇性;**青光眼眼藥水**(減少房水分泌) |
| **Sotalol** | 非選擇性 β 阻斷 + **Class III**(阻斷鉀通道、延長 QT) |

### Labetalol 與孕婦 {#labetalol-pregnancy}

Labetalol 是**妊娠高血壓與子癲前症**的第一線口服藥(與長效 nifedipine 並列,2025 AHA/ACC COR 1),也用於**孕期急性重度高血壓**(靜脈,與 hydralazine、口服速效 nifedipine 並列);2022 台灣指引建議孕期高血壓危象用**靜脈 labetalol 或 nicardipine** 加硫酸鎂(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e171、e175;[2022 台灣高血壓治療指引](https://doi.org/10.6515/ACS.202205_38%283%29.20220321A),p.293)。注意:

- 氣喘孕婦避免(非選擇性 β)。
- **Atenolol 孕期禁用**(與胎兒生長遲滯、體重較低有關;2025 AHA/ACC COR 3:有害),這不是整類的效果,metoprolol 未見相同問題(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e171、e173–e174)。
- 可能造成新生兒心搏過緩、低血糖 → 出生後觀察新生兒。
- 其他孕期可用降壓藥見 [[central-alpha2-agonists]]、[[direct-vasodilators]]、[[calcium-channel-blockers]];ACEI/ARB 禁用。

## 適應症 {#indications}

| 適應症 | 說明 |
|---|---|
| **高血壓** | 2022 台灣指引將 β 阻斷劑與 ACEI/ARB、CCB、thiazide 並列為**五大第一線**降壓藥(COR I, LOE B)(來源:[2022 台灣高血壓治療指引](https://doi.org/10.6515/ACS.202205_38%283%29.20220321A)),特別適合合併心絞痛、心肌梗塞後、心衰竭、心搏過速或需控制心率者;2025 AHA/ACC 指引則以 thiazide、ACEI/ARB、長效 DHP 類 CCB 為一般第一線,β 阻斷劑預防中風效果較差、副作用較多,**除非有冠心病或心衰竭等強適應症,不建議作為第一線**(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e149、e151)(見 [[hypertension]]) |
| **穩定型心絞痛** | 第一線抗心絞痛藥;與硝酸鹽合用可**抵銷硝酸鹽的反射性心搏過速**(見 [[nitrates]]、[[coronary-artery-disease]]) |
| **急性冠心症/心肌梗塞後** | 無禁忌(心衰竭徵象、低心輸出、休克風險、心搏過緩、傳導阻滯、氣喘發作)時早期開始口服;**LVEF ≤ 40% 者長期使用證據最強** |
| **HFrEF** | **Carvedilol、bisoprolol、metoprolol succinate** 三者有降低死亡率證據;需在**病情穩定、無明顯鬱血**時從**低劑量開始,每 2 週左右加倍**到目標劑量(見 [[heart-failure]]) |
| **心律不整** | 竇性心搏過速、PSVT、心房顫動/撲動心率控制、心室早期收縮、長 QT 症候群 |
| 其他 | 甲狀腺亢進/**甲狀腺風暴**(緩解心悸、顫抖;propranolol 並抑制 T4 → T3)、**食道靜脈曲張出血預防**(非選擇性:propranolol、nadolol、carvedilol)、偏頭痛預防、本態性顫抖、**青光眼**(timolol)、主動脈剝離、肥厚性心肌病變 |

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 機轉/說明 |
|---|---|
| **心搏過緩、房室傳導阻滯** | β1 阻斷;併用 verapamil、diltiazem、digoxin、amiodarone 更明顯 |
| 低血壓、頭暈 | 心輸出量 ↓;α1+β 阻斷者(carvedilol、labetalol)姿勢性低血壓較明顯 |
| **支氣管痙攣** | β2 阻斷;**非選擇性**最危險,β1 選擇性高劑量也可能 |
| 心衰竭惡化 | 負收縮力;急性失償時不可開始或加量 |
| **遮蔽低血糖症狀** | 心悸、顫抖、焦慮等交感症狀被遮蔽(**出汗不受影響**,屬膽鹼性);非選擇性者另外抑制肝醣分解 → 低血糖恢復慢 |
| 疲倦、運動耐力 ↓ | 心跳無法隨運動上升 |
| 中樞症狀 | 惡夢、失眠、憂鬱(脂溶性如 propranolol),影響睡眠品質 |
| 手腳冰冷 | β2 血管擴張消失;周邊動脈疾病、雷諾氏症狀加重 |
| 性功能障礙 | 勃起功能下降 |
| 代謝 | 三酸甘油酯 ↑、HDL ↓(非選擇性);血鉀輕度 ↑ |
| **驟停反彈** | β 受體上調 → 突然停藥時交感刺激放大 → 心搏過速、高血壓、**心絞痛、心肌梗塞、心律不整**;需 1–2 週**逐漸減量** |

**過量**:嚴重心搏過緩、低血壓、低血糖、休克 → atropine、升壓藥,**glucagon**(繞過 β 受體增加 cAMP)為特效處置。

**禁忌或避免**

- **氣喘**、嚴重 COPD 急性期(非選擇性禁用;選擇性小心)。
- **竇性心搏過緩**、病竇症候群、**二度以上房室傳導阻滯**(未裝節律器)。
- **心因性休克**、急性失償心衰竭、低血壓。
- **未經治療的嗜鉻細胞瘤**:必須先用 α 阻斷劑,再加 β 阻斷劑,否則 α 作用失去對抗 → 高血壓危象(見 [[alpha-blockers]])。
- 古柯鹼/安非他命引起的急性胸痛(同理,避免非選擇性)。
- 糖尿病**非禁忌**,但易低血糖者需衛教;優先選 β1 選擇性。
- 變異型心絞痛:可能加重冠狀動脈痙攣,首選 CCB。

## 交互作用 {#interactions}

| 併用 | 結果 |
|---|---|
| **Verapamil、diltiazem** | 嚴重心搏過緩、房室阻滯、心衰竭 |
| Digoxin、amiodarone、ivabradine | 心搏過緩、傳導阻滯 |
| **胰島素、磺醯脲類** | 低血糖症狀被遮蔽、恢復延遲 |
| **Clonidine** | 兩者都要停時,**先逐步停 β 阻斷劑,數天後再停 clonidine**;否則 clonidine 停藥反彈時 α 作用失去對抗 → 嚴重高血壓(見 [[central-alpha2-agonists]]) |
| 腎上腺素(過敏性休克) | 非選擇性 β 阻斷下,腎上腺素效果差且可能 α 作用過強(高血壓、反射性心搏過緩);頑固時用 glucagon |
| β2 致效劑(salbutamol、terbutaline) | 互相抵銷 |
| NSAIDs | 降壓效果 ↓ |
| DHP 類 CCB、硝酸鹽 | 良好組合:β 阻斷劑抵銷其反射性心搏過速 |
| 其他降壓藥、麻醉藥 | 加成低血壓;手術前**不需停藥**(長期服用者整個手術期間持續服用,COR 1;術前驟停可能反彈,COR 3:有害);但從未使用者**不可在手術當天才開始**(COR 3:有害)(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e183) |

## 護理重點與衛教 {#nursing}

- **給藥前量心尖脈一整分鐘與血壓**:心跳 < 60 次/分(依醫囑,常見 50–60)、收縮壓 < 90–100 mmHg,或出現新的房室傳導阻滯 → **暫停給藥並通知醫師**。
- **確認有無氣喘/COPD 病史**;出現喘鳴、呼吸困難立即通報。
- 教導病人在家**自己量脈搏**並記錄。
- **不可自行突然停藥**,即使覺得好了;手術前也照常服用;停藥需醫師指示逐漸減量。
- 糖尿病病人:低血糖時**可能沒有心悸、顫抖**,但仍會出汗、飢餓感;要更常監測血糖。
- 心衰竭病人:剛開始或加量後**每日量體重**,體重 2–3 天增加 > 1–2 公斤、水腫或呼吸困難加重要回診;疲倦感通常數週後改善。
- 起身慢;緩釋劑型(metoprolol succinate)可剝半但不可咬碎;carvedilol 隨餐服用。
- 疲倦、性功能問題、惡夢可與醫師討論換藥,不要自行停藥。
- 兒童使用 propranolol(心臟病、血管瘤):注意**心跳過慢**與低血糖,生病不進食時依醫囑暫停。
- Timolol 眼藥:點藥後壓住**鼻淚管** 1–2 分鐘,減少全身吸收(仍可能心搏過緩、氣喘發作)。
- 靜脈 esmolol、labetalol:輸液幫浦、持續心電圖與血壓監測;labetalol 注射後平躺至少 3 小時避免姿勢性低血壓。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **氣喘病人避免 propranolol / 非選擇性 β 阻斷劑**(阻斷 β2 → 支氣管收縮);「氣喘病人可以用 propranolol」是錯的。
- 服 propranolol 的護理:**確認有無氣喘、給藥前量心跳**;低血鈉、脫水不是它的副作用。
- **Propranolol 會遮蔽低血糖、傾向使血糖下降(不會使血糖上升)**;可通過血腦障壁、治療甲狀腺亢進、抑制腎素分泌。
- **Labetalol 同時阻斷 α 與 β**;**carvedilol 是 β 阻斷劑兼 α1 阻斷**(用於心衰竭)。
- **Atenolol 不會引起反射性心搏過速**(反而心搏過緩);amlodipine、prazosin、hydralazine 會。
- Class II(propranolol)**降低第 4 期去極化**、減少竇房結自律性;**sotalol = Class III 兼 β 阻斷**。
- 半衰期:**nadolol 最長**,esmolol 最短。
- **Timolol**:非選擇性 β 阻斷,**減少房水分泌**,**不是縮瞳劑**;氣喘禁用、給藥前評估心搏徐緩。
- 心絞痛用 propranolol 是**降低心肌耗氧**,不是擴張動脈;與硝酸鹽合用可抵銷反射性心跳加快。
- Propranolol 用於甲狀腺風暴、食道靜脈曲張、靜坐不能;小兒使用注意**心跳過慢**。
- 拮抗劑不會造成受體去敏感化;長期使用受體上調,**不可驟停**。
:::
