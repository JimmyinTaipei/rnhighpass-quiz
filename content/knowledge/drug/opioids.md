## 重點摘要 {#summary}

- 機轉：活化中樞與脊髓的**鴉片受體**(主要是 **μ 受體**)，抑制痛覺傳遞，並改變對疼痛的感受。
- 用於**中度到重度**疼痛(癌症疼痛、術後、燒傷、心肌梗塞)；**強效鴉片類沒有天花板效應**。
- 副作用口訣：**便秘**(不會耐受，要**預防性給軟便劑與瀉劑**)、**呼吸抑制**、**鎮靜**、**針狀瞳孔**、噁心嘔吐、**尿瀦留**、低血壓、搔癢、**欣快感**。**不會**造成腹瀉或高血壓。
- 過量三特徵：**昏迷、針狀瞳孔、呼吸抑制** → **naloxone**。
- 戒斷：打哈欠、流淚流鼻水、**瞳孔放大**、起雞皮疙瘩、**腹瀉**、腹痛、肌肉痛、顫抖、心跳快；**不會體溫過低**。
- 在台灣都屬於**管制藥品**：**嗎啡是第一級**，**fentanyl、pethidine 是第二級**，**tramadol 是第四級**。

## 作用機轉 {#mechanism}

| 受體 | 作用 |
|---|---|
| **μ(mu)** | **止痛**(脊髓以上與脊髓)、**呼吸抑制**、**欣快感**、縮瞳、**便秘**、生理依賴 |
| κ(kappa) | 脊髓止痛、鎮靜、**煩躁不安**、幻覺、利尿 |
| δ(delta) | 止痛、調節情緒 |

- **完全促效劑**：morphine、fentanyl、oxycodone、hydromorphone、methadone、pethidine。
- **部分促效劑**：buprenorphine(μ 部分促效)。
- **促效－拮抗劑**：**pentazocine**(對 **κ 受體**的促效作用強於 μ)、nalbuphine、butorphanol；有天花板效應，用在長期使用完全促效劑的人身上會**誘發戒斷**。
- **拮抗劑**：**naloxone**(注射，急救逆轉)、naltrexone(口服，成癮治療)。
- 疼痛調節的生理見 [[pain-management#physiology]]。

## 代表藥物 {#agents}

| 藥物 | 台灣管制等級 | 重點 |
|---|---|---|
| **Morphine**(嗎啡) | **第一級** | 強效鴉片類的**標準參考藥**；口服、皮下、靜脈、硬膜外；速效錠約每 4 小時一次，長效錠每 12 小時一次；口服與注射劑量比約 **3：1**；代謝物由腎臟排除，**腎衰竭**時會蓄積 |
| **Fentanyl**(吩坦尼) | **第二級** | **強效**(約為嗎啡的 50–100 倍)、脂溶性高；**經皮貼片每 72 小時換一次**，另有靜脈與口頰黏膜劑型；便秘較少；腎功能差時較適合 |
| Oxycodone、hydromorphone | 第二級 | 強效；hydromorphone 常用於腎功能不良 |
| **Pethidine**(meperidine、Demerol) | **第二級** | 代謝物 **normeperidine 會引起顫抖、譫妄、抽搐**，且半衰期長會蓄積 → **不適合癌症疼痛、長期或反覆使用**，腎功能差者與老人避免；與 **MAOI** 併用可能造成嚴重反應(血清素症候群) |
| Methadone(美沙冬) | 第二級 | 半衰期長且不穩定、會**蓄積**；**QT 延長**；用於**鴉片類成癮的替代療法**(每日**口服**，減少共用針頭造成的感染) |
| **Codeine**(可待因) | 高含量為第二級，低含量製劑為第三、四級 | **前驅藥**，需經肝臟 CYP2D6 轉成嗎啡才有效，每個人轉換差異大；**止咳劑量低於止痛劑量**；具成癮性；**便秘** |
| **Tramadol**(特拉嗎竇) | **第四級** | 弱 μ 作用加上抑制血清素、正腎上腺素回收；**降低癲癇閾值**、**血清素症候群**(併用抗憂鬱藥時)；呼吸抑制較少但仍會成癮 |
| Buprenorphine | 第三級 | 部分促效劑；舌下錠或貼片；用於疼痛與鴉片類成癮 |
| **Pentazocine**(潘他唑新) | 第二級 | κ 促效為主；可能引起煩躁、幻覺 |

(管制等級來源：[食藥署 管制藥品分級及品項](https://www.fda.gov.tw/tc/siteListContent.aspx?sid=50&id=2036))

:::note[「弱效」與「強效」]
WHO 最早把 codeine 列為第二階的「弱效」鴉片類，現在認為這個分法在藥理上不精確：codeine 只是**劑量受限**，嗎啡也沒有比其他 μ 促效劑更優越(來源：[UpToDate](https://www.uptodate.com/contents/cancer-pain-management-with-opioids-optimizing-analgesia))。國考仍會問「fentanyl 屬於弱效麻醉性止痛劑」→ **錯**，它是強效。
:::

### Fentanyl 貼片 {#fentanyl-patch}

| 項目 | 做法 |
|---|---|
| 適用 | **穩定的慢性疼痛**(已使用過鴉片類的病人)；**不適合急性或需快速調整**的疼痛 |
| 作用時間 | 貼上後約 **12–24 小時**才達到效果(初期要有救援藥)；**每 72 小時**更換；撕除後藥效仍持續約一天 |
| 黏貼部位 | **平坦、乾淨、乾燥、完整、毛髮少**的皮膚：**前胸、後背、上臂、大腿**；**不一定要貼在疼痛處** |
| 貼法 | 毛髮用剪的不要剃；貼上後以**手掌緊壓約 30 秒**；**不可剪開** |
| 更換 | **每次換不同部位**；**先撕掉舊貼片**再貼新的，**不可重疊或多貼一天**；舊貼片黏面**對折**後依管制藥品規定丟棄或繳回；在貼片或紀錄上**寫日期時間** |
| **避免加熱** | 熱水澡、泡溫泉、烤燈、電熱毯、**發燒**都會**增加吸收** → 可能**呼吸抑制** |
| 其他 | 做 **MRI 前要撕除**(含金屬可能灼傷)；惡病質病人吸收可能較差 |

## 適應症 {#indications}

- **中度至重度疼痛**：癌症疼痛、術後疼痛、**燒傷**(急性期以**靜脈**小劑量給)、創傷。
- **急性心肌梗塞**的胸痛：減輕疼痛與焦慮、擴張靜脈減輕前負荷；現行指引只在硝化甘油無效時使用。
- 急性肺水腫的呼吸困難(傳統用法)；**末期病人的呼吸困難**。
- 止咳(codeine)；止瀉(loperamide、diphenoxylate 為作用在腸道的鴉片類)。
- 麻醉輔助、PCA、硬膜外止痛(見 [[pain-management#pca]])。

## 副作用 {#adverse-effects}

| 副作用 | 會不會耐受 | 處置 |
|---|---|---|
| **便秘** | **不會** | 開始用鴉片類就**預防性**給**刺激性瀉劑**(senna)或**滲透性瀉劑**(PEG、lactulose)，搭配水分與活動；只給纖維不夠 |
| 噁心嘔吐 | 數天內耐受 | 止吐藥 |
| 鎮靜、嗜睡、意識混亂 | 數天到數週耐受 | 評估鎮靜程度；老人注意跌倒與譫妄 |
| **呼吸抑制** | 很快耐受 | 通常**先出現嗜睡**，再出現呼吸變慢變淺；呼吸 < 8–10 次／分或叫不醒 → 停藥、刺激病人、給氧、**naloxone** |
| **縮瞳**(針狀瞳孔) | 不會 | 是鴉片類作用的特徵 |
| **尿瀦留** | — | 觀察解尿、膀胱脹；術後 PCA 病人常見 |
| 低血壓(組織胺釋放、血管擴張) | — | 改變姿勢要慢 |
| 搔癢 | — | 抗組織胺；硬膜外給藥較常見 |
| **欣快感** | — | 是成癮的原因之一 |
| 膽道括約肌收縮 | — | 傳統教材：**morphine 可能加重膽道痙攣**，所以「morphine 可減輕膽道痙攣痛」是錯誤選項；膽絞痛用抗膽鹼劑(Buscopan、atropine)解痙 |
| 肌陣攣、痛覺過敏 | — | 高劑量或腎功能差時；考慮換藥 |

- 鴉片類**不會**造成**腹瀉**、**高血壓**、心跳過快。
- **合併 benzodiazepine、gabapentin、酒精**等中樞抑制劑，呼吸抑制風險大增(來源：[UpToDate](https://www.uptodate.com/contents/prevention-and-management-of-side-effects-in-patients-receiving-opioids-for-chronic-pain))。

:::warning[呼吸抑制的判斷]
鴉片類造成的是**嗜睡加上呼吸變慢**；如果病人是**呼吸急促、焦慮**，那不是鴉片類造成的，要找其他原因(肺栓塞、肺炎等)。
:::

## 過量、耐受、依賴與成癮 {#overdose}

### 急性中毒 {#toxicity}

- 三特徵：**昏迷**(意識抑制)、**針狀瞳孔**、**呼吸抑制**；另有心跳變慢、低血壓、低體溫、肺水腫。**不會**瞳孔放大、腹瀉、血壓上升。
- 海洛因中毒一樣是**瞳孔縮小**。
- 處理：維持呼吸道與通氣，給 **naloxone**(靜脈、肌肉、皮下或鼻噴)。
  - Naloxone **作用時間比多數鴉片類短**(約 30–90 分鐘) → 給藥後要**持續觀察**，可能再次呼吸抑制，需要重複給藥或持續滴注。
  - 長期使用鴉片類的病人(如癌症病人)要**稀釋後小劑量慢慢給**，只要恢復足夠呼吸即可，避免誘發**劇痛與急性戒斷**。
- 產婦在分娩前使用 pethidine 等鴉片類，**新生兒可能呼吸抑制**；產婦呼吸 < 10 次／分也用 naloxone。

### 戒斷症狀 {#withdrawal}

| 系統 | 表現 |
|---|---|
| 類似感冒 | **打哈欠、流淚、流鼻水**、打噴嚏、盜汗、**起雞皮疙瘩** |
| 眼 | **瞳孔放大** |
| 腸胃 | **噁心嘔吐、腹痛、腹瀉** |
| 肌肉 | **肌肉痠痛**、**顫抖**、抽筋 |
| 自律神經 | 心跳加快、血壓上升、發燒(**不會體溫過低**) |
| 精神 | 焦慮、易怒、失眠、**強烈渴求** |

- 短效鴉片類約在最後一次使用後 **6–12 小時**出現；戒斷通常**不會致命**(和酒精、鎮靜安眠藥戒斷不同)。

### 名詞區別 {#dependence-terms}

| 名詞 | 意義 |
|---|---|
| **耐受性**(tolerance) | 同樣劑量效果變差，需要增加劑量；是**正常的藥理現象** |
| **生理依賴**(physical dependence) | 突然停藥或給拮抗劑會出現戒斷；長期使用者都會發生，**不等於成癮** |
| **成癮**(物質使用障礙症) | **失去控制**、強迫性使用、明知有害仍持續使用、渴求 |

- 依醫囑用在疼痛上的病人**很少成癮**；**不能因為怕成癮而不給或少給**止痛藥。
- 「藥效時間變短」要先**重新評估疼痛**(疾病進展？劑量不足？)，而不是直接說「你已經耐藥了」。
- 美沙冬替代療法：**口服**、每日一次、長效，**仍會**有呼吸抑制與戒斷，不能突然停止；目的是減少注射使用與**共用針頭**(HIV、C 型肝炎)。

## 特殊族群 {#special-populations}

- **兒童**：鴉片類用於**中度至重度**疼痛，嗎啡最常用；**避免 meperidine**；**codeine 與 tramadol** 在 12 歲以下與 18 歲以下扁桃腺切除術後**禁用**(部分兒童代謝太快，可能致命的呼吸抑制)(來源：[FDA 2017](https://www.fda.gov/drugs/postmarket-drug-safety-information-patients-and-providers/codeine-information))。
- **老人**：從低劑量開始、慢慢增加；注意譫妄、跌倒、便秘。
- **腎功能不良**：嗎啡、codeine、pethidine 的代謝物蓄積 → 優先 fentanyl、hydromorphone(依醫囑)。
- **懷孕與生產**：分娩時用 pethidine 會通過胎盤 → 觀察產婦**嗜睡**(拉起床欄)、噁心嘔吐、**尿瀦留**，**監測胎心率變異性**，準備新生兒用 naloxone。

## 交互作用 {#interactions}

| 併用 | 結果 |
|---|---|
| Benzodiazepine、安眠藥、酒精、gabapentinoid、抗組織胺 | 中樞抑制與**呼吸抑制**加重 |
| **MAOI**、SSRI 等血清素藥物 + **pethidine、tramadol** | **血清素症候群**(見 [[antidepressants#serotonin-syndrome]]) |
| 促效－拮抗劑(pentazocine)或 naltrexone + 完全促效劑 | 效果下降、誘發戒斷 |
| 其他會便秘的藥：**鐵劑**、**抗膽鹼劑**、鈣離子阻斷劑、**含鋁或鈣的制酸劑** | 便秘更嚴重(含**鎂**的制酸劑反而會腹瀉) |

## 護理重點 {#nursing}

### 給藥前後 {#nursing-administration}

- 給藥前評估**疼痛分數、呼吸速率與深度、鎮靜程度**、血壓；**呼吸 < 10–12 次／分或過度嗜睡**時暫停並通知醫師。
- 看懂醫囑：「morphine 10 mg po **tid**」= **每天三次、固定口服**；「**p.r.n.**」才是需要時。途徑或劑量不清楚時先與醫師**澄清**。
- 給藥後依途徑評值止痛效果與副作用(見 [[pain-management#evaluation]])。
- 預防**跌倒**：嗜睡、姿勢性低血壓，下床要有人協助。
- **便秘預防**與排便紀錄；觀察**解尿**情形。

### 管制藥品管理 {#controlled-drugs}

- 第一到三級管制藥品需用**專用處方箋**；**上鎖、專人保管**、每班**點班**。
- 剩餘藥量丟棄要**有見證人**並記錄；空安瓿、用過的貼片依規定**繳回**。
- 護理師**不可自行斟酌**使用。

### 衛教 {#nursing-education}

- 依時間服藥，**不要自行增減或突然停藥**；長效錠**不可咬碎或剝半**(會一次釋放大量藥物)。
- 多喝水、吃纖維、依指示使用軟便劑或瀉劑；三天沒解便要告知。
- 避免喝酒與自行加服安眠藥；剛開始用藥或加量時**不要開車**。
- 藥物放在兒童拿不到的地方；貼片別讓孩子接觸。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 嗎啡作用在 **μ 受體**；會產生**欣快感**；**pentazocine** 以 κ 受體為主。
- 常見副作用：**便秘、呼吸變慢、噁心、尿瀦留、低血壓、縮瞳**；**不是腹瀉、高血壓、心跳過快**。
- 中毒：**針狀瞳孔、嗜睡昏迷、呼吸抑制、心跳變慢**；解毒劑 **naloxone(Narcan)**。
- 戒斷：流鼻水、嘔吐、顫抖、腹瀉；**不會體溫過低**。
- **Fentanyl 貼片**：**強效**(不是弱效)、**每 72 小時**更換、**手掌壓 30 秒**、換不同部位、不可多貼一天、**避免泡熱水**、不需貼在疼痛處。
- **Codeine**：成癮、止咳，止咳劑量比止痛劑量低，會便秘不是腹瀉。止咳且不成癮的是 **dextromethorphan**。
- **Methadone**：**口服**，可減少共用針頭的感染；仍會呼吸抑制與戒斷。
- 待產用 **meperidine**：注意嗜睡、尿瀦留、噁心，**監測胎心率變異性**；呼吸 < 10 次用 **naloxone**。臨終與兒童**避免 meperidine**。
