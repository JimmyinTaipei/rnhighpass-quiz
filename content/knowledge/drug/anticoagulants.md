## 重點摘要 {#summary}

- 機轉:抑制**凝血因子**,預防血栓**形成或變大**;**不會溶解**已形成的血栓(那是 [[thrombolytics]])。主要用於**靜脈血栓**(DVT、肺栓塞)與**心房顫動、機械瓣膜**的栓塞預防。
- **Heparin**:經抗凝血酶(AT)抑制 IIa、Xa;靜脈或皮下,**監測 aPTT**(1.5–2.5 倍),解毒劑 **protamine sulfate**;注意 **HIT**(血小板下降)。
- **Warfarin**:拮抗**維生素 K** → 肝臟少做 II、VII、IX、X;**監測 PT/INR,目標多為 2–3**;起效慢需與 heparin 重疊;解毒 **維生素 K**;**懷孕禁用**;深綠色蔬菜**攝取量保持穩定**。
- **DOAC**(dabigatran、-xaban 類):固定劑量、不需常規抽血,食物交互作用少;**機械瓣膜禁用**。
- 共同護理:**出血監測與衛教**、軟毛牙刷與電動刮鬍刀、避免肌肉注射、不可自行停藥或加倍補吃。

## 作用機轉 {#mechanism}

![抗血小板、抗凝血與血栓溶解劑的作用位置](/knowledge-images/antithrombotic-drug-sites.svg)

凝血因子瀑布最後都匯集到 **第十因子(Xa)→ 凝血酶(IIa)→ 纖維蛋白原變成纖維蛋白網**。靜脈血流慢,血栓以纖維蛋白網住紅血球為主(紅色血栓),所以靜脈血栓用抗凝血劑;動脈血栓以血小板為主,用 [[antiplatelets]]。

| 藥物 | 作用點 | 監測 |
|---|---|---|
| **Heparin**(未分化肝素,UFH) | 結合**抗凝血酶(antithrombin,AT,舊稱 AT III)**,使它加速抑制 **IIa 與 Xa** | **aPTT**(或 anti-Xa) |
| **LMWH**(enoxaparin 等) | 同樣經 AT,但以抑制 **Xa** 為主 | 通常不需;特殊族群驗 anti-Xa |
| Fondaparinux | 經 AT **只抑制 Xa**(合成五醣) | 不需 |
| **Warfarin** | 抑制**維生素 K 環氧化物還原酶(VKORC1)** → 肝臟無法活化**維生素 K 依賴性因子 II、VII、IX、X**(以及抗凝的 protein C、S) | **PT/INR** |
| **DOAC:Xa 抑制劑** | 直接抑制 Xa:rivaroxaban、apixaban、edoxaban | 不需常規監測 |
| **直接凝血酶抑制劑** | 直接抑制 IIa:dabigatran(口服)、argatroban、bivalirudin(靜脈) | argatroban 看 aPTT |

:::note[補充]
- **PT/INR** 反映外在與共同路徑(VII、X、V、II)→ 監測 **warfarin**(VII 半衰期最短,最早受影響)。
- **aPTT** 反映內在與共同路徑 → 監測 **heparin**。
- 口訣:「**肝素看 aPTT、Warfarin 看 PT**」— 兩者常被互換當錯誤選項。
:::

## 代表藥物 {#agents}

### Heparin(未分化肝素) {#heparin}

| 項目 | 內容 |
|---|---|
| 途徑 | **靜脈**(持續滴注,治療血栓)或**皮下**(預防);**不可口服**(腸道不吸收)、**不可肌肉注射**(血腫) |
| 起效 | 靜脈立即;皮下 20–60 分鐘;半衰期約 1–1.5 小時,停藥後數小時內作用消失 |
| 監測 | 治療劑量維持 **aPTT 為正常(對照)的 1.5–2.5 倍**;ACS 劑量為負荷 60 IU/kg(最多 4000 IU)、滴注 12 IU/kg/h(最多 1000 IU/h),aPTT 目標 **60–80 秒**(合併血栓溶解劑時 50–70 秒);PCI 中改看 **ACT 250–300 秒**(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309))(僅供參考,以醫囑為準);每天驗**血小板**(HIT) |
| 解毒劑 | **Protamine sulfate**(強鹼性蛋白與肝素結合中和);約 1 mg 中和 100 單位肝素,**緩慢靜脈注射**(過快會低血壓、過敏) |
| 懷孕 | **不通過胎盤**,懷孕期抗凝首選(與 LMWH) |
| 其他用途 | 低濃度肝素生理食鹽水沖洗導管(如 Port-A);動脈血氧分析(ABG)專用空針含肝素防凝 |
| 高警訊藥物 | 單位(Unit)不可縮寫成 U,給藥前雙人核對 |

### 低分子量肝素(LMWH) {#lmwh}

Enoxaparin(Clexane)、dalteparin、nadroparin(Fraxiparine)。

- 劑量依體重,**皮下**每 12 或 24 小時;效果可預期,**一般不需驗 aPTT**;HIT 比 UFH 少。
- 經**腎臟**排除 → CrCl < 30 mL/min 要減量或改用 UFH(ACS:enoxaparin 1 mg/kg 皮下每 12 小時,CrCl < 30 改每 24 小時;合併血栓溶解劑且 < 75 歲先 30 mg 靜脈推注,≥ 75 歲不推注、0.75 mg/kg 每 12 小時(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309));僅供參考,以醫囑為準)。
- Protamine 只能**部分**中和。
- 硬脊膜外/脊髓麻醉前後使用 → **硬膜外血腫**導致癱瘓,需依時間間隔給藥並觀察下肢感覺運動。
- 用途:DVT/PE 預防與治療、ACS、懷孕期與癌症相關血栓。

### Warfarin(Coumadin) {#warfarin}

| 項目 | 內容 |
|---|---|
| 途徑 | 口服,每天固定時間一次 |
| 起效 | **慢**:需等既有凝血因子自然耗盡,INR 開始上升需 2–3 天,完整效果 **5–7 天** |
| 與 heparin 重疊 | 初期 protein C 先下降,可能短暫**更容易凝血**;所以急性血栓先用 heparin/LMWH,再與 warfarin **重疊至少 5 天且 INR 連續 24 小時 ≥ 2** 才停注射劑 |
| 監測 | **PT/INR**:開始時頻繁,穩定後約每 4 週(最長可 12 週) |
| 目標 INR | 大多數(心房顫動、DVT/PE、生物瓣膜初期)**2.0–3.0**;**機械性二尖瓣**或合併其他危險因子的機械瓣膜 **2.5–3.5** |
| 解毒 | **維生素 K₁(phytonadione)**:INR 過高無出血 → 暫停 1–2 劑,依醫囑口服小劑量維生素 K;**嚴重出血** → 停藥 + **靜脈維生素 K(緩慢)** + **凝血酶原複合物(4F-PCC)**或新鮮冷凍血漿(維生素 K 需數小時才見效) |
| 懷孕 | **禁用**:通過胎盤,**致畸胎**(第 6–12 週,鼻骨發育不全、骨骼點狀鈣化)與胎兒出血;可哺乳 |

:::tip[小技巧]
病人拿到的 warfarin 常有不同顏色代表不同劑量(例如 1 mg、5 mg);衛教病人**認清劑量與顏色**,並看懂醫囑的切半用法(例:「1# stat & q.d. × 3 天,then 0.5# q.d.」→ 第 4 天起每天半顆)。
:::

### 直接口服抗凝血劑(DOAC) {#doac}

| 藥物 | 作用 | 用法特色 | 解毒劑 |
|---|---|---|---|
| **Dabigatran**(Pradaxa) | 直接**凝血酶(IIa)**抑制 | 每日兩次;**膠囊不可打開或咬碎**(吸收暴增);**放原包裝**防潮;約 80% 經腎排除;常見消化不良 | **Idarucizumab**(Praxbind) |
| **Rivaroxaban**(Xarelto) | **Xa** 抑制 | 每日一次;15、20 mg 需**與食物(晚餐)併服** | **Andexanet alfa**;或 4F-PCC |
| **Apixaban**(Eliquis) | **Xa** 抑制 | 每日兩次;腎功能影響較小 | 同上 |
| **Edoxaban**(Lixiana) | **Xa** 抑制 | 每日一次 | 同上(或 PCC) |

- 優點:起效快(2–4 小時)、固定劑量、**不需常規驗 INR**、與食物交互作用少、顱內出血比 warfarin 少 → 心房顫動與 VTE 多數情況**優先於 warfarin**。
- 缺點:半衰期短,**漏吃一兩劑就失去保護**;腎功能不良需調整;有交互作用(強 CYP3A4/P-gp 抑制或誘導劑)。
- **禁用**:**機械性人工瓣膜**、中重度二尖瓣狹窄合併心房顫動(這兩種仍用 warfarin)、懷孕、嚴重腎衰竭(依藥物而定)。

### 其他注射型 {#parenteral-others}

- **Argatroban**(靜脈,直接凝血酶抑制劑,經肝代謝)、**bivalirudin**(靜脈,經腎,PCI 時用)— **HIT 病人**的替代抗凝劑;不需要 AT 就有作用。
- **Fondaparinux**(皮下,每日一次,ACS 用 2.5 mg):只抑制 Xa,幾乎不引起 HIT;protamine 無效;CrCl < 30 禁用;**不可單獨用於 PCI**(導管內血栓)(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309))。

## 適應症 {#indications}

| 狀況 | 常用藥物 |
|---|---|
| **深層靜脈血栓(DVT)、肺栓塞(PE)** 治療 | LMWH/UFH → warfarin;或直接用 DOAC;一般至少 3 個月 |
| 住院、術後、長期臥床的 **VTE 預防** | 皮下 LMWH、低劑量 UFH;骨科手術後也可 DOAC |
| **心房顫動**預防中風 | 依 CHA₂DS₂-VASc 評分;**DOAC 優先**,機械瓣膜或中重度二尖瓣狹窄用 warfarin(見 [[ecg]]);**heparin 只作短期,不能口服長期預防** |
| **機械性人工瓣膜** | **終身 warfarin**(DOAC 禁用) |
| **生物性人工瓣膜** | 術後約 3–6 個月 warfarin,之後通常改 aspirin,**不需終身抗凝** |
| **急性冠心症** | 在抗血小板之外加注射型抗凝劑,持續到血管重建(住院急性期,見 [[coronary-artery-disease]]):NSTE-ACS 用**靜脈 UFH**,不打算早期導管者可用 enoxaparin 或 fondaparinux;PCI 時用 UFH(STEMI 可用 bivalirudin);**fondaparinux 不可用於支持 PCI**(導管內血栓);接受血栓溶解劑者抗凝最多 8 天或到血管重建,不做導管者**首選 enoxaparin**(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309)) |
| 心導管、體外循環、血液透析 | UFH |
| 腎病症候群 | 預防腎靜脈血栓(高凝狀態) |

:::note[補充]
**瓣膜選擇的考點**:機械瓣耐用但要**終身 warfarin** → 適合較年輕、無出血傾向、**沒有懷孕計畫**者(如 50 歲停經婦女)。**計畫懷孕的年輕女性、高齡者、出血傾向者**選生物瓣(warfarin 致畸胎,生物瓣不需終身抗凝)。
:::

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 說明與處置 |
|---|---|
| **出血**(所有抗凝劑) | 牙齦、鼻、注射處、血尿、**黑便/柏油便**、咖啡色嘔吐物、月經過多、大片瘀青;顱內出血(劇烈頭痛、意識改變)、後腹腔出血(背痛、腰側瘀斑)。處置:停藥、通知醫師、給解毒劑 |
| **肝素誘發血小板減少症(HIT)** | 免疫反應;多在用藥 **5–10 天**血小板下降 > 50%;**矛盾地發生血栓**(動靜脈)。處置:**停所有肝素**(包含**沖管肝素水**、LMWH),改 argatroban 等非肝素抗凝劑;血小板回升前不開始 warfarin |
| 注射處血腫 | 皮下注射技巧不當 |
| 骨質疏鬆、高血鉀 | 長期 heparin |
| **Warfarin 皮膚壞死** | 開始用藥最初幾天,protein C 急降(protein C 缺乏者風險高);所以要與 heparin 重疊 |
| 紫趾症候群 | Warfarin 引起膽固醇栓塞 |
| **致畸胎** | Warfarin(懷孕禁用;改 heparin/LMWH) |
| 消化不良 | Dabigatran |

**禁用或慎用**:活動性出血、出血體質(血友病、嚴重血小板減少)、**主動脈剝離**、近期顱內出血或腦、脊髓、眼部手術、嚴重未控制高血壓、消化性潰瘍出血、嚴重肝病。Warfarin 另禁用於懷孕、無法配合監測者。

## 交互作用 {#interactions}

### Warfarin 與食物 {#warfarin-food}

維生素 K 會**拮抗(降低)**warfarin 的效果。重點是**每天攝取量保持穩定**,不是完全不吃蔬菜(突然大量吃 → INR 下降、易血栓;突然不吃 → INR 上升、易出血)。

| 會**降低** warfarin 效果(INR↓) | 會**增強** warfarin 效果(INR↑,出血) |
|---|---|
| 富含維生素 K:**菠菜、青花菜、甘藍/高麗菜、芥藍、地瓜葉等深綠色蔬菜**、**納豆**、動物肝臟、蛋黃、綠茶(大量)、酪梨 | **銀杏、當歸、丹參**、大蒜、薑、魚油、**黑木耳**、大量蔓越莓汁 |
| 人參、聖約翰草 | **酒精**(急性大量)、葡萄柚汁(部分) |
| 維生素 K 補充劑、營養品 | 高劑量維生素 E |

### Warfarin 與藥物 {#warfarin-drugs}

| 增強效果(出血) | 減弱效果(血栓) |
|---|---|
| **Aspirin**、NSAIDs、其他抗血小板/抗凝劑 | Rifampin、carbamazepine、phenobarbital、phenytoin(長期)等**肝酵素誘導劑** |
| **抗生素**(metronidazole、TMP-SMX、fluoroquinolone、macrolide) | Cholestyramine(減少吸收) |
| Amiodarone、azole 類抗黴菌藥 | 口服避孕藥、雌激素 |
| **甲狀腺素**(加速凝血因子分解)、高劑量 acetaminophen | 維生素 K |
| Cimetidine、omeprazole、部分 statin、allopurinol | |

### 其他 {#other-interactions}

- DOAC:強效 P-gp/CYP3A4 抑制劑(ketoconazole、clarithromycin)↑出血;誘導劑(rifampin、carbamazepine、聖約翰草)↓效果。
- Heparin:與抗血小板、NSAID、血栓溶解劑併用加重出血。
- **Heparin 不受維生素 K 影響** → 使用 heparin 的病人**不需要**限制深綠色蔬菜。

## 護理重點與衛教 {#nursing}

### 皮下注射(Heparin、LMWH) {#sc-injection}

1. 部位:**腹部**,距肚臍至少 **5 公分**(約兩指幅);LMWH 多打在左右前外側腹壁;避開瘀青、疤痕;**輪換部位**。
2. 輕捏起皮膚,使用細短針頭(25–27G),**90 度**(很瘦者 45 度)整支針頭刺入;注射全程保持捏皮。
3. **不要回抽**、**不要按摩搓揉**、不要熱敷 → 避免微血管破裂形成血腫。
4. 拔針後以乾棉球**輕壓**,不搓揉;觀察注射部位瘀血。
5. **LMWH 預充填針筒的氣泡不要排掉**:氣泡在最後推入,可把藥液完全推進組織並封住針道;只有醫囑劑量需要調整(排掉部分藥液)時例外。
6. 肝素**不可肌肉注射**。

### 靜脈 heparin {#iv-heparin}

- 使用輸液幫浦,依 aPTT 結果以流程表調整速率;抽 aPTT **不要從正在輸注肝素的同一條管路**抽。
- 監測血紅素、血比容、**血小板**(HIT)、出血徵象。
- 床旁備有 **protamine sulfate**。

### Warfarin 衛教 {#warfarin-teaching}

- **定期驗 PT/INR**(不是 aPTT),依結果調劑量;記錄於抗凝血卡。
- 每天**固定時間**服用;**漏吃**:當天想起來就補,**隔天才想起來就跳過,絕不可一次吃雙倍**,並記下來告訴醫師。
- 深綠色蔬菜**適量、每天差不多**;避免銀杏、當歸、丹參等中藥與保健食品;任何新藥(含成藥、中藥)先問醫師藥師。
- 懷孕或計畫懷孕要先告知醫師(需換藥)。

### 所有抗凝劑共通:出血預防與觀察 {#bleeding-precautions}

- **軟毛牙刷**、**電動刮鬍刀**、避免牙線用力、避免碰撞與接觸性運動;穿鞋避免受傷。
- 觀察**瘀青、出血點、牙齦出血、流鼻血、血尿、黑便、月經過多**;劇烈頭痛、意識改變、背痛立即就醫。**血尿不是正常現象**。
- 避免**肌肉注射**、不必要的抽血與侵入性處置;抽血或注射後加壓止血時間延長(至少 5 分鐘),用較細的針頭。
- 不要自行服用 aspirin、NSAID;止痛退燒用 acetaminophen(仍需告知劑量)。
- 拔牙、內視鏡、手術前告知醫師正在服用抗凝劑;**停藥時間由醫師依手術出血風險、血栓風險與腎功能決定**,高血栓風險者可能需要「橋接」肝素。參考時間(術前停用,手術當天不算):

  | 藥物 | 中低出血風險手術 | 高出血風險手術 |
  |---|---|---|
  | Warfarin | INR ≤ 2:術前 3–4 天;INR 2–3:術前 5 天;INR ≥ 3:至少 5 天;術前 24 小時驗 INR,**< 1.5** 才手術 | 同左 |
  | Dabigatran | CrCl ≥ 80:24 小時;50–79:36 小時;30–49:48 小時 | CrCl ≥ 80:48 小時;50–79:72 小時;30–49:96 小時 |
  | Rivaroxaban(> 10 mg/天)、Apixaban、Edoxaban | CrCl ≥ 30:24 小時;15–29:36 小時 | 48 小時 |
  | Heparin(靜脈) | 4–6 小時 | 4–6 小時 |
  | Enoxaparin | 24 小時 | 24 小時 |
  | Fondaparinux | 24 小時 | 24 小時 |

  術後止血良好後恢復:warfarin 中低出血風險手術可持續服用、高出血風險 ≤ 24 小時;DOAC 中低風險 24 小時、高風險 48–72 小時(來源:[臺中榮民總醫院埔里分院藥劑科:抗凝血藥與抗血小板藥手術前後停用時間建議表(2026.06.19 修訂)](https://www.pulivh.gov.tw/UploadFiles/WebFiles/WebPagesFiles/Files/0fb9c2db-631c-4590-9c69-929ac822d1e7/抗凝血藥與抗血小板藥手術前後停用時間建議表%2020260619.pdf))。
- 隨身攜帶**抗凝血藥物識別卡**;不可自行停藥。
- 抗凝劑是「**預防血栓形成或擴大**」,**不會溶解**已形成的血栓;已形成的血栓靠身體自己的纖維蛋白溶解系統慢慢溶掉。

### 靜脈血栓病人的護理(配合抗凝治療) {#vte-care}

- 急性 DVT **患肢不可按摩、不可熱敷按壓**(血栓脫落 → 肺栓塞);抬高患肢減輕腫痛。
- 出現**突發呼吸困難、胸痛、心跳加快、咳血、焦慮** → 懷疑**肺栓塞**。
- 預防:早期下床、踝幫浦運動、避免久坐久站、**不要翹腳或交叉雙腿**、避免膝下墊枕與緊身衣物、充足水分;高風險者依醫囑使用彈性襪或間歇性充氣加壓裝置;避免口服避孕藥與吸菸。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **Heparin → aPTT、解毒 protamine sulfate;Warfarin → PT/INR、解毒維生素 K**。「heparin 監測 PT」「warfarin 監測 PTT」「PT 延長打 protamine」都是錯的。
- Heparin 使 aPTT 維持在正常的 **1.5–2.5 倍**。
- Heparin **皮下注射**(可)、不肌肉注射、**不回抽、不按摩**;可以按摩的是肌肉注射的 Demerol,不是 heparin、insulin 或皮內試驗。
- Warfarin 機轉:拮抗維生素 K,抑制 II、VII、IX、X 合成 → 深綠色蔬菜**避免大量、保持穩定**;「鼓勵多吃菠菜」「菠菜會加強 warfarin」都錯。
- 使用 heparin 的病人**不需要**避免深色蔬菜。
- Warfarin 漏吃**不可隔天吃雙倍**;銀杏、黑木耳、當歸會**增強**藥效;甲狀腺素會**增強**抗凝效果。
- 抗凝劑的目的是**抑制血栓生成**,不是溶解血栓、不是控制心跳。
- 心房顫動長期預防栓塞用**口服**抗凝劑(warfarin 或 DOAC),heparin 不能口服。
- Rivaroxaban 是**抗凝血劑**(Xa 抑制劑);clopidogrel、tirofiban、aspirin 是抗血小板藥。
- Argatroban 是**注射型**直接凝血酶抑制劑,用於 HIT,不需 antithrombin。
- 主動脈剝離**不可**用抗凝劑。
- 機械瓣 → 終身 warfarin;生物瓣 → 短期;計畫懷孕與高齡者選生物瓣。
:::
