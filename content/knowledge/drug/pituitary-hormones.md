這一類藥物把下視丘與腦下垂體的激素拿來**補充**（生長激素、desmopressin、催產素、性腺激素），或**抑制**過多的分泌（octreotide、多巴胺致效劑、持續給予的 GnRH 類似物）。激素的生理見 [[hypothalamus-pituitary]]，相關疾病見 [[pituitary-disorders]]、[[diabetes-insipidus-siadh]]

## 重點摘要 {#summary}

| 藥物 | 作用 | 用途與重點 |
|---|---|---|
| **somatropin**（生長激素） | 補充 GH | 兒童**生長激素缺乏**；**皮下**注射、**睡前**給（模仿夜間分泌）；腹部或大腿輪替 |
| **octreotide**(Sandostatin) | **體抑素類似物**，抑制 GH | **肢端肥大症**（可縮小腫瘤）；也用於類癌腹瀉、食道靜脈曲張出血 |
| **pegvisomant** | **GH 受體拮抗劑** | 肢端肥大症 |
| **bromocriptine**、**cabergoline** | **多巴胺致效劑** → 抑制泌乳素 | **泌乳素瘤**（cabergoline 首選）、肢端肥大症、抑制泌乳；bromocriptine 也用於巴金森 |
| **desmopressin**(DDAVP) | 合成 ADH，**抗利尿強、升壓弱** | **中樞性尿崩症首選**；夜尿、血友病 A 與類血友病輕症 |
| **vasopressin** | ADH 本身，抗利尿＋**血管收縮** | 尿崩症（舊）、**敗血性休克**、食道靜脈曲張出血 |
| **oxytocin**(Pitocin) | 子宮收縮、射乳 | **引產**、加強產程、**產後出血**；監測宮縮與胎心音；**水中毒** |
| **性腺激素**（FSH、hCG） | 刺激卵巢與睪丸 | **不孕症**誘導排卵 |
| **GnRH 類似物**(leuprolide) | **持續**給 → 先短暫刺激、之後**抑制** LH、FSH | **前列腺癌**、子宮內膜異位、**性早熟** |

### 國考常考點 {#exam-points}

- 尿崩症首選：**desmopressin**；屬後葉激素可治尿崩症的是 **vasopressin**
- **肢端肥大症**用 **octreotide**、bromocriptine、pegvisomant；**不適用**的是 **corticotropin**(ACTH)；somatropin、leuprolide、methimazole 都不是
- desmopressin 鼻噴劑：噴在鼻黏膜，**不要用力吸**、**不是吸入肺部**；vasopressin tannate 抽藥前**溫熱搖勻**
- 生長激素：**皮下**、腹部或大腿；**不是早上起床時**（睡前）；以發展年齡互動、發掘優勢
- **催產素**是**腦下垂體後葉**激素（不是前葉）；抗利尿作用比 vasopressin **弱**；靜脈→子宮收縮、鼻噴→射乳
- 性腺激素是**糖蛋白**、由**腦下垂體前葉**分泌（不是下視丘）；hCG 可在尿中驗到；FSH 治不孕
- **泌乳素**是**前葉**激素，受**多巴胺抑制**
- 催產素引產：出現**變異性或晚期減速**、宮縮過頻過強（每 2 分鐘以內、持續 >90 秒）、胎心率異常（如 100 次／分）→ **立即停止催產素**；**不需**監測血糖；催產素會**減少**尿量（不是增加）

## 生長激素與其拮抗 {#growth-hormone}

- **somatropin**（重組人類生長激素）
   1. 用途：兒童**生長激素缺乏**、Turner 症候群、慢性腎病的生長遲緩、成人 GH 缺乏
   2. **皮下**注射，**睡前**給藥，模仿夜間分泌高峰；部位**腹部、大腿**、上臂、臀部輪替
   3. 冷藏保存；療程長，定期追蹤身高、骨齡、血糖、甲狀腺功能
   4. 副作用：注射處反應、高血糖、水腫、關節痛、股骨頭骨骺滑脫、脊椎側彎惡化
   5. 心理照護：以**發展年齡**（而非外表）互動，鼓勵發掘**身高以外的優勢**
- **肢端肥大症**的藥物（手術為首選，見 [[pituitary-disorders#gh-excess]]）
   1. **體抑素類似物**：**octreotide**、lanreotide；抑制 GH 分泌、可**縮小腫瘤**；副作用**膽結石**、腹瀉、腹痛、血糖改變
   2. **pegvisomant**：阻斷 GH 受體，IGF-1 下降，但 GH 本身不降
   3. **多巴胺致效劑**（cabergoline、bromocriptine）：對輕度者有效
   4. **corticotropin**(ACTH)與 GH 過多無關，不能治療肢端肥大症

## 多巴胺致效劑 {#dopamine-agonists}

- 機轉：多巴胺是泌乳素的**抑制因子**，致效劑刺激前葉 D2 受體 → **泌乳素下降**
- 用途
   1. **泌乳素瘤**：**cabergoline** 為首選（作用長，一週 1–2 次，副作用較少）；**bromocriptine** 是國考常見答案（每天服、可用於準備懷孕者）；多數腫瘤會縮小（2023 Pituitary Society 共識）
   2. 肢端肥大症（輔助）
   3. 抑制產後泌乳（現在少用）
   4. bromocriptine 也是**巴金森病**用藥（見 [[antiparkinson-drugs]]）
- 副作用：**噁心、嘔吐**、**姿位性低血壓**、頭暈（**從低劑量、睡前隨餐**開始）、鼻塞；衝動控制問題（賭博、購物）；高劑量長期 cabergoline 要注意心臟瓣膜纖維化
- 泌乳素本身是**前葉**激素，生理見 [[hypothalamus-pituitary#lactation]]

## 抗利尿激素製劑 {#adh-analogues}

| | desmopressin(DDAVP) | vasopressin |
|---|---|---|
| 結構 | 合成類似物 | 天然 ADH |
| 作用 | **V2**（抗利尿）為主，**升壓作用很弱** | V2 抗利尿＋**V1 血管收縮** |
| 作用時間 | 長（鼻噴約 8–20 小時） | 短（靜脈） |
| 主要用途 | **中樞性尿崩症首選**、夜間遺尿、**血友病 A 與類血友病**輕症出血 | **敗血性休克**的升壓、食道靜脈曲張出血；尿崩症（舊） |
| 劑型 | **鼻噴劑**、口服、舌下、注射 | 靜脈；舊式油性懸浮液(**vasopressin tannate**) |

- **鼻噴劑**：噴在鼻黏膜吸收，**不要用力吸氣**、**不是吸入肺部**；鼻塞或感冒時吸收差
- **vasopressin tannate**（油性懸浮液，肌肉注射）：抽藥前**溫熱並搖勻**，讓藥物分散均勻；作用可持續 36–72 小時，**絕不可靜脈注射**；這是國考常考的舊劑型
- 台灣醫院現有的是**水溶性 vasopressin**（Pitressin 20 U/mL 注射液）（郭綜合醫院藥品資訊）
   1. 尿崩症：肌肉或皮下注射；食道靜脈曲張出血：靜脈輸注
   2. **嚴重冠心病**、慢性腎炎、動脈硬化惡化者禁用；冠心病人非用不可時，備好硝化甘油、氧氣與抗心律不整藥
   3. 副作用：臉色蒼白、噁心、腹痛、子宮痙攣、頭痛、冒汗、**心絞痛**
   4. 鋰鹽、酒精、heparin 會**減弱**抗利尿作用；carbamazepine、chlorpropamide、三環抗憂鬱劑會**增強**
- **副作用**：給太多 → **水分滯留**、**低血鈉**、頭痛、噁心、意識改變、**體重增加**、尿量減少；監測**體重**、**尿量與尿比重**、**血鈉**；口渴才喝水，避免喝太多
- vasopressin：血管收縮可能造成**心肌缺血**、腹痛、腸缺血、周邊缺血；外滲會組織壞死
- 腎因性尿崩症對 ADH **沒有反應**，改用 thiazide 加限鹽（見 [[diabetes-insipidus-siadh#di-treatment]]）

## 催產素 {#oxytocin}

- **腦下垂體後葉**激素，由下視丘製造；抗利尿作用**比 vasopressin 弱很多**
- **用途**
   1. **引產**、**加強子宮收縮**（產程遲滯）
   2. 胎盤娩出後**預防與治療產後出血**（例如 10 IU 加入 1 L 點滴滴注，依醫囑）
   3. 鼻噴劑曾用於促進**射乳**（現在少用）
- **給藥**：**靜脈滴注**，用**輸液幫浦**、接在主線的**側管**，可隨時關掉；從低劑量開始、依宮縮逐步調高（起始與增加的 mU/min 依各院流程，**待核對**）
- **監測**：**連續電子胎兒監測**（宮縮頻率、持續時間、強度與胎心率）、**血壓**、脈搏、呼吸、**輸出入量**；血糖不是必要監測
- **立即停止**的情況
   1. 宮縮**過頻**（10 分鐘超過 5 次、間隔 2 分鐘以內）或**持續太久**（超過約 90 秒）、子宮張力過高
   2. 胎心率異常：心搏過緩（如 100 次／分）、**晚期減速**或**變異性減速**
   3. 停藥後改**左側臥**、**給氧**、加快主線點滴（不含催產素）、通知醫師
- **副作用**：子宮過度刺激 → 胎兒窘迫、**子宮破裂**；長時間大量給藥有**抗利尿**作用 → **水中毒**、低血鈉、**尿量減少**；快速推注造成低血壓
- 引產的評估（Bishop 分數）與方法見 [[labor-complications#induction]]；產後出血的處置見 [[postpartum-complications#uterine-atony]]

### 其他子宮收縮劑：麥角鹼與前列腺素 {#other-uterotonics}

- 不是腦下垂體激素，但常和催產素一起考，先整理在這裡；產後出血的完整處置見 [[postpartum-complications#uterine-atony]]

| 藥物 | 作用 | 使用時機 | 禁忌與監測 |
|---|---|---|---|
| **麥角鹼類**：methylergonovine(**Methergine**)、ergonovine | 子宮**強直性**收縮、**血管收縮** | **胎兒與胎盤娩出後**，預防與治療產後出血；肌肉注射或口服 | **高血壓**、**子癇前症**、**心臟病**禁用；給藥前後**量血壓**（如 150/100 mmHg 應停藥）；不可在胎兒娩出前給 |
| **PGE2**(dinoprostone) | **軟化子宮頸**、引發宮縮 | 子宮頸未成熟時的**引產** | 子宮過度收縮、發燒、腸胃不適 |
| **PGF2α**(carboprost) | 強力子宮收縮 | 產後出血 | **氣喘**禁用（支氣管收縮） |
| misoprostol(PGE1) | 子宮收縮、軟化子宮頸 | 產後出血、藥物流產（配合 mifepristone） | 腹瀉、發燒 |

- 麥角鹼若在**第二產程前**（胎兒還沒娩出）給，強直收縮會造成**胎兒窘迫**、胎兒或胎盤被卡住
- 產後大量出血時**先按摩子宮底**、排空膀胱，依醫囑給子宮收縮劑；**不可暫停**子宮按摩
- 安胎藥（ritodrine、MgSO₄、nifedipine）作用相反，是**抑制**子宮收縮

## 性腺激素與 GnRH 類似物 {#gonadotropins}

- **性腺激素**(gonadotropins)：FSH、LH、hCG 都是**糖蛋白**；FSH、LH 由**腦下垂體前葉**分泌，hCG 由**胎盤**分泌、可在**尿液**驗到（驗孕）
   1. **FSH**（urofollitropin、follitropin）、menotropin(FSH＋LH)：刺激濾泡發育，治療**不孕**
   2. **hCG**：作用類似 LH，觸發**排卵**
   3. 副作用：**卵巢過度刺激症候群**（腹脹、腹水、少尿、血栓）、多胞胎
- **GnRH 類似物**（leuprolide 等）
   1. **脈衝式**給 → 刺激 LH、FSH（少用）
   2. **持續**給 → 一開始短暫上升(**flare**)，之後受體下調 → LH、FSH 與性激素**大幅下降**
   3. 用途：**前列腺癌**、乳癌、**子宮內膜異位症**、子宮肌瘤、**中樞性性早熟**、試管療程
   4. 副作用：熱潮紅、骨質流失、性慾下降
- 其他：**corticotropin**(ACTH)用於診斷腎上腺功能；重組 TSH 用於甲狀腺癌術後檢查
- 性激素藥物見 [[sex-hormones]]
