## 重點摘要 {#summary}

- 抑制**亨利氏環上升支粗段**的 **Na⁺-K⁺-2Cl⁻ 共同運輸** → **利尿效果最強**,腎功能差時仍有效。
- 用途:**急性肺水腫**、心衰竭體液過多(改善症狀,不改善存活)、腎病/肝硬化水腫、**急性高血鈣**。
- 副作用:**低血鉀**、低鈉、低鎂、**低鈣**、脫水低血壓、高尿酸、**耳毒性**(快速靜注、大劑量、併用 aminoglycoside)。
- 護理:**早上給藥**、每日體重與輸出入量、監測血鉀;靜脈推注要**慢**;併用毛地黃注意中毒。

## 作用機轉 {#mechanism}

上升支粗段負責回收約 **25% 過濾的鈉**,並建立腎髓質的高滲透壓(逆流倍增)。Loop 利尿劑在管腔側阻斷 **Na⁺-K⁺-2Cl⁻ 共同運輸體(NKCC2)**:

![利尿劑在腎元的作用部位](/knowledge-images/diuretic-sites-nephron.svg)

- 大量 Na⁺、Cl⁻、水排出 → **利尿效果最強**(高效能、「天花板高」:劑量增加效果持續增加)。
- 髓質高滲透壓消失 → 集尿管無法濃縮尿液。
- 上升支正常時帶正電的管腔推動 **Ca²⁺、Mg²⁺ 經細胞旁路回收**;阻斷後這個電位消失 → **鈣、鎂排出增加**(→ 低血鈣、低血鎂;也因此可治療高血鈣)。
- 更多鈉流到集尿管 → 換出 K⁺、H⁺ → **低血鉀、代謝性鹼中毒**。
- 靜脈給藥在利尿前幾分鐘就會**擴張靜脈**、降低前負荷(促使前列腺素釋放),這是急性肺水腫時呼吸困難很快改善的原因之一(前負荷見 [[cardiac-output#preload]])。
- 內耳血管紋也有 NKCC1,高濃度藥物干擾內淋巴液的電解質 → **耳毒性**。

## 代表藥物 {#agents}

| 藥物 | 特色 |
|---|---|
| **Furosemide(Lasix®)** | 最常用;口服生體可用率變異大(約 10–90%,平均約 50%),**口服劑量約為靜脈的 2 倍**;名稱記法「Lasix = lasts six hours」 |
| Bumetanide | 效價高(1 mg ≈ furosemide 40 mg),口服吸收穩定 |
| Torsemide | 作用時間長、口服吸收穩定,可一天一次 |
| **Ethacrynic acid** | **不含磺胺結構**,磺胺過敏者的替代藥;耳毒性最強 |

## 適應症 {#indications}

- **急性心衰竭/急性肺水腫**:有體液滯留者都建議靜脈給予(Class I),與氧氣、端坐、血管擴張劑並用。**2026 ESC**:未用過利尿劑者 **furosemide 40 mg IV**;已在口服者給**每日口服劑量的 2 倍**;2 小時點尿鈉 ≥ 70 mmol/L 或 6 小時尿量 ≥ 100 mL/h 表示反應足夠(每 12 小時重複到完全消腫),反應不足則**劑量加倍**或加 acetazolamide/thiazide(來源:[2026 ESC 心衰竭指引](https://doi.org/10.1093/eurheartj/ehag100) p.49、51)。(2021 ESC 寫法為口服量的 1–2.5 倍、新診斷者 20–40 mg。)劑量僅供參考,以醫囑為準。
- **慢性心衰竭有體液滯留**:2022 AHA/ACC/HFSA 與 ESC 皆為 Class I——用來**緩解鬱血症狀**,依體液狀態**動態調整劑量**、用「能維持乾體重的最低劑量」(來源:[2026 ESC 心衰竭指引](https://doi.org/10.1093/eurheartj/ehag100) p.37);HFpEF 有鬱血時也以 loop 利尿劑為第一線(Class I;來源:[2024 台灣心臟學會 HFpEF 指引](https://doi.org/10.6515/ACS.202403_40%282%29.20240206A) p.15);**不降低死亡率**,改善預後要靠 [[arni]]/ACEI、β 阻斷劑、[[potassium-sparing-diuretics|MRA]]、[[sglt2-inhibitors]] 四大支柱(見 [[heart-failure]])。
- 腎病症候群、肝硬化腹水(與 spironolactone 併用,常用比例 spironolactone 100 : furosemide 40)。
- **腎功能不全**(eGFR 低、thiazide 無效時)的水腫與高血壓;AKI 少尿期可用來試圖增加尿量(但**不能**治療 AKI 本身)。
- **急性高血鈣**:先**充分補液**,再給 loop 增加鈣排泄。
- 高血鉀的輔助降鉀(有尿時)、SIADH(合併高張食鹽水)。

## 藥動重點 {#pharmacokinetics}

| 途徑 | 起效 | 高峰 | 作用時間 |
|---|---|---|---|
| 靜脈注射 | **約 5 分鐘** | 30 分鐘 | 約 2 小時 |
| 口服 | 30–60 分鐘 | 1–2 小時 | **6–8 小時** |

- 需被分泌到管腔才有效:低白蛋白、腎功能差時需要較高劑量。
- 半衰期短 → 一天一次給藥後會有「反彈性鈉滯留」,嚴重水腫常需一天兩次或持續輸注。

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 說明與處置 |
|---|---|
| **低血鉀** | 最常見也最危險:肌肉無力、腹脹便秘、心悸、心律不整、**U 波**;併用毛地黃易中毒。監測 K⁺、補鉀或併用保鉀劑 |
| 低血鈉、低血氯、**低血鎂** | 低血鎂使低血鉀難以矯正 |
| **低血鈣** | 與 thiazide 相反 |
| **脫水、低血容積、姿勢性低血壓** | 老人跌倒;過度利尿 → 腎前性急性腎損傷(BUN/Cr 上升) |
| 代謝性鹼中毒 | 與低血鉀、低血氯並存 |
| 高尿酸、痛風 | 慎用於痛風病人 |
| 高血糖、高血脂 | 較 thiazide 輕 |
| **耳毒性** | 耳鳴、聽力下降、眩暈;與**快速靜注、高劑量、腎功能不全、併用 aminoglycoside/cisplatin** 有關;通常可逆,但可能永久 |
| 磺胺過敏 | furosemide、bumetanide、torsemide 含磺胺基,可改用 ethacrynic acid |
| 光敏感、皮疹 | 防曬 |

**禁忌/慎用**:無尿、嚴重低血鉀/低血鈉或脫水未矯正、肝昏迷前期(電解質變化與低血鉀會使血氨上升)。

## 交互作用 {#interactions}

| 併用藥物 | 結果與處置 |
|---|---|
| **Aminoglycoside(gentamicin 等)** | **耳毒性、腎毒性加成**;盡量避免,必須併用時監測聽力、腎功能與藥物濃度 |
| **[[digoxin|毛地黃]]** | 低血鉀、低血鎂 → **毛地黃中毒**;給藥前確認血鉀 |
| 鋰鹽 | 血鋰上升 |
| NSAID | 利尿與降壓效果下降、腎損傷 |
| 類固醇、amphotericin B、β₂ 促效劑 | 加重低血鉀 |
| ACEI/ARB/ARNI | 開始時姿勢性低血壓、腎前性腎損傷 |
| Cisplatin、vancomycin | 耳/腎毒性加成 |
| 降血糖藥 | 血糖稍升 |
| Milrinone | 同一條管路混合會產生沉澱,需分開管路 |

## 護理重點與衛教 {#nursing}

### 給藥 {#administration}

- **早上給藥**(如 8 AM);一天兩次時第二劑約在下午 2–4 點前,避免夜尿影響睡眠與夜間跌倒。醫囑「Lasix 1# PO PC QD」→ 早餐飯後服用。
- **靜脈推注要慢**:一般 furosemide 靜脈推注 **1–2 分鐘以上**(約不超過 20 mg/min);**大劑量(常見定義 > 80–120 mg)以輸注方式、速率 ≤ 4 mg/min**,以降低耳毒性。
- 注射液**避光**,變黃者勿用;不可與酸性藥物(如 milrinone、dobutamine 部分配方)同管混合。
- 給藥前評估:血壓、心跳、**血鉀**、腎功能、肺音、水腫程度。

### 監測 {#monitoring}

- **每日同一時間、同一磅秤、相似衣著量體重**;1 天增加 > 1 kg(或 1 週 > 2 kg)要通報——比輸出入量更可靠(ESC 將體重增加 > 2 kg/週列為心衰竭徵象;來源:[2026 ESC 心衰竭指引](https://doi.org/10.1093/eurheartj/ehag100) p.22)。
- 記錄輸出入量;急性期觀察給藥後尿量(靜脈給藥後 30–60 分鐘應出現明顯利尿)、呼吸困難與囉音是否改善。
- 追蹤 K⁺、Na⁺、Mg²⁺、BUN/Cr;**心電圖出現 U 波**或病人肌肉無力、心悸 → 懷疑低血鉀。
- 觀察脫水(口乾、皮膚彈性差、姿勢性低血壓)與耳毒性(耳鳴、聽力改變)。

### 衛教 {#education}

- 除非另有醫囑(腎衰竭、併用保鉀劑),**適量攝取高鉀食物**(香蕉、柳丁、奇異果、深綠色蔬菜、馬鈴薯),**不是避免含鉀食物**。
- 同時服用 warfarin 者:維持高鉀飲食,**維生素 K 攝取保持穩定、避免突然大量**(國考選項常寫「限維生素 K」)。
- 起身放慢、夜間備便器與夜燈,**預防跌倒**(利尿劑屬高跌倒風險藥物)。
- 限鈉飲食;不自行停藥或加量;出現耳鳴、聽力下降、嚴重抽筋、頭暈要回診。
- 防曬;糖尿病與痛風病人追蹤血糖、尿酸。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- Furosemide 分類 → **亨利氏環利尿劑**,作用於上升支粗段的 **Na⁺-K⁺-2Cl⁻**(不是鈉-氫交換、不是遠曲小管)。
- **利尿效果最強**、可**治療高血鈣** → furosemide(thiazide 反而升高血鈣)。
- **耳毒性** → loop diuretics;**加重 gentamicin 的耳毒性** → furosemide。
- Furosemide **會造成低血鉀**(「造成血鉀過高」錯);護理指導是**適量攝取含鉀食物**,「避免含鉀食物」錯。
- 長期服用 furosemide + warfarin → **高鉀、限(穩定)維生素 K** 飲食。
- CABG 術後或心因性休克時,furosemide 的目的 → **降低前負荷**。
- 肝昏迷(肝性腦病變)**不是**用利尿劑排氨,而是 lactulose;食道靜脈曲張出血也不用 furosemide。
:::
