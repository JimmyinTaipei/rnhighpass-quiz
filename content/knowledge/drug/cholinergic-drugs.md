這一頁整理作用在**乙醯膽鹼(ACh)**系統的藥物：增強 ACh 作用的**擬膽鹼藥**與**抗膽鹼酯酶藥**、阻斷 M 受體的**抗膽鹼藥**，以及阻斷骨骼肌 N 受體的**神經肌肉阻斷劑**。受體的位置與作用見 [[autonomic-nervous-system#receptors]]，失智症用的乙醯膽鹼酯酶抑制劑見 [[anti-dementia-drugs]]

## 重點摘要 {#summary}

- **擬膽鹼藥**（直接活化 M 受體）：**bethanechol** 治療術後與弛緩型神經性膀胱的**尿滯留**；**pilocarpine** 點眼**縮瞳、增加房水排出**治療青光眼
- **抗膽鹼酯酶藥**（抑制 AChE）：neostigmine、**pyridostigmine(Mestinon)**治療**重症肌無力**；physostigmine 可進入中樞，解抗膽鹼藥中毒；**有機磷**與**沙林**是不可逆的 AChE 抑制劑
- ACh 過多的表現（膽鹼性危象、有機磷中毒）：**流涎、流淚、頻尿、腹瀉、嘔吐、出汗、支氣管分泌物多、瞳孔縮小、心跳變慢**，加上肌肉顫動、無力、呼吸衰竭
- **有機磷中毒**解毒：**atropine**（拮抗 M 作用）＋**pralidoxime(PAM)**（使 AChE 復活）；**atropine 要給到肺部分泌物乾、心跳 > 80 次／分**；照護者要戴手套與隔離衣
- **抗膽鹼藥**（阻斷 M 受體）：atropine、scopolamine、ipratropium、oxybutynin、trihexyphenidyl；副作用是**口乾、視力模糊、畏光、便秘、尿滯留、心跳快、皮膚乾熱、老人意識混亂**
- 抗膽鹼藥**禁用**：**閉角型青光眼**、**攝護腺肥大**、腸阻塞
- 神經肌肉阻斷劑：**succinylcholine** 是**去極化型**（先肌束顫動再麻痺，副作用呼吸暫停、高血鉀、惡性高熱）；其他（rocuronium、tubocurarine 等）是**非去極化型**，可用 neostigmine 或 sugammadex 逆轉
- **肉毒桿菌毒素**阻止 ACh 釋放，用於除皺與肌肉痙攣

### 國考常考點 {#exam-points}

- Pilocarpine 的拮抗劑是 **atropine**；治療青光眼、**直接作用於膽鹼性受體**的是 **pilocarpine**（echothiophate 是抑制 AChE）
- **Bethanechol** 直接活化 M 受體，**不抑制 AChE**；physostigmine、sarin、edrophonium 都會抑制 AChE
- 弛緩型神經性膀胱：使用**副交感神經刺激劑**(bethanechol)幫助逼尿肌收縮
- 對中樞 AChE 影響最小：**neostigmine**（四級銨，不易通過血腦障壁）
- Physostigmine 會**縮瞳**、心跳變慢、血壓下降、逼尿肌收縮；**瞳孔放大不是**它的作用
- 沙林中毒的症狀：瞳孔縮小、頻尿、唾液增加；**心跳加速不是**（會變慢）
- 有機磷（巴拉松）中毒：**先給 atropine 與 pralidoxime**，不必等抽血結果；**有拮抗劑**；apomorphine（催吐劑）與 morphine **都不是**拮抗劑
- Atropine 的目標是心跳**大於 80 次／分**，維持在 60 次／分是錯的
- 有機磷可經**吸入、攝食、皮膚**吸收，照護者要戴口罩、手套、隔離衣，除去污染衣物並協助沐浴洗頭
- **Tensilon(edrophonium)test** 是**重症肌無力**最具代表性的檢查
- 重症肌無力用藥：**準時服藥**（延遲可能喪失吞嚥力量）、**服藥後再運動或進食**、飯前服用；**腹部絞痛是過量**的徵象，不是劑量不足
- **膽鹼性危象**：Mestinon 過量 → 瞳孔縮小、視力模糊、分泌物多、腹痛腹瀉、**血壓下降、心搏過緩**（不是血壓上升、心跳快）；處置是**停用 pyridostigmine、靜脈注射 atropine**
- 阻斷 M 受體的結果：**心跳速率上升**
- 三環抗憂鬱藥的口乾、便秘、視力模糊來自阻斷**蕈毒鹼受體**
- **Ipratropium** 吸入可減少黏液分泌、緩解支氣管痙攣（COPD 常用）
- **Atropine 不適合**治療陣發性上心室心律不整（會加速房室傳導）；可治療毛地黃中毒的心搏過緩與房室阻斷
- 抗膽鹼藥**不能治療青光眼**（atropine、cyclopentolate 會升高眼壓）；**青光眼不是**毒蕈鹼拮抗劑的適應症（膀胱痙攣、巴金森氏症、消化道痙攣才是）
- Trihexyphenidyl(Artane)要**監測眼壓**，預防青光眼
- 膀胱過動的急迫性尿失禁用 **oxybutynin**
- **Scopolamine** 預防暈車暈船；臨終嘎音可用 **scopolamine**，**不要一直抽痰**、可側臥
- 抗膽鹼藥會造成**便秘**與**尿瀦留**（鐵劑、嗎啡也會便秘）
- 內視鏡檢查前可注射 atropine 減少唾液分泌，但**一定要禁食**
- 去極化型神經肌肉阻斷劑：**succinylcholine**；副作用是**呼吸暫停**（不是低體溫、低血鉀）
- **肉毒桿菌毒素**除皺的機轉：**阻止乙醯膽鹼釋放**
- 青光眼用藥：縮瞳劑(pilocarpine)**促進房水排出**；timolol（β 阻斷劑）與 **diamox(acetazolamide)減少房水生成**；前列腺素類似物是**增加排出**

## 膽鹼性受體與藥物作用位置 {#overview}

| 類別 | 作用位置 | 結果 |
|---|---|---|
| 直接作用擬膽鹼藥 | 直接活化 **M 受體** | 副交感作用增強 |
| 抗膽鹼酯酶藥 | 抑制 **AChE**，ACh 不被分解 | M 與 N 受體都受刺激（副交感＋骨骼肌） |
| 抗膽鹼藥 | 阻斷 **M 受體** | 副交感作用被拿掉 |
| 神經肌肉阻斷劑 | 阻斷骨骼肌 **N_M 受體** | 骨骼肌鬆弛、麻痺 |
| 肉毒桿菌毒素 | 阻止神經末梢**釋放 ACh** | 弛緩性麻痺 |

- M 受體活化後的作用：**瞳孔縮小**、睫狀肌收縮（看近）、**分泌增加**（淚液、唾液、汗液、支氣管分泌）、**支氣管收縮**、**腸胃蠕動增加**、**逼尿肌收縮**、**心跳變慢**、血管擴張（血壓下降）
- 記法 SLUDGE：流涎(Salivation)、流淚(Lacrimation)、排尿(Urination)、排便與腹瀉(Defecation)、腸胃絞痛(GI)、嘔吐(Emesis)，加上心跳變慢、支氣管收縮與分泌物多、瞳孔縮小

## 直接作用擬膽鹼藥 {#direct-agonists}

| 藥物 | 用途 | 重點 |
|---|---|---|
| **Bethanechol**(Urecholine) | 術後與產後**非阻塞性尿滯留**、**弛緩型神經性膀胱**、術後腸麻痺 | 選擇性作用於膀胱與腸胃的 M 受體；**不被 AChE 分解**；口服或皮下，**不可肌肉或靜脈注射**（嚴重低血壓、心跳停止）；**機械性阻塞禁用** |
| **Pilocarpine** | **青光眼**（點眼）；口乾症（Sjögren 症候群、頭頸部放療後） | 縮瞳、睫狀肌收縮 → 小樑網打開、**房水從許萊姆氏管排出增加**；副作用：看遠模糊、夜間視力差、眉弓痛 |
| Carbachol | 青光眼、眼科手術縮瞳 | 同時作用 M 與 N |

- 禁忌：氣喘（支氣管收縮）、消化性潰瘍、心搏過緩、甲狀腺亢進、腸道或膀胱阻塞
- 過量時出現 SLUDGE 與心跳變慢，拮抗劑是 **atropine**

## 抗膽鹼酯酶藥 {#anticholinesterases}

| 藥物 | 可逆性 | 進入中樞 | 用途 |
|---|---|---|---|
| **Neostigmine**(Prostigmin) | 可逆 | **否**（四級銨） | 重症肌無力、術後腸麻痺與尿滯留、**逆轉非去極化型肌肉鬆弛劑** |
| **Pyridostigmine**(Mestinon) | 可逆 | 否 | **重症肌無力**的主要口服藥（作用比 neostigmine 長） |
| **Edrophonium**(Tensilon) | 可逆、**極短效**（數分鐘） | 否 | **Tensilon test** 診斷重症肌無力、區分肌無力危象與膽鹼性危象 |
| **Physostigmine** | 可逆 | **是**（三級胺） | **抗膽鹼藥中毒**（atropine、曼陀羅）的解毒；青光眼 |
| Donepezil、rivastigmine、galantamine | 可逆 | 是 | **阿茲海默症**（見 [[anti-dementia-drugs#mechanism]]） |
| Echothiophate | 不可逆 | 否 | 青光眼（少用） |
| **有機磷**殺蟲劑（巴拉松）、**沙林**等神經毒氣 | **不可逆** | 是 | 毒物 |

- 抗膽鹼酯酶藥使 M 與 N 受體都受刺激，所以除了 SLUDGE 以外，還有**肌肉顫動**，大量時骨骼肌與呼吸肌**無力、麻痺**

### 重症肌無力的用藥護理 {#myasthenia-gravis}

- **準時服藥**：藥效時間有限，延遲可能喪失吞嚥與咀嚼力量
- 在**飯前約 30–60 分鐘**服藥，藥效出現時再進食，減少嗆咳
- **服藥後再運動或活動**，避免過度勞累
- 國考答案：鼓勵攝取**高蛋白**食物（考選部列為正確）
- 觀察過量徵象：**腹部絞痛、腹瀉、流涎、出汗、肌束顫動**，是**劑量過多**，不是不足
- 疾病本身（自體抗體破壞 ACh 受體）與危象處理見 [[neuron-synapse#neuromuscular-junction]]；神經疾病頁之後會整理在 H 組

| | 肌無力危象(myasthenic crisis) | 膽鹼性危象(cholinergic crisis) |
|---|---|---|
| 原因 | 藥物**不足**、感染、壓力、停藥 | 抗膽鹼酯酶藥**過量** |
| 表現 | 肌肉無力、呼吸困難，**沒有** SLUDGE | 肌肉無力、呼吸困難，加上**瞳孔縮小、視力模糊、分泌物多、腹痛腹瀉、心搏過緩、血壓下降**、肌束顫動 |
| Tensilon test | 症狀**改善** | 症狀**惡化**（要備好 atropine） |
| 處置 | 維持呼吸道、**增加**抗膽鹼酯酶藥、血漿置換或 IVIG | 維持呼吸道、**停用** pyridostigmine、**靜脈注射 atropine** |

- 現在診斷重症肌無力以**抗體檢驗**（抗 ACh 受體抗體等）與神經電生理檢查為主，Tensilon test 已少用，但國考仍考它是最具代表性的檢查

### 有機磷與神經毒氣中毒 {#organophosphate-poisoning}

- **機轉**：不可逆地抑制 AChE → ACh 在 M、N 受體與中樞堆積；時間久了酵素「老化」，PAM 就無法讓它復活
- **進入途徑**：**吸入、攝食、皮膚**（與眼睛）吸收
- **症狀**
  1. M 作用：**瞳孔縮小（針尖狀）**、流淚、**流涎**、**支氣管分泌物多與支氣管收縮**、嘔吐腹瀉、頻尿與失禁、出汗、**心跳變慢**
  2. N 作用：**肌肉顫動**、抽搐，之後**無力、麻痺**（包括呼吸肌）；交感神經節受刺激也可能心跳快、血壓高
  3. 中樞：意識混亂、抽搐、昏迷、**呼吸抑制**
  4. 死因多是**呼吸衰竭**（分泌物、支氣管收縮、呼吸肌麻痺、中樞抑制）
- **處置**
  1. **維持呼吸道**，必要時插管；給氧
  2. **Atropine** 靜脈注射，拮抗 M 作用：劑量常常很大，依反應加倍追加，直到**胸部聽診清楚（分泌物乾）、心跳 > 80 次／分、收縮壓 > 80 mmHg、瞳孔不再針尖狀、腋下乾燥**（阿托品化）（來源：[Eddleston 等，Lancet 2008](https://doi.org/10.1016/S0140-6736(07)61202-1）)
  3. **Pralidoxime(PAM)**：使被抑制的 AChE **復活**，要在酵素老化前**及早**給；可改善 N 作用造成的肌肉無力（atropine 對肌肉無力沒有效）
  4. 抽搐時給 benzodiazepine
  5. **除污**：除去污染的衣物、**沐浴並清洗頭髮**；照護者戴**口罩、手套、穿隔離衣**，保持通風
- 不可用的藥：**morphine**（抑制呼吸）、**succinylcholine**（由同一類酵素分解，作用會延長）；apomorphine 是催吐劑，不是拮抗劑
- **腸胃除污**：考題選項把**胃灌洗**列為處置之一；目前毒物學會的立場是**不要常規洗胃**，只在服毒後很短時間內、量大且已保護呼吸道時才考慮；也**不建議催吐**（意識可能很快變差，增加吸入風險）（來源：[AACT／EAPCCT 2013 胃灌洗立場聲明](https://doi.org/10.3109/15563650.2013.770154)）
- 107-2 年考題（哪一種毒素會抑制 AChE）：沙林與有機磷都對，考選部兩個都給分

## 抗膽鹼藥（M 受體阻斷劑） {#antimuscarinics}

| 藥物 | 用途 |
|---|---|
| **Atropine** | **症狀性心搏過緩**（包括毛地黃中毒的心搏過緩、房室阻斷）、術前或檢查前**減少唾液與呼吸道分泌**、**有機磷中毒**、散瞳 |
| **Scopolamine**(hyoscine hydrobromide) | **預防暈車暈船**（耳後貼片，出發前數小時貼）、**臨終嘎音**（減少分泌物）；中樞作用強，易嗜睡、混亂 |
| Hyoscine butylbromide(Buscopan) | 腸胃道、膽道與泌尿道**痙攣絞痛**；不易進入中樞 |
| Glycopyrrolate | 術中減少分泌物、與 neostigmine 併用；不進入中樞 |
| **Ipratropium**、tiotropium | 吸入，**COPD** 與急性氣喘，擴張支氣管、**減少黏液分泌**（見 [[asthma-drugs#anticholinergics]]） |
| **Oxybutynin**、tolterodine、solifenacin | **膀胱過動**、急迫性尿失禁、膀胱痙攣 |
| **Trihexyphenidyl**(Artane)、benztropine | **巴金森氏症**的顫抖與僵硬、抗精神病藥引起的錐體外症狀（見 [[antipsychotics]]） |
| **Cyclopentolate**、tropicamide | 眼科檢查**散瞳**與睫狀肌麻痺 |

- **抗膽鹼副作用**（也是 atropine 中毒的表現）
  1. **口乾**、皮膚乾、**不出汗 → 體溫上升**、皮膚潮紅
  2. **散瞳、畏光、視力模糊**（看近不清）、**眼壓升高**
  3. **心跳加快**
  4. **便秘**、**尿滯留**
  5. 中樞：意識混亂、譫妄、幻覺（老人與兒童特別容易）
- 記法：「熱得像兔子、乾得像骨頭、紅得像甜菜、瞎得像蝙蝠、瘋得像帽匠」
- 很多藥有抗膽鹼副作用：**三環抗憂鬱藥**、第一代抗組織胺、phenothiazine 類抗精神病藥
- **禁忌**：**閉角型青光眼**、**攝護腺肥大**與尿路阻塞、腸阻塞、快速性心律不整
- **Atropine 不能治療陣發性上心室頻脈**：它阻斷迷走神經，房室傳導變快、心跳更快
- 解毒：**physostigmine**（可進入中樞）
- 護理：口乾可含冰塊、無糖口香糖；注意排尿與排便；戴太陽眼鏡；不要在高溫下劇烈運動；老人要注意跌倒與意識改變

## 青光眼用藥與自主神經 {#glaucoma-drugs}

| 類別 | 代表藥 | 機轉 |
|---|---|---|
| 擬膽鹼藥（**縮瞳劑**） | **Pilocarpine**、carbachol | 睫狀肌收縮、小樑網打開 → **房水排出增加** |
| 抗膽鹼酯酶藥 | Physostigmine、echothiophate | 同上（間接） |
| **β 阻斷劑** | **Timolol** | **減少房水生成**；**不是縮瞳劑**；氣喘禁用、注意心搏過緩（見 [[beta-blockers]]） |
| **碳酸酐酶抑制劑** | **Acetazolamide(Diamox)**、dorzolamide | **減少房水生成** |
| α2 致效劑 | Brimonidine | 減少房水生成、增加排出 |
| 前列腺素類似物 | Latanoprost | 增加葡萄膜鞏膜途徑的**排出**（不是抑制生成） |
| 高張劑 | Mannitol | 急性青光眼時快速降眼壓 |

- **抗膽鹼藥**（atropine、cyclopentolate）會散瞳、使房角變窄、房水排出受阻，**閉角型青光眼禁用**，也**不能**用來治療廣角性青光眼
- 青光眼本身與點眼方法之後在眼疾病頁（J 組）整理

## 神經肌肉阻斷劑 {#neuromuscular-blockers}

| | 去極化型 | 非去極化型（競爭型） |
|---|---|---|
| 代表藥 | **Succinylcholine**(suxamethonium) | **Tubocurarine**（箭毒）、pancuronium、vecuronium、**rocuronium**、atracurium、cisatracurium、mivacurium |
| 機轉 | 像兩個 ACh 接在一起，**持續去極化**終板 → 先**肌束顫動**、再弛緩性麻痺 | **競爭阻斷** N_M 受體，不引起去極化 |
| 作用時間 | 起效快、**短**（約 5–10 分鐘）；由血漿**假性膽鹼酯酶**分解 | 中到長效 |
| 逆轉 | **不能**用抗膽鹼酯酶藥逆轉（反而加強） | **Neostigmine**（併用 atropine 或 glycopyrrolate 拮抗 M 作用）；rocuronium、vecuronium 可用 **sugammadex** |
| 主要用途 | **快速插管** | 插管、手術中維持肌肉鬆弛、呼吸器病人 |

- **Succinylcholine 的副作用**
  1. **呼吸暫停**（呼吸肌麻痺），假性膽鹼酯酶缺乏的人會延長
  2. **高血鉀**（燒燙傷、大面積壓碎傷、長期臥床、脊髓損傷病人特別危險）
  3. **惡性高熱**（與吸入性麻醉藥併用時）：體溫急升、肌肉僵硬、高碳酸血症，用 **dantrolene** 治療
  4. 術後肌肉痠痛、眼壓與顱內壓暫時上升、心律不整
- 神經肌肉阻斷劑**沒有鎮靜與止痛作用**，病人可能意識清楚卻無法動，一定要**同時給鎮靜與止痛**，並以呼吸器維持通氣
- **肉毒桿菌毒素**：切斷 SNARE 蛋白、阻止 ACh 釋放 → 局部肌肉弛緩性麻痺，用於除皺、斜視、眼瞼痙攣、腦性麻痺或中風後痙攣；不是使肌肉壞死（神經肌肉接合處的毒素整理見 [[neuron-synapse#neuromuscular-junction]]）
