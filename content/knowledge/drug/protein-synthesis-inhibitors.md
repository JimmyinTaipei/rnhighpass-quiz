## 重點摘要 {#summary}

- 機轉：結合細菌核糖體，**抑制蛋白質合成**；多數是**抑菌劑**。四環黴素作用在 **30S**，巨環類、chloramphenicol、clindamycin 作用在 **50S**。
- 用途：**非典型病原**(黴漿菌、披衣菌、立克次體)、青黴素過敏者的替代藥；巨環類用於**黴漿菌肺炎**、百日咳、**幽門桿菌**(clarithromycin)；doxycycline 用於**恙蟲病**。
- 招牌副作用：四環黴素**牙齒變色、光敏感、與鈣鐵螯合**；巨環類**腸胃不適、QT 延長、藥物交互作用**；chloramphenicol **骨髓抑制、灰嬰症候群**；clindamycin **困難梭菌腸炎**。
- 護理重點：tetracycline **不可配牛奶、制酸劑、鐵劑**，以開水服用；8 歲以下與孕婦避免；避免曬太陽。

## 作用機轉 {#mechanism}

| 類別 | 結合部位 | 效果 |
|---|---|---|
| **四環黴素類** | **30S**，阻止 tRNA 進入 | 抑菌；抗菌範圍廣 |
| **巨環類** | **50S**，阻止胜肽鏈移位延長 | 多為抑菌 |
| chloramphenicol | 50S，抑制胜肽基轉移酶 | 抑菌(對部分腦膜炎病原殺菌) |
| clindamycin | 50S | 抑菌；也能**抑制毒素產生** |
| linezolid | 50S 起始複合體 | 見[[glycopeptides]] |

巨環類與 clindamycin 的結合位置相近，細菌的 *erm* 基因甲基化核糖體後，**兩者會同時抗藥**。

## 四環黴素類 {#tetracyclines}

### 代表藥與用途 {#tetracycline-uses}

| 藥物 | 用途 |
|---|---|
| **doxycycline** | **恙蟲病**與其他**立克次體**、萊姆病、鉤端螺旋體、**披衣菌**、黴漿菌、**霍亂**(縮短病程、減少腹瀉)、瘧疾預防、痤瘡；吸收較不受食物影響 |
| tetracycline | 痤瘡、幽門桿菌四合一療法、眼藥膏 |
| minocycline | 痤瘡、MRSA 皮膚感染、多重抗藥性鮑氏不動桿菌 |
| tigecycline | 靜脈注射，多重抗藥性菌的複雜感染 |
| **demeclocycline** | 會造成**腎因性尿崩**，因此被拿來治療**抗利尿激素分泌不當症候群**(SIADH)，目的**不是**抗感染 |

### 服用方式 {#tetracycline-administration}

- 與**鈣、鎂、鋁、鐵、鋅**等二價與三價金屬離子**螯合**，吸收大幅下降：**不可配牛奶、乳製品、制酸劑(胃乳)、鐵劑**同時服用，至少間隔 2 小時。
- 以**一大杯開水**服用，服藥後**保持直立至少 30 分鐘**、**不要睡前服用**，避免藥錠卡在食道造成**食道潰瘍**。
- tetracycline 最好空腹服用；doxycycline 可與食物一起服用以減少腸胃不適(但仍避開牛奶與制酸劑)。
- **過期**的 tetracycline 會分解成對腎臟有毒的物質(范可尼氏症候群)，不可服用。

### 副作用與禁忌 {#tetracycline-adverse}

| 副作用 | 說明 |
|---|---|
| 腸胃不適 | 最常見：上腹不適、噁心、腹瀉 |
| **牙齒與骨骼** | 與鈣結合沉積在發育中的牙齒與骨骼：**永久性牙齒變色**(黃褐色)、琺瑯質發育不全、骨骼生長受影響。**8 歲以下兒童、孕婦、哺乳婦女**避免；doxycycline 短期(≤ 21 天)使用的風險很低，恙蟲病等可用於任何年齡([UpToDate：tetracyclines](https://www.uptodate.com/contents/tetracyclines)) |
| **光敏感** | 日曬後容易嚴重曬傷：**避免曬太陽**、穿長袖、擦防曬 |
| 食道潰瘍 | 服藥方式不當 |
| 肝毒性 | 大劑量靜脈注射、孕婦 |
| 重複感染 | 口腔與陰道**念珠菌**、困難梭菌 |
| 其他 | 顱內壓升高(假性腦瘤)；minocycline 眩暈 |

## 巨環類 {#macrolides}

### 代表藥與用途 {#macrolide-uses}

| 藥物 | 特色 |
|---|---|
| **erythromycin** | 最早的巨環類；胃酸不穩定、腸胃副作用多、一天多次；也是**胃動素受體促效劑**，可促進胃排空(但不是多巴胺拮抗劑) |
| **clarithromycin** | **幽門桿菌三合一療法**(PPI＋amoxicillin＋clarithromycin)、黴漿菌、分枝桿菌(MAC) |
| **azithromycin** | 半衰期很長，**療程短**(常見 3–5 天)、一天一次、副作用與交互作用較少；兒童**黴漿菌肺炎**首選、百日咳、披衣菌(單一劑量)、旅遊者腹瀉 |

**適應症**：
- **非典型肺炎**：**黴漿菌**(兒童常用 azithromycin)、披衣菌、退伍軍人菌。
- **百日咳**的治療與接觸者預防。
- 青黴素過敏者的鏈球菌咽炎(但抗藥性高)。
- 生殖道**披衣菌**感染。
- 巨環類**不能**預防腸病毒(病毒感染不用抗生素)。

### 副作用與禁忌 {#macrolide-adverse}

| 副作用 | 說明 |
|---|---|
| **腸胃不適** | **最常見**：腹痛、噁心、腹瀉(erythromycin 最明顯) |
| **QT 延長** | 可能引起 torsades de pointes 心律不整；避免與其他延長 QT 的藥物併用 |
| **膽汁鬱積性肝炎** | **黃疸**(erythromycin estolate 最典型) |
| **耳毒性** | 大劑量時可逆性聽力下降 |
| 新生兒 | 出生 2 週內使用 erythromycin 與**肥厚性幽門狹窄**相關 |
| 重症肌無力 | 可能惡化 |

巨環類**不容易引起癲癇**。

### 交互作用 {#macrolide-interactions}

- **erythromycin、clarithromycin** 是 **CYP3A4 抑制劑**，會**升高**併用藥物的濃度：**triazolam**(過度鎮靜)、warfarin(出血)、theophylline、carbamazepine、statins(橫紋肌溶解)、digoxin、cyclosporine。
- **azithromycin** 的酵素抑制作用很弱，交互作用較少。
- 酵素**誘導**劑的代表是 phenobarbital，不是 erythromycin。
- erythromycin 主要經**肝臟**代謝與膽汁排除：**肝功能異常**時血中濃度上升、毒性增加。

## Chloramphenicol {#chloramphenicol}

- 廣效、容易進入**腦脊髓液**；因為毒性，現在幾乎只保留給無其他選擇的情況，外用眼藥較常見。
- **骨髓抑制**：
  - **劑量相關、可逆**的貧血與白血球、血小板減少。
  - **特異性、不可逆**的**再生不良性貧血**，與劑量無關，可能致命(外用也曾有報告)。
- **灰嬰症候群**：新生兒(尤其早產兒)肝臟的葡萄糖醛酸轉移酶不足、腎排除差，藥物蓄積 → 腹脹、嘔吐、**皮膚灰白發紺**、低體溫、循環衰竭。所以**新生兒感染不選 chloramphenicol**，較安全的是 **penicillin G**([[beta-lactams#indications]])。
- 會抑制肝臟酵素(升高 phenytoin、warfarin 濃度)。

## Clindamycin {#clindamycin}

- 用途：**厭氧菌**(橫膈以上，如吸入性肺炎、肺膿瘍、牙科感染)、G+ 皮膚軟組織感染(包括部分社區型 MRSA)、骨髓炎；**壞死性筋膜炎、毒性休克症候群**時合併使用以**抑制毒素**產生；青黴素過敏者的替代藥；細菌性陰道炎(外用)。
- **招牌副作用**：**困難梭狀桿菌腸炎**(偽膜性腸炎)風險**最高**的抗生素之一；出現嚴重腹瀉要停藥並檢查([[antibiotics-overview#c-difficile]])。
- 經肝臟代謝。

## 護理重點與衛教 {#nursing}

1. **tetracycline**：以開水服用，**不配牛奶、茶、果汁、制酸劑、鐵劑**；服藥後保持直立 30 分鐘；**避免日曬**；8 歲以下兒童與孕婦先確認醫囑；丟棄過期藥。
2. **巨環類**：注意腸胃不適與肝功能(黃疸)；詢問正在服用的藥物(安眠藥 triazolam、warfarin、statin 等)並提醒醫師或藥師；有心律不整病史者注意 QT。
3. **chloramphenicol**：定期**全血球計數**；觀察新生兒皮膚顏色、腹脹、體溫。
4. **clindamycin**：**腹瀉**每天 3 次以上或有血便、腹痛要立即通知。
5. 服用四環黴素或巨環類期間出現口腔白斑、陰道分泌物增加(念珠菌)要回報。
6. **眼藥膏**(如 tetracycline oint.)：先點眼藥水，**間隔約 5 分鐘**再擦藥膏；藥膏由**內眥往外眥**塗在**下眼瞼結膜囊**，不直接擦在角膜上；O.D. 是右眼、O.S. 左眼、O.U. 雙眼。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **clarithromycin**：干擾細菌**蛋白質**合成(巨環類，不是青黴素類)。
- **黴漿菌肺炎**：erythromycin 或 **azithromycin**(療程短、副作用少)；**β-lactam 無效**(沒有細胞壁)。
- 巨環類**最不易**引起**癲癇**；會引起腸胃不適、黃疸、耳毒性。
- 肝功能異常時會蓄積：**erythromycin**；erythromycin 會升高 **triazolam** 濃度。
- tetracycline **不可與牛奶同服**；服用後**避免曬太陽**。
- 霍亂：以**補充液體與電解質**為主，tetracycline 可**縮短病程**；霍亂病人**通常不發燒**。
- SIADH 使用 demeclocycline(四環素類)是為了**造成腎因性尿崩**，不是預防感染。
- 新生兒感染**不選 chloramphenicol**(灰嬰症候群)。
- 幽門桿菌三合一療法**不含 erythromycin**。
:::
