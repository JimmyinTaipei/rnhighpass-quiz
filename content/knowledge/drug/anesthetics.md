**麻醉藥**分成兩類：**全身麻醉藥**使病人失去意識、沒有痛覺與記憶，通常合併止痛藥（鴉片類，見 [[opioids]]）與肌肉鬆弛劑（見 [[cholinergic-drugs#neuromuscular-blockers]]）；**局部麻醉藥**只阻斷某一區域的神經傳導，病人保持清醒，脊髓麻醉與硬膜外麻醉也屬於這一類。產痛的傳導路徑見 [[spinal-cord-spinal-nerves#labor-pain]]

## 重點摘要 {#summary}

- 全身麻醉：多以**靜脈麻醉劑誘導**（propofol、thiopental）、**吸入性麻醉劑維持**（sevoflurane、desflurane）
- **MAC**（最低肺泡濃度）越小 → 效價越**強**；效價與 MAC **成反比**
- 吸入性麻醉劑**脂溶性高**，容易**通過胎盤**抑制新生兒；halothane 類會**放鬆子宮**，增加產後出血；**halothane** 使心肌對兒茶酚胺敏感，**容易心律不整**
- **Propofol**：靜脈注射、脂肪乳劑（不溶於水）、起效快恢復快、**有止吐效果**、沒有止痛作用
- **Thiopental**：高脂溶性，單次注射後很快**再分布**到肌肉與脂肪，所以作用時間短
- **Ketamine**：NMDA 拮抗劑、**解離性麻醉**，有止痛作用、血壓不降反升、甦醒時可能幻覺
- 局部麻醉藥**阻斷 Na⁺ 通道**；是弱鹼，**發炎組織 pH 下降**時離子型增加、脂溶性降低，**效果變差**；**lidocaine** 也是抗心律不整藥
- 局部麻醉劑過量(LAST)：口周麻、金屬味、耳鳴 → 抽搐 → 心律不整與心跳停止；用 **20% 脂肪乳劑**
- **脊髓麻醉**：藥打進**蜘蛛膜下腔**，常見**低血壓**（交感阻斷，麻醉前要**輸液**）與**脊髓麻醉後頭痛**
- **硬膜外麻醉**：藥打在**硬膜外腔**，不穿破硬腦膜，可留置導管持續給藥，**減痛分娩**常用 bupivacaine＋fentanyl；不需要為了預防頭痛而平躺

### 國考常考點 {#exam-points}

- **MAC 越小、麻醉劑強度越大**；酒精成癮者 MAC 較高；效價與 MAC 成正比是錯的
- 最易引起**心律不整**的吸入性麻醉劑：**halothane**
- **Propofol 有良好止吐效果**；只能靜脈注射、水溶性差、不是經由抑制麩胺酸受體
- 單次注射 **thiopental** 後會**再分布**到骨骼肌與脂肪，所以作用短暫
- 吸入性麻醉劑是**脂溶性**（不是水溶性），易過胎盤抑制新生兒；會影響子宮收縮、增加產後出血；笑氣是無色氣體
- 剖腹產全身麻醉：誘導一般用**靜脈**麻醉劑；考選部 108-1 年更正答案為「全身麻醉常發生低血壓」是錯誤敘述
- 局部麻醉劑在**發炎組織**效果降低：**pH 下降、藥物脂溶性降低**
- 可當局部麻醉劑的抗心律不整藥：**lidocaine**；lidocaine 抑制 **Na⁺ 通道**
- 局部麻醉併用 epinephrine：**血管收縮、延長作用時間**
- 2% lidocaine 用來減輕口腔疼痛，**不是用來清潔舌苔**
- 為減少藥物對胎兒的影響，剖腹產宜採**腰椎硬膜外麻醉**（區域麻醉）
- 硬膜外減痛分娩常用 **fentanyl、bupivacaine(Marcaine)**；針是進到**硬膜外腔**、不穿破硬脊膜；穿刺部位常在 **L3–4**
- 麻醉前預先輸液用**林格氏液或生理食鹽水**（目的是**預防低血壓**），**不是 D5W**；麻醉後採**左側臥**；低血壓不是給 naloxone
- 硬膜外麻醉的合併症：低血壓、排尿困難、頭痛（意外穿破硬腦膜時）；胎兒心跳變異性是**減少**不是增加
- 硬膜外減痛分娩主要阻斷傳導產痛的**交感與感覺神經**；藥只打在硬膜外腔；考題中「子宮頸口開 1 或 2 公分」不是最佳時機（新指引見下方）
- **脊髓麻醉**：麻醉前 30 分鐘給**較多靜脈輸液**；不是用在第一產程的減痛分娩
- 脊髓麻醉剖腹產後：考題答案是**平躺 6–8 小時**（不是辛氏臥位）；起床頭痛、躺下好轉 → **腦脊髓液滲漏**，平躺並補充水分
- **硬膜外麻醉不需要平躺 8 小時**；術後可塗薄荷油促進腸蠕動；剖腹產後 2 小時內優先評估子宮收縮、下肢感覺，腸蠕動不是優先項目

## 全身麻醉 {#general-anesthesia}

- 全身麻醉的組成：**意識喪失**、**失憶**、**止痛**、**肌肉鬆弛**、抑制自主神經反射；通常由好幾種藥合併完成（平衡麻醉）
- 流程：**誘導**（多用靜脈藥，快速入睡；需要快速建立呼吸道時用快速序列誘導）→ **維持**（吸入藥或持續靜脈輸注）→ **甦醒**
- 麻醉深度的傳統分期（Guedel，以乙醚為例）：第一期止痛、第二期興奮（譫妄、嘔吐、喉痙攣的危險期）、第三期手術期、第四期延髓麻痺；現代快速誘導很快就越過第二期

### 吸入性麻醉劑 {#inhaled}

| 藥物 | 重點 |
|---|---|
| **一氧化二氮**（N₂O、笑氣） | 無色、略帶甜味；**MAC 很高（效價弱）**，止痛好、單獨用無法達到手術麻醉；產科可用於分娩止痛；關閉後要給 100% 氧氣數分鐘（擴散性缺氧） |
| **Sevoflurane** | 氣味溫和、不刺激呼吸道 → 適合**吸入誘導（兒童）**；起效與恢復快 |
| Desflurane | 恢復最快；刺激呼吸道，不適合誘導 |
| Isoflurane | 便宜，恢復較慢 |
| **Halothane** | 舊藥；使心肌對**兒茶酚胺敏感 → 心律不整**；**肝炎**；現在很少用 |

- **MAC**：在一大氣壓下使 **50% 病人**對切皮刺激**不動**所需的肺泡濃度；**MAC 越小 = 效價越強**；年齡增加、懷孕、低體溫、併用鴉片類會使 MAC 下降，長期飲酒者 MAC 較高
- 吸入性麻醉劑**脂溶性高** → 很快進入腦部，也很容易**通過胎盤**，抑制新生兒的呼吸與神經行為
- Halogenated 類（sevoflurane 等）會**放鬆子宮平滑肌** → 子宮收縮不良、**產後出血**；也會擴張血管、抑制心肌 → 血壓下降
- 與 succinylcholine 一起可能引發**惡性高熱**（用 dantrolene）
- 術後**噁心嘔吐**較常見

### 靜脈麻醉劑 {#intravenous}

| 藥物 | 重點 |
|---|---|
| **Propofol** | 最常用的誘導藥與鎮靜藥；增強 GABA-A；**脂肪乳劑**（白色、不溶於水，開封後限時使用、無菌操作）；起效快、甦醒快、**止吐**；**沒有止痛作用**；副作用：**低血壓**、呼吸抑制、注射痛；長時間高劑量可能 propofol 輸注症候群 |
| **Thiopental** | 超短效巴比妥；高脂溶性，數十秒入腦，之後**再分布**到骨骼肌與脂肪而清醒；重複給藥會累積、甦醒變慢 |
| **Ketamine** | **NMDA 受體拮抗劑**，**解離性麻醉**（眼睛張開、對環境無反應）；**有止痛作用**；**血壓、心跳上升**、支氣管擴張 → 適合休克與氣喘病人；甦醒期可能**幻覺、惡夢**；濫用時是第三級毒品，長期濫用造成**慢性間質性膀胱炎**；作用與 phencyclidine(PCP)相似 |
| Etomidate | 心血管穩定；抑制腎上腺皮質 |
| Midazolam | Benzodiazepine，術前鎮靜與失憶，可用 flumazenil 拮抗（見 [[anxiolytics-hypnotics]]） |
| Dexmedetomidine | 中樞 α2 致效劑，加護病房鎮靜，病人易喚醒、呼吸抑制少；心跳變慢（見 [[central-alpha2-agonists]]） |

- 108-1 年剖腹產題：一般以**靜脈**麻醉劑誘導、吸入劑維持，所以「以吸入性麻醉藥物作為誘導」本身也不符合常規；考選部最後更正的答案是「全身麻醉常發生低血壓」為錯誤敘述

## 局部麻醉藥 {#local-anesthetics}

### 機轉與特性 {#local-mechanism}

- 從細胞內側**阻斷電位門控 Na⁺ 通道** → 不能產生動作電位，神經傳導被阻斷
- 局部麻醉藥是**弱鹼**：要以**未解離（脂溶性）**的形式穿過神經細胞膜，進入細胞後再以離子型作用
- **發炎或感染組織偏酸**（pH 下降）→ 藥物**離子型增加、脂溶性降低** → 不易進入神經 → **效果變差**（例如膿瘍處不容易麻）
- 被阻斷的順序：**細、無髓鞘的纖維先被阻斷** → 痛覺與溫度覺 → 觸覺與壓覺 → 運動；恢復時順序相反
- 併用 **epinephrine**：局部血管收縮 → 吸收變慢 → **作用時間延長、全身毒性降低**、出血減少（見 [[adrenergic-agonists#epinephrine]]）

| | 酯類(ester) | 醯胺類(amide) |
|---|---|---|
| 代表藥 | Procaine、tetracaine、benzocaine、cocaine | **Lidocaine**、**bupivacaine**、ropivacaine、mepivacaine |
| 代謝 | 血漿**假性膽鹼酯酶** | **肝臟** |
| 過敏 | 代謝產物 **PABA** 較常引起過敏 | 很少過敏 |
| 記法 | 藥名只有一個「i」 | 藥名有兩個「i」（lidocaine、bupivacaine） |

| 藥物 | 用途與重點 |
|---|---|
| **Lidocaine**(Xylocaine) | 浸潤麻醉、表面麻醉（凝膠、噴劑、2% 漱口液緩解口腔痛）；**也是 IB 類抗心律不整藥**（心室心律不整） |
| **Bupivacaine**(Marcaine) | 長效；**脊髓麻醉、硬膜外麻醉**；**心臟毒性最強** |
| Ropivacaine | 長效、心臟毒性較低；硬膜外減痛分娩 |
| Benzocaine、tetracaine | 表面麻醉；benzocaine 可能造成變性血紅素血症 |
| Cocaine | 表面麻醉兼血管收縮（鼻腔）；成癮 |

### 局部麻醉劑全身毒性 {#last}

- 原因：誤打入血管、劑量過大、吸收太快
- 表現大致依序：**口周與舌頭麻木、金屬味、耳鳴**、頭暈、躁動 → **抽搐** → 意識喪失、呼吸停止 → **心律不整、心跳停止**（bupivacaine 特別容易）
- 處理：停止給藥、求救、維持呼吸道與給氧、benzodiazepine 控制抽搐、**20% 脂肪乳劑**靜脈注射、依需要 CPR
- 預防：注射前回抽、分次給藥、不超過最大劑量

## 脊髓麻醉與硬膜外麻醉 {#neuraxial}

| | 脊髓麻醉（蜘蛛膜下腔麻醉） | 硬膜外麻醉 |
|---|---|---|
| 藥物位置 | 穿破硬腦膜，打進**蜘蛛膜下腔**的腦脊髓液 | **硬膜外腔**，**不穿破**硬腦膜 |
| 穿刺位置 | **L3–4 或 L4–5**（脊髓圓錐以下） | 腰椎 L3–4 等（也可在胸椎） |
| 劑量與起效 | 少量、**快**（數分鐘） | 量較大、較慢（10–20 分鐘） |
| 導管 | 通常單次注射 | 可**留置導管持續給藥** |
| 常用於 | **剖腹產**、下腹與下肢手術 | **減痛分娩**、剖腹產、術後止痛 |
| 低血壓 | **常見且快** | 較緩和 |
| 麻醉後頭痛 | 較常見（硬腦膜有洞） | 只有**意外穿破硬腦膜**時才會發生 |

- 穿刺位置與脊髓下端的關係見 [[spinal-cord-spinal-nerves#lumbar-puncture-site]]
- **低血壓**：交感神經被阻斷 → 血管擴張 → 血壓下降，也會減少胎盤灌流、**胎兒心跳變異性減少**
  1. 麻醉前或同時**靜脈輸液**（林格氏液或生理食鹽水 500–1,000 mL）；**不用 D5W**（會造成母親與新生兒高血糖、新生兒低血糖）
  2. 擺**左側臥**或子宮左推，避免子宮壓迫下腔靜脈
  3. 監測血壓與胎心音；血壓仍低時依醫囑給升壓劑（phenylephrine、ephedrine）；**naloxone 不是**治療低血壓的藥（是鴉片類拮抗劑）
- 其他合併症：**尿滯留**（要評估膀胱）、皮膚癢與噁心（鴉片類）、發燒、下肢無力、高位阻斷造成呼吸困難、硬膜外血腫或感染（少見）
- **評估**：麻醉平面、下肢感覺與運動恢復、血壓、膀胱；剖腹產後 2 小時內也要評估**子宮收縮**與出血（雙胞胎更要注意）

### 減痛分娩 {#labor-analgesia}

- 硬膜外減痛分娩常用**低濃度局部麻醉藥＋鴉片類**（**bupivacaine 或 ropivacaine 加 fentanyl**），阻斷傳導子宮收縮痛的 **T10–L1** 交感與感覺神經，第二產程才需要 **S2–S4**；盡量保留運動功能
- 時機：考題常以「子宮頸開 3–4 公分以上」為標準；**ACOG 指引**認為只要**產婦要求**、沒有禁忌就可以給，**不需要等到子宮頸開到某個程度**（來源：[ACOG Practice Bulletin 209](https://doi.org/10.1097/AOG.0000000000003132)）
- 可能延長第二產程、影響用力；剖腹產時用硬膜外或脊髓麻醉，**藥物對胎兒影響比全身麻醉小**
- **陰部神經阻斷**：S2–S4，用於第二產程與會陰修補
- 產程中用的鴉片類止痛（meperidine、fentanyl）與 naloxone 見 [[opioids#special-populations]]

### 脊髓麻醉後頭痛 {#pdph}

- 原因：硬腦膜穿刺處**腦脊髓液滲漏** → 腦脊髓液壓力下降、腦組織下沉牽扯
- 特徵：**坐起或站立時頭痛、躺下緩解**，常在 1–3 天內出現，可合併噁心、頸部僵硬、耳鳴
- 處理：**平躺**、**補充水分**、止痛藥、咖啡因；持續嚴重時由麻醉科做**硬膜外血液補綴**(epidural blood patch)
- 預防：使用**細針、筆尖型針頭**
- 國考答案：脊髓麻醉後**平躺 6–8 小時**預防頭痛；硬膜外麻醉不需要。但系統性回顧顯示，**常規臥床並不能預防**脊髓麻醉後頭痛，平躺主要是頭痛發生後減輕症狀（來源：[Cochrane 2016](https://doi.org/10.1002/14651858.CD009199.pub3)）
- 110-2 年剖腹產術後姿勢題，考選部送分
