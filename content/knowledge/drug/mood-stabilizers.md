## 重點摘要 {#summary}

- 用途：**雙相情緒障礙症**的急性躁期與**預防復發**(維持期)；鋰鹽也能**降低自殺**。
- **鋰鹽**：治療濃度與中毒濃度**很接近**，要定期抽血(服藥後 **12 小時**)；**脫水、低鈉、利尿劑、NSAIDs、ACEI** 使濃度上升；長期監測**腎功能與甲狀腺**。
- **Valproate**：增加 GABA；注意**肝毒性**、血小板減少、胰臟炎、體重增加；**懷孕禁用**(神經管缺損)。
- **Carbamazepine**：注意**史蒂文生氏–強生症候群**(台灣人用藥前檢測 **HLA-B\*1502**)、**顆粒性白血球缺乏**、**低血鈉**、酵素誘導的交互作用。
- **Lamotrigine**：主要預防**鬱期**；必須**慢慢加量**以避免嚴重皮疹。
- 第二代抗精神病藥(quetiapine、aripiprazole、olanzapine 等)也常作為情緒穩定劑，見 [[antipsychotics]]。

## 鋰鹽 {#lithium}

### 藥動 {#lithium-pharmacokinetics}

- 口服**快速吸收**，一般劑型服藥後 **1–2 小時**達到**最高血中濃度**(此時最容易出現副作用)，緩釋劑型約 4–5 小時；食物不影響吸收。
- **不經肝臟代謝**，幾乎**完全由腎臟排除**；在腎小管與**鈉**一起被再吸收，所以**體內鈉少、脫水時，鋰的再吸收增加 → 濃度上升**。
- 半衰期約 **24 小時**(老人、腎功能差時更長)；調整劑量後約 **4–5 天**達到穩定狀態。
- 通常**分成 2–3 次**服用(減少腸胃副作用與尖峰濃度)，緩釋劑型可一天一次。
- 起效需要時間，急性躁症約 **1–2 週**以上才見效，所以急性期常合併抗精神病藥(來源：[UpToDate：Bipolar disorder in adults and lithium](https://www.uptodate.com/contents/bipolar-disorder-in-adults-and-lithium-pharmacology-administration-and-management-of-adverse-effects))。

### 血中濃度 {#lithium-levels}

治療濃度、抽血時機與中毒分級見 [[lithium-level]]。重點：

| | 濃度(mEq/L) |
|---|---|
| UpToDate(急性期與維持期) | **0.8–1.2**，通常不超過 1.2；無法耐受者 0.6 也可能有效 |
| 台灣共識 2022：急性躁期 | 0.8–1.3 |
| 台灣共識 2022：**維持期** | **0.6–0.8** |
| 開始出現中毒 | **> 1.5** |
| 醫療急症 | **≥ 2.5** |

### 副作用 {#lithium-adverse-effects}

| 時期 | 副作用 | 處理 |
|---|---|---|
| 初期(常見、多可耐受) | **噁心、腹瀉**、上腹不適 | **隨餐服用**、分次服用；持續或新發生的嘔吐腹瀉要懷疑中毒 |
| | **細微的手抖**(約 25%) | 減少咖啡因、必要時 propranolol；**變粗大**的顫抖是中毒警訊 |
| | **多尿、口渴** | 腎臟濃縮能力下降(**腎源性尿崩症**)；補充足夠水分 |
| | 疲倦、注意力稍差 | |
| 長期 | **體重增加**、水腫 | 飲食運動；多喝水但避免含糖飲料 |
| | **甲狀腺功能低下**、甲狀腺腫 | 定期驗 **TSH**，必要時補充甲狀腺素 |
| | **慢性腎臟病** | 定期驗 **BUN、肌酸酐、尿液** |
| | 高血鈣(副甲狀腺機能亢進) | 驗**鈣** |
| | 痤瘡、**乾癬惡化**、掉髮 | 乾癬是相對禁忌 |
| | 竇房結功能障礙、心跳過慢 | 心臟病與 40 歲以上做心電圖 |

| 懷孕 | 心臟畸形(**Ebstein 畸形**)，絕對風險不高 | 計畫懷孕先與醫師討論；懷孕期間與產後濃度變化大，需密切監測 |

### 鋰中毒 {#lithium-toxicity}

**原因**(都是讓鋰排不掉或濃度上升)：

- **脫水**：發燒、嘔吐腹瀉、大量流汗、天氣熱、**躁期忙到沒吃沒喝**
- **鈉攝取減少**：低鹽飲食、節食
- **腎功能下降**、**老人**
- **藥物**：**thiazide 利尿劑**、**NSAIDs**(aspirin 除外)、**ACEI**(與 ARB)、部分抗生素
- 服藥過量(自殺)

**表現**：

| 程度 | 血中濃度(慢性中毒時的參考) | 表現 |
|---|---|---|
| 輕度 | 1.5–2.5 | **噁心嘔吐、腹瀉**、**手抖加劇**、口齒不清、嗜睡、肌肉無力 |
| 中重度 | 2.5–3.5 | **意識混亂**、**步態不穩**(運動失調)、**粗大顫抖**、肌束顫動、**肌陣攣**、反射亢進、**眼球震顫** |
| 重度 | > 3.5 | **癲癇**、昏迷、心律不整、腎衰竭，可能死亡 |

(來源：[UpToDate：Lithium poisoning](https://www.uptodate.com/contents/lithium-poisoning))

- **急性過量**：以腸胃症狀為主，神經症狀較晚出現；**慢性中毒**：以**神經症狀**為主，老人較嚴重。
- 嚴重中毒後可能留下長期的小腦與神經後遺症(SILENT 症候群)。

**處置**：

1. **停藥**，立即通知醫師、抽血驗鋰濃度、腎功能、電解質。
2. **生理食鹽水**靜脈輸液，矯正脫水、增加鋰排出。
3. **血液透析**是嚴重中毒的首選：有**嚴重症狀**(意識改變、癲癇、心律不整)不論濃度都要透析；**腎功能差且 > 4.0 mEq/L**、或 **> 5.0 mEq/L** 時建議透析。
4. **活性碳無法吸附鋰**；緩釋劑型大量服用時可考慮全腸灌洗。
5. 監測意識、生命徵象、心電圖、尿量、血鈉；癲癇用 BZD。

:::exam[國考重點]
- 病人服鋰鹽又因忙碌吃得少，出現**腹瀉、手抖、噁心嘔吐** → 最優先：與醫療團隊討論**測量血中鋰濃度**。
- 鋰中毒常見症狀：**意識障礙、腹瀉、肢體僵硬**(神經肌肉興奮)等。
- 鋰濃度 **1.2 mEq/L** 仍在治療範圍 → **持續服用，但密切監測**是否上升。
- 會讓鋰濃度上升的藥物：**ACEI、NSAIDs、thiazide 利尿劑**。
- 腎功能不佳的病人**不適合**使用鋰鹽。
:::

### 交互作用 {#lithium-interactions}

| 使鋰濃度**上升** | 使鋰濃度**下降** |
|---|---|
| **Thiazide 利尿劑** | 保鉀利尿劑 |
| **NSAIDs**(ibuprofen 等，aspirin 除外) | **Theophylline**、**咖啡因** |
| **ACEI**、ARB | SGLT2 抑制劑 |
| Tetracycline、metronidazole | **高鈉攝取** |
| GLP-1 受體促效劑 | 懷孕(腎絲球過濾率增加) |
| **脫水、低鈉** | |

- Loop 利尿劑、鈣離子阻斷劑可能升高或降低。
- 與**抗精神病藥**(尤其高劑量 haloperidol)併用，增加神經毒性與 **NMS** 風險。
- 與 ECT 併用可能增加治療後混亂，並延長 succinylcholine 作用。
- 這些藥物不是絕對不能併用，而是**開始、停用或調整劑量時**要更密切監測鋰濃度(來源：[UpToDate：Bipolar disorder in adults and lithium](https://www.uptodate.com/contents/bipolar-disorder-in-adults-and-lithium-pharmacology-administration-and-management-of-adverse-effects))。

### 用藥前後的檢查 {#lithium-monitoring}

| 時機 | 項目 |
|---|---|
| **用藥前** | 尿液分析、**BUN、肌酸酐**、**甲狀腺功能**、**鈣**、懷孕試驗(育齡女性)、心電圖(心臟危險因子或 40 歲以上)、體重 |
| 劑量調整後 | **5–7 天**驗鋰濃度 |
| 穩定期 | 鋰濃度每 6–12 個月；腎功能前 6 個月每 2–3 個月、之後每 6–12 個月；甲狀腺前 6 個月 1–2 次、之後每 6–12 個月 |
| 隨時 | 出現中毒症狀、脫水、開始或停用交互作用藥物時 |

- 國考標準答案：長期使用鋰鹽要定期檢查**腎臟功能與甲狀腺功能**(不是肝功能或肺功能)。

### 護理與衛教 {#lithium-nursing}

- **規則服藥**，不要自行增減或停藥；忘記服藥時**不要下次補吃雙倍**。
- **隨餐或飯後服用**減少腸胃不適；分次服用。
- **正常鹽分飲食**，**不要刻意低鹽或節食**；飲食與鹽分攝取保持穩定。
- 每天喝**足夠且穩定的水量**(一般約 2–3 公升，依醫囑)，**不要突然大量喝水或大幅減少**；天熱、運動、發燒、腹瀉時更要補充水分。
- 避免自行服用**止痛藥(NSAIDs)**、利尿劑；看其他科時告知正在服用鋰鹽。
- 咖啡、茶的攝取量保持穩定(突然戒掉會使鋰濃度上升)。
- 認識**中毒症狀**：嘔吐、腹瀉、**手抖變嚴重**、走路不穩、口齒不清、意識混亂 → **停藥並立即就醫**。
- 依醫囑回診抽血；抽血前**不要吃早上那一劑**(服藥後 12 小時抽)。
- 計畫懷孕先與醫師討論。

## Valproate {#valproate}

- **機轉**：**增加 GABA**(促進合成、減少分解)，並阻斷鈉通道。
- **用途**：急性躁期(可用**負荷劑量**快速達到濃度)、維持期、**混合特徵**與**快速循環**；也是抗癲癇藥。
- **血中濃度**：台灣共識急性躁期約 75–100 mg/L(µg/mL)，維持期 50–100 mg/L。
- **副作用**：腸胃不適、手抖、嗜睡、**體重增加**、**掉髮**、**血小板減少**、**肝毒性**(尤其用藥頭 6 個月)、**胰臟炎**(嚴重腹痛)、**高血氨**(意識改變)、多囊性卵巢。
- **致畸胎**：**神經管缺損**與發展問題；**育齡女性避免使用**，若必須使用要有效避孕並補充葉酸。
- **交互作用**：抑制 lamotrigine 代謝(使 lamotrigine 濃度加倍，皮疹風險增加)。
- **監測**：肝功能、血球與血小板、體重、血中濃度。
- **衛教**：出現**黃疸、腹痛、嘔吐、瘀青出血、極度疲倦**立即就醫。

## Carbamazepine {#carbamazepine}

- **用途**：躁期與維持期(第二線)、癲癇、三叉神經痛。
- **HLA-B\*1502 與 SJS/TEN**：帶有 HLA-B\*1502 基因者，發生**史蒂文生氏–強生症候群**與毒性表皮溶解症的風險高出約 **193 倍**；這個基因在漢人與東南亞人較常見。台灣自 2007 年起要求仿單加註亞裔用藥前考慮檢測，**健保自 2010 年起給付**符合適應症者用藥前的基因檢測，結果登錄在健保卡(來源：[食藥署](https://www.fda.gov.tw/TC/siteListContent.aspx?sid=1571&id=2550)；[義大醫院檢驗科](https://exdep.edah.org.tw/cp/index.php/2017-06-26-08-19-55/2017-06-28-09-06-14/467-hla-b-1502-for-carbamazepine))。
- **皮膚反應**：皮疹其實**常見**；出現**發燒、皮疹擴大、口腔或眼睛黏膜潰爛、起水泡**時，要立刻停藥就醫，確認是否為 SJS。
- **血液**：顆粒性白血球缺乏、再生不良性貧血 → 監測血球，衛教發燒、喉嚨痛、出血要回報。
- **低血鈉**(SIADH)：倦怠、無力、意識混亂時要驗血鈉；也要評估**飲水量**(雙相病人合併鋰鹽時，鋰鹽的口渴多尿與心因性多喝水也可能造成低血鈉)。
- **中樞神經**：頭暈、嗜睡、**複視**、步態不穩(與劑量相關)。
- **酵素誘導**：加速自己與其他藥物代謝(口服避孕藥**失效**、抗精神病藥與 warfarin 濃度下降)；致畸胎。
- 腎毒性**不是**它的主要問題。

:::exam[國考重點]
- Carbamazepine：病人**黏膜潰爛** → 確認是否為 **SJS**。
- Valproate：機轉是**增加 GABA**；常見**體重增加**。
- 服鋰鹽與 carbamazepine 的病人倦怠無力，鋰 0.8、**Na 120** → 鋰濃度在範圍內，要**評估飲水量**(水中毒)，也要想到 carbamazepine 造成的低血鈉。
- Loratadine(抗組織胺)**不是**躁鬱症用藥。
:::

## Lamotrigine {#lamotrigine}

- 主要**預防雙相的鬱期**，對急性躁症沒有效果。
- 必須**從低劑量開始、慢慢加量**(數週)，以降低**嚴重皮疹(SJS)**的風險；併用 valproate 時劑量要減半。
- 停藥超過數天後重新開始，要從**起始劑量**重新慢慢加。
- 衛教：出現皮疹、發燒、黏膜病變立即回報。

## 護理重點與衛教 {#nursing}

- 所有情緒穩定劑都需要**長期規則服用**才能預防復發，症狀消失不代表可以停藥。
- 告知病人與家屬藥物的作用、需要的時間與**危險徵兆**(鋰中毒、SJS、肝毒性、感染徵象)。
- 依藥物安排抽血追蹤；鼓勵家屬參與用藥管理。
- 育齡女性：討論避孕與懷孕計畫(valproate、carbamazepine、鋰鹽都有致畸胎風險)。
- 躁期病人常因「覺得自己很好」而拒藥，先同理並了解原因，再提供資訊；反覆停藥復發者討論長效針劑。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 鋰鹽：分 2–3 次服用、隨餐吃可減少腸胃不適；**不需要嚴格限鹽**(限鹽反而會中毒)；**不是**由肝臟代謝；**不是**服藥 2 天就見效。
- 鋰鹽服藥後 **0.5–2 小時**達最高濃度，此時最容易出現副作用；抽血要在服藥後 **12 小時**。
- 急性期濃度「2.0–2.5」「2.0 以上」都是錯的；「急性期 0.6–1.0」也是錯的(那是維持期的範圍)。
- 長期監測：**腎功能、甲狀腺功能**。
- 使鋰濃度上升：**ACEI、NSAIDs、thiazide**、脫水、低鈉。
- 「鼓勵病人**大量喝水**來改善副作用」**不適當**：水分要**足夠且穩定**。
:::
