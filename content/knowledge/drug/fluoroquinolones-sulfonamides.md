## 重點摘要 {#summary}

- **奎諾酮類**：抑制 **DNA gyrase** 與拓撲異構酶 IV，**影響 DNA 複製**、殺菌；口服吸收好。招牌副作用：**肌腱炎與肌腱斷裂**、神經精神症狀、QT 延長、血糖異常；**兒童、孕婦、哺乳**避免；不可與鈣鎂鋁鐵同服。
- **磺胺類**：與 **PABA 競爭**，抑制**葉酸合成**；與 trimethoprim 合用(TMP-SMX)。招牌副作用：**史帝文生–強生症候群**、結晶尿、**G6PD 缺乏者溶血**、新生兒**核黃疸**、高血鉀。
- **metronidazole**：**厭氧菌與原蟲**(陰道滴蟲、阿米巴、梨形鞭毛蟲)；服藥期間**禁酒**(類戒酒反應)。
- **泌尿道消毒劑**：nitrofurantoin(只治**膀胱炎**)、methenamine(需要**酸性尿**)。

## 奎諾酮類 {#fluoroquinolones}

### 機轉與代表藥 {#fq-agents}

抑制細菌 **DNA gyrase**(拓撲異構酶 II)與**拓撲異構酶 IV**，使 DNA 無法解旋與複製 → **殺菌**、濃度依賴型([[antibiotics-overview#mechanism]])。

| 藥物 | 特色 |
|---|---|
| **ciprofloxacin** | 以 **G− 桿菌**為主，包括**綠膿桿菌**；泌尿道、腸道感染(傷寒、痢疾)、炭疽 |
| **levofloxacin**、**moxifloxacin** | 「**呼吸道奎諾酮**」：加強對肺炎鏈球菌與非典型病原的效果；**多重抗藥性結核**的二線藥；moxifloxacin 可涵蓋部分厭氧菌 |
| norfloxacin | 口服，泌尿道 |
| **ofloxacin 滴耳液**、眼藥 | 局部使用不受全身性限制，**兒童中耳炎、外耳炎**常用 |

**藥動**：口服生體可用率高、分布廣，常可由靜脈改為口服。

### 副作用與警訊 {#fq-adverse}

| 副作用 | 說明 |
|---|---|
| 腸胃、中樞神經 | 最常見：噁心、頭痛、**頭暈**；高齡者**意識混亂、譫妄**；降低癲癇閾值 |
| **肌腱炎、肌腱斷裂** | 最常見**阿基里斯腱**；**60 歲以上**、併用**類固醇**、器官移植者風險高；出現肌腱疼痛要**停藥、休息患肢**並就醫 |
| 周邊神經病變 | 刺痛、麻木，可能不可逆 |
| **QT 延長** | moxifloxacin 最明顯；避免併用其他延長 QT 的藥物 |
| **血糖異常** | 高血糖或**低血糖**(併用降血糖藥的糖尿病病人、高齡) |
| 主動脈瘤與剝離 | 有主動脈瘤、周邊動脈疾病、高血壓、馬凡氏症候群者避免 |
| 光敏感 | 避免日曬 |
| 重症肌無力惡化、困難梭菌腸炎 | — |
| **兒童、孕婦、哺乳** | 動物實驗造成**軟骨**與關節損傷，一般**避免**，除非沒有更安全的選擇 |

衛福部與食藥署的安全資訊：全身性 fluoroquinolone 可能造成**失能、長期或不可逆**的肌肉骨骼、神經與精神不良反應；治療**急性非複雜性膀胱炎、急性鼻竇炎、慢性支氣管炎急性惡化**時，應**保留給沒有其他選擇**的病人([衛福部用藥安全資訊](https://www.mohw.gov.tw/cp-3216-23003-1.html)、[馬偕醫院風險溝通表](https://www.mmh.org.tw/know_health_view.php?docid=1310))。

### 交互作用 {#fq-interactions}

- 與**制酸劑、鈣片、牛奶、鐵、鋅、sucralfate** 螯合，吸收大幅下降 → **間隔數小時**服用。
- ciprofloxacin 抑制肝臟酵素，升高 **theophylline**(抽搐)、warfarin 濃度。
- 與 NSAIDs 併用增加中樞神經刺激(癲癇)。

## 磺胺類與 TMP-SMX {#sulfonamides}

### 機轉 {#sulfa-mechanism}

細菌必須**自己合成葉酸**；人體從食物攝取，所以有選擇性。
1. **磺胺類**(sulfamethoxazole)結構像 **PABA**，**競爭**二氫蝶酸合成酶。
2. **trimethoprim** 抑制**二氫葉酸還原酶**。
3. 兩者**依序阻斷**同一條路徑 → 合用有**協同作用**(TMP-SMX，Bactrim、Baktar)。

### 用途 {#sulfa-uses}

- **泌尿道感染**(依當地抗藥性)。
- **肺囊蟲肺炎**(PJP)的**治療與預防**(HIV 病人 CD4 < 200/μL)、弓漿蟲預防、Nocardia。
- 社區型 MRSA 皮膚感染、嗜麥芽窄食單胞菌。
- 磺胺類與 **pyrimethamine** 合用治療**弓漿蟲**；sulfadoxine＋pyrimethamine 用於瘧疾。
- 外用：燒傷(見下方)；sulfasalazine 用於潰瘍性結腸炎與類風濕性關節炎。

### 副作用與禁忌 {#sulfa-adverse}

| 副作用 | 說明與護理 |
|---|---|
| 皮疹 | 最常見之一；**任何新出現的皮疹都要立即停藥回報** |
| **史帝文生–強生症候群、毒性表皮溶解症** | 少見但致命；HIV 病人與高齡者風險較高 |
| **結晶尿** | 舊型磺胺類溶解度低，在酸性尿中沉澱 → **大量喝水**(每天 2,000–3,000 mL，無限水者) |
| **溶血** | **G6PD 缺乏症**病人避免磺胺類(同樣避免樟腦丸、蠶豆、primaquine、nitrofurantoin) |
| **核黃疸** | 磺胺類把**膽紅素**從白蛋白上擠下來：**懷孕末期、新生兒(2 個月以下)**避免 |
| 懷孕初期 | trimethoprim 干擾葉酸 → 神經管缺陷風險 |
| **高血鉀** | trimethoprim 阻斷集尿管鈉通道(像 amiloride)，高齡與腎功能不全者要監測血鉀 |
| 骨髓抑制 | 嗜中性白血球減少、葉酸缺乏 |
| 光敏感 | 避免日曬 |
| 交互作用 | 增強 **warfarin**(出血)、**sulfonylurea**(低血糖)、methotrexate、phenytoin 的作用 |

([UpToDate：TMP-SMX](https://www.uptodate.com/contents/trimethoprim-sulfamethoxazole-an-overview))

### 燒傷外用藥 {#burn-topicals}

| 藥物 | 重點 |
|---|---|
| **1% silver sulfadiazine**(磺胺嘧啶銀) | 最常用；穿透焦痂能力中等；**不影響酸鹼與電解質**；可能出現**暫時性白血球減少**；對磺胺過敏者慎用；臉部與孕婦末期、新生兒避免 |
| **mafenide acetate**(Sulfamylon) | **穿透焦痂**能力強；抑制碳酸酐酶 → **代謝性酸中毒**；塗抹時**疼痛** |
| 0.5% **silver nitrate** | 低張溶液會把電解質吸出：**低血鈉**、低血氯、低血鉀(不是高血鈉)；會把皮膚與床單染黑 |
| gentamicin 乳膏 | 可用於臉部；大面積使用要**監測腎功能**([[aminoglycosides]]) |

## Metronidazole {#metronidazole}

- 在厭氧環境被還原成有毒產物，**破壞 DNA** → 殺菌。
- 用途：
  - **厭氧菌**：腹內感染、吸入性肺炎(常併用)、**細菌性陰道炎**。
  - **原蟲**：**陰道滴蟲**(首選，**性伴侶要同時治療**，治療期間避免性行為)、**阿米巴痢疾**、**梨形鞭毛蟲**。
  - 困難梭菌腸炎(台灣指引可用於第一次非嚴重感染；猛爆型時靜脈注射)、幽門桿菌。
- 副作用：**金屬味**、噁心、**尿液變深(紅棕色)**、周邊神經病變、頭暈，大劑量癲癇。
- **類戒酒反應**：服藥期間與停藥後**至少 72 小時**內**不可飲酒**(包括含酒精的藥水、漱口水)，否則潮紅、心悸、噁心嘔吐、頭痛；部分頭孢菌素(cefoperazone)也有類似作用。治療酒癮的 **disulfiram** 是同一種原理的戒酒藥。
- 升高 warfarin 的作用。
- 陰道感染不需要做陰道沖洗，也不需要配合口服避孕藥。

## 泌尿道消毒劑 {#urinary-antiseptics}

| 藥物 | 重點 |
|---|---|
| **nitrofurantoin** | 只在**尿液**達到有效濃度 → **只治單純膀胱炎**，不能治腎盂腎炎或菌血症；**與食物或牛奶同服**可增加吸收、減少腸胃不適；尿液可能變**棕色**；副作用：**肺部反應**(急性過敏性肺炎、長期使用的肺纖維化)、周邊神經病變、肝毒性、G6PD 缺乏者溶血；腎功能差(CrCl < 30)效果差且毒性增加；**足月孕婦**避免 |
| **methenamine** | 在**酸性尿**(pH < 5.5–6)分解成**甲醛**才能殺菌 → 這時才需要**酸化尿液**(如維生素 C)；用於預防反覆泌尿道感染 |
| fosfomycin | 單次口服治療單純膀胱炎 |

蔓越莓、酸性食物對預防泌尿道感染的效果有限；對一般抗生素(如 neomycin 等胺基配醣體)**酸化尿液反而降低效果**。

## 多胜肽類 {#polymyxins}

- **colistin**(polymyxin E)、polymyxin B：破壞 G− 細胞膜；用於 **CRE、CRAB** 等多重抗藥性菌的**最後防線**；**腎毒性、神經毒性**高。
- **bacitracin**：抑制細胞壁；毒性大，只**外用**(皮膚藥膏)。

## 護理重點與衛教 {#nursing}

1. **奎諾酮類**：與制酸劑、鈣片、鐵劑、牛奶**間隔數小時**；多喝水；出現**肌腱疼痛**(腳跟)立即停藥休息並就醫；高齡者注意意識混亂與跌倒；糖尿病病人監測血糖；避免日曬；兒童與孕婦先確認醫囑。
2. **ofloxacin 滴耳液**(兒童)：藥液回溫；3 歲以下把耳廓**向下向後**拉，3 歲以上**向上向後**拉；A.D. 右耳、A.S. 左耳；滴後側躺數分鐘。
3. **TMP-SMX**：每天喝足水分；**出現皮疹、口腔潰瘍、水泡立即停藥**；詢問 G6PD 缺乏與磺胺過敏史；監測血鉀、全血球；使用 warfarin 或降血糖藥者注意出血與低血糖。
4. **metronidazole**：服藥期間與停藥後 72 小時**禁酒**；尿液變深是正常；陰道滴蟲**性伴侶同時治療**。
5. **nitrofurantoin**：與食物或牛奶同服；尿色變棕；出現咳嗽、呼吸困難、手腳麻木要回報。
6. 燒傷外用磺胺類：監測白血球(silver sulfadiazine)、酸鹼(mafenide)、電解質(silver nitrate)。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **quinolones** 抑制 **DNA gyrase**，影響 **DNA 複製**。
- **G6PD 缺乏症**：感染時**不可**以磺胺類藥物為首選(會溶血)。
- 磺胺類與 **pyrimethamine** 合用治療**弓漿蟲**。
- 新生兒感染不選 sulfamethoxazole(核黃疸)，較安全是 penicillin G。
- metronidazole 治**陰道滴蟲**最有效；服藥期間**不可飲酒**；性伴侶一起治療。
- 燒傷：**silver sulfadiazine 不影響酸鹼電解質**、注意白血球減少；**silver nitrate 造成低血鈉**(不是高血鈉)；**Sulfamylon** 造成代謝性酸中毒。
- 兒童滴耳藥(ofloxacin)：2 歲把耳廓**向下向後**拉。
:::
