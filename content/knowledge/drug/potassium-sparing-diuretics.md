## 重點摘要 {#summary}

- 作用在**集尿管**:spironolactone、eplerenone **拮抗醛固酮受體**(MRA);amiloride、triamterene **阻斷上皮鈉通道(ENaC)**。利尿弱,但**保留鉀**。
- MRA 是 **HFrEF 四大支柱**之一(與 ARNI/ACEI、β 阻斷劑、SGLT2i 並列),可**降低死亡與住院**;也用於肝硬化腹水、原發性醛固酮症、頑固性高血壓。
- 最重要副作用:**高血鉀**;spironolactone 另有**男性女乳症**、月經不規則、性功能下降(eplerenone 少)。
- **避免併用鉀補充劑、低鈉鹽,並小心與 ACEI/ARB/ARNI 合用**;監測血鉀與腎功能,**避免高鉀食物**。

## 作用機轉 {#mechanism}

集尿管主細胞在**醛固酮**作用下,打開管腔側的**上皮鈉通道(ENaC)**、增加基底側 Na⁺-K⁺-ATPase → 回收 Na⁺、同時把 **K⁺ 與 H⁺ 分泌到尿中**。這一段只負責約 2–5% 的鈉,所以利尿效果弱;但它是**決定尿中排鉀量的主要部位**。

![利尿劑在腎元的作用部位](/knowledge-images/diuretic-sites-nephron.svg)

| 類別 | 藥物 | 作用 |
|---|---|---|
| **醛固酮受體拮抗劑(MRA)** | Spironolactone、Eplerenone、Finerenone | 與醛固酮競爭**礦物皮質素受體**(不是糖皮質素受體)→ 減少 ENaC 與鈉鉀幫浦的合成;**要有醛固酮存在才有效**,起效較慢(數天) |
| **ENaC 阻斷劑** | Amiloride、Triamterene | 直接堵住鈉通道,不需經過醛固酮 |

心衰竭時 RAAS 長期活化,醛固酮促進**心肌與血管纖維化**、鈉水滯留、排鉀排鎂;MRA 阻斷這些作用,所以好處遠超過「利尿」(RAAS 見 [[blood-pressure-regulation#raas]])。

## 代表藥物 {#agents}

| 藥物 | 特色 |
|---|---|
| **Spironolactone(Aldactone®)** | 最常用 MRA;選擇性低,也拮抗雄性素、影響黃體素受體 → **男性女乳**、乳房觸痛、陽痿、月經不規則、多毛改善(用於女性多毛症、痤瘡) |
| **Eplerenone** | **選擇性** MRA,幾乎不作用於性荷爾蒙受體 → 較少男性女乳症;經 CYP3A4 代謝,避免併用強效 CYP3A4 抑制劑(clarithromycin、ketoconazole) |
| Finerenone | 非類固醇 MRA;用於第二型糖尿病合併 CKD 以保護腎臟與心血管,近年研究也用於 HFmrEF/HFpEF |
| **Amiloride** | ENaC 阻斷劑;常與 thiazide 做成複方;可治療鋰鹽引起的腎因性尿崩症 |
| **Triamterene** | ENaC 阻斷劑;常與 HCTZ 複方;可能造成**腎結石**、干擾葉酸代謝、尿液呈藍色螢光 |

## 適應症 {#indications}

### 心衰竭 {#heart-failure}

- **HFrEF(LVEF ≤ 40%)NYHA II–IV**:2022 AHA/ACC/HFSA 與 2021 ESC 皆為 **Class I**,降低死亡與住院。條件:**eGFR > 30 mL/min/1.73m²、血鉀 < 5.0 mEq/L**。
- 心肌梗塞後 LVEF ≤ 40% 合併心衰竭或糖尿病(eplerenone)。
- HFmrEF / HFpEF:可考慮(AHA 2b),以減少住院。
- 劑量:spironolactone 12.5–25 mg 起始,目標 25–50 mg/天;eplerenone 25 → 50 mg/天。
- 台灣心臟學會指引同樣將 MRA 列為 HFrEF 基礎治療之一(見 [[heart-failure]])。

### 其他 {#other-uses}

- **肝硬化腹水**:首選 spironolactone(肝硬化有次發性高醛固酮),常與 furosemide 以 **100 : 40** 比例併用。
- **原發性醛固酮症(Conn 氏症)**:手術前或不能手術者的藥物治療;也可用來鑑別。
- **頑固性高血壓**(已用 3 種含利尿劑的降壓藥仍未控制)的第四線藥物。
- 與排鉀利尿劑合用,**抵銷低血鉀**。
- 腎病症候群水腫;女性多毛症、痤瘡(spironolactone)。

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 說明與處置 |
|---|---|
| **高血鉀** | 最危險:肌肉無力、感覺異常、心搏過緩、**T 波高尖**、心律不整。高危險:腎功能差、老人、糖尿病、併用 ACEI/ARB/ARNI、NSAID、鉀補充劑。ESC:**K⁺ > 5.5 減半劑量,> 6.0 停藥** |
| 腎功能惡化 | 尤其脫水、腹瀉嘔吐時;Cr 大幅上升時減量或暫停 |
| **男性女乳症**、乳房觸痛 | spironolactone 的抗雄性素作用;可改用 eplerenone |
| 月經不規則、陽痿、性慾下降 | 同上 |
| 代謝性酸中毒 | H⁺ 分泌減少(triamterene、amiloride 也會) |
| 低血鈉、脫水 | 與其他利尿劑合用時 |
| 腸胃不適 | 隨餐服用 |
| 腎結石、葉酸缺乏 | triamterene |

**禁忌**:高血鉀(> 5.0)、**嚴重腎功能不全**(eGFR < 30 或無尿)、愛迪生氏病、同時使用鉀補充劑或兩種以上保鉀劑。

## 交互作用 {#interactions}

| 併用藥物/食物 | 結果 |
|---|---|
| **鉀補充劑(KCl)、低鈉鹽(含 KCl)、高鉀食物** | 高血鉀 |
| **ACEI、ARB、[[arni|ARNI]]** | 都減少醛固酮作用 → 高血鉀;HFrEF 常合用(有好處),但要**定期監測 K⁺ 與 Cr**;**ACEI + ARB + MRA 三者合用不建議** |
| NSAID、trimethoprim、heparin、cyclosporine/tacrolimus | 高血鉀、腎損傷 |
| β 阻斷劑 | 鉀不易進入細胞,血鉀稍升 |
| Digoxin | spironolactone 可能干擾部分 digoxin 濃度檢驗,並減少腎排泄;監測濃度 |
| 鋰鹽 | 血鋰上升 |
| 強效 CYP3A4 抑制劑 | eplerenone 濃度上升 → 高血鉀(禁忌併用) |

## 護理重點與衛教 {#nursing}

- 給藥前確認**血鉀與腎功能**;開始或調整劑量後約 **1 週、4 週**抽血,之後每 1–3 個月或依醫囑。
- 衛教**避免高鉀食物**(香蕉、柳丁、柑橘、**芭樂**、奇異果、番茄、深綠色蔬菜、馬鈴薯、果乾、**雞精**、運動飲料)、**不用低鈉鹽或薄鹽醬油**、不自行服鉀補充劑。
- 生病時(腹瀉、嘔吐、無法進食)可能需暫停 MRA,並就醫抽血(sick day)。
- 注意高血鉀症狀:肌肉無力、四肢發麻、心跳慢或不規則。
- 男性告知乳房脹痛/腫大的可能性,可與醫師討論改藥;女性可能月經不規則。
- 隨餐服用減少腸胃不適;起效需數天,不要因「尿量不多」自行加量。
- 每日量體重;肝硬化病人量腹圍。
- 兒童心臟病使用 spironolactone 時,同樣是**高血鉀**風險,不是低血鉀。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **Spironolactone 會造成高血鉀**,「可能造成血鉀過低」**錯**(兒科先天性心臟病題常考)。
- Spironolactone 衛教:**注意鉀離子濃度、不宜吃芭樂(高鉀)**;「多吃柑橘」錯。
- **醛固酮拮抗劑作用在集尿管**(不是近曲小管);拮抗的是**礦物皮質素(醛固酮)受體**,不是糖皮質素受體。
- 醛固酮受體拮抗劑、**常用於治療心衰竭** → eplerenone(干擾:chlorothiazide、furosemide、tolvaptan)。
- 能降血壓但**不抑制睪固酮/不造成男性女乳** → **eplerenone**。
- **高血鉀的藥物導因** → ACEI、醛固酮拮抗劑(thiazide、代謝性鹼中毒則造成低血鉀)。
- Triamterene、acetazolamide 可產生代謝性酸中毒。
:::
