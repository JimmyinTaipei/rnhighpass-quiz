## 重點摘要 {#summary}

- 機轉：與**青黴素結合蛋白**(PBPs)結合，**抑制細胞壁合成**，屬於**殺菌劑**、**時間依賴型**。
- 用途：青黴素類(A 族鏈球菌、梅毒首選)、頭孢菌素類(手術預防、肺炎、腦膜炎)、carbapenem(多重抗藥性的重症感染)。
- 主要副作用：**過敏**(最常見，嚴重時過敏性休克)、腹瀉與困難梭菌感染、大劑量時癲癇。
- 護理重點：給藥前**詢問過敏史**、首劑觀察並備妥 epinephrine；**按時等間隔**給藥；抗藥機轉是 **β-內醯胺酶**。

## 作用機轉 {#mechanism}

所有 β-lactam 的結構都有一個**四員環的 β-內醯胺環**。它與細菌細胞膜上的**青黴素結合蛋白**(轉肽酶)結合，阻止胜肽聚醣交叉連結，細胞壁變弱，細菌在滲透壓下破裂死亡([[microbial-pathogenesis#bacterial-structure|細菌構造]])。

- 對**正在分裂**的細菌最有效，屬於**殺菌劑**。
- **沒有細胞壁的病原無效**：**黴漿菌**、尿漿菌(Ureaplasma)；**真菌**的細胞壁也不是胜肽聚醣。
- 人體細胞沒有細胞壁，所以安全範圍大。

### 抗藥機轉 {#resistance}

| 機轉 | 代表 |
|---|---|
| **β-內醯胺酶**水解 β-內醯胺環 | 細菌對青黴素**最主要**的抗藥方式；葡萄球菌的青黴素酶、腸內菌的**廣效型 β-內醯胺酶**(ESBL)、carbapenem 分解酶 |
| **青黴素結合蛋白構造改變** | **MRSA**(染色體 *mecA* 基因產生 PBP2a，對所有傳統 β-lactam 都有抗藥性)；抗青黴素的肺炎鏈球菌 |
| 外膜通透性下降、排出幫浦 | 綠膿桿菌等 G− 菌 |

對策：加上 **β-內醯胺酶抑制劑**(clavulanic acid、sulbactam、tazobactam)，或改用 carbapenem；MRSA 則改用 vancomycin 等藥物([[glycopeptides]])。

## 代表藥物 {#agents}

### 青黴素類 {#penicillins}

| 分類 | 代表藥 | 抗菌範圍與用途 |
|---|---|---|
| **天然青黴素** | **penicillin G**(靜脈、肌肉注射)、**benzathine penicillin G**(長效肌肉注射)、penicillin V(口服) | **G+ 球菌**、**A 族鏈球菌**(咽炎、**猩紅熱**、**風濕熱預防**)、**梅毒**(首選)、腦膜炎雙球菌、多數厭氧菌、螺旋體；會被青黴素酶分解 |
| **抗葡萄球菌青黴素**(耐青黴素酶) | methicillin、**oxacillin**、**cloxacillin**、dicloxacillin | **不易被葡萄球菌的青黴素酶破壞**，用於對 oxacillin 敏感的金黃色葡萄球菌(MSSA) |
| **胺基青黴素**(廣效) | **ampicillin**、**amoxicillin** | 範圍擴大到部分 G−(大腸桿菌、嗜血桿菌)、**李斯特菌**、腸球菌；amoxicillin 用於中耳炎、鼻竇炎、**幽門螺旋桿菌**三合一療法 |
| 抗綠膿桿菌青黴素 | **piperacillin**、ticarcillin | **綠膿桿菌**、院內感染 |
| **合併 β-內醯胺酶抑制劑** | **amoxicillin＋clavulanic acid**(Augmentin)、ampicillin＋sulbactam(Unasyn)、**piperacillin＋tazobactam** | 抑制劑保護 β-lactam 不被分解，**合用效果比單獨使用好** |

### 頭孢菌素類 {#cephalosporins}

代數越新，對 **G− 菌**的效果越好、越能通過血腦障壁；第一代對 G+ 最好。

| 代 | 代表藥 | 重點 |
|---|---|---|
| 第一代 | **cefazolin**、cephalexin(口服) | G+ 與部分 G−；**手術預防性抗生素**首選 |
| 第二代 | cefuroxime、cefoxitin | 呼吸道感染；cefoxitin 可涵蓋部分厭氧菌 |
| **第三代** | **ceftriaxone**、cefotaxime、**ceftazidime** | **腦膜炎**(能進入腦脊髓液)、社區型肺炎、**淋病**(ceftriaxone)；ceftazidime 可治**綠膿桿菌** |
| 第四代 | **cefepime** | 綠膿桿菌、院內感染；腎功能不好未調整劑量會**神經毒性**(意識改變、癲癇) |
| 第五代 | ceftaroline | 目前唯一能治 **MRSA** 的頭孢菌素 |

**腸球菌**與**李斯特菌**對所有頭孢菌素都天然抗藥，這兩種菌要用 ampicillin。

- 第三代中 **ceftriaxone、cefotaxime 對綠膿桿菌效果差**；要涵蓋綠膿桿菌選 **ceftazidime** 或 cefepime。
- **ceftriaxone**：
  - **不可與含鈣溶液**(例如**林格氏液**、乳酸林格氏液)混合或經同一管路輸注，會在肺、腎形成鈣鹽沉澱；**新生兒**曾發生致死個案，新生兒需要靜脈鈣劑時避免使用。
  - 大量經膽汁排出，可在膽囊形成**膽泥**(假性膽結石)。
- 新一代合併藥物用於**多重抗藥性 G− 菌**(ESBL、CRE、多重抗藥綠膿桿菌)：**ceftazidime-avibactam**、**ceftolozane-tazobactam**，以及鐵載體頭孢菌素 **cefiderocol**；屬於需管制的後線抗生素([[antibiotics-overview#mdro]])。

### Carbapenems 與 monobactam {#carbapenems}

| 藥物 | 重點 |
|---|---|
| **imipenem**＋cilastatin | 抗菌範圍**最廣**的 β-lactam 之一；cilastatin 抑制腎臟酵素分解 imipenem；**大劑量或腎功能差時易引起癲癇** |
| **meropenem** | 癲癇風險較低；常用於**多重抗藥性**菌的重症感染 |
| ertapenem | 一天一次；**不涵蓋綠膿桿菌** |
| **aztreonam**(monobactam) | **只對 G− 菌**有效；與青黴素**沒有交叉過敏**，可用於青黴素過敏者 |

carbapenem 會讓 **valproic acid 血中濃度大幅下降**，可能誘發癲癇，兩者不可併用。carbapenem 不是 β-內醯胺酶抑制劑，「併用 amoxicillin 與 carbapenem 以免 amoxicillin 被分解」是錯誤選項。

## 適應症 {#indications}

| 感染 | 常用 β-lactam |
|---|---|
| **A 族鏈球菌**咽炎、扁桃腺炎、猩紅熱 | **penicillin**、amoxicillin(首選，不是紅黴素或萬古黴素) |
| 風濕熱的次級預防 | benzathine penicillin G 定期肌肉注射 |
| **梅毒**(含孕婦、先天梅毒) | **penicillin G**(benzathine 或水溶性)；孕婦**只能用青黴素** |
| 新生兒感染 | **penicillin G**、ampicillin(副作用較少；避免 chloramphenicol、磺胺類、tetracycline) |
| 金黃色葡萄球菌(MSSA) | oxacillin、cloxacillin、cefazolin(比 vancomycin 更好) |
| 社區型肺炎、中耳炎、鼻竇炎 | amoxicillin(±clavulanate)、ceftriaxone |
| **幽門螺旋桿菌** | **PPI＋amoxicillin＋clarithromycin**(三合一療法，不含 erythromycin) |
| 細菌性腦膜炎 | ceftriaxone、cefotaxime(新生兒加 ampicillin 涵蓋李斯特菌) |
| 綠膿桿菌 | piperacillin＋tazobactam、ceftazidime、cefepime、carbapenem |
| 手術預防 | cefazolin，劃刀前 60 分鐘內 |
| 乳腺炎 | 抗葡萄球菌青黴素或頭孢菌素，**可以持續哺乳**，用藥後 24–48 小時症狀多會改善 |

**急性支氣管炎**多由病毒引起，不用 ampicillin 等抗生素。

## 藥動重點 {#pharmacokinetics}

- **半衰期短**(多數約 1 小時)，注射劑需要**頻繁、等間隔**給藥，例如 q4h、q6h。
- 多數由**腎臟**排除，腎功能不全要調整劑量(ceftriaxone 同時經膽汁排除，較不需調整)。
- 腦脊髓液濃度平常很低，**腦膜發炎時才能進入**；第三代頭孢菌素進入較佳。
- **probenecid** 抑制腎小管分泌，可以延長青黴素的血中濃度。
- 口服：ampicillin 受食物影響大，宜**空腹**以開水服用(不要配果汁等酸性飲料)；amoxicillin 不太受食物影響。
- 稀釋後的 penicillin G 不穩定，需**冷藏 2–8℃** 並在期限內使用。

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 說明與處置 |
|---|---|
| **過敏反應** | **最常見也最危險**：蕁麻疹、血管性水腫、支氣管痙攣、**過敏性休克**(第 I 型，IgE 媒介)；也可能出現延遲型皮疹、血清病。立即停藥並處置(見[[antibiotics-overview#allergy]]) |
| 腸胃 | **腹瀉**(amoxicillin-clavulanate 最常見)、噁心；**困難梭狀桿菌腸炎**([[antibiotics-overview#c-difficile]]) |
| 皮疹 | 胺基青黴素用於 **EB 病毒感染性單核球症**時，很容易出現斑丘疹(不一定是真正過敏) |
| 神經毒性 | **大劑量**或**腎功能不全**時的**癲癇**、腦病變(青黴素、imipenem、cefepime) |
| 腎臟 | 間質性腎炎(methicillin 最典型) |
| 血液 | 溶血性貧血、白血球減少(長期大劑量) |
| 其他 | ceftriaxone 在膽囊形成沉積(膽泥)；新生兒**不可**與含鈣的靜脈輸液同時給 ceftriaxone(沉澱) |
| **Jarisch–Herxheimer 反應** | 治療**梅毒**的第一劑後數小時內發燒、畏寒、頭痛、肌肉痛，是螺旋體大量死亡釋出物質造成，**不是過敏**，給予退燒止痛並安撫 |

### 交叉過敏 {#cross-reactivity}

- 自述青黴素過敏的人，**超過 90%** 經檢查後其實不過敏。
- 確定青黴素過敏者，對**頭孢菌素**的交叉反應約 **2–3%**，carbapenem 更低，**aztreonam 沒有**([UpToDate：penicillin allergy](https://www.uptodate.com/contents/allergy-evaluation-for-immediate-penicillin-allergy-skin-test-based-diagnostic-strategies-and-cross-reactivity-with-other-beta-lactam-antibiotics))。
- 曾經發生**過敏性休克**或嚴重皮膚反應(如史帝文生–強生症候群)的人，要避免同類藥物，由醫師評估替代藥或減敏。

## 皮膚試驗 {#skin-test}

- 台灣衛生主管機關認為盤尼西林皮膚試驗**不宜硬性規定**；注射前要**詳細詢問過敏史**，注射後留觀約 **30 分鐘**並備妥急救藥物([內科學誌 2020](https://www.tsim.org.tw/ehc-tsim/s/viewFile?documentId=f2ab69c99a424c6282e9b47f871b470f))。仍依各醫院規定執行。
- 做法：**皮內注射**，一般選**前臂內側中段**；四肢嚴重水腫時可改在**前胸鎖骨下方**。
- 注射後**不可搓揉按摩**(會影響判讀)；在注射處畫圈標示，依規定時間(常見 15–20 分鐘)觀察紅腫範圍。
- 盤尼西林試驗、貼布試驗、皮內試驗都是皮膚過敏試驗；伍氏燈(Wood's light)檢查是看黴菌感染，不是過敏試驗。

## 交互作用 {#interactions}

| 併用 | 結果 |
|---|---|
| **胺基配醣體** | **協同作用**：β-lactam 破壞細胞壁，讓胺基配醣體容易進入菌體(但不可在同一袋點滴混合，會互相失去活性) |
| β-內醯胺酶抑制劑 | 擴大抗菌範圍 |
| probenecid | 延長青黴素作用 |
| carbapenem＋valproic acid | valproate 濃度下降，易癲癇 |
| 抑菌劑(如 tetracycline) | 傳統上認為可能拮抗 |
| warfarin | 部分頭孢菌素增加出血風險 |

## 護理重點與衛教 {#nursing}

1. **給藥前**：確認過敏史與過敏註記；依醫囑先完成培養採檢。
2. **首劑**：密切觀察 30 分鐘，床旁備妥 **epinephrine**；出現喘鳴、呼吸困難、血壓下降時立即停藥並急救。
3. **按時等間隔給藥**(例如 q8h 是 9 AM、5 PM、1 AM)，以維持血中濃度。
4. **靜脈給藥**：依規定稀釋與滴注時間；不與胺基配醣體混在同一袋；觀察靜脈炎。
5. **benzathine penicillin** 是混懸液，做**深部肌肉注射**(臀部)，不可打入血管；注射很痛，事先說明。
6. 觀察腹瀉次數(困難梭菌)、皮疹、口腔或陰道念珠菌感染。
7. 腎功能不全者注意意識改變、抽搐。
8. **衛教**：完成整個療程；口服 ampicillin 空腹以開水服用；服用含 clavulanate 的藥可與餐同服以減少腸胃不適；出現皮疹、呼吸困難要立即就醫；治療梅毒後按時回診追蹤血清檢驗。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 機轉：**抑制細胞壁合成**、殺菌；**黴漿菌沒有細胞壁**，青黴素無效。
- 青黴素抗藥：**β-內醯胺酶**；**MRSA**：青黴素結合蛋白改變(不是產生 β-內醯胺酶)。
- **A 族鏈球菌**首選 **penicillin**；**猩紅熱**用青黴素後約 24 小時退燒；**梅毒**用青黴素。
- **cloxacillin** 不易被葡萄球菌青黴素酶破壞；**piperacillin** 可治綠膿桿菌。
- amoxicillin 屬 β-lactam、殺菌、常見副作用腹瀉，**可以**與 clavulanate 併用(不是禁止)。
- 幽門桿菌三合一療法：omeprazole＋clarithromycin＋amoxicillin(不含 erythromycin)。
- 新生兒感染較安全：**penicillin G**。
- 青黴素過敏屬於**抗體**(IgE)媒介；皮試後**不可按摩**；水腫病人可改在**前胸鎖骨下方**做皮試。
- 稀釋後的 penicillin G 要**冷藏**。
:::
