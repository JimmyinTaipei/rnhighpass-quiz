## 重點摘要 {#summary}

- 選擇性阻斷血管平滑肌 **α1 受體** → 小動脈與靜脈擴張、血壓 ↓;同時放鬆**前列腺與膀胱頸**平滑肌 → 改善排尿。
- 代表藥:**prazosin**、doxazosin、terazosin(-azosin);tamsulosin 主要用於 BPH。
- 最重要副作用:**首劑現象**——第一次服藥或加量後**姿勢性低血壓、暈厥**。
- 護理:**低劑量開始、睡前服用**,起身動作放慢。
- 高血壓非第一線;適合**合併良性前列腺肥大(BPH)**者,以及嗜鉻細胞瘤術前。

## 作用機轉 {#mechanism}

正腎上腺素作用在血管 **α1 受體**使血管收縮(受體分布見 [[blood-pressure-regulation#autonomic-receptors]])。α1 阻斷劑:

- **小動脈擴張** → 周邊阻力 ↓;**靜脈擴張** → 靜脈回流(前負荷)↓。
- 因為靜脈也擴張,站立時血液滯留下肢 → **姿勢性低血壓**特別明顯。
- 選擇性 α1 阻斷劑**不阻斷突觸前 α2**,正腎上腺素負回饋仍在 → **反射性心搏過速比非選擇性 α 阻斷劑(phentolamine)輕**,但仍可能發生。
- 前列腺、膀胱頸、尿道平滑肌有大量 α1(特別是 α1A)→ 放鬆後尿流改善。
- 對血脂中性或略有好處,不影響血糖。

## 代表藥物 {#agents}

| 藥物 | 特色 |
|---|---|
| **Prazosin**(Minipress) | 短效,一天 2–3 次;**首劑現象最明顯**;亦用於 PTSD 惡夢 |
| **Doxazosin**(Cardura、Doxaben) | 長效,一天一次;高血壓與 BPH |
| **Terazosin**(Hytrin) | 一天一次;高血壓與 BPH |
| Tamsulosin(Harnalidge)、Silodosin | **α1A 選擇性**,主要作用在前列腺,**只用於 BPH、不當降壓藥**;較少低血壓,但會造成射精異常、白內障手術的「虹膜鬆弛症候群」 |
| Phenoxybenzamine | **非選擇性、不可逆** α 阻斷;**嗜鉻細胞瘤術前**準備 |
| Phentolamine | 非選擇性、可逆、靜脈注射;嗜鉻細胞瘤高血壓危象、**正腎上腺素等升壓劑外滲**時局部浸潤注射 |

## 適應症 {#indications}

- **高血壓**:2022 台灣指引與 2025 AHA/ACC 指引都**不列為第一線**(ALLHAT 試驗中 doxazosin 組心衰竭較多);用於頑固型高血壓的附加藥,或**合併 BPH** 的男性(見 [[hypertension]])。
- **良性前列腺肥大(BPH)**:改善頻尿、尿流細弱、排尿困難(注意:治療膀胱過動、急迫性尿失禁的是抗膽鹼藥如 oxybutynin,不是 α 阻斷劑)。
- **嗜鉻細胞瘤**:術前 10–14 天先用 α 阻斷劑(phenoxybenzamine 或 doxazosin 等)並補充體液與鹽分,**α 阻斷充分後才加 β 阻斷劑**(見 [[beta-blockers]])。
- 其他:prazosin 用於 PTSD 惡夢(仿單外)。

:::note[嗜鉻細胞瘤切除後]
腫瘤切除後兒茶酚胺來源突然消失,加上術前長期 α 阻斷,**術後常見的是低血壓(與低血糖)**,不是高血壓——應輸液擴容、必要時升壓劑,而不是再給 α 阻斷劑。
:::

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 說明與處置 |
|---|---|
| **首劑現象**(first-dose phenomenon) | 第一次服藥或加量後 30–90 分鐘內出現**姿勢性低血壓、頭暈、暈厥**;已用利尿劑、β 阻斷劑、脫水、老人風險較高 → **低劑量開始、睡前服用**、起身慢 |
| 持續性姿勢性低血壓、頭暈 | 老人跌倒風險 ↑ |
| 反射性心搏過速、心悸 | 血壓下降所致(比非選擇性 α 阻斷劑輕) |
| 鼻塞、頭痛、倦怠 | 血管擴張 |
| 鈉水滯留、水腫 | 長期單用時腎臟代償;常併用利尿劑 |
| 射精異常 | tamsulosin、silodosin 較常見 |
| 虹膜鬆弛症候群 | 白內障手術前要告知眼科醫師曾服用 α1 阻斷劑 |

**禁忌/小心**:對藥物過敏;姿勢性低血壓病史;心衰竭(非首選);與 PDE5 抑制劑(sildenafil)併用小心。

## 交互作用 {#interactions}

- **PDE5 抑制劑**(sildenafil、tadalafil):加成低血壓,兩者間隔時間並從低劑量開始。
- 其他降壓藥、**利尿劑、β 阻斷劑**、硝酸鹽、酒精:加重首劑低血壓。
- NSAIDs:降壓效果 ↓。

## 護理重點與衛教 {#nursing}

- **第一次服藥安排在睡前**,服藥後躺床;夜間起床如廁要先坐在床緣 1–2 分鐘再站起。
- **低劑量開始**,加量時重新注意首劑現象;停藥數天後重新服用,要再從低劑量開始。
- 監測臥、坐、站血壓(姿勢性低血壓),預防跌倒。
- 開車、操作機械前先確定自己對藥物的反應。
- BPH 病人:評估排尿症狀、餘尿;症狀改善需數天到數週。
- 白內障手術前主動告知醫師用藥。
- 使用 phentolamine 治療升壓劑外滲:於外滲部位皮下多點浸潤注射,越早越好(12 小時內)。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **Prazosin 初次服用易姿態性低血壓(首劑現象)→ 低起始劑量、睡前服用**。
- 具血管擴張作用、**可用於 BPH** 的降壓藥 → **prazosin**(α1 阻斷)。
- Prazosin 可用於**嗜鉻細胞瘤**引起的高血壓;嗜鉻細胞瘤**切除後**常低血壓,不需再用 α 阻斷劑。
- Prazosin 仍可能**反射性心搏過速**(atenolol 則不會)。
- 膀胱過動急迫性尿失禁用 oxybutynin,不是 doxazosin。
:::
