**類固醇**是模仿腎上腺皮質激素的藥物，主要用**糖皮質素**的**抗發炎與免疫抑制**作用，所以用途很廣，長期使用的副作用也就是醫源性**庫欣氏症候群**。皮質醇的生理見 [[adrenal-glands#cortisol]]，副作用的機轉見 [[cushing-syndrome#manifestations]]，停藥造成的腎上腺功能不足見 [[adrenal-insufficiency#steroid-withdrawal]]

## 重點摘要 {#summary}

- **作用**：抑制發炎介質(前列腺素、白三烯素、細胞激素)、穩定細胞膜、減少微血管通透性、**抑制淋巴球**與免疫反應；大劑量有**礦物皮質素**作用(保鈉排鉀)
- **用途**：氣喘與慢性阻塞性肺病急性發作、過敏與**過敏性休克**輔助、自體免疫(RA、SLE)、**器官移植**抗排斥、**腎病症候群**、**腦水腫**(腫瘤周圍)、多發性硬化症急性發作、皮膚病、癌症(淋巴瘤、止吐)、**腎上腺功能不足**的補充、**促進胎兒肺成熟**
- **不能**用來治療庫欣氏症候群、白內障；類固醇**不會治癒**多發性硬化症，也**不會增進**傷口癒合
- **長期副作用**：**高血糖**、**骨質疏鬆**、**感染**風險、**傷口癒合差**、**胃潰瘍**、**水腫與高血壓**、**低血鉀**、月亮臉與向心性肥胖、**食慾增加**體重上升、肌肉萎縮、皮膚薄、**白內障與青光眼**、情緒改變與失眠、兒童生長遲緩、腎上腺抑制
- **給藥**：**早上**服(配合皮質醇高峰)、**飯後或與制酸劑**同服；**不可突然停藥**、要**逐步減量**；遇壓力(手術、感染)告知醫師**加量**
- 飲食：**高蛋白**、**高鉀**、**高鈣**與維生素 D、**低鈉**、**低醣**、限熱量

### 國考常考點 {#exam-points}

- 臨床用途**錯誤**：**治療庫欣氏症候群**、**治療白內障**；正確：RA、器官移植、**胎兒肺成熟**、腎上腺功能不足、異位性皮膚炎、**診斷**庫欣氏症候群(地塞米松抑制試驗)
- 長期副作用：**高血糖**、**骨質疏鬆**、感染、水腫、傷口癒合困難；**不是**低血壓、低血鈉、高血鉀、食慾減退、體重降低、低血糖
- 長期 prednisolone 衛教：**飯後**或合併制酸劑；壓力時告知醫師調整；**漸進停藥**；飲食**不是高醣**
- 腎病症候群兒童服 prednisolone：**避免接觸感染源**；不可因腸胃不適自行停藥；同房避免感染病童
- 腦瘤用 **dexamethasone(Decadron)**：**減輕腦水腫**；高劑量時**監測血糖**
- 安胎時促進胎兒肺成熟：**betamethasone**
- 礦物皮質素：促進鈉、氯、水再吸收，**排鉀**(不是回收鉀)
- **eplerenone**：醛固酮拮抗劑，不影響睪固酮(spironolactone 會)；**metyrapone** 抑制皮質醇合成可治療庫欣氏症候群

## 作用與用途 {#actions}

| 作用 | 臨床用途 |
|---|---|
| **抗發炎** | 氣喘、慢性阻塞性肺病急性發作(見 [[asthma-drugs#ics]])、類風濕性關節炎、皮膚炎、痛風急性發作 |
| **免疫抑制** | **器官移植**抗排斥(見 [[immunosuppressants]])、SLE 等自體免疫、**腎病症候群**(兒童微小變化型對類固醇反應很好)、自體免疫溶血 |
| 抗過敏 | 過敏性休克的輔助(防延遲反應，第一線仍是腎上腺素，見 [[anaphylaxis]])、蕁麻疹與血管性水腫 |
| 減輕水腫 | **腦腫瘤周圍水腫**(dexamethasone)；**不建議**用於頭部外傷與中風的腦水腫 |
| 神經 | **多發性硬化症急性發作**(縮短發作，不能治癒)、重症肌無力 |
| 癌症 | 淋巴瘤與白血病化療的一部分、化療止吐(dexamethasone)、腫瘤造成的高血鈣 |
| 補充 | **腎上腺功能不足**(hydrocortisone＋fludrocortisone)、**先天性腎上腺增生** |
| 胎兒 | 早產前 **betamethasone** 或 dexamethasone 促進**胎兒肺成熟** |
| 診斷 | **地塞米松抑制試驗**診斷庫欣氏症候群(見 [[cushing-syndrome#diagnosis]]) |

- 類固醇抑制發炎也會**抑制傷口修復**，所以**不會增進傷口癒合**(見 [[inflammation-repair]])

## 藥物與效價 {#potency}

| 藥物 | 等效劑量(mg) | 抗發炎效價 | 鹽皮質效價(保鈉) | 作用時間 |
|---|---:|---:|---:|---|
| **hydrocortisone**(cortisol) | 20 | 1 | 1 | 短 |
| cortisone | 25 | 0.8 | 0.8 | 短(需肝臟活化) |
| **prednisone**、**prednisolone** | 5 | 4 | 0.8 | 中 |
| **methylprednisolone** | 4 | 5 | 很小 | 中 |
| triamcinolone | 4 | 5 | 0 | 中 |
| **dexamethasone** | 0.75 | 25–30 | **0** | **長** |
| **betamethasone** | 0.6 | 25–30 | 0 | 長 |
| **fludrocortisone** | — | 10 | **很強** | 中 |

- 數值為教科書通則，各書略有差異
- **dexamethasone、betamethasone** 幾乎沒有保鈉作用 → 適合**腦水腫**與胎兒肺成熟
- **hydrocortisone** 兩種作用都有 → 腎上腺功能不足的補充與**腎上腺危象**
- **fludrocortisone** 主要是礦物皮質素 → 原發性腎上腺功能不足、姿位性低血壓
- prednisone 要經肝臟轉成 prednisolone 才有活性；肝病者直接用 prednisolone
- **劑型**：口服、靜脈(methylprednisolone 衝擊治療)、肌肉、關節內、**吸入**(見 [[asthma-drugs#ics]])、**外用**(臉部與皺摺處用低效價，見 [[allergic-contact-dermatitis-latex#acd-treatment]])、眼藥(長期可能**青光眼、白內障**)

## 副作用 {#adverse-effects}

| 系統 | 副作用 | 護理 |
|---|---|---|
| 代謝 | **高血糖**、類固醇性糖尿病 | **監測血糖**，糖尿病人調整降血糖藥 |
| 體液電解質 | **鈉水滯留**、**水腫**、**高血壓**、**低血鉀** | 量體重、血壓、血鉀；低鈉高鉀飲食 |
| 骨骼肌肉 | **骨質疏鬆**、病理性骨折、股骨頭缺血性壞死、肌肉萎縮無力 | 補**鈣**與**維生素 D**、負重運動、防跌；使用 **3 個月以上**測骨密度或用 FRAX 評估骨折風險(ACR 2022；2025 台灣骨鬆指引)，高風險者用雙磷酸鹽、denosumab 或 teriparatide |
| 免疫 | **感染**風險增加、**感染徵象被遮蔽**、**傷口癒合差** | 避免接觸感染源、注意不明顯的感染；**活性疫苗**要依醫囑避免 |
| 腸胃 | **消化性潰瘍**、出血；**食慾增加** | **飯後**服、必要時合併制酸劑或氫離子幫浦抑制劑；觀察黑便 |
| 外觀 | 月亮臉、水牛肩、向心性肥胖、痤瘡、多毛、皮膚變薄、紫紋、易瘀青 | 說明多數停藥後會改善，關心身體心像 |
| 眼 | **白內障**、**青光眼** | 長期使用者定期眼科檢查 |
| 精神 | 欣快、失眠、情緒不穩、憂鬱、精神病 | 早上服藥減少失眠；觀察情緒 |
| 兒童 | **生長遲緩** | 追蹤身高體重；盡量用隔日療法或吸入、外用 |
| 內分泌 | **下視丘–腦下垂體–腎上腺軸抑制**、腎上腺萎縮 | 不可突然停藥 |

- 常見錯誤選項：**低血壓**、**低血鈉**、**高血鉀**、**低血糖**、**食慾減退**、**體重降低**都**不是**類固醇的副作用
- 醣類**避免高醣**、蛋白質要**高蛋白**(對抗分解)

## 給藥原則與衛教 {#nursing}

1. **早上**一次服用(約 8 點前)，配合體內皮質醇的早晨高峰，較少抑制腎上腺、減少失眠
2. 需要長期使用時可考慮**隔日療法**(兩天份在隔日早上一次給)，讓腎上腺有休息後恢復的時間
3. **飯後**服用，或依醫囑合併制酸劑、胃藥
4. **不可自行突然停藥**；病情穩定後依醫囑**逐步減量**(見 [[adrenal-insufficiency#steroid-withdrawal]])
5. 遇到**手術、感染、創傷**等壓力，告知醫師**調整劑量**；隨身攜帶用藥卡
6. **預防感染**：勤洗手、避開感冒或傳染病人、不打活性減毒疫苗(依醫囑)；兒童病房**不和感染病童同房**
7. 監測血糖、血壓、體重、血鉀、骨密度與眼睛
8. **飲食**：**高蛋白**、**高鉀**、**高鈣**與維生素 D、**低鈉**、**低醣**、控制熱量
9. 腸胃不適或其他副作用要回報，不可自己停藥

## 壓力劑量 {#stress-dose}

- 長期使用類固醇者腎上腺被抑制，遇壓力時身體無法自己增加皮質醇
- **生病日規則**(ESE／Endocrine Society 2024)
   1. **發燒、感染**等輕中度壓力：口服劑量**加倍**(或依醫囑三倍)直到康復
   2. **嘔吐**吃不下：改**注射** hydrocortisone 並就醫
   3. **手術、生產、重症**：由醫師給**靜脈 hydrocortisone** 壓力劑量，術後逐步回到原本劑量
- 腎上腺危象的劑量與處置見 [[adrenal-insufficiency#adrenal-crisis]]

## 類固醇的抑制劑與拮抗劑 {#inhibitors}

| 藥物 | 作用 | 用途 |
|---|---|---|
| **metyrapone** | 抑制皮質醇合成的最後一步 | **庫欣氏症候群** |
| ketoconazole、osilodrostat | 抑制類固醇合成酵素 | 庫欣氏症候群 |
| aminoglutethimide | 抑制膽固醇轉成孕烯醇酮 → 皮質醇、**雄性素**、**動情素**都減少 | 舊藥 |
| **mifepristone** | 阻斷**糖皮質素受體**與**黃體素受體** | 庫欣氏症候群的高血糖；終止早期妊娠 |
| **spironolactone** | 阻斷**礦物皮質素受體**；也阻斷雄性素受體 | 原發性醛固酮症、心衰竭、水腫；副作用**男性女乳症** |
| **eplerenone** | 選擇性阻斷礦物皮質素受體，**不影響性激素** | 高血壓、心衰竭 |

- spironolactone 與 eplerenone 的利尿劑作用與高血鉀見 [[potassium-sparing-diuretics]]
