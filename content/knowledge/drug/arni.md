## 重點摘要 {#summary}

- **Sacubitril**(抑制腦啡肽酶 neprilysin → **利鈉胜肽增加**:利尿、利鈉、血管擴張、抗纖維化)+ **valsartan**(ARB,阻斷血管收縮素 II)。
- **HFrEF 四大支柱**之一,比 ACEI(enalapril)更能**降低死亡與住院**;新指引建議 HFrEF 優先使用。
- 副作用:**低血壓**(最常見)、**高血鉀**、腎功能變差、**血管性水腫**;懷孕禁用。
- **與 ACEI 至少間隔 36 小時**;用藥後 **BNP 會上升**,追蹤要看 **NT-proBNP**。

## 作用機轉 {#mechanism}

心衰竭時身體同時有兩套力量在拉扯(見 [[blood-pressure-regulation#raas]] 與 [[blood-pressure-regulation#natriuretic-peptides]]):

| 系統 | 對心衰竭 | ARNI 的作用 |
|---|---|---|
| **RAAS**(血管收縮素 II、醛固酮) | 血管收縮、鈉水滯留、心肌纖維化、重塑 → **有害** | **Valsartan** 阻斷 AT1 受體 |
| **利鈉胜肽**(ANP、BNP) | 利尿利鈉、血管擴張、抑制 RAAS 與交感、抗纖維化 → **有益** | **Sacubitril** 抑制分解它們的腦啡肽酶 → 濃度上升 |

- 腦啡肽酶(neprilysin)也會分解**血管收縮素 II**,所以**單用 neprilysin 抑制劑會讓血管收縮素 II 增加**——必須搭配 ARB,這是做成複方的原因。
- 腦啡肽酶也分解**緩激肽(bradykinin)**;若再加上 ACEI(同樣阻止緩激肽分解),緩激肽大量堆積 → **血管性水腫**風險大增 → 所以 **ARNI 不能與 ACEI 併用**,改藥時要間隔 36 小時。
- 結果:降低前後負荷、減少鈉水滯留、減緩心室重塑,**降低心血管死亡與心衰竭住院**(PARADIGM-HF 試驗)。

## 代表藥物 {#agents}

| 藥物 | 劑量 |
|---|---|
| **Sacubitril/valsartan(Entresto®,健安心)** | 24/26 mg、49/51 mg、97/103 mg,**一天兩次**;每 2–4 週倍增至目標 97/103 mg bid(依血壓、血鉀、腎功能) |

低起始劑量(24/26 mg bid)用於:未曾用過 ACEI/ARB 或原本劑量低、eGFR < 30、中度肝功能不全、**老人**、收縮壓偏低者。

## 適應症 {#indications}

- **HFrEF(LVEF ≤ 40%)NYHA II–III**:
  - **2022 AHA/ACC/HFSA**:建議使用 ARNI 降低罹病率與死亡率(Class 1);已在用 ACEI/ARB 且可耐受者,**換成 ARNI**(Class 1);新診斷者**可直接使用 ARNI**,不必先試 ACEI。
  - **2021 ESC**:ARNI 建議作為 ACEI 的替代(Class I),新診斷者可考慮直接使用(IIb)。
  - **台灣心臟學會指引**同樣將 ARNI 列為 HFrEF 的優先選擇(見 [[heart-failure]])。
- **HFmrEF / HFpEF**(LVEF 偏低端者可能受益):AHA 2b,可考慮以減少住院。
- 國外部分地區也核准用於兒童心衰竭;單純高血壓不是其主要適應症。

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 說明與處置 |
|---|---|
| **低血壓、頭暈** | 最常見(比 enalapril 多);先減少利尿劑或其他降壓藥,再考慮減量 |
| **高血鉀** | valsartan 減少醛固酮;與 MRA 併用時更要監測 |
| 腎功能惡化 | 開始後 Cr 小幅上升可接受;大幅上升要評估脫水 |
| **血管性水腫** | 臉、唇、舌、喉頭腫脹 → **立即停藥、維持呼吸道**;發生率比 ACEI 略高但比單純合用少 |
| 咳嗽 | 比 ACEI 少 |

**禁忌**:
- **過去曾發生血管性水腫**(不論原因,尤其是 ACEI/ARB 相關)。
- **36 小時內使用過 ACEI**。
- **懷孕**(RAAS 抑制致胎兒腎臟與顱骨發育異常);確認懷孕立即停藥。
- 糖尿病病人併用 aliskiren;嚴重肝功能不全。

## 交互作用 {#interactions}

| 併用藥物 | 結果 |
|---|---|
| **ACEI** | **禁止併用**:血管性水腫;由 ACEI 換 ARNI 需停 ACEI **36 小時**後才開始,反之亦然 |
| ARB | 重複阻斷(已含 valsartan),不併用 |
| [[potassium-sparing-diuretics|MRA]]、鉀補充劑、低鈉鹽 | 高血鉀 |
| 利尿劑、其他降壓藥 | 低血壓 |
| NSAID | 腎功能惡化、高血鉀 |
| 鋰鹽 | 血鋰上升 |
| Statins(部分) | sacubitril 可能提高 atorvastatin 濃度(臨床意義小) |

## 護理重點與衛教 {#nursing}

- 給藥前量**血壓**;收縮壓 < 100 mmHg 或有頭暈、姿勢性低血壓時通報醫師(不要自行停用)。
- 從 ACEI 換成 ARNI:確認**最後一劑 ACEI 時間已過 36 小時**。
- 開始或調高劑量後約 **1–2 週**追蹤**血鉀與腎功能**。
- 衛教**血管性水腫**警訊(嘴唇、舌頭、臉腫、吞嚥或呼吸困難)→ 立即就醫。
- 起身放慢;避免高鉀食物過量、低鈉鹽、自行服 NSAID。
- 育齡女性避孕;計畫懷孕或懷孕時立即告知醫師。
- 一天兩次,規律服用;每日量體重、觀察水腫。
- **BNP 判讀**:ARNI 會抑制 BNP 分解 → **BNP 上升不一定代表心衰竭惡化**;使用 ARNI 者以 **NT-proBNP**(不被腦啡肽酶分解)追蹤病情(見 [[bnp]])。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- ARNI = **sacubitril(腦啡肽酶抑制劑)+ valsartan(ARB)**;作用是**增加利鈉胜肽**並阻斷 RAAS。
- **與 ACEI 間隔 36 小時**、不可併用 → 血管性水腫。
- 常見副作用:**低血壓、高血鉀、腎功能變差**;懷孕禁用。
- 使用 ARNI 後 **BNP 上升**,追蹤改用 **NT-proBNP**。
- 心衰竭「四大支柱」:**ARNI(或 ACEI/ARB)、β 阻斷劑、MRA、SGLT2 抑制劑**——都能降低死亡率;loop 利尿劑與 digoxin 只改善症狀/住院。
:::
