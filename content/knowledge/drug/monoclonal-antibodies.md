**單株抗體(mAb)**是由**單一 B 細胞株**製造、**只辨認同一個表位**的抗體，可以專一地結合特定分子（細胞激素、受體、細胞表面標記）。它們被用在**自體免疫疾病、癌症、過敏與氣喘、器官移植**等許多領域，是**生物製劑**的主力。這一頁整理**命名規則、常見藥物與標的、共同的不良反應與護理**。各疾病的完整治療見各自頁面

## 重點摘要 {#summary}

- **命名**：字尾 **-mab**；**-xi-** 嵌合（鼠＋人）、**-zu-** 人源化、**-u-** 全人；**-cept** 是受體與 IgG Fc 的**融合蛋白**（不是抗體）
- **標的決定用途**：抗 **TNF-α**（RA、克隆氏症）、抗 **CD20**（淋巴瘤、RA）、抗 **IgE**（氣喘）、抗 **HER2**／**EGFR**（癌症）、抗 **PD-1**（免疫治療）
- **共同風險**：**輸注反應**、**細胞激素釋放症候群**、**感染**（**潛伏結核、B 型肝炎再活化**）、免疫相關不良反應
- **用藥前**：篩檢**結核與 B 型肝炎**；**避免活性減毒疫苗**；**輸注時監測**生命徵象
- **口服小分子**(**-tinib**)是**標靶藥**但**不是單株抗體**

### 國考常考點 {#exam-points}

- **Omalizumab**：**結合游離 IgE**（抗 IgE），減少肥大細胞釋出介質，用於**重度過敏性氣喘**；**不是**治療痛風、不是抑制 IgG 受體
- **Etanercept**：**結合 TNF-α**（受體融合蛋白），用於 **RA**；**infliximab**、**adalimumab** 是抗 TNF 單株抗體，也用於**克隆氏症**；**最易使潛伏結核復發**的是 **infliximab**
- **Anakinra**：**阻斷 IL-1 受體**；**tocilizumab**：抗 IL-6 受體；**tofacitinib** 是 **JAK 抑制劑**（小分子）
- **Rituximab**：**抗 CD20**，用於 B 細胞淋巴瘤與 RA
- **Trastuzumab**：**靜脈滴注**，**抗 HER2**，要**監測心臟功能**；**panitumumab**：**抑制 EGFR**；**gefitinib**：EGFR **酪胺酸激酶**抑制劑（小分子）
- **Alemtuzumab**：**人源化**單株抗體，用於**移植誘導免疫抑制**
- **Adalimumab** 是 **TNF-α 抑制劑**；vedolizumab、ustekinumab 不是（分別抗整合素、抗 IL-12／23）

## 命名與種類 {#naming}

### 命名規則 {#naming-rules}

| 字尾與中綴 | 意義 | 例子 |
|---|---|---|
| **-mab** | 單株抗體 | — |
| **-omab**(**-o-**) | **鼠源** | ibritumomab |
| **-ximab**(**-xi-**) | **嵌合**（鼠可變區＋人恆定區） | **rituximab、infliximab、cetuximab** |
| **-zumab**(**-zu-**) | **人源化**（只保留鼠的 CDR） | **trastuzumab、bevacizumab、omalizumab、tocilizumab、alemtuzumab** |
| **-umab**(**-u-**) | **全人** | **adalimumab、panitumumab、denosumab、golimumab** |
| **-cept** | **受體－Fc 融合蛋白**（不是抗體） | **etanercept、abatacept** |
| 中間的標的詞 | 舊式命名：**-li-**（免疫）、**-tu-**（腫瘤）、**-ci-**（心血管）、**-vi-**（病毒） | |

1. **越人源，免疫原性越低**：鼠源與嵌合抗體較易引起**抗藥抗體**與**輸注反應**，使**療效降低**
2. **Fc 融合蛋白**利用 Fc 延長半衰期，但**沒有抗原結合區**

|---|---|---|

| **CD20（B 細胞）** | **rituximab** | **B 細胞淋巴瘤、CLL、RA**、血管炎 |
| **IgE** | **omalizumab** | **重度過敏性氣喘、慢性蕁麻疹**，見 [[asthma-drugs#biologics]] |
| **IL-5／IL-5R、IL-4Rα、TSLP** | mepolizumab、benralizumab；dupilumab；tezepelumab | 嗜酸性球型氣喘、異位性皮膚炎等 |

| **EGFR** | **cetuximab、panitumumab** | 大腸直腸癌等 |
| **VEGF** | **bevacizumab** | 多種癌症（出血、傷口癒合、蛋白尿與高血壓） |
| **PD-1／PD-L1／CTLA-4** | **pembrolizumab、nivolumab、ipilimumab** | **免疫檢查點抑制劑**，見 [[t-lymphocytes#checkpoints]]；副作用為**免疫相關不良反應** |
| **CD25／CD52** | **basiliximab**；**alemtuzumab** | **器官移植誘導**，見 [[immunosuppressants]] |

## 共同的不良反應 {#adverse-effects}

| 不良反應 | 重點 |
|---|---|
| **輸注反應** | **發燒、寒顫、搔癢、蕁麻疹、低血壓、呼吸困難**，常在**第一次輸注**；**減慢或暫停輸注**、依醫囑給**抗組織胺、退燒藥、類固醇**；嚴重者**停藥並處理過敏性休克**([[anaphylaxis]])；**與過敏反應不易區別**（也可為細胞激素釋放） |
| **細胞激素釋放症候群(CRS)** | 抗體殺死大量目標細胞時釋出細胞激素，**發燒、低血壓、缺氧**；與**目標細胞量**有關（例如 rituximab 在高腫瘤負荷時） |
| **感染** | **TNF 抑制劑**：**潛伏結核再活化**（用前驗結核與胸部 X 光）、**B 型肝炎再活化**、**黴菌感染**；**rituximab**：B 肝再活化與低 Ig；**嚴重感染要暫停** |
| **自體免疫與免疫相關反應** | **檢查點抑制劑**可引起**腸炎、肺炎、肝炎、甲狀腺炎、皮疹** |
| **心臟毒性** | **trastuzumab**（監測心臟功能） |
| **其他** | **干擾輸血前血型檢驗**（例如抗 CD38 抗體），**要通知血庫** |
| **抗藥抗體** | 療效下降 |

## 護理與用藥衛教 {#nursing}

1. **用藥前評估**
   1. **篩檢結核**（病史、**結核菌素或 IGRA**、胸部 X 光）與 **B 型肝炎**
   2. **確認懷孕狀態與避孕**
   3. **疫苗**：先完成必要的**活性減毒疫苗**，用藥期間**避免活性疫苗**([[immunization]])
2. **輸注期間**
   1. **依醫囑前處理**（抗組織胺、退燒藥）
   2. **第一次輸注較慢**，**監測生命徵象**，備妥**急救藥物**
   3. 觀察**發燒、寒顫、皮疹、呼吸困難、低血壓**，**立即減慢或停止**並通知醫師
3. **皮下注射（例如 adalimumab、etanercept、omalizumab）**：**輪替部位**，**冷藏保存**，**自行注射的教學**，**觀察注射部位反應**
4. **感染預防**：**發燒、咳嗽、傷口紅腫**要**提早就醫**；**勤洗手**，避免人潮
5. **長期追蹤**：結核與肝炎、血球與肝腎功能；**心臟**(trastuzumab)；**免疫相關反應**（檢查點抑制劑）
6. **與其他免疫製劑的分工**：**鈣調磷酸酶抑制劑與 mTOR 抑制劑**等小分子見 [[immunosuppressants]]；本頁以**抗體與融合蛋白**為主
