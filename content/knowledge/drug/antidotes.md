多數中毒靠**支持療法**就能度過，只有少數毒物有專一的**解毒劑**。本頁是毒理總論與解毒劑總表：處理順序、中毒症候群、去除毒物與加速排出，以及常見解毒劑；急診的處置流程見 [[emergency-nursing#poisoning]]，兒童誤食(鐵劑、乙醯胺基酚、鉛、腐蝕性物質)見 [[pediatric-injuries#poisoning]]，有機磷見 [[cholinergic-drugs#organophosphate-poisoning]]，巴拉刈見 [[emergency-nursing#paraquat]]，一氧化碳見 [[environmental-injury#carbon-monoxide]]，成癮物質見 [[substance-use-disorders]]。文中縮寫：NAC(N-acetylcysteine)、PAM(Pralidoxime)、BZD(Benzodiazepines)、EDTA(Ethylenediaminetetraacetic acid)、BAL(British Anti-Lewisite，dimercaprol)、DMSA(Dimercaptosuccinic acid，succimer)、AChE(Acetylcholinesterase，乙醯膽鹼酯酶)

## 重點摘要 {#summary}

- **處理順序**：穩定 **ABC**(呼吸道、呼吸、循環)→ 確認毒物(種類、量、時間、途徑) → **去除毒物** → **解毒劑** → 支持療法與監測
- **去除毒物**
   1. 皮膚、眼睛：大量清水沖洗
   2. 腸胃道：**活性碳**最常用；催吐與洗胃有嚴格條件
   3. 加速排出：**尿液鹼化**、利尿、**血液透析**(呼吸器是支持，不是排出)
- **常考解毒劑**
   1. 鴉片類 → **naloxone**；BZD → **flumazenil**
   2. 乙醯胺基酚 → **NAC**
   3. 有機磷 → **atropine ＋ PAM**
   4. 鐵 → **deferoxamine**；鉛 → **EDTA、DMSA、BAL**
   5. 一氧化碳 → **100% 氧氣、高壓氧**；氰化物 → **hydroxocobalamin**
   6. 毛地黃 → 抗體片段；heparin → **protamine**；warfarin → **維生素 K**

### 國考常考點 {#exam-points}

- 瞳孔兩側等大、小於 2 mm → **有機磷、鴉片類**
- 促進毒物排出**不包括使用人工呼吸器**
- 有機磷：解毒劑是 **atropine**(對抗蕈毒鹼作用)＋ **pralidoxime**(恢復 AChE)；**apomorphine 是催吐劑、morphine 不是拮抗劑**；「沒有拮抗劑」錯；atropine 要用到心跳較快(約 80–100 次/分以上)與分泌物乾燥，維持 60 次/分表示不足
- 沙林毒氣與有機磷都**抑制 AChE**；沙林中毒心跳**變慢**，不是加速
- 一氧化碳與血紅素的親和力約為氧的 **200–250 倍**(不是 20 倍)；處理和潛水夫病一樣給 100% 氧與高壓氧
- 巴拉刈主要經**腎臟**排出；**避免常規給高濃度氧**
- 河豚毒素阻斷**鈉通道** → 神經無法去極化
- 長期暴露**錳** → 巴金森症候群
- Deferoxamine：尿液變**玫瑰或深褐色**；輸注太快 → 低血壓、**休克**
- 活性碳對**鐵無效**

## 中毒的處理原則 {#general-management}

1. **穩定生命徵象**最優先：呼吸道、呼吸、循環；意識不清先保護呼吸道；低血糖給葡萄糖
2. **確認毒物**：名稱、量、時間、途徑；保留容器、嘔吐物；可諮詢毒物諮詢中心(如臺北榮總臨床毒物科)
3. 懷疑中毒的線索：不明原因的意識改變、抽搐、心律不整、異常瞳孔、特殊氣味
4. 自殺企圖者要做安全評估與精神科會診

### 中毒症候群 {#toxidromes}

| 症候群 | 常見毒物 | 瞳孔 | 表現 |
|---|---|---|---|
| **膽鹼性** | **有機磷**、氨基甲酸鹽、沙林 | **縮小** | 流涎、流淚、尿失禁、腹瀉、支氣管分泌物多、**心跳慢**、肌肉顫動 |
| **抗膽鹼性** | Atropine、抗組織胺、三環抗憂鬱劑 | **放大** | 皮膚乾紅、高體溫、尿滯留、心跳快、譫妄 |
| **交感神經興奮** | **安非他命、古柯鹼** | **放大** | 心跳快、高血壓、出汗、躁動 |
| **鴉片類** | Morphine、heroin、fentanyl | **針狀縮小** | **昏迷、呼吸抑制**、心跳慢 |
| 鎮靜安眠 | BZD、巴比妥類、酒精 | 正常或略小 | 嗜睡、呼吸抑制 |

1. 抗膽鹼與交感興奮都是瞳孔大、心跳快：**皮膚乾**是抗膽鹼，**出汗**是交感興奮
2. 瞳孔與成癮物質的整理見 [[substance-use-disorders]]

## 去除毒物與加速排出 {#decontamination}

| 方法 | 用法 | 不可用或無效 |
|---|---|---|
| **活性碳** | 吸附多數藥物與化學物，最好在服下 1–2 小時內給；大便變黑 | **不吸附鐵、鋰、強酸強鹼、酒精(醇類)、碳氫化合物、重金屬**；意識差未保護呼吸道時不給 |
| 洗胃 | 服下時間短、毒性高時；意識差先插管 | **腐蝕性物質**不可 |
| 催吐(吐根糖漿) | 已不建議常規使用 | **意識改變、抽搐、腐蝕性物質、碳氫化合物、小於 6 個月**不可 |
| 稀釋 | 腐蝕性物質、意識清楚時少量水或牛奶 | 不用酸鹼中和(產熱) |
| **尿液鹼化** | 弱酸性藥物：**水楊酸**、**巴比妥類**(sodium bicarbonate) | 監測血鉀與 pH |
| 利尿、**血液透析** | 水溶性、分子小、蛋白結合少的毒物(鋰、甲醇、水楊酸、巴拉刈早期) | 脂溶性或蛋白結合高的藥效果差 |

1. 呼吸器是**支持療法**，不是促進毒物排出的方法
2. 兒童催吐與稀釋的細節見 [[pediatric-injuries#decontamination]]

## 解毒劑總表 {#antidote-table}

| 毒物 | 解毒劑 | 機轉與注意 |
|---|---|---|
| **鴉片類** | **Naloxone**(Narcan) | 競爭性拮抗；作用比多數鴉片短，可能需要重複給或點滴(見 [[opioids]]) |
| **BZD** | **Flumazenil** | 競爭性拮抗；長期使用者可能誘發戒斷抽搐(見 [[anxiolytics-hypnotics]]) |
| **乙醯胺基酚** | **N-acetylcysteine**(Mucomyst) | 補充肝臟麩胱甘肽，中和毒性代謝物；越早給越好(約 8–10 小時內)(見 [[nsaids-acetaminophen]]) |
| **有機磷**、氨基甲酸鹽、神經毒氣 | **Atropine** ＋ **pralidoxime(PAM)** | Atropine 對抗蕈毒鹼作用(分泌物、心跳慢)；PAM 讓 AChE 重新活化，要在「老化」前給(見 [[cholinergic-drugs#organophosphate-poisoning]]) |
| 抗膽鹼藥 | Physostigmine | 可通過血腦障壁的 AChE 抑制劑 |
| **鐵** | **Deferoxamine** | 螯合鐵後從尿排出 → 尿液**玫瑰色**；太快輸注會低血壓、休克 |
| **鉛** | **EDTA**、**DMSA**、**BAL**、D-penicillamine | 嚴重或腦病變：BAL＋EDTA；中度：口服 DMSA |
| 汞、砷 | BAL、DMSA | |
| 銅(威爾森氏症) | D-penicillamine | |
| **一氧化碳** | **100% 氧氣**、高壓氧 | 縮短 COHb 半衰期 |
| **氰化物** | **Hydroxocobalamin**；亞硝酸鈉＋硫代硫酸鈉 | Hydroxocobalamin 與氰結合成維生素 B12 排出 |
| 甲醇、乙二醇 | **Fomepizole**(或乙醇) | 阻斷乙醇去氫酶，避免變成毒性代謝物 |
| 亞硝酸鹽(變性血紅素血症) | **Methylene blue** | |
| **毛地黃** | **毛地黃抗體片段**(Digibind、DigiFab) | 見 [[digoxin]] |
| **Heparin** | **Protamine sulfate** | 化學性中和(見 [[anticoagulants]]) |
| **Warfarin** | **維生素 K** | 嚴重出血加凝血因子濃縮物或新鮮冷凍血漿 |
| 硫酸鎂 | **葡萄糖酸鈣** | 深部肌腱反射消失是鎂中毒的早期徵象 |
| β 阻斷劑、鈣離子阻斷劑 | Glucagon、鈣劑 | |
| Isoniazid | 維生素 B6(pyridoxine) | 預防與治療抽搐(見 [[antituberculars]]) |
| 三環抗憂鬱劑 | Sodium bicarbonate | 治療 QRS 變寬與心律不整 |
| 毒蛇咬傷 | 抗蛇毒血清 | 依蛇種選擇(見 [[emergency-nursing#snakebite]]) |
| **巴拉刈** | **沒有解毒劑** | 避免常規高濃度給氧(加重肺纖維化)，主要經**腎臟**排出(見 [[emergency-nursing#paraquat]]) |
| 河豚毒素 | 沒有解毒劑 | 阻斷**鈉通道**，支持療法與呼吸器 |

1. **Apomorphine** 是催吐劑，不是有機磷的解毒劑；**morphine** 會抑制呼吸，有機磷中毒不用

## 重金屬中毒 {#heavy-metals}

1. **鉛**
   1. 來源：油漆漆片、含鉛汽油廢氣、含鉛水管、顏料、彩色印刷紙、含鉛中藥、鉛蓄電池工作
   2. 兒童主要傷害**中樞神經**(智力、行為，不可逆)；成人周邊神經病變(垂腕)、**貧血**(嗜鹼性點彩)、腎病變、腹痛(鉛絞痛)、齒齦鉛線
   3. 治療：先**移除暴露**，再依血鉛濃度用螯合劑(DMSA 口服；嚴重或腦病變 BAL＋EDTA)
   4. 高脂飲食增加鉛吸收，鈣、鐵、維生素 C 減少吸收；**煮沸不能去除鉛**
   5. 兒童預防見 [[pediatric-injuries#common-poisons]]
2. **汞**：神經與腎臟毒性(水俣病是有機汞)
3. **砷**：烏腳病(台灣西南沿海飲用深井水)
4. **錳**：長期暴露(焊接、採礦)累積在基底核 → **巴金森症候群**
5. 鎘：痛痛病(骨軟化、腎病變)；職業病見 [[occupational-health-nursing]]

## 環境與農藥毒物 {#environmental}

1. **有機磷殺蟲劑**(巴拉松)：不可逆抑制 AChE → 乙醯膽鹼堆積 → 膽鹼症候群；處理見上方解毒劑表
2. **巴拉刈**(除草劑)：口腔食道灼傷、**肺纖維化**、腎衰竭；避免高濃度氧；見 [[emergency-nursing#paraquat]]
3. **一氧化碳**：親和力約為氧的 200–250 倍，100% 氧與高壓氧(見 [[environmental-injury#carbon-monoxide]])
4. **河豚毒素**：阻斷電位依賴性**鈉通道** → 不能去極化 → 麻痺、呼吸衰竭
