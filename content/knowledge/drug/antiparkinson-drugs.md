**巴金森氏症**是中腦**黑質**的多巴胺神經元退化，紋狀體的**多巴胺不足、乙醯膽鹼相對過多**，出現靜止性顫抖、僵硬、動作遲緩與姿勢不穩。藥物治療的目標是**補充或模仿多巴胺、減少多巴胺分解，或降低乙醯膽鹼作用**，恢復兩者平衡；藥物只能改善症狀，不能阻止退化。神經傳遞物質的基礎見 [[neuron-synapse#neurotransmitters]]，疾病本身見 [[parkinson-disease]]

## 重點摘要 {#summary}

- **Levodopa** 可通過血腦障壁，在腦內轉成多巴胺；多巴胺本身不能通過血腦障壁，所以不能直接補充多巴胺
- **Carbidopa** 抑制**周邊的多巴脫羧酶**，自己**不進入腦部**，讓更多 levodopa 進腦、減少噁心與低血壓；兩者合併的複方是 **Sinemet**
- Levodopa 副作用：**噁心、厭食**、**姿勢性低血壓**、**心搏過速**與心律不整、**幻覺與精神症狀**；長期使用出現**異動症（舞蹈樣不自主運動）**與 **on-off 現象**
- 飲食：**高蛋白**餐會和 levodopa 競爭吸收與進腦的運輸；**維生素 B6** 會加速周邊轉化（單用 levodopa 時影響明顯）
- 其他藥：**多巴胺致效劑**（pramipexole、ropinirole）、**MAO-B 抑制劑**(selegiline)、**COMT 抑制劑**(entacapone)、**amantadine**、**抗膽鹼藥**(trihexyphenidyl)
- **抗精神病藥**阻斷多巴胺，會使巴金森症狀惡化，**不適用**；galantamine 是失智症用藥
- **漸凍人(ALS)**：**riluzole** 是第一個核准的藥，之後還有 edaravone

### 國考常考點 {#exam-points}

- Carbidopa 與 levodopa 併用，是因為 carbidopa 抑制**多巴脫羧酶**
- **最不容易進入腦中**的巴金森用藥：**carbidopa**（pramipexole、benztropine、amantadine 都可以進腦）
- Sinemet 中的 levodopa **可以**通過血腦障壁；**on-off 反應是 levodopa 的副作用**；Artane 是抗膽鹼藥，**不是補充多巴胺**
- **不要**補充維生素 B6、**不要**高蛋白飲食來增加藥效；長期使用可能出現**舞蹈症或不自主運動**與 **on-off 反應**
- Levodopa 的副作用有厭食、精神症狀、血壓降低；**心搏過慢不是**（會心搏過速）
- 多巴胺製劑造成的是**姿勢性低血壓**，不是高血壓
- 護理：**改變姿勢要緩慢**以免跌倒；鼓勵**大步走**，不是小碎步；酒精不能促進藥效；多喝水與高纖預防便秘；衣服用前開襟與魔鬼氈、寬鬆褲子
- 不適用於巴金森氏症：**抗精神病藥**、**galantamine** 等**乙醯膽鹼酯酶抑制劑**（增加乙醯膽鹼，治療的是失智）；抗蕈毒鹼藥、MAO-B 抑制劑、COMT 抑制劑、amantadine 都可以用
- Trihexyphenidyl(Artane)要**監測眼壓**；amantadine 的副作用有口乾、尿滯留、**周邊水腫**，血壓是**降低**不是升高
- 治療目標：重建 **dopamine 與 acetylcholine** 的平衡
- **Riluzole** 是治療肌萎縮性側索硬化症的藥（考題說「唯一」，現在已有其他藥）

## 作用位置 {#mechanism}

| 類別 | 代表藥 | 機轉 |
|---|---|---|
| 多巴胺前驅物 | **Levodopa** | 進入腦內被多巴脫羧酶轉成多巴胺 |
| 周邊多巴脫羧酶抑制劑 | **Carbidopa**、benserazide | 阻止 levodopa 在**周邊**轉成多巴胺；**不通過血腦障壁** |
| **多巴胺致效劑** | **Pramipexole**、**ropinirole**、rotigotine（貼片）、apomorphine（皮下注射）、bromocriptine | 直接活化腦內多巴胺受體 |
| **MAO-B 抑制劑** | **Selegiline**、rasagiline、safinamide | 減少腦內多巴胺分解 |
| **COMT 抑制劑** | **Entacapone**、opicapone | 減少 levodopa 在周邊分解，延長每次藥效 |
| NMDA 拮抗＋促多巴胺釋放 | **Amantadine** | 改善異動症；原本是抗 A 型流感病毒藥 |
| **抗膽鹼藥** | **Trihexyphenidyl**(Artane)、benztropine | 降低相對過多的乙醯膽鹼作用，主要改善**顫抖** |

- 多巴胺本身極性高，**不能通過血腦障壁**，所以補充的是 levodopa
- 單用 levodopa 時大部分在腸道與肝臟就轉成多巴胺，進腦的很少，周邊多巴胺又造成噁心、嘔吐、低血壓、心律不整；加上 carbidopa 可以**減少 levodopa 用量**與周邊副作用

- 乙醯膽鹼酯酶抑制劑會增加乙醯膽鹼，**不用來治療**巴金森氏症的動作症狀；巴金森病人合併失智時才會用 rivastigmine 改善認知（見 [[anti-dementia-drugs]]）

## Levodopa 與 carbidopa {#levodopa}

- **最有效**的症狀治療藥物，尤其改善動作遲緩與僵硬
- **短期副作用**
  1. **噁心、嘔吐、厭食**（與食物一起吃可減輕，但會延緩吸收）
  2. **姿勢性低血壓**、頭暈
  3. **心搏過速**、心律不整（周邊多巴胺作用在心臟 β1）
  4. **幻覺、意識混亂**、惡夢、精神症狀（老人較多）
  5. 尿液與汗液顏色變深
- **長期副作用**（使用約 5 年以上常見）
  1. **藥效減退(wearing-off)**：每次劑量的效果時間越來越短，下一劑前症狀就回來
  2. **On-off 現象**：藥效突然消失（僵住、不能動）又突然恢復，與服藥時間關係不明顯
  3. **異動症**：**舞蹈樣**、扭動的不自主運動，多在藥效高峰
- **飲食與交互作用**
  1. **蛋白質**中的胺基酸與 levodopa 競爭腸道吸收與進腦的運輸 → **避免高蛋白餐**，可在餐前約 30 分鐘服藥，或把蛋白質平均分到三餐、晚餐再多吃
  2. **維生素 B6(pyridoxine)**促進周邊多巴脫羧酶 → 單用 levodopa 時效果下降；併用 carbidopa 後影響很小，但國考答案仍是**不要補充 B6**
  3. **非選擇性 MAO 抑制劑**併用 → 高血壓危象（停 MAO 抑制劑至少兩週）
  4. **抗精神病藥**、metoclopramide 阻斷多巴胺，抵銷藥效；巴金森病人出現精神症狀時可用 quetiapine 或 clozapine（錐體外症狀少，見 [[antipsychotics#sga]]）
  5. **不可突然停藥**：可能出現類似抗精神病藥惡性症候群的高燒、僵硬、意識改變

## 其他巴金森用藥 {#other-agents}

| 藥物 | 用途 | 重點副作用 |
|---|---|---|
| **多巴胺致效劑**（pramipexole、ropinirole、rotigotine） | 早期單用（較年輕者）、合併 levodopa 減少 off 期；不寧腿症候群 | **突發嗜睡**（不要開車）、**衝動控制障礙**（病態賭博、購物、暴食、性慾亢進）、幻覺、姿勢性低血壓、下肢水腫 |
| Apomorphine | 皮下注射，**急救 off 期** | 嚴重噁心（需併用止吐藥）、低血壓 |
| **MAO-B 抑制劑**（selegiline、rasagiline） | 早期單用、合併 levodopa 延長藥效 | 失眠（selegiline 代謝物類似安非他命，**早上服用**）；與 meperidine、抗憂鬱劑併用可能血清素症候群 |
| **COMT 抑制劑**(entacapone) | 與 levodopa 同服，改善 wearing-off | 加重異動症、**尿液變橘紅色**、腹瀉；tolcapone 有肝毒性 |
| **Amantadine** | 改善**異動症**、早期輕症 | **網狀青斑**、**下肢水腫**、口乾、尿滯留、幻覺、意識混亂、**姿勢性低血壓**；腎功能差要減量 |
| **抗膽鹼藥**（trihexyphenidyl、benztropine） | 年輕、以**顫抖**為主的病人；抗精神病藥引起的錐體外症狀 | **口乾、便秘、尿滯留、視力模糊、眼壓升高（青光眼禁用、要監測眼壓）**、意識混亂與記憶變差；**老人避免**（見 [[cholinergic-drugs#antimuscarinics]]） |

## 用藥護理與生活指導 {#nursing}

1. **準時服藥**，記錄症狀與藥效時間（on、off、異動症），回診時給醫師調藥參考
2. **預防跌倒**
   1. 姿勢性低血壓：**起身、改變姿勢要慢**，先坐在床邊再站起來
   2. 走路時刻意**跨大步**、腳跟先著地、手臂擺動；轉彎時走大圈；「凍結」時可用口令或地上的線條幫助起步，**不要用小碎步**
   3. 移除地毯與雜物，浴室裝扶手
3. **便秘**：疾病本身與藥物（抗膽鹼藥）都會造成 → **多喝水、高纖飲食**、運動
4. **營養**：蛋白質照上面的方式分配；吞嚥困難時調整食物質地、坐直進食
5. 皮膚：洗澡後塗乳液，觀察有無壓傷；出汗多時保持乾爽
6. 衣著：**前開襟、魔鬼氈**、鬆緊帶褲子，方便自己穿脫
7. 避免**酒精**（加重低血壓、不會增加藥效）
8. 出現幻覺、衝動行為、嚴重異動症時告知醫師，**不可自行停藥**

## 其他神經退化疾病用藥 {#other-neurodegenerative}

| 疾病 | 藥物 | 重點 |
|---|---|---|
| **肌萎縮性側索硬化症**（ALS、漸凍人） | **Riluzole**（口服，抑制麩胺酸釋放） | 第一個核准、可延長存活的藥；副作用是疲倦、噁心、**肝指數上升**（要定期驗肝功能）、嗜中性白血球低下 |
| | Edaravone（靜脈注射，清除自由基） | 後來核准，延緩功能退步；台灣已可使用（來源：[臺北榮總藥訊 113 年 8 月](https://wd.vghtpe.gov.tw/pharm/files/3.3_new/113/藥訊-11308.pdf)） |
| **阿茲海默症** | Donepezil、rivastigmine、galantamine、memantine | 見 [[anti-dementia-drugs]] |
| **重症肌無力** | Pyridostigmine 等 | 見 [[cholinergic-drugs#myasthenia-gravis]] |

- 考題說 riluzole 是「目前唯一」可治療 ALS 的藥，是 edaravone 核准以前的說法
