**擬交感神經藥物**模仿正腎上腺素與腎上腺素，活化 **α、β 受體**（受體分布見 [[autonomic-nervous-system#receptor-types]]）。臨床上用來升血壓、強心、擴張支氣管、散瞳、解除鼻塞與安胎。休克時的強心升壓劑劑量與給藥見 [[inotropes]]，氣喘吸入劑見 [[asthma-drugs#beta2]]，中樞 α2 致效劑(clonidine)見 [[central-alpha2-agonists]]

## 重點摘要 {#summary}

- 受體作用：**α1** 血管收縮、散瞳、括約肌收縮；**α2** 抑制正腎上腺素釋放；**β1** 心跳快、收縮力強、腎素分泌；**β2** 支氣管擴張、骨骼肌血管擴張、子宮放鬆、肝醣分解；**β3** 脂肪分解
- **Epinephrine**(α＋β)：**過敏性休克與第一型過敏反應的首選**、心跳停止；局部麻醉劑併用可**收縮血管、延長作用時間**
- **Dopamine** 依劑量：低劑量 → 腎血流增加；中劑量 → β1 強心；**高劑量(> 10 mcg/kg/min)→ α 血管收縮**
- **Dobutamine** 主要活化 **β1** → 增加收縮力與心輸出量，用於急性心衰竭、心因性休克；**沒有 β2 選擇性**
- **Phenylephrine**(α1)：**散瞳**（眼底檢查）、**鼻充血解除**、升血壓
- **β2 致效劑**：terbutaline、salbutamol、fenoterol 治療**氣喘**；**ritodrine** 安胎；副作用是**心跳快、心悸、顫抖、低血鉀、高血糖**，ritodrine 要注意**胸痛、呼吸困難（肺水腫）**
- 持續給予致效劑會使受體**去敏感化**（數目減少），拮抗劑不會

### 國考常考點 {#exam-points}

- 促進脂肪分解：**β3**；皮膚與腹腔內臟血管收縮：**α 受體**
- 腎上腺素直接造成**唾液分泌減少**；不會使睫狀肌收縮、不會增加肝醣合成、不會降低收縮力
- 局部麻醉劑併用腎上腺素：使**局部血管收縮**、**延長作用時間**（減少吸收與全身毒性）
- 鼻黏膜小動脈收縮、解除鼻充血：**α1 致效劑**；散瞳做眼底檢查：**phenylephrine**
- 治療氣喘：**terbutaline**；**dobutamine 不具 β2 選擇性**（terbutaline、fenoterol、salbutamol 都有）
- 過敏性休克首選 **epinephrine**；epinephrine **不是蛋白質**、低劑量以 **β** 作用為主、會**增加**肝醣分解
- 過敏性休克：脈搏快、血壓正常或下降、過敏原來自藥物食物或昆蟲叮咬、立即注射 epinephrine；發生的是**支氣管收縮**而不是擴張
- Dopamine：**低劑量增加腎血流量**；**> 10 mcg/kg/min 末梢血管收縮**；可用於低血容量性休克（補足輸液後）；初期**不可**用高劑量、中劑量不是以收縮血管為主、高劑量不是用來強心
- 低血壓治療：α1 致效劑增加周邊阻力；**β1 拮抗劑會降低心跳**，不能治療低血壓
- 增加急性心衰竭心輸出量：**dobutamine**（活化 **β1**）
- Ritodrine(β2)：注意**胸痛、呼吸困難**；會**高血糖**（不是低血糖）、低血壓（不是高血壓）、母親與胎兒心跳增加；心搏過速是預期的副作用，**不是立即停藥**的理由
- **瘦肉精**是 β 致效劑，會引起類交感神經興奮（心悸、手抖）
- 活化中樞 α2、減少交感輸出：**clonidine**
- 重複給予 **propranolol（拮抗劑）不會**造成 β 受體去敏感化；terbutaline、norepinephrine、isoproterenol 會

## 受體選擇性與分類 {#classification}

| 藥物 | α1 | α2 | β1 | β2 | 主要用途 |
|---|---|---|---|---|---|
| **Epinephrine** | ++ | ++ | ++ | ++ | 過敏性休克、心跳停止、局部止血與延長局部麻醉 |
| **Norepinephrine** | +++ | ++ | ++ | 少 | **敗血性休克**首選升壓劑 |
| **Dopamine** | 高劑量 | | 中劑量 | | 休克、心搏過緩；低劑量作用在多巴胺受體 |
| **Dobutamine** | 少 | | +++ | 少 | 急性心衰竭、心因性休克 |
| Isoproterenol | | | +++ | +++ | 心搏過緩（少用）；會使血壓下降 |
| **Phenylephrine** | +++ | | | | 散瞳、鼻充血、升血壓 |
| Midodrine | +++ | | | | 姿勢性低血壓 |
| Oxymetazoline | +++ | | | | 鼻噴劑（連續使用超過 3 天會反彈性鼻塞） |
| **Clonidine** | | +++ | | | 降血壓（作用在中樞），見 [[central-alpha2-agonists]] |
| **Terbutaline**、**salbutamol**、fenoterol、metaproterenol | | | 少 | +++ | **氣喘**、COPD；terbutaline 也用於安胎 |
| **Ritodrine** | | | 少 | +++ | **安胎** |
| Ephedrine、pseudoephedrine | 間接＋直接 | | | | 鼻塞、低血壓（麻醉中） |

- **兒茶酚胺**（epinephrine、norepinephrine、dopamine、dobutamine、isoproterenol）：口服會被腸道與肝臟的 COMT、MAO 分解，要**靜脈、肌肉或皮下**給；作用短
- 生合成路徑：酪胺酸 → DOPA → **多巴胺** → **正腎上腺素** → **腎上腺素**（最後一步主要在**腎上腺髓質**）
- **間接作用**的擬交感藥（ephedrine、amphetamine）促使神經末梢釋放正腎上腺素，重複使用會很快失效（**快速耐藥性**）；amphetamine 類見 [[cns-stimulants]]

### 受體去敏感化 {#desensitization}

- **致效劑**持續或重複活化受體 → 受體磷酸化、被內化，數目**下調** → 反應越來越差（例如長期只用 β2 吸入劑效果變差、dobutamine 輸注 48–72 小時後耐受）
- **拮抗劑**(propranolol)不活化受體，**不會**造成去敏感化；長期使用反而使受體**上調**，驟停時反彈（見 [[beta-blockers]]）

## 腎上腺素 {#epinephrine}

- **作用**：α1 收縮血管、升血壓、減少水腫；β1 增加心跳與收縮力；β2 擴張支氣管、**抑制肥大細胞釋放介質**；代謝上**肝醣分解、血糖上升**、脂肪分解
- 劑量效應：**低劑量以 β 作用為主**（β2 使骨骼肌血管擴張，舒張壓可能下降），**高劑量以 α 作用為主**（血管收縮）
- **過敏性休克與第一型過敏反應**：第一線，**大腿前外側肌肉注射**，濃度 1 mg/mL（舊標示 1:1000），劑量 0.01 mg/kg、單次最多 0.5 mg，5 分鐘後可重複（詳細見 [[anaphylaxis#epinephrine]]）
- 心跳停止：靜脈或骨內注射 1 mg，每 3–5 分鐘（見 [[inotropes#epinephrine]]）
- **局部麻醉劑併用 epinephrine**
  1. 注射部位**血管收縮** → 麻醉藥被血流帶走得慢 → **作用時間延長**
  2. 進入全身的量減少 → **全身毒性降低**；手術出血也減少
  3. 不是為了增加吸收、促進血液循環或減少過敏
  4. 傳統上避免用在手指、腳趾、陰莖、耳朵等末端部位，怕組織缺血（依各院規範）
- 副作用：心悸、心律不整、顫抖、焦慮、頭痛、高血壓、高血糖

## 強心與升壓用的擬交感藥 {#pressors}

| Dopamine 劑量(mcg/kg/min) | 主要受體 | 效果 |
|---|---|---|
| 低劑量（約 < 3） | 多巴胺受體 | 腎與腸繫膜血管擴張 → **腎血流與尿量增加** |
| 中劑量（約 3–10） | **β1** | 心肌收縮力與心輸出量增加，部分 α 作用使周邊阻力增加 |
| 高劑量(> 10) | **α1** | **周邊血管收縮**、血壓上升；腎與肢端灌流下降 |

- 由**低劑量開始**、依血壓與尿量調整，不能一開始就用高劑量
- 低劑量雖然增加腎血流，但研究證實**沒有腎臟保護作用**，現在已不為此使用；休克時升壓劑首選是 norepinephrine（見 [[inotropes#dopamine]]）
- **Dobutamine**：主要作用 **β1** → **收縮力增加、心輸出量增加**，對血壓影響較小；用於**急性鬱血性心衰竭**、心因性休克的短期支持
- 治療低血壓的方向：**補充血量**、**α1 致效劑**增加周邊阻力、**β1 致效劑**增加心輸出量；**β1 拮抗劑**會使心跳與收縮力下降，用在低血壓是錯的
- 一定要用**輸液幫浦**、走大靜脈或中心靜脈；**外滲**會造成組織壞死，正腎上腺素與 dopamine 外滲時可局部注射 phentolamine（見 [[inotropes#extravasation]]）

::questions{ids="112-3_MS_019,106-1_MS_032,107-1_MS_026,111-1_BM_049,106-1_BM_050"}

## α1 致效劑 {#alpha1-agonists}

- **Phenylephrine**
  1. 點眼：瞳孔放大肌收縮 → **散瞳**，**不麻痺睫狀肌**（調節功能保留），用於**眼底檢查**；常與 tropicamide（抗膽鹼）併用
  2. 鼻噴或口服：鼻黏膜小動脈收縮 → **解除鼻充血**
  3. 靜脈：麻醉中低血壓；血壓上升時可能**反射性心跳變慢**
- **鼻充血解除劑**（phenylephrine、oxymetazoline、pseudoephedrine）：局部噴劑**連續使用不要超過 3 天**，否則會**反彈性鼻塞**（藥物性鼻炎）；高血壓、青光眼、攝護腺肥大、甲狀腺亢進者小心（見 [[asthma-drugs#decongestants]]）
- 中樞 **α2** 致效劑剛好相反，是**減少**交感輸出、降血壓（clonidine，見 [[central-alpha2-agonists]]）

::questions{ids="108-2_BM_061,109-2_BM_054,105-2_BM_057,114-3_BM_037,113-3_BM_031"}

## β2 致效劑 {#beta2-agonists}

- **氣喘與 COPD**：terbutaline、salbutamol(albuterol)、fenoterol 是短效(SABA)；salmeterol、formoterol 是長效(LABA)，用法見 [[asthma-drugs#beta2]]
- **副作用**：手抖（骨骼肌 β2）、**心悸與心跳快**（大劑量時 β1 也被活化，加上血管擴張引起反射）、**低血鉀**（K⁺ 進入細胞）、**高血糖**
- **Ritodrine(Yutopar)安胎**
  1. 活化子宮平滑肌 β2 → **子宮放鬆**，抑制早產宮縮
  2. 副作用：母親**心搏過速、心悸**、血管擴張造成**低血壓**、**高血糖**、低血鉀、噁心、頭痛、顫抖；胎兒**心跳增加**
  3. 最嚴重的是**肺水腫**與心肌缺血 → 監測**胸痛、呼吸困難**、肺部聽診、輸入輸出量
  4. 心跳快是預期的副作用，依醫囑設定的心跳上限（例如母親心跳超過約 120 次／分）通知醫師調整劑量，不是一出現心搏過速就停藥
  5. 安胎藥的選擇與比較（nifedipine、硫酸鎂、atosiban）見 [[labor-complications#preterm-labor]]
- **瘦肉精**（ractopamine、clenbuterol 等 β 致效劑）：加在飼料中使瘦肉增加；人吃到殘留量高的內臟或肉時，可能出現**類交感神經興奮**：心悸、心跳快、手抖、頭暈
