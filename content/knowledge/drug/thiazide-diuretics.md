## 重點摘要 {#summary}

- 抑制**遠曲小管**的 Na⁺-Cl⁻ 共同運輸 → 中等強度利尿;長期降壓主要靠**血管阻力下降**。
- **高血壓第一線藥物**之一(chlorthalidone、indapamide 證據最好);也用於輕度水腫、**鈣結石預防**、腎因性尿崩症。
- 電解質「三低一高」:**低血鉀、低血鈉、低血鎂、高血鈣**;代謝面「三高」:**高血糖、高尿酸(痛風)**、高血脂。
- eGFR < 30 時效果變差(chlorthalidone 例外仍有效);低血鉀會**加重毛地黃中毒**、會**升高鋰鹽濃度**。
- 早上服用、監測血鉀與血鈉、起身放慢、適量攝取高鉀食物(依醫囑)。

## 作用機轉 {#mechanism}

腎絲球過濾的鈉約 65% 在近曲小管、25% 在亨利氏環上升支、**5–10% 在遠曲小管**被回收。Thiazide 在遠曲小管管腔側阻斷 **Na⁺-Cl⁻ 共同運輸體(NCC)**,使這一段的鈉與水留在管腔內排出。

![利尿劑在腎元的作用部位](/knowledge-images/diuretic-sites-nephron.svg)

- **利尿強度中等**:能影響的鈉只有 5–10%,比[[loop-diuretics|亨利氏環利尿劑]]弱。
- **降壓機轉分兩期**:初期減少血容積、心輸出量;數週後血容積大致回復,但**周邊血管阻力持續下降**(血管平滑肌鈉/鈣含量下降),這是長期降壓的主因(血壓決定因素見 [[blood-pressure-regulation#determinants]])。
- **為什麼低血鉀**:更多 Na⁺ 流到下游集尿管,在醛固酮作用下「換」出 K⁺ 與 H⁺ → 低血鉀、代謝性鹼中毒;血容積下降又會活化 RAAS([[blood-pressure-regulation#raas]]),使排鉀更明顯。
- **為什麼高血鈣(與 loop 相反)**:遠曲小管 Na⁺ 回收被擋,細胞內 Na⁺ 下降,促進基底側 Na⁺/Ca²⁺ 交換 → **鈣再吸收增加、尿鈣減少**。因此可**預防含鈣腎結石**、對骨質有保護作用。
- **腎因性尿崩症的「矛盾」效果**:輕度脫水使近曲小管回收更多鈉與水 → 到達集尿管的水變少 → 尿量減少(常合併限鹽)。

## 代表藥物 {#agents}

| 藥物 | 類型 | 特色 |
|---|---|---|
| **Hydrochlorothiazide(HCTZ)** | Thiazide 型 | 最常見,常做成複方(與 ACEI/ARB);作用時間 6–12 小時 |
| Chlorothiazide | Thiazide 型 | 國考題常出現的名稱 |
| **Chlorthalidone** | Thiazide-like | 半衰期長(40–60 小時),降壓與心血管結果證據最多;CKD 第 4 期仍有降壓效果 |
| **Indapamide** | Thiazide-like | 兼具血管擴張作用,對血糖、血脂影響較小 |
| Metolazone | Thiazide-like | eGFR 低時仍有效;與 loop 併用做「**序列腎元阻斷**」,處理利尿劑阻抗 |

Thiazide 型與 thiazide-like 化學結構不同,但作用位置相同;新版高血壓指引偏好 **chlorthalidone 或 indapamide**。

## 適應症 {#indications}

- **原發性高血壓**:與 ACEI/ARB、CCB 並列第一線;**單方初始治療**的合理選擇,也是最常見的複方成分。與 ACEI/ARB 合用可互相抵銷鉀的變化。
- **輕至中度水腫**:心衰竭、肝硬化、腎病症候群;心衰竭主要仍以 loop 為主,thiazide 用於合併高血壓或與 loop 併用克服利尿劑阻抗(見 [[heart-failure]])。
- **高尿鈣、反覆含鈣腎結石**的預防;對骨質疏鬆有保護作用。
- **腎因性尿崩症**(含鋰鹽誘發者),配合限鹽。
- 腎功能:傳統上 **eGFR < 30 mL/min/1.73m²** 時效果差,需改用 loop;chlorthalidone 在 CKD 第 4 期仍有研究支持。

## 藥動重點 {#pharmacokinetics}

- 口服 1–2 小時起效;HCTZ 作用 6–12 小時,chlorthalidone 可達 48–72 小時。
- 需經腎小管**分泌到管腔**才能作用,所以腎功能差、送到管腔的藥少,效果就差。

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 機轉 / 說明與處置 |
|---|---|
| **低血鉀** | 最重要;肌肉無力、腹脹便秘、心律不整、心電圖 U 波;**併用毛地黃易中毒**。監測血鉀,飲食補鉀或依醫囑補鉀,或與 ACEI/ARB、保鉀劑合用 |
| **低血鈉** | 老人、女性、體重輕、大量喝水者風險高;意識混亂、跌倒。thiazide 引起的低血鈉比 loop **更常見**(不影響髓質濃度梯度,尿液仍可濃縮) |
| **低血鎂** | 加重低血鉀、心律不整 |
| **高血鈣** | 鈣排泄減少;可能揭露原本存在的副甲狀腺功能亢進 |
| **高尿酸、痛風** | 與尿酸在近曲小管競爭排泄;**痛風病人慎用** |
| **高血糖** | 低血鉀抑制胰島素分泌;糖尿病人監測血糖 |
| 高血脂 | 高劑量時 TG、LDL 輕度上升 |
| 代謝性鹼中毒 | 伴隨 H⁺ 流失 |
| 脫水、姿勢性低血壓、跌倒 | 老人小心 |
| **光敏感**、皮疹 | 含磺胺結構;HCTZ 長期使用與非黑色素皮膚癌風險上升有關,外出防曬 |
| 磺胺過敏 | 有交叉過敏的可能,須詢問過敏史(實際交叉率低) |

**禁忌/慎用**:無尿、對磺胺類嚴重過敏、痛風發作中、嚴重低血鉀或低血鈉未矯正。懷孕中不建議用來治療子癇前症的水腫。

## 交互作用 {#interactions}

| 併用藥物 | 結果 |
|---|---|
| **[[digoxin|毛地黃]]** | 低血鉀、低血鎂 → **毛地黃中毒**;不是「可以避免中毒」 |
| **鋰鹽** | 鈉流失使近曲小管同時回收更多鋰 → **血鋰上升、中毒**(ACEI、NSAID 也會) |
| Loop 利尿劑 | 加成利尿與低血鉀(序列阻斷,需密切監測電解質) |
| 類固醇、甘草、β₂ 促效劑、amphotericin B | 加重低血鉀 |
| NSAID | 抑制前列腺素 → 降壓與利尿效果變差、腎損傷風險 |
| 降血糖藥 | 血糖上升,可能需調整劑量 |
| 其他降壓藥、酒精 | 加重姿勢性低血壓 |
| 鈣片、維生素 D | 高血鈣 |

## 護理重點與衛教 {#nursing}

- **早上服用**;一天兩次時第二劑在下午(約 4 點前),避免夜尿影響睡眠、夜間跌倒。
- 監測**血壓(含姿勢性)、體重、輸出入量**;每天同一時間、同一磅秤、相似衣著量體重。
- 追蹤**血鉀、血鈉、血鎂、血糖、尿酸、腎功能**;教導低血鉀表現(無力、抽筋、心悸、腹脹)與低血鈉表現(頭痛、倦怠、意識混亂)。
- 除非同時服用 ACEI/ARB/保鉀劑,可**適量攝取高鉀食物**(香蕉、柳丁、奇異果、深綠色蔬菜);勿自行服用鉀補充劑。
- 起身「三部曲」、避免長時間站立與熱水澡,預防**跌倒**。
- 防曬;痛風或糖尿病病人追蹤尿酸與血糖。
- 老人不要為了「多排尿」而自行加量。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **高血壓第一線單方初始治療** → hydrochlorothiazide(干擾選項:atropine、amiodarone、dopamine)。
- **Thiazide 會「減少」尿鈣 → 可減少尿路結石與骨質疏鬆**;loop 反而**增加**鈣排泄(可治療高血鈣)。
- 「毛地黃與 thiazide 併用可避免毛地黃中毒」**錯**:thiazide 造成低血鉀,反而**增加**中毒風險。
- 「使用 thiazide 會造成高血鉀」**錯**:thiazide 是**排鉀型**;高血鉀的藥物原因是 ACEI、醛固酮拮抗劑。
- Thiazide、ACEI、NSAID 都會**使血中鋰鹽濃度上升**。
- 腎因性尿崩症可用 thiazide 加限鹽。
:::

:::warning[易混淆]
Thiazide:**低鉀、低鈉、低鎂、高鈣、高尿酸、高血糖**。Loop:**低鉀、低鈉、低鎂、低鈣**、高尿酸、耳毒性。兩者差別就在「鈣」與「耳毒性」。
:::
