## 重點摘要 {#summary}

- 結合 β 細胞 **SUR1**、關閉 K-ATP 通道 → **促進胰臟 β 細胞分泌胰島素**(需要還有功能的 β 細胞,第一型無效)。
- 分泌**不受血糖高低控制** → **低血糖風險是口服藥中最高**(Glyburide 最明顯);**體重增加**。
- 一般於**飯前約 30 分鐘**服用;老人、腎功能不佳者特別小心低血糖。
- 便宜、降 HbA1c 效果強,但長期效果會隨 β 細胞衰退而下降。

## 作用機轉 {#mechanism}

藥物結合 β 細胞 ATP 敏感性鉀通道(K-ATP)上的**磺醯脲受體 SUR1** → 通道關閉 → 細胞膜去極化 → 鈣離子流入 → 胰島素分泌。等於「繞過」了葡萄糖感測步驟(見 [[glucose-homeostasis#secretion-steps]] 的圖)。

因為作用點在 β 細胞,**第一型糖尿病或 β 細胞已衰竭者無效**。

## 代表藥物 {#agents}

| 世代 | 藥物 | 特色 |
|---|---|---|
| 第一代 | Chlorpropamide、Tolbutamide | 已少用;chlorpropamide 半衰期長、與酒精有戒酒劑樣反應 |
| 第二代 | **Glyburide(Glibenclamide)** | 作用強、低血糖風險最高,老人避免 |
| | **Glipizide** | 短效,早餐前服用 |
| | **Gliclazide** | 低血糖較少,有緩釋劑型 |
| | **Glimepiride** | 每日一次 |

## 適應症 {#indications}

第二型糖尿病,metformin 單用控制不佳時的合併用藥(特別是考量費用時)。

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 說明 |
|---|---|
| **低血糖** | 最重要;可持續很久(長效製劑、腎功能差時),可能需住院觀察;**過量服用 glipizide 等是造成低血糖的典型原因** |
| **體重增加** | 胰島素增加的合成作用 |
| 腸胃不適、皮疹、光敏感 | 少見 |
| 溶血 | G6PD 缺乏者 |

**禁忌**:第一型糖尿病、DKA、嚴重肝腎功能不全、對磺胺類過敏(可能交叉過敏)。懷孕時一般以胰島素為優先。

## 交互作用 {#interactions}

- **增強降血糖**:酒精、β 阻斷劑(另會遮蔽低血糖症狀)、NSAIDs、磺胺類抗生素、warfarin、azole 類抗黴菌藥(蛋白結合競爭或代謝抑制)。
- **減弱降血糖**:類固醇、thiazide、rifampin。
- 與[[insulin|胰島素]]併用時低血糖風險加成。

## 護理重點與衛教 {#nursing}

- 一般於**餐前約 30 分鐘**服用;服藥後**一定要進食**,不可跳餐。
- 教導辨識與處理[[diabetes#hypoglycemia|低血糖]],老人與腎功能不佳者尤其注意;隨身攜帶糖果。
- 避免飲酒。
- 監測體重、血糖、腎功能。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 機轉:**促進胰臟 β 細胞分泌胰島素**(不是促進升糖素、不是增加肝臟釋糖、不是減少受體)。
- 「單獨使用時最可能造成低血糖」→ **Glyburide**。
- 「會增加體重」的口服藥:SU、Meglitinide、TZD;**不會增加體重:Metformin**。
:::
