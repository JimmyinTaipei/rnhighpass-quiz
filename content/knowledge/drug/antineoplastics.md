## 重點摘要 {#summary}

- **傳統化學治療**攻擊**分裂快速**的細胞，所以癌細胞和正常的**骨髓、腸胃黏膜、毛囊、生殖細胞**一起受傷 → **骨髓抑制、口腔炎、噁心嘔吐、掉髮、不孕**。**神經細胞**幾乎不分裂，受影響最小。
- 骨髓抑制的**最低點(nadir)約在給藥後 7–14 天**，約 3–4 週恢復；這段時間最容易**感染與出血**。
- 各類藥的**招牌毒性**是必考：**doxorubicin 心臟毒性**、**cisplatin 腎毒性與耳毒性**、**cyclophosphamide 出血性膀胱炎**、**vincristine 神經毒性與便秘**、**bleomycin 肺纖維化**、**methotrexate 用 leucovorin 解救**。
- **標靶藥**攻擊特定分子：**imatinib**(BCR-ABL，CML)、**trastuzumab**(HER2，乳癌，監測**心臟功能**)、**EGFR 抑制劑**(肺癌，皮疹)。**免疫檢查點抑制劑**可能引起**全身各器官的免疫發炎**。
- 護理重點：**安全防護**(雙層化療手套、防水隔離衣、基因毒性廢棄物)、**防止與處理外滲**(起疱劑)、**按時預防性止吐**、監測血球與感染。

## 作用原理 {#mechanism}

### 細胞週期 {#cell-cycle}

| 時期 | 發生的事 | 作用在這期的藥 |
|---|---|---|
| **G0**(休止期) | 不分裂，**對化療最不敏感** | 幾乎沒有藥有效，所以癌細胞躲在 G0 就能逃過化療 |
| G1 | 合成 RNA、蛋白質，準備複製 | L-asparaginase |
| **S**(合成期) | **複製 DNA** | **抗代謝藥物**(methotrexate、5-FU、cytarabine)、etoposide、topotecan |
| G2 | 準備分裂 | **bleomycin**、etoposide |
| **M**(分裂期) | 有絲分裂，需要紡錘體(微管) | **長春花鹼**(vincristine)、**紫杉醇**(paclitaxel) |

- **週期專一性**(cell cycle-specific)：只作用在某一期，例如抗代謝藥、長春花鹼、紫杉醇、etoposide、bleomycin。適合**分次或持續給藥**。
- **非週期專一性**：任何時期(G0 除外)都有效，例如**烷基化劑、鉑金類、蒽環類**。效果和**劑量**成正比。
- **組合化療**：合併作用在不同時期、毒性不重疊的藥，以提高療效並減少抗藥性。

### 為什麼正常組織會受傷 {#normal-tissue}

| 分裂快的組織 | 結果 | 出現時間 |
|---|---|---|
| **骨髓** | 白血球、血小板、紅血球下降 | 最低點 **7–14 天** |
| **腸胃黏膜** | **口腔黏膜炎**、腹瀉 | 約 5–14 天 |
| **毛囊** | **掉髮** | 約 2–3 週開始，治療結束後會再長 |
| 生殖細胞 | 不孕、月經停止；**致畸胎** | — |
| **神經細胞**(永久細胞，不分裂) | 受影響最小；神經毒性是特定藥物(vincristine、oxaliplatin、紫杉醇)造成 | — |

### 治療目的與方式 {#intent}

| 名稱 | 意義 |
|---|---|
| **誘導性**(induction) | 以**高劑量、合併多種藥物**，求**快速緩解**(例：急性白血病) |
| 鞏固性、維持性 | 緩解後繼續治療，清除殘存癌細胞、防止復發 |
| **輔助性**(adjuvant) | **手術或放療後**加上化療，消滅看不見的微小轉移 |
| **前導性**(neoadjuvant) | **手術前**先化療，縮小腫瘤 |
| **救援性**(salvage) | 第一線治療失敗或復發後的治療 |
| **姑息性**(palliative) | 無法治癒時，以**緩解症狀、提升生活品質**為目標 |
| **同步化學放射治療**(CCRT) | 化療與放療同時進行，化療同時有增加放療敏感度的作用 |

- 能不能打化療要看**骨髓、肝、腎功能**與整體狀況；合併嚴重感染、肝腎功能不良時通常要先處理。

### 給藥途徑 {#routes}

- **靜脈**：最常見。周邊靜脈選**粗、有彈性**的血管；**起疱劑**或長期治療建議用**中心靜脈導管**或人工血管(**Port-A**)。
- **鞘內注射**、**Ommaya 儲存槽**(植入頭皮下、通往腦室)：藥物**難以通過血腦障壁**時，用來治療或預防**中樞神經系統**的癌症(例：白血病的中樞神經預防)。
- **膀胱灌注**：膀胱癌用 **BCG**、mitomycin、**thiotepa**，藥物直接接觸膀胱黏膜。
- 腹腔內、動脈內(例：肝癌的經動脈化學栓塞)、口服、皮下、肌肉注射。

:::note[Port-A 人工血管]
- 通常**局部麻醉**即可植入；導管可經**鎖骨下靜脈**或**腋靜脈**等進入上腔靜脈。
- 必須用**無芯針**(Huber needle)**垂直**穿刺注射座，不能用一般空針(會破壞矽膠膜)。
- 給藥前，尤其是**起疱劑**，一定要先**確認有回血**。
:::

## 分類與代表藥物 {#classes}

| 類別 | 代表藥 | 機轉 | 招牌毒性與保護劑 |
|---|---|---|---|
| **烷基化劑** | **Cyclophosphamide**、ifosfamide、**carmustine**、busulfan、dacarbazine、temozolomide、thiotepa | 在 DNA 上加烷基，使雙股交叉鍵結 | **出血性膀胱炎**(→ **mesna**)、不孕、續發性白血病 |
| **鉑金類** | **Cisplatin**、carboplatin、**oxaliplatin** | 與 DNA 交叉鍵結(作用類似烷基化劑) | cisplatin：**腎毒性、耳毒性、嚴重嘔吐、低血鎂**；oxaliplatin：**遇冷加重的周邊神經病變** |
| **抗代謝藥物** | **Methotrexate**、**5-FU**、capecitabine、cytarabine、gemcitabine、6-MP | 假冒 DNA 原料或阻斷葉酸代謝，干擾 **S 期** | MTX：黏膜炎、肝腎毒性(→ **leucovorin**)；5-FU：黏膜炎、腹瀉、**手足症候群** |
| **抗腫瘤抗生素** | **Doxorubicin**(小紅莓)、epirubicin、**bleomycin**、mitomycin、dactinomycin | 嵌入 DNA、抑制**拓樸異構酶 II**、產生自由基 | doxorubicin：**心臟毒性**(→ dexrazoxane)、**紅色尿**、起疱劑；bleomycin：**肺纖維化** |
| **微管抑制劑** | 長春花鹼：**vincristine**、vinblastine、vinorelbine；紫杉醇：**paclitaxel**、docetaxel | 干擾紡錘體，使細胞停在 **M 期** | vincristine：**神經毒性、便秘**、骨髓抑制輕；**只能靜脈注射**；paclitaxel：**過敏反應**、神經病變 |
| **拓樸異構酶抑制劑** | 第 I 型：**irinotecan**、topotecan；第 II 型：**etoposide** | 使 DNA 斷裂無法接回 | irinotecan：**腹瀉**；etoposide：快速輸注造成低血壓 |
| **荷爾蒙類** | **Tamoxifen**、**芳香環酶抑制劑**(letrozole、anastrozole)、GnRH 促效劑(leuprolide)、抗雄性素 | 阻斷荷爾蒙對腫瘤的刺激 | tamoxifen：更年期症狀、血栓、子宮內膜癌；AI：骨質疏鬆、關節痛 |
| **標靶藥**(小分子，**-tinib**) | **Imatinib**、**gefitinib**、erlotinib、osimertinib、**sorafenib** | 抑制酪胺酸激酶等訊號 | 水腫、**皮疹**、腹瀉、**手足皮膚反應** |
| **單株抗體**(**-mab**) | **Trastuzumab**、**rituximab**、**bevacizumab**、cetuximab、panitumumab | 結合腫瘤表面標記或生長因子 | **輸注反應**；trastuzumab **心臟毒性**；bevacizumab **高血壓、出血、傷口癒合差** |
| **免疫檢查點抑制劑** | Pembrolizumab、nivolumab(PD-1)、atezolizumab(PD-L1)、ipilimumab(CTLA-4) | 解除 T 細胞的煞車 | **免疫相關不良反應**(腸炎、肺炎、肝炎、甲狀腺炎等) |

### 烷基化劑與鉑金類 {#alkylating}

- **Cyclophosphamide**(Cytoxan、Endoxan)：
  - 代謝物 **acrolein** 刺激膀胱 → **出血性膀胱炎**。預防：**大量喝水**(或靜脈輸液)、**常排尿**、早上給藥(避免整夜蓄尿)，高劑量時併用 **mesna**。Ifosfamide 一定要併用 mesna。
  - 其他：骨髓抑制、掉髮、噁心嘔吐、**不孕**、SIADH；用於乳癌、淋巴瘤，也用於紅斑性狼瘡腎炎。
- **Carmustine**(BCNU)、lomustine：脂溶性高、能**通過血腦障壁** → 用於**腦瘤**；temozolomide(口服)用於惡性膠質瘤。
- Busulfan：肺纖維化、色素沉著；用於骨髓移植前處置。
- **Cisplatin**：
  - **腎毒性**：給藥前後**大量輸液水化**、利尿，監測**腎功能、尿量**。
  - 腎小管流失**鎂、鉀** → **低血鎂**、低血鉀，要監測並**補充鎂**。
  - **耳毒性**：**耳鳴、高頻聽力喪失**(是藥物造成，不是放療)。
  - **高致吐性**：急性與延遲性嘔吐都很嚴重。周邊神經病變。
- **Carboplatin**：腎毒性與嘔吐較輕，但**骨髓抑制(尤其血小板)**較明顯。
- **Oxaliplatin**：大腸直腸癌常用；**急性神經毒性遇冷誘發**(手腳、口周麻刺、喉嚨緊縮感)→ 治療後幾天**避免喝冰飲、碰冷水**；也有肝毒性。

### 抗代謝藥物 {#antimetabolites}

- **Methotrexate**(MTX)：抑制**二氫葉酸還原酶**(DHFR)，阻斷葉酸活化。
  - 高劑量後要用 **leucovorin**(活化型葉酸，folinic acid)**解救正常細胞**；同時**鹼化尿液**、大量輸液、監測血中 MTX 濃度。
  - 毒性：口腔黏膜炎、骨髓抑制、**肝毒性**、腎毒性、肺炎。
  - 避免併用 **NSAIDs**、penicillin、trimethoprim-sulfamethoxazole(減少排除或加重毒性)。
  - 低劑量每週一次用於**類風濕性關節炎**、乾癬。
  - 可鞘內注射。
- **5-FU**(fluorouracil)、口服前驅藥 capecitabine：抑制胸腺嘧啶合成酶；**口腔黏膜炎、腹瀉**、**手足症候群**(手掌腳掌紅腫脫皮)。**Leucovorin 會增強 5-FU 的作用**(和 MTX 相反，是加強療效)。
- **Cytarabine**(Ara-C)：急性骨髓性白血病；高劑量會造成**結膜炎**(預防性類固醇眼藥水)與小腦毒性。
- **6-MP**(mercaptopurine)：急性淋巴性白血病的維持治療；與 **allopurinol** 併用時必須**減量**。
- Gemcitabine：胰臟癌、肺癌；骨髓抑制、類流感症狀。
- 錯誤選項：「cisplatin 與 DHFR 結合」— 與 DHFR 結合的是 **methotrexate**。

### 抗腫瘤抗生素 {#antitumor-antibiotics}

- **Doxorubicin**(Adriamycin，小紅莓)：
  - 機轉：**嵌入 DNA**、抑制**拓樸異構酶 II**(不是第 I 型)、產生自由基。
  - **心臟毒性**：**累積劑量**相關的心肌病變與心衰竭；治療前與期間要做**心臟超音波或 MUGA 測左心室射出分率**，並記錄累積劑量。**Dexrazoxane** 可保護心臟。
  - **起疱劑**；尿液呈**紅色** 1–2 天(要事先告知病人，不是血尿)；掉髮明顯；放射回憶反應。
  - **微脂體小紅莓**(Lipo-Dox)：心臟毒性與起疱性較低，但**手足症候群**較多；是卵巢癌**復發後**的常用藥，不是初診斷首選(初診斷通常用 carboplatin 加 paclitaxel)。
- **Bleomycin**：**肺纖維化**(與累積劑量、高齡、吸氧相關，要監測肺功能)、發燒寒顫、皮膚色素沉著；**幾乎不抑制骨髓**；作用在 G2 期。
- **Mitomycin**：起疱劑；膀胱灌注。**Dactinomycin**：威爾姆氏腫瘤等兒童癌症；起疱劑。

### 微管抑制劑 {#microtubule}

| | 長春花鹼(**vincristine**、vinblastine、vinorelbine) | 紫杉醇(**paclitaxel**、docetaxel) |
|---|---|---|
| 機轉 | **抑制微管聚合**，紡錘體無法形成 | **穩定微管、阻止解聚**，紡錘體無法拆解 |
| 作用期 | **M 期** | **M 期** |
| 主要毒性 | **vincristine**：**神經毒性**(手腳麻木、深部肌腱反射消失、下顎痛)、**便秘、麻痺性腸阻塞**；**骨髓抑制輕**。vinblastine、vinorelbine：骨髓抑制較明顯 | **過敏反應**(溶劑引起)、周邊神經病變、骨髓抑制、掉髮、肌肉關節痛；docetaxel：水腫 |
| 護理 | **給軟便劑**、多喝水、多吃纖維；觀察神經症狀；**起疱劑** | 給藥前依醫囑用**類固醇、抗組織胺、H2 阻斷劑**預防過敏，給藥初期密切觀察 |

:::warning[Vincristine 只能靜脈注射]
Vincristine 等長春花鹼若誤打進**脊髓腔**(鞘內)會造成致命的神經損傷。藥品要標示「**只能靜脈注射，其他途徑可能致命**」，並建議以小袋點滴稀釋給藥，不和鞘內注射的藥放在一起送。
:::

### 拓樸異構酶抑制劑 {#topoisomerase}

- 第 I 型：**irinotecan**(大腸直腸癌)、topotecan。Irinotecan 的**早發性腹瀉**(給藥中或 24 小時內，伴隨流汗、流口水、腹痛等膽鹼症狀)用 atropine；**延遲性腹瀉**(24 小時後)用 loperamide 並補充水分，可能致命。
- 第 II 型：**etoposide**(VP-16，**週期專一性**，作用在 S 與 G2 期)；快速輸注會造成**低血壓**。蒽環類也抑制第 II 型。

### 荷爾蒙治療 {#hormonal}

腫瘤細胞帶有**荷爾蒙受體**時才有效；乳癌的**動情素受體(ER)與黃體素受體(PR)越多，反應越好**。

| 藥物 | 機轉 | 對象 | 副作用與護理 |
|---|---|---|---|
| **Tamoxifen**(Nolvadex) | **選擇性動情素受體調節劑**：在乳房**阻斷**雌激素，在子宮與骨頭有類似雌激素作用 | ER 陽性乳癌，**停經前後都可用** | **更年期症狀**(熱潮紅)、**噁心嘔吐**、**周邊水腫**、陰道分泌物；**靜脈血栓**、**子宮內膜癌**(異常陰道出血要就醫)、白內障；骨轉移病人初期可能**腫瘤暫時惡化與高血鈣** |
| **芳香環酶抑制劑**：letrozole(Femara)、anastrozole、exemestane | 抑制周邊組織把雄性素轉成雌激素 | **只用於停經後**婦女(停經前卵巢仍大量製造雌激素) | **骨質疏鬆**(監測骨密度、補鈣與維生素 D)、**關節痛** |
| GnRH 促效劑：leuprolide、goserelin | 長期使用使腦下垂體「疲乏」，性荷爾蒙下降 | 攝護腺癌、停經前乳癌 | 初期**腫瘤暫時惡化**(flare)、熱潮紅、性功能下降、骨質流失 |
| 抗雄性素：bicalutamide、enzalutamide、abiraterone | 阻斷雄性素受體或合成 | 攝護腺癌 | 男性女乳、熱潮紅、肝功能異常 |
| 類固醇(prednisolone、dexamethasone) | 使淋巴球凋亡 | 白血病、淋巴瘤、多發性骨髓瘤；也用於止吐與預防過敏 | 高血糖、感染、情緒改變 |

### 標靶治療 {#targeted}

標靶藥針對癌細胞特有的分子(見 [[neoplasia#key-genes]])，骨髓抑制通常比傳統化療輕，但有**各自獨特的副作用**。

| 藥物 | 標靶 | 主要用途 | 重點副作用與護理 |
|---|---|---|---|
| **Imatinib**(Glivec) | **BCR-ABL**、**KIT** 酪胺酸激酶 | **慢性骨髓性白血病**、**胃腸道基質瘤** | 水腫(眼周)、肌肉抽筋、噁心；**隨餐**配水服用 |
| **Gefitinib**(Iressa)、erlotinib、afatinib、**osimertinib** | **EGFR** 酪胺酸激酶 | **EGFR 突變的非小細胞肺癌**(台灣不吸菸女性的肺腺癌常見) | **痤瘡樣皮疹**、甲溝炎、腹瀉；間質性肺病 |
| **Sorafenib**(Nexavar)、lenvatinib | 多重激酶(含 VEGFR) | 肝細胞癌、腎臟癌、甲狀腺癌 | **手足皮膚反應**、高血壓、腹瀉 |
| **Trastuzumab**(Herceptin) | **HER2** | **HER2 陽性乳癌**、胃癌 | **靜脈滴注**；**心臟毒性**(左心室功能下降，**定期心臟超音波**)；首次輸注反應 |
| **Rituximab**(Mabthera) | **CD20**(B 細胞) | B 細胞淋巴瘤、慢性淋巴性白血病 | **輸注反應**(首次最常見，要慢速並預防用藥)；**B 型肝炎再活化**(用藥前驗 HBsAg，帶原者預防性抗病毒藥) |
| **Bevacizumab**(Avastin) | **VEGF**(血管新生) | 大腸直腸癌、肺癌、卵巢癌等 | **高血壓**、**蛋白尿**、出血、**傷口癒合不良**與腸穿孔(手術前後要停藥) |
| Cetuximab、**panitumumab** | **EGFR**(單株抗體) | **RAS 野生型**大腸直腸癌、頭頸癌 | **痤瘡樣皮疹**、低血鎂、輸注反應 |

:::tip[手足皮膚反應與手足症候群的照顧]
Sorafenib、capecitabine、5-FU、微脂體小紅莓常造成手掌腳掌紅、腫、痛、脫皮、龜裂。
- 洗手洗腳**不要用力搓**、用溫水，避免熱水與長時間浸泡。
- 穿**寬鬆柔軟**的鞋襪，減少摩擦與壓力，避免長時間走路或提重物。
- 塗**含尿素的保濕乳液**；起水泡或疼痛影響生活時通知醫師(可能要減量或暫停)。
:::

### 免疫治療 {#immunotherapy}

- **免疫檢查點抑制劑**：阻斷 **PD-1**、**PD-L1** 或 **CTLA-4**，讓 T 細胞重新攻擊癌細胞(機轉見 [[neoplasia#tumor-immunity]])。
- **免疫相關不良反應**：T 細胞也可能攻擊正常器官，可能在治療**數週到數月後**出現，甚至**停藥後**才發生：
  - 皮膚：皮疹、搔癢(最早、最常見)
  - **腸炎**：腹瀉、腹痛、血便
  - **肝炎**：肝指數上升
  - **肺炎**：新的咳嗽、喘
  - **內分泌**：**甲狀腺功能低下或亢進**、腦下垂體炎、腎上腺功能不足、第 1 型糖尿病(這些常需要**終身荷爾蒙補充**)
  - 少見但致命：心肌炎
- 處理：依嚴重度暫停藥物，並使用**類固醇**等免疫抑制劑(來源：[UpToDate：immune checkpoint inhibitor toxicities](https://www.uptodate.com/contents/overview-of-toxicities-associated-with-immune-checkpoint-inhibitors))。
- 護理：教病人**新出現的腹瀉、咳嗽喘、極度疲倦、頭痛視力改變**都要回報，不要自行吃止瀉藥了事；就醫時告知正在用免疫治療。
- **干擾素**(interferon-α)：常見**類流感症狀**(發燒、寒顫、頭痛、肌肉痛、疲倦)，可睡前注射並依醫囑先給 acetaminophen；也可能造成憂鬱。
- **BCG 膀胱灌注**：膀胱原位癌；灌注後可能有膀胱刺激症狀、血尿、發燒。

### 其他抗癌藥 {#other-agents}

- **L-asparaginase**：分解白血病細胞需要的天門冬醯胺；過敏反應、**胰臟炎**、高血糖、凝血異常。用於急性淋巴性白血病。
- **全反式維生素 A 酸**(ATRA)、三氧化二砷：急性前骨髓細胞性白血病；分化症候群、QT 延長。
- Bortezomib(蛋白酶體抑制劑)、thalidomide、lenalidomide：多發性骨髓瘤；神經病變、**致畸胎**、血栓。
- Hydroxyurea：慢性骨髓增生疾病。
- **放射性碘(I-131)**：甲狀腺癌術後，病人需依規定**輻射隔離**。

## 常見副作用總覽 {#adverse-effects}

| 出現時間 | 副作用 |
|---|---|
| 給藥當下到 24 小時內 | **噁心嘔吐**、**過敏或輸注反應**、**外滲**、發燒、**腫瘤溶解症候群**、irinotecan 早發性腹瀉、出血性膀胱炎(cyclophosphamide) |
| 數天到數週 | **骨髓抑制**(最低點 7–14 天)、**口腔黏膜炎**、腹瀉、**掉髮**(2–3 週)、疲倦、延遲性嘔吐、便秘(vincristine) |
| 數月到數年 | **心臟毒性**(蒽環類、trastuzumab)、**肺纖維化**(bleomycin)、神經病變、**不孕**、**續發性癌症**、認知改變 |

- 各副作用的護理(感染與出血預防、口腔黏膜炎、掉髮、營養)與腫瘤急症見 [[cancer-treatment-toxicities]]。
- 「化療最常見的副作用」：**骨髓抑制(白血球、紅血球、血小板下降)、口腔黏膜破損、掉髮、噁心嘔吐**；白血球會**減少**，不會增加。
- 「給藥後**立即**出現」：噁心嘔吐、過敏反應等；**骨髓抑制要一到兩週後**才出現。

:::exam[國考重點]
- 急性淋巴性白血病童化療後約 **7–14 天**血球最低；白血球低下時要保護病人，但**一般不需要負壓隔離病房**(負壓是用來隔離空氣傳染的病人)，可用正壓或單人房、落實手部衛生。
- **B 型肝炎帶原者**化療前要**預防性使用抗病毒藥**，避免肝炎再活化；不要吃來路不明的偏方。
:::

## 止吐藥與噁心嘔吐的預防 {#antiemetics}

### 化療引起的噁心嘔吐 {#cinv}

| 類型 | 時間 | 處理重點 |
|---|---|---|
| **急性** | 給藥後 **24 小時內** | 給藥前**預防性**止吐藥 |
| **延遲性** | **24 小時後**，可持續數天(cisplatin 最典型) | 依處方續用 dexamethasone、NK1 拮抗劑、olanzapine |
| **預期性** | **給藥前**就吐(過去經驗形成的**條件反射**) | 最好的預防是**第一次就控制好嘔吐**；發生後用**行為治療**(放鬆、分散注意力)與 **benzodiazepine**(lorazepam) |
| 突破性 | 已預防仍嘔吐 | 加上不同機轉的藥 |

- **致吐風險**：**高**：cisplatin、高劑量 cyclophosphamide、**蒽環類加 cyclophosphamide**(AC 療法)；中：carboplatin、oxaliplatin、irinotecan；低：紫杉醇、5-FU、gemcitabine；極低：vincristine、bleomycin、rituximab。

### 止吐藥 {#antiemetic-drugs}

| 藥物 | 機轉 | 重點 |
|---|---|---|
| **Ondansetron**、granisetron | **5-HT3 受體拮抗劑** | 急性嘔吐主力；**便秘**、頭痛；ondansetron 有 **QT 延長**風險 |
| **Palonosetron** | 第二代 5-HT3 拮抗劑 | 半衰期約 **40 小時**、對延遲性嘔吐也有效；**沒有 QT 延長**的報告 → **心臟病人**較適合 |
| **Aprepitant**(口服，第 1–3 天)、fosaprepitant(靜脈) | **NK1 受體拮抗劑** | 高致吐化療必用；有藥物交互作用 |
| **Dexamethasone** | 類固醇 | 與上述併用加強效果；高血糖、失眠 |
| **Olanzapine** | 抗精神病藥 | 高致吐化療的第四種藥；**嗜睡** |
| Metoclopramide、prochlorperazine | 多巴胺拮抗劑 | 低致吐或突破性嘔吐；**錐體外症候群** |
| Lorazepam | Benzodiazepine | **預期性嘔吐**、焦慮 |

- **高致吐**化療：NK1 拮抗劑 + 5-HT3 拮抗劑 + dexamethasone + **olanzapine** 四合一；**中致吐**：5-HT3 拮抗劑 + dexamethasone(carboplatin 劑量高時加 NK1 拮抗劑)(來源：[UpToDate：CINV](https://www.uptodate.com/contents/prevention-of-chemotherapy-induced-nausea-and-vomiting-in-adults)；MASCC／ESMO 2023 與 ASCO 止吐指引的共同建議)。
- 護理：止吐藥在化療**前 30–60 分鐘**依醫囑**按時給**，不要等吐了才給；少量多餐、清淡、**避免油膩與濃烈氣味**，冷食氣味較淡；吐後漱口；記錄嘔吐量與電解質。

## 安全防護(危害性藥品) {#safe-handling}

抗癌藥多數具有**致癌、致畸胎、生殖毒性**，醫護人員長期低劑量暴露也有風險。**皮膚接觸**是最常見、最重要的暴露途徑，其次是吸入、誤食與針扎(來源：[台灣腫瘤護理學會 2020 指引](https://doi.org/10.6880/TJON.202012/SP_20.01))。

### 調配 {#preparation}

- 由藥劑部在**負壓調配室**的**生物安全櫃**(第二級)中調配；盡量使用**密閉式藥品配置與給藥系統**(CSTD)。
- 從藥瓶抽藥時保持瓶內**負壓**，避免藥液**噴濺**；不可在櫃外排出針筒內的空氣。

### 個人防護裝備 {#ppe}

| 裝備 | 要求 |
|---|---|
| **手套** | **經化療藥物滲透測試**的手套，**戴雙層**；外層手套**套住隔離衣袖口**；污染或破損立即更換，長時間操作定期更換 |
| **隔離衣** | **拋棄式、低滲透、防水**，**背後開口**、長袖、袖口有彈性；不可穿出操作區 |
| 眼與臉 | 有噴濺風險時戴**護目鏡或全臉面罩** |
| 口罩 | 外科口罩**不能**防護吸入；潑灑、粉塵時戴 **N95** |

- 口服抗癌藥：完整錠劑戴單層手套取藥，**不在病房磨粉、剝半或打開膠囊**(必須破壞劑型時在生物安全櫃內進行)。

### 給藥 {#administration}

- 兩位護理師**雙重核對**：病人、藥名、**劑量(依體表面積計算)**、途徑、速率、檢驗值(血球、肝腎功能)。
- 給藥前、中**確認有回血**；接頭用**螺旋鎖**(luer-lock)，下方墊**防水吸收墊**。
- 病人接受化療後 **48 小時內**，其**尿液、糞便、嘔吐物、汗液**都含藥物：處理排泄物與被服要**戴手套、穿隔離衣**；居家建議**蓋上馬桶蓋再沖水**，被污染的衣物單獨清洗。

### 廢棄物與潑灑 {#waste-spill}

- 用過的空針、管路、藥瓶、手套、隔離衣都丟入**密閉的「基因毒性廢棄物」專用容器**，**不是**一般感染性垃圾桶。
- **潑灑**時：
  1. 隔離區域、疏散人員、放警示；
  2. 皮膚或衣服被污染 → **立即脫去衣物，用肥皂和清水沖洗皮膚**；濺入眼睛 → 大量清水或生理食鹽水沖洗；
  3. 處理人員穿隔離衣、雙層手套、**N95**、護目鏡，使用**潑灑處理包**，以吸水墊吸附；
  4. 用清潔劑清洗兩次，所有物品丟入基因毒性廢棄物；
  5. 通報並記錄暴露經過。
- **懷孕、哺乳或計畫懷孕**的工作人員，可申請**替代性職務**，避免調配與給藥。

## 外滲 {#extravasation}

### 起疱劑與刺激劑 {#vesicants}

- **起疱劑**(vesicant)：外滲會造成**水泡、組織壞死、潰瘍**。代表：**蒽環類**(doxorubicin、epirubicin、idarubicin、daunorubicin)、**長春花鹼**(**vincristine**、vinblastine、vinorelbine)、**mitomycin**、**dactinomycin**、mechlorethamine、trabectedin(來源：[UpToDate 外滲](https://www.uptodate.com/contents/extravasation-injury-from-cytotoxic-and-other-noncytotoxic-vesicants-in-adults))。
- **刺激劑**(irritant)：造成疼痛、發炎，大量或高濃度時也可能壞死。代表：**紫杉醇類**(台中榮總歸在起疱性)、鉑金類、etoposide、5-FU、cyclophosphamide 等。

### 預防 {#extravasation-prevention}

- 起疱劑或長時間輸注**優先用中心靜脈導管或 Port-A**。
- 周邊靜脈：選**前臂粗直、有彈性**的血管，**避開手背、手腕、肘窩等關節**處與下肢，避免在 24 小時內打過針的部位遠端注射；不用蝴蝶針。
- 給藥前與過程中**反覆確認回血**；請病人**有灼熱、刺痛、腫脹立刻說**。
- 多種藥依序給時，傳統教材寫「**起疱劑先給**」(血管最完整時)，目前沒有一致證據，依院內規範。

### 徵象 {#extravasation-signs}

注射部位**疼痛、灼熱、刺痛**、紅腫、**點滴速度變慢**、**沒有回血**；之後出現水泡、硬結、壞死。

:::note[外滲與局部過敏反應]
Doxorubicin 可能造成沿著靜脈的**紅色條紋與搔癢**，但**沒有疼痛、腫脹**、回血正常，這是局部過敏反應(flare)，約 30 分鐘內消退；有疼痛或腫脹就要當外滲處理。
:::

### 處理步驟 {#extravasation-management}

1. **立即停止注射**(不要沖管、不要壓迫)。
2. **保留針頭**，從**原針頭反抽**殘留藥液。
3. 依醫囑經原針頭或在**外滲部位周圍皮下注射解毒劑**，之後移除針頭。
4. 依藥物**冷敷或熱敷**，**抬高患肢** 48 小時。
5. **標示範圍、拍照**、記錄(藥名、估計外滲量、處置)，通知醫師。
6. **每天追蹤**外滲部位變化；持續疼痛或壞死時會診整形外科。

| 藥物 | 冷熱敷 | 解毒劑 |
|---|---|---|
| **蒽環類**(doxorubicin 等) | **冷敷**(**不可熱敷**) | **Dexrazoxane**(靜脈，6 小時內開始)；外用 DMSO 為替代 |
| Mitomycin、dactinomycin | **冷敷** | Mitomycin 可用 DMSO |
| **長春花鹼**(**vincristine**、vinblastine、vinorelbine) | **溫熱敷**(**不可冷敷**，冷敷會加重潰瘍) | **Hyaluronidase** 局部注射 |
| **紫杉醇**(paclitaxel、docetaxel) | **溫熱敷**(ONS／ASCO、ESMO 與台中榮總的做法；早期曾建議冷敷) | Hyaluronidase |
| Etoposide | **溫熱敷** | Hyaluronidase |
| **Cisplatin**、高濃度 dacarbazine、mechlorethamine | 冷敷 | **硫代硫酸鈉**(sodium thiosulfate)局部注射 |
| Oxaliplatin | 各指引不一致，依院內規範 | 大量外滲時口服高劑量類固醇 |
| 多數其他刺激劑(5-FU、cyclophosphamide 等) | 冷敷 | — |

- 規則：會與 **DNA 結合**的(蒽環類、烷基化劑)→ **冷敷**，使血管收縮、藥物局限；**不與 DNA 結合**的(長春花鹼、紫杉醇、etoposide)→ **熱敷**，使藥物擴散吸收，並配合 hyaluronidase。
- 冷熱敷每次約 **15–20 分鐘**，每 **4–6 小時**一次，持續 **1–2 天**(依藥物與院內規範)。
- 長春花鹼與 etoposide 外滲**不可用類固醇**，可能加重皮膚損傷。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 化療利用**分裂快速**的特性；**G0 期**細胞不易被殺；**神經細胞**受影響最小。
- 最低點 **7–14 天**；最常見副作用：**骨髓抑制、口腔炎、掉髮、噁心嘔吐**。
- **誘導性** = 高劑量、多藥合併；**輔助性** = 合併手術或放療；**姑息性** = 緩解症狀。
- 中樞神經腫瘤：**鞘內注射**、**Ommaya 儲存槽**；膀胱癌灌注：**thiotepa**、BCG、mitomycin。
- 招牌毒性：**doxorubicin 心毒性**(拓樸異構酶 II)、**cisplatin 腎毒性、耳毒性、低血鎂**、**cyclophosphamide 出血性膀胱炎**、**vincristine 神經毒性與便秘(給軟便劑)、骨髓抑制輕、M 期**、**oxaliplatin 周邊神經毒性與肝毒性**、**carmustine 用於腦瘤**、**paclitaxel 結合微管蛋白**(不是烷基化劑)、**methotrexate 不是烷基化劑**、**leucovorin 解 methotrexate**、**amifostine 保護正常細胞**、**irinotecan 是拓樸異構酶 I 抑制劑**、**etoposide 是週期專一性**。
- 標靶：**imatinib 抑制 BCR-ABL**(CML、GIST)、**gefitinib 抑制 EGFR 酪胺酸激酶**、**panitumumab 抑制 EGFR**、**trastuzumab 靜脈滴注、監測心臟**、**sorafenib 手足皮膚反應**；乳癌相關基因是 **HER2** 不是 EGFR。
- 荷爾蒙：**letrozole 只用於停經後**；**ER／PR 越高反應越好**；tamoxifen 注意**更年期症狀、噁心、水腫**。
- **干擾素**：類流感症狀。**心臟病人**的止吐選 **palonosetron**。
- 安全防護：抽藥保持**負壓**；廢棄物丟**基因毒性廢棄物**，不是感染性垃圾。
- 外滲順序：**停止注射 → 反抽 → 冷熱敷或解毒劑 → 每日追蹤**；**doxorubicin 冷敷**、**vincristine 與紫杉醇溫熱敷**；解毒劑注射在**外滲部位四周**。
:::
