## 重點摘要 {#summary}

- **抗瘧疾藥**：chloroquine 殺**紅血球期**；**primaquine** 殺**肝臟期**(紅血球外期)潛伏體，用前先驗 **G6PD**；chloroquine 抗藥地區預防用 **mefloquine** 等；重症瘧疾用 artesunate。
- **chloroquine、hydroxychloroquine**(Plaquenil)長期使用會造成**視網膜病變**，要**定期眼科檢查**，停藥後仍可能持續或出現。
- **metronidazole**：**阿米巴痢疾**、**梨形鞭毛蟲**、**陰道滴蟲**(**性伴侶同時治療**、**禁酒**)。
- **驅蟲藥**：線蟲用 **mebendazole**、albendazole、pyrantel；吸蟲、絛蟲用 **praziquantel**；蟠尾絲蟲與疥瘡可用 **ivermectin**。腸道驅蟲劑**空腹**服用。
- **疥瘡**：**頸部以下全身**塗藥(不是只塗病灶)，**晚上**塗；**同住者一起治療**；**接觸隔離**；衣物床單 **60℃ 以上熱水**洗。

## 寄生蟲與藥物總表 {#overview}

| 寄生蟲 | 代表疾病 | 首選或常用藥 |
|---|---|---|
| **瘧原蟲** | 瘧疾 | chloroquine、primaquine、artemisinin 類、mefloquine、atovaquone-proguanil |
| **痢疾阿米巴** | 阿米巴痢疾、**阿米巴肝膿瘍** | **metronidazole**，之後加腸腔藥(paromomycin) |
| **梨形鞭毛蟲** | 腹瀉、吸收不良 | metronidazole、tinidazole |
| **陰道滴蟲** | 滴蟲性陰道炎 | **metronidazole**(伴侶同治) |
| **弓漿蟲** | 先天性感染、愛滋病人腦炎 | **pyrimethamine＋磺胺藥**(sulfadiazine)＋leucovorin |
| 肺囊蟲(現歸為真菌) | 肺囊蟲肺炎 | **TMP-SMX**；替代 pentamidine |
| 隱孢子蟲 | 水瀉 | nitazoxanide；愛滋病人以抗病毒治療恢復免疫為主 |
| **線蟲**(蟯蟲、蛔蟲、鉤蟲、鞭蟲) | 腸道線蟲感染 | **mebendazole**、albendazole、pyrantel pamoate |
| 糞小桿線蟲 | 自體重複感染 | ivermectin |
| **蟠尾絲蟲** | **河盲症** | **ivermectin**(首選、副作用小) |
| 淋巴絲蟲 | 象皮病 | diethylcarbamazine、albendazole |
| **吸蟲**(**中華肝吸蟲**、肺吸蟲、血吸蟲) | 膽管病變、肺部病變 | **praziquantel** |
| **絛蟲**(豬肉、牛肉絛蟲) | 腸絛蟲、**囊尾蚴病** | praziquantel；神經囊尾蚴病用 albendazole |
| **疥蟲** | 疥瘡 | **permethrin**、benzyl benzoate、crotamiton、口服 ivermectin |
| 頭蝨 | 頭蝨 | permethrin 洗髮劑、細齒梳 |

- 寄生蟲與病媒的病原體特性(生活史、傳染途徑、檢體收集)之後整理在病原體頁；本頁只談藥物。

## 抗瘧疾藥物 {#antimalarials}

瘧原蟲在人體有**肝臟期**(紅血球外期)與**紅血球期**；**間日瘧、卵形瘧**會在肝臟留下**休眠體**，造成日後復發。瘧疾在台灣屬**第二類法定傳染病**，台灣已於 1965 年根除瘧疾，現在都是**境外移入**。

| 藥物 | 作用時期與用途 | 重要副作用與注意事項 |
|---|---|---|
| **chloroquine** | **紅血球期**；對 chloroquine 仍有感受性的瘧疾治療與預防 | 惡性瘧原蟲**普遍抗藥**；長期大量使用**視網膜病變**；腸胃不適、搔癢 |
| **hydroxychloroquine**(Plaquenil) | 抗瘧藥，臨床多用於**全身性紅斑性狼瘡、類風濕性關節炎** | **視網膜病變**：開始用藥時做眼科基礎檢查，之後**定期眼科檢查**；它的主要副作用在**眼睛**，**不是聽力** |
| **quinine**(奎寧)、quinidine | 紅血球期；重症瘧疾的舊藥 | **金雞納中毒**(**耳鳴、聽力下降**、頭痛、視力模糊)、低血糖、QT 延長 |
| **primaquine** | **肝臟期**(紅血球外期)：清除間日瘧與卵形瘧的休眠體，達到**根治**、預防復發 | **G6PD 缺乏症**(蠶豆症)病人會**溶血** → **用藥前先驗 G6PD**；懷孕禁用 |
| **artemisinin**(青蒿素)類：artesunate、artemether | 紅血球期，作用最快；**青蒿素複方療法**(ACT)是**非重症惡性瘧的第一線**；**靜脈 artesunate** 是**重症瘧疾首選** | 耐受性好；治療後數週可能延遲性溶血 |
| **mefloquine** | **chloroquine 抗藥地區的預防**(每週一次)與治療 | **神經精神副作用**(失眠、惡夢、焦慮、憂鬱、幻覺)；有精神病史、癲癇者避免 |
| atovaquone-proguanil(Malarone) | 預防(每天一次)與治療 | 耐受性好；隨含脂肪的食物服用 |
| doxycycline | 預防(每天一次) | 光敏感、食道炎；孕婦與 8 歲以下兒童避免([[protein-synthesis-inhibitors]]) |
| **pyrimethamine** | 抑制葉酸合成；與 **sulfadoxine** 合用(Fansidar)治瘧疾，與 sulfadiazine 合用治**弓漿蟲** | 葉酸缺乏 → 骨髓抑制，要加 **leucovorin**(亞葉酸) |

**出國旅遊預防**：
- 出發前到**旅遊醫學門診**評估，依目的地的抗藥情形選藥；chloroquine 抗藥地區用 **mefloquine**(出發前 **2–3 週**開始、每週一次、回國後持續 4 週)、atovaquone-proguanil(出發前 1–2 天、回國後 7 天)或 doxycycline(出發前 1–2 天、回國後 4 週)。
- 預防藥**不能完全保護**：同時**防蚊**(長袖衣褲、防蚊液、蚊帳)；**瘧蚊**傳播，多在黃昏到清晨叮咬。
- 回國後數週到數月內(甚至超過一年)**發燒**要就醫並**告知旅遊史**；診斷以**血液抹片**鏡檢(厚、薄片)或快速抗原檢驗。

## 抗原蟲藥物 {#antiprotozoals}

- **metronidazole**(Flagyl)：**阿米巴痢疾**與**阿米巴肝膿瘍**、**梨形鞭毛蟲**、**陰道滴蟲**的首選；機轉與副作用見 [[fluoroquinolones-sulfonamides#metronidazole]]。
  - **陰道滴蟲**：**性伴侶要同時治療**(即使沒有症狀)，治療期間避免性行為；不需要陰道沖洗，也不需要配合口服避孕藥。
  - 服藥期間與停藥後至少 **72 小時**內**禁酒**(類戒酒反應)；尿液可能變深色、口中有金屬味。
  - 阿米巴痢疾：metronidazole 殺組織中的滋養體後，再用**腸腔藥**(paromomycin)清除腸內的囊體，避免復發與帶原。
- **tinidazole**：單次口服，用於滴蟲、梨形鞭毛蟲。
- **pyrimethamine＋sulfadiazine＋leucovorin**：**弓漿蟲**(先天性弓漿蟲症、愛滋病人弓漿蟲腦炎)；**TMP-SMX** 可替代，也用於愛滋病人的預防([[hiv-aids#opportunistic-infections]])。
- **pentamidine**：肺囊蟲肺炎的替代藥(靜脈或吸入)；副作用**低血糖**、低血壓、腎毒性、胰臟炎。
- **nitazoxanide**：隱孢子蟲、梨形鞭毛蟲。

## 驅蟲藥 {#anthelmintics}

| 藥物 | 對象 | 機轉與重點 |
|---|---|---|
| **mebendazole** | **蟯蟲**、蛔蟲、鉤蟲、鞭蟲 | 抑制蟲體微管、使其無法吸收葡萄糖；口服吸收少，主要在腸道作用；**懷孕**(尤其第一孕期)避免 |
| **albendazole** | 同上；也治**神經囊尾蚴病**、包蟲病、淋巴絲蟲 | 同類；治療組織寄生蟲時與**含脂肪食物**同服增加吸收；監測肝功能與血球 |
| **pyrantel pamoate** | **蟯蟲**、蛔蟲、鉤蟲 | 使蟲體**痙攣性麻痺**後隨糞便排出；單次服用 |
| **praziquantel** | **吸蟲**(**中華肝吸蟲**、肺吸蟲、血吸蟲)、**絛蟲** | 增加蟲體細胞膜對鈣的通透性 → 痙攣麻痺；中華肝吸蟲**有藥可治** |
| **ivermectin** | **蟠尾絲蟲**(**河盲症**首選、副作用小)、糞小桿線蟲、**疥瘡**(口服)、頭蝨 | 作用於蟲體神經肌肉的氯離子通道 → 麻痺；空腹服用 |
| diethylcarbamazine | 淋巴絲蟲(象皮病) | 台灣(金門等地)過去曾流行，已根除 |

**服藥原則**：
- 腸道驅蟲劑**空腹**(早晨或睡前)服用，讓藥物停留在腸道、直接作用於蟲體；「**飯後服用效果較佳**」是錯的(108-2_FA_002)。
- 服藥後注意糞便中是否排出蟲體；腸道線蟲多在 **2 週後再服一次**，殺死之後孵化的幼蟲。

**蟯蟲感染的衛教**：
- **全家一起治療**，2 週後再服一劑。
- 蟲卵在**夜間**由雌蟲產在**肛門周圍** → 肛門搔癢；剪短指甲、不抓肛門、**飯前便後洗手**、每天換洗內褲，床單與內衣褲**熱水清洗**。
- 診斷用**透明膠帶肛門黏貼法**，在**清晨起床後、排便與洗澡前**採檢。

## 疥瘡與頭蝨用藥 {#scabicides}

疥瘡由**人疥蟎**鑽入皮膚角質層挖**隧道**產卵造成，**夜間劇癢**，好發於**指縫**、手腕、手肘、腋下、腰部、腹股溝與外生殖器等皺褶處，**頸部以上少見**(嬰幼兒例外)；常見於**護理之家、長照機構**等人口密集機構(疾管署：疥瘡感染症)。

| 藥物 | 用法 | 重點 |
|---|---|---|
| **permethrin 5% 乳膏** | **頸部以下全身**塗抹(嬰幼兒與老人包括頭皮、臉部)，**8–14 小時後**洗掉；**1–2 週後重複一次** | 第一線、安全性高；可用於 2 個月以上嬰兒 |
| **benzyl benzoate**(BB 乳液) | 塗抹全身，**待藥液乾後再塗一次**，**24 小時後沖掉**；**每晚或隔晚**使用，**共 3 次**(113-1_MS_029 答案) | 皮膚刺激、灼熱感；台灣常用 |
| **crotamiton**(Eurax，優力斯) | 頸部以下全身塗抹，**不塗頭臉**；通常每天一次、連續數天 | 兼有**止癢**作用，但殺疥蟲效果較差 |
| **lindane**(γ-BHC) | 塗抹後約 8 小時洗掉，**只用一次** | **神經毒性**(癲癇)、再生不良性貧血；嬰幼兒、孕婦、老人、皮膚破損者**禁用**；已不建議作為一般治療，**不可每天使用** |
| **口服 ivermectin** | 單次，**1–2 週後重複** | 大範圍、**結痂型(挪威)疥瘡**與機構群聚時使用，結痂型要與外用藥合用 |

**塗藥方法**：
1. **晚上睡前**塗藥(藥物可停留較久)，不是白天。
2. 洗澡後擦乾、待皮膚涼後，從**頸部往下塗抹全身皮膚**，**不只**塗紅疹或水泡處；特別注意**指縫、指甲下、腋下、肚臍、臀溝、外生殖器**；指甲剪短。
3. 洗手後要**重新補塗**雙手。
4. 到時間後洗澡把藥洗掉，**換穿乾淨衣物**、換床單。
5. **同住家人與密切接觸者同時治療**，即使沒有症狀(潛伏期內可能已感染)。
6. 治療後**搔癢可持續約 2–4 週**，是對蟲體殘骸的過敏反應，不代表治療失敗；可用抗組織胺止癢。4 週後仍有新隧道或新病灶要回診。

**環境與感染管制**：
- **接觸隔離**：戴**手套**、穿**隔離衣**；結痂型疥瘡傳染力極強，要單獨隔離。
- 衣物、床單、毛巾用 **60℃ 以上熱水**洗 **10 分鐘**以上，或以**烘乾機**高溫烘乾(國考寫法：至少 5 分鐘)；**可以**使用烘乾機。
- **無法清洗**的物品(枕頭、床墊、玩具、鞋子)**密封於塑膠袋 1–2 週**(國考多寫 2 週)。
- 疥蟲**離開人體**只能存活約 **2–4 天**(UpToDate：室溫下多在 24–36 小時，一般不超過 2–3 天)，**不是**2 週或 3 週；只要 40℃ 並不足以殺死疥蟲。
- **潛伏期**(疾管署)：**初次感染 2–6 週**(國考常寫約 **4 週**)才出現症狀；**再次感染 1–4 天**。
- 不共用衣物、毛巾與床單；**動物疥蟲**(犬貓疥癬)也可短暫感染人，但無法在人體繁殖。
- 疥瘡不需要保護性隔離，也不必用殺蝨劑洗頭或清除塵蟎。

**頭蝨**：permethrin 1% 洗髮劑或乳液，**7–10 天後再用一次**；以**細齒梳**濕梳清除蟲卵；枕頭、帽子、梳子熱水清洗；**同住者一起檢查**。

## 護理重點與衛教 {#nursing}

1. **primaquine**：用藥前確認 **G6PD** 結果；觀察**溶血**(茶色尿、黃疸、倦怠)。
2. **chloroquine、hydroxychloroquine**：定期**眼科檢查**(視力、視野、色覺)，出現視力模糊、畏光要回報；停藥後視網膜病變**仍可能持續或出現**。
3. **quinine**：注意**耳鳴、聽力下降**與低血糖。
4. **mefloquine**：注意情緒與睡眠改變。
5. **metronidazole**：**禁酒**、性伴侶同治、完成全部療程。
6. **驅蟲劑**：**空腹**服用；**全家一起治療**；注意個人衛生與洗手；2 週後重複。
7. **疥瘡**：晚上塗藥、頸部以下全身、同住者同治、接觸隔離、熱水清洗與密封靜置。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **primaquine** 對瘧疾的**紅血球外組織期(肝臟)**有效。
- 前往 **chloroquine 抗藥**地區，預防用 **mefloquine**。
- **pyrimethamine＋磺胺藥**治療**弓漿蟲**。
- **ivermectin** 是**蟠尾絲蟲(河盲症)**的首選、副作用最小。
- **中華肝吸蟲**：生食**淡水魚**感染，**有藥可治**(praziquantel)。
- **metronidazole** 治療陰道滴蟲：**服藥期間不可飲酒**；**性伴侶一起治療**，不是無效後才治療；不需陰道沖洗。
- **chloroquine** 的視網膜病變停藥後**仍可能出現**；抗瘧藥(hydroxychloroquine)要定期檢查**眼睛**，**不是聽力**。
- 驅蟲劑**空腹**服用，不是飯後。
- **疥瘡**：benzyl benzoate 塗抹、**待乾再塗一次**、**24 小時後沖掉**、每晚或隔晚共 3 次；**晚上**塗藥；crotamiton 不塗頭臉；lindane 有**神經毒性**、不可每天使用。
- 疥瘡照護：**接觸隔離**(手套＋隔離衣)、家人同時治療、衣物 **60℃ 以上熱水 10 分鐘**或烘乾機、無法清洗者密封 **2 週**；抗疥藥要塗**全身**，不只是紅斑處。
- 疥蟲離開人體**不會存活 2–3 週**；接觸後約 **4 週**才出現症狀；寵物的疥蟲也可能傳給人。
