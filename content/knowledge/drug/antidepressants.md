## 重點摘要 {#summary}

- 機轉：增加突觸間的**血清素與正腎上腺素**：阻止**再回收**(SSRI、SNRI、TCA)或阻止**分解**(MAOI)。
- 第一線：**SSRI**(fluoxetine、sertraline、escitalopram)或 SNRI；療效需 **2–4 週**才出現，副作用卻在**頭幾天**就出現。
- 用途：憂鬱症，以及**焦慮症、恐慌症、強迫症**(SSRI、clomipramine)、創傷後壓力症、暴食症、疼痛等。
- 危險：用藥初期與 **25 歲以下**的**自殺意念**增加；**血清素症候群**；**TCA 過量致命**(心律不整)；**MAOI + 含酪胺食物 → 高血壓危象**；雙相病人可能誘發**躁症**。
- 護理：**每天規則服用**(不是需要時才吃)、告知**延遲見效**、**不可自行驟停**、觀察自殺風險與情緒轉躁。

## 作用機轉 {#mechanism}

單胺假說與受體副作用見 [[neurotransmitters-psychiatry#monoamine]] 與 [[neurotransmitters-psychiatry#receptor-side-effects]]。

| 類別 | 機轉 | 副作用來源 |
|---|---|---|
| **SSRI** | **選擇性**抑制**血清素**再回收 | 血清素過多：腸胃、失眠或嗜睡、性功能障礙 |
| **SNRI** | 抑制**血清素與正腎上腺素**再回收 | 另外有 NE 作用：**血壓上升**、出汗、心跳加快 |
| **TCA** | 抑制**正腎上腺素與血清素**再回收 | **同時阻斷** M1(抗膽鹼)、H1(嗜睡、體重增加)、α1(姿勢性低血壓)、**鈉離子通道**(心臟傳導延遲、癲癇) |
| **MAOI** | 抑制**單胺氧化酶**，使 NE、5-HT、DA 不被分解 | 無法分解食物中的**酪胺** → 高血壓危象；交互作用多 |
| **Bupropion** | 抑制**多巴胺與正腎上腺素**再回收(NDRI) | 失眠、焦慮、**降低癲癇閾值**；沒有性功能障礙與體重增加 |
| **Mirtazapine** | 阻斷 **α2** 受體(增加 NE 與 5-HT 釋放)，並阻斷 5-HT2、5-HT3、**H1** | **嗜睡、食慾增加、體重增加** |
| Trazodone | 5-HT2 拮抗劑，並有弱的再回收抑制 | **嗜睡**(常用於失眠)、姿勢性低血壓、陰莖異常勃起(罕見) |
| Agomelatine | 褪黑激素受體致效劑＋5-HT2C 拮抗 | 需定期檢查**肝功能** |
| Esketamine | **NMDA 拮抗劑**(鼻噴劑)，用於難治型 | 解離感、血壓上升；需在醫療機構使用並觀察 |

- 所有抗憂鬱劑**當天**就改變突觸間濃度，但情緒改善要 **2–4 週**，完整療效要 **6–8 週**以上；這與受體調整、神經可塑性有關。
- TCA 的作用機轉標準答案：**抑制血清素和正腎上腺素的回收**；抑制 MAO 是 MAOI 的機轉，不是 TCA。

## 代表藥物 {#agents}

| 類別 | 藥物(商品名) | 特色 |
|---|---|---|
| SSRI | **Fluoxetine**(Prozac，百憂解) | 半衰期**最長**(活性代謝物可達 1–2 週)，停藥症候群最少；較有**活化**作用(早上吃)；也用於暴食症、兒童青少年憂鬱 |
| SSRI | **Sertraline**(Zoloft，樂復得) | 常用、交互作用較少 |
| SSRI | **Escitalopram**(Lexapro)、Citalopram | 交互作用少；citalopram 有**劑量相關的 QT 延長**，美國建議上限 40 mg/天 |
| SSRI | **Paroxetine**(Paxil) | 抗膽鹼作用與**體重增加**較多、**停藥症候群最明顯**；懷孕早期避免 |
| SSRI | **Fluvoxamine**(Luvox) | 常用於**強迫症**；強效 **CYP1A2 抑制劑**(會讓 clozapine 濃度大增)；通常睡前服用 |
| SNRI | **Venlafaxine**(Efexor) | 高劑量時**血壓上升**；停藥症候群明顯 |
| SNRI | **Duloxetine**(Cymbalta，千憂解) | 也用於**神經病變痛**、纖維肌痛；肝病者避免 |
| TCA | **Imipramine**(Tofranil) | 兒童**夜尿症**、國考也出現於**暴食症** |
| TCA | **Amitriptyline** | 慢性疼痛、偏頭痛預防；抗膽鹼與嗜睡強 |
| TCA | **Clomipramine** | **強迫症**療效最好的 TCA |
| TCA | Nortriptyline | 抗膽鹼與姿勢性低血壓較少 |
| MAOI | Phenelzine、Tranylcypromine(不可逆) | 需要嚴格的酪胺飲食限制 |
| MAOI | **Moclobemide**(可逆性 MAO-A 抑制劑) | 飲食限制較寬鬆，但仍避免大量含酪胺食物 |
| 其他 | **Bupropion**(Wellbutrin) | **戒菸**(降低對尼古丁的渴求)；癲癇、暴食症或厭食症病人禁用 |
| 其他 | **Mirtazapine**(Remeron) | 適合**失眠、食慾差、體重減輕**的病人(如老人)；睡前服用 |
| 其他 | Trazodone | 失眠 |

## 適應症 {#indications}

- **憂鬱症**、持續性憂鬱症、雙相憂鬱(須合併情緒穩定劑，避免單用)
- **焦慮症類**：廣泛性焦慮症、**恐慌症**、社交焦慮症、**強迫症**(SSRI 常需**較高劑量、較長時間**；clomipramine、fluvoxamine)、創傷後壓力症
- **暴食症**(fluoxetine；國考也以 imipramine 為答案)
- 慢性疼痛：duloxetine、amitriptyline；夜尿症：imipramine；戒菸：bupropion；經期前情緒低落症：SSRI

## 用藥原則 {#treatment-principles}

- 從**低劑量**開始，每 1–4 週視反應調整；老人與對副作用敏感者起始劑量減半。
- 足劑量使用 **4–8 週**仍無明顯改善，才考慮加量、換藥或合併治療。
- 緩解後持續用藥**數個月**(常見 4–9 個月)，反覆發作者長期維持；**停藥要逐漸減量**。
- **雙相情緒障礙症**：只用抗憂鬱劑可能誘發**躁症**或快速循環，用藥前要問過去有沒有躁症或輕躁症。

## 副作用與禁忌 {#adverse-effects}

### SSRI 與 SNRI {#ssri-effects}

| 副作用 | 說明與護理 |
|---|---|
| **腸胃不適**(噁心最常見)、腹瀉 | 多在頭 1–2 週，**飯後服用**、從低劑量開始 |
| **失眠、焦慮、坐立不安**(活化作用) | **早上服用**；初期焦慮、緊張、出汗、手抖常見，會隨時間減輕，但要與血清素症候群區分 |
| 嗜睡 | 少數人會，可改睡前服用(fluvoxamine 常睡前) |
| **性功能障礙** | 性慾降低、延遲射精、無法高潮；很常見、病人不會主動說，是停藥的常見原因 |
| 頭痛、頭暈 | 初期常見 |
| **低血鈉**(SIADH) | **老人**、合併利尿劑者風險高；注意意識混亂、疲倦、跌倒 |
| **出血**傾向 | 血小板血清素減少；併用 **NSAIDs、aspirin、抗凝血劑**時增加腸胃出血 |
| QT 延長 | citalopram、escitalopram(劑量相關) |
| 體重 | 短期多半不變；paroxetine、mirtazapine 較易增加 |
| 血壓上升 | SNRI(venlafaxine 高劑量) |
| 情緒轉躁 | 雙相病人 |

:::exam[國考重點]
- SSRI 常見副作用：**噁心、睡眠障礙、性慾降低**(體重增加不是典型)；「建議早飯後服用」是正確的衛教。
- Sertraline 是 **SSRI**(不是 SNRI)；**2 週以上**才有療效；可能有噁心、嗜睡。
- 服用 duloxetine 第 7 天出現焦慮、緊張、出汗、手抖 → **初期常見的中樞神經副作用**，加強衛教與觀察(若出現發燒、肌陣攣、意識改變就要想到血清素症候群)。
:::

### 自殺風險的警語 {#suicidality-warning}

- 美國 FDA 的黑框警語：**25 歲以下**兒童、青少年與年輕成人，開始用抗憂鬱劑後**自殺想法與行為**可能增加；開始用藥與調整劑量的**頭幾週**要密切觀察。
- 另一個原因是：憂鬱症初期改善時，**精力比情緒先恢復**，病人較有力氣付諸行動。
- 對有自殺風險的病人，一次只開**少量**藥物(尤其 TCA)，由家屬保管。

### 停藥症候群 {#discontinuation}

- **突然停藥**後數天內出現：類流感(疲倦、肌肉痛、發冷)、**頭暈、平衡差**、噁心、失眠、多夢、易怒焦慮、**感覺異常**(像觸電的感覺)。
- **Paroxetine、venlafaxine** 最明顯；**fluoxetine** 因半衰期長最少。
- 不是成癮，但要**逐漸減量**；病人症狀改善後常想自己停藥，要事先衛教。

### 血清素症候群 {#serotonin-syndrome}

- 原因：**血清素作用過多**，通常是**合併兩種以上**血清素藥物或劑量增加：SSRI、SNRI、TCA、**MAOI**、**tramadol**、**meperidine**、**dextromethorphan**(止咳藥)、**triptan**、linezolid、鋰鹽、聖約翰草、MDMA。
- **時間**：大多在用藥或加量後 **24 小時內**(多數 6 小時內)**快速**出現。
- **表現**(三大類)：
  - 精神狀態：焦慮、**躁動**、混亂、譫妄
  - 自主神經：**發燒**、**大量出汗**、心跳過快、血壓上升、**瞳孔放大**、**腹瀉**、腸音亢進
  - 神經肌肉：**肌陣攣**(clonus，下肢比上肢明顯，包括眼球陣攣)、**反射亢進**、震顫、肌肉僵硬
- 診斷用 **Hunter 準則**：有使用血清素藥物，加上自發性陣攣；或誘發性陣攣＋躁動或出汗；或眼球陣攣＋躁動或出汗；或震顫＋反射亢進；或肌肉張力增加＋體溫 > 38°C＋眼球或誘發性陣攣(來源：[UpToDate：Serotonin syndrome](https://www.uptodate.com/contents/serotonin-syndrome-serotonin-toxicity))。
- **處置**：**停用所有血清素藥物**、支持療法(輸液、降溫、監測)、**BZD** 控制躁動、中重度用 **cyproheptadine**(5-HT2A 拮抗劑)；多數在 24 小時內改善。
- 與 NMS 的比較見 [[antipsychotics#nms]]：NMS 慢(數天)、**鉛管樣僵硬**、動作少；血清素症候群快(數小時)、**陣攣與反射亢進**、腹瀉。

### 三環抗憂鬱劑(TCA) {#tca-effects}

| 副作用 | 原因 | 護理 |
|---|---|---|
| **口乾、便秘、尿滯留、視力模糊**、心跳加快、意識混亂 | 阻斷**蕈毒鹼受體**(抗膽鹼) | 多喝水、高纖；**青光眼、攝護腺肥大**避免；老人注意譫妄 |
| **姿勢性低血壓** | 阻斷 α1 | 慢慢起身、防跌 |
| 嗜睡、**體重增加** | 阻斷 H1 | 睡前服用 |
| **心臟傳導延遲**(PR、**QRS**、QT 延長)、心律不整 | 阻斷**鈉離子通道** | 用藥前 ECG；**近期心肌梗塞**、傳導阻滯者禁用 |
| 癲癇 | 降低癲癇閾值 | 有癲癇病史者小心 |

- 老人、心臟病人**避免**使用 TCA；老年憂鬱以 SSRI 為第一線。

#### TCA 中毒 {#tca-overdose}

- TCA **治療範圍窄**，過量(約一到兩週的藥量)就可能**致命**，是有自殺風險病人最危險的抗憂鬱劑。
- 表現：**意識改變到昏迷、癲癇、心律不整與低血壓**(死亡主因)，加上**抗膽鹼中毒**(發燒、皮膚潮紅乾燥、瞳孔放大、腸阻塞、尿滯留、譫妄)。
- **ECG**：**QRS > 100 毫秒**時癲癇與心室性心律不整的風險明顯增加(來源：[UpToDate：Tricyclic antidepressant poisoning](https://www.uptodate.com/contents/tricyclic-antidepressant-poisoning))。
- 處置：維持呼吸道、心電圖監測、活性碳(意識清楚、呼吸道安全時)、QRS 變寬或心律不整給**碳酸氫鈉**(sodium bicarbonate)靜脈注射、癲癇用 BZD。

### 單胺氧化酶抑制劑(MAOI) {#maoi}

- **酪胺**(tyramine)是食物中的單胺，正常會被腸道與肝臟的 MAO-A 分解；服用 MAOI 時大量酪胺進入循環，促使正腎上腺素釋放 → **高血壓危象**：劇烈**枕部頭痛**、頸部僵硬、心悸、胸痛、噁心嘔吐、大量出汗、血壓急遽上升，可能造成**顱內出血**。
- **需避免的高酪胺食物**：
  - **熟成起司**(切達、藍紋起司等；新鮮的茅屋起司可以)
  - **醃漬、煙燻、發酵或乾燥的肉類與魚**(臘腸、義大利香腸、醃魚)
  - **發酵豆類製品**(醬油、味噌、豆腐乳、納豆等)、酵母萃取物
  - **生啤酒(桶裝啤酒)**、部分紅酒
  - 蠶豆、**過熟**的水果(過熟香蕉、酪梨)、**不新鮮或變質**的食物
- 停用 MAOI 後，飲食限制仍要**持續約 2 週**(身體需要時間重新製造 MAO)。
- **藥物交互作用**：
  - 與其他血清素藥物(SSRI、SNRI、TCA、tramadol、meperidine、dextromethorphan)併用或間隔太近 → **血清素症候群**。停用 MAOI 後**至少 2 週**才能開始其他抗憂鬱劑；停用 **fluoxetine 後要等約 5 週**(半衰期長)才能開始 MAOI。
  - 擬交感藥物(感冒藥中的**減充血劑** pseudoephedrine、安非他命、中樞興奮劑) → 高血壓危象。
- 其他副作用：**姿勢性低血壓**(很常見)、失眠、體重增加、性功能障礙。
- 衛教：隨身攜帶用藥卡，看其他科或買成藥前告知正在服用 MAOI；出現劇烈頭痛立即就醫。

:::exam[國考重點]
- 服用 **MAOI**：勿食用含**酪胺**的食物(起司、臘腸、醃漬發酵食品、紅酒)，否則**高血壓危象**。
- Bupropion 另可用於**戒菸**。
- TCA 的抗膽鹼副作用(視力模糊、口乾、便秘)來自阻斷**蕈毒鹼受體**。
- Fluvoxamine(SSRI)常用於**強迫症**。
:::

## 交互作用 {#interactions}

- **血清素症候群**：與 MAOI、tramadol、meperidine、dextromethorphan、triptan、linezolid、鋰鹽、聖約翰草併用。
- **出血**：SSRI、SNRI + NSAIDs、aspirin、warfarin、其他抗凝血劑。
- **CYP 酵素**：
  - fluoxetine、paroxetine 強效抑制 **CYP2D6**：使 TCA、部分 β 阻斷劑、risperidone、codeine 轉換受影響；tamoxifen 的活化減少。
  - **fluvoxamine** 抑制 **CYP1A2**：使 **clozapine**、theophylline、caffeine 濃度上升。
- **QT 延長**藥物(citalopram、TCA)+ 其他延長 QT 的藥物。
- **酒精與中樞抑制劑**：加重嗜睡與判斷力下降；酒精也會加重憂鬱。
- 與 clozapine 併用增加**癲癇**風險。

## 護理重點與衛教 {#nursing}

### 給藥與觀察 {#nursing-administration}

- **每天規則服用**，不是心情不好才吃；錯過一劑不要下次吃兩倍。
- 告知：**副作用先來、療效後到**，通常 2–4 週才開始覺得有效，不要因為一兩週沒效就停藥。
- 觀察**自殺意念**，尤其用藥頭幾週、劑量調整時、年輕病人；有自殺風險者**一次給少量藥**、確認吞藥。
- 觀察**情緒轉躁**(話多、睡少、誇大、易怒)，立即回報。
- 老人：從低劑量開始，注意**低血鈉**、跌倒、姿勢性低血壓、抗膽鹼副作用。
- 評估腸胃症狀、睡眠、性功能、體重與血壓(SNRI)。

### 衛教 {#nursing-education}

- SSRI **飯後服用**減少噁心；有失眠的藥物**早上**吃，嗜睡的藥物**睡前**吃。
- **症狀改善後仍要持續服藥**，停藥必須由醫師指導**逐漸減量**。
- **避免飲酒**；用藥初期或嗜睡時避免開車。
- 買成藥(感冒藥、止咳藥、止痛藥)或看其他科前，告知正在服用抗憂鬱劑；避免自行合併 **NSAIDs** 或聖約翰草。
- 服用 MAOI：遵守**酪胺飲食限制**，劇烈頭痛、心悸立即就醫。
- 出現**發燒、大量出汗、肌肉抽動、腹瀉、意識混亂**要立刻就醫(血清素症候群)。
- 懷孕或計畫懷孕先與醫師討論，不要自行停藥。
- 性功能問題可以提出來討論，有調整的方法。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 機轉：SSRI = 選擇性抑制**血清素**再回收(fluoxetine)；TCA = 抑制 **NE 與 5-HT** 再回收；MAOI = 抑制**單胺氧化酶**。
- 抗憂鬱劑 **2 週以上**才有療效；憂鬱症開始恢復時是自殺高風險期。
- SSRI 副作用：**噁心、失眠、性功能障礙**；早上、飯後吃。
- TCA：**抗膽鹼**(蕈毒鹼受體)、姿勢性低血壓、**心臟毒性**，過量致命；老人不是首選。
- MAOI：**酪胺** → 高血壓危象；不可與 SSRI 併用。
- **Bupropion**：戒菸；**fluvoxamine**：強迫症；**imipramine**：夜尿症、暴食症。
- 老年憂鬱：**SSRI 第一線**；緩解後仍需維持用藥數月到一年以上，不可突然停藥。
:::
