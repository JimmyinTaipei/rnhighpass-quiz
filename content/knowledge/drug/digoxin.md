## 重點摘要 {#summary}

- 抑制心肌 **Na⁺-K⁺-ATPase** → 細胞內鈣增加 → **正性收縮力**;同時增強迷走神經張力 → **心跳變慢、房室傳導變慢**(負性心律)。
- 用途:已用足標準藥物仍有症狀的 **HFrEF**(減少住院,**不降低死亡率**);**心房顫動控制心室速率**。
- **治療窗窄**:中毒早期是**食慾差、噁心嘔吐**,另有**黃綠色視覺**、心搏過緩與各種心律不整;**低血鉀、低血鎂、高血鈣、腎功能差**會加重毒性。
- 給藥前量**心尖脈 1 分鐘**,成人 **< 60 次/分**暫停並通報(兒童標準較高);解毒劑為**毛地黃抗體片段(Digibind/DigiFab)**。

## 作用機轉 {#mechanism}

1. Digoxin 結合心肌細胞膜上的 **Na⁺-K⁺-ATPase**(與 K⁺ 競爭同一個結合位)並抑制它 → 細胞內 Na⁺ 上升。
2. 細胞內 Na⁺ 多了,**Na⁺/Ca²⁺ 交換**把鈣送出去的能力下降 → 細胞內 **Ca²⁺ 增加** → 肌漿網儲鈣增加 → 每次收縮釋放更多鈣 → **收縮力增加**(正性肌力,見 [[cardiac-output#contractility]])。
3. **增強迷走神經作用、減慢房室結傳導**、延長房室結不反應期 → **心跳變慢**(負性變時)、房室傳導變慢(負性變傳導)。這是心房顫動時能控制心室速率的原因(傳導系統見 [[cardiac-output#conduction]])。
4. 降低交感神經活性、改善壓力感受器敏感度。

**為什麼血鉀影響這麼大**:digoxin 和 K⁺ 搶同一個結合位。**低血鉀時 digoxin 更容易結合 → 毒性增加**;高血鉀時結合減少。**高血鈣**會與 digoxin 增加的細胞內鈣相加,**低血鎂**也會增加心肌興奮性 → 都加重毒性。

## 代表藥物 {#agents}

| 藥物 | 特色 |
|---|---|
| **Digoxin(Lanoxin®)** | 臨床唯一常用者;口服錠 0.25 mg、0.125 mg,也有兒童糖漿與注射劑;心衰竭起始 62.5 µg、目標 250 µg 一天一次(來源:[2026 ESC 心衰竭指引](https://doi.org/10.1093/eurheartj/ehag100) p.37;僅供參考,以醫囑為準) |
| Digitoxin | 經肝代謝、半衰期很長,台灣少用 |

## 適應症 {#indications}

- **HFrEF**:已使用 [[arni]]/ACEI/ARB、[[beta-blockers]]、[[potassium-sparing-diuretics|MRA]]、[[sglt2-inhibitors]] 等最佳治療後**仍有症狀**者,可考慮加上 digoxin 以**減少心衰竭住院**(2022 AHA/ACC/HFSA Class 2b;2021 ESC IIb)。DIG 試驗顯示**對死亡率沒有影響**。**2026 ESC 升為 IIa**(「強心配醣體 digoxin 或 digitoxin」,LVEF ≤ 40%),依據是 DIGIT-HF 試驗(digitoxin 使「死亡或心衰竭住院」合併終點下降)(來源:[2026 ESC 心衰竭指引](https://doi.org/10.1093/eurheartj/ehag100) p.34、37)。台灣共識:**末期腎病與心跳 < 60 次/分者不宜使用**(來源:[2023 台灣心臟學會慢性心衰竭藥物治療共識](https://doi.org/10.6515/ACS.202305_39%283%29.20230301A) p.12)。因此今天它**不是心衰竭的首選藥**,國考舊題寫「CHF 首選」是傳統教科書的說法。
- **心房顫動/心房撲動控制心室速率**:尤其合併心衰竭、低血壓不能用太多 β 阻斷劑者(HFpEF 合併心房顫動時 β 阻斷劑、非 DHP 類 CCB 或 digoxin 皆可控速,IIa;來源:[2024 台灣心臟學會 HFpEF 指引](https://doi.org/10.6515/ACS.202403_40%282%29.20240206A) p.15);靜態心率控制好,但**活動時控制較差**,常與 β 阻斷劑合用。
- 兒童先天性心臟病合併心衰竭(如心室中膈缺損)。

**不適用/禁忌**:心室頻脈或心室顫動、未裝節律器的**二度/三度房室傳導阻滯**、病竇症候群、**WPW 症候群合併心房顫動**(會加速經旁路傳導)、肥厚性阻塞性心肌病變、毛地黃中毒。

## 藥動重點 {#pharmacokinetics}

- 口服吸收 60–80%;口服 0.5–2 小時起效,**半衰期約 36–48 小時**(一天一次即可;停藥後需多天才排除)。
- **主要經腎臟原型排出** → **腎功能不全、老人**容易蓄積中毒,需減量(例如 0.125 mg 或隔日給藥)。
- 分布到骨骼肌,**不分布到脂肪** → 依理想體重給藥;肌肉量少的老人濃度較高。
- **血中濃度**:心衰竭建議維持約 **0.5–0.9 ng/mL**(2022 AHA,待原文核對);ESC 建議治療中目標 **< 1.2 ng/mL**,並依血中濃度調整劑量(來源:[2026 ESC 心衰竭指引](https://doi.org/10.1093/eurheartj/ehag100) p.34、37);傳統教科書治療範圍 **0.5–2.0 ng/mL**,**> 2.0 ng/mL** 視為中毒。濃度需在**給藥後 6–8 小時以上**(通常是下一劑前)抽血,否則會假性偏高。
- 劑量換算範例:醫囑 digoxin 125 mcg,錠劑 0.25 mg(= 250 mcg)→ 給**半顆**。

## 副作用與禁忌 {#adverse-effects}

### 毛地黃中毒 {#toxicity}

| 系統 | 表現 |
|---|---|
| **腸胃**(最早、最常見) | **食慾不振**、**噁心、嘔吐**、腹瀉、腹痛 |
| **視覺** | **黃視、綠視**(看東西帶黃綠色)、物體周圍光暈、視力模糊、畏光 |
| 神經 | 疲倦、無力、**頭痛**、嗜睡、意識混亂、**惡夢**、老人譫妄 |
| **心臟**(最危險) | **心搏過緩**、各度**房室傳導阻滯**、**心室早期收縮(二聯律)**、陣發性心房頻脈合併傳導阻滯、雙向性心室頻脈、**心室顫動**;幾乎任何心律不整都可能出現 |
| 電解質 | 急性大量中毒時鈉鉀幫浦被大量抑制 → **高血鉀**(預後差);慢性中毒常與**低血鉀**並存 |

- 心電圖的「**毛地黃效應**」(ST 段勺狀下降、QT 縮短)是正常用藥表現,不等於中毒。
- **高危險族群**:腎功能不全、老人、**低血鉀**(利尿劑、嘔吐腹瀉、甘草)、低血鎂、高血鈣、甲狀腺功能低下、低氧、急性心肌梗塞,以及併用 amiodarone/verapamil 等提高濃度的藥物。
- 兒童中毒常以**噁心嘔吐、食慾差、心跳變慢**表現;抽搐、痙攣**不是**典型症狀。

### 中毒處理 {#toxicity-management}

1. **停藥**、通知醫師、心電圖監測,抽血驗 digoxin 濃度、K⁺、Mg²⁺、Ca²⁺、腎功能。
2. 矯正電解質:**低血鉀時補鉀**(但高血鉀或高度房室阻斷時不可補)、補鎂。
3. 心搏過緩/房室阻斷:**atropine**,必要時暫時性心律調節器。
4. 心室性心律不整:傳統上用 **phenytoin** 或 lidocaine(國考答案);避免 amiodarone(會再提高 digoxin 濃度);電擊整流時用較低能量並小心。
5. **解毒劑:digoxin 專一性抗體片段(digoxin immune Fab,Digibind®/DigiFab®)**——致命性心律不整、K⁺ > 5.0–5.5 mEq/L 的急性中毒、大量誤服時使用(2023 AHA 中毒 focused update:Class 1)。給藥後血中「總 digoxin」濃度會假性大增,不能再用來判斷。
6. 急性誤服早期可給活性碳;**血液透析無效**(分布容積大)。

## 交互作用 {#interactions}

| 併用藥物/食物 | 結果 |
|---|---|
| **Loop、thiazide 利尿劑** | **低血鉀、低血鎂 → 中毒**(常考);需監測血鉀 |
| **Amiodarone** | digoxin 濃度上升約 **1 倍** → 開始 amiodarone 時 digoxin 劑量約**減半** |
| **Verapamil、diltiazem** | 濃度上升 + 房室傳導抑制相加 → 心搏過緩、傳導阻滯 |
| Quinidine、propafenone、macrolides(clarithromycin)、cyclosporine | 濃度上升 |
| β 阻斷劑 | 心搏過緩、房室阻斷相加 |
| 類固醇、amphotericin B、**甘草** | 低血鉀 → 中毒(甘草造成的是**低血鉀**,不是高血鉀) |
| 鈣劑靜注 | 高血鈣加重毒性 |
| 制酸劑、cholestyramine、高纖食物、St. John's wort | 吸收或濃度下降;與制酸劑間隔 2 小時 |
| 甲狀腺素 | 甲狀腺功能會改變 digoxin 需要量與心律不整風險(甲狀腺低下時較易中毒),調整甲狀腺藥物期間監測心率與濃度 |

## 護理重點與衛教 {#nursing}

### 給藥前評估 {#pre-administration}

- **量心尖脈(apical pulse)滿 1 分鐘**:左鎖骨中線第五肋間,用聽診器**膜面**,注意速率、**規則性與強度**;不能用橈動脈代替,也不能只量 30 秒。量**之前**量,不是給藥後。
- **暫停給藥並通知醫師**的心率:

| 對象 | 暫停標準(心尖脈/分) |
|---|---|
| **成人** | **< 60**(或出現新的不規則、突然 > 100–120) |
| 學齡兒童 | **< 70** |
| 幼兒/學齡前 | < 80(各書範圍 70–85) |
| 嬰兒 | < 90–110(常見考法 < 100) |

- 懷疑**脈搏短絀**(心尖脈 > 橈動脈脈搏,心房顫動或中毒時):**兩位護理人員同時**各量心尖脈與橈動脈 **1 分鐘**。
- 確認最近的 **K⁺**、腎功能、digoxin 濃度;詢問噁心、食慾、視覺改變。
- 靜脈給藥:緩慢推注 5 分鐘以上,不可肌肉注射(疼痛、吸收不穩)。

### 兒童給藥 {#pediatric}

- 口服糖漿用**有刻度的注射針筒**精確量取;嬰兒劑量以 mcg 計,**劑量計算需兩人核對**。
- **不要與奶、果汁、食物混合**(沒喝完就不知道吃了多少);最好在**飯前 1 小時或飯後 2 小時**給,每天固定時間。
- 服藥後嘔吐**不要再補一劑**。
- **漏服**:按一般「忘記服藥」的原則處理——想起來就儘快補服;但若已**接近下一次服藥時間**,就跳過這一劑、下一劑照原時間,**絕不加倍**;連續 2 天以上漏服要聯絡醫師(來源:[Mayo Clinic:Digoxin (oral route) – Proper use](https://www.mayoclinic.org/drugs-supplements/digoxin-oral-route/proper-use/drg-20072646))。
  - 「接近下一次」的實用判斷:**還沒超過兩次給藥間隔的中點 → 可補;超過中點 → 不補**。
    - 每 12 小時一次(兒童常見 BID):**6 小時內**可補。
    - 每天一次:**12 小時內**可補。
  - 國考題的解析有「4 小時」與「6 小時」兩種寫法,是不同教科書的數字;以題目的給藥頻次套用上面的中點原則最不容易錯,兩種說法的共同核心是「**接近下一劑就不補、不可加倍**」。
- 教家屬在家量心尖脈、辨識中毒症狀(**噁心嘔吐、食慾差、心跳變慢**)並就醫;藥物放兒童拿不到的地方(誤食很危險)。

### 成人衛教 {#education}

- 每天固定時間服用,不自行停藥或加倍;與制酸劑、纖維補充劑間隔 2 小時。
- 服用排鉀利尿劑者**適量攝取高鉀食物**;避免甘草製品。
- 認識中毒警訊:食慾差、噁心嘔吐、腹瀉、**看東西黃綠色或有光暈**、意識混亂、心悸或脈搏變慢。
- 就醫時告知正在服用 digoxin(避免交互作用藥物);定期抽血追蹤濃度、腎功能、血鉀。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **依醫囑繼續給藥的依據** → 成人心率 **≥ 60**(例:64 次/分可給,52 次/分暫停)。
- 給藥前量**心尖脈 1 分鐘**;「給藥後量」「量 30 秒」「量橈動脈」都錯。聽診用**膜面**。
- 腎臟疾病者是**中毒高危險群**(digoxin 經腎排泄)。
- 心電圖**U 波** = 低血鉀 → 注意**毛地黃中毒**;「T 波升高表示低血鉀」錯(高尖 T 波是高血鉀)。
- 中毒症狀:**腹瀉、噁心嘔吐、黃色視覺**、心搏過緩;「紅色視覺」「便祕」錯;常見原因之一是心搏過緩。
- 中毒時**低血鉀要補鉀**、房室阻斷用 **atropine**;毛地黃中毒的心室性心律不整/VF 首選(傳統答案)**phenytoin**。
- 與 thiazide 併用**不能**避免中毒;甘草 + 毛地黃 → **低血鉀**。
- 醫囑判讀:125 mcg ÷ 0.25 mg 錠 = **半顆**;**QOD = 隔天一次**;S.L. = 舌下。
- 漏服:未超過給藥間隔中點可補服(BID 約 6 小時內),超過就跳過、下一劑照原時間,**不可加倍**(題目解析有 4 或 6 小時兩種寫法,見 [[#pediatric]])。
- 服用 digoxin 可能造成**惡夢**等睡眠問題。
:::
