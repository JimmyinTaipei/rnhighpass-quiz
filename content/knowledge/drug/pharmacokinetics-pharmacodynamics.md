**藥物動力學**談「身體怎麼處理藥物」：吸收、分布、代謝、排泄（ADME，Absorption, Distribution, Metabolism, Excretion）；**藥效學**談「藥物怎麼作用在身體」：受體、機轉與劑量反應。本頁整理國考藥理總論的考點；給藥途徑、劑型吸收快慢、兒童劑量公式見 [[medication-administration-principles#drug-basics]]，習慣性、成癮性、耐受性的名詞見 [[medication-administration-principles#drug-effects]]。文中縮寫：AUC（Area Under the Curve，血中濃度時間曲線下面積）、CYP（Cytochrome P450，細胞色素 P450）、TI（Therapeutic Index，治療指數）、ED50（50% Effective Dose，半數有效量）、TD50／LD50（半數中毒量／半數致死量）、GPCR（G Protein-Coupled Receptor，G 蛋白偶合受體）、cAMP（cyclic AMP，環磷酸腺苷）、MAC（Minimum Alveolar Concentration，最低肺泡濃度）

## 重點摘要 {#summary}

- **藥動學 vs 藥效學**：作用機轉屬**藥效學**，不屬藥動學
- **吸收**
   1. **生體可用率**：進入全身循環的比例與速度；**靜脈注射 100%**；受劑型、溶解度、安定性、**首渡效應**影響，和作用方式無關
   2. **首渡效應**：口服經門靜脈先被肝臟代謝；**舌下、貼片**可避開（硝化甘油）
   3. **生體相等性**：學名藥與原廠藥的 **AUC**（與最高濃度）相近
- **代謝**：**第一相**（氧化、還原、水解，CYP450）→ **第二相**（**接合**：葡萄糖醛酸、硫酸、乙醯、胺基酸）增加**水溶性**；不一定依序、也不一定兩相都要
- **酵素**：**誘導劑** phenobarbital、rifampin；**抑制劑** cimetidine、葡萄柚汁、erythromycin
- **半衰期**：約 **4–5 個半衰期**達穩定濃度，也約 4–5 個半衰期排除；**輸注速率 ＝ 清除率 × 目標濃度**
- **劑量反應**：曲線**越左**效價(potency)越強；曲線**越高**效能(efficacy)越大；**TI ＝ TD50 ÷ ED50**，越大越安全
- **拮抗**：同一受體競爭 → 藥理性；不同受體效果相反 → **生理性**；直接化學結合 → 化學性

### 國考常考點 {#exam-points}

- 藥動學不包括「藥物的作用機制」
- Gs 蛋白活化 **adenylyl cyclase**(→ cAMP)；Gq 活化 phospholipase C；Gi 抑制 adenylyl cyclase
- 類固醇作用在**細胞內受體**、改變基因表現 → 起效**最慢**
- 重複給**拮抗劑**(propranolol)不會造成受體去敏感化
- 生體可用率最佳：**靜脈注射**；AUC 相同 → **生體相等性**
- NTG 舌下或貼片 → **避開首渡效應**
- 發炎組織 pH 下降 → 局部麻醉藥（弱鹼）解離增加、脂溶性下降 → 效果變差
- Fexofenadine 不易通過**血腦障壁** → 不嗜睡；thiopental 單次注射後**再分布**到肌肉脂肪 → 作用短
- 第一相不包括**結合作用**；CYP450 參與**第一相**；接合反應目的是**增加水溶性**
- Cimetidine **抑制** CYP450；phenobarbital **誘導**；clopidogrel 是**前驅藥**（CYP2C19 弱代謝者效果差）
- 半衰期 10 小時 → 約 **40 小時**達穩定；清除率 48 mL/min × 15 μg/mL ＝ **720 μg/min**
- TI 高 → **安全性高**；MAC 越小 → 麻醉**強度越大**
- 腎上腺素(β2)對抗組織胺(H1)的支氣管收縮 → **生理性拮抗**
- 葡萄柚汁**會**影響代謝；甘草使血鉀**降低**，增加毛地黃毒性；菠菜（維生素 K）**減弱** warfarin
- 懷孕：白蛋白下降使結合比例降低、**肝臟代謝增加**

## 藥效學 {#pharmacodynamics}

### 受體與訊息傳遞 {#receptors}

| 受體類型 | 例子 | 起效 |
|---|---|---|
| 離子通道型 | 菸鹼受體、GABA-A | 毫秒，最快 |
| **G 蛋白偶合受體** | 腎上腺素受體、蕈毒鹼受體、組織胺受體 | 秒 |
| 酵素型（酪胺酸激酶） | 胰島素受體、生長因子受體 | 分鐘 |
| **細胞內（核內）受體** | **類固醇**、甲狀腺素 | 小時到天，**最慢** |

1. **G 蛋白**
   1. **Gs**：活化 **adenylyl cyclase** → cAMP 上升 → 蛋白激酶 A（β 受體）
   2. **Gi**：抑制 adenylyl cyclase（α2、M2）
   3. **Gq**：活化 **phospholipase C** → IP3 與 DAG → 細胞內鈣上升（α1、M1、M3、H1）
   4. Guanylyl cyclase 由一氧化氮或心房利鈉胜肽活化，不是 Gs
2. **去敏感化**：受體被**致效劑**持續刺激而反應變差；拮抗劑不活化受體，不會造成去敏感化（反而可能使受體增加）
3. 自主神經受體的分布見 [[autonomic-nervous-system]]

::questions{ids="115-1_BM_033,112-2_BM_031,105-1_BM_049,108-2_BM_057"}

### 劑量反應與治療指數 {#dose-response}

1. **效價(potency)**：達到相同反應所需的濃度；曲線**越左**（EC50 越小）效價越強
2. **效能(efficacy)**：藥物能達到的**最大反應**；曲線越高效能越大
3. 兩藥作用在同一受體時，曲線位置在右邊的藥效價較小（強度較弱）；單看劑量反應曲線**不能判斷安全性**
4. **治療指數 TI ＝ TD50（或 LD50）÷ ED50**：越大表示中毒劑量與有效劑量差距越大、**越安全**；TI 小的藥（毛地黃、鋰鹽、theophylline、aminoglycosides）要監測血中濃度（見 [[digoxin]]、[[lithium-level]]）
5. **MAC**：吸入麻醉藥讓 50% 病人對切皮不動的最低肺泡濃度；**MAC 越小、強度越大**（見 [[anesthetics]]）

::questions{ids="112-1_BM_034,106-2_makeup_BM_049,106-2_BM_051"}

### 致效劑與拮抗劑 {#agonists-antagonists}

| 類型 | 意思 | 例子 |
|---|---|---|
| 完全致效劑 | 結合並產生最大反應 | Morphine 對 μ 受體 |
| 部分致效劑 | 結合但反應較小，可對抗完全致效劑 | Buprenorphine |
| **藥理性（競爭性）拮抗** | 和致效劑競爭**同一受體** | Naloxone 對抗 morphine、atropine 對抗乙醯膽鹼 |
| **生理性（功能性）拮抗** | 作用在**不同受體**，產生**相反**效果 | 腎上腺素（β2 擴張）對抗組織胺（H1 收縮） |
| 化學性拮抗 | 兩藥直接**化學結合**而失效 | Protamine 中和 heparin、螯合劑結合重金屬 |

::questions{ids="108-1_BM_049"}

## 藥物動力學 {#pharmacokinetics}

### 吸收 {#absorption}

1. **生體可用率**(bioavailability)：給藥後進入全身循環的比例與速度
   1. **靜脈注射 100%**，其他途徑都要經過吸收
   2. 影響因素：劑型、**溶解度**、**安定性**（胃酸破壞）、**首渡效應**、胃腸蠕動與食物；和藥物「作用方式」無關
2. **首渡效應**：口服吸收後經**門靜脈**先到肝臟被代謝，進入全身循環的量變少
   1. **舌下、口頰、經皮貼片、直腸（部分）、注射**可避開
   2. **硝化甘油**口服首渡效應很高，所以用舌下或貼片
3. **生體相等性**(bioequivalence)：同成分、同劑型的學名藥與原廠藥，**AUC**、最高濃度(Cmax)與到達時間(Tmax)沒有顯著差異
4. **pH 與解離**：只有**未解離**（脂溶性）的分子能穿過細胞膜
   1. 局部麻醉藥是**弱鹼**，發炎組織偏酸 → 解離型增加 → 進不了神經 → **效果變差**
   2. 劑型吸收快慢、管灌適合的劑型（液劑、懸浮劑）見 [[medication-administration-principles#dosage-forms]]

::questions{ids="110-1_BM_049,109-2_BM_053,106-1_BM_049,110-1_BM_059,106-1_BM_052"}

### 分布 {#distribution}

1. 影響因素：血流、脂溶性、**蛋白質結合**（只有**游離型**有作用）、組織屏障
2. **血腦障壁**：脂溶性高的藥容易進入腦；第二代抗組織胺（**fexofenadine**、loratadine）極性高、是 P-醣蛋白的受質 → 不易進入腦 → **較不嗜睡**（見 [[antihistamines-autacoids]]）
3. **再分布**：thiopental 這類高脂溶性藥，單次靜脈注射後先進入血流多的**腦**，再轉移到**骨骼肌與脂肪** → 腦中濃度下降、作用短
4. 低白蛋白（肝病、營養不良、懷孕）→ 游離型增加 → 作用與毒性增加

::questions{ids="113-1_BM_035,105-1_BM_050"}

### 代謝 {#metabolism}

1. 主要在**肝臟**；目的是讓藥物變得**較易排出**（水溶性增加），多數變成無活性，少數變成活性或毒性代謝物
2. **第一相反應**：**氧化**（含羥化）、**還原**、**水解**；主要由 **CYP450** 執行；使分子露出官能基
3. **第二相反應**：**接合**（葡萄糖醛酸化、硫酸化、乙醯化、胺基酸接合）→ **增加水溶性**，經腎臟或膽汁排出
4. 不是每種藥都要經過兩相，也不一定先第一相再第二相；有些藥不代謝就從腎臟排出
5. **前驅藥**(prodrug)：要代謝後才有活性，例如 **clopidogrel**（CYP2C19，弱代謝者效果差）、enalapril、codeine(CYP2D6 → morphine)
6. **酵素誘導與抑制**

| | 藥物 | 結果 |
|---|---|---|
| **誘導劑** | **Phenobarbital**、phenytoin、carbamazepine、**rifampin**、吸菸、長期飲酒 | 其他藥代謝加快 → **濃度下降、效果變差**（例：口服避孕藥失效） |
| **抑制劑** | **Cimetidine**、**erythromycin**、clarithromycin、ketoconazole、**葡萄柚汁** | 其他藥代謝變慢 → **濃度上升、毒性增加**（例：warfarin 出血、theophylline 中毒） |

7. 肝功能差時主要經肝代謝的藥（例：erythromycin）容易蓄積
8. 新生兒肝臟葡萄糖醛酸化能力不足 → chloramphenicol 造成灰嬰症候群

### 排泄、半衰期與清除率 {#elimination}

1. 主要經**腎臟**（過濾、分泌、再吸收），其次膽汁與糞便、肺、乳汁
2. **尿液 pH**：鹼化尿液加速弱酸性藥物（aspirin、phenobarbital）排出；促進毒物排出的方法還有利尿、血液透析，呼吸器是支持療法、不是排出毒物（見 [[antidotes]]）
3. **半衰期**(t½)：血中濃度下降一半的時間
   1. 規則給藥或定速輸注，約 **4–5 個半衰期**達**穩定狀態**（t½ 10 小時 → 約 40–50 小時）
   2. 達到穩定的時間**只和半衰期有關**，和劑量、輸注速度無關；改變劑量只改變穩定濃度的高低
   3. 停藥後約 4–5 個半衰期幾乎排除
   4. 想快一點達到有效濃度 → 給**負荷劑量**
4. **清除率**(CL)：單位時間清除藥物的血漿體積
   1. **輸注速率 ＝ CL × 目標穩定濃度**(48 mL/min × 15 μg/mL ＝ 720 μg/min)

::questions{ids="110-2_BM_054,105-2_BM_049,106-2_MS_074"}

## 藥物交互作用 {#interactions}

| 組合 | 結果 |
|---|---|
| **葡萄柚汁** ＋ 部分抗組織胺、statin、鈣離子阻斷劑 | 抑制 CYP3A4 → 血中濃度**上升** |
| **甘草** ＋ 毛地黃 | 甘草使血鉀**降低** → 毛地黃中毒風險增加 |
| **菠菜等高維生素 K 食物** ＋ warfarin | **減弱** warfarin 效果（飲食要穩定，不是完全不吃） |
| 四環黴素 ＋ 牛奶、制酸劑、鐵劑 | 螯合 → 吸收**減少** |
| MAOI ＋ 起司等高酪胺食物 | 高血壓危象 |
| 酒精 ＋ 中樞抑制劑 | 加成的呼吸與中樞抑制 |

1. **加成**(1＋1＝2)、**協同**(1＋1＞2)、**增強**（單獨無效的藥增加另一藥的效果）、**拮抗**
2. 病人的期待心理（**安慰劑效應**）會影響藥效
3. 給藥時的食物禁忌見 [[medication-administration-principles#drug-effects]]

::questions{ids="113-2_FA_011,111-2_FA_020,108-2_FA_031,108-1_FA_027"}

## 懷孕期的藥物動力學 {#pregnancy}

1. 吸收：胃排空與腸蠕動變慢、胃酸減少
2. 分布：**血漿量增加**稀釋、**白蛋白下降** → 結合比例降低、游離型增加
3. 代謝：荷爾蒙使**肝臟酵素活性增加** → 部分藥物代謝加快
4. 排泄：**腎絲球過濾率增加** → 經腎排出的藥物清除加快
5. 懷孕用藥分級與致畸胎見 [[fertilization-embryology]]
