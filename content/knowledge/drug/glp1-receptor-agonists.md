## 重點摘要 {#summary}

- 模擬腸泌素 GLP-1,但**不會被 DPP-4 快速分解**:**葡萄糖依賴性**促進胰島素分泌、**抑制升糖素**、**延緩胃排空**、**增加飽足感**。
- 大多為**皮下注射**(每天或每週一次;semaglutide 另有口服錠);單用低血糖少,**體重明顯下降**;多數證實減少心血管事件。
- 最常見副作用:**噁心、嘔吐、腹瀉**(由低劑量逐步增加);注意胰臟炎、膽囊疾病。
- **甲狀腺髓質癌或 MEN2 個人/家族史禁用**。

## 作用機轉 {#mechanism}

結合 GLP-1 受體,放大腸泌素效應(生理見 [[glucose-homeostasis#incretin]]):

| 作用部位 | 效果 |
|---|---|
| 胰臟 β 細胞 | 血糖高時 ↑胰島素分泌(血糖正常時作用減弱 → 單用少低血糖) |
| 胰臟 α 細胞 | ↓升糖素 → 肝臟產糖減少 |
| 胃 | **延緩胃排空** → 餐後血糖上升變慢(也是噁心的原因) |
| 下視丘 | ↑飽足感、↓食慾 → **體重下降** |
| 心血管、腎臟 | 部分藥物減少心血管事件、延緩腎病變 |

與 [[dpp4-inhibitors|DPP-4 抑制劑]]相比:GLP-1 RA 的藥理濃度遠高於生理值,降血糖與減重效果**強很多**,但腸胃副作用也較多。

**Tirzepatide** 同時活化 **GIP 與 GLP-1 受體**(雙重促效劑),降血糖與減重效果更強。

## 代表藥物 {#agents}

| 藥物 | 給藥 |
|---|---|
| Exenatide | 皮下,每天 2 次(另有每週劑型) |
| Liraglutide | 皮下,每天 1 次(高劑量用於肥胖) |
| Dulaglutide | 皮下,每週 1 次 |
| **Semaglutide** | 皮下每週 1 次;另有**口服**每天 1 次(空腹、少量水吞服,服後 30 分鐘再進食) |
| Tirzepatide(GIP/GLP-1) | 皮下,每週 1 次 |

(字尾多為 **-glutide**)

## 適應症 {#indications}

- 第二型糖尿病:合併**動脈硬化心血管疾病**、需要**減重**者優先;也可作為第一個注射藥(在胰島素之前)。
- **肥胖**:高劑量 liraglutide、semaglutide、tirzepatide 核准用於體重管理(不論有無糖尿病)。
- 不用於第一型糖尿病、不能取代胰島素。

## 副作用與禁忌 {#adverse-effects}

| 副作用 | 說明 |
|---|---|
| **噁心、嘔吐、腹瀉、便秘** | 最常見,通常在開始或加量時,數週後減輕;吃少量、吃慢、吃飽就停 |
| **急性胰臟炎** | 持續劇烈上腹痛放射到背 → 停藥就醫;有胰臟炎病史者避免 |
| 膽結石、膽囊炎 | 與快速減重有關 |
| **甲狀腺 C 細胞腫瘤** | 動物實驗發現 → **甲狀腺髓質癌或第二型多發性內分泌腫瘤(MEN2)個人或家族史禁用** |
| 脫水、急性腎損傷 | 嚴重嘔吐腹瀉時 |
| 糖尿病視網膜病變惡化 | 血糖快速大幅下降時,已有視網膜病變者要追蹤 |
| 注射部位反應 | 紅腫、搔癢 |
| 心跳加快 | 輕度 |

**懷孕**:應停藥(減重用途在計畫懷孕前停用)。

## 交互作用 {#interactions}

- **延緩胃排空** → 影響需要快速吸收的口服藥(如口服避孕藥、需要固定濃度的藥物)。
- 與[[insulin|胰島素]]或[[sulfonylureas|磺醯脲類]]併用 → 低血糖,常需減量。
- 麻醉:胃排空延遲增加**吸入性肺炎**風險,手術或內視鏡前需告知醫療團隊,依指示調整。

## 護理重點與衛教 {#nursing}

- **皮下注射**(腹部、大腿、上臂),**不是肌肉注射**;每週劑型固定在同一天。
- 由低劑量開始、逐步增加,以減少噁心;少量多餐、避免油膩。
- 教導胰臟炎、膽囊炎、脫水警訊。
- 詢問甲狀腺癌家族史。
- 減重效果停藥後常會回升,需搭配生活型態調整。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 腸泌素類似物的作用:**增加葡萄糖依賴性胰島素釋放、減少升糖素、減緩胃排空**;「增加葡萄糖從尿液排除」是錯的(那是 [[sglt2-inhibitors|SGLT2i]])。
- Exenatide 採**皮下注射**,「採肌肉注射」是錯的。
:::
