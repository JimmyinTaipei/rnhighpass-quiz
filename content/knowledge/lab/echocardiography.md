心臟超音波利用超音波即時看到**心臟的構造與動作**:心腔大小、心壁厚度、瓣膜開關、心包膜有沒有積液,以及最重要的**左心室射出分率(LVEF)**。它**無輻射、非侵入、可在床邊重複做**,是心衰竭分類、瓣膜疾病與心肌梗塞後評估的第一線影像檢查。

## 原理 {#principle}

- 探頭發出高頻聲波(成人約 2–5 MHz),遇到不同組織界面反射回來,依回波時間與強度組成影像。
- **M 型與 2D**:看構造與動作(心壁厚度、心腔大小、壁運動)。
- **都卜勒(Doppler)**:利用血流造成的頻率改變測量**血流方向與速度** → 評估瓣膜狹窄/逆流的嚴重度、估算**肺動脈收縮壓**、心室舒張功能;彩色都卜勒以紅(朝向探頭)、藍(遠離探頭)顯示。
- 可以計算**心搏量與心輸出量**(左心室出口面積 × 血流速度時間積分 × 心跳),所以心臟超音波、肺動脈導管、心導管都能評估心輸出量;**運動心電圖只看電氣變化,不能測心輸出量**。

### 經胸 vs 經食道 {#tte-tee}

| | 經胸(TTE) | 經食道(TEE) |
|---|---|---|
| 做法 | 探頭放在胸壁,病人**左側臥** | 像胃鏡一樣把探頭放入**食道**,從心臟正後方掃描 |
| 侵入性 | 非侵入、無痛 | 半侵入,需咽部麻醉 ± 鎮靜 |
| 優點 | 快速、床邊、可重複 | **左心房與心耳血栓**、人工瓣膜、感染性心內膜炎贅生物、主動脈剝離看得更清楚(沒有肋骨、肺、脂肪阻擋) |
| 限制 | 肥胖、COPD 肺氣腫、胸壁術後影像差 | 需禁食、有吸入與食道損傷風險 |
| 典型用途 | 心衰竭、EF、瓣膜、心包積液 | **心房顫動電擊整流前排除心耳血栓**、心內膜炎、術中監測 |

### 壓力超音波 {#stress-echo}

- 先做靜息影像,再以**運動**(跑步機/腳踏車)或**藥物**(Dobutamine 增加心跳與收縮力)增加心肌耗氧,比較前後的**壁運動**。
- 壓力下出現新的局部壁運動變差 → 該區冠狀動脈有**明顯狹窄(可誘發缺血)**。
- 低劑量 dobutamine 也可評估**存活心肌**(收縮力能改善 = 冬眠心肌,值得血管再通)。

## 適應症 {#indications}

- **心衰竭**:確認診斷、分類(EF)、找病因、追蹤治療反應。
- **急性胸痛/心肌梗塞**:新的**局部壁運動異常**、併發症(乳突肌斷裂致急性二尖瓣逆流、心室中膈破裂、心室游離壁破裂、左心室血栓、室壁瘤)。
- **瓣膜疾病**與心雜音、感染性心內膜炎。
- 心包膜積液、**心包填塞**(可導引心包膜穿刺)。
- 高血壓心臟病(左心室肥厚)、心肌病變、肺高壓、先天性心臟病(兒科)。
- 腦中風找心因性栓子(心房、心耳血栓,常需 TEE)。
- 休克鑑別(床邊超音波看收縮力、下腔靜脈、心包積液)。

## 檢查發現 {#findings}

### 射出分率與心衰竭分類 {#ef}

**LVEF = 每次收縮射出的血量 ÷ 舒張末期容積 × 100%**(詳見 [[cardiac-output#ejection-fraction]])。正常約 **55–70%**(ASE:男 52–72%、女 54–74%)。

| 分類 | LVEF | 說明 |
|---|---|---|
| **HFrEF**(射出分率降低) | **≤ 40%** | 收縮功能不良;藥物證據最完整(ARNI/ACEI/ARB、β 阻斷劑、MRA、SGLT2i) |
| **HFmrEF**(輕度降低) | **41–49%** | 介於中間 |
| **HFpEF**(射出分率保留) | **≥ 50%** | 舒張功能不良、心室僵硬;需有充填壓上升證據(如 BNP 升高、E/e′ 高) |
| **HFimpEF**(射出分率改善) | 原本 **≤ 40%**,追蹤時 **> 40%**(ESC、台灣另要求上升 ≥ 10 個百分點) | 仍需持續原治療 |

- 依據:2021 心衰竭通用定義、2022 AHA/ACC/HFSA(HFimpEF = 先前 ≤ 40%、追蹤 > 40%,經 [ACC Key Perspectives 摘要](https://www.acc.org/latest-in-cardiology/ten-points-to-remember/2022/03/29/19/53/2022-aha-acc-hfsa-heart-failure-guideline-gl-hf)核對)。舊教科書曾以 EF < 35–40% 為收縮性心衰竭、40–49% 為「灰色地帶」,國考以上表為準。
- **新分類不同處**:2023 台灣共識把 LVEF < 50% 都稱 HFrEF(再分 HFsrEF ≤ 40%、HFmrEF 41–49%),50–59% 為 HFpEF、≥ 60% 為 HFnEF(來源:[2023 台灣心臟學會慢性心衰竭藥物治療共識](https://doi.org/10.6515/ACS.202305_39%283%29.20230301A) p.4–5);2026 ESC **取消 HFmrEF**,只分 HFrEF(< 50%)與 HFpEF(≥ 50%),HFimpEF 定義為 EF 上升 ≥ 10 個百分點且 > 40%(來源:[2026 ESC 心衰竭指引](https://doi.org/10.1093/eurheartj/ehag100) p.16)。
- EF 越低,越容易有心律不整與猝死;最佳藥物治療 **≥ 3 個月**後 **EF 仍 ≤ 35%** 是考慮植入式去顫器(ICD)的條件之一(來源:[2026 ESC 心衰竭指引](https://doi.org/10.1093/eurheartj/ehag100) p.39)。
- 題目中「EF 12%」代表極嚴重的收縮功能不良。

:::exam[國考重點]
- **HFrEF ≤ 40%、HFmrEF 41–49%、HFpEF ≥ 50%**;正常 EF 約 55–70%。
- 心臟超音波、肺動脈導管、心導管**都能**評估心輸出量;**運動心電圖不能**。
- TEE 後要**確認吞嚥(作嘔)反射恢復**才可進食。
:::

### 其他重要發現 {#other-findings}

| 發現 | 意義 |
|---|---|
| **局部壁運動異常**(運動減弱、不動、反向運動) | 對應冠狀動脈供血區缺血或梗塞;**缺血時壁運動異常比心電圖變化更早出現**。可作為心肌梗塞定義中的「影像證據」 |
| 瓣膜狹窄 / 逆流 | 以都卜勒評估壓力差、瓣口面積與逆流程度(如二尖瓣狹窄 → 左心房擴大) |
| **心包膜積液** | 心臟周圍無回音(黑色)區;**心包填塞**時右心房、右心室在舒張期塌陷,下腔靜脈擴張不隨呼吸變化 |
| **左心室肥厚** | 心室壁(中隔或後壁)> 約 11–12 mm;常見於**長期高血壓**、主動脈瓣狹窄、肥厚性心肌病變(見 [[hypertension]]) |
| 心腔擴大 | 擴張性心肌病變、容積負荷(逆流) |
| 心內血栓 | 大面積前壁梗塞後的左心室心尖、心房顫動時的左心耳 |
| 舒張功能 | E/A、E/e′ 比值,估計左心室充填壓 |
| 肺動脈收縮壓 | 由三尖瓣逆流速度估算,評估肺高壓 |
| 下腔靜脈直徑與塌陷度 | 估計右心房壓、容積狀態 |

## 檢查前準備 {#preparation}

**TTE**

- **不需禁食**,不需特殊準備;穿方便露出胸部的衣服。
- 說明過程無痛、無輻射,約 20–45 分鐘;會在胸前塗凝膠、需左側臥並配合屏氣。
- 連接心電圖導線以對應心動週期。

**TEE**

- **禁食**:固體食物約 **6 小時**、清流質約 2 小時(依院內規定,常統一寫禁食 4–6 小時以上)→ 預防嘔吐吸入。
- 簽**同意書**;詢問**吞嚥困難、食道疾病(狹窄、靜脈曲張、手術)**、藥物過敏。
- **移除假牙**、放置牙墊保護探頭;建立靜脈管路(鎮靜用)。
- **咽部局部麻醉**(lidocaine 噴劑)± 靜脈鎮靜(如 midazolam);檢查中監測血氧、血壓、心電圖。
- 採**左側臥**,抽吸設備備妥。

**壓力超音波**:依醫囑檢查前禁食數小時、暫停 β 阻斷劑等影響心跳的藥物;穿適合運動的鞋。

## 檢查後護理 {#post-care}

- TTE:擦掉凝膠即可,無特殊限制。
- **TEE**:
  - **咽部麻醉退了、吞嚥(作嘔)反射恢復前禁食禁水**(約 1–2 小時);先試喝少量開水,不嗆咳才恢復進食。
  - 鎮靜者監測意識、呼吸、血氧,直到清醒;當天不可開車。
  - 喉嚨痛、輕微不適屬常見;**吞嚥疼痛、吐血、胸痛、發燒**須立即回報(懷疑食道損傷)。
- **壓力超音波**:監測生命徵象與心電圖直到恢復到基準值;觀察胸痛、心律不整。

## 併發症 {#complications}

| 檢查 | 可能併發症 |
|---|---|
| TTE | **幾乎沒有** |
| TEE | 喉嚨痛(最常見)、**吸入性肺炎**、鎮靜造成呼吸抑制/低血壓、咽部或**食道損傷/穿孔**(罕見)、心律不整、喉痙攣 |
| 壓力超音波 | 胸痛、心律不整、血壓變化;dobutamine 可引起心悸、頭痛 |
| 超音波顯影劑(微氣泡) | 罕見過敏反應 |

## 國考重點整理 {#exam-points}

:::exam[國考重點]
1. 心臟超音波評估**構造、瓣膜、EF、壁運動、心包積液**;無輻射、可床邊重複。
2. EF 分級:**HFrEF ≤ 40%、HFmrEF 41–49%、HFpEF ≥ 50%**,HFimpEF 為由 ≤ 40% 改善到 > 40%。
3. TEE:**禁食、咽部麻醉、術後吞嚥反射恢復前禁食**;看心耳血栓、心內膜炎最好。
4. 可評估心輸出量的檢查:心臟超音波、肺動脈導管、心導管;**運動心電圖不行**。
5. 瓣膜功能看超音波;心肌**灌流**範圍看**鉈-201 心肌灌注掃描**;電氣傳導看心電圖。
:::

## 相關檢查比較 {#related}

| 檢查 | 看什麼 | 備註 |
|---|---|---|
| 心臟超音波 | 構造、瓣膜、收縮與舒張功能、EF | 無輻射 |
| **鉈-201(Tl-201)心肌灌注掃描** | 心肌**血流灌注**:缺血或梗塞的**部位與範圍**、心肌存活性 | 放射性核種;存活且灌流好的心肌會攝取,缺血/壞死區呈「缺損」;常配合運動或藥物負荷 |
| 運動心電圖 | 運動誘發的 ST 下降(缺血) | 不能評估心輸出量、瓣膜 |
| 心臟 MUGA 掃描 | 精準測 EF | 放射性核種 |
| 冠狀動脈電腦斷層 | 冠狀動脈狹窄、鈣化分數 | 需顯影劑 |
| [[cardiac-catheterization]] | 冠狀動脈攝影、心內壓力 | 侵入性,可同時治療 |
