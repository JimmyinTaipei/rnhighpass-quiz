**全血球計數**(CBC)一次測出**白血球、紅血球、血紅素、血比容、紅血球指數與血小板**，是最常用的血液檢查：評估感染與發炎、貧血、出血風險，以及**化學治療後的骨髓抑制**。加做**白血球分類**(DC)後，就能算出最能反映感染風險的**絕對嗜中性白血球數**(ANC)。

## 重點摘要 {#summary}

- CBC 一次測出白血球、紅血球、血紅素、血比容、紅血球指數與血小板；加做白血球分類可算 **ANC**。
- **ANC = WBC × (seg% + band%)**；**ANC < 500/μL** 感染風險最高，採保護性隔離。
- 血小板 < 50,000 易出血、< 20,000 自發性出血、< 10,000 要評估意識狀態(顱內出血)。
- 脫水時 Hct 上升；MCV < 80 的孕婦先讓配偶驗 MCV(海洋性貧血帶因篩檢)。

### 國考常考點 {#exam-points}

- 白血球中**數量最多是嗜中性球**，**體積最大是單核球**。
- **ANC = WBC × (seg% + band%)**；**ANC < 500/μL** 感染風險最高，國考答案採**保護性隔離**；**嗜中性球比白血球總數更能反映感染風險**。
- 血小板 **< 50,000** 受傷易出血、**< 20,000** 自發性出血、**< 10,000** 評估**意識狀態**(顱內出血)；**8 萬不是正常值**。
- 要考慮暫停化療：**白血球 1,500、ANC 1,000**。
- **MCV 小於 80** 的孕婦 → 先讓**配偶驗 MCV**(海洋性貧血帶因篩檢)。
- 脫水時 **Hct 上升**，體液過量時 Hct 下降。
- 感染性單核球症：EBV 感染 **B 細胞**，血中**非典型淋巴球是活化的 T 細胞**。

## 檢驗項目與成人參考值 {#reference-range}

各醫院的方法與參考範圍略有差異，以報告為準；下表為常見範圍。

| 項目 | 參考值(成人) | 意義 |
|---|---|---|
| **白血球**(WBC) | 約 **4,000–10,000/μL** | 感染、發炎、骨髓功能 |
| **紅血球**(RBC) | 男 約 4.5–5.9 × 10⁶/μL；女 約 4.0–5.2 × 10⁶/μL | 攜氧細胞數目 |
| **血紅素**(Hb) | 男 約 **13.5–17.5 g/dL**；女 約 **12–16 g/dL**；孕婦 **≥ 11 g/dL** | **判斷貧血最主要的指標** |
| **血比容**(Hct) | 男 約 40–50%；女 約 36–46% | 紅血球占血液體積的比例；受**體液量**影響 |
| **平均紅血球容積**(MCV) | 約 **80–100 fL** | 紅血球大小，用來**分類貧血** |
| MCH、MCHC | MCH 約 27–33 pg | 每個紅血球的血紅素量(低 = 低色素) |
| RDW | 約 11.5–14.5% | 紅血球大小不一的程度 |
| **血小板**(PLT) | 約 **150,000–400,000/μL** | 凝血、出血風險 |
| 網狀紅血球 | 約 0.5–2% | 骨髓製造紅血球的能力 |

### 白血球分類 {#differential}

| 種類 | 比例 | 功能與上升的原因 |
|---|---|---|
| **嗜中性白血球**(segment + band) | 約 **50–70%**，**數量最多** | **吞噬細菌**；細菌感染、發炎、壓力、類固醇時上升 |
| 帶狀(band，不成熟) | 約 0–5% | 增加 = **左移**：骨髓急著釋放不成熟細胞，常見於**急性細菌感染** |
| **淋巴球** | 約 20–40% | 免疫(T、B、NK 細胞)；**病毒感染**、慢性淋巴性白血病；感染性單核球症出現**非典型淋巴球**(活化的 T 細胞) |
| **單核球** | 約 2–8%，**體積最大** | 進入組織成為巨噬細胞；慢性感染(結核)、恢復期 |
| **嗜酸性白血球** | 約 1–4% | **過敏、氣喘、寄生蟲感染** |
| 嗜鹼性白血球 | 約 0–1% | 釋放組織胺；過敏、慢性骨髓性白血病 |

## 絕對嗜中性白血球數(ANC) {#anc}

**ANC = 白血球總數 × (segment% + band%)**

白血球總數可能被淋巴球撐高，**ANC 才真正反映抵抗細菌感染的能力**，所以判斷感染風險要看 ANC，不是只看白血球總數。

| ANC(/μL) | 分級 | 感染風險與處置 |
|---|---|---|
| ≥ 1,500 | 正常 | 一般可以接受化學治療 |
| 1,000–1,500 | 輕度低下 | 風險輕微上升 |
| 500–1,000 | 中度低下 | 風險明顯上升，加強感染預防 |
| **< 500** | **重度低下** | **感染風險很高**；國考答案：採**保護性隔離** |
| < 100 | 極重度 | 持續超過 7 天屬於最高風險 |

(分級來源：[UpToDate：neutropenic fever](https://www.uptodate.com/contents/overview-of-neutropenic-fever-syndromes)；各機構的切點略有不同)

### 計算練習 {#anc-examples}

| 題目數據 | 計算 | ANC |
|---|---|---|
| WBC 2,500，band 30%，seg 20% | 2,500 × 50% | **1,250** |
| WBC 1,000，seg 26%，band 2% | 1,000 × 28% | **280** |
| WBC 1,200，seg 11%，band 1% | 1,200 × 12% | **144** |
| WBC 2,500，seg 8%，band 10% | 2,500 × 18% | **450** |
| WBC 3,000，seg 20%，band 5% | 3,000 × 25% | **750** |
| WBC 3,500，嗜中性球 13% | 3,500 × 13% | **455**(白血球總數看似只是輕度低下，其實已是**嚴重嗜中性白血球低下**) |

- **單核球、淋巴球不算進 ANC**。
- ANC 反映的是**感染風險**，不是出血風險(出血看**血小板**)，也不是用來判斷白血病是否緩解(緩解要看骨髓)。
- 臨床上一般**不因年齡**調整 ANC 的判讀切點(考題以「ANC 正常值隨年齡改變」為錯誤選項)。

## 偏高與偏低 {#high-low}

### 白血球 {#wbc}

| | 常見原因 |
|---|---|
| **白血球增加** | **細菌感染**、發炎、組織壞死(心肌梗塞、燒傷)、壓力、**類固醇**、懷孕；**白血病**(例：白血球 30 萬/μL 加上**費城染色體** → 慢性骨髓性白血病) |
| **白血球減少** | **化學治療**、放射治療、病毒感染、**再生不良性貧血**、紅斑性狼瘡、脾臟功能亢進、藥物(**clozapine**、抗甲狀腺藥、部分抗生素)、嚴重敗血症 |

老人或免疫低下者發生嚴重感染時，白血球可能**不上升**，甚至下降。

### 紅血球、血紅素與 MCV：貧血的分類 {#anemia}

| MCV | 類型 | 常見原因 |
|---|---|---|
| **< 80 fL** | **小球性**(常同時低色素) | **缺鐵性貧血**、**海洋性貧血**(台灣常見)、慢性病貧血 |
| 80–100 fL | 正球性 | **急性失血**、慢性病貧血、**腎衰竭**(紅血球生成素不足)、再生不良性貧血、溶血 |
| **> 100 fL** | **大球性** | **維生素 B12 或葉酸缺乏**(惡性貧血、胃切除)、酒精、肝病、methotrexate 等藥物 |

- **孕婦 MCV 偏低**(例：60 fL)：懷疑**海洋性貧血帶因**，優先安排**配偶也做 MCV 篩檢**；兩人都偏低才進一步做基因檢查與產前診斷。
- 懷孕中期血液稀釋，Hb 約 11 g/dL 仍屬正常(生理性貧血)。
- 貧血的表現：蒼白、疲倦、**心跳加快**、呼吸喘、頭暈；Hb 很低的兒童會有活動力差、心跳快、心雜音。

### 血比容 {#hematocrit}

- **體液不足**(脫水)：血液濃縮 → **Hct 上升**、BUN 上升、尿比重上升。
- **體液過量**：血液稀釋 → **Hct 下降**、BUN 下降。
- 紅血球增多症、長期缺氧(高山、慢性肺病)時 Hct 也上升。

### 血小板 {#platelets}

| 血小板(/μL) | 風險 | 護理 |
|---|---|---|
| 150,000–400,000 | 正常(**8 萬/μL 不是正常值**) | — |
| < 100,000 | 血小板減少 | 化療前常以 75,000–100,000 為可否給藥的參考 |
| **< 50,000** | 受傷、手術、侵入性處置時**容易出血** | 出血預防措施、避免侵入性處置 |
| **< 20,000** | **自發性出血**風險上升 | 軟毛牙刷或**海綿潔牙棒**、不用牙線、避免用力 |
| **< 10,000** | **自發性出血、顱內出血**高風險 | 評估**意識狀態**與神經學變化、頭痛；多數情況**預防性輸注血小板** |

- 血小板增多：發炎、缺鐵、脾臟切除後、骨髓增生疾病；過高會增加血栓風險。
- 凝血功能(PT、aPTT、INR)不在 CBC 內，要另外檢驗。

## 化學治療前後的判讀 {#chemotherapy}

- 化療後血球最低點約在 **7–14 天**，約 3–4 週恢復(見 [[antineoplastics#normal-tissue]])。
- 常見的暫緩化療參考：**白血球 < 3,000/μL**、**ANC < 1,000–1,500/μL**、**血小板 < 75,000–100,000/μL**(依療程與醫囑)。例：**白血球 1,500/μL、ANC 1,000/μL** 時要考慮暫停；紅血球 500 萬/μL、血小板 11 萬/μL 屬正常。
- 對應的護理措施(感染、出血、貧血)見 [[cancer-treatment-toxicities#myelosuppression]]。

## 檢體採集 {#specimen}

- 使用**紫色蓋(EDTA 抗凝劑)**採血管，採血後**輕輕上下顛倒混勻** 8–10 次，避免凝固；**不可用力搖晃**(溶血)。
- **不需空腹**；不要從正在輸液的手臂上方抽血(會被稀釋)。
- 血小板低下的病人，抽血後**加壓止血 5–10 分鐘**。

## 護理判讀 {#nursing}

- 看**趨勢**與病人的臨床表現，不要只看一個數字。
- 檢驗數值屬於**客觀資料**(例：「血紅素 8.8 g/dL」)；病人或家屬的陳述才是主觀資料。
- 白血球低下 → 感染預防；血小板低下 → 出血預防；血紅素低 → 活動耐受力、跌倒預防、依醫囑輸血。
