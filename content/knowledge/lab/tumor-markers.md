**腫瘤標記**是由腫瘤細胞製造，或身體對腫瘤反應而產生的物質，可以在**血液**、尿液或組織中測到。它們大多**不夠敏感也不夠專一**：良性疾病也可能上升，早期癌症卻可能正常，所以主要用途是**追蹤治療效果與偵測復發**，**不能單獨用來確診**，大多數也**不適合當篩檢工具**(來源：[NCI：Tumor Markers](https://www.cancer.gov/about-cancer/diagnosis-staging/diagnosis/tumor-markers-fact-sheet))。腫瘤的病理基礎見 [[neoplasia]]。

## 用途與限制 {#uses}

| 用途 | 說明 |
|---|---|
| **追蹤治療反應** | 治療後數值**下降**表示有效 |
| **偵測復發** | 治療後原本降到正常，又**持續上升** → 懷疑復發或轉移(例：大腸癌術後追蹤 **CEA**) |
| 評估預後、協助分期 | 數值很高常代表腫瘤負擔大 |
| 協助診斷 | 必須搭配影像與**切片病理**，不能單獨確診 |
| 篩檢(少數) | 只有特定高風險族群適用，例如**肝炎帶原者**以超音波加 **AFP** 追蹤肝癌 |

- 最好在**治療前先驗一次基準值**，之後看**趨勢**，不要只看單一數字。
- 數值**正常不代表沒有癌症**；**偏高也不一定是癌症**。

## 常用腫瘤標記 {#common-markers}

| 標記 | 主要相關癌症 | 其他會上升的情況(偽陽性) | 重點用途 |
|---|---|---|---|
| **CEA**(癌胚抗原) | **大腸直腸癌**；也見於胃癌、胰臟癌、肺癌、**乳癌** | **吸菸**、發炎性腸道疾病、肝硬化、胰臟炎 | **大腸直腸癌術前基準值與術後追蹤復發**、監測治療效果 |
| **AFP**(甲型胎兒蛋白) | **肝細胞癌**、非精原細胞性生殖細胞瘤(卵黃囊瘤) | **懷孕**(胎兒製造)、急慢性肝炎、肝硬化、新生兒 | 肝癌的**高風險族群追蹤**、治療後追蹤 |
| **CA-125** | **卵巢癌**(上皮性) | **子宮內膜異位症**、骨盆腔炎、**月經期**、懷孕、腹水、腹膜發炎 | 卵巢癌的治療反應與復發追蹤 |
| **CA19-9** | **胰臟癌**、膽道癌、胃癌 | **膽道阻塞**、胰臟炎、膽管炎 | 胰臟癌治療追蹤 |
| **CA15-3**(與 CA27.29) | **乳癌** | 良性乳房與肝臟疾病 | 監測**晚期或轉移性**乳癌的治療反應；**不能**用於早期診斷 |
| **PSA**(前列腺特異抗原) | **攝護腺癌** | **良性攝護腺增生**、攝護腺炎、**肛門指診、導尿、膀胱鏡或切片後**、射精後 | 治療後追蹤復發(根除手術後應測不到)；篩檢須與醫師討論利弊 |
| **β-hCG** | **妊娠滋養層疾病**(葡萄胎、絨毛膜癌)、睪丸生殖細胞瘤 | **懷孕** | 葡萄胎清除後追蹤到正常為止 |
| **Calcitonin**(抑鈣素) | **甲狀腺髓質癌** | — | 診斷與追蹤；家族性要篩 RET 基因 |
| Thyroglobulin(甲狀腺球蛋白) | 分化型甲狀腺癌(乳突癌、濾泡癌) | 甲狀腺仍存在時 | **全甲狀腺切除後**追蹤復發 |
| **EBV 抗體**(VCA IgA)、血漿 **EBV DNA** | **鼻咽癌** | EBV 感染 | 高風險者(家族史)篩檢、治療後追蹤 |
| LDH | 淋巴瘤、生殖細胞瘤、白血病 | 溶血、組織受損、**腫瘤溶解症候群** | 反映腫瘤負擔與預後 |
| β2-microglobulin、**M 蛋白**、尿液 **Bence Jones 蛋白** | **多發性骨髓瘤** | 腎功能不良 | 診斷、分期與追蹤 |
| NSE | 小細胞肺癌、神經母細胞瘤 | — | 追蹤 |
| 尿液 **VMA、HVA** | **神經母細胞瘤**(兒童) | 某些食物與藥物 | 診斷與追蹤 |

### 記憶口訣 {#mnemonic}

- **CEA → 大腸**，**AFP → 肝**，**CA-125 → 卵巢**，**CA19-9 → 胰臟**，**CA15-3 → 乳房**，**PSA → 攝護腺**，**β-hCG → 葡萄胎、絨毛膜癌**，**EBV → 鼻咽**，**calcitonin → 甲狀腺髓質癌**。
- 常見的錯誤配對：「CA-125 監測胰臟癌」(應是 CA19-9)、「AFP 監測肺癌」(應是肝癌)、「CA19-9 是乳癌標記」、「肝癌–CEA」、「CA15-3 用於早期診斷乳癌」。

### 參考值 {#reference-range}

各醫院的方法與正常值略有不同，以報告上的參考範圍為準。常見的大略上限：

| 標記 | 常見上限 |
|---|---|
| CEA | 約 **5 ng/mL**(不吸菸者約 3 ng/mL 以下) |
| AFP | 約 **10–20 ng/mL** |
| CA-125 | 約 **35 U/mL** |
| CA19-9 | 約 **37 U/mL** |
| CA15-3 | 約 **30 U/mL** |
| PSA | 常以 **4 ng/mL** 為參考，隨年齡增加 |

- 例：乳癌病人的 CEA 介於 1–3 ng/mL，只是**正常範圍**，不是乳癌的特徵。

## 干擾因素與檢體採集 {#interference}

- 一般為**血清**檢體，**不需空腹**。
- **PSA**：在**肛門指診、攝護腺按摩、導尿、膀胱鏡、切片**之前抽，或依規定間隔數天到數週後再抽；射精後可能暫時上升。
- **CA-125**：**月經期間**可能偏高，最好避開。
- **CEA**：**吸菸**者本來就偏高，判讀時要考慮。
- **AFP、β-hCG**：先排除**懷孕**。
- 追蹤時盡量在**同一家實驗室**、用同一種方法，數值才能互相比較。

## 護理與衛教 {#nursing}

- 向病人說明：腫瘤標記**正常不等於沒病、偏高也不等於復發**，醫師會搭配影像與症狀判斷，避免過度焦慮或輕忽。
- 治療後要**依排程回診抽血**，看的是**趨勢**。
- **B、C 型肝炎帶原者**、肝硬化病人：定期接受**腹部超音波**(常合併 **AFP**)追蹤肝癌。
- 腫瘤標記與傳染病無關：**AFP 不是**傳染病的檢驗項目(和肝炎抗原、抗體不同)。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **CEA**：**大腸直腸癌**術前診斷參考與**術後追蹤復發**；也可在乳癌等上升。
- **PSA**：攝護腺癌的偵測、治療與復發指標。**AFP**：肝癌。**CA-125**：卵巢癌。**CA19-9**：胰臟、膽道等消化道腫瘤。**EBV**：鼻咽癌。
- **CA15-3** 監測**晚期或轉移性**乳癌，**不是**早期診斷標記。
- 腫瘤標記用於**追蹤**，不能單獨確診，要搭配影像與病理。
:::
