心肌細胞一旦受損、細胞膜破裂,原本只存在細胞內的蛋白質與酵素就會漏進血液,抽血測得的濃度上升,這些物質就叫**心肌生化標記**(cardiac biomarkers,俗稱「心肌酵素」)。它們回答的問題是「**心肌有沒有壞死、壞死多久了**」,而不是「冠狀動脈有沒有狹窄」。現行指引以**心肌旋轉蛋白(cardiac troponin, cTn)**為唯一首選,CK-MB、Myoglobin、LDH 多屬輔助或舊考點,但國考仍常考它們的**時間順序**。

## 從哪裡來 {#origin}

### 心肌旋轉蛋白 Troponin {#troponin}

- **在哪裡**:Troponin(舊譯「旋轉素」,又稱肌鈣蛋白)是**橫紋肌(骨骼肌、心肌)肌節細肌絲上的調節蛋白複合體**,由三個次單元組成:

| 次單元 | 功能 | 心肌專一性 |
|---|---|---|
| **Troponin C(TnC)** | **結合 Ca²⁺**,啟動收縮的開關 | 心肌與慢縮骨骼肌相同 → **不用來診斷** |
| **Troponin I(TnI)** | **抑制**肌動蛋白與肌凝蛋白結合(放鬆狀態) | **心肌型 cTnI 與骨骼肌型胺基酸序列不同** → 心肌專一 |
| **Troponin T(TnT)** | 把整個複合體**固定在旋轉肌凝素(tropomyosin)**上 | **心肌型 cTnT** 有專一的抗體可測 |

- **生理角色**:動作電位使肌漿網釋出 Ca²⁺ → Ca²⁺ 結合 TnC → 複合體變形、拉開 tropomyosin → 肌動蛋白上的結合位露出 → 肌凝蛋白橫橋結合、收縮。平滑肌沒有 troponin,改由 **Ca²⁺-攜鈣素(calmodulin)** 啟動。
- **為什麼平常就測得到一點點**:健康人心肌細胞也有極少量的自然更新與凋亡,所以**高敏感度檢驗(hs-cTn)在大多數健康人都測得到微量**,因此「正常上限」是以健康族群的**第 99 百分位**來定,而不是「0」。
- **為什麼上升得久**:約 **3–8%** 的 troponin 游離在細胞質,細胞膜一破就先釋出(早期上升);其餘 **90% 以上**鎖在肌節結構中,要等壞死的肌原纖維慢慢被分解才陸續釋出 → 形成**長達 7–14 天**的高原期。
- **清除**:主要由網狀內皮系統清除;cTnT 的小片段部分經腎排除,所以**腎功能不全者 cTnT(與 cTnI)基準值常偏高**。

### 肌酸激酶 CK 與 CK-MB {#ck-mb}

- **CK(creatine kinase,舊稱 CPK,肌酸磷酸激酶)**:催化「磷酸肌酸 + ADP ⇄ 肌酸 + ATP」,是**高耗能組織的 ATP 緩衝庫**,集中在骨骼肌、心肌、腦。
- CK 由 M(muscle)與 B(brain)兩種次單元組成二聚體,形成三種**同功酶**:

| 同功酶 | 主要分布 | 臨床意義 |
|---|---|---|
| **CK-MM** | **骨骼肌**(約 98% 以上)、心肌(約 70–80%) | 橫紋肌溶解、肌肉損傷 |
| **CK-MB** | **心肌**(約占心肌 CK 的 **15–30%**);骨骼肌僅約 1–3% | 心肌損傷 |
| CK-BB | 腦、腸胃道、子宮、前列腺 | 臨床少用 |

- **為什麼 CK-MB「相對」心肌專一**:只有心肌含高比例的 MB 型;但骨骼肌量體太大,大量肌肉受傷時仍會讓 CK-MB 絕對值上升,因此會搭配 **CK-MB / 總 CK 比值(relative index)**:**> 2.5–3%** 較支持心臟來源。
- **為什麼 2–3 天就恢復**:CK-MB 在血中半衰期短(約 10–12 小時),不像 troponin 有結構性儲存,所以很快清掉——這正是它**用來判斷「再梗塞」**的理由(見[[cardiac-biomarkers#reinfarction]])。

### 肌紅素 Myoglobin {#myoglobin}

- **在哪裡**:**骨骼肌與心肌細胞質中**的攜氧蛋白(含一個血基質),在肌肉內暫存 O₂。
- **為什麼最早上升**:分子量最小(約 17.8 kDa),又游離在細胞質,細胞一破就可直接進入微血管,**1–3 小時**即上升。
- **為什麼最早恢復**:由**腎臟快速排除**,約 **24 小時**回到正常。
- **缺點**:骨骼肌也有,**專一性低**;現行指引已**不建議**用於急性心肌梗塞診斷(被 hs-cTn 取代)。

### 其他舊標記:LDH 與 AST {#ldh-ast}

- **LDH(乳酸脫氫酶)**:催化「丙酮酸 ⇄ 乳酸」,幾乎所有細胞都有,**專一性最低**。有 5 種同功酶:**LDH1 主要在心肌**與紅血球,LDH2 在網狀內皮系統。正常時血中 **LDH2 > LDH1(LDH1/LDH2 < 1)**;心肌梗塞時心肌大量釋出 LDH1,比值**翻轉成 > 1(flipped pattern)**。上升最慢(24–48 小時)、持續最久(10–14 天),過去用來診斷「就醫太晚」的梗塞,現已由 troponin 取代。
- **AST(GOT,麩胺酸草醋酸轉胺酶)**:存在心肌、肝、骨骼肌、紅血球;心肌梗塞後 6–12 小時上升、24–48 小時高峰、3–5 天恢復。因肝病也會上升,**已不用於心肌梗塞診斷**。

### 釋放機轉:為什麼大分子比較慢 {#release}

1. 冠狀動脈阻塞 → 心肌缺氧,**約 20–40 分鐘**開始出現不可逆壞死。
2. ATP 耗竭 → 細胞膜離子幫浦失效、細胞腫脹 → **細胞膜破裂**,胞內物質漏到組織間隙。
3. **小分子(Myoglobin)**可直接穿過微血管壁進血液 → 最快。
4. **較大的分子(CK-MB、troponin 複合體、LDH)**多先進入**心臟淋巴管**,經淋巴回流才入血 → 延遲數小時。
5. 早期**再灌流**(PCI、血栓溶解)會把壞死區的標記物一次「沖出來」(washout)→ **高峰提早且更高**,不代表梗塞更大。

## 時間表 {#timeline}

![急性心肌梗塞後肌紅素、CK-MB、Troponin、LDH 的上升、高峰與恢復時間示意](/knowledge-images/cardiac-biomarker-curve.svg)

| 標記 | 開始上升 | 高峰 | 恢復正常 | 專一性 |
|---|---|---|---|---|
| **Myoglobin** | **1–3 小時**(最早) | 6–12 小時 | **約 24 小時(最早恢復)** | 低(骨骼肌也有) |
| **CK-MB** | 3–6 小時 | 12–24 小時 | **2–3 天** | 中等 |
| **Troponin I / T** | 3–6 小時(**hs-cTn 1–3 小時**) | 24–48 小時 | **cTnI 7–10 天;cTnT 10–14 天** | **最高** |
| AST(GOT) | 6–12 小時 | 24–48 小時 | 3–5 天 | 低 |
| **LDH** | **24–48 小時(最晚)** | 3–6 天 | **10–14 天(最晚恢復)** | 最低(看 LDH1/LDH2 > 1) |

:::note[考試抓先後順序]
各教科書的時間略有出入(例如 CK-MB 開始上升寫 4–6 小時、LDH 高峰寫 48–72 小時),考試抓**先後順序**即可:
**上升先後:Myoglobin → CK-MB ≈ Troponin → AST → LDH;恢復先後:Myoglobin → CK-MB → AST → Troponin ≈ LDH。**
:::

:::exam[國考重點]
- **最具專一性**:cardiac **troponin I / T**(骨骼肌型與心肌型不同),比肌紅素、鉈-201 掃描、心電圖都專一。
- **最早上升、最快恢復**:**Myoglobin**(約 24 小時恢復)。
- **最晚上升、最晚恢復**:**LDH**;心肌梗塞時 **LDH1/LDH2 > 1**(翻轉),「LDH1/LDH2 < 1」是錯的。
- 晚就醫(3–7 天後)的梗塞:CK-MB 已恢復,看 **troponin**(或舊考法 LDH)。
- CPK 升高代表「組織損傷」,不一定是心臟;CK-MB 上升表示心肌受損。
:::

## 參考值 {#reference-range}

各醫院儀器不同,**以該院報告的參考值為準**;下表為常見範圍。

| 項目 | 常見參考值 | 說明 |
|---|---|---|
| **hs-cTnT** | **< 14 ng/L**(第 99 百分位) | 單一試劑、不分性別 |
| **hs-cTnI** | 依廠牌約 **< 16–34 ng/L**;多數建議**分性別**(女性較低) | 例:某廠牌女 < 16、男 < 34 ng/L |
| 傳統 cTnI(非高敏) | 約 **< 0.04 ng/mL** | 舊報告單位;1 ng/mL = 1000 ng/L |
| 總 CK | 男約 40–300、女約 25–200 U/L | 肌肉量、運動、種族背景差異大 |
| **CK-MB** | 質量法 **< 5 ng/mL**;活性法 **< 25 U/L** | 另看 CK-MB/總 CK > 2.5–3% |
| Myoglobin | 約 < 70–90 ng/mL | |
| LDH | 約 140–280 U/L | **LDH1/LDH2 < 1** 為正常 |
| AST(GOT) | 約 10–40 U/L | |

### 高敏感度 troponin 的判讀 {#hs-troponin}

**第四版心肌梗塞通用定義(Fourth UDMI, 2018)**把兩件事分開:

| 名詞 | 定義 |
|---|---|
| **心肌損傷**(myocardial injury) | 至少一次 cTn **> 第 99 百分位上限(URL)** |
| **急性**心肌損傷 | 上述 + cTn 有**明顯上升或下降(動態變化)** |
| **急性心肌梗塞** | 急性心肌損傷 + **心肌缺血的臨床證據**(缺血症狀、新的缺血性 ECG 變化、新出現病理性 Q 波、影像顯示新的壁運動異常、血管攝影見冠狀動脈血栓)之一 |

- **看「動態變化」比看單一數值重要**:慢性腎病、心衰竭的人 troponin 可以長期穩定地輕度偏高(慢性心肌損傷),**不是**心肌梗塞;急性梗塞則會在數小時內明顯升或降。
- **0/1 小時或 0/2 小時演算法**(2023 ESC ACS、2025 ACC/AHA ACS 皆列為建議):到院時(0 h)抽一次、1 或 2 小時後再抽一次。
  - **排除(rule-out)**:0 h 值極低(胸痛已 > 3 小時),或 0 h 低且 1–2 小時內幾乎沒變化 → 可安全出院或門診追蹤。
  - **納入(rule-in)**:0 h 值很高,或 1–2 小時內上升幅度超過該試劑切點 → 按 NSTEMI 處理。
  - **觀察區**:兩者都不符 → 3 小時後再抽,並配合心臟超音波等評估。
  - 切點**依試劑廠牌而不同**(例:hs-cTnT 0 h < 5 ng/L 可排除、≥ 52 ng/L 可納入),護理人員要知道的是「**時間點要抽準**」。
- 無法取得 hs-cTn 時,傳統 troponin 採 **0/3–6 小時**重複抽血。
- **STEMI 不等 troponin**:心電圖符合 [[ecg#acs-ecg|ST 上升型心肌梗塞]]就立即啟動再灌流,抽血結果不能延誤導管或血栓溶解治療。
- 其他定義用到的門檻:PCI 相關梗塞(4a 型)為 cTn > 5 倍 URL;CABG 相關梗塞(5 型)為 > 10 倍 URL。

### 再梗塞的判斷 {#reinfarction}

- 傳統教學:**troponin 會高 7–14 天**,若第 3–5 天又胸痛,troponin 還沒降下來,難以分辨是「舊的沒退」還是「新的梗塞」;**CK-MB 2–3 天就恢復**,若再度上升即代表**新的心肌壞死** → 所以過去用 **CK-MB 判斷再梗塞**。
- 第四版通用定義:改為懷疑再梗塞時**立即抽一次 cTn、3–6 小時後再抽**,第二次比第一次**上升 ≥ 20%** 即支持再梗塞(第一次若已下降中或穩定)。
- 國考若問「為何用 CK-MB 看再梗塞」,答「**恢復得快**」。

## 偏高的意義 {#high}

troponin 升高 = 心肌細胞受傷,**但不等於心肌梗塞**;要問「為什麼受傷」。

| 類別 | 原因 | 機轉 |
|---|---|---|
| **心臟:缺血** | **急性心肌梗塞(第 1 型:斑塊破裂血栓)** | 冠狀動脈阻塞 → 壞死 |
| | 第 2 型心肌梗塞 | 供需失衡:嚴重貧血、低血壓/休克、快速心律不整、呼吸衰竭 |
| **心臟:非缺血** | **心肌炎**、心包膜心肌炎 | 發炎直接破壞心肌細胞 |
| | **心衰竭**(急性或慢性) | 心室壁張力高、心內膜下缺血 |
| | **心臟挫傷**(胸部鈍傷) | 直接撞擊 |
| | **電擊、去顫、心肺復甦** | 電流或按壓損傷 |
| | **心導管、PCI、心臟手術、電燒後** | 操作所致 |
| | Takotsubo 心肌病變、主動脈剝離、嚴重主動脈瓣狹窄、快速心律不整 | |
| **非心臟** | **腎衰竭**(慢性腎病、透析) | 清除減少 + 左心室肥厚等慢性損傷 |
| | **敗血症**、重症 | 發炎介質、低灌流 |
| | **肺栓塞** | 右心室急性擴張受傷 |
| | **腦中風**、蜘蛛網膜下腔出血 | 交感神經暴衝 |
| | **劇烈耐力運動**(如馬拉松) | 可逆的輕度釋放 |
| | 化療藥(anthracycline)、一氧化碳中毒 | 心肌毒性 |

**CK、CK-MB 另會受骨骼肌影響**(troponin 不受影響):

| 原因 | 影響 |
|---|---|
| **肌肉注射(IM)**、手術、跌倒外傷、抽搐 | 總 CK 上升,CK-MB 可輕度上升 |
| 劇烈運動、橫紋肌溶解、肌炎、肌肉失養症 | 總 CK 大幅上升(以 CK-MM 為主) |
| 甲狀腺功能低下 | 總 CK 上升 |
| **Statin** 引起的肌病變 | 總 CK 上升(見 [[statins]]) |
| 腦部損傷、腸缺血、子宮/前列腺手術 | CK-BB 上升 |

- **Myoglobin**:骨骼肌傷害、橫紋肌溶解、腎衰竭(排除減少)都會上升。
- **LDH**:溶血、肝病、惡性腫瘤、肺栓塞、巨母紅血球性貧血等都會上升,專一性最低。
- 心肌梗塞時也會出現**非專一性的發炎反應**:白血球上升、CRP 上升、紅血球沉降速率變快、發燒(1–2 天內)。

## 偏低的意義 {#low}

- **偏低或測不到沒有臨床意義**,不代表疾病;這些物質本來就不該大量出現在血中。
- **但「單次陰性」不能排除心肌梗塞**:胸痛發生後太早抽血(< 3 小時,傳統檢驗)可能還沒上升 → 必須**依時間點重複抽血**(0/1、0/2 或 0/3–6 小時)。
- 心電圖正常 + troponin 正常,也可能是**穩定型或不穩定型心絞痛**(缺血但未壞死),仍需評估冠狀動脈疾病,見 [[coronary-artery-disease]]。
- CK 偏低:長期臥床、肌肉量少的長者可見,無特殊意義。

## 干擾因素 {#interference}

| 因素 | 影響 |
|---|---|
| **肌肉注射、近期手術、跌倒、劇烈運動** | CK、CK-MB、Myoglobin 假性上升(抽血前問清楚) |
| **溶血檢體** | LDH、AST、部分 CK 假性上升(紅血球含大量 LDH) |
| 腎功能不全 | troponin(尤其 cTnT)、Myoglobin 基準值偏高 |
| **Biotin**(維生素 B7)高劑量補充 | 部分免疫分析法(包含某些 troponin 試劑)**假性偏低** |
| 異嗜性抗體、類風濕因子、巨型肌鈣蛋白(macrotroponin) | 少數人 troponin 假性偏高 |
| 早期再灌流(PCI、血栓溶解) | 高峰提早、數值更高(washout) |
| 抽血時間點不正確 | 錯過上升或高峰,影響判讀 |

## 檢體採集與護理 {#nursing}

- **不需空腹**;靜脈血。troponin 常用肝素鋰(綠頭)或血清管,依院內規定。
- **記錄胸痛開始的時間**與**每次抽血的時間**——判讀完全依靠「距發病多久」與「兩次間的變化」。
- 依醫囑準時抽第二、第三次(0/1、0/2 或 0/3–6 小時);ACS 流程中**不因等報告延誤 12 導程 ECG(到院 10 分鐘內)與再灌流治療**。
- 懷疑 ACS 的病人**避免肌肉注射**(止痛改靜脈給藥),以免干擾 CK/CK-MB,也避免血栓溶解後血腫。
- 避免溶血:針頭不要太細、不要用力推入試管、不要劇烈搖晃。
- 追蹤趨勢而不是單一數值;高數值時同步觀察胸痛、生命徵象、心律與[[ecg#mi-evolution|心電圖的演變]]。
- 衛教:數值升高代表心肌受傷,不一定都是心臟病發作;需配合醫師後續檢查。

## 國考重點整理 {#exam-points}

:::exam[國考重點]
1. **心肌專一性最高**:cTnI / cTnT(TnC 不具專一性)。
2. **上升/恢復最快**:Myoglobin;**最晚**:LDH。
3. **CK-MB 2–3 天恢復** → 傳統用來看**再梗塞**;troponin 持續 7–14 天 → 適合**晚就醫**者。
4. 心肌梗塞 **LDH1/LDH2 > 1**(flipped)。
5. 題目給「Troponin I 15 ng/mL」(遠高於 0.04 ng/mL)→ 心肌細胞受損;「CK-MB 460 U/L」→ 明顯升高,不是正常。
6. **troponin 升高 ≠ 心肌梗塞**:腎衰竭、敗血症、肺栓塞、心肌炎、心衰竭都會升;要看**動態變化 + 缺血證據**。
7. 單次陰性不能排除,要**重複抽血**。
8. 鈣離子在骨骼肌/心肌結合 **troponin C**,在平滑肌結合 **calmodulin**。
:::
