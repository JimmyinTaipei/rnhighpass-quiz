看懂心電圖只需要一個觀念:**每一個波都是「電流走到心臟某個地方」的紀錄**。12 導程心電圖(12-lead ECG)從 12 個方向同時記錄心臟的電氣活動,是胸痛病人**第一個、也是最快**要做的檢查:看 ST 段與 T 波判斷「多嚴重、多久了」,看是哪幾個導程判斷「哪一面、哪一條血管」。

本頁涵蓋 12 導程的判讀基礎與缺血/梗塞;心律不整、傳導阻滯、電解質與 ACLS 流程另有專頁。電流的傳導路徑見 [[cardiac-output#conduction]],冠狀動脈解剖見 [[coronary-circulation#anatomy]]。

## 導程與電極位置 {#leads}

### 傳導系統與節律點 {#pacemakers}

心臟電流沿特化的傳導系統走:**SA node(竇房結)→ 心房 → AV node(房室結)→ His bundle → 左、右束支 → Purkinje 纖維 → 心室**。

- **SA node** 位在上腔靜脈與右心房交界,是正常的節律點。
- **AV node** 位在心房中膈下方、冠狀竇開口附近。電流在這裡**刻意放慢(AV delay)**,讓心房先收縮把血擠進心室,這段延遲就是心電圖上的 **PR 間期**。
- **Purkinje 纖維**傳導最快(約 4 m/s),兩側心室幾乎同時去極化,所以正常 QRS 很窄。

傳導系統每一段都有自動性,平常由最快的 SA node 帶頭(「誰跳得快誰當老大」):

| 節律點 | 自身速率 | 接手時的心電圖 |
|---|---|---|
| SA node | **60–100** 次/分 | 正常竇性節律 |
| AV 交界區 | **40–60** 次/分 | 窄 QRS,P 波倒置、看不到或在 QRS 後 |
| 心室(Purkinje) | **20–40** 次/分 | 寬 QRS,前面沒有 P 波 |

- **逸搏(escape)**:快的節律點停擺,次快的自動接手(例如 SA node 停擺,由交界區以 40–60 次/分帶頭)。
- **異位放電(ectopic)**:原本慢的節律點突然變快、超過 SA node,就搶走主導權(例如心室異位點以 150 次/分放電 = 心室心搏過速)。

### 導程原理:正極在哪裡 {#lead-principle}

每個導程就像一台從固定方向拍心臟的相機,相機放在導程的**正極**。

:::tip
**去極化電流朝著正極走 → 向上的正波;背離正極 → 向下的負波;與導程垂直 → 上下一樣大(雙向波)。** 再極化剛好相反。
:::

### 肢體導程(額面) {#limb-leads}

「左、右」指病人身體的左右。

| 導程 | 負極 → 正極 | 正極方向 | 角度 |
|---|---|---|---|
| I | 右手 → 左手 | 往左 | 0° |
| II | 右手 → 左腳 | 往左下 | +60° |
| III | 左手 → 左腳 | 往右下 | +120° |
| aVR | (中心)→ 右手 | 往右上 | −150° |
| aVL | (中心)→ 左手 | 往左上 | −30° |
| aVF | (中心)→ 左腳 | 往正下方 | +90° |

- **II、III、aVF** 的正極都在左腳,合稱**下方導程**,看心臟**下壁**;**I、aVL** 正極在左上,看**側壁**。
- 正常心室電流由右上往左下(約 +60°),正好朝著 Lead II 的正極 → **Lead II 的 QRS 最高、P 波最清楚**,所以監視器預設看 Lead II;反過來它背離 aVR → **aVR 幾乎全是負波**。
- I、II、III 是**雙極導程**(兩個電極相減);aVR、aVL、aVF 是**加壓單極導程**(一個電極對其他電極的平均)。

### 胸前導程(水平面) {#chest-leads}

V1–V6 的正極就是胸前那顆電極,由右前(V1)排到左側(V6)。V1 面對右心室,正常以負波為主;V6 面對左心室側面,以正波為主;中間約在 **V3–V4 轉正**(transition zone),稱為 R 波遞增(R wave progression)。

| 導程 | 位置 |
|---|---|
| V1 | 第 4 肋間、**胸骨右緣** |
| V2 | 第 4 肋間、**胸骨左緣** |
| V3 | V2 與 V4 連線的**中點** |
| V4 | 第 5 肋間、**左鎖骨中線** |
| V5 | 與 V4 同高(第 5 肋間)、**左前腋線** |
| V6 | 與 V4 同高(第 5 肋間)、**左腋中線** |

- **找肋間**:先摸胸骨角(Louis angle),旁邊是第 2 肋骨,往下數到第 4 肋間貼 V1、V2。
- **貼的順序**建議 V1 → V2 → V4 → V3 → V6 → V5(「124365」):V3、V5 都是「中點」,等兩邊貼好再貼。
- **肢體電極**貼四肢(手腕、腳踝內側或上臂、大腿),避開骨突;左右手貼反會讓 Lead I 整個倒過來。
- **加做導程**:下壁 MI 加做右胸導程 **V4R**(右鎖骨中線第 5 肋間)看右心室;懷疑後壁 MI 加做 **V7–V9**(與 V6 同高,往背後排)。

### 電極顏色 {#electrode-colors}

| 位置 | IEC(台灣多數機型) | AHA(美規) |
|---|---|---|
| 右手 RA | 紅 | 白 |
| 左手 LA | 黃 | 黑 |
| 左腳 LL | 綠 | 紅 |
| 右腳 RL(接地) | 黑 | 綠 |
| V1–V6 | 紅、黃、綠、棕、黑、紫 | 紅、黃、綠、藍、橘、紫 |

- **IEC**:「紅黃綠黑」從右手開始順時針——右手紅 → 左手黃 → 左腳綠 → 右腳黑(接地)。
- **AHA**:「White on right, smoke over fire, clouds over grass」——白在右手;左邊黑(煙)在紅(火)上;右邊白(雲)在綠(草)上。
- 顏色只是輔助,以導線頭上印的 RA、LA、V1…(或 R、L、F、N、C1…)字樣為準。

### 床邊監視器:3 導程與 5 導程 {#bedside-monitor}

連續心電監測的電極貼在**軀幹**(不貼四肢,活動時較不受干擾):

| 電極 | 位置 | IEC/AHA 顏色 |
|---|---|---|
| RA | 右鎖骨下方 | 紅/白 |
| LA | 左鎖骨下方 | 黃/黑 |
| LL | 左下肋緣或左下腹 | 綠/紅 |
| RL(5 導程才有) | 右下肋緣或右下腹 | 黑/綠 |
| V/C(5 導程才有) | 通常貼 V1 位置 | 白/棕 |

- 3 導程只能看 I、II、III 其中一條,**最常選 Lead II**(P 波最清楚)。
- 5 導程可同時看 Lead II 與 **V1**:V1 最適合分辨束支阻滯、寬 QRS 心搏過速。
- 貼前清潔擦乾皮膚(必要時剃毛);波形雜訊多時先檢查電極是否乾掉或脫落。

### 導程看的是心臟哪一面 {#lead-views}

| 導程 | 看的位置 | 主要供血 |
|---|---|---|
| II、III、aVF | 下壁 | 右冠狀動脈(RCA,多數人) |
| I、aVL、V5、V6 | 側壁 | 左迴旋支(LCx) |
| V1、V2 | 中膈 | 左前降支(LAD) |
| V3、V4 | 前壁 | 左前降支(LAD) |

與冠狀動脈的彩色對照見 [[#territory]]。

## 波形與間期 {#waves}

![正常心電圖波形:P 波、PR 間期、QRS、ST 段、T 波與 QT 間期](/knowledge-images/ecg-normal-complex.svg)

### 各波段代表什麼 {#components}

| 波段 | 代表的電氣活動 | 正常值(1 小格 = 0.04 秒) |
|---|---|---|
| **P 波** | **心房去極化** | 寬 < 3 小格(0.12 秒)、高 < 2.5 小格(Lead II);Lead II 圓鈍正波 |
| **PR 間期** | 心房開始去極化到心室開始去極化(主要是 AV delay) | **3–5 小格(0.12–0.20 秒)** |
| **Q 波** | 心室中膈去極化(由左往右) | 寬 < 1 小格、深 < R 波的 1/4 |
| **QRS 波** | **心室去極化** | **< 3 小格(< 0.12 秒)**,多為 0.06–0.10 秒 |
| **ST 段** | 心室已全部去極化、尚未再極化(沒有電位差) | **與基線同高**,J point 上下 < 1 小格 |
| **T 波** | **心室再極化** | 與 QRS 主波同方向;肢導高度 < R 波的 1/2 |
| **QT 間期** | 心室從去極化到再極化完成的總時間 | 約 0.35–0.44 秒,依心跳速率校正為 **QTc** |
| U 波 | 意義不明(可能是 Purkinje 再極化) | 小、常看不到;**低血鉀時明顯** |

- **心房再極化**發生在 QRS 期間,被體積大得多的心室去極化蓋掉,所以看不到。
- **J point**:QRS 結束、ST 段開始的轉折點;判斷 ST 上升或下降就是量 J point 相對於基線(TP 或 PR 段)的高度。

:::exam[國考重點]
- **P = 心房去極化、QRS = 心室去極化、T = 心室再極化**。「T 波表示心室去極化」是常見的錯誤選項。
- 電位傳導在 **AV node 延遲** → 形成 PR 間期。
:::

### 心電圖紙與格子 {#paper}

標準走紙速度 **25 mm/秒**,校正電壓 **10 mm = 1 mV**:

| 單位 | 橫向(時間) | 縱向(電壓) |
|---|---|---|
| **1 小格**(1 mm) | **0.04 秒** | 0.1 mV |
| **1 大格**(5 小格) | **0.20 秒** | 0.5 mV |
| **5 大格** | **1 秒** | — |

一張標準 12 導程記錄 **10 秒**:上三排每個導程 2.5 秒,最下面一條是 10 秒的 Lead II 節律條。

### 算心跳 {#heart-rate}

| 方法 | 算法 | 適用 |
|---|---|---|
| 大格法 | **300 ÷ 兩個 R 波之間的大格數** | 規則節律,最快 |
| 小格法 | **1500 ÷ 兩個 R 波之間的小格數** | 規則節律,最準 |
| 6 秒法 | 6 秒(30 大格)內的 QRS 數 × 10;或 10 秒整張 × 6 | **不規則節律**(例如心房顫動) |

- 口訣:R–R 間隔 **1、2、3、4、5、6 大格 → 300、150、100、75、60、50** 次/分。
- 成人正常 **60–100 次/分**;< 60 為心搏過慢,> 100 為心搏過速。

:::exam[國考重點]
- 相鄰兩個 R 波相隔 **5 大格 → 300 ÷ 5 = 60 次/分**。
- 看圖算心跳:數 R–R 之間的小格,1500 ÷ 小格數;例如約 21 小格 → 約 70 次/分。
:::

### 其他常考的波形變化 {#other-changes}

電解質與藥物對波形的影響另有專頁,這裡只列國考最常出現的對照:

| 狀況 | 心電圖 |
|---|---|
| **低血鉀** | T 波變平、**明顯 U 波**、ST 下降 → 易致**毛地黃中毒**([[potassium]]、[[digoxin]]) |
| **高血鉀** | **T 波高尖**(不是「低而寬」)→ 嚴重時 P 波消失、QRS 變寬 |
| 高血鈣 / 低血鈣 | **QT 縮短** / **QT 延長** |
| 延長 QT 的藥物 | 部分抗精神病藥(如 **thioridazine** 最明顯)、Class IA/III 抗心律不整藥等,易誘發多形性心室心搏過速 |
| 左心室肥厚 | QRS **電壓變高**(V1 的 S + V5/V6 的 R ≥ 35 mm)、可稍變寬,伴 ST-T 變化 |
| 人工節律器 | QRS(或 P 波)前的**激搏波(pacing spike)**是正常現象,代表節律器在放電 |

## 判圖步驟 {#reading-steps}

每一張心電圖都照同一個順序看,才不會漏:**節律 → 速率 → 電軸 → P 波 → PR → QRS(含 Q 波)→ ST 段 → T 波 → QT**。

| 步驟 | 看哪裡 | 在找什麼 | 正常 |
|---|---|---|---|
| 1. **節律** | 最下面的 Lead II 長條(10 秒) | RR 規不規則;每個 P 後有沒有 QRS | 最長 RR − 最短 RR < 4 小格(0.16 秒)為規則 |
| 2. **速率** | Lead II 長條 | 見 [[#heart-rate]] | 60–100 次/分 |
| 3. **電軸** | I、aVF(必要時 II) | 左偏/右偏 → 分支阻滯、心室肥厚 | I 與 aVF 都正 |
| 4. **P 波** | II、V1 | 竇性與否、心房擴大 | II 直立圓鈍 |
| 5. **PR 間期** | II | 長 → AV block;短 → 預激症候群 | 0.12–0.20 秒 |
| 6. **QRS** | V1、V6(再看 I、aVL) | 束支阻滯(寬)、心室肥厚(電壓)、**病理性 Q 波** | < 0.12 秒 |
| 7. **胸導 R 波** | V1 → V6 | transition 位置、R 波有沒有正常長高 | V3–V4 轉正 |
| 8. **ST 段** | 12 個導程逐一看、**成組比較** | 哪一區上升、對側有沒有下降 → 定位血管 | 與基線同高 |
| 9. **T 波、QT** | 全部導程 | 缺血、電解質、藥物;QT 延長 | T 與 QRS 同向 |

### 電軸 {#axis}

看 Lead I 與 aVF 的 QRS 主波方向(R > S 算正):

| | aVF 正 | aVF 負 |
|---|---|---|
| **Lead I 正** | **正常**(約 −30° ~ +90°) | 看 Lead II:II 正 → 仍屬正常;II 負 → **電軸左偏** |
| **Lead I 負** | **電軸右偏** | 極度右偏 |

- **左偏**:左心室肥厚、左前分支阻滯、下壁 MI。
- **右偏**:右心室肥厚、左後分支阻滯、側壁 MI、肺栓塞。
- **胸導轉正位置**:提早(V3 之前,逆時鐘旋轉)見於右心室肥厚、後壁 MI;延後(V4 之後,順時鐘旋轉)見於左心室肥厚、前壁 MI(R 波遞增不良)、LBBB。

### ST 段與 T 波 {#st-t}

- ST 段以 **J point** 對比基線(PR 段或 TP 段)來量,單位是 mm(小格)。
- 必須在**相鄰的 2 個以上導程**(同一區,例如 II、III、aVF)出現才有意義,單一導程的變化常是雜訊。
- ST 上升 → 損傷;ST 下降、T 倒置 → 缺血;詳見 [[#ischemia]]。

### 只看監視器還是一定要 12 導程 {#when-12-lead}

| 監視器(Lead II,最好加 V1)就能判斷 | 一定要做 12 導程 |
|---|---|
| 心跳速率、規則與否 | **胸痛、疑似急性冠心症**:ST 變化要成組看、找對側性變化、要定位 |
| 竇性過慢/過速 | 束支阻滯(需要 V1、V6)、分支阻滯(需要電軸) |
| PAC、PJC、PVC | 心房擴大、心室肥厚 |
| 心房撲動、心房顫動、PSVT | WPW 的 delta wave(只有部分導程明顯) |
| 各度 AV block | 心包膜炎(廣泛性 ST 上升) |
| VT、VF、Asystole | 寬 QRS 心搏過速的鑑別;準確量 QT、懷疑電解質異常 |

簡單說:**節律問題**(快慢、規不規則、有沒有下傳)看一條就夠;**位置與形狀的問題**(哪裡缺血、哪條束支、哪一側肥大)一定要 12 條一起看。監視器上新出現心律不整或 ST 變化,都應補一張 12 導程。

### 真實的正常 12 導程 {#normal-12-lead}

![正常 12 導程心電圖(正常竇性節律),上三排各導程 2.5 秒,最下面為 10 秒 Lead II 節律條。來源:PTB-XL #7](/knowledge-images/ecg-ptbxl-normal.svg)

用上面的步驟練習:規則、約 70 次/分、I 與 aVF 都正(電軸正常)、胸導在 V3–V4 附近轉正、P 波與 PR 正常、QRS 窄、ST 平、T 波與 QRS 同方向。

### 其他心電圖檢查 {#other-ecg-tests}

| 檢查 | 做法 | 用途 |
|---|---|---|
| **運動心電圖**(exercise stress test) | 跑步機或腳踏車逐級增加負荷,同時記錄 12 導程與血壓 | **誘發並評估心肌缺氧**(運動中 ST 下降 ≥ 1 mm 為陽性);**不能評估心輸出量** |
| 24 小時心電圖(Holter) | 攜帶式記錄器連續記錄 24–48 小時 | 抓陣發性心律不整、無症狀缺血,病人需同時寫活動與症狀日誌 |

運動心電圖期間出現胸痛、ST 明顯下降或上升、血壓下降、嚴重心律不整要立即停止;急性心肌梗塞、不穩定型心絞痛者禁做。評估心輸出量要靠心臟超音波、肺動脈導管或心導管([[echocardiography]]、[[cardiac-catheterization]])。

## 缺血、損傷、梗塞 {#ischemia}

冠狀動脈阻塞後,心肌依嚴重程度出現三種變化,心電圖各有代表(俗稱「3 I」):

![Lead II 示意:正常、ST 上升、ST 下降加 T 波倒置、病理性 Q 波](/knowledge-images/ecg-st-patterns.svg)

| 程度 | 心肌狀態 | 心電圖 |
|---|---|---|
| **缺血 ischemia** | 供氧不足,**可逆** | **ST 下降、T 波倒置** |
| **損傷 injury** | 全層受損中 | **ST 上升** |
| **梗塞 infarction** | 心肌壞死,**不可逆** | **病理性 Q 波** |

- **ST 上升**:J point 明顯高於基線,ST 段**弓背向上**、和 T 波連成一片(墓碑狀)。
- **ST 下降 + T 波倒置**:心肌缺血、NSTEMI,或 STEMI 對面導程的**對側性變化**。
- **病理性 Q 波**:壞死的心肌不再產生電流,電極「透過窗戶」看到對面心壁背離的電流而出現深 Q 波。國考常用定義是**寬 ≥ 1 小格(0.04 秒)或深度 > 同導程 R 波的 1/4**。
  - Fourth Universal Definition of MI 的定義:V2–V3 任何 Q 波 > 0.02 秒或呈 QS;其他導程 Q 波 ≥ 0.03 秒且深 ≥ 1 mm,出現在相鄰 2 個導程。
  - Q 波代表**全層(transmural)壞死**,不是「表層受損」。

### 心絞痛的心電圖 {#angina}

| 類型 | 發作時的心電圖 | 機轉 |
|---|---|---|
| 穩定型心絞痛 | **ST 下降**、T 倒置;休息緩解後恢復,平時可能完全正常 | 需氧增加時心內膜下缺血 |
| **變異型心絞痛**(Prinzmetal) | **ST 上升**(暫時性),緩解後回到基線 | 冠狀動脈**痙攣**,常在休息或清晨發作 |
| 不穩定型心絞痛 | ST 下降、T 倒置,或正常 | 斑塊破裂、未完全阻塞(見 [[#acs-ecg]]) |

:::exam[國考重點]
- **Q 波 = 心肌壞死(全層)**,出現後通常**永久存在**;「Q 波表示心肌受損在表層」是錯的。
- ST 段與 T 波的變化可協助判斷心肌是**缺血、損傷或壞死**。
- 變異型心絞痛發作時**ST 上升**;穩定型心絞痛由費力誘發、休息可緩解。
- 心電圖用來**快速分類與定位**,但診斷心肌受損**最具專一性**的是 **cardiac troponin**([[cardiac-biomarkers]])。
:::

## 急性冠心症的心電圖分類 {#acs-ecg}

| | 不穩定型心絞痛 UA | NSTEMI | STEMI |
|---|---|---|---|
| 心電圖 | ST 下降、T 倒置,或正常 | ST 下降、T 倒置,或正常 | **ST 上升**(或 STEMI 等同型) |
| 心肌酵素(Troponin) | 正常 | **上升** | **上升** |
| 心肌壞死 | 無 | 心內膜下 | **全層**(transmural) |
| 處置重點 | 抗血小板、抗凝、風險分層 | 同左,依風險決定心導管時機 | **立即再灌流**(PCI 或血栓溶解劑) |

- **UA 與 NSTEMI 的心電圖可以一模一樣**,要靠 troponin 區分;**STEMI 看到 ST 上升就立刻啟動再灌流,不必等酵素**。
- **STEMI 的 ST 上升標準**(Fourth Universal Definition of MI;2025 ACC/AHA ACS 指引 Table 3 沿用(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309))):**相鄰 2 個導程** J point 新發生上升
  - V2–V3 以外的導程:**≥ 1 mm**
  - V2–V3:男性 ≥ 40 歲 ≥ 2 mm、男性 < 40 歲 ≥ 2.5 mm、女性 ≥ 1.5 mm
- **缺血性 ST 下降**:相鄰 2 個導程新發生水平或下斜型 ST 下降 ≥ 0.5 mm,和/或 T 波倒置 > 1 mm(同上來源)。
- **新發生的 LBBB**:國考答案與舊教科書(2004 ACC/AHA)列為「視同 STEMI」;現行指引:新或推測為新的 LBBB **不應單獨作為急性心肌梗塞的診斷**,需配合臨床判斷;**無症狀者的新 LBBB 不是 STEMI 等同**(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309))。實務上依臨床表現與特殊判準(如 Sgarbossa)決定,疑似 ACS 合併新 LBBB 且血行動力不穩者仍要緊急處理。
- 後壁 MI(V1–V3 ST 下降、R 變高)屬於「看不到 ST 上升的 STEMI」:V1–V3 單獨 ST 下降 ≥ 0.5 mm 時加做 **V7–V9**(同上來源),見 [[#localization]]。

## 心肌梗塞的演變 {#mi-evolution}

![同一導程在 STEMI 不同時期的樣子:T 波高聳、ST 上升、T 波倒置、病理性 Q 波、ST 回基線而 Q 波永久留下](/knowledge-images/ecg-mi-evolution.svg)

| 階段 | 時間(約) | 心電圖 |
|---|---|---|
| ① 超急性期 | 數分鐘 | **T 波高聳**(hyperacute T) |
| ② 急性期 | 數分鐘至數小時 | **ST 上升** |
| ③ | 數小時至數天 | **T 波倒置** |
| ④ | 數小時至數天 | **病理性 Q 波出現** |
| ⑤ 陳舊期 | 數週後 | **ST 回到基線,Q 波永久留下**(T 波可能恢復或持續倒置) |

口訣:**「T 高 → ST 高 → T 掉 → Q 掉 → ST 回」**。陳舊性心肌梗塞只剩 Q 波,是判斷「以前發生過 MI」的依據。實際上 ③、④ 常同時出現,各期時間因再灌流治療而大幅縮短。

:::exam[國考重點]
MI 後最可能**永遠不會消失**的是**不正常 Q 波**;ST 上升與 T 倒置會隨時間恢復。
:::

## 冠狀動脈與 12 導程分區 {#territory}

三條主要冠狀動脈各自供應心臟的一面,而每一面剛好由固定的幾個導程「看著」。用同一個顏色對起來,就能從 ST 上升的導程反推阻塞的血管:

![冠狀動脈示意圖與 12 導程依心壁上色的對照](/knowledge-images/ecg-territory.svg)

- **右冠狀動脈 RCA**:沿右側房室溝繞到後面,多數人由它分出**後降支(PDA)**→ 供應**下壁**(II、III、aVF);多數人的 **SA node 與 AV node** 也由它供血 → 下壁 MI 常合併**竇性過慢、AV block**。
- **左前降支 LAD**:沿前室間溝往心尖走 → 供應**中膈**(V1、V2)與**前壁**(V3、V4);對角支供應高側壁。LAD 供應的心肌最多,阻塞時範圍最大(俗稱 widow maker)。
- **左迴旋支 LCx**:沿左側房室溝往後繞,分出鈍緣支 → 供應**側壁**(I、aVL、V5、V6)。

記法:下壁看「下面」的導程(II、III、aVF 正極都在左腳)、側壁看「左邊」的導程(I、aVL 正極在左手,V5、V6 在左腋下)、前壁看「前面」的胸前導程。冠狀動脈解剖與側枝循環見 [[coronary-circulation#anatomy]]。

## MI 定位 {#localization}

| 梗塞部位 | ST 上升的導程 | 通常阻塞的血管 | 對側性 ST 下降 |
|---|---|---|---|
| **下壁** inferior | **II、III、aVF** | **RCA**(少數為 LCx) | I、aVL |
| 中膈 septal | V1、V2 | LAD | — |
| **前壁** anterior | **V3、V4** | **LAD** | II、III、aVF |
| 前中膈 anteroseptal | V1–V4 | LAD | II、III、aVF |
| **側壁** lateral | **I、aVL、V5、V6** | **LCx**(或 LAD 對角支) | II、III、aVF |
| 廣泛前壁 | V1–V6、I、aVL | LAD 近端或左主幹 | II、III、aVF |
| 後壁 posterior | 沒有導程直接看得到:**V1–V3 ST 下降、R 波變高**(鏡像);V7–V9 ST 上升 | RCA 或 LCx | — |
| 右心室 | 右胸導程 **V4R ST 上升** | RCA 近端 | — |

### 對側性變化 {#reciprocal}

梗塞區**對面**的導程會出現 ST 下降(reciprocal change),例如下壁 MI 時 I、aVL 的 ST 下降。**有對側性變化更支持是真的 STEMI**,而不是心包膜炎或早期再極化。

### 右心室梗塞 {#rv-infarction}

下壁 MI 約三分之一合併右心室梗塞,**一定要加做 V4R**。右心室梗塞時右心室無力、非常依賴前負荷:

- 典型表現:低血壓、頸靜脈怒張、**肺音清澈**。
- **避免 Nitroglycerin、Morphine、利尿劑**等降低前負荷的藥物,可能導致嚴重低血壓;低血壓時依醫囑**輸液**。

:::exam[國考重點]
- **II、III、aVF 的 ST 上升(可合併 T 倒置)→ 下壁 MI**;「II、III、aVF ST 上升 = 前壁」是錯的。
- 前壁看 V3–V4(LAD)、側壁看 I、aVL、V5–V6(LCx)。
- 下壁 MI 注意心搏過慢/AV block 與右心室梗塞(慎用 NTG)。
:::

## 護理重點:疑似 STEMI {#stemi-nursing}

時間目標依 2025 ACC/AHA 急性冠心症指引(2025 AHA CPR/ECC 指引已不另列急性冠心症流程):

| 項目 | 時間目標 |
|---|---|
| 首次醫療接觸 → **完成並判讀 12 導程** | **≤ 10 分鐘**(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309)) |
| 首次醫療接觸 → 器械通過/氣球擴張(**PCI**) | **≤ 90 分鐘**(需轉院者 ≤ 120 分鐘)(同上來源) |
| 到院 → **血栓溶解劑** | **≤ 30 分鐘**(預估 PCI > 120 分鐘時;症狀發生 **12 小時內**)(時間目標來源:[2013 ACCF/AHA STEMI 指引](https://doi.org/10.1161/CIR.0b013e3182742cf6)) |

- **胸痛病人優先做 12 導程**:主訴胸悶痛、放射至肩膀、臉色蒼白,比常規給藥、止痛、胰島素更緊急。第一張沒有診斷意義而臨床仍高度懷疑,要**重複做**(傳統教學每 15–30 分鐘;2025 指引:依症狀、胸痛再發與臨床變化決定,同上來源)。
- **連續心電監測、備好去顫器**:急性 MI 最常見的死因是**心律不整**(尤其心室顫動)。
- 依醫囑給 **Aspirin 162–325 mg 嚼碎**、舌下 **Nitroglycerin**;血氧 **< 90% 才需給氧**;其他抗缺血藥無效的胸痛才給 Morphine 或 Fentanyl(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309))(劑量僅供參考,以醫囑為準)。
- **Nitroglycerin 前先量血壓**:收縮壓 < 90 mmHg 或比基準下降 > 30 mmHg、**右心室梗塞**(下壁 MI 要加做右胸導程)、近期用過 **PDE5 抑制劑**(sildenafil 24 小時、tadalafil 48 小時內)者不可給(同上來源;[[nitrates]])。
- 建立靜脈管路、抽血追蹤 **troponin**([[cardiac-biomarkers]]),但**不可因等待酵素或胸部 X 光延誤再灌流**。
- 焦慮的胸痛病人以解釋、陪伴為主;鎮靜劑(如 Lorazepam 靜注)不是急性冠心症的常規處置,可能掩蓋症狀、抑制呼吸。
- 再灌流藥物見 [[antiplatelets]]、[[anticoagulants]]、[[thrombolytics]];PCI 前後照護見 [[cardiac-catheterization]]。

## 心包膜炎與其他 ST 上升 {#pericarditis}

不是所有 ST 上升都是 STEMI。最常要鑑別的是**急性心包膜炎**:

![STEMI 的 ST 凸面向上且限於單一血管區域;心包膜炎的 ST 凹面向上、PR 段下降、分布廣泛](/knowledge-images/ecg-pericarditis.svg)

- **廣泛性 ST 上升**(幾乎所有導程,不符合單一血管分布),ST **凹面向上**(像笑臉)。
- **PR 段下降**(aVR 相反,PR 上升);**沒有對側性 ST 下降**(只有 aVR、V1 可能下降)、**不會出現 Q 波**。
- 臨床:尖銳胸痛,**坐起前傾時減輕**、平躺或深吸氣加重;可聽到**心包膜摩擦音**。

| | STEMI | 心包膜炎 |
|---|---|---|
| ST 上升分布 | 符合單一血管區域 | 廣泛、多數導程 |
| ST 形狀 | **凸面**(弓背向上) | **凹面**(笑臉) |
| 對側性 ST 下降 | **有** | 沒有(只有 aVR、V1 可能下降) |
| PR 段下降 | 沒有 | **有** |
| Q 波 | 之後會出現 | 不會 |

### 進階:良性早期再極化 {#early-repolarization}

年輕健康的人(尤其男性、運動員)常在胸前導程看到**凹面向上的 ST 上升**,J point 有小缺口(J wave / notching),屬於正常變異(benign early repolarization, BER)。與心包膜炎的區別之一:**V6 的 ST 上升高度 ÷ T 波高度 < 0.25 偏向 BER,≥ 0.25 偏向心包膜炎**。BER 的形態穩定、不隨時間演變,也沒有對側性變化;有疑慮時與舊心電圖比較並追蹤。

其他會造成 ST 上升的情況:左心室肥厚、LBBB、心室動脈瘤(陳舊 MI 後 ST 持續上升)、高血鉀、Brugada 症候群、變異型心絞痛。

## 國考重點整理 {#exam-points}

- **P 心房去極化、QRS 心室去極化、T 心室再極化**;AV node 延遲形成 PR 間期。
- **1 小格 0.04 秒、1 大格 0.2 秒**;心跳 = 300 ÷ 大格數 = 1500 ÷ 小格數;5 大格 = 60 次/分。
- **V1、V2 第 4 肋間胸骨右/左緣;V4 第 5 肋間鎖骨中線;V5 左前腋線、V6 左腋中線(與 V4 同高)**。
- **缺血 ST 下降/T 倒置、損傷 ST 上升、梗塞 Q 波**;Q 波代表全層壞死且**永久存在**。
- **II、III、aVF = 下壁(RCA)**;V1–V4 = 前中膈(LAD);I、aVL、V5、V6 = 側壁(LCx)。
- UA 與 NSTEMI 心電圖可相同,靠 **troponin** 區分;STEMI 立即再灌流,血栓溶解劑於症狀 **12 小時內**。
- 胸痛病人 **10 分鐘內完成 12 導程**,優先於其他常規工作。
- 變異型心絞痛發作時 **ST 上升**;心包膜炎是**廣泛凹面 ST 上升 + PR 下降**、坐起前傾緩解。
- 運動心電圖評估**心肌缺氧**,不能評估心輸出量。
- 低血鉀 **U 波** → 毛地黃中毒風險;高血鉀 **T 波高尖**。
