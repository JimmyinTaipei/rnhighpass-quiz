腎臟的主要工作是過濾，所以「腎功能」通常就是指**腎絲球過濾率**(GFR, glomerular filtration rate)。臨床上不直接量 GFR，而是用血中的**肌酸酐**、**尿素氮**，以及由肌酸酐算出的 **eGFR**(estimated glomerular filtration rate) 或 24 小時尿液的**肌酸酐清除率**來估計。尿液檢查見 [[urinalysis]]、白蛋白尿見 [[uacr]]、生理見 [[kidney-urinary-physiology#clearance]]

## 重點摘要 {#summary}

- 評估腎功能**最好的抽血指標是血清肌酸酐**；估 GFR 最常用 **eGFR**(由肌酸酐、年齡、性別算出)或**肌酸酐清除率**
- **肌酸酐**來自肌肉的肌酸，產量與**肌肉量**有關、**不太受飲食影響**；腎功能要喪失約 **50% 以上**血清肌酸酐才明顯上升
- **BUN**(blood urea nitrogen) 是蛋白質代謝的產物，受**蛋白質攝取、脫水、腸胃道出血、組織分解、類固醇**影響而上升，**肝衰竭、低蛋白飲食**時下降；BUN 高不一定是腎臟壞
- **BUN/Cr 比值**正常約 **10–20**：> 20 想到**脫水、腎前性**、腸胃道出血；下降想到**肝衰竭**、低蛋白
- **肌酸酐清除率(CCr, creatinine clearance)**正常約 **95–135 mL/min**(國考答案；課本男 90–139)；CCr ＝(尿肌酸酐 × 每分鐘尿量)÷ 血清肌酸酐
- eGFR **< 60 mL/min/1.73 m² 持續 3 個月以上**就算慢性腎臟病；分期 G1–G5 見下表

### 國考常考點 {#exam-points}

- 最能顯示腎功能受損的是**血清肌酸酐升高**；檢測 GFR 最佳指標是**肌酸酐清除率**(不是尿液培養、KUB，kidney, ureter and bladder X-ray 或酚紅試驗)
- 健康檢查最常用的腎功能指標是**肌酸酐**(菊糖是研究用的標準，臨床不常做)
- 肌酸酐「**易受飲食影響**」是**錯誤**敘述(課本：主要來自肌肉，較不受飲食與液體攝取影響，比 BUN 更適合追蹤腎功能)；肌酸酐升高代表腎功能已損傷 50% 以上、GFR 已下降
- **BUN 升高可能只是脫水**，不一定是腎功能差；課本要求 BUN 與肌酸酐空腹抽血，「不受飲食影響、不需空腹」是錯誤選項
- BUN/Cr 比值：**脫水 → 上升**；**肝衰竭 → 下降**；正常不是 30:1 或 40:1
- CCr 正常值 **95–135 mL/min**
- 計算：24 小時尿量 1,500 mL、尿肌酸酐 40 mg/dL、血清肌酸酐 0.8 mg/dL → CCr ＝ 40 ×(1,500 ÷ 1,440)÷ 0.8 ≈ **52 mL/min**
- GFR 20 mL/min/1.73 m² → CKD **第 4 期**；GFR 53 的長者約是正常的一半(不是 70%)，老年 GFR 本來就會下降

## 參考值 {#reference-range}

| 項目 | 成人參考值 | 備註 |
|---|---|---|
| **BUN** | 5–25 mg/dL(《內外科護理學》下冊 p.780；各院約 7–20) | 兒童較低 |
| **血清肌酸酐** | 約 0.7–1.4 mg/dL(同上)；女性略低 | 依檢驗室；肌肉量大的人較高 |
| **BUN/Cr** | 10:1–20:1(同上) | |
| **肌酸酐清除率** | 課本：男 90–139、女 80–125 mL/min(同上 p.783)；國考答案 95–135 mL/min | 24 小時尿液計算 |
| **eGFR** | ≥ 90 mL/min/1.73 m² | 隨年齡下降 |

- 參考值依各醫院檢驗室為準；國考 CCr 答案為 95–135 mL/min(109-2_MS_065)，和課本範圍大致重疊

## 肌酸酐 {#creatinine}

- 來源：肌肉中的肌酸代謝成肌酸酐，每天產量相當固定
- 腎臟處理：自由**過濾**、少量由腎小管**分泌**、不再吸收 → 很適合估 GFR
- 限制(ICU Book 5e Ch34)
   1. 受**肌肉量**影響：老人、臥床、營養不良、截肢者肌肉少，肌酸酐看起來「正常」但 GFR 其實已降
   2. 受血漿容積影響：大量輸液稀釋
   3. 腎小管會分泌一部分 → 腎功能差時高估 GFR
   4. 急性腎損傷時肌酸酐上升**落後**於真正的 GFR 下降
- GFR 和肌酸酐呈**反比曲線**：早期 GFR 掉一半肌酸酐才從 1 升到 2；後期 GFR 小幅下降肌酸酐就大幅上升
- 升高：腎功能下降(急性或慢性)、尿路阻塞、橫紋肌溶解、大量肉類(輕微)、某些藥物干擾分泌(如 trimethoprim)

## 尿素氮(BUN) {#bun}

- 來源：蛋白質分解 → 氨 → **肝臟**合成尿素 → 由腎臟排出；部分尿素在腎小管被再吸收(水分回收多時，尿素回收也多)

| BUN 上升 | BUN 下降 |
|---|---|
| 腎功能下降(急、慢性腎衰竭) | **肝衰竭**(尿素合成減少) |
| **脫水**、休克、心衰竭(腎前性) | 低蛋白飲食、營養不良 |
| **上腸胃道出血**(血液蛋白被消化吸收) | 水分過多(稀釋)、妊娠 |
| 高蛋白飲食、管灌高蛋白 | |
| 組織分解：燒傷、發燒、感染、類固醇 | |

- 「BUN 升高可能是脫水，不一定表示腎臟功能不佳」是正確敘述(課本 p.780 同)
- **氮血症**：BUN 與肌酸酐上升；合併尿毒症狀(噁心、意識改變、搔癢、出血傾向)稱**尿毒症**

::questions{ids="112-3_MS_040"}

## BUN/Cr 比值 {#bun-cr-ratio}

| 比值 | 意義 |
|---|---|
| **> 20:1** | **腎前性**(脫水、出血、心衰竭)、上腸胃道出血、高蛋白、組織分解 |
| 10–20:1 | 正常，或腎因性(腎小管壞死時兩者同步上升) |
| **< 10:1** | **肝衰竭**、低蛋白飲食、營養不良、橫紋肌溶解(肌酸酐升得多) |

- 嚴重腹瀉與發燒會造成脫水與分解增加 → 比值**上升**，不是下降
- 腎前性與腎性急性腎損傷的其他尿液指標(尿鈉、比重、滲透壓)見 [[acute-kidney-injury#diagnosis]]

::questions{ids="106-1_MS_065,110-2_MS_036"}

## 肌酸酐清除率(CCr) {#ccr}

- 公式：**CCr ＝(Ucr × V)÷ Pcr**
   1. Ucr：尿液肌酸酐濃度(mg/dL)
   2. V：每分鐘尿量(mL/min)＝24 小時尿量 ÷ 1,440
   3. Pcr：血清肌酸酐(mg/dL)
- 需收 **24 小時尿液**(做法見 [[urinalysis#24-hour-urine]])，收集當天抽血測血清肌酸酐
- 因為肌酸酐有少量被分泌，CCr 會**略高於**真正的 GFR
- 例題(105-1_MS_065)：尿量 1,500 mL/24 h → 約 1.04 mL/min；40 × 1.04 ÷ 0.8 ≈ **52 mL/min**
- 不收尿的估算：**Cockcroft-Gault** 公式(用年齡、體重、性別、血清肌酸酐估 CCr)，藥物劑量調整常用

::questions{ids="109-2_MS_065,106-2_MS_058,105-1_MS_065"}

## eGFR 與慢性腎臟病分期 {#egfr}

- **eGFR** 用血清肌酸酐加上年齡、性別計算，以每 1.73 m² 體表面積表示；KDIGO(Kidney Disease: Improving Global Outcomes) 2024 建議使用 **CKD-EPI** 方程式，必要時合併 **cystatin C**(胱抑素 C，不受肌肉量影響)
- 台灣健檢報告常用 MDRD(Modification of Diet in Renal Disease) 或 CKD-EPI 公式

| GFR 分期 | eGFR(mL/min/1.73 m²) | 描述 |
|---|---|---|
| G1 | ≥ 90 | 正常或偏高(需有腎損傷證據才算 CKD) |
| G2 | 60–89 | 輕度下降 |
| G3a | 45–59 | 輕到中度下降 |
| G3b | 30–44 | 中到重度下降 |
| G4 | 15–29 | 重度下降 |
| G5 | < 15 | 腎衰竭 |

- 分期數字依 KDIGO(2012 版提出、2024 版沿用)；白蛋白尿分級 A1–A3 見 [[uacr]]
- 年齡增加 GFR 自然下降，但 eGFR < 60 持續 3 個月以上仍算 CKD 第 3 期，要評估水腫、倦怠與飲食
- 112-1_PC_077：GFR 53 約是正常成人 GFR(約 100–125)的**一半**，說「約 70%」是錯的

::questions{ids="107-1_MS_066,112-1_PC_077"}

## 干擾因素 {#interference}

| 因素 | 影響 |
|---|---|
| 肌肉量多、大量肉類 | 肌酸酐偏高 |
| 老年、臥床、截肢、營養不良 | 肌酸酐偏低，高估腎功能 |
| 高蛋白、腸胃道出血、類固醇、tetracycline | BUN 上升 |
| 大量輸液、妊娠 | BUN、肌酸酐下降(稀釋、GFR 上升) |
| 腎毒性藥物(aminoglycoside、顯影劑、NSAIDs，nonsteroidal anti-inflammatory drugs) | 真的造成腎功能下降，用藥前後要追蹤 |

## 檢體採集與護理 {#nursing}

- 靜脈血，生化管；課本寫**抽血前一天午夜後禁食、隔日空腹抽血**(p.780)，實務依各院規定；國考「不受飲食影響，不需要空腹」是錯誤選項(112-3_MS_040)
- 做 CCr 時同時正確收集 24 小時尿液並記錄總量、身高體重
- 腎功能差的病人：注意藥物劑量調整、避免腎毒性藥物(aminoglycoside、NSAIDs、顯影劑；老年合併脫水更容易受傷，課本 p.783)、注射顯影劑前確認腎功能(檢查見 [[urologic-diagnostic-procedures]])
