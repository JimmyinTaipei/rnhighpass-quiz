血脂檢查一次抽血測四個數值:**總膽固醇(TC)**、**三酸甘油酯(TG)**、**HDL 膽固醇**,以及直接測量或用公式算出的 **LDL 膽固醇**。它反映血中脂質的運送狀態,是評估**動脈粥狀硬化與冠心病風險**、決定是否使用 [[statins]] 的核心檢查。

## 從哪裡來 {#origin}

![脂蛋白的來源與去向](/knowledge-images/lipoprotein-pathways.svg)

### 膽固醇 {#cholesterol}

- **來源**:約 **70–80% 由身體自行合成**(主要在**肝臟**,其次是小腸;幾乎所有細胞都能合成),其餘來自食物(動物性食品:蛋黃、內臟、海鮮、肥肉)。所以只靠飲食控制,膽固醇通常只能降一點;statin 抑制肝臟合成才能大幅降低。
- **功能**:構成**細胞膜**;合成**類固醇激素**(皮質醇、醛固酮、性激素 — 都是膽固醇衍生物)、**膽酸**(乳化脂肪)與**維生素 D**。
- 為什麼在血中:膽固醇是脂溶性的,不溶於血漿,必須包在**脂蛋白**中運送,所以血中的膽固醇其實是「LDL 裡的膽固醇 + HDL 裡的膽固醇 + VLDL 裡的膽固醇」。

### 三酸甘油酯(TG) {#triglyceride}

- **來源**:① **食物中的脂肪**,在小腸吸收後包成乳糜微粒;② **肝臟**把多餘的**醣類與酒精**轉成 TG,包成 VLDL 送出。
- **功能**:身體主要的**能量儲存形式**;由血管壁上的**脂蛋白脂解酶(LPL)**分解成脂肪酸,供肌肉燃燒或存入脂肪組織。
- 進食後數小時內血中 TG 大幅上升,**9–12 小時**後乳糜微粒才清除 → 這是 TG 要空腹驗的原因。

### 脂蛋白 {#lipoproteins}

脂蛋白是「外層蛋白質與磷脂、內核 TG 與膽固醇」的運輸顆粒。**蛋白質比例越高,密度越高**。

| 脂蛋白 | 在哪裡製造 | 主要內容 | 功能 | 臨床意義 |
|---|---|---|---|---|
| **乳糜微粒**(chylomicron) | **小腸**上皮細胞,經**乳糜管(淋巴)**進入血液 | **TG 最多**(食物來源);另含膽固醇、脂溶性維生素 | 把**食物中的脂肪**送到肌肉、脂肪組織 | 飯後出現;空腹時應幾乎沒有;極高 TG 時可致**急性胰臟炎** |
| **VLDL**(極低密度) | **肝臟** | **TG 為主** | 把肝臟製造的 TG 送到周邊 | TG 中的主要部分(空腹時);VLDL-C ≈ TG/5 |
| IDL(中密度) | VLDL 被 LPL 分解後 | TG 與膽固醇 | 過渡型 | 一部分回肝臟,其餘變成 LDL |
| **LDL**(低密度) | 由 VLDL → IDL 轉變而來 | **膽固醇最多**,蛋白質比例低(ApoB-100) | 把膽固醇送到**周邊細胞**(經 LDL 受體),多數最後由肝臟收回 | 過多時進入動脈內膜、氧化 → 巨噬細胞吞噬成**泡沫細胞** → **粥狀斑塊**:「**壞膽固醇**」 |
| **HDL**(高密度) | **肝臟、小腸**(ApoA-I) | **蛋白質最多**、密度最高 | 從周邊組織與動脈壁**撿回多餘膽固醇**送回肝臟(**逆向膽固醇運輸**),肝臟做成膽酸排除 | 保護因子:「**好膽固醇**」 |

:::note[補充]
**「低密度」≠「脂肪少」**。LDL 密度低是因為**脂質(膽固醇)比例高、蛋白質比例低**;HDL 蛋白質最多所以密度最高。
:::

**性別荷爾蒙**:雌激素使 LDL↓、HDL↑(停經前女性的保護作用);停經後雌激素下降 → LDL↑、**HDL↓**、心血管病增加。雄性素使 LDL↑、HDL↓,這是男性冠心病較早發生的原因之一。

## 參考值 {#reference-range}

依 NCEP ATP III 分級(國內健檢與國考沿用),單位 mg/dL:

| 項目 | 理想 | 邊緣 | 偏高 |
|---|---|---|---|
| **總膽固醇(TC)** | **< 200** | 200–239 | **≥ 240** |
| **LDL-C** | **< 100**(最適)| 100–129 接近最適;**130–159 邊緣偏高** | 160–189 高;**≥ 190 極高** |
| **HDL-C** | **≥ 60 具保護作用** | — | **過低:男 < 40、女 < 50** |
| **TG**(空腹) | **< 150** | 150–199 | **200–499 高;≥ 500 極高**(≥ 1,000 胰臟炎風險明顯) |
| Non-HDL-C(= TC − HDL) | < 130 | | 包含所有致動脈硬化脂蛋白,非空腹也可用 |

:::exam[國考重點]
- 國考常用「正常值」:**TC < 200、LDL < 130(較新題目用 < 100)、HDL 男 > 40 女 > 50、TG < 150**。
- 「空腹 8 小時以上 TG ≥ **200** mg/dL 屬高血脂(高三酸甘油酯血症)」— 150–199 屬邊緣偏高。
- LDL 135、170 → 偏高(異常);HDL 60、130 → 正常(越高越好);總膽固醇 150、170、190 → 正常。
:::

單位換算:膽固醇 mg/dL ÷ **38.7** = mmol/L;TG mg/dL ÷ **88.6** = mmol/L。

### LDL 的計算:Friedewald 公式 {#friedewald}

許多檢驗室的 LDL 不是直接測量,而是用公式算:

**LDL-C = TC − HDL-C − TG/5**(單位 mg/dL;TG/5 代表 VLDL 中的膽固醇)

- 例:TC 220、HDL 45、TG 150 → LDL = 220 − 45 − 30 = **145** mg/dL。
- **限制**:TG **> 400 mg/dL**、未空腹(有乳糜微粒)、LDL 很低(< 70)時不準確 → 改用**直接 LDL 測定**或較新的 Martin-Hopkins、Sampson 公式。

### LDL 目標值(依風險) {#targets}

LDL 治療目標是「**風險越高,目標越低**」,沒有單一正常值。各指引建議(mg/dL):

| 族群 | 台灣血脂指引(2017 高風險族群) | 2018 AHA/ACC(2025 ACS 指引更新) | 2019 ESC/EAS(2023 ESC ACS) |
|---|---|---|---|
| **急性冠心症(ACS)** | **< 70**(ACS 合併糖尿病可考慮 **< 55**) | 高強度 statin;ACS 後 LDL ≥ 70 應加非 statin 藥,**55–69 可考慮加藥**(實質目標 < 55) | **< 55** 且降幅 ≥ 50%;2 年內再發者 **< 40** |
| **穩定冠心病** | **< 70** | 極高風險者 LDL ≥ 70 加 ezetimibe/PCSK9 抑制劑 | **< 55**(極高風險) |
| 缺血性中風、周邊動脈疾病 | < 100(動脈硬化性中風可更低) | 同 ASCVD | < 55 |
| **糖尿病** | < 100;合併心血管病 < 70 | 40–75 歲至少中強度 statin | 依器官損傷 < 55–< 100 |
| 慢性腎臟病 3a–5 期 | < 100 | — | 依分期 < 55–< 70 |
| 一般低風險成人 | 依 10 年風險評估 | LDL ≥ 190 直接用藥 | 低風險 < 116,中風險 < 100 |

- 國考答題:**冠心病/ACS 病人 LDL < 70 mg/dL**;若選項出現 **< 55** 則為最新歐美指引的極高風險目標。一般成人健檢「LDL < 100 為理想」。
- Statin 使用與強度見 [[statins#indications]]。

### 代謝症候群判定(國健署) {#metabolic-syndrome}

下列 5 項中符合 **3 項(含)以上**即為代謝症候群:

| 危險因子 | 判定值 |
|---|---|
| **腹部肥胖** | 腰圍 **男 ≥ 90 cm、女 ≥ 80 cm** |
| **血壓偏高** | 收縮壓 **≥ 130** 或舒張壓 **≥ 85 mmHg**,或正在服用降壓藥 |
| **空腹血糖偏高** | **≥ 100 mg/dL**,或正在服用降血糖藥 |
| **TG 偏高** | 空腹 **≥ 150 mg/dL**,或正在服用降 TG 藥 |
| **HDL 偏低** | **男 < 40、女 < 50 mg/dL** |

- **總膽固醇、LDL、尿酸、BMI 都不是判定項目**(常見陷阱)。
- 判斷時先確認性別的腰圍與 HDL 切點,再逐項數。例:男性 腰圍 92、血壓 135/86、HDL 35 → 3 項,符合;女性 腰圍 82 即算一項危險因子。

## 偏高的意義 {#high}

### LDL-C / 總膽固醇偏高 {#high-ldl}

| 類別 | 原因與意義 |
|---|---|
| **心血管意義** | LDL 是**動脈粥狀硬化的致病因子**,越高、暴露越久,冠心病、心肌梗塞、缺血性中風風險越高;降 LDL 可直接降低事件(每降 39 mg/dL 約減少 20% 重大心血管事件) |
| **原發性** | **家族性高膽固醇血症**(LDL 受體基因缺陷;LDL ≥ 190,年輕即發生冠心病、肌腱黃色瘤、角膜弓) |
| 飲食生活 | 飽和脂肪與反式脂肪、肥胖、缺乏運動 |
| 內分泌代謝 | **甲狀腺功能低下**(LDL 受體減少)、糖尿病控制不良、**停經**、懷孕 |
| 腎臟 | **腎病症候群**(大量蛋白尿 → 肝臟代償性增加脂蛋白合成,膽固醇與 TG 都升高)、慢性腎臟病 |
| 肝膽 | **阻塞性黃疸**(膽汁淤積,膽固醇無法由膽汁排出) |
| 藥物 | 類固醇、cyclosporine、thiazide 利尿劑、部分抗精神病藥、HIV 雞尾酒療法、同化類固醇 |

### TG 偏高 {#high-tg}

| 類別 | 原因與意義 |
|---|---|
| **心血管意義** | 反映富含 TG 的殘餘脂蛋白增加,與胰島素阻抗、代謝症候群一起出現;是心血管病的**獨立但較弱**的危險因子 |
| 非心臟意義 | **≥ 500(尤其 ≥ 1,000)mg/dL → 急性胰臟炎**;皮膚發疹性黃色瘤、血清呈乳白色 |
| 飲食生活 | **未空腹**、**飲酒**、精製糖與含糖飲料、高熱量、肥胖 |
| 疾病 | **第二型糖尿病**控制不良、代謝症候群、甲狀腺功能低下、腎病症候群、慢性腎臟病(腹膜透析病人因透析液含葡萄糖,TG 較易升高)、懷孕 |
| 藥物 | 雌激素與口服避孕藥、類固醇、β 阻斷劑、thiazide、HIV 蛋白酶抑制劑、**膽酸結合樹脂**、靜脈脂肪乳劑(TPN) |

### HDL-C 偏高 {#high-hdl}

一般視為**保護因子**(規律運動、適量飲酒、雌激素、遺傳)。HDL 高 **不是**冠心病或慢性腎臟病的危險因子。極高(> 100)時保護效果不再增加,部分遺傳性狀況甚至與風險增加有關,但臨床上不需處理。

## 偏低的意義 {#low}

| 項目 | 原因 | 意義 |
|---|---|---|
| **HDL-C 偏低**(男 < 40、女 < 50) | **吸菸**、**缺乏運動**、肥胖、**胰島素阻抗/第二型糖尿病**、高 TG、停經、雄性素與同化類固醇、β 阻斷劑、HIV 治療藥物、遺傳(Tangier 病) | **心血管危險因子**,也是代謝症候群判定項目;處置以戒菸、運動、減重為主(目前沒有「提高 HDL 就能減少事件」的藥物證據) |
| 總膽固醇/LDL 偏低 | **營養不良**、吸收不良、**嚴重肝病**(肝硬化合成不足)、**甲狀腺功能亢進**、癌症、慢性感染發炎;罕見遺傳(無 β 脂蛋白血症) | 在未用藥者屬「疾病或營養狀態不佳」的線索;用藥達到的低 LDL(甚至 < 40)是安全的 |
| 急性疾病後 LDL 暫時下降 | 急性心肌梗塞、手術、重症、感染後數週 | 會**低估**真實值 → ACS 應在入院 **24 小時內**抽血,或 **4–8 週後**重驗 |
| TG 偏低 | 營養不良、甲狀腺功能亢進、吸收不良 | 本身**沒有特別臨床意義** |

血脂(膽固醇、TG)本身**不是評估營養狀態的最佳指標**;慢性營養不良看**白蛋白**。

## 干擾因素 {#interference}

| 因素 | 影響 |
|---|---|
| **未空腹** | TG 上升(可增加 20–30% 以上);Friedewald 計算的 LDL **偏低**;TC、HDL 影響小 |
| 抽血前飲酒(24–72 小時) | TG 上升 |
| **急性疾病**:心肌梗塞、手術、感染、中風 | TC、LDL、HDL 暫時下降(ACS 24 小時後開始) |
| **懷孕** | TC、TG 生理性上升(第三孕期最明顯);產後至少 6–12 週再驗 |
| 近期體重、飲食劇烈變化 | 應維持平常飲食 2 週後再驗 |
| **止血帶綁太久**(> 1 分鐘)、久站後抽血 | 血液濃縮 → 數值偏高(可達 10%);坐著休息 5 分鐘後抽 |
| **靜脈脂肪乳劑**(TPN) | TG 假性升高;需**輸注完畢 8 小時後**才抽 TG |
| 溶血、黃疸、乳糜血 | 干擾比色法 |
| 藥物 | 見上方「偏高」「偏低」;降血脂藥、雌激素、類固醇、利尿劑、β 阻斷劑 |

## 檢體採集與護理 {#nursing}

- **空腹**:驗 **TG 與 LDL(公式計算)需空腹 9–12 小時**(國考常寫 8–12 小時),期間可喝白開水,不可喝含糖飲料、咖啡加奶精、吃東西;前一晚避免高油脂大餐與**飲酒**。
  - 近年 2018 AHA/ACC 與 2019 ESC 指引允許**初次篩檢用非空腹**檢體;非空腹 TG ≥ 400 mg/dL、或需精確評估 TG/家族性高脂血症時,再以空腹重驗。國內與國考仍以**空腹**為標準答案。
  - **只驗 TC、HDL** 時可不空腹;**CBC、血液培養**不需空腹。
- 檢驗前 **2 週維持平常飲食**,不要為了「考好」刻意節食。
- 採**靜脈血**,血清管(紅頭或黃頭含分離膠);止血帶綁 < 1 分鐘,坐姿休息 5 分鐘後抽血。
- 糖尿病病人空腹抽血時,當天早上的降血糖藥或胰島素依醫囑暫緩,抽完血再用藥並盡快進食,避免低血糖。
- ACS 病人入院 **24 小時內**抽血脂。
- 結果解讀衛教:說明 LDL「壞」、HDL「好」、TG 與飲食酒精的關係;異常者衛教生活型態(見 [[statins#lifestyle]]),並依風險轉介醫師評估用藥。
- 服用 statin 者:開始或調整劑量後 **4–12 週**複查,之後每 3–12 個月追蹤。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **HDL 是好膽固醇**:偏高**不會**增加冠心病或 CKD 風險;「HDL 偏高易罹患冠心病」錯。
- **LDL「低密度」是因為脂質比例高、蛋白質比例低**,不是脂肪比例低。
- 膽固醇在**小腸**吸收後包成**乳糜微粒**經**乳糜管(淋巴)**運送,不是直接進門靜脈;**VLDL 由肝臟製造**,不是乳糜微粒的成分。
- 膽固醇衍生物:**糖皮質激素**等類固醇激素(腎上腺素、甲狀腺素、胰島素都不是)。
- 代謝症候群:5 項符合 3 項;腰圍男 90/女 80、BP 130/85、空腹血糖 100、TG 150、HDL 男 < 40/女 < 50;**不包括高尿酸、總膽固醇、LDL**。
- 血脂、血糖要空腹;CBC、血液培養不用;TPN 脂肪乳劑輸完 **8 小時**後才抽 TG。
- 停經後 **HDL 下降**、LDL 上升;規律運動使 **LDL 下降、HDL 上升**。
- 腎病症候群:大量蛋白尿、低白蛋白、**膽固醇與 TG 都上升**。
