BNP 是**心室**在「被撐大、壓力太高」時分泌的荷爾蒙。心衰竭時心室壁承受的牽張越大,BNP 就越高,所以它是**心衰竭的血液標記**:最有價值的是**數值低時幾乎可以排除心衰竭**。檢驗可測有活性的 **BNP** 或無活性的片段 **NT-proBNP**,兩者切點不同,不能混用。

## 從哪裡來 {#origin}

### 合成與切割 {#synthesis}

1. **刺激**:心室容積或壓力負荷增加 → **心室壁受牽張**(wall stress)。缺血、心搏過速、甲狀腺素、Angiotensin II、內皮素也會促進分泌。
2. **合成**:**心室肌細胞**(最早在豬腦發現,所以舊名 brain natriuretic peptide,但人體主要來源是心室)製造前驅物 **pre-proBNP → proBNP(108 個胺基酸)**。與心房分泌、儲存在顆粒中的 ANP 不同,BNP **幾乎不儲存,是受刺激後才大量轉錄合成**,因此反映的是數小時到數天的負荷狀態。
3. **切割**:proBNP 分泌時被酵素(corin、furin)切成等量的兩段:
   - **BNP(32 個胺基酸)**:**有生理活性**。
   - **NT-proBNP(76 個胺基酸)**:**沒有活性**,只是副產物。
4. **清除**:

| | BNP | NT-proBNP |
|---|---|---|
| 半衰期 | 約 **20 分鐘** | 約 **60–120 分鐘** |
| 清除方式 | 利鈉胜肽清除受體(NPR-C)、**neprilysin 分解** | 主要**經腎臟** |
| 結果 | 濃度較低,變化快 | 濃度較高、較穩定;**受腎功能影響較大** |

### 生理作用:心臟自己的「減壓閥」 {#physiology}

BNP 的作用剛好與 RAAS 相反,目的都是**降低心臟負荷**(詳見 [[blood-pressure-regulation#natriuretic-peptides]]):

| 作用 | 結果 |
|---|---|
| **利鈉、利尿**:增加腎絲球過濾、抑制集尿管再吸收鈉 | 血量 ↓ → **前負荷 ↓** |
| **擴張血管**(動、靜脈) | **後負荷 ↓**、前負荷 ↓ |
| **抑制 RAAS**(renin、aldosterone)與交感神經 | 減少水鈉滯留與血管收縮 |
| 抗心肌纖維化、抗肥厚 | 延緩心室重塑 |

心衰竭時 BNP 已經大量分泌,但代償不夠抵銷 RAAS 與交感神經的作用;[[arni]] 就是利用抑制 neprilysin,讓身體自己的 BNP 等利鈉胜肽不被分解,放大這個減壓閥。

## 參考值與切點 {#reference-range}

| 情境 | BNP | NT-proBNP | 意義 |
|---|---|---|---|
| **急性**呼吸困難(急診) | **< 100 pg/mL** | **< 300 pg/mL** | **可排除急性心衰竭** |
| 急性:高度懷疑心衰竭 | > 400 pg/mL(100–400 為灰色地帶) | 依年齡:< 50 歲 > 450;50–75 歲 > 900;> 75 歲 > 1800 pg/mL | 支持急性心衰竭 |
| **慢性/門診**(非急性症狀) | **< 35 pg/mL** | **< 125 pg/mL** | 不太可能是心衰竭 |

- 單位:pg/mL(= ng/L)。
- 切點的主要用途是**排除**(陰性預測值高);數值高時要配合症狀、身體檢查與[[echocardiography]]確認。
- 國考最常出:**BNP > 100 pg/mL 提示心衰竭**。

:::exam[國考重點]
- BNP 由**心室**受**牽張**時分泌;作用是**利鈉、利尿、擴張血管、抑制 RAAS**。
- **BNP > 100 pg/mL** 表示可能有心衰竭;**< 100 pg/mL(NT-proBNP < 300)可排除急性心衰竭**。
- 使用 **ARNI(sacubitril/valsartan)** 者 BNP 會被墊高 → 追蹤改看 **NT-proBNP**。
:::

## 臨床用途 {#uses}

| 用途 | 說明 |
|---|---|
| **診斷** | 分辨呼吸困難是心因性(心衰竭)還是肺因性(COPD、肺炎);低值可排除 |
| **預後** | 數值越高,住院與死亡風險越高;出院前值高者再住院率高 |
| **治療追蹤** | 治療有效時下降;出院前較入院時下降 > 30% 是好的預兆 |
| **篩檢** | 高危族群(高血壓、糖尿病等,第 A 期)可用來找出早期結構性心臟病(第 B 期),2022 AHA/ACC/HFSA 列為合理做法 |

## 偏高的意義 {#high}

凡是讓**心室壁受牽張**、或讓 **BNP 清除變慢**的狀況都會升高。

| 類別 | 原因 | 機轉 |
|---|---|---|
| **心臟** | **心衰竭**(HFrEF、HFpEF 都會上升;HFpEF 通常較低) | 心室容積/壓力負荷 ↑ |
| | **心房顫動**等心律不整 | 心房擴大、心室充填異常(切點需調高) |
| | 急性冠心症、心肌炎 | 缺血或受損心肌分泌 |
| | 瓣膜疾病(主動脈瓣狹窄、二尖瓣逆流)、左心室肥厚 | 壓力或容積負荷 |
| | 心臟手術、電擊後 | |
| **非心臟** | **腎功能不全** | 清除減少(NT-proBNP 影響更大)+ 容積過多 |
| | **年齡增加**、女性 | 生理性偏高;NT-proBNP 急性切點依年齡分級 |
| | **肺栓塞**、肺高壓、COPD 急性惡化合併肺心症 | **右心室**受牽張 |
| | **敗血症**、重症、燒傷 | 發炎介質、心肌抑制 |
| | 貧血、甲狀腺功能亢進、肝硬化 | 高輸出狀態 |
| | 腦中風、蜘蛛網膜下腔出血 | |
| **藥物** | **ARNI(sacubitril)** | 抑制 neprilysin → **BNP 分解減少而上升**;NT-proBNP 不受影響、反而因治療有效而下降 |

## 偏低的意義 {#low}

- **數值低 → 心衰竭可能性很低**,這是 BNP 最有價值的用法:呼吸困難病人 BNP < 100 pg/mL,應優先尋找肺部等其他原因。
- **偏低本身沒有疾病意義**,不需處理。
- **假性偏低**(有心衰竭卻不高),要小心:

| 原因 | 機轉 |
|---|---|
| **肥胖**(BMI ≥ 30) | 脂肪組織的 NPR-C 受體多、清除快,合成也較少;數值可低約 **30–50%**,判讀時切點要下修 |
| **急性肺水腫剛發生**(flash pulmonary edema,1 小時內) | BNP 還來不及合成 |
| 縮窄性心包膜炎、心包填塞 | 心室被外力限制、無法被撐大 |
| 二尖瓣狹窄、急性二尖瓣逆流 | 壓力在心房,心室未擴大 |
| 已接受利尿劑等治療後 | 負荷已下降 |

## 干擾因素 {#interference}

| 因素 | 影響 |
|---|---|
| **ARNI(sacubitril/valsartan)** | **BNP 上升**(至少服藥 8–10 週內不宜用 BNP 評估);改測 **NT-proBNP** |
| 腎功能 | eGFR 越低,兩者越高,NT-proBNP 更明顯 |
| 肥胖 | 假性偏低 |
| 年齡、性別 | 年長、女性偏高 |
| 檢體 | **BNP 在試管中不穩定**(會被蛋白酶分解),須用 EDTA 管並盡快送檢;NT-proBNP 較穩定,血清或血漿皆可 |
| Biotin 高劑量 | 部分免疫分析法受干擾 |

## 檢體採集與護理 {#nursing}

- **不需空腹**,不受進食影響。
- **BNP**:紫頭(EDTA)管,抽完儘速送檢、不可冷凍;**NT-proBNP**:依院內規定(血清或肝素/EDTA 血漿)。
- 一位病人追蹤時**固定用同一種檢驗**(BNP 或 NT-proBNP),兩者數值不能直接比較。
- 註明是否正在使用 **ARNI**、有無腎功能不全、心房顫動,方便醫師判讀。
- 搭配每日**體重**、**攝入與排出量**、水腫、呼吸音、端坐呼吸評估容積狀態(見 [[heart-failure]])。
- 衛教:數值是「心臟負擔」的指標,治療後下降代表好轉;門診追蹤可能定期抽血。

## 國考重點整理 {#exam-points}

:::exam[國考重點]
1. 來源:**心室肌**受牽張 → proBNP → **BNP(有活性)+ NT-proBNP(無活性)**。
2. 作用:利鈉利尿、擴血管、抑制 RAAS 與交感 → 降低前、後負荷。
3. **BNP > 100 pg/mL 表示心衰竭可能**;BNP < 100 / NT-proBNP < 300 排除急性心衰竭;慢性門診切點 35 / 125。
4. 偏高也見於腎功能不全、年長、心房顫動、肺栓塞、敗血症。
5. **肥胖**會假性偏低;**ARNI** 使 BNP 上升 → 看 NT-proBNP。
6. 用於**診斷、預後、治療追蹤**。
:::
