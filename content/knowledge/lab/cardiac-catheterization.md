心導管是把細長導管經**周邊血管**(橈動脈、股動脈或股靜脈)送到心臟,注入**顯影劑**在 X 光下攝影或測量壓力。它同時是**診斷**(看冠狀動脈哪裡狹窄)與**治療**(氣球擴張、放支架)的工具。護理重點集中在**術前準備**與**術後穿刺部位、遠端循環、顯影劑**的照護。

## 原理與種類 {#principle}

| 種類 | 路徑 | 看什麼 / 做什麼 |
|---|---|---|
| **左心導管/冠狀動脈攝影** | **動脈**(橈動脈優先,或股動脈)→ 主動脈 → 冠狀動脈、左心室 | 冠狀動脈狹窄位置與程度、左心室功能 |
| **右心導管** | **靜脈**(股靜脈、頸內靜脈)→ 右心房 → 右心室 → 肺動脈 | 右心壓力、**肺動脈楔壓(PCWP)**、心輸出量、各腔室血氧(先天性心臟病分流) |

- **肺動脈楔壓(PCWP)**:導管前端氣球楔在肺動脈小分支,間接反映**左心房壓 = 左心室前負荷**,正常約 **6–12 mmHg**;> 18 mmHg 表示肺鬱血。**心因性休克、左心衰竭、二尖瓣狹窄時 PCWP 上升**(二尖瓣狹窄另有右心室壓、CVP 上升,心輸出量下降)。PCWP 不代表主動脈阻力(那是全身血管阻力 SVR)。
- **各腔室血氧**:右側(上下腔靜脈、右心房、右心室、肺動脈)約 **70–75%**;左側(**肺靜脈**、左心房、左心室、主動脈)約 **95–100%**。右側血氧異常升高 → 左向右分流(ASD、VSD)。

### 冠狀動脈介入治療 PCI {#pci}

![冠狀動脈支架:導線(guide wire)引導導管(catheter)把支架(stent)送到狹窄處撐開](/knowledge-images/blausen-angioplasty-stent.png)

1. **導線**穿過狹窄處 → 沿導線送入**氣球導管**,在狹窄處充氣把斑塊壓向血管壁(氣球擴張術,舊稱 **PTCA**)。
2. 多數同時放置**支架(stent)**:包在氣球外的金屬網,氣球撐開後留在血管內當支撐,減少回縮。
3. **藥物塗層支架(DES)**:支架表面緩慢釋放抑制細胞增生的藥物(如 everolimus),**再狹窄率遠低於裸金屬支架**,為目前主流;代價是內皮覆蓋慢,**須服用雙重抗血小板藥物(DAPT)**預防支架血栓。
4. 用途:**STEMI 首選再灌流**(到院至通血 ≤ 90 分鐘)、高風險 NSTE-ACS、藥物控制不佳的穩定型心絞痛。

### 冠狀動脈繞道手術 CABG {#cabg}

- 開胸取**內乳動脈**或**大隱靜脈**,把血流從主動脈「繞過」狹窄段接到遠端冠狀動脈。
- 較適合:**左主幹**病變、**三條血管病變(尤其合併糖尿病)**、PCI 不適合的複雜病變。
- 術後重點:胸管引流量(**> 100–200 mL/hr** 須通知並評估凝血)、低血鉀心律不整、低心輸出量;詳見 [[coronary-artery-disease]]。

## 適應症 {#indications}

- 急性冠心症(STEMI 緊急、NSTE-ACS 依風險)、藥物控制不佳的心絞痛、非侵入性檢查顯示高風險缺血。
- 不明原因心衰竭、瓣膜疾病術前評估。
- 右心導管:肺高壓、心衰竭血行動力學評估、**先天性心臟病**(測壓力與分流,部分可經導管關閉 ASD、PDA)。

## 檢查前準備 {#preparation}

- **同意書**;說明過程為局部麻醉、清醒,注射顯影劑時會有**全身溫熱感**、可能有心悸。
- **禁食**:成人常規 **4–6 小時**(國考題曾寫 6–8 小時);兒童依年齡 **4–6 小時**。
- **過敏史**:顯影劑、**碘**、(傳統上問)**海鮮**過敏;曾對顯影劑過敏者依醫囑預防性給類固醇與抗組織胺。(現今認為海鮮過敏並非顯影劑過敏的特定危險因子,但仍是考題常見答案。)
- **腎功能**(creatinine、eGFR)、凝血功能、血色素、電解質、ECG。
- **Metformin**:依醫囑於檢查當天暫停,術後 **48 小時**確認腎功能穩定再恢復(腎功能不佳者尤其重要),預防乳酸中毒(見 [[metformin]])。
- **抗凝血劑**(warfarin、NOAC)依醫囑調整;**抗血小板藥通常不停**(PCI 前還會給負荷劑量)。兒童長期服用 digoxin 者依醫囑術前暫停。
- **標記遠端脈搏**:股動脈路徑在**雙側足背動脈與脛後動脈**最強處做記號;橈動脈路徑先做 **Allen test** 確認尺動脈側支循環。記錄基準的肢體顏色、溫度、脈搏;兒童測**四肢血壓**。
- 建立靜脈管路、**術前水分補充**(預防顯影劑腎病變);穿刺部位剃毛清潔、排空膀胱、移除首飾假牙。
- 學齡兒童最大的壓力源是**身體受傷與疼痛**:以玩偶、圖片解釋流程。

## 檢查後護理 {#post-care}

| | **橈動脈**(手腕) | **股動脈**(鼠蹊) |
|---|---|---|
| 止血 | 加壓止血帶(如 TR band)約 **2 小時**,依規定逐步放氣 | 拔除導管鞘後**徒手加壓** 15–20 分鐘,或止血裝置;傳統輔以砂袋(約 0.5–1.5 kg)加壓 2–4 小時 |
| 活動 | 可**早期下床**;該手避免用力、彎腕 | **平躺、穿刺側下肢伸直不可彎曲**:動脈約 **4–6 小時**(傳統 6–8 小時)、靜脈(右心導管)約 **4–6 小時** |
| 床頭 | 不限 | **床頭 ≤ 30 度**,避免屈髖 |
| 血壓 | **測對側手臂**,不在穿刺側量血壓 | |
| 出院 | 穿刺側手 **數天內不提重物** | 約 1 週避免提重、劇烈運動、盆浴 |

- **導管鞘不會立即拔除**:術中用過 heparin,需等 **ACT(活化凝血時間)**降到安全範圍再拔。
- **每 15 分鐘評估**穿刺部位與遠端循環(一般第 1 小時 q15min、第 2 小時 q30min、之後 q1h):**出血、血腫、遠端脈搏(股動脈看足背動脈)、膚色、溫度、感覺、微血管充填**,並與對側比較;可用 **6P**(pain、pallor、pulselessness、poikilothermia、paresthesia、paralysis)。
- **出血或血腫**:立即**在穿刺點(或稍近心端)直接加壓**,同時呼叫醫師、測生命徵象。
- 監測**生命徵象、心律**與胸痛(再阻塞、心律不整)。
- **多喝水**(無心衰竭限水時)或依醫囑靜脈輸液,促進**顯影劑排出**;記錄尿量。
- 意識清楚、無噁心嘔吐即可**恢復進食**,不需長時間禁食。
- 衛教:**DAPT(aspirin + P2Y12 抑制劑)不可自行停藥**,通常 ACS 或放置 DES 後約 12 個月,之後 aspirin 或單一抗血小板長期服用(見 [[antiplatelets]]);支架不代表「病好了」,仍需控制危險因子與服藥;胸痛復發立即就醫。

:::exam[國考重點]
- 股動脈路徑:**穿刺肢體伸直、平躺**,不可彎曲或做下肢主動運動;評估**足背動脈**。
- 橈動脈路徑:加壓約 2 小時、**不在穿刺側量血壓**、用 6P 評估、該手不提重物。
- 右心導管走**靜脈**;左心導管走**動脈**。右側腔室血氧 70–75%,**肺靜脈**與左側 95–100%。
- 術後多喝水排顯影劑;導管鞘待 ACT 恢復後才拔除。
- 出血時先**直接加壓**。
:::

## 併發症 {#complications}

| 併發症 | 表現與處理 |
|---|---|
| **穿刺部位出血、血腫** | 最常見;直接加壓、通知醫師 |
| **後腹腔出血**(股動脈穿刺點過高) | 看不到外出血,但有**腰背或側腹痛、血壓下降、心跳加快、血色素下降** → 緊急處理 |
| **假性動脈瘤** | 穿刺處**會搏動的腫塊、可聽到雜音** → 超音波導引加壓或注射 thrombin |
| 動靜脈瘻管、遠端血栓栓塞 | 遠端脈搏消失、肢體冰冷蒼白 |
| **顯影劑腎病變** | 術後 **48–72 小時**內 creatinine 上升;高危:慢性腎病、糖尿病、脫水、心衰竭 → 預防靠**水分補充** |
| **顯影劑過敏** | 皮疹、搔癢到過敏性休克;輕者抗組織胺,嚴重者依過敏性休克流程給 epinephrine |
| **心律不整** | 導管刺激心室、再灌流心律不整 |
| 冠狀動脈剝離、急性閉塞、心肌梗塞、腦中風 | 少見但嚴重 |
| **支架血栓** | 多在早期,常因**自行停用 DAPT** → 急性心肌梗塞 |
| **再狹窄** | 多在 **6 個月內**,表現為心絞痛復發;DES 可大幅降低 |

## 國考重點整理 {#exam-points}

:::exam[國考重點]
1. 術前:同意書、禁食、**顯影劑/碘/海鮮過敏史**、腎功能、metformin 暫停、**標記足背動脈**。
2. 術後:股動脈路徑**肢體伸直平躺**、床頭 ≤ 30 度;**q15min 評估穿刺部位與遠端脈搏、顏色、溫度、感覺**,與對側比較。
3. 出血先**直接加壓**;後腹腔出血看**腰背痛 + 血壓下降**。
4. 多喝水排顯影劑,預防顯影劑腎病變。
5. PCI 後 **DAPT 不可自行停**;DES 降低再狹窄但需抗血小板。
6. PCWP 反映左心房壓/左心室前負荷;心因性休克、二尖瓣狹窄時上升。
:::
