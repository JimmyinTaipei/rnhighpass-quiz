尿液是血液經過腎臟過濾與調整後的產物，看尿量、顏色、比重與成分，就能初步判斷腎臟、泌尿道與全身代謝的狀況。本頁整理常規尿液檢查的正常值與異常意義、各種採檢法（中段尿、導尿管、兒童集尿袋、24 小時尿液）；尿液培養的判讀見 [[urinary-tract-infection]]、腎功能抽血見 [[renal-function-tests]]、尿液白蛋白見 [[uacr]]、尿酮見 [[ketones]]

## 重點摘要 {#summary}

- 常規尿液檢查是泌尿系統**最簡便的例行檢查**；**清晨第一次尿**最濃縮，是常規分析最好的檢體
- 收集**清潔中段尿**，**30 分鐘內**送檢；放太久細菌增生、pH 變鹼、細胞與圓柱體被破壞
- 正常成人：每天約 **1,200–1,500 mL**、淡黃色、**pH 4.5–8.0**、**比重 1.010–1.030**、白血球 < 5/HPF(high-power field)、紅血球 1–3/HPF、**無**糖（或微量）、**無**酮體、**無**圓柱體
- 留置導尿管：夾管 15–30 分鐘後，消毒**採檢口**用空針抽取；**不可從尿袋取尿**
- **24 小時尿液**：開始時間的那一次尿**丟掉**、結束時間的那一次**要收**；中途漏收就**重新開始**；冷藏、檢驗單寫總量
- 24 小時尿液用來看**尿蛋白量**、**肌酸酐清除率**（見 [[renal-function-tests#ccr]]）與電解質、激素排出量

### 國考常考點 {#exam-points}

- 正常尿液 pH 是 **4.5–8.0**，不是 3.5–4.5；每天尿量約 1,200–1,500 mL；比重 1.010–1.030
- 白血球 20/HPF 是**異常**（泌尿道感染）；葡萄糖 2 mg/dL、蛋白質 5 mg/dL、每天 1,450 mL 都在正常範圍
- 尿中出現**圓柱體**表示**腎臟**疾病，肝病不會；長期嘔吐、飢餓可出現**酮體**
- 尿液**螢光黃色** → 服用**維生素 B 群**（國考答案寫維生素 B12；實際最明顯的是核黃素 B2）；**暗紅色**且排尿痛 → **尿道結石**
- **24 小時尿液可評估尿蛋白量**；尿液細菌培養**不是**初步常規檢查；酚紅試驗(PSP, phenolsulfonphthalein)測的是**腎小管**對外排泄的能力，不是腎絲球（課本 p.782–783）
- 尿中肌酸酐與尿素氮**不是**評估腎功能的最佳指標（最佳是**血清肌酸酐與 GFR**(glomerular filtration rate)）
- 留置導尿管的病人**不可以從蓄尿袋取尿**
- 24 小時尿液：**7 AM 那次不要**、**隔日 7 AM 那次要收**、檢驗單註明總量、**月經期不收**、漏收要**隔天重新開始**；**不必**為了收尿插導尿管、收集瓶**冷藏**不是保溫
- 4 歲兒童用集尿袋：清潔即可（不需優碘、不需無菌）；男童把**陰莖（盡量連陰囊）**放進袋內；女童由**會陰（肛門與陰道之間）往上**貼到恥骨
- 紅血球增加：結石、泌尿道感染、腎絲球腎炎、腫瘤、導尿受傷、輸血血型不合（111-2 考題答案；實際是溶血造成血紅素尿，鏡檢紅血球不一定增加）；**肝膽疾病、子癲前症不會**

## 參考值 {#reference-range}

依《實用基本護理學》下冊表 15-2 整理；《內外科護理學》下冊表 19-7(p.782)略有不同：pH 4.5–7.5、白血球 0–3、紅血球與潛血應為陰性，>7.5 見於鹼中毒或尿液放置過久

| 項目 | 正常（成人） | 異常與可能原因 |
|---|---|---|
| 24 小時尿量 | 1,200–1,500 mL | 少：攝水少、脫水、腎衰竭；多：糖尿病、利尿劑、尿崩症、喝水多 |
| 顏色 | 淡黃到琥珀色、清澈 | 深琥珀色：濃縮；混濁：感染；紅色：血尿（見下表） |
| 氣味 | 微腥、放久有氨味 | 惡臭：感染；水果味：酮體 |
| **pH** | **4.5–8.0**（平均約 6） | > 8：泌尿道感染（分解尿素的細菌）、放置過久；< 4.5：飢餓、脫水、酸中毒 |
| **比重** | **1.010–1.030** | 低：**尿崩症**、喝太多水、水中毒；高：**脫水**、糖尿病（尿糖）、顯影劑 |
| 白血球 | < 5/HPF | 增加：泌尿道感染、腎盂腎炎、腎結核、性病 |
| 紅血球 | 1–3/HPF | 增加：血尿（見下方「血尿」） |
| 蛋白質 | < 150 mg/天(< 10 mg/dL) | 生理性：劇烈運動、發燒後暫時性；病理性：腎絲球腎炎、**腎病症候群**、糖尿病腎病變、SLE、多發性骨髓瘤 |
| 葡萄糖 | 無或 2–20 mg/dL | 糖尿：糖尿病、高糖飲食、**妊娠**（腎糖閾下降） |
| 酮體 | 無 | 糖尿病酮酸中毒、飢餓、長期嘔吐腹瀉 |
| 膽紅素 | 陰性 | 阻塞性黃疸、肝炎（尿呈茶色） |
| 圓柱體 | 無 | **腎臟疾病**（紅血球圓柱體：腎絲球腎炎） |
| 結晶體 | 無 | 結石風險，再做進一步檢查 |

- 寡尿、無尿：每天 < 400–500 mL 稱**寡尿**（少尿）、< 100 mL 稱**無尿**（《實用基本護理學》下冊 p.369–370）；兒童以每小時每公斤尿量判斷，心臟手術後嬰兒每天 60 mL 明顯太少
- 尿滲透壓大約 50–1,200 mOsm/kg（看喝水多少）；急性腎衰竭腎前性與腎性的尿液指標比較見 [[acute-kidney-injury#diagnosis]]

## 尿液顏色 {#color}

| 顏色 | 常見原因 |
|---|---|
| 無色、很淡 | 喝水多、尿崩症、利尿劑 |
| 深黃、琥珀色 | 濃縮（脫水、發燒） |
| **螢光黃**、亮黃 | **維生素 B 群**（核黃素最明顯） |
| 橘紅 | rifampin、phenazopyridine（止尿道痛藥） |
| **紅色、暗紅** | **血尿**（結石、感染、腫瘤、腎絲球腎炎）、血紅素尿、肌紅素尿、月經汙染 |
| **茶色、可樂色** | **膽紅素**（阻塞性黃疸）、肌紅素尿（橫紋肌溶解）、急性腎絲球腎炎 |
| 混濁、白色 | 膿尿、磷酸鹽結晶、乳糜尿 |

::questions{ids="111-1_FA_052,109-2_FA_050"}

## 血尿 {#hematuria}

- **肉眼血尿**看得到紅色；**顯微血尿**要在顯微鏡下每高倍視野紅血球超過正常
- 依疼痛判斷
   1. **無痛性血尿**：要先排除**膀胱癌**等泌尿道腫瘤
   2. 合併絞痛：**尿路結石**
   3. 合併排尿灼熱、頻尿：泌尿道感染
   4. 合併水腫、高血壓、茶色尿：**急性腎絲球腎炎**
- 其他：導尿受傷、檢查後（膀胱鏡、腎切片、逆行性腎盂攝影）、輸血血型不合（血紅素尿）、抗凝血劑
- **良性前列腺肥大**：攝護腺表面血管增生可能出血，但血尿**不是常見主要症狀**；一題問「可能原因」要算進去、一題問「常見症狀」不算（114-1_MS_038 與 110-2_MS_064 答案）
- **子癲前症**主要是**蛋白尿**，不是血尿

## 檢體採集與護理 {#nursing}

### 常規尿液檢查 {#routine}

- 最好用**清晨第一次尿**（最濃，成分最容易檢出）；**隨機尿**是早晨第一次以外任何時間的尿
- **清潔中段尿**
   1. 洗手，女性先清潔會陰
   2. 先解掉前段，再接**中段**約半杯，剩下的解完
   3. 倒入試管約八分滿，不要碰觸容器內面；尿杯不要放衛生紙
- **30 分鐘內**送檢；無法立即送檢就冷藏
- 女性月經期間避免採檢；必要時改用單次導尿

### 尿液培養 {#culture}

- 先用水和中性肥皂清潔會陰與尿道口（男性清潔龜頭與包皮附近），排掉前段後以**無菌容器**接中段尿約 15 mL；手不可碰容器內面（《內外科護理學》下冊 p.781–782）；病人無法配合才用單次導尿，因為導尿會增加感染風險
- 培養每毫升菌落 ≥ 10⁵ 表示泌尿道感染；判讀與治療見 [[urinary-tract-infection]]、培養與敏感試驗見 [[culture-and-sensitivity]]
- 細菌培養是確認病菌與用藥，**不是**初步常規檢查

### 留置導尿管的病人 {#catheter-specimen}

| 步驟 | 做法 | 理由 |
|---|---|---|
| 1 | 夾住導尿管 15–30 分鐘 | 讓新鮮尿液積在管內 |
| 2 | 以酒精性消毒液環狀消毒導尿管的**採檢口** | 避免把細菌帶進封閉系統 |
| 3 | 用空針從採檢口抽取 | 不要刺到**水球管路**，否則水球消掉、導尿管滑出 |
| 4 | 鬆開管夾，注入無菌容器 | 恢復引流 |

- **不可從蓄尿袋**倒尿送檢：袋內尿液放置已久、細菌增生
- 不能為了收集檢體而拔管或另外拆開引流系統

### 兒童集尿袋 {#urine-bag}

- 清潔、擦乾會陰即可，**不需要**優碘消毒或無菌技術（培養檢體另依無菌法）
- 女童：從**會陰（肛門與陰道之間）**開始往上貼到恥骨，避免糞便汙染
- 男童：把**陰莖（盡量連同陰囊）**放進集尿袋開口
- 常檢查有無滲漏，收到尿就移除，避免皮膚刺激

::questions{ids="114-2_MS_037,109-1_MS_061,109-1_OP_068"}

### 24 小時尿液 {#24-hour-urine}

| 時間 | 做法 |
|---|---|
| 開始（例：當日 7 AM） | 請病人**解尿並丟掉**，這次是收集前就在膀胱的尿 |
| 收集期間 | 之後**每一次**的尿都倒進收集瓶；瓶子放**陰涼處或冷藏**（依檢驗加防腐劑），不是保溫 |
| 結束（隔日 7 AM） | 請病人**最後解一次並收進瓶內** |
| 送檢 | 測總量、混勻後取樣，檢驗單**註明 24 小時總量** |

- 中途**漏收或丟掉一次** → 結果不準，要**重新開始**（隔天 7 AM 再收），不是註明後繼續
- **月經期不收**；清醒能自解的病人**不需要**為了收尿而放導尿管
- 收集瓶放在病人方便處並做標示，提醒病人與家屬
- 用途：**尿蛋白量**、**肌酸酐清除率**、鈉鉀等電解質、尿酸、激素代謝物；做兒茶酚胺代謝物(VMA, vanillylmandelic acid)等特殊檢驗時，依檢驗科要求事先停某些食物或藥物
