甲狀腺功能檢驗以 **TSH** 為第一線，再配合**游離 T4** 判斷問題出在甲狀腺本身還是腦下垂體；抗體、攝碘率、掃描與超音波用來找原因。回饋的生理見 [[thyroid-parathyroid#regulation]]，疾病見 [[hyperthyroidism]]、[[hypothyroidism]]、[[thyroid-nodules-cancer]]

## 重點摘要 {#summary}

- **TSH 最敏感**：甲狀腺素小幅變動，TSH 就反向大幅變動，是篩檢甲亢與甲低的第一線
- **原發性**（甲狀腺本身）：甲亢 **TSH ↓、FT4 ↑**；甲低 **TSH ↑、FT4 ↓**
- **次發性**（腦下垂體）：TSH 與 FT4 **同方向**
- **游離 T4** 比總 T4 準：總 T4 會隨**甲狀腺結合球蛋白**(TBG)變動，例如**懷孕**、口服避孕藥讓 TBG 上升
- 找原因：**TSH 受體抗體**(Graves)、**抗 TPO 抗體**（橋本氏甲狀腺炎）、**攝碘率與掃描**（Graves 均勻升高、亞急性甲狀腺炎很低、熱結節）
- 甲狀腺全切除後的**甲狀腺球蛋白**是分化型甲狀腺癌的追蹤指標
- 一般血液檢驗**不需空腹**；做攝碘率或掃描前要避免碘（顯影劑、海帶）與抗甲狀腺藥

### 國考常考點 {#exam-points}

- 早期偵測甲亢或甲低**最敏感**：**血清 TSH**
- **Graves 病**：T4 上升、**TSH 下降**
- **碘缺乏**：T4 合成不足、甲狀腺腫，**TSH 上升**（不是過低）
- **先天性甲狀腺功能低下**：**T4 低、TSH 高**
- **甲狀腺風暴**：游離 T4 上升、**TSH 下降**（不會上升）
- **黏液水腫昏迷**：T4 下降、**TSH 上升**（原發性）
- 懷孕時 **TBG** 上升，總 T4 偏高；第二孕期 TBG 平均值最高

## 判讀表 {#interpretation}

| 結果 | 最可能的狀況 |
|---|---|
| **TSH ↓、FT4 ↑** | **原發性甲亢**（Graves 病、毒性結節、甲狀腺炎早期）；**甲狀腺風暴** |
| TSH ↓、FT4 正常、T3 ↑ | T3 型甲亢 |
| TSH ↓、FT4 正常 | 次臨床甲亢；或甲狀腺素補充過量 |
| **TSH ↑、FT4 ↓** | **原發性甲低**（橋本氏甲狀腺炎、甲狀腺切除或放射碘後、**碘缺乏**、**先天性**）；**黏液水腫昏迷** |
| TSH ↑、FT4 正常 | **次臨床甲低** |
| TSH ↓ 或正常、FT4 ↓ | **次發性甲低**（腦下垂體功能低下，見 [[pituitary-disorders#hypopituitarism]]） |
| TSH ↑ 或正常、FT4 ↑ | 少見：分泌 TSH 的腦下垂體腫瘤、甲狀腺素阻抗 |

- 參考值依各院檢驗方法不同，常見範圍：TSH 約 0.4–4 mIU/L、游離 T4 約 0.8–1.8 ng/dL（**依各院**）
- 重病、類固醇、多巴胺會暫時壓低 TSH；**biotin**（生物素）高劑量保健品會干擾部分免疫分析，檢驗前要詢問用藥

## T4、T3 與結合蛋白 {#t4-t3}

- 甲狀腺分泌以 **T4 為主**，T3 活性較強，多數 T3 由周邊組織把 T4 轉換而來（見 [[thyroid-parathyroid#synthesis]]）
- 血中 99% 以上和蛋白質（主要是 **TBG**）結合，只有**游離**部分有作用
- **TBG 上升**：**懷孕**、雌激素、口服避孕藥 → **總 T4 上升**，游離 T4 可能正常
- TBG 下降：雄性素、類固醇、腎病症候群、肝病
- 所以臨床多測**游離 T4**；T3 主要用在懷疑甲亢、TSH 已被抑制但 FT4 不高時

## 找原因的檢查 {#etiology}

| 檢查 | 用途 |
|---|---|
| **TSH 受體抗體**（TRAb、TSI） | **Graves 病**陽性；懷孕時可穿過胎盤造成新生兒甲亢 |
| **抗 TPO 抗體**、抗甲狀腺球蛋白抗體 | **橋本氏甲狀腺炎**；也可見於 Graves 病 |
| **甲狀腺攝碘率**(RAIU) | 服少量放射碘後測甲狀腺攝取比例：**Graves 病均勻升高**；**亞急性與無痛性甲狀腺炎很低**（是破壞後漏出，不是製造過多） |
| **甲狀腺掃描** | 看攝碘分布：**熱結節**（功能性，很少惡性）、冷結節、多結節性甲狀腺腫 |
| **甲狀腺超音波** | 結節大小與惡性特徵、甲狀腺腫，決定是否**細針抽吸**（見 [[thyroid-nodules-cancer#nodules]]） |
| **甲狀腺球蛋白** | 全切除與放射碘後應該很低，**再升高表示分化型甲狀腺癌復發** |
| **降鈣素** | 甲狀腺**髓質癌**的腫瘤標記 |

## 檢驗護理 {#nursing}

1. 抽血測 TSH、FT4 一般**不需空腹**；固定在早上服甲狀腺素者，依醫囑可在服藥前抽血
2. 詢問用藥：甲狀腺素、抗甲狀腺藥、**含碘藥物**(amiodarone)、類固醇、雌激素與口服避孕藥、高劑量 **biotin**
3. **攝碘率與掃描前**
   1. 確認是否**懷孕或哺乳**（放射性物質禁忌）
   2. 依醫囑停用抗甲狀腺藥與甲狀腺素一段時間
   3. 避免**含碘食物與藥物**（海帶、紫菜、海鮮、含碘鹽、**碘顯影劑**），否則甲狀腺被碘飽和、攝取率假性偏低
   4. 檢查用的放射碘劑量很低，不需要像治療劑量那樣隔離
4. 調整甲狀腺素劑量後，TSH 要幾週才穩定，通常 **6–8 週**後再複驗（教科書通則，**待核對**）
5. **新生兒篩檢**：出生滿 **48 小時**後採腳跟血，篩檢先天性甲狀腺功能低下（衛福部）；詳細流程見 [[pediatric-endocrine#newborn-screening]]
