血清鉀是**細胞外液**中的鉀濃度。體內的鉀有 98% 在細胞裡,抽血只看得到那 2%,所以它同時反映三件事:**吃進多少、腎臟排掉多少、鉀在細胞內外怎麼移動**。鉀濃度決定神經、肌肉與**心肌**的興奮性,偏高或偏低都可能引起致命心律不整。

## 鉀從哪裡來、在哪裡 {#origin}

### 分布:細胞內的主要陽離子 {#distribution}

- 全身約 3,500 mEq(約 50 mEq/kg),**約 98% 在細胞內**(細胞內濃度約 140–150 mEq/L,主要在**骨骼肌**,其次肝臟、紅血球),細胞外只有約 2%(3.5–5.0 mEq/L)。
- 這個 30 倍的濃度差靠每個細胞膜上的 **Na⁺-K⁺-ATPase(鈉鉀幫浦)** 維持:消耗 ATP,每次把 3 個 Na⁺ 送出、2 個 K⁺ 送入,屬**主動運輸**。
- 細胞外量少,只要一點點鉀從細胞「跑出來」或「跑進去」,血鉀就會大幅變動。

### 功能:為什麼這個數值這麼重要 {#function}

- **靜止膜電位**主要由 K⁺ 的細胞內外濃度比決定(靜止時細胞膜對 K⁺ 通透性遠大於 Na⁺)。
  - **細胞外 K⁺ 上升** → 濃度差變小 → 膜電位**變得較不負(靜止膜電位減小)** → 初期較易興奮,持續則鈉通道失去活性 → 傳導變慢、**房室傳導阻斷**、心臟停在舒張期。
  - **細胞外 K⁺ 下降** → 膜電位**更負(過極化)**、再極化延遲 → 肌肉無力,心肌再極化異常、易出現異位節律。
- 心肌**再極化**(心電圖 T 波、U 波)、骨骼肌與**腸道平滑肌**收縮、神經傳導。
- 參與酸鹼平衡(與 H⁺ 交換)、細胞體積、肝醣與蛋白質合成。

### 進出:什麼時候鉀會進入/離開血液 {#balance}

| 環節 | 說明 |
|---|---|
| **攝入** | 每天從食物約 50–100 mEq;蔬果、肉類、乳品、堅果含量高 |
| **細胞內外移動(短期調節)** | **胰島素**、**β₂ 刺激(腎上腺素)**、**鹼中毒** → K⁺ **進入細胞**(血鉀↓);**胰島素不足、酸中毒**(H⁺ 進細胞、K⁺ 出來)、**高血糖高滲透壓**、細胞破壞、劇烈運動 → K⁺ **移出**(血鉀↑) |
| **排出(長期調節)** | **約 90% 由腎臟**排出、約 10% 由糞便(腎衰竭時腸道排鉀增加);汗液少量 |
| **腎臟怎麼調** | 近曲小管與亨利氏環回收大部分過濾的 K⁺;真正決定排多少的是**集尿管主細胞**——受**醛固酮**調控(血鉀↑ 直接刺激醛固酮分泌 → 排鉀↑),也受到達集尿管的**鈉量與尿流量**影響(這就是**利尿劑造成低血鉀**的原因) |

腎臟「保鉀」的能力不如「保鈉」:即使完全不吃鉀,每天仍會流失 10–20 mEq,所以禁食、嘔吐加上利尿劑時很容易低血鉀。

## 參考值 {#reference-range}

| 項目 | 數值(mEq/L = mmol/L) |
|---|---|
| **成人** | **3.5–5.0**(部分檢驗室 3.5–5.1) |
| 新生兒 | 約 3.7–5.9(較高) |
| 輕度高血鉀 | 5.1–5.9 |
| 中度高血鉀 | 6.0–6.4 |
| **重度高血鉀** | **≥ 6.5**(或有心電圖變化) |
| 輕度低血鉀 | 3.0–3.4 |
| 中度低血鉀 | 2.5–2.9 |
| **重度低血鉀** | **< 2.5** |
| 危急值(各院不同) | 約 **< 2.5 或 > 6.0–6.5** |

鉀的單位是 **mEq/L**;國考題若寫 mg/dL 屬題目筆誤,判讀時仍以 3.5–5.0 為準。

## 心電圖變化 {#ecg}

![高血鉀與低血鉀的心電圖變化](/knowledge-images/potassium-ecg-changes.svg)

| | 高血鉀 | 低血鉀 |
|---|---|---|
| T 波 | **高尖、窄底(帳篷狀)**——最早出現 | **變平或倒置** |
| P 波 / PR | P 波變平→消失、**PR 延長** | P 波可能變高 |
| QRS | **變寬**,嚴重時與 T 波融合成**正弦波** | 輕度變寬 |
| ST 段 | — | **下降** |
| U 波 | — | **明顯 U 波**(T 波後的小波,低血鉀的招牌) |
| QT | 可能縮短 | QU 延長 |
| 心律 | 心搏過緩、**房室傳導阻斷**、心室顫動、**無收縮/PEA** | 心室/心房早期收縮、心室頻脈、**Torsades de pointes**、心室顫動;**加重毛地黃中毒** |

心電圖變化不一定與數值平行:慢性腎衰竭病人 K⁺ 7 mEq/L 可能只有輕微改變,急性上升時則較早出現致命心律不整。心電圖判讀見 [[ecg#waves]]。

## 偏高:高血鉀 {#high}

> 血鉀 > 5.0 mEq/L。先想三個方向:**排不掉(腎)**、**從細胞跑出來(移動)**、**吃/輸太多**;並排除**假性高血鉀**。

### 心臟與心血管藥物相關原因 {#high-cardiac}

| 原因 | 機轉 |
|---|---|
| **[[ace-inhibitors]]、[[arb]]、[[arni]]** | 血管收縮素 II ↓ → **醛固酮 ↓** → 集尿管排鉀減少 |
| **[[potassium-sparing-diuretics|保鉀利尿劑]]**(spironolactone、eplerenone、amiloride、triamterene) | 直接阻斷醛固酮或 ENaC |
| **心衰竭合併 CKD**,同時用 RAAS 抑制劑 + MRA | 最常見的心衰竭高血鉀情境 |
| [[beta-blockers|β 阻斷劑]](尤其非選擇性) | K⁺ 進入細胞減少 |
| **[[digoxin|Digoxin]] 急性大量中毒** | 鈉鉀幫浦被抑制,K⁺ 留在細胞外 |
| Heparin | 抑制醛固酮合成 |
| 心臟手術後少尿、心跳停止/低灌流造成**代謝性酸中毒**、大量輸注**庫存血**、再灌流 | 排出減少、細胞內鉀釋出 |

### 非心臟原因 {#high-noncardiac}

| 類別 | 原因 |
|---|---|
| **腎臟排出減少** | **急性腎損傷少尿期**、慢性腎臟病(GFR < 20–30 最明顯)、急性腎絲球腎炎少尿期 |
| 醛固酮不足 | **愛迪生氏病(愛迪生危機:高血鉀、低血鈉、低血壓)**、先天性腎上腺增生、低腎素低醛固酮(糖尿病腎病變) |
| 其他藥物 | NSAID、trimethoprim、cyclosporine/tacrolimus、**succinylcholine**(去極化使 K⁺ 外流) |
| **細胞內 → 外移動** | **代謝性酸中毒**、**胰島素不足/DKA**(全身鉀其實是缺的,但血鉀可偏高)、高血糖高滲透壓、β 阻斷劑、飢餓與**熱量不足**(組織分解) |
| **細胞破壞** | **燒傷早期(48 小時內)**、擠壓傷與橫紋肌溶解、**腫瘤溶解症候群**(高鉀、高磷、高尿酸、**低鈣**)、**溶血**、腸胃道大出血、**大量輸血/保存過久的血**(換血用 72 小時內新鮮血) |
| 攝入過多 | 靜脈補鉀過快或過量、**低鈉鹽/薄鹽醬油(以 KCl 取代 NaCl)**、**雞精**、果乾、高鉀蔬果(腎功能差時) |

### 臨床表現 {#high-symptoms}

- 神經肌肉:**肌肉無力**(由下肢往上的弛緩性麻痺)、感覺異常、發麻,嚴重時呼吸肌無力。
- 腸胃:**噁心**、腹瀉、腸絞痛(腸道平滑肌興奮)。
- **心臟**:心搏過緩、心律不整、**心跳停止**——最危險,常在沒有症狀下發生。

## 偏低:低血鉀 {#low}

> 血鉀 < 3.5 mEq/L。原因:**流失(腎臟或腸胃)**、**移進細胞**、**攝取不足**。有臨床意義,重度時同樣致命。

### 心臟與心血管藥物相關原因 {#low-cardiac}

| 原因 | 機轉 |
|---|---|
| **[[loop-diuretics|Loop]]、[[thiazide-diuretics|thiazide]] 利尿劑** | 更多鈉到達集尿管 → 換出 K⁺(最常見原因) |
| 心衰竭本身 | RAAS 活化 → 次發性高醛固酮 |
| **急性心肌梗塞、急救** | 大量兒茶酚胺(內生性或**epinephrine**、β₂ 促效劑) → K⁺ 進入細胞;低血鉀會增加梗塞後心室性心律不整 |
| 胰島素輸注、碳酸氫鈉 | K⁺ 移入細胞 |
| 低血鎂 | 腎臟排鉀增加,低血鉀難以矯正 |

### 非心臟原因 {#low-noncardiac}

| 類別 | 原因 |
|---|---|
| **腸胃流失** | **嘔吐**、鼻胃管抽吸(同時代謝性鹼中毒使腎臟排鉀更多)、**腹瀉**、瀉劑濫用、霍亂、腸瘻 |
| **腎臟流失** | **原發性醛固酮症(Conn 氏症)**、**庫欣氏症候群/長期類固醇**(低血鉀性鹼中毒)、**甘草**、滲透性利尿(高血糖)、急性腎損傷**利尿期**、燒傷**利尿期**、amphotericin B |
| **移入細胞** | **代謝性鹼中毒**、**胰島素治療**(DKA 治療時血鉀會急降)、β₂ 促效劑、再餵食症候群 |
| 攝取不足 | 厭食、長期禁食、酗酒、老人營養不良 |

### 臨床表現 {#low-symptoms}

- 神經肌肉:**肌肉無力、倦怠**、腿抽筋、**深部肌腱反射減弱**、嚴重時麻痺與呼吸肌無力。
- 腸胃:**腸蠕動減少、便秘、腹脹**、麻痺性腸阻塞、噁心。
- 心臟:**心悸、心律不整**、U 波,**毛地黃中毒風險上升**。
- 腎:濃縮尿液能力下降 → 多尿;代謝性鹼中毒。
- 肝硬化病人:低血鉀使腎臟**產氨增加** → 誘發**肝性腦病變**。
- 高、低血鉀**共同**會出現的:**噁心、心律不整**(肌腱反射、腸蠕動方向則相反或不一定)。

## 干擾因素 {#interference}

### 假性高血鉀(pseudohyperkalemia) {#pseudohyperkalemia}

病人體內其實正常,是**抽血或檢體處理**讓紅血球或細胞裡的鉀跑到檢體中:

| 因素 | 說明 |
|---|---|
| **溶血** | 針頭太細、抽血太用力、血液強力從針頭推入試管、劇烈搖晃、氣送管震盪 → 最常見原因;報告通常會註明溶血 |
| **止血帶綁太久**(> 1 分鐘) | 局部缺氧、酸化,K⁺ 外移 |
| **反覆握拳**、拍打血管 | 肌肉收縮釋出 K⁺,可使數值上升 1–2 mEq/L |
| 從**正在輸注含鉀點滴的同側手臂**抽血 | 檢體被點滴污染 |
| 檢體**放置過久**或冷藏全血 | 鈉鉀幫浦停止,K⁺ 漏出 |
| 採血順序錯誤(EDTA 紫頭管污染) | 假性高鉀 + 假性低鈣 |
| 血小板或白血球極高 | 凝血時細胞釋出 K⁺;改驗血漿(肝素管) |

→ 結果與臨床不符(沒有心電圖變化、沒有腎病或用藥)時,**先重抽**,但若有心電圖變化,**當真的處理**。

### 假性低血鉀 / 其他 {#other-interference}

- 從**同側不含鉀的輸液**手臂抽血 → 稀釋。
- 白血球極高(白血病)的檢體在室溫放置 → 細胞把 K⁺ 吸回去。
- **酸鹼狀態**:酸中毒使血鉀看起來偏高、鹼中毒偏低,需要一起判讀(見 [[abg]])。

## 檢體採集與護理 {#nursing}

### 採集 {#collection}

- 綠頭(肝素)或紅/黃頭(血清)管;**止血帶 < 1 分鐘、不要請病人反覆握拳**、避免拍打血管。
- 不從輸液同側手臂抽血;若必須,先停點滴並丟棄前段血。
- 針頭不要太細、抽血與注入試管動作輕柔、**輕輕上下顛倒混勻,不可用力搖晃**;儘快送檢。

### 靜脈補鉀(KCl)規則 {#iv-replacement}

氯化鉀是**高警訊藥物**:

| 規則 | 內容 |
|---|---|
| **絕對不可 IV push**(靜脈推注),也不可 IM、SC | 直接推注會造成致命心律不整、心跳停止;醫囑寫「IV push」或**沒寫途徑**,都要**先向醫師確認劑量與途徑** |
| **一定要稀釋** | 周邊靜脈濃度一般 **≤ 40 mEq/L**(部分機構至 60);更高濃度需中心靜脈 |
| **速率** | 一般病房 **≤ 10 mEq/h**;加護單位、中心靜脈並有心電圖監測時可至 20 mEq/h(依機構規範) |
| **有尿才補**(no pee, no K) | 補鉀前確認腎功能與尿量 **≥ 0.5 mL/kg/h(約 ≥ 30 mL/h)**;DKA 也是確認有尿後才補 |
| **使用輸液幫浦** | 不以重力滴注控制速率 |
| 加藥後**充分混勻** | 翻轉點滴袋數次,避免 KCl 沉在底部一次大量輸入;不在**正在滴注中**的點滴直接加藥 |
| 注意注射部位 | KCl 刺激血管:**疼痛、灼熱、發紅不是「正常現象」**,要評估靜脈炎、放慢速率或更換部位 |
| 監測 | 補鉀中追蹤血鉀、心電圖、尿量;同時矯正低血鎂 |

**計算範例**:醫囑「0.9% N/S 500 mL + 15% KCl 15 mEq IVD keep 10 hrs」,15% KCl 20 mEq/10 mL(2 mEq/mL):

- 抽取 15 ÷ 2 = **7.5 mL**(不是 1.5 mL)。
- 速率 500 mL ÷ 10 h = 50 mL/h;精密輸液套(60 gtt/mL)→ **50 gtt/min**。
- 濃度約 30 mEq/L、1.5 mEq/h,在安全範圍內。

**口服補鉀**:輕中度低血鉀首選;隨餐、配一大杯水,**緩釋錠不可咬碎**,注意腸胃刺激與黑便。

### 高血鉀的緊急處理 {#hyperkalemia-treatment}

依 UK Kidney Association(2023)與 2025 AHA 原則,**三個步驟同時進行**,並持續心電圖監測:

| 步驟 | 藥物/措施 | 起效與注意 |
|---|---|---|
| **① 穩定心肌膜**(有心電圖變化或 K⁺ ≥ 6.5 時) | **10% calcium gluconate** 靜脈注射(成人常用 30 mL,2–10 分鐘內緩慢給),或 calcium chloride(需中心靜脈) | 1–3 分鐘起效、維持 30–60 分鐘;**不會降低血鉀**;服用 digoxin 者需慢給並監測 |
| **② 把鉀移入細胞** | **Regular insulin 10 U IV + 葡萄糖 25 g**(如 50% 葡萄糖 50 mL,D50W) | 15–30 分鐘起效、維持 4–6 小時;**每小時監測血糖**至少 6 小時(低血糖);**要用短效 RI 靜脈注射**,不是中長效胰島素或皮下 |
| | **β₂ 促效劑** salbutamol 10–20 mg 霧化吸入 | 與胰島素合用效果相加;心搏過速 |
| | **碳酸氫鈉** | 只在合併**代謝性酸中毒**時考慮 |
| **③ 把鉀排出體外** | **陽離子交換樹脂**:Kayexalate®(sodium polystyrene sulfonate)、**Kalimate®**(calcium polystyrene sulfonate)**口服或保留灌腸**;新型 sodium zirconium cyclosilicate、patiromer | 數小時起效;口服樹脂可能便秘,避免與 sorbitol 併用於術後腸蠕動差者 |
| | **Loop 利尿劑**(仍有尿者) | 增加尿中排鉀 |
| | **血液透析** | 最確實;腎衰竭、藥物無效或危及生命時(**急性高血鉀是緊急透析適應症**) |
| **同時** | 停止所有鉀來源(含 KCl 點滴、保鉀藥物、ACEI/ARB)、找出原因 | **限制高鉀食物**,絕不是「多吃香蕉柳丁」 |

**心跳停止時**(2025 AHA ACLS):以高品質 CPR、電擊、epinephrine 等標準流程為主;高/低血鉀屬可逆原因 **Hs & Ts** 之一,懷疑高血鉀時依醫囑加上鈣劑、胰島素葡萄糖、碳酸氫鈉,並盡快安排透析。低張 0.3% NaCl 與降鉀無關。

### 低血鉀的處理 {#hypokalemia-treatment}

- 找原因(利尿劑、嘔吐腹瀉)並停止流失;**輕中度口服補充 + 高鉀飲食**,重度(< 2.5)、有心律不整或無法口服時靜脈補充。
- 一起檢查並補充**鎂**。
- 限制活動、**預防跌倒**(肌肉無力、心律不整),**不要鼓勵病人多下床活動**;監測心率心律。

### 飲食衛教 {#diet}

| 高鉀食物(高血鉀者避免、低血鉀者可多吃) | 說明 |
|---|---|
| 香蕉、柳丁、柑橘、奇異果、芭樂、哈密瓜、番茄、楊桃 | 腎衰竭者楊桃另有神經毒性,完全避免 |
| 深綠色蔬菜、馬鈴薯、地瓜、菇類、竹筍 | 腎病者蔬菜**先用滾水燙過、不喝菜湯**可減少鉀 |
| **雞精、肉湯、濃湯**、果乾、堅果、巧克力、咖啡 | |
| **低鈉鹽、薄鹽醬油** | 以**氯化鉀**取代鈉,腎病及服用保鉀藥物者禁用 |

腎功能不全者還要**避免熱量不足或長期飢餓**(組織分解釋出鉀)。

## 與利尿劑、ACEI、毛地黃的關係 {#drug-relations}

| 藥物 | 對血鉀 | 護理重點 |
|---|---|---|
| [[loop-diuretics]]、[[thiazide-diuretics]] | **↓(排鉀)** | 監測 K⁺、Mg²⁺;適量高鉀飲食或補鉀 |
| [[potassium-sparing-diuretics]] | **↑** | 避免鉀補充劑、低鈉鹽、高鉀食物 |
| [[ace-inhibitors]]、[[arb]]、[[arni]] | **↑** | 開始後 1–2 週抽血;與 MRA 併用更要監測 |
| [[digoxin]] | 慢性:**低血鉀使毒性上升**;急性中毒:高血鉀 | 給藥前確認 K⁺;心電圖 U 波要警覺 |
| 胰島素、β₂ 促效劑、epinephrine | **↓(移入細胞)** | 也是高血鉀的治療藥物 |
| [[beta-blockers]] | 輕度 ↑ | |
| 類固醇、甘草、amphotericin B | **↓** | 併用利尿劑或 digoxin 時更危險 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 正常值 **3.5–5.0 mEq/L**;2.9、2.7 = 低血鉀(常見原因:**嘔吐**、排鉀利尿劑;衛教:**攝取富含鉀之食物**)。
- **高血鉀心電圖**:**T 波高尖**、P 波變平、QRS 變寬、房室阻斷;「T 波低而寬」錯。**低血鉀**:T 波變平、ST 下降、**U 波** → 注意**毛地黃中毒**。
- 細胞外 K⁺ 增加 → **靜止膜電位減小**;大量 K⁺ 使心房到心室的傳導被阻斷。
- **高血鉀導因**:ACEI、醛固酮拮抗劑、**代謝性酸中毒**、溶血、組織破壞(燒傷早期、腫瘤溶解);「**胰島素分泌過多**」、thiazide、代謝性鹼中毒 → **低**血鉀。
- 高血鉀處置:**Kayexalate/Kalimate(口服或灌腸)**、**RI + 50% 葡萄糖靜注**、**碳酸氫鈉**、**緊急透析**;錯誤選項:中長效胰島素 + 5% 葡萄糖、0.3% NaCl、多吃香蕉柳丁。
- **KCl 絕不可 IV push**;醫囑沒寫途徑或寫 IV push → 向醫師**澄清途徑(與劑量)**。
- 腎衰竭/少尿期、急性腎絲球腎炎少尿期 → **限制高鉀食物**(香蕉);「給高鉀飲食預防低血鉀」錯。
- 預防腎功能不全高血鉀:**避免熱量不足或長期飢餓**;雞精、低鈉鹽、果乾都是高鉀。
- **Conn 氏症、庫欣氏症 → 低血鉀**;**愛迪生危機 → 高血鉀、低血鈉**;嗜鉻細胞瘤 5P 不包括高血鉀。
- **DKA**:補足體液、**確認尿量後再補鉀**;低血鉀會誘發**肝性腦病變**。
- 高、低血鉀都會出現:**噁心、心律不整**。
- 排鉀利尿劑病人出現肌肉無力、心悸 → **不要鼓勵多下床**,監測心律、評估電解質、補鉀食物。
- 換血用 **72 小時內**的新鮮血,避免高血鉀。
:::
