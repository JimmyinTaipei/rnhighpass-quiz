血清鈣反映**骨頭釋出、腸道吸收、腎臟排出**三者的平衡，由 **PTH**、**活性維生素 D** 與**降鈣素**調節；血磷大多和血鈣反方向變動。鈣決定神經肌肉的興奮性，所以**低血鈣興奮（抽搐）、高血鈣抑制（無力、便秘）**。調節的生理見 [[thyroid-parathyroid#calcium-regulation]]，副甲狀腺疾病見 [[parathyroid-disorders]]

## 重點摘要 {#summary}

- 總鈣正常約 **8.5–10.5 mg/dL**；血磷（成人）約 **2.5–4.5 mg/dL**；各院參考值略有不同
- 血中約一半的鈣和**白蛋白**結合，真正有作用的是**游離鈣**；**白蛋白低**時總鈣會被**低估**，要校正或直接測游離鈣
- **低血鈣**：神經肌肉**興奮** → 刺麻、**手足抽搐**、**Chvostek**、**Trousseau**、喉部痙攣、**QT 延長**、低血壓、**腹瀉**
- **高血鈣**：神經肌肉**抑制** → 無力、反射減弱、**便秘**、噁心、多尿與脫水、**腎結石**、意識混亂、**QT 縮短**、心律不整
- 高血鈣最常見原因：**原發性副甲狀腺機能亢進**（門診）與**癌症**（住院）；**長期臥床**也會讓血鈣上升
- 高血磷：**腎衰竭**（急性少尿期、慢性）、副甲狀腺功能低下；**限磷**＋隨餐**磷結合劑**

### 國考常考點 {#exam-points}

- 血鈣 6.8 mg/dL（低血鈣）：強直性痙攣、血壓下降；**不會便秘**（低血鈣是腹瀉）
- 低血鈣：**Chvostek 徵象**是**臉部**肌肉抽動；心電圖 **QT 延長**；國考把「凝血時間延長」算作低血鈣表現（鈣是凝血因子 IV）
- 高血鈣：肌肉張力**下降**、反射**減弱**、**QT 縮短**；飲食**酸灰性食物**、多喝水、**高纖**
- **長期臥床**骨鈣流失 → **高血鈣**（不是低血鈣）與尿鈣增加
- 癌症：**骨轉移**造成**高血鈣**；白蛋白低時要**校正鈣**以免低估；治療大量補水、furosemide 排鈣、**zoledronic acid(Zometa)**
- 急性腎衰竭**少尿期血磷上升**；慢性腎衰竭**高血磷**（不是低血磷）
- 高血磷：少吃**堅果、糙米**、服**磷結合劑**、**防跌**（合併低血鈣）；**不補維生素 D**（增加磷吸收）
- 腎臟活化的**維生素 D 增加**腸道鈣吸收（不是抑制）

## 鈣在哪裡、怎麼調節 {#origin}

- 體內鈣 **99% 在骨頭**，血中只有約 1%
- 血中的鈣
   1. 約 **45% 游離鈣**（有生理作用）
   2. 約 **40% 和白蛋白結合**
   3. 其餘和檸檬酸、磷酸等結合
- 調節：血鈣下降 → **PTH** 上升 → 骨釋鈣、腎回收鈣、活化維生素 D 增加腸吸收；機轉表見 [[thyroid-parathyroid#calcium-regulation]]
- 鈣的功能：神經肌肉興奮性（鈣多 → 細胞膜較穩定、較難興奮）、肌肉收縮、**凝血**、心肌收縮、骨骼與牙齒

## 參考值與判讀 {#reference-range}

| 項目 | 參考值（成人） | 說明 |
|---|---|---|
| 總鈣 | 約 **8.5–10.5 mg/dL** | 低白蛋白時偏低但游離鈣可能正常 |
| 游離鈣 | 約 4.5–5.3 mg/dL(1.12–1.32 mmol/L) | 血液氣體分析機可測；數值依各院（**待核對**） |
| 血磷 | 約 **2.5–4.5 mg/dL** | 兒童較高 |

- **校正鈣**（白蛋白以 g/dL 計）：校正鈣 ≈ 測得總鈣 ＋ 0.8 ×（4 − 白蛋白），例如白蛋白 2.0、總鈣 10.0 → 校正約 11.6，其實是高血鈣
- **酸鹼**影響游離鈣：**鹼中毒**時白蛋白結合更多鈣 → 游離鈣下降 → 可能抽搐（換氣過度的手腳麻）；**酸中毒**時游離鈣上升
- 單位：有些題目用 **mEq/L**（鈣 2 價，1 mEq/L ≈ 2 mg/dL；總鈣約 4.5–5.5 mEq/L），先看單位再判讀

## 偏低：低血鈣 {#low}

### 原因 {#low-causes}

| 類別 | 原因 |
|---|---|
| PTH 不足 | **甲狀腺或副甲狀腺手術後**、副甲狀腺功能低下、**低血鎂** |
| 維生素 D 不足 | 缺乏日曬或攝取、吸收不良、**慢性腎病**（無法活化） |
| 鈣被結合或沉積 | **急性胰臟炎**（鈣與脂肪酸結合成皂）、**大量輸血或換血**（血袋中的**檸檬酸**結合鈣）、**高血磷**、腫瘤溶解症候群 |
| 其他 | **鹼中毒**（游離鈣下降）、低白蛋白（總鈣偏低）、loop 利尿劑 |

- 新生兒換血用含檸檬酸抗凝劑的血 → **低血鈣**，依醫囑補**葡萄糖酸鈣**（不是降鈣素）

::questions{ids="108-2_OP_064"}

### 表現 {#low-symptoms}

- 神經肌肉興奮：**口周與指尖刺麻**、肌肉痙攣、**手足抽搐**、**Chvostek 徵象**（輕敲耳前，臉部抽動）、**Trousseau 徵象**（袖帶充氣後手腕屈曲）、**喉部痙攣**、癲癇
- 心血管：**QT 延長**、心律不整、心收縮力下降 → **低血壓**
- 腸胃：腸蠕動增加、腹痛、**腹瀉**
- 凝血：鈣是凝血因子，國考題算「凝血時間延長」
- 長期：白內障、皮膚乾、指甲脆

::questions{ids="105-2_MS_060,107-1_MS_060,106-2_makeup_MS_062,111-1_MS_060"}

### 處理 {#low-treatment}

1. 急性有症狀：**靜脈 10% 葡萄糖酸鈣**慢慢推、監測心電圖；防外滲；不和碳酸氫鈉或磷酸鹽同管
2. 床邊備呼吸道設備（喉部痙攣）；癲癇防護、環境安靜
3. 慢性：口服鈣＋維生素 D；同時處理低血鎂、高血磷
4. 副甲狀腺疾病的完整照護見 [[parathyroid-disorders#acute-hypocalcemia]]

## 偏高：高血鈣 {#high}

### 原因 {#high-causes}

| 類別 | 原因 |
|---|---|
| PTH 過多 | **原發性副甲狀腺機能亢進**（門診最常見） |
| **癌症**（住院最常見） | **骨轉移**（乳癌、肺癌等）溶骨（前列腺癌多為成骨性，較少高血鈣）；**多發性骨髓瘤**；腫瘤分泌 **PTHrP**（肺鱗狀細胞癌、腎細胞癌） |
| 骨鈣流失 | **長期臥床、不活動**（骨頭缺乏負重刺激）、甲狀腺機能亢進 |
| 藥物與攝取 | **thiazide** 利尿劑（減少尿鈣）、鋰鹽、過量維生素 D 或鈣片 |

- 長期臥床也會讓**尿鈣**增加 → 腎結石；這是不活動的併發症，見 [[spinal-cord-injury]] 等長期臥床病人的照護

::questions{ids="109-1_FA_029,105-2_FA_050,112-3_FA_026,113-3_MS_041,112-3_MS_024,106-2_MS_036"}

### 表現 {#high-symptoms}

- 神經肌肉抑制：**肌肉無力**、張力下降、**深肌腱反射減弱**、倦怠
- 中樞：注意力差、**意識混亂**、嗜睡，嚴重時昏迷
- 腸胃：**便秘**、**噁心嘔吐**、食慾差、消化性潰瘍、胰臟炎
- 腎臟：**多尿**、尿比重下降、口渴、**脫水**、**腎結石**
- 心臟：**QT 縮短**、**心律不整**；增加**毛地黃毒性**
- 口訣：骨頭（骨痛）、石頭（腎結石）、肚子（便秘、噁心）、心情（意識與情緒）

### 處理 {#high-treatment}

1. **大量補水**：生理食鹽水恢復血量、增加腎臟排鈣（高血鈣常合併脫水）
2. 補足水分後依醫囑給 **furosemide**（loop 利尿劑會**增加**尿鈣排出，見 [[loop-diuretics]]）；**不用 thiazide**（會減少尿鈣排出）
3. **雙磷酸鹽**（**zoledronic acid**，商品名 Zometa；pamidronate）抑制蝕骨細胞，是**癌症高血鈣**的主要藥物；**降鈣素**作用快但短
4. 飲食與衛教：**多喝水**（約每天 3000 mL，無心腎禁忌時）、**限鈣**（不鼓勵喝牛奶）、**高纖**防便秘、**酸灰性食物**（肉、蛋、穀類）酸化尿液減少結石
5. **鼓勵活動**、防跌與防病理性骨折；監測心律與意識
6. allopurinol 是降尿酸的藥，和高血鈣無關

::questions{ids="114-3_MS_040,115-1_MS_023,115-1_MS_024,113-2_BM_035"}

## 血磷 {#phosphate}

- 磷大部分在骨頭，也存在細胞內(ATP)；主要由**腎臟**排出，所以**腎衰竭**時最容易升高
- 鈣磷大多**反方向**：PTH 讓鈣上升、磷下降；腎衰竭時磷滯留、鈣下降，刺激**續發性副甲狀腺機能亢進**

| | 高血磷 | 低血磷 |
|---|---|---|
| 原因 | **急性腎衰竭（少尿期）**、**慢性腎衰竭**、**副甲狀腺功能低下**、腫瘤溶解症候群、橫紋肌溶解 | **副甲狀腺機能亢進**、再餵食症候群、酒精、呼吸性鹼中毒、長期用含鋁制酸劑 |
| 表現 | 本身症狀少，主要是合併的**低血鈣**（抽搐）；長期**軟組織鈣化**、皮膚癢 | 肌肉無力、呼吸肌無力、溶血、意識改變 |

### 高血磷的護理 {#hyperphosphatemia-nursing}

1. **限磷飲食**：少吃**堅果**、**糙米**與全穀、乳製品、蛋黃、內臟、加工肉品、**可樂**等含磷添加物的食品
2. **磷結合劑**：碳酸鈣、醋酸鈣、氫氧化鋁、sevelamer 等，**隨餐**服用，在腸道結合食物中的磷
3. **不補維生素 D**（會增加腸道磷吸收），除非醫師為了控制 PTH 處方活性維生素 D
4. 合併低血鈣時要**防跌**、注意抽搐
5. 慢性腎病的完整照護見 [[chronic-kidney-disease]]
