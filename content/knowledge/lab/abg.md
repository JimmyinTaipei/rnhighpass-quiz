由動脈抽血,評估**酸鹼平衡**與**氧合/換氣**。本頁著重在糖尿病相關的代謝性酸中毒判讀。

## 參考值 {#reference-range}

| 項目 | 正常值 | 說明 |
|---|---|---|
| **pH** | **7.35–7.45** | < 7.35 酸血症;> 7.45 鹼血症 |
| **PaCO₂** | **35–45 mmHg** | 呼吸性成分(肺調節) |
| **HCO₃⁻** | **22–26 mEq/L** | 代謝性成分(腎臟調節) |
| PaO₂ | 80–100 mmHg | 氧合 |
| SaO₂ | 95–100% | |
| 鹼基過量(BE) | −2 ~ +2 | |
| 陰離子間隙(AG) | 8–12 mEq/L | = Na⁺ − (Cl⁻ + HCO₃⁻) |

## 判讀步驟 {#interpretation}

1. **看 pH**:酸或鹼?
2. **看 PaCO₂ 與 HCO₃⁻ 誰和 pH 同方向**——同方向的是原發問題(口訣 ROME:Respiratory Opposite、Metabolic Equal)。
   - pH↓ + HCO₃⁻↓ → **代謝性酸中毒**
   - pH↓ + PaCO₂↑ → 呼吸性酸中毒
3. **看代償**:代謝性酸中毒時肺會**過度換氣**把 PaCO₂ 降低。預期 PaCO₂ ≈ **1.5 × HCO₃⁻ + 8(± 2)**(Winter's 公式);實際值不符表示合併呼吸性問題。
4. **代謝性酸中毒要算陰離子間隙**:
   - **AG 增加**:酮酸(**DKA**、酒精性、飢餓)、**乳酸**中毒(休克、metformin 相關)、**腎衰竭**、毒物(甲醇、乙二醇、水楊酸)
   - AG 正常(高氯性):**腹瀉**、腎小管酸中毒

## 糖尿病急症的血氣表現 {#dka-pattern}

| | DKA | HHS |
|---|---|---|
| pH | **< 7.30**(輕 7.25–7.30;中 7.00–7.24;重 < 7.00) | > 7.30 |
| HCO₃⁻ | **< 18 mEq/L** | > 18 mEq/L |
| PaCO₂ | 代償性**下降**(Kussmaul 呼吸) | 正常 |
| 陰離子間隙 | **增加**(> 10–12) | 正常或輕度增加 |

- DKA 是**原發性代謝性酸中毒**合併呼吸代償,**不是**呼吸性酸中毒,也不是鹼中毒。
- 例:pH 7.2、HCO₃⁻ 14 mEq/L、血清滲透壓 < 320 → 典型 DKA。
- **鉀**:酸中毒時 H⁺ 進入細胞、K⁺ 移出 → 血鉀可正常或偏高,但全身鉀不足;治療後會快速下降。
- 重碳酸鈉只在嚴重酸中毒(pH < 6.9–7.0)時考慮。

## 血漿滲透壓 {#osmolality}

- 計算:**2 × Na⁺ + 血糖/18 + BUN/2.8**(mOsm/kg);有效滲透壓 = 2 × Na⁺ + 血糖/18。
- 正常約 **275–295 mOsm/kg**。
- **> 320 mOsm/kg** 為 HHS 的診斷標準之一,會出現意識障礙。
- 例:Na⁺ 140、血糖 600 → 有效滲透壓 ≈ 280 + 33 = 313;血糖 1,000 → ≈ 336。

## 干擾因素 {#interference}

| 狀況 | 影響 |
|---|---|
| **針筒內有氣泡** | PaO₂ 偏高、PaCO₂ 偏低 |
| **送驗延遲**(室溫 > 30 分鐘) | 血球持續代謝:PaO₂ 下降、PaCO₂ 上升、pH 下降 |
| 肝素過多 | 稀釋 → PaCO₂、HCO₃⁻ 偏低 |
| 抽到靜脈血 | PaO₂ 明顯偏低 |
| 未記錄給氧濃度與體溫 | 無法正確判讀氧合 |
| 抽血前改變呼吸器設定或抽痰 | 需等約 15–20 分鐘穩定 |

## 檢體採集與護理 {#nursing}

1. 橈動脈穿刺前做 **Allen 氏試驗**,確認尺動脈側支循環足夠。
2. 使用**肝素化**空針;抽血後立即**排除氣泡**並封蓋。
3. 標示給氧方式/濃度(FiO₂)與體溫。
4. 穿刺處**加壓至少 5 分鐘**(使用抗凝劑者 10 分鐘以上),觀察出血與血腫、遠端循環。
5. 儘快送驗(塑膠空針 30 分鐘內室溫送驗;若延遲依院內規定)。
