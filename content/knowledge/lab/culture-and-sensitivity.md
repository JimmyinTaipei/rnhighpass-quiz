**培養**(culture)是把檢體放在培養基中，讓裡面的微生物長出來，再做**菌種鑑定**與**感受性試驗**(哪些抗生素有效)。它是確定感染病原、**選擇抗生素種類的依據**。檢體若在抗生素之後才採、採集時被污染、或放太久才送，結果就會失真，所以護理師的採檢技術直接影響診斷與治療。

## 重點摘要 {#summary}

- 培養做**菌種鑑定**與**感受性試驗**，是**選擇抗生素的依據**；CRP、ESR 不能用來選抗生素。
- **先採檢體、再給抗生素**。
- 血液培養：**2 套、不同部位**，瓶口用 70% 酒精消毒，空針注入**先厭氧瓶、後需氧瓶**。
- 中段尿：先解前段再接中段，30 分鐘內送檢；診斷標準 ≥ 10⁵ CFU/mL。
- 痰液：清晨、清水漱口；結核至少 2 次；確診肺結核最準確是痰液培養。

### 國考常考點 {#exam-points}

- 可作為**選擇抗生素種類依據**的檢驗：**培養**(血液、尿液)，不是 CRP、ESR、D-dimer。
- **先採檢體、再給抗生素**。
- 血液培養：**2 套、不同部位**；**不須禁食**；**瓶口用 70% 酒精**消毒；**空針注入時先厭氧瓶、後需氧瓶**；不可從輸液管路或輸液部位抽血。
- 中段尿：先解前段、無菌容器接中段；**30 分鐘內送檢**，否則冷藏；月經期間用**單次導尿**；診斷標準 **≥ 10⁵ CFU/mL**。
- 存留導尿管：**夾管 15–30 分鐘 → 消毒採檢口 → 無菌空針抽取**，不可從蓄尿袋取。
- 痰液：清晨、**清水漱口**、不用牙膏；氣切者**抽痰**取檢體；延遲送檢要**冷藏**不可放室溫；結核**至少 2 次、最好 3 次**。
- 阿米巴：**保溫、30 分鐘內送檢**；蟯蟲：**早上洗澡前**膠帶採檢。
- 確診肺結核最準確的方法：**痰液培養**。

## 檢驗原理 {#origin}

| 步驟 | 內容 | 時間 |
|---|---|---|
| 直接鏡檢 | **革蘭氏染色**看形態與顏色(見[[microbial-pathogenesis#gram-stain]])；結核菌用**抗酸性染色** | 數十分鐘到數小時，提供初步方向 |
| 培養 | 需氧與厭氧培養；結核菌、黴菌要用專用培養基 | 多數細菌 1–3 天長出 |
| 鑑定 | 生化反應、質譜儀、分子方法 | 長出後數小時到 1 天 |
| **感受性試驗** | 測出**最低抑菌濃度**(MIC)，判定對各抗生素**敏感**(S)、中間(I)或**抗藥**(R) | 再 1–2 天 |

- **血液培養**：自動化系統一般培養 **5 天**；有意義的菌血症**多在 48 小時內**長出，黴菌需要再 1–2 天([UpToDate：blood cultures](https://www.uptodate.com/contents/detection-of-bacteremia-blood-cultures-and-other-diagnostic-tests))。題目說「通常 3–7 天才有結果報告」是可以接受的敘述。
- **結核菌**：痰**塗片**每毫升要有約 **5,000–10,000 隻**菌才看得到，**培養**只要 **10–100 隻**，所以培養較敏感；固體培養基約 3–8 週長出、陰性要等 **8 週**，液體培養陰性要等 **6 週**(疾管署《結核病診治指引》第七版)。

## 結果判讀 {#interpretation}

### 感受性報告 {#susceptibility}

- 經驗性治療後，依報告改用**有效且較窄效**的藥物(見[[antibiotics-overview#empiric-definitive]])。
- 報告「抗藥」(R)的藥物即使臨床看似有效，也應與醫師討論是否更換。

### 尿液菌落數 {#urine-colony-count}

| 檢體 | 有意義的菌數 |
|---|---|
| **中段尿** | 每毫升 **≥ 10⁵ CFU**(菌落形成單位)是傳統的**泌尿道感染**診斷標準 |
| 導尿或恥骨上穿刺 | 較低的菌數即有意義(導尿檢體常用 ≥ 10³ CFU/mL) |

「尿液培養菌落數 > 100 CFU/mL」**不足以**診斷泌尿道感染；「> 10⁵ 表示正常」也是錯誤選項。

### 污染與偽陽性 {#contamination}

- 皮膚常在菌：**凝固酶陰性葡萄球菌**(如表皮葡萄球菌)、棒狀桿菌、痤瘡桿菌、芽孢桿菌。若只有一套血液培養長出這類菌，多半是**採檢污染**；兩套以上都長出才比較可能是真正感染(人工瓣膜、導管感染者例外)。
- 血液培養污染率目標是 **< 1%**；污染會導致不必要的抗生素、檢查與住院天數。

### 偽陰性 {#false-negative}

- **採檢前已使用抗生素**：最常見的原因(例如治療中的泌尿道感染複檢，培養陰性)。
- 血量或檢體量不足、送檢延遲、保存溫度不對。
- 病原無法用一般培養基培養(如黴漿菌、披衣菌、病毒)。

## 血液培養 {#blood-culture}

**適應症**：發燒合併寒顫、疑似**敗血症**、嗜中性白血球低下發燒、心內膜炎、導管相關血流感染。

| 項目 | 做法 | 原因 |
|---|---|---|
| **時機** | **給抗生素之前**；發燒、寒顫時抽 | 先給抗生素的陽性率明顯下降 |
| 是否禁食 | **不需要禁食** | 與血糖、血脂檢查不同 |
| **套數** | 成人**至少 2 套**，最好從**不同部位**分別穿刺 | 兩個部位同時長出皮膚菌的機會低，方便區分污染與真正感染；**不可同時同部位抽兩套** |
| **每套組成** | 一瓶**需氧瓶**＋一瓶**厭氧瓶** | 兩種菌都能長 |
| **血量** | 成人每套約 **20 mL**(每瓶約 10 mL)；兒童依體重減量，可只打入需氧瓶 | **血量是影響陽性率最重要的因素** |
| **部位** | 周邊靜脈穿刺(肘前靜脈)；**不可從正在輸液的管路或同側肢體抽** | 經導管抽的污染率較高，稀釋也會失真；懷疑導管感染時才由導管與周邊**各抽一套**比較 |
| **皮膚消毒** | **2% chlorhexidine 酒精**或含酒精的碘製劑，**待乾 30–60 秒**；消毒後不再觸摸穿刺點 | 減少皮膚菌污染；不含酒精的優碘效果較差 |
| **瓶口消毒** | 掀開瓶蓋後用 **70% 酒精**消毒橡皮塞並待乾 | **不用碘酒**消毒瓶口(會殘留、損壞橡皮塞) |
| **注入順序** | 用**空針**抽血：**先注入厭氧瓶、再注入需氧瓶**；用**蝴蝶針**直接接瓶：**先接需氧瓶** | 空針最後一段常混有空氣，應打入需氧瓶；蝴蝶針管路內的空氣先進入需氧瓶 |
| 血量不足 | 全部打入**需氧瓶** | 多數病原需氧或兼性厭氧 |
| 標示與送檢 | 標示採檢部位與時間；**室溫**儘快送檢，**不可冷藏** | 低溫影響細菌存活 |

:::note[換針頭嗎？新舊做法]
舊教材與國考答案：抽血後**換一支無菌針頭**再注入培養瓶(109-1_FA_045)。
現行做法：UpToDate 與國內醫院檢驗科都建議**注入培養瓶時不必換針頭**，因為換針頭沒有降低污染，反而**增加針扎風險**；只有穿刺失敗要重新扎針時才換新針([UpToDate](https://www.uptodate.com/contents/detection-of-bacteremia-blood-cultures-and-other-diagnostic-tests)、[嘉義基督教醫院檢驗科](https://www.cych.org.tw/lab/2_%E6%AA%A2%E9%AB%94%E6%8E%A1%E9%9B%86/procedure_bacteria.htm))。考題依舊答案作答，臨床依醫院規範。
:::

## 尿液培養 {#urine-culture}

尿液**常規檢查**看尿液性狀，**不能作為使用抗生素的依據**；**尿液培養**才能確認菌種並作為選藥依據。

### 清潔中段尿 {#midstream}

1. 洗手；女性由**前往後**清潔會陰，男性清潔尿道口(用清水或無菌紙巾，不需要優碘由後往前消毒)。
2. **先解掉前段尿**沖洗尿道口，再以**無菌容器**接取**中段尿**約 10–20 mL，剩下的尿解入馬桶([臺大醫院檢驗醫學部](https://www.ntuh.gov.tw/labmed/Fpage.action?fid=5132))。
3. 不可碰觸容器與蓋子內面。
4. **儘速送檢**：國考答案是 **30 分鐘內**；無法立即送檢時放 **4℃ 左右冰箱**(2–8℃)，一般不超過 24 小時。細菌在室溫下會繼續繁殖，菌數會假性升高。
5. 以清晨第一次尿為佳；**月經期間**或無法自解時，改用**單次導尿**取得檢體。

### 存留導尿管病人 {#catheter-specimen}

1. 用止血鉗**夾住引流管**(在採檢口下方)約 **15–30 分鐘**，讓新鮮尿液聚積。
2. 以酒精消毒**導尿管的採檢口**(橡皮接頭處)。
3. 用**無菌空針**由採檢口抽取尿液，注入無菌容器；**放開止血鉗**。
4. **不可**：從**蓄尿袋**倒出尿液、**分開導尿管與引流管**接頭取尿、拔掉導尿管改收自解尿。

:::tip[為什麼不能從蓄尿袋取尿]
蓄尿袋中的尿液已經存放一段時間，細菌大量繁殖，無法反映膀胱內真正的菌數；打開密閉系統則會把細菌帶進去，增加導尿管相關泌尿道感染。
:::

## 痰液培養 {#sputum-culture}

1. **清晨第一口痰**最好；採檢前**用清水漱口**，**不要用牙膏或漱口水**(可能殺死細菌、污染檢體)。
2. 深呼吸後**用力咳出氣管深部的痰**，不是口水或鼻涕；口咽部唾液不能代替痰液。
3. 痰少或黏稠：多喝水、**蒸氣或生理食鹽水噴霧吸入**稀釋痰液、姿位引流與叩擊(**血小板低下**、出血風險高的病人避免叩擊與高壓抽痰)。
4. **氣切或插管**病人：以**無菌抽痰**配合痰液收集器取得檢體。
5. **儘速送檢**；無法立即送檢時**冷藏**(2–8℃)，**不可放室溫**。
6. **結核病**：痰檢體**至少 2 次，最好 3 次，其中至少 1 次是清晨痰**([疾管署《結核病診治指引》第七版](https://www.cdc.gov.tw/InfectionReport/Info/SVtdjRgESOT_EwbAhjIJ4g?infoId=WntFbrMaP_QEYVFYkm11og))。自 2025 年 3 月起，疾管署也要求疑似結核病人全面使用**快速分子檢測**([致醫界通函第 563 號](https://www.cdc.gov.tw/Bulletin/Detail/cKtd2It31EpIrEFt2V-ZvQ?typeid=48))。

**疑似細菌性肺炎**的新入院病人，要在第一劑抗生素前**先收集痰液培養**。

## 糞便檢體 {#stool}

| 檢查 | 重點 |
|---|---|
| 常規檢查 | 用壓舌板取約**花生米大小**(稀便約 5–10 mL)；**先排空膀胱**再解便，避免尿液污染；可檢查細菌、寄生蟲、潛血 |
| 細菌培養 | 無菌容器；**不可用棉棒直接從馬桶挖取**；可以檢出**痢疾桿菌**等 |
| **阿米巴原蟲** | 活動型原蟲離開人體很快死亡，檢體要**保持接近體溫、30 分鐘內送檢**，**不可冷藏** |
| **蟯蟲** | **早上起床後、洗澡與排便前**，用透明膠帶黏貼肛門周圍 |
| 潛血 | 月經期間可能**偽陽性**；檢查前避免紅肉與鐵劑(依檢驗方法而定) |

## 傷口與其他檢體 {#other-specimens}

- **傷口**：先用**無菌生理食鹽水**沖掉表面的壞死組織與分泌物，再從**乾淨的傷口基底**取檢體；深部膿瘍以**空針抽取**，同時送需氧與厭氧培養。
- 淋病：採**子宮頸口分泌物**培養；**披衣菌**是細胞內寄生菌，檢體要**含有受感染的細胞**(刮取)，不是清澈的分泌物。
- **急性會厭炎**：**不可**用壓舌板檢查或做喉頭培養，可能誘發喉痙攣與完全阻塞。
- 呼吸道融合病毒：採**鼻咽分泌物**做抗原或分子檢測，不做細菌培養。
- 腦脊髓液：由醫師腰椎穿刺取得，立即送檢，不可冷藏。

## 干擾因素 {#interference}

| 因素 | 影響 |
|---|---|
| **採檢前已用抗生素** | 偽陰性 |
| 皮膚或周圍菌叢污染(消毒不完全、未取中段尿、從蓄尿袋取尿) | 偽陽性、混合菌 |
| 送檢延遲、放室溫(尿液、痰液) | 菌數假性增加或雜菌過度生長 |
| 冷藏(血液培養、腦脊髓液、阿米巴檢體) | 病原死亡，偽陰性 |
| 檢體量不足(血量太少) | 陽性率下降 |

## 護理重點 {#nursing}

1. **核對醫囑與病人**，確認是否**已經用過抗生素**；新入院疑似感染者先採檢再給第一劑。
2. **無菌技術**採檢，使用正確容器，**標示採檢部位、時間與方式**(中段尿、導尿、導管)。
3. 依檢體種類**儘速送檢**，並遵守保存溫度(尿液、痰液冷藏；血液培養、腦脊髓液室溫)。
4. 追蹤報告：革蘭氏染色與初步報告出來時，通知醫師調整抗生素。
5. 衛教病人自行留檢體的方法(中段尿、痰液、蟯蟲膠帶)。
