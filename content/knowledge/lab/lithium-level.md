血中鋰濃度是**服用鋰鹽的病人**才需要測的**藥物濃度監測**(therapeutic drug monitoring)。鋰鹽的**治療濃度和中毒濃度非常接近**(治療指數窄)，而且濃度會隨著水分、鈉與腎功能大幅改變，所以要定期抽血，確認劑量「剛好有效但不中毒」。藥物本身見 [[mood-stabilizers#lithium]]。

## 鋰從哪裡來、怎麼排出 {#origin}

### 來源與分布 {#source}

- 人體**本來沒有**需要的鋰；血中的鋰幾乎都來自**鋰鹽**(碳酸鋰)藥物。
- 口服後**快速完全吸收**，一般劑型 **1–2 小時**達到最高濃度，緩釋劑型約 4–5 小時。
- 鋰和鈉、鉀一樣是**單價陽離子**，分布在全身的水分中，**不和蛋白質結合、不經肝臟代謝**。

### 排出：為什麼鋰和鈉、水綁在一起 {#elimination}

- 鋰幾乎**完全由腎臟**排出：在腎絲球被自由過濾，大部分在**近端腎小管**和**鈉一起被再吸收**。
- 身體**缺鈉或脫水**時，近端腎小管會努力把鈉吸回來，**鋰也跟著被吸回來** → 血中鋰濃度上升。
- 反過來，**鈉攝取增加**時，鈉與鋰的排出都增加 → 鋰濃度下降。
- 半衰期約 **24 小時**，腎功能變差、老人會延長；每次調整劑量後約 **4–5 天**才達到穩定狀態。

這就是鋰鹽衛教一直強調「**不要低鹽、不要脫水、水分與鹽分保持穩定**」的原因。

## 參考值 {#reference-range}

**正常人**血中不應有鋰；以下是**服藥病人的目標範圍**(單位 mEq/L 與 mmol/L 數值相同)。

| 情境 | 目標濃度 | 來源 |
|---|---|---|
| 急性期與維持期 | **0.8–1.2** mEq/L(通常不超過 1.2；無法耐受時 0.6 也可能有效) | [UpToDate](https://www.uptodate.com/contents/bipolar-disorder-in-adults-and-lithium-pharmacology-administration-and-management-of-adverse-effects) |
| 急性躁期 | 0.8–1.3 | [台灣共識 2022](https://doi.org/10.1016/j.ajp.2023.103480) |
| **維持期** | **0.6–0.8** | 台灣共識 2022(舊版 2012 共識為 0.6–1.2) |
| 老人 | 通常取較低的範圍 | 腎功能較差、對副作用較敏感 |
| **開始中毒** | **> 1.5** | UpToDate |
| **醫療急症** | **≥ 2.5**(即使病人看起來沒什麼症狀) | UpToDate |

:::note[舊教材寫法]
部分國內教科書寫「急性期 1.0–1.5、維持期 0.6–1.2 mEq/L」。現行的 UpToDate 與台灣 2022 共識都把上限降到約 1.2–1.3，維持期更降到 0.6–0.8。考題的錯誤選項常是「急性期 **2.0–2.5**」「須達 **2.0 以上**才有效」「急性期 0.6–1.0」。
:::

## 偏高：鋰中毒 {#high}

### 原因 {#high-causes}

| 類別 | 原因 |
|---|---|
| **脫水**(體液減少) | 發燒、**嘔吐、腹瀉**、大量流汗(天熱、運動)、**躁期忙到不吃不喝**、厭食、心衰竭惡化 |
| **鈉不足** | **低鹽飲食**、節食、使用利尿劑 |
| **腎功能下降** | 慢性腎臟病、急性腎損傷、**老人** |
| **藥物** | **Thiazide 利尿劑**、**NSAIDs**(aspirin 除外)、**ACEI**、ARB、tetracycline、metronidazole、GLP-1 受體促效劑 |
| 劑量 | 加量、一天一次服用(濃度比分次服用高約 25%)、服藥過量(自殺) |
| 生理變化 | 產後(懷孕時增加的腎絲球過濾率突然下降) |

### 表現與分級 {#high-symptoms}

| 程度 | 濃度(慢性中毒的參考) | 表現 |
|---|---|---|
| 輕度 | 1.5–2.5 | 噁心**嘔吐、腹瀉**、**手抖加劇**、口齒不清、嗜睡、無力 |
| 中重度 | 2.5–3.5 | 意識混亂、**步態不穩**、**粗大顫抖**、肌束顫動、**肌陣攣**、反射亢進、眼球震顫 |
| 重度 | > 3.5 | **癲癇**、昏迷、心律不整(心跳過慢、QT 延長)、腎衰竭 |

- **濃度與症狀不一定相符**：急性大量服藥的人，鋰還沒進入腦部，可能濃度 > 4 卻沒什麼症狀；慢性中毒的老人，濃度只稍微偏高就可能意識混亂。所以判讀要**看症狀**，不能只看數字(來源：[UpToDate：Lithium poisoning](https://www.uptodate.com/contents/lithium-poisoning))。
- 常見副作用(細微手抖、輕微噁心、多尿)和早期中毒很像；**原本穩定的症狀突然變嚴重**，或**新出現嘔吐、腹瀉、走路不穩**，就要抽血。

### 處理 {#high-management}

1. **暫停鋰鹽**，通知醫師，立即驗鋰濃度、腎功能、電解質(鈉)、心電圖。
2. **生理食鹽水**輸液，矯正脫水、促進鋰排出；注意同時有腎源性尿崩症的病人可能發生**高血鈉**。
3. **血液透析**：
   - **有嚴重症狀**(意識改變、癲癇、心律不整)：不論濃度都建議。
   - 濃度 **> 4.0** 且**腎功能不佳**：建議。
   - 濃度 **> 5.0**，或預估 36 小時內無法降到 1.0 以下：建議考慮(來源：[EXTRIP](https://doi.org/10.2215/CJN.10021014)；[UpToDate：Lithium poisoning](https://www.uptodate.com/contents/lithium-poisoning))。
4. **活性碳無法吸附鋰**。
5. 每 4–6 小時追蹤鋰濃度(緩釋劑型可能持續吸收)，目標降到 1.0 以下。

## 偏低 {#low}

| 原因 | 說明 |
|---|---|
| **沒有規則服藥**(最常見) | 躁期病人常覺得自己沒問題而停藥；濃度偏低也可用來發現不遵從 |
| 劑量不足 | 剛開始用藥、尚未達穩定狀態 |
| **鈉攝取增加** | 高鹽飲食 |
| 藥物 | **Theophylline**、**咖啡因**大量攝取、**保鉀利尿劑**、SGLT2 抑制劑 |
| 腎臟清除增加 | **懷孕**(腎絲球過濾率上升) |

- 濃度偏低時，要先確認**抽血時間**與**服藥情形**，再考慮加量。

## 干擾因素 {#interference}

| 因素 | 影響 |
|---|---|
| **抽血時間** | 標準是**最後一次服藥後約 12 小時**(10–14 小時都可以)，通常是**早上服藥前**。服藥後 1–2 小時抽，會抽到**尖峰**，數值假性偏高 |
| 剛調整劑量 | 未滿 4–5 天尚未穩定，數值不能代表最終濃度 |
| 服藥方式 | 一天一次比分次服用的 12 小時濃度高約 25% |
| 採血管 | 使用**含鋰的肝素(lithium heparin)採血管**會造成**假性偏高**，應依檢驗單位規定使用正確的採血管 |

## 檢體採集與護理 {#nursing}

- **抽血時機**：
  - 劑量調整後 **5–7 天**
  - 穩定後每 6–12 個月(依病人狀況可更頻繁，老人與腎功能不穩者)
  - 出現中毒症狀、脫水、急性疾病、開始或停用交互作用藥物時
- **抽血前**：確認並**記錄最後一次服藥時間**；請病人當天早上**先不要吃藥**，抽完再吃。
- 同時追蹤**腎功能(BUN、肌酸酐)**、**電解質(鈉)**、**甲狀腺功能**、**鈣**。
- 結果 > 1.2–1.5 或病人有中毒症狀：**先不給下一劑**，通知醫師；觀察意識、步態、顫抖、腸胃症狀、尿量與生命徵象。
- 衛教：保持**足夠且穩定**的水分與鹽分攝取；腹瀉、嘔吐、發燒、天熱大量流汗時要多補充水分並提早回診；不要自行服用止痛藥(NSAIDs)。

## 相關檢驗 {#related}

- [[potassium]]：同樣是需要密切監測的陽離子，並受利尿劑影響
- 腎功能、甲狀腺功能(TSH)、血鈉、血鈣：鋰鹽的長期監測項目

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 抽血：服藥後 **12 小時**(早上服藥前)；**服藥後 0.5–2 小時**是最高濃度、最容易出現副作用的時間，不是最佳抽血時間。
- 治療範圍約 **0.6–1.2**；**> 1.5** 開始中毒；1.2 屬於治療範圍內 → 繼續服藥、密切監測。
- 中毒徵象：**嘔吐、腹瀉、粗大顫抖、步態不穩、意識障礙**；處置：停藥、驗濃度、輸液，嚴重時**血液透析**。
- 會使鋰濃度上升：**脫水、低鈉、thiazide、NSAIDs、ACEI**、腎功能差。
:::
