免疫檢驗用來**評估免疫功能、找出過敏原、輔助診斷自體免疫疾病與免疫缺陷**。這一頁把常考的檢驗整理成表：**檢驗什麼、結果代表什麼、哪個疾病會怎麼變**。沒有一個檢驗可以單獨診斷疾病，要結合**病史與臨床表現**

## 重點摘要 {#summary}

- **ANA**：篩檢**全身性自體免疫疾病**，**敏感度高、特異度低**；**anti-dsDNA、anti-Sm** 對 **SLE 特異**
- **RF**(類風濕因子)不特異；**anti-CCP** 對 **RA 較特異**；**ESR、CRP** 追蹤發炎
- **補體 C3、C4**：**活動期免疫複合物疾病(SLE、腎炎)下降**；**CH50** 評估整體古典路徑
- **IgE、嗜酸性球**上升見於**第Ⅰ型過敏**；**皮膚點刺試驗**與**血清特異性 IgE**找過敏原；**貼膚試驗**用於接觸性皮膚炎
- **直接庫姆斯**：紅血球上有**抗體或補體**(自體免疫溶血、輸血反應、新生兒溶血)；**間接庫姆斯**：血清中有**抗紅血球抗體**
- **CD4 計數**：HIV 免疫狀態；**淋巴球亞群**與 **Ig** 評估免疫缺陷

### 國考常考點 {#exam-points}

- **自體免疫血清反應檢查**：**抗核抗體(ANA)**；**ESR、滑膜液檢查、CRP** 不是自體免疫的血清檢查
- **SLE**：**ANA 陽性**、**anti-dsDNA 升高**、**補體 C3、C4 下降**(活動期)、**白血球減少、貧血、血小板減少**、**ESR 上升**；**不是**白血球增加
- **找出過敏原**最適合的診斷檢查：**皮膚試驗**(皮膚點刺試驗)；**過敏性疾病**的檢驗：**IgE 上升**、**嗜酸性球上升**，**不是**白血球下降
- **補體 C3、C4 下降**是**免疫複合物(Ⅲ型)**疾病的線索，**不是單純第Ⅰ型過敏**的表現
- **RA**：**RF 與 anti-CCP**；**HIV 的免疫指標**：**CD4 計數**，**CD4/CD8 比值下降**
- **輸血前必要檢驗**：**ABO 與 Rh 血型**、**血清與血球交叉配合試驗**；不是「過敏」檢查
- **結核菌素試驗**是**遲發型(Ⅳ型)**反應，**48–72 小時**判讀

## 免疫球蛋白 {#immunoglobulins}

| 檢驗 | 意義 |
|---|---|
| **血清 IgG、IgA、IgM** | **免疫缺陷**的第一步檢查；**全部低**見於 XLA、CVID；**IgA 單獨低**見選擇性 IgA 缺乏；**IgM 高、其他低**見高 IgM 症候群；見 [[primary-immunodeficiency]] |
| **總 IgE** | **異位性體質、氣喘、過敏**上升；也見寄生蟲感染、某些免疫缺陷(高 IgE)；**特異度低**，正常**不能排除**過敏 |
| **特異性 IgE** | 針對某一過敏原的 IgE，**血清檢驗**(例如 ImmunoCAP)；**陽性只代表致敏**，要**結合病史**才算過敏 |
| **血清蛋白電泳與免疫固定** | **單株 M 蛋白**見於**多發性骨髓瘤**(見 [[lymphoma-myeloma#myeloma]])；**IgG 低**見腎病症候群 |
| **新生兒 IgM** | 臍帶血 **IgM 升高** = **子宮內感染**，見 [[immune-system-basics#newborn]] |

## 過敏相關檢查 {#allergy-tests}

| 檢查 | 適用 | 重點 |
|---|---|---|
| **皮膚點刺試驗** | **第Ⅰ型**，找過敏原 | 前臂滴過敏原後輕刺，**約 15–20 分鐘**判讀風疹塊；**檢查前要停抗組織胺**；**要備妥急救** |
| **血清特異性 IgE** | 第Ⅰ型 | **不需停藥**，適合皮膚病變廣、無法停藥或高風險者；結果要**結合病史** |
| **血清類胰蛋白酶(tryptase)** | **過敏性休克**的回溯確認 | **發作後 30 分鐘到 2 小時**採血最佳，最晚 6 小時；**要與個人基準值比較**；**正常不能排除**，見 [[anaphylaxis#diagnosis]] |
| **嗜酸性球** | 輔助 | 過敏、寄生蟲上升 |
| **貼膚試驗** | **第Ⅳ型**(接觸性皮膚炎) | 貼背部 **48 小時**，**延遲 5–7 天**再判讀，見 [[allergic-contact-dermatitis-latex#acd-diagnosis]] |
| **食物或藥物激發試驗** | 確認診斷 | **在有急救能力的場所**進行 |
| **結核菌素試驗** | 結核感染 | **皮內注射 PPD，48–72 小時**看硬結(**第Ⅳ型**)；不能分辨潛伏與活動性；**干擾素 γ 釋放試驗(IGRA)**可補充，見 [[tuberculosis]] |

## 補體檢驗 {#complement-tests}

| 檢驗 | 意義 |
|---|---|
| **C3、C4** | **活動期免疫複合物疾病**(**SLE**、腎炎)被**消耗而下降**；**C4 低 + C3 正常**見**遺傳性血管性水腫**；單純第Ⅰ型過敏**正常** |
| **CH50** | 評估**古典路徑與膜攻擊複合體**的整體功能；**任一成分缺乏**都下降 |
| **AH50** | 評估**替代路徑** |
| **C1 酯酶抑制劑濃度與功能** | **遺傳性血管性水腫**診斷 |

詳細解讀與缺乏症見 [[complement-system#tests]]。

## 自體抗體 {#autoantibodies}

### 抗核抗體(ANA) {#ana}

1. **方法**：**間接免疫螢光(IIF)**，以 **HEp-2 細胞**為基質是**標準方法**(UpToDate)；也有 ELISA 等固相法
2. **結果**：以**稀釋倍數(效價)**與**螢光型態**表示
3. **意義**
   1. **敏感度高**：**幾乎所有 SLE** 都陽性；**ANA 陰性**時 SLE 可能性很低
   2. **特異度低**：**健康人**也可能陽性，**1:160 在約 5% 的正常成人陽性**(UpToDate)；SLE 研究常以 **1:80** 作為進入條件
   3. 也見於**其他自體免疫疾病**(RA、硬皮病、乾燥症)、**感染、惡性腫瘤、藥物**、有自體免疫家族史者
4. **螢光型態**(均質、斑點、核仁、著絲點等)提供**線索**，之後做**特定抗體**確認
5. **ANA 是篩檢，不是診斷**

### 特定自體抗體 {#specific-antibodies}

| 抗體 | 疾病 | 重點 |
|---|---|---|
| **Anti-dsDNA** | **SLE** | **特異**；**效價與疾病活動與狼瘡腎炎相關** |
| **Anti-Sm** | SLE | **特異**，敏感度低 |
| **Anti-Ro(SSA)／anti-La(SSB)** | **乾燥症**、SLE | 新生兒狼瘡與**先天性心臟傳導阻滯** |
| **抗組織蛋白(histone)** | **藥物性狼瘡** | |
| **抗磷脂質抗體** | 抗磷脂質症候群、SLE | **血栓與流產** |
| **Anti-Scl-70** | **廣泛型硬皮病** | |
| **抗著絲點抗體** | **局限型硬皮病(CREST)** | |
| **Anti-Jo-1** | 多發性肌炎、皮肌炎 | |
| **RF(類風濕因子)** | **RA** | **針對 IgG Fc 的自體抗體(常為 IgM)**；**敏感度中等、特異度低**，慢性感染、乾燥症也可陽性 |
| **Anti-CCP** | **RA** | **特異度高**，可**早期**出現，預測**侵蝕** |
| **抗乙醯膽鹼受體抗體** | **重症肌無力** | |
| **抗甲狀腺過氧化酶／甲狀腺球蛋白** | **橋本氏甲狀腺炎** | |
| **TSH 受體刺激抗體** | **Graves 病** | |
| **抗內在因子／抗壁細胞抗體** | **惡性貧血** | |
| **ASO** | **A 群鏈球菌感染後**(風濕熱、腎炎) | **抗鏈球菌溶血素 O**，表示近期感染 |

詳見 [[sle]]、[[rheumatoid-arthritis]]、[[autoimmune-diseases]]。

## 血球與血清學檢驗 {#blood-tests}

### 庫姆斯試驗(Coombs) {#coombs}

| | **直接庫姆斯(DAT)** | **間接庫姆斯(IAT)** |
|---|---|---|
| 檢測 | **病人紅血球上**有無**抗體或補體** | **病人血清中**有無**游離的抗紅血球抗體** |
| 方法 | 病人紅血球加**抗人類球蛋白**，看是否**凝集** | 血清先與試劑紅血球反應，再加抗人類球蛋白 |
| 臨床 | **自體免疫溶血性貧血**、**輸血溶血反應**(包括延遲)、**新生兒溶血症**、藥物性溶血 | **輸血前不規則抗體篩檢**、**交叉配合試驗**、**孕婦抗體篩檢** |

### 淋巴球與其他 {#lymphocytes}

| 檢驗 | 意義 |
|---|---|
| **淋巴球亞群(流式細胞)** | **CD3(T)、CD4、CD8、CD19(B)、CD16／56(NK)**；**CD19⁺ 幾乎沒有** = **XLA**；**T 細胞少** = SCID、DiGeorge |
| **CD4 計數** | **HIV**：**< 200／μL 易伺機性感染**，**CD4/CD8 比值下降**，見 [[hiv-aids]] |
| **TREC** | **新生兒篩檢 SCID** |
| **NBT／DHR 試驗** | **CGD**：吞噬細胞氧化爆發缺陷 |
| **嗜中性球絕對值** | **< 500／μL** 保護性隔離，見 [[complete-blood-count]]、[[cancer-treatment-toxicities#neutropenia]] |
| **ESR、CRP** | **發炎活動**，見 [[inflammatory-markers]]；**SLE 的 CRP 常不高** |

## 輸血與血型檢驗 {#transfusion-tests}

1. **ABO 與 Rh 血型鑑定**：**正向(紅血球抗原)與反向(血清抗體)**
2. **不規則抗體篩檢**(間接庫姆斯)與**交叉配合試驗**：**受血者血清**與**供血者紅血球**反應，**不是檢查「過敏」**，而是**預防抗原抗體反應造成溶血**，見 [[transfusion-reactions#before]]
3. **新生兒溶血**：**直接庫姆斯**與抗體篩檢
