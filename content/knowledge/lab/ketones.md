缺乏可利用的葡萄糖時(胰島素不足或飢餓),脂肪大量分解,肝臟把脂肪酸轉成**酮體**當替代燃料。酮體有三種:

| 酮體 | 說明 |
|---|---|
| **β-羥基丁酸(β-OHB)** | 酮酸中毒時占約 **75–80%**;血酮機測的是它 |
| **乙醯乙酸**(acetoacetate) | **尿酮試紙**(硝普鹽反應)主要測它 |
| **丙酮**(acetone) | 由乙醯乙酸自發形成,經肺呼出 → **水果味口氣** |

酮體是酸,大量堆積消耗 HCO₃⁻ → **陰離子間隙增加的代謝性酸中毒**。醣類不足時脂肪氧化不完全,也是酮體增加的原因。

## 參考值 {#reference-range}

| 血清 β-OHB(mmol/L) | 意義 |
|---|---|
| < 0.6 | 正常 |
| 0.6–1.5 | 酮體增加,需追蹤、補充水分與胰島素 |
| 1.5–3.0 | 有酮酸中毒風險,聯絡醫療團隊 |
| **≥ 3.0** | 符合**酮酸中毒**(配合 pH、HCO₃⁻),需立即就醫 |

**尿酮**:正常為陰性;試紙以陰性、微量、少量(+)、中量(++)、大量(+++)表示。

## 臨床意義:升高 {#increased}

| 原因 | 說明 |
|---|---|
| **[[diabetes#dka\|糖尿病酮酸中毒]]** | 最重要;第一型中斷胰島素、感染 |
| **SGLT2 抑制劑**相關 | 血糖可能不高(euglycemic DKA),見 [[sglt2-inhibitors#adverse-effects]] |
| 飢餓、長時間禁食、生酮飲食 | 生理性酮症,通常不造成嚴重酸中毒 |
| **酒精性酮酸中毒** | 酗酒後未進食、嘔吐 |
| 懷孕、**妊娠劇吐** | 孕婦較易產生酮體 |
| 持續嘔吐、腹瀉、發燒、劇烈運動 | |

[[diabetes#hhs|HHS]] 的特徵是「**無或微量酮體**」——少量胰島素已足以抑制脂肪分解。

## 干擾與判讀陷阱 {#interference}

- **尿酮試紙測不到 β-OHB**:酮酸中毒早期 β-OHB 為主,尿酮可能**低估**。
- 治療 DKA 時 β-OHB 轉成乙醯乙酸 → **尿酮反而看似增加**,不代表惡化;追蹤療效應用**血清 β-OHB、pH、陰離子間隙**。
- 尿酮受尿液濃縮程度影響;少尿時無法測。
- **假陽性**:含硫氫基藥物(captopril 等)、部分尿液色素。
- **假陰性**:試紙過期或受潮、檢體放置太久(丙酮揮發)。

## 何時要測 {#when-to-test}

- 第一型糖尿病:血糖持續 **> 250–300 mg/dL**、生病、**噁心嘔吐腹痛**、呼吸快而深時。
- 使用 SGLT2 抑制劑者出現上述症狀,**不論血糖高低**。
- 懷孕的糖尿病婦女。
- 血酮 ≥ 1.5 mmol/L 或尿酮中量以上 → **不宜運動**,聯絡醫療人員。

## 檢體採集與護理 {#nursing}

- 尿酮:收集新鮮尿液,依試紙規定時間比色(通常 15 秒);試紙密封保存。
- 血酮:用血酮試片以指尖血測量。
- 評估伴隨的 Kussmaul 呼吸、水果味口氣、脫水與意識狀態。
