血管受傷時，身體要在幾分鐘內**止血**；同一套機制如果在不該凝的地方啟動，就形成**血栓**；血栓或其他東西被血流帶走卡在下游，就是**栓塞**；下游組織因此缺血壞死，就是**梗塞**。抗凝血與抗血小板藥見 [[anticoagulants]]、[[antiplatelets]]、[[thrombolytics]]；水腫與休克見 [[edema-shock]]

## 重點摘要 {#summary}

- 止血：**血管收縮**（內皮素） → **初級止血**（血小板黏附、聚集成血小板栓） → **次級止血**（組織因子啟動凝血瀑布，凝血酶把纖維蛋白原變成**纖維蛋白**）；**紅血球不是主動參與者**
- **Virchow 三要素**：**血流異常**（停滯、亂流）、**內皮細胞受傷**、**高凝血狀態**
- 久坐長途飛行、長期臥床 → **血流停滯**；口服避孕藥、懷孕、癌症、抗磷脂質症候群 → **高凝血**；凝血因子缺乏（血友病、類血友病）造成的是**出血**
- 肺栓塞的栓子最常來自**下肢深部靜脈**（膝以上近端），卡在**肺動脈**；靜脈栓子不會塞到肝、腦、腎
- **DIC**：敗血症、產科急症（胎盤早期剝離、羊水栓塞）、癌症、毒蛇咬傷 → 凝血全面活化 → 血小板與凝血因子被**消耗** → **出血**
- 其他栓子：**脂肪**（長骨骨折後 24–72 小時）、**氣體**（潛水減壓症、靜脈導管）、**羊水**（分娩時）
- **紅色梗塞**：雙重血流（肺）、鬆軟組織（腸）、**靜脈阻塞**（卵巢扭轉）、**再灌流**；**白色梗塞**：單一動脈供應的實質器官（**心、腎、脾**）

### 國考常考點 {#exam-points}

- Virchow 三要素**不包括高血鈣**、**不包括 Hageman 因子缺乏**；血管肌肉層增生最不容易造成血栓（動脈瘤、粥狀硬化、血管炎都容易）
- 長途飛行後深部靜脈栓塞的主因是**血液鬱積**
- **von Willebrand 疾病**和高凝血狀態最無關（它是出血疾病）
- 止血時血小板是靠 **vWF** 黏附在內皮下膠原，**不是選擇素(E-selectin)**；凝血酶調節素(thrombomodulin)是**抗**凝血
- **膝部以下**的小腿深部靜脈血栓造成肺栓塞的風險**較低**（近端較高）；淺層靜脈血栓較少造成栓塞
- 下肢 DVT 的表現：患側水腫、疼痛、肺栓塞；**不會造成肝臟栓塞**
- 全身性（動脈）血栓栓塞的栓子**多來自左心**，不是深部腿靜脈
- DIC 檢驗：**血小板下降、PT 與 aPTT 延長、纖維蛋白原下降、FDP 與 D-dimer 上升**；纖維蛋白原**上升**、D-dimer **下降**都是錯的；慢性淋巴性白血病不是常見誘因
- DIC 衛教：**不可用力解便**、用電鬍刀、軟毛牙刷、不用牙線
- 潛水夫病是**氣體**栓塞
- 脂肪栓塞：長骨骨折後，呼吸困難、意識改變、**皮下點狀出血**、血小板減少；脂肪來自**骨髓**，不是皮下組織；國考答案認為「多發生在骨折後 72 小時」是錯的（多在 24–48 小時內）
- 羊水栓塞**沒有**病理性收縮環（那是子宮破裂的前兆）
- **脾臟缺血性凝固性壞死**是白色梗塞，和紅色梗塞最無關

## 止血 {#hemostasis}

| 步驟 | 發生什麼 | 主角 |
|---|---|---|
| 1. 血管收縮 | 受傷的血管反射性收縮，減少失血 | 神經反射、**內皮素**(endothelin) |
| 2. 初級止血 | 血小板**黏附**在暴露的內皮下膠原 → 活化、釋放物質 → **聚集**成血小板栓 | 血小板、**vWF**（黏附）、纖維蛋白原（聚集） |
| 3. 次級止血 | 內皮下的**組織因子**啟動凝血瀑布 → 凝血酶 → **纖維蛋白原變成纖維蛋白**，把血小板栓固定 | 凝血因子、鈣離子 |
| 4. 限制範圍 | 正常內皮周圍啟動抗凝與溶解，避免血栓擴大 | **凝血酶調節素**（thrombomodulin，活化蛋白質 C）、抗凝血酶、tPA |

- **紅血球**只是被包進纖維蛋白網中，不主動參與凝血
- **白血球**黏附靠的是選擇素(selectin)，血小板黏附靠的是 vWF，兩者不要混淆（白血球外滲見 [[inflammation-repair#leukocyte-extravasation]]）
- 凝血檢驗（PT／INR、aPTT）與藥物監測見 [[anticoagulants]]；血小板數值見 [[complete-blood-count#platelets]]

## 血栓 {#thrombosis}

![Virchow 三要素：血流異常、內皮細胞受傷、高凝血狀態，各舉臨床例子](/knowledge-images/virchow-triad.svg)

| 要素 | 機轉 | 臨床例子 |
|---|---|---|
| **血流異常** | 停滯讓凝血因子累積、血小板接觸內皮；亂流傷害內皮 | 長期臥床、**長途飛行久坐**、術後、心衰竭、**心房顫動**、靜脈曲張、**動脈瘤** |
| **內皮細胞受傷** | 暴露膠原與組織因子 | **動脈粥狀硬化**、血管炎、手術或外傷、靜脈導管、感染性心內膜炎 |
| **高凝血狀態** | 凝血因子增加或抗凝血物質不足 | 懷孕與產後、**口服避孕藥**（雌激素）、癌症、**抗磷脂質症候群**、遺傳性易栓症、脫水 |

- 動脈血栓：血流快，主要由血小板組成（較白），常長在粥狀硬化斑塊上 → 心肌梗塞、缺血性中風（見 [[coronary-artery-disease#atherosclerosis]]）
- 靜脈血栓：血流慢，含大量紅血球（較紅），多在下肢深部靜脈
- 血栓的結局：溶解、繼續長大、**機化**（被肉芽組織取代）後再通、脫落成**栓子**

::questions{ids="105-1_BM_047,106-2_makeup_BM_034,112-2_BM_026,114-1_BM_022,111-2_MS_033"}

### 靜脈血栓 {#venous-thrombosis}

::figure{src="/knowledge-images/servier-venous-thrombosis.svg" labels="venous-thrombosis" alt="上：正常靜脈血流與靜脈瓣；中：瓣膜後方血流停滯處形成血栓；下：血栓脫落成為栓子"}

- **淺層靜脈血栓**：靜脈曲張的病人風險較高；側枝循環多、不容易脫落，**較少造成栓塞**
- **深部靜脈血栓(DVT)**：好發在下肢；**膝以上的近端**（膕靜脈、股靜脈、髂靜脈）血栓最容易脫落造成肺栓塞；膝以下的小腿血栓風險較低
- 表現：**患側**下肢水腫、疼痛、發熱、發紅；很多人沒有症狀，第一個表現就是肺栓塞
- 預防：早期下床、下肢運動、彈性襪、抗凝血劑（見 [[anticoagulants#indications]]）

::questions{ids="111-2_BM_023,112-3_BM_022"}

### 瀰漫性血管內凝血(DIC) {#dic}

- 不是獨立的疾病，而是重症的**併發症**
- 檢驗判讀、治療與出血護理見 [[bleeding-disorders#dic]]；凝血瀑布見 [[blood-hemostasis#coagulation]]
- 常見誘因
   1. **敗血症**（最常見）
   2. 產科急症：**胎盤早期剝離**、**羊水栓塞**、子宮內死胎、嚴重子癲前症
   3. 癌症：急性前骨髓性白血病、腺癌
   4. 嚴重創傷、燒傷、**毒蛇咬傷**
- 機轉
   1. 大量組織因子（凝血活酶）進入血液 → 全身微血管形成小血栓（器官缺血）
   2. 血小板與凝血因子被**大量消耗**，纖維蛋白溶解也被活化
   3. 結果是**廣泛出血**：抽血處與傷口滲血、皮膚瘀斑、黏膜出血

| 檢驗 | DIC 的變化 |
|---|---|
| 血小板 | **下降** |
| PT、aPTT | **延長** |
| 纖維蛋白原 | **下降** |
| FDP、**D-dimer** | **上升** |

- 治療原發病因；依出血情形補充血小板、新鮮冷凍血漿、冷凍沉澱品
- 護理：預防出血
   1. 避免用力解便（軟便劑）、用力咳嗽與擤鼻涕
   2. 用**電鬍刀**、**軟毛牙刷**，不用牙線
   3. 減少肌肉注射與侵入性操作，穿刺後延長加壓
- 產後大出血要嚴密監測 DIC，產科照護見產科那一輪

## 栓塞 {#embolism}

![栓子的來源與去向：靜脈系統的栓子塞在肺，動脈系統的栓子塞在腦、腎、脾、腸、下肢；下方為脂肪、氣體、羊水等非血栓栓子](/knowledge-images/embolism-routes.svg)

- **栓子**：在血管內隨血流移動、最後卡住的固體、液體或氣體；**最常見的是血栓**（血栓栓塞）
- 靜脈栓子 → 右心 → 卡在**肺動脈**＝**肺栓塞**；最常見的來源是**下肢深部靜脈**
- 動脈（全身性）栓子：**多來自左心**（心房顫動的左心房血栓、心肌梗塞後的附壁血栓、心內膜炎贅生物）或大動脈斑塊 → 腦、腎、脾、腸、下肢
- 肺栓塞的臨床處置見 [[pulmonary-embolism-hypertension#pulmonary-embolism]]；溶栓見 [[thrombolytics#pe]]

::questions{ids="105-2_BM_040,110-2_BM_034,106-2_BM_035,110-1_BM_042"}

### 脂肪栓塞 {#fat-embolism}

- 好發：**長骨**（股骨）或**骨盆骨折**、骨科手術後；脂肪滴來自**骨髓**（不是皮下組織）
- 時間：通常在受傷後 **24–72 小時**內出現，多數在 24–48 小時
- 典型三症狀
   1. **呼吸困難**、低血氧（最常見，也是主要死因）
   2. **意識改變**、躁動不安
   3. **皮下點狀出血**（前胸、腋下、結膜）
- 也常見發燒、心跳加快、**血小板減少**
- 預防與處置：骨折早期固定、減少搬動；給氧與支持性治療

::questions{ids="108-2_BM_034,111-2_MS_021,108-2_MS_014,109-1_MS_018,112-1_MS_017"}

### 氣體與羊水栓塞 {#gas-amniotic-embolism}

- **氣體栓塞**
   1. 空氣經靜脈導管、輸液管路進入（更換管路時夾管、排氣）
   2. **減壓症（潛水夫病）**：潛水後上升太快，溶在血中的**氮氣**變成氣泡，造成關節痛、呼吸困難、神經症狀；治療是高壓氧
- **羊水栓塞**
   1. 羊水與胎兒物質經子宮或子宮頸靜脈進入母體循環
   2. 通常發生在**分娩時或剛分娩後**、**破水後**
   3. 突然呼吸困難、發紺、**心肺衰竭、休克**，常合併 **DIC**
   4. **病理性收縮環**是子宮破裂的前兆，不是羊水栓塞的表現

::questions{ids="105-1_BM_034,113-2_OP_020"}

## 梗塞 {#infarction}

::figure{src="/knowledge-images/servier-thrombus-infarct.svg" labels="thrombus-infarct" alt="左：小血栓卡在有側枝循環的分支，下游仍有血流；右：血栓完全阻塞供血分支，下游缺血梗塞"}

- **梗塞**：動脈血流（少數是靜脈回流）被阻斷，造成局部組織**缺血性壞死**；大多由血栓或栓塞造成
- 結果取決於：有沒有**側枝循環**（雙重血流）、阻塞的速度、組織對缺氧的耐受度（神經元、心肌最不耐）

| | **紅色梗塞**（出血性） | **白色梗塞**（貧血性） |
|---|---|---|
| 發生情形 | **雙重血流**的器官（**肺**：肺動脈＋支氣管動脈）；鬆軟組織（**腸**）；**靜脈阻塞**（**卵巢扭轉**、睪丸扭轉）；**再灌流**（血流重新流入已壞死的組織） | **單一動脈**供血、組織緻密的實質器官：**心臟、腎臟、脾臟** |
| 外觀 | 暗紅，有出血 | 蒼白 |

- 壞死型態：心、腎、脾是**凝固性壞死**；腦梗塞是**液化性壞死**（見 [[cell-injury-adaptation#necrosis]]）
- 心肌梗塞的時序變化見 [[coronary-artery-disease#pathology-timeline]]；腦梗塞見 [[stroke]]
- **壞疽**：肢體（多為下肢）缺血造成的凝固性壞死；合併感染液化時稱濕性壞疽
