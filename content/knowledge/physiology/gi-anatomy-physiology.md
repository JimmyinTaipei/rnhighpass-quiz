消化道從口腔到肛門是一條連續的管子，負責把食物磨碎、分解成小分子再吸收；肝臟、膽囊、胰臟與唾液腺是附屬器官。本頁整理管壁構造、腹膜、口腔到大腸各段的構造與功能、胃液分泌的調節、三大營養素的消化吸收、消化道激素與血液供應；肝膽胰見 [[liver-biliary-pancreas]]，排便反射與排便護理見 [[bowel-elimination]]，營養素與飲食見 [[nutrition-assessment-diets]]

## 重點摘要 {#summary}

- 管壁四層（由內到外）：**黏膜 → 黏膜下層 → 肌肉層 → 漿膜**；負責運動的是**肌肉層**（內環、外縱，胃多一層**內斜**）
- 神經叢：**梅氏（黏膜下）神經叢在黏膜下層**管分泌，**奧氏（肌間）神經叢在肌肉層**管運動；平滑肌收縮最主要靠**鈣離子**
- 上皮：**食道、肛門是複層扁平上皮**；胃、小腸、大腸、膽囊是**單層柱狀上皮**
- 骨骼肌只在**咽與食道上段**；推進食物最重要的是**蠕動**，分節運動負責混合，**質塊運動**引起便意
- 胃腺：**壁細胞 → 鹽酸＋內在因子**、**主細胞 → 胃蛋白酶原**、黏液頸細胞 → 黏液、**G 細胞 → 胃泌素**
- 胃液分泌：頭期靠**迷走（副交感）神經**、胃期靠**胃擴張與胃泌素**、腸期以**抑制**為主（胰泌素、CCK）
- 小腸吸收面積：**環狀皺襞（空腸最明顯）、絨毛、微絨毛**；**脂肪 → 乳糜微粒 → 乳糜管（淋巴）**，醣、胺基酸 → 微血管 → **門靜脈**
- 血液供應：**腹腔動脈幹**（胃、十二指腸、肝、胰、脾）、**腸繫膜上動脈**（小腸到橫結腸前 2/3）、**腸繫膜下動脈**（橫結腸後 1/3 到直腸上段）

### 國考常考點 {#exam-points}

- 負責消化道運動的是**外肌肉層**；奧氏神經叢在**肌肉層**、梅氏神經叢在**黏膜下層**
- 複層扁平上皮：**食道、肛門**；膽囊是**單層柱狀**（不是複層鱗狀）
- 肌肉層含骨骼肌的是**食道**（上段）；**咽**主要是骨骼肌；硬腭是骨頭
- 消化道平滑肌收縮最主要的離子是**鈣離子**；最重要的推進運動是**蠕動**
- 只有前面被腹膜覆蓋的（腹膜後器官）：**胰臟**；腹膜後器官的組合：**胰臟與升結腸**
- 大網膜連**胃大彎與橫結腸**；**肝圓韌帶**不是腹膜衍生（是臍靜脈退化）
- 唾液澱粉酶分解**澱粉**；**酸味**引起最多唾液；腮腺導管開口在**上排第二臼齒**對面，腮腺在嚼肌**外側**（不是內側）
- 牙齒主體是**牙質**；乳齒 20 顆**有犬齒**、沒有前臼齒
- 會角質化、形成舌苔的是**絲狀乳頭**
- 吞嚥反射時下食道括約肌是**鬆弛**（不是收縮）
- 食道在**氣管後方**，以**蠕動**往下送；食道靜脈曲張主要在**黏膜下層**
- 胃壁肌肉由內到外：**內斜、中環、外縱**；賁門接食道、**幽門接十二指腸**；胃小彎的血來自**腹腔動脈幹**（胃左動脈）
- **壁細胞**分泌鹽酸與內在因子；**G 細胞**分泌胃泌素；與大腸杯狀細胞分泌物相似的是**黏液頸細胞**
- 刺激胃泌素分泌最直接的是**胃膨脹**（胃酸增加反而抑制）；頭期活化的是**副交感神經到腸神經系統**
- 全胃切除後的貧血：血清 **維生素 B12 下降**
- 小腸增加面積：**微絨毛、絨毛、環狀皺襞**（腸脂垂無關）；環狀皺襞最明顯在**空腸**；盲腸**不屬於**小腸
- **布氏腺在十二指腸黏膜下層**，分泌鹼性黏液；肝胰壺腹開口在**十二指腸**；乳糜管不是十二指腸特有
- 絨毛中心的**乳糜管只吸收脂肪**（走淋巴），其他養分進微血管
- **果糖**以輔助擴散吸收；乳糖不耐症是**乳糖酶**不足；碳水化合物從**口腔**開始消化
- 胰臟脂解酶把三酸甘油酯分解成**單酸甘油酯＋游離脂肪酸**；微粒的功能是**促進脂肪吸收**
- 乳糜微粒含**維生素 A**、膽固醇、磷脂質，**不含 VLDL**；膽固醇吸收後形成乳糜微粒進**乳糜管**
- 蛋白質消化產物吸收後經**血液（門靜脈）直接進肝**
- 鐵吸收進體內後與**鐵蛋白(ferritin)**結合儲存
- **CCK** 促進胰液（酵素）分泌與膽囊收縮，**脂肪**最能刺激它分泌
- 小腸液**沒有**肝醣酶
- 腸繫膜下動脈供應**乙狀結腸**；闌尾由**腸繫膜上動脈**供應；同時接受上、下腸繫膜動脈的是**橫結腸**
- 結腸帶由**縱走平滑肌**構成；橫結腸沒有小網膜；大腸最前端是**盲腸**
- **質塊運動**最容易引起便意

## 消化道管壁與腹膜 {#wall}

### 管壁四層 {#layers}

| 層（由內到外） | 構造 | 重點 |
|---|---|---|
| **黏膜層** | 上皮、固有層、黏膜肌層 | 上皮依部位不同（見下表） |
| **黏膜下層** | 疏鬆結締組織、血管、淋巴 | **梅氏（黏膜下）神經叢**；十二指腸的**布氏腺**；**食道靜脈曲張**的靜脈在這層 |
| **肌肉層**（外肌肉層） | 內環、外縱兩層平滑肌（胃多一層內斜） | **奧氏（肌間）神經叢**夾在兩層之間；負責**運動** |
| **漿膜層** | 臟層腹膜 | 食道在胸腔段沒有漿膜，外面是結締組織外膜；迴腸最外層是漿膜 |

- 腸神經系統：**黏膜下神經叢**主要調控分泌與局部血流，**肌間神經叢**主要調控蠕動；自主神經中副交感促進、交感抑制消化道活動
- 平滑肌收縮最主要靠**鈣離子**進入細胞

| 上皮 | 部位 |
|---|---|
| **複層扁平（鱗狀）上皮** | 口腔、咽、**食道**、**肛門**（齒狀線以下）：耐磨 |
| **單層柱狀上皮** | **胃**、小腸、大腸（含闌尾、直腸）、**膽囊**：分泌與吸收 |

| 肌肉 | 部位 |
|---|---|
| 骨骼肌 | 口腔、**咽**、**食道上段**、肛門外括約肌 |
| 平滑肌 | 食道下段到肛門內括約肌；胃是**內斜、中環、外縱**三層 |

### 消化道的運動 {#motility}

| 運動 | 部位 | 作用 |
|---|---|---|
| **蠕動** | 食道到大腸 | 環肌在食團後方收縮、前方放鬆，**最重要的推進運動** |
| **分節運動** | 小腸為主 | 環肌一段段收縮，**混合**食糜、增加接觸面，推進很少 |
| 結腸袋運動 | 大腸 | 結腸袋輪流收縮，緩慢攪拌、吸收水分 |
| **質塊運動** | 大腸 | 一天數次、多在飯後（胃結腸反射），把糞便推進直腸，**引起便意**（排便反射見 [[bowel-elimination#defecation-reflex]]） |

### 腹膜 {#peritoneum}

- 腹膜分**壁層**（貼腹壁）與**臟層**（包器官），中間是腹膜腔
- **腹腔與骨盆腔**之間沒有實質構造分隔（合稱腹盆腔），腹水會流到骨盆腔；胸腔與腹腔之間有**橫膈**，胸膜腔、心包腔各自封閉
- **腹膜內器官**（被腹膜包住，有繫膜）：胃、空腸、迴腸、橫結腸、乙狀結腸、肝、脾
- **腹膜後器官**（只有前面被腹膜覆蓋）：**胰臟**、十二指腸大部分、**升結腸、降結腸**、腎臟、直腸大部分

| 構造 | 連接 |
|---|---|
| **大網膜** | **胃大彎 → 橫結腸**，像圍裙垂在小腸前面 |
| 小網膜 | 胃小彎與十二指腸起始部 → 肝臟 |
| 腸繫膜 | 把空腸、迴腸固定在後腹壁，內有血管與淋巴 |
| **鐮狀韌帶** | 肝臟 → **前腹壁與橫膈**；分開肝左右葉 |
| **肝圓韌帶** | 鐮狀韌帶下緣游離緣內，連到肚臍；是胎兒**臍靜脈**退化而成，**不是腹膜反摺** |

## 口腔、咽與食道 {#mouth-esophagus}

::figure{src="/knowledge-images/servier-gi-tract.svg" labels="gi-tract" alt="消化道全景：口腔、咽、食道、胃、肝、膽囊、胰、十二指腸、小腸、大腸各段、闌尾、直腸"}

### 唾液與唾液腺 {#saliva}

- 唾液每天約 **1.5 公升**（《內外科護理學》下冊 p.302）：潤滑食物、**唾液澱粉酶分解澱粉**（碳水化合物從口腔開始消化）、溶菌酶抗菌
- 分泌主要受**副交感神經**刺激；味道中**酸味**引起的唾液最多

| 唾液腺 | 位置與導管 |
|---|---|
| **腮腺（耳下腺）** | **最大**；在耳前下方、**嚼肌外側（表面）**；導管穿過頰肌，開口在**上排第二臼齒**對面的頰黏膜；分泌液含唾液澱粉酶 |
| 頷下腺 | 下頷骨內側；導管開口在舌下 |
| 舌下腺 | 口腔底、舌頭下方 |

### 牙齒與舌 {#teeth-tongue}

- 牙齒由外到內：琺瑯質（最硬，包牙冠）、**牙質（主體）**、齒髓（神經血管）；牙根外有白堊質，固定在上下頷骨的齒槽
- **乳齒 20 顆**：門齒 8、**犬齒 4**、臼齒 8，**沒有前臼齒**；**恆齒 32 顆**：多了前臼齒與第三臼齒
- 舌乳頭：**絲狀乳頭**最多、**沒有味蕾、會角質化**，角質堆積就是**舌苔**；蕈狀乳頭、輪廓狀乳頭（最大，排成 V 字）、葉狀乳頭有味蕾

### 吞嚥與食道 {#swallowing}

- 吞嚥三期：**口腔期**（隨意） → **咽期**、**食道期**（不隨意反射，中樞在延腦）
- 咽期反射：軟腭上提封住鼻咽、**聲門關閉**、會厭蓋住喉部、**呼吸暫停**、**上食道括約肌鬆弛**
- 食道期：蠕動把食團往下推，**下食道括約肌(LES)鬆弛**讓食物進胃；平時 LES 收縮防止胃酸逆流
- 食道：長約 25 公分，在**氣管後方**、脊柱前方，經橫膈的食道裂孔進入腹腔；**上段骨骼肌、下段平滑肌**，以**蠕動**往下送（不是分節運動）
- 影響 LES 張力的因素與胃食道逆流見 [[upper-gi-disorders#gerd]]；食道靜脈曲張是黏膜下層靜脈擴張，見 [[liver-cirrhosis#varices]]

## 胃 {#stomach}

::figure{src="/knowledge-images/servier-stomach-regions.svg" labels="stomach-regions" alt="胃的分區：賁門、胃底、胃體、幽門竇、幽門，與胃大彎、胃小彎、食道、十二指腸"}

- 分區：**賁門**（接食道） → 胃底（賁門左上方的圓頂） → 胃體 → 幽門竇 → **幽門**（幽門括約肌，接十二指腸）
- 內側凹的邊是**胃小彎**（小網膜附著），外側凸的邊是**胃大彎**（大網膜附著）
- 肌肉層三層：**內斜、中環、外縱**，用來攪拌食物成食糜
- 胃液每天 **2–3 公升**（《內外科護理學》下冊 p.305）：鹽酸、胃蛋白酶原、黏液、內在因子
- 血液：都來自**腹腔動脈幹**；胃小彎是**胃左動脈**（腹腔動脈幹直接分支）與胃右動脈

### 胃腺細胞 {#gastric-glands}

::figure{src="/knowledge-images/servier-gastric-gland-cells.svg" labels="gastric-gland-cells" alt="胃腺三種細胞：主細胞、壁細胞、黏液頸細胞"}

| 細胞 | 分泌 | 作用與臨床 |
|---|---|---|
| **壁細胞** | **鹽酸**、**內在因子** | 鹽酸活化胃蛋白酶原、殺菌；內在因子是**維生素 B12** 在迴腸吸收所必需 |
| **主細胞** | **胃蛋白酶原** | 被鹽酸活化成胃蛋白酶，開始分解蛋白質 |
| **黏液頸細胞** | 黏液 | 保護胃壁；分泌物與大腸**杯狀細胞**相似 |
| **G 細胞**（幽門竇） | **胃泌素** | 刺激壁細胞分泌胃酸、增加胃蠕動 |
| D 細胞 | 體制素 | 抑制胃泌素與胃酸 |
| 類腸嗜鉻細胞 | 組織胺 | 經 H2 受體刺激胃酸（H2 阻斷劑見 [[gi-drugs#h2]]） |

- **全胃切除**後沒有壁細胞 → 缺內在因子 → **維生素 B12 吸收不良**，需終身注射 B12（惡性貧血見 [[nutritional-disorders#water-soluble]]）

### 胃液分泌的調節 {#gastric-secretion}

| 期 | 啟動 | 機轉 |
|---|---|---|
| **頭期** | 看到、聞到、想到食物 | **迷走神經（副交感）**經腸神經系統刺激壁細胞與 G 細胞 |
| **胃期**（分泌最多） | 食物進胃 | **胃膨脹**（局部反射與迷走反射）、蛋白質消化產物 → **胃泌素**分泌 |
| **腸期** | 食糜進十二指腸 | 以**抑制**為主：酸刺激**胰泌素**、脂肪刺激 **CCK**，加上腸胃反射，減少胃酸與胃排空 |

- 促進胃酸：**胃泌素、組織胺、乙醯膽鹼（副交感）**；抑制：**交感神經**、胃內酸度升高（負回饋抑制胃泌素）、體制素、胰泌素
- 刺激胃泌素最直接的是**胃膨脹**與胜肽；胃腔內 H⁺ 增加反而**抑制**胃泌素

## 小腸 {#small-intestine}

| 段 | 特點 |
|---|---|
| **十二指腸** | 最短、C 字形包住胰頭，大部分在腹膜後；**黏膜下層有布氏腺**分泌鹼性黏液中和胃酸；**肝胰壺腹**開口（大十二指腸乳頭）、副胰管開口（小乳頭） |
| **空腸** | 約占小腸上段 40%；**環狀皺襞最明顯**、管壁厚 |
| **迴腸** | 約占下段 60%（《內外科護理學》下冊 p.307）；末端吸收**維生素 B12 與膽鹽**；接迴盲瓣進盲腸 |

- **盲腸不屬於小腸**（是大腸起點）
- 小腸液每天 2–3 公升，弱鹼性（《內外科護理學》下冊 p.307）；刷狀緣酵素：麥芽糖酶、蔗糖酶、**乳糖酶**、胜肽酶、**腸激酶**（活化胰蛋白酶原）；**沒有**「肝醣酶」

### 增加吸收面積 {#absorptive-surface}

::figure{src="/knowledge-images/servier-intestinal-villi.svg" labels="intestinal-villi" alt="小腸絨毛：微絨毛、上皮細胞、杯狀細胞、乳糜管、微血管網、小動脈與小靜脈"}

- 三層放大：**環狀皺襞** → **絨毛**（上皮細胞的指狀突起） → **微絨毛**（細胞膜表面，形成刷狀緣）；**腸脂垂與吸收面積無關**（是大腸外面的脂肪垂）
- 絨毛中央有**一條乳糜管**，只收**脂肪**（乳糜微粒）送進淋巴；醣、胺基酸、水溶性維生素進**微血管 → 門靜脈 → 肝**
- 絨毛在十二指腸也有；乳糜管不是十二指腸特有

### 三大營養素的消化與吸收 {#digestion-absorption}

| 營養素 | 消化 | 吸收 |
|---|---|---|
| **碳水化合物** | **口腔**唾液澱粉酶開始 → 胰澱粉酶 → 刷狀緣雙醣酶分解成**單醣** | 葡萄糖、半乳糖：與鈉共同運輸（次級主動運輸）；**果糖：輔助擴散**；進微血管 → 門靜脈；雙醣（蔗糖、乳糖）不能直接吸收 |
| **蛋白質** | 胃蛋白酶（胃） → 胰蛋白酶等（小腸，**以酶原形式分泌**再被活化） → 刷狀緣胜肽酶 | 胺基酸、雙胜肽、三胜肽 → 微血管 → **門靜脈直接進肝** |
| **脂肪** | **膽鹽與磷脂質乳化** → 胰脂解酶（加輔脂解酶）把**三酸甘油酯分解成單酸甘油酯＋游離脂肪酸** | 與膽鹽組成**微粒**送到上皮 → 細胞內重新合成三酸甘油酯，加膽固醇、磷脂質、蛋白質與**脂溶性維生素（A、D、E、K）** 組成**乳糜微粒** → **乳糜管（淋巴）** → 胸管 |

- **乳糖不耐症**：**乳糖酶**不足（不是澱粉酶），乳糖在大腸發酵造成腹脹、腹瀉
- 胃蛋白酶在小腸的鹼性環境就失去活性，不和胰臟蛋白酶一起作用；胰臟的蛋白酶由**腺泡細胞**分泌（導管細胞分泌碳酸氫鹽）
- 乳糜微粒在小腸上皮製造；**VLDL 是肝臟製造**的，不在乳糜微粒裡（脂蛋白見 [[lipid-profile]]）
- **鐵**：主要在十二指腸吸收，食物中的鐵只吸收一小部分；進入細胞後與**鐵蛋白(ferritin)**結合儲存，血中由運鐵蛋白運送；人體沒有主動排鐵的途徑，主要靠**調節腸道吸收量**維持平衡（鐵代謝見 [[blood-hemostasis#iron]]，缺鐵性貧血見 [[anemias#iron-deficiency]]）
- 維生素 B12：需要**內在因子**，在**迴腸末端**吸收

### 消化道激素 {#gi-hormones}

| 激素 | 分泌細胞與部位 | 刺激 | 作用 |
|---|---|---|---|
| **胃泌素** | G 細胞（幽門竇） | 胃膨脹、蛋白質、迷走神經 | 胃酸分泌、胃蠕動 |
| **胰泌素** | 十二指腸 S 細胞 | **胃酸**進十二指腸 | 胰臟分泌**碳酸氫鹽**；抑制胃酸 |
| **膽囊收縮素(CCK)** | 十二指腸與空腸 I 細胞 | **脂肪**（其次蛋白質） | **膽囊收縮**、歐迪氏括約肌放鬆、**胰臟分泌消化酶**、延緩胃排空 |
| 胃抑胜肽(GIP) | 十二指腸 | 葡萄糖、脂肪 | 促進胰島素、抑制胃 |
| **體制素** | **胃與十二指腸**的 D 細胞、胰島 δ 細胞 | 胃酸 | 廣泛抑制消化道激素與分泌 |

- 111-2_BM_015 體制素分泌部位：考選部公告**胃或十二指腸都給分**，兩處都有 D 細胞

## 大腸 {#large-intestine}

- 順序：**盲腸**（接闌尾） → 升結腸 → 橫結腸 → 降結腸 → 乙狀結腸 → 直腸 → 肛管
- 大腸特有構造：**結腸帶**（外縱肌集中成三條帶）、**結腸袋**（結腸帶較短把腸壁擠成袋狀）、**腸脂垂**（表面的脂肪垂）；**小網膜不在橫結腸**（在胃小彎與肝之間）
- 功能：吸收**水分與電解質**，每天把迴腸送來 1–2 公升的食糜濃縮成約 200–250 mL 糞便（《內外科護理學》下冊 p.309）；腸道細菌合成**維生素 K**
- 肛管：齒狀線以上是單層柱狀上皮，以下是**複層扁平上皮**；內括約肌平滑肌（不隨意）、外括約肌骨骼肌（隨意）

::questions{ids="110-2_BM_015,110-1_BM_014,106-1_BM_011"}

## 消化道的血液供應 {#blood-supply}

| 動脈 | 從腹主動脈發出 | 供應 |
|---|---|---|
| **腹腔動脈幹** | 最上面（約 T12） | 分出**胃左動脈**、**脾動脈**、肝總動脈；供應食道腹段、**胃**、**十二指腸**（上段）、**肝、膽囊、胰臟**、**脾臟** |
| **腸繫膜上動脈** | 中間 | 十二指腸下段、**空腸、迴腸**、**盲腸、闌尾**、升結腸、**橫結腸前 2/3**；同時供應小腸與大腸 |
| **腸繫膜下動脈** | 最下面 | **橫結腸後 1/3**、降結腸、**乙狀結腸**、直腸上段 |

- 橫結腸同時接受**腸繫膜上、下動脈**；迴腸**不是**腹腔動脈幹供應
- 靜脈：腸繫膜上靜脈＋脾靜脈（腸繫膜下靜脈先匯入脾靜脈） → **肝門靜脈** → 肝；胃腸吸收的養分先經肝臟處理（見 [[liver-biliary-pancreas#blood-supply]]）
