女性生殖系統負責產生卵子、分泌性激素、提供受精與懷孕的場所，乳房則負責泌乳。本頁整理外生殖器、陰道、子宮與韌帶、輸卵管、卵巢與卵子生成、月經週期，以及乳房與更年期的激素變化。文中縮寫：FSH（Follicle-stimulating hormone，濾泡刺激素）、LH（Luteinizing hormone，黃體生成素）、GnRH（Gonadotropin-releasing hormone，促性腺激素釋放激素）、hCG（human chorionic gonadotropin，人類絨毛膜促性腺激素）、LDL（Low-density lipoprotein，低密度脂蛋白）。FSH、LH 與卵巢激素的作用見 [[endocrine-overview#ovary]]，下視丘與腦下垂體見 [[hypothalamus-pituitary]]，受精與著床見 [[fertilization-embryology]]，男性構造見 [[male-reproductive-system]]

## 重點摘要 {#summary}

- 外生殖器由前往後：**陰蒂 → 尿道外口 → 陰道口**
- **陰蒂**由勃起組織構成，與男性**陰莖**同源；**小陰唇**在前方合成陰蒂包皮
- 子宮分**子宮底、子宮體、峽部、子宮頸**；子宮頸下端突入陰道，可用陰道擴張器直接看到
- 子宮壁三層：內膜（**功能層**＋基底層）、**平滑肌**肌層、外膜；月經時剝落的是**功能層**
- 支撐子宮：**主韌帶、子宮薦骨韌帶**、骨盆膈（提肛肌）、泌尿生殖膈；**圓韌帶**穿過鼠蹊管到大陰唇，維持**前傾**
- 受精最常在**輸卵管壺腹部**
- 卵子生成：**胎兒期**就有卵原細胞並進入第一次減數分裂；排卵時是**次級卵母細胞**，停在**第二次減數分裂中期**，**受精時**才完成
- 月經週期：**FSH** 促濾泡發育 → 雌激素上升 → 正回饋引起 **LH 高峰** → **排卵** → 黃體分泌**黃體素**，內膜進入**分泌期**
- **黃體素**在黃體期（分泌期）最高；黃體期的雌激素與黃體素濃度和懷孕初期接近
- 排卵後黃體素使**基礎體溫上升約 0.3–0.5 ℃**
- 懷孕時高濃度**雌激素與黃體素**抑制乳汁製造，產後下降才開始泌乳
- **更年期**：卵巢功能衰退 → **雌激素下降** → **FSH、LH 上升**

### 國考常考點 {#exam-points}

- 陰道口兩側的**前庭球是勃起組織**，不是腺體；陰道口兩側的腺體是前庭大腺（巴氏腺）
- 經過**鼠蹊管**連到**大陰唇**的是**圓韌帶**；懷孕後期圓韌帶被拉扯 → **鼠蹊部痛**
- 子宮脫垂與**主韌帶、子宮薦骨韌帶**無力有關；**懸韌帶**吊住卵巢，不支撐子宮
- 子宮肌層是**平滑肌**；子宮的血液主要來自**髂內動脈**分支的子宮動脈
- 卵巢是**產生配子**的器官；輸卵管、子宮、子宮頸都不產生配子
- **次級卵母細胞**：23 條染色體（每條仍是兩條姊妹染色分體）；**受精時**完成第二次減數分裂
- **次級濾泡**＝數層顆粒細胞＋**濾泡腔**，裡面是初級卵母細胞；成熟濾泡（葛氏濾泡）內是**次級卵母細胞**，不是 23 條的卵子
- 排卵時隨卵母細胞排出的有**透明帶、放射冠、第一極體**；**內鞘膜細胞**留在卵巢形成黃體
- 青春期 **FSH** 刺激濾泡發育
- 內鞘膜細胞（LH 刺激）合成**雄性素** → **顆粒細胞（濾泡細胞）**用芳香酶轉成**雌二醇**
- 誘發排卵的是**腦下垂體前葉 LH 高峰**；排卵後濾泡變成**黃體**，退化後才是白體
- 排卵前**顆粒細胞分泌酵素**分解濾泡壁，卵才能排出
- 排卵後一天，LH、FSH、雌激素都下降，**黃體素繼續上升**
- 分泌期的子宮內膜腺分泌**肝醣**；月經期只剝落功能層，基底層留下再生
- 純哺餵母乳會**延後排卵**（泌乳素抑制 GnRH）
- 胚胎時期性激素分泌量**高於**青春期前（胎盤 hCG 刺激胎兒性腺、胎盤也分泌雌激素）

## 外生殖器與會陰 {#vulva}

| 構造 | 重點 |
|---|---|
| 陰阜 | 恥骨聯合前方的脂肪墊，青春期長陰毛 |
| 大陰唇 | 皮膚皺褶，與男性**陰囊**同源；**圓韌帶**止於此 |
| 小陰唇 | 無毛、富含皮脂腺；前端合成**陰蒂包皮**與繫帶 |
| **陰蒂** | **勃起組織**（海綿體）、神經末梢多，與**陰莖**同源 |
| 陰道前庭 | 兩側小陰唇之間；有**尿道外口**、陰道口 |
| 前庭球 | 陰道口兩側的**勃起組織**，與陰莖球同源 |
| 前庭大腺（巴氏腺） | 陰道口後外側，性興奮時分泌潤滑液；阻塞 → 巴氏腺囊腫 |
| 會陰 | 陰道口與肛門之間；分娩時可能裂傷或切開（見 [[intrapartum-care#episiotomy]]） |

- 由前往後：**陰蒂 → 尿道外口 → 陰道口 → 肛門**

## 陰道 {#vagina}

- 子宮頸到陰道前庭的肌肉管道；上端圍繞子宮頸形成**穹窿**，**後穹窿最深**，子宮托放在後穹窿（見 [[benign-gynecologic-disorders#prolapse]]）
- 黏膜是複層鱗狀上皮，雌激素使上皮增厚並含**肝醣** → 乳酸桿菌分解成乳酸 → 陰道 **pH 約 3.8–4.5**，防止感染
- 懷孕時雌激素增加 → 陰道黏膜增生、**分泌物增加**
- 更年期雌激素下降 → 黏膜變薄、pH 上升、容易萎縮性陰道炎

::questions{ids="112-1_OP_004"}

## 子宮與韌帶 {#uterus}

- 位置：膀胱後方、直腸前方，正常**前傾前屈**
- 分部：**子宮底**（輸卵管開口以上）、**子宮體**、**峽部**（懷孕後形成子宮下段）、**子宮頸**（下端突入陰道，可用陰道擴張器直接看到，子宮頸抹片在這裡採檢）
- 子宮壁

| 層 | 構造 | 重點 |
|---|---|---|
| 子宮內膜 | **功能層**＋**基底層** | 月經時**功能層**剝落；基底層留下再生 |
| 子宮肌層 | **平滑肌** | 最厚；分娩時收縮；產後壓迫血管止血 |
| 子宮外膜 | 漿膜（腹膜） | |

- 血液：子宮動脈來自**髂內動脈**

| 韌帶或構造 | 位置 | 功能 |
|---|---|---|
| 闊韌帶 | 子宮兩側的腹膜皺褶 | 包住輸卵管、卵巢與血管；支撐力弱 |
| **圓韌帶** | 子宮角 → **鼠蹊管** → **大陰唇** | 維持**前傾**；懷孕後期被拉扯 → 鼠蹊部痛 |
| **主韌帶** | 子宮頸兩側 → 骨盆側壁 | **最主要的支撐**，無力 → 子宮脫垂 |
| **子宮薦骨韌帶** | 子宮頸後方 → 薦骨 | 支撐、把子宮頸往後拉 |
| 骨盆膈（提肛肌）、泌尿生殖膈 | 骨盆底 | 支撐骨盆器官；凱格爾運動訓練這裡 |
| 卵巢懸韌帶 | 卵巢 → 骨盆側壁 | **吊住卵巢**（內有卵巢血管），**不支撐子宮** |

- 子宮收縮：分娩前期**前列腺素**與催產素啟動收縮；**分娩後**催產素使子宮收縮、回復大小（見 [[pituitary-hormones#oxytocin]]）

## 輸卵管 {#fallopian-tube}

- 由外到內：**繖部**（接住卵） → 漏斗部 → **壺腹部**（最寬，**受精最常發生處**） → 峽部 → 子宮部
- 纖毛擺動與平滑肌蠕動把受精卵送到子宮，約 3–4 天
- 子宮外孕最常發生在輸卵管（見 [[fertilization-embryology#implantation]]）

::questions{ids="112-1_BM_008"}

## 卵巢與卵子生成 {#ovary}

### 卵子生成 {#oogenesis}

| 時期 | 細胞 | 染色體 | 停在哪裡 |
|---|---|---|---|
| 胎兒期 | **卵原細胞**（有絲分裂增生） | 雙套 46 | |
| 胎兒期到青春期 | **初級卵母細胞** | 雙套 46 | **第一次減數分裂前期**，一直停到排卵前 |
| 排卵前 | 完成第一次減數分裂 → **次級卵母細胞**＋第一極體 | 單套 23（每條含兩條染色分體） | **第二次減數分裂中期** |
| **受精時** | 完成第二次減數分裂 → **卵**＋第二極體 | 單套 23 | |

- 卵原細胞在**胎兒時期**就形成，出生後不再增加；一個初級卵母細胞只產生**一個卵**（其他是極體）
- 和精子生成比較見 [[male-reproductive-system#spermatogenesis]]

### 濾泡發育 {#follicles}

| 濾泡 | 構造 |
|---|---|
| 原始濾泡 | 初級卵母細胞＋單層扁平濾泡細胞 |
| 初級濾泡 | 濾泡細胞變立方或多層（顆粒細胞），出現**透明帶** |
| **次級濾泡** | 數層顆粒細胞＋**濾泡腔**（含液體），內仍是**初級卵母細胞** |
| **成熟濾泡（葛氏濾泡）** | 單一大濾泡腔；卵母細胞外圍有透明帶、**放射冠**；外圍**內鞘膜、外鞘膜**；排卵前內是**次級卵母細胞** |
| **黃體** | 排卵後留下的顆粒細胞與內鞘膜細胞黃體化，分泌**黃體素**與雌激素 |
| 白體 | 沒懷孕時黃體約 14 天退化成白色疤痕 |

- 雙細胞模式：**內鞘膜細胞**受 LH 刺激合成**雄性素** → **顆粒細胞**受 FSH 刺激，用**芳香酶**把雄性素轉成**雌二醇**
- 排卵時排出：次級卵母細胞、**透明帶**、**放射冠**、第一極體；**內鞘膜細胞不會排出**

::questions{ids="114-2_BM_016,113-1_BM_017,109-1_BM_006,108-2_BM_025,108-1_BM_011"}

## 月經週期 {#menstrual-cycle}

以 28 天週期、第 14 天排卵為例；排卵後到下次月經的**黃體期固定約 14 天**，週期長短差在濾泡期

| 天數 | 卵巢週期 | 子宮週期 | 激素 |
|---|---|---|---|
| 1–5 | 濾泡期開始 | **月經期**：功能層剝落 | 雌激素、黃體素都低；FSH 開始上升 |
| 6–14 | **濾泡期**：FSH 使濾泡發育，選出一個優勢濾泡 | **增生期**：雌激素使內膜增厚、腺體與螺旋動脈生長 | **雌激素**逐漸升高 |
| 約 14 | **排卵** | | 雌激素高到一定程度轉為**正回饋** → **LH 高峰**（FSH 也小高峰）→ 約 24–36 小時後排卵 |
| 15–28 | **黃體期**：黃體分泌黃體素與雌激素 | **分泌期**：內膜腺體分泌**肝醣**、內膜最厚，準備著床 | **黃體素最高**；負回饋抑制 FSH、LH |
| 沒懷孕 | 黃體退化 | 黃體素下降 → 螺旋動脈收縮、內膜缺血 → 月經 | 抑制解除，FSH 再上升 |

- 懷孕時胚胎分泌 **hCG** 維持黃體，黃體素不下降，所以不來月經；黃體期的雌激素、黃體素濃度和**懷孕初期接近**
- 排卵後一天：LH、FSH、雌激素下降，**黃體素繼續上升**
- 單一高劑量雌激素不能直接促成排卵；黃體化是 **LH** 的作用，不是 FSH

::questions{ids="113-3_BM_015,113-2_BM_002,110-2_BM_026,109-1_BM_024,107-2_BM_024,106-1_BM_024"}

### 排卵的徵象 {#ovulation-signs}

| 方法 | 變化 | 判讀 |
|---|---|---|
| **基礎體溫** | 排卵前低溫約 36.5 ℃，排卵時稍降，排卵後受**黃體素**影響上升約 0.3–0.5 ℃，高溫期約 2 週 | 體溫上升代表**已經排卵**；高溫持續超過 18 天要想到懷孕 |
| **子宮頸黏液** | 排卵期受雌激素影響變**清澈、量多、有彈性（拉絲）**，像蛋白 | 濕潤期是易受孕期；排卵後黃體素使黏液變稠、量少 |
| 排卵試紙 | 尿中 LH 上升 | 約 24–36 小時內排卵 |
| 經間痛、少量出血 | 部分婦女排卵時下腹痛 | |

- 基礎體溫每天**醒來尚未活動前**測量，需連續記錄 3–6 個月才準（課本書頁約 497）
- 用來避孕或助孕的算法見 [[family-planning#natural-methods]]、[[infertility#timing]]
- 純哺餵母乳：嬰兒吸吮使**泌乳素**上升，抑制 GnRH → **延後排卵**；排卵可能在第一次月經**之前**就恢復，所以不能用「沒來月經」判斷沒排卵

::questions{ids="109-1_OP_022"}

## 乳房 {#breast}

- 乳腺由 15–20 個乳葉組成，各有輸乳管開口於乳頭；乳暈有蒙哥馬利腺
- 雌激素促進**乳管**發育，黃體素促進**腺泡（乳葉）**發育
- 懷孕時**雌激素與黃體素濃度高**，抑制泌乳素對乳腺的作用 → **不製造乳汁**；胎盤娩出後兩者驟降 → 泌乳素開始作用 → 泌乳
- 泌乳素（前葉）負責**製造**乳汁；催產素（後葉）負責**射乳**（見 [[hypothalamus-pituitary#lactation]]）
- 乳房疾病：纖維腺瘤見 [[benign-gynecologic-disorders#breast]]，乳癌見 [[breast-cancer]]

## 性分化與一生的激素變化 {#life-stages}

- 胚胎性分化見 [[male-reproductive-system#sexual-differentiation]]
- 胚胎時期性激素分泌量**高於**青春期前：胎盤 hCG 刺激胎兒性腺，母體與胎盤的雌激素也很高；出生後下降，到青春期 GnRH 脈衝分泌才再上升
- 女嬰出生後可能有少量陰道出血（**假月經**）與乳房腫大，是離開母體雌激素後的撤退出血（見 [[fertilization-embryology#fetal-development]]）

### 更年期 {#menopause}

- 定義：連續 **12 個月**沒有月經；台灣平均約 50 歲
- 卵巢濾泡耗盡 → **雌激素（必定）下降**、黃體素下降、抑制素下降 → 負回饋消失 → **FSH、LH 上升**（FSH 上升更明顯）
- 雌激素下降的影響：熱潮紅、盜汗、陰道萎縮與 **pH 上升**、**LDL 上升**（心血管風險增加）、骨質流失
- 熱潮紅機轉與血脂變化見 [[endocrine-overview#menopause]]；症狀與照護見 [[menstrual-disorders#menopause]]；荷爾蒙療法見 [[sex-hormones#hormone-therapy]]
