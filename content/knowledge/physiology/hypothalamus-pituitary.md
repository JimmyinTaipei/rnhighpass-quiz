**下視丘**是神經系統指揮內分泌的地方，**腦下垂體**是它的執行者。本頁整理兩者的構造、連接方式（門脈與軸突）、下視丘的常考核區，以及前後葉各激素的作用與調控；下視丘的非內分泌功能（體溫、食慾、生理時鐘）也見 [[brain-anatomy#hypothalamus]]，激素與回饋總論見 [[endocrine-overview]]

## 重點摘要 {#summary}

- 腦下垂體在**蝶骨蝶鞍**的腦下垂體窩，經**漏斗柄**接下視丘；下視丘在腦下垂體**上方**、屬間腦；腦下垂體正上方是**視交叉**，腫瘤往上長會造成**雙顳側偏盲**
- **前葉**（腺垂體）：下視丘的釋放激素經**垂體門脈**送來；分泌 **GH、PRL、TSH、ACTH、FSH、LH**；中間部分泌 MSH
- **後葉**（神經垂體）：ADH 與催產素在**下視丘視上核、室旁核**合成，經**下視丘－垂體徑**（軸突運輸）送到後葉儲存、釋放；後葉細胞本身不合成
- 前葉激素多受「釋放激素」刺激，只有**泌乳素主要受多巴胺抑制**；體抑素主要抑制**生長激素**
- **生長激素**：深睡期、低血糖、運動、壓力時分泌增加；高血糖、體抑素、**IGF-1（體介素）** 抑制；作用是促進蛋白質合成、**脂肪分解**、**拮抗胰島素**（減少胰島素受體數目、促進糖質新生）
- 哺乳：吸吮 → 前葉**泌乳素**促進乳汁**製造**、後葉**催產素**讓肌上皮細胞收縮**射乳**（也讓子宮收縮）
- **ADH** 作用在集尿管的 V2 受體，插入**水通道蛋白**回收水分；高濃度時經 V1 受體**收縮血管**

### 國考常考點 {#exam-points}

- 經**下視丘－垂體徑**運送的是 **ADH**（與催產素）；泌乳素、TSH、GH 由前葉分泌，靠門脈調控
- 下視丘的調節因子經**門脈血管叢直接送到前葉**，不是靠神經衝動，也不作用在後葉
- 腦下垂體中間部分泌 **MSH**；**褪黑激素**是松果腺分泌的
- 前葉染色：**ACTH、TSH、FSH、LH 由嗜鹼性細胞**分泌；GH、泌乳素由嗜酸性細胞分泌
- ADH 在**視上核**合成；調控褪黑激素節律的是**視交叉上核**；呼吸節律在延腦、橋腦，**不是下視丘**
- 頭部外傷影響 ADH 分泌的是下視丘與後葉，**不是視丘**
- 前葉不分泌**催產素、ADH**；泌乳素是**前葉**分泌；動情素不是腦下垂體分泌的
- 睡眠無法進入沉睡期 → 影響**生長激素**；促進脂肪分解最強的是**生長激素**；**體介素**(IGF-1)抑制 GH 分泌
- 口渴時 **ADH 增加** → 集尿管水分回收增加
- 哺乳時刺激**後葉釋放催產素**（不是前葉）才讓子宮收縮；泌乳素**夜間分泌較多**；哺乳延後月經是因**泌乳素抑制 GnRH**，使雌激素與 LH 下降

## 位置與構造 {#structure}

::figure{src="/knowledge-images/servier-pituitary.svg" labels="pituitary" alt="下視丘與腦下垂體正中切面：左為前葉與垂體門脈系統，右為後葉與下視丘－垂體徑的軸突末梢"}

- **位置**：腦下垂體位在**蝶骨的蝶鞍**（腦下垂體窩），被蝶骨保護；經**漏斗柄**接到上方的**下視丘**（間腦的一部分）
- 正上方是**視交叉**：腦下垂體腫瘤往上長最先壓到視交叉，造成**雙顳側偏盲**（見 [[special-senses#visual-pathway]]）；腫瘤與經蝶骨手術見 [[pituitary-disorders]]

| | 前葉（腺垂體） | 後葉（神經垂體） |
|---|---|---|
| 胚胎來源 | 口腔外胚層的**拉克氏囊**（上皮） | 間腦往下長的**神經外胚層** |
| 和下視丘的連接 | **血管**：下視丘－垂體**門脈系統** | **神經**：下視丘－垂體**徑**（視上核、室旁核的軸突） |
| 激素在哪裡合成 | 前葉細胞自己合成 | **下視丘**合成，後葉只儲存、釋放 |
| 激素 | GH、PRL、TSH、ACTH、FSH、LH（中間部：MSH） | ADH、催產素 |

### 下視丘－垂體門脈系統 {#portal-system}

1. **上垂體動脈**進入正中隆起，形成**初級微血管叢**
2. 下視丘神經元把**釋放激素或抑制激素**分泌到初級微血管叢
3. 經**垂體門脈**往下送到前葉的**次級微血管叢**
4. 直接作用在前葉細胞，再由靜脈把前葉激素送到全身

- 好處：釋放激素不用經過全身循環稀釋，少量就有效

### 前葉的細胞與染色 {#cell-types}

| 染色 | 細胞 | 分泌 |
|---|---|---|
| **嗜酸性** | 生長激素細胞、泌乳素細胞 | **GH**、**泌乳素** |
| **嗜鹼性** | 甲狀腺刺激素細胞、促腎上腺皮質素細胞、促性腺激素細胞 | **TSH**、**ACTH**、**FSH、LH** |
| 難染細胞 | 顆粒少、染色淡 | 多被認為是幹細胞或已釋出顆粒的細胞；部分教科書認為其中包含分泌 ACTH 的細胞 |

- 記法：嗜鹼性是「TSH、ACTH、FSH、LH」這些作用在其他腺體的；嗜酸性是 GH、泌乳素

## 下視丘的常考核區 {#nuclei}

![下視丘常考核區與腦下垂體（正中矢狀切面示意）](/knowledge-images/hypothalamic-nuclei.svg)

| 核區 | 功能 | 受損的表現 |
|---|---|---|
| **視上核** | 合成 **ADH**（為主）與催產素 → 後葉 | ADH 不足 → 尿崩症（多尿） |
| **室旁核** | 合成**催產素**（為主）與 ADH → 後葉；分泌 CRH 啟動壓力反應 | |
| **視交叉上核** | **生理時鐘**：接收視網膜光訊號，控制晝夜節律與**褪黑激素** | 睡眠與節律紊亂 |
| **弓狀核** | 分泌釋放激素與**多巴胺**（抑制泌乳素）進入門脈 | |
| **腹內側核** | **飽食中樞** | 多食、肥胖 |
| **外側區** | **攝食（飢餓）中樞** | 厭食、消瘦 |
| **視前區與前區** | **散熱中樞**（流汗、血管擴張） | 高體溫 |
| **後區** | **產熱中樞**（顫抖、血管收縮） | 體溫隨環境變化 |
| **乳頭體** | 屬邊緣系統的記憶迴路 | 維生素 B₁ 缺乏時受損 |

- 下視丘的其他功能：口渴中樞、自主神經與情緒反應；**呼吸節律在延腦與橋腦**，不是下視丘
- **頭部外傷**傷到下視丘或後葉（**不是視丘**） → ADH 分泌失調（尿崩症或 SIADH，見 [[head-injury]]）

### 激素與體溫 {#body-temperature}

- 體溫調節的機轉見 [[brain-anatomy#thermoregulation]]
- 讓體溫**上升**：**甲狀腺素**（代謝率上升）、焦慮與壓力（交感神經與**腎上腺素**）、**排卵後黃體素**（基礎體溫升高約 0.3–0.5°C）
- 讓體溫**偏低**：**甲狀腺功能低下**、**老年人**（代謝率低、調節變差）

## 下視丘的釋放與抑制激素 {#hypothalamic-hormones}

| 下視丘激素 | 作用在前葉 | 備註 |
|---|---|---|
| **TRH** | 促進 **TSH** | 也會促進泌乳素 |
| **CRH** | 促進 **ACTH** | 壓力時增加 |
| **GnRH** | 促進 **FSH、LH** | 要**脈衝式**分泌才有效，持續給反而抑制 |
| **GHRH** | 促進 **GH** | |
| **體抑素**(GHIH) | 主要**抑制 GH**，也抑制 TSH | 胰島 δ 細胞與腸道也分泌，抑制多種消化道激素 |
| **多巴胺**（泌乳素抑制因子） | **抑制泌乳素** | 泌乳素是唯一主要受「抑制」控制的前葉激素 |

- 漏斗柄被切斷或壓迫時，其他前葉激素都下降，只有**泌乳素上升**（失去多巴胺抑制）

::questions{ids="110-1_BM_027,106-1_BM_023"}

## 前葉激素 {#anterior-lobe}

| 激素 | 標的 | 主要作用 |
|---|---|---|
| **生長激素**(GH) | 肝臟（產生 IGF-1）、骨骼、肌肉、脂肪 | 生長、蛋白質合成、脂肪分解、升血糖 |
| **泌乳素**(PRL) | 乳腺 | 乳汁**製造** |
| **TSH** | 甲狀腺 | T3、T4 分泌 |
| **ACTH** | 腎上腺皮質 | 皮質醇分泌 |
| **FSH** | 卵巢濾泡、睪丸**塞氏細胞** | 濾泡發育與雌激素；精子生成 |
| **LH** | 卵巢（排卵、黃體）、睪丸**萊氏細胞** | 排卵；睪固酮分泌 |

- 前葉激素不只作用在其他內分泌腺，GH 與泌乳素直接作用在骨骼、肌肉、乳腺
- FSH、LH 與睪丸卵巢的細胞見 [[endocrine-overview#gonads-placenta]]

::questions{ids="114-2_MS_042,106-2_MS_068,107-2_BM_002,108-1_BM_002,112-1_BM_039"}

### 生長激素 {#growth-hormone}

- **分泌型態**：脈衝式，**深睡期**（非快速動眼期的沉睡期）分泌最多；睡眠被干擾、無法進入沉睡期 → GH 分泌減少
- **促進分泌**：**低血糖**、**運動**（尤其高強度）、壓力、空腹、胺基酸（精胺酸）、GHRH
- **抑制分泌**：**高血糖**、**體抑素**、**IGF-1（體介素）** 的負回饋、肥胖
- **作用**
   1. 刺激肝臟產生 **IGF-1**，經 IGF-1 促進骨骺軟骨生長與蛋白質合成
   2. **促進脂肪分解**，血中脂肪酸上升（在胰島素、礦物皮質素、升糖素、GH 之中效果最強）
   3. **拮抗胰島素**：減少周邊組織的**胰島素受體數目**、降低葡萄糖利用、促進**糖質新生** → 血糖上升
- 過多或缺乏：骨骺閉合前過多是巨人症、閉合後是肢端肥大症，常合併高血糖；兒童缺乏是生長遲緩（見 [[pituitary-disorders#gh-excess]]、[[pituitary-disorders#gh-deficiency]]）

::questions{ids="112-2_FA_047,113-1_BM_005,107-2_BM_023,113-3_BM_014,112-2_BM_014,106-1_BM_022"}

### 泌乳素、催產素與哺乳 {#lactation}

| | 泌乳素 | 催產素 |
|---|---|---|
| 來源 | 前葉 | 下視丘合成、**後葉**釋放 |
| 作用 | 乳腺**製造**乳汁 | 乳腺周圍**肌上皮細胞**收縮 → **射乳反射**；**子宮收縮** |
| 刺激 | 吸吮、夜間（**夜間分泌較多**）；胎盤娩出後雌激素與黃體素下降才大量泌乳 | 吸吮、聽到寶寶哭聲；分娩時子宮頸擴張（正回饋） |
| 抑制 | 多巴胺 | 壓力、疼痛 |

- **乳汁的移出**與吸吮次數越多，泌乳量越多（供需原則），所以鼓勵**夜間哺乳**
- 泌乳素高 → **抑制 GnRH** → 雌激素與 LH 下降、不排卵 → **月經延後**（哺乳期無月經，夜間哺乳效果較好，但不建議單靠它避孕）
- 哺乳對母親的好處：子宮收縮較快、**停經前乳癌與卵巢癌風險較低**、每天多消耗約 500 大卡有助產後體重恢復
- 催產素臨床用途：靜脈滴注**引產與加強子宮收縮**；鼻噴劑曾用於促進射乳；抗利尿作用比 vasopressin 弱很多（藥物細節見 [[pituitary-hormones#oxytocin]]）

::questions{ids="109-1_OP_024,105-1_BM_024,111-2_OP_022,106-1_OP_026,114-1_OP_016,110-1_OP_023,107-2_BM_061"}

## 後葉激素：抗利尿激素 {#posterior-lobe}

- **合成**：下視丘**視上核**（為主）與室旁核 → 經軸突送到後葉儲存、釋放；**後葉細胞不合成 ADH**
- **刺激分泌**：**血漿滲透壓上升**（下視丘滲透壓感受器，同時引起口渴）、**血量或血壓下降**、疼痛、噁心、壓力
- **抑制分泌**：滲透壓下降、血量增加、**酒精**
- **作用**
   1. **V2 受體**（集尿管與遠曲小管末段）：讓**水通道蛋白**(aquaporin-2)插進細胞膜 → 水分回收增加 → 尿量減少、尿液濃縮；不是作用在近曲小管
   2. **V1 受體**（血管平滑肌）：高濃度時**收縮血管**、升高血壓，所以也叫**血管加壓素**
- 口渴時：滲透壓上升 → **ADH 增加**、醛固酮也會增加（不是被抑制）
- 臨床
   1. ADH 不足 → **尿崩症**（大量稀釋尿）；中樞性用 **vasopressin** 或 desmopressin 補充
   2. ADH 過多 → **SIADH**（水分滯留、低血鈉）
   3. 兩者的比較見 [[diabetes-insipidus-siadh]]；頭部外傷後的變化見 [[head-injury]]
