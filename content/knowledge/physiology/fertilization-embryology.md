從受精到出生分成**胚胎前期**（受精後 0–2 週）、**胚胎期**（第 3–8 週）、**胎兒期**（第 9 週到出生）。本頁整理受精、著床、胚胎膜與胎盤、三胚層、各週發育重點與雙胞胎。週數注意：本頁寫「受精後幾週」時是**胚胎學週數**，臨床的**妊娠週數**從最後一次月經算起，大約多 2 週。文中縮寫：hCG（human chorionic gonadotropin，人類絨毛膜促性腺激素）、hPL（human placental lactogen，人類胎盤泌乳素）、L/S（Lecithin/Sphingomyelin ratio，卵磷脂與抱合髓磷脂比值）。卵子與精子的生成見 [[female-reproductive-system#oogenesis]]、[[male-reproductive-system#spermatogenesis]]，胎兒循環見 [[blood-vessels#fetal-circulation]]，胎盤激素見 [[endocrine-overview#placenta]]，染色體異常與遺傳見 [[chromosomal-disorders]]、[[genetic-inheritance]]

## 重點摘要 {#summary}

- 受精最常在**輸卵管壺腹部**；精子要穿過**放射冠**與**透明帶**；單套精子＋單套卵子 → 雙套受精卵
- 受精卵邊分裂邊往子宮走：**桑椹胚**（約第 3–4 天進子宮） → **囊胚** → 約受精後 **6–10 天**以**囊胚**型態著床
- 正常著床在子宮體**上部後壁**，著床處的內膜是**底蛻膜**；懷孕後的內膜分**底蛻膜、包蛻膜、真蛻膜**
- **著床時**滋養層（融合滋養層）開始分泌 **hCG** → 維持黃體 → 驗孕的依據
- **絨毛膜**由**滋養層**發育而來，絨毛膜＋**底蛻膜**形成**胎盤**；**羊膜**是最內層
- 黃體退化後（約妊娠 7–10 週起）由**胎盤**分泌雌激素與黃體素；懷孕 11 週後主要來源是**胎盤**
- 臍帶：**兩條動脈、一條靜脈**
- **胚胎期**（受精後第 3–8 週）細胞分裂最快、**器官形成**，最容易受**致畸胎物**影響
- **心臟**是第一個有功能的器官（受精後約第 3–4 週開始跳）
- 中胚層 → **心臟**、血液、肌肉、骨骼、腎臟、生殖腺
- **第三孕期**體重增加最快；**L/S ≥ 2** 表示肺成熟

### 國考常考點 {#exam-points}

- **雙胞胎不是兩隻精子進入同一卵**；一個卵只會讓一隻精子進入（透明帶反應阻止多精受精）
- 受精時卵子才完成**第二次減數分裂**
- 著床是**囊胚**植入子宮內膜，不是「受精後立即」、也不在子宮頸內口（那是前置胎盤的位置）；著床處是**底蛻膜**，不是真蛻膜
- 著床後的子宮內膜叫**蛻膜**，不是絨毛膜
- 雙板胚胎是第 2 週（上胚層＋下胚層），**第 3 週**原腸化形成三胚層
- 第 8 週（胚胎期結束）主要器官都已形成；第 4 週胚胎只有約 4–5 mm，不是 3 公分
- 胎兒**眼睛**約 26–28 週才張開、對光有反應；16 週眼瞼仍閉著
- 致畸胎最敏感是**胚胎期**（受精後 3–8 週），不是 12–16 週
- 胎兒愈成熟**皮下脂肪愈多、胎毛愈少**
- 羊水**弱鹼性**（pH 約 7.0–7.5）；羊水量約 **34–36 週**最多，之後減少
- L/S 比值 **≥ 2** 才表示肺成熟，**< 1** 是不成熟
- 胎兒在子宮內**沒有呼吸功能**，氣體交換靠胎盤
- 子宮外孕最常見在**輸卵管**（多在壺腹部）

## 受精 {#fertilization}

- **精子獲能**：在女性生殖道中精子膜改變，才有能力受精
- 精子進入卵子的過程
   1. 穿過**放射冠**（顆粒細胞）
   2. **頂體反應**：釋放酵素溶解**透明帶**
   3. 一隻精子與卵膜融合 → 卵子**皮質反應**使透明帶變硬，**阻止其他精子進入**
   4. 卵子完成**第二次減數分裂**、排出第二極體
   5. 兩個單套原核融合 → **受精卵**（雙套 46 條）
- 時間：卵子排出後約 **12–24 小時**內可受精；精子約可存活 **3 天**
- 地點：**輸卵管壺腹部**
- 性別由精子決定（X 或 Y）

## 卵裂與著床 {#implantation}

| 時間（受精後） | 事件 |
|---|---|
| 約 30 小時 | 第一次分裂（2 細胞） |
| 第 3–4 天 | **桑椹胚**（約 16 細胞），進入子宮腔 |
| 第 4–5 天 | **囊胚**：外層**滋養層**（將來形成絨毛膜與胎盤）、內細胞團（將來形成胚胎與羊膜） |
| 第 6–10 天 | **著床**：囊胚脫出透明帶，滋養層侵入子宮內膜；約第 10–12 天完全埋入 |
| 著床時 | 融合滋養層開始分泌 **hCG**；母血約著床後數天可測到 |

- 人工生殖的胚胎植入時機見 [[infertility#art]]
- **蛻膜**：懷孕後受黃體素作用的子宮內膜

| 蛻膜 | 位置 | 結局 |
|---|---|---|
| **底蛻膜** | 胚胎與子宮肌層之間（著床處） | 與絨毛膜葉合成**胎盤的母體面** |
| 包蛻膜 | 包住胚胎面向子宮腔的部分 | 隨胎兒長大與真蛻膜融合 |
| 真蛻膜（壁蛻膜） | 其餘子宮內膜 | |

- 子宮內膜的發育受**雌激素與黃體素**影響
- **子宮外孕**：受精卵著床在子宮腔以外，**最常見在輸卵管**（多在壺腹部），其次卵巢、腹腔、子宮頸；輸卵管發炎或沾黏、子宮外孕病史、人工生殖是危險因子；臨床表現與處置見 [[high-risk-pregnancy#ectopic]]

## 胚胎膜、羊水與胎盤 {#fetal-membranes}

### 胚胎膜 {#membranes}

| 膜 | 來源 | 位置與功能 |
|---|---|---|
| **絨毛膜** | 囊胚**滋養層** | **外層**；長出絨毛，與**底蛻膜**形成胎盤；其餘部分變平滑絨毛膜 |
| **羊膜** | 內細胞團 | **最內層**，包住羊水與胎兒；後來與絨毛膜貼合 |
| 卵黃囊 | | 早期造血、原始生殖細胞來源，之後退化 |
| 尿囊 | | 臍帶血管的來源 |

### 羊水 {#amniotic-fluid}

- 來源：早期來自母體血漿滲出，**妊娠中期以後主要是胎兒尿液**；胎兒吞嚥與肺部分泌參與循環
- 性質：清澈或淡黃、**弱鹼性**（pH 約 7.0–7.5）；含胎脂、胎毛、脫落細胞（可做羊膜穿刺）
- 量：隨週數增加，約 **34–36 週最多**（約 800–1000 mL），之後減少；羊水指數與過多、過少見 [[prenatal-assessment#ultrasound]]
- 功能：保護胎兒免受撞擊、維持體溫、讓胎兒自由活動與肺部發育、防止胎兒與羊膜沾黏、分娩時擴張子宮頸

::questions{ids="108-1_OP_006"}

### 胎盤 {#placenta}

- 形成：絨毛膜葉（胎兒面）＋**底蛻膜**（母體面）；約妊娠 12 週構造完成；足月約 500 公克、直徑約 20 公分
- 母體血在絨毛間隙流動，**母血與胎兒血不直接混合**，靠絨毛膜擴散交換
- 功能

| 功能 | 重點 |
|---|---|
| 呼吸 | 氧氣與二氧化碳交換；胎兒在子宮內不靠肺呼吸 |
| 營養與排泄 | 葡萄糖（促進擴散）、胺基酸、水、電解質；胎兒代謝廢物交給母體排出 |
| 免疫 | **IgG** 可通過胎盤（被動免疫）；IgM 不能 |
| 屏障 | 部分藥物、酒精、病毒（德國麻疹、CMV、HIV）與梅毒螺旋體仍可通過，不是完全屏障 |
| **內分泌** | **hCG**（維持黃體，約妊娠 8–10 週最高）、**hPL**（拮抗胰島素）、**雌激素**、**黃體素** |

- **黃體與胎盤交接**：黃體在早期分泌黃體素維持懷孕；約妊娠 **7–10 週**後由**胎盤**接手，所以 11 週後雌激素與黃體素主要來自**胎盤**

::questions{ids="112-1_OP_003,106-2_makeup_OP_011"}

### 臍帶 {#umbilical-cord}

- 足月長約 **50–55 公分**；**兩條臍動脈**（帶缺氧血回胎盤）、**一條臍靜脈**（帶充氧血到胎兒），外包**華通氏膠**保護血管不被壓迫
- 只有一條臍動脈要注意合併先天異常（見 [[newborn-assessment#chest-abdomen]]）
- 斷臍時機與臍帶護理見 [[newborn-care#immediate-care]]、[[newborn-care#cord-care]]

## 三胚層與器官形成 {#germ-layers}

- 第 2 週：雙板胚胎（上胚層、下胚層）
- **第 3 週**：原腸化形成**三胚層**；第 3–8 週是**器官形成期**

| 胚層 | 發育成 |
|---|---|
| **外胚層** | **表皮**、毛髮、指甲、**神經系統**（腦、脊髓、周邊神經）、眼睛水晶體、內耳、牙釉質、腎上腺髓質、腦下垂體 |
| **中胚層** | **心臟**、血管、**血液**、骨骼、**肌肉**、真皮、結締組織、**腎臟**與輸尿管、**生殖腺**、腎上腺皮質、脾臟 |
| **內胚層** | 消化道與呼吸道**上皮**、**肝臟**、**胰臟**、甲狀腺、副甲狀腺、胸腺、膀胱與尿道上皮 |

- 外胚層記「外面與神經」、內胚層記「管子的內襯與它長出的腺體」、中胚層是其餘
- 生殖器官分化見 [[male-reproductive-system#sexual-differentiation]]

## 發育分期與致畸胎 {#development-periods}

| 時期（受精後） | 特點 | 致畸胎 |
|---|---|---|
| **胚胎前期** 0–2 週 | 受精、卵裂、著床 | 「全有或全無」：受影響大多流產，沒流產多半正常 |
| **胚胎期** 3–8 週 | **細胞分裂與分化最快**、**器官形成**；第 8 週主要器官都已形成 | **最敏感**，容易造成重大結構畸形 |
| **胎兒期** 9 週–出生 | 器官長大與功能成熟、體重增加 | 主要影響生長與功能（例：腦部、生殖器仍可能受影響） |

- 常見致畸胎物：酒精、抗癲癇藥、isotretinoin、warfarin、ACE 抑制劑、德國麻疹、CMV、梅毒、輻射、高血糖；懷孕用藥分級與藥物見各藥物頁
- 孕前葉酸預防神經管缺陷見 [[prenatal-care#nutrient-needs]]

::questions{ids="106-2_OP_006"}

## 胎兒發育重點 {#fetal-development}

用**妊娠週數**（從最後一次月經算），括號是常考里程碑

| 妊娠週數 | 重點 |
|---|---|
| 5–6 週 | **心臟開始跳動**（受精後約第 22 天），超音波可見胎心；**心臟是第一個有功能的器官** |
| 10 週（受精後 8 週） | 胚胎期結束，主要器官雛形都已形成，開始叫胎兒 |
| 12 週 | 外生殖器可分辨性別、指甲出現、開始**吞嚥羊水**、腎臟製造尿液、都卜勒可聽到胎心音 |
| 16 週 | 胎便開始在腸道形成、骨骼骨化明顯、頭髮出現 |
| **20 週** | **胎毛、胎脂**出現；母親感覺**胎動**（初產約 18–20 週）；聽診器可聽到胎心音；建立**睡眠與活動週期** |
| 24 週 | 第二型肺泡細胞開始製造**表面張力素**；可存活的下限（約 22–24 週） |
| **28 週** | **眼睛張開**、對光有反應；皮下脂肪開始堆積 |
| 32–36 週 | **皮下脂肪**大量堆積、**體重增加最快**；胎毛逐漸減少；L/S 約 35 週達 2 |
| 37–40 週 | 足月；胎毛大多消失、胎脂只剩皺褶處 |

- **第三孕期**是體重快速增加的時期；第二孕期長度增加較明顯
- 女嬰出生後的**假月經**、乳房腫大：出生後母體**雌激素中斷**引起，數天內消失；IgG 可經胎盤到胎兒；新生兒評估見 [[newborn-assessment]]

::questions{ids="109-2_OP_010,109-1_OP_005,108-2_OP_060"}

### 肺的發育與成熟 {#lung-maturity}

| 時期（妊娠週數） | 發育 |
|---|---|
| 偽腺期 約 5–17 週 | **氣管、支氣管**形成到末端細支氣管 |
| 小管期 約 16–25 週 | 呼吸性細支氣管、微血管增生；約 24 週開始製造表面張力素 |
| 囊狀期 約 24–36 週 | 終末囊（原始肺泡）形成，表面張力素增加 |
| 肺泡期 約 36 週到兒童期 | 真正肺泡大量形成，出生後持續增加 |

- 胎兒在子宮內有**呼吸樣動作**但**沒有呼吸功能**，肺內充滿液體
- **L/S 比值**（羊水中卵磷脂與抱合髓磷脂）
   1. **≥ 2**：肺成熟，出生後發生呼吸窘迫機會低
   2. < 1.5：不成熟；**< 1 表示很不成熟**
   3. 糖尿病母親的胎兒肺成熟較慢
- 產前類固醇促進胎兒肺成熟，新生兒呼吸窘迫症候群見 [[ards-respiratory-failure#neonatal-rds]]

## 雙胞胎 {#twins}

| | **同卵（單卵）** | **異卵（雙卵）** |
|---|---|---|
| 形成 | **一個受精卵**分裂成兩個胚胎 | **兩個卵**分別被**兩隻精子**受精 |
| 基因、性別 | 相同、同性別 | 和一般兄弟姊妹一樣，性別可不同 |
