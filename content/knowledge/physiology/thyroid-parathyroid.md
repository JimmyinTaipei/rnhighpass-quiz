**甲狀腺**掌管全身的代謝速度，**副甲狀腺**與甲狀腺的濾泡旁細胞一起調節血鈣。本頁整理構造、甲狀腺素的合成與作用、檢驗的生理基礎，以及鈣磷調節；甲狀腺疾病見 [[hyperthyroidism]]、[[hypothyroidism]]、[[thyroid-nodules-cancer]]，回饋軸見 [[endocrine-overview#feedback]]

## 重點摘要 {#summary}

- 甲狀腺在氣管前方，左右兩葉以**峽部**相連；組織特徵是**濾泡**，腔內充滿**膠體**(甲狀腺球蛋白)
- **濾泡細胞**分泌 T4、T3；**濾泡旁細胞**(C 細胞)分泌**降鈣素**；**副甲狀腺主細胞**分泌 **PTH**
- 甲狀腺**主要分泌 T4**(約 90%)，**T3 活性較強**、半衰期較短；血中運輸以 T4 為主，大多和 **TBG** 結合
- 合成：攝取碘離子 → 氧化成碘分子 → 酪胺酸碘化(MIT、DIT) → 偶合成 T3、T4 → 存在膠體
- 甲狀腺素：**基礎代謝率**與產熱上升、心跳與心輸出量增加、促進醣類分解；**胎兒與嬰兒腦部發育**必需(缺乏 → 呆小症)
- 碘缺乏或甲狀腺功能低下 → T4 下降 → **TSH 上升** → 甲狀腺腫；**TSH 是最敏感的篩檢**
- **PTH**：骨(活化蝕骨細胞釋鈣)、腎(**遠曲小管回收鈣**、**近曲小管排磷**、活化維生素 D)、腸(經維生素 D 吸收鈣) → 血鈣 ↑、血磷 ↓
- **降鈣素**抑制蝕骨細胞、讓骨質密度上升，作用和 PTH 相反

### 國考常考點 {#exam-points}

- 具有**膠體**構造的是**甲狀腺**
- 甲狀腺激素合成的第一步：**碘離子轉成碘分子**(國考答案)
- 甲狀腺**主要分泌 T4**；T4 半衰期**較長**、活性**較低**
- **Graves 病 TSH 下降**；先天性甲狀腺功能低下 **T4 低、TSH 高**；碘不足時 TSH **升高**(不是過低)
- 甲狀腺素不足 → **心輸出量降低**、怕冷；甲狀腺亢進 → 基礎代謝率增高、**脈搏變快**；寒冷時身體會**釋放甲狀腺素**
- 孕期補碘是為了胎兒**腦部神經發育**；孕期 **TBG 在第二孕期最高**
- 作用與 PTH 相反的是**濾泡旁細胞**(降鈣素)
- PTH 在腎臟**促進遠曲小管回收鈣**、**抑制近曲小管回收磷**；PTH 幫助維生素 D 轉成**骨化三醇**
- 分泌持續增加讓骨密度**下降**的是 **PTH**；讓骨密度**上升**的是**降鈣素**；最有利骨密度的是**活性維生素 D 上升**
- 副甲狀腺被切除 → **低血鈣**、高血磷、喉部痙攣與手足抽搐；副甲狀腺功能低下**不會骨質疏鬆**

## 構造 {#structure}

::figure{src="/knowledge-images/servier-thyroid.svg" labels="thyroid" alt="甲狀腺：左為前面觀(左右葉、峽部、錐狀葉)，右為背面觀(上下各一對副甲狀腺)"}

- **甲狀腺**：在喉部下方、氣管前方，蝴蝶形；左右兩葉、中間**峽部**(約在第 2–4 氣管環)，部分人有往上的**錐狀葉**
- **濾泡**：單層濾泡細胞圍成，腔內是**膠體**(主要成分是甲狀腺球蛋白，用來合成並儲存甲狀腺素)
- **濾泡旁細胞**(C 細胞)：散在濾泡之間，分泌**降鈣素**
- **副甲狀腺**：通常 **4 個**(上下各一對)，貼在甲狀腺**背面**；主細胞分泌 PTH
- 甲狀腺手術可能誤傷副甲狀腺(低血鈣)與**喉返神經**(聲音沙啞)，護理見 [[hyperthyroidism#thyroidectomy]]

## 甲狀腺素的合成與運送 {#synthesis}

1. **攝取碘**：濾泡細胞以鈉碘共同運輸蛋白，把血中的碘離子(I⁻)主動運進細胞
2. **氧化**：過氧化酶(TPO)把碘離子轉成碘分子(I₂)(國考把這步列為合成的第一步)
3. **碘化**：碘接到甲狀腺球蛋白上的**酪胺酸** → 單碘酪胺酸(MIT)、雙碘酪胺酸(DIT)
4. **偶合**：MIT＋DIT → **T3**；DIT＋DIT → **T4**；存在膠體中
5. **釋放**：TSH 刺激濾泡細胞吞回膠體、分解甲狀腺球蛋白，釋出 T4 與少量 T3

| | T4(甲狀腺素) | T3(三碘甲狀腺素) |
|---|---|---|
| 分泌量 | **約 90%**，是主要分泌物 | 少；大部分由周邊組織(肝、腎)把 T4 去碘轉成 |
| 活性 | 較低(可視為前驅物) | **較高** |
| 半衰期 | **較長**(約一週) | 較短(約一天) |
| 血中運輸 | 量最多，大多和**甲狀腺結合球蛋白**(TBG)結合 | 結合較少 |

- 只有**游離**的甲狀腺素有作用；T4 也可能轉成沒有活性的**逆 T3**(rT3)
- **懷孕**：雌激素讓肝臟製造的 **TBG 增加**，在**第二孕期**達高峰並維持，總 T4 上升但游離 T4 大致正常；孕期代謝率上升，甲狀腺素分泌**增加**而不是被抑制；未控制的嚴重甲亢才較易流產
- **碘**是合成原料：孕期需要增加碘攝取，以支持胎兒**腦部神經發育**；缺碘可能造成**呆小症**(克汀症)與智能發展受損

## 甲狀腺素的作用 {#actions}

| 系統 | 作用 | 不足時 | 過多時 |
|---|---|---|---|
| 代謝 | **基礎代謝率**與耗氧量上升、**產熱** | 怕冷、代謝率低 | 怕熱、多汗、體重減輕 |
| 心血管 | 增加 β 受體反應，**心跳與心輸出量增加** | 心跳慢、**心輸出量降低** | **心搏過速**、心悸 |
| 醣類與蛋白質 | 促進醣類**分解**(異化)；正常量促進蛋白質合成 | 醣類異化減少 | 蛋白質分解、肌肉無力 |
| 生長發育 | 骨骼生長、**腦部發育**(胎兒到兒童) | 兒童：**呆小症**；成人：**黏液水腫** | |
| 神經 | 反應與情緒 | 遲鈍、嗜睡 | 焦躁、震顫 |

- **寒冷**時下視丘增加 TRH → TSH → **甲狀腺素**分泌，提高代謝產熱(同時交感神經使血管收縮、顫抖)；不會增加流汗或減少代謝
- **黏液水腫**(myxedema)：成人甲狀腺激素不足，黏多醣堆積在皮下形成**非凹陷性水腫**(國考題目把「TSH」寫成甲狀腺激素，指的是甲狀腺相關荷爾蒙不足)

## 調節與檢驗的生理基礎 {#regulation}

- 下視丘 TRH → 腦下垂體 TSH → 甲狀腺 T4、T3，T3／T4 **負回饋**抑制 TRH 與 TSH(見 [[endocrine-overview#feedback]] 的圖)
- **TSH 最敏感**：甲狀腺素只要小幅改變，TSH 就會反向大幅變化，所以是篩檢甲亢與甲低的第一線檢驗；判讀表見 [[thyroid-function-tests#interpretation]]
- 依 TSH 與 T4 的方向判斷

| 狀況 | T4 | TSH | 道理 |
|---|---|---|---|
| **Graves 病**(甲狀腺刺激抗體刺激甲狀腺) | ↑ | **↓** | T3、T4 太多，負回饋抑制 TSH |
| **原發性甲狀腺功能低下**(含先天性、橋本氏甲狀腺炎) | **↓** | **↑** | 甲狀腺做不出來，負回饋解除 |
| **碘缺乏** | ↓ | **↑** | TSH 持續刺激 → **甲狀腺腫大** |
| 腦下垂體功能低下(次發性) | ↓ | ↓ | 上游不足 |

- **呆小症**是胎兒或嬰幼兒期**甲狀腺素**不足(生長激素不足是矮小症)；新生兒篩檢與治療見 [[pediatric-endocrine#congenital-hypothyroidism]]

## 鈣磷調節 {#calcium-regulation}

![血鈣調節：副甲狀腺素、降鈣素與活性維生素 D](/knowledge-images/calcium-regulation.svg)

| | 副甲狀腺素(PTH) | 降鈣素 | 活性維生素 D(骨化三醇) |
|---|---|---|---|
| 來源 | 副甲狀腺主細胞 | 甲狀腺濾泡旁細胞 | 皮膚或食物 → 肝臟 25-羥化 → **腎臟 1α-羥化** |
| 刺激分泌 | **血鈣下降** | 血鈣上升 | **PTH**、低血磷 |
| 骨 | **活化蝕骨細胞**，釋出鈣與磷 | **抑制蝕骨細胞**，鈣沉積到骨 | 促進骨礦化 |
| 腎 | **遠曲小管回收鈣 ↑**；**近曲小管回收磷 ↓**；活化維生素 D | 增加鈣排出 | 增加鈣磷回收 |
| 腸 | 間接(經維生素 D) | | **增加鈣、磷吸收** |
| 結果 | 血鈣 ↑、**血磷 ↓** | 血鈣 ↓ | 血鈣 ↑、血磷 ↑ |

- PTH 作用在腎小管細胞膜受體，經 **cAMP** 傳遞，所以尿中 cAMP 會增加
- 低血鈣主要刺激**副甲狀腺**分泌 PTH，不是下視丘或腦下垂體

### 影響骨質密度的激素 {#bone-density}

| 讓骨密度上升 | 讓骨密度下降 |
|---|---|
| **降鈣素**持續增加 | **PTH**持續增加(副甲狀腺機能亢進) |
| **活性維生素 D** 上升 | **皮質醇**過多(抑制成骨、減少腸道吸收鈣) |
| **雌激素**、**雄性素** | 甲狀腺素過多(骨代謝加快) |
| | **雌激素下降**(停經後骨質疏鬆的主因)、雄性素下降 |

- 骨鬆藥物見 [[bone-calcium-drugs]]；疾病照護留給肌肉骨骼那一輪

### 副甲狀腺功能異常 {#parathyroid-disorders}

| | 副甲狀腺功能低下 | 副甲狀腺機能亢進 |
|---|---|---|
| 血鈣、血磷 | 鈣 ↓、**磷 ↑**、尿磷 ↓ | 鈣 ↑、磷 ↓ |
| 神經肌肉 | 興奮性上升：**手足抽搐**、**喉部痙攣與喘鳴**、Chvostek 徵象、Trousseau 徵象 | 興奮性下降：肌肉無力、便秘 |
| 骨骼 | 骨密度**正常或增加**(不是骨質疏鬆) | 骨質流失、骨痛、易骨折 |
| 常見原因 | **甲狀腺或副甲狀腺手術**誤切 | 副甲狀腺腺瘤；慢性腎病(次發性) |

- 正常血鈣約 8.5–10.5 mg/dL；兒童副甲狀腺功能低下時血鈣常低於約 7 mg/dL(依題目選項)；飲食避免**高磷**食物
- **PTH 刺激試驗**：注射 PTH 後尿中 cAMP 上升 → 腎臟反應正常、問題在 PTH 分泌不足(原發性)；cAMP 不上升 → 受體沒反應(假性副甲狀腺功能低下)
- 疾病的治療與護理見 [[parathyroid-disorders]]；血鈣、血磷數值判讀見 [[calcium-phosphate]]
