**B 淋巴球**是**體液性免疫**的主角：它們辨認抗原後分化成**漿細胞**，大量分泌**抗體**到血液與體液中。T 細胞管「細胞對細胞」的戰鬥，B 細胞則是**用抗體在細胞外打仗**。這一頁依序說明 B 細胞的發育、活化的兩條路、生發中心裡的調整，以及初次與二次反應

## 重點摘要 {#summary}

- B 細胞在**骨髓**發育成熟；表面的 **BCR**（膜型抗體＋CD79）辨認抗原；活化後變成**漿細胞**（分泌抗體）與**記憶 B 細胞**
- **T 依賴**（蛋白質抗原）：需要 **Tfh** 的 **CD40L–CD40** 與 **IL-4／IL-21**，才能**類別轉換**與**親和力成熟**，並產生記憶
- **T 非依賴**（莢膜多醣、LPS）：不需要 T 細胞、反應快，但**以 IgM 為主、記憶差**，嬰幼兒反應不佳 → **結合型疫苗**
- **初次反應**：潛伏期長、**IgM 先出現**；**二次反應**：快、**IgG 為主**、濃度高、親和力高
- **體液性免疫對付胞外病原與毒素**；**細胞性免疫**（T 細胞）對付細胞內病原與腫瘤

### 國考常考點 {#exam-points}

- 初次免疫反應**最先出現 IgM**；之後轉換成 **IgG**；多次接種疫苗後反應**更快、抗體濃度更高、親和力更高**，以 **IgG** 為主
- **類別轉換**(IgM → IgG)需要 **T 細胞**；**莢膜多醣**可**快速產生抗體反應而不需要 T 細胞**
- **體細胞超突變**負責**親和力成熟**，主要酵素是 **AID**，不是 RAG1／RAG2、TdT（那些是 V(D)J 重組用）
- **XLA（Bruton 病）**：**BTK 基因**缺陷，**pre-B 細胞無法分化成 B 細胞**，幾乎都是**男性**，血清**各類抗體極低**
- **B 細胞也是 APC**，可以呈現抗原給 T 細胞，不是「不能」
- **淋巴結濾泡**聚集的 B 細胞（生發中心）製造**抗體**
- **主動免疫**：自己產生抗體或淋巴球（接種疫苗、感染後）；**被動免疫**：直接得到抗體（胎盤 IgG、母乳、免疫球蛋白注射）
- **漿細胞**是抗體工廠；多發性骨髓瘤是漿細胞惡性增生，**免疫球蛋白輕鏈**可沉積成**類澱粉**
- **CD20** 是 B 細胞標記，是 rituximab 的標的

## B 細胞的發育 {#development}

### 骨髓內的階段 {#bone-marrow}

1. **前驅 B 細胞(pro-B)**：開始重組**重鏈基因**（V(D)J 重組，**RAG1／RAG2**、TdT 參與）
2. **pre-B 細胞**：重鏈（μ 鏈）與替代輕鏈組成 **pre-BCR**，通過後才繼續；接著重組**輕鏈**（κ 或 λ）
3. **未成熟 B 細胞**：表面出現完整的 **IgM(BCR)**
4. **中樞耐受**：此時若 BCR 對**自身抗原**反應太強，會**受體編輯**（重新重組輕鏈）或**凋亡**
5. 通過後離開骨髓，到周邊（脾臟、淋巴結）成熟為 **naive B 細胞**，表面同時有 **IgM 與 IgD**，等待抗原

:::basics[為什麼 XLA 的男孩 6 個月後才發病]
**BTK（Bruton 酪胺酸激酶）**基因位於 **X 染色體**，pre-B 細胞傳訊需要它。缺陷時 B 細胞卡在 **pre-B** 階段，外周血幾乎沒有成熟 B 細胞與漿細胞，**所有類別的抗體都低**。新生兒靠**母體 IgG** 保護，約 **3–6 個月**後母體抗體消退，才開始反覆**細菌感染**（中耳炎、鼻竇炎、肺炎，常見**有莢膜的細菌**如肺炎鏈球菌、流感嗜血桿菌）。治療是定期**免疫球蛋白補充治療**，細節見 [[primary-immunodeficiency]]

來源：UpToDate：Primary humoral immunodeficiencies：An overview
:::

### 重要的 B 細胞表面分子 {#b-markers}

| 分子 | 說明 |
|---|---|
| **BCR（膜型 Ig）＋Igα／Igβ(CD79a／b)** | 抗原辨識與傳訊 |
| **CD19、CD21(CR2)、CD81** | **共受體複合體**，增強活化；CD21 也是 **C3d** 與 **EBV** 的受體 |
| **CD20** | B 細胞標記（成熟期），**漿細胞沒有**；**rituximab** 的標的 |
| **MHC II** | 使 B 細胞能當 APC，呈現抗原給 Tfh |
| **CD40** | 結合 T 細胞的 **CD40L**，T 依賴活化必要 |

## B 細胞的活化 {#activation}

### T 依賴活化（蛋白質抗原） {#t-dependent}

1. B 細胞用 **BCR** 專一結合抗原，內吞後切成胜肽，放在 **MHC II** 上
2. 在淋巴結 T–B 交界，**Tfh** 辨認 MHC II＋胜肽，提供 **CD40L–CD40** 與細胞激素（**IL-4、IL-21**）
3. B 細胞開始增殖，一部分很快變成**短命的漿細胞**，分泌**低親和力 IgM**（早期反應）
4. 另一部分進入**濾泡**，形成**生發中心**，在此進行類別轉換與親和力成熟

### 生發中心 {#germinal-center}

1. **暗區**：B 細胞（中心母細胞）快速增殖，同時發生
   1. **體細胞超突變**：抗體可變區基因點突變，產生親和力不同的變異株（需 **AID** 酵素）
   2. **類別轉換**：恆定區換成 IgG、IgA 或 IgE，**抗原特異性不變**（也需要 AID）
2. **明區**：B 細胞（中心細胞）與抗原競爭，由**濾泡樹突細胞**呈現抗原、**Tfh** 提供訊號
   1. 親和力**高**的存活
   2. 親和力**低**的凋亡，這就是**親和力成熟**
3. 最後分化成 **長壽漿細胞**（主要回到**骨髓**，持續分泌抗體）與**記憶 B 細胞**
4. **CD40L 缺陷** → 無法類別轉換 → **高 IgM 症候群**：IgM 正常或高、IgG／IgA／IgE 低

### 類別轉換由細胞激素決定 {#class-switching}

| 細胞激素（來源） | 轉換成 | 意義 |
|---|---|---|
| **IL-4**(Th2) | **IgE**、IgG4 | **過敏與寄生蟲** |
| **IFN-γ**(Th1) | **IgG**（促進調理與補體活化的次類別） | 細胞內與病毒感染 |
| **TGF-β**（＋IL-5、IL-21 等） | **IgA** | **黏膜免疫** |

### T 非依賴活化 {#t-independent}

| | **TI-1** | **TI-2** |
|---|---|---|
| 抗原 | **LPS** 等微生物成分 | **重複的多醣**（肺炎鏈球菌、腦膜炎雙球菌、流感嗜血桿菌的**莢膜**） |
| 機轉 | 直接活化 B 細胞（多株） | **交聯**多個 BCR |
| 結果 | 非特異的多株抗體 | 抗原特異的 **IgM** |
| 特點 | — | **快**；**不類別轉換、無親和力成熟、記憶差**；**嬰幼兒（約 2 歲前）反應不佳**；**脾臟邊緣區 B 細胞**重要 |

1. **脾臟切除者**對莢膜細菌特別容易敗血症，需要接種對應疫苗
2. **結合型疫苗**（把多醣接在**蛋白質載體**上，例如 Hib、結合型肺炎鏈球菌、腦膜炎雙球菌）讓這些抗原變成 **T 依賴**，嬰幼兒也能產生 IgG 與記憶（[[immunization#vaccine-types]]）
3. 未結合的多醣疫苗（例如 23 價肺炎鏈球菌多醣疫苗）對 2 歲以下效果差

## 初次與二次免疫反應 {#primary-secondary}

| | **初次反應** | **二次（回憶）反應** |
|---|---|---|
| 反應細胞 | naive B 細胞 | **記憶 B 細胞** |
| 潛伏期 | **長**（約 1 週以上才偵測到） | **短**（約 1–3 天） |
| 抗體類別 | **IgM 先出現**，之後 IgG | **IgG 為主** |
| 抗體濃度 | 低 | **高**（可達初次的數十倍） |
| 親和力 | 低 | **高**（已親和力成熟） |
| 持續時間 | 短 | **長** |

1. 這是**追加劑(booster)**的原理：第二、三劑使抗體濃度更高、更持久
2. **IgM** 有半衰期短（約 5 天）的特性，所以血中**只有 IgM 升高**常表示**近期感染**；**IgG 升高而 IgM 不高**代表過去感染或接種
3. 新生兒臍帶血 **IgM 升高** = 子宮內感染（[[immune-system-basics#newborn]]）
4. 以上時間為教科書常見的大約值，不同抗原與個體有差異（屬「標示為教科書常見值」，非單一指引數字）

## 體液性與細胞性免疫的比較 {#humoral-vs-cellular}

| | **體液性免疫** | **細胞性免疫** |
|---|---|---|
| 主角 | **B 細胞、漿細胞、抗體** | **T 細胞**（CD4 與 CD8） |
| 辨認方式 | BCR／抗體**直接**辨認完整抗原（蛋白、多醣、脂質） | TCR 辨認 **MHC 呈現的胜肽**，**必須經 MHC** |
| 作用位置 | **細胞外**（血液、體液、黏膜） | **細胞內**感染、腫瘤、移植 |
| 對付 | **胞外細菌、毒素、病毒（進入細胞前）** | **病毒感染細胞、細胞內菌、真菌、原蟲、腫瘤** |
| 機轉 | 中和、**調理**、**活化補體**、ADCC、肥大細胞去顆粒 | **CTL 殺細胞**、**Th1 活化巨噬細胞** |
| 可被動轉移 | 能（輸注血清或免疫球蛋白） | 較難（需移植細胞） |
| 缺陷的表現 | **胞外化膿菌**反覆感染 | **病毒、真菌、細胞內菌**，嚴重 |
| 例子 | XLA、選擇性 IgA 缺乏 | DiGeorge、HIV |
| 過敏類型 | 第一、二、三型 | 第四型 |

1. **抗體不能進入細胞內**，所以**抗體不能中和已在細胞內的病毒**；病毒進入細胞後要靠 **CD8 T 細胞**、NK 細胞與干擾素
2. **病毒感染後**：抗體可**阻止病毒擴散與再感染**（中和），但**不能阻止已發生的感染進展**；真正控制病情的主要是 **CD8 T 細胞**
3. **兩者合作**：Tfh 幫 B 細胞；Th1 提供 IFN-γ 讓 B 細胞轉換 IgG；NK 細胞以抗體的 **Fc 受體(CD16)** 做 ADCC
4. **T 細胞需要 MHC**，B 細胞辨認抗原**不需要 MHC**；形成細胞性免疫反應所需的時間**比體液性免疫長**（108-1_MS 國考說法）

## B 細胞的臨床連結 {#clinical}

1. **XLA、普通變異型免疫缺乏、選擇性 IgA 缺乏**等體液性缺陷：見 [[primary-immunodeficiency]]
2. **B 細胞腫瘤**：多發性骨髓瘤（漿細胞），**輕鏈沉積**形成類澱粉（[[lymphoma-myeloma#myeloma]]）；胃的 **MALT 淋巴瘤**為 B 細胞，與**幽門螺旋桿菌**慢性胃炎有關，早期**根除 H. pylori** 即可治療
3. **B 細胞抗體製造異常**：自體抗體（SLE、第二型與第三型過敏）見 [[hypersensitivity-reactions]]
4. **抗 CD20 單株抗體(rituximab)**清除 B 細胞，用於淋巴瘤與自體免疫病，詳見 [[monoclonal-antibodies]]
5. 抗體的結構、五類 Ig 與血型：見 [[immunoglobulins-hla]]
