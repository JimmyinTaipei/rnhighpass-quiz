血糖(血漿葡萄糖)空腹時維持在約 **70–99 mg/dL**,飯後一般不超過 140 mg/dL。腦部幾乎只能用葡萄糖當能量,所以身體有多重機制防止血糖過低;而**降血糖的激素只有胰島素一種**。

每一段最後的「**藥物對應**」說明哪一類降血糖藥是在放大或阻斷這個機制。

## 胰臟內分泌細胞 {#islets}

胰島(蘭氏小島,islets of Langerhans)約占胰臟 1–2%,主要細胞:

| 細胞 | 比例 | 分泌 | 作用 |
|---|---|---|---|
| β 細胞 | 約 60–70% | **胰島素**、C-胜肽、胰澱素(amylin) | 降血糖 |
| α 細胞 | 約 20–30% | **升糖素** | 升血糖 |
| δ 細胞 | 約 5–10% | 體制素(somatostatin) | 抑制胰島素與升糖素 |
| PP 細胞 | 少量 | 胰多胜肽 | 調節胰臟外分泌、食慾 |

胰臟的腫瘤會以分泌的激素命名:**胰島素瘤**(insulinoma)造成反覆低血糖、嗜睡、意識混亂,切除後症狀消失;升糖素瘤造成高血糖與皮疹。

## 胰島素的分泌 {#insulin-secretion}

### 葡萄糖刺激 β 細胞分泌胰島素 {#secretion-steps}

![β 細胞分泌胰島素的步驟與藥物作用點](/knowledge-images/insulin-secretion-pd.svg)

1. 葡萄糖經 **GLUT2** 進入 β 細胞(GLUT2 親和力低,只有血糖高時才大量進入,因此是「血糖感測器」)。
2. **葡萄糖激酶**磷酸化 → 糖解與氧化磷酸化 → **ATP 上升**。
3. ATP 使 **ATP 敏感性鉀通道(K-ATP)關閉** → 鉀留在細胞內 → **細胞膜去極化**。
4. **電位控制型鈣通道**打開 → Ca²⁺ 流入。
5. 細胞內 Ca²⁺ 上升 → 含胰島素的囊泡**胞吐**。

胰島素分泌呈**雙相**:第一相在數分鐘內釋放儲存的胰島素,第二相持續較久;第二型糖尿病早期即喪失第一相。

**藥物對應**:[[sulfonylureas|磺醯脲類]]與 [[meglitinides|Meglitinide]] 結合 K-ATP 通道上的 SUR1 次單位,**直接關閉**通道——跳過了「血糖高才分泌」的步驟,所以血糖不高時也會分泌 → 低血糖。

### 影響分泌的因素 {#secretion-regulators}

| 增加分泌 | 減少分泌 |
|---|---|
| 血糖上升(最主要) | 血糖下降 |
| 胺基酸(如精胺酸)、脂肪酸 | 體制素 |
| **腸泌素**(GLP-1、GIP) | 交感神經(α₂ 受體)、腎上腺素 |
| 副交感神經(迷走神經) | 禁食、運動 |
| 升糖素(旁分泌) | |

高蛋白、低醣的一餐會同時刺激**胰島素與升糖素**分泌,兩者作用抵銷,因此不會發生低血糖。

### 腸泌素效應 {#incretin}

**口服**葡萄糖引起的胰島素分泌,比**靜脈注射**同樣血糖值時多出 50–70%,差別來自腸道分泌的**腸泌素**:

- **GLP-1**(類升糖素胜肽-1,迴腸與結腸的 **L 細胞**)與 **GIP**(十二指腸的 K 細胞)。
- 食物還在腸道、血糖尚未上升時就先通知胰臟準備——屬於**前饋(feedforward)調節**。
- GLP-1 的作用是**葡萄糖依賴性**:只在血糖高時促進胰島素分泌,同時抑制升糖素、延緩胃排空、增加飽足感。
- 血中的 GLP-1 在數分鐘內被 **DPP-4 酵素**分解。

![腸泌素、DPP-4 與相關藥物](/knowledge-images/incretin-dpp4.svg)

**藥物對應**:[[dpp4-inhibitors|DPP-4 抑制劑]]讓自身 GLP-1 不被分解;[[glp1-receptor-agonists|GLP-1 受體促效劑]]是不會被 DPP-4 分解的 GLP-1 類似物。

## 胰島素的作用 {#insulin-action}

### GLUT4 與葡萄糖攝取 {#glut4}

![胰島素促進 GLUT4 轉位與葡萄糖代謝](/knowledge-images/insulin-glut4-pd.svg)

- 胰島素與細胞膜上的**胰島素受體**(酪胺酸激酶受體)結合 → 細胞內訊息(IRS → PI3K → Akt)→ 儲存在細胞內囊泡的 **GLUT4 轉位到細胞膜** → 葡萄糖進入細胞。
- GLUT4 只存在**骨骼肌、心肌與脂肪組織**,是唯一「**需要胰島素**」的葡萄糖轉運蛋白,所以飯後血糖主要由肌肉吸收。
- **胰島素阻抗**:受體數目減少或受體後訊息傳遞變差,GLUT4 上膜不足 → 第二型糖尿病的核心缺陷。
- **運動**收縮肌肉時,可經 AMPK 讓 GLUT4 **不靠胰島素**轉位 → 運動能降血糖、增加胰島素敏感性。
- **藥物對應**:[[tzd|TZD]] 活化 PPAR-γ 增加胰島素敏感性;[[metformin]] 活化 AMPK。

### 各器官的作用 {#insulin-organs}

| 器官 | 胰島素的作用 | 結果 |
|---|---|---|
| 肝臟 | ↑肝醣合成;**↓肝醣分解、↓糖質新生** | 減少肝臟釋出葡萄糖 |
| 肌肉 | ↑GLUT4 攝取葡萄糖、↑肝醣合成、↑蛋白質合成 | 血糖下降、合成作用 |
| 脂肪 | ↑葡萄糖攝取、↑三酸甘油酯合成;**抑制荷爾蒙敏感性脂解酶** | 抑制脂肪分解 → 不產生酮體 |
| 全身細胞 | 活化 Na⁺/K⁺-ATPase | **鉀移入細胞** → 可用於治療高血鉀(胰島素 + 葡萄糖) |

腦細胞、紅血球、肝臟、腎臟攝取葡萄糖**不需要胰島素**(使用 GLUT1、GLUT2、GLUT3)。

### 葡萄糖轉運蛋白比較 {#glucose-transporters}

| 轉運蛋白 | 分布 | 特色 |
|---|---|---|
| GLUT1 | 紅血球、血腦障壁 | 基礎攝取,不需胰島素 |
| GLUT2 | 肝臟、β 細胞、腸道與腎小管基底側 | 低親和力、雙向;β 細胞的血糖感測器 |
| GLUT3 | 神經元 | 高親和力,確保腦部供應 |
| **GLUT4** | 骨骼肌、心肌、脂肪 | **受胰島素調控** |
| GLUT5 | 小腸 | 吸收果糖 |
| SGLT1 | 小腸、腎小管 S3 段 | 與 Na⁺ 共同運輸;吸收葡萄糖/半乳糖 |
| **SGLT2** | 腎近曲小管 S1–S2 段 | 回收約 90% 過濾的葡萄糖 |

### 胰島素缺乏時 {#insulin-deficiency}

胰島素缺乏(如 β 細胞被破壞)會造成:

- 血糖上升 → 血漿**滲透壓上升**、滲透性利尿
- 脂肪分解 → 血漿**游離脂肪酸增加** → 酮體生成
- 肌肉蛋白質分解 → 血漿**胺基酸增加**(被送去肝臟做糖質新生)
- 升糖素失去抑制 → **升糖素增加**

這些正是 [[diabetes#dka|糖尿病酮酸中毒]]的來源。

## 升血糖的機制 {#counter-regulation}

### 反調節激素 {#counter-hormones}

| 激素 | 主要作用 | 臨床意義 |
|---|---|---|
| **升糖素** | 肝醣分解、糖質新生、生酮 | 低血糖急救(1 mg 肌肉/皮下注射) |
| **腎上腺素** | 肝醣分解、抑制胰島素分泌 | 低血糖時的冒汗、心悸、手抖來源;壓力性高血糖 |
| **皮質醇** | **糖質新生**、降低周邊葡萄糖利用 | 長期使用**類固醇**的副作用:高血糖;重症壓力性高血糖 |
| **生長激素** | 糖質新生;**減少胰島素受體數目**、拮抗胰島素 | 黎明現象;肢端肥大症可合併糖尿病 |
| 甲狀腺素 | 增加腸道吸收與肝臟產糖 | 甲狀腺機能亢進使血糖上升 |
| 人類胎盤泌乳素 | 拮抗胰島素 | [[diabetes#gdm\|妊娠糖尿病]]的主因 |

**醛固酮**、抑制素對血糖幾乎沒有影響。

### 肝臟的產糖 {#hepatic-glucose}

- **肝醣分解**:空腹前約 12–24 小時的主要來源。
- **糖質新生**:以乳酸、胺基酸(丙胺酸)、甘油為原料合成葡萄糖;長時間禁食或壓力時是主要來源。第二型糖尿病空腹高血糖主要來自肝臟產糖過多。
- **藥物對應**:[[metformin]] 主要是**減少肝臟糖質新生**,所以特別能降低空腹血糖。
- 酒精會抑制糖質新生 → 空腹喝酒易低血糖。

### 腎臟的葡萄糖回收 {#renal-glucose}

- 腎絲球每天過濾約 180 g 葡萄糖,正常幾乎全部在近曲小管回收(SGLT2 約 90%、SGLT1 約 10%)。
- 回收有上限(**最大運輸速率 Tm**);血糖超過約 **180 mg/dL(腎閾值)** 時,過濾量超過回收能力 → **尿糖** → 帶走水分(滲透性利尿)。
- 懷孕時腎閾值下降,可能出現尿糖但血糖正常。
- **藥物對應**:[[sglt2-inhibitors|SGLT2 抑制劑]]刻意阻斷回收,把腎閾值降到約 40–120 mg/dL,讓葡萄糖從尿液排出。
