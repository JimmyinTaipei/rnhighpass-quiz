肌肉組織負責運動、維持姿勢、產熱，以及推動血液與內臟內容物。本頁整理三種肌肉組織、骨骼肌的構造與肌節、收縮機轉與能量來源、快慢肌、收縮型態，以及國考常考的主要骨骼肌；神經肌肉接合處與終板電位見 [[neuron-synapse#neuromuscular-junction]]，心肌的收縮力與 Frank-Starling 見 [[cardiac-output#myocyte]]，等長與等張運動的護理應用見 [[activity-immobility#isometric-isotonic]]

## 重點摘要 {#summary}

- 三種肌肉：**骨骼肌**（橫紋、多核、隨意）、**心肌**（橫紋、**間盤**、不隨意）、**平滑肌**（無橫紋、單核、不隨意）；**有橫紋的是骨骼肌與心肌**
- 肌肉收縮產生**大量體熱**（顫抖產熱），是體溫的主要來源
- 結構層級：肌肉 → 肌束 → **肌纖維**（一個肌細胞） → **肌原纖維** → **肌絲**（粗：肌凝蛋白；細：肌動蛋白）
- **肌節**＝相鄰兩條 **Z 線**之間，是收縮的基本單位
- **滑動肌絲學說**：**肌動蛋白與肌凝蛋白**交互作用；收縮時 **I 帶與 H 區變短**，**A 帶長度不變**
- 骨骼肌興奮收縮耦合：動作電位沿 **T 小管** → **肌漿網**經 **ryanodine 受體**釋放鈣 → 鈣結合**旋轉素 C** → 旋轉肌凝素移開 → 橫橋形成
- **ATP 結合肌凝蛋白**，讓橫橋與肌動蛋白**分離**；死後缺 ATP → 橫橋分不開 → **屍僵**
- 能量：**磷酸肌酸**最快（數秒）→ 無氧糖解（用**葡萄糖**、產乳酸）→ 有氧呼吸（最持久）
- 慢肌（紅肌）：**粒線體、肌紅素、微血管多**；快肌（白肌）：**肝醣多**、直徑較粗、易疲勞
- 骨骼肌受損靠**衛星細胞**修補；心肌幾乎不能再生

### 國考常考點 {#exam-points}

- **逼尿肌**是平滑肌；橫膈、上咽縮肌、肛門外括約肌是骨骼肌
- 直徑由大到小：**肌原纖維** > 微小管 > 中間絲 > 微絲
- 肌原纖維由**肌絲**組成（題目寫「由肌絲組成」為正確）；儲存鈣的是肌漿網，不是肌原纖維
- 胸大肌的肌束排列是**會聚式**（扇形）
- 收縮最初數毫秒到數秒的主要能量是**磷酸肌酸**；長時間活動後磷酸肌酸被**用完**，不是堆積的代謝物（乳酸、ADP、自由基才會增加）
- 無氧呼吸主要能量來源是**葡萄糖**（乳酸是產物）
- 鈣離子主要來自**肌漿網**，經 **ryanodine 受體**釋放；骨骼肌的鈣結合**旋轉素**，平滑肌的鈣結合**攜鈣素**
- 力擊之後，肌凝蛋白結合 **ATP** → 橫橋與肌動蛋白**分離**
- 屍僵是因為**缺乏 ATP**，不是乳酸堆積或缺鈣
- 手舉椅子靜止不動＝**等長收縮**（肌肉長度不變、張力增加）
- 心肌：鈣由細胞外少量流入，**誘發肌漿網釋放更多鈣**（流入量**小於**肌漿網釋放量）；**不反應期幾乎和收縮期一樣長**，所以不會加成、不會強直收縮
- 骨骼肌和心肌**都有 T 小管**；**間盤**是心肌特有
- 膕旁肌（股二頭肌、半腱肌、半膜肌）伸髖屈膝；**股薄肌**屬內收肌群，作用不同
- 經**跟腱**附著跟骨的是**腓腸肌**（與比目魚肌）
- **股三角**：上界腹股溝韌帶、**外側縫匠肌**、內側內收長肌
- 屈髖最主要是**股直肌**（與髂腰肌）；股四頭肌中只有股直肌跨過髖關節
- **三角肌**前部屈肩、後部伸肩、中部外展；**肱三頭肌**伸肘；**胸大肌**使上臂**內收、內旋**
- **旋轉肌袖**＝棘上肌、**棘下肌**、小圓肌、肩胛下肌（大圓肌、三角肌不是）
- 附著肱骨**內上髁**的是前臂**屈肌**群（例：橈側腕屈肌）；外上髁是伸肌群
- **胸大肌不附著肩胛骨**；斜方肌、前鋸肌、肱二頭肌都附著肩胛骨
- 張口（下拉下頜）的是**翼外肌**；閉口的是嚼肌、顳肌、翼內肌；臉頰穿刺傷後無法張嘴 → 傷到翼外肌
- **頸闊肌**是顏面表情肌；嚼肌、顳肌是咀嚼肌，頦舌肌是舌肌
- 骨盆膈主要是**提肛肌**，支撐子宮；凱格爾運動訓練的就是提肛肌
- 維持背部直立最重要的是**豎脊肌**

## 三種肌肉組織 {#muscle-types}

| | **骨骼肌** | **心肌** | **平滑肌** |
|---|---|---|---|
| 位置 | 附著骨骼；舌、咽上部、**橫膈**、肛門外括約肌 | 心臟 | 血管、內臟、**膀胱逼尿肌**、子宮、虹膜 |
| 外觀 | **橫紋**、長圓柱 | **橫紋**、分支 | **無橫紋**、梭形 |
| 細胞核 | **多核**、在周邊 | 1–2 個、在中央 | 單核、在中央 |
| 控制 | **隨意**（體神經） | 不隨意（自律神經、節律細胞） | 不隨意（自律神經、激素） |
| 特殊構造 | T 小管發達 | **間盤**（含間隙接合，同步收縮） | 緻密體；單一單位平滑肌有間隙接合 |
| 鈣的結合對象 | **旋轉素 C** | 旋轉素 C | **攜鈣素** |
| 再生 | **衛星細胞**可修補 | 幾乎不能，壞死後變疤痕 | 可分裂再生 |

- 電性突觸（間隙接合）存在於心肌、平滑肌、部分神經細胞，**骨骼肌沒有**（每條纖維都靠運動神經支配）
- 肌肉的功能：運動、維持姿勢、穩定關節、**產熱**（約占體熱大部分，冷時顫抖）、推動血液與淋巴回流

## 骨骼肌的構造 {#structure}

### 由大到小 {#hierarchy}

1. 整條**肌肉**：外包肌外膜，兩端以**肌腱**接骨
2. **肌束**：一束肌纖維，外包肌束膜；排列方式決定力量與活動範圍
   1. 平行（縫匠肌）、梭形（肱二頭肌）
   2. **會聚式**（扇形，**胸大肌**、顳肌）
   3. 羽狀（股直肌、三角肌）：纖維多、力量大
   4. 環狀（口輪匝肌、括約肌）
3. **肌纖維**：一個多核長細胞；細胞膜叫肌膜，向內凹成 **T 小管**；細胞內有**肌漿網**（儲存鈣）
4. **肌原纖維**：一條條排在肌纖維內，由重複的肌節組成
5. **肌絲**：粗肌絲（**肌凝蛋白**，頭部有 ATP 酶）與細肌絲（**肌動蛋白**＋旋轉肌凝素＋旋轉素）
- 依直徑：肌纖維 > **肌原纖維**（約 1–2 μm） > 細胞骨架的微小管 > 中間絲 > 微絲

### 肌節 {#sarcomere}

| 區域 | 內容 | 收縮時 |
|---|---|---|
| **Z 線** | 細肌絲固定處；**相鄰兩條 Z 線之間＝一個肌節** | 互相靠近 |
| **I 帶**（明帶） | 只有細肌絲 | **變短** |
| **A 帶**（暗帶） | 粗肌絲的全長（含與細肌絲重疊處） | **不變** |
| **H 區** | A 帶中央只有粗肌絲的部分 | **變短**（可消失） |
| M 線 | 粗肌絲中央固定處 | 不變 |

- 肌絲本身長度不變，只是**互相滑動**重疊更多（滑動肌絲學說）
- 骨骼肌受傷後由肌纖維旁的**衛星細胞**（肌肉幹細胞）增生修補；纖維芽細胞形成的是疤痕

## 收縮機轉 {#contraction}

### 興奮收縮耦合 {#excitation-contraction}

1. 運動神經末梢釋放**乙醯膽鹼** → 終板電位 → 肌膜產生動作電位（神經肌肉接合處、重症肌無力、肉毒桿菌毒素見 [[neuron-synapse#neuromuscular-junction]]）
2. 動作電位沿 **T 小管**深入肌纖維
3. T 小管上的電壓感應器（DHP 受體）拉開**肌漿網**上的 **ryanodine 受體** → 鈣釋放到肌漿（IP₃ 受體主要用在平滑肌）
4. **鈣結合旋轉素 C** → 旋轉肌凝素移開，露出肌動蛋白上的結合位
5. 肌凝蛋白頭部結合肌動蛋白形成**橫橋** → **力擊**（把細肌絲往中央拉）
6. **ATP 結合肌凝蛋白頭部** → 橫橋**分離**；ATP 水解後頭部再「上膛」，重複循環
7. 刺激停止 → 鈣被**鈣幫浦（需要 ATP）**送回肌漿網 → 旋轉肌凝素再蓋住結合位 → 舒張
- 參與骨骼肌收縮的蛋白：肌凝蛋白、肌動蛋白、旋轉素、旋轉肌凝素；**攜鈣素不參與骨骼肌**（是平滑肌的）

:::exam
屍僵：死後 ATP 耗盡，肌凝蛋白無法和肌動蛋白分離，肌肉停在收縮狀態；約死後 2–6 小時出現，由小肌肉、頭頸部開始（見 [[end-of-life-care]]）；不是乳酸堆積、不是缺鈣、也不是血液凝固
:::

### 能量來源 {#energy}

| 來源 | 速度與持續時間 | 說明 |
|---|---|---|
| 肌肉內現有 ATP | 立即，約 2–3 秒 | 存量很少 |
| **磷酸肌酸** | **最快補充 ATP**，約 10–15 秒 | 磷酸肌酸＋ADP → 肌酸＋ATP；短跑、舉重的起步 |
| **無氧糖解** | 快，約 30 秒到 2 分鐘 | 用**葡萄糖**（來自肝醣）→ 丙酮酸 → **乳酸**；1 分子葡萄糖只產 2 ATP |
| 有氧呼吸 | 慢但最持久 | 粒線體氧化葡萄糖、脂肪酸；需要氧（**肌紅素**儲氧） |

- 肌肉疲勞：長時間活動後**磷酸肌酸與肝醣耗盡**，乳酸、ADP、無機磷、**氧化自由基**堆積；肌酸代謝成**肌酸酐**由腎排出（見 [[renal-function-tests]]）
- 運動後要多吸的氧氣叫「氧債」，用來補回磷酸肌酸、氧化乳酸

::questions{ids="114-3_BM_012,108-1_BM_018,111-1_BM_018,112-2_BM_011"}

### 快肌與慢肌 {#fiber-types}

| | **慢肌（紅肌、第 I 型）** | **快肌（白肌、第 II 型）** |
|---|---|---|
| 收縮 | 慢、持久、不易疲勞 | 快、有力、**易疲勞** |
| 代謝 | **有氧** | **無氧糖解** |
| **粒線體** | **多** | 少 |
| **肌紅素** | **多**（所以紅） | 少 |
| 微血管 | 多 | 少 |
| **肝醣** | 少 | **多** |
| 纖維直徑 | **細** | 粗 |
| 例子 | 維持姿勢的肌肉（比目魚肌、豎脊肌）、馬拉松 | 眼外肌、短跑、舉重 |

- 紅肌的紅色來自**肌紅素**，不是血紅素

::questions{ids="111-2_BM_011,105-2_BM_018"}

### 收縮的種類 {#contraction-types}

| 種類 | 肌肉長度 | 張力 | 例子 |
|---|---|---|---|
| **等長收縮** | **不變** | 增加 | **手舉椅子不動**、上石膏肢體的肌肉固定運動、股四頭肌下壓床面 |
| 等張—**向心收縮** | 變短 | 大致不變 | 舉起啞鈴 |
| 等張—**離心收縮** | 變長 | 大致不變 | 慢慢放下啞鈴、下樓梯 |

- 單一刺激 → **單收縮**；刺激頻率增加 → **加成**；頻率夠快 → **強直收縮**（骨骼肌才會）
- 力量大小靠**動員更多運動單位**與提高刺激頻率
- 等長、等張運動的護理應用（上石膏做等長、關節炎做等張）見 [[activity-immobility#isometric-isotonic]]

::questions{ids="115-1_BM_002,114-2_FA_031,110-1_FA_046,108-2_FA_047"}

## 心肌與平滑肌 {#cardiac-smooth}

### 心肌 {#cardiac}

- 動作電位沿 **T 小管**傳入（骨骼肌和心肌都有 T 小管）
- **鈣誘發鈣釋放**：平台期細胞外鈣經 L 型鈣通道**少量流入** → 觸發肌漿網釋放**大量**鈣；所以細胞外流入的鈣**小於**肌漿網釋放的量
- **不反應期很長**，幾乎和整個收縮期重疊 → 心肌**不會加成、不會強直收縮**，確保每次收縮後都能舒張充血
- **間盤**連接相鄰心肌細胞，含橋粒（機械連接）與**間隙接合**（電流快速傳遞，讓心房或心室一起收縮）
- 心肌的張力和**起始長度**有關(Frank-Starling)；單一骨骼肌纖維則在最適長度時張力最大
- 心肌收縮力與心輸出量見 [[cardiac-output#myocyte]]

::questions{ids="114-1_BM_001,110-1_BM_019,110-2_BM_017,109-2_BM_018"}

### 平滑肌 {#smooth}

- 沒有肌節、沒有旋轉素；粗細肌絲斜向排列，附著在**緻密體**
- 鈣來源：**細胞外流入為主**＋肌漿網；**鈣結合攜鈣素** → 活化肌凝蛋白輕鏈激酶 → 肌凝蛋白磷酸化 → 橫橋形成
- 收縮慢、持久、耗能少；可被牽拉後仍維持張力（膀胱、子宮）
- 受自律神經、激素與局部因子調節；**乙醯膽鹼**對不同平滑肌可興奮（腸胃、膀胱）也可抑制（部分血管），消化道平滑肌收縮最主要的離子是**鈣**

::questions{ids="105-1_BM_017,113-1_BM_010,114-3_BM_020,114-2_BM_012"}

## 失調時 {#dysregulation}

- 重症肌無力、肉毒桿菌中毒：[[neuromuscular-demyelinating]]；裘馨氏肌失養症、脊髓性肌肉萎縮症：[[single-gene-disorders]]
- 廢用性肌肉萎縮與臥床：[[activity-immobility#immobility-effects]]；細胞萎縮：[[cell-injury-adaptation]]
- 腔室症候群（肌肉腔隙壓力升高）：[[fractures#compartment-syndrome]]
- 皮肌炎：[[pediatric-musculoskeletal#dermatomyositis]]
