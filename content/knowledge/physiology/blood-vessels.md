血管把心臟打出的血送到全身再帶回來：**動脈**離開心臟、**微血管**交換物質、**靜脈**回到心臟。本頁整理血管壁構造、全身主要動脈與靜脈(國考最愛考「誰是誰的分支、誰匯入誰」)、肝門循環、中心靜脈壓，以及胎兒循環與出生後的變化；血壓與血流阻力見 [[blood-pressure-regulation#determinants]]，微血管的液體交換見 [[edema-shock#starling]]，心臟本身見 [[cardiac-output#structure]]，冠狀動脈見 [[coronary-circulation#anatomy]]

## 重點摘要 {#summary}

- 管壁三層：**內膜**(內皮)、**中膜**(平滑肌與彈性纖維)、**外膜**；**微血管只有一層內皮與基底膜，沒有平滑肌**
- **彈性動脈**＝主動脈與其大分支(緩衝心臟射血、維持舒張期血流)；**肌肉動脈**＝腎、脾、股動脈等中型動脈；**小動脈**是阻力最大、調節血壓的血管段
- 腹主動脈分支：**腹腔動脈幹(胃、肝、脾)**、腸繫膜上下動脈、**腎動脈**、**性腺動脈(卵巢、睪丸)**；下肢主要血液來自**髂外動脈 → 股動脈**；陰莖與骨盆臟器來自**髂內動脈**
- 靜脈：頸內靜脈＋鎖骨下靜脈 → **頭臂靜脈** → 上腔靜脈；**奇靜脈匯入上腔靜脈**；**肝靜脈直接匯入下腔靜脈**；左睪丸靜脈匯入**左腎靜脈**
- 胎兒循環：**臍靜脈(1 條)帶充氧血**、**臍動脈(2 條)帶缺氧血**；三個分流＝**靜脈導管**(臍靜脈 → 下腔靜脈)、**卵圓孔**(右心房 → 左心房)、**動脈導管**(肺動脈 → 主動脈)
- 出生後：肺擴張 → **肺血管阻力下降**；剪臍帶 → **全身血管阻力上升** → 左心房壓 > 右心房 → 卵圓孔關閉；**血氧分壓上升**使動脈導管收縮

### 國考常考點 {#exam-points}

- **彈性動脈是主動脈**；腎、脾、股動脈是肌肉動脈
- **微血管管壁沒有平滑肌**；血液循環中**阻力最大是小動脈**
- 腎動脈、卵巢動脈都是**腹主動脈**的直接分支；**腎臟不由腹腔動脈幹供應**
- 支氣管動脈來自**胸主動脈**；**眼球**由頸內動脈(眼動脈)供應，不是頸外動脈
- 肱動脈脈搏在**肱二頭肌內側**摸
- 頸內靜脈放導管到上腔靜脈要經過**頭臂靜脈**
- **肱靜脈是深層靜脈**(與肱動脈伴行)；頭靜脈、貴要靜脈、肘正中靜脈是上肢淺層靜脈；貴要靜脈走前臂內側、與肱靜脈合成腋靜脈
- **奇靜脈匯入上腔靜脈**，不是下腔靜脈
- 肝臟血液來自**肝動脈與肝門靜脈**；與下腔靜脈直接相連的是**肝靜脈**
- 中心靜脈壓與頸靜脈壓都反映**右心房壓力**
- 卵圓孔連通**左、右心房**；胎兒時血液由**右心房流向左心房**
- 靜脈導管連接**臍靜脈與下腔靜脈**，位於肝臟後側，出生後閉鎖成**靜脈韌帶**
- **臍靜脈**閉合成**肝圓韌帶**(臍動脈遠端成內側臍韌帶)
- 動脈導管功能性關閉的主因是出生後**血氧分壓上升**，不是肺動脈壓上升；肺擴張後**肺動脈阻力下降**
- 出生後**全身血管阻力增加、肺血管阻力降低**；兒童心臟血管含氧量最高在**肺靜脈**

## 血管的種類與構造 {#structure}

| 血管 | 管壁特色 | 功能 |
|---|---|---|
| **彈性動脈**(主動脈、肺動脈幹、頭臂動脈幹、頸總動脈等大分支) | 中膜**彈性纖維最多** | 收縮期撐開儲存能量，舒張期回彈繼續推血(緩衝壓力、讓血流連續) |
| **肌肉動脈**(分配動脈：腎、脾、股、肱、橈動脈等) | 中膜**平滑肌最多** | 依器官需要分配血流 |
| **小動脈** | 平滑肌相對很厚、管徑小 | **阻力最大**的血管段，收縮或舒張決定周邊阻力與血壓(阻力與半徑 4 次方成反比，見 [[blood-pressure-regulation#determinants]]) |
| **微血管** | **只有一層內皮細胞＋基底膜，沒有平滑肌** | 物質交換；入口有**微血管前括約肌**調節開放數量 |
| 小靜脈、靜脈 | 管壁薄、管腔大，四肢靜脈有**靜脈瓣** | 容量血管(靜息時約 2/3 血量在靜脈)；靠骨骼肌幫浦與靜脈瓣把血送回心臟 |

- 三層構造：**內膜**(內皮細胞，分泌 NO、前列腺環素、內皮素)、**中膜**(平滑肌、彈性纖維)、**外膜**(結締組織，大血管有滋養血管 vasa vasorum)
- 動脈與伴行靜脈相比：動脈中膜厚、管腔圓；靜脈中膜薄、管腔大且不規則
- 靜脈瓣功能不良 → 靜脈曲張(見 [[peripheral-vascular-disease#varicose-veins]])

## 體循環的主要動脈 {#arteries}

| 區域 | 動脈 | 供應或重點 |
|---|---|---|
| 主動脈弓三分支 | **頭臂動脈幹**(右頸總＋右鎖骨下)、**左頸總動脈**、**左鎖骨下動脈** | 右側有頭臂動脈幹，左側直接由主動脈弓發出 |
| 頭頸 | **頸外動脈** | **臉部肌肉、舌頭、牙齒**(上頜動脈)、頭皮 |
| | **頸內動脈** | 腦(參與威利氏環)、**眼球**(眼動脈) |
| 上肢 | 鎖骨下 → 腋動脈 → **肱動脈** → 橈動脈、尺動脈 | 肱動脈在**肱二頭肌內側**、肘窩可摸到(量血壓位置)；脈搏位置見 [[pulse-blood-pressure]] |
| 胸部 | **胸主動脈** → **支氣管動脈**、肋間動脈、食道動脈 | 支氣管動脈營養肺組織(肺動脈負責氣體交換，見 [[respiratory-anatomy]]) |

| | 腸繫膜上動脈 | 小腸、升結腸、橫結腸前 2/3、胰頭 |
| | 腸繫膜下動脈 | 降結腸、乙狀結腸、直腸上段 |
| 腹部(成對) | **腎動脈** | 由**腹主動脈**直接發出(見 [[kidney-urinary-physiology]]) |
| | **性腺動脈**(卵巢動脈、睪丸動脈) | 由**腹主動脈**直接發出(約在腎動脈下方)；子宮動脈則來自髂內動脈 |
| 骨盆 | 腹主動脈分成左右**髂總動脈** → **髂內動脈** | 骨盆臟器、臀部、會陰；**陰部內動脈**的分支供應陰莖海綿體(勃起)；子宮動脈；胎兒的臍動脈也由此分出 |
| 下肢 | **髂外動脈** → 股動脈 → 膕動脈 → 脛前(足背)、脛後動脈 | **下肢最主要的血液來源**；心導管後摸足背動脈評估下肢循環 |

## 主要靜脈與匯流 {#veins}

| 區域 | 路徑 | 重點 |
|---|---|---|
| 頭頸 | 頸內靜脈＋鎖骨下靜脈 → **頭臂靜脈** → 兩側頭臂靜脈合成**上腔靜脈** → 右心房 | 經頸內靜脈放中心靜脈導管到上腔靜脈，會經過**頭臂靜脈**(見 [[central-venous-catheter#insertion]])；椎靜脈匯入頭臂靜脈 |
| 上肢淺層 | **頭靜脈**(外側)、**貴要靜脈**(前臂**內側**)、**肘正中靜脈**(連接兩者) | 抽血與周邊靜脈注射常用(見 [[iv-therapy]])；貴要靜脈在上臂與肱靜脈合成**腋靜脈** |
| 上肢深層 | **肱靜脈**、橈靜脈、尺靜脈 | 深層靜脈與**同名動脈伴行**(肱靜脈伴肱動脈) |
| 胸壁 | **奇靜脈** | 收集胸壁與後縱膈，匯入**上腔靜脈**；門脈高壓時是側枝循環之一 |
| 腹部 | 腎靜脈 → 下腔靜脈；**左睪丸(卵巢)靜脈 → 左腎靜脈**，右側直接入下腔靜脈 | 左側路徑較長、角度直，所以精索靜脈曲張多在左側 |
| 肝 | **肝靜脈 → 下腔靜脈** | 與下腔靜脈直接相連的是肝靜脈，不是脾靜脈或腸繫膜靜脈 |
| 下肢淺層 | **大隱靜脈**(內踝前方 → 大腿內側 → 股靜脈)、**小隱靜脈**(外踝後方 → **膕靜脈**) | 大隱靜脈常取來做冠狀動脈繞道；也是靜脈曲張好發處 |

## 肝門循環 {#portal}

- 門脈系統＝血液流經兩套微血管床：胃、腸、脾、胰的靜脈血 → 脾靜脈＋腸繫膜上靜脈 → **肝門靜脈** → 肝竇 → **肝靜脈** → 下腔靜脈
- 肝臟雙重血液供應：**肝門靜脈**(約 3/4，富含營養)＋**肝動脈**(約 1/4，富含氧)
- 門脈高壓時血液繞道：食道靜脈曲張、痔、臍周靜脈(海蛇頭)，見 [[liver-cirrhosis]]；肝的構造見 [[liver-biliary-pancreas]]

::questions{ids="107-1_BM_013"}

## 中心靜脈壓與頸靜脈壓 {#cvp}

- **中心靜脈壓(CVP)**＝上腔靜脈靠近右心房的壓力，等於**右心房壓力**，反映右心前負荷與血量；正常約 2–8 mmHg(約 3–10 cmH₂O，各書略有差異)；測量方法與零點見 [[central-venous-catheter#cvp]]
- **頸靜脈壓(JVP)**：內頸靜脈和右心房之間沒有瓣膜，頸靜脈搏動的高度可以看出右心房壓力；量法是床頭抬高約 45 度，量內頸靜脈搏動最高點到**胸骨角**的垂直距離，**超過 3–4 cm 為升高**(右心衰竭、液體過量、心包膜填塞)，見 [[heart-failure#manifestations]]
- 兩者都**不能**代表左心房、肺動脈或頸動脈的壓力；左心房壓力要看肺微血管楔壓(PCWP)

::questions{ids="105-1_MS_032"}

## 胎兒循環 {#fetal-circulation}

胎兒的肺沒有呼吸，氧氣來自**胎盤**，所以循環要繞過肝臟與肺臟。路徑(兒科課本書頁 414–416，重新整理)：

1. 胎盤(充氧血) → **臍靜脈**(1 條，**含氧最高**)
2. 臍靜脈大部分經**靜脈導管**(在肝臟後側)繞過肝臟 → **下腔靜脈**；一部分流入肝門靜脈
3. 下腔靜脈 → 右心房 → 大部分經**卵圓孔**到**左心房** → 左心室 → 主動脈 → 先供應心臟、頭部與上肢
4. 上腔靜脈的回流血 → 右心房 → 右心室 → 肺動脈幹 → 大部分經**動脈導管**直接進入**主動脈**(降主動脈)，只有少量到肺
5. 降主動脈 → 髂內動脈 → **臍動脈**(2 條，**帶缺氧血**) → 回到胎盤

| 構造 | 連接 | 胎兒時血流 | 出生後 | 留下的構造 |
|---|---|---|---|---|
| **臍靜脈** | 胎盤 → 肝與靜脈導管 | 含氧最多 | 剪臍帶後閉合 | **肝圓韌帶** |
| **靜脈導管** | **臍靜脈 → 下腔靜脈** | 繞過肝臟 | 臍靜脈血流中斷而閉合 | **靜脈韌帶** |
| **卵圓孔** | **右心房 → 左心房** | 繞過肺 | **出生後即功能性關閉**(左房壓 > 右房壓，瓣膜被壓住)；數月到數年才完全融合 | **卵圓窩** |
| **動脈導管** | **肺動脈 → 主動脈** | 繞過肺 | 出生後約 **4 天**功能性關閉、**1–3 個月**解剖性閉塞(兒科課本；國考題也有寫 2–4 天) | **動脈韌帶** |
| **臍動脈** | 髂內動脈 → 胎盤 | 缺氧血 | 出生後比臍靜脈早收縮關閉 | 遠端成**內側臍韌帶**，近端仍是上膀胱動脈 |

### 出生後的變化 {#transition}

1. 第一口呼吸、肺擴張 → **肺血管阻力下降**、肺血流增加 → 回到左心房的血變多 → **左心房壓力上升**
2. 剪斷臍帶、低阻力的胎盤消失 → **全身血管阻力上升**、左心室與主動脈壓力上升；下腔靜脈回流減少 → **右心房壓力下降**
3. **左心房壓 > 右心房壓** → 卵圓孔的瓣膜被推向中膈而關閉
4. **血氧分壓上升**(加上胎盤來的前列腺素減少) → 動脈導管平滑肌收縮 → 功能性關閉
5. 結果：肺循環與體循環分開，**肺靜脈**變成含氧最高的血管；動脈導管若沒關 → 開放性動脈導管(見 [[congenital-heart-disease#left-to-right]])

:::exam[國考重點]
- 動脈導管關閉的主因是**血氧分壓上升**；「肺動脈壓上升導致動脈導管關閉」是錯的(出生後肺動脈壓是**下降**)
- 卵圓孔關閉是因為**左心房壓力大於右心房**；「右心房壓力高於左心房」是錯的
- 形成肝圓韌帶的是**臍靜脈**，不是臍動脈
- 臍帶有**兩條動脈、一條靜脈**；臍動脈含缺氧血、臍靜脈含充氧血
:::
