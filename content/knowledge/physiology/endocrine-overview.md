**內分泌系統**用血液中的激素調節遠處的器官，作用比神經慢但持久。本頁整理激素的分類與作用方式、各內分泌腺分泌什麼、回饋調節、松果腺，以及性腺與胎盤的激素；下視丘與腦下垂體見 [[hypothalamus-pituitary]]，胰島與血糖見 [[glucose-homeostasis]]

## 重點摘要 {#summary}

- 內分泌腺**沒有導管**，激素經**血液**送到有**專一性受體**的標的細胞；外分泌腺(汗腺、唾腺、胰臟腺泡)經導管排出
- **類固醇激素由膽固醇衍生**：皮質醇、醛固酮、性激素、活性維生素 D；胰島素是蛋白質、腎上腺素與甲狀腺素由酪胺酸衍生
- 水溶性激素作用在**細胞膜受體**，靠第二訊息傳遞物(cAMP 或 IP3／Ca²⁺)，作用快；脂溶性激素(類固醇、甲狀腺素)進入細胞作用在**核受體**、改變基因表現，作用慢但持久
- 多數激素靠**負回饋**；**正回饋**只有分娩時的催產素與排卵前的 LH 高峰
- **兼具神經與腺體組織**的內分泌器官：**腦下垂體**(前葉是腺體、後葉是神經)與**腎上腺**(皮質是腺體、髓質是神經嵴來的神經組織)
- **松果腺**(上視丘)分泌**褪黑激素**：**暗時多、光照抑制**，前驅物是**血清素**；可用於時差
- 心臟(ANP)、腎臟(腎素、EPO)、胃(胃泌素)、脂肪(瘦素)都會分泌激素；**脾臟不分泌激素**
- 升血糖的激素很多(升糖素、腎上腺素、皮質醇、生長激素、甲狀腺素)，**降血糖只有胰島素**；醛固酮對血糖幾乎沒有影響

### 國考常考點 {#exam-points}

- GnRH 是胜肽類激素，經 **IP3 與 Ca²⁺** 作用；皮質醇、雌激素是核受體
- 腦下腺**後葉**是神經外胚層來的，**不是上皮組織**衍生；甲狀腺、胰臟腺泡、腎上腺皮質都是上皮
- **腎上腺皮質絲球帶分泌醛固酮**，束狀帶才分泌糖皮質素；降鈣素由**甲狀腺濾泡旁細胞**分泌，不是副甲狀腺
- 腎上腺素和骨骼生長關係最小；生長激素、副甲狀腺素、降鈣素、雌激素都影響骨骼
- **腸泌素促進胰島素分泌是前饋**，不是負回饋
- 褪黑激素**夜晚睡眠時最高**；腦砂只是鈣化，不分泌；松果腺**不是淋巴器官**
- **hPL 拮抗胰島素**，是妊娠糖尿病的主因；hCG 的結構與作用最像 **LH**；懷孕期間**催產素不會持續大量增加**
- 睪丸切除 → 睪固酮下降、負回饋消失 → **LH 上升**
- 睪固酮經 **5α 還原酶**變成活性更強的 **DHT**；**芳香環轉化酶**把雄性素轉成雌激素，決定女性第二性徵
- 更年期熱潮紅是**雌激素下降**，不是黃體素；停經後 **HDL 下降**、LDL 上升

## 激素的分類與作用方式 {#hormone-types}

![全身主要內分泌腺的位置](/knowledge-images/endocrine-glands-overview.svg)

| 類別 | 例子 | 溶解性 | 受體位置 | 特點 |
|---|---|---|---|---|
| **胜肽、蛋白質** | 胰島素、升糖素、生長激素、泌乳素、ADH、催產素、PTH、降鈣素、各種釋放激素 | 水溶性 | 細胞膜 | 在血中游離運送，半衰期短、作用快 |
| **醣蛋白**(胜肽類的一種) | TSH、FSH、LH、hCG | 水溶性 | 細胞膜 | 共用相同的 α 次單位，差在 β 次單位 |
| **胺類**(由胺基酸衍生) | 腎上腺素、正腎上腺素、多巴胺(酪胺酸)；褪黑激素(色胺酸) | 水溶性 | 細胞膜 | 作用快 |
| **甲狀腺素**(T3、T4) | 酪胺酸＋碘 | 脂溶性 | **細胞核** | 雖是胺類，作用方式像類固醇 |
| **類固醇**(由**膽固醇**衍生) | 皮質醇、醛固酮、睪固酮、雌激素、黃體素、活性維生素 D | 脂溶性 | 細胞質或**細胞核** | 需要攜帶蛋白運送；改變基因轉錄，作用慢而持久 |

- 膜受體的訊息傳遞
   1. **cAMP**(Gs 蛋白)：升糖素、ACTH、TSH、腎上腺素的 β 受體
   2. **IP3 與 Ca²⁺**(Gq 蛋白)：**GnRH**、TRH、ADH 的血管 V1 受體、催產素、α1 受體
   3. **酪胺酸激酶受體**：胰島素、IGF-1
- 類固醇與甲狀腺素**穿過細胞膜**，和細胞內受體結合後進入細胞核調控基因，所以「由受體的性質來看作用最慢」的是類固醇激素
- 激素經**血液**(不是淋巴)運送，靠**專一性受體**決定哪些細胞有反應

## 主要內分泌腺與激素 {#glands}

| 腺體 | 激素 | 主要作用 |
|---|---|---|
| 下視丘 | 釋放與抑制激素；合成 ADH、催產素 | 控制腦下垂體，見 [[hypothalamus-pituitary]] |
| 腦下垂體前葉 | GH、PRL、TSH、ACTH、FSH、LH | 見 [[hypothalamus-pituitary#anterior-lobe]] |
| 腦下垂體後葉 | 釋放 ADH、催產素(在下視丘合成) | 見 [[hypothalamus-pituitary#posterior-lobe]] |
| 松果腺 | 褪黑激素 | 晝夜節律、睡眠 |
| 甲狀腺濾泡細胞 | T3、T4 | 提高代謝率、產熱、生長發育 |
| 甲狀腺**濾泡旁細胞**(C 細胞) | **降鈣素** | 抑制蝕骨細胞、降低血鈣 |
| 副甲狀腺**主細胞** | 副甲狀腺素(PTH) | 升高血鈣 |
| 腎上腺皮質 | **絲球帶：醛固酮**；**束狀帶：皮質醇**；網狀帶：雄性素 | 保鈉排鉀；升血糖與抗發炎；第二性徵 |
| 腎上腺**髓質** | 腎上腺素、正腎上腺素 | 交感作用 |
| 胰島 | **α 細胞：升糖素**；β 細胞：胰島素；δ 細胞：體抑素 | 調節血糖，見 [[glucose-homeostasis]] |
| 睪丸、卵巢 | 睪固酮；雌激素、黃體素 | 見下方「性腺與胎盤的激素」 |
| 胸腺 | 胸腺素 | T 淋巴球成熟 |

- **胚胎來源**
   1. 腦下垂體**前葉**：口腔外胚層向上長出的**拉克氏囊**(Rathke's pouch)，屬上皮組織
   2. 腦下垂體**後葉**：間腦底部往下長的**神經外胚層**，屬神經組織
   3. 腎上腺**皮質**來自中胚層(腺體)，**髓質**來自**神經嵴**(相當於特化的交感節後神經元)
   4. 甲狀腺來自咽部底的內胚層；胰臟腺泡與胰島來自內胚層
   5. 所以由神經組織與腺體組織**共同組成**的是**腦下垂體與腎上腺**
- **兼有內分泌功能的器官**
   1. **心臟**：心房分泌**心房利鈉胜肽**(ANP)，促進排鈉利尿、降血壓
   2. **腎臟**：腎素(啟動 RAAS，見 [[blood-pressure-regulation]])、**紅血球生成素**(EPO)、活化維生素 D
   3. **胃腸**：胃泌素、胰泌素、膽囊收縮素、腸泌素(GLP-1、GIP)
   4. 脂肪組織：瘦素(抑制食慾)；肝臟：IGF-1；皮膚：合成維生素 D₃
   5. **脾臟沒有內分泌功能**(過濾血液、免疫)
- 和骨骼生長、維持有關的激素：**生長激素**、**副甲狀腺素**、**降鈣素**、雌激素、睪固酮、活性維生素 D；**腎上腺素**主要作用在心血管與代謝，和骨骼較無關(鈣磷調節見 [[thyroid-parathyroid#calcium-regulation]])
- 胰島素、甲狀腺素這類是激素，**不是神經傳導物質**；多巴胺、甘胺酸、血清素才是

## 回饋調節 {#feedback}

![下視丘－腦下垂體－標的腺的負回饋軸](/knowledge-images/hormone-feedback-axes.svg)

- **負回饋**(最常見)：激素的效果回頭抑制自己的分泌，例如皮質醇抑制 CRH 與 ACTH、T3／T4 抑制 TRH 與 TSH、睪固酮抑制 GnRH 與 LH
   1. 拿掉下游腺體 → 下游激素消失 → 上游激素**上升**(例：兩側睪丸切除 → 睪固酮下降 → **LH、FSH 上升**，第二性徵無法發育)
   2. 依上游激素升或降判斷病變在哪一層，見上圖下方的表
- **正回饋**(少數)：效果放大原本的刺激
   1. 分娩時子宮頸被撐開 → 催產素增加 → 子宮收縮更強(佛格森反射)
   2. 排卵前雌激素持續升高 → 引發 **LH 高峰** → 排卵
- **前饋**(feedforward)：在變化發生**之前**就先調整；例如進食後血糖還沒上升，腸道已分泌**腸泌素**(GLP-1、GIP)促進胰島素分泌(見 [[glucose-homeostasis]])
- 激素與血糖：升血糖的有升糖素、腎上腺素、皮質醇、生長激素、甲狀腺素；**降血糖只有胰島素**；**醛固酮**主要調節鈉鉀與水分，對血糖影響最小

::questions{ids="112-2_BM_020,110-1_BM_028,113-2_BM_014"}

## 松果腺 {#pineal}

- 位置：**上視丘**，在**第三腦室頂部**的後方(見 [[brain-anatomy#epithalamus]])
- **松果腺細胞**(pinealocyte)以**血清素**為前驅物(色胺酸 → 血清素 → 褪黑激素)合成**褪黑激素**
- 分泌節律
   1. 視網膜感受光線 → 下視丘**視交叉上核**(生理時鐘，見 [[hypothalamus-pituitary#nuclei]]) → 經交感神經控制松果腺
   2. **光照抑制**分泌，**黑暗時分泌增加**，夜晚睡眠時濃度**最高**
- 作用：調節晝夜節律與睡眠，可用來減輕**時差**與某些睡眠問題
- **腦砂**(brain sand)是松果腺內隨年齡增加的**鈣化沉積**，**不會分泌**，X 光上可當中線標記
- 松果腺是內分泌腺，**不是淋巴器官**，不製造免疫細胞(淋巴器官有胸腺、脾臟、扁桃腺、淋巴結)

::questions{ids="107-1_BM_002,110-2_BM_023,114-1_BM_004,106-2_makeup_BM_002,114-3_BM_005"}

## 性腺與胎盤的激素 {#gonads-placenta}

性激素藥物(避孕藥、荷爾蒙療法、抗雄性素)見 [[sex-hormones]]；生殖系統的完整生理留給產科輪

### 睪丸 {#testis}

| 細胞 | 受哪個激素刺激 | 分泌或功能 |
|---|---|---|
| **萊氏細胞**(間質細胞，Leydig cell) | **LH** | **睪固酮** |
| **塞氏細胞**(Sertoli cell，曲細精管內) | **FSH**(加上睪固酮) | 支持精子生成、分泌**抑制素**(回饋抑制 FSH)、雄性素結合蛋白、抗穆勒氏管激素 |

- GnRH 刺激腦下垂體分泌 LH，LH 才作用在萊氏細胞，所以 GnRH 對萊氏細胞是**間接**作用
- 睪固酮分泌後在周邊組織(攝護腺、皮膚)經 **5α 還原酶**變成**雙氫睪固酮**(DHT)，活性更強；也可經**芳香環轉化酶**變成雌激素
- **雄性素不敏感症**(46,XY，缺雄性素受體)
   1. 有睪丸，抗穆勒氏管激素讓子宮與輸卵管退化 → **沒有子宮**
   2. 受體缺陷 → 睪固酮無法負回饋 → LH 上升 → **睪固酮濃度上升**(這一項才是「缺受體」直接造成的)
   3. 外觀為女性(睪固酮經芳香化變成雌激素)，沒有月經

::questions{ids="110-2_BM_019,108-2_BM_023,109-2_BM_026,114-2_BM_001"}

### 卵巢 {#ovary}

- 濾泡的**內膜細胞**受 LH 刺激產生雄性素 → **顆粒細胞**受 **FSH** 刺激，用**芳香環轉化酶**把雄性素轉成**雌激素**
- 排卵後黃體分泌**黃體素**與雌激素；黃體素讓**基礎體溫上升約 0.3–0.5°C**(見 [[hypothalamus-pituitary#body-temperature]])
- 決定女性第二性徵的關鍵酵素是**芳香環轉化酶**；5α 還原酶與男性外生殖器、雄性禿有關
- FSH、LH 是**腦下垂體前葉**分泌的醣蛋白(促性腺激素)，**不是下視丘**；雌激素由卵巢與胎盤分泌，不是腦下垂體

- **多囊性卵巢症候群**(PCOS)：主因是**雄性素過多**與**胰島素阻抗**(不是雌激素過多)，LH／FSH 比例失衡 → 慢性不排卵、月經異常、不孕；卵巢有許多小囊泡；肥胖與糖尿病風險增加

::questions{ids="108-1_BM_028,107-1_BM_062,108-1_OP_040,112-1_BM_029"}

### 胎盤 {#placenta}

| 激素 | 特點 |
|---|---|
| **hCG**(人類絨毛膜促性腺激素) | 結構與作用最像 **LH**；維持黃體繼續分泌黃體素；尿液可驗出(驗孕) |
| **hPL**(人類胎盤泌乳素) | 隨週數增加；**拮抗胰島素**，讓母體血糖偏高供應胎兒 → **妊娠糖尿病**的主因，懷孕中後期胰島素需要量增加 |
| 雌激素、黃體素 | 維持妊娠；抑制乳汁分泌(胎盤娩出後才開始大量泌乳) |

- 懷孕期間 hPL、雌激素、黃體素、**泌乳素**都持續上升；**催產素**要到分娩與哺乳時才大量釋放
- 妊娠糖尿病的照護見 [[diabetes]]

::questions{ids="109-1_BM_017,112-1_OP_031,115-1_BM_008,111-1_BM_030"}

### 更年期 {#menopause}

- 卵巢功能衰退 → **雌激素下降** → 負回饋消失 → **FSH、LH 上升**
- **熱潮紅**：雌激素下降使下視丘體溫調節不穩定，血管收縮與舒張失調，以皮膚發熱、流汗散熱；和**黃體素減少無關**；體重過輕的人(脂肪少，周邊芳香化產生的雌激素少)症狀較嚴重
- 雌激素對心血管的保護消失：**LDL、總膽固醇上升，HDL 下降**，血小板凝集與纖維蛋白原增加
- 骨質流失加快(骨質疏鬆留給肌肉骨骼那一輪)
- 荷爾蒙療法：60 歲以下或停經 10 年內開始，對多數人利大於弊(The Menopause Society 2022 立場聲明，[PubMed 35797481](https://pubmed.ncbi.nlm.nih.gov/35797481/))；用藥細節見 [[sex-hormones#hormone-therapy]]
