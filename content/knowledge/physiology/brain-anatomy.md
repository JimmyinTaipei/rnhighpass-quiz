腦分成**大腦**、**間腦**、**腦幹**（中腦、橋腦、延腦）與**小腦**。大腦皮質負責意識、思考、語言與隨意運動；間腦是感覺轉運站與內分泌、自主神經的總指揮；腦幹掌管生命中樞與大部分腦神經；小腦協調動作與平衡。外面有三層腦膜與腦脊髓液保護。12 對腦神經另見 [[cranial-nerves]]

## 重點摘要 {#summary}

- **額葉**：初級運動區、**布洛卡區**（表達性失語）、前額葉（思考、判斷、人格、注意力）；**頂葉**：初級體感覺區；**顳葉**：聽覺、**韋尼克區**（感覺性失語）、記憶；**枕葉**：**視覺**（禽距裂兩側）
- 左側（優勢）半球管**語言與計算**，右側管**空間**；**胼胝體**連接左右半球
- **邊緣系統**：海馬迴（新記憶，受損 → 順向失憶）、杏仁核（恐懼）、扣帶迴、穹窿、乳頭體
- **基底核**與黑質屬錐體外系統，黑質多巴胺神經元退化 → 巴金森氏症（動作遲緩）
- **下視丘**：體溫（負回饋、對核心溫度敏感）、飢餓與飽足、渴、**ADH**（視上核）、**生理時鐘**（視叉上核）、控制腦下垂體；**不**管呼吸節律；**松果腺**在上視丘、第三腦室頂部，分泌褪黑激素
- **延腦**：心血管、呼吸、**嘔吐**、**吞嚥**中樞，**錐體**（皮質脊髓徑）與薄核；壓力受器反射在延腦整合
- **腦脊髓液**由**脈絡叢**製造，**大腦導水管**連接第三與第四腦室，**室間孔**連接側腦室與第三腦室
- **硬腦膜外血腫** = **中腦膜動脈**、有清醒期；**慢性硬腦膜下血腫** = **橋靜脈**、老人、數週後才出現症狀
- **前大腦動脈**阻塞 → 對側**下肢**無力比上肢明顯；中大腦動脈阻塞 → 對側臉與上肢、語言

### 國考常考點 {#exam-points}

- **枕葉**受損 → 視覺障礙、無法解析看見的東西；初級視覺區在**枕葉**、**禽距裂**上下兩側
- 思考解決問題時活性最高的是**額葉**；**額葉腦瘤** → 注意力不集中、短期記憶喪失、人格改變、對側偏癱
- **左側**大腦損傷 → **語言障礙、計算能力降低**；空間缺損與半側忽略多見於**右側**
- 表達性失語症 = **額葉的布洛卡區**；失語症與**韋尼克區**最相關（其他選項是視丘、海馬迴、前運動皮質時）
- 連接左右半球、把訊息傳到對側的是**胼胝體**（不是內囊、穹窿、大腦腳）
- 腦部是**高代謝**器官，以**葡萄糖**為主要能量、幾乎只能有氧代謝；葡萄糖**可以**通過血腦障壁
- 失去害怕感 → **杏仁核**；順向失憶 → **海馬迴**；屬於邊緣系統的是**海馬**（不是黑質、松果腺、基底核）
- 外側皮質脊髓徑在**延腦錐體**交叉，不是在脊髓；下運動神經元損傷**不會**張力亢進
- 巴金森氏症**不是**自體免疫，多巴胺**減少**、乙醯膽鹼相對增加，與遺傳和環境有關；手足徐動型腦性麻痺 = **基底核**與錐體外病變
- ADH 在**下視丘視上核**合成；調控褪黑激素分泌的是**視叉上核**；褪黑激素來自**上視丘**的松果腺（第三腦室頂部）
- 下視丘中風 → 飢餓、多食、肥胖；體溫調節用**負回饋**，下視丘對**核心**溫度較敏感；感覺溫度後增減衣物靠大腦皮質，**不是**杏仁核
- 頸動脈竇壓力受器的訊息傳到**延腦**；噴射性嘔吐的腫瘤壓迫在**延腦**；接收迷走神經訊號、調控嘔吐的是**延髓**；吞嚥最相關的是**腦幹**
- 延腦有**錐體**（內含**皮質脊髓徑**）；**薄核在延腦**，中腦**沒有**薄核；內側蹄系傳**本體覺**
- 意識清楚、四肢癱瘓、不能說話、但能眨眼與轉動眼球 → **橋腦**（閉鎖症候群）
- 腦幹中風常見：眼球活動不協調、運動障礙、嘔吐反射減弱；**手顫抖不是**
- 疼痛刺激時四肢**伸直、內轉** → **去大腦僵直**，**中腦**受損
- 小腦：評估精細動作、肌張力與平衡；受損 → **運動失調**
- 硬膜上出血主要是**動脈**破裂（中腦膜動脈），「主要是靜脈」是錯的；慢性硬膜下出血多為**靜脈**出血
- 顱內壓開始上升時的代償：**增加腦脊髓液吸收**（把腦脊髓液擠到脊髓腔）
- 腦脊髓液正常：清澈、壓力 **70–180 mmH₂O**、蛋白質 **15–45 mg/dL**、葡萄糖約血糖的 **60–80%**；葡萄糖只有血糖的 20–30% 是**異常**
- 腰椎穿刺後**平躺**，不是頭高腳低俯臥；**腦池穿刺**後最重要觀察**呼吸**（靠近延腦）
- 清醒成人出現大量 **δ 波** → 腦部受損；**β 波**不會出現在 NREM；作夢在 **REM**；REM 時**胃酸分泌增加**、心跳血壓上升、肌肉張力**下降**
- 每晚約 4–6 個睡眠週期，每週期約 **90 分鐘**；NREM 第 4 期最難叫醒，尿床與夢遊多在 NREM 深睡期
- 枕葉**沒有**參與意識清醒與睡眠的調節（視丘、皮質、腦幹有）

### 各葉的功能 {#lobes}

| 腦葉 | 主要構造 | 功能 | 受損時 |
|---|---|---|---|
| **額葉** | **中央前回**（初級運動區）、前運動區、**布洛卡區**（額下回）、前額葉 | 隨意運動、語言表達、計畫、判斷、解決問題、人格、注意力 | 對側偏癱、**表達性失語**、人格改變、失去抑制、注意力不集中、短期記憶差 |
| **頂葉** | **中央後回**（初級體感覺區）、體感覺聯合區 | 觸覺、痛溫覺、本體感覺的定位；空間感 | 對側感覺異常、部位失認、左右辨向障礙；右側受損 → **半側忽略** |
| **顳葉** | 初級聽覺區（顳上回，外側溝內）、**韋尼克區**（顳上回後部，靠近頂葉的角迴）、內側的海馬迴 | 聽覺、語言理解、記憶 | 聽覺障礙、**感覺性失語**（說話流暢但內容混亂、聽不懂）、記憶障礙 |
| **枕葉** | 初級視覺區（**禽距裂**上下兩側） | 視覺 | **視野缺損**、看得到但無法辨識 |

- 額葉與頂葉以**中央溝**為界；顳葉在**外側溝**（薛氏裂）下方
- 初級運動區與初級體感覺區都是**對側**支配，而且像倒過來的人形：頭在外側下方、腳在內側（靠近大腦正中），所以前大腦動脈阻塞時腳最受影響

### 語言區與失語症 {#aphasia}

| 類型 | 受損區域 | 表現 |
|---|---|---|
| **表達性（運動性）失語** | **布洛卡區**（額葉） | 聽得懂，但說話不流暢、費力、字句短 |
| **感覺性（接受性）失語** | **韋尼克區**（顳葉） | 說話流暢但內容空洞錯亂，聽不懂別人說話 |
| 全面性失語 | 兩區都受損（大範圍中大腦動脈梗塞） | 說與聽都不行 |

- 大多數人（包括多數左撇子）的語言中樞在**左側**；左側半球也負責計算、邏輯分析；右側半球負責空間、臉孔辨識、音樂

### 白質的連結 {#white-matter}

1. **胼胝體**：最大的連合纖維，連接**左右大腦半球**
2. **內囊**：大腦皮質與腦幹、脊髓之間上下行纖維的通道（投射纖維），夾在視丘、尾核與豆狀核之間；這裡小小的中風就會造成對側整個半身無力
3. **穹窿**：連接海馬迴與乳頭體（邊緣系統的一部分）

### 腦的能量代謝 {#brain-metabolism}

- 腦重約體重的 2%，卻用掉全身約 **20% 的氧氣**，屬**高代謝**器官
- 主要能量是**葡萄糖**，靠 GLUT1 通過血腦障壁；幾乎只能**有氧**代謝，幾乎不儲存肝醣，所以缺氧或低血糖幾分鐘就會受損
- 長期飢餓時可以改用酮體

## 邊緣系統與記憶 {#limbic-system}

::figure{src="/knowledge-images/servier-limbic-system.svg" labels="limbic-system" alt="邊緣系統"}

| 構造 | 功能 |
|---|---|
| **海馬迴** | 把短期記憶轉成長期記憶（記憶固化）；受損 → **順向失憶**（記不住新的事），阿茲海默症早期受影響 |
| **杏仁核** | **恐懼**與情緒記憶；受損 → 失去害怕的感覺 |
| 扣帶迴 | 情緒、動機、注意力 |
| 穹窿、乳頭體 | 連接海馬迴與下視丘，屬於記憶迴路；乳頭體在維尼克氏腦病變（缺乏維生素 B₁）時受損 |

- 下視丘與視丘前核也常被列入邊緣系統；黑質、松果腺、基底核**不屬於**邊緣系統
- 精神疾病與腦區（前額葉、邊緣系統、多巴胺路徑）的關係見 [[neurotransmitters-psychiatry#brain-regions]]

## 基底核與運動途徑 {#basal-ganglia}

::figure{src="/knowledge-images/servier-brain-horizontal.svg" labels="brain-horizontal" alt="大腦水平切面：基底核、內囊與視丘"}

### 錐體路徑與錐體外路徑 {#motor-pathways}

| 項目 | 錐體路徑 | 錐體外路徑 |
|---|---|---|
| 組成 | **皮質脊髓徑**（到脊髓）、皮質延髓徑（到腦幹運動核） | **基底核**、黑質、紅核、小腦等，經紅核脊髓徑、前庭脊髓徑、網狀脊髓徑等下傳 |
| 功能 | 隨意、精細、靈巧的動作 | 調節肌張力、姿勢、動作的啟動與流暢 |
| 交叉 | 外側皮質脊髓徑在**延腦錐體**交叉（不是脊髓） | |
| 受損 | 上運動神經元症狀：痙攣、反射亢進、巴賓斯基陽性 | 不自主動作、僵直、動作遲緩或過多 |

- 上與下運動神經元損傷的比較見 [[spinal-cord-spinal-nerves#umn-lmn]]；下運動神經元損傷是弛緩、萎縮、肌束顫動，**不會**張力亢進

### 基底核 {#basal-nuclei}

1. 組成：**尾核**、**殼核**（兩者合稱**紋狀體**）、**蒼白球**（殼核＋蒼白球 = 豆狀核）、視丘下核；中腦的**黑質**和它們形成迴路
2. 功能：決定動作要不要開始、要做多大，抑制不需要的動作
3. 失調
   1. **巴金森氏症**：**黑質**的多巴胺神經元退化 → 紋狀體多巴胺不足、乙醯膽鹼相對過多 → **動作遲緩**、僵直、靜止型顫抖；病因與遺傳、環境（農藥等）有關，**不是**自體免疫
   2. 亨丁頓舞蹈症：紋狀體退化 → 舞蹈樣不自主動作
   3. **手足徐動型腦性麻痺**：基底核與錐體外病變 → 不自主、緩慢扭動的動作，影響書寫
4. 小腦病變的顫抖是**意向性**（動作時才抖），基底核病變的巴金森顫抖是**靜止型**

- 多巴胺四條路徑（中腦邊緣、中腦皮質、黑質紋狀體、結節漏斗）與抗精神病藥副作用見 [[neurotransmitters-psychiatry#dopamine-pathways]]

## 間腦 {#diencephalon}

::figure{src="/knowledge-images/servier-brain-sagittal.svg" labels="brain-sagittal" alt="腦正中矢狀切面(右為前)"}

### 視丘 {#thalamus}

- 感覺的**轉運站**：除了嗅覺，所有感覺都在視丘換神經元後送到大腦皮質
- 也參與運動迴路（基底核、小腦）與意識清醒

### 下視丘 {#hypothalamus}

| 功能 | 重點 |
|---|---|
| **體溫調節** | 以**負回饋**統整產熱與散熱；對**核心體溫**（流過的血液溫度）最敏感；前部偏散熱、後部偏產熱 |
| **飢餓與飽足** | **外側區**是攝食中樞、**腹內側核**是飽食中樞；腹內側受損 → **多食、肥胖**；控制食慾的主要器官是下視丘，不是腦下垂體 |
| 渴與水分 | 滲透壓受器 → 口渴；**視上核**（與室旁核）製造 **ADH**，經神經送到**腦下垂體後葉**釋放 |
| 催產素 | 室旁核製造，後葉釋放 |
| **生理時鐘** | **視叉上核**接收視網膜的光訊號，控制晝夜節律與松果腺分泌褪黑激素 |
| 控制腦下垂體前葉 | 分泌釋放與抑制激素 |
| 自主神經與情緒 | 壓力時啟動交感神經與 **HPA 軸**（下視丘－腦下垂體－腎上腺），見 [[neurotransmitters-psychiatry#hpa-axis]] |

- **呼吸節律**由**延腦與橋腦**控制，**不是**下視丘
- 各核區的位置示意圖與激素對照見 [[hypothalamus-pituitary#nuclei]]

### 體溫調節的機轉 {#thermoregulation}

1. 皮膚的溫度受器：**冷受器比熱受器多**，所以四肢皮膚對冷較敏感
2. 冷熱覺經**外側脊髓視丘徑**上傳，到視丘再到大腦皮質產生「冷、熱」的感覺；下視丘同時接收這些訊息
3. 效應器：血管（收縮保熱、擴張散熱）、骨骼肌（顫抖產熱）、汗腺（散熱）
4. **行為調節**（增減衣物、調室溫）由**大腦皮質**決定，**不是**杏仁核
5. 碰到極熱或極冷時，先由**脊髓反射**（縮回反射）保護，不必等大腦

### 上視丘 {#epithalamus}

- **松果腺**位在**第三腦室頂部**的後方，分泌**褪黑激素**；分泌節律由下視丘的**視叉上核**控制（暗時分泌多）

## 腦幹 {#brainstem}

::figure{src="/knowledge-images/servier-brainstem.svg" labels="brainstem" alt="腦幹腹側觀"}

### 中腦、橋腦、延腦 {#brainstem-parts}

| 部位 | 重要構造 | 功能 | 腦神經 |
|---|---|---|---|
| **中腦** | 大腦腳、**紅核**、**黑質**、**四疊體**（上丘：視覺反射；下丘：聽覺反射）、大腦導水管 | 視聽反射、動作調節 | III、IV |
| **橋腦** | 橋腦核、呼吸調節中樞 | 連接大腦與小腦、調節呼吸節律 | **V**（從橋腦外側鑽出）、VI、VII、VIII（在橋延交界） |
| **延腦** | **錐體**（內含**皮質脊髓徑**，在此交叉）、橄欖體、**薄核與楔狀核**（後柱在此換神經元） | **心血管中樞**、**呼吸中樞**、**嘔吐**、**吞嚥**、咳嗽、打噴嚏中樞 | IX、X、XI、XII |

- **網狀結構**貫穿整個腦幹，往上投射到視丘與皮質，稱**網狀活化系統**，維持**清醒與意識**
- 頸動脈竇與主動脈弓壓力受器的訊號經舌咽、迷走神經傳到**延腦**的孤立徑核，整合後調節心跳與血壓
- 顱內壓升高或腫瘤壓迫延腦的嘔吐中樞 → **噴射性嘔吐**（常沒有噁心）

### 腦幹受損的表現 {#brainstem-lesions}

1. **腦幹中風**：複視、眼球活動不協調、眩暈、吞嚥困難、構音障礙、**嘔吐反射減弱**、交叉性感覺或運動障礙；手顫抖不是典型表現
2. **閉鎖症候群**：**橋腦腹側**梗塞，四肢與臉部癱瘓、不能說話，但意識清楚，能眨眼、眼球上下轉動
3. **兒童腦幹腫瘤**：多條腦神經受壓 → 吞嚥困難、說話不清、嘔吐、步態不穩
4. **姿勢**（對疼痛刺激）

| 姿勢 | 上肢 | 下肢 | 受損位置 | 預後 |
|---|---|---|---|---|
| **去皮質僵直** | **屈曲**、內收（手縮向胸前） | 伸直 | 大腦半球、內囊、視丘（紅核以上） | 較好 |
| **去大腦僵直** | **伸直、內轉** | 伸直 | **中腦或橋腦** | **較差** |

5. **呼吸型態**（典型對應）

| 呼吸型態 | 特徵 | 常見受損位置 |
|---|---|---|
| **陳施氏呼吸** | 漸強漸弱，與呼吸暫停交替 | 雙側大腦半球或間腦；也見於心衰竭、瀕死 |
| 中樞神經性過度換氣 | 持續深而快 | 中腦、橋腦上部 |
| 長吸式呼吸 | 吸氣後停頓 | 橋腦 |
| 叢集式呼吸 | 不規則的一陣一陣，夾雜暫停 | 橋腦下部、延腦上部 |
| 失調性呼吸(Biot) | 完全不規則 | **延腦** |

## 腦膜、腦室與腦脊髓液 {#meninges-csf}

::figure{src="/knowledge-images/servier-meninges.svg" labels="meninges" alt="頭皮、顱骨與三層腦膜"}

### 三層腦膜與空間 {#meninges}

| 層次 | 特點 | 相關的出血 |
|---|---|---|
| 顱骨與硬腦膜之間：**硬膜外腔**（潛在空間） | 有**中腦膜動脈**走在顳骨內面 | **硬腦膜外（上）血腫** |
| **硬腦膜** | 最厚最硬，兩層；向內摺成**大腦鐮**、**小腦天幕**；兩層之間是**硬腦膜竇**（如上矢狀竇） | |
| 硬腦膜與蜘蛛膜之間：硬膜下腔 | 有連到硬腦膜竇的**橋靜脈** | **硬腦膜下血腫** |
| **蜘蛛膜** | 薄、無血管；伸入硬腦膜竇形成**蜘蛛膜顆粒** | |
| 蜘蛛膜與軟腦膜之間：**蜘蛛膜下腔** | 充滿**腦脊髓液**，大血管走在這裡 | 蜘蛛膜下腔出血（動脈瘤破裂） |
| **軟腦膜** | 緊貼腦表面 | |

### 硬腦膜外與硬腦膜下血腫 {#hematoma-basics}

| 項目 | 硬腦膜外（上）血腫 | 硬腦膜下血腫 |
|---|---|---|
| 出血來源 | **中腦膜動脈**（顳骨骨折） | **橋靜脈** |
| 性質 | **動脈**，快速 | **靜脈**，較慢；**慢性**可在受傷數週到數月後才出現 |
| 典型病程 | 受傷後短暫昏迷 → **清醒期** → 突然惡化 | 急性：受傷後即昏迷；慢性：記憶變差、嗜睡、意識慢慢變差 |
| 好發 | 年輕人顳部撞擊 | 老人、酗酒、服抗凝血劑（腦萎縮使橋靜脈被拉緊） |
| 影像 | 雙凸透鏡狀 | 新月狀 |
| 處置 | 以**手術**為主，容易出現顱內壓升高 | 依大小與症狀，鑽孔引流或開顱 |

- 慢性硬腦膜下出血**不一定**有顱底骨折的徵象（Battle's sign、耳鼻漏），也**不一定**出現庫欣氏三病徵

### 腦室與腦脊髓液循環 {#csf-flow}

::figure{src="/knowledge-images/servier-csf-ventricles.svg" labels="csf-ventricles" alt="腦脊髓液的循環路徑(箭頭)"}

1. **製造**：各腦室的**脈絡叢**（微血管＋室管膜細胞），每天約 500 mL，全身隨時約有 150 mL
2. **流向**
   1. **側腦室**（左右各一）
   2. → **室間孔**（Monro 孔）
   3. → **第三腦室**（間腦中間）
   4. → **大腦導水管**（中腦導水管，Sylvius 導水管）
   5. → **第四腦室**（橋腦、延腦與小腦之間）
   6. → 正中孔與外側孔 → **蜘蛛膜下腔**（腦與脊髓周圍），一部分往下到脊髓中央管
3. **吸收**：**蜘蛛膜顆粒** → 硬腦膜竇（靜脈血）
4. 功能：浮力保護（使腦的重量減輕）、緩衝撞擊、運送養分與代謝物
5. 任何一處阻塞（如導水管狹窄）→ 腦脊髓液堆積 → **水腦症**

### 腦脊髓液的正常值 {#csf-values}

| 項目 | 正常值 |
|---|---|
| 外觀 | **清澈、無色** |
| 壓力（側躺） | **70–180 mmH₂O** |
| 蛋白質 | **15–45 mg/dL** |
| 葡萄糖 | 約為血糖的 **60–80%**（約 50–80 mg/dL） |
| 白血球 | 0–5 個/mm³（淋巴球） |

- 細菌性與病毒性腦膜炎的判讀見 [[cns-infections#csf]]；細菌性時蛋白質**升高**、葡萄糖**下降**

### 腰椎穿刺與腦池穿刺 {#csf-procedures}

1. **腰椎穿刺**：L3–L4 或 L4–L5（位置的理由見 [[spinal-cord-spinal-nerves#lumbar-puncture-site]]）
   1. 用途：取腦脊髓液檢查（含細胞學找惡性細胞）、量壓力、**鞘內注射**化學藥物（如治療中樞神經白血病）
   2. **懷疑顱內壓升高時不宜**做，以免腦疝脫
   3. 穿刺後**平躺**數小時並多喝水，預防穿刺後頭痛
2. **腦池穿刺**：從枕骨下方進入小腦延髓池，靠近延腦的呼吸與心血管中樞，穿刺後**最重要觀察呼吸**（有無呼吸困難、發紺）

### 顱內壓的代償 {#icp-compensation}

1. 顱骨是固定容積，裡面是**腦組織、血液、腦脊髓液**三者（Monro-Kellie 假說）
2. 一樣東西變多（血腫、腫瘤、水腫）時，先由另外兩者讓出空間
   1. 最先：**腦脊髓液**被擠到脊髓蜘蛛膜下腔、**吸收增加**、製造減少
   2. 其次：靜脈血被擠出顱內
3. 代償用完後，顱內壓急速上升，最後腦組織被擠過天幕或枕骨大孔（腦疝脫，這是失代償，不是代償）

## 意識、腦波與睡眠 {#sleep}

### 意識的維持 {#consciousness}

- 清醒靠**腦幹網狀活化系統**、**視丘**與**大腦皮質**共同維持；枕葉主要處理視覺，不參與清醒與睡眠的調節
- 清醒時，正腎上腺素、血清素、乙醯膽鹼、組織胺神經元活性**增強**；睡眠時減弱（REM 時乙醯膽鹼又增強），GABA 神經元促進睡眠
- 意識評估用 GCS（睜眼、語言、運動），**總分下降 2 分以上**就要立即報告；詳細評估方法在神經評估頁

:::note[114-2 基醫考題]
「清醒狀態時神經傳導物質的活性」一題，四個選項都與生理事實不符，考選部**送分**
:::

### 腦波 {#eeg}

| 波 | 頻率 | 出現時機 |
|---|---|---|
| **β 波** | 最快（約 13–30 Hz）、振幅最小 | **清醒、專注、思考**；**不會**出現在 NREM |
| **α 波** | 約 8–13 Hz | 清醒、**放鬆、閉眼** |
| **θ 波** | 約 4–7 Hz | 想睡、淺睡（NREM 第 1、2 期）；兒童 |
| **δ 波** | 最慢（約 0.5–4 Hz）、振幅最大 | **深睡**（NREM 第 3、4 期）、嬰兒；**清醒成人出現大量 δ 波 → 腦部受損** |

### 睡眠週期 {#sleep-cycle}

1. 一晚約 **4–6 個週期**，每個週期約 **90 分鐘**：NREM 1 → 2 → 3 → 4 → 3 → 2 → REM
2. 越接近天亮，REM 越長、深睡期越短
3. 睡眠中斷後，要從 **NREM 第 1 期**重新開始，不是直接進 REM

| 階段 | 腦波 | 特點 |
|---|---|---|
| NREM 第 1 期 | α → θ | 最淺、很容易叫醒 |
| NREM 第 2 期 | θ（加上睡眠紡錘波） | 仍容易叫醒 |
| NREM 第 3 期 | 開始出現 δ | 深睡，**呼吸、心跳、血壓下降** |
| NREM 第 4 期 | δ 為主 | **最深、最難叫醒**；**生長激素**分泌最多；**尿床、夢遊**多在此期 |
| **REM** | 類似清醒（低振幅、快） | **作夢**；眼球快速轉動；骨骼肌張力**消失**；心跳、血壓、呼吸**上升且不規則**；**胃酸分泌增加**（消化性潰瘍夜間痛）；自主神經不穩，不是由副交感主宰 |

- 新版分期（美國睡眠醫學會）把 NREM 第 3、4 期合併成 N3；國考多半仍用四期的說法
- 影響睡眠的因素、失眠與促進睡眠的護理見 [[sleep-rest]]
