呼吸系統把空氣送到肺泡，讓氧氣進入血液、二氧化碳排出。本頁整理構造；空氣怎麼進出肺見 [[ventilation-mechanics]]，氣體交換、運送與呼吸調控見 [[gas-exchange-transport]]

## 重點摘要 {#summary}

- **傳導區**：鼻 → 咽 → 喉 → 氣管 → 支氣管 → **終末細支氣管**，只導氣、清淨、加溫加濕，不交換氣體(解剖無效腔約 150 mL)
- **呼吸區**：**呼吸性細支氣管** → 肺泡管 → 肺泡囊 → 肺泡，開始有氣體交換
- 喉：**甲狀軟骨**構成喉結；**環狀軟骨**是唯一完整的環；聲帶前端接甲狀軟骨、後端接**杓狀軟骨**；**環甲肌**收縮讓聲帶繃緊
- 氣管有 C 形**透明軟骨**環、內襯**偽複層纖毛柱狀上皮**；**細支氣管以下沒有軟骨**
- **右主支氣管較短、寬、直** → 異物與插太深的氣管內管容易進右側(左肺呼吸音變小)
- 右肺 3 葉(水平裂、斜裂)，左肺 2 葉(斜裂)；肺門在肺的**內側(縱膈)面**
- **第一型肺泡細胞**負責氣體交換；**第二型肺泡細胞**分泌**表面張力素**，防止肺泡塌陷
- 嬰幼兒：鼻腔窄、黏膜微血管多、舌頭比例大、喉頭高、**耳咽管短寬平**、肋骨水平、胸壁順應性**高**、以**腹式呼吸**為主

### 國考常考點 {#exam-points}

- 最接近肺泡囊、開始有氣體交換的是**呼吸性細支氣管**；只導氣不交換的最末端是**終末細支氣管**
- 沒有軟骨的是**細支氣管**；氣管軟骨是**透明軟骨**(不是彈性軟骨)，後方接的是**平滑肌**(氣管肌)
- 氣管在**食道前方**，約在**第 4–5 胸椎(胸骨角)**分成左右主支氣管(第 2 胸椎是錯的)
- 喉結＝**甲狀軟骨**；調節聲帶張力、位在環狀軟骨上方的是**杓狀軟骨**；繃緊聲帶的肌肉是**環甲肌**
- 分泌表面張力素＝**第二型肺泡細胞**；交換氣體＝**第一型肺泡細胞**；呼吸膜＝第一型肺泡細胞＋**微血管內皮**＋兩者的基底膜
- 不通過肺門的是**胸管**(淋巴管)
- 臟層胸膜貼在**肺表面**(不是氣管壁)；胸膜與腹膜都是**漿膜**，但不是包住腔內「所有」器官
- 早產兒呼吸窘迫是**第二型肺泡細胞**發育不全、表面張力素不足；**剖腹產**比陰道產更容易有暫時性呼吸急促
- 嬰幼兒胸壁順應性**較高**(說「較低」是錯的)；耳咽管**短、寬、水平**(說「長、窄、垂直」是錯的)

## 呼吸道的分區 {#zones}

::figure{src="/knowledge-images/servier-respiratory-tract.svg" labels="respiratory-tract" alt="呼吸道全景：鼻腔、咽、喉、氣管、左右主支氣管、細支氣管與左右肺(看圖者左邊是病人右側)"}

| 分法 | 範圍 | 功能 |
|---|---|---|
| **上呼吸道** | 鼻、鼻竇、咽、喉 | 過濾、加溫加濕、發聲、嗅覺 |
| **下呼吸道** | 氣管以下到肺泡 | 導氣與氣體交換 |
| **傳導區** | 鼻 → 終末細支氣管 | 只導氣；這段空氣不參與交換＝**解剖無效腔**(約 150 mL) |
| **呼吸區** | 呼吸性細支氣管 → 肺泡 | **氣體交換** |

- 傳導區的三個保護功能
   1. 過濾：鼻毛、黏液黏住灰塵與微生物
   2. 加溫加濕：鼻腔黏膜血管豐富
   3. **黏液纖毛清除**：纖毛把黏液往咽部推，再咳出或吞下；吸菸會讓纖毛失去功能
- **肺也是排泄器官**：排出 CO₂、水蒸氣與揮發性物質(和皮膚、腎臟、消化道並列)
- 鼻腔與咽的其他構造(鼻竇、扁桃腺、耳咽管)見 [[pediatric-respiratory-infections]]；吞嚥時會厭蓋住喉口，見 [[cranial-nerves#swallowing]]

## 喉 {#larynx}

::figure{src="/knowledge-images/servier-larynx.svg" labels="larynx" alt="喉：左為前面觀(舌骨、甲狀軟骨與喉結、環甲膜、環狀軟骨、氣管軟骨環)，右為冠狀切面(會厭、聲帶)"}

| 軟骨 | 數目 | 位置與特徵 |
|---|---|---|
| **甲狀軟骨** | 1 | 最大；前方突起是**喉結**(男性較明顯)；聲帶**前端**附著處 |
| **環狀軟骨** | 1 | 甲狀軟骨下方；**唯一完整的環**；下接氣管 |
| **會厭軟骨** | 1 | 彈性軟骨；吞嚥時蓋住喉口，防止食物進入氣管 |
| **杓狀軟骨** | 2 | 坐在**環狀軟骨後上方**；聲帶**後端**附著處，轉動時改變聲帶張力與開闔 |
| 小角軟骨、楔狀軟骨 | 各 2 | 小，在杓狀軟骨附近 |

- **聲帶**：前接甲狀軟骨、後接杓狀軟骨；兩側聲帶之間的空隙是**聲門**
- 喉內肌
   1. **環甲肌**：把甲狀軟骨往前下拉 → **聲帶繃緊**、音調變高；由**喉上神經外支**支配
   2. **後環杓肌**：唯一讓聲門**打開**的肌肉
   3. 其他喉內肌：讓聲門關閉；由**喉返神經**支配(迷走神經分支)
- 臨床
   1. 甲狀腺手術傷到喉返神經 → **聲音沙啞**，雙側受傷可能呼吸道阻塞，見 [[hyperthyroidism#thyroidectomy]]
   2. **環甲膜**在甲狀軟骨與環狀軟骨之間，是緊急開放呼吸道(環甲膜切開)的位置

## 氣管與支氣管樹 {#bronchial-tree}

- **氣管**
   1. 位置：從環狀軟骨下緣(約第 6 頸椎)到**胸骨角(約第 4–5 胸椎)**分叉，分叉處內側的脊叫**隆凸**
   2. 在**食道前方**
   3. 軟骨：16–20 個 **C 形透明軟骨**環，開口朝後；後方由**氣管肌(平滑肌)**與結締組織連接，讓食團通過食道時氣管可以讓位
   4. 上皮：**偽複層纖毛柱狀上皮**＋杯狀細胞(分泌黏液)
   5. 血液供應：甲狀腺下動脈與**支氣管動脈**
- **左右主支氣管**

| | 右主支氣管 | 左主支氣管 |
|---|---|---|
| 長度與管徑 | **較短、較寬** | 較長、較窄(要繞過主動脈弓與心臟) |
| 角度 | **較垂直**(接近氣管延長線) | 較水平 |
| 臨床 | 異物、吸入物、**插太深的氣管內管**容易進右側 | — |

- 氣管內管插太深 → 進右主支氣管 → **左肺呼吸音減弱**、左胸起伏小；插管後要聽兩側呼吸音、照胸部 X 光確認
- **分支順序**：主支氣管 → **葉支氣管**(右 3、左 2) → **節支氣管**(每個肺節一支，姿位引流依肺節擺位) → **細支氣管** → **終末細支氣管** → **呼吸性細支氣管** → 肺泡管 → 肺泡囊 → 肺泡
- 越往下的變化

| 構造 | 軟骨 | 平滑肌 | 上皮 | 功能 |
|---|---|---|---|---|
| 氣管、主支氣管 | C 形環 | 少 | 偽複層纖毛柱狀 | 導氣 |
| 葉、節支氣管 | 不規則軟骨片 | 增加 | 偽複層纖毛柱狀 | 導氣 |
| **細支氣管** | **沒有** | **最多**(氣喘時收縮) | 單層柱狀到立方 | 導氣、調節氣流 |
| 終末細支氣管 | 沒有 | 有 | 單層立方 | **傳導區的最末端** |
| 呼吸性細支氣管 | 沒有 | 少 | 單層立方，壁上開始長肺泡 | **開始交換氣體** |
| 肺泡 | 沒有 | 沒有 | 單層扁平(第一型肺泡細胞) | 氣體交換 |

- 細支氣管沒有軟骨支撐，管徑靠平滑肌調控：**交感(β₂)使其擴張、副交感(迷走神經)使其收縮並增加分泌**，藥物對應見 [[asthma-drugs]]、[[autonomic-nervous-system]]

## 肺 {#lungs}

::figure{src="/knowledge-images/servier-lung-lobes.svg" labels="lung-lobes" alt="肺葉拆開圖：右肺上、中、下三葉，左肺上、下兩葉(看圖者左邊是右肺)"}

| | 右肺 | 左肺 |
|---|---|---|
| 葉 | **3 葉**(上、中、下) | **2 葉**(上、下) |
| 裂 | **水平裂**分上葉與中葉；**斜裂**把下葉和上、中葉分開 | 只有**斜裂** |
| 形狀 | 較寬短(右側肝臟把橫膈頂高) | 較窄長；有**心切跡**與**舌葉**(上葉前下方，相當於右中葉) |

- 右肺的斜裂在後方把**上葉與下葉**分開、在前方把**中葉與下葉**分開，所以斜裂和上葉也有關係
- **肺尖**高出鎖骨上方，**肺底**坐在橫膈上
- **肺門**在肺的**內側(縱膈)面**，通過：主支氣管、肺動脈、肺靜脈、支氣管動靜脈、神經、淋巴管；**胸管不經過肺門**(它在後縱膈沿脊柱上行)
- 兩套血液供應
   1. **肺循環**：肺動脈帶缺氧血到肺泡交換，肺靜脈帶充氧血回左心房
   2. **支氣管動脈**(來自主動脈)：供應支氣管與肺組織本身的養分
- 神經
   1. **膈神經**來自**頸神經叢(C3–C5)**，支配橫膈；頸椎高位損傷會影響自主呼吸，見 [[spinal-cord-spinal-nerves#plexuses]]
   2. 迷走神經：副交感，支氣管收縮、分泌增加；也傳回主動脈體與肺牽張受器的訊息

## 肺泡與呼吸膜 {#alveoli}

::figure{src="/knowledge-images/servier-alveoli.svg" labels="alveoli" alt="終末細支氣管、呼吸性細支氣管、肺泡管、肺泡囊與肺泡周圍的微血管網"}

- 兩肺約有 3 億到 5 億個肺泡，總交換面積約 **70 平方公尺**(來源：OpenStax Anatomy and Physiology 2e，22.2)

| 細胞 | 形態與比例 | 功能 |
|---|---|---|
| **第一型肺泡細胞** | 扁平，覆蓋肺泡表面的大部分 | **氣體交換**；構成呼吸膜 |
| **第二型肺泡細胞** | 立方，散在第一型之間 | **分泌表面張力素**；肺泡受損後增生修補、分化成第一型 |
| **肺泡巨噬細胞**(塵細胞) | 在肺泡腔游走 | 吞噬灰塵與微生物 |

- **呼吸膜**(氣體要穿過的屏障，厚度不到 1 μm)
   1. 第一型肺泡細胞
   2. 兩者融合的基底膜
   3. **微血管內皮細胞**
- 呼吸膜**變厚**(肺水腫、肺纖維化)或**面積變小**(肺氣腫、肺葉切除)都會降低氣體擴散，見 [[gas-exchange-transport#diffusion]]
- **表面張力素**：降低肺泡內液體的表面張力，讓小肺泡不塌陷、肺比較好撐開；作用見 [[ventilation-mechanics#compliance]]
   1. 第二型肺泡細胞受損(例如 ARDS) → 表面張力素減少 → **肺擴張不全**

::questions{ids="108-1_BM_013,108-1_BM_022,108-2_BM_029,111-1_BM_004,114-2_MS_034"}

## 胸膜 {#pleura}

- 胸膜是**漿膜**(單層扁平的間皮細胞＋結締組織)，分兩層
   1. **臟層胸膜**：緊貼**肺表面**，也伸進肺葉之間的裂
   2. **壁層胸膜**：襯在胸壁內面、縱膈與橫膈上
   3. **肋膜腔**(胸膜腔)：兩層之間的潛在空間，只有少量潤滑液；平常是**負壓**，讓肺跟著胸壁擴張
- 心臟由心包膜包住，不在胸膜內；腹腔也有腹膜後器官不被腹膜包住，所以「包覆所有臟器」是錯的
- 肋膜腔跑進空氣＝**氣胸**；空氣只進不出(單向活瓣)＝**張力性氣胸**，空氣卡在**肋膜腔**，壓迫肺與縱膈腔；跑進液體、血或膿＝肋膜積水、血胸、膿胸，見 [[pleural-chest-trauma]]
- 肋膜腔負壓與跨肺壓的變化見 [[ventilation-mechanics#pressures]]

## 嬰幼兒的呼吸道特徵 {#infant}

| 特徵 | 和成人比 | 臨床意義 |
|---|---|---|
| 鼻腔 | **狹小**，黏膜柔軟、**微血管豐富** | 鼻塞就影響呼吸與餵食；容易鼻出血 |
| 呼吸方式 | 嬰兒以**鼻呼吸**為主 | 鼻塞時要先清鼻腔 |
| 舌頭 | 在口腔所占**比例大** | 意識改變或感染時容易阻塞呼吸道 |
| 喉頭與會厭 | 喉頭位置**較高**、會厭軟骨**比例較大** | 容易嗆到、**吸入性肺炎** |
| 氣道管徑 | 小；傳統說法認為 8 歲前最窄處在**環狀軟骨** | 輕微水腫就明顯阻塞(哮吼、會厭炎) |
| 氣管 | **較短、分叉處較高** | 吸入物容易進入、插管深度要小心 |
| **耳咽管(歐氏管)** | **較短、較寬、呈水平** | 鼻咽分泌物易進中耳 → **中耳炎** |
| 鼻竇 | 上頜竇、篩竇出生就有；**額竇到學齡期才發育** | 學齡前少見額竇炎 |
| 肋骨與胸壁 | 肋骨**較水平**、胸壁軟、**順應性較高** | 胸廓擴張有限，靠**腹式(橫膈)呼吸**(到學齡期)；呼吸窘迫時出現**肋間、胸骨凹陷** |
| 肺泡 | 出生時數量少，到約 **8 歲**才發育完整(來源：OpenStax Anatomy and Physiology 2e，22.7) | 呼吸儲備小 |
| 代謝率 | 較高 | **年紀越小呼吸越快**，數呼吸要看腹部起伏 |

- 測量嬰幼兒呼吸速率：看**腹部起伏**、數**滿 1 分鐘**；正常值與評估見 [[respiratory-assessment#measurement]]

## 胎兒肺的發育與第一口氣 {#fetal-lung}

- 第二型肺泡細胞約在**妊娠 20 週**開始分泌少量表面張力素，到**約第 8 個月**才足夠讓肺順利擴張(來源：OpenStax Anatomy and Physiology 2e，22.7)
- **早產** → 表面張力素不足 → 肺泡塌陷、形成**透明膜** → **新生兒呼吸窘迫症候群**；新生兒的照護與表面張力素給予留在第 16 輪產科新生兒
- 出生時引發第一口氣的刺激
   1. 化學：缺氧、CO₂ 上升、酸中毒刺激化學受器
   2. 溫度：外界較冷
   3. 觸覺與機械：擦乾、刺激皮膚
- **陰道產道擠壓胸廓**，把肺內液體擠出；**剖腹產**少了這一步，肺液殘留較多 → **暫時性呼吸急促**較常見
