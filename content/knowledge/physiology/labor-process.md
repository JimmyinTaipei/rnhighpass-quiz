分娩是胎兒、胎盤與胎膜經由產道娩出的過程。本頁整理產兆與真假陣痛、影響分娩的四個因素（產道、娩出物、產力、產婦姿勢與心理）、胎頭構造與徑線、胎勢胎產式胎位、分娩機轉、四個產程與胎盤剝離。待產時的護理評估與照護見 [[intrapartum-care]]，產時胎心監測見 [[intrapartum-fetal-monitoring]]，產痛見 [[labor-pain-relief]]，難產與引產見 [[labor-complications]]。文中縮寫：LOA（Left occiput anterior，左枕前位）、ROA（Right occiput anterior，右枕前位）、OA（Occiput anterior，枕前位）、OP（Occiput posterior，枕後位）、SOB（Suboccipitobregmatic diameter，枕下前囟徑）、OF（Occipitofrontal diameter，枕額徑）、OM（Occipitomental diameter，枕頦徑）、SMB（Submentobregmatic diameter，頦下前囟徑）、BPD（Biparietal diameter，雙頂徑）

## 重點摘要 {#summary}

- **真陣痛**：**規則**、間隔越來越短、強度越來越強、**子宮頸變薄擴張**、走動**不會**緩解；**假陣痛**相反
- 分娩 4P：產道(Passage)、娩出物(Passenger)、產力(Powers)、產婦姿勢與心理（Position、Psyche）
- 正常是**頭頂產式**、完全**俯屈**，以最小的**枕下前囟徑**通過產道
- 分娩機轉：**銜接 → 下降 → 俯屈 → 內迴轉 → 伸展 → 復位、外迴轉 → 娩出**
- 第一產程：規則宮縮到子宮頸**全開（10 公分）**；第二產程：全開到**胎兒娩出**；第三產程：到**胎盤娩出**；第四產程：產後 **1–2 小時**

### 國考常考點 {#exam-points}

- 真陣痛：**宮縮間隔逐漸變短、規律、強度增加**；不是「走路會緩解」、不是「一定伴隨破水」
- 宮縮壓 40 mmHg 但**不規則**、子宮頸**沒有變化**、痛在**腹部**、**走動可減輕** → **假陣痛**
- 第一胎、離醫院 20 分鐘：出現**約 5 分鐘一次的規則陣痛**再去醫院（破水或大量出血要立即去）
- **腹輕感**後：呼吸變輕鬆、橫膈緊繃減輕、**頻尿更明顯**、鼠蹊與下肢不適**增加**（不是緩解）；初產婦約在分娩前 **2 週**出現，經產婦常到**分娩開始**才出現
- **初產婦**子宮頸**先變薄再擴張**；**經產婦**變薄與擴張**同時進行**
- 確認破水：**羊齒試驗**（顯微鏡下看到羊齒狀結晶）；硝嗪試紙遇羊水變**藍**色（不是粉紅色）
- 生理性收縮環：子宮**上段變厚、下段變薄**
- 子宮收縮**以子宮底最強**、間歇性、不受意志控制；**不受**腸胃神經支配
- **膀胱截石臥位**方便醫師接生，但對產程幫助有限、產婦較易呼吸困難
- 腹部四段觸診(Leopold)的目的是**檢查胎產式與胎位**；第一段找出**子宮底**是哪個部位；不必脹膀胱（要先排空）
- 先露部位與母親骨盆前後左右的關係＝**胎位**；胎頭部分屈曲時以**枕額徑**通過；**面產式**以**頦下前囟徑**通過；**頭頂產式**徑線最短
- 宮底摸到軟而不圓、恥骨上摸到硬而圓、臍下聽到胎心音 → **頭產式**
- **LOA** 產程最短；**ROA** 內迴轉 **45 度**到 OA（ROP 要轉 135 度）
- LOA 內迴轉完成後，胎頭**矢狀縫與骨盆前後徑平行**；撥露時胎位多已轉成 **OA**
- 胎頭娩出後的下一個機轉是**外迴轉**
- 胎頭：**冠狀縫**在額骨與頂骨之間（兩頂骨之間是**矢狀縫**）；**枕額徑(OF)小於枕頦徑(OM)**；骨盆**出口**前後徑大於橫徑
- 初產婦子宮頸全開後，宮縮間歇也看得到胎頭不縮回＝**著冠**
- 第一產程從**規則宮縮**開始算（不是從不規則陣痛或入院時間）
- **鄧氏法**：胎盤**暗紅粗糙的母體面**先出、**較易剝離不完全**；胎盤碎片殘留常是**晚期產後出血**的主因

## 產兆 {#premonitory-signs}

分娩前幾天到幾週會出現的徵象

| 產兆 | 說明 |
|---|---|
| **腹輕感**(lightening) | 胎頭下降進入骨盆 → 子宮底下降 |
| | 呼吸**變輕鬆**、胃部壓迫減輕 |
| | 膀胱受壓 → **頻尿更明顯**；骨盆、鼠蹊、下肢的壓迫感與抽筋**增加** |
| | **初產婦**約在分娩前 **2 週**；**經產婦**常到**分娩開始**才出現 |
| **假陣痛** | 不規則的子宮收縮（見下方真假陣痛表） |
| **現血**(bloody show) | 子宮頸變軟、變薄時，**黏液栓**脫落，帶少量血絲的黏液 |
| | 多數在 24–48 小時內開始分娩 |
| 子宮頸變化 | 變軟（成熟）、變薄、開始擴張 |
| 破水 | 約 10% 在分娩開始前破水（早期破水見 [[perinatal-infections#prom-chorioamnionitis]]） |
| 其他 | 體重減輕約 0.5–1.5 公斤（水分排出）、突然精力旺盛（築巢本能）、下背痛、腹瀉 |

- 初產婦與經產婦的子宮頸變化不同
   1. **初產婦**：子宮頸**先變薄**，再擴張
   2. **經產婦**：變薄與擴張**同時進行**
- 分娩開始的機轉有多種學說（催產素、黃體素下降、前列腺素、胎兒腎上腺皮質醇），目前沒有單一定論

### 真陣痛與假陣痛 {#true-false-labor}

| | **真陣痛** | **假陣痛** |
|---|---|---|
| 規律性 | **規則** | 不規則 |
| 間隔 | **逐漸縮短** | 不變或時長時短 |
| 強度 | **逐漸增強** | 不變或減弱 |
| 疼痛位置 | 從**下背部**開始，往前繞到腹部 | 侷限在**下腹部** |
| 走動 | 走動時**更強** | 走動或**休息後減輕**、消失 |
| 子宮頸 | **變薄、擴張** | **沒有變化** |
| 鎮靜劑 | 不會停 | 常會停 |

- 判斷真假陣痛**最可靠的依據是子宮頸變化**
- 懷孕中期以後的布拉克斯頓希克斯收縮(Braxton Hicks)屬於假陣痛，見 [[maternal-adaptation#reproductive]]
- 何時要到醫院：見 [[intrapartum-care#when-to-go]]

### 確認破水 {#rupture-tests}

| 檢查 | 結果 |
|---|---|
| 陰道窺器 | 看到羊水從子宮頸口流出或積在後穹窿 |
| **硝嗪試紙**(Nitrazine) | 羊水偏鹼（pH 約 7.0–7.5） → 試紙變**藍**（陰道分泌物偏酸，維持黃色） |
| | 血液、精液、尿液、陰道感染會**偽陽性** → 採檢時要避開 |
| **羊齒試驗**(Fern test) | 液體塗在玻片上乾燥，顯微鏡下看到**羊齒狀結晶** → **可確認破水** |

- 破水後最優先的護理見 [[intrapartum-care#rupture-of-membranes]]

## 影響分娩的因素 {#four-ps}

### 產道 {#passage}

- **骨性骨盆**：兩塊髖骨、薦骨、尾骨；以**骨盆界線**（恥骨聯合上緣 → 髂恥線 → 薦骨岬）分成
   1. **假骨盆**：界線以上，支撐懷孕的子宮，與分娩關係小
   2. **真骨盆**：界線以下，就是產道，分成入口、骨盆腔、出口
- 真骨盆三個平面

| 平面 | 形狀特徵 | 重要徑線 |
|---|---|---|
| **入口** | **橫徑 > 前後徑**（橫向的橢圓） | 產科結合徑（恥骨聯合內面到薦骨岬）約 11 公分以上，是入口**最短的前後徑** |
| **骨盆腔**（中骨盆） | **前後徑 > 橫徑** | **坐骨棘間徑**約 10 公分，是產道**最窄**處；也是判斷胎頭高度(station)的基準 |
| **出口** | **前後徑 > 橫徑** | 坐骨結節間徑約 10–11 公分 |

- 因為入口橫向寬、出口前後寬，胎頭進入骨盆時多是**橫向或斜向**，下降時要**內迴轉**成枕前位才能娩出
- 軟產道：子宮下段、子宮頸、陰道、骨盆底肌肉與會陰
- 骨盆四型（依入口形狀）

| 類型 | 入口形狀 | 對分娩 |
|---|---|---|
| **女型**(gynecoid) | 圓形 | **最利於陰道分娩**，最常見 |
| 男型(android) | 心形、前窄 | 不利，易難產 |
| 類人猿型(anthropoid) | 前後徑長的橢圓 | 常以枕後位娩出 |
| 扁平型(platypelloid) | 橫徑長、前後徑短 | 不利，胎頭不易銜接 |

- 骨盆骨骼解剖見 [[skeletal-system#pelvis]]

::questions{ids="115-2_OP_008"}

### 娩出物：胎頭 {#fetal-skull}

- 胎頭是胎兒**最大、最不易變形**的部分，能否通過產道主要看胎頭
- 顱頂骨之間有膜性的**顱縫**與**囟門**，分娩時骨頭可以重疊（**塑形**），讓胎頭變小

| 構造 | 位置 | 臨床意義 |
|---|---|---|
| **矢狀縫** | **兩塊頂骨之間** | 連接前後兩個囟門；陰道內診時用來判斷胎頭方向 |
| **冠狀縫** | **額骨與頂骨之間** | |
| 人字縫 | 頂骨與枕骨之間 | |
| 額縫 | 兩塊額骨之間 | |
| **前囟門** | 兩塊額骨與兩塊頂骨交接，**菱形**（較大） | 約 **12–18 個月**關閉 |
| **後囟門** | 兩塊頂骨與枕骨交接，**三角形**（較小） | 約 **6–8 週**關閉 |

- **胎頭塑形**(molding)：顱骨重疊使頭型變長，出生後**數天內**恢復
- 新生兒囟門凹陷代表**脫水**，膨出代表顱內壓上升；新生兒頭部評估（產瘤、頭血腫）見 [[newborn-assessment#head]]

| 徑線 | 長度（約） | 何時以它通過產道 |
|---|---|---|
| **枕下前囟徑(SOB)** | **9.5 公分** | **頭頂產式**，胎頭**完全俯屈**，**最小**的前後徑 |
| 枕額徑(OF) | 11.5–12 公分 | **前頂產式**，胎頭**部分俯屈**（軍姿） |
| **枕頦徑(OM)** | **13.5 公分** | **額產式**，**最大**的前後徑 → 通常無法陰道生產 |
| 頦下前囟徑(SMB) | 9.5 公分 | **面產式**，胎頭**完全仰伸** |
| **雙頂徑(BPD)** | 9.5 公分 | **最大的橫徑**；超音波用來估算週數與追蹤胎兒生長 |

- 徑線大小：**OM > OF > SOB**
- 數字各書略有差異，記大小順序比記數字重要

### 娩出物：胎勢、胎姿、胎產式、胎位 {#fetal-position-terms}

| 名詞 | 定義 | 種類 |
|---|---|---|
| **胎勢**(attitude) | 胎兒身體各部分之間的關係（彎曲程度） | 正常是**屈曲**：下巴貼胸、四肢屈曲；也可能伸展（反屈） |
| **胎姿**(lie) | 胎兒長軸與母親長軸的關係 | **縱位**（平行，超過 99%）、**橫位**（垂直）、斜位 |
| **胎產式**(presentation) | 最先進入骨盆的部位（**先露部位**） | **頭產式**約 95–96%、**臀產式**約 3–4%、**肩產式**約 0.5% |
| **胎位**(position) | **先露部位的特定點與母親骨盆前後左右的關係** | 例如 LOA、ROA、LOP |

- 頭產式依俯屈程度再分

| 頭產式 | 胎勢 | 特定點 | 通過徑線 |
|---|---|---|---|
| **頭頂產式**(vertex) | **完全俯屈** | 枕骨(O) | SOB（**最小**，最順利） |
| 前頂產式(military) | 部分俯屈 | 頂骨 | OF |
| 額產式(brow) | 部分仰伸 | 額骨(F) | OM（**最大**） |
| 面產式(face) | **完全仰伸** | 頦骨(M) | SMB |

- 臀產式：完全臀產式（大腿與膝都屈曲）、**伸腿臀產式**（大腿屈曲、膝伸直，最常見）、足位與膝位（不完全）；特定點是**薦骨(S)**
- 胎位的寫法
   1. 第一個字：母親骨盆的**左(L)或右(R)**
   2. 第二個字：先露部位的特定點：**枕骨 O**、頦骨 M、薦骨 S、肩胛骨 Sc
   3. 第三個字：母親骨盆的**前(A)、後(P)、橫(T)**
   4. 例：枕骨在母親骨盆**左前方** → **LOA**
- **LOA 最常見、產程最短**；**枕後位**(OP)產程較長、下降與擴張較慢、下背痛明顯（見 [[labor-complications#occiput-posterior]]）
- 用**腹部四段觸診**(Leopold)判斷胎產式與胎位，做法見 [[prenatal-assessment#leopold]]
   1. 檢查前先**排空膀胱**
   2. 第一段：摸**子宮底**，判斷是頭還是臀（頭硬而圓、可浮動；臀軟而不規則）
   3. 第二段：摸兩側，找**胎背**（胎心音最清楚的一側）
   4. 第三段：摸恥骨聯合上方，判斷**先露部位**與是否固定
   5. 第四段：面向孕婦腳，判斷**先露部位下降程度**與胎頭俯屈
- 胎心音聽診位置依胎位而不同，見 [[intrapartum-fetal-monitoring#auscultation-site]]

::questions{ids="113-2_OP_009,110-2_OP_009,110-2_OP_015,110-1_OP_008,109-2_OP_015"}

### 產力 {#powers}

- **主要產力**：**子宮收縮**，第一產程讓子宮頸變薄擴張
- **次要產力**：第二產程產婦**向下用力**（腹壓），幫助胎兒娩出
- 正常子宮收縮的特性
   1. **不受意志控制**、**間歇性**（收縮與放鬆交替，放鬆期讓胎盤血流恢復）
   2. 從子宮角開始，向下擴散；**子宮底收縮最強、最久**（底部優勢）
   3. 受**催產素**、前列腺素與自主神經影響，**不受**腸胃神經支配
- 宮縮的評估（頻率、持續時間、強度）見 [[intrapartum-care#contractions]]
- **生理性收縮環**
   1. 分娩時子宮分成**上段**（主動收縮）與**下段**（被動伸展）
   2. 上段肌肉每次收縮後**縮短變厚**、下段被拉長**變薄**，兩段交界形成生理性收縮環
   3. 產程受阻時，收縮環上升到肚臍附近、在腹部可見，稱為**病理性收縮環**（班德爾環），是**子宮破裂**的前兆（見 [[labor-complications#uterine-rupture]]）
- 子宮頸變薄擴張的力量
   1. 宮縮把子宮頸往上拉
   2. 胎兒先露部位壓迫子宮頸
   3. 前羊膜囊的靜水壓
   4. 宮縮時胎兒軸壓力把胎兒往下推

::questions{ids="110-1_OP_017,107-2_OP_012,107-1_OP_010"}

### 產婦姿勢與心理 {#position-psyche}

| 姿勢 | 優點 | 缺點 |
|---|---|---|
| 直立（站、走、坐、蹲） | 利用**重力**幫助胎頭下降、宮縮較有效、**減少壓迫下腔靜脈** | 會陰較難保護、接生者操作不便 |
| **蹲姿** | 骨盆出口加大 | 久蹲疲累 |
| 側臥 | 休息、減少下腔靜脈壓迫、**減緩急產**、會陰撕裂較少 | |
| 手膝跪姿 | 減輕下背痛、**幫助枕後位旋轉** | |
| **膀胱截石臥位** | **方便醫師接生**與會陰處理 | 對產程進展**幫助有限**、**仰臥低血壓**、產婦較易**呼吸困難**、會陰撕裂與會陰切開較多 |

- 待產與生產時應讓產婦**自由選擇姿勢**(WHO 2018)，待產姿勢的護理見 [[intrapartum-care#first-stage-care]]
- 心理：恐懼與焦慮使兒茶酚胺上升 → 宮縮變弱、產程延長、疼痛加劇（害怕、緊張、疼痛循環見 [[labor-pain-relief#theories]]）

::questions{ids="106-2_makeup_OP_016"}

## 分娩機轉 {#cardinal-movements}

胎頭通過骨盆時為了配合產道形狀所做的一連串轉動（以 LOA 為例）

| 順序 | 機轉 | 說明 |
|---|---|---|
| 1 | **銜接**(engagement) | 胎頭最大橫徑（雙頂徑）通過骨盆入口；胎頭高度約到 **0**（坐骨棘）；初產婦常在分娩前 2 週，經產婦在分娩時 |
| 2 | **下降**(descent) | 整個分娩過程持續進行 |
| 3 | **俯屈**(flexion) | 胎頭遇到阻力時下巴貼胸，改以**最小的 SOB** 前進 |
| 4 | **內迴轉**(internal rotation) | 枕骨轉到**恥骨聯合下方**(OA)，**矢狀縫與骨盆出口前後徑平行**；ROA、LOA 轉 **45 度**，ROP、LOP 轉 **135 度** |
| 5 | **伸展**(extension) | 枕骨抵住恥骨聯合下緣當支點，胎頭仰伸，依序娩出頭頂、額、臉、下巴 |
| 6 | **復位**(restitution) | 胎頭娩出後轉回與肩膀垂直的方向（LOA 轉回左側） |
| 7 | **外迴轉**(external rotation) | 肩膀在骨盆內做內迴轉（雙肩徑轉成前後向），胎頭跟著轉向母親大腿內側 |
| 8 | **娩出**(expulsion) | 前肩從恥骨聯合下方娩出，再娩出後肩與身體 |

- 第二產程**撥露、著冠**時，胎頭多已完成內迴轉成 **OA**
- 胎頭娩出後的下一步是**復位與外迴轉**
- 胎頭與骨盆徑線對不上（胎頭骨盆不對稱）、胎位不正時，機轉會受阻 → 難產（見 [[labor-complications]]）

## 四個產程 {#stages}

| 產程 | 範圍 | 初產婦（約） | 經產婦（約） |
|---|---|---|---|
| **第一產程** | **規則宮縮**開始 → 子宮頸**全開（10 公分）** | 12–14 小時 | 6–8 小時 |
| **第二產程** | 子宮頸全開 → **胎兒娩出** | 數十分鐘到 2 小時 | 數分鐘到 1 小時 |
| **第三產程** | 胎兒娩出 → **胎盤娩出** | 5–30 分鐘 | 5–30 分鐘 |
| **第四產程** | 胎盤娩出後 **1–2 小時**（恢復期） | | |

- 各產程時間是課本的傳統數值，現行指引的時限見下方第一產程與第二產程
- 計算方式
   1. 第一產程從**規則宮縮**開始算，不是從第一次不規則陣痛或入院時間
   2. 例：凌晨 3 點開始規則宮縮、下午 3 點全開、4 點 10 分胎兒娩出、4 點 20 分胎盤娩出 → 第一產程 **12 小時**、第二產程 **1 小時 10 分**、第三產程 **10 分鐘**

::questions{ids="114-2_OP_011,115-1_OP_008"}

### 第一產程 {#first-stage}

| 期別 | 子宮頸（課本） | 宮縮 | 產婦表現 |
|---|---|---|---|
| **潛伏期** | 0–3(4) 公分；以**變薄**為主 | 每 5–30 分鐘、持續 30–40 秒、輕度 | **興奮、話多、有信心**，能走動 |
| **活動期** | 4–7 公分；擴張**最快**（最大斜率期） | 每 3–5 分鐘、40–60 秒、中度 | 嚴肅、專注在宮縮上，較少說話 |
| **過渡期** | 8–10 公分 | 每 2–3 分鐘、60–90 秒、強 | 煩躁、失去控制感、怕被留下、腿發抖、噁心嘔吐、**現血增加**、**想用力**、有便意 |

- **Friedman 曲線**把活動期再分成**加速期、最大斜率期（擴張最快）、減速期**；過渡期大致相當於減速期
- 現行指引的活動期起點
   1. **WHO 2018**：子宮頸 **5 公分**以後才算活動期
   2. **ACOG／SMFM 2014**：**6 公分**以後才算活動期
   3. 舊考題多以 3–4 公分為界；兩種說法都要認得
- 時限
   1. WHO 2018：活動期初產婦通常不超過 12 小時、經產婦不超過 10 小時；**不再用「每小時 1 公分」**當作產程遲滯的標準
   2. 潛伏期延長(Friedman)：初產婦 > 20 小時、經產婦 > 14 小時
- 各期的行為反應與護理見 [[intrapartum-care#maternal-behavior]]

::questions{ids="107-1_OP_015"}

### 第二產程 {#second-stage}

- 範圍：子宮頸**全開** → **胎兒娩出**
- 徵象
   1. 宮縮強、密，產婦**不自主想向下用力**、有便意感（胎頭壓迫直腸）
   2. 會陰膨出、肛門擴張、現血增加
   3. **撥露**：宮縮時看到胎頭，宮縮停止時**縮回**陰道內
   4. **著冠**(crowning)：胎頭最大徑通過陰道口，**宮縮間歇時也不會縮回**
- 疼痛來源：子宮韌帶與**陰道、會陰的伸展**、宮縮時細胞缺氧、**胎兒先露部位壓迫**會陰與周圍構造；經 **S2–S4**（陰部神經）傳導（詳見 [[labor-pain-relief#pain-sources]]）
- 時限
   1. 課本：初產婦約 2 小時（有硬膜外麻醉約 3 小時）
   2. **ACOG／SMFM 2014**：初產婦**用力至少 3 小時**、經產婦至少 2 小時才算停滯（有硬膜外麻醉可更久）
   3. WHO 2018：初產婦通常 3 小時內、經產婦 2 小時內
- 用力方法與會陰保護見 [[intrapartum-care#second-stage-care]]

::questions{ids="114-2_OP_022,113-1_OP_008"}

### 第三產程 {#third-stage}

- **胎盤剝離的徵象**
   1. 子宮變**圓、硬**，子宮底**上升**
   2. 陰道外的**臍帶變長**
   3. 突然一陣**出血**
- 胎盤娩出方式

| | **希氏法**(Schultze) | **鄧氏法**(Duncan) |
|---|---|---|
| 剝離位置 | 從**中央**開始 | 從**邊緣**開始 |
| 先娩出的面 | **胎兒面**（光滑、發亮、灰白） | **母體面**（**暗紅、粗糙**） |
| 出血 | 胎盤娩出**後**才出血（血包在胎膜內） | 剝離時就有出血 |
| 剝離不完全 | 較少 | **較易**剝離不完全、**碎片殘留** |
| 頻率 | 約 80% | 約 20% |

- **胎盤碎片殘留**：子宮收縮不良 → 產後出血，常是**晚期產後出血**（產後 24 小時到 12 週）的主因；處置是清除子宮內的殘留組織（見 [[postpartum-complications#retained-placenta]]）
- 胎盤娩出後要檢查胎盤與胎膜是否完整、臍帶血管數（2 動脈 1 靜脈，見 [[fertilization-embryology#umbilical-cord]]）
- 第三產程的護理見 [[intrapartum-care#third-stage-care]]

::questions{ids="112-1_OP_012,112-1_OP_032"}

### 第四產程 {#fourth-stage}

- 胎盤娩出後 **1–2 小時**，產後出血最危險的時期
- 子宮底應在**肚臍附近**、硬而圓；護理見 [[intrapartum-care#fourth-stage-care]]

## 母體與胎兒對分娩的反應 {#responses}

- 母體
   1. **心血管**：每次宮縮把約 300–500 mL 血液擠回循環 → 心輸出量增加、血壓上升；**仰臥**時子宮壓迫下腔靜脈 → 低血壓
   2. **呼吸**：耗氧量增加；疼痛、焦慮可能**換氣過度** → 呼吸性鹼中毒（處理見 [[labor-pain-relief#hyperventilation]]）
   3. **腸胃**：蠕動與排空**變慢**，容易噁心嘔吐
   4. **泌尿**：胎頭壓迫膀胱 → 不易察覺尿意、**膀胱脹**會阻礙胎頭下降
   5. 體溫可輕度上升、白血球可上升（可達 2–3 萬）
- 胎兒
   1. 宮縮時胎盤血流暫時減少，健康胎兒可以耐受；胎心率反應見 [[intrapartum-fetal-monitoring]]
   2. 經過產道擠壓排出肺內液體，有助於出生後呼吸
   3. 胎頭受壓可出現**產瘤**、塑形
