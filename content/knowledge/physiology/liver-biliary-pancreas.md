肝臟是人體最大的腺體，同時負責製造膽汁、處理腸道吸收來的養分、合成蛋白質與解毒；胰臟的外分泌部製造消化酶。本頁整理肝臟的位置與韌帶、雙重血液供應、肝小葉構造、肝臟功能、膽汁與膽道、膽紅素代謝與黃疸、胰液；消化道其他部分見 [[gi-anatomy-physiology]]，胰島素與升糖素見 [[glucose-homeostasis]]，肝炎見 [[viral-hepatitis]]，肝癌見 [[liver-cancer]]

## 重點摘要 {#summary}

- 肝臟在**右上腹**、約占體重 2%(《內外科護理學》下冊 p.310)；**鐮狀韌帶**連到前腹壁與橫膈，下緣的**肝圓韌帶**是胎兒**臍靜脈**退化而成
- **肝門**有肝動脈、門靜脈、肝管進出；**下腔靜脈不經肝門**(在肝後面，接收肝靜脈)
- 雙重血液：**門靜脈**帶腸道吸收的養分(血量較多)、**肝動脈**(腹腔動脈幹分支)帶充氧血
- 肝小葉：以**中央靜脈**為中心的六角形，角落是**門脈三合體**(肝動脈、門靜脈、膽管分支)；血液經**竇狀隙**流向中央靜脈，竇狀隙內有**庫佛氏細胞**
- 肝臟**製造**膽汁、合成白蛋白與凝血因子、儲存肝醣；**膽囊才儲存膽汁**；抗體由漿細胞製造
- 膽道：總肝管＋**膽囊管 → 總膽管**；總膽管＋**主胰管 → 肝胰壺腹** → 開口在**十二指腸**
- 膽汁大部分是水；**膽鹽乳化脂肪**，經**腸肝循環**回收的比例最高
- 胰液弱鹼性(碳酸氫鹽中和胃酸)，含澱粉酶、脂解酶(與**輔脂解酶**)、蛋白酶原；胰管注入**十二指腸**

### 國考常考點 {#exam-points}

- 肝圓韌帶是**臍靜脈**(不是臍動脈)退化；連肝到前腹壁與橫膈的是**鐮狀韌帶**
- **不經過肝門**的是下腔靜脈；尾葉右側是**下腔靜脈**
- 肝小葉以**中央靜脈**為中心(不是肝動脈)；**中央靜脈不屬於**門脈三合體
- 竇狀隙管壁是**內皮細胞**(不是肝細胞)，同時接收門靜脈與肝動脈的血、流向中央靜脈；**庫佛氏細胞在竇狀隙**
- 供應肝臟充氧血的是**腹腔動脈幹**(肝總動脈)；把腸道養分帶進肝的是**肝門靜脈**
- **頸段食道**的靜脈不經肝門靜脈(走甲狀腺下靜脈)
- 膽汁由**肝臟製造、注入十二指腸**；膽汁中比率最高的是**水**；腸肝循環回收比例最高的是**膽鹽**
- 脂肪乳化需要**膽鹽與磷脂質**
- 總膽管＝**總肝管＋膽囊管**；肝胰壺腹＝**總膽管＋主胰管**
- 膽囊黏膜是**單層柱狀上皮**、在方形葉**右側**、只儲存不製造膽汁；CCK 由**十二指腸**分泌
- 肝臟功能**不包括儲存膽汁**(106-2_makeup_MS_011 答案 C；「合成抗體」其實也不是肝臟功能，抗體由漿細胞製造)
- 胰臟主要血管來自**脾動脈**；胰管與副胰管都注入**十二指腸**(不是空腸)
- 能分解脂肪與蛋白質的消化酶來自**胰臟**；胰液**不能**把醣分解成單醣(雙醣由刷狀緣酵素分解)
- **輔脂解酶由胰臟分泌**，本身沒有脂解作用
- 新生兒照光治療：把非結合膽紅素**光異構化**成水溶性，不經肝臟結合就能排出
- 黃疸：**灰白便**(不是橘色便)、茶色尿、皮膚癢、鞏膜黃
- 溶血性黃疸：**肝功能正常**、PT 正常、尿中**沒有**膽紅素、以**非結合膽紅素**上升為主
- 阻塞性黃疸：**PT 延長**(維生素 K 吸收不良)、**ALP 上升**、灰白便、尿中出現**膽紅素**

## 肝臟的位置、分葉與韌帶 {#liver-anatomy}

- 位置：右上腹，橫膈下方，大部分被肋骨保護
- 分葉：**右葉、左葉**(以鐮狀韌帶分開)，下面另有**方形葉**(膽囊與肝圓韌帶之間)與**尾葉**(下腔靜脈與靜脈韌帶之間)

| 構造 | 重點 |
|---|---|
| **鐮狀韌帶** | 腹膜反摺，把肝臟連到**前腹壁與橫膈** |
| **肝圓韌帶** | 在鐮狀韌帶下緣，一端到肚臍；胎兒**臍靜脈**閉鎖形成，**不是腹膜反摺**；在肝左葉與方形葉之間 |
| 靜脈韌帶 | 胎兒靜脈導管閉鎖形成 |
| 冠狀韌帶 | 肝臟上面連到橫膈的腹膜反摺 |
| **肝門** | **肝固有動脈、肝門靜脈、左右肝管**、神經與淋巴進出；**下腔靜脈不經過** |

## 雙重血液供應 {#blood-supply}

| 血管 | 來源 | 帶來 |
|---|---|---|
| **肝門靜脈** | 腸繫膜上靜脈＋脾靜脈(收胃、腸、胰、脾的靜脈血) | **腸道吸收的養分**、毒素與藥物；占肝臟血量的大部分 |
| **肝動脈** | **腹腔動脈幹** → 肝總動脈 → 肝固有動脈 | **充氧血** |
| 肝靜脈 | 中央靜脈匯集 → 肝靜脈 → **下腔靜脈** | 離開肝臟 |

- 經肝門靜脈回流：胃、小腸、大腸、胰、脾、闌尾，直腸上段經腸繫膜下靜脈也進門靜脈
- **頸段食道**的靜脈回流到甲狀腺下靜脈(體循環)，不經門靜脈
- 門靜脈與體循環的交通處(食道下段、直腸、臍周)在門脈高壓時擴張成靜脈曲張(見 [[liver-cirrhosis#portal-hypertension]])

## 肝小葉 {#lobule}

::figure{src="/knowledge-images/servier-liver-lobule.svg" labels="liver-lobule" alt="肝小葉：中央靜脈、肝細胞板、竇狀隙、庫佛氏細胞、膽小管，底部是門脈三合體的肝動脈、門靜脈與膽管分支"}

- 肝小葉是肝臟的**構造與功能單位**，約略呈**六角形**
- 中心是**中央靜脈**；肝細胞排成板狀，從中央靜脈向外輻射
- 六角形角落是**門脈三合體**：**肝動脈分支、門靜脈分支、膽管**(中央靜脈不在裡面)
- **竇狀隙**：肝細胞板之間的寬大微血管，管壁是**有孔的內皮細胞**；同時接收**門靜脈與肝動脈**的血，往**中央靜脈**流
- **庫佛氏細胞**：位在**竇狀隙**的巨噬細胞，吞噬細菌與老化紅血球
- 膽汁的方向相反：肝細胞分泌到**膽小管** → 往外流到門脈三合體的**膽管**

## 肝臟的功能 {#functions}

| 類別 | 功能 |
|---|---|
| 醣類 | 葡萄糖合成**肝醣**儲存、肝醣分解、糖質新生(見 [[glucose-homeostasis]]) |
| 蛋白質 | 合成**白蛋白**、**凝血因子**(凝血酶原等，需要維生素 K)；把**氨轉成尿素** |
| 脂質 | 合成膽固醇、脂蛋白(VLDL)、**膽鹽** |
| 儲存 | 肝醣、脂溶性維生素(A、D、E、K)、維生素 B12、鐵、銅 |
| 解毒與代謝 | 藥物、酒精、激素的代謝與去活化 |
| 膽汁 | **製造**膽汁(每天約 1,000 mL，《內外科護理學》下冊 p.311)、結合膽紅素 |
| 免疫 | 庫佛氏細胞吞噬 |

- 肝臟**不儲存膽汁**(膽囊儲存)，也**不合成抗體**(漿細胞製造)
- 肝功能衰退時：白蛋白下降(水腫、腹水)、凝血因子下降(出血、PT 延長)、血氨上升(肝性腦病變)、雌激素代謝差(男性女乳、蜘蛛痣)，詳見 [[liver-cirrhosis#manifestations]]

## 膽汁與膽道 {#bile}

- 膽汁成分：大部分是**水**，其餘是**膽鹽**、膽色素(膽紅素)、膽固醇、磷脂質(卵磷脂)、電解質；**沒有消化酶**
- **膽鹽＋磷脂質**把大油滴**乳化**成小油滴，讓脂解酶作用，並組成微粒幫忙吸收(見 [[gi-anatomy-physiology#digestion-absorption]])
- **腸肝循環**：膽鹽在**迴腸末端**再吸收，經門靜脈回肝重新分泌，**回收比例最高**(九成以上)；迴腸切除會造成膽鹽流失與脂肪吸收不良

### 膽道 {#biliary-tree}

- 左、右肝管 → **總肝管**；總肝管＋**膽囊管 → 總膽管**
- 總膽管＋**主胰管 → 肝胰壺腹**(華特氏壺腹)，由**歐迪氏括約肌**控制，開口在**十二指腸**(大十二指腸乳頭)
- **膽囊**：在肝右葉下面、**方形葉右側**；黏膜是**單層柱狀上皮**；**儲存並濃縮**膽汁(不製造)
- 進食脂肪 → **十二指腸**分泌 **CCK** → 膽囊收縮、歐迪氏括約肌放鬆 → 膽汁流入十二指腸
- 膽結石、膽囊炎與 T 型管照護：見 [[biliary-pancreatic]]

## 膽紅素代謝與黃疸 {#bilirubin}

![膽紅素代謝：老化紅血球在脾臟分解成非結合膽紅素，經白蛋白運到肝臟結合，隨膽汁到腸道變成尿膽素原與糞膽素，部分經腸肝循環與腎臟排出；圖中標示三型黃疸的位置](/knowledge-images/bilirubin-metabolism.svg)

- 紅血球(壽命約 120 天)在脾臟被巨噬細胞分解：血紅素 → 血基質 → 膽綠素 → **非結合膽紅素**(間接型、**脂溶性**，與**白蛋白**結合運送，不能從尿排出)
- 肝細胞用**葡萄糖醛酸轉移酶**把它變成**結合膽紅素**(直接型、**水溶性**) → 隨膽汁進腸道
- 腸道細菌把它變成**尿膽素原**：大部分變成**糞膽素**(糞便呈棕色)；部分再吸收，經門靜脈回肝(腸肝循環)，少量經腎臟從尿排出
- **新生兒照光治療**：藍光把皮膚中的非結合膽紅素**光異構化**成水溶性的異構物，不需肝臟結合就能隨膽汁與尿排出(新生兒黃疸見兒科頁)

| 項目 | **溶血性**(肝前) | 肝細胞性 | **阻塞性**(肝後) |
|---|---|---|---|
| 原因 | 紅血球破壞太多(溶血性輸血反應、G6PD 缺乏) | 肝炎、肝硬化 | 膽結石、胰頭癌、膽道閉鎖 |
| 血中膽紅素 | **非結合**為主 | 兩種都上升 | **結合**為主 |
| 尿中膽紅素 | **沒有** | 有 | **有**(茶色尿) |
| 尿中尿膽素原 | **增加** | 增加或正常 | 減少或沒有 |
| 糞便 | 顏色較深 | 較淡 | **灰白色(陶土色)** |
| 肝功能 | **正常** | AST、ALT 上升 | **ALP**、GGT 上升 |
| 凝血酶原時間 | 正常 | 延長(合成差) | **延長**(脂溶性維生素 K 吸收不良，補充 K 可矯正) |
| 其他 | 貧血 | — | **皮膚搔癢**(膽鹽沉積)、脂肪便 |

- 黃疸的表現：**鞏膜**最先看到黃、皮膚黃、茶色尿；糞便是**灰白色**(不是橘色)
- 尿中出現膽紅素表示血中**結合膽紅素**上升，最常見於**阻塞性黃疸**
- 肝功能檢驗數值與判讀見 [[liver-function]]

## 胰臟的外分泌 {#pancreas}

- 位置：在**胃後方**、腹膜後；胰頭在十二指腸 C 形彎內，胰尾靠近脾臟
- 血液：主要來自**脾動脈**分支，胰頭另有胰十二指腸動脈
- 外分泌部占絕大部分(**腺泡細胞**製造消化酶，導管細胞分泌碳酸氫鹽)；內分泌部是**蘭氏小島**(胰島素、升糖素，見 [[glucose-homeostasis]])
- 胰管：**主胰管**與總膽管會合成肝胰壺腹；**副胰管**單獨開口；兩者都注入**十二指腸**

| 胰液成分 | 作用 |
|---|---|
| **碳酸氫鹽**(受**胰泌素**刺激) | 弱鹼性，**中和**從胃來的酸性食糜 |
| 胰澱粉酶 | 澱粉 → 雙醣(再由刷狀緣酵素分解成單醣) |
| **胰脂解酶**＋**輔脂解酶** | 三酸甘油酯 → 單酸甘油酯＋游離脂肪酸；輔脂解酶由胰臟分泌，把脂解酶固定在油滴表面，本身沒有脂解作用 |
| 蛋白酶原(胰蛋白酶原、胰凝乳蛋白酶原) | 以**沒有活性**的形式分泌，在十二指腸由**腸激酶**活化，避免消化胰臟自己 |
| 核酸酶 | 分解核酸 |

- 消化酶的分泌主要受 **CCK** 刺激；胰臟酵素提早在胰臟內活化就是胰臟炎(見 [[biliary-pancreatic#acute-pancreatitis]])
