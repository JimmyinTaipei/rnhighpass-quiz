皮膚是全身面積最大的器官，國考生理解剖常考表皮分層、各種細胞與受器的位置、三種腺體的差別。本頁整理構造、附屬器與功能；皮膚病灶與常見皮膚病見 [[skin-diseases]]，燒傷的深度與照護見 [[burns]]，體溫調節見 [[body-temperature#regulation]]

## 重點摘要 {#summary}

- 三層：**表皮**(角質化複層鱗狀上皮，**沒有血管**，養分靠真皮擴散)→ **真皮**(結締組織，**有微血管**、神經、毛囊與腺體)→ **皮下組織**(脂肪與較大血管，不屬於皮膚本身)
- 表皮五層(由深到淺)：**基底層 → 棘狀層 → 顆粒層 → 透明層 → 角質層**
   1. **基底層**細胞會分裂增生，往上推；**黑色素細胞**與 **Merkel 細胞**在這層
   2. **透明層只在厚皮膚**(手掌、腳底)；薄皮膚只有四層
   3. 最淺的**角質層**細胞已死亡、**完全角質化**
- 表皮的四種細胞：**角質細胞**(最多)、**黑色素細胞**(基底層，製造黑色素擋紫外線)、**蘭氏細胞**(抗原呈現，免疫)、**Merkel 細胞**(**表皮觸覺**)
- 真皮：**乳頭層**(疏鬆結締組織，有觸覺小體與微血管環)、**網狀層**(緻密不規則結締組織，大量膠原纖維，有**巴齊尼小體**感受壓覺與振動)
- 腺體：**皮脂腺**(全泌腺，開口**毛囊**)、**外泌汗腺**(全身，手掌腳底最多，開口**皮膚表面**，汗液無臭，散熱)、**頂漿汗腺**(腋下、乳暈、會陰，開口**毛囊**，青春期後活躍，細菌分解後產生**體臭**)

### 國考常考點 {#exam-points}

- 黑色素細胞在**基底層**；「網狀層」是真皮，不是表皮的一層
- 表皮**沒有血管**、**沒有纖維母細胞**(纖維母細胞在真皮)；底層細胞**具增生功能**；屬複層**鱗狀**上皮，不是柱狀
- 最淺層表皮細胞**完全角質化**；最底層不角質化；厚皮膚五層，薄皮膚四層(不是兩層)
- 真皮**含豐富微血管**、由結締組織組成、分**乳頭層與網狀層**(基底層是表皮)；傷及真皮是**二度**燒傷
- **眼瞼**皮膚最薄；角質層最厚在**手掌、腳底**(不是頭皮)；皮脂腺在**真皮**，不在皮下組織
- **巴齊尼小體**在**網狀層**(深層真皮到皮下)；**Merkel 細胞**傳遞表皮觸覺
- 皮脂腺導管**大多開口於毛囊**、是**全泌腺**；**耵聹腺是特化的汗腺**(頂漿型)，不是皮脂腺
- 汗腺導管**直接開口於皮膚表面**、只受**交感神經**支配；頂漿汗腺排泄管開口於毛囊
- **外泌汗腺分泌液不會產生體臭**；指甲每天長約 **0.1 mm**；毛囊可深達皮下組織
- 曬太陽使黑色素**合成增加**，不是黑色素細胞數量大量增加

## 表皮 {#epidermis}

### 表皮的分層 {#epidermal-layers}

| 層(由深到淺) | 特點 |
|---|---|
| **基底層**(生發層) | 單層立方或柱狀細胞，**持續分裂**；有**黑色素細胞**、**Merkel 細胞** |
| **棘狀層** | 數層細胞以胞橋小體相連，**蘭氏細胞**多在此層 |
| **顆粒層** | 細胞開始角質化，內含角質透明顆粒，細胞核退化 |
| **透明層** | **只在厚皮膚**(手掌、腳底)，透明扁平死細胞 |
| **角質層** | 最外層，**完全角質化的死細胞**，不斷脫落；防水、防摩擦 |

- 新細胞從基底層推到角質層再脫落，約需 4 週(書頁 1035，待核對)
- 表皮**沒有血管**，靠真皮乳頭層微血管擴散供應養分；所以只傷到表皮的擦傷不會流血

### 表皮的細胞 {#epidermal-cells}

| 細胞 | 位置 | 功能 |
|---|---|---|
| **角質細胞**(Keratinocyte) | 各層，數量最多 | 製造角蛋白，形成保護屏障 |
| **黑色素細胞**(Melanocyte) | **基底層** | 製造黑色素傳給角質細胞，**吸收紫外線**；膚色深淺取決於**黑色素的量**，各人種黑色素細胞數目差不多 |
| **蘭氏細胞**(Langerhans cell) | 棘狀層 | 捕捉抗原、呈現給 T 細胞，屬皮膚免疫 |
| **Merkel 細胞** | **基底層** | 與感覺神經末梢相接，**傳遞觸覺**(辨識形狀、質地) |

- 紫外線刺激黑色素細胞**多製造黑色素**，膚色變深；不是細胞數量大量增加
- 蘭氏細胞在接觸性皮膚炎中負責呈現過敏原，見 [[allergic-contact-dermatitis-latex#acd-mechanism]]

## 真皮與皮下組織 {#dermis}

| 層 | 組成 | 內含 |
|---|---|---|
| **乳頭層**(真皮上 1/5) | **疏鬆**結締組織，向上突起形成真皮乳頭(指紋) | 微血管環、**觸覺小體**(Meissner，輕觸) |
| **網狀層**(真皮下 4/5) | **緻密不規則**結締組織，大量**膠原纖維**與彈性纖維 | 毛囊、皮脂腺、汗腺、較大血管、**巴齊尼小體**(壓覺、振動) |
| **皮下組織** | 疏鬆結締組織與**脂肪** | 較大血管與神經；保溫、緩衝、儲存能量；皮下注射打在這層 |

- 真皮主要細胞是**纖維母細胞**(製造膠原與彈性纖維)，還有肥大細胞、巨噬細胞
- 皮膚厚度：**眼瞼最薄**，背部真皮最厚；**手掌、腳底角質層最厚**
- 老化：真皮膠原與彈性纖維減少 → 皺紋、彈性差；皮下脂肪變薄 → 怕冷、易受壓傷；感覺受器減少 → 對壓力與溫度的感覺變差
- 傷口癒合的過程見 [[bandaging#wound-healing]]

## 表皮衍生物 {#appendages}

### 毛髮與指甲 {#hair-nails}

- 毛髮：**毛幹**露出皮膚，**毛根**包在毛囊內；毛囊由表皮往下陷入真皮，常深達**皮下組織**；底部的毛乳頭供應養分
- **豎毛肌**是平滑肌，受交感神經支配，收縮時毛髮豎起(雞皮疙瘩)，並擠壓皮脂腺排出皮脂
- 指甲：由**甲母質**持續生長，**每天約 0.1 mm**；甲床的血色可用來看末梢循環(微血管回填)

### 三種腺體 {#glands}

| | 皮脂腺 | 外泌汗腺(小汗腺) | 頂漿汗腺(大汗腺) |
|---|---|---|---|
| 分泌方式 | **全泌腺**(整個細胞解體成為分泌物) | 局部分泌(細胞不受損) | 舊稱頂漿分泌，現認為也是局部分泌 |
| 位置 | 全身(**手掌、腳底沒有**)，頭臉最多；腺體在**真皮** | **全身**，**手掌、腳底**、額頭最多 | **腋下、乳暈、肛門與會陰**、肚臍周圍 |
| 開口 | **毛囊** | **直接開口於皮膚表面** | **毛囊** |
| 分泌物 | 皮脂，潤滑皮膚毛髮、抑菌 | 清澈、稀薄、**無臭**的水與鹽 | 黏稠，含蛋白與脂質；細菌分解後產生**體臭** |
| 調控 | 雄性素 | **交感神經**(膽鹼性)；**散熱** | 交感神經(腎上腺素性)；**青春期後**才活躍 |

- 特化腺體：**耵聹腺**(外耳道，耳垢)與睫毛的腺體是**特化的頂漿型汗腺**；乳腺也是特化的汗腺
- 青春期雄性素增加 → 皮脂分泌增多 → 青春痘

## 皮膚的功能 {#functions}

1. **保護**：角質層與皮脂形成物理與化學屏障(弱酸性)，防水、防微生物入侵；黑色素擋紫外線
2. **免疫**：蘭氏細胞呈現抗原
3. **感覺**：觸覺(Merkel 細胞、觸覺小體)、壓覺與振動(巴齊尼小體)、痛覺與溫度覺(游離神經末梢)
4. **體溫調節**：流汗蒸發散熱、皮膚血管擴張或收縮；見 [[body-temperature#regulation]]
5. **合成維生素 D**：紫外線照射皮膚，把 7-去氫膽固醇轉成維生素 D₃，再經肝、腎活化(見 [[calcium-phosphate]])
6. **排泄與吸收**：汗液排出少量尿素與鹽；脂溶性藥物可經皮吸收(貼片)
7. 皮膚失去完整性(燒傷)時，這些功能都受影響：體液流失、體溫過低、感染，見 [[burns#pathophysiology]]
