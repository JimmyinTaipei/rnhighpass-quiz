**免疫系統**的任務是分辨「自己」與「外來或異常」，並清除後者。它不是單一器官，而是由**障壁、免疫器官、免疫細胞與可溶性分子**組成的網絡。這一頁先畫出整張地圖，再詳細說明**先天免疫**；補體、發炎、T 細胞、B 細胞與抗體各有自己的頁面

## 重點摘要 {#summary}

- 免疫有三道防線：**障壁**(皮膚、黏膜、胃酸、溶菌酶、正常菌叢)、**先天免疫**(吞噬細胞、NK、補體、發炎、干擾素)、**後天免疫**(T 細胞、B 細胞、抗體)
- **先天免疫**：快、非特異、沒有典型記憶；**後天免疫**：慢、對特定抗原、有記憶
- **嗜中性球**是最多也最早到感染處的吞噬細胞；**巨噬細胞**由**單核球**分化；**NK 細胞**殺病毒感染與腫瘤細胞
- **胸腺**淘汰自體反應性 T 細胞；**脾臟**過濾血液；**淋巴結**過濾淋巴液；骨髓與胸腺是**中央**淋巴器官
- 新生兒：**IgG 過胎盤**、**IgM 不過胎盤**；**母乳(初乳)的分泌型 IgA** 保護腸道

### 國考常考點 {#exam-points}

- 胃酸、消化酶、皮膚、黏膜屬**先天(非特異性)**免疫，不是特異性免疫
- **嗜中性球**：多型核白血球、血液中最多的吞噬細胞、最早聚集到感染處、屬**先天**免疫；死亡的嗜中性球由**巨噬細胞**清除
- **巨噬細胞來自單核球**；肝臟 **Kupffer 細胞**、表皮**蘭氏細胞**都是組織中的吞噬與免疫細胞
- **TLR4** 辨識革蘭氏陰性菌的**脂多醣**(內毒素)；TLR 位於細胞膜或內體膜；內毒素是**脂多醣，不是蛋白質**
- **細胞毒殺性 T 細胞不是先天免疫細胞**；NK 細胞、巨噬細胞、肥大細胞是
- **胸腺**的功能：剔除自體反應性 T 細胞(中樞耐受)；**松果腺、腮腺不是**淋巴器官／組織
- 淋巴液在**頸內靜脈與鎖骨下靜脈交會處**匯入靜脈；淋巴循環**不是**用來回收鉀離子
- 新生兒血液或臍帶血 **IgM 升高** = 子宮內感染(TORCH)；**IgG** 是唯一能通過胎盤的抗體；胎兒無法自製 **IgA**，由母乳獲得

## 免疫系統的全貌 {#overview}

### 三道防線 {#three-lines}

| 防線 | 成分 | 特異性 | 速度 | 記憶 |
|---|---|---|---|---|
| **第一道：障壁** | 皮膚、黏膜、纖毛、胃酸、溶菌酶、抗菌胜肽、正常菌叢 | 非特異 | 立即 | 無 |
| **第二道：先天免疫反應** | 吞噬細胞、NK 細胞、肥大細胞、補體、發炎、發燒、干擾素 | 非特異(辨識病原共有的模式) | 數分鐘到數小時 | 無典型記憶 |
| **第三道：後天免疫反應** | T 淋巴球、B 淋巴球、抗體 | 特異(針對某個抗原) | 初次反應數天到數週 | 有 |

先天免疫的重要性在於「爭取時間」：多數細菌每 20 至 30 分鐘就分裂一次，而後天免疫要數天到數週才能做出抗體與專一的 T 細胞(UpToDate)

### 先天與後天免疫比較 {#innate-vs-adaptive}

| 項目 | 先天免疫 | 後天免疫 |
|---|---|---|
| 辨識的受體 | **PRR**(類鐸受體等)，由胚系基因直接編碼，不重組 | **TCR 與 BCR**，經基因重組，每個淋巴球的受體都不同 |
| 辨識對象 | 病原共有的分子模式(**PAMP**)與受損細胞釋出的分子(**DAMP**) | 特定抗原的小片段(抗原決定位) |
| 反應速度 | 分鐘到小時 | 初次接觸要數天到數週 |
| 記憶 | 沒有典型記憶(但可被「訓練」，見下方) | 有；再次接觸反應更快更強 |
| 主要細胞 | 嗜中性球、單核球與巨噬細胞、樹突細胞、NK 細胞、肥大細胞、嗜酸性球、嗜鹼性球 | T 淋巴球、B 淋巴球(漿細胞) |
| 可溶性成分 | 補體、溶菌酶、防禦素、CRP、干擾素 | 抗體 |
| 遺傳 | 出生時就有，由父母遺傳 | 出生後接觸抗原才發展；學到的反應**不會**遺傳給下一代 |

- **NK 細胞與先天淋巴細胞(ILC)**雖然是淋巴球，但沒有抗原專一的受體，屬於先天免疫
- 兩套系統不是各做各的：先天免疫(樹突細胞、巨噬細胞)負責**呈現抗原與提供活化訊號**給後天免疫；後天免疫的抗體與細胞激素又**強化**先天免疫(例如抗體幫助吞噬、T 細胞釋出的 IFN-γ 活化巨噬細胞)

:::basics[先天免疫也能被「訓練」？]
過去認為先天免疫沒有記憶，但近年發現接觸過感染、**卡介苗(BCG)**、麻疹腮腺炎德國麻疹疫苗或微生物成分(例如 LPS)後，巨噬細胞等細胞的反應會被**表觀遺傳修飾**調高，下一次遇到同一種甚至不相干的病原時反應更強，稱為**訓練免疫**(trained immunity)

1. 機轉：改變基因轉錄的調控，不是基因重組，所以和 T、B 細胞的記憶不同
2. 時間：單核球與嗜中性球壽命短，但骨髓的造血幹細胞能保留這種記憶，持續產生被訓練過的細胞
3. 意義：出生時接種 BCG 可降低低體重嬰兒的感染死亡率(UpToDate 引用的臨床試驗)；也是疫苗有「非特異性保護」說法的背景

來源：UpToDate：An overview of the innate immune system
:::

### 主動免疫與被動免疫 {#active-passive}

- **主動免疫**：自己產生抗體與記憶細胞，保護久、產生慢；來源是感染後痊癒或**接種疫苗**
- **被動免疫**：直接得到現成的抗體，效果快、維持短；來源是**經胎盤的 IgG**、**母乳的 IgA**、注射免疫球蛋白或單株抗體
- 表格與疫苗細節見 [[immunization#immunity-types]]

## 免疫器官與淋巴循環 {#lymphoid-organs}

淋巴球在**中央(初級)淋巴器官**發育成熟，離開後在**周邊(次級)淋巴器官**遇到抗原並展開免疫反應

### 中央與周邊淋巴器官 {#primary-secondary}

| 器官 | 類型 | 功能與考點 |
|---|---|---|
| **骨髓** | 中央 | 所有血球的來源；**B 細胞**在此發育與選擇；T 細胞的前驅細胞也從這裡出發 |
| **胸腺** | 中央 | **T 細胞**發育成熟；皮質做**正向選擇**、髓質做**負向選擇**，**剔除自體反應性 T 細胞**(中樞耐受)；位於縱膈腔前方，**幼年最大**，青春期後逐漸萎縮 |
| **淋巴結** | 周邊 | **過濾淋巴液**；皮質有淋巴濾泡(B 細胞、生發中心)，副皮質是 T 細胞區，髓質有漿細胞與巨噬細胞；**內有巨噬細胞與樹突細胞**；**輸入淋巴管多於輸出淋巴管** |
| **脾臟** | 周邊 | **過濾血液**；紅髓的巨噬細胞清除**衰老的紅血球與血小板**及血中病原體；白髓是 T、B 細胞反應的地方；是**血液傳播病原體**的免疫反應場所 |
| **扁桃體(扁桃腺)** | 周邊 | 位於**咽部**(消化道與呼吸道的交會處)的淋巴小結，對經口與經鼻的病原產生免疫；屬周邊而**非**中央淋巴器官 |
| **黏膜相關淋巴組織(MALT)** | 周邊 | 呼吸道與消化道黏膜下的淋巴組織；**小腸的派亞氏斑**(Peyer's patch，GALT)監測腸道抗原、產生分泌型 IgA；闌尾也屬於 |

- **不屬於**淋巴器官或淋巴組織的常見陷阱：**松果腺**(內分泌)、**腮腺**(唾液腺)
- 脾臟切除或無脾的人，對有莢膜的細菌(肺炎鏈球菌、B 型嗜血桿菌、腦膜炎雙球菌)特別容易重症感染，要接種相關疫苗([[immunization]])
- 免疫老化的一個原因是**胸腺萎縮**：新生的 naive T 細胞變少，老年人對新抗原(包括疫苗)的反應變差

:::note[題目陷阱：扁桃體的位置]
107-2 生解 027 的標準答案把扁桃體的位置寫成「食道與氣管交會處」，實際指的是**咽部**(消化道與呼吸道的交會處)；解剖上扁桃體在咽的側壁與後壁，不是食道或氣管本身，這題依公布答案作答

### 淋巴管與淋巴循環 {#lymphatic-circulation}

1. 路徑：組織間液進入**微淋巴管**(盲端，管壁細胞重疊成單向的瓣) → 淋巴管(有瓣膜，經過淋巴結) → 淋巴幹 → 兩條淋巴導管 → **靜脈角**
   1. 右淋巴導管：收集**右上半身**的淋巴
   2. **胸管**：收集其餘大部分，包括下半身與左上半身；起點在腹部的乳糜池
   3. 匯入處：**頸內靜脈與鎖骨下靜脈交會處**
2. 動力：淋巴管沒有心臟推動，靠**骨骼肌收縮、呼吸與瓣膜**讓淋巴單向流動
3. 功能
   1. 回收組織間液與其中的**蛋白質**，**調節血漿與組織液之間的液體平衡**
   2. 運送腸道吸收的**脂肪**與脂溶性維生素(小腸絨毛的**乳糜管**)
   3. 把病原與免疫細胞帶到淋巴結，由淋巴結清除並啟動免疫反應
   4. 清除組織中的紅血球與細菌
4. **淋巴循環不是主要回收鉀離子的途徑**(國考陷阱)
5. 淋巴阻塞(腫瘤、手術、感染)會讓富含蛋白質的組織液堆積成**淋巴水腫**

## 免疫細胞 {#cells}

### 白血球的譜系 {#leukocytes}

所有免疫細胞都由骨髓的**造血幹細胞**分化而來，分成兩條主線

1. **骨髓系**：嗜中性球、嗜酸性球、嗜鹼性球、單核球(→巨噬細胞、樹突細胞)、肥大細胞(在組織內成熟)，另外還有紅血球與血小板
2. **淋巴系**：T 細胞、B 細胞(→漿細胞)、NK 細胞、先天淋巴細胞

成人白血球分類的大致比例：嗜中性球最多(約 50–70%)，其次淋巴球(約 20–40%)、單核球、嗜酸性球，嗜鹼性球最少(不到 1%)，判讀見 [[complete-blood-count#reference-range]]

### 先天免疫的主要細胞 {#innate-cells}

1. **嗜中性球**(neutrophil，**多型核白血球**，PMN)
   1. 血液中**數量最多的吞噬細胞**，感染時**最早**被趨化到發炎部位
   2. 殺菌：吞入後與顆粒融合，靠 **NADPH 氧化酶**產生活性氧(呼吸爆發)與顆粒內的蛋白酶、防禦素
   3. 垂死時會釋放染色質網狀結構，稱**嗜中性球胞外陷阱(NET)**，捕捉並殺死微生物
   4. 壽命短，死亡後由**巨噬細胞**吞噬清除(efferocytosis)，避免釋出毒性物質造成發炎
   5. **慢性肉芽腫病**：NADPH 氧化酶基因缺陷 → 吞入的細菌殺不死，反覆發生葡萄球菌、腸道細菌與麴菌感染(之後整理在原發性免疫缺陷頁)
2. **單核球與巨噬細胞**(monocyte、macrophage)
   1. 單核球在血液循環，進入組織後分化成**巨噬細胞**或樹突細胞；**巨噬細胞由單核球分化**，不是由嗜酸性球、嗜鹼性球或淋巴球而來
   2. 功能：吞噬病原與死亡細胞、**呈現抗原**給 T 細胞、分泌 IL-1、IL-6、**TNF-α** 與補體成分、清除凋亡細胞
   3. 殺菌方式：吞噬溶酶體、**活性氧**、**一氧化氮(NO)**、分泌 TNF-α；**不包括**形成補體膜攻擊複合體
   4. 受 **IFN-γ**(由 T 細胞或 NK 細胞釋出)活化後殺菌力大增；結核菌被吞入後要靠這個訊號才殺得死
   5. 細菌入侵組織時，巨噬細胞常是**第一道防線**的吞噬細胞，嗜中性球再被招募過來
3. **樹突細胞**(dendritic cell)
   1. **最強的抗原呈現細胞**，連接先天與後天免疫
   2. 在組織中捕捉抗原後移行到淋巴結，把抗原呈現給 naive T 細胞(之後整理在 T 淋巴球頁)
   3. 表皮的**蘭氏細胞**(Langerhans cell)是樹突細胞的一種，功能是**免疫與吞噬**
4. **嗜酸性球**(eosinophil)
   1. 主要對付**寄生蟲**(蠕蟲)，也參與過敏反應；被 IL-5 招募
   2. 增多的常見原因：**過敏**(氣喘、過敏性鼻炎)、**寄生蟲感染**、天疱瘡等皮膚病
   3. **EBV 感染**增多的是**淋巴球**，不是嗜酸性球
5. **嗜鹼性球與肥大細胞**
   1. 嗜鹼性球只在**血液**中；**肥大細胞**駐留在黏膜與結締組織，兩者表面都有 **IgE 受體**
   2. 活化後釋出**組織胺**、白三烯、前列腺素等，造成**血管擴張、通透性增加、平滑肌收縮**，是第一型過敏反應的主角(之後整理在過敏反應頁)
   3. 肥大細胞也能被 TLR、補體片段 **C3a、C5a** 直接活化，在細菌感染時**早期**釋出 TNF-α 與 IL-8，招募嗜中性球
6. **自然殺手細胞**(NK cell)
   1. **先天**淋巴球，不需要事先致敏；對付**病毒感染的細胞**與**腫瘤細胞**
   2. 辨識方式：正常細胞表面的 **MHC I** 會抑制 NK 細胞；病毒感染與腫瘤細胞常**減少 MHC I**，抑制訊號消失就被殺(「缺少自我」)；細胞受壓力時表現的配體則提供活化訊號
   3. 殺傷：釋放**穿孔素與顆粒酶**，誘發目標細胞凋亡；也能靠 Fc 受體(CD16)進行**抗體依賴性細胞毒殺(ADCC)**
   4. 分泌 **IFN-γ** 活化巨噬細胞；受 IL-12、IL-15 與第一型干擾素活化
   5. **細胞毒殺性 T 細胞**同樣會釋放穿孔素與顆粒酶，但它是**後天**免疫細胞，要抗原專一活化

### 常駐組織的巨噬細胞 {#tissue-macrophages}

| 組織 | 名稱 |
|---|---|
| 肝臟 | **庫佛氏細胞**(Kupffer cell) |
| 腦與視網膜 | **微膠細胞**(microglia) |
| 肺 | 肺泡巨噬細胞(塵細胞) |
| 骨 | 蝕骨細胞 |
| 表皮 | 蘭氏細胞(樹突細胞) |
| 結締組織 | 組織球 |

- 這些常駐巨噬細胞有一部分來自**胚胎的卵黃囊或胎肝**，會**長期駐守**組織做維護與修復，不是全靠血液單核球補充(例：庫佛氏細胞)
- 巨噬細胞也是**抗原呈現細胞**，並負責維持組織恆定(清除凋亡細胞、回收鐵)

## 先天免疫的運作 {#innate-response}

### 第一道防線：障壁 {#barriers}

| 部位 | 防禦機制 |
|---|---|
| **皮膚** | 角質層的物理障壁、表面偏酸與脂肪酸、乾燥、皮膚正常菌叢；表皮蘭氏細胞 |
| **眼、口** | 淚液與唾液含**溶菌酶**(分解細菌細胞壁的胜肽聚醣)，也有沖洗作用 |
| **呼吸道** | 黏液捕捉微粒、**纖毛**向上擺動排出、咳嗽與打噴嚏、肺泡巨噬細胞 |
| **消化道** | **胃酸**、膽鹽、**消化酶**、腸蠕動；腸道正常菌叢競爭養分與附著位置；派亞氏斑與分泌型 IgA |
| **泌尿道** | 尿液沖刷；尿道結構 |
| **陰道** | **乳酸桿菌**使陰道偏酸，抑制致病菌 |
| 全身 | **抗菌胜肽**(防禦素 defensin、cathelicidin)在皮膚、黏膜與嗜中性球顆粒內，直接在微生物膜上打洞 |

- 這些都屬於**非特異性**防禦，**胃酸與消化酶不是特異性免疫**

### 正常菌叢 {#microbiota}

- 正常菌叢佔據位置、競爭養分、產生抑菌物質，並**幫助免疫系統成熟**
- **廣效抗生素**清掉腸道正常菌叢後，致病菌(困難梭狀桿菌、念珠菌)趁機增生，也會影響消化與**黏膜免疫**；與骨髓造血功能無關([[microbial-pathogenesis#host-defense]])

### 病原體的辨識：PRR 與 PAMP {#pattern-recognition}

先天免疫細胞不認識「某一種」病原，而是認得**微生物共有、不易突變的分子模式**

1. **PAMP**(病原體相關分子模式)：只有微生物有、整類病原共有、對微生物生存很重要所以不能輕易突變的結構
   1. 革蘭氏陰性菌的**脂多醣**(LPS，內毒素)，其中的 lipid A 最重要
   2. 細菌的胜肽聚醣、脂磷壁酸、鞭毛蛋白
   3. 未甲基化的微生物 DNA(CpG)
   4. 病毒的雙股 RNA
   5. 真菌的 β-葡聚醣
2. **DAMP**(危險相關分子模式，又稱 alarmin)：受傷或壞死的宿主細胞釋出的核蛋白、熱休克蛋白、ATP 等，讓沒有感染的組織傷害也能引起發炎
3. **PRR**(模式辨識受體)：辨識 PAMP 與 DAMP 的受體，分成
   1. **類鐸受體(TLR)**：在**細胞膜或內體膜**上(不是只在樹突細胞、也不是在細胞核)，**不需要先有病原刺激才表現**
   2. **NOD 樣受體(NLR)**：細胞質內，組成**發炎體**(inflammasome)，活化 caspase-1 後產生 **IL-1β 與 IL-18**
   3. **RIG-I 樣受體(RLR)**：細胞質內辨識病毒 RNA，誘發**第一型干擾素**
   4. C 型凝集素受體：例如辨識真菌 β-葡聚醣的 dectin-1、巨噬細胞的甘露糖受體
   5. 可溶性 PRR：甘露糖結合凝集素(MBL)、**C 反應蛋白(CRP)**、補體的 C1q，可當調理素或啟動補體

| TLR | 辨識對象 |
|---|---|
| **TLR4** | **革蘭氏陰性菌脂多醣(LPS)**；是最先被發現的 TLR，對 LPS 極敏感 |
| TLR2(與 TLR1 或 TLR6 成對) | 細菌的脂蛋白(也包括革蘭氏陽性菌的脂磷壁酸與胜肽聚醣) |
| TLR5 | 鞭毛蛋白 |
| TLR3、TLR7、TLR8、TLR9 | **病毒與細菌的核酸**(TLR3：雙股 RNA；TLR7、8：單股 RNA；TLR9：CpG DNA)，位於**細胞內的內體**，促進第一型干擾素 |

來源：UpToDate：An overview of the innate immune system 的人類 TLR 表

- **內毒素是脂多醣，不是蛋白質**；它位於革蘭氏陰性菌外膜，細菌裂解時釋出，刺激先天免疫產生細胞激素，可引起**發燒與休克**([[microbial-pathogenesis#toxins]])
- 缺乏 TLR3 或其傳訊分子的人，特別容易發生嚴重的單純疱疹病毒腦炎(UpToDate)

:::basics[PRR 如何啟動發炎？]
TLR 與 IL-1 受體共用傳訊路徑：配體結合 → 接合蛋白 **MyD88** → 活化 IKK，使抑制蛋白 IκB 被磷酸化而降解 → **NF-κB** 進入細胞核 → 轉錄 **TNF-α、IL-1β、IL-6** 等促發炎細胞激素。核酸型 TLR(例如 TLR3、TLR4 的另一條路徑)則經 IRF3 產生**第一型干擾素**

來源：UpToDate：An overview of the innate immune system；Chen 2018 Oncotarget
:::

### 吞噬作用 {#phagocytosis}

1. **趨化**：感染處釋出的訊號形成濃度梯度，吞噬細胞往高濃度走
   1. 嗜中性球的趨化因子：**C5a**、IL-8、白三烯 B4、細菌的 N-甲醯胜肽
   2. 白血球怎麼穿出血管，見 [[inflammation-repair#leukocyte-extravasation]]
2. **辨識與附著**：直接由 PRR 辨識，或靠**調理素**(opsonin)包住病原再被辨識
   1. 主要調理素：補體的 **C3b**、抗體 **IgG**、CRP
   2. 吞噬細胞表面有 C3b 的受體(CR1、CR3)與 IgG 的 Fc 受體
3. **吞入**：形成吞噬小體(phagosome)
4. **融合**：與溶酶體融合成**吞噬溶酶體**
5. **殺菌**
   1. 氧依賴：**呼吸爆發**，NADPH 氧化酶產生超氧陰離子、過氧化氫、次氯酸；巨噬細胞還會產生一氧化氮
   2. 氧非依賴：溶菌酶、防禦素、乳鐵蛋白、蛋白酶(彈性蛋白酶)
6. **排出殘渣**，巨噬細胞與樹突細胞會把抗原片段呈現給 T 細胞

### 急性期反應與發燒 {#acute-phase}

1. 巨噬細胞受刺激後釋出 **IL-1、IL-6、TNF-α**，它們是**內生性致熱原**與急性期反應的啟動者
2. **發燒**：這些細胞激素作用在**下視丘**，經前列腺素 E2 把體溫調定點調高(解熱鎮痛藥抑制前列腺素合成，所以能退燒)
3. **肝臟**製造**急性期反應物**
   1. 上升：**CRP**、血清類澱粉 A、纖維蛋白原、補體、MBL、鐵調素(使血清鐵下降)
   2. 臨床用 CRP、ESR 當發炎指標([[inflammatory-markers]])
4. 骨髓釋出更多嗜中性球，血中**白血球上升**
5. **TNF-α** 是**引起敗血症全身反應的主要因子**；大量產生會造成**休克、循環崩潰、出血性壞死**，但**不會**引起傷口癒合([[sepsis#mechanism]])

### 干擾素 {#interferons}

| 類型 | 來源 | 作用 |
|---|---|---|
| **第一型(IFN-α、IFN-β)** | **病毒感染的細胞**、漿細胞樣樹突細胞 | 讓鄰近未感染的細胞進入**抗病毒狀態**；增加 MHC I 表現；活化 NK 細胞 |
| **第二型(IFN-γ)** | T 細胞(Th1、CTL)、NK 細胞 | **活化巨噬細胞**，增強殺菌；是細胞性免疫的核心細胞激素 |

- 抗病毒狀態：細胞內被誘導出一批酵素(例如抑制蛋白質合成的 PKR、降解 RNA 的 RNase L)，使病毒難以複製；干擾素**不直接殺死病毒**，也不是病毒的抗體
- 臨床用途與副作用：**干擾素 α** 用於 B 型與 C 型肝炎，副作用是**類流感症狀**(發燒、肌肉痛)、疲倦、憂鬱、血球下降([[immunosuppressants#biologics]])

## 新生兒、懷孕與老年的免疫 {#life-stages}

### 新生兒的免疫 {#newborn}

1. **抗體的來源**
   1. **IgG**：唯一能經**胎盤**主動運送的抗體，主要在**懷孕後期**運給胎兒；新生兒出生時的 IgG 主要是**母體的被動免疫**
   2. **IgM**：分子量大，**不能過胎盤**；胎兒妊娠約 20 週後可自行合成少量 IgM、IgG、IgE
   3. **IgA**：胎兒**無法自行製造**，要靠**初乳與母乳的分泌型 IgA(sIgA)** 保護腸道與黏膜
   4. **IgE** 不會從母乳來
2. **診斷子宮內感染**：臍帶血或新生兒血中 **IgM 升高** → 胎兒自己產生了抗體，代表子宮內曾感染(**TORCH** 如巨細胞病毒、德國麻疹)，見 [[perinatal-infections]]
   1. IgG 升高不能用來診斷，因為多半來自母體
3. **母乳的免疫成分**：sIgA 能對抗水痘、單純疱疹、流感等病原；母乳還有溶菌酶、乳鐵蛋白與寡糖，提供腸道被動免疫
4. **新生兒自己的免疫系統還很弱**(Simon 2015)
   1. 先天免疫：嗜中性球殺菌與趨化能力差、補體濃度比成人低(約低 10–80%)、**NK 細胞與干擾素反應弱**，所以容易有細菌與病毒感染；**早產兒**更明顯
   2. 後天免疫：抗體反應偏 **Th2** 與**調節性 T 細胞**，**Th1 反應弱**；B 細胞對需要 T 細胞幫忙的抗原反應差、抗體親和力成熟與類別轉換不完全
   3. 臨床意義：母體 IgG 逐漸減少後嬰幼兒更容易感染；疫苗的設計與接種時程都要考慮這些特性([[immunization]])

### 懷孕 {#pregnancy}

- 母體免疫偏向 **Th2**，胎盤滋養層只表現非典型的 HLA，並有局部免疫抑制，才能容忍半異體的胎兒
- 結果：有些**自體免疫疾病懷孕時緩解**，但對流感等感染較容易重症

### 老化 {#aging}

1. **胸腺萎縮** → naive T 細胞減少，對新抗原與疫苗反應變差
2. 先天免疫：嗜中性球與巨噬細胞吞噬與殺菌力下降、NK 細胞數量與功能下降
3. **慢性低度發炎**：IL-1β、IL-6、TNF-α 偏高，與動脈粥狀硬化、失智症、癌症風險有關
4. 臨床：**感染的死亡率較高**；**潛伏的水痘帶狀疱疹病毒再活化**成帶狀疱疹([[herpesviruses#varicella-zoster-virus]])；疫苗保護力較差；**自體免疫與腫瘤**風險增加
