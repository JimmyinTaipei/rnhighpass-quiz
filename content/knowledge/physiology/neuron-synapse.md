神經系統的基本單位是**神經元**，負責產生與傳遞電訊號；數量更多的**神經膠細胞**負責支持、絕緣與防禦。訊號在細胞內以**動作電位**傳遞，到了末端再經**突觸**交給下一個神經元、肌肉或腺體。本頁整理生理學的基礎，精神科用到的神經傳導物質與腦區見 [[neurotransmitters-psychiatry]]

## 重點摘要 {#summary}

- 形成髓鞘的膠細胞：**中樞是寡突膠細胞**（一個細胞包好幾條軸突）、**周邊是許旺細胞**（一個細胞只包一段）
- **星狀膠細胞**維持**血腦障壁**、調節細胞外 K⁺、回收神經傳遞物質、損傷後形成疤痕；**微膠細胞**來自骨髓、負責**吞噬**；**室管膜細胞**襯在腦室，協助腦脊髓液流動
- 靜止膜電位約 **−70 mV**，因為靜止時細胞膜對 **K⁺ 的通透性遠大於 Na⁺**；細胞外 K⁺ 升高會使膜電位**變得較不負**
- 動作電位：**Na⁺ 內流去極化 → K⁺ 外流再極化 → 過極化**；遵守**全有全無**、有**不反應期**、**不能加成**
- 化學性突觸靠 **Ca²⁺ 內流**觸發突觸小泡**胞吐**；**IPSP** 是 Cl⁻ 內流或 K⁺ 外流造成的**過極化**；突觸後電位是漸進電位，**沒有不反應期**
- 神經肌肉接合處：**肉毒桿菌毒素**切斷 SNARE、阻斷 ACh 釋放；**有機磷與沙林**抑制 AChE；**重症肌無力**是 ACh 受體被抗體破壞

### 國考常考點 {#exam-points}

- 形成髓鞘的兩種細胞是**寡突膠細胞與許旺細胞**；寡突膠細胞**可以**同時包覆多條軸突，「一個寡突膠細胞只形成一個軸突的髓鞘」是錯的；寡突膠細胞會**抑制**軸突再生，只在中樞
- **源自骨髓**、遷移到中樞成熟的是**微膠細胞**；**吞噬**壞死組織是微膠細胞，**不是**星狀細胞
- 受損時對**血腦障壁**影響最大、參與形成血腦障壁的是**星狀細胞**；**分泌腦脊髓液**的是脈絡叢，**不是**星狀細胞；協助腦脊髓液生成與流動的膠細胞是**室管膜細胞**
- 髓鞘的功能：組成白質、跳躍式傳導、包覆 A 型纖維；**不提供 ATP**
- 痛覺的初級傳入神經元（背根神經節）是**偽單極**神經元，**不是多極**；支配骨骼肌的運動神經元是**多極**神經元
- 神經受傷後細胞體的**尼氏體溶解**（染色質溶解）
- 靜止時對 **K⁺** 通透性遠大於 Na⁺；**細胞外 K⁺ 增加 → 靜止膜電位減小**（較不負）
- 去極化 = **Na⁺ 流入**；過極化時 Na⁺ 通道已失活、**K⁺ 持續外流**
- **河豚毒(TTX)**與 **lidocaine** 都阻斷**電位門控 Na⁺ 通道** → 無法去極化
- 動作電位**不具加成作用**（加成是漸進電位的特性）
- 電性突觸 = **間隙接合**；**骨骼肌細胞之間沒有**間隙接合（心肌、平滑肌、部分神經元有）
- 神經末梢釋放神經傳遞物質最直接相關的是 **Ca²⁺** 內流
- **終板電位**是興奮性突觸後電位的一種，正常情況下**一定會引發肌肉動作電位**
- 抑制 **AChE** 的毒素：**沙林、有機磷**（考選部 107-2 兩個都給分）；河豚毒阻斷 Na⁺ 通道，箭毒阻斷菸鹼型受體
- **一氧化氮**是氣體，**不儲存在突觸小泡**；**P 物質**是胜肽類；**胰島素不是**神經傳遞物質
- 腸道神經系統包括**黏膜下神經叢**與肌間神經叢

## 神經系統的分類 {#divisions}

| 層次 | 包括 | 說明 |
|---|---|---|
| **中樞神經系統**(CNS) | 腦、脊髓 | 整合訊息、下達指令 |
| **周邊神經系統**(PNS) | 12 對腦神經、31 對脊神經、神經節 | 把訊息帶進、帶出中樞 |
| 　體神經 | 骨骼肌、皮膚與關節的感覺 | 多為隨意控制 |
| 　自主神經 | 交感、副交感 | 支配心肌、平滑肌、腺體，不隨意 |
| 　**腸道神經系統** | **肌間神經叢**（Auerbach，控制蠕動）、**黏膜下神經叢**（Meissner，控制分泌與局部血流） | 位在消化道壁內，可獨立運作，也受自主神經調節 |

- 功能上分成**感覺（傳入）**與**運動（傳出）**；腹腔叢、腹下神經叢屬於**自主神經**叢，薦神經叢屬於**體神經**叢，都不是腸道神經系統

## 神經元 {#neuron}

::figure{src="/knowledge-images/servier-neuron.svg" labels="neuron" alt="多極神經元的構造"}

### 構造 {#neuron-structure}

1. **細胞體**：含細胞核與大量**尼氏體**（粗糙內質網，製造蛋白質）
2. **樹突**：接收訊號，通常多條、短而分支
3. **軸丘**：軸突的起點，Na⁺ 通道最密，是**動作電位最先產生**的地方
4. **軸突**：一條，把訊號送離細胞體；外面可能有**髓鞘**，髓鞘之間的缺口是**蘭氏結**
5. **軸突終端**：形成突觸，釋放神經傳遞物質

### 分類 {#neuron-types}

| 依突起數目 | 構造 | 例子 |
|---|---|---|
| **多極** | 一條軸突、多條樹突 | 最常見；**運動神經元**（支配骨骼肌，形成神經肌肉接合處）、中間神經元 |
| **雙極** | 一條樹突、一條軸突 | 視網膜、嗅上皮、內耳的感覺神經元 |
| **偽單極**（假單極） | 一條突起分成周邊支與中樞支 | **背根神經節**與腦神經感覺神經節的**一般感覺神經元**（痛、溫、觸覺） |
| 單極 | 只有一個突起 | 人體罕見 |

- 依功能：**感覺（傳入）神經元**、**運動（傳出）神經元**、**中間神經元**（在中樞內連接，數量最多）

## 神經膠細胞 {#glia}

::figure{src="/knowledge-images/servier-neural-tissue.svg" labels="neural-tissue" alt="中樞神經組織：神經元與四種膠細胞"}

| 細胞 | 位置 | 主要功能 |
|---|---|---|
| **星狀膠細胞** | 中樞，數量最多 | ① 足突包住微血管，**誘導並維持血腦障壁**的緊密接合 ② 調節細胞外 **K⁺** ③ **回收**神經傳遞物質（如麩胺酸） ④ 供應神經元養分 ⑤ 參與腦發育 ⑥ 損傷後增生形成**疤痕**（膠質增生） |
| **寡突膠細胞** | 中樞 | 形成**中樞髓鞘**（白質），一個細胞可包覆**多條軸突**；會**抑制**軸突再生 |
| **微膠細胞** | 中樞 | 中樞的**巨噬細胞**，**吞噬**病原與壞死組織；**源自骨髓**的單核球系，胚胎期遷入中樞 |
| **室管膜細胞** | 襯在腦室與脊髓中央管 | 有纖毛，協助**腦脊髓液流動**；參與構成**脈絡叢**（真正分泌腦脊髓液的是脈絡叢） |
| **許旺細胞** | 周邊 | 形成**周邊髓鞘**，一個細胞只包**一段**軸突；協助周邊神經**再生** |
| **衛星細胞** | 周邊神經節 | 包圍神經節內的細胞體，提供支持 |

## 髓鞘與神經纖維 {#myelin}

1. **組成**：膠細胞的細胞膜一層層包住軸突，主要是脂質（髓磷脂）
2. **功能**
   1. **絕緣**，讓動作電位只在蘭氏結產生 → **跳躍式傳導**，速度快、耗能少
   2. 有髓鞘的纖維聚集成**白質**；細胞體聚集處是灰質
   3. 髓鞘**不供應 ATP**，能量來自軸突本身的粒線體
3. **纖維分類**（依傳導速度）
   1. **A 型**：有髓鞘、最粗最快；其中 **Aδ** 傳**快速刺痛**、**Aβ** 傳觸壓覺、**Aα** 傳本體感覺與支配骨骼肌
   2. **B 型**：有髓鞘，自主神經節前纖維
   3. **C 型**：**無髓鞘**、最細最慢，傳**慢性鈍痛**、溫度覺與自主神經節後纖維
4. **發育**：出生時髓鞘化尚未完成，出生後持續進行到兒童期、青春期（這也是嬰兒巴賓斯基反射呈陽性的原因之一）
5. **疾病**：中樞髓鞘被破壞是**多發性硬化症**；周邊髓鞘被破壞是格林－巴利症候群

::questions{ids="105-1_BM_020"}

## 神經損傷與再生 {#regeneration}

1. 軸突被切斷後，**細胞體**腫脹、細胞核偏位、**尼氏體溶解**（染色質溶解，chromatolysis）
2. 斷端以遠的軸突與髓鞘退化，稱**華勒氏變性**(Wallerian degeneration)
3. **周邊**神經可以再生：許旺細胞排成通道引導軸突長回去，每天約 1–3 毫米（待核對）
4. **中樞**神經很難再生：寡突膠細胞會抑制軸突生長，星狀膠細胞形成疤痕阻擋

::questions{ids="107-1_BM_016"}

## 靜止膜電位 {#resting-potential}

1. 神經細胞靜止時，膜內比膜外負，約 **−70 mV**
2. 形成原因
   1. **K⁺ 外漏通道**多半開著，靜止時細胞膜對 **K⁺ 的通透性遠大於 Na⁺**，K⁺ 順濃度往外流，留下負電
   2. **Na⁺–K⁺ 幫浦**每次把 **3 個 Na⁺ 送出、2 個 K⁺ 送入**，維持濃度梯度並貢獻少量負電
   3. 細胞內帶負電的蛋白質出不去
3. 因為主要由 K⁺ 決定，**細胞外 K⁺ 濃度改變**影響最大
   1. 細胞外 K⁺ **升高**：濃度差變小，K⁺ 外流減少，膜電位**變得較不負**（靜止膜電位減小、接近閾值），例如高血鉀
   2. 細胞外 K⁺ **降低**：膜電位更負（過極化），細胞較難興奮，例如低血鉀造成肌肉無力
   3. 血鉀與心電圖的關係見 [[potassium#function]]

::questions{ids="115-1_BM_006,110-1_BM_022"}

## 動作電位 {#action-potential}

![神經元動作電位：膜電位變化與離子通道](/knowledge-images/action-potential.svg)

### 各期 {#ap-phases}

1. **到達閾值**（約 −55 mV）：刺激使膜電位上升到閾值，電位門控 Na⁺ 通道開始大量打開
2. **去極化**：**Na⁺ 快速流入**，膜電位上升到約 +30 mV
3. **再極化**：Na⁺ 通道**失活**，電位門控 **K⁺ 通道打開，K⁺ 流出**，膜電位往下降
4. **過極化**：K⁺ 通道關得慢，K⁺ 持續外流，膜電位短暫低於靜止值；此時 Na⁺ 難以通過細胞膜
5. **恢復**：K⁺ 通道關閉，Na⁺–K⁺ 幫浦維持離子梯度

### 特性 {#ap-properties}

| 特性 | 動作電位 | 漸進電位（突觸後電位、受器電位、終板電位） |
|---|---|---|
| 大小 | **全有全無**，一旦達閾值就是固定大小 | 隨刺激強度改變 |
| 加成 | **不能加成** | **可以加成**（時間與空間加成） |
| 不反應期 | **有**（絕對與相對） | **沒有** |
| 傳導 | 沿軸突**不衰減**地傳到末端 | 隨距離衰減，只在局部 |
| 方向 | 去極化 | 可以是去極化（興奮）或過極化（抑制） |

- **絕對不反應期**：Na⁺ 通道失活，再強的刺激也無法引發第二個動作電位，因此訊號只能單向前進
- **相對不反應期**：需要比平常更強的刺激才能引發

### 阻斷 Na⁺ 通道的毒素與藥物 {#na-channel-blockers}

- **河豚毒(tetrodotoxin)**：阻斷電位門控 Na⁺ 通道 → 無法**去極化** → 肌肉麻痺、呼吸衰竭
- **局部麻醉劑**（lidocaine 等）：同樣阻斷 Na⁺ 通道，讓痛覺訊號傳不上去；細的無髓鞘痛覺纖維最先被阻斷

::questions{ids="105-2_BM_051,113-3_BM_013,111-2_BM_016,107-1_BM_020,106-2_BM_021,106-1_BM_019"}

## 突觸 {#synapse}

### 電性與化學性突觸 {#synapse-types}

| 項目 | 電性突觸 | 化學性突觸 |
|---|---|---|
| 構造 | **間隙接合**（gap junction，由連接子組成） | 突觸前末梢、突觸間隙、突觸後受體 |
| 速度 | 幾乎沒有延遲 | 有突觸延遲 |
| 方向 | 可雙向 | 單向 |
| 分布 | **心肌、平滑肌**、部分神經元 | 大多數神經元、神經肌肉接合處 |

- **骨骼肌細胞之間沒有間隙接合**，每一條肌纖維都要靠運動神經的化學性突觸來啟動
- 緊密接合負責封閉細胞間隙（如血腦障壁），胞橋小體與黏著帶負責細胞間的機械連結，都不是電性突觸

### 化學性突觸的傳遞步驟 {#synaptic-steps}

::figure{src="/knowledge-images/servier-synapse.svg" labels="synapse" alt="化學性突觸"}

1. 動作電位傳到軸突終端
2. 電位門控 **Ca²⁺ 通道**打開，**Ca²⁺ 流入**
3. 突觸小泡靠 **SNARE 蛋白**與細胞膜融合，以**胞吐**釋放神經傳遞物質
4. 神經傳遞物質擴散過突觸間隙，與突觸後膜的**受體**結合
5. 突觸後膜產生突觸後電位
   1. **EPSP**（興奮性）：Na⁺ 流入（或陽離子通道打開）→ 去極化
   2. **IPSP**（抑制性）：**Cl⁻ 流入**或 **K⁺ 流出** → **過極化**，較難達到閾值
6. 訊號終止：被酵素分解（如 ACh 被 **AChE** 分解）、被突觸前末梢或星狀膠細胞**回收**、或擴散離開

- 突觸後電位是**漸進電位**：可興奮也可抑制、可以加成、**沒有不反應期**；許多 EPSP 在軸丘加成到閾值才會引發動作電位

## 神經肌肉接合處 {#neuromuscular-junction}

::figure{src="/knowledge-images/servier-neuromuscular-junction.svg" labels="nmj" alt="神經肌肉接合處(運動終板)"}

1. 運動神經末梢釋放 **乙醯膽鹼(ACh)**
2. ACh 與肌膜（**運動終板**）上的**菸鹼型（N 型）ACh 受體**結合，Na⁺ 流入，產生**終板電位**
3. 終板電位屬於**興奮性突觸後電位**，但幅度很大，**正常情況下一定會引發肌肉動作電位**；它只能是興奮性
4. 突觸間隙的 **AChE** 很快把 ACh 分解，肌肉才能放鬆

### 影響神經肌肉接合處的毒素、藥物與疾病 {#nmj-disorders}

| 作用點 | 例子 | 結果 |
|---|---|---|
| 阻斷 ACh **釋放** | **肉毒桿菌毒素**（蛋白酶，切斷 **SNARE** 蛋白） | **弛緩性麻痺**，最後呼吸肌無力；局部注射用於除皺、肌肉痙攣；見 [[clostridium-botulinum-tetani#clostridium-botulinum]] |
| 抑制 **AChE** | **有機磷**殺蟲劑、**沙林**毒氣（不可逆）；neostigmine、pyridostigmine（可逆，治療用） | ACh 堆積：瞳孔縮小、流涎、流淚、頻尿、腹瀉、**心跳變慢**、肌肉顫動，最後無力 |
| 阻斷 **N 型受體** | 箭毒(curare)、非去極化型神經肌肉阻斷劑 | 骨骼肌鬆弛（手術麻醉用） |
| **受體被抗體破壞** | **重症肌無力**（自體免疫） | ACh 受體減少，活動後越來越無力 |
| 阻斷 **Na⁺ 通道** | 河豚毒 | 神經與肌肉都無法產生動作電位 |

- 107-2 年考題（哪一種毒素會抑制 AChE）的選項中，沙林與有機磷都對，考選部兩個都給分

## 神經傳遞物質 {#neurotransmitters}

| 類別 | 代表 | 重點 |
|---|---|---|
| 膽鹼類 | **乙醯膽鹼(ACh)** | 神經肌肉接合處、自主神經節、副交感節後；對平滑肌可能**興奮也可能抑制**，取決於受體與器官 |
| 單胺類：兒茶酚胺 | **多巴胺**、正腎上腺素、腎上腺素 | 多巴胺與**動機、獎賞**（中腦邊緣路徑）、動作控制有關 |
| 單胺類：其他 | **血清素**、組織胺 | 情緒、睡眠、食慾 |
| 胺基酸 | **麩胺酸**（主要興奮性）、**GABA**（腦部主要抑制性）、**甘胺酸**（脊髓主要抑制性） | 破傷風毒素阻斷甘胺酸與 GABA 的釋放，造成強直 |
| 胜肽 | **P 物質**（痛覺傳遞）、腦內啡與腦啡肽（止痛）、神經胜肽 Y | 在細胞體合成後運送到末梢 |
| 氣體 | **一氧化氮(NO)**、一氧化碳 | 需要時才由 L-arginine 合成，直接擴散，**不儲存在突觸小泡**、不靠胞吐 |
| 嘌呤 | ATP、腺苷 | |

- **巴金森氏症**：黑質的**多巴胺**神經元退化，紋狀體多巴胺不足、**乙醯膽鹼相對過多**；治療目標是恢復多巴胺與乙醯膽鹼的平衡（補多巴胺、或用抗膽鹼藥）
- 精神疾病與神經傳導物質（憂鬱症的血清素與正腎上腺素、思覺失調症的多巴胺、焦慮症的 GABA）見 [[neurotransmitters-psychiatry#overview]]
- **胰島素**是胰臟分泌的荷爾蒙，不是神經傳遞物質
