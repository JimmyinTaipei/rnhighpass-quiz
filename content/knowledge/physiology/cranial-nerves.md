12 對腦神經從腦直接發出，負責頭頸部的感覺與運動，迷走神經還一路延伸到胸腹內臟。考試最常考：每對神經的**功能**、**誰負責哪條眼外肌與哪個腺體**、**受損時的表現**，以及昏迷與腦死評估用的**腦幹反射**。腦幹本身的構造見 [[brain-anatomy#brainstem]]

## 重點摘要 {#summary}

- **純感覺**：I 嗅、II 視、VIII 前庭耳蝸；**純運動**：III 動眼、IV 滑車、VI 外展、XI 副、XII 舌下；**混合**：V 三叉、VII 顏面、IX 舌咽、X 迷走
- 眼外肌：**外直肌 = VI**、**上斜肌 = IV**，其他眼外肌、上眼瞼提肌、**瞳孔括約肌與睫狀肌**（調節水晶體）都是 **III**
- 臉的**感覺**與**咀嚼**是 **V**（拔牙麻醉阻斷 V）；臉的**表情肌**是 **VII**（走在**耳下腺**裡，耳下腺腫瘤會壓迫）
- 腺體：**VII → 淚腺、下頷下腺、舌下腺**；**IX → 耳下腺**；**X → 胸腹內臟**（心、肺、胃腸、膽汁分泌）
- 頸動脈竇與頸動脈體 → **IX**；主動脈弓與主動脈體 → **X**；聲帶 → **X**（喉返神經）；轉頭與聳肩 → **XI**；舌頭運動 → **XII**
- 腦幹反射：瞳孔(II → III)、角膜(V → VII)、頭眼、前庭動眼、作嘔(IX → X)、咳嗽(X)；**深部肌腱反射是脊髓反射，不是腦幹反射**

### 國考常考點 {#exam-points}

- 耳下腺（腮腺）腫瘤最容易壓迫**顏面神經**；刺激耳下腺分泌的是**舌咽神經**
- 淚腺與下頷下腺的副交感來自**顏面神經**
- 加速肝臟分泌膽汁的是**迷走神經**；頸部手術後食慾差、便秘 → **迷走神經**受損；支配聲帶肌群 → **迷走神經**
- 主動脈體的 O₂ 訊息 → **迷走神經**；頸動脈竇的血壓訊息 → **舌咽神經**
- 手電筒照眼引起瞳孔反射的**傳入**神經是**視神經**（傳出是動眼神經）
- 使眼球向下內側看並內旋的是**上斜肌**；滑車神經支配**上斜肌**，**不是外直肌**；調節水晶體曲度的是**動眼神經**
- 右眼外展神經受壓 → **向右看**時複視最明顯；車禍後右眼向外移動困難＋複視 → **外展神經**
- 咀嚼困難＋臉頰沒有觸覺 → **三叉神經**；三叉神經從**橋腦**表面鑽出
- 無法轉頭、肩下垂、不能聳肩 → **副神經**
- 舌下神經支配**所有舌內在肌**與大部分舌外在肌（顎舌肌由迷走神經支配）
- 輪廓狀乳頭在舌後部、**含味蕾**；絲狀乳頭最多但**沒有**味蕾；舌頭的味覺由 VII、IX（與 X）傳遞，不是只有顏面神經
- 影響吞嚥的腦神經：**VII、IX、X**（題目選項組合中）；第五對腦神經受壓**不會**造成複視；視交叉受壓 → 雙顳側偏盲
- 腦死判定的腦幹反射包括**頭眼反射**；**膝反射、肱二頭肌反射**等深腱反射不屬於腦幹功能評估

## 腦神經的位置 {#overview}

::figure{src="/knowledge-images/lynch-cranial-nerves.svg" labels="cranial-nerves" alt="腦底觀的 12 對腦神經(上為前)"}

| 出腦位置 | 腦神經 |
|---|---|
| 大腦（嗅球） | I |
| 間腦（視交叉） | II |
| **中腦** | **III**（腹側，大腦腳之間）、**IV**（唯一從**背側**出來的） |
| **橋腦** | **V**（橋腦外側） |
| 橋腦與延腦交界 | VI（內側）、VII、VIII（外側，小腦橋腦角） |
| **延腦** | IX、X、XI、XII（XII 從錐體與橄欖體之間） |

- 記類型的口訣（依 I 到 XII 的順序，S 感覺、M 運動、B 混合）：S S M M B M B S B B M M

## 各對腦神經 {#each-nerve}

| 編號與名稱 | 類型 | 功能 | 怎麼檢查 | 受損時 |
|---|---|---|---|---|
| **I 嗅神經** | 感覺 | 嗅覺（穿過篩板） | 閉眼、一次一側鼻孔，聞咖啡、肥皂等 | 嗅覺喪失；前顱底骨折時常見 |
| **II 視神經** | 感覺 | 視覺；**瞳孔對光反射的傳入** | 視力、視野、眼底 | 同側眼盲；視交叉受壓 → 雙顳側偏盲 |
| **III 動眼神經** | 運動（含副交感） | 上直肌、下直肌、內直肌、下斜肌、**上眼瞼提肌**；副交感 → **瞳孔括約肌**（縮瞳）、**睫狀肌**（調節水晶體曲度） | 瞳孔大小與對光反射、眼球運動、眼瞼 | **眼瞼下垂**、**瞳孔散大**、眼球偏向外下方；顳葉鉤迴疝脫壓迫 III → **同側瞳孔散大** |
| **IV 滑車神經** | 運動 | **上斜肌**：使眼球**內旋**與向下（眼球內收時往下看最明顯）；經眶上裂進入眼眶 | 請病人往鼻側下方看 | 垂直複視、下樓梯時看不清；單側受損會複視與斜視 |
| **V 三叉神經** | 混合 | **臉部、角膜、口腔與牙齒的感覺**（V1 眼神經、V2 上頷神經、V3 下頷神經）；**咀嚼肌**(V3) | 臉三區的觸覺與痛覺、角膜反射（傳入）、咬緊牙齒摸咬肌 | 臉頰失去感覺、咀嚼困難；三叉神經痛；**不會**造成複視 |
| **VI 外展神經** | 運動 | **外直肌**：眼球向**外側**轉 | 請病人往兩側看 | 患側眼**無法外展**、內斜，**往患側看時複視最明顯**；顱內路徑長，顱內壓升高時容易受壓 |
| **VII 顏面神經** | 混合 | **臉部表情肌**；**舌前 2/3 味覺**；副交感 → **淚腺**、**下頷下腺**、**舌下腺**；鐙骨肌；出顱後**穿過耳下腺**分支 | 皺眉、閉眼、鼓頰、微笑；角膜反射的**傳出**（眨眼） | 貝爾氏麻痺（同側整個臉癱、閉不了眼）；耳下腺腫瘤或手術易傷 |
| **VIII 前庭耳蝸神經** | 感覺 | **聽覺**（耳蝸）與**平衡**（前庭） | 耳語、音叉（韋伯、林內）、平衡 | 聽力喪失、耳鳴、眩暈 |
| **IX 舌咽神經** | 混合 | **舌後 1/3 味覺**與咽部感覺（**作嘔反射的傳入**）；莖突咽肌；副交感 → **耳下腺**；**頸動脈竇**（血壓）與**頸動脈體**（O₂、CO₂）的傳入 | 作嘔反射、吞嚥 | 作嘔反射減弱、吞嚥困難 |
| **X 迷走神經** | 混合 | 咽與**喉部肌肉**（喉返神經 → **聲帶**）、**作嘔反射的傳出**、吞嚥；副交感 → **心臟**（心跳變慢）、肺、**胃腸到橫結腸**（蠕動、分泌、**膽汁分泌**）；**主動脈弓與主動脈體**的傳入 | 說「啊」看懸雍垂是否置中、聲音、吞嚥 | 聲音沙啞（甲狀腺或頸部手術傷到喉返神經）、吞嚥困難；胃腸蠕動變差 → 食慾差、便秘 |
| **XI 副神經** | 運動 | **胸鎖乳突肌**（轉頭）、**斜方肌**（聳肩） | 對抗阻力轉頭、聳肩 | 無法把頭轉向對側、**肩下垂、不能聳肩** |
| **XII 舌下神經** | 運動 | **所有舌內在肌**與大部分舌外在肌（顎舌肌除外，由迷走神經支配） | 伸舌看是否置中 | 伸舌時舌尖**偏向患側**、構音困難 |

### 眼外肌整理 {#extraocular-muscles}

| 肌肉 | 主要動作 | 神經 |
|---|---|---|
| **外直肌** | 外展（向外側） | **VI** |
| **上斜肌** | 內旋、下轉（眼球內收時往下看） | **IV** |
| 內直肌 | 內收 | III |
| 上直肌 | 上轉 | III |
| 下直肌 | 下轉 | III |
| 下斜肌 | 外旋、上轉 | III |
| 上眼瞼提肌 | 張開眼瞼 | III |

- 口訣：**LR6 SO4**，其餘是 III
- 一條眼外肌麻痺時，往那條肌肉負責的方向看，兩眼對不齊，**複視最明顯**

### 腦神經與腺體（副交感） {#parasympathetic-glands}

| 腦神經 | 神經節 | 目標 |
|---|---|---|
| III 動眼 | 睫狀神經節 | 瞳孔括約肌、睫狀肌 |
| VII 顏面 | 翼腭神經節 | **淚腺**、鼻腔腺體 |
| VII 顏面 | 下頷下神經節 | **下頷下腺**、**舌下腺** |
| IX 舌咽 | 耳神經節 | **耳下腺** |
| X 迷走 | 器官壁內 | 心、肺、胃腸、肝膽 |

### 舌頭：味覺與運動 {#tongue}

1. **舌乳頭**
   1. **絲狀乳頭**：數目最多，**沒有味蕾**，負責觸覺與摩擦
   2. **蕈狀乳頭**：多在舌尖與兩側，**有味蕾**
   3. **輪廓狀乳頭**：約 8–12 個，在舌後部排成 V 字形，最大、**味蕾最多**
   4. 葉狀乳頭：舌兩側後方
2. 味蕾也分布在軟腭、咽部與會厭，**不是只在舌頭**
3. 味覺傳遞：舌**前 2/3 → VII**、舌**後 1/3 → IX**、會厭附近 → X
4. 舌頭的感覺：前 2/3 一般感覺 → V；運動 → **XII**（顎舌肌 → X）

### 吞嚥與腦神經 {#swallowing}

| 階段 | 腦神經 |
|---|---|
| 口腔期：咀嚼、唇頰閉合、舌頭推送 | V（咀嚼）、VII（唇頰）、XII（舌） |
| 咽部期：咽部感覺、吞嚥反射 | **IX**（感覺）、**X**（咽喉肌肉） |
| 食道期 | X |

- 吞嚥中樞在**延腦**；腦幹中風、腦神經受損的病人要先做吞嚥篩檢再進食

## 腦幹反射 {#brainstem-reflexes}

| 反射 | 做法 | 傳入 → 傳出 | 腦幹位置 |
|---|---|---|---|
| **瞳孔對光反射** | 手電筒照一眼，兩眼都縮（直接與間接） | **II → III** | 中腦 |
| **角膜反射** | 棉絲輕觸角膜，正常會眨眼 | **V → VII** | 橋腦 |
| **頭眼反射**（娃娃眼） | 快速轉頭，正常眼球往反方向轉（像娃娃眼）；腦幹失功能時眼球跟著頭轉 | VIII → III、VI | 中腦到延腦 |
| 前庭動眼反射（冰水試驗） | 外耳道灌冰水，正常眼球偏向灌水側 | VIII → III、VI | 橋腦 |
| **作嘔反射** | 壓舌板碰咽後壁 | **IX → X** | 延腦 |
| 咳嗽反射 | 抽痰刺激氣管 | X → X | 延腦 |

- **深部肌腱反射**（膝反射、肱二頭肌反射）與腹部反射、肛門反射都是**脊髓反射**，不屬於腦幹功能評估
- 腦死判定要確認以上腦幹反射全部消失，再加上**無自行呼吸**測試；兩次判定間隔 3 歲以上至少 4 小時（來源：[腦死判定準則](https://6laws.net/6law/law3/腦死判定準則.htm)），先決條件與完整流程見 [[cranial-nerve-spine-disorders#brain-death]]
