血液由血漿與血球組成，負責運送氧氣與養分、維持酸鹼與體溫、防禦感染與止血。本頁整理血液組成、造血、紅血球與鐵代謝、白血球、血小板、止血與凝血瀑布、天然抗凝與纖維蛋白溶解、血型與骨髓檢查；檢驗數值見 [[complete-blood-count]] 與 [[coagulation-tests]]，貧血見 [[anemias]]，出血疾病見 [[bleeding-disorders]]，血栓與 DIC 的病理見 [[thrombosis-embolism-infarction]]

## 重點摘要 {#summary}

- 血液約占體重 **8%**(《兒科護理學》p.481)：**血漿 55%**(九成是水)、**血球 45%**
- 血漿蛋白：**白蛋白**(最多，肝臟製造，維持**膠體滲透壓**)、球蛋白(抗體)、**纖維蛋白原**(凝血)；血清＝血漿去掉凝血因子
- 造血：胎兒**卵黃囊 → 肝臟、脾臟 → 骨髓**；成人只剩胸骨、肋骨、脊椎、顱骨、骨盆等**扁平骨**的紅骨髓
- **紅血球生成素(Erythropoietin，EPO)**：**腎臟**在**缺氧**時分泌，作用在**紅骨髓**
- 紅血球：**無細胞核、無粒線體**，雙凹圓盤、直徑約 **7–8 μm**，壽命約 **120 天**；老舊紅血球被脾臟、肝臟、骨髓的巨噬細胞破壞
- 白血球：**嗜中性球最多**、**單核球最大**(進入組織變成巨噬細胞)、**嗜鹼性球**釋放組織胺、**嗜酸性球**對抗寄生蟲與參與過敏
- 止血三步：**血管收縮 → 血小板栓 → 凝血(纖維蛋白)**；凝血因子多由**肝臟**製造，**II、VII、IX、X** 需要維生素 K
- 外在路徑看**凝血酶原時間(Prothrombin time，PT)**，內在路徑看**活化部分凝血活酶時間(Activated partial thromboplastin time，aPTT)**
- **抗凝血酶(Antithrombin，AT)**抑制凝血酶與 Xa；**胞漿素**分解纖維蛋白產生 **D-dimer**

### 國考常考點 {#exam-points}

- 紅血球直徑是 7–8 **微米**(不是奈米)；成熟紅血球**沒有細胞核也沒有粒線體**
- 血球壽命最長的是**紅血球**(約 120 天)；血小板約 10 天
- 紅血球內催化 CO₂＋H₂O → 碳酸的是**碳酸酐酶**
- EPO 由**腎臟**分泌，**缺氧時分泌增加**(不是減少)，標的是**紅骨髓**
- 鐵進入體內與**鐵蛋白(Ferritin)**結合儲存；食物中的鐵只吸收約一成；人體主要靠**調控吸收**維持鐵恆定，沒有主動排鐵的途徑
- 胎兒造血器官：卵黃囊、肝臟、脾臟、骨髓；**胰臟不是**
- 最終成熟不在骨髓的是 **T 淋巴球**(在胸腺)
- 血液中數量最多的吞噬細胞是**嗜中性球**；單核球變成**巨噬細胞**
- 與過敏最相關的白血球增多是**嗜酸性球**；**釋放組織胺的是嗜鹼性球**(與肥大細胞)，不是嗜酸性球
- 白蛋白下降 → 膠體滲透壓下降 → **水腫**；能增加膠體滲透壓的血品是**白蛋白**
- 血管受傷後的凝血和**紅血球**最無關
- 初級止血是血小板經 **vWF** 黏在膠原上，不是靠內皮細胞的選擇素
- A 型血友病缺**第八因子**、B 型缺**第九因子**：**凝血時間延長、出血時間正常**
- 抗凝血酶本身作用慢，要和 heparin 結合才加快；蛋白質 C 由**肝臟**製造
- A 型血的人血中有**抗 B 抗體**；ABO 天然抗體是 **IgM**
- 交叉試驗看的是**凝集**(血型相容)，不是檢查過敏
- 骨髓抽吸：成人**後腸骨嵴**或胸骨；**18 個月以下**嬰幼兒用**近側脛骨**，較大兒童用**後腸骨嵴**；不用全身麻醉；術後加壓、觀察出血

## 血液的組成 {#composition}

| 成分 | 比例 | 重點 |
|---|---|---|
| **血漿** | 約 55% | 九成是水，其餘是蛋白質、電解質、葡萄糖、脂質、激素、廢物 |
| 白蛋白 | 血漿蛋白中最多(約 55%) | **肝臟**製造；維持**膠體滲透壓**、運送脂肪酸、膽紅素、藥物與激素 |
| 球蛋白 | | α、β 球蛋白運送物質；**γ 球蛋白是抗體** |
| **纖維蛋白原** | 約 7% | 肝臟製造；凝血時變成纖維蛋白 |
| **血球** | 約 45%(血比容) | 紅血球、白血球、血小板 |

- 依《內外科護理學》上冊 p.941–942
- **血清**＝血漿凝固後的液體，已經用掉纖維蛋白原與凝血因子
- 血液的功能：運送氧氣、CO₂、養分與激素；維持 pH 7.35–7.45 與體溫；防禦感染；止血
- 白蛋白低(肝硬化、腎病症候群、營養不良) → 水分滲到組織間 → **水腫**(見 [[edema-shock]])；輸**白蛋白**可提高膠體滲透壓(血品見 [[transfusion-reactions#products]])
- 營養評估的血清蛋白(白蛋白、運鐵蛋白)見 [[nutrition-assessment-diets]]；運鐵蛋白由**肝臟**製造，不是腎臟

## 造血 {#hematopoiesis}

::figure{src="/knowledge-images/servier-hematopoiesis.svg" labels="hematopoiesis" alt="造血：造血幹細胞分成骨髓系與淋巴系前驅細胞，骨髓系產生紅血球、巨核細胞與血小板、嗜中性球、嗜酸性球、嗜鹼性球、單核球與巨噬細胞，淋巴系產生 T、B、NK 細胞"}

- 所有血球都來自骨髓的**造血幹細胞**
   1. **骨髓系**：紅血球、巨核細胞(碎裂成血小板)、嗜中性球、嗜酸性球、嗜鹼性球、單核球
   2. **淋巴系**：B 細胞(骨髓成熟)、**T 細胞(移到胸腺成熟)**、自然殺手細胞(NK 細胞)
- 造血部位隨年齡改變(《兒科護理學》p.481；《內外科護理學》上冊 p.945)

| 時期 | 主要造血部位 |
|---|---|
| 胚胎早期 | **卵黃囊** |
| 胎兒中期 | **肝臟**、脾臟(也有胸腺、淋巴結) |
| 胎兒後期到嬰兒 | 骨髓逐漸成為主角，肝脾仍有少量 |
| 兒童 | 全身骨骼的骨髓都是紅骨髓 |
| 青春期後到成人 | 長骨被脂肪取代成**黃骨髓**，只剩**胸骨、肋骨、脊椎、顱骨、骨盆**(與股骨、肱骨近端)造血 |

- 成人骨髓抽吸選**胸骨或腸骨**，因為這兩處仍在造血
- 造血需要的原料：**鐵**(血紅素)、**維生素 B12 與葉酸**(DNA 合成)、蛋白質；缺乏時的貧血見 [[anemias]]
- 調控激素
   1. **EPO**：**腎臟**偵測到**缺氧**(貧血、高海拔、肺病)時分泌，刺激紅骨髓製造紅血球；嬰兒期主要由肝臟製造(《內外科護理學》上冊 p.943)；慢性腎臟病缺 EPO 造成腎性貧血(見 [[chronic-kidney-disease#anemia]])
   2. **雄性素**促進紅血球生成，所以男性血紅素較高
   3. 血小板生成素(主要由肝臟製造)刺激巨核細胞
   4. 顆粒球聚落刺激因子(Granulocyte colony-stimulating factor，G-CSF)刺激嗜中性球，化療後用來縮短嗜中性球低下期(見 [[cancer-treatment-toxicities#neutropenia]])
- 骨髓三系都減少＝**再生不良性貧血**；EPO 與造血藥物見 [[hematinics]]

## 紅血球與鐵代謝 {#rbc}

- 形狀：**雙凹圓盤**、直徑約 **7–8 μm**，彈性高，可變形擠過微血管
- **成熟紅血球沒有細胞核、沒有粒線體**(只能無氧糖解)，所以不能分裂、也不能修復
- 生成過程：前紅血球母細胞 → 紅血球母細胞 → 正母細胞(排出細胞核) → **網狀紅血球**(進入血液 1–2 天) → 紅血球；網狀紅血球上升表示骨髓正在加速製造(出血、溶血、補鐵後)
- 壽命約 **120 天**，老舊紅血球被**脾臟**(主要)、肝臟、骨髓的巨噬細胞吞噬；血紅素分解成膽紅素(見 [[liver-biliary-pancreas#bilirubin]])
- **血紅素(Hemoglobin，Hb)**
   1. 由 4 條球蛋白鏈＋4 個含鐵的血基質組成；成人型 HbA 是 **2α2β**，胎兒型 **HbF 是 2α2γ**(對氧親和力較高)
   2. 血基質的 **Fe²⁺** 結合 O₂；CO₂ 一小部分結合在球蛋白上(胺基甲醯血紅素)
   3. **一氧化碳**和血紅素的親和力遠高於氧氣，形成碳氧血紅素，造成組織缺氧(見 [[environmental-injury#carbon-monoxide]])
- 紅血球內的**碳酸酐酶**催化 CO₂＋H₂O ⇌ H₂CO₃，是 CO₂ 以碳酸氫根運送的關鍵(見 [[gas-exchange-transport#co2-transport]])
- 正常值：成人女性 Hb 約 12–15 g/dL、男性約 14–16.5 g/dL，嬰兒約 9–14 g/dL(《兒科護理學》p.482)；完整參考值見 [[complete-blood-count#reference-range]]

### 鐵代謝 {#iron}

- 吸收：主要在**十二指腸**，以 **Fe²⁺(亞鐵)** 形式吸收；食物中的鐵只吸收約 **10%**；**動物性(血基質)鐵比植物性鐵好吸收**；維生素 C 幫助、茶與鈣減少吸收
- 運送：血中與**運鐵蛋白(Transferrin)**結合
- 儲存：在肝臟、脾臟、骨髓與**鐵蛋白(Ferritin)**結合，過多時成為血鐵質；**血清鐵蛋白**反映體內儲存鐵
- 人體**沒有主動排鐵的途徑**(只隨脫落細胞與出血流失)，所以主要靠**控制腸道吸收**維持恆定；反覆輸血會鐵沉積，需要排鐵劑(見 [[hematinics#chelators]])
- 缺鐵時的檢驗變化見 [[anemias#iron-deficiency]]

## 白血球 {#wbc}

| 白血球 | 比例 | 特徵與功能 |
|---|---|---|
| **嗜中性球** | 最多(約 50–70%) | **最早到達急性發炎**處，吞噬細菌；膿就是死掉的嗜中性球；分葉核(Seg)與帶狀核(Band，較不成熟) |
| **嗜酸性球** | 約 1–4% | 對抗**寄生蟲**、參與**過敏**與氣喘；過敏性疾病時增加 |
| **嗜鹼性球** | 最少(< 1%) | 顆粒含**組織胺**與肝素，參與過敏反應(功能類似組織中的肥大細胞) |
| **單核球** | 約 2–8% | **體積最大**；進入組織變成**巨噬細胞**，吞噬並呈現抗原；增加表示慢性感染 |
| 淋巴球 | 約 20–40% | B 細胞(分化成漿細胞**製造抗體**)、T 細胞(細胞性免疫)、NK 細胞 |

- 比例依《兒科護理學》表 9-1 與常用參考範圍整理，實際以醫院檢驗值為準；白血球分類與**絕對嗜中性球數(Absolute neutrophil count，ANC)**計算見 [[complete-blood-count#differential]] 與 [[complete-blood-count#anc]]
- 年紀越小，嗜中性球上升越可能代表感染(《兒科護理學》p.483)
- 各種免疫細胞的角色見 [[immune-system-basics#leukocytes]]

## 血小板 {#platelets}

- 骨髓的**巨核細胞**細胞質碎裂而成，**沒有細胞核**；正常約 **15–40 萬/mm³**，壽命約 **10 天**(《內外科護理學》上冊 p.947)
- 約三分之一存在**脾臟**；脾腫大時血小板被扣留而下降
- 功能：黏附、活化、聚集形成**血小板栓**；釋放 ADP 與**血栓素 A₂(Thromboxane A₂，TXA₂)**招來更多血小板；提供磷脂質表面讓凝血因子作用
- **Aspirin** 不可逆抑制 COX-1 → TXA₂ 減少，效果持續到血小板汰換(約 7–10 天)，所以術前要停藥(見 [[antiplatelets]])
- 數量下降的原因與照護見 [[bleeding-disorders#thrombocytopenia]]

## 止血 {#hemostasis}

1. **血管收縮**：受傷血管反射性收縮，內皮釋放**內皮素(Endothelin)**加強收縮
2. **初級止血(血小板栓)**：內皮受損露出**膠原** → 血漿中的**類血友病因子(von Willebrand factor，vWF)**把血小板(醣蛋白 Ib 受體)黏到膠原上 → 血小板變形、釋放 ADP 與 TXA₂ → 經**醣蛋白 IIb/IIIa** 與纖維蛋白原互相連結成栓；約 15–30 秒形成(《內外科護理學》上冊 p.948)
3. **次級止血(凝血)**：凝血瀑布產生**凝血酶**，把纖維蛋白原變成**纖維蛋白網**，把血小板栓固定成穩定血塊；需要數分鐘
4. **血塊收縮與修復**，之後由纖維蛋白溶解移除血塊

- 止血需要血管內皮、血小板、凝血因子與纖維蛋白；**紅血球不參與**止血機轉(只是被網在血塊裡)
- 初級止血異常(血小板少、vWF 不足、aspirin)：**出血時間延長**、皮膚黏膜出血(瘀點、流鼻血)
- 次級止血異常(血友病、缺維生素 K、肝病)：**凝血時間延長**、深部組織與關節出血
- 血栓形成的 Virchow 三要素與 DIC 機轉見 [[thrombosis-embolism-infarction#hemostasis]]

## 凝血瀑布 {#coagulation}

![凝血瀑布與纖維蛋白溶解：內在路徑由接觸活化經 XII、XI、IX(加 VIIIa)；外在路徑由組織因子加 VII；兩者活化 X，Xa 加 Va 把凝血酶原變成凝血酶，凝血酶把纖維蛋白原變成纖維蛋白，XIIIa 交聯成穩定血塊；胞漿素分解纖維蛋白產生 FDP 與 D-dimer；標示維生素 K 依賴因子 II、VII、IX、X](/knowledge-images/coagulation-cascade.svg)

| 因子 | 名稱 | 重點 |
|---|---|---|
| I | **纖維蛋白原** | 被凝血酶切成纖維蛋白 |
| II | **凝血酶原** | 維生素 K 依賴；活化成凝血酶(IIa) |
| III | **組織因子(Tissue factor，TF)** | 組織受傷釋出，啟動外在路徑 |
| IV | **鈣離子** | 多數步驟需要；血液檢體加檸檬酸鈉或 EDTA 抓走鈣就不會凝固 |
| VII | | 維生素 K 依賴；**半衰期最短**，所以 warfarin 或肝病時 **PT 最先延長** |
| VIII | 抗血友病因子 | **A 型血友病**缺乏；在血中由 vWF 攜帶保護 |
| IX | Christmas 因子 | 維生素 K 依賴；**B 型血友病**缺乏 |
| X | Stuart 因子 | 維生素 K 依賴；內外路徑匯合點 |
| XII | Hageman 因子 | 接觸活化，啟動內在路徑 |
| XIII | 纖維蛋白穩定因子 | 讓纖維蛋白交聯 |

- 凝血因子大多由**肝臟**製造；**II、VII、IX、X**(加上蛋白質 C、S)需要**維生素 K** 才有活性 → 肝病、阻塞性黃疸(脂溶性維生素 K 吸收差)、新生兒、warfarin 都會延長 PT
- 三條路徑
   1. **外在路徑**：TF＋VII → VIIa；用 **PT／國際標準化比值(International normalized ratio，INR)** 反映，**warfarin** 監測用
   2. **內在路徑**：XII → XI → IX(＋VIIIa) ；用 **aPTT** 反映，**heparin** 監測用；**血友病 A、B 只延長 aPTT，PT 正常**
   3. **共同路徑**：X → Xa(＋Va) → 凝血酶原 → **凝血酶** → 纖維蛋白原 → **纖維蛋白** → XIIIa 交聯
- 體內實際上以組織因子啟動為主，內外路徑的分法主要用來解讀檢驗；檢驗做法與判讀見 [[coagulation-tests]]
- 藥物在凝血瀑布的作用點見 [[anticoagulants#mechanism]]

## 天然抗凝與纖維蛋白溶解 {#anticoagulation-fibrinolysis}

- 身體同時有煞車，讓血塊只在受傷處形成
   1. **抗凝血酶(AT，舊稱 AT III)**：肝臟製造，抑制**凝血酶與 Xa**；本身作用慢，**和 heparin 結合後加速上千倍**(heparin 的藥理見 [[anticoagulants#heparin]])
   2. **蛋白質 C 與蛋白質 S**：**肝臟**製造、維生素 K 依賴；凝血酶結合內皮的**凝血酶調節素(Thrombomodulin)**後活化蛋白質 C，分解 **Va 與 VIIIa**
   3. 組織因子路徑抑制物：抑制 TF–VIIa
   4. 肝臟與脾臟的**巨噬細胞**(單核吞噬細胞系統)清除活化的凝血因子
- **纖維蛋白溶解**
   1. 內皮釋放**組織胞漿素原活化劑(Tissue plasminogen activator，t-PA)** → **胞漿素原 → 胞漿素**
   2. 胞漿素分解纖維蛋白 → **纖維蛋白分解產物(Fibrin degradation products，FDP)**；交聯過的纖維蛋白分解後產生 **D-dimer**，D-dimer 上升表示體內有血塊形成又被溶解(深部靜脈血栓、肺栓塞、DIC)
   3. 血栓溶解劑(alteplase 等)就是補充 t-PA(見 [[thrombolytics#mechanism]])；tranexamic acid 則反過來抑制纖溶來止血
- 天然抗凝因子缺乏(AT、蛋白質 C、S 缺乏)會容易血栓

## 血型 {#blood-groups}

| 血型 | 紅血球表面抗原 | 血漿中的抗體 |
|---|---|---|
| A | A | **抗 B** |
| B | B | 抗 A |
| AB | A、B | 都沒有(萬能受血者) |
| O | 都沒有 | 抗 A、抗 B(紅血球為萬能捐血者) |

- ABO 抗體是出生後自然產生的 **IgM**，不能通過胎盤；輸錯血型會立刻**凝集與溶血**
- Rh：有 D 抗原為 Rh(+)；Rh(−) 的人要先接觸過 Rh(+) 血才產生抗 D(**IgG**，可通過胎盤)
- 新生兒溶血：**ABO 不合**多發生在 **O 型母親**懷 A 或 B 型胎兒，第一胎就可能發生、通常較輕；**Rh 不合**是 Rh(−) 母親懷 Rh(+) 胎兒，**第二胎起**較嚴重(見 [[immunoglobulins-hla#rh]]、[[transfusion-reactions#rhig]])
- 輸血前檢驗：ABO 與 Rh 定型、抗體篩檢、**交叉試驗**(看病人血清與捐血者紅血球是否**凝集**，確認相容，不是檢查過敏)；流程見 [[transfusion-reactions#before]]
- 抗原抗體細節見 [[immunoglobulins-hla#abo]]

## 骨髓抽吸與切片 {#bone-marrow-exam}

- 目的：看骨髓與**造血組織**是否正常，**診斷**白血病、不明原因貧血、血小板減少、無法解釋的**肝脾腫大**、淋巴瘤與癌症是否侵犯骨髓(分期)，以及**評估化療或移植效果**；可算出各系血球前驅細胞的數量與比例
- **評估「骨髓壓力」不是骨髓檢查的目的**

| 項目 | 成人 | 兒童(《兒科護理學》p.486–487) |
|---|---|---|
| 部位 | **後腸骨嵴**(最常用)、前腸骨嵴；**胸骨**(第 2–3 肋間，只能抽吸) | **18 個月以下：近側脛骨**(骨面平、好定位)；**18 個月以上：後腸骨嵴**(骨髓量多、避開大血管) |
| 麻醉 | **局部麻醉**，不需全身麻醉 | 局部麻醉，常加短效鎮靜 |
| 術後加壓 | 至少 5–10 分鐘，血小板低者更久；可平躺壓住或砂袋加壓 | 紗布覆蓋加壓**至少 15 分鐘**，凝血差者更久 |

- 檢查前：評估**出血病史與用藥**(aspirin、warfarin 等)、過敏史；解釋並取得同意書
- 檢查後：監測**生命徵象**(用鎮靜者到完全清醒)；**第 1 小時**密切看傷口出血；觀察感染；24 小時保持乾燥
- 不選肋骨、脊椎或脛骨(成人)；白血病病人的做法見 [[leukemia#bone-marrow-aspiration]]

## 失調時 {#dysregulation}

- 貧血(缺鐵、巨球性、再生不良、溶血)與紅血球增多症：[[anemias]]
- 血小板減少、ITP、血友病、DIC：[[bleeding-disorders]]；凝血檢驗：[[coagulation-tests]]
- 白血病、淋巴瘤、多發性骨髓瘤：[[leukemia]]、[[lymphoma-myeloma]]
- 輸血與輸血反應：[[transfusion-reactions]]；造血幹細胞移植：[[stem-cell-transplant]]
- 血栓、栓塞、梗塞：[[thrombosis-embolism-infarction]]
