**腎上腺**是兩個腺體疊在一起：外層**皮質**分泌類固醇，內層**髓質**其實是特化的交感神經。本頁整理構造、三種皮質激素與髓質激素的作用，以及壓力時的激素變化；腎上腺疾病見 [[cushing-syndrome]]、[[adrenal-insufficiency]]、[[pheochromocytoma-aldosteronism]]，負回饋與判斷病變層次見 [[endocrine-overview#feedback]]

## 重點摘要 {#summary}

- 位置：腹膜後、**腎臟上方**；外層**皮質**來自中胚層，內層**髓質**來自神經嵴
- 皮質三層(由外到內)，記法「鹽、糖、性」
   1. **絲球帶**：**礦物皮質素(醛固酮)**
   2. **束狀帶**(最厚)：**糖皮質素(皮質醇)**
   3. **網狀帶**：**雄性素**
- 髓質的**嗜鉻細胞**分泌**腎上腺素**(約 80%)與正腎上腺素，受交感**節前纖維**直接支配
- **醛固酮**：作用在**遠曲小管與集尿管**，**保鈉排鉀**(也排氫離子)，水跟著鈉回收 → 血量與血壓上升
- **皮質醇**：**清晨 6–8 點最高**、午夜最低；升血糖、分解蛋白質、抗發炎、抑制免疫、抑制生長、讓骨質流失
- 自體免疫破壞**整個皮質**(愛迪生氏病) → 糖皮質素、礦物皮質素與雄性素都不足，**ACTH 大量增加**；髓質激素不受影響
- 壓力與休克：ACTH、皮質醇、**腎素**、醛固酮、ADH、兒茶酚胺都**上升** → 血糖上升(壓力性高血糖)

### 國考常考點 {#exam-points}

- **嗜鉻細胞**在**腎上腺髓質**；可分成絲球帶、束狀帶、網狀帶的是**腎上腺皮質**
- 醛固酮作用在**遠曲小管與集尿管**，**不是近曲小管**；礦物皮質素促進鉀**排出**，不是再吸收
- 血管張力素原由**肝臟**分泌；腎素本身不收縮血管；失血與缺水都讓醛固酮與血管張力素 II **增加**
- 血管收縮素 II 增加 → 動脈壓上升；ANP 增加、醛固酮降低 → 血壓下降
- 皮質醇是皮質分泌量**最多**的類固醇，清晨最高，會**升高**血糖、增加抗壓與抗發炎
- 庫欣氏症候群是**糖皮質素**過多：肌肉流失、水腫、傷口癒合差、**糖質新生增加、胰島素利用降低**(高血糖)
- 康氏症候群是**醛固酮**過多；ACTH 大量分泌的是**愛迪生氏症**(接受糖皮質素治療的人 ACTH 反而被抑制)
- 原發性腎上腺皮質功能不全要破壞約 **90%** 以上皮質才出現症狀；皮膚變黑是 ACTH 與 MSH 增加
- 最可能抑制生長的激素是**皮質醇**
- 重症病人高血糖最可能是**壓力引起的糖質新生**；休克時腎素**上升**
- 腎上腺素讓唾液分泌**減少**、心臟收縮**增強**、肝醣**分解**

| 部位 | 細胞 | 分泌 | 主要調控 |
|---|---|---|---|
| 皮質**絲球帶**(最外) | 小團狀排列 | **醛固酮**(礦物皮質素) | **血管張力素 II**、**高血鉀**；ACTH 影響小 |
| 皮質**束狀帶**(最厚) | 柱狀排列、富含脂滴 | **皮質醇**(糖皮質素) | **ACTH** |
| 皮質**網狀帶** | 網狀排列 | **雄性素**(DHEA 等) | ACTH |
| **髓質** | **嗜鉻細胞** | **腎上腺素**、正腎上腺素 | 交感神經節前纖維 |

- 皮質激素都由**膽固醇**合成(類固醇激素)；髓質的兒茶酚胺由酪胺酸合成
- 髓質相當於沒有軸突的交感節後神經元，所以腎上腺和腦下垂體一樣，是神經與腺體共同組成的器官

## 醛固酮與腎素－血管張力素系統 {#aldosterone}

- RAAS 的完整流程與降血壓藥作用點見 [[blood-pressure-regulation#raas]]
   1. 血壓或血量下降、低血鈉、交感興奮 → 腎臟近腎絲球細胞分泌**腎素**
   2. 腎素把**肝臟**分泌的**血管張力素原**切成血管張力素 I → 肺臟的 ACE 轉成**血管張力素 II**
   3. 血管張力素 II：**收縮小動脈**、刺激**醛固酮**與 ADH、引起口渴、增加近曲小管的鈉氫交換
- **醛固酮的作用**(遠曲小管與集尿管)
   1. **回收鈉**(氯跟著回收)，**水跟著鈉**回到血液 → 血量與血壓上升
   2. **排出鉀**與**氫離子**
- 失血、缺水、休克 → 腎素、血管張力素 II、醛固酮都**增加**
- **心房利鈉胜肽**(ANP)作用相反：排鈉利尿、降血壓
- 醛固酮過多(**康氏症候群**，原發性醛固酮過多症)：高血壓、**低血鉀**、代謝性鹼中毒
- 題目分歧：110-2_BM_027(選錯誤者)考選部答案為(D)；但依生理學，血管張力素 II 減少確實會減少近曲小管分泌氫離子，(D)是對的敘述，反而(C)「醛固酮過量造成腎小管性酸中毒」是錯的(醛固酮過多造成**代謝性鹼中毒**)；作答以考選部答案為準

## 皮質醇 {#cortisol}

- **分泌節律**：受 ACTH 控制，**清晨起床後 6–8 點最高**、傍晚下降、**午夜最低**；壓力時大量增加
- 是皮質分泌量**最多**的類固醇

| 系統 | 作用 | 過多時(庫欣氏症候群)的表現 |
|---|---|---|
| 醣類 | 肝臟**糖質新生增加**、周邊**胰島素利用降低** | **高血糖**、類固醇性糖尿病 |
| 蛋白質 | 分解肌肉蛋白質提供糖質新生原料 | **肌肉流失、無力**、皮膚變薄、紫紋 |
| 脂肪 | 脂肪重新分布 | 向心性肥胖、月亮臉、水牛肩 |
| 免疫與發炎 | **抗發炎**、抑制免疫，淋巴球與嗜伊紅球下降 | **易感染、傷口癒合差** |
| 水鹽 | 高濃度時有礦物皮質素作用 | 鈉水滯留、**水腫**、高血壓 |
| 骨骼與生長 | 抑制成骨細胞、減少腸道吸收鈣；抑制生長激素作用 | 骨質疏鬆；兒童**生長受抑制** |
| 心血管 | 讓血管對兒茶酚胺有反應(允許作用) | |

- 長期使用類固醇藥物的副作用與減量見 [[corticosteroids]]
- **地塞米松抑制試驗**(DST)：給 dexamethasone 正常會抑制 ACTH 與皮質醇；庫欣氏症候群與部分**憂鬱症**病人(HPA 軸過度活化)皮質醇**無法被抑制**(見 [[neurotransmitters-psychiatry#hpa-axis]])

### 皮質功能不足的生理 {#cortical-insufficiency}

- **原發性**(愛迪生氏病，常見自體免疫)：整個皮質被破壞 → **糖皮質素、礦物皮質素、雄性素**都減少；通常破壞 **90% 以上**才有明顯症狀
   1. 皮質醇少 → 負回饋消失 → **ACTH 與 CRH 大量增加**
   2. ACTH 與 MSH 來自同一個前驅蛋白 → **皮膚與黏膜變黑**
   3. 醛固酮少 → 低血鈉、**高血鉀**、低血壓
- **次發性**：腦下垂體 ACTH 不足或下視丘 **CRH** 不足 → 主要是皮質醇不足，醛固酮多半正常，皮膚不會變黑
- **接受糖皮質素治療**的人：外來類固醇抑制 ACTH(不會增加)，長期使用可能腎上腺萎縮
- 腎上腺危象的處置見 [[adrenal-insufficiency#adrenal-crisis]]

## 腎上腺髓質 {#medulla}

- **腎上腺素**約 80%、正腎上腺素約 20%；受交感神經節前纖維(乙醯膽鹼)刺激直接釋放
- 作用與交感神經相同，受體與各器官反應見 [[autonomic-nervous-system]]
   1. 心跳加快、**心臟收縮增強**(β1)
   2. 支氣管擴張(β2)、瞳孔放大、**睫狀肌放鬆**(看遠)
   3. **肝醣分解**、脂肪分解 → 血糖與脂肪酸上升
   4. **唾液分泌減少**而黏稠、腸胃蠕動減少
- 藥物見 [[adrenergic-agonists]]；髓質腫瘤見 [[pheochromocytoma-aldosteronism#pheochromocytoma]]

## 壓力反應 {#stress-response}

| 系統 | 速度 | 激素 | 主要效果 |
|---|---|---|---|
| **交感－腎上腺髓質** | 快(秒) | 腎上腺素、正腎上腺素 | 戰或逃：心跳、血壓、血糖上升 |
| **HPA 軸**(下視丘－腦下垂體－腎上腺) | 慢(分鐘到小時) | CRH → ACTH → **皮質醇** | 維持血糖、抑制發炎 |
| **RAAS 與 ADH** | 中等 | 腎素、血管張力素 II、醛固酮、ADH | 保留鹽與水、維持血壓 |
| 其他 | | 升糖素、生長激素 | 升血糖 |

- **HPA 軸**是面對壓力源時**主要**的內分泌調節系統；壓力也會改變**前額葉與邊緣系統**(杏仁核)，見 [[trauma-stress-disorders#stress-response]]
- **休克代償**：血壓下降 → **腎素上升** → 醛固酮上升；ACTH、ADH 也上升
- **重症病人的高血糖**：多半不是新發現的糖尿病，而是壓力讓兒茶酚胺、皮質醇、升糖素增加 → **糖質新生**與胰島素阻抗(壓力性高血糖)
