男性生殖系統負責產生精子、分泌雄性素，並把精子送進女性生殖道。本頁整理陰囊與睪丸、精子生成、導管與附屬腺體、陰莖、精液與精液分析，以及胚胎性分化。文中縮寫：FSH（Follicle-stimulating hormone，濾泡刺激素）、LH（Luteinizing hormone，黃體生成素）、DHT（Dihydrotestosterone，雙氫睪固酮）、AMH（Anti-Müllerian hormone，抗穆勒氏管激素）。睪丸細胞與激素的回饋見 [[endocrine-overview#testis]]，女性構造見 [[female-reproductive-system]]，男性生殖疾病見 [[male-reproductive-disorders]]，前列腺肥大與前列腺癌見 [[urologic-disorders]]

## 重點摘要 {#summary}

- **陰囊**的**肉膜肌**與**提睪肌**調整睪丸位置，讓睪丸比體溫低約 2–3 ℃，精子才能正常生成
- 精子在**曲細精管**生成
- **塞氏細胞**（支持細胞）：受 FSH 作用，形成**血睪障壁**、分泌**雄性素結合蛋白**、抑制素、AMH
- **萊氏細胞**（間質細胞）：在曲細精管**之間**，受 **LH** 刺激分泌**睪固酮**
- 精子生成約 **64–74 天**；**初級精母細胞雙套**，次級精母細胞、精細胞、精子都是**單套**
- 精子在**副睪**成熟、獲得運動能力並**儲存**；副睪上皮有**靜纖毛**
- 精液路徑：曲細精管 → 直細精管 → 睪丸網 → 輸出小管 → **副睪** → **輸精管** → 射精管 → 尿道
- 精液約 60–70% 來自**精囊**（含**果糖**），約 25–30% 來自**前列腺**
- **前列腺**在**膀胱下方**、泌尿生殖膈上方、**直腸前方**（肛門指診可摸到）
- 龜頭與**陰莖球**都由**尿道海綿體**構成
- 胚胎外生殖器發育成男性，直接靠 **DHT**

### 國考常考點 {#exam-points}

- 產生精子的是**曲細精管**；睪丸網、直細精管、輸出小管只負責運送
- 分泌雄性素的是**萊氏細胞**；形成血睪障壁的是**塞氏細胞**；**曲細精管內沒有萊氏細胞**
- 睪丸內與睪固酮結合的是**雄性素結合蛋白**（塞氏細胞分泌）；血中運送睪固酮的是性激素結合球蛋白
- 含**血睪障壁**的是**曲細精管**
- 精子**儲存並成熟**在**副睪**，不是精囊；精囊分泌果糖等液體
- 與副睪直接相連的是**輸精管**
- 精子生成全程約 **60–70 天**
- 精子 23 條染色體（單套），最適溫度**低於體溫**；**FSH** 有助精子生成
- **雙套**的是精原細胞與**初級精母細胞**；**單套 23 條不成對**的是**精細胞**與精子
- 具**肉膜肌**的是**陰囊**
- 前列腺在直腸**前方**，不是後方
- 開口在**前列腺段尿道**的有射精管、前列腺導管、前列腺小囊；**尿道球腺導管開口在海綿體段（陰莖段）尿道**
- 輸精管經**鼠蹊管**進入骨盆腔
- 精液分析：精子濃度 800 萬/mL（低於 1,600 萬/mL）＝**精蟲減少症**

## 陰囊與睪丸 {#testis}

- **陰囊**：皮膚下有**肉膜肌**（平滑肌，冷時收縮使陰囊皺縮）；**提睪肌**（骨骼肌）冷時把睪丸往上拉，熱時放鬆下降
- 睪丸溫度約比腹腔低 2–3 ℃；隱睪（睪丸留在腹腔）會影響精子生成並增加睪丸腫瘤風險（見 [[pediatric-genitourinary]]、[[male-reproductive-disorders#testicular-tumors]]）
- 睪丸外有白膜，向內分隔成約 250 個小葉，每小葉有 1–4 條**曲細精管**

| 細胞 | 位置 | 受誰刺激 | 功能 |
|---|---|---|---|
| **塞氏細胞**（支持細胞） | 曲細精管**內**，從基底膜延伸到管腔 | **FSH**＋睪固酮 | 相鄰細胞以緊密接合形成**血睪障壁**（保護精子不被免疫系統攻擊）；餵養精子；分泌**雄性素結合蛋白**（讓曲細精管內睪固酮濃度高）、**抑制素**（負回饋抑制 FSH）、胚胎期分泌 **AMH** |
| **萊氏細胞**（間質細胞） | 曲細精管**之間**的結締組織 | **LH** | 分泌**睪固酮** |
| 精原細胞與各期生殖細胞 | 曲細精管內，由外往管腔成熟 | | 精子生成 |

## 精子生成 {#spermatogenesis}

| 細胞 | 分裂 | 染色體 |
|---|---|---|
| **精原細胞** | 有絲分裂增生（青春期開始） | 雙套 46 |
| **初級精母細胞** | 進入第一次減數分裂 | **雙套 46** |
| 次級精母細胞 | 第一次減數分裂完成 → 2 個 | 單套 23（每條含兩條染色分體） |
| **精細胞** | 第二次減數分裂完成 → 4 個 | **單套 23 條、不成對** |
| 精子 | 精細胞變形（精子形成），長出頭部頂體與尾部鞭毛 | 單套 23 |

- 一個初級精母細胞產生 **4 個精子**；一個初級卵母細胞只產生 1 個卵（比較見 [[female-reproductive-system#oogenesis]]）
- 全程約 **64–74 天**（約 2 個多月）；所以影響精子的因素（發燒、藥物、熱）要 2–3 個月後才反映在精液分析
- 精子在女性生殖道約可存活 **3 天**（課本書頁約 496）

## 導管與附屬腺體 {#ducts-glands}

| 構造 | 重點 |
|---|---|
| **副睪** | 睪丸後上方；上皮有**靜纖毛**；精子在此**成熟、獲得運動能力並儲存**（約 2 週） |
| **輸精管** | 接副睪；隨**精索**經**鼠蹊管**進入骨盆腔，繞到膀胱後方；男性結紮在此 |
| 精索 | 輸精管、睪丸動靜脈（蔓狀靜脈叢）、神經、提睪肌；精索扭轉與靜脈曲張見 [[male-reproductive-disorders#torsion]] |
| 射精管 | 輸精管壺腹＋精囊導管合成，穿過前列腺開口於**前列腺段尿道** |
| **精囊** | 膀胱後方；分泌**果糖**（精子能量）、前列腺素，占精液**約 60–70%**；**不儲存精子** |
| **前列腺** | **膀胱下方**、泌尿生殖膈上方、**直腸前方**、恥骨聯合後方；分泌弱鹼性液體（含 PSA，Prostate-specific antigen），占約 25–30%；導管開口於前列腺段尿道 |
| **尿道球腺**（考伯氏腺） | 泌尿生殖膈內；導管開口於**海綿體段尿道**；射精前分泌黏液潤滑並中和尿道酸性 |

- 男性尿道：前列腺段 → 膜部（穿過泌尿生殖膈） → 海綿體段（陰莖段）
- 前列腺分區與疾病：前列腺癌多在**周邊區**，良性肥大多在**移行區**（見 [[urologic-disorders]]）

## 陰莖 {#penis}

- 三條勃起組織：背側兩條**陰莖海綿體**（近端分開成**陰莖腳**）、腹側一條**尿道海綿體**（包住尿道）
- **尿道海綿體**前端膨大成**龜頭**、近端膨大成**陰莖球**
- 勃起：副交感神經 → 一氧化氮使動脈擴張 → 海綿體充血、壓迫靜脈；射精靠交感神經（勃起功能障礙用藥見 [[sex-hormones]]）
- 包皮包住龜頭；包莖與兒童包皮處理見 [[pediatric-genitourinary]]

## 性分化與同源器官 {#sexual-differentiation}

- 第 7 週前男女胚胎相同（未分化性腺、**中腎管**與**副中腎管**兩套、相同的外生殖器原基）
- 男性分化步驟
   1. Y 染色體的 **SRY** 基因 → 性腺分化成**睪丸**
   2. 塞氏細胞分泌 **AMH** → **副中腎管（穆勒氏管）退化**（不長子宮、輸卵管）
   3. 萊氏細胞分泌**睪固酮** → **中腎管**發育成副睪、輸精管、精囊
   4. 睪固酮經 5α 還原酶轉成 **DHT** → **外生殖器**（陰莖、陰囊）與**前列腺**男性化
- 沒有 SRY → 卵巢；沒有 AMH → 副中腎管發育成輸卵管、子宮、陰道上段；沒有雄性素 → 外生殖器發育成女性
- 5α 還原酶缺乏或雄性素不敏感 → 外生殖器女性化（見 [[endocrine-overview#testis]]）

| 男性 | 女性 | 共同原基 |
|---|---|---|
| 睪丸 | 卵巢 | 生殖腺 |
| **陰莖**（龜頭、海綿體） | **陰蒂** | 生殖結節 |
| 陰莖球 | 前庭球 | |
| **陰囊** | **大陰唇** | 陰唇陰囊隆起 |
| 尿道海綿體段 | 小陰唇 | 尿道褶 |
| 尿道球腺 | 前庭大腺 | |
| 前列腺 | 尿道旁腺(Skene's gland) | 泌尿生殖竇 |
