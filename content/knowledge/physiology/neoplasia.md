**腫瘤**(neoplasm)是細胞**不受正常調控、持續增生**所形成的異常組織；即使刺激消失，它仍會繼續長。腫瘤分成**良性**與**惡性**，惡性腫瘤就是一般說的**癌症**。本頁整理病理學的基本觀念：命名、良惡性區別、轉移、分級與分期、致癌的基因與外在因子，這些是病理、微免與內外科癌症章節共同的基礎。抗癌藥見 [[antineoplastics]]，腫瘤標記見 [[tumor-markers]]。

## 細胞的異常生長 {#abnormal-growth}

腫瘤之前，細胞常先出現一連串「還可逆」的變化。國考常考這幾個名詞的差別：

| 名詞 | 定義 | 可逆嗎 | 例子 |
|---|---|---|---|
| 增生(hyperplasia) | 細胞**數目**增加，形態正常 | 可逆 | 子宮內膜增生、良性攝護腺增生 |
| 肥大(hypertrophy) | 細胞**體積**變大 | 可逆 | 高血壓的左心室肥大 |
| **化生**(metaplasia) | 一種成熟細胞**被另一種成熟細胞取代** | 可逆 | 吸菸者支氣管：纖毛柱狀上皮 → 鱗狀上皮；**巴瑞特食道**：鱗狀 → 柱狀上皮 |
| **異生**(dysplasia) | 細胞大小形狀不一、排列紊亂，但**尚未突破基底膜**；是**癌前病變** | 輕中度可能可逆 | 子宮頸上皮內病變(CIN 1–3) |
| **原位癌**(carcinoma in situ) | 重度異生**占據上皮全層**，但**仍未穿過基底膜** | 不可逆，但切除可治癒 | 子宮頸原位癌、乳管原位癌 |
| 侵襲癌(invasive carcinoma) | 癌細胞**穿過基底膜**進入間質 | — | 此時才有機會轉移 |
| 分化不良(anaplasia) | 細胞完全失去分化特徵，是**惡性**的標誌 | — | 未分化癌 |

- 上皮的癌是否「穿過**基底膜**」，是原位癌和侵襲癌的分界。
- 異生依異常程度分**輕、中、重度**；重度異生占據全層就等於原位癌。

## 命名與分類 {#nomenclature}

依**細胞來源**與**良惡性**命名：

| 來源 | 良性 | 惡性 |
|---|---|---|
| **上皮**(覆蓋上皮) | **乳頭狀瘤**(papilloma) | **鱗狀細胞癌**(squamous cell carcinoma) |
| **上皮**(腺體) | **腺瘤**(adenoma) | **腺癌**(adenocarcinoma) |
| 結締組織：脂肪 | 脂肪瘤(lipoma) | 脂肪肉瘤(liposarcoma) |
| 結締組織：骨 | 骨瘤(osteoma) | **骨肉瘤**(osteosarcoma) |
| 結締組織：軟骨 | 軟骨瘤(chondroma) | **軟骨肉瘤**(chondrosarcoma) |
| 平滑肌 | 平滑肌瘤(leiomyoma，例：子宮肌瘤) | 平滑肌肉瘤(leiomyosarcoma) |
| 橫紋肌 | 橫紋肌瘤(rhabdomyoma) | **橫紋肌肉瘤**(rhabdomyosarcoma，兒童常見的軟組織惡性腫瘤) |
| 血管 | 血管瘤(hemangioma) | 血管肉瘤(angiosarcoma) |
| 造血與淋巴 | — | 白血病、淋巴瘤、多發性骨髓瘤 |

- 規則：良性 = 字尾 **-oma**；惡性上皮 = **carcinoma(癌)**；惡性間質(結締組織、肌肉、骨) = **sarcoma(肉瘤)**。
- **例外**(名字是 -oma，卻是**惡性**)：**淋巴瘤**(lymphoma)、**黑色素瘤**(melanoma)、精原細胞瘤(seminoma)、間皮瘤(mesothelioma)、肝細胞瘤(hepatoma，即肝細胞癌)。
- **胚芽細胞瘤**(-blastoma)：來自胚胎組織，多見於兒童，多為惡性，例如神經母細胞瘤、**視網膜母細胞瘤**、腎母細胞瘤(**威爾姆氏腫瘤**)、髓母細胞瘤。
- **畸胎瘤**(teratoma)：含兩種以上胚層的組織(毛髮、牙齒)，成熟型多為良性。
- **不是腫瘤**：缺陷瘤(hamartoma，組織在原位長得雜亂)、迷離瘤(choristoma，正常組織長錯位置)。

## 良性與惡性腫瘤的區別 {#benign-vs-malignant}

| 特徵 | 良性 | 惡性 |
|---|---|---|
| **分化** | **分化良好**，像原來的組織 | **分化不良**或未分化 |
| 細胞形態 | 大小形狀一致 | **多形性**(大小形狀不一)、**核大且深染** |
| **核質比** | 正常 | **上升**(核變大) |
| 有絲分裂 | 少、正常 | **多**，且有**異常分裂象** |
| **生長速度** | 慢，可能停止 | **快** |
| **包膜** | **常有纖維包膜**，界線清楚、可推動 | **沒有包膜**，界線不清、固定 |
| 生長方式 | **擴張性**(推擠周圍) | **浸潤性**(侵入周圍) |
| **轉移** | **不會** | **會** |
| 復發 | 切除後少復發 | **容易復發** |
| 全身影響 | 通常很少 | **消瘦(惡病質)、貧血**、發燒、副腫瘤症候群 |

癌細胞的生物特性(常出在「下列何者正確」)：

- **失去接觸抑制**(contact inhibition)：正常細胞長滿就停止分裂，癌細胞會疊著長。
- **細胞間黏著性降低、活動力增加**：容易脫落、移動 → 侵犯與轉移。
- 不需要生長訊號也會增生，對抑制訊號沒有反應；**逃避細胞凋亡**；端粒酶活化 → **無限分裂**。
- 誘發**血管新生**(分泌 VEGF)；**逃避免疫**；代謝改變(大量利用葡萄糖)。
- 常造成**消瘦、貧血**(惡病質與慢性病貧血)。

:::warning[良性不代表沒有危險]
良性腫瘤如果長在**密閉空間**(顱內)或**管腔**(支氣管、腸道)，會**壓迫或阻塞**而產生症狀，甚至致命；內分泌腺的良性腫瘤也可能分泌過多荷爾蒙(例：腦下垂體腺瘤)。
:::

## 侵犯與轉移 {#metastasis}

### 轉移的步驟 {#metastasis-steps}

1. 癌細胞彼此**鬆脫**，分泌酵素**分解基底膜與細胞外基質**。
2. **侵入**淋巴管或血管。
3. 在循環中**存活**(躲過免疫細胞)。
4. 在遠處**穿出血管**、**著床**並誘發血管新生，長成轉移病灶。

### 轉移途徑 {#metastasis-routes}

| 途徑 | 特性 | 例子 |
|---|---|---|
| **淋巴轉移** | **癌(carcinoma)** 最常見；先到**區域淋巴結**(前哨淋巴結) | 乳癌 → 腋下淋巴結 |
| **血行轉移** | **肉瘤(sarcoma)** 最常見；常到**肺**(經體靜脈)與**肝**(經門靜脈) | 骨肉瘤 → 肺；大腸癌 → 肝 |
| **播種(體腔)轉移** | 癌細胞掉進腹腔、胸腔等**體腔**表面散布 | **卵巢癌** → 腹膜；胃癌 → 卵巢(Krukenberg 腫瘤) |

- 「接觸轉移」**不是**轉移途徑。
- 常見的轉移部位：**淋巴結、肝、肺、骨、腦**；**腎臟**雖然血流多，卻**很少**被轉移。
- 腦的轉移瘤最常來自**肺癌、乳癌**。

### 骨轉移 {#bone-metastasis}

- 最常轉移到骨頭的癌：**乳癌、攝護腺癌、肺癌、腎臟癌、甲狀腺癌**。
- **成骨性**(osteoblastic，X 光變白)：最典型是**攝護腺癌**。
- **溶骨性**(osteolytic，骨頭被破壞)：**肺癌、腎臟癌、甲狀腺癌、多發性骨髓瘤**；乳癌多為溶骨或混合型。
- 溶骨會釋出鈣 → **高血鈣**、骨痛、**病理性骨折**、脊髓壓迫。
- 偵測：**骨掃描**(靜脈注射放射性同位素)。

## 分級與分期 {#grading-staging}

| | **分級(grading)** | **分期(staging)** |
|---|---|---|
| 看什麼 | 顯微鏡下細胞的**分化程度** | 腫瘤的**大小、侵犯範圍、淋巴結、遠處轉移** |
| 表示 | **G1**(分化良好)→ G2 → G3 → **G4**(未分化)；GX 無法評估 | **TNM** 與 0–IV 期 |
| 臨床意義 | 反映惡性度 | **與預後、治療方針最相關**，比分級重要 |

### TNM 系統 {#tnm}

| 代號 | 意義 |
|---|---|
| **T**(原發腫瘤) | **TX**：原發腫瘤**無法評估**；**T0**：**沒有**原發腫瘤證據；**Tis**：原位癌；T1–T4：大小或侵犯範圍遞增 |
| **N**(區域淋巴結) | NX：無法評估；N0：無淋巴結轉移；N1–N3：轉移淋巴結的數量或範圍遞增 |
| **M**(遠處轉移) | M0：無遠處轉移；**M1**：有遠處轉移(通常 = 第 IV 期) |

- 前綴代表分期的依據：**c**(臨床，依身體檢查與影像)、**p**(病理，依**手術切除**的組織)、**y**(治療後)、**r**(復發)、**a**(屍檢)。**沒有「s」**。
- 分期：**0 期** = 原位癌；I–III 期依 TNM 組合；**IV 期** = 遠處轉移。每種癌的組合規則不同，由 AJCC 分期手冊訂定(來源：[NCI：Cancer Staging](https://www.cancer.gov/about-cancer/diagnosis-staging/staging))。
- 乳癌的例子：腫瘤 **2–5 公分** = **T2**；同側腋下 **1–3 顆**淋巴結 = **N1**；手術後病理報告就寫 **pT2N1**。沒有遠處轉移時為第 II 期(IIB)。

:::note[舊寫法 MX]
現行 AJCC 第 8 版已經**不使用 MX**(沒有證據就寫 M0)，但國考題仍可能出現「pT2N1Mx」這種寫法，看到時照題意判讀即可。
:::

## 癌化的分子機轉 {#molecular}

癌症是**多重步驟**的過程：**基因突變且沒有被修復**是第一步(起始)，再經過促進、進展，累積多個突變才成為癌。

### 兩大類基因 {#gene-types}

| | **致癌基因**(oncogene) | **抑癌基因**(tumor suppressor gene) |
|---|---|---|
| 正常角色 | 原致癌基因：促進細胞生長 | 踩煞車、修復 DNA、啟動凋亡 |
| 致癌方式 | **功能增強**(gain of function)，**一個**等位基因突變就夠 | **功能喪失**(loss of function)，通常**兩個**等位基因都失去(**雙重打擊**) |
| 比喻 | 油門卡住 | 煞車壞掉 |

**雙重打擊理論**(two-hit hypothesis，Knudson)：以**視網膜母細胞瘤**(RB 基因)為典型。遺傳型病人出生就帶一個突變，只要再一次打擊就發病，所以**較早發、常雙側**。

### 常考的基因 {#key-genes}

| 基因 | 類型 | 相關腫瘤 |
|---|---|---|
| **RB** | 抑癌 | **視網膜母細胞瘤**、骨肉瘤 |
| **TP53**(p53，「基因守護者」) | 抑癌 | **人類癌症最常突變**的基因；Li-Fraumeni 症候群 |
| **APC** | 抑癌 | **家族性腺瘤性瘜肉症**(FAP)、大腸直腸癌 |
| **BRCA1、BRCA2** | 抑癌(DNA 修復) | **家族性乳癌與卵巢癌** |
| WT1 | 抑癌 | 威爾姆氏腫瘤 |
| DNA 錯配修復基因 | DNA 修復 | 遺傳性非瘜肉症大腸癌(Lynch 症候群) |
| **RAS** | 致癌 | 胰臟癌、大腸癌、肺癌等(最常見的致癌基因突變) |
| MYC | 致癌 | **勃氏淋巴瘤**(t(8;14)) |
| **HER2**(ERBB2) | 致癌(基因放大) | **乳癌**(標靶藥 trastuzumab) |
| **EGFR** | 致癌 | **非小細胞肺癌**(標靶藥 gefitinib 等) |
| **BCR-ABL**(t(9;22)，費城染色體) | 致癌(融合基因) | **慢性骨髓性白血病**(標靶藥 imatinib) |
| **KIT** | 致癌 | **胃腸道基質瘤**(GIST，也用 imatinib) |
| **BCL2**(t(14;18)) | 抑制凋亡 | **濾泡性淋巴瘤** |
| BRAF、RET | 致癌 | 甲狀腺乳突癌(**TP53 突變少見**)、黑色素瘤(BRAF) |

這些基因多半就是**標靶藥物**的作用點，見 [[antineoplastics#targeted]]。

## 致癌因子 {#carcinogens}

### 化學性 {#chemical}

| 致癌物 | 主要相關癌症 |
|---|---|
| **菸草** | 肺癌、口腔癌、喉癌、食道癌、**膀胱癌**、胰臟癌等 |
| **檳榔** | **口腔癌**(台灣特別重要；合併菸酒風險倍增) |
| 酒精 | 口腔、咽喉、食道、肝癌、乳癌 |
| **黃麴毒素**(發霉花生、穀類) | **肝癌**(與 B 型肝炎協同) |
| 芳香胺(苯胺染料、橡膠業) | **膀胱癌** |
| **砷**(台灣烏腳病地區的井水) | 皮膚癌、膀胱癌、肺癌 |
| **石綿** | **間皮瘤**、肺癌 |
| **苯** | **白血病** |
| 氯乙烯 | 肝血管肉瘤 |
| 甲醛 | **鼻咽癌**、白血病(**不是**大腸癌) |
| 亞硝胺(醃燻食物) | 胃癌、食道癌、鼻咽癌(鹹魚) |
| 烷基化類抗癌藥 | 續發性白血病 |

### 物理性 {#physical}

- **紫外線**：皮膚的基底細胞癌、鱗狀細胞癌、**黑色素瘤**。
- **游離輻射**(原爆、放射線)：**白血病**、甲狀腺癌、乳癌。
- 慢性刺激、慢性發炎(如慢性潰瘍、慢性肝炎)也會增加癌化機會。

:::tip[基本護理的連結]
**惡性腫瘤部位不可熱敷**：熱療使局部血管擴張、代謝增加，可能促進腫瘤生長與擴散。
:::

### 生物性(病毒、細菌、寄生蟲) {#biological}

| 病原 | 相關腫瘤 | 重點 |
|---|---|---|
| **人類乳突病毒 HPV 16、18**(高危險型) | **子宮頸癌**、口咽癌、肛門癌、**陰莖鱗狀細胞癌** | **第 16 型**最相關；E6 抑制 p53、E7 抑制 RB。**第 6、11 型**(低危險型)造成**尖形濕疣(菜花)**，不是子宮頸癌的危險因子 |
| **EB 病毒**(EBV) | **鼻咽癌**、**勃氏淋巴瘤**、部分何杰金氏淋巴瘤、移植後淋巴增生疾病 | 大多數人都感染過 EBV，**感染不等於一定得鼻咽癌** |
| **B 型肝炎病毒**(HBV) | **肝細胞癌** | DNA 病毒，**嵌入宿主基因**使細胞永生化；台灣肝癌最主要原因 |
| **C 型肝炎病毒**(HCV) | 肝細胞癌 | 經慢性發炎與肝硬化 |
| **HTLV-1** | **成人 T 細胞白血病／淋巴瘤**(不是慢性淋巴性白血病) | 反轉錄病毒 |
| **HHV-8**(卡波西肉瘤疱疹病毒) | **卡波西肉瘤**(常見於愛滋病人) | |
| **幽門螺旋桿菌** | **胃腺癌**、胃 **MALT 淋巴瘤**(B 細胞) | 細菌；**不是**食道癌的原因 |
| 肝吸蟲(華支睪吸蟲) | 膽管癌 | |
| **埃及血吸蟲** | **膀胱癌**(鱗狀細胞癌) | |

- **與癌症無關**、常當成錯誤選項的：**A 型肝炎病毒**(急性感染、不會慢性化)、**腺病毒**、**巨細胞病毒**(CMV)。
- 病毒致癌的機轉：病毒基因**嵌入**宿主 DNA，或病毒蛋白**抑制抑癌基因**(p53、RB)，使細胞**永生化**但不死亡。
- 可用**疫苗**預防的癌症：**B 型肝炎疫苗**(肝癌)、**HPV 疫苗**(子宮頸癌等)。

(來源：[IARC Group 1 致癌物清單](https://monographs.iarc.who.int/list-of-classifications))

### 其他危險因子 {#other-risks}

- **荷爾蒙**：長期雌激素刺激 → 子宮內膜癌、乳癌。
- **免疫抑制**：器官移植、愛滋病 → 淋巴瘤、卡波西肉瘤、皮膚癌風險上升。
- **遺傳**：BRCA、APC、RB 等家族遺傳基因。
- 年齡(突變隨時間累積)、肥胖、缺乏運動、飲食(高脂低纖 → 大腸癌)。

## 腫瘤與免疫 {#tumor-immunity}

- **免疫監視**：細胞毒性 T 細胞透過 **MHC 第一類分子**辨認癌細胞；**NK 細胞**專殺 MHC 表現下降的細胞。
- 癌細胞的**免疫逃脫**：**降低 MHC 表現**、表現 **PD-L1** 讓 T 細胞「踩煞車」、分泌抑制性物質。**免疫檢查點抑制劑**就是解除這個煞車，見 [[antineoplastics#immunotherapy]]。
- 所以免疫功能低下的人，癌症(尤其病毒相關的)發生率較高。

## 腫瘤對全身的影響 {#host-effects}

- **惡病質**(cachexia)：腫瘤與免疫細胞釋放 **TNF-α**、IL-6 等細胞激素 → 食慾差、肌肉與脂肪消耗。
- **貧血**：慢性病貧血、骨髓被侵犯、出血、治療副作用。
- **副腫瘤症候群**(腫瘤分泌荷爾蒙或引發免疫反應)：

| 表現 | 機轉 | 常見腫瘤 |
|---|---|---|
| **高血鈣** | 分泌副甲狀腺素相關蛋白(PTHrP)，或骨轉移溶骨 | 肺鱗狀細胞癌、乳癌、多發性骨髓瘤 |
| **SIADH**(低血鈉) | 分泌抗利尿激素 | **小細胞肺癌** |
| 庫欣症候群 | 分泌 ACTH | 小細胞肺癌 |
| **紅血球增多** | 分泌**紅血球生成素**(EPO) | **腎臟癌**、肝癌 |
| 肌無力症候群 | 自體抗體 | 小細胞肺癌 |

腎臟癌常見的是**分泌過多** EPO 造成紅血球增多，而不是「EPO 不足」。

## 診斷方法 {#diagnosis}

| 方法 | 重點 |
|---|---|
| **切片病理檢查**(biopsy) | **確定診斷的標準**；可經**內視鏡**、細針穿刺、手術切除取得組織，同時提供分級 |
| 細胞學檢查 | 抹片、刮取或抽取細胞；適合**篩檢**(如子宮頸抹片)，但**不能**取代組織切片確診 |
| 影像 | X 光、超音波、電腦斷層、**核磁共振(沒有游離輻射)**、正子造影(PET)、**骨掃描**(找骨轉移) |
| **腫瘤標記** | 主要用來**追蹤治療效果與復發**，不能單獨確診，見 [[tumor-markers]] |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 惡性：**分化不良、無包膜、生長快、易轉移易復發、核質比上升、失去接觸抑制、黏著性低**；良性**有包膜**，但長在密閉空間也會有症狀。
- 命名：上皮惡性 = **癌**，結締組織惡性 = **肉瘤**；**淋巴瘤、黑色素瘤**雖是 -oma 卻是惡性；**乳頭狀瘤**來自上皮。
- **異生**是癌前病變；**原位癌** = 異常占據上皮全層、**未穿過基底膜**。
- 癌多經**淋巴**轉移、肉瘤多經**血行**；卵巢癌經**播種**；「接觸轉移」不是途徑；腎臟很少被轉移；**攝護腺癌骨轉移為成骨性**。
- **TX = 無法評估**(不是沒有腫瘤)；G4 = 未分化；手術病理分期用 **p**，沒有 s；分期比分級更影響預後。
- 基因：**RB**(雙重打擊、視網膜母細胞瘤)、**APC**(FAP)、**BRCA1/2**(乳癌卵巢癌)、**BCR-ABL**(CML)、**KIT**(GIST)、t(14;18)(濾泡性淋巴瘤)、**EGFR**(肺癌)、**HER2**(乳癌)。
- 病毒：**HPV 16**—子宮頸癌；**EBV**—鼻咽癌、勃氏淋巴瘤；**HBV**—肝癌；**HTLV-1**—成人 T 細胞白血病；幽門桿菌—胃癌與 MALT 淋巴瘤；**A 型肝炎、腺病毒、CMV 不致癌**。
- **確診靠切片病理**；MRI 沒有輻射；骨掃描找骨轉移。
:::
