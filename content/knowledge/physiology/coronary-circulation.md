心肌 24 小時不停收縮,幾乎完全靠**有氧代謝**,主要燃料是**脂肪酸**。靜息時心肌已經從冠狀動脈血中抽取約 **70–75% 的氧**(其他組織約 25%),所以需求增加時**不能再多抽氧,只能增加冠狀動脈血流**。一旦血流跟不上需求,就會缺血——心絞痛與心肌梗塞的共同起點。

每一段最後的「**藥物對應**」「**臨床對應**」說明哪一類藥物或疾病與這個機制有關。

## 冠狀動脈的分支與供應區 {#anatomy}

![冠狀動脈分支(前面觀)](/knowledge-images/coronary-arteries.svg)

左、右冠狀動脈都**直接由升主動脈**根部(主動脈瓣上方的主動脈竇)分出,是主動脈最先分出的分支。

| 血管 | 走向 | 主要供應區 | 阻塞時的心電圖導程 |
|---|---|---|---|
| **左冠狀動脈主幹**(LM) | 很短,隨即分成 LAD 與 LCx | 左心室大部分 | 廣泛導程;死亡率高 |
| **左前降支**(LAD,前心室間動脈) | 沿前心室間溝往心尖 | **左心室前壁、心尖、心室中膈前 2/3**;分出對角支、中膈支 | V1–V4(前中膈、前壁) |
| **左迴旋支**(LCx) | 走在**左側冠狀溝**內繞到後方 | **左心室側壁**、左心房;分出鈍緣支 | I、aVL、V5–V6 |
| **右冠狀動脈**(RCA) | 走在右側冠狀溝,分出右緣支,多數再分出**後心室間動脈**(PDA) | **右心房、右心室、左心室下壁**、中膈後 1/3;**竇房結(約 60%)**與**房室結(約 80–90%)** | **II、III、aVF**(下壁) |

- 左冠狀動脈的兩大分支是**前心室間動脈(LAD)與迴旋動脈(LCx)**;後心室間動脈與邊緣動脈不屬於左冠狀動脈的主要分支。
- **優勢型**:由哪一條供應後心室間動脈(PDA)決定。約 70–85% 的人是**右優勢**,少數為左優勢(由 LCx 供應)或共同優勢。
- **靜脈回流**:心臟壁大部分的缺氧血經心大、中、小靜脈匯入**冠狀竇**,再注入**右心房**;冠狀竇開口旁就是房室結。

**臨床對應**:**下壁梗塞**(II、III、aVF ST 上升)多為 RCA 阻塞,因 RCA 供應竇房結與房室結,常合併**心搏過緩與房室傳導阻斷**,也可能合併右心室梗塞(低血壓時避免 NTG、需補液)。前壁梗塞(LAD)範圍大,易造成心衰竭與心因性休克。心電圖定位詳見 [[ecg#territory]]、[[ecg#localization]];冠狀動脈攝影見 [[cardiac-catheterization]]。

## 冠狀動脈灌流 {#perfusion}

### 主要在舒張期灌流 {#diastolic-filling}

- 心室收縮時,心肌把貫穿心壁的小血管**擠壓關閉**,左心室心內膜下的血流在收縮期幾乎停止;所以**左心室的冠狀動脈血流約 70–80% 發生在舒張期**。
- 冠狀動脈灌流壓 ≈ **主動脈舒張壓 − 左心室舒張末期壓(LVEDP)**:舒張壓太低(休克、主動脈瓣閉鎖不全)或 LVEDP 太高(心衰竭)都會減少灌流。
- **心內膜下層**受壓最大、最遠離心外膜的大血管 → 最容易缺血,梗塞也從心內膜下開始。
- 右心室壓力低,收縮期與舒張期都有灌流。

### 心跳速率的雙重打擊 {#tachycardia}

心跳加快時,縮短最多的是**舒張期** → 灌流時間減少;同時心跳快本身增加耗氧 → **供給減少、需求增加**。

| 心跳 | 心動週期 | 舒張期 |
|---|---|---|
| 60 次/分 | 1.0 秒 | 約 0.6–0.7 秒 |
| 120 次/分 | 0.5 秒 | 約 0.2–0.25 秒 |

### 冠狀動脈血流的調節 {#autoregulation}

- **代謝性調節最重要**:心肌代謝增加 → 局部**腺苷**、CO₂、H⁺、K⁺ 增加、氧分壓下降 → 冠狀小動脈擴張。靜息血流約 225 mL/min(約占 CO 4–5%),劇烈運動時可增加 3–4 倍(冠狀血流儲備)。
- 在灌流壓約 60–140 mmHg 範圍內有**自動調節**;狹窄的血管遠端小動脈已經最大擴張,儲備用完 → 一運動就缺血(穩定型心絞痛)。
- 內皮分泌 NO 使血管擴張;粥狀硬化使內皮功能受損、容易痙攣。

:::exam[國考重點]
- 冠狀動脈**主要在舒張期灌流**;心跳越快舒張期越短 → 灌流越少。
- **β 阻斷劑**減慢心跳 → **延長舒張期**,增加心內膜下缺血區的供氧,同時降低收縮力與耗氧;它**不會**「縮短射血時間來省氧」。
- 冠狀動脈痙攣引起的**變異型心絞痛**,非選擇性 β 阻斷劑可能讓 α 收縮作用失去對抗而加重,首選 **CCB** 與硝酸鹽。
:::

**藥物對應**:[[beta-blockers|β 阻斷劑]]延長舒張期;[[nitrates|硝酸鹽]]擴張心外膜大冠狀動脈並解除痙攣;[[calcium-channel-blockers|CCB]] 擴張冠狀動脈,是變異型心絞痛首選。
**臨床對應**:**主動脈內氣球幫浦(IABP)**在**舒張期充氣**,把主動脈舒張壓推高 → 增加冠狀動脈灌流;收縮期前放氣 → 降低後負荷。(原理仍是考點;但 2025 指引**不建議**心肌梗塞合併心因性休克**常規**使用 IABP,因未改善存活(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309))。)

## 心肌耗氧量的決定因素 {#oxygen-demand}

心肌耗氧量(MVO₂)主要由三個因素決定:

| 決定因素 | 說明 | 增加的情況 |
|---|---|---|
| **心跳速率** | 最重要、最容易調整;每跳都耗氧,且壓縮舒張期 | 運動、發燒、焦慮、疼痛、貧血、甲狀腺亢進、抽菸 |
| **收縮力** | 收縮越強耗能越多 | 交感興奮、正性肌力藥 |
| **心室壁張力** | Laplace 定律:壁張力 ∝ 壓力 × 半徑 ÷ 壁厚 → 由**前負荷**(心室擴大、半徑↑)與**後負荷**(血壓↑)決定 | 高血壓、心室擴大、輸液過多 |

- 雙乘積(**心跳 × 收縮壓**,rate-pressure product)是臨床上估計心肌耗氧量的簡便指標;心絞痛通常在固定的雙乘積時發作。
- **心衰竭的代償**(心跳加快、心室擴張、心肌肥厚)都會**增加**心肌需氧量,不會減少。
- **抽菸**:尼古丁使心跳加快、血管收縮、血壓上升 → 需氧量增加;一氧化碳與血紅素結合 → 血液**攜氧能力下降**,供給減少。
- 等長運動(提重物、用力閉氣)使血壓陡升、壁張力大增,冠心病人應避免;性行為前可預防性含 NTG。

### 抗心絞痛藥如何平衡供需 {#antianginal}

| 藥物 | 降低需求 | 增加供給 |
|---|---|---|
| [[nitrates\|硝酸鹽]](NTG、ISDN) | **擴張靜脈 → 前負荷↓** → 心室半徑與壁張力↓(主要機轉);較高劑量擴張動脈 → 後負荷↓ | 擴張心外膜冠狀動脈、解除痙攣、促進側枝血流 |
| [[beta-blockers\|β 阻斷劑]] | **心跳↓、收縮力↓**、運動時血壓↓ | 舒張期延長 → 灌流時間↑ |
| [[calcium-channel-blockers\|CCB]] | DHP 類:後負荷↓;verapamil、diltiazem:另外心跳↓、收縮力↓ | 冠狀動脈擴張(痙攣首選) |
| 氧氣 | — | 低血氧時提高血氧含量(SpO₂ < 90% 才給;≥ 90% 不建議常規給(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309))) |
| 嗎啡 | 止痛、降焦慮、前負荷↓ | — |
| 半坐臥、臥床休息、軟便劑 | 回心血量↓、活動與用力↓ | — |
| 血管再通(PCI、CABG、[[thrombolytics\|血栓溶解劑]]) | — | 恢復血流(根本治療) |
| [[antiplatelets\|抗血小板劑]](aspirin) | **不降低**耗氧量 | 防止血栓形成、阻塞加重 |

- NTG **不會**增加心肌收縮力;它主要是降低前負荷,使心肌需氧量下降(不是主要靠擴張冠狀動脈增加血流)。硝酸鹽經 **NO → cGMP** 放鬆平滑肌,不是 cAMP。
- 阿斯匹靈抑制血小板凝集,**不能**止痛、不能溶解血栓,也**不能**降低心肌耗氧量。

## 側枝循環 {#collateral}

- 冠狀動脈分支之間原本就有細小的吻合支。當某條血管**慢慢**狹窄,遠端缺血、壓力差持續存在 → 吻合支在數週到數月間逐漸擴大,形成**側枝循環**,繞過狹窄處供血。
- 規律**有氧運動**可能促進側枝發展;**急性**完全阻塞(血栓)時側枝來不及形成,因此突然的阻塞損傷較大,而長期慢性狹窄的病人,梗塞範圍可能較小。
- 冠狀動脈基本上屬於**功能性終末動脈**:側枝通常不足以完全取代被阻塞的主要分支,運動時仍會缺血。

**藥物對應**:[[nitrates|硝酸鹽]]可擴張側枝血管,把血流重新分配到缺血區。
**臨床對應**:[[coronary-artery-disease]] 的心臟復健以漸進式有氧運動為主。

## 心肌缺血後的變化時間 {#ischemia-timeline}

| 缺血時間 | 變化 | 可逆性 |
|---|---|---|
| 數秒 | 有氧代謝停止,改為無氧醣解 → 乳酸堆積、ATP 下降;先出現舒張功能變差,再出現收縮力下降 | 可逆 |
| 數分鐘 | 心電圖 ST-T 變化、胸痛(**缺血階梯**:代謝 → 舒張功能 → 收縮功能 → 心電圖 → 胸痛) | 可逆 |
| **< 20 分鐘** | 心肌細胞尚未死亡;恢復血流後功能可在數小時到數天內恢復(**心肌昏迷** stunning) | **可逆** |
| **20–40 分鐘以上** | 開始**不可逆損傷**(細胞膜破裂、壞死),由**心內膜下**開始 | 不可逆 |
| 3–6 小時 | 壞死由心內膜下像波浪一樣擴展到**全層**(穿壁性梗塞) | 不可逆 |
| 數小時到數天 | 肌鈣蛋白等細胞內物質釋入血液(見 [[cardiac-biomarkers]]);嗜中性球、巨噬細胞清除壞死組織,第 3–7 天心肌最脆弱、易破裂 | — |
| 約 6–8 週 | 壞死心肌由**結締組織(纖維疤痕)**取代 | 心肌細胞幾乎不能再生 |

- 「**時間就是心肌**」:搶救的目標是在不可逆損傷擴展前恢復血流——STEMI 首選直接 PCI(首次醫療接觸至器械通過 ≤ 90 分鐘,需轉院者 ≤ 120 分鐘(來源:[2025 ACC/AHA 急性冠心症指引](https://doi.org/10.1161/CIR.0000000000001309))),預估 PCI > 120 分鐘時到院 30 分鐘內給予[[thrombolytics|血栓溶解劑]](詳見 [[coronary-artery-disease]])。
- 心肌梗塞的心電圖演變(ST 上升 → 病理性 Q 波 → T 波倒置)見 [[ecg#mi-evolution]]。
- 疤痕組織不能收縮也不能正常傳導 → 心衰竭、心律不整、室壁瘤。

:::exam[國考重點]
- 冠狀動脈源自**升主動脈**;LAD → 前壁與中膈;LCx → 側壁;RCA → **下壁、竇房結、房室結**(下壁梗塞易心搏過緩)。
- 冠狀動脈在**舒張期**灌流,心跳快 → 灌流少、耗氧多。
- 心肌耗氧量三大因素:**心跳速率、收縮力、壁張力(前後負荷)**;β 阻斷劑、硝酸鹽、CCB 能降耗氧,**阿斯匹靈不行**。
- 缺血約 **20 分鐘內可逆**,之後由心內膜下開始壞死;壞死心肌由**結締組織**取代。
:::

**臨床對應**:[[coronary-artery-disease]]、[[heart-failure]]。
