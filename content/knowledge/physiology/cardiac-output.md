心臟是一個幫浦,任務是讓**心輸出量(cardiac output, CO)**配合全身組織的需求。心輸出量由**心跳速率**與**心搏量**決定,心搏量又由**前負荷、後負荷、收縮力**三個因素決定——幾乎所有強心、利尿、血管擴張藥,都是在調整這三個因素其中之一。

每一段最後的「**藥物對應**」「**臨床對應**」說明哪一類藥物或疾病與這個機制有關。

## 心臟構造與血流路徑 {#structure}

![心臟構造與血流路徑](/knowledge-images/heart-blood-flow.svg)

**血流路徑**:上、下腔靜脈 → **右心房** →(三尖瓣)→ **右心室** →(肺動脈瓣)→ 肺動脈 → 肺 → **肺靜脈** → **左心房** →(二尖瓣)→ **左心室** →(主動脈瓣)→ 主動脈 → 全身。

- 開口於**右心房**:上腔靜脈、下腔靜脈、**冠狀竇**(收集心臟壁大部分的缺氧血)。**肺靜脈開口於左心房**,不是右心房。
- 心臟位置:心尖約在**左鎖骨中線與第 5 肋間**交會處,也就是心尖搏動最強點(PMI);7 歲以上兒童與成人位置相同。左心室肥大時 PMI **向左下偏移**、搏動增強且範圍變大。
- 心臟壁:心外膜(漿膜性心包膜臟層)、心肌層、心內膜。**心包腔**位於漿膜性心包膜的**壁層與臟層之間**,正常有少量潤滑液;積液過多即心包膜填塞。
- 心房內壁有**梳狀肌**;心室內壁有**心肉柱**(肉柱)、**乳頭肌**與**腱索**。梳狀肌只在心房,所以「右心室有梳狀肌」是錯的。
- 心房中膈上有**卵圓窩**(胎兒卵圓孔的遺跡);**冠狀溝**是心房與心室在心臟表面的分界。
- 右心室與左心室每分鐘輸出量**相等**(串聯循環),只是左心室壓力高、壁厚約為右心室 3 倍。

### 瓣膜 {#valves}

| 瓣膜 | 位置 | 防止逆流至 | 構造 |
|---|---|---|---|
| **三尖瓣**(右房室瓣) | 右心房 ↔ 右心室 | 右心房 | 腱索 + 乳頭肌 |
| **二尖瓣**(僧帽瓣、左房室瓣) | 左心房 ↔ 左心室 | **左心房** | 腱索 + 乳頭肌 |
| 肺動脈瓣(半月瓣) | 右心室 → 肺動脈 | 右心室 | 無腱索 |
| 主動脈瓣(半月瓣) | 左心室 → 主動脈 | 左心室 | 無腱索 |

- **腱索**一端接房室瓣的瓣葉,另一端接**心室**的乳頭肌(不是接心房);心室收縮時乳頭肌同時收縮、拉住腱索,防止瓣葉翻進心房。
- 瓣膜開關完全由**兩側壓力差**決定,瓣膜本身沒有肌肉。

**臨床對應**:二尖瓣閉鎖不全時,收縮期血液逆流回左心房 → **全收縮期雜音**;二尖瓣狹窄使左心房、肺微血管楔壓(PCWP)、右心壓力、CVP 都上升,心輸出量**下降**。人工瓣膜:機械瓣耐用但需**終身 warfarin**;生物瓣耐用性較差、聲音小,多數不需終身抗凝,適合計畫懷孕婦女與高齡者(見 [[anticoagulants]])。

## 心動週期 {#cardiac-cycle}

心動週期(cardiac cycle)指一次心跳中心房、心室收縮與舒張的完整過程。心跳 75 次/分時,一個週期約 0.8 秒,其中心室收縮約 0.3 秒、舒張約 0.5 秒——**正常心率下舒張期比收縮期長**。

| 時期 | 房室瓣 | 半月瓣 | 心室容積 | 重點 |
|---|---|---|---|---|
| 心房收縮 | 開 | 關 | 最後再充填約 20%(atrial kick) | 之後達**舒張末期容積(EDV)**,前負荷最大 |
| **等容收縮期** | **關**(→ S1) | 關 | 不變 | 心室壓力快速上升,四個瓣膜全關 |
| 射血期 | 關 | **開** | 下降 | 心室壓 > 主動脈壓,主動脈瓣被推開 |
| **等容舒張期** | 關 | **關**(→ S2) | 不變 | 心室壓 < 主動脈壓,主動脈瓣關閉(主動脈壓力曲線的重搏切跡) |
| 快速充填期 | **開** | 關 | 快速上升 | 心室壓 < 心房壓,房室瓣打開(→ S3 在此期) |

- **收縮期 = S1 到 S2 之間**;S2 到下一個 S1 是舒張期。
- 舒張末期(房室瓣即將關閉、等容收縮尚未開始)心室容積最大 → **前負荷最大的時間點**。
- 心跳加快時主要縮短的是**舒張期** → 心室充填與冠狀動脈灌流時間都減少(見 [[coronary-circulation#perfusion]])。

## 心音與聽診 {#heart-sounds}

| 心音 | 產生原因 | 時間 | 意義 |
|---|---|---|---|
| **S1**(lub) | **房室瓣(二尖瓣、三尖瓣)關閉** | **心室收縮開始**(等容收縮期) | 正常;心尖最清楚 |
| **S2**(dub) | **半月瓣(主動脈瓣、肺動脈瓣)關閉** | **心室舒張開始** | 正常;心底最清楚。**吸氣**時回心血量增加、肺動脈瓣晚關 → 生理性分裂音在**吸氣**時較明顯 |
| **S3** | 血液快速衝入順應性差或過度充盈的心室 | **舒張早期**(S2 之後,快速充填期) | 兒童、年輕人、孕婦可為生理性;成人多代表**心衰竭**(容積過量),又稱心室奔馬律 |
| **S4** | 心房用力把血推入**僵硬、肥厚**的心室 | **舒張末期**(S1 之前,心房收縮) | **左心室肥厚、高血壓、主動脈瓣狹窄**、急性心肌梗塞;心房顫動時沒有 S4 |

**聽診位置**(心音在「血流下游」聽得最清楚,不是瓣膜的解剖位置):

| 區域 | 位置 |
|---|---|
| 主動脈瓣區 | **胸骨右緣第 2 肋間** |
| 肺動脈瓣區 | **胸骨左緣第 2 肋間** |
| Erb's point | 胸骨左緣第 3 肋間 |
| 三尖瓣區 | 胸骨左緣第 4–5 肋間 |
| 二尖瓣區(心尖) | **左鎖骨中線第 5 肋間** |

- 聽診器**膜面**聽高頻音(S1、S2、心尖脈、多數雜音);**鐘面**輕放聽低頻音(**S3、S4**、二尖瓣狹窄的舒張期雜音)。
- S3、S4 都是低頻音:病人採**左側臥**使心尖貼近胸壁,用**鐘面**聽**心尖**。
- 測心尖脈:病人休息後,聽診器(膜面)置於左鎖骨中線第 5 肋間,**數滿 1 分鐘**並注意節律與強弱;服 [[digoxin]] 前必測。

:::exam[國考重點]
- S1 = 房室瓣關閉 = 收縮期**開始**;S2 = 半月瓣關閉 = 舒張期**開始**;S1–S2 之間是收縮期。
- S3 出現在**舒張早期**(不是舒張末期)→ 心衰竭;S4 在舒張末期 → 心室僵硬(高血壓、肥厚)。
- 聽 S3 用**鐘面**、左側臥、心尖處;主動脈瓣區在**胸骨右緣**第 2 肋間。
:::

**臨床對應**:[[heart-failure]] 出現 S3;[[hypertension]] 造成左心室肥厚出現 S4;心包膜填塞時心音**模糊低沉**。

## 心輸出量的決定因素 {#determinants}

**心輸出量(CO)= 心跳速率(HR)× 心搏量(SV)**

| 指標 | 定義 | 成人正常值 |
|---|---|---|
| 心輸出量 CO | 每分鐘由**一側**心室打出的血量 | 約 4–8 L/min(靜息約 5 L/min) |
| 心搏量 SV | 每跳打出的血量 = **EDV − ESV** | 約 60–100 mL(典型 70 mL) |
| 心指數 CI | CO ÷ 體表面積,校正體型 | **2.5–4.0 L/min/m²**;< 2.2 表示灌流不足(心因性休克常 < 1.8–2.2) |
| 射出分率 EF | SV ÷ EDV | **50–70%** |

**計算範例**:心跳 70 次/分,EDV 120 mL、ESV 50 mL → SV = 70 mL → CO = 70 × 70 = 4,900 mL = **4.9 L/min**。

- **心搏量只由前負荷、後負荷、收縮力決定;心跳速率不是心搏量的決定因素**(心跳速率決定的是 CO)。
- 心跳加快在一定範圍內能增加 CO;但**心跳過快(如 200 次/分)**時舒張期太短、心室來不及充填,SV 大幅下降 → CO 反而**減少**,冠狀動脈灌流也變差。
- 測量 CO:心臟超音波([[echocardiography]])、肺動脈導管熱稀釋法、心導管([[cardiac-catheterization]]);**運動心電圖不能測 CO**(它評估的是心肌缺血)。
- CVP(中心靜脈壓)反映**右心房壓力**,正常約 2–8 mmHg(約 3–10 cmH₂O,各教科書略有差異);上腔靜脈壓 8 mmHg 屬正常範圍。PCWP 反映左心房壓力。

**影響心輸出量的生理狀況**:

| 狀況 | CO | 說明 |
|---|---|---|
| 懷孕 | ↑ 30–50% | 血量增加;供應子宮胎盤 |
| 產後初期 | ↑ | 胎盤循環停止、組織液回收使回心血量增加 → 反射性**心搏過緩**(50–60 次/分,持續約 6–10 天) |
| 老化 | ↓ | 心肌收縮力下降、血管彈性減低 |
| 甲狀腺功能低下 | ↓ | 心跳慢、收縮力弱;亢進則相反 |
| 敗血性休克早期 | ↑ | 血管擴張、SVR↓,屬高動力期(暖休克) |
| 心因性休克 | ↓ | 幫浦衰竭,PCWP、CVP **上升**;最常見原因為心肌梗塞 |
| 低血容性休克、大面積燒傷初期 | ↓ | 前負荷不足,CVP **下降** |
| **Valsalva 操作**(閉氣用力) | ↓ | 胸內壓↑ → 靜脈回流↓ → CO↓、血壓先降;放鬆後反彈並刺激迷走神經 → 心搏過緩 |

## 前負荷 {#preload}

**前負荷(preload)**:心室收縮前,心肌纖維被拉長的程度,臨床上以**舒張末期容積(EDV)或舒張末期壓力**代表——主要由**回心血量**決定。

| 增加前負荷 | 減少前負荷 |
|---|---|
| 血量增加、輸液、鈉水滯留 | 利尿、限鈉限水、失血、脫水 |
| 平躺、抬腿、**頭低腳高** | **高坐臥/半坐臥**、雙腳下垂(血液留在下肢) |
| 交感使靜脈收縮 | 靜脈擴張(硝酸鹽、嗎啡) |
| 心房收縮有效 | 心房顫動(失去 atrial kick)、胸內壓↑(Valsalva、正壓呼吸) |

**藥物對應**:[[loop-diuretics|Loop 利尿劑]]、[[thiazide-diuretics|Thiazide]]、限鈉限水 → 減少血量;[[nitrates|硝酸鹽]](低劑量以擴張靜脈為主)與嗎啡 → 靜脈擴張、血液留在周邊;[[ace-inhibitors|ACEI]]/[[arb|ARB]] 減少醛固酮 → 減少鈉水滯留;BNP 本身有利鈉利尿、擴張血管作用,可降低前後負荷(見 [[bnp]])。
**臨床對應**:低血壓時採頭低腳高或抬高下肢,是為了**增加前負荷**以提高 CO;肺水腫則相反,要**減少**前負荷(高坐臥、雙腳下垂、利尿)。

## 後負荷 {#afterload}

**後負荷(afterload)**:心室射血時必須克服的阻力。左心室的後負荷主要來自**全身血管阻力(SVR)**與主動脈壓力(也受主動脈瓣狹窄影響);右心室則是肺血管阻力。

- 後負荷↑ → 射血困難、SV↓、心肌壁張力與耗氧量↑;長期導致**左心室肥厚**。
- 高血壓、主動脈瓣狹窄、血管收縮(交感、Ang II)使後負荷上升。
- 高坐臥姿、限鈉限水主要是減少**前**負荷,不是後負荷。

**藥物對應**:動脈血管擴張劑([[direct-vasodilators|Hydralazine]]、[[calcium-channel-blockers|Dihydropyridine CCB]])、[[ace-inhibitors|ACEI]]/[[arb|ARB]]/[[arni|ARNI]] 降低 SVR 與後負荷;**Nitroprusside 同時擴張動、靜脈 → 前後負荷都下降**;嗎啡可降低前負荷並輕度降低後負荷。**主動脈內氣球幫浦(IABP)**:舒張期充氣 → 增加冠狀動脈灌流;收縮期前放氣 → 降低後負荷。

## 收縮力 {#contractility}

**收縮力(contractility)**:在前、後負荷不變時,心肌本身的收縮強度(inotropy)。

| 增加收縮力(正性肌力) | 降低收縮力(負性肌力) |
|---|---|
| 交感神經、腎上腺素(**β1**) | β 阻斷劑、非 DHP 類 CCB(verapamil、diltiazem) |
| 細胞內 Ca²⁺↑ | 心肌缺血/梗塞、酸中毒、低血氧 |
| 甲狀腺素 | 心肌病變、心肌炎 |

### 心肌收縮的細胞機轉 {#myocyte}

- 心室肌細胞**靜止膜電位約 −90 mV**。
- 動作電位:第 0 期 Na⁺ 快速流入去極化 → 第 2 期**高原期**(plateau)由 **L 型鈣通道** Ca²⁺ 持續流入維持 → 第 3 期 K⁺ 流出再極化。
- **鈣誘發鈣釋放**:流入的少量 Ca²⁺ 觸發肌漿網釋放大量 Ca²⁺(**肌漿網釋放量 > 細胞外流入量**)→ 與肌鈣蛋白 C 結合 → 收縮。
- 心肌與骨骼肌一樣靠**橫小管**把動作電位傳入細胞內。
- 心肌**不反應期很長,幾乎與收縮期重疊** → 不會發生加成或強直收縮,保證每次收縮後都能舒張充血。
- 心肌主要能量來源是**脂肪酸**(有氧代謝),粒線體多,極度依賴氧氣。
- 細胞外 Ca²⁺ 過高使收縮力增強(嚴重時停在收縮狀態),並不是讓心跳加快。

**藥物對應**:[[inotropes|Dobutamine]](β1)、Dopamine、Milrinone(PDE3 抑制 → cAMP↑)、[[digoxin|Digoxin]](抑制 Na⁺/K⁺-ATPase → 細胞內 Ca²⁺↑)增加收縮力;[[beta-blockers|β 阻斷劑]]與 verapamil/diltiazem 降低收縮力。Dopamine 劑量效應:低劑量作用於 D1 → 腎臟血流↑;中劑量 β1 → **收縮力↑**、CO↑;高劑量 α1 → 血管收縮、血壓↑。
**臨床對應**:NTG **不會**增加心肌收縮力,它是透過減少前負荷來降低心肌需氧量。

## Frank–Starling 定律 {#frank-starling}

回心血量越多 → 舒張末期心肌纖維被拉得越長 → 肌動蛋白與肌凝蛋白重疊更理想、對 Ca²⁺ 更敏感 → **收縮越強、心搏量越大**。這讓心臟「進多少、打多少」,左右心室輸出自動保持一致。

![Frank–Starling 曲線與心衰竭用藥](/knowledge-images/frank-starling.svg)

- 正常心臟的曲線陡而高;**心衰竭**時收縮力下降,曲線**低而平**:前負荷再增加,SV 增加很少,多出來的只是充血(肺水腫、水腫)。
- 心室過度擴張超過最適長度時,收縮反而變差(失代償)。
- 心衰竭的代償:心跳加快、心室擴張(利用 Frank–Starling)、心肌肥厚、交感與 RAAS 活化——但這些代償都會**增加**心肌需氧量。

**藥物對應**:
- 利尿劑、限鈉、NTG → **沿同一條曲線往左移**:充血改善,SV 幾乎不下降(圖中 B → C)。
- 正性肌力藥([[inotropes]]、[[digoxin]])→ **整條曲線往上移**(C → D)。
- 降後負荷的血管擴張劑([[ace-inhibitors|ACEI]]、[[arni|ARNI]]、[[direct-vasodilators|Hydralazine]])也讓衰竭心臟的曲線上移。

## 射出分率 {#ejection-fraction}

**射出分率(EF)= 心搏量(SV)÷ 舒張末期容積(EDV)× 100%**

- 正常左心室 EF 約 **50–70%**(多以心臟超音波測量)。
- 心衰竭依 EF 分類(2021 ESC、2022 AHA/ACC/HFSA 一致;國考以此為準。2026 ESC 已取消 HFmrEF、以 EF < 50% 為 HFrEF,台灣 2023 共識也把 < 50% 通稱 HFrEF,詳見 [[echocardiography#ef]]):

| 分類 | 左心室 EF |
|---|---|
| **HFrEF**(射出分率降低) | **≤ 40%** |
| HFmrEF(射出分率輕度降低) | 41–49% |
| **HFpEF**(射出分率保留) | **≥ 50%** |
| HFimpEF(射出分率改善) | 原本 ≤ 40%,追蹤時 > 40%(AHA);ESC 與台灣另要求上升 **≥ 10** 個百分點(來源:[2026 ESC 心衰竭指引](https://doi.org/10.1093/eurheartj/ehag100) p.16;[2023 台灣心臟學會慢性心衰竭藥物治療共識](https://doi.org/10.6515/ACS.202305_39%283%29.20230301A) p.4) |

- HFrEF 是收縮功能差;HFpEF 多為舒張功能差(心室僵硬,常見於高血壓、高齡),EF 正常但充填壓高。
- EF 極低(如 12%)的心衰竭病人:半坐臥、限水限鈉、每日量體重與輸出入量;**不要**把雙腳抬高 30 度以上(會增加回心血量、加重肺充血)。

**臨床對應**:[[heart-failure]] 的分類與用藥依 EF 決定;EF 以 [[echocardiography]] 評估。

## 傳導系統 {#conduction}

![心臟傳導系統](/knowledge-images/heart-conduction-system.svg)

| 構造 | 位置 | 固有速率 | 特點 |
|---|---|---|---|
| **竇房結**(SA node) | 右心房上壁、上腔靜脈開口附近 | **60–100 次/分** | 正常節律點(自主性最高) |
| 心房內/結間路徑 | 心房壁;Bachmann 束到左心房 | — | 兩心房幾乎同時收縮 |
| **房室結**(AV node) | **心房中膈下部**、**冠狀竇開口**附近(Koch 三角) | **40–60 次/分** | **傳導最慢**,延遲約 0.1 秒 → 心房先收縮完、心室充填完成(對應心電圖 PR 間期) |
| **希氏束**(His bundle) | 穿過纖維性心骨架進入心室中膈 | 40–60(與房室交界同) | 心房與心室之間唯一的電傳導通道 |
| 左、右束支 | 心室中膈兩側;左束支再分前、後分支 | 20–40 次/分 | — |
| **浦金氏纖維**(Purkinje) | 心內膜下 | **20–40 次/分** | **傳導最快**,使心室由心尖往心底同步收縮 |

- 越下游的節律點速率越慢:竇房結失效時由房室交界接手(交界性心律 40–60),完全房室傳導阻斷時由心室接手(20–40,常出現暈厥,需節律器)。
- 節律細胞沒有穩定的靜止膜電位,第 4 期緩慢自發去極化(If 電流 + T 型鈣通道);竇房結、房室結的去極化(第 0 期)靠 **Ca²⁺ 流入**,所以 CCB 會減慢房室結傳導。
- **高血鉀**使心肌膜電位變淺、傳導變慢,嚴重時阻斷心房到心室的衝動(見 [[potassium]])。
- 心電圖波形:P 波 = 心房去極化;QRS = 心室去極化;T 波 = 心室再極化(詳見 [[ecg#waves]])。

**藥物對應**:[[beta-blockers|β 阻斷劑]](propranolol)降低第 4 期去極化斜率、減少竇房結自主性,並**減慢房室傳導**;[[calcium-channel-blockers|Verapamil、Diltiazem]] 減慢房室結傳導;[[digoxin]] 增強迷走作用、減慢房室傳導;amiodarone 延長動作電位時間(含碘,甲狀腺功能異常者小心)。

## 自主神經對心臟的影響 {#autonomic}

| | 交感神經 | 副交感神經(迷走神經) |
|---|---|---|
| 傳導物質/受體 | 正腎上腺素 → **β1** | 乙醯膽鹼 → **蕈毒鹼型 M2** |
| 分布 | 竇房結、房室結、心房與**心室**肌 | 主要在**竇房結、房室結與心房**,心室很少 |
| 心跳速率 | ↑(正性變時) | ↓ |
| 房室傳導 | ↑(正性變傳導) | ↓(心跳與傳導速度**都變慢**) |
| 收縮力 | **↑**(正性肌力) | 心房收縮力↓;對心室影響小 |
| 細胞機轉 | cAMP↑ → If 與 Ca²⁺ 電流↑ | **增加 K⁺ 通透性** → 膜電位變負(過極化),到達閾值需要更久 |

- 靜息時以迷走神經張力為主,所以竇房結實際速率(約 70)低於其固有速率(約 100)。
- 運動員迷走張力高,常有竇性心搏過緩,不需治療。
- 迷走刺激的臨床應用:頸動脈竇按摩、Valsalva 可終止陣發性心室上心搏過速(PSVT);但裝節律器或急性心肌梗塞病人要避免 Valsalva(用力排便)。

**藥物對應**:[[beta-blockers|β 阻斷劑]]阻斷 β1 → 心跳慢、收縮力降;atropine 阻斷 M 受體 → 心跳加快(用於有症狀的心搏過緩);[[inotropes|Dobutamine]] 活化 β1。
**臨床對應**:休克初期由**交感神經**(不是副交感)釋放兒茶酚胺,使心跳加快、周邊血管收縮;見 [[blood-pressure-regulation#autonomic-receptors]]。
