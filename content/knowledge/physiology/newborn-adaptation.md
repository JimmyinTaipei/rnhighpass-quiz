新生兒出生後要在幾分鐘到幾天內，從靠胎盤供氧、供養、排廢物，轉成自己呼吸、自己維持體溫與血糖。本頁依「呼吸 → 循環 → 體溫 → 血糖 → 腸胃與大便 → 肝臟與黃疸 → 血液 → 腎臟 → 免疫 → 母體荷爾蒙影響 → 過渡期 → 睡眠活動狀態與暗示行為」排列。新生兒的評估見 [[newborn-assessment]]，日常照護見 [[newborn-care]]，早產兒見 [[preterm-infant]]，黃疸、低血糖等疾病見 [[neonatal-disorders]]。胎兒循環的構造見 [[blood-vessels]]。文中縮寫：IgG（Immunoglobulin G，免疫球蛋白 G）

## 重點摘要 {#summary}

- 第一次呼吸：產道擠壓排出部分肺液、出生後**低氧、高二氧化碳、低溫、觸覺**等刺激呼吸中樞；肺擴張後剩下的肺液被**淋巴與微血管吸收**
- 循環轉換：肺血管阻力下降、左心壓力上升 → **卵圓孔**功能性關閉；血氧上升 → **動脈導管**收縮關閉
- 散熱四途徑：**蒸發**（擦乾、延後洗澡）、**傳導**（預熱布單與磅秤）、**對流**（避開風口、關門窗）、**輻射**（遠離冷牆與窗戶）
- 新生兒靠**棕色脂肪**做**非顫抖性產熱**；冷壓力 → 耗氧增加、**低血糖**、代謝性酸中毒
- 出生後幾小時的能量主要來自**葡萄糖**（肝醣分解）
- 胎便多在 **24 小時內**排出（超過 24–48 小時沒排要評估）；第 3–4 天**過渡便**，之後母乳便或配方奶便
- 胃容量小、**賁門括約肌鬆弛** → 易溢奶；胃排空約 **2–4 小時**
- **生理性黃疸**：出生 **24 小時後**出現（多在第 2–3 天），足月兒第 3–5 天高峰；**24 小時內**出現是**病理性**
- 腸道出生時**無菌** → 不能合成**維生素 K** → 出生時肌肉注射維生素 K；足月兒體內鐵存量夠用約 **4–6 個月**
- IgG 可經胎盤，**IgA、IgM 不可以**（IgA 從母乳得到）
- 過渡期：**第一反應期**（出生 30 分鐘內，清醒、吸吮反射強，**肌膚接觸與第一次哺乳**的好時機） → 相對不反應期（睡） → 第二反應期

### 國考常考點 {#exam-points}

- 首次呼吸**正確**：出生後**肺擴張使呼吸道液體進入微血管**（與淋巴）；產道擠壓**不會**把液體全部排出；斷臍使**二氧化碳升高**（不是降低）；胸部反彈形成的是**負壓**
- 出生後 4–6 小時內最主要的能量來源：**葡萄糖**
- 預防體熱散失**錯誤**：「體溫穩定前不洗澡是預防**對流**」（應是**蒸發**）；溫熱毛毯包裹是**傳導**、嬰兒床遠離牆壁是**輻射**、立即擦乾是**蒸發**
- 出生即刻保溫**不適當**：「出生後**立即沐浴**」；預熱布單、擦乾後肌膚接觸、維持室溫都適當
- 新生兒腸胃與排泄**錯誤**：「出生 **12 小時內未解胎便**就通知醫師」（24–48 小時才算延遲）
- 新生兒消化**錯誤**：「胃排空約 **6 小時**」（約 2–4 小時）；唾液少、賁門括約肌不成熟、24 小時內排胎便都對
- 出生 3–4 天體重下降 **5–10%**（生理性體重減輕）；3–4 天後排**過渡便**；避免餵太飽（賁門括約肌不成熟）
- 生理性黃疸：多在出生後 **2–3 天**出現；皮膚發黃**由頭往腳、由中心往四肢**；**輕壓鼻尖或骨突處**看黃；早產兒發生率比足月兒高
- 「生理性黃疸**出生 24 小時內**出現」錯（24 小時內是病理性）；生理性黃疸**不是** ABO、Rh 溶血造成，也**不是**大多屬於母乳性黃疸
- 出生 2–6 小時的過渡期，心跳呼吸變化大、腸蠕動增加、解胎便都正常；**出現黃疸**是異常
- 新生兒生理**正確**：出生後 **3–5 個月內鐵質足夠**；未進食前腸道是**無菌**（所以維生素 K 低）；糖尿病母親的新生兒易**低**血糖；**IgA 不能**通過胎盤
- 女嬰**假月經**：與母親**雌性素**中斷有關
- 即刻肌膚接觸的最佳時機：**第一反應期**（清醒、吸吮反射強）
- **安靜清醒期**：注意周圍、眼睛張大明亮、對照顧者有反應、**呼吸規律**；「呼吸不規律」不是安靜清醒期
- 無臉部表情與眼球活動、**呼吸規律**、偶有驚嚇與突發吸吮 → **安靜睡眠期**
- **脫離性**暗示：轉開臉、**伸展**、打哈欠、哭、扭動（表示累或刺激太多）；「手腳屈曲、臉轉向照顧者表示想睡」是錯的

## 呼吸 {#respiration}

- 出生前：肺泡充滿**肺液**，氣體交換靠胎盤；懷孕後期與產程中肺液分泌減少、吸收增加
- 啟動第一次呼吸的因素

| 類別 | 刺激 |
|---|---|
| 化學 | 斷臍後胎盤氣體交換停止 → **低氧、二氧化碳升高、酸中毒** → 刺激化學感受器 |
| 溫度 | 從溫暖子宮到較冷的環境 → 皮膚冷刺激 |
| 觸覺 | 產道擠壓、擦乾、觸摸 |
| 機械 | 陰道生產時胸廓被擠壓，排出部分肺液；胸廓**彈回**形成**負壓**，吸入空氣 |

- 肺擴張後，肺泡內剩餘的液體被**肺間質、淋巴管與微血管吸收**（剖腹產沒有產道擠壓，肺液較多 → 較易**暫時性呼吸急促**，見 [[neonatal-disorders#ttn]]）
- **表面張力素**降低肺泡表面張力，讓肺泡不塌陷；早產兒不足 → 呼吸窘迫症候群（見 [[ards-respiratory-failure#neonatal-rds]]）
- 正常呼吸 **30–60 次/分**，以**腹式**、**鼻呼吸**為主，可有**週期性呼吸**（停 < 20 秒，不合併心跳變慢或發紺）

## 循環轉換 {#circulation}

- 斷臍 → 體循環阻力**上升**；第一次呼吸肺擴張 → 肺血管阻力**下降**、肺血流增加 → 左心房壓力**高於**右心房 → **卵圓孔**功能性關閉
- 血氧上升、前列腺素下降 → **動脈導管**收縮，功能性關閉約出生後 **10–15 小時**（多數 72 小時內），解剖性關閉約 2–3 週（早產兒容易不關，見 [[congenital-heart-disease#left-to-right]]）
- **靜脈導管**、**臍動脈與臍靜脈**閉鎖成韌帶
- 正常心跳 **110–160 次/分**（哭時可到 180，睡時可到 100）
- 胎兒循環的路徑與構造見 [[blood-vessels]]

## 體溫調節 {#thermoregulation}

- 新生兒容易失溫：**體表面積比體重大**、**皮下脂肪少**、皮膚薄、血管靠近表面、不會發抖、出生時全身是濕的
- **產熱**：靠**棕色脂肪**分解的**非顫抖性產熱**（位於肩胛間、頸部、腋下、腎臟與大血管周圍）；也增加活動與哭
- **四種散熱途徑**

| 途徑 | 例子 | 預防 |
|---|---|---|
| **蒸發** | 出生時身上的羊水、洗澡後沒擦乾 | **立即擦乾**、換掉濕布、**體溫穩定前不洗澡**（延後到 24 小時後） |
| **傳導** | 放在冷的磅秤、冷的床單或聽診器上 | **預熱**布單、磅秤墊布、溫暖的手、**肌膚接觸** |
| **對流** | 冷氣風口、開窗、人員走動帶動氣流 | 關門窗、避開風口、包毯、保溫箱側門少開 |
| **輻射** | 靠近冷牆、冷窗（不直接接觸） | 嬰兒床**遠離外牆與窗戶**、輻射加溫台、**戴帽子**（頭部表面積大） |

- **冷壓力**(cold stress)：受冷 → 分解棕色脂肪 → **耗氧增加**、**消耗葡萄糖**（低血糖）、**無氧代謝**（代謝性酸中毒）、肺血管收縮 → 呼吸窘迫，惡性循環
- **中性溫度環境**：讓新生兒耗氧最少就能維持體溫的環境溫度；早產兒的保溫箱設定見 [[preterm-infant#thermoregulation]]
- 新生兒正常體溫（腋溫）約 **36.5–37.5°C**；量體溫的方法見 [[body-temperature]]
- 出生即刻保溫：產房室溫約 **25–28°C**、預熱布單、**擦乾**後**肌膚接觸**、戴帽子；**不要立即洗澡**

## 血糖與能量 {#glucose}

- 斷臍後母親的葡萄糖供應中斷 → 新生兒先用**肝醣分解**的**葡萄糖**（出生後數小時最主要的能量），之後靠進食與脂肪
- 出生後 1–2 小時血糖降到最低再回升；儘早哺餵可以預防低血糖
- 低血糖的高危險群（糖尿病母親的新生兒、早產、SGA、LGA、冷壓力、窒息）與處置見 [[neonatal-disorders#hypoglycemia]]

::questions{ids="112-1_OP_029"}

## 腸胃與大便 {#gastrointestinal}

- 特點
   1. **胃容量小**（第 1 天約 5–7 mL、第 3 天約 22–27 mL、第 10 天約 60–80 mL），**胃排空約 2–4 小時**（母乳較快）
   2. **賁門括約肌鬆弛** → 容易**溢奶**；餵完拍打嗝、不要餵太飽
   3. **唾液少**；澱粉酶與脂肪酶不足（澱粉與脂肪消化較差），乳糖與蛋白質可以消化
   4. 腸道出生時**無菌**，進食後 24 小時內細菌進駐
   5. **胃結腸反射**明顯 → 吃完就解便
- 大便的變化

| 種類 | 時間 | 特徵 |
|---|---|---|
| **胎便**(meconium) | 出生後 **24 小時內**（多數 48 小時內）排出 | **墨綠色、黏稠、無臭**（羊水、胎毛、腸道分泌物、膽汁） |
| **過渡便** | 出生 **3–4 天** | 綠黃色、較稀，混有黏液 |
| **母乳便** | 之後 | **金黃色、糊狀或稀糊**、微酸味、次數多 |
| **配方奶便** | 之後 | 淡黃到黃褐色、**較成形**、較臭、次數較少 |

- **24–48 小時還沒排胎便** → 評估**腸阻塞、肛門閉鎖、巨結腸症、胎便栓塞**（見 [[pediatric-gi]]）；12 小時內還沒解仍可觀察
- **生理性體重減輕**：出生 3–4 天下降 **5–10%**（無感性水分喪失、尿與胎便排出、剛開始吃得少），**10–14 天**回到出生體重；吐奶增加**不是**生理性原因（評估見 [[newborn-care#weight-feeding]]）

## 肝臟與生理性黃疸 {#liver-jaundice}

- 新生兒膽紅素多：**紅血球多且壽命短**（約 70–90 天）、**肝臟葡萄糖醛酸轉移酶不足**（結合能力差）、**腸肝循環**增加（腸道無菌、β-葡萄糖醛酸苷酶多、胎便排出慢）
- **生理性黃疸**

| 項目 | 足月兒 | 早產兒 |
|---|---|---|
| 出現 | 出生 **24 小時後**，多在第 **2–3 天** | 第 3–4 天 |
| 高峰 | 第 **3–5 天** | 第 5–7 天 |
| 消退 | 約 1 週 | 約 2 週 |
| 發生率 | 約 60% | 約 80%（較高） |

- 皮膚變黃的順序：**由頭往腳、由身體中心往四肢**（先臉、鞏膜，再軀幹，最後手腳）
- 觀察：自然光下**輕壓鼻尖、額頭或胸骨**等骨突處，放開時看皮膚顏色
- 出生 **24 小時內**就黃、上升太快、數值太高、持續太久 → **病理性黃疸**，見 [[neonatal-disorders#hyperbilirubinemia]]
- 膽紅素代謝見 [[liver-biliary-pancreas#bilirubin]]；母乳相關黃疸見 [[breastfeeding#breastfeeding-jaundice]]

::questions{ids="108-1_OP_027,107-2_OP_029,106-2_OP_030,106-1_OP_030"}

## 血液 {#blood}

- 出生時紅血球、血紅素較高（約 14–24 g/dL），之後下降；**延遲斷臍**可增加鐵存量
- **維生素 K**：腸道**無菌**、母乳含量少、肝臟不成熟 → **凝血因子 II、VII、IX、X** 不足 → 出生時**肌肉注射維生素 K₁** 預防出血（見 [[bleeding-disorders#vitamin-k]]、[[newborn-care#immediate-care]]）
- **鐵**：足月兒在懷孕後期從母親儲存的鐵，夠用約 **4–6 個月**（課本與國考寫 3–5 個月）；之後要從副食品補充（早產兒存量少，要提早補）
- 白血球出生時偏高（可達 9,000–30,000/mm³）

::questions{ids="106-2_makeup_OP_030"}

## 腎臟與排尿 {#renal}

- 腎小球過濾率低、**濃縮尿液能力差** → 容易脫水，也容易水分過多；6 個月內純母乳**不需要額外喝水**
- 多數在出生 **24 小時內**解第一次尿；第 1 天約 1 次，之後每天增加，約第 5–6 天每天 6 次以上
- 尿布上可有**磚紅色尿酸鹽結晶**（前幾天正常）

## 免疫 {#immunity}

- **IgG** 可經胎盤 → 出生時有母親的**被動免疫**，約 3–6 個月後下降
- **IgA、IgM 不能**通過胎盤；**分泌型 IgA** 從**初乳與母乳**獲得
- 新生兒自己製造 IgM；臍帶血 **IgM 升高**表示**子宮內感染**
- 細節見 [[immune-system-basics#newborn]]

## 母體荷爾蒙的影響 {#hormone-effects}

- **假月經**（女嬰）：出生後母親的**雌性素**中斷 → 子宮內膜剝落 → 陰道少量出血或白色黏液，約 1 週消失，**正常**
- **乳房腫大**（男女嬰都可），甚至分泌少量乳汁（俗稱巫婆乳）：受母親雌性素影響，**不要擠**，約 2 週消退
- 女嬰小陰唇、男嬰陰囊可暫時水腫

::questions{ids="109-1_OP_029"}

## 過渡期 {#transition}

| 時期 | 時間 | 表現 | 護理 |
|---|---|---|---|
| **第一反應期** | 出生後約 **30 分鐘**（到 1 小時） | **清醒**、警覺、哭聲大、**吸吮反射強**、心跳（可達 180）與呼吸（可達 80）快、可有鼻翼搧動與少許囉音、腸音出現 | **肌膚接觸**、**第一次哺乳**的最佳時機；保溫 |
| **相對不反應期**（睡眠期） | 出生後約 1–2 小時起，持續 2–4 小時 | **熟睡**、對刺激反應少、心跳呼吸回穩 | 讓他睡、保溫、減少打擾 |
| **第二反應期** | 出生後約 2–8 小時 | 再度清醒、對刺激有反應、**心跳呼吸變化大**、**腸蠕動增加**、**解胎便**、**口腔分泌物多**（可能作嘔） | 觀察呼吸道、必要時抽吸、哺乳 |

- 過渡期出現**黃疸**、持續呼吸急促、發紺、呻吟、體溫不穩 → **異常**

## 睡眠活動狀態與暗示行為 {#behavioral-states}

- Brazelton 的六種狀態

| 狀態 | 表現 |
|---|---|
| **安靜睡眠**（深睡） | 眼睛閉、**沒有眼球運動**、**沒有臉部表情**、**呼吸規律**；偶有驚嚇或突發的吸吮動作；很難叫醒 |
| **活動睡眠**（淺睡） | 眼睛閉但**有快速眼動**、呼吸不規律、有吸吮動作與表情、肢體偶爾動 |
| **半睡半醒**（昏睡） | 眼睛半張、反應慢、可能進入睡眠或醒來 |
| **安靜清醒** | **眼睛張大明亮**、**注意周圍**、身體動作少、**對照顧者有反應**、**呼吸規律**；**最適合互動與學習**（親子互動、衛教） |
| **活動清醒** | 眼睛張開、肢體活動多、呼吸不規律、對刺激敏感、開始煩躁 |
| **哭** | 大哭、臉漲紅、肢體亂動；需要安撫 |

- 新生兒的**暗示行為**(cues)

| 暗示 | 表現 | 意思 |
|---|---|---|
| **投入性**(engagement) | **注視照顧者**、臉轉向照顧者、微笑、手腳放鬆、發出聲音 | 想互動 |
| **脫離性**(disengagement) | **轉開臉**、避開眼神、**伸展**或拱背、打哈欠、皺眉、哭、扭動、打嗝 | 累了、刺激太多，需要休息 |
| 飢餓 | 尋乳、吸手、伸舌、把手放進嘴裡；晚期**哭**、拱背 | 要吃奶（見 [[breastfeeding#feeding-cues]]） |
| 吃飽 | 吸吮變慢、推開乳房或奶瓶、手放鬆、睡著 | 停止餵食 |
