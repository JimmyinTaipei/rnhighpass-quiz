懷孕時母體幾乎每個系統都會改變，以支持胎兒生長並為分娩與哺乳做準備；心理上也要完成接受懷孕、建立母親角色的任務。本頁整理各系統的生理變化與帶來的不適原因、藥物代謝的改變、各孕期的心理反應、Rubin 的母性任務，以及準父親與手足的反應。不適的處理見 [[prenatal-care#discomforts]]，懷孕的診斷徵象見 [[prenatal-assessment#signs]]，胎盤激素見 [[endocrine-overview#placenta]]。文中縮寫：hCG（human chorionic gonadotropin，人類絨毛膜促性腺激素）、hPL（human placental lactogen，人類胎盤泌乳素）、MSH（Melanocyte-stimulating hormone，黑色素刺激素）、GFR（Glomerular filtration rate，腎絲球過濾率）

## 重點摘要 {#summary}

- **雌激素**：子宮肥大、子宮頸與陰道**充血變軟**、子宮頸**黏液塞**、陰道分泌物增加、乳管發育
- **黃體素**：**平滑肌鬆弛** → 心灼熱感、便秘、膽囊排空延遲、輸尿管擴張、靜脈曲張；體溫稍升
- **鬆弛素**：主要由**黃體**分泌；骨盆關節與韌帶鬆弛
- 心血管：**血液容積增加 40–50%**（血漿增加多於紅血球 → **生理性貧血**）；心輸出量增加 30–50%；心跳**增加 10–15 次/分**；第二孕期血壓稍降；**仰臥低血壓**
- 血液：**纖維蛋白原與凝血因子上升** → 高凝血；白血球上升；**血小板不增加**（正常或稍降）
- **心臟病孕婦最容易心衰竭**：**28–32 週**（血液容積高峰）、**待產分娩時**、**產後 48 小時**
- 呼吸：耗氧增加、潮氣容積增加、橫膈上抬 → 呼吸短促
- 泌尿：GFR 增加約 50%；**第一與第三孕期頻尿**
- 皮膚：**黃褐斑**、**腹中線**（MSH、雌激素、黃體素），產後逐漸變淡；妊娠紋、蜘蛛痣
- 骨骼：**腰椎前凸**、重心前移、骨盆關節鬆弛 → 下背痛、鴨步
- 內分泌：甲狀腺稍大、**甲狀腺素增加**；醛固酮增加；FSH、LH 受抑制
- 心理：第一孕期**矛盾**、注意力在自己身體；第二孕期感受胎動、接受懷孕；第三孕期**脆弱、擔心胎兒與生產**、保護身體界限
- **Rubin 四項母性任務**：確保自己與胎兒**安全**、使**重要他人接受**新生兒、與胎兒**連成一體**、學習**貢獻自己**

### 國考常考點 {#exam-points}

- 雌激素使子宮頸**變軟、充血、黏液增加、腺體增生**；子宮頸**不會變肥厚堅硬**、**長度不會增加**；子宮壁**後期變薄**是被撐開，不是雌激素作用
- 孕期白帶增加、黏稠、無臭：雌激素使上皮與肝醣增加，**嗜乳酸桿菌**作用；黃綠色分泌物是**異常**（感染）
- **布拉克斯頓希克斯收縮**：不規則、**無痛**、短暫的子宮收縮，正常，不需安胎
- 懷孕 14 週通常還**感覺不到胎動**（初產約 18–20 週）
- 血小板**不會**比未懷孕時增加；血漿量增加、血比容降低、纖維蛋白原增加都正確
- 心臟病孕婦心衰竭的危險時期**不包括 22–26 週**；**38–40 週不是**負荷最大
- **鬆弛素大部分由黃體分泌**；第一孕期 hCG 來自滋養層（胎盤前身）
- 甲狀腺素**增加**；醛固酮**增加**（不是減少）；FSH、LH **減少**
- 膽囊排空時間延長、膽汁排出減少；心灼熱感是**黃體素**讓賁門括約肌鬆弛
- 黃褐斑是腦下垂體**黑色素刺激素**增加；腹中線產後**逐漸變淡**，不是胎兒異常
- 子宮變大 → **腰背脊柱向前凸**、重心前移
- 懷孕時白蛋白下降 → 藥物與白蛋白結合**減少**（游離藥物增加），肝臟代謝**增加**，GFR 增加使腎排泄**加快**，胃排空**變慢**
- 第一孕期：**矛盾心理**、全神貫注於自己身體變化；第三孕期：擔心胎兒有缺陷、雙手護住肚子（**身體界限**）
- 準父親第二孕期會**想像胎兒模樣與自己當父親的形象**；擬娩症候群有焦慮、噁心嘔吐、疲累失眠，但**不是逃避**父親角色

## 生殖系統與乳房 {#reproductive}

| 構造 | 變化 | 原因與意義 |
|---|---|---|
| 子宮 | 足月約 1,000 公克、容量約 5 公升；早期**肌細胞肥大、壁增厚**，後期被撐開**變薄**（約 0.5–1 公分） | 雌激素、黃體素；子宮底高度與週數見 [[prenatal-assessment#fundal-height]] |
| 子宮峽部 | 變軟（**黑加氏徵象**，約 6–8 週）；分娩時形成子宮下段 | 可能徵象 |
| 子宮頸 | **變軟**（**古德爾氏徵象**）、**充血**（紫藍色，**查德威克氏徵象**）、腺體增生、**黏液塞**封住子宮頸口 | 雌激素；黏液塞防止上行感染，產前排出＝見紅 |
| 陰道 | 黏膜增厚充血、結締組織變鬆；**分泌物增加**（白、稠、微酸、無臭）、pH 下降 | 雌激素使上皮與肝醣增加，**嗜乳酸桿菌**產生乳酸；念珠菌陰道炎較常見 |
| 卵巢 | 停止排卵；黃體維持到約 10 週 | hCG 維持黃體 |
| 乳房 | 脹痛、變大、乳暈變深、蒙哥馬利腺突出、靜脈明顯；第二孕期起可有**初乳** | 雌激素（乳管）、黃體素（腺泡） |
| **子宮收縮** | **布拉克斯頓希克斯收縮**：約第二孕期起，**不規則、無痛**、數秒到 1 分鐘，休息或換姿勢會停 | 促進子宮血流；和真陣痛的比較見 [[labor-process#true-false-labor]] |

## 心血管與血液 {#cardiovascular}

| 項目 | 變化 |
|---|---|
| 血液容積 | **增加 40–50%**，約 **28–34 週**達高峰 |
| 血漿 vs 紅血球 | 血漿增加約 50%、紅血球約 20–30% → 血紅素、**血比容下降**（**生理性貧血**，血紅素 < 11 g/dL 才算貧血） |
| 心輸出量 | 增加 30–50%（心搏量＋心跳） |
| 心跳 | **增加 10–15 次/分** |
| 血壓 | **第二孕期稍降**（周邊血管阻力下降），第三孕期回到孕前 |
| 姿勢 | **仰臥低血壓症候群**：仰躺時子宮壓迫下腔靜脈 → 回心血減少 → 頭暈、低血壓、胎兒缺氧；改**左側臥** |
| 下肢靜脈 | 子宮壓迫骨盆靜脈＋黃體素 → 下肢水腫、靜脈曲張、痔瘡 |
| 凝血 | **纖維蛋白原**與凝血因子 VII、VIII、X 上升 → **高凝血狀態**（產後血栓風險） |
| 白血球 | 上升（分娩時更高） |
| 血小板 | **正常或稍降**，不增加 |
| 心臟 | 橫膈上抬使心臟往上、往左移；可有功能性收縮期雜音 |

- **心臟病孕婦心衰竭的高危險時期**
   1. **28–32 週**：血液容積達高峰
   2. **待產與分娩**：每次宮縮把約 300–500 mL 血液擠回循環，用力時負荷大
   3. **產後 48 小時內**：子宮收縮使血液回到循環、下腔靜脈壓迫解除 → 回心血量突然增加
- 心臟病孕婦的照護見 [[high-risk-pregnancy#cardiac]]

## 呼吸、泌尿、消化 {#other-systems}

| 系統 | 變化 | 帶來的不適 |
|---|---|---|
| 呼吸 | 耗氧增加約 20%；**潮氣容積增加**（每分鐘通氣量增加）；橫膈上抬約 4 公分、胸廓變寬；輕度呼吸性鹼中毒；鼻黏膜充血 | 呼吸短促、鼻塞、流鼻血 |
| 泌尿 | 腎血流與 **GFR 增加約 50%**；**輸尿管擴張**（右側較明顯，黃體素＋子宮壓迫）；葡萄糖可能出現在尿中 | **第一孕期**（子宮壓迫膀胱）與**第三孕期**（先露部下降）頻尿；泌尿道感染與腎盂腎炎風險增加 |
| 口腔 | 牙齦充血、易出血；部分孕婦**流涎** | 牙齦炎 |
| 胃 | 黃體素使**賁門括約肌鬆弛**、胃排空變慢；子宮把胃往上推 | **心灼熱感**（第二、三孕期） |
| 腸 | 黃體素使**蠕動變慢**、水分吸收增加；子宮壓迫 | **便秘**、痔瘡、腹脹 |
| 膽囊 | 平滑肌鬆弛 → **排空時間延長**、膽汁排出減少、膽汁濃縮 | 膽結石風險增加；搔癢（膽汁滯留） |
| 肝 | 白蛋白下降（稀釋）；**鹼性磷酸酶上升**（胎盤製造） | 蜘蛛痣、手掌紅斑（雌激素） |
| 噁心嘔吐 | 第一孕期，與 **hCG**、雌激素上升有關 | 孕吐，多在 12–16 週緩解 |

## 皮膚、骨骼與內分泌 {#skin-msk-endocrine}

- 皮膚
   1. **黃褐斑**（妊娠斑）：臉頰、額頭、鼻子的褐色斑；**黑色素刺激素**、雌激素、黃體素增加；日曬加重；產後多會變淡
   2. **腹中線（黑線）**：肚臍到恥骨的褐色線；乳暈、外陰也變深；**產後逐漸變淡**
   3. **妊娠紋**：皮膚被撐開、真皮彈性纖維斷裂；產後變成銀白色，不會完全消失
   4. 蜘蛛痣、手掌紅斑：雌激素
- 骨骼肌肉
   1. **腰椎前凸**、肩膀後仰，身體**重心前移** → 下背痛
   2. **鬆弛素**與黃體素使骨盆關節與恥骨聯合**鬆弛、活動度增加** → 鴨步、恥骨痛
   3. 腹直肌被撐開，可能**腹直肌分離**；腹肌張力下降
- 內分泌

| 腺體 | 變化 |
|---|---|
| 腦下垂體 | 前葉稍大；**泌乳素上升**；**FSH、LH 受抑制**；MSH 上升；後葉催產素到分娩才大量分泌 |
| **甲狀腺** | 稍腫大；**甲狀腺素（總量）增加**，基礎代謝率上升；游離甲狀腺素大致正常 |
| 副甲狀腺 | 鈣需求增加，副甲狀腺素上升 |
| 腎上腺 | 皮質醇上升；**醛固酮增加**（對抗黃體素的排鈉作用，限鈉時更高） |
| 胰臟 | 胰島素分泌增加；hPL 造成**胰島素阻抗**（見 [[diabetes#gdm]]） |
| 黃體 | 分泌**鬆弛素**（大部分）、黃體素；約 10 週後由胎盤接手 |
| 胎盤 | hCG、hPL、雌激素（以**雌三醇**為主）、黃體素 |

## 懷孕時的藥物代謝 {#pharmacokinetics}

| 階段 | 變化 | 結果 |
|---|---|---|
| 吸收 | 胃排空**變慢**、胃酸**減少**、腸蠕動慢；潮氣容積增加 | 口服藥吸收時間延長；**吸入藥物吸收增加** |
| 分布 | 血漿容積增加；**白蛋白下降** | 與白蛋白結合的藥物**減少**、游離藥物增加 |
| 代謝 | 肝臟酵素活性增加（部分） | 部分藥物**代謝加快** |
| 排泄 | **GFR 增加** | 腎排泄的藥物**清除加快**，可能要調高劑量 |

- 抗癲癇藥、鋰鹽等在孕期濃度會改變，要監測血中濃度；致畸胎物見 [[fertilization-embryology#development-periods]]

## 各孕期的心理反應 {#psychological}

| 孕期 | 孕婦 | 常見表現 |
|---|---|---|
| **第一孕期** | **不確定與矛盾**（憂喜參半）；**注意力集中在自己**身體的變化 | 反覆想繼續工作或當專職母親、情緒起伏、懷疑是否真的懷孕 |
| **第二孕期** | **接受懷孕**；感受**胎動**後覺得胎兒是真實的；較內向、自戀 | 情緒較穩定，開始想像寶寶、穿孕婦裝 |
| **第三孕期** | **脆弱**、擔心胎兒有缺陷與生產過程；保護**身體界限**；準備新角色 | 怕被撞到而護住肚子、做夢、準備嬰兒用品、急著想生 |

## Rubin 的母性任務 {#rubin-tasks}

| 任務 | 行為例子 |
|---|---|
| **確保自己與胎兒安全渡過** | 定期產檢、**主動尋求生產資訊**、請教親友、遵從醫囑控制血糖、戒菸、為安胎忍受不適 |
| **使重要他人接受新生兒** | 讓配偶、家人、**大寶**接受寶寶（例：跟大寶說以後可以和弟妹一起玩） |
| **與胎兒連成一體** | 感受胎動、**對胎兒說話**、取名字、想像寶寶 |
| **學習貢獻自己** | 為了胎兒改變生活、忍受不適與限制（住院安胎、腹水不舒服也覺得值得） |

- **母性角色獲得**的過程(Rubin)
   1. **模仿**：學別的孕婦穿孕婦裝、走路
   2. **角色扮演**：參加媽媽教室**練習哺餵姿勢與嬰兒沐浴**、抱別人的嬰兒
   3. **幻想**：想像寶寶的樣子與將來
   4. **內射—投射—拒絕**：觀察別人的做法，套用到自己身上，不合適就放棄
   5. **悲傷**：放下原本的角色與生活
- 護理：鼓勵表達感受、提供資訊，促進與胎兒連結的方法是**鼓勵和胎兒說話**、表達對胎動的感受

## 家庭成員的反應 {#family}

- **準父親**
   1. 第一孕期：宣告期，接受懷孕的事實，可能矛盾
   2. 第二孕期：調整期，感受胎動後較投入，**想像胎兒模樣與自己當父親的形象**
   3. 第三孕期：集中期，準備生產與父親角色，擔心生產與能否勝任
   4. **擬娩症候群**：準父親出現類似懷孕的症狀（**焦慮、沮喪、食慾不振、噁心嘔吐、疲累、失眠**、體重增加），表示對懷孕的投入與壓力，不是逃避
- **手足（大寶）**
   1. 依年齡用**圖畫書**、故事解釋懷孕過程
   2. 讓大寶參與：**用聽診器聽胎心音**、摸胎動、一起準備寶寶用品
   3. 出現嫉妒或退化行為時，多陪伴、不責備、不要求「要愛妹妹」
- **祖父母**：可能提供支持，也可能有傳統觀念的衝突；尊重並納入照護
