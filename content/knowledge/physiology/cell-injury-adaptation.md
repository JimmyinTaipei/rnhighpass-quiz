細胞受到刺激時，先試著**適應**；刺激太強或太久，就出現**可逆性傷害**；再超過界限，細胞**死亡**（壞死或凋亡）。這是所有疾病的共同起點：心肌梗塞是缺血造成的凝固性壞死、腦中風留下液化性壞死的空腔、巴瑞特食道是化生。發炎與修復接在細胞死亡之後，見 [[inflammation-repair]]；異生之後的腫瘤見 [[neoplasia]]

## 重點摘要 {#summary}

- **細胞適應**（可逆）：**肥大**＝細胞變大、**增生**＝細胞數目增加、**萎縮**＝細胞變小或變少、**化生**＝一種成熟細胞換成另一種成熟細胞
- **異生不是適應**：細胞大小形狀不一、排列紊亂，是**癌前病變**；重度異生占滿上皮全層就是原位癌
- **可逆性傷害**：細胞腫脹（最早）、細胞膜泡狀凸出、粒線體腫脹、內質網擴張、**脂肪變性**（肝最常見）
- **不可逆的指標**：細胞核依序**核濃縮 → 核碎裂 → 核溶解**，以及細胞膜與溶小體破裂
- **壞死**：成群細胞、膜破裂、**引起發炎**；**凋亡**：單一細胞、**皺縮**、凋亡小體被吞噬、**不引起發炎**
- 壞死的型態看器官：**腦＝液化性**、心腎脾＝凝固性、**結核＝乾酪性**、胰臟＝脂肪壞死、血管炎＝類纖維蛋白樣

### 國考常考點 {#exam-points}

- 石膏固定後肌肉量減少＝**萎縮**（廢用性）；**良性前列腺「肥大」其實是增生**（細胞數目增加，不是細胞本身變大）
- 胃食道逆流使食道下段出現柱狀上皮＝**化生**（巴瑞特食道是**腸化生**）；吸菸者支氣管柱狀上皮變成鱗狀上皮也是**化生**，不是異生
- **癌前期**細胞的特徵是**異生**（不是萎縮、肥大、增生）
- **細胞核崩裂（核碎裂）不是可逆性傷害**；脂肪變性是可逆性傷害；肝最常以脂肪變性呈現可逆傷害
- 壞死時細胞核最早出現**核濃縮**
- 凋亡的細胞會**皺縮**（細胞腫脹是壞死）；凋亡**不會**比壞死更容易引起發炎；病毒性肝炎的肝細胞死亡是病理性凋亡、月經週期內膜崩離是生理性凋亡
- **脂褐質**最容易出現在**萎縮的心肌細胞**（老化的耗損性色素）
- 高血鈣造成腎臟鈣沉積＝**轉移性鈣化**；動脈粥狀硬化、胰臟炎脂肪壞死、受損瓣膜的鈣化＝**營養不良性鈣化**
- 腦梗塞數週後留下囊狀空腔＝**液化性壞死**
- 分裂最慢的是**神經元**（永久細胞），所以化療與放療對神經細胞的直接效果較小
- 屍僵是 **ATP 耗盡**，肌動蛋白與肌凝蛋白無法分離

## 細胞適應 {#adaptation}

![細胞適應四種型態（肥大、增生、萎縮、化生）與異生的比較；異生以虛線框表示不是適應，而是癌前病變](/knowledge-images/cell-adaptation.svg)

| 型態 | 改變 | 常見原因 | 例子 |
|---|---|---|---|
| **肥大**(hypertrophy) | 細胞**體積變大**，數目不變 | 工作負荷增加、激素刺激 | 運動員骨骼肌；高血壓的**左心室肥大**；懷孕子宮的平滑肌（同時有增生） |
| **增生**(hyperplasia) | 細胞**數目增加** | 激素刺激、組織代償 | **良性前列腺增生**(BPH)；子宮內膜增生；懷孕與哺乳的乳腺；部分肝臟切除後的再生 |
| **萎縮**(atrophy) | 細胞**變小**，嚴重時數目也減少 | 見下方 | 石膏固定後的肌肉、老年的腦、停經後的子宮 |
| **化生**(metaplasia) | 一種**成熟**細胞被**另一種成熟**細胞取代 | 長期刺激，換成較耐受的細胞 | 吸菸者支氣管：纖毛柱狀上皮 → 複層鱗狀上皮；**巴瑞特食道**：鱗狀上皮 → 含杯狀細胞的柱狀上皮（腸化生） |

- 肥大和增生常一起出現；**只能肥大不能增生**的是不會分裂的細胞（心肌、骨骼肌）
- 萎縮的原因
   1. **廢用**：骨折上石膏、長期臥床；預防靠全關節運動、上石膏的肢體做等長運動（見 [[activity-immobility#isometric-isotonic]]）
   2. 失去神經支配：神經損傷、脊髓損傷
   3. 血流減少：動脈硬化造成的腦萎縮
   4. 營養不良、內分泌刺激減少（停經後的子宮與乳房）
   5. 壓迫：腫瘤壓迫周圍組織
   6. 老化
- 化生是**可逆**的，但長期刺激下，化生的上皮可能再發生**異生**，進而發展成癌（巴瑞特食道 → 食道腺癌；吸菸者支氣管 → 鱗狀細胞癌）

:::note[異生(dysplasia)不是適應]
異生是細胞大小形狀不一、核大而深染、排列紊亂，尚未突破基底膜，屬於**癌前病變**；依程度分輕、中、重度，**重度異生占據上皮全層＝原位癌**。增生、化生、異生、原位癌、侵襲癌的完整比較見 [[neoplasia#abnormal-growth]]
:::

### 細胞的分裂能力 {#cell-types}

| 類型 | 分裂情形 | 例子 | 和化療、放療的關係 |
|---|---|---|---|
| 不穩定細胞 | 持續分裂 | 骨髓、皮膚與黏膜上皮、毛囊、生殖細胞 | 最容易受傷 → 骨髓抑制、黏膜炎、落髮 |
| 穩定細胞 | 平時不分裂，受傷時可再生 | 肝、腎小管、纖維母細胞 | |
| 永久細胞 | 出生後幾乎不分裂 | **神經元**、心肌 | 對化療、放療的直接效果最差；但化療仍可能造成周邊神經病變 |

- 再生與疤痕修復見 [[inflammation-repair#regeneration-vs-repair]]

## 細胞傷害 {#cell-injury}

![細胞傷害：正常細胞經可逆性傷害到壞死，另一條路是凋亡](/knowledge-images/cell-injury-death.svg)

- 原因
   1. **缺氧**：最常見（缺血、貧血、一氧化碳中毒、呼吸衰竭）；骨突處長期受壓造成的組織缺血見 [[pressure-injury#pathophysiology]]
   2. 物理：外傷、溫度、輻射
   3. 化學與藥物：酒精、藥物過量、毒物
   4. 感染、免疫反應、遺傳缺陷、營養失衡
- 缺氧時粒線體做不出 ATP → 細胞膜上的鈉鉀幫浦停擺 → 鈉與水進入細胞 → **細胞腫脹**，這是最早出現的變化

| | 可逆性傷害 | 不可逆性傷害（細胞死亡） |
|---|---|---|
| 細胞 | **腫脹**（水腫變性）；**細胞膜泡狀凸出** | 細胞膜破裂 |
| 胞器 | **粒線體腫脹**、**內質網擴張**、核糖體脫落 | 粒線體嚴重損傷、**溶小體破裂**（水解酶釋出，細胞自我消化） |
| 細胞核 | 染色質輕度聚集 | **核濃縮 → 核碎裂 → 核溶解** |
| 細胞質 | **脂肪變性** | |
| 結果 | 刺激去除後可恢復 | 不能恢復 |

- **脂肪變性**(fatty change)：三酸甘油酯堆積在細胞質，**肝最常見**（酒精、肥胖、糖尿病、營養不良、缺氧），也見於心臟與腎臟；持續下去可能變成脂肪性肝炎與肝硬化

::questions{ids="106-2_BM_033,110-1_BM_041,106-2_BM_034"}

### 細胞內堆積與病理性鈣化 {#accumulations}

| 堆積物 | 特徵 | 常見情形 |
|---|---|---|
| 脂質 | 脂肪變性；巨噬細胞吞膽固醇變成泡沫細胞 | 脂肪肝；動脈粥狀硬化斑塊 |
| **脂褐質**(lipofuscin) | 黃褐色顆粒，是脂質過氧化後的殘渣，又稱「**耗損性色素**」 | **老化與萎縮**的細胞，特別是**心肌、神經元、肝**；器官呈褐色時稱「褐色萎縮」 |
| 血鐵質(hemosiderin) | 鐵的儲存形式，黃褐色 | 局部出血後（瘀青由紫變黃綠褐）；全身鐵過多（多次輸血） |
| 類澱粉 | 蛋白質摺疊錯誤沉積在細胞外 | 見 [[autoimmune-diseases#amyloidosis]] |

| | **營養不良性鈣化** | **轉移性鈣化** |
|---|---|---|
| 發生在 | **已經受損或壞死**的組織 | **正常**組織 |
| 血鈣 | 正常 | **高血鈣** |
| 例子 | 動脈粥狀硬化斑塊、受損或老化的**心臟瓣膜**、**胰臟炎的脂肪壞死**、結核乾酪性壞死 | 副甲狀腺機能亢進、維生素 D 中毒、腎衰竭、骨轉移，鈣沉積在**腎臟**、肺、胃黏膜、血管 |

- 高血鈣的原因與處理見 [[calcium-phosphate]]、[[parathyroid-disorders]]

## 細胞死亡 {#cell-death}

### 壞死 {#necrosis}

- **細胞核變化的順序**：**核濃縮**（pyknosis，最早） → **核碎裂**(karyorrhexis) → **核溶解**(karyolysis)
- 細胞膜破裂、內容物漏出 → 吸引白血球 → **引起發炎**；漏出的酵素可在血中測到（例：心肌梗塞的心肌旋轉蛋白，見 [[cardiac-biomarkers]]）
- 壞死一定是**病理性**的，常是成群細胞一起死亡

| 型態 | 特徵 | 典型器官或疾病 |
|---|---|---|
| **凝固性壞死** | 組織輪廓還在幾天，之後被吞噬清除 | 缺血造成的梗塞：**心臟**、**腎臟**、脾臟（**腦除外**） |
| **液化性壞死** | 組織被酵素分解成液狀，最後留下空腔 | **腦梗塞**（數週後形成囊狀區域）；細菌感染形成的**膿瘍** |
| **乾酪性壞死** | 肉眼像起司的白色鬆軟物質，周圍有肉芽腫 | **結核**（見 [[inflammation-repair#granulomatous-inflammation]]） |
| **脂肪壞死** | 脂肪酶分解脂肪，脂肪酸和鈣結合（皂化），呈白色斑塊 | **急性胰臟炎**；乳房外傷 |
| **類纖維蛋白樣壞死** | 血管壁有抗原抗體複合物與纖維蛋白沉積 | 血管炎、惡性高血壓 |

- **壞疽**(gangrene)不是一種獨立的顯微型態，而是臨床用語：肢體缺血造成的凝固性壞死（乾性壞疽），若再合併細菌感染而液化（濕性壞疽）；產氣莢膜梭菌造成的是**氣性壞疽**，見 [[anaerobes]]

::questions{ids="111-1_BM_033"}

### 凋亡 {#apoptosis}

- 細胞**主動、耗能**的程式性死亡，由一群蛋白酶(caspase)執行
- 過程：細胞**皺縮** → 染色質凝集 → 細胞碎成**凋亡小體**（膜仍完整） → 巨噬細胞**吞噬**；溶小體的水解酶參與分解
- **膜沒有破，所以不引起發炎**
- 生理性凋亡
   1. **月經週期**子宮內膜崩離
   2. 胚胎發育時指間組織消失
   3. 胸腺淘汰會攻擊自己的 T 細胞
- 病理性凋亡
   1. **病毒性肝炎**的肝細胞死亡
   2. **輻射**、化療造成 DNA 嚴重受損（p53 啟動）
   3. 腫瘤細胞若關閉凋亡就能存活下來，見 [[neoplasia#molecular]]

| | 壞死 | 凋亡 |
|---|---|---|
| 細胞大小 | **腫脹** | **皺縮** |
| 細胞膜 | 破裂 | **完整**（形成凋亡小體） |
| 範圍 | 成群細胞 | 單一細胞 |
| 發炎 | **有** | **沒有** |
| 意義 | 一定是病理性 | 生理或病理性 |
| 耗能 | 被動 | 主動、耗能 |

::questions{ids="109-2_BM_040,113-3_BM_021,106-2_makeup_BM_017"}

### 死後變化 {#postmortem}

- 死亡後細胞全面停止產生 ATP，出現屍冷、屍斑、屍僵；時間與遺體護理見 [[end-of-life-care#postmortem-changes]]
- **屍僵**的機轉：肌肉放鬆需要 ATP 讓肌凝蛋白頭與肌動蛋白**分開**；ATP 耗盡後兩者一直結合，肌肉維持收縮僵硬（不是血液凝固，也不是鈣通道持續開放）；之後肌肉蛋白分解才逐漸緩解
