**發炎**是組織受傷或感染時，**血管與免疫細胞協調出來的防禦反應**，目的是**清除傷害因子、移除壞死組織，並啟動修復**。急性發炎通常有益，但過度或持續不退的發炎會傷害組織，轉成**慢性發炎**；壞死與發炎之後，身體再用**再生或修復**把組織補回來

## 重點摘要 {#summary}

- **急性發炎五徵**：**紅、腫、熱、痛、功能喪失**；機轉是**血管擴張、微血管通透性增加、白血球外滲**
- **白血球外滲順序**：**著邊 → 滾動 → 黏附 → 穿越 → 趨化**；**吞噬不是外滲的步驟**
- **嗜中性球最先到**，單核球與巨噬細胞數日後接手；**慢性發炎**以**巨噬細胞、淋巴球、漿細胞**為主，嗜中性球少
- 主要介質：**組織胺、血清素**(血管活性胺)、**緩激肽**、**補體 C3a/C5a**、**前列腺素與白三烯**(花生四烯酸代謝物)、**IL-1、TNF-α、IL-6**
- **肉芽腫**是慢性發炎的一種，**結核**的肉芽腫中央**乾酪性壞死**
- **一期癒合**：傷口對合，快、疤小；**二期癒合**：靠底部**肉芽組織**填補，慢、疤大、易感染；**類固醇、感染、糖尿病**使癒合延遲

### 國考常考點 {#exam-points}

- 急性發炎的細胞主要是**嗜中性球**(不是嗜酸性球)，組織間隙堆積的是**滲出液**(不是漏出液)；**緩激肽**與**痛覺**有關
- 血管**舒張**的主要介質是**組織胺**等，**IL-1 不是**主要的血管舒張介質；**血清素**屬**血管活性胺**；**組織胺不是**花生四烯酸的代謝物
- 白血球外滲**最先**是**著邊**；**吞噬**不屬於外滲的步驟
- **TNF-α** 是敗血症全身反應的主因，大量產生可造成休克與循環崩潰，**不會**促進傷口癒合
- **慢性發炎**浸潤的細胞是巨噬細胞、淋巴球、漿細胞；**嗜中性球**出現機會最少
- 肉芽腫性發炎常見於**結核、痲瘋、類肉瘤**，**B 型肝炎**最不常見；**慢性肉芽腫發炎造成的縮窄性心包炎**最常見的病因是**結核**
- **偽膜性**發炎：**困難梭狀桿菌**(偽膜性結腸炎)、白喉；**膿胸、膿瘍、闌尾炎**是**化膿性**，**水泡**(如帶狀疱疹)是**漿液性**；發炎使組織表面壞死稱**潰瘍**
- 傷口癒合**延遲**：**感染、類固醇、糖尿病(灌流不良)**；**類固醇不會**增強癒合強度；**傷口保持濕潤**才有助於**上皮化**，乾燥不利
- **機化**時**微血管大量增生**；**心肌梗塞**後死亡的心肌細胞由**結締組織(疤痕)**取代
- **冷療**能抑制發炎：**血管收縮**，減少血流以及白血球與淋巴球送到組織

## 急性發炎 {#acute-inflammation}

### 起因與過程 {#acute-process}

1. 常見起因：感染(細菌、病毒等)、組織壞死(缺血、創傷、梗塞)、異物、免疫反應、物理與化學傷害(燒燙傷、輻射、毒素)
2. **辨識**：組織常駐的巨噬細胞、肥大細胞、樹突細胞與內皮細胞用 **PRR** 偵測到 **PAMP**(病原)或 **DAMP**(受損細胞釋出)，釋放發炎介質([[immune-system-basics#pattern-recognition]])
   1. 例：**尿酸結晶**、細胞外 ATP 會活化細胞質的**發炎體**，使 caspase-1 把前驅的 IL-1β 切成有活性的 IL-1β；所以**痛風**是尿酸結晶引起的急性發炎，對一般抗發炎藥無效時可用 IL-1 拮抗劑
3. **血管變化**
   1. 先有幾秒的短暫**血管收縮**，之後，**小動脈擴張**，血流增加，造成**紅**與**熱**
   2. **微血管通透性增加**，富含蛋白質的液體漏到組織間隙形成**滲出液**，造成**腫**(水腫)
   3. 液體流失使血流變慢、血液變濃，白血球靠到血管壁
4. **白血球外滲與趨化**：把嗜中性球、單核球帶到發炎處(見下一節)
5. **吞噬與清除**：吞噬病原與壞死組織([[immune-system-basics#phagocytosis]])
6. **結束**：傷害因子清除後，發炎被**主動收束**(嗜中性球凋亡並被巨噬細胞吞噬、促發炎介質減少、巨噬細胞轉成修復型)；沒清除乾淨則**慢性化**

- 病理學把急性發炎的步驟記成五個 R：**辨識**(recognition)、**招募**白血球(recruitment)、**清除**傷害因子(removal)、**調控**(regulation)、**消退與修復**(resolution)
- 發炎時**淋巴流增加**，幫忙排出水腫液、白血球與碎屑；嚴重感染時淋巴管也可能把病原帶走造成擴散；傷口旁出現**紅色線條**是**淋巴管炎**，引流的淋巴結腫痛則是**淋巴結炎**

### 發炎五徵 {#cardinal-signs}

| 徵象 | 原因 |
|---|---|
| **紅**(rubor) | 小動脈擴張、充血 |
| **熱**(calor) | 血流增加(局部)；全身發炎時還有發燒 |
| **腫**(tumor) | 通透性增加，滲出液與細胞堆積 |
| **痛**(dolor) | **緩激肽**、**前列腺素 E2** 等刺激神經末梢；組織腫脹壓迫 |
| **功能喪失**(functio laesa) | 疼痛、水腫與組織傷害使器官無法正常運作 |

### 滲出液與漏出液 {#exudate-transudate}

| 項目 | **滲出液**(exudate) | 漏出液(transudate) |
|---|---|---|
| 原因 | **發炎**：血管**通透性增加** | 靜水壓上升或血漿膠體滲透壓下降(心衰竭、肝硬化、腎病症候群) |
| 蛋白質 | **多** | 少 |
| 細胞 | 多(白血球) | 少 |
| 外觀與比重 | 較混濁、比重高 | 清澈、比重低 |
| 例子 | **感染造成的肋膜積水**、膿 | 心衰竭的水腫與肋膜積水 |

### 血管通透性增加的機轉 {#permeability}

1. **內皮細胞收縮**(最常見)：發生在**微靜脈**，組織胺、緩激肽、白三烯等與受體結合後很快出現，**短暫**(約 15–30 分鐘)
2. **細胞激素引起的內皮回縮**：TNF、IL-1 造成，要約 4–6 小時才出現，但可持續 24 小時以上
3. **內皮直接受傷**：燒傷、部分感染與毒素使內皮壞死脫落；立刻漏水並持續數小時到數天，輕中度熱傷、紫外線(曬傷)則是延遲 2–12 小時才漏
4. **白血球傷害內皮**：白血球黏附在血管壁後釋出的毒性物質造成
5. **胞飲轉運增加**(VEGF 等)，以及**新生血管**尚未成熟時也會漏
6. 同一個刺激常同時有好幾種機轉，例如熱傷就同時有內皮收縮、直接傷害與白血球傷害

來源：Robbins Basic Pathology 第 9 版，第 2 章(發炎與修復)

### 白血球外滲 {#leukocyte-extravasation}


白血球要離開血管才能工作，主要發生在**微靜脈**(肺是微血管)，順序固定

1. **著邊**(margination)：血管通透性增加、血流變慢，白血球被擠到血管壁邊
2. **滾動**(rolling)：內皮細胞被活化後表現 **selectin**，與白血球微弱結合，使其在血管壁上滾動
   1. **P-selectin**：平時儲存在內皮細胞內，組織胺、凝血酶刺激後數分鐘內移到細胞表面
   2. **E-selectin**：要靠 **TNF、IL-1** 誘導表現
   3. 白血球上的 **L-selectin** 也參與
3. **牢固黏附**(adhesion)：趨化激素讓白血球的 **integrin**(LFA-1、Mac-1)變成高親和力狀態，與內皮的 **ICAM-1**(及 VCAM-1)緊密結合；白血球沿血管壁排列，像鋪路石，稱**鋪道**
4. **穿越**(transmigration，diapedesis)：從內皮細胞間隙擠過去，需要 **PECAM-1(CD31)**；穿出後分泌**膠原蛋白酶**溶解基底膜
5. **趨化**(chemotaxis)：沿著**趨化因子的濃度梯度**走向發炎中心
   1. 嗜中性球的趨化因子：**C5a**、**白三烯 B4**、**IL-8**(趨化激素)、細菌的 N-甲醯甲硫胺酸胜肽
6. 抵達後才進行**吞噬**，吞噬**不屬於**外滲的步驟

- **白血球黏附缺陷**：白血球上的 CD18(integrin β2)缺陷，無法牢固黏附，表現為臍帶延遲脫落、臍炎與反覆細菌感染([[complement-system#deficiencies]])
- **冷療**使血管收縮，減少血流與白血球、淋巴球送到組織，所以能抑制發炎；之後在冷熱療頁整理

來源：Robbins Basic Pathology 第 9 版，第 2 章(發炎與修復)

### 發炎的細胞 {#inflammatory-cells}


| 細胞 | 出現時機 | 角色 |
|---|---|---|
| **嗜中性球** | **最先**：多數急性發炎的前 **6–24 小時**以它為主；組織中壽命短，約 24–48 小時凋亡 | 吞噬與殺菌，釋出蛋白酶與活性氧；也會傷害宿主組織；累積死亡的嗜中性球與壞死物形成**膿** |
| **單核球與巨噬細胞** | 約 **24–48 小時**取代嗜中性球(皮膚傷口約第 3 天) | 吞噬壞死組織與**死亡的嗜中性球**；分泌細胞激素與生長因子，**啟動修復**；慢性發炎的主角 |
| **嗜酸性球** | 過敏、寄生蟲 | 對付寄生蟲；氣喘等過敏疾病增多；**EBV 感染**增多的是淋巴球 |
| 肥大細胞、嗜鹼性球 | 早期 | 釋出組織胺等，造成血管變化 |
| **淋巴球、漿細胞** | 慢性、病毒感染、免疫性發炎 | 免疫反應與抗體 |
| 血小板 | 早期 | 止血、釋出生長因子與介質 |

- **例外**：綠膿桿菌感染會持續招募嗜中性球好幾天；**病毒感染**時淋巴球可能先到；某些過敏反應以**嗜酸性球**為主
- 嗜中性球最先到的原因：數量最多、對趨化激素反應最快、能黏得很牢(P-selectin、E-selectin 很快被誘導)
- 發炎時白血球分類的變化(嗜中性球上升、核左移)見 [[complete-blood-count#high-low]]

來源：Robbins Basic Pathology 第 9 版，第 2 章(發炎與修復)

### 化學介質 {#mediators}

| 類別 | 介質 | 主要作用 |
|---|---|---|
| **血管活性胺** | **組織胺**(肥大細胞、嗜鹼性球、血小板) | **小動脈擴張、微靜脈通透性增加**，早期且短暫 |
| | **血清素**(血小板) | 屬血管活性胺；作用是**血管收縮** |
| **激肽系統** | **緩激肽** | 通透性增加、血管擴張、**痛** |
| **補體** | **C3a、C5a**(過敏毒素)、**C3b**、C5b-9 | 肥大細胞釋出組織胺；**C5a 趨化**；C3b 調理；MAC 溶解([[complement-system]]) |
| **花生四烯酸代謝物** | **前列腺素**(PGE2：血管擴張、痛、發燒；PGI2；PGD2) | 血管擴張、痛、發燒 |
| | **血栓素 A2** | 血小板凝集、血管收縮 |
| | **白三烯**(LTB4：趨化、白血球黏附；LTC4、D4、E4：血管收縮、通透性增加、支氣管收縮) | 趨化與過敏性氣道收縮 |
| **細胞激素** | **IL-1、TNF-α、IL-6**(巨噬細胞) | 活化內皮、發燒、急性期反應；**TNF-α** 是敗血症全身反應的主因 |
| **趨化激素** | **IL-8** | 嗜中性球趨化 |
| 其他 | 一氧化氮、**血小板活化因子(PAF)**、活性氧與溶酶體酵素 | 血管擴張、通透性增加、白血球黏附與趨化、殺菌，也會傷組織 |

- 介質多半是**短效**的：會很快衰解、被酵素分解(例如緩激肽被激肽酶分解)或被清除，避免發炎失控
- 介質分兩大類：**預先儲存**在顆粒內、刺激後立刻釋出(組織胺、血清素)，以及**刺激後才新合成**(前列腺素、白三烯、細胞激素)；**血漿來源**的(補體、激肽)平常是無活性的前驅物，被切開才活化
- 血管**舒張**的主要介質是**組織胺、前列腺素、一氧化氮**；**IL-1 與 TNF** 主要負責活化內皮與引起全身反應
- **組織胺**是預先儲存在肥大細胞顆粒內的介質，**不是**花生四烯酸的代謝物；前列腺素、血栓素、白三烯才是

:::basics[為什麼類固醇與 NSAID 都能抗發炎？]
細胞膜的磷脂質經**磷脂酶 A2** 變成**花生四烯酸**，之後分兩條路：**環氧合酶(COX)**路徑產生前列腺素與血栓素，**脂氧合酶**路徑產生白三烯

1. **NSAID**(aspirin、ibuprofen、**celecoxib** 等)抑制 **COX**，所以減少前列腺素與血栓素，能退燒、止痛、消炎；celecoxib 專一抑制 COX-2，較少腸胃出血([[nsaids-acetaminophen]])
2. **類固醇**(糖皮質素)抑制磷脂酶 A2，上游就減少，所以前列腺素與白三烯**兩條**都減少，抗發炎範圍更廣，同時抑制免疫與傷口癒合
3. **白三烯受體拮抗劑**(如 montelukast)只阻斷白三烯的受體，用在氣喘與過敏性鼻炎
:::

### 全身性反應 {#systemic-response}


- **發燒**：細菌的內毒素等**外源性致熱原**刺激白血球釋出 IL-1、TNF(內生性致熱原)，作用於下視丘，使血管周圍細胞合成**前列腺素 E2**，把體溫調定點調高；**NSAID 與 aspirin** 抑制 COX 而退燒
- **急性期反應物**：**IL-6** 刺激肝臟大量製造 **CRP、纖維蛋白原、血清類澱粉 A**，濃度可上升數百倍([[inflammatory-markers]])
  1. CRP、SAA 能附著在微生物表面，當調理素並活化補體
  2. **纖維蛋白原**使紅血球堆疊成錢串狀(rouleaux)而沉降變快，這就是**紅血球沉降速率(ESR)**升高的原因
- **白血球上升**：細菌感染以嗜中性球為主，病毒感染以淋巴球為主，寄生蟲與過敏以嗜酸性球為主
- 反應過度失控時，造成**敗血症**與休克([[sepsis]])
- **TNF、IL-1、IL-6** 是急性期反應最重要的三個細胞激素

來源：Robbins Basic Pathology 第 9 版，第 2 章(發炎與修復)

### 發炎的結果 {#outcomes}


1. **消散**(resolution)：傷害因子被清除、傷害有限且組織能再生，恢復正常構造與功能
   1. 腔室(胸腔、腹腔、關節腔)裡的少量滲出液，由白血球的蛋白酶消化後被吸收，也屬消散
   2. 滲出液很多、沒辦法清掉時，肉芽組織會長進滲出物，稱**機化**，最後留下疤痕
2. **修復與纖維化**：組織破壞多、或由不能再生的細胞組成時，用**肉芽組織**修補，最後留下疤痕
3. **膿瘍形成**：化膿性發炎局部被包住，因為組織被破壞，**通常以疤痕收場**
4. **慢性發炎**：傷害因子持續存在，或急性反應沒有結束

## 發炎的種類 {#types}

### 依滲出物的型態 {#morphology}

| 型態 | 特徵 | 例子 |
|---|---|---|
| **漿液性** | 稀薄、含少量蛋白質的液體，細胞少；體腔內的稱**積液** | **水泡**(病毒感染如帶狀疱疹、燙傷)、肋膜與心包腔積液 |
| **纖維素性** | 傷害較重、通透性很高，**纖維蛋白原**漏出形成纖維蛋白網；常見於體腔襯裡(腦膜、心包、胸膜)；可被分解而消散，滲出太多則**機化**成疤痕 | 纖維素性心包炎、肋膜炎(有摩擦音)；心包炎機化後可造成**縮窄性心包炎** |
| **化膿性** | 大量嗜中性球、壞死細胞與水腫液形成**膿**；**化膿菌**(例如葡萄球菌)特別容易引起 | **膿瘍**(局部被包住，中央壞死、周邊有嗜中性球、外圍血管與纖維母細胞增生)、**膿胸**、**闌尾炎**、蜂窩性組織炎(瀰漫性) |
| **偽膜性** | 纖維素、壞死細胞與細菌覆蓋在黏膜表面形成「膜」 | **困難梭狀桿菌**(偽膜性結腸炎)、白喉 |
| **潰瘍** | 發炎使**組織表面壞死**脫落，留下凹陷缺損；只發生在壞死與發炎靠近表面的地方 | **消化性潰瘍**(胃、十二指腸，急慢性發炎並存)、口腔、泌尿生殖道黏膜潰瘍，以及循環不良的老年人**下肢皮膚潰瘍** |

- **膿瘍**是局部被包起來的膿；**膿胸**是膿積在胸膜腔；**蜂窩性組織炎**是沿組織間隙擴散的化膿性發炎([[skin-bone-infections]])

### 急性與慢性發炎比較 {#acute-vs-chronic}

| 項目 | 急性 | 慢性 |
|---|---|---|
| 起病與時間 | 快：數分鐘到數日 | 慢：數天到數年 |
| 主要細胞 | **嗜中性球** | **巨噬細胞、淋巴球、漿細胞**，嗜中性球少 |
| 主要變化 | 血管變化、水腫、滲出 | 組織**破壞與修復同時進行**、纖維化、血管新生 |
| 傷害與纖維化 | 通常輕微、有自限性 | 常嚴重且持續進展 |
| 局部與全身徵象 | 明顯 | 不明顯，可能很隱微 |
| 常見原因 | 感染、創傷 | 急性發炎未清除、持續感染(結核)、自體免疫、長期異物或毒素 |

- **慢性發炎的細胞互動**：巨噬細胞把抗原呈現給 T 細胞並分泌 IL-12；活化的 T 細胞再分泌細胞激素招募與活化巨噬細胞，形成**循環**讓發炎持續下去
  1. **Th1** 分泌 **IFN-γ**，活化巨噬細胞(傳統活化)
  2. **Th2** 分泌 IL-4、IL-5、IL-13，招募**嗜酸性球**，與寄生蟲及過敏反應有關
  3. **Th17** 分泌 IL-17，招募**嗜中性球與單核球**
  4. 長期的類風濕性關節炎滑膜、自體免疫性甲狀腺炎甚至可以長出像淋巴結的構造(含生發中心)
- 慢性發炎的特徵：**單核球／巨噬細胞與淋巴球**浸潤、**血管增生**與**纖維化**(疤痕)

來源：Robbins Basic Pathology 第 9 版，第 2 章(發炎與修復)

### 肉芽腫性發炎 {#granulomatous-inflammation}


1. **定義**：一種慢性發炎。活化的**巨噬細胞**聚集成團(外觀像上皮，稱**類上皮細胞**)，常融合成**多核巨細胞**，周圍有淋巴球圍成一圈，老的肉芽腫外圍還有纖維母細胞；是身體把**無法清除的物質**「圍起來」的策略
2. **形成的三種情況**
   1. 對某些微生物(**結核菌**、梅毒螺旋體、黴菌)的**持續 T 細胞反應**：T 細胞的細胞激素(**IFN-γ**)持續活化巨噬細胞
   2. 免疫性發炎疾病，例如**克隆氏症**
   3. 原因不明的**類肉瘤病**，以及對惰性異物(縫線、碎片)的**異物肉芽腫**
3. **種類**
   1. **乾酪性(壞死性)**：中央壞死像乾酪(缺氧加自由基傷害)，典型是**結核病**；看到肉芽腫一定要先排除結核
   2. **非乾酪性**：**類肉瘤病、克隆氏症、痲瘋**與異物反應
4. **常見疾病**：結核病、痲瘋、類肉瘤病、克隆氏症(偶見非乾酪性肉芽腫；**潰瘍性結腸炎**通常沒有)、梅毒第三期(梅毒腫)、貓抓病；**B 型肝炎**不是典型的肉芽腫性疾病
5. 肉芽腫能把致病物質「圍起來」，是有用的防禦；但常殺不死病原，肉芽腫之後的**纖維化**甚至是造成器官功能障礙的主因(例如結核)
6. **慢性肉芽腫性心包炎**造成**縮窄性心包炎**，最常見的病因是**結核**([[tuberculosis]])
7. **化膿性肉芽腫**名字雖然有肉芽，其實是**血管增生**的病灶，組織學與微血管性血管瘤相似
8. **慢性肉芽腫病**是吞噬細胞缺陷(NADPH 氧化酶)，不是這裡的肉芽腫性發炎，之後在原發性免疫缺陷頁整理

來源：Robbins Basic Pathology 第 9 版，第 2 章(發炎與修復)；Shah 2017 肉芽腫綜論

## 再生與修復 {#repair}

### 再生與修復的差別 {#regeneration-vs-repair}


- **再生**：由原本的細胞增生，**完全恢復**組織構造與功能
- **修復**：用**肉芽組織**填補，最後成為**疤痕**(纖維化)，功能不一定完整
- 能不能再生要看細胞的分裂能力
   1. **不穩定細胞**(持續分裂，由幹細胞補充)：造血細胞與大多數**表面上皮**(皮膚、口腔、陰道、子宮頸、消化道、泌尿道)，只要幹細胞還在就容易再生
   2. **穩定細胞**(平時幾乎不分裂，受傷或組織量減少時會增生)：**肝、腎、胰臟**的實質細胞，以及**內皮細胞、纖維母細胞、平滑肌細胞**(這些對傷口癒合很重要)；除了**肝臟**之外，再生能力都有限
   3. **永久細胞**(出生後不再分裂)：大部分**神經元**與**心肌細胞**；損傷後無法再生，只能由**疤痕**取代，所以**心肌梗塞後死亡的心肌細胞由結締組織取代**
   4. 骨骼肌通常歸在永久細胞，但有衛星細胞提供一些再生能力
- 完整的再生只發生在由**不穩定與穩定細胞**組成的組織；永久細胞組織受傷一定留下疤痕

來源：Robbins Basic Pathology 第 9 版，第 2 章(發炎與修復)

### 傷口癒合的四個階段 {#healing-phases}


| 階段 | 時間 | 主要事件 |
|---|---|---|
| **止血** | 受傷後數小時內 | 血管收縮、血小板聚集、纖維蛋白形成血塊當**臨時基質**；血小板釋出生長因子 |
| **發炎** | 約 1–3 天 | **嗜中性球**最先到(沒有感染約維持 2–5 天)，清除細菌與壞死組織；**單核球**變成**巨噬細胞**，繼續清理並啟動修復 |
| **增生** | 約第 4 天到 3 週 | **上皮再生**(傷口邊緣角質細胞移行並增生)；**血管新生**；**肉芽組織**形成；纖維母細胞製造**膠原**；**傷口收縮**(肌纖維母細胞) |
| **重塑(成熟)** | 約第 3 週到 1 年 | 膠原重新排列、交聯，抗張力增加；血管減少；疤痕變平、變淡 |

- 四個階段**重疊**進行，不是截然分開
- **肉芽組織**：新生的微血管、纖維母細胞與巨噬細胞組成，外觀**粉紅到紅色、顆粒狀**，健康時**不易出血**；顏色暗而**易出血**可能表示感染
- **機化**：壞死組織、血栓或滲出物被肉芽組織取代的過程，此時**微血管大量增生**
- **傷口強度**：縫合的傷口因為有縫線，強度約是正常皮膚的 70%；**拆線時(約 1 週)只剩約 10%**，之後 4 週內快速增加，約 **3 個月**達到正常的 **70–80%**，之後幾乎不會再進步(所以疤痕處永遠比正常皮膚弱)

來源：Landén 2016；Robbins Basic Pathology 第 9 版，第 2 章；OpenStax Medical-Surgical Nursing 第 28 章

### 一期、二期與三期癒合 {#intention}


| 類型 | 傷口 | 過程與結果 |
|---|---|---|
| **一期癒合**(primary intention) | 乾淨、沒感染、邊緣**能對合**：手術縫合、釘合或用膠 | **最快**；主要靠上皮再生，只有局部破壞，**疤痕小**、收縮很少 |
| **二期癒合**(secondary intention) | 組織缺損多、邊緣**無法對合**：大傷口、膿瘍、潰瘍、壓傷、器官梗塞 | 再生加疤痕；由**底部往上**長出大量肉芽組織，再**收縮**、上皮化；**較慢、疤痕較大、感染風險高** |
| **三期癒合**(tertiary，延遲一期閉合) | 刻意讓傷口先開放(等感染控制，或準備植皮、皮瓣) | 之後再縫合 |

1. 一期癒合的時間軸(乾淨的縫合傷口)
   1. **24 小時內**：嗜中性球出現在切口邊緣，基底細胞開始分裂；24–48 小時上皮細胞從兩側往中間移行
   2. **第 3 天**：嗜中性球大致被**巨噬細胞**取代，**肉芽組織**長進切口，出現與切口垂直排列的膠原
   3. **第 5 天**：**新生血管**達高峰，肉芽組織填滿切口，膠原開始橫跨連接
   4. **第 2 週**：膠原與纖維母細胞持續增加，發炎細胞、水腫與血管漸退，疤痕開始「變白」
   5. **約 1 個月**：疤痕是少發炎細胞的結締組織，覆蓋正常的表皮；**被破壞的皮膚附屬器(毛囊、汗腺)永久消失**
2. 二期癒合和一期的差別
   1. 傷口表面形成**較大的痂**
   2. **發炎更強**，因為要清除更多壞死物，也更容易造成發炎性傷害
   3. 需要更多肉芽組織，所以**疤痕也更大**
   4. 有明顯的**傷口收縮**：約 6 週內大傷口可縮到原本的 5–10%，靠**肌纖維母細胞**

來源：Robbins Basic Pathology 第 9 版，第 2 章(發炎與修復)；OpenStax Medical-Surgical Nursing 第 28 章

### 影響傷口癒合的因素 {#healing-factors}


| 類別 | 延遲癒合的因素 | 說明 |
|---|---|---|
| 局部 | **感染**、壞死組織與**異物**、**血流灌注不足**(動脈硬化、糖尿病、靜脈曲張)、水腫、局部壓力或扭力 | **感染是臨床上最重要的延遲因素**：使發炎期延長、傷害加重；壓力或扭力會使傷口裂開 |
| 全身 | **糖尿病**、**營養不良**(蛋白質缺乏、**維生素 C 缺乏**抑制膠原合成)、年紀大、抽菸、免疫低下 | |
| 藥物與治療 | **類固醇**(抑制發炎與 TGF-β，使疤痕變弱)、免疫抑制劑、化學治療、放射治療 | **類固醇不會**增強癒合強度；少數情況(如角膜感染)會刻意合用以減少疤痕混濁 |

- 傷害的**類型與位置**也重要：只有不穩定與穩定細胞的組織能完整再生，永久細胞的組織(心、腦)一定留疤
- 有利癒合的處理：**清創**移除壞死組織、控制感染、改善血流與營養、**維持適當濕潤**(利於角質細胞移行與上皮化；乾燥反而不利)
- 題目提到**微量元素**(銅、硒、矽等)有助傷口癒合；營養與傷口護理的細節之後在傷口與壓傷頁整理

來源：Robbins Basic Pathology 第 9 版，第 2 章(發炎與修復)；OpenStax Medical-Surgical Nursing 第 28 章

### 修復的併發症 {#repair-complications}


1. **癒合不良**：機械張力、感染或灌流不良使傷口**裂開**(dehiscence)，嚴重時內臟脫出
2. **過度疤痕**
   1. **蟹足腫**(keloid)：膠原堆積過多，疤痕**突出並超出原本傷口範圍**，不會自行消退；有**遺傳傾向**，**深膚色族群**較常見
   2. **肥厚性疤痕**：膠原過多但**限於原本傷口範圍**，可能隨時間縮小(Robbins Basic 沒有收錄這項區分，依一般病理學，待課本核對)
   3. **過度的肉芽組織**：長得比周圍皮膚還高(舊稱「proud flesh」)，擋住上皮再生，要燒灼或切除才能讓上皮接合
3. **攣縮**：疤痕收縮造成關節活動受限，常見於燒傷
4. **粘連**：腹部手術後腸管與腹壁黏在一起
5. **纖維化**：**持續**的傷害(慢性感染、免疫反應)使膠原過度堆積；疤痕是一次短暫傷害後有秩序的修復，纖維化則多見於慢性疾病，會造成器官功能障礙(肺纖維化、肝硬化)
6. **機化的滲出液**：纖維素性心包炎機化後形成緻密疤痕，會讓心包腔閉鎖並限制心肌收縮

來源：Robbins Basic Pathology 第 9 版，第 2 章(發炎與修復)
