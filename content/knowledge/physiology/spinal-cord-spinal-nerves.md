脊髓是腦和身體之間的高速公路：**白質**裡的徑路把感覺送上去、把運動指令送下來；**灰質**則是不必經過大腦就能完成的**脊髓反射**中樞。31 對**脊神經**從椎間孔出來，在頸、臂、腰、薦組成神經叢，再分支到全身

## 重點摘要 {#summary}

- 成人脊髓止於 **L1–L2**(脊髓圓錐)，以下是**馬尾**；**腰椎穿刺**選 **L3–L4 或 L4–L5**，避開脊髓
- 脊髓靠**軟脊膜**延伸的**齒狀韌帶**(兩側)與**終絲**(下端連到尾骨)固定
- **後根 = 感覺**(細胞體在**背根神經節**，偽單極)；**前根 = 運動**；**前角**是支配骨骼肌的 α 運動神經元；脊神經是混合神經
- **後柱**(精細觸覺、震動、本體感覺)到**延腦才交叉**；**脊髓視丘徑**(痛、溫)進脊髓**很快就交叉**；**皮質脊髓徑**在**延腦錐體交叉** → 半側脊髓損傷時，同側運動與本體感覺喪失、對側痛溫覺喪失
- **膈神經 C3–C5**(頸叢)；上肢由 **C5–T1**(臂叢)支配；**肱骨幹骨折 → 橈神經 → 垂腕**；**股神經**受損 → 膝反射消失；**坐骨神經**支配大腿後側(股二頭肌)
- 反射弧：**受器 → 感覺神經元 → 中樞 → 運動神經元 → 動器**；牽張反射是**單突觸**(Ia → α 運動神經元)；縮回反射需要**中間神經元**

### 國考常考點 {#exam-points}

- 腰椎曲是**向前凸**的次發彎曲；腰椎棘突短寬、**水平向後**；橫突有孔(橫突孔，椎動脈通過)的是**頸椎**；腰椎穿刺**不在** L1–L2
- 「每個椎孔都有脊髓通過」是**錯**的(L2 以下只有馬尾)；每個椎間孔都有脊神經通過
- **齒狀韌帶**來自**軟脊膜**；連到尾骨、固定脊髓下端的是**終絲**
- 支配骨骼肌的運動神經元細胞體在**灰質前角**；傳遞一般體表感覺的神經節是**背根神經節**
- **垂腕** → **橈神經**(沿肱骨的橈神經溝走，**肱骨幹骨折**最容易傷到)
- 膈神經來自**頸神經叢**(C3–C5)，不是臂叢、不是肋間神經
- **股神經**受損 → **膝反射消失**(大腿內收是閉孔神經；足外翻是腓淺神經)
- 坐骨神經支配**股二頭肌**(膕旁肌群)；股四頭肌是股神經、臀大肌是臀下神經、臀中肌是臀上神經
- **左側 T6 半側截斷**：**左側** T6 以下運動與震動覺消失；**右側** T6 以下痛溫覺消失
- 心臟轉移痛在**左手臂內側**(T1–T5)；第一產程痛經 **T10–L1**，第二產程會陰痛經 **S2–S4**(陰部神經)
- 尾骶骨按摩、按摩、TENS 是運用**門閥控制理論**
- 反射弧最終端是**動器**；縮回反射**需要中間神經元**；牽張反射的傳出神經是 **α 運動神經元**，傳入是 **Ia** 纖維，中樞在脊髓
- 使用**硫酸鎂**時最重要的評估是**深部肌腱反射**(膝反射消失是鎂中毒最早的徵象)
- **C3–C5 完全損傷**：四肢癱瘓、無法自行呼吸、受傷以下反射消失，且因神經性休克出現**心搏過慢與低血壓**(不是心搏過速、高血壓)；**T12–L3** 脊髓休克**不影響自行呼吸**

## 脊椎與脊髓的位置 {#vertebral-column}

### 脊椎的特徵 {#vertebrae}

| 部位 | 數目 | 特徵 |
|---|---|---|
| 頸椎 | 7 | 椎體小、**橫突有孔**(橫突孔，椎動脈通過)；C1 寰椎、C2 樞椎 |
| 胸椎 | 12 | 有與肋骨相接的關節面；棘突**細長、往下斜** |
| 腰椎 | 5 | 椎體最大最厚；棘突**短寬、呈方形、水平向後**；橫突沒有孔 |
| 薦椎 | 5 塊癒合成 1 塊 | |
| 尾椎 | 3–5 塊癒合 | |

- **彎曲**：胸曲與薦曲是出生就有的**初級彎曲**(向後凸)；**頸曲**(抬頭後)與**腰曲**(站立行走後)是**次發彎曲**，**向前凸**
- **椎孔**疊起來成為椎管，裡面是脊髓；**椎間孔**由上下兩個椎骨圍成，每個都有一條脊神經通過；**椎間盤**在椎體之間

### 脊髓的範圍與固定 {#cord-extent}

1. 脊髓上接延腦(枕骨大孔)，**成人下端止於 L1–L2**，末端變細稱**脊髓圓錐**(新生兒較低，約 L3)
2. 圓錐以下的腰薦神經根在椎管內往下走，像馬尾巴，稱**馬尾**，所以 L2 以下的椎孔裡**沒有脊髓**
3. 固定構造
   1. **齒狀韌帶**：**軟脊膜**往兩側延伸成齒狀，穿過蜘蛛膜下腔附著在硬脊膜上，左右各約 21 個
   2. **終絲**：軟脊膜從脊髓圓錐往下延伸，連到**尾骨**
4. 外有三層脊膜：**硬脊膜**、蜘蛛膜、**軟脊膜**
   1. **硬膜外腔**(硬脊膜與椎骨之間)：有脂肪與靜脈叢，**硬膜外麻醉**打在這裡
   2. **蜘蛛膜下腔**：充滿**腦脊髓液**，**腰椎穿刺**與**脊髓麻醉**打在這裡

### 腰椎穿刺的位置 {#lumbar-puncture-site}

- 選 **L3–L4 或 L4–L5** 間隙，在脊髓圓錐以下，只會碰到漂浮的馬尾神經根
- 兩側**髂嵴最高點的連線**約通過 **L4 棘突**，用來定位

## 脊髓切面構造 {#cross-section}

::figure{src="/knowledge-images/servier-spinal-cord-section.svg" labels="spinal-cord-section" alt="脊髓橫切面(上為後側)；圖中沒有畫出背根神經節"}

1. **灰質**在中央呈 H 形(蝴蝶形)，是神經元細胞體所在
   1. **後角**：接收感覺訊息，與感覺神經元形成突觸
   2. **前角**：支配骨骼肌的 **α 與 γ 運動神經元**細胞體
   3. **側角**：只在 **T1–L2**，是**交感神經節前神經元**；薦髓 S2–S4 有副交感節前神經元
   4. **中央管**：在灰質中央，與腦室相通
2. **白質**在外圍，由有髓鞘的徑路組成，分成後柱、側柱、前柱
3. **神經根**
   1. **後根(背根)**：**感覺**纖維，上面膨大處是**背根神經節**(偽單極神經元的細胞體)
   2. **前根(腹根)**：**運動**纖維
   3. 後根傳入、前根傳出，稱**貝爾－馬讓迪定律**；兩根在椎間孔附近合成**脊神經**，是**混合神經**
4. **31 對脊神經**：頸 8、胸 12、腰 5、薦 5、尾 1

## 上行與下行徑路 {#tracts}

![三條主要徑路的交叉位置](/knowledge-images/spinal-tracts.svg)

| 徑路 | 傳什麼 | 位置 | 在哪裡交叉 |
|---|---|---|---|
| **後柱－內側蹄系** | 精細觸覺、**震動覺**、**本體感覺**(位置覺) | 後柱(薄束、楔束) | **延腦**(換元後交叉) |
| **脊髓視丘徑** | **痛覺、溫度覺**、粗觸覺 | 側柱與前柱 | 進入**脊髓後 1–2 節內** |
| **外側皮質脊髓徑** | 隨意運動(精細動作) | 側柱 | **延腦錐體**(約 85–90%) |
| 前皮質脊髓徑 | 軀幹的隨意運動 | 前柱 | 在脊髓各節交叉 |

### 脊髓半側截斷症候群 {#brown-sequard}

脊髓只有左或右半邊受損(例如刀傷)時：

1. **同側**、受傷以下：**運動**喪失(皮質脊髓徑已在延腦交叉過)、**震動覺與本體感覺**喪失(後柱還沒交叉)
2. **對側**、受傷以下 1–2 節：**痛覺與溫度覺**喪失(脊髓視丘徑在受傷處以下已交叉到對側)

### 上運動神經元與下運動神經元損傷 {#umn-lmn}

| 項目 | 上運動神經元(大腦皮質到脊髓的徑路) | 下運動神經元(前角細胞、前根、周邊神經) |
|---|---|---|
| 肌張力 | **痙攣性**(升高) | **弛緩性**(降低) |
| 深部肌腱反射 | **亢進** | **減弱或消失** |
| 巴賓斯基反射 | **陽性** | 陰性 |
| 肌肉萎縮 | 輕微(廢用性) | **明顯**，可見肌束顫動 |
| 例子 | 中風、脊髓損傷的慢性期 | 小兒麻痺、周邊神經損傷、ALS 的下運動神經元部分 |

## 皮節 {#dermatomes}

::figure{src="/knowledge-images/servier-dermatomes.svg" labels="dermatomes" alt="皮節：每一條脊神經負責的皮膚區域(前面與背面)"}

- 每一對脊神經負責的一條皮膚區域稱**皮節**，用來判斷脊髓損傷或神經根壓迫的層級
- 常用標誌：**C6 拇指**、**T4 乳頭**、**T10 肚臍**、**L1 鼠蹊**、**L4 膝前**、**S1 足外側**、**S3–S5 肛門周圍**(馬鞍區)
- 各書的皮節圖分界略有不同，考試以上面這些標誌為準

### 轉移痛 {#referred-pain}

1. 內臟的痛覺纖維和某段皮膚的感覺纖維進入**同一脊髓節段**，大腦把內臟痛誤判成那段皮膚痛
2. 例子
   1. **心臟** → T1–T5 → **胸前與左手臂內側**；機轉與心肌梗塞的轉移痛見 [[coronary-artery-disease#referred-pain]]
   2. 橫膈、肝膽 → C3–C5 → **右肩**
   3. 腎臟、輸尿管 → 腰部與鼠蹊

### 產痛的傳導 {#labor-pain}

| 產程 | 疼痛來源 | 傳入脊髓 | 疼痛位置 |
|---|---|---|---|
| **第一產程**(子宮頸擴張) | 子宮頸擴張、子宮體下段伸展、子宮收縮時肌肉**缺氧** | **T10–L1** | 下腹部與下背部 |
| **第二產程**(子宮頸全開後) | 胎頭下降壓迫與拉扯**陰道、會陰**，子宮韌帶伸張 | **S2–S4**(陰部神經) | 會陰、直腸、大腿 |

### 門閥控制理論 {#gate-control}

1. 脊髓後角(膠狀質)像一道閘門，決定痛覺訊號能不能往上傳
2. 傳觸壓覺的**粗纖維(Aβ)**興奮時，會活化後角的抑制性中間神經元，把閘門**關小**，細纖維(Aδ、C)傳的痛覺就較難通過
3. 應用：**按摩**、**尾骶骨加壓按摩**、輕撫、**TENS**；聽音樂、注意力集中法是轉移注意力(大腦層次)，溫水淋浴主要是放鬆

## 脊髓反射 {#reflexes}

![反射弧的五個組成：受器、感覺神經元、中樞、運動神經元、動器](/knowledge-images/reflex-arc.svg)

### 反射弧 {#reflex-arc}

1. **受器**：接收刺激(如皮膚痛覺受器、肌梭)
2. **感覺(傳入)神經元**：經後根進入脊髓
3. **中樞**：脊髓灰質，多數經**中間神經元**整合
4. **運動(傳出)神經元**：從前角經前根出去
5. **動器**：執行反應的**肌肉或腺體**，是反射弧的**最終端**

### 常見的脊髓反射 {#reflex-types}

| 反射 | 突觸 | 過程 | 意義 |
|---|---|---|---|
| **牽張反射**(膝反射等深部肌腱反射) | **單突觸** | 肌肉被拉長 → **肌梭** → **Ia 纖維** → 直接接 **α 運動神經元** → 同一條肌肉收縮 | 維持肌張力與姿勢；動器是**梭外肌纖維**，不是肌梭 |
| 肌腱反射(高爾基肌腱器) | 多突觸 | 肌腱張力過大 → **Ib 纖維** → 抑制同一條肌肉 | 保護肌肉與肌腱不被拉傷 |
| **縮回反射**(屈肌反射) | **多突觸** | 痛覺刺激 → 感覺神經元 → **中間神經元** → 屈肌收縮，把手腳縮回 | 碰到燙的東西、踩到釘子；**不需大腦下令**，是極度冷熱時的保護機制 |
| 交叉伸肌反射 | 多突觸 | 一腳縮回時，**對側**伸肌收縮撐住身體 | 維持平衡 |

### 深部肌腱反射的評估 {#dtr}

| 反射 | 脊髓節段 | 神經 |
|---|---|---|
| 肱二頭肌 | C5–C6 | 肌皮神經 |
| 肱橈肌 | C5–C6 | 橈神經 |
| 肱三頭肌 | C6–C8(以 C7 為主) | 橈神經 |
| **膝反射**(股四頭肌) | **L2–L4** | **股神經** |
| 踝反射(小腿三頭肌) | S1–S2 | 脛神經 |

- 分級：**0** 消失、**1+** 減弱、**2+** 正常、**3+** 增強、**4+** 亢進合併陣攣
- **硫酸鎂**治療子癇前症時，每次給藥前都要評估**膝反射**：鎂中毒最早的徵象是**深部肌腱反射消失**，接著才是呼吸抑制(呼吸 < 12 次／分)、尿量減少
- **巴賓斯基反射**：刮足底外側時大腳趾上翹、其他腳趾張開；成人陽性代表**上運動神經元**病變，**未滿 1–2 歲的嬰兒**陽性是正常的(皮質脊髓徑髓鞘化未完成)

### 脊髓休克 {#spinal-shock}

1. 脊髓急性損傷後，**受傷平面以下**所有運動、感覺與**反射都暫時消失**，肌肉弛緩
2. 表現：無法控制大小便(**尿瀦留**)、**腸蠕動降低、腹脹**、**肛門反射消失**；可持續數天到數週，反射回來後轉成痙攣性
3. 能不能自己呼吸看受傷高度：**C3–C5** 以上 → 膈神經受影響、無法自行呼吸；**胸腰段**(如 T12–L3)不影響呼吸
4. **T6 以上**(尤其頸髓)損傷會切斷交感神經的下行控制 → **神經性休克**：**心搏過慢、低血壓**、周邊血管擴張、皮膚溫暖；與失血的心搏過速不同，低血壓的鑑別見 [[hypotension]]
