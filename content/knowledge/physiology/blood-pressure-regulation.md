血壓是血液對血管壁的側壓力,「血壓」一般指**動脈壓**。身體要讓血壓維持在足以灌流腦、心、腎,又不至於傷害血管的範圍:**短期**(秒到分鐘)靠神經反射,**中長期**(小時到天)靠 RAAS、ADH、利鈉胜肽與腎臟調整血量。

每一段最後的「**藥物對應**」「**臨床對應**」說明哪一類降壓藥或疾病與這個機制有關。

## 血壓的決定因素 {#determinants}

**血壓(BP)= 心輸出量(CO)× 全身血管阻力(SVR)**,而 CO = 心跳速率 × 心搏量(見 [[cardiac-output#determinants]])。

| 因素 | 對血壓的影響 |
|---|---|
| 心輸出量 | CO↑ → 血壓↑(**不是**降低) |
| 血量 | 血量↓(失血、脫水)→ 血壓↓;輸液過快 → 血壓↑ |
| 周邊血管阻力 | 主要由**小動脈**決定(循環中阻力最大的血管段);阻力與**半徑的 4 次方成反比** |
| 血液黏稠度 | 血球比容↑(如 > 50%)→ 黏稠度與阻力↑ → 血壓↑ |
| 動脈彈性 | 彈性差(老化、動脈硬化)→ **收縮壓↑**、脈搏壓變寬 |

- **半徑的威力**:壓力不變時,血管半徑變為 2 倍,阻力變 1/16,血流量變 **16 倍**。所以小動脈稍微收縮或擴張就能大幅改變血壓——這也是降壓藥多以血管為目標的原因。
- 決定血流量的是「兩端壓力差 ÷ 阻力」;阻力由半徑、血管長度、黏稠度決定。人體血管長度幾乎固定,故「動脈長度」不列為調節血壓的因素;心跳速率對單一血管的血流速率影響最小。
- **收縮壓**主要反映心搏量與大動脈彈性;**舒張壓**主要反映**周邊血管阻力**。
- 血管內皮會分泌擴張血管的**一氧化氮(NO)、前列腺環素**(緩激肽也經由 NO 擴張血管),以及收縮血管的**內皮素-1(endothelin-1)**。
- 組織代謝增加時(CO₂、H⁺、腺苷、K⁺ 增加),局部小動脈與**微血管前括約肌舒張**、開放的微血管變多、血流增加(局部自動調節)。

**藥物對應**:所有降壓藥都在降低 CO 或 SVR——[[beta-blockers|β 阻斷劑]]降 CO;[[calcium-channel-blockers|CCB]]、[[alpha-blockers|α 阻斷劑]]、[[direct-vasodilators|直接血管擴張劑]]降 SVR;[[thiazide-diuretics|利尿劑]]先降血量、長期降 SVR;[[ace-inhibitors|ACEI]]/[[arb|ARB]] 兩者都降。

## 平均動脈壓與脈搏壓 {#map}

| 指標 | 公式 | 正常/目標 | 意義 |
|---|---|---|---|
| 脈搏壓(脈壓) | 收縮壓 − 舒張壓 | 約 40 mmHg(30–50) | 反映**心搏量與動脈管壁的彈性/張力** |
| **平均動脈壓 MAP** | **舒張壓 + 1/3 脈搏壓** = (收縮壓 + 2 × 舒張壓)÷ 3 | 約 70–105 mmHg;重症目標 **≥ 65 mmHg** | 一個心動週期中推動器官灌流的平均壓力 |

- 心動週期中舒張期較長,所以 MAP **較接近舒張壓**。公式要記成「1/3 收縮壓 + **2/3 舒張壓**」。
- **計算練習**:
  - 146/82 mmHg:脈搏壓 = 146 − 82 = **64**;MAP = 82 + 64/3 ≈ **103**。
  - 140/80 mmHg:MAP = 80 + 60/3 = **100**。
  - 收縮壓 120、脈搏壓 30 → 舒張壓 90 → MAP = 90 + 10 = **100**。
- 脈搏壓通常**小於**舒張壓;血壓由主動脈往小動脈逐漸下降,小動脈的壓力**明顯低於**主動脈,壓力降最大的就是小動脈段。
- **MAP ≥ 65 mmHg 的意義**:腦、腎、冠狀動脈的自動調節大約在 MAP 60–150 mmHg 之間有效;MAP 低於約 60–65 時,器官血流會隨血壓下降 → 尿量減少、意識改變、乳酸上升。Surviving Sepsis Campaign 2021 建議敗血性休克以 **MAP ≥ 65 mmHg** 為初始目標,低灌流時第一小時內給予晶體溶液 **30 mL/kg**(不是 40 mL/kg、也不是 MAP ≥ 60)。
- 心跳速率下降、心搏量減少、周邊阻力下降 → 三者同向 → MAP 下降。

**脈搏壓異常**:

| 變寬 | 變窄 |
|---|---|
| 主動脈瓣閉鎖不全(Corrigan 脈)、老化與動脈硬化、甲狀腺亢進、貧血、運動、**顱內壓上升**(Cushing 反射) | **心包膜填塞**、嚴重主動脈瓣狹窄、休克(心搏量小)、心衰竭 |

**臨床對應**:心包膜填塞的三個特徵是奇脈(吸氣時收縮壓下降 > 10 mmHg)、頸靜脈怒張、心音遙遠,且脈搏壓**變窄**;低血壓時動脈脈波振幅與傳導速度都下降。見 [[hypotension]]。

## 短期調控:神經反射 {#short-term}

### 壓力感受器反射 {#baroreceptor}

1. **感受器**:位於**頸動脈竇**(頸總動脈分叉處)與**主動脈弓**的牽張感受器,感受血管壁被撐開的程度。
2. **傳入神經**:頸動脈竇 → **舌咽神經(CN IX)**;主動脈弓 → **迷走神經(CN X)**。
3. **整合中樞**:**延腦**的心血管中樞(血管運動中樞);不是下視丘或大腦。
4. **反應**(以血壓上升為例):感受器放電↑ → 迷走神經(副交感)↑、交感↓ → 心跳變慢、收縮力下降、小動脈與靜脈擴張 → 血壓回降。血壓下降時則相反:交感↑ → 心跳快、血管收縮、腎素分泌↑。

- 反射在數秒內作用,負責**起身時**、失血初期、Valsalva 等的即時調整;持續數天的高血壓會讓壓力感受器「重設」,所以它**無法**長期決定血壓。
- **姿位性低血壓**:平躺改站立,約 500–700 mL 血液滯留下肢 → 回心血量與 CO 下降 → 壓力感受器反射不足時頭暈、跌倒。老人、脫水、使用 [[alpha-blockers|α 阻斷劑]]、[[nitrates|NTG]]、利尿劑者風險高。
- **頸動脈竇按摩**、Valsalva 可以增強迷走作用,用來終止陣發性心室上心搏過速(PSVT)。

**藥物對應**:[[alpha-blockers|α1 阻斷劑]]首次劑量常引起姿位性低血壓(first-dose effect),宜睡前服用;[[central-alpha2-agonists|中樞 α2 促效劑]]作用於延腦,降低交感輸出。

### 化學感受器與中樞缺血反應 {#chemoreceptor}

- **周邊化學感受器**:頸動脈體、主動脈體,感受**低血氧、高碳酸、酸中毒** → 主要刺激呼吸,也經延腦增加交感 → 血管收縮、血壓上升(血壓降到約 80 mmHg 以下時更明顯)。
- **中樞缺血反應**:腦部血流嚴重不足時,延腦直接強烈興奮交感,是最後的防線。
- **Cushing 反射**:顱內壓上升壓迫腦部 → 血壓上升、脈搏壓變寬、心搏過緩、呼吸不規則。

**臨床對應**:休克的代償由**交感神經**(腎上腺素、正腎上腺素)啟動:心跳加快、皮膚與內臟血管收縮(四肢冰冷)、腎血流下降、呼吸加快加深;腸胃蠕動**減少**,不會增加。副交感神經不分泌腎上腺素。

## 中長期調控:激素與腎臟 {#long-term}

### 腎素-血管張力素-醛固酮系統 {#raas}

1. **血管張力素原**(angiotensinogen):由**肝臟**製造,持續存在血漿中。
2. **腎素**(renin):由腎臟入球小動脈的**近腎絲球細胞**分泌。刺激因素:
   - 腎灌流壓下降(低血壓、失血、脫水、休克、腎動脈狹窄)
   - 交感神經經 **β1 受體**刺激
   - **緻密斑**偵測到遠曲小管的 NaCl 減少
3. 腎素把血管張力素原切成**血管張力素 I**(幾乎無活性)。
4. **血管張力素轉換酶(ACE)**(主要在**肺微血管內皮**)把 Ang I 轉成**血管張力素 II**;ACE 同時負責**分解緩激肽**。
5. **Ang II** 經 **AT1 受體**:
   - 強力收縮小動脈 → SVR↑
   - 刺激**腎上腺皮質(球狀帶)分泌醛固酮** → 集尿管與遠曲小管**保鈉保水、排鉀(與 H⁺)**
   - 刺激 ADH 分泌與口渴
   - 增強交感活性;出球小動脈收縮以維持腎絲球過濾率
   - 長期促進心肌肥厚、纖維化與血管重塑
6. 血壓與血量恢復後,腎素分泌減少(負回饋)。

- 失血、缺水 → 腎素、Ang II、醛固酮**都增加**;休克代償時腎素**上升**。
- 腎素本身是酵素,**不直接**作用於血管平滑肌。
- **原發性醛固酮過多症**(Conn 氏症候群):醛固酮自主過量 → 高血壓、**低血鉀**、代謝性鹼中毒;血鈉正常或略高、血容量增加。

**藥物對應**:見下方 [[blood-pressure-regulation#drug-sites]]。ACEI 抑制 Ang I → Ang II,Ang II 與醛固酮都**減少**,並使緩激肽**累積**(乾咳、血管性水腫),保鉀而可能**高血鉀**(不會低血鉀);ARB(losartan 等 -sartan)阻斷 AT1 受體,屬「血管張力素 II 受體拮抗劑」;**Aliskiren** 直接抑制腎素;MRA 阻斷醛固酮受體。

### 抗利尿激素 {#adh}

- **合成**:**下視丘視上核**(與室旁核)的神經元;經**下視丘-垂體徑**(神經軸突)運送,儲存並由**腦下垂體後葉釋放**(後葉只負責儲存釋放,不是合成)。
- **刺激分泌**:血漿**滲透壓上升**(最敏感,約 1–2% 的變化即可;同時產生口渴)、血量或血壓明顯下降、Ang II、疼痛、壓力、噁心、手術。
- **作用**:
  - V2 受體:使**集尿管**插入水通道蛋白(aquaporin-2)→ **增加集尿管對水的通透性**,是直接調控集尿管水再吸收最強的激素(不是作用在近曲小管)。
  - V1 受體:**收縮血管平滑肌**(因此又名**血管加壓素 vasopressin**);大劑量會使血壓上升,不是下降。
- 口渴時身體是**增加** ADH、增加水通道蛋白來保水。
- 參考:沒有 ADH 時,近曲小管仍負責約 65% 的鈉與水再吸收(等張回收)。

**臨床對應**:ADH 過多 → **SIADH**(低血鈉、低血漿滲透壓、尿量少、尿比重**高**;限水,嚴重時高張食鹽水);ADH 不足 → **中樞性尿崩症**(尿多、尿比重 < 1.005、高血鈉;每小時監測輸出入量與尿比重)。產痛、手術等壓力會增加 ADH。Vasopressin 也用於敗血性休克的升壓。

### 利鈉胜肽 {#natriuretic-peptides}

| | ANP(心房利鈉胜肽) | BNP(B 型利鈉胜肽) |
|---|---|---|
| 分泌來源 | **心房**肌細胞,心房被撐大時 | 主要由**心室**肌細胞,心室壁張力增加時(以 proBNP 形式分泌,切成 BNP 與 NT-proBNP) |
| 作用 | 排鈉利尿、擴張血管、**抑制腎素、醛固酮與 ADH**、降低交感張力 → **降低前後負荷** | 同左 |

- 利鈉胜肽是 RAAS 的**對抗系統**。**心衰竭**時心房與心室壓力上升 → ANP、BNP **分泌增加**(不是被抑制),但作用被強大的 RAAS 與交感壓過。
- 心衰竭時腎臟灌流不足 → **鈉離子再吸收增加**、水分跟著進入血液 → 水腫(代償的副作用)。
- 利鈉胜肽由 **neprilysin(腦啡肽酶)**分解。

**藥物對應**:[[arni|ARNI]](sacubitril/valsartan)中的 sacubitril 抑制 neprilysin,讓自身利鈉胜肽作用更久,valsartan 則阻斷 AT1。服用 ARNI 後 **BNP 會上升**(neprilysin 被抑制),追蹤心衰竭宜看 NT-proBNP(見 [[bnp]])。
**臨床對應**:BNP 用來診斷與追蹤 [[heart-failure]],BNP > 100 pg/mL 支持心衰竭;BNP 不是心肌壞死指標。

### 腎臟的壓力-利尿機制 {#pressure-natriuresis}

- 動脈壓上升 → 腎臟排出更多鈉與水(**壓力利尿、壓力排鈉**)→ 血量減少 → 血壓回到原點;血壓下降時則保留鈉水。
- 只要腎臟功能與鹽分攝取不變,這個機制可以在數天內把血壓拉回同一個設定點,**力量沒有上限**,因此長期血壓主要由腎臟決定(Guyton 模型)。
- 高血壓的本質可以理解成「腎臟需要更高的壓力才能排出同樣的鈉」——慢性腎臟病、高鹽飲食、RAAS 過度活化都會把設定點往上推。

**藥物對應**:[[thiazide-diuretics|Thiazide]] 與 [[loop-diuretics|Loop 利尿劑]]直接增加排鈉;限鈉飲食(每日鈉 < 2 g)同樣作用在這個機制。
**臨床對應**:[[hypertension]]、慢性腎臟病。

## 自主神經受體與血壓 {#autonomic-receptors}

| 受體 | 主要位置 | 活化時 | 對血壓 | 相關藥物 |
|---|---|---|---|---|
| **α1** | 皮膚、腹腔內臟等小動脈與靜脈平滑肌 | **血管收縮** | SVR↑ → 血壓↑ | 促效:phenylephrine、norepinephrine;阻斷:prazosin 等 [[alpha-blockers]] |
| α2(中樞、突觸前) | 延腦、交感神經末梢 | 抑制正腎上腺素釋放 → 交感輸出↓ | 血壓↓ | 促效:clonidine、methyldopa([[central-alpha2-agonists]]) |
| **β1** | 心臟;腎臟近腎絲球細胞 | 心跳、收縮力、傳導↑;**腎素分泌↑** | CO↑ → 血壓↑ | 促效:dobutamine;阻斷:[[beta-blockers]] |
| β2 | 骨骼肌小動脈、支氣管、子宮 | 血管擴張、支氣管擴張 | 輕度 SVR↓ | 非選擇性 β 阻斷劑會阻斷 → 氣喘禁用 |
| M(蕈毒鹼型) | 竇房結、房室結 | 心跳↓ | 血壓↓ | atropine 阻斷 → 心跳↑ |
| D1 | 腎臟、腸繫膜血管 | 血管擴張 | — | 低劑量 dopamine |

- 使皮膚及腹腔內臟血管收縮的是 **α 型**腎上腺素受體。
- 低血壓的處置:**α1 促效劑**增加 SVR;**β1 促效劑**(不是拮抗劑)增加心跳與 CO;中劑量 dopamine 以 β1 為主增加 CO,高劑量出現 α1 作用增加 SVR;抬高下肢增加前負荷。
- Carvedilol、labetalol 同時阻斷 **α1 與 β** 受體。

**藥物對應**:[[beta-blockers]]、[[alpha-blockers]]、[[central-alpha2-agonists]]、[[inotropes]]。

| [[arni\|ARNI]] | AT1 受體 + neprilysin | ARB + 利鈉胜肽作用增強 |
| [[potassium-sparing-diuretics\|MRA]](spironolactone、eplerenone) | 集尿管醛固酮受體 | 排鈉保鉀;eplerenone 選擇性高,不影響雄性素作用,少男性女乳 |
| [[thiazide-diuretics\|Thiazide]]、[[loop-diuretics\|Loop]] | 遠曲小管、亨利氏環上行枝 | 排鈉利尿 → 血量↓;thiazide 長期還會使血管阻力下降 |
| [[calcium-channel-blockers\|CCB]] | 血管平滑肌 L 型鈣通道 | 小動脈擴張 → SVR↓ |
| [[direct-vasodilators\|直接血管擴張劑]](hydralazine、minoxidil、nitroprusside) | 血管平滑肌 | SVR↓(反射性心搏過速、鈉水滯留) |
| [[alpha-blockers\|α1 阻斷劑]](-zosin) | 血管 α1 受體 | SVR↓ |
| [[central-alpha2-agonists\|中樞 α2 促效劑]](clonidine、methyldopa) | 延腦 α2 受體 | 交感輸出↓ |

:::exam[國考重點]
- **血壓 = CO × SVR**;舒張壓主要由**周邊血管阻力**決定;阻力最大在**小動脈**,與半徑 4 次方成反比。
- **MAP = 舒張壓 + 1/3 脈搏壓**,較接近舒張壓;敗血性休克目標 **MAP ≥ 65**。
- 壓力感受器:頸動脈竇(**舌咽神經**)、主動脈弓(迷走神經)→ **延腦**。
- 血管張力素原來自**肝臟**;腎素來自近腎絲球細胞;ACE 主要在肺。
- 醛固酮保鈉排鉀 → 醛固酮過多**低血鉀**;ACEI/ARB/MRA → **高血鉀**。
- ADH 由**下視丘視上核合成**、垂體後葉釋放,作用在**集尿管**,也收縮血管。
- 使動脈壓上升:Ang II↑;使血壓下降:醛固酮↓、ANP↑、鹽水保留↓。
:::

## 影響血壓的生理因素 {#physiologic-factors}

| 因素 | 影響 |
|---|---|
| **年齡** | 動脈彈性隨年齡下降 → **收縮壓上升**、脈搏壓變寬(不是變低);兒童血壓較低 |
| **晝夜** | 睡眠時最低,清晨起床後快速上升(晨間高峰,心血管事件好發於早晨),傍晚較高 |
| **姿勢** | 平躺、坐、站之間差異通常不大;由臥突然站起會暫時下降(姿位性低血壓)。測量時固定姿勢與手臂高度(與心臟同高) |
| **運動** | 運動當下收縮壓上升;**規律有氧運動**長期可降血壓並提高 HDL。**等長運動**(舉重、用力閉氣)使血壓陡升,高血壓與心臟病人應避免 |
| **情緒與疼痛** | 焦慮、生氣、疼痛、壓力 → 交感↑ → 血壓上升 |
| **性別** | 停經前女性血壓通常低於同齡男性,停經後差距縮小 |
| **溫度** | 寒冷 → 血管收縮 → 血壓上升;泡溫泉、熱水浴 → 周邊血管擴張 → 血壓下降、頭部血流減少而頭暈 |
| 其他 | **膀胱脹滿**、用力排便(Valsalva 後反彈)、**顱內壓上升** → 血壓上升;抽菸(尼古丁)→ 血管收縮、血壓上升;肥胖、高鹽 → 血壓上升 |
| 藥物與物質 | **鎮靜劑、麻醉止痛劑**擴張血管 → 血壓下降;類固醇 → 鈉水滯留、血壓上升;**酒精**:飲用當下擴張血管使血壓下降(國考「喝紅酒使血壓下降」),但長期大量飲酒反而使血壓上升,是高血壓危險因子 |
| 疾病狀態 | 過敏性休克:組織胺使**小動脈擴張**、微血管通透性增加 → 血壓下降;組織胺是血管擴張物質,不會使血壓上升 |

**臨床對應**:高血壓病人要避免體表溫差過大、用力排便;泡熱水澡頭暈時協助身體前傾、頭部低於心臟。見 [[hypertension]]、[[hypotension]]。
