**補體**是血漿中約 60 種蛋白質(多數由肝臟製造)組成的系統，名字來自「**補充**抗體的作用」。它平常不活化，遇到病原才像骨牌一樣**一個切開下一個**，最後把病原標記起來、引起發炎，甚至直接溶解

## 重點摘要 {#summary}

- 三條活化路徑啟動的方式不同，但都匯集到**大量 C3b 沉積**與**膜攻擊複合體**(MAC，**C5b-9**)
- **古典**路徑由抗原抗體複合物(**IgM、IgG1、IgG3**)啟動；**凝集素**路徑由 MBL 或 ficolin 辨識病原糖類；**替代**路徑靠 C3 自發水解，**不需要抗體**，是**最早**的反應
- 四大功能：**調理**(C3b)、**發炎**(C3a、C5a 過敏毒素)、**趨化**(C5a)、**溶解**(MAC)；另外清除免疫複合物與凋亡細胞
- 缺乏**早期**古典成分(C1q、C4、C2) → **SLE**；缺乏 **C3** → 嚴重細菌感染；缺乏 **C5 到 C9** → **奈瑟氏菌**感染；缺乏 **C1 抑制劑** → 遺傳性血管性水腫
- 免疫複合物疾病(SLE、急性腎絲球腎炎)的血清 **C3、C4 會下降**，不是上升

### 國考常考點 {#exam-points}

- 感染時**最早**活化的是**替代路徑**；古典路徑需要**抗體**(以 **IgM** 最有效，IgG 也可以)；抗體是透過**古典**路徑活化補體，**不是**替代路徑
- **MAC = C5b-9**(不含 C1、C3、C5a)；較容易被 MAC 殺死的是**奈瑟氏菌**(革蘭氏陰性菌)，B 肝病毒、葡萄球菌、鏈球菌較不受影響
- **C3b** 的主要功能是**調理**(促進吞噬細胞辨識)；**C5a** 能**趨化並活化吞噬細胞**；**C3a** 促使肥大細胞釋出組織胺
- 巨噬細胞殺菌的方式有抗體幫助吞噬、一氧化氮、TNF-α，**沒有**形成 MAC
- 補體**對熱不穩定**：血清加熱 **56℃ 30 分鐘**會破壞補體活性
- **急性鏈球菌感染後腎絲球腎炎**：免疫複合物與補體沉積，血清 **C3(與 C4)下降**；**SLE** 活動期 C3、C4 下降，**ANA 陽性**
- 內毒素**可活化補體**，也會引起高燒；不是抑制發炎

## 補體做什麼 {#functions}

| 功能 | 片段 | 說明 |
|---|---|---|
| **調理作用** | **C3b**(進一步成為 iC3b、C3d) | 大量 C3b 共價附著在病原表面，吞噬細胞靠 **C3 受體**(CR1、CR3)辨識並吞入；稱**免疫黏附** |
| **發炎** | **C3a、C4a、C5a**(過敏毒素) | 小片段被釋放，作用在肥大細胞與嗜鹼性球使其**釋出組織胺**，造成**血管擴張、通透性增加、平滑肌收縮**；**C5a 最強** |
| **趨化與活化** | **C5a** | 吸引**嗜中性球與單核球**到感染處，並活化它們 |
| **溶解** | **MAC(C5b-9)** | 在細胞膜上打洞，使細胞滲透壓溶解 |
| 清除免疫複合物 | C3b、C4b | 附著在免疫複合物上，由**紅血球上的 CR1** 運到肝與脾，被巨噬細胞清除；缺乏時免疫複合物堆積(像 SLE) |
| 清除凋亡細胞 | C1q 等 | 凋亡與壞死細胞表面會讓補體附著，促進被清除；缺乏時容易自體免疫 |
| 協助 B 細胞反應 | C3d | 附在抗原上，經 B 細胞的 CR2 給額外的活化訊號，等於天然佐劑 |

- 命名規則(2019 年更新版)：補體成分用 **C + 數字**(C1 到 C9)，替代路徑的成分叫**因子**(因子 B、因子 D)；活化時被切開，**小片段(a)被釋放**，**大片段(b)附著在標的**繼續反應
- 轉化酶的舊寫法：C3 轉化酶舊書寫成 **C4b2a**，新版寫成 **C4b2b**；考試或課本兩種寫法都可能出現，指的是同一個東西

## 三條活化路徑 {#pathways}

![補體三條活化路徑與共同的終末路徑](/knowledge-images/complement-pathways.svg)

### 路徑比較 {#pathway-comparison}

| 項目 | 古典路徑 | 凝集素路徑 | 替代路徑 |
|---|---|---|---|
| 啟動 | 抗原抗體複合物；也可由 CRP、凋亡細胞啟動 | 病原表面的糖類(甘露糖、N-乙醯葡萄糖胺、岩藻糖) | C3 持續微量自發水解；病原、受損細胞表面 |
| 需要抗體 | **是**(IgM、IgG1、IgG3) | 否 | 否 |
| 辨識分子 | **C1q**(C1 複合體：C1q、C1r、C1s) | **MBL**、ficolin、collectin | C3(H2O)、**因子 B**、**因子 D**、properdin |
| 蛋白酶 | C1r、C1s | MASP-1、MASP-2 | 因子 D |
| 被切開的成分 | C4 與 C2 | C4 與 C2 | 因子 B |
| C3 轉化酶 | **C4b2b** | **C4b2b** | **C3bBb**(properdin 穩定) |
| C5 轉化酶 | C4b2b3b | C4b2b3b | C3bBb3b |
| 性質 | 特異性免疫的效應機制 | 先天，早期警報 | 先天，**最古老**，也是放大迴路 |

### 古典路徑 {#classical-pathway}

1. **啟動**：C1q 結合在抗體的 **Fc 區**
   1. **IgM** 與 **IgG1、IgG3** 能有效活化；IgG2 較弱；**IgG4、IgD、IgE 不能**活化古典路徑
   2. **IgM** 是五聚體，一個分子就足以讓 C1q 結合；IgG 需要兩個以上相鄰
   3. 沒有抗體時，**C 反應蛋白(CRP)**也能結合 C1q
2. **放大**：C1r 自我活化，切開 C1s；C1s 切開 **C4** 與 **C2**
   1. **C4b** 以共價鍵附著在標的表面，再捕捉 **C2b**，形成 **C3 轉化酶(C4b2b)**
   2. C3 轉化酶把大量 **C3** 切成 C3a(釋出)與 **C3b**(附著)
   3. C3b 再結合 C3 轉化酶，成為 **C5 轉化酶(C4b2b3b)**
3. **攻擊**：C5 轉化酶切開 C5，之後進入共同的終末路徑

### 凝集素路徑 {#lectin-pathway}

- 和古典路徑**很像**，只是凝集素取代抗體、病原糖類取代抗原、**MASP 取代 C1r 與 C1s**
- **MBL**(甘露糖結合凝集素)是肝臟製造的**急性期反應物**，辨識細菌、真菌與部分病毒表面的糖，**不會**結合宿主細胞末端的半乳糖與唾液酸，所以能分辨自己與外來
- MASP-2 切開 C4 與 C2，之後的 C3 轉化酶、C5 轉化酶與 MAC 都和古典路徑**相同**
- MBL 缺乏可能和兒童反覆(多半輕微)感染有關，但證據有爭議

### 替代路徑 {#alternative-pathway}

1. **啟動(tickover)**：血中的 C3 有不穩定的硫酯鍵，**持續自發水解**成 C3(H2O)
   1. 速率約每小時 1%，**不需要抗體或事先接觸病原**
2. **形成轉化酶**：C3b(或 C3(H2O))結合**因子 B**，**因子 D** 把 B 切成 Ba(釋出)與 **Bb**，形成 **C3bBb**；**properdin(備解素)**穩定這個複合物
3. **選擇性放大**：在**宿主正常細胞**上，C3b 很快被調控蛋白失活；在**病原、受損細胞或缺乏調控蛋白**的表面則被**放大迴路**(越多 C3b → 越多 C3bBb → 越多 C3b)大量沉積
4. 另一個 C3b 結合 C3bBb，成為 **C5 轉化酶(C3bBb3b)**，進入終末路徑
5. **放大迴路也服務其他路徑**：古典或凝集素路徑先放上的 C3b，可以被替代路徑放大，很多 C3b 其實由這個迴路貢獻
6. 因為不需要抗體，**感染初期最早**由替代路徑與凝集素路徑起反應；**properdin** 是唯一的正向調控蛋白，基因在 **X 染色體**

:::basics[為什麼 C3 和 C4 要靠「硫酯鍵」黏在標的上？]
C3 與 C4 分子裡有一個很容易起反應的硫酯鍵。被切開成 C3b 或 C4b 的瞬間，這個鍵暴露出來，只有**幾微秒**的時間可以與附近的標的共價結合，來不及的就被水解失去作用。因此補體反應只會留在**活化的表面附近**，不會到處亂黏(這也是補體在血漿中的液相活化不太有效的原因)

來源：UpToDate：Complement pathways
:::

### 終末路徑與膜攻擊複合體 {#terminal-pathway}

1. **C5 轉化酶**切開 **C5**
   1. **C5a**：強力的過敏毒素與趨化因子
   2. **C5b**：附著後開始組裝 MAC
2. **組裝**：C5b 依序結合 **C6、C7、C8**，再聚合**多個 C9**
   1. **C7** 讓複合物變親脂，才能**插入細胞膜**
   2. C5b-8 已有一些溶解力，加上 **C9** 才有效率
3. **結果**：形成**穿膜孔洞**，細胞膜失去完整性，因滲透壓而**溶解**
4. **MAC = C5b、C6、C7、C8、C9**(**C5b-9**)，不含 C1、C3、C5a
5. **誰容易被溶解**
   1. **革蘭氏陰性菌**，特別是**奈瑟氏菌**(腦膜炎雙球菌、淋病雙球菌)
   2. **革蘭氏陽性菌**有厚的胜肽聚醣細胞壁，MAC 不容易接觸到細胞膜，主要靠 C3b 調理後被吞噬
   3. 缺乏 C5 到 C9 的人，最特別的問題就是**反覆奈瑟氏菌感染**
6. 同類型的「打洞」機制：細胞毒殺性 T 細胞與 NK 細胞的**穿孔素**

## 補體怎麼被控制 {#regulation}

補體很強，所以**近一半的補體蛋白其實是調控蛋白**，目的是不傷到宿主細胞(附近無辜的細胞)，也不讓補體在血漿中空轉。調控發生在三個關鍵步驟：啟動、放大(轉化酶)、攻擊(MAC)

| 調控蛋白 | 位置 | 作用 | 缺乏時 |
|---|---|---|---|
| **C1 抑制劑**(C1-INH) | 血漿 | 抑制 C1r、C1s 與 MASP；也抑制凝血與**激肽**系統 | **遺傳性血管性水腫** |
| C4 結合蛋白(C4BP) | 血漿 | 加速 C4b2b 衰變，當輔因子 | — |
| **因子 H**、**因子 I** | 血漿 | 抑制替代路徑：使 C3bBb 解離、因子 I 切開 C3b | 補體耗盡、反覆化膿菌感染；異合子缺陷與非典型溶血尿毒症候群、老年黃斑部病變有關 |
| **DAF(CD55)** | 細胞膜 | 加速 C3 與 C5 轉化酶衰變 | **陣發性夜間血紅素尿症(PNH)** |
| **MCP(CD46)** | 細胞膜 | 輔因子，協助因子 I 切開 C3b、C4b | 非典型溶血尿毒症候群 |
| **CD59**(protectin) | 細胞膜 | 擋住 C8 與 C9，**阻止 MAC 組裝** | **PNH** |
| S 蛋白(vitronectin) | 血漿 | 抑制液相的 MAC | — |
| 羧肽酶 N | 血漿 | 切掉過敏毒素的 C 端精胺酸，使 C3a、C5a 失活 | — |

- 調控的三種方式：**阻止轉化酶形成**、讓轉化酶**解離**(衰變加速作用)、**蛋白質水解**切開 C3b 與 C4b(輔因子作用，由因子 I 執行)
- 宿主細胞表面有 DAF、MCP、CD59 保護，病原通常沒有，所以補體只傷害病原

### 遺傳性血管性水腫 {#hereditary-angioedema}

1. **原因**：**C1 抑制劑**缺乏或功能不良(**體染色體顯性**)
2. **機轉**：C1 抑制劑不夠 → C1 在血漿中過度切開 C4 與 C2，且**激肽系統失控**，產生過量**緩激肽** → 血管通透性增加
3. **表現**：發作性、**非搔癢**的皮膚黏膜腫脹，常見臉、四肢、腸道(劇烈腹痛)，**喉頭水腫**可致命；**沒有蕁麻疹**
4. **檢驗**：**C4 偏低而 C3 正常**；進一步測 C1 抑制劑的量與功能
5. **處置**：因為是緩激肽造成，**抗組織胺、類固醇與腎上腺素通常無效**；急性發作用 **C1 抑制劑濃縮液**、**icatibant**(緩激肽 B2 受體拮抗劑)等
6. 之後在蕁麻疹與血管性水腫頁整理其他類型

### 陣發性夜間血紅素尿症 {#pnh}

- **PIGA 基因**的後天體細胞突變，使血球缺乏 **GPI 錨定蛋白**，包括 **CD55 與 CD59** → 紅血球失去補體保護，被補體**血管內溶血**
- 表現：溶血性貧血、血紅素尿、血栓
- 治療：**抗 C5 單株抗體**(eculizumab、ravulizumab)
- 抗 C5 治療會增加**腦膜炎雙球菌**侵襲性感染的風險(仿單有加框警語)，因此治療前要**接種腦膜炎雙球菌疫苗**，而且即使接種過仍要留意發燒、頸部僵硬等感染徵象

## 補體缺乏症 {#deficiencies}

**口訣**：缺乏**早期古典成分**(C1q、C1r/s、C4、C2) → **自體免疫(SLE)**；缺乏 **C3** → **嚴重化膿菌感染**；缺乏**終末成分**(C5 到 C9) → **奈瑟氏菌**

| 缺乏 | 主要表現 |
|---|---|
| **C1q、C1r/s、C4、C2** | **SLE**(C1q 完全缺乏 90% 以上會得 SLE；C4 完全缺乏約 80%)，也可有反覆細菌感染；**C2 缺乏最常見**(白人約兩萬分之一)；**部分 C4A 缺乏**很常見，與 HLA-B8、DR3 單倍型和 SLE 有關 |
| **C3** | 出生後不久就出現**嚴重反覆的有莢膜細菌**感染(肺炎鏈球菌為主，也有 Hib、腦膜炎雙球菌)；存活者容易有免疫複合物**腎絲球腎炎** |
| **C5、C6、C7、C8、C9** | **奈瑟氏菌**(尤其腦膜炎雙球菌)反覆感染，多半輕到中度；**C9 缺乏**常見於日本與韓國人，症狀較輕 |
| 因子 B、因子 D、**properdin** | 奈瑟氏菌與肺炎鏈球菌嚴重感染；**properdin 缺乏是 X 染色體隱性**，患者是**男性**，家族中有腦膜炎雙球菌感染的男孩要想到 |
| MBL、MASP-2、ficolin-3 | 兒童反覆感染(關聯有爭議) |
| **C1 抑制劑** | 遺傳性血管性水腫 |
| 因子 H、因子 I、MCP | 非典型溶血尿毒症候群、C3 腎絲球病、老年黃斑部病變 |
| **CD55、CD59** | PNH |
| **CR3**(CD11b/CD18) | **白血球黏附缺陷**：臍帶延遲脫落、臍炎、嚴重反覆細菌感染 |

### 補體缺乏者的照護 {#deficiency-care}

1. **疫苗**：可接種所有常規疫苗(包括活性減毒疫苗)；特別要有**腦膜炎雙球菌、肺炎鏈球菌、Hib** 疫苗，優先選**結合型**疫苗([[immunization]])
2. **警覺**：發燒、頸部僵硬、劇烈頭痛、**瘀斑或紫斑**要立刻就醫，建議隨身攜帶病情識別卡
3. **抗生素預防**：依感染的頻率與嚴重度個別決定
4. **補充**：多半不長期輸血漿，感染時也通常用標準抗生素即可

## 補體的檢驗與判讀 {#tests}

### 常用檢驗 {#test-types}

| 檢驗 | 測什麼 | 重點 |
|---|---|---|
| **CH50**(總溶血性補體) | **古典路徑**整體功能，需要 **C1 到 C9 全部**成分才正常 | 正常約 150–250 單位/mL；**完全缺乏任一成分幾乎測不到**(C9 缺乏例外，仍測得到)；用來篩檢缺乏症 |
| **AH50** | **替代路徑**整體功能 | CH50 與 AH50 **都低**：C3 或 C5–C9 缺乏；**只有 AH50 低**：因子 B、D 或 properdin 缺乏 |
| **C3、C4** 濃度 | 抗原量(免疫比濁法) | 一般參考：C3 約 80–160 mg/dL、C4 約 16–48 mg/dL；各實驗室不同，以報告為準 |

- **檢體處理**：補體不穩定，抽血後要**當天檢驗或立刻冷凍**，放在室溫數小時會下降，造成**假性偏低**
- **「冷活化」**：有冷球蛋白等免疫複合物時，CH50 可以假性很低(甚至零)，但 C3、C4 濃度只輕度下降
- 補體屬於**急性期反應物**，發炎或感染時最多可比基準值增加約 50%，**升高本身沒有特別的臨床意義**
- 新生兒補體偏低，約在 **6 到 18 個月**達到成人濃度

### C3、C4 下降的意義 {#c3-c4}

| 型態 | 代表什麼 | 常見疾病 |
|---|---|---|
| **C3、C4 都下降**(CH50 下降) | **古典路徑活化**：免疫複合物消耗補體 | **SLE 活動期**(尤其狼瘡腎炎)、**急性鏈球菌感染後腎絲球腎炎**、冷球蛋白血症、血清病 |
| **C4 下降、C3 正常** | 古典路徑的部分活化，或 C4 本身缺乏 | **遺傳性血管性水腫**、部分 SLE、冷球蛋白血症、C4 部分缺乏 |
| **C3 下降、C4 正常** | **替代路徑活化** | **膜增生性腎絲球腎炎、C3 腎絲球病**(C3 腎炎因子)、非典型溶血尿毒症候群的一部分 |
| 升高 | 急性期反應 | 感染、發炎，沒有特殊意義 |

1. 為什麼 C4 低而 C3 正常也常見？血漿中 C3 的基礎濃度是 C4 的 3 到 6 倍，所以消耗後 C4 先掉出正常範圍；另外在血漿中的可溶性免疫複合物上形成 C3 轉化酶的效率低
2. 追蹤：SLE 治療有效時，C3 與 C4 會回升到正常，是**好的預後徵象**；但**部分 C4 缺乏的人 C4 會一直偏低**，不一定代表疾病還在活動
3. **免疫複合物疾病(SLE、急性腎絲球腎炎)的 C3、C4 是下降，不會上升**，這是國考常見陷阱

:::note[題目陷阱：急性腎絲球腎炎的補體]
「急性腎絲球腎炎的 C3 與 C4 值會**上升**」是**錯誤**的敘述：抗原抗體複合物沉積在腎絲球並**消耗補體**，血清 C3 下降(通常 C3 下降較明顯)。常見題型：110-2 病理 061、107-1 藥理 064。急性腎絲球腎炎與鏈球菌的關係見 [[streptococci]]
:::

## 補體與臨床 {#clinical}

- **溶血性輸血反應**：ABO 不合時受血者的 **IgM、IgG** 抗體結合紅血球並**活化補體** → 血管內溶血(第二型過敏反應；之後在輸血反應頁整理)
- **超急性排斥**：受贈者原有的抗體加上補體攻擊移植器官血管([[immunosuppressants#rejection]])
- **血清病、SLE、急性腎絲球腎炎**：第三型過敏反應，免疫複合物活化補體造成組織傷害(之後在過敏反應頁整理)
- **內毒素**可以活化補體(與細菌感染時的發炎與敗血症有關，[[sepsis#mechanism]])
- **補體抑制藥物**：anti-C5 抗體(eculizumab、ravulizumab)用於 PNH、非典型溶血尿毒症候群、重症肌無力等；C5a 受體拮抗劑 avacopan 用於 ANCA 相關血管炎；使用抗 C5 都要注意腦膜炎雙球菌感染

:::basics[補體受體：吞噬細胞怎麼「看見」C3b？]
補體片段要有相對應的受體才能作用

| 受體 | 辨識 | 表現的細胞與功能 |
|---|---|---|
| **CR1(CD35)** | C3b、C4b | **紅血球**(運送免疫複合物到肝脾)、吞噬細胞、B 細胞；是免疫黏附受體 |
| **CR2(CD21)** | C3d | **B 細胞**的共受體；也是 **EB 病毒**的受體 |
| **CR3(CD11b/CD18)**、CR4 | iC3b | 巨噬細胞、嗜中性球；促進吞入；缺乏即**白血球黏附缺陷** |
| C3aR、C5aR | C3a、C5a | 許多細胞，啟動**發炎反應**與趨化；肥大細胞與嗜鹼性球經它們脫顆粒 |

:::
