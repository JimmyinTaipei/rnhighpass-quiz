骨骼系統由骨、軟骨、韌帶與關節組成，負責支持、保護、運動槓桿、造血與儲存鈣磷。本頁整理骨組織與骨細胞、骨化與生長、顱骨、脊柱、胸廓、上下肢骨與骨盆、關節的分類與構造；肌肉見 [[muscular-system]]，骨折與癒合見 [[fractures]]，骨質疏鬆症見 [[osteoporosis]]，全關節運動的動作名稱見 [[activity-immobility#rom-joints]]

## 重點摘要 {#summary}

- 骨骼功能：**支持、保護**(顱骨護腦、胸廓護心肺)、**運動**(肌肉附著的槓桿)、**造血**(紅骨髓)、**儲存礦物質**(體內約 **99% 的鈣、90% 的磷**在骨骼，《內外科護理學》下冊 p.511)
- 骨組織兩型：外層**緻密骨**(由**骨單位**組成，中央是**哈氏管**)；內層**海綿骨**(由**骨小樑**交織，空隙中有紅骨髓)
- 骨細胞三種：**造骨細胞**(製造骨基質)、**骨細胞**(成熟、住在骨陷窩)、**蝕骨細胞**(分解骨質，單核球系來源的多核細胞)
- 長骨縱向生長靠**骨骺板**(生長板，透明軟骨)；青春期後骨化成**骨骺線**，就不再長高；骨增粗靠**骨膜**的造骨細胞
- 顱骨＝**8 塊腦顱骨**(額 1、頂 2、顳 2、枕 1、蝶 1、篩 1)＋**14 塊顏面骨**；**副鼻竇在額骨、篩骨、蝶骨、上頜骨**
- 脊柱：頸椎 7、胸椎 12、腰椎 5、薦椎 1(5 塊癒合)、尾椎 1；**頸曲與腰曲向前凸**、胸曲與薦曲向後凸
- 肋骨 12 對：**第 1–7 對真肋**、第 8–12 對假肋(其中 11、12 是浮肋)
- 骨盆：**髖骨＝髂骨＋坐骨＋恥骨**；坐時承重在**坐骨粗隆**；骨髓抽吸取**髂嵴**(後髂嵴)
- 關節：**纖維關節**(顱縫)、**軟骨關節**(恥骨聯合、椎間盤)、**滑液關節**(活動度最大)

### 國考常考點 {#exam-points}

- **骨小樑**是**海綿骨**的構造；骨單位、中央管(哈氏管)、穿通管(伏克曼氏管)是**緻密骨**的構造
- 青春期長骨**縱向生長**最重要的是**骨骺板**；骨骺線是生長停止後的痕跡，不會再長
- 三塊**聽小骨**在**顳骨**裡
- **下頜骨沒有副鼻竇**；含副鼻竇的是額骨、篩骨、蝶骨、上頜骨(鼻骨、顴骨、腭骨都沒有)
- 連接**顱腔與椎管**的是**枕骨大孔**；蝶骨大翼與小翼之間是**眶上裂**
- **枕骨**與第 1 頸椎(寰椎)形成關節；蝶骨不和頸椎相接
- **顴弓**＝顴骨的顳突＋**顳骨**的顴突
- 上頜骨參與眼眶、鼻腔、口腔，**不參與顱腔**；腭骨參與鼻腔、眼眶、上腭，**也不參與顱腔**
- 棘突最長的是**胸椎**(細長往下斜)；腰椎棘突短寬水平
- 脊柱側面：**頸段、腰段前凸**，胸段、薦段後凸；嬰兒約 **3 個月抬頭**時頸曲形成，約 1 歲**站立行走**後腰曲形成
- **第 7 肋是真肋**(也是典型肋骨)，第 8 肋軟骨接在第 7 肋軟骨上
- **鷹嘴**是**尺骨**的標記；滑車、小頭是肱骨遠端的構造
- 承接坐姿體重的是**坐骨粗隆**；骨髓抽吸常取靠近體表的**髂嵴**
- 男女骨盆：女性骨盆入口、出口較寬，**恥骨弓角度較大**；**真骨盆較深的是男性**
- **髕骨是種子骨**(長在股四頭肌肌腱裡)；**脛骨是長骨**；**大轉子在股骨**
- **踝關節**＝脛骨、腓骨＋**距骨**(跟骨不參與)
- 位於**膝關節腔內**的是**半月板**(十字韌帶在關節囊內但在滑膜外，國考答半月板)
- 滑液關節**都有**關節囊、滑液膜、關節腔、關節軟骨，但**不一定有關節盤**(只有膝、顳下頜等少數有)

## 骨骼的功能與分類 {#functions}

| 功能 | 說明 |
|---|---|
| 支持 | 撐起身體、提供肌肉與內臟附著 |
| 保護 | 顱骨護腦、脊柱護脊髓、胸廓護心肺、骨盆護骨盆腔器官 |
| 運動 | 骨是槓桿、關節是支點、肌肉提供力量 |
| 造血 | 紅骨髓製造血球；成人只剩扁平骨與長骨近端(見 [[blood-hemostasis#hematopoiesis]]) |
| 儲存 | 鈣、磷(羥磷灰石)、鎂；黃骨髓儲存脂肪 |

- 依《內外科護理學》下冊 p.510–511
- 依形狀分類

| 類型 | 例子 |
|---|---|
| 長骨 | 股骨、**脛骨**、腓骨、肱骨、橈骨、尺骨、指骨 |
| 短骨 | 腕骨、跗骨 |
| 扁平骨 | 顱頂骨、胸骨、肋骨、肩胛骨 |
| 不規則骨 | 椎骨、部分顱骨(蝶骨、篩骨) |
| 種子骨 | **髕骨**(長在肌腱內) |

- 構成骨骼與牙齒的礦物質以**鈣、磷**為主，也有鎂；血鈣與血磷的調節見 [[calcium-phosphate]]

## 骨組織與骨細胞 {#bone-tissue}

### 長骨的構造 {#long-bone}

| 部位 | 說明 |
|---|---|
| **骨骺** | 長骨兩端；內部是海綿骨，表面覆蓋**關節軟骨**(透明軟骨) |
| **骨幹** | 中段管狀；外層緻密骨、中間**骨髓腔**(成人為黃骨髓) |
| 幹骺端 | 骨幹與骨骺交界，生長最活躍；兒童骨髓炎、骨肉瘤好發 |
| **骨骺板** | 幹骺端的透明軟骨板，負責**縱向生長**；成年骨化成**骨骺線** |
| **骨外膜** | 包在骨外面(關節面除外)，有血管神經與**造骨細胞**；負責骨增粗與骨折修復 |
| 骨內膜 | 襯在骨髓腔內面 |

- 依《內外科護理學》下冊 p.507、509

### 緻密骨與海綿骨 {#compact-spongy}

| | **緻密骨** | **海綿骨** |
|---|---|---|
| 位置 | 骨的外層、長骨骨幹 | 骨的內層、長骨兩端、扁平骨內 |
| 基本單位 | **骨單位**(哈氏系統)：同心圓骨板圍著**中央管(哈氏管)** | **骨小樑**交織成網，**沒有骨單位** |
| 管道 | 哈氏管(縱走，含血管神經)、**穿通管(伏克曼氏管)**(橫向連接) | 營養由骨小樑間的骨髓供應 |
| 空隙 | 小 | 大，充滿**紅骨髓** |

- 骨細胞住在**骨陷窩**，彼此以**骨小管**相通

### 骨細胞 {#bone-cells}

| 細胞 | 功能 | 備註 |
|---|---|---|
| **造骨細胞** | 分泌膠原與骨基質，讓鈣鹽沉積 | 在骨膜深層與骨內膜；鹼性磷酸酶升高代表造骨活躍 |
| **骨細胞** | 維持骨基質 | 造骨細胞被基質包住後變成，住骨陷窩 |
| **蝕骨細胞** | 分解骨質、釋出鈣 | 多核大細胞，由**單核球／巨噬細胞系**來源；副甲狀腺素間接活化，降鈣素抑制 |

- 骨一直在**重塑**：蝕骨細胞吸收 → 造骨細胞補上；骨質量約在 **30–35 歲達高峰**，35 歲以後吸收大於生成(《內外科護理學》下冊 p.510)，停經後下降更快(見 [[osteoporosis]])

::questions{ids="106-2_makeup_BM_004"}

### 骨化與生長 {#ossification}

1. **膜內骨化**：間葉組織直接變成骨，例：**顱頂扁平骨**、鎖骨
2. **軟骨內骨化**：先形成透明軟骨模型再被骨取代，例：**長骨**、椎骨、骨盆
- **縱向生長**：骨骺板的軟骨細胞增生、肥大、鈣化，再被骨取代；骨骺板在青春期後閉合 → 骨骺線
- **增粗**：骨外膜造骨細胞在外面加骨，蝕骨細胞同時把骨髓腔擴大
- 兒童骨折傷到**骨骺板**可能造成肢體長短不一(見 [[fractures#pediatric]])

| 影響骨骼的因素 | 作用 |
|---|---|
| 生長激素、類胰島素生長因子 | 刺激骨骺板生長；兒童缺乏 → 侏儒，過多 → 巨人症 |
| 甲狀腺素 | 促進生長與骨骺成熟 |
| **性激素**(雌激素、睪固酮) | 青春期生長加速，之後讓骨骺板**閉合**；雌激素抑制骨吸收 |
| **副甲狀腺素** | 血鈣低時促進骨吸收、釋出鈣 |
| **降鈣素** | 抑制蝕骨細胞、降低血鈣 |
| **活性維生素 D**(1,25-(OH)₂D₃) | 促進腸道吸收鈣磷，**增加骨密度**；缺乏 → 兒童佝僂症、成人骨軟化症 |
| 皮質醇 | 抑制造骨、增加骨吸收 → 長期使用類固醇骨質疏鬆 |

- 依《內外科護理學》下冊 p.511 表 17-1 方向重新整理；與骨骼生長**最無關**的是**腎上腺素**(105-1_BM_002)
- 增加骨密度：活性維生素 D 上升、雌激素正常；**皮質醇上升、雌激素下降、降鈣素下降都不利**(112-3_BM_016)

## 顱骨 {#skull}

### 腦顱骨與顏面骨 {#skull-bones}

| 骨 | 數目 | 重點 |
|---|---|---|
| **額骨** | 1 | 前額；**含額竇** |
| **頂骨** | 2 | 顱頂；兩頂骨間是**矢狀縫**，額骨與頂骨間是冠狀縫 |
| **顳骨** | 2 | 兩側；**內有三塊聽小骨**(錘骨、砧骨、鐙骨)與內耳；乳突；外耳道 |
| **枕骨** | 1 | 後下方；**枕骨大孔**(延腦與脊髓交界通過)；枕髁與**寰椎**形成關節 |
| **蝶骨** | 1 | 顱底中央，像蝴蝶；**蝶鞍**(腦下垂體窩)；**含蝶竇**；有視神經管通眼眶 |
| **篩骨** | 1 | 鼻腔頂；篩板(嗅神經通過)；**含篩竇** |
| **上頜骨** | 2 | 參與**眼眶、鼻腔、口腔**；**含上頜竇**(最大的副鼻竇) |
| **下頜骨** | 1 | 唯一可動的顱骨(顳下頜關節)；**沒有副鼻竇** |
| 顴骨 | 2 | 頰骨；顴突＋**顳骨**顴突 → **顴弓** |
| 腭骨 | 2 | 硬腭後段；參與**鼻腔、眼眶、上腭** |
| 鼻骨、淚骨 | 各 2 | 鼻樑、眼眶內側 |
| 犁骨、下鼻甲 | 1、2 | 鼻中隔、鼻腔外側壁 |

- 顱腔由腦顱骨圍成(額、頂、顳、枕、蝶、篩)；**上頜骨、腭骨不參與顱腔**
- 舌骨不和任何骨直接成關節，靠肌肉懸吊；聽小骨與舌骨通常不算在 22 塊顱骨內

### 顱底的孔與裂 {#foramina}

| 孔裂 | 位置 | 通過的構造 |
|---|---|---|
| **枕骨大孔** | 枕骨 | 延腦與脊髓交界、椎動脈；**連接顱腔與椎管** |
| 視神經管 | 蝶骨小翼 | 視神經(CN II)、眼動脈 |
| **眶上裂** | **蝶骨大翼與小翼之間** | 動眼、滑車、外展神經與三叉神經眼支 |
| 圓孔 | 蝶骨 | 三叉神經上頜支 |
| 卵圓孔 | 蝶骨 | 三叉神經下頜支 |
| 棘孔 | 蝶骨 | 腦膜中動脈 |
| 頸靜脈孔 | 顳骨與枕骨之間 | 內頸靜脈、舌咽、迷走、副神經 |
| 頸動脈管 | 顳骨 | 內頸動脈 |
| 內耳道 | 顳骨 | 顏面神經、前庭耳蝸神經 |

- 腦神經的走向與功能見 [[cranial-nerves]]；顱底骨折的徵象見 [[head-injury]]
- 胎兒與新生兒的顱縫、囟門、胎頭徑線留到產科分娩機轉頁

::questions{ids="108-1_BM_003,108-2_BM_003"}

## 脊柱 {#vertebral-column}

- 頸椎 **7**、胸椎 **12**、腰椎 **5**、薦椎 1(5 塊癒合)、尾椎 1(3–5 塊癒合)；各段特徵(橫突孔、棘突方向)與椎孔、椎間孔見 [[spinal-cord-spinal-nerves#vertebrae]]
- 典型椎骨：**椎體**(承重)＋**椎弓**(圍成椎孔)，椎弓上有棘突、2 個橫突、上下關節突；椎體之間是**椎間盤**(纖維環包住髓核，屬軟骨關節)
- 特殊椎骨：**C1 寰椎**(沒有椎體與棘突，和枕骨成關節，負責點頭)；**C2 樞椎**(齒突，負責轉頭)；**C7 隆椎**(低頭時頸後最突出，用來數椎骨)
- 棘突：**胸椎最長**，細長往下斜、像屋瓦重疊；腰椎短寬、水平向後(所以腰椎穿刺從腰椎間隙進針)

### 脊柱的彎曲 {#curves}

| 彎曲 | 方向 | 出現時間 |
|---|---|---|
| 胸曲、薦曲 | **向後凸** | 出生就有(**初級彎曲**) |
| **頸曲** | **向前凸** | 約 **3 個月**能抬頭後(次級彎曲) |
| **腰曲** | **向前凸** | 約 **1 歲**站立、行走後(次級彎曲) |

- 新生兒整條脊柱呈 C 形向後凸
- 異常彎曲：**脊柱側彎**(冠狀面側彎合併旋轉)、**駝背**(胸曲過大，骨質疏鬆椎體壓迫骨折常見)、**脊柱前凸**(腰曲過大，孕婦、肥胖)；兒童脊柱側彎見 [[pediatric-musculoskeletal#scoliosis]]

::questions{ids="112-1_BM_002,105-1_OP_050,110-1_BM_002,114-1_BM_013,109-2_BM_002"}

## 胸廓 {#thorax}

- 胸廓＝**胸骨**＋**12 對肋骨**＋12 塊胸椎＋肋軟骨
- 胸骨：胸骨柄、胸骨體、劍突；**胸骨角**(柄體交界)平第 2 肋，是數肋骨與聽診定位的標記，也大約是氣管分叉的高度(見 [[respiratory-anatomy#bronchial-tree]])

| 肋骨 | 對數 | 前端連接 |
|---|---|---|
| **真肋** | **第 1–7 對** | 各自以肋軟骨直接接胸骨 |
| 假肋 | 第 8–10 對 | 肋軟骨接在**上一條肋軟骨**(第 8 接第 7)，間接接胸骨 |
| 浮肋 | 第 11–12 對 | 前端游離，不接胸骨 |

- 典型肋骨是第 3–9 對；第 1、2、10、11、12 對形態特殊
- 骨髓抽吸成人可選胸骨，但兒童不用(見 [[blood-hemostasis#bone-marrow-exam]])

::questions{ids="113-3_BM_005"}

## 上肢骨 {#upper-limb}

| 部位 | 骨 | 重要標記 |
|---|---|---|
| 肩帶 | 鎖骨、肩胛骨 | 肩胛骨的肩峰、喙突、關節盂(和肱骨頭成肩關節) |
| 上臂 | **肱骨** | 肱骨頭、外科頸(老人骨折好發)、**骨幹中段的橈神經溝**、遠端**滑車**(接尺骨)與**小頭**(接橈骨)、內上髁與外上髁 |
| 前臂 | **尺骨**(內側、小指側) | **鷹嘴**(手肘後方尖端)、冠狀突、滑車切跡 |
| 前臂 | **橈骨**(外側、拇指側) | 橈骨頭、遠端莖突；遠端骨折＝柯雷氏骨折 |
| 手 | 腕骨 8、掌骨 5、指骨 14 | 舟狀骨最常骨折 |

- **肱骨骨幹骨折**最容易傷到**橈神經** → **垂腕**(見 [[spinal-cord-spinal-nerves#plexuses]])
- 解剖姿勢下手掌朝前，所以**橈骨在外側**、尺骨在內側

## 下肢骨與骨盆 {#lower-limb}

### 骨盆 {#pelvis}

- **髖骨**由**髂骨、坐骨、恥骨**三塊在青春期癒合而成，三者交會在**髖臼**；兩側髖骨＋薦骨＋尾骨＝骨盆
- 重要標記
   1. **髂嵴**：髂骨上緣，靠近體表，**骨髓抽吸**常取後髂嵴(105-2_BM_004)
   2. 髂前上棘：臀部肌肉注射、測量下肢長度的定位點
   3. **坐骨粗隆**：坐骨最粗壯處，**坐著時承受體重**(久坐壓傷好發)
   4. 坐骨棘：分娩時評估胎頭下降高度的參考點(station 0)
   5. **恥骨聯合**：兩側恥骨以纖維軟骨相連(軟骨關節)

| 比較 | 男性 | 女性 |
|---|---|---|
| 整體 | 粗厚、高窄 | 輕薄、寬淺 |
| 骨盆入口 | 心形、較窄 | **橢圓形、較寬** |
| 骨盆出口 | 較窄 | **較寬** |
| **恥骨弓角度** | 小(約 50–60 度) | **大(約 80–90 度)** |
| **真骨盆深度** | **較深** | 較淺 |

- 分娩時的骨盆徑線與骨盆分型留到產科分娩機轉頁

::questions{ids="115-2_BM_003,105-2_BM_004,106-2_BM_005"}

### 下肢骨 {#leg-bones}

| 部位 | 骨 | 重要標記 |
|---|---|---|
| 大腿 | **股骨**(人體最長最重) | 股骨頭、股骨頸(老人髖骨折好發)、**大轉子**(外側可觸摸)、小轉子、內外髁 |
| 膝 | **髕骨** | **種子骨**，在股四頭肌肌腱內 |
| 小腿 | **脛骨**(內側、承重) | 脛骨粗隆、內踝；**長骨**；嬰幼兒骨髓抽吸取**近側脛骨** |
| 小腿 | 腓骨(外側、不承重) | 外踝；腓骨頸旁有腓總神經(石膏太緊壓迫 → 足下垂) |
| 足 | 跗骨 7(**距骨**、跟骨、舟狀骨、骰骨、3 塊楔狀骨)、蹠骨 5、趾骨 14 | 距骨接脛腓骨；**跟骨**最大，跟腱附著 |

## 關節 {#joints}

### 關節的分類 {#joint-types}

| 結構分類 | 活動度 | 例子 |
|---|---|---|
| **纖維關節** | 不動或微動，**沒有關節腔** | **顱縫**(不動)、脛腓骨間的韌帶聯合、牙齒與齒槽的嵌合 |
| **軟骨關節** | 微動，**沒有關節腔** | **恥骨聯合**、**椎間盤**、第 1 肋與胸骨、兒童骨骺板 |
| **滑液關節** | 可自由活動，**有關節腔** | 肩、肘、腕、髖、膝、踝、指間 |

- 依《內外科護理學》下冊 p.512 表 17-2 重新整理

### 滑液關節的構造 {#synovial}

- **每個**滑液關節都有
   1. **關節軟骨**：骨端表面的透明軟骨，減少摩擦、吸收衝擊；**沒有血管**，靠滑液營養，所以受損很難修復(退化性關節炎的病變處，見 [[osteoarthritis#physical-exam]])
   2. **關節囊**：外層纖維囊、內層**滑液膜**
   3. **關節腔**：充滿**滑液**(滑液膜分泌，潤滑與營養軟骨)
   4. 周圍韌帶加強穩定
- **不是每個都有**：**關節盤／半月板**(膝關節、顳下頜關節、胸鎖關節)、滑液囊(肌腱與骨摩擦處)
- 類風濕性關節炎是**滑液膜**發炎增生(血管翳)，見 [[rheumatoid-arthritis]]

::questions{ids="105-1_BM_004"}

### 滑液關節的類型 {#synovial-types}

| 類型 | 動作 | 例子 |
|---|---|---|
| **球窩關節** | 多軸，可屈伸、內收外展、旋轉、迴旋 | **肩關節**(最靈活、最易脫臼)、**髖關節**(最穩) |
| **樞紐關節** | 單軸屈伸 | 肘(肱尺)、膝、指間 |
| 車軸關節 | 旋轉 | 寰樞關節(轉頭)、近端橈尺(旋前旋後) |
| 髁狀關節 | 雙軸 | 腕(橈腕)、掌指 |
| 鞍狀關節 | 雙軸 | 拇指腕掌關節(對掌) |
| 平面關節 | 滑動 | 腕骨間、跗骨間 |

- 各關節可做的全關節運動(例：髖關節**沒有旋前**，旋前旋後只在前臂)見 [[activity-immobility#rom-joints]]

### 膝、踝、髖、肩 {#major-joints}

| 關節 | 組成 | 重點構造 |
|---|---|---|
| **膝關節** | 股骨、脛骨、髕骨(腓骨不參與) | **關節腔內**：內外側**半月板**、前後**十字韌帶**；兩側：脛側(內側)與腓側(外側)副韌帶；前方：**髕韌帶**(關節囊外) |
| **踝關節** | **脛骨、腓骨＋距骨** | 內踝(脛骨)、外踝(腓骨)；外側韌帶最常扭傷(內翻扭傷) |
| 髖關節 | 股骨頭＋髖臼 | 關節囊與韌帶強韌，最穩定；股骨頭血液供應經股骨頸，頸骨折易**股骨頭缺血性壞死** |
| 肩關節 | 肱骨頭＋肩胛骨關節盂 | 關節盂淺，靠**旋轉肌袖**穩定(見 [[muscular-system#upper-limb]])，最易脫臼 |

- 膝關節的理學檢查(前抽屜、Lachman、McMurray、膨出徵象)見 [[osteoarthritis#physical-exam]]

::questions{ids="106-2_makeup_BM_005,113-1_BM_012,106-1_BM_004,114-2_FA_029"}

## 臥床與骨骼 {#immobility}

- 長期臥床：骨骼失去重力與肌肉牽拉 → **骨吸收增加** → 血鈣、尿鈣升高 → 骨質流失與**泌尿道結石**；肌肉完全不動每天約失去 3% 強度(見 [[activity-immobility#immobility-effects]])
- 骨突處(枕骨、薦骨、肩胛、股骨大轉子、足跟)容易壓傷；平躺最容易壓傷的是**枕骨與薦骨**(見 [[pressure-injury]])

::questions{ids="112-3_FA_026,112-3_FA_028"}
