空氣到了肺泡之後，氧氣要穿過呼吸膜進血液、由血紅素送到組織，二氧化碳反向排出；呼吸的深度與速率則由腦幹依血中 CO₂、H⁺、O₂ 調整。構造見 [[respiratory-anatomy]]，通氣見 [[ventilation-mechanics]]，血氣判讀見 [[abg]]

## 重點摘要 {#summary}

- **外呼吸**＝肺泡與肺微血管之間的交換；**內呼吸**＝微血管與組織細胞之間的交換
- 氣體由**分壓高往分壓低**擴散；**CO₂ 溶解度約是 O₂ 的 20 倍**，所以分壓差小也擴散得比 O₂ 快
- 擴散變慢：呼吸膜**變厚**、面積變小、分壓差變小、氣體**分子量變大**
- **V/Q 約 0.8**；**分流**(有血流沒通氣，例如肺擴張不全、ARDS)；**無效腔**(有通氣沒血流，例如**肺栓塞**)
- **低氧性肺血管收縮**：通氣差的肺區血管收縮 → 血流轉到通氣好的肺泡 → **改善 V/Q**
- O₂ 絕大部分(約 97% 以上)和血紅素結合；**右移**＝CO₂、H⁺、體溫、2,3-BPG 上升 → 放氧增加(**波爾效應**)；**左移**＝pH 上升、CO、胎兒血紅素
- CO₂ 運送：**碳酸氫根約 70%**(紅血球內**碳酸酐酶**催化)、碳醯胺基血紅素約 20–23%、溶解約 7–10%
- 呼吸中樞在**延腦**(節律)與**橋腦**(調節)；平常最主要的刺激是 **CO₂**；**頸動脈體(舌咽神經)**與**主動脈體(迷走神經)**感應低血氧

### 國考常考點 {#exam-points}

- 降低擴散能力的是**氣體分子量增加**；氣體靠**隨機運動**穿過呼吸膜；O₂ 擴散比 CO₂ **慢**；呼吸膜變厚**會**變慢
- 缺氧引起肺血管收縮的目的：**改善通氣／血流比**；肺泡氧分壓低於約 70 mmHg → 肺血管**收縮、血流減少**
- 肺栓塞的 V/Q 失衡：**通氣足夠、但部分肺區血流受阻**
- ARDS 用 PEEP(Positive end-expiratory pressure) 的目的：**減少分流**、撐開塌陷肺泡、改善氧合(不會增加靜脈回流，也不是改善血管通透性)
- 波爾效應的意義：曲線**右移**讓更多氧**釋出**；pH **上升**使曲線**左移**(最不會右移)
- CO₂ 最主要的運送形式：**碳酸氫根(重碳酸根)離子**；紅血球內催化 CO₂＋H₂O 的酵素：**碳酸酐酶**
- CO 與血紅素親和力約為氧的 **210 倍**(國考答案；教科書多寫 200–250 倍)，見 [[environmental-injury#carbon-monoxide]]
- 正常刺激呼吸中樞的主要物質是 **CO₂**；調節呼吸的化學物質**不包括一氧化氮**；CO₂ 增加會**刺激**呼吸(說「抑制」是錯的)
- 主動脈體經**迷走神經**傳 O₂ 訊息；呼吸節律中樞在**延腦**；**橋腦上方的呼吸調節區抑制吸氣**
- 門窗緊閉頭暈：體內 **CO₂ 上升、呼吸變快**；劇烈運動後呼吸**深而快**；高海拔：CO₂ 下降、**pH 上升**、刺激**周邊化學接受器**
- 血壓下降時呼吸會**加快**(說「減慢」是錯的)；年紀越小呼吸越快；體溫下降呼吸變慢

## 分壓與擴散 {#diffusion}

- **道耳吞定律**：混合氣體中每種氣體的分壓＝總壓 × 該氣體比例；海平面空氣氧氣 21% → PO₂ 約 160 mmHg
- **亨利定律**：溶進液體的氣體量和分壓、溶解度成正比
- 各處的分壓(約略值，mmHg)

| 位置 | PO₂ | PCO₂ |
|---|---:|---:|
| 大氣 | 約 160 | 約 0.3 |
| 肺泡 | 約 100–104 | 約 40 |
| 回到肺的靜脈血 | 約 40 | 約 45–46 |
| 離開肺的動脈血 | 約 95–100 | 約 40 |
| 組織細胞 | 約 40 以下 | 約 45 以上 |

數值為教科書常用的約略值(來源：OpenStax Anatomy and Physiology 2e，22.4)

- 肺泡的 PO₂ 比大氣低：吸入的空氣被呼吸道的水蒸氣稀釋，又和留在肺內含 CO₂ 的空氣混合
- 影響擴散速率(費克定律)

| 擴散變快 | 擴散變慢 |
|---|---|
| 分壓差增加 | 呼吸膜**變厚**(肺水腫、肺纖維化、肺炎) |
| 交換**面積**增加 | 面積減少(**肺氣腫**、肺葉切除、肺擴張不全) |
| 氣體**溶解度**增加(CO₂ 遠高於 O₂) | 氣體**分子量**增加 |

- 所以肺部疾病常先出現**低血氧**，CO₂ 到後期才上升
- 新生兒、早產兒的血氧正常值與成人不同；國考答案以 **PaO₂(Partial pressure of arterial oxygen) 70、PaCO₂(Partial pressure of arterial carbon dioxide) 40 mmHg** 為早產兒的正常範圍
- 呼吸膜的構造見 [[respiratory-anatomy#alveoli]]

## 通氣與血流配合(V/Q) {#vq}

![正常 V/Q、分流(肺泡塌陷或積液，有血流沒通氣)、無效腔(肺栓塞，有通氣沒血流)三種比較](/knowledge-images/vq-matching.svg)

- 全肺每分鐘肺泡通氣量約 4 L、肺血流約 5 L → **V/Q 約 0.8**
- 站立時：肺尖通氣與血流都少，但血流少得更多(V/Q 較高)；肺底血流較多(V/Q 較低)

| | V/Q | 意思 | 例子 | 給氧效果 |
|---|---|---|---|---|
| **分流** | 低(極端為 0) | 有血流、**沒通氣** | **肺擴張不全**、肺炎、**ARDS**、肺水腫 | 差；要先**把肺泡打開**(PEEP、深呼吸、翻身) |
| **無效腔** | 高(極端為無限大) | 有通氣、**沒血流** | **肺栓塞**、休克時肺血流減少 | 要恢復血流 |

- **低氧性肺血管收縮**(肺特有的反應)
   1. 全身其他血管遇到缺氧會**擴張**，**肺血管遇到缺氧會收縮**
   2. 肺泡 PO₂ 下降(約低於 70 mmHg)的區域血管收縮 → 血流轉到通氣好的肺泡 → **改善 V/Q、減少分流**
   3. 全肺長期缺氧(COPD、高海拔)時大範圍血管收縮 → **肺高壓** → 右心衰竭(肺心症)
- **PEEP**(呼氣末正壓)：吐氣結束時保留正壓，撐開塌陷的肺泡 → **減少分流**、提高功能肺餘量；副作用是胸內壓上升、**靜脈回流減少**，見 [[mechanical-ventilation#modes]]

## 氧氣的運送與解離曲線 {#oxygen-transport}

![氧合血紅素解離曲線：PO₂ 100 約 97%、60 約 90%、40 約 75%；右移與左移的因素](/knowledge-images/oxygen-dissociation-curve.svg)

- 血中的氧
   1. **約 97% 以上和血紅素結合**(氧合血紅素)，每個血紅素可結合 4 個 O₂
   2. 只有極少數(約 1.5–3%)溶在血漿；PaO₂ 測的是溶解的這一部分(來源：Guyton and Hall Textbook of Medical Physiology，Transport of Oxygen and Carbon Dioxide)
- 曲線是 **S 形**
   1. **平坦段**(PO₂ 60–100)：PaO₂ 稍微下降，飽和度仍高，是安全範圍
   2. **陡峭段**(PO₂ 60 以下)：PO₂ 小降、飽和度大降 → 組織容易拿到氧，但病人也很快變差
   3. 臨床對照：**PaO₂ 60 mmHg ≈ SaO₂(Arterial oxygen saturation) 90%**，這是給氧與呼吸衰竭判斷的重要切點
- **P₅₀**：血紅素 50% 飽和時的 PO₂，約 27 mmHg；P₅₀ 變大＝右移

| | 右移(抓氧變鬆、**放氧增加**) | 左移(抓氧變緊、**不易放氧**) |
|---|---|---|
| CO₂ | 上升 | 下降 |
| H⁺／pH | H⁺ 上升(**pH 下降**) | **pH 上升** |
| 體溫 | 上升 | 下降 |
| 2,3-BPG | 上升(高海拔、貧血、慢性缺氧) | 下降(庫存血) |
| 其他 | 運動中的肌肉 | **一氧化碳**、**胎兒血紅素**、變性血紅素 |

- **波爾效應**：CO₂ 與 H⁺ 讓血紅素對氧的親和力下降 → 曲線右移 → 代謝旺盛的組織拿到更多氧
- **胎兒血紅素**對 2,3-BPG 結合差 → 曲線左移 → 能從母血搶到氧
- **一氧化碳**：搶走血紅素結合位置，又讓剩下的血紅素不放氧；脈衝式血氧會**假性正常**
- **發紺**：微血管中的去氧血紅素夠多時才看得出來；**貧血**病人即使很缺氧也可能不發紺，紅血球過多症較早出現

## 二氧化碳的運送 {#co2-transport}

![CO₂ 三種運送方式：溶在血漿、碳醯胺基血紅素、碳酸氫根；紅血球內碳酸酐酶產生 HCO₃⁻，經膜上的交換蛋白(Band 3)一個 HCO₃⁻ 換一個 Cl⁻(氯轉移)](/knowledge-images/co2-transport.svg)

| 形式 | 比例(約) | 說明 |
|---|---:|---|
| **碳酸氫根(HCO₃⁻)** | **約 70%** | 紅血球內 **碳酸酐酶** 催化 CO₂＋H₂O → H₂CO₃ → H⁺＋HCO₃⁻；HCO₃⁻ 經紅血球膜上的**交換蛋白(Band 3)**出到血漿、同時 Cl⁻ 進入(**氯轉移**)，一個換一個、電荷保持平衡 |
| **碳醯胺基血紅素** | 約 20–23% | CO₂ 接在血紅素的胺基酸上 |
| 溶在血漿 | 約 7–10% | PaCO₂ 測的是這一部分 |

比例來源：OpenStax Anatomy and Physiology 2e，22.5(碳酸氫根約 70%、溶解約 7–10%)；與血紅素結合的比例教科書寫法約 20–23%

- H⁺ 由血紅素緩衝，所以靜脈血 pH 只比動脈血略低
- 到了肺部反應倒過來：HCO₃⁻ 回到紅血球 → 變回 CO₂ → 擴散進肺泡呼出
- **霍爾丹效應**：去氧血紅素比較能攜帶 CO₂；在肺部血紅素接上氧，就把 CO₂ 釋出
- 這條反應式就是呼吸與酸鹼的關聯：**CO₂ 滯留 → H⁺ 增加 → 呼吸性酸中毒**；CO₂ 排太多 → 呼吸性鹼中毒，見 [[abg#respiratory]]

## 呼吸的調控 {#control}

### 呼吸中樞 {#centers}

| 位置 | 名稱 | 作用 |
|---|---|---|
| **延腦** | 背側呼吸群 | 產生**基本吸氣節律**(平靜呼吸) |
| 延腦 | 腹側呼吸群 | 用力呼吸時啟動吸氣與呼氣輔助肌 |
| **橋腦上方** | **呼吸調節區**(呼吸調節中樞) | **抑制吸氣**、讓吸氣提早結束 → 呼吸變快變淺 |
| 橋腦下方 | 長吸區 | 延長吸氣；失去上方抑制時出現長吸式呼吸 |
| 大腦皮質 | — | 可以暫時自主控制(說話、憋氣)，但 CO₂ 上升到一定程度就會被迫呼吸 |

- 呼吸節律由**延腦與橋腦**控制，**不是下視丘**；腦幹受損的呼吸型態見 [[brain-anatomy#brainstem-lesions]]
- 腦池穿刺、延腦受壓(顱內壓升高、腦疝)最怕呼吸停止

### 化學接受器 {#chemoreceptors}

| | **中樞化學接受器** | **周邊化學接受器** |
|---|---|---|
| 位置 | **延腦**腹側表面 | **頸動脈體**(頸總動脈分叉處)、**主動脈體**(主動脈弓) |
| 傳入神經 | — | 頸動脈體 → **舌咽神經**；主動脈體 → **迷走神經** |
| 主要感應 | 腦脊髓液的 **H⁺**(由血中 **CO₂** 穿過血腦屏障產生) | **PaO₂ 下降**(約低於 60 mmHg 才明顯)，也感應 CO₂ 與 H⁺ 上升 |
| 重要性 | **平常最主要的呼吸驅動力** | 缺氧時的驅動力；高海拔適應的起點 |

- 調節呼吸的化學物質：**CO₂、H⁺、O₂**(碳酸氫根經 H⁺ 間接影響)；一氧化氮不是
- **慢性 CO₂ 滯留**(COPD)：中樞化學接受器逐漸適應高 CO₂，呼吸較依賴低血氧刺激；給太多氧可能讓 PaCO₂ 上升(機轉現在認為以 V/Q 惡化與霍爾丹效應為主)，所以這類病人給氧目標是 SpO₂(Peripheral oxygen saturation) 88–92%(來源：[BTS Guideline for oxygen use in adults 2017](https://www.brit-thoracic.org.uk/clinical-resources/guidelines/emergency-oxygen/))，見 [[abg#respiratory]]

### 其他影響呼吸的因素 {#other-factors}

| 因素 | 呼吸變化 | 機轉 |
|---|---|---|
| **運動** | **深而快** | 肌肉與關節的本體感受器、皮質訊號、代謝增加 |
| 密閉空間 CO₂ 累積 | 變快 | CO₂ 刺激中樞化學接受器 |
| 發燒 | 變快 | 代謝率上升 |
| 體溫下降 | 變慢 | 代謝率下降 |
| **血壓下降**、出血 | **變快** | 壓力受器與組織缺氧 |
| 年齡 | 越小越快 | 代謝率高、肺容量小 |
| 疼痛、焦慮 | 變快 | 皮質與邊緣系統 |
| 鴉片類、鎮靜劑 | 變慢變淺 | 抑制延腦呼吸中樞，見 [[opioids]] |
| 肺過度擴張 | 吸氣停止 | **赫鮑二氏反射**：肺牽張受器經迷走神經抑制吸氣，嬰兒較明顯 |

### 高海拔 {#altitude}

1. 大氣壓下降 → 吸入的 PO₂ 下降 → **刺激周邊化學接受器** → 換氣增加
2. 換氣增加 → CO₂ 排出 → **CO₂ 下降、pH 上升(呼吸性鹼中毒)**
3. 數天到數週的適應
   1. 腎臟排出 HCO₃⁻，代償鹼中毒
   2. 紅血球 **2,3-BPG 增加** → 曲線右移、放氧給組織
   3. 腎臟分泌**紅血球生成素增加** → 紅血球增多
   4. 肌肉微血管密度**增加**
