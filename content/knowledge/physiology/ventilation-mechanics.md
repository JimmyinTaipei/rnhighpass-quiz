**肺通氣**是空氣進出肺的機械過程，靠的是胸腔容積改變造成的壓力差。本頁整理呼吸肌、壓力、順應性、肺容積與肺功能檢查；構造見 [[respiratory-anatomy]]，進到肺泡之後的交換見 [[gas-exchange-transport]]

## 重點摘要 {#summary}

- 空氣由高壓流向低壓；**波以耳定律**：容積變大、壓力變小
- **平靜吸氣**：**橫膈**收縮下降＋**外肋間肌**收縮（肋骨上提） → 胸腔變大；**平靜呼氣是被動的**（肺彈性回縮）
- 用力吸氣加上胸鎖乳突肌、斜角肌；**用力呼氣**用**內肋間肌**與**腹肌**
- 吸氣時：胸膜內壓**更負**、**跨肺壓上升**、**肺泡壓下降**（低於大氣壓）、大氣壓不變
- **順應性**＝肺多容易被撐開；**表面張力素**讓順應性上升；**肺氣腫順應性上升**、肺纖維化與 ARDS 下降
- 肺容積：潮氣 500、吸氣儲備約 3,000、呼氣儲備約 1,100、餘氣約 1,200 mL；**肺活量＝IRV＋TV＋ERV**
- **阻塞性**：FEV1(Forced expiratory volume in 1 second) 下降、**FEV1/FVC < 0.7**；**限制性**：FVC(Forced vital capacity) 下降、FEV1/FVC 正常或上升
- **肺泡通氣量＝（潮氣容積－無效腔）×呼吸次數**；淺快呼吸的肺泡通氣量反而變少

### 國考常考點 {#exam-points}

- 用力吸氣**和腹肌無關**；費力呼吸時主要的**呼氣**輔助肌是**腹肌**；吸氣時收縮的是**外**肋間肌（內肋間肌是錯的）
- 呼氣時肋骨**下降**、橫膈放鬆上升；平均吸氣約 2 秒、呼氣約 3 秒
- 吸氣時胸膜內壓**降低**（說「增加」是錯的）、肺泡壓**降低**（說「增加」是錯的）、跨肺壓增加
- 氣胸後胸膜內壓上升到接近大氣壓 → **跨肺壓下降** → 肺塌陷
- 表面張力素穩定的是**小**肺泡（說「穩定大肺泡」是錯的）；深呼吸可增加分泌；**胸腔術後深呼吸**是為了**擴張肺泡、增加交換面積**
- 肺氣腫：肺泡壁破壞 → **順應性增加**、回彈力下降、呼吸道阻力**上升**、交換面積下降
- **潮氣容積＋吸氣儲備容積＝吸氣容量**；平靜呼氣後正常吸一口氣＝**潮氣容積**
- 評估呼吸道阻塞嚴重度最重要的是 **FEV1**；阻塞性的特徵是 **FEV1/FVC 下降**；COPD 最早的肺功能變化依國考答案是 **FEV1 下降**
- 肺氣腫**不會**出現 FEV1/FVC > 80%；肺活量 2 L、FEV1/FVC 85% → **限制性**
- 神經肌肉病變造成呼吸衰竭：**潮氣容積下降**
- 肺泡通氣量計算：(500－150)×12＝**4,200 mL**；(450－150)×12＝**3,600 mL**
- 潮氣 200 mL、每分鐘 40 次：每次只有 50 mL 進到肺泡 → **低血氧**（不是 CO₂ 下降或鹼中毒）
- 換氣過度＝**深而快**、CO₂ 排出過多 → CO₂ 下降、O₂ 略升、**呼吸性鹼中毒**；「換氣過度就等於增加換氣」是錯的（運動時通氣增加但 CO₂ 正常）

## 呼吸肌 {#muscles}

::figure{src="/knowledge-images/servier-breathing.svg" labels="breathing" alt="吸氣時橫膈收縮下降、肋骨上提胸廓變大；呼氣時橫膈放鬆上升"}

| 時機 | 肌肉 | 動作 |
|---|---|---|
| 平靜吸氣 | **橫膈**（主要，膈神經 C3–C5） | 收縮變平、下降 → 胸腔上下徑變大 |
| 平靜吸氣 | **外肋間肌** | 肋骨與胸骨上提、往外 → 前後與左右徑變大 |
| 用力吸氣（輔助） | **胸鎖乳突肌、斜角肌**、胸小肌 | 再把上胸廓往上拉 |
| 平靜呼氣 | 不需要肌肉 | 肺與胸壁**彈性回縮**（被動） |
| 用力呼氣（輔助） | **內肋間肌**、**腹肌**（腹直肌、腹斜肌） | 肋骨下拉、腹壓把橫膈往上推 |

- 呼吸困難的病人會用到輔助肌：**聳肩、胸鎖乳突肌明顯收縮**、吐氣時腹肌用力
- 嬰幼兒肋骨水平，主要靠橫膈，所以看**腹部起伏**數呼吸，見 [[respiratory-anatomy#infant]]

## 壓力變化 {#pressures}

| 壓力 | 定義 | 平靜時（相對大氣壓） | 吸氣 | 呼氣 |
|---|---|---|---|---|
| 大氣壓 | 外界空氣壓力（海平面 760 mmHg） | 0 | 不變 | 不變 |
| **肺泡壓** | 肺泡內的壓力 | 0 | **略低於大氣壓** → 空氣流入 | 略高於大氣壓 → 空氣流出 |
| **胸膜內壓** | 肋膜腔內的壓力 | **約 −4 mmHg**（永遠負壓） | **更負** | 回到原本的負壓 |
| **跨肺壓** | 肺泡壓－胸膜內壓，把肺撐開的力量 | 正值 | **增加** | 減少 |

胸膜內壓約 −4 mmHg、隨呼吸小幅起伏但始終低於肺泡壓與大氣壓（來源：OpenStax Anatomy and Physiology 2e，22.3）

- 吸氣的順序
   1. 橫膈與外肋間肌收縮 → 胸腔變大
   2. 胸膜內壓變得更負 → 跨肺壓上升 → 肺跟著擴張
   3. 肺泡容積變大 → 肺泡壓低於大氣壓 → 空氣流入，直到兩者相等
- 胸膜內壓為什麼是負的：肺有往內縮的彈性，胸壁有往外彈的傾向，兩者把肋膜腔往相反方向拉
- **氣胸**：空氣進入肋膜腔 → 胸膜內壓上升到等於大氣壓 → **跨肺壓變成 0** → 肺塌陷

## 順應性、表面張力與呼吸道阻力 {#compliance}

- **順應性**＝每增加一單位壓力，肺容積增加多少；順應性高＝容易撐開，但也比較不容易自己縮回來
- 影響肺順應性的兩個回縮力
   1. 肺組織的**彈性纖維**
   2. 肺泡內液體的**表面張力**（佔大部分）
- **表面張力素**（第二型肺泡細胞分泌的磷脂與蛋白質）
   1. 降低表面張力 → 肺**順應性上升**、呼吸做功下降
   2. **穩定小肺泡**：依拉普拉斯定律，半徑越小的肺泡塌陷壓力越大；表面張力素在小肺泡濃度較高，讓大小肺泡壓力接近，小肺泡不會塌陷、把氣排進大肺泡
   3. 減少液體滲進肺泡
   4. **深呼吸**撐開肺泡，會刺激第二型細胞分泌；術後深呼吸、誘發性肺量計用來預防**肺擴張不全**
- 順應性改變

| 方向 | 原因 |
|---|---|
| **上升** | **肺氣腫**（彈性纖維被破壞）、老化 |
| **下降** | 肺纖維化、**ARDS**、新生兒表面張力素不足、肺水腫、肺擴張不全；胸壁因素：肥胖、脊柱側彎、腹脹 |

- **呼吸道阻力**
   1. 和管徑關係最大：管徑減半，阻力增加約 16 倍（與半徑四次方成反比）
   2. 阻力上升：支氣管痙攣（氣喘）、分泌物、黏膜水腫、管外壓迫
   3. 肺氣腫：肺泡壁破壞，失去把小氣道往外拉的力量 → 吐氣時小氣道塌陷 → **空氣滯留**、阻力上升
   4. 交感(β₂)擴張支氣管、副交感收縮，藥物見 [[asthma-drugs]]

::questions{ids="110-2_BM_029,114-1_BM_009,111-1_MS_059"}

## 肺容積與肺容量 {#volumes}

![肺量計曲線：潮氣容積、吸氣與呼氣儲備容積、餘氣容積，以及吸氣容量、功能肺餘量、肺活量、肺總量](/knowledge-images/spirogram.svg)

| 名稱 | 定義 | 成人男性約略值 |
|---|---|---|
| **潮氣容積**（TV，Tidal volume） | 平靜時一次吸入或呼出的量 | **500 mL** |
| **吸氣儲備容積**（IRV，Inspiratory reserve volume） | 平靜吸氣後還能再用力吸入的量 | 約 3,000 mL |
| **呼氣儲備容積**（ERV，Expiratory reserve volume） | 平靜呼氣後還能再用力呼出的量 | 約 1,100–1,200 mL |
| **餘氣容積**（RV，Residual volume） | 用力呼完仍留在肺內的量，防止肺泡塌陷 | 約 1,200 mL |
| **吸氣容量**（IC，Inspiratory capacity） | **TV＋IRV** | 約 3,500 mL |
| **功能肺餘量**（FRC，Functional residual capacity） | **ERV＋RV**，平靜呼氣後留在肺內的量 | 約 2,300 mL |
| **肺活量**（VC，Vital capacity） | **IRV＋TV＋ERV**，最大吸氣後能呼出的最大量 | 約 4,600 mL |
| **肺總量**（TLC，Total lung capacity） | 四個容積相加 | 約 5,800 mL |

數值為健康年輕男性的約略值（來源：Guyton and Hall Textbook of Medical Physiology；OpenStax Anatomy and Physiology 2e，22.3）；女性約少 20–25%，也隨年齡、身高、姿勢改變

- 「容積」是不能再分的單一量；「容量」是兩個以上容積相加
- **肺量計量不到餘氣容積**，所以也量不到 FRC 與 TLC；要用氦氣稀釋、氮氣沖洗或體箱
- **FRC** 是兩次呼吸之間的氧氣倉庫，讓血氧不會隨呼吸大幅起伏；**呼氣末正壓（PEEP，Positive end-expiratory pressure）** 就是提高 FRC、撐開塌陷的肺泡
- 神經肌肉病變（重症肌無力、肌萎縮）：呼吸肌無力 → **潮氣容積與肺活量下降** → 換氣不足、CO₂ 上升

::questions{ids="105-2_BM_029,113-2_BM_019,105-1_MS_052"}

## 肺功能檢查：阻塞性與限制性 {#spirometry}

- **FVC**（用力肺活量）：深吸到底後用最快速度吐完的總量
- **FEV1**（第一秒用力呼氣容積）：用力吐氣第一秒吐出的量
- **FEV1/FVC**：正常成人約 0.7–0.8 以上
- 檢查時機與護理（檢查前停用支氣管擴張劑的時間、配合吹氣）見 [[respiratory-assessment#imaging]]

| | 阻塞性 | 限制性（侷限性） |
|---|---|---|
| 問題在哪 | 氣流出不來（呼吸道變窄或塌陷） | 肺撐不開（肺本身變硬或胸壁、肌肉受限） |
| 例子 | **COPD**（肺氣腫、慢性支氣管炎）、**氣喘**、支氣管擴張症 | **肺纖維化**、塵肺症、肥胖、脊柱側彎、**神經肌肉疾病**、大量肋膜積水 |
| FEV1 | **下降** | 下降 |
| FVC | 正常或輕度下降 | **下降** |
| **FEV1/FVC** | **下降(< 0.7)** | **正常或上升** |
| 餘氣容積、肺總量 | **上升**（空氣滯留、過度充氣） | **下降** |
| 一氧化碳擴散量（DLCO，Diffusing capacity of the lung for carbon monoxide） | 肺氣腫下降；氣喘、慢性支氣管炎多正常 | 肺纖維化下降 |

- COPD 的診斷：使用支氣管擴張劑後 **FEV1/FVC < 0.7**；嚴重度依 **FEV1 佔預測值的百分比**分 GOLD 1–4（來源：[GOLD 2026 Report](https://goldcopd.org/2026-gold-report-and-pocket-guide/)），疾病見 [[copd#diagnosis]]
- 氣喘的特徵是**可逆**：給支氣管擴張劑後 FEV1 明顯改善，見 [[asthma]]
- 阻塞早期最先受影響的是小呼吸道；國考答案以 **FEV1 下降**為 COPD 最早出現的變化

## 無效腔與肺泡通氣量 {#dead-space}

- **每分鐘通氣量**＝潮氣容積 × 呼吸次數(500 × 12＝6,000 mL/min)
- **解剖無效腔**：留在傳導區、不參與交換的空氣，成人約 **150 mL**（約等於體重的磅數，150 磅約 150 mL）
- **肺泡無效腔**：有通氣但沒有血流的肺泡，例如**肺栓塞**，見 [[gas-exchange-transport#vq]]
- 生理無效腔＝解剖無效腔＋肺泡無效腔
- **肺泡通氣量＝（潮氣容積－無效腔）× 呼吸次數**，真正參與交換的是這個量

| 呼吸方式 | 每分鐘通氣量 | 肺泡通氣量 |
|---|---|---|
| 正常：500 mL × 12 次 | 6,000 mL | (500－150) × 12＝**4,200 mL** |
| 淺快：200 mL × 40 次 | 8,000 mL | (200－150) × 40＝**2,000 mL** |
| 深慢：1,000 mL × 6 次 | 6,000 mL | (1,000－150) × 6＝5,100 mL |

- **淺快呼吸**看起來喘得很用力，但大部分空氣都在無效腔來回 → 肺泡通氣不足 → **低血氧**、CO₂ 上升
- 所以呼吸訓練教**深而慢**的呼吸；呼吸器設定也要考慮管路增加的無效腔

## 換氣過度與換氣不足 {#hyper-hypoventilation}

| | **換氣過度** | **換氣不足** |
|---|---|---|
| 定義 | 肺泡通氣量**超過**代謝需要 | 肺泡通氣量**不足** |
| PaCO₂(Partial pressure of arterial carbon dioxide) | **< 35 mmHg** | **> 45 mmHg** |
| 酸鹼 | **呼吸性鹼中毒** | **呼吸性酸中毒** |
| 常見原因 | 焦慮、恐慌、疼痛、待產時呼吸過快、高海拔、發燒、肺栓塞早期、水楊酸中毒早期 | COPD 惡化、鎮靜劑或鴉片類過量、神經肌肉疾病、胸壁受限、術後疼痛不敢深呼吸 |
| 症狀 | 頭暈、**口唇與手指麻刺感**、手足抽搐（游離鈣下降） | 頭痛、嗜睡、意識混亂（CO₂ 麻醉） |

- 「換氣過度」不等於「通氣增加」：運動時通氣量增加，但 CO₂ 產生也增加，PaCO₂ 維持正常（這叫呼吸加深加快，不是換氣過度）
- 換氣過度時 O₂ 會略升、CO₂ 明顯下降
- 處置與血氣判讀見 [[abg#respiratory]]
