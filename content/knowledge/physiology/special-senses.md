**感覺器官**把光、聲音、重力、化學物質轉成神經訊號送到大腦。本頁整理眼、耳、平衡、味覺與嗅覺的構造與生理；眼睛疾病見 [[eye-disorders]]，耳朵疾病見 [[ear-disorders]]，腦神經的分布與檢查見 [[cranial-nerves]]，皮膚感覺與痛覺傳導見 [[spinal-cord-spinal-nerves#tracts]]

## 重點摘要 {#summary}

- 眼球三層：**纖維層**（角膜、鞏膜）、**血管層**（脈絡膜、睫狀體、虹膜）、**神經層**（視網膜）；**脈絡膜**富含血管，供應視網膜外層營養
- **房水**由**睫狀突**分泌 → 後房 → 瞳孔 → 前房 → **小樑網 → 許萊姆氏管** → 靜脈；正常眼壓約 10–21 mmHg
- 視網膜：**桿細胞**（暗處、夜視、視紫質需要維生素 A）、**錐細胞**（顏色、明視、集中在中央小窩）；訊號：**感光細胞 → 雙極細胞 → 神經節細胞** → 視神經；**視神經盤**沒有感光細胞是**盲點**
- 視網膜上的影像**上下顛倒、左右相反**，由大腦還原
- 看近的**調節**：睫狀肌收縮（動眼神經的副交感）、水晶體變厚、瞳孔縮小、兩眼內聚
- **近視**焦點在視網膜前（凹透鏡）、**遠視**在視網膜後（凸透鏡）、**老花**是水晶體彈性變差（凸透鏡）
- 視覺徑路：**鼻側纖維在視交叉交叉**；視交叉受壓 → **雙顳側偏盲**；視交叉之後（視徑、視放射、枕葉）受損 → 對側**同側偏盲**
- **耳咽管**連通**中耳與鼻咽**、平衡鼓膜內外壓力；嬰幼兒的耳咽管**短、寬、平**，容易中耳炎
- **耳蝸**柯蒂氏器負責聽覺；**半規管**（壺腹嵴）偵測**旋轉**；**橢圓囊與球囊**（耳石）偵測**直線加速度與重力**
- **味蕾**：**絲狀乳頭沒有味蕾**（數量最多）；**蕈狀乳頭**分布廣、有味蕾；輪廓狀乳頭在舌根排成 V 形、味蕾最多；**鮮味**來自**麩胺酸**

### 國考常考點 {#exam-points}

- 充滿血管、供應眼球與視網膜營養的構造：**脈絡膜**；視網膜**不是**由鞏膜供應營養
- 房水（水樣液）由**睫狀突**分泌
- 調節水晶體曲度的神經：**動眼神經**（副交感）；瞳孔對光反射的傳入神經：**視神經**
- 視網膜傳導順序：**桿細胞與錐細胞 → 雙極細胞 → 神經節細胞**
- 影像在視網膜上**上下顛倒且左右相反**
- 色盲：**錐細胞**基因異常、**視蛋白種類太少**；**X 染色體隱性**、男性多
- 人體對**冷**刺激較敏感：冷接受器在皮膚**淺層**、數量較多；水的導熱力比空氣強，濕冷熱效果較好
- 舌乳頭：**蕈狀乳頭**分布廣且有味蕾；**絲狀乳頭沒有味蕾**；輪廓狀乳頭在舌後半部有味蕾；鮮味與**麩胺酸**有關
- 耳咽管連通**鼻咽與中耳**；嬰幼兒耳咽管**短、寬、平**（不是長、窄、垂直）
- 動態平衡感受器「嵴」位於**半規管**；耳石復位術恢復的是**橢圓囊與球囊**的功能
- 與耳朵功能無關的：**黃斑部退化**（梅尼爾氏症、良性陣發性姿勢性眩暈、動暈症都和內耳有關）
- 老年人聽力退化從**高頻**開始

## 感覺總論 {#general-senses}

| 接受器 | 偵測 | 例子 |
|---|---|---|
| 機械性 | 觸、壓、振動、牽張、聲音、重力 | 皮膚觸覺小體、肌梭、耳蝸毛細胞、耳石 |
| 溫度 | 冷、熱 | 皮膚的冷與熱接受器 |
| 痛覺 | 組織傷害 | 游離神經末梢 |
| 化學性 | 化學物質 | 味蕾、嗅覺細胞、頸動脈體 |
| 光 | 光線 | 視網膜桿細胞與錐細胞 |

- **適應**：持續刺激時反應變小（例如戴久了忘記手錶）；**痛覺幾乎不適應**
- **冷接受器**位置較淺、數量多於熱接受器 → 對冷較敏感；長時間接觸冷熱會**適應**、敏感度下降
- 冷熱與痛覺經**外側脊髓視丘徑**上行；內臟的轉移痛見 [[spinal-cord-spinal-nerves#referred-pain]]

## 味覺與嗅覺 {#taste-smell}

| 舌乳頭 | 位置 | 味蕾 |
|---|---|---|
| **絲狀乳頭** | 遍布舌背，**數量最多** | **沒有**，負責摩擦與觸覺 |
| **蕈狀乳頭** | 舌尖與舌緣，**分布廣** | **有** |
| **輪廓狀乳頭** | **舌根**，排成 V 字形，最大 | **有**，數量最多 |
| 葉狀乳頭 | 舌側後方，人類較退化 | 有 |

- 五種基本味覺：甜、鹹、酸、苦、**鮮味**（**麩胺酸**，味精）
- 味覺神經：舌前 2/3 **顏面神經**(CN VII)、舌後 1/3 **舌咽神經**(CN IX)、會厭附近迷走神經（見 [[cranial-nerves#tongue]]）
- **嗅覺**：鼻腔頂部嗅覺上皮 → 嗅神經(CN I)→ 嗅球 → 直接到大腦嗅覺皮質與邊緣系統（**不經過視丘**），所以氣味和情緒、記憶關係密切
- 老化：味蕾與嗅覺神經元減少，加上藥物影響 → 食慾下降

::questions{ids="106-1_BM_012,115-1_BM_019,111-1_BM_019,105-2_BM_013,111-2_BM_010"}

## 眼睛 {#eye}

::figure{src="/knowledge-images/servier-eye-section.svg" labels="eye-section" alt="眼球水平切面(左為前)：角膜、虹膜、水晶體、睫狀體、玻璃體、視網膜、脈絡膜、鞏膜、視神經盤與視神經"}

| 層 | 構造 | 功能 |
|---|---|---|
| **纖維層**（外） | **角膜** | 透明、**沒有血管**（靠淚液與房水供應）、主要的屈光構造；感覺神經豐富（角膜反射） |
| | **鞏膜** | 白色堅韌，維持眼球形狀、保護 |
| **血管層**（中，葡萄膜） | **脈絡膜** | **富含血管**，供應**視網膜外層**營養；吸收散射光 |
| | **睫狀體** | **睫狀突分泌房水**；睫狀肌調節水晶體 |
| | **虹膜** | 控制瞳孔大小：括約肌（副交感，縮瞳）、放大肌（交感，散瞳） |
| **神經層**（內） | **視網膜** | 感光細胞把光轉成神經訊號 |
| 內容物 | **水晶體** | 透明、可調節曲度；混濁就是**白內障** |
| | 玻璃體 | 膠狀，維持眼球形狀 |
| | **房水** | 供應角膜與水晶體營養、維持**眼壓** |

### 房水循環與眼壓 {#aqueous-humor}

1. **睫狀突**分泌房水到**後房**
2. 經**瞳孔**流到**前房**
3. 從前房角（隅角）的**小樑網**流入**許萊姆氏管**，再回到靜脈
- 正常眼壓約 **10–21 mmHg**；房水排不出去 → 眼壓升高 → 壓壞視神經 → **青光眼**（見 [[eye-disorders#glaucoma]]）

::questions{ids="114-1_MS_014,108-1_BM_016,105-1_MS_024"}

### 視網膜與感光 {#retina}

| | **桿細胞** | **錐細胞** |
|---|---|---|
| 功能 | **暗處與夜間視覺**、對光敏感 | **顏色**、**明亮處的清晰視覺** |
| 色素 | **視紫質**（需要**維生素 A**） | 三種視蛋白（感應紅、綠、藍） |
| 分布 | 視網膜周邊多 | 集中在**黃斑部中央小窩**（視力最清楚） |
| 異常 | 缺維生素 A → **夜盲** | 視蛋白種類少 → **色盲** |

- 訊號傳遞：**桿細胞與錐細胞 → 雙極細胞 → 神經節細胞** → 神經節細胞的軸突集合成**視神經**
- 光要先穿過神經節細胞與雙極細胞層才到達最外側的感光細胞
- **視神經盤**：視神經離開眼球處，沒有感光細胞 → **盲點**
- **色盲**：**X 染色體隱性**遺傳，男性遠多於女性；紅綠色盲最常見
- 視網膜**最外層是色素上皮層**，視網膜剝離是感覺層與色素上皮層分開，失去來自脈絡膜的營養
- 影像經角膜與水晶體折射後在視網膜上**上下顛倒、左右相反**

- 紅綠色盲是 X 性聯隱性遺傳，規則見 [[genetic-inheritance#x-linked-recessive]]

::questions{ids="106-2_makeup_BM_020,110-1_BM_024,114-2_BM_017,111-1_BM_028,108-1_PC_011"}

### 調節與屈光異常 {#refraction}

- **看近的調節**
  1. **睫狀肌收縮**（動眼神經的副交感纖維） → 懸韌帶放鬆 → 水晶體**變厚**、屈光力增加
  2. **瞳孔縮小**
  3. 兩眼**內聚**
- 看遠時睫狀肌放鬆、水晶體變扁

![正視、近視與遠視：光線聚焦的位置與矯正鏡片](/knowledge-images/refraction.svg)

| 屈光異常 | 原因 | 焦點 | 矯正 |
|---|---|---|---|
| **近視** | 眼軸太長或屈光力太強 | 視網膜**前方** | **凹透鏡** |
| **遠視** | 眼軸太短或屈光力太弱 | 視網膜**後方** | **凸透鏡** |
| **老花眼** | 40 歲後水晶體**彈性變差**、看近無法調節 | 看近時落在後方 | **凸透鏡**（閱讀眼鏡） |
| **散光** | 角膜或水晶體各方向弧度不同 | 無法聚成一點 | **圓柱鏡片** |

- 高度近視眼軸長、視網膜被拉薄 → 視網膜剝離風險較高

::questions{ids="106-2_BM_015,107-2_BM_019"}

### 視覺徑路與視野缺損 {#visual-pathway}

![視覺徑路與損傷位置的視野缺損：視神經、視交叉、視徑、枕葉皮質](/knowledge-images/visual-pathway.svg)

- 路徑：**視網膜 → 視神經 → 視交叉 → 視徑 → 視丘的外側膝狀體 → 視放射 → 枕葉視覺皮質**
- 在視交叉，**鼻側視網膜的纖維交叉**到對側，顳側纖維不交叉；所以每一側的大腦接收**對側視野**
- 損傷位置與視野

| 損傷位置 | 視野缺損 |
|---|---|
| 一側**視神經** | 同側眼**全盲** |
| **視交叉中央**（**腦下垂體腫瘤**由下往上壓，見 [[pituitary-disorders#adenoma]]） | **雙顳側偏盲**（兩眼外側都看不到） |
| 一側**視徑**、視放射 | 對側**同側偏盲**（兩眼的同一側都看不到） |
| 一側**枕葉皮質** | 對側同側偏盲，常**保留黃斑**（中央視力） |

- 中風的視野缺損與照護見 [[stroke#hemisphere]]；顱內腫瘤壓迫對視覺的影響見 [[brain-tumors#manifestations]]

::questions{ids="109-2_MS_004"}

### 淚器與眼外肌 {#accessory-structures}

- 淚液路徑：**淚腺**（眼眶外上方；顏面神經的副交感支配）→ 眼表 → 內眥的**淚點** → 淚小管 → 淚囊 → **鼻淚管** → 鼻腔下鼻道；所以點眼藥後**壓住內眥淚點**可減少藥物流到鼻腔、被全身吸收
- 淚液含**溶菌酶**，有保護作用；老化時淚液量與品質下降（乾眼）
- 六條眼外肌與支配神經（外直肌 CN VI、上斜肌 CN IV、其餘 CN III）見 [[cranial-nerves#extraocular-muscles]]

::questions{ids="106-2_BM_003,114-2_PC_043"}

## 耳朵與聽覺 {#ear}

::figure{src="/knowledge-images/servier-ear.svg" labels="ear" alt="外耳、中耳、內耳切面(左為外側)：耳廓、外耳道、鼓膜、聽小骨、耳咽管、半規管、耳蝸與前庭耳蝸神經"}

| 部位 | 構造 | 功能 |
|---|---|---|
| **外耳** | 耳廓、**外耳道**（耵聹腺分泌耳垢） | 收集聲音、保護 |
| **中耳** | **鼓膜**、三塊**聽小骨**（錘骨 → 砧骨 → 鐙骨）、**耳咽管** | 把聲波**放大**並傳到內耳的卵圓窗；**耳咽管**連通中耳與**鼻咽**，平衡鼓膜內外壓力、引流分泌物 |
| **內耳** | **耳蝸**（聽覺）、**前庭**（橢圓囊、球囊）與**半規管**（平衡） | 把振動轉成神經訊號，經**前庭耳蝸神經**(CN VIII)送到腦幹 |

- 聲音傳導：外耳道 → **鼓膜** → 錘骨 → 砧骨 → **鐙骨** → 卵圓窗 → 耳蝸內淋巴液波動 → **柯蒂氏器毛細胞**彎曲 → 耳蝸神經 → 腦幹 → 顳葉聽覺皮質
- 耳蝸**底部**感應**高頻**、頂端感應低頻；**老年性聽損從高頻開始**
- **耳咽管**：吞嚥、打哈欠時打開；感冒或過敏時阻塞 → 中耳負壓與積液；搭飛機下降時吞嚥或嚼口香糖可平衡壓力
- **嬰幼兒的耳咽管短、寬、較水平** → 鼻咽的細菌容易進入中耳，所以**中耳炎**較多（見 [[pediatric-respiratory-infections]]）

### 聽力喪失的種類與音叉試驗 {#hearing-loss}

| | **傳導性** | **感覺神經性** |
|---|---|---|
| 病變位置 | **外耳或中耳**（耳垢、中耳炎、鼓膜破裂、耳硬化症） | **內耳或聽神經**（老化、噪音、耳毒性藥物、梅尼爾氏症、聽神經瘤） |
| **任內試驗**(Rinne) | 患耳**骨導 ≥ 氣導**（陰性） | **氣導 > 骨導**（陽性，和正常一樣，只是時間都縮短） |
| **韋伯試驗**(Weber) | 偏向**患耳**（患耳較大聲） | 偏向**健耳** |
| 噪音中 | 反而聽得較清楚 | 更聽不清楚 |

- 聽力檢查與聽力障礙的照護見 [[ear-disorders#hearing-loss]]

## 平衡 {#balance}

| 構造 | 感受器 | 偵測 |
|---|---|---|
| **橢圓囊、球囊** | 斑(macula)，上有**耳石** | **靜態平衡**：頭部位置、**重力**與**直線加速度** |
| **半規管**（三條互相垂直） | 壺腹內的**壺腹嵴**(crista) | **動態平衡**：頭部**旋轉**（角加速度） |

- 前庭的訊號經前庭神經到腦幹前庭核與小腦，配合視覺與本體感覺維持平衡
- **良性陣發性姿勢性眩暈**(BPPV)：**橢圓囊的耳石脫落**掉進半規管，頭部轉到某個位置時引發短暫眩暈；用**耳石復位術**（Epley 法）把耳石移回橢圓囊
- **動暈症**：視覺與前庭訊號不一致；scopolamine 貼片或抗組織胺預防（見 [[cholinergic-drugs#antimuscarinics]]）
- 內耳疾病（梅尼爾氏症、BPPV、前庭神經炎）見 [[ear-disorders#vertigo]]；**黃斑部退化**是眼睛的病，和耳朵無關

## 兒童與老化 {#development-aging}

- 新生兒出生時就有**瞳孔對光反射**與眨眼反射；**出生頭幾個月偶爾斜視**是正常的，之後持續斜視要轉介；剛出生哭泣時沒有眼淚是正常的
- 嬰兒最早發展的知覺是**觸覺**（胎兒期就有反應）
- 老化：老花眼、白內障、淚液減少、瞳孔變小（需要更多光線）、**高頻聽力**先下降、嗅覺與味覺減退
