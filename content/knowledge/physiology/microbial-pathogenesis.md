**微生物**(microorganism)包括細菌、病毒、真菌、原蟲，廣義上也把蠕蟲與不含核酸的**普利昂**(prion)一起討論。它們致病的方式不同：細菌靠**侵襲力與毒素**，病毒必須**進入細胞借用宿主的機器複製**，普利昂則是**錯誤摺疊的蛋白質**。這一頁整理微免總論最常考的觀念，也是之後各病原體頁、抗生素頁的基礎。

## 微生物的分類 {#classification}

| 類別 | 細胞型態 | 核酸 | 細胞壁 | 繁殖 | 代表 | 抗生素有效嗎 |
|---|---|---|---|---|---|---|
| **普利昂** | 無細胞，只有蛋白質 | **無** | 無 | 誘導正常蛋白錯誤摺疊 | 庫賈氏病、狂牛症 | 無效，一般滅菌也不易破壞 |
| **病毒** | 無細胞 | **DNA 或 RNA 其中一種** | 無 | **組合**(assembly)，只能在活細胞內 | 流感、HIV、疱疹 | **無效**(用抗病毒藥) |
| **細菌** | **原核**，單細胞 | DNA 與 RNA 都有 | 多數有**胜肽聚醣** | **二分裂** | 葡萄球菌、大腸桿菌 | 有效 |
| 特殊細菌 | 原核 | 都有 | 黴漿菌**無細胞壁** | 立克次體、披衣菌為**絕對細胞內寄生** | 黴漿菌、立克次體、披衣菌 | 部分有效(β-lactam 對黴漿菌無效) |
| **真菌** | **真核**，單細胞(酵母菌)或多細胞(黴菌) | 都有 | **幾丁質、葡聚醣** | 無性或有性 | 念珠菌、麴菌 | 無效(用抗黴菌藥) |
| **原蟲** | 真核，單細胞 | 都有 | 無 | 多樣 | 瘧原蟲、阿米巴 | 用抗寄生蟲藥 |
| **蠕蟲** | 真核，多細胞 | 都有 | 無 | 有性生殖、產卵 | 蛔蟲、吸蟲、絛蟲 | 用驅蟲藥 |

### 細菌與真菌的比較 {#bacteria-vs-fungi}

| 項目 | 細菌 | 真菌 |
|---|---|---|
| 細胞 | **原核**(無核膜) | **真核** |
| 細胞數 | 單細胞 | **不一定是多細胞**：酵母菌(如念珠菌)是單細胞，黴菌是多細胞菌絲 |
| 細胞壁 | 胜肽聚醣 | **幾丁質與葡聚醣**，沒有胜肽聚醣，所以對 penicillin **無感受性** |
| 細胞膜固醇 | 無(黴漿菌例外，培養要加固醇) | **麥角固醇**(ergosterol)，是抗黴菌藥的作用目標 |
| 生殖 | 無性(二分裂) | 無性與有性 |
| 光合作用 | 少數(藍綠菌) | **不能行光合作用** |

- **細菌沒有膜狀胞器**：沒有**粒線體、溶酶體、中心體、葉綠體**、內質網與高基氏體；細胞質內有**核糖體**(70S，動物細胞為 80S)，也可能有**質體**(plasmid)。細胞壁是細菌有、動物細胞沒有的構造。

### 科霍假說 {#koch-postulates}

科霍(Robert Koch)提出判斷「某病原造成某病」的原則：病原要在每個病例找得到、可以**分離培養**、接種到健康宿主會引起同樣疾病、並能再次分離出同一病原。

它的限制是：**無法人工培養**的病原(如痲瘋分枝桿菌、梅毒螺旋體)、**無症狀帶原者**、以及**不是感染造成的疾病**(例如**帕金森氏症**)都不適用。

## 細菌的構造 {#bacterial-structure}

### 革蘭氏染色 {#gram-stain}

步驟：**結晶紫**(初染) → **碘液**(媒染) → **酒精脫色** → **番紅**(safranin，複染)。細胞壁厚的細菌能留住結晶紫而呈**紫色**；細胞壁薄、外層有外膜的細菌被酒精脫色後，染上番紅而呈**紅色**。

| 項目 | **革蘭氏陽性菌**(G+) | **革蘭氏陰性菌**(G−) |
|---|---|---|
| 顏色 | **藍紫色** | **紅色**(與番紅相同) |
| 胜肽聚醣層 | **厚** | 薄 |
| 壁酸、脂壁酸(teichoic、lipoteichoic acid) | **有** | 無 |
| 外膜 | 無 | **有**(細胞壁外還有一層外膜) |
| **脂多醣**(LPS，內毒素) | **無** | **有** |
| 芽孢 | **只有 G+ 會形成**(芽孢桿菌屬 *Bacillus*、梭狀芽孢桿菌屬 *Clostridium*) | 不形成 |
| 代表菌 | 葡萄球菌、鏈球菌、腸球菌、梭狀芽孢桿菌、李斯特菌、白喉桿菌 | 大腸桿菌、克雷白氏菌、綠膿桿菌、奈瑟氏菌、沙門氏菌、弧菌 |

:::tip[判斷技巧]
題目說「染出與番紅相同的顏色」＝革蘭氏陰性：**有外膜與內毒素、沒有脂壁酸、不會形成芽孢**，例如大腸桿菌。
:::

**不適合革蘭氏染色的細菌**：分枝桿菌細胞壁含大量**分枝菌酸**(mycolic acid)，要用**抗酸性染色**(acid-fast stain)；黴漿菌沒有細胞壁；立克次體、披衣菌太小且寄生在細胞內；螺旋體太細，要用暗視野顯微鏡。

### 表面構造與芽孢 {#surface-structures}

| 構造 | 成分 | 功能與考點 |
|---|---|---|
| **莢膜**(capsule) | 多為**多醣** | **抵抗吞噬作用**，是重要的毒力因子；肺炎鏈球菌、b 型嗜血桿菌、腦膜炎雙球菌的疫苗就是針對莢膜 |
| 線毛(pilus、fimbriae) | 蛋白質 | 附著在宿主細胞(如大腸桿菌附著尿道上皮)；**性線毛**用於接合作用 |
| 鞭毛(flagellum) | 蛋白質 | 運動 |
| **芽孢**(內孢子，endospore) | 多層厚壁、含吡啶二羧酸鈣 | 營養不足時形成的休眠構造，**耐熱、耐乾燥、耐化學消毒劑**；滅菌的定義就是要殺死芽孢 |

### 細菌的生長 {#growth}

- **生長曲線**：遲滯期 → **對數期**(log phase，分裂最快，**對作用在細胞壁的抗生素最敏感**) → 靜止期 → 死亡期。
- **氧氣需求**：絕對需氧(結核菌、綠膿桿菌)、兼性厭氧(大腸桿菌、葡萄球菌)、**絕對厭氧**(梭狀芽孢桿菌、類桿菌)。

### 細菌遺傳與基因轉移 {#gene-transfer}

| 方式 | 媒介 | 說明 |
|---|---|---|
| **轉化作用**(transformation) | 環境中的**游離 DNA** | Griffith 實驗：無毒的肺炎雙球菌加入**死亡有毒菌的 DNA(核酸)**，就變成有毒菌 |
| **導入作用**(轉導，transduction) | **噬菌體**(phage) | 噬菌體把一個細菌的基因帶到另一個細菌 |
| **接合作用**(conjugation) | **性線毛**，常傳遞**質體** | 抗藥性質體(R 因子)在細菌間擴散的主要方式 |

「**分泌作用**」不是基因轉移的方式。基因轉移讓抗藥性快速擴散，詳見[[antibiotics-overview#resistance]]。

## 細菌的致病機轉 {#pathogenesis}

### 侵襲力 {#invasiveness}

1. **附著**：線毛、黏附素。
2. **侵入與擴散**：玻尿酸酶、鏈球菌激酶(溶解血塊)、凝固酶(金黃色葡萄球菌，形成纖維蛋白外殼)。
3. **逃避免疫**：
   - 莢膜抗吞噬。
   - **在吞噬細胞內存活**：抑制吞噬體與溶酶體融合或逃出吞噬體，例如**結核分枝桿菌、退伍軍人菌、李斯特菌、鼠疫桿菌、土倫桿菌、布氏桿菌、沙門氏菌**。**破傷風桿菌不是**細胞內寄生菌，它靠外毒素致病。
4. **造成傷害**：毒素，或引起過度的發炎反應。

### 外毒素與內毒素 {#toxins}

| 項目 | **外毒素**(exotoxin) | **內毒素**(endotoxin) |
|---|---|---|
| 來源 | 活菌**分泌**；G+ 與 G− 都可能產生 | **G− 細胞壁外膜的脂多醣**，**細菌死亡、溶解後才釋出** |
| 化學成分 | **蛋白質** | 脂多醣(毒性部位是 **lipid A**) |
| 毒性 | **極強**，作用專一 | 較弱，作用全身而非專一 |
| 耐熱 | 多數**不耐熱** | **耐熱** |
| 可做成類毒素疫苗 | **可以**(破傷風、白喉類毒素) | 不行 |
| 表現 | 依毒素而定(見下表) | **發燒**、**活化補體**、刺激巨噬細胞釋放細胞激素(IL-1、TNF-α)、血管擴張、**敗血性休克**、瀰漫性血管內凝血、急性呼吸窘迫症候群 |

內毒素是**促進**發炎反應，不是抑制。**大腸桿菌引起的敗血性休克**是內毒素造成的。

| 外毒素 | 作用機轉 | 結果 |
|---|---|---|
| **白喉毒素** | 使延長因子 EF-2 失活，**抑制蛋白質合成** | 偽膜、**心肌炎**、神經炎 |
| **破傷風毒素**(痙攣毒素) | **神經毒素**，阻斷抑制性神經傳遞物質(甘胺酸、GABA)釋放 | **痙攣性麻痺**、牙關緊閉、角弓反張 |
| **肉毒桿菌毒素** | **神經毒素**，阻斷乙醯膽鹼釋放 | **弛緩性麻痺**、複視、吞嚥困難、呼吸衰竭 |
| **霍亂毒素** | 腸毒素，使腸細胞 **cAMP 上升**，大量分泌水與電解質 | **米湯樣水瀉**；**不會破壞腸壁細胞** |
| 百日咳毒素 | 使細胞 cAMP 上升 | 淋巴球增多、陣發性咳嗽 |
| 炭疽毒素 | 水腫毒素與致死毒素 | 水腫、組織壞死 |
| 金黃色葡萄球菌腸毒素、**毒性休克症候群毒素**(TSST-1) | 腸毒素耐熱；TSST-1 是**超抗原**，非專一地大量活化 T 細胞 | 食物中毒嘔吐；毒性休克症候群 |
| 化膿性鏈球菌紅斑毒素 | 超抗原 | **猩紅熱**的紅疹 |
| 志賀毒素 | 抑制蛋白質合成 | 血便、溶血性尿毒症候群(也見於腸道出血性大腸桿菌 O157:H7) |

## 病毒 {#viruses}

### 構造 {#virus-structure}

- **核酸**：只含 **DNA 或 RNA 其中一種**，絕不會兩種都有。
- **蛋白殼**(capsid)：包住核酸。核酸加蛋白殼稱為核蛋白殼(nucleocapsid)。
- **套膜**(envelope)：部分病毒在出芽時**帶走宿主細胞膜**，上面插有**病毒的醣蛋白**，負責與目標細胞結合。
- **分節基因體**(segmented genome)：核酸分成數段，兩株病毒同時感染一個細胞時可以**交換片段**。代表是**正黏液病毒**(流感病毒，8 段)與輪狀病毒；彈狀病毒(狂犬病)、小 RNA 病毒(腸病毒)、黃病毒(登革熱)都不分節。流感的**抗原轉移**(shift)就是片段重組造成的([[respiratory-viral-infections#influenza-virus]])。

| 項目 | **有套膜病毒** | **無套膜病毒**(裸露病毒) |
|---|---|---|
| 對乾燥、胃酸、膽汁、清潔劑、**乙醚與酒精** | **敏感**，容易被破壞 | **抵抗力強** |
| 傳播 | 多靠飛沫、血液、體液、性行為等直接接觸 | 環境中存活久，常經**糞口傳染** |
| 例子 | 疱疹病毒家族、**HIV**、**B 型肝炎**、流感、麻疹、冠狀病毒、狂犬病、登革熱 | **腺病毒**、**腸病毒**(含小兒麻痺)、**諾羅病毒**、**輪狀病毒**、**A 型肝炎**、E 型肝炎、HPV |

:::exam[國考重點]
- 腸病毒、諾羅病毒沒有套膜，**酒精效果有限**，要用**含氯漂白水**：一般環境 **500 ppm**，病人分泌物或排泄物污染的物品 **1,000 ppm**([衛福部腸病毒消毒新聞稿](https://www.mohw.gov.tw/fp-16-74190-1.html))。冷凍不能殺死腸病毒。
- 套膜「不能」使病毒更耐乾燥與酸，反而讓病毒更脆弱。
:::

### 複製步驟 {#replication}

**附著**(attachment) → **穿入**(penetration) → **去殼**(uncoating) → **巨分子合成**(核酸複製、蛋白質合成) → **組合**(assembly) → **釋出**(出芽或細胞裂解)。

- 病毒沒有核糖體，**一定要借用宿主的核糖體進行轉譯**(translation)；不是所有病毒都有自己的核酸聚合酶。
- 病毒以**組合**的方式產生下一代，**不是二分裂**；對抗生素**沒有感受性**。

| 病毒核酸 | 複製重點 |
|---|---|
| DNA 病毒 | 多數在**細胞核**內複製(痘病毒例外，在細胞質) |
| **正股(+)單股 RNA** | 本身就能當 mRNA，**直接轉譯出病毒蛋白**(如腸病毒、冠狀病毒、黃病毒) |
| **負股(−)單股 RNA** | 要先用病毒自帶的 RNA 聚合酶轉成正股才能轉譯(如流感、麻疹、狂犬病) |
| **反轉錄病毒** | 用**反轉錄酶**把 RNA **先轉成 DNA**，再嵌入宿主基因體(如 HIV) |

**RNA 病毒突變率高**：RNA 依賴型 RNA 聚合酶(RdRp)與反轉錄酶(RNA 依賴型 DNA 聚合酶)**缺乏校正功能**，複製錯誤不會被修正。這也是流感每年要重新配製疫苗、HIV 容易產生抗藥性的原因。

### 組織趨向性 {#tropism}

病毒只感染特定細胞，主要取決於**宿主細胞表面的受體**，其次是細胞內的轉錄因子與物理環境(溫度、pH)；細胞膜的脂肪組成影響最小。

| 病毒 | 病毒蛋白 | 宿主受體 |
|---|---|---|
| **HIV** | gp120 | 輔助型 T 細胞的 **CD4** 加上趨化激素共同受體(CCR5 或 CXCR4) |
| **EB 病毒** | gp350／gp220 | **B 細胞**的 C3d 補體受體(CR2、CD21) |
| **A 型流感病毒** | 血球凝集素(HA) | 呼吸道上皮的**唾液酸** |
| 狂犬病病毒 | G 蛋白 | 神經肌肉接合處的**乙醯膽鹼受體**；腦中可見 **Negri 小體** |
| 小病毒 B19 | — | 紅血球前驅細胞的 **P 抗原**(所以「狂犬病病毒與紅血球 P 抗原」是錯誤配對) |

### 病毒感染的型態 {#infection-patterns}

| 型態 | 說明 | 例子 |
|---|---|---|
| 急性感染 | 短期內清除 | 流感、腸病毒 |
| **潛伏感染** | 病毒躲在細胞內不複製，日後再活化 | **疱疹病毒家族**(帶狀疱疹、唇疱疹復發) |
| 慢性感染 | 持續複製 | B 型、C 型肝炎，HIV |
| 轉形感染 | 導致細胞癌化 | HPV、EBV、HBV(見[[neoplasia]]) |
| **無症狀感染** | 沒有症狀，但**仍可能散播病毒** | 很多病毒感染都是 |

- 無症狀感染的機率因病毒而異；慢性感染不一定無症狀；初期無症狀不代表後期輕微。
- **病毒逃避免疫的方式**：流感病毒以**抗原漂移、抗原轉移**改變外套抗原；**疱疹病毒**潛伏在神經細胞內，不被免疫系統辨認；HIV 感染並破壞**輔助型 T 細胞**(CD4)，而且突變快。HIV **不是超級抗原**；超級抗原是金黃色葡萄球菌的毒性休克症候群毒素、化膿性鏈球菌的致熱外毒素這類細菌毒素。
- 感染後**終身免疫**：血清型單一的病毒，例如**德國麻疹**、麻疹、腮腺炎、水痘。腸病毒、腺病毒、流感病毒有很多血清型或會變異，可以反覆感染。

### 病毒的散播 {#virus-transmission}

- **垂直感染**：病毒由母體傳給胎兒或新生兒(如 B 型肝炎、HIV、德國麻疹)。
- **糞口傳染**：以**無套膜病毒居多**，因為要耐得住胃酸與膽汁。
- **病媒傳染**：節肢動物媒介病毒(如登革熱、日本腦炎)**必須能在病媒蚊體內複製**。
- 抑制病毒在族群散播最好的方式是**疫苗接種**。

## 普利昂 {#prions}

- **只有蛋白質、沒有核酸**：錯誤摺疊的普利昂蛋白會誘導正常蛋白也錯誤摺疊，在腦中堆積，造成**海綿狀腦病變**(庫賈氏病、新型庫賈氏病、狂牛症)。
- 不引起發炎與免疫反應，潛伏期長，病程進展快且致命。
- 對一般消毒與滅菌方法**抵抗力極強**；疾管署《滅菌監測感染控制措施指引》把普利昂污染的器械列為「先清潔、後消毒或滅菌」順序的**唯一例外**，須依專門的處理程序。

## 真菌與寄生蟲概要 {#fungi-parasites-overview}

- **真菌**：真核；酵母菌(單細胞，出芽生殖，如念珠菌、隱球菌)、黴菌(多細胞菌絲，如麴菌、皮癬菌)、**雙相型真菌**(體溫下是酵母菌、室溫下是黴菌)。細胞膜的**麥角固醇**是 azoles 與 amphotericin B 的作用目標。
- **原蟲**：單細胞真核生物，如痢疾阿米巴、梨形鞭毛蟲、陰道滴蟲、弓漿蟲、瘧原蟲。
- **蠕蟲**：多細胞，包括線蟲、吸蟲、絛蟲；組織內的蠕蟲感染常見**嗜酸性白血球增加**([[complete-blood-count#differential]])。
- **體外寄生蟲**：疥蟲、頭蝨；病媒節肢動物：蚊、蜱、蚤、恙蟎。

## 感染鏈與宿主防禦 {#chain-of-infection}

### 感染鏈六環 {#chain-links}

| 環節 | 說明 | 打斷的方法 |
|---|---|---|
| 1. **病原體** | 細菌、病毒、真菌等 | 早期診斷、治療；清潔、消毒、滅菌 |
| 2. **傳染窩** | 病原生存繁殖的地方：人(病人、帶原者)、動物、環境 | 環境清潔、處理污物、病媒防治 |
| 3. **出口** | 呼吸道、腸胃道、泌尿生殖道、血液、皮膚傷口 | 咳嗽禮節、戴口罩、正確處理排泄物與分泌物 |
| 4. **傳染途徑** | 接觸(直接、間接)、飛沫、空氣、共同媒介物(食物、水)、病媒 | **手部衛生**(最重要)、隔離措施、個人防護裝備 |
| 5. **入口** | 通常與出口相同；侵入性管路、傷口 | 無菌技術、管路照護、傷口照護 |
| 6. **易感宿主** | 年齡、營養、免疫力、慢性病、侵入性治療 | 預防接種、營養、控制慢性病 |

護理措施與隔離的細節，之後在感染管制頁整理。

### 感染的過程 {#infection-stages}

- **潛伏期**：病原進入到出現症狀之前。
- **前驅期**：出現非特異性症狀(倦怠、低燒)，**傳染力常在此時最強**。
- **疾病期**(發病期)：出現該病特有的症狀。
- **恢復期**：症狀消退。

名詞：**定殖**(colonization)是病原存在並繁殖但沒有造成組織傷害；**帶原者**沒有症狀但會排出病原；**伺機性感染**是在宿主免疫力下降時，平常不致病的微生物才造成感染。

### 宿主的防禦 {#host-defense}

- **第一道防線**：完整的皮膚與黏膜、纖毛、胃酸、淚液與唾液中的溶菌酶、**正常菌叢**(競爭養分與附著位置)。
- **第二道防線**：發炎反應、吞噬作用、補體、發燒。
- **第三道防線**：後天免疫(抗體、T 細胞)。

廣效抗生素破壞**正常菌叢**，會讓致病菌(如困難梭狀桿菌、念珠菌)趁機增生，也會影響消化與黏膜免疫；但與骨髓造血功能無關。

## 微生物控制概要 {#microbial-control}

| 名詞 | 定義 |
|---|---|
| **滅菌**(sterilization) | 殺死**所有**微生物，**包括細菌芽孢**，達到完全無菌 |
| 消毒(disinfection) | 殺死大部分致病微生物，但不一定能殺死芽孢；分高、中、低層次 |
| 清潔(cleaning) | 去除污垢與有機物，是消毒與滅菌的**前提** |
| 防腐(antisepsis) | 在**皮膚、組織**上抑制或殺死微生物 |

**抵抗力由強到弱**：普利昂 ＞ **細菌芽孢** ＞ 分枝桿菌 ＞ **無套膜病毒** ＞ 真菌 ＞ 一般細菌 ＞ **有套膜病毒**。

| 方法 | 作用機轉與重點 |
|---|---|
| **高壓蒸氣滅菌** | 濕熱**傳導比乾熱好**；重力式滅菌鍋 **121℃** 下包裝物品最少 **30 分鐘**，132℃ 最少 15 分鐘(疾管署 2013 滅菌監測指引表一)。常見錯誤選項：「100℃、15 分鐘」 |
| **酒精**(70–75%) | **使蛋白質變性、破壞細胞膜**；**70% 比 95% 有效**(需要水分才能使蛋白質變性，95% 會讓表面蛋白質快速凝固形成保護層)；**不能殺芽孢** |
| **戊二醛**(glutaraldehyde，2%，Cidex) | 使蛋白質與核酸**烷基化**；**高層次消毒劑**，長時間浸泡可殺芽孢；用於**內視鏡**、呼吸治療器材 |
| 過氧化氫 | 氧化作用；3% 可去除管路上的血漬與痰痂；**過氧化氫電漿**用於**不耐熱的塑膠器材**低溫滅菌 |
| **紫外線** | 使 DNA 形成胸腺嘧啶二聚體；**穿透力差**，只能消毒直接照射的表面 |
| 石碳酸類(如來舒 Lysol) | 使蛋白質變性、破壞細胞膜；不可用於嬰兒用品與玩具 |
| 含氯漂白水 | 氧化作用；可殺無套膜病毒 |
| **巴斯德消毒法** | 用於**牛奶、果汁**；只是消毒，不是滅菌 |

各種消毒劑的濃度、Spaulding 分類與無菌技術，之後在無菌技術與消毒滅菌頁詳細整理。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 革蘭氏陽性菌：**紫色**、胜肽聚醣**厚**、有脂壁酸、**沒有脂多醣**、只有它會形成**芽孢**。
- 內毒素是 **G− 的脂多醣**，**細菌死亡後釋出**，會**活化補體、引起發燒與敗血性休克**。
- 白喉毒素**抑制蛋白質合成**；破傷風與肉毒桿菌毒素是**神經毒素**；霍亂毒素使 cAMP 上升造成水瀉，不會讓腸細胞穿孔。
- 噬菌體傳遞基因＝**導入作用**；肺炎雙球菌實驗證明遺傳物質是 **DNA**。
- 莢膜(多醣)**抵抗吞噬**。
- **腺病毒**沒有套膜，能抵抗乙醚；病毒一定要借用宿主核糖體**轉譯**。
- 病毒複製順序：附著穿入 → 去殼 → 合成 → 組合 → 釋出。
- 科霍假說不適用於**非感染性疾病**(帕金森氏症)。
:::
