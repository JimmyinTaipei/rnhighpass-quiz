細胞是生物體最基本的構造與功能單位。本頁整理人體組成階層、解剖術語與體腔、細胞膜與胞器、細胞核與蛋白質合成、膜運輸、細胞週期、有機化合物與上皮組織；細胞的傷害與適應見 [[cell-injury-adaptation]]，遺傳與染色體見 [[genetic-inheritance]]，體液與滲透壓見 [[fluid-electrolytes]]，神經細胞的膜電位見 [[neuron-synapse]]。文中縮寫：ATP(Adenosine Triphosphate，三磷酸腺苷)、DNA(Deoxyribonucleic Acid，去氧核糖核酸)、RNA(Ribonucleic Acid，核糖核酸)、rRNA(ribosomal RNA，核糖體 RNA)

## 重點摘要 {#summary}

- **組成階層**：化學 → 細胞 → 組織 → 器官 → 系統 → 個體；**DNA 屬化學階層**；**細胞**是最基本的構造與功能單位
- **細胞膜**：磷脂雙層＋蛋白質＋膽固醇＋少量醣類(醣萼)，**沒有核酸**；細胞骨架在細胞質，不是細胞膜產生的
- **膜的層數**
   1. **雙層膜**：**粒線體**、細胞核
   2. 單層膜：內質網、高基氏體、溶小體、過氧化體
   3. **沒有膜**：核糖體、核仁、中心粒
- **胞器功能**：粒線體 → **ATP**；高基氏體 → 修飾、**分類、包裝、運送**；溶小體 → 水解酶；核仁 → **rRNA**；中心體 → 紡錘體；泛素 → 標記蛋白質**降解**
- **膜運輸**：擴散與滲透不耗能；**初級主動運輸直接用 ATP**(鈉鉀幫浦、鈣幫浦)；**次級主動運輸靠電化學梯度**(鈉鈣交換子、鈉－葡萄糖共同運輸)
- **有絲分裂**：前期染色體凝集 → **中期排在赤道板** → 後期分向兩極 → 末期分成兩個細胞

### 國考常考點 {#exam-points}

- DNA 屬於**化學**階層
- 左季肋區被肋骨刺傷大出血 → **脾臟**；腹部九分區最下方水平線通過**髂嵴**
- 腹腔與骨盆腔之間沒有實質分隔，積水互通
- 雙層膜胞器：**粒線體**(核糖體、溶小體、過氧化體、高基氏體都不是)
- 主要由膜構成的胞器：**內質網**(核仁、核糖體、中心粒沒有膜)
- 粒線體內腔充滿**基質**；粒線體 DNA **不和組蛋白結合**；提供身體大部分(不是 20%)的 ATP
- 腺嘌呤(A)配**胸腺嘧啶(T)**；醣基化是**轉譯後修飾**；核仁製造 **rRNA**
- 醣萼的功能：**細胞辨識與環境互動**
- 鈉鉀幫浦是**主動運輸**；初級主動運輸子是**鈣幫浦**(鈣通道、鈉鈣交換子不是)
- 中心體被破壞 → **有絲分裂**無法完成
- 碳水化合物 C：H：O ＝ **1：2：1**；動物性脂肪的**飽和脂肪**比植物性多；磷脂質含脂肪酸
- 肌腱是緻密結締組織，**沒有上皮**；食道是複層鱗狀上皮、主支氣管是有纖毛的假複層柱狀上皮

## 人體的組成與解剖術語 {#body-organization}

1. **組成階層**：化學(原子、分子，如 DNA、蛋白質)→ **細胞** → 組織 → 器官 → 器官系統 → 個體
2. **解剖學姿勢**：身體直立、面向前、雙臂垂於兩側、**手掌向前**、雙腳平行
3. **體腔**
   1. 背側體腔：顱腔、脊椎腔
   2. 腹側體腔：**胸腔**(兩側胸膜腔、縱膈與心包腔)與**腹骨盆腔**
   3. **腹腔與骨盆腔之間沒有實質分隔**，腹水會流到骨盆腔
   4. 胸膜只包肺臟(心臟由**心包膜**包)；腹膜不包所有腹腔器官，**腎臟、胰臟**等是**腹膜後器官**
4. **腹部九分區**：兩條垂直的鎖骨中線＋兩條水平線(上方**肋下線**、下方**髂嵴**連線或髂結節間線)
   1. 右季肋區：肝臟、膽囊；上腹區：胃、部分肝臟；**左季肋區：脾臟**、胃的一部分
   2. 左下肋骨骨折要想到**脾臟破裂**，右下肋骨骨折要想到肝臟

## 細胞膜與細胞連接 {#cell-membrane}

1. **流體鑲嵌模型**：**磷脂雙層**為骨架，鑲嵌**蛋白質**(通道、載體、受體)、**膽固醇**，外側有**醣蛋白與醣脂**；**不含核酸**
2. **醣萼**(glycocalyx)：細胞膜外側的醣鏈，負責**細胞辨識**(自己與外來)、與環境互動，也和血型抗原有關
3. 細胞膜的功能：物質運輸、**訊息傳遞**(受體)、**細胞辨識與黏附**；**細胞骨架**(微管、微絲、中間絲)在細胞質裡，不是細胞膜產生的
4. 細胞連接

| 連接 | 功能 |
|---|---|
| 緊密接合 | 封住細胞間隙，防止物質從細胞間漏過 |
| 胞橋小體 | 把細胞牢牢連在一起(皮膚、心肌) |
| **間隙接合(裂隙結合)** | 由連接子形成通道，離子直接流到隔壁細胞 → **電性突觸**、心肌同步收縮 |

5. 黴菌與人類細胞最大的不同是**細胞壁**；細菌是原核生物，只有**核糖體**、沒有溶小體等膜狀胞器(見 [[microbial-pathogenesis]])

## 胞器 {#organelles}

| 胞器 | 膜 | 功能 |
|---|---|---|
| **粒線體** | **雙層**(內膜摺成嵴，內腔為**基質**) | 有氧呼吸、氧化磷酸化產生**大部分的 ATP**；有自己的環狀 DNA(母系遺傳、**不和組蛋白結合**)，但大部分蛋白質仍由細胞核 DNA 編碼 |
| 細胞核 | 雙層(核膜有核孔) | 儲存 DNA、轉錄 |
| 粗糙內質網 | 單層 | 附有核糖體，合成分泌與膜蛋白 |
| 平滑內質網 | 單層 | 合成脂質與類固醇、解毒、儲存鈣(肌漿網) |
| **高基氏體** | 單層 | 修飾、**分類、包裝與運送**蛋白質與脂質 |
| **溶小體** | 單層 | 含**水解酶**，分解廢物與外來物；細胞凋亡時參與分解 |
| 過氧化體 | 單層 | 分解過氧化氫、脂肪酸氧化 |
| **核糖體** | **沒有膜** | 合成蛋白質(細菌 70S、人類 80S) |
| 中心體(中心粒) | 沒有膜 | 微管組織中心，分裂時形成**紡錘體** |

1. **泛素**(ubiquitin)：和要分解的蛋白質結合，把它送到**蛋白酶體降解**；幫蛋白質摺疊的是分子伴侶(熱休克蛋白)
2. 心肌等耗能多的細胞粒線體多

## 細胞核與蛋白質合成 {#nucleus}

1. **核仁**：沒有膜，製造 **rRNA** 並組裝核糖體
2. **DNA 鹼基配對**：A－**T**(兩個氫鍵)、G－C(三個氫鍵)；RNA 沒有 T，A 配 **U**
3. 蛋白質合成：DNA →(**轉錄**)→ mRNA →(**轉譯**，核糖體)→ 胺基酸鏈 → **轉譯後修飾**(**醣基化**、磷酸化、摺疊，在內質網與高基氏體)
4. 轉錄後修飾是針對 mRNA(剪接、加帽加尾)，不是蛋白質
5. **巴氏體**＝X 染色體數 − 1；Klinefelter(XXY)最多 1 個(見 [[chromosomal-disorders]])

## 細胞膜的運輸 {#membrane-transport}

| 方式 | 能量 | 方向 | 例子 |
|---|---|---|---|
| 簡單擴散 | 不耗能 | 高 → 低濃度 | 氧、二氧化碳、脂溶性物質 |
| 促進性擴散 | 不耗能 | 高 → 低，需載體或通道 | 葡萄糖進入多數細胞、**離子通道**(鈣通道、鉀通道) |
| **滲透** | 不耗能 | **水**經半透膜由低溶質往高溶質 | |
| **初級主動運輸** | **直接水解 ATP** | 逆濃度 | **鈉鉀幫浦**(送出 3 Na⁺、送入 2 K⁺)、**鈣幫浦**、氫鉀幫浦 |
| **次級主動運輸** | 利用初級運輸建立的**電化學梯度** | 一個順、一個逆 | **鈉鈣交換子**(反向)、鈉－葡萄糖共同運輸(同向) |
| 胞吞、胞吐 | 耗能 | 大分子、顆粒 | 吞噬作用、分泌 |

1. 滲透壓濃度：葡萄糖不解離，1 莫耳溶於 1 公升水 ＝ **1 Osm/L**；NaCl 解離成 2 個粒子 → 2 Osm/L
2. 細胞外鉀濃度上升 → 鉀外流的驅動力變小 → 靜止膜電位變小(較不負)(見 [[neuron-synapse]])

::questions{ids="115-1_BM_001,114-2_BM_011,106-2_BM_017,110-1_BM_022,105-2_BM_017,109-2_BM_017"}

## 細胞週期與分裂 {#cell-cycle}

1. 細胞週期：G1 → **S**(DNA 複製)→ G2 → **M**(分裂)；不分裂的細胞停在 G0
2. 有絲分裂各期

| 期 | 重點 |
|---|---|
| 前期 | 染色質**凝集**成染色體、核膜消失、紡錘體形成 |
| **中期** | 染色體排列在**赤道板** |
| 後期 | 姊妹染色分體**分離**向兩極 |
| 末期 | 核膜重新形成、細胞質分裂 |

3. **中心體**被破壞 → 紡錘體做不出來 → **有絲分裂**無法完成；DNA 複製、轉錄、轉譯不受影響
4. **神經元**是永久性細胞，成熟後不再分裂(各種細胞的分裂能力見 [[cell-injury-adaptation#cell-types]])

::questions{ids="108-2_BM_017,107-1_BM_008,107-1_MS_039"}

## 有機化合物與能量 {#organic-compounds}

1. **碳水化合物**：通式 Cn(H₂O)n，C：H：O ＝ **1：2：1**(葡萄糖 C₆H₁₂O₆)
2. **脂質**：疏水、不溶於水
   1. **飽和脂肪酸**沒有雙鍵，**動物性脂肪**含量較多，室溫多為固態；植物油、魚油多為不飽和
   2. **磷脂質**＝甘油＋**脂肪酸**＋磷酸根，是細胞膜的主成分
   3. 脂蛋白：乳糜微粒在腸道形成(VLDL 是肝臟另外分泌的)；**LDL 脂質比例高、蛋白質少**所以密度低(見 [[lipid-profile]])
3. **胺基酸**：非必需胺基酸是人體**能自行合成**，不是不需要
4. **能量**：劇烈運動時肌肉以**葡萄糖**無氧糖解產生少量 ATP 與乳酸；脂肪完全氧化需要醣類代謝的產物，醣類不足會產生過多**酮體**

::questions{ids="111-1_BM_017,107-1_BM_017,110-2_BM_032,112-2_FA_043,111-2_FA_043,114-2_FA_027,111-1_BM_018"}

## 上皮組織 {#epithelium}

1. 四大基本組織：**上皮**、結締、肌肉、神經
2. 上皮覆蓋體表、襯在管腔與體腔、形成腺體；細胞排列緊密、有基底膜、沒有血管
3. **肌腱、韌帶、真皮**是結締組織，**沒有上皮**

| 部位 | 上皮 |
|---|---|
| 血管內皮、肺泡 | 單層鱗狀 |
| 胃、小腸(絨毛)、**膽囊** | **單層柱狀** |
| **主支氣管**、氣管 | **假複層纖毛柱狀** |
| **食道**、口腔、陰道、皮膚 | **複層鱗狀** |
| 膀胱 | 移形上皮 |

4. 腺體(如子宮腺)由上皮衍生；腦下腺**後葉**是神經組織衍生，不是上皮
