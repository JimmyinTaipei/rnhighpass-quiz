**自主神經系統**(又稱自律神經)不需要意識控制，負責支配**心肌、平滑肌與腺體**，維持心跳、血壓、消化、排尿與體溫等內在恆定。它分成**交感神經**(緊急時的「戰或逃」)和**副交感神經**(平時的「休息與消化」)，多數器官同時接受兩者支配、作用互相拮抗。作用在這些受體的藥物見 [[cholinergic-drugs]] 與 [[adrenergic-agonists]]

## 重點摘要 {#summary}

- 自主神經的傳出路徑由**兩個神經元**組成：**節前神經元**(細胞體在腦幹或脊髓)→ 自主神經節 → **節後神經元** → 作用器官；體運動神經只有一個神經元直達骨骼肌
- **交感**：節前細胞體在**胸腰髓 T1–L2 的側角**；神經節靠近脊髓(交感神經鏈、腹腔神經節等)，所以**節前短、節後長**
- **副交感**：節前細胞體在**腦幹(CN III、VII、IX、X)與薦髓 S2–S4**；神經節靠近或位在器官壁內，所以**節前長、節後短**
- 傳遞物質：**所有節前纖維都釋放 ACh**、神經節上是 **N 受體**；副交感節後釋放 **ACh → M 受體**；交感節後多數釋放**正腎上腺素 → α、β 受體**，**汗腺例外**(交感節後釋放 ACh → M 受體)
- **腎上腺髓質**相當於交感神經節，節前纖維直接支配，分泌**腎上腺素(約 80%)**與正腎上腺素入血
- 交感興奮：**心跳快、收縮力強、瞳孔放大、支氣管擴張、唾液少而黏、腸胃蠕動變慢、肝醣分解、血糖上升、豎毛肌收縮**；副交感大致相反，並使**淚液、唾液分泌增加**、**瞳孔縮小**、**排尿**
- 排尿與排便反射的中樞在**薦髓 S2–S4**；T6 以上脊髓損傷在脊髓休克期過後可能發生**自主神經反射異常**，最常見的誘因是**膀胱脹**

### 國考常考點 {#exam-points}

- 副交感神經**節後**神經元分泌 **乙醯膽鹼(ACh)**；刺激淚腺大量分泌淚液的也是 ACh
- 副交感使心跳變慢，主要經由**蕈毒鹼型(M)受體**(心臟是 M2)；迷走神經興奮時**心跳速率與傳導速度都變慢**；**切斷迷走神經 → 心跳加快**
- 交感活化 → **心跳變快、收縮力增加**(β1)
- 促進**脂肪分解**的是 **β3** 受體；造成**皮膚與腹腔內臟血管收縮**的是 **α(α1)** 受體
- 腎上腺素直接造成**唾液分泌減少**；睫狀肌收縮是副交感作用、腎上腺素促進肝醣**分解**而非合成
- **阻斷 M 受體 → 心跳速率上升**(支氣管擴張、腸胃活性下降、瞳孔放大)
- 壓力、警覺期、被追著跑：交感興奮 → **瞳孔放大**、支氣管擴張；「瞳孔縮小」「支氣管收縮」是副交感作用，是常見的錯誤選項
- 副交感興奮的反應：**瞳孔收縮**；支氣管舒張、肝醣分解增加都是交感
- **雞皮疙瘩**是交感使豎毛肌收縮，與**副交感無關**(豎毛肌沒有副交感支配)
- 焦慮伴隨的身體症狀主要是**自主神經系統反應**
- 交感節前神經元細胞體在**脊髓**(胸腰段側角)；**第二薦髓不屬於交感起源**(是副交感)
- **白交通枝**內是**交感節前纖維**(有髓鞘)；灰交通枝是交感節後纖維
- **大內臟神經**的節前纖維來自**胸段脊髓**(約 T5–T9)
- 副交感神經節：**翼腭神經節**(屬顱部副交感)；上頸神經節是交感，前庭神經節與背根神經節是感覺神經節，**背根神經節不屬於自主神經節**
- 支配**耳下腺**分泌的是**耳神經節**(CN IX)
- 副交感興奮時排尿：**逼尿肌收縮、尿道內括約肌放鬆**
- 排便：直腸壓力受器的訊息傳到**骨盆(薦髓 S2–S4)排便反射中樞**；中樞不在 L3–L4，外括約肌由隨意控制
- **S2–S4 完全損傷 → 溢尿性(弛緩型)神經性膀胱**，膀胱容量大、無法反射排空，屬下運動神經元型
- 自主神經反射異常：**最常見原因是膀胱脹**；發生在**脊髓休克期之後**；病灶以下的皮膚**蒼白**、以上**潮紅冒汗**；血壓極高合併**心跳變慢**；是急症要**立即處理**

## 自主神經與體神經 {#overview}

![交感、副交感與體運動神經的神經元數目、神經傳遞物質與受體](/knowledge-images/autonomic-pathways.svg)

| | 體神經(運動) | 自主神經 |
|---|---|---|
| 作用器官 | 骨骼肌 | 心肌、平滑肌、腺體 |
| 控制 | 隨意 | 不隨意 |
| 神經元數目 | 一個(脊髓前角或腦幹 → 骨骼肌) | **兩個**(節前 → 神經節 → 節後) |
| 傳遞物質與受體 | ACh → 骨骼肌 N 受體 | 見下方受體一節 |
| 對作用器官的影響 | 只有興奮 | 可興奮也可抑制 |
| 去除神經後 | 骨骼肌**癱瘓萎縮** | 平滑肌與心肌仍有自發活動，只是失去調節 |

- 自主神經的傳入(感覺)纖維把內臟的牽張、化學訊息帶回中樞，經**下視丘**、**腦幹**(心血管、呼吸中樞)與脊髓整合
- 下視丘是自主神經的最高整合中樞，邊緣系統的情緒也會經下視丘引起自主神經反應(緊張時心悸、冒汗)

## 交感與副交感的起源與神經節 {#origins}

| | 交感(胸腰系統) | 副交感(顱薦系統) |
|---|---|---|
| 節前細胞體 | **T1–L2 脊髓側角**(灰質中間外側柱) | **腦幹**的 CN III、VII、IX、X 核；**薦髓 S2–S4** |
| 神經節位置 | 靠近脊髓：**交感神經鏈**(椎旁神經節)、**椎前神經節**(腹腔、上腸繫膜、下腸繫膜神經節) | 靠近或位在**器官壁內**(終末神經節) |
| 節前／節後長度 | 節前**短**、節後**長** | 節前**長**、節後**短** |
| 分布範圍 | 全身(包括皮膚血管、汗腺、豎毛肌) | 頭部、胸腹腔與骨盆的內臟；**不支配**皮膚、大部分血管、汗腺、豎毛肌 |
| 反應 | 一條節前纖維接觸很多節後神經元 → **廣泛、全身性** | 較**局部、個別** |

### 交感神經的走法 {#sympathetic-route}

- 節前纖維從脊髓**前根**出來 → 經**白交通枝**(節前纖維**有髓鞘**，所以是白色)進入交感神經鏈，之後有三種走法
  1. 在同一節或上下移動後的椎旁神經節換神經元 → 節後纖維經**灰交通枝**(無髓鞘)回到脊神經 → 皮膚血管、汗腺、豎毛肌
  2. 在頸部神經節換神經元(**上頸神經節**等)→ 頭頸部與胸腔器官(瞳孔放大肌、心臟、肺)
  3. **穿過神經鏈不換神經元**，形成**內臟神經**，到椎前神經節才換：**大內臟神經**(來自**胸髓約 T5–T9**)→ 腹腔神經節；小內臟神經 → 上腸繫膜神經節；腰內臟神經 → 下腸繫膜神經節
- **腎上腺髓質**：節前纖維直接到達，不換神經元；髓質細胞相當於節後神經元，分泌兒茶酚胺入血
- 白交通枝只出現在 T1–L2；灰交通枝每一對脊神經都有

### 副交感神經的走法 {#parasympathetic-route}

| 節前纖維 | 神經節 | 支配 |
|---|---|---|
| **動眼神經**(CN III) | **睫狀神經節** | 瞳孔括約肌(縮瞳)、睫狀肌(看近) |
| **顏面神經**(CN VII) | **翼腭神經節** | **淚腺**、鼻腔與上顎腺體 |
| 顏面神經(CN VII) | **下頜下神經節** | 下頜下腺、舌下腺 |
| **舌咽神經**(CN IX) | **耳神經節** | **耳下腺** |
| **迷走神經**(CN X) | 器官壁內的終末神經節 | 心臟、肺、食道、胃、小腸、肝胰、**近端大腸(約到橫結腸前 2/3)** |
| **骨盆內臟神經**(S2–S4) | 器官壁內的終末神經節 | 遠端結腸、直腸、膀胱、生殖器 |

- 迷走神經帶了約 75% 的副交感纖維；腦神經的副交感功能見 [[cranial-nerves#parasympathetic-glands]]
- 自主神經節的種類：交感神經鏈、椎前神經節(腹腔、上腸繫膜)、顱部副交感神經節(睫狀、翼腭、下頜下、耳)；**背根神經節、前庭神經節**內是感覺神經元的細胞體，**不是**自主神經節

## 神經傳遞物質與受體 {#receptors}

### 膽鹼性與腎上腺素性纖維 {#fibers}

- **膽鹼性纖維**(釋放 ACh)：所有節前纖維、**副交感節後**、交感節後到**汗腺**的纖維、體運動神經
- **腎上腺素性纖維**(釋放正腎上腺素)：其餘交感節後纖維
- 作用結束的方式不同
  - ACh：在突觸間隙被**乙醯膽鹼酯酶(AChE)**分解成膽鹼與醋酸，所以作用短暫；抑制 AChE 的藥物與毒物見 [[cholinergic-drugs#anticholinesterases]]
  - 正腎上腺素：主要被神經末梢**回收**(再攝取)，其餘被 **MAO** 與 **COMT** 分解；從腎上腺髓質進入血液的兒茶酚胺作用比神經直接釋放的更持久、更廣泛

### 受體種類與主要作用 {#receptor-types}

| 受體 | 主要位置 | 活化後的作用 |
|---|---|---|
| **N_N**(神經節型菸鹼受體) | 所有自主神經節、腎上腺髓質 | 節後神經元興奮、腎上腺髓質分泌 |
| **N_M**(肌肉型菸鹼受體) | 骨骼肌神經肌肉接合處 | 骨骼肌收縮 |
| **M1** | 中樞、胃壁細胞 | 認知；胃酸分泌 |
| **M2** | **心臟**(竇房結、房室結、心房) | **心跳變慢、房室傳導變慢**、心房收縮力下降 |
| **M3** | 平滑肌、外分泌腺、血管內皮 | 支氣管收縮、腸胃蠕動增加、**瞳孔括約肌與睫狀肌收縮**、逼尿肌收縮、腺體分泌(淚液、唾液、汗液)、內皮釋放 NO 使血管擴張 |
| **α1** | 血管平滑肌(皮膚、腹腔內臟)、瞳孔放大肌、括約肌、豎毛肌、前列腺 | **血管收縮**、瞳孔放大、膀胱內括約肌與腸胃括約肌收縮、雞皮疙瘩 |
| **α2** | 突觸前神經末梢、中樞、胰島 β 細胞 | **抑制正腎上腺素釋放**(負回饋)、交感輸出 ↓、胰島素分泌 ↓ |
| **β1** | **心臟**、腎臟近腎絲球細胞 | **心跳加快、收縮力增加、傳導加快**；**腎素分泌** |
| **β2** | **支氣管**、骨骼肌與冠狀血管、子宮、肝臟、睫狀肌 | **支氣管擴張**、骨骼肌血管擴張、子宮放鬆、**肝醣分解**、睫狀肌放鬆(看遠) |
| **β3** | **脂肪組織**、膀胱逼尿肌 | **脂肪分解**、逼尿肌放鬆 |
| D1 | 腎臟與腸繫膜血管 | 血管擴張(低劑量 dopamine 增加腎血流) |

- 同一種傳遞物質在不同器官作用不同，**取決於受體**：例如 ACh 使心臟變慢(M2)、卻使腸胃收縮(M3)
- **阻斷 M 受體**等於拿掉副交感，交感作用相對顯現：心跳上升、支氣管擴張、腸胃活性下降、瞳孔放大、口乾、尿滯留(抗膽鹼藥的作用與副作用見 [[cholinergic-drugs#antimuscarinics]])
- 各受體在血壓調節上的角色見 [[blood-pressure-regulation#autonomic-receptors]]

## 交感與副交感對各器官的作用 {#effects}

| 器官 | 交感(受體) | 副交感(M 受體) |
|---|---|---|
| **瞳孔** | 放大肌收縮 → **瞳孔放大**(α1) | 括約肌收縮 → **瞳孔縮小** |
| 睫狀肌 | 放鬆 → 看遠(β2) | **收縮** → 看近(調節) |
| 淚腺 | — | **分泌淚液** |
| **唾液腺** | **量少、黏稠**(α1) | **量多、稀薄** |
| **心臟** | **心跳加快、收縮力增加**、傳導加快(β1) | **心跳變慢、傳導變慢**、心房收縮力下降(M2) |
| **支氣管** | **擴張**(β2) | **收縮**、分泌增加 |
| 腸胃道 | 蠕動與分泌**減少**、括約肌**收縮** | 蠕動與分泌**增加**、括約肌放鬆 |
| 肝臟 | **肝醣分解**、糖質新生 → **血糖上升**(β2、α1) | 肝醣合成 |
| 胰臟 | 胰島素分泌減少(α2) | 胰液、胰島素分泌增加 |
| **脂肪組織** | **脂肪分解**(β3) | — |
| 腎臟 | **腎素分泌**(β1) | — |
| **膀胱** | 逼尿肌**放鬆**(β2、β3)、內括約肌**收縮**(α1)→ 儲尿 | 逼尿肌**收縮**、內括約肌**放鬆** → **排尿** |
| 皮膚與腹腔內臟血管 | **收縮**(α1) | 多數沒有副交感支配 |
| 骨骼肌血管 | 擴張(β2) | — |
| **汗腺** | **分泌增加**(交感節後釋放 ACh → M) | — |
| **豎毛肌** | 收縮 → **雞皮疙瘩**(α1) | 沒有副交感支配 |
| 腎上腺髓質 | 分泌腎上腺素與正腎上腺素(N_N) | — |
| 男性生殖 | 射精 | 勃起 |

- 記法：交感把血液與能量送到**心臟、肺、骨骼肌**(逃跑用)，暫停消化與排泄；副交感負責**吃完飯後的消化、排泄與儲存**
- 迷走神經持續有張力讓靜止心跳維持在約 70 次／分(竇房結本身約 100 次／分)，所以**切斷迷走神經會心跳加快**；切斷迷走也會使胃液分泌減少
- 淚腺與唾液腺受副交感支配，所以抗膽鹼藥會**口乾、眼乾**

### 壓力反應與自主神經 {#stress}

- 面對壓力(一般適應症候群的**警覺期**)時，下視丘活化交感神經與腎上腺髓質，出現**心跳加快、血壓上升、血糖上升、瞳孔放大、支氣管擴張、冒汗、肌肉緊繃、口乾、新陳代謝上升**
- 同時下視丘–腦下垂體–腎上腺軸使皮質醇分泌增加(較慢、較持久)
- **焦慮**伴隨的心悸、出汗、呼吸急促、肌肉緊繃，主要是自主神經系統的反應(焦慮程度與護理見 [[anxiety-disorders]])

## 內臟的自主反射 {#visceral-reflexes}

### 排尿反射 {#micturition}

| 神經 | 來源 | 作用 |
|---|---|---|
| **骨盆神經**(副交感) | **S2–S4** | 逼尿肌**收縮**、內括約肌**放鬆** → 排尿 |
| 腹下神經(交感) | T11–L2 | 逼尿肌放鬆、內括約肌收縮 → 儲尿 |
| 陰部神經(體神經) | S2–S4 | **外括約肌**(骨骼肌)，可隨意控制 |

- 膀胱充滿 → 牽張受器 → 薦髓排尿中樞 → 副交感使逼尿肌收縮；大腦皮質與腦橋排尿中樞可以抑制或啟動這個反射

### 排便反射 {#defecation}

- 糞便進入直腸 → **直腸壁壓力受器**受刺激 → 訊息傳到**薦髓 S2–S4 排便反射中樞**
- 骨盆神經(副交感)使直腸收縮、**肛門內括約肌**(平滑肌)放鬆；**外括約肌**是骨骼肌，由陰部神經隨意控制，所以可以「忍住」

### 脊髓損傷後的神經性膀胱 {#neurogenic-bladder}

| | 上運動神經元型(反射型、痙攣型) | 下運動神經元型(弛緩型、溢尿型) |
|---|---|---|
| 損傷位置 | **S2 以上**(薦髓排尿中樞完好，但與大腦失去聯繫) | **S2–S4 薦髓**或馬尾、骨盆神經 |
| 膀胱 | 容量**小**、逼尿肌不自主收縮 | 容量**大**、逼尿肌無力 |
| 排尿 | 可利用**反射排尿**(敲擊恥骨上方、刺激大腿內側)，但排不乾淨 | 無法反射排空、尿液滿了才溢出 → **溢尿性**；用**間歇導尿**、Credé 或 Valsalva 法，可用膽鹼性藥物(bethanechol)增加逼尿肌收縮(見 [[cholinergic-drugs#direct-agonists]]) |

- 脊髓休克期(數天到數週)所有反射消失，膀胱都是弛緩、尿滯留，需要導尿(見 [[spinal-cord-spinal-nerves#spinal-shock]])

### 自主神經反射異常 {#autonomic-dysreflexia}

- 發生在 **T6 以上**的脊髓損傷、**脊髓休克期過後**
- 病灶以下的有害刺激(**最常見是膀胱脹**，其次是便秘與糞便嵌塞、壓瘡、緊的衣物)→ 引發病灶以下大範圍**交感反射**、血管收縮 → **嚴重高血壓**
- 壓力受器感覺到血壓升高 → 迷走神經使**心跳變慢**；但從腦往下抑制交感的訊號過不了損傷處，血管收縮無法解除
- 表現：**陣發性劇烈頭痛**、血壓突然升高、心搏過緩、**病灶以上潮紅與冒汗**、鼻塞，病灶以下皮膚**蒼白**、起雞皮疙瘩
- 處理是急症
  1. 立刻**讓病人坐起**、雙腳放低，鬆開緊的衣物
  2. 每 2–5 分鐘量血壓
  3. **找出並移除誘因**：先檢查膀胱與導尿管(有沒有扭折、阻塞)，需要時導尿；再檢查直腸(用含局部麻醉劑的潤滑劑)
  4. 血壓仍高時依醫囑給降壓藥
