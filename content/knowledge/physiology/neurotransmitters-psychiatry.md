精神科用藥幾乎都是在「調高或調低某一種神經傳導物質」，所以只要先記住**哪個物質太多、哪個太少會出現什麼症狀**，再記住**藥物擋住哪個受體**，大部分藥理題與副作用題都能推出答案。本頁整理國考最常考的多巴胺四條路徑、單胺假說、GABA 與麩胺酸，以及與精神疾病相關的腦區。

疾病頁：[[schizophrenia]]；藥物頁：[[antipsychotics]]。

## 重點摘要 {#summary}

- 精神科用藥幾乎都是在「調高或調低某一種神經傳導物質」，先記**哪個物質太多、太少會出現什麼症狀**，再記藥物擋哪個受體。
- **多巴胺有四條路徑**；思覺失調症與多巴胺**過高**有關，藥物擋多巴胺，所以副作用像巴金森氏症。
- **單胺假說**：憂鬱症 = 血清素與正腎上腺素**不足**；躁症 = 兒茶酚胺（DA、NE）**過多**；焦慮 = 正腎上腺素過高、GABA 不足。
- 壓力與 **HPA 軸**相關；受體被阻斷會造成副作用（見受體與副作用對照）。

### 國考常考點 {#exam-points}

- 思覺失調症 → 多巴胺**過高**（不是過低）；巴金森氏症 → 黑質多巴胺**不足**。
- 血清素**過少**（不是過多）與自殺有關。
- 躁症 → 兒茶酚胺過多；焦慮 → 正腎上腺素過高、GABA 不足。

## 神經傳導物質總覽 {#overview}

| 物質 | 主要來源 | 主要功能 | 太多 | 太少 | 相關藥物 |
|---|---|---|---|---|---|
| **多巴胺**(DA) | 中腦**腹側被蓋區**(VTA)、**黑質** | 動機、獎賞、思考、動作協調、抑制泌乳素 | **思覺失調症正性症狀**、躁症 | **巴金森氏症**、負性症狀、憂鬱(缺乏動力與快樂) | 抗精神病藥擋 D2；levodopa 補多巴胺 |
| **血清素**(5-HT) | 腦幹**縫核**(raphe nuclei) | 情緒、睡眠、食慾、衝動控制、疼痛 | 血清素症候群 | **憂鬱、自殺、衝動攻擊**、焦慮；強迫症與血清素失調有關 | SSRI、SNRI、TCA、MAOI |
| **正腎上腺素**(NE) | 腦幹**藍斑核**(locus coeruleus) | 警覺、注意力、壓力反應(戰或逃) | **焦慮、恐慌**、**躁症**、酒精戒斷的交感亢進 | **憂鬱**(疲倦、注意力差) | SNRI、TCA；clonidine 降低戒斷時的 NE |
| **GABA** | 全腦的中間神經元 | 中樞**最主要的抑制性**物質 | 過度鎮靜 | **焦慮**、失眠、癲癇 | **BZD**、巴比妥鹽、酒精都增強 GABA-A |
| **麩胺酸**(Glutamate) | 大腦皮質、海馬 | 中樞**最主要的興奮性**物質、學習記憶 | 神經毒性(中風、癲癇後細胞死亡) | NMDA 受體功能低下 → 思覺失調症(含負性與認知症狀)的假說 | Ketamine(NMDA 拮抗劑)可快速抗憂鬱；memantine 治療失智 |
| **乙醯膽鹼**(ACh) | 基底前腦(Meynert 基底核)、紋狀體中間神經元 | 記憶、注意力；在紋狀體與多巴胺互相平衡 | 紋狀體內相對過多 → 類巴金森症狀 | **阿茲海默症**的記憶衰退 | 抗膽鹼藥(biperiden)治 EPS；AChE 抑制劑治失智 |
| **組織胺**(H1) | 下視丘 | 清醒 | — | 被阻斷 → **嗜睡、體重增加** | 多數抗精神病藥與 TCA 的副作用來源 |

- 胜肽類神經傳導物質的代表是 **P 物質**(substance P，痛覺傳遞)、腦內啡；胰島素是**激素**，不是神經傳導物質。
- 雙相情緒障礙症與單胺類(DA、5-HT、NE)失調有關，**與腦內啡沒有直接關係**。

:::exam[國考重點]
- 思覺失調症 → 多巴胺**過高**(不是過低)。
- 憂鬱症 → 血清素與正腎上腺素**不足**；血清素**過少**(不是過多)與自殺有關。
- 躁症 → 兒茶酚胺(DA、NE)**過多**。
- 焦慮 → 正腎上腺素過高、GABA 不足。
- 巴金森氏症 → 黑質多巴胺**不足**；思覺失調症用藥擋多巴胺，所以副作用就像巴金森氏症。
:::

## 多巴胺四條路徑 {#dopamine-pathways}

多巴胺路徑是思覺失調症的症狀、抗精神病藥的療效和副作用的共同答案。抗精神病藥(D2 拮抗劑)沒辦法只擋其中一條，所以「擋對地方 → 療效；擋錯地方 → 副作用」。

| 路徑 | 起點 → 終點 | 正常功能 | 思覺失調症時 | 藥物擋 D2 後 |
|---|---|---|---|---|
| **中腦邊緣**(mesolimbic) | VTA → 依核、邊緣系統 | 獎賞、情緒、動機 | **過度活躍** → **幻覺、妄想**(正性症狀) | ✔ **療效**：正性症狀改善 |
| **中腦皮質**(mesocortical) | VTA → **前額葉皮質** | 思考、計畫、動機、情感表達 | **活性不足** → **負性症狀**(情感平淡、動機缺乏)與**認知障礙** | ✘ 可能使負性症狀更明顯(續發性負性症狀) |
| **黑質紋狀體**(nigrostriatal) | **黑質** → 紋狀體(基底核) | 動作協調 | 通常正常 | ✘ **錐體外徑症候群**(EPS)、遲發性運動異常 |
| **結節漏斗**(tuberoinfundibular) | 下視丘 → 腦下垂體前葉 | 多巴胺**抑制泌乳素** | 通常正常 | ✘ **高泌乳素血症**：溢乳、月經不規則、男性女乳症、性功能障礙 |

- 另外，延腦的**化學感受器觸發區**(CTZ)也有 D2 受體，所以抗精神病藥大多**有止吐作用**(prochlorperazine、metoclopramide 的止吐原理相同)，而這些止吐藥也會造成 EPS 與 NMS。
- **第二代抗精神病藥**比較少 EPS 的原因：對 **5-HT2A** 的阻斷大於 D2(5-HT2A 阻斷會讓黑質紋狀體釋出較多多巴胺)、與 D2 受體結合較「鬆」、較集中作用在邊緣系統與皮質(來源：[UpToDate：Second-generation antipsychotic medications](https://www.uptodate.com/contents/second-generation-antipsychotic-medications-pharmacology-administration-and-side-effects))。Clozapine 對 D2 的親和力低，是 EPS 最少的抗精神病藥。
- 抗精神病效果大約需要占據 **65% 的 D2 受體**，這也是所有抗精神病藥的共同機轉(aripiprazole 屬於 D2 **部分致效劑**，例外)。

:::tip[記憶法]
**邊緣 → 幻覺妄想；皮質 → 負性認知；黑質 → 動作；漏斗 → 泌乳素。**
「正性多、負性少」：正性症狀是多巴胺太多(邊緣)，負性症狀是多巴胺太少(皮質)。
:::

## 受體與副作用對照 {#receptor-side-effects}

精神科藥物的副作用大多可以從「它還擋了哪些受體」推出來。抗精神病藥與三環抗憂鬱劑(TCA)都同時擋很多受體。

| 被阻斷的受體 | 造成的副作用 | 代表藥物 |
|---|---|---|
| **D2**(黑質紋狀體) | EPS、遲發性運動異常 | 高效價第一代：haloperidol |
| **D2**(結節漏斗) | 泌乳素上升 | haloperidol、**risperidone、paliperidone** |
| **M1 蕈毒鹼**(抗膽鹼) | **口乾、便秘、尿滯留、視力模糊**、心跳加快、意識混亂(老人) | chlorpromazine、**clozapine**、olanzapine、TCA |
| **α1 腎上腺素** | **姿勢性低血壓**、頭暈、反射性心跳加快 | chlorpromazine、clozapine、risperidone、TCA |
| **H1 組織胺** | **嗜睡**、**體重增加** | chlorpromazine、clozapine、olanzapine、quetiapine、mirtazapine |
| **5-HT2C** | 食慾增加、體重增加 | olanzapine、clozapine |
| **5-HT2A** | (阻斷是好事)減少 EPS | 大多數第二代 |

- 口訣：抗膽鹼作用就是「**乾、秘、尿、看不清**」，老人要注意譫妄、跌倒與尿滯留；**青光眼、攝護腺肥大**的人要小心使用。
- Clozapine 雖然抗膽鹼作用很強，卻常見**流口水**(不是口乾)，原因與吞嚥反射變差有關(來源：[UpToDate：Second-generation antipsychotic medications](https://www.uptodate.com/contents/second-generation-antipsychotic-medications-pharmacology-administration-and-side-effects))。

## 血清素與正腎上腺素：單胺假說 {#monoamine}

### 單胺假說 {#monoamine-hypothesis}

- **憂鬱症**：腦中的單胺類(**血清素、正腎上腺素**，以及多巴胺)功能不足。抗憂鬱劑都是在增加突觸間的單胺：阻止再回收(SSRI、SNRI、TCA)或阻止分解(MAOI)。
- **躁症**：兒茶酚胺(**NE、DA**)功能過度亢進(兒茶酚胺假說)。
- 單胺假說不完整：抗憂鬱劑**當天**就提高突觸間的血清素，但情緒改善要 **2–4 週**以上，因此目前認為還牽涉受體數量調整(下調)、神經可塑性與腦源性神經滋養因子(BDNF)。這也是國考常考「服藥初期不要因為沒效就自行停藥」的原理。

### 血清素與自殺、強迫症 {#serotonin-clinical}

- 自殺身亡者的腦脊髓液中，血清素代謝物(5-HIAA)**偏低**，與衝動和攻擊行為有關。
- **強迫症**與血清素失調有關，所以治療以 SSRI 為主(通常需要較高劑量、較長時間)。

## 壓力與 HPA 軸 {#hpa-axis}

- 壓力 → **下視丘**分泌 CRH → **腦下垂體**分泌 ACTH → **腎上腺皮質**分泌**皮質醇**。皮質醇正常情況下會回頭抑制下視丘與腦下垂體(負回饋)。
- 許多重度憂鬱症病人的 HPA 軸**過度活化**、皮質醇**偏高**，負回饋變差。過去用**地塞米松抑制試驗**(DST)來看：正常人服用 dexamethasone 後皮質醇會被抑制，部分憂鬱症病人**抑制不下來**。DST 現在不作為診斷工具，但仍是國考考點。
- 長期高皮質醇與海馬迴體積變小有關，這可以連到憂鬱症的記憶與專注力問題。
- 壓力反應同時牽涉前額葉與邊緣系統，HPA 軸是個體面對壓力時主要的調節系統。

## 與精神疾病有關的腦區 {#brain-regions}

| 腦區 | 功能 | 與精神疾病的關係 |
|---|---|---|
| **前額葉** | 計畫、判斷、解決問題、抑制衝動、工作記憶 | 思覺失調症「前額葉功能低下」→ 負性與認知症狀；額葉受損 → 人格改變、判斷力差、失去抑制 |
| **邊緣系統** | 情緒與記憶 | 包含**海馬迴、杏仁核**、扣帶迴等；黑質、松果腺、基底核**不屬於**邊緣系統 |
| **海馬迴** | 形成**新的**記憶 | 受損 → **順向失憶**(記不住新事物)；阿茲海默症早期受影響；憂鬱症與長期壓力時體積變小 |
| **杏仁核** | **恐懼**與情緒記憶 | 受損 → 失去害怕的感覺；焦慮症、創傷後壓力症時過度活躍 |
| **下視丘** | 自主神經、體溫、食慾、睡眠、HPA 軸 | 憂鬱症的食慾、睡眠改變；抗精神病藥影響體溫調節(NMS、中暑) |
| **基底核**(紋狀體) | 動作的啟動與協調 | 受損或多巴胺不足 → 巴金森氏症；抗精神病藥 → EPS |
| **黑質** | 製造多巴胺送往紋狀體 | 神經元退化 → **動作遲緩**、顫抖(巴金森氏症) |
| **腦幹縫核 / 藍斑核** | 分別製造血清素 / 正腎上腺素 | 單胺假說的源頭 |

- 思覺失調症病人的影像研究常見**側腦室擴大**、灰質減少(尤其前額葉與顳葉)，但沒有一項可以用來診斷。
- 思考如何解決問題時，**額葉**活性最高；表達性失語症是額葉的**布洛卡區**受損。
