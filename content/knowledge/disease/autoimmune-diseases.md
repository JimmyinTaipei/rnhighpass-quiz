**自體免疫疾病**是免疫系統**失去對「自己」的耐受**，攻擊自身組織所造成的疾病。它可以只影響**單一器官**(器官特異性，例如橋本氏甲狀腺炎)，也可以是**全身性**(例如 SLE)。這一頁先講共同的機轉，再把常考的疾病整理成表，並連到各自的頁面

## 重點摘要 {#summary}

- **耐受失敗**：**中樞耐受**(胸腺與骨髓清除自體反應細胞)與**周邊耐受**(Treg、anergy、凋亡)都出問題
- **原因**是遺傳(**HLA 是最主要的遺傳因子**)與環境(感染、**分子模擬**、紫外線、藥物、荷爾蒙)交互作用
- **女性較多**，發生率是男性數倍，性別偏向是自體免疫的線索之一
- **傷害機轉**由**第Ⅱ、Ⅲ、Ⅳ型**過敏反應組成：抗體、免疫複合物、T 細胞
- **全身性(非器官特異性)**：**SLE**、**類風濕性關節炎**、硬皮病、乾燥症；**器官特異性**：甲狀腺、胰島、神經肌肉接合處等

### 國考常考點 {#exam-points}

- **影響自體免疫疾病易感性的主要遺傳因子是 HLA**，不是 CTLA-4 或 FOXP3
- **非器官特異性**自體免疫疾病：**SLE**；**器官特異性**：Graves、橋本、第一型糖尿病、重症肌無力、惡性貧血(見 [[neuromuscular-demyelinating#myasthenia-gravis]])
- **SLE 起因**：**無法清除凋亡細胞**，細胞核成分暴露誘發自體抗體
- **分子模擬**：微生物抗原與自身抗原相似，抗微生物的抗體或 T 細胞攻擊自己(例如 **A 群鏈球菌 → 風濕熱**)
- **Graves 病**：自體抗體**模擬 TSH 結合受體使細胞活化與增生**，**不是破壞細胞**；**重症肌無力**：抗體**阻斷乙醯膽鹼受體**；**Goodpasture**：抗**基底膜第四型膠原蛋白**
- **猩紅熱不是自體免疫疾病**(是毒素引起)，**風濕熱**是
- **鞏皮症(系統性硬化症)**：女性多、**雷諾氏現象**、食道蠕動異常、皮膚纖維化；**斯耶格雷症候群**：唾液腺與淚腺**淋巴球浸潤**，乾眼乾口
- **多發性骨髓瘤的類澱粉**：前驅物是**免疫球蛋白輕鏈**；**甲狀腺髓質癌**最容易產生類澱粉沉積

## 免疫耐受與自體免疫的成因 {#tolerance}

### 耐受機制 {#tolerance-mechanisms}

| | 位置 | 機制 |
|---|---|---|
| **中樞耐受** | **胸腺**(T 細胞)、**骨髓**(B 細胞) | **負向選擇**清除對自體反應強的細胞；**AIRE** 讓胸腺呈現周邊組織抗原；B 細胞可**受體編輯** |
| **周邊耐受** | 周邊組織 | **Treg** 抑制；**anergy**(沒有共刺激訊號)；**凋亡**(活化後被清除)；**免疫特權部位**(眼、睪丸、腦) |

詳細見 [[t-lymphocytes#selection]]、[[b-lymphocytes#development]]。

### 耐受失敗的成因 {#causes}

1. **遺傳**
   1. **HLA** 是最主要的遺傳因素(例如 **HLA-B27** 與強直性脊椎炎、**DR3**、**DR4**)，見 [[immunoglobulins-hla#hla-disease]]
   2. **其他基因**：**補體缺乏**(C1q、C2、C4 缺乏易患 SLE，見 [[complement-system]])、**FOXP3**(IPEX)、**CTLA-4**、**AIRE**
   3. 同卵雙胞胎**不是 100%** 一致，表示環境也重要
2. **環境與誘發**
   1. **感染**與**分子模擬**
   2. **組織傷害**釋出隱藏抗原(例如眼外傷後的交感性眼炎)
   3. **紫外線**(SLE)、**吸菸**(RA)、**藥物**(藥物性狼瘡)、荷爾蒙
3. **性別**：女性較多，**雌激素**可能影響免疫
4. **無法清除凋亡細胞**：細胞核成分暴露，免疫系統產生抗核抗體(**SLE** 的重要機轉)

### 分子模擬 {#molecular-mimicry}

1. 微生物的某個**抗原與自身組織抗原相似**，免疫反應(抗體或 T 細胞)**交叉反應**，攻擊自己
2. 例子：**A 群鏈球菌的 M 蛋白**與心臟瓣膜、關節組織的抗原相似 → **急性風濕熱**([[streptococci]])；類風濕性關節炎也被討論
3. **猩紅熱**是鏈球菌的外毒素造成，**不是**自體免疫疾病

## 傷害機轉 {#mechanisms}

| 型別 | 機轉 | 疾病 |
|---|---|---|
| **第Ⅱ型** | 自體抗體結合細胞表面或基底膜 | 自體免疫溶血性貧血、ITP、**Goodpasture**、天疱瘡 |
| **第Ⅱ型(功能型)** | 抗體**活化**受體 | **Graves 病**(TSH 受體) |
| **第Ⅱ型(功能型)** | 抗體**阻斷**受體 | **重症肌無力**(乙醯膽鹼受體)、惡性貧血(內在因子) |
| **第Ⅲ型** | 自體抗原與抗體形成免疫複合物沉積 | **SLE**、**類風濕性關節炎**(部分)見 [[hypersensitivity-reactions#type-3]] |
| **第Ⅳ型** | 自體反應 **T 細胞** | **第一型糖尿病**、**多發性硬化症**、類風濕性關節炎(部分) |

## 疾病總表 {#disease-table}

| 疾病 | 類別 | 自體抗原與抗體 | 重點 |
|---|---|---|---|
| **全身性紅斑性狼瘡(SLE)** | **全身性**，Ⅲ型為主 | **ANA**、**anti-dsDNA**、anti-Sm | 見 [[sle]] |
| **類風濕性關節炎(RA)** | 全身性，Ⅲ與Ⅳ型 | **RF**、**anti-CCP** | 見 [[rheumatoid-arthritis]] |
| **乾燥症** | 全身性 | anti-Ro(SSA)、anti-La(SSB) | 唾液腺與淚腺淋巴球浸潤 |
| **鞏皮症** | 全身性 | anti-Scl-70(廣泛型)、**抗著絲點抗體**(CREST) | 皮膚纖維化、雷諾氏現象 |
| **Graves 病** | 器官特異性，Ⅱ型 | **TSH 受體刺激抗體** | 甲狀腺亢進、突眼 |
| **橋本氏甲狀腺炎** | 器官特異性，Ⅳ型為主 | 抗甲狀腺過氧化酶、抗甲狀腺球蛋白 | 甲狀腺低下 |
| **第一型糖尿病** | 器官特異性，Ⅳ型 | 抗胰島細胞抗體、抗 GAD | 胰島 β 細胞破壞，見 [[diabetes]] |
| **重症肌無力** | 器官特異性，Ⅱ型 | **抗乙醯膽鹼受體抗體** | 眼瞼下垂最早，**休息後改善** |
| **惡性貧血** | 器官特異性 | 抗內在因子、抗壁細胞抗體 | 維生素 B12 缺乏 |
| **多發性硬化症** | 器官特異性，Ⅳ型 | 針對髓鞘的 T 細胞 | 中樞神經脫髓鞘 |
| **Goodpasture 症候群** | 器官特異性，Ⅱ型 | **IgG 抗基底膜第四型膠原蛋白** | 肺出血與腎絲球腎炎 |
| **自體免疫溶血性貧血** | Ⅱ型 | 抗紅血球抗體 | **庫姆斯試驗陽性** |
| **ITP** | Ⅱ型 | 抗血小板抗體 | 血小板低下 |
| **急性風濕熱** | 分子模擬 | 抗鏈球菌抗體交叉反應 | 心臟炎、關節炎、舞蹈症 |
| **川崎氏症** | 血管炎(病因不明) | — | 見 [[kawasaki-disease]] |

1. **重症肌無力**：病理在**神經肌肉接合處**(**突觸後**的乙醯膽鹼受體)，不是骨骼肌或運動神經元本身；**Tensilon(edrophonium)試驗**是代表性檢查；詳細見神經系統頁面(待製作)
2. **抗核抗體(ANA)**：篩檢全身性自體免疫疾病的**敏感**指標，但**特異性低**，健康人也可能陽性；細節見 [[sle]] 與 [[immunology-labs#ana]]

## 硬皮病(系統性硬化症) {#scleroderma}

1. 以**皮膚與內臟纖維化**、**血管病變**為特徵；**女性多**，30–50 歲
2. **臨床**
   1. **雷諾氏現象**(手指遇冷或壓力發白發紫發紅)常是**最早症狀**
   2. **皮膚**變厚變硬、緊繃，手指**硬指**，面部**表情缺失**、口周皺褶
   3. **食道**蠕動異常、**吞嚥困難、胸骨後灼熱**(胃食道逆流)
   4. **肺**(間質纖維化、肺高壓)、**腎**(硬皮病腎危象，血壓急速升高)、心臟
3. **類型**：**局限性(CREST：鈣化、雷諾氏、食道、指端硬化、微血管擴張)**與**廣泛性(scl-70)**
4. **護理**：**保暖**(手套、襪子，避免遇冷)、**戒菸**、保護皮膚避免外傷、**飯後勿立即平躺**(減輕逆流)、少量多餐、口腔與皮膚照護、情緒支持
5. 無法治癒；以**免疫抑制劑**與器官特異性治療為主

## 乾燥症(斯耶格雷症候群) {#sjogren}

1. **淚腺與唾液腺**被淋巴球浸潤破壞 → **乾眼、口乾**；也可出現關節痛、疲倦
2. **女性多**，常合併其他自體免疫疾病(RA、SLE)
3. **抗體**：**anti-Ro(SSA)**、**anti-La(SSB)**；可伴 RF
4. **併發症**：**齲齒**、口腔念珠菌、**淋巴瘤**風險增加
5. **護理**：**人工淚液**、頻繁喝水、**無糖口香糖**刺激唾液、口腔衛生、避免抗膽鹼藥物

## 類澱粉沉積症 {#amyloidosis}

1. **類澱粉**是不溶性的纖維狀蛋白質沉積在細胞外，**剛果紅染色**呈蘋果綠雙折射
2. 依前驅蛋白質分類

| 類型 | 前驅蛋白質 | 相關疾病 |
|---|---|---|
| **AL(原發性)** | **免疫球蛋白輕鏈** | **多發性骨髓瘤**、漿細胞疾病 |
| **AA(續發性)** | **血清類澱粉 A(SAA)**，急性期蛋白 | **慢性發炎**(RA、結核、發炎性腸病) |
| **降鈣素來源** | 降鈣素 | **甲狀腺髓質癌** |
| **透析相關** | β2 微球蛋白 | 長期血液透析 |
| **阿茲海默** | Aβ | 阿茲海默症 |

3. **器官**：**腎臟**(蛋白尿、腎病症候群)、**心臟**(限制型心肌症)、肝脾腫大、舌肥大

## 其他自體免疫疾病 {#others}

1. **皮肌炎與多發性肌炎**：肌肉發炎，近端肌無力；皮肌炎有**紫紅色眼瞼疹**
2. **混合性結締組織病**：兼有 SLE、硬皮病、肌炎的特徵，**高效價 anti-U1 RNP**
3. **血管炎**：**川崎氏症**(兒童)、**Takayasu(無脈症)**等，見 [[kawasaki-disease]]
