**自閉症類群障礙症(ASD)** 是一種從幼兒早期就出現、持續終身的**神經發展障礙症**。DSM-5 把過去的自閉症、**亞斯伯格症**與未分類廣泛性發展障礙合併成一個「類群」，因為症狀的嚴重度差別很大。護理的核心是**理解孩子對改變與感官刺激的敏感**，維持可預測的環境，並及早介入。早期療育流程見 [[intellectual-disability#early-intervention]]，行為治療技術見 [[individual-cognitive-behavioral-therapy#behavior-therapy]]

## 重點摘要 {#summary}

- **社交溝通障礙**：缺乏眼神接觸、不理人、叫名字沒反應、難以分享情緒、缺乏想像性遊戲(扮家家酒)、語言遲緩、**鸚鵡式仿說**、代名詞反轉、答非所問
- **侷限重複的行為**：**堅持固定常規與同一性**(走固定路線、改變就大吵)、**刻板重複動作**(拍手、搖晃、轉圈)、對物體的部分特別執著(轉輪子)、**感官過度或過低反應**
- **3 歲前**出現、**男多於女**(約 4 倍)、**持續終身**；智力不是核心條件；嬰幼兒期易被誤認為**聽覺障礙**
- 治療：**早期療育**、應用行為分析、結構化教學、語言與**感覺統合治療**；藥物(如 risperidone)只用於**激躁、攻擊、自傷**等伴隨症狀，**無法治癒**
- 照護：**維持固定作息與環境**、**事先預告**、**簡短具體的指令**、**避免過度刺激與突然的身體接觸**、**一對一固定照顧者**、自傷時**頭盔與手套保護**

### 國考常考點 {#exam-points}

- 自閉症兒童**不喜歡**彈性多變的生活與環境，對主要照顧者**沒有**強烈依戀，**不會**主動參與扮家家酒，語言溝通**有障礙**
- **重度智能不足不是核心障礙**；核心是**社交互動、語言溝通與重複刻板行為**；**動作協調困難與身體眼球不自主擺動**也不是核心
- **通常 3 歲前**發病，**不是**學齡期後才出現；**多數成年後不會恢復正常**，但教育後社會與語言行為可改善，預後受**智商**影響
- 堅持每天走固定路線回家＝**儀式化行為**；喜歡玩車子的輪子＝**對物體局部的執著**(刻板)，不是儀式化
- DSM-5 中**亞斯伯格症不再是獨立診斷**
- 照護：**維持一致、可預測的環境**；**不要**增加居家環境的改變或安排變化多端的活動；**明確具體的指示**；**一對一照護、避免過度視聽刺激**；處置前**事先告知**
- **不要突然擁抱或碰觸**；初次評估**不必**用身體接觸；感官過度反應安排**感覺統合治療**
- 撞頭、拉頭髮頻繁 → **頭盔與手套保護**；不是罰站兩小時、口頭約定約束、每次打針；聽到救護車聲尖叫拍頭 → **暫停活動、帶離到安靜處**
- 攻擊行為可用**消弱法**等行為技巧；藥物(含 haloperidol)在嚴重攻擊時仍可依評估使用；不長時間隔離
- 家長指導：**不要有罪惡感**(不是教養造成)、**公平對待**其他孩子、可帶孩子走入人群；**不要每天安排不同活動**；不是靠吃藥治癒、也不用 luminal 治療

## 臨床表現 {#manifestations}

### 核心症狀 {#core-symptoms}

| 面向 | 常見表現 |
|---|---|
| **社交情緒互動** | 不理人、**不看人**、缺乏眼神接觸、叫名字無反應、不會分享喜悅、對主要照顧者也較淡漠、難以交朋友 |
| **非語言溝通** | 少用手勢與臉部表情、聽不懂言外之意 |
| **語言** | 語言發展遲緩甚至無語言、**鸚鵡式仿說**、**代名詞反轉**(你我顛倒)、答非所問、語調平板、照字面理解 |
| **人際與遊戲** | **缺乏想像性與社會性遊戲**(不玩扮家家酒)、喜歡獨自玩、遊戲玩法單調 |
| **堅持同一性** | 堅持固定的作息、路線與擺設，**改變就焦慮、大吵大鬧** |
| **刻板重複** | 拍手、搖晃身體、轉圈、排列物品、重複語句 |
| **侷限興趣** | 對物體的局部(輪子、旋轉的東西)或特定主題異常執著 |
| **感官異常** | 對聲音、觸碰、光線**過度敏感**(怕吵、拒絕被碰、尖叫)，或**反應過低**(對痛不敏感、尋求旋轉等刺激) |

1. 症狀在**發展早期**出現(DSM-5-TR 不設年齡切點；國考與 DSM-IV 寫「3 歲前」)，可能要到社交要求超過能力時才完全表現
   1. 診斷需同時有**社交溝通與互動的三方面缺損**，以及**侷限重複行為四類中至少兩類**
2. 嬰幼兒期常因對聲音與叫喚沒有反應、語言遲緩，被誤認為**聽覺障礙**，所以要先做聽力檢查
3. 依所需支持程度分為三個等級(需要支持、需要大量支持、需要非常大量支持)
4. **智力**差異很大：可能合併智能不足(過去稱低功能)，也可能智力正常或優異(過去稱高功能、亞斯伯格)
5. 常見共病：智能不足、**ADHD**、癲癇、焦慮、睡眠與腸胃問題、自傷行為

### 病因與預後 {#etiology-prognosis}

1. **神經發展異常**，與**遺傳**關係最強；高齡父母、早產與部分孕期因素增加風險
2. **不是**父母教養方式或嬰兒期依附關係造成；疫苗**不會**引起自閉症
3. 預後
   1. 核心症狀**持續終身**，多數成年後仍需不同程度的支持
   2. 透過早期療育與教育，社交與語言能有明顯改善，部分孩子可以進入普通班
   3. 預後與**智力**、**5–6 歲前是否有溝通性語言**有關

## 治療 {#treatment}

1. **早期療育**：越早越好，結合語言、職能、物理治療與特殊教育(台灣的早療流程見 [[intellectual-disability#early-intervention]])
2. **行為治療**
   1. **應用行為分析(ABA)** 與正向行為支持：用增強物建立適當行為
   2. 不當行為用**消弱法**(移除對它的增強)
   3. 結構化教學：用視覺提示、固定流程表幫助理解
3. **語言治療**與**社交技巧訓練**
4. **感覺統合治療**：處理感官過度或過低反應
5. **藥物**
   1. **無法治癒**自閉症，也不能改善核心症狀
   2. 嚴重**激躁、攻擊、自傷**時可用第二代抗精神病藥(risperidone、aripiprazole)，必要時傳統藥物，見 [[antipsychotics]]
   3. 合併過動可在評估後用興奮劑，見 [[cns-stimulants]]
   4. 使用一段時間無效時由醫師重新評估，不是自行持續加量

## 護理 {#nursing}

### 照護原則 {#nursing-principles}

1. **安全第一**
   1. 自閉症兒童對危險的認知不足，又可能有自傷，隨時維持**安全的環境**
   2. 頻繁撞頭或拉扯頭髮時，先用**頭盔與手套**保護，再找出誘因與替代行為
   3. 有嚴重自傷且其他方法無效時，**必要時**依醫囑做適當約束，不是一開始就約束或用針劑
2. **維持一致與可預測**
   1. 固定的作息、吃飯與就寢時間、固定照顧者(**一對一**)
   2. 環境改變或處置前**事先預告**，用圖卡或流程表說明
   3. 不要隨時改變常規、不要安排變化多端的環境
3. **減少過度刺激**
   1. 安靜、低刺激的環境，避免過度視聽刺激
   2. 聽到突發聲音(救護車)而尖叫拍頭：**暫停活動、帶離到安靜的地方**，等平穩後再回來
4. **溝通**
   1. **簡短、具體、結構化**的語句，避免抽象語言
   2. 給予**正向回饋**
   3. **不要突然碰觸或擁抱**，先評估觸覺敏感度
   4. 不強迫言語互動，也不要期待孩子給予一般的情感回饋，以免挫折
5. **固著行為**若沒有危險，不必強行制止；可逐步引導成較適當的行為
6. 評估情緒、認知與日常生活功能，**鼓勵發展適齡的技能**
7. 不用長時間隔離或懲罰性的長時間 time out

### 家長指導 {#parent-education}

1. 自閉症**不是**教養造成，不要心存罪惡感
2. **及早**接受早期療育，症狀多在幼兒期就被發現
3. 症狀會持續到成人期，要有長期規劃，但教育與訓練能帶來進步
4. 維持固定的作息與環境，給予明確具體的指令，增加孩子的安全感與信任
5. 可以帶孩子**走入人群**參與社交活動，事先預告與準備
6. **公平對待**其他孩子，不要因為照顧病童而忽略手足
7. 藥物用來減輕伴隨症狀，不能治癒
8. 照顧者的壓力很大，鼓勵參加家長團體、運用喘息服務
