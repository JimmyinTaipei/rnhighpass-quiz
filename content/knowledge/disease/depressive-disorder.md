憂鬱症(鬱症)是以**持續的情緒低落或失去興趣**為核心，合併睡眠、食慾、精力、專注力、自我價值感等改變，且**至少持續 2 週**、影響功能的疾病。女性的盛行率約為男性的 **2 倍**，是全球失能的主要原因之一，也是**自殺**最重要的相關疾病。國考考點集中在「診斷時間」「自殺評估與防範」「溝通方式」「營養與活動」「抗憂鬱藥」與「ECT」。

本頁依「生理 → 病因 → 臨床表現 → 診斷與相關疾病 → 特殊族群(產後、老年、青少年)→ 治療與 ECT → 護理 → 自殺評估與處置 → 危機處理」排列。藥物見 [[antidepressants]]；溝通技巧的通則見 [[schizophrenia#communication]]。

## 相關生理 {#physiology}

- **單胺假說**：血清素、正腎上腺素(以及多巴胺)**不足**。見 [[neurotransmitters-psychiatry#monoamine]]。
- **HPA 軸過度活化**：皮質醇偏高、地塞米松抑制試驗(DST)抑制不下來。見 [[neurotransmitters-psychiatry#hpa-axis]]。
- 海馬迴體積變小、腦源性神經滋養因子(BDNF)下降；抗憂鬱劑與 ECT 都被認為能促進神經可塑性。
- **甲狀腺功能低下**可以造成類似憂鬱的症狀(不是亢進)，所以初次診斷要檢查甲狀腺功能。

## 病因 {#etiology}

### 生物因素 {#biological}

- **遺傳**：一等親有憂鬱症，風險約增加 2–3 倍。
- **神經傳導物質與內分泌**：單胺不足、HPA 軸異常、甲狀腺低下、女性荷爾蒙變化(經期前、產後、更年期)。
- **身體疾病**：中風、巴金森氏症、癌症、糖尿病、心臟病、慢性疼痛、甲狀腺疾病。
- **藥物與物質**：類固醇、干擾素、部分抗高血壓藥、酒精、鎮靜安眠藥，以及古柯鹼與安非他命的戒斷。

### 心理學理論 {#psychological}

| 理論 | 重點 |
|---|---|
| **精神分析**(佛洛依德) | 對失落對象的憤怒**轉向自己**；最常用的防衛機轉是**內射**(introjection：把過錯歸咎於自己，「都是我沒照顧好媽媽，她才會過世」)；**本我弱、超我強**(過度嚴苛的自我要求) |
| **認知理論**(貝克 Beck) | **認知三角**：對**自己、世界、未來**都有負向看法；常見**認知扭曲**：**獨斷推論**(沒有證據就下負面結論)、**過度類化**(一次失敗就認為永遠失敗)、**兩極化**(全有全無)、選擇性摘錄、誇大或縮小、個人化 |
| **行為理論**(學習無助，Seligman) | 反覆經驗無法控制的挫折，**學到「做什麼都沒用」**的無望感 |
| **依附理論** | 早年**不安全的依附關係**：面對親密關係時害怕被拋棄 |
| 人際理論 | 人際衝突、角色轉換、失落、社交孤立 |

- **自閉思考**是思覺失調症的概念，不是 Beck 的認知扭曲。

### 社會因素與病因模式 {#social}

- **失落**(喪偶、失戀、失業)、長期壓力、社會孤立、家庭衝突、**童年受虐或忽視**、經濟困難、暴力。
- **潛在因素**(家族史、早年經驗)、**誘發因素**(重大失落)、**持續因素**(家屬用錯誤的方式督促、缺乏支持)的概念同 [[schizophrenia#stress-vulnerability]]。

## 臨床表現 {#manifestations}

| 面向 | 表現 |
|---|---|
| **情緒** | 憂鬱、悲傷、空虛、哭泣；**失樂**(對原本喜歡的事失去興趣)；也可能以**易怒**表現(兒童青少年) |
| **認知** | **無價值感、過度罪惡感**、無望、無助；**注意力不集中、猶豫不決**；反覆想到死亡、**自殺意念** |
| **行為** | 動作與言語遲緩(或激躁不安)、退縮、整天躺床、個人衛生變差 |
| **生理** | 失眠(尤其**早醒**)或嗜睡；**食慾下降、體重減輕**(或暴食、體重增加)；疲倦、沒精力；性慾降低；便秘；身體疼痛 |
| 精神病症狀(嚴重時) | **罪惡妄想**、**虛無妄想**(「我的內臟都爛了」)、貧窮妄想、責備自己的幻聽 |

:::tip[記憶法 SIG E CAPS]
**S**leep 睡眠、**I**nterest 興趣、**G**uilt 罪惡感、**E**nergy 精力、**C**oncentration 專注、**A**ppetite 食慾、**P**sychomotor 動作遲緩或激躁、**S**uicide 自殺。再加上核心的「憂鬱情緒」。
:::

- 憂鬱症常與焦慮症、物質使用、**飲食障礙症**共病。
- 老年人較少主動說出「心情不好」，常以**身體不適**或**記憶變差**來表現，見 [[depressive-disorder#late-life]]。

## 診斷與相關疾病 {#diagnosis}

### 鬱症發作的診斷重點 {#diagnostic-criteria}

以下依 DSM-5-TR 的內容**摘要改寫**(非準則原文)：

- 九項症狀(憂鬱情緒、失樂、體重或食慾改變、失眠或嗜睡、動作激躁或遲緩、疲倦、無價值感或過度罪惡感、注意力下降或猶豫不決、反覆想到死亡或自殺)中，**至少 5 項**；
- 其中**至少一項是「憂鬱情緒」或「失樂」**；
- 症狀在**同一個 2 週**期間，**幾乎每天、一天中大部分時間**出現；體重變化指**一個月內超過 5%**；
- 造成明顯痛苦或**社會、職業功能減損**；
- 不是物質或身體疾病引起；**從來沒有躁症或輕躁症發作**(有的話要考慮雙相情緒障礙症)。

- 註明項(specifier)：伴**焦慮困擾**、伴**混合特徵**、**憂鬱型**(清晨最糟、早醒、明顯罪惡感)、**非典型**(嗜睡、吃多、對拒絕敏感)、**伴精神病特徵**、**伴僵直**、**周產期發作**(懷孕期間或產後 4 週內發作)、**季節型**(多在**秋冬**發作、春夏緩解)。

:::exam[國考重點]
- 鬱症發作 = **至少 2 週**(不是 6 個月)；「偶爾睡不好」不符合，要「**幾乎每天**」。
- 憂鬱症與血清素**不足**、**女性多於男性**、甲狀腺功能**低下**有關。
- 季節性憂鬱多在**秋冬**發作 → **光照治療**。
:::

### 其他憂鬱症類障礙 {#other-depressive}

| 疾病 | 重點 |
|---|---|
| **持續性憂鬱症**(輕鬱症) | 憂鬱情緒**持續至少 2 年**(兒童青少年 1 年)，大多數日子都有，症狀可以較輕；期間沒有連續 2 個月以上的無症狀期 |
| **經期前情緒低落症**(PMDD) | 月經來潮前**最後一週**出現明顯情緒不穩、易怒、焦慮、憂鬱，以及專注力下降、疲倦、失去控制感等；**月經開始後幾天內改善**、月經結束後一週症狀很少；必須造成**明顯痛苦或影響工作、人際**(所以「不影響工作效率」不符合) |
| **侵擾性情緒失調症** | 兒童(6–18 歲診斷、**10 歲前**發病)：**反覆嚴重的脾氣爆發**(每週約 3 次以上)，爆發之間**持續易怒**，至少 12 個月；目的是避免把兒童易怒過度診斷為雙相 |
| 物質或藥物引起、身體疾病引起 | 類固醇、酒精、甲狀腺低下、中風後等 |
| 適應障礙症伴憂鬱情緒 | 壓力事件後 3 個月內出現，症狀未達鬱症 |
| **正常哀傷** | 以**思念逝者**為主，情緒一陣一陣、自尊通常保留；延長哀傷障礙症則是失落後 12 個月以上仍嚴重影響功能 |

- **雙相情緒障礙症**：一定要問過去有沒有躁症或輕躁症；雙相的鬱期若只用抗憂鬱劑，可能誘發躁症。

### 評估工具 {#assessment-tools}

| 工具 | 用途 |
|---|---|
| **PHQ-9** | 9 題自填，每題 0–3 分；**≥ 20 分為重度**；第 9 題問自殺或自傷念頭 |
| **心情溫度計**(BSRS-5) | 台灣社區篩檢與自殺防治常用，見 [[depressive-disorder#bsrs5]] |
| **主觀心情評分** | 「0 到 10 分，0 分最低落，你現在幾分？」：**心情的主觀評估**，方便追蹤變化 |
| 愛丁堡產後憂鬱量表(EPDS) | 產後篩檢，10 題，常用切點 ≥ 12–13 分；不問睡眠食慾等身體症狀(產後本來就會變) |
| 老人憂鬱量表(GDS) | 老人，題目以是非題為主、避免身體症狀 |
| 漢氏憂鬱量表(HAM-D) | 臨床人員評估嚴重度與療效 |

## 特殊族群 {#special-populations}

### 產後情緒障礙 {#postpartum}

| | **產後情緒低落**(postpartum blues) | **產後憂鬱症**(postpartum depression) | **產後精神病**(postpartum psychosis) |
|---|---|---|---|
| 頻率 | **很常見**(一半以上的產婦) | 約 **10–15%** | 罕見(約千分之 1–2) |
| 發生時間 | 產後 **2–3 天**開始，數天內達高峰 | 大多在產後**數個月內**(一半在懷孕前或懷孕期間就開始) | 通常在產後**數天到 2 週內**，急性發作 |
| 表現 | 情緒起伏、容易哭、焦慮、失眠，**輕微** | 符合鬱症：失去興趣(包括對嬰兒)、罪惡感、覺得自己是不好的母親、**自殺念頭** | **幻覺、妄想**、混亂、嚴重失眠；可能**傷害嬰兒或自殺** |
| 病程 | **2 週內自行緩解** | 需要治療 | **精神科急症**，需要住院；常與雙相情緒障礙症有關 |
| 處置 | 支持、休息、衛教；超過 2 週未緩解要評估 | 心理治療、抗憂鬱劑、社會支持 | 住院、確保母嬰安全 |

- 產後荷爾蒙變化：胎盤娩出後**雌激素與黃體素急遽下降**(不是上升)，加上睡眠剝奪、角色轉變、缺乏支持。
- 危險因子：**過去憂鬱或雙相病史**、懷孕期間憂鬱或焦慮、缺乏支持、壓力事件、非計畫懷孕、嬰兒健康問題。
- 產後憂鬱的媽媽可能出現「**不想要卻闖進腦中**」的傷害嬰兒念頭，通常沒有意圖，要**直接詢問**並評估是否有精神病症狀；有意圖時多見於產後精神病。
- 建議產後至少篩檢一次(常在**產後 4–8 週**)，並確保篩檢陽性時有後續轉介(來源：[UpToDate：Postpartum unipolar major depression](https://www.uptodate.com/contents/postpartum-unipolar-major-depression-epidemiology-clinical-features-assessment-and-diagnosis))。
- 產後心理調適期(Rubin)：接受期(taking-in)鼓勵產婦說出生產經驗；緊執期(taking-hold)鼓勵學習照顧新生兒；放手期(letting-go)仍可能有不自覺的哀傷。**哭泣、缺乏育兒信心不等於產後憂鬱症**，要看時間與嚴重度。

::questions{ids="112-2_OP_021,112-3_OP_015,113-1_OP_015,113-3_OP_012,114-3_OP_016"}

### 老年憂鬱 {#late-life}

- 老人較少說「心情不好」，常表現為**身體不適**(疼痛、失眠、腸胃症狀)、疲倦、食慾差、**記憶力與專注力變差**，容易被當成「老化」而忽略。
- **假性失智**：憂鬱造成的認知功能下降，治療憂鬱後可以改善。

| | 憂鬱(假性失智) | 失智症 |
|---|---|---|
| 發生 | 相對**快速**，時間點可以說得出來 | 緩慢、漸進 |
| 對記憶的態度 | **強調**自己記不住、常回答「**不知道**」 | 掩飾或否認，常**虛談**、答錯 |
| 情緒 | 持續憂鬱 | 情緒起伏、淡漠 |
| 表現的一致性 | 變化大、努力不足 | 較一致地退化 |
| 治療後 | 可以**改善** | 持續退化 |

- **老年人自殺率是各年齡層中最高的**，尤其是**獨居、喪偶、身體疾病、慢性疼痛、男性**；**輕度失智**的老人也可能自殺。老人可能用**飲酒或濫用處方藥**來因應壓力與憂鬱。
- 用藥：**SSRI 為第一線**；TCA 的抗膽鹼、姿勢性低血壓與心臟毒性較大，不是首選。症狀緩解後仍需**持續用藥數月到一年以上**，不能自行停藥。
- 喪偶的老人：先進一步**評估自殺意念與計畫**；哀傷輔導可以協助表達失落的感受。

::questions{ids="114-2_PC_019,113-2_PC_021,112-2_PC_033,107-2_PC_031,114-3_PC_018,113-1_PC_018,113-1_PC_019,110-2_PC_032"}

### 兒童與青少年憂鬱 {#youth}

- 表現常是**易怒**、成績退步、缺課、拒學、行為問題、身體抱怨，而不是典型的悲傷。症狀範圍包括認知、情緒、行為與生理；屬於**內向性**(internalizing)問題。
- 青春期後**女性多於男性**；最嚴重的合併症是**自殺**。
- 治療以心理治療與家庭介入為主，藥物常用 fluoxetine 等 SSRI；抗憂鬱劑在 **25 歲以下**有增加自殺想法的警語，開始用藥時要密切觀察。
- **家屬衛教**：
  - 讓孩子知道自己生病了、需要治療；多陪伴、**避免長時間獨處**；鼓勵戶外運動、規律睡眠。
  - **不要說「不要胡思亂想，好好讀書」**，也不要額外安排補習增加壓力。
  - 藥物有副作用(頭痛、嗜睡)時**不要自行停藥**，回診和醫師討論。
  - 均衡飲食(全穀類、奶製品、魚油、蔬菜與維生素)可以作為輔助。

## 治療 {#treatment}

### 治療原則 {#treatment-principles}

- 目標是**完全緩解**並恢復功能(只有「有反應」但未緩解，復發率較高)。
- **輕度**：心理治療、運動等支持性介入，或抗憂鬱劑。
- **中度**：抗憂鬱劑或心理治療，兩者療效相近，依病人偏好、可近性與費用決定。
- **重度**：**藥物合併心理治療**；有**自殺行為、僵直、拒食造成脫水營養不良、精神病症狀**而需要快速見效時，考慮 **ECT**(來源：[UpToDate：Major depressive disorder in adults. Approach to initial management](https://www.uptodate.com/contents/major-depressive-disorder-in-adults-approach-to-initial-management))。
- **治療分期**：
  - **急性期**：以達到緩解為目標，抗憂鬱劑通常 **2–4 週**開始見效，完整療效要 **6–8 週**以上。
  - **持續期**：緩解後繼續用藥**數個月**(常見 4–9 個月)預防復發。
  - **維持期**：反覆發作的病人可能需要長期用藥。
- 第一線藥物：**SSRI 或 SNRI** 等第二代抗憂鬱劑。見 [[antidepressants]]。

### 心理治療與其他治療 {#psychotherapy}

| 治療 | 重點 |
|---|---|
| **認知治療**(CBT) | 找出並挑戰**自動化負向想法**。病人說「我的小孩一定看不起我」，用蘇格拉底式提問：「**有什麼情況讓你有這種想法？**」而不是空泛安慰或否定 |
| 人際治療(IPT) | 處理哀傷、角色轉換、人際衝突 |
| 行為活化 | 安排有成就感與愉悅感的活動 |
| **光照治療** | **季節性憂鬱**：早上使用高亮度光照；光線經**視網膜 → 視交叉上核**，調節**松果體褪黑激素**分泌與晝夜節律 |
| 重複經顱磁刺激(rTMS) | 以磁場刺激前額葉，不需麻醉，用於藥物效果不佳者 |
| Ketamine、esketamine | NMDA 拮抗劑，數小時到數天內改善自殺意念與憂鬱，用於難治型憂鬱 |
| 運動、睡眠、飲食 | 輔助治療 |
| 哀傷輔導 | 提供支持性環境，協助表達失落的感受 |

### 電氣痙攣療法(ECT) {#ect}

以短暫電流誘發一次全身性癲癇發作，被認為會增加單胺類釋放、促進海馬迴與杏仁核的神經新生與可塑性。是**效果最快、最強**的憂鬱症治療之一。

- **適應症**：
  - **嚴重憂鬱症合併強烈自殺意念**、拒食而危及生命
  - **伴精神病特徵**的憂鬱、**僵直**
  - 藥物無效或無法使用藥物(懷孕、老人藥物副作用大)、過去對 ECT 反應好
  - **藥物無效的躁症**、雙相憂鬱；**思覺失調症合併僵直**
  - **人格障礙症不是適應症**
- **禁忌**：沒有絕對禁忌症；相對禁忌包括**顱內壓增加**(腦瘤)、近期心肌梗塞或中風、腦動脈瘤等，因為誘發癲癇會暫時升高血壓、心跳與顱內壓。
- **療程**：每週 **2–3 次**，多數在 **6–12 次**內緩解；結束時逐漸減少頻率，之後可能需要維持性 ECT。
- **電極位置**：雙側(兩側顳部)效果快但認知副作用較多；**單側**是放在**非優勢半球**(多數人是右側)的額顳部，記憶副作用較少。

**治療前護理**：
1. **知情同意**：由醫師完整說明療效、過程、風險與替代治療，病人(或法定代理人)簽署同意書；只說「睡一覺就好」違反知情同意。
2. **禁食**(通常前一晚午夜後)，預防麻醉時嘔吐吸入。
3. 治療前**排空膀胱**；**移除活動假牙**、髮夾、首飾、隱形眼鏡；穿寬鬆衣物；鬆動的牙齒要先處理。
4. 測量生命徵象、體重，確認檢查(心電圖、血液檢查)完成。
5. 用藥：**短效麻醉劑**(如 propofol、methohexital)、**肌肉鬆弛劑 succinylcholine**(減少抽搐造成骨折)、**抗膽鹼藥**(atropine 或 glycopyrrolate，減少分泌物與心跳過緩)；**不是**給 Demerol。
6. 減輕焦慮：說明過程、允許提問。

**治療中與治療後護理**：
- 給氧、放**咬合墊**保護牙齒與舌頭，監測心電圖、血氧與發作時間。
- 清醒前採**側臥**、維持呼吸道通暢、監測生命徵象直到穩定。
- 醒來後常有**短暫意識混亂**(10–30 分鐘)：**重新定向**(告訴他人、時、地)、**預防跌倒**、陪伴。
- 常見副作用：**頭痛**(最常見)、肌肉痠痛(succinylcholine)、噁心、下顎痠痛；**短暫記憶喪失**(順向失憶多在療程結束後 **2 週內**恢復，療程前後的逆向失憶部分可能無法恢復)；麻醉相關的**呼吸暫停**。
- 完全清醒、生命徵象穩定後就可以**進食並照常參與病房活動**；療程期間**不要開車**，療程結束後 1–2 週內避免做重大決定(來源：[UpToDate：Overview of electroconvulsive therapy](https://www.uptodate.com/contents/overview-of-electroconvulsive-therapy-ect-for-adults))。
- 使用鋰鹽的病人：可能增加 ECT 後的混亂與譫妄，並延長 succinylcholine 的作用，要告知醫師。

:::exam[國考重點]
- ECT 適應症：**嚴重憂鬱＋強烈自殺意念**、**藥物無效的躁症**、**思覺失調症合併僵直**；人格障礙不是。
- 治療前：**禁食、排空膀胱、拿下活動假牙**、簽同意書。
- 併發症：**頭痛、呼吸暫停、短暫記憶喪失**；腦出血不是主要併發症。
- 單側 ECT 的電極放在**非優勢**半球的額顳交接處。
:::

## 護理 {#nursing}

### 護理優先順序 {#nursing-priorities}

1. **安全：評估自殺風險、預防自我傷害**(永遠是第一優先)，見 [[depressive-disorder#suicide-risk]]。
2. **營養與水分**：體重急遽下降、只喝少許果汁 → 護理診斷「**營養不均衡：少於身體需要**」。
3. 睡眠、排泄(便秘)、個人衛生。
4. 建立信任關係、表達情緒、自尊。
5. 活動與社交、家屬支持、出院準備。

### 生理需求 {#nursing-physical}

- **飲食**：提供**高熱量、高蛋白、易消化**的食物，**少量多餐**，準備病人喜歡的食物，陪伴進食；記錄攝取量、**每週量體重**；數天沒吃要注意脫水與電解質。
- **睡眠**：白天減少躺床、安排活動；睡前放鬆；觀察早醒(自殺的高風險時段)。
- **自我照顧**：病人出現退化行為時，採**部分協助**並**鼓勵他自己做**能做的部分，給予小步驟與正向回饋；**完全代勞**會加深無力感與依賴。
- **排泄**：活動少、吃得少、抗憂鬱劑的抗膽鹼作用都會造成便秘。

### 活動安排 {#nursing-activity}

- 從**簡單、短時間、容易成功、非競爭性**的活動開始(散步、整理床單、簡單手工)，再逐漸增加；讓病人有成就感。
- 短期目標要具體、可達成：例如「**在護理人員陪伴下願意到大廳走動**」。
- 不要一開始就要求參加大型團體或需要高度專注的活動。

### 溝通與建立關係 {#nursing-communication}

- **同理病人的感受與想法**；給予**簡單、直接、清楚**的訊息(病人專注力差、決策困難)；協助病人**表達想法與感覺**；接受病人的沉默與哭泣。
- **不要用督促、打氣、空泛保證**(「開心一點」「你一定會好起來」「想那麼多沒用」)，也不要與病人爭辯他的負向想法。
- **不言不語的病人**：**短暫而多次的陪伴**，「我在這裡陪你，你想說的時候隨時可以說」。
- **低自尊、責怪自己**的病人：傾聽並同理，**適時澄清**他的價值觀與不合理的想法，找出並肯定他的優點。
- 病人抱怨藥物不舒服：先請他**描述**是怎樣的不舒服，再與醫師討論。
- 更多溝通技巧見 [[schizophrenia#communication-techniques]]。

### 家屬 {#nursing-family}

- 協助家屬**了解病人目前的狀況**與疾病(憂鬱症是疾病，**不是**懶惰、逃避或裝病)。
- 家屬抱怨照顧負擔時：**同理家屬的辛苦**，同時說明持續治療的重要，並連結支持資源。
- 教導家屬辨認**自殺警訊**與復發徵兆、協助藥物遵從、移除家中危險物品。

### 出院準備 {#nursing-discharge}

- 持續服藥，**症狀改善後也不能自行停藥**；轉院時帶著目前所有的藥物(藥袋)讓醫師評估，不要自己先停。
- 提供**自殺防範與求助的資訊與管道**(安心專線 1925、回診、急診)，與病人一起擬定**安全計畫**。
- 出院後第一週到第一個月是**自殺高風險期**，安排早期回診或電話追蹤。

## 自殺評估與處置 {#suicide-risk}

這一節適用於所有精神疾病(憂鬱症、雙相、思覺失調症、物質使用、人格障礙)與一般科病人。

### 名詞 {#suicide-terms}

| 名詞 | 定義 |
|---|---|
| **自殺意念** | 有想死或想結束生命的**念頭**，可能還沒有具體計畫(「我活著沒意思，真想死了」) |
| 被動意念 vs 主動意念 | 被動：「希望睡著就不要醒來」；主動：「我想殺了自己」 |
| **自殺威脅** | 用言語或文字表達自殺念頭，讓別人相信他想死(「你離開我，我就去死」) |
| **作態性自殺** | 有自傷行為，目的是讓別人以為他想死，但其實沒有死的意圖 |
| **自殺企圖** | 有死的意圖的**自傷行為**，但沒有死亡(例：藥物過量、手腕有自己割的傷口) |
| **自殺身亡** | 因帶有死亡意圖的自傷行為而死亡 |
| 非自殺性自傷 | 故意傷害身體組織但**沒有死的意圖**(例：以割傷來調節情緒) |

### 危險因子與保護因子 {#suicide-risk-factors}

| 危險因子 | 保護因子 |
|---|---|
| **過去自殺企圖**(**最重要**，企圖後第一年、尤其第一週風險最高) | 有配偶、懷孕、為人父母(尤其母親) |
| **精神疾病**：約 50–90% 自殺身亡者生前有精神疾病，以**憂鬱症**、雙相、**物質(酒藥癮)使用**、思覺失調症、邊緣型人格最常見 | 良好的社會支持與家庭連結 |
| **無望感**、無助、無價值感、衝動性 | 經濟獨立 |
| **家族自殺史** | 宗教信仰與活動 |
| 男性(自殺身亡率較高；女性企圖較多) | 活下去的理由(孩子、責任) |
| **老年人**(自殺死亡率最高)、青少年 | 與治療人員的良好關係 |
| **容易取得致命工具**(槍、藥物、農藥、燒炭) | 有效的因應技巧 |
| 身體疾病與慢性疼痛、失業、經濟困難、**重大失落**(喪偶、失戀)、社會孤立 | |
| 童年受虐、剛出獄、**剛出院** | |
| 命令式幻聽、被羞辱感 | |

(來源：[UpToDate：Suicidal ideation and behavior in adults. Risk factors, clinical features, and assessment](https://www.uptodate.com/contents/suicidal-ideation-and-behavior-in-adults-risk-factors-clinical-features-and-assessment))

- 自殺危險因子分布在生物、心理、社會、經濟、文化各層面，**不是單一因素**；防治需要**跨領域合作**，不是只由專責人員負責。
- 藥癮者的自殺不只是用藥過量，**與憂鬱等精神問題有關**。

### 迷思與事實 {#suicide-myths}

| 迷思 | 事實 |
|---|---|
| 問病人有沒有想自殺，會讓他更想自殺 | **不會**；直接詢問不會增加自殺意念，反而讓病人覺得被理解 |
| 說要自殺的人不會真的去做 | 很多自殺者事前都有**示警**(說出來、交代後事) |
| 病情好轉就沒有自殺危險 | **憂鬱開始改善、精力恢復時**風險反而升高(有了行動的力氣)；**剛出院**也是高風險期 |
| 想自殺的人一心求死 | 大多**矛盾**，想死也想活；自殺念頭常是**暫時的**，經介入可以緩解 |
| 失智或年紀大的人不會自殺 | 老年人自殺率最高，輕度失智也可能自殺 |

### 自殺警訊 {#warning-signs}

- 說出想死、活著沒意思、「我會拖累你們」、「有什麼方法可以解脫」、詢問藥物能不能致死
- **把心愛的東西送人**、交代後事、寫遺書、道別
- 準備工具(囤積藥物、買木炭)
- 情緒突然**從很低落變得平靜或開朗**
- 退縮、不參加活動、長時間**凝視窗外**、反覆提到死亡

### 自殺評估 {#suicide-assessment}

1. **直接、清楚地問**：「你有沒有不想活下去的念頭？」「你有想過要結束自己的生命嗎？」
2. 若有，繼續評估：
   - **想法**：多久出現一次、有多強烈、是主動還是被動？(「還有什麼想法閃過心頭？這個想法有多強烈？」)
   - **計畫**：方法、地點、時間有沒有想好？
   - **工具**：是否**容易取得**？致命性有多高？
   - **意圖**：有多想去做？有沒有被救的可能？
   - **準備行為**：是否已經囤藥、寫遺書？
   - **過去**：以前有沒有自殺企圖？用什麼方法？
3. 評估精神疾病、物質使用、無望感、支持系統、活下去的理由。
4. 資料來源包括病人、家屬與病歷；病人不同意家屬參與，家屬仍可以提供資訊。

#### 心情溫度計(BSRS-5) {#bsrs5}

台灣全國自殺防治中心與台灣自殺防治學會推廣的**簡式健康量表**，自填或由他人詢問，評估**最近一星期(包括今天)**。

- **前 5 題**：**睡眠困難**、**感覺緊張不安**、**覺得容易苦惱或動怒**、**感覺憂鬱、心情低落**、**覺得比不上別人**(分別對應失眠、焦慮、敵意、憂鬱、自卑)；每題 0(完全沒有)到 4 分(非常厲害)。
- **附加題**：「**有自殺的想法**」，單獨計分。

| 前 5 題總分 | 意義與建議 |
|---|---|
| 0–5 分 | 身心適應狀況良好 |
| **6–9 分** | 輕度情緒困擾，建議找家人或朋友談談、抒發情緒 |
| 10–14 分 | 中度情緒困擾，建議尋求紓壓管道或接受心理專業諮詢 |
| ≥ 15 分 | 重度情緒困擾，建議尋求專業輔導或精神科治療 |

- **附加題「有自殺的想法」≥ 2 分**(中等程度)時，建議尋求專業輔導或精神科治療。
- 總分 **6 分**是研究驗證的篩檢切點(來源：[台灣自殺防治學會：心情溫度計專區](https://www.tsos.org.tw/web/page/bsrs)；全國自殺防治中心《自殺防治系列 12：心情溫度計》)。

### 防範措施 {#suicide-prevention}

#### 住院病人 {#suicide-inpatient}

- **觀察頻率依風險分級**：一般常規每 15 分鐘；中度風險每 5 分鐘；高風險**持續觀察或一對一**(不能離開視線，包括如廁)。降低觀察頻率要有穩定的臨床改善(例如情緒改善、開始談論未來至少一整天)(來源：[UpToDate：Suicidal ideation and behavior in adults. Management](https://www.uptodate.com/contents/suicidal-ideation-and-behavior-in-adults-management))。國考的標準答案常是「依評估的危險程度，採**每 15 分鐘密切觀察**」。
- **環境安全**：房間**靠近護理站**、避免單人房與人少的地方；移除**皮帶、鞋帶、繩索、電線、塑膠袋、刀片、玻璃、打火機、藥物**；檢查病人與訪客帶來的物品；浴室、窗戶、吊掛點的安全。
- **給藥時確認吞下**，避免囤藥。
- **高風險時段**：夜間與清晨、**交班時間**、週末假日、人力少的時候、家屬會客後、**症狀開始改善時**、出院前後。
- **鼓勵病人說出感受與自殺的想法**，**不要避免談論自殺**；和病人討論自殺的原因與替代的因應方法。
- 安排病人參與活動、避免獨處，同時保持觀察。
- 事件發生後(自殺企圖或身亡)，病房要進行團隊檢討，並支持工作人員與其他病友。

:::warning[不自殺契約的新舊觀念]
國考曾以「契約內容包含病人承諾在某段時間內不會自傷或自殺，或有衝動時會主動找工作人員」為正確答案，並把「與病人訂定不自殺契約」列為照護重點之一。
目前的實證認為，**不自殺契約沒有證據能降低自殺**，反而可能給人**錯誤的安全感**，已經被**安全計畫**取代(來源：[UpToDate：Suicidal ideation and behavior in adults. Management](https://www.uptodate.com/contents/suicidal-ideation-and-behavior-in-adults-management))。作答時依題意選擇，但臨床上以安全計畫為主，而且契約不能取代觀察與評估。
:::

#### 安全計畫 {#safety-plan}

由病人與治療人員**一起寫**(約 30 分鐘)，內容包括：

1. 自殺念頭與危機的**觸發因素與警訊**
2. 自己可以使用的**因應方法**(運動、聽音樂、轉移注意力)
3. 可以陪伴或轉移注意的**人與地方**
4. 可以求助的**家人朋友**
5. **專業人員與緊急求助管道**：醫院、急診、**安心專線 1925**
6. **限制致命工具**：請家屬協助保管藥物、刀具、木炭、農藥等

- 病人願不願意一起擬定，也可以作為評估風險的線索。

#### 社區與出院後 {#suicide-community}

- **守門人「1 問、2 應、3 轉介」**：主動**關懷詢問**、**適當回應**(傾聽、同理、支持)、**轉介**專業資源。
- 求助專線：**安心專線 1925**(24 小時免付費)、生命線 1995、張老師 1980。
- 自殺企圖者出院後的**關懷訪視與追蹤**，是降低再次自殺的重要策略。
- 鋰鹽對情緒障礙病人、clozapine 對思覺失調症病人，都有降低自殺的證據。

### 自殺的社會學分類(涂爾幹 Durkheim) {#durkheim}

| 類型 | 原因 | 例子 |
|---|---|---|
| **利己型**(egoistic) | 與社會**整合太少**，缺乏歸屬 | 獨居、孤立的老人 |
| **利他型**(altruistic) | 與社會**整合太強**，為團體犧牲 | 殉國、殉道 |
| **失範型**(anomic，社會混亂型) | 社會規範或生活**突然改變**，失去依循 | **配偶外遇、被情人拋棄**、突然破產或失業 |
| **宿命型**(fatalistic，致命型) | **過度的管制與壓迫**，看不到希望 | 長期被**債主催討**、囚犯、受虐者 |

### 病人在病房自殺身亡時 {#suicide-death}

**保留現場**，依序：①通知當班主管並**報警** → ②**通知家屬** → ③**書寫護理紀錄**(客觀、完整)。

:::exam[國考重點]
- 最優先：有自殺意念或企圖的病人，先**評估自殺危險程度**並**採取自殺防範措施**。
- 憂鬱症最容易自殺的時期：**病情開始恢復時**。
- 「我活著沒意思，真想死了」屬於**自殺意念**；藥物過量加手腕割傷屬於**自殺企圖**。
- 最重要的危險因子：**過去的自殺企圖**；家族自殺史也是高危險群。
- 不要避免與病人討論自殺；房間**靠近護理站**、密切觀察。
- 老年人自殺死亡率最高；自殺者約 90% 有精神疾病。
:::

## 危機處理 {#crisis}

### 危機的概念 {#crisis-concept}

- **危機**：個體遇到壓力事件，**慣用的因應方法失效**，原本的**平衡狀態被擾亂**。危機有時間限制，通常 **4–6 週**內會以某種方式解決；結果可能**比危機前更好、恢復原狀或更差**，因此也是成長的機會。
- **類型**：**發展性(成熟性)危機**(青春期、結婚、退休)、**情境性危機**(失業、離婚、疾病、親人死亡)、**社會性(意外)危機**(天災、戰爭、暴力)。

### 卡普蘭(Caplan)的危機發展 {#caplan}

| 階段 | 表現 |
|---|---|
| 1. 焦慮升高(前奏) | 面對壓力源，**焦慮**上升，先試著用**過去成功的經驗**解決 |
| 2. **紊亂期** | 慣用的因應方法**失敗**，焦慮持續升高、**功能變得紊亂**；思考僵化，可能使用壓抑、否認、合理化、外射等防衛機轉 |
| 3. 求助期 | 動員內外在資源、嘗試新方法、**向外尋求支援**；問題解決就能恢復平衡 |
| 4. 危機期(崩潰) | 問題仍未解決，焦慮升到極點 → 嚴重紊亂、**人格崩潰**或精神疾病 |

- 國考 107-2 的順序答案寫作「**前奏期 → 焦慮升高期 → 求助期 → 危機期**」，各教科書命名略有不同；關鍵是「**慣用方法失敗、功能紊亂 = 紊亂期**」「最後才是危機(崩潰)」。
- 先生車禍過世後**激動不安、捶打家人** → **紊亂期**。

### 安吉列拉(Aguilera)的平衡因素 {#aguilera}

壓力事件會不會形成危機，取決於三個**平衡因素**：

1. **對事件的知覺**：病人怎麼看這件事、覺得有多嚴重(評估「**對事件的感覺與觀點**」)
2. **情境支持**：家人、朋友、社會資源
3. **因應機轉**：過去處理壓力的方法

三者都足夠 → 恢復平衡、不形成危機；任一不足 → 可能形成危機。

### 危機處置原則 {#crisis-intervention}

- **立即**處理、**聚焦此時此刻**(here and now)與眼前的問題，而不是深入探討過去。
- **先評估**病人對壓力事件的**感受與事件對生活的影響**、自殺或傷人危險。
- 技巧：**宣洩**(引導說出情緒與關切的事)、支持與陪伴、澄清、提供資訊、協助**發掘病人適用的因應方法**、動員支持系統、問題解決。
- 目標是恢復到**危機前的功能水準**。
- 不要等病人「準備好了」才介入；也不要**忽略**病人的感受(例如被霸凌的學生)。
- 慢性精神病人家中衝突(父子各說各話)時，居家護理師的首要目標是**改善家庭溝通與互動**、協助家庭因應。

### 災難心理衛生 {#disaster}

| 災後階段 | 表現與護理重點 |
|---|---|
| 英雄期 | 災後立即，大家奮力救災 |
| **蜜月期** | 救援與物資大量湧入(約災後一週到數月)；要注意災民**容易被忽略的心理與行為問題** |
| 幻滅期 | 援助減少、重建困難，失望與憤怒 |
| 重建期 | 逐步恢復生活 |

- **急性期**首要目標：**穩定狀態、減緩症狀**、滿足安全與基本需求(心理急救)。
- **安心團體**(減壓會談，debriefing)：專業人員引導受災者表達感受、回顧經驗，整合情緒與認知；不強迫參加。
- **不可**在初期強迫災民回到現場做暴露治療(造成二次創傷)。
- 尊重當事人的**自主性、文化與宗教**。
- 災難**可以預防與準備**，不是只強調災後處置。
- 倖存者急性期常見：麻木、過度警覺、創傷經驗再現、失眠、罪惡感(倖存者罪惡感)；持續超過 1 個月且影響功能要考慮**創傷後壓力症**。
- **資源保存理論**(Hobfoll)：資源分成物件(房屋、車)、情境(工作、婚姻)、個人特質(性格、能力、自信)、能量(時間、金錢、知識)四類，資源流失會增加壓力反應。
- **哀傷的急性期**：首要是讓哀傷者**抒發情緒**，不急著處理財產或未來規劃。
