**甲狀腺機能亢進**是甲狀腺製造太多甲狀腺素，讓全身代謝加速。本頁整理原因、表現、藥物與放射性碘、甲狀腺風暴，以及甲狀腺切除術的護理；甲狀腺素的生理與檢驗見 [[thyroid-parathyroid]]，功能低下見 [[hypothyroidism]]，甲狀腺癌見 [[thyroid-nodules-cancer]]

## 重點摘要 {#summary}

- 原因：**葛瑞夫茲氏病**最常見（自體免疫，**甲狀腺刺激抗體**作用在 TSH 受體）；毒性多結節性甲狀腺腫、毒性腺瘤、甲狀腺炎、吃太多甲狀腺素
- 檢驗：**TSH 下降**、游離 T4 與 T3 上升；葛瑞夫茲氏病 TRAb 陽性
- 表現：**怕熱、多汗**、皮膚溫熱潮濕、**心搏過速**與心悸、**食慾增加但體重減輕**、**腹瀉**、**手指細顫**、神經質、**月經減少或停經**、指甲遠端分離、肌肉無力、深肌腱反射**增強**
- **葛瑞夫茲氏病特有**：**突眼**、**脛前黏液水腫**、瀰漫性甲狀腺腫
- 治療三選一：**抗甲狀腺藥**、**放射性碘**、**手術**；β 阻斷劑(propranolol)緩解心悸與手抖
- **抗甲狀腺藥**：先大劑量、再慢慢減量，**不可症狀一消失就停藥**；注意**顆粒性白血球減少**（喉嚨痛、發燒要立刻回診）
- **碘劑**(SSKI)：抑制甲狀腺素**釋放與合成**、讓甲狀腺血管減少，多用在**術前**；**不超過約 2 週**（會逸脫）；可混牛奶或果汁、**用吸管**避免牙齒染色
- **甲狀腺風暴**：高燒、心搏過速、譫妄；首選 **propranolol**，再給抗甲狀腺藥、碘劑、類固醇，物理降溫
- **甲狀腺切除術後**：半坐臥、頭頸用枕頭支托；觀察**出血與呼吸道阻塞**、**聲音沙啞**（喉返神經）、**口周刺麻與手足抽搐**（低血鈣）

### 國考常考點 {#exam-points}

- 葛瑞夫茲氏病：神經質、**突眼**、**手指顫抖**；怕熱（不是怕冷）；脛前黏液水腫是**非凹陷性**
- 甲亢**食慾增加**（不是不振）、腸蠕動加快、**T3 上升**；甲亢最可能心跳 > 100 次／分
- 甲亢表徵：月經減少、指甲遠端鬆脫、脛前黏液水腫；深肌腱反射是**增強**
- 葛瑞夫茲氏病是甲狀腺素過多引起，好發於**年輕女性**，血脂**下降**
- 飲食：**高熱量、高蛋白、高碳水化合物**；**不宜高纖**
- 突眼：睡覺**抬高床頭**（不是平躺）
- 抗甲狀腺藥：**先大劑量再減量**；副作用是顆粒性白血球**減少**；碘劑**不超過 2 週**；碘劑**可**和牛奶、果汁一起喝、用吸管；碘劑主要是**抑制釋放與合成**
- 放射性碘：治療劑量後第一週限制訪客、**單獨睡**、避開孕婦；長期追蹤的是**甲狀腺功能低下**
- 甲狀腺風暴：首選 **propranolol**；體溫過高、譫妄；**TSH 下降**（不是上升）
- 甲狀腺切除：一般**次全切除**；常見併發症**出血、聲門水腫、呼吸道阻塞**、**喉返神經受損**；**單側**喉返神經受傷才是聲音沙啞（雙側會失聲或呼吸道阻塞）；手足抽搐是**低血鈣**不是甲狀腺低下
- 術後：**半坐臥**、頭頸枕頭支托；鼓勵**深呼吸咳嗽**；**冰涼液狀食物**；觀察聲音嘶啞與口部刺麻；一週內評估 Chvostek、Trousseau 徵象

## 原因與病理 {#causes}

| 原因 | 特點 |
|---|---|
| **葛瑞夫茲氏病**(Graves) | **最常見**；自體免疫，**甲狀腺刺激抗體**（TSI、TRAb）像 TSH 一樣持續刺激甲狀腺；好發 **20–40 歲女性**；瀰漫性腫大、**突眼**、**脛前黏液水腫** |
| 毒性多結節性甲狀腺腫 | 年長者；結節自主分泌 |
| 毒性腺瘤 | 單一功能性結節（熱結節） |
| 甲狀腺炎 | 發炎破壞濾泡、把儲存的激素釋出，**暫時性**，之後常轉為低下 |
| 外源性 | 吃太多甲狀腺素或含碘藥物 |

## 表現 {#manifestations}

| 系統 | 表現 |
|---|---|
| 代謝 | **怕熱**、**多汗**、**食慾增加但體重減輕**、疲倦 |
| 心血管 | **心搏過速**（常 > 100 次／分）、心悸、脈搏壓變大、心房顫動、高輸出性心衰竭 |
| 神經精神 | **神經質**、易怒、焦慮、失眠、**手指細顫**、深肌腱反射**增強** |
| 腸胃 | 腸蠕動加快、**腹瀉** |
| 皮膚與指甲 | 皮膚**溫熱潮濕**、髮絲細軟、**指甲遠端與甲床分離** |
| 肌肉骨骼 | 近端肌肉無力、骨質流失 |
| 生殖 | **月經量減少或停經**、不易受孕；少女可能**原發性無月經** |
| 眼睛（葛瑞夫茲氏病） | **突眼**、眼瞼後縮、凝視、眼睛乾澀畏光、複視 |
| 皮膚（葛瑞夫茲氏病） | **脛前黏液水腫**（脛前皮膚增厚、**非凹陷性**） |
| 血脂 | 膽固醇**下降** |

- 老年人可能只有心房顫動、體重減輕與淡漠，典型症狀不明顯
- 檢驗：**TSH 下降**、游離 T4 上升、T3 上升；葛瑞夫茲氏病**甲狀腺刺激抗體**陽性、攝碘率增加
- 甲亢和聽力損失的關聯最小（高血壓、糖尿病、頭部外傷較會影響聽力）

## 治療 {#treatment}

### 抗甲狀腺藥 {#antithyroid-drugs}

- **硫醯胺類**(thionamides)：**methimazole**、**PTU**(propylthiouracil)，抑制甲狀腺素**合成**；PTU 另外抑制周邊 T4 轉成 T3
- 選擇：ATA 2016 建議多數人用 **methimazole**；**PTU** 用在**懷孕第一孕期**與**甲狀腺風暴**（PTU 有嚴重肝毒性）；國考常以 PTU 為例
- 用法：**先大劑量**，甲狀腺功能恢復後**逐漸減量**維持，通常治療 1–2 年；數週內才開始改善；**症狀消失或數值正常不可自行停藥**
- 副作用：**顆粒性白血球減少**（喉嚨痛、發燒、口腔潰瘍 → 停藥並立即驗白血球）、皮疹、肝功能異常
- 藥物細節見 [[thyroid-drugs#thionamides]]

### 碘劑 {#iodine}

- **飽和碘化鉀溶液**(SSKI)、盧戈氏液：大量碘抑制甲狀腺素的**釋放與合成**，並讓腺體**變小、血管減少**
- 用途：**甲狀腺切除術前**準備（約 7–10 天）、甲狀腺風暴
- 只能短期用，**不宜超過約 2 週**，否則會**逸脫**，抑制作用消失，大量甲狀腺素釋出反而加重
- 服用：味苦且刺激，可**稀釋在牛奶或果汁**中、**用吸管**喝以免**牙齒染色**；存放在深色玻璃瓶避光
- 甲狀腺風暴時要在抗甲狀腺藥**之後**（約 1 小時）才給，避免碘被拿去合成更多激素

::questions{ids="107-2_MS_070,112-1_MS_070,113-1_MS_046,106-2_MS_065,110-2_MS_068,106-1_MS_072"}

### 放射性碘(¹³¹I) {#radioactive-iodine}

- 甲狀腺會攝取放射性碘，被輻射破壞而縮小；口服，**懷孕與哺乳禁用**
- 服用前後依醫囑空腹，以利吸收
- **居家防護**（第一週左右，依醫院指示）
   1. **限制訪客**，**單獨睡**，避免和**孕婦與嬰幼兒**近距離或長時間接觸
   2. 經**尿液、糞便、唾液**排出：如廁後**沖水 2–3 次**，馬桶坐下使用避免噴濺，勤洗手
   3. 餐具、毛巾分開，衣物分開洗
   4. **多喝水**、多排尿，加速排出（不是限水）
   5. 實際隔離天數與距離依劑量而定；台灣目前沒有公告的出院劑量門檻（核能安全委員會研議中），以各院衛教單張為準（**待核對**）
- 效果在數週到數月出現；**之後很多人會變成甲狀腺功能低下**，需終身定期追蹤甲狀腺功能（不是追蹤甲亢復發的 T3 上升）

::questions{ids="114-1_MS_043"}

### 護理 {#nursing}

1. **飲食**：**高熱量、高蛋白、高碳水化合物**與維生素，少量多餐；**避免高纖**（加重腹瀉）、避免咖啡因
2. **環境**：涼爽、安靜，多汗時勤換衣被；安排休息
3. **突眼照護**
   1. 睡覺**抬高床頭**，減少眼眶水腫
   2. 戴太陽眼鏡、人工淚液；眼瞼無法閉合時睡前貼閉或用眼罩，預防角膜受傷
   3. 限鹽可減輕眶周水腫（和限鉀無關）
4. 監測心跳、體重、睡眠與情緒；依醫囑給 β 阻斷劑（見 [[beta-blockers]]）
5. 教導按時服藥、識別顆粒性白血球減少與甲狀腺風暴的徵象

::questions{ids="112-3_MS_047,111-2_MS_073"}

## 甲狀腺風暴 {#thyroid-storm}

- 甲亢**急性惡化**、危及生命；誘因：**感染**、**手術**（尤其術前未控制好）、放射性碘、突然停藥、外傷、分娩、糖尿病酮酸中毒
- 表現
   1. **高燒**（常 > 38.5–40°C）、大量流汗、脫水
   2. **心搏過速**（常 > 130 次／分）、心房顫動、心衰竭
   3. 躁動不安、**譫妄**、昏迷
   4. 噁心嘔吐、腹瀉、黃疸
- 檢驗：游離 T4、T3 **上升**，**TSH 下降**（不是上升）；診斷靠臨床（可用 Burch-Wartofsky 評分）
- 處置(ATA 2016)
   1. **propranolol**：最快緩解心搏過速、顫抖與躁動（也減少 T4 轉 T3）
   2. **抗甲狀腺藥**：PTU 或 methimazole，阻斷合成
   3. **碘劑**：抗甲狀腺藥給後約 1 小時再給，阻斷釋放
   4. **類固醇**(hydrocortisone)：減少 T4 轉 T3、補充相對不足
   5. 降溫：冰毯、**acetaminophen**；**不用 aspirin**（會把甲狀腺素從結合蛋白擠出，游離激素更多）
   6. 補充水分與葡萄糖、治療誘因、加護病房監測
- levothyroxine 是治療**低下**的，風暴時不能給

## 甲狀腺切除術 {#thyroidectomy}

- 方式：**次全切除**（保留部分組織維持功能，甲亢常用）、全切除（癌症；術後終身補充甲狀腺素）
- **術前**
   1. 用抗甲狀腺藥讓功能接近正常，**碘劑 7–10 天**讓腺體變小、減少出血；β 阻斷劑控制心跳
   2. 教導術後起身時**雙手托住後頸**，避免牽扯傷口；練習深呼吸與咳嗽
- **術後**
   1. **半坐臥**，**頭頸以枕頭支托固定**，避免頸部過度屈曲或伸展（不可平躺或俯臥）
   2. **呼吸道**：觀察呼吸困難、喘鳴、頸部腫脹；傷口**出血**（連頸後的敷料也要看）與血腫、**聲門水腫**可造成**急性呼吸道阻塞**；床邊備氣管切開包與抽吸設備
   3. **喉返神經**：每次評估請病人說話，**單側受損 → 聲音沙啞**；**雙側受損 → 失聲、呼吸道阻塞**
   4. **低血鈣**（副甲狀腺被誤切或受傷）：**口周與指尖刺麻**、肌肉抽搐、**Chvostek 徵象**、**Trousseau 徵象**、喉部痙攣；術後**一週內**特別注意，床邊備**葡萄糖酸鈣**（機轉見 [[thyroid-parathyroid#parathyroid-disorders]]）；這是低血鈣，不是甲狀腺功能低下
   5. **甲狀腺風暴**：術後 12–48 小時內注意高燒與心搏過速
   6. 鼓勵**深呼吸與咳嗽**（托住頸部），預防肺部併發症
   7. 飲食：先給**冰涼的液狀或軟質食物**，減輕喉嚨不適；之後均衡飲食，不需要高碘
- 低血鈣的急性處置與副甲狀腺疾病的照護見 [[parathyroid-disorders#acute-hypocalcemia]]
