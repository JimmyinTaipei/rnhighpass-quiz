骨折是骨的連續性中斷，常合併肌肉、血管、神經損傷。本頁整理骨折分類與表徵、急救、癒合過程、併發症與腔室症候群、石膏、牽引、外固定器、髖骨骨折、脫臼、截肢，以及兒童與新生兒骨折；骨的構造見 [[skeletal-system]]，石膏肢體的基本照護與拐杖見 [[activity-immobility#cast-care]]，扭傷冷熱敷見 [[heat-cold-therapy#sprain]]，脂肪栓塞的機轉見 [[thrombosis-embolism-infarction#fat-embolism]]，骨質疏鬆骨折見 [[osteoporosis]]

## 重點摘要 {#summary}

- 表徵：**疼痛與壓痛、腫脹瘀血、畸形、功能喪失、異常活動、骨擦音**、肌肉痙攣；線狀骨折可能症狀不明顯，要照 X 光
- 到院前：先處理危及生命的問題，骨折部位**先固定再搬動**（超過上下兩個關節）；**不在現場復位**、開放性傷口蓋無菌敷料，**冰敷不熱敷**
- 癒合五期：**血腫形成 → 細胞增生 → 骨痂形成 → 骨化（鞏固） → 重塑**；成人約 **10–18 週**；骨痂期需要足夠**蛋白質、鈣、維生素 D**
- 神經血管評估 **6P**：疼痛、蒼白、感覺異常、麻痺、脈搏消失、溫度改變（冰冷）；**腫脹與瘀斑不是 6P**
- **腔室症候群**：筋膜包住的腔室壓力升高 → 缺血；最早是**與傷勢不成比例的疼痛**、被動牽拉痛、**感覺異常**；處置是**立即解除石膏或敷料**、肢體**與心臟同高**（不抬高、不冷熱敷）、必要時**筋膜切開**
- 石膏：未乾前不覆蓋、用手掌托；**灼熱點、臭味、滲液 → 感染**；**不可伸入抓癢**、不用熱風；拆石膏後皮膚黃棕色皮屑正常、**漸進活動不立刻負重**
- 牽引：**重錘懸空**、**拉力與骨長軸平行**、減少摩擦、**重量依醫囑不自行調整**、不用被單蓋住繩子；床尾抬高形成反牽引
- 髖骨骨折：患肢**外旋、縮短**；外固定器病人**可下床**，插針處無菌消毒
- 膝上截肢：術後立即**彈性繃帶**控制水腫、殘肢抬高**不超過 24–48 小時**、每天**俯臥**防髖屈曲攣縮、**不在兩腿間放枕頭**
- 兒童：青枝骨折、骨骺板受傷影響生長；石膏未固定的關節要**照常活動**；新生兒鎖骨骨折**仰睡**、患側先穿後脫

### 國考常考點 {#exam-points}

- 骨折到院前最優先是**固定骨折部位**，不是止痛、復位或熱敷
- 癒合順序：**血腫 → 細胞增生 → 骨痂 → 骨化 → 重塑**(①③⑤②④)；病理學說法是機化血塊 → **軟性骨痂 → 骨性骨痂 → 層狀骨**
- 血腫期、細胞增生期患肢要**固定**，不做等張運動；**骨痂期補充營養**；重塑期仍要漸進運動
- 成人骨折癒合約 10–18 週；「6 個月仍可見骨折線且骨痂生長緩慢」是**延遲癒合**的描述，不是骨折不癒合(106-2_MS_017)
- **病理性骨折**＝骨本身有病變（轉移性腫瘤、骨鬆、骨腫瘤）在輕微外力下骨折；長期行軍、運動員反覆外力是**疲勞性骨折**
- 6P **不包括腫脹**；兒童石膏的異常徵象**不包括瘀斑（紫斑）**
- 腔室症候群不是長期臥床的併發症，是骨折、擠壓傷、石膏或環形燒傷後的**急性**問題
- 腔室症候群的表現**不包括皮膚出血斑點**；包括感覺異常（兩點辨識變差）、脈搏減弱、微血管充填 > 3 秒、肢端蒼白冰冷
- 腔室症候群處置：**去除敷料、夾板或石膏**；**不可抬高超過心臟**、不冷熱敷、不加壓包紮
- 上石膏後小腿末端**感覺異常**要立即處理（去除石膏）；石膏內發癢、微血管充填 2 秒、足背脈搏 2+ 都正常
- 石膏**灼熱點**表示其下有感染或壓瘡，要立即處理；石膏「酸味」不是典型感染描述，國考認為臭味才是(111-2_MS_020)
- 長骨骨折後皮膚出現**點狀出血**先想**脂肪栓塞**，不是低血容性休克
- 石膏遠端**蒼白冰冷＝動脈**受阻；**發紺、腫脹＝靜脈**回流受阻
- **不可用抓癢器**伸入石膏內；癢可用冷風吹
- 拆石膏 3 個月：皮膚**黃棕色皮屑**、肢體僵硬、平衡感改變；肌肉張力**下降**（不是增加）
- 移除下肢石膏後**不要立即下床行走**，先做肌力與關節運動再漸進負重；行走時可用彈性繃帶
- 牽引：**重錘懸空不擺動**、**摩擦力愈小拉力愈有效**、**拉力與骨長軸平行**；**不用罩單蓋繩子**、**不自行調整重量**
- 勃克式牽引是**直線式皮膚牽引**，用於髖或股骨骨折術前制動與下背痛；腳跟懸空是為了**預防壓傷**，不是「避免血液循環受阻」(107-2_MS_017)
- 骨盆牽引是**皮膚牽引**；**床尾抬高**增加反牽引；拉力體重的 1/2 太重
- 骨外固定器：插針處**無菌消毒**、可預防性抗生素、做等長運動；**不需要避免下床**
- 髖骨骨折：患肢**外旋、縮短**
- 截肢：**彈性繃帶**控制水腫並塑形；**枕頭抬高不可超過 24–48 小時**；**膝上截肢採俯臥**防髖屈曲攣縮；**兩腿間不放枕頭**（會外展攣縮）；殘肢要運動
- 兒童石膏：**未固定的上下關節照常活動**；不可用烤燈、吹風機熱風烘乾；抬高患肢；石膏灼熱點或滲液不是正常
- 5 歲以下兒童跌倒，國考答**髖部**容易脫臼（實務上兒童最常見的是**牽引肘**，由手被拉扯造成）
- 新生兒鎖骨骨折：**患側先穿後脫**、不測圍巾徵象、從背部臀部抱起、**仍要仰睡**（趴睡錯）

## 分類與表徵 {#types}

| 分法 | 類型 | 說明 |
|---|---|---|
| 皮膚是否破損 | **閉鎖性** | 皮膚完整 |
| | **開放性**（複雜性） | 骨端穿出或傷口通到骨折處；**感染（骨髓炎）風險高**，需清創與抗生素（見 [[skin-bone-infections]]） |
| 斷裂程度 | 完全 | 骨完全斷開 |
| | 不完全 | 只斷一側，例：**青枝骨折**（兒童） |
| 骨折線 | 橫、斜、**螺旋**（扭轉力；幼兒要想到虐待）、**粉碎**（三塊以上）、**壓迫**（椎體，骨鬆）、嵌入、撕裂 | |
| 原因 | 創傷性 | 外力大於骨的強度 |
| | **病理性** | 骨有病變（**轉移性腫瘤**、骨鬆、骨腫瘤、骨髓炎），輕微外力就斷 |
| | **疲勞性** | 反覆外力累積（長期行軍、跑者） |

- 常見名稱：**柯雷氏骨折**（橈骨遠端，跌倒手撐地，銀叉畸形）；**股骨頸骨折**（老人跌倒）；**鎖骨骨折**（新生兒產傷、兒童）
- 表徵（《內外科護理學》下冊 p.583）：疼痛壓痛、腫脹瘀血、**畸形**（縮短、成角、旋轉）、**功能喪失**、**異常活動**、**骨擦音**、肌肉痙攣、感覺受損
- 診斷：**X 光**（復位前後與癒合期都要照）；複雜者電腦斷層、核磁共振

## 急救與治療原則 {#first-aid}

1. 先評估**呼吸道、呼吸、循環**，處理大出血與休克（股骨、骨盆骨折可大量出血）
2. **固定**：用夾板固定骨折**上下兩個關節**，再搬動；懷疑脊椎受傷要整體翻身（見 [[spinal-cord-injury]]）
3. **不在現場復位**；開放性骨折露出的骨端**不推回**，覆蓋無菌敷料
4. 抬高患肢、**冰敷**減輕腫脹（**不熱敷**）
5. 評估受傷部位以下的神經血管(6P)
- 醫療處置：**復位**（閉鎖性徒手復位、牽引復位、**開放性復位內固定**）→ **固定**（石膏、夾板、牽引、外固定器、內固定） → **復健**
- 術後可用加壓冷療裝置（例：Aircast）減輕腫脹與疼痛

## 骨折癒合 {#healing}

| 期 | 時間（大約） | 發生什麼 | 護理重點 |
|---|---|---|---|
| **血腫形成** | 受傷後 1–3 天 | 斷端出血形成血腫，發炎反應 | **固定**、冰敷抬高、止痛 |
| **細胞增生** | 數天 | 纖維母細胞、軟骨母細胞、造骨細胞增生，形成肉芽組織 | 仍要固定，不做患肢等張運動 |
| **骨痂形成** | 2–6 週 | 軟骨與編織骨形成**骨痂**（軟性 → 骨性），連接斷端 | **補充蛋白質、鈣、維生素 D**；等長運動 |
| **骨化（鞏固）** | 數週到數月 | 骨痂被**骨**取代，X 光看到骨折線消失 | 依醫囑漸進負重 |
| **重塑** | 數月到 1 年以上 | 蝕骨與造骨細胞把多餘骨痂修成**層狀骨** | 漸進運動、恢復功能 |

- 成人長骨約 **10–18 週**癒合；兒童較快、老人較慢
- 影響癒合：**年齡、血液供應**（股骨頸、舟狀骨、脛骨下 1/3 血供差）、**固定是否穩固**、感染、營養、**抽菸**、糖尿病、類固醇
- **延遲癒合**：癒合速度比預期慢；**不癒合**：骨折端無法接合、癒合停止，常見於肱骨中 1/3、股骨頭、脛骨下 1/3（《內外科護理學》下冊 p.592）；處置有支架、植骨、電刺激；**癒合不正**：在錯誤位置癒合
- 病理機轉與一般傷口修復見 [[inflammation-repair#repair]]

## 併發症 {#complications}

| 併發症 | 時間 | 重點 |
|---|---|---|
| **休克** | 立即 | 骨盆、股骨骨折出血量大 |
| **腔室症候群** | 數小時內 | 見下節 |
| **脂肪栓塞** | 多在 24–48 小時 | 長骨（股骨）、骨盆骨折；**呼吸困難**、**意識改變**、**前胸腋下點狀出血**；早期固定預防，給氧（見 [[thrombosis-embolism-infarction#fat-embolism]]） |
| **深部靜脈血栓、肺栓塞** | 數天 | 下肢骨折、髖部手術、臥床；早期活動、抗凝（見 [[anticoagulants#dvt-assessment]]） |
| **感染、骨髓炎** | 數天到數週 | 開放性骨折最常見（見 [[skin-bone-infections]]） |
| **缺血性壞死** | 數月 | **股骨頸骨折**傷到股骨頭血管 → 股骨頭壞死 |
| 延遲癒合、不癒合、癒合不正 | 數月 | 見上節 |
| 廢用症候群 | 長期 | 肌肉萎縮、關節僵硬、骨質流失（見 [[activity-immobility#immobility-effects]]） |

## 腔室症候群 {#compartment-syndrome}

- 定義：肌肉、神經、血管被**筋膜**包成腔室，腔室內壓力上升（內部出血水腫，或外面石膏、敷料、環形燒傷焦痂太緊） → 微血管灌流下降 → 肌肉神經**缺血**；不處理約 4–6 小時造成永久傷害（**待核對**）
- 好發：**前臂、小腿**骨折、擠壓傷、石膏太緊、**環形燒傷**（見燒傷頁）、長時間壓迫
- **6P**（神經血管評估）

| P | 表現 | 說明 |
|---|---|---|
| **Pain** 疼痛 | **與傷勢不成比例**、止痛藥無效、**被動牽拉手指腳趾時劇痛** | 最早、最重要 |
| **Paresthesia** 感覺異常 | 麻、刺痛、**兩點辨識或尖鈍覺變差** | 神經對缺血敏感，也是早期徵象；國考也接受「最早出現感覺異常」(108-1_MS_019) |
| **Pallor** 蒼白 | 肢端蒼白、**微血管充填 > 3 秒** | |
| **Paralysis** 麻痺 | 無法活動手指腳趾 | 晚期 |
| **Pulselessness** 脈搏消失 | 遠端脈搏減弱或摸不到 | **晚期**，有脈搏不代表沒有腔室症候群 |
| **Poikilothermia** 冰冷 | 肢端變冷 | |

- 基護與部分課本只講 **5P**（少了冰冷）；**腫脹、瘀斑、皮膚出血斑點都不是 6P**
- 處置
   1. **立即**通知醫師，**鬆開或剖開石膏、移除敷料與彈繃**
   2. 肢體放在**與心臟同高**：抬高會降低動脈灌注壓，加重缺血；**不冰敷、不熱敷**
   3. 測腔室壓力：壓力 > 30 mmHg 或 ΔP（舒張壓 − 腔室壓）< 30 mmHg 合併臨床表現 → **筋膜切開術**（教學網站，二手）
   4. 筋膜切開後傷口開放、無菌換藥，數天後關閉或植皮
- 與燒傷的關係：環形燒傷的焦痂沒有彈性 → **焦痂切開術**，不改善再筋膜切開

## 石膏 {#cast}

### 種類 {#cast-types}

| 材質 | 特性 |
|---|---|
| 熟石膏 | 便宜、塑形好；**乾燥需 24–72 小時**、重、怕水 |
| 玻璃纖維（合成） | 輕、**約 30 分鐘內硬化**、透 X 光、較耐水；邊緣較粗糙 |

- 形式：短臂、長臂、短腿、長腿、**人字形石膏**（髖部，用在髖關節發育不良與股骨骨折，會陰處開窗方便排泄）、石膏背心
- 依《內外科護理學》下冊 p.542–543

### 上石膏與未乾時 {#cast-application}

1. 上石膏前：清潔皮膚、套**石膏襪套**、骨突處墊**棉墊**
2. 石膏凝固時會**發熱**（約 10–15 分鐘），之後因水分蒸發病人會**覺得冷**，非石膏處要保暖（《內外科護理學》下冊 p.546）
3. 未乾前：**用手掌托**（手指會壓出凹痕 → 壓瘡）；放在枕頭上；**不覆蓋衣物被單**，讓水分散發；每 2 小時翻身讓各面乾燥
4. **不用烤燈、吹風機熱風**加速乾燥（外乾內濕、燙傷）
5. **抬高患肢**高於心臟（沒有腔室症候群時）減輕腫脹，前 24–48 小時可在石膏兩側冰敷
6. 石膏邊緣用膠布做**花瓣狀包邊**，預防磨破皮膚

### 評估與護理 {#cast-care}

| 觀察 | 代表 | 處理 |
|---|---|---|
| 遠端**蒼白、冰冷**、脈搏弱 | **動脈**循環受阻 | 立即通知 |
| 遠端**發紺、腫脹** | **靜脈**回流受阻 | 抬高，不改善通知 |
| 疼痛加劇、被動牽拉痛、麻、無法動 | **腔室症候群** | 立即通知、剖開石膏 |
| 石膏表面**灼熱點** | 下方**感染或壓瘡** | 立即通知（可能開石膏窗） |
| **臭味、滲液** | 感染、組織壞死 | 通知 |
| 石膏內發癢 | 正常 | **冷風吹**、輕敲石膏；**不可伸入抓癢** |
| 長骨骨折後點狀出血 | **脂肪栓塞** | 給氧、通知 |

- 每 1–2 小時評估 6P，前 24–48 小時最密集
- 運動：患肢做**等長運動**防肌肉萎縮；**未被固定的關節做全關節運動**；健側照常活動（見 [[activity-immobility#isometric-isotonic]]）
- 衛教：保持石膏乾燥（洗澡套塑膠袋）、不放異物進石膏、石膏破裂鬆動要回診

### 拆石膏後 {#cast-removal}

- 皮膚有**黃棕色皮屑**（角質與皮脂堆積）：**溫水輕洗、塗乳液**，不用力刷
- 肌肉**萎縮、張力下降**、關節僵硬、**平衡感改變** → **漸進**做肌力與關節運動，再扶持練習行走；**不立即下床負重**
- 患肢易腫：行走時可用**彈性繃帶**，休息時抬高
- 皮膚久未曬太陽較敏感，**避免曝曬**

::questions{ids="111-2_MS_020,109-1_MS_020,105-1_MS_019,109-2_MS_021,114-2_MS_013"}

## 牽引 {#traction}

- 目的：**復位與固定**、減輕**肌肉痙攣**與疼痛、預防攣縮變形
- 原理：**牽引力**（重錘） vs **反牽引力**（病人體重、與床的摩擦力）；常**抬高床尾或床頭**讓體重形成反牽引

| 類型 | 做法 | 例子 |
|---|---|---|
| **皮膚牽引** | 牽引帶或泡棉腿套貼在皮膚上；**重量較輕**；可間歇使用 | **勃克式牽引**（直線，髖或股骨骨折術前、下背痛）、**骨盆牽引**（下背痛）、頸椎牽引、**布萊安特牽引**（幼兒） |
| **骨骼牽引** | **鋼針穿過骨頭**；重量較重、持續使用 | 股骨幹骨折的平衡懸吊牽引、顱骨牽引（頸椎骨折） |

### 牽引的照護原則 {#traction-care}

1. **重錘懸空**：不碰床、不碰地、**不擺動**；不碰撞病床
2. 繩子在滑輪溝內、**不被被單或罩單蓋住**（會增加摩擦、也看不到）；**摩擦力愈小，拉力愈有效**
3. **拉力方向與骨的長軸平行**；病人維持在床的正中，不滑向床尾
4. **重量依醫囑**，**不可自行增減或拿掉**（床旁記錄單核對）
5. 每 1–2 小時評估 6P 與皮膚：牽引帶下、**腳跟**、骨突處防**壓傷**；**勃克式牽引的腳跟懸空是為了預防壓瘡**；腓骨頭附近不可受壓（**腓總神經** → 足下垂）
6. 骨骼牽引：**插針處每天無菌消毒**，觀察紅腫滲液（骨髓炎）
7. 做等長運動、健側運動、深呼吸咳嗽，預防臥床併發症
- 依《內外科護理學》下冊 p.553 表 17-15 方向重新整理

### 骨盆牽引 {#pelvic-traction}

- 用於下背痛、腰椎間盤突出：骨盆帶套在髂嵴，**屬皮膚牽引**
- 姿勢：床頭稍抬高、膝屈曲（減少腰椎前凸）；**床尾抬高**增加反牽引
- 拉力依醫囑，**體重的 1/2 太重**(113-1_MS_013)；可間歇使用
- 背架照護與椎間盤突出術後見 [[cranial-nerve-spine-disorders]]

::questions{ids="114-3_MS_013,107-2_MS_017,113-1_MS_013"}

## 外固定器 {#external-fixator}

- 鋼針打進骨折兩端，用外面的支架連接；用在**開放性骨折**、粉碎性骨折、肢體延長
- 照護
   1. **插針處**：每天以**無菌技術**消毒，觀察紅腫熱痛、滲液、鬆動；必要時**預防性抗生素**
   2. 患肢抬高減輕腫脹，評估 6P
   3. 做**等長運動**與未固定關節的活動
   4. 骨折穩定後**可下床活動**（依醫囑部分負重），**不需要因怕鬆脫而臥床**
   5. 支架不可當把手提起肢體

::questions{ids="114-3_MS_012"}

## 髖骨骨折 {#hip-fracture}

- 好發**老年女性、骨質疏鬆**，多在跌倒後；分**股骨頸骨折**（關節囊內，易**缺血性壞死**、不癒合）與粗隆間骨折（關節囊外）
- 表徵：**患肢外旋、縮短**、髖部或鼠蹊疼痛、無法站立
- 處置：術前可用**勃克式牽引**制動減痛；手術（內固定或人工髖關節置換，見 [[osteoarthritis#tha]]）；術後早期下床
- 護理：預防**深部靜脈血栓**、肺炎、壓傷、譫妄；術後下肢可包彈性繃帶促進靜脈回流（見 [[bandaging]]）；防跌與骨鬆治療

::questions{ids="105-1_MS_020"}

## 脫臼 {#dislocation}

- 關節面完全分離＝**脫臼**；部分分離＝半脫臼；**肩關節最常見**（關節盂淺）
- 表徵：劇痛、關節變形、**活動度喪失**、肢體長度改變
- 處置：盡早**復位**（避免缺血性壞死與神經血管傷害），之後固定、評估神經血管
- 人工髖關節術後脫位的表現見 [[osteoarthritis#tha-complications]]

## 截肢 {#amputation}

- 原因：**周邊血管疾病**（糖尿病最多）、嚴重創傷、**骨腫瘤**、感染
- 部位：膝上、膝下、足部；上肢肘上、肘下等；保留愈長的殘肢、愈多關節，義肢功能愈好（《內外科護理學》下冊 p.596）

### 術後照護 {#amputation-care}

1. **控制水腫、塑形**：術後**立即用彈性繃帶**由遠端往近端、以**回反摺形**包紮殘肢（見 [[bandaging#techniques]]）；或用硬敷料
2. **抬高殘肢**減輕腫脹，但**不超過 24–48 小時**，之後不再墊枕頭（避免**屈曲攣縮**）
3. **預防攣縮**
   1. **膝上截肢**：怕**髖關節屈曲、外展攣縮** → 每天**俯臥**數次、殘肢**維持內收**，**兩腿間不放枕頭**
   2. **膝下截肢**：怕**膝關節屈曲攣縮** → 膝伸直，不在膝下墊枕、不長時間坐著屈膝
4. **殘肢運動與肌力訓練**及早開始（不是不動）；上肢與健肢肌力訓練準備用拐杖
5. 殘肢皮膚照護：每天清潔、檢查；傷口癒合後**由外往縫線方向按摩**、輕拍，讓殘肢耐受壓力
6. **幻肢感與幻肢痛**：是真的疼痛，不是想像；止痛、熱敷、按摩、鏡像治療
7. 義肢：暫時性義肢早期步行；**起床後就穿上**（避免殘肢腫脹）；永久義肢約術後數月殘肢定型後裝配
8. 心理：身體心像改變、哀傷，鼓勵表達與參加病友團體

## 兒童與新生兒骨折 {#pediatric}

- 兒童骨骼特點：**骨膜厚、骨較有彈性** → 常見**青枝骨折**；癒合快；**骨骺板**受傷可能造成**生長停滯、肢體長短不一**
- 常見：鎖骨（新生兒、幼兒）、**肱骨髁上骨折**（易傷肱動脈與正中神經）、前臂；**螺旋骨折、多處不同時期骨折要想到兒虐**（見 [[family-violence]]）
- 脫臼：國考題答 **5 歲以下兒童跌倒容易髖部脫臼**（108-2_OP_076，詳解也註明實務上兒童創傷性髖脫臼少見）；幼兒最常見的是**牽引肘**（橈骨頭半脫位，手被往上拉造成）
- 兒童石膏照護
   1. 評估皮膚、甲床顏色溫度、6P；抬高患肢
   2. **未被石膏固定的上下關節要照常活動**，減少僵硬
   3. **不用烤燈、吹風機熱風**；石膏弄濕不可用熱風烘
   4. 石膏表面灼熱點或滲液**不是正常**，要通知
   5. 人字形石膏、Bryant 牽引、Pavlik 吊帶見 [[pediatric-musculoskeletal#ddh-treatment]]

### 新生兒鎖骨骨折 {#clavicle-newborn}

- 原因：**巨嬰、肩難產**等產傷；表現為患側手臂少動、**擁抱反射不對稱**、局部骨擦感
- 多為青枝骨折，約 2–4 週自行癒合，只需限制患側手臂活動
- 護理
   1. 穿衣**患側先穿、脫衣患側後脫**
   2. 抱起時**支撐頭頸、背部與臀部**，**不從手臂或腋下**抱
   3. **不做圍巾徵象**（手肘拉過對側）
   4. **仍然仰睡**（預防嬰兒猝死），不可趴睡
- 新生兒產傷的其他種類見 [[neonatal-disorders#birth-injuries]]
