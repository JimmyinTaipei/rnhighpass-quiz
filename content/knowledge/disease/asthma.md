**氣喘**是**氣道的慢性發炎疾病**：氣道對各種刺激過度敏感，出現**可逆的氣流阻塞**，症狀是**反覆的喘鳴、咳嗽、胸悶與呼吸困難**，常在**夜間或清晨**加重，可以自行緩解或經治療緩解。台灣約有 **200 萬人**受氣喘困擾（2022 成人指引），**學齡兒童盛行率約 15%**（2023 兒童指引）。氣喘多數屬**第Ⅰ型過敏**（[[hypersensitivity-reactions#type-1]]），所以這一頁和過敏頁面互相連結；藥物細節見 [[asthma-drugs]]

## 重點摘要 {#summary}

- **病生理**：Th2、**IgE**、肥大細胞、**嗜酸性球(IL-5)**造成**氣道發炎、支氣管收縮、黏液增加**；長期造成**氣道重塑**（基底膜增厚、平滑肌肥大、黏液腺增生）
- **典型**：**呼氣性喘鳴**、咳嗽、胸悶，症狀**多變**，夜間與清晨較重；常合併過敏性鼻炎與異位性皮膚炎
- **診斷**：病史＋**肺功能證實的變異性氣流阻塞**（支氣管擴張劑後 FEV1 上升 **≥12% 且 ≥200 mL**，或**尖峰流速日變異率 > 10%**）
- **治療**：**控制型藥物**（吸入型類固醇為核心）＋**緩解型藥物**；**GINA 不再建議只用 SABA**，優先採 **ICS-formoterol 當緩解藥(Track 1)**
- **急性發作**：**SABA**（吸入器加輔助器）、**早期口服類固醇**、**氧氣**，重度加 **ipratropium**；**再評估**，不要常規做胸部 X 光或給抗生素
- **護理**：**環境控制**、**正確使用吸入器**（用 ICS 後漱口）、**尖峰流速監測**、**氣喘行動計畫**

### 國考常考點 {#exam-points}

- **典型呼吸音**是**喘鳴音（wheeze，呼氣性）**；**stridor** 是**吸氣性**，代表上呼吸道阻塞，不是氣喘
- 氣喘發作：**平滑肌收縮（不是舒張）**、**血管通透性增加**、黏膜水腫、黏液增加；**IgE 升高**；**嗜酸性球**浸潤；**紅血球不參與**
- **IL-5** 刺激嗜酸性球；**TH2** 參與；**組織胺、白三烯**是介質，**緩激肽**不是主要的氣喘介質
- **呼吸性酸中毒**的原因：**低血氧**與通氣不足使 CO₂ 滯留；嚴重時 PaCO₂ **「看似正常」是危險徵兆**
- **嚴重發作時**：呼吸急促、**心跳加快**（不是減慢）、使用輔助肌、**無法說完整句**、**坐臥式（坐直、前傾）**最適合
- **尖峰流速計**目的：**監測氣道狀況與嚴重度、評估治療反應**（不是訓練呼吸肌或促進排痰）；**同一支、取三次最高值**
- **吸入型類固醇**：預防用、**不能緩解急性發作**、**用後要漱口**（預防口腔念珠菌）
- 氣喘病人避免使用**非選擇性 β 阻斷劑(propranolol)**；也慎用 **aspirin／NSAID**（部分人會誘發發作）
- **氣喘控制評估(GINA)**：過去 4 週的**日間症狀每週 > 2 次、夜間因氣喘醒來、SABA 緩解每週 > 2 次、活動受限**，**0 項＝控制良好，1–2 項＝部分控制，3–4 項＝控制不佳**
- 護理衛教：用**熱水（55℃ 以上）每週洗寢具**、避免羽絨與地毯、**百葉窗取代布窗簾**、**避免高強度運動誘發**（游泳等可控制呼吸的有氧運動較適合）、**沙塵暴時減少外出並戴口罩**

## 病生理 {#pathophysiology}

### 發炎機轉 {#inflammation}

1. **致敏**：過敏原由 APC 呈現給 **Th2**，Th2 分泌 **IL-4、IL-5、IL-13**，B 細胞製造 **IgE**，附著在**肥大細胞**上（[[t-lymphocytes#th-subsets]]、[[b-lymphocytes#class-switching]]）
2. **早期反應（數分鐘）**：過敏原再次進入，肥大細胞去顆粒，釋出**組織胺、前列腺素 D2、白三烯**，造成**支氣管收縮、黏膜水腫、黏液分泌**
3. **晚期反應（數小時）**：**IL-5** 吸引**嗜酸性球**，釋出毒性蛋白傷害上皮，使氣道**持續發炎與高反應**
4. **非第 2 型**（嗜中性球為主、肥胖相關等）的氣喘，對吸入型類固醇反應較差
5. **氣道高反應性**：氣道對冷空氣、運動、煙霧等**輕微刺激**就收縮，是氣喘的特徵

### 病理變化 {#pathology}

| | |
|---|---|
| **支氣管壁** | **黏膜水腫**、**嗜酸性球與淋巴球浸潤**、**平滑肌肥大與增生** |
| **基底膜** | **增厚**（氣道重塑） |
| **黏液腺與杯狀細胞** | **增生**，黏液增加，可形成**黏液栓** |
| **痰液** | 可見 **Curschmann 螺旋**與 **Charcot-Leyden 結晶**（嗜酸性球產物） |

1. **可逆性**：早期的支氣管收縮可由支氣管擴張劑逆轉；**長期未控制**會出現**固定的氣流阻塞**（氣道重塑）
2. 兒童與成人都有；**兒童氣喘**常與**異位性體質**相關，**IgE 升高**

## 誘發因子 {#triggers}

| 類別 | 例子 |
|---|---|
| **過敏原** | **塵蟎**、蟑螂、寵物、黴菌、花粉（春季）；食物（較少見；「台灣最常見的氣喘過敏原是海鮮」是錯誤敘述） |
| **呼吸道感染** | **病毒感染**（感冒），兒童最常見的發作誘因 |
| **環境** | **冷空氣**（例如愛吃冰、沒穿外套）、空氣污染、**沙塵暴**、菸、二手菸、香水與刺激性氣味 |
| **運動** | **運動誘發**：運動後 5–10 分鐘最明顯 |
| **藥物** | **非選擇性 β 阻斷劑**、**aspirin 與 NSAID**（阿斯匹靈誘發氣喘，見 [[antihistamines-autacoids#eicosanoids]]） |
| **其他** | **情緒起伏**、**胃食道逆流**、肥胖、經期前後、**職業暴露** |

1. 兒童常把發作歸因於「吃冰」或「沒戴口罩」，護理上要**肯定其觀察**，再說明**真正的誘因是過敏原、感染與冷空氣**，不是只有食物冷熱
2. **誘因控制**是預防的基礎（環境控制見 [[allergic-rhinitis#environment]]）
3. **懷孕**的氣喘病人**不要停用吸入型類固醇**（2022 成人指引），控制不佳對胎兒的風險更大

## 臨床表現 {#clinical}

1. **症狀**：**反覆喘鳴、咳嗽（夜間與清晨）、胸悶、呼吸困難**；症狀**時有時無**，常被**運動、笑、冷空氣、過敏原**誘發
2. **理學檢查**：最典型是**呼氣性喘鳴音**（可在強迫呼氣時才聽到）；**呼氣時間延長**
3. **嚴重發作**：說話不連貫、**輔助肌使用**、**前傾坐姿**、**躁動或意識改變**、發紺
4. **沉默肺(silent chest)**：**喘鳴消失不是變好**，而是**氣流太少**，是**危及生命**的警訊，要立刻就醫
5. **血液氣體**
   1. 早期：**過度換氣 → 呼吸性鹼中毒**
   2. 持續惡化：**PaCO₂ 回到正常是警訊**
   3. 進一步：**CO₂ 滯留 → 呼吸性酸中毒**（**低血氧**與呼吸肌疲乏）
6. **常見共病**：過敏性鼻炎、異位性皮膚炎、鼻竇炎、胃食道逆流、肥胖與睡眠呼吸中止

## 診斷 {#diagnosis}

氣喘的診斷同時需要：**典型的變異性呼吸症狀** ＋ **已證實的變異性呼氣氣流受限**(GINA 2026)。**盡量在開始吸入型類固醇之前**完成檢查，因為治療後變異性會下降而更難證實

### 肺功能 {#spirometry}

| 方式 | 標準 |
|---|---|
| **支氣管擴張劑反應試驗**（吸入 200–400 mcg salbutamol 後 10–15 分鐘） | **成人**：FEV1 或 FVC 上升 **≥ 12% 且 ≥ 200 mL**（**≥ 15% 且 ≥ 400 mL** 更有把握）；**兒童**：FEV1 上升 ≥ 12% 預估值 |
| **尖峰流速日變異率**（連續 2 週，每日早晚測） | **成人 > 10%**；**兒童 > 13%** |
| 抗發炎治療 4 週後肺功能改善 | **成人** FEV1 上升 ≥ 12% 且 ≥ 200 mL |

1. **FEV1／FVC 在健康成人通常 > 0.75–0.80**，健康兒童 > 0.90；氣喘**可正常**（症狀緩解時）
2. **若無肺量計**，可用**尖峰呼氣流速(PEF)**作變異性評估，但**較不可靠**
3. **支氣管激發試驗**：高度懷疑但肺功能正常時使用；**懷孕**期間不建議用來確診或降階治療
4. **FeNO（呼氣一氧化氮）**、血中**嗜酸性球**、**IgE** 與**過敏原皮膚試驗**：輔助判斷第 2 型發炎與過敏體質
5. **胸部 X 光**主要用來**排除其他疾病**

### 鑑別診斷 {#differential}

| 疾病 | 區別 |
|---|---|
| **COPD** | 多為老年吸菸者；**使用支氣管擴張劑後 FEV1／FVC < 0.7**（固定性阻塞） |
| **心衰竭** | 端坐呼吸、水腫、**濕囉音** |
| **誘發性喉阻塞（聲帶功能異常）**、上呼吸道阻塞 | **吸氣性喘鳴(stridor)** |
| **異物吸入（兒童）**、**囊狀纖維化** | 突發、單側喘鳴、反覆感染 |
| **慢性上呼吸道咳嗽症候群**（鼻涕倒流） | 鼻部症狀、清喉嚨 |

**5 歲以下兒童**無法做肺功能，診斷靠**反覆的喘鳴型態**、**異位性體質家族史**與**治療反應**；喘鳴在 0–2 歲很常見，不一定是氣喘（2023 兒童指引）

## 尖峰呼氣流速(PEF)監測 {#pef}

1. **目的**：**監測氣道阻塞程度與嚴重度**、評估治療反應、找出誘因、**作為行動計畫的依據**
2. **方法**
   1. **站或坐直**，歸零，**深吸一口氣**，**含緊吹嘴**，**用力快速吹出**
   2. **連續吹三次，取最高值**（不是平均）
   3. **每次使用同一支流速計**（不同儀器可差 20%）
   4. 早晚固定時間測量，必要時在**服用緩解藥前後**測；**記錄**
3. **個人最佳值**：規則治療下**症狀穩定時**測得的最高值；兒童隨成長調整
4. **三色區**（國內衛教常用，各指引略有差異，待核對）
   1. **綠燈**：約**個人最佳值 80% 以上**，控制良好
   2. **黃燈**：約 **50–80%**，氣喘惡化，要**依行動計畫加藥**與追蹤，**不可減藥**
   3. **紅燈**：**< 50%**，嚴重，**立即使用緩解藥並就醫**
5. 例：個人最佳值 220 L/min，清晨 130（約 59%）、傍晚 170（約 77%） → 都在**黃燈區**，表示呼吸道有發炎與黏膜水腫，要**小心監測 PEF 變化**、依行動計畫處理（國考答案）

## 控制評估與嚴重度 {#control}

### 症狀控制（過去 4 週，GINA） {#symptom-control}

| 問題 | 是／否 |
|---|---|
| **日間氣喘症狀每週多於 2 次** | |
| **夜間因氣喘醒來** | |
| **因症狀使用緩解藥(SABA)每週多於 2 次** | |
| **日常活動因氣喘受限** | |

1. **無一項**：**控制良好**；**1–2 項**：**部分控制**；**3–4 項**：**控制不佳**
2. 同時評估**未來風險因子**：**過去一年發作過**、需要口服類固醇、**FEV1 偏低**、吸菸、肥胖、**使用過度的 SABA**、吸入器使用不正確等
3. **ICS-formoterol 緩解藥**的使用次數**不算**在上述 SABA 次數中；**運動前**使用的緩解藥通常也不計

### 嚴重度的定義 {#severity}

GINA 以**達成控制所需的治療強度**回溯定義：

1. **輕度氣喘**：用**低強度治療**即可控制（隨需低劑量 ICS-formoterol，或低劑量 ICS＋隨需 SABA）
2. **中度氣喘**：需要第 3 或第 4 階治療（低到中劑量 ICS-LABA）才能控制
3. **重度氣喘**：即使用**最佳化的高劑量**第 4 與第 5 階治療仍**控制不佳**，或**降階就失控**
4. 嚴重度**不是一次評估**就能定，要先確認**診斷、吸入技巧、遵從性與共病**

## 治療 {#treatment}

### 治療目標 {#goals}

1. **良好控制症狀**、維持**正常活動**
2. **降低發作風險**、避免**肺功能下降**與藥物副作用
3. **各種治療**均以**個別化**、**反覆評估（評估 → 調整 → 回顧）**

### 階梯治療（成人與青少年，GINA 2026） {#step-therapy}

GINA 提供**兩條路徑**，**Track 1 為優先**：

| | **Track 1（優先）：緩解藥為低劑量 ICS-formoterol** | **Track 2（替代）：緩解藥為 SABA（或 ICS-SABA）** |
|---|---|---|
| **第 1–2 階** | **隨需低劑量 ICS-formoterol**（沒有每日維持用藥，稱 AIR） | 第 1 階：吸 SABA 時同時吸 ICS；第 2 階：**每日低劑量 ICS**（或 LTRA）＋隨需 SABA |
| **第 3 階** | **低劑量維持 ICS-formoterol＋隨需 ICS-formoterol(MART)** | **低劑量 ICS-LABA**＋隨需 SABA |
| **第 4 階** | **中劑量維持** ICS-formoterol＋隨需(MART) | **中到高劑量 ICS-LABA**＋隨需 SABA |
| **第 5 階** | 加 **LAMA**(tiotropium)；**轉診做表型評估**；考慮**生物製劑**（anti-IgE、anti-IL5／5R、anti-IL4Rα、anti-TSLP）與短期口服類固醇 | 同 Track 1 |

1. **為什麼 Track 1 優先**：比 SABA 緩解藥可降低**嚴重發作約 55%**（第 1–2 階，與只用 SABA 比較），**一種藥物與一個吸入器**同時當緩解與維持，也能**直接升降階**
2. **GINA 不再建議「只用 SABA」**：SABA 單用會訓練病人把支氣管擴張劑當成主要治療，**忽略發炎**，增加發作與死亡風險
3. **降階**：**控制良好達 3 個月**後，找出**最低有效劑量**
4. **每次回診都要檢視**：**診斷**、**吸入器技巧**、**遵從性**、**誘發因子**、**共病**，才決定是否升階
5. 台灣 2022 成人指引的階梯與 GINA 一致；**生物製劑**要依健保規範，見 [[asthma-drugs#biologics]]
6. **運動前**：用低劑量 ICS-formoterol(Track 1)或 SABA

### 預防與長期管理 {#long-term}

1. **戒菸**、避免二手菸
2. **接種流感疫苗**與肺炎鏈球菌疫苗（[[immunization]]）
3. **體重控制**與運動（游泳、騎腳踏車等**可控制呼吸的有氧運動**）
4. **氣喘行動計畫**：書面，依**症狀或 PEF** 寫明何時加藥、何時就醫
5. **定期追蹤**：肺功能每年至少一次，控制不佳者更頻繁

## 急性發作 {#exacerbation}

### 評估 {#exacerbation-assessment}

1. **詢問**：誘發因子、症狀時間、已用藥物、**曾經重症或插管**、**是否可能是過敏性休克**（若同時有過敏性休克表現，**先給腎上腺素**，見 [[anaphylaxis]]）
2. **檢查**：**意識**、**呼吸次數**、**說話能力**、**輔助肌使用**、**喘鳴**、**脈搏**、**血氧飽和度**、**PEF**
3. **重度發作**：**只能說單字或短句**、**坐直前傾**、躁動、**呼吸次數 > 30 次／分**、**心跳 > 120 次／分**、**SpO₂ < 90%**、**PEF ≤ 50%**；**昏睡、意識混亂、沉默肺**要**立即送加護**
4. **兒童**：用臨床評分（例如 PRAM）；**嬰幼兒**呼吸次數隨年齡不同

### 處置(GINA 2026) {#exacerbation-treatment}

| 處置 | 重點 |
|---|---|
| **SABA** | **加壓定量吸入器＋輔助器**（必要時加面罩），第 1 小時每 **20 分鐘**一次 × 3，之後依反應減少；**噴霧器**用於無法使用吸入器者 |
| **氧氣** | **控制流量**，使**血氧維持 93–95%**（成人）；**不要過度給氧**，但**缺氧時不要吝於給氧** |
| **全身性類固醇** | **越早越好**（1 小時內）；成人 **prednisolone 40–50 mg／天 × 5–7 天**；兒童（6–11 歲）**1–2 mg／kg／天，最多 40 mg，3–5 天**；**不到 2 週不需遞減** |
| **ipratropium** | **中重度**發作**加在 SABA 上**，降低住院風險 |
| **靜脈硫酸鎂** | **重度**且初始治療無效者考慮 |
| **腎上腺素 IM** | 只在**過敏性休克**、或無法使用吸入治療時考慮 |
| **不需要** | **常規胸部 X 光**、**常規抗生素** |

1. **再評估**：**開始治療 1 小時內**重新評估症狀、生命徵象、血氧與 **PEF／FEV1**
2. **大量 SABA 的副作用**：**心跳加快、心悸、焦慮**，可造成**低血鉀、心律不整、乳酸中毒**；這些症狀**不要誤認為氣喘惡化**而加更多藥(GINA)
3. **出院**：**繼續或升階控制型藥物**（含 ICS）、**檢視吸入技巧與行動計畫**、**數天內追蹤**
4. **護理**
   1. **維持呼吸道通暢**：**坐臥式**（坐直或半坐，前傾），必要時協助咳痰
   2. **監測**生命徵象、**血氧**、**意識**，記錄**用藥反應**
   3. **補充水分**；**提供安靜、穩定的環境**以降低焦慮
   4. 不要把病人放平，也不要延誤給藥

## 兒童氣喘 {#pediatric}

1. **診斷**：6 歲以上依**肺功能**（支氣管擴張劑後 FEV1 上升 **≥ 12% 預估值**，PEF 變異率 **> 13%**）；**5 歲以下**依症狀型態、異位性體質與治療反應
2. **兒童特有的臨床**：**感冒誘發**最常見；**IgE 升高**、**異位性皮膚炎**與**過敏性鼻炎**常見；**呼吸性酸中毒**的原因主要是**低血氧**
3. **吸入器選擇**（依年齡與配合度）
   1. **定量噴霧器(MDI)＋輔助器(spacer)**最適合**嬰幼兒與年幼兒童**，**幼童加面罩**
   2. **乾粉吸入器(DPI)**不需**手口協調**，但**要有足夠的吸氣力**，**約 5 歲以上**
   3. 醫囑「**早晚各 2 puffs**」是**每次吸 1 下、分開 2 次**，**不是連續吸 2 次**
   4. 吸入型藥物的**優點**：劑量與全身副作用**比口服少**
4. **居家照護指導**
   1. **每週用 55℃ 以上熱水清洗**床單、被套、枕巾並烘乾；**避免羽絨、地毯、毛絨玩具**；用**百葉窗**取代布窗簾
   2. **運動**：**可控制呼吸的有氧運動**（游泳、慢跑、騎腳踏車），運動前依醫囑**預防用藥**
   3. **PEF 若在黃燈區**（約 50–80%）要**依行動計畫加藥與就醫評估**，**不能減藥**
   4. **ICS 用後漱口**（預防鵝口瘡）
   5. **避免誘因**：感冒預防、避免二手菸、規律作息、**避免情緒激動**
5. **心理與學校**：父母告知老師與校護病況、標示在校用藥；經孩子與父母同意可向同學簡單說明；**不要過度保護、不限制參加體育活動**，運動前依醫囑預防用藥

## 護理與衛教 {#nursing}

1. **用藥衛教**
   1. **區分控制型與緩解型**：**吸入型類固醇不是急救藥**，**短效支氣管擴張劑**才是；**症狀好轉也不要自行停用控制型藥物**
   2. **吸入器技巧**：每次回診**示範並回覆示範**；**用 ICS 後漱口並吐出**；**MDI 要「慢而深」吸**，吸完**閉氣約 5–10 秒**
   3. **記錄緩解藥使用頻率**，增加表示控制變差
2. **環境與生活**
   1. **環境控制**（塵蟎、寵物、黴菌、菸害）見 [[allergic-rhinitis#environment]]
   2. **沙塵暴或空汙**：**減少外出、戴口罩**、**維持正常作息**，**關閉門窗**（使用空氣清淨機）
   3. **避免高強度運動**，**選擇可控制呼吸的有氧運動**
3. **避免的藥物**：**非選擇性 β 阻斷劑**（propranolol，**也包含 β 阻斷劑眼藥水**）；**有氣喘病史的高血壓病人**應改用其他降壓藥（[[beta-blockers]]）；**aspirin／NSAID** 使用前先問是否會誘發
4. **社區**：**獨居、反覆發作住院者**，確認**居家環境、用藥遵從性、行動計畫、緊急求助管道**；居服員與家屬要學會辨識**紅燈**
5. **心理支持**：焦慮與憂鬱在氣喘病人並不少見，要**教導辨別氣喘發作與焦慮（恐慌）發作**（2022 成人指引）
