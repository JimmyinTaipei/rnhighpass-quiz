**乳癌**是台灣**女性發生率第一**的癌症(112 年約 1 萬 7 千多人)，發生年齡高峰在 45–69 歲，比歐美年輕。早期發現靠**乳房攝影**篩檢，治療結合手術、放療、化療、**荷爾蒙治療**與 **HER2 標靶治療**。護理重點是**術後手臂復健與淋巴水腫預防**，以及**身體心像**的調適。癌症總論見 [[cancer]]。

## 危險因子 {#risk-factors}

多數和**雌激素長期暴露**有關：

| 類別 | 危險因子 |
|---|---|
| 荷爾蒙 | **初經早、停經晚**、**未曾生育**或**第一胎在 30 歲以後**、**未哺乳**、停經後長期使用**雌激素加黃體素**、停經後**肥胖**(脂肪組織製造雌激素) |
| 遺傳 | **一等親**(母親、姊妹、女兒)有乳癌；**BRCA1、BRCA2** 突變(**只占約 5–10%**，不是大多數乳癌的原因) |
| 個人史 | 對側乳癌、**非典型增生**、胸部放射線照射史 |
| 生活 | **高脂飲食**、飲酒、缺乏運動 |

- **保護因子**：生育次數多、**哺餵母乳**、規律運動、維持體重(例：BMI 23 屬正常，不是危險因子)。
- **男性也會**得乳癌(約占 1%)。

## 病理 {#pathology}

- 最常見的是**浸潤性乳管癌**；**浸潤性小葉癌**細胞彼此黏著差、容易散布，觸診不易摸清楚。
- **乳管原位癌**：粉刺型常有中央壞死與**鈣化**，可在乳房攝影發現。
- **管狀癌**分化好、**預後較佳**。
- **發炎性乳癌**：癌細胞阻塞皮膚淋巴管 → 皮膚紅腫熱、**橘皮樣變化**(peau d'orange)，進展快、預後差。
- **乳頭 Paget 氏病**：癌細胞沿乳管到乳頭表皮 → 乳頭濕疹樣脫屑、糜爛。
- 分子分型決定治療：**ER、PR**(荷爾蒙受體)、**HER2**。**三陰性**乳癌 = **ER、PR、HER2 都陰性**(與細胞角蛋白無關)，不適合荷爾蒙或 HER2 標靶治療，預後較差。
- 乳癌相關的是 **HER2** 基因，不是 EGFR(肺癌)。
- 最常見的**良性**乳房腫瘤：**纖維腺瘤**(年輕女性，圓滑、可移動、無痛)。

## 臨床表現 {#manifestations}

- 最常見：**無痛**、硬、邊界不規則、**不易推動**的腫塊；**多數不會痛**。
- 最好發在乳房**外上四分之一**(乳腺組織最多，靠近腋下)。
- **乳頭凹陷或回縮**、兩側乳頭高低不一(腫瘤牽扯乳管與懸韌帶)、乳頭**血性分泌物**。
- 皮膚凹陷(酒窩徵象)、**橘皮樣**、紅腫、潰瘍。
- **腋下淋巴結腫大**；晚期轉移到**骨頭**(背痛、高血鈣、脊髓壓迫，**胸椎**最常見)、肺、肝、腦。

## 篩檢與診斷 {#screening}

| 方法 | 重點 |
|---|---|
| **乳房 X 光攝影** | **唯一證實能降低死亡率**的篩檢工具，可發現**鈣化點**。台灣 114 年起公費 **40–74 歲**女性**每 2 年 1 次**(舊制：45–69 歲，及 40–44 歲**二等親內**有乳癌家族史者，也是每 2 年 1 次) |
| 乳房超音波 | 年輕女性、緻密乳房的輔助檢查，**不是**公費篩檢工具 |
| 乳房自我檢查 | 月經結束後約 **5–7 天**(乳房最不腫脹)、停經者每月固定一天；**不能取代**乳房攝影，也無法檢測到所有腫瘤。學校教導乳房自我檢查屬於**健康促進**措施 |
| 確診 | 粗針或手術**切片病理**，並檢測 ER、PR、HER2 |
| 腫瘤標記 | **CA15-3** 監測晚期或轉移性乳癌，**不能早期診斷**；CEA 也可能上升(見 [[tumor-markers]]) |

:::note[乳房自我檢查的定位]
UpToDate 建議一般風險女性**不需要**常規做乳房自我檢查(沒有降低死亡率，還增加良性切片)，改為強調「**乳房自我覺察**」：熟悉自己的乳房，有變化就就醫(來源：[UpToDate](https://www.uptodate.com/contents/screening-for-breast-cancer-strategies-and-recommendations))。國考仍常考自我檢查的方法與時間。
:::

- **有家族史**的女性：不能「等有異狀再做攝影」，要**依規定定期篩檢**，並衛教**戒菸、規律運動**等生活型態調整。

### 分期 {#staging}

- T 依腫瘤大小：**T1 ≤ 2 公分**、**T2 > 2–5 公分**、T3 > 5 公分、T4 侵犯胸壁或皮膚(含發炎性乳癌)。
- N 依腋下淋巴結：N1 同側可移動的 1–3 顆。
- 例：3 公分腫瘤、同側腋下淋巴結轉移、無遠處轉移 → **T2N1M0 = 第 II 期**(IIB)。分期原理見 [[neoplasia#tnm]]。

## 治療 {#treatment}

### 手術 {#surgery}

| 術式 | 內容 |
|---|---|
| **乳房保留手術**(部分切除) | 切除腫瘤與周圍正常組織，**術後要合併放療** |
| **改良式乳房根除術**(MRM) | 切除**整個乳房與腋下淋巴結**，**保留胸大肌** |
| 根除性乳房切除術(Halsted) | 連胸大、小肌一起切除，現在很少用 |
| **前哨淋巴結切片** | 先找第一顆引流淋巴結，**沒有轉移就不做腋下廓清**，大幅降低淋巴水腫 |
| 乳房重建 | 立即或延遲重建(義乳植入或自體皮瓣) |

### 全身與局部輔助治療 {#adjuvant}

- **放療**：乳房保留術後、腫瘤大或淋巴結多時；可能出現皮膚炎、胸壁放療造成**食道炎**(吞嚥痛)。
- **化療**：常用蒽環類(doxorubicin，**心臟毒性**)、紫杉醇、cyclophosphamide。
- **荷爾蒙治療**(ER／PR 陽性，**受體越多反應越好**)：**tamoxifen**(停經前後都可用；注意**更年期症狀、噁心、水腫**、血栓、子宮內膜癌)，**芳香環酶抑制劑**(letrozole 等，**只用於停經後**)，停經前可合併卵巢抑制，通常服用 5–10 年。
- **HER2 陽性**：**trastuzumab**(靜脈滴注，**監測心臟功能**)。
- 藥物細節見 [[antineoplastics#hormonal]] 與 [[antineoplastics#targeted]]。

## 術後護理 {#nursing-postop}

### 手術後初期 {#postop-early}

- 評估傷口、**引流管**(負壓引流，記錄量與性質)、患側手臂的感覺與循環。
- 腋下**僵硬、緊繃、麻木**感常見，但要追蹤、做復健，不是「不用理會」。
- 疼痛評估用 PQRST(R 是部位與放射，不是恢復)，見 [[pain-management#pqrst]]。

### 手臂復健運動 {#arm-exercise}

| 時間 | 運動 |
|---|---|
| **術後當天到第 1–2 天** | **手指屈伸、握球、腕部與手肘以下**的關節運動 |
| 第 2–3 天起 | 手肘彎曲伸直、梳頭、刷牙洗臉等日常活動(依醫囑) |
| **引流管拔除、傷口允許後**(約 1 週後) | **肩關節**運動：**爬牆**、轉繩、滑輪、繞肩；循序漸進到全關節範圍 |

- 太早大幅度抬肩可能增加積液；太晚則造成**肩關節僵硬**。**肩關節運動**配合肌肉收縮能幫助**淋巴回流**，改善淋巴水腫。
- 游泳等劇烈運動要等傷口完全癒合、醫師同意後。

### 淋巴水腫 {#lymphedema}

- 機轉：**腋下淋巴結切除或放療**使**淋巴管阻塞**，淋巴液回流受阻 → 同側手臂腫脹；可能在術後**數月到數年**才出現，不是只在術後一個月。
- 預防與照護：
  - **抬高患肢**：臥床時用枕頭墊高，使**手腕高於手肘、手肘高於肩膀**。
  - 早期**手部與手臂運動**，維持理想體重。
  - **保護患側皮膚**避免傷口與感染：做家事戴手套、避免蚊蟲叮咬與燙傷、**外出避免陽光直射患肢**、修指甲不要剪到皮膚；有紅腫熱痛(蜂窩性組織炎)立即就醫。
  - 傳統衛教：**患側不量血壓、不打針抽血**、不戴緊的首飾與衣袖、不提重物。
  - 已發生淋巴水腫：**彈性袖套**、徒手淋巴引流按摩、複合式消腫治療。
- 術後患肢腫脹**不會自然消失**，要積極預防與處理。

(來源：[UpToDate：lymphedema](https://www.uptodate.com/contents/clinical-features-diagnosis-and-staging-of-peripheral-lymphedema))

### 身心調適 {#psychosocial}

- 乳房切除影響**身體心像**與女性角色認同；手術前的害怕要先以**開放式問句**了解擔心的內容(例：「可以跟我說您在害怕些什麼嗎？」)，不是急著保證或勸說。
- 介紹**義乳、內衣**、重建選擇；轉介**病友團體**(屬於「互動性社區」)。
- 伴侶與性生活的調適；年輕病人討論生育保存。
- 末期病人的心理反應(Kübler-Ross 五階段)見 [[end-of-life-care#kubler-ross]]。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 危險因子：**初經早、停經晚**、未生育、長期使用雌激素加黃體素、高脂飲食、家族史；**生產次數多、哺乳是保護因子**；**BRCA 只占少數**。
- 腫塊多**無痛**、好發**外上四分之一**、**乳頭凹陷**；**橘皮 = 發炎性乳癌**；**三陰性 = ER、PR、HER2 陰性**；最常見良性腫瘤是**纖維腺瘤**；**管狀癌預後較好**。
- 公費乳房攝影：**每 2 年 1 次**(舊制 45–69 歲及 40–44 歲二等親家族史；114 年起 40–74 歲)。
- **改良式根除術保留胸大肌**；術後先做**手肘以下**運動，**肩關節運動**改善淋巴水腫。
- 淋巴水腫：**淋巴管阻塞**；手腕 > 手肘 > 肩膀墊高；**避免陽光直射患肢**。
- 3 公分加腋下淋巴結轉移 = **T2N1 第 II 期**。
:::
