高血壓是指動脈血壓**持續**高於正常,是國人最常見的慢性病之一,也是**腦中風**(尤其出血性)、冠心病、心衰竭與慢性腎臟病的首要可改變危險因子。多數人**沒有症狀**,常被稱為「沉默殺手」,所以正確量測與長期服藥遵從是照護核心。

本頁依「生理 → 病理 → 診斷與分級 → 血壓量測 → 併發症與急症 → 特殊族群 → 檢驗 → 藥物 → 治療 → 護理 → 衛教與社區」排列。低血壓另見 [[hypotension]]。

## 血壓的生理 {#physiology}

血壓由「心臟打出多少血」與「血管有多窄」決定:**血壓 = 心輸出量 × 周邊血管阻力**。詳細機轉見 [[blood-pressure-regulation]]。

### 收縮壓、舒張壓、脈壓與平均動脈壓 {#bp-components}

| 指標 | 主要決定因素 | 數值 |
|---|---|---|
| **收縮壓**(SBP) | 心輸出量:心室收縮力、心搏量、循環血量、大動脈彈性 | — |
| **舒張壓**(DBP) | **周邊血管阻力**(小動脈口徑) | — |
| **脈壓**(PP)= SBP − DBP | 心搏量與大動脈管壁張力 | 正常約 30–50(平均 40)mmHg |
| **平均動脈壓**(MAP) | 器官灌流壓 | **MAP = DBP + ⅓ 脈壓 =(SBP + 2 × DBP)÷ 3**;≥ 65 mmHg 才足以灌流器官 |

- 口訣:**收縮看心臟、舒張看血管**。
- MAP 較接近舒張壓,因為一個心動週期中**舒張期較長**。例:SBP 120、脈壓 30 → DBP 90 → MAP = 90 + 10 = **100** mmHg。
- **脈壓過大**(> 60):老年動脈硬化(典型「單純收縮期高血壓」)、主動脈瓣閉鎖不全、甲狀腺機能亢進、顱內壓升高(Cushing 反應)。
- **脈壓過小**(< 30):休克、心衰竭、主動脈瓣狹窄、心包膜填塞。
- 血壓調節中樞(心血管中樞)在**延腦**,不在下視丘。

### 血壓如何被調控 {#regulation}

- **短期**(秒):壓力感受器反射(頸動脈竇、主動脈弓)→ 延腦 → 調整心跳與血管張力。見 [[blood-pressure-regulation#baroreceptor]]。
- **中長期**(分鐘到天):**腎素–血管收縮素–醛固酮系統**(RAAS)、抗利尿激素(ADH)、利鈉胜肽,透過血管收縮與**水鈉滯留**調整血量。見 [[blood-pressure-regulation#raas]]。

### 影響血壓的生理因素 {#influencing-factors}

| 使血壓**上升** | 使血壓**下降** |
|---|---|
| 交感興奮:疼痛、焦慮、情緒激動、**膀胱脹滿** | 休息、睡眠(**夜間最低**) |
| **寒冷**(末梢血管收縮) | 溫熱環境、**熱水澡、三溫暖**(血管擴張) |
| **用力排便、閉氣**(Valsalva) | 飲酒的**急性**作用(血管擴張) |
| 運動當下、剛進食、吸菸、咖啡因 | 大量出血、脫水 |
| **顱內壓升高**(Cushing 反應:血壓↑、心跳↓、呼吸不規則、脈壓變大) | 由臥到站(姿勢性)|
| 血液黏稠度上升(Hct > 50%) | 組織胺(血管擴張) |

- **晝夜節律**:清晨起床後上升,午後至傍晚最高,夜間睡眠最低;清晨血壓急升是中風與心肌梗塞好發於早上的原因之一。
- **姿勢**:站 > 坐 > 躺(舒張壓);REM 睡眠期心跳、血壓上升。
- 飲酒:**當下**使血管擴張、血壓下降;但**長期過量飲酒**是高血壓危險因子——兩者不矛盾,題目要看問的是哪一種。

## 病因與病理生理 {#pathophysiology}

### 原發性與續發性 {#types}

| | 原發性(本態性)高血壓 | 續發性高血壓 |
|---|---|---|
| 比例 | **90–95%** | 5–10% |
| 原因 | 找不到單一病因;遺傳 + 環境(高鈉、肥胖、飲酒、缺乏運動、壓力)| 有**明確**可治療的病因 |
| 特徵 | 中年後緩慢出現、常有家族史 | **年輕**(< 30 歲)或突然發生、多種藥物仍控制不良、原本穩定突然惡化、低血鉀 |

:::warning[易錯]
「有家族史」「抽菸、喝酒、高膽固醇飲食」是**原發性**的危險因子,不是續發性高血壓的病因。
:::

### 原發性高血壓的機轉 {#essential-mechanism}

- **腎臟排鈉能力下降**:鈉鹽敏感性,需較高血壓才能排出同量鈉(壓力–利尿曲線右移)。
- **RAAS 與交感神經過度活化**:血管收縮、水鈉滯留、心跳加快。
- **血管重塑與內皮功能障礙**:NO 減少、內皮素增加 → 小動脈壁增厚、管腔變窄 → 阻力固定升高;大動脈變硬 → 收縮壓與脈壓上升(老年人)。
- **胰島素阻抗與肥胖**:高胰島素血症促進腎臟保鈉、刺激交感神經;這也是高血壓常與糖尿病、血脂異常一起出現(代謝症候群)的原因。

### 續發性高血壓的常見原因 {#secondary-causes}

| 類別 | 疾病 | 線索與重點 |
|---|---|---|
| 腎實質 | 慢性腎臟病、**急性腎絲球腎炎** | 腎炎症候群:血尿、**高血壓**、少尿、氮血症、輕度蛋白尿;腎病症候群則以大量蛋白尿、水腫、低白蛋白為主 |
| 腎血管 | **腎動脈狹窄**(老人動脈硬化、年輕女性纖維肌肉發育不良)、腎移植後移植腎動脈狹窄 | 腎臟灌流下降 → RAAS 活化;腹部雜音;用 ACEI 後腎功能急降 |
| 內分泌 | **原發性醛固酮症** | 高血壓 + **低血鉀**、代謝性鹼中毒 |
| | **嗜鉻細胞瘤** | 陣發性高血壓 + 頭痛、心悸、冒汗、蒼白(5P);驗 **24 小時尿液** VMA/metanephrine |
| | **庫欣氏症候群** | 糖皮質素具礦物皮質作用 → 保鈉排鉀、水鈉滯留 |
| | 甲狀腺機能亢進/低下、副甲狀腺機能亢進 | |
| 血管 | 主動脈窄縮 | 上肢血壓高、下肢血壓低、股動脈脈搏弱且延遲 |
| 其他 | **阻塞型睡眠呼吸中止** | 打鼾、白天嗜睡;夜間血壓不下降 |
| 藥物 | NSAIDs、類固醇、口服避孕藥(雌激素)、**cyclosporine**、**紅血球生成素(EPO)**、減充血劑(pseudoephedrine)、甘草、安非他命、古柯鹼 | 先檢視用藥 |

**嗜鉻細胞瘤的處置**:術前先給 **α 阻斷劑**(phenoxybenzamine;prazosin/doxazosin 亦可)控制血壓、補足血容積,**之後**才能加 β 阻斷劑(先 β 會讓 α 作用無對抗 → 血壓更高)。腫瘤切除後兒茶酚胺驟降 → 要注意**低血壓**與**低血糖**。

**脊髓損傷(T6 以上)的自主神經反射異常**:損傷平面以下的刺激(最常見**膀胱脹**、便秘、褥瘡)→ 嚴重高血壓、搏動性頭痛、損傷平面以上潮紅冒汗、**心跳過緩**;發生在脊髓休克期**之後**。處置:**立即坐起**、鬆開衣物、找出並移除刺激(先檢查導尿管/排空膀胱)。

## 診斷與分級 {#diagnosis}

### 血壓分級 {#classification}

新舊指引切點不同,國考舊題多用 140/90,新題與臨床用 130/80,兩者都要會。

| 分級 | **2022 台灣 / 2017 與 2025 ACC/AHA** | 舊版(JNC 7 等) |
|---|---|---|
| 正常 | < 120 **且** < 80 | < 120 且 < 80 |
| 血壓偏高(elevated) | 120–129 **且** < 80 | 120–139 或 80–89 稱「**高血壓前期**」 |
| **第 1 期高血壓** | **130–139 或 80–89** | 140–159 或 90–99 |
| **第 2 期高血壓** | **≥ 140 或 ≥ 90** | ≥ 160 或 ≥ 100 |
| 高血壓危象 | **> 180 和/或 > 120** | 同 |

- 收縮壓與舒張壓落在不同級別時,以**較高的級別**為準。
- 診斷不能只靠一次量測:需**不同天、多次**量測(診間 ≥ 2 次、每次 ≥ 2 個讀數取平均),並建議以**居家血壓**或 24 小時血壓監測確認。
- **白袍高血壓**:診間高、居家正常;**隱匿性高血壓**:診間正常、居家高(心血管風險與真正高血壓相當)。

| 量測方式 | 相當於診間 130/80 的切點 |
|---|---|
| 居家血壓平均 | 130/80 |
| 24 小時平均 | 125/75 |
| 白天平均 | 130/80 |
| 夜間平均 | 110/65 |

:::exam[國考重點]
- 新指引:**≥ 130/80 即為高血壓**;「130–139/80–89 為高血壓前期」是舊分類。
- 高血壓危象的數字 **180/120**。
- 138/88、沒有糖尿病或心血管疾病、低風險者:先**生活型態調整**,追蹤 3–6 個月未達標再考慮藥物(見 [[#treatment-threshold]])。
:::

### 初次評估 {#initial-evaluation}

1. **確認診斷**:正確量測、居家血壓。
2. **找續發性原因**:病史、用藥、低血鉀等線索(見 [[#secondary-causes]])。
3. **評估標靶器官傷害**:眼底、心電圖(左心室肥大)、[[echocardiography|心臟超音波]]、[[uacr|尿液白蛋白]]、eGFR。
4. **評估其他心血管危險因子**:血糖/[[hba1c]]、[[lipid-profile|血脂]]、吸菸、肥胖、家族史;計算整體心血管風險決定用藥時機。
5. 基本檢驗:電解質([[potassium|血鉀]]、鈉)、肌酸酐、尿酸、尿液分析、血色素、TSH(視情況)。

## 血壓的量測 {#measurement}

本段是基本護理最常考的內容。原則:**量測條件標準化**,讓誤差最小。

### 量測前準備 {#measurement-preparation}

- 量測前**靜坐休息 5 分鐘**;**30 分鐘內**不吸菸、不喝咖啡、不運動、不進食;先**排空膀胱**。
- 坐姿:背有靠、**雙腳平放地面不翹腳**,手臂裸露(衣袖捲起不可過緊)、**手臂支托與心臟同高**(右心房高度,約胸骨中點/第四肋間)。
- 量測時**不說話、不移動**。
- 選擇正確尺寸的壓脈帶(見下)。

### 壓脈帶尺寸 {#cuff-size}

- 氣囊**寬度 = 上臂(或大腿)周長的 40%**(約上臂長度的 2/3);**長度 = 周長的 80–100%**。成人標準氣囊寬約 12–14 cm。
- 手臂較粗(肥胖)者用大號;兒童依年齡與臂圍選擇,不可用成人壓脈帶。
- 氣囊中心對準**肱動脈**,下緣在**肘窩上 2.5 cm**;鬆緊度以可放入一指為宜。

### 聽診法步驟 {#auscultation}

1. **先觸診估計收縮壓**:觸摸橈動脈或肱動脈,充氣到脈搏消失,再**加 30 mmHg**,作為聽診時的充氣高度(避免因**聽診間隙**而低估收縮壓)。
2. 聽診器(膜面)置於肱動脈上,不可塞在壓脈帶下。
3. 以**每秒 2–3 mmHg** 的速度放氣。
4. 讀取**柯氏音**(Korotkoff sounds):

| 期 | 聲音 | 意義 |
|---|---|---|
| 第一期 | 首次出現清楚的輕敲聲 | **收縮壓** |
| 第二期 | 雜音、嗖嗖聲 | 聽診間隙可出現在第一、二期之間 |
| 第三期 | 聲音變清脆響亮 | |
| 第四期 | 聲音突然**變低沉、模糊** | 兒童、孕婦、高心輸出量(運動、甲亢)者作為舒張壓 |
| 第五期 | **聲音消失** | **成人舒張壓** |

5. 需重複測量時:**完全放氣**,手臂抬高或休息 **1–2 分鐘**再測;取兩次平均。

### 常見誤差 {#measurement-errors}

| 假性**偏高** | 假性**偏低** |
|---|---|
| 壓脈帶**太窄** | 壓脈帶**太寬** |
| 壓脈帶**太鬆** | 壓脈帶**太緊** |
| 手臂**低於**心臟 | 手臂**高於**心臟 |
| 視線**低於**水銀柱刻度(仰視) | 視線**高於**水銀柱刻度(俯視) |
| **放氣太慢**(靜脈鬱血 → 舒張壓偏高) | 放氣太快(漏聽 → 收縮壓偏低) |
| 未休息、剛活動、膀胱脹、說話、翹腳、背沒靠 | 充氣不夠高而落在**聽診間隙** → 收縮壓偏低 |
| 連續測量未放氣、未間隔 | |

記法:**「窄、鬆、低」都偏高**;反之偏低。

### 部位選擇 {#measurement-site}

- **初次**兩手都量,之後以**數值較高**的那一側為準。正常兩臂差距在 10 mmHg 以內(一般右臂略高、慣用手略高);差距 > 10–15 mmHg 要**再測一次雙手**,仍有差距需懷疑鎖骨下動脈狹窄或**主動脈剝離**。
- **不可**量血壓的手臂:**靜脈輸液側**、**動靜脈瘻管**(洗腎)側、**乳癌腋下淋巴清除**側、**偏癱**患側、骨折/石膏/傷口、周邊中心靜脈導管(PICC)側 → 改量對側或下肢。
- **下肢血壓**:病人**俯臥**,壓脈帶包在**大腿下 1/3**,聽診**膕動脈**;下肢收縮壓比上肢**高 10–40 mmHg**,舒張壓相近。也可在小腿量足背/脛後動脈。
- **踝肱指數**(ABI)= 踝部收縮壓 ÷ 肱動脈收縮壓;< 0.9 表示周邊動脈疾病。

### 特殊狀況 {#measurement-special}

- **心房顫動**等心律不整:脈搏不規則使每次讀數差異大,**量 3 次取平均**;同時由兩人測**心尖脈與橈動脈脈搏**(脈搏短絀)。
- **兒童**:依年齡、性別、身高百分位判讀;順序常為呼吸 → 脈搏 → 體溫 → 血壓(先做不會讓孩子哭的)。
- **姿勢性低血壓**評估:平躺 5 分鐘 → 站起 1 分鐘與 3 分鐘各量一次,見 [[hypotension#orthostatic]]。
- **電子血壓計**:居家使用建議上臂式、經認證的機型;腕式易受手腕高度影響。心律不整者準確度下降。
- **記錄**:必須是實際量到的數值;照抄前次數值屬偽造紀錄,有法律責任。

### 居家血壓量測:722 原則 {#home-bp}

國健署推行「**722**」:

- **7**:連續 **7 天**量測(就診前或調藥後)。
- **2**:每天 **2 次**——**早上**起床後 1 小時內、上廁所後、**服藥前、早餐前**;**晚上**睡前 1 小時內。
- **2**:每次量 **2 遍**,間隔 1 分鐘,取平均。

其他:固定同一手臂與時間;沐浴、飲酒、飯後或運動後 30 分鐘內不量;記錄數值帶回門診。

## 併發症 {#complications}

### 標靶器官傷害 {#target-organ-damage}

長期高血壓使血管壁增厚變硬、心臟後負荷上升,傷害下列器官:

| 器官 | 變化 | 表現與檢查 |
|---|---|---|
| **腦** | 小動脈硬化、微動脈瘤、動脈粥狀硬化 | **腦中風**(高血壓是**出血性中風**最主要的危險因子;栓塞型中風則多來自心房顫動)、血管性失智 |
| **心臟** | 後負荷↑ → **左心室肥大**(向心性)→ 舒張功能不良 → 心衰竭;冠狀動脈疾病 | 心尖搏動**增強並向左下偏移**、**S4**、心電圖 QRS 電壓增高([[ecg]])、超音波左心室壁增厚 |
| **腎臟** | 腎小動脈硬化 | 蛋白尿([[uacr]])、eGFR 下降,是洗腎第二大原因(僅次於糖尿病) |
| **眼睛** | 高血壓性視網膜病變 | 動脈變細、動靜脈交叉壓迹、火焰狀出血、棉絮斑;嚴重時**視乳突水腫** |
| **大血管** | 動脈粥狀硬化、主動脈瘤、**主動脈剝離** | 周邊動脈疾病、間歇性跛行 |

### 高血壓危象 {#hypertensive-crisis}

血壓 **> 180/120 mmHg** 稱高血壓危象,依是否有**急性標靶器官傷害**分為兩種:

| | **高血壓急症**(hypertensive emergency) | **高血壓緊急狀況**(hypertensive urgency,新指引稱「嚴重高血壓無急性器官傷害」) |
|---|---|---|
| 器官傷害 | **有**,且正在進行 | 無 |
| 例子 | 高血壓腦病變、腦中風、**急性肺水腫**、急性冠心症、**主動脈剝離**、急性腎損傷、子癇症、視乳突水腫(舊稱**惡性高血壓**:舒張壓常 > 130 + 視乳突水腫) | 血壓很高但只有輕微頭痛或無症狀;常因停藥、焦慮、疼痛 |
| 處置地點 | **加護病房**、靜脈藥物、動脈導管連續監測 | 門診或急診觀察,**口服藥**在 24–48 小時內慢慢降 |

**高血壓急症降壓速度**(不可一下子降到正常,會造成腦、心、腎缺血):

1. 第 1 小時:平均動脈壓下降**不超過 25%**。
2. 之後 2–6 小時:降到約 **160/100–110**。
3. 之後 24–48 小時:再逐步降到正常。

例外:**主動脈剝離**第 1 小時內就要把收縮壓降到 **< 120 mmHg**(並控制心跳 < 60,先給 β 阻斷劑);嚴重子癇前症/子癇、嗜鉻細胞瘤危象的目標也不同;急性缺血性中風則要**放寬**(準備血栓溶解時 < 185/110)。

**常用靜脈藥**:nicardipine、clevidipine、labetalol、esmolol、nitroglycerin(合併冠心症、肺水腫)、**nitroprusside**(作用最快最短;**避光**包覆、注意**氰化物中毒**)。比較表見 [[direct-vasodilators#iv-agents]]。

:::warning[已不建議]
**舌下含服短效 nifedipine** 處理高血壓危象曾很常見(國考仍有題目,給藥方式為舌下含服、不可咬碎吞服),但血壓下降幅度無法控制,可造成中風與心肌梗塞,現行指引**不建議**。
:::

**護理**:

- 安靜環境、臥床、床頭抬高;連續監測血壓(靜脈藥物每 5–15 分鐘,或動脈導管)、心跳、意識、神經學檢查、尿量。
- 觀察器官傷害徵象:劇烈頭痛、視力模糊、意識改變、抽搐(腦)、胸痛、呼吸困難(心、肺)、少尿(腎)。
- 靜脈降壓藥使用**輸液幫浦**,依醫囑滴定;注意血壓過度下降(頭暈、意識變差)。
- 社區或居家遇到血壓 > 180/120 合併頭痛、視力模糊、胸痛、單側無力 → **立即就醫**(撥 119),不是先泡熱水、散步或只做飲食衛教。
- 若出現心跳停止等急救情況,依 2025 AHA ACLS 流程處理。

## 特殊族群 {#special-populations}

### 妊娠高血壓疾病 {#pregnancy}

懷孕時高血壓的定義仍是 **≥ 140/90 mmHg**(間隔 4 小時兩次);**≥ 160/110** 為嚴重高血壓。

| 分類 | 定義 |
|---|---|
| **慢性高血壓** | 懷孕前,或懷孕 **20 週前**就有高血壓(或產後 12 週仍未恢復) |
| **妊娠高血壓** | 懷孕 **20 週後**新發生、**無蛋白尿**、無器官損傷;產後 12 週內恢復 |
| **子癇前症** | 20 週後新發高血壓 + **蛋白尿**(≥ 300 mg/24 小時或尿蛋白/肌酸酐比 ≥ 0.3),或雖無蛋白尿但有器官損傷(血小板 < 10 萬、肝指數上升、肌酸酐上升、肺水腫、新發頭痛或視覺障礙) |
| **子癇症** | 子癇前症 + **抽搐/痙攣**(無其他原因) |
| 慢性高血壓併子癇前症 | 原有高血壓,20 週後新出現蛋白尿或器官損傷 |
| HELLP 症候群 | 溶血(Hemolysis)、肝指數上升(Elevated Liver enzymes)、血小板低(Low Platelets) |

- 舊教科書以「高血壓、蛋白尿、**水腫**」為三大徵候;水腫在正常孕婦也很常見,現行診斷**已不列入水腫**。
- **危險因子**:初產、多胞胎、先前子癇前症、慢性高血壓、糖尿病/妊娠糖尿病、腎臟病、自體免疫疾病、肥胖、高齡、體外受精;α 型重度海洋性貧血(Hb Bart's 水腫胎)也常合併。
- **警訊**:劇烈頭痛、視力模糊、**上腹或右上腹痛**、突然水腫加劇、尿量減少 → 立即量血壓並就醫。
- **對胎兒**:胎盤灌流不足 → **胎兒生長遲滯**(IUGR)、羊水過少、**胎盤早期剝離**、早產;追蹤**臍動脈都卜勒 S/D 比值**(正常隨週數遞減,第三孕期 > 3.0 表示胎盤阻力高)。妊娠高血壓不是主要致畸因子。
- **治療**:
  - 降壓藥:**labetalol、nifedipine(長效)、methyldopa**、急性時靜脈 **hydralazine**;**ACEI、ARB、aliskiren 禁用**(胎兒腎臟發育異常、羊水過少)。
  - **硫酸鎂**(MgSO₄)預防與治療子癇抽搐;監測**膝反射、呼吸次數(≥ 12)、尿量(≥ 30 mL/h)**,解毒劑為葡萄糖酸鈣。
  - 根治是**娩出胎兒與胎盤**;妊娠高血壓或輕度子癇前症滿 **37 週**引產,嚴重子癇前症 34 週後即考慮終止妊娠。
  - 低劑量 **aspirin**(高危險孕婦 12–16 週開始)可預防子癇前症。
- **護理**:**左側臥**(減少子宮壓迫下腔靜脈、增加胎盤與腎臟血流)、安靜環境減少刺激、每日體重與尿蛋白、胎動與胎心音監測;子癇抽搐時保護呼吸道、側躺、防止受傷,不可約束。
- **飲食**:足夠的**優質蛋白質**;國考答案常為「減少鹽分」,但現行 ACOG **不建議**子癇前症嚴格限鈉(會減少血管內容積與胎盤灌流),一般清淡飲食即可。
- **產後**:子宮收縮劑 **Methylergonovine(Methergine)/Ergonovine** 會收縮血管升壓 → 妊娠高血壓、子癇前症**禁用**,改用 oxytocin;子癇仍可發生在產後 48 小時內;未來發生高血壓與心血管疾病的風險較高,需長期追蹤。

### 其他族群 {#other-populations}

| 族群 | 重點 |
|---|---|
| **糖尿病** | 目標 < 130/80;合併蛋白尿或 CKD 時首選 **ACEI 或 ARB**(減少蛋白尿);非選擇性 β 阻斷劑會遮蔽低血糖症狀。見 [[diabetes#nephropathy]] |
| **慢性腎臟病** | 首選 ACEI/ARB(有蛋白尿時);監測血鉀與肌酸酐;目標依指引 < 130/80(KDIGO 2021 建議標準化量測下 SBP < 120;國考舊題答案 < 130/85) |
| **老年人** | 常見**單純收縮期高血壓**與姿勢性低血壓;起始劑量低、慢慢加;量坐姿與站姿血壓;預防跌倒;衰弱者目標可放寬 |
| **兒童青少年** | 以年齡、性別、身高百分位判讀(≥ 95 百分位);年齡越小越要找續發性原因(腎臟病、主動脈窄縮) |
| **氣喘/COPD** | 避免**非選擇性** β 阻斷劑(propranolol、nadolol)→ 支氣管收縮;可用 CCB、ACEI/ARB、thiazide;必要時選擇性 β1(metoprolol、bisoprolol) |
| **良性攝護腺肥大** | α1 阻斷劑(doxazosin、terazosin)可同時改善排尿,但注意**首劑姿勢性低血壓** |
| **冠心病/心衰竭** | 優先 β 阻斷劑、ACEI/ARB/ARNI、MRA;見 [[coronary-artery-disease]]、[[heart-failure]] |
| **痛風** | 避免 thiazide(尿酸上升);losartan 可促進尿酸排泄 |
| **育齡女性** | ACEI/ARB 需避孕;未控制的高血壓不宜使用含雌激素的口服避孕藥與荷爾蒙補充療法 |

## 藥物治療 {#drugs}

### 分類總覽 {#drug-classes}

第一線藥物為 **A**(ACEI/ARB)、**C**(鈣離子阻斷劑)、**D**(thiazide 類利尿劑);β 阻斷劑用於有特定適應症(心絞痛、心肌梗塞後、心衰竭、心搏過速)時。

| 類別 | 代表藥 | 主要作用 | 重要副作用 |
|---|---|---|---|
| [[ace-inhibitors\|ACE 抑制劑]] | Captopril、Enalapril、Lisinopril、Ramipril | ↓ Angiotensin II、↓ 醛固酮 | **乾咳**、血管性水腫、**高血鉀**、懷孕禁忌 |
| [[arb\|ARB]] | Losartan、Valsartan、Irbesartan、Telmisartan | 阻斷 AT₁ 受體 | 高血鉀、懷孕禁忌(不咳) |
| [[calcium-channel-blockers\|鈣離子阻斷劑]] | Amlodipine、Nifedipine;Diltiazem、Verapamil | 血管平滑肌放鬆;非 DHP 類減慢心跳 | 下肢水腫、頭痛潮紅、牙齦增生;非 DHP:心搏過緩、便秘 |
| [[thiazide-diuretics\|Thiazide 類利尿劑]] | Hydrochlorothiazide、Indapamide、Chlorthalidone | 排鈉利尿 → 血管阻力下降 | **低血鉀**、低血鈉、高血糖、高尿酸 |
| [[beta-blockers\|β 阻斷劑]] | Metoprolol、Bisoprolol、Atenolol、Carvedilol、Labetalol | ↓心跳、↓心收縮力、↓腎素 | 心搏過緩、疲倦、支氣管收縮、遮蔽低血糖 |
| [[potassium-sparing-diuretics\|保鉀利尿劑/MRA]] | Spironolactone、Eplerenone | 阻斷醛固酮 | **高血鉀**、男性女乳 |
| [[loop-diuretics\|環利尿劑]] | Furosemide | 強效利尿 | 低血鉀、耳毒性;高血壓只在腎功能差或水腫時使用 |
| [[alpha-blockers\|α₁ 阻斷劑]] | Prazosin、Doxazosin、Terazosin | 血管擴張 | **首劑暈厥**(睡前服) |
| [[central-alpha2-agonists\|中樞 α₂ 促效劑]] | Clonidine、Methyldopa | ↓交感輸出 | **驟停反彈性高血壓**、嗜睡、口乾 |
| [[direct-vasodilators\|直接血管擴張劑]] | Hydralazine、Minoxidil、Nitroprusside | 直接放鬆小動脈 | 反射性心搏過速、水鈉滯留;minoxidil 多毛;nitroprusside 氰化物中毒 |
| 腎素抑制劑 | Aliskiren | 直接抑制腎素 | 不可與 ACEI/ARB 併用於糖尿病 |

### 選藥原則 {#drug-selection}

- **大多數人從兩種藥的低劑量合併**開始(第 2 期或高於目標 20/10 mmHg 以上時),最好用**單一錠複方**(single-pill combination)提高服藥遵從;低風險的第 1 期、老年衰弱者可從單一藥物開始。
- 常用組合:**A + C**、**A + D**;不足時 **A + C + D**;仍不足(頑固性高血壓)加 **spironolactone**。
- **不可**合併:ACEI + ARB、ACEI/ARB + aliskiren(高血鉀、腎衰竭);非 DHP 類 CCB(verapamil、diltiazem)+ β 阻斷劑(心搏過緩、房室傳導阻滯)需謹慎。
- 依共病選藥(見 [[#other-populations]])。
- **會引起反射性心搏過速**的:DHP 類 CCB(nifedipine、amlodipine)、α₁ 阻斷劑、hydralazine、minoxidil;β 阻斷劑則會減慢心跳。

:::exam[國考重點]
- RAAS 各作用點最常考:**aliskiren** 抑制腎素 → **ACEI(-pril)** 抑制 Ang I → Ang II 並使 **bradykinin 上升(乾咳)**→ **ARB(-sartan)** 阻斷 AT₁ 受體 → **spironolactone/eplerenone** 阻斷醛固酮受體。
- 「losartan 是 ACEI」「aliskiren 抑制利鈉胜肽分解(那是 sacubitril)」都是錯的。
- **孕婦禁用 ACEI/ARB**;孕婦可用 labetalol、nifedipine、methyldopa、hydralazine。
- **氣喘**避免 propranolol;**糖尿病蛋白尿**首選 ACEI/ARB;**BPH** 選 α₁ 阻斷劑;**嗜鉻細胞瘤**先用 α 阻斷劑。
- **Clonidine** 驟停 → 反彈性高血壓。
:::

## 治療策略 {#treatment}

### 何時開始用藥 {#treatment-threshold}

依 2022 台灣與 2025 ACC/AHA 指引:

| 狀況 | 處置 |
|---|---|
| 血壓偏高(120–129/< 80) | 生活型態調整,每 3–6 個月追蹤 |
| **第 1 期**,低心血管風險 | **先生活型態調整 3–6 個月**,未達標再用藥 |
| **第 1 期**,合併心血管疾病、糖尿病、CKD 或高風險 | 生活型態調整 **+ 藥物** |
| **第 2 期**(≥ 140/90) | 生活型態調整 **+ 藥物**(常直接兩種藥合併) |

### 控制目標 {#targets}

| 指引 | 目標 |
|---|---|
| 2022 台灣、2017/2025 ACC/AHA | 大多數成人 **< 130/80 mmHg**(居家血壓以 722 量測) |
| 舊版指引(國考舊題) | 一般 **< 140/90**;糖尿病/CKD < 130/80(部分舊題 CKD < 130/85) |
| 老年衰弱、預期壽命短 | 個別化放寬,避免姿勢性低血壓與跌倒 |

### 生活型態調整 {#lifestyle-summary}

生活型態調整是**所有**高血壓病人的基礎,不因開始服藥而停止。台灣指引以 **S-ABCDE** 記憶:

| 項目 | 內容 | 約可降低收縮壓 |
|---|---|---|
| **S**odium restriction 限鈉 | 鈉 2–2.4 g/天(鹽 5–6 g) | 5–6 mmHg |
| **A**lcohol limitation 限酒 | 男 ≤ 2 份、女 ≤ 1 份酒精/天 | 3–4 mmHg |
| **B**ody weight reduction 減重 | BMI 20–24,每減 1 kg 約降 1 mmHg | 5–6 mmHg |
| **C**igarette smoke cessation 戒菸 | 降低整體心血管風險 | — |
| **D**iet adaptation 飲食 | **DASH 飲食** | 約 11 mmHg |
| **E**xercise adoption 運動 | 每週 ≥ 150 分鐘中等強度有氧 | 5–8 mmHg |

細節見 [[#education]]。

### 頑固性高血壓 {#resistant}

使用包含利尿劑在內的**三種**足量降壓藥仍未達標(或需四種以上才達標)。先排除**假性**原因:量測錯誤、白袍效應、**服藥遵從性差**(最常見)、高鈉飲食、NSAIDs 等藥物、睡眠呼吸中止;再找續發性原因。第四種藥通常加 spironolactone。

## 護理 {#nursing}

### 常見護理問題 {#nursing-diagnoses}

| 護理問題 | 相關因素 | 措施重點 |
|---|---|---|
| 知識缺失/健康管理無效 | 無症狀、不了解需長期服藥 | 衛教疾病與併發症、722 量血壓、用藥與生活型態 |
| 服藥不遵從 | 無症狀、副作用、多種藥 | 簡化處方(複方錠、每日一次)、藥盒、家屬協助、處理副作用 |
| 潛在危險性受傷(跌倒) | 姿勢性低血壓、利尿劑夜尿 | 改變姿勢要慢、利尿劑早上服 |
| 心輸出量減少/組織灌流改變 | 後負荷增加、器官傷害 | 監測生命徵象、器官功能 |
| 急性疼痛(頭痛) | 血壓驟升 | 評估是否為高血壓急症 |

### 臨床護理措施 {#nursing-clinical}

- **正確量測**血壓(見 [[#measurement]]),每日固定時間、同一手臂、同一姿勢量並記錄;用藥調整期加測站姿血壓。
- **給藥前評估**:
  - β 阻斷劑、非 DHP 類 CCB、clonidine:先量**心跳**(心尖脈),< 60 次/分或有頭暈時暫停並報告;詢問**氣喘**病史。
  - 利尿劑、ACEI/ARB、MRA:追蹤**血鉀、肌酸酐、鈉**、體重、輸出入量。
- **觀察副作用**:
  - 排鉀利尿劑(thiazide、furosemide)出現**肌肉無力、抽筋、心悸、腹脹** → 懷疑低血鉀:監測心律、驗電解質、補充含鉀食物(香蕉、柑橘、深綠色蔬菜)、協助活動防跌。
  - 保鉀藥物(spironolactone、ACEI/ARB)→ 避免大量高鉀水果、**代鹽**(低鈉鹽多為氯化鉀)與鉀補充劑;腎功能差者**不可吃楊桃**(神經毒性)。
  - ACEI 乾咳 → 報告醫師改 ARB,不要自行停藥;嘴唇、舌頭、臉部腫脹(血管性水腫)→ 立即停藥就醫。
  - 所有降壓藥:姿勢性低血壓 → 起身「**坐起 → 床緣坐 → 站立**」各停一下。
- 保持**排便通暢**(高纖、足夠水分,必要時軟便劑),避免用力解便與閉氣。
- 因禁食檢查錯過的降壓藥:依醫囑於恢復進食後補服,**不可**下一次一起吃兩倍劑量;降壓藥原則上檢查當天早上仍以少量開水服用(依醫囑)。
- 與病人溝通時避免防衛性回答(例如病人抱怨藥沒效,不要回「我們的藥都是最好的」),應探討原因並轉達醫師。

### 服藥衛教 {#medication-education}

- **血壓控制良好是藥物的效果,不代表治好了**——不可自行停藥或減藥(驟停 clonidine、β 阻斷劑會反彈,血壓失控易中風)。
- 忘記服藥:想起來就補,但若接近下一次服藥時間就跳過,**不可一次吃兩倍**。
- 起身放慢;利尿劑早上吃(避免夜尿影響睡眠與跌倒)。
- 避免自行服用 **NSAIDs**、含**甘草**或偽麻黃鹼的感冒藥、減肥藥;服用鋰鹽者併用 ACEI/thiazide 會使**血鋰上升**。
- **葡萄柚汁**會提高部分 CCB(felodipine、nifedipine)血中濃度。
- 帶血壓紀錄與藥袋回診。

## 衛教與社區護理 {#education}

### 飲食 {#diet}

#### 限鈉 {#sodium}

- 每日**鈉 2,000–2,400 mg**,約等於**食鹽 5–6 g**(1 茶匙)。國考常用「鈉 2,400 mg = 鹽 6 g」;WHO 建議鹽 < 5 g。換算:**鹽(g)× 0.4 = 鈉(g)**。
- 限鈉的目的是減少**水分滯留**,降低血管內容積與心臟負荷。
- **隱藏的鈉**:**味精**(麩胺酸鈉)、**小蘇打/發粉**(碳酸氫鈉)、醬油、烏醋、番茄醬、沙茶醬、豆瓣醬、**加工食品**(火腿、香腸、罐頭、泡麵、醃漬物、蜜餞、麵線)、**運動飲料**、起司。
- 技巧:用**天然辛香料**(蔥、薑、蒜、九層塔、檸檬、醋、胡椒)取代鹽與醬料;烹調以**清蒸、水煮、涼拌**取代紅燒、滷、醃;起鍋前再加鹽;麵湯不要喝完;看營養標示的「鈉」含量。
- 低鈉鹽多是**氯化鉀**,腎功能不全或服用保鉀藥物者不可自行使用。

#### DASH 飲食 {#dash}

**DASH**(Dietary Approaches to Stop Hypertension)是降壓效果最明確的飲食型態:

| 多吃 | 少吃 |
|---|---|
| **蔬菜、水果**(富含**鉀**、鎂) | 鈉 |
| **全穀類**、**高纖** | 飽和脂肪、**紅肉**、全脂乳品 |
| **低脂**乳製品(**鈣**) | **甜食、含糖飲料** |
| 堅果、豆類、魚、家禽 | 油炸、動物油 |

- 原則:「**低鈉、低脂、高纖、高鉀鈣鎂**」——「高鈣高鈉」是錯的。
- **高纖**(燕麥、大麥、豆類、蔬果)可結合膽酸、減少膽固醇吸收。
- 腎功能不全者高鉀的 DASH 飲食需與醫師、營養師討論。
- 膽固醇:國考常用「每日 < 300 mg」;美國 2015 年後的飲食指南已取消明確上限,改為「儘量少吃」。
- 咖啡因:一般適量(每天 1–2 杯)不必完全禁止,但量血壓前 30 分鐘避免。

#### 體重與酒精 {#weight-alcohol}

- 維持 **BMI 18.5–24**(台灣:24–26.9 過重、≥ 27 肥胖)、腰圍男 < 90、女 < 80 cm。
- 酒精:男性每天 ≤ 2 份、女性 ≤ 1 份(1 份約 10 g 酒精 ≈ 啤酒 250 mL、紅酒 100 mL、烈酒 30 mL);最好不喝。應酬時學會婉拒、自我克制。

### 運動 {#exercise}

- **有氧(等張)運動**:快走、慢跑、騎腳踏車、**游泳**、**太極拳**、健走;每週至少 **150 分鐘中等強度**(或 75 分鐘費力),建議**每天 30 分鐘**、每週 5 天以上。
- 可加入每週 2–3 次**動態**阻力運動(輕重量、多次數)。
- **避免等長運動**(舉重、提重物、伏地挺身撐住不動):閉氣用力產生 **Valsalva** → 血壓瞬間上升。
- 避免**三溫暖、烤箱、泡溫泉/熱水澡**,以及冷熱水交替:血管急劇擴張或收縮,血壓劇烈波動。洗澡水溫勿過高、時間勿過長,冬天浴室先保暖。
- 運動前暖身、運動後緩和;出現胸痛、頭暈、呼吸困難立即停止;血壓 > 180/110 未控制時先不做中高強度運動。
- 規律運動也能**提高 HDL**、改善胰島素敏感性、協助減重。

### 其他生活調整 {#other-lifestyle}

- **戒菸**(包括電子菸、二手菸)。
- 壓力管理、規律作息、充足睡眠;懷疑睡眠呼吸中止(打鼾、白天嗜睡)要就醫。
- 保暖:冬天清晨起床先在被窩中活動手腳、戴帽子圍巾,避免突然接觸冷空氣。
- 避免**用力解便**:高纖、多喝水(無限水醫囑)。

### 社區衛生與三段五級 {#prevention}

| 段/級 | 內容 | 高血壓的例子 |
|---|---|---|
| 初段:**促進健康** | 一般民眾健康生活 | 健康飲食(少鹽)、規律運動、體重控制的衛教 |
| 初段:**特殊保護** | 針對高危險群 | 有家族史、肥胖、代謝症候群、血壓偏高者的生活型態介入 |
| 次段:**早期診斷、早期治療** | 篩檢、及早治療 | 社區量血壓、成人預防保健、整合性篩檢、722 居家量測;新診斷者開始治療 |
| 三段:**限制殘障** | 控制疾病、防止併發症 | 已確診者**規則服藥**、用藥指導(如社區藥局用藥諮詢)、定期追蹤器官功能 |
| 三段:**復健** | 恢復功能 | 中風後的復健 |

- 判斷原則:「**找出**還沒被發現的人」屬次段;「已經確診、**控制疾病防止併發症**」屬三段限制殘障。題目若描述「教導老人按時服藥」,要看對象是否已確診。
- **資源**:國健署**成人預防保健**(40–64 歲每 3 年一次、**65 歲以上每年一次**,含血壓、血糖、血脂、腎功能);社區血壓站;慢性病連續處方箋;高血壓病友團體。
- **代謝症候群**(國健署,5 項中 ≥ 3 項):腰圍男 ≥ 90、女 ≥ 80 cm;**血壓 ≥ 130/85**(或服藥中);空腹血糖 ≥ 100 mg/dL;三酸甘油酯 ≥ 150 mg/dL;HDL 男 < 40、女 < 50 mg/dL。高尿酸**不在**其中。
- **計畫評值**:過程評值(人力、時間、經費、參與率)、衝擊評值(知識、態度、**行為**如規則量血壓、就醫行為)、結果評值(**罹病率、死亡率**、中風發生率)。
- **流行病學**:調查村里三高分布屬**描述性流行病學**。
- 社區個案**優先順序**:傳染性疾病(開放性肺結核、登革熱)通常優先於穩定的高血壓個案;慢性病中以「血壓/血糖不穩定**又**不遵從治療」者最需持續追蹤。
- 四大非傳染病的共同危險因子:**吸菸、不當飲酒、缺乏運動、不健康飲食**。
