分娩期異常是指產力、產道、胎兒或胎盤臍帶出問題，使分娩無法順利進行或危及母嬰。本頁整理產力異常與產程延長、急產、胎位與胎產式異常、肩難產、多胞胎、子宮破裂與內翻、羊水栓塞、臍帶脫垂、胎兒窘迫、胎死腹中、早產與安胎、過期妊娠，以及引產、器械生產與剖腹產。正常分娩見 [[labor-process]]，待產護理見 [[intrapartum-care]]，胎心監測見 [[intrapartum-fetal-monitoring]]，前置胎盤與胎盤早期剝離見 [[high-risk-pregnancy#late-bleeding]]，早期破水與感染見 [[perinatal-infections#prom-chorioamnionitis]]。文中縮寫：CPD(Cephalopelvic disproportion，胎頭骨盆不對稱)、OP(Occiput posterior，枕後位)、ECV(External cephalic version，胎頭外轉術)、IUFD(Intrauterine fetal death，胎死腹中)、DIC(Disseminated intravascular coagulation，瀰漫性血管內凝血)、VBAC(Vaginal birth after cesarean，剖腹產後陰道生產)、TOLAC(Trial of labor after cesarean，剖腹產後嘗試陰道生產)

## 重點摘要 {#summary}

- **低張性**宮縮：多在**活動期**、宮縮弱而少 → 排除 CPD 後用**催產素**、人工破水
- **高張性**宮縮：多在**潛伏期**、痛但無效、休息期張力高 → **休息、止痛**，**不用催產素**
- **枕後位**：產程長、**下背痛**、內迴轉 **135 度**；**薦骨加壓**、手膝跪姿、側臥
- **肩難產**：**McRoberts 屈腿**＋**恥骨上加壓**；**不可壓子宮底**、不可用力拉
- **臍帶脫垂**：**不可推回**；用手把**先露部位往上頂**、**膝胸臥**或垂頭仰臥、**溫生理食鹽水紗布**覆蓋、緊急剖腹產
- **子宮破裂**：撕裂痛、**宮縮停止**、胎心音消失、腹部摸到胎體、休克
- **Bishop 分數**：子宮頸**擴張、變薄、位置、軟硬**與**胎頭高度**；分數低先讓子宮頸**成熟**(前列腺素)

### 國考常考點 {#exam-points}

- 枕後位產程延長的主要機轉：**內迴轉成枕前位、費時長**；枕後位**第一產程較長**、**子宮頸擴張較慢**(先露部下降**較慢**)
- 潛伏期延長但母胎無異常：**不是立即剖腹產**；給水分食物、找原因、常換姿勢
- 6 公分、10 分鐘 2 次、20 秒、10 mmHg、3 小時無進展、胎心正常 → **低張性** → **輸注催產素**(不是 ritodrine)
- 硬膜外麻醉後 2 小時胎頭不下降、無 CPD → 優先**評估膀胱**
- 有急產經驗、7 公分、一直有便意 → **不可讓她去廁所解便**；聯絡醫師、準備接生、內診、吹蠟燭式呼吸先不用力
- 待產突然撕裂性腹痛、腹部明顯凹陷、測不到宮縮與胎心 → **子宮破裂**
- 肩難產：**屈曲大腿靠向腹部**(McRoberts)、**注意胎心音**；**不可**壓子宮底、**不可**加強催產素
- 臍帶脫垂：**不可**把臍帶推回子宮
- 用 oxytocin 引產出現變異性減速 → **停止**滴注
- Bishop 項目：**子宮頸擴張、變薄、位置、軟硬度**、**胎頭高度**；**不包括**胎兒體重、懷孕週數、胎位
- Bishop 用來評估**引產前子宮頸成熟度**(例如過期妊娠)；每項 0–3 或 0–2 分；分數**越高**越容易引產成功
- 子宮頸 < 1 公分、變薄 30%、摸不到先露部位、位置後、硬 → **0 分** → **前列腺素陰道塞劑**促子宮頸成熟
- 真空吸引：吸杯放在**枕骨**(後囟門前方的俯屈點)，不是前囟門；**配合宮縮**牽引；胎頭**要已固定**；**CPD 不適用**；新生兒可能**頭血腫**
- 剖腹產：區域麻醉術後**不必等排氣**即可進食；術前 1 天與手術當天**聽胎心音**；**不需**術前 3 天低渣或劃線
- 剖腹產後**不一定**每胎都要剖腹；子宮下段橫切口**出血少**；胎兒窘迫是緊急剖腹產的適應症
- VBAC：**曾子宮破裂**不宜；前胎**子宮下段橫切**可以嘗試；前置胎盤不宜；剖腹次數**會影響**

## 產力異常與產程延長 {#dysfunctional-labor}

| | **高張性子宮收縮** | **低張性子宮收縮** |
|---|---|---|
| 出現時機 | **潛伏期** | **活動期**(原本進展正常後變慢) |
| 宮縮 | 頻繁、**不協調**、**休息期張力高**(子宮沒有放鬆) | **弱、次數少**、持續短、強度低(容易按下去) |
| 疼痛 | **與宮縮強度不成比例的劇痛** | 疼痛不明顯 |
| 子宮頸 | 沒有進展 | 擴張變慢或停止 |
| 胎兒 | 胎盤灌流不足 → 早期出現胎兒窘迫 | 較晚；產程長易感染 |
| 原因 | 焦慮、疲累、子宮肌肉不協調 | CPD、胎位不正、**子宮過度膨大**(多胞胎、羊水過多、巨嬰)、**膀胱脹**、過早給止痛或麻醉、多產 |
| 處置 | **休息**、**鎮靜止痛**、補充水分；**不用催產素** | **先排除 CPD 與胎位不正**，再**催產素**、**人工破水**；排空膀胱、走動換姿勢 |

- **產程延長的定義**
   1. 潛伏期延長：初產婦 > 20 小時、經產婦 > 14 小時(Friedman)
   2. **活動期停滯**(ACOG／SMFM 2014)：子宮頸 **≥ 6 公分**且已破水，宮縮足夠 **4 小時**以上或宮縮不足並用催產素 **6 小時**以上仍沒有進展
   3. **第二產程停滯**：初產婦用力 ≥ 3 小時、經產婦 ≥ 2 小時(有硬膜外可更久)
- **潛伏期延長**但母胎沒有異常
   1. **不需要立即剖腹產**
   2. 提供**水分與食物**、休息、止痛
   3. 評估原因(假陣痛、過早用止痛、子宮頸未成熟)
   4. **常換姿勢**、走動，幫助胎兒轉位下降
- 產程停滯時**先評估膀胱**(硬膜外麻醉後尤其常見)、宮縮、胎位、胎頭與骨盆
- 產程延長的危險：產婦**疲累脫水**、**感染**、產後出血；胎兒窘迫
- 催產素用法與停藥條件見 [[pituitary-hormones#oxytocin]]

### 急產 {#precipitate-labor}

- 從規則宮縮到胎兒娩出 **< 3 小時**
- 原因：產道阻力低(經產婦)、宮縮過強(含催產素過量)
- 危險
   1. 母親：**軟產道裂傷**、**子宮破裂**、**產後出血**(子宮疲乏)、羊水栓塞
   2. 胎兒：宮縮過強 → 缺氧；**顱內出血**；來不及消毒而感染；墜地受傷
- 護理
   1. 有急產史、經產婦宮縮密且**有便意感** → **不要讓她去廁所解便**(可能把孩子生在馬桶)
   2. 內診確認子宮頸、**通知醫師**、**準備接生環境**
   3. 未全開時教**哈氣、吹蠟燭式**呼吸，先不要用力；側臥
   4. 來不及時護理師接生：胎頭著冠時**輕壓胎頭**讓它**慢慢**娩出(不是用手擋住阻止娩出)，保護會陰
   5. 產後檢查軟產道裂傷、注意子宮收縮與出血

## 胎位與胎產式異常 {#malpresentation}

### 枕後位 {#occiput-posterior}

- 胎頭枕骨在母親骨盆**後方**(ROP 較常見)
- 影響
   1. 胎頭要**內迴轉 135 度**才轉成枕前位 → **費時長** → **第一、二產程延長**
   2. **先露部下降較慢**、**子宮頸擴張較慢**
   3. 胎頭壓迫薦骨 → 明顯**下背痛**
   4. 少數轉不過來 → 以直接枕後位娩出、會陰裂傷較大，或需器械生產
- 護理
   1. **薦骨反向施壓**、按摩、熱敷減輕背痛(見 [[labor-pain-relief#non-pharmacologic]])
   2. **手膝跪姿**、**膝胸臥**、骨盆搖擺、**側臥**(胎背那一側朝上)，幫助胎頭旋轉
   3. 補充水分、排空膀胱、陪伴

::questions{ids="111-1_OP_016,106-2_OP_017"}

### 臀產式 {#breech}

- 約 3–4%；早產兒較多
- 分類：完全臀產式、**伸腿臀產式**(最常見)、足位與膝位(不完全)，見 [[labor-process#fetal-position-terms]]
- 危險
   1. **臍帶脫垂**(尤其足位)
   2. 後出頭卡住 → 新生兒窒息、產傷
   3. 羊水裡有胎便**不一定**代表窘迫(臀部受壓排出)
- 處置
   1. 約 **36–37 週**以後可做**胎頭外轉術**(ECV)，在超音波與胎心監測下進行
   2. 課本另有**膝胸臥式**矯正運動，效果證據不足
   3. 足月單胎臀位多數**剖腹產**；陰道生產需有經驗者
- 胎心音在**臍上**聽

### 橫位、面產式、額產式 {#other-malpresentation}

| | 說明 | 處置 |
|---|---|---|
| **橫位**(肩產式) | 胎兒長軸與母親垂直；子宮底與恥骨上都摸不到主要胎塊，頭臀分在兩側 | 足月**無法陰道生產** → **剖腹產**；破水時易**臍帶脫垂**、手臂脫出 |
| **面產式** | 胎頭**完全仰伸**，以 SMB 通過；內診摸到眼、鼻、口 | 頦骨在前(頦前位)可陰道生產；頦骨在後無法 → 剖腹產；新生兒臉部腫脹瘀青 |
| **額產式** | 胎頭**部分仰伸**，以**最大的 OM** 通過 | 持續額產式通常**無法陰道生產** → 剖腹產 |

### 胎頭骨盆不對稱 {#cpd}

- 胎頭與骨盆大小或形狀不相稱(骨盆狹窄、巨嬰、胎位不正)
- 徵象：初產婦足月胎頭**未銜接**、產程停滯、胎頭塑形明顯、產瘤大
- **CPD 時不可用催產素加強宮縮**、**不可用真空吸引或產鉗** → 剖腹產
- 骨盆四型見 [[labor-process#passage]]

### 巨嬰與肩難產 {#shoulder-dystocia}

- **巨嬰**：出生體重 **≥ 4,000 公克**(或 4,500 公克)；危險因子：**糖尿病**(見 [[high-risk-pregnancy#diabetes]])、肥胖、過期妊娠、多產
- **肩難產**：胎頭娩出後，前肩卡在**恥骨聯合**後方
   1. 徵象：胎頭娩出後又**縮回**緊貼會陰(**烏龜徵象**)
   2. 處置(呼叫支援、記錄時間)
      1. **McRoberts 手法**：協助產婦**大腿用力屈曲靠向腹部** → 骨盆出口變大
      2. **恥骨上加壓**：在恥骨聯合**上方**往下、往側推前肩
      3. 醫師做旋轉手法、先娩出後臂
      4. **不可壓子宮底**(會把肩膀卡得更緊、子宮破裂)、**不可**用力牽拉胎頭、**不可**加強子宮收縮劑
      5. 持續**監測胎心音**
   3. 新生兒併發症：**臂神經叢損傷**(厄氏麻痺)、**鎖骨骨折**(見 [[fractures#clavicle-newborn]])、窒息
   4. 母親：產後出血、軟產道裂傷

::questions{ids="113-3_OP_022"}

### 多胞胎 {#multiple-pregnancy}

- 雙胞胎的種類與形成見 [[fertilization-embryology#twins]]
- 懷孕期：**早產**、子癇前症、貧血、妊娠糖尿病、羊水過多、**雙胞胎輸血症候群**(單絨毛膜)、胎兒生長受限
- 分娩期：胎位不正、宮縮乏力、臍帶脫垂、第二胎胎盤早期剝離；多需剖腹產
- 產後：子宮過度膨大 → **產後出血**
- 護理：增加營養與休息、更頻繁產檢、早產衛教(見 [[high-risk-pregnancy#preterm-risk]])

## 子宮破裂與子宮內翻 {#uterine-problems}

### 子宮破裂 {#uterine-rupture}

- 危險因子：**前次剖腹產**(尤其**古典直式切口**)或子宮肌瘤切除、**催產素過量**、產程受阻(CPD、胎位不正)、多產、外傷
- **前兆**：**病理性收縮環**(班德爾環)升到肚臍附近、子宮下段壓痛、宮縮過強、產婦躁動
- **破裂時**
   1. 突然**撕裂般劇痛**，之後**宮縮停止**
   2. 腹部外形改變(**凹陷**)、**腹壁下摸到胎體**
   3. **胎心音消失**或嚴重減速
   4. 內出血 → **休克**、陰道出血
- 處置：停止催產素、**休克處置**(輸液輸血、給氧)、**緊急剖腹手術**
- 和其他急症區別：羊水栓塞以呼吸困難、低血氧、心跳停止為主；胎盤早期剝離子宮**硬如木板**、仍有宮縮

::questions{ids="114-1_OP_021"}

### 子宮內翻 {#uterine-inversion}

- 子宮底翻出(部分或全部)到子宮頸或陰道外，多在**第三產程**
- 原因：胎盤還沒剝離就**用力拉臍帶**、按壓鬆弛的子宮底、植入性胎盤
- 表現：大量出血、劇痛、**休克**(與出血量不成比例)、腹部摸不到子宮底、陰道口看到紅色團塊
- 處置：呼叫支援、**不要**先剝胎盤、**停用子宮收縮劑**、休克處置、醫師徒手推回(必要時用子宮鬆弛劑或麻醉)，推回後才給子宮收縮劑
- 預防：第三產程**不可猛拉臍帶**

## 羊水異常 {#amniotic-fluid}

### 羊水栓塞 {#amniotic-fluid-embolism}

- 羊水與胎兒成分進入母體循環 → 類過敏反應
- 多在分娩中或產後不久，危險因子：宮縮過強、急產、剖腹產、高齡
- 表現：突然**呼吸困難**、**發紺**、低血氧、**低血壓**休克、抽搐、**心跳停止**，接著**DIC**大出血
- 處置：**CPR**、給氧與插管、升壓、處理 DIC(輸血與凝血因子)；孕婦急救時子宮左推、準備緊急剖腹產(見 [[cpr]])
- 病理機轉見 [[thrombosis-embolism-infarction]]

### 羊水過多與過少 {#amniotic-fluid-volume}

| | **羊水過多** | **羊水過少** |
|---|---|---|
| 定義(約) | > 2,000 mL 或 **AFI ≥ 24–25 公分** | < 500 mL 或 **AFI ≤ 5 公分** |
| 原因 | 胎兒**無法吞嚥**(食道閉鎖、無腦兒)、**母親糖尿病**、多胞胎 | 胎兒**腎臟異常或尿路阻塞**、胎盤功能不良、**過期妊娠**、破水 |
| 影響 | 呼吸困難、胎位不正、**臍帶脫垂**、破水後**胎盤早期剝離**、產後出血 | **臍帶受壓**(變異性減速)、肺發育不全、肢體變形、胎便吸入 |
| 處置 | 半坐臥、必要時羊膜穿刺減量 | 增加水分攝取、監測胎兒；產時可羊膜腔灌注 |

- AFI 的測量見 [[prenatal-assessment#ultrasound]]；羊水的生理見 [[fertilization-embryology#amniotic-fluid]]

## 臍帶脫垂 {#cord-prolapse}

- 破水後臍帶滑到先露部位**前方或旁邊**，被胎兒先露部位壓住 → 胎兒缺氧
- 危險因子：**胎頭未固定時破水**(含人工破水)、**臀位**(足位)、**橫位**、早產兒、**羊水過多**、多胞胎
- 徵象：陰道看到或摸到臍帶、破水後突然出現**變異性減速**或**心搏過緩**
- 處置(呼叫醫師，持續到剖腹產)
   1. **戴無菌手套**伸入陰道，把**先露部位往上頂**，解除對臍帶的壓迫，手留在原處
   2. 姿勢：**膝胸臥式**或**垂頭仰臥**(Trendelenburg)、抬高臀部
   3. 脫出的臍帶**不可推回子宮**、盡量不碰觸(避免血管痙攣)
   4. 用**溫無菌生理食鹽水紗布覆蓋**臍帶，保持濕潤溫暖
   5. 給氧、停止催產素、持續監測胎心音
   6. 子宮頸**未全開** → **緊急剖腹產**；已全開且胎頭低 → 可能器械生產
- 預防：破水後**立即聽胎心音**；胎頭未固定時不做人工破水

::questions{ids="113-3_OP_021"}

## 胎兒窘迫 {#fetal-distress}

- 胎兒在子宮內**缺氧**、酸中毒；現在較常用「胎心率圖形異常」描述
- 原因
   1. 母親：低血壓(仰臥、硬膜外麻醉)、貧血、高血壓、子癇前症、發燒
   2. 子宮：**宮縮過強**(催產素過量)、子宮破裂
   3. 胎盤：**胎盤早期剝離**、前置胎盤出血、**胎盤功能不良**(過期妊娠、生長受限)
   4. 臍帶：**臍帶受壓**、脫垂、繞頸、羊水過少
- 徵象
   1. 胎心率異常：持續心搏過速或**過緩**、**變異減少或消失**、**反覆晚期減速**、嚴重變異性減速、延長減速(判讀見 [[intrapartum-fetal-monitoring#interpretation]])
   2. **羊水胎便染色**(頭產式時更有意義)
   3. 胎動減少
- 處置：**子宮內復甦**(左側臥、停催產素、加快輸液、給氧、通知醫師，見 [[intrapartum-fetal-monitoring#intrauterine-resuscitation]])；無法改善 → **儘快娩出**(器械生產或**緊急剖腹產**)，準備新生兒復甦

## 胎死腹中 {#iufd}

- 懷孕 20 週以後胎兒死在子宮內
- 表現：**胎動停止**、聽不到胎心音、子宮不再長大；超音波確認
- 留置太久(約 **4 週**以上) → 母親**凝血異常、DIC**；要追蹤凝血功能
- 處置：多數引產(前列腺素、催產素)
- 護理：**哀傷輔導**
   1. 讓父母依意願看、抱、為嬰兒命名，留下照片、手腳印等紀念
   2. 傾聽、允許表達情緒，不說「還年輕可以再生」
   3. 安排單獨房間，避開其他新生兒
   4. 說明下次懷孕的評估、轉介支持團體

## 早產與安胎 {#preterm-labor}

- **早產**：懷孕 **20(或 24)週到未滿 37 週**出現規則宮縮與子宮頸變化
- 危險因子、徵兆與高危險孕婦的自我照顧見 [[high-risk-pregnancy#preterm-risk]]；早期破水見 [[perinatal-infections#prom-chorioamnionitis]]
- 治療目標：安胎約 **48 小時**，爭取時間給**產前類固醇**與轉送到有新生兒加護病房的醫院(ACOG PB 171)

| 安胎藥 | 機轉 | 副作用與監測 |
|---|---|---|
| **Ritodrine**(Yutopar) | **β2 致效劑** → 子宮平滑肌放鬆 | **心悸、心跳快**、手抖、**高血糖**、**低血鉀**、**肺水腫**；母親心跳 **> 120 次/分**、胸痛、呼吸困難、濕囉音、血壓 < 90/60 → **停藥**通知醫師(解藥 propranolol)；用輸液幫浦；歐美已不建議長時間注射(見 [[adrenergic-agonists#beta2-agonists]]) |
| **Nifedipine**(Adalat) | **鈣離子阻斷劑** | 頭痛、臉潮紅、**低血壓**、反射性心跳快；監測血壓與胎心(見 [[calcium-channel-blockers]]) |
| **Atosiban**(Tractocile) | **催產素受體拮抗劑** | 副作用少，適合**心臟病**或對 ritodrine 副作用明顯者 |
| **硫酸鎂** | 與鈣競爭 → 抑制收縮 | 安胎效果有限；**< 32 週**短期使用做**胎兒神經保護**(降低腦性麻痺)；毒性監測**膝反射、呼吸、尿量**，解藥**葡萄糖酸鈣**(見 [[hypertension#pregnancy]]、[[fluid-electrolytes]]) |
| Indomethacin | 前列腺素抑制 | < 32 週短期；動脈導管提早關閉、羊水減少 |

- **產前類固醇**：**24–34 週**可能在 7 天內早產者給 **betamethasone** 12 mg 肌肉注射、間隔 24 小時共 2 劑，**促進胎兒肺成熟**(見 [[corticosteroids]])
- 安胎護理
   1. 說明藥物副作用、監測生命徵象、**肺音**、輸出入量、血糖、宮縮與胎心
   2. 安胎藥與臥床可能心悸、手抖、便秘、腹脹、肌力變差 → 症狀護理；**灌腸是禁忌**(刺激宮縮)
   3. 穩定後返家：適度休息、避免提重物，但**不需絕對臥床**(沒有安胎效果、增加血栓)
   4. 心理支持：傾聽擔心
- 無法安胎時：止痛用藥要小心(早產兒呼吸抑制)，多選區域麻醉；**胎頭固定後才人工破水**(減少臍帶脫垂)；準備早產兒的照護(見 [[preterm-infant]])

::questions{tag="早產" limit="8"}

## 過期妊娠 {#post-term}

- 懷孕滿 **42 週**以上(41 週以後稱晚期足月)
- 危險
   1. **胎盤功能退化** → 胎兒缺氧、**羊水過少**、**胎便吸入**、胎死腹中
   2. 胎盤功能仍好時 → **巨嬰**、難產、肩難產
   3. 新生兒**過熟症候群**：皮膚脫皮乾裂、胎脂與胎毛少、指甲長、警覺
- 處置
   1. 先**確認週數**(早期超音波)
   2. 41 週後加強胎兒監測(NST、羊水量，見 [[prenatal-assessment#antepartum-testing]])
   3. 依子宮頸成熟度(**Bishop**)**引產**

## 引產 {#induction}

- 定義：在自然產程開始前，用藥物或機械方法**誘發宮縮**；**催生**是加強已開始但進展不好的宮縮
- 適應症
   1. 母親：**妊娠高血壓、子癇前症**、糖尿病、**過期妊娠**、**早期破水**沒有自然宮縮、絨毛膜羊膜炎
   2. 胎兒：**胎死腹中**、胎兒生長受限、羊水過少、同種免疫
- 禁忌：**前置胎盤**、血管前置、**橫位**、臍帶脫垂、**CPD**、**古典直式剖腹產**或子宮全層手術史、活動性生殖器疱疹

### Bishop 分數 {#bishop-score}

| 項目 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| **子宮頸擴張**(公分) | 0(閉合) | 1–2 | 3–4 | ≥ 5 |
| **子宮頸變薄**(%) | 0–30 | 40–50 | 60–70 | ≥ 80 |
| **胎頭高度** | −3 | −2 | −1、0 | +1、+2 |
| **子宮頸軟硬度** | **硬** | 中等 | 軟 | |
| **子宮頸位置** | **後方** | 中間 | 前方 | |

- 滿分 13 分；評估**引產前子宮頸成熟度**
- **≥ 8 分**：子宮頸成熟，引產成功率接近自然產
- **≤ 6 分**：子宮頸未成熟 → 先用**子宮頸成熟**方法
- 項目**不包括**胎兒體重、懷孕週數、胎位、胎心率
- 例：擴張 < 1 公分(0)、變薄 30%(0)、摸不到先露部位(高於 −3，0)、位置後(0)、硬(0) → **0 分** → **前列腺素陰道塞劑**

::questions{ids="113-2_OP_021,112-2_OP_033,107-2_OP_033,106-1_OP_018"}

### 引產方法 {#induction-methods}

| 方法 | 說明 | 護理 |
|---|---|---|
| **剝膜** | 內診時把胎膜從子宮下段分離，釋放前列腺素 | 可能少量出血與不適 |
| **前列腺素**(PGE2 dinoprostone 陰道塞劑、PGE1 misoprostol) | **軟化子宮頸**、誘發宮縮；**子宮頸未成熟**時用 | 放置後臥床約 30 分鐘到 2 小時、監測宮縮與胎心；宮縮過強要取出塞劑；與催產素間隔依藥物說明；**氣喘**、前次剖腹產慎用(見 [[pituitary-hormones#other-uterotonics]]) |
| 機械性擴張 | 子宮頸放 **Foley 球囊**導管 | 感染、破水 |
| **人工破水**(羊膜切開術) | 用羊膜鉤刺破胎膜，加強宮縮；**胎頭要已固定** | 破水前後**聽胎心音**(臍帶脫垂)、記錄羊水顏色與量、監測體溫 |
| **催產素** | 子宮頸成熟後誘發或加強宮縮；靜脈滴注、輸液幫浦、**側管** | 連續胎心監測；宮縮過強、胎心異常(晚期或變異性減速)**立即停藥**；長時間大量給 → 水中毒(見 [[pituitary-hormones#oxytocin]]) |

## 器械生產 {#operative-vaginal}

| | **真空吸引** | **產鉗** |
|---|---|---|
| 做法 | 吸杯放在胎頭**枕骨**(矢狀縫上、**後囟門前方約 3 公分**的俯屈點)，產生負壓後**配合宮縮**往外牽引 | 兩片鉗葉夾住胎頭兩側，配合宮縮牽引 |
| 新生兒併發症 | **頭血腫**、**產瘤**(吸杯處腫脹)、帽狀腱膜下出血、頭皮擦傷 | 臉部壓痕瘀青、**顏面神經麻痺**、頭顱骨折 |
| 母親併發症 | 軟產道裂傷較少 | **軟產道裂傷**較多 |

- 必要條件：**子宮頸全開**、**已破水**、**胎頭已固定**(高度夠低)、知道胎位、**沒有 CPD**、排空膀胱、有經驗的醫師、麻醉或止痛足夠
- 適應症：第二產程延長、**產婦疲累無法用力**、胎兒窘迫、母親心臟病須縮短用力
- 禁忌：**CPD**、胎頭未固定、子宮頸未全開；真空吸引不用於 34 週前早產兒、臉產式
- 護理：說明過程、排空膀胱、監測胎心、配合宮縮時鼓勵用力；產後檢查新生兒頭部與母親產道
- 新生兒頭血腫與產瘤的比較見 [[newborn-assessment#head]]

::questions{ids="115-2_OP_021,105-2_OP_034"}

## 剖腹產 {#cesarean}

- 經**腹壁與子宮切口**取出胎兒
- 適應症
   1. 母親：**CPD**、**前置胎盤**(完全性與部分性)、前次古典切口或子宮手術、產程停滯、活動性生殖器疱疹、子宮破裂
   2. 胎兒：**胎兒窘迫**(緊急剖腹產)、**橫位**、多數臀位、**臍帶脫垂**、巨嬰
- 子宮切口

| | **子宮下段橫切** | 古典直切(子宮體) |
|---|---|---|
| 出血 | **較少** | 較多 |
| 下一胎子宮破裂 | **低** → 可考慮 VBAC | **高** → **不宜**陰道生產 |
| 用在 | 大多數剖腹產 | 早產兒、橫位、前置胎盤在前壁等 |

- **術前護理**
   1. 說明、簽同意書、心理支持(緊急剖腹產尤其需要)
   2. **禁食**：固體食物術前 6–8 小時、清流質到術前 2 小時(美國麻醉醫學會)；依醫囑給制酸劑
   3. **術前 1 天與手術當天聽胎心音**
   4. 留置**導尿管**(避免膀胱受傷)、建立靜脈管路、術前 60 分鐘內預防性抗生素
   5. 皮膚準備：**不常規剃毛**，必要時用電剪
   6. 麻醉前靜脈輸液(不用葡萄糖水，見 [[labor-pain-relief#pharmacologic]])
- **術後護理**
   1. 生命徵象、**子宮收縮與惡露**、傷口出血、尿量
   2. **區域麻醉**後**不必等排氣**即可漸進進食(加速術後康復)；全身麻醉依腸蠕動恢復
   3. **早期下床**預防血栓與腸脹氣；導尿管約術後 12–24 小時移除
   4. 止痛(硬膜外或 PCA)、咳嗽時壓住傷口
   5. 儘早**肌膚接觸**與哺乳(橄欖球式抱法避開傷口)
   6. 產後護理見 [[postpartum-care#cesarean-care]]

::questions{ids="112-1_OP_023,111-1_OP_015,108-1_OP_016"}

### 剖腹產後陰道生產 {#vbac}

- **剖腹產後不一定**下一胎都要剖腹；符合條件可嘗試陰道生產(TOLAC)，成功稱 VBAC(ACOG PB 205)
- 適合：前次 **1 次(或 2 次)子宮下段橫切**、這胎沒有其他剖腹產適應症、醫院能隨時進行緊急剖腹產
- **不適合**：**曾子宮破裂**、**古典直切**或 T 形切口、子宮體大手術、**前置胎盤**等陰道生產禁忌
- 剖腹產**次數越多**，子宮破裂風險越高
- 主要危險：**子宮破裂**(見上方)；產程中連續胎心監測，注意子宮破裂徵象
