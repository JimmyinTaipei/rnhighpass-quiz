耳朵疾病主要造成**聽力喪失**、**耳鳴**與**眩暈**。耳朵構造、聲音傳導與平衡生理見 [[special-senses#ear]]；**中耳炎、滴耳藥與中耳手術後護理**見 [[pediatric-respiratory-infections#otitis-media]]；聽神經瘤見 [[brain-tumors#types]]

## 重點摘要 {#summary}

- **傳導性**聽力喪失：**外耳或中耳**(耳垢栓塞、中耳炎、鼓膜破裂、耳硬化症)；**任內試驗陰性**(患耳**骨導 ≥ 氣導**)、**韋伯試驗偏向患耳**
- **感覺神經性**聽力喪失：**內耳或聽神經**(老化、噪音、耳毒性藥物、梅尼爾氏症、聽神經瘤)；**任內試驗陽性**(**氣導 > 骨導**)、**韋伯偏向健耳**；在噪音中更聽不清楚
- 聽力分級：**25 分貝以內正常**；26–40 輕度、41–55 中度、56–70 中重度、71–90 重度、**90 以上極重度**
- **梅尼爾氏症**：**內淋巴水腫**；**陣發性眩暈、耳鳴(低沉)、單側感覺神經性聽力喪失(早期低頻)、耳悶脹**；**不會耳痛**；**低鹽**飲食、限制水分、利尿劑、抗組織胺；發作時**立即臥床**、動作緩慢；藥物無效時迷路切除術
- **良性陣發性姿勢性眩暈**：耳石掉進半規管；頭部轉到某個位置引發短暫眩暈；**耳石復位術**
- 與聽障者溝通：**面向光線**讓對方看清嘴型、**先告知主題**、轉換話題先提示、說話**慢、清楚、音調稍低**、不要大吼
- **噪音**：每天 8 小時暴露在 **85 分貝**以上會傷害聽力

### 國考常考點 {#exam-points}

- 右耳聽障、韋伯偏向右耳、右耳任內試驗氣導 ≤ 骨導 → 病變在**外耳或中耳**(傳導性)
- **感覺神經性**聽力喪失：任內試驗**氣導時間比骨導長**；韋伯是偏向**健側**；在噪音中聽力**不佳**；外耳道與鼓膜正常
- 任內試驗 **AC < BC** 屬於**傳導性**；韋伯患耳較大聲是**傳導性**(不是感覺神經性)；**藥物毒性造成感覺神經性**；助聽器**不能完全**改善溝通
- 音叉評估：目的是區別傳導性與感覺神經性、**避免強烈敲擊**；感覺神經性的患耳在韋伯試驗聽到的聲音**較小**
- 聽力分級：只能聽見 60 分貝以上是**中重度**，不是重度
- 與聽力問題最無關的：**甲狀腺亢進**(高血壓、糖尿病、頭部外傷都有關)
- 與聽障者溝通：**不要等對方先開口**、也**不是護理師先開口**自己說，要**先讓對方知道主題**；面部採光良好；換話題先通知；家中電話加擴音、電鈴加閃光；說話速度勿太快、音調稍低
- 梅尼爾氏症：**單側**(不是雙側)感覺神經性聽力喪失、利尿劑、急性眩暈時臥床(可採患耳在上)、避免快速移動
- 梅尼爾氏症護理：急性發作立即臥床、生活規律情緒平穩、血管擴張劑可改善耳鳴；**不是多喝水**
- 梅尼爾氏症：內耳淋巴水腫、**耳鳴**是典型症狀；**耳痛不是**；**不是傳導性**
- 飲食：**低鹽**(不是低鉀、不是低脂)；可用利尿劑、抗組織胺、抗焦慮劑；鼓勵在不發作時做平衡運動
- 梅尼爾氏症又稱迷路水腫、好發 40–60 歲；女性在**月經前或月經期間**(不是月經後)容易惡化；藥物無效可做**迷路切除術**；原因是**內耳**(不是外耳)淋巴液過多
- 初期是**低頻**聽力喪失
- 滴耳藥：使用前搖勻、**躺向健側使患耳朝上**；**不需先滴生理食鹽水**、**不用棉棒擦耳內**
- 2 歲幼兒滴耳藥：耳垂**往下往後**拉(不是往上往後)；藥溫接近體溫；**不直接滴在鼓膜**；滴後可輕按耳屏；**不用棉棒塞住耳道**
- 給左耳藥：頭側向**右側**；3 歲以下耳垂**向下向後**；6 歲兒童耳廓**向上向後**
- 勞工健康保護規則：每天 8 小時暴露在 **85 dB** 以上會造成聽力傷害

## 聽力喪失 {#hearing-loss}

| | **傳導性** | **感覺神經性** |
|---|---|---|
| 病變 | **外耳、中耳**：耳垢栓塞、外耳炎、**中耳炎**與中耳積液、**鼓膜破裂**、**耳硬化症** | **內耳(耳蝸)、聽神經**：**老化**、**噪音**、**耳毒性藥物**(aminoglycoside、loop 利尿劑、cisplatin、高劑量 aspirin)、**梅尼爾氏症**、**聽神經瘤**、病毒感染、先天 |
| 聽力特徵 | 聲音變小但清楚；自己說話覺得大聲；**在噪音中反而聽得較清楚** | 聲音不清楚、聽得到但聽不懂；**噪音中更差**；常有耳鳴 |
| **任內試驗** | 患耳**骨導 ≥ 氣導**(陰性) | **氣導 > 骨導**(陽性)，兩者時間都縮短 |
| **韋伯試驗** | 偏向**患耳** | 偏向**健耳** |
| 治療 | 多可藥物或手術矯正 | 助聽器、**人工電子耳**；多為永久 |

- 混合性：兩者兼有
- **音叉試驗**
  1. **任內試驗**：音叉放在**乳突**(骨導)，聽不到時移到**外耳道口**(氣導)；正常氣導時間約是骨導的 2 倍
  2. **韋伯試驗**：音叉放在**頭頂中線或前額**，問哪一耳較大聲
  3. 輕敲音叉，**不要用力敲擊**
- **純音聽力檢查**的分級(國考使用)

| 聽閾(分貝) | 程度 |
|---|---|
| ≤ 25 | 正常 |
| 26–40 | 輕度 |
| 41–55 | 中度 |
| 56–70 | 中重度 |
| 71–90 | 重度 |
| > 90 | 極重度 |

- **相關疾病**：**高血壓、糖尿病**(內耳微血管與神經病變)、**頭部外傷**(顳骨骨折)、腎臟病、自體免疫疾病；甲狀腺**低下**也可能(先天性甲狀腺低下要追蹤聽力)；**甲狀腺亢進**一般無關
- **老年性聽力喪失**：從**高頻**開始，聽不清楚子音、女性與小孩的聲音；在吵雜環境更困難
- **噪音性聽損**：長期噪音先傷害 **4,000 Hz** 附近；依勞工健康保護規則，每天 8 小時暴露在 **85 分貝**以上屬噪音作業，要定期聽力檢查與配戴耳塞、耳罩

### 與聽障者溝通 {#communication}

1. 先**引起注意**(輕拍肩膀、到對方看得到的位置)，**先告知要談的主題**，換話題時先提示
2. **面對面**，讓**光線照在說話者臉上**(不要背光)，方便讀唇與看表情
3. 說話**慢、清楚、音調稍低**，句子簡短；**不要大吼**(會扭曲嘴型、讓聲音失真)
4. 不嚼東西、不遮嘴；必要時換句話說、寫字、手勢或手語
5. 減少背景噪音；對著聽力較好的耳朵說話
6. 鼓勵病人**主動告知**別人自己聽力不好，並說出需要
7. 居家：電話加擴音器、門鈴與火警加**閃光**裝置
8. **助聽器**：先戴一段時間適應；**不能完全恢復**正常聽力；不戴時取出電池、避免潮濕與高溫

## 眩暈與內耳疾病 {#vertigo}

### 梅尼爾氏症 {#menieres-disease}

- **機轉**：內耳膜迷路**內淋巴液過多**(**內淋巴水腫**、迷路水腫)；原因不明
- 好發 **40–60 歲**；壓力、疲勞、高鹽飲食、咖啡因、酒精、**月經前或月經期間**(水鈉滯留)容易發作
- **典型表現**
  1. **陣發性旋轉性眩暈**：數十分鐘到數小時，常合併噁心嘔吐
  2. **耳鳴**(低沉的嗡嗡聲)
  3. **單側感覺神經性聽力喪失**，**早期是低頻**、起伏不定，反覆發作後逐漸變成永久
  4. 耳朵悶脹感
  5. **不會耳痛**、不是傳導性
- **治療**
  1. 飲食：**低鹽**、**限制水分**、避免**咖啡因、酒精、尼古丁**與味精
  2. 藥物：**利尿劑**(減少內淋巴)、**抗組織胺**與鎮靜止吐藥(急性眩暈)、**抗焦慮劑**、**血管擴張劑**(改善內耳循環與耳鳴)
  3. 藥物無效：鼓室內注射(類固醇或 gentamicin)、內淋巴囊減壓術、前庭神經切斷術；**迷路切除術**可以根除眩暈，但患耳**聽力會完全喪失**
- **護理**
  1. 急性發作：**立即臥床**、閉眼休息，環境安靜、光線柔和；可躺向使眩暈較輕的姿勢(考題答案可採患耳在上)
  2. 移動身體**要緩慢**、避免頭部快速轉動；拉起床欄、協助下床，**預防跌倒**
  3. 不發作時鼓勵做**頭部與全身的平衡運動**(前庭復健)，幫助代償
  4. 記錄發作情形；生活規律、情緒平穩、減壓
  5. 發作期間不要開車或高處作業

### 其他眩暈 {#other-vertigo}

| 疾病 | 特點 | 處理 |
|---|---|---|
| **良性陣發性姿勢性眩暈** | 最常見的周邊性眩暈；**橢圓囊耳石脫落**掉入半規管；**翻身、躺下、抬頭**到某個姿勢時突然天旋地轉，**數十秒**就停；沒有聽力喪失 | **耳石復位術**(Epley 法)；之後睡覺頭部稍高、避免突然姿勢改變 |
| 前庭神經炎 | 病毒感染後；**持續數天**的嚴重眩暈、噁心嘔吐；**聽力正常** | 短期止暈藥、類固醇、及早前庭復健 |
| **動暈症** | 視覺與前庭訊號不一致(搭車船飛機) | 坐在晃動少的位置、看遠方地平線；出發前 **scopolamine 貼片**或抗組織胺 |
| 中樞性眩暈 | 腦幹或小腦中風、腫瘤；合併**複視、構音困難、無力、走路不穩** | **急症**，要排除中風(見 [[stroke]]) |

- 眩暈和**頭暈**不同：眩暈是**天旋地轉**的感覺；頭暈眼前發黑常是低血壓或心律不整
- 平衡的生理見 [[special-senses#balance]]

## 外耳與中耳疾病 {#external-middle-ear}

| 疾病 | 重點 |
|---|---|
| **耳垢栓塞** | 傳導性聽損、耳悶；**不要用棉棒往裡挖**(會推更深)；用耳垢軟化劑或由醫護人員沖洗(鼓膜破裂者禁止沖洗) |
| **外耳炎**(游泳耳) | 外耳道細菌(綠膿桿菌)或黴菌感染；**拉耳廓或按壓耳屏時疼痛**；抗生素耳滴劑；保持耳道乾燥、游泳後擦乾 |
| **中耳炎** | 經耳咽管上行感染；耳痛、發燒、鼓膜紅腫膨出；傳導性聽損(見 [[pediatric-respiratory-infections#otitis-media]]) |
| **耳硬化症** | 鐙骨基部骨質異常增生、固定在卵圓窗 → **漸進性傳導性聽損**；年輕女性、有家族史、懷孕時可能惡化；**鐙骨切除術**加人工鐙骨或助聽器 |
| 鼓膜破裂 | 外傷、氣壓、中耳炎；多可自行癒合；保持乾燥、不要擤鼻用力 |

- 中耳手術後的姿勢與注意事項(張口打噴嚏、避免擤鼻與潛水)見 [[pediatric-respiratory-infections#ear-surgery]]

## 滴耳藥 {#ear-drops}

1. 核對藥名與耳別：**A.D. 右耳、A.S. 左耳、A.U. 雙耳**
2. 藥液**回溫到接近體溫**(太冷會刺激內耳引起眩暈)；懸浮液**使用前搖勻**
3. **側臥、患耳朝上**：給**左耳藥時頭側向右**
4. 拉直外耳道
   1. **3 歲以下**：耳垂**往下、往後**拉
   2. **3 歲以上與成人**：耳廓**往上、往後**拉
5. 藥液**沿著外耳道壁**滴入，**不可直接滴在鼓膜上**；滴管不碰耳朵
6. 滴後**輕按耳屏**或按摩耳前，幫助藥液流入；**維持姿勢約 5 分鐘**
7. **不需要先滴生理食鹽水**；**不可用棉棒擦拭耳內**或把棉球塞進耳道深處(必要時在外耳口放一小塊鬆的棉花)
