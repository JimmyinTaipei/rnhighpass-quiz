**腦下垂體疾病**分成「分泌太多」(功能性腺瘤)、「分泌太少」(功能低下)與「腫瘤佔位壓迫」三類。本頁整理常見腺瘤、肢端肥大症、功能低下、腦下垂體中風，以及經蝶骨手術與伽瑪刀的護理；正常生理見 [[hypothalamus-pituitary]]，後葉的尿崩症與 SIADH 見 [[diabetes-insipidus-siadh]]，其他腦瘤見 [[brain-tumors]]

## 重點摘要 {#summary}

- 腺瘤種類：**泌乳素瘤最常見**；生長激素腺瘤(肢端肥大症)；**ACTH 腺瘤(庫欣氏病)**；LH 腺瘤極少見
- 佔位症狀：頭痛、**雙顳側偏盲**(壓迫**視交叉**)、海綿竇受壓時腦神經 III、IV、VI 麻痺、壓壞正常組織造成功能低下
- **肢端肥大症**：手腳變大、臉部粗糙、下顎突出、**多汗**、關節痛、**腕隧道症候群**、睡眠呼吸中止與嗜睡、**葡萄糖耐受性降低**、高血壓
- **巨人症**：青春期前(骨骺未閉合)生長激素過多；末期促性腺激素不足 → 第二性徵延遲；**不會低血糖**
- 治療：**經蝶骨手術**首選，**不保證不復發**；放射治療或伽瑪刀；**octreotide** 可縮小腫瘤
- **功能低下**：生長激素最常也最早缺乏；**席漢氏症候群**是**產後大出血**造成腦下垂體缺血壞死；表現為虛弱、低血糖、黏液水腫、無月經
- **腦下垂體中風**：腺瘤在**蝶鞍**內出血或梗塞、壓力急升 → 突發劇烈頭痛、頸部僵硬、畏光、視力受損、荷爾蒙不足；**不會半側偏癱**
- **經蝶骨術後**：床頭抬高 30 度；**不擤鼻涕、不打噴嚏咳嗽、不用力解便**；鼻流清水用**尿糖試紙**檢查(腦脊髓液含糖)，不可塞住或抽吸；監測**尿崩症**與低血容積

### 國考常考點 {#exam-points}

- 腫瘤壓迫**視交叉** → **雙顳側偏盲**(不是頂葉、枕葉或腦神經)
- 不是常見功能性腺瘤的是 **LH 腺瘤**
- 庫欣氏**病**是腦下垂體 ACTH 分泌過多；長期服類固醇是醫源性庫欣氏**症候群**
- 肢端肥大症：**多汗**(不是少汗)、可能**高血鈣**與腎結石(不是低血鈣)
- 巨人症**不會**低血糖；經蝶骨手術**不保證根治**
- 席漢氏症候群是**產後大出血**，不是腦下垂體切除
- 腦下垂體中風**不會**肢體半側偏癱
- 經蝶骨術後**不可平躺**(床頭抬高)、鼻水驗糖、**不可用力擤鼻涕**；術後第 4 天持續流鼻水與頭痛 → 疑腦脊髓液漏，教導不擤鼻涕、暫不下床
- 術後多尿、劇渴是**尿崩症**，不是血糖上升；類固醇要**飯後**吃
- 伽瑪刀：**不開刀、不流血、不痛**，腫瘤**不會立即消失**
- 生長激素缺乏兒童：**睡前**皮下注射(模擬夜間分泌高峰)，不是早上；用**發展年齡**互動，智力正常

## 腦下垂體腺瘤 {#adenoma}

| 腺瘤 | 比例 | 分泌過多造成 |
|---|---|---|
| **泌乳素瘤** | **最常見** | 女性：**無月經、溢乳**、不孕；男性：性慾降低、勃起障礙 |
| 生長激素腺瘤 | 常見 | 巨人症、**肢端肥大症** |
| ACTH 腺瘤 | 較少 | **庫欣氏病**(庫欣氏症候群的一種，見 [[cushing-syndrome]]) |
| TSH 腺瘤 | 罕見 | 次發性甲狀腺亢進 |
| LH／FSH 腺瘤 | **極少見**、多半不分泌 | 常以佔位症狀表現 |
| 無功能腺瘤 | 常見 | 只有佔位症狀與功能低下 |

- **佔位症狀**(與分泌無關)
   1. 頭痛
   2. 往上壓迫**視交叉** → **雙顳側偏盲**、視力下降(視覺徑路見 [[special-senses#visual-pathway]])
   3. 往側邊侵犯海綿竇 → 腦神經 III、IV、VI 受影響(複視、眼瞼下垂)
   4. 壓迫正常腦下垂體 → 功能低下
- 診斷：MRI、各激素濃度、視野檢查
- **泌乳素瘤**治療以藥物為主：多巴胺致效劑 **cabergoline**(2023 Pituitary Society 共識的首選，作用長、副作用較少)或 **bromocriptine**(國考常考)；藥物無效或壓迫視力時才手術；藥物細節見 [[pituitary-hormones#dopamine-agonists]]
- **庫欣氏病**的原因：腦下垂體腺瘤分泌過多 **ACTH** → 刺激雙側腎上腺皮質；腎上腺皮質增生、肺癌分泌 ACTH(異位)與長期服類固醇是庫欣氏症候群的其他原因

## 生長激素過多：巨人症與肢端肥大症 {#gh-excess}

| | 巨人症 | 肢端肥大症 |
|---|---|---|
| 發生時期 | **青春期前**，骨骺未閉合 | **成人**，骨骺已閉合 |
| 主要表現 | 身高異常增加 | 骨骼末端與軟組織增厚 |

- **肢端肥大症的表現**
   1. 外觀：手腳變大(戒指、鞋子變緊)、下顎突出、鼻與嘴唇變厚、舌頭變大、皮膚增厚、**多汗**、皮脂增多、多毛
   2. 骨骼肌肉：**關節痛**、肌肉無力
   3. 神經：**腕隧道症候群**(軟組織壓迫正中神經)、頭痛、睡眠呼吸中止與白天**嗜睡**
   4. 代謝：生長激素拮抗胰島素 → **葡萄糖耐受性降低**、糖尿病；可能**高血鈣**、尿鈣增加與**腎結石**
   5. 心血管：高血壓、心臟肥大
- 巨人症：生長激素拮抗胰島素，血糖**上升**而不是低血糖；腫瘤變大壓到促性腺激素細胞 → 第二性徵發育延遲
- 診斷：**IGF-1** 上升；口服葡萄糖後生長激素**無法被抑制**
- **治療**(Endocrine Society 2014)
   1. **經蝶骨腺瘤切除**為首選；術後仍可能殘留或**復發**，要追蹤生長激素與 IGF-1
   2. 放射治療或伽瑪刀(腫瘤侷限、手術無法完全切除時)
   3. 藥物：體抑素類似物 **octreotide**(可**縮小腫瘤**)、生長激素受體拮抗劑 pegvisomant、cabergoline
- 外觀改變大多不會完全恢復，需給予身體心像的支持

## 腦下垂體功能低下 {#hypopituitarism}

- **原因**：腺瘤壓迫、**手術或放射治療**後、**席漢氏症候群**、腦下垂體中風、頭部外傷、感染
- **席漢氏症候群**：懷孕時腦下垂體變大、血流需求高，**產後大出血**造成低血壓 → 腦下垂體**缺血壞死**；早期線索是**產後無法泌乳**、月經不再來
- 激素缺乏的表現(**生長激素最常也最早缺乏**)

| 缺乏 | 表現 |
|---|---|
| 生長激素 | 兒童生長遲緩；成人肌肉減少、疲倦 |
| LH、FSH | 無月經、不孕、性慾下降、第二性徵退化 |
| TSH | 怕冷、疲倦、**黏液水腫**等甲狀腺低下表現 |
| ACTH | **虛弱無力、低血糖**、低血壓；壓力時可能腎上腺危象 |
| 泌乳素 | 產後無法泌乳 |

- 治療：終身補充缺乏的激素(類固醇、甲狀腺素、性激素、生長激素)
   1. 同時缺 ACTH 與 TSH 時，**先補類固醇、再補甲狀腺素**，避免甲狀腺素增加代謝後誘發腎上腺危象(Endocrine Society 2016)
   2. 生病或手術時類固醇需加量，隨身攜帶識別卡

::questions{ids="115-1_MS_044"}

### 腦下垂體中風 {#apoplexy}

- 腺瘤在狹小的**蝶鞍**內突然**出血或梗塞**，內部壓力急升
- 表現：突發**劇烈頭痛**、**頸部僵硬**、畏光、噁心嘔吐、**視力受損**與視野缺損、眼肌麻痺、意識改變、急性腎上腺功能不足(**荷爾蒙失調**)
- 和一般腦中風不同，**通常沒有半側偏癱**
- 處置：急診**靜脈類固醇**、監測視力與意識，視力惡化時緊急減壓手術

::questions{ids="111-2_MS_004,113-3_MS_046"}

### 兒童生長激素缺乏 {#gh-deficiency}

- 身材矮小但比例正常、**智力正常**；骨齡落後
- 治療：**生長激素皮下注射**，通常**睡前**給(模擬夜間分泌高峰)，部位輪替(腹部、大腿等)
- 護理：依**發展年齡**而不是外表年齡互動；鼓勵發展身高以外的優勢能力；定期測身高、記錄生長曲線
- 其他兒童內分泌問題見 [[pediatric-endocrine]]

::questions{ids="111-1_OP_069"}

## 治療與護理 {#treatment}

### 經蝶骨手術 {#transsphenoidal-surgery}

- 由**上唇內側或鼻腔**經**蝶竇**進入蝶鞍切除腫瘤，**頭部外表沒有傷口**；術後鼻腔填塞
- **術前**
   1. 說明術後鼻腔填塞、需**用口呼吸**，練習深呼吸但**不用力咳嗽**
   2. 口腔清潔改用漱口，**暫時不刷牙**(避免傷到上唇切口，時間依醫囑)
   3. 視野與激素基準值；依醫囑術前給類固醇
- **術後**
   1. **床頭抬高約 30 度**，降低顱內壓與傷口張力；不可平躺
   2. **不擤鼻涕、不打噴嚏、不用力咳嗽、不用力解便**(可依醫囑給軟便劑)、**不彎腰**(時間依醫囑)，避免顱內壓上升與腦脊髓液漏
   3. **腦脊髓液鼻漏**：鼻腔流出清澈水樣液體或吞嚥時有鹹味 → 用**尿糖試紙**檢測(腦脊髓液**含葡萄糖**、一般鼻涕不含)，通知醫師；**不可抽吸、不可塞住鼻孔**；持續漏時暫時臥床，注意腦膜炎徵象
   4. 監測**尿崩症**：術後多尿、劇渴、尿比重低 → 是 ADH 不足，不是血糖上升；記錄輸出入量與尿比重(見 [[diabetes-insipidus-siadh]])
   5. 監測**低血容積與休克**、顱內壓上升徵象、視力與視野
   6. 補充類固醇時**飯後**服用，減少胃腸刺激；說明不可自行停藥
- 腫瘤太大或往上長太多時改用開顱手術，術後照護見 [[brain-tumors]]

::questions{ids="110-2_MS_071,109-2_MS_007,108-1_MS_073,115-2_MS_001"}

### 伽瑪刀與放射治療 {#gamma-knife}

- **伽瑪刀**是立體定位放射手術：戴固定頭架，把多道伽瑪射線聚焦在腫瘤上
- **不用開刀、沒有傷口、不流血、不痛**，不需引流管
- 效果**慢慢出現**(數月到數年)，腫瘤**不會立即消失**；日後可能出現腦下垂體功能低下，需長期追蹤
