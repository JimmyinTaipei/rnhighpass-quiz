出血疾病依問題出在哪一段止血過程，分成血管、血小板與凝血因子三類。本頁整理出血的鑑別與原因、血小板減少與出血預防、ITP、血友病、類血友病、維生素 K 缺乏與新生兒出血、DIC；止血與凝血瀑布見 [[blood-hemostasis#hemostasis]]，檢驗判讀見 [[coagulation-tests]]，血友病與類血友病的遺傳見 [[single-gene-disorders#hemophilia]]，DIC 的病理機轉見 [[thrombosis-embolism-infarction#dic]]

## 重點摘要 {#summary}

- **血小板型出血**(血小板少、功能差、vWF 不足)：皮膚黏膜**瘀點**、流鼻血、牙齦出血、月經過多；**出血時間延長**
- **凝血因子型出血**(血友病、維生素 K 缺乏、肝病)：**關節血腫**、深部肌肉出血、受傷後延遲出血；**凝血時間延長**
- **血小板減少**：< 50,000 受傷易出血、< 20,000 可能自發出血、< 10,000 注意**顱內出血**；照護是**避免 aspirin／NSAID、肌肉注射、用力閉氣、牙線與牙籤**，用軟毛牙刷、電動刮鬍刀、軟便劑
- **ITP**：自體抗體破壞血小板，骨髓**巨核細胞正常或增加**；兒童多在**病毒感染後**急性發生、多數 **6 個月內自行緩解**；無或輕微出血先**觀察**，需要時類固醇或 IVIG
- **血友病**：X 性聯；**A 缺 VIII、B 缺 IX**；**膝關節**最常出血；關節出血**冰敷、固定、抬高、補凝血因子**，**不熱敷**；適合**游泳**；儘早教居家照護
- **類血友病**：最常見的遺傳性出血疾病；黏膜出血；輕型可用 **desmopressin**
- **DIC**：敗血症、產科急症(胎盤早期剝離、羊水栓塞)、創傷、毒蛇咬傷、癌症；**血小板與纖維蛋白原下降、PT／aPTT 延長、FDP 與 D-dimer 上升**；**先治原因**，再補血小板與血漿成分

### 國考常考點 {#exam-points}

- 出血疾病的原因：vWD、第 VIII 因子缺乏、肝硬化(凝血因子製造少)、維生素 K 缺乏；**維生素 D 缺乏不是**
- 類血友病是出血傾向，和**高凝血狀態無關**
- 血小板減少的定義在國考答案是 **< 100,000/mm³**；**> 30,000 且沒有嚴重出血通常不需治療**；可能顱內出血造成頭痛與意識改變；**皮膚黏膜很容易出現紫斑**
- 血小板 40,000：**還不是**「非常容易自發出血」；要**避免 aspirin 與 heparin**、給**軟便劑**；**不用肌肉注射**
- 血小板低：**避免閉氣用力**；不用牙線與牙籤，改軟毛牙刷或海綿潔牙棒；**鼻黏膜可塗凡士林**保濕；不用 NSAID 止痛；不是輸「凝血因子」而是輸血小板
- 急性 ITP：好發**兒童病毒感染後**、病程 **< 6 個月**、**自發痊癒率高、很少復發**；骨髓**巨核細胞增加**；與**自體免疫**有關、**不是細菌感染後**；避免 aspirin
- ITP 幼兒：**多數會自行緩解**，不是「只能長期藥物控制」；脾臟切除**不在 3 歲前**做(課本：5 歲以上、持續 1 年以上的慢性 ITP 才考慮)
- 血友病：A 缺 **VIII**、B 缺 **IX**；**凝血時間延長、出血時間正常**；X 性聯隱性，**不是**體染色體隱性
- 血友病表徵：**皮膚瘀血、刷牙牙齦出血**；關節血腫最常在**膝關節**，其次肘、踝；**肩關節較少**
- 血友病關節出血：**不熱敷**(會加重出血)；加壓、冰敷、休息、抬高、依醫囑補凝血因子
- 血友病運動：**游泳**最適合；避免籃球、躲避球、跳馬等衝撞運動；鼓勵**適度活動**強化關節周圍肌肉
- 血友病照護：避免肌肉與靜脈注射等不必要的侵入性處置、**不頻繁抽血**、定期看牙、用**軟毛牙刷**；止痛**不用 aspirin**；儘早給病童與家屬**居家照護知識**；**學齡期**(不是學齡前)才開始學自己注射凝血因子(靜脈注射)
- 女性帶因者與正常男性：**每個兒子 1/2 機率**罹病、每個女兒 1/2 機率帶因
- 新生兒維生素 K 缺乏的原因：腸道菌叢不足、肝臟不成熟、**維生素 K 不易通過胎盤**；**不是腸道吸收能力不成熟**
- DIC：**纖維蛋白原下降**(不是上升)、**D-dimer 上升**(不是下降)、血小板下降、PT／aPTT 延長；**優先治療原因**(例如敗血症)；常見誘因不包括慢性淋巴性白血病；DIC 病人**不可用力解便**
- 胎盤早期剝離產後：**預防產後大出血並持續觀察凝血機制**(DIC)

## 出血的鑑別與原因 {#causes}

| | 血小板與血管型 | 凝血因子型 |
|---|---|---|
| 例子 | 血小板減少、ITP、aspirin、**類血友病**、維生素 C 缺乏(血管脆弱) | **血友病**、維生素 K 缺乏、肝病、warfarin、DIC |
| 出血部位 | **皮膚黏膜**：瘀點、紫斑、流鼻血、牙齦出血、月經過多 | **關節血腫**、深部肌肉血腫、內出血 |
| 時間 | 受傷後**立即**出血 | **延遲**出血或止血後再出血 |
| 檢驗 | **出血時間延長**、血小板數下降(vWD 時正常) | **凝血時間、PT 或 aPTT 延長**，出血時間正常 |

- **紫斑**是皮膚內出血造成的紫紅色斑塊，**壓下不會退色**(和紅疹不同)；< 3 mm 稱瘀點，較大稱瘀斑
- 原因分類
   1. 血小板：骨髓製造少(再生不良、白血病、化療)、破壞多(ITP、DIC、脾腫大、heparin)、功能差(aspirin、尿毒症、血小板無力症)
   2. 凝血因子：遺傳(血友病、vWD)、**肝病**(製造少)、**維生素 K 缺乏**(阻塞性黃疸、吸收不良、長期抗生素、新生兒、warfarin)、消耗(DIC)
   3. 電解質：國考把**低血鈣**列為凝血時間與出血時間延長的原因(鈣是凝血第 IV 因子，見 [[calcium-phosphate]])
- 檢驗判讀見 [[coagulation-tests#interpretation]]

## 血小板減少症 {#thrombocytopenia}

- 正常 15–40 萬/mm³；國考答案以 **< 100,000/mm³** 稱血小板減少症(有些教材用 < 150,000)
- 出血風險(依常用分級，輸注門檻見 [[complete-blood-count#platelets]])

| 血小板(/mm³) | 風險 |
|---|---|
| 50,000–100,000 | 手術或外傷後出血較多 |
| 20,000–50,000 | 輕微碰撞就瘀青；**> 30,000 且沒有嚴重出血通常不需治療** |
| < 20,000 | 可能**自發性出血** |
| < 10,000 | **顱內出血**風險：評估**意識狀態**、頭痛、瞳孔 |

- **出血預防措施**(血小板低、DIC、抗凝治療共用)
   1. 口腔：**軟毛牙刷**，很低時改**海綿潔牙棒**；**不用牙線、牙籤、牙縫刷**
   2. 皮膚：**電動刮鬍刀**；剪短指甲；避免碰撞，床欄加護墊；穿軟底鞋
   3. 侵入性處置：**避免肌肉與皮下注射**、量肛溫、肛門塞劑與灌腸；抽血或注射後**加壓 5–10 分鐘**
   4. **避免閉氣用力**(Valsalva)：用**口服軟便劑**、不用力解便、不用力咳嗽或擤鼻涕；鼻黏膜乾燥可塗**凡士林**
   5. 藥物：**不用 aspirin、NSAID**，避免 heparin、warfarin；止痛用 acetaminophen
   6. 觀察：瘀點、黑便、血尿、牙齦出血、月經量、頭痛與意識改變
- 依醫囑輸**血小板濃厚液**；化療造成的血小板減少見 [[cancer-treatment-toxicities#thrombocytopenia]]
- **肝素誘發的血小板減少(Heparin-induced thrombocytopenia，HIT)**：用 heparin 5–10 天後血小板下降並反而**形成血栓**，要停所有 heparin、改用 argatroban 等(見 [[anticoagulants#adverse-effects]])
- 其他：**血栓性血小板減少性紫斑症(Thrombotic thrombocytopenic purpura，TTP)**與**溶血性尿毒症候群(Hemolytic uremic syndrome，HUS)**是微血管內形成血小板血栓，消耗血小板並溶血；骨髓**巨核細胞減少**的血小板減少是**再生不良性貧血**(見 [[anemias#aplastic]])

## 免疫性血小板減少症(ITP) {#itp}

- 舊稱**特發性血小板減少性紫斑症**；自體抗體(IgG)附在血小板上，在**脾臟**被破壞；骨髓**巨核細胞正常或增加**(代償)
- 兒童與成人不同

| | 兒童(急性為主) | 成人(慢性為主) |
|---|---|---|
| 好發 | **2–5 歲**，**病毒感染或疫苗接種後** 1–3 週突然出現 | 20–40 歲女性，與自體免疫疾病(SLE)有關 |
| 病程 | 多數 **6 個月內自行緩解**，**很少復發**；約 2 成變慢性 | 多為**慢性**，容易反覆 |
| 表現 | 突然全身瘀點、瘀斑、流鼻血，**人看起來很好**；肝脾、淋巴結不腫大 | 皮膚黏膜出血、月經過多 |

- 病程分期(ASH 2019)：新診斷 < 3 個月、持續性 3–12 個月、**慢性 > 12 個月**
- 治療
   1. 兒童新診斷、**無或只有輕微皮膚出血**：ASH 2019 建議**觀察**，不論血小板多少；門診追蹤即可
   2. 有明顯黏膜出血或需要快速提升：**類固醇**(prednisolone)或**靜脈免疫球蛋白(Intravenous immunoglobulin，IVIG)**；嚴重出血輸血小板(會被破壞，效果短)
   3. 慢性：血小板生成素受體促效劑、rituximab；**脾臟切除**——課本寫 **5 歲以上、持續 1 年以上**才考慮(《兒科護理學》p.510)，不在 3 歲前做；切除後要預防感染(疫苗、發燒就醫)
- 國考常考的「類固醇治療」仍是正確答案；觀察策略是現行指引的補充
- 護理
   1. 居家安全：床欄與地板加**護墊**、避免碰撞性運動、戴安全帽
   2. **禁用 aspirin**、NSAID；不做肌肉注射
   3. 教家長辨認出血徵象：大片瘀斑、血尿、黑便、頭痛、嘔吐、意識改變(顱內出血)
   4. 安撫家長：多數會自行好轉

## 血友病 {#hemophilia}

- 遺傳與檢驗重點(見 [[single-gene-disorders#hemophilia]])：**X 性聯隱性**、患者幾乎都是男性；**A 型缺第八因子**(約 80–85%)、**B 型缺第九因子**；**aPTT 與凝血時間延長**，出血時間、PT、血小板正常
- 嚴重度依凝血因子活性：**< 1% 重度**(自發性關節與肌肉出血)、1–5% 中度、5–40% 輕度(手術或外傷後才出血)
- 表現
   1. 學步時開始容易**瘀青**；刷牙**牙齦出血**、換牙或拔牙出血不止
   2. **關節血腫**：最常在**膝關節**，其次肘、踝；肩、腕較少；關節腫、熱、痛、活動受限；反覆出血 → **血友病關節病變**(關節變形、攣縮)
   3. 深部肌肉血腫(腸腰肌出血會壓迫股神經)；**顱內出血**最危險
- 治療
   1. **補充凝血因子**(A 型補 VIII、B 型補 IX)，**靜脈注射**；出血時儘早補充
   2. **預防性(規律)補充**：WFH 2020 認為是改變血友病自然病程的唯一方法，減少關節損傷
   3. **Emicizumab(Hemlibra)**：模仿第八因子功能的單株抗體，**皮下注射**；健保 2026-03-01 起給付範圍擴大到**嚴重(FVIII < 1%)無抑制物**的 A 型血友病預防性治療(健保藥品給付規定 4.2.7，**條文細節待核對**)
   4. 輕型 A 型可用 **desmopressin(DDAVP)** 釋放體內儲存的 VIII 與 vWF；tranexamic acid 用於口腔出血
   5. 部分病人產生**抑制物**(抗第八因子抗體)，補因子效果變差
- **關節出血的處理**
   1. 儘早**補充凝血因子**
   2. **休息**、**冰敷**、**加壓**、**抬高**(RICE)，必要時**副木固定**(《內外科護理學》上冊 p.980)；輕微外出血加壓 10–15 分鐘或冷敷(《兒科護理學》p.508)
   3. **不熱敷**(血管擴張會加重出血)、不按摩
   4. 止痛用 **acetaminophen**，**不用 aspirin**；出血停止後逐步做物理治療恢復關節活動
- 生活與居家照護
   1. 運動：**游泳**、騎腳踏車(戴護具)；**避免籃球、躲避球、跳馬、足球**等衝撞運動；鼓勵**適度活動**強化關節周圍肌肉
   2. 避免**肌肉注射**與不必要的侵入性處置、**不需頻繁抽血**；疫苗改皮下注射並加壓
   3. 口腔：**軟毛牙刷**、定期看牙預防齲齒(拔牙前要補因子)
   4. 家中不放 aspirin；配戴醫療識別手環
   5. **儘早教導居家照護**：家長學會辨認出血與在家注射凝血因子；**學齡期**孩子開始學自我注射(靜脈注射，不是皮下)
   6. 心理社會：父母(母親帶因)易有罪惡感與**過度保護**，要協助父母讓孩子適度獨立；手足也需要關心，可到病房探視；學校活動選擇不衝撞的項目，不是「積極參加所有活動」
- 遺傳諮詢：**帶因女性與正常男性**的孩子——兒子 1/2 罹病、女兒 1/2 帶因(見 [[genetic-inheritance#x-linked-recessive]])

## 類血友病 {#vwd}

- **最常見的遺傳性出血疾病**，多為體染色體顯性；vWF 不足或功能差 → 血小板無法黏附，第八因子也容易被分解
- 表現：**皮膚黏膜出血**(流鼻血、牙齦出血、月經過多、手術後出血)；**出血時間延長**，嚴重時 aPTT 延長
- 治療：輕型(第 1 型)用 **desmopressin(DDAVP)**；嚴重用含 vWF 的凝血因子濃縮製劑；tranexamic acid；避免 aspirin
- 遺傳見 [[single-gene-disorders#vwd]]

## 維生素 K 缺乏與新生兒出血 {#vitamin-k}

- 維生素 K 是 **II、VII、IX、X** 與蛋白質 C、S 活化的必要物質(見 [[blood-hemostasis#coagulation]])；缺乏時 **PT 先延長**
- 原因：**阻塞性黃疸**與脂肪吸收不良(脂溶性維生素)、長期廣效抗生素(殺死製造維生素 K 的腸道菌)、**warfarin**、肝病、新生兒
- **新生兒維生素 K 缺乏性出血**(舊稱新生兒出血性疾病)
   1. 原因：**維生素 K 不易通過胎盤**、出生時**腸道無菌**(還沒有製造維生素 K 的菌叢)、**肝臟不成熟**、**母乳**中維生素 K 少；腸道吸收能力**不是**原因
   2. 預防：出生後**肌肉注射維生素 K₁**(新生兒常規照護)
- 治療：維生素 K₁(phytonadione)；嚴重出血加新鮮冷凍血漿或凝血酶原複合物；warfarin 過量的處理見 [[anticoagulants#warfarin]]

## 瀰漫性血管內凝血(DIC) {#dic}

- 機轉：大量**組織因子(凝血活酶)**進入血液 → 全身微血管**廣泛凝血** → **消耗**血小板與凝血因子，同時纖溶亢進 → **既血栓又出血**(病理細節見 [[thrombosis-embolism-infarction#dic]])
- 誘因：**敗血症**(最常見)、**產科急症**(**胎盤早期剝離**、**羊水栓塞**、死胎滯留、子癇前症)、嚴重創傷與燒傷、**毒蛇咬傷**、溶血性輸血反應、急性前骨髓性白血病與轉移癌；**慢性淋巴性白血病不是常見誘因**
- 表現：抽血與注射處**滲血不止**、瘀點瘀斑、黏膜與腸胃道出血、血尿；微血栓造成肢端發紺、壞死、器官衰竭(腎、肺、腦)
- 檢驗

| 項目 | DIC |
|---|---|
| 血小板 | **下降** |
| PT、aPTT | **延長** |
| **纖維蛋白原** | **下降**(被消耗) |
| **FDP、D-dimer** | **上升** |
| 周邊血液抹片 | 破碎紅血球 |

- ISTH 明顯 DIC 計分：有潛在疾病時，依血小板、D-dimer／FDP、PT 延長、纖維蛋白原 < 1 g/L 計分，**≥ 5 分**為明顯 DIC，每天重算(Taylor 2001)
- 治療
   1. **優先治療原因**(控制敗血症、儘速娩出胎兒與胎盤)
   2. 補充：出血時依醫囑輸**血小板**、**新鮮冷凍血漿**、**冷凍沉澱品**(補纖維蛋白原)；**不是優先輸全血**(血品見 [[transfusion-reactions#products]])
   3. 以血栓為主的慢性 DIC 才考慮 heparin
- 護理
   1. 落實**出血預防措施**(見 [[#thrombocytopenia]])：**不用力解便**、不用力咳嗽擤鼻、電動刮鬍刀、軟毛牙刷、不用牙線
   2. 監測生命徵象、意識、尿量、出血量與部位、肢端循環
   3. 減少穿刺次數，穿刺後延長加壓
- 產後出血與胎盤早期剝離：產後要**預防大出血並持續觀察凝血機制**
