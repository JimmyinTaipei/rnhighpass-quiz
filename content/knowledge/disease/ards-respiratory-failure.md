**呼吸衰竭**是肺無法維持足夠的氧合或排出 CO₂；**急性呼吸窘迫症候群**(ARDS，Acute respiratory distress syndrome)是其中最嚴重、最典型的一種，因為肺微血管受傷、肺泡被富含蛋白質的液體淹沒。本頁也整理早產兒的**新生兒呼吸窘迫症候群**(機轉不同但名字相近)。血氣判讀見 [[abg]]，V/Q 與分流見 [[gas-exchange-transport#vq]]

## 重點摘要 {#summary}

- **低血氧型呼吸衰竭**：PaO₂(Partial pressure of arterial oxygen) < 60 mmHg(PaCO₂(Partial pressure of arterial carbon dioxide) 正常或偏低)；**高碳酸型**：PaCO₂ > 50 mmHg 且 pH 下降
- 評估氧合與通氣最準的是**動脈血氣**(SpO₂(Peripheral oxygen saturation) 看不到 CO₂)
- 早期：**躁動不安、意識混亂**、心跳與呼吸加快、血壓上升；晚期：發紺、心跳變慢、低血壓、昏迷
- **ARDS**：直接或間接傷害 → 肺泡微血管**通透性增加** → **非心因性肺水腫**、透明膜、第二型細胞受損 → 肺擴張不全、**分流** → **給氧也難改善的低血氧**
- 診斷(Berlin 2012)：1 週內發生、**雙側浸潤**、不能用心衰竭解釋、**PaO₂/FiO₂ ≤ 300**(PEEP(Positive end-expiratory pressure) ≥ 5)；2023 全球定義加入高流量鼻導管與 SpO₂/FiO₂
- 治療：處理原因；**肺保護性通氣**(潮氣容積 4–8 mL/kg 理想體重)；**PEEP 防止吐氣時肺泡塌陷**、增加功能肺餘量；嚴重者**俯臥**每天 12 小時以上
- **新生兒呼吸窘迫症候群**：早產、**表面張力素不足**；呼氣**咕嚕聲**、凹陷、**胸部 X 光毛玻璃樣**；血氣為**呼吸性(與代謝性)酸中毒**＋低血氧

### 國考常考點 {#exam-points}

- 評估急性呼吸衰竭的氧合與通氣：**動脈血液氣體分析**
- 慢性肺病早期呼吸衰竭：**焦躁不安及意識混亂**(不是低血壓、心跳過慢或發紺)
- ARDS 的病生理：**肺泡微血管膜通透性增加 → 肺水腫**；**不是心因性肺水腫**；吸入性肺炎也會引起
- ARDS 的舊診斷標準(1994 美歐共識)：急性發作、雙側浸潤、**P/F ≤ 200**、**肺微血管楔壓 ≤ 18 mmHg**
- ARDS 處置**錯誤**的是「用陽壓呼吸器**降低**功能肺餘量」(PEEP 是**增加** FRC(Functional residual capacity))
- PEEP 的目的：**避免吐氣時肺泡塌陷**、減少分流、改善氧合；不是避免纖維化或送 100% 氧
- ARDS 呼吸道清除：**咳嗽無效時抽痰**；每 2 小時翻身(不是 4 小時)；不是為了休息而給鎮靜
- 新生兒 RDS：呼氣有**咕嚕聲**、肺泡缺表面張力素而塌陷、X 光**毛玻璃樣**；**不會是呼吸性鹼中毒**
- 表面張力素過少 → 新生兒呼吸窘迫症候群；胎兒在子宮內**有**呼吸動作；表面張力素**不是 28 週才開始**製造
- 羊水 **L/S 比 ≥ 2** 表示胎兒肺成熟
- 早產兒 CPAP(Continuous positive airway pressure)：用在**有自發呼吸**者、壓力約 **4–7 cmH₂O**(8–12 太高)、增加功能肺餘量、防止**吐氣**時肺泡塌陷(說「吸氣時」是錯的)；仍窘迫要插管
- **Silverman-Anderson 計分**：評估早產兒呼吸困難，**滿分 10 分、分數越高越嚴重**；項目是**呼氣**咕嚕聲(不是吸氣)

## 呼吸衰竭 {#respiratory-failure}

| | **低血氧型**(第一型) | **高碳酸型**(第二型) |
|---|---|---|
| 血氣 | **PaO₂ < 60 mmHg**；PaCO₂ 正常或偏低 | **PaCO₂ > 50 mmHg**、pH < 7.35；常合併低血氧 |
| 問題 | 氧進不去：**分流**、V/Q 不配合、擴散障礙 | 氣換不出：**通氣不足** |
| 原因 | **ARDS**、肺炎、肺水腫、肺栓塞、肺擴張不全 | **COPD 惡化**、嚴重氣喘、**鴉片類與鎮靜劑**、神經肌肉疾病(重症肌無力、格林巴利、高位脊髓損傷)、胸壁外傷、肥胖 |
| 給氧效果 | 分流多時效果有限 | 有效，但要控制濃度(COPD 目標 SpO₂ 88–92%) |

切點為常用的臨床定義；PaO₂ 60 mmHg 約等於 SaO₂(Arterial oxygen saturation) 90%，見 [[abg#oxygenation]]

- **徵象**

| 時期 | 表現 |
|---|---|
| **早期** | **躁動不安**、焦慮、**意識混亂**、頭痛、心跳與呼吸加快、血壓上升、使用輔助肌 |
| 晚期 | 發紺、嗜睡到昏迷(CO₂ 麻醉)、**心跳變慢**、**低血壓**、心律不整、呼吸變慢或停止 |

- CO₂ 滯留時病人變得**嗜睡**是危險訊號(意識下降 → 通氣更差)，見 [[abg#respiratory-acidosis-care]]
- **評估**：動脈血氣最能同時看氧合與通氣；SpO₂ 只看氧合；呼吸型態、意識、輔助肌
- **處置**
   1. 維持呼吸道：抽痰、姿勢(半坐臥)
   2. 給氧：依類型與目標調整
   3. 通氣支持：**非侵襲性正壓呼吸器**(COPD 惡化、心因性肺水腫效果好)→ 不行則**插管與機械通氣**，見 [[mechanical-ventilation]]
   4. 處理原因：支氣管擴張劑、抗生素、利尿劑、拮抗鴉片類

## 急性呼吸窘迫症候群(ARDS) {#ards}

### 原因 {#ards-causes}

| 直接傷害肺 | 間接(全身性) |
|---|---|
| **肺炎**(最常見的直接原因)、**吸入胃內容物**、吸入煙霧或毒氣、**溺水**、肺挫傷 | **敗血症**(最常見)、嚴重創傷與休克、大量輸血(輸血相關急性肺損傷)、急性胰臟炎、燒傷 |

- 敗血症見 [[sepsis]]；輸血相關急性肺損傷見 [[transfusion-reactions]]

### 病理生理 {#ards-pathophysiology}

1. **滲出期**(約第 1 週)
   1. 發炎細胞(嗜中性球)與介質傷害**肺泡上皮與微血管內皮**
   2. **微血管通透性增加** → 富含蛋白質的液體滲進肺泡 → **非心因性肺水腫**
   3. 蛋白質與壞死細胞在肺泡壁形成**透明膜**
   4. **第二型肺泡細胞受損** → 表面張力素減少 → 肺泡塌陷(**肺擴張不全**)
2. 結果
   1. 大量肺泡沒有通氣但仍有血流 → **分流** → 給高濃度氧也難以改善的**頑固性低血氧**
   2. 肺變硬、**順應性下降** → 呼吸做功增加、淺快呼吸
   3. 低氧性肺血管收縮與微血栓 → 肺高壓
3. **增生期與纖維化期**：第二型細胞增生修補；部分病人留下**肺纖維化**

| | ARDS | 心因性肺水腫 |
|---|---|---|
| 機轉 | 微血管**通透性**增加 | 左心衰竭 → 肺微血管**靜水壓**上升 |
| 肺微血管楔壓 | 正常(≤ 18 mmHg) | 上升 |
| 水腫液 | 蛋白質多 | 蛋白質少 |
| 對利尿劑與強心治療 | 反應差 | 反應好 |

- 心因性肺水腫見 [[heart-failure#acute-hf]]；水腫機轉見 [[edema-shock#starling]]

::questions{ids="111-2_MS_058,112-1_BM_013,114-1_MS_033"}

### 診斷 {#ards-diagnosis}

| 定義 | 主要條件 |
|---|---|
| 美歐共識(1994，國考舊考點) | 急性發作；胸部 X 光**雙側浸潤**；**肺微血管楔壓 ≤ 18 mmHg**(排除左心衰竭)；**PaO₂/FiO₂ ≤ 200**(≤ 300 稱急性肺損傷) |
| **Berlin 定義(2012)** | 已知傷害後 **1 週內**；**雙側浸潤**；不能完全用心衰竭或輸液過量解釋；插管且 **PEEP ≥ 5 cmH₂O** 時 **PaO₂/FiO₂ ≤ 300**：輕度 201–300、中度 101–200、重度 ≤ 100；取消「急性肺損傷」與楔壓條件(來源：[JAMA 2012](https://doi.org/10.1001/jama.2012.5669)) |
| **全球定義(2023 共識)** | 保留 Berlin 條件，另外：用**高流量鼻導管 ≥ 30 L/min** 或非侵襲性呼吸器的病人也可診斷；可用 **SpO₂/FiO₂ ≤ 315**(SpO₂ ≤ 97% 時)取代血氣；**超音波**可取代 X 光(來源：[AJRCCM 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10870876)) |

- 例：FiO₂(Fraction of inspired oxygen) 0.5、PaO₂ 75 → P/F＝150 → 中度 ARDS
- 國考若問「肺微血管楔壓 ≤ 18」是舊定義的答案

::questions{ids="107-1_MS_051"}

### 治療 {#ards-treatment}

1. **處理原因**：敗血症的抗生素與輸液、引流感染源
2. **肺保護性通氣**(來源：[ATS/ESICM/SCCM 2017](https://doi.org/10.1164/rccm.201703-0548ST))
   1. **小潮氣容積**：4–8 mL/kg 理想體重
   2. 限制吸氣高原壓 < 30 cmH₂O，避免把肺撐破(氣壓傷)
   3. 允許 PaCO₂ 稍高(允許性高碳酸血症)
3. **PEEP**
   1. 吐氣末保持正壓 → **防止吐氣時肺泡塌陷**、**增加功能肺餘量**、減少分流、可降低需要的氧濃度
   2. 副作用：胸內壓上升 → **靜脈回流與心輸出量下降**、血壓下降；氣胸
4. **俯臥**：中重度 ARDS 每天俯臥 **12 小時以上**(同上指引)，讓背側塌陷的肺泡重新通氣；注意臉部與骨突處壓傷、管路滑脫
5. 輸液：休克處理後採**保守輸液**，避免肺水腫加重
6. 其他：鎮靜、必要時神經肌肉阻斷劑；最嚴重者葉克膜(ECMO)
7. 血色素不需要刻意維持在正常值；國考題中「用陽壓呼吸器降低功能肺餘量」是錯誤處置

::questions{ids="109-1_MS_053,111-1_MS_052"}

### 護理 {#ards-nursing}

1. 監測：SpO₂、動脈血氣、呼吸型態、意識、生命徵象；呼吸器壓力與潮氣容積
2. 呼吸道清除：**咳嗽無效時抽痰**；抽痰前後給氧、時間要短(PEEP 中斷會讓肺泡塌陷，密閉式抽痰較好)
3. **每 2 小時翻身**、依醫囑俯臥
4. 預防呼吸器相關肺炎(床頭抬高 30–45 度、口腔護理)
5. 輸液與出入量、體重；觀察 PEEP 造成的低血壓
6. 鎮靜與止痛依醫囑，目的是讓病人配合呼吸器，不是單純讓病人休息
7. 營養支持、預防壓傷與深部靜脈血栓；家屬支持

## 新生兒呼吸窘迫症候群 {#neonatal-rds}

- 早產兒照護的完整內容(保溫、餵食、其他早產併發症)在第 16 輪產科新生兒；這裡整理呼吸相關部分
- **原因**：**早產** → 第二型肺泡細胞不成熟、**表面張力素不足** → 肺泡塌陷；越早產越常見(26–28 週出生約一半會發生，來源：OpenStax Anatomy and Physiology 2e，22.7)
- 胎兒肺發育：約 20 週開始少量分泌表面張力素，到約第 8 個月才足夠；胎兒在子宮內就有呼吸動作，見 [[respiratory-anatomy#fetal-lung]]
- **其他危險因子**：母親糖尿病、剖腹產(未經產程)、男嬰、窒息
- **評估胎肺成熟**：羊水**卵磷脂／抱合髓磷脂(L/S)比 ≥ 2** 表示肺成熟(經典判讀，國考常考)
- **表現**(出生後數小時內出現並加重)
   1. 呼吸急促、**呼氣咕嚕聲**(聲門半關閉，想保住肺泡內的氣)
   2. **鼻翼搧動**、**胸骨與肋間凹陷**、發紺
   3. 胸部 X 光：**毛玻璃樣**、支氣管充氣像、肺容積小
   4. 血氣：**低血氧、高碳酸血症(呼吸性酸中毒)**，加上缺氧造成的代謝性酸中毒；**不是呼吸性鹼中毒**
- **Silverman-Anderson 計分**：上胸與腹部起伏是否同步、肋間凹陷、劍突下凹陷、鼻翼搧動、**呼氣咕嚕聲**，每項 0–2 分，**總分 0–10，越高越嚴重**
- **預防與治療**
   1. 預期早產時，**產前給母親類固醇**促進胎肺成熟
   2. **CPAP**(持續性氣道正壓)：用於**有自發呼吸**的早產兒；國考答案壓力約 **4–7 cmH₂O**；作用是**增加功能肺餘量、防止吐氣時肺泡塌陷**
   3. 仍然窘迫 → **插管**、呼吸器、經氣管內管給**外源性表面張力素**
   4. 給氧時監測血氧，避免高濃度氧造成早產兒視網膜病變與慢性肺病；氧氣頭罩的流量見 [[oxygen-therapy#devices]]
   5. 保溫、減少刺激、維持體液與營養
