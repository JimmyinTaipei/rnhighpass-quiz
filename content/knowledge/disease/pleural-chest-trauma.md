**肋膜腔**是臟層與壁層胸膜之間的潛在空間，平常只有少量潤滑液、維持**負壓**，讓肺貼著胸壁擴張（解剖見 [[respiratory-anatomy#pleura]]，壓力見 [[ventilation-mechanics#pressures]]）。液體、膿、空氣或血跑進來，肺就被壓扁、撐不開。本頁整理肋膜疾病與胸部外傷；胸管與水下引流的照護見 [[chest-tube]]

## 重點摘要 {#summary}

- 肋膜腔進液體＝**肋膜積水**、進膿＝**膿胸**、進空氣＝**氣胸**、進血＝**血胸**；都會讓**患側呼吸音減弱或消失**、胸廓起伏變小
- 叩診分辨：**積水、血胸 → 濁音**；**氣胸 → 過度反響音**
- 積水分**漏出液**（心衰竭、肝硬化、腎病）與**滲出液**（感染、癌症、肺栓塞）；感染造成的是滲出液
- **自發性氣胸**：肺尖的**小氣泡破裂**；年輕瘦高男性、吸菸、肺氣腫
- **張力性氣胸**：空氣只進不出 → 縱膈腔與**氣管偏向健側**、頸靜脈怒張、低血壓 → **立即針刺減壓**，再放胸管
- **肋骨骨折**：吸氣時痛 → **淺快呼吸** → 肺擴張不全、肺炎；重點是**止痛**、深呼吸與咳嗽，不再用胸帶綁緊
- **連枷胸**：相鄰數根肋骨各斷兩處以上 → **反常（奇異性）呼吸**：吸氣**內陷**、呼氣**外凸**；常合併肺挫傷

### 國考常考點 {#exam-points}

- 左側氣胸患側評估：**呼吸音消失**（不是濁音、不是觸覺語顫增加、不是濕囉音）
- 自發性氣胸身體評估：吸氣時兩側不對稱、**觸覺語顫減弱**、叩診**過度反響音**；**橫膈移動度變小**（說「變大」是錯的）
- 打籃球突然單側胸痛、患側起伏小、**氣管偏向對側**、呼吸音減弱、**過度反響音** → **氣胸**
- 車禍後**一側聽不到呼吸音或減弱** → 懷疑氣胸；一側叩診濁音比較像血胸或積水
- **張力性氣胸**：**單側呼吸音減弱**；車禍後右側聽不到呼吸音、氣管偏左 → **準備胸部針刺減壓**
- 肺氣腫病人的自發性氣胸：**肺尖氣泡破裂**
- 氣胸放胸管的目的：**移除肋膜腔中的氣體**
- 右下肺叩診濁音、呼吸音減弱、X 光**肋膜橫膈角變鈍** → **右側肋膜積水**
- 感染造成的肋膜積水多是**滲出液**；急性期**氣喘**不會造成肋膜積液（心衰竭、肺栓塞、肋膜炎會）
- **膿胸**病變在**肋膜腔**；**間皮瘤**好發在**肋膜**
- 胸腔穿刺姿勢、術後合併症與放液量見 [[respiratory-assessment#thoracentesis]]
- 肋骨骨折：**淺呼吸、吸氣時更痛**
- **連枷胸**：造成**奇異性呼吸**；連枷段是**吸氣內陷、呼氣外凸**（題目寫相反是錯的）；治療著重**肺部再擴張**；不是「胸腔肌肉創傷」、不是深慢呼吸
- 會出現奇異性呼吸的是**連枷胸**（不是張力性氣胸、呼吸衰竭）
- 胸壁鈍傷後**呼吸音降低** → 可能**肺挫傷**；「受傷部位有吸吮聲」是開放性氣胸
- 肋骨骨折合併氣血胸、有心衰竭病史：**不宜給全血**（加重心臟負荷）；止痛、給氧、高蛋白食物是適當的

## 肋膜炎 {#pleurisy}

1. 原因：肺炎、結核、病毒感染、肺栓塞、紅斑性狼瘡等自體免疫疾病、癌症
2. 表現
   1. **尖銳胸痛**：深吸氣、咳嗽時加重，局限在一側
   2. **肋膜摩擦音**：吸氣與呼氣都聽得到、**咳嗽後不會消失**，見 [[respiratory-assessment#adventitious]]
   3. 為了減痛，呼吸**淺快**；積水變多後疼痛反而減輕、摩擦音消失
3. 護理
   1. 治療原因、止痛(NSAID)
   2. **側躺向患側**或用枕頭支撐患側胸壁，減少胸壁活動
   3. 咳嗽時按住胸壁；深呼吸、誘發性肺量計預防肺擴張不全

## 肋膜積水 {#effusion}

1. 定義：肋膜腔液體增加；常見原因**心衰竭**（最常見）、肺炎、癌症、肺栓塞
2. 漏出液與滲出液

| | 漏出液 | 滲出液 |
|---|---|---|
| 機轉 | 靜水壓上升或膠體滲透壓下降，肋膜本身正常 | 肋膜**發炎或癌症**，微血管通透性增加 |
| 常見原因 | **心衰竭**、肝硬化、腎病症候群、低白蛋白 | **肺炎（肺炎旁積液）**、結核、**癌症**、肺栓塞、紅斑性狼瘡、胰臟炎 |
| 外觀與內容 | 清澈淡黃、蛋白質與 LDH 低 | 混濁、蛋白質與 LDH 高、細胞多 |

- 判別用 **Light 準則**：符合任一項就是滲出液
   1. 肋膜液蛋白質／血清蛋白質 > 0.5
   2. 肋膜液 LDH／血清 LDH > 0.6
   3. 肋膜液 LDH > 血清 LDH 正常上限的 2/3
   4. 來源：Light RW 等，Ann Intern Med 1972;77:507–513
- 漏出液與滲出液的發炎機轉見 [[inflammation-repair]]

3. 表現：呼吸困難（量多時）、乾咳、胸悶；患側**呼吸音減弱**、**叩診濁音**、**觸覺語顫減弱**；大量時氣管推向**健側**
4. 檢查：胸部 X 光**肋膜橫膈角變鈍**；超音波定位；**胸腔穿刺**抽液檢查
5. 治療
   1. 治療原因（心衰竭用利尿劑、肺炎用抗生素）
   2. 量多、症狀明顯：**胸腔穿刺**放液或放**胸管**引流
   3. 反覆發生的惡性肋膜積水：**肋膜沾黏術**（把藥打進肋膜腔讓兩層黏在一起）或長期留置肋膜導管
6. 護理：半坐臥或坐起趴在床旁桌、給氧、監測呼吸；穿刺護理見 [[respiratory-assessment#thoracentesis]]

## 膿胸 {#empyema}

1. 定義：**肋膜腔**裡有膿；多由**肺炎**、肺膿瘍擴散，或胸部手術、外傷後感染
2. 表現：發燒、胸痛、呼吸困難、咳嗽、食慾差、體重減輕；患側呼吸音減弱、叩診濁音
3. 治療
   1. **抗生素**＋**胸管引流**；BTS 2023 建議先用**小管徑胸管**引流
   2. 引流不好：肋膜腔注入纖維蛋白溶解劑，或手術（胸腔鏡清創、**肋膜剝離術**）
   3. 來源：[BTS Pleural Disease Guideline 2023 摘要](https://pmc.ncbi.nlm.nih.gov/articles/PMC11037506/)
4. 護理：深呼吸、咳嗽、早期下床、營養；觀察引流液性狀與量、發燒曲線

## 氣胸 {#pneumothorax}

::figure{src="/knowledge-images/servier-pneumothorax.svg" labels="pneumothorax" alt="左為正常的肺貼著胸壁；右為病人左側氣胸，肋膜腔充滿空氣(藍色)，左肺塌陷縮小"}

1. 機轉：空氣進入肋膜腔 → 肋膜腔負壓消失 → **跨肺壓下降**、肺塌陷，見 [[ventilation-mechanics#pressures]]
2. 分類

| 類型 | 原因 | 重點 |
|---|---|---|
| **原發性自發性** | 肺尖的**小氣泡(bleb)破裂**，沒有肺病 | **年輕、瘦高男性**、吸菸 |
| **續發性自發性** | 原本有肺病：**肺氣腫**（肺大泡破裂）、肺結核、囊性纖維化 | 肺功能差，症狀較重 |
| **外傷性** | 肋骨骨折刺破肺、穿刺傷 | 常合併血胸（**氣血胸**） |
| **醫源性** | 中心靜脈導管、胸腔穿刺、支氣管鏡切片、**正壓呼吸器**（氣壓傷） | 處置後突然喘、SpO₂(Peripheral oxygen saturation) 下降要想到 |
| **開放性** | 胸壁有開口，吸氣時空氣從傷口吸入 | 傷口有**吸吮聲**（吸吮性胸部傷口） |
| **張力性** | 空氣只進不出（**單向活瓣**） | 縱膈腔推向健側、休克；**最緊急** |

3. 表現
   1. **突然**單側**尖銳胸痛**、呼吸困難、呼吸快、心跳快
   2. 患側：**胸廓起伏變小**、**觸覺語顫減弱**、叩診**過度反響音**、**呼吸音減弱或消失**、橫膈移動度變小
   3. 量大時氣管偏向**健側**
   4. 皮下氣腫：皮膚按壓有**捻髮音**
4. 檢查：胸部 X 光（肺邊緣與胸壁之間沒有肺紋路）；超音波看不到肺滑動；躺著拍的片子前側氣胸容易漏看(ICU Book 5e)
5. 治療：依症狀與大小，不是一律放胸管
   1. 沒症狀或輕微：**觀察**、給氧、追蹤 X 光
   2. 有症狀：**針頭抽氣**或放**小管徑胸管**；BTS 2023 也接受原發性自發性氣胸病人在有支持與追蹤時採門診處理
   3. 反覆發生或持續漏氣：胸腔鏡手術切除肺泡、**肋膜沾黏術**
   4. 來源：[BTS Pleural Disease Guideline 2023 摘要](https://pmc.ncbi.nlm.nih.gov/articles/PMC11037506/)
6. 衛教：戒菸；復發風險高，突然胸痛、喘要就醫；氣胸未治好前不要搭飛機、潛水（以醫師指示為準）

### 開放性氣胸 {#open-pneumothorax}

1. 胸壁穿刺傷，吸氣時空氣經傷口進入肋膜腔，可聽到**吸吮聲**
2. 急救：用**無菌、不透氣的敷料**蓋住傷口，**只貼三邊**（留一邊讓空氣排出），或用有排氣閥的胸部封口敷料；完全密封可能變成張力性氣胸
3. 之後放胸管、手術修補
4. 胸部刺入的物品**不要拔出**，固定後送醫

### 張力性氣胸 {#tension-pneumothorax}

![單純氣胸與張力性氣胸的比較：張力性氣胸時患側肋膜腔空氣越積越多，把縱膈腔、心臟與氣管推向健側](/knowledge-images/tension-pneumothorax.svg)

1. 機轉：破口像**單向活瓣**，吸氣時空氣進入、吐氣出不去 → 患側壓力越來越高 → 縱膈腔推向健側、壓迫大靜脈 → **靜脈回流減少、心輸出量下降**（阻塞性休克）
2. 常見情境：**胸部外傷**、**使用正壓呼吸器**的病人、開放性氣胸蓋得太密
3. 表現
   1. 嚴重呼吸困難、躁動、發紺、SpO₂ 快速下降
   2. **氣管偏向健側**、患側呼吸音消失、過度反響音
   3. **頸靜脈怒張**、**低血壓**、心跳快 → 可能心跳停止
   4. 呼吸器病人：**氣道壓力突然升高**（高壓警報）、低血壓
4. 處置：**臨床診斷就處理，不等 X 光**
   1. 立即**針刺減壓**，再放**胸管**
   2. 穿刺位置
      1. 傳統與國考書：患側**第 2 肋間、鎖骨中線**
      2. 新做法：成人改在**第 5 肋間、腋中線稍前方**，用 8 cm 長的 14 號針；胸壁較薄、失敗率較低（ICU Book 5e，Ch28）
      3. 實際位置依醫師與院內規範
   3. 給高濃度氧氣、準備急救

## 血胸 {#hemothorax}

1. 原因：**胸部外傷**（肋骨骨折、穿刺傷）最常見；胸腔手術後、抗凝血劑、腫瘤
2. 表現：呼吸困難、患側**叩診濁音**、呼吸音減弱；出血多時**低血容性休克**（心跳快、血壓低、皮膚濕冷）
3. 治療：放**胸管**引流並記錄出血量；輸血、輸液
4. 大量血胸可能要開胸止血：放胸管時立即引流約 **1,500 mL**，或之後持續每小時約 **200 mL** 達數小時（時間各來源寫 2–4 小時不一；來源：[MSD Manual 專業版 血胸](https://www.msdmanuals.com/de/profi/verletzungen-vergiftungen/thoraxtrauma/hämatothorax)）
5. 空氣與血同時存在＝**氣血胸**

## 肋骨骨折 {#rib-fracture}

1. 最常見的胸部外傷；中段肋骨最常斷
2. 特別注意
   1. **第 1、2 肋骨**骨折：需要很大的力量，可能合併大血管、臂神經叢損傷
   2. **下段肋骨**（第 9–12）骨折：可能合併**肝、脾、腎**損傷
3. 表現：受傷處疼痛、壓痛，**吸氣、咳嗽時更痛** → 不敢深呼吸，**呼吸淺快**；摸到骨擦音
4. 合併症：**肺擴張不全**、**肺炎**（老人風險最高）、氣胸、血胸、肺挫傷
5. 治療與護理
   1. **止痛**最重要：口服或注射止痛藥、病人自控式止痛、硬膜外止痛、肋間神經阻斷，見 [[pain-management]]
   2. 止痛後鼓勵**深呼吸**、**誘發性肺量計**、按住胸壁**有效咳嗽**、早期下床
   3. **不用胸帶或膠布環繞固定胸部**：會限制胸廓擴張，增加肺擴張不全與肺炎
   4. 半坐臥；評估呼吸音、SpO₂、疼痛分數，止痛後要再評值
6. 合併心衰竭病史時：輸液、輸血要小心容積負荷，見 [[heart-failure]]

## 連枷胸 {#flail-chest}

![連枷胸的反常呼吸：吸氣時胸壁往外擴、連枷段被吸進去；呼氣時胸壁往內縮、連枷段被推出來](/knowledge-images/flail-chest.svg)

1. 定義：**相鄰數根肋骨各斷兩處以上**（或合併胸骨骨折），形成一塊和胸壁失去連結的「連枷段」
2. **反常（奇異性）呼吸**
   1. **吸氣**：胸腔負壓變大，連枷段被**吸進去（內陷）**
   2. **呼氣**：胸腔壓力上升，連枷段被**推出來（外凸）**
   3. 方向和其他胸壁相反 → 患側肺擴張不好、換氣變差
3. 表現：胸壁不對稱、反常移動、劇烈疼痛、**淺快呼吸**、呼吸困難、發紺
4. 低血氧的主因常是底下的**肺挫傷**，不只是胸壁不穩
5. 治療：重點是讓**肺部再擴張**、維持換氣
   1. **止痛**、給氧、肺部清潔
   2. 換氣不足：插管與**正壓呼吸器**（從裡面把胸壁撐起來，稱內固定）
   3. 必要時手術固定肋骨
6. 護理：監測呼吸型態、SpO₂、動脈血氣；半坐臥；止痛後深呼吸與咳嗽；小心輸液避免加重肺挫傷

::questions{ids="106-1_MS_055,108-1_MS_053,109-2_MS_059"}

## 肺挫傷 {#pulmonary-contusion}

1. 胸壁鈍傷造成肺組織瘀血、出血、水腫；常和肋骨骨折、連枷胸一起出現
2. 表現：**呼吸音降低**、爆裂音、呼吸困難、低血氧、咳血；受傷後**一兩天內**可能越來越嚴重
3. 治療：給氧、止痛、肺部清潔；**避免輸液過量**；嚴重時用呼吸器；可能進展成 ARDS，見 [[ards-respiratory-failure#ards]]
