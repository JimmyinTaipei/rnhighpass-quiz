退化性關節炎是最常見的關節炎，常見於老人與負重關節；痛風是尿酸鈉結晶沉積造成的急性發炎性關節炎；兩者嚴重時都可能需要人工關節。本頁整理退化性關節炎、痛風、全髖與全膝關節置換、關節鏡、骨科身體檢查、腕隧道症候群與背架；滑液關節構造見 [[skeletal-system#synovial]]，類風濕性關節炎見 [[rheumatoid-arthritis]]，降尿酸藥物見 [[gout-drugs]]，痛風與骨鬆的社區衛教見 [[older-adult-chronic-disease#lifestyle]]

## 重點摘要 {#summary}

- **退化性關節炎**：**關節軟骨**退化磨損 → 軟骨下骨硬化、**骨贅**、關節間隙變窄；**局部、非發炎性**，不影響其他系統
- 危險因子：**年齡、肥胖、關節受傷或重複使用、停經後婦女**、家族史；長期類固醇是骨鬆與股骨頭壞死的危險因子，不是 OA
- 表現：**活動後痛、休息緩解**；**晨僵 < 30 分鐘**、活動幾分鐘就改善；**輾軋音**；**負重關節**（膝、髖、腰椎）與**遠端指間**（**Heberden 結節**）
- X 光：**骨贅、關節間隙變窄**；血液 ESR、CRP、RF 正常，關節液清澈
- 治療護理：**減重、運動**（**游泳、水中運動、騎腳踏車、走路、太極**；不慢跑跳躍）、熱敷、手杖（健側拿）、止痛藥（acetaminophen、NSAID）；末期**人工關節**
- **痛風**：高尿酸 → **尿酸鈉結晶**沉積關節；**男性、遠端小關節**（大腳趾）；可併**痛風石、腎結石、腎病變**；急性期休息、抬高、**冰敷**，少吃**內臟、海鮮、肉汁、啤酒**，**多喝水**
- **全髖置換術後防脫位**：髖**屈曲 < 90 度**、**不交叉腿、不內收**、**不內旋**；兩腿間**外展枕**；坐**高而硬、有扶手**的椅子、加高馬桶、長柄取物器；6 週內不開車、不性交
- 脫位徵象：**疼痛突然加劇、患肢縮短、內外旋、活動受限**
- 全膝置換：**CPM**每天增加 5–10 度、可抬高患肢；注意深部靜脈血栓、腓神經麻痺
- 檢查：**Thomas**＝髖屈曲攣縮；**McMurray**＝半月板；**抽屜／Lachman**＝十字韌帶；**Bulge**＝少量積液、**Ballottement**＝大量積液；**Phalen、Tinel**＝腕隧道症候群（正中神經）

### 國考常考點 {#exam-points}

- 清晨膝僵、**熱敷可改善**、上下樓梯有**輾軋音**的 60 歲女性 → **退化性關節炎**
- OA 適合**等張運動**（騎腳踏車、游泳）；**不適合慢跑**、跑步、深蹲；Plaquenil 是 RA 藥、避免高普林是痛風
- OA 的表現：40 歲男性 **X 光關節間隙減少與骨贅**；尺側偏斜、天鵝頸、對稱性、發燒倦怠體重減輕都是 **RA**
- **Heberden 結節**是 OA（遠端指間）；**膝關節不會形成 Heberden 結節**；尺側偏斜、Felty 症候群是 RA
- OA **不影響其他系統**；乾燥症、血管炎、發燒貧血是 RA 或其他自體免疫病
- OA 危險因子：**肥胖、重複受傷、停經後婦女**；**長期類固醇不是**
- OA 疼痛**活動後加劇、休息減輕**；RA 是不活動後（早晨）僵硬
- 關節僵硬時**不要整天站立**；早上溫水澡、手杖分擔髖與背部壓力是對的
- 骨性關節炎的診斷檢查：**X 光骨贅與關節腔變窄**；ANA、CRP 上升、滑液混濁不是
- 痛風：**男性四肢遠端關節**、可能**腎臟病變**；不是生育年齡女性、不是近端大關節；高尿酸者**大部分不會**發作痛風
- 痛風照護：**減少肉類、海鮮、啤酒**；不服水楊酸（aspirin 會影響尿酸排泄）；急性期可冰敷
- 全髖置換：**外展、中立**，**不外旋也不內旋**；**不可以「保持外旋、避免外展」**
- 翻身時兩腿間夾**外展枕**（「內展枕」是錯的）；翻向健側也要夾枕
- **用骨泥**的人工關節**術後 1–2 天**就可下床，「1 星期後才下床」錯；**未用骨泥**者國考答 **6 週後才負重**
- 全髖置換最常見原因是**退化性關節炎**（不是骨折）；最常見的長期合併症是**無菌性鬆脫**
- 「屈曲髖關節**不可小於** 90 度」是錯的，應是**不可大於** 90 度
- 置換術後脫位表現**不包括活動度增加**（會受限）
- 全膝置換術後**可以抬高下肢**；CPM 刺激軟骨癒合、每天增加 5–10 度；合併症有深部靜脈血栓、**腓神經麻痺**
- 關節鏡檢查後**不能立即恢復日常活動**，要休息、觀察血腫、神經血管、感染
- Thomas 試驗陽性表示**對側**（抬離床面那側）髖關節屈曲攣縮
- McMurray 評估**半月板**（不是前十字韌帶）；Tinel 不是膝的檢查
- 可完成全關節活動但**無法對抗阻力** → 肌力 **3 分**
- 膝關節**少量**積液 → **膨出徵象**；大量 → 浮動試驗
- 腕隧道症候群：**正中神經**受壓；**女性**、30–60 歲多；**Phalen**（手背相貼、腕屈曲 60 秒手指麻）、Tinel 陽性
- 背架：先在床上穿好再下床、內層穿薄衣保護皮膚、避免軟深沙發；**不可穿著背架洗澡**

## 退化性關節炎 {#osteoarthritis}

### 病理 {#pathophysiology}

1. **關節軟骨**含水量與蛋白多醣減少 → 變薄、龜裂、磨損
2. 軟骨下骨受力增加 → **硬化**、囊腫
3. 關節邊緣**骨贅（骨刺）**增生；剝落碎片使滑膜輕度發炎、少量積液
4. **關節間隙變窄** → 變形、活動受限
- 原發性：與老化、遺傳有關；續發性：受傷、先天髖關節異常、肥胖、感染、痛風等之後

### 危險因子 {#risk-factors}

| 有關 | 說明 |
|---|---|
| **年齡** | 最重要；多在 40 歲後出現症狀 |
| **肥胖** | 膝關節負荷大增；BMI 35 屬高危險 |
| **關節受傷、反覆使用** | 半月板或十字韌帶傷、職業性跪蹲 |
| **停經後婦女** | 雌激素下降，女性膝與手 OA 較多 |
| 遺傳、先天髖關節發育不良 | |
| ~~長期類固醇~~ | 是**骨質疏鬆**、**股骨頭缺血性壞死**的危險因子，不是 OA |

### 臨床表現 {#clinical}

- 疼痛：**活動、負重後加劇，休息後緩解**；晚期休息也痛
- **晨僵 < 30 分鐘**，活動幾分鐘就鬆開；久坐後起身僵硬
- **輾軋音**（骨擦音）、關節腫大（骨性）、活動度下降、變形（膝內翻 O 型腿）
- 好發：**膝**、**髖**、腰頸椎、**遠端指間關節**（**Heberden 結節**）、近端指間（Bouchard 結節）、拇指腕掌關節
- **不影響其他系統**：沒有發燒、倦怠、貧血、體重減輕（這些是 RA）
- 診斷：**X 光**看到**關節間隙不對稱變窄、骨贅、軟骨下硬化**；ESR、CRP、RF 正常；關節液清澈、黏稠

| | **退化性關節炎(OA)** | **類風濕性關節炎(RA)** |
|---|---|---|
| 本質 | 軟骨退化，**局部非發炎** | 自體免疫**滑膜炎**，全身性 |
| 年齡 | 中老年 | 30–50 歲女性 |
| 分布 | **不對稱**、負重關節、**遠端指間** | **對稱**、小關節、**近端指間與掌指** |
| 晨僵 | **< 30 分鐘** | **> 1 小時** |
| 疼痛 | 活動後加重 | 休息、早晨較重 |
| 手部 | **Heberden** 結節 | **尺側偏斜**、天鵝頸、鈕釦孔 |
| 全身症狀 | 無 | 倦怠、發燒、貧血、類風濕結節 |
| 檢驗 | 正常 | RF、anti-CCP、ESR、CRP 上升 |

### 治療與護理 {#oa-nursing}

1. **減重**：減輕膝髖負擔，最有效的非藥物治療之一
2. **運動**（2019 ACR／Arthritis Foundation 強烈建議）
   1. **低衝擊有氧**：**游泳、水中有氧、騎腳踏車、走路**、**太極**
   2. 股四頭肌**等長、等張**肌力訓練，穩定膝關節
   3. **避免**慢跑、跳躍、爬山、深蹲、跪坐、長時間站立
3. **熱敷**、早晨溫水浴減輕僵硬；急性腫痛可短暫冰敷
4. **輔具**：**手杖拿在健側**，分擔髖、膝與背部的壓力（見 [[activity-immobility#cane-walker]]）；護膝、鞋墊
5. **動靜平衡**：活動與休息交替，**關節僵硬時不要整天站立**
6. 藥物：**acetaminophen**、**外用或口服 NSAID**（注意腸胃與腎，見 [[nsaids-acetaminophen]]）、關節內類固醇注射；2019 ACR **強烈反對** glucosamine、chondroitin
7. 手術：關節鏡清創、截骨矯正、**人工關節置換**

## 痛風 {#gout}

- 機轉：**高尿酸血症**（普林代謝產物，製造過多或腎排泄減少） → **尿酸鈉結晶**沉積在關節與周圍組織 → 嗜中性球吞噬 → 急性發炎
- 高尿酸血症的人**大部分不會**發作痛風
- 好發：**男性**（停經前女性少）、**四肢遠端關節**，**大腳趾第一蹠趾關節**最典型；夜間突然紅腫熱劇痛
- 誘因：**飲酒（尤其啤酒）**、**高普林飲食**（內臟、海鮮、肉汁、濃湯）、脫水、手術、利尿劑、低劑量 aspirin
- 慢性：**痛風石**（耳殼、手肘、關節）、關節變形、**尿酸腎結石**與**腎病變**
- 診斷：關節液看到**負雙折射針狀尿酸鈉結晶**；急性期血尿酸可能正常

| 時期 | 處理 | 護理 |
|---|---|---|
| **急性發作** | colchicine、NSAID、類固醇；**不在急性期開始降尿酸藥** | **休息、抬高、冰敷**；床架撐起被單；**不用 aspirin** |
| 間歇期與慢性 | **降尿酸藥**：allopurinol（第一線，**漢人先驗 HLA-B*5801**）、febuxostat、benzbromarone；目標血尿酸 **< 6 mg/dL**(2020 ACR) | 開始降尿酸時同時預防性用抗發炎藥 3–6 個月 |

- 衛教
   1. **減少內臟、海鮮、肉類、肉汁、啤酒與烈酒**、含糖飲料
   2. **多喝水**（每天 2000 mL 以上，有腎病依醫囑），預防尿酸結石
   3. 控制體重（不要激烈節食，會升高尿酸）
   4. 低脂乳製品可降低風險
   5. 社區衛教（高普林蔬菜如豆苗、蘑菇）見 [[older-adult-chronic-disease#lifestyle]]
- 藥物細節見 [[gout-drugs]]

## 人工關節置換 {#arthroplasty}

### 全髖關節置換術 {#tha}

- 適應症：最常見是**退化性關節炎**；其次股骨頸骨折、股骨頭缺血性壞死、RA
- 固定方式
   1. **骨泥固定**：穩定快，**術後 1–2 天即可下床**、依耐受負重；多用於老人、骨質差
   2. **非骨泥固定**（骨頭長入假體）：國考答**約 6 週後才完全負重**；現代植入物多可依醫囑早期部分負重（**待核對**）

#### 防脫位（後側入路） {#hip-precautions}

| 要 | 不要 |
|---|---|
| 平躺時患肢**外展、中立**（腳尖朝上），兩腿間放**外展枕** | **內收**：兩腿交叉、蹺腳、側躺時上腿往前跨 |
| **翻身**時兩腿間**夾枕頭**，可翻向健側 | **內旋**：腳尖向內、從患側扭身 |
| 坐**高而硬、有扶手、椅背直**的椅子；**加高馬桶座** | **髖屈曲 > 90 度**：坐矮椅或軟深沙發、彎腰撿東西、蹲、盤腿 |
| 用**長柄取物器、穿鞋襪輔具**或請人協助 | 6 週內**開車、性交**（依醫囑） |
| 上樓**健側先上**、下樓**患側先下**（好上壞下） | 提重物、跑、跳 |

- 實證提醒：2020、2023 系統回顧發現後側入路術後有沒有這些限制，**脫位率沒有明顯差異**（約 2.2% vs 2.0%），前側入路多不設限；國考與多數醫院仍照上表，**依醫囑**

#### 合併症 {#tha-complications}

- **脫位**：多在術後早期；**疼痛突然加劇、患肢縮短、內旋或外旋、活動受限**（活動度**不會增加**） → 立即通知
- **深部靜脈血栓、肺栓塞**：等長運動、踝幫浦運動、彈性襪、抗凝、早期下床
- **感染**：早期傷口感染或晚期血行感染；拔牙等侵入性處置前告知醫師
- **無菌性鬆脫**：**最常見的長期合併症**（假體磨損、骨質流失）
- 腓神經損傷、肢體長短不一、異位性骨化

### 全膝關節置換術 {#tka}

- 術後**可抬高患肢**減輕腫脹（膝下不墊枕，避免屈曲攣縮）
- **持續被動運動機（Continuous passive motion，CPM）**：術後 1–2 天開始，依耐受**每天增加 5–10 度**，促進關節活動與軟骨癒合；目標約屈曲 90 度以上
- 股四頭肌等長運動、直膝抬腿；冰敷止痛
- 合併症：**深部靜脈血栓**、**腓神經麻痺**（足背屈無力、小腿外側麻）、感染、膝僵硬

::questions{ids="107-1_MS_019,114-2_MS_012,115-1_FA_005"}

## 關節鏡檢查 {#arthroscopy}

- 用內視鏡進入關節腔檢查或手術（半月板修補、清創、韌帶重建）；局部或脊椎麻醉
- 術後
   1. 加壓包紮、**抬高、冰敷**
   2. 觀察**關節血腫**、遠端**神經血管**、**發燒與傷口紅腫**
   3. **不能因為不痛就立刻恢復日常活動**，依醫囑漸進活動，24 小時內避免過度使用

::questions{ids="112-2_MS_020"}

## 骨科身體檢查 {#physical-exam}

| 檢查 | 做法 | 陽性代表 |
|---|---|---|
| **Thomas 試驗** | 平躺，一側膝抱向胸口 | **對側**大腿抬離床面 → 對側**髖屈曲攣縮** |
| **McMurray 試驗** | 屈膝，旋轉小腿並伸直 | 喀聲或痛 → **半月板損傷** |
| **抽屜試驗** | 屈膝 90 度，小腿往前或往後拉 | 往前移位過多 → **前十字韌帶**；往後 → 後十字韌帶 |
| **Lachman 試驗** | 屈膝 20–30 度往前拉脛骨 | **前十字韌帶**損傷（較敏感） |
| **膨出徵象(Bulge sign)** | 由下往上推擠膝內側液體，再輕壓外側 | 內側鼓起 → **少量積液** |
| **浮動試驗(Ballottement)** | 壓擠髕上囊後下壓髕骨 | 髕骨浮動回彈 → **大量積液** |
| **Phalen 試驗** | **兩手背相貼、腕屈曲 60 秒** | 手指麻木刺痛 → **腕隧道症候群** |
| **Tinel 徵象** | **敲擊**腕部掌側正中神經 | 刺痛放射到手指 → **腕隧道症候群**（也用於其他神經壓迫） |
| Homan 徵象 | 足背屈 | 小腿痛 → 深部靜脈血栓（見 [[anticoagulants#dvt-assessment]]） |

- **肌力 0–5 分**：0 無收縮、1 只有收縮、2 去除重力可動、**3 可抗重力但不能抗阻力**、4 可抗部分阻力、5 正常（見 [[activity-immobility#muscle-strength]]）
- 步態、關節活動度、肢體長度與周徑也是評估重點

::questions{ids="114-1_MS_012,108-1_MS_018,106-1_MS_019,105-1_MS_022,106-2_makeup_MS_018"}

## 腕隧道症候群 {#carpal-tunnel}

- **正中神經**在腕隧道（腕骨與屈肌支持帶之間）受壓
- 危險因子：**女性**（30–60 歲）、**重複手腕動作**（電腦、家務）、懷孕、甲狀腺功能低下、糖尿病、RA、肥胖
- 症狀：**拇指、食指、中指與無名指橈側**麻木刺痛，**夜間加重**、甩手可緩解；晚期**魚際肌萎縮**、拇指對掌無力、抓握掉東西
- 檢查：**Phalen**、**Tinel** 陽性；神經傳導檢查
- 治療：**腕部副木固定在中立位**（夜間）、避免重複動作、NSAID、局部類固醇注射；無效則**腕隧道鬆解術**
- 術後：抬高、觀察手指循環與感覺、漸進手指運動

::questions{ids="112-1_MS_019,111-1_MS_018,110-1_MS_021"}

## 下背痛與背架 {#back-brace}

- 下背痛與腰椎間盤突出的機轉、症狀與手術護理見 [[cranial-nerve-spine-disorders#herniated-disc]]；骨盆牽引見 [[fractures#pelvic-traction]]
- 背架照護
   1. 背架內**先穿一件薄棉內衣**，保護皮膚、吸汗
   2. **在床上平躺時穿好**再下床；躺下後再脫
   3. **不可穿著背架洗澡**
   4. 避免坐**太軟或太深的沙發**、彎腰提重物；撿東西屈膝蹲下保持背直
   5. 檢查背架邊緣皮膚有無紅腫破皮
