月經問題是婦科門診最常見的主訴。本頁整理正常月經與經期衛生、不正常子宮出血、無月經、多囊性卵巢症候群、痛經、經前症候群與毒性休克症候群，以及更年期的變化與照護；月經週期與激素見 [[female-reproductive-system#menstrual-cycle]]，荷爾蒙療法與避孕藥見 [[sex-hormones]]，子宮肌瘤與子宮內膜異位見 [[benign-gynecologic-disorders]]，陰道炎見 [[sexually-transmitted-infections]]。文中縮寫：AUB（Abnormal uterine bleeding，不正常子宮出血）、PCOS（Polycystic ovary syndrome，多囊性卵巢症候群）、PMS（Premenstrual syndrome，經前症候群）、PMDD（Premenstrual dysphoric disorder，經期前情緒低落症）、NSAIDs（Nonsteroidal anti-inflammatory drugs，非類固醇抗發炎藥）、FSH（Follicle-stimulating hormone，濾泡刺激素）、LH（Luteinizing hormone，黃體生成素）、LDL（Low-density lipoprotein，低密度脂蛋白）

## 重點摘要 {#summary}

- 正常月經：週期約 **24–38 天**、經期 **≤ 8 天**（FIGO 2018；課本寫 21–35 天、2–7 天）
- **青春期**不正常出血最常見原因是**無排卵週期**（下視丘—腦下垂體—卵巢軸還不成熟）
- 無月經先排除**懷孕**
- **多囊性卵巢**：**雄性素過多**、**排卵障礙**（月經稀少或無月經）、多囊卵巢；常合併**胰島素阻抗**與肥胖；雌激素**不是**過多
- **原發性痛經**：**前列腺素**過多使子宮痙攣；月經來潮前數小時開始、**來潮初期最痛**、持續約 2–3 天；**熱敷**、**NSAIDs**、口服避孕藥
- **續發性痛經**：有骨盆腔病灶（子宮內膜異位、子宮腺肌症、肌瘤、骨盆腔炎）
- **經前症候群**：**黃體期**出現身心症狀，**月經來就緩解**；照護以**生活調整**為主
- **更年期**：連續 12 個月沒有月經；**雌激素下降、FSH 與 LH 上升**；熱潮紅、陰道萎縮、骨質流失、LDL 上升

### 國考常考點 {#exam-points}

- 原發性痛經是**痙攣性**疼痛、**月經開始前數小時**出現、**來潮初期最明顯**；充血性悶痛、月經前一週開始、整個經期都痛是續發性的特徵
- 原發性痛經與**前列腺素**有關，所以用 NSAIDs 抑制前列腺素；**不會給前列腺素製劑**
- 痛經護理：**休息、下腹部熱敷**、溫熱飲品；避免咖啡因與冰品；不是「自行服用止痛藥」就好
- 經前症候群出現在**黃體期**；國考答案認為**初經後的年輕時期**較容易出現（學理上盛行率高峰在 20–30 多歲，作答依答案）
- 經前症候群的可能原因（國考答案）：**前列腺素過多**、泌乳素過高、醛固酮與抗利尿激素增加（水分滯留）、缺乏維生素 B6、鈣、鎂
- 經前症候群護理：**規律作息、良好睡眠**、運動；**減少鹽、咖啡因、糖、酒**；不建議高鹽高熱量或冰飲；不是補雌激素
- 多囊性卵巢的表徵：雄性素過多（多毛、痤瘡）、**月經過少或無月經**、肥胖、胰島素阻抗；**不是月經次數過多、不是雌激素過多**
- 更年期：FSH 大量增加、**LH 上升**、雌激素下降、黃體素下降、**LDL 上升**、陰道 **pH 上升**

## 正常月經與經期衛生 {#normal-menstruation}

| 項目 | 正常範圍 |
|---|---|
| 初經 | 約 10–15 歲（台灣平均約 12 歲） |
| 週期 | **24–38 天**(FIGO 2018)；課本與舊題常寫 21–35 天 |
| 經期 | **≤ 8 天**；課本常寫 3–7 天 |
| 經血量 | 約 20–80 mL；影響生活品質的大量出血就算過多 |
| 規律性 | 最長與最短週期相差 ≤ 7–9 天 |

- 經期衛生
   1. 衛生棉 2–4 小時更換一次；**衛生棉條至少 4–8 小時更換**，不可整夜或過久留置（毒性休克症候群）
   2. 由前往後清潔會陰；**淋浴**，避免盆浴與陰道灌洗
   3. 經期可正常活動與運動，不需禁止洗頭洗澡
- 經期不適可補充的營養：鈣、鎂、維生素 B6、**維生素 E**（111-2 題答案）；鐵質補充經血流失

## 不正常子宮出血 {#aub}

| 名稱 | 意思 |
|---|---|
| 月經過多 | 經血量過多或經期過長 |
| 月經過少 | 量少 |
| 月經頻繁 | 週期 < 24 天 |
| 月經過稀 | 週期 > 38 天 |
| 經間出血 | 兩次月經之間出血 |
| 停經後出血 | 停經 12 個月後又出血 → **要排除子宮內膜癌** |

- 原因分類(FIGO PALM-COEIN)
   1. 構造性 PALM：息肉、**子宮腺肌症**、**子宮肌瘤**、惡性腫瘤與增生
   2. 非構造性 COEIN：凝血異常、**排卵障礙**、子宮內膜因素、醫源性（藥物、IUD）、其他
- 依年齡想原因
   1. **青春期**：**無排卵週期**最常見（初經後 1–2 年下視丘—腦下垂體—卵巢軸還不成熟），其次是凝血異常
   2. 生育年齡：懷孕相關（流產、子宮外孕）先排除，再想肌瘤、息肉、排卵障礙
   3. 停經前後與停經後：子宮內膜增生與**子宮內膜癌**（肥胖、糖尿病、高血壓是危險因子，見 [[gynecologic-cancers#endometrial]]）
- 治療：依原因；荷爾蒙（黃體素調整週期、讓內膜規則剝落，見 [[sex-hormones]]）、NSAIDs、tranexamic acid、含黃體素 IUD；大量出血時輸液、輸血、子宮內膜搔刮；貧血補鐵

## 無月經 {#amenorrhea}

- **原發性**：15 歲（有第二性徵）仍未初經，或 13 歲沒有第二性徵發育
- **續發性**：原本月經規則者停 **3 個月**，或不規則者停 6 個月
- **先排除懷孕**
- 常見原因

| 部位 | 原因 |
|---|---|
| 下視丘 | 壓力、**過度減重**、厭食症、過度運動 → GnRH 減少 |
| 腦下垂體 | **高泌乳素血症**（泌乳素瘤、藥物）、席漢氏症候群（產後大出血） |
| 卵巢 | **多囊性卵巢**、**透納氏症**（卵巢發育不全）、早發性卵巢功能不全 |
| 子宮與生殖道 | 子宮腔沾黏（Asherman，刮宮後）、**處女膜閉鎖**、先天無子宮 |
| 其他 | 甲狀腺功能異常、懷孕、哺乳、停經 |

- 透納氏症見 [[chromosomal-disorders]]；厭食症見 [[eating-disorders]]；泌乳素見 [[pituitary-disorders]]

## 多囊性卵巢症候群 {#pcos}

- 最常見的**排卵障礙**原因，也是不孕的常見原因
- 診斷（Rotterdam，2023 國際指引沿用）：以下**三項有兩項**，並排除其他原因
   1. **排卵障礙**：月經過稀或無月經
   2. **雄性素過多**：臨床（多毛、痤瘡、雄性禿）或血中雄性素高
   3. 超音波多囊卵巢（或 AMH 升高，成人可用）
- 機轉：LH／FSH 比例升高、卵巢雄性素過多、**胰島素阻抗**（高胰島素也刺激雄性素）
- 表現：**月經過少或無月經**、**多毛**、痤瘡、**肥胖**、黑色棘皮症、不孕
- 長期風險：第 2 型糖尿病、血脂異常、**子宮內膜增生與癌**（長期無排卵、雌激素沒有黃體素對抗）、睡眠呼吸中止
- 治療
   1. **減重與運動**是第一線（體重減 5–10% 就可能恢復排卵）
   2. 不想懷孕：口服避孕藥調整月經、降低雄性素
   3. 胰島素阻抗：metformin
   4. 想懷孕：letrozole 或 clomiphene 誘導排卵（見 [[infertility#treatment]]）
- 內分泌機轉見 [[endocrine-overview#ovary]]

## 痛經 {#dysmenorrhea}

| | **原發性** | **續發性** |
|---|---|---|
| 原因 | 沒有骨盆腔病灶；子宮內膜**前列腺素**過多 → 子宮強烈收縮、缺血 | 有病灶：**子宮內膜異位症**、子宮腺肌症、子宮肌瘤、骨盆腔炎、IUD |
| 開始年齡 | 初經後 6–12 個月（開始有排卵週期） | 多在 25 歲以後，或原本不痛後來才痛 |
| 時間 | **月經開始前數小時**到來潮時，**來潮初期最痛**，持續約 48–72 小時 | 可在月經前一兩週就開始，整個經期甚至經後都痛 |
| 性質 | **痙攣性**下腹痛，可放射到背部與大腿；可伴噁心、腹瀉、頭痛 | 悶痛、充血性，常有性交痛、經血量多、不孕 |
| 檢查 | 骨盆腔檢查正常 | 超音波、腹腔鏡找病灶 |

- 原發性痛經的處置
   1. **NSAIDs**（抑制前列腺素）：疼痛開始或月經來時就吃效果最好
   2. **口服避孕藥**：抑制排卵、內膜變薄、前列腺素減少；連續使用數個月
   3. 非藥物：**下腹部熱敷**、溫熱飲品、休息、規律運動、按摩
   4. 避免**咖啡因**、冰品、酒精
   5. **不使用前列腺素製劑**（會加重子宮收縮）
- 續發性痛經：治療原本的疾病（見 [[benign-gynecologic-disorders]]）

::questions{ids="110-2_OP_034,110-2_OP_039,105-2_OP_035,105-1_OP_037"}

## 經前症候群 {#pms}

- 定義：**黃體期**（排卵後到月經前）反覆出現身體、情緒與行為症狀，**月經來潮後數天內緩解**，濾泡期沒有症狀
- 症狀：乳房脹痛、腹脹、水腫、體重增加、頭痛、易怒、焦慮、情緒低落、食慾改變（想吃甜食）、失眠或嗜睡
- 原因不明，可能與**黃體期激素波動**和**血清素**對激素的敏感性有關；國考答案列出的因素：**前列腺素過多**、泌乳素過高、醛固酮與抗利尿激素增加造成水分滯留、缺乏維生素 B6、鈣、鎂
- 好發：國考答案選「初經後年輕時期」；學理上盛行率高峰在生育年齡 20–30 多歲
- 照護
   1. 記錄 2–3 個週期的症狀日誌，確認與黃體期相關
   2. **規律作息、充足睡眠**、規律有氧運動、放鬆技巧
   3. 飲食：**少鹽**（減少水腫）、**少咖啡因**、少糖、少酒；少量多餐、複合碳水化合物；補充鈣、維生素 B6
   4. 嚴重時：SSRIs 或口服避孕藥（依醫囑）
- **經期前情緒低落症**(PMDD)：情緒症狀嚴重、影響功能，是 DSM-5-TR 的憂鬱症類別診斷（見 [[depressive-disorder]]）

## 毒性休克症候群 {#tss}

- **金黃色葡萄球菌**（少數鏈球菌）毒素造成，與**長時間留置衛生棉條**、子宮帽、產後或手術傷口有關
- 表現：突然**高燒**、**低血壓**、**瀰漫性紅疹**（1–2 週後手掌腳掌脫皮）、嘔吐腹瀉、多器官衰竭
- 處置：移除異物、輸液、抗生素、升壓劑
- 預防：棉條用最低吸收量、**4–8 小時更換**、不整夜使用；病原體見 [[staphylococcus-aureus]]

## 更年期 {#menopause}

| 名稱 | 定義 |
|---|---|
| 停經過渡期（更年期） | 月經開始不規則到停經後 1 年 |
| **停經** | **連續 12 個月沒有月經**；台灣平均約 50 歲 |
| 停經後 | 最後一次月經之後 |
| 早發性停經 | 40 歲前 |

- 激素變化：卵巢濾泡耗盡 → **雌激素下降**（必定）、黃體素下降 → 負回饋消失 → **FSH 大量上升、LH 上升**（機轉見 [[endocrine-overview#menopause]]）
- 身心變化

| 系統 | 變化 |
|---|---|
| 血管運動 | **熱潮紅**、夜間盜汗、心悸 |
| 泌尿生殖 | 陰道萎縮、乾澀、**pH 上升**、性交痛、萎縮性陰道炎、頻尿、尿失禁、泌尿道感染 |
| 骨骼 | 骨質快速流失 → 骨質疏鬆（見 [[osteoporosis]]） |
| 心血管 | **LDL、總膽固醇上升**、HDL 下降 → 冠心病風險增加 |
| 皮膚 | 變薄、彈性下降 |
| 心理 | 情緒起伏、失眠、記憶力下降、空巢期壓力 |

- 照護
   1. 規律**負重運動**、鈣與維生素 D、戒菸限酒、定期骨密度檢查
   2. 熱潮紅：穿著可穿脫的衣物、保持室內涼爽、避免辛辣、咖啡因與酒精
   3. 陰道乾澀：水性潤滑劑、陰道保濕劑；局部雌激素依醫囑
   4. **凱格爾運動**改善尿失禁（見 [[urinary-elimination#kegel]]）
   5. 定期子宮頸抹片、乳房攝影；停經後出血要就醫
   6. 心理支持、夫妻溝通
- 荷爾蒙療法的適應症、禁忌與副作用見 [[sex-hormones#hormone-therapy]]；社區的更年期保健見 [[maternal-child-health#women]]
