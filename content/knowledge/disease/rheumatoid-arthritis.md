**類風濕性關節炎(RA)**是**慢性、全身性自體免疫疾病**，主要攻擊**滑膜**，造成**對稱性**多關節炎，長期可**破壞軟骨與骨**而變形。女性是男性的數倍，**30–50 歲**好發。它不只侵犯關節，也會影響肺、眼、血管與血液等；治療趨勢是**早期診斷、積極治療**以防止關節破壞

## 重點摘要 {#summary}

- **病理**：**滑膜炎 → 增生 → 血管翳(pannus)** 侵蝕軟骨與骨；**TNF-α、IL-1、IL-6**與 T 細胞、B 細胞參與
- **典型**：**對稱性**、**小關節(掌指、近端指間、腕)**、**晨僵 > 1 小時**、**遠端指間關節通常不侵犯**
- **畸形**：**尺側偏斜**、天鵝頸、鈕釦孔變形；**類風濕結節**
- **抗體**：**RF**(敏感，不特異)、**anti-CCP**(較特異)；**ESR、CRP 上升**，貧血(慢性病貧血)
- **藥物**：**methotrexate** 為首選 DMARD，再加其他 DMARD 或**生物製劑**(**TNF 抑制劑**如 etanercept)；NSAID 只緩解症狀
- **護理**：**急性期休息並保護關節**、**慢性期規律運動**、**熱敷與冷敷**、**輔具與簡化活動**

### 國考常考點 {#exam-points}

- **病理特徵**：**關節滑膜增生與發炎**，**血管翳**造成**軟骨與骨侵蝕**；**增殖性滑膜炎**最常見於 RA
- **臨床**：症狀**通常兩側對稱**；**活動後僵硬減輕**(晨僵，**活動後會改善**)；**不是**活動後加重；**手部尺側偏斜與近端指間過度伸展(天鵝頸)變形**
- **流行病學**：**女性**較多(男性不是 3 倍)，**30–50 歲**；與老化無關
- **RF 陽性**對診斷有幫助，但**不特異**；**anti-CCP** 較特異
- **屬第Ⅲ型**(免疫複合物)為主，也有第Ⅳ型成分；考題常把 **RA 列為免疫複合物型**的例子
- **與退化性關節炎比較**：**OA 疼痛在活動後加劇、休息緩解**，**晨僵 < 30 分鐘**，**非對稱**、DIP 與負重關節；**RA 晨僵久**，對稱，PIP、MCP
- **藥物**：**etanercept** 結合 **TNF-α**；**aspirin／NSAID** 不能改變疾病進程；**cyclosporine** 長期用要注意**腎毒性**；**methotrexate** 要注意**肝毒性與骨髓抑制**
- **好發於年輕男性、薦腸關節、HLA-B27 陽性**的是**強直性脊椎炎**，不是 RA
- 護理：**急性期**採**休息與關節等長(靜態)運動**；**避免**長時間同一姿勢；**運動**以**主動與被動運動**維持關節活動度

## 病生理與危險因子 {#pathophysiology}

### 病理 {#pathology}

1. **自體免疫**：免疫細胞(T 細胞、B 細胞、巨噬細胞)侵入**滑膜**，釋出 **TNF-α、IL-1、IL-6** 等發炎介質
2. **滑膜增生**，形成**血管翳(pannus)**，向關節軟骨與骨**侵蝕**，造成**關節破壞與變形**
3. **瓜胺酸化蛋白質**是自體抗原，**anti-CCP** 針對它；**吸菸**促進瓜胺酸化
4. 補體活化與**免疫複合物**(**RF**＋IgG)在滑膜腔，加重發炎(第Ⅲ型)
5. **TNF-α** 是主要的藥物標的

### 危險因子 {#risk-factors}

1. **女性**、中年；**遺傳**(**HLA-DR4**，「共同表位」)
2. **吸菸**是最強的環境危險因子(UpToDate)
3. 其他：感染、牙周病、肥胖、荷爾蒙

## 臨床表現 {#clinical}

### 關節表現 {#joint}

1. **對稱性多關節炎**：**手(掌指 MCP、近端指間 PIP)、腕、足趾的蹠趾關節**常先受侵犯；**遠端指間(DIP)通常不受侵犯**(與 OA 不同)
2. **晨僵 > 1 小時**，**活動後減輕**；休息後僵硬加重
3. **關節腫脹、壓痛、溫熱**(滑膜炎)
4. **畸形**(長期未控制)：**尺側偏斜**(掌指關節向尺側偏移)、**天鵝頸變形**(PIP 過度伸展、DIP 屈曲)、**鈕釦孔變形**(PIP 屈曲、DIP 過度伸展)、**Z 字拇指**
5. **頸椎(寰樞關節)**不穩定是麻醉與插管需要注意的併發症
6. **Baker 囊腫**(膝後)

### 關節外表現 {#extra-articular}

| 系統 | 表現 |
|---|---|
| **全身** | **疲倦、低燒、食慾不振、體重減輕** |
| **皮膚** | **類風濕結節**(皮下，常在**前臂伸側、肘**，與 RF 陽性有關)、血管炎 |
| **肺** | **間質性肺病**、胸膜炎、結節 |
| **心臟** | 心包膜炎、動脈硬化風險增加 |
| **眼** | **乾眼**(合併乾燥症)、鞏膜炎 |
| **血液** | **慢性病貧血**；**Felty 症候群**(RA＋脾腫大＋嗜中性球低下) |
| **骨骼** | **骨質疏鬆**(發炎與類固醇) |

## 診斷與檢驗 {#diagnosis}

1. **2010 ACR／EULAR 分類標準**：依**受侵犯的關節**、**血清(RF、anti-CCP)**、**急性期反應(ESR、CRP)**、**症狀持續時間(≥ 6 週)**計分，**總分達 6 分以上**(滿分 10)分類為 RA；**不必**達到標準才能診斷(UpToDate)
2. **檢驗**

| 檢驗 | 意義 |
|---|---|
| **RF(類風濕因子)** | **針對 IgG Fc 的自體抗體**(常為 IgM)；**敏感度中等、特異度低**，慢性感染與其他自體免疫也可陽性；**效價高與嚴重度、關節外表現相關** |
| **Anti-CCP** | **特異度高**，可**早期出現**，**預測關節侵蝕** |
| **ESR、CRP** | **疾病活動的追蹤**，上升 |
| **血球** | **貧血**(慢性病)，血小板可上升 |
| **關節液** | 發炎性(白血球增加)，排除痛風與感染 |

3. **影像**：X 光可見**關節周圍骨質疏鬆、關節間隙狹窄、骨侵蝕**；**超音波與 MRI** 可早期偵測滑膜炎
4. **疾病活動度**：用 **DAS28**(壓痛與腫脹關節數、ESR 或 CRP、整體評估)評估；台灣健保對生物製劑的給付與 DAS28 有關，**細節待核對**

### 與退化性關節炎(OA)比較 {#ra-vs-oa}

| | **RA** | **OA(退化性)** |
|---|---|---|
| 機轉 | 自體免疫滑膜炎 | 軟骨磨損、老化與機械因素 |
| 年齡與性別 | 30–50 歲，**女性多** | **老年**，多與老化、肥胖、外傷相關 |
| 關節 | **對稱**，**MCP、PIP**、腕 | **不對稱**，**DIP**、膝、髖、脊椎(**負重**關節) |
| 晨僵 | **> 1 小時**，休息後加重、活動改善 | **< 30 分鐘**，活動後疼痛加劇、**休息緩解**，晚上較僵 |
| 全身症狀 | **有**(疲倦、低燒) | 通常**沒有** |
| 實驗室 | **RF、anti-CCP**、ESR、CRP 上升 | 正常 |
| X 光 | 骨質疏鬆、**間隙狹窄**、**侵蝕** | **骨刺**、間隙狹窄、硬化 |
| 畸形 | **尺側偏斜、天鵝頸** | **Heberden 結節(DIP)**、Bouchard 結節(PIP) |

與痛風、強直性脊椎炎(**HLA-B27**、年輕男性、**薦腸關節**)的區別，見 [[immunoglobulins-hla#hla-disease]]。

## 藥物治療 {#drugs}

### 治療原則 {#principles}

1. **早期診斷、早期積極治療**，**治療到目標(treat-to-target)**：目標是**緩解或低疾病活動**
2. **三大類藥物**
   1. **緩解症狀**：**NSAID**、**類固醇**(短期橋接)
   2. **疾病修飾抗風濕藥(DMARD)**：**減緩關節破壞**
   3. **生物製劑與標靶合成 DMARD**
3. **NSAID 與 aspirin 不能改變疾病進程**，只緩解疼痛與發炎(**選擇性 COX-2 抑制劑**對血小板影響較小)([[nsaids-acetaminophen]])

### DMARD 與生物製劑 {#dmards}

| 類別 | 藥物 | 重點 |
|---|---|---|
| **傳統合成 DMARD(csDMARD)** | **methotrexate(MTX，首選)**、sulfasalazine、leflunomide、hydroxychloroquine | **MTX 每週一次**(最大約 **25 mg／週**)，**合併葉酸**；副作用**肝毒性、骨髓抑制、口腔潰瘍**；**懷孕、肝病、酗酒、嚴重腎功能不全**避免 |
| **TNF 抑制劑** | **etanercept**、**infliximab**、**adalimumab**、golimumab、certolizumab | **阻斷 TNF-α**；用前先**篩檢結核與 B 型肝炎**；**感染風險增加**；不用於初始單藥(MTX 初始療效相近) |
| **其他生物製劑** | **tocilizumab**(抗 IL-6 受體)、**abatacept**(阻斷共刺激 CD28–B7)、**rituximab**(抗 CD20)、anakinra(IL-1 受體拮抗) | 對 TNF 抑制劑反應不佳時使用 |
| **JAK 抑制劑** | **tofacitinib、baricitinib、upadacitinib** | **口服**；有**安全性疑慮**(心血管、血栓、感染、惡性腫瘤)，限制使用 |
| **類固醇** | prednisone | **短期低劑量橋接**；**長期副作用多**，**使疤痕與傷口變弱** |
| **免疫抑制劑** | azathioprine、**cyclosporine**(**腎毒性、高血壓**) | 較少用 |

1. **MTX 注意事項**：**每週**一次(不是每天，是常見的用藥錯誤)、**葉酸**、**定期驗血球與肝腎功能**、**避免酒精**、懷孕前停藥
2. **生物製劑與 JAK 抑制劑**使用期間**避免活性減毒疫苗**，**感染徵象要提早就醫**([[immunization]])
3. 單株抗體的命名與輸注反應見 [[monoclonal-antibodies]]
4. 台灣**健保**對生物製劑與標靶合成 DMARD 有**給付規定**(例如傳統 DMARD 無效、疾病活動度)，**細節待核對**

## 護理與衛教 {#nursing}

1. **疼痛與僵硬處理**
   1. **晨間**以**溫水浴**或**熱敷**減輕僵硬；**急性發炎期(紅腫熱痛明顯)**可**冷敷**，**不要按摩**發炎的關節
   2. 依醫囑**服藥**，**定時**服用 NSAID 並**餐後服用**減少胃腸刺激
2. **休息與運動**
   1. **急性期**：**休息**、關節**擺放功能位置**、**副木固定**，進行**等長運動**(靜態收縮)與輕度**關節活動**，避免激烈活動
   2. **緩解期**：**規律運動**維持**關節活動度**與肌力(游泳、散步)，**避免疲勞**；運動以**主動運動**為主，依個別狀況由復健人員指導
   3. **不要長時間維持同一姿勢**，**休息與活動交替**
3. **關節保護**
   1. 使用**大關節**與**較強的肌肉**(用手掌拿重物而非手指)
   2. **避免**用手指長時間緊握、扭轉
   3. **輔具**：開瓶器、加粗握把、穿衣輔具、拐杖；**維持正常體重**
   4. **簡化活動**、**分段完成**，**節省體力**
4. **飲食**：均衡營養，**omega-3 脂肪酸**(魚油)可能有輔助作用；**維持理想體重**，**戒菸**
5. **用藥衛教**：**MTX 每週一次**、**葉酸**、**定期抽血**；**生物製劑前**篩檢**結核與 B 肝**；**感染預防**
6. **心理支持**：慢性疼痛、外觀與功能改變易**憂鬱**，鼓勵**參與病友團體**
7. **跌倒與骨質疏鬆**預防(類固醇與活動減少)
