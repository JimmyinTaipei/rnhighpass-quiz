**酒精使用障礙症**是最常見的物質使用問題之一。酒精是**中樞神經抑制劑**，長期大量飲用會讓大腦「適應」成高興奮狀態，一旦突然停酒就出現**戒斷**，嚴重時發生可能致命的**震顫性譫妄**。慢性飲酒加上營養不良，造成**維生素 B1 缺乏**相關的腦病變與全身合併症。物質使用的總論與護理原則見 [[substance-use-disorders]]，戒酒藥物見 [[addiction-treatment-drugs#alcohol-drugs]]

## 重點摘要 {#summary}

- **代謝**：酒精 →（醇去氫酶）→ **乙醛** →（**乙醛去氫酶 ALDH**）→ 醋酸；ALDH2 活性不足者喝酒會臉紅心悸
- **戒斷機轉**：長期飲酒使 **GABA 抑制功能下降**、**麩胺酸與正腎上腺素增加** → 停酒後**交感神經亢奮**；**不是** GABA 功能增加
- **戒斷時間軸**：6–36 小時**顫抖、焦慮、失眠、出汗、心跳快** → **酒精性幻覺**（以**視幻覺**、觸幻覺為主） → **痙攣** → 少數 **48–96 小時**出現**震顫性譫妄**（意識混亂、視幻覺、發燒、心跳快、血壓高）
- **治療**：**BZD** 為首選；**先給 thiamine 再給葡萄糖**；補充水分、**鉀與鎂**；**不給酒**緩解戒斷
- **威尼克氏腦病變**（維生素 **B1**）：**意識混亂、眼肌麻痺（眼球震顫）、運動失調**，及早補充可恢復；**柯沙可夫症候群**：**近期記憶喪失**、**虛談**，多不可逆
- 長期目標：**持續追蹤、強化支持、預防再度飲酒**；家屬參加支持團體是為了**增進家屬自己的因應**

### 國考常考點 {#exam-points}

- 長期飲酒住院第 **2 天**心跳快、血壓高、大量流汗、**看到蛇** → **震顫性譫妄**
- 酒精戒斷譫妄以**視幻覺**為主，**不是聽幻覺、嗅幻覺**
- 戒斷症狀：焦慮、厭食、失眠、**顫抖**、流汗；停酒後短時間內發生、持續約 5–7 天；常有**營養不良與維生素 B 群缺乏**
- 「酒精戒斷會**提高 GABA 抑制功能**」是**錯的**；戒斷有**交感神經亢奮**，可用 **BZD** 治療；不是提供微量酒精
- **威尼克氏腦病變**缺乏**維生素 B1**：意識障礙、眼肌麻痺、運動失調；周邊神經病變也是 **B1** 缺乏，不是維生素 E；不是維生素 A 或 C
- **柯沙可夫症候群**典型症狀是**近期記憶力喪失**（加上虛談）；懷疑配偶不忠是**酒精性嫉妒妄想**
- 長期目標＝**持續追蹤、強化支持、預防再度使用**；酒癮**不適合**「漸進式戒除」
- 家屬參加支持團體的主要目的是**增進家屬的因應行為**，不是改變病人
- 急性酒精中毒主要影響**中樞神經系統**
- 酒精性肝炎肝細胞中可見 **Mallory 小體**；慢性酗酒常見周邊神經病變、擴張性心肌症、慢性胰臟炎；**橫紋肌溶解不是**常見的慢性後遺症
- 酒癮者對吸入性麻醉劑有**交叉耐受**，需要較高的麻醉劑量（MAC 較高）
- 酒精戒斷與交感神經亢奮時，臨床常見**低血鎂**、低血鉀（見下方考題分歧）

## 酒精的代謝與作用 {#pharmacology}

1. **吸收**：胃吸收一部分，**主要在小腸**；空腹、碳酸飲料、胃排空快時吸收較快（國考有「喝酒又喝水會增加吸收」的考法）
2. **代謝**：主要在**肝臟**
   1. 酒精 →（醇去氫酶 ADH）→ **乙醛**（有毒，造成臉紅、心悸、噁心）
   2. 乙醛 →（**乙醛去氫酶 ALDH**）→ 醋酸 → 水與二氧化碳
   3. **ALDH2 活性不足**的人喝酒後乙醛蓄積，容易**臉紅**、心悸；這類人長期飲酒**食道癌**風險較高
   4. **disulfiram** 就是抑制 ALDH，讓病人一喝酒就難受（見 [[addiction-treatment-drugs#alcohol-drugs]]）
3. **中樞作用**：增強 **GABA-A** 的抑制作用、抑制 **NMDA（麩胺酸）**；少量解除抑制、話多，大量則動作失調、意識下降、呼吸抑制
4. **交叉耐受**：與 BZD、巴比妥、全身麻醉劑交叉耐受，所以酒癮者需要較高的麻醉劑量，也是用 BZD 治戒斷的原理

## 篩檢與評估 {#screening}

| 工具 | 內容 |
|---|---|
| **AUDIT** | WHO 發展的 10 題問卷：飲酒量與頻率、依賴症狀、飲酒造成的傷害；分數越高風險越高（切點依教科書：8 分以上為危險飲酒，20 分以上考慮酒精依賴，列待核對） |
| **CAGE** | 4 題：想要**減少**(Cut down)、被批評而**惱怒**(Annoyed)、**罪惡感**(Guilty)、早上起床就要喝一杯(**Eye-opener**)；2 題以上需要進一步評估 |
| 實驗室 | **GGT** 上升、**MCV 變大**、AST > ALT（約 2 倍）、血中酒精濃度 |

## 急性酒精中毒 {#intoxication}

1. 主要影響**中樞神經系統**：口齒不清、步態不穩、判斷力差、情緒失控 → 嗜睡、昏迷、**呼吸抑制**、低體溫、低血糖、嘔吐吸入
2. 處理：**維持呼吸道**、側臥防吸入、監測生命徵象與血糖、保暖、補充水分；給葡萄糖前先給 thiamine
3. 酒精**沒有專一的解毒劑**；昏迷原因不明、懷疑合併鴉片類時，可先試用 **naloxone**（國考有「以 naloxone 矯正乙醇引起的昏迷」的敘述，臨床上只在懷疑合併鴉片類時有效）
4. 要排除被酒精掩蓋的疾病：**頭部外傷、顱內出血**、低血糖、敗血症、肝昏迷

## 酒精戒斷 {#withdrawal}

### 機轉 {#withdrawal-mechanism}

1. 長期飲酒，大腦為了平衡酒精的抑制作用，**GABA 受體敏感度下降**、**NMDA（麩胺酸）受體增加**
2. 突然停酒或減量 → 抑制不夠、興奮過度，加上**正腎上腺素分泌增加** → **交感神經亢奮**、痙攣
3. 反覆戒斷會讓神經更容易興奮，下次戒斷更嚴重

### 時間軸 {#withdrawal-timeline}

依長庚急診流程指引與教科書通則整理（個別差異大）：

| 停酒後時間 | 表現 |
|---|---|
| **6–36 小時** | **輕度戒斷**：雙手、眼瞼、舌頭**顫抖**，**焦慮**、頭痛、**失眠**、**厭食**、**出汗**、噁心嘔吐、心跳加快 |
| 約 12–48 小時 | **酒精性幻覺**：意識大致清楚，以**視幻覺**為主（看到蟲、蛇、動物），也可有觸幻覺（蟲在皮膚上爬） |
| 約 6–48 小時 | **戒斷痙攣**：全身性強直陣攣發作 |
| **48–96 小時** | **震顫性譫妄**（約 **5%**）：意識混亂、定向感障礙、激躁或嗜睡、胡言亂語、**視幻覺**與觸幻覺、**瞳孔放大**、大量出汗、**心跳快、血壓高、發燒**；持續約 1–5 天 |

- 戒斷整體約持續 **5–7 天**
- 震顫性譫妄**未治療致死率約 5%**，常合併頭部外傷、心律不整、心肌梗塞、脫水、吸入性肺炎、**低血鉀與低血鎂**
- 和鴉片類戒斷不同，酒精戒斷**可能致命**

### 評估：CIWA-Ar {#ciwa-ar}

1. 評估 10 個項目：噁心嘔吐、**顫抖**、**出汗**、焦慮、激躁、觸覺障礙、聽覺障礙、視覺障礙、頭痛、**定向感**
2. 滿分 **67 分**，分數越高越嚴重；台灣家醫科文獻的分級：**15 分以下輕度**、**16–20 分中度**、**21 分以上重度**；輕度與中度可在門診治療，重度有震顫性譫妄風險要住院（黃力偉、董至剛〈酒癮及戒斷症候群〉，家庭醫學與基層醫療 31 卷 10 期）；國外部分量表以 10 分、19 分為切點，各院略有不同
3. 長庚流程指引：**CIWA-Ar > 16 分**、生命徵象不穩、持續痙攣或出現震顫性譫妄 → 維持呼吸道與生命徵象並**住院**
4. 依分數**症狀觸發式**給 BZD，定時重新評估

### 戒斷的治療 {#withdrawal-treatment}

1. **BZD 為首選**：與酒精交叉耐受，可減輕戒斷並預防**痙攣與震顫性譫妄**
   1. 長效的 chlordiazepoxide、diazepam 戒斷過程較平順
   2. **肝功能差或老人**用 **lorazepam**（不經肝臟氧化代謝）
   3. 震顫性譫妄、嚴重激躁：靜脈 BZD，必要時加上 haloperidol 或其他藥物，住加護病房
   4. 藥物細節見 [[anxiolytics-hypnotics#indications]]
2. **Thiamine（維生素 B1）**：**在給葡萄糖之前**先給，避免誘發威尼克氏腦病變；營養不良者先注射再改口服
3. **水分、電解質與營養**：補充**鉀、鎂**、葉酸與綜合維生素；矯正低血糖
4. **輔助**：β 阻斷劑或 clonidine 減輕心跳快與高血壓，但**不能**預防痙攣與譫妄（「BZD 加 α1 阻斷劑」是錯的）
5. **不要給酒**來緩解戒斷
6. 抗精神病藥會降低痙攣閾值，不作為單獨治療

:::note[考題分歧：酒精戒斷的鎂離子]
107-2_PC_005 的答案敘述「酒精戒斷和正腎上腺素增加都會**增加**鎂離子的濃度」，但臨床上酒精戒斷與震顫性譫妄常見的是**低血鎂**（長庚急診流程指引也列為常見電解質失調），需要補充鎂。這題用刪去法（其他三個選項明顯錯誤）作答，臨床照護以低血鎂為準
:::

## 營養缺乏相關的神經病變 {#wernicke-korsakoff}

| | 威尼克氏腦病變 | 柯沙可夫症候群 |
|---|---|---|
| 原因 | 急性**維生素 B1(thiamine)缺乏** | 威尼克氏腦病變未及時治療的慢性後果 |
| 表現 | 三大症狀：**意識混亂**、**眼肌麻痺或眼球震顫**、**運動失調**（步態不穩） | **近期記憶嚴重喪失**、無法學習新事物、**虛談**填補記憶空白、遠期記憶相對保留 |
| 預後 | **急症**，及早大劑量 thiamine 可以改善 | 多為**不可逆**，部分改善 |

1. 給**葡萄糖前先給 thiamine**，否則葡萄糖代謝會耗盡剩下的 B1，誘發或加重腦病變
2. **周邊神經病變**：手腳麻木刺痛，也和 B1 等營養缺乏與酒精毒性有關

## 身體合併症 {#complications}

| 系統 | 合併症 |
|---|---|
| **肝** | **脂肪肝** → **酒精性肝炎**（肝細胞內 **Mallory 小體**） → **肝硬化**、肝癌 |
| 腸胃與胰 | 胃炎、消化性潰瘍、食道靜脈曲張出血、**急性與慢性胰臟炎**（慢性胰臟炎最常見的原因是長期酗酒） |
| 神經 | 威尼克－柯沙可夫症候群、**周邊神經病變**、小腦退化、酒精性失智、戒斷痙攣 |
| 心血管 | **擴張性心肌症**、高血壓、心律不整 |
| 血液與代謝 | 巨球性貧血（葉酸缺乏）、血小板低下、低血糖、低鉀、低鎂、高尿酸 |
| 生殖與胎兒 | 性功能障礙；孕期飲酒造成**胎兒酒精症候群**（生長遲緩、特殊臉型、智能不足） |
| 精神 | 憂鬱、自殺、焦慮；**酒精性嫉妒妄想**（懷疑配偶不忠）；酒精性幻覺症 |
| 外傷 | 跌倒、頭部外傷、酒駕事故、家庭暴力 |

- 酒精造成脂肪肝的機轉見 [[environmental-injury#alcohol]]；維生素 B1 等缺乏症總表見 [[nutritional-disorders#water-soluble]]

## 長期治療 {#long-term-treatment}

1. **藥物**：disulfiram（嫌惡）、naltrexone（減少渴求）、acamprosate（維持戒酒），見 [[addiction-treatment-drugs#alcohol-drugs]]
2. **心理社會治療**
   1. 動機式晤談、認知行為治療、預防復發訓練
   2. **匿名戒酒會(AA)**；家屬參加家屬支持團體（Al-Anon 等），目的在**增進家屬的因應能力**、減少共依存
   3. 家庭治療、婚姻治療
3. **戒酒原則**：**完全戒酒**，不適合漸進式減量；要在醫療監督下安全戒斷

## 護理 {#nursing}

### 護理目標 {#nursing-goals}

| 階段 | 目標 |
|---|---|
| **短期** | 安全度過戒斷：維持生命徵象、處理戒斷症狀、**預防痙攣與譫妄**、預防合併症 |
| 中期 | 斷絕酒精與其他物質來源、提升戒酒動機、建立健康習慣與因應方式 |
| **長期** | **持續追蹤、強化支持系統、預防再度飲酒** |

### 戒斷期護理 {#nursing-withdrawal}

1. 每 1–4 小時評估**生命徵象**、意識、顫抖、出汗與 CIWA-Ar
2. **安全**：床欄、低床、移除危險物品、**痙攣防護**；震顫性譫妄時有跌倒、自拔管路的風險
3. 環境**安靜、光線適中**，減少錯覺；簡短重複定向（譫妄護理見 [[delirium#nursing]]）
4. 依醫囑給 BZD 並觀察**過度鎮靜與呼吸抑制**；**先給 thiamine 再給葡萄糖**
5. 補充水分、電解質與營養，記錄輸出入
6. 對幻覺：不爭辯、給予安全感，必要時調整燈光

### 心理社會護理 {#nursing-psychosocial}

1. 中立、不批判；病人常用**否認、合理化、投射**，協助覺察飲酒造成的問題
2. 設定一致的規則，處理操縱行為
3. 教導壓力因應與拒酒技巧，安排規律作息與活動
4. 評估**自殺風險**、家庭暴力與兒童安全（見 [[family-violence]]）
5. 家屬衛教：成癮是疾病、避免共依存、照顧自己、參加支持團體
