上消化道指食道、胃與十二指腸（到屈氏韌帶為止）。本頁整理胃食道逆流與巴瑞特氏食道、食道裂孔疝氣、食道弛緩不能、食道憩室、食道癌、腐蝕性物質誤食、胃炎、消化性潰瘍與壓力性潰瘍、上消化道出血、胃癌與胃切除後的傾倒症候群；構造與生理見 [[gi-anatomy-physiology]]，用藥見 [[gi-drugs]]，幽門螺旋桿菌與除菌見 [[helicobacter-pylori]]

## 重點摘要 {#summary}

- **胃食道逆流**：下食道括約肌(LES)**壓力太低**或不當鬆弛；**心灼熱感最常見**；護理：**飯後 2–3 小時內不躺下**、睡前 2–3 小時不進食、**床頭抬高**、少量多餐、減重、戒菸酒咖啡、避免高脂與提重物彎腰
- **巴瑞特氏食道**：長期逆流讓食道下段鱗狀上皮變成含**杯狀細胞**的柱狀上皮（腸化生） → **腺癌**風險上升，風險高低看**異生程度**
- **食道裂孔疝氣**：胃從食道裂孔滑進縱膈腔；**滑動型最常見**；多見於**中老年、肥胖、女性**；飯後**立即**心灼熱、平躺加重
- **食道弛緩不能**：LES 不能放鬆、食道蠕動消失 → 一開始就吞嚥困難，**情緒壓力**會加重
- **食道癌**：台灣以**鱗狀細胞癌**為主、好發**中下段**、**男性**多；菸、酒、**檳榔**、**過熱過鹹**食物；漸進性吞嚥困難、體重減輕、**聲音沙啞**；術後最嚴重合併症是**吻合處滲漏**
- **消化性潰瘍**：胃與十二指腸的潰瘍，主因**幽門螺旋桿菌**、**NSAID／aspirin**；胃潰瘍**飯後痛**、胃酸正常；十二指腸潰瘍**空腹、半夜痛**、進食緩解、胃酸多
- **上消化道出血**：吐血（咖啡渣）、**黑便**；嚴重時**心搏過速、血壓下降**、肢端冰冷；血管加壓素要**逐漸減量**不可驟停
- **胃癌**：與**醃漬燻烤**食物、幽門螺旋桿菌有關，好發**胃竇（遠端）**，以**腺癌**為主；**全胃切除**後終身補充**維生素 B12**
- **傾倒症候群**：早期在飯後 10–30 分鐘（高張食糜快速進入空腸、細胞外液移入腸道 → 循環血量下降）；預防：**少量多餐、低醣、高蛋白、適量脂肪、乾性食物、用餐不喝湯水、半坐臥進食、飯後躺下**

### 國考常考點 {#exam-points}

- 胃食道逆流最常見症狀是**心灼熱感**；**腹瀉**不是典型表現；原因是 LES 壓力**太低**（不是太高）
- 胃食道逆流護理的錯誤選項：**進食後立即平躺**、睡前吃宵夜、穿緊身衣；不用 β 阻斷劑治療
- 降低 LES 壓力：**胰泌素**、抗膽鹼藥、**香菸**、脂肪、酒、咖啡因、巧克力；**副交感（擬膽鹼）藥物會提高** LES 壓力
- 心口灼熱常形容為燒灼感，**進食後平躺會加重**（不會緩解）
- 巴瑞特氏食道最具診斷意義的是**杯狀細胞**；增加**腺癌**（不是鱗狀細胞癌）風險；原因是**長期胃食道逆流**；男性較多；惡化成腺癌最相關的是**上皮異生程度**
- 食道腺癌與**長期胃食道逆流**最相關
- 食道裂孔疝氣：胃經食道裂孔進入**縱膈腔**；**滑動型**占大多數（不是 20%）；常見於中老年、肥胖（**不是**男性瘦弱者）；症狀在**飽餐後立即**出現（不是 1 小時後）；可有胸頸背緊迫感、吞嚥困難
- 食道弛緩不能：在食道**下段**、會引起食道炎、早期就吞嚥困難、**情緒壓力會加重**
- 食道憩室：用**鋇劑食道攝影**確定位置（不是電腦斷層）；避免食道鏡以防穿孔；餐後 2 小時勿劇烈運動；不一定要手術
- 食道癌：好發中下段（不是上 1/3）、**鱗狀細胞癌**最常見（**腺癌最常見**是錯的）、男性多、喜食**過熱過鹹刺激性**食物；腹痛不是常見表徵、**聲音沙啞**是；飲食要**高熱量高蛋白**（不是低蛋白）；光動力治療後避光約 1 個月
- 誤食強酸強鹼：**不可催吐、不可洗胃、不可給中和劑**；兒童誤食鹼水或漂白水可先給少量**清水或牛奶**稀釋
- 急性胃炎：症狀期間要**暫時禁食**（「不需禁食、正常飲食」是錯的）、避免 aspirin 與類固醇
- 自體免疫性胃炎好發**胃體與胃底**（不是胃竇），有抗壁細胞與抗內在因子抗體 → 惡性貧血
- 消化性潰瘍包括**胃潰瘍與十二指腸潰瘍**
- 十二指腸潰瘍：**餓的時候痛、半夜痛醒、吃了就改善**；胃潰瘍：**左上腹、飯後 0.5–1 小時更痛**、常見噁心嘔吐、胃酸**正常**；「胃潰瘍原因是胃酸增加」是錯的
- **克林氏潰瘍**見於**嚴重燒傷**；庫欣氏潰瘍見於頭部外傷；燒傷病人靜脈給 H2 阻斷劑是**預防壓力性潰瘍**
- 消化性潰瘍手術後最不常見的合併症是**便秘**
- 上消化道出血：嚴重時**心搏過速、血壓不穩**；多為黑便（不是鮮血便）；出血停止後**血管加壓素不可立即停**
- 胃癌與**醃漬食物**有關、以腺癌最常見、好發遠端；全胃切除預防惡性貧血補 **維生素 B12**
- 胃腸道基質瘤**最好發在胃**（不是小腸），源自 Cajal 氏間質細胞、多有 c-KIT 突變
- 早期傾倒症候群機轉：**細胞外液迅速移入腸道、循環血量減少**；原因是**食物快速進入腸道**
- 預防傾倒症候群：少量多餐、**低醣**、**高蛋白**、適量（或高）脂肪、**乾性食物**、進食時半坐臥、**飯後躺下**；錯誤選項：高醣、多喝液體、飯後立即散步

## 胃食道逆流與巴瑞特氏食道 {#gerd}

- 機轉：**下食道括約肌(LES)壓力太低**或不當鬆弛 → 胃酸逆流到食道；腹內壓增加（肥胖、懷孕、緊身衣、彎腰提重）與食道裂孔疝氣會加重

| 會降低 LES 壓力（加重逆流） | 會提高 LES 壓力 |
|---|---|
| **胰泌素**、CCK、**抗膽鹼藥**、硝酸鹽、鈣離子阻斷劑、黃體素；**香菸**、酒、咖啡因、巧克力、薄荷、**高脂食物** | 胃泌素、**副交感（擬膽鹼）藥物**、metoclopramide、蛋白質 |

- 症狀：**心灼熱感（最常見）**、胃酸逆流、反胃、吞嚥困難或疼痛、慢性咳嗽、聲音沙啞；**飯後與平躺時加重**
- 治療：PPI 每天 1 次、**餐前 30–60 分鐘**服用，先試 8 週，症狀改善後嘗試停藥(ACG 2022)；藥物見 [[gi-drugs#ppi]]
- 護理指導（ACG 2022 也建議前三項）
   1. **睡前 2–3 小時不進食**，**飯後 2–3 小時內不躺下**、不做劇烈運動
   2. 夜間症狀：**床頭抬高**（墊高床頭，不是只墊枕頭）
   3. 戒菸，避免酒、咖啡、巧克力、高油脂與誘發症狀的食物
   4. **少量多餐**、細嚼慢嚥；**體重過重要減重**
   5. 避免增加腹壓：緊身衣、束腹、**提重物、彎腰**、便秘用力
- 嬰兒胃食道逆流見 [[pediatric-gi#gerd]]

### 巴瑞特氏食道 {#barrett}

- 長期逆流讓**食道下段**的複層鱗狀上皮被**柱狀上皮**取代，出現**杯狀細胞**（腸化生）是診斷依據
- 是**食道腺癌**的前驅病變；惡化風險取決於**上皮異生(dysplasia)的程度**；男性較多
- 處置：PPI 控制逆流、定期內視鏡追蹤切片

## 食道癌 {#esophageal-cancer}

- 類型：台灣以**鱗狀細胞癌**為主，好發**食道中下段**；**腺癌**來自巴瑞特氏食道，多在下段
- 危險因子：**男性**、**吸菸、喝酒、嚼檳榔**、**喜食過熱、過鹹、刺激性**食物、亞硝胺；腺癌與長期胃食道逆流、肥胖有關
- 表現：**漸進性吞嚥困難**（先固體後液體）、吞嚥痛、體重減輕；侵犯喉返神經 → **聲音沙啞**；腹痛**不是**常見表現
- 治療：食道切除＋重建（把胃拉上來或用結腸代替），適用中、下段；化學與放射治療；光動力治療後皮膚對光敏感，要**避光約 1 個月**
- 術後護理
   1. **吻合處滲漏**是最嚴重合併症（發燒、胸痛、頸部傷口滲液），鼻胃管不可自行調整
   2. 半坐臥、預防吸入性肺炎
   3. 營養：**高熱量、高蛋白**；不能由口進食時經**胃造口或空腸造口**灌食（管灌見 [[enteral-parenteral-nutrition]]）
- 食道癌也列在 [[cancer#other-cancers]]

## 誤食腐蝕性物質 {#corrosive}

- 強酸、強鹼（鹼水、通樂、漂白水）會灼傷口腔、食道與胃，嚴重時穿孔、日後**食道狹窄**
- **不可催吐**（再次灼傷、吸入）、**不可洗胃**、**不可給中和劑**（酸鹼中和會產熱）
- 國考答案：兒童誤食鹼水或漂白水，可先給**少量清水或牛奶**稀釋再送醫；送醫後內視鏡確認沒有穿孔，才考慮由口進食；懷疑穿孔或潰瘍先禁食
- 觀察口腔與食道灼傷、呼吸道水腫、穿孔徵象（胸痛、腹膜炎）；其他化學性傷害見 [[environmental-injury#chemical]]

## 胃炎 {#gastritis}

| 類型 | 原因 | 重點 |
|---|---|---|
| **急性胃炎** | NSAID、aspirin、類固醇、酒精、壓力、食物中毒 | 上腹痛、噁心嘔吐；症狀期**暫時禁食**，緩解後漸進飲食；依醫囑給制酸劑；避免 aspirin、類固醇、菸酒 |
| **慢性 B 型胃炎** | **幽門螺旋桿菌** | 從**胃竇**開始；與消化性潰瘍、胃癌、MALT 淋巴瘤有關（見 [[helicobacter-pylori]]） |
| **自體免疫性（A 型）胃炎** | 抗**壁細胞**與抗**內在因子**抗體 | 侵犯**胃體與胃底**（壁細胞所在）、黏膜萎縮、胃酸減少 → **惡性貧血** |

## 消化性潰瘍 {#peptic-ulcer}

- 定義：胃或十二指腸黏膜缺損深達黏膜肌層以下；**消化性潰瘍＝胃潰瘍＋十二指腸潰瘍**（口腔、食道潰瘍不算）
- 原因：**幽門螺旋桿菌**與**長期 aspirin、NSAID、類固醇**最常見；其他：胃泌素瘤、吸菸、壓力（《內外科護理學》下冊 p.368）

| 比較 | **胃潰瘍** | **十二指腸潰瘍** |
|---|---|---|
| 年齡 | 50 歲以上較多 | 年輕人較多 |
| 胃酸 | **正常或偏低** | **增加** |
| 疼痛位置 | 上腹中線偏**左** | 上腹中線偏**右** |
| 疼痛時間 | **飯後 0.5–1 小時**，進食加重 | **飯後 2–3 小時、空腹、半夜痛醒**，**進食後緩解** |
| 其他 | 噁心嘔吐常見、**吐血**較多、惡性變化要切片排除 | **黑便**較多 |

- 合併症：**出血**（最常見）、**穿孔**（突然劇痛、腹部僵硬如木板 → 緊急手術）、幽門阻塞（嘔吐）
- 治療：除菌（見 [[helicobacter-pylori]]）、PPI 或 H2 阻斷劑、黏膜保護劑、停用 NSAID；用藥目的是**中和胃酸、減少胃酸分泌、保護黏膜**，不是促進胃排空；**H1 阻斷劑不用於潰瘍**（見 [[gi-drugs#peptic-ulcer-drugs]]）
- 飲食：沒有特殊潰瘍飲食，規律進食、避免讓自己不適的刺激性食物（酒、咖啡、辣椒、肉汁）與菸；舊說法「多喝牛奶中和胃酸」已不建議（牛奶會反彈刺激胃酸）
- 手術後合併症：**傾倒症候群**、邊緣復發性潰瘍、出血、輸入環症候群、鹼性逆流性胃炎、B12 與鐵缺乏；**便秘不常見**

### 壓力性潰瘍 {#stress-ulcer}

- 重症、燒傷、頭部外傷、呼吸器病人因黏膜缺血形成**急性多發糜爛**，多在**胃體**，以出血表現
- **克林氏(Curling)潰瘍**：**嚴重燒傷**；**庫欣氏(Cushing)潰瘍**：**中樞神經創傷**或手術
- 預防：靜脈給 **H2 阻斷劑或 PPI**（燒傷病人給 cimetidine 是為了**預防壓力性潰瘍**）

## 上消化道出血 {#upper-gi-bleeding}

- 定義：**屈氏韌帶以上**（食道、胃、十二指腸）的出血；常見原因：**消化性潰瘍**、**食道靜脈曲張**、急性胃黏膜病變、食道撕裂、胃癌
- 表現：**吐血**（鮮紅或**咖啡渣樣**）、**黑便（柏油便）**；大量時也可解暗紅血便；**低血容積**徵象：**心搏過速、血壓下降**、皮膚蒼白濕冷、**肢端冰冷、指甲床蒼白**、尿量減少、意識改變
- 糞便顏色：上消化道出血與**口服鐵劑、鉍劑、豬肝**會解黑便；**直腸出血**是鮮紅色

| 處置 | 重點 |
|---|---|
| 評估 | 生命徵象、嘔吐物與糞便的**性質顏色**、腹部是否**脹硬**（穿孔）、Hb、BUN（血液在腸道被吸收會上升） |
| 復甦 | 禁食、**粗針頭**建立靜脈輸液、輸血；限制性輸血門檻 **Hb 7 g/dL**，心血管病人個別化(ACG 2021) |
| 止血 | 復甦後 **24 小時內**做內視鏡（注射、電燒、止血夾）；內視鏡止血後高劑量 PPI；靜脈曲張出血另見肝硬化頁 |
| 藥物 | 血管加壓素或 somatostatin 類：出血停止後要**逐漸減量**，**不可立即停** |
| 鼻胃管 | 評估出血量與清出血塊；課本與技術書寫**冰生理食鹽水（可加腎上腺素）灌洗**止血，現行指引以內視鏡止血為主，冰水灌洗沒有止血證據（**待核對**台灣醫學中心做法；111-1_MS_041 國考答案仍把冰鹽水灌洗視為正確） |

- 112-1_FA_045 管灌前反抽 150 mL 咖啡色液體：要暫停灌食、報告（可能出血），不可打回；管灌見 [[enteral-parenteral-nutrition]]

## 胃癌與胃腸道基質瘤 {#gastric-cancer}

- 危險因子：**幽門螺旋桿菌**、**醃漬、燻烤、高鹽**食物（亞硝胺）、吸菸、萎縮性胃炎與惡性貧血、家族史、胃部分切除後
- 以**腺癌**最常見，好發**胃竇與遠端**；男性、年長者較多
- 表現：早期只有消化不良、上腹不適；晚期體重減輕、貧血、腹部腫塊、左鎖骨上淋巴結(Virchow node)
- 篩檢：國健署 2026 年起 45–74 歲終身一次公費糞便幽門螺旋桿菌抗原檢測（見 [[helicobacter-pylori#diagnosis]]）
- 手術：次全胃切除（Billroth I 胃十二指腸吻合、Billroth II 胃空腸吻合）、全胃切除（食道空腸吻合）
   1. 術後禁食、鼻胃管減壓，腸蠕動恢復後才漸進溫和飲食
   2. **全胃切除**沒有內在因子 → 定期注射 **維生素 B12** 預防惡性貧血
   3. 注意傾倒症候群、吻合處滲漏、輸入環症候群
- **胃腸道基質瘤(GIST)**：起源於 **Cajal 氏間質細胞**，**最好發在胃**、其次小腸；多有 **c-KIT** 或 PDGFRA 突變（可用 imatinib）；預後看腫瘤大小、有絲分裂數與位置

## 傾倒症候群 {#dumping}

- 胃切除（尤其 **Billroth II 胃空腸吻合**）後失去幽門控制，食物**快速進入空腸**；症狀可持續 6–12 個月（《內外科護理學》下冊 p.374–375）

| | **早期** | **晚期** |
|---|---|---|
| 時間 | 飯後 **10–30 分鐘** | 飯後 **2–4 小時** |
| 機轉 | 高張食糜進入空腸 → **細胞外液迅速移入腸道** → **循環血量減少**＋腸道擴張 | 大量醣類快速吸收 → 血糖驟升 → 胰島素分泌過多 → **低血糖** |
| 症狀 | 腹脹、腹痛、噁心嘔吐、腹瀉；**心悸、頭暈**、冒汗、臉潮紅、姿勢性低血壓 | 冒冷汗、顫抖、心悸、飢餓、意識混亂 |

- 預防（國考與課本）
   1. **少量多餐**、細嚼慢嚥
   2. **低醣**（避免甜食與精緻澱粉）、**高蛋白**、**適量脂肪**（國考也接受「高脂肪」）
   3. **乾性食物**；**用餐時不喝湯水**，液體在兩餐之間喝
   4. 進食時**半坐臥**，**飯後躺下**休息 20–30 分鐘（延緩胃排空）；不要飯後立即散步
- 傾倒症候群與基護的治療飲食也連 [[nutrition-assessment-diets]]
