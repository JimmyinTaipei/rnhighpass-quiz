**腦中風**是腦部血管阻塞或破裂，使部分腦組織缺血壞死，突然出現偏癱、口齒不清、失語、視野缺損或意識改變。缺血性中風約占八成以上。治療最重要的是**時間**：越早打通血管，留下的腦組織越多。腦部血液供應與 ACA／MCA／PCA 的症狀見 [[brain-anatomy#blood-supply]]，語言區與失語見 [[brain-anatomy#aphasia]]，抗血小板與溶栓藥見 [[antiplatelets]] 與 [[thrombolytics]]

## 重點摘要 {#summary}

- **缺血性**：**血栓型**（動脈粥狀硬化，常在**休息或睡眠中**發生，常先有 **TIA**、漸進或階梯式惡化）、**栓塞型**（多來自**心房顫動**、瓣膜疾病，**活動中突然**發生）、小洞梗塞（高血壓小血管病變）
- **出血性**：**腦內出血**（**高血壓**最主要）、**蜘蛛膜下腔出血**（多為**漿果型動脈瘤**破裂，突發**最劇烈的頭痛**、頸部僵硬，腦脊髓液**血色**）
- **TIA**：症狀在 24 小時內（多數 1 小時內）完全恢復、影像沒有梗塞，是**中風的警訊**；用**抗血小板藥**(aspirin)
- **辨認中風**：**微笑（臉歪）、舉手（單側無力）、說你好（口齒不清）、快打 119**，記下發作時間
- 急診先做**非顯影電腦斷層**排除出血
- **靜脈溶栓**：**4.5 小時內**，alteplase 或 tenecteplase；禁忌包括**出血**、動脈瘤或動靜脈畸形、近期手術或出血、嚴重肝病與凝血異常
- **取栓**：大血管阻塞，6 小時內；經影像篩選可到 **24 小時**
- **出血性中風**：**不可用溶栓劑與 aspirin**；控制血壓、**軟便劑**(MgO)避免用力、床頭抬高 30 度；蜘蛛膜下腔出血用 **nimodipine** 預防血管痙攣
- **左腦**受損：右側偏癱、**失語**、計算差、動作慢而謹慎；**右腦**受損：左側偏癱、**空間感與認知缺損、單側忽略**、衝動、判斷力差

### 國考常考點 {#exam-points}

- 腦中風危險因子：高血壓、糖尿病、中風病史；**高密度脂蛋白(HDL)過高不是**
- **出血性中風最主要危險因子：高血壓**
- **TIA 是血栓型中風的警訊**；栓塞型症狀**突然**發生；出血性有劇烈頭痛；缺血性（血栓型）**通常在休息時**發作，不是活動時
- 血栓型發病前**有先驅症狀**；栓塞型**多因心臟病**（不是高血壓）；出血型腦脊髓液**不清澈**、多**突然**發作
- rt-PA：可以打通血管、動脈瘤或動靜脈畸形不適用、嚴重肝病不適用；**不是 8 小時內**（是 3–4.5 小時）
- 出血性中風：給 **MgO** 避免便秘；**不可**給溶栓劑或 aspirin；不是平躺
- TIA 用 **aspirin**；中風後 aspirin 100 mg QD 的目的是**抗血小板凝集**
- 左手 3 分、左腳 1 分（下肢重於上肢）→ **右側大腦前動脈**
- **左腦**損傷：計算能力降低、**語言障礙**；**右腦**損傷：**左側偏癱、空間及認知缺損、行動快而衝動**
- 腦幹中風：眼球活動不協調、運動障礙、嘔吐反射減弱；**手顫抖不是**
- 自發性蜘蛛膜下腔出血最常見原因：**動脈瘤破裂**；好發於 Willis 環的是**漿果型動脈瘤**；神經學檢查有 Kernig、Brudzinski、頸部僵硬，**Homan's sign 不是**
- 吞嚥困難：坐姿或高坐臥進食、糊狀食物、進食後抬高床頭；**不要閒聊分散注意力**；食物性狀**最後**才用**液體**
- 擺位：避免長時間高坐臥（髖屈曲畸形）、大腿外側**粗隆捲軸**防外旋、**患側腋下墊枕**防肩內收；**膝下不可墊枕**（膝屈曲畸形）；**腰下不可懸空**；足托板預防垂足
- 意識不清完全臥床：**被動**關節運動，**不是加阻力運動**；肌力 0 分只能被動運動
- 單側忽略：**教導轉頭**代償視野、**鼓勵注意與照顧患側**；**不要常變動擺設**；叫人鈴與電話放**健側**
- 偏癱安全：常用物品放**健側**；床面**降低**（不是搖高）；浴室止滑墊與固定洗澡椅；臥床拉起床欄
- 上下床：床面降到雙腳可著地；不要升高到家屬腰部；漸進下床；防滑鞋
- 量血壓：**不可量患側**與點滴側；左側偏癱又右手打點滴 → **量右下肢**
- 功能性尿失禁：建立表達如廁需求的方法、**白天每 2–3 小時協助如廁**；不要包尿布、不要留置尿管
- 便秘：**早餐後**協助坐馬桶（胃結腸反射）
- 側臥受壓點不是枕骨與骶骨（那是仰臥）；側臥時頭頸脊椎保持**平直**；半坐臥床頭 30–45 度
- 全關節運動：站在**要運動的那一側**、由**近心端到遠心端**、每天至少 2 次；踝關節被動屈曲支托**足背與足後跟**
- 約束：每 2 小時鬆開並改變姿勢；要醫囑**與家屬同意書**；約束帶綁在床架、不可綁床欄

## 種類與原因 {#types}

| 類型 | 機轉 | 好發與特徵 |
|---|---|---|
| **血栓型**（缺血） | 動脈粥狀硬化處形成血栓、逐漸阻塞 | 老人、高血壓、糖尿病、高血脂；**休息或睡眠中**發生（醒來才發現）；常先有 **TIA**；症狀**漸進或階梯式**惡化；意識多清楚 |
| **栓塞型**（缺血） | 栓子（多來自心臟）隨血流卡住腦血管 | **心房顫動**、瓣膜疾病、心肌梗塞後；**活動中突然**發生、症狀一開始就最嚴重 |
| 小洞梗塞（缺血） | 長期高血壓使深部小動脈阻塞 | 症狀較單純（純運動或純感覺） |
| **腦內出血** | 小動脈破裂 | **高血壓**最常見（基底核、視丘）；也有類澱粉血管病變、抗凝血藥、動靜脈畸形；**活動或情緒激動時**突然發生；頭痛、嘔吐、意識快速變差 |
| **蜘蛛膜下腔出血** | 多為**漿果型動脈瘤**破裂（好發 **Willis 環**分叉處） | **突發「一生中最痛」的頭痛**、頸部僵硬（Kernig、Brudzinski 陽性）、嘔吐、意識改變；腦脊髓液**血色**；外傷也會造成 |

- **危險因子**：**高血壓**（最重要）、**心房顫動**、糖尿病、吸菸、**高 LDL 或低 HDL**、肥胖、缺乏運動、過量飲酒、**中風或 TIA 病史**、年齡、家族史
- **TIA**（暫時性腦缺血發作）：短暫局部神經症狀，**24 小時內完全恢復**（多在 1 小時內）、影像沒有梗塞；之後幾天內中風風險高，要立即就醫檢查與用抗血小板藥
- 動靜脈畸形：先天血管團，年輕人出血或癲癇的原因
- 病理：腦梗塞的腦組織發生**液化壞死**（腦富含脂質、少結締組織），數週後形成**囊狀空腔**；心臟與腎臟梗塞則是凝固性壞死

## 臨床表現 {#manifestations}

### 左腦與右腦 {#hemisphere}

| | **左側大腦**（多數人的優勢半球） | **右側大腦** |
|---|---|---|
| 偏癱 | **右側** | **左側** |
| 語言 | **失語症**（表達或理解） | 語言多正常 |
| 認知與行為 | **計算**、邏輯變差；動作**慢而謹慎**、容易焦慮與憂鬱 | **空間與知覺**障礙、**單側忽略**（忽略左側）、判斷力差、**衝動**、高估自己的能力、否認病情 |
| 安全 | 需要溝通輔助 | **跌倒風險高**，要提醒與監督 |

- **同側偏盲**：雙眼同一側的視野看不見 → 物品放在看得到的一側、教病人轉頭掃視
- 大腦前動脈(ACA)阻塞：對側**下肢比上肢無力**；大腦中動脈(MCA)阻塞：對側**臉與上肢較嚴重**、失語或忽略；後循環：視野、眩暈、複視、吞嚥困難（見 [[brain-anatomy#blood-supply]]）
- 腦幹中風：複視、眩暈、構音障礙、**嘔吐反射減弱**、交叉性症狀（見 [[brain-anatomy#brainstem-lesions]]）

## 急性期處置 {#acute-treatment}

1. **辨認與送醫**：微笑、舉手、說你好，**立刻打 119**，記下**最後正常的時間**（睡醒才發現的，以睡前最後正常時間計）
2. **急診**：維持呼吸道與氧合、**驗血糖**（低血糖可模仿中風）、**非顯影電腦斷層**排除出血、評估中風嚴重度(NIHSS)
3. **靜脈溶栓**（缺血性）
   1. **症狀發生 4.5 小時內**：**tenecteplase 0.25 mg/kg（最多 25 mg）單次推注**，或 **alteplase(rt-PA)0.9 mg/kg（最多 90 mg）**，10% 先推、其餘 60 分鐘輸注（來源：[2026 AHA／ASA 急性缺血性中風指引](https://doi.org/10.1161/STR.0000000000000513)）
   2. 國考舊題寫 **3 小時內**；**8 小時是錯的**
   3. **禁忌**（出血風險）：**顱內出血**、蜘蛛膜下腔出血、**動脈瘤或動靜脈畸形**、近期頭部外傷或中風、近期大手術、活動性出血、**嚴重肝病**與凝血異常、血小板過低、使用抗凝血劑、血壓過高無法控制
   4. 護理：給藥前血壓要降到 **< 185/110 mmHg**、之後 24 小時維持 **< 180/105 mmHg**（185/110 待核對 2026 版原文；2026 AHA／ASA 已確認溶栓後不建議把收縮壓降到 < 140，比較的對照組就是 < 180，來源：[2026 AIS 指引](https://professional.heart.org/en/guidelines-statements/2026-guideline-for-the-early-management-of-patients-with-acute-ischemic-strokestr0000000000000513)）；頻繁評估神經學與血壓；觀察**出血**（牙齦、尿、注射處、意識變差、頭痛嘔吐）；**24 小時內不給抗血小板或抗凝血藥**、避免不必要的穿刺與插管
4. **動脈取栓**：大血管阻塞（如內頸動脈、MCA 近端、基底動脈），**6 小時內**；經影像篩選可延到 **24 小時**（來源：[2026 AHA／ASA 急性缺血性中風指引](https://doi.org/10.1161/STR.0000000000000513)；[台灣腦中風學會 2023 取栓指引](https://www1.cgmh.org.tw/intr/intr5/6370Z/guidelines/Taiwan/2_EVT_TW_2023.pdf)）
5. **抗血小板**：沒有溶栓者盡早給 **aspirin**（**抗血小板凝集**、預防再中風）；TIA 與輕微中風短期可合併 clopidogrel；心房顫動造成的栓塞型用**抗凝血劑**預防再發
6. **血壓**：沒有溶栓的缺血性中風通常**允許血壓偏高**，以維持缺血區灌流；溶栓或取栓後**不建議把收縮壓強降到 < 140 mmHg**(2026 AHA／ASA)
7. 維持正常血糖與體溫；預防吸入性肺炎（**吞嚥篩檢**前禁食）與深部靜脈栓塞

::questions{ids="113-3_MS_005,109-2_MS_006"}

### 出血性中風 {#hemorrhagic}

- **不可給溶栓劑**，**不可給 aspirin**（會加重出血；頭痛發燒用 acetaminophen）
- **控制血壓**、矯正抗凝血作用（例如 vitamin K、凝血因子）
- **預防顱內壓升高**：床頭抬高 **30 度**（不是平躺）、頭頸正中、**軟便劑(MgO)**避免用力解便、避免咳嗽與憋氣（見 [[increased-icp#nursing]]）
- 大血腫或小腦出血可能手術清除
- **蜘蛛膜下腔出血（動脈瘤破裂）**（來源：[2023 AHA／ASA 動脈瘤性蜘蛛膜下腔出血指引](https://doi.org/10.1161/STR.0000000000000436)）
  1. **再出血**：多在第一天，要盡早以**栓塞(coiling)或夾閉(clipping)**處理動脈瘤
  2. **動脈瘤預防措施**：絕對安靜、減少刺激與探訪、光線柔和、床頭抬高、軟便劑、止痛、避免用力
  3. **血管痙攣**：出血後約 **3–14 天**最容易發生，造成遲發性腦缺血 → 口服 **nimodipine** 預防；維持正常血量
  4. 其他：**水腦**、**低血鈉**、抽搐
- 動靜脈畸形：手術切除、栓塞或放射手術

::questions{ids="106-2_MS_004,105-1_MS_005"}

## 護理與復健 {#nursing}

### 吞嚥困難 {#dysphagia}

1. **由口進食前先做吞嚥篩檢**；未通過前禁食，必要時鼻胃管
2. **坐直**（坐姿或高坐臥 60–90 度）、頭稍前傾、**下巴內收**再吞
3. 食物從**糊狀、半固體**開始，再到小塊與一般固體，**液體最後**才給（液體流太快最容易嗆）；液體可用增稠劑；鮮魚湯、鮮奶等稀的不適合剛開始練習
4. 食物放在**健側**、小口、慢慢吃、確認吞完再給下一口
5. **環境安靜、不要閒聊**、不要看電視分心
6. 進食後**維持坐姿或抬高床頭 30–60 分鐘**；檢查患側頰內有無殘留食物，做口腔護理

### 擺位、翻身與關節運動 {#positioning}

| 部位 | 做法 | 目的 |
|---|---|---|
| 肩 | **患側腋下墊枕**、手臂外展、手肘伸直、手掌放在枕上略高於手肘 | 防**肩關節內收**攣縮、肩部半脫位與手腫 |
| 髖 | 大腿外側放**粗隆捲軸**（髖部到膝蓋） | 防**髖關節外旋** |
| 膝 | **膝下不墊枕** | 防**膝關節屈曲畸形** |
| 踝 | **足托板**使踝關節維持約 90 度 | 防**垂足** |
| 腰 | 腰部凹處放小枕支撐，**不要懸空** | 維持脊椎生理曲度 |
| 床頭 | **避免長時間高坐臥** | 防髖屈曲畸形 |

- 側臥：頭、頸與脊椎**保持平直**；背後墊枕支撐；胸前抱枕、兩腿之間放枕；保護外側足踝等骨突處；受壓點是耳廓、肩峰、大轉子、膝外側、外踝（**枕骨與骶骨是仰臥**的受壓點）
- 臥位角度：半坐臥床頭約 **30–45 度**、坐臥 45–60 度、高坐臥 60–90 度
- 每 2 小時翻身，**特別注意偏癱側皮膚**；壓力性損傷的評估與預防見 [[pressure-injury#prevention]]
- **關節運動**
  1. 肌力 0–1 分、意識不清 → **被動**全關節運動；**不可做加阻力運動**
  2. 操作者站在**要運動的那一側**、靠近病人；支托關節的**近端與遠端**；由**近心端往遠心端**（肩 → 肘 → 腕）
  3. 每天至少 2 次，每個動作重複數次，在不痛的範圍內
  4. 踝關節屈曲：一手握**足後跟**、另一手握**足背**
  5. 髖關節外展：一手托腳後跟、一手托膝下，伸直往外水平移動
  6. 各關節的動作名詞與運動種類見 [[activity-immobility#rom]]
- 早期下床：漸進（坐起 → 床邊站 → 走）；輪椅放在**健側**、拉好煞車

### 安全、溝通與單側忽略 {#safety}

1. **預防跌倒**：常用物品與**叫人鈴放健側**；床面**降到最低**、鎖住床輪；臥床拉起床欄；浴室止滑墊、固定洗澡椅與扶手；穿防滑鞋；便盆椅不用時收好
2. **單側忽略**
   1. 教導病人**轉頭掃視**患側，代償視野缺損
   2. **鼓勵注意並照顧患側**（穿衣先穿患側、洗患側手臂）
   3. **環境擺設保持固定**，不要常變動
   4. 叫人鈴、電話放**健側**；接近病人時從健側開始，再慢慢引導注意患側
3. **失語症**：問是非題、說話慢而簡短、配合手勢與圖卡、給足夠時間回答（見 [[brain-anatomy#aphasia]]）
4. **量血壓**：**不可量偏癱側**（循環差、讀數不準），也不可量點滴側；兩手都不行時量**下肢**
5. **約束**：只在必要時；需醫囑與家屬同意書；約束帶固定在**床架**而非床欄；**每 2 小時鬆開**、檢查循環並改變姿勢

### 排泄與其他 {#elimination}

- **功能性尿失禁**（膀胱正常，但溝通或行動困難來不及如廁）：建立表達如廁需要的方法、**白天每 2–3 小時協助如廁**；避免長期包尿布與留置導尿管
- **便秘**：**早餐後**利用胃結腸反射協助坐馬桶、足夠水分與纖維、順時針按摩腹部；糞便嵌塞時先指診、油劑保留灌腸
- 憂鬱：中風後常見，影響復健意願
- 再中風預防：控制血壓、血糖、血脂，戒菸，規則服用抗血小板或抗凝血藥
