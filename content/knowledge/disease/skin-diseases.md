本頁整理皮膚病灶的描述、乾癬、常見良性皮膚腫瘤與三種皮膚癌。皮膚構造見 [[skin]]；細菌性皮膚感染見 [[skin-bone-infections]]，帶狀疱疹與單純疱疹見 [[herpesviruses]]，接觸性皮膚炎見 [[allergic-contact-dermatitis-latex]]，蕁麻疹見 [[urticaria-angioedema]]，壓力性損傷見 [[pressure-injury]]，燒傷見 [[burns]]

## 重點摘要 {#summary}

- 病灶分**原發性**(疾病直接造成)與**續發性**(原發病灶演變、搔抓或治療後形成)；**膨疹是原發性**，糜爛、潰瘍、抓痕是續發性
- **乾癬**：慢性、免疫相關、**不會傳染**；表皮增生過快 → **邊界清楚的紅斑＋銀白色鱗屑**；**頭皮、肘膝伸側、下背**，**對稱**；**冬天惡化、夏天日曬改善**；Koebner 現象、Auspitz 徵象
- 良性腫瘤：**脂漏性角化症**(中老年，蠟狀、像黏在皮膚上的褐色斑塊，良性)、表皮囊腫(良性，內含角質)、脂肪瘤、纖維瘤(纖維組織)、蜘蛛狀血管瘤(**雌激素**升高：懷孕、肝硬化)
- 皮膚癌：危險因子**紫外線過度曝曬**、皮膚白皙、免疫抑制、砷、放射線；**確診靠切片**
   1. **基底細胞癌**：**最常見**，臉部，珍珠樣邊緣、中央潰瘍；生長慢、**極少轉移**
   2. **鱗狀細胞癌**：日光性角化症、慢性傷口或疤痕可轉變，可轉移
   3. **黑色素瘤**：黑色素細胞惡化，**轉移快、致死率最高**；用 **ABCDE** 自我檢查痣
- 護理：每天**自我檢查皮膚**；痣出現潰瘍、滲液、出血、痛癢、變大變色 → 就醫；病灶**不要加壓、摩擦**；防曬

### 國考常考點 {#exam-points}

- **膨疹**(Wheal)是原發性病灶；潰瘍、糜爛、抓痕是續發性
- 乾癬是**銀灰色(銀白色)鱗屑**；**對稱**分布；**冬天惡化**(不是夏天出現冬天消失)
- **Koebner 現象**是**皮膚受傷處長出新病灶**；角質層的微小膿瘍是 **Munro 微膿瘍**
- **脂漏性角化症是良性**；表皮囊腫是良性；纖維瘤是纖維組織(脂肪細胞腫瘤是脂肪瘤)；蜘蛛狀血管瘤與**雌激素**有關
- **基底細胞癌最常見，但致死率不是最高**；致死率最高是**黑色素瘤**；基底細胞癌與鱗狀細胞癌共同危險因子是**陽光**
- 皮膚癌預防：長時間曬太陽**要重複塗抹**防曬乳；**陰天也要防曬**；曬傷可冷水浸泡
- 皮膚惡性腫瘤病灶**不可加壓**；每日檢查皮膚；減少曝曬
- 臭氧層變薄 → 紫外線增加 → 皮膚癌、白內障增加(見 [[environmental-food-hygiene]])

## 皮膚病灶 {#lesions}

### 原發性病灶 {#primary-lesions}

| 病灶 | 特徵 | 例子 |
|---|---|---|
| **斑疹**(Macule) | 平坦、只有顏色改變，< 1 cm；> 1 cm 稱斑片 | 雀斑、麻疹早期 |
| **丘疹**(Papule) | 隆起、實心，< 1 cm | 痣、疣 |
| **斑塊**(Plaque) | 隆起、扁平、> 1 cm，常由丘疹融合 | **乾癬** |
| **結節**(Nodule) | 實心，較深，1–2 cm；更大稱腫瘤 | 脂肪瘤 |
| **水泡**(Vesicle) | 含清澈液體，< 1 cm；> 1 cm 稱**大水泡**(Bulla) | 帶狀疱疹、淺二度燒傷 |
| **膿疱**(Pustule) | 含膿液 | 青春痘、毛囊炎 |
| **膨疹**(Wheal) | **真皮水腫**造成短暫隆起，邊界清楚、形狀不規則、**癢**，數小時內消退 | **蕁麻疹**、蚊蟲叮咬 |

- 大小切點各書不一(0.5 或 1 cm)，本表依常用教科書(待核對)

### 續發性病灶 {#secondary-lesions}

| 病灶 | 特徵 |
|---|---|
| **鱗屑**(Scale) | 角質層脫落的碎片，如乾癬、頭皮屑 |
| **痂皮**(Crust) | 血清、膿或血乾掉 |
| **糜爛**(Erosion) | **表皮流失**，潮濕、界線清楚的淺凹，癒合**不留疤** |
| **潰瘍**(Ulcer) | 缺損**深達真皮或皮下**，癒合**留疤** |
| **抓痕**(Excoriation) | 搔抓造成線狀、深淺不一的表皮缺損 |
| **裂隙**(Fissure) | 線狀裂開深達真皮，如手足皸裂 |
| **苔蘚化**(Lichenification) | 長期搔抓使皮膚**增厚、紋路變深**，如慢性濕疹 |
| **疤痕**、**萎縮** | 真皮受損後纖維化；皮膚變薄、發亮 |

## 乾癬 {#psoriasis}

- 機轉：免疫(T 細胞)相關的慢性發炎，**表皮細胞增生過快**(更新週期縮短到數天)，角質來不及成熟就堆積成鱗屑；有遺傳傾向；**不會傳染**
- 誘發或惡化：皮膚外傷、感染(鏈球菌咽炎)、壓力、**冬天乾冷**、抽菸飲酒、某些藥物(鋰鹽、乙型阻斷劑)、突然停用全身性類固醇
- 表現
   1. **邊界清楚的紅色斑塊**，上覆**銀白色鱗屑**，刮除後見點狀出血(**Auspitz 徵象**)
   2. 好發**頭皮、肘與膝伸側、下背、臀溝**，**對稱**分布
   3. **Koebner 現象**：在**外傷、搔抓**的皮膚上長出新病灶
   4. 指甲凹陷、甲剝離；部分病人合併**乾癬性關節炎**
   5. 病理：角質層內中性球聚集成 **Munro 微膿瘍**
- 治療：局部類固醇、**維生素 D 衍生物**、焦油、角質軟化劑；**光照治療**(窄波 UVB，或口服補骨脂素再照 UVA 即 PUVA)；全身性 methotrexate、cyclosporine、生物製劑
- 護理：避免抓傷與摩擦皮膚(Koebner)、保濕、溫水洗澡、軟化鱗屑後輕輕去除；PUVA 當天**戴太陽眼鏡、避免日曬**；疾病不會傳染，協助處理身體心象與社交退縮

## 良性皮膚腫瘤 {#benign-tumors}

| 腫瘤 | 來源與特徵 |
|---|---|
| **脂漏性角化症** | **良性**表皮角質細胞增生；中老年人臉、軀幹；褐到黑色、**蠟狀、像貼在皮膚上**的疣狀斑塊；不會惡化，可冷凍或雷射去除 |
| **表皮囊腫** | **良性**，表皮陷入真皮形成囊，內含乳白色有臭味的**角質**碎屑 |
| **脂肪瘤** | 脂肪細胞的良性腫瘤，柔軟可推動 |
| **纖維瘤** | **纖維結締組織**增生(不是脂肪) |
| **蜘蛛狀血管瘤** | 中央小動脈向外放射的細小血管，壓迫會變白；與**雌激素**升高有關(懷孕、**肝硬化**，見 [[liver-cirrhosis]]) |
| **日光性角化症** | 長期日曬部位的粗糙紅色鱗屑斑，屬**癌前病變**，可轉變為鱗狀細胞癌 |

## 皮膚癌 {#skin-cancer}

| | 基底細胞癌 | 鱗狀細胞癌 | 黑色素瘤 |
|---|---|---|---|
| 來源 | 表皮基底細胞 | 表皮角質細胞 | **黑色素細胞** |
| 頻率 | **最常見** | 第二常見 | 較少 |
| 部位 | **臉**(鼻、眼周)等日曬處 | 日曬處、唇、慢性傷口或燒傷疤痕 | 白人多在軀幹與腿；**亞洲人常見於手掌、腳底、指甲**(肢端型) |
| 外觀 | **珍珠樣**隆起邊緣、中央潰瘍、微血管擴張 | 角化、鱗屑的結節，易潰爛 | 顏色不均的痣樣病灶 |
| 轉移 | **極少轉移**，局部侵犯 | 可轉移 | **早期轉移**，**致死率最高** |

- 危險因子：**紫外線過度曝曬**(兩種角質細胞癌的共同危險因子)、白皙易曬傷、多次嚴重曬傷(尤其兒童時期)、免疫抑制、砷、放射線；黑色素瘤還有多發或異常痣、家族史
- 診斷：**切片檢查**；治療以手術切除為主(Mohs 手術可保留較多正常組織)
- **ABCDE** 檢查痣：**A**symmetry 不對稱、**B**order 邊緣不規則、**C**olor 顏色不均、**D**iameter 直徑 > 6 mm、**E**volving 大小形狀顏色在變化(或隆起)
- 癌症的一般治療與照護見 [[cancer]]

::questions{ids="105-1_MS_045"}

### 預防與護理 {#prevention}

1. 防曬
   1. 避免上午 10 點到下午 4 點的強烈陽光(待核對：國健署多寫 10–14 點)；**陰天也要防曬**(紫外線可穿透雲層)
   2. 穿長袖、戴寬邊帽與太陽眼鏡
   3. 防曬乳：國考題寫 **SPF 15 以上、長時間在陽光下要重複塗抹**；美國皮膚科學會現行建議**廣效、SPF 30 以上、防水**，出門前約 15 分鐘塗，戶外**約每 2 小時**或游泳流汗後**補擦**
   4. 曬傷可用冷水浸泡或冷敷緩解
2. 每天或定期**自我檢查皮膚**(用鏡子看背部、頭皮、腳底)；痣有**潰瘍、滲液、出血、痛癢**或 ABCDE 改變就要就醫
3. 病灶照護：保持清潔，**不要加壓、摩擦或刺激**病灶
4. 紫外線的健康危害見 [[environmental-injury#ultraviolet]]
