糖尿病是一群以**慢性高血糖**為共同特徵的代謝疾病,原因是胰島素**分泌不足**、**作用不良(胰島素阻抗)**或兩者皆有。長期高血糖會傷害大、小血管與神經,是國人洗腎、失明與非外傷性截肢的主要原因之一。

本頁依「生理 → 病理 → 分類與診斷 → 併發症 → 檢驗 → 藥物 → 治療 → 護理 → 飲食與預防」排列。藥物、檢驗與生理機轉各有獨立頁面,本頁以**嵌入**(左側藍線)或**連結**的方式引用,內容只維護一份。

## 血糖調控的生理 {#physiology}

血糖由「降血糖的**胰島素**」與「升血糖的**反調節激素**」維持在空腹約 70–99 mg/dL。詳細機轉見 [[glucose-homeostasis]];這裡只列出和疾病、用藥直接相關的重點。

### 反調節激素 {#counter-regulatory}

- **升糖素**(glucagon)、**腎上腺素**、**皮質醇**、**生長激素**、甲狀腺素都會升高血糖;臨床上「壓力、感染、手術、類固醇」會讓血糖上升,就是透過這些激素。詳見 [[glucose-homeostasis#counter-regulation]]。
- 醛固酮、抑制素(inhibin)對血糖幾乎沒有影響——國考常拿來當「無關」的選項。

## 病理生理 {#pathophysiology}

### 第一型:絕對缺乏胰島素 {#patho-type1}

- **自體免疫**(T 細胞媒介,屬第四型過敏反應)破壞胰島 β 細胞,病理上可見胰島炎(insulitis,蘭氏小島發炎)。
- 血中可測到**自體抗體**:抗 GAD65、胰島細胞抗體(ICA)、胰島素自體抗體(IAA)、IA-2、ZnT8。
- 與 **HLA-DR3 / DR4** 基因型有關;常在病毒感染後出現症狀。
- β 細胞剩下約 10–20% 時才出現症狀,因此發病看似「突然」:三多一少、體重減輕,常以**酮酸中毒**為第一次表現。
- **C-胜肽(C-peptide)很低或測不到**——代表自己幾乎不再製造胰島素(見本節末的說明)。

### 第二型:胰島素阻抗 + β 細胞功能逐漸衰退 {#patho-type2}

- **胰島素阻抗**:肌肉、脂肪、肝臟對胰島素反應變差(受體數目減少、受體後訊息傳遞缺陷,GLUT4 轉位不足)。內臟脂肪釋出游離脂肪酸與發炎激素是主要推手。
- 初期胰臟以**高胰島素血症**代償,血糖仍正常;β 細胞長期過勞、糖毒性與脂毒性、**類澱粉(amylin)沉積**使分泌能力逐漸下降,血糖才開始升高。
- β 細胞數目早期**沒有明顯減少**;需要胰島素治療通常是病程多年後的事。
- **多基因遺傳**,與家族史、肥胖、缺乏運動、年齡相關;與 HLA、自體免疫無關。
- 因為仍有少量胰島素足以抑制脂肪分解,較少發生酮酸中毒,急性併發症以 **HHS** 為代表。

### 高血糖如何傷害組織 {#hyperglycemia-damage}

| 機轉 | 說明 | 相關併發症 |
|---|---|---|
| 多元醇路徑 | 醛糖還原酶把葡萄糖轉成山梨醇(sorbitol),細胞內滲透壓上升 | 神經病變、白內障 |
| 糖化終產物(AGEs) | 葡萄糖與蛋白質非酵素性結合(與 [[hba1c]] 同原理) | 血管壁變硬、基底膜增厚 |
| 蛋白激酶 C 活化、氧化壓力 | 血管通透性與新生血管因子改變 | 視網膜病變、腎病變 |
| 滲透性利尿 | 血糖超過腎閾值(約 180 mg/dL)→ 尿糖 → 帶走水分與電解質 | 多尿、口渴、脫水 |

腎臟病理:腎絲球**基底膜增厚**、系膜擴張,典型為**結節性腎絲球硬化**(Kimmelstiel–Wilson nodule)。

:::note[C-胜肽是什麼]
胰島素原(proinsulin)切割後產生**等量**的胰島素與 C-胜肽。外源注射的胰島素不含 C-胜肽,所以 C-胜肽可用來評估「自己還能分泌多少胰島素」,也可區分低血糖是注射過量(胰島素高、C-胜肽低)還是胰島素瘤/磺醯脲類(兩者都高)。
:::

## 分類與診斷 {#classification}

### 分類 {#types}

#### 第一型糖尿病 {#type1}

約占 5–10%。多發生於兒童、青少年(學齡期到青春期為高峰),體型偏瘦,需**終身胰島素**治療。成人緩慢發生的自體免疫型稱為 LADA。

::questions{tag="第一型糖尿病|第1型糖尿病" limit="8"}

#### 第二型糖尿病 {#type2}

約占 90% 以上。多見於成人、肥胖者,但因兒童肥胖增加,**青少年第二型**也在上升。病程緩慢,初期常**無症狀**,常在健檢時才被發現,診斷時可能已有併發症。

::questions{tag="糖尿病|第二型糖尿病" keyword="第 ?(2|二) ?型" limit="8"}

#### 妊娠糖尿病 {#gdm}

**懷孕中才首次**出現的高血糖(懷孕前即有糖尿病者稱「妊娠前糖尿病」,不是 GDM)。

- **原因**:胎盤分泌的**人類胎盤泌乳素(hPL)**、黃體素、皮質醇等造成胰島素阻抗,於**懷孕中後期**(24 週後)最明顯,因此胰島素需求量隨週數增加;**產後胎盤娩出,需求量驟降**。
- **篩檢**:懷孕 **24–28 週**做 [[ogtt#gdm-criteria|口服葡萄糖耐受試驗]];有高危險因子(肥胖、前胎 GDM、曾生巨嬰、家族史)者第一次產檢就要驗血糖。
- **治療**:飲食與運動為先,不足時用**胰島素**(不經胎盤);口服藥非首選。
- **對胎兒/新生兒的影響**:母體葡萄糖可通過胎盤、胰島素不能 → 胎兒自行分泌大量胰島素(高胰島素血症)→
  - **巨嬰**(>4,000 g)、肩難產
  - 出生後母體糖分來源中斷但胰島素仍高 → **新生兒低血糖**
  - 呼吸窘迫症候群(胰島素抑制表面張力素成熟)、紅血球增多症、高膽紅素血症、**低血鈣**
  - **羊水過多**(胎兒多尿)
- **妊娠前糖尿病**若在器官形成期血糖控制不佳,**先天畸形**(心臟、神經管、尾端退化症候群)風險上升,所以懷孕前應先把 [[hba1c#targets|HbA1c]] 控制在 6.5% 以下。
- **產後追蹤**:產後 4–12 週再做 75 g OGTT,之後每 1–3 年追蹤;未來第二型糖尿病風險高,下一胎第一次產檢就應篩檢。
- 產後避孕:含雌激素的口服避孕藥會影響血糖,常以保險套等屏障法為優先建議。

::questions{tag="妊娠糖尿病" limit="10"}

#### 其他特定型 {#other-types}

| 類別 | 例子 |
|---|---|
| 單基因缺陷 | MODY(年輕人成年型糖尿病)、新生兒糖尿病 |
| 胰臟外分泌疾病 | 慢性胰臟炎、胰臟切除、囊性纖維化、血色素沉積症 |
| 內分泌疾病 | 庫欣氏症候群、肢端肥大症、嗜鉻細胞瘤、升糖素瘤、甲狀腺機能亢進 |
| 藥物引起 | **類固醇**、thiazide 利尿劑、**第二代抗精神病藥(clozapine、olanzapine)**、tacrolimus、部分 HIV 用藥 |

長期使用 clozapine 需定期監測體重、空腹血糖與血脂(代謝症候群),但精神症狀穩定時不宜驟然停藥。

### 診斷標準 {#diagnosis}

符合下列**任一項**即可診斷(沒有典型症狀時需**另一天重複**確認,或同一次抽血兩項都異常):

| 檢驗 | 糖尿病 | 糖尿病前期 | 正常 |
|---|---|---|---|
| [[hba1c]] | **≥ 6.5%** | 5.7–6.4% | < 5.7% |
| [[blood-glucose#fasting\|空腹血漿血糖]](禁食 ≥ 8 小時) | **≥ 126 mg/dL** | 100–125(空腹血糖偏高 IFG) | < 100 |
| [[ogtt]] 第 2 小時血糖 | **≥ 200 mg/dL** | 140–199(葡萄糖耐受不良 IGT) | < 140 |
| [[blood-glucose#random\|隨機血糖]] | **≥ 200 mg/dL** 且有典型症狀 | — | — |

:::exam[國考重點]
- 空腹 **126**、隨機/OGTT 2 小時 **200**、HbA1c **6.5%** 三個數字最常考。
- 「HbA1c ≥ 6.0% 即可確診」「空腹 110 可診斷」都是錯的。
- 代謝症候群的血糖標準是空腹 **≥ 100 mg/dL**,與糖尿病的 126 不同。
:::

## 併發症與處理 {#complications}

### 急性併發症 {#acute}

#### 低血糖 {#hypoglycemia}

**定義**:血糖 < 70 mg/dL(第 1 級);< 54 mg/dL 為臨床顯著(第 2 級);需要他人協助處理者為嚴重(第 3 級)。

**原因**:胰島素或[[sulfonylureas|磺醯脲類]]過量、進食延遲或太少、運動量增加、飲酒(抑制肝臟糖質新生)、腎功能變差(藥物清除變慢)。好發於**胰島素作用高峰**、**餐前**與**運動後**。

**表現**

| 類型 | 機轉 | 症狀 |
|---|---|---|
| 交感神經(腎上腺素)症狀 | 血糖下降 → 腎上腺素釋放 | **冒冷汗、手抖(震顫)、心悸、心跳過快**、飢餓、焦慮、皮膚濕冷蒼白 |
| 神經缺糖症狀 | 腦部缺乏葡萄糖 | **頭痛、複視/視力模糊**、注意力不集中、反應遲鈍、行為改變、抽搐、昏迷 |

長期糖尿病有自主神經病變,或服用 **β 阻斷劑**者,交感症狀會被遮蔽(低血糖無感)。低血糖可在短時間內造成腦部永久傷害,**危險性比酮酸中毒更高**。

**處理:15-15 原則**

1. 意識清楚:立即吃 **15 g 快速吸收的醣類**(葡萄糖片 3–4 片、果汁或含糖飲料 120–150 mL、方糖 3 顆),**15 分鐘後再測**,仍 < 70 就重複。
2. 血糖回升後,若距離下一餐超過 1 小時,補充含複合醣類與蛋白質的點心(如麵包、牛奶)避免再掉。
3. 意識不清、無法吞嚥:**不可經口餵食**(吸入危險);靜脈注射 **50% 葡萄糖 20–50 mL**,或肌肉/皮下注射**升糖素 1 mg**(居家可由家屬施打)。
4. 服用 [[alpha-glucosidase-inhibitors|α-葡萄糖苷酶抑制劑]] 者發生低血糖,要給**葡萄糖**,蔗糖分解被抑制、效果差。

::questions{tag="低血糖|低血糖症" limit="10"}

#### 糖尿病酮酸中毒(DKA) {#dka}

**機轉**:胰島素**嚴重缺乏** + 反調節激素上升 →

1. 葡萄糖無法利用、肝臟持續產糖 → 高血糖 → 滲透性利尿 → **多尿(初期尿量增加)、脫水**、電解質流失
2. 脂肪大量分解 → 游離脂肪酸在肝臟轉成**酮體** → **代謝性酸中毒**(陰離子間隙增加)

**誘因**:第一型病人**中斷胰島素**最常見;感染、急性疾病、手術、壓力;第一型以 DKA 首次發病;使用 [[sglt2-inhibitors#adverse-effects|SGLT2 抑制劑]] 可發生血糖不高的酮酸中毒。

**表現**:數小時至 1–2 天內快速發生;口渴、多尿、噁心嘔吐、**腹痛**、**庫斯毛耳氏呼吸(Kussmaul:深而快)**以排出 CO₂ 代償、**呼氣有水果(丙酮)味**、皮膚乾燥潮紅、心跳快、血壓低,嚴重時意識障礙。

**處置**(順序很重要)

1. **補充水分**:先給等張 **0.9% 生理食鹽水**(第一小時約 1–1.5 L),之後依鈉濃度改 0.45% 食鹽水。
2. **補鉀**:酸中毒時鉀移出細胞,血鉀常「正常或偏高」,但全身總鉀其實不足;給胰島素後鉀會移回細胞內 → **低血鉀**。確認**有尿**後依血鉀補充;血鉀 < 3.3 mEq/L 時要先補鉀再給胰島素。
3. **胰島素**:**靜脈連續輸注短效胰島素(RI)**,低劑量開始(約 0.1 U/kg/h)——不用皮下注射大劑量(脫水時皮下吸收不穩定)。
4. 血糖降到約 **200–250 mg/dL** 時,輸液加入**葡萄糖**(如 D5 ½NS),繼續給胰島素直到**酸中毒矯正、酮體清除**——胰島素的目標是停止酮體產生,不只是降血糖(教科書版本數值略有差異,300 mg/dL 也常見)。
5. **重碳酸鈉**:一般不給,只在嚴重酸中毒(pH < 6.9–7.0)才考慮。
6. 監測:每小時血糖、生命徵象、意識、輸出入量;每 2–4 小時電解質與 [[abg|動脈血氣]];注意過快降血糖或補液造成腦水腫(兒童尤其)。

::questions{tag="糖尿病酮酸中毒|酮酸中毒" limit="12"}

#### 高滲透壓高血糖狀態(HHS) {#hhs}

**機轉**:仍有少量胰島素 → 足以抑制脂肪分解(**無或微量酮體**),但不足以控制血糖 → 血糖極高(常 > 600,可 > 800 mg/dL)→ 嚴重**滲透性利尿** → **極度脫水**、血漿滲透壓 > 320 mOsm/kg → 神經症狀。

**族群與誘因**:**第二型**、**老年人**(口渴感差、喝水不易)、感染(肺炎、泌尿道)、急性疾病、藥物(類固醇、thiazide)、**全靜脈營養(TPN)**、飲水不足。

**表現**:數天到數週緩慢發生;嚴重脫水(皮膚黏膜乾燥、溫暖潮紅、心搏過速、低血壓、休克)、意識改變甚至昏迷、局部神經症狀或癲癇;**沒有 Kussmaul 呼吸、沒有水果味**。

**處置**:同 DKA 原則,但**補液量更多**(脫水更嚴重,平均缺水 8–10 L)是首要;胰島素需求通常較少;同樣要補鉀;血糖降至約 300 mg/dL 加入葡萄糖;預防血栓。死亡率高於 DKA。

::questions{tag="高滲透壓高血糖狀態|高血糖高滲透壓狀態|高滲透度高血糖狀態|高血糖高滲透壓症候群" limit="10"}

#### DKA 與 HHS 比較 {#dka-vs-hhs}

| 項目 | DKA | HHS |
|---|---|---|
| 好發 | 第一型、年輕 | 第二型、老年 |
| 發生速度 | 快(< 24 小時) | 慢(數天–數週) |
| 血糖 | > 250 mg/dL | > 600 mg/dL |
| 動脈 pH | **< 7.30** | > 7.30 |
| HCO₃⁻ | **< 18 mEq/L** | > 18 mEq/L |
| 血/尿酮體 | **明顯陽性** | 無或微量 |
| 有效血漿滲透壓 | 不定(常 < 320) | **> 320 mOsm/kg** |
| 陰離子間隙 | > 10–12 | 不定 |
| 呼吸 | **Kussmaul、水果味** | 無特殊 |
| 脫水 | 中度 | **極嚴重** |
| 治療重點 | 胰島素停止酮體生成 + 補液補鉀 | **大量補液** + 胰島素 + 補鉀 |

檢驗細節見 [[ketones]]、[[abg#dka-pattern]]。

#### 清晨高血糖:蘇莫吉效應與黎明現象 {#somogyi}

| | 蘇莫吉效應(Somogyi effect) | 黎明現象(dawn phenomenon) |
|---|---|---|
| 機轉 | 夜間(凌晨 2–3 點)**低血糖** → 反調節激素 → 清晨**反彈性高血糖** | 清晨生長激素、皮質醇分泌 → 清晨高血糖,夜間沒有低血糖 |
| 常見原因 | 晚間/睡前**胰島素劑量過多**、晚餐吃太少 | 生理性;胰島素在清晨作用不足 |
| 分辨 | 測**凌晨 2–3 點血糖**:偏低 | 凌晨 2–3 點血糖正常或偏高 |
| 處理 | **減少**晚間胰島素、睡前點心 | 調整晚間 NPH 時間或增加劑量 |

::questions{keyword="(蘇莫吉|Somogyi|黎明現象)" limit="4"}

### 慢性併發症 {#chronic}

大血管病變(冠心病、腦中風、周邊動脈疾病)是糖尿病最主要的**死因**;小血管病變(視網膜、腎臟、神經)與血糖控制程度最直接相關。

#### 糖尿病視網膜病變 {#retinopathy}

- **非增殖性**:微血管瘤(最早)、點狀出血、硬性滲出物、棉絮狀斑。
- **增殖性**:視網膜缺血 → **新生血管**(易破裂)→ 玻璃體出血、**牽引性視網膜剝離** → 失明。
- **黃斑部水腫**:可發生在任何階段,影響中心視力。
- 治療:嚴格控制血糖血壓;抗血管新生因子(anti-VEGF)眼內注射;**雷射光凝固治療可延緩惡化,但無法恢復已失去的視力**;玻璃體切除術。
- 篩檢:第二型診斷時、第一型診斷 5 年內開始,之後**每年**散瞳眼底檢查。

::questions{tag="糖尿病視網膜病變" keyword="視網膜" limit="6"}

#### 糖尿病腎病變 {#nephropathy}

- 國內洗腎(末期腎病)最主要原因。
- 最早可偵測的變化是**白蛋白尿**(舊稱微量白蛋白尿:每日 30–300 mg,見 [[uacr]]),之後 eGFR 逐漸下降。
- 病理:腎絲球**基底膜增厚**、通透性增加(不是變薄)、結節性腎絲球硬化。
- 處置:HbA1c 約 7%;**血壓 < 130/80 mmHg**;**ACEI/ARB**(降低腎絲球內壓、減少蛋白尿);[[sglt2-inhibitors|SGLT2 抑制劑]];蛋白質約 **0.8 g/kg/天**(不宜高蛋白);避免腎毒性藥物與顯影劑。
- 每年檢查 UACR 與 eGFR。

::questions{tag="糖尿病腎病變" keyword="腎" limit="6"}

#### 糖尿病神經病變 {#neuropathy}

- **遠端對稱性多發神經病變**(最常見):襪套–手套分布的麻木、刺痛、燒灼感,**震動覺、溫度覺、痛覺喪失**、腳踝反射**減弱或消失**(不是亢進)→ 足部受傷而不自知。
- **自主神經病變**:姿勢性低血壓、胃輕癱(胃排空延遲 → 血糖難預測)、神經性膀胱、腹瀉/便秘、勃起功能障礙、**低血糖無感**、無痛性心肌梗塞。
- 篩檢:每年用 **10 g 單纖維尼龍絲**(monofilament)與 128 Hz 音叉評估足部感覺。

#### 糖尿病足 {#diabetic-foot}

神經病變(感覺喪失、足部變形)+ 周邊血管疾病(缺血、傷口難癒合)+ 感染 → 潰瘍、蜂窩性組織炎、骨髓炎、壞疽,嚴重需截肢。足部照護見 [[#foot-care]]。

::questions{tag="糖尿病足|糖尿病足部病變|糖尿病" keyword="(足部|足趾|趾甲|雞眼|糖尿病足)" limit="10"}

#### 大血管病變與其他 {#macrovascular}

- 冠狀動脈疾病、腦血管疾病、周邊動脈疾病:高血壓、血脂異常、吸菸會加乘風險。
- 感染:白血球功能下降、血流差 → 易有泌尿道感染、黴菌感染、傷口感染;**鼻腦白黴菌症**(mucormycosis)好發於控制不良或酮酸中毒病人。
- 牙周病、皮膚病變(黑色棘皮症代表胰島素阻抗)。

## 治療策略 {#treatment}

### 共通原則 {#treatment-principles}

治療的五大支柱:**飲食、運動、藥物、血糖監測、衛教**,缺一不可。目標是控制血糖同時避免低血糖,並積極控制血壓、血脂、戒菸以預防大血管病變。

### 第一型糖尿病 {#treatment-type1}

- **必須用胰島素**,口服降血糖藥無效。
- 採「基礎–餐前」(basal–bolus)模式模擬生理分泌:長效胰島素提供基礎量 + 每餐前速效/短效胰島素;或使用胰島素幫浦(持續皮下輸注)。
- 依醣類計算與運動量調整餐前劑量;搭配連續血糖監測(CGM)。
- 兒童青少年:鼓勵正常參與學校與社交活動、體育課,家屬與學校共同照護(見 [[#school-community]])。

### 第二型糖尿病 {#treatment-type2}

1. 生活型態調整(減重 5–10%、飲食、運動)從診斷當天開始。
2. **第一線藥物:[[metformin]]**(無禁忌症時)。
3. 依**共病**選擇加上的藥物,不只看血糖:
   - 有**動脈硬化心血管疾病** → 優先選已證實心血管益處的 [[glp1-receptor-agonists|GLP-1 RA]] 或 [[sglt2-inhibitors|SGLT2i]]
   - 有**心衰竭**或**慢性腎臟病** → 優先 [[sglt2-inhibitors|SGLT2i]]
   - 需要**減重** → GLP-1 RA 或 GIP/GLP-1 雙重促效劑
   - 需要**避免低血糖**(老人、獨居)→ 避免磺醯脲類
   - 考量**費用** → 磺醯脲類、TZD 較便宜
4. HbA1c 明顯偏高(如 > 10%)、有明顯高血糖症狀或體重下降、急性疾病、手術或懷孕時,使用**胰島素**。住院中暫時改用胰島素,不代表「一旦打了就終生要打」。

### 生病與手術時 {#sick-day}

- **不可自行停用胰島素**:感染、發燒、外傷、壓力使反調節激素上升,胰島素需求常**增加**。
- 但若只是**食慾不振、吃得少**,不應增加胰島素劑量(會低血糖),須依血糖調整。
- 每 3–4 小時測血糖;第一型血糖 > 250 mg/dL 時測酮體。
- 多喝水;無法進食時以含醣流質(果汁、運動飲料)維持每小時約 15 g 醣類。
- 嘔吐、腹瀉、脫水時,暫停可能造成腎傷害或酮酸中毒的藥物([[metformin]]、[[sglt2-inhibitors]]、利尿劑、ACEI/ARB、NSAIDs),病況改善再恢復——須依醫囑。
- 持續嘔吐、無法進食、酮體中度以上、意識改變 → 立即就醫。

### 臨床護理 {#nursing-clinical}

#### 胰島素給藥 {#nursing-insulin}

#### 自我血糖監測(SMBG) {#smbg}

- 頻率依治療方式:**使用胰島素者每天 2–4 次以上**(多次注射者每餐前與睡前);口服藥控制穩定者頻率較低。
- 時機:餐前、餐後 2 小時、睡前,懷疑低血糖時,運動前後,生病時;懷疑蘇莫吉效應時加測凌晨 2–3 點。
- 技巧:溫水洗手擦乾(酒精未乾會影響結果)、採**指腹側面**(神經較少)、輪換手指、不要用力擠壓;記錄數值與飲食、運動、用藥供回診調整。
- 各種干擾因素見 [[blood-glucose#interference]]。

#### 足部照護 {#foot-care}

| 應該 | 不應該 |
|---|---|
| **每天檢查**雙腳(包含腳底、趾縫),看不到腳底用**鏡子**或請家人協助 | 赤腳走路(包括室內)、穿拖鞋或涼鞋外出 |
| 用 **37°C 以下溫水**清洗,先用**手肘或溫度計**測水溫(腳感覺遲鈍) | 長時間泡腳;用**熱水袋、電毯、暖暖包**直接熱敷 |
| 徹底擦乾,**尤其趾縫** | 在**趾縫擦乳液**(潮濕易黴菌感染) |
| 乾燥處擦乳液(腳跟、腳背) | **自行用刀片或剪刀割除雞眼、硬繭**,或用雞眼藥膏 |
| 趾甲**平剪(直線)**、用銼刀修邊角,不剪太短 | 剪成圓弧、挖趾甲邊的肉 |
| 穿**淺色、棉質**吸汗的襪子,每天更換 | 穿有破洞、太緊的襪子(鬆緊帶勒住血流) |
| 穿**包覆性、楦頭寬**的合腳鞋子;**穿鞋前檢查鞋內異物**;傍晚腳最腫時買鞋 | 新鞋一次穿一整天 |
| 發現傷口:清水/生理食鹽水沖洗、無菌敷料覆蓋、**儘速就醫** | 自行處理、等它自己好 |
| 戒菸、控制血糖與血脂 | |

教學方法:足部檢查屬於**技能**,最適合**示範教學 + 回覆示教**。

#### 住院與急性期 {#nursing-acute}

- 低血糖、DKA、HHS 的處置見 [[#acute]];監測意識、生命徵象、輸出入量、電解質(特別是**鉀**)。
- 胰島素注射前確認病人**用餐時間**(RI 於飯前 30 分鐘),禁食檢查時與醫師確認劑量。
- 胰島素屬**高警訊藥物**:給藥前核對病人與醫囑,避免給錯人(若家屬質疑「病人沒有糖尿病」而及時攔下,屬於跡近錯失)。
- 傷口照護:血糖控制不良會延遲癒合;設定傷口目標要具體、可測量(例如兩週內縮小至某尺寸)。
- 與營養師共同擬定住院飲食,屬於**協同性(相互依賴性)護理功能**。

### 社區與學校護理 {#school-community}

- **學校**:
  - 糖尿病學童**不應被禁止上體育課**或減少社交活動;鼓勵正常參與,並讓學童**隨身攜帶糖果、果汁**。
  - 校園低血糖好發於**餐前與運動後**;出現冒冷汗、手抖時,先測血糖,若 < 70 mg/dL 立即給 15 g 快速醣類(如果汁),**15 分鐘後再測**。學校護理師到場應攜帶**血糖機、葡萄糖片、血壓計**。
  - 運動前可先吃少量點心(如一片花生醬麵包、2–3 顆牛奶糖);胰島素注射後約 60–90 分鐘、避開作用高峰再運動,不要注射在即將運動的肢體;不建議睡前劇烈運動(夜間低血糖)。
  - 學校護理師做個案管理:了解用藥、指導高/低血糖處理、經醫囑備妥緊急用品;在學童與家長**同意後**才向同學進行衛教。
  - 以家庭為中心、增能(empowerment):讓父母參與治療與檢查過程,逐步讓孩子學會自我照顧(自我注射屬技能,需反覆練習——熟練原則)。
- **社區個案管理**:
  - 最需要持續管理的是**血糖不穩又不遵從服藥**的個案。
  - 老年個案、教育程度較低者學習注射技巧宜用**個別指導**與示範回示教。
  - 資源:健保**糖尿病共同照護網**、醫療給付改善方案、糖尿病友團體(屬於互動性社區)、長照資源(居家護理、交通接送、輔具);**傷口清創屬醫療處置,不能由居家照服員執行**。
  - 健康信念模式、健康促進模式常以糖尿病情境出題:例如個案認為「不就醫也沒關係」→ 加強**嚴重性認知**;「我知道我做得到」→ **自覺自我效能**。

::questions{tag="糖尿病|第一型糖尿病|第1型糖尿病" keyword="(學童|學校|學生|社區|個案管理|家訪|長照)" limit="10"}

## 飲食控制、運動與預防 {#lifestyle}

### 飲食原則 {#diet}

| 營養素 | 建議(占總熱量) | 說明 |
|---|---|---|
| 醣類 | 約 **45–60%** | 個別化;以全穀、蔬菜、豆類為主,限制精製糖與含糖飲料;**不需要完全禁止澱粉** |
| 蛋白質 | 約 **15–20%** | 腎病變者約 0.8 g/kg/天 |
| 脂肪 | 約 **20–35%** | **飽和脂肪 < 7–10%**,避免反式脂肪 |
| 膽固醇 | < 200–300 mg/天 | 國考常見「< 300 mg」 |
| 膳食纖維 | 每天 25–35 g | 延緩醣類吸收、降低膽固醇 |
| 鈉 | < 2,300 mg/天 | 合併高血壓者更嚴格 |

- **定時定量**,特別是使用胰島素或磺醯脲類者,避免延遲進餐。
- **醣類計算**:1 份醣類 = 15 g(約 ¼ 碗飯、1 份水果);依份數分配三餐,胰島素使用者可依份數調整餐前劑量。
- 烹調:清蒸、水煮、燉、滷、涼拌,避免油炸。
- **酒精**:儘量避免;若喝,需與食物一起(空腹喝酒易低血糖),不選含糖或藥酒。
- 病童正餐沒吃完:要**立即補充醣類食物**,不是下一餐多吃或多打胰島素。

#### 升糖指數(GI) {#glycemic-index}

GI 是吃含醣食物後血糖上升的**速度與幅度**,與葡萄糖(100)比較。

| 使 GI **較低** | 使 GI **較高** |
|---|---|
| 纖維多(全穀、糙米、燕麥、全麥麵包) | 精製澱粉(白飯、白吐司) |
| 完整的塊狀水果 | 果汁 |
| 多醣類澱粉 | 單醣、雙醣 |
| 與蛋白質、脂肪、醋同時吃 | **澱粉糊化程度高**(煮得越久越軟爛) |
| 豆類、乳製品 | 越成熟的水果 |

### 運動 {#exercise}

- **每週至少 150 分鐘中等強度有氧運動**,分散於至少 3 天,不連續 2 天以上不運動;加上每週 2–3 次阻力運動。
- 效益:**增加胰島素敏感性**、降血糖、降三酸甘油酯、**提升 HDL**、增強心肺耐力、控制體重。
- 時機:**飯後 1–2 小時**;避開胰島素作用高峰;晨起運動宜先吃少量食物。
- 運動前血糖 < 100 mg/dL 先補充醣類;血糖 > 250 mg/dL 合併酮體(或 > 300 mg/dL)先不運動。
- 不要把胰島素打在**即將運動的肢體**(吸收加快 → 低血糖)。
- 隨身攜帶糖果與識別卡;穿合適的鞋襪,運動後檢查雙腳。

### 預防(三段五級) {#prevention}

| 段/級 | 內容 | 糖尿病的例子 |
|---|---|---|
| 初段:促進健康 | 一般性健康生活 | 均衡營養、規律運動、體重控制、定期健康檢查的衛教 |
| 初段:特殊保護 | 針對高危險群 | 糖尿病前期、肥胖、有家族史或 GDM 病史者的生活型態介入 |
| 次段:早期診斷、早期治療 | 篩檢 | 成人預防保健(含空腹血糖)、孕婦 24–28 週篩檢、代謝症候群篩檢 |
| 三段:限制殘障 | 控制疾病、預防併發症 | 規則用藥、每年眼底/腎功能/足部檢查、足部照護 |
| 三段:復健 | 恢復功能 | 截肢後復健、視障重建 |

- **代謝症候群**(國健署,5 項中 ≥ 3 項):腰圍男 ≥ 90、女 ≥ 80 cm;血壓 ≥ 130/85 mmHg;空腹血糖 ≥ 100 mg/dL;三酸甘油酯 ≥ 150 mg/dL;HDL 男 < 40、女 < 50 mg/dL。
- 四大非傳染病(癌症、糖尿病、心血管疾病、慢性呼吸道疾病)共同危險因子:**吸菸、不當飲酒、缺乏運動、不健康飲食**。
