本頁整理男性生殖器官的常見疾病：睪丸腫瘤、睪丸扭轉、副睪炎與睪丸炎、精索靜脈曲張與陰囊水腫、包莖、陰莖癌，以及射精問題。構造與精子生成見 [[male-reproductive-system]]，前列腺肥大與前列腺癌、勃起功能障礙見 [[urologic-disorders]]，兒童隱睪與尿道下裂見 [[pediatric-genitourinary]]，男性不孕見 [[infertility#male-factors]]。文中縮寫：AFP(Alpha-fetoprotein，α 胎兒蛋白)、hCG(human chorionic gonadotropin，人類絨毛膜促性腺激素)、LDH(Lactate dehydrogenase，乳酸脫氫酶)

## 重點摘要 {#summary}

- **睪丸腫瘤**：約 95% 是**生殖細胞腫瘤**；好發 **15–35 歲**；**青春期後多為惡性**；常見表現是**無痛性**睪丸腫塊
- **精原細胞瘤**(seminoma)最常見，對放射線敏感、預後好
- 腫瘤標記：**卵黃囊瘤 → AFP**；**絨毛膜癌 → hCG**；LDH 反映腫瘤量
- 危險因子：**隱睪症**(最重要)、家族史、柯林菲特症候群
- 生殖細胞腫瘤最常見的染色體異常是 **12 號短臂等臂染色體**，i(12p)
- **睪丸扭轉**：青少年突然劇烈陰囊痛、睪丸上提、**提睪反射消失**；黃金時間約 **6 小時**
- **精索靜脈曲張**：多在**左側**，摸起來像「一袋蟲」，男性不孕最常見可治療的原因
- 陰莖 **Bowen 病**＝**原位鱗狀細胞癌**

### 國考常考點 {#exam-points}

- 三歲男孩 AFP 上升 → **卵黃囊瘤**(幼兒最常見的睪丸生殖細胞腫瘤)
- hCG 升高 → **絨毛膜癌**
- 青春期後的睪丸腫瘤多來自生殖細胞，而且**大多是惡性**(題目寫「大多為良性」是錯的)
- 陰莖 Bowen 病是**原位癌**，不是過敏、結核或黴菌
- 前列腺癌好發**周邊區**(見 [[urologic-disorders#prostate-cancer]])

## 睪丸腫瘤 {#testicular-tumors}

| 類型 | 好發 | 重點 |
|---|---|---|
| **精原細胞瘤** | 30–40 歲 | **最常見**；對放射線與化療敏感，預後好；腫瘤標記多半正常(少數 hCG 輕度上升) |
| 胚胎癌 | 20–30 歲 | 侵襲性強 |
| **卵黃囊瘤** | **3 歲以下男童**最常見；成人多混在混合型 | **AFP 上升** |
| **絨毛膜癌** | 20–30 歲 | 很早經血液轉移；**hCG 上升** |
| 畸胎瘤 | 兒童多良性；**青春期後即使看起來成熟也可能轉移** | 含三胚層組織 |
| 非生殖細胞(萊氏細胞瘤、塞氏細胞瘤) | 少 | 萊氏細胞瘤可分泌雄性素或雌激素 |

- 精原細胞瘤以外的統稱**非精原細胞瘤**
- 表現：**無痛性**睪丸腫大或硬塊、陰囊沉重感；少數因出血或梗塞而痛；男性女乳症(hCG)；轉移到後腹腔淋巴結 → 背痛
- 檢查：陰囊超音波、AFP、hCG、LDH；**不做陰囊穿刺切片**(會造成腫瘤沿陰囊擴散)
- 治療：經**鼠蹊部**睪丸切除術；依類型與分期加放射治療或化學治療(cisplatin 為主)；治癒率高
- 護理
   1. 化療前**冷凍保存精子**
   2. 身體心像與性功能的擔心：單側切除通常不影響性功能與生育；可放人工睪丸
   3. **睪丸自我檢查**：15 歲起每月一次，**溫水洗澡後**陰囊放鬆時，用拇指與食指輕輕滾動每顆睪丸，摸到硬塊、腫大或沉重感就就醫
- 隱睪症在 1 歲前完成睪丸固定術可降低風險但不會完全消除(見 [[pediatric-genitourinary#cryptorchidism]])

## 睪丸扭轉 {#torsion}

- 精索扭轉 → 睪丸血流中斷；**青少年**(12–18 歲)與新生兒最常見，常在睡眠或運動時發生
- 表現：**突然劇烈**單側陰囊痛，可放射到下腹、噁心嘔吐；睪丸腫脹、**位置上提**、橫位；**提睪反射消失**；**抬高陰囊疼痛不會減輕**
- 處置：**急診**，都卜勒超音波確認，**6 小時內手術**復位並固定(對側也固定)；超過 12–24 小時睪丸多半壞死需切除
- 和**副睪炎**比較：副睪炎疼痛**漸進**、可能發燒與排尿症狀、**抬高陰囊疼痛減輕**(Prehn 徵象)、提睪反射存在

## 副睪炎與睪丸炎 {#epididymitis}

- **副睪炎**：35 歲以下多是**性傳染病**(披衣菌、淋病)，年長者多是大腸桿菌等泌尿道細菌(前列腺肥大、導尿)
- 治療：抗生素(性伴侶一起治療)、臥床、**抬高陰囊**、冰敷、止痛、避免提重物
- **腮腺炎睪丸炎**：青春期後感染腮腺炎時約 1/3 併發，多單側，可能造成睪丸萎縮與不孕；預防靠 MMR 疫苗(見 [[childhood-infectious-diseases#mumps-virus]])

## 精索靜脈曲張與陰囊水腫 {#varicocele}

| | **精索靜脈曲張** | **陰囊水腫**(鞘膜積液) |
|---|---|---|
| 原因 | 精索蔓狀靜脈叢擴張；**左側**較多(左睪丸靜脈直角匯入左腎靜脈) | 睪丸鞘膜內積液 |
| 表現 | 站立時明顯、平躺消失；摸起來像**一袋蟲**；陰囊沉重或悶痛 | 無痛、柔軟腫大；**透光試驗陽性** |
| 影響 | 陰囊溫度上升 → **精子品質下降**，男性不孕最常見可治療的原因 | 嬰兒多在 1 歲內自行吸收；成人大或不適時手術 |
| 處置 | 不孕、疼痛或睪丸萎縮時手術結紮或栓塞 | 手術；嬰兒合併疝氣要手術 |

- 突然出現右側精索靜脈曲張、或平躺不消失 → 要排除腹部腫瘤壓迫

## 包莖與陰莖疾病 {#penis}

- **包莖**：包皮無法往後翻露出龜頭；兒童生理性包莖多會自然改善(見 [[pediatric-genitourinary]])；成人包莖容易龜頭包皮炎、排尿困難，是**陰莖癌**的危險因子 → 包皮環切術
- **嵌頓包莖**：包皮往後翻後卡住回不去 → 龜頭水腫、缺血，是**急症**；導尿或清潔後要把包皮**推回原位**預防
- **陰莖癌**：多為**鱗狀細胞癌**；危險因子：未割包皮、包莖、衛生不良、**HPV**(見 [[human-papillomavirus]])、抽菸
- **Bowen 病**：陰莖幹或陰囊的**原位鱗狀細胞癌**，紅色斑塊，少數會變侵襲性；龜頭上的稱 Queyrat 紅斑增生

## 射精與性功能問題 {#ejaculation}

- **逆行性射精**：射精時膀胱頸沒有關緊，精液逆流進**膀胱**；原因：攝護腺手術(TURP)、糖尿病神經病變、α 阻斷劑；射精量少或沒有，**射精後尿液混濁**，可造成不孕(可從尿液回收精子做人工生殖)
- **性腺功能低下**：睪固酮不足；原發性(睪丸)FSH、LH 高，續發性(下視丘或腦下垂體)FSH、LH 低；睪固酮補充見 [[sex-hormones#androgens]]
- 勃起功能障礙見 [[urologic-disorders]]
