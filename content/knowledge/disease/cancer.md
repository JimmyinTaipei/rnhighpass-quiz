**癌症**是細胞失去調控、不斷增生並能**侵犯與轉移**的疾病群，自民國 71 年起一直是**台灣十大死因之首**。本頁是癌症護理的總論：流行病學、預防與篩檢、診斷、治療方式(尤其**手術與放射治療**)與整體照護。病理基礎見 [[neoplasia]]，藥物見 [[antineoplastics]]，副作用與急症見 [[cancer-treatment-toxicities]]，疼痛見 [[pain-management]]。

## 重點摘要 {#summary}

- 癌症是細胞失控增生、能**侵犯與轉移**的疾病群，自民國 71 年起是**台灣十大死因之首**；**肺癌**發生人數與死亡人數都是第一。
- 預防分三段：**戒菸、戒檳榔、疫苗**是初級預防；**癌症篩檢**屬第二段(早期診斷與適當治療)；復健與限制殘障屬第三段。篩檢陽性要**轉介確診**。
- 國健署公費篩檢：**子宮頸癌、乳癌、大腸癌、口腔癌、肺癌**(五癌)；**攝護腺癌不在內**。
- 治療方式以**手術與放射治療**為主；體內放射治療分**封閉式**(排泄物無放射性)與**非封閉式**(體液有放射性)，輻射防護靠時間、距離、屏蔽。
- 照護重點：**中心靜脈導管(Port-A)**維護、心理社會與靈性支持、姑息照護。

### 國考常考點 {#exam-points}

- **四癌篩檢** = 子宮頸癌、乳癌、大腸癌、口腔癌；**肺癌 111 年加入**成為五癌；**攝護腺癌不在**公費篩檢內。
- 篩檢屬於**第二段預防**(早期診斷與適當治療)；**定期體檢不是初級預防**；糞便潛血陽性 → **轉介大腸鏡**。
- 114 年起：乳房攝影 **40–74 歲**每 2 年、糞便潛血 **45–74 歲**每 2 年、抹片增列 **25–29 歲每 3 年**、HPV 檢測 35／45／65 歲、LDCT 吸菸史 **≥ 20 包－年**(戒菸 15 年內)。舊題：乳癌 **45–69 歲**或 40–44 歲有家族史每 2 年 1 次。
- 放療：**神經細胞最不敏感**；輻射強度與**距離平方成反比**；**週末休息**。
- **封閉式體內放療**：**排泄物不具放射性**、射源脫落用**長柄鑷子**放**鉛桶**、禁止懷孕訪客、集中護理、鉛屏。**非封閉式**(I-131)的體液才有放射性。
- **伽馬刀**：**< 3 公分**、**無傷口**、約半小時；用的是**鈷-60 伽馬射線**不是碘。
- 手術：**切除原發或已轉移的固態腫瘤**；冷凍手術不是分期；雷射出血少。**姑息性治療以緩解症狀為目的**。
- Port-A：局部麻醉、經**鎖骨下或腋靜脈**、注射前**測回血**、**無芯針**、每月 heparin 沖洗、**手臂不需限制活動**；**PICC 不是幼兒長期化療的首選**。

## 台灣的癌症概況 {#epidemiology}

依國民健康署 **112 年癌症登記**(來源：[國健署](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=4878&pid=19734))：

- 新發生癌症 **13 萬 8,051 人**。
- 十大癌症發生人數(男女合計)：**① 肺癌 ② 大腸癌 ③ 女性乳癌 ④ 肝癌 ⑤ 攝護腺癌 ⑥ 口腔癌**(含口咽、下咽) ⑦ 甲狀腺癌 ⑧ 皮膚癌 ⑨ 胃癌 ⑩ 子宮體癌。
- **男性第一名是大腸癌**；**女性第一名是乳癌**、第二名是肺癌。
- 肺癌已連續 3 年是發生人數第一，也是**癌症死亡的第一名**。

## 危險因子與預防 {#prevention}

致癌因子(菸、檳榔、酒、黃麴毒素、病毒等)見 [[neoplasia#carcinogens]]。

### 三段五級預防 {#prevention-levels}

| 段 | 級 | 癌症的例子 |
|---|---|---|
| **第一段**(初級預防：避免發生) | 1. 健康促進 | 衛教、**戒菸、戒檳榔、節酒**、均衡飲食(**高纖、少紅肉與加工肉**)、規律運動、維持體重 |
| | 2. 特殊保護 | **B 型肝炎疫苗、HPV 疫苗**、避免職業暴露、防曬 |
| **第二段**(次級預防：早期發現) | 3. **早期診斷與適當治療** | **癌症篩檢**：子宮頸抹片、乳房攝影、糞便潛血、口腔黏膜檢查、LDCT；乳房自我檢查 |
| **第三段**(三級預防：減少失能) | 4. 限制殘障 | 積極治療、避免併發症 |
| | 5. 復健 | 乳癌術後手臂復健、造口照護、喉切除後的發聲訓練 |

- **「定期接受身體檢查」屬於早期發現(第二段)**，不是初級預防。
- 篩檢陽性時要**轉介確診**(例：糞便潛血陽性 → **大腸鏡**)，護理師扮演**轉介者與個案管理者**。

### 癌症的警訊 {#warning-signs}

美國癌症學會的「**CAUTION**」七大警訊：

| 字母 | 警訊 |
|---|---|
| **C** | 排便或排尿習慣改變 |
| **A** | 傷口**久不癒合**(例：口腔潰瘍超過兩週) |
| **U** | 不正常的**出血或分泌物** |
| **T** | 乳房或其他部位**增厚或腫塊** |
| **I** | 消化不良或**吞嚥困難** |
| **O** | 疣或痣明顯改變 |
| **N** | 持續咳嗽或**聲音沙啞** |

另外，**不明原因體重減輕**、持續疲倦、不明發燒也要注意。兒童的癌症警訊不同，見 [[pediatric-cancers#warning-signs]]。

## 國健署公費癌症篩檢 {#screening}

民國 99 年起推動**四癌篩檢**(子宮頸癌、乳癌、大腸癌、口腔癌)，**111 年 7 月**加入**肺癌**成為**五癌篩檢**；**114 年起擴大年齡**(來源：[國健署 114 年擴大癌症篩檢](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=4809&pid=18712))。

| 癌症 | 方法 | 對象(114 年起) | 頻率 |
|---|---|---|---|
| **子宮頸癌** | **子宮頸抹片** | **25–29 歲**女性(114 年新增)；**30 歲以上**女性 | 25–29 歲**每 3 年 1 次**；30 歲以上公費**每年 1 次**，建議至少每 3 年 1 次 |
| | **HPV 檢測**(114 年新增) | **35、45、65 歲**女性 | 當年度 1 次 |
| **乳癌** | **乳房 X 光攝影** | **40–74 歲**女性(舊制：45–69 歲，及 40–44 歲二親等內有乳癌家族史者) | **每 2 年 1 次** |
| **大腸癌** | **糞便潛血檢查**(免疫法) | **45–74 歲**；**40–44 歲**有家族史(父母、子女或兄弟姊妹曾罹患大腸癌)(舊制：50–74 歲) | **每 2 年 1 次** |
| **口腔癌** | **口腔黏膜檢查** | **30 歲以上有嚼檳榔(含已戒)或吸菸**者；18–29 歲有嚼檳榔的原住民 | **每 2 年 1 次** |
| **肺癌** | **低劑量電腦斷層**(LDCT) | ① **家族史**：父母、子女或兄弟姊妹曾罹患肺癌的**男性 45–74 歲、女性 40–74 歲**；② **重度吸菸史**：**50–74 歲**，吸菸 **≥ 20 包－年**，**目前吸菸或戒菸 15 年內**(114 年前為 30 包－年) | **每 2 年 1 次** |

- **攝護腺癌、肝癌不在**公費五癌篩檢內；肝癌高風險者(B、C 型肝炎帶原)另有**成人預防保健**的 B、C 型肝炎篩檢，並建議定期腹部超音波追蹤。
- 例：60 歲男性、**已戒菸 20 年** → 可做**大腸癌**與(若有吸菸或檳榔史)**口腔癌**篩檢；戒菸超過 15 年**不符合**吸菸史的 LDCT 條件，攝護腺癌篩檢不是公費項目。
- 考題若用 114 年以前的規定(乳癌 45–69 歲、大腸癌 50–74 歲、肺癌吸菸史 30 包－年)，以題目年份為準作答。例：111 年題目中 45 歲、無菸檳的原住民女性，公費項目是成人預防保健、子宮頸癌、乳癌與 B、C 型肝炎篩檢；當時大腸癌要 50 歲才符合，114 年起 45 歲就符合了。
- 乳癌家族史者(40–44 歲)的公費乳房攝影也是**每 2 年 1 次**，不是每年。
- **成人預防保健**(健康檢查)：**40–64 歲每 3 年 1 次**、**65 歲以上每年 1 次**(另有原住民、小兒麻痺者等較寬的條件)，並含一次性的 **B、C 型肝炎篩檢**。

:::note[篩檢工具的評估]
- **敏感度**：有病的人被驗出陽性的比例(高 → 偽陰性少)；**特異度**：沒病的人被驗出陰性的比例(高 → 偽陽性少)。
- **陽性預測值** = 真陽性 ÷ 全部陽性；盛行率越高，陽性預測值越高。
- 篩檢是**早期發現**，陽性要**確診**，不是直接診斷。
:::

## 診斷與分期 {#diagnosis}

- **確診靠切片病理**；影像找範圍與轉移；腫瘤標記用於追蹤(見 [[tumor-markers]])。
- 分期 TNM 與分級見 [[neoplasia#grading-staging]]。
- 告知診斷時，評估病人想知道多少、提供支持，並確認理解。

## 治療目標與方式 {#treatment}

| 目標 | 意義 |
|---|---|
| **治癒**(curative) | 消滅所有癌細胞 |
| 控制(control) | 延長存活、延緩惡化 |
| **姑息**(palliative) | **不以治癒或延長生命為目的**，而是**緩解症狀**(疼痛、呼吸困難、阻塞)、提升生活品質 |

常合併多種方式：**手術**與**放射治療**是**局部治療**；化學治療、標靶、免疫、荷爾蒙治療是**全身治療**。手術或放療後加化療稱**輔助性**治療，手術前先化療稱**前導性**治療(見 [[antineoplastics#intent]])。

### 手術治療 {#surgery}

| 類型 | 目的與例子 |
|---|---|
| **預防性** | 切除癌前病變或高風險器官：大腸瘜肉切除、**BRCA 帶因者預防性乳房切除**、FAP 的全結腸切除 |
| **診斷性** | **切片**、前哨淋巴結切片、剖腹探查，確定診斷與分期 |
| **根治性** | 切除**原發腫瘤**(或可切除的轉移病灶)及周圍組織與淋巴結；適合**局部、實質固態**腫瘤 |
| 減積(debulking) | 盡量切除腫瘤以提高化放療效果，例：卵巢癌 |
| 重建性 | 乳房重建、頭頸部皮瓣 |
| 姑息性 | 解除阻塞、止血、減輕疼痛(例：造口繞道) |

- **冷凍手術**：以極低溫破壞組織，是**治療**方式，不是分期工具。**雷射手術**：切割時同時封閉血管，**出血較少**。
- 手術只能處理**局部**；分化差、已擴散的腫瘤需要全身治療。

## 放射治療 {#radiotherapy}

### 原理 {#radiotherapy-principles}

- 游離輻射**直接或經由自由基**破壞細胞 DNA，使細胞無法分裂而死亡。
- **分裂越快、越缺乏分化**的細胞越敏感(淋巴瘤、精原細胞瘤、骨髓、腸胃黏膜)；**神經細胞、肌肉**等不分裂的細胞**最不敏感**。
- 需要氧氣形成自由基：**貧血、缺氧**的腫瘤對放療較不敏感。
- 劑量單位 **Gy**(戈雷)；通常**分次**照射，**週一到週五每天一次、週末休息**，連續約 5–7 週，讓正常細胞有時間修復(「連續 6–7 週不間斷」是錯的)。
- 用途：根治、手術前後輔助、合併化療(**同步化學放射治療，CCRT**)、**姑息**(骨轉移止痛、止血、解除壓迫)。

### 體外放射治療 {#external-beam}

- 機器從體外照射，**病人身上沒有放射性**，治療後可以正常接觸家人。
- **定位標記**不可洗掉；照射時病人要保持固定姿勢(頭頸部用面罩)。
- **立體定位放射手術**(**伽馬刀**)：多道**鈷-60 伽馬射線**從不同角度聚焦在小腫瘤，**適用直徑約 3 公分以下**的腦部病灶，**不需切開傷口**，通常一次治療，約數十分鐘到一小時。

### 體內放射治療 {#brachytherapy}

| | **封閉式**(密封射源) | **非封閉式**(開放射源) |
|---|---|---|
| 方法 | 把射源放到**腫瘤內或旁邊**：**腔內**(子宮頸癌**後荷式**近接治療)、**組織插植**(攝護腺 I-125 碎粒) | **口服或注射**放射性藥物，隨血液分布：**I-131**(甲狀腺癌)、Radium-223(骨轉移) |
| 病人會放出輻射嗎 | **射源在體內時會**；取出後就沒有(永久植入的碎粒劑量會逐漸衰減) | **會** |
| **體液與排泄物** | **不具放射性**，按一般方式處理 | **具放射性**(尿液、唾液、汗液)：專用廁所、**沖水兩次**、單獨清洗衣物、使用拋棄式餐具 |

**封閉式體內放療的護理**(後荷式子宮頸癌近接治療)：

- **單人房**，門口與床旁放置**鉛屏**、張貼輻射警示；**懷孕者與兒童不可探訪**，訪客**限制時間並保持距離**。
- 護理人員配戴輻射劑量計，**集中護理**、縮短停留時間，必要時穿鉛衣。
- 射源若**脫落**：**不可用手拿**，用**長柄鑷子**夾起放入**鉛製容器**，立即通知放射治療單位。
- 射源在陰道內時：**臥床**、床頭抬高不超過約 30 度、留置導尿管、**低渣飲食**減少排便、翻身時避免射源移位；觀察陰道出血與分泌物。

### 輻射防護三原則 {#radiation-protection}

| 原則 | 說明 |
|---|---|
| **時間** | 接觸時間越短，劑量越少 → 集中護理 |
| **距離** | 輻射強度與**距離的平方成反比**：距離加倍，暴露減為四分之一 |
| **屏蔽** | 鉛屏、鉛衣、鉛容器 |

### 放射治療的副作用 {#radiotherapy-effects}

副作用主要發生在**照射範圍內**：皮膚炎、口腔炎、食道炎、腹瀉等。詳見 [[cancer-treatment-toxicities#radiation-site-effects]]。

## 中心靜脈導管 {#vascular-access}

| 裝置 | 特色 |
|---|---|
| **人工血管**(Port-A) | 注射座**植入皮下**，由**外科醫師在手術室**置放，多為**局部麻醉**；導管經**鎖骨下或腋靜脈**進入上腔靜脈。用**無芯針**垂直插入；**不用時每月以含 heparin 的生理食鹽水(約 100 U/mL，10 mL)沖洗**。傷口癒合後手臂**不需限制活動** |
| **PICC**(周邊置入中心靜脈導管) | 由上臂靜脈置入，**受過訓練的護理師**可以執行；導管外露，需每週換藥沖洗；不適合好動的幼兒長期使用 |
| 隧道式導管(Hickman) | 經皮下隧道出口在胸前；常用於**造血幹細胞移植** |

- 給藥前一定**反抽確認回血**；無回血時可請病人**抬高手臂、咳嗽、改變姿勢**，仍無回血要通報，**不可**強行推注。
- 觀察感染(發燒、出口紅腫)、阻塞、血栓(手臂腫脹)。

## 整體照護 {#nursing}

### 心理社會與靈性 {#psychosocial}

- 診斷初期常見**震驚、否認、憤怒、焦慮與憂鬱**；給予時間、傾聽，提供正確資訊。
- **身體形象改變**：掉髮、乳房切除、造口、頭頸部手術 → 鼓勵表達感受、介紹輔具與病友團體。
- 家屬也需要支持；評估照顧負荷與經濟、工作問題，轉介社工與癌症資源管理師(個管師)。
- 末期病人的安寧照護見 [[end-of-life-care]]。

### 其他照護重點 {#general-care}

- 口腔、皮膚、營養、疲憊、感染與出血預防：見 [[cancer-treatment-toxicities]]。
- **骨轉移**病人：**預防病理性骨折**，翻身與移位要支托，**避免叩擊背部**；沐浴水溫約 41–43°C，擦洗四肢**由遠心端往近心端**。有深部靜脈栓塞時**不按摩患肢**。
- 腎臟癌對**化學治療與荷爾蒙治療反應差**，主要靠手術、標靶藥與免疫治療。

## 其他常考癌症 {#other-cancers}

有專頁的器官癌：[[breast-cancer]]、[[gynecologic-cancers]]、[[colorectal-cancer]]、[[lung-cancer]]、[[liver-cancer]]、[[head-neck-cancers]]、[[leukemia]]、[[lymphoma-myeloma]]、[[pediatric-cancers]]；造血幹細胞移植見 [[stem-cell-transplant]]。以下是暫時沒有專頁的癌症重點：

| 癌症 | 重點 |
|---|---|
| **胃癌** | **幽門螺旋桿菌**、醃燻食物；全胃切除後缺**內在因子** → 需終身補充維生素 B12；傾食症候群 |
| 食道癌 | 菸、酒、檳榔、熱食；吞嚥困難漸進加重 |
| **攝護腺癌** | **PSA** 追蹤；**成骨性骨轉移**；荷爾蒙治療(去勢) |
| **膀胱癌** | **吸菸**、芳香胺、砷；**無痛性血尿**；膀胱灌注 BCG 或化療藥 |
| 腎臟癌 | 血尿、腰痛、腹部腫塊；紅血球增多；對化療反應差 |
| 甲狀腺癌 | 乳突癌最常見、預後好；術後放射性碘；**髓質癌看 calcitonin** |
| 腦瘤 | 顱內壓升高(頭痛、嘔吐、視乳頭水腫)、**突發抽搐**；續發性腦瘤多來自**肺癌、乳癌**；兒童腦瘤見 [[pediatric-cancers#brain-tumors]] |
| 皮膚癌 | 紫外線、砷；黑色素瘤看痣的 ABCDE 變化 |
