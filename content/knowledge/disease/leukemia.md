**白血病**是骨髓中的造血幹細胞發生惡性變化，**不成熟的白血球(芽細胞)**大量增生，擠壓正常造血，並跑到周邊血液與器官。依病程分**急性**(芽細胞為主、進展快)與**慢性**(較成熟的細胞、進展慢)，依細胞來源分**淋巴性**與**骨髓性**。**急性淋巴性白血病(ALL)是兒童最常見的癌症**。癌症總論見 [[cancer]]，化療毒性與照護見 [[cancer-treatment-toxicities]]。

## 四種白血病比較 {#types}

| | **ALL** | **AML** | **CML** | **CLL** |
|---|---|---|---|---|
| 好發 | **兒童**(2–6 歲高峰) | **成人**(年齡越大越多) | 成人(中年) | **老人**(50–60 歲以上)，台灣較少見 |
| 增生的細胞 | 不成熟淋巴球(芽細胞)，**大多是 B 細胞型** | 不成熟骨髓系芽細胞(可見 Auer 小體) | 各階段的顆粒球，**白血球可高達數十萬** | **小而成熟**外觀的 B 淋巴球(功能不正常) |
| 特色 | 常侵犯**中樞神經**與睪丸，需**中樞神經預防** | APL 亞型易 **DIC** 出血(用 ATRA) | **費城染色體 t(9;22)**、**BCR-ABL**(> 90%)；脾臟腫大 | 常無症狀；**低丙種球蛋白 → 容易感染** |
| 治療 | 多階段化療 2–3 年 | 強力化療、造血幹細胞移植 | **Imatinib** 等 **BCR-ABL 酪胺酸激酶抑制劑**(口服) | **早期不需治療**、定期追蹤；有症狀再治療 |

- **CML** 若沒有控制，會從慢性期進入加速期，再到**芽細胞危象**(像急性白血病，預後最差)。
- 例：白血球 **30 萬/μL**、骨髓有**費城染色體** → **慢性骨髓性白血病**。

## 臨床表現 {#manifestations}

症狀來自兩方面：**正常造血被擠掉**，以及**白血病細胞浸潤器官**。

| 機轉 | 表現 |
|---|---|
| **紅血球製造減少** | **貧血**：蒼白、**疲倦**、喘、心跳快 |
| **正常白血球減少**(芽細胞沒有功能) | **發燒、反覆感染**(即使白血球總數很高) |
| **血小板減少** | **出血**：瘀點、瘀斑、**流鼻血**、牙齦出血 |
| 浸潤骨髓與骨膜 | **骨頭痛**、關節痛、兒童**跛行或拒絕走路** |
| 浸潤淋巴與網狀內皮系統 | 淋巴結腫大、**肝脾腫大**(腹脹) |
| 浸潤中樞神經 | 頭痛、嘔吐、抽搐(顱內壓上升) |
| 其他 | 牙齦腫脹(AML)、睪丸腫大(ALL)、高尿酸 |

- 兒童初診斷最常見的是**發燒、疲倦、蒼白、出血點、骨頭痛**。

## 診斷 {#diagnosis}

- **全血球計數**：白血球可能**升高、正常或降低**，常見芽細胞；貧血、血小板減少(見 [[complete-blood-count]])。
- **骨髓抽吸與切片**：**確定診斷**的檢查，**骨髓中芽細胞 ≥ 20%**(兒童 ALL 常高達 80% 以上)；並做細胞型態、流式細胞儀、染色體(費城染色體)與基因檢查。
- **腰椎穿刺**：檢查**中樞神經是否侵犯**(不是確診白血病的檢查)。

### 骨髓抽吸術的護理 {#bone-marrow-aspiration}

| 項目 | 重點 |
|---|---|
| 目的 | 了解骨髓與**造血組織**是否正常，**診斷白血病**等血液疾病、評估治療效果 |
| 部位 | 成人：**後腸骨嵴**(最常用)、前腸骨嵴；胸骨(只能抽吸)；**2 歲以下嬰幼兒：脛骨**。**不用肋骨、脊椎** |
| 麻醉 | **局部麻醉**(兒童常加鎮靜)，通常不需全身麻醉；抽吸時會有短暫的**拉扯痛** |
| 姿勢 | 後腸骨嵴：俯臥或側臥 |
| 術後 | 穿刺處**加壓至少 5 分鐘**(血小板低時更久)，可用**砂袋加壓**或平躺壓住；觀察**出血與感染**；24 小時內保持乾燥 |

## 治療 {#treatment}

### 急性淋巴性白血病的治療階段 {#all-phases}

| 階段 | 目的 | 常用藥物 |
|---|---|---|
| **誘導緩解期** | 以**強力、多藥**化療，**快速達到完全緩解** | **Vincristine**、**prednisolone**(或 dexamethasone)、**L-asparaginase**、蒽環類 |
| 鞏固或加強期 | 消滅殘存的白血病細胞 | 高劑量 methotrexate 等 |
| **中樞神經預防** | 化療藥物**難以通過血腦障壁**，中樞神經是白血病細胞的「庇護所」 | **鞘內注射**(經腰椎穿刺打入脊髓腔)methotrexate 等；不是打入骨髓 |
| **維持期** | 預防復發，約 **2–3 年** | 口服 **6-MP**、methotrexate |

- **完全緩解**的標準：**骨髓芽細胞 < 5%**、**周邊血液沒有芽細胞**、血球數接近正常、**沒有其他器官浸潤**。
- 高風險或復發 → **造血幹細胞移植**(見 [[stem-cell-transplant]])；新的免疫治療如 CAR-T。
- 化療後血球最低點約 **7–14 天**。

### 其他類型 {#other-treatment}

- **AML**：cytarabine 加蒽環類誘導，之後鞏固化療或異體移植；APL 用**全反式維生素 A 酸(ATRA)**與三氧化二砷。
- **CML**：口服 **imatinib**(抑制 **BCR-ABL**)，多數可長期控制；要**規則服藥**、隨餐服用。
- **CLL**：早期觀察；需要時用 BTK 抑制劑、rituximab 等；預防感染(疫苗、免疫球蛋白)。

## 護理 {#nursing}

### 化療期間 {#nursing-chemo}

- **腫瘤溶解症候群預防**：化療開始前後**大量輸液**(**不可限水**)、**allopurinol** 或 **rasburicase**(降低尿酸，**不是**用來預防腫瘤溶血)、監測尿酸、電解質、尿量(見 [[cancer-treatment-toxicities#tumor-lysis]])。
- 藥物副作用：
  - **Vincristine**：手腳**麻刺感**、**便秘**(給軟便劑)。
  - **Prednisolone**：增加感染、高血糖、情緒改變、月亮臉；**不要自行停藥**。
  - **L-asparaginase**：**高血糖**(監測血糖)、**胰臟炎**(腹痛)、過敏反應、凝血異常。
- **鞘內注射後**：依醫囑**平躺**一段時間(約 30 分鐘到數小時)，減少頭痛、讓藥物分布；**不是**立即下床活動。
- 用 **G-CSF** 提升嗜中性白血球；侵入性處置嚴守無菌。
- **Nystatin**(Mycostatin)是**抗黴菌**藥，預防念珠菌，不是預防革蘭氏陽性菌。

### 感染、出血與貧血 {#nursing-cytopenia}

- 感染預防(ANC < 500 保護性隔離、手部衛生、飲食安全、**不打活性疫苗**)、出血預防與貧血照護，見 [[cancer-treatment-toxicities#myelosuppression]]。
- **發燒時不用 aspirin**；病童發燒要立即告知。
- **輸紅血球濃厚液**(兒童)：
  - 輸血前、**開始後 15 分鐘**與輸完後量生命徵象；只用**生理食鹽水**排氣與沖管；使用輸血過濾器，依體重控制速度。
  - 出現**寒顫、心跳快、不安、發燒**等輸血反應時，**立即停止輸血**、以生理食鹽水維持管路並通知醫師；**不是**用溫血器繼續輸。

### 心理社會 {#nursing-psychosocial}

- 學齡期兒童住院最在意**學業與同儕關係** → 安排床邊教學、同學聯繫。
- 青少年在意外觀(掉髮、月亮臉)與自主性；鼓勵表達感受。
- 疾病末期與瀕死病童的照護，見 [[end-of-life-care#children]]。

## 預後 {#prognosis}

兒童 ALL 的 5 年存活率已達約 **90%**。預後因子：

| 較好 | 較差 |
|---|---|
| **1–9 歲**發病 | **< 1 歲**或 **> 10 歲**(青少年) |
| 初診白血球 **< 50,000/μL** | 白血球很高 |
| **B 細胞前驅型** | **T 細胞型** |
| 多倍體(hyperdiploidy) | **費城染色體**、部分基因重組 |
| 誘導期快速反應 | **中樞神經侵犯** |
| 女孩 | 男孩(略差) |

- **兒童的 ALL 預後比成人好**。

:::note[有疑義的考題]
112-1_MS_042 的答案是「**T 細胞型**急性淋巴性白血病預後最好」，但另一題 106-2_makeup_OP_071 以「T 細胞型預後較佳」為**錯誤**選項，病理學上也是 **B 細胞前驅型預後較好**。本頁採用後者。
:::

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **兒童最常見：ALL**，好發 **2–6 歲**；ALL **以 B 細胞型為多**(不是 T 細胞型)；**成人 ALL 預後比兒童差**。
- **CML**：**費城染色體**(約 90%)、**BCR-ABL**、**imatinib**；白血球可達 30 萬。
- **CLL**：50 歲以上、**早期不需治療**、容易感染；增生的是**小而成熟**外觀的淋巴球，不是不成熟淋巴球。
- 初診斷表現：**發燒、疲憊**、蒼白、流鼻血；貧血原因是**紅血球製造減少**。
- **確診靠骨髓抽吸**(芽細胞比例)，不是腰椎穿刺；**嬰幼兒骨髓穿刺選脛骨**；成人選**後腸骨嵴**、**不選肋骨、脊椎**；**局部麻醉**；術後**砂袋加壓**。
- **中樞神經預防：鞘內注射**(不是注入骨髓)；鞘內注射後**平躺**，不是立即下床。
- 緩解標準：骨髓芽細胞 < 5%、**周邊血液無芽細胞**、無器官浸潤。
- **Allopurinol、rasburicase** 預防**腫瘤溶解症候群**的高尿酸；**不可限水**。L-asparaginase **高血糖**；vincristine **麻刺感與便秘**。
- **侵犯中樞神經者預後較差**；年齡 > 10–13 歲、T 細胞型預後較差。
:::
