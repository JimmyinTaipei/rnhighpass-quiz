**先天性心臟病**是出生時就存在的心臟或大血管結構異常。理解它的關鍵是**血往哪裡分流**：左心壓力高，缺口會讓血由**左往右**分流 → 肺血太多、不發紺；如果右側出口被擋住或大血管接錯，缺氧血進入體循環 → **發紺**。胎兒循環與出生後的變化見 [[blood-vessels#fetal-circulation]]；兒童心衰竭見 [[heart-failure#pediatric]]；兒童心導管見 [[cardiac-catheterization#post-care]]；川崎病見 [[kawasaki-disease]]；感染性心內膜炎見 [[infective-endocarditis]]

## 重點摘要 {#summary}

- 分類（兒科書頁 427）
   1. **非發紺型、肺血流增加**（左至右分流）：**ASD、VSD、PDA**
   2. **非發紺型、阻塞型**：**AS、PS、COA**
   3. **發紺型、肺血流減少**：**TOF**、三尖瓣閉鎖
   4. **發紺型、肺血流增加**：**TGA**、動脈幹
- **VSD 最常見**（約 35%），其次 ASD（約 30%）；**TOF 是最常見的發紺型**（兒科書頁 428–429、434）
- 母親懷孕早期**德國麻疹**感染易造成先天性心臟病（PDA 等）（見 [[perinatal-infections]]）
- 左至右分流 → 肺充血、反覆呼吸道感染、心衰竭；長期肺高壓可變成**艾森曼格氏症候群**（分流反轉、出現發紺）
- **PDA**：胸骨左緣第 2 肋間**連續性機器聲**雜音、**洪脈、脈搏壓寬**；不發紺
- **COA**：**上肢血壓比下肢高**、股動脈脈搏弱或摸不到、頭痛暈眩流鼻血、腳冷
- **TOF** 四缺損：**肺動脈狹窄**、**VSD**、**主動脈跨位**、**右心室肥大**；缺氧發作採**膝胸臥式**或蹲姿
- **PGE1**：維持動脈導管**開放**，用在**導管依賴型**發紺心臟病（TGA、嚴重 PS、肺動脈閉鎖、三尖瓣閉鎖）；副作用**呼吸暫停**
- **Indomethacin／ibuprofen**：**關閉**早產兒 PDA；注意尿量減少、出血（兒科書頁 431）
- 照護：減少心臟負荷（集中護理、減少哭泣、避免便祕）、營養（少量多餐、每次 ≤ 30 分鐘、奶嘴軟孔稍大）、預防感染與心內膜炎、避免過度保護

### 國考常考點 {#exam-points}

- 嬰兒最常見先天性心臟病：**VSD**
- **不屬於**發紺型：**ASD**（TOF、TGA、三尖瓣閉鎖都是發紺型）
- ASD：一般**不發紺**、1 歲內約一半會自己閉合、要預防呼吸道感染；**不需要 PGE1**
- PDA **不會**有：發紺缺氧發作、**紅血球增多症**；會有：心搏過快、肺動脈高壓、餵食困難、肺水腫、寬脈搏壓
- 早產兒 PDA：無症狀者 **12 週內**可能自動關閉；治療用 **indomethacin（或 ibuprofen）**，**不是 PGE1**；體重 < 1,000 g 有心衰竭宜早結紮
- Indomethacin 治療中 **尿量 < 1 mL/kg/hr** 要通知醫師
- COA 的錯誤敘述：「**下肢**血壓比上肢高」「下肢溫度較高」「頸動脈搏動變弱」「肺血管阻力升高而發紺」
- 嚴重 AS：脈搏微弱、心跳快、收縮期雜音、易疲倦；**不會**發紺與杵狀指；**不做** BT 分流術
- TOF 發紺是**右至左**分流、主因是**肺動脈狹窄**；缺氧發作好發於早晨、餵奶、哭泣、排便
- TOF 缺氧發作表現：哭後發紺、**鞏膜灰色**、唇與口腔黏膜暗藍；**不會**「皮膚彈性差呈黃色」
- 缺氧發作最優先：**膝胸臥式**；再給氧、morphine；**不是**給濃縮紅血球
- 膝胸臥式原理：**減少下肢**靜脈回流、增加全身血管阻力 → 肺血流增加；「減少**上肢**回流」是錯的
- 增加 TOF 肺血流的方法：膝胸臥式、PGE1、BT 分流術；**aspirin 不是**
- TGA：出生後不久發紺、紅血球增多、第二心音加重；**上下肢血壓差**是 COA 不是 TGA；PGE1 目的是**維持動脈導管開放**
- PGE1 **不適合**主動脈狹窄（COA 題的答案）；注意**呼吸窘迫或呼吸暫停**
- 4–6 歲：心臟在胸部、像愛心形、會發出碰碰聲 → 用**畫人形與心臟位置、說手術後會發出規律的蹦蹦聲**解釋
- 心臟病嬰兒餵食：少量多餐、**每次不超過 30 分鐘**、**奶嘴軟、孔稍大**、吸吮差可擠母奶用奶瓶或**鼻胃管**；**低鈉配方不必取代母乳**（母奶鈉低）；補**鐵**（不是鈣）增加載氧
- VSD 合併心衰竭呼吸喘：**半坐臥**
- 術後尿量：嬰兒約 **2 mL/kg/hr**、兒童 1–2 mL/kg/hr；< 1 通知醫師；胸管引流連續 3 小時 > **3 mL/kg/hr** 要通知醫師

## 兒童心臟評估 {#assessment}

依兒科書頁 420–422 重新整理

- 測**四肢血壓**與脈搏壓（正常差值約 30–50 mmHg）；上下肢血壓差 → 想到 COA
- 視診：發紺（去氧血紅素 > 5 g/dL 才明顯）、**杵狀指**、蹲姿、呼吸費力、餵食時流汗
- 嬰幼兒心尖在**第 3–4 肋間**與左鎖骨中線交會處；7 歲以上在第 5 肋間（見 [[cardiac-output#heart-sounds]]）
- 脈搏：**絲脈**（弱小）→ 心功能差；**股動脈弱或摸不到** → COA；**洪脈**（強大、脈搏壓寬）→ **PDA**
- 檢驗：慢性缺氧 → **紅血球增多症**、血比容上升；右至左分流時 SpO₂ < 92%；新生兒給 100% 氧氣 15 分鐘 PaO₂ 仍 < 50 mmHg 提示發紺型心臟病
- 心導管各腔室含氧：右心約 70–75%，**肺靜脈**、左心與主動脈約 95–98%（肺靜脈 70–75% 是異常）

| 心雜音強度(Levine) | 特點 |
|---|---|
| I–II 級 | 輕；第 I 級要仔細聽 |
| III 級 | 中等 |
| **IV 級以上** | 合併**震顫(thrill)** |
| VI 級 | 聽診器不碰胸壁也聽得到 |

- **功能性（無害性）心雜音**：約 80% 兒童聽得到；柔和（多為 I–III 級）、無震顫、多在收縮期、**躺著較明顯、坐起可能消失**、發燒或運動時變大；心臟結構正常（兒科書頁 421）
- 合併症狀、發紺、很響且傳導、X 光或心電圖異常 → 可能是病理性，轉介小兒心臟科

## 非發紺型：左至右分流 {#left-to-right}

| 項目 | **ASD**（心房中隔缺損） | **VSD**（心室中隔缺損） | **PDA**（開放性動脈導管） |
|---|---|---|---|
| 比例 | 約 30%，第二常見 | 約 35%，**最常見** | 約 10%；早產兒 < 1,500 g 達 40–50% |
| 分流 | 左心房 → 右心房 | 左心室 → 右心室 | 主動脈 → 肺動脈 |
| 雜音 | 嬰兒期常聽不到，長大才明顯 | **胸骨左緣第 3–4 肋間收縮期**雜音；出生 4–8 週才出現；小缺損雜音反而大 | **胸骨左緣第 2 肋間連續性機器聲** |
| 表現 | 多數無症狀，大一點活動耐力差；很少嬰兒期心衰竭 | 小缺損無症狀；大缺損 3–4 個月內心衰竭、肺水腫、反覆感染 | **洪脈、脈搏壓寬**、心搏過速、餵食困難、生長遲緩、肺水腫 |
| 自然閉合 | **1 歲內約一半** | 小缺損 2 歲前約 45–50%、5 歲前 1/3–1/2 | 足月兒很少；早產兒 **12 週內**可能關閉 |
| 治療 | 心導管關閉器（第二型、< 2 公分）為首選；否則開心手術，約 5 歲 | 依必要性不依年齡；關閉器或開心修補；以前用肺動脈繃紮術 | 早產兒 **indomethacin／ibuprofen**；導管栓塞（線圈、關閉器）；結紮（可胸腔鏡） |

依兒科書頁 428–431 重新整理

- 左至右分流長期 → 肺血管受損、**肺高壓**；嚴重時分流反轉成右至左 → **艾森曼格氏症候群**，出現發紺，此時已不適合單純修補（兒科書頁 429）
- PDA 的胎兒生理與出生後關閉（功能性關閉約 2–4 天，解剖性 1–3 個月形成動脈韌帶）見 [[blood-vessels#transition]]
- 放關閉器後通常服 **aspirin 約半年**預防血栓、短期避免碰撞（兒科書頁 426）

## 非發紺型：阻塞型 {#obstructive}

| 項目 | **AS**（主動脈瓣狹窄） | **PS**（肺動脈瓣狹窄） | **COA**（主動脈縮窄） |
|---|---|---|---|
| 位置 | 主動脈瓣（瓣膜型最常見）、瓣上、瓣下 | 肺動脈瓣 | 主動脈靠近動脈導管處 |
| 心臟變化 | **左心室肥大** | **右心室肥大** | 左心室負荷增加 |
| 表現 | 輕度只有雜音；重度**脈搏弱、血壓低、心跳快**、胸痛、易累、昏厥、猝死 | 輕度只有收縮期雜音；重度運動耐力差、新生兒可經卵圓孔右至左分流而發紺 | **上肢血壓比下肢高**（10–20 mmHg 以上）、**股動脈脈搏弱**、**頭痛、暈眩、流鼻血**、**腳冷**、走路腳痛 |
| 治療 | 氣球瓣膜擴張術；再狹窄或瓣下型用手術（Ross、Konno、瓣膜置換） | 氣球瓣膜擴張術為第一線；重度新生兒先用 **PGE1** | 單一處用氣球擴張；長段切除後端端吻合或移植 |
| 注意 | 壓差大(> 50 mmHg)要**限制劇烈運動** | 輕度追蹤、預防心內膜炎 | 常見於**透納氏症候群**（見 [[chromosomal-disorders]]） |

依兒科書頁 431–434 重新整理

- AS 是**非發紺型**，不會杵狀指；需要的是減輕心臟負荷與擴張瓣膜，**不是** BT 分流術
- 成人主動脈瓣狹窄見 [[valvular-heart-disease]]

## 發紺型先天性心臟病 {#cyanotic}

### 法洛氏四重畸形(TOF) {#tof}

| 缺損 | 說明 |
|---|---|
| 1 **肺動脈狹窄**（右心室出口狹窄） | 決定發紺嚴重度 |
| 2 **心室中隔缺損** | 右心缺氧血經缺口流出 |
| 3 **主動脈跨位** | 主動脈騎在 VSD 上，接收兩側心室的血 |
| 4 **右心室肥大** | 後天形成，因為右心室要對抗狹窄 |

兒科書頁 434

- 右心室出口越窄 → 越多缺氧血經 VSD 進主動脈（**右至左分流**）→ 發紺越重；多在出生約 2 個月後明顯
- 長期缺氧：**杵狀指**、**蹲姿**、易疲倦、生長差、**紅血球增多** → 易**腦血管意外、血栓、腦膿瘍**；也有心內膜炎風險
- X 光：**靴型心**（兒科書頁 435）

### 缺氧發作 {#hypercyanotic-spell}

- 右心室出口突然緊縮 → 肺血更少 → 突然**發紺加劇**、呼吸淺快、躁動、**鞏膜灰色**、唇與口腔黏膜暗藍；嚴重時抽搐、昏迷、猝死（兒科書頁 435）
- 誘因：**早晨、哭鬧、餵奶、排便**、抽血等刺激

| 步驟 | 做法 | 原理 |
|---|---|---|
| 1 **姿勢（最優先）** | 安撫，抱成**膝胸臥式**；大孩子會自己**蹲下** | 腿彎曲 → **下肢**靜脈回流減少（少一些缺氧血進右心）、**全身血管阻力增加** → 右心血改流向肺動脈 → **肺血流增加** |
| 2 氧氣 | 依醫囑給氧 | |
| 3 藥物 | **morphine**（放鬆漏斗部、鎮靜）、propranolol（減慢心跳）；矯正酸中毒 | |
| 4 預防 | 集中護理、減少哭泣、避免便祕與脫水 | 脫水會讓血更濃、易血栓 |

兒科書頁 435 重新整理

- 不是輸濃縮紅血球；**aspirin** 也不能增加肺血流

### TOF 的手術 {#tof-surgery}

- **暫時姑息手術**：把體循環的血分流到肺 → **（改良式）布萊洛克－陶西分流術(BT shunt)**：鎖骨下動脈接肺動脈（現多用人工血管）；或中心分流術（兒科書頁 436）
- **完全矯正**：多在 **3–6 個月**；補 VSD、擴大肺動脈出口、矯正主動脈跨位（兒科書頁 436）
- 肺動脈閉鎖的新生兒先用 **PGE1** 維持動脈導管（兒科書頁 434）

### 三尖瓣閉鎖、大血管轉位、動脈幹 {#other-cyanotic}

| 項目 | **三尖瓣閉鎖** | **大血管轉位(TGA)** | **動脈幹** |
|---|---|---|---|
| 構造 | 右心房血進不了右心室；一定要有 ASD 或卵圓孔才能活 | **主動脈接右心室、肺動脈接左心室** → 兩個獨立循環 | 只有一條大動脈騎在 VSD 上 |
| 存活靠 | ASD、VSD、PDA | 合併 ASD、VSD、**PDA** 讓兩邊血混合 | — |
| 表現 | 發紺、左心室肥大與衰竭、生長遲緩、杵狀指 | **出生不久就發紺**、低血氧、**紅血球增多**、X 光**蛋形心**；未治療 1 年內死亡 | 肺血多 → 心衰竭、發紺、生長遲滯 |
| 暫時處置 | **PGE1** 維持動脈導管 | **PGE1**；**心房中隔氣球造口術(Rashkind)**增加混合 | 縮窄肺動脈 |
| 根治手術 | 三階段：BT 分流 → **Glenn**（上腔靜脈接肺動脈）→ **Fontan**（下腔靜脈接肺動脈，約 4–5 歲） | **大血管轉位手術(Arterial switch)**，冠狀動脈要重植；舊式心房轉位術（Mustard、Senning） | 補 VSD、右心室到肺動脈接人工瓣膜導管，最好 2 歲前 |

依兒科書頁 437–440 重新整理

- TGA 合併大 VSD 時混合較好，發紺**較輕**，反而要注意心衰竭；「合併 VSD 讓發紺更嚴重、立即給 100% 氧」是錯的（108-1 年考題）
- 上下肢血壓差是 **COA** 的表現，不是 TGA

## 藥物 {#drugs}

| 藥物 | 作用 | 用在 | 護理重點 |
|---|---|---|---|
| **前列腺素 E1**（PGE1，alprostadil）靜脈持續滴注 | **維持動脈導管開放** | **導管依賴型**：TGA、嚴重 PS 或肺動脈閉鎖、三尖瓣閉鎖、TOF 合併肺動脈閉鎖 | **呼吸暫停**（最重要，備好插管）、發燒、皮膚潮紅、低血壓；監測呼吸與 SpO₂ |
| **Indomethacin／ibuprofen** | 抑制前列腺素 → **關閉動脈導管** | **早產兒 PDA** | 腎血流下降 → **尿量 < 1 mL/kg/hr** 通知醫師；出血傾向、腸胃道出血；壞死性腸炎風險 |
| Digoxin | 增加收縮力、減慢心跳 | 心衰竭 | 給藥前量**心尖脈 1 分鐘**，心跳過慢依醫囑暫停；不與奶、果汁或食物混；每 12 小時一次者忘了服在 **6 小時內補**，超過就跳過、不加倍（見 [[digoxin#pediatric]]） |
| 利尿劑 | 減輕前負荷 | 心衰竭 | furosemide 低血鉀；**spironolactone 是保鉀**（高血鉀） |
| Propranolol | 減慢心跳、放鬆漏斗部 | TOF 缺氧發作預防 | 注意**心跳過慢**、低血糖 |
| 鐵劑 | 增加血紅素載氧 | 缺氧且缺鐵者 | 用吸管或滴管避免牙齒染色 |
| Aspirin | 抗血小板 | 放置關閉器、分流術後 | 不是用來增加肺血流 |

## 先天性心臟病兒童的照護 {#nursing}

依兒科書頁 440–445 重新整理

### 減少心臟負荷 {#reduce-workload}

- 觀察心輸出量不足：心跳呼吸加快、活動耐力差、蒼白或發紺、四肢冷、**尿量減少**
- **集中護理**、安撫、**減少哭泣**；**避免便祕**（閉氣用力增加心臟負擔）
- 休息時上半身抬高 **30–45 度**；心衰竭呼吸喘採**半坐臥**
- 依醫囑給利尿劑、強心劑、血管擴張劑並監測副作用

### 營養與餵食 {#feeding}

| 原則 | 做法 |
|---|---|
| 少量多餐 | 依需求餵，**每次不超過 30 分鐘**，累了就停 |
| 奶嘴 | **柔軟、洞孔稍大**省力（不可太大以免嗆到）；餵食中休息、拍背排氣 |
| 母乳 | 可親餵；吸吮差時擠出母奶用奶瓶餵；母奶鈉低，**不必換成低鈉配方** |
| 熱量 | 奶中加糖或中鏈脂肪；大孩子高熱量高蛋白、**限制高鹽食物** |
| 鼻胃管 | 吸吮力差、太累時**鼻胃管灌食**，減少耗氧 |
| 氧氣 | 用氧中的嬰兒餵食時氧氣持續給 |
| 鐵劑 | 低血氧者補**鐵**，不是鈣 |
| 監測 | 定期量**體重** |

::questions{ids="109-2_OP_063,107-1_OP_072"}

### 預防感染與心內膜炎 {#infection-prevention}

- 口腔衛生、飯後刷牙；不與呼吸道感染病童同房；流行期少去公共場所；洗手
- 高危險群在牙科治療等侵入性處置前依醫囑給**預防性抗生素**（見 [[infective-endocarditis]]）
- 依時程接種疫苗（含流感）

### 活動與發展 {#activity}

- 依心臟功能設計活動；**避免過度保護**，鼓勵自我照顧與同儕活動
- 已完全矯正者依一般兒童建議（每天累積 60 分鐘身體活動）；需限制者用「**說話測試**」（運動時還能輕鬆說話）控制強度；用抗凝劑或有節律器避免碰撞型運動(AHA 2013)
- 等張（有氧）運動如走路、游泳較適合；避免閉氣用力的等長運動

### 依認知發展解釋 {#explaining}

| 年齡 | 對心臟的理解 | 解釋方式 |
|---|---|---|
| 4–6 歲 | 心臟在胸部，像**愛心**形狀，會發出**碰碰聲** | 畫人形與心臟位置，說手術後心跳會更規律 |
| 7–10 歲 | 知道心臟不是愛心形、很重要，但不懂怎麼打血 | 畫心臟外形，說明血怎麼打出去 |
| 10–11 歲以上 | 懂靜脈、動脈與循環 | 可討論血液循環 |

兒科書頁 440

### 協助家庭 {#family}

- 重複提供資訊、用口語化說明；鼓勵父母說出擔心並參與照護
- 注意手足的需要；介紹支持團體（中華民國心臟病兒童基金會）（兒科書頁 443）

## 心臟手術護理 {#surgery}

- **密閉式手術**不碰心臟內部（如 PDA 結紮、BT 分流、COA 修補）；**開心手術**要體外循環與低溫（兒科書頁 446）
- 術前：量身高體重（算體表面積給藥）、發燒或感染要延後；依醫囑停 digoxin 與抗凝劑；依年齡做心理準備、參觀加護病房

術後重點（兒科書頁 449–451）

| 項目 | 重點 |
|---|---|
| 呼吸 | 呼吸器照護、抽痰、翻身、拍痰 |
| 循環 | 監測心跳節律、血壓、CVP、末梢灌流 |
| 尿量 | 新生兒 2–3、嬰兒約 **2**、兒童 1–2、青少年 0.5–1 mL/kg/hr；**< 1 mL/kg/hr 通知醫師** |
| 胸管 | 保持通暢、低於胸部；**連續 3 小時 > 3 mL/kg/hr** → 可能出血，通知醫師（見 [[chest-tube]]） |
| 疼痛 | 依醫囑止痛，用適齡疼痛量表 |
| 出院 | 教導 digoxin、利尿劑、鉀的給法；傷口照護；何時回診 |

- 107-2 年考題：8 個月、7 公斤嬰兒術後 24 小時尿量 60 mL（約 0.36 mL/kg/hr）→ **異常**
- 術後也可能用 ECMO 或心室輔助器支持（見 [[iabp-ecmo]]）
