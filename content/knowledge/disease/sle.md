**全身性紅斑性狼瘡(SLE)**是**典型的全身性自體免疫疾病**：身體產生針對**細胞核成分**的自體抗體，形成**免疫複合物**沉積在皮膚、關節、腎臟、血管等處，造成多器官發炎。**育齡女性最多**，病程呈**復發與緩解**交替。無法治癒，目標是**控制發炎、預防器官損傷**

## 重點摘要 {#summary}

- **屬第Ⅲ型(免疫複合物型)過敏**，起因於**無法清除凋亡細胞**使細胞核成分暴露，引發自體抗體
- 典型：**蝴蝶斑、光敏感、口腔潰瘍、關節炎、腎炎、血球低下、漿膜炎**
- **ANA** 幾乎都陽性(**敏感**)；**anti-dsDNA、anti-Sm** **特異**；**活動期補體 C3、C4 下降**；常見**貧血、白血球與血小板低下**
- **羥氯奎寧**是基礎藥；活動期用**類固醇**，嚴重器官受侵犯加**免疫抑制劑**
- 護理：**防曬**(長袖、寬邊帽、太陽眼鏡、防曬乳)、**預防感染**、**懷孕在病情穩定後**

### 國考常考點 {#exam-points}

- SLE 屬**第Ⅲ型**；是**對抗自己抗體**所引起，不是遲發型(Ⅳ型)、也不是 IgE
- **最相關的自體抗體**：**抗核抗體(ANA)**；**anti-dsDNA** 與 **anti-Sm** 特異性高
- **血液表現**：**貧血、白血球減少、血小板減少**；**不是白血球增加**；**ESR 上升**；**活動期補體下降**
- **蝴蝶斑**是典型皮膚症狀，但**不是主要或唯一**；皮膚症狀多在**日曬後加重**，**不侷限於頸部與胸部**
- **血球低下**(例如溶血性貧血)主要與**第Ⅱ型**機轉(自體抗體破壞血球)有關
- **藥物性狼瘡**：**hydralazine、procainamide、isoniazid** 等；**停藥後多數緩解**，**抗組織蛋白抗體**陽性，**很少侵犯腎與中樞神經**
- **護理指導**：**避免直接日曬**(長袖、長褲、帽子、太陽眼鏡)、**高蛋白、高維生素**飲食(有腎炎時依醫囑調整蛋白質與鹽)、**預防感染**、**病情控制良好後 3–6 個月以上才考慮懷孕**、**避免誘發**(感染、壓力、某些藥物)

## 病生理 {#pathophysiology}

1. **無法有效清除凋亡細胞**，**細胞核成分(DNA、組蛋白、核糖核蛋白)**暴露
2. **自體反應性 B 細胞**與 **T 細胞**活化，產生**抗核抗體**與**免疫複合物**
3. 複合物**沉積**在腎絲球、皮膚、關節、血管 → 活化**補體** → **嗜中性球**浸潤 → **發炎與組織傷害**(第Ⅲ型，[[hypersensitivity-reactions#type-3]])
4. 補體被**消耗**，所以**活動期 C3、C4 下降**；**早期補體(C1q、C2、C4)缺乏**反而使人更容易得 SLE，因為凋亡細胞與複合物清除不良([[complement-system]])
5. **血球低下**由**抗血球抗體**造成(**第Ⅱ型**)
6. **危險因子**：**女性(雌激素)**、**遺傳(HLA-DR2、DR3 等)**、**紫外線**、**EB 病毒等感染**、某些**藥物**、**吸菸**

## 臨床表現 {#clinical}

| 系統 | 表現 |
|---|---|
| **全身** | **疲倦**、發燒、體重減輕、淋巴結腫 |
| **皮膚黏膜** | **蝴蝶斑**(面頰與鼻樑的紅斑，**不侵犯鼻唇溝**)、**盤狀紅斑**、**光敏感**、**口腔或鼻腔潰瘍(多無痛)**、**脫髮**、雷諾氏現象 |
| **肌肉骨骼** | **關節痛與關節炎**(多為**對稱、非侵蝕性**，僵硬、腫脹、壓痛)，手與膝最常見 |
| **腎臟** | **狼瘡腎炎**：**蛋白尿、血尿、水腫、高血壓**，是預後的重要因素 |
| **血液** | **溶血性貧血**、**白血球減少**(淋巴球低下)、**血小板減少** |
| **漿膜** | **胸膜炎**(胸痛)、**心包膜炎** |
| **神經精神** | 頭痛、癲癇、**精神症狀**、認知問題、中風 |
| **心肺** | 心內膜炎(Libman-Sacks)、肺炎、肺高壓、**加速的動脈硬化** |

1. **皮膚症狀**不限於蝴蝶斑，暴露在陽光的部位(頸、胸、手臂)都可能出現
2. **抗磷脂質抗體**：**血栓**(靜脈與動脈)與**習慣性流產**；**抗 Ro(SSA)**：**新生兒狼瘡**與**先天性心臟傳導阻滯**
3. **急性發作的誘因**：**日曬、感染、壓力、停藥、懷孕與產後、某些藥物**

## 診斷 {#diagnosis}

### 抗體與檢驗 {#labs}

| 檢驗 | 意義 |
|---|---|
| **ANA(抗核抗體)** | **敏感**(幾乎全部 SLE 都陽性)但**特異性低**，其他自體免疫與健康人都可能陽性；**ANA 陰性**時 SLE 的可能性很低 |
| **Anti-dsDNA** | **特異性高**；**效價與疾病活動及狼瘡腎炎相關** |
| **Anti-Sm** | **特異性高**，但敏感度低 |
| **補體 C3、C4** | **活動期下降**(尤其腎炎)；用來追蹤疾病活動 |
| **抗磷脂質抗體** | 血栓與流產風險 |
| **Anti-Ro(SSA)／La(SSB)** | 新生兒狼瘡、乾燥症 |
| **血球計數** | **貧血、白血球減少、血小板減少** |
| **ESR、CRP** | **ESR 常上升**；**CRP 在 SLE 活動時常不明顯上升**，上升時要考慮感染 |
| **尿液** | **蛋白尿、血尿、細胞圓柱** |
| **直接庫姆斯試驗** | 自體免疫溶血性貧血 |

### 分類標準 {#classification}

1. **2019 EULAR／ACR 分類標準**
   1. **進入條件**：**ANA 陽性**(UpToDate 指出需要有 ANA 陽性作為進入標準)
   2. **計分**：七個臨床領域與三個免疫領域，每項權重 2–10
   3. 總分 **≥ 10 分**即分類為 SLE(UpToDate 轉述：敏感度約 96%，特異度約 93%)
2. 較舊的 **ACR 1997** 的 11 項標準仍常見於教科書與考題(例如：蝴蝶斑、盤狀疹、光敏感、口腔潰瘍、關節炎、漿膜炎、腎病變、神經病變、血液異常、免疫異常、ANA)，**符合 4 項**
3. **分類標準不是診斷標準**，臨床診斷仍靠整體判斷

## 治療 {#treatment}

目標：**達到緩解或低疾病活動**、**預防器官損傷**、**減少類固醇用量**。

| 藥物 | 用途與重點 |
|---|---|
| **羥氯奎寧(hydroxychloroquine)** | **幾乎所有病人的基礎治療**，減少發作、器官損傷與血栓；**每年眼科檢查**(視網膜毒性) |
| **類固醇** | **活動期**快速控制；**重症**用高劑量或脈衝治療；盡量**低劑量、短期**；副作用見下 |
| **免疫抑制劑** | **azathioprine、mycophenolate**、methotrexate、**cyclophosphamide**(重度腎炎或神經侵犯)；見 [[immunosuppressants]] |
| **生物製劑** | **belimumab**(抗 BAFF／BLyS)等，用於標準治療無效者 |
| **NSAID** | 緩解關節痛與漿膜炎；**要注意腎功能**(狼瘡腎炎者避免) |
| **其他** | 抗凝治療(抗磷脂質症候群)、**降血壓與降血脂**、骨質保護 |

1. **無法治癒**，**以降低炎症和損傷為目標**
2. **類固醇副作用**：庫欣氏臉、體重增加、高血糖、高血壓、**骨質疏鬆**、感染、情緒改變、白內障；**不可自行停藥**，要逐漸減量
3. **預後**：感染與心血管疾病、腎炎是主要死因；**長期存活率已大幅改善**

## 特殊情況 {#special}

### 懷孕與新生兒 {#pregnancy}

1. **懷孕前**：先讓病情**穩定至少 6 個月**(UpToDate)，並使用**與懷孕相容**的藥物(羥氯奎寧、azathioprine 等可繼續，**mycophenolate、cyclophosphamide、methotrexate** 要在懷孕前停)
2. **懷孕風險**：**流產、早產、子癇前症、狼瘡發作**；**抗磷脂質抗體**增加胎兒死亡與血栓風險
3. **抗 Ro／La 抗體**陽性母親的新生兒可出現**新生兒狼瘡**(皮疹，多為暫時性)與**先天性心臟傳導阻滯**(永久性)
4. **避孕**：**活動期或抗磷脂質抗體陽性**時避免含雌激素的避孕藥
5. 台灣常見護理指導：「**病情控制良好後 3–6 個月**可與醫師討論懷孕計畫」；UpToDate 強調**至少 6 個月**，兩者精神一致，**以醫師評估為準**

### 藥物性狼瘡 {#drug-induced}

1. 常見藥物：**hydralazine、procainamide、isoniazid**、部分抗生素、minocycline、TNF 抑制劑
2. 表現較輕：**發燒、關節痛、漿膜炎**；**很少**侵犯腎臟與中樞神經；**抗組織蛋白抗體**常陽性，**anti-dsDNA** 少見
3. **停藥後多可緩解**(數週到數月)，通常不需要長期免疫抑制

## 護理 {#nursing}

1. **防曬**
   1. **避免直接日曬**與其他紫外線來源(包括某些燈具)，**外出穿長袖、長褲，戴寬邊帽與太陽眼鏡**
   2. **使用防曬乳**(UpToDate 建議 SPF ≥ 55，可阻擋 UVA 與 UVB)，**即使陰天**
   3. **避免**增加光敏感的藥物(例如磺胺類、四環黴素)
2. **預防感染**：**勤洗手**、避免人潮聚集與接觸感染者、**接種不活化疫苗**(流感、肺炎鏈球菌)，**使用免疫抑制劑時避免活性減毒疫苗**([[immunization]])
3. **飲食**：**均衡、高蛋白、高維生素**；有**腎炎與高血壓**時依醫囑**低鹽**與調整蛋白質；補充**鈣與維生素 D**(防止類固醇骨質疏鬆)；避免**苜蓿芽**(含刀豆胺酸，可能誘發活動)(待核對)
4. **休息與運動**：疲倦時**休息**，緩解期適度運動(減少疲倦、保護骨質)；避免過度勞累
5. **皮膚與關節**：**溫水**清潔、避免刺激性清潔劑與染髮、**關節保護**
6. **用藥**：**不可自行停用類固醇**；每年**眼科檢查**(羥氯奎寧)；**定期追蹤**尿液、血球、補體
7. **懷孕**：病情穩定後與醫師討論，**避免不相容的藥物**；規畫產前照護
8. **心理與社會支持**：外觀改變(**月亮臉、脫髮、皮疹**)與慢性病負擔易造成**憂鬱與自我形象**問題，青少年尤其要支持**自我概念**；介紹病友團體
9. **觀察惡化**：**發燒、水腫、泡沫尿、血尿、胸痛、呼吸困難、神經症狀**要立即就醫
