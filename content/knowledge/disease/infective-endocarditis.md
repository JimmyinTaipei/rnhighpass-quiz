**感染性心內膜炎**是微生物感染心臟內膜，最常見於**心臟瓣膜**，在瓣膜上形成含細菌、血小板與纖維蛋白的**贅生物**。它會破壞瓣膜，造成**心雜音、心衰竭**；贅生物脫落會造成**全身栓塞**。本頁也整理其他心臟發炎疾病：**風濕性心臟病**、**心肌炎**、**心包膜炎與心包填塞**。

## 重點摘要 {#summary}

- **感染性心內膜炎**：瓣膜上形成**贅生物**，破壞瓣膜造成心雜音與心衰竭，脫落造成**全身栓塞**；最常見菌種是**金黃色葡萄球菌**。
- 周邊徵象：**裂片狀出血**、**Janeway 病灶**(無痛)、**Osler 結節**(疼痛)、**Roth 斑**(視網膜)。
- **風濕熱**：5–15 歲、咽喉鏈球菌感染後、最常侵犯二尖瓣；診斷看**瓊斯氏標準**與 ASO；用抗生素，心衰竭時低鹽。
- **心肌炎**最常見原因是病毒；**心包膜炎**胸痛平躺加重、前傾減輕。
- **心包填塞**：低血壓、頸靜脈怒張、心音低沉(Beck 三徵)，可有奇異脈。

### 國考常考點 {#exam-points}

- 心內膜炎最常見的菌種：**金黃色葡萄球菌**；它造成的心內膜炎**不是毒素**引起的。
- 周邊徵象：**裂片狀出血**在指甲床；**Janeway 病灶**在手掌腳底，**無痛**；**Osler 結節**在指趾腹，**疼痛**；**Roth 斑**在**視網膜**，不是四肢。
- 常見**腦栓塞**、心雜音；二尖瓣贅生物易造成全身栓塞。
- 懷疑心內膜炎要問**心臟血管手術史**。
- 亞急性細菌性心內膜炎屬**第三型過敏反應**(免疫複合物)。
- 風濕熱：**5–15 歲**；**咽喉**鏈球菌感染後；主要表現**心臟炎**；最常侵犯**二尖瓣**；**ESR 上升**；**ASLO** 協助診斷；皮下結節**無痛**；是**自體免疫、非細菌性**發炎。
- 瓊斯氏主要標準不包括**白血球增多**與**凝血時間延長**；風濕熱沒有**結膜炎**與**四肢末梢脫皮**(那是川崎氏症)。
- 風濕熱治療：**抗生素**；心衰竭時**低鹽**；**不要**多做體能活動；病理為**阿孝夫氏小體**。
- 兒童最常見的後天性心臟病：**川崎氏症**；IVIG 降低冠狀動脈瘤。
- 心肌炎最常見原因：**病毒**；**不做阻力運動**；心肌炎是擴張性心肌病變常見的原因。
- 心包膜炎胸痛**平躺加重、坐起前傾減輕**；可用 aspirin；縮窄性心包炎最常見病因是**結核**。
- 心包填塞：**低血壓、頸靜脈怒張、心音低沉**、**奇異脈**、CVP 上升；**脈搏壓變窄**、收縮壓不會上升、摩擦音不會增強。

## 感染性心內膜炎 {#infective-endocarditis}

### 致病菌與危險因子 {#ie-causes}

| 型態 | 常見菌 | 特點 |
|---|---|---|
| **急性** | **金黃色葡萄球菌**(**目前最常見**，見 [[staphylococcus-aureus]]) | 可侵犯**正常瓣膜**；進展快、破壞大；**靜脈藥癮者**常侵犯**三尖瓣** |
| **亞急性** | **草綠色鏈球菌**([[streptococci#viridans-streptococci]])、腸球菌 | 多發生在**已受損的瓣膜**(風濕性心臟病、先天性心臟病)；常與**牙科處置**有關；病程數週到數月 |
| 人工瓣膜 | 凝固酶陰性葡萄球菌、金黃色葡萄球菌 | 手術後早期多為院內菌([[gram-positive-bacteria#coagulase-negative-staphylococci]]) |

- **危險因子**：**人工瓣膜**、**曾得過心內膜炎**、先天性心臟病、**風濕性心臟病**等瓣膜疾病、**心臟手術**、**靜脈藥癮**、長期中心靜脈導管、血液透析、口腔衛生差。
- 懷疑心內膜炎時，護理師最需要收集的是**心臟瓣膜或心臟血管手術史**。

### 致病機轉 {#ie-mechanism}

- 瓣膜內皮受損 → 血小板與纖維蛋白沉積 → 菌血症時細菌附著 → 形成**贅生物**。
- 贅生物脫落 → **栓塞**(腦、脾、腎、四肢)；右心贅生物則造成肺栓塞。
- 抗原抗體**免疫複合物**沉積 → 腎絲球腎炎、Osler 結節、Roth 斑。亞急性細菌性心內膜炎屬於**第三型過敏反應**(免疫複合物媒介)。
- 金黃色葡萄球菌心內膜炎是**細菌直接侵犯**瓣膜，不是毒素造成的。

### 臨床表現 {#ie-manifestations}

- **發燒**：最常見(約 9 成)，合併倦怠、食慾差、體重減輕。
- **新出現或改變的心雜音**(約 85%)；瓣膜破壞可造成**心衰竭**。
- **栓塞**：**腦栓塞(中風)**常見；也可造成脾梗塞、腎梗塞、肢體缺血。
- 周邊徵象：

| 徵象 | 位置 | 特點 |
|---|---|---|
| **裂片狀出血**(splinter hemorrhage) | **指甲床** | 線狀紅褐色出血 |
| **Janeway 病灶** | **手掌、腳底** | **無痛性**紅斑 |
| **Osler 結節** | **手指、腳趾指腹** | **疼痛性**紅紫色小結節 |
| **Roth 斑** | **視網膜** | 中心蒼白的出血斑；**不是**在四肢末梢 |
| 瘀點 | 結膜、口腔黏膜、皮膚 | — |

- 其他：脾腫大、杵狀指(亞急性)、血尿(腎絲球腎炎)。

### 診斷 {#ie-diagnosis}

- **血液培養**：**給抗生素前**抽 **2–3 套**，從不同穿刺部位抽，最好間隔抽取([[culture-and-sensitivity#blood-culture]])。
- **心臟超音波**：先做經胸壁超音波，看**贅生物**、瓣膜破壞與膿瘍；**經食道心臟超音波**(TEE)敏感度較高([[echocardiography]])。
- **Duke 準則**(2023 Duke-ISCVID 版)：
  - **主要準則**：典型菌的**血液培養陽性**；影像顯示**贅生物**、膿瘍或新的人工瓣膜滲漏；手術中直接看到。
  - **次要準則**：易感因素(瓣膜病、人工瓣膜、藥癮)、**發燒 ≥ 38°C**、**血管現象**(栓塞、Janeway 病灶)、**免疫現象**(Osler 結節、Roth 斑、腎絲球腎炎)、不符合主要準則的微生物證據。
  - 確定診斷：2 項主要準則，或 1 主要＋3 次要，或 5 項次要。
- 其他：貧血、ESR 與 CRP 上升、血尿。

### 治療與護理 {#ie-treatment}

- **長期靜脈抗生素**：自體瓣膜一般 **4–6 週**，依菌種與感受性選藥，例如青黴素或頭孢菌素，MRSA 用 vancomycin([[glycopeptides]])；人工瓣膜療程更長。
- **手術**：瓣膜嚴重破壞造成心衰竭、瓣膜膿瘍、贅生物大且反覆栓塞、黴菌感染、抗生素控制不佳時，做瓣膜置換。
- 護理：
  1. 準時給抗生素、維持**長期靜脈管路**，監測藥物血中濃度與腎功能。
  2. 監測體溫、心雜音變化與心衰竭徵象。
  3. 觀察**栓塞徵象**：意識改變、肢體無力、腹痛、血尿、肢體冰冷。
  4. 發燒時臥床休息，減少心臟負荷。
  5. 衛教**口腔衛生**與定期看牙，比預防性抗生素更重要。

### 預防性抗生素 {#prophylaxis}

依 AHA 2021 聲明，只有**最高風險**的病人在**牙科處置**前需要預防性抗生素([Wilson 2021](https://doi.org/10.1161/CIR.0000000000000969))。

- **最高風險的病人**：
  - **人工瓣膜**或瓣膜修補材料。
  - **曾得過感染性心內膜炎**。
  - 特定**先天性心臟病**：未矯正的發紺型心臟病、術後 6 個月內，或修補後仍有殘餘缺損。
  - 心臟移植後有瓣膜病變。
- **哪些處置要給**：會**動到牙齦**、牙根尖周圍或穿破口腔黏膜的牙科處置，例如**拔牙**、洗牙。一般泌尿道與腸胃道處置**不需要**。
- **怎麼給**：處置前 **30–60 分鐘**口服 **amoxicillin 2 g** 單次；青黴素過敏者改用其他藥物(azithromycin、doxycycline 等)。

## 風濕熱與風濕性心臟病 {#rheumatic-heart-disease}

**A 群 β 型溶血性鏈球菌**造成**咽喉炎**後約 2–4 週，身體產生的抗體與心臟、關節組織發生**交叉反應**。這是**自體免疫**、**非化膿性**的發炎，不是細菌直接感染心臟。菌的特性與瓊斯氏標準見 [[streptococci#streptococcus-pyogenes]]。

- **好發年齡**：**5–15 歲**兒童；不是 65 歲以上女性。
- 感染源是**咽喉**感染，**不是皮膚**感染(皮膚感染可造成腎絲球腎炎，但不會造成風濕熱)。
- **瓊斯氏標準**：

| 主要標準 | 次要標準 |
|---|---|
| **心臟炎**(最主要的臨床表現) | 發燒 |
| **多發性、遊走性關節炎** | 關節痛 |
| **舞蹈症**(Sydenham) | **ESR、CRP 上升** |
| **邊緣性紅斑** | 心電圖 PR 間期延長 |
| **皮下結節**：**無痛**、位於骨突處與肌腱 | — |

- 需有**先前鏈球菌感染的證據**：**ASLO(ASO)效價上升**或咽喉培養陽性。
- 白血球增多、凝血時間延長**不是**瓊斯氏標準。結膜炎、四肢末梢脫皮是**川崎氏症**的表現。
- 病理：心肌內的**阿孝夫氏小體**(Aschoff body)。
- **風濕性心臟病**：最常侵犯**二尖瓣**(其次主動脈瓣)，造成狹窄或逆流。
- **治療**：
  1. **青黴素**清除鏈球菌。
  2. **阿斯匹靈**等抗發炎藥治療關節炎；嚴重心臟炎時用類固醇。
  3. **心臟炎急性期臥床休息**，不要從事劇烈體能活動。
  4. 有心衰竭症狀時**低鹽飲食**、利尿劑。
- **次級預防**：長效 **benzathine penicillin G** **每 3–4 週肌肉注射**一次，防止再感染而復發。持續時間依心臟受損程度而定：
  - 無心臟炎：5 年或到 21 歲。
  - 有心臟炎：10 年以上。
  - 有殘留瓣膜病變：可到 40 歲或終身。

| 比較 | **風濕熱** | **川崎氏症** |
|---|---|---|
| 病因 | A 群鏈球菌咽喉炎後的免疫反應 | 不明，血管炎 |
| 年齡 | 5–15 歲 | **5 歲以下** |
| 特徵 | 心臟炎、遊走性關節炎、舞蹈症、邊緣性紅斑、皮下結節 | 發燒 ≥ 5 天、**結膜充血**、草莓舌、**四肢末梢脫皮**、頸部淋巴結腫大 |
| 心臟 | **瓣膜**(二尖瓣) | **冠狀動脈瘤** |
| 治療 | 青黴素、阿斯匹靈 | **IVIG**(降低冠狀動脈瘤)＋**高劑量阿斯匹靈** |

- **川崎氏症**是已開發國家兒童**最常見的後天性心臟病**。

## 心肌炎 {#myocarditis}

- **最常見原因是病毒**，尤其是**克沙奇 B 型病毒**等腸病毒；其他原因包括**白喉外毒素**、自體免疫、藥物。
- 表現：類流感症狀後出現胸痛、心悸、呼吸困難、心律不整、心衰竭；可演變成**擴張性心肌病變**。
- **護理**：
  1. **臥床休息**、限制活動，以減少心肌耗氧；恢復期逐步增加活動，**不做阻力運動**或劇烈運動。
  2. 心衰竭時**限制水分與鈉**，減少前負荷。
  3. 心肌炎病人**對毛地黃敏感**，使用時要監測脈搏與中毒徵象([[digoxin]])。
  4. 使用類固醇時觀察**糞便顏色**，注意腸胃道出血。

## 心包膜炎與心包填塞 {#pericarditis}

- **病因**：病毒(最常見)、細菌、**結核菌**、心肌梗塞後、尿毒症、自體免疫(紅斑性狼瘡)、放射治療。慢性肉芽腫性發炎造成**縮窄性心包炎**，最常見的病因是**結核菌**。
- **表現**：
  - **胸痛**：尖銳，**深呼吸、咳嗽、平躺時加重**，**坐起前傾時減輕**。
  - **心包膜摩擦音**。
  - 發燒。
  - 心電圖廣泛性 ST 上升。
- **護理**：
  1. 協助**坐起前傾**，**不要**鼓勵平躺深呼吸。
  2. 發燒時臥床休息，減少心肌耗氧。
  3. 依醫囑給 **aspirin 或 NSAID**、colchicine([[nsaids-acetaminophen]])。
  4. 提供高蛋白、高醣飲食。
  5. 監測有無心包填塞。

### 心包填塞 {#cardiac-tamponade}

心包腔液體快速增加，壓迫心臟，使心室舒張充填受限，心輸出量下降。

| 表現 | 說明 |
|---|---|
| **貝克氏三病徵** | **低血壓**、**頸靜脈怒張**(**中心靜脈壓上升**)、**心音遙遠低沉** |
| **奇異脈** | **吸氣時**收縮壓下降 > 10 mmHg，脈搏變弱 |
| **脈搏壓變窄** | 不是變寬 |
| 其他 | **心跳加快**、呼吸困難、**尿量減少**；液體增加後**摩擦音反而減弱** |

- 收縮壓**不會上升**。
- 處置：緊急**心包膜穿刺術**或手術引流。術後監測生命徵象與心電圖，確認引流管通暢，補充足夠體液以維持心輸出量；**不需要保護隔離**。
