**脊髓損傷**多由車禍、高處跌落、運動傷害造成，損傷平面以下的運動、感覺與自主神經功能受影響。急性期重點是**固定脊椎、維持呼吸與血壓**，之後要預防**自主神經反射異常**、處理**神經性膀胱與腸道**、預防壓傷，並長期復健（制動的影響與關節運動見 [[activity-immobility]]）。脊髓徑路、Brown-Séquard 症候群與上下運動神經元見 [[spinal-cord-spinal-nerves#tracts]]，排尿反射與自主神經見 [[autonomic-nervous-system#visceral-reflexes]]

## 重點摘要 {#summary}

- **C3–C5 支配橫膈**（膈神經）：C4 以上完全損傷**無法自行呼吸**；**頸髓**受傷 → **四肢癱瘓**；胸腰受傷 → **下半身癱瘓**
- **脊髓休克**：受傷後立即出現，損傷以下**弛緩性癱瘓、感覺消失、所有反射消失**（包括**肛門反射**）、尿滯留、**麻痺性腸阻塞**；**肛門反射（球海綿體反射）恢復** = 脊髓休克結束
- **神經性休克**（T6 以上，特別是頸髓）：交感中斷 → **低血壓、心跳變慢**、皮膚溫暖乾燥、**體溫隨環境下降**
- **自主神經反射異常**：**T6 以上**、**脊髓休克期之後**；最常見誘因**膀胱脹**；**血壓極高、心跳變慢、搏動性頭痛**、病灶以上潮紅冒汗；**立刻讓病人坐起**、每 2–5 分鐘量血壓、**找出並移除誘因**（先查膀胱）
- 神經性膀胱：**S2 以上**損傷 → **反射型（痙攣型）**，敲恥骨上方、刺激大腿內側或肛門可誘發排尿；**S2–S4** 損傷 → **弛緩型（溢尿型）**，用 Credé 法、間歇導尿、bethanechol
- 搬動與翻身：**圓滾木翻身法**，頭頸軀幹成一直線，**枕頭放兩膝之間**；疑似頸椎損傷打開呼吸道用**推顎法**
- 完全或不完全損傷要靠**神經學檢查**（尤其薦部感覺與肛門收縮）判斷，不是電腦斷層

### 國考常考點 {#exam-points}

- C3–C5 完全損傷：四肢癱瘓、**無法自行呼吸**、損傷以下所有運動感覺反射消失；會**心搏過緩、低血壓**（不是心搏過速、高血壓）
- T12–L3 損傷的脊髓休克：大小便無法控制、腹脹、肛門反射消失；**可以自行呼吸**
- 頸椎損傷造成呼吸衰竭的原因是**肺泡通氣不足**（肺栓塞不是）
- 脊髓休克期：損傷以下運動、感覺、**反射減弱或消失**（**肛門反射不正常**）、**尿滯留**、腸蠕動下降；血壓不會是 160/100
- 判斷已渡過脊髓休克期：**肛門反射**出現（不是作嘔、頭眼、角膜反射）
- 脊髓休克期照護：可插**鼻胃管**減壓、考題答案可用高劑量類固醇；**電腦斷層不能確診完全或不完全損傷**
- **神經性休克**：車禍脊髓受損；頸髓損傷的神經性休克徵象是**體溫下降**
- 自主神經反射過度：發生在 **T6 以上**（不是 T6–T12）、脊髓休克期**之後**；**嚴重高血壓、搏動性頭痛**、**心跳變慢**；病灶**以上**潮紅冒汗；誘因是膀胱脹（走路不是）
- 自主神經反射過度的立即處置：**抬高床頭**（坐起）；不需插管；**不是等血壓正常才排除誘因**；**不是每 30 分鐘**才量血壓
- T3–T5 損傷、血壓 250/140、心跳 50、大量出汗、劇烈頭痛、6 小時沒解尿 → **自主神經過度反射**
- 頸椎 C5–6 完全損傷、過了休克期 → **痙攣型神經性膀胱**、薦神經受刺激即可**反射排尿**；**Credé 法不適用**於這型
- 肛門反射與外括約肌張力**陽性** → S2–S4 排尿反射中樞**完整**；上運動神經元型用**反射**排尿，下運動神經元型才用 Credé 法
- 上運動神經元型可**敲恥骨上緣或刺激肛門**誘發排尿；下運動神經元型的反射中樞**不完整**、**不能**靠反射排尿
- 頸椎受損大小便失禁：**重複輕敲恥骨上方**刺激排尿；不要每小時喝 300 mL；凱格爾運動不適用
- 脊髓損傷無法自行排空膀胱：考題答案是**以手向下壓迫膀胱部位**（Credé 法）；不要限水到 1,000 mL、不建議長期留置導尿管
- Gardner-Wells 頸椎牽引：**移除時漸進減重**；砂袋不是越重越好；裝上後**立即**照 X 光；骨釘處不是每天用優碘消毒 3 次
- 頸椎損傷有氣切與鼻胃管、需要抽痰時的翻身：**左側臥床頭 30–45 度 → 半坐臥 → 右側臥床頭 30–45 度 → 半坐臥**（避免完全平躺）
- 脊椎手術後：**圓滾木翻身**、脊柱平直、翻身單抓肩與臀；**不可俯臥**；**不用一般便盆**；中硬度床墊；觀察腦脊髓液滲漏與手腳感覺運動
- 圓滾木翻身：枕頭放**兩膝之間**（不是膝膕下）
- 脊髓損傷病人感覺喪失，是**熱療的高危險族群**
- 病人說「乾脆死了算了」，回答「努力復健一定會好起來」是**不適當的保證**
- 四肢癱瘓返家、妻子照顧疲憊、浴室狹小：**復健訓練、喘息服務、居家無障礙改善**；社區照顧關懷據點**不適合**（對象是 65 歲以上長者）

## 損傷平面與功能 {#levels}

| 完全損傷平面 | 保留的功能 | 照護重點 |
|---|---|---|
| **C1–C3** | 頭部少量活動 | **需要呼吸器**、完全依賴 |
| **C4** | 頭頸控制、聳肩；橫膈部分功能 | 可能需要呼吸器；可用口控或下巴控制電動輪椅 |
| **C5** | 肩膀、**屈肘**（肱二頭肌） | 橫膈功能保留；進食需輔具 |
| **C6** | **伸腕** | 可用腕部帶動手指抓握（肌腱固定作用），部分自我照顧 |
| **C7** | **伸肘**（肱三頭肌） | 可自行轉位、推手動輪椅 |
| C8–T1 | 手指功能 | 生活大致自理（輪椅） |
| T2–T12 | 上肢完整、軀幹部分 | **下半身癱瘓**；T6 以上仍有自主神經反射異常風險 |
| L1–L5 | 部分下肢 | 可能用支架與柺杖行走 |
| **S2–S4** | 下肢多數保留 | **膀胱、腸道與性功能**障礙 |

- 神經叢與皮節見 [[spinal-cord-spinal-nerves#plexuses]] 與 [[spinal-cord-spinal-nerves#dermatomes]]
- 頸椎與上胸椎損傷還會影響肋間肌與腹肌 → 咳嗽無力、痰咳不出

### 完全與不完全損傷 {#complete-incomplete}

- **完全損傷**：損傷平面以下，包括**最下端薦髓(S4–S5)**的感覺與運動**完全沒有**；**不完全損傷**：薦部仍保留部分感覺或肛門自主收縮
- 用 **ASIA 分級**（AIS A 完全損傷 → E 正常），要靠**神經學檢查**判斷；電腦斷層看骨折與壓迫，**不能確定**是否完全損傷；而且要等脊髓休克結束才能確定

| 不完全損傷型態 | 機轉 | 表現 |
|---|---|---|
| **中央脊髓症候群** | 老人頸椎過度伸展 | **上肢比下肢無力**、手最嚴重 |
| 前脊髓症候群 | 脊髓前動脈缺血、屈曲傷 | 損傷以下**運動與痛溫覺喪失**，**本體感覺與震動覺保留** |
| **脊髓半側截斷**(Brown-Séquard) | 穿刺傷 | **同側**運動與本體感覺喪失、**對側**痛溫覺喪失（見 [[spinal-cord-spinal-nerves#brown-sequard]]） |
| 馬尾症候群 | L1 以下馬尾受壓 | 下肢弛緩性無力、**鞍狀麻木**、大小便功能障礙 |

## 急性期 {#acute-phase}

### 脊髓休克與神經性休克 {#spinal-neurogenic-shock}

| | **脊髓休克** | **神經性休克** |
|---|---|---|
| 本質 | 損傷以下**脊髓反射暫時全部消失** | 交感神經中斷造成的**血流動力學休克** |
| 平面 | 任何平面 | **T6 以上**（特別是頸髓） |
| 表現 | **弛緩性癱瘓**、感覺消失、**深部肌腱反射與肛門反射消失**、**尿滯留**、**麻痺性腸阻塞**與腹脹、無法排汗 | **低血壓**、**心跳變慢**、皮膚**溫暖乾燥**、**體溫隨環境改變**（多為**下降**）、少尿 |
| 時間 | 數天到數週（可到數月） | 數天到數週 |
| 結束的徵象 | **肛門反射**（球海綿體反射）恢復，之後反射亢進、痙攣出現 | 血壓心跳回穩 |
| 處置 | 導尿、**鼻胃管減壓**、預防壓傷與深部靜脈栓塞 | 輸液、升壓劑、心跳過慢時 atropine；保暖 |

- 脊髓休克期間，損傷以下的所有反射都消失，**不會**出現自主神經反射異常
- 神經性休克和其他休克的區別：過敏性休克（蜜蜂螫傷）、阻塞性休克（張力性氣胸）、心因性休克（心肌梗塞）都會**心跳加快**，神經性休克是**心跳變慢**
- 脊髓休克的基礎見 [[spinal-cord-spinal-nerves#spinal-shock]]

### 固定、牽引與治療 {#immobilization}

1. **現場與急診**：假設有脊椎損傷，**頸圈與長背板**固定；呼吸道用**推顎法**；搬動時多人合作、**圓滾木翻身**
2. **呼吸**：C3–C5 損傷觀察呼吸次數、肺活量、血氧；呼吸衰竭時插管與呼吸器
3. **血壓**：避免低血壓，維持脊髓灌流
4. **類固醇**
   1. 考題答案：急性期可用**高劑量 methylprednisolone** 減輕脊髓水腫
   2. 美國神經外科學會(AANS／CNS)2013 年**不建議**使用：感染、腸胃出血等副作用，效益不明（來源：[Hurlbert 等，Neurosurgery 2013](https://doi.org/10.1227/NEU.0b013e31827765c6)）
   3. AOSpine 2017：受傷 **8 小時內**開始、**24 小時**的療程可以作為**選項**（來源：[Fehlings 等，Global Spine J 2017](https://doi.org/10.1177/2192568217703085)）
   4. 現行指引意見分歧，依醫囑使用
5. **頸椎骨骼牽引**（Gardner-Wells、Crutchfield 頭骨牽引鉗）
   1. 重量**依醫囑**，不是越重越好（過重會過度牽引、傷到神經血管）
   2. 裝上後**立即照 X 光**確認復位
   3. 砂袋**懸空**、不可碰地或放在床上，不可任意拿掉
   4. 骨釘處依各院規範清潔（常用生理食鹽水或 chlorhexidine），觀察感染
   5. **移除時漸進減重**，不可一次全部拿掉
6. **頭環背架**(halo vest)：頭環以骨釘固定在顱骨，連接背心；可早期下床；**背心邊緣下墊薄棉布保護皮膚**；床邊備扳手，急救時可打開前片
7. **手術**：減壓、復位與內固定（融合）

## 自主神經反射異常 {#autonomic-dysreflexia}

- 機轉、誘因與表現見 [[autonomic-nervous-system#autonomic-dysreflexia]]
- 發生在 **T6 以上**、**脊髓休克期之後**（反射恢復後）
- **誘因**：**膀胱脹**（最常見，導尿管扭折或阻塞）、便秘與糞便嵌塞、壓傷、嵌甲、緊身衣物、月經或分娩
- **表現**：血壓突然**極高**、**心跳變慢**、**劇烈搏動性頭痛**、視力模糊、鼻塞、**病灶以上潮紅冒汗**，病灶以下**蒼白**、雞皮疙瘩
- **立即處置**（來源：[Consortium for Spinal Cord Medicine 2020 指引](https://pva.org/wp-content/uploads/2021/09/CPG_Autonomic-Dysreflexia_2025_digital_03.26-.pdf)）
  1. **立刻讓病人坐起**（床頭抬高），雙腳放低，利用姿勢性低血壓降壓
  2. **鬆開緊的衣物**與束帶
  3. **每 2–5 分鐘量一次血壓**
  4. **同時找出並移除誘因**：先查**膀胱**（導尿管是否扭折阻塞，沒有導尿管就導尿），再查直腸（用含局部麻醉劑的潤滑劑），**不是等血壓正常才處理**
  5. 收縮壓仍很高時依醫囑給速效降壓藥
- 預防：規律排尿與排便、教導病人與家屬辨認症狀、隨身帶說明卡

## 神經性膀胱與腸道 {#bladder-bowel}

| | 上運動神經元型（反射型、痙攣型） | 下運動神經元型（弛緩型、溢尿型） |
|---|---|---|
| 損傷位置 | **S2 以上**（包括頸髓、胸髓） | **S2–S4** 薦髓、馬尾 |
| 排尿反射中樞 | **完整**（肛門反射與外括約肌張力**陽性**） | **被破壞** |
| 膀胱 | 容量**小**、不自主收縮、可能與括約肌不協調 | 容量**大**、逼尿肌無力、**溢尿** |
| 排尿訓練 | **誘發反射排尿**：**輕敲恥骨上方**、輕撫大腿內側、拉陰毛、**刺激肛門**；配合間歇導尿 | **Credé 法**（雙手在恥骨上方往下往前壓）、Valsalva 法、**間歇導尿**；可用 **bethanechol** 增加逼尿肌收縮（見 [[cholinergic-drugs#direct-agonists]]） |

- **膀胱訓練**
  1. 脊髓休克期先導尿；之後盡量改**間歇導尿**，長期留置導尿管易感染與結石
  2. 水分每天約 **2,000–3,000 mL**，白天**平均分配**（約每小時 100–150 mL），睡前減少；**不可以限水**（會增加感染與結石），也不要一次大量
  3. 定時排尿或導尿，量**餘尿**；餘尿越少越成功（常用餘尿 < 50–100 mL 為目標，各書標準不同）
  4. 凱格爾運動用於應力性尿失禁，對脊髓損傷的神經性膀胱沒有幫助
- 腸道：**定時排便訓練**（飯後利用胃結腸反射）、高纖、足夠水分、軟便劑或塞劑、手指刺激肛門；預防糞便嵌塞（也是自主神經反射異常的誘因）
- 兩型膀胱的生理背景見 [[autonomic-nervous-system#neurogenic-bladder]]

## 護理與復健 {#nursing}

1. **呼吸**
   1. 咳嗽無力 → 協助咳嗽（在上腹部隨咳嗽往上推）、抽痰、深呼吸訓練、翻身
   2. 有**氣切與鼻胃管**時避免完全平躺：**側臥床頭 30–45 度與半坐臥交替**，減少逆流與吸入
2. **皮膚**：感覺喪失、不能動 → **壓傷**高風險（見 [[pressure-injury]]）；每 2 小時翻身、輪椅上每 15–30 分鐘減壓；感覺喪失是**熱療的高危險族群**（容易燙傷）；長期傷口先**評估影響癒合的因素**
3. **心血管**：姿勢性低血壓（坐起要慢、彈性襪、腹帶）、**深部靜脈栓塞**預防
4. **體溫**：無法發抖與流汗調節 → 依環境保暖或降溫
5. **肌肉骨骼**：全關節運動、預防攣縮與垂足；痙攣可用 baclofen
6. **心理**：失落、憂鬱、自殺意念；病人說「乾脆死了算了」時要**傾聽與同理**，不要給「一定會好起來」這種**不適當的保證**
7. **性功能與生育**：依損傷平面可能有反射性勃起；射精障礙（含逆行性射精）
8. **長期照顧**：復健訓練、**喘息服務**、**居家無障礙環境改善**、照顧技巧與壓力處理、家庭照顧者支持團體；社區照顧關懷據點與安養中心的對象不適合

### 脊椎手術後與圓滾木翻身 {#spine-surgery}

- **圓滾木翻身法**(log roll)
  1. 2–3 人合作，由一人（通常在頭側）喊口令，**頭、頸、軀幹與下肢成一直線同時翻**
  2. 利用**翻身單**，雙手抓在**肩部與臀部**
  3. 側臥後**枕頭放在兩膝之間**，背後用枕頭支撐；不是放在膝膕處
- 脊椎手術後 48 小時內
  1. 評估**手腳的感覺與運動**、傷口出血與**腦脊髓液滲漏**
  2. 床墊用**中硬度**（不是軟床）
  3. **不可俯臥**；平躺或側臥
  4. **不用一般便盆**（放入取出時脊椎會扭轉），依醫囑使用骨折便盆或協助在床邊便盆椅解便
- 椎間盤突出與椎板切除術後的背架、活動與運動指導之後在 H 組整理
