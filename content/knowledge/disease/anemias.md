貧血是紅血球數目、血紅素或血比容低於同年齡、同性別的正常值，使血液攜氧能力下降。本頁整理貧血的分類與共同照護、缺鐵性貧血、巨球性貧血(維生素 B12 與葉酸缺乏)、再生不良性貧血、溶血性貧血(含海洋性貧血與蠶豆症的照護)，以及紅血球增多症；血球生成與鐵代謝見 [[blood-hemostasis]]，檢驗數值見 [[complete-blood-count#anemia]]，鐵劑、B12、EPO 與排鐵劑見 [[hematinics]]，海洋性貧血與蠶豆症的遺傳見 [[single-gene-disorders]]

## 重點摘要 {#summary}

- 分類：**小球性**(缺鐵、海洋性貧血)、**大球性／巨母紅血球**(維生素 B12、葉酸缺乏)、**正球性**(急性出血、溶血、再生不良、慢性腎病)
- 共同表現：**蒼白、疲倦、心跳加快**、活動時喘、頭暈；嚴重時心臟衰竭；兒童注意力差、生長遲緩
- **缺鐵性貧血**：最常見；成人多因**慢性出血**(腸胃道、月經過多、痔瘡)，嬰幼兒好發 **6–24 個月**；**湯匙狀指甲、舌炎、口角炎、吞嚥困難**；**鐵蛋白低**、運鐵蛋白飽和度低、總鐵結合能力高
- **惡性貧血**：自體抗體攻擊**壁細胞與內在因子** → B12 吸收不良；**手腳麻木、步態不穩**、牛肉色舌炎、皮膚檸檬黃；**終生補充 B12**
- **葉酸缺乏**：酗酒、飲食差、懷孕、methotrexate；**沒有神經症狀**
- **再生不良性貧血**：骨髓衰竭，**紅血球、白血球、血小板都減少**；照護重點是**防感染、防出血**、活動量依耐受
- **溶血性貧血**：黃疸、脾腫大、網狀紅血球上升；重型海洋性貧血靠**輸血＋排鐵**，蠶豆症靠**避開誘發物**
- **真性紅血球增多症**：臉潮紅、頭痛、皮膚癢；併發**栓塞、出血、痛風**；**放血**、多喝水、不臥床

### 國考常考點 {#exam-points}

- 缺鐵性貧血是**小球、低色素**(體積小、顏色淺)；診斷是鐵蛋白低、**運鐵蛋白飽和度低**(不是高)
- 小球性貧血最常見原因是**缺鐵**；B12 與葉酸缺乏是**大球性**
- 嚴重缺鐵：吞嚥困難、舌炎口炎、湯匙狀指甲；**手足麻木是 B12 缺乏**，不是缺鐵
- 嬰幼兒缺鐵好發於 **6–24 個月的足月兒**；長期貧血會**心跳加快**(不是變慢)；Hb 5.5 g/dL 的兒童會心跳快、注意力差、生長遲緩，**不會**因此常發燒
- 孕婦 **Hb < 11 g/dL 且鐵蛋白 < 12 μg/L** 表示缺鐵性貧血；**延遲斷臍**可增加新生兒鐵存量
- 口服鐵劑：**兩餐之間**(或飯前 1 小時)服用、**配柑橘汁**；**不配牛奶、茶、制酸劑**；液態鐵劑用**吸管**；**黑便是正常**(不用停藥)
- 惡性貧血是缺 **B12**，因為產生對抗**內在因子**的自體抗體；紅血球**大**而不是小；可有膽紅素上升、舌炎與皮膚黃
- 惡性貧血的國考答案用**席林氏測驗**鑑別；**費城染色體是慢性骨髓性白血病**，與惡性貧血無關；**骨髓切片不是確診方法**；需**終生**補充 B12
- 再生不良性貧血：骨髓被破壞或抑制，**三系都減少**；骨髓的**巨核細胞減少**(ITP 則是巨核細胞正常或增加)；可用**幹細胞移植**或 ALG＋cyclosporin；**不吃生菜沙拉**、避免粗硬食物與 aspirin；活動時胸痛、喘是活動過度的警訊
- 重型 β 海洋性貧血定期輸血的孩子**不會蒼白**，而是長期鐵沉積的**青銅色皮膚**；體型矮瘦、塌鼻頭大、肝脾腫大
- 排鐵劑 deferoxamine：**皮下**輸注、**晚上**進行；尿液**橘紅色是正常**的排鐵現象(不是出血)；用藥期間配合醫囑補**維生素 C**；國考答案「最適合 5–7 歲才開始」為錯誤選項
- 鐮狀細胞貧血：**多喝水**、感染立即治療；**不臥床休息不動、也不定期輸全血**；止痛**不用 aspirin**
- 紅血球增多症：**臉色潮紅**(不是蒼白)、結膜充血、皮膚癢、頭痛；併發栓塞、出血、痛風，**不是過敏或感染**；每天喝水 **3,000–4,000 mL**、**不要一直臥床**(會增加血栓)

## 分類 {#classification}

| 依紅血球大小(MCV) | 常見原因 | 重點 |
|---|---|---|
| **小球性**(< 80 fL)低色素 | **缺鐵**、海洋性貧血、慢性病 | 缺鐵：鐵蛋白低；海洋性：鐵蛋白正常或高(見 [[single-gene-disorders#thalassemia]]) |
| 正球性 | **急性出血**、**溶血**、**再生不良**、慢性腎病(缺 EPO) | 看網狀紅血球：上升＝骨髓有反應(出血、溶血)；下降＝製造不足 |
| **大球性**(> 100 fL) | **維生素 B12、葉酸缺乏**、酗酒、肝病 | 巨母紅血球：DNA 合成受阻，細胞質長大但核成熟慢 |

| 依機轉 | 例子 |
|---|---|
| 製造減少 | 缺鐵、B12 與葉酸缺乏、再生不良、骨髓被白血病或癌細胞取代、腎病缺 EPO、化療骨髓抑制 |
| 破壞增加(溶血) | 海洋性貧血、鐮狀細胞、蠶豆症、遺傳性球形紅血球症、自體免疫、血型不合輸血、瘧疾 |
| 失血 | 急性出血、慢性腸胃道出血、月經過多、**鉤蟲感染** |

- MCV、MCH 等指數與參考值見 [[complete-blood-count#anemia]]
- 病因的對應：海洋性是**血紅素球蛋白鏈製造減少**；鐮狀細胞是**血紅素結構異常**(不是血小板被破壞)；再生不良是**骨髓被破壞或抑制**；缺鐵是**原料不足**

## 共同表現與照護 {#nursing}

- 表現(由組織缺氧與代償而來)
   1. 皮膚黏膜、指甲床、結膜**蒼白**；造口顏色變**蒼白**也提示貧血
   2. **心跳加快**、心悸、呼吸急促；嚴重時心臟擴大、心臟衰竭
   3. 疲倦、頭暈、耳鳴、怕冷、注意力不集中；兒童生長發展遲緩、食慾差
   4. 血壓可能下降(不是上升)
- 護理
   1. **活動與休息**：評估活動耐受度，**集中護理**、安排休息；起身要慢，預防跌倒
   2. 必要時給氧；依醫囑輸**紅血球濃厚液**(輸血護理見 [[transfusion-reactions]])
   3. 飲食：高鐵、高蛋白、富含維生素 B12 與葉酸的食物；少量多餐
   4. 口腔照護：舌炎、口炎時用軟毛牙刷與溫和漱口
   5. 找出原因：成人缺鐵要找腸胃道出血；糞便潛血檢查前的準備見 [[admission-discharge-specimens#specimen-principles]]
- 癌症病人的貧血與疲憊見 [[cancer-treatment-toxicities#anemia-fatigue]]

## 缺鐵性貧血 {#iron-deficiency}

- **最常見**的貧血；鐵代謝見 [[blood-hemostasis#iron]]
- 原因
   1. **慢性失血**(成人最常見)：腸胃道出血(潰瘍、痔瘡、大腸癌，見 [[lower-gi-disorders#hemorrhoids]])、**月經過多**、鉤蟲感染
   2. 需求增加：**嬰幼兒**快速生長(**6–24 個月**；6 個月後母體帶來的鐵用完)、青春期、**懷孕**
   3. 攝取不足：只喝牛奶、偏食、速食
   4. 吸收不良：胃切除、乳糜瀉、制酸劑
- 表現：貧血共同症狀＋**湯匙狀指甲**(指甲變薄、凹陷)、**舌炎**(舌頭紅而平滑)、**口角炎**、**吞嚥困難**、**異食癖**(吃冰、泥土)
- 檢驗

| 項目 | 缺鐵性貧血 |
|---|---|
| MCV、MCH | **下降**(小球、低色素) |
| 血清鐵 | 下降 |
| **鐵蛋白** | **下降**(最早、最敏感) |
| 總鐵結合能力(TIBC) | **上升** |
| 運鐵蛋白飽和度 | **下降** |

- 孕婦：Hb < 11 g/dL 為貧血，合併鐵蛋白 < 12 μg/L 為缺鐵性貧血(105-2_OP_029)；多吃紅肉、深綠色蔬菜，鐵劑配維生素 C；新生兒**延遲斷臍**可增加鐵存量
- 治療與衛教
   1. 先找出並處理出血原因
   2. 飲食：**動物性鐵**(紅肉、肝臟、蛋黃)比植物性好吸收；配**維生素 C**(柑橘)；避免同時喝**茶、咖啡、牛奶**，玉米、全穀的植酸也會減少吸收
   3. 口服鐵劑：**兩餐之間**或飯前 1 小時；配果汁；**不與牛奶、制酸劑、四環黴素併服**；液態鐵劑用**吸管**、服後漱口，避免牙齒染色；**黑便**是正常現象；腸胃不適可改飯後(吸收變差)
   4. 新說法：AGA 2020 建議口服鐵**每天最多 1 次**，**隔日服用**吸收率相近或更好、腸胃副作用較少；國考仍以「兩餐之間、每天服用」為答案
   5. 肌肉注射鐵劑：**Z 字型深部肌肉注射**、抽藥後**換針頭**、注射後停 5–10 秒再拔針、**不搓揉**；現行多改用**靜脈鐵劑**(注射鐵的做法見 [[hematinics#iron]])
- 補鐵後網狀紅血球約 1 週上升、Hb 約 2 個月恢復，之後**繼續補 3 個月**填滿儲存鐵(常用建議，待核對)

## 巨母紅血球性貧血 {#megaloblastic}

- 維生素 B12 或葉酸不足 → **DNA 合成受阻**，骨髓出現巨母紅血球、紅血球**大**(MCV 上升)且容易在骨髓內破壞 → 間接膽紅素與 LDH 上升(皮膚**檸檬黃**)

| | 維生素 B12 缺乏 | 葉酸缺乏 |
|---|---|---|
| 吸收 | 需胃壁細胞的**內在因子**，在**迴腸末端**吸收 | 空腸吸收 |
| 原因 | **惡性貧血**、**全胃切除**、迴腸切除、吸收不良、**純素食**、長期 metformin 或 PPI | **酗酒**、飲食缺乏蔬菜、**懷孕**、溶血、**methotrexate**、phenytoin |
| 儲存 | 肝臟存量可用數年 | 只夠數個月 |
| **神經症狀** | **有**：手腳針刺麻木、本體感覺差、**步態不穩**、記憶差 | **沒有** |
| 治療 | 補 B12(惡性貧血需**終生**) | 口服葉酸；備孕補葉酸預防神經管缺陷 |

- 單補葉酸可改善貧血但**不能**改善 B12 缺乏的神經病變，所以要先確認是否缺 B12
- 食物：B12 只在**動物性食物**(肉、蛋、奶、海鮮)；葉酸在深綠色蔬菜、肝臟、豆類

### 惡性貧血 {#pernicious}

- **自體免疫**：抗**壁細胞**與抗**內在因子**抗體 → 自體免疫性胃炎(胃體、胃底萎縮，胃酸少) → B12 吸收不良(見 [[upper-gi-disorders#gastritis]])
- 表現：貧血症狀(蒼白、喘、心悸)＋**牛肉色光滑舌炎**＋**手腳麻木、運動協調變差**＋輕微黃疸
- 診斷：血清 B12 低、**抗內在因子抗體**；國考答案是**席林氏測驗**(測 B12 吸收)，BSH 2014 指出此測驗已不使用(試劑停產)，現行以抗體檢查為主(《內外科護理學》上冊 p.949 仍列席林氏測驗)
- **費城染色體**是慢性骨髓性白血病的檢查，與惡性貧血無關；**骨髓切片不是確診方法**
- 治療：**終生**補充維生素 B12；國考答案是**終生肌肉注射**；BSH 2014 認為高劑量口服 B12 也可作為替代(**待核對原文**)；神經症狀者先用注射
- 全胃切除後要預防性補充 **B12**(術後營養見 [[upper-gi-disorders#dumping]])

## 再生不良性貧血 {#aplastic}

- **骨髓衰竭**：造血幹細胞被破壞或抑制，骨髓被脂肪取代 → **紅血球、白血球、血小板都減少**(全血球減少)；骨髓**巨核細胞減少**
- 原因
   1. 後天(多數)：**自體免疫**(T 細胞攻擊幹細胞，原因不明)、藥物(chloramphenicol、化療藥)、**苯**等化學物、放射線、肝炎病毒
   2. 先天：**范康尼氏貧血**(體染色體隱性，合併骨骼與腎臟異常)
- 表現與檢驗門檻(《兒科護理學》p.502)
   1. 貧血：血比容 < 30% 時心跳快、呼吸急促
   2. 感染：**嗜中性球 < 1,500/mm³** 容易細菌感染
   3. 出血：**血小板 < 50,000/mm³** 容易瘀斑、出血
- 治療：輸血支持；**造血幹細胞移植**(年輕、有配對者)；**抗胸腺細胞球蛋白(Antithymocyte globulin，ATG／ALG)＋cyclosporine** 免疫抑制治療(見 [[immunosuppressants]])
- 護理
   1. **預防感染**：手部衛生、避免出入人多處與探訪者生病；**不吃生食**(生菜沙拉、生魚片)；監測體溫(發燒處理見 [[cancer-treatment-toxicities#febrile-neutropenia]])
   2. **預防出血**：軟食、**避免粗硬食物**、軟毛牙刷、電動刮鬍刀；**不用 aspirin**、避免肌肉注射
   3. **活動量依耐受**：活動時胸痛或喘是活動過度，要休息；少量多餐、高蛋白與維生素
   4. 青少年：事先告知 cyclosporine 的外觀副作用(多毛、牙齦增生)，用電話或視訊維持同儕聯繫
- 幹細胞移植見 [[stem-cell-transplant]]

::questions{ids="106-1_MS_038,105-2_OP_064,110-1_OP_068,114-3_OP_042"}

## 溶血性貧血 {#hemolytic}

- 紅血球在壽命結束前被破壞 → 貧血＋**黃疸**(間接膽紅素上升)＋**脾腫大**＋**網狀紅血球上升**；長期會有**膽色素結石**
- 依機轉

| 類型 | 例子 | 重點 |
|---|---|---|
| 血紅素異常 | **海洋性貧血**、**鐮狀細胞貧血** | 體染色體隱性；遺傳與篩檢見 [[single-gene-disorders#thalassemia]]、[[single-gene-disorders#sickle-cell]] |
| 酵素缺乏 | **G6PD 缺乏症** | X 性聯；氧化壓力 → **Heinz 小體**(見 [[single-gene-disorders#g6pd]]) |
| 細胞膜異常 | 遺傳性球形紅血球症 | 脾切除可改善(見 [[single-gene-disorders#spherocytosis]]) |
| 免疫性 | 自體免疫溶血、**血型不合輸血**、新生兒溶血 | **直接庫姆氏試驗(Coombs test)陽性**；見 [[transfusion-reactions#reactions]] |
| 其他 | 人工瓣膜機械破壞、瘧疾、DIC | |

### 海洋性貧血的照護 {#thalassemia-care}

- 輕型(帶因)：不需治療，**不要誤補鐵**；婚前、產前篩檢與遺傳諮詢(見 [[single-gene-disorders#thalassemia]])
- **重型 β 海洋性貧血**
   1. 表現：出生約 6 個月後開始嚴重貧血、肝脾腫大、生長遲緩；骨髓擴張造成**頭大、顴骨隆起、塌鼻**
   2. **定期輸血**：維持血紅素，抑制骨髓過度擴張(輸血前目標值依 TIF 指引，**待核對**)
   3. **鐵沉積**：反覆輸血 → 鐵沉積在皮膚(**青銅色**)、心臟(心衰竭、心律不整，最常見死因)、肝臟、胰臟(糖尿病)、內分泌腺(生長與青春期延遲)；所以規律輸血的孩子**不是蒼白**，而是青銅色
   4. **排鐵治療**：deferoxamine(Desferal)**皮下輸注**，用輸注幫浦在**晚上睡覺時**慢慢打；排出的鐵使尿液呈**橘紅色**，是正常現象；配合醫囑補充**維生素 C** 增加排鐵；也有口服排鐵劑(用藥細節見 [[hematinics#chelators]])
   5. 開始排鐵的時機依輸血次數與鐵蛋白決定(通常在幼兒期)，**不是等到 5–7 歲**(114-1_OP_041)
   6. **脾臟切除**：脾腫大或輸血需求太高時考慮；術後易受**有莢膜細菌**感染，需肺炎鏈球菌等疫苗與發燒立即就醫
   7. **造血幹細胞移植**是唯一根治方法
- 家庭照護：長期反覆住院，**以家庭為中心**；新住民家庭**尊重原有文化習慣與常規**、使用專業翻譯，不只配合單一文化，也不要請家人代翻

### 蠶豆症(G6PD 缺乏症)的照護 {#g6pd-care}

- 平時和一般孩子一樣，重點是**避開氧化誘發物**(台大〈認識蠶豆症〉、亞東醫院衛教)
   1. **蠶豆**與其製品(哺乳母親也要避免)
   2. **樟腦丸、萘丸**(衣櫥、廁所都不要放)、**紫藥水(龍膽紫)**
   3. 藥物：**磺胺類**、抗瘧藥、部分解熱鎮痛劑；就醫時主動告知、隨身攜帶卡片，用藥由醫師或藥師確認(各院清單不完全一致)
- 急性溶血徵象：臉色蒼白、**黃疸**、**茶色或深色尿**、疲倦 → 立即就醫；新生兒期特別注意高膽紅素血症(膽紅素代謝見 [[liver-biliary-pancreas#bilirubin]])
- 住院幼兒的心理照護：學步期(1–3 歲)以**平行遊戲**為主、怕**分離焦慮**，維持日常作息、減少與父母分離、用簡短句子說明；「聯合性遊戲」是學齡前期的特徵
- 遺傳與機轉見 [[single-gene-disorders#g6pd]]

### 鐮狀細胞貧血的照護 {#sickle-cell-care}

- 台灣少見，國考多考預防危象：**多喝水**、避免寒冷與缺氧、**感染立即治療**、適度休息；疼痛用 acetaminophen 或依醫囑用鴉片類，**不用 aspirin**
- **不需要定期輸注全血**；危象時依醫囑輸血、補液、給氧
- 機轉與表現見 [[single-gene-disorders#sickle-cell]]

## 紅血球增多症 {#polycythemia}

| 類型 | 原因 | EPO |
|---|---|---|
| **真性紅血球增多症** | 骨髓增生性腫瘤(多有 **JAK2** 突變)，紅血球、白血球、血小板都增加 | 低 |
| 次發性 | 慢性缺氧(**高海拔**、慢性阻塞性肺病、發紺型心臟病、**吸菸**)、會分泌 EPO 的腫瘤(腎癌) | 高 |
| 相對性 | **脫水**、利尿劑使血漿減少 | 正常 |

- 真性紅血球增多症多在 50–60 歲以後發生；血液黏稠、血流慢
- 表現：**臉色潮紅**、**結膜充血**、**頭痛**、頭暈、視力模糊、**洗熱水澡後皮膚癢**(組織胺釋放)、脾腫大、高血壓
- 併發症：**栓塞**(中風、心肌梗塞、深部靜脈血栓)、**出血**(血小板功能異常)、**痛風**(細胞代謝快 → 尿酸高)、消化性潰瘍；**不是過敏或感染**
- 治療
   1. **放血術**：每次約 500 mL；ELN 2018 建議把**血比容維持在 45% 以下**(《內外科護理學》上冊 p.959 寫初期每 2–3 天放血)
   2. **低劑量 aspirin**(81–100 mg/天)預防血栓
   3. 高風險(> 60 歲或曾血栓)加 **hydroxyurea** 抑制骨髓；課本列的放射性磷(³²P)現在少用
   4. 尿酸高用 allopurinol
- 護理
   1. **多喝水**，每天約 **3,000–4,000 mL**，降低血液黏稠度
   2. **不要長時間臥床**，鼓勵活動、腳部運動，避免久坐久站與穿緊身衣；觀察血栓徵象
   3. 頭暈與視力模糊時**預防跌倒**；深呼吸與有效咳嗽促進通氣
   4. 避免太熱的水洗澡，皮膚癢可用溫水與保濕
   5. 放血後觀察低血壓與頭暈，起身要慢
