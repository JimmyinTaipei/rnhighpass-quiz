周邊血管疾病包括**動脈**變窄或擴張(周邊動脈疾病、動脈瘤、血管炎)與**靜脈**回流不良(靜脈曲張、慢性靜脈功能不全、靜脈血栓)。兩者的照護方向常常**相反**：動脈缺血要讓血流下去，靜脈鬱滯要讓血流回來。血管構造與靜脈瓣見 [[blood-vessels#structure]]；動脈粥狀硬化的機轉見 [[coronary-artery-disease]]；深部靜脈血栓的抗凝治療見 [[anticoagulants]]；肺栓塞見 [[pulmonary-embolism-hypertension]]；顱內動脈瘤見 [[stroke]]

## 重點摘要 {#summary}

- 動脈 vs 靜脈：見下表；**動脈病肢體放低、不熱敷；靜脈病肢體抬高**
- **周邊動脈疾病(PAD)**：動脈粥狀硬化；**間歇性跛行**(走路痛、休息緩解)→ 嚴重時休息也痛 → 潰瘍壞疽(內外上冊書頁 917)
- **ABI**(踝收縮壓 ÷ 手臂收縮壓)：1.00–1.40 正常、**≤ 0.90 異常**、≤ 0.40 重度、> 1.40 血管鈣化無法壓縮(內外上冊書頁 901；ACC/AHA 2024)
- PAD 治療：**戒菸**、**規律走路運動**(每週 3 次、每次 30–45 分鐘、至少 12 週)、抗血小板、statin、控制血壓血糖、足部照護(內外上冊書頁 918)
- 急性動脈阻塞 **6P**：疼痛、感覺異常、皮溫變冷、蒼白、麻痺、無脈搏 → 緊急(內外上冊書頁 918)
- **柏格氏病**：與**抽菸**絕對相關、40 歲以下男性、**下肢**中小動脈與靜脈發炎阻塞；最重要的治療是**戒菸**(內外上冊書頁 922)
- **雷諾氏病**：**年輕女性**、**手指**(肢體末端)、遇**冷或情緒壓力**誘發，顏色**白 → 紫 → 紅**；保暖、戒菸、減壓、nifedipine(內外上冊書頁 921–922)
- **腹主動脈瘤**：腹部**搏動感**與搏動性腫塊、收縮期血管嘈音；維持收縮壓約 **100–120 mmHg**、避免閉氣用力；**劇烈下背痛＋休克 → 破裂**(內外上冊書頁 915–916)
- **靜脈曲張**：靜脈瓣功能不良；**逆行性充盈試驗、手壓測驗**；**抬高雙腿、彈性襪、運動、控制體重**、避免久站久坐與緊身衣(內外上冊書頁 927–929)
- **靜脈鬱滯性潰瘍**：**足踝內側**、邊緣不整、**褐色色素沉著**、凹陷性水腫；**加壓治療**是核心(內外上冊書頁 929–930)

### 國考常考點 {#exam-points}

- 吸菸對動脈阻塞的影響：血管收縮、心跳加快、心肌需氧增加；**血液攜氧能力下降**(不是增加，一氧化碳占據血紅素)
- 下肢動脈疾病護理：**鼓勵促進下肢血循的運動**；**不抬高患肢、不熱敷**、低飽和脂肪
- 柏格氏病：**與抽菸有關**；不是靜脈為主、不是好發上肢、會間歇性跛行
- 血栓閉塞性脈管炎最常侵犯**腳**
- 雷諾氏病錯誤敘述：「好發於**近心端**肢體」(是末端手指)
- 腹主動脈瘤：病人主訴**腹部有心跳搏動感**；聽到的是**收縮期**嘈音；疼痛轉到下背部是**惡化**(可能破裂)
- 腹主動脈瘤護理錯誤：「術後採**高坐臥**」(避免腹部屈曲壓迫移植血管)；正確：收縮壓 100–120、避免閉氣用力、記錄輸出入量
- **主動脈剝離**(剝離性動脈瘤)**不給抗凝血劑**；要控制心跳與血壓(見 [[hypertension]])
- 高安氏動脈炎：侵犯**主動脈與分支**、上肢摸不到脈搏 → **無脈症**
- 評估靜脈瓣功能：**逆行性充盈試驗(特倫德堡試驗)**、**手壓測驗**；艾倫試驗看手部動脈、霍曼氏徵象看 DVT
- 靜脈曲張護理：**睡前抬高患肢**、規律運動、避免外傷、控制體重；**不穿緊身衣**
- 靜脈結紮剝除術後：床尾抬高約 **15 度**、膝不彎、下床穿彈性襪、觀察末梢循環；臥床期間**要**在床上做全關節運動(每小時)
- 鬱滯性潰瘍：**足踝內側、色素沉著、凹陷性水腫**；趾甲變厚、腳趾潰瘍是**動脈**性

## 動脈還是靜脈 {#arterial-vs-venous}

| 項目 | **動脈功能不全**(缺血) | **靜脈功能不全**(鬱滯) |
|---|---|---|
| 疼痛 | **間歇性跛行**；嚴重時休息痛、夜間痛，**腿垂下較舒服** | 久站後脹痛、沉重，**抬高較舒服** |
| 脈搏 | **減弱或摸不到** | 正常 |
| 皮膚 | **冷、蒼白**(抬高更白)、發亮變薄、**毛髮脫落**、**趾甲變厚** | **溫**、**褐色色素沉著**(血鐵質)、脂性皮膚硬化 |
| 水腫 | 沒有或很少 | **凹陷性水腫** |
| 潰瘍位置 | **腳趾、足部突起處** | **足踝內側** |
| 潰瘍外觀 | 邊緣整齊、深、蒼白、**很痛** | 邊緣不整、淺、紅色肉芽、滲液多 |
| 姿勢 | 肢體**略低於心臟** | 肢體**抬高高於心臟** |
| 加壓 | **不可**加壓 | **彈性襪、加壓繃帶** |
| 熱 | **不熱敷**(感覺差易燙傷、代謝增加) | — |

## 評估檢查 {#assessment}

依內外上冊書頁 899–901 重新整理

| 檢查 | 怎麼做 | 評估 |
|---|---|---|
| **踝肱指數(ABI)** | 足背或脛後動脈收縮壓 ÷ 肱動脈收縮壓 | **周邊動脈疾病**最常用；≤ 0.90 異常、0.71–0.90 輕度、0.41–0.70 中度、≤ 0.40 重度、> 1.40 無法壓縮 |
| 抬腿測驗(灌注測驗) | 雙腿抬高 60 度 1 分鐘再坐起垂下，看膚色恢復時間 | 慢性動脈功能不全；> 40 秒嚴重缺血 |
| 艾倫試驗 | 壓住橈、尺動脈再放開一條 | 手部動脈側支(見 [[arterial-line#allen-test]]) |
| **逆行性充盈試驗**(特倫德堡試驗) | 平躺抬腿排空靜脈 → 大腿綁止血帶 → 站立觀察，再鬆開 | **隱靜脈瓣與交通靜脈瓣功能** |
| **手壓測驗** | 一手摸曲張靜脈，另一手壓其上方約 20 公分處，下方感覺到衝擊 → 瓣膜不良 | 靜脈瓣功能 |
| 霍曼氏徵象 | 足部背屈，小腿痛為陽性 | 深部靜脈血栓(敏感度與特異度都低) |
| 杜卜勒超音波 | 非侵入性看血流 | 動靜脈都可；DVT 的主要檢查 |

## 周邊動脈疾病 {#pad}

- 危險因子：年齡、**抽菸**、糖尿病、高血壓、高血脂(內外上冊書頁 917)
- 分期(Rutherford)：無症狀 → 輕中重度**間歇性跛行** → **休息時疼痛** → 小範圍組織壞死 → 大範圍壞死(內外上冊書頁 917)
- 治療：抗血小板(aspirin、clopidogrel)、cilostazol 改善跛行、statin、降壓；血管成形術、繞道手術(內外上冊書頁 918；ACC/AHA 2024)

護理(內外上冊書頁 919)

1. 促進動脈血流：肢體**略低於心臟**；依醫囑做**伯格－艾倫運動**(抬腿 → 坐起垂腿活動腳踝 → 平躺保暖)
2. **漸進式走路運動**：走到疼痛出現、休息緩解後再走
3. **戒菸**最重要；低飽和脂肪、控制體重
4. 足部照護：每天檢查、溫水中性肥皂洗淨擦乾(趾縫)、乳液防乾裂、小心剪趾甲、合腳鞋襪、**不赤腳**、避免過冷過熱、**不熱敷**
5. 情緒支持：面對截肢的恐懼

### 急性動脈阻塞 {#acute-occlusion}

- 血栓或栓子(常來自心房顫動)突然堵住動脈
- **6P**：疼痛(Pain)、感覺異常(Paresthesia)、皮膚變冷(Poikilothermia)、蒼白(Pallor)、麻痺(Paralysis)、無脈搏(Pulselessness)(內外上冊書頁 918)
- 緊急：通知醫師、肢體平放或略低、**不熱敷不按摩**、準備抗凝與取栓手術；延誤會壞死截肢

## 柏格氏病與雷諾氏病 {#buerger-raynaud}

| 項目 | **柏格氏病**(血栓閉塞性脈管炎) | **雷諾氏病** |
|---|---|---|
| 病因 | **抽菸**(絕對相關)、自體免疫 | 不明(原發性)；續發於 SLE、硬皮症等 |
| 好發 | **40 歲以下男性**、吸菸者 | **年輕女性**(15–45 歲) |
| 血管 | **下肢**中小動脈與靜脈發炎、栓塞 | 手指小動脈**痙攣** |
| 誘因 | 抽菸 | **寒冷、情緒壓力** |
| 表現 | **間歇性跛行**、肢端冷白麻、表淺靜脈發炎(紅色壓痛索狀)、脈搏弱、潰瘍壞疽 | 手指**白 → 紫(發紺)→ 紅(充血)**、麻木刺痛；嚴重時指尖潰瘍 |
| 治療 | **戒菸**最重要、運動、保護肢體、必要時手術 | 保暖、避免突然接觸冷(冰箱取物戴手套)、戒菸、減壓；**nifedipine**；痙攣時溫水泡(不超過約 32 ℃，待核對) |

## 動脈瘤與主動脈剝離 {#aneurysm}

### 動脈瘤 {#aaa}

- 真性：**紡錘狀**(整圈擴張)、**囊狀**(一側鼓起)、**剝離性**(血進入管壁夾層)；假性：管壁破裂被周圍組織包住(內外上冊書頁 914)
- 動脈粥狀硬化造成的動脈瘤最常在**腹主動脈**；梅毒可侵犯胸主動脈的血管滋養管
- 腹主動脈瘤表現：常無症狀；**腹部心跳搏動感**、搏動性腫塊、**收縮期嘈音**；壓迫造成背、腰、腹痛(內外上冊書頁 915)
- **破裂**：突然**劇烈下背或腹痛**＋**休克** → 緊急手術

| 治療 | 重點 |
|---|---|
| 小(書上 < 6 公分) | 內科：**收縮壓 100–120 mmHg**(太低灌流不足、太高易破裂)、減重、運動、戒菸、每年追蹤 |
| 大(書上 > 6 公分) | 手術：切除後接人工血管；或血管內支架 |

內外上冊書頁 915；手術切點各指引不同(常見 5.5 公分)，待核對

護理(內外上冊書頁 916)

1. 按時服降壓與降膽固醇藥；**避免閉氣用力**(便祕、提重物)
2. 疼痛就依醫囑止痛，避免忍痛使血壓升高
3. 心悸、皮膚濕冷、背胸腹痛 → 可能破裂，立即就醫
4. 術後：監測生命徵象與血行動力、**下肢脈搏與皮溫顏色**、**尿量 < 30 mL/hr** 要評估腎功能、腸蠕動(麻痺性腸阻塞)、感染
5. 術後**不採高坐臥**，避免髖部過度屈曲壓迫移植血管(國考答案；角度依醫囑)
6. 傷口癒合前 6–12 週避免提重物等用力活動

### 主動脈剝離 {#dissection}

- 主動脈內膜撕裂，血流進入管壁夾層；常與**高血壓**、馬凡氏症候群有關(見 [[single-gene-disorders]])
- 突發**撕裂般劇烈胸痛或背痛**，易誤以為心肌梗塞；兩手血壓或脈搏不對稱
- 處置：**控制心跳與血壓**(β 阻斷劑、靜脈降壓劑，見 [[hypertension]])、止痛、準備手術；**不給抗凝血劑與血栓溶解劑**

### 高安氏動脈炎 {#takayasu}

- 大血管炎，侵犯**主動脈弓與其分支** → 狹窄；上肢脈搏摸不到、兩手血壓差 → 又稱**無脈症**；好發年輕女性

## 靜脈曲張 {#varicose-veins}

- 靜脈壁或**靜脈瓣**缺損 → 血液逆流、淤積 → 表淺靜脈擴張扭曲；約 10% 人有，女性較多(內外上冊書頁 927)
- 危險因子：家族史、年長、**長期站立**、肥胖、懷孕、緊束腰帶；續發性來自深部靜脈功能不良或血栓
- 表現：久站後腿脹痛沉重、小腿抽筋、靜脈扭曲、皮膚褐色、嚴重時鬱血性潰瘍；經期前與懷孕加重(內外上冊書頁 928)
- 評估瓣膜：**逆行性充盈試驗**、**手壓測驗**、杜卜勒超音波

| 治療 | 做法 |
|---|---|
| 支持療法 | 休息時**抬高雙腿**、站立時穿**彈性襪**、散步游泳增加小腿肌肉幫浦 |
| 硬化療法 | 注射硬化劑使曲張靜脈閉塞，之後彈性繃帶 24–72 小時、再換彈性襪 |
| 手術 | **結紮與剝除術**；雷射、射頻等微創 |

內外上冊書頁 928–929

### 護理與衛教 {#varicose-nursing}

- 預防與衛教：**常改變姿勢**、避免久站久坐與翹腳、**維持理想體重**、**規律運動**、**避免外傷**、躺下時腿高於心臟(睡前抬高)、**不穿緊身衣褲與過緊腰帶**(內外上冊書頁 929)
- 結紮剝除術後(內外上冊書頁 929)
   1. 24 小時內臥床，**床尾抬高約 15 度**、膝不彎曲
   2. 彈性繃帶定時放鬆觀察出血、感染、神經損傷、末梢循環
   3. **每小時在床上做全關節運動**；24 小時後漸進下床，7 天內避免用力
   4. **下床都要穿彈性襪**

## 慢性靜脈功能不全與鬱滯性潰瘍 {#venous-insufficiency}

- 深部與交通靜脈瓣閉鎖不全 → 靜脈高壓 → 水腫、紅血球外滲 → **血鐵質**沉著(褐色) → 受重力影響在**足踝內側**形成潰瘍(內外上冊書頁 929–930)
- 潰瘍特徵：邊緣**不整齊**、凹陷、紅褐色；下肢垂下或起床時痛
- 治療：**加壓治療**(彈性襪或多層繃帶，先確認不是動脈疾病)、擴創、抑菌敷料、感染才用抗生素、必要時手術(內外上冊書頁 930)
- 護理：抬高下肢、穿脫彈性襪的方法(早上起床前穿)、皮膚保濕、避免抓傷、傷口無菌換藥；傷口照護見 [[wound-dressings]]

## 血栓性靜脈炎與深部靜脈血栓 {#venous-thrombosis}

| 項目 | 表淺血栓性靜脈炎 | 深部靜脈血栓(DVT) |
|---|---|---|
| 常見原因 | **靜脈注射**超過 72 小時、刺激性藥物(抗生素、化療、KCl)、靜脈曲張 | **Virchow 三要素**：血流鬱滯(久坐、臥床、長途飛行)、血管內皮受損、高凝血(懷孕產後、口服避孕藥、癌症) |
| 表現 | 沿靜脈**紅、腫、熱、痛**、摸起來硬如索狀 | 單側小腿或大腿**腫脹、疼痛、發紅溫熱**；霍曼氏徵象可陽性；也可能沒症狀 |
| 危險 | 很少栓塞 | **肺栓塞**(栓子多來自下肢深部靜脈) |
| 處置 | **立即拔除靜脈導管、換部位**、抬高、**濕熱敷** | **抗凝血劑**、抬高患肢、急性期臥床依醫囑、**不按摩患肢**、觀察肺栓塞徵象 |

依內外上冊書頁 927 與抗凝血藥頁重新整理

- 靜脈注射引起的靜脈炎處理見 [[iv-therapy#complications]]；heparin、warfarin 與 DOAC 的護理見 [[anticoagulants]]
- 預防 DVT：術後**早期下床**、腳踝幫浦運動、彈性襪或間歇充氣加壓、足夠水分、避免久坐與緊身衣；高危險者依醫囑預防性抗凝
- 長途飛行 DVT 的主要原因是**血液鬱積**
