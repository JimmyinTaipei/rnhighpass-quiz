**頭部外傷**從頭皮撕裂傷、顱骨骨折，到腦組織挫傷與顱內出血都有。撞擊當下的傷害（原發性）無法逆轉，照護重點是預防**繼發性腦傷**：缺氧、低血壓、顱內壓升高、抽搐、感染。評估方法見 [[neuro-assessment]]，顱內壓升高的處置見 [[increased-icp]]，腦膜與血腫的解剖見 [[brain-anatomy#hematoma-basics]]

## 重點摘要 {#summary}

- 以 GCS 分輕度(13–15)、中度(9–12)、**重度(3–8)**；重度要保護呼吸道、維持氧合與血壓
- **顱底骨折**：**前顱窩**→ **浣熊眼、腦脊髓液鼻漏**；**中顱窩**→ **巴特爾氏徵象**（耳後乳突瘀血）、**耳漏**、**鼓室積血**
- 腦脊髓液漏：滴在紗布上有**光暈徵象**；**不可擤鼻涕、用力咳嗽、抽吸、填塞、沖洗**，**不可經鼻放管或插管**；用無菌紗布鬆鬆接住；表示**硬腦膜**破損
- **腦震盪**：暫時性神經功能障礙，**沒有腦組織結構損傷**；**腦挫傷**：腦組織**有實質損傷**（瘀血、水腫）
- **硬膜上出血**：多為顳骨骨折撕裂**腦膜中動脈**（**動脈**出血）；典型**短暫昏迷 → 清醒期 → 突然惡化**；要緊急**手術**
- **硬膜下出血**：**橋靜脈**撕裂（**靜脈**出血）；急性型合併嚴重腦挫傷；**慢性型好發老人**（腦萎縮），輕微撞到後**數週**才出現記憶變差、行為改變、嗜睡，可**鑽孔引流**
- 併發症：顱內壓升高、**外傷後癲癇**（開放性較多）、腦膜炎、**尿崩症或 SIADH**（下視丘與腦下垂體受傷）、創傷後症候群（可持續數月到數年）

### 國考常考點 {#exam-points}

- 顱底骨折的徵象：鼓室積血、巴特爾氏徵象、浣熊眼；**巴賓斯基氏徵象不是**
- 前顱窩顱底骨折：可能**鼻漏或浣熊眼**；腦脊髓液滲漏是**硬腦膜**（不是蜘蛛膜）破損；**不需立即手術**；床頭**不是越高越好**（約 30 度）
- 耳漏、鼻漏：有**光暈徵象**；不可用力咳嗽打噴嚏；臥床休息利於硬腦膜癒合；**不可抽吸鼻孔內液體**
- 確認鼻漏是腦脊髓液，表示**硬腦膜受損**；腦震盪**沒有**實質損傷、腦挫傷**有**；有鼻漏耳漏**不可**用抽吸管抽吸
- 頭部外傷合併症：**創傷後症候群可持續數月到數年**；**開放性**比封閉性更易有癲癇；腦脊髓液瘻管是顱底骨折與硬腦膜破裂，不是循環阻塞；ADH 失調是**下視丘**受損（不是視丘）
- 硬膜上出血：**動脈**出血、常先有**清醒期**、易顱內壓升高、以手術為主；受傷時意識清楚、縫合傷口時突然昏迷 → **硬膜上出血**
- 慢性硬膜下出血：**靜脈出血**、多發生在**老年人**、會有顱內壓升高與意識混亂、必要時手術移除；**不會**有巴特爾氏徵象、鼻漏耳漏、也不一定有庫欣氏三徵
- 頭部外傷合併腦水腫的點滴：考題答案是 **D5S**（0.45% saline 與 D5W 會加重腦水腫）
- 頭部外傷術後尿崩症：**每小時**監測輸入輸出、尿比重、尿色；尿崩症是 ADH **不足**、會**高血鈉**；SIADH 是 ADH **過多**、低血鈉
- 頭顱骨骨折病人**不適合經鼻**插管；疑似頸椎損傷用**推顎法**，不用壓額抬下巴
- 清洗沾在頭髮上的新鮮血漬用**冷水**

## 分類與機轉 {#types}

- **開放性**（頭皮與硬腦膜破裂，腦與外界相通，感染與癲癇風險高）與**封閉性**
- **原發性**損傷：撞擊當下的骨折、挫傷、軸突斷裂、出血
- **繼發性**損傷：之後的**缺氧、低血壓**、腦水腫、顱內壓升高、抽搐、發燒、高或低血糖、感染；這是護理可以預防的部分
- 撞擊側的傷(coup)與對側的傷(contrecoup)：腦在顱內前後晃動，對側也可能挫傷

### 顱骨骨折 {#skull-fracture}

| 類型 | 特點 | 處置 |
|---|---|---|
| 線狀骨折 | 最常見；跨過腦膜中動脈溝時要注意硬膜上出血 | 多數觀察即可 |
| 凹陷性骨折 | 骨片壓向腦組織 | 常需手術抬起骨片、清創 |
| **顱底骨折** | X 光不易看到，靠**臨床徵象**診斷 | 多數**保守治療**；持續漏或感染才手術 |

| 顱底骨折位置 | 徵象 |
|---|---|
| **前顱窩** | **浣熊眼**（雙側眼眶周圍瘀血）、**腦脊髓液鼻漏**、嗅覺喪失 |
| **中顱窩**（顳骨） | **巴特爾氏徵象**（耳後**乳突**瘀血，常在受傷後 1–2 天出現）、**腦脊髓液耳漏**、**鼓室積血**、聽力受損、顏面神經麻痺 |

- **腦脊髓液漏**的判斷與處理
  1. 液體滴在紗布或面紙上，中間是血、外圈是淡黃色的環 → **光暈徵象**
  2. 葡萄糖試紙陽性支持是腦脊髓液（鼻涕不含葡萄糖；混有血時不準）
  3. 代表**硬腦膜破損**，腦與外界相通 → **腦膜炎**風險
  4. **不可**擤鼻涕、用力咳嗽打噴嚏、憋氣；**不可**抽吸、填塞、沖洗鼻腔或耳道；用**無菌紗布鬆鬆覆蓋**接住，記錄量與性質
  5. **不可經鼻**放鼻胃管、抽痰或氣管插管（管子可能經破損的顱底進入顱內）
  6. 臥床休息、床頭抬高約 30 度（依醫囑），多數 1–2 週內自行癒合

### 腦震盪與腦挫傷 {#concussion-contusion}

| | 腦震盪 | 腦挫傷 |
|---|---|---|
| 結構損傷 | **沒有**實質損傷（影像多正常） | **有**：腦組織瘀血、出血、水腫 |
| 表現 | 短暫意識喪失或恍惚、受傷前後的事記不得、頭痛、頭暈、噁心 | 依位置有局部神經缺損、意識障礙，可能顱內壓升高 |
| 預後 | 多數數天到數週恢復 | 依嚴重度 |

- **腦震盪後症候群**（創傷後症候群）：頭痛、頭暈、注意力差、記憶變差、易怒、失眠、焦慮，**可持續數月到數年**
- 輕度頭部外傷返家衛教：24 小時內要有人陪伴並定時叫醒；出現**嗜睡難叫醒、劇烈頭痛、反覆嘔吐、單側無力、抽搐、瞳孔不等大、鼻耳流清水**立即回診
- **瀰漫性軸突損傷**：加速減速力量撕扯白質軸突，受傷後**立即**昏迷、影像可能變化不大，預後差

### 顱內出血與血腫 {#hematoma}

| | **硬膜上出血**（硬腦膜外血腫） | 急性硬膜下出血 | **慢性硬膜下出血** |
|---|---|---|---|
| 位置 | 顱骨與硬腦膜之間 | 硬腦膜與蜘蛛膜之間 | 同左 |
| 血管 | **腦膜中動脈**（**動脈**），常合併**顳骨骨折** | **橋靜脈**（**靜脈**） | **橋靜脈**（**靜脈**），緩慢滲血 |
| 好發 | 年輕人、頭部側面撞擊 | 嚴重頭部外傷 | **老人**（腦萎縮、橋靜脈被拉長）、酗酒、**使用抗凝血劑** |
| 病程 | **短暫昏迷 → 清醒期 → 數分鐘到數小時內迅速惡化**；同側瞳孔放大、對側無力 | 受傷後 48 小時內，常一開始就昏迷 | 輕微撞擊後**數週到數月**才出現：**頭痛、記憶變差、行為怪異、嗜睡、意識漸差**、輕偏癱；容易誤認為失智 |
| 電腦斷層 | 凸透鏡形 | 新月形 | 新月形（低密度） |
| 治療 | **緊急開顱移除血腫**、止血 | 開顱手術 | **顱骨鑽孔引流**；小的可觀察 |

- 外傷性**蜘蛛膜下腔出血**與**腦內出血**也常見；動脈瘤破裂的蜘蛛膜下腔出血見 [[stroke#types]]
- 慢性硬膜下出血**不會**造成巴特爾氏徵象或鼻漏耳漏（那是顱底骨折），也不一定有庫欣氏三徵

## 急救與治療 {#treatment}

1. **呼吸道與頸椎**：頭部外傷都要假設**可能有頸椎損傷**，固定頸椎；打開呼吸道用**推顎法**（不用壓額抬下巴）；顱底骨折避免經鼻插管
2. **避免缺氧與低血壓**：兩者都會使預後明顯變差；重度頭部外傷依年齡維持收縮壓 ≥ 100–110 mmHg（來源：[Brain Trauma Foundation 第 4 版指引](https://doi.org/10.1227/NEU.0000000000001432)）
3. **電腦斷層**：頭部外傷的首選檢查
4. **輸液**：**避免低張溶液**（0.45% NaCl、D5W 會加重腦水腫）；考題答案為 D5S，臨床多用 **0.9% NaCl** 等張溶液，同時避免高血糖
5. 手術：清除血腫、抬起凹陷骨片、修補硬腦膜、減壓顱骨切除
6. 顱內壓監測與處置見 [[increased-icp#treatment]] 與 [[icp-monitoring]]
7. **預防外傷後早期抽搐**：BTF 建議用 **phenytoin** 減少受傷後 **7 天內**的早期抽搐，但不能預防晚期癲癇；levetiracetam 證據較少、臨床也常用（來源：[Brain Trauma Foundation 第 4 版指引](https://doi.org/10.1227/NEU.0000000000001432)）；**類固醇不建議**用於頭部外傷（同上來源）

## 併發症 {#complications}

| 併發症 | 重點 |
|---|---|
| 顱內壓升高、腦疝脫 | 腦水腫在受傷後 24–72 小時達高峰（見 [[increased-icp]]） |
| **外傷後癲癇** | **開放性**、凹陷性骨折、顱內出血較多；早期（7 天內）與晚期 |
| **腦膜炎** | 腦脊髓液漏、開放性傷口 |
| **尿崩症**（見 [[diabetes-insipidus-siadh]]） | **下視丘或腦下垂體後葉**受傷 → ADH **不足** → **大量稀薄尿、尿比重低、高血鈉**；**每小時**記錄輸入輸出、尿比重與尿色，依醫囑給 desmopressin |
| **SIADH** | ADH **過多** → 水分滯留、**稀釋性低血鈉**、意識變差、抽搐；**限水** |
| 腦耗鹽症候群 | 腎臟排鈉過多 → 低血鈉合併**脫水**，要補鈉與水（與 SIADH 處理相反） |
| 水腦 | 外傷性蜘蛛膜下腔出血後吸收不良 |
| 創傷後症候群 | 見上方腦震盪 |

::questions{ids="106-2_makeup_MS_005"}

## 護理 {#nursing}

1. 定時神經學評估（GCS、瞳孔、生命徵象、肌力）並與前次比較；**意識下降、瞳孔不等大**立即通報
2. 顱內壓升高的預防與姿勢（床頭 30 度、頭頸正中、避免用力）見 [[increased-icp#nursing]]
3. 腦脊髓液漏照護（見上方）；觀察發燒、頸部僵硬等腦膜炎徵象
4. 記錄輸入輸出、體重、血鈉，及早發現尿崩症或 SIADH
5. 安全：躁動時找原因（缺氧、疼痛、膀胱脹、顱內壓上升）；必要時依規定約束並定時評估循環
6. 頭皮傷口沾到的**新鮮血漬**用**冷水**清洗（熱水會使蛋白質凝固）
7. 復健與家屬支持：認知、行為與情緒改變可能長期存在
