雙相情緒障礙症是一種**反覆發作**的情緒疾病：病人會有**躁症(或輕躁症)發作**，大多數也會有**鬱症發作**，兩次發作之間可能恢復正常。第一型的終生盛行率約 1%，**男女相當**，多在青少年後期到 20 多歲發病，**遺傳**影響很大。它的**自殺**風險與物質濫用、焦慮等共病都很高，而且常從症狀出現到確定診斷要經過好幾年。

國考考點集中在「躁症的症狀」「躁症病人的營養與活動安排」「溝通與設限」「鋰鹽」。本頁藥物部分見 [[mood-stabilizers]]；鬱期的護理與自殺評估見 [[depressive-disorder]]。

## 相關生理 {#physiology}

- **兒茶酚胺假說**：躁症與**正腎上腺素、多巴胺**功能**過度亢進**有關；鬱期則與單胺不足有關。見 [[neurotransmitters-psychiatry#monoamine]]。
- **晝夜節律與睡眠**：睡眠被剝奪、時差、日夜顛倒都可能誘發躁症；**睡眠需求減少**常是躁症的第一個警訊。
- 與腦內啡**沒有直接關係**。

## 病因 {#etiology}

- **遺傳**：最強的危險因子，一等親罹病者風險明顯增加。家族史屬於**潛在(素質)因素**。
- **神經傳導物質與內分泌**：NE、DA、5-HT 失調；甲狀腺功能異常。
- **誘發因素**：壓力事件、**睡眠剝奪**、物質(安非他命、古柯鹼、酒精)、類固醇；**抗憂鬱劑**可能誘發躁症或快速循環；產後也是高風險期。
- 早年創傷、成長經驗造成的個性改變，也屬於潛在因素。
- 衛教時可以告訴家屬：這個病與**腦內神經傳導物質與內分泌**有關，需要**藥物治療**，不是個性或教養問題。

### 常用的心理防衛機轉 {#defense-mechanisms}

| 機轉 | 在雙相中的表現 |
|---|---|
| **反向作用** | 用**誇大、自大**的言行，掩飾內心的**無助與自卑** |
| **否認** | 否認挫折、焦慮與疾病 |
| **內射** | 鬱期把失落與不滿轉向自己 |

- 「合理化」不是雙相病人典型的防衛機轉。

## 臨床表現 {#manifestations}

### 躁症 {#mania}

| 面向 | 表現 |
|---|---|
| **情緒** | **高昂、欣快、誇張**，或**易怒**(被阻止時很快變得生氣罵人)；情緒轉變快 |
| **自尊** | **自尊膨脹、誇大**，甚至**誇大妄想**(「我是神力女超人」「我要拯救世界」) |
| **睡眠** | **睡眠需求減少**：睡 2–3 小時就覺得精神很好(不是失眠後疲倦) |
| **言語** | **話多、說個不停、搶話**、音量大、語速快 |
| **思考** | **意念飛躍**(話題跳來跳去，但前後仍有一點關聯)、音韻聯結、思考奔馳 |
| **注意力** | **容易分心**，被無關的刺激吸引，吃飯、洗澡都無法專心完成 |
| **活動** | **目標導向活動增加**(一直參加社交、工作、打電話)或無目的的忙碌；翻箱倒櫃、四處管閒事 |
| **判斷力與衝動** | **過度投入有風險的活動**：亂花錢、大量買東西送人、投資、**性行為不檢點**、危險駕駛 |
| 外觀 | **濃妝**、衣著鮮豔暴露、配件誇張 |
| 生理 | 不吃不睡，**體重減輕**、脫水、疲憊 |
| 人際 | 操縱、挑釁、試探界線、干預他人、好辯；對住院不滿、投訴 |
| 精神病症狀 | 約 60–75% 的雙相病人一生中曾出現精神病症狀，多與情緒一致(誇大妄想) |

- 病人**想法很多，但注意力容易轉移、缺乏組織力**，所以通常**無法把計畫完成**。
- 國考常把躁症的特徵與「**意念飛躍、活動量增加、注意力分散**」連在一起；「**體重增加**」「睡眠需求增加」「注意力集中」「對所有活動興趣減少」都**不是**躁症的特徵。

:::tip[記憶法 DIGFAST]
**D**istractibility 分心、**I**mpulsivity 衝動(花錢、性)、**G**randiosity 誇大、**F**light of ideas 意念飛躍、**A**ctivity 活動增加、**S**leep 睡眠需求減少、**T**alkativeness 話多。
:::

### 輕躁症與鬱症 {#hypomania-depression}

- **輕躁症**：症狀與躁症相同但較輕，**沒有明顯的功能損害**、**不需要住院**、**沒有精神病症狀**；旁人看得出與平常不同。
- **鬱症發作**：表現與 [[depressive-disorder#manifestations]] 相同；雙相鬱期較常有嗜睡、吃多、動作遲緩、精神病症狀。鬱期與混合期是**自殺**的高風險時期。

## 診斷與分類 {#diagnosis}

### 診斷重點 {#diagnostic-criteria}

以下依 DSM-5-TR 的內容**摘要改寫**(非準則原文)：

| | **躁症發作** | **輕躁症發作** |
|---|---|---|
| 核心 | 異常且持續的高昂、誇張或易怒情緒，**加上**活動量或精力持續增加 | 相同 |
| 時間 | **至少 1 週**，幾乎每天、一天大部分時間(**需要住院則不限時間**) | **至少連續 4 天** |
| 其他症狀 | 誇大、睡眠需求減少、話多、意念飛躍、分心、目標導向活動增加或激躁、從事高風險活動：**至少 3 項**(若只有易怒而沒有高昂，需要 **4 項**) | 相同 |
| 嚴重度 | **明顯功能損害**，或需要**住院**，或有**精神病症狀** | **沒有**明顯功能損害、不需住院、沒有精神病症狀 |

### 分類 {#types}

| 分類 | 定義 |
|---|---|
| **第一型** | 至少**一次躁症發作**(可以有或沒有鬱症發作) |
| **第二型** | 至少一次**輕躁症**發作**加上**至少一次**鬱症發作**，**從來沒有**躁症發作 |
| **循環性情緒障礙症** | 至少 **2 年**(兒童青少年 1 年)，多次輕躁與憂鬱症狀，但都**未達**輕躁症或鬱症發作的標準 |
| 物質或藥物引起 | 抗憂鬱劑、類固醇、安非他命等；若在藥物作用消失後仍持續，則算真正的躁症 |
| **快速循環**(註明項) | **12 個月內**有 **4 次以上**情緒發作；與抗憂鬱劑、甲狀腺低下有關，自殺風險較高 |
| 混合特徵(註明項) | 躁期同時有憂鬱症狀，或鬱期同時有躁的症狀；自殺風險高 |

- 鑑別診斷：思覺失調症、情感思覺失調症、注意力不足過動症、邊緣型人格障礙症、**甲狀腺機能亢進**、物質使用(安非他命、古柯鹼)、類固醇。
- 很多病人第一次以鬱症表現，被診斷為憂鬱症，直到出現躁症才確診；所以每位憂鬱症病人都要問過去有沒有躁或輕躁的經驗。

:::exam[國考重點]
- 躁症發作 = **至少 1 週**；輕躁症 = **至少 4 天**。
- 第二型 = **輕躁＋鬱症**，沒有躁症。
- 快速循環 = 一年 **4 次以上**。
:::

## 治療 {#treatment}

### 急性躁期 {#acute-mania}

- 第一線：**鋰鹽**、**valproate**，或**第二代抗精神病藥**(aripiprazole、quetiapine、olanzapine、risperidone 等)；嚴重時合併情緒穩定劑與抗精神病藥(來源：[Taiwan consensus 2022 update](https://doi.org/10.1016/j.ajp.2023.103480)；[UpToDate：Bipolar mania and hypomania in adults. Choosing pharmacotherapy](https://www.uptodate.com/contents/bipolar-mania-and-hypomania-in-adults-choosing-pharmacotherapy))。
- **抗精神病藥可以用於急性躁症**，也用來控制激躁；急性激躁可短期合併 BZD。
- **停用抗憂鬱劑**。
- 輕躁症**也需要藥物治療**，不是只做心理治療。
- 藥物無效、懷孕、嚴重激躁或危及生命時可用 **ECT**(每週 2–3 次，不是每天)。

### 鬱期 {#bipolar-depression}

- 以 **quetiapine**、**lurasidone**、lamotrigine、鋰鹽等為主。
- **避免單用抗憂鬱劑**(可能誘發躁症或快速循環)；需要時必須合併情緒穩定劑。

### 維持期 {#maintenance}

- 大多數雙相病人都需要**長期維持治療**；規則服藥是預防復發**最關鍵**的因素。台灣共識：急性期緩解後前 6 個月為持續期，之後為維持期，是否長期維持依發作次數、嚴重度與家族史決定。
- 台灣共識的維持期單一藥物首選：**鋰鹽**(血中濃度 **0.6–0.8** mEq/L)、valproate、lamotrigine、**長效針劑 aripiprazole**；合併治療首選鋰鹽＋valproate。並強調**長效針劑**的角色，以及長期使用抗憂鬱劑與第一代抗精神病藥的風險(來源：[Taiwan consensus 2022 update](https://doi.org/10.1016/j.ajp.2023.103480))。
- **心理社會治療**(心理教育、認知行為治療、家庭治療、人際與社會節律治療)可以幫助病人因應壓力、辨認早期徵兆、**預防復發**。

## 護理 {#nursing}

### 護理問題與優先順序 {#nursing-priorities}

急性躁期最優先的護理目標是：**確保病人得到足夠的營養與休息**，並維護病人與他人的**安全**。

常見護理診斷：

- **營養攝取不足**(忙到不吃、只吃一口就走開)
- **睡眠型態紊亂**
- **思考過程改變**(意念飛躍、誇大)
- **自我照顧能力缺失**(洗澡、梳洗無法專心完成)
- **社交互動障礙**(操縱、干預他人、衝突)
- 潛在危險性受傷、潛在危險性對他人的暴力行為
- 鬱期或混合期：潛在危險性對自己的暴力行為(自殺)

### 環境 {#nursing-environment}

- **減少刺激**：安排**簡單、安靜**的空間，避免吵雜與人多的大廳；環境**簡化**、減少裝飾與色彩鮮豔的布置；限制訪客人數與時間。
- **安全**：家具擺設避免跌撞或被拿來破壞；移除危險物品。
- 必要時**隔離**，原則是獨處、隔離、**減少感覺輸入**，不是懲罰。

### 營養、睡眠與身體照顧 {#nursing-physical}

- 提供**高熱量、高蛋白、方便拿著邊走邊吃**的食物(手指食物：三明治、飯糰、水果、營養補充品)，**少量多餐**；**監測進食的質與量**與體重。
- 補充**足夠水分**(大量活動與出汗；服用鋰鹽時尤其重要)。
- **睡眠**：減少咖啡因與晚間刺激，建立規律的睡前例行活動，白天安排休息時段；記錄睡眠時數。
- **個人衛生**：洗澡、洗頭時**在旁協助**，避免被其他事物吸引而中斷；注意**月經週期**與衛生用品；衣著過於暴露時溫和提醒。

### 活動安排 {#nursing-activity}

- 選擇**能消耗體力**、**非競爭性**、**短時間就能看到成果**的活動，再依病人的專注力調整：散步、打掃、協助布置活動場地、簡單的書寫或繪畫。
- **避免**：需要長時間專注的**精細活動**(刺繡、串珠)、**競爭性**與容易引起衝突的團體遊戲、會讓病人更興奮的大型團體活動、使用剪刀等危險工具的活動。
- 躁症病人容易受他人影響，較適合**單獨或小團體**活動。

:::note[國考答案的細節]
109-2 題目中「活動過多」的病人，答案選「**寫書法、繪畫、下棋**」，排除「剪紙」。下棋雖然有競爭性，但屬於安靜、單純的一對一活動；判斷時優先排除**精細、危險、刺激性高**的選項。
:::

### 溝通與行為處理 {#nursing-communication}

| 情境 | 適當的處理 | 不適當 |
|---|---|---|
| 意念飛躍、話題亂跳 | **簡短、清楚、具體**的句子，把話題拉回重點(**集中話題**：「你先告訴我要坐哪裡吃午餐？」) | 跟著話題跑、長篇大論 |
| **操縱**行為(威脅病友、搶主導權) | **一致、堅定、就事論事地設限**，全體工作人員採**一致的規則** | 權威式壓制、包容縱容、私下要病友忍耐 |
| 過多的要求(外出買零食) | **拖延並轉移注意力、給予適當限制、協商給予部分滿足** | 立即約束 |
| 要求離開隔離室 | **說明原因並設限**(「你發燒要觀察，暫時不能出來」)、**部分接受**(「我先幫你量體溫，再依結果決定」) | 不理會、因為要求太多就改成約束 |
| 在客廳批評醫護、說要投訴媒體 | **把病人帶開**，轉移到其他活動(例如陪伴參加歌唱活動) | 在眾人面前辯論澄清、一直肯定他的抱怨 |
| 不斷投書給院長 | **了解他的行為與想法，並與他討論** | 置之不理 |
| 因為要求被拒而**摔東西** | **引導用言語表達憤怒** | 說教、立刻討論行為 |
| 易與人起衝突、有攻擊行為 | 帶離現場、**以堅定口氣指示適當的行為**、鼓勵用言語表達感受，必要時**帶入保護室隔離** | 把病人留在現場 |
| 管閒事(大聲要求處理掉藥的病友) | 先了解掉藥病人的狀況，並**把游先生帶開、轉移注意力** | 「這不關你的事」 |
| **性方面不適當的行為**(進入異性房間、躺在異性床上、濃妝暴露) | **了解行為原因**、**轉移注意力**、提醒要尊重他人；**把兩人分開並持續觀察**，評估性互動的程度，教導適當的異性互動 | 以隔離或約束作為懲罰、沒收化妝品衣物、置之不理 |
| 追求護理師 | **明確說明彼此是護病關係** | 開玩笑、接受 |
| 大量買東西送人(包括送給護生) | **與病人討論送禮的適當程度**，不接受禮物 | 收下或當眾拒絕讓他難堪 |
| 質疑衛教、與護生爭辯 | **了解雙方的想法，適時引導與澄清** | 讓護生繼續和他辯論 |
| 打電話報警說被監禁 | **與病人會談，傾聽他住院的不舒服** | 沒收電話、斥責 |
| 團體中不斷抱怨住院規則 | **接納，並邀請團體成員表達經驗** | 請他離開團體 |
| 擔心藥物副作用、要求看藥品手冊 | **先同理與傾聽**，主動評估他的疑慮並**提供清楚的藥物衛教** | 「醫師開的就對了」 |

### 出院準備與家屬衛教 {#nursing-discharge}

- 雙相情緒障礙症**容易復發**，**配合醫囑長期規則服藥**，**不要自己減藥或停藥**；停藥前一定要和醫師討論。
- **復發的早期警訊**：**睡眠時間變少卻不覺得累**、話變多、花錢變多、計畫變多、易怒；或是興趣減少、疲倦、退縮。出現時及早回診。
- **規律作息**：固定睡眠與起床時間，避免熬夜、日夜顛倒、長途時差。
- **避免酒精與毒品**，也不要自行服用含咖啡因的提神飲料或減肥藥。
- 記錄**情緒日記**，幫助辨認變化。
- 家屬協助：注意警訊、陪伴回診、必要時協助管理**信用卡與財務**、減少家中衝突與批評。
- 服用鋰鹽者的飲食、水分與抽血衛教見 [[mood-stabilizers#lithium-nursing]]。
- 反覆因停藥而復發的病人，可以和醫師討論**長效針劑**。
