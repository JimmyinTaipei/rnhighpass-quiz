本頁依遺傳模式整理常考的**單基因疾病**：每個疾病寫遺傳、機轉、關鍵表現與護理重點。遺傳模式的規則、機率怎麼算、全部疾病的分類總表在 [[genetic-inheritance]]；染色體異常在 [[chromosomal-disorders]]。血液疾病的輸血、排鐵與照護見 [[anemias#hemolytic]]，凝血因子治療與照護見 [[bleeding-disorders]]

## 重點摘要 {#summary}

- **體染色體隱性**：海洋性貧血、鐮刀型貧血、苯酮尿症等先天代謝異常、囊性纖維化、威爾森氏症、脊髓性肌肉萎縮症、嬰兒型多囊腎
- **體染色體顯性**：軟骨發育不全(FGFR3)、成骨不全（膠原蛋白）、馬凡氏症、神經纖維瘤症、成人型多囊腎、家族性高膽固醇血症、類血友病
- **X 性聯隱性**：血友病 A／B、G6PD 缺乏症、裘馨氏肌失養症
- **海洋性貧血**：α 型在第 16 號、β 型在第 11 號染色體；**MCV** 是篩檢第一步；夫妻同型帶因 → 胎兒 **1/4** 重型，做羊膜穿刺或絨毛取樣產前診斷；**重型 β 型在胎兒期正常**，出生半年後才發病
- **G6PD 缺乏症**：氧化壓力下溶血（Heinz 小體）；避免**蠶豆、樟腦丸（萘）、紫藥水**、磺胺類等藥物；不影響智力
- **裘馨氏肌失養症**：缺**肌縮蛋白**(dystrophin)；男童 2–5 歲發病、**Gower 徵象**、**小腿假性肥大**、腰椎前凸；鼓勵適度活動（游泳），避免肥胖與長期臥床

### 國考常考點 {#exam-points}

- 海洋性貧血是**體染色體隱性**（不是顯性、不是性染色體、不是多基因）；α 型由第 **16** 號、β 型由第 **11** 號染色體控制；根治 β 型的唯一方法是**骨髓（造血幹細胞）移植**
- 篩檢孕婦是否為海洋性貧血帶因者：**平均紅血球體積(MCV)**
- 夫妻同型帶因：胎兒重型的機率 **1/4**（不是 75%）；和性別無關；**重型 β 型在胎兒期是正常的**
- **Hb Bart's** 出現在 **α 型**海洋性貧血
- 缺鐵性貧血與海洋性貧血：缺鐵**血清鐵下降**；海洋性貧血**鐵蛋白上升**；兩者 MCV 都偏小
- 鐮刀型貧血**不會**出現顱骨變大、顴骨隆起（那是重型海洋性貧血）；預防危象**不需要定期輸注全血**，要多喝水、治療感染、休息
- **甲基丙二酸血症**是有機酸代謝異常、AR；甲基丙二酸堆積**不會**造成楓糖尿症
- 囊性纖維化：**不可用止咳劑與抗組織胺**（會讓痰更難咳出）；給胰酵素、脂溶性維生素、高熱量高蛋白、大量水分
- 威爾森氏症是**體染色體隱性**（不是顯性）；銅沉積在肝與腦、角膜棕綠色環、神經與精神症狀
- **嬰兒型**多囊腎是 **AR**；**成人型**是 **AD**(PKD1)，雙側腎囊腫、常合併肝囊腫
- 軟骨發育不全：**AD**、約 90% 與 **FGFR3** 有關；四肢短、前額突出、鼻樑凹陷，**智力與生殖力正常**
- 成骨不全：藍色鞏膜、可能聽力喪失；**不需要限制所有活動**、不要完全固定不動；雙磷酸鹽可降低骨折
- **B 型**血友病缺**第九因子**；A 型缺第八因子：**凝血時間延長、出血時間正常**
- G6PD：應避免**紫藥水、樟腦丸**；誘發溶血的不包括抗痙攣藥；**較不影響智力**；紅血球內常見 **Heinz 小體**
- 裘馨氏肌失養症是 **X 性聯隱性**（不是體染色體隱性）；蹲下後無法自己站起(Gower)、腰椎前凸、腓腸肌假性肥大；**巴羅氏徵象是髖關節發育不良**的檢查，不是肌失養症；CPK 上升
- 裘馨氏肌失養症：游泳是好的運動，但**不要高強度**；不必禁止游泳；每日胸腔物理治療預防肺炎、控制體重、調整居家環境

## 體染色體隱性 {#autosomal-recessive}

### 海洋性貧血 {#thalassemia}

- 血紅素的**球蛋白鏈製造減少**，紅血球小而少 → 小球性低色素貧血、無效造血與溶血
- 台灣、東南亞、地中海地區常見；**國人帶因率約 6%**，以**甲型（α 型）較多**（衛生福利部 2017「帶因夫妻孕期接受檢查，防治重型海洋性貧血兒」）
- 遺傳：**體染色體隱性**

| | α 型 | β 型 |
|---|---|---|
| 基因位置 | 第 **16** 號染色體（每條有 2 個 α 基因，共 4 個） | 第 **11** 號染色體（每條 1 個 β 基因，共 2 個） |
| 常見缺陷 | 基因**缺失** | **點突變** |
| 嚴重型 | 4 個 α 基因全缺：胎兒水腫(**Hb Bart's**)，多在子宮內或出生後不久死亡；孕婦易發生妊娠高血壓 | 兩個 β 基因都異常：**重型 β 型**（Cooley 貧血） |
| 發病時間 | 胎兒期 | 胎兒期用胎兒血紅素（不需要 β 鏈）所以**正常**；出生後約 **6 個月**胎兒血紅素被取代時才發病 |

- **重型 β 型**表現：嚴重貧血、**肝脾腫大**、生長遲緩、**骨髓擴張造成顱骨變大、顴骨隆起、塌鼻**（地中海臉）、反覆輸血造成**鐵沉積**
- 帶因者（輕型）：多無症狀，只有 **MCV 偏小**；不要誤以為缺鐵而長期補鐵
- **產前篩檢流程**
   1. 孕婦驗**全血球計數**，MCV < 80 fL 為疑似帶因（MCV 是第一步，見 [[complete-blood-count#anemia]]）
   2. 配偶也驗；兩人都疑似時做血紅素電泳或基因檢查確認型別
   3. **夫妻同型帶因**：每胎 1/4 重型 → 建議**絨毛取樣或羊膜穿刺**產前診斷
- 和缺鐵性貧血的區別

| | 缺鐵性貧血 | 海洋性貧血 |
|---|---|---|
| MCV | 小 | 小 |
| 血清鐵 | **下降** | 正常或上升 |
| 鐵蛋白 | **下降** | 正常或**上升**（反覆輸血更高） |
| 遺傳 | 否 | 是(AR) |

- 治療：重型需定期輸血＋**排鐵劑**；**造血幹細胞移植**是唯一根治方法；輸血與排鐵的照護見 [[anemias#thalassemia-care]]

### 鐮刀型貧血 {#sickle-cell}

- β 鏈第 6 個胺基酸由麩胺酸換成纈胺酸 → **HbS**；缺氧、脫水、酸中毒時聚合，紅血球變成鐮刀狀
- 非洲裔常見，台灣很少；帶因者對**瘧疾**有保護作用
- 表現
   1. 溶血性貧血、黃疸
   2. **血管阻塞危象**：劇烈疼痛、**手足腫痛**（嬰幼兒）、胸部症候群、中風
   3. 視網膜病變、腎臟損傷
   4. 脾臟早期腫大，之後反覆梗塞而萎縮（自體脾切除） → 易被有莢膜細菌感染
- 預防危象：**多喝水**、避免缺氧與寒冷、及早治療感染、休息；不需要常規定期輸注全血

::questions{ids="107-2_OP_046,106-2_makeup_OP_066"}

### 先天代謝異常 {#metabolic}

- 多為 **AR**，酵素缺乏 → 受質堆積或產物不足；**新生兒篩檢**可早期發現
- 苯酮尿症、半乳糖血症、楓糖尿症、高胱胺酸尿症、先天性腎上腺增生症的飲食與照護見 [[pediatric-endocrine#inborn-errors]]
- **有機酸血症**（甲基丙二酸血症、異戊酸血症）
   1. 胺基酸分解途徑中斷，有機酸堆積 → **代謝性酸中毒**、酮酸血症、高血氨、嘔吐、昏迷
   2. 急性期：停止蛋白質、靜脈葡萄糖提供熱量、矯正酸中毒（碳酸氫鈉）
   3. 異戊酸血症有**臭腳汗味**；楓糖尿症是另一種病（支鏈胺基酸），尿有楓糖味

::questions{ids="107-1_OP_063"}

### 囊性纖維化 {#cystic-fibrosis}

- 第 7 號染色體 **CFTR**（氯離子通道）突變，AR；白人最常見的致死性遺傳病，台灣很少
- 外分泌腺分泌物**黏稠**
   1. 肺：痰黏稠阻塞 → 反覆感染（綠膿桿菌）、支氣管擴張
   2. 胰臟：外分泌不足 → 脂肪痢、脂溶性維生素缺乏、生長遲緩
   3. 新生兒胎便阻塞腸道；男性不孕
   4. 汗液含鹽量高（**汗液氯離子試驗**）
- 照護：胸腔物理治療、補充**胰酵素**、**脂溶性維生素**、**高熱量高蛋白**、大量水分與鹽分；**不用止咳劑與抗組織胺**；提供遺傳諮詢

::questions{ids="108-1_OP_065"}

### 威爾森氏症 {#wilson}

- **ATP7B** 基因異常，肝臟無法把銅排到膽汁，AR
- 銅沉積
   1. 肝：肝炎、**肝硬化**
   2. 腦（基底核）：顫抖、構音困難、類巴金森症狀，以及**精神與行為症狀**
   3. 角膜：**Kayser-Fleischer 環**（角膜周邊棕綠色環）
- 檢驗：血中**銅藍蛋白下降**、24 小時尿銅上升
- 治療：螯合劑(D-penicillamine)、鋅、**低銅飲食**（避免動物內臟、貝類、堅果、巧克力）；嚴重時肝臟移植

::questions{ids="110-1_BM_044"}

### 脊髓性肌肉萎縮症 {#sma}

- **SMN1** 基因缺失 → 脊髓前角運動神經元退化 → 近端肌肉無力萎縮、呼吸與吞嚥困難，AR
- 台灣約每 48 人有 1 人帶有致病基因（2026 年國健署 SMA 新生兒篩檢記者會資料）；**2026-07-01 起納入公費新生兒篩檢**，早期治療效果較好
- 已生過一個患孩：下一胎患病 1/4，應做產前基因診斷（題目見 [[genetic-inheritance#mendelian]]）

### 多囊腎 {#pkd}

| | 嬰兒型（兒童型） | 成人型 |
|---|---|---|
| 遺傳 | **體染色體隱性**(PKHD1) | **體染色體顯性**（多數為 **PKD1**，其次 PKD2） |
| 表現 | 新生兒雙側腎臟腫大、肺發育不全；常合併肝臟纖維化 | 中年才出現症狀：**雙側腎囊腫**、高血壓、血尿、腰痛，逐漸腎衰竭；常合併**肝囊腫**、腦動脈瘤 |

- **單純性腎囊腫**很常見，多半無害

::questions{ids="109-1_BM_034,110-2_BM_047"}

## 體染色體顯性 {#autosomal-dominant}

### 軟骨發育不全 {#achondroplasia}

- **最常見的侏儒症**；約 90% 以上與 **FGFR3** 基因的活化突變有關，抑制長骨的軟骨內骨化；約八成是新突變
- 表現：**四肢短**（近端更明顯）、軀幹長度大致正常、**頭大前額突出**、**鼻樑凹陷**、腰椎前凸
- **智力正常、生殖力正常**
- 其他基因：Fibrillin-1 是馬凡氏症、NF-1 是神經纖維瘤症

::questions{ids="108-1_BM_048,113-1_BM_030,114-3_BM_030"}

### 成骨不全（玻璃娃娃） {#osteogenesis-imperfecta}

- **第一型膠原蛋白**基因（COL1A1、COL1A2）異常，多為 AD
- 表現：**骨頭脆弱、反覆骨折**、骨骼變形與身材矮小、**藍色鞏膜**、牙齒發育不全、**聽力喪失**、關節鬆弛
- 照護
   1. 搬動時**支托軀幹與四肢**，不拉扯手腳；換尿布時抬臀部而不是抬腳
   2. 不要完全固定不動（骨質會更流失）；在安全範圍內活動，**游泳**等低衝擊運動合適；固定時健側多運動
   3. **雙磷酸鹽**降低骨折頻率；嚴重變形可做骨髓內釘固定
   4. 家長要知道反覆骨折不等於受虐，但仍需評估

::questions{ids="111-1_OP_079,113-3_OP_028"}

### 馬凡氏症 {#marfan}

- **原纖維蛋白（fibrillin-1，FBN1）** 基因異常，結締組織彈性纖維脆弱，AD
- 表現：**高瘦、四肢與手指細長**、關節過度伸展、胸廓變形；**水晶體脫位**；**主動脈根部擴張與剝離**（主要死因）、二尖瓣脫垂
- 避免劇烈與碰撞運動；fluoroquinolone 類抗生素可能增加主動脈剝離風險（見 [[fluoroquinolones-sulfonamides]]）

### 神經皮膚症候群 {#neurocutaneous}

- **第一型神經纖維瘤症**（NF1，第 17 號染色體）：多處**咖啡牛奶斑**、皮膚神經纖維瘤、虹膜 Lisch 結節；表現度差異大
- **結節性硬化症**：癲癇、智能障礙、臉部血管纖維瘤、腦部結節

### 家族性高膽固醇血症 {#familial-hypercholesterolemia}

- **LDL 受體**基因異常，肝臟無法清除 LDL，AD
- 異型合子 LDL 約為正常的 2–3 倍、年輕就發生冠心病；同型合子更嚴重；可見肌腱黃色瘤
- 檢驗與治療見 [[lipid-profile#high-ldl]]、[[statins]]

### 類血友病與遺傳性球形紅血球症 {#vwd}

- **類血友病**(von Willebrand disease)：**最常見的遺傳性出血疾病**，多為 AD；vWF 不足使血小板無法黏附 → 皮膚黏膜出血（流鼻血、牙齦出血、月經過多）、**出血時間延長**；屬於出血傾向，和高凝血狀態無關（見 [[thrombosis-embolism-infarction#hemostasis]]）
- 治療與照護見 [[bleeding-disorders#vwd]]

### 遺傳性球形紅血球症 {#spherocytosis}

- 紅血球膜骨架蛋白異常，多為 AD；紅血球變成球形、在脾臟被破壞 → 溶血性貧血、黃疸、**脾腫大**、膽結石；脾臟切除可改善

## X 性聯 {#x-linked}

### 血友病 {#hemophilia}

| | A 型 | B 型 |
|---|---|---|
| 缺乏 | **第八凝血因子** | **第九凝血因子**（Christmas 因子） |
| 比例 | 約 80–85%，較常見 | 約 15% |

- X 性聯隱性，患者幾乎都是男性；約三分之一是新突變（沒有家族史）
- 凝血功能：**凝血時間與 aPTT 延長**；**出血時間、PT、血小板數正常**（血小板功能正常）
- 表現：**關節血腫**（以**膝關節**最常見）、深部肌肉出血、拔牙或手術後出血不止
- 遺傳諮詢：女性帶因者的兒子 1/2 罹病（見 [[genetic-inheritance#x-linked-recessive]]）
- 凝血因子補充、關節出血處理、運動與生活照護見 [[bleeding-disorders#hemophilia]]

### G6PD 缺乏症（蠶豆症） {#g6pd}

- 紅血球缺乏**葡萄糖-6-磷酸去氫酶**，無法對抗氧化壓力；X 性聯，**男嬰較多**（主要由母親傳給兒子）
- 台灣新生兒篩檢最常發現的異常項目
- 接觸氧化物質 → 血紅素變性沉積成 **Heinz 小體** → **急性溶血**：貧血、**黃疸**（新生兒高膽紅素血症）、茶色尿
- 誘發因子
   1. **蠶豆**及其製品（哺乳母親也要避免）
   2. **樟腦丸（萘丸）**、**紫藥水**、龍膽紫
   3. 藥物：**磺胺類**、抗瘧藥(primaquine)、高劑量 aspirin 等解熱鎮痛劑（見 [[fluoroquinolones-sulfonamides]]、[[nsaids-acetaminophen]]）
   4. 感染
- 不發作時和正常人一樣，**不影響智力**；給家長「避免清單」並在就醫時主動告知

### 裘馨氏肌失養症 {#duchenne}

- **Dystrophin（肌縮蛋白）** 基因異常 → 肌纖維膜不穩定、肌肉細胞反覆壞死，由脂肪與結締組織取代；X 性聯隱性，**男童**
- **貝克型**：同一基因、還有部分功能，較晚發病、較輕
- 表現
   1. 2–5 歲開始走路容易跌倒、爬樓梯困難、**鴨子步態**
   2. **Gower 徵象**：從地上站起來時要用手撐著腿往上爬
   3. **小腿（腓腸肌）假性肥大**、站立時**腰椎前凸**
   4. 約 12 歲前後需要輪椅；之後脊柱側彎、**呼吸衰竭**與心肌病變，是主要死因
   5. 血中 **CK(CPK)**、aldolase、AST 明顯上升
- 護理
   1. 鼓勵**適度**活動維持肌力與關節活動度，避免長期臥床；游泳是好的運動，但不要高強度
   2. 控制體重、預防肥胖
   3. 每日胸腔物理治療、預防呼吸道感染
   4. 調整居家環境、提供輔具，預防跌倒
   5. 家庭支持與遺傳諮詢（母親可能是帶因者）
- **巴羅氏徵象**、歐特蘭尼徵象是髖關節發育不良的檢查，不要混淆

::questions{ids="114-1_OP_049,105-2_OP_077,112-2_OP_077,114-2_OP_050"}

### 雷特氏症 {#rett}

- **MECP2** 基因異常，X 性聯顯性，幾乎都是**女孩**
- 6–18 個月前發展正常，之後**退化**：失去語言與手部功能、出現**重複搓手**動作、步態異常、癲癇、頭圍成長變慢
