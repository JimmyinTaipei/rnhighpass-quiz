**急性腎損傷**(AKI, acute kidney injury)是腎功能在短時間內突然下降，含氮廢物（BUN，blood urea nitrogen、肌酸酐）排不出去，水分、電解質與酸鹼跟著失衡。2002 年起醫界把「急性腎衰竭」改稱急性腎損傷，把輕度的腎功能下降也納入，因為即使輕微也會影響預後（《內外科護理學》下冊 p.809）。及早找到原因多半可以恢復；腎功能檢驗見 [[renal-function-tests]]，高血鉀處理見 [[potassium#hyperkalemia-treatment]]

## 重點摘要 {#summary}

- 原因分三類
   1. **腎前性**（最常見）：腎灌流不足但腎臟本身沒壞 → 脫水、出血、燒傷、敗血性休克、**心衰竭、心肌梗塞**；持續太久會變成缺血性腎小管壞死
   2. **腎性**：腎實質受損 → **急性腎小管壞死**（最常見；缺血、腎毒性藥物、顯影劑、肌紅素）、腎絲球腎炎、SLE、**急性間質性腎炎**（藥物過敏）
   3. **腎後性**：尿路阻塞 → 結石、**攝護腺肥大**、腫瘤、血塊
- 病程四期：**初始期 → 少尿期 → 利尿期 → 恢復期**
- **少尿期**（< 400 mL/天，約 1–8 週）：**高血鉀**、低血鈉、高血磷低血鈣、高血鎂、**代謝性酸中毒**、體液過多（水腫、肺水腫、高血壓）、尿毒症狀、貧血與出血傾向
- **利尿期**（每天 1–5 L，約 10–14 天）：腎小管還不會回收 → **脫水、低血鉀、低血鈉**；BUN 與肌酸酐一開始仍高
- 腎前性 vs 腎性：腎前性 **BUN/Cr > 20**、尿鈉 **< 20**、尿比重高、尿滲透壓 > 500；腎性尿比重固定在 **1.010**、尿鈉 > 40
- 少尿期液體：**前一天尿量 ＋ 其他流失 ＋ 約 500 mL**（無感性流失）；限鉀、限鈉、限磷，**高熱量、限蛋白（以高生物價為主）**
- 透析適應症：危及生命的**高血鉀**、**肺水腫**等體液過多、嚴重酸中毒、尿毒症狀（心包膜炎、意識改變）、可透析的毒物；**利尿期不是**適應症

### 國考常考點 {#exam-points}

- 嚴重燒傷、心肌梗塞、敗血性休克是**腎前性**；**SLE 是腎性**
- 腎前性檢驗：BUN/Cr > 20:1、尿比重 > 1.015、尿滲透壓 500 以上；「**尿鈉 > 40 mEq/L**」是腎性才有（錯誤選項）
- 24 小時尿量 300–350 mL → **少尿期**、少尿型 AKI；高血鉀心電圖是 **T 波高尖**（不是低而寬）；AKI 腎臟**不會變小**（變小是慢性）；攝護腺肥大造成的是**腎後性**
- 少尿期生化：肌酸酐、BUN、鉀**上升**，**血磷上升**（不是下降）
- 燒傷初期大量肌紅素 → **急性腎小管壞死**；燒傷初期 GFR(glomerular filtration rate) **下降**（不是增加）
- 急性腎小管傷害是**腎小管**上皮壞死，病理**不是**絲球體壞死；可造成少尿（< 400 mL/天），缺血、重金屬、有機溶劑都是原因
- 急性間質性腎炎：藥物（抗生素）過敏，停藥後腎功能多可恢復，**不需要長期透析**
- 少尿期護理：**限制水分**、**限制高鈉高磷**、高熱量低蛋白、**不可**高鉀飲食；Kayexalate 是讓鉀**從腸道排出**
- 計算：尿量 360 mL ＋ 嘔吐 150 mL ＋ 無感性約 500 mL ≈ 1,000 mL；只給 510 mL 是錯的
- 急性腎衰竭的酸鹼：**代謝性酸中毒**，矯正用**碳酸氫鈉**（不是「矯正代謝性鹼中毒」）
- 兒童 AKI：尿量 < 0.5–1 mL/kg/hr、意識改變、高血鉀；BUN 與肌酸酐**上升**（不是降低）
- 透析適應症包括急性高血鉀、急性肺水腫、巴比妥類中毒；**利尿期不是**

## 相關生理 {#physiology}

- 腎臟收到約 1/4 的心輸出量，腎小管（特別是近曲小管與上升支）耗氧多，**最怕缺血**
- GFR 的決定因素與自我調節見 [[kidney-urinary-physiology#filtration]]；肌酸酐反應 GFR 有延遲，見 [[renal-function-tests#creatinine]]

## 病因與病理生理 {#pathophysiology}

### 原因分類 {#causes}

| 類別 | 機轉 | 常見原因 |
|---|---|---|
| **腎前性** | 腎灌流減少，腎實質本身正常；及時恢復灌流就可逆 | 血容積不足（脫水、出血、嘔吐腹瀉、**燒傷**、腹水等第三空間）、**敗血性休克**、過量降血壓藥；心輸出量下降（**心衰竭、心肌梗塞**、心包填塞、肺栓塞）；血管阻塞；肝腎症候群 |
| **腎性** | 腎實質受損 | **急性腎小管壞死**（最常見）；急性或急進性腎絲球腎炎；**急性間質性腎炎**；腎毒性物質（重金屬、有機溶劑、**顯影劑**、aminoglycoside、amphotericin B、NSAIDs，nonsteroidal anti-inflammatory drugs）；惡性高血壓、血管炎、SLE |
| **腎後性** | 腎臟以下尿路阻塞 | 輸尿管結石、血塊、腫瘤；膀胱出口阻塞（**攝護腺肥大**、攝護腺癌、膀胱癌）；尿道狹窄 |

依《內外科護理學》下冊表 19-13(p.809)整理

- **急性腎小管壞死**(ATN, acute tubular necrosis)：缺血或毒素讓腎小管上皮壞死、脫落阻塞管腔 → GFR 下降；原因有缺血（休克、大手術）、腎毒性藥物、**橫紋肌溶解或燒傷的肌紅素**、溶血的血紅素
- **急性間質性腎炎**：多為藥物過敏（penicillin、sulfonamide、NSAIDs），可有發燒、紅疹、蛋白尿；**停藥後多可恢復**；慢性間質性腎炎與止痛劑濫用、鉛鎘中毒有關（同上表 19-12）

## 分類與診斷 {#classification}

### KDIGO 診斷與分期 {#kdigo}

- 符合任一項就是 AKI（KDIGO，Kidney Disease: Improving Global Outcomes 2012）
   1. **48 小時內**血清肌酸酐上升 **≥ 0.3 mg/dL**
   2. **7 天內**肌酸酐升到基準值的 **1.5 倍**以上
   3. 尿量 **< 0.5 mL/kg/h 持續 6 小時**

| 分期 | 血清肌酸酐 | 尿量 |
|---|---|---|
| 1 | 基準的 1.5–1.9 倍，或上升 ≥ 0.3 mg/dL | < 0.5 mL/kg/h 持續 6–12 小時 |
| 2 | 基準的 2.0–2.9 倍 | < 0.5 mL/kg/h 持續 ≥ 12 小時 |
| 3 | 基準的 3 倍，或 ≥ 4.0 mg/dL，或開始腎臟替代療法（未滿 18 歲另含 eGFR，estimated glomerular filtration rate < 35） | < 0.3 mL/kg/h 持續 ≥ 24 小時，或無尿 ≥ 12 小時 |

- 新舊說法：課本與國考仍以「少尿 < 400 mL/天、無尿 < 100 mL/天」描述；KDIGO 以肌酸酐變化與每公斤每小時尿量分期。2026 AKI／AKD(acute kidney disease) 指引草案加入腎損傷生物標記並定義 3 個月內的急性腎臟疾病(AKD)，**尚未正式出版**（2026-10-21 查 KDIGO 網站）
- **非少尿型** AKI：每天尿量 500 mL 以上甚至 2,000 mL，但廢物一樣排不掉（同上 p.810）

### 臨床病程 {#phases}

| 期別 | 時間 | 尿量 | 重點 |
|---|---|---|---|
| **初始期** | 受傷到出現症狀（數小時到數天） | 開始減少 | 及早治療原因多半可逆 |
| **少尿期** | 約 1–8 週（越長預後越差） | **< 400 mL/天**（無尿 < 100 mL） | 高血鉀、低血鈉、高磷低鈣、高鎂、**代謝性酸中毒**、體液過多、尿毒症狀 |
| **利尿期** | 約 10–14 天 | 每天 1–2 L，可達 4–5 L | 腎小管還不能濃縮 → **脫水、低血鉀、低血鈉**；BUN 與肌酸酐先仍高再慢慢降 |
| **恢復期** | 數月到 1 年 | 正常 | GFR 在 1–2 年內恢復到正常的 70–80%，部分病人留下慢性腎病 |

依《內外科護理學》下冊 p.810–812 整理

### 少尿期的表現 {#oliguric-manifestations}

| 問題 | 原因與表現 |
|---|---|
| **體液過多** | 水腫、高血壓、頸靜脈怒張 → **肺水腫**、心衰竭 |
| **高血鉀** | 排不出去 → 感覺異常、肌肉無力、**T 波高尖**、PR 延長 → 心律不整、心跳停止 |
| 低血鈉 | 稀釋 → 噁心、頭痛、意識混亂 |
| 高血磷、低血鈣 | 磷排不掉，鈣跟著下降 → 軟組織鈣化 |
| 高血鎂 | 反射減弱、肌肉無力、呼吸麻痺 |
| **代謝性酸中毒** | H⁺ 排不掉 → Kussmaul 呼吸、噁心、嗜睡 |
| 尿毒症候群 | 噁心嘔吐、厭食、口腔潰瘍、頭痛、意識改變、**心包膜炎** |
| 貧血與出血傾向 | EPO(erythropoietin) 減少、尿毒素影響血小板功能 |
| 感染 | 免疫力下降，是重要死因 |

### 診斷 {#diagnosis}

| 指標 | **腎前性** | **腎性**（急性腎小管壞死） |
|---|---|---|
| **BUN/Cr** | **> 20:1**（可達 20–40） | 10–15:1 |
| 尿比重 | **> 1.015–1.020**（腎臟還會濃縮） | **固定在 1.010** |
| 尿滲透壓 | **> 500 mOsm/kg** | < 350 |
| **尿鈉** | **< 20 mEq/L**（腎臟努力保鈉） | **> 40 mEq/L** |
| 尿沉渣 | 正常或玻璃樣圓柱體 | 顆粒圓柱體、上皮細胞 |

- 其他：**腎臟超音波**看有沒有阻塞（腎後性）與腎臟大小（**AKI 腎臟正常或變大、CKD 變小**）；血鉀、鈣磷、ABG(arterial blood gas)、CBC(complete blood count)；必要時切片
- 使用顯影劑的檢查要權衡腎毒性（同上 p.812）

## 治療策略 {#treatment}

1. **找出並矯正原因**：腎前性 → 補足血量、矯正休克與心衰竭；腎性 → 停用腎毒性藥物；腎後性 → 解除阻塞（導尿、輸尿管支架）
2. **維持水分與電解質**
   1. 少尿期液體量：**前一天尿量 ＋ 其他可測量流失 ＋ 約 500 mL**（無感性流失）
   2. **高血鉀**：葡萄糖酸鈣穩定心肌、RI(regular insulin)＋葡萄糖、碳酸氫鈉把鉀移入細胞、Kayexalate（口服或灌腸）由腸道排鉀、必要時透析（詳見 [[potassium#hyperkalemia-treatment]]）
   3. 高血磷：限磷、**磷結合劑**；高血鎂：避免含鎂制酸劑與灌腸劑
   4. **代謝性酸中毒**：依醫囑**碳酸氫鈉**
   5. 體液過多：依醫囑 furosemide（[[loop-diuretics]]），無效時透析
3. **營養**：**高熱量**（避免自身蛋白質分解）、**限蛋白**（以高生物價蛋白為主）、**限鈉、限鉀、限磷**；不能吃就管灌或 TPN(total parenteral nutrition)
4. **腎臟替代療法**（透析）：見下方適應症；做法見 [[dialysis-crrt]]，加護病房常用 [[dialysis-crrt#crrt]]

### 透析適應症 {#dialysis-indications}

| 適應症 | 說明 |
|---|---|
| **危及生命或難治的高血鉀** | 藥物無效時 |
| **體液過多**（肺水腫、心衰竭） | 利尿劑無效 |
| 嚴重**代謝性酸中毒** | |
| **尿毒症狀** | 心包膜炎、尿毒性腦病變、出血 |
| 可透析的**藥物或毒物** | 巴比妥類、鋰鹽、甲醇、水楊酸 |

- **利尿期**尿量已經增加，不是透析適應症

## 護理 {#nursing}

### 臨床護理 {#nursing-clinical}

- **輸入輸出量**：每天記錄，必要時每小時尿量；**每天同一時間、同一體重計、穿同樣衣服、排尿後進食前**量體重
- 體液過多徵象：水腫、血壓上升、**肺囉音**、呼吸困難 → 半坐臥、限水
- **限水技巧**：口渴時含小冰塊、維生素 C 片；把水量平均分配到一天；吃藥時配餐減少喝水（同上 p.823）
- 監測血鉀與**心電圖**；避免高鉀食物與含鉀低鈉鹽、注意輸血（保存過久的血含鉀高）
- **利尿期**：防**脫水與低血鉀**，依尿量補充水分與電解質
- 預防感染：無菌技術、盡量避免留置導尿管、口腔護理
- 藥物：依腎功能調劑量；避免 aminoglycoside、NSAIDs、顯影劑等腎毒性藥物
- 尿毒症狀：意識、出血徵象、心包膜摩擦音

### 預防 {#prevention}

- 高危險群：老人、糖尿病、慢性腎臟病、心衰竭、敗血症、大手術、使用腎毒性藥物
- 維持足夠血量與血壓；使用顯影劑前後補充水分；監測藥物濃度（如 vancomycin、aminoglycoside）
- 燒傷、擠壓傷：積極輸液維持尿量，避免肌紅素造成腎小管阻塞

## 兒童 {#pediatric}

- 兒童常見原因：脫水（腸胃炎）、敗血症、心臟手術後、溶血性尿毒症候群、急性腎絲球腎炎
- 兒童課本分三期（少尿、利尿、恢復）：**少尿 < 1.0 mL/kg/hr**、**無尿 < 1 mL/kg/天**；利尿期約在少尿期開始 2 週左右，要防鈉鉀流失（《兒科護理學》p.610–611）
- 表現：水腫、嗜睡、呼吸快、心律不整、抽搐；BUN 與肌酸酐**上升**（腎前性 BUN 升得比肌酸酐快）、高血鉀、低血鈉（稀釋）、高磷低鈣
- 補液要算無感性流失（兒童約 300 mL/m²/天）＋尿量；每天體重約減 0.5–1%、血鈉維持約 140 表示補液恰當（同上）
- 腎前性兒童：尿鈉 < 20、尿比重 ≥ 1.020；腎性：尿鈉 > 40、尿比重約 1.012–1.015
- 少尿期一樣**限水**，不可給高鉀高鈉飲食；Kayexalate 讓鉀從腸道排出（不是增加吸收）
