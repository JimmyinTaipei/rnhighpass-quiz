**物質使用障礙症**是指反覆使用酒精、毒品或藥物，即使已經造成身體、心理、家庭與工作的傷害，仍然**無法控制、無法停止**。它是**腦部酬償系統改變**的慢性、容易復發的疾病，不只是意志力或道德問題。酒精見 [[alcohol-use-disorder]]，美沙冬等戒治藥物見 [[addiction-treatment-drugs]]，鎮靜安眠藥的依賴與戒斷見 [[anxiolytics-hypnotics#adverse-effects]]

## 重點摘要 {#summary}

- **耐受性**：腦與身體適應較高濃度，**需要更多量**才達到原來效果；**戒斷**：停用或減量後出現的身心不適
- **心理依賴**：強烈渴求，為了避免不愉快而持續使用；**生理依賴**：停用會出現生理戒斷
- **鴉片類(海洛因、嗎啡)**：中毒＝**針狀瞳孔、嗜睡昏迷、呼吸抑制、心跳變慢**；戒斷＝**打呵欠、流淚流鼻水、瞳孔放大、起雞皮疙瘩、腹瀉、肌肉骨頭痠痛**，不致命也**不會體溫過低**
- **興奮劑(安非他命、古柯鹼、搖頭丸)**：中毒＝心跳快、血壓高、瞳孔放大、高熱、妄想；**戒斷＝全身耗竭虛脫、嗜睡、憂鬱**(自殺風險)
- **K 他命**：NMDA 拮抗劑、解離性麻醉藥、**第三級毒品**；長期使用造成**慢性間質性(潰瘍性)膀胱炎**
- 護理：**中立不批判**、護理師**自我覺察**、對操縱行為**設限**、**動機式晤談**(不面質)、監測生命徵象與戒斷、鼓勵**自我照顧**；追蹤以**門診與社區**為主

### 國考常考點 {#exam-points}

- **耐受性**＝需要增加量才有同樣效果、腦部已適應較高濃度；「停止使用後出現的身心不適」是**戒斷**不是耐受性
- 心理依賴＝**強烈渴求、為避免不愉快而持續使用**；「使用過量或過久、想戒卻控制失敗、仍有渴求」＝**控制失調**
- 鴉片類**作用越短效**，戒斷**出現越快、持續越短、越強烈**
- 海洛因中毒：**呼吸抑制、昏迷**、**針狀瞳孔**、心跳變慢；「**瞳孔放大**」是戒斷，不是中毒
- 嗎啡戒斷：**食慾不振、打呵欠、流鼻水、肌肉痠痛**；渴藥、不安、流淚、發汗、瞳孔放大、腹痛、骨頭痠痛 → **鴉片類**戒斷
- 嗎啡使用後產生**欣快感**；不是提神、不是只能口服、護理師不能自行斟酌使用
- **安非他命戒斷**＝全身**耗竭虛脫、憂鬱沮喪**；安非他命的身體依賴性比咖啡因、LSD、大麻高
- **K 他命**：慢性**間質性膀胱炎**(頻尿、夜尿、血尿)，**不是急性**；常見心跳快、震顫、噁心嘔吐；醫學上用於麻醉；PCP 的作用類似 ketamine
- **古柯鹼**長期鼻吸 → **鼻中膈穿孔**(K 他命鼻吸也會，考選部曾 A、C 都給分)
- **MDMA(搖頭丸)**：結構類似安非他命、促進血清素釋放並抑制再回收、**高熱**、**橫紋肌溶解**與**急性腎衰竭**；英文簡稱**不是 NMDA**
- **LSD** 作用在**血清素**受體產生幻覺；**大麻 THC** 結合 **CB1 受體**
- **新興影響精神物質(NPS)**：派對使用、偽裝成**咖啡包、茶包、糖果**、**混用嚴重**；**不是天然、也不容易檢測**
- 精神動力學說：成癮者固著在**口腔期**(不是性蕾期)；酒癮與 **ALDH** 代謝有關；父母酗酒子女風險高；青少年好奇與同儕認同
- 古柯鹼過量血壓上升、呼吸不規則 → **最優先維持生命徵象穩定**
- 急診常見問題：鴉片戒斷(肌肉痙攣、骨頭痛)、**譫妄**、**急性精神病**；**夢遊不是**
- 護理：**不批判**、不鼓勵否認或隔離、妄想時**增加現實感但不爭辯**、操縱或暴力時**設限**；動機式晤談**不是直接面質**；追蹤輔導**不是以住院為主**

## 名詞與診斷 {#definitions}

### 重要名詞 {#terms}

| 名詞 | 意思 |
|---|---|
| **中毒** | 剛使用後，物質對中樞神經造成的可逆性行為與生理變化 |
| **耐受性** | 反覆使用後效果變差，**需要更多量**才達到原來效果；或用同樣的量效果明顯變弱 |
| **戒斷** | 長期大量使用後**停用或減量**，出現與該物質作用**相反**的身心症狀；再使用該物質或同類藥物可以緩解 |
| **心理依賴** | **強烈渴求**，為了得到快感或避免不愉快而持續或間歇使用 |
| **生理(身體)依賴** | 身體已適應物質，停用會出現生理戒斷；長期使用處方鴉片類者也會有，**不等於成癮** |
| **交叉耐受** | 對一種物質耐受，對同類物質也耐受(酒精與 BZD；海洛因與美沙冬)；也是用 BZD 治酒精戒斷、美沙冬治海洛因成癮的原理 |
| **共病** | 物質使用常合併憂鬱、焦慮、人格障礙、思覺失調症，自殺風險升高 |

### DSM-5 診斷(摘要) {#dsm5}

DSM-5 不再區分「濫用」與「依賴」，合併成**物質使用障礙症**，依 12 個月內符合的項目分輕、中、重度：

| 面向 | 內容 |
|---|---|
| **控制失調** | 用得比預期多或久、**想戒卻戒不掉**、花很多時間取得或恢復、**強烈渴求** |
| **社會功能減損** | 無法履行工作、學業、家庭責任；人際問題仍持續使用；放棄重要活動 |
| **危險使用** | 在危險情境(如開車)仍使用；**明知對身心有害仍持續使用** |
| **藥理學準則** | **耐受性**、**戒斷** |

- 嚴重度依符合的項目數分級(數目切點依記憶整理，列入 DSM 待核對清單)：2–3 項輕度、4–5 項中度、6 項以上重度
- 依醫囑使用的鴉片類或鎮靜藥出現的耐受與戒斷，不列入診斷項目

## 病因 {#etiology}

1. **生物**
   1. 成癮物質直接活化中腦邊緣系統的**酬償路徑**(腹側被蓋區到依核)，**多巴胺**增加產生愉悅感(見 [[neurotransmitters-psychiatry#dopamine-pathways]])
   2. **遺傳**：父母有酒癮或物質使用問題，子女風險較高；酒精代謝酵素(**ALDH2**)的差異影響飲酒行為
2. **心理**
   1. 精神動力學說：固著在**口腔期**，用物質滿足口腔需求、逃避焦慮
   2. 學習理論：使用後的快感是**正增強**，避免戒斷不適是**負增強**
   3. 認知：對物質的期待與信念；用物質**自我治療**憂鬱或焦慮
3. **社會**
   1. **同儕**影響，青少年因**好奇**、尋求認同而嘗試
   2. **家庭功能失調**、衝突、缺乏支持
   3. 物質容易取得、社會文化對使用的態度
4. 成因與「對成癮物質的認知」**有關**；病人也可能有想戒的矛盾心情

## 台灣毒品分級與法律 {#taiwan-law}

依毒品危害防制條例(法務部說明)：

| 級別 | 常見例子 |
|---|---|
| **第一級** | **海洛因、嗎啡、鴉片、古柯鹼**；2026-06-27 起**依托咪酯**(喪屍煙彈)升列第一級 |
| **第二級** | **安非他命**、甲基安非他命、**MDMA(搖頭丸)**、**大麻**、LSD |
| **第三級** | **K 他命(愷他命)**、**FM2**(flunitrazepam)、nimetazepam(一粒眠)、triazolam |
| **第四級** | alprazolam(蝴蝶片)、lorazepam、diazepam 等多數 BZD 類、zolpidem |

1. **施用第一、二級**：有刑責；初次施用通常先由法院裁定**觀察、勒戒**(最長 **2 個月**)，有繼續施用傾向者裁定**強制戒治**(**6 個月以上、最長 1 年**)
2. **施用第三、四級**：沒有刑罰，但有**罰鍰**並須參加**毒品危害講習**
3. 醫療用的管制藥品(嗎啡、美沙冬、BZD)另依**管制藥品管理條例**分級管理，和「毒品」是不同的法律概念
4. 毒品分級每 3 個月由法務部與衛福部共同審議，會隨新興物質調整
5. 同一物質的兩種分級可能不同：例如**依托咪酯**在管制藥品(醫療用)列**第四級**，作為毒品則自 2026-06-27 起升列**第一級**；一粒眠在 2010 年已由第四級改列第三級(食藥署管制藥品分級修正摘要)，舊資料寫第四級是過時的

## 各類物質的中毒與戒斷 {#substances}

### 中樞神經抑制劑：鴉片類 {#opioids}

| | 表現 |
|---|---|
| **中毒** | 欣快感、嗜睡到**昏迷**、**針狀瞳孔**、**呼吸抑制**、**心跳變慢**、低血壓、便秘 |
| **戒斷** | 渴藥、不安、**打呵欠**、**流淚流鼻水**、**瞳孔放大**、**起雞皮疙瘩**、出汗、**腹瀉**、腹痛、噁心嘔吐、**肌肉與骨頭痠痛**、失眠、發燒 |
| **時間** | 短效的海洛因 6–12 小時出現戒斷、強烈但較短；美沙冬較晚出現、較輕但拖較久 |

1. 過量處理：維持呼吸道與通氣、給 **naloxone**，要持續觀察再次呼吸抑制(見 [[opioids#toxicity]])
2. 戒斷**不會致命**(和酒精、鎮靜安眠藥戒斷不同)，但很痛苦，是再用的主要原因
3. **注射**使用：HIV、B 型與 C 型肝炎、心內膜炎、蜂窩性組織炎；減害與美沙冬維持治療見 [[addiction-treatment-drugs#methadone]]
4. 瞳孔兩側等大且很小(< 2 mm)的昏迷病人，要想到**鴉片類**或**有機磷**中毒

### 中樞神經抑制劑：鎮靜安眠藥 {#sedatives}

1. BZD、Z 類安眠藥、巴比妥；FM2 曾被用在約會強暴
2. 中毒：嗜睡、口齒不清、步態不穩、呼吸抑制(合併酒精或鴉片類最危險)
3. 戒斷：焦慮、失眠、顫抖，嚴重時**痙攣與譫妄**，**可能致命** → 要**逐步減量**(見 [[anxiolytics-hypnotics#withdrawal]])

### 中樞神經興奮劑 {#stimulants}

| 物質 | 中毒 | 戒斷與長期 |
|---|---|---|
| **安非他命**(安公子、冰塊) | 精力旺盛、話多、失眠、食慾差、**心跳快、血壓高、瞳孔放大**、高熱、**被害妄想與幻覺**(類似思覺失調症)、暴力 | **全身耗竭虛脫**、**嗜睡**、食慾增加、**憂鬱沮喪**、自殺風險；長期體重減輕、牙齒損壞 |
| **古柯鹼** | 同上，強烈血管收縮 → **心肌梗塞、中風**、心律不整 | 戒斷像安非他命；**鼻吸**造成**鼻中膈穿孔**，注射造成感染 |
| **MDMA(搖頭丸)** | 結構類似安非他命；促進**血清素**釋放並抑制再回收；親密感、知覺增強；**高熱**、脫水或喝太多水造成**低血鈉**、**橫紋肌溶解**、**急性腎衰竭** | 情緒低落、記憶受損 |

1. 興奮劑本身生理戒斷較輕，但**心理依賴**強；在常見成癮物質中，安非他命的身體依賴性比咖啡因、LSD、大麻高
2. 急性期處理：**維持生命徵象**、降溫、處理激躁與精神病症狀(BZD、抗精神病藥)；舊教材寫可**酸化尿液**(維生素 C)加速安非他命排出
3. 醫療用興奮劑(methylphenidate)見 [[cns-stimulants]]

### 解離性麻醉藥：K 他命與 PCP {#dissociatives}

1. **K 他命**(愷他命、ketamine)：**NMDA 受體拮抗劑**，醫學上用於**麻醉**；台灣列**第三級毒品**
   1. 中毒：解離感(靈魂出竅)、幻覺、**心跳快、血壓高**、**眼球震顫**、震顫、噁心嘔吐、動作協調變差、視覺模糊
   2. 長期：**慢性間質性(潰瘍性)膀胱炎**：**頻尿、夜尿**、尿急、血尿、膀胱萎縮；認知與記憶受損；鼻吸傷害鼻黏膜
   3. 戒斷症狀不明顯，但心理依賴強
2. **PCP(天使塵)**：作用與 ketamine **相似**，激躁、暴力、眼球震顫、高血壓

### 迷幻劑與大麻 {#hallucinogens}

| 物質 | 作用 | 表現 |
|---|---|---|
| **LSD**(搖腳丸) | 作用在**血清素(5-HT2A)受體** | 視幻覺、知覺扭曲、聯覺、瞳孔放大；「倒敘」(停用後再現知覺經驗)；生理依賴低 |
| **大麻**(THC) | 結合 **CB1 大麻素受體** | 放鬆、時間感改變、**結膜充血**、食慾增加、口乾、心跳快；長期**動機缺乏**、記憶變差、誘發精神病 |

### 新興影響精神物質(NPS) {#nps}

1. 合成的新物質，結構一直改，常偽裝成**咖啡包、奶茶包、果凍、糖果、電子煙油**
2. 常在**派對**使用，一包內常**混合多種成分**，劑量不明，容易中毒或死亡
3. **不是天然的**，而且**不容易被一般檢驗檢出**
4. **依托咪酯**(etomidate，麻醉誘導藥)被做成「**喪屍煙彈**」電子煙油，使用後可能出現不自主動作、意識改變；台灣 **2026-06-27 起升列第一級毒品**

### 其他成癮行為 {#behavioral-addictions}

1. **嗜賭症(賭博障礙症)**：DSM-5 唯一列入「物質相關及成癮障礙症」的行為成癮；越賭越大、想停不下來、說謊借錢、追回損失
2. **網路遊戲障礙**：DSM-5 列為需要進一步研究的狀況；社區宣導屬一級預防(見 [[community-mental-health#prevention-levels]])

## 治療 {#treatment}

### 治療階段 {#treatment-phases}

| 階段 | 目標與內容 |
|---|---|
| **急性解毒(戒斷期)** | 安全度過中毒與戒斷：監測生命徵象、處理戒斷症狀與合併症、營養與水分電解質 |
| **復健期** | 心理社會治療、建立新的生活型態與支持系統、職業復健 |
| **預防復發(後續追蹤)** | 辨識**高危險情境**與誘因、因應渴求、定期門診諮商、自助團體；以**門診與社區**為主 |

1. **藥物**：鴉片類用美沙冬或丁基原啡因維持治療、naltrexone；酒癮用 disulfiram、naltrexone、acamprosate(見 [[addiction-treatment-drugs]])
2. 物質成癮治療要**藥物與心理復健並重**，單靠其中一種效果有限
3. 是**慢性、會復發**的疾病，需要**長期**努力；復發不等於失敗，而是調整治療的機會

### 心理社會治療 {#psychosocial}

1. **動機式晤談(MI)**
   1. 以病人為中心，**表達同理**、**發展矛盾**(現在的行為和目標之間的落差)、**與抗拒同行**(不爭辯)、**支持自我效能**
   2. **不是直接面質**，面質容易引發防衛與抗拒
2. **改變階段**：懵懂期(沒意識到問題) → 沉思期(矛盾) → 準備期 → 行動期 → 維持期，可能復發再循環；依階段給予不同介入
3. **認知行為治療與預防復發訓練**：辨識誘因、因應渴求、拒絕技巧
4. **家庭治療**：成癮常與家庭互動有關，評估家庭問題、澄清成員的角色、期待、責任與感受
5. **團體與自助團體**：NA(匿名戒毒會)、AA(匿名戒酒會)、治療性社區
6. 精神動力心理治療多在**恢復期**進行，疏導內心問題、以健康方式表達憤怒

### 減害 {#harm-reduction}

1. 在病人還無法立刻完全停用時，先**降低死亡、感染與犯罪**，再把病人帶進治療
2. 台灣 2005 年起的藥癮愛滋減害計畫：**衛教諮詢、清潔針具、美沙冬替代療法**，藥癮者 HIV 新增數大幅下降(見 [[addiction-treatment-drugs#methadone-taiwan]])

## 護理 {#nursing}

### 評估 {#assessment}

1. 使用的物質、途徑、量、頻率、最後一次使用時間、戒斷史
2. **生命徵象**、意識、瞳孔、戒斷症狀、營養與感染(注射部位、肝炎、HIV)
3. 心理：防衛機轉(**否認、合理化、投射**)、情緒、自殺風險、共病
4. 社會：家庭、工作、法律問題、支持系統
5. **護理師的自我覺察**：先覺察自己對成癮行為的價值觀、態度與感受，避免偏見影響關係

### 照護原則 {#nursing-principles}

1. **態度**
   1. **中立、接納、不批判**；不譴責使用行為
   2. 協助病人了解並接納**成癮是一種疾病**，需要長期治療
   3. 物質使用**常合併道德與法律問題**，更要保持專業
2. **生理**
   1. **監測生命徵象與戒斷症狀**；急性中毒時**維持生命徵象穩定最優先**
   2. 提供**安全的環境**(預防跌倒、痙攣、自傷，防止物質帶入)
   3. 維持**營養、水分與電解質**
   4. **鼓勵病人自我照顧**，不要什麼都替他做
3. **心理**
   1. 面對**否認**時，不鼓勵逃避，協助病人覺察問題、處理內在衝突
   2. 出現**妄想**時，**增加現實感**，不與病人爭辯內容，同理他的害怕
   3. **操縱或暴力行為**：一致的規則、**適當設限**
   4. 核心議題是病人**對問題的覺察能力**；一起討論可行的戒除方法、訂定目標並評值
4. **社會與追蹤**
   1. 家屬參與治療與支持團體
   2. 出院後定期門診諮商、參加治療與自助團體、建立健康的生活型態與調適方式
   3. 追蹤輔導以**門診與社區**為主，不是以住院為主

### 照護分期 {#nursing-phases}

國考書常用的四期分法：

| 分期 | 重點 |
|---|---|
| **接觸期** | 建立**治療性關係**，同時協助病人調整生活作息、處理戒斷 |
| **說服期** | 用**動機式晤談**提高改變動機，不用強迫式面質 |
| **積極治療期** | 心理治療、家庭治療、學習因應技巧 |
| **預防再濫用期** | **加強行為改變**、確認**危險因子**、建立預防措施與支持系統 |
