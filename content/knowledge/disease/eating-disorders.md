**飲食障礙症**是以**異常的進食行為**與**對體重、體型的過度在意**為核心的疾病，常在**青春期**發病，女性較多。神經性厭食症是精神疾病中**死亡率最高**的之一，死因包括營養不良的併發症與自殺。這一頁比較**厭食症與暴食症**，並整理急性期的營養照護與行為約定。認知扭曲見 [[individual-cognitive-behavioral-therapy#cognitive-distortions]]，抗憂鬱藥見 [[antidepressants]]

## 重點摘要 {#summary}

- **厭食症**：限制熱量使**體重顯著過低**、**強烈害怕變胖**、**身體心像扭曲**（很瘦仍覺得胖）；分**限制型**與**嗜食清除型**
- **暴食症**：反覆**短時間吃下大量食物且失控**，加上**不當補償行為**（催吐、瀉劑、利尿劑、禁食、過度運動），**每週至少 1 次、持續 3 個月**；體重多在正常範圍
- 身體表徵：**無月經**、**便秘**、怕冷四肢冰冷、低血壓心搏過慢、胎毛；催吐者有**低血鉀**、牙齒侵蝕、腮腺腫大、手背繭
- 急性期：先**穩定生命徵象與營養**，訂**飲食行為約定**、在公共區域進食、**監測餐後**、**防止過度運動**；體重**循序漸進**增加，預防**再餵食症候群**
- 治療：營養重建＋**認知行為治療**＋**家庭治療**（青少年）；**SSRI** 用於暴食症與共病憂鬱；最常見的共病是**憂鬱症**

### 國考常考點 {#exam-points}

- 厭食症**好發青少女與年輕女性**，不是停經後婦女；自覺體重過重、操控食物、**停經**；**便秘**而非腹瀉；**不會**經血過多
- 厭食症**不是**「自覺太瘦」；BMI **小於 16** 已屬**重度以上**的過輕（DSM-5-TR：15–15.99 重度、小於 15 極重度），不是正常
- 厭食症分**限制型**與**嗜食／清除型**；清除行為包含**瀉劑**與**自我催吐**
- 暴食症診斷是**每週至少一次、持續 3 個月**，**不是一個月**；禁食與過度運動也是補償行為
- 最常見共病是**憂鬱症**，不是思覺失調症；厭食症**不用 haloperidol** 當主要治療；暴食症可用 **imipramine** 或 SSRI
- 急性期第一週首要措施：**建立飲食行為約定**（不是先做精神動力分析、認知或家庭治療）
- 行為約定：**體重由護理人員固定時間測量**、**在公共區域進食**、**防止過度運動**、不可把食物分給別人
- 營養復健：**每週增加 3 公斤或 3–5 公斤都太快**；過度餵食造成**心血管負擔過重**（再餵食症候群）；監測**餐後**而不是只看到開始吃
- 「上個月拉鍊還拉得上，今天拉不上表示變胖了」是**客觀觀察**，**不是**認知扭曲；「吃一次麵包變胖就嚴禁所有碳水化合物」是**過度推論**
- 青少年厭食症的護理：**行為契約**與病人討論營養目標，並轉介**家庭心理諮商**

## 疾病比較 {#comparison}

| 項目 | 神經性厭食症 | 神經性暴食症 | 嗜食症 |
|---|---|---|---|
| 核心 | **限制熱量**，體重顯著過低，**害怕變胖**，身體心像扭曲 | 反覆暴食加**不當補償行為** | 反覆暴食，**沒有**規律的補償行為 |
| 體重 | **顯著過低** | 多為**正常**或略高 | 常過重或肥胖 |
| 亞型或頻率 | **限制型**、**嗜食清除型** | 暴食與補償**每週至少 1 次，持續 3 個月** | 每週至少 1 次，持續 3 個月 |
| 病識感 | 常**否認**生病，抗拒治療 | 對暴食感到羞恥，較願意求助 | 羞恥、自責 |
| 好發 | 青少年與年輕女性 | 青少年晚期與年輕女性 | 成人較多 |

1. 暴食的定義：在一段時間內（例如 2 小時）吃下明顯多於一般人的量，並**覺得無法控制**吃什麼或吃多少
2. 厭食症的嚴重度以成人 BMI 分級：**輕度 ≥ 17、中度 16–16.99、重度 15–15.99、極重度 < 15**；兒童與青少年用 BMI 百分位
3. BMI 小於 18.5 即為過輕

## 臨床表現與身體併發症 {#manifestations}

### 行為與心理 {#behavior}

1. 對食物過度關注：蒐集食譜、計算熱量、把食物切得很碎、**玩弄食物**、替別人煮飯自己卻不吃
2. 隱藏或丟棄食物、穿寬鬆衣服掩飾體型、頻繁量體重或照鏡子
3. **過度運動**、催吐、使用瀉劑、利尿劑或減肥藥
4. 自我評價**過度受體重與體型影響**
5. 常見的認知扭曲
   1. 二分法：「不是完美的瘦就是失敗」
   2. 過度推論：「吃一次麵包變胖，所以要嚴禁所有碳水化合物」
   3. 災難化：「現在增加 1 公斤，以後會一直胖下去」
   4. 個人化：「別人在看我，表示我該減肥了」
   5. 控制：「我唯一能控制的就是體重」
6. 常用的防衛機轉：**否認**（否認瘦與生病）、**反向**（對母親的怨恨表現為讚美），見 [[psychodynamic-theories#by-disorder]]

### 身體併發症 {#complications}

| 系統 | 厭食症（飢餓） | 暴食症（清除行為） |
|---|---|---|
| 心血管 | **心搏過慢**、低血壓、心律不整、心臟萎縮 | **低血鉀**造成心律不整 |
| 內分泌與生殖 | **無月經**（下視丘－腦下垂體－性腺軸受抑制）、骨質疏鬆 | 月經不規則 |
| 體溫與皮膚 | **低體溫**、**怕冷**、四肢冰冷、皮膚乾燥、**胎毛** | 手背因催吐形成的繭（羅素徵象） |
| 腸胃 | 胃排空延遲、**便秘** | **牙齒琺瑯質侵蝕**、**腮腺腫大**、食道炎、食道撕裂 |
| 電解質與代謝 | 低血糖、低血磷 | **低血鉀**、代謝性鹼中毒（催吐）、脫水 |
| 血液與其他 | 貧血、白血球減少、水腫 | — |

## 病因 {#etiology}

1. **生物**：遺傳、血清素與多巴胺調節、下視丘功能
2. **心理**：完美主義、低自尊、對控制的需求、強迫特質；**多重因素**造成，不是單一原因
3. **家庭**：過度保護、過度涉入、衝突、對外表與成就的高期待；家庭變故（例如父母離異）可能是促發因素
4. **社會文化**：媒體把瘦與美麗成功連結、特定運動（芭蕾、體操）與職業
5. 共病：**憂鬱症**最常見，其次是焦慮、強迫症、物質使用與人格障礙；**自殺**風險高

## 治療 {#treatment}

1. **住院的時機**：生命徵象不穩（心搏過慢、低血壓、低體溫）、嚴重電解質異常、BMI 極低或體重快速下降、昏厥、拒絕進食、自殺風險
2. **營養重建**
   1. 由少量開始、**循序漸進**增加熱量
   2. 體重增加速度要適中：**門診每週 0.5–1 公斤**、**住院可達每週 1.5 公斤**；熱量從每公斤 **30–40 大卡**開始逐步增加，最後可達 70–100 大卡（臺北聯醫營養部）；每週 3 公斤以上**太快**
3. **再餵食症候群**
   1. 長期飢餓後重新餵食，胰島素上升使**磷、鉀、鎂**移入細胞內，血中濃度驟降，並有體液滯留
   2. 後果：**心臟負擔過重**、心律不整、心衰竭、呼吸衰竭、抽搐，嚴重可致死
   3. 高危險：**BMI < 16**、3–6 個月內體重下降超過 15%、**10 天以上幾乎沒有進食**、餵食前鉀磷鎂已偏低(NICE)
   4. 預防：低熱量起始、**監測電解質**（特別是**血磷**）與心臟、補充 thiamine 與電解質
4. **心理治療**
   1. **認知行為治療**：修正對體重與體型的扭曲認知
   2. **家庭治療**：兒童與青少年厭食症的重要治療
   3. **行為治療**：飲食行為約定、增重的獎勵（例如增加活動或會客的權利）
   4. 深層的精神動力治療與認知、家庭治療，要等**生命徵象與營養穩定**後才進行
5. **藥物**
   1. **暴食症**：**SSRI**(fluoxetine)或 TCA(imipramine)可減少暴食與催吐，見 [[antidepressants]]
   2. **厭食症**：沒有藥物能單獨治療，SSRI 用於共病憂鬱、焦慮或強迫；**haloperidol 不是**常用治療

## 護理 {#nursing}

### 急性期的首要措施 {#acute-nursing}

1. **安全與生命徵象**：監測心跳、血壓、體溫、電解質、輸入輸出量
2. **建立飲食行為約定**（第一週的首要措施），與病人**共同討論**營養攝取目標，增加參與感與遵從性
3. 約定內容
   1. **體重由護理人員**在**固定時間**測量（例如清晨排尿後、穿同樣衣服），不由病人決定
   2. 在**公共區域**、在護理人員觀察下進食，**限定用餐時間**
   3. 餐後**觀察至少 1 小時**，必要時限制如廁，防止催吐
   4. **防止過度運動**
   5. 不可把食物分給別人、藏食物
   6. 達到目標體重給予獎勵（增加活動、會客、外出）
4. 處理拒食時態度**溫和而堅定**，不要與病人爭辯食物或體重，也不要威脅

### 長期照護 {#long-term-nursing}

1. 建立信任的治療性關係，關心病人的感受，而不是只談體重與食物
2. 協助辨識與修正**認知扭曲**，提升自尊，發展體重以外的自我價值
3. 教導以語言表達情緒，找出替代的因應方式
4. 營養衛教，逐步恢復正常進食模式
5. 邀請**家人**參與，並轉介**家庭治療**；家庭衝突常與發病有關
6. 評估**憂鬱與自殺**風險
7. 出院後持續追蹤，注意復發的徵象
