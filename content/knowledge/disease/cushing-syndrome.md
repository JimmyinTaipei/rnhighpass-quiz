**庫欣氏症候群**是身體長期暴露在過多**皮質醇**（糖皮質素）下的表現，最常見的是長期服用類固醇；**庫欣氏病**專指腦下垂體 ACTH 腺瘤造成的那一種。皮質醇的正常作用見 [[adrenal-glands#cortisol]]，腦下垂體腺瘤與經蝶骨手術見 [[pituitary-disorders]]

## 重點摘要 {#summary}

- 原因
   1. **外源性**（醫源性）：長期**類固醇藥物**，最常見；ACTH 被抑制、腎上腺萎縮
   2. **ACTH 依賴性**：**腦下垂體 ACTH 腺瘤**（**庫欣氏病**，內生性最常見）→ **雙側腎上腺增生**；**異位 ACTH**（小細胞肺癌等）
   3. **ACTH 非依賴性**：**腎上腺皮質腺瘤**或癌自主分泌 → ACTH 被抑制、對側腎上腺萎縮
- 表現：**月亮臉**、**水牛肩**、**向心性肥胖**而**四肢細**；**皮膚變薄**、**紫紋**、易瘀青；肌肉流失無力；**高血糖**；**高血壓**、**水腫**；**低血鉀性鹼中毒**；**骨質疏鬆**；**易感染**、**傷口癒合差**；女性**多毛**、痤瘡、月經異常；情緒不穩、失眠、憂鬱或欣快
- 檢查：**24 小時尿液游離皮質醇**、**深夜唾液皮質醇**、**地塞米松抑制試驗**（皮質醇無法被抑制）；確定後測 **ACTH** 找來源，再做影像
- 治療：減少或停用外源性類固醇（**慢慢減量**）；**經蝶骨手術**切除腦下垂體腺瘤；**腎上腺切除術**；不適合手術者用抑制皮質醇合成的藥
- 飲食：**高蛋白**、**高鉀**、**高鈣**與維生素 D、**低鈉**、**低熱量**、**低醣**
- 護理：預防**感染**與**跌倒骨折**、保護皮膚、監測血糖血壓體重、關心身體心像與情緒

### 國考常考點 {#exam-points}

- 表徵：**低血鉀性鹼中毒**；皮膚**變薄**（不是變厚）；體毛**增加**；糖質新生**增加**
- 機轉：肌肉無力 = **蛋白質分解**；高血糖 = 肝臟**糖質新生增加**、周邊**胰島素利用降低**；水腫與高血壓 = 鈉水滯留；免疫抑制 = **淋巴球下降**、白血球總數可上升
- **雙側腎上腺變大＋ACTH 上升** → **腦下垂體前葉腫瘤**；單側腺瘤時 ACTH 下降
- 診斷最具特異性：**24 小時尿液游離皮質醇**
- 飲食**錯誤**的是**低蛋白**（應高蛋白）
- 長期類固醇最可能的副作用：**高血糖**（不是低血鈉、高血鉀、低血壓）
- 長期 prednisolone：**飯後**或合併制酸劑服用、壓力時告知醫師加量、**漸進式停藥**；飲食**不是高醣**
- **糖皮質素不是**庫欣氏症候群的治療（它是原因）

## 原因與分類 {#causes}

| 類型 | 原因 | ACTH | 腎上腺 |
|---|---|---|---|
| **外源性**（最常見） | 長期口服、注射、大量吸入或外用類固醇 | **↓** | 萎縮 |
| ACTH 依賴性 | **腦下垂體 ACTH 腺瘤 = 庫欣氏病**（內生性最常見，多為女性） | **↑** | **雙側增生、變大** |
| | **異位 ACTH**：**小細胞肺癌**、類癌 | **↑↑** | 雙側增生；低血鉀常很明顯 |
| ACTH 非依賴性 | **腎上腺皮質腺瘤**、腎上腺皮質癌、雙側結節增生 | **↓** | 腫瘤側變大、**對側萎縮** |

- 名稱：**庫欣氏症候群**是所有皮質醇過多的統稱；**庫欣氏病**只指腦下垂體 ACTH 腺瘤
- 判斷層次的邏輯和其他軸相同：皮質醇高＋ACTH 高 → 問題在上游（腦下垂體或異位）；皮質醇高＋ACTH 低 → 問題在腎上腺或外來藥物（見 [[endocrine-overview#feedback]]）

## 表現與機轉 {#manifestations}

| 系統 | 表現 | 機轉 |
|---|---|---|
| 外觀與脂肪 | **月亮臉**、**水牛肩**（頸背部脂肪墊）、**向心性肥胖**、**四肢細瘦** | 脂肪重新分布 |
| 肌肉與皮膚 | **肌肉流失、近端無力**（起身困難）；**皮膚變薄**、**紫紋**（腹部、大腿）、**易瘀青**、傷口癒合差 | **蛋白質分解**；膠原合成減少 |
| 代謝 | **高血糖**、類固醇性糖尿病 | 肝臟**糖質新生增加**、周邊**胰島素利用降低** |
| 心血管與水鹽 | **高血壓**、**水腫**、**低血鉀**、**代謝性鹼中毒** | 大量皮質醇有礦物皮質素作用 → **保鈉排鉀排氫** |
| 骨骼 | **骨質疏鬆**、病理性骨折（脊椎壓迫性骨折）；兒童**生長遲緩** | 抑制成骨、減少腸道吸收鈣、增加尿鈣 |
| 免疫 | **易感染**、感染症狀不明顯（發燒與發炎反應被壓） | **淋巴球與嗜伊紅球下降**；嗜中性球釋出使**白血球總數上升** |
| 生殖與毛髮 | 女性**多毛**、痤瘡、**月經不規則**；性慾下降 | 腎上腺雄性素增加；抑制性腺軸 |
| 精神 | **情緒不穩**、易怒、失眠、憂鬱，或欣快、精神病症狀 | |
| 腸胃 | **消化性潰瘍**風險 | 胃酸增加、黏膜保護減少 |

- 色素沉著只見於 ACTH 很高時（異位 ACTH）；腎上腺腫瘤或外源性類固醇 ACTH 低，不會變黑

## 診斷 {#diagnosis}

1. **先問用藥**：口服、注射、吸入、外用類固醇，排除外源性(Endocrine Society 2008)
2. **篩檢**（以下擇二項，異常者再確認）
   1. **24 小時尿液游離皮質醇**(UFC)：反映一整天分泌總量；收集時第一次尿丟棄、之後全部收集，保存依檢驗室規定
   2. **深夜唾液皮質醇**：正常人午夜皮質醇最低，庫欣氏症候群失去日夜節律
   3. **1 mg 隔夜地塞米松抑制試驗**：前一晚 11 點左右口服 dexamethasone，隔天早上 8 點抽血；正常皮質醇被抑制，庫欣氏症候群**無法被抑制**
3. **找來源**：測血漿 **ACTH**
   1. ACTH 低 → 腎上腺 CT 或 MRI
   2. ACTH 高 → **蝶鞍 MRI**；必要時岩下竇採血，區分腦下垂體與異位
4. 其他檢驗：血糖、血鉀、白血球分類、骨密度

## 治療 {#treatment}

- **外源性**：在治療原疾病允許下**慢慢減量**，**不可突然停藥**（腎上腺萎縮，會腎上腺危象，見 [[adrenal-insufficiency#steroid-withdrawal]]）；可改隔日給藥
- **庫欣氏病**：**經蝶骨腦下垂體腺瘤切除術**為首選(Pituitary Society 2021)；術後照護見 [[pituitary-disorders#transsphenoidal-surgery]]；失敗者放射治療、藥物或雙側腎上腺切除
- **腎上腺腫瘤**：**腹腔鏡腎上腺切除術**
- **異位 ACTH**：切除原發腫瘤
- **藥物**（不適合手術或等待期間）：抑制皮質醇合成（ketoconazole、metyrapone、osilodrostat）、作用在腦下垂體（pasireotide、cabergoline）、阻斷受體(mifepristone)
- 手術成功後體內皮質醇驟降，殘餘的腎上腺被抑制很久，需**暫時補充類固醇**，可能長達數月到一年以上

## 護理 {#nursing}

1. **預防感染**：手部衛生、避免接觸感染者、注意不明顯的感染徵象（體溫可能不高）、傷口無菌照護
2. **皮膚**：皮膚薄易破，用軟毛巾、避免膠布直接貼皮膚、勤翻身、防碰撞瘀青
3. **防跌與骨折**：肌肉無力與骨質疏鬆，環境安全、協助活動、搬運輕柔
4. **監測**：**血糖**、**血壓**、**體重**與水腫、**血鉀**、輸入輸出量
5. **飲食**
   1. **高蛋白**：補充分解流失的肌肉蛋白
   2. **高鉀**：補低血鉀
   3. **高鈣**、維生素 D：預防骨質疏鬆
   4. **低鈉**：減少水腫與高血壓
   5. **低熱量**、**低醣**：控制體重與血糖
6. **身體心像與情緒**：說明外觀多數會隨治療改善；觀察情緒變化、憂鬱與自殺意念
7. 長期服類固醇者的衛教（飯後服、壓力時加量、不可自行停藥、隨身攜帶用藥卡），藥物細節見 [[corticosteroids#nursing]]

## 腎上腺切除術 {#adrenalectomy}

- 適應症：腎上腺皮質腺瘤或癌（庫欣氏症候群）、**醛固酮瘤**、**嗜鉻細胞瘤**（見 [[pheochromocytoma-aldosteronism]]）；多採**腹腔鏡**
- **術前**：控制血糖、血壓、血鉀；嗜鉻細胞瘤要先 α 阻斷
- **術後**
   1. **腎上腺功能不足**：皮質醇驟降 → **低血壓**、**低血鈉**、**高血鉀**、**低血糖**、虛弱、意識改變；依醫囑**靜脈類固醇**，之後改口服再慢慢減量
   2. 生命徵象與**每小時尿量**（<30 mL/小時異常）、輸液維持體液容積
   3. 出血、腸蠕動恢復、傷口感染（皮質醇高者癒合慢）
   4. **雙側**切除者需**終身**補充糖皮質素與礦物皮質素(fludrocortisone)，衛教壓力時加量
- 腎臟根除性切除術可能一併切除同側腎上腺，術後也要觀察腎上腺功能不足
