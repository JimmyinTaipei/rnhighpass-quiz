**慢性腎臟病**(CKD, chronic kidney disease)是腎臟慢慢、不可逆地失去功能。早期幾乎沒有症狀，等腎功能只剩 5–10% 時，水分與廢物排不出去，全身各系統都出問題，稱為**末期腎臟病**或**尿毒症**，需要透析或腎臟移植才能維持生命（《內外科護理學》下冊 p.814）。台灣透析發生率與盛行率居全球前段，及早篩檢與延緩惡化是護理重點。腎功能檢驗見 [[renal-function-tests]]，白蛋白尿見 [[uacr]]

## 重點摘要 {#summary}

- 定義(KDIGO, Kidney Disease: Improving Global Outcomes)：腎臟結構或功能異常 **> 3 個月**；**eGFR(estimated glomerular filtration rate) < 60 mL/min/1.73 m²** 或有**腎損傷標記**（白蛋白尿 ACR，albumin-to-creatinine ratio ≥ 30 mg/g、尿沉渣異常、影像或病理異常、腎移植史）
- 舊名「慢性腎衰竭」「慢性腎功能不全」定義不清，台灣腎臟醫學會建議改用「慢性腎臟病」
- 分期：G1 ≥ 90、G2 60–89、**G3a 45–59、G3b 30–44**、G4 15–29、**G5 < 15**；台灣把 1–3a 期稱**初期 CKD**、3b–5 期稱 **Pre-ESRD**
- 高危險群：**糖尿病、高血壓**、痛風（高尿酸）、心血管疾病、腎臟病家族史、65 歲以上、自體免疫疾病、長期吃止痛藥或不明藥物、抽菸、代謝症候群
- 台灣新發透析主因是**糖尿病**（2022 年 46.1%）；課本寫「原發性腎絲球腎炎最多」是較早的資料
- 末期表現：**高血鉀、代謝性酸中毒、體液過多與高血壓**、**貧血**（EPO，erythropoietin 不足）、**高血磷、低血鈣、次發性副甲狀腺功能亢進**、出血傾向、搔癢與尿毒霜、心包膜炎、尿毒性腦病變
- 治療：控制**血壓**與血糖、**ACEI(angiotensin-converting enzyme inhibitor)／ARB**(angiotensin II receptor blocker) 減少蛋白尿、SGLT2(sodium–glucose cotransporter 2) 抑制劑、矯正貧血與鈣磷、**低蛋白（高生物價）、足夠熱量、限鈉鉀磷**、避免腎毒性藥物
- 第 4 期轉介腎臟科、介紹透析方式與**通路**；第 5 期開始透析或移植

### 國考常考點 {#exam-points}

- GFR(glomerular filtration rate) 20 → **第 4 期**；eGFR 9.2 → **第 5 期**，下一步是**開始透析或腎移植**；GFR 15 → 介紹**透析治療通路**
- CKD 高危險群**不包括體重過輕**；**HDL(high-density lipoprotein) 高**不是危險因子（高血糖、高尿酸、高血壓才是）
- 預防：定期測**血壓、血糖、肌酸酐、蛋白尿**；不是少喝水、不是一般人都吃低蛋白、不是吃藥「改善」腎功能
- 國健署護腎「三少」是**少鹽、少油、少糖**，不是少熱量
- 典型合併症：貧血、胃腸出血、月經不規則、**副甲狀腺功能亢進**（不是低下）；表現有氮血症、高血脂、代謝性酸中毒，**血磷升高**（不是低血磷）
- 血壓目標：國考答案 **130/85 以下**（較舊）；課本 < 130/80，蛋白尿 > 1 g/天 < 125/75；KDIGO 2021 可耐受時收縮壓 < 120（見下方）
- ACEI：減少蛋白尿、乾咳、低血壓，會造成**高血鉀**（不是低血鉀）
- 腎性貧血：**EPO 缺乏**、紅血球壽命縮短；**鐵劑與葉酸不會刺激造血**（是原料）；靜脈鐵劑可減少 EPO 用量；用 EPO 前鐵蛋白 > 200、運鐵蛋白飽和度 > 20%、無控制不良高血壓；**Hct 不是「至少要 35%」**
- 血液透析病人的**葉酸、維生素 C** 要在**透析結束後**吃（水溶性，會被透析移除）
- 飲食：**低蛋白、以高生物價為主**（蛋、奶、魚、肉）、足夠熱量讓蛋白質不被當熱量燒掉；可用冬粉、米粉、米苔目等低氮澱粉補熱量；**麵筋、豆類、堅果是低生物價且高磷高鉀**，不宜多吃；不用肉汁高湯拌飯；**不生吃蔬菜**（先燙過去鉀）；不用含鉀低鈉鹽；慢性腎衰竭**不是**低油飲食對象
- 低蛋白飲食適用：**尿毒症、肝昏迷**；高血鉀預防：避免熱量不足或長期飢餓（組織分解釋出鉀）、不喝雞精、不吃水果乾、不用低鈉鹽
- 兒童慢性腎衰竭：**不可**給高鉀飲食（香蕉、橘子）；要注意出血、搔癢、貧血
- 多重共病腎衰竭病人用藥：胰島素可能要**減量**、注意毛地黃中毒、避免含鎂制酸劑；**鐵劑不可和制酸劑併用**（降低吸收）

## 相關生理 {#physiology}

- 腎元一旦壞掉不會再生；剩下的腎元代償 → 腎絲球內壓力上升 → 腎絲球肥大、硬化 → 惡性循環（同上 p.816）
- 腎臟的內分泌功能（腎素、EPO、活化維生素 D）見 [[kidney-urinary-physiology#endocrine-homeostasis]]

## 病因與病理生理 {#pathophysiology}

### 原因與危險因子 {#risk-factors}

- 主要原因：**糖尿病腎病變**、**高血壓腎硬化**、慢性腎絲球腎炎、多囊腎、反覆泌尿道感染與阻塞、SLE、痛風性腎病、止痛劑腎病變
- 台灣：2022 年新發透析病人主診斷**糖尿病 46.1%**；透析發生率每百萬人口 536 人、盛行率每百萬人口 3,806 人（2024 台灣腎病年報）
- 高危險群（應篩檢）：糖尿病、高血壓、**高尿酸或痛風**、心血管疾病、腎臟病家族史、**65 歲以上**、自體免疫疾病、長期使用 NSAIDs(nonsteroidal anti-inflammatory drugs)、鋰鹽或來源不明藥物、惡性腫瘤（多發性骨髓瘤）、抽菸、代謝症候群（同上 p.814）

## 分類與診斷 {#classification}

### 定義與分期 {#staging}

| 期別 | eGFR(mL/min/1.73 m²) | 描述 | 課本的護理指導重點（表 19-16） | 追蹤 |
|---|---|---|---|---|
| **1** | ≥ 90 | 腎功能正常但有腎損傷（蛋白尿、血尿） | 認識腎臟、常見檢查、生活保健 | 每半年 |
| **2** | 60–89 | 輕度下降＋腎損傷 | 分期與危險因子、血壓血脂血糖 | |
| **3a** | 45–59 | 中度下降 | 慢性腎衰竭症狀、惡化因子；**開始介紹血液透析、腹膜透析** | 每 3 個月 |
| **3b** | 30–44 | | 同上；貧血、鈣磷異常開始出現 | |
| **4** | 15–29 | 重度下降 | 貧血治療（EPO、鐵劑）、預防感染；**介紹透析通路**（瘻管、導管） | |
| **5** | **< 15** | 末期腎臟病 | 透析或換腎準備、通路照護、緊急就醫時機 | 每 2–4 週 |

- 第 1、2 期一定要有**腎損傷證據**才算 CKD；**eGFR < 60 持續 3 個月以上**就算第 3 期以上
- KDIGO 的完整分類是 **CGA**：病因(Cause)＋ GFR 分期(G1–G5)＋白蛋白尿分期（**A1 < 30、A2 30–300、A3 > 300 mg/g**），兩者合起來判斷進展風險（見 [[uacr]]）
- 台灣分工：1–3a 期屬「初期慢性腎臟病照護」、3b–5 期屬健保「Pre-ESRD 照護與衛教計畫」（國健署資料集；計畫收案條件依健保署公告）
- 篩檢：台灣腎臟醫學會建議先看尿液常規的**蛋白尿與血尿**，再以血清肌酸酐算 eGFR；ACR 或 PCR(protein-to-creatinine ratio) 也可用（同上 p.814）；計算公式見 [[renal-function-tests#egfr]]
- 超音波：慢性腎臟病**腎臟縮小**（糖尿病、多囊腎例外）；急性腎損傷腎臟正常或變大

### 末期腎臟病的全身表現 {#manifestations}

依《內外科護理學》下冊表 19-17(p.817–818)整理

| 系統 | 表現 | 原因 |
|---|---|---|
| 體液電解質酸鹼 | **高血鉀**、低或高血鈉、**高血磷、低血鈣**、**代謝性酸中毒** | 排鉀排磷排酸能力下降 |
| 心血管 | **高血壓**（早期就常見）、水腫、心衰竭、**心包膜炎**（摩擦音、胸痛） | 鈉水滯留、腎素增加、尿毒素刺激 |
| 血液 | **貧血**、**出血傾向**（血小板數量正常但功能差：鼻出血、瘀斑、腸胃出血） | **EPO 減少**、尿毒素抑制骨髓並縮短紅血球壽命 |
| 免疫 | 容易感染 | 白血球與細胞免疫功能下降 |
| 呼吸 | Kussmaul 呼吸、肺水腫、肋膜炎、尿毒性肺 | 代謝性酸中毒代償、體液過多 |
| 腸胃 | 噁心嘔吐、厭食、**口中金屬味、尿毒性口臭**、口炎、消化性潰瘍與出血、尿毒性腸炎、便秘 | 尿素分解成氨、PTH(parathyroid hormone) 增加胃酸、限水與磷結合劑 |
| 神經 | **尿毒性腦病變**（警覺度下降最早）、周邊神經病變（下肢、不寧腿）、撲翼樣震顫、抽搐 | 尿毒素、電解質異常 |
| 泌尿 | 早期**多尿、夜尿**（不能濃縮）；晚期少尿無尿；**尿比重固定 1.010**、蛋白尿 | 腎元損傷 |
| 骨骼 | **腎性骨病變**：骨痛、自發性骨折、軟骨症、骨質疏鬆；**轉移性鈣化** | 高磷低鈣 → **次發性副甲狀腺功能亢進**、活性維生素 D 減少 |
| 皮膚 | 黃灰或蒼白、**搔癢**、**尿毒霜**、乾燥、瘀斑、指甲變化 | 尿色素沉積、貧血、鈣磷沉積 |
| 生殖 | 性慾減退、陽萎、月經減少或停經 | 荷爾蒙下降 |
| 代謝 | 高血脂、胰島素需要量減少 | 胰島素由腎臟代謝減少 |

- 鈣磷與副甲狀腺：腎臟排不出磷 → **血磷上升**、血鈣下降；腎臟不能活化維生素 D → 腸道吸收鈣減少；兩者都刺激副甲狀腺 → **次發性副甲狀腺功能亢進** → 骨頭的鈣被拉出來（見 [[calcium-phosphate]]、[[parathyroid-disorders]]）

## 治療策略 {#treatment}

### 延緩惡化 {#slow-progression}

| 項目 | 做法 |
|---|---|
| **血壓** | 課本：< 130/80 mmHg，蛋白尿 > 1 g/天 < 125/75(p.821)；KDIGO 2021 血壓指引：可耐受時收縮壓 **< 120 mmHg**（標準化診間量測）；國考較舊答案 130/85 以下 |
| **ACEI／ARB** | 首選降壓藥：放鬆出球小動脈、降低腎絲球內壓、**減少蛋白尿**；副作用**高血鉀**、乾咳(ACEI)、低血壓、開始時肌酸酐輕度上升；見 [[ace-inhibitors]]、[[arb]] |
| **SGLT2 抑制劑** | KDIGO 2024 建議用於多數 CKD（含非糖尿病）以延緩進展與減少心衰竭；見 [[sglt2-inhibitors]] |
| 血糖 | 糖尿病病人控制 HbA1c；腎功能差時胰島素需要量下降、metformin 依 eGFR 調整 |
| 避免腎毒性 | NSAIDs、aminoglycoside、顯影劑、來源不明中草藥；依 eGFR 調整藥物劑量 |
| 其他 | 戒菸、控制血脂與尿酸、治療代謝性酸中毒（碳酸氫鈉） |

::questions{ids="106-2_MS_079,107-1_MS_065,112-2_MS_059"}

### 腎性貧血 {#anemia}

- 原因：**EPO 不足**（主因）、尿毒素抑制骨髓、紅血球壽命縮短、缺鐵、出血、透析流失
- 治療原則(KDIGO 2026 Anemia in CKD)
   1. 先找並矯正**缺鐵**等可逆原因；血液透析病人優先**靜脈鐵劑**（可減少 EPO 用量）
   2. **紅血球生成刺激劑**（ESA，erythropoiesis-stimulating agent，如 EPO）：透析病人 Hb 約 9–10 g/dL 考慮開始；成人用 ESA 時 **Hb 不要超過 11.5 g/dL**，不追求正常值（過高增加高血壓、血栓與心血管事件）
   3. 一線用 ESA，HIF(hypoxia-inducible factor)-PHI 類口服藥為替代選擇
- 課本：EPO 或鐵劑讓 Hct 維持 33–36%(p.821–822)；國考：使用 EPO 前**鐵蛋白 > 200 ng/mL、運鐵蛋白飽和度 > 20%、無控制不良的高血壓**，「Hct 至少要達到 35%」是錯的
- **鐵劑、葉酸是造血原料**，本身不刺激骨髓；鐵劑不要和制酸劑一起吃
- **葉酸、維生素 B 群與 C 是水溶性**，會被透析移除 → **透析結束後**服用
- 鐵劑、EPO 等造血藥物見 [[hematinics#esa]] 與 [[hematinics#iron]]

::questions{ids="105-2_MS_063,106-2_MS_078,107-2_MS_066,111-1_MS_064"}

### 鈣磷與骨病變 {#mineral-bone}

- **限磷飲食**：少吃內臟、全穀、堅果、乳製品過量、可樂汽水、加工食品（含磷添加物）
- **磷結合劑**：**和餐一起吃**（在腸道抓住食物的磷）；碳酸鈣、醋酸鈣、sevelamer、lanthanum；含鋁的長期使用會鋁中毒；副作用便秘
- 依醫囑**活性維生素 D**、calcimimetic(cinacalcet)控制副甲狀腺素；課本：先把血磷降到 5.5 mg/dL 以下再補鈣(p.821)
- 藥物見 [[bone-calcium-drugs]]、[[calcium-phosphate]]

### 飲食 {#diet}

| 成分 | CKD 未透析 | 血液透析 | 腹膜透析 |
|---|---|---|---|
| 熱量 | 60 歲以下 35 kcal/kg、以上 30–35 | 同左 | 同左（透析液葡萄糖也算熱量） |
| **蛋白質** | **0.6–0.75 g/kg**（第 4 期起，50% 以上高生物價） | **1.2 g/kg** | **1.2–1.3 g/kg**（腹膜流失蛋白質） |
| 鉀 | 高血鉀時 1.5–2.5 g | 2–3 g | 3–4 g |
| 鈉 | 1–3 g | 2–3 g | 2–4 g |
| 磷 | 8–12 mg/kg | 800–1,200 mg | 800–1,200 mg |

依《內外科護理學》下冊表 19-18(p.823)整理

- 新舊說法：課本第 4 期起 0.6 g/kg；**KDIGO 2024** 建議 G3–G5 未透析成人蛋白質約 **0.8 g/kg/天**、避免 > 1.3 g/kg；實際由醫師與營養師依病人決定
- **高生物價蛋白**：蛋、牛奶、魚、雞、瘦肉（含必需胺基酸多、含氮廢物少）；**低生物價**：豆類、**麵筋**、堅果、五穀（且磷鉀較高）
- **足夠熱量**：熱量不夠身體會分解蛋白質（BUN，blood urea nitrogen 上升）與組織（釋出鉀）；可用**冬粉、米粉、米苔目、粄條**等低氮澱粉、油脂、糖補足 → 慢性腎衰竭**不需要**低油飲食
- 降鉀：蔬菜**先切後燙**、湯汁不喝、不用肉汁高湯拌飯；避免**生菜、精力湯、果乾**、楊桃、雞精、**低鈉鹽與薄鹽醬油**（以鉀取代鈉）
- 液體（未透析）：**前一天尿量 ＋ 約 500–800 mL**；透析病人兩次透析間體重增加控制在**乾體重 5% 以內**（詳見 [[dialysis-crrt#dry-weight]]）
- 低蛋白飲食適用：**尿毒症**、**肝昏迷**；燒傷、肺炎要高蛋白

### 腎臟替代療法 {#renal-replacement}

- 第 4 期開始衛教透析方式（血液透析、腹膜透析、腎移植、安寧緩和）並**提早建立通路**（動靜脈瘻管需數週成熟）
- 第 5 期或出現無法控制的高血鉀、體液過多、酸中毒、尿毒症狀時開始透析
- 透析與腎移植見 [[dialysis-crrt]]；2022 年台灣新發透析病人使用腹膜透析約 9.5%、盛行病人約 7.5%（2024 台灣腎病年報）

## 護理 {#nursing}

### 臨床護理 {#nursing-clinical}

- **體液過多**：每天同時間量體重（排尿後、進食前、同衣物同體重計）、輸入輸出量、血壓、呼吸音、水腫部位；口渴時含小冰塊、把水量平均分配到全天(p.823)
- **營養**：依表限制、少量多餐、營造用餐環境、補充水溶性維生素與維生素 D；不遵從時請營養師會診
- **皮膚搔癢**：溫水清潔、保濕潤膚、剪短指甲；控制血磷
- **出血**：觀察瘀斑、牙齦與腸胃出血；軟毛牙刷、避免肌肉注射
- **感染**：免疫力差，注意導管與瘻管傷口、呼吸道感染
- 藥物：避免含鎂制酸劑、注意毛地黃中毒（透析後低血鉀更易中毒）、胰島素可能要減量
- 心理：長期治療與飲食限制，鼓勵表達、家庭支持、病友團體

### 社區與居家 {#nursing-community}

- 篩檢對象：上方高危險群；健檢包含**血壓、血糖、血清肌酸酐(eGFR)與尿蛋白**；成人預防保健依年齡定期篩檢
- 衛教：國健署護腎「**三少**」：少鹽、少油、少糖；多喝水（未限水者）；不亂服藥、不吃來源不明草藥；控制三高；戒菸
- 一般民眾不需要刻意限水或吃低蛋白飲食

## 兒童 {#pediatric}

- 兒童常見原因：先天腎臟與泌尿道異常（發育不良、膀胱輸尿管逆流造成腎瘢痕）、腎絲球疾病
- 問題：生長遲緩（要注意熱量與活性維生素 D）、貧血、腎性骨病變、高血鉀、高血壓
- 護理：限鉀（**不可**給香蕉、橘子）、含鐵與葉酸食物、觀察出血與皮膚搔癢、學校生活與心理支持；腹膜透析在兒童常用
