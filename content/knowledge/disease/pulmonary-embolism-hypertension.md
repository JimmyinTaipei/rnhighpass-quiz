**肺栓塞**是栓子(大多是下肢深部靜脈的血栓)隨血流卡在肺動脈，造成「有通氣、沒血流」的無效腔與右心負荷；**肺水腫**是液體淹沒肺泡；**肺高壓**長期下來會讓右心衰竭，肺病造成的叫**肺心症**。血栓與栓塞的病理見 [[thrombosis-embolism-infarction]]，抗凝與溶栓藥見 [[anticoagulants]]、[[thrombolytics]]

## 重點摘要 {#summary}

- 肺栓塞來源多是**下肢深部靜脈血栓**；危險因子：**手術(尤其髖膝關節置換)**、久坐久臥、癌症、懷孕產後、雌激素、肥胖
- 表現：**突然呼吸困難**、**突然胸痛**(吸氣時痛)、呼吸與心跳加快、焦慮；大範圍時低血壓、休克、心跳停止
- 血氣：**低血氧＋呼吸性鹼中毒**；V/Q：**通氣足夠、血流受阻**
- 診斷：低可能性時 **D-dimer** 陰性可排除；確診用**電腦斷層肺血管攝影**
- **2026 AHA/ACC** 依臨床嚴重度分 **A–E**；ESC 2019 用高、中、低風險
- 治療：沒有禁忌就**立即抗凝**；長期首選**直接口服抗凝血劑(DOAC)**；需要注射時多用低分子量肝素；**持續低血壓(E 類)**考慮溶栓
- 預防：**避免久坐**、早期下床、腿部運動、彈性襪或間歇充氣加壓、藥物預防
- **肺心症**：COPD 等肺病 → 缺氧 → 肺血管收縮 → 肺高壓 → **右心衰竭**；長期氧療、**限鈉限水**、半坐臥

### 國考常考點 {#exam-points}

- 疑似肺栓塞最可能的症狀：**突然胸痛**(不是發燒、噘嘴式呼吸、泡沫痰)
- 全髖關節置換術後出現胸痛、呼吸短促、蒼白冰冷 → **肺栓塞**
- 肺栓塞的預防最重要：**避免久坐以預防深部靜脈血栓**
- Heparin 維持 aPTT 為正常值的 **1.5–2.5 倍**
- 肺栓塞的血氣：pH 上升、PaCO₂(Partial pressure of arterial carbon dioxide) 下降、**PaO₂(Partial pressure of arterial oxygen) 下降**(呼吸性鹼中毒＋低血氧)
- 肺栓塞造成的休克，國考答案是「心因性」，現行分類是**阻塞性休克**，見 [[edema-shock#shock-types]]
- 急性肺水腫的表徵：**端坐呼吸**、**粉紅色泡沫痰**(不是心跳變慢或高燒)
- 肺心症清除痰液：**不鼓勵攝取大量水分**(右心衰竭要限水)；深呼吸咳嗽、扣擊震顫、姿位引流、支氣管擴張劑可以
- 肺心症採坐臥式：橫膈下降、胸廓擴張、改善氧合；**不是**為了增加回心血量(坐起來回心血量減少)
- 肺心症出院：**回家仍要用氧氣**；減少水分與鹽分；漸進增加活動

## 肺栓塞 {#pulmonary-embolism}

### 危險因子與機轉 {#pe-risk}

1. 來源：大多數來自**下肢與骨盆的深部靜脈血栓**；血栓形成的三要素(血流停滯、內皮傷害、高凝血)見 [[thrombosis-embolism-infarction#venous-thrombosis]]
2. 危險因子
   1. **手術**(尤其**髖、膝關節置換**、骨盆與腹部大手術)、**創傷**、骨折
   2. **久坐久臥**、長途旅行、中風或癱瘓
   3. **癌症**與化學治療
   4. **懷孕與產後**、口服避孕藥與更年期荷爾蒙(雌激素)
   5. 肥胖、吸菸、高齡、過去曾有血栓、遺傳性易栓症、中心靜脈導管
3. 栓子以外的栓塞(脂肪、空氣、羊水)見 [[thrombosis-embolism-infarction#embolism]]
4. 機轉
   1. 肺動脈被堵住 → 該區**有通氣、沒有血流**(無效腔)，見 [[gas-exchange-transport#vq]]
   2. 血管收縮介質與缺氧 → 換氣過度 → **PaCO₂ 下降、呼吸性鹼中毒**，同時**低血氧**
   3. 大範圍阻塞 → 肺動脈壓急升 → **右心室擴大、衰竭** → 左心充填減少 → **低血壓、阻塞性休克**、無脈搏電氣活動

### 表現 {#pe-manifestations}

| 常見 | 嚴重時 |
|---|---|
| **突然呼吸困難**(最常見) | 低血壓、休克 |
| **突然胸痛**(肋膜痛：吸氣時加重) | 暈厥 |
| 呼吸加快、心跳加快 | 頸靜脈怒張(右心衰竭) |
| 焦慮、不安、有瀕死感 | 心跳停止(多為無脈搏電氣活動) |
| 咳嗽、少量咳血、低燒 | — |
| 單側小腿腫痛(深部靜脈血栓) | — |

- 術後病人突然喘、胸痛、蒼白冰冷 → 先想到肺栓塞
- 血氣：**低血氧＋呼吸性鹼中毒**，見 [[abg#oxygenation]]

### 診斷 {#pe-diagnosis}

1. 先依臨床評分估計可能性(例如 Wells 分數)
2. **D-dimer**：血栓分解產物；**陰性可排除**低或中等可能性的病人；陽性不一定是肺栓塞(手術、懷孕、癌症、高齡都會升高)
3. **電腦斷層肺血管攝影**(CTPA)：確診的主要檢查
4. **肺通氣灌流掃描**：不能打顯影劑(過敏、腎功能差)或懷孕時考慮
5. 下肢靜脈超音波：找深部靜脈血栓
6. 評估嚴重度：心臟超音波(右心室擴大)、肌鈣蛋白、BNP、血壓
7. 心電圖：最常見是**竇性心搏過速**；教科書提到的 S1Q3T3 並不常見

### 嚴重度分類 {#pe-classification}

| 2026 AHA/ACC 臨床分類 | 意思 | 大致對應 ESC 2019 |
|---|---|---|
| **A** | 沒有症狀、意外發現 | 低風險 |
| **B** | 有症狀、嚴重度分數低 | 低風險 |
| **C** | 有症狀、嚴重度分數高(可合併右心功能不全或生物標記上升) | 中風險 |
| **D** | 心肺衰竭將要發生(D1 暫時低血壓、D2 血壓正常但有組織灌流不足) | 中高風險 |
| **E** | **心肺衰竭**：持續低血壓、休克(E1)，頑固性休克或心跳停止(E2) | **高風險** |

2026 分類來源：[2026 AHA/ACC 急性肺栓塞指引](https://doi.org/10.1161/CIR.0000000000001415)(Circulation 2026；原文網站無法讀取，依多篇摘要交叉核對)；依使用者規則以 AHA 為主，ESC 2019 對照供參考

### 治療 {#pe-treatment}

1. **一般處置**：給氧(目標血氧)、半坐臥、心電與血氧監測；低血壓時小心輸液、必要時升壓劑
2. **抗凝**：沒有絕對禁忌就**立即開始**
   1. 口服長期治療：**直接口服抗凝血劑**(apixaban、rivaroxaban、edoxaban、dabigatran)優先於 warfarin(2026 AHA/ACC)
   2. 需要注射時：**低分子量肝素優先於傳統肝素**；頑固性休克或心跳停止(E2)兩者皆可
   3. 傳統肝素依 **aPTT 維持正常值 1.5–2.5 倍**調整，見 [[anticoagulants#iv-heparin]]
   4. A、B 類病情穩定者可在門診用 DOAC 治療；C–E 類住院
3. **血栓溶解**
   1. **E 類(持續低血壓、休克)**：全身性溶栓或導管、手術取栓
   2. D 類：病情可能惡化時考慮
   3. A、B、C1 類**不建議**常規溶栓(出血與顱內出血風險)
   4. 藥物與禁忌見 [[thrombolytics#pe]]
4. **下腔靜脈過濾器**：有血栓但**不能抗凝**的病人
5. 多專科**肺栓塞反應小組**(PERT)共同決策
6. 抗凝療程通常至少 3 個月，依原因是否可逆決定是否延長

### 護理與預防 {#pe-nursing}

1. 急性期
   1. 半坐臥、給氧、監測 SpO₂(Peripheral oxygen saturation)、呼吸、心跳、血壓、意識
   2. 安撫焦慮、減少耗氧
   3. 抗凝或溶栓期間觀察**出血**：牙齦、尿液、黑便、注射處、意識改變(顱內出血)
2. **預防深部靜脈血栓與肺栓塞**
   1. **避免久坐久站**：長途旅行每 1–2 小時起來走動、做足踝運動
   2. 術後**早期下床**、臥床時做**足踝幫浦運動**
   3. 依醫囑使用彈性襪、**間歇充氣加壓裝置**、低分子量肝素等藥物預防
   4. 適量水分避免脫水；但預防的關鍵是**活動**，不是每天喝 3,000 mL
   5. 戒菸、控制體重；有血栓病史者評估雌激素藥物
3. 深部靜脈血栓的完整護理在第 15 輪心血管補完

## 肺水腫 {#pulmonary-edema}

| | 心因性 | 非心因性 |
|---|---|---|
| 機轉 | 左心衰竭、二尖瓣疾病、輸液過量 → 肺微血管**靜水壓**上升 | 微血管**通透性**上升(ARDS)、復張性、高海拔、神經性 |
| 處置重點 | 利尿劑、硝酸鹽、降低前負荷 | 處理原因、PEEP(Positive end-expiratory pressure)、肺保護性通氣 |

- **表現**：急性嚴重呼吸困難、**端坐呼吸**、**粉紅色泡沫痰**、兩側爆裂音、焦慮、冒冷汗、低血氧
- **處置**：**坐起、雙腳下垂**(減少回心血量)、給氧或非侵襲性正壓呼吸器、依醫囑利尿劑與硝酸鹽；詳細見 [[heart-failure#acute-hf]]
- ARDS 的非心因性肺水腫見 [[ards-respiratory-failure#ards-pathophysiology]]；胸腔穿刺後的復張性肺水腫見 [[respiratory-assessment#thoracentesis]]

## 肺高壓與肺心症 {#pulmonary-hypertension}

1. **定義**：右心導管測得靜止時**平均肺動脈壓 > 20 mmHg**(2022 ESC/ERS；舊標準 ≥ 25 mmHg)(來源：[2022 ESC/ERS 肺高壓指引](https://doi.org/10.1093/eurheartj/ehac237))
2. **分類**(五大類)

| 類別 | 原因 |
|---|---|
| 1 肺動脈高血壓 | 原發性、遺傳、藥物、結締組織疾病、先天性心臟病 |
| 2 左心疾病 | 左心衰竭、瓣膜疾病(**最常見**) |
| 3 **肺病或缺氧** | **COPD**、肺纖維化、睡眠呼吸中止、高海拔 |
| 4 慢性血栓栓塞 | 肺栓塞後血栓沒有溶解 |
| 5 其他或多重原因 | 血液疾病、全身性疾病 |

3. **肺心症**：**肺部疾病**(第 3 類，最常見是 COPD)造成肺高壓 → **右心室肥厚、擴大、衰竭**
   1. 機轉：長期缺氧 → **低氧性肺血管收縮**、紅血球增多(血液變稠)、肺血管床被破壞，見 [[gas-exchange-transport#vq]]
   2. 表現：活動性呼吸困難、疲倦；右心衰竭：**頸靜脈怒張**、**下肢水腫**、**肝腫大**、腹水；第二心音肺動脈成分增強
4. **治療**
   1. 治療原本的肺病；**長期氧氣治療**(改善缺氧、降低肺血管阻力，見 [[copd#oxygen]])
   2. 利尿劑減輕水腫(注意低血鉀與代謝性鹼中毒)
   3. 第 1 類肺動脈高血壓才用專用藥物(例如內皮素受體拮抗劑、PDE5 抑制劑 sildenafil、前列環素)；第 4 類需抗凝，部分可手術取栓
5. **肺心症的護理**
   1. **坐臥式(半坐臥)**：橫膈下降、胸廓好擴張、改善氧合，同時**減少回心血量**減輕右心負擔
   2. 呼吸道清除：深呼吸咳嗽、扣擊震顫、姿位引流、支氣管擴張劑；**不鼓勵大量喝水**(右心衰竭要限水)，痰稠可用噴霧濕化
   3. **限制鈉與水分**、監測體重與水腫、出入量
   4. 出院：**居家氧氣要繼續用**；**漸進式增加活動**，活動中出現不適(心跳異常、胸痛、明顯喘)要停止休息
   5. 避免鎮靜安眠藥(抑制呼吸)、戒菸、預防感染(疫苗)
