兒童泌尿生殖系統的國考重點是幾個**先天異常**：**膀胱輸尿管逆流**(反覆泌尿道感染)、**隱睪症**、**尿道下裂**的手術後照護。兒童泌尿道感染見 [[urinary-tract-infection#children]]，腎炎與腎病症候群見 [[glomerular-diseases]]，威爾姆氏腫瘤見 [[pediatric-cancers#wilms]]

## 重點摘要 {#summary}

- 兒童腎功能：出生時 GFR(glomerular filtration rate) 只有成人的 15–20%，3 個月約 50%，**約 2 歲達成人值**；嬰幼兒**濃縮與稀釋尿液能力差**，容易脫水或水中毒；**4–5 歲**才能完全控制膀胱
- **膀胱輸尿管逆流**(VUR, vesicoureteral reflux)：輸尿管進入膀胱的隧道太短，排尿時尿液逆流 → 反覆**泌尿道感染**、腎臟**結疤**；**VCUG**(voiding cystourethrography) 診斷與分級(1–5 級，越高越嚴重)
- VUR 治療：輕度(1–3 級)**預防性抗生素**並追蹤，常隨年齡自行消失；重度做**輸尿管再植入術**或內視鏡注射
- **隱睪症**：睪丸停在腹腔到陰囊之間；**早產兒較多**；多數在出生後 **3–6 個月**內自行下降；未下降者約 **6–18 個月**做**睪丸固定術**，以降低**不孕**與**睪丸癌**風險
- 隱睪檢查：**暖手、溫暖環境**；6 個月以下**平躺**檢查，6 個月以上採**蹲姿**放鬆提睪肌
- **尿道下裂**：尿道開口在陰莖**腹側**；**新生兒不可割包皮**(留給修補用)；約 **6–12 個月**手術
- 尿道下裂術後：導尿管**固定在腹部或腿上**、**不限水**、預防**便秘**、**不可跨坐**父母身上、**限制活動**約 2 週、**雙層尿布**；尿液從陰莖以外處滲出要**通知醫師**

### 國考常考點 {#exam-points}

- VCUG：目的在**評估膀胱輸尿管逆流**及其嚴重度；要**放導尿管**灌顯影劑；**不需禁食 8 小時或灌腸**；檢查後**多喝水**排出顯影劑
- VUR **不會導致腎病症候群**；會導致反覆泌尿道感染、腎臟結疤與高血壓
- 隱睪症：
   1. 睪丸在胎兒 **7–8 個月**開始下降、**8–9 個月**才進入陰囊(「7 個月時應已進入陰囊」是錯的)
   2. 早產兒發生率高於足月兒；出生後一年內仍可能自行下降
   3. **不是兩歲以內都不用處理**；不用生長激素
   4. 術後腫脹**冰敷**；傷口避免尿便汙染
   5. 6 個月以上檢查採**蹲姿**(不是站姿)
   6. **隱睪症是睪丸癌最主要的危險因子**
- 尿道下裂術後：
   1. **導尿管固定於腹部或腿上**，避免牽扯傷口(不是固定在床欄)
   2. **不可限水**；預防便秘
   3. **不可跨坐**、要限制活動與臥床休息；用床上拱型護架避免壓迫
   4. 尿液從陰莖以外部位滲出是**異常**，要通知醫師
- 兒童 GFR **約 2 歲**才接近成人標準(「1 歲達成人標準」是錯的)；5 歲時 GFR 已達成人程度

## 兒童泌尿系統的特性 {#physiology}

- 胎兒 9–12 週開始製造尿液，排到羊水；雙側腎臟沒有發育 → **羊水過少**(《實用兒科護理》p.582)
- 新生兒**出生後 48 小時內**應該排尿；尿布上偶爾有粉紅色是**尿酸鹽結晶**，不一定是血(同書 p.582–583)
- **GFR**：出生時約成人的 15–20%，3 個月約 50%，**約 2 歲接近成人**；嬰幼兒濃縮與稀釋能力不足，對脫水與體液過多的耐受差
- 每日尿量隨年齡增加(同書 p.582 表 11-1 整理)：
   1. 新生兒第 1–2 天：約 30–60 mL
   2. 1 歲內：約 400–500 mL
   3. 學齡前：約 600–700 mL
   4. 學齡到青春期：約 650–1,400 mL
- 嬰兒膀胱位在腹腔，脹滿時可在恥骨聯合上 1–4 公分摸到，也是**恥骨上膀胱穿刺**的位置；**4–5 歲**才能完全控制膀胱
- 新生男嬰：右側精索較短、右側陰囊較高；腹膜鞘狀突沒閉合 → **陰囊水腫**，通常數個月內自行消失

## 檢查與護理 {#procedures}

- 兒童做檢查前依年齡解釋、準備；疲倦或剛餵完奶時檢查比較容易入睡，無法配合的孩子依醫囑**鎮靜**(《實用兒科護理》p.585)
- **排尿性膀胱尿道攝影**(VCUG)：
   1. 目的：看膀胱與尿道構造、有無**逆流**並分級
   2. 先**放導尿管**，灌入顯影劑到膀胱，在 X 光下看排尿時有沒有逆流，約 15 分鐘
   3. 先說明注入顯影劑時會有**尿意**；檢查後最初幾次解尿可能**刺痛**
   4. 檢查後**多喝水**以利排尿
- 腎臟超音波：不痛、會塗凝膠；區分囊腫與實質腫瘤
- 尿液檢體：嬰兒用集尿袋、導尿或恥骨上膀胱穿刺；收集後**立即送檢**，否則冷藏(詳見 [[urinalysis]])
- 其他成人也會做的泌尿檢查見 [[urologic-diagnostic-procedures]]

## 膀胱輸尿管逆流 {#vur}

- 正常：輸尿管斜斜穿過膀胱壁、埋在黏膜下一段距離，排尿時膀胱收縮把這段壓扁 → 尿液不會逆流
- **原發性**：這段隧道**太短**(先天)，排尿時尿液逆流回輸尿管，排完又流回膀胱 → 殘尿、細菌滋生；有**家族性**
- **繼發性**：泌尿道感染、膀胱出口阻塞、神經性膀胱、手術造成
- 來源：《實用兒科護理》p.588

### 分級 {#vur-grades}

| 級數 | 逆流到哪裡 | 擴張程度 |
|---|---|---|
| 1 | 只到輸尿管下段 | 輸尿管不擴張 |
| 2 | 到腎盂 | 腎盞不擴張 |
| 3 | 到腎盂 | 腎盞**輕微**擴張 |
| 4 | 到腎盂 | 腎盂、腎盞、輸尿管**明顯擴張** |
| 5 | 大量逆流 | **嚴重水腎**、輸尿管彎曲 |

- 依國際分級整理(《實用兒科護理》p.589)；等級越高越嚴重、越不容易自行消失

### 表現與治療 {#vur-treatment}

- 表現：多以**泌尿道感染**表現(嬰兒發燒、餵食差；較大兒童頻尿、解尿痛灼熱)；長期反覆感染 → **腎臟結疤**、高血壓、蛋白尿，甚至腎衰竭
- 有泌尿道感染、產前水腎或家族史的孩子要評估 VUR
- 輕度(1–3 級)：
   1. **長期低劑量預防性抗生素**(如 TMP-SMX、nitrofurantoin)，配合定期尿液檢查與 VCUG 追蹤，等逆流隨年齡消失
   2. 新舊說法：課本提到美國小兒科醫學會 2011 年對常規預防性抗生素持保留(《實用兒科護理》p.589)；之後 **RIVUR 試驗(2014)** 顯示預防性抗生素可將復發泌尿道感染約減半，所以臨床仍依年齡、級數與感染史個別決定；國考答案「輕微 VUR 可使用預防性抗生素」為正確敘述
- 重度：**輸尿管再植入術**(把輸尿管斜埋進膀胱壁、加長隧道)，或**內視鏡注射填充物**(Deflux)到輸尿管開口下方，當天可出院
- 衛教：預防泌尿道感染的生活習慣見 [[urinary-tract-infection#prevention]]

## 隱睪症 {#cryptorchidism}

- 睪丸沒有從腹腔經腹股溝管降到陰囊，停在中途(《實用兒科護理》p.603)
   1. **回縮型睪丸**：遇冷、觸摸、害怕時提睪反射把睪丸拉到腹股溝，**可用手推回陰囊** → 不需治療
   2. **異位睪丸**：下降路徑偏離，停在恥骨上、大腿根部或會陰
   3. **未下降睪丸**：停在腹腔與陰囊之間
- 睪丸在胎兒 **7–8 個月**開始下降、**8–9 個月**進入陰囊；**早產兒**發生率高(約 30%)，足月兒約 3%；多數在出生後 **3 個月**內自行下降，6 個月時約剩 1.5%；右側較常見
- 機轉：需要胎兒 LH 與睪固酮；腹腔溫度比陰囊高 → 青春期後**精子生成受損(不孕)**、**睪丸癌**風險增加；半數以上合併**疝氣**
- 表現：患側**陰囊較小、表面平滑、缺少皺褶**
- 檢查：
   1. 先**暖手**、環境溫暖，避免提睪反射
   2. **6 個月以下平躺**觸診雙側陰囊，找不到再沿腹股溝檢查
   3. **6 個月以上採蹲姿**(盤腿或蹲)讓提睪肌放鬆
   4. 摸不到時：超音波、電腦斷層偽陰性高；**腹腔鏡**可同時診斷與治療
- 治療：
   1. **睪丸固定術**：把睪丸拉下縫在陰囊內；課本寫 6–24 個月、**2 歲前**完成(《實用兒科護理》p.604)
   2. 新指引：**AUA(American Urological Association) 2014** 建議 6 個月後仍未下降就轉介，**18 個月前**完成手術；**不建議荷爾蒙治療**(hCG、LHRH 效果差)
- 術後照護：
   1. 腫脹時**冰敷**、依醫囑止痛
   2. 傷口避免尿便汙染、注意感染
   3. 術後數日限制活動、淋浴
   4. 長期追蹤，青春期起教導**睪丸自我檢查**

## 尿道下裂 {#hypospadias}

- 尿道開口在陰莖**腹側**(下方)任一處；以靠近龜頭的**前段**最多，嚴重者開口在陰囊或會陰；男嬰約 1/250(《實用兒科護理》p.605)
- 原因：胎兒期睪固酮不足，尿道皺摺沒有在中線癒合；可能合併**隱睪症**、腹股溝疝氣
- 表現：
   1. 尿道口不在龜頭中央；包皮背側多、腹側短，像**頭罩**
   2. 陰莖向腹側彎曲(**chordee**)，勃起疼痛
   3. 無法站著直線排尿；括約肌正常，**不會尿失禁**
   4. 陰囊型、會陰型陰莖短小時要做**染色體檢查**確認性別
- **新生兒不可割包皮**：保留包皮作為日後重建材料
- 手術：約 **6–12 個月**做**尿道重建術**(大小便訓練前、較無記憶、止痛需求少)；矯正陰莖彎曲並把尿道開口移到龜頭；複雜近端型需兩階段
- 術後常見併發症：尿道狹窄、**尿道皮膚瘻管**、感染、陰莖仍彎曲

### 術後護理 {#hypospadias-postop}

- **導尿管或支架**：從新尿道放進膀胱引流，**固定在腹部或大腿上**避免牽扯；監測尿量、顏色與**通暢度**(《實用兒科護理》p.606–608)
- **雙層尿布法**：內層尿布剪開口，讓導管拉到外層；內層接大便、外層接尿，換尿布時只換外層，減少摩擦傷口
- **水分**：**不限水**，鼓勵足夠水分(保持尿液流動、減少感染)
- **預防便秘**：正常飲食、依醫囑軟便劑，解便用力會影響傷口
- **活動**：限制活動約 **2 週**、避免壓迫手術部位；**不可跨坐**在父母身上或玩跨騎玩具；可用**床上拱型護架**避免被蓋壓迫；必要時約束
- 傷口：頭 3 天可能少量滲血；觀察龜頭顏色(粉紅色)；**尿液從陰莖以外的地方滲出 → 通知醫師**(可能是瘻管)
- 藥物：止痛、**oxybutynin** 減少膀胱痙攣、預防性抗生素、軟便劑
- 敷料移除後可洗澡；導尿管拔除後觀察解尿，剛開始會有暫時不適
- 心理：學齡前兒童怕被「切掉」，用治療性遊戲解釋，避免「切開、修理」等字眼，讓他知道生殖器還在、不是做錯事被懲罰

## 尿道上裂與包莖 {#epispadias-phimosis}

- **尿道上裂**：尿道開口在陰莖**背側**，比尿道下裂少見；常合併**膀胱外翻**；陰莖向背側彎曲，**可能尿失禁**；手術與照護類似尿道下裂(《實用兒科護理》p.608)
- **包莖**：包皮口狹窄，無法推回到冠狀溝
   1. **生理性包莖**：新生兒大多包皮與龜頭黏在一起，隨年齡分離(1 歲約 50%、3 歲約 90% 可推回)；包皮軟、沒有疤 → 不需處理，**不要強行推回**
   2. **病理性包莖**：包皮口結疤狹窄，排尿困難、尿流細、反覆感染
   3. 治療：每天兩次塗**類固醇藥膏**(betamethasone)約 4–8 週，有效率 85% 以上；無效或反覆感染才考慮手術
   4. 清潔：洗澡時輕輕推到能推的位置清洗，再拉回原位
- 來源：《實用兒科護理》p.608–609

## 威爾姆氏腫瘤 {#wilms}

- **兒童最常見的原發性腎臟惡性腫瘤**，多在 **5 歲以下**(10 歲以下的腎臟腫瘤幾乎都是它)；起源於**腎臟**、惡性
- 最常見表現是**無痛的腹部腫塊**(不是血尿)；可有高血壓
- 術前**避免觸診腹部**(怕腫瘤破裂擴散)；照護細節見 [[pediatric-cancers#wilms]]
