早產兒是妊娠**未滿 37 週**出生的新生兒。各器官都還不成熟，越早出生問題越多，照護的核心是**呼吸、體溫、營養、預防感染與併發症**，以及**發展性照護與家庭參與**。早產的產科處置（安胎）見 [[labor-complications#preterm-labor]]；新生兒的分類與成熟度評估見 [[newborn-assessment#classification]]、[[newborn-assessment#ballard]]；新生兒呼吸窘迫症候群見 [[ards-respiratory-failure#neonatal-rds]]。文中縮寫：RDS（Respiratory distress syndrome，呼吸窘迫症候群）、PDA（Patent ductus arteriosus，開放性動脈導管）、IVH（Intraventricular hemorrhage，腦室內出血）、NEC（Necrotizing enterocolitis，壞死性腸炎）、ROP（Retinopathy of prematurity，早產兒視網膜病變）、BPD（Bronchopulmonary dysplasia，支氣管肺發育不良）、PPHN（Persistent pulmonary hypertension of the newborn，新生兒持續性肺高壓）、TPN（Total parenteral nutrition，全靜脈營養）、NICU（Neonatal intensive care unit，新生兒加護病房）

## 重點摘要 {#summary}

- 定義：**< 37 週**；晚期早產 34–36⁶⁄₇ 週、極早產 < 32 週、超早產 < 28 週；體重分 < 2,500、< 1,500、< 1,000 公克
- 外觀：皮膚**薄、紅、透明看得到血管**、**胎毛多**、皮下脂肪少、足底皺摺少、乳暈平、耳軟、睪丸未降或小陰唇突出；**肌張力低、四肢伸展**、反射弱
- 主要問題：**RDS**（表面張力素不足）、**呼吸暫停**（中樞不成熟）、**PDA**、**IVH**（腦血管脆弱）、**NEC**（腸道缺血）、**ROP**（氧氣）、BPD、**低體溫**、**低血糖**、**黃疸**、**感染**、貧血
- 體溫：棕色脂肪少、體表面積大 → **保溫箱**（中性溫度）、極早產兒**高濕度（約 70–80%）**、出生時**塑膠膜覆蓋**、戴帽子
- 餵食：**吸吮、吞嚥、呼吸協調約 32–34 週**才成熟 → 之前用**口胃管或鼻胃管灌食**或 TPN；經口餵食每次**不超過約 30 分鐘**，出現**壓力線索**（疲倦、嗆奶、呼吸暫停、發紺、心跳慢）就減慢或停止
- NEC：**腸黏膜缺血缺氧**、好發**迴腸末端與升結腸**；**腹脹、膽汁性嘔吐、血便**；**禁食、胃管減壓、TPN、抗生素**、**不量肛溫**；**母乳**預防
- 發展性照護：**袋鼠式護理**、**築巢**維持屈曲姿勢、**集中護理**、減少光線與噪音、鼓勵父母**觸摸與參與**

### 國考常考點 {#exam-points}

- 31 週早產兒生理特徵**錯誤**：「表面張力素不足容易出現**持續性肺動脈高壓**」（應是 **RDS**）；腎小管再吸收差有蛋白尿尿糖、凝血因子與維生素 K 低、暫時性乳糖吸收不良都對
- 29 週早產兒**正確**：**中樞神經系統不成熟，易發生呼吸暫停**；IgA **本來就不能**經胎盤（不是早產才有的問題）；黃疸是**葡萄糖醛酸轉移酶**不足（不是 β-葡萄糖醛酸苷酶不足）；早產兒最常見的心臟問題是 **PDA**（不是心室中膈缺損）
- 28 週、960 公克**正確**：**沒有吸吮吞嚥反射時用腸道外營養**；表面張力素是**氣管內給予**（不是靜脈點滴）；早產兒四肢**伸展**（不是屈曲內縮）；胎毛**多**、足底皺摺**少**
- 28 週早產兒**錯誤**：「吸吮和吞嚥**已能協調**，可以由口進食」
- 26 週早產兒最可能：**四肢肌張力無力、難以維持屈曲**；早產兒**躺姿放鬆伸展**、足月兒屈曲；早產兒抓握反射**較弱**、足跟碰耳朵**較容易**、手肘**較容易**越過胸前
- NEC **正確**：原因是**腸黏膜缺血缺氧**；**錯誤**：「以革蘭氏**陽性**菌最常侵犯」（多為革蘭氏陰性）、「好發**幽門與小腸近端**」「好發**乙狀結腸與直腸**」（應是**迴腸末端與升結腸**）、「先用鼻胃管餵半奶」（應**禁食**）
- NEC 護理**最不適當**：「腸蠕動減慢，**嘔吐物不含膽汁**」（NEC 嘔吐物常**含膽汁**）；避免量肛溫、觀察活動力下降與體溫不穩、**立即禁食給 TPN** 都適當；**哺餵母乳**是最佳預防
- 26 週早產兒保溫**不適當**：「保溫箱 **28–30°C、濕度 45–50%**」；25 週 680 公克**錯誤**：「保溫箱**濕度 40%**」（極早產兒要 **70–80%**）；毛毯包裹戴帽子、手腳套、**塑膠膜覆蓋**、預熱輻射台、加熱潮濕的氧氣都適當
- 早產兒保溫**不適當**：「低出生體重早產兒**絕對不能**執行袋鼠式護理」（穩定時袋鼠式護理反而能**維持體溫**）；集中護理、處置時不離開保溫箱都適當
- 經口餵食**錯誤**：「低週數低體重早產兒餵食時間延長到 **60 分鐘**以減少壓力」；**安靜清醒並有飢餓暗示**時開始、出現**壓力暗示**就減慢或停止、觀察呼吸膚色並調整奶瓶與流速都正確
- 餵食壓力線索**不包括**「**會因為呼吸而中止吞嚥**」（這是正常的自我調節）；吸不到 5 分鐘就睡著、呼吸喘鼻翼搧動心跳變慢、嗆奶咳嗽膚色改變都是
- 口胃管灌食**不適當**：「灌食時頭部抬高**大於 30 度**」；插管前用**無菌蒸餾水**潤滑、灌食前**檢查胃殘餘量**、每天熱量 **100–120 kcal/kg** 都正確
- 擺位**不適當**：「口胃管灌食後頭部抬高 **45 度約 10 分鐘**」；休息時**肩膀向前、雙手屈曲靠近中線與嘴**、髖膝屈曲並預留活動空間、**呼吸暫停時頸部微仰**都正確
- 發展性照護**正確**：**袋鼠式護理**；**錯誤**：固定雙臂與腿呈**伸展**、**分散護理**（應**集中**）、**環境明亮**
- 促進統整化行為**不適當**：「**絕對避免觸摸或抱起**早產兒」
- 媽媽到 NICU 探視**錯誤**：「告知**減少觸摸**以避免刺激與感染」；說明特性與設備、示範照護技巧、**鼓勵袋鼠護理**都對

## 定義與原因 {#definition}

- 分類（週數與體重的分類表見 [[newborn-assessment#classification]]）

| 名稱 | 週數 |
|---|---|
| 晚期早產兒(late preterm) | 34⁰⁄₇–36⁶⁄₇ 週 |
| 中度早產 | 32–33⁶⁄₇ 週 |
| 極早產兒 | < 32 週 |
| 超早產兒 | < 28 週 |

- 晚期早產兒**外表像足月**，但仍容易**低體溫、低血糖、呼吸問題、黃疸、餵食困難**，不能當成足月兒照顧
- 早產的原因：早期破水、子宮頸閉鎖不全、多胞胎、子癇前症、前置胎盤與胎盤早期剝離、感染（絨毛膜羊膜炎、泌尿道感染）、母親年齡過小或過大、抽菸、營養不良、前次早產；很多找不到原因（產科危險因子見 [[high-risk-pregnancy#preterm-risk]]）

## 外觀與成熟度 {#features}

| 項目 | 早產兒 | 足月兒 |
|---|---|---|
| 姿勢 | **四肢伸展、放鬆**（像青蛙腿） | 四肢**屈曲** |
| 肌張力與反射 | **低**；吸吮、尋乳、**抓握**、踏步反射**弱或缺乏** | 好 |
| 皮膚 | **薄、紅、透明**、看得到血管、皮下脂肪少、水腫 | 較厚、看不太到血管 |
| 胎毛 | **多** | 少 |
| 足底 | 皺摺**少** | 前 2/3 以上有皺摺 |
| 乳房 | 乳暈平、摸不到乳房組織 | 乳暈突起、乳房組織 ≥ 3–4 mm |
| 耳 | 軟、平、回彈慢 | 硬、成形、立刻回彈 |
| 生殖器 | 男：**睪丸未降**、陰囊平滑；女：**陰蒂與小陰唇突出** | 男：睪丸已降、陰囊皺摺多；女：大陰唇覆蓋 |
| Ballard 神經肌肉 | **方形窗角度大**、**手肘越過中線**、**腳跟容易碰耳朵**、膝膕角大 | 相反 |
| 頭 | 頭相對大、囟門大、骨縫寬 | |

## 各系統不成熟與問題 {#systems}

| 系統 | 不成熟 | 結果 |
|---|---|---|
| **呼吸** | **表面張力素不足**（約 34–35 週才足夠）、肺泡少、胸壁軟、呼吸中樞不成熟 | **RDS**、**呼吸暫停**、BPD |
| **心血管** | 動脈導管對氧氣反應差 | **PDA**（早產兒最常見的心臟問題）；低血壓 |
| **神經** | 腦室周圍**生發基質**血管脆弱、腦血流自我調節差；中樞不成熟 | **IVH**、腦室周圍白質軟化；**呼吸暫停**；反射弱 |
| **體溫** | **棕色脂肪少**、皮下脂肪少、體表面積大、皮膚薄（**蒸發**多）、不會屈曲保暖 | **低體溫**、冷壓力 |
| **消化** | **吸吮吞嚥呼吸不協調**（32–34 週才成熟）、胃容量小、賁門鬆、腸蠕動弱、**乳糖酶與脂肪消化差** | 餵食困難、吸入、胃食道逆流、**NEC**、暫時性乳糖吸收不良 |
| **肝臟** | **葡萄糖醛酸轉移酶不足**；肝醣存量少；凝血因子合成少 | **黃疸**（更早、更高、更久）、**低血糖**、出血傾向 |
| **腎臟** | 腎絲球過濾率低、腎小管**再吸收差**、濃縮能力差 | 脫水或水分過多、電解質不平衡、**蛋白尿、尿糖**、藥物排除慢 |
| **血液** | 紅血球壽命短、紅血球生成素低、鐵存量少、抽血多 | **早產兒貧血**、維生素 K 低 → 出血 |
| **免疫** | 經胎盤的 **IgG 少**（懷孕後期才大量傳）、皮膚屏障差、侵入性管路多 | **感染**、敗血症 |
| **眼睛** | 視網膜血管還沒長完 | **ROP**（氧氣濃度波動是危險因子） |
| **代謝** | 鈣磷存量少 | 低血鈣、早產兒代謝性骨病 |

## 常見併發症 {#complications}

### 呼吸窘迫症候群 {#rds}

- **表面張力素不足** → 肺泡塌陷、透明膜形成；出生後數小時內呼吸急促、**呻吟**、鼻翼搧動、肋間凹陷、發紺；X 光**毛玻璃狀**
- 處置：**產前類固醇**（母親，促進肺成熟）、**CPAP**、**表面張力素經氣管內給予**、給氧與呼吸器；完整內容見 [[ards-respiratory-failure#neonatal-rds]]、[[oxygen-therapy]]

### 呼吸暫停 {#apnea}

- **早產兒呼吸暫停**：呼吸停止 **≥ 20 秒**，或較短但合併**心跳變慢**（< 100 次/分）、**發紺**或**血氧下降**；原因是**呼吸中樞不成熟**，週數越小越常見
- 和**週期性呼吸**（停 5–10 秒、不合併心跳變慢或發紺）不同（見 [[respiratory-assessment]]）
- 處置
   1. 心肺與血氧監測，警示響起先看病人
   2. **輕柔觸覺刺激**（搓背、腳底）；無效給正壓通氣
   3. 擺位：**頸部微仰**（嗅物姿勢），**避免過度屈曲或伸展**（壓迫呼吸道）
   4. 依醫囑 **caffeine citrate**（中樞興奮劑）；必要時 CPAP
   5. 排除感染、低血糖、體溫不穩、貧血、胃食道逆流等誘因

### 開放性動脈導管 {#pda}

- 早產兒動脈導管對氧氣的收縮反應差 → 左向右分流 → 肺血流增加、心衰竭；**連續性機器樣雜音**、**脈壓變寬**、跳躍脈
- 處置：限水、依醫囑 **indomethacin 或 ibuprofen**（前列腺素合成抑制劑）關閉，無效手術結紮；見 [[congenital-heart-disease#left-to-right]]

### 腦室內出血 {#ivh}

- 多在出生後 **72 小時內**；**< 32 週**風險高
- 預防：**頭部置中**、**抬高床頭約 30 度**、**避免頭低腳高**與快速輸液、減少刺激與疼痛、輕柔處置、避免血壓與血氧大波動；見 [[pediatric-neuro#ivh]]

### 壞死性腸炎 {#nec}

- **原因**：**腸黏膜缺血缺氧**（窒息、低血壓、PDA、紅血球增多） → 黏膜受損 → **細菌侵入**（多為**革蘭氏陰性菌**） → 壞死；**配方奶**、過快增加奶量是危險因子；**母乳**有保護作用
- **好發部位**：**迴腸末端與升結腸**
- **表現**：**腹脹**、**胃殘餘量增加**、**膽汁性嘔吐**（綠色）、**血便**、腹壁發紅；腸蠕動**減慢或消失**；全身：**活動力下降、體溫不穩**、呼吸暫停、心跳變慢；X 光**腸壁積氣**、門靜脈積氣，穿孔時有腹腔游離氣體
- **處置與護理**
   1. **立即禁食**、**胃管減壓**（低壓間歇抽吸）
   2. **TPN**、靜脈輸液
   3. 依醫囑**抗生素**
   4. 每班量**腹圍**（同一位置）、觀察腹部與大便潛血
   5. **不量肛溫**（避免腸穿孔），量腋溫
   6. 平躺或側臥、不用尿布綁緊腹部
   7. 穿孔或壞死 → 手術（切除、腸造口）
   8. **預防**：**哺餵母乳**（含 IgA、乳鐵蛋白）、**慢慢增加奶量**
- 嬰兒其他腸胃疾病見 [[pediatric-gi]]

::questions{ids="113-3_OP_033,113-1_OP_035,108-2_OP_063"}

### 早產兒視網膜病變 {#rop}

- 視網膜血管未發育完成，**氧氣濃度過高或波動**促使異常血管增生 → 視網膜剝離、失明
- 預防：**依目標範圍給氧**（監測血氧，避免過高與大起大落）；高危險早產兒（依台灣篩檢條件，例如 < 32 週或 < 1,500 公克）出生後約 4 週起由眼科**定期篩檢**；治療見 [[eye-disorders#rop]]

### 支氣管肺發育不良與其他 {#bpd-others}

- **BPD**：長期**氧氣與呼吸器**造成肺損傷；矯正 36 週還需要氧氣；需要長期氧氣、限水、利尿劑、足夠熱量
- **早產兒貧血**：生成素低、抽血多 → 減少抽血量、補鐵、必要時紅血球生成素或輸血
- **黃疸**：更早、更高、更久，照光閾值較低（見 [[neonatal-disorders#hyperbilirubinemia]]）
- **低血糖**、低血鈣：見 [[neonatal-disorders#hypoglycemia]]
- **感染**：嚴格**洗手**、無菌技術、管路照護（見 [[perinatal-infections#neonatal-infections]]）

## 體溫維持 {#thermoregulation}

- 目標：在**中性溫度環境**（耗氧最少）維持腋溫約 36.5–37.5°C
- 出生時
   1. 產房室溫提高、**預熱輻射加溫台**
   2. **< 32 週**：**不先擦乾**，直接用**塑膠膜或塑膠袋**（食品級）包住身體（頭露出），減少**蒸發與對流**
   3. 戴帽子、轉送用預熱的轉送保溫箱
- **保溫箱**
   1. 箱溫依**體重與日齡**設定（極早產兒初期常需 **34–36°C**），或用**皮膚溫度探頭**自動控制（貼在腹部或肝區，不要貼在骨突或被壓住）
   2. **濕度**：極低與超低出生體重兒初期 **70–80%**（甚至更高），減少皮膚**蒸發散熱與水分流失**，再隨日齡與皮膚成熟逐漸降低；**40–50% 太低**
   3. **集中護理**，少開側門、用操作孔；不放在窗邊、冷氣口
   4. 保溫箱內也可以用**包巾、帽子、手腳套**
   5. 給氧與呼吸器的氣體要**加溫加濕**
- 低體溫的影響（冷壓力：耗氧增加、低血糖、酸中毒）見 [[newborn-adaptation#thermoregulation]]

::questions{ids="112-2_OP_052,106-1_OP_054,110-2_OP_053"}

## 營養與餵食 {#feeding}

- 需要：熱量 **100–120 kcal/kg/天**（有的需要更高）；首選**母乳**（加**母乳強化劑**），沒有時用早產兒配方
- 依成熟度選擇方式

| 情況 | 方式 |
|---|---|
| 極早產、病況不穩、NEC、沒有腸道功能 | **TPN**（腸道外營養）；病況許可儘早**微量餵食**（少量母乳） |
| **< 32–34 週**、**吸吮吞嚥呼吸不協調**、沒有吸吮與嘔吐反射 | **口胃管或鼻胃管灌食**（早產兒用鼻呼吸，多用**口胃管**） |
| 約 **32–34 週**、病況穩定、出現飢餓暗示 | 開始**經口餵食**（親餵或奶瓶），不足部分仍由管灌補 |

- **管灌注意**
   1. 插管前用**無菌蒸餾水**潤滑（不用油性潤滑劑），確認位置
   2. 每次餵食前**反抽胃殘餘量**；殘餘量增加、膽汁色、腹脹 → 先暫停並報告（NEC 早期徵象）
   3. 灌食時床頭抬高約 **15–30 度**，用**重力**慢慢流入，不用力推
   4. 灌食後**維持抬高約 30 度**、**右側臥或俯臥**（在監測下）約 **30–60 分鐘**，促進胃排空、防止逆流與吸入
   5. 灌食時讓寶寶**吸安撫奶嘴**（非營養性吸吮），促進消化與吸吮發展
   6. 早產兒兒童管灌的細節見 [[enteral-parenteral-nutrition#pediatric]]
- **經口餵食**（cue-based feeding，依暗示餵）
   1. **開始時機**：**安靜清醒**、出現**飢餓暗示**（尋乳、吸吮動作、手放嘴邊）
   2. 每次**不超過約 20–30 分鐘**；時間拉長會**消耗太多能量**、增加嗆奶，**不能**用延長到 60 分鐘來減壓
   3. 觀察**呼吸、膚色、心跳**；用**節律性餵食**（每吸 3–5 口讓他休息呼吸）、調整奶瓶角度與奶嘴流速、側躺餵
   4. **壓力線索**(feeding stress cues) → **減慢或停止**、刺激呼吸

| 壓力線索（要暫停） | 不是壓力線索 |
|---|---|
| **疲倦**、吸幾分鐘就睡著 | 吸幾口後**為了呼吸而暫停吞嚥**（正常自我調節） |
| **嗆奶、咳嗽**、奶從嘴角流出 | 吸吮時偶爾短暫休息 |
| **呼吸暫停**、呼吸喘、**鼻翼搧動** | |
| **發紺**、膚色改變、血氧下降 | |
| **心跳變慢** | |
| 張開手指、皺眉、轉開頭、拱背 | |

## 擺位與發展性照護 {#developmental-care}

- **發展性照護**(developmental care)：調整環境與照護方式，讓早產兒的**生理與行為穩定**（統整化行為），促進腦部發育
- 措施

| 項目 | 做法 |
|---|---|
| **擺位** | 用包巾或捲軸**築巢**（鳥巢），維持**屈曲**、**雙手靠近中線與嘴巴**、**肩膀向前**、髖膝屈曲，**預留四肢活動空間**；呼吸暫停時**頸部微仰**；定時改變姿勢，預防頭形扁平 |
| **集中護理** | 把評估與處置**集中**在同一時段，之後讓他**長時間休息**（**不是分散護理**） |
| 光線 | **降低光線**、遮蓋保溫箱、**日夜週期**；不是一直明亮 |
| 聲音 | 降低噪音、輕關保溫箱門、不在箱上放東西；清醒時可以**播放輕柔音樂**或父母說話 |
| 疼痛與觸摸 | **寧握**（facilitated tucking：雙手包住四肢維持**屈曲**）、**非營養性吸吮**、口服蔗糖水；溫柔、**有預告**的觸摸 |
| **袋鼠式護理** | 父母**裸胸與只穿尿布的早產兒肌膚接觸**、直立在胸前；穩定體溫、心跳、呼吸與血氧，促進睡眠、**母乳**與**親子依附**、縮短住院（WHO 2022：出生後儘早、每天越久越好） |
| 依暗示照護 | 看早產兒的**穩定訊號**（手放嘴邊、抓握、放鬆）與**壓力訊號**（打哈欠、打嗝、張開手指、轉開臉、膚色改變）調整步調 |

::questions{ids="113-1_OP_033,112-3_OP_035"}

## 家庭支持 {#family}

- 父母常有**罪惡感、焦慮、失落**（不是想像中的寶寶），看到管路與儀器會害怕
- 護理
   1. **說明**早產兒的特性、身上的**管路與設備**、目前狀況
   2. **鼓勵探視**、**觸摸**（洗手後）與**袋鼠式護理**；**不叫父母減少觸摸**
   3. **示範並讓父母練習**照護技巧（換尿布、餵食、沐浴），出院前**親自照顧**
   4. 鼓勵**擠母乳**送到 NICU
   5. 傾聽感受、提供支持團體與資源（早產兒基金會、追蹤門診）
- 出院後：**矯正年齡**評估生長發展（到約 2 歲）、眼科與聽力追蹤、預防接種**依實際年齡**
