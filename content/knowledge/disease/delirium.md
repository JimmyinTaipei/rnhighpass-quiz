**譫妄**是大腦在身體疾病、藥物或物質影響下發生的**急性功能障礙**，可以看成「急性腦衰竭」。病人在幾小時到幾天內變得**注意力無法集中、意識混亂、時好時壞**，常在夜間躁動、拔管、看到不存在的東西。譫妄是**醫療上的警訊**，背後往往有感染、缺氧、電解質異常或藥物問題，要優先找原因。與失智症的比較見 [[dementia#differential]]

## 重點摘要 {#summary}

- **核心**：**注意力**與**意識清晰度**下降、**急性發作**(數小時到數天)、**一天內起伏**(夜間常加重)、伴隨其他**認知障礙**、有**身體原因**
- **表現**：定向感障礙、近期記憶差、語無倫次、**視幻覺**與錯覺最常見、睡醒週期紊亂、躁動或嗜睡
- **類型**：**過動型**(躁動、拔管、喊叫)、**活動低下型**(安靜嗜睡，最容易被忽略)、混合型
- **高危險群**：老人、**失智**、重病、**手術後**、**加護病房**、頭部外傷、多重用藥、視聽障礙；但**任何年齡**都可能發生
- **處置**：**找出並治療原因**、**維持生命徵象穩定**；**安全、安靜、照明適當**的環境；**簡短重複告知人時地**；**盡量不約束**；**避免 BZD**

### 國考常考點 {#exam-points}

- 車禍頭部外傷住加護病房，幾天後突然**躁動、胡言亂語、拔管、時躺時坐** → **譫妄**(不是思覺失調症、雙相、失智)
- 譫妄是**急性發作**、**意識混亂且起伏**；失智是**緩慢進行**、意識清楚；兩者**任何年齡**都可能，譫妄**不是**只發生在老人
- 最常見的知覺障礙是**視幻覺**(不是觸幻覺、聽幻覺)；DSM-5 的認知困擾包括**失去定向感、語言、視覺空間能力**
- 譫妄**不是**以記憶障礙為必要條件；病程**不是慢性化**；移除病因後**通常可以恢復**
- 病因：手術創傷、**酒癮與戒斷**、**電解質不平衡**、急性創傷、**知覺刺激過多**、腦血管損傷；**退化**與**夜眠片段**不是主要原因
- 護理目標**最優先**是**維持生命徵象穩定、治療原因**；措施是**安全、安靜、舒適的環境**、**簡短扼要重複告知人時地**
- **不要**：儘量約束隔離、增加感官刺激、要求參與定向感訓練、限制飲水、優先給安眠藥
- 失智症病人發生譫妄 → 避免 **BZD**(會加重譫妄)；可短期用抗精神病藥
- 病房放**時鐘和月曆**是提供**現實定向**

## 臨床表現 {#manifestations}

### 核心特徵(DSM-5 摘要) {#core-features}

1. **注意力障礙**：無法集中、維持或轉移注意力，問題要重複問；**對環境的覺察下降**
2. **急性發作**：數小時到數天內出現，和平常的狀態明顯不同
3. **一天內起伏**：時好時壞，**傍晚與夜間**常加重(清醒時看起來正常，容易被誤以為沒事)
4. **伴隨其他認知障礙**：**定向感**(時間最先)、**近期記憶**、**語言**(語無倫次、答非所問)、**視覺空間**、**知覺**
5. 有證據顯示是**身體疾病、物質中毒或戒斷、藥物**造成，且不能用原本的失智症解釋，也不是昏迷

### 伴隨症狀 {#associated-symptoms}

| 面向 | 表現 |
|---|---|
| **知覺** | **視幻覺最常見**(看到蟲、人、動物)、**錯覺**(把點滴架看成人)；酒精戒斷常有觸幻覺(蟲在爬) |
| 思考 | 語無倫次、片段的被害想法 |
| 睡眠 | **睡醒週期紊亂**、日夜顛倒、夜間躁動 |
| 精神運動 | 過動(躁動、拉扯管路、想下床)或遲緩(嗜睡、反應慢) |
| 情緒 | 害怕、焦慮、易怒、淡漠，變化快 |
| 腦波 | 多為**瀰漫性變慢**(酒精與鎮靜劑戒斷可見快波) |

### 類型 {#subtypes}

| 類型 | 表現 | 注意 |
|---|---|---|
| **過動型** | 躁動不安、喊叫、**拔管**、爬床欄、幻覺明顯 | 跌倒、自拔管路的風險高；常見於酒精戒斷 |
| **活動低下型** | 安靜、嗜睡、反應慢、少說話 | **最常被忽略**或誤認為憂鬱，預後較差；老人最常見 |
| **混合型** | 兩者快速交替；或活動量正常但注意力與覺察仍受損 | — |

## 病因與誘因 {#etiology}

| 類別 | 例子 |
|---|---|
| **感染** | 泌尿道感染、肺炎、敗血症 |
| **代謝與電解質** | **電解質不平衡**(低鈉、高鈣)、**脫水**、低血糖、肝腎衰竭、甲狀腺 |
| **缺氧與循環** | 缺氧、休克、心衰竭、貧血 |
| **腦部** | **頭部外傷**、**腦血管疾病**、腦炎、癲癇發作後 |
| **藥物** | **抗膽鹼藥**、**BZD**、鴉片類(**pethidine**)、類固醇、多重用藥 |
| **物質** | 酒精或鎮靜劑**中毒或戒斷**(震顫性譫妄，見 [[alcohol-use-disorder#withdrawal-timeline]]) |
| **手術與加護病房** | **手術創傷**、麻醉、加護病房的**感覺超載**(噪音、燈光、儀器聲)或**感覺剝奪**、睡眠剝奪、管路、約束 |
| 其他 | 疼痛、**尿滯留**、**便秘**、視聽障礙沒有輔具、環境改變 |

1. **易發因子**：高齡(65 歲以上)、**失智**、重病、髖骨骨折、視聽障礙、營養不良、多重用藥
2. 易發因子越多，越小的誘因就能引發譫妄
3. 「退化」是慢性過程，不是急性行為改變的原因；偶爾睡不好也不是主要病因

## 評估與鑑別 {#assessment}

### 評估工具 {#cam}

**CAM(Confusion Assessment Method)**：符合 ① **且** ②，再加上 ③ **或** ④，就判斷為譫妄

1. **急性發作且病程起伏**
2. **注意力不集中**
3. 思考**紊亂**
4. **意識程度改變**(過度警覺、嗜睡、木僵)

- 加護病房插管病人用 **CAM-ICU**
- 每班評估一次以上，因為症狀會起伏

### 與失智、憂鬱的鑑別 {#differential}

| | 譫妄 | 失智症 | 憂鬱(假性失智) |
|---|---|---|---|
| **發生** | **急性**，數小時到數天，說得出時間 | **緩慢**、漸進 | 數週到數月 |
| **病程** | **一天內波動**，夜間加重；原因去除後**多可恢復** | 慢性、進行性、**不可逆** | 治療後可恢復 |
| **意識** | **混亂、起伏** | **清楚**(晚期例外) | 清楚 |
| **注意力** | **明顯受損** | 早期大致保留 | 不專心 |
| 記憶 | 近期與立即記憶差 | **近期記憶**先退化 | 抱怨記不住 |
| 知覺 | **視幻覺**常見 | 中晚期才有 | 少見 |
| 腦部影像 | 多正常 | **腦萎縮、腦溝變寬、腦室擴大** | 正常 |

1. 失智症病人**更容易**發生譫妄；原本失智的人突然變得更混亂，要先找身體原因(發燒、咳痰、尿滯留)
2. 失智症的照護見 [[dementia#nursing]]

## 預後 {#prognosis}

1. 找出並治療原因後，多數**可以恢復**，但老人可能持續數週到數月
2. 譫妄會增加**住院天數、跌倒、失能、入住機構與死亡率**，也和日後認知退化有關
3. 所以**預防**和**早期發現**很重要

## 治療 {#treatment}

1. **找出並治療原因**：感染、電解質、缺氧、疼痛、尿滯留、便秘；檢討用藥，停用或減少抗膽鹼藥、BZD 與鴉片類(見 [[cholinergic-drugs#antimuscarinics]])
2. **非藥物措施為主**(下方護理)
3. **藥物**
   1. 只有在病人**非常痛苦或有危險**、且非藥物方法無效時，才**短期、低劑量**使用 **haloperidol** 或第二代抗精神病藥(見 [[antipsychotics#indications]])
   2. **避免 BZD**：會讓意識更混亂、加重譫妄；例外是**酒精或 BZD 戒斷**造成的譫妄(見 [[anxiolytics-hypnotics#indications]])
   3. 路易氏體失智或巴金森氏症病人對抗精神病藥敏感，要更小心

## 護理 {#nursing}

### 護理優先順序 {#nursing-priorities}

1. **生理優先**：監測**生命徵象**、意識、血氧、液體與電解質、血糖、排尿排便；配合找出原因治療
2. **安全**：預防跌倒、自拔管路與受傷
3. 減輕混亂與恐懼，促進定向感
4. 家屬支持與衛教

### 環境 {#environment}

1. **安全、安靜、舒適**；減少噪音、不必要的儀器警報與夜間打擾
2. **刺激適中**：避免**感覺超載**，也避免感覺剝奪；不是「增加感官刺激」，也不是全暗
3. **白天明亮、夜間昏暗**，維持日夜節律；夜間留小夜燈減少錯覺
4. 放**時鐘、月曆**、熟悉的物品與家人照片
5. 盡量由**固定的護理人員**照顧，鼓勵**家屬陪伴**
6. 病床靠近護理站，便於觀察

### 溝通與定向 {#orientation}

1. 溝通**簡短扼要**，語氣平穩，一次一件事
2. **重複告知人、時、地**(現在幾點、在哪家醫院、我是誰)，不是要求病人參加定向感訓練課程
3. 解釋每一項處置，減少恐懼
4. 對幻覺與錯覺：不爭辯，告訴病人他是安全的，必要時調整光線
5. 戴上**眼鏡、助聽器**、假牙

### 生理照顧 {#physical-care}

1. 維持**水分與營養**，不要為了減少尿失禁而限制飲水
2. **控制疼痛**
3. 促進睡眠：白天活動、夜間減少打擾；**不要優先給安眠藥**
4. **早期下床活動**，避免長期臥床
5. 注意尿滯留與便秘；不必要的導尿管與管路儘早移除

### 約束 {#restraint}

1. 身體約束會**增加躁動、加重譫妄**，並造成皮膚損傷、跌倒與吸入性肺炎，**盡量避免**，不是第一線措施
2. 先用替代方法：家屬陪伴、固定管路、遮蓋管路、移到護理站旁、處理疼痛與尿意
3. 不得已時(例如反覆拔除氣管內管)：依醫囑與機構規範執行，向病人與家屬**說明並取得同意**；緊急情況先保護病人，隨即通知醫師並聯絡家屬補說明
4. 技術要點：保護部位先包**棉墊**；鬆緊度可伸入 **1–2 指**；固定在**不會移動的床架**，不綁在床欄等可移動的設備；用**可快速解開**的結；定時評估循環並鬆綁活動(精神科約束規範見 [[schizophrenia#restraint]])

:::note[考題分歧：約束用的結]
110-2_FA_049 的答案把「家屬無法立即聯絡就先約束、再補同意」當成錯誤敘述，而「先包棉墊、再用平結」當成正確；但多數基本護理教科書固定床架時用**可單手快速解開的活結(或套結)**，平結受力後不易解開。作答以題目答案為準，臨床以機構規範為準
:::

### 家屬衛教 {#family-education}

1. 說明譫妄是**身體疾病造成的急性腦功能障礙**，不是「發瘋」或失智，多數會隨原因改善而恢復
2. 鼓勵家屬陪伴、帶熟悉的物品，用平靜的語氣重複告知現在的狀況
3. 發現病人突然變得混亂、嗜睡或躁動時要告知醫護人員
