副甲狀腺分泌的 **PTH** 讓血鈣上升、血磷下降，所以**亢進 = 高血鈣、低血磷**，**低下 = 低血鈣、高血磷**，大部分表現都從血鈣推得出來。本頁整理兩種疾病的原因、表現、治療與護理；PTH 與鈣磷調節的生理見 [[thyroid-parathyroid#calcium-regulation]]，血鈣、血磷數值的意義見 [[calcium-phosphate]]

## 重點摘要 {#summary}

- **機能亢進**：高血鈣、**低血磷**、尿鈣與尿磷增加
   1. 原發性：**副甲狀腺腺瘤**最常見；續發性：**慢性腎病**(活化維生素 D 不足、磷滯留 → 低血鈣 → PTH 代償增加)
   2. 表現：**骨痛、骨質疏鬆、病理性骨折**；**腎結石**、**多尿、尿比重下降**、口渴；**便秘**、噁心、消化性潰瘍；肌肉無力、倦怠、憂鬱；**心律不整**(QT 縮短)
   3. 護理：**每天約 3000 mL 水**、**限鈣**(少乳製品)、**高纖**、**酸化尿液**(蔓越莓、酸灰性食物)、鼓勵活動但**防跌防骨折**
- **功能低下**：低血鈣、**高血磷**
   1. 原因：**甲狀腺或副甲狀腺手術**誤切或傷及血流(最常見)、自體免疫、先天、低血鎂
   2. 表現：神經肌肉興奮性上升 → **口周與指尖刺麻**、肌肉痙攣、**手足抽搐**、**Chvostek 徵象**、**Trousseau 徵象**、**喉部痙攣與喘鳴**、癲癇；長期：**白內障**、基底核鈣化、皮膚乾、指甲脆
   3. 急性：**靜脈**注射 **10% 葡萄糖酸鈣**(慢慢推並監測心電圖)；床邊備**氣管插管與氣切設備**
   4. 長期：**口服鈣**＋**活性維生素 D**；**限高磷食物**(乳酪、牛奶、蛋黃、肉類)；必要時隨餐服**磷結合劑**

### 國考常考點 {#exam-points}

- 亢進：**高血鈣、低血磷**；**多尿、尿比重下降**、腎結石；**骨痛、便秘**、噁心、**心律不整**；**骨質流失**(不是骨鈣沉積)；不會凸眼(那是 Graves 病)
- 亢進的護理：**多喝水**(不是限水)、**限鈣**、**蔓越莓**酸化尿液、**高纖**；**不要**用維生素 C 促進排鈣(草酸鈣結石)
- 慢性腎衰竭造成的是**續發性副甲狀腺機能亢進**，不是低下
- 低下：低血鈣、**高血磷**；**嗜睡**、**白內障**；**Chvostek** 與 **Trousseau** 陽性(低血鉀、低血糖不會)
- 低下的處置：**靜脈**葡萄糖酸鈣(不是口服、不是碳酸氫鈉或磷酸鹽)；床邊備**氣切包、氣管內管、喉頭鏡**；**限磷**；隨餐服**氫氧化鋁**結合磷；補充**維生素 D**(不是維生素 A)
- **副甲狀腺切除術後**口唇與手指刺麻、抽搐 → **低血鈣**
- 低下**不是**骨質疏鬆的危險因素(PTH 不足，骨鈣不會流失)；亢進才是

## 機能亢進 {#hyperparathyroidism}

| | 原發性 | 續發性 |
|---|---|---|
| 原因 | **副甲狀腺腺瘤**(多數單一顆)、增生、極少數為癌 | **慢性腎病**：腎臟無法活化維生素 D、磷排不出 → 血鈣偏低 → 副甲狀腺持續代償；也見於維生素 D 缺乏 |
| 血鈣 | **↑** | 正常或 ↓ |
| 血磷 | **↓** | **↑**(腎病) |
| 處理 | 符合條件者**副甲狀腺切除術** | 控制血磷(限磷、磷結合劑)、活性維生素 D、calcimimetic(cinacalcet)；嚴重者手術 |

- 長期續發性刺激後，副甲狀腺可能自主分泌，稱三發性
- 原發性的手術適應症(第五屆國際研討會 2022，依 Mayo Clinic 整理核對)：血鈣超過正常上限 **1 mg/dL 以上**、骨密度 **T 值 ≤−2.5** 或脊椎骨折、**腎結石**或腎鈣化、腎功能下降(eGFR <60)、尿鈣過高、**年齡 <50 歲**；有症狀者都建議手術

### 表現：骨頭、石頭、肚子、心情 {#hyper-manifestations}

| 系統 | 表現 | 原因 |
|---|---|---|
| 骨骼 | **骨痛**、**骨質疏鬆**、**病理性骨折**、囊狀骨病變 | PTH 活化蝕骨細胞，骨鈣流失 |
| 腎臟 | **腎結石**、**多尿**、**尿比重下降**、口渴、脫水 | 尿鈣多；高血鈣讓腎臟濃縮尿液的能力下降 |
| 腸胃 | **便秘**、**噁心**、嘔吐、食慾差、**消化性潰瘍**、胰臟炎 | 平滑肌活動下降；高血鈣刺激胃泌素與胃酸 |
| 神經肌肉 | **肌肉無力**、深肌腱反射減弱、倦怠、注意力差、憂鬱、嚴重時意識混亂 | 神經肌肉興奮性下降 |
| 心血管 | **心律不整**、**QT 縮短**、高血壓 | 鈣影響心肌電生理 |

- 多數病人是抽血**意外發現高血鈣**、沒有症狀
- 檢驗：血鈣 ↑、PTH ↑(或不該正常卻正常)、血磷 ↓、尿鈣 ↑；高血鈣的其他原因(癌症、臥床)見 [[calcium-phosphate#high]]

### 護理 {#hyper-nursing}

1. **水分**：每天約 **3000 mL**(無心腎禁忌時)，稀釋尿鈣、預防腎結石與脫水；記錄輸入輸出
2. **飲食**：**限鈣**(減少牛奶、乳酪等乳製品)；**高纖**改善便秘；**蔓越莓**與**酸灰性食物**(肉、蛋、穀類)讓尿液偏酸，減少鈣鹽結石
3. 避免過量**維生素 C**(代謝成草酸，增加草酸鈣結石)、維生素 D 與含鈣制酸劑；thiazide 利尿劑會減少尿鈣排出、讓血鈣更高，要避免
4. **防骨折**：鼓勵**活動**(臥床會讓骨鈣更流失)但要**防跌**；搬動輕柔；必要時用背架支托
5. 監測：心尖脈**測滿 1 分鐘**注意心律不整；毛地黃病人要小心(高血鈣增加毛地黃毒性)；意識變化
6. 副甲狀腺切除術後：照護同甲狀腺切除術(呼吸道、出血、喉返神經，見 [[hyperthyroidism#thyroidectomy]])，並**監測低血鈣**：剩下的腺體一時還沒恢復，加上骨頭大量回收鈣(**飢餓骨症候群**)，術後血鈣可能快速下降

## 功能低下 {#hypoparathyroidism}

- 原因
   1. **手術**：甲狀腺切除或頸部手術誤切副甲狀腺或傷及血流(最常見，可能是暫時或永久)
   2. 自體免疫、先天缺乏(如 DiGeorge 症候群)、頸部放射線
   3. **低血鎂**：鎂不足會讓 PTH 分泌與作用都變差；低血鎂要先補鎂，否則低血鈣補不起來
- **假性副甲狀腺功能低下**：PTH 足夠但腎臟與骨骼沒有反應，有些人合併**身材矮小、圓臉、短頸、掌骨短**；注射 PTH 後尿中 cAMP 不上升(試驗見 [[thyroid-parathyroid#parathyroid-disorders]])

### 表現 {#hypo-manifestations}

| 系統 | 表現 |
|---|---|
| 神經肌肉(興奮性 ↑) | **口周、指尖、腳趾刺麻**；肌肉痙攣、**手足抽搐**(tetany)；**Chvostek 徵象**；**Trousseau 徵象**；**喉部痙攣、喘鳴** → 呼吸道阻塞；**癲癇**發作(可能咬傷舌頭) |
| 精神 | 焦慮、易怒、**嗜睡**、意識改變 |
| 心血管 | **QT 延長**、心律不整、低血壓、心衰竭 |
| 腸胃 | 腹痛、**腹瀉**(平滑肌痙攣，不是便秘) |
| 長期 | **白內障**、**基底核鈣化**、皮膚乾粗、頭髮稀疏、指甲脆、牙齒發育不良(兒童) |
| 骨骼 | 骨密度**正常或增加**(不是骨質疏鬆) |

- **Chvostek 徵象**：輕敲耳前(顏面神經處)，同側嘴角與臉部肌肉抽動
- **Trousseau 徵象**：血壓計袖帶充氣到收縮壓以上維持約 3 分鐘，手腕屈曲、掌指關節屈曲、手指伸直併攏(**助產士手**)；比 Chvostek 更有特異性
- 兩個徵象反映的是**低血鈣**，低血鉀或低血糖不會出現
- 兒童：血鈣常 **<7 mg/dL**、手足痙攣、喉部肌肉痙攣與喘鳴；X 光**沒有**骨質疏鬆

### 急性低血鈣的處置 {#acute-hypocalcemia}

1. **靜脈**注射 **10% 葡萄糖酸鈣**(calcium gluconate)，**慢慢推**，同時**監測心電圖**；口服太慢，不用於急性期
2. 注射時確認靜脈通暢：鈣劑**外滲**會造成組織壞死；不可和**碳酸氫鈉**或**磷酸鹽**同管混合(會沉澱)；使用毛地黃者推太快易心律不整
3. 床邊備**氣管內管、喉頭鏡、氣切包**與抽吸設備，觀察喘鳴與呼吸困難
4. **癲癇與抽搐防護**：床欄加護墊、維持呼吸道通暢、環境安靜、**減少聲光刺激**
5. 低血鎂時一併補鎂
6. 重新呼吸袋讓 CO₂ 上升、減輕鹼中毒的做法，只用在**換氣過度**造成的抽搐(鹼中毒讓游離鈣下降)，不是低血鈣的主要處置

### 長期治療與護理 {#hypo-nursing}

- 慢性：**口服鈣**＋**活性維生素 D**(calcitriol)為第一線(第二屆國際指引 2022)；控制不佳者才考慮 PTH 製劑
- 目標血鈣在正常範圍**偏低**，避免**尿鈣過高**造成腎結石(依醫囑追蹤血鈣與尿鈣；確切目標值**待核對**)
- **飲食**：**高鈣、低磷**
   1. 限制**高磷**食物：**乳酪、牛奶**、**蛋黃**、肉類、堅果、全穀、可樂；牛奶鈣多但磷也多，國考答案都是限制
   2. 隨餐或飯前服**磷結合劑**(**氫氧化鋁**、碳酸鈣)，在腸道結合食物中的磷
   3. 腹瀉不適用高纖改善(低下的腸胃症狀是腹瀉，不是便秘)
- 衛教：**終身**服藥與定期抽血；認識刺麻、抽搐等低血鈣警訊並立即就醫；定期眼科檢查(白內障)
- 兒童：關心身材矮小、圓臉等外觀(假性者)對身體心像的影響；補的是**維生素 D**，不是**維生素 A**
