**腦膜炎**是包覆腦與脊髓的**軟腦膜與蜘蛛膜**發炎，典型表現是**發燒、頭痛、頸部僵硬**與意識改變。**細菌性腦膜炎**是急症，要在**幾小時內給抗生素**；**病毒性(無菌性)腦膜炎**多半自癒，只需支持療法。兩者主要靠**腦脊髓液(CSF)**區分。

## 相關生理：腦脊髓液 {#csf-physiology}

- 由**腦室的脈絡叢**產生，室管膜細胞協助調節生成與流動；經蜘蛛膜顆粒吸收回靜脈竇。
- 腦脊髓液循環或吸收受阻會造成水腦；顱內壓升高時，代償機制之一是**增加腦脊髓液吸收**。

## 腦脊髓液判讀 {#csf}

| 項目 | **正常** | **細菌性** | **病毒性(無菌性)** | 結核性、黴菌性 |
|---|---|---|---|---|
| 外觀 | **清澈**、無色 | **混濁、膿樣** | 清澈 | 清澈或微混，可呈毛玻璃狀 |
| 壓力(側臥) | **70–180 mmH₂O** | **明顯上升** | **正常或稍上升** | 上升 |
| 白血球 | 0–5/μL，淋巴球 | **大量，以嗜中性球為主** | 輕度上升，以**淋巴球**為主 | 以淋巴球為主 |
| 蛋白質 | **15–45 mg/dL** | **明顯上升** | 正常或輕度上升 | 上升 |
| 葡萄糖 | 約**血糖的 60–80%**(50–80 mg/dL) | **明顯下降**(細菌消耗) | **正常** | 下降 |
| 其他 | — | 革蘭氏染色、培養 | PCR(腸病毒、疱疹病毒) | 抗酸染色；隱球菌用**墨汁染色**、**莢膜多醣體抗原** |

- 口訣：**細菌性「糖低、蛋白高、嗜中性球多、混濁」**；**病毒性「清澈、糖正常、淋巴球」**。
- 葡萄糖只有血糖的 20–30% 屬於**異常**，常見於細菌性腦膜炎。
- **腦室外引流**造成的細菌感染也是細菌性腦膜炎，腦脊髓液**葡萄糖減少**。
- **日本腦炎**等病毒性腦炎：蛋白質**上升**，葡萄糖正常。
- 多發性硬化症的腦脊髓液會有 **IgG 上升**(寡株帶)，不是感染。

## 致病原 {#pathogens}

| 年齡或情境 | 常見致病菌 |
|---|---|
| **新生兒** | **B 族鏈球菌**、**大腸桿菌**、李斯特菌([[streptococci#streptococcus-agalactiae]]、[[gram-negative-bacteria#escherichia-coli]]、[[gram-positive-bacteria#listeria-monocytogenes]]) |
| 嬰幼兒與兒童 | **肺炎鏈球菌**、**腦膜炎雙球菌**；Hib 疫苗普及前以 **b 型流行性感冒嗜血桿菌**最常見([[gram-negative-bacteria#haemophilus-influenzae]]) |
| 青少年、年輕成人 | **腦膜炎雙球菌**(團體生活、宿舍、新兵) |
| 成人 | **肺炎鏈球菌**最常見，其次為腦膜炎雙球菌 |
| 老人、免疫低下、孕婦 | 肺炎鏈球菌、**李斯特菌**、革蘭氏陰性桿菌 |
| 神經外科術後、腦室引流 | 葡萄球菌、革蘭氏陰性桿菌 |
| **病毒性** | **腸病毒最常見**，其次是**腮腺炎病毒**(腮腺炎最常見的併發症就是無菌性腦膜炎)、疱疹病毒 |
| **黴菌性** | **新型隱球菌**(**鴿糞**、有**莢膜**；免疫低下者較常見，但免疫正常者也會感染，見 [[fungi#cryptococcus-neoformans]])；白色念珠菌**不是**最常見的黴菌性腦膜炎致病菌 |
| **嗜酸性** | **廣東住血線蟲**：吃到生的**非洲大蝸牛、蛞蝓**等陸螺感染([[helminths-ectoparasites#angiostrongylus-cantonensis]]) |
| 結核性 | 結核菌，病程亞急性([[tuberculosis]]) |

:::note[舊答案：幼童細菌性腦膜炎的主要致病原]
106-1 微免 072 的答案是**流行性感冒嗜血桿菌**，這是 Hib 疫苗普及前的情形。台灣已把 Hib 納入五合一疫苗常規接種，目前兒童細菌性腦膜炎以**肺炎鏈球菌**、腦膜炎雙球菌較常見。作答時依公布答案；題目若寫「目前」或「疫苗普及後」，就選肺炎鏈球菌([[immunization#childhood-schedule]])。
:::

## 流行性腦脊髓膜炎 {#meningococcal}

依疾管署疾病介紹(2026-03 更新)：

- 病原：**腦膜炎雙球菌**，**革蘭氏陰性雙球菌**，有**莢膜**可抗吞噬；**只感染人**，**不是人畜共通**傳染病([[gram-negative-bacteria#neisseria-meningitidis]])。
- **傳染窩**：人。健康人約 5–10% 在**鼻咽**無症狀帶菌，是主要傳染來源。
- **傳染方式**：直接接觸**喉嚨或鼻腔分泌物**，或經**飛沫**傳染；需要親密(咳嗽、親吻)或長時間接觸。**不是空氣傳染**。
- **潛伏期** 2–10 天，通常 3–4 天。
- **可傳染期**：發病前 7 天起，到**適當抗生素治療後 24 小時**。
- 好發族群：**1 歲以下嬰兒**、學生、宿舍住宿者、新兵；**無脾臟**或補體缺乏者風險高。
- 表現：發燒、頭痛、頸部僵硬，常合併**出血性皮疹(瘀點、紫斑)**；嚴重時猛爆性敗血症與腎上腺出血(Waterhouse-Friderichsen 症候群)。
- 法定傳染病**第二類**，**24 小時內**通報([[notifiable-diseases]])。
- **防護**：**飛沫防護**到有效抗生素治療滿 **24 小時**；密切接觸者依衛生單位評估給**預防性抗生素**，並監測症狀。

## 臨床表現 {#manifestations}

- **成人與兒童**：**發燒、劇烈頭痛、頸部僵硬**、畏光、噴射狀嘔吐、意識改變、痙攣。
- **嬰兒**：症狀不典型：發燒或體溫過低、躁動、嗜睡、吸吮差、**前囟門膨出**、高音調哭聲。**前囟門約 12–18 個月關閉**，3 歲兒童顱內壓升高時**不會出現囟門膨出**。
- **腦膜刺激徵象**：

| 徵象 | 做法與陽性反應 |
|---|---|
| **頸部僵硬** | 被動屈頸時有阻力、疼痛 |
| **克尼格氏徵象**(Kernig，柯林氏) | 平躺，**髖與膝屈曲 90 度**，再**伸直小腿**時產生**阻力或疼痛** |
| **布魯辛斯基氏徵象**(Brudzinski) | 平躺，**抬起頭部屈頸**時，**髖與膝不自主屈曲** |
| **角弓反張** | 頭與背部強烈後仰，嚴重時出現 |

- 不是腦膜炎徵象：**巴賓斯基氏徵象**(上運動神經元)、**Ortolani 與 Barlow 徵象**(髖關節發育不良)、**Homan 徵象**(深部靜脈栓塞)、**Romberg 測驗**(小腦與本體感覺)、**Murphy 徵象**(膽囊炎)、**Rovsing 徵象**(闌尾炎)。
- **蜘蛛膜下腔出血**也有頸部僵硬、Kernig 與 Brudzinski 陽性，因為血液刺激腦膜。
- 併發症：**顱內壓升高**、水腦、痙攣、**聽力喪失**、SIADH、敗血症與 DIC、神經學後遺症。

## 診斷：腰椎穿刺 {#lumbar-puncture}

| 項目 | 重點 |
|---|---|
| 部位 | **L3–L4 或 L4–L5** 椎間(成人脊髓末端約在 L1–L2，這個位置不會刺到脊髓)，進入**蜘蛛膜下腔** |
| 用途 | 診斷(腦脊髓液分析、細胞學、壓力)，也可**治療**：鞘內注射化學藥物，例如治療中樞神經系統白血病 |
| **禁忌** | **顱內壓升高**(可能造成**腦疝脫**)、穿刺部位感染、凝血異常；有局部神經症狀、視乳頭水腫、意識障礙或免疫低下者先做**電腦斷層** |
| **姿勢** | **側臥**、頭頸前屈、雙膝屈向胸部(蝦米狀)，背部與床面垂直；可坐姿前傾。**不是俯臥**，也不是頭高腳低 |
| 防護 | **無菌技術**；操作者戴**手套、口罩、隔離衣、護目鏡** |
| 穿刺後 | 觀察穿刺部位滲液或出血、下肢感覺運動、**腦疝脫**與感染徵象；鼓勵**多喝水** |
| **最常見合併症** | **腰椎穿刺後頭痛**(腦脊髓液滲漏；**坐起時加重、平躺緩解**)，不是腰痛 |

:::note[舊答案：腰椎穿刺後平躺 4–6 小時]
國考答案要求穿刺後**仰臥平躺 4–6 小時**以預防頭痛(108-2 兒科 080、114-2 基護 022)。「俯臥」或「頭高腳低俯臥」都不是答案。

UpToDate 與多數實證指出：穿刺後臥床**不能預防**腰椎穿刺後頭痛；有效的預防是使用**較細的針或無創傷性針頭**。發生頭痛時才平躺休息、補充水分與咖啡因，嚴重者做硬膜外血液補片。考試依國考答案作答。脊髓麻醉後頭痛的處理見產後護理：暫時平躺並補充水分。
:::

## 治療 {#treatment}

### 細菌性腦膜炎 {#bacterial-treatment}

- **急症**：抽血液培養後**立即給經驗性靜脈抗生素**，不要因為等電腦斷層或腰椎穿刺而延誤。
  - 成人常用 **ceftriaxone＋vancomycin**。
  - 50 歲以上或免疫低下者加 **ampicillin**，涵蓋李斯特菌。
  - 見 [[beta-lactams#cephalosporins]]、[[glycopeptides]]。
- 療程一般**至少 10 天**，依菌種 7–21 天。
- **Dexamethasone**：在**第一劑抗生素之前或同時**給，減少聽力喪失等神經後遺症，對肺炎鏈球菌與 Hib 腦膜炎有益。劑量計算例：10 mg/2 mL，醫囑 7 mg → 抽 **1.4 mL**。
- 控制顱內壓、痙攣與發燒；監測水分與鈉(SIADH)。

### 病毒性腦膜炎 {#viral-treatment}

- **不用抗生素**，以**支持療法、症狀治療**為主：止痛、退燒、補充水分；除非合併細菌感染才給抗生素。
- 單純疱疹病毒腦炎用 **acyclovir**([[antivirals]])。
- 預後好，**大多數沒有神經後遺症**，病程較短。

## 腦炎與腦膿瘍 {#encephalitis-abscess}

- **腦炎**：腦實質發炎，以**意識改變、行為改變、痙攣、局部神經症狀**為主。
  - **單純疱疹病毒**：最常見的散發性腦炎，侵犯**顳葉**；病毒潛伏在**神經節**的神經細胞中([[herpesviruses#herpes-simplex-virus]])。
  - **日本腦炎**：**三斑家蚊**傳播，**不會人傳人**，不需要隔離病人的血液與分泌物([[vector-borne-zoonotic#japanese-encephalitis-virus]])。
  - 腸病毒重症、狂犬病([[rna-viruses#rabies-virus]])。
- **腦膿瘍**：鄰近感染直接擴散(**鼻竇炎、中耳炎**、牙齒感染)或血行散播(**心內膜炎**)；表現為頭痛、發燒、局部神經症狀。未治療的鼻竇炎可能併發腦膜炎、腦膿瘍。
- **庫賈氏病**：普利昂蛋白引起，大腦呈**海綿狀變性**，屬第四類法定傳染病，詳見 [[prions]]。

## 護理措施 {#nursing}

1. **感染管制**：細菌性腦膜炎在找出菌種前採**飛沫防護**，腦膜炎雙球菌與 Hib 在有效抗生素治療滿 **24 小時**後可解除([[infection-control#transmission-based-precautions]])。腦膜炎**不是空氣傳染**。
2. **準時給抗生素**，療程要完整(細菌性至少 10 天靜脈注射)。
3. **監測神經學狀態**：意識(GCS)、瞳孔、生命徵象；注意**噴射狀嘔吐、躁動、認知改變**等顱內壓升高徵象。
4. **降低顱內壓**：
   - 床頭抬高 **30 度**、頭頸維持正中。
   - 避免**頭低腳高的姿位引流**、**背部叩擊與不必要的抽痰**、咳嗽與用力解便。
   - 監測**便秘**，給**高纖維飲食**或軟便劑。
   - 避免髖關節過度屈曲。
5. 提供**安靜、昏暗**的環境以減輕畏光與頭痛；**集中護理**；**不要增加環境刺激**。
6. **疼痛**：給止痛劑，用姿勢調整減輕頸部疼痛。
7. **發燒**：維持體溫正常，降低代謝與腦部耗氧。
8. **痙攣防護**：床欄加護墊，備妥抽吸與氧氣。
9. 監測**輸出入量**與血鈉；嬰兒每日測**頭圍**、觀察前囟門。
10. 出院後追蹤**聽力**與發展。
11. 預防：依時程接種 **Hib、肺炎鏈球菌**疫苗([[immunization]])；出國到流行地區可自費接種腦膜炎雙球菌疫苗。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 腦脊髓液由**脈絡叢**產生；正常**清澈**、壓力 **70–180 mmH₂O**、蛋白質 **15–45 mg/dL**、葡萄糖約**血糖的 60–80%**。
- **細菌性**：**混濁、蛋白質明顯上升、葡萄糖明顯下降**、嗜中性球多；腦室引流感染也是葡萄糖減少。
- **病毒性(無菌性)**：**清澈**、壓力**正常或稍上升**、淋巴球、葡萄糖**正常**(葡萄糖 30 mg/dL 不符合)；治療是**支持療法**，**不給抗生素**，**多數無後遺症**；最常見病因是**腸病毒**與**腮腺炎病毒**。
- 新生兒細菌性腦膜炎：**大腸桿菌**(與 B 族鏈球菌)；幼童：國考答案是**流感嗜血桿菌**。
- 腦膜炎雙球菌：有莢膜、**飛沫**傳染、**出血性皮疹**；**不是人畜共通**。
- 新型隱球菌：**鴿糞**、**莢膜多醣體抗原**快速診斷、造成黴菌性腦膜炎；免疫正常者也可能感染。
- 腦膜刺激：**Kernig**(屈髖屈膝 90 度後伸直小腿有阻力疼痛)、**Brudzinski**(屈頸時髖膝屈曲)、**頸部僵硬**、角弓反張；**Ortolani、Homan 不是**。
- 3 歲兒童顱內壓升高**不會有前囟門膨出**。
- 腦膜炎合併顱內壓升高：**不要背部叩擊、抽痰、頭低腳高**；預防便秘、高纖飲食；環境要**安靜**，不要增加刺激。
- 腰椎穿刺：**L3–L4**(或 L4–L5)；**顱內壓升高時不宜**；採**側臥屈曲**，**不是俯臥**或頭高腳低；最常見合併症是**頭痛**不是腰痛；國考答案是穿刺後**仰臥平躺 4–6 小時**、多喝水；操作防護要**手套、口罩、隔離衣、護目鏡**。
- 日本腦炎：**三斑家蚊**；不需要隔離病人的血液與分泌物；腦脊髓液**蛋白質上升**。
- 嗜酸性腦膜炎：**廣東住血線蟲**，吃生**陸螺、蛞蝓**感染。
