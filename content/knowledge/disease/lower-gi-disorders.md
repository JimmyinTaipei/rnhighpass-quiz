下消化道指屈氏韌帶以下的小腸、大腸、直腸與肛門。本頁整理闌尾炎與腹膜炎、發炎性腸道疾病、吸收不良與乳糜瀉、腸阻塞與腸繫膜缺血、腹壁疝氣、憩室與梅克爾氏憩室、大腸息肉、痔瘡與肛門疾病；構造見 [[gi-anatomy-physiology]]，用藥見 [[gi-drugs]]，大腸癌與腸造口見 [[colorectal-cancer]]，便秘、灌腸與坐浴見 [[bowel-elimination]] 與 [[heat-cold-therapy]]，感染性腹瀉見 [[infectious-diarrhea]]

## 重點摘要 {#summary}

- **闌尾炎**：先**肚臍周圍**痛、噁心食慾差，再轉到**右下腹麥氏點**；徵象有 **Rovsing**、**腰大肌**、**閉孔肌**、反彈痛；術前**禁食、不熱敷、不灌腸、不給瀉劑**；術後早期下床、**6 週內不提重物**
- **腹膜炎**：持續腹痛、**腹肌僵硬如木板**、**壓痛與反彈痛**、**腸音減少**、叩診鼓音；早期體溫可正常，敗血症時體溫反而可能下降
- **發炎性腸道疾病(IBD，Inflammatory bowel disease)**：**潰瘍性結腸炎**從直腸往上**連續**、只侵犯**黏膜與黏膜下層**、**血便與裡急後重**、毒性巨結腸症、癌化風險高；**克隆氏症**好發**迴腸末端**、**跳躍**病灶、**全層**、**非乾酪性肉芽腫**、鵝卵石外觀、**狹窄、瘻管**、脂肪痢
- **吸收不良**：脂肪 → 脂肪痢與脂溶性維生素缺乏；蛋白質 → **體重下降**與水腫；**乳糜瀉**是對**麩質**(小麥、大麥、黑麥，燕麥常被汙染)的自體免疫反應，飲食改用米、玉米
- **腸阻塞**：**腹部絞痛、嘔吐、腹脹、不排便不排氣**；體液積在腸腔加上嘔吐 → **循環血量減少、低血壓**、**低鈉低鉀低氯**；早期腸音**增加**(高音調)，晚期才消失
- **疝氣**：**腹股溝疝氣最常見**；**絞窄性疝氣**是急症；術後**托高陰囊加冰敷**、預防便秘與咳嗽用力、暫不提重物
- **痔瘡**：以**齒狀線**分內痔(無痛、鮮血)與外痔(痛)；原因是**腹壓與靜脈回流受阻**(便秘、懷孕、久站久坐、門脈高壓)；術後**側臥或俯臥**、**監測解尿(尿瀦留)**、**12 小時後**才溫水坐浴、**初期低渣**、第一次解便要有人陪

### 國考常考點 {#exam-points}

- 闌尾炎徵象：**麥氏點壓痛**、**Rovsing(壓左下腹、右下腹痛)**、**腰大肌**、**閉孔肌**、Blumberg(反彈痛)；**Murphy 是膽囊炎**、**Turner／Cullen 是出血性胰臟炎**、Kernig 是腦膜炎
- 闌尾炎護理：右下腹**不可熱敷**、術前**不灌腸**、術後**鼓勵下床**(不是臥床)、有引流管採**半坐臥**(不是平躺)、術後 **6 週內避免提重物**；兒童腹肌不自主僵硬如木板要懷疑**腹膜炎**
- 腹膜炎：**腹肌僵硬**、**壓痛與反彈痛**、腸蠕動**降低**、叩診**鼓音**(不是實音)；「體溫持續上升」是錯的(敗血症時可下降)；原發性常見致病菌為**革蘭氏陽性鏈球菌**
- 潰瘍性結腸炎：**裡急後重**、**糞便經常帶血**、腹瀉合併大量**血與膿樣黏液**；**不**侵犯全腸壁、**不**易形成肛門瘻管、**不**產生肉芽腫；是大腸癌危險因子
- 克隆氏症：**全層侵犯使腸壁增厚**、**非連續**病灶、好發**迴腸末端**也會侵犯結腸、**鵝卵石**、**肉芽腫(非乾酪性)**、**比潰瘍性結腸炎易狹窄**；潰瘍深(不是表淺)、腸壁增厚(不是變薄)；**侵犯小腸**與脂肪痢是克隆氏症的特點
- IBD 可能與**感染、食物過敏**、免疫與遺傳有關；好發年輕人、男女相近、**歐美比東方常見**
- 吸收不良：**蛋白質吸收不良 → 體重下降**
- 乳糜瀉是**麩質**引起的**自體免疫**腸病變，不適合吃**燕麥片**，可吃米飯、玉米、蛋
- 惡性貧血與自體免疫、**胃切除**有關，須終生補充 **B12**；「骨髓切片確定診斷」是錯的
- 小腸阻塞：**嘔吐頻率增加**、嘔吐物可有**糞臭**、可見強蠕動波、**鈉鉀氯降低**；腸阻塞**不會腹瀉**、**不會高血壓**；循環血量減少 → **低血壓**、尿量**減少**
- 腸阻塞灌腸採**膝胸臥式**
- 全腸壁梗塞最主要原因是**腸繫膜動脈急性阻塞**
- 腹股溝疝氣嚴重時壓迫**精索** → 睪丸血流受阻；術後**陰囊支托**、**多吃蔬果預防便秘**；不熱敷、肥胖者應減重、不可立即搬重物
- 憩室炎併發症：**膿瘍、出血、瘻管**(不是胰臟炎)
- 梅克爾氏憩室最常見的異位組織是**胃黏膜**
- **增生性息肉是非贅瘤性**；腺瘤越大、絨毛成分越多越容易癌化
- 痔瘡原因：便秘、**懷孕**、**肝硬化(門脈高壓)**、久站；**動脈粥狀硬化不是**；痔瘡、食道靜脈曲張、下肢靜脈曲張都是**靜脈曲張**，囊性水瘤是**淋巴管**異常
- 第二產程**用力不當**會使痔瘡變大
- 痔瘡術後：**定時監測解尿型態**、側臥或俯臥、**8 小時內 2 塊以上敷料浸濕表示出血**；「立即溫水坐浴」「冰水坐浴」「初期高纖維」是錯的
- 內外痔分界是**齒狀線**；內痔區由**自主神經**支配(不痛)、外痔區由**體感覺神經**支配(痛)
- 肛門瘻管術後併發症：**出血、瘻管復發、解便失禁**；**便秘最少見**

## 闌尾炎 {#appendicitis}

- 原因：闌尾腔被**糞石**、淋巴組織增生或異物阻塞 → 細菌繁殖、腫脹缺血 → 穿孔與**腹膜炎**
- 好發 10–30 歲；典型病程是**肚臍周圍或上腹痛**、噁心嘔吐、食慾不振，數小時後轉移到**右下腹**，可有輕微發燒、白血球上升

| 徵象 | 做法與陽性表現 | 意義 |
|---|---|---|
| **麥氏點壓痛** | 肚臍與右前上腸骨棘連線外 1/3 處壓痛 | 闌尾炎最典型 |
| **Rovsing 徵象(洛夫辛)** | 壓**左下腹** → **右下腹**痛 | 闌尾炎 |
| **腰大肌徵象(Psoas)** | 右髖對抗阻力屈曲或向後伸展時右下腹痛 | 闌尾貼近腰大肌 |
| **閉孔肌徵象(Obturator)** | 右髖屈曲後**向內旋轉**時下腹痛 | 骨盆位闌尾 |
| **反彈痛(Blumberg)** | 壓下後**突然放手**更痛 | 腹膜受刺激(腹膜炎) |
| Murphy 徵象 | 壓右上腹時吸氣中斷 | **膽囊炎**，不是闌尾炎 |
| Cullen／Grey Turner(透納氏)徵象 | 肚臍周圍／腰側瘀青 | **出血性胰臟炎** |

- 術前護理
   1. **禁食**、靜脈輸液；採**半坐臥**讓發炎局限在下腹
   2. **不可熱敷**(加速發炎與穿孔)、**不可灌腸或給瀉劑**(增加腸蠕動與腸壓 → 穿孔)
   3. 持續評估疼痛與腹部：疼痛**突然緩解**後又全腹痛、腹肌**僵硬如木板**要懷疑**穿孔與腹膜炎**
- 術後護理
   1. **早期下床**促進腸蠕動與預防肺部合併症；有引流管採**半坐臥**(不是平躺)以利引流
   2. 觀察傷口有無紅、腫、熱、痛；腸蠕動恢復後由流質漸進
   3. 出院指導：術後約 **6 週內避免提重物**與劇烈運動(109-1_MS_008 答案)
- 兒童闌尾炎：表達不清、穿孔率較高；術前禁食所以**不給口服**止痛藥，術後要評估腹膜炎徵象

## 腹膜炎 {#peritonitis}

| 類型 | 原因 |
|---|---|
| 原發性(找不到腹腔病灶) | 肝硬化腹水感染(自發性細菌性腹膜炎)、**鏈球菌(革蘭氏陽性)**、肺炎球菌，經血液或淋巴進入(課本書頁 402) |
| 續發性(最常見) | **闌尾炎穿孔**、消化性潰瘍穿孔、憩室炎、IBD、腸扭結、膽囊炎、胰臟炎、骨盆腔感染、手術吻合處滲漏 |

- 臨床表徵
   1. **持續腹痛**，從局部擴大到全腹；嘔吐隨病程越來越明顯
   2. 觸診**壓痛與反彈痛**，嚴重時**腹肌僵硬如木板**；聽診**腸蠕動音降低或消失**；腹脹叩診**鼓音**
   3. 體溫：早期可正常，菌血症時上升；**敗血症時體溫可能下降、脈搏上升**，表示很嚴重(課本書頁 401)
   4. 白血球上升、代謝性酸中毒
- 處置：禁食、**鼻胃管減壓**、輸液、抗生素、手術修補或引流；半坐臥讓膿液局限在骨盆腔

## 發炎性腸道疾病 {#ibd}

- 原因未明，與**遺傳、免疫失調、腸道菌與感染、飲食(食物過敏)**有關；好發**青少年與年輕成人**、男女相近；**歐美較常見**，台灣與亞洲發生率逐年上升

| 比較 | 潰瘍性結腸炎(UC，Ulcerative colitis) | 克隆氏症(CD，Crohn disease，區域性腸炎) |
|---|---|---|
| 部位 | **直腸開始往近端延伸**，只在**大腸** | **口到肛門都可能**，最常見**迴腸末端**，也會侵犯結腸 |
| 分布 | **連續性** | **跳躍性**(病灶之間有正常黏膜) |
| 深度 | **黏膜與黏膜下層**，潰瘍淺 | **全層**，潰瘍深、裂隙 |
| 外觀 | 偽息肉、黏膜易出血 | **鵝卵石**狀、**腸壁增厚** |
| 病理 | 隱窩膿瘍，**沒有肉芽腫** | **非乾酪性肉芽腫** |
| 症狀 | **血便**、腹瀉合併**血與膿樣黏液**、**裡急後重** | 右下腹痛、腹瀉、**脂肪痢**、體重減輕、營養不良，血便較少 |
| 合併症 | **毒性巨結腸症**、出血、**大腸癌風險較高** | **狹窄與腸阻塞**、**瘻管**、肛門周圍膿瘍與**肛門瘻管**、吸收不良(B12、膽鹽) |
| 手術 | 全結腸直腸切除可治癒 | 無法根治，術後易復發 |

- 兩者都會有**腹瀉與營養缺乏**，也都可能有腸道外表現(關節炎、皮膚、眼睛、原發性硬化性膽管炎)
- 腹瀉合併大量血與膿樣黏液 → 先想**潰瘍性結腸炎**；腸激躁症沒有血便
- 治療目標是**不靠類固醇的長期緩解**與黏膜癒合(ACG 2025，二手)；藥物：5-ASA(5-aminosalicylic acid，mesalamine，輕中度 UC 第一線)、類固醇(誘導緩解，不長期用)、免疫調節劑、生物製劑(TNF-α，Tumor necrosis factor-α，抑制劑 infliximab、adalimumab)、小分子 JAK(Janus kinase)抑制劑 tofacitinib；細節見 [[gi-drugs#ibd-drugs]]
- 護理
   1. 急性期腸道休息，必要時管灌或全靜脈營養；緩解後**高熱量、高蛋白、低渣**，少量多餐，避免咖啡因、酒精、辛辣與菸
   2. 記錄排便次數與性狀、輸出入量、體重；肛門周圍皮膚清潔與保護
   3. 減輕壓力，教導按時服藥與副作用；需要時做腸造口(見 [[colorectal-cancer#ostomy]])

## 吸收不良與乳糜瀉 {#malabsorption}

- 原因：消化酵素不足(慢性胰臟炎、膽汁不足)、吸收面積減少(小腸切除、克隆氏症、乳糜瀉)、乳糖酶缺乏

| 吸收不良的營養素 | 表現 |
|---|---|
| 脂肪 | **脂肪痢**(油亮、浮起、惡臭)、脂溶性維生素 A、D、E、K 缺乏(夜盲、骨質軟化、出血傾向) |
| 蛋白質 | **體重下降**、肌肉萎縮、**低白蛋白水腫** |
| 碳水化合物(乳糖) | 腹脹、排氣多、**水樣腹瀉** |
| 鐵、葉酸 | 小球性或巨球性貧血、舌炎 |
| 維生素 B12 | **巨球性貧血**、周邊神經病變(需要內在因子與**迴腸末端**) |
| 鈣、鎂 | 手足抽搐、骨質疏鬆 |

- **惡性貧血**：自體免疫破壞壁細胞 → 缺內在因子 → B12 吸收不良；**胃切除**後也會發生；要**終生補充 B12**(注射)；診斷靠血中 B12、抗內在因子與抗壁細胞抗體，不靠骨髓切片(貧血細節留血液輪)
- **乳糜瀉(粥狀瀉，Celiac disease)**
   1. 遺傳體質的人吃到**麩質**(小麥、大麥、黑麥的蛋白質)引起**自體免疫**反應 → 小腸絨毛萎縮 → 吸收不良
   2. 表現：慢性腹瀉、脂肪痢、腹脹、生長遲緩；不是血便
   3. 治療：**終生無麩質飲食**；**燕麥**常被小麥汙染，國考視為不適合；可吃**米、玉米、蛋**、肉、蔬果；不用抗生素

::questions{ids="110-1_MS_009,113-2_MS_021,111-1_OP_073,113-3_OP_045"}

## 腸阻塞與腸繫膜缺血 {#obstruction}

| 類型 | 原因 |
|---|---|
| 機械性 | 腸腔內(糞石、膽石、異物)、腸壁(腫瘤、先天閉鎖、IBD 狹窄)、腸外(**手術後粘連**最常見、**絞窄性疝氣**、**腸扭結**、**腸套疊**) |
| 非機械性(麻痺性) | **腹部手術後**最常見、腹膜炎、低血鉀、抗膽鹼藥、脊髓損傷 |

- 年齡：兒童多為先天(腸套疊、閉鎖、疝氣)，成人以**手術後粘連**、老人以**大腸腫瘤**較常見(課本書頁 417)
- 機轉：腸液與電解質積在腸腔、加上嘔吐 → **脫水**、**低鈉、低鉀、低氯** → **循環血量減少、低血壓、尿量減少**；腸壓升高使腸壁缺血、細菌穿透 → 壞死、腹膜炎、敗血症；體液移動的原理見 [[fluid-electrolytes#volume-deficit]]
- 四大症狀：**腹部絞痛**、**嘔吐**、**腹脹**、**不排便不排氣**(不會腹瀉)

| 比較 | 小腸(高位)阻塞 | 大腸(低位)阻塞 |
|---|---|---|
| 嘔吐 | **早而頻繁**、量多，可為膽汁或**糞臭味** | 晚出現或沒有 |
| 腹脹 | 較輕 | **明顯** |
| 疼痛 | 陣發性絞痛，可見蠕動波 | 較輕、持續 |
| 酸鹼 | 胃液流失 → 代謝性鹼中毒 | 較晚出現代謝性酸中毒 |

- 腸音：早期**增加、高音調**(腸子用力推擠)，晚期或麻痺性才**減少或消失**
- 處置：**禁食**、**鼻胃管減壓**、輸液矯正電解質、監測輸出入量與腹圍；絞窄或完全阻塞要手術
- 灌腸若需要時採**膝胸臥式**(107-1_FA_031)
- **急性腸繫膜缺血**：**腸繫膜動脈急性阻塞**(心房顫動的血栓最常見)造成全腸壁梗塞；好發 60 歲以上，**腹痛比壓痛嚴重**，死亡率高

::questions{ids="114-3_MS_006,111-1_MS_009,108-2_MS_010,106-2_MS_016,105-2_MS_003,115-2_MS_006,107-1_FA_031,107-2_BM_042"}

## 腹壁疝氣 {#hernia}

| 種類 | 重點 |
|---|---|
| **間接性腹股溝疝氣** | **最常見**，男性多；經**腹股溝內環**沿**精索**(女性為圓韌帶)下降，可到陰囊；多為**先天**鞘狀突未閉合，嬰兒與年輕人 |
| 直接性腹股溝疝氣 | 直接穿過腹股溝**後壁**，腹壁肌肉無力，**老年人**(慢性咳嗽、攝護腺肥大、便秘使腹壓上升) |
| 股疝氣 | 經股環，**女性**較多，易絞窄 |
| 臍疝氣 | 嬰兒多見(見 [[pediatric-gi#hernia]])；成人見於肥胖、懷孕、腹水 |
| 切口疝氣 | 舊手術切口；肥胖、營養不良、傷口感染 |
| **絞窄性疝氣** | 推不回去、血流受阻 → 腸阻塞、腸壞死，**急症** |

- 嚴重的腹股溝疝氣會壓迫**精索**，使睪丸血流受阻
- 表現：站立、咳嗽、用力時鼓出，平躺時可推回；突然劇痛、推不回、嘔吐要懷疑絞窄
- 術後護理
   1. 咳嗽或打噴嚏時用手或枕頭**壓住傷口**
   2. 男性腹股溝修補後易**陰囊水腫**：用軟枕**托高陰囊**並**冰敷**(不是熱敷)
   3. 排尿困難時男性可**站立解尿**
   4. **多吃蔬果、喝水預防便秘**，必要時軟便劑；避免用力、咳嗽、提重物(課本寫 2 週內避免增加腹壓的活動；搬運工要延後回到粗重工作)
   5. 肥胖會增加復發，**應減重**

## 憩室與梅克爾氏憩室 {#diverticular}

- **憩室症**：大腸黏膜從肌層弱點向外突出，多在**乙狀結腸**；與**低纖維飲食**、便秘、腸內壓高、年紀大有關
- **憩室炎**：憩室內糞便滯留發炎 → 左下腹痛、發燒；併發症是**膿瘍**、**出血**、**瘻管**、穿孔與腹膜炎、狹窄(**不是胰臟炎**)
   1. 急性期禁食或清流質、抗生素；緩解後**高纖維**飲食預防復發
- **梅克爾氏憩室(Meckel diverticulum)**：卵黃管殘留，位於**迴腸**；最常見的異位組織是**胃黏膜**(分泌胃酸 → 潰瘍、**無痛性直腸出血**)，其次是胰臟組織
   1. 「2 的規則」：約 2% 人口、離迴盲瓣約 2 呎、長約 2 吋、多在 2 歲前出現症狀

::questions{ids="109-2_MS_011,110-2_BM_040"}

## 大腸息肉 {#polyps}

| 類型 | 性質 |
|---|---|
| **增生性息肉** | **非贅瘤性**，最常見，幾乎不會癌化 |
| 發炎性(偽)息肉 | 非贅瘤性，見於 IBD |
| 幼年型、普杰氏(Peutz-Jeghers)息肉 | **錯構瘤**(非贅瘤性)，但 Peutz-Jeghers 症候群全身癌症風險增加 |

## 痔瘡 {#hemorrhoids}

::figure{src="/knowledge-images/servier-hemorrhoids.svg" labels="hemorrhoids" alt="直腸肛門縱切面：齒狀線以上的內痔靜脈叢與脫垂的內痔，齒狀線以下的外痔靜脈叢與外痔"}

- 定義：肛門的痔靜脈叢**靜脈曲張**；與食道靜脈曲張、下肢靜脈曲張機轉相同(靜脈回流受阻、壓力上升)
- 原因：**長期便秘或腹瀉**、**懷孕**(子宮壓迫、第二產程**用力不當**)、**久站久坐**、遺傳、**門脈高壓(肝硬化)**、直腸腫瘤；動脈粥狀硬化**不是**原因

| 比較 | 內痔 | 外痔 |
|---|---|---|
| 位置 | **齒狀線以上** | **齒狀線以下** |
| 神經 | **自主神經** → **不痛** | **體感覺神經** → **疼痛**、腫脹 |
| 主要表現 | **解便時鮮紅色出血**、脫垂 | 疼痛、腫塊、栓塞時劇痛 |

- 內痔分度與處置(課本書頁 410–411)

| 分度 | 表現 | 處置 |
|---|---|---|
| 第一度 | 出血、不脫垂 | 高纖飲食、軟便劑、硬化治療 |
| 第二度 | 解便時脫出，**會自己縮回** | 硬化治療、橡皮筋結紮、紅外線凝固 |
| 第三度 | 脫出後要**用手推回** | 橡皮筋結紮、紅外線凝固 |
| 第四度 | **推不回**或推回又脫出 | 痔瘡切除術、痔瘡環狀切除(PPH，Procedure for prolapse and hemorrhoids) |

- 非手術護理：高纖維、多喝水、定時排便、不久蹲；**溫水坐浴**減輕疼痛與腫脹(做法見 [[heat-cold-therapy#heat-methods]])；長期出血會**缺鐵性貧血**
- 痔瘡切除術後護理
   1. 姿勢：**側臥或俯臥**，避免壓迫肛門傷口；手術時多採**截刀式臥姿**
   2. **尿瀦留**最常見：每 2 小時評估解尿型態與膀胱脹；先誘尿，超過時間無法解尿依醫囑導尿
   3. 出血：術後 24 小時內與術後 7–10 天容易出血；**8 小時內 2 塊以上會陰敷料浸濕**表示出血過多
   4. 疼痛：止痛劑或局部麻醉藥膏；術後 **12 小時後**才開始**溫水坐浴**，每天 2–3 次(不是立即坐浴，也不用冰水坐浴)
   5. 飲食：**初期軟質低渣**，之後再改**高纖維**並配合軟便劑
   6. **第一次解便要有人陪**，避免疼痛與出血引起昏倒
- 產後痔瘡：側臥評估、溫水坐浴、多喝水與高纖飲食，**不要減少進食**

## 肛門裂隙與肛門瘻管 {#anal-fissure-fistula}

- **肛門裂隙(肛裂)**：硬便撕裂肛管上皮，多在**後正中線**；**解便時劇痛**與少量鮮血；處置：軟便劑、容積性瀉劑、高纖、**溫水坐浴**，無效再做內括約肌切開
- **肛門瘻管**：肛門腺體隱窩感染形成**膿瘍**，破出到肛門周圍皮膚成為管道；也見於**克隆氏症**；表現是肛門旁持續有膿樣或血色分泌物、搔癢
   1. 處置：瘻管切開術或掛線(橡皮筋逐步收緊)
   2. 術後併發症：**出血**、**瘻管復發**、**解便失禁**(傷到外括約肌)；**便秘最少見**
   3. 護理：止痛、軟便劑、高纖飲食、**排便後坐浴**保持清潔
