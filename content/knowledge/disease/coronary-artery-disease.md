冠狀動脈疾病是**冠狀動脈粥狀硬化**使心肌的血液供應不足所引起的一群疾病,從活動時才胸悶的**穩定型心絞痛**,到斑塊破裂、血栓阻塞造成的**急性冠心症**(不穩定型心絞痛、心肌梗塞)。心肌梗塞時「**時間就是心肌**」:越早打通血管,存活的心肌越多,所以辨認症狀、10 分鐘內完成心電圖與縮短再灌流時間是照護重點。

本頁依「生理 → 病理 → 分類 → 症狀與轉移痛 → 檢查 → 緊急處理 → 併發症 → 藥物 → 心導管與手術 → 護理 → 心臟復健 → 預防」排列。心電圖判讀細節見 [[ecg]]。

## 冠狀動脈的正常生理 {#physiology}

### 冠狀動脈與供應區域 {#coronary-anatomy}

- 左、右冠狀動脈由**升主動脈根部**(主動脈瓣上方的主動脈竇)發出,不是主動脈弓。
- **左冠狀動脈主幹**很快分成:
  - **左前降支(LAD)**:沿前室間溝往心尖 → 供應**左心室前壁、心室中膈前 2/3、心尖**。阻塞時梗塞面積大,俗稱「寡婦製造者」。
  - **左迴旋支(LCx)**:沿左房室溝往後 → 供應**左心室側壁**、部分後壁。
- **右冠狀動脈(RCA)**:沿右房室溝往後 → 供應**右心室、左心室下壁**;約 85% 的人由 RCA 分出**後降支**(右優勢型);也供應 **SA 結**(約 60%)與 **AV 結**(約 85–90%)——所以**下壁梗塞常合併心搏過緩、房室傳導阻滯**。

![[ecg#territory]]

### 心肌氧氣的供給與需求 {#oxygen-balance}

![[coronary-circulation#oxygen-demand]]

- 冠狀動脈主要在**舒張期**灌流(收縮期心肌收縮擠壓血管,左心室心內膜下最明顯)→ 心跳越快、舒張期越短,供血越少;這也是 **β 阻斷劑**「減慢心跳 → 延長舒張期灌流」能改善缺血的原因。
- 心肌在休息時就已經抽取血中約 70–75% 的氧,需求增加時只能靠**增加冠狀動脈血流**——血管狹窄時這條路被卡住,就出現缺血。
- 詳細見 [[coronary-circulation]]。

## 病因與病理生理 {#pathophysiology}

### 危險因子 {#risk-factors}

| 無法改變 | 可以改變 |
|---|---|
| **年齡**(男 ≥ 45 歲、女 ≥ 55 歲或停經後) | **高血脂**(LDL↑、HDL↓、TG↑) |
| **男性**(停經前女性有雌激素保護) | **高血壓** |
| **早發性冠心病家族史**(一等親男 < 55、女 < 65 歲發病) | **吸菸**(含二手菸、電子菸) |
| | **糖尿病**、代謝症候群、肥胖(尤其腹部肥胖) |
| | 缺乏運動、不健康飲食、過量飲酒、心理壓力、慢性腎臟病 |

- **性別差異**:雄性素使 LDL↑、HDL↓;女性**停經後**雌激素下降 → HDL↓、LDL↑、TG↑、血小板凝集與纖維蛋白原↑,風險快速追上男性。
- **吸菸**:尼古丁 → 血管收縮、心跳與血壓上升 → 心肌耗氧↑;**一氧化碳**與血紅素結合 → 攜氧能力**下降**;損傷內皮、促進血栓。
- HDL **偏高**是保護因子;嚼檳榔主要與口腔癌相關,不列入冠心病傳統危險因子。
- 個案判斷題要逐項比對數值:例如空腹血糖 96–99 mg/dL 屬正常,**不算**危險因子。

### 動脈粥狀硬化 {#atherosclerosis}

1. **內皮損傷**:高血壓的剪力、吸菸毒素、高血糖、氧化的 LDL。
2. **脂質進入內膜並被氧化** → 吸引單核球變成巨噬細胞,吞下脂質成為**泡沫細胞** → **脂肪紋**(最早的病灶,年輕時就開始)。
3. **平滑肌細胞增生**、分泌膠原 → 形成**纖維帽**包住脂質核心 → **纖維粥狀斑塊**。
4. 斑塊慢慢長大使管腔狹窄;狹窄 > 70% 時,活動增加需氧就供應不足 → **穩定型心絞痛**。
5. **斑塊破裂或侵蝕**(纖維帽薄、脂質核心大、發炎多的「不穩定斑塊」最容易破)→ 暴露脂質與膠原 → **血小板黏附凝集** → **血栓**形成 → 突然部分或完全阻塞 → **急性冠心症**。

急性心肌梗塞最常見的原因就是**粥狀斑塊破裂 + 血栓**;冠狀動脈痙攣、栓塞、血管炎較少見。粥狀硬化最常侵犯**腹主動脈**、冠狀動脈、頸動脈、下肢動脈,腹主動脈瘤多由此造成。

### 缺血、損傷與梗塞 {#ischemia-injury-infarction}

| 程度 | 心肌狀態 | 可逆嗎 | 心電圖 |
|---|---|---|---|
| **缺血**(ischemia) | 氧氣供不應求 | **可逆**(約 20 分鐘內恢復血流) | ST 下降、T 波倒置 |
| **損傷**(injury) | 細胞受損中 | 及時再灌流可救回 | **ST 上升** |
| **梗塞**(infarction) | 心肌**壞死** | **不可逆** | **病理性 Q 波** |

缺氧的心肌改用無氧代謝 → **乳酸**堆積刺激神經末梢 → 疼痛;收縮力也在數十秒內下降。完全阻塞後約 20–40 分鐘心內膜下開始壞死,3–6 小時內壞死向外擴展到全層——這是「越早打通越好」的根據。

### 心肌梗塞的病理變化時序 {#pathology-timeline}

| 時間 | 肉眼 | 顯微鏡 |
|---|---|---|
| **0–4 小時** | **無變化** | 光學顯微鏡**看不出**(電子顯微鏡可見粒線體腫脹) |
| 4–12 小時 | 可能有斑駁 | 心肌**波浪狀纖維**、開始凝固性壞死 |
| 12–24 小時 | 暗紅斑駁 | **凝固性壞死**、核固縮、收縮帶 |
| **1–3 天** | 黃褐色梗塞中心 | **嗜中性球**浸潤 |
| **3–7 天** | 周圍充血邊緣 | **巨噬細胞**吞噬壞死組織 → 組織最軟弱,**心臟破裂風險最高** |
| 7–10 天 | 黃色軟化、凹陷 | **肉芽組織**形成 |
| **2–8 週** | 灰白疤痕 | **纖維化**(膠原沉積) |
| > 2 個月 | 疤痕完成 | 緻密纖維疤痕 |

心肌細胞**不能再生**,壞死後由**結締組織(疤痕)**取代,不能收縮。

## 分類 {#classification}

### 穩定型心絞痛 {#stable-angina}

**固定狹窄**的冠狀動脈在**需氧增加**時供應不足。

- **誘因**:勞動、爬樓梯、快走、**用力解便**、情緒激動、寒冷、飽餐、性行為。
- **特徵**:胸骨後壓迫感,持續**短暫**(通常 **< 15–20 分鐘**,多為 2–5 分鐘),**休息或舌下硝化甘油可緩解**;每次誘因與程度相似、可預期。
- 心電圖:發作時 **ST 下降**,平時可正常。

### 變異型心絞痛(Prinzmetal) {#variant-angina}

- **冠狀動脈痙攣**造成,與活動**無關**,常在**休息、半夜或清晨**發作;抽菸、古柯鹼、寒冷可誘發。
- 發作時心電圖 **ST 上升**(短暫的全層缺血),緩解後恢復。
- 治療首選 **鈣離子阻斷劑**與**硝酸鹽**;**不宜單用 β 阻斷劑**(α 受體作用失去對抗,可能加重痙攣)。見 [[calcium-channel-blockers]]。

### 急性冠心症(ACS) {#acs}

斑塊破裂 + 血栓造成的急性缺血,依心電圖與心肌生化標記分為三種:

![[ecg#acs-ecg]]

| | 不穩定型心絞痛(UA) | NSTEMI | STEMI |
|---|---|---|---|
| 血管 | 部分阻塞 | 部分阻塞(或短暫完全阻塞) | **完全阻塞** |
| 症狀 | 休息時也發作、新發生、或頻率強度越來越增加 | 同左,通常更久 | 持續胸痛 > 20–30 分鐘 |
| 心肌壞死 | **無** | 有(**心內膜下**) | 有(**全層**) |
| Troponin | **正常** | **上升** | **上升** |
| 處置重點 | 抗血小板、抗凝、依風險安排心導管 | 同左 | **立即再灌流**(不必等 troponin) |

- UA 是心肌梗塞的**前兆**,需要住院處理;與 NSTEMI 的心電圖可以完全相同,要靠 troponin 區分。
- 看到 ST 上升就要啟動再灌流流程,**不可等酵素結果**。
- **第 2 型心肌梗塞**:不是斑塊破裂,而是氧氣供需失衡(嚴重貧血、低血壓、心搏過速、呼吸衰竭)造成心肌壞死,處理原因為主。

## 臨床表現 {#manifestations}

### 典型胸痛 {#chest-pain}

- **部位**:胸骨後或心前區,範圍大、手掌或拳頭大小(病人常握拳放在胸前——Levine 徵象),不是一根手指指得出來的點。
- **性質**:**壓迫感、緊縮感、沉重感、悶痛**、燒灼感,很少是刺痛。
- **放射**:左肩、**左手臂內側**(尺側)到小指、頸部、**下顎**、牙齒、背部(肩胛骨間)、上腹部;也可放射到右側或雙臂。
- **伴隨症狀**:**冒冷汗**、臉色蒼白、噁心嘔吐、呼吸困難、頭暈、心悸、焦慮、瀕死感。

### 轉移痛:為什麼痛在手臂 {#referred-pain}

![心肌缺血的轉移痛部位](/knowledge-images/mi-referred-pain.svg)

心臟的內臟感覺神經(隨交感神經)經 **T1–T4(T5)** 脊髓節段進入脊髓,和**胸壁、左臂內側皮膚**的體感覺神經匯聚在同一群脊髓神經元上;大腦習慣把這條路徑的訊號解讀為「皮膚」來的,於是覺得痛在手臂或胸壁。頸部、下顎與肩膀則與 C3–C5 的匯聚有關。

其他器官的轉移痛(常一起考):**肝膽 → 右肩**(橫膈刺激經膈神經 C3–C5)、**腎臟/輸尿管 → 腰背與鼠蹊部**、闌尾 → 臍周、胰臟 → 背部。

### 非典型表現 {#atypical}

- **女性、老年人、糖尿病人**(自主神經病變)、慢性腎臟病人常**沒有典型胸痛**,只有呼吸困難、極度疲倦、噁心、上腹不適、意識混亂或暈厥 → 容易被延誤。
- **無痛性(沉默性)心肌梗塞**:糖尿病人尤其常見,可能只在心電圖出現陳舊性 Q 波時才發現。
- **下壁 MI** 常表現為**上腹痛、噁心嘔吐**,易被誤認為胃痛;也常合併心搏過緩與低血壓(迷走神經興奮、右心室梗塞)。

### 心絞痛與心肌梗塞比較 {#angina-vs-mi}

| | 穩定型心絞痛 | 急性心肌梗塞 |
|---|---|---|
| 誘因 | 勞動、情緒、寒冷、飽餐 | 可無誘因,常在**清晨**、休息時發生 |
| 持續時間 | **短**(< 15–20 分鐘,多數數分鐘) | **> 20–30 分鐘**,可達數小時 |
| **休息或 NTG** | **可緩解** | **無法緩解** |
| 伴隨症狀 | 較少 | **冒冷汗**、噁心嘔吐、呼吸困難、瀕死感 |
| 生命徵象 | 多正常或短暫上升 | 血壓可**下降**、心律不整、低灌流 |
| 心電圖 | 發作時 ST 下降 | ST 上升 → Q 波(STEMI) |
| Troponin | 正常 | **上升** |

胸痛鑑別:**主動脈剝離**(撕裂樣、放射到背部、兩臂血壓差大)、**肺栓塞**(突發呼吸困難、肋膜痛、下肢 DVT)、**張力性氣胸**、**心包膜炎**(尖銳痛,**前傾坐起減輕**、平躺深吸氣加重)、胃食道逆流、肌肉骨骼痛。

:::exam[國考重點]
- 胸痛「**持續超過 20–30 分鐘、休息與 NTG 無法緩解、合併冒冷汗**」→ 懷疑心肌梗塞。
- 心臟轉移痛 → **左手臂內側**;肝膽 → **右肩**。
- 多位病人同時需要處理時,**胸悶合併放射痛、冒冷汗**的病人最優先(立即做心電圖)。
- 用餐時突然嗆咳、無法說話 → 呼吸道異物梗塞,不是心肌梗塞。
:::

## 檢查 {#diagnosis}

### 12 導程心電圖 {#ecg}

胸痛病人**首次醫療接觸後 10 分鐘內**完成並判讀 12 導程心電圖;第一張無法確診而臨床仍懷疑時,每 15–30 分鐘重複。完整判讀見 [[ecg]]。

### 心肌生化標記 {#biomarkers}

心肌細胞壞死、細胞膜破裂後,細胞內的蛋白質漏到血液中;**troponin** 是心肌特有,是診斷心肌梗塞的首選(為什麼會升高、偏高偏低的意義見 [[cardiac-biomarkers]])。

![[cardiac-biomarkers#timeline]]

- 心肌梗塞的診斷(第四版全球定義):**troponin 上升和/或下降**且至少一次高於第 99 百分位,**加上**缺血的證據(症狀、新的心電圖變化、病理性 Q 波、影像顯示新的心肌壞死、或冠狀動脈攝影看到血栓)。
- 高敏感度 troponin 採 **0 小時/1–2 小時**重複抽血,看**動態變化**。
- 其他:心肌梗塞後白血球與 CRP 上升、紅血球沉降速率上升(發炎反應);電解質(**鉀、鎂**過低增加心律不整);血脂、血糖、HbA1c、腎功能(準備顯影劑)。
- 國考仍考的舊標記:**LDH**(24–48 小時上升、持續 10–14 天;心肌梗塞時 **LDH1 > LDH2**,稱「翻轉」)、AST。

### 其他檢查 {#other-tests}

| 檢查 | 原理 | 看到什麼 | 護理重點 |
|---|---|---|---|
| **運動心電圖**(跑步機) | 增加心肌需氧,誘發缺血 | 運動中 ST 下降、胸痛、血壓下降 → 陽性;評估心肌**缺氧**與活動耐力 | 檢查前 2–4 小時禁食、不抽菸不喝咖啡;穿舒適鞋子;依醫囑停用 β 阻斷劑等;出現胸痛、頭暈、ST 明顯變化即停止。**不能**評估心輸出量;急性 MI、不穩定型心絞痛禁做 |
| **藥物負荷試驗** | 無法運動者用 dobutamine(增加需氧)或 dipyridamole/adenosine/regadenoson(擴張正常血管,造成「盜血」) | 配合超音波或核醫 | dipyridamole/adenosine 前 **12–24 小時避免咖啡因**(拮抗藥效);氣喘者慎用 adenosine |
| **心肌灌注掃描**(鉈-201、Tc-99m) | 放射性物質隨血流進入**有灌流**的心肌 | 缺血區在負荷時缺損、休息時回填;梗塞區永久缺損 → **確定心肌受損部位與範圍** | 少量放射線,多喝水排出;孕婦避免 |
| **心臟超音波** | 超音波 | **局部室壁運動異常**、EF、併發症(乳突肌斷裂、心室中膈破裂、心包膜積液) | [[echocardiography]] |
| **冠狀動脈電腦斷層** | 顯影劑 + CT | 冠狀動脈狹窄、鈣化分數 | 心跳需慢(可能給 β 阻斷劑)、顯影劑過敏與腎功能 |
| **心導管冠狀動脈攝影** | 導管注射顯影劑 | 狹窄位置與程度,**診斷黃金標準**,同時可治療 | [[cardiac-catheterization]] |
| **24 小時心電圖**(Holter) | 攜帶式記錄 | 無症狀缺血、心律不整 | 記錄活動與症狀日誌,不可洗澡 |

- **瓣膜**看心臟超音波、**傳導**看心電圖、**心肌灌流與受損範圍**看核醫灌注掃描、**冠狀動脈狹窄**看心導管。

## 緊急處理 {#emergency}

### 院外處理(一般民眾,僅供參考) {#prehospital}

以下為衛教民眾的原則,依 2025 AHA 指引整理;實際處置以救護人員與醫師為準。

1. 胸痛或胸悶**超過 5 分鐘**、或合併冒冷汗、呼吸困難 → **立即撥打 119**,不要自行開車就醫(救護車可沿途做心電圖、事先通知醫院啟動心導管室,也能處理心跳停止)。
2. 停止活動,**坐下或半躺**休息,鬆開衣物。
3. 醫師曾開立**舌下硝化甘油**者:坐下後含 1 顆;**5 分鐘仍未緩解或更痛 → 立即撥 119**,之後可每 5 分鐘再含 1 顆,**最多 3 顆**(舊衛教是「3 顆無效才就醫」,現行強調第一顆無效就叫救護車)。見 [[nitrates#sublingual]]。
4. 無過敏、無出血問題、未被醫師禁止者,救護人員或醫師可能請病人**嚼服 aspirin**(160–325 mg;嚼碎吸收較快)。民眾不宜在未經指示下自行給藥。
5. 病人**失去意識、沒有正常呼吸** → 立即 **CPR** 並使用 **AED**。

### 院內處理:急性冠心症流程 {#in-hospital}

依 2025 AHA ACLS 急性冠心症流程與 2025 ACC/AHA ACS 指引:

**到院後 10 分鐘內**

- **12 導程心電圖**(10 分鐘內完成判讀)、連續心電監測、備妥**去顫器**。
- 生命徵象、SpO₂;建立**靜脈輸液管路**;抽血(troponin、電解質、凝血功能、CBC、腎功能)。
- 簡短病史與身體評估:胸痛特徵與**開始時間**(決定再灌流方式)、血栓溶解劑禁忌症、**24–48 小時內有無使用 PDE5 抑制劑**(sildenafil 等)。
- **胸部 X 光**可做但**不可延誤**送心導管室。

**初始藥物**

| 處置 | 現行建議 | 舊觀念(MONA) |
|---|---|---|
| **Aspirin** | **162–325 mg 嚼服**(非腸溶或嚼碎),之後每日低劑量 | 同 |
| **氧氣** | 只在 **SpO₂ < 90%**、呼吸窘迫或心衰竭時給 | 所有病人鼻導管 2–4 L/min |
| **硝化甘油** | 舌下每 5 分鐘一次、最多 3 次,持續胸痛、高血壓、心衰竭可改靜脈;**收縮壓 < 90 mmHg、心跳 < 50 或 > 100、右心室梗塞、24–48 小時內用過 PDE5 抑制劑者禁用** | 同 |
| **嗎啡** | NTG 無效的胸痛**才考慮**(可延遲口服 P2Y12 抑制劑吸收、掩蓋症狀),也可用 fentanyl | 常規給予:止痛、減焦慮、擴張靜脈降前負荷、減少心肌耗氧 |
| **P2Y12 抑制劑** | ticagrelor、clopidogrel、prasugrel,與 aspirin 合用(雙重抗血小板) | — |
| **抗凝血劑** | heparin(監測 **aPTT**)、enoxaparin、bivalirudin、fondaparinux | — |
| **β 阻斷劑** | 無心衰竭、低心輸出、休克、心搏過緩或傳導阻滯時,24 小時內開始口服 | — |
| **高強度 statin** | 儘早開始(atorvastatin 40–80 mg、rosuvastatin 20–40 mg) | — |

- **MONA**(Morphine、Oxygen、Nitroglycerin、Aspirin)是傳統口訣,國考仍常出現;目前指引已**不再**以此作為常規,答題時注意題目要的是傳統還是現行觀念。
- **鎮靜劑**:焦慮的急性胸痛病人,先做心電圖、給氧(需要時)與止痛,不應自行給 lorazepam 等靜脈鎮靜劑。

**再灌流治療(STEMI)**

| 方式 | 時間目標 |
|---|---|
| **直接經皮冠狀動脈介入治療(Primary PCI)**——首選 | **首次醫療接觸到導管打通 ≤ 90 分鐘**(需轉院者 ≤ 120 分鐘) |
| **血栓溶解劑**——無法在 120 分鐘內做 PCI、症狀開始 **12 小時內** | **到院到給藥(door-to-needle)≤ 30 分鐘**;給藥後 3–24 小時內仍應轉送做心導管 |

- 症狀超過 12 小時但仍有缺血、心因性休克者,仍考慮 PCI。
- NSTEMI/UA:依風險分層,高風險(血行動力不穩定、持續胸痛、致命心律不整)**立即**(2 小時內)心導管,其他多在 24–72 小時內。
- 血栓溶解劑的禁忌與護理見 [[thrombolytics]]。

![[ecg#stemi-nursing]]

**急性期一般護理**

- **臥床休息**(最初 12–24 小時,病情穩定後漸進活動);**半坐臥**(降前負荷、利呼吸)——「平躺可降低心臟負荷」是錯的。
- 連續心電監測(**心律不整是心肌梗塞早期最常見的死因**,尤其心室顫動,多在發病後數小時內)。
- 疼痛評估(部位、性質、強度、持續時間),給藥後評估效果;每次胸痛再發都要做心電圖。
- 生命徵象、SpO₂、肺音(心衰竭)、尿量(心輸出量)、意識、末梢循環。
- 避免 **Valsalva**:給**軟便劑**;急性期使用床上便盆時,先**溫熱便盆**、由護理人員協助翻身放置,不讓病人自己用力抬臀;穩定後改用床旁便盆椅。
- 飲食:急性期**清淡、易消化、少量多餐**、**限鈉**(避免水分滯留、減輕心臟負荷)、避免過冷過熱與咖啡因。
- 心理:焦慮會增加交感刺激與耗氧;解釋檢查與治療、讓病人參與決定、同理回應,不應為了休息而限制家屬探視。

## 併發症 {#complications}

| 併發症 | 時間 | 表現與重點 |
|---|---|---|
| **心律不整** | **最早、最常見**(發病數小時內) | 心室早期收縮、**心室心搏過速/顫動**(早期死亡主因)、下壁 MI 合併**心搏過緩、房室傳導阻滯**(RCA 供應 SA/AV 結) |
| **心衰竭、肺水腫** | 數小時到數天 | 大範圍前壁 MI;呼吸困難、囉音、S3。見 [[heart-failure]] |
| **心因性休克** | 多在 24–48 小時內 | 左心室 ≥ 40% 壞死;低血壓、濕冷、少尿;CVP、PCWP 上升;緊急 PCI、升壓強心劑、IABP。見 [[heart-failure#cardiogenic-shock]] |
| **右心室梗塞** | 與下壁 MI 同時 | 低血壓、頸靜脈怒張、**肺音清澈**;需要**足夠輸液**維持前負荷,**避免 NTG、嗎啡、利尿劑** |
| **乳突肌斷裂** | **3–5 天** | 突發**急性二尖瓣逆流** → 新的收縮期雜音、急性肺水腫 |
| **心室中膈破裂** | 3–5 天 | 新的全收縮期雜音、心因性休克 |
| **心室游離壁破裂** | **3–7 天**(巨噬細胞期) | 心包膜填塞(低血壓、頸靜脈怒張、心音遙遠)→ 猝死 |
| 左心室室壁瘤、附壁血栓 | 數週 | 心衰竭、心律不整、**栓塞**(中風)→ 需抗凝血劑 |
| **心包膜炎** | 早期 1–3 天 | 尖銳胸痛,坐起前傾減輕、心包膜摩擦音 |
| **Dressler 症候群** | **數週後**(2–10 週) | 自體免疫性心包膜炎:發燒、胸痛、摩擦音;以 NSAIDs(aspirin)或 colchicine 治療 |
| 再梗塞、梗塞後心絞痛 | 任何時候 | 再次胸痛要重做心電圖與 troponin |

- 心肌梗塞使心輸出量下降,也可能造成**腎前性急性腎損傷**。
- 需要**長期抗凝血劑**的情形:心房顫動、左心室附壁血栓、機械瓣膜。

## 心導管與手術治療 {#revascularization}

### 心導管與 PCI {#pci}

![[cardiac-catheterization#pci]]

術前準備與術後護理(穿刺部位、遠端循環、制動時間)見 [[cardiac-catheterization#preparation]] 與 [[cardiac-catheterization#post-care]]。

- **支架置放後**需持續服用**雙重抗血小板**(aspirin + P2Y12 抑制劑,一般約 12 個月,之後通常終身 aspirin 或單一抗血小板);**不可自行停藥**(支架內血栓 → 再梗塞)。病人想停藥時,先**傾聽原因**、個別化說明,不要責備或恐嚇。

### 冠狀動脈繞道手術(CABG) {#cabg}

![[cardiac-catheterization#cabg]]

**術後護理重點**:

- **胸管引流**:每小時記錄量與顏色;**> 100 mL/h** 需注意凝血功能,**> 200 mL/h**(或連續 2–3 小時 > 150 mL/h)屬異常出血,立即通知醫師;注意心包膜填塞(引流突然減少、血壓下降、頸靜脈怒張)。
- **凝血**:heparin 殘留用 **protamine** 中和;PT 延長給**維生素 K** 或新鮮冷凍血漿。
- **維持心輸出量**:dobutamine 增加收縮力、furosemide 降前負荷、nitroglycerin 擴張靜脈降前負荷、nitroprusside 同時降前後負荷;監測尿量與**血鉀**。
- 術後發燒**不可用 aspirin 退燒**(增加出血),改用 acetaminophen(但術後 aspirin 抗血小板仍依醫囑持續)。
- 疼痛控制、深呼吸咳嗽(抱枕支托胸骨)、早期下床;胸骨傷口 6–8 週內避免提重物、推拉與開車。
- 醫囑判讀:「Pethidine 50 mg IM **st.**」= **立即給一次**,不可重複。

## 護理 {#nursing}

### 常見護理問題 {#nursing-diagnoses}

| 護理問題 | 相關因素 | 措施重點 |
|---|---|---|
| **急性疼痛** | 心肌缺血、缺氧 | 評估疼痛(PQRST)、依醫囑 NTG/止痛、給氧(SpO₂ < 90%)、臥床休息、心電圖 |
| **心輸出量減少** | 心肌壞死、心律不整 | 心電監測、生命徵象、尿量、肺音、末梢循環;依醫囑給藥 |
| 潛在危險性心律不整 | 心肌缺血、電解質不平衡 | 連續監測、備去顫器、監測血鉀血鎂 |
| **活動無耐力** | 心輸出量↓、耗氧與供氧失衡 | 漸進式活動、監測活動反應(見 [[#cardiac-rehab]]) |
| 潛在危險性出血 | 抗血小板、抗凝、溶栓 | 監測穿刺部位、牙齦、尿便、神經學徵象;減少侵入性處置 |
| **焦慮/恐懼** | 瀕死感、加護環境 | 陪伴、說明、讓病人參與決策 |
| 知識缺失 | 新診斷、複雜藥物 | 出院衛教 |

### 住院與出院 {#admission-discharge}

- 入院護理評估:生命徵象、健康史、環境介紹;**治療飲食由醫師開立**,護理師負責執行與衛教。
- 家屬提供的資料屬**主觀資料**;護理師觀察與量測的屬客觀資料。
- **出院準備自入院就開始**;出院後病床單位做**終末消毒**(不需無菌技術)。
- **出院衛教**:用藥(雙重抗血小板、statin、β 阻斷劑、NTG 隨身攜帶與使用方法)、胸痛時的處理流程、危險因子控制、活動與性生活、參加心臟復健、回診時間。

## 心臟復健 {#cardiac-rehab}

心臟復健是**多專業整合**的計畫(運動訓練、危險因子控制、營養、心理支持、衛教、戒菸),能降低死亡與再住院;心肌梗塞、PCI、CABG、穩定型心絞痛、心衰竭病人都應轉介。

### 分期 {#rehab-phases}

| 分期 | 時間與地點 | 內容 |
|---|---|---|
| **第一期**(住院期) | 住院中 | 床上關節運動 → 坐起 → 床旁站立 → 室內行走 → 走廊行走 → 爬樓梯;約 1–2 MET 開始;衛教與出院準備 |
| **第二期**(門診監測期) | 出院後約 **1–3 個月**(常見 36 次) | 醫院中心監測下的有氧運動與阻力訓練,依運動測試結果開立運動處方 |
| **第三期**(維持期) | 終身 | 居家或社區自行運動、維持健康生活型態 |

### 活動監測與停止指標 {#activity-monitoring}

活動中或活動後出現下列情況,**停止**活動並報告:

- 心跳比休息時**增加 > 20 次/分**(部分教材以增加 20–25% 為界)、或心跳反而下降。
- **收縮壓上升 > 20–40 mmHg** 或**下降 > 10 mmHg**。
- 胸痛、呼吸困難、頭暈、**冒冷汗**、臉色蒼白、極度疲倦。
- 新出現心律不整、心電圖 ST 變化。
- 輕微體溫上升本身不是停止活動的指標。

### 代謝當量(MET) {#met}

以 **MET**(代謝當量)選擇活動強度:**1 MET = 休息時耗氧 3.5 mL O₂/kg/min**。

| 活動 | 約 MET |
|---|---|
| 躺、坐、進食、盥洗 | 1–2 |
| 慢走(每小時 3 公里)、淋浴、穿衣 | 2–3 |
| **性行為**(與熟悉伴侶)、中速走路 | 3–4 |
| **爬兩層樓梯**、騎腳踏車、園藝 | 4–5 |
| 慢跑、游泳 | 7 以上 |

- 能**爬兩層樓梯不喘、無胸痛**,大致可以恢復性生活。
- MI 後恢復性生活:選在休息充足時、熟悉的環境與伴侶、室溫適中;**避免飽餐或飲酒後**;醫師許可者可在**事前**預防性含 NTG(服用 PDE5 抑制劑者不可);出現胸痛即停止。

### 運動原則 {#exercise}

- 以**等張(有氧)運動**為主:走路、騎腳踏車、游泳、太極;避免**等長運動**(提重物、推重物)與**閉氣用力**(Valsalva)。
- 每次先**暖身 5–10 分鐘**、運動 20–30 分鐘、再緩和 5–10 分鐘;每週 3–5 次。
- **飯後 1–2 小時**再運動;避免極冷極熱環境。
- **目標心跳**:初期約為最大心跳(220 − 年齡)的 **60–70%**,之後依運動測試漸進到 70–85%;或以休息心跳 + 20–30 次/分作為住院期上限;服用 β 阻斷劑者心跳上升受限,可用**自覺費力程度**(Borg 量表約 11–13,「有點累」)評估。

## 預防 {#prevention}

### 初級預防:控制危險因子 {#primary-prevention}

- **血脂**:LDL 目標依風險分層;無冠心病的一般族群從生活型態開始,新發現高血脂(非極端值)先**調整生活 3–6 個月**再評估用藥。數值與目標見 [[lipid-profile]]。

![[lipid-profile#targets]]

- **高血壓**、**糖尿病**控制:見 [[hypertension]]、[[diabetes]]。
- **戒菸**:最有效的單一措施之一;戒菸 1 年後冠心病風險約降一半。
- **體重與腰圍**:BMI 18.5–24、腰圍男 < 90、女 < 80 cm。
- **運動**:每週 **150 分鐘中等強度**或 75 分鐘費力有氧運動;規律運動**降低 TG、LDL,提升 HDL**。
- **飲食**:
  - 地中海飲食或 DASH:蔬果、全穀、豆類、堅果、魚、橄欖油。
  - **飽和脂肪 < 10%** 總熱量、避免**反式脂肪**;烹調以**清蒸、水煮、烤**取代油炸、油煎、快炒。
  - **高纖**(燕麥、大麥、豆類、蔬果):可溶性纖維在腸道結合膽酸,增加膽固醇排出。
  - 膳食膽固醇:國考常用「每日 **< 300 mg**」;美國 2015 年後的飲食指南已取消明確上限,改為「儘量少吃」,台灣衛教仍常用 300 mg。
  - 不以「降膽固醇飲料」代替飲水、不以不吃早餐減重。

### 次級預防:已有冠心病 {#secondary-prevention}

- 藥物:**抗血小板**(終身 aspirin 或 P2Y12)、**高強度 statin**(LDL 目標 < 70,極高風險 < 55 mg/dL)、β 阻斷劑(EF 下降或心衰竭者)、ACEI/ARB(EF ≤ 40%、高血壓、糖尿病、CKD)。
- 隨身攜帶**舌下 NTG**並知道使用方法。
- 參加**心臟復健**。
- 血壓 < 130/80、糖尿病 HbA1c 約 < 7%。
- 每年接種**流感疫苗**。
- 心理:憂鬱在心肌梗塞後很常見,會增加死亡率,要篩檢與轉介。

### 三段五級 {#prevention-levels}

| 段/級 | 冠心病的例子 |
|---|---|
| 初段:促進健康 | 健康飲食、規律運動、不吸菸的衛教 |
| 初段:特殊保護 | 高血壓、高血脂、糖尿病者的危險因子控制;高危險群戒菸 |
| 次段:早期診斷、早期治療 | 成人預防保健(血脂、血糖、血壓)、胸痛及早就醫、10 分鐘內心電圖 |
| 三段:限制殘障 | 再灌流治療、次級預防用藥、預防併發症 |
| 三段:復健 | **心臟復健**、重返工作 |
