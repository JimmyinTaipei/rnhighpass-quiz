這一頁整理兒科常考的神經疾病。兒童腦膜炎與腦炎見 [[cns-infections]]，熱性痙攣見 [[pediatric-respiratory-infections#febrile-seizure]]，兒童癲癇見 [[epilepsy#children]]，兒童顱內壓升高與 GCS 見 [[increased-icp#children]] 與 [[neuro-assessment#pediatric-gcs]]，兒童腦瘤見 [[pediatric-cancers]]，妥瑞氏症見 [[child-adolescent-mental-health]]

## 重點摘要 {#summary}

- **腦性麻痺**：出生前、產程中或出生後早期**發育中的腦受損**(缺氧最常見)，造成**非進行性**的動作與姿勢障礙；**痙攣型**(錐體路徑，張力高、反射亢進)最常見；**不是都有智能障礙**；目標是**增進功能、預防殘障加重、促進生長發展**
- 腦性麻痺進食：**坐直、頭正中略前傾、肩膀前屈、髖膝約 90 度、雙腳有支撐**；食物放在**舌頭後方或兩側**(放前方會被吐舌反射推出來)；下顎控制、增稠液體、**鼓勵用輔具自己吃**
- **水腦**：腦脊髓液過多 → 嬰兒**頭圍快速增加**、**前囟門膨出**、骨縫分開、頭皮靜脈擴張、**落日眼**、**尖聲哭**、嘔吐、躁動
- **V-P shunt** 術後：觀察**顱內壓升高**(=分流管**阻塞**)與**發燒、沿管路紅腫**(=**感染**)；每天量頭圍、摸囟門；不可俯臥壓傷口
- **神經管缺陷**：隱性脊柱裂 → 脊髓膜膨出(囊內只有腦膜與腦脊髓液) → **脊髓脊髓膜膨出**(囊內有脊髓或神經，常合併**水腦**、下肢癱瘓、神經性膀胱)；術前**俯臥**、囊上蓋**無菌生理食鹽水濕紗**、保護囊不被糞便污染、髖關節外展；預防靠**懷孕前開始補充葉酸**
- **早產兒腦室內出血**：生發基質血管脆弱；床頭抬高 15–30 度、頭部正中、**集中照護減少打擾**、避免血壓劇烈波動；觀察囟門與頭圍(可能續發水腦)；**鼓勵父母探視**
- **雷氏症候群**：病毒感染(流感、水痘)時用 **aspirin** 引起；急性**腦病變＋肝功能障礙**；早期主要是**持續嘔吐**；肝指數與**血氨上升**、PT 延長、**低血糖**、腦水腫

### 國考常考點 {#exam-points}

- 腦性麻痺：缺氧是出生前與產程中最常見的原因；**非進行性**運動障礙；痙攣型**伸展反射、深部肌腱反射、張力增加**；**智能障礙不是主要問題、不是全部都有**；語言訓練**及早**開始
- 痙攣型：**伸展反射增加**(不是不自主扭動、不是肌腱反射降低)；徐動型是**基底核**受損的**不自主運動**(不是雙下肢麻痺)；運動失調型是小腦
- 腦性麻痺治療目標：**增進運動功能、預防殘障加重**；不是病毒造成(那是小兒麻痺)
- 進食：**食物放舌頭後方**；**坐起身體正中**；不要頭後仰、肩後傾、雙腳懸空；膝蓋不要低於大腿；食物不要高於嘴巴；**不要完全由照顧者餵食**；不要給流質(用增稠劑)；三指下顎控制法可用
- 15 個月大輕度腦性麻痺：主要護理是**促進成長及發展**；家庭評估重點是支持系統、情緒反應、對疾病的認知(**家人未來目標不是目前重點**)；24 個月的發展任務**不包括增強痛覺反應**
- 水腦 V-P shunt 術後：記錄頭圍、摸囟門、觀察意識與顱內壓、管路處勿碰撞擠壓；**紅腫熱是感染不是阻塞**；觀察**噴射狀嘔吐、尖聲哭**；**不要水平俯臥**；**可以抱起餵奶**
- V-P shunt 術後第 5 天哭鬧不喝奶、發燒 38.2°C → 優先做**感染評估**
- 頭圍測量：經**眉毛上方**與**枕骨隆突**繞一圈(不是經耳垂)
- 脊髓脊髓膜膨出合併水腦的術前：**不可垂頭俯臥**；腿部外展防髖脫位；軟奶嘴小孔；保持會陰乾淨避免糞便污染囊
- 脊髓脊髓膜膨出術後：觀察腦膜炎徵象、被動運動與按摩防攣縮、監測哭聲與頭圍；**不需要**特別昏暗的環境
- 早產兒腦室內出血：床頭抬高 15–20 度、監測血壓與血比容、觀察囟門與頭圍；**不要限制家屬探視**；**集中照護減少打擾**(床頭不是 45 度、不要聲光刺激、不給高張溶液)
- 腦室內出血發生在**生發基質**脆弱血管破裂
- 雷氏症候群**早期**的主要徵象：**嘔吐**(去大腦僵直、反射消失是晚期)
- 葉酸：懷孕前開始補充、可預防**脊柱裂**、易被高溫與紫外線破壞；**深綠色蔬菜**是代表來源
- 新生兒反射：擁抱反射是四肢**對稱外展伸直**；頸部強直反射是**臉轉向那側的手腳伸直**、對側屈曲；尋乳反射是**頭轉向刺激側、張嘴**；巴賓斯基是**大拇趾背屈、其他腳趾扇形張開**
- 10 個月大仍存在的反射：**巴賓斯基反射**(驚嚇、抓握、踏步都已消失)

## 腦性麻痺 {#cerebral-palsy}

- **定義**：胎兒期、產程或出生後早期(約 2 歲前)**發育中的腦受損**，造成**非進行性**的動作與姿勢障礙；腦損傷不會惡化，但隨成長可能出現攣縮與變形
- **原因**：出生前最常見(子宮內缺氧、感染、腦部發育異常)；產程中缺氧；**早產**與低出生體重、早產兒腦室內出血與腦室周圍白質軟化；新生兒**核黃疸**；出生後腦膜炎、頭部外傷
- **分型**

| 類型 | 受損位置 | 表現 |
|---|---|---|
| **痙攣型**(最常見) | **錐體路徑**(運動皮質) | **張力高**、**深部肌腱反射與伸展反射亢進**、陣攣、Babinski 陽性；**剪刀步態**、用腳尖走路；依部位分偏癱、雙下肢癱、四肢癱 |
| **運動困難型**(含**徐動型**) | **基底核**、錐體外路徑 | **不自主的扭動**、張力忽高忽低、流口水、說話困難；影響書寫等精細動作 |
| **運動失調型** | **小腦** | 平衡與協調差、步態寬而不穩、意向性顫抖 |
| 混合型 | | 兼有以上 |

- **合併問題**：**粗動作發展遲緩**(最普遍)、**語言與發音困難**、吞嚥與咀嚼困難、**智能障礙**(約一半有，**不是全部**)、癲癇、斜視與視力問題、聽力障礙、便秘、骨質疏鬆、攣縮與髖脫位；**痛覺通常正常**
- **治療目標**：**增進運動功能**、**預防攣縮與殘障加重**、**促進最大程度的生長發展與獨立**；無法治癒
  1. 物理、職能、**語言治療**及早開始；支架、輔具、輪椅
  2. 痙攣：baclofen、**肉毒桿菌毒素**局部注射、手術(肌腱延長、選擇性脊神經後根切斷)
- **進食護理**
  1. **坐直**、身體正中，**頭稍微前傾**(下巴微收)，**肩膀前屈**，髖與膝約 90 度、**雙腳踩在地上或腳踏板**
  2. 食物放在**舌頭後方或兩側**：放在舌尖會引發**吐舌反射**把食物推出
  3. 餵食者的湯匙與眼睛和孩子**同高或略低**，避免孩子仰頭
  4. **三指下顎控制法**：協助閉嘴、穩定下顎、促進咀嚼
  5. 稀的液體用**增稠劑**；不要只給流質
  6. 張力高與不自主動作消耗熱量多 → **高熱量**飲食；監測體重
  7. **鼓勵使用輔具**(彎柄湯匙、防滑碗)學習自己吃
- **家庭**：剛確診時評估家庭的**支持系統與資源**、**對診斷的情緒反應**、**對疾病的認知**；教導居家復健；避免過度保護
- 幼兒期的發展任務：促進**自理能力**、建立**正向身體心像**、提供活動所需的額外熱量

## 水腦 {#hydrocephalus}

- **原因**：腦脊髓液**製造過多、流動受阻或吸收不良**
  1. **阻塞性**(非交通性)：中腦導水管狹窄最常見、腫瘤、Chiari II 畸形(脊髓脊髓膜膨出)
  2. **交通性**：蜘蛛膜絨毛吸收不良(腦膜炎、腦室內出血後)
- **嬰兒表現**(骨縫未閉合，頭會變大)
  1. **頭圍快速增加**、**前囟門膨出緊繃**、**骨縫分開**、頭皮靜脈擴張、前額突出
  2. **落日眼**(眼球往下，上方露出眼白)
  3. **尖聲哭**、躁動、餵食差、**噴射狀嘔吐**、嗜睡
  4. 晚期：痙攣、呼吸與心跳變慢
- 較大兒童：頭痛、嘔吐、視乳突水腫、步態與學業改變(見 [[increased-icp#children]])
- **頭圍測量**：用軟尺經**眉毛上方**與**枕骨隆突**繞頭一圈，每天同一時間、同一位置
- **治療**：**腦室腹膜分流術(V-P shunt)**，把腦室的腦脊髓液經皮下導管引到腹腔；或內視鏡第三腦室造廔
- **V-P shunt 術後護理**
  1. 姿勢依醫囑：初期常平躺或躺向**非手術側**，避免壓到分流閥與傷口；**不要水平俯臥**
  2. **可以抱起餵奶**(依醫囑抬高床頭的角度)
  3. **阻塞或功能不良**：**顱內壓升高**徵象再出現(囟門膨出、頭圍增加、噴射狀嘔吐、尖聲哭、嗜睡、躁動)
  4. **感染**(術後數週內最常見)：**發燒**、沿管路**紅腫熱痛**、哭鬧不喝奶、腹痛；術後幾天出現發燒要**優先評估感染**
  5. 每天量**頭圍**、摸**囟門**；觀察意識與生命徵象
  6. 傷口保持乾燥；分流管處不要碰撞擠壓；未經醫囑**不要按壓**分流閥
  7. 衛教：分流管需定期追蹤，成長時可能需要更換；教家長辨認阻塞與感染
- 分流管感染時移除，暫時改用腦室外引流(見 [[icp-monitoring]])

## 神經管缺陷 {#neural-tube-defects}

- 胚胎第 3–4 週神經管沒有閉合；**懷孕前與懷孕早期補充葉酸**可大幅減少發生

| 類型 | 內容 | 表現 |
|---|---|---|
| **隱性脊柱裂** | 椎弓沒閉合，**沒有膨出** | 腰薦部皮膚**小凹、毛叢**、血管瘤；多數沒症狀 |
| **脊髓膜膨出** | 囊內只有**腦脊髓膜與腦脊髓液** | 神經功能多正常 |
| **脊髓脊髓膜膨出** | 囊內有**脊髓或神經根** | 病灶以下**弛緩性癱瘓**、感覺喪失、**神經性膀胱與腸道**、髖脫位與足部變形；**80–90% 合併水腦**(Chiari II) |
| 無腦兒 | 頭端神經管未閉合 | 無法存活 |

- 兩種膨出都屬囊性脊柱裂；考題常考兩者的差別，所以不要混為一談
- 產前篩檢：母血與羊水的**甲型胎兒蛋白**升高、超音波
- **術前護理**(出生後盡快手術)
  1. **俯臥**或側臥，**頭部平放**，**不可垂頭**(會加重水腦與顱內壓)
  2. 囊上覆蓋**無菌、以溫生理食鹽水浸濕的紗布**，保持濕潤，避免破裂與感染
  3. 囊下方墊隔離，**避免尿布與糞便污染**；保持臀部與會陰乾淨
  4. 兩腿間墊小枕使**髖關節外展**，預防髖脫位
  5. 測量**頭圍**、觀察囟門(水腦)
  6. 俯臥餵奶不易，可用**軟、小孔的奶嘴**，減少吞入空氣
  7. 從出生就採**無乳膠**照護(反覆手術與導尿，乳膠過敏機率高)
- **術後護理**：觀察**腦膜炎**徵象與神經功能、**監測哭聲與頭圍**(水腦)、傷口保護、**被動運動與按摩**預防攣縮、膀胱(間歇導尿)與腸道訓練；長期復健與家庭支持
- **葉酸**
  1. 從**懷孕前**開始補充，持續到懷孕早期
  2. 曾生過神經管缺陷孩子的婦女需要較高劑量(依醫囑)
  3. 來源：**深綠色蔬菜**、肝臟、酵母、豆類、柑橘；屬水溶性 B 群，**易被高溫與紫外線破壞**
  4. 國健署建議：育齡婦女每天 **400 微克**；備孕婦女從**懷孕前 1 個月**到懷孕期間每天 **600 微克**；每天至少 1–2 碗深綠色蔬菜，必要時依醫師指示用補充劑(來源：[國健署葉酸新聞稿](https://www.mohw.gov.tw/cp-16-81835-1.html))

## 早產兒腦室內出血 {#ivh}

- 懷孕 32 週以前出生的早產兒，腦室旁的**生發基質**血管脆弱，血壓或血流波動時容易破裂出血；多發生在出生後**數天內**
- 危險因子：越早產、呼吸窘迫、低血壓或血壓劇烈起伏、氣胸、快速輸液或高張溶液、頻繁處置
- 表現：可能沒有症狀，嚴重時活動力差、呼吸暫停、**血比容下降**、**血壓下降**、囟門膨出、痙攣；以**頭部超音波**診斷
- 併發症：**出血後水腦**、腦室周圍白質軟化、**腦性麻痺**
- **護理**
  1. 床頭抬高約 **15–30 度**、**頭部保持正中**，避免頭部過度轉向與頭低腳高
  2. **集中照護**、減少不必要的打擾，動作輕柔
  3. 環境**安靜、光線柔和**，減少聲光刺激
  4. 避免血壓劇烈波動：輸液速度依醫囑，**避免快速推注高張溶液**；疼痛控制
  5. 監測血壓、**血比容**、囟門、**頭圍**
  6. **鼓勵父母探視與參與照顧**(洗手即可)，不要限制探視
- 早產兒的其他問題(呼吸窘迫、視網膜病變、壞死性腸炎)之後在兒科與產科輪整理

## 雷氏症候群 {#reye-syndrome}

- 兒童在**病毒感染**(流行性感冒、**水痘**)期間或之後**使用 aspirin**，引發急性**腦病變**與**肝臟脂肪變性**
- **表現**
  1. **早期：持續且嚴重的嘔吐**、倦怠嗜睡
  2. 之後：躁動、意識混亂、過度換氣
  3. 晚期：昏迷、**去大腦僵直**、反射消失、呼吸停止
- **檢驗**：**肝指數(AST、ALT)上升**、**血氨上升**、**凝血酶原時間延長**、**低血糖**；肝臟腫大但通常**沒有黃疸**；腦脊髓液多正常
- **治療**：支持療法、**控制腦水腫與顱內壓**(見 [[increased-icp]])、矯正低血糖與凝血異常
- **預防**：**18 歲以下病毒感染發燒時不用 aspirin**，退燒改用 acetaminophen 或 ibuprofen(見 [[nsaids-acetaminophen#reye-syndrome]])

## 新生兒反射 {#newborn-reflexes}

| 反射 | 做法與正常反應 | 約何時消失 |
|---|---|---|
| **尋乳反射**(rooting) | 輕觸嘴角或臉頰 → **頭轉向刺激側、張嘴**找乳頭 | 約 3–4 個月(睡眠中可較久) |
| **吸吮反射** | 東西放進嘴裡 → 吸吮 | 約 10–12 個月後轉為自主吸吮 |
| **吐舌反射**(extrusion) | 碰到舌尖 → 舌頭往外推 | 約 4 個月(可開始餵副食品的時機) |
| **擁抱反射**(Moro) | 突然改變姿勢或巨響 → 雙臂**對稱外展伸直**、手指張開，再屈曲內收像擁抱 | 約 4 個月(3–6 個月) |
| **驚嚇反射**(startle) | 巨響 → 手臂屈曲、握拳 | 約 4 個月 |
| **手掌抓握** | 東西放在手心 → 握緊 | 約 3–4 個月 |
| 足底抓握 | 壓腳掌 → 腳趾屈曲 | 約 8–10 個月 |
| **頸部強直反射**(擊劍姿勢) | 平躺時把頭轉向一側 → **轉向側的手腳伸直**、對側屈曲 | 約 4–6 個月 |
| **踏步反射** | 扶直身體、腳碰平面 → 交替踏步 | 約 2 個月 |
| **巴賓斯基反射** | 從腳跟沿腳底**外側**往前劃到拇趾 → **大拇趾背屈、其他腳趾扇形張開** | 約 **12–24 個月**(會走路後)，是**最晚消失**的 |

- 消失時間為教科書參考值，各書略有差異(待以兒科課本核對)；原始反射該消失卻持續、該有卻沒有、或兩側不對稱，都可能是神經系統異常(例如腦性麻痺)
- 眨眼、作嘔、咳嗽、打噴嚏、吞嚥等保護性反射**終生存在**(見 [[spinal-cord-spinal-nerves#newborn-reflexes]])
