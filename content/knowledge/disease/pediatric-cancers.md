兒童癌症和成人不同：多數是**胚胎性或造血系統**的腫瘤(不是成人常見的上皮癌)，**生長快但對化療敏感**，整體 5 年存活率約 **80%** 以上。最常見的是**白血病**，其次是**腦瘤**(最常見的**實體**腫瘤)，再來是淋巴瘤、神經母細胞瘤、威爾姆氏腫瘤、骨腫瘤等。白血病見 [[leukemia]]，淋巴瘤見 [[lymphoma-myeloma]]，化療照護見 [[cancer-treatment-toxicities]]，兒童疼痛評估見 [[pain-management#children]]。

## 兒童癌症的警訊 {#warning-signs}

| 警訊 | 可能的癌症 |
|---|---|
| **不明原因發燒**、**臉色蒼白**、疲倦、**容易瘀青或出血** | 白血病 |
| **骨頭或關節痛**、跛行、夜間痛 | 白血病、骨肉瘤、伊汶氏肉瘤、神經母細胞瘤骨轉移 |
| **腹部腫塊** | 威爾姆氏腫瘤、神經母細胞瘤、肝母細胞瘤、淋巴瘤 |
| **早晨頭痛合併嘔吐**、走路不穩、性格改變 | 腦瘤 |
| **瞳孔白色反光**(貓眼反射)、斜視 | **視網膜母細胞瘤** |
| **無痛淋巴結持續腫大** | 淋巴瘤 |
| 不明原因體重減輕 | 多種 |

(來源：[UpToDate：childhood cancer](https://www.uptodate.com/contents/overview-of-common-presenting-signs-and-symptoms-of-childhood-cancer))

## 腦瘤 {#brain-tumors}

- 兒童**最常見的實體腫瘤**；最常見的原發性腦瘤是**膠質瘤**(星狀細胞瘤)。
- 兒童腦瘤多在**天幕下**(後顱窩：**小腦、腦幹**)，成人多在天幕上。
- **髓母細胞瘤**：最常見於 **5 歲以下兒童的小腦**，惡性，可經腦脊髓液散播。
- 依位置的症狀：

| 位置 | 症狀 |
|---|---|
| **小腦** | **走路不穩、步態偏斜**、協調差、眼球震顫 |
| **腦幹** | **腦神經麻痺**：**吞嚥困難、說話不清**、臉部無力、複視；嘔吐 |
| 額葉 | 性格與情緒改變、注意力與記憶變差 |
| 腦室或阻塞腦脊髓液 | 水腦、顱內壓上升 |

### 顱內壓上升 {#icp}

- 兒童：**早晨醒來頭痛**、**噴射狀嘔吐**(壓迫**延腦**嘔吐中樞)、**躁動或嗜睡**、視乳頭水腫、複視；**嬰兒**：**囟門膨出**、**頭圍增加**、**高頻哭聲**、落日眼。
- 晚期**庫欣三症狀**：**心跳變慢、血壓上升**(脈壓變大)、**呼吸不規則**；**不是**心跳快、血壓下降。
- 成人腦瘤：**突發抽搐**是重要警訊；**類固醇**(Decadron)用來**減輕腦水腫**。

### 腦瘤手術後護理 {#brain-postop}

- 監測**意識、瞳孔、生命徵象**與神經學變化；注意**尿崩症**(抗利尿激素不足 → 大量稀尿)或 SIADH。
- 天幕上手術：**床頭抬高約 30 度**(依醫囑)促進靜脈回流、降低顱內壓；**不可抬高床尾**。
- 避免**用力咳嗽、用力解便**(軟便劑)等使顱內壓上升的動作。
- 觀察傷口與腦脊髓液滲漏；預防抽搐。
- 頭部放療的皮膚與頭髮照護見 [[cancer-treatment-toxicities#radiation-skin-care]](撐傘戴帽防曬)。

## 神經母細胞瘤 {#neuroblastoma}

- 來自**神經嵴細胞**(交感神經系統)，**最常發生在腎上腺髓質**，其次是脊椎旁的交感神經鏈；**嬰幼兒最常見的顱外實體腫瘤**。
- 症狀**與腫瘤位置和轉移部位有關**：
  - 腹部：**越過中線**、質硬、不規則的腹部腫塊，腹痛
  - 眼眶轉移：**眼眶周圍瘀青**(熊貓眼)、眼球突出
  - 頸部或胸部：**霍納氏症候群**(**上眼瞼下垂**、縮瞳)、呼吸困難
  - 脊椎旁：脊髓壓迫(下肢無力、大小便異常)
  - 骨髓與骨轉移：骨痛、貧血、發燒
- 診斷：**尿液兒茶酚胺代謝物**(**VMA、HVA**)上升(驗**尿液**，不是抽血)、影像、MIBG 掃描、**骨髓檢查**(確認骨髓是否侵犯)。
- 分期(INSS)：**第 III 期**是腫瘤**越過中線**、無法完全切除，但**還沒有遠處轉移**；**第 IV 期**才有遠處轉移(骨髓、骨、肝)；**4S 期**嬰兒可能自行消退。
- 治療依風險：手術、化療、放療，高風險者加自體幹細胞移植與免疫治療。

## 威爾姆氏腫瘤 {#wilms}

- **腎母細胞瘤**，**兒童最常見的原發腎臟惡性腫瘤**，好發 2–5 歲。
- 相關先天異常：**WAGR 症候群**(威爾姆氏腫瘤、無虹膜、泌尿生殖異常、發展遲緩)、半身肥大。病理的 **Homer-Wright 偽玫瑰花結**是**神經母細胞瘤**的特徵，不是威爾姆氏腫瘤。
- 表現：常由家長洗澡時發現**無痛、光滑、單側、不越過中線**的**腹部腫塊**；**高血壓**(腎素分泌增加，**不是低血壓**)、血尿、腹痛、發燒、**貧血**、疲倦。
- **術前禁止觸診腹部**：腫瘤包膜很脆，觸壓可能**破裂而擴散** → 床頭掛警示、洗澡與抱小孩時小心。
- 治療：**患側腎臟切除術**(診斷後盡快)＋**化療**(vincristine、dactinomycin ± doxorubicin)；第 III 期以上加**局部放療**(腹部或腰部照射，**不是全身性**)。第三期代表腫瘤殘留在腹腔內，只靠手術無法根除。
- 術後護理：**監測血壓、腎功能、輸出入量**(只剩一個腎)、腸蠕動(術後與 vincristine 可能腸阻塞)；白血球 < 1,000 時保護性隔離。
- 預後好(整體存活率約 90%)(來源：[UpToDate：Wilms tumor](https://www.uptodate.com/contents/clinical-presentation-diagnosis-and-staging-of-wilms-tumor))。

## 骨腫瘤 {#bone-tumors}

| | **骨肉瘤** | 伊汶氏肉瘤 |
|---|---|---|
| 好發 | **青春期**生長快速期、男性略多 | 兒童與青少年 |
| 部位 | 長骨的**幹骺端**，**膝關節周圍**最多：**股骨遠端、脛骨近端**，其次肱骨近端(**不是**最常見在肱骨) | 長骨**骨幹**、骨盆、肋骨 |
| 表現 | 局部**持續性疼痛**(**夜間與活動時更痛**)、腫脹、**跛行**、**病理性骨折** | 疼痛、腫脹，常有**發燒**等全身症狀 |
| 轉移 | **肺** | 肺、骨、骨髓 |
| 治療 | **術前化療**(高劑量 methotrexate、doxorubicin、cisplatin)＋手術：多數可做**保肢手術**，**不是全部都要截肢** | 化療＋手術或放療(對放療敏感) |

### 截肢術後護理 {#amputation}

- 觀察殘肢**出血、滲液、感染**。
- 殘肢以**彈性繃帶**(八字形)包紮塑形、減少水腫；術後初期可短暫抬高減輕水腫，之後**避免長時間墊高殘肢**，並**俯臥**預防髖關節**屈曲攣縮**。
- **幻肢痛**是真實的疼痛，要評估並使用藥物或神經阻斷處理。
- **暫時性義肢**可早期使用；**永久性義肢**要等殘肢**消腫、形狀穩定**(數週到數月)後才裝，不是術後立即裝。
- **身體心像**：鼓勵表達、同儕支持、復健與重返學校。

## 視網膜母細胞瘤 {#retinoblastoma}

- 兒童最常見的**眼內惡性腫瘤**，多在 **5 歲前**(常 2 歲前)發現；與 **RB 抑癌基因**(**雙重打擊**)有關，遺傳型常**雙側**發生，日後也較易得骨肉瘤(見 [[neoplasia#molecular]])。
- 表現：**白瞳症**(照相或視力檢查時瞳孔出現**白色反光**，**貓眼反射**)、**斜視**、眼睛紅痛。
- 治療：化療、雷射、冷凍、放療；嚴重時**眼球摘除**並裝義眼；**遺傳諮詢**與兄弟姊妹篩檢。

## 其他 {#other-tumors}

- **橫紋肌肉瘤**：兒童最常見的**軟組織肉瘤**，好發頭頸部(眼眶)與泌尿生殖道。
- **肝母細胞瘤**：幼兒腹部腫塊，**AFP 升高**。
- **生殖細胞瘤**：**卵黃囊瘤**(幼兒睪丸腫瘤)**AFP 升高**。

## 癌症病童的照護 {#nursing}

### 檢查 {#procedures}

- **2 歲以下**骨髓穿刺常選**脛骨**；較大兒童選後腸骨嵴(見 [[leukemia#bone-marrow-aspiration]])；侵入性檢查前給予鎮靜止痛、用**遊戲**說明。

### 感染預防與疫苗 {#vaccination}

- 化療期間**不可接種活性減毒疫苗**：**水痘、MMR、輪狀病毒、口服沙賓**、卡介苗。
- **不活化疫苗可以接種**：例如**四合一**(DTaP-IPV)、**流感疫苗**(建議病童與家人都接種)。
- 避免接觸**水痘、麻疹**病人；接觸到水痘要立即告知(可能需要免疫球蛋白或抗病毒藥)。
- 飲食注意**煮熟與新鮮**、手部衛生；不需要所有食物都用微波處理；**縮短住院**以減少院內感染。
- 其他保護措施見 [[cancer-treatment-toxicities#infection-prevention]]。

### 血管通路 {#vascular-access}

- 長期化療多用 **Port-A**(外科醫師在手術室植入；不用時**每月以含 heparin 生理食鹽水沖洗**)；**PICC 不是**好動幼兒長期化療的最佳選擇(外露、易拉扯與感染)。
- Port-A 傷口癒合後**不需限制同側手臂活動**；反抽無回血時可請病童抬高手臂、改變姿勢(見 [[cancer#vascular-access]])。

### 身心與家庭 {#family}

- 依發展階段誠實說明病情，**不要隱瞞**：隱瞞會讓孩子更焦慮、孤單；用孩子能理解的語言與遊戲。
- 學齡兒童在意**學業與同儕**；青少年在意**外觀與自主**(掉髮、截肢)，鼓勵表達並提供假髮、頭巾、病友分享。
- **兄弟姊妹**可能因被忽略而出現**行為改變**(易怒、打同學)：讓手足了解病情、參與照顧、給予個別關心，而不是直接責罵。
- 父母的罪惡感與照顧負擔：提供支持團體、社工與兒童癌症基金會資源。
- 疾病末期的安寧照護、兒童的死亡概念與家屬支持見 [[end-of-life-care#children]]。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **貓眼反射 → 視網膜母細胞瘤**；**髓母細胞瘤 → 5 歲以下小腦**；腦幹腫瘤 → **吞嚥困難、說話不清**；顱內壓上升 → **早晨頭痛、噴射狀嘔吐**。
- 腦瘤術後**不可抬高床尾**；避免用力咳嗽解便。
- **威爾姆氏腫瘤**：**腎臟**、**避免觸診腹部**、**高血壓**(不是低血壓)、監測**腎功能、血壓、輸出入量**；放療是**局部**不是全身；**不需監測血銅**。
- **神經母細胞瘤**：驗**尿液** VMA(不是抽血驗兒茶酚胺)；第 III 期**越過中線無法完全切除但未遠處轉移**；轉移到眼眶可有眼瞼症狀。
- **骨肉瘤**：青春期、**膝周圍**(股骨遠端、脛骨近端)、**夜間痛較明顯**、病理性骨折；**不是全部截肢**；截肢後**不立即裝永久義肢**、評估**幻肢痛**。
- 化療病童：**四合一可以打**，**口服沙賓、水痘、MMR、輪狀病毒不可**；食物不必全部微波。
- **PICC 不是**幼兒長期化療的首選；Port-A 同側手臂**不需限制活動**。
- 不要對病童**隱瞞病情**；手足行為改變要**了解與關懷**。
:::
