**甲狀腺功能低下**是甲狀腺素不足，讓全身代謝變慢。本頁整理原因、甲狀腺炎、表現、甲狀腺素治療與護理，以及危急的黏液水腫昏迷；甲狀腺素的生理見 [[thyroid-parathyroid]]，亢進見 [[hyperthyroidism]]

## 重點摘要 {#summary}

- **原發性**（甲狀腺本身）佔大多數：**橋本氏甲狀腺炎**、甲狀腺切除或放射性碘治療後、碘缺乏、藥物（鋰鹽、amiodarone）；次發性來自腦下垂體（見 [[pituitary-disorders#hypopituitarism]]）
- 原發性：**T4 下降、TSH 上升**；TSH 是最敏感的篩檢
- 表現：**怕冷**、疲倦、嗜睡、反應慢、**便秘**、**食慾下降但體重增加**、皮膚乾粗、掉髮、聲音沙啞、**心搏過緩**、**心輸出量降低**、月經過多
- **黏液水腫**：黏多醣堆積在皮下 → 臉部浮腫、**非凹陷性**水腫
- 檢驗：**高膽固醇**、**稀釋性低血鈉**、貧血（可能為巨球性）
- 治療：**終身** levothyroxine；**早上空腹**服用、**不可自行停藥或改劑量**；老人與心臟病人**低劑量開始**，**新生兒要儘早足量**
- 交互作用：**增強抗凝血劑**、降低毛地黃效果、**使血糖上升**（糖尿病人要監測血糖）
- 護理：保暖但**不用電毯、熱水袋**（皮膚感覺遲鈍易燙傷）、**洗澡水不要太熱**；**低熱量、低脂低膽固醇、高纖**飲食
- **黏液水腫昏迷**：嚴重低下的急症，**T4 下降、TSH 上升**、低體溫、**低血鈉、低血糖**、換氣不足、昏迷；靜脈甲狀腺素加類固醇，不用抗甲狀腺藥

### 國考常考點 {#exam-points}

- 造成黏液性水腫的是**甲狀腺**機能低下
- 甲低表徵：**低血鈉**；怕冷（不是對熱敏感）；**非凹陷性**水腫；體重**增加**
- 甲低：周邊血管阻力增加、心臟聽診可能有心音改變、巨球性貧血；**葡萄糖吸收不會增加**
- 飲食：**低膽固醇**、低熱量、低脂、**高纖**
- 黏液水腫：洗澡水溫**不要太熱**；不用電毯與熱水袋
- 甲狀腺素：**空腹**吃（不是飯後）；**監測血糖**（會升高）；**增加抗凝血劑**效應；新生兒**儘早高劑量**；心絞痛病人從**低劑量**開始；終身服用
- 黏液水腫昏迷：T4 下降、**TSH 上升**、血鈉與血糖下降；**不會**高血糖；不用抗甲狀腺藥；不是副甲狀腺的併發症

## 原因 {#causes}

| 類型 | 原因 |
|---|---|
| **原發性**（甲狀腺本身，TSH ↑） | **橋本氏甲狀腺炎**（最常見）、**甲狀腺切除**或**放射性碘**治療後、碘缺乏、藥物（鋰鹽、amiodarone、抗甲狀腺藥過量）、先天性 |
| 次發性（腦下垂體，TSH ↓） | 腦下垂體腫瘤、手術、席漢氏症候群 |

### 甲狀腺炎 {#thyroiditis}

| | 橋本氏甲狀腺炎 | 亞急性甲狀腺炎 | 產後甲狀腺炎 |
|---|---|---|---|
| 原因 | **自體免疫**（抗 TPO、抗甲狀腺球蛋白抗體），淋巴球浸潤 | 常在病毒感染後 | 產後一年內，自體免疫 |
| 甲狀腺 | 無痛、橡皮樣腫大，後期萎縮 | **疼痛、壓痛**，可伴發燒 | 無痛 |
| 功能變化 | 慢慢走向**低下** | 先短暫**亢進**、再短暫低下，多數恢復 | 先亢進、再低下，多數恢復 |
| 處理 | 甲狀腺素補充 | 止痛消炎藥、嚴重時類固醇、β 阻斷劑 | 依症狀 |

- 橋本氏甲狀腺炎的病理：濾泡被淋巴球與生發中心取代、濾泡細胞嗜酸性變（Hürthle 細胞）；日後甲狀腺淋巴瘤風險增加
- 先天性甲狀腺功能低下（呆小症）的新生兒篩檢與照護見 [[pediatric-endocrine#congenital-hypothyroidism]]

| 系統 | 表現 |
|---|---|
| 代謝 | **怕冷**、疲倦、**食慾下降但體重增加**、基礎代謝率下降 |
| 心血管 | **心搏過緩**、**心輸出量降低**、**周邊血管阻力增加**、舒張壓上升、心包膜積液（心音遙遠） |
| 皮膚毛髮 | 皮膚**乾燥粗糙**、蒼白偏黃、掉髮與眉毛外側稀疏、指甲脆 |
| **黏液水腫** | 黏多醣堆積 → 臉部與眼瞼浮腫、舌頭變大、**聲音沙啞低沉**、**非凹陷性**水腫 |
| 神經精神 | 反應與思考變慢、嗜睡、記憶差、憂鬱；深肌腱反射**放鬆期延長** |
| 腸胃 | **便秘**、腸蠕動慢、葡萄糖吸收**變慢** |
| 生殖 | **月經過多**、不易受孕 |
| 檢驗 | **高膽固醇**與三酸甘油酯、**低血鈉**（排水能力下降）、貧血（含**巨球性**）、CK 上升 |

- 老人表現不典型，容易被當成老化或失智；對鎮靜安眠藥、鴉片類**特別敏感**（代謝慢）

## 治療：甲狀腺素 {#levothyroxine}

- **levothyroxine**（合成 T4）：多數人需要**終身服用**，**不可自行停藥或更改劑量**
- 服法：**早上空腹**（早餐前約 30–60 分鐘），和鈣片、鐵劑、制酸劑**間隔約 4 小時**(ATA 2014)
- 劑量
   1. **年長者與心臟病（如心絞痛）病人**：從**低劑量**開始、慢慢加，避免心肌耗氧突然增加
   2. **新生兒與嬰兒**：**儘早**、以**足量**治療，避免智能與生長發育遲緩
- 交互作用
   1. **增強口服抗凝血劑**(warfarin)效果 → 監測凝血時間
   2. **降低毛地黃**效果
   3. 代謝加快使**血糖上升** → 糖尿病人要監測血糖、調整降血糖藥
- 觀察過量：心悸、心搏過速、胸痛、失眠、怕熱、體重下降
- 數週後才達穩定，依 TSH 調整劑量；藥物細節見 [[thyroid-drugs#levothyroxine]]

## 護理 {#nursing}

1. **保暖**：提高室溫、加衣被；**不用電毯、熱水袋**（皮膚感覺遲鈍、易燙傷，且周邊血管擴張可能讓血壓下降）；**洗澡水溫勿過熱**
2. **飲食**：**低熱量**、**低脂、低膽固醇**；**高纖**加足夠水分改善便秘
3. 皮膚乾燥：溫和清潔、保濕乳液、勤翻身
4. 活動與休息交替；監測心跳、體重、排便
5. 少用鎮靜劑與鴉片類，必要時減量並觀察呼吸
6. 衛教終身服藥與回診；說明症狀會隨治療慢慢改善，給予耐心

## 黏液水腫昏迷 {#myxedema-coma}

- 嚴重、長期未治療的甲狀腺低下急性惡化；常見誘因：**寒冷**、**感染**、手術、**鎮靜劑與鴉片類**、停藥；多見於冬天的年長女性
- 表現：**低體溫**、意識變差到**昏迷**、**換氣不足**（二氧化碳滯留）、**心搏過緩**、低血壓、**低血鈉**、**低血糖**
- 檢驗：**T4 下降**；原發性者 **TSH 上升**
- 處置
   1. 加護病房，必要時**插管**支持呼吸
   2. **靜脈甲狀腺素**（levothyroxine，必要時加 T3）
   3. **靜脈類固醇**(hydrocortisone)，直到排除腎上腺功能不足
   4. **被動保暖**（蓋毯子、提高室溫）；**不用電毯**等主動加溫，以免血管擴張造成休克
   5. 小心補液、矯正低血鈉與低血糖，治療誘因
- **不用**抗甲狀腺藥（那是治療亢進的）
