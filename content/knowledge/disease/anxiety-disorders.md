**焦慮**是面對威脅或不確定時的不安與緊張，伴隨**自主神經興奮**的身體反應。適度的焦慮能提高警覺、促進學習；當焦慮**過度、持續、與情境不相稱**，並影響生活功能時，就是**焦慮症**。這一頁先說明焦慮的分級與評估，再介紹各種焦慮症與護理。強迫症見 [[obsessive-compulsive-disorder]]，創傷與壓力相關疾病見 [[trauma-stress-disorders]]，用藥見 [[anxiolytics-hypnotics]]

## 重點摘要 {#summary}

- 焦慮依 Peplau 分**輕、中、重、恐慌**四級，關鍵是**知覺範圍**：輕度擴大、利學習；中度縮小、仍能在指導下學習；重度極度縮小、無法學習；恐慌時失去控制
- **恐慌症**：**非預期**、突然發作、**數分鐘內達高峰**，伴心悸、胸痛、喘不過氣、瀕死感，之後**持續擔心再發作**並**逃避**
- **畏懼症**：特定場所（電梯、地下室、大眾運輸）、社交（被觀察、評價）、特定對象（動物、高處、打針）；病人**知道不合理**卻無法控制
- **廣泛性焦慮症**：**至少 6 個月**、對**多件事**過度擔心，伴坐立不安、肌肉緊繃、易疲勞、失眠
- 治療：**SSRI／SNRI ＋ 認知行為治療**；**BZD 只短期**；護理以**陪伴、安全、簡短清楚的溝通、放鬆技巧**為主，**不約束**中度焦慮者

### 國考常考點 {#exam-points}

- 焦慮的身體症狀以**自主神經（交感）反應**為主；**防衛機轉能降低焦慮**；**輕度焦慮**最利學習，**中度**知覺範圍已縮小
- **中度焦慮**：知覺範圍縮小、**選擇性注意**、仍能在指導下學習；生命徵象上升、聲音顫抖、頭痛；**重度焦慮**：哭泣、踱步、搓手、言談困難、無法接受衛教，可能胃痛、頭痛、**過度換氣**
- **情境性焦慮**：平常從容，只在特定情境（如資格考）焦慮；**特質性焦慮**是人格上長期的焦慮傾向
- 考試前打球紓解焦慮 → **行為取向**的適應方式
- **恐慌發作**是**非預期**的，不是「預期中的反覆發作」；數分鐘內達高峰；之後**避免不熟悉的情境**、更關注身體感受
- **社交焦慮症**：害怕在**被觀察或評價**的情境出糗；**特定場所畏懼症**：電梯、地下室、開放或封閉空間，**不是只與社交有關**
- **恐慌發作的處置**：**留在身旁、說「你在醫院，我們陪著你，你很安全」**、**一起慢呼吸**，必要時**紙袋**（國考答案；現行急救指引不建議）；不要否定（「你不會死，不用想太多」）、不要要求詳細說明
- **病因**：**學習理論**＝刺激與反應連結（一朝被蛇咬，十年怕草繩）；**正腎上腺素過高、GABA 不足**；**HPA 軸**是壓力主要的調節系統
- **分離焦慮症的兒童**：增強安全感、教導因應、訓練獨立；**不要突然增加分離次數**
- 會談：高度焦慮時問「**你現在覺得怎麼樣？**」（此時此刻），不要問過去如何處理或深入家庭議題

## 焦慮的分級與評估 {#levels}

### Peplau 的焦慮四級 {#peplau-levels}

| 程度 | 知覺與學習 | 生理與行為 | 護理重點 |
|---|---|---|---|
| **輕度** | 知覺範圍**擴大**、警覺性高，**最有利學習與解決問題** | 輕微坐立不安、易怒、咬指甲、手指敲打 | 一般支持；鼓勵表達，可以教導新技巧 |
| **中度** | 知覺範圍**縮小**，**選擇性注意**，只專注於目前關切的事；**仍能在指導下學習** | 心跳呼吸加快、流汗、聲音顫抖、頭痛、腸胃不適、頻尿 | **陪伴**、語調平穩、**簡短清楚**的句子；降低刺激；**協助解決問題**、引導說出感受與發生了什麼事；依醫囑給藥 |
| **重度** | 知覺範圍**極度縮小**，只注意零碎細節，**無法學習**、難以做邏輯判斷 | 頭痛、噁心、頭暈、失眠、顫抖、**過度換氣**、瀕臨崩潰感；**哭泣、踱步、搓手、言談困難** | **移開刺激**、**留在身旁**、安全為先；同中度的措施；必要時依醫囑給藥 |
| **恐慌** | 無法處理所發生的事，可能**失去現實感** | 行為失控（奔跑、尖叫、退縮或僵住）、說話混亂；胸痛、麻木、喘、心悸 | 移到**安全**的地方、**不離開**、防止受傷；給藥；事後再與病人討論發生了什麼 |

:::exam[國考重點]
辨別等級的關鍵是**知覺範圍與能否學習**：輕度擴大、能學；中度縮小、**在指導下**能學；重度極度縮小、**不能學**；恐慌**失控**。中度焦慮**不用約束**，也**不安排挑戰新活動**
:::

### 焦慮的類型與因應 {#types}

1. **情境性（狀態）焦慮**：面對特定壓力情境才出現，離開情境後緩解，例如平時從容、只在資格考時焦慮
2. **特質性焦慮**：人格中長期存在的焦慮傾向
3. **預期性焦慮**：擔心某件事「可能會發生」，例如恐慌症病人擔心下一次發作
4. **漂浮性焦慮**：沒有固定對象的焦慮，多見於廣泛性焦慮症
5. 面對焦慮的適應方式
   1. **行為取向**：用具體行動紓解，例如打球、運動、打掃
   2. **認知取向**：改變想法與評估，例如轉念、正向思考
   3. **情緒取向**：宣洩情緒、哭泣、尋求情感支持
   4. **防衛機轉**：無意識降低焦慮（見 [[psychodynamic-theories#defense-mechanisms]]）

### 評估 {#assessment}

1. **生理層面**：焦慮常引起交感神經興奮（心悸、出汗、呼吸急促、頻尿），也可能是身體疾病或藥物造成，所以**一定要做生理評估**
2. **情緒與行為**：從**語言與非語言**訊息評估，例如咬指甲、踱步、聲音顫抖
3. **認知層面**：注意力、知覺範圍與問題解決能力，可判斷焦慮的程度
4. **靈性層面**：信念與意義來源，有助於了解病人因應行為的力量來源
5. 鑑別身體疾病：甲狀腺機能亢進、心律不整、低血糖、氣喘、咖啡因或藥物、物質戒斷

## 病因 {#etiology}

| 取向 | 解釋 |
|---|---|
| **生物** | 遺傳；**正腎上腺素（藍斑核）過度活躍**、**GABA 不足**、血清素失調；壓力反應以**下視丘－腦下垂體－腎上腺(HPA)軸**為主要調節系統，前額葉與邊緣系統（杏仁核）參與 |
| **精神分析** | 焦慮是本我、自我與超我之間的衝突，自我用防衛機轉處理 |
| **人際關係**（沙利文） | 焦慮來自早年的人際不安全感與重要他人的不認可 |
| **學習理論**（行為） | 焦慮是**刺激與反應連結**學來的；特定畏懼症是**過去被畏懼對象傷害**的經驗所制約，例如「**一朝被蛇咬，十年怕草繩**」 |
| **認知** | 扭曲的認知與災難化的解讀誘發焦慮 |

1. 精神分析的焦慮來自內在衝突，不是「同儕缺乏同理心」
2. 「肛門期與防衛機轉」屬精神分析學派，不是人際關係學派
3. 災難經驗不只造成立即的心理改變，長期也可能影響知覺與性格

## 各種焦慮症 {#disorders}

### 恐慌症 {#panic-disorder}

1. **恐慌發作**的特徵
   1. **突然**出現強烈恐懼或不適，**數分鐘內達到高峰**
   2. 身體症狀：**心悸、胸痛、喘不過氣、發抖、出汗、頭暈、麻木**、噁心
   3. 認知症狀：**失現實感、失自我感**、怕失控或發瘋、**瀕死感**
2. **恐慌症**：**反覆、非預期**的恐慌發作（強烈恐懼在**數分鐘內達到高峰**，13 項身心症狀中出現 **4 項以上**），之後**至少 1 個月**持續擔心再發作，或行為明顯改變（逃避）
3. 發作後的典型反應
   1. **預期性焦慮**：持續擔心下一次發作
   2. **逃避**：避開不熟悉或難以逃離的情境，可能合併特定場所畏懼症
   3. 更加**關注**身體感受
4. 要先排除身體疾病（心臟、甲狀腺、呼吸），但檢查正常後不要再無止境地檢查
5. 治療
   1. 長期：**SSRI**、認知行為治療（含暴露與呼吸訓練）
   2. 急性：**BZD**（如 alprazolam）短期快速緩解（見 [[anxiolytics-hypnotics#bzd-classes]]）
   3. 鋰鹽不是治療藥物
   4. 恐慌症不是器質性因素造成的急性混亂（那是譫妄）

### 畏懼症 {#phobias}

| 疾病 | 害怕的對象 | 重點 |
|---|---|---|
| **特定場所畏懼症** agoraphobia | 難以逃離或求助的場所：**電梯、地下室、大眾運輸、開放或封閉空間、人群** | 主動逃避；**知道害怕不合理**卻無法控制；不只與社交有關 |
| **社交焦慮症**（社交畏懼症） | **被他人觀察或評價**的社交情境：上台報告、在公共場所用餐、與人交談 | 怕出糗與被批評；焦慮**有明確的社交誘因**，不是漂浮性焦慮 |
| **特定畏懼症** | 特定對象或情境：動物、高處、打針、血 | 多與過去不愉快經驗的**制約**有關 |

1. 畏懼症的症狀通常**持續 6 個月以上**（DSM 的時間條件）
2. 社交焦慮症與**選擇性不語症**不同：後者是在特定場合（如學校）不說話，在家中可正常說話
3. 社交焦慮症病人若合併肥胖等身體狀況，恐懼必須與這些狀況**無關**或過度，才算社交焦慮症
4. 治療：**系統減敏感法**、暴露治療（見 [[individual-cognitive-behavioral-therapy#exposure-techniques]]）、SSRI；表演焦慮可用 propranolol 減輕周邊症狀

### 廣泛性焦慮症 {#gad}

1. 核心：**至少 6 個月**、對**多件事**（工作、家庭、健康、金錢）**過度且難以控制的擔心**
2. 伴隨症狀（至少三項）：**坐立不安、易疲勞、注意力不集中、易怒、肌肉緊繃、睡眠障礙**
3. 區分
   1. 恐慌症是**陣發、數分鐘達高峰**；廣泛性焦慮是**長期、廣泛**
   2. 罹病焦慮症是擔心自己得了某種重病
   3. 「肌肉緊繃、心神不寧、易分心、易疲倦、隨時有焦慮」描述的是**廣泛性焦慮症**，不是恐慌症
4. 治療：SSRI／SNRI、**buspirone**、認知行為治療、放鬆訓練；BZD 只短期

### 分離焦慮症 {#separation-anxiety}

1. 與依附對象（通常是父母）分離或預期分離時，出現**與發展階段不相稱**的過度焦慮
2. 表現：擔心父母出事、拒絕上學、不敢獨自睡、做分離的惡夢、分離時頭痛肚子痛
3. 兒童與青少年至少持續約 4 週，成人通常 6 個月以上
4. 護理
   1. **增強安全感**：可預測的常規、分離前清楚的說明與承諾
   2. **教導因應能力**
   3. **訓練獨立性**，採**漸進式**分離
   4. **不要突然增加分離的次數或時間**，會加重恐懼

## 治療原則 {#treatment}

1. **藥物**（細節見 [[anxiolytics-hypnotics]] 與 [[antidepressants]]）
   1. **SSRI／SNRI**：多數焦慮症的**長期首選**，起效需數週
   2. **BZD**：短期、急性使用，注意依賴與戒斷
   3. **buspirone**：廣泛性焦慮症，起效慢、無依賴
   4. propranolol：表演焦慮的周邊症狀
2. **心理治療**
   1. **認知行為治療**：辨識與修正災難化想法、暴露、放鬆與呼吸訓練
   2. 系統減敏感法：畏懼症
   3. 支持性治療與團體治療
3. **分級照護**（依 NICE 的概念）：先衛教與追蹤，再到低強度介入（自助、團體），效果不佳再到高強度心理治療或藥物，並依病人偏好選擇

## 護理 {#nursing}

### 護理原則 {#nursing-principles}

1. **評估焦慮程度**，依程度選擇介入：中度焦慮的照護原則是**先觀察並辨識病人不同焦慮程度的表現**
2. **陪伴與安全**：不讓重度或恐慌的病人獨處，保持環境安靜、降低刺激
3. **溝通**
   1. 語調平穩、句子**簡短清楚**
   2. 高度焦慮時聚焦**此時此刻**：「你現在覺得怎麼樣？」
   3. 不要問需要複雜回想或深入的問題（過去怎麼處理、家庭狀況、原因是什麼）
   4. **描述觀察到的行為**協助覺察，例如「我看到你在咬指甲、走來走去，你現在覺得怎麼樣？」
4. **不否定**病人的感受：不要說「焦慮是多餘的」「不用想太多」
5. **中度焦慮**的措施
   1. 用溝通技巧協助病人**解決問題**
   2. 傾聽與**同理**以減輕焦慮
   3. 評值並學習適當的因應技巧
   4. **不需要約束**，也不安排挑戰新活動
6. **環境**：安排**結構化、規律**的活動，降低不確定感；漸進參與人際互動；不要面質與挑戰（見 [[milieu-therapy#by-condition]]）

### 恐慌發作時的處置 {#panic-nursing}

1. **留在身旁**，用簡短明確的話給予安全感：「你現在在醫院，我們陪著你，你很安全」
2. **一起做慢而深的呼吸**（放鬆呼吸）；過度換氣時國考答案可用**紙袋**重複呼吸；現行急救指引不建議（心肺疾病引起的喘會因此低血氧），臨床以引導慢呼吸為主
3. 確保環境安全，降低刺激
4. 依醫囑給予短效抗焦慮藥
5. 發作當下**不適合**
   1. 否定病人的感受（「你不會死，這是正常的焦慮症狀」）
   2. 要病人冷靜並詳細描述感覺
   3. 詢問過去怎麼處理、詳細追問誘因
   4. 叫病人「與症狀共存」
6. **發作過後**再與病人討論誘因、預警徵象與因應方法

### 找出焦慮的模式 {#pattern}

1. 焦慮反覆在特定時間出現時，用**時間軸**引導病人討論症狀出現前發生的事，例如每天護生交班時都焦慮害怕，可能與分離有關
2. 不要一開始就用行為契約限制病人尋求安全的行為，也不要直接要求調藥

### 衛教 {#education}

1. 說明焦慮與身體症狀的關係，減少災難化的解讀
2. 教導**腹式呼吸、漸進式肌肉放鬆**、正念等放鬆技巧，平常就要練習
3. 減少咖啡因、酒精與尼古丁
4. 規律運動與睡眠
5. 規則服藥；BZD 不可自行增量或驟停
6. 認識預警徵象與求助方式
