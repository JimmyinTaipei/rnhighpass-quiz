**敗血症**是身體對感染的**反應失調**，造成**危及生命的器官功能障礙**。**敗血性休克**是敗血症中循環與代謝異常特別嚴重的一群，死亡率超過 4 成。處理重點是**早期辨識**、**先抽血液培養再儘快給抗生素**、**輸液與升壓劑**恢復灌流，以及**找出並控制感染源**。

## 重點摘要 {#summary}

- **敗血症**是身體對感染的反應失調，造成危及生命的器官功能障礙；**敗血性休克**屬**分布性休克**，早期心輸出量增加、皮膚溫暖潮紅。
- 病理：**微血管通透性增加、有效循環血量下降**，可有尿量減少、代謝性酸中毒、DIC；**TNF-α** 是主要因子，**大腸桿菌**的**內毒素**最常引起。
- 處理重點：**先抽血液培養(兩套不同部位)再儘快給抗生素**；Hour-1 bundle：晶體液 **30 mL/kg**、**MAP ≥ 65 mmHg**。
- 器官功能障礙指標：血小板 < 100,000/μL、尿量 < 0.5 mL/kg/h、收縮壓 < 90 mmHg。
- 導管感染要儘速拔除中心靜脈管路。

### 國考常考點 {#exam-points}

- 引起敗血症全身反應的主要因子：**TNF-α**；腫瘤壞死因子活化可產生**微小血栓**(DIC)。
- 敗血症不是全身循環血量增加，而是**微血管通透性增加、有效循環血量下降**；會出現**尿量減少、代謝性酸中毒**，不會出現血壓上升或尿量增加。
- **大腸桿菌**最常引起敗血性休克；機轉是**內毒素**，不是外毒素。
- 敗血性休克屬於**分布性休克**(與過敏性、神經性同類)；早期**心輸出量增加**、**皮膚溫暖潮紅**；**CVP 不會升高**。
- ARDS 最常見的危險因子：**敗血性休克**。
- 發燒型態：敗血症常見**間歇熱**。
- **先抽血液培養再給抗生素**；兩套**不同部位**；空針抽血先注入**厭氧瓶**。
- Hour-1 bundle：晶體液 **30 mL/kg**(不是 40)、**MAP ≥ 65 mmHg**(不是 60)；廣效抗生素療程約 **7–10 天**。
- 器官功能障礙指標：**血小板 < 100,000/μL**(> 140,000 是正常)、尿量 < 0.5 mL/kg/h、收縮壓 < 90 mmHg。
- DIC：**優先治療敗血症的原因**。
- 導管感染：**儘速拔除中心靜脈管路**。

## 定義：新舊比較 {#definitions}

| 名詞 | 舊定義(Sepsis-2，2001) | 現行定義(**Sepsis-3，2016**) |
|---|---|---|
| **SIRS** | 下列 **≥ 2 項**：體溫 **> 38°C 或 < 36°C**；心跳 **> 90 次／分**；呼吸 **> 20 次／分或 PaCO₂ < 32 mmHg**；白血球 **> 12,000 或 < 4,000/μL**(或帶狀核 > 10%) | **不再用於定義敗血症**(太敏感、不夠特異)，但仍可用來篩檢 |
| 敗血症 | 感染＋SIRS | 感染造成**器官功能障礙**：**SOFA 分數上升 ≥ 2 分** |
| 嚴重敗血症 | 敗血症＋器官功能障礙 | **取消**這個名詞 |
| **敗血性休克** | 敗血症＋輸液後仍低血壓 | 充分輸液後仍需**升壓劑**才能維持 **MAP ≥ 65 mmHg**，**且**血中**乳酸 > 2 mmol/L** |

- **qSOFA**(床邊快速評估)：**呼吸 ≥ 22 次／分**、**意識改變**、**收縮壓 ≤ 100 mmHg**，≥ 2 項表示預後較差。Surviving Sepsis 2021 **不建議單獨用 qSOFA 篩檢**(和 SIRS、NEWS、MEWS 相比不夠敏感)。
- 器官功能障礙的常見指標：**尿量 < 0.5 mL/kg/h**、**血小板 < 100,000/μL**、**膽紅素上升**、**收縮壓 < 90 mmHg** 或 MAP < 65 mmHg、意識改變、低血氧、肌酸酐上升、乳酸上升。

:::note[舊答案：SIRS 與「嚴重敗血症」]
國考題仍常用 Sepsis-2 的分級：SIRS → 敗血症 → 嚴重敗血症 → 敗血性休克。
- 106-2 補考 內外 077：病人有感染，體溫 38.5°C、心跳 130 次／分、血壓 55/30 mmHg、無尿，答案是**敗血性休克**。
- 113-3 內外 047：SIRS 條件是**體溫 > 38°C 或 < 36°C**、**白血球 > 12,000 或 < 4,000/μL**。心跳是 > 90 次／分(不是 < 60)，PaCO₂ 是 < 32 mmHg(不是 < 40)。

現行 Sepsis-3 已取消「嚴重敗血症」，以器官功能障礙(SOFA ≥ 2)定義敗血症。作答時依題目用的分級回答([Sepsis-3](https://doi.org/10.1001/jama.2016.0287))。
:::

## 病因與病理生理 {#pathophysiology}

- **常見感染源**：**肺炎**(最常見)、**泌尿道感染**、腹腔感染(腸穿孔、腹膜炎)、皮膚軟組織感染、**中心靜脈導管**。
- **常見菌**：革蘭氏陰性菌以**大腸桿菌**最常見([[gram-negative-bacteria#escherichia-coli]])，其次是克雷白氏菌、綠膿桿菌；革蘭氏陽性菌以**金黃色葡萄球菌**為主([[staphylococcus-aureus]])；免疫低下者也可能是念珠菌。
- **高危險群**：**65 歲以上**、嬰兒、免疫低下(化療、類固醇、HIV、無脾)、糖尿病、慢性病、侵入性管路、近期手術。

### 致病機轉 {#mechanism}

1. 革蘭氏陰性菌細胞壁的**內毒素**(脂多醣，LPS)刺激巨噬細胞，釋放 **TNF-α**、IL-1、IL-6 等細胞激素。**TNF-α 是引起全身反應的主要因子**。大腸桿菌引起的敗血性休克是**內毒素**造成的，**不是外毒素**([[microbial-pathogenesis]])。
2. **血管擴張**、**微血管通透性增加**，液體滲到組織間隙，**有效循環血量減少**。它不是「全身循環血量增加」，而是**相對性低血容**。
3. 凝血系統活化，全身產生**微小血栓** → 消耗凝血因子與血小板 → **瀰漫性血管內凝血**(DIC)。
4. 代謝率與細胞耗氧量增加，組織灌流卻下降 → 無氧代謝 → **乳酸上升**、**代謝性酸中毒**。
5. 多重器官衰竭：**急性呼吸窘迫症候群**(ARDS，**敗血症是最常見的危險因子**)、**急性腎損傷**(腎前性，尿量減少)、肝功能異常、意識改變。

### 血行動力學：暖休克與冷休克 {#hemodynamics}

| 時期 | 心輸出量 | 周邊血管阻力 | 皮膚 | 其他 |
|---|---|---|---|---|
| **早期(高動力、暖休克)** | **增加** | **下降** | **溫暖、潮紅** | 心跳快、脈壓寬、發燒 |
| 晚期(低動力、冷休克) | 下降 | 上升 | 濕冷、蒼白、花斑 | 少尿、意識改變 |

- 敗血性、過敏性、神經性休克都屬於**分布性(血管性)休克**；中心靜脈壓(CVP)通常**偏低**，不會升高([[hypotension#shock]])。
- 國考題說「敗血性休克**初期**心輸出量明顯降低」是錯的。「休克時**血壓上升、尿量增加**」也是錯的。

## 臨床表現 {#manifestations}

- **發燒或體溫過低**(老人、嬰兒可能沒發燒)、寒顫；發燒型態常為**間歇熱**：一天內體溫有時高於 39°C，有時降到正常以下，交替出現。
- **心跳快**、**呼吸快**(代償代謝性酸中毒)、血壓下降、**意識混亂**。
- **尿量減少**、皮膚花斑、微血管回填時間延長。
- 檢驗：白血球上升或下降、帶狀核增加、**CRP 與 procalcitonin 上升**、**乳酸上升**、血小板下降、凝血時間延長、高血糖([[inflammatory-markers]])。
- 動脈血液氣體：**代謝性酸中毒**，早期可能合併呼吸性鹼中毒；病人是**低血氧**，不會高血氧。

| 檢查 | 目的 | 詳見 |
|---|---|---|
| **血液培養 2 套**(需氧＋厭氧) | 找出菌種與感受性；**給抗生素前**抽，兩套**不同部位**(或同部位不同時間) | [[culture-and-sensitivity#blood-culture]] |
| 感染部位檢體 | 尿液、痰液、傷口、導管尖端等 | [[culture-and-sensitivity]] |

| **乳酸** | 組織灌流不足的指標；> 2 mmol/L 要追蹤，≥ 4 mmol/L 表示灌流嚴重不足 | [[inflammatory-markers#lactate-high]] |
| 血小板、PT/aPTT、D-dimer、纖維蛋白原 | 評估 DIC | — |

- 血糖不是診斷敗血症的檢驗項目。

## 治療：1 小時組合照護 {#hour-1-bundle}

Surviving Sepsis Campaign 的 **1 小時組合照護**(Hour-1 bundle)要求辨識敗血症後 **1 小時內開始**以下處置：

1. **測乳酸**；> 2 mmol/L 時 2–4 小時內再測。
2. **給抗生素前先抽血液培養**，但不能因此明顯延誤抗生素。
3. **給廣效抗生素**：可能為敗血性休克者 **1 小時內**給；可能為敗血症但無休克者，3 小時內給。
4. 低血壓或乳酸 **≥ 4 mmol/L**：**晶體液 30 mL/kg**，前 **3 小時內**給完。
5. 輸液中或輸液後仍低血壓：給**升壓劑**，維持 **MAP ≥ 65 mmHg**，首選 **norepinephrine**([[inotropes]])。

其他處置：
- **控制感染源**：引流膿瘍、清創、手術處理腸穿孔；感染來自**中心靜脈導管**時應**儘快移除管路**。
- **抗生素調整**：拿到培養結果後改用窄效藥物(**降階**)。一般療程約 **7–10 天**，依感染部位調整([[antibiotics-overview#empiric-definitive]])。
- **輸液監測**：追蹤 **MAP**、**尿量(≥ 0.5 mL/kg/h)**、心跳、微血管回填、意識與乳酸；收縮壓仍 < 80–90 mmHg 表示需要調整輸液或升壓劑。
- 需大量升壓劑仍不穩定時，可加 vasopressin 或**類固醇**(hydrocortisone)。
- **DIC**：**優先治療敗血症本身**；依出血與檢驗值輸血小板、新鮮冷凍血漿等**成分血**，不是全血。
- **呼吸**：依血氧給氧氣；ARDS 或意識差時才插管。插管不是一到急診就要立刻做的處置，要先建立靜脈管路輸液並抽培養。

:::note[舊答案：早期目標導向治療(EGDT)]
107-2 內外 078 的選項「輸液治療並維持**中心靜脈壓 ≥ 8 mmHg**」被當成正確敘述。這是 2001 年 EGDT 的目標(CVP 8–12 mmHg、ScvO₂ ≥ 70%)。之後 ProCESS、ARISE、ProMISe 三個大型試驗都顯示 EGDT 沒有降低死亡率，現行 Surviving Sepsis 2021 已**不再用 CVP 目標**，改以 MAP、尿量、乳酸、微血管回填等動態指標引導輸液([Surviving Sepsis 2021](https://doi.org/10.1007/s00134-021-06506-y))。該題的錯誤選項是「先給抗生素再抽血液培養」。
:::

## 護理措施 {#nursing}

1. **早期辨識**：監測生命徵象、意識與尿量；感染病人出現**呼吸快、意識改變、血壓下降**時立即通報。
2. **血液培養**：給抗生素前，**兩套分別在不同部位抽**；瓶口用**酒精**消毒(不用碘酒)；用空針抽血時**先注入厭氧瓶**([[culture-and-sensitivity#blood-culture]])。
3. **準時給抗生素**，給完第一劑後監測過敏反應。
4. **建立大管徑靜脈管路**，依醫囑快速輸液；聽診肺部，注意肺水腫。
5. **升壓劑**：最好經**中心靜脈**給，監測外滲。
6. **留置導尿管**，每小時記錄尿量；監測乳酸、血糖、電解質、凝血功能。
7. **出血預防**：DIC 時觀察皮膚瘀斑、牙齦與注射部位出血。
8. **發燒護理**：體溫過低時用溫暖的靜脈輸液、逐步回溫，避免快速加溫。
9. **感染管制**：手部衛生、管路組合式照護，早期移除不必要的管路([[infection-control#bundles]])。
10. **兒童病人**：加護病房的學齡兒童常在意父母是否準時探視，這是**分離焦慮**；安排固定探視並讓家長參與照顧。

:::note[舊答案：用碘酒消毒培養瓶口]
111-2 基護 051 問血液培養時哪些做法錯誤，答案是 ①③④：先打抗生素再抽、兩套同時同部位抽、先注入需氧瓶。「注入前用**碘酒**消毒瓶口」沒有被列為錯誤。現行做法是瓶口用 **70% 酒精**消毒並待乾，碘劑會殘留在橡皮塞上([[culture-and-sensitivity#blood-culture]])。遇到這題可依公布答案作答，實務上用酒精。
:::
