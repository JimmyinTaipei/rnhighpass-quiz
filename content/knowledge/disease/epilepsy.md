**癲癇**是大腦神經元**反覆、不受控制的同步異常放電**，造成發作性的意識、動作、感覺或行為改變。單次因發燒、低血糖、戒酒等明確原因引起的抽搐不一定是癲癇。用藥(phenytoin 濃度、副作用、停藥原則)見 [[antiepileptics]]，兒童熱性痙攣見 [[pediatric-respiratory-infections#febrile-seizure]]

## 重點摘要 {#summary}

- **診斷靠腦波(EEG)**找異常放電；電腦斷層與磁振造影找**原因**(腫瘤、中風、外傷)，**不能確定**放電位置
- 分類：**局部發作**(舊稱部分發作；有意識障礙的舊稱複雜性部分發作，常源自**顳葉**、發作前有**先兆**)、**全身發作**(強直陣攣＝大發作、失神＝小發作、肌躍、失張力)
- **強直陣攣發作**：意識喪失 → **強直期**(全身僵直、**牙關緊閉**、雙腳伸直、呼吸暫停、發紺)→ **陣攣期**(規律抽動)→ **發作後期**(混亂、嗜睡、頭痛)
- **發作時**：保護頭部、移開危險物、**側臥**讓分泌物流出、鬆開衣領；**不約束肢體**、**不把任何東西塞進嘴裡**、**不需叫醒**、不做口對口人工呼吸；**記錄開始時間與發作型態**
- **癲癇重積狀態**：發作超過 **5 分鐘**，或反覆發作、**兩次之間意識沒有恢復**；局部發作與失神發作也會重積；最常見誘因是**自行停藥**
- 重積狀態處置：**先確保安全、維持呼吸道並給氧**，再依醫囑靜脈注射短效 benzodiazepine
- 兒童：避免騎腳踏車、攀高與無人陪伴游泳；藥物難治時可用**生酮飲食**(高脂、極低醣)

### 國考常考點 {#exam-points}

- 確立癲癇診斷的檢查：**腦波**；電腦斷層**不能**確定異常放電位置
- 發作時：**頭偏向一側**或側臥讓唾液流出、**移開枕頭**、確認氧氣與抽吸設備；病人意識不清**不需叫醒**
- 不可：**從嘴角塞藥**、**用力扳開牙齒**、**約束肢體**、按壓病人、強行放壓舌板
- 意識不清的發作：拉起床欄但**不約束**、不從嘴角給藥、**平臥頭側向一邊**、不給刺激
- 額葉腦瘤術後突然全身抽搐：給 100% 氧氣、記錄部位與時間、確認床欄；**不要喚醒**
- 學校發作：側臥、疏散人群、移開硬物；**不做口對口人工呼吸**；**不用壓額抬下巴**；記錄型態與時間
- 重積狀態：靜脈給短效抗癲癇藥(benzodiazepine)、**一次發作超過 5 分鐘**、兩次之間意識沒恢復；**小發作與局部發作也會**重積
- 重積狀態：確認安全後**維持呼吸道、給氧最優先**；最常見原因**不是強光**(是停藥)；定義不是 60 分鐘；**不要按壓或喚醒**
- 學齡兒童癲癇較不適當的運動：**騎腳踏車**(穿救生衣游泳、羽毛球、跑步可以)
- 生酮飲食：**高脂肪、低醣類**(不是高蛋白)；用於**難治型**癲癇；酮體有鎮定作用(考題答案)；**不需要增加水分**
- 重積病童的以家庭為中心照護：父母可參與照顧、決策與侵入性處置(依意願)；**不應避免父母參與**治療計畫

## 分類 {#classification}

| 2025 ILAE 分類 | 舊稱 | 特徵 |
|---|---|---|
| **局部發作**，意識保留 | 單純性部分發作 | 一側肢體抽動、麻木、怪味或怪光等；意識清楚 |
| **局部發作**，意識受影響 | **複雜性部分發作**(精神運動性發作) | 常源自**顳葉**；發作前有**先兆**(怪味、似曾相識感、上腹不適)；凝視、咂嘴、搓手等**自動症**；事後不記得 |
| 局部進展成雙側強直陣攣 | 次發性全身發作 | 從局部開始再擴散 |
| **全身強直陣攣** | **大發作** | 見下方 |
| **失神** | **小發作** | **兒童**；突然發呆數秒、眼皮眨動，**沒有跌倒與發作後期**，一天可發作很多次；過度換氣可誘發；腦波 **3 Hz 棘慢波**；用 **ethosuximide**、valproate |
| 肌躍 | | 短暫電擊般的肌肉抽動，常在早上 |
| 失張力 | 跌倒發作 | 突然肌肉無力跌倒，要戴頭盔 |
| 不明、無法分類 | | 資料不足時 |

- 2025 年 ILAE 分類用「**意識**」是否受影響取代以前的「覺察」(來源：[ILAE 2025 發作分類](https://www.ilae.org/updated-classification-epileptic-seizures-2025))；國考題目多用舊稱，作答時兩種名稱都要認得
- 常見原因：先天或基因、**腦傷**(外傷、中風、腫瘤、感染)、發育異常；也有找不到原因的
- 誘發因素：**漏藥或自行停藥**、**睡眠不足**、**飲酒**與戒酒、壓力、**發燒與感染**、閃光(光敏感型)、低血糖、電解質異常、月經

### 強直陣攣發作的過程 {#tonic-clonic}

1. **先兆**(不一定有)：局部發作開始的表現
2. **強直期**(數十秒)：突然**意識喪失**跌倒，可能大叫一聲；**全身肌肉僵直**、**牙關緊閉**、**雙腳伸直**、**呼吸暫停**、**發紺**、瞳孔放大
3. **陣攣期**(1–2 分鐘)：肢體**規律抽動**、口吐白沫、可能**咬傷舌頭**、尿失禁
4. **發作後期**：意識混亂、嗜睡、頭痛、肌肉痠痛，可能有暫時性肢體無力(Todd 麻痺)；**不記得**發作經過

- 順序是先強直、後陣攣；「陣攣後期才出現牙關緊閉與雙腳伸直」是錯的

## 發作時的處置 {#first-aid}

1. **保持冷靜、記錄時間**：發作開始時間、持續多久、從哪裡開始、型態、眼睛方向、有無失禁
2. **保護安全**
   1. 在床上：**拉起並包覆床欄**，**移開頭下枕頭**(避免口鼻悶住)
   2. 在地上：**移開身旁堅硬、尖銳物**，頭下墊軟物
   3. **疏散圍觀人群**，保持通風；鬆開領口與緊身衣物
3. **維持呼吸道**
   1. **側臥或頭偏向一側**，讓唾液與嘔吐物流出
   2. **不要把任何東西放進嘴裡**(壓舌板、藥物、手指)，**不要用力扳開牙齒**：會斷牙、阻塞呼吸道、咬傷施救者
   3. 抽搐中**不做口對口人工呼吸**，也**不做壓額抬下巴**；備好**氧氣與抽吸設備**
4. **不約束、不壓制肢體**(會骨折或脫臼)
5. **不需叫醒病人**，也不要給刺激；發作中意識不清是預期的
6. **發作後**：維持側臥(復甦姿勢)、評估呼吸、意識與受傷情形、讓病人休息；完全清醒前不給飲食
7. **需要叫救護車或通知醫師**：超過 **5 分鐘**、一次接一次、意識沒恢復、受傷、水中發作、懷孕、第一次發作

## 癲癇重積狀態 {#status-epilepticus}

- **定義**：發作持續 **5 分鐘以上**，或反覆發作、**兩次之間意識沒有恢復**；舊定義是 30 分鐘，**60 分鐘是錯的**；**任何型態**(包括局部發作、失神發作)都可能重積
- **最常見原因**：**自行停藥**或漏藥；其他是感染發燒、飲酒與戒酒、腦傷、代謝異常(不是強光)
- **處置**(來源：[美國癲癇學會 2016 指引](https://aesnet.org/clinical-care/clinical-guidance/guideline-prolonged-seizures))
  1. 確保安全後，**維持呼吸道、給氧**最優先；監測生命徵象與心電圖、驗血糖
  2. **靜脈注射短效 benzodiazepine**(lorazepam、diazepam；沒有靜脈管路時肌肉注射 midazolam)
  3. 仍持續發作時給 fosphenytoin、valproate 或 levetiracetam(藥物流程見 [[antiepileptics#status-epilepticus]])
  4. 抽搐時**不要按壓**或試圖喚醒病人
- 持續發作可能造成缺氧、高熱、橫紋肌溶解與永久腦傷，是急症

## 長期照護與衛教 {#nursing}

1. **規律服藥**，不可自行停藥；定期驗血中濃度(見 [[antiepileptics#nursing]])
2. **記錄發作日誌**：日期、時間、型態、誘因，回診時給醫師參考
3. 避免誘因：**充足睡眠**、不喝酒、規律生活、減壓；光敏感者注意閃爍光線
4. **安全**
   1. 避免**高處**、**獨自游泳**或泡澡(改淋浴)、操作危險機器
   2. 駕駛依法規與醫師評估；台灣不是一律不能考照
   3. 戴醫療識別手環
5. 懷孕前與醫師討論藥物、補充葉酸，**不可自行停藥**
6. 心理社會：污名、就學就業歧視、焦慮與憂鬱；《學校衛生法》要求學校對癲癇等學生**加強輔導與照顧**


### 兒童 {#children}

- 運動：鼓勵參加，但**避免騎腳踏車**、攀爬高處；游泳要**穿救生衣並有人一對一陪伴**；羽毛球、跑步等平地運動可以
- 在學校發作的處置同上，老師與同學要知道怎麼做
- **生酮飲食**
  1. **高脂肪、極低醣、適量蛋白質**(脂肪與非脂肪約 3:1 或 4:1)，讓身體以**酮體**作為腦的能量來源
  2. 用於**藥物難治型**癲癇，不是藥物控制良好的兒童
  3. 不需要增加液體攝取；要監測血酮、血糖、生長、腎結石與血脂
- **以家庭為中心的照護**：彈性探訪、依父母意願讓其參與照顧與侵入性處置、隨時說明病況，並**讓父母參與治療計畫與決策**
