**腎絲球疾病**是腎絲球的過濾膜受到免疫或其他原因傷害。國考主要比較兩種表現：**腎炎**（發炎為主：血尿、高血壓、腎功能下降）與**腎病症候群**（漏蛋白為主：大量蛋白尿、低白蛋白、水腫、高血脂）。腎絲球的構造見 [[kidney-urinary-physiology]]，尿液檢查見 [[urinalysis]]，水腫機轉見 [[edema-shock]]

## 重點摘要 {#summary}

- **急性腎絲球腎炎**(AGN, acute glomerulonephritis)：多在 **A 群 β 型溶血性鏈球菌**喉嚨或皮膚感染後 **1–3 週**；屬**第三型過敏**（免疫複合體沉積）；**不是**泌尿道感染
- AGN 表現：**血尿**（茶色、可樂色尿）、**高血壓**、眼瞼與臉部**水腫**、**少尿**、輕到中度蛋白尿；**GFR(glomerular filtration rate) 下降**、BUN(blood urea nitrogen) 上升；**ASO(antistreptolysin O) 上升、C3 下降**
- AGN 照護：**急性期臥床**、**限鈉與水**、**少尿期避免高鉀**（香蕉、柳橙、牛奶、蛋）、每天同時同秤量體重、**密切監測血壓**；喉嚨痛或皮膚感染要早治療
- **腎病症候群**：腎絲球**通透性過高** → **大量蛋白尿**（成人 ≥ 3.5 g/天）、**低白蛋白血症**、**全身水腫**、**高血脂**；血壓多正常
- 兒童腎病症候群多為**微小變化疾病**：光學顯微鏡正常、電子顯微鏡見**足細胞足突消失**；**類固醇反應好**(> 90%)
- 腎病症候群照護：**利尿劑與限鈉水**控制水腫、**正常量蛋白質**（不是低蛋白）、**抗凝劑**防血栓、預防**感染**與**皮膚破損**（勤翻身）
- **多囊腎**：**體染色體顯性**、多在 **40 歲後**發病；腰痛、血尿、高血壓、腎臟摸得到；用**超音波**診斷

### 國考常考點 {#exam-points}

- 腎炎 vs 腎病症候群：**兩者都有水腫與蛋白尿**；**血尿**是腎炎、**高血脂**是腎病症候群
- AGN：
   1. **補體 C3 下降**（「C3、C4 上升」是錯的）；**GFR 下降**（「GFR 上升」是錯的）
   2. 主要是**血尿**，**不是大量蛋白尿**
   3. 抗生素只用在仍有鏈球菌感染時，**不需長期服用 penicillin**，也不是上呼吸道感染就要吃抗生素
   4. 兒童少尿期：**避免牛奶、蛋、香蕉**等高鉀食物；**不吃洋芋片、海苔、蘇打餅**等高鈉零食；尿量維持 **1–2 mL/kg/h**
   5. **急性期臥床**，不是「多下床活動減輕水腫」
   6. BUN 100 mg/dL 時採**低蛋白**、高碳水化合物；不是高蛋白，也不是生酮飲食
- 慢性腎絲球腎炎：BUN、肌酸酐**上升**、CCr(creatinine clearance) **下降**；**腎切片**可早期確診；腎臟**變小**、皮質萎縮
- 腎病症候群：
   1. 檢查：**蛋白尿、白蛋白下降、膽固醇與三酸甘油酯上升**；**沒有菌尿**、血鈣不會上升
   2. 主要變化是**腎絲球通透性過高**；水腫因**血漿膠體滲透壓下降**
   3. 照護：**利尿劑＋限水**控制水腫；嚴重水腫**臥床**，不是多下床；腎功能正常時蛋白質**正常或偏高**，不是低蛋白；不需補鈉
   4. 兒童水腫皮膚照護：**要經常翻身**、寬鬆棉質衣服、支托、保持皺摺處乾燥
   5. 兒童腎病症候群與微小變化疾病：**不是鏈球菌引起**、**不靠抗生素**、通常**沒有高血壓與明顯血尿**
- **快速進行性腎絲球腎炎**(RPGN, rapidly progressive glomerulonephritis)：病理特徵**新月體**；原因有 Goodpasture 症候群、紅斑性狼瘡、鏈球菌感染後；**NSAID(nonsteroidal anti-inflammatory drug) 不是**
- **IgA 腎病變**（Berger 氏病）：**全世界最常見的原發性腎絲球腎炎**；IgA 沉積在**繫膜區**；血尿與蛋白尿；好發**年輕人**（不是老年女性）
- 多囊腎：**不是青春期**發病（成人型多在 40 歲後）；**嬰兒型是體染色體隱性**

## 腎炎與腎病症候群比較 {#comparison}

| | 急性腎絲球腎炎（腎炎） | 腎病症候群 |
|---|---|---|
| 核心問題 | 腎絲球**發炎** → 過濾下降、紅血球漏出 | 腎絲球**通透性過高** → 白蛋白大量漏出 |
| 常見原因 | **A 群 β 型溶血性鏈球菌**感染後 | 兒童多原因不明（**微小變化疾病**）；成人多為膜性腎病變或續發於糖尿病、狼瘡 |
| 好發年齡（兒童） | **6–12 歲** | **2–5 歲** |
| 水腫 | **局部**（眼瞼、臉部，早上明顯） | **全身**，可有腹水、肋膜積水、陰囊水腫 |
| 血壓 | **升高** | 正常或降低 |
| 蛋白尿 | 輕到中度 | **大量**（試紙 3＋～4＋） |
| 血尿 | **明顯**（茶色尿） | 少或無 |
| BUN、肌酸酐 | **上升** | 多正常 |
| 血清白蛋白 | 輕微下降（稀釋） | **明顯下降** |
| 血脂 | 正常 | **升高** |
| 治療 | 支持療法；有感染證據才給抗生素 | **類固醇**為主 |
| 預後 | 多數完全恢復、很少再發 | 常**復發** |

- 來源：《實用兒科護理》p.600 表 11-4、《內外科護理學》下冊 p.791–796 整理

## 急性腎絲球腎炎 {#agn}

### 病因與機轉 {#agn-pathophysiology}

- 鏈球菌抗原與抗體形成**免疫複合體**，沉積在腎絲球 → 活化**補體** → 發炎 → 過濾膜受損，**紅血球與蛋白質漏到尿中**；過濾面積減少 → **GFR 下降**、鈉與水滯留 → **少尿、水腫、高血壓**（《實用兒科護理》p.594–595）
- 屬於**第三型（免疫複合體型）過敏反應**，見 [[hypersensitivity-reactions]]
- 感染後約 **1–2 週**（上呼吸道）或 **2–3 週**（皮膚）發病；兒童以 **6–12 歲男童**較多，3 歲以下少見、很少再發（同書 p.594）
- 其他可造成腎炎的原因：細菌性心內膜炎、B 型肝炎等感染；**紅斑性狼瘡**、**IgA 血管炎**（舊稱 Henoch–Schönlein 紫斑症）、Goodpasture 症候群（《內外科護理學》下冊 p.791 表 19-9 整理）
- 鏈球菌本身見 [[streptococci]]

### 臨床表徵與檢查 {#agn-diagnosis}

- **血尿**：少量**深茶色、可樂色**尿；尿中有紅血球、**紅血球圓柱體**、蛋白質，**沒有菌尿**
- **水腫**：以**臉部、眼瞼**為主，早上明顯
- **高血壓**：嚴重時頭痛、視力模糊，甚至**高血壓性腦病變**（抽搐、昏迷）
- **少尿**、體重增加；體液過多可出現呼吸困難、肺水腫
- 檢查：
   1. **ASO（抗鏈球菌溶血素 O）上升**：證明之前有鏈球菌感染（皮膚感染後較少上升）
   2. **C3 下降**，約 6–8 週恢復正常（《實用兒科護理》p.595）；課本內外科寫 C3、C4 都下降（《內外科護理學》下冊 p.792），腎臟學教科書一般寫 PSGN(post-streptococcal glomerulonephritis) 的 C4 多正常
   3. BUN、肌酸酐上升（兒童 BUN 多不超過 100 mg/dL）；GFR 下降
   4. 兒童通常不需腎切片；成人可做腎切片了解病理與預後
- 病程：急性期約 1–2 週後進入**利尿期**，尿量增加、血壓下降；肉眼血尿 1–2 週緩解，顯微鏡血尿可持續到 1 年（《實用兒科護理》p.595）

### 治療與護理 {#agn-nursing}

- 治療以**支持療法**為主，多數兒童會自行恢復
   1. **抗生素**：喉頭或皮膚培養出鏈球菌時才給(penicillin)，目的是限制細菌散播，**不改變腎炎病程**；**不需長期預防性服用**
   2. 利尿劑(furosemide)、降血壓藥
   3. 成人嚴重或自體免疫型：類固醇、免疫抑制劑，必要時**血漿去除術**（《內外科護理學》下冊 p.792）
- **活動**：**急性期臥床休息**，直到肉眼血尿消失、水腫消退、血壓恢復；恢復後避免劇烈運動到血尿、蛋白尿消失（《實用兒科護理》p.596–597）
- **飲食**：
   1. **限鈉**：不另外加鹽；避免**洋芋片、海苔、鹹蘇打餅**等高鈉點心
   2. **限水**：兒童每天尿量 < 200–300 mL 時限水；把可喝的量分配到白天，用小杯子讓孩子覺得量多
   3. **少尿期限鉀**：避免**香蕉、柑橘、葡萄、牛奶、蛋、瘦肉**
   4. **蛋白質**：兒童一般不需限制，除非 **BUN 達 100 mg/dL**；成人腎功能恢復前**適度限蛋白、高醣**提供熱量（《內外科護理學》下冊 p.792–793）
   5. 利尿期開始、血壓下降後飲食即可恢復
- **監測**：每天固定時間、同一磅秤、相同衣著量**體重**；**輸入輸出量**；**血壓**（兒童約每 4 小時）；觀察頭痛、躁動、視力模糊、抽搐等高血壓腦病變徵象；兒童尿量維持約 **1–2 mL/kg/h**
- **預防**：喉嚨痛、皮膚感染要**早期就醫治療**；避免與感冒的孩子一起玩

## 慢性腎絲球腎炎 {#cgn}

- 腎絲球慢慢被瘢痕與纖維組織取代；可由急性腎炎進展而來，也可能一開始就是慢性；紅斑性狼瘡、糖尿病、高血壓等全身疾病也會造成類似變化（《內外科護理學》下冊 p.794）
- 表現：初期症狀不明顯，**高血壓**最主要；夜尿、蛋白尿、水腫；最後進展到**尿毒症**
- 檢查：
   1. 影像：**腎臟變小**、皮質萎縮（不是變厚變大）
   2. **腎臟活體組織切片**可**早期確診**
   3. **BUN、肌酸酐上升**，**肌酸酐清除率下降**；尿比重低、蛋白尿、紅血球圓柱體
- 處置：控制血壓與水腫、預防感染；進展到腎衰竭時透析或移植，照護見 [[chronic-kidney-disease]]

## 腎病症候群 {#nephrotic}

### 病因與機轉 {#nephrotic-pathophysiology}

- 腎絲球過濾膜（尤其**足細胞**）受損 → **通透性增加** → **大量蛋白尿** → **低白蛋白血症** → **血漿膠體滲透壓下降** → 水移到組織間隙 → **水腫**
- 血管內容積減少 → 刺激**腎素–血管收縮素–醛固酮**與**抗利尿激素** → 鈉與水再滯留 → 水腫更嚴重
- 肝臟加速合成蛋白質時一併合成脂蛋白 → **高膽固醇、高三酸甘油酯**
- 尿中流失抗體(IgG)與補體因子 → **容易感染**（兒童常見**腹膜炎**）；凝血因子失衡 → **血栓**（腎靜脈栓塞）
- 來源：《內外科護理學》下冊 p.795–796；《實用兒科護理》p.598
- 原因：
   1. 原發性腎絲球疾病：**兒童以微小變化疾病為主**（80–90% 為原發性）；**成人以膜性腎病變為主**；其他如局部節段性腎絲球硬化(FSGS, focal segmental glomerulosclerosis)
   2. 續發性：**糖尿病**、**紅斑性狼瘡**、類澱粉沉積症、B 型肝炎、腫瘤、藥物（含 NSAID）

### 臨床表徵與檢查 {#nephrotic-diagnosis}

- **水腫**：最早常是**眼眶周圍**（早上明顯），逐漸**全身**，包括腹水、肋膜積水、**陰囊水腫**；皮膚蒼白如蠟；體重增加、衣服變緊
- 尿液**泡沫多**、尿量減少；血壓多正常或偏低
- 檢查：
   1. 成人：尿蛋白 **≥ 3.5 g/天**；血清白蛋白 **< 3 g/dL**；膽固醇 **> 300 mg/dL**（《內外科護理學》下冊 p.796）
   2. 兒童：試紙尿蛋白 **3＋～4＋**、血清白蛋白 **< 2.5 g/dL**、膽固醇 **> 200 mg/dL**；BUN 與肌酸酐多**正常**；微小變化型多**沒有血尿**（《實用兒科護理》p.599）
   3. 腎切片：成人用來確診與判斷預後；12 歲以下、沒有特殊表現的兒童通常先用類固醇（KDIGO，Kidney Disease: Improving Global Outcomes 2025 兒童腎病症候群）

::questions{ids="115-2_BM_028,112-1_OP_074,110-1_BM_038,108-2_BM_038,106-2_makeup_BM_045"}

### 治療 {#nephrotic-treatment}

- **類固醇**(prednisolone)：
   1. 微小變化疾病對類固醇反應很好(**> 90%**)，多在 1–3 週內蛋白尿減少、開始利尿
   2. 課本療程：每天 2 mg/kg 分次服用 4 週 → 改隔日給藥 4 週 → 在 2–4 個月內逐漸減量停藥（《實用兒科護理》p.599）
   3. **KDIGO 2025** 兒童首次發作：口服類固醇共 **8 週**（每日 4 週＋隔日 4 週）**或 12 週**（每日 6 週＋隔日 6 週）；復發時每日 60 mg/m² 或 2 mg/kg（最多 60 mg）到完全緩解 3 天，再改隔日 40 mg/m² 或 1.5 mg/kg（最多 40 mg）4 週；以前「延長到半年」的做法已不建議
   4. 治療 4 週沒有完全緩解要進一步評估（類固醇抗性）；經常復發或類固醇依賴者改用**免疫抑制劑**（cyclophosphamide、calcineurin 抑制劑、rituximab 等），見 [[immunosuppressants]]
- **利尿劑**(furosemide)＋必要時**靜脈白蛋白**：嚴重水腫時使用，見 [[loop-diuretics]]
- **抗凝劑**：預防腎靜脈血栓；教導避免受傷、觀察出血
- 成人另可用 ACEI(angiotensin-converting enzyme inhibitor)／ARB(angiotensin II receptor blocker) 降低蛋白尿、降血脂藥
- 類固醇副作用與衛教見 [[corticosteroids]]

### 護理 {#nephrotic-nursing}

- **體液**：每天同一時間、同一磅秤量**體重**；**腹圍**（兒童急性期每 4 小時）；**輸入輸出量**；呼吸困難時抬高床頭
- **飲食**：
   1. **限鈉**（成人 0.5–1 g/天；兒童急性期 < 1,500 mg/天）；避免洋芋片、海苔、鹹蘇打餅、醃漬物
   2. **限水**以減輕水腫
   3. **蛋白質正常量**：成人 0.8–1 g/kg/天、以動物性蛋白為主，搭配高熱量；腎功能下降時才減少（《內外科護理學》下冊 p.796）；兒童 0.9–1.8 g/kg/天（《實用兒科護理》p.601）
   4. 服利尿劑時注意補鉀
- **活動**：**嚴重水腫時臥床休息**，可減輕腎臟負擔與水腫；水腫改善後鼓勵上學與日常活動
- **皮膚**：水腫皮膚易破損 → **每 2 小時翻身**、軟墊保護骨突處、**寬鬆棉質衣服**、保持皺摺處清潔乾燥、陰囊水腫用支托帶、避免在水腫肢體注射
- **預防感染**：觀察發燒、**腹痛腹脹**（腹膜炎）；避免接觸感染者；**勤洗手**；同房病童避免安排有感染的孩子
- **類固醇衛教**：**不可自行停藥**；月亮臉、食慾增加、高血糖、低血鉀、易感染、生長遲緩，停藥後改善
- **疫苗**：類固醇治療期間**不可打活性減毒疫苗**（麻疹、水痘等），常規疫苗停藥後約 3 個月再打；不活化疫苗可打（《實用兒科護理》p.602）
- 外觀改變帶來的低自尊：用治療性遊戲讓孩子表達感受

## 其他腎絲球疾病 {#other-gn}

- **快速進行性腎絲球腎炎**(RPGN)：數週到數月內腎功能快速惡化；病理特徵是鮑氏囊內的**新月體**
   1. 原因：抗腎絲球基底膜抗體（**Goodpasture 症候群**，同時侵犯肺 → 咳血）、免疫複合體（**紅斑性狼瘡**、鏈球菌感染後、IgA）、ANCA 相關血管炎
   2. 治療：類固醇、免疫抑制劑、**血漿去除術**
- **IgA 腎病變**（Berger 氏病）：
   1. **全世界最常見的原發性腎絲球腎炎**，也是慢性腎臟病的重要原因
   2. IgA 沉積在腎絲球**繫膜區**
   3. 常在上呼吸道感染時出現**血尿**，合併蛋白尿；好發**年輕人**，男性較多
   4. KDIGO 2025 IgA 腎病變與 IgA 血管炎指引已出版，治療以控制血壓與蛋白尿為主
- **狼瘡腎炎**：見 [[sle]]
- **糖尿病腎病變**：見 [[chronic-kidney-disease]]、[[diabetes#nephropathy]]

## 多囊性腎病 {#polycystic}

- **成人型**：**體染色體顯性遺傳**（第 16 對染色體為主），雙側腎臟長滿充滿液體的囊泡，壓迫腎元，最後腎衰竭；**多在 40 歲以後**發病（《內外科護理學》下冊 p.797）
- **嬰兒型**：**體染色體隱性遺傳**，見 [[single-gene-disorders]]
- 表現：**腰痛**（最常見；鈍痛或囊泡破裂的尖銳痛）、**血尿**、夜尿、**泌尿道感染**、**高血壓**；腎臟比正常大 2–3 倍、摸得到（觸診要輕）
- 檢查：**超音波**或電腦斷層確認囊腫；避免顯影劑
- 治療：止痛（**避免阿斯匹靈**，怕出血）、利尿劑、降血壓、感染用抗生素；低鹽、避免蛋白質過量與脫水；末期透析或移植
- 護理：
   1. 早期**多喝水**（約 2,500 mL/天）；腎功能變差時改為限水
   2. 遺傳諮詢，家人定期追蹤
   3. 預防泌尿道感染、不亂吃成藥或中藥
- 來源：《內外科護理學》下冊 p.797–798
