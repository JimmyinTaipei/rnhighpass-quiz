**強迫症**的核心是兩件事：反覆闖入、讓人極度不安的**強迫思考**，以及為了減輕這份不安而不得不做的**強迫行為**。病人多半知道這些想法與行為**不合理、過度**，卻難以抗拒，耗費大量時間並影響生活。強迫症在 DSM-5 已獨立成「強迫症及相關障礙症」，但臨床上仍與焦慮密切相關，焦慮的分級與護理見 [[anxiety-disorders]]，防衛機轉見 [[psychodynamic-theories#defense-mechanisms]]

## 重點摘要 {#summary}

- **強迫思考**：反覆、侵入、不想要的念頭、衝動或影像（怕髒、怕傷害他人、對稱、宗教或性），引起強烈焦慮
- **強迫行為**：為了降低焦慮而重複的**動作**（洗手、檢查、排列）或**心智活動**（默數、默念）；兩者有其一、耗時或造成困擾即可診斷
- 多數成人**有病識感**、覺得不合理；兒童與部分病人病識感較差；常用**抵消、隔離、反向、理智化**
- 治療：**SSRI**（如 fluvoxamine）＋**暴露及反應預防(ERP)**，兩者合併效果最好
- 護理：**剛入院先接納**儀式行為以降低焦慮，建立信任後**逐步減少**；評估**自傷與皮膚破損**，必要時戴手套；**不約束、不強迫中止**

### 國考常考點 {#exam-points}

- **強迫行為**＝難以自我控制地重複某些動作或行為；不是作態動作（把正常動作做得誇張），也不是刻板行為
- 強迫症的防衛機轉：**抵消**（強迫行為最相關）、**隔離**、**反向**、**理智化**；**內射、合理化、投射**都不是
- 心中默念圓周率以消除「希望妹妹死掉」的念頭 → **抵消**
- **成人多半有病識感**，知道不合理；**兒童不一定**知道過度；發病前常有**求全、完美、固執、缺乏彈性**的傾向
- 強迫症不一定要強迫思考與強迫行為同時出現；也不是「最常在中年」發生，多在青少年到成人早期
- **首選藥物**：**SSRI**（如 **fluvoxamine**）；短效 BZD、興奮劑、抗精神病藥都不是首選
- **最有效的行為治療**：**暴露及反應預防**；強迫症的治療需**藥物加行為治療**
- **剛入院**覺得門把髒、用紙包著才轉 → **提供紙張直到焦慮減輕**；不要強迫觸摸、不要講道理、不要叫他去洗門把
- 強迫洗手到破皮 → **評估自我傷害**，必要時**戴手套**洗手；護理目標**不是直接中止**洗手
- 協助覺察焦慮與行為的關係：「**我看到妳在咬指甲和走來走去，妳現在覺得怎麼樣？**」
- 強迫症狀急性焦慮期的措施：**同理焦慮、用溝通技巧協助解決問題、評估過去的因應技巧**；**不約束隔離**

## 臨床表現 {#manifestations}

### 強迫思考與強迫行為 {#obsessions-compulsions}

| 主題 | 強迫思考 | 常見強迫行為 |
|---|---|---|
| 汙染 | 怕細菌、怕髒、怕被傳染 | **重複洗手**、清潔、用紙包門把 |
| 懷疑與傷害 | 怕門沒鎖、怕瓦斯沒關、怕自己傷害別人 | **重複檢查**、反覆確認 |
| 對稱與秩序 | 東西必須排整齊、對稱 | 排列、重新擺放 |
| 禁忌念頭 | 傷害家人、褻瀆、性的念頭 | **心智活動**：默念、默數、祈禱，用來「抵消」念頭 |

1. 強迫思考是**自己的**念頭，病人知道它來自自己的腦中，這點與思覺失調症的**思想插入**不同
2. 強迫行為通常與要消除的事**沒有實際關聯**，或明顯過度
3. 症狀耗費大量時間（例如每天超過 1 小時），或造成明顯痛苦與功能減損
4. 病人常覺得想法**不合理、並非自己所願**，試圖抗拒，但抗拒時焦慮更高，最後還是做了

### 病識感 {#insight}

1. DSM-5 依病識感分為：**良好或尚可**、**差**、**缺乏病識感或有妄想信念**
2. 大多數成人病人知道症狀過度且不合理
3. 兒童與青少年常**缺乏足夠病識感**，不一定認為強迫行為過度

### 相關疾病 {#related-disorders}

| 疾病 | 重點 |
|---|---|
| **身體臆形症** | 執著於自認外表的缺陷，反覆照鏡、整形 |
| **囤積症** | 難以丟棄物品，堆積造成生活空間受影響 |
| **拔毛症、摳皮症** | 反覆拔頭髮或摳皮膚，難以停止 |
| **強迫型人格障礙症** | 完美主義、重視細節與規則、**固執缺乏彈性**；**不是**強迫思考與強迫行為；病人多不覺得自己有問題（自我協調），細節見 [[personality-disorders#cluster-c]] |

:::warning[容易混淆]
**強迫症**的症狀讓病人痛苦、想抗拒（自我不協調）；**強迫型人格障礙症**是長期的人格特質，病人通常認為自己的標準才是對的（自我協調）
:::

## 病因 {#etiology}

1. **生物**
   1. **血清素**調節失調，所以 SSRI 有效
   2. 大腦**眼眶額葉、扣帶迴與基底核**的迴路過度活躍
   3. 遺傳；少數兒童與鏈球菌感染後的自體免疫有關（教科書通則）
2. **精神分析**
   1. 與**肛門期**的衝突與固著有關
   2. 常用的防衛機轉：**抵消、隔離、反向、理智化**
3. **學習理論**：強迫行為減輕焦慮，形成**負增強**，所以行為被維持
4. 病前人格常有**求全、完美主義、強調是非、缺乏通融**

### 防衛機轉的對應 {#defenses}

| 機轉 | 在強迫症的表現 |
|---|---|
| **抵消** undoing | 重複洗手、默念數字，以消除不被接受的念頭或罪惡感；**與強迫行為最相關** |
| **隔離** isolation | 情感與想法分開，只剩沒有情緒的強迫念頭 |
| **反向** reaction formation | 對攻擊衝動表現出過度的整潔、禮貌與規矩 |
| **理智化** intellectualization | 有條理地描述喪子細節，卻說不出心中的傷痛 |

## 治療 {#treatment}

1. **藥物**
   1. **SSRI** 為**第一線**：fluvoxamine(Luvox)、fluoxetine、sertraline、paroxetine 等
   2. 強迫症常需要**較高劑量**與**較長時間**（數週到數月）才見效
   3. clomipramine（三環類）也有效，副作用較多
   4. 效果不佳時可加上低劑量抗精神病藥（增強治療）
   5. 細節見 [[antidepressants]]
2. **行為治療**：**暴露及反應預防(ERP)** 最有效；也可用系統減敏感、思考中斷法（見 [[individual-cognitive-behavioral-therapy#exposure-techniques]]）
3. **認知治療**：修正「想到就會發生」「我必須確定百分之百安全」等過度責任感與災難化的想法（見 [[individual-cognitive-behavioral-therapy#cbt]]）
4. **藥物加行為治療**合併效果最好

## 護理 {#nursing}

### 護理原則 {#nursing-principles}

1. **初期接納**儀式行為
   1. 剛入院時強迫行為是降低焦慮的方式，**強迫中止會引發嚴重焦慮甚至恐慌**
   2. 例：病人覺得門把髒、要用紙包著才轉 → **提供紙張，直到焦慮減輕**
   3. 不要強迫他觸摸、不要只是講道理說明不必要、不要叫他負責清洗門把（會強化對髒汙的關注）
2. **建立信任**後，與病人**共同**訂定計畫，**逐步**限制儀式的時間與次數
3. **安全與身體照護**
   1. 評估**自我傷害**的可能性
   2. 洗手過度導致皮膚破損時，可**戴手套**洗手、使用護手霜，處理傷口
   3. 注意營養、睡眠與排泄，儀式可能耽誤基本需求
4. **安排時間**：預留足夠的時間給儀式，避免因時間壓力而增加焦慮；在儀式之外安排結構化活動轉移注意
5. **約束與隔離不適用**：僅有焦慮與強迫行為、沒有立即危險時，不可約束隔離
6. **協助覺察**
   1. 描述觀察到的行為，問病人此刻的感受，例如「我看到妳在咬指甲和走來走去，妳現在覺得怎麼樣？」
   2. 引導病人連結焦慮的出現與強迫行為的關係
   3. 鼓勵描述感受，例如「當時小孩過世時，您的感覺如何？」
7. **同理焦慮**，評估病人過去用過哪些因應技巧，協助學習新的因應方式
8. 家屬衛教：家人不要配合儀式（例如替他反覆檢查），也不要責罵；與家人的衝突會加重症狀

### 衛教 {#education}

1. 說明強迫症是可以治療的疾病，症狀不是病人「想太多」或故意的
2. SSRI 需要數週才見效，要規則服藥，不可自行停藥
3. 練習 ERP 時焦慮會先升高，耐受後才會下降，這是正常的
4. 學習放鬆技巧，作為面對焦慮的替代方式
