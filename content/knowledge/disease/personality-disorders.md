**人格**是一個人相對穩定的想法、情緒、人際與行為方式。當這種方式**僵化、缺乏彈性、在各種場合都一樣**，而且讓自己或身邊的人長期受苦，就是**人格障礙症**。病人通常覺得「我就是這樣」(自我協調)，**很少主動求醫**，多半因為人際、工作或法律問題，或合併憂鬱、物質使用、自傷才被帶來。人格發展理論與防衛機轉見 [[psychodynamic-theories#defense-mechanisms]]

## 重點摘要 {#summary}

- **一般特徵**：內在經驗與行為**明顯偏離文化期待**，表現在**認知、情感、人際功能或衝動控制**中至少兩方面；**持久、缺乏彈性、遍及廣泛情境**；可追溯到**青春期或成年早期**；造成痛苦或**社會職業功能減損**
- **A 群(古怪)**：**妄想型**(多疑不信任)、**孤僻型**(冷漠、偏好獨處)、**思覺失調型**(古怪信念與言行、社交焦慮)
- **B 群(戲劇化、情緒化)**：**反社會型**(漠視並侵犯他人權益、不知悔改)、**邊緣型**(怕被拋棄、人際與情緒不穩、**衝動自傷**、**分裂**)、**做作型**(吸引注意、情緒膚淺多變、性挑逗)、**自戀型**(自大、特權感、缺乏同理)
- **C 群(焦慮害怕)**：**畏避型**(怕批評與拒絕)、**依賴型**(需要被照顧、討好順從)、**強迫型**(完美主義、**固執缺乏彈性**)
- **護理**：**團隊一致**、**清楚設限**並說明對行為的期待、**避免被操縱**、中立**就事論事**、護理師**自我覺察**；常見問題行為是**自傷、操縱、衝動**

### 國考常考點 {#exam-points}

- 人格障礙症可追溯到**青春期或成年早期**，「最早到**成人晚期**才顯現」是錯的
- 與**自我(ego)功能薄弱**有關，自我控制力較差；**和遺傳有關**；衝動與自殺和**血清素(5-HIAA)偏低**有關，不是過高
- 古怪思考與言談、心電感應、身體飄起的錯覺、社交焦慮**不隨熟悉而減少**、壓力下短暫精神症狀 → **A 群思覺失調型**；照護可用**抗精神病藥**、定期會談了解壓力源，**不面質、不採權威**
- 妄想型的治療**首重建立治療性人際關係**(讓病人至少能信任一些人)
- 怕被拋棄、空虛、情緒不穩、過度消費與割腕 → **邊緣型**；對護理師理想化又貶損 → **全好全壞的二分法(分裂)**
- 「你們不來我就去撞牆」＝**操縱行為**；處理是**界限清楚的設限**，不是配合要求、忽視或限制行動
- 分化行為(說別班護理師壞話)：**傾聽動機、保持中立、就事論事**，並**告知團隊**，不是隱瞞
- 邊緣型的最適當措施是**避免被病人操縱**；自傷者**要評估並處理傷口**，不可當作態而忽略
- 反社會型：**無法遵守社會規範**、不負責任、**不知悔恨並合理化傷害**；「認為自己很重要、希望他人自動順從」是**自戀型**；反社會型住院咆哮威脅 → **設限並說明對行為的期待**
- 做作型：**用外表吸引注意**、**情緒快速轉變且膚淺**、**不適當的性挑逗**；衝動易怒攻擊**不是**做作型的特徵
- 自戀型的應對：**了解並包容，但避免過度讚美**；不接受對醫護人員的貶低，也不用開玩笑
- **畏避型**＝害怕批評或拒絕、避開需要人際接觸的工作；討好順從怕失去支持是**依賴型**
- **強迫型**＝**完美主義、重視細節、固執缺乏彈性**；不是宗教妄想、不愛冒險
- 治療重點是**改善困擾症狀、給予情緒支持、增進適應能力**，**不是改變個性本質**；問題行為是**自傷、操縱、衝動**，不是自我照顧缺失

## 總論 {#overview}

### 一般特徵(DSM-5 摘要) {#general-features}

1. 持久的內在經驗與行為模式，**明顯偏離**個人所屬文化的期待，表現在下列至少兩方面
   1. **認知**：看待自己、他人與事件的方式
   2. **情感**：情緒反應的範圍、強度、穩定性與恰當性
   3. **人際功能**
   4. **衝動控制**
2. **持久、缺乏彈性**，**遍及**各種個人與社會情境
3. 造成臨床上明顯的**痛苦**或**社會、職業等功能減損**
4. 模式**穩定且長期**，起始可追溯到**青春期或成年早期**
5. 不是其他精神疾病、物質或身體疾病造成
6. 兒童與青少年**少數情況**可診斷(特質普遍、持續，且不只是某個發展階段的表現；18 歲以下需持續**至少 1 年**)；**反社會型必須年滿 18 歲**，且 **15 歲前**有行為規範障礙症的證據

### 特性 {#characteristics}

1. **自我協調**(ego-syntonic)：病人覺得自己的想法與行為是合理的，問題是別人造成的 → **病識感差**、很少主動求醫
2. 與強迫症、焦慮症等**自我不協調**(病人覺得痛苦、想改變)不同
3. 常合併**憂鬱、焦慮、物質使用、飲食障礙、自傷與自殺**
4. 兩種以上的人格障礙症可以同時存在

## 病因 {#etiology}

1. **生物**
   1. **遺傳**：家族聚集，思覺失調型與思覺失調症有遺傳關聯
   2. **血清素功能偏低**(腦脊髓液 5-HIAA 低)與**衝動、攻擊、自殺**有關；杏仁核過度反應與情緒不穩有關
2. **精神動力**
   1. **自我(ego)功能薄弱**、超我發展不良 → 自我控制差
   2. 心性發展固著：例如**肛門期**過度嚴格管教 → 日後**一板一眼、缺乏彈性**(強迫型)
   3. 客體關係：邊緣型與分離個體化過程(Mahler 的和解期)受挫有關，無法把好與壞整合在同一個人身上 → **分裂**(見 [[psychodynamic-theories#object-relations-attachment]])
3. **心理社會**
   1. **童年創傷**、受虐、被忽視、失落(邊緣型、反社會型尤其常見)
   2. 不一致或冷漠的教養、家庭衝突
   3. 兒童期的**行為規範障礙症**部分會發展成反社會型(見 [[child-adolescent-mental-health#conduct-disorder]])

## 三群十種類型 {#types}

### A 群：古怪、奇特 {#cluster-a}

| 類型 | 核心特徵 | 照護要點 |
|---|---|---|
| **妄想型** | 普遍**多疑、不信任**，認為別人要害他或利用他；把無心的話解讀成侮辱；**記恨**；對配偶忠誠無故懷疑 | 首重**建立信任的治療性關係**；說話直接、誠實、一致；不爭辯、不開玩笑；事先說明各項處置 |
| **孤僻型** | 與人疏離、**偏好獨處**、情感冷淡、對讚美或批評都**不在意**、缺乏親密關係 | 尊重需要的距離，漸進增加互動；不強迫參加團體 |
| **思覺失調型** | **古怪的信念或魔術式思考**(心電感應、第六感)、關係意念、**不尋常的知覺**(身體飄起的錯覺)、古怪言談(含糊、繞圈子)、多疑、行為與外表古怪；**社交焦慮不會因熟悉而減少**；壓力下可出現**短暫精神病症狀** | 低劑量**抗精神病藥**處理精神病症狀與焦慮；定期會談了解壓力源；**不面質怪異言論**；不採權威或嚴格控制 |

- 和思覺失調症的差別：思覺失調型沒有持續的妄想與幻覺，現實感大致保留

### B 群：戲劇化、情緒化、反覆無常 {#cluster-b}

| 類型 | 核心特徵 |
|---|---|
| **反社會型** | 15 歲以後持續**漠視並侵犯他人權益**：**不守法**、欺騙說謊、**衝動**、易怒攻擊、不顧自己與他人安全、**不負責任**(無法維持工作、不還債)、**缺乏悔意**、**合理化**傷害他人的行為；年滿 18 歲才診斷 |
| **邊緣型** | **瘋狂地避免被拋棄**；人際關係**不穩定且強烈**，在**理想化與貶低**之間擺盪；**自我認同**不穩；**衝動**(花錢、性、物質、暴食、危險駕駛)；**反覆自殺、自傷**(割腕)；**情緒極不穩定**；**慢性空虛感**；強烈的憤怒；壓力下短暫的被害意念或解離 |
| **做作型** | 不是焦點就不舒服；**用外表吸引注意**；**不適當的性誘惑或挑逗**；**情緒快速轉變且膚淺**；說話誇張戲劇化但缺乏細節；容易受暗示；把關係想得比實際親密 |
| **自戀型** | **自大**、誇大自己的重要性與成就；幻想無限成功與權力；認為自己**特別**；**需要過度讚美**；**特權感**；剝削他人；**缺乏同理心**；嫉妒；傲慢；自尊其實很脆弱，受批評時暴怒或羞愧 |

#### 邊緣型的防衛機轉與行為 {#borderline}

1. **分裂(splitting)**：用**全好或全壞**看人，同一個人今天是「最好的護理師」，明天變成「最壞的」；也會把團隊分成好人與壞人，引起工作人員之間的衝突
2. **投射性認同**：把自己無法接受的情緒投射給別人，並引發對方真的出現那種情緒
3. **操縱行為**：用威脅(「不來我就撞牆」)、自傷、討好或挑撥來控制他人、達到目的
4. 自傷多是為了**緩解強烈的情緒痛苦**或因應被拋棄的恐懼，也可能致命，**每一次都要評估**
5. 治療：**辯證行為治療(DBT)** 是實證最多的心理治療，教導**情緒調節、痛苦耐受、人際效能與正念**；藥物只處理目標症狀(NICE CG78)

### C 群：焦慮、害怕 {#cluster-c}

| 類型 | 核心特徵 | 照護要點 |
|---|---|---|
| **畏避型** | **害怕被批評、否定或拒絕**，**避開需要人際接觸的工作**；除非確定被喜歡否則不交往；覺得自己能力不足、不討人喜歡；其實**渴望關係** | 接納、肯定；循序漸進增加社交；**自我肯定訓練** |
| **依賴型** | **過度需要被照顧**；日常決定需要別人大量建議與保證；怕失去支持而**不敢表達不同意**、**討好順從**；一段關係結束就急著找下一個依靠 | 鼓勵**自己做決定**、承擔責任；給予有限的選擇；避免護理師成為新的依賴對象 |
| **強迫型** | 專注於**秩序、規則、細節**；**完美主義**反而做不完；過度投入工作；**固執、缺乏彈性**；不願授權；吝嗇；保留沒用的東西 | 給予足夠時間；不批評其儀式化的做事方式；逐步練習彈性與放鬆 |

- **強迫型人格障礙症**和**強迫症**不同：前者是**自我協調**的性格特質，沒有真正的強迫思考與強迫行為(見 [[obsessive-compulsive-disorder#related-disorders]])

## 治療 {#treatment}

1. **心理治療為主**
   1. 邊緣型：**辯證行為治療**；也可用心智化治療、基模治療
   2. 認知行為治療、團體治療、家庭治療
   3. 治療關係需要長期、一致、界線清楚
2. **藥物**：沒有藥物能治好人格障礙症，只針對**目標症狀**
   1. 情緒不穩與衝動：SSRI、情緒穩定劑(見 [[antidepressants]]、[[mood-stabilizers]])
   2. 短暫精神病症狀、思覺失調型：低劑量抗精神病藥(見 [[antipsychotics#indications]])
   3. 邊緣型常有過量服藥的風險，處方量要謹慎，避免 BZD
3. **治療重點**：**改善導致困擾的症狀**、**給予情緒支持**、**增進適應生活與環境的能力**；**不是改變個性本質**

## 護理 {#nursing}

### 照護原則 {#nursing-principles}

1. **自我覺察**：病人的操縱、貶低或挑撥容易引起護理師的憤怒、挫折或想拯救的情緒，要覺察並在團隊中討論
2. **團隊一致**
   1. 全體工作人員遵守**同樣的規則與後果**
   2. 定期開會溝通，避免被分化
3. **清楚設限**
   1. 事先說明**可接受與不可接受的行為**及違反的**後果**
   2. 以**平靜、就事論事**的態度執行，不帶懲罰或情緒
   3. 設限的目的是提供**界限清楚、安全的環境**
4. **處理行為而不是人格**：針對具體的問題行為(**自傷、操縱、衝動**)擬定措施
5. 增強適當行為，協助病人學習以語言表達情緒與需要
6. 治療性關係要**溫和、中立、一致**，避免過度親近或過度疏離

### 操縱與分裂 {#manipulation}

1. 辨識操縱：威脅、討好、挑撥、要求特殊待遇、試探規則
2. **不配合不合理的要求**，也**不要忽視**(可能真的自傷)；用**一致的設限**回應
3. 面對**分化行為**(「你比小夜班好多了，他還說你壞話」)
   1. 傾聽病人的想法與動機
   2. **保持中立**，不附和也不辯解
   3. **就事論事**地討論
   4. **告知團隊**，不隱瞞
4. 鼓勵病人直接向當事人表達不滿

### 自傷 {#self-harm}

1. 每次都**評估自殺與自傷風險**、**處理傷口**；不要當作「作態」而忽略
2. 以**平靜、就事論事**的方式照顧傷口，不給予過多情緒性關注(避免增強)，也不責備
3. 移除危險物品，必要時密切觀察
4. **不自傷約定**：國考有「依行為治療與病人訂定不自傷約定」的正確答案，也有「與病人訂契約保證不自殺」不是最適當措施的題目；現行建議以**安全計畫**取代單純的口頭保證(見 [[depressive-disorder#safety-plan]])
5. 協助辨識引發自傷的情緒與情境，學習替代的因應方式(DBT 技巧)

### 各群的照護重點 {#nursing-by-cluster}

| 群 | 重點 |
|---|---|
| **A 群** | **建立信任**為首要；誠實、一致、尊重距離；不面質、不爭辯；必要時藥物 |
| **B 群** | **設限**、團隊一致、避免被操縱；評估自傷與暴力；反社會型說明對行為的期待與後果；自戀型包容但不過度讚美、不接受貶低；做作型注意適當行為而不增強戲劇化表現 |
| **C 群** | 接納與支持；**自我肯定訓練**、練習做決定；漸進暴露於社交情境；強迫型練習彈性 |

### 家屬 {#family}

1. 說明人格障礙症的特性，減少家屬的自責與衝突
2. 協助家屬設定一致的界線，不因威脅而讓步，也不放棄關心
3. 家庭治療處理界線不清與雙重束縛的溝通(見 [[group-family-therapy#family-therapy]])
