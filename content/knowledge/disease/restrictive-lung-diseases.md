**限制性肺病**的共同點是肺**撐不開**：肺容積變小，吸不飽，但吐氣速度相對正常。原因可以在肺組織本身(纖維化、塵肺)、肋膜、胸壁或呼吸肌。本頁整理肺實質的限制性疾病與**肺擴張不全**；肺功能的比較見 [[ventilation-mechanics#spirometry]]，阻塞性疾病見 [[copd]]

## 重點摘要 {#summary}

- 限制性：**FVC(Forced vital capacity) 與肺總量下降**、**FEV1/FVC 正常或上升**、順應性下降；阻塞性則是 FEV1/FVC 下降
- 原因：肺纖維化、塵肺症、類肉瘤病；肋膜積水、胸壁變形、肥胖；**神經肌肉疾病**
- **塵肺症**：吸入礦物粉塵 → 巨噬細胞吞噬 → 慢性發炎與**纖維化**；矽肺症容易合併**結核**
- **石綿**：肺纖維化(下葉為主)、肋膜斑、**肋膜惡性間皮瘤**、**肺癌**(和吸菸相乘)、**喉癌**
- **肺擴張不全**：肺泡塌陷；**呼吸音減弱**、**叩診濁音**、觸覺語顫減弱，大範圍時氣管偏向**患側**
- 預防術後肺擴張不全：**深呼吸**、**誘發性肺量計**、咳嗽、翻身、**早期下床**、止痛；呼吸器設定**定時深呼吸(嘆息)**也是為了預防它

### 國考常考點 {#exam-points}

- 肺活量 2 L、FEV1/FVC 85% → **限制型肺病**
- **不屬於**石綿相關疾病的是**肺膿瘍**；石綿相關：廣泛間質纖維化、**肋膜間皮瘤**、**喉癌**、肺癌
- 疑似肺擴張不全：**呼吸音減弱**(不是慢而深的呼吸、不是正常體溫)
- 肺擴張不全的身體評估：**叩診濁音**；觸覺語顫**變小**、呼吸音**變小**、氣管**往患側**偏(說往健側是錯的)
- 呼吸器每分鐘設定數次深呼吸，首要預防**肺擴張不全**
- 粉塵作業勞工的特殊健康檢查包含**肺功能檢查**(國考答案)

## 限制性肺病的原因 {#causes}

| 位置 | 例子 |
|---|---|
| 肺間質 | **特發性肺纖維化**、**塵肺症**、類肉瘤病、過敏性肺炎、結締組織病(類風濕、硬皮症)、藥物(amiodarone、bleomycin、methotrexate)、放射線 |
| 肺泡 | 肺擴張不全、ARDS、新生兒表面張力素不足 |
| 肋膜 | 大量肋膜積水、肋膜增厚 |
| 胸壁 | 脊柱側彎、**肥胖**、連枷胸、腹脹 |
| 呼吸肌與神經 | **重症肌無力**、**格林巴利症候群**、肌失養症、頸髓損傷 |

- 共同表現：活動時呼吸困難、**淺快呼吸**(較省力)、乾咳；肺纖維化常有吸氣末**爆裂音**、杵狀指
- 肺間質病變讓呼吸膜變厚 → **擴散能力下降**、低血氧，見 [[gas-exchange-transport#diffusion]]
- 長期缺氧 → 肺高壓、肺心症

## 間質性肺病與肺纖維化 {#interstitial}

1. **特發性肺纖維化**：原因不明，多見於年長、吸菸男性；進行性、預後差
2. 表現：慢慢加重的**活動性呼吸困難**、**乾咳**、雙側肺底吸氣末細爆裂音、杵狀指
3. 檢查：高解析度電腦斷層、肺功能(限制性、擴散量下降)
4. 治療：抗纖維化藥物可減緩肺功能下降；氧氣治療、肺部復健、戒菸、疫苗；末期考慮肺移植
5. **類肉瘤病**：非乾酪性**肉芽腫**侵犯肺門淋巴結與肺，病因不明
6. 護理：節省體力、呼吸訓練、給氧、預防感染；類固醇治療時注意副作用，見 [[corticosteroids]]

## 塵肺症 {#pneumoconiosis}

機轉、種類與空氣汙染見 [[environmental-injury#air-pollution]]，重點整理如下

| 種類 | 粉塵與職業 | 特點 |
|---|---|---|
| **矽肺症** | 二氧化矽：採石、隧道、噴砂、玻璃、陶瓷 | 上葉結節性纖維化；**容易合併結核** |
| 煤礦工人塵肺症 | 煤塵 | 黑色結節 |
| **石綿肺** | 石綿：舊建材、隔熱材、造船、剎車片 | 下葉間質纖維化、**肋膜斑** |

- 不是過敏反應，而是巨噬細胞吞噬粉塵後持續發炎、纖維化；脫離暴露後仍可能惡化
- 沒有有效治療，**預防最重要**：減少粉塵(濕式作業、通風)、防護口罩、**職業健康檢查**
- 依勞工健康保護規則，粉塵作業屬特別危害健康作業，國考答案寫其特殊健康檢查要包含**肺功能檢查**(法規附表的完整項目待核對，職業衛生在第 7 輪社區 A 整理)

### 石綿相關疾病 {#asbestos}

| 疾病 | 說明 |
|---|---|
| **石綿肺** | 廣泛間質纖維化，下葉為主 |
| 肋膜斑、肋膜增厚 | 最常見的石綿暴露標記 |
| **惡性間皮瘤** | 肋膜(或腹膜)的惡性腫瘤，暴露後潛伏期很長 |
| **肺癌** | 和**吸菸有相乘作用** |
| **喉癌**、卵巢癌 | 國際癌症研究署列為石綿造成的癌症 |

來源：[IARC Monographs Volume 100C, Asbestos(2012)](https://publications.iarc.who.int/120)

- 肺膿瘍是細菌感染造成的化膿，**不是**石綿相關疾病，見 [[pneumonia]]

## 肺擴張不全 {#atelectasis}

1. 定義：一部分肺泡**塌陷**、沒有空氣；屬於**分流**(有血流沒通氣)，見 [[gas-exchange-transport#vq]]
2. 原因

| 類型 | 機轉 | 例子 |
|---|---|---|
| **吸收性**(阻塞性) | 呼吸道被堵住，遠端肺泡的氣體被吸收後塌陷 | **痰栓**、異物、腫瘤 |
| **壓迫性** | 肺被外面的東西壓扁 | 肋膜積水、氣胸、腹脹 |
| **術後**、淺呼吸 | 麻醉、疼痛不敢深呼吸、臥床 | 胸腹部手術後最常見 |
| 表面張力素不足 | 肺泡表面張力大 | ARDS、早產兒 |

3. 表現
   1. 小範圍可能沒症狀；大範圍時呼吸困難、呼吸淺快、心跳快、SpO₂(Peripheral oxygen saturation) 下降
   2. 術後早期常見**低燒**
   3. 患側：**呼吸音減弱**、**叩診濁音**、**觸覺語顫減弱**、胸廓起伏變小
   4. 大範圍塌陷：氣管與縱膈**偏向患側**(被拉過去)；積水或張力性氣胸則是推向健側
4. 胸部 X 光：患部變白、肺容積變小
5. 預防與護理
   1. **深呼吸**、**誘發性肺量計**(撐開肺泡、刺激表面張力素分泌)，見 [[ventilation-mechanics#compliance]]
   2. 有效咳嗽、按住傷口再咳、抽痰清除痰栓
   3. **每 2 小時翻身**、**早期下床**
   4. 適當止痛，讓病人敢深呼吸
   5. 呼吸器病人：設定**定時深呼吸(嘆息)**或用 PEEP(Positive end-expiratory pressure)，預防肺泡塌陷
6. 呼吸道清潔技術見 [[airway-clearance]]
