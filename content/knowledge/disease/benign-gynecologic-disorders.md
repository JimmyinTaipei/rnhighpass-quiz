本頁整理婦科常見的良性疾病與婦科手術護理：子宮肌瘤、子宮內膜異位症與子宮腺肌症、子宮脫垂與移位、子宮頸與陰道問題、卵巢良性腫瘤、乳房良性腫瘤，以及婦科檢查、子宮切除與腹腔鏡手術的護理。婦科癌症見 [[gynecologic-cancers]]，陰道炎與骨盆腔炎見 [[sexually-transmitted-infections]]，痛經與月經問題見 [[menstrual-disorders]]，壓力性尿失禁見 [[urologic-disorders#incontinence]]，子宮構造與韌帶見 [[female-reproductive-system#uterus]]。文中縮寫：GnRH（Gonadotropin-releasing hormone，促性腺激素釋放激素）、CO₂（二氧化碳）

## 重點摘要 {#summary}

- **子宮肌瘤**：最常見的婦科良性腫瘤；平滑肌瘤，**依賴雌激素**（停經後縮小、懷孕時變大）；**肌層內**最常見；最常見症狀是**不正常子宮出血**（經血過多）；惡性變化很少(< 1%)
- **子宮內膜異位症**：子宮內膜組織長在**子宮腔以外**；在卵巢形成**巧克力囊腫**
- **子宮腺肌症**：子宮內膜組織長進**子宮肌層**
- 兩者都會造成**續發性痛經**、**性交痛**、**不孕**
- **子宮脫垂**：分娩損傷、老化雌激素下降使**主韌帶、子宮薦骨韌帶**與骨盆底無力；**骨盆底肌肉運動**，**子宮托放在陰道後穹窿**，嚴重時手術
- 子宮頸**糜爛（外翻）**常用**冷凍治療**
- 正常白帶在排卵期、**月經前與懷孕時增加**
- 陰道瘻管最常見原因是**手術傷害**（已開發國家）
- **腹部超音波要脹膀胱**；陰道超音波要排空膀胱
- 腹腔鏡：術中**頭低腳高**；術後**肩痛**來自 CO₂ 刺激橫膈，可按摩、膝胸臥式
- 子宮切除術後 **6 週**內避免性生活、盆浴、提重物、**騎腳踏車**
- **乳房纖維腺瘤**：**最常見的乳房良性腫瘤**，年輕女性（< 30 歲）、界限清楚、可移動、多半不痛

### 國考常考點 {#exam-points}

- 子宮肌瘤以**肌層內**最多，不是漿膜下；很少惡化；與**雌激素**有關，不是黃體素過多；常有**不正常子宮出血**
- 腹腔鏡手術中是**頭低腳高**（膀胱截石＋垂頭仰臥），不是頭高腳低；術前要**清潔肚臍**；術後禁食 6–8 小時後可進食
- 子宮肌瘤術後：觀察並記錄**出血的量、性質、顏色**；微創手術後早期下床，不用臥床 24 小時；不能立即恢復性生活或做重訓
- 子宮切除術前腸道準備：**術前一天**低渣流質、午夜後禁食、瀉劑或灌腸、預防性抗生素；**不需要前三天就開始低渣**（國考答案）
- 子宮切除術後出院：**6 週內避免性生活**；不要盆浴坐浴；避免騎腳踏車與久坐（骨盆腔充血）；陰道持續有中量鮮血分泌物要回診
- 與子宮內膜異位有關：**卵巢巧克力囊腫**、**子宮腺肌症**；絨毛膜癌與骨盆腔炎無關
- 子宮脫垂：教**骨盆底肌肉運動**；原因主要是**分娩損傷與老化**，不是先天；可用子宮托或手術，不是只能手術；第一度是子宮頸下降但還在陰道內
- 子宮托放在**陰道後穹窿**
- 正常陰道分泌物在**經期前與孕期增加**，不是減少
- 陰道瘻管最常見原因是**手術傷害**；甲基藍試驗是把染劑灌進膀胱、看陰道內棉塞是否變藍，不是用試紙
- 性交疼痛的處理要**夫妻一起**討論，不是只治療女方
- 卵巢甲狀腺腫屬於**畸胎瘤**
- 乳房纖維腺瘤：**最常見的乳房良性腫瘤**；好發 30 歲以下（不是 70 歲以上）；界限清楚；懷孕時可能變大；與 **MED12** 基因突變有關

## 婦科檢查與手術護理 {#procedures}

### 檢查 {#exams}

| 檢查 | 護理重點 |
|---|---|
| 內診（骨盆腔檢查） | 排空膀胱；膀胱截石臥位；說明過程、維護隱私、女性陪檢；檢查前 24–48 小時避免陰道灌洗、塞劑與性交（抹片） |
| **腹部超音波** | **喝水脹膀胱**（把腸子推開、當作聲窗）；不需簽同意書或鎮靜 |
| 陰道超音波 | **排空膀胱** |
| 陰道鏡 | 放大看**子宮頸**轉化區，切片（見 [[gynecologic-cancers#cervical-screening]]） |
| 子宮輸卵管攝影 | 月經乾淨後到排卵前（見 [[infertility#diagnosis]]） |
| 子宮內膜搔刮(D&C) | 術後少量出血正常；2 週內避免盆浴、性交、棉條 |

::questions{ids="107-1_OP_039"}

### 子宮切除術 {#hysterectomy}

- 種類：全子宮切除（子宮體＋子宮頸）、次全切除（保留子宮頸）、根除性（加周圍組織與淋巴結，婦癌用）；可經腹部、陰道或腹腔鏡；是否切除卵巢要分開說明
- 術前
   1. 腸道準備：**術前一天**低渣流質，**午夜後禁食**；依醫囑瀉劑或灌腸、預防性抗生素
   2. 備血、放導尿管、會陰與腹部皮膚準備
   3. 心理準備：失去子宮的感受、身體心像、對性生活的擔心
- 術後
   1. 觀察陰道出血（量、性質、顏色）與傷口
   2. 早期下床預防血栓與腸脹氣
   3. 導尿管移除後注意自解小便與尿瀦留
- 出院衛教
   1. **6 週內避免性生活**、陰道灌洗與棉條
   2. **淋浴**，避免盆浴與坐浴
   3. 6 週內避免提重物、劇烈運動、**騎腳踏車或騎馬**、久坐（骨盆腔充血）
   4. 少量淡紅或褐色分泌物可持續數週；**持續中量以上鮮血**、發燒、惡臭分泌物、排尿疼痛要回診
   5. 子宮切除後**沒有月經、無法懷孕**；若同時切除卵巢會出現更年期症狀
   6. 性生活恢復後可能需要潤滑劑；鼓勵夫妻溝通

::questions{ids="107-1_OP_038,106-1_OP_016"}

### 腹腔鏡手術 {#laparoscopy}

- 術前：**清潔肚臍**（切口位置）、排空膀胱、禁食
- 術中：灌入 **CO₂** 撐開腹腔；採**頭低腳高**（垂頭仰臥）讓腸子往上移，看清骨盆腔
- 術後
   1. **肩膀與背部疼痛**：殘留的 CO₂ 刺激橫膈，經膈神經轉移到肩膀；可**按摩**、走動、膝胸臥式或抬高臀部幫助氣體吸收，通常 1–3 天消失
   2. 禁食約 6–8 小時，清醒、有腸音後即可進食
   3. 恢復快，可早期下床；性生活與劇烈運動仍依醫囑延後

## 子宮肌瘤 {#fibroids}

- **最常見**的婦科良性腫瘤；子宮**平滑肌**的良性腫瘤；生育年齡女性常見
- **依賴雌激素**：懷孕時可能變大、**停經後縮小**
- 依位置

| 種類 | 位置 | 特點 |
|---|---|---|
| **肌層內** | 子宮肌層內 | **最常見**；子宮變大、經血量增加 |
| **黏膜下** | 突入子宮腔 | 最少但**出血最明顯**、不孕、流產；可能有蒂脫出子宮頸 |
| 漿膜下 | 往子宮外突出 | 少出血；壓迫膀胱或直腸；有蒂可能扭轉 |

- 表現：多半**沒有症狀**；**不正常子宮出血**（經血過多、經期延長，最常見） → **缺鐵性貧血**；下腹腫塊、壓迫症狀（頻尿、便秘）、經痛、不孕
- **惡性變化很少**(< 1%)；停經後肌瘤快速變大要懷疑肉瘤
- 治療
   1. 無症狀：定期追蹤（超音波）
   2. 藥物：NSAIDs、止血藥、口服避孕藥或含黃體素 IUD 減少出血；**GnRH 類似物**讓肌瘤暫時縮小（術前用，長期會骨質流失）
   3. 手術：**肌瘤切除術**（想保留生育）、**子宮切除術**（不想再生育）；子宮動脈栓塞、高能聚焦超音波
- 護理：評估出血量與貧血、補鐵、手術護理（見上方）

## 子宮內膜異位症與子宮腺肌症 {#endometriosis}

| | **子宮內膜異位症** | **子宮腺肌症** |
|---|---|---|
| 定義 | 子宮內膜組織長在**子宮腔以外**（卵巢最常見、子宮薦骨韌帶、骨盆腔腹膜、直腸子宮凹陷） | 子宮內膜組織長進**子宮肌層** |
| 特徵 | 卵巢內形成充滿陳舊血液的**巧克力囊腫**（子宮內膜瘤） | 子宮**均勻變大**、變軟 |
| 好發 | 生育年齡、未生育 | 40 歲以上、經產婦 |
| 機轉 | **經血逆流**學說最常被接受；依賴雌激素 | 內膜往肌層內生長 |
| 表現 | **續發性痛經**（逐漸加劇）、**性交痛**、排便痛、**不孕**、骨盆腔沾黏 | **續發性痛經**、**經血過多** |

- 治療：止痛(NSAIDs)、荷爾蒙抑制雌激素與月經（口服避孕藥、黃體素類如 dienogest、GnRH 類似物、danazol）；腹腔鏡切除病灶或囊腫；不想生育且症狀嚴重 → 子宮（與卵巢）切除
- 用藥細節見 [[sex-hormones]]；不孕的處理見 [[infertility]]
- 懷孕與停經後症狀通常減輕

::questions{ids="106-2_makeup_OP_035,113-3_BM_029,105-2_BM_045,105-1_BM_045"}

## 子宮脫垂與子宮移位 {#prolapse}

- **子宮脫垂**：子宮沿陰道往下掉
- 原因：**分娩損傷**（多產、急產、巨嬰、器械助產）、**停經後雌激素下降**、慢性腹壓增加（慢性咳嗽、便秘、肥胖、提重物）；支撐的**主韌帶、子宮薦骨韌帶**與骨盆底肌肉無力
- 分度（課本）

| 分度 | 程度 |
|---|---|
| 第一度 | 子宮頸下降到陰道內，但還沒到陰道口 |
| 第二度 | 子宮頸到達或露出陰道口 |
| 第三度 | 整個子宮脫出陰道口外 |

- 表現：下腹或會陰**沉重感、下墜感**、腰痠，久站或提重物後加重、平躺減輕；陰道口有東西掉出；合併**膀胱膨出**（頻尿、壓力性尿失禁、排尿不完全）或**直腸膨出**（排便困難）
- 處置
   1. 輕度：**骨盆底肌肉運動（凱格爾運動）**、減重、治療慢性咳嗽與便秘、避免提重物（見 [[urinary-elimination#kegel]]）
   2. **子宮托**：放在**陰道後穹窿**撐住子宮；定期取出清洗、回診檢查陰道有無潰瘍；停經後可合併局部雌激素
   3. 手術：陰式子宮切除術、骨盆底重建
- **子宮移位**：正常是前傾前屈；**後傾後屈**多半無症狀，少數有腰痛、經痛、不孕；可做膝胸臥式

## 子宮頸與陰道問題 {#cervix-vagina}

### 子宮頸糜爛（外翻）與子宮頸炎 {#cervical-ectropion}

- 「糜爛」其實多是**子宮頸外翻**：柱狀上皮外露到子宮頸外口，看起來紅、顆粒狀；常見於年輕、口服避孕藥、懷孕（雌激素高）
- 先做**子宮頸抹片**排除癌前病變
- 無症狀不需治療；分泌物多或反覆出血 → **冷凍治療**（最常用）、電燒或雷射；術後 2–4 週會有水樣分泌物，避免性交與棉條
- 子宮頸炎多由披衣菌、淋病引起（見 [[sexually-transmitted-infections]]）

::questions{ids="107-2_OP_040"}

### 陰道分泌物 {#discharge}

- 正常白帶：透明或乳白、無味或微酸、不癢；功能是**濕潤陰道**，也是**陰道生態平衡的指標**
- **量增加**：排卵期、**月經前**、**懷孕**、性興奮、口服避孕藥（雌激素）
- 異常：顏色（黃綠、灰白、帶血）、異味、搔癢、灼熱 → 陰道炎（見 [[sexually-transmitted-infections]]）

::questions{ids="106-2_OP_040"}

### 陰道瘻管 {#fistula}

- 陰道與膀胱（**膀胱陰道瘻管**，漏尿）或直腸（**直腸陰道瘻管**，陰道排氣、排便、**糞臭味**）之間的異常通道
- 原因：已開發國家最常見是**手術傷害**（子宮切除術），其次是放射治療、癌症；開發中國家多是**難產**長時間壓迫
- 檢查：**甲基藍試驗**：陰道內放棉塞，把甲基藍灌進膀胱，棉塞變藍 → 膀胱陰道瘻管
- 治療：小瘻管先放導尿管等待自行癒合；多數要**手術修補**
- 護理：會陰清潔與皮膚保護、除臭、心理支持

::questions{ids="109-2_OP_036"}

### 性交疼痛 {#dyspareunia}

- 原因：陰道乾澀（停經、哺乳）、陰道炎、會陰傷口、子宮內膜異位、骨盆腔炎、陰道痙攣、心理因素
- 處理
   1. **夫妻一起**討論，找出彼此忽略的問題（不是只治療女方）
   2. 找原因期間可暫時避免性交，改用其他親密方式
   3. 使用**無刺激性的水性潤滑劑**
   4. 治療原本疾病；必要時轉介性諮商

## 卵巢良性腫瘤 {#ovarian-benign}

| 種類 | 重點 |
|---|---|
| 功能性囊腫（濾泡囊腫、黃體囊腫） | 最常見；多在 1–3 個月經週期內自行消失 |
| 子宮內膜瘤（巧克力囊腫） | 子宮內膜異位在卵巢（見上方） |
| **成熟畸胎瘤**（皮樣囊腫） | **最常見的卵巢生殖細胞腫瘤**，多為良性；含三胚層組織（毛髮、皮脂、牙齒）；**卵巢甲狀腺腫**是以甲狀腺組織為主的畸胎瘤 |
| 漿液性、黏液性囊腺瘤 | 上皮性良性腫瘤 |

- 併發症：**卵巢扭轉**（突然劇烈下腹痛、噁心嘔吐，急診手術）、破裂
- 卵巢癌見 [[gynecologic-cancers#ovarian]]；兒童睪丸與卵巢的生殖細胞腫瘤與腫瘤標記見 [[male-reproductive-disorders#testicular-tumors]]

## 乳房良性疾病 {#breast}

| 疾病 | 重點 |
|---|---|
| **纖維腺瘤** | **最常見的乳房良性腫瘤**；**30 歲以下**年輕女性；圓、硬、**界限清楚**、**可移動**、多半**不痛**；依賴荷爾蒙，**懷孕時可能變大**；與 **MED12** 基因突變有關；小且穩定可追蹤，大或變大時切除 |
| 纖維囊腫變化 | 最常見的乳房病變；月經前脹痛、多處結節，月經後減輕；減少咖啡因、穿合適內衣 |
| 乳腺炎、乳房膿瘍 | 多在哺乳期（見 [[perinatal-infections#mastitis]]） |
| 葉狀瘤 | 少見、長得快，可能復發 |

- 乳房自我檢查與乳癌見 [[breast-cancer]]
