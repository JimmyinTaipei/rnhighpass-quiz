**淋巴瘤**是淋巴球在淋巴結或淋巴組織形成的惡性腫瘤，分成**何杰金氏淋巴瘤**與**非何杰金氏淋巴瘤**；**多發性骨髓瘤**則是會製造抗體的**漿細胞**在骨髓中惡性增生。三者都屬於 B 細胞系統的惡性腫瘤(多數)，治療以化療、標靶(rituximab)與幹細胞移植為主。癌症總論見 [[cancer]]，病理基因見 [[neoplasia#key-genes]]。

## 何杰金氏與非何杰金氏淋巴瘤 {#hodgkin-vs-nhl}

| | **何杰金氏淋巴瘤** | **非何杰金氏淋巴瘤**(NHL) |
|---|---|---|
| 比例 | 少(約 1 成) | **多**；**最常見的是瀰漫性大 B 細胞淋巴瘤** |
| 好發 | **雙峰**：**15–35 歲年輕人**與 55 歲以上；男略多於女 | 年齡越大越多 |
| 特徵細胞 | **Reed-Sternberg 細胞**(大、雙核、「貓頭鷹眼」)，**診斷必須看到** | 多數為 **B 細胞**，少數 T 細胞 |
| 擴散 | 從**單一淋巴結區**開始(常在**頸部**)，**依序往相鄰淋巴結**擴散 | **不連續**、常同時侵犯**多個周邊淋巴結**、**瀰漫性**分布 |
| 結外侵犯 | 較少 | **常見**：**骨髓**、腸胃道、皮膚、中樞神經 |
| B 症狀 | **較常見** | 較少(相對於何杰金氏) |
| 相關因子 | **EB 病毒** | EBV(勃氏)、幽門桿菌(胃 MALT)、HIV、免疫抑制、自體免疫病 |
| 預後 | **好**(多數可治癒)，與**分期**有關 | 依亞型差異大 |

### 症狀 {#lymphoma-symptoms}

- **無痛性淋巴結腫大**(頸部、鎖骨上、腋下、鼠蹊)：質地像橡皮、可移動、**無壓痛**。
- **B 症狀**：**不明原因發燒**(> 38°C)、**夜間盜汗**、**6 個月內體重減輕 > 10%**；出現 B 症狀表示預後較差(分期加註 B)。
- 何杰金氏：**皮膚搔癢**、喝酒後淋巴結疼痛(少見但特殊)；縱膈腔腫塊 → **咳嗽、呼吸困難、胸悶**、上腔靜脈症候群。
- 可侵犯**肝、脾**；腸胃道症狀(嘔吐、排便改變)不是何杰金氏的典型表現。

### 常考的特殊類型 {#nhl-subtypes}

| 類型 | 特點 |
|---|---|
| **瀰漫性大 B 細胞淋巴瘤** | **最常見**的淋巴瘤；侵襲性，但用 R-CHOP 化療可治癒 |
| **濾泡性淋巴瘤** | 惰性、B 細胞；**t(14;18)**，BCL2 過度表現 |
| **勃氏淋巴瘤** | 生長極快(兒童常見的腹部腫塊)；**MYC t(8;14)**；與 **EBV** 相關；化療時高風險**腫瘤溶解症候群** |
| **胃 MALT 淋巴瘤** | **B 細胞**淋巴瘤；與**幽門螺旋桿菌**相關，**除菌**治療可能緩解 |
| 成人 T 細胞白血病／淋巴瘤 | **HTLV-1** |

### Ann Arbor 分期 {#staging}

| 期別 | 範圍 |
|---|---|
| I | **單一**淋巴結區域(或單一結外部位) |
| **II** | **橫膈膜同側** **2 個以上**淋巴結區域 |
| III | **橫膈膜兩側**的淋巴結區域 |
| IV | **瀰漫性侵犯**淋巴結以外的器官(骨髓、肝、肺) |

加註 **A**(無 B 症狀)或 **B**(有 B 症狀)；E 表示結外侵犯。

### 非何杰金氏淋巴瘤的國際預後指標(IPI) {#ipi}

五個不良因子：**年齡 > 60 歲**、**LDH 升高**、**身體功能狀態差**、**第 III–IV 期**、**2 個以上結外部位侵犯**。**性別不是**預後指標；貧血(血紅素低)也與預後較差有關。

### 治療與護理 {#lymphoma-treatment}

- 何杰金氏：ABVD 等化療 ± 放療；早期治癒率高。**Bleomycin** 注意**肺纖維化**、doxorubicin 注意心臟毒性。
- NHL：**R-CHOP**(rituximab、cyclophosphamide、doxorubicin、vincristine、prednisolone)。
  - **Rituximab** 可能使 **B 型肝炎再活化** → 化療前驗 **HBsAg**，帶原者預防性使用抗病毒藥(如 lamivudine、entecavir)。
  - 首次 rituximab 注意**輸注反應**。
- 復發或高風險：**自體造血幹細胞移植**、CAR-T。
- 護理：感染與出血預防、放療皮膚照護、營養、生育保存諮詢(年輕病人)、長期追蹤續發性癌症與心肺毒性。
- 淋巴瘤病人做**骨髓抽吸**是為了評估骨髓是否侵犯(部位與護理見 [[leukemia#bone-marrow-aspiration]])。

## 多發性骨髓瘤 {#myeloma}

- **骨髓中的漿細胞惡性分化並過度增生**，大量製造**單株免疫球蛋白**(M 蛋白)或**輕鏈**(尿中的 **Bence Jones 蛋白**)。
- 好發於 **60 歲以上**老人。

### 表現：CRAB {#crab}

| 字母 | 表現 | 機轉 |
|---|---|---|
| **C** | **高血鈣**(意識混亂、便秘、多尿、口渴) | 骨頭被破壞釋放鈣 |
| **R** | **腎功能不全** | 輕鏈堵塞腎小管、高血鈣、脫水 |
| **A** | **貧血**(疲倦) | 骨髓被漿細胞占據 |
| **B** | **骨痛**(**背痛**最常見)、**溶骨性病灶**(X 光「打洞」)、**病理性骨折**、脊髓壓迫 | 腫瘤活化蝕骨細胞 |

- 另有**反覆感染**(正常抗體減少)、高黏滯症候群、**類澱粉沉積症**(沉積物來自**免疫球蛋白輕鏈**)。
- **腹瀉不是**典型表現。

### 診斷 {#myeloma-diagnosis}

- **骨髓中克隆性漿細胞 ≥ 10%**(例：40%)加上 CRAB 等器官損傷 → 確診(來源：[IMWG 2014](https://doi.org/10.1016/S1470-2045(14)70442-5))。
- 血清與尿液蛋白電泳找 **M 蛋白**、Bence Jones 蛋白；β2-微球蛋白與白蛋白用來分期(見 [[tumor-markers]])。
- 全身骨骼影像看溶骨病灶。

### 治療與護理 {#myeloma-nursing}

- 治療：**bortezomib**(周邊神經病變)、**lenalidomide**、thalidomide(**致畸胎**、**血栓**)、dexamethasone、抗 CD38 單株抗體；適合者做**自體造血幹細胞移植**；**雙磷酸鹽**或 denosumab 保護骨骼；放療止痛。
- 護理：
  - **鼓勵每天喝水 2,000–3,000 mL 以上**：保護腎臟、幫助排出鈣與輕鏈。
  - **鼓勵適度活動與負重**(減少骨鈣流失)，**不是避免運動**；同時**預防跌倒**與骨折，翻身移位要支托，必要時**背架**。
  - 疼痛控制；監測腎功能、血鈣、意識；避免 NSAIDs 與顯影劑傷腎。
  - **感染預防**(避免接觸感冒者、疫苗)。
  - 新出現的背痛合併下肢無力、大小便異常 → 懷疑**脊髓壓迫**(見 [[cancer-treatment-toxicities#spinal-cord-compression]])。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **Reed-Sternberg 細胞 = 何杰金氏淋巴瘤**；好發**年輕人**與老人，不是「女性老年人」；**頸部無痛淋巴結**、搔癢、B 症狀；腸胃症狀不典型。
- **非何杰金氏**：多個周邊淋巴結、**瀰漫性**、**常侵犯骨髓**；**B 症狀較何杰金氏少**。最常見 **瀰漫性大 B 細胞淋巴瘤**；**濾泡性 t(14;18)**；**胃 MALT 是 B 細胞**。
- Ann Arbor **第 II 期 = 橫膈膜同側 2 個以上**淋巴結區。
- NHL 預後不佳：**身體功能差、結外侵犯、血紅素低**、年齡 > 60、LDH 高；**性別不是**指標。
- NHL 化療前驗 **HBsAg**、預防性 **lamivudine**。
- 骨髓瘤：**漿細胞惡性增生**；**骨痛、腎功能不全、貧血**，**不會腹瀉**；確診看**骨髓漿細胞比例**；類澱粉來自**免疫球蛋白輕鏈**；**鼓勵喝水、不要避免運動**、可穿背架。
:::
