**失智症**(DSM-5 稱**重度認知障礙症**)是腦部疾病造成的**後天、持續、進行性**認知退化，記憶、語言、判斷與執行能力逐步下降，最後連日常生活都需要他人協助。它和**譫妄**(急性、意識波動)與**老年憂鬱的假性失智**(治療後可改善)要分清楚。用藥細節見 [[anti-dementia-drugs]]，譫妄見 [[delirium]]，老年憂鬱見 [[depressive-disorder#late-life]]

## 重點摘要 {#summary}

- **定義**：一項或多項**認知範疇**比過去明顯退步，且**影響日常生活的獨立性**；只退步但仍能獨立生活 → **輕型認知障礙症**
- **類型**：**阿茲海默症**最多，其次**血管性**；另有路易氏體、額顳葉；少數是可治療的原因(甲狀腺低下、維生素 B12 缺乏、常壓性水腦)(見 [[parkinson-disease]])
- **記憶**：**近期記憶先退化**(新學的記不住)，**遠期記憶保留最久**；**虛談**填補記憶空白；定向感依**時間 → 地點 → 人物**喪失
- **精神行為症狀**：**被偷妄想**、易怒、激躁、**遊走走失**、**日落症候群**(黃昏後更混亂激動)、憂鬱、幻覺
- **照護**：**安全第一**；**固定作息、固定照顧者、熟悉的物品、不變動擺設**；**簡短具體、一次一件事**；**不爭辯妄想、轉移注意力**；協助**發揮殘存能力**

### 國考常考點 {#exam-points}

- DSM-5：認知障礙症是**一項或多項**認知範疇退步，**記憶障礙不是必要條件**；認知範疇包含**學習和記憶**、複雜注意力、執行功能、語言、知覺動作、社會認知；不包含睡眠、人格、認知偏誤
- 病程是**慢性、進行性、不可逆**；**不是急性**；能說出發病時間點的是**假性失智**，不是失智症
- 失智症記憶喪失依**立即 → 近期 → 遠期**的考法(新學的先忘)；**遠期記憶最先喪失是錯的**；**地點或人物先失去定向是錯的**，先失去**時間**
- 多發性認知缺損：**失語、失用、失認**；**失眠不是**
- **日落症候群**見於**失智症**(黃昏後混亂、激動惡化)，**不要把窗簾拉起來**，傍晚要**開燈、維持明亮**；老年憂鬱**不會**合併日落症候群
- 走失是阿茲海默症**中期**的重要表徵；情緒不穩、忘了付錢、忘了梳洗、懷疑兒子偷錢 → **混亂期(中期)**
- 照護：**不要**每天變化活動、**不要**變動環境擺設、**不要**每天安排不同照顧者；**家人照片和熟悉物品**可以放；**最首要目標是安全**
- 溝通：**重點重複、輔以手勢**；**注意音調與姿勢推測感受**；每次見面**簡短自我介紹**；**不要**澄清或糾正妄想、**不要**要求背名字、**不要**用成語
- 懷疑媳婦偷地契 → **轉移注意力**(帶去散步)；不是澄清、不是請媳婦解釋；病人打人且發燒咳痰 → **帶離現場並處理身體問題**(協助排痰)，不是立刻打針或約束
- MMSE 評估定向、注意力與計算、記憶、語言，**不評估情緒**；**不是**評估意識的工具；滿分 30 分，**受教育程度影響**
- 阿茲海默症病理：**類澱粉蛋白斑塊、神經纖維糾結**、海馬迴萎縮、**腦溝變寬、腦室擴大**；腦中**乙醯膽鹼減少**
- 長照 2.0 納入 **50 歲以上**失智者(不是 40 或 60 歲)；疑似個案要確診 → **失智共同照護中心**；失智據點**不**協助申請外籍看護；**團體家屋**專屬失智者

## 認知範疇與記憶 {#cognitive-domains}

### 認知範疇(DSM-5 摘要) {#domains}

| 範疇 | 例子 |
|---|---|
| **複雜注意力** | 持續、分配、選擇性注意，處理速度 |
| **執行功能** | 計畫、決策、工作記憶、彈性思考 |
| **學習和記憶** | 立即、近期記憶，新學習的能力 |
| **語言** | 找字困難、命名、理解、流暢度 |
| **知覺動作** | 視覺空間、使用工具、穿衣 |
| **社會認知** | 辨識情緒、同理、行為抑制 |

1. **重度認知障礙症**(失智症)：一項或多項範疇比過去**明顯退步**，且**影響日常活動的獨立性**(例如付帳單、服藥需要協助)
2. **輕型認知障礙症**：退步程度較輕，**日常生活仍能獨立**，只是要花更多力氣或使用輔助方法
3. 必須排除只發生在**譫妄**期間，以及能用其他精神疾病(如憂鬱)更好解釋的情況

### 記憶的種類 {#memory}

| 種類 | 時間範圍 | 失智症的變化 |
|---|---|---|
| **立即記憶** | 數秒到數分鐘(例：重複剛說的三樣東西) | 早期就受影響 |
| **近期記憶** | 數分鐘到數天或數週(例：早餐吃什麼、昨天誰來過) | **最早明顯退化**，記不住新發生的事 |
| **遠期記憶** | 數月到數年以前(例：年輕時的工作、結婚) | **保留最久**，晚期才喪失 |

1. 正常老化也以**近期記憶**減退較明顯，但不會嚴重到影響日常生活
2. **虛談**(confabulation)：病人無意識地編故事**填補記憶空白**，不是故意說謊；早中期就可見
3. **定向感**喪失順序：**時間 → 地點 → 人物**(最後才不認得親人)

## 分類與病因 {#types}

| 類型 | 特徵 |
|---|---|
| **阿茲海默症** | 最常見；**緩慢漸進**，近期記憶先退化；年齡是最大危險因子，也和遺傳(家族史、唐氏症)有關 |
| **血管性失智症** | 中風或小血管病變造成；**階梯式惡化**，常有局部神經症狀；危險因子是高血壓、糖尿病、高血脂、抽菸，**控制三高可預防** |
| **路易氏體失智症** | 認知**明顯起伏**、早期就有**鮮明視幻覺**、**巴金森症狀**、快速動眼期睡眠行為障礙；對**抗精神病藥非常敏感** |
| **額顳葉失智症** | 發病較年輕；早期是**人格與行為改變**(失去抑制、冷漠、不得體)或語言退化，記憶相對保留 |
| 可治療或可逆的原因 | 甲狀腺低下、**維生素 B12 缺乏**、**常壓性水腦**(步態不穩、尿失禁、失智)、硬腦膜下血腫、神經性梅毒、藥物、憂鬱 |

::figure{src="/knowledge-images/servier-brain-lobes.svg" labels="brain-lobes" alt="大腦四葉的位置：額顳葉失智以額葉與顳葉為主"}

### 阿茲海默症的病理 {#ad-pathology}

1. **類澱粉蛋白斑塊**(老年斑塊)與 **tau 蛋白形成的神經纖維糾結**，是典型病變
2. 從**海馬迴**與內側顳葉開始，逐漸擴及大腦皮質；影像可見**腦萎縮、腦溝變寬、腦室擴大**
3. 基底前腦膽鹼神經元退化，**乙醯膽鹼減少**，所以藥物以乙醯膽鹼酯酶抑制劑為主(見 [[anti-dementia-drugs#mechanism]])
4. 是**慢性、進行性、不可逆**的退化性疾病，**不是可逆的**

### 預防 {#prevention}

1. 控制**高血壓、糖尿病、高血脂**，戒菸、節制飲酒
2. 規律運動、多動腦、**多參與社交活動**、均衡飲食(地中海飲食)
3. 預防頭部外傷、矯正聽力、治療憂鬱
4. 輕型認知障礙症到社區據點參加活動以**延緩退化**，屬三段預防的**限制殘障**

## 臨床表現與分期 {#manifestations}

### 認知症狀 {#cognitive-symptoms}

1. **記憶障礙**：重複問同一件事、忘記剛吃過飯(午睡後要吃早餐)、東西亂放後懷疑被偷
2. **失語**：找字困難、命名不能，晚期只剩單字或無語言
3. **失用**：動作能力正常卻不會穿衣、使用餐具
4. **失認**：感覺正常卻認不出物品或人臉
5. **執行功能障礙**：無法計畫、判斷力差、算錯錢、上街忘了付錢
6. **定向感障礙**：先失去時間，再來是地點(在熟悉的地方迷路)與人物

### 精神行為症狀(BPSD) {#bpsd-symptoms}

| 類型 | 表現 |
|---|---|
| 妄想 | **被偷妄想**最常見(東西自己藏起來找不到 → 認為家人偷)、被害、被遺棄、配偶不忠 |
| 幻覺 | 視幻覺較多(路易氏體尤其常見) |
| 情緒 | **易怒**、焦慮、憂鬱、淡漠 |
| 行為 | 激躁、攻擊、**遊走與走失**、翻箱倒櫃、重複行為、不適當的性行為 |
| 睡眠 | 日夜顛倒、夜間遊走 |
| **日落症候群** | **黃昏或夜間**光線變暗、刺激減少時，**混亂、焦躁、激動加重** |

### 病程分期 {#stages}

國考常用三期分法(各書年齡與年限不同，以症狀判斷)：

| 期別 | 常見表現 | 對應 CDR |
|---|---|---|
| **早期(健忘期)** | **近期記憶**減退、學習新事物能力下降、對人與周遭事情**興趣降低**、工作表現變差、情緒與個性改變；基本自理可以 | 1(輕度) |
| **中期(混亂期)** | 記憶更差、**定向感障礙、走失**、判斷力差(忘了付錢)、**被偷妄想**、易怒、**日落症候群**、失語失用失認、需要協助梳洗與日常生活 | 2(中度) |
| **晚期(失智期)** | 遠期記憶也喪失、不認得家人、語言幾乎喪失、**大小便失禁**、**吞嚥困難**、臥床、完全依賴 | 3(重度) |

:::note[考題分歧：日落症候群算早期還是中期]
- 114-2_PC_020 的答案把「出現日落症候群」當成**早期**主要症狀，臥床與無法自理屬晚期、失語屬中晚期
- 多數教科書把日落症候群放在**中期**的精神行為症狀；114-3_MS_003 也把「夜間活動增加」排除在早期表現之外
- 作答時：比較題選「最早出現」的就選它，單獨問分期則以中期為主
:::

## 鑑別 {#differential}

| | 失智症 | 譫妄 | 憂鬱(假性失智) |
|---|---|---|---|
| 發生 | **緩慢**、說不出時間點 | **急性**(數小時到數天) | 相對較快，說得出時間 |
| 病程 | 慢性進行、**不可逆** | 一天內**波動**，原因去除後多可恢復 | 治療憂鬱後**可改善** |
| 意識 | **清楚**(到晚期) | **混亂、起伏** | 清楚 |
| 注意力 | 早期大致正常 | **明顯受損** | 不專心、不努力 |
| 對記憶的態度 | 掩飾、**虛談** | — | **強調記不住**、常答「不知道」 |

1. 詳細比較見 [[delirium#differential]] 與 [[depressive-disorder#late-life]]
2. 老人有心情抑鬱與興趣缺缺，但**腦部影像顯示腦萎縮、腦溝變大** → 考慮阿茲海默症
3. 失智者也會發生**譫妄**；症狀突然惡化時先找身體原因(感染、脫水、藥物)

## 評估工具 {#assessment-tools}

| 工具 | 用途與重點 |
|---|---|
| **MMSE**(簡易智能量表) | **滿分 30 分**，分數越高越好；評估**定向感、記憶(登錄與回憶)、注意力與計算、語言、建構**；**不評估情緒**、**不用於評估急性意識狀態**；分數受**教育程度**影響 |
| **CDR**(臨床失智評估量表) | 評估**失智嚴重度**：0 正常、0.5 未確定或極輕度、1 輕度、2 中度、3 重度；健保與長照用來分級 |
| **SPMSQ**(簡易心智狀態問卷) | 10 題，依錯誤題數**篩檢**認知功能障礙，**不是**用來確定失智等級 |
| **AD8** | 8 題的極早期失智篩檢，由本人或家屬填寫 |
| **ADL、IADL** | 日常生活與工具性日常生活**功能**；評估失能，不是評估認知 |

1. 修正版柯氏量表、ADL、IADL 是**身體功能**評估；MMSE 是**認知**評估，所以「用 MMSE 評估失能」不適當
2. 老年人評估原則
   1. 反應慢或答不出來時，**換個問法**再試
   2. 分次收集資料，避免疲倦；生命回顧的內容**也要收集**
   3. 病人與家屬的說法**都要聽**，不是只採家屬的版本

## 治療 {#treatment}

1. **藥物**：輕中度用乙醯膽鹼酯酶抑制劑，中重度用 memantine，都只能延緩症狀，見 [[anti-dementia-drugs]]
2. **非藥物介入**
   1. **現實導向**：時鐘、日曆、明顯標示，隨時提供人時地的訊息
   2. **懷舊治療**：翻閱相簿、談過去成功的經驗，提升自尊(見 [[group-family-therapy#group-types]])
   3. 認知促進活動、音樂、藝術、園藝、規律運動
3. **精神行為症狀**：先找原因(疼痛、感染、便秘、環境)，用非藥物方法；抗精神病藥只短期用於嚴重症狀，**避免 BZD**，見 [[anti-dementia-drugs#bpsd-drugs]]
4. 治療可逆的原因(甲狀腺、維生素 B12、常壓性水腦)

## 護理 {#nursing}

### 照護目標與原則 {#nursing-principles}

1. **首要目標是安全**，預防跌倒、走失、誤食與受傷
2. 維持**最佳的生活功能**與**尊嚴**；協助**發揮尚存的優勢和能力**，不要什麼都替他做(會加速失能)
3. **固定、可預測的環境**
   1. 規律的作息，**不要每天改變活動**
   2. **固定的照顧者**，不要每天換不同人員
   3. **不要變動擺設**；帶家中**熟悉的物品與家人照片**來布置
4. **環境刺激適中**：安靜、熟悉，不要過度刺激，也不要完全剝奪；可安排與同輩的團體活動
5. **現實導向**：時鐘與日曆放在醒目處、房間與廁所明顯標示、光線充足
6. 稱呼病人**習慣的稱謂或名字**

### 溝通 {#communication}

1. 先叫名字、眼神接觸，從正面靠近
2. **簡短、具體**，**一次只談一件事**、一次一個步驟
3. 用**封閉式或選擇式**問句，避免開放式；不用成語、諺語與抽象語言
4. **重點重複**，輔以**手勢、示範、圖片**
5. 速度放慢、音量適中、**音調低沉**(高音調聽起來像生氣，老人也較難聽清楚高頻)
6. 注意病人的**音調、表情與姿勢**推測感受；眼神避開可能表示聽不懂
7. 記不住護理師名字 → **每次見面簡短自我介紹**，不要要求背名字或反問
8. 聽力障礙：面對面、說慢一點，不是只能大聲說話

### 精神行為症狀的處理 {#bpsd}

1. **先找原因**：疼痛、發燒、咳痰、便秘、尿滯留、飢餓、環境改變、溝通誤會
2. **激躁或攻擊**：保持冷靜、**帶離刺激的現場**、處理身體不適；不是立即打針、約束或說教
3. **妄想**(懷疑家人偷東西)
   1. **不爭辯、不糾正**，也不用請家屬解釋
   2. 接納情緒，**轉移注意力**到喜歡的活動
   3. 觀察病人**常藏東西的地方**，找不到時幫忙找
   4. 在病人面前說話不要壓低聲音或竊竊私語，以免加重懷疑
4. **幻覺**：不爭辯，也不完全忽略；評估是否引起害怕並給予安全感
5. **日落症候群**：傍晚**開燈、維持明亮**(不要拉上窗簾調暗)、減少噪音、白天安排活動、維持作息
6. **遊走與走失**
   1. 配戴**有姓名與電話的手鍊**、辦理**預防走失指紋捺印**、衛星定位
   2. 大門加裝門栓或密碼鎖、門口警示
   3. 住院時安排在**靠近護理站**的病房，不是鎖病室門或給抗焦慮劑
7. **睡眠**：白天安排適度活動、**白天不要調暗燈光補眠**、減少午睡

### 日常生活照顧 {#adl-care}

1. **如廁**：**定時帶去廁所**，廁所明顯標示；不要直接包尿布、不要限水
2. **飲食**：手指食物、提醒咀嚼吞嚥，晚期注意嗆咳與營養
3. **居家安全**：危險物品(藥品、清潔劑、刀具)**收起來**；瓦斯安全
4. 穿衣：依順序擺好衣服，用簡單的鬆緊帶與魔鬼氈

### 家屬與照顧者 {#caregiver}

1. **傾聽照顧者的感受**，給予情緒支持
2. 介紹**社會資源**：喘息服務、日間照顧、家屬支持團體、照顧訓練
3. 教導溝通與行為處理技巧
4. 照顧者長期身心疲憊時，提供**喘息服務**與**情緒支持**

## 老年精神健康 {#geriatric-mental-health}

1. **正常老化**：近期記憶較容易減退，但不影響日常生活；學習速度變慢、反應時間延長
2. **Erikson**：老年期任務是**統整 vs 絕望**；生命回顧時覺得虛度光陰而懊悔、焦慮 → 絕望(見 [[psychodynamic-theories#erikson]])
3. **常見精神問題**：憂鬱(常以身體症狀表現、自殺風險最高)、失智、譫妄、焦慮、失眠、以飲酒或濫用處方藥因應壓力(見 [[depressive-disorder#late-life]])
4. **用藥**：從**最低劑量開始、慢慢加**；第二代抗精神病藥錐體外徑症狀較少；避免 TCA 與 BZD(見 [[antipsychotics#nursing-monitoring]])
5. **睡眠指導**
   1. 前一晚失眠，白天**不要多臥床**，仍維持白天活動
   2. 有計畫地安排白天活動、規律起床時間、限制午睡
   3. 白天精神好的偶爾失眠不必過度擔心；必要時才短期用藥
6. **遷移壓力**(搬進機構)：入住前充分準備、**固定照顧者**、鼓勵親友常探視、提供日常活動的選擇
7. **溝通**：一次只談一個問題、給足夠時間回答、適度眼神接觸
