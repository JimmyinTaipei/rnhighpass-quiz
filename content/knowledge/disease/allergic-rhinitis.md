**過敏性鼻炎**是**IgE 媒介**的鼻黏膜慢性發炎：吸入過敏原後，肥大細胞釋出組織胺與白三烯，造成**打噴嚏、水樣鼻漏、鼻塞、鼻癢**。它是最常見的第Ⅰ型過敏疾病之一，常和**氣喘、異位性皮膚炎、結膜炎**並存，所以護理指導會同時涵蓋這些疾病

## 重點摘要 {#summary}

- 症狀四聯：**打噴嚏、水樣鼻漏、鼻塞、鼻(眼)癢**；**季節性**(花粉)與**常年性**(**塵蟎**、蟑螂、黴菌、寵物)
- 診斷靠病史與理學檢查；**皮膚點刺試驗**或**血清特異性 IgE**確認過敏原
- 治療：**迴避過敏原** → **鼻用類固醇**(最有效的單一藥物) → **第二代口服抗組織胺**或鼻用抗組織胺 → 合併用藥 → **過敏原免疫治療**
- **去鼻充血劑**噴劑**連續使用過久**會造成**藥物性鼻炎**
- **異位性疾病**常同時存在，「過敏性鼻炎與蕁麻疹不可能一起發生」是**錯的**

### 國考常考點 {#exam-points}

- 過敏性鼻炎屬**第Ⅰ型**；鼻黏膜蒼白水腫、**鼻分泌物嗜酸性球增加**、血中 IgE 常升高
- 過敏原迴避、環境控制是**基礎治療**；**抗組織胺**緩解症狀，**類固醇**也可用於緩解過敏症狀
- 護理指導(要選**對**與**錯**時)
  1. **避免**使用**羽絨被、羽毛枕、地毯、毛絨玩具、厚重窗簾**；**建議**防螨寢具、除濕機與有濾網的空調、定期熱水清洗寢具
  2. **風大的天氣戴口罩**；花粉季節關閉門窗、外出後盥洗，**但**室內仍要**維持通風**與使用空氣清淨設備
  3. **異位性過敏有遺傳傾向**，要提醒家族史
- 抗組織胺的副作用：**嗜睡、口乾**(第一代明顯)；見 [[antihistamines-autacoids]]

## 臨床表現 {#clinical}

1. **鼻部症狀**：**打噴嚏(連續)**、**水樣鼻漏**、**鼻塞**、**鼻癢**、後鼻滴流引起咳嗽或喉嚨癢
2. **眼部症狀**：**眼睛癢、流淚、結膜充血**(過敏性結膜炎)
3. **外觀與理學檢查**
   1. **過敏性敬禮**：兒童常用手掌向上揉鼻，造成**鼻樑橫紋**
   2. **過敏性黑眼圈**(眼下暗影)
   3. **鼻甲蒼白、水腫**(感染則偏紅)
4. **分類**
   1. **季節性**(枯草熱)：花粉、黴菌孢子，在特定季節發作
   2. **常年性**：**塵蟎**、蟑螂、寵物毛屑、黴菌，全年或加重
   3. 亦可依症狀**間歇性與持續性**、**輕度與中重度**分級
5. **併發症與共病**
   1. **氣喘**：上下呼吸道同一種過敏發炎，鼻炎控制不好會讓氣喘更難控制
   2. 鼻竇炎、**中耳炎(積液)**、**睡眠呼吸障礙**、注意力與學習受影響

## 診斷 {#diagnosis}

1. **病史**：症狀與接觸的關係、季節性、家族史(異位性)、家中環境(寢具、寵物、地毯)
2. **皮膚點刺試驗**：確認過敏原的**首選**；檢查前要**停用抗組織胺**(約數天，依藥物)
3. **血清特異性 IgE**：無法停藥或皮膚病變廣時使用；總 IgE 與血中嗜酸性球**僅供參考**
4. **鼻分泌物塗片**可見嗜酸性球
5. 先排除**感染**(病毒感冒：症狀約一週內好轉、鼻分泌物變黃)與**非過敏性鼻炎**(自主神經性、藥物性、血管收縮性)

## 治療 {#treatment}

### 治療階梯 {#step-therapy}

1. **迴避過敏原與環境控制**(見下節)
2. **鼻用類固醇**(例如 fluticasone、mometasone)：**對鼻塞、鼻癢、打噴嚏、流鼻水全面有效**，是**最有效**的單一藥物；**需要規則使用**才有效(數天到一週起效)
3. **第二代口服抗組織胺**(loratadine、cetirizine、fexofenadine 等)：緩解**打噴嚏、流鼻水、搔癢**，對鼻塞效果較差
4. **鼻用抗組織胺**(azelastine、olopatadine)：起效快，可在預期接觸前使用
5. **鼻用類固醇＋鼻用抗組織胺的複方**：單藥不夠時使用
6. **白三烯受體拮抗劑**(montelukast)：效果有限，**合併氣喘**時可考慮
7. **短期**使用**去鼻充血劑**：口服(**高血壓、心臟病、青光眼、攝護腺肥大慎用**)與噴劑(連續使用超過**數天**會**反彈性鼻塞**，即**藥物性鼻炎**)
8. **異丙托溴銨(ipratropium)鼻噴劑**：用於**水樣鼻漏**為主者
9. **過敏原免疫治療**(皮下注射 SCIT 或舌下含服 SLIT)：用於**藥物控制不佳**或不願長期用藥者，療程以**年**計；**第一次與劑量調整階段要在有急救能力的場所觀察**

### 第一代與第二代抗組織胺 {#antihistamine-choice}

| | **第一代** | **第二代** |
|---|---|---|
| 例子 | diphenhydramine、chlorpheniramine、hydroxyzine | loratadine、cetirizine、fexofenadine |
| 通過血腦障壁 | **容易** | **較難** |
| **嗜睡、認知影響** | **明顯** | **輕微或無** |
| **抗膽鹼副作用**(口乾、尿滯留、視力模糊) | **明顯** | **少** |
| 建議 | 一般**不建議**用於鼻炎，**老年人避免** | **首選** |

## 環境控制與護理指導 {#environment}

過敏原迴避的效果有限，但仍是治療一環。重點是**塵蟎**(最常見的室內過敏原)：

1. **寢具**
   1. 床墊、枕頭使用**防螨(防過敏原)寢具套**
   2. **每週**用**熱水**與清潔劑清洗床單、被套、枕套，並以**烘衣機熱風烘乾**
   3. **避免羽絨被、羽毛枕**；可用**化纖**材質(例如尼龍枕頭)
2. **居室**
   1. **移除地毯**、厚重窗簾，改用**可水洗的百葉窗**或窗簾；少用布面沙發
   2. **減少毛絨玩具**、書堆與雜物
   3. **保持乾燥**，使用**除濕機**，因為塵蟎靠吸收空氣中的水氣生存
   4. **使用有濾網的空調**並定期清洗濾網，**避免用掃把乾掃**，改用**濕拖與有濾網的吸塵器**
3. **蟑螂**：清除食物殘渣、密封垃圾；**黴菌**：除濕、清理浴室與通風不良處
4. **寵物**：最有效是**不養**；若要養，**不進臥室**
5. **花粉**：花粉季**關閉門窗**、外出戴口罩與眼鏡、回家後**洗臉與沖澡、換衣服**，避免晾衣在戶外
6. **不要**把「關閉門窗並開空調循環室內空氣」當成萬能(要使用濾網並定期清潔，否則反而累積過敏原)
7. **戒菸**與避免二手菸、空氣污染、香水與刺激性氣味
8. **衛教要點**
   1. 異位性過敏有**家族遺傳傾向**
   2. **正確使用鼻噴劑**：噴頭朝向**外側鼻壁**，**不要朝向鼻中隔**，噴後輕輕吸氣，避免用力擤鼻
   3. 規則用藥，不要只在症狀嚴重時才用
   4. **過敏性鼻炎、氣喘、異位性皮膚炎、蕁麻疹**可同時存在
