**尿崩症**與 **SIADH** 都是抗利尿激素(ADH)出問題，方向剛好相反：一個留不住水、一個留太多水。本頁整理兩者的原因、檢驗、治療與護理，並和腦耗鹽症候群比較；ADH 的正常生理見 [[hypothalamus-pituitary#posterior-lobe]]，頭部外傷與腦瘤術後的變化也見 [[head-injury]]、[[pituitary-disorders#transsphenoidal-surgery]]

## 重點摘要 {#summary}

- **尿崩症**：ADH 不足或無效 → **多尿**(每天可達數公升)、**稀釋尿**(尿比重 **< 1.005**、尿色淡)、**劇渴**、**血鈉與血漿滲透壓上升**、脫水(黏膜乾、眼眶凹陷、**心搏過速**、脈搏細弱、嚴重時低血容積休克)
- 尿崩症 2022 年國際建議改名：中樞性 → 精胺酸血管加壓素缺乏(**AVP-D**)、腎因性 → 精胺酸血管加壓素抗性(**AVP-R**)；國考仍用尿崩症
- 尿崩症**不可限水**；中樞性用 **desmopressin**(DDAVP)，鼻噴劑噴在**鼻黏膜**、**不要用力吸**進肺部；腎因性用 **thiazide** 加限鹽
- **SIADH**：ADH 過多 → 水分滯留 → **稀釋性低血鈉**(< 135 mEq/L)、**低血漿滲透壓**、**尿量少**、**尿比重與尿滲透壓高**、**尿鈉高**、低尿酸
- SIADH 常見原因：**肺小細胞癌**等腫瘤、中樞神經疾病(頭部外傷、腦瘤、腦膜炎)、肺部疾病、藥物；**不是**泌尿道疾病
- SIADH 早期**食慾不振**、噁心、頭痛，嚴重時意識改變、抽搐、昏迷(水中毒)
- SIADH 治療：**限水**(每天約 500–1,000 mL)、治療原因；嚴重時 **3% 高張食鹽水**(緩慢)＋furosemide；demeclocycline(四環素類，**讓腎臟對 ADH 不敏感**，不是為了抗感染)

### 國考常考點 {#exam-points}

- 腦下垂體**後葉**受損 → 尿崩症 → **多尿**(不是少尿)；屬於腦下垂體後葉症候群的是**尿崩症**
- 腦瘤術後尿崩症：**ADH 不足**、尿比重**低**、血漿滲透壓**上升**、可能**高血鈉**
- 中樞性尿崩症：多尿、劇渴、**心搏過速**；**不會**體液過多或水腫、**不會**低血鈉
- 尿崩症的尿比重 **< 1.005**，不是 1.010–1.030；嚴重時低血容積休克
- 尿崩症適合的輸液：**0.33% 食鹽水**(低張)
- 腎因性尿崩症：**thiazide＋限鹽**；vasopressin tannate 是油性懸浮液，抽藥前**溫熱並搖勻**
- 水分剝削試驗檢測**滲透壓**、尿量、體重(不是鈣、鉀)；兒童體重下降 **3–5%** 就要停止(20 公斤減 1 公斤不可繼續)
- SIADH：血鈉低、尿量少、**尿比重高**；照護是**限水**、監測抽搐與昏迷、預防**低血鈉**(不是高血鈉)、鼓勵**高纖**飲食
- SIADH 不是腦下垂體**前葉**的問題

## 兩者比較(含腦耗鹽症候群) {#comparison}

| | 尿崩症 | SIADH | 腦耗鹽症候群 |
|---|---|---|---|
| 機轉 | ADH **不足**(中樞性)或腎臟**沒反應**(腎因性) | ADH **過多** | 腦部疾病讓腎臟大量排鈉 |
| 尿量 | **大量** | **少** | 多 |
| 尿比重、尿滲透壓 | **低**(< 1.005) | **高** | 高 |
| 血鈉 | **高**(或正常) | **低**(稀釋性) | 低 |
| 血漿滲透壓 | **高** | **低** | 低 |
| 體液容積 | **不足**(脫水) | 正常或略多(通常沒有水腫) | **不足** |
| 處理 | **補水**、desmopressin | **限水** | **補鈉補水**(不可限水) |

- 頭部外傷、腦部手術(尤其經蝶骨手術)後兩種都可能出現，要**每小時**記錄輸出入量、尿比重與尿色(見 [[head-injury]])

## 尿崩症 {#diabetes-insipidus}

### 原因 {#di-causes}

| 類型 | 機轉 | 常見原因 |
|---|---|---|
| **中樞性**(AVP-D) | 下視丘或後葉**分泌 ADH 不足** | **頭部外傷**、**腦下垂體或腦部手術**、腦瘤、感染、原因不明 |
| **腎因性**(AVP-R) | 集尿管對 ADH **沒有反應** | 鋰鹽、高血鈣、低血鉀、慢性腎病、遺傳 |

- 要和**原發性劇渴**(喝太多水)區分

### 表現與檢驗 {#di-manifestations}

- **多尿**、夜尿，尿色淡如水、**尿比重 < 1.005**、尿滲透壓低
- **劇渴**、喜歡喝冰水；喝水跟不上時 → **高血鈉**、血漿滲透壓上升
- 脫水：黏膜乾燥、**眼眶凹陷**、體重下降、**心搏過速**、脈搏細弱、低血壓，嚴重時**低血容積休克**

### 水分剝削試驗 {#water-deprivation-test}

1. 開始禁水，**每小時**量體重、尿量、尿比重，並抽血與驗尿測**滲透壓**
2. 密切觀察生命徵象與意識
3. 體重下降 **3–5%** 或出現低血壓、心搏過速等脫水徵象時**停止**(例：20 公斤的兒童減少 1 公斤就停)
4. 最後給 desmopressin：尿液變濃 → **中樞性**；沒變化 → **腎因性**
- 正常人或原發性劇渴者禁水後尿液會濃縮；尿崩症的尿持續稀釋

### 治療 {#di-treatment}

- **中樞性**：補充 ADH
   1. **desmopressin(DDAVP)**：鼻噴劑、口服、皮下或靜脈注射；鼻噴劑作用約 8–20 小時
   2. vasopressin 水溶液：靜脈或肌肉注射，作用短
   3. vasopressin tannate **油性懸浮液**：抽藥前先**溫熱、搖勻**(國考常考的舊劑型；台灣醫院現有的是**水溶性** vasopressin 注射液 Pitressin，見 [[pituitary-hormones#adh-analogues]])
- **腎因性**：**thiazide 利尿劑**加**限鹽**(必要時限蛋白質)，讓近端小管回收更多水；停用鋰鹽等原因藥物
- 補液：高血鈉脫水時依醫囑給**低張溶液**(例：**0.33%** 或 0.45% 食鹽水、5% 葡萄糖液)

### 護理 {#di-nursing}

1. 每小時記錄**輸出入量**、**尿比重**、尿色；每日同時間量**體重**；監測血鈉、血漿滲透壓與生命徵象
2. **不可限制水分**，讓病人依口渴喝水，床邊備水；限水會讓病人無法代償而嚴重脫水
3. 避免咖啡、茶、酒精等**利尿飲品**；睡前少喝水、減少夜間干擾
4. **desmopressin 鼻噴劑**：噴入鼻腔、讓藥附著在**鼻黏膜**吸收，**不要用力吸氣**(藥會流到咽喉、效果變差)、**不是吸入肺部**；鼻塞或感冒時吸收差，需告知醫師
5. 觀察**用藥過量**：尿量太少、體重增加、頭痛、水腫、低血鈉(水中毒)
6. 出院指導：自我注射或噴藥方法、劑量與副作用、記錄體液、**隨身攜帶識別卡**、定期回診

- 題目用詞：112-1_OP_070 選項中的「血管緊縮素」指的是**血管加壓素**(vasopressin／desmopressin)

## 抗利尿激素分泌不當症候群(SIADH) {#siadh}

### 原因 {#siadh-causes}

- **惡性腫瘤**：**肺小細胞癌**最典型(腫瘤自己分泌 ADH)，其他如胰臟癌、淋巴瘤(腫瘤急症見 [[cancer-treatment-toxicities]])
- **中樞神經疾病**：頭部外傷、腦瘤、腦部手術、腦膜炎、腦中風
- **肺部疾病**：肺炎、肺結核、正壓呼吸器
- **藥物**：carbamazepine、抗憂鬱劑(SSRI)、cyclophosphamide、vincristine、chlorpropamide 等
- 疼痛、噁心、手術後壓力
- **通常不是**泌尿道疾病造成

### 表現與檢驗 {#siadh-manifestations}

| 檢驗 | SIADH 的變化 |
|---|---|
| 血鈉 | **< 135 mEq/L**(稀釋性低血鈉) |
| 血漿滲透壓 | **降低**(低張) |
| 尿量 | **減少** |
| 尿比重、尿滲透壓 | **升高**(尿液不適當地濃縮) |
| 尿鈉 | **升高**(例：> 40 mEq/L) |
| 血中尿酸 | 降低 |

- 症狀隨血鈉下降速度與程度加重：**食慾不振**、噁心嘔吐(最早)、頭痛、體重增加但**通常沒有明顯水腫** → 倦怠、混亂、**肌肉抽搐** → 癲癇發作、**昏迷**(水中毒、腦水腫)
- 體液是**低張**的，不是高張

### 治療 {#siadh-treatment}

1. **限水**：每天約 **500–1,000 mL**(依醫囑與嚴重度)
2. 治療原因(腫瘤、停用藥物)
3. 嚴重或有神經症狀的低血鈉：**3% 高張食鹽水**加 furosemide，**緩慢**矯正；第一個 24 小時血鈉上升**不超過 10 mEq/L**，太快會造成滲透性去髓鞘症候群(European hyponatraemia guideline 2014)
4. 藥物：**demeclocycline**(四環素類，副作用是讓腎臟對 ADH 不敏感，用來**排水**，**不是預防感染**)、**tolvaptan**(V2 受體拮抗劑)

### 護理 {#siadh-nursing}

1. **確實執行限水**，向病人與家屬說明原因；口渴時可用漱口、少量冰塊(計入攝入量)
2. 每日體重、輸出入量；監測**血鈉**、血漿與尿液滲透壓、血壓、中心靜脈壓
3. 評估**意識**與神經症狀，注意**肌肉抽搐**、癲癇與**昏迷**，做好安全防護
4. 床頭**平放或抬高不超過約 10 度**，增加靜脈回流、減少 ADH 分泌(不是頭低腳高)
5. 限水易**便秘**：鼓勵**高纖**與含鈉的食物
6. 給 3% 食鹽水時用輸液幫浦控速，密切追蹤血鈉
