高危險妊娠是指懷孕時母親或胎兒因生理、心理或社會因素，發生不良結果的機會比一般孕婦高。本頁整理高危險因素、合併心臟病與糖尿病、妊娠劇吐與貧血、懷孕早期出血（流產、子宮頸閉鎖不全、子宮外孕、葡萄胎）、第三孕期出血（前置胎盤與胎盤早期剝離）、子癇前症與 HELLP、Rh 與 ABO 血型不合，以及早產高危險孕婦的自我照顧。高血壓分類、降壓藥與硫酸鎂見 [[hypertension#pregnancy]]，妊娠糖尿病診斷與治療見 [[diabetes#gdm]]、[[ogtt#gdm-criteria]]，孕期感染見 [[perinatal-infections]]，胎兒評估見 [[prenatal-assessment]]。文中縮寫：NYHA（New York Heart Association，紐約心臟學會）、hCG（human chorionic gonadotropin，人類絨毛膜促性腺激素）、DIC（Disseminated intravascular coagulation，瀰漫性血管內凝血）、HELLP(Hemolysis, Elevated Liver enzymes, Low Platelets)

## 重點摘要 {#summary}

- 高危險妊娠**不一定**有不良結果；良好的產前照護與胎兒評估可以**降低危險**
- **心臟病**：28–32 週、**待產分娩**、**產後 48 小時**最容易心衰竭；多數可**陰道生產**（減痛、縮短第二產程），不是一律剖腹產
- **糖尿病**：巨嬰、**羊水過多**、**新生兒低血糖**、呼吸窘迫、子癇前症；需要時用**胰島素**
- 流產：**先兆性**＝出血、子宮頸口**未開**；**不可避免（迫切性）**＝子宮頸口**已開**
- **子宮頸閉鎖不全**：第二孕期**無痛性**子宮頸擴張、反覆流產 → **子宮頸環紮術**（約 12–14 週）
- **子宮外孕**：最常在**輸卵管壺腹部**；可用 methotrexate 或手術
- **葡萄胎**：子宮**大於週數**、**hCG 很高**、劇吐、看不到胎兒
- **前置胎盤**：**無痛**、**鮮紅**、反覆出血，子宮軟、胎位常不正；**禁止陰道內診**
- **胎盤早期剝離**：**腹痛**、子宮**硬如木板**、高張宮縮、**暗紅**出血或內出血、胎心音異常、**DIC**；血滲入肌層＝**庫弗萊爾氏子宮**
- **HELLP**：**溶血**、**肝指數上升**、**血小板 < 10 萬**；多在第三孕期或產後
- **Rh 陰性**母親：**28 週**與產下 Rh 陽性嬰兒後 **72 小時內**給抗 D 免疫球蛋白

### 國考常考點 {#exam-points}

- Goodwin 產前胎兒危險計分**包括年齡與產次**；一般孕婦不是「零危險」；高危險妊娠的定義包括**胎兒**
- 心臟病孕婦：**不一律剖腹產**；產後**不是絕對平躺**；**產後 48 小時**靜脈回流增加要密切監測；第一級可以哺乳；38–40 週不是負荷最大；體重增加控制在約 10 公斤、飯後躺下休息
- 妊娠糖尿病的合併症**不包括羊水過少**（是羊水過多）
- 糖尿病母親的巨嬰出生後低血糖：母親的葡萄糖中斷，但新生兒**體內胰島素過多**
- 孕婦拒絕胰島素：說明上一胎 4,100 公克巨嬰可能與血糖有關，**血糖不穩對寶寶有影響**，鼓勵接受治療
- 8 週、點狀出血、微痛、子宮頸口未開、胎心正常 → **先兆性流產** → **臥床休息、黃體素**
- 子宮頸環紮術：前兩胎約 21 週**無痛性流產**、這胎 16 週 → 適合；已破水、規則宮縮、子宮頸已開 4 公分、28 週才發現的都不適合
- 子宮外孕：hCG **會上升**（但比正常慢）；**不是只能腹腔鏡**（也可藥物 methotrexate）；好發輸卵管壺腹部；出血時腹痛
- 8 週出血、劇吐、子宮大於週數、hCG 高、沒有胎兒 → **葡萄胎**
- 32 週突然**腹痛＋暗紅色出血** → **胎盤早期剝離**；子宮硬、壓痛、高張宮縮、胎心音難測、可以沒有外出血
- 胎盤早期剝離的處置：依醫囑做**凝血篩檢**（預防 DIC 出血）；不是熱敷、不是給抗生素
- 前置胎盤：**腹部不會呈木板狀**（那是早期剝離）；常合併**胎位不正**；**禁止陰道內診**；**有前置胎盤病史者再發率高**；與高齡、多次刮宮、多胎、前次剖腹產有關；診斷要到約 32 週後才確定（早期低位胎盤可能上移）；不是一律絕對臥床
- 前置胎盤安胎失敗：**不是只能剖腹產**（邊緣性或低位可嘗試陰道生產）
- 胎盤早期剝離的出血**不是**無痛性；與逆行性感染無關；常是**高張**宮縮
- HELLP：**H＝溶血**（不是血尿）、**EL＝肝指數上升**、**LP＝血小板 < 10 萬**；多在**第三孕期**，不是第一孕期；與 ABO 血型不合無關
- 重度子癇前症的危險徵候：**嚴重頭痛、視力模糊**；4 小時 400 mL 尿量正常；肌酸酐是**上升**不是下降
- Rh 陰性初產下 Rh 陽性女嬰：**此胎產後 72 小時內**注射
- 早產高危險孕婦：每天**喝水 2,000–3,000 mL**；**不要**按摩乳頭（會引起宮縮）；安胎穩定後仍要限制活動；避免咖啡因

## 高危險因素 {#risk-factors}

| 類別 | 例子 |
|---|---|
| 母親基本資料 | **< 18 歲或 ≥ 34 歲**、身高 < 145 公分、肥胖或過瘦、多產 |
| 產科病史 | 流產或早產、死產、前次剖腹產、子癇前症、產後出血、巨嬰、先天異常兒 |
| 內科疾病 | **心臟病**、**糖尿病**、高血壓、腎病、甲狀腺、**貧血**（含海洋性貧血）、紅斑性狼瘡、感染（梅毒、B 肝、HIV） |
| 本次懷孕 | **多胞胎**、出血、子癇前症、胎位不正、羊水過多或過少、胎兒生長遲滯、Rh 陰性、過期妊娠 |
| 社會心理 | 抽菸、酒精、藥物濫用、未產檢、經濟或支持不足、家暴 |

- **Goodwin 產前危險計分**：把母親年齡、產次、產科病史、內科疾病、本次懷孕問題加權計分，分數越高越危險
- 有危險因素**不一定**會有不良結果；良好產前照護、胎兒評估可降低危險

## 合併心臟病 {#cardiac}

- 懷孕血液容積與心輸出量增加，心臟負荷加重（見 [[maternal-adaptation#cardiovascular]]）
- **心衰竭高危險時期**：**28–32 週**、**待產與分娩**、**產後 48 小時**
- 依 NYHA 分級：第 I、II 級多可順利懷孕；第 III、IV 級懷孕風險高
- 產前照護
   1. **充分休息**：每晚 8–10 小時睡眠，**飯後躺下休息至少 30 分鐘**（左側臥）
   2. 限制體重增加（約 **10 公斤**）、適度限鈉、補鐵預防貧血（貧血增加心臟負荷）
   3. 預防感染（上呼吸道感染會誘發心衰竭）
   4. 觀察心衰竭徵象：咳嗽、呼吸困難、端坐呼吸、心跳加快、水腫加劇
   5. 心臟病孕婦較易**早產、流產**、胎兒生長遲滯
- 分娩
   1. 多數可**陰道生產**；剖腹產依產科適應症，**不是一律剖腹產**
   2. 半坐臥或**側臥**、給氧、**硬膜外減痛**降低心臟負荷
   3. **縮短第二產程**（真空吸引或產鉗），避免長時間閉氣用力
- 產後
   1. **產後 48 小時**回心血量突然增加 → 密切監測生命徵象、輸入輸出、肺音
   2. 半坐臥休息，**漸進下床**（不是絕對平躺）；預防血栓
   3. 第 I、II 級可以哺乳；III、IV 級依體力評估
   4. 避孕避免含雌激素製劑（見 [[family-planning]]）
- 心衰竭治療見 [[heart-failure]]

## 合併糖尿病 {#diabetes}

- 診斷、篩檢（24–28 週 75 g 一階段）與血糖目標見 [[diabetes#gdm]]、[[ogtt#gdm-criteria]]
- **對母親**：**子癇前症**、羊水過多、感染（泌尿道、陰道念珠菌）、難產與剖腹產、產後出血、日後第 2 型糖尿病
- **對胎兒與新生兒**

| 合併症 | 機轉 |
|---|---|
| **巨嬰**（≥ 4,000 公克）、肩難產 | 母親高血糖 → 胎兒**高胰島素**促進生長 |
| **羊水過多** | 胎兒高血糖造成多尿 |
| **新生兒低血糖** | 出生後母親的葡萄糖**中斷**，但新生兒體內**胰島素仍過多** |
| 呼吸窘迫症候群 | 高胰島素延緩肺表面張力素成熟 |
| 低血鈣、高膽紅素血症、紅血球過多 | |
| 先天畸形（妊娠前糖尿病） | 器官形成期高血糖 |
| 胎死腹中 | 第三孕期血糖控制不良 |

- 治療：飲食、運動、血糖監測；不夠時用**胰島素**（不通過胎盤）；胰島素需要量隨孕程**增加**（胎盤激素拮抗），產後**驟降**
- 孕婦拒絕用藥時：同理她的擔心，說明**血糖控制不良對寶寶的影響**（例如上一胎巨嬰可能與血糖有關），鼓勵接受治療
- 妊娠末期每週 **NST** 評估胎盤功能（見 [[prenatal-assessment#nst]]）
- 新生兒低血糖的照護見 [[neonatal-disorders#hypoglycemia]]

## 妊娠劇吐與貧血 {#hyperemesis}

- **妊娠劇吐**：持續嚴重嘔吐，**體重下降 > 5%**、脫水、酮尿、電解質失衡（低血鉀）
   1. 與 hCG 很高有關（多胞胎、葡萄胎較常見）
   2. 處置：暫時禁食、**靜脈輸液**補水與電解質、止吐劑、**維生素 B1**（預防 Wernicke 腦病變）；症狀改善後少量多餐、從乾的食物開始
   3. 記錄輸入輸出、體重、尿酮；心理支持
- **貧血**
   1. 懷孕血紅素 **< 11 g/dL**（第二孕期 < 10.5）才算貧血（生理性稀釋見 [[maternal-adaptation#cardiovascular]]）
   2. 最常見是**缺鐵性貧血**：補鐵、飲食（見 [[prenatal-care#nutrient-needs]]、[[anemias#iron-deficiency]]）
   3. 巨母紅血球性貧血：葉酸或 B12 不足
   4. **海洋性貧血**：夫妻都帶因時做產前診斷（見 [[anemias#thalassemia-care]]）

## 懷孕早期出血 {#early-bleeding}

### 流產 {#abortion}

20 週前（或胎兒體重 < 500 公克）懷孕終止

| 種類 | 出血與腹痛 | 子宮頸口 | 處置 |
|---|---|---|---|
| **先兆性（脅迫性）** | **點狀或少量出血**、輕微腹痛 | **未開** | **臥床休息**、避免性交與提重物、依醫囑**黃體素**；超音波確認胎心 |
| **不可避免（迫切性）** | 出血增加、規則腹痛、可能破水 | **已開** | 無法保住，等待排出或清除 |
| 不完全 | 大量出血、部分組織排出 | 開 | **子宮內膜刮除術**、子宮收縮劑 |
| 完全 | 組織全部排出後出血減少 | 關閉 | 觀察 |
| **稽留（過期）** | 胎兒已死亡但留在子宮內，可能無症狀 | 關閉 | 清除；留置太久有 **DIC** 風險 |
| **習慣性（反覆性）** | 連續 3 次以上（新定義 2 次） | | 找原因：染色體、子宮構造、**子宮頸閉鎖不全**、抗磷脂抗體 |
| 敗血性 | 發燒、惡臭分泌物 | | 抗生素、清除 |

- 流產後護理：觀察出血與感染、Rh 陰性者給抗 D 免疫球蛋白、哀傷輔導；人工流產法規見 [[obstetric-nursing-foundations#ethics-law]]

### 子宮頸閉鎖不全 {#cervical-insufficiency}

- 子宮頸在**沒有宮縮**下**無痛性擴張**，在**第二孕期**（約 16–24 週）反覆流產或早產；常先破水
- 原因：先天、子宮頸錐狀切除或多次擴張刮除、子宮頸撕裂傷
- **子宮頸環紮術**
   1. 依病史（**前胎第二孕期無痛性流產**）：約 **12–14 週**預防性施行
   2. 依超音波：有早產史且子宮頸變短
   3. **禁忌**：已破水、規則宮縮、感染、出血、子宮頸已明顯擴張、胎兒異常
   4. 術後：觀察宮縮、出血、破水；避免性交與提重物；約 **36–37 週**拆線（臨產或破水時要立即拆）

### 子宮外孕 {#ectopic}

- 受精卵著床在子宮腔外，**輸卵管壺腹部**最常見（機轉與危險因子見 [[fertilization-embryology#implantation]]）
- 表現：**停經、下腹痛、陰道點狀出血**三徵；破裂 → 劇烈腹痛、**肩痛**（血液刺激橫膈）、低血壓休克、臍周瘀青
- 診斷：**hCG 會上升但比正常慢**（48 小時增加不到預期）；陰道超音波**子宮腔內看不到妊娠囊**
- 治療
   1. 未破裂、生命徵象穩定、hCG 不高 → **methotrexate** 肌肉注射，追蹤 hCG 到陰性
   2. 腹腔鏡輸卵管切開或切除
   3. 破裂、休克 → 緊急剖腹手術、輸血
- 護理：監測生命徵象與腹痛、休克處置、Rh 陰性給抗 D 免疫球蛋白、哀傷與日後懷孕的衛教

::questions{ids="107-2_OP_031"}

### 葡萄胎 {#molar-pregnancy}

- 胎盤絨毛**滋養層異常增生**成水泡狀
- 表現：**陰道出血**（常為深褐色、斷續）、**子宮大於週數**、**hCG 異常高**、**嚴重孕吐**、**20 週前出現子癇前症**、甲狀腺亢進；**超音波看不到胎兒**（完全性），呈「暴風雪」狀
- 治療：**真空吸引刮除**；追蹤 **hCG** 每週到正常，再每月追蹤 6–12 個月
- 追蹤期間要**確實避孕**（懷孕會讓 hCG 上升，無法判斷是否復發）；可能演變成**絨毛膜癌**（見 [[gynecologic-cancers#gtd]]）

::questions{ids="110-2_OP_030"}

## 第三孕期出血 {#late-bleeding}

| | **前置胎盤** | **胎盤早期剝離** |
|---|---|---|
| 定義 | 胎盤著床在**子宮下段**，部分或完全蓋住子宮頸內口 | 正常位置的胎盤在胎兒娩出**前**剝離 |
| **出血** | **無痛性**、**鮮紅色**、突然、可反覆；外出血量＝實際出血 | **伴隨腹痛**、**暗紅色**；可能**隱性內出血**，外出血少於實際 |
| 子宮 | **軟**、無壓痛 | **硬如木板**、壓痛、**高張性宮縮** |
| 胎兒 | 胎心音多正常；常合併**胎位不正**、先露部高浮 | 胎心音異常或消失 |
| 併發症 | 產後出血（子宮下段收縮差）、植入性胎盤 | **DIC**、休克、**庫弗萊爾氏子宮**（血液滲入子宮肌層 → 收縮差、產後出血）、腎衰竭 |
| 危險因子 | **多產、高齡**、**前次剖腹產**、**多次子宮刮除術**、**多胎**、抽菸、**前置胎盤病史**（再發率高） | **高血壓、子癇前症**、腹部外傷、古柯鹼、抽菸、早期破水、前次早期剝離 |
| 診斷 | **超音波**；第二孕期的低位胎盤多會隨子宮下段延長而「上移」，**約 32 週後**才確定 | 臨床表現為主；超音波不一定看得到 |

- **前置胎盤**的分類：完全性（蓋住整個內口）、部分性、邊緣性、低位胎盤
- **前置胎盤護理**
   1. **禁止陰道內診與肛診**、灌腸、性交（可能引起大出血）
   2. 監測**生命徵象、出血量**、子宮收縮與**胎心率**
   3. 臥床休息（依出血狀況，不是一律絕對臥床）、備血、建立靜脈管路
   4. 生產方式：**完全性與部分性**原則上**剖腹產**；**邊緣性或低位**在準備好剖腹產的情況下可嘗試陰道生產
   5. 檢查與治療前向個案與家屬說明
- **胎盤早期剝離護理**
   1. **左側臥**、給氧、建立大管徑靜脈管路、備血
   2. 監測生命徵象、**子宮張力**、腹圍、胎心率、尿量
   3. 依醫囑**凝血功能檢查**（纖維蛋白原、血小板、PT／aPTT），預防與及早發現 **DIC**
   4. 準備緊急生產；產後注意子宮收縮與出血
- 第一、二孕期出血（流產、子宮外孕、葡萄胎）見上方

## 妊娠高血壓疾病 {#hypertensive-disorders}

分類、用藥、硫酸鎂監測、aspirin 預防與飲食見 [[hypertension#pregnancy]]；這裡整理重度表現、子癇與 HELLP

- **重度子癇前症的表現**（任一）：收縮壓 **≥ 160** 或舒張壓 **≥ 110**；**血小板 < 10 萬**；肝指數上升到正常 2 倍、**右上腹或上腹痛**；**肌酸酐上升**（> 1.1 mg/dL 或加倍）；**肺水腫**；新發**嚴重頭痛**或**視力模糊**(ACOG 2020)
- 尿量減少（24 小時 < 500 mL 或每小時 < 30 mL）也是警訊；4 小時 400 mL 屬正常
- **子癇症前兆**：嚴重頭痛、**視力模糊**、**上腹痛**、**深部肌腱反射亢進**、噁心嘔吐 → 準備硫酸鎂、安靜環境、床欄保護
- **HELLP 症候群**

| 字母 | 意思 | 檢驗 |
|---|---|---|
| **H** | **溶血**(Hemolysis) | 周邊血液抹片破碎紅血球、LDH 上升、膽紅素上升 |
| **EL** | **肝指數上升**(Elevated Liver enzymes) | AST、ALT 上升；肝腫脹 → **右上腹痛** |
| **LP** | **血小板低**(Low Platelets) | **< 10 萬/mm³** |

   1. 是重度子癇前症的變化型，多在**第三孕期**或**產後**；少數沒有明顯高血壓
   2. 併發症：DIC、胎盤早期剝離、肝破裂、腎衰竭
   3. 處置：穩定母親後**儘快生產**；硫酸鎂、降壓、必要時輸血小板
- 子癇抽搐時的護理見 [[hypertension#pregnancy]]

## Rh 與 ABO 血型不合 {#rh}

- **Rh 血型不合**
   1. **母親 Rh 陰性、胎兒 Rh 陽性**：胎兒紅血球在**分娩**（或出血、流產、羊膜穿刺）時進入母體 → 母親產生抗 D 抗體(IgG)
   2. **第一胎通常不受影響**；下一胎抗體通過胎盤 → 胎兒溶血、貧血、**胎兒水腫**、新生兒黃疸
   3. 預防：給 Rh 陰性母親**抗 D 免疫球蛋白**(RhoGAM)
      1. 懷孕 **28 週**
      2. 產下 **Rh 陽性**嬰兒後 **72 小時內**
      3. 流產、子宮外孕、羊膜穿刺、絨毛取樣、產前出血、腹部外傷後
   4. 已經致敏（間接 Coombs 陽性）就不再給；追蹤抗體效價與胎兒貧血
- **ABO 血型不合**
   1. 多是**母親 O 型**、胎兒 A 或 B 型
   2. **第一胎就可能發生**，通常比 Rh 輕
   3. 主要表現是出生後**新生兒黃疸**（見 [[neonatal-disorders#hemolytic-disease]]）
- 台灣 Rh 陰性比例很低（約 0.3%）

## 早產高危險孕婦的自我照顧 {#preterm-risk}

- 早產徵兆：37 週前**規則宮縮**（每 10 分鐘 1 次以上）、下腹悶痛或經痛樣痛、**下背痛**、骨盆壓迫感、陰道分泌物增加或帶血、**破水**
- 自我照顧
   1. 每天**喝水 2,000–3,000 mL**（脫水會刺激宮縮）、**排空膀胱**
   2. 減少活動、避免提重物與性交；**不要刺激乳頭**（會釋放催產素）
   3. 學會自己摸宮縮、記錄；有徵兆立即就醫
   4. 避免含咖啡因飲料；治療泌尿道與陰道感染
- 安胎藥與早產的處置見 [[labor-complications#preterm-labor]]
