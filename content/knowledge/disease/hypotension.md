低血壓一般指**收縮壓 < 90 mmHg 或舒張壓 < 60 mmHg**。平時血壓偏低但沒有症狀的人不需要治療;有意義的是「血壓**下降**造成**器官灌流不足**」——頭暈、視力模糊、暈厥、跌倒,嚴重時是休克。國考最常考的是**姿勢性低血壓**、孕婦的**仰臥低血壓症候群**與**區域麻醉後低血壓**。

## 生理:血壓為什麼會掉 {#physiology}

血壓 = 心輸出量(心跳 × 心搏量)× 周邊血管阻力,任何一項下降都會讓血壓下降(見 [[blood-pressure-regulation#determinants]])。**平均動脈壓(MAP)< 65 mmHg** 時腦、腎、冠狀動脈灌流不足。

| 機轉 | 例子 |
|---|---|
| **血量不足**(前負荷↓) | 出血、脫水、嘔吐腹瀉、利尿過度、第三空間流失(腸阻塞、燒傷)、大量腹水一次抽太多 |
| **血管擴張**(阻力↓) | **熱療、泡溫泉、熱水澡**、飲酒、過敏性休克、敗血症、**區域麻醉**(交感阻斷)、鴉片類止痛劑(組織胺釋放)、降壓藥與硝酸鹽 |
| **心臟打不出去** | 心肌梗塞、心衰竭、心律不整(過快或過慢)、心包膜填塞 |
| **靜脈回流受阻** | 孕婦仰臥(子宮壓迫下腔靜脈)、張力性氣胸、正壓呼吸 |
| **反射失靈** | 自主神經病變(糖尿病、巴金森氏症)、老化、長期臥床 |
| **內分泌** | **腎上腺功能不足**(低血壓 + 低血鈉 + 高血鉀);長期類固醇驟停 |

:::warning[易錯]
年長者動脈硬化、長期使用類固醇(水鈉滯留)、原發性醛固酮症會使血壓**上升**,不是低血壓的原因。
:::

## 姿勢性低血壓 {#orthostatic}

### 定義與機轉 {#orthostatic-definition}

由臥(或坐)到站立後 **3 分鐘內**,**收縮壓下降 ≥ 20 mmHg** 或**舒張壓下降 ≥ 10 mmHg**(常伴心跳增加)。

站起來時約 500–1,000 mL 血液滯留在下肢與內臟 → 回心血量↓ → 心輸出量↓。正常人靠**壓力感受器反射**讓心跳加快、血管收縮在數秒內代償;代償不足就發生姿勢性低血壓。

### 高危險群 {#orthostatic-risk}

- **老年人**(壓力感受器敏感度下降)、**長期臥床**(剛下床)、脫水或失血。
- **產後**:分娩失血 + 腹腔壓力突然解除使內臟血管擴張 → 第一次下床易暈倒。
- **術後、麻醉後**、使用鴉片類止痛劑。
- **藥物**:[[alpha-blockers|α₁ 阻斷劑]](**首劑效應**)、[[nitrates|硝酸鹽]]、[[ace-inhibitors|ACEI]](首劑)、利尿劑、三環抗憂鬱劑、抗精神病藥、**levodopa**、鎮靜安眠藥。
- **自主神經病變**:糖尿病、巴金森氏症、脊髓損傷。
- 熱療:溫泉、熱水澡、**溫水坐浴**時間過長、全身用熱。

### 表現 {#orthostatic-symptoms}

起身後頭暈、眼前發黑、視力模糊、無力、噁心、臉色蒼白、冒冷汗、心跳加快,嚴重者**暈厥與跌倒**。

### 評估:姿勢性生命徵象 {#orthostatic-vitals}

1. 病人**平躺 5 分鐘**後量血壓與脈搏。
2. 協助**站起**(無法站可坐起),在 **1 分鐘與 3 分鐘**時各量一次(分別偵測典型與延遲型姿勢性低血壓)(來源:[2022 台灣高血壓治療指引](https://doi.org/10.6515/ACS.202205_38%283%29.20220321A),p.238)。
3. 比較:符合上述下降幅度即為陽性;若心跳增加 ≥ 30 次/分但血壓未降,需考慮體位性心搏過速症候群(POTS)或血量不足。
4. 過程中有頭暈、要暈倒就立即讓病人躺下。

### 處置與預防 {#orthostatic-management}

- **漸進式下床**:平躺 → **半坐臥** → **床緣坐、雙腳下垂**並做足背屈伸運動 → 無頭暈才**站立** → 有人陪同再行走;每個步驟停留約 1–2 分鐘。
- 第一次下床前(產後、術後)先評估**生命徵象**與出血量,最好有人陪伴。
- 發生頭暈:立即**坐下或躺下**,**頭部放低、抬高下肢**;在坐浴或泡澡時頭暈 → **停止坐浴**,協助身體前傾、頭低於心臟,不要讓病人直接站起走動。
- 熱療/泡溫泉:時間勿過長(溫泉每次 ≤ 15 分鐘;溫水坐浴 15–20 分鐘、40–43 °C),起身要慢。全身用熱比局部用熱更容易造成低血壓。
- 藥物:α₁ 阻斷劑**低劑量、睡前**開始;硝化甘油舌下含服時**坐下或躺下**;利尿劑早上服用;檢視並調整造成低血壓的藥物。高血壓病人方面,2025 AHA/ACC 指出隨機試驗中積極降壓反而**降低**姿勢性低血壓風險,無症狀的姿勢性低血壓不必因此放寬收縮壓 < 130 的目標,開始或加藥後評估有無**症狀**即可(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e179–e180)。
- 慢性病人:足夠水分(無心衰竭、腎衰竭限水時)、適度增加鹽分(無高血壓時;2025 AHA/ACC 也註明嚴重症狀性姿勢性低血壓者不宜限鈉(來源:[2025 AHA/ACC 高血壓指引](https://doi.org/10.1161/CIR.0000000000001356),p.e141));穿**彈性襪**或腹帶;睡覺時床頭抬高約 10°;起床前先在床上活動手腳;避免長時間站立、飽餐後立刻起身與大量飲酒。
- 藥物治療(簡述):midodrine(α₁ 促效劑,升壓)、fludrocortisone(礦物皮質素,增加血量);會造成**臥位高血壓**,睡前不服用。
- **跌倒**屬病人安全事件,除了記錄,還要依規定**通報**。

## 孕婦的低血壓 {#pregnancy}

### 仰臥低血壓症候群 {#supine-hypotensive-syndrome}

懷孕中後期(約 **20 週以後**)平躺時,增大的子宮**壓迫下腔靜脈**(與腹主動脈)→ 回心血量↓ → 心輸出量與血壓下降,子宮胎盤血流也減少。

- **表現**:平躺數分鐘後頭暈、臉色蒼白、冒冷汗、噁心、心悸、血壓下降;胎心率可能變慢。
- **處置**:**立即改為左側臥**(或以楔形枕把右臀墊高、手推子宮向左)——這是解決原因的第一步;給氧、蓋毯子都沒有解決壓迫問題。
- **衛教**:懷孕後期避免長時間平躺,睡覺以**左側臥**為佳;產檢、胎心監測、做超音波時注意姿勢。
- 孕婦心肺復甦時,同樣要**持續以手將子宮推向左側**(left lateral uterine displacement),解除主動脈與下腔靜脈壓迫、讓胸外按壓有效(來源:[2025 AHA CPR/ECC 指引摘要與流程圖](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines),孕婦心跳停止流程圖)。

### 區域麻醉後低血壓 {#neuraxial-anesthesia}

**硬膜外或脊髓麻醉**阻斷交感神經 → 下半身血管擴張 → **母體低血壓**,是最常見的併發症 → 胎盤灌流下降 → 胎心率**變異性減少**、晚期減速。

- **預防**:麻醉前建立靜脈輸液,依醫囑給予等張晶體液(0.9% 生理食鹽水或乳酸林格氏液,常見 500–1,000 mL)預先補充;麻醉前量基準血壓與胎心音;麻醉後**避免仰臥**,採左側臥或子宮左移;麻醉後前 30 分鐘每 5 分鐘量一次血壓。
- **發生時**:
  1. 左側臥/子宮左移
  2. 加快輸液
  3. 給氧
  4. 監測血壓與胎心率
  5. 依醫囑給升壓劑(**ephedrine**、phenylephrine)
- 易混淆:**naloxone** 是鴉片類造成呼吸抑制的解毒劑,不是治療麻醉後低血壓。
- 脊髓麻醉後平躺 6–8 小時是為了預防**脊髓性頭痛**,與低血壓處置不同。

## 其他臨床情境 {#other-situations}

| 情境 | 為什麼低血壓 | 重點 |
|---|---|---|
| **血液透析** | 短時間移除大量水分 | 透析中低血壓、抽筋、頭痛:平躺抬腿、減慢脫水、依醫囑給生理食鹽水;心臟功能差者較適合**腹膜透析**(持續、緩慢) |
| **腹水/胸水穿刺** | 一次抽太多 → 體液重新分布 | 腹水大量抽出後注意心跳加快、血壓下降(常需補白蛋白);胸腔穿刺一次不超過 1,000–1,500 mL |
| **急性輸血反應** | 溶血、過敏 | **立即停止輸血**,以生理食鹽水維持靜脈通路,再通知醫師與血庫、保留血袋 |
| **過敏性休克** | 第 I 型過敏,血管擴張與通透性增加 | 立即**肌肉注射 epinephrine**(大腿外側) |
| **鴉片類止痛劑** | 組織胺釋放、血管擴張 | 同時監測呼吸,呼吸抑制用 naloxone |
| **腎上腺危象** | 皮質醇與醛固酮不足 | 低血壓、低血鈉、高血鉀、低血糖;靜脈 hydrocortisone 與生理食鹽水 |
| **嗜鉻細胞瘤術後** | 兒茶酚胺突然消失 | 術後低血壓與低血糖,見 [[hypertension#secondary-causes]] |

## 與休克的分界 {#shock}

低血壓合併**組織灌流不足的徵象**(意識改變、皮膚濕冷蒼白、微血管回填 > 2 秒、**尿量 < 0.5 mL/kg/h**、乳酸上升)就是**休克**,需要緊急處置。休克的完整內容之後另開頁,這裡只列與低血壓處置相關的原則:

| 休克類型 | 例子 | 首要處置 |
|---|---|---|
| 低血容性 | 出血、脫水 | **晶體液**(生理食鹽水、乳酸林格氏液)以**大管徑周邊靜脈**快速輸注;出血者止血與輸血 |
| 心因性 | 大面積心肌梗塞 | 謹慎給液體,[[inotropes|強心/升壓劑]]、緊急再灌流(見 [[coronary-artery-disease]]) |
| 分布性 | 敗血性、過敏性、神經性 | 敗血症:1 小時內抽血液培養後給抗生素,低血壓或乳酸 ≥ 4 mmol/L 給晶體液 **30 mL/kg**(Surviving Sepsis 2021:前 3 小時內給完;1 小時組合照護:1 小時內開始),目標 **MAP ≥ 65 mmHg**,仍低則給 **norepinephrine** |
| 阻塞性 | 心包膜填塞、張力性氣胸、肺栓塞 | 解除阻塞(心包膜穿刺、胸管、溶栓) |

- **姿勢**:平躺並**被動抬高下肢**約 30–45°(增加回心血量);傳統的頭低腳高(Trendelenburg)會使腹腔臟器壓迫橫膈、影響呼吸,現行已不建議作為常規。
- **升壓藥機轉**:α₁ 促效(norepinephrine、phenylephrine)↑周邊阻力;β₁ 促效(dobutamine)↑心跳與收縮力;中劑量 dopamine 同時增加心輸出量,高劑量增加血管阻力。詳見 [[inotropes]]。
- 心跳停止後恢復自發循環(ROSC)的血壓目標:2025 AHA 要求避免低血壓,**MAP 至少維持 65 mmHg**,以輸液或升壓劑調整;2025 版流程圖**已不再列**舊版(2020)的「收縮壓 ≥ 90 mmHg」,也沒有指定哪一種升壓劑(來源:[2025 AHA CPR/ECC 指引摘要與流程圖](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines),心跳停止後照護流程圖)。國考舊題若考「收縮壓 ≥ 90」,是依 2020 版作答。

## 護理重點整理 {#nursing}

- **評估**:血壓、脈搏(快而弱是代償)、意識、皮膚溫度與顏色、微血管回填、尿量;姿勢性生命徵象;用藥史;跌倒風險。
- **安全**:漸進式改變姿勢、床欄與呼叫鈴、下床有人陪同、夜間照明、防滑鞋;利尿劑早上服。
- **衛教**:起身三步驟(躺 → 坐 → 站,各停一下)、出現頭暈立即坐下或躺下、泡澡時間不要太長、足量水分、避免大量飲酒與長時間站立。
- **紀錄與通報**:低血壓造成的跌倒屬病安事件,需通報。

:::exam[國考重點]
- **熱療**使血管擴張 → 血壓**下降**、脈搏**加快**、頭暈;不是血壓上升。
- **產後第一次下床**最優先:評估生命徵象、漸進式下床、有人陪同。
- 孕婦平躺頭暈、血壓下降 → **左側臥**。
- **硬膜外麻醉**最常見併發症是**母體低血壓**,造成胎心率變異性**減少**;預防是麻醉前輸液,處置是左側臥、加快輸液、給氧、升壓劑。
- 急性輸血反應 → **先停止輸血**、以生理食鹽水維持通路。
- **α₁ 阻斷劑首劑**、**舌下硝化甘油**、levodopa 會造成姿勢性低血壓。
:::
