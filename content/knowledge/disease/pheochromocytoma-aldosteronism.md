這兩種腎上腺腫瘤都是**續發性高血壓**的原因：**嗜鉻細胞瘤**來自髓質、分泌兒茶酚胺；**原發性醛固酮症**來自皮質絲球帶、分泌醛固酮。髓質與醛固酮的生理見 [[adrenal-glands#medulla]]、[[adrenal-glands#aldosterone]]，其他續發性高血壓見 [[hypertension#secondary-causes]]

## 重點摘要 {#summary}

- **嗜鉻細胞瘤**
   1. 腎上腺**髓質**嗜鉻細胞腫瘤，分泌過多**腎上腺素與正腎上腺素**；多數良性，部分與遺傳症候群（MEN2 等）有關
   2. **5P**：**陣發性高血壓**(Pressure)、**頭痛**等疼痛(Pain)、**心悸**(Palpitation)、**冒汗**(Perspiration)、**蒼白**(Pallor)；另有高血糖、焦慮、體重下降
   3. 誘發：情緒、壓力、運動、**按壓腹部**、姿勢改變、某些藥物
   4. 診斷：**24 小時尿液** metanephrine 與 **VMA**，或血漿游離 metanephrine
   5. 術前先 **α 阻斷劑**、補足水分與鹽分，**之後才加 β 阻斷劑**；術後注意**低血壓**、**低血糖**、尿量
   6. 護理：休息、避免壓力與**咖啡、茶**；**高熱量**、高蛋白、高維生素
- **原發性醛固酮症**（**康氏症候群**）
   1. 多為**醛固酮腺瘤**（絲球帶）或雙側增生
   2. **高血壓**＋**低血鉀**＋**代謝性鹼中毒**；鈉水滯留、血容積**增加**；**腎素被抑制**
   3. 低血鉀：**肌肉無力**、疲倦、麻痺、抽筋、**心律不整**、嚴重時**呼吸抑制**；腎濃縮能力下降 → **多尿、夜尿**、口渴
   4. 篩檢：**醛固酮／腎素比值**；2025 指引建議**所有高血壓**病人都篩檢
   5. 治療：單側腺瘤做**腹腔鏡腎上腺切除**；雙側用 **spironolactone** 等；**限鈉**、補鉀

### 國考常考點 {#exam-points}

- 嗜鉻細胞瘤 5P **不包括高血鉀**
- VMA 是驗 **24 小時尿液**（不是血液）；可用尿液 VMA 確立診斷的是**嗜鉻細胞瘤**
- 嗜鉻細胞瘤飲食**不是**低維生素、低蛋白、低熱量；要**避免咖啡、茶**；觀察頭痛、視力改變、胸痛、意識混亂（高血壓危象）
- 術後**低血壓**（不是高血壓，不需 α 阻斷劑）；**每小時尿量**應 ≥ **30 mL**；必要時靜脈皮質醇；輸液維持血容積
- 康氏症候群：**低血鉀**、**代謝性鹼中毒**、血容積**增加**（不是低血容積）、血鈉正常或偏高、**多尿夜尿**、心律不整、呼吸抑制；不會男性女乳症
- 原發性醛固酮症護理**錯誤**：鼓勵火腿、香腸、起司等**高鈉**食物
- 醛固酮分泌腺瘤 = **康氏症候群**；醛固酮過多造成低血鉀的是**孔恩氏症**(Conn)

## 嗜鉻細胞瘤 {#pheochromocytoma}

### 病理與表現 {#pheo-manifestations}

- 來自腎上腺**髓質**的嗜鉻細胞；在腎上腺以外的交感神經節者稱**副神經節瘤**
- 相當比例與遺傳有關：**MEN2**（合併甲狀腺髓質癌、副甲狀腺增生，見 [[thyroid-nodules-cancer#types]]）、von Hippel-Lindau 病、神經纖維瘤病
- 兒茶酚胺作用在 α 與 β 受體（見 [[autonomic-nervous-system]]）

| 表現 | 原因 |
|---|---|
| **陣發性或持續性高血壓**、高血壓危象 | α1 血管收縮 |
| **頭痛**、胸痛、腹痛 | 血壓急升、血管收縮 |
| **心悸**、心搏過速、心律不整 | β1 |
| **大量冒汗** | 交感興奮 |
| **臉色蒼白**、四肢冰冷 | 皮膚血管收縮 |
| **高血糖**、體重下降、怕熱 | 肝醣分解、代謝率上升 |
| 焦慮、顫抖、瀕死感 | 中樞興奮 |
| 姿位性低血壓 | 長期血管收縮使血容積減少 |

- 誘發因素：情緒激動、壓力、運動、**觸診或按壓腹部**、排便用力、麻醉、某些藥物（β 阻斷劑單獨使用、鴉片類、metoclopramide、三環抗憂鬱劑）

::questions{ids="107-1_MS_071,110-1_MS_069"}

### 診斷 {#pheo-diagnosis}

- 第一線：**血漿游離 metanephrine** 或 **24 小時尿液分段 metanephrine**(Endocrine Society 2014)
- **VMA**（香草杏仁酸）：兒茶酚胺的最終代謝產物，收集 **24 小時尿液**；國考題的標準答案
- 收集 24 小時尿液：第一次尿丟棄、之後全部收集到容器（常加酸性保存劑、冷藏）；依檢驗室規定避免干擾的食物與藥物（**咖啡、茶、香蕉、香草、巧克力**等是舊式 VMA 檢驗常列的限制）
- 定位：CT 或 MRI；必要時核醫掃描

::questions{ids="105-1_MS_030"}

### 治療與護理 {#pheo-treatment}

- **術前準備**（約 7–14 天，Endocrine Society 2014）
   1. 先給 **α 阻斷劑**（phenoxybenzamine、doxazosin 等）控制血壓
   2. **高鈉飲食**與**足夠水分**，恢復被收縮的血容積，減少術後低血壓
   3. α 阻斷充分後，心搏過速才加 **β 阻斷劑**；**不可先給 β**（α 作用無對抗 → 血壓更高），藥物見 [[alpha-blockers]]、[[beta-blockers]]
- **高血壓危象**：靜脈 **phentolamine**、nicardipine 等
- **手術**：多採腹腔鏡腎上腺切除；術中操作腫瘤時血壓可能劇烈波動
- **術後**
   1. **低血壓**：兒茶酚胺突然消失、血管擴張 → 依醫囑**大量輸液**，必要時升壓劑；**不用 α 阻斷劑**
   2. **低血糖**：胰島素不再被抑制，術後頭一兩天監測血糖
   3. 生命徵象與**每小時尿量**（**<30 mL/小時**為異常）
   4. 雙側切除或傷及皮質：觀察**腎上腺功能不足**，必要時靜脈皮質醇（見 [[adrenal-insufficiency#adrenal-crisis]]）
   5. 出血、腸蠕動恢復
   6. 遺傳性者需長期追蹤復發
- **術前與發作期護理**
   1. **臥床休息**、環境安靜、減少情緒壓力
   2. 監測血壓（含姿位性）、心跳、血糖；觀察**頭痛、視力改變、胸痛、意識混亂**等危象警訊
   3. **避免咖啡、茶**、可樂等刺激物；**不要按壓腹部**
   4. **高熱量、高蛋白、高維生素**飲食補充代謝消耗

## 原發性醛固酮症（康氏症候群） {#primary-aldosteronism}

### 病理與表現 {#pa-manifestations}

- 原因：**醛固酮腺瘤**（康氏症候群）、**雙側腎上腺增生**；少數家族性或癌
- 醛固酮作用在遠曲小管與集尿管：**保鈉**、**排鉀**、**排氫** → 鈉水滯留、**低血鉀**、**代謝性鹼中毒**；血容積增加反過來**抑制腎素**
- 「醛固酮逃脫」讓鈉不會無限滯留，所以**明顯水腫少見**、血鈉多半正常或略高

| 表現 | 原因 |
|---|---|
| **高血壓**（常為頑固性） | 鈉水滯留、血容積增加 |
| **肌肉無力**、疲倦、**抽筋**、麻痺、強直性痙攣、**呼吸抑制** | **低血鉀**；**鹼中毒**讓游離鈣下降 |
| **心律不整**、U 波 | 低血鉀 |
| **多尿**、**夜尿**、口渴 | 低血鉀讓腎小管對 ADH 反應變差 |
| 葡萄糖耐受不良 | 低血鉀抑制胰島素分泌 |

- 只有一部分病人有自發性低血鉀，所以**血鉀正常也不能排除**(2025 AHA/ACC)
- **續發性**醛固酮增多：腎素增加所引起，如心衰竭、肝硬化腹水、腎病症候群、腎動脈狹窄；腎素**高**，和原發性（腎素**低**）相反

::questions{ids="113-2_BM_029,106-1_BM_047,112-1_MS_069,114-3_MS_043,107-2_MS_073,106-1_MS_074,105-1_MS_071,110-2_MS_070"}

### 篩檢、治療與護理 {#pa-treatment}

- **篩檢**：血漿**醛固酮／腎素比值**(ARR)；2025 Endocrine Society 指引建議**所有高血壓病人**都篩檢（過去只篩頑固性高血壓或合併低血鉀者）；抽血前先**矯正低血鉀**
- 確認後做腎上腺 CT，必要時**腎上腺靜脈採樣**區分單側或雙側
- **單側**（腺瘤）：**腹腔鏡腎上腺切除術**，多數血鉀恢復、血壓改善
- **雙側**或不手術：**礦物皮質素受體拮抗劑**（**spironolactone**、eplerenone）為第一線；spironolactone 可能造成男性女乳症、月經異常與高血鉀（見 [[potassium-sparing-diuretics]]）
- **護理**
   1. **監測血壓**、心律、**血鉀**、肌力、呼吸
   2. 觀察**低血鉀**：肌肉無力、疲倦、麻痺、心律不整、**呼吸抑制**；**強直性痙攣**是代謝性鹼中毒使游離鈣下降
   3. **限鈉飲食**：避免**火腿、香腸、起司**、醃漬與加工食品
   4. **補鉀**：依醫囑口服鉀，攝取高鉀蔬果；低血鉀的處理見 [[potassium#low]]
   5. 記錄輸出入量（多尿）；腎上腺切除後照護見 [[cushing-syndrome#adrenalectomy]]
