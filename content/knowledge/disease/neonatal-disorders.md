本頁整理足月與晚期早產新生兒常見的疾病：**高膽紅素血症**、**低血糖**、**暫時性呼吸急促**、**胎便吸入症候群**與**產傷**。早產兒特有的問題(呼吸暫停、壞死性腸炎、視網膜病變等)見 [[preterm-infant]]；新生兒感染與敗血症見 [[perinatal-infections#neonatal-infections]]；新生兒呼吸窘迫症候群見 [[ards-respiratory-failure#neonatal-rds]]；正常的生理性黃疸見 [[newborn-adaptation#liver-jaundice]]。文中縮寫：AAP(American Academy of Pediatrics，美國兒科醫學會)、IDM(Infant of diabetic mother，糖尿病母親的新生兒)、TTN(Transient tachypnea of the newborn，新生兒暫時性呼吸急促)、MAS(Meconium aspiration syndrome，胎便吸入症候群)、PPHN(Persistent pulmonary hypertension of the newborn，新生兒持續性肺高壓)

## 重點摘要 {#summary}

- **病理性黃疸**：出生 **24 小時內**出現、上升太快、數值超過依週數與日齡的照光閾值、足月兒持續 > 2 週、**直接膽紅素升高**(灰白便、茶色尿)
- 溶血：**Rh 不合**(母 Rh⁻、子 Rh⁺，**第二胎以後**、較嚴重)；**ABO 不合**(母 **O 型**、子 A 或 B，**第一胎就可能**、通常較輕)
- **核黃疸**：未結合膽紅素通過血腦屏障 → 嗜睡、吸吮差、**角弓反張**、尖哭、抽搐；後遺症**聽力損傷**、發展遲緩、腦性麻痺
- **照光**：**眼罩**、**遮住生殖器**(尿布)、其他皮膚**儘量暴露**、**每 2 小時翻身**、光源距離約 **45–50 公分**(傳統燈)、**補充水分**、量體溫；副作用：**稀綠便**、**脫水**、**體溫不穩**、皮疹、古銅色嬰兒；**繼續哺乳**；抽血時**暫停照光**；家長探視時可**關燈、取下眼罩**互動
- **低血糖**高危險：**糖尿病母親的新生兒**、早產、SGA、LGA、冷壓力、窒息、敗血症 → 出生後 **30 分鐘到 1 小時內**測血糖、**儘早餵食**；處置後 **30–60 分鐘**複測
- **TTN**：**剖腹產**、肺液吸收慢，呼吸急促(可到 100 次/分以上)，**24–72 小時**內緩解
- **MAS**：**過期產兒**、子宮內缺氧排胎便；**小氣道阻塞**(活瓣效應)、化學性肺炎、**氣胸**、**PPHN**；出生後很快呼吸窘迫
- **鎖骨骨折**：巨嬰、肩難產；**患側手臂少動**、**擁抱反射不對稱**、局部腫痛與**骨摩擦音**；抱時托**背與臀**、不從腋下拉手臂

### 國考常考點 {#exam-points}

- 照光探視**正確**：**關燈、移除眼罩**讓媽媽和寶寶互動；**錯誤**：照光時塗嬰兒油按摩、「照光會解出黃色糊便」(多是**稀綠便**)、每 **4** 小時翻身
- 高膽紅素血症最適當：**儘早餵食**，促進膽紅素排泄；**錯誤**：每 4 小時翻身、光源 30–45 公分、出現黃疸**立即停餵母乳**
- 35 週早產兒傳統照光**錯誤**：光源與皮膚 **30–40 公分**(傳統燈約 **45–50 公分**)；體溫升高與脫水、**採血前暫停照光**、**眼罩與遮生殖器**都正確
- 照光時最重要的護理目標：**眼罩**與**足夠水分**；不是每小時採腳跟血、不是說沒有副作用
- 照光副作用**錯誤**：「**便秘**」(會腹瀉、稀便)；結膜炎(眼罩)、皮疹、體溫不穩都可能
- ABO 不合(母 O、子 B)**正確**：**有較高機會發生聽力損傷、發展遲緩**(核黃疸後遺症)；**錯誤**：ABO 比 Rh 嚴重、通常發生在第二胎以後、換血用 **B 型**(應用 **O 型紅血球**)
- 足月兒第 2 天膽紅素 12 mg/dL 深黃 → **生理性黃疸**；第 3 天 16 mg/dL → 照光，**眼罩與水分**最重要
- 糖尿病母親的新生兒照顧**錯誤**：「**出生後 4 小時**才測第一次血糖」(應 **30 分鐘到 1 小時內**)；評估盜汗、呼吸喘、嗜睡；血糖低於約 36–40 mg/dL 要處置；**儘早餵食**
- 37 週、體重減 10% 以上、血糖 33 mg/dL **錯誤**：「每 **6–8 小時**監測一次血糖」(處置後 30–60 分鐘複測，穩定後餐前監測)；立即餵食、餵不好給靜脈葡萄糖、目標 ≥ 45 mg/dL 都正確
- MAS **錯誤**：「**早產兒**較常發生」(應是**過期產兒、足月兒**)；黏稠胎便阻塞呼吸道、肺泡過度擴張甚至**氣胸**、出生後很快呼吸窘迫都正確
- MAS 會導致**缺氧與小氣道阻塞**(不是呼吸性鹼中毒、腸阻塞)
- 42 週、羊水有胎便：國考答「**胎頭娩出時用 DeLee 管抽吸鼻咽及口腔**」(舊做法；2015 年後 AHA／AAP 已不建議常規產時抽吸)
- 出生第 3 天左手臂活動受限、**擁抱反射不對稱**、兩肩不等高、局部腫痛 → **鎖骨骨折**
- 鎖骨骨折**錯誤**：「為其執行**圍巾徵象**評估」(會拉扯患側)；骨摩擦感、擁抱反射不對稱、抱起時**支持後背與臀部**、不從手臂抱都正確

## 高膽紅素血症 {#hyperbilirubinemia}

### 生理性與病理性黃疸 {#jaundice-types}

| | **生理性黃疸** | **病理性黃疸** |
|---|---|---|
| 出現時間 | 出生 **24 小時後**(足月兒多在第 2–3 天) | 出生 **24 小時內** |
| 高峰與數值 | 足月兒第 3–5 天，多數 < 12–15 mg/dL | **上升快**(每天 > 5 mg/dL)、超過依週數與小時數的照光閾值 |
| 持續 | 足月 1 週、早產 2 週內消退 | 足月 > **2 週**、早產 > 3 週 |
| 膽紅素種類 | **間接(未結合)** | 間接或**直接(結合)**升高(直接 > 1–2 mg/dL 異常) |
| 原因 | 紅血球多壽命短、肝酵素不成熟、腸肝循環 | **溶血**(Rh、ABO、蠶豆症)、**頭血腫**等血腫吸收、紅血球增多症、**感染**、甲狀腺低下、**膽道閉鎖**(直接型、灰白便)、餵食不足 |

- 黃疸的評估(由頭往腳、輕壓鼻尖)見 [[newborn-adaptation#liver-jaundice]]；用**經皮膽紅素儀**篩檢，高時抽血確認
- 母乳相關黃疸(**哺乳性**：吃不夠，增加哺餵；**母乳性**：晚發)見 [[breastfeeding#breastfeeding-jaundice]]；**出現黃疸不需要立即停餵母乳**
- AAP 2022：35 週以上新生兒依**週數、出生後小時數**與**神經毒性危險因子**(溶血、蠶豆症、敗血症、白蛋白低、週數 < 38 週等)查曲線決定是否照光；照光時**繼續哺乳**

### 溶血：Rh 與 ABO 不合 {#hemolytic-disease}

| | **Rh 不合** | **ABO 不合** |
|---|---|---|
| 血型組合 | 母 **Rh 陰性**、胎兒 **Rh 陽性** | 母 **O 型**、胎兒 **A 或 B 型** |
| 機轉 | 第一胎分娩時母親接觸胎兒血 → 產生 **IgG 抗 D 抗體** → 下一胎通過胎盤溶血 | 母親本來就有**抗 A、抗 B 的 IgG** |
| 胎次 | **第一胎通常沒事**，**第二胎以後** | **第一胎就可能**發生 |
| 嚴重度 | **較嚴重**：貧血、**胎兒水腫**、死胎 | **通常較輕** |
| 直接 Coombs 試驗 | 強陽性 | 弱陽性或陰性 |
| 預防 | 母親懷孕 **28 週**與產後 **72 小時內**打 **Rh 免疫球蛋白** | 無法預防 |

- 台灣 Rh 陰性少見(約 0.3%)，**ABO 不合**較常見
- 產前處置見 [[high-risk-pregnancy#rh]]；Rh 免疫球蛋白見 [[transfusion-reactions#rhig]]

### 核黃疸 {#kernicterus}

- **未結合(間接)膽紅素**是**脂溶性**，濃度太高、**白蛋白低**、**酸中毒**、早產、感染時，容易通過**血腦屏障**沉積在基底核
- 早期：**嗜睡、吸吮差**、張力低；中期：**尖聲哭**、**角弓反張**、發燒；晚期：**抽搐**、呼吸暫停
- 後遺症：**聽力損傷**、**發展遲緩**、手足徐動型**腦性麻痺**、牙齒琺瑯質發育不良
- 會和白蛋白競爭的藥物(例如 **sulfonamide**、ceftriaxone)新生兒避免使用

### 照光治療 {#phototherapy}

- 原理：藍綠光(波長約 460–490 nm)把皮膚中的未結合膽紅素轉成**水溶性**的異構物，經**膽汁與尿液**排出，不需要肝臟結合
- 護理

| 項目 | 做法 |
|---|---|
| 眼睛 | 戴**不透光眼罩**，保護視網膜；眼罩不要壓鼻孔；定時取下看眼睛有無分泌物(結膜炎) |
| 生殖器 | 用**尿布**或遮光物遮住(國考寫貼隔光紙) |
| 皮膚 | 其他皮膚**儘量暴露**(只穿尿布)；**不塗油、乳液**(會灼傷)；觀察皮疹 |
| 翻身 | **每 2 小時**翻身，讓各面都照到 |
| 距離 | 傳統照光燈與皮膚約 **45–50 公分**(依機型說明)；太近會過熱灼傷 |
| 體溫 | **每 2–4 小時**量，避免**過熱或過冷** |
| 水分 | **增加餵食次數**(母乳寶寶繼續親餵)、觀察尿量與體重(**不感性水分喪失**增加、**稀便**) |
| 大便 | **稀、綠色**、次數多 → 注意臀部皮膚 |
| 抽血 | 抽血時**暫停照光**(光會使檢體膽紅素下降)，檢體避光 |
| 監測 | 依醫囑測膽紅素(**不是每小時**採血)；停照光後可能**反彈** |
| 親子 | 餵奶與家長探視時可**關燈、取下眼罩**，讓親子眼對眼互動 |

- 副作用：**脫水**、**體溫不穩**、**稀便(腹瀉)**、**皮疹**、**古銅色嬰兒症候群**(直接膽紅素高時)、眼睛傷害(沒戴眼罩)、親子分離；**不會便秘**
- 光纖照光毯可在母親床邊或包在身上，較不影響親子接觸

::questions{ids="115-2_OP_034,113-2_OP_036,112-2_OP_055,106-1_OP_051,105-1_OP_055"}

### 換血 {#exchange-transfusion}

- 適應症：膽紅素超過換血閾值或出現**急性膽紅素腦病變**徵象、嚴重溶血與貧血
- 經**臍靜脈**，以約 **2 倍血量**的血分次抽出與輸入，移除膽紅素與抗體、矯正貧血
- 血品：**Rh 不合**用 **O 型 Rh 陰性**；**ABO 不合**用 **O 型紅血球**(配 AB 型血漿)，**不是**用新生兒自己的血型
- 護理：保暖、監測生命徵象與血糖、鈣(檸檬酸鹽造成低血鈣)、鉀，觀察感染、心律不整、NEC

## 新生兒低血糖 {#hypoglycemia}

- **高危險群**
   1. **糖尿病母親的新生兒**(IDM)：胎兒時期母親高血糖 → 胎兒**胰島素分泌多** → 出生後母親的糖斷了，胰島素還高 → **低血糖**(出生後 1–2 小時最明顯)；也常是 **LGA**、有產傷、RDS、低血鈣、紅血球增多症、黃疸
   2. **早產**、**SGA**(肝醣存量少)、**LGA**
   3. **冷壓力**、窒息、**敗血症**、呼吸窘迫(消耗多)
- **表現**(常不明顯)：**顫抖(jitteriness)**、**嗜睡**、**吸吮差**、**盜汗**、**呼吸急促或呼吸暫停**、發紺、張力低、哭聲弱或尖、低體溫、抽搐
- **篩檢**：高危險群**出生後 30 分鐘到 1 小時內**測第一次血糖(先餵食後再測)，之後依規定在**餵食前**監測(多為 12–24 小時)
- **處置切點**(AAP 2011，無症狀高危險群)

| 出生後 | 處置切點 | 目標 |
|---|---|---|
| 0–4 小時 | < 25 mg/dL → 餵食，1 小時後複測；複測仍 < 25 → 靜脈葡萄糖 | 餵食前 **≥ 40 mg/dL** |
| 4–24 小時 | < 35 mg/dL → 餵食，1 小時後複測；仍 < 35 → 靜脈葡萄糖 | 餵食前 **≥ 45 mg/dL** |
| 有症狀 | **< 40 mg/dL** → **靜脈葡萄糖** | |

- 國考與課本常寫 **< 40 mg/dL**(或 < 36 mg/dL)就要處置、目標 **≥ 45 mg/dL**
- **護理**
   1. **儘早餵食**(出生後 1 小時內、母乳或配方)，必要時**葡萄糖凝膠**塗口腔黏膜
   2. 餵不好或有症狀 → 依醫囑**靜脈注射葡萄糖**(10% 葡萄糖)，**不快速推高濃度**(反彈性高胰島素)
   3. 處置後 **30–60 分鐘複測**，穩定後每次餵食前監測；**不是每 6–8 小時**
   4. **保暖**(減少消耗)、觀察顫抖與抽搐
- 孕期糖尿病的處置見 [[high-risk-pregnancy#diabetes]]、[[diabetes]]

## 新生兒暫時性呼吸急促 {#ttn}

- 又稱濕肺症；**肺液吸收延遲**
- 危險因子：**剖腹產**(尤其**沒有經過產程**)、產程急、母親糖尿病、男嬰、晚期早產
- 表現：出生後數小時內**呼吸急促**(60–120 次/分)、輕微呻吟、鼻翼搧動、輕度發紺；X 光肺紋增加、葉間裂積液
- 病程：**24–72 小時**內自行緩解
- 處置：**給氧**(維持血氧)、保暖、監測；呼吸太快時暫停經口餵食，改管灌或靜脈；要和 RDS、肺炎、MAS 區分

## 胎便吸入症候群 {#meconium-aspiration}

- 原因：胎兒在子宮內**缺氧** → 迷走神經刺激、腸蠕動增加、肛門括約肌放鬆 → **排胎便到羊水**；喘息時吸入
- 好發：**過期產兒**、**足月兒**、SGA、胎盤功能不良、臍帶問題；**早產兒很少**(腸道不成熟)
- 病理：黏稠胎便造成**小氣道阻塞**(**活瓣效應**：氣進得去出不來 → 肺泡**過度擴張**、**氣胸**)、**化學性肺炎**、表面張力素失去作用 → **缺氧、高碳酸、酸中毒**，可合併 **PPHN**
- 表現：羊水**墨綠色**、新生兒皮膚指甲臍帶染綠；出生後**很快**出現呼吸窘迫、桶狀胸、發紺
- 處置
   1. **產時**：國考舊答案是「**胎頭娩出、肩膀娩出前用 DeLee 管抽吸口鼻**」；2015 年後 AHA／AAP 已**不建議常規產時抽吸**
   2. **出生後**：**活力好**(哭、肌張力好) → 一般照護；**活力不好** → 2025 AHA／AAP **不常規氣管內抽吸**，先做**初步步驟**、需要時**正壓通氣**，懷疑氣管被胎便阻塞才插管抽吸
   3. 給氧、呼吸器、表面張力素、抗生素；注意**氣胸**；PPHN 時一氧化氮吸入或 ECMO
- 復甦流程見 [[newborn-assessment#resuscitation]]；人工氣道抽吸見 [[artificial-airway]]

## 產傷 {#birth-injuries}

- 危險因子：**巨嬰**、**肩難產**、**臀位**、**器械生產**(真空吸引、產鉗)、急產、CPD

| 產傷 | 表現 | 護理 |
|---|---|---|
| **產瘤、頭血腫、帽狀腱膜下出血** | 見 [[newborn-assessment#head]] | 頭血腫注意**黃疸**；帽狀腱膜下出血注意**休克** |
| **鎖骨骨折**(最常見的產傷骨折) | **患側手臂活動少**、**擁抱反射不對稱**(患側不動)、兩肩不等高、局部**腫脹壓痛**、**骨摩擦音**；X 光確認 | 通常 **2–3 週**自行癒合(形成骨痂腫塊)；**抱時托住背與臀**，**不從腋下或手臂拉**；穿衣先穿患側、脫衣先脫健側；可把患側袖子固定在衣服上；**不做圍巾徵象**等拉扯患肢的檢查 |
| **臂神經叢損傷** | **爾勃氏麻痺**(Erb，C5–C6)：患側手臂**內收內旋、肘伸直、前臂旋前**(服務生討小費姿勢)，**擁抱反射消失**但**抓握反射存在**；Klumpke(C8–T1)：手部無力、爪狀手 | 擺位(避免拉扯)、**被動關節運動**(約 1 週後)、復健；多數數月內恢復 |
| **顏面神經麻痺**(多為產鉗) | 哭時**患側臉不動**、嘴歪向健側、**眼睛閉不上** | **人工淚液**保護眼睛、餵食時協助含乳；多數數週內恢復 |
| 長骨骨折(肱骨、股骨) | 患肢不動、擁抱反射不對稱 | 固定 |

- 鎖骨骨折與兒童骨折的其他內容見 [[fractures#clavicle-newborn]]
