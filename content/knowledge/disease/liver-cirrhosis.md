肝硬化是肝細胞長期受損後，纖維組織與再生結節取代正常肝小葉，造成**肝功能下降**與**門脈高壓**。本頁整理肝硬化的類型與表現、門脈高壓的側枝循環、腹水與腹腔放液、食道靜脈曲張出血、肝性腦病變、肝衰竭與脂肪肝；肝臟構造與功能見 [[liver-biliary-pancreas]]，肝炎病毒見 [[viral-hepatitis]]，肝癌見 [[liver-cancer]]，腹水形成的機轉見 [[edema-shock#cirrhosis-ascites]]，lactulose 與靜脈曲張用藥見 [[gi-drugs#liver-drugs]]

## 重點摘要 {#summary}

- **類型**：**壞死後**（B、C 型肝炎，全世界與台灣最常見，黃疸較嚴重）、**酒精性**（雷氏，小結節）、**膽源性**（膽汁滯留 → **全身搔癢**、**脂肪便**）、**心因性**（右心衰竭 → **肝腫大**）
- **肝功能不足**：黃疸、**低白蛋白**、**凝血酶原時間延長**、**血氨上升**；**動情素代謝不掉** → **蜘蛛痣、手掌紅斑、男性女乳、睪丸萎縮**
- **門脈高壓**：**肝硬化是最主要的肝內原因**；側枝三處 = **食道胃底靜脈曲張**、**海蛇頭**、**痔**；脾腫大 → 血小板與白血球減少
- **腹水**：門脈高壓＋低白蛋白＋醛固酮增加；護理：**低鈉**、依醫囑限水、**每天同一時間量體重與腹圍**、記輸出入量、**半坐臥**；放液後注意**心跳加快、低血壓**
- **食道靜脈曲張出血**：肝硬化**上消化道出血的主因**；**先止血**（血管收縮藥、內視鏡結紮），可輸新鮮冷凍血漿；**禁用鎮靜安眠藥**（誘發肝昏迷）；平時軟質飲食、避免過熱、用力咳嗽與提重物
- **肝性腦病變**：血氨上升引起；誘因 = **腸胃道出血、感染、便秘**、低血鉀與代謝性鹼中毒（利尿劑）、脫水、**鎮靜劑**；早期**嗜睡、日夜顛倒**，第二期**撲翼樣震顫**；**lactulose 酸化糞便**、預防便秘
- **蛋白質**：國考舊答案是肝昏迷**低蛋白**；現行課本與 ACG 2026 都**不限制蛋白質**（1.2–1.5 g/kg／天，加睡前點心）

### 國考常考點 {#exam-points}

- B、C 型肝炎造成的是**壞死後肝硬化**
- 「**酒精性**肝硬化會全身搔癢」是錯的，搔癢是**膽源性**；膽源性會脂肪便、壞死後會黃疸、心因性會肝腫大
- **手掌紅斑**原因是肝臟**荷爾蒙（動情素）代謝減少**，不是門脈高壓
- 肝硬化合併症：腹水、肝性腦病變、食道靜脈曲張；**高血壓不是**（門脈高壓不是全身高血壓）
- 肝衰竭會凝血病變、男子女乳、高血氨；**高白蛋白血症是錯的**
- 門脈高壓最主要的肝內原因是**肝硬化**；食道靜脈曲張機轉是**門靜脈**高壓（不是下腔靜脈），曲張的是**黏膜下層**靜脈
- 肝硬化飲食建議**低鈉**（不是低熱量、高脂肪）
- 腹水：**每天測體重與腹圍**、監測利尿劑成效、依醫囑限水；「床頭抬高 80 度」是錯的（採半坐臥）；居家「飲食不需任何限制」是錯的
- 抽出腹水 1,500 mL 後可能**心跳加快**（循環血量下降）
- 113-1 肝硬化合併意識混亂：ALT、AST 上升與**血氨 120** 符合；白蛋白 4.0 與 PT 5 秒不符合；護理答案是**限水與蛋白質**、**每天測體重腹圍並記輸出入量**（國考答案；現行不限蛋白）
- 食道靜脈曲張出血：**不可給鎮靜安眠藥**；首要是**止血**；可輸新鮮冷凍血漿；飲食避免過熱過冷與粗糙食物
- 肝性腦病變誘因：感染、**便秘**、腸胃道出血；**高血鉀不是**（低血鉀才是）
- 肝性腦病變初期是**嗜睡、人格改變**，**昏睡無法喚醒**是末期；深腱反射是**增強**（「消失」是錯的）；第四期 Babinski 陽性、肌肉僵直與抽搐
- 肝硬化男性是**睪丸萎縮**（不是腫脹）
- 預防肝性腦病變惡化要**預防便秘**；不用利尿劑排氨、不給鎮靜劑

## 類型與病因 {#types}

| 類型 | 原因 | 特徵 |
|---|---|---|
| **壞死後肝硬化** | **B、C 型肝炎**、藥物或化學物質中毒 | 全世界與台灣**最常見**；肝臟小、大小不一的結節；**黃疸較嚴重** |
| **酒精性（雷氏，Laennec）肝硬化** | 長期飲酒＋營養不良 | 先**脂肪肝** → 酒精性肝炎 → 肝硬化；**小結節**(< 1 cm)、Mallory 小體 |
| **膽源性肝硬化** | 原發性（自體免疫）或續發性（肝外膽道長期阻塞） | 膽汁滯留：**全身搔癢**、黃疸、茶色尿、灰白便、**脂肪便**與脂溶性維生素缺乏 |
| **心因性肝硬化** | 長期**右心衰竭**、縮窄性心包炎 | 肝臟鬱血 → **肝腫大**、輕度黃疸、腹水 |

- 其他原因：代謝功能障礙相關脂肪性肝病（MASLD，Metabolic dysfunction-associated steatotic liver disease，舊稱非酒精性脂肪肝）、威爾森氏症（銅堆積）、血色素沉積症
- 肝硬化會增加**肝細胞癌**風險，要每 3–6 個月追蹤腹部超音波與甲型胎兒蛋白（見 [[liver-cancer]]）

## 臨床表徵 {#manifestations}

| 機轉 | 表現 |
|---|---|
| 肝細胞功能不足 | 疲倦、食慾差、消瘦；**黃疸**；**低白蛋白** → 水腫與腹水；**凝血因子減少** → PT 延長、出血傾向；**血氨上升** → 肝性腦病變 |
| **動情素代謝減少** | **蜘蛛痣**（前胸、臉、手臂）、**手掌紅斑（肝掌）**、男性**女乳化、睪丸萎縮**、性慾減退；女性月經失調 |
| **門脈高壓** | **腹水**、**脾腫大**（脾功能亢進 → 血小板、白血球、紅血球減少）、**食道靜脈曲張**、**腹壁靜脈曲張（海蛇頭）**、**痔** |
| 其他 | **肝腎症候群**（腎臟本身正常卻衰竭）、自發性細菌性腹膜炎、肝肺症候群 |

- **肝衰竭**：凝血病變與出血、**低白蛋白**、高血氨與肝性腦病變、黃疸、男性女乳；BUN 製造減少使 BUN／肌酸酐比值下降（見 [[renal-function-tests]]）

## 門脈高壓與側枝循環 {#portal-hypertension}

![門脈高壓與側枝循環示意：肝硬化使門靜脈回肝受阻，血液改走食道胃底靜脈、臍旁靜脈與直腸靜脈三條側枝回到上、下腔靜脈，並造成脾臟腫大](/knowledge-images/portal-hypertension-collaterals.svg)

- 原因依位置分：肝前（門靜脈血栓）、**肝內（肝硬化最主要**，血吸蟲病也是）、肝後（右心衰竭、肝靜脈阻塞）
- 側枝循環：門脈血回不了肝，改走壓力較低的路回到上、下腔靜脈
   1. **食道與胃底靜脈曲張**：胃左（冠狀）靜脈 → 食道**黏膜下**靜脈 → 奇靜脈 → 上腔靜脈；破裂會大出血
   2. **海蛇頭**：臍旁靜脈 → 腹壁靜脈，以肚臍為中心放射狀
   3. **痔**：上直腸靜脈 → 中、下直腸靜脈 → 下腔靜脈（見 [[lower-gi-disorders#hemorrhoids]]）
- 側枝讓腸道吸收的氨與毒素繞過肝臟 → 肝性腦病變；分流手術或經頸靜脈肝內門脈系統分流術（TIPS，Transjugular intrahepatic portosystemic shunt）也會增加肝性腦病變

## 腹水與腹腔放液 {#ascites}

- 機轉：**門脈高壓**（微血管靜水壓上升）＋**低白蛋白**（膠體滲透壓下降）＋**醛固酮與抗利尿激素增加**（鈉水滯留）（詳見 [[edema-shock#cirrhosis-ascites]]）
- 評估：腹圍增加、**移動性濁音**、液波震盪、體重增加、呼吸困難；腹部超音波
- 處置
   1. **限鈉**：每天約 2 g 鈉(AASLD 2021)
   2. **利尿劑**：spironolactone 為主，合併 furosemide；注意低血鉀或高血鉀、低血鈉、腎功能與肝性腦病變
   3. 限水：只在**血鈉明顯偏低**時才限水（AASLD 2021 以 < 125 mmol/L 為參考）；國考題目「依醫囑給予適當水分限制」視為正確
   4. **腹腔放液術**：大量腹水造成呼吸困難或對利尿劑無效時；大量放液(> 5 L)後依醫囑補充**白蛋白**(AASLD 2021)
   5. 頑固性腹水：TIPS、腹腔靜脈分流
- 護理
   1. **每天同一時間、同一磅秤測體重**，**每天量腹圍**（同一位置做記號），記錄**輸出入量**
   2. 採**半坐臥**減輕橫膈壓迫、改善呼吸；水腫部位抬高、勤翻身保護皮膚
   3. 監測電解質、腎功能與意識
   4. 居家：**低鈉飲食**、不舉重物不過勞、**不可自行服藥**（避免 NSAID 與肝毒性藥）
- 腹腔放液護理（檢查前後細節見 [[gi-diagnostic-procedures#paracentesis]]）
   1. 放液前**排空膀胱**、量體重腹圍與生命徵象，採**坐姿或半坐臥**
   2. 無菌技術；**緩慢引流**，注意**心跳加快、血壓下降**、臉色蒼白、冒冷汗（放液 1,500 mL 後可能心跳加快，課本書頁 466）
   3. 穿刺處無菌紗布覆蓋，滲液時立即更換；觀察腹痛、發燒（腹膜炎）
- **自發性細菌性腹膜炎**：腹水感染，腹水中性球 > 250／mm³ 即可治療（課本書頁 465）；表現可很輕微，腹水病人發燒或意識變差要想到

## 食道靜脈曲張出血 {#varices}

- 肝硬化病人**上消化道出血最主要的原因**；表現吐鮮血或咖啡渣、黑便、休克；上消化道出血的一般處置見 [[upper-gi-disorders#upper-gi-bleeding]]

| 處置 | 重點 |
|---|---|
| 復甦 | 建立靜脈管路、輸血（限制性輸血）、**新鮮冷凍血漿**或血小板矯正凝血 |
| 藥物 | **血管收縮藥**：vasopressin（出血停止後**逐漸減量**）、terlipressin、**octreotide(Sandostatin)**；**預防性抗生素**(Baveno VII) |
| 內視鏡 | **食道靜脈瘤結紮（EVL，Endoscopic variceal ligation）**為首選；硬化劑注射（EIS，Endoscopic injection sclerotherapy） |
| 氣球填塞 | **三腔管(Sengstaken-Blakemore)**：胃球、食道球、胃抽吸；食道球依醫囑定時放鬆（課本多寫每 6–12 小時放鬆約 30 分鐘）、使用不超過 24 小時；三條管要**貼標籤**；床旁備剪刀；現行只當內視鏡前的**暫時過渡**(Baveno VII) |
| 分流 | TIPS 或手術分流，用於反覆出血 |
| 預防出血 | **非選擇性 β 阻斷劑**（propranolol、carvedilol）或定期結紮；**furosemide 不是**靜脈曲張用藥 |

- 護理
   1. 出血時**禁用鎮靜安眠藥**：肝臟代謝不了，會掩蓋或誘發**肝性腦病變**
   2. 監測生命徵象、意識、輸出入量；血液在腸道分解會增加血氨 → 依醫囑灌腸或 lactulose
   3. 平時：**軟質飲食**、細嚼慢嚥、避免**粗糙、過熱過冷**的食物，**避免用力咳嗽、解便用力與提重物**（增加腹壓），戒酒
   4. 血小板低時避免侵入性操作（例如抽痰取痰檢）

::questions{ids="106-2_makeup_MS_012,114-2_MS_009,109-1_MS_038,110-1_FA_056"}

## 肝性腦病變 {#hepatic-encephalopathy}

- 機轉：腸道細菌分解蛋白質產生**氨**，肝臟無法轉成尿素，加上側枝分流 → 血氨上升進入腦部
- **誘發因素**：**腸胃道出血**（血液是蛋白質）、**感染**、**便秘**、**低血鉀與代謝性鹼中毒**（利尿劑）、脫水與大量放腹水、**鎮靜安眠藥**、手術、過量蛋白質；**高血鉀不是**

| 分期 | 表現（課本書頁 475 整理） |
|---|---|
| 第一期 前驅期 | 人格與行為改變、欣快或易怒、**嗜睡**、**日夜顛倒**、注意力差、輕微手抖 |
| 第二期 逼近期 | 意識混亂、定向感喪失、**撲翼樣震顫**、肝臭 |
| 第三期 木僵期 | 昏睡但**可喚醒**、嚴重混亂、肌肉抽搐僵硬、**深腱反射增強**、腦波異常 |
| 第四期 昏迷期 | **昏迷**、對痛無反應、**Babinski 陽性**、肌肉僵直與抽搐、撲翼樣震顫消失 |

- 檢驗：**血氨上升**（不單靠血氨診斷）、肝功能異常
- 治療與護理
   1. **矯正誘因**：止血、治療感染、補鉀、避免鎮靜劑
   2. **Lactulose**：**酸化糞便**，讓氨變成銨離子留在腸道，並輕瀉排出；調到**每天 2–3 次軟便**；也可保留灌腸；效果不好加 **rifaximin**（抑制產氨細菌）（ACG 2026，二手；課本書頁 475）
   3. **預防便秘**，記錄排便次數；腹瀉過多會脫水與低血鉀，要記輸出入量
   4. 每天評估意識、定向感、**撲翼樣震顫**、寫字或畫圖、連續減 7；安全防護、床欄，必要時約束
   5. 飲食：國考舊答案是**低蛋白**；現行課本與 ACG 2026 **不限制蛋白質**，每天 1.2–1.5 g/kg、少量多餐加**睡前點心**，必要時支鏈胺基酸
- 肝昏迷的蛋白質（新舊說法）
   1. 國考：109-1_FA_042「肝昏迷適用低蛋白質飲食」為正確答案；113-1_MS_007「限制水分與蛋白質」為正確選項
   2. 現行：蛋白質限制會增加死亡率，大多數病人不限制（課本書頁 475；ACG 2026）

## 脂肪肝 {#fatty-liver}

- 肝臟是可逆性傷害時最常出現**脂肪變性**的器官（見 [[cell-injury-adaptation]]）
- 原因：**酗酒**最常見的單一原因；代謝相關（肥胖、糖尿病、高血脂）稱 MASLD；藥物（類固醇）、營養不良
- 可進展為脂肪性肝炎 → 肝硬化 → 肝癌；處置是**戒酒、減重、運動**、控制血糖與血脂
