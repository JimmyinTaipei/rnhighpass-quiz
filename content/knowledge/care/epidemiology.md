流行病學研究**族群**的健康狀態與疾病分布(誰、在哪裡、什麼時候)以及造成這些分布的因素，目的是找出原因、擬定與評價預防措施。社區衛生護理師用它判斷高危險群、選擇介入層次(三段五級)、判讀研究與篩檢結果。率的公式(發生率、盛行率、死亡率)在 [[vital-statistics]]；傳染病的流行名詞在 [[notifiable-diseases#epidemiology-terms]]

## 重點摘要 {#summary}

- **疾病自然史**：易感受期 → 臨床前期(症狀前期) → 臨床期 → 殘障期(或復原、死亡)；**篩檢最適合臨床前期**
- **三段五級**：初段＝①促進健康、②特殊保護；次段＝③早期診斷與適當治療；末段＝④限制殘障、⑤復健
- 致病模式：**三角模式適合傳染病**；網狀、輪狀、螺狀模式適合**多因子的慢性病**；螺狀模式多了**時間**
- 研究設計：**罕見疾病 → 病例對照**(回溯、省時省錢、算**勝算比 OR**，odds ratio)；**罕見暴露、要因果時序 → 世代研究**(前瞻、算發生率與**相對危險性 RR**，relative risk)；**最能證明因果 → 臨床試驗**(隨機分派)
- 因果判定**唯一必要條件是時序性**(因在果之前)
- 篩檢：**敏感度**＝有病者中篩出陽性；**特異性**＝沒病者中篩出陰性；**陽性預測值**＝陽性者中真的有病，**會隨盛行率升高而升高**

### 國考常考點 {#exam-points}

- 判斷三段五級的級數：通案衛教、均衡飲食、婚前健康諮詢 → **第一級**；疫苗、口罩、保險套、免費針具 → **第二級**；篩檢、早期發現 → **第三級**；持續服藥、個案管理防惡化 → **第四級**；復健、居家復能 → **第五級**
- 三角模式三要素是**宿主、病原、環境**(沒有「壓力」)；社交距離、清除孳生源 → 處理**環境**
- 輪狀模式：宿主(以**遺傳基因為軸心**)外圍包著**生物、社會、物理環境**
- 病例對照研究：研究開始時**已經有病例**；病例組選**新發病者**；**不能算發生率與 RR**，只能算勝算比
- 世代研究：可觀察**自然史**、可算**發生率與 RR**、能推論因果，但**成本高、耗時**，不適合罕見疾病與潛伏期很長的疾病
- 橫斷研究：同時測暴露與疾病，**無法確定時序**；適合**不隨時間改變**的因子(血型、基因)
- 家戶訪視調查長者盛行率會漏掉住機構的人 → **選樣偏差**
- 探討**遺傳**與疾病 → **雙胞胎研究**；探討**環境**與疾病 → 移民研究
- 敏感度與特異性是篩檢工具的**效度**，不是信度；信度高不代表效度高
- 計算題先畫 **2×2 表**，再看分母是「有病的人」(敏感度、偽陰性率)、「沒病的人」(特異性、偽陽性率)還是「陽性的人」(陽性預測值)

## 定義與目的 {#definition}

- 研究對象是**族群**，不是單一病人；內容包括健康狀態、疾病分布、決定因素(致病因子)，用來**控制健康問題**
- 方法依研究主題分三類：

| 類型 | 問的問題 | 做法 | 產出 |
|---|---|---|---|
| **描述流行病學** | 什麼病、誰、在哪裡、什麼時候(人、時、地) | 整理疾病的分布 | **提出**致病假說 |
| **分析流行病學** | 為什麼 | 比較有病與沒病、暴露與沒暴露的人(橫斷、病例對照、世代、生態) | **檢定**假說、找危險因子 |
| **實驗流行病學** | 介入有沒有效 | 研究者**主動操控**介入並設對照組(臨床試驗、社區試驗) | 證實因果、評價預防與治療措施 |

- 不只研究傳染病，也研究慢性病、事故傷害與健康行為
- 國考 108-1 題：流行病學是「研究族群健康狀態、疾病分布狀況及致病因子的學科」；分析流行病學探討的是暴露與疾病的**因果關係**，不是只找「生理性原因」

## 疾病自然史與三段五級 {#natural-history}

### 疾病自然史 {#stages}

| 時期 | 狀態 | 對應的預防 |
|---|---|---|
| **易感受期** | 還沒生病，但有危險因子(宿主易感、暴露於病原或環境) | 初段：促進健康、特殊保護 |
| **臨床前期**(症狀前期、次臨床期) | 體內**已有病理變化**，但**還沒有症狀** | 次段：**篩檢**、早期診斷與治療 |
| **臨床期** | 出現症狀與徵象，可以臨床診斷 | 次段的適當治療；末段的限制殘障 |
| **殘障期**(或復原) | 留下功能障礙；也可能痊癒 | 末段：限制殘障、復健 |
| 死亡期 | 死於原發疾病或其併發症(如癌症末期併發敗血症) | — |

- 篩檢就是在臨床前期把「看起來健康、其實已經有病」的人找出來，所以 112-1 題答**症狀前期**

### 三段五級 {#prevention-levels}

| 段 | 級 | 目的 | 社區例子(國考出現過) |
|---|---|---|---|
| **初段** | ①**促進健康** | 提升整體健康與抵抗力，不針對特定疾病 | 均衡飲食與睡眠衛教、健康飲食指導、**婚前健康諮詢**、傳染病防治的衛生教育、老人下肢肌力運動 |
| | ②**特殊保護** | 針對**特定**疾病或危害採取防護 | 疫苗(老人肺炎鏈球菌疫苗)、**PM2.5(細懸浮微粒，particulate matter ≤ 2.5 μm)高時戴口罩**、**免費注射器與保險套**(防 HIV、肝炎)、水質淨化、工廠防護器具、認識逃生路徑(防意外) |
| **次段** | ③**早期診斷、適當治療** | 在臨床前期發現並治療，阻斷病程 | 糞便潛血檢查、子宮頸抹片、**早期發現懷孕青少女**、疫情調查與早期發現病例 |
| **末段** | ④**限制殘障** | 已發病者不再惡化、預防併發症 | 鼓勵慢性病人持續服藥、個案管理、居家護理 |
| | ⑤**復健** | 恢復自主能力、減少依賴 | **居家復能服務**、職能與心理復健 |

- 傳染病人早期診斷治療，對病人是**次段**，對社區其他易感者則有**初段**的效果(課本 p.248)
- 教導**已有高血壓**的老人按時服藥：國考 106-2 補考把它歸次段(控制疾病)，嚴格說也可以算限制殘障；這題的答案是「逃生路徑屬次段」錯
- **用字陷阱**：題目寫「三段五級的**第三級**」是指五級的第 3 級(早期診斷)，不是「第三段(末段)預防」；108-2 青少女懷孕題答「早期發現懷孕青少女」
- 五級的完整內容與「定期體檢屬第一級」的課本說法見 [[nursing-concepts-health#five-levels]]；各疾病的三段五級見 [[hypertension#prevention]]、[[diabetes#prevention]]、[[cancer#prevention-levels]]

## 致病模式 {#causation-models}

多數疾病不是單一原因造成(**多重因果**)，下面四種模式用來說明因子之間的關係

| 模式 | 提出者 | 組成 | 適合解釋 |
|---|---|---|---|
| **三角模式** | Gordon | **宿主、病原、環境**三角平衡，任一角改變就失衡而發病 | **傳染病**(登革熱、流感)；不適合多因子慢性病 |
| **網狀模式** | MacMahon 等(1970) | 許多原因交織成的**因果網**(例：缺乏運動、高脂飲食 → 肥胖 → 高血壓、高血脂 → 冠狀動脈硬化) | **慢性病** |
| **輪狀模式** | Mausner | 中心是宿主，宿主的軸心是**遺傳基因**；外圈是**生物、社會、物理環境**，各部分比重依疾病不同 | 慢性病；強調**宿主與環境**的互動 |
| **螺狀模式** | 陳建仁(1999) | 以輪狀模式為基礎，加上**時間**向度：宿主易感性與環境暴露隨時間動態交互作用(分子 → 細胞 → 組織 → 器官 → 系統 → 個體) | 慢性病的長期發展 |

- 三角模式的介入：**病原**＝消毒、抗病毒藥；**宿主**＝疫苗、提升免疫力、戴口罩；**環境**＝社交距離、通風、清除孳生源(登革熱巡倒清刷)
- 114-2 題：輪狀模式「環境因子包含生物、物理、社會」正確；「強調時間」的是螺狀模式與疾病自然史；「強調宿主與病原互動」的是三角模式
- 宿主因子分類：**基因缺陷**屬個人**生物**因子；單親家庭、社會支持、貧窮屬**社會經濟**因子(106-1 題)

## 描述流行病學：人、時、地 {#descriptive}

| 面向 | 看什麼 | 例子 |
|---|---|---|
| **人** | 年齡、性別、種族(以及職業、社經地位) | 女性罹病率較高但死亡率較低(較早就醫，或遺傳、荷爾蒙、生活習慣不同) |
| **時** | ①**長期趨勢**：多年來的變化；②**週期變動**：季節性起伏；③**短期波動**：數小時到數天的聚集 | ①慢性病逐年上升；②蟲媒傳染病隨季節；③食物中毒、急性傳染病爆發(同一時段共同暴露) |
| **地** | 行政區或自然環境(氣候、土壤、水質、空氣) | 依自然環境比較較容易看出環境因素；行政區資料容易取得但較難提出假說 |

- 特殊設計：**雙胞胎研究**比較同卵與異卵雙胞胎，最適合探討**遺傳**的影響；**移民研究**比較移民與原居地、移入地居民，探討**環境與生活習慣**的影響(106-2 補考題)
- 描述流行病學的目的是**提出假說**，不能證明因果

## 分析流行病學 {#analytic}

### 四種觀察性研究 {#study-designs}

| 設計 | 起點與方向 | 優點 | 缺點 | 可算的指標 |
|---|---|---|---|---|
| **橫斷研究**(cross-sectional) | 同一時間點同時測暴露與疾病 | 快、便宜，可得**盛行率** | **無法確定時序**，難推因果；不適合罕見病 | 盛行率 |
| **病例對照研究**(case-control，回溯法) | 從**結果**出發：先選有病(病例組)與沒病(對照組)，**回溯**過去暴露 | **省時省錢、樣本少**；適合**罕見疾病**與**潛伏期長**的疾病；可同時看多種暴露 | **回憶偏差**(訪談偏差)；對照組選擇不易；**不能算發生率** | **勝算比(OR)**，用來估計 RR |
| **世代研究**(cohort，前瞻法) | 從**暴露**出發：追蹤暴露組與非暴露組，看誰發病 | 時序清楚，最適合推論**因果**；可觀察**疾病自然史**；可同時看多種結果；適合**罕見暴露** | **耗時、成本高、樣本大**；追蹤流失；不適合罕見疾病 | **發生率、相對危險性(RR)** |
| **生態研究**(ecological) | 以**族群**(國家、社區)為單位比較 | 用現成資料、快 | 不是個人資料，易有**生態謬誤** | 群體層級的相關 |

- 病例對照研究的病例組選**新發病者**：久病、復發或得病後行為改變的人，暴露資料容易被疾病本身影響(105-1 題)
- 對照組通常用**配對**(年齡、性別相近)，不是隨機抽樣(112-2 題)
- 世代研究與病例對照研究都屬**縱貫性**設計(橫跨一段時間)；但只有世代研究能算發生率(115-1 題)
- 探討**懷孕用藥與胎兒畸形**：已知可能有害，不能做臨床試驗(違反倫理)，用**世代研究**追蹤(113-1 題)
- **相對危險性(RR)**＝暴露組發生率 ÷ 非暴露組發生率；> 1 危險因子、＝ 1 無關、< 1 保護因子，見 [[vital-statistics#incidence-prevalence-examples]]
- 110-1 題的①「適合研究罕見致癌因子」：學理上世代研究確實適合**罕見暴露**，但考選部答案是 ②③(自然史、因果)，作答時選最核心的兩項

### 研究偏差 {#bias}

| 偏差 | 發生在 | 例子 |
|---|---|---|
| **選樣偏差**(selection bias) | 選研究對象時，樣本不能代表母群體 | 用**家戶訪視**調查社區 65 歲以上骨鬆盛行率，漏掉住機構與住院的長者 |
| **訊息偏差**(information bias) | 收集或測量資料時 | **回憶偏差**(病例組比較會努力回想暴露)、訪談者偏差、測量工具不準 |
| **干擾**(confounding) | 第三個因子同時和暴露與疾病有關，扭曲兩者的關係 | 喝咖啡與肺癌的關係被抽菸干擾 |

## 實驗流行病學 {#experimental}

| 設計 | 對象 | 特徵 | 優點 | 缺點 |
|---|---|---|---|---|
| **臨床試驗**(clinical trial) | **個人** | 研究者操控介入；**隨機分派**到實驗組與對照組 | 最能控制情境與干擾，**最能證明因果** | 情境人為、和真實生活不同；**倫理問題**；難以讓受試者完全照計畫做；成本高 |
| **社區試驗**(community trial) | **整個團體或社區** | 多用來評價**初段預防**；通常 > 6 個月(例：飲水加氟) | 能直接評估行為改變對發生率的影響 | 控制精密度較低；社區之間組成不同；人口流動高時效果打折 |

- 108-2 題：臨床試驗「隨機分派是必要條件」「適合探討因果」正確；以社區為對象的是社區試驗；回憶偏差是病例對照研究的缺點

::questions{ids="108-2_PC_061"}

## 因果關係的判定 {#causality}

| 條件 | 意思 |
|---|---|
| **相關的強度** | 暴露者發病的機會比沒暴露者高很多(例：抽菸者肺癌風險高) |
| **相關的一致性** | 不同團隊、方法、情境都得到相同結果 |
| **正確的時序性** | **因一定在果之前**(先暴露才發病)；**唯一的必要條件** |
| **劑量效應** | 暴露越多，風險越高 |
| **符合現存生物知識** | 能用已知的生物機轉解釋 |
| **相關的特定性** | 某因子只造成某病；但缺乏特定性**不代表**沒有因果(慢性病多因多果) |

- 時序性不成立，其他條件再強也不能說有因果；橫斷與回溯設計難以證明時序
- 106-1 題考選部答案把「具高的相對危險性」判為**錯誤**的判斷條件；課本與 Hill(1965)都把「相關的強度」列為條件之一，作答時記得：RR 高是**支持**因果的證據，不是必要條件

::questions{ids="107-2_PC_043,106-1_PC_044,105-2_PC_047"}

## 篩檢 {#screening}

篩檢是在看起來健康的人之中，**快速找出疑似有病的人**再轉介確診，屬次段預防；篩檢結果不是診斷

### 2×2 表與指標 {#screening-indices}

| | 確實有病 | 確實沒病 |
|---|---|---|
| **篩檢陽性** | a 真陽性 | b 偽陽性 |
| **篩檢陰性** | c 偽陰性 | d 真陰性 |

| 指標 | 公式 | 意思 |
|---|---|---|
| **敏感度**(真陽性率) | a ÷ (a＋c) | **有病的人**被篩出陽性的比例；抓病人的能力 |
| **特異性**(真陰性率) | d ÷ (b＋d) | **沒病的人**被篩出陰性的比例；排除健康者的能力 |
| 偽陰性率 | c ÷ (a＋c)＝1 − 敏感度 | 有病卻被判陰性 |
| 偽陽性率 | b ÷ (b＋d)＝1 − 特異性 | 沒病卻被判陽性 |
| **陽性預測值** | a ÷ (a＋b) | **篩檢陽性的人**中真的有病的比例 |
| 陰性預測值 | d ÷ (c＋d) | 篩檢陰性的人中真的沒病的比例 |

- **效度**(準不準)由敏感度與特異性決定；**信度**(一不一致)是重複測量的穩定性。信度是效度的**必要條件但不充分**：一直量錯也很一致
- 敏感度與特異性是**工具本身的特性**，不受盛行率影響；**預測值受盛行率影響**：盛行率越高，陽性預測值越高
- 敏感度與特異性通常此消彼長：把切點放寬，敏感度上升、特異性下降
- 好的篩檢工具要敏感度、特異性**都高**

### 計算例題 {#screening-examples}

| 題目 | 2×2 表 | 答案 |
|---|---|---|
| 糞便潛血 460 人：陽性 80 人中確診 30；陰性 380 人中 350 無病(110-2) | a 30、b 50、c 30、d 350 | 敏感度 30/60＝50%；**特異性 350/400＝87.5%**；偽陽性率 12.5%；偽陰性率 50% |
| 流感快篩 200 人：陽性 40 人中 36 有病；陰性 160 人中 132 無病(105-1) | a 36、b 4、c 28、d 132 | **敏感度 36/64**；特異性 132/136；36/40 是陽性預測值 |
| 慢性腎臟病篩檢：40 位病人 20 位陽性；160 位健康者 140 位陰性(111-1) | a 20、c 20、b 20、d 140 | **敏感度 50%**；特異性 87.5% |
| 子宮頸癌篩檢：2,500 位病人 500 陽性；3,200 位健康者 1,600 陽性(111-2) | a 500、c 2,000、b 1,600、d 1,600 | **陽性預測值 500/2,100≈23.81%**；敏感度 20%、特異性 50% |
| 兩廠牌快篩：敏感度 99% vs 90%(115-2) | — | 敏感度較高的廠牌**正確檢出的感染者較多**；不需要盛行率就能比較 |
| 大腸癌工具敏感度 80%、特異度 94%(112-1) | — | 「**未罹病者中 94% 篩檢陰性**」正確；「陽性者中 80% 確診」是把敏感度誤當陽性預測值 |

## 在社區衛生護理的應用 {#community-application}

- 用途：找出**高危險群**與危險因子、**疾病監測**(校園腸病毒、流感)、排定健康問題優先次序、設計並**評價**衛生計畫、提供衛生教育的依據
- 資料來源：戶口普查與人口登記、罹病資料(法定傳染病通報、癌症登記)、死亡資料、特殊調查；機關分工見 [[vital-statistics#data-sources]]
- 學校護理師用流行病學做校園評估：疾病監測、了解校園環境危險因子、提供衛教依據；**教學器材設備管理不是**流行病學的目的(111-2 題)

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 三角模式包括壓力 | 宿主、病原、環境 | 壓力是影響宿主的因子之一 |
| 三角模式最適合慢性病 | 最**不**適合慢性病 | 慢性病多因子，用網狀、輪狀、螺狀 |
| 輪狀模式強調時間 | 強調時間的是**螺狀模式** | 輪狀是宿主與三種環境 |
| 病例對照研究可算發生率 | 只能算**勝算比** | 病例數與對照數是研究者決定的 |
| 病例對照研究適合非罕見疾病 | 適合**罕見**疾病 | 直接找已發病的人，不用等 |
| 世代研究成本比病例對照低 | **較高** | 要長期追蹤大樣本 |
| 世代研究最適合罕見疾病 | 適合**罕見暴露** | 罕見病要追蹤非常多人才等得到病例 |
| 臨床試驗以社區為對象 | 以**個人**為對象 | 社區為對象是社區試驗 |
| 橫斷研究能確定因果時序 | **不能** | 暴露與疾病同時測量 |
| 敏感度又稱真陰性率 | 敏感度＝**真陽性率**；特異性＝真陰性率 | |
| 敏感度與特異度代表信度 | 代表**效度** | |
| 陽性預測值是病人中篩出陽性的比例 | 那是**敏感度**；陽性預測值是陽性者中真的有病 | 分母不同 |
| 提高敏感度也會提高特異度 | 通常**此消彼長** | |
| 信度高效度一定高 | 不一定 | 信度是效度的必要非充分條件 |
| 逃生路徑衛教屬次段預防 | **初段**(預防意外) | 還沒發生事故 |
