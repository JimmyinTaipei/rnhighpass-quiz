**神經系統評估**用來發現意識、瞳孔、肌力與反射的變化，及早察覺顱內壓升高與腦疝脫。病人狀況不穩定時要**定時重複評估、和前一次比較**，分數下降或瞳孔改變要立即通報。解剖與反射的基礎見 [[brain-anatomy]]、[[cranial-nerves#brainstem-reflexes]] 與 [[spinal-cord-spinal-nerves#reflexes]]；顱內壓升高見 [[increased-icp]]

## 重點摘要 {#summary}

- 評估順序：**意識(GCS)→ 瞳孔 → 生命徵象 → 運動與感覺 → 反射**；**意識改變是顱內壓升高最早、最敏感的徵象**
- **GCS**：睜眼(E)1–4、語言(V)1–5、運動(M)1–6，**總分 3–15**；記錄**最佳**反應；國考以 **7 分以下為昏迷**，**8 分以下**是重度腦傷、要保護呼吸道
- 插管無法說話時語言記 **E**(氣管內管)或 **T**(氣管切開)，眼睛腫到張不開記 **C**
- 瞳孔：大小、形狀、**對光反射**、兩側是否相等；**單側瞳孔放大、對光變慢**是天幕疝脫的警訊
- 肌力 0–5 分：**1 分只有肌肉收縮、2 分去除重力可動、3 分可抗重力**
- 病理反射：**Babinski**(腳趾背屈、扇開)與 **Hoffmann**(彈中指、拇指屈曲)代表**上運動神經元**病變
- 腦膜刺激徵象：**頸部僵硬、Kernig、Brudzinski**；小腦：**Romberg**、走直線、指鼻試驗
- 檢查：**EEG** 看電氣活動(癲癇)、**PET** 看代謝、**誘發電位**看感覺傳導路徑與腦幹；腦血管攝影後**患肢伸直臥床**、觀察足背脈搏

### 國考常考點 {#exam-points}

- GCS 三部分是**睜眼、語言、運動**(不是瞳孔)；疼痛刺激才睜眼是 **E2**；呻吟聲是 **V2**
- 叫喚才睜眼、人地對但時間錯、能遵照指示 → **E3V4M6**
- 運動反應記**最佳**反應，不是最差；插氣管內管語言記「**E**」，氣管切開記「**T**」，眼腫無法張開記「**C**」
- **E1V2M3**：疼痛刺激眼睛也不睜開；V2 是無法理解的聲音、M3 是異常屈曲(不是撥開疼痛處)
- GCS 從 E4V5M5 降到 E3V4M4 要**立即報告**
- 兒童 GCS：**7 分以下**定義為昏迷；評估嬰幼兒最好**有父母陪同**；最高 15 分
- 兒童 GCS：叫他才睜眼、會哭但可安撫、輕觸會收縮 → **E3V4M5 = 12 分**；痛才睜眼、躁動無法安撫、對痛收縮 → **E2V2M4 = 8 分**
- 「人、時、地」評估的是**定向感**(不是注意力)；問年輕時的事評估遠期記憶；**MMSE 滿分 30 分、與教育程度有關**，**不是**評估急性腦傷的意識
- **頭眼反射**：快速轉頭，眼球往**反方向**移動是正常；眼球**跟著頭同方向**轉代表腦幹受損；懷疑**頸椎損傷不可做**
- 腦幹功能評估：瞳孔對光、角膜、作嘔、頭眼反射；**肱二頭肌反射、腹部反射、肛門反射不是**
- **Hoffmann 反射**：彈病人中指遠端 → 拇指屈曲
- 小腦病變：Romberg 陽性、無法腳跟對腳尖走直線、無法單腳站；**Brudzinski 是腦膜刺激徵象**，與小腦無關
- 肌力 **1 分 = trace**(微弱，有收縮但關節不動)；**poor(2 分)適合協助性主動運動**
- **EEG 不能診斷腦腫瘤**；檢查前洗頭，檢查後黏膠可用丙酮清除
- **PET** 測**腦部代謝活動**(血流灌流是 SPECT)；不是侵入性檢查，也不是頭部外傷最常用的檢查(那是 CT)
- 評估大腦各葉與腦幹功能的檢查：**誘發電位**
- 腦血管攝影後**不需絕對臥床 24 小時**，也**不可**立即下床；鼓勵喝水、評估穿刺肢體循環、監測生命徵象
- 脊髓攝影(水性顯影劑)後**不是平躺**，要**床頭抬高 30–45 度**
- 腰椎穿刺：**側臥屈膝抱膝**(蝦米狀)，不是俯臥；L3–4 或 L4–5；術後**平躺**、多喝水；最常見併發症是**頭痛**；顱內壓升高時不宜做

## 意識 {#consciousness}

### 意識程度 {#levels}

| 程度 | 表現 |
|---|---|
| 清醒(alert) | 對環境有完整反應、定向感正常 |
| **嗜睡**(lethargy、somnolence) | 想睡，叫喚可醒，回答正確但較慢 |
| **混亂**(confusion) | 定向感錯亂(通常先錯時間，再錯地點，最後是人)、注意力差 |
| 遲鈍(obtundation) | 需要大聲叫或搖動才醒，醒後很快又睡 |
| **木僵**(stupor) | 只有強烈或疼痛刺激才有反應，無法正常對話 |
| **昏迷**(coma) | 疼痛刺激也叫不醒；淺昏迷仍有反射動作，深昏迷所有反應消失 |

- 意識由**腦幹網狀活化系統**與**大腦皮質**共同維持(見 [[brain-anatomy#consciousness]])
- **意識改變是顱內壓升高最早出現、也最敏感**的變化，比生命徵象改變更早
- 譫妄(急性、起伏、注意力差)見 [[delirium]]；失智見 [[dementia]]

### 格拉斯哥昏迷量表(GCS) {#gcs}

| 項目 | 分數 | 成人 |
|---|---|---|
| **睜眼(E)** | 4 | 自己睜眼 |
| | 3 | 叫喚才睜眼 |
| | 2 | **疼痛刺激才睜眼** |
| | 1 | 疼痛刺激也不睜眼 |
| **語言(V)** | 5 | 定向感正常、對答切題 |
| | 4 | **混亂**(會對話但定向感錯，例如時間答錯) |
| | 3 | 用詞不當(說出單字或片語，但不成對話) |
| | 2 | **無法理解的聲音**(呻吟) |
| | 1 | 沒有聲音 |
| **運動(M)** | 6 | **遵照指令**動作 |
| | 5 | **定位疼痛**(會撥開疼痛刺激) |
| | 4 | 疼痛時**縮回**(正常屈曲回縮) |
| | 3 | **異常屈曲**(去皮質姿勢) |
| | 2 | **伸直**(去大腦姿勢) |
| | 1 | 沒有動作 |

- **總分 3–15**；13–15 輕度、9–12 中度、**3–8 重度**腦傷；國考常以 **7 分以下為昏迷**
- **記錄最佳反應**：兩側不一樣時記好的一側(並另外記錄兩側差異)
- 疼痛刺激從**中樞**(按壓眼眶上緣、斜方肌)開始，判斷是否定位；用周邊刺激(壓指甲床)看肢體縮回
- **無法評估時的記號**
  1. 語言：**氣管內管記「E」**(endotracheal)、**氣管切開記「T」**；失語症記「A」
  2. 睜眼：臉部受傷**眼睛腫到張不開記「C」**(closed)
  3. 有記號的項目不計分，總分要註明，例如 E3VEM6
- 每次評估和前一次比較；**總分下降 2 分以上**、或運動分數下降，要立即通報
- 原始量表由 Teasdale 與 Jennett 於 1974 年發表(來源：[Teasdale & Jennett，Lancet 1974](https://doi.org/10.1016/S0140-6736(74)91639-0))

| 項目 | 分數 | 嬰幼兒(不會說話) |

### 心智狀態評估 {#mental-status}

| 項目 | 評估方法 |
|---|---|
| **定向感** | 問**人、時、地** |
| 注意力 | 100 連續減 7、倒著拼字 |
| 近期記憶 | 說三樣東西，幾分鐘後請他回想 |
| **遠期記憶** | 問年輕時求學、工作等基本資料 |
| 計算、判斷、抽象思考 | 算術、情境判斷、解釋成語 |

- **MMSE**：**滿分 30 分**，分數越高認知越好；**受教育程度影響**；用於**篩檢認知障礙**(失智)，**不是**評估急性腦傷的意識(那是 GCS)

## 瞳孔與腦幹 {#pupils}

- 評估：**大小**(mm，用瞳孔尺)、**形狀**、**對光反射**(直接與間接)、**兩側是否相等**
- 正常約 2–6 mm、圓、兩側相等、對光迅速收縮

| 表現 | 可能原因 |
|---|---|
| **單側瞳孔放大、對光變慢或固定** | **天幕疝脫**壓迫同側**動眼神經**(神經外科急症) |
| 雙側瞳孔放大固定 | 嚴重缺氧、腦死、阿托品類藥物 |
| **雙側針尖狀** | **橋腦**病變、**鴉片類**中毒、有機磷中毒 |
| 單側瞳孔小、眼瞼下垂、無汗 | 霍納氏症候群(交感神經受損) |
| 橢圓形 | 早期動眼神經受壓 |

- 腦幹反射(瞳孔對光、角膜、頭眼、冰水、作嘔、咳嗽)的做法見 [[cranial-nerves#brainstem-reflexes]]
- **頭眼反射**(洋娃娃眼)：撐開眼睛、快速左右轉頭；**正常是眼球往頭轉動的反方向動**(像娃娃眼)，腦幹受損時眼球跟著頭轉；**懷疑頸椎損傷禁做**，改用冰水試驗
- 昏迷病人對疼痛的姿勢(去皮質、去大腦)與呼吸型態的對應見 [[brain-anatomy#brainstem-lesions]]
- 腦部損傷常見的特殊呼吸型態是**陳施氏呼吸**與**畢歐氏呼吸**；庫斯毛耳氏呼吸是代謝性酸中毒，喟嘆式呼吸多與焦慮有關

## 運動、感覺與反射 {#motor-sensory}

### 肌力 {#muscle-strength}

| 分數 | Lovett 名稱 | 表現 | 適合的運動 |
|---|---|---|---|
| 5 | 正常(normal) | 可抗重力與**完全阻力** | 加阻力運動 |
| 4 | 佳(good) | 可抗重力與**部分阻力** | 加阻力運動 |
| 3 | 尚可(fair) | **可抗重力**、不能抗阻力(約 50%) | 主動運動 |
| 2 | 不佳(poor) | **去除重力**下可完成全關節活動 | **協助性主動運動** |
| 1 | 微弱(trace) | **肌肉有收縮，但關節不能動**(約 10%) | 被動運動 |
| 0 | 零(zero) | 完全沒有收縮 | 被動運動 |

- 兩側比較；**旋前肌偏移**(雙手平舉、手心朝上、閉眼，弱側會往下並旋前)可發現輕微偏癱

::questions{ids="109-2_FA_042,112-2_FA_048,108-2_FA_045"}

### 反射 {#reflexes}

- **深部肌腱反射**的節段與 0–4+ 分級見 [[spinal-cord-spinal-nerves#dtr]]；上運動神經元病變 → 反射**亢進**；下運動神經元病變 → 反射減弱或消失
- **病理反射**(上運動神經元病變)
  1. **Babinski 徵象**：用鈍物從腳跟沿腳底**外側**往前劃到拇趾下方，**拇趾背屈、其他腳趾扇形張開**為陽性；2 歲以下(開始走路前)出現是正常的
  2. **Hoffmann 反射**：握住病人中指，**彈壓中指遠端指甲** → **拇指與食指屈曲**為陽性，常見於頸髓病變
  3. 陣攣(clonus)：快速背屈腳踝後持續有節律的抽動
- 新生兒反射見 [[spinal-cord-spinal-nerves#newborn-reflexes]]

::questions{ids="109-2_MS_005"}

### 小腦與腦膜刺激徵象 {#cerebellum-meninges}

| 檢查 | 做法 | 陽性代表 |
|---|---|---|
| **Romberg 測驗** | 雙腳併攏站立，先張眼再**閉眼**，閉眼後搖晃或跌倒為陽性 | 本體感覺(脊髓後柱)或前庭異常；小腦病變睜眼也站不穩(國考把它列為小腦評估) |
| 腳跟對腳尖走直線(tandem gait) | 走一直線 | 小腦 |
| 指鼻試驗、跟膝脛試驗 | 摸鼻尖再摸檢查者手指 | 小腦(辨距不良) |
| 快速輪替動作 | 手心手背快速翻轉 | 小腦 |
| **頸部僵硬** | 仰臥被動彎曲頸部 | 腦膜刺激 |
| **Kernig 徵象** | 仰臥，髖與膝屈曲 90 度後**伸直膝蓋**，大腿後側痛、無法伸直 | 腦膜刺激 |
| **Brudzinski 徵象** | 仰臥，**彎曲頸部** → 髖與膝**自動屈曲** | 腦膜刺激 |

- 腦膜炎與蜘蛛膜下腔出血都會有腦膜刺激徵象(見 [[cns-infections]])
- 小腦的功能見 [[brain-anatomy#cerebellum]]

## 診斷檢查 {#diagnostics}

| 檢查 | 看什麼 | 護理重點 |
|---|---|---|
| **電腦斷層(CT)** | 結構；**急性出血**、骨折，**頭部外傷首選**(快) | 顯影劑：確認碘過敏與腎功能；躁動病人可能需要鎮靜 |
| **磁振造影(MRI)** | 結構，軟組織、腦幹與脊髓比 CT 清楚 | 移除金屬；**心律調節器等植入物要先確認**；時間較長、噪音大、幽閉恐懼 |
| **正子造影(PET)** | **腦部代謝活動**(注射放射性葡萄糖)：癲癇病灶、失智、腫瘤 | 檢查前禁食、控制血糖 |
| SPECT | **腦血流灌流** | |
