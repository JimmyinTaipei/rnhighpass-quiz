基本護理第一章是整本書的概念基礎：**什麼是健康**、病人在**疾病各階段**的反應、**預防的層級**、**護理的範圍與功能**、**護理理念的演變**與**倫理法律**。國考常把這些概念放進小情境，問「屬於哪一級預防」「是哪一種護理功能」「符合哪一種理念或理論」。倫理四原則與台灣護理倫理規範見 [[nursing-ethics-principles]]，護理工作模式見 [[nursing-care-models]]，護理人員法的業務與罰則見 [[nursing-personnel-act]]，Erikson 發展階段見 [[psychodynamic-theories#erikson]]

## 重點摘要 {#summary}

- **WHO**（World Health Organization，世界衛生組織）：健康是**生理、心理、社會**的完好狀態，**不只是沒有疾病或虛弱**
- 健康與疾病是**同一連續線**的兩端、**動態而相對**，沒有明確界線；多數人在中間；位置受生活事件、老化與內外環境影響
- 影響健康的四類因素：**人類生物性**、**環境**（物理、社會、政治）、**生活型態**、**健康照護組織**；社經地位不同，維護健康的能力也不同
- **Maslow**：生理 → 安全 → 愛與歸屬 → 自尊 → **自我實現（最高）**；**生理需要最優先**
- 疾病病程三期：**開始期**（建立信任、不強迫面對）、**接受期**（關心檢查結果、依賴，鼓勵參與計畫）、**恢復期**（增加自我照顧能力）
- **三段五級**：第一段＝①促進健康、②特殊保護；第二段＝③早期診斷適當治療；第三段＝④限制殘障、⑤復健
- 護理功能：**獨立性**（衛教、清潔、觀察）、**依賴性**（依醫囑給藥、導尿）、**協同性**（營養師開飲食、護理師追蹤）
- 護理理念四期(Bevis)：**苦行僧**（犧牲奉獻）→ **浪漫主義**（順從、醫師助手）→ **實用主義**（二戰、功能性護理）→ **具人文色彩的存在主義**（整體、自主、全責護理）
- 護理強調 **care** 而不是 cure；核心構面是**人、環境、健康、護理**

### 國考常考點 {#exam-points}

- WHO 定義只寫「生理、心理沒有疾病或虛弱」是錯的(113-3_FA_004)；健康與疾病**不是絕對、不是明確可測**，位置**受內外在環境影響**(106-2_FA_006)
- 影響健康：「不同社經狀態維持健康的能力都相同」錯(112-1_FA_004)
- 觀點：「人與生態環境和諧」是**生態學**觀點，說成**社會學**觀點是錯的；消費者觀點把健康看成可購買的商品(111-2_FA_001)
- Maslow：最高層是**自我實現**(111-1_FA_001)；**維持身體舒適**最優先(106-2_makeup_FA_037)；子宮切除後覺得「不像女人」→ **自尊**(105-1_FA_004)
- Erikson 提出**八個發展階段**(110-1_FA_003)
- 三段五級：社區**子宮頸抹片與胸部 X 光篩檢＝第二段第三級**(105-1_FA_006)；雇主提供**定期體檢＝第一段第一級**(110-2_FA_013)；易感受期去除危險因子＝**促進健康**(114-1_FA_001)
- 病程：開始期「應儘速讓病人接受疾病事實」錯(112-3_FA_003)；化療時**很關心血液檢查結果＝接受期**(110-2_FA_016)
- Suchman：**接觸醫療照顧期**希望多了解疾病徵兆與預後(115-2_FA_003)
- 護理功能：依醫囑導尿＝**醫療輔助行為、次專業性、非獨立性**(113-3_FA_002)；營養師給飲食計畫、護理師追蹤＝**協同（合作）性**（110-2_FA_018、107-2_FA_006）；身體評估＝**專業性**，依營養師建議追蹤飲食＝**協同性**(114-2_FA_002)；「用護理過程解決問題是相互依賴功能」錯(105-1_FA_005)
- 跟醫師巡房：**觀察病程發展與醫療計畫，確認病人需求**(110-1_FA_005)
- 討論並驗證合適的護理措施＝**研究者**角色(106-2_OP_002)
- 理念：不計報酬到大量傷患醫院支援以求精神昇華＝**苦行僧主義**(115-1_FA_003)
- 南丁格爾：**以自然法則提供合宜環境**以恢復健康(114-2_FA_003)；Roy 適應模式要協助王先生調適**心情欠佳**(112-1_FA_001)；**Orem**＝滿足自我照顧需求(106-1_FA_068)；**Henderson 不是**治療性人際關係（那是 Peplau）(107-2_FA_003)
- 倫理：注射化療時評估有無滲漏＝**不傷害原則**(108-2_FA_019)；ICN（International Council of Nurses，國際護理協會）護理師基本責任**不包括疾病診斷**(108-2_FA_020)
- 趨勢：「**產兒照護人口增加**」錯（少子化）(112-2_FA_001)；護理教育「走向師徒制、以教學內容為導向」錯(113-2_FA_001)

## 健康 {#health}

### 定義與學者觀點 {#health-definitions}

| 學者 | 對健康的看法 |
|---|---|
| **WHO** | **生理、心理、社會**的完好狀態，不只是沒有疾病或虛弱 |
| Dunn | 健康軸與環境軸構成象限；高度健康要功能良好、免疫力強、身心精神和諧 |
| Pender | **正向動態**的狀態，不只是沒有疾病 |
| **南丁格爾** | 生命能毫無阻礙地運用每一種能力；護理是**為病人準備最合宜的環境**，讓病人在最自然的情境下自然痊癒 |
| **Orem** | 能處理問題、**達到自我照顧** |
| Rogers | 人與環境不斷互動，配合就是健康 |
| Neuman | **正常防禦線**的動態平衡，透過三級預防減輕壓力源 |
| **Roy** | 整合與完整；**適應良好**就是健康 |

- 不同觀點（國考 111-2）：生理學觀點＝身體系統功能異常就是疾病；流行病學觀點＝宿主在環境中對病原的易感性；消費者觀點＝健康是可購買的商品；「人與生態環境和諧」屬生態學觀點
- 來源：實用基本護理學上冊 p.3–4、表 1-1

### 影響健康的因素 {#determinants}

1. **人類生物性**：遺傳、性別、種族、老化
2. **生活環境**：物理（空氣、水、噪音）、社會（教育、經濟、宗教）、政治（醫療資源分配）
3. **生活型態與行為**：休閒、飲食、睡眠與休息、價值觀
4. **健康照護組織**：健康保險制度、就醫便利性
- 社經地位不同，維持健康的能力也不同；健保制度與就醫可近性會影響民眾的健康選擇
- 來源：同書 p.3

::questions{ids="112-1_FA_004"}

### Maslow 需要層次 {#maslow}

| 層次（由低到高） | 內容 | 護理例 |
|---|---|---|
| **生理** | 空氣、食物、水、休息、排泄、免於疼痛 | **維持身體舒適**、會陰沖洗時保暖 |
| 安全 | 免於受傷與恐懼 | 介紹環境與常規、預防意外 |
| 愛與歸屬 | 愛、親密、歸屬 | 安排家屬探視、協助與家人溝通 |
| **自尊** | 自我概念、自我肯定 | 化療掉髮在意別人眼光、**子宮切除後覺得不像女人**、適當遮蓋減少暴露 |
| **自我實現** | 潛能發揮到極致，**最高層** | 協助完成心願 |

- 排護理問題的優先順序時也依此原則，見 [[nursing-process#priority]]

## 疾病 {#illness}

### 疾病病程三期 {#illness-stages}

| 期 | 病人反應 | 護理重點 |
|---|---|---|
| **開始期** | 開始不舒服、易受刺激哭泣；生氣、害怕、**否認**、退縮、罪惡感 | 滿足生理需求、**建立信任**；尊重、耐心；病人否認時**不強迫面對事實**，給時間 |
| **接受期** | 已確診、接受治療，注意力集中在疾病，**每次檢查完都問結果**；自我中心、依賴、退化 | 把病人當成治療小組一員，**鼓勵參與計畫** |
| **恢復期** | 逐漸回到平日生活 | 建立自信、**增加自我照顧能力**、建立支持網路 |

- 三期長短不一、可能重疊，順序固定但沒有時間限制
- 來源：同書 p.6、表 1-3

::questions{ids="112-3_FA_003,110-2_FA_016"}

### 判定疾病與疾病行為 {#illness-behavior}

1. Baumann 判定疾病的三種方式：有沒有症狀徵象、個人直覺、能否執行日常生活活動
2. **Suchman** 疾病行為五期

| 期 | 行為 |
|---|---|
| 感覺徵兆期 | 覺得身體不適，準備就醫 |
| 假設生病角色期 | **先尋求他人協助或自我治療** |
| **接觸醫療照顧期** | 轉向**專業醫療**；想多了解自己的徵兆與預後 |
| 依賴期 | 接受專業治療 |
| 復健期 | **放棄病人角色** |

- 來源：同書 p.7

::questions{ids="115-2_FA_003"}

## 預防 {#prevention}

### 健康與疾病連續線 {#continuum}

1. 健康是持續、**動態**的狀態，與疾病是**相對**的
2. 兩者沒有明顯分界，是**同一連續線的兩端**；**大多數人在中間**
3. 在線上的位置受**生活事件與老化**影響
- 來源：同書 p.7–8

::questions{ids="106-2_FA_006"}

### 三段五級 {#five-levels}

| 段 | 級 | 內容 |
|---|---|---|
| 第一段（初段） | **①促進健康** | **衛生教育**、營養、個性發展、合適的工作與休閒環境、婚姻座談、遺傳優生、**定期體檢** |
| | ②特殊保護 | **預防注射**、個人衛生、環境衛生、避免職業危害、預防意外、特殊營養、去除致癌物、避免過敏原 |
| 第二段（次段） | **③早期診斷、適當治療** | **篩檢**、特殊體檢（**子宮頸抹片、胸部 X 光**）、及早治療 |
| 第三段（末段） | ④限制殘障 | 適當治療阻止惡化與併發症、提供限制殘障與避免死亡的設備 |
| | ⑤復健 | 心理、生理、職能復健；復健醫院、就業、長期照顧 |

- 課本把這套學說歸於文斯樂(Winslow)；社區與精神科頁依 Leavell 與 Clark 的說法，內容相同，見 [[community-mental-health]]
- 「定期體檢」屬**第一級**（課本表 1-4），「針對特定疾病的篩檢」屬**第三級**；國考 110-2 雇主定期體檢答第一段第一級、105-1 社區抹片與胸部 X 光篩檢答第二段第三級
- 疾病自然史的**易感受期**（還沒發病）：去除危險因子＝**促進健康**；發病後才是早期診斷、限制殘障與復健
- 預防接種的層級見 [[immunization]]
- 來源：同書 p.8、表 1-4

::questions{ids="105-1_FA_006,110-2_FA_013,114-1_FA_001"}

### 壓力與調適 {#stress}

1. 壓力：身體對刺激的一連串生理、情緒、心理反應；壓力源可來自環境、物理、心理、情緒、社會
2. Selye：局部適應症候群（如發炎）與**全身適應症候群**(GAS, general adaptation syndrome)
   1. **警覺期**：交感興奮、正腎上腺素 → 心跳快、血壓與血糖上升、**瞳孔放大**、冒汗
   2. 抵抗期：恢復恆定，或轉成慢性壓力
   3. 耗竭期：能量耗盡，出現心律不整、高血壓、消化性潰瘍，甚至死亡
3. 壓力源越久越嚴重越容易致病；短時間多重小壓力也可能致病；主觀感受越強，致病性越高
4. 處置：規律運動、營養、休息、放鬆技巧、支持系統、自我肯定；「習慣化」（不隨便換病人物品）、避免同時多重改變、改變環境、排優先次序
- 來源：同書 p.9–10

## 護理的範圍與功能 {#nursing-scope}

### 業務範圍 {#scope}

- 護理人員法第 24 條：**健康問題的護理評估**、**預防保健的護理措施**、**護理指導及諮詢**、**醫療輔助行為**（應在醫師指示下行之）
- 依醫囑導尿屬於**醫療輔助行為**，不是護理指導及諮詢
- 來源：同書 p.11；護理人員法第 24 條

### 專業程度與護理功能 {#functions}

| 分類 | 種類 | 說明與例 |
|---|---|---|
| 專業程度 | **專業性** | 長期訓練、獨立思考判斷：**評估健康問題**、增進舒適 |
| | **次專業性** | 有專業知識、經一段訓練就能做：**量體溫、給藥、導尿**等技術 |
| | 非專業性 | 不需深思熟慮的簡單工作：擦澡 |
| 護理功能 | **獨立性** | 不需醫囑：身體清潔、**觀察症狀反應**、護理指導 |
| | **依賴性**（非獨立性） | 依**醫囑**：治療、給藥、協助手術、約束、導尿 |
| | **協同性**（合作性） | 與團隊共同決定或執行：**營養師給飲食計畫，護理師追蹤執行** |

- 判斷題：「身體評估」＝專業性；「依營養師建議追蹤飲食」＝協同性；「依醫囑導尿」＝醫療輔助、次專業性、非獨立性
- 運用護理過程解決病人的健康問題屬於護理的**獨立性**功能，不是「相互依賴」
- 跟醫師巡房的目的：**觀察病程發展與醫療計畫、確認病人需求**（ICN 規範中護理師與同僚的合作）
- 護理措施分類（在護理計畫裡用）見 [[nursing-process#interventions]]

## 護理理念與理論 {#philosophy}

### 護理理念四期(Bevis) {#philosophy-stages}

| 理念 | 時代 | 重點 |
|---|---|---|
| **苦行僧主義** | 約 1850–1920 | 自我否定、**犧牲奉獻**、「燃燒自己照亮別人」、不為自己謀利；南丁格爾時代仍強調犧牲 |
| **浪漫主義** | 1890 起 | 依賴、**聽命權威**、女性特質（順從服侍）、當醫師的好助手 |
| **實用主義** | 二次大戰 | 面對大量傷患與人力短缺，重視效率，發展**功能性護理、成組護理** |
| **具人文色彩的存在主義** | 現代主流 | 人是整體且獨特；**自主、尊重病人權益**；發展**全責護理**、居家護理 |

- 護理理念的四個基本概念：**人、環境、健康、護理**
- 例：不計報酬到大量傷患醫院支援、追求精神與靈性的昇華 → **苦行僧主義**

## 倫理與法律 {#ethics-law}

1. 倫理原則：**自主**（提供資訊讓病人自己決定、簽同意書）、**不傷害**（預防保護病人免於傷害）、**施益**（行善）、**公平**、誠實、保密
   1. 化療注射時評估注射部位有無紅腫滲漏 → **不傷害**
   2. 細節與情境判斷見 [[nursing-ethics-principles#four-principles]]
2. **ICN**：護理師基本職責是**預防疾病、促進健康、維持（恢復）健康、減輕痛苦**；**不包括疾病診斷**
   1. 對病人：首要責任是需要照顧的病人、尊重價值觀與信仰、保密、**不能拒絕照顧病人**（如愛滋病人）
   2. 對同僚：與團隊合作（跟醫師巡房以觀察病程、確認需求）
3. 法律問題：侵權（該急救不急救、未經同意抽血）、**護理過失**（應注意而未注意）、違法（擅自攜出管制藥品）、**偽造文書**（沒量卻抄舊值）；停業或歇業 **30 日內**報備，停業以一年為限
- 來源：同書 p.14–17、表 1-7

::questions{ids="108-2_FA_019,108-2_FA_020"}

## 護理專業與趨勢 {#profession}

1. 護理專業特性：重視人是**身、心、靈、社會**的整體；強調 **care 而非 cure**；核心構面是人、環境、健康、護理
2. **護理專業核心素養**（台灣護理教育評鑑委員會）：批判性思考、基礎生物醫學、一般臨床技能、溝通與合作、**關愛**、**倫理素養**、**克盡職責**、**終身學習**
3. 護理教育要因應政策與醫療型態調整、學新科技，同等重視**知識技術與倫理、社會正義**；不是走回師徒制或只以教學內容為導向
4. 台灣趨勢（國考 112-2 的正確選項）：**管理式照護**增加、發展**進階護理角色**、重視**實證與資訊化**；「產兒照護人口增加」是錯的
- 來源：同書 p.16–18；趨勢依國考 112-2_FA_001、113-2_FA_001

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 |
|---|---|
| WHO 健康＝生理心理沒有疾病 | 生理、心理、社會完好，不只是沒病 |
| 健康與疾病界線明確、可測量 | 連續線、動態、相對 |
| 社經地位不影響維護健康的能力 | 會影響 |
| Maslow 最高層是自尊 | 自我實現 |
| 開始期要病人儘快接受事實 | 不強迫，先建立信任 |
| 定期體檢是第二段 | 第一段第一級 |
| 篩檢是第一段 | 第二段第三級 |
| 依醫囑導尿是獨立性、專業性 | 非獨立性、次專業性 |
| 營養師訂計畫護理師追蹤是依賴性 | 協同性 |
| 用護理過程解決問題是相互依賴功能 | 獨立性功能 |
| 疾病診斷是 ICN 護理師的基本責任 | 不是 |
| Henderson＝治療性人際關係 | Peplau |
| 浪漫主義強調自主 | 浪漫主義強調順從；存在主義強調自主 |
