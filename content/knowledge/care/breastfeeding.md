母乳哺育的目標是讓母親**有信心、有效**地把乳汁移給嬰兒。本頁依「泌乳生理 → 母乳成分 → 母乳與配方奶 → 十措施與肌膚接觸 → 飢餓暗示 → 姿勢與含乳 → 吃夠了嗎 → 常見問題 → 退奶 → 禁忌與配方奶」排列。泌乳的荷爾蒙與產後生理見 [[postpartum-adaptation#lactation]]；乳腺炎見 [[perinatal-infections#mastitis]]；哺乳法規與母嬰親善醫院見 [[maternal-child-health#breastfeeding]]；哺乳期避孕見 [[family-planning#postpartum]]。文中縮寫：WHO（World Health Organization，世界衛生組織）、UNICEF（United Nations Children's Fund，聯合國兒童基金會）、ABM（Academy of Breastfeeding Medicine，母乳哺育醫學會）、IgA（Immunoglobulin A，免疫球蛋白 A）、LAM（Lactational amenorrhea method，泌乳無月經法）

## 重點摘要 {#summary}

- 泌乳素（前葉）**製造**乳汁、**夜間分泌多**；催產素（後葉）**射乳**；乳量依**供需原則**，**移出越多，分泌越多**
- **初乳**：黃、稠、量少；**蛋白質、礦物質、IgA 高**，**脂肪與醣類低**；**輕瀉**作用幫助胎便排出、減少黃疸
- **前奶**清淡、水分與乳糖多；**後奶**白而濃、**脂肪多、熱量高**；一側吃到自己鬆開再換邊
- 母乳比配方奶：**乳清蛋白比例高**（約 60 : 40）、乳糖與不飽和脂肪酸高；**鈣、鐵濃度較低但吸收率高**
- **依需求哺餵**，看**早期飢餓暗示**（轉頭尋乳、吸手、伸舌）就餵，不等大哭；6 個月內純母乳**不需要喝水**
- 正確含乳：嘴**張大**、**下唇外翻**、含住**大部分乳暈**（上方露出較多）、兩頰**飽滿**、**只聽到吞嚥聲**；**嘖嘖聲、兩頰凹陷**是含乳不正確
- 生理性脹奶（產後 3–5 天）：**增加哺乳次數**、餵前刺激射乳反射並擠出一點讓乳暈變軟；**不限水**、不定時餵
- 擔心奶水不足：先**評估嬰兒尿布（尿、便）與體重**、觀察一次完整哺餵，不急著補配方奶；生理性體重減輕 **< 10%**，**10–14 天**回到出生體重

### 國考常考點 {#exam-points}

- 泌乳機轉：**乳汁移出與吸吮次數**影響泌乳量；吸吮刺激**後葉**分泌催產素；**催產素**（不是泌乳素）作用於肌上皮細胞；泌乳素**夜間分泌多**
- 胎盤娩出後使乳房開始泌乳的是**泌乳素**
- 初乳**不適當**的敘述：「**脂肪和醣類含量較高**」（其實較低）；初乳蛋白質與礦物質較高、水分較低、含益菌生
- 產婦說初乳黃黏要擠掉：初乳能**促進胎便排出、減少膽紅素再吸收、減少黃疸**；初乳的抗體主要是 **IgA**，不是 IgM
- 產後第一天說「沒有奶水」：回應「**現在乳房分泌初乳，正是寶寶需要的**」
- **後奶**較白、**脂肪多、熱量高**；前奶清淡、**不是**富含酪蛋白
- 母乳與配方奶比較**錯誤**：「母乳的**鈣鐵濃度較高**」（其實較低，但吸收率高）；比例上母乳**乳清蛋白**較牛奶多
- 母乳營養素作用**錯誤**：「**酪蛋白**加強脂溶性維生素吸收」；正確：寡糖防病菌黏附、長鏈不飽和脂肪酸助視網膜發育、乳鐵蛋白和鐵結合使細菌無法利用
- 純母乳寶寶喝完就解稀糊便：母乳**水分多**、新生兒**胃結腸反射**明顯 → 正常，不是過敏
- **6 個月內**純母乳寶寶**不需要餵開水**（增加腎臟負荷、減少吸吮）
- 飢餓暗示：轉頭、**伸舌**、手伸向嘴、扭動身體、臉轉向照顧者；「**臉部放鬆**」不是飢餓暗示；不要固定每 2–3 小時，也不要等大哭
- 正確含乳：以**乳頭輕觸嬰兒嘴唇**引發張口；**上乳暈露出比下乳暈多**；**不要下壓乳暈**；**嘖嘖聲**表示含乳不正確；吸吮與吞嚥**不是全程 1 : 1**（開始時快而淺，奶水流出後才慢而深約 1 : 1）
- 不需要「每次兩側都要餵」；嬰兒快吸幾下又放開可能是在啟動射乳反射；奶水過多也可能讓嬰兒拒吸；吃奶時間與頻率**會變化**
- 乳頭扁平：嬰兒吸的是**乳房**不是乳頭 → 先**評估乳頭伸展性**
- 產後第三天乳房變硬、熱、不痛 → **增加哺乳次數**；嚴重脹奶想打退奶針 → **刺激噴乳反射，協助擠出乳汁**；「熱敷按摩直到乳房柔軟」「定時餵」「穿緊胸罩限水退奶」都不適當
- 預防脹奶最適宜：**依嬰兒需求哺餵**；第一週**減少喝水不能預防**脹奶；產後即刻肌膚接觸、依飢餓訊號哺乳都有幫助
- 乳房觸痛、發熱、變硬有硬塊（乳腺管阻塞）：讓寶寶**多吸**，吸不好就**每 2–3 小時擠奶**；不減少水分、不用乳頭罩
- 奶水不足的原因**不包括**「未限制哺餵時間及次數」；含乳不正確、母親沒自信、疼痛（抑制催產素反射）都會
- 新生兒出生 3,800 公克，產後第 2 天 3,500 公克（減 7.9%）、有尿與墨綠色便 → **不需要補配方奶**，先觀察完整哺餵、確保有效吸吮、24 小時親子同室、跟著寶寶作息休息
- 出生 2 週體重 3,700 公克（還沒回到出生體重）→ 同理感受並**今天儘快到醫院評估**哺乳與新生兒
- 剖腹產初產婦擔心沒脹奶：**評估尿便**、了解含乳與手擠奶情形；「**產程過長及剖腹產會延後脹奶，這是正常的**」被判為**不適當**的回應（沒有先評估就帶過）
- 寶寶好像吃不飽：新生兒胃小、睡得多，**少量多次**哺餵符合需求；不說「乳房太小」「別擔心」
- 早發性母乳黃疸（第 3 天）：**繼續哺餵**，而且要**更頻繁**
- WHO 十措施的肌膚接觸：**至少 1 小時**、監測膚色或血氧、出現尋乳徵象時嘗試第一次餵奶；**剖腹產也應進行**
- 漸進性離乳**錯誤**做法：**熱敷乳房**（應冷敷）；想離奶時**不要排空乳房**（只擠出一點減輕不適）
- 母乳哺育的**禁忌不包括**生理性黃疸

## 泌乳生理 {#lactation-physiology}

| 階段 | 時間 | 重點 |
|---|---|---|
| 泌乳第一期(lactogenesis I) | 懷孕中期起 | 乳腺開始製造**初乳**；高濃度黃體素抑制大量泌乳 |
| 泌乳第二期(lactogenesis II) | 胎盤娩出後，產後 **2–4 天**「奶來了」 | 黃體素急降 → 泌乳素作用 → 乳量增加，常伴**生理性脹奶** |
| 泌乳第三期(galactopoiesis) | 之後 | 乳量由**乳汁移出的頻率與量**決定（**供需原則**） |

- 兩個反射
   1. **泌乳反射**：吸吮 → 下視丘 → **腦下垂體前葉**分泌**泌乳素** → 腺泡**製造**乳汁；**夜間**分泌多 → 夜間哺乳有助奶量
   2. **射乳反射**(let-down)：吸吮或看到、想到、聽到嬰兒 → **腦下垂體後葉**分泌**催產素** → 腺泡周圍**肌上皮細胞收縮** → 乳汁射出；**焦慮、疼痛、沒信心**會抑制
- 射乳反射的表現：乳房刺痛或脹熱、另一側滴奶、子宮收縮痛、嬰兒吸吮由快變慢並開始吞嚥
- 乳頭勃起反射：碰觸乳頭使乳頭直立，有利含乳；扁平或凹陷乳頭較不明顯
- 剖腹產、產程延長、產後出血、肥胖、糖尿病、早產等可能使「奶來」延遲，但**仍要儘早、頻繁哺餵**並評估嬰兒攝取

## 母乳成分 {#composition}

### 初乳、過渡乳與成熟乳 {#milk-stages}

| | **初乳**(colostrum) | 過渡乳 | **成熟乳** |
|---|---|---|---|
| 時間 | 懷孕中期到產後約 2–5 天 | 產後約 5 天到 2 週 | 產後約 2 週以後 |
| 外觀 | **黃色、黏稠**、量少 | 由黃轉白 | 白色、較稀 |
| 成分特點 | **蛋白質、礦物質、脂溶性維生素（A、E、K）、IgA、白血球高**；**脂肪、乳糖較低**；**水分較少** | 脂肪、乳糖逐漸增加 | 脂肪、乳糖、熱量較高 |
| 作用 | 保護腸道（**分泌型 IgA**）、**輕瀉作用**幫助**胎便排出** → 減少膽紅素腸肝循環、**降低黃疸**；含益菌生（寡糖）促進好菌；量少正好配合新生兒小胃容量 | | 提供生長所需 |

### 前奶與後奶 {#foremilk-hindmilk}

| | **前奶**(foremilk) | **後奶**(hindmilk) |
|---|---|---|
| 時間 | 每次哺乳**開始**時 | 每次哺乳**後段** |
| 外觀 | 較稀、偏青白 | **較白、濃稠** |
| 成分 | **水分、乳糖、蛋白質**較多，解渴 | **脂肪多、熱量高**，提供飽足與體重增加 |

- 讓嬰兒吃完一側到**自己鬆開**（吃到後奶），需要再換另一側；下次從上次後餵或沒餵的那側開始，**不必每次兩側平均**

### 營養素的作用 {#nutrients}

| 成分 | 作用 |
|---|---|
| **乳清蛋白**(whey) | 母乳以乳清蛋白為主（乳清：酪蛋白約 **60 : 40**，牛奶約 20 : 80）；凝塊**細軟易消化** |
| 酪蛋白(casein) | 母乳中較少；形成軟凝乳、幫助鈣磷吸收 |
| **乳鐵蛋白**(lactoferrin) | 和鐵結合，使**腸道致病菌無法利用鐵**（抑菌） |
| **寡糖**（益菌生） | 促進雙歧桿菌生長，**阻止致病菌黏附**腸壁 |
| 分泌型 IgA、溶菌酶、白血球 | 被動免疫，減少腸胃道與呼吸道感染 |
| 乳糖 | 母乳較高，提供能量、幫助鈣吸收、促進腦部發育 |
| 長鏈多元不飽和脂肪酸（DHA、ARA） | 幫助**腦與視網膜**發育 |
| 脂肪酶 | 幫助脂肪消化與脂溶性維生素吸收 |
| 鈣、鐵 | **濃度比配方奶低**，但**吸收率高** |
| 維生素 D、K | 母乳含量低 → 新生兒出生時打維生素 K；純母乳寶寶依建議補充維生素 D（見 [[newborn-care#weight-feeding]]） |

- 母乳水分約 88%；**6 個月內純母乳寶寶不需要另外喝水**
- 母乳寶寶的大便：**金黃、糊狀或稀糊**、帶酸味、次數多（可每餐後都解）；母乳水分多加上新生兒**胃結腸反射**明顯，**不是**對母乳過敏
- 母乳的好處
   1. 嬰兒：減少腸胃炎、中耳炎、呼吸道感染、壞死性腸炎（早產兒）、嬰兒猝死症、日後肥胖與糖尿病
   2. 母親：**促進子宮收縮與復舊**、減少產後出血、延後排卵、減少乳癌與卵巢癌、幫助體重恢復、增進親子依附
   3. 經濟方便、溫度適當、無菌

## 成功哺餵母乳十措施與肌膚接觸 {#ten-steps}

- WHO／UNICEF 2018 修訂的十措施（母嬰親善醫院的認證基礎，台灣由國健署認證）

| 類別 | 措施（重點） |
|---|---|
| 機構管理 | 1. 遵守母乳代用品行銷守則、有書面政策並監測；2. 工作人員有足夠的知識與能力 |
| 臨床照護 | 3. **產前**和孕婦與家人討論母乳哺育；4. 產後**立即且不中斷的肌膚接觸**，協助儘早開始哺乳；5. 協助母親開始並維持哺乳、處理常見困難；6. 沒有醫療需要，**不給新生兒母乳以外的食物或液體**；7. **親子同室**、24 小時在一起；8. 協助母親辨認並回應**飢餓暗示**（依需求哺餵）；9. 告知母親使用**奶瓶、奶嘴、安撫奶嘴**的風險；10. 出院時安排**持續支持**（社區、支持團體） |

- **產後立即肌膚接觸**(skin-to-skin)
   1. 出生後擦乾，將**只包尿布**的新生兒直接趴在母親**裸露胸前**，蓋上被單保暖
   2. **至少 1 小時**、不中斷，直到第一次哺乳完成
   3. 讓新生兒自己找乳房、用手觸摸乳頭；出現**尋乳徵象**時協助第一次哺乳，不硬把乳頭塞進嘴裡
   4. 過程中觀察新生兒**膚色、呼吸**（必要時血氧），預防突發性虛脫
   5. **剖腹產**：母親清醒、母嬰穩定時，在手術室或恢復室也要儘早進行
- 肌膚接觸的好處：穩定新生兒體溫、心跳、呼吸與血糖、減少哭鬧、促進催產素與泌乳、**直接促進親子依附**（見 [[postpartum-psychosocial-adaptation#attachment]]）

## 飢餓暗示與哺餵頻率 {#feeding-cues}

| 早期暗示（這時就餵） | 中期 | 晚期（先安撫再餵） |
|---|---|---|
| 睡眠中眼球動、嘴巴動、**伸舌**、**轉頭尋乳**、張嘴、**吸吮手或拳頭** | 伸展身體、扭動、手伸向嘴、臉轉向照顧者、動作變多 | **哭**、激動、臉漲紅 |

- **依需求哺餵**(demand feeding)：不限時間與次數；新生兒每天約 **8–12 次**
- **不要等大哭才餵**：大哭時不易含乳，要先安撫
- **吃飽**的表現：自己鬆開乳房、**臉部與手放鬆**、入睡
- 新生兒胃容量小、睡眠多，**少量多次**是正常的，不是奶水不夠

::questions{ids="113-2_OP_015,110-2_OP_022,106-2_makeup_OP_001"}

## 哺乳姿勢與含乳 {#position-latch}

- 常用姿勢：**搖籃式**、**橄欖球式**（剖腹產、雙胞胎、乳房大）、**側躺式**（剖腹產、夜間）、交叉搖籃式（早產兒、含乳困難）
- 共同原則：嬰兒**耳、肩、髖成一直線**，**肚子貼肚子**，鼻子對乳頭，母親身體放鬆、有支托
- 含乳步驟
   1. 用**乳頭輕觸嬰兒上唇或嘴唇**，引發**尋乳反射**
   2. 等嬰兒**嘴巴張大**，快速把嬰兒抱向乳房（帶寶寶靠近乳房，不是把乳房塞給寶寶）
   3. 嬰兒**由下往上不對稱**地含住一大口乳房組織
- 正確含乳的表徵

| 正確 | 不正確 |
|---|---|
| 嘴巴張大、上下唇像魚嘴外翻，**尤其下唇外翻** | 嘴唇內縮、只含乳頭 |
| 下巴貼乳房，**上方乳暈露出比下方多** | 下方乳暈露出較多 |
| **兩頰飽滿**、圓鼓 | **兩頰凹陷** |
| 吸吮慢而深、**可聽到吞嚥聲** | **嘖嘖聲**、咂嘴聲 |
| 母親**乳頭不痛**，餵完乳頭形狀正常 | 乳頭疼痛、餵完乳頭扁或有壓痕 |

- **不需要下壓乳暈**幫寶寶留呼吸空間（會讓乳頭滑出），鼻子靠著乳房仍能呼吸
- 吸吮與吞嚥的節律：一開始**快而淺**（約 2–3 次吸吮一次吞嚥）刺激射乳，奶水流出後**慢而深**，約 1 : 1；不是全程平穩 1 : 1

::questions{ids="110-2_OP_002,113-2_OP_019,105-2_OP_018,114-3_OP_014"}

## 吃夠了嗎 {#adequate-intake}

- 評估嬰兒攝取足夠

| 項目 | 足夠的表現 |
|---|---|
| 哺餵次數 | 每天 **8–12 次** |
| 尿布 | 出生第 1 天約 1 片濕尿布，**每天增加**；第 5–6 天起每天 **6 片以上**、尿色淡 |
| 大便 | 胎便（墨綠）→ 過渡便 → 第 4–5 天起**金黃色**糊便，每天 3 次以上 |
| 體重 | 生理性體重減輕 **< 10%**（多在第 3–4 天最低），**10–14 天**回到出生體重 |
| 行為 | 餵完放鬆滿足、清醒時有活力 |

- 母親擔心奶水不足時，先做這些
   1. **評估嬰兒尿布與體重**，用實際資料回應擔心
   2. **觀察一次完整的哺餵**，確認含乳與有效吸吮
   3. 鼓勵 **24 小時親子同室**、看暗示餵、增加哺乳或**手擠奶**次數
   4. 母親跟著嬰兒作息**休息**
   5. 肯定母親的哺乳決定；沒有醫療需要**不補配方奶**（會減少吸吮刺激）
- 需要轉介評估：體重減輕 **≥ 10%**、**2 週還沒回到出生體重**、尿布明顯不足、嗜睡吸吮無力、黃疸加重
- 生理性體重減輕見 [[newborn-care#weight-feeding]]，黃疸見 [[neonatal-disorders#hyperbilirubinemia]]

::questions{ids="115-2_OP_015,113-1_OP_013,112-2_OP_025,115-1_OP_016"}

## 常見問題 {#common-problems}

### 生理性脹奶 {#engorgement}

- 時間：產後 **3–5 天**奶量增加時；乳房**變硬、熱、脹**，可能不太痛；原因是乳汁增加加上**血管充血與組織水腫**
- 預防：產後**立即肌膚接觸**、**儘早**開始、**依需求頻繁**哺餵、正確含乳
- 處理

| 做 | 不做 |
|---|---|
| **增加哺乳次數**、依需求哺餵 | 定時、減少次數 |
| 餵前溫熱敷幾分鐘或溫水淋浴、輕柔撫觸，**刺激射乳反射** | 熱敷加**用力按摩直到乳房柔軟** |
| 乳暈太硬時先**手擠一點奶**或用**反向按壓軟化**乳暈再含乳 | 餵完每次把餘奶擠空（會刺激更多分泌） |
| 餵後**冷敷**減輕腫脹，必要時消炎止痛藥 | **限制水分**（不能預防也不能治療） |
| 穿合身、支托性的胸罩 | 穿太緊的胸罩 |

- 新舊說法：舊課本寫「熱敷、按摩擠出」；ABM 2022 建議**不用力深層按摩**（會加重水腫與組織損傷），改用**輕柔淋巴引流式撫觸、冷敷、消炎止痛**，並依需求哺餵
- 脹奶沒處理 → 乳腺管阻塞、乳腺炎

::questions{ids="114-2_OP_016,110-1_OP_020,115-2_OP_014,105-2_OP_023"}

### 乳腺管阻塞與乳腺炎 {#plugged-duct}

- 乳腺管阻塞：**局部硬塊、觸痛**，可能微熱，全身症狀輕
- 處理：讓嬰兒**多吸**（下巴對著硬塊的方向）；吸不好就**每 2–3 小時擠奶**；輕柔撫觸、冷敷、休息；不減少喝水、不用乳頭罩
- 合併發燒、紅腫熱痛、類流感症狀 → **乳腺炎**，仍要**繼續哺乳**（見 [[perinatal-infections#mastitis]]）

::questions{ids="107-1_OP_023"}

### 乳頭問題 {#nipple-problems}

- **乳頭扁平或凹陷**：嬰兒吸的是**乳房**（乳暈與乳房組織），不是只吸乳頭 → 先**評估乳頭伸展性**；伸展性好就能親餵；餵前用手或吸乳器把乳頭拉出、改變姿勢；不需要懷孕期常規牽引乳頭
- **乳頭疼痛、破皮**：多是**含乳不正確** → 先調整姿勢與含乳；餵完擠一點後奶塗在乳頭、自然風乾；從較不痛的一側開始；要離開時先用手指伸進嬰兒嘴角**解除吸力**

::questions{ids="112-3_OP_014"}

### 奶水不足 {#low-supply}

- 多數是「**覺得**不夠」；真正不足的常見原因
   1. **含乳不正確**、無效吸吮
   2. **限制哺餵次數或時間**、夜間不餵、補配方奶或水、使用奶嘴
   3. 母親**沒自信、焦慮、疼痛、疲倦**（抑制催產素反射）
   4. 少數為母親因素（胎盤殘留、甲狀腺低下、乳房手術、席漢氏症候群）
- 處理：增加有效移出（勤餵、手擠奶）、改善含乳、休息與支持、建立信心

### 母乳黃疸 {#breastfeeding-jaundice}

| | **哺乳性黃疸**（早發性，breastfeeding jaundice） | **母乳性黃疸**（晚發性，breast milk jaundice） |
|---|---|---|
| 時間 | 出生第 **2–4 天** | 第 1 週末起，可持續數週 |
| 原因 | **吃得不夠** → 排便少、膽紅素腸肝循環增加 | 母乳中某些成分使膽紅素代謝變慢 |
| 處理 | **繼續且增加哺餵**（每天 8–12 次）、改善含乳 | 通常**繼續哺餵**；數值高時依醫囑照光 |

- 新生兒黃疸的評估與照光見 [[neonatal-disorders#phototherapy]]

::questions{ids="108-2_OP_026"}

## 退奶與離乳 {#weaning}

- **漸進式離乳**最好：每隔幾天**減少一次哺乳**，用杯子或奶瓶取代，讓乳量慢慢下降
- 退奶期間

| 做 | 不做 |
|---|---|
| 穿**合身、支托性**的胸罩（國考也寫束胸） | **熱敷**（會促進泌乳） |
| 脹痛時**冷敷**、止痛藥 | **把乳房排空**（會刺激泌乳素，奶更多） |
| 太脹時**只擠出一點**減輕不適 | 突然完全停止（易阻塞、乳腺炎） |

- 國考也把「**限制水分**」「小麥汁、韭菜」列為退奶措施（106 年題），現在證據不足，限水對退奶沒有明確效果
- 退奶藥：cabergoline、bromocriptine（多巴胺促效劑，抑制泌乳素，見 [[pituitary-hormones#dopamine-agonists]]）

::questions{ids="106-2_makeup_OP_021,106-1_OP_023"}

## 母乳禁忌與配方奶 {#contraindications-formula}

- **不適合哺餵母乳**
   1. 嬰兒**半乳糖血症**（典型）
   2. 母親 **HIV 感染**（台灣建議不哺餵）、HTLV 感染
   3. 母親使用**非法藥物**、正在接受**化學治療**或放射性同位素檢查治療
   4. 暫時不親餵：母親**活動性肺結核**未治療（可擠出母乳給嬰兒）、**乳房上有疱疹病灶**、水痘（產前 5 天到產後 2 天發作）
- **不是禁忌**：**生理性黃疸**、母親 **B 型肝炎**（新生兒依時程打 HBIG 與疫苗）、**乳腺炎**、一般感冒、多數常用藥物
- 配方奶
   1. 依罐上的比例泡，**不要太濃或太稀**；先加水再加奶粉；用 70°C 以上的開水沖泡再放涼（減少阪崎腸桿菌）
   2. 泡好在室溫 **2 小時內**喝完，剩下的丟掉
   3. 奶瓶、奶嘴清洗後消毒
   4. 餵食時抱著嬰兒、奶瓶傾斜讓奶嘴充滿奶，**不要讓嬰兒自己躺著吸奶瓶**（嗆奶、中耳炎、奶瓶性齲齒）
- 母乳保存：室溫(< 25°C)約 4 小時、冷藏約 4 天、冷凍 3–6 個月；解凍後不再冷凍（數值依國健署母乳衛教，各來源略有差異）
