產科護理的目標是讓母親與嬰兒平安，同時讓家庭有好的生產經驗。本頁整理產科照護的演進、以家庭為中心的照護、溫柔(友善)生產與拉梅茲的健康生產措施、生產教育、產科護理人員的角色、跨文化照護與倫理法律；婦幼生命統計見 [[vital-statistics]]，產檢、母嬰親善與哺乳政策見 [[maternal-child-health]]，分娩期的實際照護見 [[intrapartum-care]]。文中縮寫：LDR(Labor, Delivery, Recovery room，待產、分娩、恢復同一間的「樂得兒」產房)、LDRP(加上 Postpartum)

## 重點摘要 {#summary}

- 演進：從產婆在家接生 → 醫院與醫師主導、重視**安全** → 現在兼顧**安全與生產經驗**、尊重婦女自主
- 洗手預防**產褥熱**：Semmelweis(1847 年推動接生前洗手)
- **以家庭為中心**的產科照護
   1. 懷孕生產是**正常、健康的生命事件**，不是疾病
   2. **家庭成員都被注意與尊重**，可參與生產過程(配偶、手足、其他家人)
   3. **陪產**、**親子同室**、**樂得兒產房**(待產、分娩、恢復在同一環境)
   4. 產後**立即肌膚接觸**、儘早哺乳
   5. 沒有合併症時**提早出院**與家人團聚
   6. 依個案需求**個別化**，不是一律相同的常規
   7. 賦權婦女**自主選擇**生產方式與地點
- **溫柔(友善)生產**：自由走動與變換姿勢、可進食飲水、自選陪伴者、非藥物減痛；**不常規剃毛、灌腸、會陰切開、禁食**
- **拉梅茲六大健康生產措施**(見下方)
- 護理角色：**照顧者**、**諮詢者**、教育者、管理者、研究者、倡議者
- 跨文化：不違反照護原則下**尊重習俗**，採**不批判**的態度和個案一起討論

### 國考常考點 {#exam-points}

- 以家庭為中心的照護**不包括**「增加產前基因篩檢次數」、**不是**「留院直到適應母職」、**不是**「提供完全相同的常規照護以符合評鑑」、**不是**只讓準父親陪產、也**不是**只考慮婦女需求
- 醫院不是唯一能提供溫和生產的場所(助產所、在家生產也可以)
- 「禁食、灌腸、會陰切開等常規處置」**不是**人性化生產的說法；溫柔生產**不常規剃毛**
- 友善生產：產婦**自己決定陪伴者**、**待產可自由走動**；不是建議用止痛藥麻醉、也不是待產禁食
- 拉梅茲倡議：**分娩時可下床活動、變換姿勢**；不鼓勵常規催產素、仰臥、持續胎兒監測
- 生產教育：讓孕婦**能因應懷孕與分娩**，朝向**以家庭為中心**；不是醫護主導、也不是「一定不要用藥物減痛」
- 電話協助產後哺乳問題 → **諮詢者**；直接協助產婦如廁 → **照顧者**
- 婆婆堅持喝生化湯 → **不批判，和產婦討論她的想法與決定**；不要私下倒掉或假裝沒看見
- 照顧新住民婦女：**不與照護原則衝突時尊重其文化**；不是以配偶意見為主、也不是要求她改採台灣方式
- 產科照護趨勢：**提升衛教能力**、網路**資源共享**；不是延長住院、不是挑戰傳統習俗
- 台灣現況：**母嬰親善醫院**已列入醫院評鑑項目(國考答案)

## 產科照護的演進 {#history}

- 西方
   1. 早期由有經驗的女性(產婆、助產士)在家陪產接生
   2. 17–18 世紀產鉗發明與改良，醫師開始參與接生
   3. 19 世紀 Holmes 與 **Semmelweis** 發現接生者的手傳染**產褥熱**，推動**洗手**；Lister 發展外科無菌技術 → 產婦死亡率大幅下降
   4. 20 世紀生產移到醫院，剖腹產、麻醉、胎兒監測、超音波、產前遺傳診斷進步
   5. 近年自然生產運動興起，強調婦女的身體自主與生產經驗
- 台灣
   1. 傳統產婆 → 日治時期開始培訓助產士 → 戰後醫院生產普及，產科醫師主導
   2. 現在：**母嬰親善**推動(2001 年起)、**助產師**法制化、溫柔生產與助產所再受重視
   3. 照護趨勢：提升專業人員**衛教能力**、利用網路**資源共享**、縮短住院、尊重多元文化
- 婦嬰生命統計(孕產婦死亡率、新生兒與嬰兒死亡率)的定義與算法見 [[vital-statistics]]

## 以家庭為中心的產科照護 {#family-centered}

| 原則 | 做法 |
|---|---|
| 生產是**正常的生命事件** | 減少不必要的醫療介入；健康孕婦不當病人看待 |
| **家庭參與** | 家中每位成員的需求都被注意與尊重；配偶陪產、**手足**與其他家人可參與 |
| **母嬰不分離** | 產後**立即肌膚接觸**、**親子同室**、儘早哺乳；點眼藥等可延到第一次哺乳後 |
| 環境 | **樂得兒產房**(LDR／LDRP)：待產、分娩、恢復(產後)在同一房間；居家化的環境 |
| **自主選擇** | 生產計畫書；賦權婦女選擇生產方式、地點與陪伴者 |
| 個別化 | 依需求調整，不是所有人都做相同的常規 |
| 出院 | 無合併症時**提早出院**，搭配出院後電話或居家追蹤 |
| 支持系統 | 婚姻品質與支持系統會影響婦女的適應，要一起評估 |

- 產後母嬰同室與哺乳細節見 [[maternal-child-health#breastfeeding]]

## 溫柔生產與拉梅茲措施 {#gentle-birth}

- **溫柔(友善、人性化)生產**的做法
   1. 和產婦一起擬定**生產計畫書**
   2. 待產時**自由走動**、選擇舒適姿勢；可以**進食飲水**
   3. **產婦自己決定陪伴者**(伴侶、家人、陪產員)
   4. 優先用**非藥物減痛**(按摩、熱敷、水中待產、呼吸放鬆)，需要時再用藥物
   5. **不常規**剃毛、灌腸、會陰切開、禁食、持續胎兒監測
   6. 第二產程可用直立、側躺、蹲姿等，依身體感覺用力
   7. 產後**立即肌膚接觸**、延遲斷臍、母嬰同室
- 新舊做法與證據(WHO 2018 產時照護建議)見 [[intrapartum-care#evidence-based-care]]
- **拉梅茲六大健康生產措施**(Lamaze International)
   1. 讓產程**自然開始**
   2. 產程中**走動、移動、變換姿勢**
   3. 請家人、朋友或陪產員**持續陪伴與支持**
   4. **避免不必要的醫療介入**
   5. **避免仰躺生產**，依身體的感覺用力
   6. **母嬰在一起**，不分離，有助哺乳
- 拉梅茲呼吸法等減痛技巧見 [[pain-management]]

## 生產教育 {#childbirth-education}

- 目的：讓孕婦與家人**有能力因應**懷孕、分娩與育兒，減少恐懼，增加自我控制感
- 方向：朝向**以家庭為中心**，鼓勵伴侶參與；提供各種減痛方法(藥物與非藥物)的資訊，讓孕婦**自己選擇**，不是「一定不能用藥」
- 內容：懷孕生理變化與不適、營養與運動、產兆與何時到院、分娩過程、減痛方法、產後照護、母乳哺育、新生兒照護
- 孕期衛教與生產準備見 [[prenatal-care]]

## 產科護理人員的角色 {#nurse-roles}

| 角色 | 例子 |
|---|---|
| **照顧者** | 直接協助無法下床的產婦如廁、執行護理技術 |
| **諮詢者** | **電話協助**產後母親解決哺乳問題；回答孕產婦的疑問 |
| 教育者 | 產前教育、出院衛教 |
| 管理者 | 規劃病房作業、協調團隊 |
| 研究者 | 發展與運用實證 |
| 倡議者 | 保護婦女與嬰兒的權益、爭取友善政策 |
| 協調者 | 轉介社會資源、銜接社區追蹤 |

- 擁有護理師與助產師執照者，可依規定執業登錄(國考答案認為「只能單一證照登錄」錯誤)

## 跨文化照護 {#cultural-care}

- 台灣常見的產後習俗：**坐月子**(不洗頭、不吹風、吃麻油雞)、**生化湯**；新住民婦女可能有母國不同的習俗
- 原則
   1. 先了解個案與家人的信念和理由
   2. **不與照護原則衝突時尊重**其習俗
   3. 有衝突時採**不批判**的態度，提供正確資訊，**和產婦一起討論**，由她做決定(例：生化湯可能增加產後出血，與子宮收縮劑同用要和醫師討論)
   4. 語言不通時用通譯或翻譯衛教單張，**以產婦本人的意見為主**，不是只聽配偶
   5. 不可私下倒掉、假裝沒看見或強迫改採台灣方式
- 坐月子的現代做法見 [[postpartum-care#doing-the-month]]

## 倫理與法律 {#ethics-law}

- 產科常見的倫理議題：人工流產、產前篩檢與選擇性終止妊娠、人工生殖與代理孕母、剖腹產的自主選擇、未成年懷孕、胎兒與母親權益衝突
- **知情同意**：說明處置目的、風險、替代方案，由產婦(或法定代理人)自主決定
- **人工流產**(優生保健法)
   1. 第 9 條列出可依自願施行的情形(遺傳、傳染或精神疾病；胎兒畸型之虞；性侵受孕；懷孕或生產會影響心理健康或家庭生活等)
   2. **未婚的未成年人**要經**法定代理人同意**
   3. **有配偶者**依「影響心理健康或家庭生活」施行時，要**配偶同意**；其他款(例如配偶的親屬有遺傳疾病)法條沒有要求配偶同意
   4. 施行細則：應在**妊娠 24 週內**施行(醫療行為例外)
   5. **RU486**(mifepristone)：符合法定條件、經醫師評估後可用於**早期懷孕(約 7 週內)**的藥物流產(用法見 [[sex-hormones#emergency-contraception]])
   6. 條文整理見 [[maternal-child-health#eugenics-art]]
- 生產事故救濟：2016 年公布《生產事故救濟條例》，生產造成產婦或新生兒死亡、重傷時可申請救濟，不必先證明過失(條文細節待核對全國法規資料庫)
