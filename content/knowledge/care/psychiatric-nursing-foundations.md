這一頁整理精神科護理的「基本功」：精神醫學怎麼從關押走向人道與社區、護理人員應該怎麼看待精神病人，以及在醫療團隊中的角色。理論模式(精神分析、人際關係等)見 [[psychodynamic-theories#nursing-models]]，社區心理衛生與三級預防見 [[community-mental-health]]，治療性溝通見 [[schizophrenia#communication]]

## 重點摘要 {#summary}

- **四次革新**：①**Pinel 除去病人的鎖鍊**(人道主義)；②**Freud 精神分析**；③**社區精神醫學**(Maxwell Jones 的**治療性社區**、**去機構化**)；④**生物精神醫學**(精神藥物、腦科學)
- **基本認識**：病人的怪異想法與行為**有目的、有意義**；病因是**多重因素**；病人常缺乏自信、安全感與挫折忍受度；**不以道德標準衡量**病人；重度精神疾病也能復元
- **照護方式**：精神科病房普遍採**主責護理**，護理計畫由**主責護理師**擬定；社區常用**個案管理**(不限護理師)
- **角色**：直接照顧者、教育者、諮商者、**個案管理者**、**代言者**(為病人與家屬爭取權益、影響政策)、協調者與聯繫者、研究者
- **工作範圍**：**保健性**(初級預防)、**治療性**(次級)、**復健性**(三級)

### 國考常考點 {#exam-points}

- 主張**不以鐵鍊限制病人**、奠定**人道主義**照護、精神醫學**首次革命** → **Pinel(畢乃爾)**
- **第四次革新**是**生物精神醫學**蓬勃發展；Jones、治療性社區、去機構化屬於**第三次**
- 對精神病人的正確認識：怪異行為**有目的與意義**、病因**非單一**、多半**缺乏自信與安全感、挫折忍受度低**；「一旦診斷重度精神疾病就難以治癒、不需積極治療」是錯的
- **勿以道德標準衡量**病人的行為；不用封閉式問句引導、不用嚴格管理、不用批判言辭
- 精神衛生護理學會推動**精神衛生護理師**、**社區精神衛生護理能力鑑定**、**精神衛生臨床護理專家**；精神科專科護理師已納入國家專科護理師制度(考選部 A、D 都給分)
- 社區照護常採**個案管理者**；個案管理者**不是只有護理師**能擔任；精神科病房普遍是**主責護理**而不是功能性護理；護理計畫由**主責護理師**擬定
- 參與研討會、協助病人與家屬爭取福利權益、在政策制定時提供有利病人的資訊 → **代言者**
- 精神護理之家的護理人員角色：**聯繫者、策劃者、協調者、個案管理者**；**不是醫療疾病診斷者**

## 精神醫學發展史 {#history}

### 古代與中世紀 {#ancient}

1. 古希臘 Hippocrates：以體液失衡解釋精神疾病，視為腦部疾病
2. 中世紀：被視為**魔鬼附身**，以驅魔、監禁甚至獵巫對待
3. **Weyer(韋耶)**：16 世紀主張精神疾病和身體疾病一樣，和巫魔無關

### 四次革新 {#revolutions}

| 次 | 代表 | 重點 |
|---|---|---|
| **第一次** | **Pinel(畢乃爾)**，18 世紀末法國 | **除去病人的鎖鍊**，以人道立場對待病人；英國 Tuke 的**道德治療**、美國 Dix 推動改善收容環境 |
| **第二次** | **Freud(佛洛伊德)** | **精神分析**，重視潛意識與早期經驗，開啟心理治療 |
| **第三次** | **Maxwell Jones** 等 | **社區精神醫學**：**治療性社區**、**去機構化**、社區心理衛生中心 |
| **第四次** | 1950 年代起 | **生物精神醫學**：**chlorpromazine** 等精神藥物、神經傳導物質與腦科學研究 |

- **Kraepelin(克雷佩林)**：精神疾病的描述與分類(早發性失智)；Bleuler 提出「精神分裂」一詞
- 各教科書的分期略有不同，國考以上表為主

### 精神衛生護理的發展 {#nursing-history}

1. 早期護理人員多擔任看守與生活照顧
2. 19 世紀末開始有精神科護理的專門訓練
3. **Peplau** 1952 年提出**人際關係理論**，把**治療性人際關係**確立為精神科護理的核心(見 [[psychodynamic-theories#peplau]])
4. 隨精神藥物與社區化發展，護理角色擴展到給藥與副作用監測、團體與家庭治療、社區與居家照護、個案管理

### 台灣 {#taiwan}

1. 1990 年公布**精神衛生法**，之後多次修正；111 年(2022)修正強化社區與人權(見 [[schizophrenia#law]])
2. 以**精神醫療網**分區規劃醫療資源，發展急性、慢性、日間留院、社區復健、居家治療與精神護理之家等多層次服務(見 [[community-mental-health#resources]])
3. **中華民國精神衛生護理學會**推動專業認證
   1. **精神衛生護理師**
   2. **社區精神衛生護理能力鑑定**
   3. **精神衛生臨床護理專家**
   4. 精神科專科護理師過去由學會推動，現已納入衛福部的專科護理師制度

## 對精神病人的基本認識 {#basic-concepts}

1. 病人怪異的想法與行為都**有目的、有意義**，是為了滿足某種需要或傳達某種訊息
2. 精神疾病是**基因、生活、心理、社會**相互影響的結果，不是單一原因(見 [[psychodynamic-theories#biopsychosocial]])
3. 病人多半**缺乏自信、沒有安全感、挫折忍受度與抗壓性低**
4. **不以道德標準**衡量病人的行為；接納病人這個人，但不一定接受他的行為
5. 每個人都有成長與改變的潛力；重度精神疾病也能**復元**，仍需積極治療與復健
6. 溝通多用**開放式問句**，避免批判、說教與嚴格管理

## 精神衛生護理的理論模式 {#models}

| 模式 | 重點 |
|---|---|
| 醫療模式 | 疾病由生物因素造成，重視診斷與藥物 |
| 精神分析模式 | 潛意識衝突與早期經驗，運用移情與防衛機轉的分析 |
| **人際關係模式** | Sullivan、Peplau：人際互動與治療性人際關係；團體中體驗到人與人可以互相信賴 |
| 社會模式 | Caplan：社會環境與壓力，重視預防與社區 |
| 存在主義模式 | 尋找意義、為自己的選擇負責 |
| 溝通模式 | Berne 的交流分析 |
| 行為模式 | 學習理論、增強與行為修正 |
| 護理模式 | 整體性評估與護理過程 |

- 詳細內容見 [[psychodynamic-theories#nursing-models]]

## 精神醫療團隊與護理人員角色 {#team-roles}

### 醫療團隊 {#team}

1. 精神科醫師、護理人員、臨床心理師、社會工作師、職能治療師，必要時藥師、營養師
2. 各專業分工並定期開會，共同擬定治療計畫；病人與家屬也是團隊的一員

### 照護方式 {#care-delivery}

1. 精神科病房普遍採用**主責護理**(primary nursing)：由**主責護理師**負責評估與擬定護理計畫，提供連續性照護
2. 社區照護常採**個案管理**；個案管理者可以由護理師、社工師等擔任，不是只有護理師

### 護理人員角色 {#nurse-roles}

| 角色 | 例子 |
|---|---|
| 直接照顧者 | 生活照顧、給藥、觀察、安全維護 |
| 治療性人際關係者與諮商者 | 會談、情緒支持、團體治療 |
| 教育者 | 疾病與用藥衛教、家屬衛教 |
| **代言者** | 參與研討會與會議、**為病人與家屬爭取福利與權益**、在法案與政策制定時**提供有利病人的資訊** |
| **個案管理者** | 評估、計畫、資源連結、協調 |
| 協調者與聯繫者 | 聯繫團隊、機構與家屬 |
| 策劃者 | 擬定照護與活動計畫 |
| 研究者 | 參與研究、實證照護 |

- 醫療疾病的**診斷**屬於醫師，不是護理人員的角色
- 社區中的角色(個案發現者、疾病預防者等)見 [[community-mental-health#nursing-roles]]

### 工作範圍 {#scope}

| 性質 | 對應預防 | 例子 |
|---|---|---|
| **保健性** | 初級 | 心理健康促進、衛生教育 |
| **治療性** | 次級 | 急性症狀照護、危機處置 |
| **復健性** | 三級 | 出院後強化社交技巧、生活與職業訓練 |

### 精神衛生護理人員的條件 {#nurse-qualities}

1. **自我覺察**：了解自己的價值觀、情緒與偏見，避免影響治療關係
2. 接納、同理、尊重、真誠
3. 情緒穩定，能面對病人的攻擊、退縮與操縱
4. 持續學習，具備評估、溝通、團體與危機處理能力
