衛生教育是有計畫地提供學習經驗，讓人在**知識、態度與行為**上自願改變，是健康促進最常用的工具之一。這頁整理護理指導的設計：學習領域、原則、行為目標、教學方法與評價；健康促進的理論(健康信念模式、跨理論模式、PRECEDE-PROCEED)與渥太華憲章見 [[health-promotion]]

## 重點摘要 {#summary}

- 三個學習領域：**認知**(知道、說出、列舉)、**情意**(願意、認同、喜愛)、**技能**(能執行、能操作)
- 步驟：**評估需求 → 擬訂目標 → 規劃內容 → 執行 → 評價**
- **行為目標五要素**：對象、行為、結果、情境、標準；要**可觀察、可測量**
- 依目的選方法：增加知識 → **講述**；學技能 → **示範與回覆示教**、個別指導；改變態度 → **討論、角色扮演、價值澄清**；快速傳給大眾 → **大眾媒體、健康傳銷**
- 計畫評價：執行中看**過程**(場次、人數、參與度)；結束後看**衝擊**(知識、態度、行為)與**結果**(罹病率、死亡率)；比較投入與產出看**效率**

### 國考常考點 {#exam-points}

- 情意目標用「**願意**、認同、喜愛」；「說出、列舉、明白」是認知；「正確執行」是技能
- 技術教學(胰島素注射、用鏡子看腳底)→ **示範＋回示教**或**個別指導**，不是講述法
- 反覆練習注射技巧 → **熟練原則**
- 講述法：短時間傳達大量、有組織的知識，**要穿插提問**；不是問題導向學習
- 小組討論：**人數少**、多用開放式問題、**結束時要總結**；團體衛教最常用的是講述法
- 團體動力法**不是**用團體壓力逼成員發言
- 自我導向學習：**以學習者為中心**、適合**成人**、自己訂目標與策略
- 電視廣告、大眾媒體宣導篩檢 → **健康傳銷**；COVID-19 要快速宣導 → **大眾媒體**
- 記錄**參與人數** → 過程評價；**行為**改變(能選六大類食物、健康飲食比率增加) → 效果或衝擊評價；**人力物力財力** → 效率評價；計畫執行**初期**看是否符合需求 → **形成性**評價；完成後衡量價值 → **總結性**評價
- **具體目標**(objective)才要量化、包含人時事與程度；**總目標**(goal)是方向性描述

## 衛生教育的目的與概念 {#concepts}

- 目的：增加**知能**、改變**態度**(含責任感)、建立**行為**；改善廚房設備屬環境改善，**不是**衛生教育的直接目的(109-2 題)
- 對象是全民，場所包括學校、醫院、社區、職場與家庭；病人生病時的學習動機最強，醫院是好時機
- 影響學習的因素(課本 p.120)：有學習需要與動機、主動參與、由簡入繁、善用媒體、學習會有停滯期、**學習需要增強**
- 家庭教育是基礎(父母是孩童衛教的第一人選)；**學校**是推行衛教最有效的場所，善用同儕影響；隨時做機會教育

## 學習領域 {#domains}

| 領域 | 內容 | 層次(低 → 高) | 目標動詞例子 |
|---|---|---|---|
| **認知**(cognitive) | 知識與智力 | 知識、理解、應用、分析、綜合、評鑑 | 說出、列舉、指出、明白、解釋 |
| **情意**(affective) | 態度、價值、興趣 | 接受、反應、價值判斷、價值組織、價值體系形成 | **願意**、認同、喜愛、重視 |
| **技能**(psychomotor) | 動作操作 | 知覺、心向、模仿、機械化、複雜反應、創造 | 正確執行、示範、操作 |

- 「學童**願意**定期接受口腔檢查」→ 情意；「能正確執行刷牙方法」→ 技能；「能說出一項預防蛀牙的方法」「能明白刷牙好處」→ 認知(109-1 題)
- 「列舉三項有益健康的運動」是認知，**無法**代表情意改變(111-2 題)
- **主副附學習**(Kilpatrick)：**主學習**＝這次教學的直接目標(學會胰島素注射)；**副學習**＝相關的知識與概念(為什麼要打、注射部位、隱私、注意事項)；**附學習**＝過程中養成的態度與理想(自我照顧的信心)(107-1 題)
- **練習律**(Thorndike)：正確的練習會**增加正確反應、減少錯誤**；另有準備律、效果律

::questions{ids="111-2_PC_059,109-1_PC_057,107-1_PC_063"}

## 原則 {#principles}

- **教學原則**(教育學通則)：
   1. **準備原則**：學習者身心成熟、有動機時才教
   2. **類化原則**：把學到的應用到類似情境
   3. **熟練原則**：反覆練習到熟練，例：讓兒童**反覆練習胰島素注射**(106-1 題)
   4. **自動原則**：學習者主動、自發地學
- **Green(1990)衛生教育原則**(課本 p.121)：累積學習效果、多重目標、集合教育目標、**參與**、特殊情境、中介目標(兼顧親友與重要他人)、多樣方法、多樣化、健康促進、行政原則

::questions{ids="106-1_PC_080"}

## 計畫步驟與目標 {#planning}

### 步驟 {#steps}

1. **評估學習者的需要與興趣**
2. **設定目標**(行為目標)
3. **擬定計畫**：為什麼教(目標)、教什麼(內容)、何時、何處、誰教、怎麼教
4. **實施**
5. **評價**：學習與教學兩方面

- 112-2 失智預防衛教的順序：**確認需求 → 擬訂目標 → 規劃內容 → 執行 → 評價**
- 社區護理過程的計畫原則(RUMBA、5W)見 [[community-nursing-process#planning]]

### 行為目標 {#objectives}

| 要素 | 意思 | 例：「家屬在家中為中風個案做兩次完整的手部復健運動」 |
|---|---|---|
| **對象** | 誰要做 | 家屬 |
| **行為** | 可觀察的動詞 | 做 |
| **結果** | 行為的產物 | 完整的手部復健運動 |
| **情境** | 條件、時間、地點、工具 | 在家中 |
| **標準** | 達成的程度 | 兩次 |

- 課本與 Ross & Mico 衛生教育計畫模式都用這五要素：**人、行為、結果、情境、標準**(105-1 題)
- 一個行為目標只寫**一項行為、一項結果**；要可觀察、可操作、可測量
- 「老人每日能執行雙側下肢肌力運動至少 30 次」是好的行為目標；「家屬能**認同**」「能鼓勵」「能說出益處」不夠具體或不是行為(113-2 題)
- **總目標(goal) vs 具體目標(objective)**：總目標是長期、方向性、較抽象；**具體目標**才要**量化可測量**並包含人、時間、做什麼與程度(115-1 題)

::questions{ids="112-2_PC_059,105-1_PC_057,113-2_PC_036,115-1_PC_033"}

## 教學方法 {#methods}

### 依目的選方法(課本 p.123) {#method-by-purpose}

| 目的 | 適合的方法 |
|---|---|
| 增加**知識** | 講述(演講)、辯論、專家報告、閱讀 |
| 提高**理解** | 示範、戲劇、個案研究、問題解決 |
| 獲得**技能** | **示範、回覆示教**、角色扮演、練習、遊戲、模擬 |
| 改變**態度** | **討論、角色扮演**、個案研究、**價值澄清** |

- 改變態度選「討論、角色扮演、價值澄清」；專家報告(單向)與辯論(立場對立)效果差(107-2 題)
- 職場減鈉：**鹽分計示範**＋**講述**各種食物含鈉量最適當(112-2 題)

### 各方法重點 {#method-details}

| 方法 | 重點 |
|---|---|
| **講述法** | 以教師為中心；**短時間傳達大量、有組織的知識**；適合大班與較低層次學習；較難顧到個人需求；時間要依學習者年齡與注意力調整，**要穿插提問**；教材宜具體 |
| **問答法** | 鼓勵參與，可了解學習效果；可能讓學習者焦慮 |
| **小組討論** | **人數少**、學習者參與度高；適合較高層次的認知與**情意**學習；主持人用**開放式問題**，**結束時綜合整理** |
| **示範法與回覆示教** | 技術的實際解說，再由學習者做一次確認；適合**技能**(胰島素注射、用鏡子檢查腳底、貝氏刷牙) |
| **個別指導** | 一對一，依個人程度與需求調整；適合教育程度低的長者學技術、家訪 |
| **角色扮演** | 練習溝通與態度；教育者要接納學習者在角色中的反應 |
| **價值澄清法** | 協助檢視並確立自己的價值觀與態度 |
| **團體動力法** | 透過團體互動、支持與經驗分享改變行為；**不是**用團體壓力強迫發言 |
| **自學教材、電腦教學** | 可在家進行；教材架構要完整 |
| **自我導向學習** | **以學習者為中心**，自己診斷需求、訂目標、找資源、評估結果；適合**成人** |
| **健康傳銷**(社會行銷) | 用商業行銷的方法與**大眾媒體**推廣健康行為(電視廣告、媒體宣導大腸癌篩檢) |
| **大眾媒體** | 電視、廣播、網路，**最快**觸及大量民眾(疫情宣導)；講座、傳單、海報較慢、範圍小 |

- 團體衛生教育最常用、最經濟的是**講述法**；小組討論人數過多會減少發言機會(107-1 題；常見建議約 6–12 人，待核對)
- 國考 109-2 題：成人講述「40–50 分鐘最適合」判為錯
- 一份教案包括單元名稱、對象、時間、教學研究、單元目標與行為目標(認知、技能、情意)、教學活動、教具、時間分配與評鑑(課本表 4-5)

## 評價 {#evaluation}

### 依時間與參照標準(教學評量) {#learning-evaluation}

| 評價 | 時間 | 目的 |
|---|---|---|
| **診斷性評價** | 教學**前**(或遇到學習困難時) | 了解起點能力、找出學習困難的原因 |
| **形成性評價** | 教學或計畫**進行中**(含計畫初期) | 隨時修正；確認是否符合需求、有沒有接觸到對的對象、參與人數夠不夠 |
| **總結性評價** | 教學或計畫**結束後** | 衡量整體成效與價值 |

- **標準參照評價**：看學習者是否達到**預先設定的標準**；常模參照則是和其他人比較(110-2 題)
- 形成性評價的重點在**過程**，國考把它和**過程評價**視為相近概念；它**不是**結構評價(106-2 補考)
- 社區健康營造後，居民提升口腔癌與檳榔認知、願意改變以種檳榔維生的方式 → 國考答**總結性評價**(109-1 題)

### 依評價內容(計畫評價) {#program-evaluation}

| 評價 | 看什麼 | 例子 |
|---|---|---|
| **過程評價** | 執行情形：場次、**參與人數**、參與程度、進度、滿意度 | 記錄每次參與人數；評估民眾參與程度 |
| **衝擊評價** | 短中期改變：知識、態度、**行為**、技能、體能 | 參與者健康飲食習慣的比率增加；下肢肌力改善 |
| **結果評價** | 長期健康狀態：罹病率、死亡率、生活品質 | 社區居民的罹病率與死亡率 |
| **效果評價** | 達到預期目標的程度 | 能依飲食指南選擇六大類食物共 200 人(**行為目標**的效果評價) |
| **效率評價** | 投入的**人力、物力、財力**與成果的關係 | 獨居老人關懷計畫的資源使用狀況 |
| **合適性評價** | 計畫是否符合需求、是否解決對的問題 | — |
| **成效評價** | 計畫的**價值**、是否**引發其他問題** | 完成後評價價值與衍生問題 |

- 「共辦 8 場講座」「500 人次參加」「園遊會 5,000 人」都是**過程**評價，不是效果(109-1 題)
- **Donabedian** 三面：**結構**(人力、物力、設備是否適當)、**過程**(保存每次紀錄、執行情形)、**結果**(知識態度改變、罹病率與死亡率)；國考 108-1 答「罹病率及死亡率屬結果評值」
- 社區護理過程的評值四種類(效果、效率、合適性、成效)與第三類錯誤見 [[community-nursing-process#evaluation]]；PRECEDE-PROCEED 的過程、衝擊、結果評值見 [[health-promotion#precede-proceed]]
- 用語提醒：「impact」在 PRECEDE-PROCEED 譯為**衝擊**(短中期的行為改變)，在社區評值四種類譯為**成效**(計畫的價值與衍生問題)，要看題目給的選項組合判斷

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 「能說出」「能明白」是情意目標 | 是**認知** | 情意用「願意、認同、喜愛」 |
| 技術教學用講述法 | **示範＋回示教**、個別指導 | 技能要做出來才能確認 |
| 講述時儘量不要提問 | 要**穿插提問** | 維持注意力、評估理解 |
| 講述法是問題導向學習 | 以教師為中心的知識傳遞 | |
