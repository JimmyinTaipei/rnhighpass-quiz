新生兒評估從出生的第一分鐘開始：先判斷要不要**復甦**，再用 **Apgar** 看對子宮外生活的適應，接著做**從頭到腳的身體評估**與**成熟度評估**，最後依週數與體重分類，找出高危險新生兒。新生兒的生理調適見 [[newborn-adaptation]]，出生後的立即護理與日常照護見 [[newborn-care]]，早產兒見 [[preterm-infant]]，黃疸、低血糖、產傷等見 [[neonatal-disorders]]。新生兒反射見 [[pediatric-neuro#newborn-reflexes]]。文中縮寫：AHA（American Heart Association，美國心臟學會）、AAP（American Academy of Pediatrics，美國兒科醫學會）、CPAP（Continuous positive airway pressure，連續正壓呼吸）、SGA（Small for gestational age，小於妊娠年齡）、AGA（Appropriate for gestational age，適於妊娠年齡）、LGA（Large for gestational age，大於妊娠年齡）

## 重點摘要 {#summary}

- 復甦(2025 AHA／AAP)：出生先問「**足月？肌張力好？有呼吸或哭？**」→ 都是就**肌膚接觸**；否則**保暖、擦乾、擺位、刺激、必要時清呼吸道**；**呼吸暫停或喘息、心跳 < 100** → **正壓通氣**；心跳 **< 60** → **胸外按壓：通氣 3 : 1**、100% 氧氣
- **Apgar**：出生 **1 分與 5 分**評**心跳、呼吸、肌張力、反射、膚色**，各 0–2 分；**不含**血氧、排泄、外觀、身高體重
- 心跳、呼吸都要數**滿 1 分鐘**；心跳 110–160、呼吸 30–60 次/分
- 頭圍約 **33–35 公分**（比胸圍大約 2 公分）；身長約 **45–55 公分**；體重 2,500–4,000 公克
- **產瘤**：頭皮**水腫**、**越過骨縫**、出生時最明顯、**數天消失**；**頭血腫**：**骨膜下出血**、**不越過骨縫**、界線清楚、出生後 **1–2 天才明顯**、**數週到數月吸收**、可加重黃疸
- 正常皮膚表現：胎脂、胎毛、**肢端發紺**、**粟粒疹**、**毒性紅斑**、**蒙古斑**、先露部位瘀點；**葡萄酒色斑**（永久）與**出生 24 小時內黃疸**是異常
- **New Ballard**：早產兒**肌張力低**、關節鬆 → **方形窗角度大**、**手肘可越過中線**、**腳跟可拉到耳朵**、姿勢**伸展**；身體成熟度：皮膚薄透看得到血管、胎毛多、足底皺摺少、乳暈平、耳軟、陰囊平滑睪丸未降、小陰唇突出
- 依體重與週數：**SGA < 第 10 百分位**、**LGA > 第 90 百分位**；低出生體重 < 2,500 公克、極低 < 1,500 公克、超低 < 1,000 公克

### 國考常考點 {#exam-points}

- Apgar **不包括**：**排泄情況**、**血氧濃度**、外觀是否完整、身高體重；除了心跳、呼吸、膚色、反射之外還要評**肌肉張力**
- 出生 1 分鐘哭聲宏亮、呼吸規則、心跳 128、四肢略屈曲、軀幹粉紅四肢藍 → **8 分**
- 新生兒身體評估**不適當**：「心尖脈睡覺時測 **30 秒**」（要測**滿 1 分鐘**）；腹部先聽診再觸診、手拉直放開看手臂回彈、頭圍從**眉毛上方繞過耳朵頂端到枕骨粗隆**都正確
- 需進一步追蹤：出生頭圍 **40–42 公分**（正常約 33–35）；身長 45–55 公分、瞳孔間距 3.5–4 公分、視力約 20 公分內都正常
- 產瘤：頭皮邊緣**水腫越過骨縫中線**（真空吸引）；局部軟組織腫脹、**鬆軟、界線不清楚** → **產瘤（頭皮軟組織水腫）**；回答家長「**出生後數天會自行消失**」
- 頭血腫**錯誤**：「**出生時最明顯，隨後變小**」（其實出生後才慢慢明顯）；頭血腫**界線清楚**、可單側或雙側、骨膜下血管破裂、**可引發黃疸**
- 頭部評估**正確**：**胎頭變形**(molding)數天到數週恢復；頭血腫**不越過**骨縫、產瘤是**皮下水腫**；前囟門約 **12–18 個月**（不是 12–18 週）關閉
- 新生兒**軀幹長、四肢短**；**前囟門比後囟門晚**關閉
- 39 週頭產式新生兒異常：**耳朵上緣低於內外眼眥連線**（低位耳）；胎頭變形、結膜下點狀出血、**艾柏斯坦小珠**（硬腭小白點）都正常
- 評估男性新生兒**皮膚飽和度**的最佳部位：**腹部**
- 皮膚**異常**：出生時**臉部葡萄酒色斑**；臀部蒙古斑、2–3 天出現的毒性紅斑、先露部位瘀點都正常
- 毒性紅斑通常在**出生後 4 天內**出現、**1–3 週**消失、**不需治療**；新生兒**膿疱**要想到**感染**（多為金黃色葡萄球菌）、具傳染性
- **毛細血管瘤**（草莓狀血管瘤）會**逐漸消退**，不是永久；**粟粒疹**約 **2–4 週**消失（不是 3–5 天）；**蒙古斑**多在 **1–5 歲**淡化（不是 12–18 歲），邊界不明顯，多在臀部、背部、大腿
- 出生時**臉部偏黃**（疑似 24 小時內黃疸）代表潛在異常；**手腳肢端發紺**正常
- 足月男嬰**異常**：**陰囊表面光滑少皺褶**；出生 1 個月男嬰正常：**睪丸已下降、陰囊皺摺多**
- 乳頭白色分泌物是母親**雌性素**影響；**Ortolani** 聽到喀答聲 → **髖關節脫臼**；外耳低於眼外眥 → 可能染色體異常
- New Ballard 最佳時間：足月兒**出生後 24 小時內**
- New Ballard 方法**正確**：**手臂反彈**是把手肘彎曲 5 秒再伸直放開，看反彈角度；方形窗是手腕往**前臂內側（屈側）**彎；圍巾徵象看手肘與**中線**的關係；姿勢是**安靜平躺**時看（不是哭時）
- 早產兒特徵：**方形窗 90 度**、**手肘可以越過中線**、**腳跟容易拉到耳朵**、**膝膕角大（如 140 度）**、**全身胎毛豐富**、四肢**伸展**放鬆；足月兒**方形窗 0 度**、手肘**不能**越過中線、四肢**屈曲**
- 足月兒身體成熟度**錯誤**：「**乳暈平坦無突起**」（足月兒乳暈突起 3–4 mm 以上）；**皮膚透明可見靜脈**不符合 39 週
- 女嬰生殖器最成熟：**大陰唇覆蓋陰蒂及小陰唇**
- 懷孕 30 週出生 2,400 公克 → **LGA**

## 新生兒復甦 {#resuscitation}

- 出生前：產前諮詢、**團隊分工**、**檢查設備**（保溫台、吸引、面罩與甦醒球、氧氣、血氧計、插管用物）
- 2025 AHA／AAP 新生兒復甦流程（重點，流程圖原文見參考資料）

| 步驟 | 判斷 | 處置 |
|---|---|---|
| 出生 | 啟動**臍帶處理計畫**（健康新生兒延遲斷臍） | |
| 快速評估 | **足月？肌張力好？有呼吸或哭？** | 三個都是 → **和父母肌膚接觸**、常規照護、維持體溫、持續評估 |
| 初步步驟（約 1 分鐘內完成到開始通氣） | 有任一項「否」 | **保暖並維持正常體溫**、**擦乾**、**擺位**（頸部微仰的嗅物姿勢）、**刺激**、**必要時**清呼吸道 |
| 評估呼吸與心跳 | **呼吸暫停或喘息**，或**心跳 < 100 次/分** | **正壓通氣**、接**血氧計**、考慮心電監視 |
| | 呼吸費力或持續發紺 | 血氧計、**需要時給氧**、考慮 **CPAP** |
| 通氣後 | 心跳仍 **< 100** | **通氣矯正步驟**（面罩密合、重新擺位、抽吸、張口、加壓、換氣道）、考慮插管或喉罩 |
| | 心跳 **< 60** | 插管或喉罩、**胸外按壓**、**按壓：通氣 3 : 1**、**100% 氧氣**、建立**臍靜脈導管或骨內管路** |
| | 心跳仍 **< 60** | **epinephrine 每 3–5 分鐘**（臍靜脈或骨內）；考慮**低血容**、**氣胸** |
| 心跳 ≥ 100 | | 復甦後照護、和家屬溝通、團隊回顧 |

- 目標血氧（出生後，右手）

| 出生後 | 目標 SpO₂ |
|---|---|
| 2 分鐘 | 65–70% |
| 3 分鐘 | 70–75% |
| 4 分鐘 | 75–80% |
| 5 分鐘 | 80–85% |
| 10 分鐘 | 85–95% |

- 新生兒胸外按壓用**雙拇指環抱法**、胸骨下 1/3、深度約胸廓前後徑 1/3；**按壓與通氣 3 : 1**（每分鐘約 90 下按壓、30 次通氣），和兒童、成人不同（見 [[cpr]]）
- **抽吸**：**不常規**抽吸；分泌物阻塞呼吸道或需要正壓通氣時才抽，**先口後鼻**、時間短；過度或太深的抽吸刺激**迷走神經** → 心跳變慢
- **胎便染色羊水**：活力好的新生兒照一般照護；**活力不好**也**不再常規氣管內抽吸**，先給正壓通氣，阻塞時才抽吸（國考舊題答「胎頭娩出時用 DeLee 管抽吸口鼻」，見 [[neonatal-disorders#meconium-aspiration]]）

## Apgar 評分 {#apgar}

- 出生後 **1 分鐘**與 **5 分鐘**評估；5 分鐘 < 7 分時每 5 分鐘再評，直到 20 分鐘
- 用途：評估新生兒對**子宮外生活的立即適應**與**復甦的效果**；**不用來決定**要不要開始復甦（要不要通氣看呼吸與心跳）

| Apgar | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| **心跳**(Heart rate) | 無 | < 100 次/分 | **≥ 100 次/分** |
| **呼吸**(Respiratory effort) | 無 | 慢、不規則、哭聲弱 | **規則、哭聲宏亮** |
| **肌張力**(Muscle tone) | 軟弱 | **四肢稍屈曲** | **四肢屈曲**、活動好 |
| **反射**（刺激反應，Reflex irritability） | 無 | **皺眉、扭臉** | 咳嗽、打噴嚏、大哭 |
| **膚色**(Color) | 全身發紺或蒼白 | **軀幹粉紅、四肢發紺** | 全身粉紅 |

- 例：哭聲宏亮(2)、心跳 170(2)、軀幹粉紅手腳微紫(1)、四肢屈曲(2)、抽吸時臉部扭曲(1) → **8 分**
- 判讀：**7–10 分**正常；**4–6 分**中度抑制，需要協助（刺激、給氧）；**0–3 分**重度抑制，需要**立即復甦**
- 大多數健康新生兒 1 分鐘只有 8–9 分，因為**肢端發紺**很常見

## 生命徵象與測量 {#vital-signs}

| 項目 | 足月新生兒 | 方法與注意 |
|---|---|---|
| 心跳 | **110–160 次/分** | 在**安靜**時聽**心尖脈**、數**滿 1 分鐘** |
| 呼吸 | **30–60 次/分** | 看腹部起伏、數**滿 1 分鐘**；可有短暫週期性呼吸 |
| 體溫 | 腋溫約 36.5–37.5°C | 多量腋溫（見 [[body-temperature]]） |
| 血壓 | 約 60–80／40–50 mmHg | 不常規量，有需要時用合適的壓脈帶 |
| 體重 | **2,500–4,000 公克** | 裸身、預熱磅秤墊布 |
| 身長 | 約 **45–55 公分**（平均約 50） | 平躺，頭頂到腳跟，膝蓋壓直 |
| 頭圍 | 約 **33–35 公分** | 量尺經**眉毛上方**、**耳朵頂端**、繞過**枕骨粗隆**最突出處 |
| 胸圍 | 約 30–33 公分 | 經過**乳頭**；**頭圍比胸圍大約 2 公分** |

- 新生兒身體比例：**頭大**（約身長 1/4）、**軀幹長、四肢短**、腹部圓凸
- 頭圍太大（例如 40 公分以上）要想到**水腦**；太小要想到小頭症（先天感染等）
- 評估順序：先做安靜時才能做的（看、聽心肺、聽腹部），再做會讓他哭的（觸診、量體溫、反射）；**腹部先聽診再觸診**

## 頭部 {#head}

- **囟門**

| | 前囟門 | 後囟門 |
|---|---|---|
| 形狀 | **菱形** | **三角形** |
| 大小 | 約 2–3 × 3–4 公分 | 約 0.5–1 公分 |
| 關閉 | **12–18 個月** | **6–8 週**（約 2 個月） |

- 囟門**凹陷** → 脫水；**膨出** → 顱內壓升高（哭的時候會暫時鼓起）；骨縫可輕微重疊
- **胎頭變形**(molding)：顱骨為了通過產道而**重疊**，頭形拉長；**數天到數週**恢復，正常
- 頭皮腫塊比較

| | **產瘤**（胎頭腫塊，caput succedaneum） | **頭血腫**(cephalohematoma) | 帽狀腱膜下出血(subgaleal hemorrhage) |
|---|---|---|---|
| 原因 | 產道或**真空吸引**壓迫 → 頭皮**軟組織水腫** | **骨膜下**血管破裂 → 血液積在骨膜與顱骨之間 | 帽狀腱膜下靜脈破裂（**真空吸引**） |
| 範圍 | **越過骨縫**，界線**不清楚** | **不越過骨縫**，界線**清楚**；可**單側或雙側** | 範圍大、可到頸部與耳後，隨姿勢移動 |
| 觸感 | **鬆軟**、按壓有凹陷 | 較硬、有波動感 | 波動感、越來越大 |
| 出現 | **出生時最明顯** | 出生後 **24–48 小時**才明顯，之後**慢慢變大一點** | 出生後數小時到數天 |
| 消失 | **數天內**（約 2–3 天） | **數週到 3 個月**；吸收時可**加重黃疸**、少數鈣化 | 可大量失血、休克 → **急症** |
| 處置 | 不用處理，向家長解釋 | 不抽吸（避免感染），觀察黃疸與血紅素 | 監測頭圍、生命徵象、輸血 |

::questions{ids="107-1_OP_047,108-2_OP_028,106-1_OP_028,115-1_OP_017,114-2_OP_018,105-1_OP_027"}

## 臉與五官 {#face}

- **耳**：耳廓上緣應和**內外眼眥連線**（眼角延長線）**等高**；**低位耳** → 染色體異常（例如唐氏症）、腎臟異常；耳前小孔、耳垂附屬物也要記錄
- **眼**：出生時可**眼瞼水腫**；**結膜下出血**（產道壓迫）正常，1–2 週消失；可看到**紅光反射**（沒有要懷疑白內障或視網膜母細胞瘤）；**能看到約 20 公分**遠的東西、喜歡看人臉與黑白對比；可短暫斜視
- **口**：**艾柏斯坦小珠**（Epstein pearls，硬腭或齒齦上的**白色小珠**）正常，數週消失；**鵝口瘡**擦不掉要治療（見 [[perinatal-infections#neonatal-infections]]）；檢查**唇顎裂**、舌繫帶、新生兒牙
- **鼻**：新生兒**用鼻子呼吸**，鼻塞會呼吸困難；檢查後鼻孔閉鎖
- **頸**：短、皮膚皺摺多；檢查**斜頸**、腫塊、**鎖骨**是否完整（骨折見 [[neonatal-disorders#birth-injuries]]）

::questions{ids="113-1_OP_018"}

## 皮膚 {#skin}

| 表現 | 特徵 | 意義 |
|---|---|---|
| **胎脂**(vernix caseosa) | 白色乳酪狀，皺摺處多 | 保護、保溫；不需要用力洗掉；過期產兒少 |
| **胎毛**(lanugo) | 細軟毛，肩背多 | 早產兒多，足月兒少 |
| **肢端發紺** | 手腳發紫，軀幹粉紅 | **正常**（末梢循環差），出生後數天消失 |
| 斑駁（大理石紋） | 受冷時皮膚出現網狀紋路 | 正常，要保暖 |
| **粟粒疹**(milia) | **鼻尖、下巴**的**白色小點**（皮脂腺阻塞） | 正常，**2–4 週**消失，**不要擠** |
| **毒性紅斑**(erythema toxicum) | 紅斑中間有黃白色小丘疹，**胸腹背**多；出生後 24–48 小時（**4 天內**）出現 | **良性**，**1–3 週**自行消失，**不需治療** |
| **膿疱** | 有膿的小疱 | **異常**，多為**金黃色葡萄球菌**感染，有**傳染性** |
| **蒙古斑**(Mongolian spot) | **臀部、背部、大腿**的**藍灰色**斑，**界線不清楚** | 正常，亞洲人多，約 **1–5 歲**（學齡前）淡化；**不要誤認為瘀傷**（虐待） |
| **鸛咬痕**(salmon patch) | 後頸、眼瞼、額頭的淡紅斑，哭時更紅 | 正常，多在 1–2 年內淡化 |
| **草莓狀血管瘤**（毛細血管瘤） | 出生後數週出現、凸起鮮紅，**先長大再消退** | 多在 **5–10 歲**前**自然消退**，**不是永久** |
| **葡萄酒色斑**(port-wine stain) | 平的**暗紅到紫紅**斑，出生就有 | **永久**、不會消退；臉部三叉神經區要想到 **Sturge-Weber 症候群** → **異常** |
| **瘀點**(petechiae) | **先露部位**的小出血點 | 產道壓迫，**正常**；**全身**散布要想到血小板低或感染 |
| **黃疸** | 皮膚、鞏膜黃 | 出生 **24 小時內**出現 → **病理性**（見 [[neonatal-disorders#hyperbilirubinemia]]） |
| 脫皮 | 手腳脫皮、皮膚乾裂 | 足月兒輕微脫皮正常；明顯脫皮、乾裂見於**過期產兒** |

- **皮膚彈性**(turgor)：捏起**腹部**皮膚看回彈，是評估水分的最佳部位（四肢末端與陰囊不準）
- 膚色看**軀幹與黏膜**（手腳常有肢端發紺）

## 胸、腹與臍帶 {#chest-abdomen}

- **胸**：圓桶狀；**乳房腫大**或有白色分泌物（母親**雌性素**影響），不要擠；劍突可凸出
- **腹**：圓凸、柔軟；**先聽診腸音再觸診**；肝臟可在右肋下 1–2 公分摸到；舟狀腹（凹陷）要想到橫膈疝氣
- **臍帶**：**2 條動脈、1 條靜脈**；**單一臍動脈**要注意合併**腎臟、心臟**等先天異常；觀察出血、分泌物；照護見 [[newborn-care#cord-care]]

## 生殖器與肛門 {#genitalia}

| | 足月 | 早產 |
|---|---|---|
| 男嬰 | **睪丸已下降**到陰囊、**陰囊皺摺多**、色素沉著 | 睪丸在腹股溝或未下降、**陰囊平滑少皺摺** |
| 女嬰 | **大陰唇覆蓋陰蒂與小陰唇** | **陰蒂與小陰唇突出**、大陰唇小 |

- 男嬰：尿道口位置（**尿道下裂**）、包皮不要硬推；陰囊水腫多會自行吸收
- 女嬰：**假月經**、白色陰道分泌物正常（母親雌性素）
- **肛門**：確認通暢（肛門閉鎖）；記錄**第一次解胎便**與**第一次解尿**的時間（多在 24 小時內）

## 四肢、背部與髖關節 {#extremities}

- 姿勢：足月兒**四肢屈曲**（子宮內姿勢）；早產兒**伸展**
- 手指腳趾數目、**通貫掌**（simian crease，唐氏症）、多指併指
- **髖關節**：**Ortolani**（外展時**喀答**一聲復位）、**Barlow**（內收往後推會脫出）、兩側大腿皺摺與膝蓋高度是否對稱 → 發展性髖關節發育不良（見 [[pediatric-musculoskeletal]]）
- 足部：先天性馬蹄內翻足
- 背部：脊柱是否直、有無**薦尾部小凹、毛叢、腫塊**（脊柱裂，見 [[pediatric-neuro]]）
- 肌張力：把手臂拉直再放開，看**回彈**屈曲的程度

## 成熟度評估：New Ballard Score {#ballard}

- 用途：用**神經肌肉成熟度 6 項**＋**身體成熟度 6 項**，估計**妊娠週數**（可評 20–44 週）
- 時間：出生後 **12–24 小時內**最準（國考：足月兒**出生後 24 小時內**）；極早產兒越早越好
- 原則：早產兒**肌張力低、關節鬆**，所以被動姿勢的**角度大**、手腳**容易拉過去**

### 神經肌肉成熟度 {#neuromuscular}

| 項目 | 做法 | 早產兒 | 足月兒 |
|---|---|---|---|
| **姿勢**(posture) | 安靜**平躺**時看四肢 | 四肢**伸展**、放鬆 | 四肢**屈曲**、內收 |
| **方形窗**(square window) | 把手腕往**前臂屈側**彎，看手掌和前臂的角度 | 角度大（**90 度**，極早產 > 90 度） | 角度小（**0 度**） |
| **手臂反彈**(arm recoil) | 手肘**彎曲 5 秒**後拉直放開，看反彈後的肘角 | 反彈慢、角度大（接近 180 度） | 很快彈回屈曲，角度 < 90 度 |
| **膝膕角**(popliteal angle) | 平躺、大腿貼腹部，伸直小腿，看膝後角度 | 角度大（**140–180 度**） | 角度小（< 90 度） |
| **圍巾徵象**(scarf sign) | 把手臂拉過胸前往**對側肩膀**，看**手肘**的位置 | 手肘可**越過中線**、甚至到對側 | 手肘**不能越過中線** |
| **足跟至耳**(heel to ear) | 把腳往同側耳朵拉 | **容易拉到耳朵** | 拉不到耳朵、有阻力 |

### 身體成熟度 {#physical-maturity}

| 項目 | 早產兒 | 足月兒 | 過期產兒 |
|---|---|---|---|
| **皮膚** | 薄、紅、**透明**、**看得到血管** | 較厚、表淺脫皮、**看不太到血管** | 乾裂、**像羊皮紙**、脫皮多 |
| **胎毛** | **多**（極早產沒有） | 少、局部 | 幾乎沒有 |
| **足底皺摺** | 少，只有**前段**有橫紋 | 前 2/3 以上到**整個足底** | 整個足底、深 |
| **乳房** | 乳暈**平**、幾乎摸不到乳房組織 | 乳暈**突起**、乳房組織 **3–4 mm 以上**（到 5–10 mm） | |
| **眼與耳** | 眼瞼可能**黏合**；耳廓**平、軟**、摺起後**慢慢**回彈或不回 | 眼瞼張開；耳軟骨**硬**、**成形**、摺起**立刻回彈** | |
| **生殖器（男）** | 陰囊**平滑**、睪丸**未降** | 睪丸**下降**、陰囊**皺摺多** | 皺摺深 |
| **生殖器（女）** | **陰蒂與小陰唇突出** | **大陰唇覆蓋陰蒂與小陰唇** | |

## 新生兒分類 {#classification}

- 依**妊娠週數**

| 分類 | 週數 |
|---|---|
| **早產兒** | **< 37 週**（晚期早產 34⁰⁄₇–36⁶⁄₇ 週；極早產 < 32 週；超早產 < 28 週） |
| **足月兒** | **37⁰⁄₇–41⁶⁄₇ 週** |
| **過期產兒** | **≥ 42 週** |

- 依**出生體重**

| 分類 | 體重 |
|---|---|
| 低出生體重(LBW) | **< 2,500 公克** |
| 極低出生體重(VLBW) | **< 1,500 公克** |
| 超低出生體重(ELBW) | **< 1,000 公克** |
| 巨嬰 | **≥ 4,000 公克**（也有用 4,500） |

- 依**體重與週數的關係**（對照生長曲線）

| 分類 | 定義 | 常見原因與問題 |
|---|---|---|
| **SGA** 小於妊娠年齡 | 體重 **< 第 10 百分位** | 子宮內生長遲滯（胎盤功能不良、高血壓、抽菸、先天感染、染色體異常）；**低血糖**、低體溫、紅血球增多症、胎便吸入 |
| **AGA** 適於妊娠年齡 | 第 10–90 百分位 | |
| **LGA** 大於妊娠年齡 | 體重 **> 第 90 百分位** | **糖尿病母親**、遺傳；**低血糖**、產傷（**鎖骨骨折**、臂神經叢損傷）、呼吸窘迫 |

- 例：30 週出生 2,400 公克 → 30 週平均約 1,500 公克，遠大於第 90 百分位 → **LGA**（同時也是早產兒、低出生體重）
- **過期產兒**特徵：皮膚**乾裂脫皮**、胎脂與胎毛少、指甲長、警覺；**胎盤功能不良**、**胎便吸入**、低血糖、紅血球增多症風險高（見 [[labor-complications#post-term]]）
