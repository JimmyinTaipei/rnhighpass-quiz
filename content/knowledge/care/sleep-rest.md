睡眠是**主動**的生理過程，由視丘、腦幹與下視丘的生理時鐘調控，讓大腦修補、鞏固記憶、調節情緒與免疫。住院病人因疼痛、噪音、夜間治療與焦慮，睡眠常被打斷。本頁整理**睡眠週期與各期特性**、**影響睡眠的因素與藥物**、**失眠標準**與**促進睡眠的護理**。精神科的睡眠障礙與失眠用藥見 [[anxiolytics-hypnotics]]、[[depressive-disorder]]

## 重點摘要 {#summary}

- 睡眠分**非快速動眼期(NREM, non-rapid eye movement)** 與**快速動眼期(REM, rapid eye movement)**；一個週期約 **90 分鐘**，成人一晚約 **4–6 個週期**（課本；國考答案也接受 4–5 個）
- 週期順序：NREM 1 → 2 → 3 → 4 → 3 → 2 → **REM**；**前半夜深睡（3、4 期）多，後半夜 REM 多**
- NREM 第 2 期占總睡眠最多（約 40–45%）；第 3、4 期（慢波、深睡）**極難叫醒**，**生長激素分泌最多**、蛋白質合成、**基礎代謝率下降 10–30%**、血壓下降；**尿床、夢遊、打鼾、磨牙**多在 4 期
- REM：腦波像清醒、**作生動彩色的夢且醒來記得**、**記憶與學習**、肌肉張力最低、心跳呼吸血壓不規則、**胃酸與腎上腺素增加**（胃潰瘍夜間痛）；在 REM 被吵醒要**從 NREM 第 1 期重新開始**
- 年齡：嬰兒 REM 約 50%、成人約 20–25%；**老人總睡眠、深睡期、REM 都減少**，淺睡與夜醒增加、早睡早醒
- 影響睡眠的藥物：**安眠藥與鎮靜劑**減少 REM 與深睡、停藥反彈惡夢；**酒精**讓人好入睡但中斷 REM、半夜醒；**利尿劑**夜尿；**digoxin 惡夢**；**β 阻斷劑**睡眠障礙；**咖啡因、尼古丁**延長入睡；色胺酸（牛奶、香蕉）助眠
- 失眠（國際睡眠障礙分類 ICSD, International Classification of Sleep Disorders）：**入睡超過 30 分鐘**、整晚醒著超過 40 分鐘或**夜醒超過 2 次且每次超過 5 分鐘**、早醒 30 分鐘以上、**總睡眠少於 6.5 小時**、**睡眠效率成人 < 80%**（青少年 < 90%、老人 < 65%）
- 護理：規律作息、**白天少睡、午睡不要太長**、睡前 4–5 小時以前運動、**午後不喝含咖啡因飲料**、睡前少喝水並排空膀胱、床只用來睡、**20 分鐘睡不著就起床**、減少夜間噪音與燈光、**集中護理**、睡前背部按摩或溫水拭浴、依醫囑睡前 30 分鐘給止痛藥

### 國考常考點 {#exam-points}

- 夢境在 **REM** 發生、醒後最容易記得(109-2_FA_045)
- 睡眠功能：**NREM 時血壓下降、REM 幫助記憶學習、REM 夢境生動且彩色**(107-2_FA_049)；REM 時新陳代謝**加速**（說減緩是錯的）
- 正確敘述：生物時鐘影響入睡、一生 1/3 在睡覺、**成人一晚 4–5 個週期**、**NREM 基礎代謝率下降**；前半夜 REM 較多是錯的、被中斷不會從那一期再睡(105-1_FA_050)
- NREM 第 4 期減少的原因：老人、鎮靜劑、發燒；**高血脂不是**(107-1_FA_047)
- 68 歲多重用藥、晚上開燈睡：影響睡眠的是**多重用藥、digoxin 易惡夢、夜間燈光太亮**(106-2_FA_049)；改善：**睡前 2–4 小時少喝水、請醫師調整多重用藥、夜間光線調暗**；白天多次小睡、長期安眠藥是錯的(106-2_FA_050)
- 術後疼痛睡不好：「**建議白天多休息以減少疲倦**」是錯的(108-1_FA_045)；冠狀動脈繞道術後：依醫囑給 **acetaminophen**、睡前**溫水拭浴**；睡前喝紅茶牛奶（含咖啡因）、睡前 1 小時做關節運動不適當(108-1_FA_055)
- 失眠標準：**成人睡眠效率 85% 未達失眠**（< 80% 才算）；老人入睡超過 40 分鐘、夜醒 2–4 次每次超過 10 分鐘、成人每晚只睡 5 小時都達標準(110-2_FA_047)

## 休息與睡眠的概念 {#concepts}

1. **休息**：身體停止或改變活動，加上精神放下焦慮，兩者兼具才是真正的休息
2. **睡眠**：主動的過程；對外界刺激反應降低，但**有意義的刺激**（叫名字、寶寶哭聲）仍可叫醒
3. 調控：視丘與腦幹的網狀活化系統、下視丘的生理時鐘；**褪黑激素**由松果體在夜間分泌（高峰約晚上 11 點到清晨 3 點），**光線會抑制**分泌，見 [[brain-anatomy]]
4. 目的：大腦修補、鞏固記憶、調節情緒與免疫、組織修復

## 睡眠週期與各期 {#sleep-stages}

| 期 | 特性 | 生理變化 |
|---|---|---|
| **NREM 1**（最淺） | 入睡過渡期，只有數分鐘；**容易叫醒**；有漂浮感、肢體抽動 | 肌肉放鬆、眼球緩慢轉動 |
| **NREM 2**（淺睡） | **占總睡眠最多(40–45%)**；對外界刺激反應變少，但仍容易叫醒 | 心跳、呼吸、體溫漸降 |
| **NREM 3**（熟睡） | 慢波出現，**很難叫醒** | 肌肉鬆弛、生命徵象變慢、**血壓下降** |
| **NREM 4**（沉睡） | **極難叫醒**；最需要的修復期 | **基礎代謝率下降 10–30%**、**生長激素分泌最多**、**蛋白質合成**；**尿床、夢遊、打鼾、磨牙** |
| **REM**（活動性睡眠） | 腦波活躍像清醒；**作生動彩色的夢、醒後記得**；**記憶與學習** | 快速眼動、**全身肌肉張力最低**；心跳、呼吸、血壓**不規則、上升**；**胃酸**分泌增加、腎上腺素增加、代謝加速；男性勃起 |

1. 課本說明：新版分期已把 NREM 第 3、4 期合併為 N3；國考仍用四期
2. 一個完整週期約 **90 分鐘**，一晚 4–6 個；前半夜 3、4 期較多，越到天亮 **REM 越長**
3. 在 REM 被中斷，再入睡要**從 NREM 第 1 期開始**
4. 年齡變化：嬰兒睡最多、REM 約 50%；**老人**總睡眠時數、**3、4 期與 REM 減少**，1、2 期增加、夜醒多、睡眠效率差、白天打盹

## 影響睡眠的因素 {#factors}

| 因素 | 例子 |
|---|---|
| 生理 | 疼痛、發燒、咳嗽、呼吸困難、夜尿、胃食道逆流、皮膚癢；老化；女性月經、懷孕、更年期 |
| 心理 | 壓力、焦慮、憂鬱、害怕、失落 |
| 環境 | 噪音、燈光（含手機與 3C 藍光）、陌生病房、溫度、床墊 |
| 生活型態 | 作息不規律、輪班、時差；**睡前 3 小時內激烈運動**、睡前過飽或太餓 |
| 飲食 | **咖啡因**（咖啡、茶、可樂、巧克力）、**尼古丁**延長入睡；**酒精**抑制 REM；**色胺酸**（牛奶、乳酪、香蕉、堅果、豆類）、鈣、鎂幫助睡眠 |
| 社會支持 | 支持少者易情緒低落、睡不好 |

### 影響睡眠的藥物 {#drugs}

| 藥物 | 影響 |
|---|---|
| 安眠藥 | 抑制 REM、減少 NREM 3、4 期、早醒；**長期用、突然停會反彈惡夢**；療程以 4–6 週為原則 |
| 鎮靜劑（benzodiazepine、barbiturate） | REM 與 NREM 3、4 期減少，第 1 期增加 |
| 酒精 | 容易入睡，但中斷 REM，清晨 2–3 點醒來 |
| 抗憂鬱劑、安非他命 | 減少 REM |
| **digoxin**（毛地黃） | **易惡夢**，見 [[digoxin]] |
| **β 阻斷劑** | 可能引起睡眠障礙、惡夢，見 [[beta-blockers]] |
| 利尿劑 | 夜尿；盡量白天服用 |
| 老人多重用藥 | 睡眠中斷 |

## 睡眠障礙 {#sleep-disorders}

### 失眠 {#insomnia}

1. DSM-5(Diagnostic and Statistical Manual of Mental Disorders, 5th edition)失眠：對睡眠質或量不滿意，有入睡困難、維持困難或早醒，**每週至少 3 晚、持續至少 3 個月**
2. 分型：**入睡困難型**（焦慮、身體不適）、**睡眠維持困難型**（憂鬱、身體疾病）；依病程分短暫性（< 1 週）、短期（1 週–1 個月）、慢性（> 1 個月）

| ICSD 失眠描述（課本上冊 459–460） | 標準 |
|---|---|
| 入睡困難 | 上床到入睡**超過 30 分鐘** |
| 睡眠不實 | 整晚醒著總共**超過 40 分鐘**，或醒著時間占總睡眠 10% 以上，或**夜醒超過 2 次且每次超過 5 分鐘** |
| 早醒 | 比平常早醒 **30 分鐘以上** |
| 時數或效率不足 | 總睡眠**少於 6.5 小時**；睡眠效率（實際睡著時間 ÷ 躺床時間）**成人 < 80%**、青少年 < 90%、老人 < 65% |

::questions{ids="110-2_FA_047"}

### 嗜睡與睡眠剝削 {#hypersomnia-deprivation}

1. 嗜睡：主要睡眠至少 7 小時仍過度想睡，每週至少 3 次、超過 3 個月；原因如睡眠呼吸中止、REM 失調
2. 阻塞性睡眠呼吸中止(OSA, obstructive sleep apnea)：睡時上呼吸道軟組織塌陷，打鼾、白天嗜睡
3. 睡眠剝削(sleep deprivation)的表現

| 被剝削的睡眠 | 表現 |
|---|---|
| **REM** | 興奮、躁動、情緒不穩、注意力不集中、多疑、混亂、對痛敏感；癲癇病人易發作 |
| **NREM** | 退縮、冷漠、反應慢、身體不適、白天睡太多；**生長激素減少，影響組織修補** |
| 兩者 | 疲倦、頭痛、視力模糊、判斷與記憶下降；嚴重時錯亂、幻覺（長住加護病房者） |

## 促進睡眠的護理 {#interventions}

### 評估 {#assessment}

1. 睡眠史：平常就寢與起床時間、夜醒次數、總時數、品質、睡前習慣（小酌、熱水澡、3C）、壓力事件、用藥（安眠藥、類固醇、利尿劑）、環境
2. 觀察：黑眼圈、打哈欠、疲倦、易怒、注意力與記憶下降

### 措施 {#measures}

| 類別 | 做法 | 原理 |
|---|---|---|
| 規律作息 | 固定起床與就寢時間；**寧可少睡也不要貪睡** | 穩定生理時鐘 |
| 白天活動 | **白天少睡、午睡不要太長**；安排白天活動 | 累積睡意 |
| 運動 | 規律中量運動，在**睡前 4–5 小時以前**；睡前不劇烈運動、不做關節訓練 | 太接近睡前交感神經興奮 |
| 飲食 | **午餐後不喝茶、咖啡、可樂**；睡前不抽菸喝酒；可喝**熱牛奶** | 咖啡因與尼古丁興奮；色胺酸助眠 |
| 排尿 | **睡前 2–4 小時少喝水、睡前排空膀胱**；夜尿多者膀胱訓練；利尿劑白天服 | 減少夜醒 |
| 刺激控制 | **床只用來睡覺**；**躺 20 分鐘睡不著就起床**離開，想睡再回床 | 建立床與睡眠的連結 |
| 3C | 睡前避免長時間看手機與螢幕 | 藍光抑制褪黑激素 |
| 環境 | 關燈或調暗、拉床簾、調室溫、降低電話與說話音量、推車輪子上油 | 減少干擾 |
| **集中護理** | 夜間治療與給藥**集中安排**，避免不必要的叫醒；限制睡前訪客 | 保留完整睡眠週期 |
| 身體舒適 | 合適睡姿（呼吸困難用半坐臥）、管路長度適當；睡前**背部按摩、溫水拭浴、熱水泡腳** | 放鬆 |
| 疼痛 | 依醫囑**睡前 30 分鐘**給止痛藥（如 acetaminophen）或冷熱敷 | 疼痛最常打斷睡眠 |
| 安眠藥 | 短期輔助（4–6 週）；**吃了直接上床**、不外出不上下樓；8 小時內不開車或操作機械；起床仍昏沉要換短效藥 | 防跌倒與依賴 |

1. 老人：避免長期安眠藥；多重用藥請醫師檢討；夜間保留小夜燈防跌但光線不要太亮，見 [[patient-safety-environment]]
2. 背部按摩手法見 [[hygiene-comfort-care#back-care]]；疼痛處置見 [[pain-management]]

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 睡不好就白天多休息、多次小睡 | 白天少睡、維持規律 | 白天睡多晚上更難睡 |
| 前半夜 REM 較多 | 後半夜 REM 較多 | 前半夜以深睡為主 |
| 在哪一期醒來就從哪一期再睡 | 從 NREM 1 重新開始 | 週期要重來 |
| REM 新陳代謝減緩 | 新陳代謝加速 | 腦部活躍 |
| 睡前喝紅茶牛奶、睡前做運動 | 熱牛奶可以、紅茶含咖啡因；運動提前 | 刺激交感神經 |
| 長期吃安眠藥改善睡眠 | 短期輔助 | 依賴、REM 減少、反彈 |
| 睡眠效率 85% 算失眠 | 成人 < 80% 才算 | ICSD 標準 |
