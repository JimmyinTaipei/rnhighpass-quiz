化學治療、放射治療與標靶治療除了殺死癌細胞，也會傷害**分裂快速的正常組織**，而腫瘤本身也可能引起需要立即處理的**腫瘤急症**。本頁整理護理師最常處理的副作用與急症；各藥物的特有毒性見 [[antineoplastics]]，血球判讀見 [[complete-blood-count]]，疼痛見 [[pain-management]]。

## 骨髓抑制 {#myelosuppression}

化療後白血球、血小板、紅血球在約 **7–14 天**降到最低(nadir)，約 3–4 週恢復。三條血球線對應三個護理重點：**感染、出血、貧血**。

### 嗜中性白血球低下與感染 {#neutropenia}

![[complete-blood-count#anc]]

#### 為什麼感染很危險 {#infection-risk}

- **感染是癌症病人死亡的主要原因之一**。
- 嗜中性白血球太少時，**發炎反應不明顯**：可能**沒有膿、紅腫不明顯**，肺炎的 X 光也可能不典型，**發燒常是唯一的徵象**。
- 感染來源多是病人**自己的腸道與皮膚菌**，經由受損的黏膜、導管進入血液。

#### 嗜中性白血球低下發燒(醫療急症) {#febrile-neutropenia}

- 定義：**口溫單次 ≥ 38.3°C**，或 **≥ 38.0°C 持續 1 小時**；加上 **ANC < 500/μL**(或預期 48 小時內降到 < 500)。
- 處置：立即通知醫師，**先抽血液培養**(周邊與導管各一套)，**1 小時內**給**廣效抗生素**；**未確立致病菌前就先用廣效抗生素**(來源：[UpToDate](https://www.uptodate.com/contents/overview-of-neutropenic-fever-syndromes)；[ASCO／IDSA 2018](https://doi.org/10.1200/JCO.2017.77.6211))。
- 監測生命徵象(敗血性休克)、尿量、意識。
- 病人衛教：**發燒不要自己吃退燒藥**，要**立即回院**；每天量體溫。
- 發燒時**避免 NSAIDs 與 aspirin 退燒**(遮蔽發燒、增加出血風險)。
- **不量肛溫、不用肛門塞劑、不灌腸**：可能造成黏膜破損、細菌入血與出血。

#### 感染預防措施 {#infection-prevention}

| 措施 | 重點 |
|---|---|
| **手部衛生** | **最重要**的措施；接觸病人前後都要洗手 |
| 保護性隔離 | 國考：**ANC < 500/μL** 採**保護性隔離**(單人房、戴口罩、訪客限制)，**不是負壓隔離**(負壓用於空氣傳染病人)。實務上，一般化療病人以**標準防護與手部衛生**為主；高效率過濾(HEPA)的**正壓**保護環境主要用於**異體造血幹細胞移植** |
| 避免接觸感染源 | 不接觸感冒、**水痘、麻疹**病人；少去人多的公共場所；外出戴口罩 |
| **疫苗** | 化療期間**不可接種活性減毒疫苗**(水痘、MMR、輪狀病毒、口服沙賓、卡介苗)；**不活化疫苗可以打**(流感、四合一 Tdap-IPV)。家人應接種流感疫苗 |
| 皮膚黏膜 | 每天沐浴、會陰清潔；**口腔護理**；避免侵入性處置；導管部位無菌照護 |
| **飲食** | 食物要**完全煮熟**、**徹底洗淨**；避免**生魚片、生菜沙拉、半熟蛋(溏心蛋)**、未殺菌乳品、**含活菌的發酵食品**(優格、養樂多、泡菜)。可以吃**洗淨去皮的水果**(如柑橘) |
| 環境 | 傳統教材：病房不放**鮮花、盆栽**與積水容器；不清理寵物排泄物 |
| **G-CSF** | 皮下注射，刺激骨髓製造嗜中性白血球，縮短低下期；副作用**骨頭痛** |

:::note[低微生物飲食的新證據]
國考仍以「避免生食、禁食生食」為答案。研究顯示嚴格的「中性白血球低下飲食」並沒有比**一般的食品安全原則**(煮熟、洗淨、避免生食與未殺菌食品)更能減少感染；台灣醫院多採食品安全原則(來源：[UpToDate](https://www.uptodate.com/contents/overview-of-neutropenic-fever-syndromes))。
:::

### 血小板減少與出血 {#thrombocytopenia}

- 分級與輸注門檻見 [[complete-blood-count#platelets]]。血小板 **< 10,000/μL** 要注意**顱內出血**：評估**意識狀態**、頭痛、瞳孔。
- **出血徵象**：瘀點、瘀斑、牙齦出血、流鼻血、黑便、血尿、月經過多、頭痛與意識改變。
- **預防措施**：
  - 用**軟毛牙刷**；血小板很低時改用**海綿潔牙棒**；不用牙線、牙籤、牙縫刷。
  - 用**電動刮鬍刀**；避免碰撞與跌倒；穿軟底鞋。
  - **避免肌肉與皮下注射、量肛溫、肛門塞劑、灌腸**。
  - 以**口服軟便劑**預防便秘與用力排便；不擤鼻太用力；**天冷時鼻黏膜塗凡士林保濕**。
  - **避免 aspirin、NSAIDs**；有出血傾向時限制使用抗凝血藥(warfarin、heparin)。
  - 抽血或注射後**加壓 5–10 分鐘**。
- 依醫囑輸注**血小板**；嚴重自發性出血時輸注，不是輸「凝血因子」。

### 貧血與疲憊 {#anemia-fatigue}

- 原因：骨髓抑制、出血、營養不良、腎功能下降；**全胃切除**(缺內在因子 → 維生素 B12 吸收差)、脾臟切除也會影響。
- 表現：**蒼白、疲倦、心跳加快**、呼吸喘、頭暈、**血壓可能下降**(不是心跳變慢、血壓上升)。
- 處置：依醫囑輸**紅血球濃厚液**、紅血球生成素；補充**鐵與葉酸**(紅肉、深綠色蔬菜)；**集中護理**讓病人休息；起身要慢，預防跌倒。
- **癌因性疲憊**是最常見的症狀之一，**休息無法完全緩解**：鼓勵**適度的規律運動**(散步)，不是長時間臥床；安排活動與休息、節省體力。

## 口腔併發症 {#oral}

### 口腔黏膜炎 {#mucositis}

- 化療(5-FU、methotrexate、蒽環類)與**頭頸部放療**最常見，約在化療後 **5–14 天**出現。
- WHO 分級：**0** 無；**1** 疼痛、紅斑；**2** 紅斑、潰瘍，**仍可吃固體**；**3** 潰瘍，**只能吃流質**；**4** **無法由口進食**。
- **口腔評估**每天做；**白斑擦不掉** → 念珠菌感染；小水泡或潰瘍 → 可能是單純疱疹。

| 措施 | 做法 |
|---|---|
| 清潔 | **軟毛牙刷**，每餐後與睡前刷牙；以**生理食鹽水**或**小蘇打水**(碳酸氫鈉)頻繁漱口；血小板很低時用海綿棒 |
| **不要用** | **含酒精的市售漱口水**、**雙氧水(過氧化氫)**、檸檬甘油棒：會刺激或破壞黏膜 |
| 止痛 | **進食前**依醫囑用局部麻醉漱口液(**xylocaine** 溶液)；**第 4 級**或疼痛嚴重時**規律給全身性止痛藥**(常需鴉片類)。局部麻醉劑是止痛用，**不是**用來清潔舌苔 |
| 抗發炎 | 依醫囑使用含類固醇的口內膏 |
| 念珠菌感染 | **Nystatin**(Mycostatin)是**抗黴菌藥**(不是抗細菌)：在**進食與口腔清潔後**使用，含漱後**吞下**(同時治療食道)，依醫囑也可能只漱口；**安排在其他漱口之後**，避免被沖掉 |
| 預防 | 給予**推注型 5-FU** 或高劑量 melphalan 時，**含冰塊約 30 分鐘**(口腔冷凍療法)可減輕黏膜炎(來源：[UpToDate](https://www.uptodate.com/contents/oral-toxicity-associated-with-systemic-anticancer-therapy)；[MASCC／ISOO 2020](https://doi.org/10.1002/cncr.33100)) |
| 飲食 | **軟質、溫涼、清淡**；避免辛辣、酸、過燙、粗硬與酒精；嘴唇塗保濕劑 |

- 意識不清、口腔有**擦不掉的白斑合併潰瘍與疼痛** → 與醫師討論 **xylocaine 加 nystatin** 處方。

### 口乾與放療的口腔影響 {#xerostomia}

- **頭頸部放療**會破壞**唾液腺** → 口乾、味覺改變、蛀牙與感染風險增加；味覺多在治療後數月逐漸恢復，唾液腺損傷可能持久。
- 若無禁忌，每天喝水 **2,000–3,000 mL**，隨時小口喝水；**咀嚼**(無糖口香糖)可刺激唾液、維持濕潤；人工唾液。
- 治療前先**處理蛀牙**與牙周病，治療中與治療後用**含氟**牙膏，避免**放射性骨壞死**。
- **張口運動**的目的是**預防牙關緊閉**(咀嚼肌纖維化)，不是促進唾液分泌。
- 活動假牙在黏膜炎時要取下，不要整天配戴。

## 放射治療的皮膚與局部反應 {#radiation-skin}

### 急性皮膚反應 {#radiation-skin-grades}

約在治療開始 **2–3 週後**出現，依序為：**紅斑敏感 → 乾性脫屑**(乾燥、搔癢、脫皮)→ **濕性脫屑**(表皮剝落、滲液)。**色素沉著**與纖維化、微血管擴張屬於較晚期的變化(考題以「色素沉著不是急性反應」為答案)。

### 照射部位皮膚照護 {#radiation-skin-care}

| 項目 | 做法 |
|---|---|
| **皮膚標記** | **保持完整、不可洗掉**；模糊時請放射治療人員補畫 |
| 清潔 | 用**溫水輕柔清洗、輕拍乾**，**不可搓洗**。國考答案「照射處只用清水」；UpToDate 指出**溫和的中性洗劑**清洗不會加重皮膚炎，依院內衛教 |
| **不可冷熱敷** | 不用冰敷、熱敷、熱水袋、烤燈 |
| 防曬 | 避免陽光直射，外出**撐傘、戴帽**；治療結束後一年仍要防曬 |
| 衣物 | 寬鬆、柔軟的棉質衣物；不綁緊 |
| 避免刺激 | 不貼**膠布**、不擦含酒精或香料的產品、不抓；刮鬍子只用**電動刮鬍刀** |
| 乾性脫屑、搔癢 | 依醫囑擦**水性保濕乳液**或**低效類固醇**乳膏 |
| **濕性脫屑** | **生理食鹽水**沖洗，覆蓋**親水性敷料**(例：DuoDerm)或不沾黏敷料；依醫囑塗氧化鋅等藥膏；觀察感染 |
| 頭部照射 | 頭髮在照射範圍內會掉：用溫和洗髮精、**先梳髮尾再梳髮根**、避免吹風機熱風直吹、不用酒精 |

(來源：[UpToDate：Radiation dermatitis](https://www.uptodate.com/contents/radiation-dermatitis))

### 依照射部位的其他反應 {#radiation-site-effects}

| 部位 | 反應與護理 |
|---|---|
| **頭頸部**(鼻咽癌、口腔癌) | 口腔黏膜炎、**口乾**、味覺改變、吞嚥痛、**牙關緊閉**；鼻咽癌可能**中耳積液、聽力下降**(治療前評估聽力)。飲食以**軟質、細碎、濕潤、易吞嚥**為主，**不是高纖粗糙食物** |
| **胸部**(肺癌、乳癌、食道癌) | **放射性食道炎**(吞嚥痛、胸口灼熱)、放射性肺炎(乾咳、喘) |
| **腹部與骨盆腔**(子宮頸癌、直腸癌) | **腹瀉**：**低渣飲食**、**減少乳製品**(暫時性乳糖不耐)、補充水分、依醫囑止瀉劑；**膀胱炎**(頻尿、解尿痛)：多喝水 |
| 腦部 | 掉髮、疲倦、腦水腫(頭痛、嘔吐，依醫囑用類固醇) |
| 全身 | **疲倦**、食慾下降；照射範圍內的骨髓也會受抑制 |

## 其他常見副作用 {#other-toxicities}

### 噁心嘔吐 {#nausea}

- 預防性止吐藥與分類見 [[antineoplastics#antiemetics]]。
- **少量多餐**、選擇**高熱量高蛋白**、清淡、冷食或室溫食物；避免油膩、甜膩、氣味濃的食物；飯後坐著休息。
- 同理並給予具體建議，不要只說「過幾天就好」或推薦偏方。

### 掉髮 {#alopecia}

- 多在化療後 **2–3 週**開始；**大多是暫時的**，治療結束後數月會長回來(髮質、顏色可能不同)。告訴病人「掉髮不可逆」是錯的。
- 鼓勵**表達感受**；討論**頭巾、帽子、假髮**；介紹年齡相仿的病友分享經驗(青少年特別在意身體形象)。
- 用溫和洗髮精、軟梳，避免燙染與高溫吹整；頭皮防曬保暖。

### 腸道與其他 {#bowel-other}

- **腹瀉**：irinotecan、5-FU、骨盆腔放療 → 補充水分電解質、低渣飲食、依醫囑止瀉；肛門周圍皮膚保護。
- **便秘**：vincristine、鴉片類、止吐藥(5-HT3 拮抗劑)、活動少 → 水分、纖維、**軟便劑**。
- **周邊神經病變**：vincristine、紫杉醇、鉑金類 → 注意燙傷與跌倒。
- **生育**：治療前討論**精子或卵子冷凍保存**；治療期間要**避孕**(致畸胎)。

### 營養與惡病質 {#nutrition}

- **食慾不振**的原因包括腫瘤細胞激素、味覺改變、噁心、疼痛，以及**焦慮與憂鬱**；評估時要注意情緒對食慾的影響。
- 少量多餐、**高熱量高蛋白**、在感覺最好的時段吃最多；肉類變難吃時改用蛋、豆、魚、乳品補蛋白(嗜中性白血球低下時要煮熟、選殺菌產品)。
- 兒童：讓孩子**參與選擇與準備餐點**、用有趣的擺盤；定期量體重。
- 定期**量體重**、評估營養指標；必要時營養師會診、管灌或靜脈營養。

## 腫瘤急症 {#oncologic-emergencies}

| 急症 | 常見癌症 | 主要表現 | 處置重點 |
|---|---|---|---|
| **嗜中性白血球低下發燒** | 化療後 | 發燒(可能是唯一徵象) | 血液培養後 **1 小時內**廣效抗生素 |
| **腫瘤溶解症候群** | 白血病、**勃氏淋巴瘤**等**生長快、對化療敏感**的腫瘤 | 高鉀、高磷、**低鈣**、高尿酸、急性腎損傷 | **大量輸液**、allopurinol、rasburicase、監測電解質 |
| **上腔靜脈症候群** | **肺癌**(尤其小細胞肺癌)、淋巴瘤 | **臉與頸部腫脹**、頸靜脈怒張、**呼吸困難**、頭痛 | **半坐臥**、給氧；確立病理後放療或化療，嚴重時**血管支架** |
| **脊髓壓迫** | **乳癌、肺癌、攝護腺癌**、多發性骨髓瘤 | **背痛**(最早)、無力、感覺異常、**大小便失禁** | 立即**高劑量類固醇**、MRI、放療或手術 |
| **高血鈣** | 骨轉移(乳癌、肺癌)、**多發性骨髓瘤** | **意識混亂、嗜睡、虛弱、心律不整、嘔吐、便秘**、多尿脫水 | **大量生理食鹽水**、**雙磷酸鹽**(zoledronic acid，Zometa)、calcitonin |
| **SIADH** | **小細胞肺癌** | **低血鈉**、意識改變、抽搐 | **限水**、監測血鈉與意識 |

### 腫瘤溶解症候群 {#tumor-lysis}

- 大量癌細胞**同時被殺死**(通常在化療後 12–72 小時)，細胞內物質湧入血液：
  - **高尿酸**(核酸代謝)→ 尿酸結晶堵塞腎小管 → **急性腎損傷**
  - **高血鉀** → 心律不整
  - **高血磷** → 與鈣結合沉積 → **低血鈣**(抽搐、心律不整)
  - **不會高血鈣**、不會造成尿糖異常
- **預防**：
  - 化療前開始**大量靜脈輸液**，維持高尿量；**不可限制水分**或「減少輸液降低心臟負擔」。
  - **Allopurinol**(減少尿酸生成)；高風險者用 **rasburicase**(分解尿酸；**G-6-PD 缺乏症禁用**)。
  - 每 4–6 小時監測**尿量、鉀、磷、鈣、尿酸、肌酸酐**與心電圖。
- **治療**：高血鉀依醫囑處理(**Kayexalate 用來降血鉀**，不是降血鈉)，必要時**血液透析**。不需要預防性類固醇或抗組織胺。

:::note[鹼化尿液]
舊教材的預防措施包括在輸液中加**碳酸氫鈉鹼化尿液**，國考也曾把它當成正確處置。UpToDate 現在**不建議常規鹼化尿液**：沒有證據改善預後，且可能促進磷酸鈣沉積(來源：[UpToDate：TLS](https://www.uptodate.com/contents/tumor-lysis-syndrome-prevention-and-treatment))。
:::

### 上腔靜脈症候群 {#svc-syndrome}

- 縱膈腔腫瘤或淋巴結**壓迫上腔靜脈**，上半身的血液無法回流；**最常見的原因是肺癌**(非小細胞與小細胞)，其次是淋巴瘤(來源：[UpToDate](https://www.uptodate.com/contents/malignancy-related-superior-vena-cava-syndrome))。
- 表現：**臉、頸部與上肢水腫**、臉部潮紅、**頸靜脈與胸壁靜脈怒張**、**呼吸困難**、咳嗽、頭痛、頭脹；**平躺或彎腰時加重**，所以**早上起床時最明顯**(不是晚上)。
- 護理：**半坐臥或高坐臥**、給氧、減少焦慮；**避免在上肢量血壓、打針或輸液**；觀察呼吸道阻塞與意識變化。
- 治療：先確立病理診斷，依癌症類型做**放射治療或化學治療**；症狀嚴重時放置**血管內支架**可最快緩解。

### 脊髓壓迫 {#spinal-cord-compression}

- 多由脊椎骨轉移的腫瘤壓迫硬膜外；**約 60–70% 發生在胸椎**(來源：[UpToDate](https://www.uptodate.com/contents/clinical-features-and-diagnosis-of-neoplastic-epidural-spinal-cord-compression))。
- 表現：**背痛最早出現**(躺下、咳嗽時更痛)→ 下肢無力、感覺異常 → **大小便失禁或尿滯留**(較晚)；上運動神經元徵象：**巴賓斯基徵象陽性**、**反射亢進**。**布魯辛斯基徵象**是**腦膜刺激**的徵象，不屬於脊髓壓迫。
- **越早治療，越能保住行走功能**：新出現背痛合併神經症狀要立即通報；依醫囑給**高劑量 dexamethasone**、安排 MRI，接著放療或手術減壓。
- 護理：定時神經學評估、**圓滾翻身**維持脊柱平直、膀胱與排便照護、預防壓傷與跌倒。

### 惡性腫瘤高血鈣 {#hypercalcemia}

- 機轉：**骨轉移溶骨**，或腫瘤分泌**副甲狀腺素相關蛋白**(PTHrP)；**骨轉移常出現高血鈣**(不是低血鈣)。
- 表現：**疲倦、虛弱、嗜睡、意識混亂**、食慾差、**噁心嘔吐、便秘**、**多尿與脫水**、腎結石、**心律不整**(QT 縮短)。
- **白蛋白低**時要**校正血鈣**，否則會低估高血鈣：校正鈣 = 測得鈣 + 0.8 ×(4 − 白蛋白)。
- 治療：
  1. **大量靜脈生理食鹽水**補充容積(**不是限水**)；
  2. **雙磷酸鹽**(**zoledronic acid，Zometa**)或 denosumab 抑制蝕骨；
  3. calcitonin 快速但短暫降鈣；
  4. 補足水分後，必要時才用 loop 利尿劑促進鈣排出。
- 護理：鼓勵**下床活動**(減少骨質釋放鈣)、監測意識與心電圖、I/O；不需要鼓勵多喝牛奶補鈣。

### SIADH {#siadh}

- 腫瘤(**小細胞肺癌**)異位分泌抗利尿激素，或 vincristine、cyclophosphamide 等藥物引起 → 水分滯留、**稀釋性低血鈉**。
- 護理：**限制水分**(**不要鼓勵多喝水**)、每日體重、I/O、監測**血鈉、意識程度**、尿液滲透壓；預防抽搐與跌倒。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 化療病人**發燒要立即告知**，不可自行吃退燒藥；**未確立致病菌前先用廣效抗生素**；不量肛溫、不用塞劑。
- **ANC < 500** 保護性隔離(**不是負壓**)；**嗜中性白血球低下**要避免生菜沙拉、生魚片、溏心蛋、優格、養樂多、泡菜，**可吃柑橘**；不打活性疫苗(**口服沙賓、水痘、MMR、輪狀病毒不可**；**四合一、流感可以**)。
- 血小板低：**海綿潔牙棒**、電動刮鬍刀、**凡士林保濕鼻黏膜**、不用 NSAIDs 與灌腸塞劑；**血小板 1 萬評估意識**。
- 貧血：蒼白、疲倦、**心跳加快**；集中護理；疲憊時鼓勵**適度活動**。
- 口腔炎：**生理食鹽水**清潔、**不用雙氧水與含酒精漱口水**、進食前用 xylocaine、**nystatin 是抗黴菌藥**、**第 4 級規律給全身止痛藥**。
- 放療皮膚：**標記不可洗掉**、清水輕洗**不可搓洗**、**不可冷熱敷**、撐傘防曬、濕性脫屑用 **N/S 加親水性敷料**；**色素沉著不是急性反應**。
- 鼻咽癌放療：治療前**處理蛀牙、評估聽力**；**張口運動是預防牙關緊閉**；軟質食物；**週末休息**，不是連續不間斷照射。
- 胸部放療 → **食道炎**；骨盆腔放療腹瀉 → **低渣、減少乳製品**。
- **TLS**：**高鉀、高磷、高尿酸、低鈣**(不是高鈣)；**大量給水**、allopurinol、rasburicase；**不可減少輸液**。
- **SVC 症候群**：**肺癌**最常見；臉腫、頭痛、呼吸困難；**早上明顯**；半坐臥。
- **脊髓壓迫**：乳癌轉移多在**胸椎**；背痛、失禁、**巴賓斯基陽性**；**不會布魯辛斯基徵象**；蹠反射異常而電解質正常 → 想到脊髓壓迫。
- **高血鈣**：意識混亂、嗜睡、虛弱、心律不整、嘔吐、**便秘** → 大量輸液、**Zometa**。
- **SIADH**：**限水**，不是多喝水。
:::
