護理師靠**觀察**收集病人的資料，靠**溝通**了解病人的感受並建立**專業性人際關係**。國考最常考的是**情境題：病人說了一句話，護理師怎麼回應最適當**，答案幾乎都是「先接納、再探問病人的感受或擔心」；另外常考**觀察的種類**、**症狀與徵象**、**溝通模式的要素**與**護病關係各期的重點**。主客觀資料在護理過程的用法見 [[nursing-process#data-types]]，行為過程記錄也見 [[documentation-orders#methods]]，佩普洛的護病關係與精神科溝通見 [[psychodynamic-theories#peplau]]

## 重點摘要 {#summary}

- 觀察種類：**旁觀性**(不互動，夜班巡房、昏迷病人)、**參與性**(有互動；**執行護理技術時是觀察的最好時機**)、**自省性**(觀察自己)
- **直接觀察**＝用感官(視、聽、觸、嗅、叩)；**間接觀察**＝查病歷、檢驗報告、會診報告、護理記錄
- **症狀**不需儀器：**主觀症狀**是病人自己的感受(痛、暈、癢、累)，**客觀症狀**是別人看得到的(蒼白、呼吸急促、閉眼皺眉、冒冷汗)；**徵象**要用儀器或視觸叩聽(血壓、心跳、WBC(white blood cell，白血球)、爆裂音)
- **治療性溝通**：有目標、有計畫、有時限、**以病人需要為中心**；不是為了解決護理師的常規問題，也不是打聽與疾病無關的隱私
- 好的回應：**接納 → 探問感受**(「你擔心的是什麼？」「可以多說一點嗎？」)；壞的回應：不當保證、建議性忠告(「如果我是你…」)、**防禦性態度**、批判、改變話題、陳腔濫調
- **重述**＝把病人的話簡短說回去(「你說你聽得到聲音？」)；**反映**＝把問題丟回(「你想你能怎麼做？」)；**澄清**＝請病人說清楚(「能否再舉例？」)
- **同理心**：站在病人立場了解並說出來，客觀；**同情心**：主觀、情緒性介入，容易讓自己陷入困境；**接納不等於贊同**
- 護病關係四期：**互動前期**(護理師準備、自我探索)、**認識期**(介紹環境與常規、建立信任、試探行為)、**工作期**(共同擬計畫、解決問題)、**結束期**(從關係一開始就要準備；加強持續服藥、出院計畫)

### 國考常考點 {#exam-points}

- 擦澡時同時看骨突處有無壓傷＝**參與性觀察**(111-2_FA_010)
- 間接觀察：**查閱病歷 Hb、會診報告、護理記錄**(108-2_FA_027)；從病歷檢驗資料發現營養不良**不是**直接觀察(105-2_FA_038)
- 觀察時機：**換藥時可看到感染情形**(110-1_FA_010)
- 症狀：**傷口疼痛**是症狀(110-1_FA_007)；徵象：**血壓、WBC、爆裂音**(108-2_FA_026)；**呼吸急促與臉色蒼白是客觀症狀**，頭暈是主觀症狀、血壓心跳是徵象(106-2_FA_007)
- 行為過程觀察可**選擇特定時間活動**進行；錄音錄影要事先告知；不要邊談邊記；要記錄當時情境(110-1_FA_012)；分析時**以行為發生的前後情境為依據**(106-2_FA_010)
- 治療性溝通的目的**不包含**了解與疾病無關的隱私(107-1_FA_007)；「目的是協助護理師解決常規問題」錯(106-2_makeup_FA_008)
- 情境回應(都選探問感受)：對體型煩惱 →「**妳有什麼樣的煩惱**」(105-1_PC_056)；是否開膝關節 →「**你的擔心是什麼**」(115-1_FA_005)；抱怨復健太多 →「**聽起來您很生氣，可以再具體多講一點嗎**」(113-2_FA_005)；要求繼續住院 → **了解其感受與想法**(113-1_FA_005)；看窗外流淚 →「**您怎麼了？我們可以聊一聊**」(108-1_FA_012)；抱怨夜班護理師 →「**您能告訴我昨天夜裡的情況嗎**」(105-2_FA_009)；吃不下 →「**你哪裡不舒服？我幫你檢查看看**」(105-1_FA_012)；擔心減胎與嬰靈 → **詢問宗教信仰、鼓勵說出看法**(113-3_OP_025)；哺乳太累不想餵 → **實際觀察哺餵困難並協助**(106-2_FA_008)；沮喪、夜裡哭泣 → 告訴她心情不佳是正常的、多休息、請家人提供音樂(108-1_FA_003)
- 「不會吧！我們醫院的藥都是最好的」＝**防衛性態度**(114-1_FA_009)；「嗯嗯，啊？…我現在沒空陪您聊天」＝**無意義問答**的不當溝通(111-2_FA_009)
- 「你說你聽得到聲音？」＝**重述**(112-3_FA_005)
- 治療性觸摸(輕拍肩膀)有助溝通；距離不是越近越好；沉默時不必急著轉話題；接納不等於贊同(107-1_FA_010)；談到家庭時低頭不語 → **靜靜陪伴，給時間思考**(106-2_makeup_FA_010)
- 「溝通時勿直視病人，視線低於病人眼睛」**不適宜**，應與病人視線等高(107-2_FA_010)
- 伯儂模式：病人說「我好痛」→ 病人是**發訊者**；護理師疑惑的表情是**收訊者的回饋**，不是發訊者的非語言傳遞(114-3_FA_009)
- 說粵語的護理師把恍惚的香港病人帶回病床：**王先生使用的語言不是障礙**(護理師會粵語)(112-2_FA_007)；這是**使用病人能了解的語言**以達雙向溝通(112-2_FA_008)
- 專業性人際關係：**不需贊同病人的想法**(112-1_FA_007)；**雙方都能從互動中獲益成長**(109-1_FA_005)；「為了解決病人**所有**問題」錯(106-2_FA_011)
- 認識期：**介紹環境與病房常規**(105-1_FA_009)；結束期：**加強持續服藥的意願**(106-1_FA_010)
- 同情心常使自己陷入需要幫助的困境(107-2_FA_009)
- 稱呼病人：**先生、女士**或**姓氏加職稱**；不用床號、不用全名(107-1_FA_009)

## 觀察 {#observation}

- 觀察：有目的地運用感官收集資料；目的：**擬訂護理計畫與評值**、提供醫療團隊診斷治療參考、研究
- 正確觀察的條件：**有目的、有計畫**(who、when、what、where、how)、**客觀**(排除偏見)、**有彈性**、**持續**
- 來源：實用基本護理學上冊 p.73–74

### 觀察的種類 {#observation-types}

| 種類 | 特點 | 例 |
|---|---|---|
| **旁觀性**(非參與性) | 不與病人互動，病人通常不知道被觀察 | 夜班巡房、照顧昏迷病人 |
| **參與性** | 與病人互動(接觸、語言、非語言)，可建立關係 | **執行技術時**(擦澡時看骨突處、換藥時看傷口)；最好的觀察時機 |
| **自省性**(內省性) | 觀察自己的表現，自我反省 | 措施後病人反應不如預期，回頭檢討 |

- 來源：同書 p.74

::questions{ids="111-2_FA_010"}

### 直接與間接觀察 {#observation-methods}

1. **直接觀察**：用感覺器官(視、聽、觸、嗅；味覺少用)
   1. 一般身體檢查順序：**視 → 觸 → 叩 → 聽**；**腹部**改為**視 → 聽 → 叩 → 觸**(避免觸診影響腸音)
   2. **視診**是最基本、最重要的方法
   3. 嗅覺：過熟果香味(酮酸中毒)、尿味、綠膿桿菌感染傷口的特殊惡臭
2. **間接觀察**：由病歷取得 → 醫囑、**檢驗報告**、**會診結果**、**護理記錄**、各種圖表
3. 觀察範圍由病人向外擴展：病人本身 → 周圍環境與設備安全 → 重要親友 → 社會大環境；病人周圍的私人空間要經同意才改變(導致感染或意外的環境除外)
- 來源：同書 p.75–80

::questions{ids="108-2_FA_027,105-2_FA_038"}

### 症狀與徵象 {#symptoms-signs}

| | 定義 | 例 |
|---|---|---|
| **主觀症狀**(自覺症狀) | 病人**自己感受**到的 | 疼痛、脹、癢、麻、**眩暈**、口渴、心悸、疲倦無力、焦慮 |
| **客觀症狀**(他覺症狀) | **別人看得到**的，不需儀器 | 紅腫、**臉色蒼白**、消瘦、**呼吸急促**、傷口流膿、**閉眼皺眉**、冒冷汗、手壓患部 |
| **徵象** | 要用**儀器**或**視觸叩聽等特殊方法**測得 | **體溫、血壓、心跳**、**WBC**、水腫程度、腸音次數、**胸部爆裂音** |

- 判斷：不用工具就看得到 → 客觀症狀；要量、要聽診、要驗 → 徵象
- 「空腹血糖 180」「X 光浸潤」「痰液結核菌陽性」都是徵象(檢驗結果)，「傷口疼痛」是症狀
- 來源：同書 p.80–81

::questions{ids="110-1_FA_007,108-2_FA_026,106-2_FA_007"}

### 觀察時機與要報告的情況 {#timing-report}

1. 時機：交接班與巡房、晨間或寢前護理、量生命徵象、協助檢查、**給藥、換藥與管路護理時**、衛教時、傾聽病人陳述時、看病歷與報告時、家訪時
2. 要報告：生命徵象異常、**意識改變**、危險徵象(大出血、休克)、措施後仍無法緩解的症狀、合併症先兆、器官功能突然障礙、病況好轉後又復發的症狀、**意外事件**、強烈情緒或異常行為
3. 記錄可用「**A、B、C**」：外表(appearance)、行為(behavior)、言談(conversation)；最好直接引述病人的話
- 來源：同書 p.81–82

::questions{ids="110-1_FA_010"}

### 行為過程記錄 {#process-recording}

1. 常用於精神科實習：選特定**目的或主題**與**時間**，與病人會談至少 15–20 分鐘，**事後回溯**書寫
2. 功能：記錄護病間**語言與非語言**互動；**發現病人真正的健康問題**；**護理師自我分析與成長**；反思有效與無效的溝通技巧
3. 格式：基本資料 → **會談情境**(時間地點、影響互動的環境與情緒) → 互動目的(五大層面評估、JOMAC 認知評估) → 三欄：**病人行為／護理師行為／分析** → 心得
4. JOMAC：判斷力(judgment)、定向感(orientation)、記憶力(memory)、抽象思考(abstract thinking)、計算能力(calculation)
5. 注意
   1. 本質上**不是**以問題為導向的記錄
   2. 要錄音錄影**必須事先告知並徵得同意**
   3. 會談時不要邊談邊寫，事後回溯
   4. 要記錄**當時情境**；分析以行為發生的**前後情境**為依據；護理師當時的情緒、重複出現的言行、正向的言行都要記
- 來源：同書 p.83–84

## 溝通 {#communication}

### 治療性溝通 {#therapeutic-communication}

- 定義：護理師與病人之間**有目標、有計畫、有時間限制**、**以病人需要為中心**的互動；與社交性(隨意)、商業性(利益偏向自己)溝通不同；隨時隨地都可能發生
- 目的
   1. 建立並維持專業性人際關係
   2. 收集資料(含生活型態)以擬計畫
   3. 了解病人個別需要
   4. 給予個別的護理指導
   5. 了解病人對醫護人員的態度與看法
   6. 提升病人身心平衡
- **不是**為了解決護理師的常規問題，也**不是**打聽與疾病無關的隱私
- 來源：同書 p.85–86

::questions{ids="107-1_FA_007,106-2_makeup_FA_008"}

### 溝通模式 {#models}

| 模式 | 要素 |
|---|---|
| **舒拉姆**(Schramm) | 來源 → **製碼**成訊息 → 傳播 → 接收者**譯碼** → 反應 |
| **伯儂**(Berlo) | **發訊者**、**訊息**、**途徑**(語言與非語言)、**收訊者**、**回饋** |
| **伯恩**(Berne，溝通分析 PAC) | 自我狀態：父母式(P)、成人式(A)、兒童式(C)；**互補溝通**(平行、可持續)、**交錯溝通**(交叉、立刻產生障礙)、**曖昧溝通**(話中有話、口是心非) |

- 伯儂模式例：病人表情平淡說「我好痛，需要止痛針」→ 病人是**發訊者**，話是語言訊息，平淡表情是發訊者的非語言訊息；護理師疑惑的表情是**收訊者的回饋**
- 來源：同書 p.87–89

::questions{ids="114-3_FA_009"}

### 語言與非語言 {#channels}

1. 語言溝通(說與寫)約占 **35%**；非語言約 **65%**
2. 非語言：**臉部表情**(最常用、世界共通)、眼神接觸、**姿勢與手勢**(雙手抱胸上身後仰＝防衛)、修飾、音調、**觸摸**、個體距離
3. 護理師自己的負向非語言(一直看錶、打呵欠、匆忙手勢)病人很容易感受到
4. **語言與非語言互相抵觸**時(說「好看啊」卻一臉不耐)，病人會感到挫折
5. Edward T. Hall 的四種距離

| 距離 | 範圍 | 用於 |
|---|---|---|
| 親密 | 0–1.5 呎(約 0–45 cm) | 配偶、親子 |
| **個人** | 1.5–4 呎(約 45–120 cm) | 摯友；**與病人討論溝通** |
| 社交 | 4–12 呎(約 120–360 cm) | 同事、一般社交 |
| 公眾 | 12–25 呎(約 360–750 cm) | 演講、上課 |

- 距離**不是越近越好**，侵入安全距離會讓人不安
- 來源：同書 p.89–93

### 影響溝通的因素 {#barriers}

| 環節 | 例 |
|---|---|
| 發訊者 | 中風失語、喉癌、情緒過度激動；國籍、教育、文化、價值觀 |
| 訊息 | 不完整、不清楚、**醫學術語**、沒有組織、**用接收者聽不懂的語言**、**兩種互相抵觸的訊息** |
| 途徑 | 選錯途徑；衛教手冊配合口頭說明效果較好 |
| 接受者 | 聽障、不識字、意識改變(頭部損傷、藥酒癮)、**中重度焦慮**(視而不見、聽而不聞)、兒童 |
| 後溝通 | 環境吵雜、不隱密、氣氛不融洽 |

- 例：病人恍惚喃喃自語、護理師聽不懂內容 → 是障礙；但護理師**會說病人的語言(粵語)**，所以病人使用的語言**不是**障礙；改用病人聽得懂的語言＝**使用病人能了解的語言以達雙向溝通**
- 例：護理師帶著情緒上班、心不在焉，回答「嗯嗯，啊？您剛剛說什麼？我現在沒空陪您聊天」→ **無意義問答**的不當溝通
- 來源：同書 p.93–94

::questions{ids="112-2_FA_007,112-2_FA_008,111-2_FA_009"}

### 會談 {#interview}

1. 方式：**正式會談**(結構化、省時，但病人像受審)、**非正式會談**(自由表達，但較難控制)；臨床常先正式、再讓病人自由說、最後總結
2. 原則
   1. 用**病人能了解的語言**，避免醫學術語，衛教後請病人說說看
   2. **傾聽**：參與式、同理式、非評斷傾聽；避免選擇性傾聽
   3. 合適、隱密的環境
   4. **坐在床旁椅、與病人視線等高**、身體稍前傾；不要站著俯視；注視雙眼與鼻尖的三角區，不是瞪視，也不是刻意避開視線
   5. 不要一再重複別人問過的問題
   6. 依病人狀況(聾、病危、語言障礙)調整方式
   7. **同理並接納**：接受不代表贊同；不批判、不貼標籤
3. 開放式問句(「昨晚睡得如何？」)讓病人多說；病人表達困難時可用**封閉式**問句(「傷口還痛嗎？」)
- 來源：同書 p.95–98

::questions{ids="107-2_FA_010"}

### 治療性會談技巧 {#therapeutic-techniques}

| 技巧 | 做法與例 |
|---|---|
| 稱呼與自我介紹 | 用「**先生、女士、小姐**」或**姓氏加職稱**；**不用床號或病名**；說明會談時間 |
| 關懷與專注傾聽 | 說出聽到的事實，不加價值判斷 |
| **接納** | 「嗯」「我能了解你的意思」、點頭；**接受不等於贊同** |
| 讚賞 | 針對具體行為讚美 |
| **沉默** | 關心的沉默；病人整理思緒、情緒激動時，**靜靜陪伴給時間** |
| **治療性觸摸** | 輕拍肩膀、握手；注意性別與分寸 |
| **重述** | 把病人的重點說回去：「你昨晚都沒睡」「你說你聽得到聲音？」 |
| **澄清** | 「我不太確定了解你的意思，能說清楚一點嗎？」「能否再舉例？」 |
| 詢問 | 具體、誠懇、**虛心**(「不好意思我剛沒聽清楚，你說醫師怎麼了？」)、一次一個焦點、開放式 |
| **反映** | 把問題還給病人：「你想，你能怎麼做呢？」「你覺得呢？」 |
| 集中焦點 | 「你提到很無助，是什麼事讓你這樣覺得？」；病人明顯不想談時要尊重 |
| 提供訊息 | 主動告訴病人該知道的 |
| 開放話題 | 「你今天想談什麼？」「然後呢？」 |
| 鼓勵描述感受 | 把觀察到的非語言(咬唇、搓手)提出，讓病人說明 |
| 面質 | 關係良好時才用，精神科較常用 |
| 總結 | 會談結束前摘要重點、計畫下次 |

- **同理心回應**的句型：「你覺得○○(情緒字眼)，因為○○(內容)」；例：「聽起來您很生氣，可以再具體多講一點嗎？」
- 來源：同書 p.98–103

::questions{ids="112-3_FA_005,107-1_FA_010,106-2_makeup_FA_010,107-1_FA_009"}

### 非治療性技巧(要避免) {#non-therapeutic}

| 技巧 | 例 |
|---|---|
| **改變話題** | 病人說很緊張，護理師說「你肚子餓不餓？」；病人沉默時急著轉話題 |
| **不當保證** | 「不用怕，醫師很高明，沒問題」「開完刀加強復健一定會好」「腫瘤不一定是惡性的」 |
| 切斷式反應 | 病人話還沒說完就插話 |
| 過早下結論 | 「你可能是煩惱檢驗結果，放輕鬆就睡得著」 |
| 猜測 | 沒證據就臆測：「您是不是得了憂鬱症」 |
| **批判的態度** | 「你這樣做讓我很失望」「我認為你這樣對病沒好處」；不可以批評同事 |
| **建議性忠告** | 「**如果我是你**，我會…」「你只要均衡飲食就不必煩惱」 |
| 完全的同意 | 「你說得很對」 |
| 不協調 | 語言與表情矛盾 |
| **防禦性態度** | 病人抱怨醫院或某醫護人員，護理師馬上辯護：「不會吧！我們的藥都是最好的」「夜班人手不足，您不可以批評」 |
| 超過負荷 | 一次問一連串問題 |
| 陳腔濫調 | 「每個人都有不順心的時候，看開點」 |
| 無意義問答 | 心不在焉、答非所問 |

- 情境題的解題法：選項裡有**保證、勸告、辯護、說教、轉移話題**的先刪；留下**接納並請病人多說感受或擔心**的那一個
- 例外：病人表達的是具體身體不適或實際困難時，探問並**實際評估或協助**(吃不下 →「你哪裡不舒服？我幫你檢查看看」；哺乳困難 → 觀察哺餵並協助)
- 來源：同書 p.103–105

## 專業性人際關係 {#professional-relationship}

### 與社交性關係的不同 {#vs-social}

| | 專業性(治療性)人際關係 | 社交性人際關係 |
|---|---|---|
| 信念 | **不批判地接受**病人的信念，雙方信念未必相同 | 彼此有相同的信念 |
| 目標 | **以病人為中心**，共同訂目標 | 不一定有目標 |
| 需求 | **以滿足病人需求為前提** | 滿足雙方 |
| 進行 | 有計畫訂時間，**由護理師負責引導** | 隨性，雙方共同負責 |
| 期限 | **暫時性**，依目標達成而結束 | 不一定 |
| 自我表露 | 是助人的**手段**，對病人有幫助時才做 | 對等表露 |
| 結束 | **有計畫**、逐漸結束 | 可隨時、突然結束 |

- 特性：**特定的**(目標、時間、地點)、**有目的**、**短暫**(期限事先說明)、**專業**(依倫理守則規範權利義務)、**可分期**
- 是協助解決病人**健康問題**的關係，不是要解決病人「所有」問題；**雙方都可以從中獲益或成長**(護理師得到成就感)
- 來源：同書 p.105–106、表 3-3

::questions{ids="112-1_FA_007,109-1_FA_005,106-2_FA_011"}

### 建立的要素 {#elements}

1. **信任**：必備條件
2. **同感心(同理心)**：站在病人立場了解並表達出來，**客觀**
3. 尊重、**關懷**(最重要的特色)、**坦誠**(答應的事做到，不給不當保證)
4. 面質：開始期或信任不足時不適用
5. **接納**：接受病人有這種行為感覺，**不一定贊同**，不判對錯
6. 適度自我開放

| | 同理心(empathy) | 同情心(sympathy) |
|---|---|---|
| 立場 | 進入**病人**的參考架構 | 從**自己**的立場 |
| 性質 | **客觀**，幫病人解決問題 | **主觀、情緒性**介入 |
| 結果 | 病人感到被了解 | 常使自己**陷入需要幫助的困境** |

- 「設身處地」是同理心
- 來源：同書 p.98、106–107

::questions{ids="107-2_FA_009"}

### 發展四期 {#phases}

| 期 | 意義 | 護理重點 |
|---|---|---|
| **互動前期** | 還沒見到病人 | 護理師**自我探索**能力與限制；收集病人資料；**計畫第一次會談** |
| **認識期**(介紹期、開始期) | 入院時開始接觸、建立基本信任；病人可能出現**試探行為** | **介紹醫院環境與住院常規**；互相介紹、說明服務範圍；收集隱私資料前先說明目的；**視診**是最不具威脅的觀察；化解試探行為 |
| **工作期** | 有信任與共識 | **鼓勵病人與家屬參與擬訂並執行計畫**；用護理過程一起解決問題；注意病人的依賴 |
| **結束期** | **從建立關係時就要開始準備**，不是出院前才準備 | **加強持續服藥的意願**；一起評值關係與目標；**及早出院計畫**；轉介資源；處理分離失落與暫時退化 |

- 各期有順序但不一定連續，壓力下可能退回上一期
- 結束關係**不比**開始關係容易
- 佩普洛的四期與精神科應用見 [[psychodynamic-theories#peplau]]
- 來源：同書表 3-4 p.107–109

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 |
|---|---|
| 擦澡時看骨突處是旁觀性觀察 | 參與性觀察 |
| 查病歷是直接觀察 | 間接觀察 |
| 呼吸急促、臉色蒼白是徵象 | 客觀症狀(不用儀器) |
| 血壓、心跳是症狀 | 徵象 |
| 錄音錄影可不告知 | 要事先告知並徵得同意 |
| 溝通時視線低於病人、不直視 | 視線等高、溫和注視 |
| 距離越近越好 | 個人距離約 45–120 cm |
| 病人沉默要趕快轉話題 | 陪伴、給時間 |
| 接納就是贊同 | 接受不等於贊同 |
| 護病關係是社交性關係 | 專業性、治療性、暫時性 |
| 要解決病人所有問題 | 協助解決健康問題 |
| 結束期在出院前才準備 | 建立關係時就要準備 |
| 同情心是設身處地 | 那是同理心 |
| 以床號或全名稱呼病人 | 先生、女士或姓氏加職稱 |
| 「如果我是你，我會…」 | 建議性忠告，要避免 |
