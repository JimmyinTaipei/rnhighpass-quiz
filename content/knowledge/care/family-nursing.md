家庭是社區衛生護理最基本的服務單位：個人的健康行為來自家庭，家庭的價值又構成社區。家庭護理先用工具把家庭看清楚(成員、發展階段、內在結構、功能、壓力與資源)，再**和家庭一起**訂目標、運用資源；目標是讓家庭自己有能力處理健康問題。家庭暴力見 [[family-violence]]；遺傳疾病的家族譜系判讀見 [[genetic-inheritance]]

## 重點摘要 {#summary}

- 家庭類型：**核心**(父母＋未婚子女)、**折衷**(主幹，三代：祖父母＋一對已婚夫婦＋孫)、**大家庭**(同一代有兩對以上已婚者)、**混合**(再婚帶前婚子女)、**雙核心**(離婚後共同監護)、**家族網**(住附近、互相交流物資與服務)
- **Duvall** 依**第一個(最大)孩子**的年齡分 8 期；生育期＝第一個孩子 < 30 個月；最後一個孩子離家到夫妻一人退休＝中年期
- 家庭**內在結構**四要素：**角色、權力、溝通、價值**；關係複雜數＝**N(N − 1) ÷ 2**
- **APGAR**：適應(遇困難可求助、運用資源)、合作(討論與分擔)、成長(支持新發展)、情感(表達關愛)、融洽(共處時光、共享資源)；7–10 分無障礙、4–6 中度、0–3 重度
- 危機：**成長性**(可預期的發展轉變，如空巢)vs **情境性**(突發，**正向事件也算**，如中頭彩)
- 工具：**家系圖**＝世代關係與**遺傳疾病**(至少三代)；**生態圖**＝家庭與**外在系統、資源**的互動；**家庭圈**＝**權力**(圈的大小)與親疏(距離)
- 家庭護理：先**建立信任**；目標依**家庭感受的緊急性**排序、**和家庭共同**訂定；目標是**賦權**，不是讓家庭依賴護理師

### 國考常考點 {#exam-points}

- 林先生、父親、太太與兩個女兒同住 → **折衷家庭**；喪偶帶子＋離婚帶女再婚 → **混合家庭**；成年子女住附近常互相幫忙 → **家族網**
- Friedman(1981)廣義定義：**兩個或以上的人、情緒上互相影響**、住得靠近；「婚姻血緣認養、同住、依社會角色互動」是 Burgess 等(1963)的傳統定義
- 5 歲孩子 → 有學齡前兒童家庭(簡化 5 期的**成員增加期**)；建立夫妻認同屬**結婚期**；孩子各自成家屬**獨立期**，不是擴散期
- Duvall 評估的目的：了解家庭現階段的**保健事項與發展任務**
- 誰賺錢誰有權 → **情況(工具)權威型**；身兼數職無法扮演好每個角色 → **角色力竭**
- 有效溝通用「**我**」開頭(我訊息)，不用「你」開頭
- 10 人家庭的關係複雜數＝10 × 9 ÷ 2＝**45**
- 硬體結構支持＝裝扶手、緊急鈴；**軟體**結構支持＝角色有彈性(太太出國，先生身兼母職)；社福機構、衛生所屬**外在**資源
- 卡加利模式的「內在結構」：家庭組成、界限、次系統等；**家庭發展階段**屬「發展」類
- 家訪排程：**傳染病個案排最後**；新生兒、產婦等易受感染者排前面
- 評估照顧者技術(外籍看護導尿、太太換胃造口) → **請他實際操作**給你看
- 家庭增能的表現：主動找資源、能解決問題、對未來有希望、和護理師是夥伴；**遵從護理師指引或持續依賴不是**

## 家庭的定義與類型 {#definitions}

### 定義 {#family-definition}

| 學者 | 重點 |
|---|---|
| Burgess、Locke、Thomas(1963) | 經**婚姻、血緣或認養**組成；一起住在認定的家；依夫妻、親子等**社會角色互動**；分享共同文化(傳統、狹義) |
| **Friedman(1981)** | **兩個或以上**的人，**情緒上互相影響**，住得很靠近(廣義) |
| Stuart(1991) | 家庭是一個系統；可以沒有血緣、可以不同住、可以沒有孩子；彼此有承諾；有保護、養育、社會化功能 |

- 家庭護理的**最終目標**是**改善案家健康問題**、提升自我照顧能力；發現需求、提供資源、完整評估都是過程(106-1 題)
- 2019 年同性婚姻合法化，家庭定義更多元

::questions{ids="106-2_makeup_PC_070,106-1_PC_063"}

### 類型 {#family-types}

| 類型 | 組成 |
|---|---|
| **核心家庭** | 已婚父母＋未婚子女(兩代)；台灣最多 |
| **折衷家庭**(主幹家庭) | 父母＋**一對已婚子女**＋其未婚子女(三代)；祖孫二代同住也歸折衷 |
| **大家庭** | 多代同住，且**同一代有兩個以上已婚者** |
| 三代家庭 | 三代以上同住 |
| **重組(混合)家庭** | 繼父或繼母帶著各自前婚子女組成 |
| 雙人核心家庭 | 已婚、沒有孩子同住 |
| **雙核心家庭** | 離婚後**共同監護**，孩子屬於兩個核心家庭 |
| 不生育核心家庭 | 選擇不生(頂客族) |
| 單親家庭、未婚單親 | 離婚、喪偶、遺棄或未婚 |
| 未婚夫婦與孩子、未婚同居 | 沒有正式婚姻契約 |
| 同志家庭 | 同性伴侶，有或沒有孩子 |
| **家族網**(kin network) | 核心家庭或未婚者**住在原生家庭附近**，互相交流物資與服務 |
| 公社家庭 | 多個核心家庭(可無親屬關係)同住，共享資源與工作 |

- 新住民家庭：各縣市有新住民家庭服務中心；尊重**宗教文化差異**(回教不吃豬肉製品，例如麻油豬肝)，協助家人理解，而不是要求新住民融入(110-2 題)

## 家庭發展：Duvall 八階段 {#development}

以**第一個孩子**的年齡分期(不是最小的孩子)；每個家庭不一定依序經過每一期，也可能同時處在好幾期

| 簡化 5 期 | Duvall 階段 | 定義 | 主要發展任務 |
|---|---|---|---|
| **結婚期** | ①結婚期 | 新婚，無孩子 | **建立夫妻認同**、建立親戚網絡、決定是否為人父母；家庭計畫 |
| **成員增加期** | ②**生育期** | 第一個孩子 **< 30 個月** | 統合嬰兒成為家庭一員、**適應父母與祖父母新角色**、**維持穩定婚姻** |
| | ③有學齡前兒童 | 第一個孩子 **2.5–6 歲** | 孩子社會化、適應親子分離；家長適應疲憊與缺乏隱私 |
| **成員擴散期** | ④有學齡兒童 | 第一個孩子 6–13 歲 | 孩子發展同伴關係、適應學校影響 |
| | ⑤有青少年 | 第一個孩子 13 歲到獨立(約 20 歲) | 增加自主、再強化婚姻與事業、**開始關心老一代**；父母建立自己的興趣 |
| **獨立期** | ⑥孩子離家(空巢) | 第一個到最後一個孩子離家(約 8 年) | **孩子各自成家立業**；建立獨立認同、重新適應婚姻 |
| | ⑦**中年期** | **最後一個孩子離家到夫妻一人退休**(約 15 年) | 再投資夫妻關係、建立姻親與孫子關係、照顧高齡父母 |
| **退休／死亡期** | ⑧老年期 | 退休到死亡(10–15 年) | 適應退休、健康衰退、收入減少、喪偶 |

- 評估家庭發展的目的：了解**現階段的保健事項與發展任務**(110-2 題)
- 111-1 題的 A、B、C 都把「第一個孩子」換成「最後一個孩子」，所以錯；只有中年期的定義本來就用最後一個孩子

::questions{ids="113-3_PC_040,112-1_PC_064,111-1_PC_064,110-2_PC_064,108-2_PC_071,105-2_PC_061"}

## 家庭內在結構 {#structure}

- **家庭關係複雜性定律**(Bossard)：互動關係數＝**N(N − 1) ÷ 2**(N＝家庭人口)；4 人 6 種、8 人 28 種、10 人 45 種
- 四要素：**角色結構、權力結構、溝通過程、價值系統**(Friedman 等；發展、功能不是內在結構要素，109-2 題)

### 角色結構 {#roles}

| 情況 | 意思 |
|---|---|
| 角色衝突 | 面對做不到的角色期望而內心衝突 |
| **角色力竭** | **身兼數種角色**，要求超過能力所及(丈夫生病，太太要賺錢、持家又照顧) |
| 角色一致(調和) | 實際扮演與規定、分配、能力一致 |
| 角色不一致 | 實際扮演與規定、分配、能力不一致 |
| 角色互補 | 一個人的角色由另一個人補充 |
| 角色相稱 | 角色規定與發展型態相對應 |

- 正式角色(父親、長子)與非正式角色(和事佬、代罪羔羊)

### 權力結構 {#power}

| 權力類型 | 意思 |
|---|---|
| **傳統權威型** | 依傳統(如父系)，不論是否養家都由他決策 |
| **情況(工具)權威型** | 依情況轉移，**誰賺錢養家誰權力最大**(先生生病或留職停薪，太太養家並作主) |
| **分享權威型** | 民主家庭，共同參與決策 |

- 決策方式：意見一致、讓步妥協、聽天由命(「讓步妥協」是決策方式，不是權力類型)

### 溝通與價值 {#communication-values}

- 有效溝通：訊息**具體明確**、**言行一致**、用「**我**」開頭表達自己的感受、給予適切**回饋**、真誠開放
- 價值系統：家庭認為什麼重要，受信念、文化、宗教影響，決定保健行為，不易改變

::questions{ids="109-2_PC_052,107-1_PC_069,114-3_PC_040,113-1_PC_040,113-1_PC_041,105-1_PC_062"}

## 家庭功能 {#function}

- WHO(1978)：生物、經濟、教育、心理、社會文化功能；近年整理為**情感、社會化、生育、經濟、健康照護**五功能
- **PRACTICE** 評估表：現存問題(P)、角色(R)、情感(A)、溝通(C)、時期(T)、疾病(I)、調適(C)、生活環境(E)，用來詳細記錄
- **APGAR**(Smilkstein)：初次接觸時快速評估，每題「經常 2、有時 1、幾乎很少 0」分

| 項目 | 問的是 | 國考情境 |
|---|---|---|
| **A 適應度** | 遇到困難時能**運用內外在資源**、向家人求助 | 父親中風，兒子主動找里長與社區護理師 |
| **P 合作度** | 家人**討論事情、分擔問題**的方式(權力與責任分配) | — |
| **G 成長度** | 想從事新活動或新方向時，家人**接受並支持** | 父母雖擔心仍支持孩子當無國界醫療人員 |
| **A 情感度** | 家人表達**關愛**與回應情緒 | — |
| **R 融洽度** | 家人**共處時光**、共享時間空間與資源 | — |

- 總分 **7–10** 家庭功能無障礙、**4–6** 中度障礙、**0–3** 重度不足
- 「成長度是調適彼此相處的壓力」錯(111-2 題)；「領域度」不是 APGAR 項目

::questions{ids="113-2_PC_041,111-2_PC_063,111-1_PC_062,107-2_PC_070,107-1_PC_070"}

## 家庭壓力與資源 {#stress-resources}

### 家庭危機 {#crisis}

| 危機 | 特徵 | 例子 |
|---|---|---|
| **成長性(發展性)危機** | 人生發展階段轉變，**可預期**、可事先準備 | 結婚、生育、**空巢期**、退休 |
| **情境性危機** | **突發**、不可預期，**正向或負向**都可能 | 親人死亡、**失業**、**意外傷害**、買新房、**中頭彩**、外派進修 |

- 生活改變單位(Holmes 與 Rahe)：150–300 輕中度危機，約一半的人 2 年內生病；> 300 重度，約 70%；配偶死亡 100 分最高

### 家庭資源 {#resources}

| 內在資源 FAMLIS | 外在資源 SCREEEM |
|---|---|
| F 財力支持 | S 社會資源(親友鄰居、社福機構) |
| A 精神支持 | C 文化資源 |
| M 醫療處置(家人能照顧病人) | R 宗教資源 |
| L 愛 | E 經濟資源 |
| I 資訊或教育 | E 教育資源 |
| S **結構支持**：**硬體**(為中風家人裝扶手、緊急鈴)與**軟體**(角色彈性，太太出國、先生身兼母職) | E 環境資源 |
| | M 醫療資源(衛生所家訪) |

- **家庭長處**評估(Otto 1963)：讓家庭發現自己的潛能、提升自信、讓護理師了解家庭的能力；**不是為了完成評估報告**(105-1 題)

## 家庭評估工具 {#tools}

| 工具 | 呈現什麼 | 重點 |
|---|---|---|
| **家系圖**(genogram) | 家庭成員、**世代關係**、健康史與**遺傳疾病** | 以個案為中心，**至少三代** |
| **生態圖**(eco-map，Hartman 1978) | 家庭與**外在系統**(醫療、學校、職場、社區)的連結與能量互動 | 評估**外在資源**與社會支持 |
| **家庭圈**(family circle) | 大圓圈代表家，小圓圈代表成員：**圓圈大小＝權力**、**距離＝親疏** | 由個案**獨自**依主觀感受畫；會**隨時間改變**；每個人畫的都不一樣 |
| APGAR | 家庭功能滿意度 | 見上 |

### 家系圖符號(課本圖 19-2) {#genogram}

| 符號 | 意思 |
|---|---|
| 方形／圓形 | 男／女；個案用雙框或另外標示 |
| 夫妻實線相連，男在左 | 結婚 |
| 夫妻線上 **兩條斜線** | **離婚**；一條斜線為分居 |
| 夫妻**虛線**相連 | **未婚同居** |
| 子女依出生順序由左到右 | 兄姊在左 |
| 子女連線用**虛線** | **領養** |
| 叉號 | 死亡 |
| **虛線圈起** | **同住**的成員 |
| 半塗或點 | 帶因者 |

- 105-2 題「至少畫三代」與「虛線圈起表示同住」**都給分**
- 108-2 題：同居三年並領養三歲男孩 → 夫妻虛線(同居)＋子女虛線(領養)

| 大類 | 內容 |
|---|---|
| **結構** | **內在**：**家庭組成**、性別、性別取向、排行、**次系統**、**界限**；外在：擴展的家庭、較大的系統；情境：種族、社會階層、宗教、環境 |
| **發展** | **家庭發展階段**、任務、依附關係 |
| **功能** | 工具性(日常生活活動)；情感性(溝通、問題解決、角色、影響與權力、信念、聯盟) |

## 家庭護理過程 {#nursing-process}

1. **收集家庭與個人健康資料**(評估)
2. **確認家庭與個人健康問題**(診斷，可用 NANDA-I 家庭相關診斷：家庭因應失能、家庭運作失常、照顧者角色緊張等)
3. **與家庭共同設立目標**
4. **決定優先順序**
5. **動員資源執行**
6. **評值**

- 106-2 題順序：資料收集 → 確認問題 → 共同設目標 → 決定優先順序 → 動員資源 → 評值
- **建立信賴關係**是一切的基礎；家庭冷漠疏離時，先設法建立信任，再談療育、避孕(105-2 題)
- 目標排序的主要依據：**家庭本身感受到的緊急性**；也考慮家庭的內外在資源、家庭感受的治療效果；**不是護理師覺得重要的**
- 和家庭**共同**設定目標，人會朝自己選的目標努力；**不替家庭規劃所有照護計畫**
- 有跌倒高風險的長者家庭(行動不便＋高齡)，最優先是**居家安全評估、預防跌倒**(114-1 題)；防跌細節見 [[patient-safety-environment#falls]]
- 全家體位異常：全家一起改生活型態、兒童**漸進式**減重、注意身體心像；**不要**因怕嬰兒過重而提早停餵母乳(115-1 題；母乳哺育建議見 [[maternal-child-health]])
- 評值照顧技術：請照顧者**實際操作**(導尿管護理、胃造口換藥)，比口頭說明、看結果或問病人更準確

## 家庭訪視 {#home-visit}

- 目的：以專業知識技術到家服務，解決現在並預防未來的健康問題；能實際看到家庭環境、互動與自我照顧情形
- 階段：初始 → 訪視前 → 訪視 → 終止 → 訪視後；成功的關鍵是**信任關係**；基本技能：觀察、傾聽、提問、探究、促使
- 流程：準備 → 實際訪視 → 預約下次 → 記錄(回來立即寫) → 評值

| 排程原則 | 理由 |
|---|---|
| 時效性與問題嚴重度優先：影響人數多、致死率高、後遺症重、經濟損失大 | — |
| **易受感染者(新生兒、產婦)排前面** | 避免把病原帶過去 |
| **傳染病個案排最後** | 例：國外旅遊返國疑似登革熱 |
| 路線順路安排；路線單一式兩份 | 一份留辦公室備緊急聯絡 |

### 賦權與契約 {#empowerment}

- **家庭賦權(增能)**：家庭能**接受並控制所需資源**、有**決策與解決問題**能力、會**溝通並取得資源**；結果是正向自尊、能達成目標、有控制感與**對未來的希望**
   1. 主動尋求社區資源、自己發現問題並處理、和護理師成為**夥伴** → 是賦權
   2. **遵從護理師指引**、**持續依賴**護理師 → **不是**賦權
- **護理契約**(contracting)：讓家庭**正式參與**護理過程、**共同**界定雙方的責任與控制；
   1. 是**持續、可重新談判**的協議，可書面也可口頭
   2. 和家庭中**能負責、適當的成員**簽約，最好全家都審閱
   3. 目標與分工由雙方**共同**決定，不是護理師單方面分派
   4. 開始期(共同收集資料、建立目標、發展計畫)→ 運作期(分工、設時限、執行、評值與重新協商)→ 結束期
   5. 不適合：認知能力低、緊急情況、不想主動參與的人
- 其他訪視技巧：代言(爭取權益)、諮商、賦權

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| Duvall 以最小子女的年齡分期 | 以**第一個(最大)**孩子 | 只有中年期用最後一個孩子 |
| 生育期是孩子 3–6 歲 | 第一個孩子 **< 30 個月** | 2.5–6 歲是學齡前 |
| 每個家庭都依同樣週期發展 | 不一定 | 可能跳過或同時處在多期 |
| 孩子成家立業是擴散期 | **獨立期** | 擴散期是學齡與青少年 |
| 情境性危機只指負向事件 | 正向事件也算 | 中頭彩也會打破平衡 |
| 空巢期是情境性危機 | **成長性**危機 | 可預期 |
| 經濟、教育、環境是內在資源 | **外在**資源(SCREEEM) | |
| 家庭圈要和家人商議後畫 | 個案**獨自**依主觀畫 | |
| 家庭圈大小代表付出多寡 | 代表**權力** | |
| 生態圖看遺傳疾病 | 那是**家系圖** | 生態圖看外在資源 |
| 傳遞訊息以「你」開頭 | 用「**我**」開頭 | 避免指責 |
| 依護理師覺得重要的排目標 | 依**家庭感受的緊急性** | 以家庭為中心 |
| 護理師為家庭規劃所有照護 | 和家庭**共同**規劃 | |
| 遵從指引是家庭增能 | 增能是有能力自己決定 | |
| 卡加利內在結構包括發展階段 | 發展階段屬**發展**類 | |
