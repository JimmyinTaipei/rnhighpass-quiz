社區衛生護理以**整個人口群體**為服務對象，目標是**健康促進與疾病預防**，不是治療疾病。本頁整理學門的定義與發展、特性與分科、社區護理師的角色（國考最常考）、基層保健的原則，以及護理人員怎麼參與健康政策。衛生行政組織與照護體系見 [[health-administration-system]]；生命統計見 [[vital-statistics]]；社區心理衛生見 [[community-mental-health]]

## 重點摘要 {#summary}

- 特性：以**人口群體**為焦點、目標是**健康促進與疾病預防**、稱「個案」不稱「病人」、**自主性與獨立性高**、**個案管理時間長**、服務層面廣、以群體為單位並用**管理與組織**為策略
- 發展三階段：**地段護理(1860–1900) → 公共衛生護理(1900–1970) → 社區衛生護理（1970 起）**；臺灣公衛重點：**傳染病防治 → 婦幼衛生 → 家庭計畫 → 基層保健醫療 → 健康促進與人口老化**
- 角色判斷關鍵字：**爭取權益、發聲、促成立法 → 代言者（倡議者）**；收案建卡、擬計畫、整合資源 → **個案管理者**；通知轉介與後續追蹤 → **照護協調者**；民眾無法自己下判斷 → **顧問**
- 基層保健醫療 **4A**：可近性、可用性、可接受性、**負擔得起**（穩定性不是）
- 政策制定 6 步驟：形成問題 → **排定議程** → **發展政策（擬草案、遊說）** → 通過政策 → 執行 → 評值；所有部門的政策都考慮健康＝**健康融入所有政策(HiAP)**

### 國考常考點 {#exam-points}

- 社區衛生護理**不是**以疾病照護、疾病管理或醫療治療成效為主要目標
- 與醫院護理比較：社區護理師**自主性較高**，較能看到個案與家庭的互動，與社區機構聯繫較多
- **綜合性**(generalized)＝地段管理、**不分科**，服務整個地段的家庭；**專科化**(specialized)才只服務特定族群
- 最早的模式是**地段護理**；不是「由公共衛生護理發展到地段護理」
- 臺灣衛生所服務重點：**傳染病防治 → 婦幼衛生與家庭計畫 → 基層保健醫療 → 健康促進**
- 「熟悉流行病學與生命統計、用數據監測計畫成效」屬於**以實證為基礎的能力**
- White(1982)3E：用科學技術控制環境危險因子＝**工程**(Engineering)；另兩個是**教育**與**強制**（法規）
- 向立法委員遊說促進立法＝政策過程的**發展政策**階段；公民透過**利益團體**遊說與監督
- 推動健康促進計畫時，護理師**不是**以研究者身分替民眾規劃一切，而是與民眾共同確認需求、賦能民眾

## 名稱與定義 {#definition}

- 學門名稱的演變：地段護理(district nursing)、訪視護理(visiting nursing)、公共衛生護理(public health nursing)、社區衛生護理(community health nursing)；臺灣的課程與台灣護理學會委員會都已改稱「社區衛生護理」
- 「公共衛生護理」原意是服務**所有**有需要的民眾(Lillian Wald)，後來被誤解成只給窮人的官方免費服務，所以改用「社區衛生護理」強調照顧**整個社區**
- 兩種實務取向：
   1. **以社區為導向**(community-oriented)：評估社區健康問題、監測與評值，預防**人口群體**的疾病與失能
   2. **以社區為基礎**(community-based)：依執業場所區分，在社區、工廠、學校提供個人或家庭直接照護
- 美國的公共衛生護理四協會(Quad Council)認為兩個名稱可以互換，重點是**人群為中心**、預防保健，以及社會公平的倡議與政策發展
- 熱氣球模式：三個支柱是**評估、政策發展、保證**；六種措施是疾病預防、健康促進、健康保護、健康維護、健康恢復、健康監測

## 發展歷史 {#history}

### 國外三階段(Spradley 1990) {#three-stages}

| 時期 | 對象 | 導向 | 重點 | 代表 |
|---|---|---|---|---|
| **地段護理**(1860–1900) | 貧病者 | 個體 | 治療，開始注意預防 | 1859 年 William Rathbone 在英國利物浦成立第一個地段訪視護理機構，把城市分成 18 個地段 |
| **公共衛生護理**(1900–1970) | 有需要的民眾 | **家庭** | 治療與預防 | Lillian Wald 在「保健護士」前加上「公共」；保險公司開始給付家訪 |
| **社區衛生護理**（1970 起） | **整個社區** | **人群** | 健康促進與疾病預防 | 社區整體照護與社區衛生計畫 |

### 臺灣 {#taiwan-history}

- 1925 年北平「第一區公共衛生事務所」開始培育公共衛生護理人員
- 遷臺後各地衛生所聘用公共衛生護理人員做地段護理；1965 年公共衛生護理課程與實習納入各級護理教育
- 台灣護理學會 2005 年出版社區衛生護理專業範疇與職責規範，2011 年開辦**社區衛生護理師認證**
- 臺灣公共衛生重點的變遷（國考順序）：
   1. **傳染病防治**（光復初期，瘧疾、鼠疫、天花陸續根除；1965 年 WHO 宣布臺灣為瘧疾根除地區）
   2. **婦幼衛生**
   3. **家庭計畫**
   4. **基層保健醫療**（1983 年起群體醫療執業中心）
   5. **健康促進**、慢性病防治與**人口老化**、長照
- 衛生所各階段任務見 [[health-administration-system#health-station]]

## 特性 {#characteristics}

| 特性 | 說明 |
|---|---|
| 以**人群**為焦點 | 對象包括個人、家庭、團體、社區，考慮整體健康 |
| 目標是**健康促進與疾病預防** | 預防性服務，不是治癒性照護 |
| 稱「**個案**」不稱病人 | 對象可能是健康的人；個案是主動合作者 |
| **獨立性與自主性高** | 現場沒有醫師即時指示，自己依評估排優先次序 |
| **個案管理時間長** | 持續性、整體性照護，問題複雜 |
| 服務**層面廣** | 除直接護理，也要處理生理、心理、社會與物理環境因素 |
| 以**群體**為單位、以**管理與組織**為策略 | 用管理與組織理論計畫、執行與評值衛生計畫 |

- 社區護理強調**夥伴關係與跨領域合作**

### 綜合性與專科化 {#generalized-specialized}

| | 綜合性(generalized) | 專科化(specialized) |
|---|---|---|
| 方式 | **地段管理、不分科** | 依疾病或族群分科 |
| 對象 | 地段內**全部家庭** | 特定族群（例：結核病、糖尿病個案） |
| 優點 | 容易和家庭建立關係、以**家庭為中心**整體考量 | 專精 |

### 分科與執業場域 {#specialties}

- 課本列 8 種分科：一般不分科、社區心理衛生、社區精神殘障（學習障礙）、公共衛生、社區兒童、**學校衛生**、**職業健康**、**居家護理**
- 台灣護理學會依執業場域分 5 類（也是社區衛生護理師認證的領域）：
   1. 以醫療院所為基礎的社區護理（出院準備、持續性照護）
   2. **衛生所（室）**護理：執行國家公共衛生政策的官方角色
   3. **學校**衛生護理
   4. **職業健康**護理：最早建立標準化訓練與資格認證
   5. **長期照護**：機構式、居家式、社區式

## 社區護理師的角色 {#roles}

| 角色 | 做什麼 | 國考情境 |
|---|---|---|
| **照護提供者**(care provider) | 評估、計畫、提供直接護理並評值 | |
| **教育者**(educator) | 找出高危險群，用教學方法改變危險行為 | |
| **代言者／倡議者**(advocate) | 替弱勢**爭取**服務與權益，**傳達需求**，促成**政策與立法** | 製作「遊民的一日」影片宣導；向里長爭取志工陪獨居老人就醫；為老人爭取無障礙設施；爭取居家護理健保給付；為弱勢促成立法 |
| **個案管理者**(case manager) | 評估、**收案建卡**、擬完整持續的計畫、連結資源 | 健康問題家庭收案建卡並提供服務與指導 |
| **協調者**(collaborator) | 協調不同部門與專業 | |
| **照護協調者**(care coordinator) | 通知、**轉介**、後續追蹤 | 篩檢發現疑似大腸癌，通知、轉介與追蹤 |
| **領導者／觸媒者**(leader／catalyst) | 主動引導民眾認識潛在危險並促成改變 | |
| **研究者**(researcher) | 用研究改進照護 | |
| **顧問**(counselor) | 民眾**無法獨立下判斷**時給建議，但仍培養其自己做決定 | |
| **諮詢者**(consultant) | 提供其他專業人員諮詢 | |
| **個案發現者**(case finder) | 主動到社區找需要服務的人、篩檢 | |
| **流行病學者**(epidemiologist) | 用流行病學研究社區疾病型態 | |
| **評值者**(evaluator) | 評值計畫成效並回饋民眾、賦權 | |

- 推動健康促進計畫：與民眾**共同**評估需求、用實證策略、參與政策；**不是**主要以研究者身分替民眾規劃
- 賦權（empowerment，又譯增能、培力）是社區護理的核心概念，見 [[community-nursing-process#partnership-empowerment]]

### 必備特質與核心能力 {#competencies}

- WHO 1974 年三項特質：
   1. 以促進社區健康為己任
   2. **以照護弱勢團體為優先**（依脆弱性排序，所以婦幼服務多）
   3. 能與個案（個人、家庭、團體、社區）合作計畫與評值
- WHO 2010 社區衛生護理四項核心能力：建構社區社會資本、評估社區問題與風險、規劃與執行照顧計畫、發展地方健康政策
- 國考 110-1 題：熟悉**流行病學與生命統計**、分析健康數據監測計畫成效 → **以實證為基礎的能力**
- 學歷：基層(generalist)至少大學；進階(specialist)需碩博士，能獨立做社區評估、計畫與政策分析

### 3E 預防策略 {#three-e}

- White(1982)提出社區護理控制環境危害的三種措施：
   1. **工程**(Engineering)：用**科學技術**改變或控制環境中的危險因子（例：防護設施、安全設計）
   2. **教育**(Education)：衛教改變行為
   3. **強制**(Enforcement)：法規強制（例：機車安全帽、酒駕罰則）

## 基層保健醫療 {#primary-health-care}

- WHO 1978 年**阿瑪阿塔宣言**：以**基層保健醫療**（primary health care，PHC）達成「**全民均健**」(Health for All)
- 原則（4A，課本另加可靠 accountable）：
   1. **可近性**(accessibility)：距離近、方便
   2. **可用性**(availability)：有服務可用
   3. **可接受性**(acceptability)：符合民眾文化與信仰
   4. **負擔得起**(affordability)
- 國考把「**穩定性**」列為錯誤選項
- 基層醫療的工作：預防接種、傳染病防治、癌症篩檢、慢性病防治；**罕見疾病治療**屬於醫學中心的三級醫療，不是基層的主要服務

## 健康政策 {#health-policy}

### 定義 {#policy-definition}

- **公共政策**：政府決定做或不做的事；**健康政策**是直接影響民眾健康或醫療服務體系運作的公共政策
- **健康融入所有政策**（HiAP，Health in All Policies）：**所有部門**（交通、教育、環境等）的公共政策都要把健康效益納入考量，不只是衛生部門的責任
- **2025 衛生福利政策白皮書**(2016)：總目標「**共享生活幸福平等，全人全程安心健康**」，方向包括消除健康不平等、重塑健康服務體系、創新資訊科技、拓展國際參與
- 健康平等與 SDGs 見 [[health-equity]]

### 政策制定過程 {#policy-process}

政策制定與護理過程的邏輯相同（Bullock 等 1993）

| 護理過程 | 政策制定過程 | 護理人員可以做的 |
|---|---|---|
| 評估、確立問題 | **形成問題** | 讓民眾與政府注意到未被滿足的需要 |
| 設定目標、排優先 | **排定議程** | 讓政府把問題優先排入審議 |
| 發展護理計畫 | **發展政策**（擬政策草案） | **向民意代表溝通遊說**、提供資料 |
| 與個案選定計畫 | **通過政策**（立法） | |
| 執行計畫 | **執行政策** | |
| 評值計畫 | **評值政策** | |

- 公民可以加入**利益團體**，用團體力量對關鍵利害關係人(stakeholders)**遊說與監督**
- 護理人員參與政策的做法：加入專業組織、事先蒐集立法與支持反對者資料、對不同對象準備不同說法（民代看選票、政府看成本效益）、協調內部共識、引發公眾討論、掌握時機、持續蒐集實證資料
- 爭取權益與促成立法是**代言者**角色

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 社區護理主要目標是疾病照護 | **健康促進與疾病預防** | |
| 社區護理比醫院護理更依賴醫療團隊 | 社區護理**自主性較高** | |
| 綜合性社區護理只服務特殊族群 | 綜合性是**地段管理、不分科** | 專科化才服務特定族群 |
| 由公共衛生護理發展到地段護理 | **地段 → 公衛 → 社區** | |
| 爭取權益是協調者 | 爭取權益是**代言者** | 協調者是整合不同部門 |
| 基層保健原則包括穩定性 | 4A：可近、可用、可接受、負擔得起 | |
| HiAP 強調衛生部門自己的責任 | **所有公共政策**都要考慮健康 | |
