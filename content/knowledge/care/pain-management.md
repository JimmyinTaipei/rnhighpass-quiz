**疼痛**是與實際或潛在組織損傷有關的**不愉快感覺與情緒經驗**，而且**永遠是主觀的**：病人說痛就是痛(來源：[IASP 2020](https://www.iasp-pain.org/resources/terminology/))。疼痛被視為「**第五生命徵象**」，護理師要**定時評估、依醫囑給藥並評值效果**，同時運用非藥物方法。藥物細節見 [[opioids]] 與 [[nsaids-acetaminophen]]。

## 疼痛的機轉 {#physiology}

### 疼痛的四個步驟 {#nociception}

| 步驟 | 發生的事 | 對應的止痛方法 |
|---|---|---|
| **傳導轉換**(transduction) | 組織受傷釋放**前列腺素**、緩激肽、組織胺等，刺激痛覺接受器 | **NSAIDs** 抑制前列腺素生成；局部麻醉 |
| **傳遞**(transmission) | 經 **Aδ 纖維**(快、尖銳、定位清楚)與 **C 纖維**(慢、鈍、灼熱、不易定位)傳到脊髓，再上傳到視丘與大腦 | 局部麻醉、神經阻斷、硬膜外止痛 |
| **知覺**(perception) | 大腦皮質**意識到**疼痛，受情緒、經驗、文化影響 | 放鬆、分散注意力、認知行為方法 |
| **調節**(modulation) | 腦與脊髓釋放**內生性鴉片**(腦內啡)、血清素、正腎上腺素，**抑制**痛覺傳遞 | **鴉片類止痛藥**、抗憂鬱劑(神經痛輔助藥) |

### 閘門控制理論 {#gate-control}

- Melzack 與 Wall(1965)提出：脊髓後角有一個「**閘門**」，決定痛覺訊號能不能上傳到大腦。
- **粗的 Aβ 纖維**(觸覺、壓覺)被刺激時會**關閉閘門**，細的痛覺纖維訊號就傳不上去。
- 應用：**按摩、搓揉、按撫法**、**薦骨(尾骶骨)加壓按摩**、經皮神經電刺激(TENS)、冷熱敷。
- 大腦往下傳的訊號(情緒、注意力)也能開關閘門，所以**焦慮會加重疼痛**，分散注意力能減輕疼痛。

:::note[生產疼痛的其他理論]
- **害怕－緊張－疼痛**(Dick-Read)：害怕使肌肉緊張，加重疼痛 → 產前教育、放鬆。
- **制約反射**(Lamaze 心理預防法)：以呼吸技巧建立新的反應。
- **按撫法**(effleurage)依據**閘門控制理論**，適合輕中度疼痛；**薦骨重壓**可減輕**下背痛**(例：枕後位造成的腰痠，按摩時**不要讓產婦平躺**，改側躺或膝跪姿)。
:::

### 閾值與耐受度 {#threshold}

- **疼痛閾值**：開始感覺到痛的最小刺激強度。**冷熱療**、按摩等可以**提高**閾值(不是降低)。
- **疼痛耐受度**：能忍受的最大疼痛；受情緒、疲倦、文化、過去經驗影響。

## 疼痛的分類 {#types}

| 分類 | 特性 | 例子 |
|---|---|---|
| **急性疼痛** | 突然發生、**有明確原因**、隨傷口癒合消失；常伴隨**交感神經反應** | 術後疼痛、骨折 |
| **慢性疼痛** | 持續或反覆，**超過正常癒合時間**；常伴隨憂鬱、失眠、功能受限，交感反應不明顯 | 慢性下背痛、關節炎 |
| 身體性(somatic) | 皮膚、肌肉、骨頭；**定位清楚**、刺痛或痠痛 | 骨轉移痛、傷口痛 |
| 內臟性(visceral) | 器官受擴張、缺血、發炎；**不易定位**、悶痛絞痛，常有**轉移痛** | 腸阻塞、膽絞痛 |
| **神經病變性** | 神經本身受損；**灼熱、電擊、麻刺**，對一般止痛藥反應較差 | 帶狀疱疹後神經痛、化療神經病變、糖尿病神經病變 |
| **轉移痛**(referred pain) | 內臟痛**反映到遠處皮膚** | 膽囊炎 → **右肩胛**；心肌梗塞 → 左肩與左臂；橫膈刺激 → 肩膀 |
| **幻肢痛** | 截肢後仍感覺已不存在的肢體疼痛 | 截肢術後 |
| **突發性疼痛**(breakthrough pain) | 已用長效止痛藥控制良好，仍**突然出現**的短暫劇痛 | 癌症病人活動時 |

:::note[慢性疼痛的時間定義]
國際疼痛研究學會(IASP)與 ICD-11 定義**慢性疼痛為持續或反覆超過 3 個月**。部分國內教材寫「持續 1 個月以上」或「3–6 個月以上」，考題曾以「持續 1 個月以上」為正確答案；作答時選最接近「持續超過一段時間」的選項，臨床上以 3 個月為準。
:::

- **腔隙症候群**的疼痛：患肢緊繃、脈搏減弱、冰冷，**止痛藥無法緩解**，而且**被動伸展時劇痛**，是緊急狀況。

## 疼痛評估 {#assessment}

### 評估原則 {#assessment-principles}

- **病人的自我報告是最可靠的依據**；不能因為病人沒喊痛、在睡覺或在笑，就判斷沒有疼痛。
- **定時**評估(包括入院、每班、給止痛藥後、活動或換藥前後)，並記錄。
- **每個疼痛部位分開評估、分開記錄**，不要取平均。
- 生理徵象(**心跳加快、血壓上升、呼吸加快、瞳孔放大**、盜汗)在急性疼痛時可能出現，但慢性疼痛常沒有；**尿量**與疼痛沒有直接關係。
- 評估疼痛屬於**獨立性護理功能**；依醫囑給止痛藥屬於**非獨立性(依賴性)護理功能**。

### PQRST 評估 {#pqrst}

| 字母 | 內容 | 問法 |
|---|---|---|
| **P** | 誘發與緩解因素(Provoking／Palliating) | 「**什麼情況會讓疼痛更嚴重**？什麼會讓它好一點？」 |
| **Q** | 性質(Quality) | 刺痛、鈍痛、灼熱、**麻刺**、絞痛？(神經病變性的麻刺痛會影響**輔助藥物**的選擇) |
| **R** | 部位與放射(Region／Radiation) | 哪裡痛？會不會延伸到別處？ |
| **S** | 強度(Severity) | 0–10 分幾分？ |
| **T** | 時間(Timing) | 什麼時候開始？持續還是間歇？多久了？ |

### 評估工具 {#scales}

| 工具 | 適用對象 | 重點 |
|---|---|---|
| **數字量表**(NRS) | 能溝通的成人與較大兒童(約 **8 歲以上**) | **0 = 不痛，10 = 最痛**；請病人說出**當下**的分數 |
| 視覺類比量表(VAS) | 成人 | 10 公分直線上標示位置 |
| 語言描述量表 | 成人、老人 | 不痛、輕度、中度、重度 |
| **臉譜量表**(Wong-Baker FACES) | **約 3 歲以上**能表達的兒童 | 從笑臉到哭臉，讓孩子**挑選代表自己的臉** |
| 籌碼量表(Poker Chip) | 約 4 歲以上 | 用籌碼數量代表「疼痛有幾塊」 |
| **FLACC** 行為量表 | **2 個月到 7 歲**，或**無法用言語表達**(意識不清、認知障礙)的病人 | 5 項各 **0–2 分**：**臉**(Face)、**腿**(Legs)、**活動**(Activity)、**哭泣**(Cry)、**可安撫性**(Consolability)；總分 0–10，**越高越痛**。「雙腳持續踢動」屬於腿部 2 分。**沒有「呼吸型態」** |
| NIPS | **新生兒**(含早產兒) | 臉部表情、哭、**呼吸型態**、手臂、腿、清醒狀態 |
| CPOT、BPS | 加護病房**插管、無法說話**的成人 | 臉部表情、身體動作、肌肉張力、與呼吸器的配合 |
| PAINAD | **失智症**病人 | 呼吸、負向聲音、臉部表情、肢體語言、可安撫性 |

- **嬰兒**最可靠的疼痛指標是**臉部表情**(皺眉、擠眼、鼻唇溝加深、嘴巴張開)；嬰幼兒評估看臉部表情、哭泣、呼吸型態、肢體動作，不是「意識程度」。
- 兒童疼痛評估的 **QUESTT** 原則：詢問孩子(Question)、使用量表(Use)、評估行為與生理變化(Evaluate)、請父母參與(Secure)、考慮疼痛原因(Take cause)、採取行動並評值(Take action)。

## 止痛藥使用原則 {#analgesic-principles}

### WHO 止痛原則 {#who-principles}

1. **口服優先**(by mouth)
2. **按時給藥**(by the clock)：持續性疼痛要**定時給**，維持穩定血中濃度，**不要等痛了才給**
3. **依階梯**(by the ladder)
4. **個別化**(for the individual)：劑量依效果調整，**鴉片類沒有固定上限**
5. **注意細節**：預防副作用、評值、衛教

### 三階梯止痛 {#ladder}

| 階梯 | 疼痛程度 | 用藥 |
|---|---|---|
| 第一階 | **輕度**(1–3 分) | **非鴉片類**：acetaminophen、NSAIDs ± 輔助藥 |
| 第二階 | **中度**(4–6 分) | **弱效鴉片類**(codeine、tramadol)或**低劑量強效鴉片類** ± 非鴉片類 ± 輔助藥 |
| 第三階 | **重度**(7–10 分) | **強效鴉片類**(morphine、fentanyl、oxycodone、hydromorphone) ± 非鴉片類 ± 輔助藥 |

- 階梯是**從非鴉片類開始**往上爬；**重度疼痛可以直接從第三階開始**，不必一階一階等。WHO 2018 年指引將階梯定位為**教育與一般原則**，強調個別化評估(來源：[WHO 2018](https://www.who.int/publications/i/item/9789241550390)；[UpToDate：cancer pain](https://www.uptodate.com/contents/overview-of-cancer-pain-general-principles-of-management-and-pain-syndromes))。
- **可以合併不同作用機轉**的止痛藥(例：鴉片類加 acetaminophen 加輔助藥)，效果更好、各自劑量較低。
- 非鴉片類與弱效鴉片類有**天花板效應**(超過某劑量效果不再增加、副作用增加)；**強效鴉片類沒有天花板效應**。

### 輔助性止痛藥 {#adjuvants}

| 疼痛類型 | 輔助藥 |
|---|---|
| **神經病變性**(麻刺、灼熱、電擊) | **Gabapentin、pregabalin**、三環抗憂鬱劑(amitriptyline)、SNRI(duloxetine) |
| 骨轉移痛 | NSAIDs、**類固醇**、雙磷酸鹽或 denosumab、**放射治療** |
| 神經壓迫、腦水腫、腸阻塞 | **類固醇**(dexamethasone) |
| 肌肉痙攣、膽道或腸絞痛 | 肌肉鬆弛劑、抗膽鹼劑(**Buscopan**、atropine) |

### 突發性疼痛與給藥時間 {#breakthrough}

- 長效止痛藥**按時給**，另外開**短效的救援劑量**(約為每日總量的 **5–15%**)給突發性疼痛(來源：[UpToDate](https://www.uptodate.com/contents/cancer-pain-management-with-opioids-optimizing-analgesia))。
- 如果病人**還沒到下次給藥時間就痛到受不了**：**不要叫病人忍耐**，也不要說他已經耐藥或會成癮；應**進一步評估疼痛**，並**與醫師討論調整處方**(加救援劑量、增加劑量或縮短間隔)。
- 醫囑劑量或途徑不清楚時(例：開 IM 但病人只有靜脈管路、劑量不合理)，先**聯絡醫師澄清**，不要自行更改。

### 給藥途徑 {#routes}

- **口服優先**；無法口服時用**皮下、靜脈**、經皮貼片、直腸。
- **避免肌肉注射**：會痛、吸收不穩定，兒童尤其害怕打針。
- **休克、低血容**(例：**燒傷急救期**)：周邊循環差，肌肉與皮下吸收不可靠 → 用**靜脈注射**，小劑量分次給。
- 肌肉注射時減輕疼痛的方法：繃緊皮膚、快速進針與拔針、注射後按摩(依藥物)。**注射前熱敷**注射部位**不適當**。

### 病人自控式止痛(PCA) {#pca}

- 病人自己按鈕給藥(多為靜脈嗎啡或 fentanyl)，機器設定**每次劑量、鎖定時間**與上限，可加上**持續基礎劑量**。
- 優點：**血中濃度穩定**、止痛**更即時**、病人有控制感，**總用藥量通常較少**。
- **只能由病人自己按**；家屬或訪客「代按」可能造成過量。
- 監測**鎮靜程度與呼吸**(呼吸 < 10 次／分、叫不太醒 → 停用並通知醫師，依醫囑 **naloxone**)、噁心、搔癢、**尿瀦留**。
- 例：術後病人**呼吸 8 次／分**還在睡 → 不是讓他休息，要**立刻再次確認生命徵象**、評估鎮靜程度並處理。

### 硬膜外止痛 {#epidural}

- 經硬膜外導管給局部麻醉劑與鴉片類。
- 觀察：**呼吸抑制**(鴉片類可能延遲出現)、**低血壓**、下肢**無力或麻木**、**尿瀦留**、搔癢、導管部位感染；翻身下床前先評估下肢力氣。

## 非藥物處置 {#non-pharmacologic}

| 方法 | 機轉與重點 |
|---|---|
| **冷敷** | 血管收縮、減少腫脹、**降低神經傳導**、**提高疼痛閾值**；適合**急性損傷 24–48 小時內** |
| **熱敷** | 血管擴張、肌肉放鬆；適合**肌肉痙攣**、慢性痠痛；**急性發炎、出血、惡性腫瘤部位不可熱敷** |
| 冷熱敷的使用 | **間歇使用**(約 20–30 分鐘)，持續使用會產生反彈作用並增加組織損傷風險 |
| **按摩**、薦骨加壓、TENS | **閘門控制理論** |
| **擺位與支托** | 以枕頭**支托疼痛部位**、舒適臥位(例：骨轉移的髖部) |
| **分散注意力** | 看卡通、玩遊戲、聽音樂、說故事(依年齡選擇) |
| **放鬆技巧** | 深呼吸、漸進式肌肉放鬆、引導式想像；剖腹產傷口痛可教**呼吸放鬆技巧** |
| 認知行為、催眠、音樂治療 | 改變對疼痛的解讀，降低焦慮 |
| **EMLA 乳膏**(局部麻醉) | 打針、抽血等**侵入性處置前約 60 分鐘**塗在皮膚並覆蓋 |

- 非藥物方法是**輔助**，**不能取代**止痛藥；**不要只叫病人「放輕鬆」**而不處理疼痛。

## 特殊族群 {#populations}

### 兒童 {#children}

- 用適合年齡的量表(見 [[pain-management#scales]])，並讓父母參與。
- 輕度疼痛：**acetaminophen**(例：扁桃腺切除術後**按時**服用)；兒童**避免 aspirin**(雷氏症候群)。
- 中重度疼痛：**鴉片類(嗎啡)**，依體重計算，優先口服或靜脈；**避免 meperidine**(代謝物會引起抽搐)。
- **Codeine、tramadol**：12 歲以下兒童及 18 歲以下扁桃腺或腺樣體切除術後**禁用**(代謝差異可能造成致命的呼吸抑制)(美國 FDA 2017 年警語)。
- 常見錯誤觀念：「孩子沒喊痛就是不痛」「痛時再給藥可以減少副作用」「針劑優先」都是錯的。

### 老人與認知障礙者 {#elderly}

- 老人常**少報**疼痛；失智者用 **PAINAD** 等行為量表。
- 「**從低劑量開始、慢慢調整**」；避免 meperidine；注意 NSAIDs 的腸胃、腎臟、心血管風險。

### 臨終病人 {#end-of-life}

- 疼痛**不會因為感官衰退就消失**；要**持續評估**，並**按時**給止痛藥，**不要因為怕成癮而少給**。
- 無法口服時改**皮下或靜脈**，不用肌肉注射。瀕死兒童：**按時靜脈注射 morphine**。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確觀念 |
|---|---|
| 痛時再給藥比按時給藥好 | 持續性疼痛要**按時給**，另給救援劑量 |
| 第一階使用弱效鴉片類 | 第一階是**非鴉片類** |
| 鴉片類有天花板效應 | 強效鴉片類**沒有**天花板效應 |
| 優先考慮靜脈或肌肉注射 | **口服優先** |
| 不可併用不同類止痛藥 | **可以併用**不同機轉的藥 |
| 冷熱療會降低疼痛閾值 | 冷熱療**提高**疼痛閾值 |
| 冷療要持續不可間斷 | 冷熱療要**間歇**使用 |
| 經常用止痛藥一定會成癮 | 依醫囑用於疼痛時成癮少見；**耐受、生理依賴 ≠ 成癮** |
| 疼痛指數記錄取平均 | 每個部位**分開記錄** |

## 評值 {#evaluation}

- 給藥後依途徑評值：**靜脈約 15–30 分鐘**，**口服約 30–60 分鐘**。
- 評值要寫出**病人的反應與改變**，例如「疼痛指數由 7 分降至 4 分」，而不是只寫「已給止痛藥」。
- 同時評估副作用：**鎮靜程度、呼吸**、噁心、便秘、尿瀦留。

:::note[護理問題的優先順序]
病人同時有疼痛、無效性呼吸型態、便秘時，**呼吸問題最優先**；其餘依病人最困擾、最危急的程度排序。病人拒用止痛藥時，先了解原因(怕成癮、怕副作用)，提供衛教，並運用非藥物方法。
:::

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **閘門控制理論**：按摩、**尾骶骨按摩**、背部按摩、按撫法。
- 評估：**PQRST**(「什麼會讓疼痛更嚴重」是 P)；NRS **0 分不痛、10 分最痛**，請病人說出當下分數；每個部位分開記錄。
- 兒童工具：**2 歲術後換藥、意識不清的嬰幼兒 → FLACC**；**3 歲 → 臉譜量表**；FLACC 每項 **0–2 分**，**沒有呼吸型態**；**嬰兒最佳指標是臉部表情**。
- 三階梯：**按時給藥、口服優先、從非鴉片類開始**；解毒劑 **naloxone**；**PCA 可減少總藥量**。
- 燒傷休克期止痛用**靜脈注射**；癌末骨轉移重度疼痛 → **靜脈 morphine 並以枕頭支托**。
- 服藥後提前疼痛 → **進一步評估並與醫師討論調整處方**。
- 評值寫**疼痛分數的變化**；評估疼痛是**獨立性**功能，依醫囑給藥是**非獨立性**功能。
- 慢性疼痛：持續超過一段時間(考題答案「1 個月以上」，IASP 為 3 個月)；尿量與疼痛評估較無關。
:::
