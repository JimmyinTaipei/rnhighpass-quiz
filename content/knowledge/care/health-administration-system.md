這一頁整理**誰負責什麼**：中央的衛生福利部各司署、地方的衛生局與**衛生所**，以及臺灣健康照護體系的分層（預防保健、急性醫療、後續照護）與偏鄉離島政策。國考最常考「某項業務屬於哪個司或署」。社區護理師的角色與健康政策見 [[community-health-nursing-intro]]；健保制度見 [[national-health-insurance]]；長照體系見 [[long-term-care]]

## 重點摘要 {#summary}

- **衛生福利部**是中央最高衛生行政機關（2013-07-23 由衛生署與內政部社政業務整合成立）；地方是 **22 縣市衛生局**與**衛生所**
- 職掌口訣：**疫情監測 → 疾管署**；**菸檳、癌症篩檢、婦幼與慢性病 → 國健署**；食品藥物 → 食藥署；健保 → 健保署；**原住民族與離島醫療、護理 → 護理及健康照護司**；**醫院評鑑、醫事人員、緊急醫療 → 醫事司**；**長照 → 長期照顧司**；家暴性侵防治 → **保護服務司**
- 2026-09-30 組織法修正公布：社家署改為**兒少及家庭支持署**，長照業務併入新的**社會發展及長期照顧署**；**施行日待行政院定**（截至 2026-10）
- 衛生所三類：都市以**預防保健**為主；一般鄉鎮預防為主、醫療為輔；**偏遠山地離島預防與醫療並重**、以居家護理為重點
- 偏鄉離島：**IDS 計畫**、「**醫師動、病人不動**」、**在地醫療為主、空中轉診為輔**、偏鄉數位資訊醫療照護網

### 國考常考點 {#exam-points}

- 我國最高衛生行政機關：**衛生福利部**（不是國健署、衛生局）
- 「發展及提升**原住民族及離島**地區健康照護品質」、部落社區健康營造補助：**護理及健康照護司**
- **醫院評鑑**與教學醫院評鑑：**醫事司**
- 推動長照 2.0：**長期照顧司**
- 疾管署宗旨：建立現代化防疫體系，免除國人疫病威脅；疫情監測與警訊發布是疾管署，不是國健署
- 菸品與檳榔危害防制：**國健署**，不是食藥署；家暴防治法規：**保護服務司**，不是照護司
- 衛生所護理師的範疇：家戶健康管理、慢性病防治、癌症防治；**食品衛生稽查**屬於衛生局，不是衛生所護理師
- 基層醫療的服務**不包括罕見疾病治療**
- **群體醫療執業中心設在衛生所內**（不是私人診所），以門診醫療為主，改善山地離島與偏遠地區醫療
- 社區醫療群與家庭醫師整合照護是**自願參加**，「每個家庭都有家庭醫師」**不是**現況
- 偏鄉政策**不是**「病人動、醫師不動」，也**不是**興建醫學中心；離島以在地醫療為主
- 民眾在死亡前得到尊嚴的安寧服務，屬於健康照護體系中的**復健及後續性服務**

## 中央衛生行政組織 {#central}

### 衛生福利部 {#mohw}

- 2013-07-23 由**行政院衛生署**與**內政部社政業務**整合成立
- 現行組織（衛福部網站，2026-06 更新）：
   1. **業務單位 10 司**：綜合規劃司、社會保險司、社會救助及社工司、護理及健康照護司、保護服務司、醫事司、心理健康司、中醫藥司、長期照顧司、口腔健康司
   2. **輔助單位 6 處**：秘書、人事、政風、會計、統計、資訊
   3. **所屬機關**：疾病管制署、食品藥物管理署、中央健康保險署、國民健康署、社會及家庭署（國民年金局暫不設置）
   4. 任務編組：全民健康保險會、全民健康保險爭議審議會等

| **綜合規劃司** | 衛福政策規劃與考核、衛生教育 | |

- 加害人處遇在**心理健康司**、被害人保護在**保護服務司**

| 署 | 職掌 |

| **國民健康署** | 生育健康、婦幼、**國民健康促進**、**癌症**與其他非傳染病防治、**菸害與檳榔防制**、衛生所業務督導 |

| **社會及家庭署** | 現行：老人、身障、婦女、兒少與家庭福利；2026 修法後改為兒少及家庭支持署 |

### 2026 組織法修正 {#reorganization-2026}

- 衛生福利部組織法 **2026-09-30 修正公布**（第 2、5、8 條），**施行日期由行政院以命令定**；截至 2026-10 未見施行命令
- 新的次級機關：疾管署、食藥署、健保署、國健署，加上：
   1. **兒少及家庭支持署**：托育照顧、早期療育、兒少福利與權益、家庭支持、兒少健康與醫療照護
   2. **社會發展及長期照顧署**：高齡者與身心障礙者權益福利、**長期照顧**、國民年金
- 刪除原社會及家庭署；第 2 條掌理事項明列原住民族與離島醫療、心理健康與成癮防治、口腔健康等
- 國考目前仍以舊組織（社家署、長照司）出題，作答依題目年份

## 地方衛生行政與衛生所 {#local}

- 地方：**22 個縣市政府衛生局**，下轄**衛生所**（2020 年底 374 所，課本引國健署）；直轄市衛生局例如新北市設健康管理、疾病管制、醫事管理、食品藥物管理、心理衛生、長照、衛生稽查等科
- 衛福部對地方衛生機關有業務**指導、監督與協調**責任

### 衛生所 {#health-station}

- 最基層的醫療衛生服務單位，1945 年首創
- 各階段任務（課本整理）：

| 時期 | 重點 |
|---|---|
| 1945–1960 服務體系擴展期 | **傳染病防疫**；每鄉鎮一衛生所、每縣市一衛生局，瘧疾、天花等相繼根除 |
| 1961–1982 特定服務期 | **結核病防治**、**家庭計畫**、婦幼衛生 |
| 1983 年起整合轉型期 | **群體醫療執業中心**、基層保健服務中心，綜合保健醫療；1997 年起社區健康評估訓練 |
| 1995 年起全民健保時期 | 社區整合性照護網絡、**健康促進**、社區健康營造、健康城市、四癌篩檢、結核病都治、高齡友善、長照 2.0 |

- 衛生所三種類型：
   1. **都市**地區：以**預防保健**為主
   2. **一般鄉鎮**：預防保健為主、醫療為輔
   3. **偏遠地區**（含山地、離島）：**預防保健與醫療並重**，以**居家護理**為重點的基層保健服務
- 主要業務：菸害防制、婦幼衛生、癌症與慢性病防治、社區健康營造、門診醫療、行政相驗、**預防接種**、監測通報、傳染病防治、精神病人管理、長期照護、緊急醫療
- **衛生所護理師**的範疇：家戶健康管理、中老年病防治、癌症防治、預防接種等；**食品衛生稽核**是衛生局稽查人員的業務
- 困境：慢性病與失能年數增加、業務量與考核目標上升，人力增加跟不上，都市衛生所護理人員流動率高

### 群體醫療執業中心 {#group-practice-center}

- 為了醫療資源缺乏地區，**1983 年試辦 12 所**，由教學醫院醫師支援
- **設在衛生所內**，負責衛生所的**門診醫療**，同時協助預防保健，強化衛生所整體功能
- 對象是山地、離島與偏遠地區

### 社區醫療群與分級醫療 {#community-medical-group}

- 健保推動**家庭醫師整合照護計畫**：多家基層診所與合作醫院組成**社區醫療群**，提供會員（**自願參加**）周全性、協調性與持續性的照護
- 「**厝邊好醫師，社區好醫院**」：強化衛生所社區健康評估、建立在地化社區醫療照護網絡、**雙向轉診**、地區醫院與基層醫師合作
- 現況**不是**每個家庭都有家庭醫師

## 健康照護體系 {#care-system}

### 三段照護 {#three-tiers}

| 段 | 服務 | 機構 |
|---|---|---|
| 第一段 | **公共衛生與預防保健** | 衛生所、診所、社區醫療群 |
| 第二段 | **急性醫療** | 醫學中心、區域醫院、地區醫院 |
| 第三段 | **復健及後續性服務**：急性後期照護、長照、**安寧** | 護理之家、長照機構、日間照護、居家服務、慢性醫院、安養機構 |

- 強調民眾在**死亡前得到尊嚴**的安寧緩和療護屬於**復健及後續性服務**

### 各子體系 {#subsystems}

- **健康促進體系**（國健署）：營養與肥胖防治、**四癌篩檢**（大腸癌、子宮頸癌、口腔癌、乳癌）、戒菸與無菸無檳環境、健康識能
- 公費篩檢條件（國考 111-2 題依當時規定）：原住民成人預防保健與 B、C 肝炎篩檢年齡比一般民眾早、子宮頸抹片 30 歲以上、乳房攝影 45–69 歲（或 40–44 歲有家族史）；**2022 年（111 年）7 月起加入肺癌低劑量電腦斷層，成為五癌**（子宮頸、乳、大腸、口腔、肺）；**2025 年（114 年）起再擴大**（乳癌 40–74 歲、大腸癌 45–74 歲、子宮頸抹片 25 歲起、特定年齡新增 HPV 檢測），條件表見 [[national-health-insurance#preventive-services]]
- **傳染病管制體系**（疾管署）：2005 年成立**國家衛生指揮中心**，中央、區域、地方三層聯防；法定傳染病見 [[notifiable-diseases]]，預防接種見 [[immunization]]
- **食品藥品安全**：**食安五環**（源頭控管、重建生產管理、加強查驗、加重黑心廠商責任、全民監督）
- **醫療資源配置**：社區醫療群、分級醫療與雙向轉診；醫療機構設置標準第 12-1 條全日平均護病比（見 [[nurse-staffing-policy]]）
- **緊急醫療救護**：6 區緊急醫療應變中心、急救責任醫院、AED 設置與民眾 CPR 訓練、緊急醫療資源缺乏地區改善計畫
- **特殊照護體系**：
   1. **急性後期照護**（PAC，Post-Acute Care）：介於急性醫療與長照之間，例如腦中風、燒燙傷急性後期整合照護
   2. **安寧緩和療護**：安寧緩和醫療條例、意願書與健保卡註記、安寧共同照護與社區安寧；法規細節見 [[end-of-life-care#law]]
   3. **口腔健康**照護
   4. **成癮防治**：藥癮替代治療、酒癮治療補助、網路成癮；見 [[substance-use-disorders]]
- **長照體系**：長照服務法與長照 2.0 的 ABC 社區整體照顧，見 [[long-term-care]]、[[long-term-care-services]]
- **精神疾病照護**：社區關懷訪視、精神醫療與復健、社區心理衛生中心，見 [[community-mental-health]]
- **醫事人力**：2020 年公共衛生師法公布，公共衛生師負責環境健康風險、疫病調查、健康調查與促進、食品安全風險等方案

## 偏鄉與離島醫療 {#rural-island}

- **IDS 計畫**（全民健康保險山地離島地區醫療給付效益提升計畫，Integrated Delivery System）：由有能力、有意願的**責任醫院**到山地離島提供**專科門診、定點與巡迴醫療**、急診與後送；目標「**鄉鄉有醫療、村村有支援**」，原則「**醫師動、病人不動**」「醫療不中斷」
- **偏鄉數位資訊醫療照護網**：醫學影像傳輸（PACS，Picture Archiving and Communication System）遠距判讀、衛生所**電子病歷互通**，達成醫療在地化
- **空中轉診**：2018 年蘭嶼後送直升機失事後，政策改為「**在地醫療為主、空中轉診為輔**」，並建立空中轉診後送遠距會診平臺雙重把關
- 人力：公費生培育、在地醫事人員養成、離島與山地開業獎勵
- 西醫、中醫、牙醫的醫療資源不足地區改善方案（巡迴醫療）
- **不是**積極興建離島醫學中心，也**不是**「病人動、醫師不動」

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 最高衛生行政機關是國健署 | **衛生福利部** | 國健署是所屬機關 |
| 疫情監測與警訊發布是國健署 | **疾管署** | |
| 菸檳危害防制是食藥署 | **國健署** | |
| 原住民與離島醫療是醫事司 | **護理及健康照護司** | 處務規程第 9 條 |
| 家暴防治法規是照護司 | **保護服務司** | |
| 國健署負責長照與離島醫療 | 長照：**長照司**；離島：**照護司** | |
| 衛生所護理師負責食品稽查 | 食品稽查是**衛生局** | |
| 群體醫療執業中心設在私人診所 | 設在**衛生所內** | |
| 偏鄉「病人動、醫師不動」 | **醫師動、病人不動** | |
| 安寧屬於急性醫療服務 | 屬於**復健及後續性服務** | |
