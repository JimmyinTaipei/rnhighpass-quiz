**護理過程**是護理師用來解決護理對象健康問題的科學化方法：有系統地收集資料、找出問題、訂目標與措施、執行，再看有沒有達到目標。國考考點集中在**主觀與客觀資料的分辨**、**護理診斷怎麼寫才對**、**問題的優先順序**、**目標怎麼寫才具體**、**獨立性與非獨立性措施**，以及**評值存在於每一步**。護理記錄的寫法（SOAPIE：subjective, objective, assessment, plan, implementation, evaluation；DART：data, action, response, teaching）見 [[documentation-orders]]，會談與觀察技巧見 [[observation-communication]]，Maslow 需要層次見 [[motivation-theories#maslow]]

## 重點摘要 {#summary}

- 五步驟：**評估 → 診斷 → 計畫 → 執行 → 評值**；有些書分四步（評估含診斷）或六步（多「目標」，美國護理學會 ANA, American Nurses Association 1991）
- 特點：**以病人（全人）為中心**、開放動態可隨時修訂、**以目標為指引**、有時效與持續性、循環回饋、**雙向人際互動**；不是以治癒疾病為中心
- 與醫療過程不同：醫療過程以**生物化學模式**找疾病；護理過程以**整體性模式**收集全人需求、找病人的反應
- **主觀資料**：病人、家屬、重要他人**說出來**的感受（「我好痛」「他晚上都睡不著」）；**客觀資料**：護理師或醫療人員**看到、量到、檢查到**的（臉色蒼白、R 26 次／分、肌力 3 分、引流液淡紅）
- **初級（第一手）資料來源**＝意識清楚的病人本人；家屬、醫療團隊、病歷、文獻是次級來源
- 護理診斷 **PES**：P 健康問題（診斷名稱）、E 相關因素（原因）、S 徵象與症狀（定義特徵）
- 優先順序：**威脅生命優先** → 依 **Maslow** 生理 → 安全 → 愛與歸屬 → 自尊 → 自我實現；不威脅生命時尊重病人自覺最重要的；相關問題排在一起
- 成果目標：以**病人為主詞**、可觀察可測量、有**時間**與**標準**（例：「3/15 病人能說出三種以上富含鐵質的食物」）
- **評值**不是只在最後，**每一步都要評值**；目標未達成要找原因，不一定是措施不好

### 國考常考點 {#exam-points}

- 特點：「以疾病治癒為中心」錯(112-2_FA_013)；「以**生物化學模式**為依據」是醫療過程(105-1_FA_015)
- 安寧病人自拔鼻胃管：符合護理過程特點的是「**跟病人共同討論可行的方法**」，不是寫「不遵從」(114-2_FA_005)
- 評估收集**身心靈、社會、認知、發展**等過去與現在的資料(114-3_FA_005)；評估資料**可以**作為評值依據(105-2_FA_012)；病人主訴與病歷不符再向照顧者確認＝**評估**(113-1_FA_006)
- 主觀資料：家屬說「昨天就開始喘了」(113-3_FA_006)、家屬說病人不吃青菜少喝水(107-1_FA_012)、家屬說「他晚上都沒辦法睡覺」(106-2_makeup_FA_014)、病人說「我好痛好不舒服」(111-1_FA_012)
- 客觀資料：**肌力 3 分**(113-2_FA_009)、**呼吸淺快 25 次**(110-2_FA_019)、**臉色蒼白盜汗**(110-2_FA_025)、**胸管引流液淡紅色**(109-2_FA_016)；取得客觀資料的方法：**儀器檢查、觀察**(112-1_FA_011)
- 第一手資料來源：**病人本人**說「我覺得胸悶」(109-2_FA_019)
- PES 三要素是 P.E.S. 不是 P.E.O.；健康問題＝診斷名稱、徵象症狀＝定義特徵(112-3_FA_007)；三要素沒有「健康目標」(112-1_FA_012)
- 「只要一個明顯表徵就能確立診斷」錯(110-1_FA_011)；護理診斷不是「以治療為目標」(105-1_FA_016)
- 書寫：「脊髓損傷」（醫學診斷）不能當導因，「缺乏護理指導」不能當導因(112-1_FA_014)
- 睡眠型態紊亂的鑑定性特徵：醒來 3 次、日間打瞌睡、反應遲鈍；「**病房太吵**」是**相關因素**不是特徵(109-2_FA_018)
- 計畫階段**不包括收集資料確立問題**(115-1_FA_007)；目標「主要以護理師經驗設定」錯(115-1_FA_009)；目標**需要醫療團隊認同支持**(106-2_makeup_FA_013)
- 優先順序：「護理人員覺得最重要的優先」錯(114-1_FA_005)；術後**居家照顧知識缺乏排最後**(112-2_FA_012)；氣爆傷患優先處理**欠穩定的生命徵象**(108-2_FA_017)；Maslow 排序 **②呼吸 ①社交 ④身體心像 ③靈性**(112-1_FA_010)
- 最具體目標：「3/15 病人能**說出三種以上**富含鐵質的食物」(113-2_FA_008)；「**二星期後傷口縮小至 3×2×1 cm**」(110-2_FA_024)；「5/29 病人能攝取 **2,000 大卡／天**」(109-2_FA_017)；「病人能解釋血糖控制與合併症關係」＝**認知目標**(113-1_FA_009)
- 計畫：病人與親友**要參與**擬定(106-2_FA_013)；措施要具體：「睡前給予 **250 mL 溫牛奶**」(106-2_makeup_FA_007)
- 執行期：**提供個別性照護活動**(112-3_FA_006)；**獨立性**護理活動：**教導初產婦哺餵母乳**(112-2_FA_014)；與家屬協助偏癱病人每天練走＝**治療性**措施(108-2_FA_024)
- 評值：**每一步都可評值**（114-2_FA_008、107-2_FA_013）；「是最後一個步驟」錯(111-2_FA_014)；冰枕 20 分鐘後問感覺＝**評值**(106-1_FA_009)；「10/13 褥瘡傷口已改善」**不具體**(108-1_FA_015)

## 基本概念 {#concepts}

### 問題解決法 {#problem-solving}

| 方法 | 特點 |
|---|---|
| 與生俱來 | 不經思考、靠本能；過度驚嚇時常用，**失敗率最高** |
| 嘗試錯誤 | 不斷試；浪費人力金錢，用在病人身上可能危及生命 |
| 洞察性 | 試過幾次後理解事件關係，下次直接用對的方法 |
| 想像推論 | 先猜整體情況再推論 |
| **科學化** | 邏輯、系統化，**最有效**；護理過程就是科學化的問題解決 |

- 臨床問題解決六步驟(deWit)：確立問題 → 收集資料 → 分析 → 發展方案 → 執行 → 評值
- 來源：實用基本護理學上冊 p.249–250

### 發展與步驟數 {#history}

- 1955 年 **Lydia Hall** 最早提出「護理過程」，分三步
- 1973 年美國護理學會(ANA)：**五步**（評估、診斷、計畫、執行、評值）
- 1991 年 ANA：**六步**，把「成果確認（目標）」獨立出來
- 四步驟的分法把診斷併入評估、目標併入計畫
- 來源：同書 p.251、255

### 護理過程與醫療過程 {#vs-medical}

| | 護理過程 | 醫療過程 |
|---|---|---|
| 依據 | **整體性模式**：生理、心理、靈性、社會、認知、發展 | **生物化學模式**：生理、病理、化學 |
| 尋找 | 病人對現存或潛在健康問題的**反應**、促進健康的需求 | **疾病** |
| 結論 | **護理診斷** | 醫學診斷 |
| 處置 | 護理處方＋協同醫療處方 | 醫師處方治病 |
| 目的 | 滿足全人基本需求 | 恢復身體健康 |

- 來源：同書表 6-2 p.252

### 特點與功能 {#characteristics}

1. 特點
   1. **開放、有彈性、動態**：隨需求改變修訂計畫
   2. **個別性、整體性的全人照顧**，以病人為中心
   3. **以目標為指引**，有計畫、有時效、持續
   4. 循環系統，強調**回饋**與隨時評值
   5. 有創意地解決問題
   6. 是護理師與護理對象的**雙向人際互動**
   7. 滿足個人、家庭、社區的需求
2. 對病人的功能：提升照護品質、得到持續照顧、**參與自我照顧**
3. 對護理師的功能：增加信心與成就感、促進專業成長、增加責任感、提升專業價值
- 病人拒絕或自拔管路時，符合護理過程精神的是**與病人共同討論**可行方法，而不是把病人的行為寫成「不遵從」
- 來源：同書 p.252–254

## 護理評估 {#assessment}

- 第一步，有系統地收集與健康有關的資料並驗證；是**持續**的過程
- 用途：確立護理診斷的基礎、整體照顧、有效措施、**作為評值的依據**、研究
- 來源：同書 p.256

### 主觀與客觀資料 {#data-types}

| | 主觀資料(S) | 客觀資料(O) |
|---|---|---|
| 誰提供 | **病人、家屬、重要他人**說出來的 | 醫療專業人員用感官或儀器取得 |
| 例 | 病人：「我肚子脹、頭好痛」<br>家屬：「很少看到他喝水」「他昨天一直起來上廁所」<br>看護：「他每晚醒 3–4 次」 | 臉色蒼白、冒冷汗、淚流滿面抱肚子<br>BP(blood pressure)、HR(heart rate)、R、SpO₂、體溫<br>肌力 3 分、輸出入量<br>引流液顏色、傷口大小 |
| 方法 | **會談** | **觀察、檢查、儀器** |

- 判斷的關鍵：**看是誰「說」的**。家屬或看護說的仍是主觀資料；護理師記錄「病人說不喜歡下床」也是轉述病人的話，仍屬主觀
- 觀察到的**行為**（淚流滿面、皺眉、不敢翻身）是客觀資料
- 來源：同書 p.256

::questions{ids="113-3_FA_006,113-2_FA_009,112-1_FA_011,111-1_FA_012,110-2_FA_019,110-2_FA_025,109-2_FA_016,107-1_FA_012,106-2_makeup_FA_014"}

### 資料來源 {#data-sources}

1. **初級（第一手）來源**：**病人本人**，前提是意識清楚、精神穩定、不是嬰幼兒；提供的是主觀資料
2. 次級來源
   1. 家屬、親友、保母：病人無法表達時提供；**仍是主觀資料**
   2. 健康團隊成員：醫師、護理師、檢驗師、營養師、社工；客觀資料，但只能描述事實、**不能加入自己的主觀意見**
   3. 病歷與健康記錄：較完整客觀
   4. 文獻與書籍
3. 嚴重腦損傷無法表達的病人，哭泣反應是護理師**觀察到的**資料，不是病人的第一手陳述
- 來源：同書 p.256–257

::questions{ids="109-2_FA_019,114-3_FA_005,105-2_FA_012,113-1_FA_006"}

### 收集方法與注意事項 {#data-collection}

1. 方法：**會談**、**直覺**（專業經驗判斷）、**觀察**（護理師的**獨立性功能**，用視聽嗅觸）、**檢查**（生命徵象、身體檢查、檢驗）
2. 注意
   1. 有深度與廣度，但不侵犯隱私
   2. 安靜、隱蔽、舒適的環境
   3. 用正確的工具與熟練技術
   4. **不加主觀評斷**
   5. 用系統性表格較完整；收集後要記錄
3. 發現資料互相矛盾（例：病人說的與病歷的家庭樹不同）→ 再向照顧者確認，仍屬**評估**
- 來源：同書 p.257–258

### 評估架構 {#frameworks}

1. 全人六層面：生理、心理、社會、發展、認知、靈性
2. 常用架構：**Gordon 11 項功能性健康型態**（臨床最常用）、NANDA-I（NANDA International，前身為北美護理診斷協會）分類型態 II（13 個領域、47 個類別，由 Gordon 修訂而來）、Maslow 需要層次、Henderson 14 項需要、Roy 適應模式、Orem 自我照顧
3. NANDA-I 13 領域：健康促進、營養、排泄與交換、活動／休息、知覺／認知、自我知覺、角色關係、性學、因應／壓力耐受、生命原則、安全／保護、舒適、生長／發展
- 來源：同書 p.258–263、表 6-3

## 護理診斷 {#diagnosis}

- 第二步，是**評估的最後結果**；描述**病人對健康問題或生命過程的反應**，是護理師在權責內可以處理的
- 北美護理診斷協會(NANDA, North American Nursing Diagnosis Association)1982 年成立，2002 年改名 **NANDA International(NANDA-I)**
- 來源：同書 p.259、267–268

### 三要素 PES {#pes}

| 要素 | 內容 | 例：睡眠型態紊亂 |
|---|---|---|
| **P** 健康問題 | 診斷**名稱** | 睡眠型態紊亂 |
| **E** 相關因素 | **原因**，要是護理能處理的 | 活動太少、**病房太吵**、室溫太熱 |
| **S** 徵象與症狀 | 又稱**定義特徵**、**線索**；是「一群」，分主要與次要線索 | 夜醒 3 次以上、超過 30 分鐘才睡著、白天打瞌睡、反應遲緩 |

- 不能只靠**一個**表徵就確立診斷
- 措施主要針對**相關因素**（矯正導因）
- 來源：同書 p.267–270、表 6-7

::questions{ids="112-3_FA_007,112-1_FA_012,110-1_FA_011,109-2_FA_018"}

### 三種類型 {#diagnosis-types}

| 類型 | 定義 | 寫法 |
|---|---|---|
| **問題焦點性** | 已經存在的問題 | 直接寫名稱，例：睡眠型態紊亂；要有定義特徵與相關因素 |
| **潛在危險性** | 暴露在危險因素中、容易發生 | 名稱前加「**潛在危險性**」，例：潛在危險性便秘；寫危險因素 |
| **健康促進性** | 想增進安適、實現健康潛能 | 名稱前加「**增進的準備度**」，例：增進睡眠的準備度 |

- 來源：同書表 6-6 p.269

### 命名過程與書寫 {#writing}

1. 命名五步：收集資料 → 組織分類 → 分析（與正常比較，設假設） → 確立問題（對照定義特徵、確認導因是護理能處理的） → 命名
2. 寫法：「**診斷名稱／相關因素**」，或「…與…有關」
3. 書寫指引

| 不可以寫成 | 錯誤例 | 正確例 |
|---|---|---|
| **醫學診斷** | 腦血管意外 | 潛在危險性皮膚完整性受損／腦血管意外引起固定不動 |
| 治療性需要 | 需要情緒支持 | 恐懼／對手術過程不了解 |
| 症狀或徵象 | 頭痛、血壓 180/140 | 潛在危險性損傷／高血壓導致頭暈 |
| 治療或檢查 | 注射胰島素、心導管 | 焦慮／對胰島素注射知識不足 |
| **護理目標** | 維持理想體重 | 營養失衡：少於身體需要／化療致食慾差、口腔破損 |
| **價值判斷** | …／懶惰 | 沐浴自我照顧能力缺失／關節腫痛無力 |
| **醫學診斷當導因** | 皮膚完整性受損／**脊髓損傷** | 寫出脊髓損傷造成的「固定不動」 |
| **可能引起法律糾紛的導因** | 知識缺失／**缺乏護理指導** | 知識缺失／對高血壓藥物知識不足 |
| 護理師遇到的問題 | 不合作、不順從 | 找出背後原因 |
| 兩個問題寫在一起 | 焦慮、活動耐力減少／… | 分開兩個診斷 |

- 「口腔黏膜改變／化療抵抗力低」「睡眠型態紊亂／治療造成不適」是可接受的寫法
- 來源：同書 p.270–275

::questions{ids="112-1_FA_014,105-1_FA_016"}

## 護理計畫 {#planning}

- 第三步，三件事：**排優先順序 → 訂目標 → 擬措施**；計畫階段不再收集資料確立問題
- 來源：同書 p.275

::questions{ids="115-1_FA_007"}

### 優先順序 {#priority}

1. **威脅生命**的先處理（呼吸、循環、生命徵象不穩）
2. 依 **Maslow** 需要層次：**生理** → 安全 → **愛與歸屬**（社交） → **自尊**（身體心像） → **自我實現**（靈性）
3. 不威脅生命時，**病人自覺最重要**的可以優先（不是護理師覺得最重要的）
4. 相關的問題排在一起（導因在前、結果在後）
5. 排優先不代表要等前一個解決，可以同時處理
- 例：結腸切除剛回病房 → 呼吸道清除無效、周邊組織灌流、急性疼痛優先，**居家照顧知識缺乏排最後**
- 例：氣爆傷患 → 先處理**生命徵象不穩定**，焦慮與身體心像之後
- 來源：同書 p.275–276

::questions{ids="114-1_FA_005,112-2_FA_012,112-1_FA_010,108-2_FA_017"}

### 護理目標的種類 {#goal-types}

| 分類 | 種類 | 說明 |
|---|---|---|
| 時間 | **短程** | 通常**少於一週**；例：三天內不靠灌腸能自解 |
| | **長程** | 長期照護才能達成；例：居家期間無皮膚破損 |
| 衛教目標 | **認知** | 知道、理解、應用、分析、判斷；例：能**解釋**血糖控制與合併症的關係 |
| | **情意** | 態度、價值、信念 |
| | **技能** | 能正確操作技術 |
| 敘述方式 | **過程（中心）目標** | 護理師的期待，用概念性字眼：維持、促進、預防、減輕；例：維持呼吸道通暢 |
| | **成果（具體）目標** | **病人**接受照護後能達成的，**寫在護理計畫表**，是評值的依據；例：一星期內呼吸音清澈 |

- 來源：同書 p.276–278、表 6-9

::questions{ids="113-1_FA_009"}

### 成果目標怎麼寫 {#outcome-criteria}

1. 要素：**對象**（病人本人可省略；照顧者要寫出）、**行動**（可觀察、可測量的動詞：說出、做出、增加）、**情況**、**結果**、**標準**、**特定時間**
2. 例：一星期時，病人在早餐前測得的血糖能在 140 mg/dL 以下
3. 判斷具體與否

| 不具體 | 具體 |
|---|---|
| 協助病人下床活動（主詞是護理師，是措施） | 3/15 病人能說出三種以上富含鐵質的食物 |
| 病人使用止痛藥後疼痛緩解（緩解多少？） | 給止痛藥後疼痛降到 2 分 |
| 病人能增加纖維質攝取量（增加多少？） | 5/29 病人能攝取 2,000 大卡／天 |
| 一星期內傷口完全癒合（不切實際） | 二星期後傷口縮小至 3×2×1 cm |
| 提供高熱量高蛋白飲食（是措施） | 病人體重在○月○日前增加○ kg |

4. 設定原則
   1. **切合實際**：符合病人的能力與資源（2 公斤早產兒一個月長到 4 公斤不可能）
   2. 護理師有能力執行並達成（末期癌痛「去除疼痛」做不到，「減輕不適」可以）
   3. **病人可接受**：與病人、照顧者共同討論
   4. **醫療團隊認同支持**，不與治療目標衝突（醫囑限制下床，就不能訂每天下床 30 分鐘）
   5. 不是只依護理師的專業經驗設定
- 來源：同書 p.277–278

::questions{ids="113-2_FA_008,110-2_FA_024,109-2_FA_017,115-1_FA_009,106-2_makeup_FA_013"}

### 擬訂護理措施 {#interventions}

1. 原則
   1. 依據目標；去除或減輕**相關因素**
   2. 與醫療計畫協調，不互相抵觸
   3. 個別性、整體性
   4. **入院就要擬訂**，隨問題改變修訂
   5. **病人與親友一起參與**
   6. 考慮單位的人力、設備、時間與經費
   7. 文字**簡明、具體、可執行**：寫出誰、做什麼、何時、如何、幾次、多久、何處（例：睡前給予 250 mL 溫牛奶；依翻身表由家屬每 2 小時協助翻身拍背）
2. 依護理功能分類

| 功能 | 定義 | 例 |
|---|---|---|
| **非獨立性** | 依**醫囑**執行 | 導尿、給氧、給抗生素、置中心靜脈導管 |
| **獨立性** | 不需醫囑，依專業判斷 | **衛教**（教初產婦哺餵母乳）、個人衛生、擺位、翻身、觀察、誘尿按摩 |
| **相依性**（合作性） | 與團隊合作 | 與營養師訂飲食、與社工討論出院、與藥師討論用藥；**執行 p.r.n. 醫囑**（先判斷再給） |

3. 依活動特性：**治療性**（處理現存問題）、修復性與支持性（慢性問題）、**預防性**（避免可能的問題）；國考 108-2_FA_024 把協助偏癱病人每天練習走路歸為**治療性**
- 來源：同書 p.278–280、表 6-10

::questions{ids="106-2_FA_013,106-2_makeup_FA_007,112-2_FA_014,108-2_FA_024"}

## 護理執行 {#implementation}

1. 執行前：**再評估**，確認計畫仍合宜、了解學理與技術
2. 執行時：了解目的、準備環境、注意**安全、舒適、自主、尊嚴**；同時**衛教**；依病人自我照顧能力（Orem：完全代償、部分協助、支持教育）；鼓勵病人與家屬參與；隨時觀察反應
3. 執行後：新問題報告團隊；**記錄**原因、過程、結果
- 執行期的工作是**提供個別性照護活動**；確認資料正確屬評估、排優先屬計畫、重設目標屬評值後的修訂
- 來源：同書 p.280–281

::questions{ids="112-3_FA_006"}

## 護理評值 {#evaluation}

1. 意義：看病人執行措施後的反應**是否達到成果目標**；持續、系統的批判性思考
2. **評值不是最後一步**，而是**存在於每一個步驟**中，從初步評估後就開始
3. 步驟：確認成果目標 → 計畫 → 執行 → 評估反應 → **與目標比較**（全部、部分、未達成） → 未達成就**再評估**（診斷錯？目標不切實際？沒按計畫做？出現新問題？） → **修訂護理診斷**、目標或計畫 → 回饋
4. 目標未達成**不一定是措施不好**，要找原因；全部達成表示問題解決，可以結案
5. 書寫：**日期＋病人表現的具體行為**（可省略達成程度）；例：4/7 壓力性損傷傷口 0.5×0.7×1 cm
6. 例：冰枕使用 20 分鐘後詢問病人感覺 → **評值**
- 來源：同書 p.281–283

::questions{ids="114-2_FA_008,111-2_FA_014,108-1_FA_015,107-2_FA_013,106-1_FA_009"}

## 護理計畫表單 {#care-plan-form}

1. 依護理過程步驟書寫：問題出現日期、**護理診斷**（名稱、相關因素、主客觀資料）、**成果目標**、護理計畫、**護理評值**
2. 簡明、具體，用醫學專門術語；各機構格式不同，許多醫院已電腦化
3. 目的：照顧指引、持續性照顧、團隊聯繫、教學、評值依據、研究與考核
- 記錄範例（SOAPIER、焦點記錄）見 [[documentation-orders#methods]]
- 來源：同書 p.284–285

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 |
|---|---|
| 家屬說的話是客觀資料 | 家屬、看護說的都是主觀資料 |
| 量出來的 I/O 是主觀資料 | 量測值都是客觀資料 |
| 淚流滿面、抱肚子是主觀資料 | 觀察到的行為是客觀資料 |
| 護理過程以疾病治癒為中心 | 以病人（全人）為中心 |
| 護理診斷三要素含目標 | PES：問題、原因、徵象症狀 |
| 一個明顯表徵就能下診斷 | 要一群定義特徵 |
| 「病房太吵」是定義特徵 | 是相關因素 |
| 醫學診斷可當導因 | 要寫出醫學診斷造成的護理可處理的反應 |
| 護理師覺得最重要的先處理 | 威脅生命 → Maslow → 病人自覺重要 |
| 目標由護理師依經驗訂 | 與病人、團隊共同訂定 |
| 病人家屬不必參與計畫 | 要參與 |
| 評值是最後一步 | 每一步都有評值 |
| 目標沒達成表示措施不好 | 要再評估找原因 |
