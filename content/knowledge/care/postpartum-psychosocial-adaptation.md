產後婦女同時面對身體復原、新的母親角色與家庭關係改變，產後期本身就是壓力情境。本頁依「Rubin 三期 → 母性角色與產後壓力 → 親子依附 → 促進依附的措施（肌膚接觸、親子同室） → 父親 → 手足 → 適應不良的徵兆與溝通」排列。懷孕期的心理與 Rubin 四項母性任務見 [[maternal-adaptation#psychological]]、[[maternal-adaptation#rubin-tasks]]；產後情緒低落、產後憂鬱與產後精神病見 [[postpartum-complications#postpartum-mood]]、[[depressive-disorder#postpartum]]；肌膚接觸的做法見 [[breastfeeding#ten-steps]]

## 重點摘要 {#summary}

- Rubin 產後三期：**接受期**（第 1–2 天，以**自己**為中心、被動依賴、**重述分娩過程**、要吃要睡） → **緊執期**（第 3–10 天，介於依賴與獨立，**主動學習照顧嬰兒**與自我照顧） → **放手期**（放下理想中的分娩與嬰兒，接受**真實的嬰兒**與新角色）
- 接受期先**滿足她的休息與飲食需求**，同時鼓勵接觸嬰兒；緊執期是**衛教的最佳時機**，多給肯定
- 親子依附的進展：觸摸由**指尖 → 手掌 → 擁抱**；**認同行為**（找嬰兒像誰）；**互惠期**（能讀懂嬰兒的暗示並回應）
- 促進依附：產後**立即肌膚接觸**（剖腹產也可以）、**24 小時親子同室**、早期頻繁哺餵、對嬰兒說話、眼對眼接觸
- 親子同室以**母嬰需要**為中心：母親**很累時可以把嬰兒推回嬰兒室**；**不論是否餵母乳**都可以親子同室
- 父親的依附：**全神貫注**(engrossment)：專注凝視、想抱、覺得寶寶很完美；新手爸爸**循序漸進**，先撫觸再學抱
- 手足：**包含 2 歲以下**的孩子都鼓勵參與；給大孩子特別時間，接受暫時的退化行為
- 警訊：對嬰兒說負面的話、不看不碰、除餵奶外都交給別人、表現害怕或排斥

### 國考常考點 {#exam-points}

- **接受期**行為：注意力集中在**自己**、重述生產經過（「昨晚一直夢到我如何生小孩」「生小孩好痛，下次再也不要生了」）、說很累不想餵奶；不是主動關心新生兒或積極尋求意見
- 產後第二天宮縮痛、睡不好、拒絕餵奶 → **接受期**，**先滿足她的需求，同時鼓勵多接觸新生兒**；不是因為第二胎沒興趣，也不是宮縮痛異常
- 產後 **3–10 天**注意母職學習與身體功能恢復 → **緊執期**(taking-hold)；產後第 3 天主動學嬰兒沐浴 → 緊執期
- 緊執期是「**介於依賴與獨立之間**」的時期；「話多、喜歡談論生產過程」是接受期
- 剖腹產想和新生兒相處：產檯上即可肌膚接觸、建議 24 小時親子同室；**產婦疲憊想休息時仍堅持親子同室**是錯的
- 親子同室**正確**：母親非常疲憊時可把嬰兒推回嬰兒室；**不是**出生 6 小時後才開始、**不是**禁止祖父母接觸、**不是**趴睡；**不是只有餵母乳的媽媽**才能親子同室；讓較大的兄姊撫摸新生兒是適當的
- 依附關係**錯誤**敘述：「除了**兩歲以下**的小孩外，鼓勵所有家人參與」（兩歲以下也要）
- 大寶 2 歲、媽媽擔心照顧兩個孩子：最需要追蹤的是「**除了哺餵，其他時間都請月嫂照顧**」（依附不足）
- 父親凝視寶寶並說「我是爸爸」→ **全神貫注**（英文 engrossment；題目選項寫成 engorgement）
- 新手爸爸不敢抱：**循序漸進，先撫觸再教抱**
- 最無助於父親建立依附：**詢問新生兒血型**；陪哺乳、說話、換尿布都有幫助
- 「妹妹跟爸爸長得好像」→ **認同行為**(claiming)
- 進入**互惠期**：母親能**了解新生兒的飢餓與飽足行為**並回應；用手指觸摸臉頰是最早的接觸
- 第一天仔細觀察新生兒並詢問外觀 → **給她充分時間認識和熟悉新生兒**
- 母嬰親善十措施中**直接**促進依附的是**產後立即肌膚接觸**
- Apgar 7、8 分、正在縫會陰 → **立即**把新生兒放在母親胸腹部肌膚接觸，不用等縫完或送嬰兒室
- 產後立即肌膚接觸：新生兒直接放在**乳房上**、讓新生兒**用手觸摸乳頭**（兩者都給分）；不是 1 小時後才做、不是硬把乳房塞進嘴裡
- 潛在適應不良：看寶寶時**皺眉哭著說「他看起來好可怕」**；和朋友談生產過程、撫摸頭部腫塊、輕聲說話都是正常
- 寶寶照光住院、媽媽覺得自己不是好媽媽：**不適當**的是「為避免感染不鼓勵探訪」
- 第四胎又生女兒、家人不來 → 「**聽起來妳很難過……妳現在的想法是？**」（同理＋開放式問句）
- 新住民產婦變胖變醜、先生要離台、擔心獨自照顧 → 身體心像改變、缺乏社會支持、照顧壓力；**「低自尊」較不恰當**（沒有資料支持）

## Rubin 產後三期 {#rubin-phases}

- Rubin（1961、1977）觀察產後婦女的行為與態度，分成三期；時間是大概，**個別差異大**，經產婦與支持多的婦女可能較快

| | **接受期**(taking-in) | **緊執期**(taking-hold) | **放手期**(letting-go) |
|---|---|---|---|
| 時間 | 產後 **1–2 天** | 產後 **3–10 天** | 約產後 2 週以後，可持續數週 |
| 注意力 | **集中在自己**的需要（睡眠、飲食、舒適） | 轉向**母親角色**與**自己的身體功能** | 接受新角色與家庭關係改變 |
| 行為 | **被動、依賴**，希望別人照顧與做決定；**重複談論分娩經過**（統整生產經驗，也可能夢到）；食慾好、需要大量睡眠；說話多、較興奮 | **主動、獨立**，想學會照顧嬰兒（餵奶、沐浴、換尿布）與自我照顧（排泄、會陰）；在意自己做得好不好、容易**沒信心**；可能睡眠不足 | **放下**理想中的分娩經驗與想像中的嬰兒（性別、外表），**接受真實的嬰兒**是獨立的個體；重新安排夫妻與家庭角色；可能有失落與哀傷 |
| 護理 | **滿足生理需求**（休息、飲食、止痛）、傾聽她談分娩經過、協助她統整經驗；**同時鼓勵接觸嬰兒**，不勉強她馬上學技巧 | **衛教的最佳時機**：示範後讓她自己做、**多給肯定與鼓勵**、提供正確資訊；注意產後情緒低落 | 讓她表達失落；鼓勵夫妻溝通、安排家務與照顧分工；支持返回職場的準備 |

- 例句判斷

| 例句 | 時期 |
|---|---|
| 「昨晚一直夢到生小孩的過程」「生小孩好痛，下次不要生了」「我好累，不想餵奶」 | 接受期 |
| 「多喝水奶會不會變多？」「我要怎麼讓奶水增加？」「教我幫寶寶洗澡」 | 緊執期 |
| 「寶寶的個性和我想的不一樣，但我知道他要什麼」 | 放手期 |

## 母性角色與產後壓力 {#maternal-role}

- **母性角色獲得**(maternal role attainment)：從懷孕開始，經過模仿、角色扮演、幻想，到產後實際照顧，**逐漸形成自己的母親風格**，約需數個月；懷孕期的四項母性任務見 [[maternal-adaptation#rubin-tasks]]
- 影響因素：分娩經驗（過程不如預期、剖腹產、併發症）、嬰兒狀況（早產、生病、性別不如預期）、**社會支持**、婚姻關係、經濟、文化、母親年齡與經驗、身體不適與疲倦
- 臺灣產後壓力研究（課本整理 Hung 2005、2007）：坐月子期間壓力分三大類
   1. **擔心母育角色獲得**：嬰兒作息無法預期、嬰兒突然生病、睡姿影響頭形、吐奶
   2. **擔心負向的身體改變**：腹部肌肉鬆弛、身材沒恢復、妊娠紋、腰痠背痛
   3. **擔心缺乏社會支持**：家人心理支持、家務人手、經濟、夫妻關係
- 初產婦較常擔心**嬰兒**（突然生病、腹肌鬆弛）；經產婦較常擔心**腰痠背痛、身材、夜間睡眠中斷**
- 護理診斷常見：**身體心像改變**（變胖變醜）、**缺乏社會支持**（先生不在、沒有親友）、**照顧者角色壓力**、知識缺失、睡眠型態紊亂；要有資料支持才下診斷（例如沒有自我評價低落的表現就不寫「低自尊」）
- **跨文化**：新住民產婦注意語言、飲食與坐月子習俗、遠離原生家庭的支持缺乏，轉介新住民相關資源（見 [[obstetric-nursing-foundations#cultural-care]]）

## 親子依附 {#attachment}

- **連結**(bonding)：出生後**最初**幾分鐘到幾天，父母對嬰兒產生情感連結，是單向的開始
- **依附**(attachment)：親子間**長期、雙向**的情感關係，在互動中慢慢建立，可持續數個月（課本寫連結與依附持續到產後 4–5 個月，同時伴隨分離個別化）
- 出生後母嬰仍有懷孕時那樣親密的關係，稱為**情緒共生**(emotional symbiosis)
- 依附行為的進展

| 階段或行為 | 表現 |
|---|---|
| **觸摸順序** | **指尖**輕觸嬰兒四肢與臉頰 → **手掌**撫摸軀幹 → **整個抱住**、擁入懷中 |
| **眼對眼接觸**(en face) | 調整姿勢讓臉和嬰兒的臉在同一平面，凝視嬰兒 |
| 聲音 | 用高音調、輕柔的聲音對嬰兒說話，叫嬰兒的名字 |
| **認同行為**（claiming、宣稱） | **找嬰兒像誰**（「跟爸爸長得好像」），把嬰兒納入家庭；先找相似處，再看嬰兒獨特的地方 |
| **互惠**(reciprocity) | 母親能**讀懂嬰兒的暗示**（飢餓、吃飽、累了、想玩）並**適當回應**，嬰兒也回應母親 |
| **同步**(synchrony) | 親子的互動節奏配合得剛好 |

- 嬰兒這邊也會促進依附：注視、哭與安靜、抓握、尋乳與吸吮、氣味
- 第一天母親**仔細觀察新生兒、問外觀** → 正在**認識**嬰兒，給她**充分的時間**，不急著教技巧

## 促進依附的措施 {#promoting-attachment}

### 產後立即肌膚接觸 {#early-contact}

- 新生兒擦乾、評估穩定（例如 **Apgar 7–8 分**）後，**立即**放在母親裸露的胸腹部（**直接在乳房上**），蓋被保暖；不用等會陰縫合完成，也不用先送嬰兒室
- 讓新生兒自己探索、**用手觸摸乳頭**、出現尋乳時協助哺乳；不硬把乳房塞進嘴裡
- **剖腹產**：母親清醒、母嬰穩定時，在手術室或恢復室也可以
- 是母嬰親善十措施中**最直接**促進依附的一項；做法見 [[breastfeeding#ten-steps]]

::questions{ids="107-1_OP_011,106-2_makeup_OP_002,108-2_OP_022"}

### 親子同室 {#rooming-in}

- **親子同室**(rooming-in)：母嬰 **24 小時**在同一房間，由母親（與家人）照顧，護理人員隨時提供協助與諮詢
- 好處：**促進依附**、**提高母乳哺餵成功率**（看暗示就餵）、讓父母**熟悉嬰兒、增加照顧信心**、讓家人參與、嬰兒適應日後的家庭環境
- 原則
   1. 新生兒穩定後就可以開始（不是固定 6 小時後），剖腹產也鼓勵
   2. **不論餵母乳或配方奶**都可以
   3. 以**母嬰需要**為中心：母親**非常疲憊**或身體不適想休息時，可以把嬰兒**暫時推回嬰兒室**；不是一定要強制同室
   4. 鼓勵**父親與家人**（含祖父母、兄姊）參與，注意洗手、生病者暫不接觸
   5. 嬰兒**仰睡**、在自己的小床上
   6. 教父母觀察嬰兒的呼吸、膚色與異常徵象，告訴他們如何求助

::questions{ids="115-1_OP_012,106-2_makeup_OP_026,105-1_OP_025"}

### 新生兒需要住院時 {#separated}

- 嬰兒因黃疸照光、早產或生病住院 → 母親容易**自責、覺得自己不是好媽媽**
- 措施：評估她對自己身體與寶寶照護的擔心；**鼓勵並安排探視**、**眼對眼與身體接觸**、袋鼠護理、擠母乳送去；運用支持系統讓她能把心力放在嬰兒身上；**不因怕感染而不鼓勵探視**

::questions{ids="109-2_OP_023"}

## 父親 {#father}

- 父親對新生兒的依附稱為**全神貫注**（engrossment，Greenberg 與 Morris 1974）：**專注凝視**、想抱想摸、覺得嬰兒**很完美**、強烈被吸引、對自己當爸爸感到驕傲與自尊提升
- 112-1 題的選項把 engrossment 寫成 engorgement（那個字是**脹奶**），作答時看中文「全神貫注」
- 新手爸爸常因**沒經驗而害怕**（「她軟軟的，我不敢抱」）：**循序漸進**，先**撫觸**建立熟悉感，再示範與練習抱嬰兒、換尿布、沐浴；肯定他的努力
- 有幫助的行為：陪伴哺乳、對嬰兒說話、換尿布、抱嬰兒、肌膚接觸；**只問血型**這類資訊沒有情感互動，最無助於依附
- 也要注意父親的疲倦與產後情緒（父親也可能有產後憂鬱）

::questions{ids="112-1_OP_024,109-2_OP_022,108-1_OP_020"}

## 手足與家庭 {#siblings-family}

- **手足競爭**(sibling rivalry)：新生兒出生，大孩子怕失去父母的愛，可能出現**退化行為**（尿床、吸手指、要喝奶瓶、要人抱）、生氣、攻擊嬰兒、黏人
- 措施
   1. 懷孕時就讓大孩子知道並參與（看超音波、準備嬰兒用品）
   2. 新生兒出生後，**讓大孩子（包含 2 歲以下）來看、撫摸嬰兒**，在照顧中給他**小任務**
   3. 父母**每天保留時間單獨陪大孩子**（例如嬰兒睡時唸書給他聽）；訪客也關心大孩子
   4. 接受暫時的退化，不責罵；給予肯定
   5. 大孩子的作息盡量不變；不要在這時候剛好戒尿布或換房間
- 媽媽**同時以乳房安撫大寶與新生兒**、大寶睡時抱著新生兒凝視，都是正常的依附表現
- **除了哺餵以外都交給別人**（月嫂、家人）、很少主動接觸嬰兒 → 依附不足的警訊，要持續追蹤
- 家人都應參與：產後婦女的身心狀況會影響依附；家庭支持越多，適應越好

## 適應不良的徵兆與溝通 {#warning-signs}

- 依附或適應不良的徵兆
   1. 對嬰兒表達**負面**評價、**害怕或排斥**（「他看起來好可怕」）、說嬰兒醜或像不喜歡的人
   2. **不看、不碰、不叫名字**，餵奶時不看嬰兒、抱的姿勢僵硬遠離身體
   3. 除了必要的照顧都交給別人，不想學照顧
   4. 對嬰兒的暗示**沒有反應**或過度生氣
   5. 持續情緒低落、哭泣、失眠、對什麼都沒興趣超過 2 週 → 評估**產後憂鬱**（見 [[postpartum-complications#postpartum-mood]]）
- 治療性溝通：產婦表達難過（例如生了女兒家人不來）時，先**同理反映情緒**、用**開放式問句**讓她說出想法；不急著安慰「不要難過」、不把原因歸給荷爾蒙、不說教
