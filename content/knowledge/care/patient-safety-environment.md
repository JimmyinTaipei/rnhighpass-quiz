醫院裡的病人因疾病、藥物與陌生環境，比一般人更容易受傷。本頁整理**舒適的醫療環境**(溫度、溼度、光線、通風、噪音)、病房常見的**傷害**(跌倒、燙傷、觸電、給錯藥、放射線)、**約束**、**火災與地震**應變，以及**病人單位**的設備與清潔。醫院層級的災害應變計畫與廢棄物法規見 [[hospital-safety-environment]]，病人安全通報與年度目標見 [[patient-safety-reporting]]，用氧的防火見 [[oxygen-therapy#precautions]]

## 重點摘要 {#summary}

- 一般舒適室溫約 **20–24 ℃**、相對溼度 **40–60%**；**嬰幼兒與老人稍暖**，**發燒、燙傷、甲狀腺機能亢進**病人稍涼(代謝率高)；室內外溫差 **4–6 ℃**
- 溼度：**支氣管炎與呼吸道感染約 80%**、氣喘宜偏低；手術室溼度要夠高，避免靜電產生火花
- 光線：一般病房約 150–200 lux(米燭光)、手術室 750–1,500 lux；**眼科術後光線稍暗**；書寫時光源在**非慣用手後上方**
- 傷害分類：**跌倒＝最常見的機械性傷害**；**給藥錯誤＝最常見的化學性傷害**；燙傷屬**溫度性傷害**
- 跌倒好發：**浴廁、樓梯**與上下床、輪椅；**夜間與清晨**；高危險群：65 歲以上與 5 歲以下、曾跌倒、感覺或認知障礙、使用輔具、服用降壓藥、降血糖藥、利尿劑、瀉劑、鎮靜劑
- 約束：**要有醫囑與同意書**，不是護理獨立功能；保護病人與他人，不是處罰；**1–2 指**鬆緊、**綁床架不綁床欄**；每 **15–30 分鐘**看 **CTMS**(color 顏色、temperature 溫度、motion 活動、sensation 感覺)、每 **2 小時**鬆開翻身
- 火災 **RACE**：Rescue 救援、Alarm 通報、Contain 侷限、Extinguish／Evacuate 滅火或疏散；**濃煙密布先疏散**；不搭電梯
- 滅火器：紙木棉(A 類)用**泡沫或乾粉**；油類(B)泡沫、CO₂、乾粉；**電氣(C)用 CO₂ 或乾粉，不用泡沫**；金屬(D)用乾粉
- 輻射防護：**時間、距離、屏蔽**；MRI(磁振造影)與內視鏡**沒有游離輻射**
- 地震撤離(課本)：**先讓能行動者自行離開，再抬離無法行動者**；不搭電梯

### 國考常考點 {#exam-points}

- 室溫：發燒病人病房**低於**一般室溫；嬰兒室**高於**一般室溫；燙傷病人代謝率高，室溫**稍低**；室內外溫差 4–6 ℃(說 1–3 ℃ 是錯的)
- 手術室溫度與溼度：國考答案 **20–27 ℃、50–70%**(課本寫醫療機構設置標準 20–28 ℃、溼度 50–80%)
- 眼科術後光線要**稍暗**(說調亮是錯的)；支氣管炎病房溼度約 **80%**；溼度太低可在皮膚上**擦乳液**
- 給藥錯誤是**化學性**傷害、跌倒是**機械性**傷害；感覺功能障礙者用熱要防**燙傷**；老人或用鎮靜劑**不等於**一律約束
- 跌倒最常發生在**浴廁與樓梯**；定向障礙或無家屬陪伴者安置在**靠近護理站**；不做治療時**床降到最低**(坐床緣雙腳著地)，不是固定床高或床升高
- 床欄依需要起落，不是永遠拉起；**夜間保留照明**；助行器放在**病人方便拿的健側**；浴室門口**不放活動地毯**、用止滑設施
- 老人跌倒外因性(環境)因素：**光線不足**、地面濕滑、地毯、障礙物；內因性：中風病史、白內障、鎮靜劑、姿位性低血壓
- 老人居家：浴室門**向外開**、樓梯加欄杆、夜燈；鞋子**防滑、合腳**，「魔鬼氈、鞋底厚重」不能降低跌倒
- 跌倒風險藥物：利尿劑、降壓藥、瀉劑、鎮靜安眠藥；**退燒藥不算**
- 約束：**必須有醫囑**；目的是**防止意識不清病人傷害自己**；CTMS 的 **C＝顏色、T＝溫度、M＝活動、S＝感覺**(不是心理感受)
- 約束鬆緊：**可伸入 1–2 指**；平結綁在**床架**；循環每 15–30 分鐘看一次(說每 2 小時看一次是錯的)
- 兒童約束：唇顎裂術後用**手肘約束**；10 歲躁動拔管用**雙套結**、棉墊保護手腕、固定在床架；木乃伊約束用於嬰幼兒短時間治療
- RACE 的 **A＝Alarm 通報啟動警報**、**E＝Extinguish 滅火**(或 Evacuate)；濃煙密布第一時間**疏散病人**
- 燃紙火災**不用 CO₂**(用泡沫或乾粉)；配電盤用 CO₂；油漆用泡沫；鎂金屬用乾粉
- 不具放射線傷害的檢查：**胃鏡**(CT 與胸部 X 光有游離輻射)
- 地震：**先協助能行動者**，再抬離無法行動者(說先抬無法行動者是錯的)；床頭上方不放花瓶；鋼瓶用鎖鍊固定
- 化療後的點滴管屬**基因毒性廢棄物**，不是一般紅色感染性；小兒集尿袋屬**感染性可燃**
- 舊血漬用**雙氧水**；新血漬用冷水

## 舒適的醫療環境 {#comfort}

| 項目 | 一般原則 | 依病況調整 |
|---|---|---|
| **溫度** | 約 20–24 ℃(課本 20–23.8 ℃)；冷氣時室內外溫差 **4–6 ℃** | 嬰幼兒、老人體溫調節差 → **稍暖**；發燒、燙傷、甲亢代謝率高 → **稍涼**；手術室、產房、加護病房、嬰兒室依《醫療機構設置標準》20–28 ℃ |
| **溼度** | 相對溼度 **40–60%** | **支氣管炎、呼吸道感染約 80%**(黏膜不乾)；氣喘偏低(課本 10–20%，過溼易誘發)；手術室偏高(防靜電火花) |
| **光線** | 一般病房 150–200 lux；手術室 750–1,500 lux；日光可殺菌並幫助合成維生素 D | **眼科術後光線稍暗**；燈光不直射臉；角落、樓梯、浴廁要夠亮防跌倒；老人房間要明亮 |
| **通風** | 空氣含氧約 21%；降到 13% 以下呼吸異常 | 病房遠離廚房、洗衣房、汙物間；全院禁菸 |
| **噪音** | 長期 **85 分貝(dB, decibel)以上**會傷聽力並使血壓上升 | 說話音量適中但**不要耳語**(會讓病人起疑)；推車輪子上油；清晨與夜間少廣播 |
| **色彩** | 牆與床單不要全白(冷漠) | 藍色鎮靜(躁症)、米黃色刺激(憂鬱)、**藍綠色**最護眼(手術室)、粉紅色溫馨(產兒科) |

1. 溼度調節：太高用除溼機、空調；太低用加溼機或放水盆，**皮膚擦乳液**減輕乾燥
2. 書寫時光源在**非慣用手的後上方**，避免手的陰影擋住紙面
3. 國考手術室題(110-2_FA_017)的答案是 **20–27 ℃、50–70%**；課本的溫度引《醫療機構設置標準》20–28 ℃、溼度寫 50–80%，作答以題目選項為準

## 醫院常見傷害的分類 {#injury-types}

| 類型 | 代表事件 | 重點 |
|---|---|---|
| **機械性** | **跌倒**(最常見，約占醫院意外的八成以上)、碰撞 | 見下節 |
| **化學性** | **給藥錯誤**(最常見)、消毒劑 | 三讀五對、條碼給藥，見 [[medication-administration-principles]] |
| **溫度性** | 用熱導致**燙傷**、冷療凍傷 | 幼兒、老人、**感覺功能障礙**、肢體麻痺者對熱較遲鈍；熱水袋水溫不超過約 46 ℃ |
| **電** | 觸電 | 電器接地、**三孔插頭**；先擦乾手；拔插頭**握插頭**不拉電線；電熱毯不可弄溼；壞掉的電線立刻停用送修 |
| **放射線** | X 光、CT、放射治療 | 時間、距離、屏蔽，見下方「放射線傷害」 |

1. 燙傷預防：用熱前**評估自我保護能力**、依個別情形調整溫度與時間、隨時觀察皮膚、教家屬正確方法並回覆示教；用熱的溫度與禁忌見第 10 輪冷熱療法，燒傷深度見 [[environmental-injury#burn-depth]]
2. 「照護老年人或使用鎮定劑的病人應約束」是錯的：先用床欄、陪伴、靠近護理站等措施，約束是最後手段

## 跌倒 {#falls}

### 危險因子與好發情境 {#fall-risk}

1. 高危險群(課本與 115–116 年病安目標)
   1. 年齡 **65 歲以上與 5 歲以下**
   2. 住院期間或**過去一年內曾跌倒**
   3. 感覺功能損傷(偏癱、截癱、聽力或視力差)
   4. 身體狀況：頭暈、虛弱、**姿位性低血壓**、平衡與步態不穩、**頻繁如廁**
   5. **認知或意識改變**：譫妄、躁動、失智、憂鬱
   6. 使用輔具：拐杖、助行器、義肢、石膏、輪椅
   7. 藥物：**降壓藥、降血糖藥、利尿劑、瀉劑、鎮靜安眠藥**、麻醉止痛藥
2. 內因性與外因性
   1. **內因性**(病人本身)：年齡、中風病史、白內障、失禁、認知退化、姿位性低血壓、用藥
   2. **外因性**(環境)：**光線不足**、地面濕滑、活動地毯、障礙物、不合腳的鞋
3. 好發地點與時間：**浴廁、樓梯**，上下床與輪椅移位時；**夜間與清晨**

### 預防措施 {#fall-prevention}

| 面向 | 做法 | 原理 |
|---|---|---|
| 熟悉環境 | 入院介紹環境、**叫人鈴**放在伸手可及處 | 陌生環境是跌倒主因之一 |
| 環境 | 走道無障礙、地面乾燥(拖地先拖一半)、濕地放警示牌；浴廁裝**扶手、止滑設施、叫人鈴**；**夜間保留夜燈** | 夜間起身如廁最常跌倒 |
| 床與輪椅 | 不做治療時**床降到最低**(坐床緣雙腳著地)；**床輪與輪椅固定**；床欄依需要拉起並教正確使用 | 床太高起身會前傾跌倒；床欄不當使用反而攀爬跌落 |
| 物品 | 眼鏡、助聽器、拐杖、便盆、尿壺放在**隨手可得**處；助行器放在**健側**方便拿 | 減少彎腰、伸手失去平衡 |
| 活動 | **漸進下床**：坐起 → 坐床緣 1–2 分鐘 → 站立 → 行走；偏癱者由**健側**下床 | 預防姿位性低血壓 |
| 衣鞋 | 褲長合適；鞋子**防滑、合腳** | 太長褲管與拖鞋易絆倒 |
| 警示與安置 | 高危險標示(床頭牌、手圈)；**定向障礙、無家屬陪伴者住靠近護理站** | 方便隨時觀察 |
| 藥物 | 檢討跌倒風險藥物必要性 | 藥物整合 |
| 出院 | 出院跌倒與衰弱風險評估、居家環境指導 | 115–116 年病安目標第四項新增衰弱預防 |

1. 意識清楚、左下肢乏力的老人：**夜間仍要開照明**；助行器放在方便取用處，不是放在患側床尾；浴室門口不放小地毯
2. 老人居家環境：浴室門**向外開**(跌倒在門後才打得開)、樓梯加欄杆、夜燈、物品**固定擺放**
3. **課本與國考不同**
   1. 課本寫「在浴室門口放一地毯減少潮溼」，但國考(110-1_FA_006、111-1_PC_067)把**浴室門口放小地毯或活動地毯**當成**錯誤**，現行病安目標寫的是**止滑設施**，作答以國考為準
   2. 課本寫穿「厚底」鞋；國考(113-3_PC_049)認為「**魔鬼氈、鞋底厚重**」不能降低跌倒，病安目標只寫**防滑、大小合適**
4. 跌倒後：評估生命徵象與受傷部位、通報、重新評估危險因子並修改照護計畫；跌倒沒有受傷**不是**警訊事件(見 [[patient-safety-reporting]])
5. 社區老人的衰弱評估(Fried、SOF、ICOPE)見 [[older-adult-chronic-disease#frailty]]；家訪的居家安全評估見 [[family-nursing#nursing-process]]

## 約束 {#restraint}

1. 目的：**保護病人避免自傷**(意識不清、拔管)、**保護他人免受攻擊**；**不是處罰**，也不是為了方便照顧
2. 適應症：意識混亂或躁動、會自拔管路、易跌落床、術後保護傷口(如唇顎裂)、持續抓傷皮膚
3. **約束前**
   1. **需要醫囑**(不是護理獨立功能)，並向家屬說明、**簽同意書**
   2. 先試其他方法：陪伴、床欄、找出躁動原因(疼痛、缺氧、膀胱脹)
4. **約束時**
   1. 選合適的約束用品；骨突與手腕先墊**棉墊**
   2. 鬆緊度**可伸入 1–2 指**
   3. 肢體維持**功能位置、微彎**，不可完全伸直
   4. 約束帶用**可快速解開**的方式綁在**床架**，**不綁床欄**(床欄移動會拉扯肢體)；課本寫用**平結**綁床架
   5. 約束胸腹時注意呼吸
5. **約束後**
   1. 每 **15–30 分鐘**觀察末梢循環，用 **C.T.M.S.** 評估：**C 顏色(color)、T 溫度(temperature)、M 活動(motion)、S 感覺(sensation)**；蒼白、冰冷、麻木立刻鬆開
   2. 每 **2 小時**鬆開一次，翻身、皮膚護理、關節運動(受壓部位見 [[pressure-injury#sites]]、關節運動見 [[activity-immobility#rom-practice]])
   3. 記錄約束原因、方式、起訖時間與評估結果
   4. 北醫衛教單張寫每 30–60 分鐘看皮膚循環、每 2 小時鬆開；國考依課本的 15–30 分鐘

| 約束法 | 用途 |
|---|---|
| **木乃伊約束** | 嬰幼兒做**短時間**頭頸部治療或檢查(如抽血、灌食管) |
| **手肘約束** | 嬰兒**唇顎裂術後**，讓手碰不到臉，手腕仍可活動 |
| **雙套結**(棉布繃帶) | 手腕或腳踝，先墊棉墊，固定在床架；適合較大兒童或成人防拔管 |
| 約束手套 | 防抓傷、防拔管，手指不受綁 |
| 背心、腰帶(波氏) | 坐輪椅或臥床防跌落，注意呼吸 |
| 床欄 | 防跌落床，不算約束肢體 |

1. 兒童約束也要醫囑與家長同意；約束肢體的循環不可隔 2 小時才看
2. 精神科約束依《精神衛生法》，醫囑要寫方式、理由、評估頻率與起訖時間，見 [[schizophrenia#restraint]]；譫妄病人盡量不約束，見 [[delirium#restraint]]；癲癇發作時**不約束**，見 [[epilepsy]]

## 火災 {#fire}

1. 醫院常見起火原因：**電器使用不當**(最常見)、亂丟菸蒂或床上抽菸、整修工程、醫療設備或燈具過熱、廚房
2. 預防：防火建材、滅火器與警報器、逃生路線標示；定期檢查電路(**不超量用電**)與消防設備；緊急出口與走廊保持通暢；全院禁菸，用氧處、手術室與氧氣儲存室附近 **12 呎內**標示「嚴禁煙火」(見 [[oxygen-therapy#precautions]])；定期消防演練

### RACE 與 PASS {#race}

| 字母 | 英文 | 做法 |
|---|---|---|
| **R** | **Rescue** 救援 | 把病人移出危險區；能走的病人走安全路線離開、**不搭電梯**；不能走的用床單、毛毯、輪椅、擔架搬運 |
| **A** | **Alarm** 通報 | **啟動警報器**、通報消防單位與院內 |
| **C** | **Contain** 侷限 | **關門窗**、關閉氧氣與電器，把火煙侷限在一區 |
| **E** | **Extinguish／Evacuate** 滅火或疏散 | 依火災種類用適合的滅火器做**初期滅火**；撲滅不了就**疏散** |

1. RACE **不一定照字母順序**，要依現場判斷；**濃煙密布**時第一步是**疏散病人**，不是開窗排煙或先去滅火
2. 滅火器用法 **PASS**：**Pull** 拉插銷、**Aim** 瞄準火源底部、**Squeeze** 壓把手、**Sweep** 左右掃射
3. 醫院層級的應變計畫、演練頻率與 RACE 法規面見 [[hospital-safety-environment#disaster-response]]

| 類別 | 火災 | 起火物 | 適用滅火器 |
|---|---|---|---|
| A | 普通火災 | 紙、木材、布、塑膠 | **泡沫、乾粉** |
| B | 油類火災 | 汽油、溶劑、**油漆**、油脂 | 泡沫、CO₂、乾粉 |
| C | 電氣火災 | 電線、馬達、**配電盤** | **CO₂、乾粉**；**不可用泡沫**(導電)；斷電後視同 A、B 類 |
| D | 金屬火災 | 鈉、鉀、**鎂**、鋰 | **乾粉**(專用) |

(依內政部消防署防火管理訓練教材整理)

## 放射線傷害 {#radiation}

1. 會產生**游離輻射**：X 光、**電腦斷層(CT, computed tomography)**、核醫檢查、放射治療
2. **沒有游離輻射**：**磁振造影(MRI, magnetic resonance imaging)**用磁場與無線電波；**超音波**；**內視鏡**(胃鏡、大腸鏡)用光學鏡頭
3. 院方管制：鉛牆屏蔽、輻射警告標示、設備經主管機關認證、工作人員配戴**劑量計(佩章)**並定期追蹤劑量與健檢
4. 體外輻射防護三原則
   1. **時間**：集中護理，縮短接觸時間
   2. **距離**：離輻射源越遠越好
   3. **屏蔽**：鉛屏、鉛衣、鉛圍裙、鉛手套、甲狀腺護頸
5. 輻射的生物效應、輻射單位與放射治療病人照護見 [[environmental-injury#ionizing-radiation]]

:::note[考題分歧：何者不具放射線傷害]
109-1_FA_016 的公告答案是**胃鏡**；但選項中的**全身 MRI** 也沒有游離輻射(課本本章就註明 MRI 不具放射線)，學理上兩個選項都對。作答時選完全不用影像能量的胃鏡

## 地震 {#earthquake}

1. 結構與設備：燈具、櫃子、書架加強固定；笨重易碎物不放高處；**氣體鋼瓶用鎖鍊固定**；化學藥品分類並防震存放
2. 平時準備：通道暢通、急救衛材與藥品、緊急照明、飲水(約 2 天量)與物資
3. 病人安全
   1. **病床床頭燈上方不放花瓶、罐子**
   2. 地震時**遠離窗戶**，避免玻璃割傷
   3. 撤離時(課本)：**先協助能行動者自行離開，再用擔架、被單抬離無法行動者**；**不搭電梯**
4. 定期防震演習

## 醫療廢棄物 {#medical-waste}

分類、顏色與貯存規定見 [[hospital-safety-environment#medical-waste]]，病房常考的判斷：

1. 沾血或體液的紗布、棉球、**壓舌板**、**小兒集尿袋** → **感染性可燃**(紅色)
2. 針頭、刀片、縫針、與針頭相連的空針 → **廢尖銳器具**，不易穿透的容器
3. **化療藥物**及接觸過的點滴管 → **基因毒性廢棄物**，不是一般感染性紅袋
4. 胸腔引流瓶與引流管 → 感染性
5. 乾淨的點滴瓶、未沾血的輸液管 → 一般醫療廢棄物
6. 針頭回收筒與垃圾桶**八分滿**就封口移除
7. 廢尖銳器具(針頭、縫合針、刀片)是**不可燃**的，以**熱處理**或**滅菌後粉碎**處理(來源：實用基本護理學上冊 表 2-8 p.51)
8. 感染性廢棄物：**可燃用紅色**容器焚化，**不可燃用黃色**容器滅菌(同上)；國考把針頭等尖銳器械的收集容器答**黃色**(106-2_makeup_PC_048)
9. 透析廢液、殘肢、血液都屬可燃或熱處理類；**注射針頭**是不可燃(105-2_PC_060)
10. 感染性廢棄物可以短時間室溫貯存(5℃ 以上以 1 日為限)，所以「絕不可室溫貯存」錯(108-2_PC_050)；貯存天數見 [[hospital-safety-environment#medical-waste]]

## 病人單位 {#patient-unit}

1. 病人單位是病人在醫院最基本的生活環境：病床(比家用床高，約 26 吋，可升降並有床輪)、床墊、床旁桌、床上桌、床頭的醫療氣體、抽吸與插座
2. 床的手搖桿用完要**收起**，避免絆倒
3. 布類汙漬處理(課本第 5 章)

| 汙漬 | 清除 |
|---|---|
| **新血漬** | **冷水**或氨水(熱水會讓蛋白凝固) |
| **舊血漬** | **雙氧水(過氧化氫)** |
| 指甲油 | 丙酮或乙醚 |
| 膠布痕跡 | 汽油、乙醚、石油精 |
| 排泄物與分泌物 | 0.5% 漂白水 |

1. 有傳染性的布單放進**感染性汙衣袋**，先消毒再清洗；消毒與滅菌見 [[asepsis-sterilization]]

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 發燒病人室溫要調高 | 稍低於一般室溫 | 幫助散熱 |
| 眼科術後光線調亮 | 光線稍暗 | 減少刺激與畏光 |
| 給藥錯誤是物理性傷害 | 化學性傷害 | 藥物是化學物質 |
| 床欄永遠拉起、床固定在高位 | 依需要使用床欄，床降到最低 | 攀爬床欄或從高床跌落更嚴重 |
| 浴室門口放小地毯防滑 | 用止滑墊與扶手 | 活動地毯會滑動絆倒 |
| 約束是護理獨立功能 | 要醫囑與同意書 | 限制人身自由 |
| 約束帶綁在床欄、綁到手指伸不進去 | 綁床架、1–2 指 | 床欄會動、太緊壓迫循環 |
| 每 2 小時才看約束肢體循環 | 每 15–30 分鐘看 CTMS，每 2 小時鬆開 | 缺血可能很快發生 |
| CTMS 的 S 是心理感受 | S 是感覺(sensation) | 評估神經壓迫 |
| 濃煙密布先開窗排煙 | 先疏散病人 | 開窗會讓火勢擴大，濃煙致命 |
| 紙張起火用 CO₂ | 泡沫或乾粉 | CO₂ 對 A 類固體火效果差 |
| 電器起火用泡沫 | CO₂ 或乾粉 | 泡沫導電 |
| 地震先抬無法行動的病人 | 課本：先讓能行動者離開 | 課本的撤離順序(108-2_FA_018) |
| 化療點滴管丟紅色感染性袋 | 基因毒性廢棄物 | 細胞毒性藥物另外處理 |
