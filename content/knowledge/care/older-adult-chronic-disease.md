台灣已是**超高齡社會**（65 歲以上 > 20%），社區護理面對的中老年問題，一是**老化本身**（生理改變、更年期、衰弱），二是**慢性病**（三高、代謝症候群、骨質疏鬆、痛風）。社區的做法是**早期篩檢發現個案**、教導自我照顧、預防失能，讓長者**在地老化**。老年人口指標見 [[vital-statistics]]；長照需求評估見 [[long-term-care#assessment]]，長照服務與預防延緩失能見 [[long-term-care-services#prevention]]；跌倒預防見 [[patient-safety-environment#falls]]

## 重點摘要 {#summary}

- 正常老化：**心輸出量下降**、唾液與胰島素分泌減少、腦重量減少
- **衰弱**介於健康與失能之間，**可逆**，能用周全性評估早期發現；處置是**活動**與營養，**不是多休息**
- **Fried** 五項：體重減輕、疲憊、**握力**下降、**行走速度**變慢、**身體活動量**低；≥ 3 項衰弱。**跌倒次數不在內**
- **SOF** 三項：體重減輕 **≥ 5%**、**無法不用手從椅子站起 5 次**、精力降低；**1 項衰弱前期、≥ 2 項衰弱**
- **ICOPE** 六項內在能力：**認知、行動、營養、視力、聽力、憂鬱**
- 骨質疏鬆：T 值 **≥ −1 正常**、−1 到 −2.5 骨質減少、**≤ −2.5 骨質疏鬆**；**負重運動**（不是游泳）；**體重過輕**才是危險因子
- 慢性病：**無法根治、須終生控制**、初期無症狀、可能造成**失能**；個案管理最優先是**篩檢發現個案**，最終目標是**自我照顧**
- 衛教數字：膽固醇 **< 300 mg/日**、食鹽 **≤ 6 g/日**、每週 **150 分鐘中度或 75 分鐘費力**身體活動

### 國考常考點 {#exam-points}

- 「全球化」不是老年人口成長的原因
- 更年期**不會低血壓**（雌激素減少反而較易高血壓）
- 衰弱「無法恢復」錯；王老先生無力、體重減輕 → 轉介老醫、延緩失能活動、教防跌，**不叫他多休息**
- 陳老太太體重 65 → 63 kg（約 3%）、只能站起 3 次、一個月 2–3 天沒精神 → SOF 只符合下肢 1 項 → **衰弱前期**
- 骨鬆警訊：**身高變矮、下背痛**（113-3 題更正為只有①③）
- 骨鬆防治：鈣（乳品、豆製品、深綠色蔬菜）、適度日曬（不塗防曬）、負重運動；**不建議**常規用傳統荷爾蒙療法預防
- 坐姿肌力訓練**適合**長者
- 獨居老人不建議直接**入住機構**，先連結社區支持
- 代謝症候群最主要因素是**生活型態**；限 6 g 的是**鹽**，不是澱粉
- 痛風：豆苗、蘑菇是**高普林**蔬菜要少吃；避免啤酒、多喝水
- 血脂高的學生：**不用降膽固醇飲料代替水**、不建議不吃早餐

## 老年人與老化 {#aging}

- 老年人口成長的原因：社會經濟水準提升、**醫療科技進步**、**公共衛生改善**（死亡率下降、壽命延長），加上生育率下降；「全球化」無關（108-1 題）
- 正常老化的生理變化（105-1 題）

| 系統 | 變化 |
|---|---|
| 心血管 | 心肌彈性降低、**心輸出量下降**、血管阻力上升 |
| 消化 | **唾液分泌減少** |
| 內分泌 | **胰島素分泌減少**、胰島素阻抗增加 |
| 神經 | **腦組織重量減少** |

- 更年期生理變化：熱潮紅、盜汗、骨質疏鬆、心血管風險上升（雌激素保護減弱，較易**高**血壓，不是低血壓）（112-3 題）；婦女更年期保健見 [[maternal-child-health#women]]
- 老年人的生理、心理、社會變化細節見 [[sleep-rest]] 與第 15 輪內外總論

## 衰弱 {#frailty}

- 衰弱(frailty)是多系統生理儲備下降、對壓力的抵抗力變差的**症候群**，介於健康與失能之間；**動態、可逆**，可透過老年周全性評估（CGA，comprehensive geriatric assessment）早期發現（112-1 題）
- 處置：**增加活動**（阻力運動）、補充蛋白質、轉介老年醫學或家醫科、參加社區**預防及延緩失能**活動、教防跌；**多休息會加速肌肉流失**（110-2 題）

| 量表 | 項目 | 判定 |
|---|---|---|
| **Fried 衰弱表現型**(Fried 2001) | ① 非預期**體重減輕** ② **疲憊**（自覺精力差） ③ **握力**下降 ④ **行走速度**變慢 ⑤ **身體活動量**低 | 0 項健康、1–2 項衰弱前期、**≥ 3 項衰弱** |
| **SOF 衰弱指標**(Ensrud 2008) | ① 一年內非預期體重減輕 **≥ 5%** ② **無法不用手扶從椅子站起 5 次** ③ 自覺**精力降低**（過去一週常提不起勁） | 0 項無衰弱、**1 項衰弱前期**、**≥ 2 項衰弱** |

- 114-2 題：**跌倒次數**不是 Fried 的項目
- 111-1 題：SOF 體重減輕是 **5%**，不是 5 公斤
- 112-2 題：65 → 63 kg 只減 3%、站起只有 3 次（符合）、一個月 2–3 天（不算常）→ 1 項 → **衰弱前期**；SOF 沒有「嚴重衰弱」這一級
- **ICOPE**（WHO 長者整合性照護）：評估六項**內在能力**——**認知、行動、營養、視力、聽力、憂鬱**；藥物、失禁、日常生活活動不在六項內（113-3 題）；國健署長者功能評估依此設計

## 骨質疏鬆的社區防治 {#osteoporosis}

骨質疏鬆的病理、分類、骨密度判讀與 2025 台灣指引的鈣與維生素 D 建議見 [[osteoporosis]]；藥物見 [[bone-calcium-drugs]]。本節只整理社區衛教考點

| 項目 | 重點 |
|---|---|
| 診斷 | 髖部或腰椎**雙能量 X 光(DXA)**骨密度；T 值 **≥ −1 正常**、−1 到 −2.5 **骨質減少**、**≤ −2.5 骨質疏鬆**(WHO) |
| 危險因子 | **高齡**、**女性**（停經後雌激素下降）、**家族史**、**體型瘦小或體重過輕**、**飲酒過量**、吸菸、缺乏運動、**過度防曬**（維生素 D 不足） |
| 不是危險因子 | **體位過重**、身材高大、男性 |
| 警訊 | **身高變矮**（壓迫性骨折）、駝背、**下背痛**；睡眠改變、體重減輕不是 |
| 好發部位 | **脊椎**（鬆質骨）、髖部、手腕 |
| 飲食 | 乳品、**豆製品**、**深綠色蔬菜**補鈣；鈣片要評估後用，不能單靠鈣片 |
| 日曬 | 適度曬太陽合成維生素 D；**塗防曬乳會阻擋** |
| 運動 | **負重運動**（快走、慢跑、爬樓梯、阻力訓練）；**游泳、水中有氧**對骨密度效果有限 |
| 荷爾蒙療法 | 可能增加乳癌、中風、血栓風險，**不建議常規用來預防** |
| 不適當 | 減少運動量、穿堅固束腹、刻意減重 |

- 113-3 題答案考選部更正為 **A（只有身高變矮、下背痛）**

## 中老年保健政策與社區支持 {#policy}

- **長者運動**（111-2 題）
   1. 每週累計 **150 分鐘**中等費力運動
   2. 強度以**不疼痛**為原則，體能進步再逐漸增加類型、強度、次數
   3. **坐姿肌力訓練安全，適合**體能差、平衡差的長者
   4. 活動量不足、體能差者先**增加日常活動**
- **獨居老人**支持：定期**關懷訪視**、轉介**社福機構**（送餐、志工）、參與宗教或社區活動；不先建議入住長照機構（在地老化）（111-2 題）
- **獨居老人的界定**（112-2 題，內政部標準，原文待核對）
   1. 同住者**沒有照顧能力**（如心智年齡很低的成年子女）→ 視同獨居
   2. 與 **65 歲以上**配偶同住、沒有其他能照顧的家人 → 符合
   3. 同住子女只是每週出差幾天 → 不符合
- 社區護理在老人照護的策略（110-1 題）：接獲通報去評估＝**發現個案**；送醫並轉入安養機構持續照顧＝**追蹤檢查治療**；機構照護不是「居家照護服務」
- 高齡友善城市、長照 2.0 見 [[long-term-care-services]]；老人保護通報見 [[family-violence]]

## 慢性病概論 {#chronic-disease}

| 特性 | 說明 |
|---|---|
| 病因多重、潛伏期長 | 和生活型態有關 |
| **初期多無症狀** | 所以要篩檢 |
| **無法根治、須終生控制** | **穩定控制不等於治癒** |
| 早期發現可延緩惡化 | 次段預防 |
| 常造成**殘障或機能不全** | 中風後遺症、糖尿病失明截肢 |
| 不只發生在老人 | 年輕化 |
| 需要的是**長期自我照顧**，不是密集醫療照護 | — |

- 個案管理流程：**篩檢發現個案**（最優先）→ 確診轉介 → 追蹤檢查治療 → 衛教自我照顧（106-2 題）
- 個案管理目標：**控制疾病、預防合併症**、會用資源；**最終目標是自我照顧**；「早日痊癒」錯（111-2 題）
- 台灣心臟病、糖尿病防治困難：民眾認知不足、疾病互相影響、醫療院所較少參與保健；**不是**醫療院所不足（105-1 題）
- 三段五級預防見 [[health-promotion]]；社區護理過程見 [[community-nursing-process]]

## 三高、代謝症候群與痛風衛教 {#lifestyle}

| 衛教項目 | 建議 |
|---|---|
| 膽固醇 | 每日 **< 300 mg**（105-2 題寫 400 為錯；美國 2015 年後已不設上限，國考以此為準） |
| 食鹽 | 每日 **≤ 6 g**（鈉 2,400 mg） |
| 身體活動 | 每週 **≥ 150 分鐘中度**或 **75 分鐘費力**；減重以**有氧運動**為主，不必高強度 |
| 高纖飲食 | 促進膽固醇排泄、**延緩糖分吸收**、促進腸蠕動；**不會降低蛋白質吸收**（109-1 題） |
| 代謝症候群飲食 | 少鹽少油、高纖、避免空腹飲酒；澱粉適量選全穀，不是「每日 6 g」 |

- **代謝症候群判定**（國健署）：下列 5 項有 **≥ 3 項**
   1. 腹部肥胖：腰圍男 **≥ 90 cm**、女 **≥ 80 cm**
   2. 血壓 **≥ 130/85 mmHg**（或服藥）
   3. 空腹血糖 **≥ 100 mg/dL**（或服藥）
   4. 三酸甘油酯 **≥ 150 mg/dL**（或服藥）
   5. HDL 男 **< 40**、女 **< 50 mg/dL**
- 最主要原因是**生活型態**（106-1 題）；112-2 題 BMI 26、腰圍 88 cm 的女性屬**過重**且腹部肥胖
- 血脂：108-2 題「三酸甘油酯 **≥ 200 mg/dL** 屬高血脂」是國健署舊的高血脂定義；代謝症候群用 ≥ 150；檢驗判讀見 [[lipid-profile]]
- 108-1 題：62 歲男性 TG 250、BP 142/92、空腹血糖 96 → 血糖正常，**不是**危險因子
- 高血壓危險因子：妊娠高血壓病史、久坐、壓力熬夜、肥胖；**BMI 24** 是過重邊緣，危險性最低（107-2 題）
- 使血壓突然上升：**溫差大**、**用力排便**(Valsalva)（106-1 題）；高血壓衛教見 [[hypertension]]
- 學生血脂異常：教看**營養標示**、增加運動、了解危害、均衡飲食、戒菸；不用降膽固醇飲料取代水、不要不吃早餐
- **痛風**：避免**啤酒**、每日喝水 **≥ 2,000 mL**、定期驗腎功能；**豆苗、蘑菇、蘆筍**等高普林蔬菜在頻繁發作時少吃（109-2 題）

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 老化使心輸出量增加 | **下降** | |
| 更年期易低血壓 | 較易高血壓 | 雌激素保護減弱 |
| 衰弱無法恢復 | **可逆** | |
| 衰弱長者要多休息 | 增加活動 | 休息加速肌少 |
| Fried 包含跌倒次數 | 不包含 | 五項見上 |
| SOF 體重減 5 公斤 | **5%** | |
| ICOPE 包含藥物、失禁、ADL | 認知、行動、營養、視力、聽力、憂鬱 | |
| 游泳可改善骨鬆 | 負重運動 | 水中無承重 |
| 體重過重是骨鬆危險因子 | **過輕**才是 | |
| 骨鬆男性高於女性 | 女性高 | 停經 |
| 坐姿肌力訓練不適合長者 | 適合 | 安全 |
| 慢性病穩定控制＝治癒 | 終生控制 | |
| 慢性病個案管理以早日痊癒為目標 | 自我照顧 | |
| 膽固醇每日 < 400 mg | < 300 mg | |
| 高纖飲食降低蛋白質吸收 | 不會 | |
