社區護理過程和個人的護理過程一樣有**評估、診斷、計畫、執行、評值**五步，但對象是整個社區，所以重點在**和社區一起**排定優先順序、運用資源與**賦權**。社區健康營造則是讓居民**由下而上**自己找出並解決健康議題。評估方法與次系統見 [[community-assessment]]；社區護理師角色見 [[community-health-nursing-intro#roles]]

## 重點摘要 {#summary}

- 社區健康問題的優先順序：**Freeman 五原則**＝**預防效果**、**問題的嚴重性**、機構政策與目標、可利用資源、居民的了解與期待；嚴重性看**影響人數、致死率、殘障比例、經濟損失**
- 急性**傳染病**(登革熱、麻疹、開放性肺結核)通常優先於慢性病與篩檢率問題；**社會正義**原則下，弱勢族群的問題要優先
- 目標要**具體可測量**(例：學童能說出三種預防流感的方法)
- 社區夥伴關係與賦權：**由下而上**、平等互動、民眾**自決自主自助**，護理師是協助者，不是領導者或決定者
- 社區健康營造步驟(國考)：**成立推動小組 → 訂定健康議題 → 結合社區資源 → 激發民眾參與 → 永續經營**；永續最重要的是**種子志工培訓**

### 國考常考點 {#exam-points}

- 和居民對問題優先順序**達成共識**、排定多個問題的優先次序 → **民意團體過程**
- 排序考量**不包括護理人員的動機**(要看社區對問題的了解與動機)；判斷嚴重性**不看社區凝聚力**
- 依 Freeman 原則**最優先**考慮**預防效果**；登革熱比高血壓、腦中風、心臟病優先(預防效果與傳播)
- 開放性肺結核優先於高血壓，依據是**問題的嚴重性**
- 社區健康診斷要善用社區**內外**資源，「以社區內資源為主」不是原則
- 在長者住處附近的學校活動中心設疫苗站 → **可近性**
- 社區夥伴關係**不是**依照衛生所目標辦活動，也**不是**護理師居於領導地位
- 社區增能是**由下而上**、平等的權力關係，**能**提升個人對生活的掌控
- 賦權營造健康環境：**不是**政府主動提供，而是激發居民自己營造
- 社區健康營造：**由下而上**，專家**不**擔任社區領導者，護理師**不**替社區決定議題；最終目的是改善健康與生活品質、發揮自決自主自助(不是「改變社區環境」本身)
- 社區運動社團一起推健康體能 → **結合社區資源**
- 社會資源運用優先考量社區需要、資源質量與持續性、合理分配；**不是**民意代表的意見，也**不是**配合社區組織的利益
- 健康社區評估三面向：**社區資產與能力**、**社區參與與賦權**、**跨領域合作與結盟**(不包括醫療福利資源開發)
- 原住民族及離島**部落社區健康營造**：跨領域合作，建構「**在地人服務在地人**」的健康照護資源

## 社區護理過程 {#nursing-process}

### 概念模式 {#models}

- **社區為夥伴**(Anderson 與 McFarlane)：評估社區核心與 8 個次系統 → 分析壓力源與阻力 → 社區護理診斷 → 以**初段、次段、末段預防**計畫措施 → 評值，見 [[community-assessment#community-as-partner]]
- **White 公共衛生護理模式**：影響健康的四類決定因素(人類生物、環境、醫療技術與機構、社會)；工作優先次序 **3P**：預防(prevention) → 保護(protection) → 促進(promotion)；措施 **3E**：教育、工程、強制，見 [[community-health-nursing-intro#three-e]]
- **以社區為個案的護理過程**(Stanhope 與 Lancaster)：界定社區 → 收集資料 → 統整分析 → 問題清單與優先順序 → 社區診斷 → 介入計畫 → 執行 → 評值，任一階段未完成就回到資料收集
- **MAPP**(Mobilizing for Action through Planning and Partnerships)：組織與夥伴 → 共同願景 → 四項評估 → 策略主題 → 目標與策略 → 行動週期
- 社區護理診斷分類可用 **Omaha 系統**(美國訪視護士協會發展，適合社區與居家)

### 社區護理診斷 {#diagnosis}

- 由資料收集 → 解釋、聚集與分類資料 → 確立健康問題
- 原則：**邀請居民共同參與**、考量**衛生政策**走向、以護理師與團隊能解決的問題優先考量、運用社區**內外**資源

### 排定優先順序 {#priority}

| 準則 | 說明 |
|---|---|
| 社區對問題的**了解** | 民眾知道問題存在、原因與解法 |
| 社區解決問題的**動機** | 居民最想解決的問題，推行最順利 |
| 問題的**嚴重性** | **影響人數**多、**致死率**高、**殘障**比例高、**經濟損失**大 |
| **可利用資源** | 沒有資源反而引發無力感 |
| **預防效果** | 能防患未然的優先(Freeman 列為最優先考量) |
| 護理人員解決問題的**能力** | 從專長領域著手，獲得社區信任 |
| **健康政策與目標** | 與國家、機構政策配合，容易得到經費與人力 |
| 解決的**快速性**與持續效果 | 被動的社區先做容易見效的 |

- **Ruth Freeman 五原則**：預防效果、問題的嚴重性、機構的政策與目標、可利用的資源、居民的了解與期待
- Goeppinger 另提：社區對問題的了解、解決動機、護理人員與團隊的能力、嚴重性、解決速度
- **社區凝聚力**是社區的資源或能力，不是判斷問題嚴重性的指標
- **護理人員自己的動機**不是排序依據
- 計分方法：
   1. **Muecke**：每項準則 0–2 分，加總越高越優先
   2. **Stanhope 與 Lancaster**：準則比重 1–10 乘上**資源**分數 1–10 後加總
   3. **基本優先順序評比**(Vilnius 與 Dandoy)：(影響大小 A ＋ 2 × 嚴重性 B) × 介入有效性 C，再用 **PEARL**(正當性、成本可負擔、可接受、資源可及、合法)篩選
- 國考題型：
   1. 疑似**肺結核**、本土**登革熱**、**麻疹**群聚 → 優先於篩檢率低、資源不足、認知不足
   2. 高血壓、腦中風、登革熱、心臟病都偏高 → 依預防效果先處理**登革熱**
   3. **社會正義**：整體嬰兒死亡率低，但某弱勢族群特別高 → 該族群問題**優先**
- 和居民一起決定優先順序 → **民意團體過程**(見 [[community-assessment#holistic-methods]])

### 計畫 {#planning}

- 內容：排定優先順序、訂定目標、尋求資源、設計**初段、次段、末段預防**措施
- 計畫的特色：綜合性、可修正、分階段且有期限、有預算、民眾可接受、可評價
- 目標原則：
   1. **RUMBA**：真實(realistic)、可了解(understandable)、**可測量**(measurable)、行為(behavioral)、可達成(achievable)
   2. **5W**：誰、做什麼、何時、在哪裡、怎麼做
- 最容易評值的目標：**具體可測量的行為**(「國小學童能說出三種預防流感的方法」)；「問題解決能力提升」「認同健康飲食重要」較難測量

### 執行與社區動力 {#implementation}

- 護理師扮演**協調者**與**觸媒、催化者**，目標是讓社區發展**自行解決問題的能力**
- Warren 社區動力圖：社區組成要素 ＋ **溝通**(縱向與橫向) ＋ **領導與決策**(官方與非官方) → 發揮五項功能
- 服務地點的安排考慮**可近性**(例：在長者住處附近的學校活動中心打疫苗)

### 評值 {#evaluation}

| 種類 | 問的是 |
|---|---|
| **效果**(effectiveness) | 達到預期目標的程度(最常用) |
| **效率**(efficiency) | 資源利用與成本效益 |
| **合適性**(relevance／adequacy) | 目標是否真的解決問題；解決錯的問題＝**第三類錯誤** |
| **成效**(impact) | 計畫的價值、是否引發其他問題 |

- Donabedian：**結構、過程、結果**三面評值，見 [[quality-management-concepts]]

## 社區夥伴關係與賦權 {#partnership-empowerment}

- **社區夥伴關係**：尊重社區文化、促進民眾主動參與、**由下而上**匯集需求、專業人員與民眾**共同討論決定**活動
   1. 護理師**不是**居於領導地位
   2. **不是**依照衛生所的目標辦活動(由上而下)
- **賦權**(empowerment，又譯增能、培力)：
   1. **由下而上**、**平等**的權力關係與對話
   2. 民眾主動參與社區健康活動
   3. 包括過程與結果，能提升個人與社區對生活和環境的**掌控**
   4. 營造健康支持性環境要由專業人員**激發居民**自己營造，不是政府主動提供

## 社區健康營造 {#health-making}

### 緣起 {#history}

- **社區發展**：社區發展工作綱要(公共設施、生產福利、精神倫理建設)，由**社區發展協會**推動
- **社區總體營造**：1994 年文建會提出，從**由上而下**轉為**由下而上**
- **社區健康營造**：衛福部(國健署) **1999 年**開始推動，補助設立社區健康營造中心；目標「健康生活化，生活健康化」
- 承辦單位：民間團體(社區發展協會、農會、基金會)、醫療院所、學校、**衛生所**與公所；近年主力逐漸轉到衛生所

### 主要精神 {#spirit}

- **由下而上**、民眾**自發自覺**發現問題，發揮**自決、自主、自助**的力量
- 結合不同專業與社區資源，激發民眾關心自己的健康
- 目的是改善**健康狀況與生活品質**，透過社區發展讓民眾自己解決健康議題
- 護理師的功能：完整社區評估、提供衛教與醫療相關服務、連結資源；**不**替社區決定議題，專家**不**擔任社區領導者

### 步驟 {#steps}

| 國考 115-1 題的順序 | 說明 |
|---|---|
| 1. **成立社區健康營造推動小組** | 熱心居民、老師、專業人士等組成 |
| 2. **訂定社區健康議題** | 健康社區評估，了解社區特性與需求 |
| 3. **結合社區資源** | 例：與社區運動社團共同推健康體能 |
| 4. **激發民眾共同參與** | 宣導、活動、競賽 |
| 5. **永續經營** | **種子志工培訓**最重要 |

- 課本(嘉義市衛生局手冊)的步驟是**找出健康議題 → 凝聚共識 → 強化社區組織與網絡 → 喚起參與興趣**；國考 105-2 題「第一步驟」答案是**找出健康議題**
- 實施四期程：**組織期 → 行銷籌備期 → 行動期 → 評價回饋期**
- 永續經營要看的是：是否接受民眾**自決與創意**的組織文化、是否發展多元健康生活策略、是否經過民眾自決健康需求的過程；**不需要**由上而下形成行動

### 策略與手法 {#strategies}

- 七大面向：機構特性與運作(推動小組)、**社區資源運用**、**激發民眾參與**、訂定符合社區特性的議題、引發社區動力的手法、營造步驟、4 期程
- **健康社區評估**和傳統社區健康評估不同的三個特色：
   1. 以**社區資產與社區能力**為導向
   2. 提升**社區參與與賦權**
   3. **跨領域合作與社區結盟**
- 引發社區動力的手法：攀龍附鳳(聯合其他團體)、圍棋術與選舉術(讓村里鄰長成為幹部)、傳播理論、**社會行銷**(產品、價格、通路、促銷、夥伴)、學習理論、競賽、網絡、情報(海報、社區通訊、網站)
- 社會資源運用原則：
   1. 符合**社區需要**
   2. 確認資源負荷，確保**質量與持續性**
   3. 重視社會責信、使用透明、**合理分配**
   4. 與資源提供者建立長久關係
   5. 統整協調
- 運用人力依專長、把握經濟原則、依預算執行並公開收支；以社區整體利益為核心，**不是**配合特定組織的利益或民意代表的意見

### 相關運動 {#related-movements}

- **健康城市**：WHO 1986 年提出，源於阿瑪阿塔宣言與**渥太華健康促進憲章**(建立健康公共政策、創造支持環境、強化社區行動、發展個人技能、調整健康服務方向)；指標分健康、健康服務、環境、社經四大面向
- **安全社區**：WHO 社區安全推廣協進中心認證，基於實證與傷害紀錄；國健署 2005 年開始推動
- **高齡友善城市**：WHO 八大面向(敬老、親老、無礙、暢行、安居、連通、康健、不老)；嘉義市首先試辦，全臺 22 縣市都已推動
- **原住民族及離島部落社區健康營造**(衛福部護理及健康照護司)：跨領域合作，建構「**在地人服務在地人**」的健康照護資源；原住民慢性病照護可運用部落特性做社區健康營造，見 [[health-equity#indigenous]]
- 美國 Healthy People 的 **MAP-IT**：動員、評估、計畫、執行、追蹤

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
