分娩疼痛是主觀而個別的經驗，與子宮收縮、產道伸展、恐懼、過去經驗與文化都有關。本頁整理產痛的來源、非藥物減痛的理論與方法、換氣過度的處理，以及藥物減痛與產科麻醉的護理。一般疼痛評估與閘門控制理論見 [[pain-management]]，麻醉藥本身見 [[anesthetics]]，鴉片類見 [[opioids]]，產前的呼吸法練習見 [[prenatal-care#childbirth-preparation]]。文中縮寫：TENS（Transcutaneous electrical nerve stimulation，經皮神經電刺激）

## 重點摘要 {#summary}

- 第一產程痛來自**子宮頸變薄擴張**、**子宮下段伸展**、宮縮時肌肉**缺氧**，經 **T10–L1** 傳導
- 第二產程痛來自**陰道與會陰伸展**、**胎兒壓迫**會陰與周圍構造，經 **S2–S4**（陰部神經）
- **呼吸放鬆技巧**用**條件反射**理論；**腹部輕撫、意象、音樂**用**門閥控制**理論；**Read** 提出**害怕—緊張—疼痛**循環
- **換氣過度**：頭暈、嘴唇手指發麻 → **放慢呼吸**、用手或紙袋罩住口鼻
- 硬膜外麻醉：前後輸注**不含葡萄糖**的晶體液、**左側臥**、監測**血壓**與胎心音、注意**尿瀦留**

### 國考常考點 {#exam-points}

- **條件反射**理論用在**呼吸放鬆技巧**；輕撫按摩、集中注意力與意象**不是**條件反射（是門閥控制）；**Read** 提出的是**害怕、緊張、疼痛循環**
- 第二產程痛的來源**不包括子宮下段伸展**（那是第一產程）；第三產程痛來自**胎盤排出時的宮縮與子宮頸擴張**
- 國考把「第二產程主要來源是子宮收縮、陰道會陰伸展」當成錯誤敘述（課本寫的是韌帶、陰道會陰伸展與胎兒壓迫）
- 泡澡減痛：**不是第二產程才能泡**；水溫約 **37°C**、水面**蓋過腹部**
- 待產中頭暈、嘴唇手指麻刺感 → **換氣過度** → 優先**教導減慢呼吸速率**（不是給氧、不是加快點滴）
- 6 公分要求針灸：針灸**可能**減輕產痛 → **協助照會中醫師**（護理師不可自行針刺）
- 2 公分、宮縮 6–7 分鐘一次、說痛到無法忍受 → 依宮縮給**按摩放鬆**技巧（國考答案；現行 ACOG 指引產婦要求就可以給硬膜外）
- 剖腹產硬膜外麻醉前：側躺蝦米姿勢、L3–4 穿刺、給藥後監測生命徵象；**不輸注 1,000 mL 葡萄糖水**（要用林格氏液或生理食鹽水）

## 產痛的來源 {#pain-sources}

| 產程 | 疼痛來源 | 部位 | 傳導 |
|---|---|---|---|
| **第一產程** | **子宮頸變薄與擴張**、**子宮下段伸展**、宮縮時子宮肌肉**缺氧** | **下腹部**、**下背部**，可放射到大腿 | 內臟神經，經 **T10–L1** 進入脊髓 |
| **第二產程** | 子宮韌帶伸張、**陰道與會陰肌肉伸展**、細胞缺氧、可能的撕裂、**胎兒先露部位壓迫**會陰與周圍構造 | **會陰部** | 陰部神經，經 **S2–S4** |
| **第三產程** | **胎盤排出**時的**子宮收縮**與子宮頸擴張 | 恥骨聯合上方、下背 | |

- 影響疼痛感受的因素：恐懼焦慮、疲累、過去經驗、對生產的期待、文化、支持系統、胎位（**枕後位**下背痛明顯）、膀胱脹
- 疼痛是主觀的：產婦說痛就是痛，**尊重**她的感受，不要否認

## 非藥物減痛的理論 {#theories}

| 理論 | 提出者與內容 | 應用 |
|---|---|---|
| **害怕—緊張—疼痛循環** | **Dick Read**(1933)：不了解生產 → 害怕 → 肌肉緊張 → 疼痛加劇 → 更害怕 | 產前**生產教育**、放鬆技巧，打斷循環 |
| **條件反射**（精神預防性減痛法） | 源自 Pavlov 的條件反射；**拉梅茲**(Lamaze)法：反覆練習，讓「宮縮」連結到「放鬆與呼吸」，取代原本「宮縮 → 緊張疼痛」的反應 | **呼吸放鬆技巧**（要在產前反覆練習） |
| **門閥控制理論** | 刺激其他感覺神經或轉移注意力，在脊髓後角「關閘」，減少痛覺往上傳 | **腹部輕撫法**、按摩、反向施壓、冷熱敷、**集中注意力與意象法**、**音樂** |

- 閘門控制理論的神經機轉見 [[pain-management#gate-control]]

## 非藥物減痛方法 {#non-pharmacologic}

| 類別 | 方法 | 要點 |
|---|---|---|
| 皮膚刺激 | **腹部輕撫法** | 宮縮時用指尖在下腹輕輕畫圈 |
| | **反向施壓** | 用拳頭或網球**壓住薦骨**，對**枕後位的下背痛**特別有效 |
| | 按摩 | 肩、背、手、腳；可教伴侶做 |
| | **熱敷**、冷敷 | 熱敷下背或下腹；第二產程**會陰溫濕敷**可減輕著冠時的燒灼感 |
| | **水療** | 見下方 |
| | 穴位按壓 | 合谷、三陰交等 |
| | 皮內注射水阻斷 | 在薦骨區皮內注射少量無菌水，緩解**下背痛** |
| | TENS | 下背貼電極 |
| 感覺刺激 | **呼吸技巧** | 見下方 |
| | 音樂、芳香療法、**意象法**、集中注意力（注視一點） | 轉移注意力、放鬆 |
| 認知 | 生產教育、催眠、提供產程資訊 | 減少恐懼 |
| 其他 | **改變姿勢**、走動、生產球、**排空膀胱**、陪伴 | |

- **水療**（淋浴、泡澡）
   1. 水溫約 **36–37°C**（太熱會讓產婦體溫上升、胎兒心搏過速）
   2. 泡澡時**水面蓋過腹部**，浮力讓身體輕鬆、好移動
   3. 進入**活動期**後再泡較好（太早泡可能讓宮縮變弱）；**不是**第二產程才能泡
   4. 泡水時仍要定時聽胎心音
   5. 時間：考題寫一次不超過約 **1.5 小時**（待核對）
   6. 已破水不一定是禁忌，依各院規定；有感染、出血、胎兒窘迫時不宜
- **針灸**：可能減輕產痛，產婦要求時協助**照會中醫師**；護理師不可自行針刺
- **呼吸技巧**（拉梅茲，產前練習見 [[prenatal-care#childbirth-preparation]]）

| 時機 | 呼吸 |
|---|---|
| 潛伏期 | **慢速胸式**（或腹式）深呼吸，每分鐘約 6–9 次 |
| 活動期 | **加速**的淺呼吸，隨宮縮強度調整 |
| 過渡期、子宮頸未全開想用力 | **喘息—吹氣**（哈哈哈—呼）、**吹蠟燭式**呼吸，避免太早用力 |
| 第二產程用力 | 有便意時**開聲門**用力（見 [[intrapartum-care#second-stage-care]]） |
| 胎頭著冠 | **哈氣**、喘息，讓胎頭慢慢出來 |

- 每次宮縮開始與結束都做一次**清潔呼吸**（深吸慢吐）

### 換氣過度 {#hyperventilation}

- 原因：疼痛、焦慮、呼吸太快太深 → CO₂ 排出太多 → **呼吸性鹼中毒**
- 表現：**頭暈**、**嘴唇與手指發麻刺痛**、手腳抽筋
- 處理
   1. **教導放慢呼吸速率**、陪她一起呼吸（跟著手勢）
   2. 用**雙手或紙袋罩住口鼻**，吸回自己呼出的 CO₂
   3. 安撫、減少焦慮
- 不是缺氧，給氧或加快點滴**不是**優先處置
- 呼吸性鹼中毒見 [[abg]]

## 藥物減痛與產科麻醉 {#pharmacologic}

| 方法 | 用在 | 護理重點 |
|---|---|---|
| **全身性鴉片類**（meperidine、fentanyl 靜脈或肌肉注射） | 第一產程 | 母親嗜睡、噁心、呼吸抑制；通過胎盤 → 胎心**變異減少**、新生兒**呼吸抑制**；**接近分娩時**給藥影響最大 → 準備 **naloxone**（見 [[opioids#special-populations]]） |
| 鎮靜劑、安神劑 | 潛伏期休息、減少焦慮 | 不能止痛；新生兒嗜睡 |
| **硬膜外麻醉** | **減痛分娩**、剖腹產 | 見下方 |
| **脊髓麻醉** | **剖腹產** | 低血壓較快較常見、脊髓麻醉後頭痛（見 [[anesthetics#pdph]]） |
| **陰部神經阻斷** | **第二產程**、會陰切開與修補、器械生產 | 阻斷 S2–S4，不影響宮縮 |
| 局部浸潤 | 會陰切開與縫合 | |
| **全身麻醉** | **緊急剖腹產**、區域麻醉禁忌 | **吸入性肺炎**（術前禁食、制酸劑）、新生兒抑制、子宮鬆弛 → 產後出血 |

- 硬膜外減痛分娩
   1. 藥物：低濃度局部麻醉藥＋鴉片類（藥理見 [[anesthetics#labor-analgesia]]）
   2. 時機：考題常以子宮頸 **3–4 公分**以上為準；**ACOG 2019**：產婦**要求**、沒有禁忌就可以給，**不必等**子宮頸開到某個程度
   3. 擺位：**側躺蝦米狀**或坐姿彎腰，穿刺 **L3–4** 或 L2–3
   4. 麻醉前**靜脈輸注晶體液**（林格氏液或生理食鹽水 500–1,000 mL），**不用葡萄糖水**（母親與新生兒血糖問題）
   5. 給藥後：**每 5 分鐘量血壓**（前 15–30 分鐘）、監測**胎心音**、**左側臥**或子宮左推
   6. **低血壓** → 左側臥、加快輸液、依醫囑升壓劑
   7. **評估膀胱**（感覺不到尿意 → **尿瀦留**，阻礙胎頭下降）
   8. 下肢感覺與運動、跌倒預防；第二產程可能延長、用力感變弱
   9. 禁忌：凝血異常、穿刺處感染、嚴重低血容、產婦拒絕
- 脊髓與硬膜外的比較見 [[anesthetics#neuraxial]]
