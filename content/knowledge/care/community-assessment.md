社區健康評估是**社區護理過程的第一步**：用多種方法收集社區的主觀與客觀資料，找出社區的能力、問題與資源，作為排定優先順序與計畫的依據。國考最常考三件事：**某項資料屬於哪個次系統**、**某種情境用的是哪種評估方法**、**資源是有形還是無形**。排定優先順序、計畫與評值、社區健康營造見 [[community-nursing-process]]；人口與生命統計指標見 [[vital-statistics]]

## 重點摘要 {#summary}

- 社區四要素：**居民、地理疆界、社會互動、社區認同**；Ross 的類型：**地理性、功能性、互動性**（病友團體是**互動性**）
- **Warren 五項功能**：生產分配消費、**社會化**（學習價值觀與知識）、**社會控制**（巡守隊）、**社會參與**（文康活動、志工）、**相互支援**（送餐、捐助）
- **Anderson 與 McFarlane 社區為夥伴模式**：社區核心（歷史、人口特性、價值與信仰）＋**8 個次系統**（物理環境、健康及社會服務、經濟、安全與交通、政治與政府、溝通、教育、娛樂）；強調**平等互惠、由下而上、增能**
- 評估方法：**走街式**（感官觀察環境與生活型態）、**重要人物訪談**（立意或滾雪球選人）、**參與式觀察**（參加活動，看互動、權力與決策）、**社會指標／文獻考察**（統計資料）、**社會調查**（問卷）、**民意團體過程**（達成共識、排優先）、**焦點團體**（深入討論特定議題）、**德爾菲法**（專家匿名多回合）、**影像發聲法**（居民拍照討論）
- 資源：**有形**＝人力、物力、財力(3M)，**人力最容易取得但最難掌控**；**無形**＝社區意識、文化規範、社區凝聚力

### 國考常考點 {#exam-points}

- 次系統歸類：垃圾處理、空氣水質、動植物 → **物理環境**；疾病與罹病率、醫療資源可近與可用、醫療社福機構、就醫滿意度 → **健康及社會服務**；獨居老人共餐 → **社會福利**；防火巷、消防栓 → **安全**；與正式與非正式領導人的互動、對里長滿意度 → **政治與政府**；圖書館數量與使用 → **教育**；民眾對知識的接受度 → **教育**（不是溝通）；訊息傳遞管道 → **溝通**；教育程度、婚姻 → **人口特性**
- **社區發展史**最能了解居民的價值觀、風俗習慣、文化特性與政治體系
- 社區需求評估的**第一步**是**文獻查證與二手資料**收集
- 重要人物訪談：對象**必須非常了解社區**，要包括各層級，用**立意或滾雪球**取樣（不是隨機）；資料帶個人色彩，不一定客觀
- **走街式調查**看不出人口與生命統計，要查戶政與衛生統計
- 了解**權力分配、溝通方式、決策過程** → **參與式觀察**；參加社區健走活動觀察互動 → **參與式觀察**
- 透過網路邀請族群填答調查 → **社會調查**；運用政府統計資料 → **文獻考察**
- 了解居民對問題的認識與解決動機、排優先順序 → **民意團體過程**；**德爾菲法**是專家共識，不適合收集一般居民的需求、價值觀與文化
- 名額已滿 → **可用性**不足；調查自費檢驗能力 → **可負擔性**；調查醫療院所數量 → **量及分布**
- **身心障礙人數**不能從戶政系統取得（社政資料）；**民眾對社區的認同感**要用問卷或訪談
- 判斷某社區糖尿病死亡率是否偏高，最不適合拿**世界衛生組織(World Health Organization, WHO)全球資料**比較；應比全國、縣市、該社區往年
- 社區評估強調**民眾參與**，不是由學者主導；資源盤點的功能**不包括凝聚共識**
- 以群體為基礎的服務**比較符合成本效益**
- 本章綜合題(107-2)考免費乳癌篩檢資格，篩檢條件見 [[national-health-insurance#preventive-services]]

## 社區的概念 {#community}

### 定義與要素 {#definition}

- WHO(2004)：一群人，通常在固定地理區域，在特定社會結構下發展出相近的文化、價值與規範，因而有共同需求與互助承諾；成員**共同創造社會規範、行使社會功能**
- 國內行政定義（社區發展工作綱要）：由鄉鎮市區主管機關劃定、可依法設立社區發展協會的區域
- 四要素：
   1. **居民**(people)
   2. **地理疆界**(place)
   3. **社會互動**(social interaction)
   4. **社區認同**（我屬感、社區情結）
- 社區定義的三大概念：**地點、人、功能**；社區是**動態**、有彈性的

### 社區類型 {#community-types}

| 類型 | 依據 | 例子 |
|---|---|---|
| **地理性**（地域性） | 地理或行政疆界 | 村里、鄉鎮 |
| **功能性**（共同利益） | 分散各地的人因共同利益或功能結合 | 護理師公會 |
| **互動性** | 因相似特質與需要聚集、互助，不受地理限制 | **糖尿病、乳癌病友團體**（國考答案） |

- 功能性社區**不是**以地理疆界劃分
- **群體**(aggregate)：一群分享一個以上個人或環境特質的人；社區由許多群體組成，每個人通常屬於多個群體

### 臺灣社區的特性 {#taiwan-community}

- 地理疆界不明確、住宅從平面變立體、人口流動快、功能混雜（住商工混合）、生活圈擴大、缺乏本土性 → 居民的**社區認同**較弱

### Warren 五項社區功能 {#functions}

| 功能 | 意思 | 例子 |
|---|---|---|
| **生產－分配－消費** | 提供食衣住行育樂所需 | 假日小農市集 |
| **社會化** | 居民學習價值觀、文化、知識與相處技巧 | 讀書會、學校 |
| **社會控制** | 維持秩序與安全、規範行為 | **巡守隊、守望相助隊** |
| **社會參與** | 提供參加團體與活動的機會 | **社區文康活動**、導護志工、歌唱班 |
| **相互支援** | 居民生病或經濟困難時提供協助 | **獨居老人送餐**、慈善捐助、急難救助 |

### 健康的社區 {#healthy-community}

- 沒有絕對健康的社區，是**相對、動態**的
- 可從三方面判斷（依 Donabedian）：**結果**（死亡率、罹病率、平均餘命、滿意度、犯罪率）、**結構**（服務與資源的型態與利用）、**過程**（社區解決問題的能力）
- 健康與否要由**居民自己決定**，護理師與社區是**夥伴**

## 社區健康評估 {#assessment}

### 意義與目的 {#purpose}

- 了解社區動力與功能型態、文化與能力、信念與價值，確認健康需求並排定優先順序，作為計畫與預算的依據
- 目的：讓照護計畫**真正反映社區需求**、提升預防性照護計畫的品質
- 評估要結合**客觀資料**（統計、調查）與**主觀資料**（觀察、感受）
- 重視**民眾參與**，學者與專家只是協助

### 評估內容 {#content}

| 方向 | 內容 | 資料來源 |
|---|---|---|
| **地理環境** | 社區界限與範圍、醫療保健服務的地點、自然環境、氣候、動植物、人為環境（工業、汙染、房屋、交通） | 地圖、地方簡報、走街式調查、重要人物 |
| **人口群體** | 人口數與密度、**組成**（年齡、性別、**婚姻**、族群、職業、**教育程度**、依賴人口）、成長與流動（自然與社會增加率）、健康狀況（死亡、罹病）、**社區發展史** | **戶政事務所**、衛生所、人口普查 |
| **社會系統** | 保健、福利、教育、經濟、政治、娛樂、宗教、溝通、安全與運輸（課本列 9 大系統） | 各機關資料、走街、訪談、問卷 |

- 教育程度的用途：作為**健康指導**（衛教內容與教材難易）的依據
- 戶政系統可以取得遷入遷出、出生死亡、外籍人口；**身心障礙人數**屬社政資料
- 社區發展史可從**圖書館、地方誌**取得，最能了解價值觀、風俗習慣、文化與政治體系

### 社區為夥伴模式 {#community-as-partner}

Anderson 與 McFarlane 的「社區為夥伴」(community as partner)架構：

- **社區核心**：歷史、**人口特性**（年齡、性別、婚姻、教育、性比、社會增加率）、價值與信仰
- **8 個次系統**：

| 次系統 | 評估內容舉例 |
|---|---|
| **物理環境** | 空氣、水質、**垃圾處理**、氣候、動植物、人為環境 |
| **健康及社會服務** | 疾病與罹病率、醫療資源**可近性與可用性**、醫療與社福機構的分布與類型、**就醫滿意度**、獨居老人共餐等福利服務 |
| **經濟** | 職業、收入、失業率、貧戶比率 |
| **安全與交通** | 消防與警政、**防火巷、滅火器、消防栓**、犯罪與事故、大眾運輸 |
| **政治與政府** | 權力結構、決策、居民與**正式與非正式領導人**的互動、對**村里長滿意度** |
| **溝通** | 正式與非正式**訊息傳播管道**（公布欄、社區報、社群媒體） |
| **教育** | 學校、**圖書館**數量與使用、教育程度、對**知識的接受度** |
| **娛樂** | 公園、活動中心、休閒設施與滿意度 |

- 評估後分析**壓力源**與**阻力**，訂出社區護理診斷，再以**三段預防**計畫措施
- 特徵：**與社區平等互惠**、**由下而上**匯集需求、**喚起社區意識**、評估過程本身讓民眾**增能**；**不是**專業主導，也不是只看內部互動
- 了解**社區動力**看溝通方式、領導與決策、團體互動；人口特性資料不屬於社區動力

### 評估步驟 {#steps}

1. **文獻查證與二手資料**（第一步）
2. 實地考察：走街式調查
3. 訪談重要人物、參與式觀察，以社會調查補足
4. 綜合分析一手與二手、質性與量性資料
5. 向社區民眾報告結果並尋求回饋

- 社區健康評估過程可分準備、評估、**診斷**、計畫、執行、評值；**診斷期**包括歸納資料要點、解釋與組織資料、陳述社區健康問題、**設立優先順序**

## 評估方法 {#methods}

### 整體性評估方法 {#holistic-methods}

| 方法 | 做法 | 適合收集 | 注意 |
|---|---|---|---|
| **擋風玻璃式／走街式調查** | 步行或乘車，用**視、聽、嗅、味、觸**等感官觀察 | 物理環境、生活型態、居民互動、安全設施、娛樂與醫療機構分布 | **主觀**資料；看不出人口與生命統計 |
| **重要人物訪談** | 訪談**非常了解社區**的人（居民、在社區工作者、有影響力者） | 社區發展、特性、主要問題、各系統資料 | 用**立意或滾雪球**取樣；要包括各層級與不同立場；資料帶個人色彩 |
| **參與式觀察** | 以社區成員身分**參加社區活動**觀察 | 社區互動、**權力分配**、溝通與領導**決策型態** | 例：參加重陽健走、里內健走 |
| **社會指標**（文獻考察） | 用政府與機構的**統計資料**和其他社區比較 | 生命統計、衛生統計 | 屬次級資料 |
| **社會調查** | **隨機**選部分居民，以問卷或街頭訪談詢問 | 無法直接觀察的價值觀、滿意度、特定族群風險 | 例：網路邀請更年期婦女填寫心血管風險調查 |
| **民意團體過程**(nominal group process) | 護理師主持正式會議，邀居民與服務提供者討論、**投票排序** | 居民對問題的認識與**解決動機**、**排定優先順序**、達成**共識** | 評估社區需求最常用 |

- 民意團體過程六步驟：提問最大的問題 → 全部記錄 → 逐項說明原因與解法 → 投票 → 依結果再討論 → 最後投票達成共識

### 特定議題評估方法 {#specific-methods}

| 方法 | 做法 | 用途 |
|---|---|---|
| **焦點團體訪談** | 8–12 人、1.5–2.5 小時，主持人引導討論**少數議題** | 問題確認後，深入討論可行策略與分工；快速、成本低、不識字者也能參加 |
| **德爾菲法**(Delphi) | **專家**以**匿名**問卷**多回合**回饋，用描述性統計呈現共識 | 專家預測與共識；**不適合**收集居民的需求、價值觀、民族性與文化 |
| **影像發聲法**(photovoice) | 居民拍照記錄生活，再以照片為媒介團體討論 | 了解需求、引發反思、影響政策 |

## 社區資源 {#resources}

### 有形與無形 {#tangible-intangible}

| 類別 | 項目 | 例子 |
|---|---|---|
| **有形**(3M) | **人力**(manpower) | 志工、里長、專家、醫護人員 |
| | **物力**(material) | 活動中心、醫療院所、電子公布欄、器材 |
| | **財力**(money) | 公共基金、政府補助、捐款 |
| **無形** | 社區精神力量 | **社區意識**（歸屬感、參與感、責任感、榮譽感）、**文化規範**、**社區凝聚力** |

- **人力資源最容易取得，但最難掌控**（動機與時間各不同）
- 社區意識的凝聚是社區工作成敗的關鍵
- 也可分為內部與外部資源、正式（公私部門服務）與非正式（家人、鄰居、宗教與互助團體）資源
- **資源盤點**的功能：掌握資源所在、檢視重疊的服務、衡量可提供的服務量；凝聚共識要靠社區會議與參與，不是資源盤點本身

### 服務資源的屬性 {#resource-attributes}

| 屬性 | 問的是 | 國考情境 |
|---|---|---|
| **可近性**(accessible) | 地點與交通方便嗎 | 在長者住處附近的學校活動中心打疫苗 |
| **可用性**(available) | 數量夠、需要時有嗎 | 老人健檢**名額已滿** |
| **可負擔性**(affordable) | 付得起嗎 | 調查民眾**自費**檢驗的能力 |
| **可接受性**(acceptable) | 符合居民文化與期待嗎 | |
| **可信任性**(accountable) | 可靠、值得信任嗎 | |
| **量及分布** | 夠不夠、平均嗎 | 調查社區有多少醫療院所 |

- Stanhope 與 Lancaster 用 **7A** 評估社會系統：察覺(aware)、可近、可用、可負擔、可接受、足夠(adequate)、適當(appropriate)
- 除了社區內資源，也要評估居民是否利用**社區外**資源

## 比較資料的選擇 {#comparison}

- 判斷社區某項指標是否偏高，要找**條件相近**的比較基準：全國、所在縣市、該社區往年
- **WHO 全球資料**差異太大，最不適合

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 病友團體是地理性或虛擬社區 | **互動性社區** | 依 Ross 分類與國考答案 |
| 功能性社區以地理疆界劃分 | 以**共同利益**結合 | |
| 巡守隊是相互支援 | **社會控制** | |
| 送餐服務是社會參與 | **相互支援** | |
| 重要人物用隨機抽樣 | **立意或滾雪球** | 對象必須了解社區 |
| 重要人物資料較客觀 | 帶**個人色彩** | 要訪問多人 |
| 民眾對知識的接受度屬於溝通 | 屬於**教育** | |
| 用德爾菲法收集居民文化與需求 | 德爾菲是**專家**共識 | |
| 從戶政系統取得身心障礙人數 | 屬**社政**資料 | |
| 以群體為基礎的服務不符成本效益 | **較符合**成本效益 | |
| 社區夥伴模式由專業主導 | **平等互惠、由下而上** | |
