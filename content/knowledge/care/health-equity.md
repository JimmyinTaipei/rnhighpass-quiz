**健康不平等**是不同社會群體之間**有系統的**健康差距，多半來自出生、成長、生活、工作的社會條件與資源分配不公平。社區護理師的職責之一是讓**弱勢族群**得到公平、可近、合乎文化的照護。本頁整理弱勢族群的定義、臺灣的健康平等政策(原住民族、新住民、身心障礙、遊民)，以及國際的 SDGs 與 WHO。生命統計指標見 [[vital-statistics]]；社區護理師的角色見 [[community-health-nursing-intro#roles]]

## 重點摘要 {#summary}

- **弱勢族群**：比一般人更容易受傷害的群體，健康較差、照護**可近性差**、平均餘命短、罹病與死亡風險高
- 2020 健康國民白皮書縮小三種不平等：**生命週期**(老人、兒童、婦幼)、**社經背景**(低收入、失業)、**身心狀態**(身障、藥酒癮)
- 原住民族政策核心：**文化能力與文化安全**、人才訓練融入**文化敏感度**、依部落差異**個別化**(不是一致性照護)、社區健康營造
- 在遊民庇護所、貧民住宅區**設診所** → 提高**可近性**；新移民婦女照護最需要**文化照護能力**
- SDGs 第 3 項「**確保健康及促進各年齡層的福祉**」：孕產婦死亡率 **< 70／10 萬活產**、消除可預防的新生兒與 **5 歲以下**兒童死亡、非傳染病過早死亡減少**三分之一**

### 國考常考點 {#exam-points}

- 原住民族文化健康站服務 **55 歲以上**原住民(不是 45 歲)
- 原住民族癌症篩檢重點**不是胰臟癌**；原鄉重點是結核病、消化系癌症(肝癌等)、三高；衛福部 107 年原鄉健康不平等改善策略**不包括骨骼肌肉傷害**
- 原住民健康政策要納入文化與傳統，**從小紮根**，不是只顧成人工作能力
- 原住民 **55 歲以上**每年 1 次成人預防保健(一般民眾 65 歲)；保費補助是戶長無職業的未滿 20 歲與 55 歲以上原住民**全額補助**(國考把「部分補助」判為不適當)
- 新住民政策：支持團體、子女發展篩檢、發展遲緩早期療育；「**成立國際小學提供雙語教育**」不是衛生政策
- 身心障礙鑑定是**功能導向**(ICF)，評估社會參與與環境需求，由醫事、社工、特教等專業團隊鑑定；證明**仍有程度分級**
- 2025 白皮書弱勢照顧：積極性社會救助、社區互助網絡、急難救助機制；「強化國際交流服務」不屬於這一項
- **臺灣不是 WHO 會員國**；2009–2016 年以**觀察員**身分出席世界衛生大會
- 國健署「青少年好漾館」對應 SDG 3 **良好健康與福祉**；社區護理對 SDGs 的貢獻是**改善弱勢易感族群的健康**

## 健康不平等 {#health-inequity}

- **健康不平等**(health inequity)：不同社會群體的健康有**系統性**差異，與出生、成長、生活、工作、年齡等**社會條件**有關，屬於**可避免且不公平**的差距
- 全球貧富差距擴大，健康差距跟著擴大
- 臺灣政策方向：
   1. **2020 健康國民白皮書**：延長健康平均餘命、**促進健康平等**；縮小生命週期、社經背景、身心狀態三種不平等
   2. **2025 衛生福利政策白皮書**：注重不同性別、年齡、族群、地區、社經狀態、身障與疾病群體的特殊需求與資源障礙；**健全社會安全網、綿密弱勢照顧**(積極性社會救助、社區互助網絡、完備急難救助)

## 弱勢族群 {#vulnerable-populations}

- 一般包括：經濟弱勢、少數族群、未保險者、老人、遊民、低收入戶兒童、身心障礙者、慢性病群體
- 2020 健康國民白皮書的分類：
   1. 參與經濟生產但弱勢：失業、貧窮工作者、非典型工作者、外籍勞工、職災受害者
   2. 未參與經濟生產：老人、貧窮兒童、身障、找不到工作者
   3. 其他社經弱勢：低收入戶、單親中低收入、無業、低教育、**原住民**、**遊民**、**身心障礙者**
   4. 新興弱勢：卡奴、屋奴、藥癮與酒癮者
- 政府雖有補助，弱勢者常不知道或不會主動申請 → 社區護理師要協助申請、結合社區與非政府組織資源(**代言者**、個案管理者)

### 提高可近性的策略 {#access}

| 原則 | 意思 | 例子 |
|---|---|---|
| **可近性** | 距離、時間、交通方便 | 在**遊民庇護所、貧民住宅區設診所**；偏遠原住民就醫交通補助 |
| 可負擔性 | 費用負擔得起 | 保費補助、免部分負擔 |
| 可接受性 | 合乎文化與信仰 | 通譯、文化敏感的衛教 |

## 原住民族健康 {#indigenous}

- 原住民平均餘命比全國約少 **10 歲**(課本)，所以多項服務提早：
   1. 成人預防保健 **55 歲以上每年 1 次**(一般 65 歲)
   2. B、C 型肝炎篩檢 **40–79 歲**終身 1 次(一般 45 歲)
   3. 口腔黏膜檢查：**18 歲以上嚼檳榔**的原住民(一般 30 歲以上吸菸或嚼檳榔)
   4. 健保費：戶長無職業時，**未滿 20 歲與 55 歲以上**原住民**全額補助**自付保費
   5. 偏遠地區原住民可申請**就醫交通費補助**
- **原住民族文化健康站**(原住民族委員會)：服務 **55 歲以上**健康、亞健康、衰弱、輕度失能的原住民長者，結合文化照顧
- 衛福部 107 年原鄉健康不平等改善策略的重點(國考)：**結核病**、**消化系癌症**、**三高**防治；骨骼肌肉傷害不在其中
- 促進原鄉健康平等的措施：平等的生育保健、健康促進、篩檢與追蹤；尊重原民文化的健康老化與照顧網絡；結核病主動篩檢與用藥指導；運用三段五級延緩失能；**部落社區健康營造**；傳承文化的健康飲食課程
- 擬定政策的原則：
   1. **文化能力**與**文化安全**列為關鍵指標
   2. 人才訓練融入**文化敏感度**
   3. 整體考量健康、疾病、心理衛生、性別、老化與文化
   4. 各部落文化不同，要**個別化**，不是提供一致的照護
   5. 健康意識要**從小紮根**，不是上小學後才開始
- 原住民族與離島醫療屬於衛福部**護理及健康照護司**，見 [[health-administration-system#departments]]

## 新住民 {#immigrants}

- 新移民(外籍配偶)婦女照護最需要的是**文化照護能力**(cultural competence)：理解並尊重文化差異、信仰與衛生習慣；語言只是其中一部分
- 政策：
   1. 尚未納保的外籍配偶，孕產服務由**外籍配偶照顧輔導基金**補助
   2. 外籍配偶諮詢專線、孕產婦關懷專線提供**通譯**
   3. 新住民**支持團體**
   4. 子女**兒童發展篩檢**，發展遲緩者提供**早期療育**
- 成立國際小學提供雙語教育**不是**衛生政策

## 身心障礙者 {#disability}

- 定義(身心障礙者權益保障法第 5 條)：**8 類身體系統**構造或功能損傷，影響**活動與社會參與**，經專業團隊鑑定與評估、**領有身心障礙證明**者
- 鑑定新制採 **ICF**(國際健康功能與身心障礙分類系統，International Classification of Functioning, Disability and Health)精神，**功能導向**：
   1. 由**醫事、社會工作、特殊教育、職業輔導評量**等專業人員組成團隊
   2. 先做**鑑定**，再由社政做**需求評估**(家庭經濟、照顧、社會參與需求)
   3. 鑑定包括身體功能與構造、活動與參與、**環境因素**
- 身心障礙證明**仍有程度分級**(國考把「無需區分嚴重等級」判為錯)
- 身障鑑定與醫療輔具政策由衛福部護理及健康照護司規劃

## 遊民與貧窮 {#homeless-poverty}

- **遊民**：流浪、流落街頭或在公共場所露宿者
- 收容輔導三階段：**緊急服務**(外展熱食、沐浴、禦寒、衛生保健) → **過渡服務**(臨時安置、收容所) → **穩定服務**(就業、居住，促使自立)；精神疾病遊民見 [[community-mental-health]]
- 社區護理師促成在**遊民庇護所設診所**＝提高可近性；製作影片讓大眾了解遊民處境＝**代言者**
- 貧窮族群：社會救助法的低收入戶、中低收入戶；健保第五類由政府全額負擔保費，見 [[national-health-insurance#six-categories]]

## 全球公共衛生 {#global-health}

### 世界衛生組織 {#who}

- 1948 年成立，總部在**瑞士日內瓦**
- 憲章：享有最高可能標準的健康是每個人的**基本權利**；**政府**對人民的健康負有責任
- **臺灣不是會員國**；2009–2016 年以**觀察員**身分出席世界衛生大會(WHA，World Health Assembly)

### 永續發展目標 {#sdgs}

- 聯合國 2015 年通過 **17 項永續發展目標**(SDGs，Sustainable Development Goals)，2030 年達成
- **SDG 3：確保健康及促進各年齡層的福祉**(Good health and well-being)：

| 目標 | 內容 |
|---|---|
| 3.1 | 全球孕產婦死亡率降到每 **10 萬活產 < 70** |
| 3.2 | 消除可預防的新生兒(≤ 12‰)與 **5 歲以下兒童**(≤ 25‰)死亡 |
| 3.3 | 終結愛滋、結核、瘧疾等流行 |
| 3.4 | 非傳染病**過早死亡減少三分之一**，促進心理健康 |
| 其他 | 物質濫用、交通事故、性與生殖健康、全民健康覆蓋 |

- **SDG 10**：減少國內及國家間的不平等
- 社區護理對 SDGs 的貢獻：**改善弱勢易感族群的健康**(SDG 3)；消除貧窮、性別平等、環境永續不是護理專業的直接貢獻
- 例：國健署「青少年好漾館」(青少年性與心理健康資訊) → **SDG 3**
- 國考 110-1 題把「非傳染病過早死亡減少**三分之二**」判為錯

### 數位健康 {#digital-health}

- 行動健康、遠距醫療、穿戴裝置可以改善弱勢族群的可近性，但要注意數位落差與健康識能

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 文化健康站服務 45 歲以上 | **55 歲以上** | |
| 原住民癌篩重點是胰臟癌 | 肝癌等消化系癌症；胰臟癌不是公費篩檢 | |
| 原住民政策只考慮疾病，不需考慮文化 | 要融入**文化敏感度** | |
| 整合各部落提供一致性照護 | **個別化**，尊重部落差異 | |
| 新移民照護最需要多國語言能力 | **文化照護能力** | 語言只是一部分 |
| 身障證明不分等級 | 仍有**程度分級** | |
| 臺灣 2012 年成為 WHO 正式會員 | 不是會員，曾是 WHA 觀察員 | |
| SDGs 非傳染病過早死亡減少三分之二 | **三分之一** | |
| 孕產婦死亡率目標百萬分之 70 | **十萬分之 70** | |
