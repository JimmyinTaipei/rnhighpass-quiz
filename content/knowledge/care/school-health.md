學校衛生由**教育部**主管（不是衛福部），依《學校衛生法》（2002 年公布）推動。學校護理師在**健康中心**做健康檢查與管理、緊急傷病處理、衛生諮詢，也支援健康教學；服務對象是**全校師生與教職員工**。校園採光、照度、噪音等環境標準見 [[environmental-food-hygiene#school-environment]]；校園菸害見 [[health-promotion]]；學生傳染病見 [[notifiable-diseases]]

## 重點摘要 {#summary}

- 主管機關：中央**教育部**；直轄市、縣市**政府**（教育局處）；學校內由**衛生保健組**執行
- 護理人員（第 7 條）：高中以下 **未達 40 班 1 人、40 班以上至少 2 人**；營養師（第 23-1 條）：高中以下 **40 班以上至少 1 人**
- **健康中心**（第 6 條）：健康檢查與管理、緊急傷病處理、衛生諮詢、**支援**健康教學；2026-09 修正新增主管機關**協助備置生理用品、推動月經教育**
- 常見體格缺點（第 11 條）：**視力不良、聽力不良、齲齒、寄生蟲病、肝炎、脊椎彎曲、運動傷害、肥胖、營養不良**
- 學生健康檢查：委託醫療機構；**身高、體重、視力可由學校護理人員**做；結果 **1 個月內**通知
- 健康體適能四要素：**身體組成、心肺耐力、肌力與肌耐力、柔軟度**；最重要是**心肺耐力**
- 高中以下**全面禁菸、電子煙及新型態菸品**（第 24 條）

### 國考常考點 {#exam-points}

- 45 班國小 → **護理人員 2 名、營養師 1 名**
- 「我國尚未通過學校衛生法」錯（2002 年公布）
- 直轄市學校衛生由**教育局**負責
- 健康中心**不是**健康教學的主要場所（那是教室）
- 糖尿病、氣喘屬第 12 條「重大傷病加強照顧」，不是第 11 條「體格缺點」
- 學校護理師優先處理：**當日腸病毒請假 10 人**（傳染病群聚）＞視力不良率、過重率、齲齒率
- 學生經痛求助時說明青春期變化 → **非例行性**教學
- 健康檢查早期發現並矯治 → 五級中的第三級「**早期診斷適當治療**」（屬次段預防）
- 「校園安全監測」不是學校護理師的主要角色

## 學校衛生行政 {#administration}

| 層級 | 單位 |
|---|---|
| 中央 | **教育部**（綜合規劃司為內部單位，學校衛生業務由學生事務及特殊教育司主管，司名待核對） |
| 直轄市 | 直轄市政府**教育局** |
| 縣（市） | 縣（市）政府教育處 |
| 學校 | 學務處**衛生保健組**；學校衛生委員會 |

- 學校衛生法 2002 年公布施行（106-1 題）；涉及衛生、環保、社政業務時，由教育主管機關**會同**相關機關辦理（第 2 條）
- 各級主管機關設**學校衛生委員會**（醫藥、公衛、營養、心理健康專家），提供政策、計畫、教育、保健服務、環境衛生的諮詢（第 5 條）

| 條文 | 內容 |
|---|---|
| 第 6 條 | 學校指定單位或專責人員規劃推動；設**健康中心**；主管機關協助備置**生理用品**、推動**月經教育**（2026-09-23 新增） |
| 第 7 條 | 高中以下 **< 40 班護理人員 1 人、≥ 40 班至少 2 人**；專科以上**得比照** |
| 第 8 條 | 建立學生健康管理制度、定期健康檢查 |
| 第 11 條 | 常見**體格缺點或疾病**加強預防與矯治（見下表） |
| 第 12 條 | 心臟病、**氣喘**、癲癇、**糖尿病**、血友病、癌症、精神疾病、罕見疾病等重大傷病或身心障礙學生，**加強輔導照顧**，必要時調整課業與活動 |
| 第 13 條 | 學生或教職員工罹患傳染病，會同衛生、環保機關防疫；必要時禁止到校；主管機關得命**停課** |
| 第 14 條 | 配合衛生機關辦理預防接種；**國小新生**入學前未完成接種，學校通知衛生機關補接種 |
| 第 23、23-1 條 | 學校午餐由**營養師**督導；高中以下 **≥ 40 班至少置營養師 1 人**；應提供蔬食選擇 |
| 第 24 條 | 高中以下**全面禁菸、電子煙及新型態菸品**；不得供售菸品、類菸品、酒、檳榔 |

- 110-2 題：「專科以上學校**應**定期檢測學生健康體適能」錯（考選部答案 A；條文出處待核對）

## 學校衛生工作模式 {#models}

- **傳統學校衛生計畫**三大內容：**健康教學、健康服務、健康環境**
   1. 評值計畫成果要用**結果指標**：營養午餐計畫要減少過重學生 → **過重盛行率**；滿意度、成本、困難不是成果（113-1 題）
   2. 計畫流程：統計健檢結果界定需求 → 設定總目標與具體目標 → 調查人力物力財力資源 → 執行 → **評值**（評值在活動之後，107-1 題）
- **健康促進學校**(WHO)六大範疇：**學校衛生政策、學校物質環境、學校社會環境、社區關係、個人健康技能（健康教學與活動）、健康服務**；「加強藥物濫用管理」不是範疇名稱（106-2 補考題）；渥太華五大行動綱領見 [[health-promotion]]

::questions{ids="113-1_PC_044,107-1_PC_075,106-2_makeup_PC_073"}

## 健康服務 {#health-services}

### 健康中心 {#health-center}

- 功能：**健康檢查與管理**、**緊急傷病處理**、**衛生諮詢**、**支援**健康教學；健康教學主要場所是**教室**（105-2 題）
- 校內緊急傷病：學童突然倒下 → 叫（確認意識與呼吸）、叫（求救、指定人打 119、拿 AED）、**CAB**；單人按壓與吹氣 **30 : 2**，不是 15 : 1（106-1 題）；完整急救流程見 [[cpr]]

### 學生健康檢查 {#health-exam}

| 規定 | 內容（學生健康檢查實施辦法） |
|---|---|
| 誰做 | **委託醫院、診所或醫師公會**；**身高、體重、視力**可由學校**護理人員**做，教師協助（第 3 條） |
| 新生 | 入學時做**健康基本資料調查**（家族史、個人病史、特殊疾病、預防接種紀錄）（第 4 條） |
| 通知 | 檢查後 **1 個月內**通知學生及家長（成年學生須本人同意才通知家長）（第 6 條） |
| 異常 | 健康指導、轉介複查與矯治並追蹤；傳染病依衛生法令；**特殊疾病學生做個案管理**（第 7 條） |
| 隱私部位 | 胸腹部、泌尿生殖檢查需學生與家長同意；不同意在校檢查，**家長自行帶去醫療院所並交回報告**（111-1 題） |
| 保密 | 健康資料要保密 |

- 例行檢查頻率：國小每學期量**身高、體重、視力**；全身健康檢查在入學年級（國小一、四年級，國中、高中一年級，依基準表；細節待核對附表）
- 111-1 題 D「氣喘需缺點矯治」錯：氣喘是第 12 條重大傷病，不是體格缺點
- 健康檢查早期發現與矯治 → 三段五級的第三級「**早期診斷、適當治療**」（107-1 題）

### 常見體格缺點 {#physical-defects}

| 學校衛生法第 11 條（體格缺點或疾病） | 第 12 條（重大傷病，加強照顧） |
|---|---|
| **視力不良**、聽力不良、**齲齒**、寄生蟲病、肝炎、**脊椎彎曲**、**運動傷害**、**肥胖**、營養不良 | 心臟病、**氣喘**、癲癇、**糖尿病**、血友病、癌症、精神疾病、罕見疾病、身心障礙 |

- 114-2 題：①視力不良 ③脊椎彎曲 ④肥胖 ⑥運動傷害；糖尿病、氣喘不是
- 優先順序：**急性傳染病群聚**（當日腸病毒請假 10 人）要立即通報與防疫，先於慢性的視力、體位、齲齒問題（110-1 題）；腸病毒見 [[childhood-infectious-diseases#enteroviruses]]
- 學生血脂異常的衛教見 [[older-adult-chronic-disease#lifestyle]]；兒童肥胖與口腔見 [[maternal-child-health#child]]

### 視力保健 {#vision}

- 閱讀距離 **30–40 公分**（不是 20）
- 用眼 **30 分鐘休息 10 分鐘**（109-2 題）；看電視距離約畫面對角線 **6–8 倍**、畫面略低於視線（15 度以下）
- 書桌光線從**寫字手的對側**來（右撇子從左前方，所以「最好由左前方」不是一律正確）；照度足夠即可，不是越亮越好；教室照度標準見 [[environmental-food-hygiene#school-environment]]
- 收集視力不良資料的目的：了解盛行率、**調整座位**、**個案管理**；不是校園安全教育（109-1 題）
- 110-1 題答 B（30–40 公分）；電視距離與光源方向的數字依國考詳解，待核對

### 健康體適能 {#fitness}

- 四要素：**身體組成、心肺耐力、肌力與肌耐力、柔軟度**（113-3 題）
- 最重要是**心肺耐力**（112-1 題）
- 檢測項目：身體組成用 BMI；坐姿體前彎（柔軟度）；仰臥捲腹（肌耐力）；**立定跳遠**評估**瞬發力**（不是心肺）；心肺耐力用跑走（高中職**男 1,600 公尺、女 800 公尺**，國考詳解，待核對教育部體適能網）

::questions{ids="113-3_PC_044,112-1_PC_071"}

## 健康教學與護理師角色 {#roles}

- **例行性**教學：朝會宣導、與健康教育老師合教、家長講座；**非例行性（隨機）**教學：學生來健康中心求助時就地衛教（經痛時說明青春期變化）（108-2 題）
- 學校護理師角色：學生健康檢查與管理、**緊急傷病處理**、**教職員工生保健**、健康教學與諮詢、傳染病防治、環境衛生監測；**校園安全監測**屬總務與全體教職員，不是護理師主要角色（113-3 題）
- **Wold(1981)** 學校護理五個系統性概念：**公共衛生、適應功能、互助性人際關係、工具、系統化過程**；沒有「全球健康」（107-2 題）
- 健康促進活動內容（施行細則第 14 條）：健康體適能、健康飲食、壓力調適、性教育、**菸害防制**、藥物濫用防制、事故傷害防制、視力保健、口腔保健、體重控制、正確就醫用藥

::questions{ids="108-2_PC_054,113-3_PC_036,107-2_PC_073"}

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 學校衛生主管機關是衛福部 | **教育部** | 學校衛生法第 2 條 |
| 我國尚未通過學校衛生法 | 2002 年已公布 | |
| 45 班護理人員 1 名 | **2 名**（≥ 40 班） | 第 7 條 |
| 健康中心是健康教學主要場所 | 教室 | |
| 糖尿病、氣喘是體格缺點 | 重大傷病（第 12 條） | |
| 健檢結果 3 個月內通知 | **1 個月**內 | 健檢辦法第 6 條 |
| 護理人員每學期檢查口腔 | 身高、體重、視力 | |
| 活動前準備包括評值 | 評值在活動後 | |
| 用滿意度評值減重計畫成果 | 用過重盛行率 | 結果指標 |
| 立定跳遠評估心肺功能 | 瞬發力 | |
| 閱讀距離 20 公分 | 30–40 公分 | |
| 照度越亮越好 | 足夠即可 | |
| CPR 15 : 1 | **30 : 2** | |
