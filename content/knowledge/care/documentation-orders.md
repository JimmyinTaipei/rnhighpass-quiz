**記錄**把病人的狀況、治療與反應如實寫下，讓醫療團隊互相溝通，也是法律文件。國考集中在**記錄原則(哪一句違反時效性、準確性)**、**時間欄與更正方法**、**SOAPIE(subjective, objective, assessment, plan, implementation, evaluation)與 DART(data, action, response, teaching)各項放什麼**、**哪些情況要報告醫師**、**TPR(temperature, pulse, respiration)單的記錄方式**，以及**醫囑種類(S.O.S.、p.r.n.、order renew、口頭醫囑)**。給藥醫囑與給藥縮寫見 [[medication-administration-principles#orders]]，病歷法規與保存年限見 [[medical-records-consent]]，電子病歷與護理資訊系統見 [[nursing-information-systems]]，主客觀資料與護理過程見 [[nursing-process]]

## 重點摘要 {#summary}

- 記錄目的：**溝通(最主要)**、評估病人、**法律證明文件**、調查研究、教學、稽核、醫療費用與保險證明
- 原則：**正確性、完整性、簡潔明瞭、統一格式、時效性、組織性**
- **時間欄寫「執行時間」**，不是記錄時間；執行完立刻記，不拖延也不提早
- 寫錯：畫**兩條線**、上面註明 **error** 並簽名，不可塗改、擦掉或用修正液；電子病歷修改要電子簽章、**保留原紀錄**
- 電子病歷完成後 **24 小時內**用醫事人員憑證 IC 卡簽章
- 記錄**事實**：寫「拒絕吞藥、把藥吐出」，不寫「不合作」；傷口寫部位、大小、性狀
- 措施後症狀仍未緩解、病況改變、意外事件、情緒特別不穩 → **記錄並報告**
- 記錄方法：傳統式(資料來源導向)、**以問題為導向(SOAPIER)**、**焦點記錄(DART)**
- **S.O.S.**：臨時醫囑，需要時給**一次**，**12 小時**沒用就失效；**p.r.n.**：**長期醫囑**，依間隔需要時給、可重複
- **order renew**：以上的醫囑**全部無效**，以下才有效
- 口頭／電話醫囑：寫下、**複誦**確認，最好**兩位護理師**在場；**護生不能接受**；事後盡速補開(醫療法：24 小時內)

### 國考常考點 {#exam-points}

- 痰液顏色改變要記錄，最主要目的是**溝通**(107-2_FA_011)
- 主觀資料不必特別註明「病人主訴」，家屬提供的才要註明是誰說的；「應標註病人主述以區辨非家屬」錯(115-1_FA_006)
- 護理師觀察到的行為、生命徵象、**身體評估資料**都是**客觀**資料；家屬的主訴是主觀(115-2_FA_005)
- 正確書寫：包含**主客觀資料**、**精確記載數據**；不可用自己習慣的方式、要依時間順序(107-2_FA_008)；具體的：「**左髖骨破皮傷口 1×2 cm，乾燥無滲液**」(112-1_FA_008)、「**足跟壓瘡 4×5 cm²，無紅腫滲出液**」(109-1_FA_020)
- 「10:00 協助翻身發現腳跟破皮，給予換藥」沒寫大小與性狀 → 違反**準確性**(111-1_FA_009)；白班下班前才補記上午的事 → 違反**時效性**(109-1_FA_006)
- 記錄注意：**連續書寫、不留白、不另起一行**；時間欄是執行時間；少用英文縮寫；病人拒絕的治療也要記(105-1_FA_014)
- 電子病歷錯了「可刪除不留原紀錄」錯(112-2_FA_010)；電子簽章「48 小時內」錯，課本是 **24 小時**(108-2_FA_021)；11 AM 開始灌腸到 11:30 結束，時間欄寫 **11 AM**
- 急救紀錄由**當班主護**撰寫，急救失敗也要寫過程(113-3_FA_007)
- 只要記錄不必報告：**體溫 37.6 ℃ 經衛教能多喝水**(110-2_FA_002)；傷口泛紅、跌倒、病人衝突都要報告
- SOAP：「A」寫健康問題與原因(手術後傷口疼痛)，寫「傷口感染引發疼痛」是錯的推論(108-1_FA_013)；「E」＝**疼痛由 5 分降為 3 分**(107-2_FA_014)；給 Demerol 記在「**I**」(106-2_makeup_FA_015)；「有吞嚥反射但易嗆，需持續注意」屬**評值**(105-1_FA_011)
- DART：病人主訴疼痛、臉色蒼白＝**D**(105-2_FA_014)；給 pethidine＝**A**(108-2_FA_025)；DART 不含**護理目標**(111-2_FA_013)；SOAPIE 的「A」**不是**對應 DART 的「T」(109-2_FA_007)
- 行為過程紀錄**不是**問題導向的記錄法(105-2_FA_015)
- 生命徵象記錄表**不寫病況進展**(109-2_FA_006)；**operated at 9:00** 寫在 40 ℃ 以上欄位，不在 TPR 以下欄位(109-1_FA_004)
- 病歷保存：106-2 補考選項沒有正確答案，**送分**(現行至少 7 年)(106-2_makeup_FA_009)
- 醫囑：**order renew** 代表之前的醫囑無效(110-2_FA_021、107-1_FA_008)；p.r.n. **不是**臨時醫囑、不是只給一次(108-1_FA_014)；S.O.S. 是臨時醫囑、需要時給一次、12 小時內有效、執行後要記錄(105-1_FA_027)；S.O.S. 12 小時內已給過一次，**不能再給**(106-1_FA_013)；口頭醫囑最好**兩位護理師在場**(109-2_FA_005)；護生不可接受口頭醫囑；長期醫囑沒有 7 日期限
- 縮寫：**R/O＝疑似**(110-1_FA_014)、**M.B.D.＝許可出院**(106-2_makeup_FA_012)、**A.A.D.＝自動出院**(106-1_FA_014)

## 記錄的目的 {#purposes}

| 目的 | 說明 |
|---|---|
| **溝通** | **最主要**；團隊閱讀彼此紀錄、交班，減少重複詢問與干擾病人 |
| 評估病人 | 提供確立問題與擬計畫的資料 |
| **法律證明文件** | 醫療糾紛、刑案、保險、遺囑查驗的證據；完整紀錄是證明醫護無過失的依據 |
| 調查研究 | 出生、死亡、疾病統計 |
| 教學 | 實習生與新進人員學習 |
| 稽核 | 評鑑、人事考核 |
| 費用 | 健保申報、保險理賠、職災認定 |

- 來源：實用基本護理學上冊 p.125–126

## 記錄的原則 {#principles}

| 原則 | 重點 |
|---|---|
| **正確性** | 真實、明確、準確；基本資料盡速填；**排除主觀與偏見**(寫「拒絕吞藥並吐出」，不寫「不合作」)；**記錄者就是執行者**，寫完立刻簽職稱全名；實習生簽 S.N. 後由護理師或教師加簽 |
| **完整性** | 全人評估、**主客觀資料**都要有；目標與措施具體可行、不要太理想化；評值要明確；**病人拒絕的治療要記錄原因** |
| 簡潔明瞭 | 不含糊、不過度修飾；避免中英夾雜與自創縮寫(公認縮寫除外) |
| 統一格式 | 全院一致；護理記錄用敘述式或 SOAP、DART |
| **時效性** | **執行後立刻記錄**，不拖延也不提早 |
| **組織性** | **依時間先後順序** |

- 主觀資料直接寫內容即可，不必冠上「病人主訴」；**家屬或親友提供的才寫出是誰說的**(如「案母說：…」)
- 判斷違反哪個原則
   1. 只寫「發現腳跟破皮」、沒寫大小與性狀 → **準確性**
   2. 下班前才把上午的生命徵象與處置一次補記 → **時效性**
   3. 「病人多坐臥休息、進食量少」「病人不配合」 → 不夠具體或有主觀判斷
- 來源：同書 p.126–129

::questions{ids="115-1_FA_006,115-2_FA_005,107-2_FA_008,112-1_FA_008,109-1_FA_020,111-1_FA_009,109-1_FA_006"}

### 書寫與更正 {#corrections}

1. 筆：依規定用黑、藍或紅色**油性筆**；不用鉛筆、擦擦筆、水性筆
2. **連續書寫、不留空白**；留空白要畫斜線；**不可另起一行**
3. **時間欄寫執行時間**(例：11 AM 開始灌腸、11:30 結束，時間寫 11 AM)
4. 寫事實，不寫「我認為…」
5. 寫錯：在錯誤處畫**兩條線**，上方用紅筆註明 **error** 並簽名；**不可塗抹、擦掉、用修正液**(醫療法第 68 條：刪改畫線去除、不得塗燬，增刪處簽名並註明日期)
6. 電子病歷
   1. 記錄後 **24 小時內**用**醫事人員憑證 IC 卡**完成電子簽章，簽章後不能隨意更改
   2. 修改要用 IC 卡簽署並記錄時間，**原紀錄要保留**
7. 急救紀錄由**當班主護**負責，過程、時間都要寫，轉單位或急救失敗也不能省略
- 來源：同書 p.127–129；醫療法第 68 條

::questions{ids="105-1_FA_014,112-2_FA_010,108-2_FA_021,113-3_FA_007"}

### 要記錄也要報告的情況 {#report}

1. 措施後**仍無法緩解**的症狀
2. 疾病症狀、**合併症先兆**、病況或**意識改變**
3. 治療護理後改善或**惡化**的症狀
4. 情緒特別不穩、過度沮喪
5. **意外事件**(如跌倒)經過、病人外出與返院時間
- 只需記錄的例子：低燒病人經衛教後能多喝水(已處理且穩定)
- 需報告的例子：糖尿病足換藥後傷口周圍明顯泛紅、姿位性低血壓病人跌倒、病人間衝突
- 來源：同書 p.128

## 記錄方法 {#methods}

### 三種方法比較 {#methods-compare}

| 方法 | 特點 | 內容 |
|---|---|---|
| **傳統式**(資料來源導向，SOR, source-oriented recording) | 依資料來源分開、依時間描述；較主觀、易重複、較無組織 | **系統記錄法**(依系統的評估表)、**敘述記錄法**、**行為過程記錄**(改良的敘述法，記錄護病間語言與非語言互動，用於發現問題與護理師自我分析) |
| **以問題為導向**(POR, problem-oriented recording) | 1964 年 Weed 提出(醫療用 POMR, problem-oriented medical recording)，1978 年 Henderson 推薦護理用 | 基本資料、問題列表、初步計畫、**病情進展記錄(SOAPIER)**、出院摘要 |
| **護理焦點記錄**(focus charting) | 以病人為中心、一個焦點一個健康問題；易懂、彈性大 | **D.A.R.T.** |

- 行為過程記錄屬於**傳統式**，不是問題導向
- 來源：同書 p.129–132、表 4-1

::questions{ids="105-2_FA_015"}

### SOAPIER {#soapier}

| 項目 | 放什麼 | 例(腹腔鏡膽囊切除術後) |
|---|---|---|
| **S** 主觀資料 | 病人或家屬說的 | 「傷口好痛，痛到睡不著，7 分」 |
| **O** 客觀資料 | 觀察、測量、檢驗 | 術後第一天、皺眉、生命徵象、傷口紗布無滲液 |
| **A** 評估 | 分析主客觀資料後**確立問題與原因** | 急性疼痛／手術傷口 |
| **P** 計畫 | 目標與擬訂的措施 | 舒適臥位、教導支托傷口、必要時依醫囑給止痛 |
| **I** 執行 | **實際做了什麼**，含依醫囑給藥 | Demerol 50 mg IM |
| **E** 評值 | 執行後的**成效** | 疼痛由 5 分降到 3 分；「有吞嚥反射但易嗆，需持續注意餵食」 |
| **R** 修改或重新評估 | 未解決時找原因、修計畫 | — |

- 「A」寫的是根據資料確立的護理問題；資料裡沒有證據的推論(例：「傷口**感染**引發疼痛」)是錯的
- 來源：同書表 4-1 p.131、範例 p.133

::questions{ids="108-1_FA_013,107-2_FA_014,106-2_makeup_FA_015,105-1_FA_011"}

### 焦點記錄 DART {#dart}

| 項目 | 放什麼 | 對應 SOAPIE |
|---|---|---|
| **D** 資料(data) | 與焦點有關的**主觀與客觀資料** | **S＋O**(含 A 的問題，寫在「焦點」欄) |
| **A** 護理行動(action) | 立即的護理活動或計畫，**含依醫囑給藥** | **P＋I** |
| **R** 反應(response) | 病人接受照護後的結果 | **E** |
| **T** 護理指導(teaching) | 與問題有關的衛教 | (屬措施的一部分) |

- 焦點：病人最擔心的事、病況明顯改變、**護理診斷／健康問題**、重要事件(術後返室、放中心導管)；**不用醫學診斷**當焦點
- 每次不一定四項都有：常先寫 D、A、T，**R 到下一個時間點**才寫
- DART **沒有「護理目標」**這一項
- 來源：同書 p.130–134、表 4-2

## 病歷內容 {#record-contents}

### 生命徵象記錄表(TPR 單) {#tpr-sheet}

1. 基本資料用黑或藍筆；**手術、生產日數用紅筆**
2. TPR 依 T → P → R 順序；重疊時用空心圓圈起；與前次用實線連成曲線；**不同符號不連線**
3. 發燒處理後下降的體溫畫**紅色空心圓**，用紅色虛線連到原體溫
4. **特殊處置**(如溫水拭浴)以藍筆寫在 35–37 ℃ 欄位
5. **40 ℃ 以上欄位用紅筆**寫：**入院**、**出院**(discharged、M.B.D.、A.A.D.)、**轉出**、**手術時間**(operation、sent to OR)、**生產**、**死亡**
6. TPR 以下欄位：血壓、體重、**大便次數**(灌腸後解 1 次寫 **1/E**)、輸出入量、疼痛指數(黑色空心圓)
7. **大便**：統計前一天早上 8 點到今天早上 8 點，記在前一天；**輸出入量**：大夜班統計前一天 7 點到今天 7 點，記在前一天
8. 身高體重：入院量一次，之後每週一次；腹水、心衰竭依醫囑每天量
9. 手術當天紅筆寫 **OP day**，次日起寫術後第 1、2、3 天
10. 生命徵象記錄表**不寫病況進展**(病況寫在護理記錄與病程記錄)
- 來源：同書 p.137–141

### 其他單張與病歷保管 {#other-records}

1. 醫囑記錄、會診記錄、給藥記錄、護理評估(入院評估、每日評估、跌倒與壓力性損傷評估)、**護理記錄**(護理師的法定業務)、檢驗報告、住院許可證、出院摘要
2. 住院期間：病歷放護理站，**不放病人單位**；行動護理車推進病房要關閉病人畫面
3. 病人或家屬問病情、預後 → **請主治醫師說明**，護理師不依病歷直接解答
4. 保存(醫療法第 70 條)：**至少 7 年**；**未成年者到成年後 7 年**；**人體試驗永久**；電子病歷相同；護理紀錄由執業機構保存 7 年(護理人員法第 25 條)
5. 病歷是**醫院的財產**，由醫院保管
6. 細節與成年年齡見 [[medical-records-consent#retention]]
- 來源：同書 p.141–150

## 醫囑 {#orders}

- 執行**非獨立性**護理工作前，必須先核對醫囑；看不懂或有疑問**不可猜**，先向開立醫師確認
- 給藥醫囑的完整內容、St.、q.d. 等給藥縮寫與 p.r.n. 判讀細節見 [[medication-administration-principles#orders]]
- 來源：同書 p.141、159–160

### 醫囑的種類 {#order-types}

| 種類 | 定義 | 處理 |
|---|---|---|
| **長期醫囑**(standing order) | 自開立日起持續執行，**直到停止(D.C.)** | 紙本謄寫到 Kardex 與給藥單後打「/」並簽名；執行後再打勾、記時間簽名；**沒有 7 日期限** |
| **p.r.n.** | **屬長期醫囑**；需要時給，醫師要註明**間隔**，可重複 | 護理師判斷需要才給；**每次給後記錄用藥情形並評值** |
| **臨時醫囑**(stat order) | 開立後**立即執行、只執行一次** | 紙本先打半勾「\」，執行後完成全勾「/」並簽名 |
| **S.O.S.** | **屬臨時醫囑**；如有需要給**一次** | **12 小時內**未執行就失效；**已給過一次也失效**，再需要要重開 |

- 例：「Steam inhalation 15 min S.O.S.」：12 小時內有需要可給 15 分鐘蒸氣一次；12 小時後才出現需要，要請醫師重開；12 小時內已給過一次又有需要，**不能再給**
- 來源：同書 p.159–160

::questions{ids="105-1_FA_027,106-1_FA_013,108-1_FA_014"}

### 口頭、電話醫囑與 order renew {#verbal-orders}

1. 口頭或電話醫囑只在**緊急**時(急救、立即危及生命)
   1. **寫下**內容、**複誦**一次，醫師確認後才執行
   2. 最好**兩位護理師**在場確認
   3. 事後**盡速請醫師補開**；護理記錄寫醫師姓名、時間、方式與內容；醫療法第 68 條：情況急迫可先口頭，**24 小時內**完成書面
   4. **醫護實習生不能接受**口頭或電話醫囑；「新進護理師三個月後才可接」不是課本的規定
2. **order renew**(醫囑更新、醫囑重整)：**以上的醫囑都無效**，**以下的才有效**；多個 renew 時以最新的為準；之前的長期醫囑視同停止
3. 不是所有護理措施都需要醫囑：獨立性護理活動(衛教、翻身、擺位)不需醫囑
- 來源：同書 p.160；醫療法第 68 條

## 交班報告 {#handoff}

1. 方式：一對一、團體、**床邊交班**(可看病人安全、幫接班者與病人建立關係，注意隱私)；電子化交班或紙本 **Kardex**
2. 內容
   1. 住院病人：基本資料、入院時間、目前病情、生命徵象、**管路**(名稱、位置、到期日)、輸液種類與速度、治療護理與反應
   2. 當天手術、生產、特殊檢查：名稱、時間、病人情況
   3. 次日手術或檢查：名稱、時間、準備情形
   4. 特殊情形
3. **ISBAR**(醫策會 2010)：**I** 介紹(自我介紹、確認病人)、**S** 情境(現況與改變)、**B** 背景(病史、用藥、治療)、**A** 評估(最近生命徵象、檢查、管路、待追蹤)、**R** 建議(後續處理、預防危急狀況)
4. 交班優先報告的是**會影響接班照護的近期處置**(例：早上 9 點打過止痛藥)，而不是家族史或已痊癒的舊病史
- 來源：同書 p.161–162、課後題 p.164

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 |
|---|---|
| 時間欄寫記錄的時間 | 寫執行時間 |
| 寫錯用修正液或擦掉 | 畫線、註明 error、簽名 |
| 電子病歷錯了直接刪除 | 修改要簽章並保留原紀錄 |
| 電子簽章 48 小時內 | 24 小時內 |
| 病人拒絕的治療不必記錄 | 要記錄原因 |
| 每項記錄另起一行 | 連續書寫、不留白 |
| 寫「病人不合作」 | 寫出具體行為 |
| 主訴都要冠「病人主訴」 | 家屬說的才註明是誰說的 |
| SOAP 的 A 寫推論出的醫學原因 | 寫有資料支持的護理問題與原因 |
| 給藥寫在 SOAPIE 的 P | 寫在 I；DART 寫在 A |
| DART 有目標 | DART 是資料、行動、反應、指導 |
| 行為過程紀錄是問題導向 | 是傳統式(敘述法的改良) |
| p.r.n. 是臨時醫囑、只給一次 | 長期醫囑，依間隔可重複 |
| S.O.S. 12 小時內可給多次 | 只給一次 |
| order renew 以下的醫囑無效 | 以上的無效 |
| 護生緊急時可接口頭醫囑 | 不行 |
| 長期醫囑 7 日失效 | 到 D.C. 才停 |
| R/O＝排除 | R/O＝疑似 |
