**安寧緩和療護**是為**威脅生命疾病**的病人**與家屬**提供的全人照顧，目標是**減輕身、心、靈的痛苦**、提升生活品質，而**不是**等到最後幾天才開始，也不是「放棄治療」。臨終照護的重點是**症狀控制與舒適**、**尊重病人的意願**、**陪伴家屬道別與哀傷**。本頁整合基本護理、內外科與兒科的臨終照護考點。疼痛見 [[pain-management#end-of-life]]，鴉片類見 [[opioids]]。

## 安寧緩和療護的概念 {#palliative-care}

- 定義(安寧緩和醫療條例)：為**減輕或免除末期病人之生理、心理及靈性痛苦**，施予緩解性、支持性之醫療照護，以增進其生活品質。
- **四全照顧**：**全人**(身心靈)、**全家**、**全隊**(醫師、護理、社工、心理、宗教、志工等)、**全程**(含家屬的哀傷輔導)；加上**全社區**稱「五全」。
- 照護模式：**安寧住院**、**安寧居家**、**安寧共同照護**(安寧團隊到一般病房照會)、社區安寧。
- **適用對象**：**癌症末期**與**非癌症末期**。健保給付的非癌症末期包括：**失智症**(老年期及初老期器質性精神病態)、其他大腦變質、**心臟衰竭**、慢性阻塞性肺病、其他肺部疾病、**慢性肝病及肝硬化**、**急性與慢性腎衰竭**、**運動神經元疾病**(漸凍症)。**思覺失調症**、**大腸憩室炎**等不是末期疾病，不符合。
- 仍可以接受緩解症狀的治療(例：**骨轉移止痛的放療**、抽腹水)；也**不一定要住院**。

## 腦死判定 {#brain-death}

依《腦死判定準則》：

- **先決條件**：
  1. **深度昏迷**，昏迷指數 **≤ 5**，且**必須依賴人工呼吸器**維持呼吸；
  2. 昏迷**原因已經確定**；
  3. 遭受**無法復原的腦部結構損壞**。
- **排除**可逆的原因：**藥物中毒**、**低體溫**(< 35°C)、**代謝或內分泌障礙**、休克等(**可逆性昏迷不適用**)。
- 判定：由合格醫師進行**兩次**程序相同的**腦幹功能測試**：
  - **腦幹反射**全部消失：瞳孔對光反射、角膜反射、**頭眼反射**(洋娃娃眼)、前庭動眼反射、作嘔與咳嗽反射
  - **無自行呼吸**(無呼吸測試)

## 瀕死的生理變化 {#physical-changes}

| 系統 | 變化 | 護理 |
|---|---|---|
| **感官** | 視力模糊、眼神渙散、**瞳孔放大**、眼球固定；觸覺與痛覺變遲鈍，但**疼痛不會因此消失**；**聽覺是最後消失的知覺** | 在床旁**用正常音量、清楚緩慢**地說話，**不要耳語**或在病人面前討論病情；鼓勵家屬**說話與觸摸**；室內保持**柔和光線**，不需刻意昏暗；眼睛閉不上時以**生理食鹽水紗布覆蓋** |
| **呼吸** | **陳施氏呼吸**(最常見)、**喟嘆式呼吸**、**張口呼吸**、呼吸由深變淺；**臨終嘎嘎音** | 見下方臨終嘎嘎音；呼吸困難可用**嗎啡**、電扇、半坐臥 |
| **循環** | 心跳**快而弱**、脈搏**細弱**(絲脈)、**血壓下降**；**四肢末端先冰冷**(由末梢往身體中心)、**發紺、斑駁**；**盜汗**但周邊血管收縮(「感覺很熱，身體卻很冰」) | 脈搏以**頸動脈**最容易測得，**心尖搏動最後消失**；以**被子保暖**(熱水袋等要特別注意溫度，避免燙傷)；**不需頻繁量血壓** |
| **肌肉與臉部** | 肌肉張力下降、下顎下垂；**希氏面容**(眼窩凹陷、鼻尖尖細、臉色灰白) | 翻身與擺位以舒適為原則，維持皮膚清潔乾燥 |
| **腸胃** | 食慾與進食量減少、**吞嚥困難**、腸蠕動**變慢**(便秘、腹脹)，**括約肌鬆弛** → 大小便失禁 | **不勉強進食**；不再強調營養；便秘以舒適為主(不插肛管)；會陰清潔，肛周皮膚可用**氧化鋅** |
| **泌尿** | **尿量減少**、濃縮；可能尿滯留或失禁 | 必要時導尿並預防感染 |
| **神經精神** | 嗜睡、意識混亂、**譫妄躁動**(臨終躁動)、**看到或聽到已過世的親友** | 找出可逆原因(疼痛、尿滯留、便秘、缺氧)；床欄加護墊防撞傷，**不用約束**；必要時與醫師討論**鎮靜藥** |

### 臨終嘎嘎音 {#death-rattle}

- 原因：**吞嚥與咳嗽反射消失**，口咽的分泌物積在喉部，隨呼吸發出聲音；**不是「喉嚨有痰要抽」**。病人意識多已不清，通常**不覺得痛苦**，但家屬會很擔心。
- 處置：
  - **側臥**或**半坐臥、頭側一邊**，讓分泌物流出；
  - 與醫師討論**減少輸液量**；
  - 依醫囑給**抗膽鹼藥**(hyoscine／scopolamine)減少分泌；
  - **口腔護理**；
  - **避免深部抽痰**(刺激、無效，只在口腔前端輕抽)，也**不需要叩擊或提高氧氣濃度**、不需要送急診；
  - 向家屬**解釋這是正常的瀕死現象**，鼓勵把握時間陪伴。

### 最後幾天的照護原則 {#last-days}

- **停止或減少非必要的處置與監測**：每天抽血、每 10 分鐘量血壓等，要與醫師**討論利弊與對病人的意義**，不是機械式執行。
- **簡化藥物**，保留**止痛、止喘、鎮靜、止吐**等症狀控制藥；無法口服時改**皮下**給藥，而不是堅持口服。
- **疼痛**：持續評估並**按時**給止痛藥，**不因怕成癮而少給**(見 [[pain-management#end-of-life]])。
- **營養與水分**：臨終時食慾下降是正常的；**不勉強進食**、不為了家屬安心而增加點滴或插管灌食(可能加重水腫、腹水、分泌物)；用**海綿棒沾水或茶水**濕潤口腔，**尊重病人選擇的進食方式**(例：病人不願插鼻胃管，就提供少量多餐的流質)。
- **難以控制的症狀**(躁動、呼吸困難)：可與家屬**共同討論照護目標**，說明**緩和鎮靜**的目的與可能效應後再決定；緩和鎮靜是為了緩解痛苦，**不是**安樂死或協助自殺。
- 生命以「日」計時：**引導家屬道別並陪伴在側**；不要在病床旁討論後事，也不需推急救車到床邊。

## 心理反應與照護 {#psychological}

### Kübler-Ross 瀕死心理五階段 {#kubler-ross}

| 階段 | 病人的表現(例) | 護理 |
|---|---|---|
| **否認與隔離** | 「不可能，一定是弄錯了」；拒絕討論 | 否認是**暫時的防衛機轉**：**給予時間**、不強迫面對現實、傾聽 |
| **憤怒** | 「**為什麼是我？**」對家人、醫護發脾氣 | **接納**憤怒是正常反應，不要以牙還牙，也不要避開不理；傾聽需要 |
| **討價還價(磋商)** | 「讓我活到女兒結婚」、**放生積功德**、向神明許願 | 傾聽、了解心願，協助完成可行的願望 |
| **憂鬱** | 「我快要死了，**再也看不到**女兒了」；哭泣、退縮 | **陪伴**、允許哭泣、鼓勵說出害怕；**移除危險物品**；不要說「別難過」「病情沒那麼糟」 |
| **接受** | 平靜，關心如何安排與照顧自己 | 仍要**持續陪伴與支持**，尊重需要安靜的時刻 |

- **不一定依序**出現，可能反覆、跳過，**也可能停留在否認期直到死亡**；不是每個人最後都能到接受期。
- 這些反應**也適用於家屬**。
- 簽了意願書的病人哭著說「請救救我」→ 先**同理想活下去的渴望**、了解他的想法，並評估身心靈與社會需求；需要時再討論是否撤回意願書，而不是直接判定為否認期。
- 剛得知罹患末期癌症時：先**陪伴**(輕握手、拍肩)，不是立刻給一堆資訊或空泛的保證。

### 靈性照顧與生命回顧 {#spiritual}

- 病人問「如果神愛我，為何這樣對我？」→ **接納其哀傷為正常反應**、傾聽，不急著說教或保證。
- **生命回顧**：在**舒適護理時**自然引導病人回想重要的人與事，找到生命的意義；可以**邀家屬一起**；出現感傷情緒時**陪伴而不轉移話題**；目的不是評斷一生成敗。
- 協助完成**四道人生**：**道謝、道愛、道歉、道別**。
- 尊重宗教信仰，依需要轉介宗教師。

### 其他照護 {#other-psych}

- 鄰床病人過世後害怕到睡不著 → 最優先**評估病人對死亡的感受**。
- 以**觸摸**表達關心；可以與病人討論後事與心願，不必迴避。
- 瀕死期的護理重點是**評估病人面對死亡的調適能力**、維持開放溝通。

## 家屬的哀傷照護 {#grief}

- **預期性哀傷**：病人還在世時，病人與家屬**已開始經驗哀傷**，可以**有時間道別、完成心願**、逐漸接受死亡；但**不能避免**死亡發生時的急性哀傷。
- **複雜性哀傷**的高風險：**突然或創傷性死亡**、無法見最後一面(例：**隔離病房的傳染病病人**)、與逝者關係緊張或過度依賴、缺乏支持；要**轉介**專業團隊並追蹤。
- 評估**家庭關係動態**，找出需要哀傷支持的人。

### 剛過世時的照護 {#at-death}

| 適當 | 不適當 |
|---|---|
| **陪伴、同理**：「我相信您現在的痛苦是難以想像的」 | 「節哀順變」「要堅強」「時間會治療一切」「至少你還有其他孩子」 |
| 帶到**安靜的房間**，**允許哭泣、鼓勵宣洩情緒** | 請家屬克制情緒、急著說明離院手續 |
| 讓家屬**與遺體獨處、觸摸、道別** | 避免家屬觸碰遺體、急著移走遺體 |
| **在醫院政策允許下**提供宗教儀式(如**助唸**)的空間 | 一律要求到太平間才能舉行 |
| 用**照片等紀念物**引導回憶與談論逝者 | 建議清除所有遺物、用工作轉移注意力 |

- 家屬要求急救已簽 DNR 的病人時：先**同理**不捨的心情(「我了解您捨不得」)，再溝通，而不是只強調「他已經簽了」。

## 相關法規 {#law}

### 安寧緩和醫療條例 {#hospice-act}

| 項目 | 內容 |
|---|---|
| 末期病人 | 罹患嚴重傷病，經醫師診斷**不可治癒**，且有醫學證據顯示**近期內病程進行至死亡已不可避免** |
| 誰可以預立意願書 | **成年且具行為能力**之人(**不必已是末期**)。民法成年年齡自 112 年起為 **18 歲**；舊條文寫「二十歲以上」，舊考題以此為答案 |
| 見證 | **具完全行為能力者二人以上**在場見證；**實施安寧緩和醫療的醫療機構所屬人員不得為見證人** |
| 醫療委任代理人 | 可預立**醫療委任代理人**，在本人無法表達時**代為簽署**意願書 |
| 撤回 | 意願人**隨時**可以書面**撤回** |
| 健保卡註記 | 註記後效力與正本相同，**轉院不需重簽**；**反覆住院也不必每次重簽** |
| 執行條件 | 由**二位相關專科醫師**診斷為末期病人，並有意願書 |
| 未簽署且昏迷時 | 由**最近親屬**出具**同意書**代替(一人即可)；**不得違反病人昏迷前明示的意思**；**無最近親屬**時，經安寧緩和醫療照會後，依病人**最大利益由醫師出具醫囑**代替(不是由里長簽) |
| 撤除維生醫療 | 符合上述規定時，原本已施予的**心肺復甦術或維生醫療可以終止或撤除** |
| 未成年人 | 簽署意願書需**法定代理人同意**；無法表達時由**法定代理人簽署** |

**最近親屬的順序**(意見不一致時依此順序)：

1. **配偶**
2. **成年子女、孫子女**
3. **父母**
4. **兄弟姐妹**
5. **祖父母**
6. 曾祖父母、曾孫子女或**三親等旁系血親**(伯叔姑舅姨、姪甥)
7. **一親等直系姻親**(公婆、岳父母、女婿媳婦)

- **堂兄弟姊妹**是四親等旁系血親，**不在**最近親屬內。
- 例：病人**口頭**表示過不要急救但沒簽署，昏迷後母親要求插管、20 歲女兒希望撤除 → **女兒(第 2 順位)優先於父母(第 3 順位)**，可以由女兒**簽署同意書後撤除**。

(來源：[安寧緩和醫療條例](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=L0020066))

### 病人自主權利法 {#patient-autonomy-act}

| 項目 | 內容 |
|---|---|
| 施行 | **108 年 1 月 6 日**起施行，是亞洲第一部完整保障病人自主的專法 |
| **預立醫療決定**(AD) | **具完全行為能力**之人事先以書面表明，在**特定臨床條件**時**接受或拒絕維持生命治療**與**人工營養及流體餵養**的全部或一部 |
| 程序 | ① 先參加醫療機構的**預立醫療照護諮商**(ACP)，並經核章；**意願人、至少一位二親等內親屬、醫療委任代理人**應參與；② **公證**或**二人以上見證**；③ **註記於健保卡**才生效 |
| **五種特定臨床條件** | ① **末期病人** ② **不可逆轉之昏迷** ③ **永久植物人** ④ **極重度失智** ⑤ 其他經中央主管機關公告的疾病(例：罕見疾病與其他痛苦難以忍受、無法治癒者)。「**重度衰弱**」不在法定條件中 |
| 確診 | **二位相關專科醫師**確診，並經**緩和醫療團隊至少二次照會** |
| 醫療委任代理人 | **成年且具行為能力**、經書面同意；受遺贈人、器官受贈人等**不得擔任**(繼承人除外) |
| 撤回 | 隨時可以書面撤回或變更 |

| 比較 | 安寧緩和醫療條例 | 病人自主權利法 |
|---|---|---|
| 適用 | **末期病人** | **五種臨床條件** |
| 可拒絕的 | 心肺復甦術、維生醫療 | 維持生命治療、**人工營養及流體餵養** |
| 前置程序 | 不需要諮商 | **必須參加預立醫療照護諮商** |
| 本人無法表達時 | 最近親屬可出具同意書 | **只能依本人事先的預立醫療決定**，家屬不能代替 |

(來源：[病人自主權利法](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=L0020189))

## 遺體護理 {#postmortem-care}

### 死亡後的遺體變化 {#postmortem-changes}

| 變化 | 時間與特點 |
|---|---|
| **屍冷**(體溫下降) | **最早出現**的變化；約**每小時下降 1°C**，直到與室溫相同 |
| **屍斑**(屍體低垂部位的紫紅色斑) | 血液循環停止後因**重力**沉積在**身體低處**；約死後 **20–30 分鐘**開始，**2 小時左右明顯**；**受壓迫的部位不會形成**屍斑 |
| **屍僵**(肌肉僵硬) | 肌肉內 **ATP 耗盡**，肌動蛋白與肌凝蛋白無法分開(**不是血液凝固**)；約死後 **2–4 小時**開始，**由頭頸部(下頷)開始**往下，**小肌肉比大肌肉先僵硬**；約 12 小時全身僵硬，**24–48 小時後逐漸緩解**(會再軟化) |
| 腐敗 | 細菌分解組織 |

### 遺體護理的步驟 {#postmortem-steps}

- **在屍僵發生前**完成擺位：
  - **仰臥**、身體平直(**不是側臥**)；**頭下放一個枕頭**，防止血液沉積使臉部變色；
  - 輕閉雙眼(可用濕棉球)、**裝回假牙**並閉合嘴巴(下頷下可墊捲起的毛巾)；
  - 雙手放在身側或前胸；**不用繃帶纏綁**手腳。
- **管路**：鼻胃管**先反抽或引流胃內容物再拔除**；導尿管**先抽出水囊的水再拔除**；拔除後的傷口以敷料覆蓋，較大的傷口可縫合以維持皮膚完整。
- 以溫水清潔身體，更換乾淨衣物；會陰與身體開口處以護墊吸收排出物。
- 依院內規定掛上**身分識別**，貴重物品交給家屬並記錄。
- **尊重宗教與文化**：在醫院政策允許下提供**助唸**等儀式空間；讓家屬參與擦澡或更衣。

### 護理人員自身的哀傷 {#nurse-self-care}

- 照顧臨終病人可能出現**無力感、焦慮、低落** → 可**調整主護**、提供同儕支持與團隊討論，不是要求「勇於承擔」或質疑是否適任。

## 兒童與死亡 {#children}

### 兒童的死亡概念 {#death-concept}

| 年齡(發展階段) | 對死亡的理解(Nagy、Piaget) | 照護 |
|---|---|---|
| **< 3 歲**(嬰幼兒) | **沒有死亡概念**，對**分離與失落**有反應 | 父母陪伴、維持日常習慣 |
| **3–5 歲**(學齡前期，前運思期) | 死亡是**暫時的、可逆的**，像**睡覺**或出遠門，**會再醒過來**；可能有**魔術思考**，以為是自己害的 | 用具體、正確的字眼(說「死了」，不說「睡著了」)；澄清不是他的錯 |
| **5–9 歲**(學齡期早期) | 死亡是**可避免的**，把死亡**擬人化**(死神、鬼)，**只有被抓到的人、老人才會死**；開始知道死亡不能復活 | 繪本、遊戲；回答問題 |
| **9–10 歲以上**(具體運思後期到形式運思期) | 死亡是**普遍、不可避免、不可逆**的，**生物體死後無法復活** | 可以直接討論，關心實際與靈性問題 |
| **青少年** | 概念**成熟**但覺得「**自己不會這麼年輕就死**」；**較不容易與父母和醫護人員**談論死亡，較依賴同儕 | 尊重隱私與自主、同儕支持 |

### 與瀕死病童溝通 {#talking-with-children}

- **誠實、依發展階段**說明，**不要隱瞞**或給不實的痊癒希望。
- 病童問「我是不是快死了？」→ 先**了解他為什麼這樣問、在擔心什麼**，不要否認或打發。
- 運用**遊戲、繪畫、繪本、角色扮演**讓孩子表達想法與感受。
- 生氣的病童(「為什麼是我？」)：**仔細傾聽、鼓勵表達需要**。
- 疼痛：依醫囑**按時靜脈注射 morphine**，**不用 meperidine**；用 QUESTT 原則評估(見 [[pain-management#children]])。
- 生理照護以**舒適**為主：維持皮膚清潔乾燥；**不勉強進食**(吞嚥困難時不要硬餵)；不追求維持血壓的輸液或持續抗生素。
- 瀕死兒童的變化同成人：陳施氏或喟嘆式呼吸、**喉頭肌肉鬆弛無法自行咳出分泌物**、末梢冰冷發紺、脈搏弱、**聽覺最後消失**。
- **兒童安寧緩和療護**應在**診斷確立時就可以介入**，與治癒性治療並行，以**家庭為中心**。
- 未成年病童的不施行心肺復甦術由**法定代理人**簽署，**沒有「滿 7 歲須自行簽署」**的規定；簽署前最好與病童充分溝通、盡量完成病童的心願。

### 支持父母與手足 {#family-of-child}

- 父母：接納哀傷、**提供他們想知道的正確資訊**(避免醫學術語)、評估靈性需求；不主動反覆追究「為什麼沒有早點發現」。
- 病童死亡時：通知時**直接使用「死亡」的字眼**；讓家人**有時間與孩子獨處**、抱抱孩子；經歷急救後死亡的孩子，**先適當整理遺體**再讓母親道別；**新生兒**死亡前後也鼓勵父母**抱抱、說話**；不要轉移父母的注意力。
- **手足**：依年齡說明、**安排探視**瀕死的兄弟姊妹、可以**參加喪禮**；用繪本與遊戲引導表達；行為問題要了解原因而不是只糾正；請學校老師一起關心；不要說「你是大孩子了，要自己忍耐」。
- 兒童面對親人死亡：用他能懂的語言說明、允許難過、接受**退化行為**，不要避談過世的親人。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **聽覺最後消失**；**陳施氏呼吸**最常見；脈搏以**頸動脈**最易測、心尖搏動最後消失；**末梢先冰冷**、盜汗、發紺、希氏面容；腸蠕動變慢、**括約肌鬆弛失禁**；可能看到過世親友、譫妄。
- **臨終嘎嘎音：側臥或半坐臥頭側一邊、減少輸液、scopolamine、口腔護理，不要抽痰**。
- 臨終照護：**以病人意願為優先**、說話清楚緩慢、**不耳語**、**不刻意昏暗**、**按時止痛**、**不勉強進食與增加點滴**、藥物可改皮下、減少不必要監測、**引導家屬道別**；譫妄**不約束**。
- Kübler-Ross：「為什麼是我」= **憤怒**；放生、「讓我活到…」= **討價還價**；「再也看不到女兒」= **憂鬱**；「告訴我怎麼照顧自己」= **接受**；**不一定依序、可能停在否認期**；否認期**給時間**。
- 哀傷：陪伴同理、**安靜房間宣洩**、**紀念物引導**；預期性哀傷**無法避免急性哀傷**。
- 安寧：**癌症與非癌症**皆適用；住院、居家、**共同照護**；**不一定住院**；照顧**病人與家屬**；**思覺失調症、憩室炎不符合**。
- 條例：**成年**(舊題「二十歲以上」)即可預立，**不限末期病人**；**二位見證人**、醫療機構人員**不可見證**；可預立**醫療委任代理人**；可**隨時撤回**；最近親屬**配偶 → 成年子女孫子女 → 父母 → …**，**堂兄不是**。
- 病主法：預立醫療決定可**拒絕維持生命治療與人工營養及流體餵養**；**須先 ACP 諮商**；**重度衰弱不是**法定條件。
- 腦死：**昏迷指數 ≤ 5**、依賴呼吸器、**原因確定且不可逆**；**低體溫、藥物、代謝造成的昏迷不適用**；**兩次**腦幹功能測試；包含**頭眼反射**。
- 遺體：**屍冷最早**；屍斑約 **2 小時**明顯、受壓處不形成；屍僵 **2–4 小時**、**由下頷開始**、**小肌肉先**、不是血液凝固；屍僵前**仰臥、頭墊枕、裝假牙**；**鼻胃管先引流再拔**。
- 兒童：**3–5 歲死亡像睡覺會醒來**；**9 歲死後無法復活**；**6 歲**認為死亡可避免、只有老人或被抓到的人會死；**青少年較不會與醫護談死亡**；**讓手足探視與參加喪禮**；**兒童安寧可在診斷時介入**；DNR 由**法定代理人**簽。
:::
