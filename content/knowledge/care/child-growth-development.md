「生長」是身體整體或部分大小與重量的增加；「發展」是身心隨年齡與環境互動而產生的變化，包括質與量，是學習與成熟的結果（華杏書頁 18）。本頁整理生理成長的數字、各系統的發展、動作與語言里程碑、三大發展理論與兒童的疾病概念、遊戲與繪畫發展、氣質與丹佛發展篩檢；兒童生命徵象的正常值與測量見 [[pulse-blood-pressure#pediatric-vital-signs]]，嬰兒營養與副食品見 [[maternal-child-health]]，住院時如何應用發展理論見 [[hospitalized-child]]。文中縮寫：DDST-II（Denver Developmental Screening Test II，丹佛發展篩檢測驗第二版）、IQ（Intelligence Quotient，智商）

## 重點摘要 {#summary}

- **發展原則**：有方向與順序、早期是後期的基礎、有個別差異、有關鍵期；**頭尾定律**（頭 → 四肢）、**近遠定律**（中心 → 周邊）、簡單 → 複雜；各系統發展速度**不一致**
- **體重**：6 個月約出生的 **2 倍**、1 歲 **3 倍**、2 歲半 **4 倍**（出生 3 公斤：6 公斤、9 公斤、12 公斤）
- **身高**：1 歲增加約 **50%**、2 歲約成人的**一半**、4 歲約出生的 **2 倍**、13 歲約 **3 倍**
- **頭圍**：出生約 **34 公分**、1 歲約 **47 公分**；1 歲時**胸圍等於頭圍**
- **囟門**：前囟門 **12–18 個月**關閉，後囟門出生後約 **2 個月**關閉
- **乳齒**：20 顆，下中門齒 → 上中門齒 → 側門齒 → **第一大臼齒 → 犬齒** → 第二大臼齒，約 2 歲半長齊；**恆齒**約 **6 歲**先長第一大臼齒
- **皮亞傑**：物體恆存（感覺動作期）→ 自我中心、泛靈、**沒有保留概念**（前運思期）→ 保留概念、可逆性（具體運思期）→ 抽象、假設推理（形式運思期）
- **遊戲**：單獨 → 旁觀 → **平行**（幼兒）→ **聯合**（學齡前）→ **合作**（學齡期）
- **氣質**：先天的行為反應模式，**無好壞、與智力無關**，可作為因材施教的依據
- **DDST-II**：0–6 歲篩檢（不是智力測驗），四大項：粗動作、精細動作與適應、語言、身邊處理及社會性；早產兒用**矯正年齡**

### 國考常考點 {#exam-points}

- 出生 3 公斤：4 歲約 15 公斤（約 5 倍）；6 個月 4.5 公斤是**過輕**
- 0–1 歲是**神經系統**生長最快的時期
- 3 歲兒童呼吸仍以**腹式（橫膈）**為主，約 7 歲後才改為胸式
- 20 個月大還沒長的乳齒：**第二大臼齒**
- 6 個月頭頂軟軟的：是前囟門，12–18 個月關閉，正常
- 頸部淋巴結界限**不清楚** → 異常（小於 1 公分、可移動、不壓痛為正常）
- 15 個月：**不需扶持獨自行走**；8 個月獨坐很穩；18 個月倒退走；三輪車、疊 9–10 塊積木是 3 歲
- 躲貓貓轉移注意力 → 嬰兒已有**物體恆存**
- 2–6 歲換成大底面積的藥杯，就以為藥變少 → 還沒有**質量保留**
- 3 歲以為遮住自己就沒人看見 → **自我中心**
- 具體運思期的疾病概念：**接觸傳染**（接近生病的人）、外在原因造成；形式運思期才知道是**器官功能不良**
- 2 歲半堅持自己吃 → **自主**；5 歲模仿老師收餐盒 → **主動（進取）**；10 歲 → **勤勉**
- 交換玩具但各玩各的 → **平行遊戲**；一起玩、互借玩具但沒有規則 → **聯合遊戲**；聯合遊戲是學齡前，不是青春期
- 羅文菲爾特：約 **3–3.5 歲**開始替塗鴉命名；**7–9 歲**（圖式期）充分表現創造性；10 歲接近**寫實**
- 氣質：初次接觸新的人事物「接受或退縮」是**趨避性**；尿布一點濕就哭是**反應閾低**；氣質**不能預測智力**
- DDST-II 評估項目包括**語言與社會適應**；氣質、物體恆存、挫折容忍度都不是
- 18 個月無法**倒退走** → 懷疑延遲；4–4.5 歲會扣扣子、單腳站 5 秒

## 生理的發展 {#physical-growth}

### 發展原則與生長型態 {#principles}

1. 發展有一定的模式與順序、有方向性；早期發展是晚期的基礎；有個別差異與關鍵期（華杏書頁 18）
   1. **頭尾定律**：由頭部開始，再到四肢
   2. **近遠定律**：由身體中心往周邊
   3. 由簡單到複雜、由整體到特殊
2. 四種生長型態（華杏書頁 18）

| 型態 | 包括 | 最快的時期 |
|---|---|---|
| 一般式 | 身體大小、呼吸、消化、循環、肌肉骨骼 | 嬰兒期與青春期 |
| **神經式** | 神經系統及附屬器官 | **出生到 1 歲** |
| 生殖式 | 生殖器官 | 青春期 |
| 淋巴式 | 胸腺、脾臟、淋巴系統 | 出生後快速，約 12 歲達高峰，之後退化 |

### 體重與身高 {#weight-height}

| 年齡 | 體重 | 身高 |
|---|---|---|
| 0–6 個月 | 每週增加約 140–200 公克；**6 個月約出生的 2 倍** | 每月約 2.5 公分 |
| 6–12 個月 | 每週約 85–140 公克；**1 歲約 3 倍** | 每月約 1.25 公分；1 歲約增加出生身長的 **50%** |
| 幼兒期（1–3 歲） | 每年 2–3 公斤；**2 歲半約 4 倍** | **2 歲約成人的一半** |
| 學齡前期（3–6 歲） | 每年 2–3 公斤 | 每年 5–7.5 公分；**4 歲約出生的 2 倍** |
| 學齡期（6–12 歲） | 每年 2–3 公斤 | 7 歲後每年約 5 公分；**13 歲約 3 倍** |

華杏書頁 19 表 1-10 整理；出生平均身長約 50 公分、體重約 3.4 公斤

1. 體重最能反映健康與營養狀態
2. 算法例題：出生 3 公斤 → 6 個月約 6 公斤、1 歲約 9 公斤、2 歲半約 12 公斤、3 歲約 12–14 公斤、**4 歲約 15 公斤**（約 5 倍，依國考題）
3. 體重增加不足時找原因：泡奶濃度不對、腹瀉、嘔吐、先天或內分泌問題（華杏書頁 15）

### 頭圍、胸圍、囟門與身體比例 {#head-proportions}

1. **頭圍**：出生約 34 公分、1 歲約 47 公分、3 歲約 51 公分、5 歲約成人的 90%（華杏書頁 19）
2. **胸圍**：出生時比頭圍小約 2 公分；**1 歲時等於頭圍**，之後胸圍大於頭圍
3. **囟門**
   1. **前囟門**：頭頂中間、菱形，**12–18 個月**關閉；6 個月摸起來軟軟的是正常
   2. **後囟門**：枕部、三角形，出生後約 **6–8 週**關閉
   3. 太早關閉要評估顱骨早閉；囟門膨出或凹陷的意義見 [[newborn-assessment]]
4. **身體比例**（華杏書頁 18）
   1. 出生時頭大、下肢短（下肢約占身長 1/3），身體中點在**肚臍**附近
   2. 2 歲時中點在肚臍稍下方，頭約占身長 **1/4**
   3. 成人頭約占身長 1/8、下肢約 1/2

### 牙齒 {#teeth}

1. **乳齒** 20 顆，女孩比男孩早；約 6 個月開始長，**2 歲半長齊**（華杏書頁 20–21）
2. 萌出順序（華杏圖 1-5 整理）

| 順序 | 牙齒 | 約略月齡 |
|---|---|---|
| 1 | **下排中央門齒** | 6–8 個月 |
| 2 | 上排中央門齒 | 約 9 個月 |
| 3 | 側門齒 | 約 12 個月 |
| 4 | **第一大臼齒** | 約 15 個月 |
| 5 | **犬齒** | 約 18 個月 |
| 6 | **第二大臼齒**（最晚） | 約 24–26 個月 |

3. 第一大臼齒比犬齒**早**長；20 個月大通常還沒長第二大臼齒
4. **恆齒** 32 顆，約 **6 歲**先長**第一大臼齒**（六歲齒，長在乳臼齒後方，不是替換乳齒），之後門齒 7–9 歲、前臼齒 10–12 歲、犬齒 11–12 歲、第二大臼齒約 13 歲、第三大臼齒 17–22 歲
5. 口腔保健與塗氟見 [[maternal-child-health]]

### 各系統的發展 {#systems}

| 系統 | 重點（華杏書頁 20 表 1-11 整理） |
|---|---|
| 神經 | 腦重出生約 350 公克，1 歲約 800 公克（成人的一半），2 歲約出生的 3 倍；6 歲前發展最快；脊神經髓鞘化約 3 歲完成 |
| 骨骼 | 6 歲前用**手腕 X 光**判斷骨齡；脊柱：3 個月出現頸部彎曲（抬頭）、7 個月出現腰部彎曲（坐）；1 歲前生理性 O 形腿，3–4 歲 X 形腿，5–8 歲自行恢復；骨骼到青春期後才成熟 |
| 心臟 | 2 歲以下心尖約在**第 3–4 肋間**、左鎖骨中線**稍外**；7 歲以後在左鎖骨中線第 5 肋間 |
| 呼吸 | 胸廓近圓形；**嬰幼兒以橫膈（腹式）呼吸為主，約 7 歲後改為胸式** |
| 消化 | 胃容量出生 10–20 mL、1 歲 210–360 mL；約 3 個月唾液大量分泌而流口水 |
| 泌尿 | 新生兒 GFR 約成人的 30–50%，**2 歲**達成人標準；3 歲可憋尿 6–9 小時 |
| 淋巴 | 學齡期發育最快，青春期高峰後退化 |
| 感覺 | **觸覺**發育最早、最重要；出生已有聽覺、嗅覺、味覺（喜歡甜）；3–5 個月能分辨顏色，斜視約 6 個月消失 |

GFR：Glomerular Filtration Rate（腎絲球過濾率）

1. 兒童常可摸到頸部淋巴結：**小於 1 公分、界限清楚、可移動、不壓痛**屬正常；**界限不清、固定、融合或壓痛**要進一步評估（身體評估一般原則，依國考詳解，待核對）
2. 大小便訓練：肛門期約 1 歲半到 2 歲開始，3 歲多已能完成（華杏書頁 21）

## 動作、語言與智力 {#motor-language}

### 動作發展 {#motor}

| 年齡 | 粗動作 | 精細動作與生活 |
|---|---|---|
| 3 個月 | 俯臥翻仰臥 | 看自己的手，用手掌抓 |
| 6 個月 | 雙手向前撐著坐、自由翻身 | 敲擊手上的東西 |
| 7 個月 | 不需支持坐穩 | 拇指與四指相對抓 |
| **8 個月** | **獨坐很穩**、匍匐爬 | 單手抓玩具 |
| 9–10 個月 | 爬、扶著站起 | **拇指食指鉗夾**、自己拿奶瓶 |
| 12 個月 | 獨站片刻、扶家具走 | 東西一個一個放進容器 |
| **15 個月** | **不需扶持獨自行走**、手膝爬樓梯 | 自己用杯子、湯匙；疊 **2** 塊積木 |
| 18 個月 | 扶著上樓梯、**倒退走**、擲球 | 自己脫衣服；疊 3–4 塊積木 |
| 2 歲 | 自行上下樓梯、原地跳 | 疊 5–6 塊、模仿畫直線、開門 |
| **3 歲** | **騎三輪車**、單腳站數秒、兩腳交替上樓 | 疊 **9–10 塊**、自己刷牙、解扣子 |
| 4 歲 | **單腳跳**、兩腳交替下樓 | 剪刀沿線剪、畫「口」、**扣扣子、穿襪子**、自己穿衣 |
| 5 歲 | 接反彈球、跳繩 | 寫簡單的字與名字 |
| 6 歲 | 快跑、跳、爬 | 畫出身體 3–6 個部分 |

華杏書頁 24–26 表 1-15 整理

1. 自己穿襪子、拉拉鍊是 3–4 歲的能力，不是 2 歲
2. 4 歲已能自行上下樓梯

### 語言與智力 {#language-iq}

1. 6 歲前是語言關鍵期，**2–4 歲**最重要（華杏書頁 26–27）
   1. 1 個月用不同哭聲表達；8–12 個月回聲期（立即模仿）
   2. 1–1.5 歲**單字期**（一個字代表整句）；1.5–2 歲雙字期，能指出 2–3 個身體部位
   3. 2–2.5 歲單句期（鸚鵡式學語）；2.5–3 歲雙句期（**好問期**），3 歲約 900 個字
2. **智商**＝心智年齡 ÷ 實際年齡 × 100；90–109 正常、70 以下智能不足；只是參考，受遺傳、營養、情緒、文化影響
3. 智能不足的分級、早期療育見 [[intellectual-disability]]；選玩具與遊戲要依**心智（認知）年齡**而不是實際年齡，仍要有安全限制、鼓勵社會參與、可搭配非語言溝通

## 發展理論 {#theories}

三個理論的完整說明見 [[psychodynamic-theories#interpersonal-developmental]]；這裡整理兒童各階段的重點

|---|---|---|---|
| 0–1 歲 | 口腔期：吸吮、咬；斷奶與餵食 | **信任 vs 不信任**（重要人物：母親）；約 6 個月出現陌生人焦慮 | 感覺動作期 |

### 皮亞傑認知發展 {#piaget}

1. **感覺動作期**（0–2 歲）
   1. 從反射動作 → 循環反應 → 主動嘗試錯誤
   2. 4–8 個月開始建立**物體恆存**（東西消失會去找），8–12 個月對看不見的東西仍有記憶 → 玩**躲貓貓**可以轉移注意力
   3. **18–24 個月心靈表象**：行動前會先在心裡想、出現模仿；仍沒有保留概念
2. **前運思期**（2–7 歲）
   1. 使用符號、語言與象徵
   2. **自我中心**：以為別人和自己看到、想的一樣（遮住自己吸手指，就以為沒人看見）
   3. **泛靈觀**（萬物有靈）、單向思考、**不能可逆**
   4. **沒有保留概念**：只看外觀（液面變低就以為藥變少）
   5. 沒有時間觀念，用每天固定的具體活動了解時間（「吃完午飯媽媽就來」）
3. **具體運思期**（7–11 歲）
   1. **質量、長度、數目、重量保留**；**可逆性**思考、去自我中心、分類
   2. 推理限於具體事物；了解過去、現在、未來
4. **形式運思期**（11 歲以上）：**抽象思考**、建立假設並驗證、融合數個觀念
5. 10 歲尚未完成的是**抽象思考**；性別恆定、保留概念、可逆性都已有
6. 107-2_OP_059 國考答「感覺動作期」：題幹「用感官得到的心像了解世界、但不能保留」對應感覺動作期最後的**心靈表象階段**（華杏書頁 23）

### 兒童的疾病概念 {#illness-concepts}

| 階段 | 疾病概念 | 例子 |
|---|---|---|
| 前運思期（2–7 歲） | **現象論**：外來、和自己無關的現象；**傳染**：只因為兩件事接近，帶有魔力；常認為是**做錯事的懲罰** | 「我生病是因為不乖」 |
| 具體運思期（7–11 歲） | **接觸傳染**：外在的人、物、行為造成；**內在化**：外來的東西進到體內 | 「沒戴帽子、吃冰才發作」、「靠近感冒的人」 |
| 形式運思期（11 歲以上） | **生理的**：**器官功能不良**；**精神生理的**：心理與態度會影響健康 | 能提出假設再驗證 |

1. 具體運思期最適合的說法：「接觸生病的人」
2. 「器官功能不良」與「提出假設再驗證」屬於形式運思期

## 遊戲與繪畫發展 {#play-drawing}

### 遊戲發展 {#play}

| 遊戲 | 年齡 | 特點 |
|---|---|---|
| **單獨遊戲** | 嬰兒到 2 歲 | 自己玩玩具、填充玩偶、躲貓貓，不重視玩伴 |
| 旁觀者遊戲 | 幼兒 | 在旁邊看別人玩，不加入，也能分享快樂 |
| **平行遊戲** | **幼兒期（學步期）主要特徵** | 在旁邊玩相似的玩具，偶爾交談、**交換玩具**，但**各玩各的**，沒有合作 |
| 雙人遊戲 | 3–4 歲 | 兩人合作完成，學習互動 |
| **聯合遊戲** | 學齡前（3–6 歲） | 拿玩具一起玩、互借玩具；**沒有團體目標、規則常變動** |
| **合作遊戲** | 學齡期（5–8 歲以上） | 有團體目標、分工、規則與**競爭**（下棋、玩牌、團體運動） |

華杏書頁 199 表 4-4 整理

1. 青少年重視同儕與團體活動，不是喜歡單獨遊戲
2. 2 歲 8 個月：互換玩具但各玩各的 → 平行遊戲
3. 3 歲左右由平行進入聯合，治療性遊戲可安排**和玩伴一起完成的簡單遊戲**；需要訂規則的合作與競爭遊戲適合學齡期

|---|---|---|

## 氣質 {#temperament}

1. **氣質**：一個人**先天**對內在或外在刺激的行為反應模式
   1. **無好壞之分**，**與智力和未來成就無關**，不能用來預測智力發展
   2. 用途：因材施教、協助父母了解孩子並調整教養方式、建立親子關係
   3. 氣質和父母教養互相影響
2. 九個向度（華杏書頁 28 表 1-17 整理）

| 向度 | 意思 | 例子 |
|---|---|---|
| 活動量 | 一天中動作的快慢與多寡 | |
| 規律性 | 睡眠、飢餓、排泄是否規律 | |
| **趨避性** | **初次**接觸新的人、物、食物、環境時**接受或退縮** | 很快接受新同學、新老師 → 趨性；第一次到托嬰中心大哭 → 避性高 |
| 適應度 | 適應新事物的**難易與時間長短** | |
| **反應閾** | 引起反應所需的**最小刺激量** | 尿布一點點濕就哭 → **反應閾低** |
| **反應強度** | 反應的**激烈程度** | 哭得很大聲 |
| 情緒本質 | 正向與負向情緒的比例 | |
| **注意力分散度** | 是否容易**受外界干擾**而改變正在做的事 | |
| 堅持度 | 遇到阻礙時繼續原活動的傾向 | |

3. 三種型態
   1. **易養育型**（約 40%）：情緒正向、作息規律、容易適應
   2. **難養育型**（約 10%）：避性、適應慢、作息不規律、反應強烈，父母需要極大耐心
   3. **慢吞吞型**（約 15%）：活動量小、**情緒偏負向**、對新事物退縮、適應慢
   4. 其餘約 35% 無法歸入單一類型（混合型）（Thomas 與 Chess 紐約縱貫研究）
4. 容易混淆：「容易受外界干擾」是注意力分散度高，不是反應強度或堅持度

## 丹佛發展篩檢測驗 {#ddst}

1. **DDST-II**：最常用的兒童發展**篩檢**工具，適用 **0–6 歲**；**不是智力測驗**（華杏書頁 29）
2. 四大項
   1. **粗動作**
   2. **精細動作與適應**
   3. **語言**
   4. **身邊處理及社會性**（個人－社會）
3. 氣質、物體恆存、記憶、自我概念、挫折容忍度都**不在**評估項目
4. **早產兒**用**矯正年齡**：實際年齡減去早產的月數（10 個月大、早產 2 個月 → 用 8 個月的標準）
5. 判讀
   1. 每個項目以長條表示 25、50、75、90% 的同齡兒童能通過的年齡
   2. 無法通過 **90%** 同齡兒童能通過的項目 → **延遲(D)**
   3. 落在 75–90% 之間沒通過 → **警訊(C)**
   4. 結果：**正常**（沒有延遲、最多 1 個警訊）、**可疑**（2 個以上警訊或 1 個以上延遲）、**無法測試**（拒絕測試等）
   5. 生病、害怕會影響結果
6. 國考常見里程碑
   1. 15–17 個月多數能**倒退走** → 18 個月還不會要懷疑延遲；向前踢球約 2 歲、單腳平穩站立約 3 歲以上、腳跟接腳尖走約 4–5 歲
   2. 18 個月應走得很穩；疊 6 塊積木約 2 歲、騎三輪車約 3 歲
   3. 約 30 個月 90% 能說出 6 個身體部位（依國考題）
   4. 會扣扣子、用手指夾葡萄乾、單腳站 5 秒 → 約 4–4.5 歲
7. 發展遲緩的通報與早期療育見 [[intellectual-disability#early-intervention]]
