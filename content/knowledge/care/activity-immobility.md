「活動」讓肌肉、骨骼、心肺都維持功能；病人一旦長期臥床或肢體被固定，各系統就會開始退化，稱為**制動**(immobility)，嚴重時成為**廢用症候群**。本頁整理**運動的種類**(被動、主動、加阻力；等長、等張)、**全關節運動**、**肌力分級**、**拐杖、手杖、助行器**的用法，以及**制動對各系統的影響與護理**。翻身擺位與支托物見 [[positioning-body-mechanics]]，壓力性損傷見 [[pressure-injury]]，約束見 [[patient-safety-environment#restraint]]

## 重點摘要 {#summary}

- 依肌力選運動：**0–1 分被動運動**、**2 分協助性主動運動**、**3 分主動運動**、**4–5 分加阻力運動**
- **等長運動**(isometric，肌肉固定運動)：關節不動、肌肉長度不變、**張力增加**；**主動性**運動；用於**上石膏肢體**、術後早期(股四頭肌下壓床面、凱格爾運動)；促進靜脈回流、防 DVT(deep vein thrombosis，深部靜脈血栓)、維持肌力、防萎縮，但**不能維持關節活動度**
- **等張運動**(isotonic)：張力不變、**肌肉長度與關節角度改變**；走路、跑步、騎車、游泳、伏地挺身；增加肌力與心肺功能、**維持關節活動度**
- 全關節運動(ROM, range of motion)：每個關節做到最大範圍但不痛不累；**由近心端到遠心端**；被動運動時**支托關節前後**；每個動作 5–10 次、每天至少 2–3 回；受傷關節暫停
- 拐杖：使用前**加強上肢肌力**(床上撐起、握球)；腋下留**兩橫指**、**用手撐**不靠腋下(防臂神經叢受壓)；手肘彎 20–30 度；拐杖尖在腳尖前 15 cm、外 15 cm
- 手杖：**握在健側(有力的手)**，與**患肢同時**向前；四腳手杖比單腳穩
- 助行器最穩但最慢：手把約與**腰同高**、手肘微彎(課本 15–20 度；國考題寫 ≤ 30 度)；先移助行器 → 患肢 → 健肢
- 長期臥床的影響：皮膚(壓力性損傷)、骨骼肌肉(**高血鈣、骨質疏鬆、肌萎縮、攣縮、垂足、髖外旋**)、循環(**心臟負荷增加、姿位性低血壓、DVT**、Valsalva 增加)、呼吸(**墜積性肺炎**、呼吸性酸中毒)、代謝(**負氮平衡**)、腸胃(便秘、逆流)、泌尿(**尿滯留、感染、結石**)、心理(憂鬱、低自尊)

### 國考常考點 {#exam-points}

- 上石膏肢體預防肌萎縮：**等長運動**(113-1_FA_031、107-2_MS_021)；等長運動是**靜態、主動**運動(114-2_FA_031)；說它是被動運動(111-1_FA_048)或「肌肉長度與關節角度改變」(110-1_FA_046)都是錯的
- 腦梗塞臥床病人「膝蓋下壓貼近床面」＝**等長運動**(106-1_FA_045)；「腿伸直膝蓋下壓」只能促進循環與肌力、**不能維持關節活動**(107-2_FA_043)
- 全髖置換術後股四頭肌等長收縮：減輕腫脹、預防血栓、維持肌力；**不能增加肌肉質塊**(108-2_FA_013)
- 等張運動**可增加肌肉強度與張力**、關節角度會改變(108-2_FA_047)；「肌肉收縮變短、張力與強度增強」不正確(106-2_makeup_FA_048，等張是張力不變)
- 骨折病人：**患肢做等長、健肢做等張**；倒過來是錯的(106-2_makeup_MS_017)
- 股骨術後肌力 2 分：**協助性主動運動**(106-1_MS_020)
- 預防長期臥床肌萎縮：**全關節活動**(108-2_FA_046)；被動 ROM 時**關節前後都要支托**(106-2_makeup_FA_050)
- 髖關節**沒有旋前**(114-2_FA_029、110-2_FA_009)；肩部 ROM **沒有外翻**(107-1_FA_043)；旋前＝**前臂旋轉掌心朝下**(113-2_FA_030)；腕過度伸展＝**手背朝前臂外側彎**(111-2_FA_047)
- 肱骨近端骨折上石膏：**避免肩關節水平內收**，前臂旋前旋後、手指、手腕運動可做(109-2_FA_043)
- 拐杖：使用前上肢做**加阻力運動**(112-3_FA_029)；下肢骨折臥床時加強上肢「**坐在床上伸直手臂撐起**」(105-2_FA_044)；**身體重心放腋下是錯的**(108-2_MS_015)；使用拐杖前增強「患側下肢」是錯的，要增強上肢(115-2_MS_012)
- 平躺量拐杖：**腋下到足底再加 2 吋(5 cm)**，「減 2 吋」是錯的；兩點步態不適合虛弱者(112-3_FA_029)
- 右下肢無力用手杖：**左手持手杖、放左腳尖前外側約 6 吋**(109-2_MS_020)；手杖握健側、與患肢同出(115-2_MS_012)
- 長期臥床：**髖部外旋、血液黏稠度增加**(113-2_FA_029)；**負氮平衡**(112-3_FA_027)；用力解便(Valsalva)使**心搏出量下降**(110-2_FA_038)
- 全膝置換術後**多上下樓梯、走遠路**不適當(114-2_MS_012)；全髖置換術後坐著**雙膝分開、不交叉腿**，不蹲下撿東西(106-2_MS_020)
- 石膏肢體：評估**疼痛、蒼白、麻痺、感覺異常**(115-2_OP_050)；石膏未乾**抬高患肢**、不用烤燈或吹風機(106-2_makeup_OP_079)

## 運動的種類 {#exercise-types}

### 依關節活動：被動、主動、加阻力 {#joint-exercise}

| 類型 | 定義 | 適合 | 例子 |
|---|---|---|---|
| **被動運動** | 由他人或機器帶動，病人不出力 | 肌力 0–1 分：偏癱、痙攣、意識不清 | 被動 ROM、膝關節置換後 CPM(continuous passive motion，連續性被動運動機) |
| **協助性主動運動** | 病人出力、他人協助完成 | 肌力 2 分：無法對抗重力 | 健側手協助患側手抬起 |
| **主動運動** | 病人自己完成、能對抗重力 | 肌力 3 分以上 | 主動 ROM、走路、騎車 |
| **加阻力運動** | 主動運動再加阻力 | 肌力 4–5 分 | 舉砂袋、彈力帶；**用拐杖前加強上肢** |

1. 被動運動能改善局部血流、提供感覺刺激、防攣縮惡化，但**無法增強肌力**
2. 偏癱者鼓勵**用健側協助患側**運動

### 依肌肉收縮：等長與等張 {#isometric-isotonic}

| | **等長運動**(isometric) | **等張運動**(isotonic) |
|---|---|---|
| 肌肉長度 | **不變** | **改變**(縮短或延長) |
| 肌肉張力 | **增加** | 不變 |
| 關節 | **不動** | 會動 |
| 性質 | 靜態、**主動**運動；又稱**肌肉固定運動** | 動態、主動運動 |
| 效果 | 維持肌力與張力、防萎縮、**促進靜脈回流防 DVT**、減輕局部腫脹；**不能維持關節活動度、不能增加肌肉質塊** | 增加肌力與耐力、改善心肺功能、增加骨密度、**維持關節活動度** |
| 適用 | **上石膏肢體**、牽引、術後早期、關節不宜活動者 | 一般活動、復健後期 |
| 例子 | 股四頭肌運動(腿伸直、膝下壓床面或腳推床尾板 10 秒再放鬆)、推牆、平板支撐、**凱格爾運動** | 走路、慢跑、游泳、騎車、爬山、伏地挺身、二頭肌彎舉 |

## 肌力分級 {#muscle-strength}

徒手肌力測試(manual muscle test)0–5 分，國考也稱 Lovett 量表

| 分數 | 表現 | 建議運動 |
|---|---|---|
| 0 | 完全沒有收縮 | 被動運動 |
| 1 | **肌肉有輕微收縮，但關節不能動** | 被動運動 |
| 2 | 去除重力後關節可做全範圍運動，無法抗重力 | 協助性主動運動 |
| 3 | 可抗重力完成全範圍運動，不能抗阻力 | 主動運動 |
| 4 | 可抗重力與部分阻力 | 加阻力運動 |
| 5 | 正常，可抗完全阻力 | 加阻力運動 |

1. 神經學檢查的肌力評估見 [[neuro-assessment]]；中風病人的擺位與復健見 [[stroke]]

## 全關節運動 {#rom}

### 名詞 {#rom-terms}

| 名詞 | 定義 |
|---|---|
| 外展／內收 | 肢體**離開**／**移向**身體中線 |
| 屈曲／伸展 | 關節角度**變小**／由屈曲回到伸直 |
| 過度伸展 | 超過伸直位置，例如頭往後仰、**腕部彎向手背**、手臂往後舉 |
| 旋前／旋後 | **前臂**旋轉使掌心**朝下**／**朝上**(只有前臂有) |
| 外翻／內翻 | 足部轉向外側／內側(踝關節) |
| 外旋／內旋 | 遠離／朝向身體中線旋轉(肩、髖) |
| 迴轉 | 肢體伸直以近端關節為中心畫圓(肩、髖) |
| 上舉／下壓 | 聳肩／放下肩膀 |
| 前伸／後縮 | 下頜(或肩胛)向前推出／回到原位 |
| 橈側偏移／尺側偏移 | 腕部向拇指側／小指側彎 |

### 各關節有哪些動作 {#rom-joints}

| 關節 | 動作 | 沒有 |
|---|---|---|
| 頸 | 屈曲、伸展、過度伸展、側屈、旋轉 | — |
| 肩 | 屈曲、伸展、過度伸展、外展、內收、內旋、外旋、**迴轉**、水平外展與內收、上舉下壓 | **外翻、內翻、旋前** |
| 肘 | 屈曲、伸展 | — |
| 前臂 | **旋前、旋後** | — |
| 腕 | 屈曲、伸展、過度伸展、橈側與尺側偏移 | — |
| 髖 | 屈曲、伸展、過度伸展、外展、內收、內旋、外旋、迴轉 | **旋前、旋後** |
| 膝 | 屈曲、伸展 | — |
| 踝與足 | 背屈、蹠屈、**外翻、內翻** | — |

### 執行要點 {#rom-practice}

| 要點 | 做法 | 原理 |
|---|---|---|
| 順序 | **近心端 → 遠心端** | 先放鬆大關節 |
| 範圍 | 每個關節做到最大範圍，但**不超過疼痛點**、不過度疲勞 | 避免傷害；漸進增加耐力 |
| 支托 | 被動運動時**托住關節的前後**(做肩部時托腕與肘) | 防關節脫位與肌腱拉傷 |
| 次數 | 每個動作 5–10 次、緩慢有節律；每天至少 2–3 回 | 維持活動度 |
| 觀察 | 疼痛、疲累、呼吸急促、胸悶就暫停；運動前後量生命徵象 | 評估耐受度 |
| 受傷關節 | 暫停；例如肱骨近端骨折上石膏**避免肩水平內收** | 防移位 |

## 輔具 {#assistive-devices}

### 拐杖 {#crutches}

1. 種類：**腋下拐杖**可減少下肢約 80% 負重(下肢骨折)；**前臂拐杖**約 40–50%(下肢偏癱、麻痺)
2. 使用前：**加強上肢與手部肌力**(加阻力運動、床上伸直手臂撐起、握橡皮球)
3. 測量(課本上冊 396)
   1. 平躺：**身高減 40 cm(約 16 吋)**，或**腋窩到足底再加 5 cm(約 2 吋)**
   2. 站立：拐杖頂端與腋窩保持**兩橫指**距離
   3. 手肘彎曲 **20–30 度**；拐杖尖放在**腳尖前 15 cm、再往外 15 cm**
4. **重量撐在手上，不靠在腋下**：腋下受壓會傷臂神經叢、手臂麻痺
5. 不穿拖鞋、注意地面乾燥

| 步態 | 順序 | 適合 |
|---|---|---|
| **四點式** | 健側拐 → 患側腳 → 患側拐 → 健側腳 | 雙腳都能負重；**最安全、最慢** |
| **三點式** | 兩拐＋患側腳一起 → 健側腳 | **患肢部分或完全不能負重**；較快 |
| **兩點式** | 健側拐＋患側腳 → 患側拐＋健側腳 | 雙腳可部分負重、協調好、手臂有力；比四點快 |
| **搖擺式** | 兩拐向前 → 身體擺過去 | 下肢麻痺(常用前臂拐杖) |

1. 上樓梯：**健側腳先上**，拐杖與患肢再上(好的上天堂)；下樓梯：**拐杖與患肢先下**，健側腳再下(壞的下地獄)

### 手杖與助行器 {#cane-walker}

1. **手杖**：老人下肢無力時用；**握在健側(較有力的手)**，放在同側腳尖前外側約 15 cm(6 吋)；手杖**與患肢同時**向前，再跨健肢；四腳手杖比單腳穩
2. **助行器**：四個支點，**最穩定但最慢**；手把約與**腰(股骨大轉子)同高**；手肘微彎(課本 15–20 度，國考題寫可彎 ≤ 30 度)；**先移助行器約一臂長 → 患肢 → 健肢**；無輪的要抬起、有輪的推動
3. **輪椅**：上下時**固定輪子**；偏癱者輪椅放**健側**；協助下床前先坐床緣測脈搏血壓
4. 全膝關節置換術後：抬高患肢、術後 1–2 天可用 CPM、用助行器；**避免爬樓梯與長距離行走**直到復健評估允許
5. 全髖關節置換術後：防脫位，坐著**雙膝分開、不交叉腿、不蹲、不坐低椅**，髖屈曲不超過 90 度；骨折與關節置換詳細內容留肌肉骨骼輪

### 石膏固定肢體 {#cast-care}

1. 評估神經血管 **5P**：疼痛(pain)、蒼白(pallor)、脈搏(pulselessness)、感覺異常(paresthesia)、麻痺(paralysis)；腔室症候群留肌肉骨骼輪
2. 石膏未乾：**抬高患肢**減輕腫脹；用手掌(不用手指)托；**不用烤燈、吹風機熱風**(燙傷、外乾內濕)；床上支架撐起被蓋
3. 患肢做等長運動、其他關節做全關節運動；健側照常活動
- 懸臂帶支托上石膏手臂與彈性繃帶包紮見 [[bandaging#arm-sling]]

## 制動對各系統的影響 {#immobility-effects}

| 系統 | 變化 | 機轉與重點 |
|---|---|---|
| 皮膚 | **壓力性損傷** | 骨突處受壓缺血，見 [[pressure-injury]] |
| 骨骼 | **高血鈣、骨質疏鬆**、病理性骨折；**腎結石** | 缺乏負重與肌肉收縮，鈣離子由骨質游離 |
| 肌肉 | **肌萎縮**、肌力每週約降 12%(下肢最先) | 廢用 |
| 關節 | **攣縮**(不動 8 小時就可能開始)、**垂足、垂腕、髖外旋** | 長期仰臥、被蓋壓腳 |
| 心血管 | **心臟負荷增加**(臥床 24 小時約 1 L 體液由腿移到胸)；**姿位性低血壓**；**DVT**(血漿量減少、血液黏稠＋靜脈血流慢＋內皮損傷)；**Valsalva 動作增加** | ANP 利尿致血容量下降；Valsalva 時胸內壓增加 → 靜脈回流與**心搏出量下降** |
| 呼吸 | 潮氣容積與肺活量下降、分泌物積在下垂部位 → **墜積性肺炎**；PaCO₂ 上升 → **呼吸性酸中毒** | 胸廓擴張受限、纖毛擺動差 |
| 代謝 | **負氮平衡**(蛋白質分解大於合成)、基礎代謝率下降 | 肌肉流失＋食慾差 |
| 腸胃 | 食慾下降、**便秘**(甚至糞石)、胃食道逆流 | 腸蠕動減慢 |
| 泌尿 | **尿滯留**、**泌尿道感染**、**尿路結石**、電解質流失 | 臥姿使膀胱排空差；尿鈣增加 |
| 心理社會 | 憂鬱、焦慮、低自尊、依賴、身體心像改變、感覺剝奪 | 社交減少 |

## 護理措施 {#interventions}

1. 皮膚：至少每 2 小時翻身、減壓床墊、保持清潔乾燥，見 [[pressure-injury#prevention]]
2. 骨骼肌肉：每天至少 2–3 次全關節運動；負重運動(雙手拉床頭板、腳推床尾板)；**足托板、粗隆捲軸**防垂足與髖外旋，見 [[positioning-body-mechanics#support-devices]]
3. 循環：**漸進式下床**(先抬床頭 → 坐床緣擺動雙腿 → 站立)；下肢運動；必要時依醫囑彈性襪或間歇性加壓裝置(SCD, sequential compression device)；DVT 見 [[thrombosis-embolism-infarction]]
4. 呼吸：深呼吸、腹式呼吸、咳嗽、誘發性肺量計，見 [[airway-clearance]]
5. 代謝：**高蛋白、高熱量**飲食，補充醣類節省蛋白質
6. 腸胃：進食抬高床頭、飯後維持 30–60 分鐘；高纖飲食、腹部按摩、排便時給予隱私；避免用力閉氣解便
7. 泌尿：無限制時每天液體 **2,000–3,000 mL** 預防結石與感染；排尿時抬高床頭；有尿管每天尿管護理、盡早移除
8. 心理：安排活動與社交、鼓勵自我照顧

## 常見錯誤 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 等長運動是被動運動 | 是主動運動 | 病人自己收縮肌肉 |
| 等長運動可維持關節活動度 | 不能；要靠全關節運動或等張運動 | 關節不動 |
| 骨折患肢做等張、健肢做等長 | 患肢等長、健肢等張 | 患肢被固定不能動 |
| 拐杖靠腋下撐住身體 | 用手撐、腋下留兩橫指 | 防臂神經叢受壓 |
| 用拐杖前加強患側下肢 | 加強上肢 | 上肢要撐體重 |
| 手杖拿在患側 | 拿在健側、與患肢同出 | 擴大支撐面、分擔患肢負重 |
| 臥床病人基礎代謝率上升 | 下降、負氮平衡 | 活動減少 |
| 臥床病人膀胱餘尿減少 | 增加、易尿滯留 | 臥姿排尿困難 |
