長照 2.0(2017–2026)把服務對象擴大、向前延伸到**預防及延緩失能**、向後銜接**居家醫療與安寧**，並建立**社區整體照顧服務體系(ABC)**。國考題幾乎都依長照 2.0 出題；現行的申請資格與給付規定在**長期照顧服務申請及給付辦法**，2025–2026 年分三階段修正，本頁把考試答案與現行規定並列。長照的定義、評估工具與服務類型見 [[long-term-care]]；個案管理與出院準備見 [[home-care-discharge-planning]]

## 重點摘要 {#summary}

- 流程：民眾向**照管中心**申請 → **照顧管理專員（照專）**評估並**核定長照需要等級（2–8 級）與給付額度** → **A 單位（社區整合型服務中心）個管**擬照顧計畫、派案 → **B 單位**提供服務（給付辦法第 3–5 條）
- 四包錢（給付辦法第 7 條）：**照顧及專業服務**、**交通接送**、**輔具及居家無障礙環境改善**、**喘息服務**；各項額度**不可互相流用**
- 部分負擔（附表五）：照顧及專業服務、喘息 → **低收 0%、中低收 5%、一般戶 16%**
- 喘息：對象是**家庭照顧者**；**2–6 級每年 32,340 元、7–8 級每年 48,510 元**（舊題寫成 14 天、21 天）；可在居家、機構、日照、小規模多機能、巷弄長照站使用
- ABC：**A 社區整合型服務中心**（擬計畫、連結資源）、**B 複合型服務中心**（提供專業服務）、**C 巷弄長照站**（健康促進、共餐、預防失能、臨托）；原則**培植 A、擴充 B、廣布 C**
- 失智：疑似失智要確診 → **失智共同照護中心**；認知促進、照顧者支持團體 → **失智社區服務據點**
- 現行對象（2026-01-01 起）：**65 歲以上**（原住民 **55 歲以上**）、**領身心障礙證明**、**失智症（不限年齡）**、**急性後期整合照護收案對象**，且要經評估為失能

### 國考常考點 {#exam-points}

- 長照 2.0 擴大的對象（國考答案）：**50 歲以上失智症**、**55 歲以上原住民**、**49 歲以下身心障礙者**、**65 歲以上僅工具性日常生活活動功能(Instrumental Activities of Daily Living, IADL)失能的獨居老人**、**65 歲以上衰弱老人**
   1. 「60 歲以上失智」「40 歲以上失智」都錯
   2. 50 歲關節退化、沒有身障證明 → **不符合**
   3. 65 歲以上日常生活活動功能(Activities of Daily Living, ADL)與 IADL **都滿分** → **不符合**（沒有失能）
   4. 現行（2026-01-01 起）失智症**不限年齡**，見 [[long-term-care-services#eligibility]]
- **核定失能等級與給付額度的是照管中心照專**，不是 A 個管或出院準備個管
- 喘息服務**不是只在 C 據點**；**一般戶要付 16%**，不是全額補助；外籍看護工**休假期間可申請**；居家與機構喘息**可合併使用**
- 機構住宿式喘息是把**被照顧者**送去機構，不是照顧者入住
- 小規模多機能 = 日間照顧＋居家服務＋臨時住宿，**不含輔具租借**；目的**不是增加老人再就業**
- C 巷弄長照站**沒有醫師駐點**、**不擬照顧計畫**；應**普設 C**，不是普設 A
- ABC 的目的：**整合與銜接服務資源**
- 長照 2.0 財源：**菸品健康福利捐、捐贈收入**、遺贈稅、菸酒稅、政府預算；**不是**長照保險費或健保費
- 家庭照顧者服務的對象**不只照顧 65 歲以上老人者**
- 預防及延緩失能**包括口腔保健、認知促進、膳食營養**，**不包括職業訓練**
- 失智據點**不負責申請外籍照服員**（那是照管中心的評估業務）
- **原住民族文化健康站**：服務 **55 歲以上**原住民（健康、亞健康、衰弱、輕度失能）；原鄉困境是交通、人力流動、文化語言，**不是照顧者太多**
- 照服員**不可執行傷口清創**；糖尿病足潰瘍個案可申請輔具、居家護理指導、交通接送回診

## 服務對象 {#eligibility}

- 現行申請資格（長期照顧服務申請及給付辦法第 2 條，2025-06-19 修正；第 3、4 款自 2026-01-01 施行）：因身心失能，且符合下列之一
   1. **65 歲以上**；具原住民身分者 **55 歲以上**
   2. **領有身心障礙證明**（不限年齡）
   3. **失智症**（不限年齡，納入**年輕型失智且失能者**）
   4. 評估期間符合健保署**急性後期整合照護計畫(post-acute care, PAC)**的收案對象
- 全日住宿式服務與團體家屋的服務使用者另依其他規定照顧，不適用給付辦法
- 長照 2.0 核定本的擴大對象（國考依此出題）

| 對象 | 長照 1.0 | 長照 2.0（國考答案） | 現行給付辦法 |
|---|---|---|---|
| 老人 | 65 歲以上失能 | 65 歲以上失能；**僅 IADL 失能的獨居**；**衰弱老人** | 65 歲以上失能 |
| 原住民 | 55 歲以上山地原住民 | **55 歲以上**（含平地） | 55 歲以上 |
| 身心障礙 | 50 歲以上 | **49 歲以下也納入**（不限年齡） | 領身障證明 |
| 失智症 | 未單列 | **50 歲以上** | **不限年齡**（2026-01-01 起） |
| 急性後期 | 無 | 無 | **PAC 收案對象**（2026-01-01 起） |

- 情境判斷
   1. 48 歲偏癱、IADL 失能（身障）→ 符合；86 歲巴氏 < 60 → 符合；65 歲巴氏無失能但 IADL 失能且 SOF 衰弱指標(Study of Osteoporotic Fractures frailty index)3 項中 2 項 → 符合（衰弱）
   2. 48 歲植物人由家人照顧 → 符合；52 歲失智、臨床失智評分量表(Clinical Dementia Rating, CDR)2 分 → 符合
   3. 70 歲獨居但 ADL 滿分、無失能 → **不符合**

## 照管流程與 ABC {#care-management}

### 照管中心與長照需要等級 {#care-management-center}

- **照管中心**受理申請，**照專**到宅評估，核定**長照需要等級**與**給付額度**（給付辦法第 3 條）
   1. 等級分 **1–8 級**，第 1 級是未失能，**不給付**；第 2–8 級依等級給付（第 7 條）
   2. 照專要訂**照顧問題清單**，並依公告期間**複評**（第 5–6 條）
- **A 單位（社區整合型服務中心）個管**依問題清單與家庭需求**擬照顧計畫**，經照管中心核定後協調特約單位提供服務（第 4–5 條）
- 流程：照專評估核定 → A 個管擬計畫派案 → B 單位服務 → 定期複評

### 社區整體照顧服務體系 ABC {#abc}

| 層級 | 名稱 | 功能 |
|---|---|---|
| **A** | 社區整合型服務中心（長照旗艦店） | **擬照顧計畫**、連結與協調服務、個案管理 |
| **B** | 複合型服務中心（長照專賣店） | 提供**專業長照服務**（日照、居家服務、復健等），擴充服務量 |
| **C** | **巷弄長照站**（長照柑仔店） | 社區第一線：**健康促進、共餐、預防及延緩失能**、社會參與、臨時照顧（喘息） |

- 推動原則：**培植 A、擴充 B、廣布 C**；以居家、社區為主，機構為輔；由**中央、地方政府與民間**三方協力
- 主要目的：**整合與銜接服務資源**，提高可近性（不是減少照顧人力或節省成本）
- 輕型認知障礙者轉介到巷弄據點活動、共餐，延緩退化 → 屬**三段預防的限制殘障**（112-3 題答案）

## 給付與部分負擔 {#benefits}

### 四包錢 {#four-packages}

| 項目 | 內容（給付辦法第 8 條） | 額度（附表二） | 給付週期 |
|---|---|---|---|
| **照顧及專業服務**（B、C 碼） | 居家照顧、日間照顧、家庭托顧、**專業服務**（居家復能、護理指導、營養、進食與吞嚥、居家藥事等） | 2 級 10,020 元到 8 級 36,180 元／月 | 按月，可保留 6 個月內使用 |
| **交通接送**（D 碼） | **就醫、復健、透析**為限 | 依分區 1,680–2,400 元／月 | 按月 |
| **輔具及居家無障礙環境改善**（E、F 碼） | 輔具購置租賃、扶手、浴室改善等 | 第一組 **40,000 元／3 年**；第二組（含智慧科技輔具）60,000 元／3 年，2026-07-01 起 | 每 3 年 |
| **喘息服務**（G 碼） | 給家庭照顧者休息 | 2–6 級 **32,340 元**、7–8 級 **48,510 元**／年 | 每年 |

- 四類額度**不得互相流用**（第 7 條）
- 超過額度或非給付項目要**自費**（第 15 條）；居家服務時數不夠可以自費加買
- 聘僱外籍家庭看護工者：給付照顧及專業服務額度的 **30%**，用在居家照顧服務以外的項目（第 10 條）；2025-09-01 起可使用**日間照顧與家庭托顧**
- 第二組輔具（2026-07-01 起）：移位、移動、沐浴排泄、居家照顧床、安全看視等智慧科技輔具；其中居家無障礙改善 3 年內以 2 萬元為限

### 部分負擔 {#copayment}

| 長照身分別（第 14 條） | 照顧及專業服務 | 喘息 | 輔具及無障礙 | 交通接送（第一區到第四區） |
|---|---|---|---|---|
| 第一類：低收入戶等 | **0%** | 0% | 0% | 0% |
| 第二類：中低收老人津貼（第二款）或身障生活補助 | **5%** | 5% | 10% | 10%、9%、8%、7% |
| 第三類：一般戶 | **16%** | 16% | 30% | 30%、27%、25%、21% |

- 來源：給付辦法附表五（2025-06-19 修正）；照顧管理與政策鼓勵服務**免部分負擔**

### 喘息服務 {#respite}

- 屬**家庭照顧者支持服務**（長照服務法第 13 條），服務對象是**家庭照顧者**，以照顧者需求為主
- 型態：**居家喘息**、**機構喘息**（把被照顧者暫送機構）、**日間照顧中心喘息**、**小規模多機能夜間喘息**、**巷弄長照站臨托**；不同型態可合併使用
- 額度：2–6 級 32,340 元／年、7–8 級 48,510 元／年（附表二）
   1. 舊題：輕中度每年最多 **14 天**、重度最多 **21 天**（以每日 2,310 元計，額度相同）
- 不給喘息的情形：**沒有家庭照顧者**或可協助照顧的人、已依身障法接受臨時及短期照顧（給付辦法第 11 條）；外籍看護工**休假期間可申請**
- 情境：照顧者要外出探親一週、身心疲憊想旅遊、年長家屬體力不支但不願送機構 → **喘息服務**；照顧者孤單 → **情緒支持、支持團體**

## 長照 2.0 的擴充與創新服務 {#ltc-2}

### 小規模多機能 {#small-multifunction}

- 以**日間照顧**為基礎，擴充**居家服務**與**臨時住宿（夜間喘息）**，一站式、因地制宜
- 目的：發展多元社區照顧、符合社區需求、落實在地老化；**不含輔具租借**，也**不是為了老人再就業**

### 失智照護 {#dementia-services}

| 資源 | 功能 |
|---|---|
| **失智共同照護中心** | 協助疑似個案**確診**、個案管理、整合醫療與長照資源 |
| **失智社區服務據點** | 極輕度與輕度失智者的**認知促進**、共餐、安全看視、**照顧者支持團體與照顧訓練** |
| **團體家屋** | 失智者小規模共同生活的住宿照顧；國考答案「專屬失智症個案的照顧模式」 |
| 瑞智學堂、瑞智互助家庭 | 失智個案與家屬的家庭支持 |
| 機構失智專區 | 中度以上、具行動能力的失智者，可申請**特別處遇費**補助 |

- 失智症照護的其他內容見 [[dementia#taiwan-resources]]

### 預防及延緩失能 {#prevention}

- 對象：健康、亞健康、衰弱長者；在 C 巷弄長照站、關懷據點、文化健康站辦理
- 內容：**肌力強化運動**、**生活功能重建**、**認知促進**、**口腔保健與吞嚥**、**膳食營養**、社會參與（不包括職業訓練）

### 家庭照顧者支持 {#caregiver-support}

- 長照服務法第 13 條：資訊提供與轉介、**長照知識與技能訓練**、**喘息服務**、**情緒支持與團體服務轉介**
- 長照 2.0 建置**家庭照顧者支持服務據點**與支持中心；對象不限照顧 65 歲以上老人者
- 讓照顧者了解其他家庭的經驗、增加心理適應 → **家屬支持團體**

### 原住民族長照 {#indigenous}

- **原住民族文化健康站**：服務 **55 歲以上**原住民的健康、亞健康、衰弱與輕度失能長者，結合文化與部落特性
- 推動困境：**交通不便**、醫事與照顧**人力不足且流動率高**、**文化語言障礙**、青壯人口外移（照顧者**不足**）
- 慢性病照護可結合三段五級、部落社區健康營造、具文化特色的健康飲食

## 資源轉介情境 {#referral-scenarios}

| 情境 | 最適當的資源 |
|---|---|
| 下肢癱瘓、浴室太小輪椅無法迴轉 | **居家無障礙環境改善** |
| 四肢癱瘓，妻子每天擦澡很疲憊、浴室狹小 | 復健訓練＋**喘息服務**＋居家無障礙改善 |
| 中風後用助行器，上下樓與洗澡需部分協助 | **居家復能**＋**居家服務** |
| 獨居、輕度中風用助行器，ADL 80 分 | **送餐**＋**居家服務** |
| 肺氣腫住無電梯五樓、上下樓困難 | 送餐、居家服務、輔具中心；**不適合共餐**（要自己出門） |
| 糖尿病足潰瘍、行動不便、每月回診 | 輪椅輔具、**居家護理**指導、**交通接送**；照服員**不可清創** |
| 全身癱瘓、有氣切與尿管，照顧者無人輪替且技巧不熟 | **長期照顧管理中心**（一次評估整合多項服務） |

## 長照 3.0 {#ltc-3}

- 期間 **2026–2035**，接續長照 2.0；行政院 **2025-12-31 核定**（衛福部長照專區）
- 已施行的配套（給付辦法 2025-06-19 修正，衛福部新聞稿）
   1. **2025-09-01**：聘外籍看護家庭可用日照與家托；交通接送價格調整；營養照護調整
   2. **2026-01-01**：納入**年輕型失智且失能者**（失智不限年齡）與**急性後期整合照護**對象
   3. **2026-07-01**：輔具第二組與**智慧科技輔具**租賃（每 3 年 6 萬元）
- 衛福部 2025 年說明的方向（待核對）：健康促進、醫療與照顧整合、積極復能、提升機構量能、強化家庭支持、導入智慧照顧、落實安寧善終、人力專業發展
- 出院銜接長照：行政院 2026-04 新聞稿提到平均天數由 2017 年 51 天降到 2025 年 4 天，目標 2 天內（二手轉述，待核對）；出院準備見 [[home-care-discharge-planning#discharge-planning]]
- 組織：衛生福利部組織法 2026-09-30 修正公布，新增**社會發展及長期照顧署**，施行日待行政院定

## 常見混淆 {#pitfalls}

| 容易誤會 | 正確 | |
|---|---|---|
| A 個管核定失能等級 | **照專**核定等級與額度 | A 個管擬計畫 |
| 喘息全額補助 | 一般戶 **16%**、中低收 5%、低收 0% | |
| 喘息只在 C 據點 | 居家、機構、日照、小規機、C 據點都有 | |
| 應普設 A | **廣布 C** | 培植 A、擴充 B |
| 長照 2.0 失智對象 60 或 40 歲以上 | **50 歲以上**；現行不限年齡 | |
| 家托是到宅服務 | 到**照服員家** | |
