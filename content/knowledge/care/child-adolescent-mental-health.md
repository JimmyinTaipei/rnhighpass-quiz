兒童與青少年的精神健康問題要放在**發展階段**中看：同樣的行為在不同年齡意義不同，孩子也常用**行為與身體症狀**來表達情緒。這一頁先整理分類與照護原則，再介紹題數較少但常考的**學習障礙、抽搐症與妥瑞氏症、排泄障礙症、行為規範障礙症、青少年憂鬱、校園霸凌**。主要疾病各有獨立頁面：[[autism-spectrum-disorder]]、[[intellectual-disability]]、[[adhd]]、[[eating-disorders]]、[[anxiety-disorders#separation-anxiety]]

## 重點摘要 {#summary}

- **神經發展障礙症**：智能不足、**自閉症類群障礙症**、**ADHD**、**特定學習障礙症**、**抽搐症**（含妥瑞氏症）、溝通障礙；**遺尿症屬排泄障礙症**，不屬於這一類
- **內向性**問題（憂鬱、焦慮）容易被忽略；**外向性**問題（ADHD、行為規範障礙、對立反抗）多在與同儕互動與團體生活中被發現
- **學習障礙**：**智力正常**，但閱讀、書寫或數學等特定能力顯著落後；**妥瑞氏症**：**18 歲前**、**多種動作抽動＋至少一種聲語抽動**、**超過 1 年**，**不影響智能**
- **遺尿症**：**5 歲以後**仍反覆尿濕；**行為規範障礙症**：持續侵犯他人權利與違反重要社會規範，護理要**設限**並以正向增強為主
- 照護原則：**第一次評估同時包含孩子與家屬**；可用圖畫、遊戲、閱讀等媒介表達；**有自殺或傷人危險時保密有例外**，要告知家屬

### 國考常考點 {#exam-points}

- **遺尿症不屬於神經發展障礙症**（屬排泄障礙症）；智能不足、自閉症、ADHD 屬於
- 遺尿症是 **5 歲以後**仍反覆尿濕衣服或床
- 「很聰明、人緣好，但認字差、文章表達不清楚」→ **閱讀障礙症**；閱讀障礙**不是**智力偏低造成
- 6 歲、一年多來不自主眨眼、扮鬼臉、聳肩、發出「哼哼」聲 → **妥瑞氏症**；**18 歲前**出現；**聲語型抽動是必要條件**，不罕見；**不影響智能**，不需要特殊教育
- 妥瑞氏症的護理：**正向心理支持**、教導**放鬆**、發掘**潛能與專長**建立自信；可能合併 ADHD、強迫症；可能出現**回音性言語**
- **行為規範障礙症**的護理：對非適應性行為**設限**；不以處罰為主；不容許干擾行為；可做遊戲治療
- 侵擾行為、衝動控制及行為規範障礙症是在**與同儕互動**中被發現；語言障礙症多在 3 歲前被發現；兒童的精神症狀**與年齡、發展階段有關**
- 青少年照護：可用**圖畫**引導表達、可推薦**閱讀**；**有自殺危險時不能再遵守對家人保密的約定**；**第一次評估需同時包含病人與家屬**
- **青少年憂鬱症**屬**內向性**障礙，女性多、最嚴重的合併症是**自殺**；藥物首選 **SSRI**，不是 TCA；輕度不做 ECT
- **校園霸凌**：個人或集體**持續**以言語、肢體、網路等方式**故意**欺負他人；受霸凌者可能轉而霸凌更弱勢的人；成績好也可能被霸凌；網路霸凌**不一定**要兩次以上

## 分類與照護原則 {#overview}

### DSM-5 的分類 {#classification}

| 類別 | 包含的疾病 |
|---|---|
| **神經發展障礙症** | **智能不足**、溝通障礙（語言障礙症等）、**自閉症類群障礙症**、**ADHD**、**特定學習障礙症**、動作障礙症（含**抽搐症與妥瑞氏症**） |
| **排泄障礙症** | **遺尿症**、遺糞症 |
| **侵擾行為、衝動控制及行為規範障礙症** | 對立反抗症、**行為規範障礙症** |
| **焦慮症** | **分離焦慮症**、選擇性不語症 |
| **餵食及飲食障礙症** | 厭食症、暴食症、異食症等 |
| 情緒障礙 | 兒童與青少年憂鬱症、侵擾性情緒失調症 |

1. 兒童精神疾病的病徵**與年齡與發展階段有關**
2. 發現的時機
   1. 語言障礙症、自閉症：多在**幼兒期**（3 歲前）
   2. 輕度智能不足、學習障礙：多在**入小學後**課業變難時
   3. 行為規範障礙等外向性問題：多在**與同儕互動**、團體生活中
3. **內向性**(internalizing)：憂鬱、焦慮、退縮，情緒向內，容易被忽略
4. **外向性**(externalizing)：ADHD、對立反抗、行為規範障礙，行為向外，容易引人注意

### 兒童與青少年的照護原則 {#principles}

1. **評估**
   1. **第一次評估同時包含孩子與家屬**，澄清就診原因與期待
   2. 也要單獨與青少年會談，給予表達的空間
   3. 從家庭、學校、同儕多方收集資料
2. **溝通與治療媒介**
   1. 依發展階段使用**遊戲、圖畫、說故事、閱讀治療**等媒介引導表達情緒
   2. 不要認為圖畫或書籍會讓青少年覺得被輕視
3. **保密與安全**：尊重青少年的隱私，但有**自殺、傷人或受虐**等重大安全疑慮時，**保密有例外**，要告知家屬與相關人員
4. **家庭參與**：親職教育、家庭治療
5. **學校合作**：與老師、輔導老師、學校護理師共同擬定計畫
6. 行為問題以**正向增強**為主，設定清楚一致的規範

## 特定學習障礙症 {#learning-disorder}

1. **智力正常或以上**，但**閱讀、書寫或數學**等特定學業技能，顯著低於年齡與智力應有的程度
2. 即使已提供針對性的協助，學習困難仍持續**至少 6 個月**
3. 不是因為智力不足、感官障礙、缺乏教育機會或情緒問題造成
4. **閱讀障礙**最常見：認字困難、閱讀慢且錯誤多、理解困難、常合併**書寫表達**錯誤
5. 常在**入學後**被發現，常與 ADHD 共病
6. 處置：特殊教育與補救教學、提供替代方式（聽讀、延長考試時間）、增強自信，避免被貼上「懶惰」或「笨」的標籤

## 抽搐症與妥瑞氏症 {#tic-disorders}

1. **抽動(tic)**：突然、快速、重複、**不自主**、無節律的動作或發聲
   1. **動作型**：眨眼、扮鬼臉、聳肩、搖頭、甩頭
   2. **聲語型**：清喉嚨、吸鼻子、「哼哼」聲、動物叫聲；少數有**穢語**、**回音性言語**
2. **妥瑞氏症**的條件（DSM-5-TR 摘要）
   1. **多種動作抽動**加**至少一種聲語抽動**（不必同時出現）
   2. 抽動持續**超過 1 年**
   3. **18 歲前**發病，常在學齡期（約 5–7 歲）開始
3. 特點
   1. 壓力、疲勞、興奮時加重，專注於喜歡的事或睡眠時減少
   2. 可短暫忍住，但會有想動的衝動
   3. **不會影響智能**，本身也不造成腦部傷害；學習困難多與合併的 ADHD 或強迫症有關
   4. 與基底核與多巴胺系統有關；興奮劑可能加重抽動
4. 治療：衛教與心理支持；**習慣反轉訓練**等行為治療；症狀嚴重影響生活時用藥（例如多巴胺拮抗劑、α2 促效劑）
5. 護理
   1. 評估孩子對疾病的認知，給予**正向心理支持**
   2. 教導**放鬆**，減少抽動引起的疲倦
   3. 教導家人與老師**不要責罵或要孩子停止**，越注意越緊張
   4. 協助同學了解，減少嘲笑；發掘**潛能與專長**，建立自信
   5. 盡量在一般班級接受教育

## 排泄障礙症 {#elimination}

1. **遺尿症**
   1. 生理或心智年齡**至少 5 歲**以後，仍反覆將尿排在床上或衣服上
   2. 頻率約每週 2 次、持續 3 個月以上，或造成明顯困擾（DSM 條件）
   3. 分夜間型（最常見）、日間型；原發性（從未持續乾過）與續發性（曾乾過一段時間後又尿床，常與壓力事件有關）
   4. 先排除泌尿道感染、糖尿病等身體原因
   5. 處置：睡前限水、睡前排尿、**尿床警報器**、正向增強（乾的夜晚給貼紙）；必要時藥物(desmopressin)；**不責罵、不羞辱**
2. **遺糞症**：**4 歲以後**反覆在不適當處排便，常與**便秘**溢流有關；處理便秘、建立如廁習慣、正向增強

## 行為規範障礙症 {#conduct-disorder}

1. 持續地**侵犯他人的基本權利**或**違反重要的社會規範**：過去 **12 個月**內符合 15 項中至少 **3 項**、最近 **6 個月**至少 1 項；**10 歲前**出現任一症狀為兒童期發病型
   1. 攻擊人或動物（霸凌、打架、虐待動物）
   2. 破壞財物、縱火
   3. 欺騙或偷竊
   4. 嚴重違規（逃家、逃學、夜不歸）
2. **對立反抗症**：對權威者生氣、易怒、爭辯、反抗、報復，但沒有嚴重侵犯他人；可能發展成行為規範障礙
3. 危險因子：衝動與 ADHD、家庭衝突與不一致的管教、受虐、同儕影響
4. 成年後部分會發展成**反社會型人格障礙症**（見 [[personality-disorders#cluster-b]]）
5. 護理
   1. 對非適應性行為**明確設限**，讓孩子知道行為的後果
   2. 規範一致、獎懲清楚，以**正向增強**為主，處罰易引發反抗與敵意
   3. 不容許因挫折出現的干擾行為，改教導適當的挫折因應
   4. 可用遊戲治療、社交技巧訓練、問題解決訓練
   5. **家庭治療**：家長抗拒（「醫師弄錯對象」）時，用合作的態度「**讓我們一起來幫助孩子**」，不要指責家長（見 [[group-family-therapy#family-nursing]]）

## 校園霸凌 {#bullying}

1. **定義**（依教育部校園霸凌防制準則的概念整理）：個人或集體**持續**以言語、文字、圖畫、肢體動作、電子通訊或網路等方式，**直接或間接**、**故意**貶抑、排擠、欺負、騷擾或戲弄他人，使對方處於有敵意或不友善的環境，造成身心或財產上的損害或影響學習
   - **校園霸凌**的範圍：相同或不同學校的校長、教師、職員、工友、學生**對學生**，在**校園內或校外**發生的霸凌（113 年修正條文）
2. 型態：肢體、言語、關係（排擠）、性、反擊型、**網路霸凌**
3. 重點
   1. **任何人**都可能被霸凌，成績好或特質突出的孩子也可能
   2. 長期受霸凌者可能**轉而霸凌比自己弱勢的人**（反擊型）
   3. 網路霸凌傳播快、影響範圍廣，**不一定**要發生兩次以上才算
4. 受害者的表現：拒學、成績下降、身體不適、退縮、焦慮憂鬱、自傷自殺
5. 處置
   1. 先確保**安全**，同理並傾聽，不責怪受害者
   2. 依規定通報學校，啟動防制機制
   3. 危機處置技巧：**宣洩、澄清、再保證**，**不可忽略**受害者的感受
   4. 同時輔導受害者、霸凌者與旁觀者

## 慢性病青少年的心理社會照護 {#chronic-illness}

1. 青少年重視**外表**與**同儕關係**、追求**獨立與自主**
2. 慢性病（例如 SLE、癌症、糖尿病）與治療（類固醇造成月亮臉、痘痘）會影響外表與自我形象
3. 護理
   1. **誠實**說明疾病與治療對外觀的影響，不要說「影響不大」來安撫
   2. 鼓勵與**同儕保持聯繫**
   3. 主動評估疼痛，避免因隱瞞而未處理
   4. **傾聽、支持、不評論**
   5. 讓青少年參與治療決策，培養自我照顧
