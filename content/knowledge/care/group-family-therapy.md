**團體治療**是由治療者帶領一群有相似或不同問題的成員，透過成員之間的互動來改變；**家庭治療**則把整個家庭當成一個系統，不把問題放在某一個人身上。兩者都以**人際互動**為治療媒介。個別、行為與認知治療見 [[individual-cognitive-behavioral-therapy]]，環境與活動治療見 [[milieu-therapy]]，相關理論背景見 [[psychodynamic-theories]]

## 重點摘要 {#summary}

- 團體治療的療效來自 **Yalom 療效因子**：**灌注希望、普遍性、傳達訊息、利他、原生家庭經驗再現、發展社交技巧、模仿行為、人際學習、凝聚力、情緒宣洩、存在因素**
- 團體發展分**初始期、工作期、結束期**：**凝聚力**是重要因子；工作期要鼓勵誠實表達並避免互相攻擊，**結束期**才處理分離
- 型態多樣：**會心團體**（言語表達、探討現在與過去情緒）、**心理演劇**、**懷舊團體**（老人）、**閱讀治療**、娛樂與職能治療團體
- **家庭治療**把家庭當成**動態的開放系統**，問題是**系統的產物**，可**多世代傳遞**，不必全家到齊才能進行
- 主要學派：**鮑恩的系統性**（自我分化、三角關係）、**米紐慶的結構性**（次系統、界線）、**策略性**（解決溝通問題）；目標是**改善家庭功能與溝通**

### 國考常考點 {#exam-points}

- **普遍性**：發現自己的問題「不特別」、別人也有；**灌注希望**：看到他人改善而有信心；**凝聚力**：歸屬感、接納；**利他**：幫助別人提升自尊；**人際學習**：從回饋了解自己的互動模式；**存在因素**：面對孤獨、責任與無常
- 團體**最佳人數約 6–8 人**（非 3–5 人）；同質性與異質性、開放性與封閉性團體**沒有絕對好壞**
- **工作期**：避免互相攻擊、鼓勵誠實表達、維持凝聚力；「協助成員準備與團體分離」屬**結束期**
- 成員因爭執**離場**：**不中斷**團體、重申規範、照顧害怕的成員、鼓勵表達**此時此刻**的感受
- **老人回顧過去成功經驗、翻老照片提升自尊 → 懷舊治療**；**用語言探討過去與現在情緒、重建人格 → 會心團體**
- 家庭**次系統**屬**內在結構**；**文化、社經地位、宗教**屬外在結構
- **鮑恩**目標是**提高**自我分化；**三角關係**可存在任何三個成員，不限夫妻或手足；**策略性家庭治療**以**解決溝通問題**為導向
- 家庭治療的目的：**改善家庭功能、改善成員互動、協助家庭改善問題**；**不是矯正個人性格**；著重**此時此刻**，要訂目標，可安排家庭作業

## 團體治療 {#group-therapy}

### 團體的基本原則 {#group-principles}

1. 團體由**領導者**帶領，成員間的互動是主要的治療因素
2. 人數：一般小團體約 **6–8 人**（也有 6–10 人的說法），3–5 人偏少
3. 團體類型沒有絕對優劣，要依治療目標與環境決定
   1. **同質性**團體（症狀相似）與**異質性**團體（背景多元）各有優缺點
   2. **開放性**團體（成員可中途加入）與**封閉性**團體（固定成員）也依目標選擇
4. **團體規範**：明示的規定或默契的期待
   1. 可用公開陳述的形式表達
   2. 功能：促進團體目標實現、提供互動準則、協助處理人際衝突
   3. 作用是建立凝聚力與互相依賴合作，不是形成團體的「獨立自主」
5. 護理人員運用團體時，是以**人際關係模式**為基礎：成員感謝彼此接納與信任，體驗到人與人可以互相信賴

### Yalom 的療效因子 {#curative-factors}

| 因子 | 意思 | 情境例子 |
|---|---|---|
| **灌注希望** instillation of hope | 看到他人改善或成功，產生信心與期待 | 「我以前也睡不好，後來準時吃藥、按時睡，現在睡得很好」 |
| **普遍性**（共通性、普及性） universality | 發現自己的問題並不特殊，別人也有 | 治療者問：「大家有沒有類似的經驗？」 |
| **傳達訊息** imparting information | 從治療者或成員得到衛教與建議 | 解說疾病、藥物與因應方式 |
| **利他** altruism | 透過幫助他人，覺得自己有價值 | 「幫助別人讓我變得更重要，也更看重自己」 |
| **原生家庭經驗再現** corrective recapitulation | 團體重現早年家庭互動，並有機會修正 | 對領導者像對父母一樣依賴或對抗 |
| **發展社交技巧** socializing techniques | 在團體學習並練習人際互動技能 | 練習表達需求與傾聽 |
| **模仿行為** imitative behavior | 觀察並學習他人有效的適應行為 | 學習他人處理壓力的方式 |
| **人際學習** interpersonal learning | 從成員的回饋了解自己的互動模式與盲點，並修正 | 「他指出我講話的態度讓人不舒服，我才發現自己的問題」 |
| **凝聚力** cohesiveness | 感受到接納、歸屬感與彼此的共同點 | 成員覺得「這裡是我的團體」 |
| **情緒宣洩** catharsis | 在安全環境中表達與釋放壓抑的強烈情緒 | 哭泣、說出長期壓抑的憤怒 |
| **存在因素** existential factors | 面對孤獨、死亡、責任、無常，學會為自己的人生負責 | 「子女忙碌，我要學習自己照顧自己」 |

:::note[爭議題：依考選部公布答案]
108-2_PC_011 病人說「別人的回饋幫助我了解如何表達感受，才不會造成不好的後果」，考選部公布答案為**情緒宣洩**；就 Yalom 的分類，這段描述更貼近**人際學習**。作答以公布答案為準，但學習時請記住：**由回饋了解並修正互動模式 → 人際學習**

### 團體的發展階段與領導者角色 {#stages}

| 階段 | 重點 | 領導者的角色 |
|---|---|---|
| **初始期** | 建立信任、說明目的與規範、成員互相認識 | 營造安全氛圍、建立規範 |
| **工作期** | 處理衝突、深入自我探索與改變 | 避免成員互相攻擊、鼓勵誠實表達、維持凝聚力 |
| **結束期** | 處理分離與焦慮、統整學習 | 協助成員準備與團體分離、回顧與統整 |

1. 「協助成員準備與團體分離」是**結束期**的任務，不屬於工作期
2. 成員因爭執憤而離場、團體瀰漫不安時
   1. 不要中斷團體去個別安撫
   2. 重申團體規範
   3. 允許害怕的成員暫時離開
   4. 鼓勵成員表達**此時此刻**的感受，把衝突當成討論的素材

### 團體治療的型態 {#group-types}

| 型態 | 特色 | 適用情境 |
|---|---|---|
| **心理治療團體**（會心團體偏重此時此刻的真誠交流） | 用**語言**表達，探討**現在與過去**的情緒與心理問題，促進**人格重建**與行為修正 | 需要自我覺察、情緒探索者 |
| **心理演劇**（心理劇） | 以角色扮演與情境模擬宣洩情緒、處理衝突 | 情緒難以言語表達者 |
| **懷舊團體**（懷舊治療） | 引導**老人**回顧並分享過去的經驗（例如翻閱家族相簿），重整生命事件、提升自尊與自信 | 老年憂鬱、常有「時不我與」感嘆者、輕中度失智 |
| **閱讀治療** bibliotherapy | 閱讀書籍後分享對故事人物的看法與感受，間接處理自己的經驗 | 兒童與青少年，例如地震後的創傷經驗 |
| **說故事／自創故事** | 口述故事，或由成員自己編故事，藉故事投射內在感受 | 兒童、青少年 |
| **娛樂治療團體** | 以休閒活動促進社交與減壓 | 社交退縮者 |
| **職能治療團體** | 透過工作與生活技能活動訓練功能 | 功能退化、需復健者 |
| **健康指導團體** | 提供衛教知識與健康促進資訊 | 疾病與藥物衛教 |
| **生物回饋團體** | 用儀器監測生理訊號，學習放鬆 | 壓力與焦慮的生理反應 |

:::exam[國考重點]
老人翻老照片回憶成功經驗 → **懷舊治療**；與老人討論過去成功經驗提升自尊 → 懷舊治療；以閱讀書籍後在團體分享 → **閱讀治療**；用言語探討過去與現在的情緒問題、人格重建 → **會心團體**
:::

## 家庭治療 {#family-therapy}

### 基本概念 {#family-concepts}

1. 以**系統理論**為基礎：家庭是**動態的開放系統**，成員互相影響，一個人改變會牽動其他人
2. 偏差行為或心理問題是**整個家庭系統的產物**，不是個人單一的問題，**被指認的病人**只是家庭問題的表現
3. 家庭問題與溝通模式可以**世代間傳遞**
4. 實務重點
   1. 不一定要集合**全體**家人，關鍵成員參與即可
   2. 著重家庭系統的結構、互動模式與功能，不是只看全家的病態溝通
   3. 也會處理家庭危機，不只是諮商與行為修正
5. 目的
   1. 改善家庭功能
   2. 改善家庭成員的互動與溝通
   3. 協助家庭改善目前面臨的問題
   4. 不是矯正個人性格的偏差（那是個別治療）

### 家庭評估 {#family-assessment}

1. 進行家庭治療前要收集的資料
   1. 家庭的**發展階段與過程**
   2. 家庭的**因應能力**
   3. 家庭的**內、外在結構**
   4. 家庭的功能（例如社會化功能、溝通、支持）
2. 結構的區分

| 類別 | 內容 |
|---|---|
| **內在結構** | 家庭成員組成、**次系統**（夫妻、父母、手足）、界線、權力、角色、溝通模式 |
| **外在結構** | **文化、宗教、社經地位**、延伸家庭、社區與社會系統 |

### 主要學派 {#schools}

| 學派 | 代表 | 核心概念 | 治療重點 |
|---|---|---|---|
| **系統性**（家庭系統） | **鮑恩 Bowen** | **自我分化**、**三角關係**、核心家庭情緒系統、家庭投射歷程、多世代傳遞、情緒截斷 | **提高**成員的自我分化；打破三角關係 |
| **結構性** | **米紐慶 Minuchin** | **次系統、界線**（糾結、疏離、清楚）、權力階層 | 重整家庭結構，調整過鬆或過緊的界線 |
| **策略性** | 海利等 | 症狀是**溝通不良或權力失衡**的表現 | 以**解決問題與改善溝通**為導向，使用具體策略與指令 |
| **分析性**（精神動力） | — | 無意識衝突、移情與早年家庭經驗 | 探討早年家庭經驗對現在關係的影響 |
| **經驗性／溝通** | 薩提爾 Satir | 溝通姿態與自尊 | 促進一致、清楚的溝通 |
| **家庭依附關係治療** | — | 以依附關係的安全感為核心 | 修復家庭中的依附與信任 |

1. 鮑恩的**三角關係**：兩人緊張時拉入第三人（或一件事、一個物）來緩和，可存在任何三個成員之間
2. 鮑恩的目標是**提高**自我分化，不是降低

### 常見的家庭互動概念 {#family-patterns}

| 概念 | 說明 |
|---|---|
| **雙重束縛** double-bind | 同時收到互相矛盾的訊息，又無法逃離也無法指出矛盾，例如嘴上說愛，行為卻拒絕 |
| **假性和諧** | 表面維持和諧，掩蓋真實的衝突與差異 |
| **自我界域** ego-boundary | 個人與他人之間的心理界線，界線不清會形成過度依賴或糾結 |
| **三角關係** triangles | 第三者被拉入二人的緊張 |
| **代罪羔羊** | 家庭把衝突與問題全部歸咎於某一位成員 |
| **婚姻分裂與偏斜** | 李茲用來解釋家庭與思覺失調症的關係（見 [[psychodynamic-theories#sullivan]]） |

1. 考題情境：邊緣型人格障礙症的女兒經濟依賴母親，心情好時撒嬌，不順意就以割腕威脅
   1. 適合處理：**自我界域**、**雙重束縛**、**假性和諧**
   2. 最不適宜：**三角關係**，因為情境中只有母女二人，沒有第三者被拉入

### 護理與治療原則 {#family-nursing}

1. 治療目標與方式
   1. 要有**明確的治療目標**
   2. 著重**此時此刻**的互動，不是只討論過去
   3. 可以安排**家庭作業**
   4. 核心是**促進有效的溝通**
2. 與家屬的溝通
   1. 家屬抗拒或誤會時，用**合作與支持**的態度，例如「讓我們一起來幫助小賀」
   2. 不要指責（「小孩的病，通常是大人的問題」），也不要用道德壓力（「這是你的責任與義務」）
   3. 先同理家屬的壓力與焦慮
3. 家庭互動的護理措施（例：住院病人每次母親探視就吵著要回家，母親威脅「再吵就不來了」）
   1. 適當的**支持與教導**
   2. 著重**現在情境**的互動
   3. 可從症狀切入討論
   4. 不採用家屬原有的威脅方式
4. 適合安排家庭治療的情境
   1. 症狀（例如幻聽）與家庭人際衝突相關，如思覺失調症病人與母親的男友爭執
   2. 物質使用障礙症病人的家庭：診斷家庭問題，澄清成員的角色、期待、責任與感受
   3. 兒童行為問題，需要家長一起參與
