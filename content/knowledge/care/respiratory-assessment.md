呼吸評估從**測量呼吸**開始，接著是視、觸、叩、聽的身體評估，再配合血氧、血氣、影像與侵入性檢查。構造見 [[respiratory-anatomy]]，血氣判讀見 [[abg]]，呼吸調控見 [[gas-exchange-transport#control]]

## 重點摘要 {#summary}

- 測呼吸時**不要讓病人知道**(會改變呼吸)：量完脈搏手指不移開，接著數呼吸
- 觀察**速率、深度、節律、費力程度**、呼吸聲、膚色、輔助肌；規則時數 30 秒乘 2，**不規則、生命徵象不穩定、嬰兒數滿 1 分鐘**
- 正常速率：成人與青少年 **12–20**、學齡兒童 18–25、幼兒 22–37、嬰兒 30–53 次／分；新生兒以**腹式呼吸**為主、節律不規則
- **庫斯毛耳氏**＝深快規則(**DKA**、代謝性酸中毒)；**陳施氏**＝漸深漸淺再暫停(**臨終**、心衰竭)；**畢歐氏**＝不規則夾雜暫停(腦部病變)；**喟嘆式**＝臨終、大出血
- 呼吸變快：大出血、血壓下降、缺氧、發燒(見 [[body-temperature]])、焦慮、疼痛；變慢：**顱內壓升高**、**鴉片類**、體溫下降；男性比女性略慢
- 異常呼吸音：**爆裂音(囉音)**＝肺泡有液體；**乾囉音**＝大呼吸道分泌物；**哮鳴音**＝下呼吸道狹窄；**喘鳴音(stridor)**＝**上呼吸道阻塞，要緊急處理**
- 缺氧最早的表現是**躁動不安**；**發紺是晚期**；SpO₂(Peripheral oxygen saturation) 正常 **95–100%**
- **支氣管鏡**後禁食到**作嘔反射恢復**；少量血絲痰正常
- **胸腔穿刺**：坐床緣、頭與手趴在床旁桌上；術後監測**氣胸**、復張性肺水腫、出血、低血壓

### 國考常考點 {#exam-points}

- 測呼吸「讓病人知道」是錯的；測量前確認病人沒有剛運動或進食；生命徵象不穩定要測 1 分鐘
- 6 個月嬰兒：**先數呼吸、再測心尖脈**(說「先測心尖脈」是錯的)；觀察腹部起伏；節律不規則是正常的；5 個月大約 30–40 次／分
- 正常新生兒採**腹式呼吸**(說「胸式呼吸」是錯的)，速率 30–60 次／分，可有短暫的呼吸暫停
- 庫斯毛耳氏呼吸是**深快且規則**(說「節律不規則」是錯的)；陳施氏呼吸不是「淺而慢的規則型態」；畢歐氏呼吸**不規則**
- **喟嘆式呼吸**見於**臨終**或**大出血**；臨終最常見**陳施氏呼吸**；腦部損傷常見**畢歐氏與陳施氏(潮式)呼吸**
- 腦壓過高 → **呼吸過慢**；說「腦壓升高呼吸變快」是錯的
- 車禍後呼吸急促、血壓下降 → 最可能是**內出血**；大出血**呼吸加快**；胸腔積水、急性疼痛呼吸**不會變慢**；年紀越大呼吸**越慢**
- 陳施氏呼吸是**客觀徵象**，不是主觀症狀
- 支氣管音出現在**下肺區**是異常(實質化)；可清楚聽到病人說的話＝**支氣管語音**；胸廓左右徑大於前後徑是**正常**
- 吸氣期、不連續、含水分的大聲呼吸音＝**囉音(爆裂音)**；**哮吼音(stridor)**＝上呼吸道發炎或異物阻塞
- 拔除人工氣道後出現**喘鳴**要緊急處理(喉頭水腫)；呼吸困難最不常見的徵象是**咳血**
- 早期氧合不足：**躁動不安**(不是發紺、低血壓或心跳變慢)
- 血氧計 SpO₂ 正常 **95–100%**(單位是 %，不是 mmHg)；感應器位置要**定期更換**；顯示心跳與實際脈搏相符才準確
- 支氣管鏡後：**作嘔反射恢復才可進食**；不用抬高 80–90 度、不用臥床 4 小時、少量血絲痰**不需立即通知醫師**；不常規給 Atropine
- 胸腔穿刺前：**坐在床緣、頭與手趴在床旁桌上**；不需禁食、不需常規給 Atropine；術後合併症**不包括「凝血功能變差」**；術後 **SpO₂ 88%** 最需緊急處理
- 火場病人離開時沒有呼吸異常，**不代表**沒有吸入性灼傷
- 護理問題的優先順序：**呼吸問題(無效性呼吸型態、呼吸困難)最優先**；呼吸困難病人可用**床上桌**趴著維持舒適姿勢

## 呼吸的測量 {#measurement}

1. 時機：病人休息 5–10 分鐘後；剛運動、進食、吸菸、情緒激動後要等一下再測
2. 方法
   1. 量完橈動脈脈搏後，**手指仍放在手腕上**，假裝繼續量脈搏，同時看胸部或腹部起伏
   2. 一吸一吐算 1 次
   3. 規則時數 30 秒 × 2；**不規則、生命徵象不穩定、嬰幼兒**數滿 **1 分鐘**
3. 同時觀察
   1. 速率、**深度**(淺、正常、深)、**節律**(規則與否)
   2. 費力程度：輔助肌、鼻翼搧動、凹陷、說話是否斷斷續續
   3. 呼吸聲(鼾聲、喘鳴)、膚色與唇色、意識、姿勢
4. 嬰幼兒
   1. 在**安靜時先數呼吸**，再做會讓孩子哭鬧的檢查(心尖脈、量耳溫)
   2. 嬰兒以**腹式呼吸**為主，看**腹部**起伏
   3. 節律不規則是正常的

| 年齡 | 正常呼吸速率(次／分) |
|---|---|
| 新生兒 | 30–60(國考答案)；腹式呼吸、節律不規則 |
| 嬰兒 | 30–53 |
| 幼兒 | 22–37 |
| 學齡兒童 | 18–25 |
| 青少年到成人 | **12–20** |

嬰兒到成人的範圍引自 OpenStax Fundamentals of Nursing，7.2；新生兒為國考常用值

- 新生兒的**週期性呼吸**：短暫停頓是正常的；停止呼吸 **20 秒以上**，或較短但合併**心跳變慢、發紺或血氧下降**，才是**呼吸暫停**(來源：[AAP. Apnea of Prematurity, Pediatrics 2016](https://doi.org/10.1542/peds.2015-3757))，早產兒照護留第 16 輪

## 影響呼吸速率的因素 {#factors}

| 因素 | 呼吸變化 |
|---|---|
| 年齡 | **越小越快**，年紀大較慢 |
| 性別 | **男性比女性略慢** |
| 運動 | 深而快 |
| 發燒 | 變快；體溫下降變慢 |
| **大出血**、**血壓下降**、休克 | **變快**(組織缺氧、壓力受器) |
| 缺氧、高海拔 | 變快 |
| 焦慮、**急性疼痛** | 變快 |
| 胸腔積水、肺部疾病 | 變快變淺 |
| **顱內壓升高** | **變慢**(合併血壓上升、脈搏變慢＝庫欣氏三病徵)，見 [[increased-icp]] |
| **鴉片類**、鎮靜安眠藥 | **變慢變淺**，見 [[opioids]] |

## 呼吸型態 {#patterns}

![常見的呼吸型態：正常、呼吸過速、呼吸過慢、庫斯毛耳氏、陳施氏、畢歐氏、喟嘆式的波形示意](/knowledge-images/breathing-patterns.svg)

| 型態 | 特徵 | 常見原因 |
|---|---|---|
| 呼吸過速 | 成人每分鐘 > 20 次 | 發燒、缺氧、焦慮、疼痛、出血 |
| 呼吸過慢 | 成人每分鐘 < 12 次 | **顱內壓升高**、鴉片類過量、低體溫 |
| 呼吸暫停 | 呼吸停止 | 呼吸道阻塞、心肺停止、藥物 |
| 換氣過度 | 深而快，CO₂ 下降 | 焦慮、待產，見 [[ventilation-mechanics#hyper-hypoventilation]] |
| **庫斯毛耳氏呼吸** | **深而快、規則**，常超過每分鐘 20 次 | **糖尿病酮酸中毒**、尿毒症等**代謝性酸中毒**(把 CO₂ 呼出來代償) |
| **陳施氏(潮式)呼吸** | 由淺變深、再由深變淺，接著**呼吸暫停**，週期出現 | **臨終**、心衰竭、雙側大腦或間腦病變、腦壓升高 |
| **畢歐氏呼吸** | 深淺不一、**完全不規則**、夾雜暫停 | 腦膜炎、**腦幹(延腦)病變**、腦傷 |
| **喟嘆式呼吸** | 正常呼吸中夾雜**深長的嘆息** | **臨終**、**大出血**、焦慮 |
| **端坐呼吸** | 平躺時喘，**坐起來**才好呼吸 | 心衰竭、肺水腫、**COPD**、氣喘、大量腹水 |
| 噘嘴式呼吸 | 吐氣時嘴唇噘起 | **COPD** 自己發展出來的代償(維持小氣道打開) |

- 腦部病變時的呼吸型態與定位見 [[brain-anatomy#brainstem-lesions]]
- 不會採端坐呼吸的是**腦幹腫瘤**(不是心肺或腹部問題)

## 身體評估：視、觸、叩、聽 {#physical-exam}

### 視診 {#inspection}

1. 胸廓形狀
   1. 正常成人**左右徑大於前後徑**(約 2：1)
   2. **桶狀胸**：前後徑增加，接近 1：1，見於**肺氣腫**、COPD
   3. 漏斗胸、雞胸、脊柱側彎：可能造成侷限性通氣
2. 胸廓擴張：吸氣時兩側應**對稱**往外擴張；一側擴張變小 → 該側有氣胸、肋膜積水、肺擴張不全或疼痛
3. 費力呼吸的徵象：**輔助肌**(胸鎖乳突肌、斜角肌)、**鼻翼搧動**、**肋間或胸骨凹陷**(兒童明顯)、**三腳架姿勢**(身體前傾、雙手撐膝或桌)、說話要分段
4. 指甲：**杵狀指**(甲床與指甲角度消失)見於慢性缺氧，例如支氣管擴張症、肺癌、發紺型先天性心臟病
5. 膚色：中心性發紺看嘴唇、舌頭；周邊性發紺看指甲、四肢

### 觸診與叩診 {#palpation-percussion}

| | 觸覺語顫(請病人說「一、二、三」) | 叩診音 |
|---|---|---|
| 正常肺 | 有 | **反響音** |
| **實質化**(肺炎) | **增強** | **濁音** |
| **肋膜積水** | 減弱或消失 | **濁音、實音** |
| **氣胸** | 減弱或消失 | **過度反響音** |
| **肺氣腫** | 減弱 | **過度反響音** |
| 肺擴張不全 | 減弱 | 濁音 |

- 叩診正常的肺是反響音；**肺部基底部反響音是正常**；胃泡處是鼓音

### 正常呼吸音 {#breath-sounds}

| 呼吸音 | 正常位置 | 特徵 |
|---|---|---|
| 氣管音 | 頸部氣管上 | 很響、粗糙 |
| **支氣管音** | 胸骨柄 | 響、音調高；**呼氣比吸氣長** |
| 支氣管肺泡音 | 前胸第 1–2 肋間、背部兩肩胛骨之間 | 中等；吸氣與呼氣差不多長 |
| **肺泡音** | **大部分肺野**(周邊、肺底) | 柔和、音調低；**吸氣比呼氣長** |

- 在**肺周邊或下肺區**聽到支氣管音是**異常**：代表肺組織實質化(肺炎)，聲音傳導變好
- 呼吸音**減弱或消失**：氣胸、肋膜積水、肺擴張不全、嚴重氣喘(安靜胸，非常危險)、氣管內管插太深(單側)

### 異常呼吸音 {#adventitious}

| 呼吸音 | 聲音特徵 | 時相 | 代表 | 例子 |
|---|---|---|---|---|
| **爆裂音**(**囉音**、濕囉音) | **不連續**、細碎劈啪聲，像頭髮在耳邊搓 | 多在**吸氣** | 塌陷的小氣道或**肺泡有液體**，吸氣時突然打開 | **肺水腫**、心衰竭、肺炎、肺纖維化、肺擴張不全 |
| **乾囉音** | 連續、低音調、像打鼾 | 吸氣與呼氣 | **大呼吸道有分泌物** | 支氣管炎；**咳嗽後可能改變或消失** |
| **哮鳴音**(喘鳴音、wheeze) | 連續、高音調、像吹哨 | 多在**呼氣** | **下呼吸道狹窄** | **氣喘**、COPD |
| **哮吼音**(stridor) | 高音調、尖銳 | 多在**吸氣**，不用聽診器也聽得到 | **上呼吸道(喉、氣管)阻塞** | **哮吼、會厭炎、異物**、**拔管後喉頭水腫**、吸入性灼傷 |
| **肋膜摩擦音** | 粗糙、像皮革互相摩擦 | 吸氣與呼氣 | 肋膜發炎 | 肋膜炎；**咳嗽後不會消失**，憋氣時消失 |

- 中文譯名各書不同：wheeze 有人譯「喘鳴音」，stridor 有人也譯「喘鳴」或「哮吼音」；作答時看英文或看描述(高音調**吸氣**＝上呼吸道)
- **stridor 是緊急狀況**：可能很快完全阻塞，要通知醫師、準備緊急插管或氣切

### 語音傳導 {#voice-sounds}

| 檢查 | 方法 | 異常時 |
|---|---|---|
| **支氣管語音** | 請病人說話 | 聽診器可**清楚聽到說的內容** |
| **羊語音** | 請病人說「ㄧ」 | 聽起來像「ㄚ」 |
| 耳語胸語音 | 請病人小聲耳語 | 耳語也聽得清楚 |

- 三者陽性都代表**實質化**(肺炎)；正常肺只聽到模糊的聲音

::questions{ids="112-1_MS_054,108-2_MS_054,106-2_makeup_OP_060,108-1_OP_067,106-1_MS_054"}

## 呼吸困難與缺氧的徵象 {#dyspnea-hypoxia}

1. **呼吸困難**是主觀感受；客觀上看
   1. 呼吸速率增加、使用輔助肌、**端坐呼吸**、**噘嘴式呼吸**、鼻翼搧動、凹陷
   2. **咳血**不是呼吸困難的常見徵象(是另一個症狀)
2. 缺氧的表現

| 時期 | 表現 |
|---|---|
| **早期** | **躁動不安**、焦慮、判斷力下降、**心跳加快**、呼吸加快、血壓上升 |
| **晚期** | **發紺**、意識混亂到昏迷、**心跳變慢**、**血壓下降**、心律不整 |

- 發紺要靠去氧血紅素夠多才看得到，**貧血**病人可能缺氧卻不發紺，見 [[gas-exchange-transport#oxygen-transport]]
- 處理優先順序：依 ABC，**呼吸道與呼吸問題最優先**；呼吸困難時採**坐姿或半坐臥**，身體前傾趴在**床上桌**(放枕頭)最省力

::questions{ids="108-2_MS_057,115-1_MS_034,111-2_FA_012,114-3_FA_008,114-1_FA_022"}

## 脈衝式血氧監測 {#pulse-oximetry}

1. 原理：感應器發出兩種波長的光，依含氧與去氧血紅素吸光不同算出 **SpO₂**，同時顯示脈搏
2. 正常值：**SpO₂ 95–100%**(單位是 %)；PaO₂(Partial pressure of arterial oxygen) 60 mmHg 約等於 SpO₂ 90%
3. 位置：手指、腳趾、耳垂、額頭；新生兒可放手掌或腳掌
4. 護理
   1. 確認**機器顯示的心跳和實際脈搏相符**，波形穩定，數值才可信
   2. **定期更換感應器位置**，避免壓傷與燙傷(彈簧夾式尤其要注意；頻率依院內規範)
   3. 去除指甲油、假指甲；肢體保暖
5. 會讓數值不準的情況
   1. 周邊灌流差(休克、低體溫、四肢冰冷)、病人一直動
   2. 指甲油、假指甲、強光
   3. **一氧化碳中毒**：COHb 被當成氧合血紅素 → **數值假性正常**，見 [[environmental-injury#carbon-monoxide]]
   4. 皮膚顏色較深的人可能**高估**血氧(來源：[US FDA Safety Communication 2021](https://www.fda.gov/medical-devices/safety-communications/pulse-oximeter-accuracy-and-limitations-fda-safety-communication))
6. SpO₂ 只看氧合，**看不到 CO₂**；COPD 或使用鴉片類的病人血氧正常不代表沒有換氣不足，要配合呼吸型態與血氣，見 [[abg#oxygenation]]

::questions{ids="106-1_OP_059,114-2_MS_035,115-2_FA_026"}

## 痰液 {#sputum}

| 痰液外觀 | 可能原因 |
|---|---|
| 白色或透明黏液 | 正常、病毒感染、慢性支氣管炎早期 |
| 黃綠色、膿性 | **細菌感染**、慢性支氣管炎急性發作、支氣管擴張症 |
| **鐵鏽色** | **肺炎鏈球菌肺炎** |
| **粉紅色泡沫** | **急性肺水腫** |
| 血絲或咳血 | 結核、肺癌、支氣管擴張症；肺栓塞也可能咳血 |
| 大量膿痰、靜置分三層 | **支氣管擴張症**，見 [[copd#bronchiectasis]] |

- 收集方法(清晨第一口痰、只用清水漱口、氣切病人用抽痰收集)見 [[culture-and-sensitivity#sputum-culture]]
- 痰液顏色改變要記錄，作為評估病情變化的依據

## 影像與肺功能檢查 {#imaging}

1. **胸部 X 光**
   1. 標準是**站姿後前位**、**深吸氣後憋氣**
   2. 移除胸前金屬物品；育齡婦女確認是否懷孕
   3. 用途：肺炎浸潤、肋膜積水、氣胸、心臟大小、管路位置(氣管內管、中心靜脈導管、胸管)
2. 電腦斷層：腫瘤、肺栓塞(電腦斷層肺血管攝影)；用顯影劑要評估過敏與腎功能
3. **肺通氣灌流掃描**：懷疑肺栓塞但不能打顯影劑時使用
4. **肺功能檢查**：FEV1(Forced expiratory volume in 1 second)、FVC(Forced vital capacity) 的意義見 [[ventilation-mechanics#spirometry]]；依醫囑在檢查前停用支氣管擴張劑(時間依藥物種類)；教病人用力、持續吐氣
5. **動脈血氣**：見 [[abg]]
6. **尖峰呼氣流量**：氣喘居家監測，見 [[asthma]]

## 支氣管鏡檢查 {#bronchoscopy}

1. 目的：直接看氣管與支氣管、取痰或灌洗液、切片、取出異物、清除痰栓
2. 檢查前
   1. 簽同意書、說明過程
   2. **禁食禁水**(依醫囑，通常數小時)，避免嘔吐吸入
   3. 移除假牙
   4. 咽喉噴**局部麻醉劑** → **作嘔反射暫時消失**
3. 檢查後
   1. **禁食禁水，直到作嘔反射恢復**才先喝少量水，再進食
   2. 姿勢：半坐臥或側臥，方便分泌物流出；不需要抬高到 80–90 度，也不需要臥床 4 小時以上
   3. 監測生命徵象、呼吸型態、聲音
   4. **少量血絲痰是正常的**(黏膜輕微受傷)
   5. 要通知醫師：**大量咳血**、**喘鳴音**或呼吸困難(喉頭痙攣、水腫)、發燒、胸痛或單側呼吸音減弱(切片後**氣胸**)
   6. 喉嚨痛可含冰塊或喝溫水(作嘔反射恢復後)

## 胸腔穿刺(胸腔放液穿刺術) {#thoracentesis}

1. 目的
   1. 診斷：抽肋膜液檢驗(滲出液或漏出液、細胞、細菌、癌細胞)
   2. 治療：抽出大量積液，減輕呼吸困難
2. 穿刺前
   1. 簽同意書；說明過程中**不可咳嗽、深呼吸或移動**
   2. 不需要禁食，也不需要常規給 Atropine
   3. 現在建議在**超音波導引**下定位(來源：[BTS Pleural Disease Guideline 2023](https://www.brit-thoracic.org.uk/clinical-resources/clinical-statements/pleural-procedures/))
3. **姿勢**
   1. **坐在床緣**、雙腳有支撐，身體前傾，**頭與手臂趴在床旁桌(放枕頭)上** → 肋間隙張開、積液沉到肺底
   2. 無法坐起：躺向**健側**、床頭稍抬高，患側在上
4. 穿刺位置：在積液範圍內，沿**肋骨上緣**進針，避開肋骨下緣的血管神經
5. 放液量：一次抽太多可能造成**復張性肺水腫**；常用上限是第一次約 **1.5 L**(BTS 建議，2023 版指出證據有限；**以醫囑為準**)，過程中病人咳嗽不止、胸悶要停止
6. 穿刺後
   1. 照**胸部 X 光**，排除氣胸
   2. 監測生命徵象、**SpO₂**、呼吸型態、呼吸音、穿刺處滲液
   3. 合併症
      1. **氣胸**：突然喘、患側呼吸音減弱、SpO₂ 下降
      2. **復張性肺水腫**：持續咳嗽、粉紅色泡沫痰、喘
      3. 出血、血胸
      4. **低血壓**(血管迷走反射或大量放液)
      5. 感染
   4. 術後 **SpO₂ 88%** 是最需要緊急處理的情況
- 肋膜積水的原因與漏出液、滲出液判讀見 [[pleural-chest-trauma#effusion]]；留置胸管見 [[chest-tube]]

::questions{ids="113-3_MS_034,113-1_MS_034,106-2_MS_056,110-2_MS_053"}

## 吸入性傷害的評估 {#inhalation-injury}

1. 懷疑吸入性灼傷的線索
   1. 在**密閉空間**著火、臉部或頸部燒傷
   2. **鼻毛燒焦**、口鼻有煤灰、**碳粒痰**
   3. **聲音沙啞**、**喘鳴音**、呼吸困難
2. 呼吸道水腫可能在**數小時後才出現**：剛離開火場沒有呼吸異常，**不代表沒有**吸入性灼傷，要持續觀察
3. 出現呼吸窘迫或上呼吸道水腫徵象 → **及早插管**維持呼吸道
4. 意識不清、頭痛、噁心嘔吐 → 懷疑**一氧化碳中毒**，見 [[environmental-injury#carbon-monoxide]]
5. 燒傷的照護見 [[burns#inhalation]]
