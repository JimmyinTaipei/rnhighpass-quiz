**造血幹細胞移植**是先用高劑量化療(或加全身放療)清除病人的骨髓與癌細胞，再輸入健康的造血幹細胞，讓它在骨髓「**植入**」並重建造血與免疫功能。用於白血病、淋巴瘤、多發性骨髓瘤、再生不良性貧血、重型海洋性貧血等。護理重點是**植入前的嚴重感染與出血風險**，以及異體移植特有的**移植物對抗宿主疾病**(GVHD)。白血病見 [[leukemia]]，免疫抑制劑見 [[immunosuppressants]]。

## 重點摘要 {#summary}

- 造血幹細胞移植是先用高劑量化療(或加全身放療)清除骨髓，再輸入健康幹細胞讓它**植入**重建造血與免疫。
- 依捐贈者分自體與異體；依來源分骨髓、周邊血液幹細胞與臍帶血。
- 植入前有嚴重**感染與出血**風險，採**保護性隔離**；幹細胞輸注後約 14–28 天開始造血。
- 主要併發症：**肝靜脈阻塞疾病**(右上腹痛、黃疸、腹水)與**移植物對抗宿主疾病(GVHD)**(皮膚、腸胃道、肝)。

### 國考常考點 {#exam-points}

- 預處理高劑量化療：**破壞骨髓與癌細胞，讓幹細胞有生長空間**；幹細胞輸注後約 **14–28 天**才開始造血；移植過程採**保護性隔離**。
- **周邊血液幹細胞**：捐贈者**連續數天**打 G-CSF、**不需麻醉**、收集後休息無不適**可返家**；受贈者**較易有慢性 GVHD**；**懷孕哺乳、血栓病史、自體免疫病**是禁忌。
- **骨髓捐贈**：抽出過濾後**可立即輸注**。
- **急性 GVHD**：傳統在 **100 天內**，**皮膚、腸胃道、肝**：**紅疹、腹瀉、膽紅素上升**，**不是便秘**、不是藥物過敏；病理是 **T 細胞媒介的上皮損傷**；**骨髓移植**最易發生 GVHD。
- **肝靜脈阻塞疾病**：移植後約 2–3 週 **右上腹痛、黃疸、腹水、體重增加**；移植前**肝炎**會增加風險。
- 移植後 **2 週內**的感染以**細菌**為主，**不是 CMV**。

## 移植的種類 {#types}

### 依捐贈者 {#donor-types}

| | **自體移植** | **異體移植** |
|---|---|---|
| 幹細胞來源 | **病人自己**(治療緩解後先收集冷凍保存) | **他人**：HLA 相合的兄弟姊妹、非親屬捐贈者(骨髓資料庫)、半相合家人、臍帶血 |
| 目的 | 讓病人**承受更高劑量化療**後救回骨髓 | 同時提供新的**免疫系統**，產生「**移植物對抗白血病**」效果 |
| GVHD | **不會** | **會** |
| 排斥 | 無 | 可能 |
| 常用於 | 多發性骨髓瘤、淋巴瘤 | 急性白血病、骨髓造血不良、再生不良性貧血 |

- 異體移植需要 **HLA**(人類白血球抗原)配對，配對越吻合，GVHD 與排斥越少。

### 依幹細胞來源 {#cell-sources}

| 來源 | 收集方式 | 特點 |
|---|---|---|
| **骨髓** | 捐贈者在**全身麻醉**下，從**後腸骨嵴**多點抽取(量依受贈者體重，常約 **10–15 mL/kg**，成人約 1,000 mL 左右) | 抽出後**過濾**即可**立即輸給受贈者**(或冷凍保存)；捐贈者術後要**平躺**加壓止血，腰臀痠痛數天 |
| **周邊血液幹細胞** | 捐贈者**連續數天**(約 4–5 天)**皮下注射白血球生成激素**(G-CSF)，把幹細胞從骨髓「動員」到血液，再用**血液分離機**收集，**不需麻醉** | **植入較快**、復發較少，但**慢性 GVHD 較多**；捐贈者可能**骨頭痠痛**，收集後休息無不適**即可返家**(來源：[UpToDate](https://www.uptodate.com/contents/hematopoietic-cell-transplantation-hct-sources-of-hematopoietic-stem-progenitor-cells)) |
| 臍帶血 | 出生時收集、冷凍 | 配對要求較寬，但細胞量少、植入慢 |

- 幹細胞冷凍保存在 **−196°C 液態氮**中(不是 −40°C)。
- 周邊血液幹細胞捐贈的**禁忌**包括：**懷孕或哺乳**、**血栓病史**(肺栓塞、深部靜脈栓塞)、**自體免疫疾病**、嚴重心肺疾病；血小板正常(> 150,000)不是禁忌。

## 移植過程 {#process}

1. **評估與準備**：心、肺、肝、腎功能、感染篩檢、牙科處理；放置**中心靜脈導管**(常用 **Hickman** 隧道式導管)。
2. **預處理**(conditioning)：**高劑量化療 ± 全身放療**，目的是**破壞病人的骨髓與癌細胞**，**抑制免疫**以免排斥，並讓植入的幹細胞有**生長空間**。
3. **幹細胞輸注**(第 0 天)：像輸血一樣經中心靜脈導管輸注；冷凍保存的幹細胞含保存劑 DMSO，可能有**噁心、特殊氣味**、血壓變化，要監測生命徵象。
4. **植入前的低下期**：血球極低，**約 2–4 週**(骨髓約 14–28 天，周邊血液幹細胞較快，約 10–14 天)後才開始造血；**嗜中性白血球連續數天 > 500/μL** 代表植入。
5. **免疫重建**：需要數個月到一年以上；異體移植要持續使用**免疫抑制劑**預防 GVHD。

## 移植後的主要併發症 {#complications}

| 時間 | 併發症 |
|---|---|
| **植入前**(約前 30 天) | **細菌感染**(最常見)、**黴菌感染**(念珠菌、麴菌)、單純疱疹再活化、**口腔黏膜炎**、出血、**肝靜脈阻塞疾病**、**急性 GVHD 開始出現** |
| 植入後早期(30–100 天) | **巨細胞病毒**(CMV)感染與肺炎、急性 GVHD、肺囊蟲 |
| 晚期(> 100 天) | **慢性 GVHD**、帶狀疱疹、莢膜細菌感染、復發、續發性癌症、不孕、白內障 |

- **移植後前兩週**的感染以**細菌**為主，**CMV 通常在植入後(第 30–100 天)**才常見。

### 肝靜脈阻塞疾病(竇狀隙阻塞症候群) {#vod}

- 預處理化療傷害肝臟小靜脈 → 肝臟充血。常在**移植後 3 週內**出現。
- 表現：**右上腹痛**、**肝腫大**、**黃疸**(膽紅素上升)、**腹水**、**體重突然增加**、水腫。
- 風險：移植前曾有**肝炎**或肝病、高劑量預處理。
- 護理：**每天量體重與腹圍**、I/O、肝功能；限制鈉與水分(依醫囑)；治療藥物 defibrotide。

### 移植物對抗宿主疾病(GVHD) {#gvhd}

**捐贈者的 T 細胞**把病人的身體當成外來物攻擊。只發生在**異體**移植(及含淋巴球的輸血，如未照射的血品)；**骨髓移植**是最常發生 GVHD 的移植。

| | **急性 GVHD** | **慢性 GVHD** |
|---|---|---|
| 時間 | 傳統定義為**移植後 100 天內**(常在**植入前後，約 2–4 週**) | 通常在 **100 天後** |
| 主要器官 | **皮膚、腸胃道、肝臟** | 全身多器官，類似自體免疫病 |
| 表現 | **皮膚**：**斑丘疹**(常先出現在手掌、腳掌、耳朵)，嚴重時起水泡脫皮；**腸胃**：**大量水瀉**、腹痛、噁心嘔吐；**肝**：**膽紅素上升**、黃疸、肝功能異常 | 皮膚硬化、**口乾眼乾**、口腔潰瘍、關節攣縮、肺部阻塞、肝功能異常 |
| 病理 | **T 細胞媒介**的**上皮細胞**損傷 | 纖維化 |
| 風險 | HLA 不合、非親屬捐贈、年紀大 | **周邊血液幹細胞**來源、曾有急性 GVHD、**年紀大** |

(來源：[UpToDate：acute GVHD](https://www.uptodate.com/contents/clinical-manifestations-diagnosis-and-grading-of-acute-graft-versus-host-disease))

- 異體移植後 3 週出現**全身紅疹與腹瀉** → 優先想到**急性 GVHD**(不是單純藥物過敏)；可做**皮膚切片**確診，並追蹤**肝功能與膽紅素**。
- **便秘不是** GVHD 的表現。
- 預防與治療：**免疫抑制劑**(cyclosporine 或 tacrolimus 加 methotrexate 等)、**類固醇**；皮膚照護、腹瀉的水分電解質與營養、評估排便量。
- 輕度的 GVHD 也帶有**移植物對抗白血病**效果，可降低復發。

## 護理重點 {#nursing}

### 感染預防 {#infection-prevention}

- 異體移植病人住在 **HEPA 過濾、正壓**的**保護性隔離病房**；進入前**確實洗手**、戴口罩，限制訪客，生病的人不可探視。
- **預防性**抗細菌、抗黴菌、抗病毒藥(acyclovir)，依醫囑監測 CMV。
- **口腔護理**、會陰清潔、中心導管無菌照護；**不量肛溫**。
- 飲食：煮熟、新鮮、衛生；避免生食(見 [[cancer-treatment-toxicities#infection-prevention]])。
- **發燒**立即通知(嗜中性白血球低下發燒是急症)。
- 疫苗：移植後免疫力歸零，約 **6–12 個月後**依計畫**重新接種**不活化疫苗；活性減毒疫苗至少 **2 年後**且沒有 GVHD、未使用免疫抑制劑時才可考慮。

### 出血與輸血 {#transfusion}

- 血小板與紅血球低下時依醫囑輸血；移植病人的血品要經過**放射線照射**(去除淋巴球，預防輸血引起的 GVHD)，並使用去白血球血品。
- 出血預防措施見 [[cancer-treatment-toxicities#thrombocytopenia]]。

### 身心與出院 {#psychosocial}

- 長時間隔離、身體不適與死亡威脅 → 焦慮、憂鬱、孤獨；保持與家人、同學聯繫(視訊)。
- 出院後仍要**持續服用免疫抑制劑**、定期回診、避免人潮、注意 GVHD 徵象(皮膚紅疹、腹瀉、黃疸、口眼乾)。
