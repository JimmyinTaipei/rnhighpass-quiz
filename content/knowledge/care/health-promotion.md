健康促進是「讓人們更能掌控並改善自己健康」的**過程**，對象是**全體民眾**，做法不只是衛教，還包括政策、環境與社區行動。這頁整理健康促進的概念、國際憲章與國內政策、菸害防制，以及國考最常考的行為改變理論；衛生教育的教學方法、目標與評價見 [[health-education]]，三段五級見 [[epidemiology#prevention-levels]]

## 重點摘要 {#summary}

- **健康促進 vs 疾病預防**：健康促進對象是**全體民眾**、積極拓展健康潛能；疾病預防對象是**高危險群**、避免疾病或危險行為發生
- **渥太華憲章(1986)五大行動綱領**：建立健康的**公共政策**(法規)、創造**支持性環境**(設施)、強化**社區行動力**(社區參與)、發展**個人技能**(講座、衛教)、**調整健康服務**方向(醫院做預防)
- **健康信念模式**：自覺罹患性＋自覺嚴重性 → 威脅感；自覺利益 − 自覺障礙 → 是否行動；**行動線索**觸發行動
- **跨理論模式**：無意圖期 → 意圖期(6 個月內)→ 準備期(1 個月內)→ 行動期(改變 < 6 個月)→ 維持期(≥ 6 個月)；可能復發
- **PRECEDE**(predisposing, reinforcing, and enabling constructs in educational diagnosis and evaluation)**三因素**：**傾向因素**(知識、態度、信念)、**促成因素**(資源、可近性、技能)、**增強因素**(行為後的回饋、讚賞、支持)
- **菸害防制法(2023-03-22 施行)**：未滿 **20 歲**與孕婦不得吸菸；**電子煙等類菸品全面禁止**；孕婦或未滿 3 歲兒童在場的室內不得吸菸

### 國考常考點 {#exam-points}

- 判斷渥太華綱領：**立法取締酒駕、傳染病防治法規定權責 → 公共政策**；健康步道、運動教室、飲水機、平價素食餐廳 → **支持性環境**；培訓社區戒菸種子、一週一餐素 → **社區行動力**；講座、體重控制課程 → **個人技能**；醫院開**戒菸門診** → **調整健康服務**
- 健康信念模式：講**後遺症、預後** → 嚴重性；講**高危險因子** → 罹患性；**費用、時間成本** → 障礙；不確定疫苗有沒有效 → 利益；**名人代言、通知單、口號** → 行動線索
- 跨理論模式：「我想運動但找不到時間」→ **意圖期**，用**自我再評價**；維持期倦怠 → **增強管理**；行動期仍可能**退回**意圖期
- PRECEDE：**可近性** → 促成因素；**媽媽讚賞、好寶寶點數** → 增強因素；**預算、人力、課程時數** → 行政與政策診斷；流行病學診斷是**確定健康問題**；**下肢肌力改善** → 衝擊評值
- Pender 三大要素：個人特質與經驗、行為特異性的認知與情感、行為結果；「下班太累不能參加」→ **自覺行動障礙**；「我知道我做得到」→ **自覺自我效能**
- 健康體適能：**心肺耐力、肌力與肌耐力、柔軟度、身體組成**(平衡力、骨密度不是)
- Lalonde(1974)四大因素：**生活型態、環境、人類生物學(遺傳)、健康照護體系**；影響最大的是**生活型態**
- 健康識能越低，**預防保健利用率越低**；社經弱勢要**優先**納入；增進識能是**賦權**民眾自己做決定，不是醫療人員代為決定
- 社區賦權是**由下而上**；法律罰則屬**社會改變**(由上而下)，不是賦權

## 健康促進的概念 {#concepts}

### 健康促進與疾病預防 {#vs-prevention}

| | 健康促進 | 疾病預防 |
|---|---|---|
| 對象 | **全體民眾** | 疾病**高危險群** |
| 取向 | 積極(approach)：拓展健康潛能、達到最佳安適 | 消極(avoid)：避免某疾病或某行為發生 |
| 三段五級 | 第一段第一級(促進健康) | 第二級以後(特殊保護、篩檢等) |

- WHO(World Health Organization，世界衛生組織)渥太華憲章：健康促進是**使人們能增加對自身健康的控制並改善健康的過程**；是**過程**，不是狀態(110-2 題)
- 推動要件：整合各項資源、正向的支持環境、以健康為目的、以**個人生活型態與環境改變**為策略；單靠教育改變**認知**不是最有效的方法(107-1 題)

### 介入策略的層次 {#intervention-types}

| 策略 | 方向 | 例子 |
|---|---|---|
| **衛生教育** | 提供知識 | 健康知識講座 |
| **行為改變** | 針對個人 | 正向或負向增強 |
| **社區賦權**(empowerment) | **由下而上**：協助民眾發現並解決自己的問題，取得更多控制權 | 社區自組健走團、培訓在地種子 |
| **社會改變** | **由上而下**：修法、政策、環境結構 | **酒駕罰則**、騎機車戴安全帽 |

- 正向健康行為可以透過**健康政策、支持性環境與教育活動**一起達成(108-1 題)
- 推動社區健康促進計畫要以**目標族群的特性**設計活動(107-2「健康 100 腰動動」)，不是只找友善的人或以行政單位為主力

### 健康體適能 {#fitness}

| 類別 | 要素 |
|---|---|
| **健康體能**(health-related) | **心肺耐力、肌力與肌耐力、柔軟度、身體組成** |
| 競技體能(skill-related) | 敏捷、平衡、協調、速度、瞬發力、反應時間 |

- **登階運動**(3 分鐘登階)評估與加強**心肺耐力**；仰臥起坐、伏地挺身練肌力肌耐力；伸展練柔軟度
- 骨質密度、平衡力**不是**健康體能要素；腰圍、體脂肪只是身體組成的一部分
- 運動屬於身體活動，但身體活動不一定是運動(運動是有計畫、有結構、重複的身體活動)
- 規律身體活動要**長期**累積才能降低大腸癌等慢性病風險，「3 週」不夠(111-1 題)
- WHO 2020 建議：5–17 歲**每天平均 60 分鐘**中高強度身體活動；成人每週 **150–300 分鐘**中等強度；BMI 與腰圍見 [[nutrition-assessment-diets#anthropometrics]]，兒少健康體位見 [[health-promotion#applications]]

::questions{ids="114-2_PC_035,111-1_PC_057,110-2_PC_059,108-1_PC_070,106-2_makeup_PC_047"}

### 健康識能 {#health-literacy}

- **個人健康識能**：取得、理解、運用健康資訊與服務，為自己和他人做健康決定的能力；**組織健康識能**：機構有責任讓人公平地取得與運用資訊(課本 p.104)
- 識能低的人預防保健利用率**較低**、住院與醫療費用較高
- 國健署推動方向(國考 109-1、111-1、114-1 題)：
   1. 提升資訊**可近性**(評估需求與傳播管道)、依區域與族群特性傳播、發展評估工具
   2. 運用 eHealth 與新媒體；透過社區、學校、職場、醫院等場域推動
   3. 提供**實證、非商業**的資訊；複雜照護者要有清楚易執行的出院計畫
   4. **社經弱勢優先**納入；擴大巡迴醫療是就醫可近性，不是識能策略
- 對原住民、新住民：用**聽得懂的語言**(雙語手冊)、媽媽教室、學中文；目標是增進**自己掌控健康的能力**，醫療人員不代為決定；傳統服飾表演與識能無關(109-1 題)

## 國內外重要政策與會議 {#policies}

### 健康決定因素 {#determinants}

- **Lalonde 報告**(1974，加拿大衛生福利部長)：影響健康的四大因素
   1. **生活型態**(影響最大；國考詳解常寫約 50%，比例待核對)
   2. 環境
   3. 人類生物學(遺傳)
   4. 健康照護體系
- 「生理、心理、社會、靈性」是整體健康的層面，不是 Lalonde 四大因素(105-1 題)
- **健康人民 2030**(Healthy People 2030，美國，每 10 年訂一次)：健康的**社會決定因素**分五部分(經濟穩定、教育、健康照護可近性與品質、鄰里與建築環境、社會與社區背景)
- 國內：1989 年國民健康促進研討會起步；2009《2020 健康國民白皮書》兩大目標：**延長健康平均餘命、促進健康平等**；健康不平等見 [[health-equity]]

### 渥太華憲章五大行動綱領 {#ottawa}

| 綱領 | 核心 | 國考例子 |
|---|---|---|
| **建立健康的公共政策** | 立法、財政、行政措施 | 取締酒駕、傳染病防治法明訂機關權責、禁菸法規 |
| **創造支持性環境** | 改變物理與社會環境，讓健康選擇更容易 | 公園健康步道、公司運動教室、學校飲水機、物美價廉素食餐廳 |
| **強化社區行動力** | 社區參與、運用在地資源、社區自主 | 培訓社區戒菸種子宣導不賣菸給青少年、鼓勵社區一週一餐素 |
| **發展個人技能** | 提供資訊、教育、生活技能 | 健康飲食講座、慢性病預防講座、符合健康識能的體重控制課程、素食烹飪比賽或營養講座 |
| **調整健康服務方向** | 醫療機構從治療轉向預防與健康促進 | 醫療院所開**戒菸門診** |

- 「發展高科技精準醫療」**不是**五大綱領(109-2 題)
- 114-3 題題幹寫「不得販賣菸品予未滿 18 歲」是舊法用語；現行菸害防制法是**未滿 20 歲**

### 健康城市與高齡友善城市 {#healthy-cities}

- **健康城市**：Hancock 與 Duhl(1986)提出理想健康城市的 **11 項品質**，例如乾淨安全的環境、穩定永續的生態、**強而有力的支持性社區**、**高度參與**、**滿足基本需求**、多元有活力與創新的經濟、與歷史文化的連結、**有品質的衛生醫療服務**、良好的健康狀態
   1. 目標**不是**「全體居民都沒有疾病」(106-2 補考)
   2. 「現代化、智慧化的生活環境」**不是**11 項之一(106-1 題)
- **高齡友善城市**(WHO 2007)八大面向：無障礙與安全的公共空間、交通運輸、住宅、社會參與、敬老與社會融入、工作與志願服務(公民參與與就業)、通訊與資訊、社區支持與健康服務；「**醫院數目**」不是(106-1 題)
- 社區健康營造、安全社區見 [[community-nursing-process]]

### 菸害防制 {#tobacco-control}

| 規定(菸害防制法，2023-03-22 施行) | 條文 |
|---|---|
| **菸品**含紙菸、菸絲、**雪茄**與其他含尼古丁的菸草製品 | 第 3 條 |
| **類菸品**(電子煙)：任何人不得製造、輸入、販賣、供應、展示、廣告，也**不得使用**；加熱菸等指定菸品要先通過健康風險評估 | 第 15 條 |
| **未滿 20 歲**與**孕婦**不得吸菸(舊法 18 歲)；父母應禁止未成年人吸菸 | 第 16 條 |
| 任何人(包括家人)不得**供應**菸品給未滿 20 歲者 | 第 17 條 |
| 學校、醫療機構、大眾運輸、3 人以上共用室內工作場所等**全面禁菸** | 第 18 條 |
| **孕婦或未滿 3 歲兒童在場**的室內場所不得吸菸 | 第 20 條 |
| 在禁菸場所吸菸，負責人應勸阻，**在場其他人也可以勸阻** | 第 21 條 |
| 未滿 20 歲吸菸者要接受**戒菸教育** | 第 42 條 |

- 菸害：焦油致癌；**尼古丁**造成成癮與戒斷；孕婦吸菸尼古丁經胎盤到胎兒
- **電子煙不是戒菸工具**；戒菸藥物、尼古丁戒斷與國健署戒菸服務補助對象見 [[addiction-treatment-drugs#smoking-cessation]]；成癮的診斷見 [[substance-use-disorders]]
- 高中以下學校：2026-09-23 修正的學校衛生法第 24 條要求**全面禁菸、電子煙及新型態菸品**
- 健康信念模式的運用：運動員擔任拒菸大使「我拒菸，我驕傲」→ **行動線索**(114-3 題)

## 行為改變理論 {#theories}

### 健康信念模式 {#hbm}

Hochbaum 等(1958)提出，Becker 與 Rosenstock 改良；用來預測人會不會採取**預防行為**

| 要素 | 意思 | 介入例子 |
|---|---|---|
| **自覺罹患性**(易感性) | 覺得自己會不會得病 | 說明**高危險因子** |
| **自覺嚴重性** | 得病後果多嚴重(失能、死亡、家庭工作受影響) | 說明**後遺症、預後**；「若罹患子宮頸癌會影響家庭也可能會死」 |
| 自覺威脅 | 罹患性＋嚴重性 | — |
| **自覺利益** | 行動能帶來的好處 | 「不確定疫苗是否有效」＝利益認知不足 |
| **自覺障礙** | 行動的代價：費用、時間、疼痛、不方便 | 「考量諮商費用與時間」；里幹事協助預約＝**降低障礙** |
| **行動線索** | 觸發行動的內外在提示 | **名人代言**、通知單、媒體宣傳、口號 |
| 修正因素 | 人口學、社會心理、結構因素(知識經驗) | — |
| 自我效能 | 後來加入：相信自己做得到 | — |

- 82 歲糖尿病個案說「現在沒不舒服，死了就算了」→ 加強**嚴重性**認知(109-1 題)
- 中風後擔心再中風會坐輪椅 → **嚴重性**認知(112-1 題)
- 缺點：把健康責任放在個人、忽略大環境；行為沒改變時容易**責怪個案**(課本 p.109)

::questions{ids="115-2_PC_034,114-3_PC_034,114-3_PC_035,114-2_PC_040,112-3_PC_034,112-1_PC_059,111-2_PC_056,109-1_PC_079,106-2_PC_079,106-2_makeup_PC_065"}

### Pender 健康促進模式 {#pender}

Pender(1975 提出、1996 修正)；以「趨向健康」為導向，不是以避免疾病為導向

| 三大要素 | 內容 |
|---|---|
| ①**個人特質與經驗** | 先前相關行為；生物、心理、社會文化因素 |
| ②**行為特異性的認知與情感** | **自覺行動利益、自覺行動障礙、自覺自我效能**、行動相關感受、**人際間的影響**、**情境的影響** |
| ③**行為結果** | 對行動計畫的承諾、立即的競爭性需求與喜好、健康促進行為 |

- 「下班太累，無法參加」→ **自覺行動障礙**(114-1 題)；「我知道我可以做到」→ **自覺自我效能**(107-2 題)
- 政策與法規**不是** Pender 的三大要素(108-2 題)
- 109-1 題的策略：審思久坐的價值＝**自我再評估**、設定可達成但具挑戰的目標、由成功經驗**提升自我效能**、記錄好處並正向回饋＝**強化改變的效益**；題目沒有處理障礙與訂契約

::questions{ids="114-1_PC_045,109-1_PC_060,108-2_PC_068,107-2_PC_062"}

### 自我效能、社會生態模式與 Beattie 模式 {#other-models}

- **自我效能**(Bandura)：個人相信自己在特定情境下能完成特定行為；有**程度、類化、強度**三個層面；失敗經驗會讓低自我效能者更低；**外在資源多不等於自我效能高**(114-1 題)
- **社會生態模式**：行為受多層因素影響
   1. 個人：知識、態度、技能
   2. 人際：家人、朋友、同事的支持
   3. 組織：學校、職場的規定
   4. **社區**：社區環境與資源，例如里長規劃健走步道、公園運動器材(113-1 題)
   5. 公共政策：法律與政策
- **Beattie 健康促進模式**：依「權威式 vs 協商式」與「個人 vs 集體」分四象限：健康說服(權威、個人)、個人諮詢(協商、個人)、立法與政策行動(權威、集體)、**社區組織發展**(協商、集體)；在關懷據點和民眾協調時間地點開瑜珈班 → **社區組織發展**(106-2 題)

::questions{ids="114-1_PC_034,113-1_PC_036,106-2_PC_080"}

### PRECEDE-PROCEED 模式 {#precede-proceed}

Green 等(1980)提出 PRECEDE，之後加上 PROCEED(policy, regulatory, and organizational constructs in educational and environmental development)；共 **9 階段**：1–5 規劃、6 執行、7–9 評值

| 階段 | 內容 |
|---|---|
| 1 社會評估 | 用社會指標(失業率、缺工率)了解**生活品質** |
| 2 **流行病學評估** | 用生命統計資料**確定健康問題**(罹病、死亡、殘障) |
| 3 行為與環境評估 | 找出造成健康問題的**行為**與環境原因 |
| 4 教育與生態評估 | 分析三類因素(下表) |
| 5 **行政與政策評估** | 資源、**預算、人力、時間**、政策與組織支持 |
| 6 執行 | — |
| 7 **過程評值** | 執行過程，例如活動參與率 |
| 8 **衝擊評值** | 傾向、促成、增強因素與**行為**的改變：知識、態度、技能、**體能**(例：12 週防跌後下肢肌力改善) |
| 9 **結果評值** | 健康狀態與生活品質：罹病率、死亡率 |

| 三因素 | 內容 | 例子 |
|---|---|---|
| **傾向因素**(性向，predisposing) | 行為發生**前**的個人動機：知識、態度、信念、價值觀、自我效能 | 布告欄口腔衛生海報 |
| **促成因素**(enabling) | 讓行為能發生的資源與技能：**可近性**、方便性、費用、醫療設備與保險 | 篩檢服務的可近性、牙醫到校檢查 |
| **增強因素**(reinforcing) | 行為發生**後**的回饋：家人、朋友、老師的讚賞、獎勵、社會支持 | **媽媽讚賞**刷牙、老師給**好寶寶點數** |

::questions{ids="108-2_PC_067,108-1_PC_072,107-2_PC_063,106-2_makeup_PC_064,106-1_PC_057"}

### 理性行為論 {#reasoned-action}

- Ajzen 與 Fishbein(1980)：人是理性的，**行為意圖**是行為的直接決定因素；行為意圖由**對行為的態度**與**主觀規範**(重要他人認為該不該做，以及自己是否依從)決定

### 跨理論模式 {#ttm}

| 階段 | 定義 | 適合的改變策略 |
|---|---|---|
| **無意圖期** | 未來 **6 個月內**不打算改變(資訊不足或屢試屢敗失去信心) | **意識覺醒**、環境再評價 |
| **意圖期** | 打算在 **6 個月內**改變，利弊拉鋸(「想運動但找不到時間」) | 意識覺醒、環境再評價、**自我再評價**、自我解放 |
| **準備期** | 打算在 **1 個月內**行動，已有具體計畫 | 自我解放、自我再評價、**助人之人際關係**；提供必要資源 |
| **行動期** | 已改變但**未滿 6 個月** | **增強管理**、反制約、**刺激控制**、社會支持 |
| **維持期** | 維持 **6 個月以上**，防止復發 | 反制約、刺激控制、增強管理 |

- 十個改變策略分兩類：
   1. **認知(內隱)**：意識覺醒、情感喚起、自我再評價、環境再評價、自我解放、社會解放
   2. **行為(外顯)**：反制約、增強管理、刺激控制、助人之人際關係
- 改變不是單向：行動期或維持期都可能**復發**退回較早階段(105-1 題)
- 維持期出現倦怠 → **增強管理**(自我獎勵、外在獎勵)(108-1 題)
- 衡量作決定：比較改變的利益(pros)與代價(cons)；面對猶豫的人(「沒檢查就沒事」)先同理與探索擔憂，**不要直接替他預約**(115-2 題)

## 健康議題的應用 {#applications}

- **四大非傳染性疾病**(癌症、糖尿病、心血管疾病、慢性呼吸道疾病)的共同危險因子：**吸菸、不當飲酒、缺乏運動、不健康飲食**(WHO；106-1 題)
- **代謝症候群**：控制體重屬**初段**預防；篩檢屬次段；個案管理與轉介屬次段或末段(108-2 題)；判定標準與社區慢性病照護見 [[older-adult-chronic-disease#lifestyle]]，血脂見 [[lipid-profile]]
- **兒少健康體位**(112-3 題)：每天累積 **60 分鐘以上**中度身體活動；螢幕時間每天 **2 小時內**；以**全穀雜糧**為主；肥胖**青少年**比肥胖兒童更容易變成肥胖成人
- 高血壓、糖尿病的社區防治見 [[hypertension#prevention]]、[[diabetes#prevention]]

- 肥胖(BMI ≥ 27)合併吸菸、飲酒、高鹽醃漬飲食：**飲食要調整**(少油、少鹽、少糖與加工食品)、每天至少 5 份蔬果、轉介減重與戒菸門診；「飲食可不用限制」不適宜(112-2 題)

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 健康促進是一種狀態 | 是一種**過程** | 渥太華憲章定義 |
| 健康促進屬三段五級第二級 | 第一段**第一級** | 第二級是特殊保護 |
| 健康促進要避免某行為發生 | 那是**疾病預防** | 健康促進是積極拓展潛能 |
| 社區賦權是由上而下 | **由下而上** | 民眾自己發現並解決問題 |
| 酒駕罰則是社區賦權 | **社會改變**／健康公共政策 | 靠法律外在約束 |
| 單靠教育改變認知最有效 | 要結合政策、環境與社區 | 知道不等於做到 |
| 健康體能包括平衡力、骨密度 | 心肺耐力、肌力肌耐力、柔軟度、身體組成 | 平衡力是競技體能 |
| 健康識能低的人預防保健用得多 | 用得**少** | |
| 醫療人員直接替民眾做健康決策 | 增進民眾**自己決定**的能力 | 賦權 |
| 菸品不包括雪茄 | **包括** | 第 3 條 |
| 可以用電子煙幫助戒菸 | 類菸品**全面禁止**，也不是戒菸工具 | 第 15 條 |
| 行動期的人不會退回意圖期 | 可能**復發** | |
| 外在資源越多自我效能越高 | 自我效能是**內在信念** | |
| 講腦中風危險因子可提升嚴重性認知 | 那是**罹患性**；講**後遺症**才是嚴重性 | |
