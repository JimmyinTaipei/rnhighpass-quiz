**個別心理治療**是治療者與病人一對一的談話治療，依理論取向分成**分析、支持、人本、人際、行為、認知**等幾大類；其中**行為治療與認知治療**在國考佔最多題。這一頁先講個別心理治療的類型與護理角色，再把**行為治療**與**認知治療**分開說明，最後用一張表比較各學派。團體與家庭治療見 [[group-family-therapy]]，環境與活動治療見 [[milieu-therapy]]，理論背景見 [[psychodynamic-theories]]

## 重點摘要 {#summary}

- **個別心理治療**：支持性治療以**減輕症狀、強化自我功能、提升自尊**為目標，著重**此時此刻**；分析式治療探索**潛意識與早年經驗**，用**自由聯想、夢的解析、抗拒與移情的解析**
- **行為治療**針對**可觀察的具體行為**，運用**增強**（正、負）、**逐步養成**、**代幣制度**、**行為契約**、**社交技巧訓練**、**系統減敏感**、**暴露及反應預防**
- **認知治療**：憂鬱與焦慮來自**扭曲的認知**；**貝克**的認知三合一是對**自己、外界、未來**的負向看法，治療重點是找證據、檢驗想法、建立替代想法
- **理情治療(Ellis)**用 **ABCDE** 駁斥非理性信念；**現實治療(Glasser)**強調**正當、責任、現實**與此時此刻
- 治療選擇要看問題：**具體不當行為**用行為治療；**急性正性症狀**先用藥物；**探索創傷與早年經驗**屬分析式治療

### 國考常考點 {#exam-points}

- 支持性治療**不宜探討問題背後的原因**（那是洞察式治療）；目的是改善症狀、提升自尊、強化自我功能
- 適合做個別心理治療的條件：**智力中上、症狀不嚴重、有內省能力**；**個性執著**不利
- 精神分析的核心技巧：**自由聯想、夢的解析、抗拒的解析、移情的解析**；**正向增強**屬行為治療，**認知再建構**屬認知治療
- **增強是增加行為**：**正增強＝給喜歡的**，**負增強＝移除厭惡的**；**處罰是減少行為**
- **逐步養成法**：從**最簡單**的小步驟開始、步伐要小，常用於**自我照顧缺失**或智能不足者
- **代幣制度**屬**操作制約**，症狀嚴重混亂、無法理解代幣意義時**不適合**；**行為治療團隊態度要一致**，不可扮黑白臉
- **強迫症**的行為治療首選是**暴露及反應預防(ERP)**；**洪水法**是立即長時間強烈暴露，不是「逐步」
- **過度概括**＝用單一事件推論一般原則；**二分法思考**＝非黑即白；**選擇性偏差推論**＝只抓單一細節下結論
- **理情治療**＝**駁斥非理性信念**；**現實治療**＝**責任、現實、此時此刻**，不探討過去

## 個別心理治療 {#individual-psychotherapy}

### 類型比較 {#types}

| 類型 | 目標與重點 | 常用技巧 | 適用 |
|---|---|---|---|
| **支持性** | 減輕症狀、**維持或恢復現有適應機制**、強化自我功能、提升自尊；**此時此刻** | 傾聽、同理、保證、衛教、協助因應 | 急性期、危機、哀傷、較嚴重的精神病 |
| **再教育性** | 協助評估並改善**行為模式**，增加獨立自主 | 澄清、訓練、指導 | 需要學習新因應方式者 |
| **分析式（心理分析）** | 把**潛意識衝突意識化**，探索**早年人格發展中的心理情結** | **自由聯想、夢的解析、抗拒的解析、移情的解析** | 有內省能力、動機強、症狀不嚴重者 |
| **人本**（個人中心） | 相信人有**成長與自我實現**的潛能；羅傑斯 | **無條件正向關懷、真誠一致、同理** | 重視自我成長者 |
| **存在－人文主義** | 人是自主的，能**自由選擇並創造有意義的生存方式** | 探討意義、責任與選擇 | 生命意義與孤獨感議題 |
| **人際關係心理治療(IPT)** | 處理**當下的人際問題** | 短期、結構式、聚焦人際 | 憂鬱症 |

:::exam[國考重點]
支持性心理治療的錯誤選項常是「探討問題背後的原因」；個人中心治療的關鍵字是「無條件正向關懷」；存在－人文主義的關鍵字是「自由創造有價值意義的生存方式」
:::

### 人際關係心理治療(IPT) {#ipt}

1. 概念：憂鬱症與**人際功能**有關，治療聚焦**現在**的人際議題，不分析早年事件，也不是在改錯誤認知
2. 四個常見問題領域
   1. 悲傷與失落
   2. 人際角色糾紛（衝突）
   3. 角色轉換困難
   4. 人際缺損（孤立、缺乏關係）
3. 常與**抗憂鬱藥物**合併使用，不需要二選一

### 動機式晤談(MI) {#motivational-interviewing}

1. 用在**物質使用障礙**等「不想改變」或「矛盾」的病人，重點是引出病人自己改變的動機
2. 四項核心原則
   1. 表達**同理**
   2. 創造**不一致**：讓病人看見目前的行為與自己的目標、價值有落差
   3. **順著阻力而行、避免爭辯**
   4. 支持**自我效能**
3. **不用直接面質**，也不是夢的解析；對立會讓病人更防衛
4. 物質使用障礙的心理治療多在**恢復期**進行，疏導內心問題並與家庭、心理因素一併處理

### 評估適不適合做個別心理治療 {#suitability}

| 有利條件 | 不利條件 |
|---|---|
| 智力中上，能理解與溝通 | 個性執著、防衛強、缺乏彈性 |
| 症狀不嚴重，能維持現實感與注意力 | 急性精神病症狀嚴重 |
| 有**內省能力**、能自我覺察 | 缺乏求助動機 |

### 護理人員的角色 {#nursing-role}

1. 運用**治療性人際關係**促進病人的改變與成長，護理師與病人接觸時間最長
2. 鼓勵**自我表露**，並協助處理**阻礙改變的阻力**
3. 提供衛教是心理衛生教育的範疇，不是個別心理治療的核心
4. 病人對護理師出現**情感轉移**（例如吵鬧、依賴、討好）時
   1. 先了解這是轉移現象，不必個人化
   2. 適合的措施：**支持性治療**關懷情緒、**再教育性治療**訓練獨立自主、**環境治療**與鼓勵活動參與
   3. **不適合**用強硬的**面質**指責行為「嚴重影響關係」，容易破壞信任
5. 提供就業資訊屬社會工作與職能治療，不是個別心理治療措施

## 行為治療 {#behavior-therapy}

**行為治療**認為行為是**學習**來的，所以可以**重新學習**；重點放在**可觀察的具體行為**，不探討早年成長與潛意識

### 理論基礎 {#behavior-theory}

| 理論 | 代表 | 重點 |
|---|---|---|
| **古典制約** | 巴夫洛夫 | 中性刺激與無條件刺激反覆配對 → 引起條件反應；**系統減敏感**的基礎 |
| **操作制約** | 史金納 | 行為受**後果**影響；**增強、處罰、代幣制度、逐步養成**的基礎 |
| **社會學習** | 班杜拉 | 觀察與模仿；**自我效能**；**社交技巧訓練**常用示範與角色扮演 |

### 增強與處罰 {#reinforcement}

| 名稱 | 做法 | 對行為的影響 | 例子 |
|---|---|---|---|
| **正增強** | **給予**喜歡的刺激 | **增加**行為 | 病人安靜後獲得稱讚 |
| **負增強** | **移除**厭惡的刺激 | **增加**行為 | 一週都沒有攻擊行為，就解除禁止外出 |
| **處罰** | 給予厭惡刺激，或**剝奪**喜歡的事物 | **減少**行為 | 攻擊後減少外出購物次數 |
| **消弱**（消去） | 不再給予增強物 | 行為逐漸**消失** | 對討要注意的行為不予理會 |

1. 增強與處罰的差別是**目的**：增強是為了**增加**行為，處罰是為了**減少**行為
2. 增強物要依個案的偏好選擇，**對個案有影響**才有效，不能只依病房管理方便
3. 稱讚、點數、貼紙、活動特權、解除限制都可以當增強物
4. 兒童與智能障礙者
   1. 增強物要**立即**且**明確**
   2. 延宕數天才給獎勵，效果差

:::note[爭議題：依考選部公布答案]
111-1_PC_012「出手攻擊後，哪一項是**負向增強**的處置」，考選部更正答案為**送到保護室**。依行為學理，負增強的目的是**增加**良好行為，題目的情境是要**減少**攻擊，學理上較接近處罰或暫停(time-out)，所以這題有定義爭議。作答以公布答案為準，但自己要記住學理：負增強＝移除厭惡刺激以增加行為
:::

### 常用技術 {#behavior-techniques}

#### 逐步養成法(shaping) {#shaping}

1. 概念：把複雜的目標行為拆成很多小步驟，**連續接近**目標，每接近一步就給增強
2. 原則
   1. 從**最簡單**、最容易達成的步驟開始
   2. 步伐要**小而明確**，太大步驟易挫折而中斷
   3. 進度依個案能力調整，不是越快越好
3. 用途：塑造**新行為**，常用於**自我照顧功能缺失**（穿衣、刷牙、盥洗）與智能障礙者

#### 代幣制度(token economy) {#token-economy}

1. 以**有交換價值的象徵物**（籌碼、貼紙、點數）代替金錢，**可換取**物品或特權
2. 學理：**操作制約**，代幣是**次級增強物**
3. 注意事項
   1. 病人要有基本認知能力與學習動機
   2. **精神症狀混亂**、無法理解代幣與獎勵關係時不適合，待症狀穩定後再用
   3. 規則要明確、兌換要即時，團隊執行要一致

#### 行為契約與行為治療的執行 {#behavior-contract}

1. 執行步驟
   1. 收集問題行為，用 **ABC 分析**
      1. A：行為前的情境（前因）
      2. B：出現的行為
      3. C：行為之後的結果（後果）
   2. 評估個案改變的意願
   3. 建立個案的增強物
   4. 與個案**共同討論**並訂定契約，明確寫出期望行為與後果
2. 家屬的感受不是行為分析的客觀資料；個案是未成年或行為能力受限時，需取得家屬或法定代理人同意
3. 團隊要點
   1. 行為治療需要**醫療團隊合作**，態度與標準要**一致**
   2. 醫師與護理師不可分別扮黑白臉
   3. 不是一出現不適當行為就一律處罰，以正向增強為主
4. 適用與不適用
   1. 適用：**具體可觀察的不當行為**，例如破壞病房安寧、攻擊行為
   2. 不適用：急性**正性症狀**（幻覺、妄想）以藥物為主；探討早年經驗與創傷的失落挫折屬分析式治療

#### 社交技巧訓練(SST) {#sst}

1. 用在人際疏離、功能退化而常重複住院的病人
2. 原則
   1. **結構化**的練習活動，**目的清楚**
   2. **重複指導**、修正與練習，運用**角色扮演**或實況演練
   3. 循序漸進，不要快速灌輸，過快會讓病人焦慮與挫折
   4. 搭配**代幣制度**增強目標行為
3. 訓練要延伸到社區與日常生活，不能只在住院時練習

#### 焦慮、恐懼與強迫的行為技術 {#exposure-techniques}

| 技術 | 做法 | 適用 |
|---|---|---|
| **系統減敏感法** | 建立焦慮階層，從最輕的情境開始，**放鬆**與刺激配對（**相互抑制**：放鬆與焦慮不能同時存在），逐步往上 | 畏懼症、焦慮；考題也把它列為強迫症洗手的適切策略（搭配反應預防），立即面對畏懼情境的洪水法與約束隔離則不適當 |
| **暴露及反應預防(ERP)** | **暴露**於引發焦慮的刺激（如碰觸門把），同時**阻止強迫行為**（不洗手），學習耐受焦慮 | **強迫症最有效的行為治療**（見 [[obsessive-compulsive-disorder#treatment]]） |
| **洪水法** | **立即**且**長時間**直接面對最害怕的情境 | 畏懼症；強度高，不是「逐步」 |
| **思考中斷法** | 出現強迫或不想要的想法時，用口令或動作打斷 | 強迫思考 |
| **生理回饋** | 用儀器顯示生理訊號，學習放鬆 | 壓力與焦慮的生理反應 |
| **肯定訓練** | 練習適當表達需求、感受與界線 | 退縮、被動、難以拒絕的人 |

:::exam[國考重點]
情境題「讓個案有意識地碰觸髒的門把，再幫助耐受不洗手的焦慮」答案是**暴露及反應預防**；用玩具轉移注意力以避免繼續洗手，也屬於反應阻止的運用
:::

## 認知治療 {#cognitive-therapy}

### 貝克的認知理論 {#beck}

1. 概念：**情緒與行為受想法影響**，不是事件本身；憂鬱與焦慮的人會有**扭曲的認知**
2. **認知三合一**：對**自己**、**外界（世界與生活經驗）**、**未來**的負向看法
3. **自動化想法**是不經思考、快速浮現的負向念頭，背後有**核心信念（基模）**
4. 與其他學派區分
   1. 早期未解決的衝突與焦慮：佛洛伊德
   2. 環境塑造人格、可用行為技巧矯正：行為學派
   3. 高情感表露的家庭會增加復發：家庭理論

### 常見的認知扭曲 {#cognitive-distortions}

| 扭曲 | 說明 | 例子 |
|---|---|---|
| **二分法思考**（兩極化、全有全無） | 非黑即白，沒有中間地帶 | 「沒升經理，我就是失敗者」 |
| **過度概括**（過度推論） | 用**單一事件**推出一般原則 | 吃麵包變胖一次，就「嚴禁所有碳水化合物」 |
| **選擇性偏差推論**（選擇性摘取） | 只抓**單一細節**下結論，忽略整體 | 只記得別人皺眉，就認為大家都討厭我 |
| **武斷推論** | **沒有證據**就下結論 | 朋友沒回訊息，就認為對方生氣 |
| **災難化** | 把結果往最糟處想 | 心跳快就想到心臟病發作 |
| **個人化** | 把與自己無關的事件**歸咎於自己** | 孩子成績不好是我沒做好 |
| **讀心術** | 擅自認定他人的想法 | 「他一定覺得我很糟」 |
| **情緒推理** | 把感覺當成事實 | 我覺得很沒用，所以我真的沒用 |
| **控制的謬誤** | 認為自己要為一切負責，或完全無法控制 | 一切都是我的錯／我什麼都改變不了 |

1. 區分重點：**過度概括**是由單一事件推論到大多數事件，**個人化**則是把無關的事歸咎於自己
2. 憂鬱症病人常自責「我是個糟糕的母親」，這是需要被檢驗的想法

### 認知行為治療(CBT)的原則與步驟 {#cbt}

1. 特色
   1. 結構化、短期、**此時此刻(here and now)**，不強調早年經驗或潛意識
   2. 理論基礎：**認知理論加學習理論**
   3. 有**家庭作業**，也包含放鬆訓練處理生理反應
2. 步驟
   1. 讓病人看見負向想法如何影響情緒與行為
   2. 找出**支持與反對**想法的證據（**現實檢驗**），排除自我中心的解讀
   3. 找出背後的內在錯誤信念或假設，並修正
   4. **認知再建構**：建立**替代想法**
   5. 安排作業練習
3. 護理溝通示範：病人說「我的小孩一定覺得我很糟」
   1. 適合：「有什麼情況，讓你有這種想法？」（引導病人提出證據）
   2. 不適合：過度保證（「世界上的媽媽都是好媽媽」）、反問批判（「你真那麼糟嗎」）、叫病人別想
4. 運用
   1. 憂鬱症、焦慮症、強迫症（認知再建構加行為作業）
   2. 創傷後壓力症：修正對創傷起因與結果的**扭曲認知**
   3. 飲食障礙症：糾正對食物與體重的扭曲認知
5. 「了解深層經驗結構、尊重保護個案存在的真實性」是**存在主義**的取向，不是 CBT

### 理情行為治療(REBT) {#rebt}

1. 創始者：艾利斯(Ellis)
2. **ABCDE**
   1. **A**(Activating event)：誘發事件
   2. **B**(Belief)：對事件的信念，可能是**非理性**的
   3. **C**(Consequence)：情緒與行為的後果
   4. **D**(Disputing)：**駁斥**非理性信念
   5. **E**(Effect)：產生新的、合理的信念與情緒
3. 重點：引起情緒的不是事件 A，而是對 A 的信念 B
4. 家庭作業：**正確描述情緒(C)**、**記錄客觀事件(A)**、**記錄內在信念(B)**，再找**非理性信念**並以**合理的替代信念**駁斥
5. 不是消除不良的事件情境，也不是建立社交技巧，也不是修正早年創傷經驗

### 現實治療 {#reality-therapy}

1. 創始者：葛拉瑟(Glasser)
2. **3R**：**正當**(Right)、**責任**(Responsibility)、**現實**(Reality)，藉此有效管理個人生活
3. 重點
   1. 重視**此時此刻與未來**，不重視過去的探討
   2. 協助病人為自己的行為負責
   3. 先建立良好治療關係
4. 不是潛意識引導，也不是以面質矯正錯誤認知

## 學派比較 {#comparison}

| 學派 | 看問題的角度 | 治療焦點 | 關鍵字 |
|---|---|---|---|
| 精神分析 | 潛意識衝突、早年經驗 | **過去**，探索與解析 | 自由聯想、夢的解析、抗拒、移情 |
| 行為 | 學習而來的行為 | **目前**可觀察的行為 | 增強、代幣、逐步養成、系統減敏 |
| 認知 | 扭曲的想法 | **此時此刻**的想法 | 認知三合一、自動化想法、認知再建構 |
| 理情(REBT) | 非理性信念 | 想法與信念 | ABCDE、駁斥 |
| 現實 | 行為的責任 | 此時此刻與未來 | 3R |
| 人本 | 成長與自我實現 | 當事人的經驗 | 無條件正向關懷 |
| 人際(IPT) | 人際功能 | 現在的人際問題 | 悲傷、糾紛、角色轉換 |
