孕期護理的目標是讓孕婦了解身體變化、減輕不適、吃得夠也吃得對，並為分娩做準備。本頁整理各孕期的不適與處理、危險徵象、姿勢與運動、會陰按摩、性生活、營養與體重、文化飲食，以及生產準備；不適的生理原因見 [[maternal-adaptation]]，產檢與胎動計數見 [[prenatal-assessment]]，孕期疫苗見 [[perinatal-infections#pregnancy-vaccines]]，一般營養評估見 [[nutrition-assessment-diets]]。文中縮寫：BMI(Body mass index，身體質量指數)、DRIs(Dietary Reference Intakes，國人膳食營養素參考攝取量)

## 重點摘要 {#summary}

- 第一孕期不適：**孕吐**、頻尿、乳房脹痛、疲倦、白帶增加；第二、三孕期：**心灼熱感、便秘、痔瘡、靜脈曲張、下肢水腫、小腿抽筋、下背痛**、呼吸短促、仰臥低血壓
- **頻尿**：白天**照常喝水**，睡前少喝；有灼熱痛、血尿才就醫
- **下肢水腫**：**左側臥**、抬高下肢、**足背屈運動**、穿舒適軟鞋；不要穿**及膝**彈性襪(勒住膝下)
- **下背痛**：**骨盆搖擺(傾斜)運動**、腹肌強化、腰背伸展、正確坐姿(背挺直、重量落在**坐骨**)
- 伸展會陰最有效：**蹲踞運動**；強化骨盆肌肉：**盤腿坐、凱格爾、蹲踞**
- **會陰按摩**：約 **34 週**起，每週 3–4 次以上；潤滑後拇指伸入陰道約 3–5 公分，往**下(肛門方向)與兩側**壓成 U 形
- 有流產或早產病史、出血、破水、前置胎盤 → **避免性交**，可擁抱親吻
- 熱量：**第二、三孕期每天加約 300 大卡**；蛋白質加 10 公克；**哺乳期**蛋白質加 15 公克(比懷孕多)
- **葉酸**孕前就開始；**第三孕期補鐵**；素食者注意 **B12**、鐵、鋅
- 增重依孕前 BMI(下方表)；第一孕期增加最少
- 生產計畫書由**婦女表達需要並做選擇**；生產球依**身高**選尺寸

### 國考常考點 {#exam-points}

- 懷孕 30 週下背痛優先教**骨盆搖擺運動**；**凱格爾運動不是**減下背痛的運動
- 第三孕期下肢腫脹：穿**及膝彈性襪**是不適當的(應穿褲襪型或全長彈性襪)
- 坐姿：背挺直、重量集中在**坐骨**；選有靠背的椅子，坐滿椅面
- 會陰按摩：約 32–34 週開始、每週 3–4 次；**不是無菌技術**；目的是**增加**延展性；有微熱感是正常；按壓方向是**往下與兩側**，不是往上
- 有 18 週流產史的孕婦諮詢性生活：**避免性交，但可擁抱、親吻**
- 第一孕期常孕吐，**體重增加最少**；熱量依**母體耗氧增加**而增加；BMI 22 第一孕期不必加熱量
- 蛋奶素第三孕期：需補葉酸(深綠色蔬菜)、鐵增加；促進紅血球發育的不是維生素 E
- 妊娠期蛋白質**少於**哺乳期；第一孕期熱量可不增加；不需特別增加維生素 K
- 增重：BMI 18.5–24.9 → **11.5–16 公斤**；BMI 24 → 約 11–15 公斤(國考選項)；BMI 30 → **5–9 公斤**、不可節食減重；第二、三孕期每週約 0.4–0.5 公斤(不是 0.3)、第三孕期每月 1.5–2 公斤；雙胞胎不是單胞胎的 2 倍
- 20 週、BMI 20、增重 3 公斤、子宮底在臍上一橫指 → **符合週數**，維持即可
- 25 週增重 3 公斤偏少 → 先**評估飲食**(「您目前吃得如何？」)，不是直接下結論
- 孕婦的文化飲食習慣(不吃冰、喜辣)：**尊重**、不批判，評估飲食；不要和公婆一起說服她
- 廓清式呼吸是在每次宮縮**開始與結束**各做一次的**深而慢**的呼吸，不是正常速率的 2 倍
- 生產球依**身高**挑尺寸；32 週可開始練習；最好有人陪伴

## 各孕期的不適與處理 {#discomforts}

### 第一孕期 {#first-trimester}

| 不適 | 原因 | 處理 |
|---|---|---|
| **噁心嘔吐(孕吐)** | hCG、雌激素上升；胃排空慢 | **少量多餐**；**起床前吃蘇打餅乾等乾點心**、慢慢起床；避免油膩與強烈氣味；乾濕分開；維生素 B6、薑；嚴重脫水、體重下降 → 妊娠劇吐(見 [[high-risk-pregnancy#hyperemesis]]) |
| **頻尿** | 子宮壓迫膀胱 | **白天維持適當飲水**，睡前少喝；勿憋尿；凱格爾運動；有灼熱痛、血尿、發燒才是感染 |
| 乳房脹痛 | 雌激素、黃體素 | 穿合適、有支撐的胸罩 |
| 白帶增加 | 雌激素 | 清水清潔、穿棉質內褲、不灌洗；癢、異味、黃綠色要就醫 |
| 疲倦、嗜睡 | 黃體素、代謝增加 | 多休息、午睡 |
| 鼻塞、流鼻血 | 雌激素使黏膜充血 | 加濕、生理食鹽水 |

::questions{ids="108-2_OP_009"}

### 第二、三孕期 {#later-trimesters}

| 不適 | 原因 | 處理 |
|---|---|---|
| **心灼熱感** | **黃體素**使賁門鬆弛、子宮推擠胃 | **少量多餐**；**飯後不立即躺下**、睡覺墊高床頭；避免油炸、辛辣、咖啡；必要時依醫囑制酸劑 |
| **便秘** | 黃體素使腸蠕動慢、鐵劑、子宮壓迫 | 多喝水、高纖、規律運動、定時排便 |
| **痔瘡** | 便秘＋骨盆靜脈壓迫 | 預防便秘、溫水坐浴、避免久坐久站 |
| **靜脈曲張** | 子宮壓迫下腔靜脈、靜脈壁鬆弛 | 抬高下肢、避免久站與翹腿；穿**全長或褲襪型**彈性襪(早上起床前穿) |
| **下肢水腫** | 靜脈回流受阻、水分滯留 | **左側臥**、**抬高下肢**、**足背屈運動**、穿舒適軟鞋；**避免及膝彈性襪**與過緊衣物；**臉、手突然水腫**要量血壓(子癇前症) |
| **小腿抽筋** | 鈣磷不平衡、神經受壓、疲勞 | 抽筋時**伸直膝蓋、把腳掌往上扳(背屈)**；補充鈣；避免伸直腳尖 |
| **下背痛** | **腰椎前凸**、重心前移、韌帶鬆弛 | **骨盆搖擺(傾斜)運動**、腹肌強化、腰背伸展；正確姿勢、低跟鞋、硬床；撿東西蹲下而非彎腰 |
| 圓韌帶痛(鼠蹊痛) | 圓韌帶被拉扯 | 慢慢改變姿勢、側躺屈膝、熱敷 |
| 呼吸短促 | 橫膈上抬 | 姿勢挺直、睡覺墊高上身 |
| 頭暈、**仰臥低血壓** | 子宮壓迫下腔靜脈、血管擴張 | **左側臥**、慢慢起身、避免久站 |
| 腕隧道症候群 | 水腫壓迫正中神經 | 副木、抬高手 |
| 失眠 | 胎動、頻尿、不舒服 | 側臥加枕頭支撐、睡前放鬆 |

### 危險徵象 {#warning-signs}

出現以下情況要**立即就醫**：

1. **陰道出血**
2. **陰道流出水樣液體**(破水)
3. **劇烈頭痛、視力模糊、上腹痛**、臉與手突然水腫(子癇前症)
4. **胎動明顯減少或停止**
5. 37 週前規則宮縮、下腹痛、背痛(早產)
6. 發燒、畏寒、排尿灼熱
7. 持續嘔吐無法進食

## 姿勢與活動 {#posture}

- **坐姿**：坐有靠背的椅子、坐滿椅面，背挺直，身體重量落在**坐骨**；雙腳平放，可墊小凳
- **站姿**：骨盆微微內收、不要挺肚子；避免久站，換腳或抬一腳
- **起床**：先側翻，再用手撐起身(避免腹肌用力)
- **提物**：蹲下、背打直，用腿出力
- **睡姿**：第二孕期後**左側臥**，膝間放枕頭

## 運動 {#exercise}

- 沒有禁忌時，每週約 **150 分鐘中等強度**有氧運動(健走、游泳、孕婦瑜伽、固定式腳踏車)(ACOG 2020)
- 避免：接觸性與易跌倒的運動、潛水、高溫環境運動(熱瑜伽)、第一孕期後**長時間仰躺**
- 停止運動並就醫：陰道出血、漏水、規則宮縮痛、頭暈、胸痛、呼吸困難、小腿腫痛
- **產前運動**

| 運動 | 目的 |
|---|---|
| **蹲踞運動** | **伸展會陰與骨盆底**、增加骨盆出口，最有效的會陰伸展運動 |
| **盤腿坐** | 伸展大腿內側、**強化骨盆底肌**、增加骨盆關節活動 |
| **凱格爾運動** | 收縮放鬆**骨盆底肌**(陰道、肛門)，預防尿失禁、產後恢復 |
| **骨盆搖擺(傾斜)運動** | **減輕下背痛**、增加腰部柔軟度 |
| 腹肌強化、腰背伸展 | 支撐腰背、減輕背痛 |
| 腿部與足背屈運動 | 促進下肢循環、減少水腫與抽筋 |

- 凱格爾運動做法見 [[urinary-elimination#kegel]]

## 會陰按摩 {#perineal-massage}

- 目的：增加會陰組織的**延展性**，減少分娩時的會陰裂傷與會陰切開(初產婦效果較明顯)
- 時機：約 **34 週**起(國考答案：32–34 週或預產期前 6 週)，每週 **3–4 次以上**，每次約 5–10 分鐘
- 做法
   1. 洗手、剪短指甲(**清潔即可，不是無菌技術**)
   2. 半坐臥或**一腳踩在椅子上**，可用鏡子
   3. 手指(或拇指)塗**潤滑油**，伸入陰道約 **3–5 公分**
   4. 往**下(肛門方向)壓**，再往**兩側**呈 U 形推，維持到有**微熱、緊繃感**(正常)
   5. 避開**尿道口**(預防泌尿道感染)
- 禁忌：陰道感染、前置胎盤、出血、破水

## 日常生活 {#daily-living}

- **性生活**
   1. 正常懷孕整個孕期都可以，姿勢以不壓迫腹部為主(側臥、女上位)
   2. **避免性交**：陰道出血、**破水**、前置胎盤、**流產或早產病史**、早產徵兆、子宮頸閉鎖不全；可用擁抱、親吻等方式維持親密
   3. 精液含前列腺素、乳頭刺激會引起宮縮
- **工作**：避免長時間站立、提重物、接觸化學物或輻射；勞基法有產檢假與孕期調整工作的保障
- **旅行**：安全帶繫在**腹部下方**(骨盆)與胸前；長途每 1–2 小時起來走動；36 週後避免長途
- **沐浴**：淋浴為主，避免泡太熱的水與三溫暖
- **戒菸、戒酒**(胎兒酒精症候群)、避免二手菸；用藥前先問醫師
- 牙科：第二孕期最適合治療
- 疫苗：流感、百日咳(Tdap)、新冠疫苗可接種；活性疫苗(MMR、水痘)懷孕禁打

## 營養 {#nutrition}

### 每日需要量 {#nutrient-needs}

| 營養素 | 懷孕 | 哺乳 | 說明 |
|---|---|---|---|
| **熱量** | 第一孕期 **+0**；**第二、三孕期 +300 大卡** | **+500 大卡** | 依母體**耗氧與代謝增加**；不是「一人吃兩人補」 |
| **蛋白質** | **+10 公克**(第二期起，第一期依 DRIs 版本 +0 或 +10，待核對第八版原表) | **+15 公克** | 胎兒、胎盤、子宮、乳房、血液增加；**哺乳期比懷孕期多** |
| **葉酸** | 每天 **400 μg** 從**懷孕前**就開始補充(孕期總需要約 600 μg) | | 預防**神經管缺陷**；深綠色蔬菜、肝臟、豆類；曾生神經管缺陷兒者依醫囑高劑量 |
| **鐵** | **第三孕期到產後 2 個月**每天另補充約 **30 毫克**鐵劑(總建議量約 45 毫克) | 同左 | 生理性貧血與胎兒儲存；**配維生素 C 或柳橙汁**吃，**不和牛奶、茶、咖啡同服**；會便秘、黑便 |
| 鈣 | 每天 1,000 毫克(不另增加) | 同左 | 牛奶、小魚乾、豆製品；不足時抽筋 |
| 碘 | 需要量增加 | 增加 | 加碘鹽、海帶海苔；胎兒腦部發育 |
| 維生素 D | 每天 400 IU(10 μg) | 同左 | 曬太陽、強化食品 |
| 維生素 B12 | 稍增加 | 稍增加 | **素食者**易缺 → 蛋奶、強化食品或補充劑 |
| 維生素 K | 不必特別增加 | | 新生兒出生後注射 |
| 水分 | 每天 2,000–3,000 mL | 多喝 | 預防便秘與泌尿道感染 |

- 數值依國人膳食營養素參考攝取量(北醫附醫衛教單張)；碘、B12 的增加量待核對第八版原表

### 飲食原則與禁忌 {#diet-principles}

- 均衡六大類，**選多醣類**(全穀)、少單醣精緻糖；少量多餐
- **避免**：酒精、生食與未熟的肉蛋(弓形蟲、李斯特菌)、未殺菌乳製品、**大型魚**(鯊魚、旗魚、鮪魚的汞)；咖啡因每天 **< 200–300 毫克**(約 1–2 杯咖啡)
- **素食孕婦**
   1. 蛋奶素：多吃蛋奶、豆類、全穀、堅果
   2. 全素易缺：**B12、鐵、鋅、鈣、維生素 D、ω-3**；吃海苔海藻、強化食品，依醫囑補充 B12
   3. 葉酸從深綠色蔬菜攝取；第三孕期鐵劑增加
- **文化飲食習慣**(不吃冰、坐月子食物、辣與冷食)：先**評估**飲食與理由，**尊重、不批判**，不違反營養原則就接受，必要時提供正確資訊讓孕婦自己決定；不要和家人一起說服她

### 體重增加 {#weight-gain}

依**孕前 BMI**(單胞胎，IOM 2009；國健署孕婦健康手冊沿用)

| 孕前 BMI | 總增重 | 第二、三孕期每週 |
|---|---|---|
| **< 18.5** | **12.5–18 公斤** | 約 0.5 公斤 |
| **18.5–24.9** | **11.5–16 公斤** | 約 **0.4–0.5 公斤**(每月約 1.5–2 公斤) |
| 25.0–29.9 | **7–11.5 公斤** | 約 0.3 公斤 |
| **≥ 30** | **5–9 公斤** | 約 0.2 公斤 |

- 第一孕期只增加約 **0.5–2 公斤**(常孕吐，**三個孕期中最少**)；大部分在第二、三孕期
- 雙胞胎：BMI 正常者約 17–25 公斤(**不是單胞胎的 2 倍**)
- 肥胖孕婦：**不可節食或減重**、不採極低熱量飲食；控制增重在 5–9 公斤
- 增重太少：先**評估飲食內容**，再一起調整；太多：增加妊娠高血壓、妊娠糖尿病、巨嬰風險
- 判讀例：孕前 BMI 20、20 週增重 3 公斤、子宮底在臍上一橫指 → **與週數相符**

## 生產準備 {#childbirth-preparation}

- 產前教育的方向與內容見 [[obstetric-nursing-foundations#childbirth-education]]
- **生產計畫書**
   1. 包含待產、分娩(姿勢、減痛、陪伴者、會陰切開、斷臍)、產後與寶寶照護(肌膚接觸、哺乳、親子同室)的選擇
   2. 也說明醫院的流程與常規
   3. 鼓勵婦女**表達擔憂與需要**；醫護人員提供資訊與討論，**由婦女做選擇**(國考答案認為「兩者共同做決定」不適當)
   4. 有醫療狀況時可能需要調整，事先說明
- **拉梅茲呼吸**
   1. **廓清式呼吸**：每次宮縮**開始與結束**各做一次**深而慢**的呼吸，當作放鬆與開始結束的訊號
   2. 慢速胸式呼吸：約平常速率的一半，用在早期宮縮
   3. 加速呼吸、喘息吹氣：宮縮變強時用，速率較快但不超過平常的 2 倍，避免過度換氣(手腳麻、頭暈 → 用手或紙袋罩口鼻)
   4. 依產婦需要與放鬆程度調整，不必死板
- **生產球**
   1. 第三孕期即可開始練習
   2. 尺寸依**身高**挑選(坐上去膝蓋與髖同高或略低)
   3. 坐姿搖擺可放鬆**會陰與骨盆**、幫助胎頭下降
   4. 第一次使用最好**有人陪伴**，避免跌倒
- 何時到醫院(規則宮縮、破水、見紅)見 [[intrapartum-care#when-to-go]]；非藥物減痛見 [[pain-management]]
