家庭計畫是讓夫妻依自己的意願決定生育的時機與人數，護理師要提供各種方法的正確資訊，讓個案自己選擇。本頁整理選擇原則、各方法的效果比較、自然避孕法的算法、屏障法、子宮內避孕器、結紮，以及產後與哺乳期的避孕；口服避孕藥、避孕針、緊急避孕與 RU486 的藥理見 [[sex-hormones#contraceptives]]，人工流產的法規見 [[maternal-child-health]]，月經週期與排卵見 [[female-reproductive-system#menstrual-cycle]]。文中縮寫：IUD（Intrauterine device，子宮內避孕器）、LAM（Lactational amenorrhea method，泌乳無月經法）、BBT（Basal body temperature，基礎體溫）

## 重點摘要 {#summary}

- 選擇避孕法要考慮：**效果**、安全與副作用、**是否哺乳**、**生育計畫**（暫時或永久）、使用方便、宗教文化、**夫妻雙方意願**
- 效果最好（一般使用一年懷孕率 < 1%）：**植入劑、子宮內避孕器、結紮**；效果最差：**殺精劑、自然避孕法、性交中斷法**
- **安全期**（課本算法）：**最短週期 − 18**＝危險期第一天；**最長週期 − 10**＝危險期最後一天；週期不規則、哺乳期不適用
- **基礎體溫**：排卵後上升約 0.3–0.5 ℃；**排卵前 3 天到排卵後 2 天**是危險期；體溫上升代表**已經**排卵
- **子宮頸黏液**：排卵期清澈、量多、可拉絲 → 危險期
- **泌乳無月經法**：**純哺乳**、**月經沒恢復**、**產後 6 個月內**三者都符合才可靠
- 哺乳期**避免含雌激素**的避孕藥（減少乳汁），改用單純黃體素、IUD、保險套
- **保險套**是唯一同時預防**性傳染病**的方法
- **女性結紮**可在產後 **24–48 小時**內做；不影響排卵與月經
- **男性結紮**後**不會立即**有效，要等精液檢查確認無精子（約 3 個月）

### 國考常考點 {#exam-points}

- 安全期法要用**過去數個月的紀錄**找出**最長與最短週期**，不是只憑記憶
- 安全期的避孕效果遠低於 80%（一般使用一年懷孕率約 24%）；卵子排出後只存活約 **24 小時**，不是 48–72 小時
- 基礎體溫高溫期約 36.7 ℃、低溫期約 36.5 ℃，**排卵時稍降**（約 36.2 ℃），排卵後才上升
- 哺乳期**單一雌激素**避孕藥會**減少奶量**，不適合；不哺乳打算生育也要選可逆的方法；永久避孕時男性結紮手術較簡單
- 女性結紮後卵巢**仍會排卵**，卵子被身體吸收；男性結紮不經腹腔，**不會**腹腔沾黏

## 選擇與效果比較 {#comparison}

一般使用(typical use)第一年懷孕率，數字依 CDC 2014 附錄(Trussell 2011)

| 方法 | 一般使用懷孕率 | 可逆 | 防性病 | 重點 |
|---|---:|---|---|---|
| 皮下植入劑 | 0.05% | 是 | 否 | 黃體素，約 3 年 |
| **輸精管結紮** | 0.15% | 否 | 否 | 要確認無精子才有效 |
| 含黃體素 IUD | 0.2% | 是 | 否 | 經血量減少 |
| **輸卵管結紮** | 0.5% | 否 | 否 | |
| 銅 IUD | 0.8% | 是 | 否 | 可當緊急避孕；經血量可能增加 |
| 避孕針 | 6% | 是 | 否 | 每 3 個月 |
| 口服避孕藥、貼片、陰道環 | 9% | 是 | 否 | 漏吃就失敗 |
| 子宮帽 | 12% | 是 | 否 | |
| **男用保險套** | 18% | 是 | **是** | |
| 女用保險套 | 21% | 是 | 是 | |
| 性交中斷法 | 22% | 是 | 否 | 射精前液可能含精子 |
| **自然避孕法**（安全期、基礎體溫、黏液） | 24% | 是 | 否 | 完全正確使用可降到約 3–5% |
| 殺精劑 | 28% | 是 | 否 | 不能預防 HIV |

- 一般使用和完全正確使用差很多的方法（避孕藥、保險套、自然法），衛教重點是**正確、持續使用**
- 泌乳無月經法：三個條件都符合時，產後 6 個月內效果約 98%(WHO)

## 自然避孕法 {#natural-methods}

不改變生理、沒有副作用，但需要夫妻配合禁慾，失敗率高；也可反過來用在**助孕**（找出易受孕期，見 [[infertility#timing]]）

### 月經週期法（安全期） {#calendar}

- 原理：排卵約在**下次月經前 14 天**（±2 天）；卵子可存活約 1 天、精子約 3 天
- 算法（課本書頁約 496）
   1. 記錄過去數個月（一般建議至少 6 個月）的月經週期，找出**最長**與**最短**
   2. **最短週期 − 18 ＝ 危險期第一天**
   3. **最長週期 − 10 ＝ 危險期最後一天**
   4. 例：週期 28–32 天 → 28 − 18 ＝ 10、32 − 10 ＝ 22 → 月經第 **10–22 天**是危險期
- 另一常見版本(Ogino-Knaus)：最短 − 18、最長 − **11**；作答依題目選項
- 不適用：**月經不規則**、產後與哺乳期、接近更年期

### 基礎體溫法 {#bbt}

- 每天**早上醒來尚未起床活動前**測量並記錄，連續 3–6 個月
- 排卵前約 36.5 ℃；排卵時稍降約 36.2 ℃；排卵後黃體素使體溫上升到約 36.7 ℃ 並維持約 2 週（課本書頁約 497）
- **危險期：排卵前 3 天到排卵後 2 天**
- 限制：體溫上升時已經排卵，**無法事先預測**排卵；發燒、睡眠不足、飲酒、情緒會影響
- 高溫期**超過 18 天**沒來月經 → 可能懷孕

::questions{ids="108-2_OP_017"}

### 子宮頸黏液法與其他 {#mucus-lam}

- **子宮頸黏液法**（比林斯法）：月經後乾燥期 → 排卵前混濁黏稠 → **排卵期清澈、量多、滑、可拉絲（像蛋白）＝危險期** → 排卵後變少變稠
- 症狀體溫法：黏液＋基礎體溫一起判斷，比單一方法準
- **泌乳無月經法**：純哺乳（或幾乎純哺乳、夜間也餵）抑制排卵；**三個條件**都要符合：**純哺乳、月經未恢復、產後 6 個月內**；任一不符就要改用其他方法
- **性交中斷法**：射精前抽出；射精前液可能有精子，失敗率高

## 屏障法 {#barrier}

- **男用保險套**
   1. 勃起後、任何接觸前戴上；捏住前端空氣、留儲精空間
   2. 射精後在陰莖變軟前握住套口一起抽出
   3. 只用水性潤滑劑（油性會讓乳膠破裂）；每次用新的
   4. **唯一能預防性傳染病與 HIV** 的避孕方法（見 [[sexually-transmitted-infections]]）
- 女用保險套：女性自己控制，可預防性病
- **子宮帽**：需醫師量尺寸，配合殺精劑；性交後**至少留 6 小時**再取出、24 小時內取出（避免中毒性休克症候群）；體重變化大或產後要重新量
- 殺精劑：單獨使用效果差；頻繁使用可能刺激黏膜、增加 HIV 感染機會

## 子宮內避孕器 {#iud}

- 種類：**銅 IUD**（無荷爾蒙，銅離子造成無菌性發炎、毒殺精子）、**含黃體素 IUD**（子宮頸黏液變稠、內膜變薄，見 [[sex-hormones#contraceptive-types]]）
- 放置時機：**月經期或月經剛結束**（子宮頸較開、可排除懷孕）；產後約 **4–6 週**返診，或胎盤娩出後立即放置；銅 IUD 也可在性行為後 5 天內放置當緊急避孕
- 衛教
   1. 每次**月經後摸尾線**，確認還在；摸不到或摸到硬塑膠要回診
   2. 放置後初期可能有痙攣痛、點狀出血；銅 IUD 經血量與經痛可能增加
   3. 依種類定期更換（3–10 年不等）
   4. 警訊：月經延遲或懷孕徵象、腹痛或性交痛、發燒或異常分泌物（骨盆腔炎）、尾線變長或變短 → 回診
- 禁忌：懷孕、骨盆腔感染或性病、不明原因陰道出血、子宮腔變形、子宮頸癌或子宮內膜癌
- 放置後懷孕：子宮外孕的**比例**較高，要排除

## 結紮 {#sterilization}

| | **女性：輸卵管結紮** | **男性：輸精管結紮** |
|---|---|---|
| 做法 | 腹腔鏡或小切口把輸卵管綁緊切斷、夾住或電燒；剖腹產時可一起做 | 陰囊小切口切斷輸精管，**局部麻醉**、門診手術 |
| 時機 | **產後 24–48 小時內**（子宮底高、腹壁鬆，小切口在臍下）或產後 6 週後 | 任何時候 |
| 生效 | **立即** | **不會立即生效**：輸精管遠端仍有精子，要用其他方法避孕到精液檢查**確認無精子**（約 3 個月或射精約 20 次後） |
| 對生理的影響 | 卵巢仍排卵、分泌激素，**月經照常**；卵子被腹腔吸收 | 睪丸仍分泌睪固酮、仍有射精（只是沒有精子），**不影響性功能**；不進腹腔、不會腹腔沾黏 |
| 風險 | 麻醉與腹腔手術風險；失敗時子宮外孕比例高 | 陰囊血腫、感染 |
| 可逆性 | 視為**永久**；復通手術成功率不一定 | 視為**永久** |

- 結紮前要確認夫妻**都了解是永久性**、無意再生育，並簽同意書；優生保健法相關規定見 [[maternal-child-health]]
- 已確定不再生育的夫妻，男性結紮手術較簡單、風險較低

## 產後與哺乳期避孕 {#postpartum}

- 產後排卵可能在**第一次月經之前**恢復；不哺乳者最早約產後 3–4 週就可能排卵 → 恢復性生活就要避孕
- 哺乳期選擇

| 方法 | 哺乳期 | 理由 |
|---|---|---|
| 泌乳無月經法 | 可，三條件都符合時 | |
| 保險套、IUD、結紮 | **可** | 非荷爾蒙，不影響泌乳 |
| 單純黃體素（迷你丸、避孕針、植入劑、含黃體素 IUD） | 可 | 不減少乳汁 |
| **含雌激素**（複方口服避孕藥、貼片、陰道環） | **避免**；產後 21 天內禁用 | **減少乳汁量**、產後血栓風險高 |
| 單一雌激素製劑 | 不適合 | 同樣會抑制泌乳；而且單用雌激素不是避孕藥 |

- 不哺乳者：複方避孕藥約產後 21–28 天後再開始（國考答案寫 28 天，細節見 [[sex-hormones#contraceptive-contraindications]]）

::questions{ids="113-3_OP_013"}

## 護理與諮詢 {#nursing}

- 評估：年齡、生育史與生育計畫、月經週期、是否哺乳、疾病史（高血壓、血栓、偏頭痛、抽菸）、性伴侶數與性病風險、夫妻溝通與文化宗教
- 原則：提供完整正確的資訊，由**夫妻共同決定**，尊重自主；鼓勵伴侶一起參與
- 衛教內容：使用方法、失敗時怎麼辦（緊急避孕）、副作用、何時回診
- 社區角度的家庭計畫與少子化政策見 [[maternal-child-health]]
