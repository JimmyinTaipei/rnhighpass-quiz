全民健保是**強制性的社會保險**，由**健保署**當唯一保險人，保費由被保險人、雇主、政府共同分擔。國考重點：保險性質、六類投保、眷屬與保費計算、財源、**給付與不給付**、**部分負擔與免部分負擔**、支付制度，以及健康照護經濟學的**道德危害**。DRG、總額對醫院經營的影響見 [[nursing-budgeting-drg]]；衛生行政組織見 [[health-administration-system]]

## 重點摘要 {#summary}

- 性質：**強制性社會保險**、**單一保險人**(中央健康保險署)、**公辦公營**、自給自足與**隨收隨付**；納保率 99% 以上
- 被保險人分**六類**(不是十類)；眷屬保費由被保險人繳，**超過三口以三口計**
- 財源：**保險費**(被保險人、雇主、政府分擔，最主要)、**補充保費**、**菸品健康福利捐**、**公益彩券盈餘**；不包括企業捐款
- **部分負擔**的目的：抑制**道德危害**、強化個人責任、推動**分級醫療**；**重大傷病、分娩、山地離島就醫**免部分負擔
- **不給付**：預防接種(政府負擔)、美容手術、**義齒**、義眼、眼鏡、助聽器、**輪椅**、拐杖、成藥與指示藥、特別護士、病房差額等；血液透析、**針灸**、安寧療護、慢性精神病照護、預防保健**有給付**
- 國外緊急傷病或分娩：可申請**核退自墊醫療費用**
- 支付制度：以**論量計酬**為主＋**DRGs**(論病例)＋論日(精神慢性、日間住院)＋論人(慢性呼吸照護)；整體用**總額支付制度**控制費用

### 國考常考點 {#exam-points}

- 全民健保**不是**非強制性或可自由參加的商業保險
- 現行健保**不是**多元保險人；被保險人分**六**類，不是十類
- 欠繳保費**不會鎖卡**；但保險人對「**有能力繳納而拒不繳納**」者，經查證輔導後可暫停給付(健保法第 37 條)
- 道德危害的對策是**部分負擔**；總額與 DRGs 是控制**供給端**
- 2015 年健保決議是**一般費率與補充費率都調降**(4.91% → 4.69%、2% → 1.91%)，不是「一般調降、補充調高」
- 健全照護體系的原則是可用、可近、可接受、負擔得起；「**可主動性**」不是
- 預防保健(國考題依當時規定)：成人預防保健 40–64 歲**每 3 年**、65 歲以上每年；子宮頸抹片 30 歲以上**每年**；乳房攝影 45–69 歲**每 2 年**；兒童預防保健 7 歲以下共 **7 次**，其中未滿 1 歲 6 個月 **4 次**
- 孕婦**不能**接種德國麻疹疫苗(活性減毒)，抗體陰性者**產後**接種
- 居家護理支付制度的國考答案是**資源耗用群(RUGs)**

## 健保的性質 {#nature}

- 1995 年 3 月開辦，整合原本的勞保、公保、農保等醫療給付；全國醫院幾乎都特約，民眾可到任何特約院所就醫
- **強制性社會保險**(健保法第 1 條)：符合資格者都要投保；基本理念是**危險共同分擔**、互助
- **單一保險人**：中央健康保險署(健保法第 7 條)，公辦公營
- 財務**自給自足、自負盈虧**，以**隨收隨付**維持短期平衡；安全準備來源包括年度結餘、滯納金、**菸酒健康福利捐**(第 76 條)

## 投保與保險費 {#premium}

### 六類被保險人(健保法第 10 條) {#six-categories}

| 類 | 對象 |
|---|---|
| 第一類 | 公務人員、公職人員、受僱者、**雇主**、自營業主、專門職業自行執業者 |
| 第二類 | 無一定雇主而參加**職業工會**者、外僱船員 |
| 第三類 | **農會、漁會**會員或實際從事農漁業者 |
| 第四類 | 義務役、替代役、軍校軍費生、矯正機關收容人 |
| 第五類 | **低收入戶** |
| 第六類 | 榮民與榮眷家戶代表、其他地區人口的家戶戶長 |

- 投保順序：有雇主由雇主投保 → 無固定雇主加入職業工會或農漁會 → 沒工作的人依附有工作的親屬當**眷屬** → 都沒有則到**鄉鎮市區公所**投保

### 保險費 {#premium-calc}

- 一般保險費＝投保金額 × **費率** × 負擔比例 × (本人＋眷屬人數)
- 費率上限 **6%**(第 18 條)；**2021 年起一般費率 5.17%、補充保費 2.11%**，2026 年仍維持
- 眷屬保費由被保險人繳，**超過三口以三口計**(第四口起免繳)
- 保費由**被保險人、雇主(投保單位)、政府**依類別比例分擔；低收入戶由政府全額負擔
- **補充保險費**(二代健保 2013 年起)：六類所得
   1. 全年累計超過當月投保金額 **4 倍**的獎金
   2. 兼職薪資
   3. 執行業務收入
   4. 股利
   5. 利息
   6. 租金
- 二代健保 2013 年開始時一般費率降為 4.91%；2015 年再調降為 4.69%、補充費率 1.91%

### 欠費 {#arrears}

- 國考答案：未繳保費**不會被鎖卡**
- 健保法第 37 條：對**有能力繳納而拒不繳納**者，經查證與輔導後可**暫停給付**；已由投保單位扣繳、分期繳納中、家暴受保護期間不在此限

## 給付範圍 {#benefits}

- 七大類：
   1. 門診(西醫、牙醫，含**血液透析**、產檢、分娩)
   2. 住院(含管灌飲食、呼吸照護病房)
   3. **中醫**(含**針灸**、傷科)
   4. 生育(自然產、剖腹產、新生兒照護，免部分負擔)
   5. **預防保健**(兒童、成人、產檢、子宮頸抹片、乳房攝影；2006 年起經費改由國健署公務預算支應)
   6. 其他：復健、**居家照護**、**慢性精神病**、社區復健、**安寧療護**
   7. 藥品與特殊材料
- **不給付**(第 51 條)：

| 類別 | 項目 |
|---|---|
| 由政府負擔 | **預防接種**、其他法令規定由政府負擔的醫療 |
| 非必要醫療 | 藥癮治療、**美容外科**、非外傷齒列矯正、預防性手術、人工生殖、變性手術 |
| 藥品 | 成藥、指示藥 |
| 人員與費用 | 指定醫師、**特別護士**、病房費差額、膳食(管灌除外)、病人交通、掛號、證明文件 |
| 裝具 | **義齒**、義眼、眼鏡、助聽器、**輪椅**、拐杖 |
| 其他 | 血液(緊急輸血除外)、人體試驗、日間住院(精神病除外) |

### 核退自墊醫療費用 {#reimbursement}

- 可以申請核退的情況(第 55 條)：
   1. 國內因**緊急傷病或分娩**，在非特約院所立即就醫
   2. **國外**罹患公告的特殊傷病、**不可預期的緊急傷病或緊急分娩**，在當地就醫(核退金額有上限)
   3. 暫停給付期間就醫，之後繳清保費
   4. 住院部分負擔全年累計超過上限的部分
- 國外就醫要在**門急診當日或出院日起 6 個月內**申請(國考詳解)

## 部分負擔 {#copayment}

### 目的與類型 {#copayment-purpose}

- 保險讓就醫的價格變低，民眾容易過度使用 → **道德危害**；部分負擔讓病人負擔一部分費用，以：
   1. 抑制不必要的醫療利用
   2. 強化個人責任
   3. 推動**分級醫療**，避免病人集中到大醫院
- 類型：**定率**(coinsurance，按比例)、**定額**(copayment，固定金額)、**自負額**(deductible)

### 法定比率(健保法) {#copayment-rates}

- 門診與急診：**20%**；居家照護 **5%**；不經轉診到地區醫院、區域醫院、醫學中心門診：30%、40%、50%(第 43 條；實務上依前一年平均費用改用**定額**公告)
- 住院(第 47 條)：

| 病房 | 10% 以下 | 20% | 30% |
|---|---|---|---|
| **急性**病房 | 30 日內 10% | 31–60 日 | 61 日以上 |
| **慢性**病房 | 30 日內 5%；31–90 日 10% | 91–180 日 | 181 日以上 |

- 現行(2023-07-01 新制，截至 2026-10)：
   1. **急診**改依**醫院層級**定額(醫學中心 750 元、區域醫院 400 元、地區醫院與診所 150 元；**中低收入與身障者** 550／300／150 元)；舊制依檢傷分級收費
   2. **門診藥品**：醫學中心與區域醫院上限提高為 300 元，地區醫院與診所上限 200 元
   3. **慢性病連續處方箋**：醫院**第 1 次**調劑也要收藥品部分負擔，第 2 次起免收；診所維持免收
   4. 中低收入與身障者的藥品部分負擔，不論院所層級都按**基層診所**方式收
   5. 目的：落實**分級醫療**，讓大醫院回歸急重難罕，病情穩定的慢性病人回基層

### 免部分負擔 {#copayment-exemptions}

- 法定(第 48 條)：**重大傷病**、**分娩**、**山地離島地區就醫**
- 其他(課本整理)：離島轉診到本島當次、榮民與榮眷家戶代表、**低收入戶**、**3 歲以下兒童**、列管**結核病**病人到指定院所、勞保職業傷病、油症病人；身心障礙者門診基本部分負擔按診所層級收取

## 支付制度 {#payment}

| 方式 | 說明 | 健保使用 |
|---|---|---|
| **論量計酬**(fee-for-service) | 依每項服務的支付標準逐項計費 | 主要方式；給付項目**正面表列** |
| **論病例計酬**(case payment)／**DRGs**(Diagnosis-Related Groups) | 同一診斷關聯群定額包裹支付；源自美國 1983 年 Medicare | 選擇性手術與部分住院 |
| **論日計酬**(per-diem) | 每住一天固定支付 | 精神科慢性病床、日間住院 |
| **論人計酬**(capitation) | 每人每期固定支付 | 慢性呼吸照護病房 |
| **資源耗用群**(RUGs，Resource Utilization Groups) | 依照護需求分群支付，長照與居家常用 | 國考 105-2 題：**居家護理**的答案 |

- **總額支付制度**(global budget)：健保法第 60–65 條；衛福部擬總額範圍 → 行政院核定 → **健保會**與醫院、西醫基層、牙醫、中醫四個部門協商；各部門再依分區分季算**點值**，控制費用成長
- 居家護理的實際申報是**訪視費加各項處置費**(論次、論量)，RUGs 是教科書寫法與研究方向，作答依國考答案
- 新藥依安全、療效、相對療效、預算衝擊、藥事經濟、倫理社會衝擊審查；用藥價調查讓健保價趨近市場價
- 醫院經營與 DRG 的細節見 [[nursing-budgeting-drg]]

|---|---|---|

| 乳房攝影 | 45–69 歲(40–44 歲有家族史)每 2 年 | 2025 年起 **40–74 歲**每 2 年 |
| 糞便潛血 | 50–74 歲每 2 年 | 2025 年起 **45–74 歲**每 2 年；40–44 歲一等親有大腸癌也可 |
| 肺癌低劑量電腦斷層(LDCT) | 無 | 2025 年起：一等親有肺癌的 45–74 歲男性、40–74 歲女性；50–74 歲重度吸菸(≥ 20 包年)；每 2 年 |
| 口腔黏膜 | 30 歲以上吸菸或嚼檳榔(含已戒)；18 歲以上嚼檳榔原住民 | 相同 |
| 兒童預防保健 | 7 歲以下共 **7 次**；未滿 1 歲 6 個月 **4 次** | |
| 孕婦產檢 | 舊題寫 10 次 | **14 次**(使用者確認)；新住民產檢補助見 [[maternal-child-health#prenatal]]，產檢細節見 [[prenatal-assessment]] |
| 兒童牙齒塗氟 | 未滿 6 歲每半年；弱勢兒童每 3 個月 | 見 [[maternal-child-health#oral-health]] |

- 例：53 歲女性、無菸、檳榔已戒 → 乳房攝影、子宮頸抹片、糞便潛血、口腔黏膜**都可以做**
- 例：49 歲女性、無菸檳 → 成人預防保健、子宮頸抹片、乳房攝影
- 孕婦德國麻疹抗體陰性：**不能**在孕期接種 MMR(活性減毒疫苗)，**產後**補接種，見 [[immunization]]

## 健康照護經濟 {#health-economics}

### 健康照護的特性 {#characteristics}

- 需求的**時點與內容不確定**(不知道何時生病、要用多少)，所以需要保險分散風險
- 有**外部效用**(例：預防接種保護別人)
- **無法預先生產與庫存**；使用與製造**不可分離**；使用者也參與成果的製造
- **資訊不對稱**：醫療提供者比病人懂，可能**誘發需求**(供給誘發需求)

### 保險帶來的問題 {#insurance-problems}

| 名詞 | 發生時間 | 意思 | 對策 |
|---|---|---|---|
| **道德危害**(moral hazard) | **投保後** | 就醫便宜了，就**過度使用**醫療或減少預防行為 | **部分負擔**、轉診制度 |
| **逆選擇**(adverse selection) | **投保前** | 高風險的人比較想投保、低風險的人不投保 | **強制納保** |

- 健全照護體系的評估原則：**可用性、可近性、可接受性、可負擔性**，見 [[community-health-nursing-intro#primary-health-care]]

### 健保的挑戰 {#challenges}

- 人口老化、重大傷病與新科技使費用上升 → 由健保會依「量出為入、收支連動」定期微調費率
- 近貧戶繳不出保費 → 擴大弱勢保費補助
- 總額壓抑住院服務 → 適度鬆綁
- 昂貴新藥與新科技 → 籌措財源納入給付
- 數位化：**健康存摺**(民眾查詢自己的就醫資料)、**雲端藥歷**(避免重複用藥)、健康醫療雲

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 健保是非強制或可自由參加的商業保險 | **強制性社會保險** | |
| 多元保險人 | **單一保險人**(健保署) | |
| 被保險人分十大類 | **六類** | |
| 主要財源是公益彩券與菸捐 | 主要是**保險費** | 菸捐、彩券是補充 |
| 企業捐款是財源 | 不是 | |
| 未繳保費就鎖卡 | 不鎖卡；有能力拒繳才可能暫停給付 | |
| 義齒、輪椅有給付 | **不給付** | 非積極治療性裝具 |
| 針灸不給付 | 中醫針灸**有給付** | |
| 國外就醫只能全額自費 | 可**申請核退** | |
| 防道德危害用總額或 DRGs | 用**部分負擔** | 總額、DRGs 控制供給端 |
| 孕婦抗體陰性可在孕期打德國麻疹疫苗 | **產後**才打 | 活性減毒疫苗 |
