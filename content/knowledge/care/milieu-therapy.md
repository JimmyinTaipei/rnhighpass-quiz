**環境治療**把病房、日間留院、康復之家等整個環境當成治療工具：透過**安全、結構化、支持性**的環境與人際互動，讓病人學習適應、增進自主與自我價值。護理人員與病人相處的時間最長，所以是環境治療最重要的執行者。團體與家庭治療見 [[group-family-therapy]]，行為與認知治療見 [[individual-cognitive-behavioral-therapy]]，社區精神醫療服務的大架構之後整理在社區心理衛生頁

## 重點摘要 {#summary}

- **環境治療**＝**治療性社區**：提供安全、結構、支持、使參與與肯定，讓病人有**自主與參與決策**的機會，工作人員是**角色模範**
- **硬體與氣氛**：時鐘與月曆增加**現實感與定向感**；允許在安全前提下擺放**私人物品**；保護室要有觀察窗與中性柔和的色彩
- **依病人調整**：**躁症與暴力者減少刺激**、**憂鬱者防自殺並給希望**、**被害妄想者簡要問候保持距離**；**避免競爭性活動**
- **態度治療(門寧格)**：退縮者**主動友善**、多疑者**被動友善**、操控與過分要求者**就事論事**
- **復健機構**：**日間留院**(症狀穩定、有復健潛能、夜間可返家)、**康復之家**(住宿、日常自理、學習社區生活)、**庇護性工廠**(保護性工作)、**護理之家**(缺乏復健潛能、高度照護)

### 國考常考點 {#exam-points}

- 在病房公共區域掛**時鐘與日曆**：增加**定向感與現實感**，是**現實導向**的措施，尤其適合老人、失智與譫妄
- 環境治療的**緊急處置**重點功能是**保護(containment)**；環境治療強調**自治自主**，且**住院期間就要連結家庭與社區資源**
- **躁症**或**焦躁攻擊**者要**減少環境刺激**；**憂鬱症**要**監視防自殺**；**暴力病人避免競爭性活動**；保護室不用**鮮紅色**
- **約束與隔離**是**最後手段**，要依醫囑與最少限制原則，不是「即刻使用」，也不是「完全不能用」
- **門寧格態度治療**：**操控、挑撥、過分要求** → **就事論事**；**退縮、憂鬱** → **主動友善**；**多疑、被害妄想** → **被動友善**
- **日間留院**：半開放、**自主與自我管理**；病人**不可自行停藥**，也要學習人際互動與處理家庭衝突
- **康復之家**首要目標是**培養社區獨立生活的能力**，不是減藥、返家或就業；**生活自我管理**優先於庇護性工作
- 症狀穩定、可返家同住、有復健潛能 → **日間型復健機構**；無家屬照顧或家庭支持差 → **住宿型機構或康復之家**；無復健潛能、需高度照護 → **護理之家**
- 精神復健計畫包含**心理復健、職能復健、社會功能復健**，**不含**物理治療復健

## 環境治療的概念 {#concept}

### 定義與功能 {#definition}

1. **milieu** 的意思是「中間的、安全的地方」；治療性環境提供安全、規律、可預測的生活，讓病人在人際互動中學習
2. 環境治療的目標
   1. 透過病人的**自主與被支持的決定**改變行為
   2. 用治療性溝通提升**自尊**
   3. 所有參與者彼此**尊重**
3. 環境治療的五大功能(教科書分類)

| 功能 | 意思 | 例子 |
|---|---|---|
| **保護** containment | 維護病人與他人的**身體安全**，必要時設限 | 緊急情況下最重要的功能，病人躁動攻擊時 |
| **支持** support | 給予接納、關懷與情緒支持 | 護理人員的陪伴與傾聽 |
| **結構** structure | 規律的作息與清楚的規則，增加可預測感 | 住院生活作息表 |
| **使參與** involvement | 讓病人主動參與活動與決策 | 生活討論會、病友會 |
| **肯定** validation | 承認病人的價值與個別性 | 尊重姓名、隱私與意見 |

### 基本原則 {#principles}

1. 設施兼具**人性化**與**家庭化**，增加歸屬感
2. 讓病人有機會**參與環境決策**，提供**自治自主**的機會
3. 活動設計依個別需求與能力多元化，不追求整體一致性
4. 工作人員成為病人的**角色模範**，先自我覺察、尊重自己與他人
5. 提供**限制內的自由**：維持安全、遵守必要規則，但不能無故剝奪病人的合法權益
6. **住院期間就開始**評估與連結家庭與社區資源，為回歸社區做準備

:::exam[國考重點]
環境治療的正確敘述通常是「**兼具人性化與家庭化、讓病人參與環境決策、工作人員是角色模範**」；錯誤選項常是「活動設計宜整體一致」、「嚴格限制私人物品」、「不可讓病人參與決策」
:::

## 治療性環境的設計與運用 {#design}

### 硬體環境 {#hardware}

| 項目 | 做法 | 理由 |
|---|---|---|
| **時鐘與月曆** | 公共區域懸掛 | 提供時間線索，增加**定向感與現實感**(現實導向) |
| **私人物品** | 在安全前提下允許擺放適量物品 | 增加歸屬感與個別性，不是嚴格禁止 |
| **公共電話** | 設置供病人對外聯繫 | 維持社交功能與病人權益 |
| **窗簾** | 可使用防火、無懸掛危險的材質 | 兼顧安全與隱私，不是一律不可裝設 |
| **保護室** | 設**觀察窗**，用淡藍、淡綠等**中性柔和**色彩 | 便於隨時觀察病人；**鮮紅色**會刺激情緒 |
| **護理站玻璃** | 採**強化玻璃** | 防範破壞 |
| **老人病房** | 牆壁與地板用**對比色** | 協助辨認空間界線，**預防跌倒** |
| **損壞的物品** | **立即修繕** | 避免病人利用殘骸自傷或傷人 |

### 環境與活動的原則 {#activity-principles}

1. 住院生活作息表與**生活討論會**是環境治療的常見運用
2. 生活討論會中，病人不斷抱怨規定時(例如躁症病人)
   1. 適當：**接納**其感受，並**邀請其他成員表達經驗**，利用同儕回饋
   2. 不適當：反覆解說條文、放任暢所欲言、直接指出干擾以致增加防衛
3. 活動以**非競爭性**、結構化、簡單、具合作性質的為主，避免引發挫折、敵意與衝動
4. **約束與隔離**是最後手段，依醫囑與最少限制原則，不是「即刻」使用
5. 失智症病人適度提供多感官刺激可能有益，不是一律不適合

### 依疾病與情境調整 {#by-condition}

| 病人情境 | 環境治療的重點 |
|---|---|
| **躁症**、焦躁、攻擊 | **降低**環境刺激(安靜空間、降低音量)，不是增加刺激；必要時依醫囑隔離 |
| **憂鬱症** | **監視**防自殺；高度結構化的環境給安全感；支持自我探索並給予**希望**；以支持與信任處理抗拒，不是外在硬性控制 |
| **思覺失調症(被害妄想、多疑)** | **安全**為第一：注意環境、定時安檢；**簡要適度**的問候，不密集互動；提供新的認同對象；活動不是全部停止，改為低威脅、非競爭的團體 |
| **慢性思覺失調症** | 協助**熟悉環境**(人員、病友、作息、設施)；安排促進人際互動的活動；團體活動建立自信與成就感；**不安排競爭性活動** |
| **廣泛性焦慮症** | 安排**結構性、規律**的活動降低不安；**漸進**參與人際互動；**不面質**挑戰 |
| **老人、失智、譫妄** | **現實導向**：時鐘、月曆與清楚的標示；對比色預防跌倒 |
| **陌生環境造成不安** | 用**環境治療**(而不是認知、行為或心理治療)改善 |

### 門寧格的態度治療 {#attitude-therapy}

依病人的行為特質，採取不同的護理**態度**：

| 態度 | 適用的病人 |
|---|---|
| **主動友善** active friendliness | **退縮、嚴重憂鬱、退化**的病人，由護理人員主動接近 |
| **被動友善** passive friendliness | **多疑、被害妄想**的病人，不強迫互動，讓病人決定距離 |
| **就事論事** matter-of-fact | **操控、挑撥離間、過分要求、反社會**的病人，態度堅定一致、不帶感情、清楚設定界限 |
| **堅定溫和** kind firmness | 需要限制但仍保持尊重關懷的情況，如衝動、躁動(版本與分類略有差異，待核對) |

:::note[待核對]
門寧格態度治療的完整分類，教科書版本不一(例如有些列出「寬容」或「期待」)，本頁只收**歷屆題確實出現的三種**：主動友善、被動友善、就事論事
:::

## 社區中的精神復健與機構選擇 {#rehabilitation}

精神復健(含**心理復健**、**職能復健**、**社會功能復健**，不含物理治療)的目標是提升**生活品質、重新融入社區、減輕家庭照顧負擔**。思覺失調症有七八成會逐漸慢性化，所以要**及早開始**復健計畫；社區心理衛生、三級預防與各機構收案條件見 [[community-mental-health#resources]]

### 機構比較與選擇 {#settings}

| 機構 | 適用對象 | 特色與目標 |
|---|---|---|
| **日間留院**(日間住院、日間型復健機構) | 症狀**已穩定**、有**局部功能退化**與**復健潛能**；**夜間可返家**由家屬照顧 | 介於住院與社區之間，**半開放、有自主性**，白天做生活技能、社交與工作訓練；仍要**規律服藥**、也要學習人際互動與處理家庭衝突 |
| **康復之家**(住宿型) | 症狀穩定、**日常生活可自理**，但家庭支持不足或無處可去 | 首要目標是**培養社區獨立生活的能力**；仍有生活規則與門禁；不是以減藥或返家為主要目標 |
| **住宿型精神復健機構** | **無家屬照顧**或家庭支持系統差 | 提供住宿與復健 |
| **庇護性工廠** | 症狀穩定，需要工作訓練 | **保護性**的工作環境，訓練工作習慣與社交技巧，**最能強化適應社區生活與就業** |
| **支持性就業** | 能力較好者 | **一般職場**加上就業輔導 |
| **慢性住院** | 病情穩定但**嚴重失能**，缺家庭照顧或無復健潛能 | 長期照護 |
| **精神護理之家** | **無復健潛能**、需高度日常生活照護 | 長期療養 |
| **急性住院** | 症狀急性發作、有自傷或傷人危險 | 緊急處置 |

1. 選擇的順序要看三件事
   1. 目前**症狀是否穩定**
   2. **家庭支持**與夜間能不能返家
   3. 有無**復健潛能**
2. 復健目標的**先後順序**
   1. 先是**生活自我管理**(盥洗、整理環境等基本自理)
   2. 再是**社會參與**
   3. 最後才是**職業復健**(庇護性工作、支持性就業)
3. 考題情境對應
   1. 剛住進康復之家 → 培養**社區獨立生活技能**
   2. 日間留院病人不常洗澡、房間堆滿雜物 → 最需要**生活自我管理**，不是危機處置
   3. 症狀穩定、家屬可接受返家同住、有工作與復健潛能 → 出院前轉介**日間型精神復健機構**
   4. 要強化適應社區生活的能力 → **庇護性工廠**
   5. 症狀穩定但局部功能退化，需積極復健 → **日間住院**
4. 復元與賦能的概念見社區心理衛生頁(之後整理)

## 活動治療 {#activity-therapy}

1. **職能治療**：透過有目的的作業活動(日常生活、工作、手工藝、休閒)訓練功能與適應
2. **娛樂治療**：以遊戲、運動等休閒活動促進社交、釋放壓力與提升生活樂趣
3. **藝術、音樂與舞蹈治療**：用創作與表達處理難以言語的情緒
4. 這些屬於**精神復健**的一部分，著重**功能恢復與社會參與**
5. 要依病人的能力與情況安排；對暴力或慢性病人**避免競爭性**活動
