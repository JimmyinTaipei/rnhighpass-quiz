**家庭暴力**是指家庭成員之間的**身體、精神、經濟或性**方面的不法侵害，包括配偶與親密伴侶之間、對兒童、對老人與身心障礙者的虐待與疏忽。暴力常在家中反覆發生、被隱藏，受害者可能以「跌倒」等理由就醫。護理人員是**法定責任通報人員**，要能辨識、保護與通報。精神科病房的暴力處置見 [[schizophrenia#violence]]，創傷後的反應與創傷知情照護見 [[trauma-stress-disorders#trauma-informed-care]]

## 重點摘要 {#summary}

- **對象**：可能發生在**任何具有家庭關係**的人之間（配偶、前配偶、同居伴侶、親屬）；2015 年修法（2016 年施行）後非同居的**親密關係暴力**也可聲請保護令
- **型態**：**身體虐待**、精神（情緒、心理）虐待、**性虐待**、**經濟控制**、**疏忽**、遺棄；**目睹家暴**的兒少也是受害者
- **迷思**：受害者多為女性但**男性也會受害**；成因是**多重因素**；施暴者**多不是精神病人**、**可以改變與控制**暴力行為
- **責任通報**：醫事人員知悉疑似家暴、兒少受虐、老人或身障者受虐、性侵害，**至遲 24 小時內**通報主管機關；**113 保護專線**
- **護理**：**確保安全與隱私最優先**；接納、不批判、**不面質**受暴者的矛盾；詳實記錄與驗傷；說明保護令與資源；尊重受暴者的決定並提供安全計畫

### 國考常考點 {#exam-points}

- 家暴**可能發生在任何具有家庭關係者之間**；男性也會受害；**身體虐待屬於**家庭暴力；成因**多為多重因素**，不是單一因素
- 施暴者**不是**多為精神病人，也**不是**沒有能力控制暴力
- 造成家暴的社會因素：**工作壓力、家庭管教方式、媒體學習**；醫療制度不是
- 酒後被毆打頭部流血由警察社工送急診 → **最優先：找適當空間，確保安全與隱私**（其次才是處理傷口、保護令、告訴）
- 懷疑受暴時，護理師**首要確定病人的安全及隱私**；法律**明確規定**醫事人員要通報；**收集與保存證據**也是護理師的責任
- 長期受暴卻說「夫妻吵架難免」要出院 → **耐心傾聽、覺察其矛盾與壓力、聚焦支持與連結資源**，**不要立即面質**防衛
- 新移民身上新舊不同的瘀青卻說跌倒 → **先會談評估可能原因**，不是先驗血小板或加扶手
- 5 歲孩子被留在家 3 天只有水和零食 → **疏忽**
- 兒少遭受虐待、猥褻或性交，或施用毒品，醫事人員**至遲 24 小時**內通報
- 兒虐：施虐者**多為兒童認識的人**；性虐待**不容易**從舉止發現；疏忽與情緒虐待也可能致死；疏忽是**照顧不足**，不是過度保護
- 兒虐徵象：多處新舊瘀傷、身體髒污有異味、寒冬穿短袖；**活潑好動不是**徵象
- 與受虐兒談話：接納、中立，**不要協助指認或責怪施虐者**；**1 歲以下任何骨折都要通報**；**和父母分開會談**
- 性虐待的表現：害怕獨處、討厭被碰觸、不合年齡的性知識、退縮或敵意、反覆泌尿道感染、外陰或肛門撕裂瘀傷；「營養不良」比較屬於疏忽；性虐待**也可能**有發展遲滯
- **嬰兒搖晃症候群**：屬兒童虐待、**須通報**；**不可逆**的腦傷；初期嗜睡或煩躁；抱嬰兒要支撐頭頸
- 兒童疏忽：不帶慢性病童回診、未讓學齡兒童上學、常讓 6 歲以下兒童獨自在家；言語威脅、藐視辱罵屬**情緒虐待**
- 性侵害個案：提供**隱密、保密**的照護、詳實記錄傷勢與言行、男醫師檢查時女護理師陪同；**不可回答記者問題**
- 幼年常受父母忽視或虐待，日後較可能有**暴力傾向**（暴力的代間傳遞）

## 定義與型態 {#definitions}

### 家庭暴力 {#domestic-violence}

1. **家庭成員**（家暴法第 3 條）：配偶或前配偶；現有或曾有同居關係、家長家屬或家屬間關係者；現為或曾為直系血親或直系姻親；四親等以內的旁系血親、四親等以內血親的配偶、配偶的四親等以內血親及其配偶；以及上述成員的未成年子女
2. **定義**（第 2 條）：家庭成員間實施**身體、精神或經濟**上的騷擾、控制、脅迫或其他不法侵害；**目睹家庭暴力**＝看見或直接聽聞家庭暴力
3. **修法重點**（現行條文為 112 年 12 月 6 日修正）
   1. **2023 年**：**目睹家暴的兒童及少年**納入保護令的保護範圍
   2. **2015 年**：**非同居的親密關係**（交往中或曾交往）暴力：被害人**年滿 16 歲**可準用保護令等規定（第 63-1 條）
   3. **2015 年**：通常保護令有效期間**2 年以下**，每次延長**2 年以下**
4. **型態**

| 型態 | 例子 |
|---|---|
| **身體** | 毆打、推撞、掐脖、燒燙、限制行動 |
| **精神（情緒、心理）** | 辱罵、威脅、恐嚇、羞辱、控制交友與行蹤、跟蹤騷擾 |
| **經濟** | 控制金錢、不給生活費、強迫借貸 |
| **性** | 強迫性行為、性羞辱 |
| **疏忽與遺棄** | 對依賴者不提供基本照顧（兒童、老人、身障者） |

### 暴力週期 {#cycle-of-violence}

親密關係暴力常依循反覆的循環（Walker 的暴力週期，教科書通則）：

| 階段 | 表現 |
|---|---|
| **壓力累積期** | 摩擦增加、言語衝突，受暴者小心翼翼想避免衝突 |
| **暴力爆發期** | 嚴重的身體或性暴力 |
| **蜜月期（懊悔期）** | 施暴者道歉、送禮、承諾不再犯，受暴者因而留下或撤回求助 |

- 循環會越來越快、暴力越來越嚴重，蜜月期越來越短
- 受暴者不離開的原因：經濟依賴、為了孩子、害怕報復、文化與家庭壓力、自責、仍有感情、新移民缺乏支持系統

### 成因 {#causes}

1. **多重因素**造成
2. **個人**：施暴者幼年受虐或**目睹家暴**（暴力的代間傳遞）、低自尊、控制欲、**酒精與物質使用**
3. **家庭**：衝突、權力不平等、**管教方式**以打罵為主
4. **社會**：**工作壓力**、失業、經濟困難、**媒體學習**、文化對暴力的容忍、社會孤立

### 常見迷思 {#myths}

| 迷思 | 事實 |
|---|---|
| 只有女性會受害 | 多數是女性，但**男性也會受害** |
| 家暴是單一原因造成 | **多重因素** |
| 施暴者多是精神病人 | **多數不是**；施暴者**能選擇並控制**暴力行為，也能透過處遇改變 |
| 夫妻吵架是家務事 | 家暴是**犯罪與公共衛生問題**，法律規定專業人員必須通報 |
| 受暴者自己不離開就是願意被打 | 離開需要資源與時間，**分手前後**反而是最危險的時候 |

## 兒童虐待與疏忽 {#child-abuse}

### 類型 {#child-abuse-types}

| 類型 | 內容 |
|---|---|
| **身體虐待** | 打、踢、燙、勒、**搖晃** |
| **情緒（精神）虐待** | 長期**言語威脅、藐視、辱罵**、拒絕、恐嚇、讓孩子目睹家暴 |
| **性虐待** | 猥褻、性交、性剝削、讓兒童接觸色情 |
| **疏忽** | 照顧**不足**：不給食物衣物、不就醫（**慢性病不回診**）、**不讓學齡兒童上學**、**讓 6 歲以下兒童獨自在家**、缺乏監督 |

1. 施虐者**多為兒童認識的人**（父母、照顧者、親屬）
2. 任何類型都可能造成嚴重傷害甚至**死亡**，不只身體虐待

### 身體表徵與危險訊號 {#child-abuse-signs}

1. **病史**：說法前後不一致、和傷勢不符、和發展能力不符（不會走的嬰兒「自己跌倒骨折」）；延遲就醫
2. **皮膚**：**多處新舊不同**的瘀傷、在不容易碰撞的部位（背、臀、大腿內側、耳朵）、有形狀的傷痕（皮帶、手掌、香菸燙傷）、浸泡燙傷（手套或襪子狀、界線清楚）
3. **骨折**：多處不同癒合期的骨折、肋骨骨折；**1 歲以下嬰兒任何骨折都要通報**
4. **頭部**：硬腦膜下出血、視網膜出血（嬰兒搖晃症候群）
5. **疏忽**：營養不良、生長遲緩、**身體髒污發出異味**、**衣著不合季節**（寒冬穿短袖）、未打疫苗、齲齒
6. **性虐待**：外陰、肛門、口腔或喉嚨的撕裂傷、瘀傷、腫脹；**反覆泌尿道感染**、解尿困難、性病、懷孕
7. **行為**：害怕回家、害怕特定的人、退縮或攻擊、**害怕獨處、討厭被碰觸**、**不合年齡的性知識或行為**、睡眠障礙、說謊、對人敵意不信任、發展遲滯；**活潑好動不是**受虐徵象

### 嬰兒搖晃症候群 {#shaken-baby}

1. 照顧者用力前後搖晃嬰兒，因嬰兒頭大、頸部肌肉無力，造成**硬腦膜下出血**、**視網膜出血**、腦水腫
2. 屬於**兒童身體虐待**，**須通報**
3. 初期**嗜睡或煩躁**、嘔吐、餵食困難，嚴重時痙攣、昏迷、死亡；倖存者常有**永久性**的神經損傷，**不可逆**
4. 預防：教導父母面對嬰兒哭鬧的因應方法，抱嬰兒時**支撐頭頸部**

### 兒虐的護理 {#child-abuse-nursing}

1. **安全第一**：儘速讓受虐兒與施虐者**隔離**
2. **分開會談**：受虐兒與父母**分開問診**
3. 與孩子談話
   1. 安靜隱密的環境，用孩子聽得懂的語言、開放式問句
   2. 接納、中立，**不誘導**、**不要求指認或責怪施虐者**，避免孩子自責或害怕
   3. 告訴孩子這不是他的錯
4. 注意**隱私**；詳實記錄傷勢（位置、大小、顏色、照片）與孩子和照顧者的原話
5. **24 小時內通報**，配合社工與警政
6. 評估家庭壓力與支持系統，提供社會資源與親職教育（高風險家庭）

## 老人與身心障礙者虐待 {#elder-abuse}

1. **型態**：身體、精神、性、**經濟剝削**（侵占財產、強迫轉移存款）、**疏忽**、**遺棄**
2. **危險因子**：失能或失智、照顧者壓力大或有物質使用問題、社會孤立
3. 徵象：無法解釋的傷痕、壓傷、營養不良、衛生不佳、害怕照顧者、財務突然改變
4. 依**老人福利法**與**身心障礙者權益保障法**，醫事人員知悉時同樣要在 **24 小時內**通報
5. 預防：照顧者支持與喘息服務（見 [[dementia#caregiver]]）

## 性侵害 {#sexual-assault}

1. 依**性侵害犯罪防治法**，醫事人員知悉要在 **24 小時內**通報
2. **急診照護**
   1. 提供**隱密、保密**的空間，**不回答媒體問題**，由醫院統一對外
   2. 由**經過訓練的人員**處理，**減少重複陳述**（減述）
   3. 男性醫師檢查時**女性護理人員陪同**
   4. 驗傷與採證前**不要清洗、更衣、如廁**（若可能），證物依程序保存與交接
   5. 詳實記錄身體傷勢與言行反應
   6. 評估懷孕與性傳染病，依醫囑提供**緊急避孕**與預防性治療
3. 心理照護：接納、不責備，**不是你的錯**；評估急性壓力反應與創傷後壓力症（見 [[trauma-stress-disorders#ptsd]]）

## 法律與通報 {#reporting}

### 責任通報 {#mandatory-reporting}

| 法規 | 對象 | 時限 |
|---|---|---|
| **家庭暴力防治法**第 50 條 | 疑似家庭暴力 | 知悉後**立即**、至遲 **24 小時** |
| **兒童及少年福利與權益保障法**第 53 條 | 兒少遭遺棄、身心虐待、猥褻或性交、施用毒品等 | 至遲 **24 小時** |
| **性侵害犯罪防治法** | 性侵害 | **24 小時** |
| **老人福利法**第 43 條 | 老人受虐、遺棄、疏忽 | **24 小時** |
| **身心障礙者權益保障法**第 76 條 | 身心障礙者受虐 | **24 小時** |

1. 責任通報人員包括**醫事人員**、社工、教育、保育、警察、司法人員等
2. 通報給**直轄市、縣（市）主管機關**；民眾可撥 **113 保護專線**，緊急時撥 110
3. 通報人的身分**應保密**
4. 是「**疑似**」就要通報，不需要先確認

### 保護令 {#protection-order}

| 種類 | 重點 |
|---|---|
| **緊急保護令** | 有急迫危險時，由檢察官、警察或主管機關聲請（可用言詞、電信傳真）；法院**得不經審理程序**，實務上於**4 小時內**以書面核發 |
| **暫時保護令** | 在通常保護令核發前的暫時保護 |
| **通常保護令** | 審理後核發，有效期間 **2 年以下**、可延長（每次 2 年以下）；內容可包括禁止施暴、遠離住所、遷出、暫時監護、加害人處遇計畫 |

## 護理 {#nursing}

### 評估 {#assessment}

1. **單獨會談**：在**隱密、安全**的地方，伴侶或照顧者不在場時詢問
2. 直接但不批判地詢問：「有沒有人傷害你或讓你害怕？」
3. 受傷原因和傷勢不符、新舊不同的傷、反覆急診、延遲就醫 → 提高警覺，**先會談評估可能原因**
4. 評估**危險程度**：暴力頻率與嚴重度是否增加、掐脖、使用武器、威脅殺人、是否正在分手
5. 評估受暴者的身心反應：憂鬱、焦慮、創傷後壓力、物質使用、**自殺風險**

### 處置原則 {#nursing-principles}

1. **確保安全與隱私最優先**
2. 處理身體傷害；**詳實客觀記錄**（原話、傷勢位置與大小、照片），協助**驗傷**，取得驗傷診斷書，作為日後法律證據
3. **接納、不批判、不面質**
   1. 受暴者常淡化（「夫妻吵架難免」）、自責、想回家，這是**矛盾與防衛**
   2. 耐心傾聽，**覺察他的矛盾與壓力**，聚焦在**支持與連結資源**
4. **尊重受暴者的自主決定**，不強迫立即離開或提告；提供資訊讓他自己選擇
5. **安全計畫**：緊急聯絡電話（113、110）、預先準備證件與金錢、可以去的安全地點、和孩子約好求救暗號
6. 說明法律保障：通報、保護令、庇護所、法律扶助、經濟補助
7. **24 小時內通報**，與社工、警政合作
8. 新移民：注意語言與文化，必要時安排通譯，提供新住民服務資源

### 對兒童與家庭的長期處遇 {#long-term}

1. 目睹或受虐兒童：心理評估與治療，預防日後的情緒問題與暴力行為
2. 加害人處遇計畫：認知教育輔導、戒酒戒癮、精神治療
3. 預防：親職教育、高風險家庭關懷、壓力管理與社會支持
