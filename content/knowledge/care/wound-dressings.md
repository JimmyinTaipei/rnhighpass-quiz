本頁整理傷口照護原則、清創與各種敷料的選擇，以及換藥步驟。傷口的分類、顏色評估與癒合三期見 [[bandaging#wounds]]，細胞層次的修復見 [[inflammation-repair#healing-phases]]，壓力性損傷各期的敷料見 [[pressure-injury#treatment]]，燒傷傷口見 [[burns#wound-care]]，膠帶造成的皮膚損傷見 [[hygiene-comfort-care#adhesive]]

## 重點摘要 {#summary}

- **濕潤癒合**：傷口在**濕潤**環境中表皮細胞移行較快，上皮化約是乾燥環境的 **2 倍**；結痂乾燥反而延遲癒合；但滲液太多會使周圍皮膚**浸潤**
- 傷口照護原則：**洗手**、換藥**無菌技術**、每次換藥評估傷口與周圍皮膚、**營養**（蛋白質、維生素 A、B、C、E，鋅、鐵、銅、硒、矽等微量元素）、必要時**隔離**、依傷口選敷料、**清創**移除壞死組織
- **TIME** 傷口床準備：**T**issue 移除壞死組織、**I**nfection／inflammation 控制感染、**M**oisture 維持濕度平衡、**E**dge 評估邊緣與潛行
- 敷料依**滲液量**與**是否感染**選擇：乾燥 → 親水凝膠；少量 → 透明薄膜；中量 → 親水性纖維、泡棉、藻膠、親水性膠體；大量 → 高吸收敷料或引流袋；感染 → **含銀、含碘**
- 換藥順序：**由清潔往汙染**、由傷口中心往外；生理食鹽水清洗；換完記錄傷口變化

### 國考常考點 {#exam-points}

- 「傷口保持**乾燥**有助於上皮化」是**錯的**；濕潤環境才有利
- 銅、硒、矽等微量元素**有助**傷口癒合；清創移除壞死組織**有助**癒合；必要時隔離
- **親水性膠體敷料**可吸收分泌物、減少細菌滋生、減輕疼痛
- **含銀敷料適用於感染性傷口**；**藻膠敷料適用於滲液多的傷口**
- **傳統紗布**易使傷口過乾或吸不了滲液而**浸潤**，造成細胞感染壞死，換藥時易破壞肉芽

## 清創 {#debridement}

| 方法 | 做法 | 特點 |
|---|---|---|
| **外科（銳利）清創** | 用手術刀或剪刀切除壞死組織 | 最快；可能出血、需止痛 |
| **機械性清創** | 水療、傷口沖洗、濕到乾紗布 | 不具選擇性，會連健康組織一起移除，痛 |
| **自體溶解清創** | 用親水性膠體、親水凝膠等保濕敷料，讓傷口自己的酵素分解壞死組織 | 最溫和、不痛，但較慢；感染傷口不適用 |
| **酵素清創** | 塗抹蛋白分解酵素藥膏 | 有選擇性 |
| **生物性清創** | 醫療用蛆 | 國外使用 |

- 腳跟穩定、乾燥、沒有感染的黑色焦痂（例如缺血肢體）可先不清創，當作天然保護（見 [[pressure-injury#treatment]]）

## 敷料的種類 {#dressing-types}

| 敷料 | 特性 | 適用 | 注意 |
|---|---|---|---|
| **傳統紗布** | 便宜、易取得 | 清創、各種傷口的外層 | 傷口易**過乾**，吸不了大量滲液時**浸潤**；黏住傷口，換藥破壞肉芽 |
| **透明薄膜** | 半透性，防水、防菌、可透氣、**可直接看到傷口** | **表淺、滲液少**：第 1、2 期壓力性損傷、植皮區、靜脈導管固定 | 不吸收滲液；周圍皮膚脆弱者移除要小心 |
| **親水性膠體**（水膠體） | 吸收分泌物形成凝膠，維持濕潤，**減少細菌滋生**、減痛 | 少到中量滲液、自體溶解清創、預防摩擦 | 感染或深的傷口不適合；有異味屬正常凝膠，不是感染 |
| **親水凝膠** | 含大量水分，**補充濕度** | **乾燥傷口**、黑痂或黃色腐肉的自體溶解 | 需要第二層敷料 |
| **泡棉** | 吸收力好、緩衝減壓 | **中量**滲液、骨突處 | |
| **藻膠**（海藻酸鈣） | 吸收後成凝膠，有止血作用 | **滲液多**的傷口、腔洞 | **乾燥傷口不可用** |
| **親水性纖維** | 吸收後凝膠化，把滲液鎖住 | 中到大量滲液 | |
| **含銀、含碘、蜂蜜** | 抑制微生物 | **感染性傷口**、高感染風險 | 碘不宜大面積長期使用（甲狀腺、腎功能） |

- 依滲液選擇（內外下冊書頁 1050 重新整理）：**乾燥 → 親水凝膠或親水性膠體**；**少量 → 透明薄膜、親水凝膠、藻膠**；**中量 → 親水性纖維、泡棉、親水性膠體**；**大量 → 高吸收敷料或傷口引流袋**

## 換藥步驟 {#dressing-change}

1. 準備
   1. 核對醫囑與病人、解釋目的；疼痛的傷口**換藥前給止痛藥**
   2. 洗手、備物、注意隱私與保暖
2. 移除舊敷料
   1. 戴清潔手套；膠帶**沿毛髮方向、低角度**慢慢撕，同時壓住周圍皮膚
   2. 敷料黏住傷口時，先用生理食鹽水**浸濕再移除**
   3. 觀察舊敷料上滲液的量、顏色、氣味
3. 清潔傷口（無菌技術，換無菌手套或用無菌鑷子）
   1. **由清潔往汙染**：手術切口由**切口線**往兩側；開放性傷口由**中心往外環形**；每支棉棒**只擦一次**
   2. 一般用**生理食鹽水**清洗；消毒液會傷害肉芽，不常規用於乾淨的肉芽傷口
   3. 引流管周圍：由引流口往外環形
4. 評估：大小（長寬深）、組織顏色、滲液、氣味、周圍皮膚、疼痛、感染徵象（見 [[bandaging#wound-healing]]）
5. 覆蓋：依傷口選擇敷料，大小超過傷口邊緣；固定時避開關節活動處
6. 記錄：傷口狀況、使用的敷料、病人反應；傷口培養要先清洗再採檢
- 換藥屬於**外科無菌技術**，見 [[asepsis-sterilization]]
