**社區心理衛生**是把精神醫療從「把病人關在醫院」轉為「在病人生活的社區中預防、治療與復健」。它照顧的不只是精神病人，而是**社區全體成員的心理健康**；對病人的目標是**適應社區生活、促進復元**，而不是治癒疾病。各類社區精神醫療資源的簡表也在 [[schizophrenia#community-resources]]，環境治療與復健活動見 [[milieu-therapy#rehabilitation]]

## 重點摘要 {#summary}

- **特性**：以社區**全體成員**的心理健康為對象；**持續性、一致性**的照顧；**醫院與社區的銜接**不可或缺；評估**個案、家屬與社區**三方面；以病人的**優勢**發展因應能力，不是由專業人員主導
- **去機構化**的推動原因：重視**病人人權**、**治療模式改變**、**精神藥物**的發明；長期住院會造成**機構化**
- **三級預防**：初級＝**心理健康促進、衛生教育、高危險群教育**；次級＝**早期發現、早期治療、危機處置、門診急診住院**；三級＝**復健、重返社區**（社區復健中心、康復之家、庇護工場、精神護理之家）
- **資源選擇**：無病識感拒絕服藥就醫 → **居家治療**；症狀穩定、有復健動機、能主動服藥 → **社區復健中心**；穩定但無法回家住 → **康復之家**；慢性化需要生活照顧 → **精神護理之家**
- **復元**：**非線性**、朝向**發揮潛力、掌握自己生活**的歷程；核心是**希望**、自信、意義與自主；**賦能**＝提供充分資訊、讓個案**自決**

### 國考常考點 {#exam-points}

- 社區精神心理衛生的目的：提升生活適應、促進復元、以優勢取向發展因應能力；「**由專業人員積極主導治療計畫**」不適宜
- 護理師的主要任務是協助病人**適應社區生活**，不是治癒疾病
- 社區精神護理要評估**個案、家屬與社區**三方面；**注重持續性、一致性的照顧**；仍使用護理過程；要考量家屬、環境、文化與經濟
- 以社區為基礎的治療模式**較適合症狀穩定**的病人；病人重返社區後最可能的影響是**家屬照護負荷增加**
- **醫院與社區的銜接**是不可或缺的一環；社區心理衛生不是以「社區沒有精神疾病」為目標，也不是以生物醫學模式為主
- **社區心理衛生中心**：辦理**心理健康促進活動**及**高危險群的危機處理**
- WHO：病人有權利在**社區**而非機構接受照顧；全球推動社區心理衛生的原因是**人權、治療模式改變、精神藥物**（不是機構化運動）
- **初級預防**：心理健康講座、高危險群教育、新手媽媽講座、網路成癮宣導、張老師資源、正當休閒；護理功能是**衛生教育**
- **次級預防**：**危機處置**（自殺者）、門診、急診、住院、急性症狀的住院治療
- **三級預防**：社區復健中心、康復之家、**復健商店**、**庇護工場**、**精神護理之家**、協助重返社區與就業；工作目的**強調復健**；居家護理師強化社交技巧屬**復健性**
- 三段五級：**葉酸**、**安全防護器具**屬**第二級（特殊保護）**
- 去機構化增加的社區病人最需要**三級的復健機構**
- 精神護理之家：症狀**穩定且慢性化**、不需急性住院但需**生活照顧**、無家可歸的慢性病人；提供**生活照顧**；**不收**需急性住院者；人力與設置基準見 [[long-term-care#institutional]]
- 社區復健中心收案：**精神科診斷、症狀穩定、有復健動機與潛能、可主動服藥規律門診**；**不需**家屬接送
- 康復之家（住宿型）：**低限制**的社區住宅、提供**獨立生活訓練與異常事件處理**；首要目標是**強化社區獨立生活能力**；社區復健中心是日間型
- 庇護性工場的目的：**工作態度與工作能力的訓練**
- 獨居、無病識感、出院不吃藥不就醫 → **居家治療**；醫院體系的精神科居家護理**以護理師家訪為主**；居家治療內容包含**身體與精神的健康評估**、評估範圍是**整體性**的、服務對象**包含**無病識感拒絕服藥者
- 慢性病人社區照護**不做停藥準備**；社區復健**不是主動餵藥**，而是提升病人參與治療的能力
- 個案管理：**個別化、持續性**的照顧計畫；協助**資源連結**；要與家屬建立治療結盟；個案拒絕家訪不能只改電訪；要評值住院的必要性
- 參加會所、了解自己的問題並享有自決 → **賦能模式**；復元**不是**線性好轉，而是**朝向發揮潛力、掌握自我生活**
- 復元的錯誤敘述：「理解精神疾病**無法控制、無法克服**」「建立容許**退縮退化**的環境」「探索生命意義是禁忌」
- 遊民收容輔導三階段：**緊急、過渡、穩定**服務（沒有回歸服務）
- 慢性精神病人**四段七級**：第一級健康促進、第二級高風險篩檢、第三級急性醫療、第四級醫院復健、第五級社區復健、**第六級精神長照（轉介居家治療與精神長照機構）**、第七級安寧

## 意義與特性 {#concepts}

1. **心理衛生**：促進個人心理健康、預防心理疾病，使人能有效適應環境、發揮潛能
2. **社區心理衛生工作的特性**
   1. 對象是**社區全體成員**，不只病人
   2. 重視**預防**與**持續性、一致性**的照顧
   3. **醫院與社區銜接**，以多元機構與跨專業團隊合作
   4. 以**病人優勢**與**復元**為取向，病人與家屬共同參與決策
   5. 評估**個案、家屬、社區**三方面（生活習慣、社交、照顧者的了解程度、經濟、社區資源）
   6. 仍運用**護理過程**（評估、診斷、目標、措施、評值）
3. **社區模式的限制**：較適合**症狀穩定**的病人；急性期仍需要住院；病人回社區後**家屬照護負荷增加**，需要喘息與支持

## 發展 {#history}

### 西方 {#history-west}

1. 1950 年代**抗精神病藥(chlorpromazine)** 問世，加上對**病人人權**的重視與**治療模式改變**，推動**去機構化**
2. 1963 年美國社區心理衛生中心法案，廣設社區心理衛生中心
3. Caplan 提出預防精神醫學的**三級預防**與危機理論
4. **WHO**：病人有權在**社區**接受照顧，而不是在偏遠的機構長期安置；需要心理社會的整合性照護
5. 去機構化的副作用：社區資源不足時病人可能成為遊民、反覆住院（旋轉門現象）

### 去機構化與機構化 {#deinstitutionalization}

1. **機構化**：長期住院後，病人變得被動、依賴、退縮、失去生活能力
2. **去機構化**：**避免不必要的長期住院**，讓病人在**限制最少**的環境接受治療，**不是**「所有病人都不應住在機構」，也不是「先能獨立生活才能出院」
3. 避免機構化的護理：提供**多樣化的生活功能訓練**、鼓勵自主選擇、讓病人自己負責服藥與日常事務，而不是集體行動、排隊吃藥、一成不變

### 台灣 {#history-taiwan}

1. 1990 年公布**精神衛生法**，之後陸續修正；**111 年(2022)修正**強化社區支持，要求地方設置**社區心理衛生中心**
2. 推動**強化社會安全網計畫**，整合精神病人、自殺企圖者、家暴與兒少保護的關懷訪視
3. 精神衛生法的強制住院、強制社區治療見 [[schizophrenia#law]]

## 三級預防 {#prevention-levels}

| 層級 | 目的 | 社區心理衛生的例子 | 護理功能 |
|---|---|---|---|
| **初級** | 預防心理疾病發生、**促進心理健康** | **心理健康講座**、壓力調適與情緒管理課程、新手父母與孕期講座、**高危險群衛生教育**、網路成癮宣導、提供**張老師**等資源、倡導正當休閒、減少對精神疾病的偏見、社區心理衛生篩檢 | **保健性**：衛生教育 |
| **次級** | **早期發現、早期診斷、早期治療**，縮短病程 | **危機處置**（自傷自殺高危險者）、**門診、急診、住院**、急性症狀的住院治療、自殺防治高關懷 | **治療性** |
| **三級** | **復健**、減少殘障、重返社區 | **社區復健中心**、**康復之家**、**庇護工場與復健商店**、**精神護理之家**、職業重建與就業輔導、日間留院 | **復健性**：社交技巧、生活與職業訓練 |

1. 日間留院列在**末段（三級）**預防的機構（社區衛生護理學課本第 18 章）；部分精神科教材歸次級，以題目敘述判斷
2. **三段五級**(Leavell & Clark)：第一級健康促進、第二級**特殊保護**（預防接種、**孕期葉酸**、**工作防護器具**）、第三級早期診斷與適當治療、第四級限制殘障、第五級復健
3. **慢性精神病人四段七級健康促進模式**（國考考法）

| 級 | 策略 |
|---|---|
| 一 | 健康促進 |
| 二 | 高風險篩檢（健康檢查、菸檳榔等高風險族群） |
| 三 | 急性醫療（急性症狀控制） |

## 社區精神醫療與復健資源 {#resources}

### 怎麼選 {#resource-selection}

| 病人狀況 | 首選 |
|---|---|
| 無病識感、拒絕服藥與就醫、干擾家庭或社區，但未達強制住院 | **居家治療** |
| 拒絕居家治療的嚴重病人 | **強制社區治療**（見 [[schizophrenia#compulsory-treatment]]） |
| 症狀穩定、有復健動機、白天需要訓練 | **社區復健中心**（日間型） |
| 症狀穩定、能自理，但**無法回家居住** | **康復之家**（住宿型） |
| 症狀穩定且**慢性化**、自我照顧功能不足、需要生活照顧 | **精神護理之家** |
| 需要工作態度與能力訓練 | **庇護工場**、復健商店 |
| 白天需要醫療與復健、晚上可回家 | **日間留院** |
| 急性症狀、危險 | 急診、急性病房 |

### 各類機構 {#facilities}

1. **社區復健中心**（日間型精神復健機構）
   1. 收案：**符合精神科診斷**、**症狀穩定**、**具有復健動機與潛能**、**可主動服藥並規律門診**
   2. **不需要家屬接送**；不是所有想做職業訓練的人都收
   3. 內容：工作能力與態度、生活技能、社交技巧訓練
2. **康復之家**（住宿型精神復健機構）
   1. 症狀穩定、能自理，但暫時**無法回家住**或家庭無法照顧
   2. **限制較少**、接近一般社區住宅；提供**獨立生活訓練**與**異常事件的處理**
   3. 首要目標：**強化在社區獨立生活的能力**（不是減藥、不是急著回家或找工作）
   4. 訓練計畫依個人需要，不是每個人都一定參加相同訓練
3. **精神護理之家**
   1. 對象：症狀**穩定且慢性化**、**不需急性住院**但需**生活照顧**、**自我照顧功能不足**、無家可歸的慢性病人
   2. 提供**生活照顧**與護理，屬**三級預防**；不收需要急性住院的人
   3. 護理人員角色：聯繫者、策劃者、協調者、**個案管理者**；不是疾病診斷者
   4. 協助住民提升日常生活功能 → **自我管理**能力
4. **居家治療**（精神科居家照護）
   1. 對象：**無病識感**、**拒絕就醫或不規則服藥**、症狀干擾家庭與社區、家屬無法督促就醫
   2. 醫院體系的居家治療**以護理師家庭訪視為主**，健保給付
   3. 內容：**身體與精神的整體性評估**、給藥與注射、家屬衛教、危機處理、轉介
   4. 服務依**評估的需要**而定，不是只依家屬需求；以直接服務為主
5. **就業服務**（依能力分三類）
   1. **庇護性就業**：就業能力不足者，安置在庇護商店、庇護農場、庇護工場，提供**工作態度與工作能力**訓練，不是高壓工作或收入自給
   2. **支持性就業**：還無法獨立競爭就業者，提供個別化安置、訓練與工作協助
   3. **一般競爭性就業**：能獨立工作；由縣市政府職業重建服務窗口評估與轉介
6. **會所(Clubhouse)**：會員與工作人員一起經營，強調**賦能**與自主

### 社區心理衛生中心與社會安全網 {#community-mh-center}

1. **法源**：111 年修正的精神衛生法第 28 條，地方主管機關由**社區心理衛生中心**辦理
   1. **病人個案管理**、關懷訪視與追蹤
   2. **心理衛生促進**、教育訓練、諮詢
   3. 轉介、轉銜、資源開發與網絡聯結
   4. **自殺防治**、精神疾病防治、**災後心理重建**
2. 對高危險群做**危機處理**與自殺風險評估
3. 人員包括心理、護理、職能治療、社工等
4. 不是出院前的暫時安置處、不是長照、也不直接提供職業訓練

### 服務的困境 {#barriers}

1. **社區復健機構分布不均**、人力不足
2. 社區民眾的**汙名與排斥**
3. 家屬負荷沉重、支持不足
4. 醫院與社區銜接不完整

## 個案管理 {#case-management}

### 社區精神病人的追蹤訪視分級 {#visit-levels}

依衛福部「社區關懷訪視及個案管理人員安全手冊」（社區衛生護理學課本表 18-1 整理），衛生局公衛護理人員依病情與穩定度把個案分成一到五級：

| 級別 | 主要對象 | 訪視頻率 |
|---|---|---|
| **一級** | 新收案或出院 3 個月內、活性症狀干擾明顯、危險行為處理後 3 個月內 | 兩星期內訪視一次，前 3 個月每月訪視一次 |
| **二級** | 一級追蹤滿 3 個月以上、症狀仍有干擾 | 3 個月一次 |
| **三級** | 二級追蹤滿 6 個月以上、症狀較輕 | 6 個月一次 |
| **四級** | 症狀與功能影響輕微 | 1 年一次 |
| **五級** | 特殊個案：精神醫療無法接觸但有干擾行為 | 督導會議討論後決定 |

- 各級另依「活性症狀干擾性」「社區生活功能障礙」「家屬對病人照顧的態度」「心理問題與醫療問題」的總分判斷，細項以手冊為準
- 家庭支持薄弱、獨居、主要照顧者 65 歲以上、強制住院後出院、家中有兩位以上精神病人等**特殊個案**，可加派社區關懷訪視員定期訪視

### 原則與過程 {#case-management-process}

1. **目的**：讓病人得到**個別化、持續性**、協調整合的照顧
2. **過程**：**主動發現個案** → 評估需要（含居住安全、權益保護） → 擬定計畫 → **資源連結** → 監測 → **評值**（含是否需要治療或住院、成本效益）
3. **原則**
   1. 與病人與**家屬建立治療結盟**
   2. 協助**資源連結**（醫療、經濟、就業、居住）
   3. **日常生活管理**是重點
   4. 個案拒絕家訪時，要了解原因、調整方式，不是只改電訪了事
   5. 不是每位病人都一定要回歸社區，依個別狀況而定
4. **積極性社區治療(ACT)**：多專業團隊、低個案比、24 小時、在社區直接提供服務，給反覆住院的重症病人

## 復元與賦能 {#recovery}

1. **復元**：即使仍有症狀，也能**重建有意義、有希望的生活**，是**朝向發揮潛力、掌握自我生活**的歷程
   1. **非線性**，會有起伏
   2. 要素：**希望**、自信、正向的自我感、**生命意義**、**自主與責任**、社會連結
   3. 承擔日常生活自我照顧的責任是**助力**
   4. 錯誤觀念：疾病無法控制與克服、終生受苦無法找到意義、建立容許退縮退化的環境、探索生命意義是禁忌
2. **復元的三個要素**（Leamy 2011，社區衛生護理學課本整理）：**賦能**（自主、勇氣、為自己負責）、**社會連結**（人際與就業，重建社會角色）、**希望與樂觀**（有目標、有策略、相信自己做得到）
3. **賦能(empowerment)模式**：**提供充分的資訊**，協助個案了解自己的狀況，**擁有自決的能力**；不是由專業人員替個案決定或承擔所有責任
4. **優勢觀點**：看見病人的能力與資源，而不是只看缺陷
5. 照顧慢性病人的原則：**相信個案有成長與改變的潛力**，**關注希望**；計畫與個案共同擬定，不是護理師主導；不刻意保持距離

## 社區精神衛生護理的角色與能力 {#nursing-roles}

| 角色 | 例子 |
|---|---|
| **個案發現者** | 主動關心社區民眾，用工具與會談**篩檢高危險群** |
| **疾病預防者** | 發現有心理困擾的個案、衛生教育 |
| **直接照顧者** | 居家訪視、給藥、危機處理 |
| **個案管理者** | **連結社區資源**、協調整合 |
| **教育諮詢者** | 教導家屬如何照顧社區生活的病人、團體諮詢 |
| **聯繫者** | 促進病人與醫療人員之間的訊息溝通 |
| 研究者 | 參與社區心理衛生研究 |

1. 角色是多元的，**不只是個案管理者**，也提供直接照護與研究
2. **社區精神衛生護理實務能力**（中華民國精神衛生護理學會 2008 年起辦理能力鑑定；社區衛生護理學課本整理）
   1. **治療性人際關係**
   2. **精神衛生整合性需求評估**
   3. **健康生活自我管理**（含**建構自我**與賦能）：協助病人確立並解決生活問題、增強自我管理策略
   4. **疾病管理**（含藥物管理）：症狀與用藥的自我監測，而不是讓病人住院控制症狀
   5. **資源連結**（含**就業與就學輔導**）：協助處理經濟困境與就業需求，依病人意願與能力協助
   6. **家庭護理治療與處置**
   7. **社區危機處置**
3. 社區精神病人的**六大需求**：疾病管理、危機處置、心理復元、生活管理、家庭支持、社會參與
4. **家庭評估**：評估**家庭對個案的態度**、家庭成員的健康與照顧能力；協助家屬學習照顧技巧，不是指責家屬，也不是組織病人與家屬抗衡
5. 社區家暴與自殺高危險個案見 [[family-violence#nursing]]、[[depressive-disorder#suicide-community]]

## 其他社區議題 {#other-topics}

1. **遊民收容輔導**採三階段：**緊急服務**（外展、緊急庇護）、**過渡服務**（安置與生活重建）、**穩定服務**（租屋、就業、自立）
2. 社區中疑似精神病人、尚未就醫：通報衛生局，由社區心理衛生中心或醫療團隊評估（見 [[schizophrenia#community-resources]]）
