不孕症是夫妻共同的問題，檢查與治療都要兩人一起參與。本頁整理定義、男女雙方的原因、檢查、助孕的時機、人工授精與試管嬰兒的流程與併發症、人工生殖法，以及心理照護；排卵藥與黃體素的藥理見 [[sex-hormones#infertility]]、[[pituitary-hormones#gonadotropins]]，精液分析的數值見 [[male-reproductive-system#semen-analysis]]。文中縮寫：AMH（Anti-Müllerian hormone，抗穆勒氏管激素）、HSG（Hysterosalpingography，子宮輸卵管攝影）、IUI（Intrauterine insemination，子宮內人工授精）、IVF-ET（In vitro fertilization and embryo transfer，體外受精胚胎植入術）、ICSI（Intracytoplasmic sperm injection，單一精蟲顯微注射）、OHSS（Ovarian hyperstimulation syndrome，卵巢過度刺激症候群）、hCG（human chorionic gonadotropin，人類絨毛膜促性腺激素）、FSH（Follicle-stimulating hormone，濾泡刺激素）

## 重點摘要 {#summary}

- 定義：有規律、未避孕的性生活 **12 個月**仍未懷孕；女性 **35 歲以上 6 個月**就要評估(ASRM 2020)
- **原發性**：從未懷孕；**繼發性**：曾懷孕（不論結果）後無法再懷孕
- 原因約各 1/3：**女性**、**男性**、雙方或**原因不明**；**夫妻要一起檢查**
- 女性：**排卵障礙**（多囊性卵巢、高泌乳素、甲狀腺）、**輸卵管**（骨盆腔炎、子宮內膜異位、手術沾黏）、子宮（肌瘤、沾黏）、子宮頸、**年齡**
- 男性：精子生成異常（精索靜脈曲張、隱睪、腮腺炎睪丸炎、熱、藥物）、輸精管阻塞、射精障礙
- 檢查：基礎體溫與排卵監測、**AMH**（卵巢庫存量，**任何一天**都可抽）、月經第 2–3 天 FSH、**HSG**（月經乾淨後、排卵前）、超音波；男性先做**精液分析**
- 助孕：排卵前後**隔天**行房
- **人工授精**：洗過的精子打進子宮腔；適合子宮頸因素、輕度男性因素、**捐精**、原因不明；**輸卵管阻塞不適合**（要做試管嬰兒）
- **試管嬰兒**：**促排卵 → 監測濾泡 → hCG 觸發排卵 → 取卵與受精 → 胚胎植入 → 黃體支持**
- 併發症：**OHSS**、**多胞胎**（必要時減胎）、子宮外孕
- 人工生殖法：受術者必須是**夫妻**；**代理孕母未合法**

### 國考常考點 {#exam-points}

- AMH **不受月經週期影響**，不用挑第 14 天抽；是評估卵巢庫存量的指標
- 精液收集用**自慰**，不用一般保險套或性交中斷法；禁慾 2–7 天；保持室溫或體溫，**不可冷藏**
- 人工授精可用**新鮮精液或冷凍解凍的精液**；禁慾約 2–5 天；注入後平躺約 10–15 分鐘即可（不用 12 小時）；約 **2 週後**驗孕（不是第 7 天）
- 人工授精的適應症**不包括輸卵管阻塞**
- 試管嬰兒步驟順序：**促卵泡成熟 → 偵測卵泡成熟度 → 注射 hCG 引發排卵 → 人工生殖技術 → 維持黃體期**
- 國考答案：受精卵分裂到 **2–8 個細胞**時植入（第 2–3 天胚胎）；現在也常培養到第 5 天**囊胚**再植入
- 助孕不需要**每天**行房（國考答案認為錯誤），排卵前後隔天一次即可；性交後墊枕抬高臀部、溝通彼此感受、觀察排卵期黏液變稀變多都正確
- 人工生殖法：**未婚者不可**當受術者；禁止代理孕母；捐贈人不可是**四親等內旁系血親**；男性捐贈人 20 歲以上未滿 50 歲
- 試管嬰兒失敗、個案否認結果時：**鼓勵表達感受與擔憂**，詢問是否需要聯絡配偶，和醫療團隊一起討論後續；不要急著要她接受現實或叫她「再接再厲」

## 原因 {#causes}

### 女性因素 {#female-factors}

| 部位 | 原因 | 線索 |
|---|---|---|
| **排卵** | **多囊性卵巢症候群**（最常見）、高泌乳素血症、甲狀腺功能異常、體重過輕或過重、過度運動、早發性卵巢功能不全 | 月經不規則或無月經、基礎體溫單相 |
| **輸卵管與腹膜** | **骨盆腔炎**（披衣菌、淋病）、**子宮內膜異位症**、手術後沾黏、子宮外孕病史 | 下腹痛、經痛；HSG 顯影不通 |
| 子宮 | 子宮肌瘤（黏膜下）、息肉、子宮腔沾黏（Asherman 症候群）、先天子宮畸形 | 月經量異常、反覆流產 |
| 子宮頸 | 黏液不利精子通過、子宮頸手術後 | |
| **年齡** | 35 歲後卵子數量與品質下降，40 歲後明顯 | AMH 低、FSH 高 |

- 相關疾病：多囊性卵巢見 [[menstrual-disorders#pcos]]、子宮內膜異位與肌瘤見 [[benign-gynecologic-disorders]]、骨盆腔炎見 [[sexually-transmitted-infections]]

### 男性因素 {#male-factors}

| 類型 | 原因 |
|---|---|
| 精子生成異常 | **精索靜脈曲張**（最常見可治療的原因）、隱睪、**腮腺炎睪丸炎**、睪丸受傷、高溫（泡溫泉、久坐、緊身褲）、抽菸、酒精、藥物（化療、類固醇）、放射線 |
| 激素 | 下視丘或腦下垂體功能低下（FSH、LH 低）、高泌乳素 |
| 輸送阻塞 | 輸精管或副睪阻塞（感染、手術、先天缺如）、結紮 |
| 射精與性功能 | 勃起功能障礙、**逆行性射精**（射進膀胱）、早洩 |
| 染色體 | 柯林菲特症候群（見 [[chromosomal-disorders]]） |

- **FSH 低於正常**會讓精子生成不足；精液分析判讀見 [[male-reproductive-system#semen-values]]

## 檢查 {#diagnosis}

| 對象 | 檢查 | 重點 |
|---|---|---|
| 女性 | 基礎體溫、排卵試紙、黃體期黃體素 | 確認**有無排卵**（做法見 [[female-reproductive-system#ovulation-signs]]） |
| 女性 | 月經第 2–3 天 FSH、LH、雌二醇；泌乳素、甲狀腺 | FSH 高 → 卵巢功能下降 |
| 女性 | **AMH** | 濾泡顆粒細胞分泌，反映**卵巢庫存量**；**不受月經週期影響，任何一天都可抽**；年輕女性平均約 2–4 ng/mL，隨年齡下降；高度升高見於多囊性卵巢 |
| 女性 | 陰道超音波 | 子宮、卵巢、竇狀濾泡數 |
| 女性 | **HSG** | 月經乾淨後到排卵前（約週期第 6–11 天，避免已懷孕）；顯影劑看子宮腔與**輸卵管是否通暢**；檢查後可能痙攣痛、少量出血；有骨盆腔感染不能做 |
| 女性 | 腹腔鏡、子宮鏡 | 子宮內膜異位、沾黏；子宮腔病灶 |
| 男性 | **精液分析** | 第一線檢查；採檢衛教見 [[male-reproductive-system#semen-collection]] |
| 夫妻 | 性交後試驗（舊） | 排卵期性交後數小時取子宮頸黏液看活動精子；現在少用 |

## 助孕的時機 {#timing}

- 易受孕期：**排卵前 5 天到排卵當天**（精子存活約 3 天、卵子約 1 天）
- 找排卵：月經週期、基礎體溫、子宮頸黏液（排卵期**由黏稠變稀薄、由少變多**）、排卵試紙
- 行房：排卵前後**隔天一次**；**不需要每天**（國考答案）
- 性交後可墊枕抬高臀部、平躺一下
- 避免潤滑劑（可能影響精子）；戒菸、限酒、維持正常體重
- 夫妻多溝通彼此感受，不要讓「排定行房」破壞親密關係

::questions{ids="109-1_OP_036"}

## 治療 {#treatment}

- 先處理原因：減重（多囊性卵巢）、降泌乳素、甲狀腺治療、精索靜脈曲張手術、輸卵管或子宮手術
- **排卵誘導**：clomiphene、letrozole、性腺激素注射，再用 hCG 觸發排卵（藥理見 [[sex-hormones#infertility]]）；要用超音波監測濾泡，避免多胞胎與 OHSS

### 人工授精 {#iui}

- 做法：排卵前後把**處理過（洗過）的精子**直接注入**子宮腔**；可用**新鮮精液**或**冷凍解凍**的捐贈精液
- **適應症**
   1. 子宮頸因素：精子無法穿透子宮頸黏液
   2. 輕度男性因素：精子稍少、活動力稍差
   3. 性交困難、射精障礙
   4. 使用**捐贈精子**
   5. 原因不明
- **不適合：輸卵管阻塞**（精卵無法相遇）、重度男性因素 → 改試管嬰兒
- 衛教：取精前禁慾約 2–5 天；注入後平躺約 10–15 分鐘；可正常活動；約 **2 週後**驗孕

::questions{ids="112-3_OP_024,112-2_OP_038"}

### 試管嬰兒 {#art}

| 步驟 | 內容 |
|---|---|
| 1. **促排卵**（促卵泡成熟） | 每天注射性腺激素，讓多個濾泡同時發育；GnRH 類似物或拮抗劑防止提早排卵 |
| 2. **監測濾泡** | 陰道超音波量濾泡大小、抽血驗雌二醇 |
| 3. **hCG 觸發** | 濾泡成熟時注射 hCG，模擬 LH 高峰 |
| 4. **取卵** | hCG 後約 **34–36 小時**，經陰道超音波導引抽取卵子（靜脈麻醉） |
| 5. **受精** | 卵與精子在培養皿受精；精子差時用 **ICSI** |
| 6. **胚胎植入** | 國考答案：分裂到 **2–8 個細胞**（第 2–3 天）植入；現在常培養到第 5 天**囊胚**再植入，並限制植入數目（減少多胞胎）；其餘冷凍 |
| 7. **黃體支持** | 給黃體素維持內膜，幫助著床 |
| 8. 驗孕 | 植入後約 2 週抽血驗 hCG |

- 已少用的方法：**禮物嬰兒**（GIFT，卵子與精子一起放回輸卵管）、ZIFT（受精卵放回輸卵管）；都需要至少一側輸卵管通暢
- 植入胚胎在子宮內著床的過程見 [[fertilization-embryology#implantation]]

::questions{ids="110-1_OP_039,106-2_makeup_OP_040"}

### 併發症 {#complications}

- **卵巢過度刺激症候群**(OHSS)
   1. 危險因子：年輕、多囊性卵巢、AMH 高、濾泡多、懷孕後 hCG 上升
   2. 機轉：血管通透性增加 → 液體跑到第三空間
   3. 表現：卵巢腫大、腹脹、腹痛、**腹水**、體重快速增加、尿少；嚴重時血液濃縮、**血栓**、胸水、呼吸困難、腎衰竭
   4. 護理：**每天量體重與腹圍**、記錄輸入輸出量、避免劇烈運動與性行為（卵巢扭轉、破裂）、嚴重時住院輸液與預防血栓
- **多胞胎妊娠**：早產、妊娠高血壓等風險；必要時**減胎**
- 子宮外孕、流產；取卵時出血或感染

## 人工生殖法 {#law}

- 受術者必須是**夫妻**，一方不孕或有重大遺傳疾病，**至少一方**提供健康生殖細胞；**未婚者不可**
- **代理孕母**目前**未合法**
- 捐贈：**無償**；男性 **20 歲以上未滿 50 歲**、女性 20 歲以上未滿 40 歲；捐贈人不可是受術者的直系血親、直系姻親或四親等內旁系血親
- 條文細節見 [[maternal-child-health#eugenics-art]]

::questions{ids="107-2_OP_001"}

## 護理 {#nursing}

- 心理反應：震驚、否認、憤怒、罪惡感、孤立、哀傷；治療期長、費用高、反覆失敗 → 焦慮、夫妻關係緊張、自尊受損
- 原則
   1. **夫妻一起**檢查與諮詢，不把責任放在一方
   2. 提供檢查與治療流程的資訊，協助做決定
   3. 治療失敗或否認結果時，**鼓勵表達感受**、陪伴，必要時聯絡配偶，與醫療團隊討論下一步；不要說教或催促接受
   4. 轉介支持團體、心理諮商
- 衛教：注射藥物方法、回診時間、OHSS 警訊、生活型態（戒菸、限酒、體重、避免陰囊高溫）
