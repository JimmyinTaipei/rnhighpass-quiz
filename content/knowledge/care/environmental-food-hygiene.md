環境衛生是控制人類生活環境中可能危害健康的因素：水、廢棄物、病媒、住屋、空氣、食品與各種公害。社區衛生護理師要能判讀水質與空氣品質指標、指導民眾面對空汙與食物中毒，並參與學校、社區的環境改善。重金屬中毒與一氧化碳、紫外線見 [[environmental-injury]]；職場的噪音與粉塵見 [[occupational-health-nursing#hazards]]；醫院內的廢棄物分類見 [[hospital-safety-environment#medical-waste]]

## 重點摘要 {#summary}

- 自來水處理：**混凝（凝集） → 沉澱 → 過濾 → 消毒**；**曝氣**＝增加溶氧、去除 CO₂（二氧化碳）與硫化氫臭味、讓鐵錳氧化沉澱、**提高 pH** 減少管線腐蝕；水庫優養化用**硫酸銅**除藻
- 垃圾處理：前處理（破碎、壓縮、分選）→ **中間處理**（**焚化**、堆肥）→ **最終處置**（**衛生掩埋**、海洋棄置）；減廢 5R＝減量、**再使用**、回收、再生、拒絕
- 室內空氣：**CO₂ 8 小時 1,000 ppm(0.1%)** 是室內空氣品質指標；通風是預防**病態建築症候群**最有效的方法
- **AQI**（air quality index，空氣品質指標）：0–50 良好（綠）、51–100 普通（黃）、101–150 **對敏感族群不健康**（橘）、151–200 **對所有族群不健康**（紅）、201–300 非常不健康（紫）、301–500 危害（褐紅）；AQI 不含 CO₂
- 水汙染越嚴重：**BOD**（biochemical oxygen demand，生化需氧量）**越高、溶氧越低、氨氮越高**
- 酸雨主因**硫氧化物、氮氧化物**；溫室效應主因 **CO₂**（CO 不是溫室氣體）；臭氧層破洞主因**氟氯碳化物**

### 國考常考點 {#exam-points}

- 曝氣的目的選「增加溶氧、去除不良氣味與 CO₂、提高 pH」；**不是**淨水除濁、不是降低 pH、不是抑制藻類
- 焚化屬**中間處理**，餘熱可發電，但設備與維護費高；**掩埋**才是最終處置；海洋處理屬最終處置；堆肥的主要優點是**改善土壤**
- 自備餐具 → 5R 的**再使用**(reuse)
- 感染性醫療廢棄物：室溫 **1 日**、**0–5 ℃ 冷藏 7 日**、0 ℃ 以下冷凍 30 日；不可燃者滅菌後可衛生掩埋
- 室內 CO₂ **1–3%** 才會出現頭痛、倦怠、注意力差（課本表 25-12）
- 室內空氣品質標準：CO₂ 1,000 ppm／8 小時；CO（一氧化碳）9 ppm；甲醛 0.08 ppm；PM2.5（細懸浮微粒，particulate matter ≤ 2.5 μm）35 μg/m³／24 小時；PM10（粒徑 ≤ 10 μm 懸浮微粒）75 μg/m³
- 用高濃度鹽或糖保存 → **醃漬法**；基改食品「與傳統食品比對後實質相等即同樣安全」→ **實質等同**
- 食品包裝**不必**強制標示「製造方法」
- 紫外線指數：0–2 低量、3–5 中量、**6–7 高量**、8–10 過量、≥ 11 危險
- 物理性公害：熱、放射性、噪音、振動、紫外線；**空氣、土壤汙染屬化學性**
- 與公害程度**成反比**：**國民對公害的認識**、土地利用、法規、勤儉；成正比：人口密度、工業產量、國民生產毛額、能源消耗、廢棄物量

## 飲水衛生與汙水處理 {#water}

### 自來水處理 {#water-treatment}

| 步驟 | 作用 |
|---|---|
| **曝氣** | 水噴成小水滴與空氣混合：**增加溶氧**；逸出 CO₂ 與**硫化氫**（去臭味）；鐵、錳氧化成氫氧化物沉澱；**提高 pH**、減低對水管的腐蝕 |
| **混凝（膠凝）** | 加混凝劑使懸浮微粒聚成大顆粒 |
| **沉澱** | 讓大顆粒沉降 |
| **過濾** | 砂濾去除細小懸浮物 |
| **消毒** | 加氯殺菌，保留餘氯 |

- 順序：**混凝 → 沉澱 → 過濾 → 消毒**（105-1 題）
- 水庫**優養化**（藻類大量繁殖）用**硫酸銅**除藻（106-1 題）
- 飲用水水質標準（2024-11-25 修正）：大腸桿菌群 ≤ 6（MPN 最大可能數或 CFU 菌落形成單位／100 mL）、總菌落數 ≤ 100 CFU/mL；物理性如臭度 3 初嗅數、濁度 2 NTU(nephelometric turbidity unit)、色度 5 鉑鈷單位（課本表）
- 111-1 題敘述「增加一氧化碳」是錯的：曝氣增加的是**溶氧**

### 水汙染指標 {#water-pollution}

| 指標 | 汙染越嚴重時 |
|---|---|
| **生化需氧量(BOD)** | **越高**（微生物分解有機物要消耗更多氧） |
| **溶氧量（DO，dissolved oxygen）** | **越低** |
| **氨氮(NH₃-N)** | **越高**（糞便、有機物分解） |
| 生物種類 | 減少，但耐汙物種可能大量增加 |

- 陸域地面水體分甲、乙、丙、丁、戊五類；**甲類**適用**一級公共用水**（只需消毒）；國考 108-1 答一級公共給水河川 **BOD 1 ppm 以下**（數值在附表，待核對）
- 化學性水媒疾病：**汞 → 水俁病**（生物濃縮、食物鏈、中樞神經）；**鎘 → 痛痛病**；**砷 → 烏腳病**；**硝酸鹽 → 藍嬰症**（變性血紅素血症），見 [[environmental-injury#heavy-metals]]

### 汙水處理 {#sewage}

| 級 | 方法 | 去除 |
|---|---|---|
| 一級（基本） | 篩除、沉澱、膠凝 | 懸浮物 |
| 二級（生物） | 厭氧（化糞池）或需氧（**活性汙泥**、滴濾池）分解有機物 | 有機物與懸浮固體 80–95% |
| 三級（化學） | 活性碳吸附、砂濾、離子交換 | 氮、磷等 |

- **衛生下水道**是都市衛生的指標

## 垃圾與廢棄物處理 {#waste}

- 原則「**減毒、減廢**」；5R：**減量**(reduce)、**再使用**(reuse)、**回收**(recycle)、**再生**(regeneration)、**拒絕**(refuse)（課本 p.679）；自備餐具＝再使用

| 階段 | 方法 |
|---|---|
| **前處理** | 破碎、**壓縮**、**分選**、乾燥、磨碎 |
| **中間處理** | **焚化**、**堆肥**、熱解、垃圾衍生燃料 |
| **最終處置** | **衛生掩埋**、安定掩埋、封閉掩埋、**海洋棄置** |

| 方法 | 優點 | 缺點 |
|---|---|---|
| **焚化** | 最安全衛生、剩餘量少、占地小、不受天候影響、**餘熱可發電** | 設備與維護費高、技術要求高；灰渣仍要掩埋 |
| **堆肥** | 有機物發酵成腐質土，**改善土壤** | 銷售受季節與農作影響 |
| **衛生掩埋** | 最終處置；覆土防臭味與病媒 | 占地 |

- 醫療廢棄物（事業廢棄物貯存清除處理方法及設施標準第 8 條，2023-11-01）：感染性廢棄物用**熱處理**者裝**紅色**、用**滅菌**者裝**黃色**；產出機構貯存：**5 ℃ 以上 1 日、0–5 ℃ 7 日、0 ℃ 以下 30 日**
   1. 不可燃的感染性廢棄物（玻璃、金屬）**滅菌後**可視為一般廢棄物、衛生掩埋（110-2、109-2 題）
   2. 「可燃感染廢棄物用黃色容器焚化」錯：焚化用紅色
   3. 放射性廢棄物裝在有輻射標誌的專用容器（課本：白色袋置入鉛筒），不是黑色或紅色塑膠袋
   4. 病房的分類與判斷見 [[patient-safety-environment#medical-waste]]

### 室內空氣品質 {#indoor-air}

- 汙染源：室外空汙、**燃燒**（CO、NO₂）、建材與油漆（**甲醛**、揮發性有機物、石綿）、事務機（臭氧）、清潔用品、**生物性**（黴菌、塵蟎）、人的呼吸(CO₂)與吸菸
- **室內空氣品質標準**(2012-11-23)：

| 項目 | 標準 |
|---|---|
| **二氧化碳** | **1,000 ppm**（8 小時值） |
| 一氧化碳 | 9 ppm（8 小時值） |
| 甲醛 | 0.08 ppm（1 小時值） |
| 總揮發性有機化合物 | 0.56 ppm（1 小時值） |
| 細菌 | 1,500 CFU/m³ |
| 真菌 | 1,000 CFU/m³（室內外比 ≤ 1.3 不在此限） |
| PM10 | 75 μg/m³（24 小時值） |
| PM2.5 | 35 μg/m³（24 小時值） |
| 臭氧 | 0.06 ppm（8 小時值） |

- 115-1 題「室內空氣品質指標」：二氧化碳、細菌數、懸浮微粒**都給分**；「塵埃」不是法定項目
- **病態建築症候群**（SBS，sick building syndrome；WHO 1982）：在建築物內出現頭暈、頭痛、疲倦、注意力差、眼鼻喉刺激、類氣喘等非特異症狀，離開後改善；密閉空調是主因 → **增加通風**最有效；控制汙染源（綠建材、少裝潢、事務機隔離、室內禁菸）、新裝潢先開窗通風、定期清洗空調與濾網、除溼

## 病媒管制 {#vector-control}

- 病媒是把病原體從一個宿主帶到另一個宿主的媒介，多為節肢動物（蚊、蠅、蟑螂、跳蚤、蝨）與鼠
- 殺蟲劑：有機磷、氨基甲酸鹽（作用類似有機磷但殘留短）、**合成除蟲菊**（對哺乳類毒性低）、昆蟲生長調節劑、抗凝血劑（殺鼠）、忌避劑（敵避 DEET）
- 正確使用環境用藥：看許可證與標示、噴藥時人畜離開、用後洗手換衣
- 登革熱孳生源清除「巡、倒、清、刷」見 [[notifiable-diseases#control-principles]]

## 食品衛生 {#food}

- 食品衛生管理依**食品安全衛生管理法**；食品引起的問題分四類：食品媒介疾病（霍亂、傷寒）、人畜共通疾病、寄生蟲疾病、**食物中毒**
- **食物中毒**定義：**2 人以上**吃了相同食物出現相似症狀（肉毒桿菌或急性化學性中毒 1 人即成立，待核對食藥署原文）；病原與分類見 [[infectious-diarrhea]]、[[staphylococcus-aureus]]、[[clostridium-botulinum-tetani]]、[[gram-negative-bacteria]]
- **食安五環**：①源頭控管 ②重建生產管理 ③加強查驗（十倍查驗） ④加重黑心廠商責任 ⑤全民監督
- 食品規範與標章：**GHP**(good hygienic practice)食品良好衛生規範（所有業者的最低標準）、**HACCP**(hazard analysis and critical control points)危害分析重要管制點（預防製程危害）、CAS（台灣優良農產品）、產銷履歷 TAP(traceable agriculture product)、TQF（台灣優良食品）
- **食品包裝標示**（食安法第 22 條）：品名、內容物、**淨重容量或數量**、**食品添加物名稱**、**製造或負責廠商**、原產地、有效日期、營養標示、基因改造原料；**製造方法不需標示**（109-2 題）
- 食品保存法：冷藏冷凍、乾燥、**醃漬**（高濃度鹽或糖造成高滲透壓，微生物脫水）、煙燻、加熱殺菌、保存劑、發酵（114-2 題）
- **基因改造食品**（FAO，聯合國糧農組織，評估原則）：**實質等同**、過敏原、標識基因（不得帶臨床抗生素抗性）、微生物不具病原性；基改原料要經健康風險評估與查驗登記並標示
- **反式脂肪**：部分氫化植物油產生，升 LDL（低密度脂蛋白膽固醇）、降 HDL（高密度脂蛋白膽固醇）；台灣 2018 年起禁止食品使用不完全氫化油

## 公害防治 {#pollution}

### 公害分類與影響因素 {#pollution-types}

| 分類 | 例子 |
|---|---|
| **物理性** | **熱汙染**、**放射性**、**噪音**、振動、紫外線、地層下陷 |
| **化學性** | **空氣**、水、**土壤**、食品、藥物、殺蟲劑汙染 |
| 生物性 | 微生物汙染 |
| 精神性 | 視覺汙染、心理環境破壞 |

- **加重**公害：人口密度、工業產量、國民生產毛額、能源消耗、廢棄物量
- **減輕**公害：土地利用度、法規、國民勤儉、**對公害的認識**（與公害程度成反比，106-1 題）

### 空氣汙染指標 {#air-quality-index}

| 指標 | 重點 |
|---|---|
| **PSI**（pollutant standards index，空氣汙染指標，舊制） | 以 PM10、SO₂、NO₂、CO、O₃ 換算副指標，**取當日副指標最大值**；0–50 良好、51–100 普通（中等）、**> 100 不良**（對健康有不良影響）；**不含 PM2.5、不含 CO₂** |
| PM2.5 十級（舊制） | 第 1–3 級低(0–35)、4–6 中、7–9 高(54–70)、**第 10 級 ≥ 71 μg/m³**（紫爆） |
| **AQI**（2016 年起整合 PSI 與 PM2.5） | 監測 **O₃、PM2.5、PM10、CO、SO₂、NO₂**；六級顏色（下表） |

| AQI | 等級 | 顏色 |
|---|---|---|
| 0–50 | 良好 | 綠 |
| 51–100 | 普通 | 黃 |
| 101–150 | **對敏感族群不健康** | 橘 |
| 151–200 | **對所有族群不健康** | 紅 |
| 201–300 | 非常不健康 | 紫 |
| 301–500 | 危害 | 褐紅 |

- PM2.5：粒徑 ≤ 2.5 μm，飄浮久、可**深入肺泡**並進入血液，增加氣喘、心血管疾病與肺癌；PM2.5 日平均 70 μg/m³ 已遠超過「普通」
- **空氣品質標準 PM2.5**：課本與 113-1 題寫 24 小時 35、年平均 **15** μg/m³；**2024-09-30 修正加嚴為日平均 30、年平均 12 μg/m³**（新聞報導，附表原文待核對），WHO 2021 準則更低
- 高中以下**空汙停課**：預報 AQI ≥ 400 或 PM2.5 ≥ 350.4 μg/m³（教育部 2017，課本）
- **紫外線指數**：0–2 低量級、3–5 中量級、**6–7 高量級**、8–10 過量級、≥ 11 危險級（中央氣象署依 WHO）；UVI（ultraviolet index，紫外線指數）7＋AQI 130 → 高量級、對敏感族群不健康（110-1 題）
- 戴口罩防 PM2.5 屬**特殊保護**，見 [[epidemiology#prevention-levels]]

### 全球環境問題 {#global-issues}

| 問題 | 主因 | 影響 |
|---|---|---|
| **酸雨** | **硫氧化物、氮氧化物**溶於雨水（SO₂ 為主因） | 課本與國考：**pH < 5.5**；溶出岩石與土壤中的有毒金屬、土壤與湖泊酸化、腐蝕建築與古蹟、傷害動植物 |
| **溫室效應** | **CO₂**（最大宗）、甲烷、**氧化亞氮**、氟碳化物、六氟化硫；CO₂ 吸收的是**紅外線** | 全球暖化、**海平面上升**、降雨型態改變、病媒分布改變 |
| **臭氧層破壞** | **氟氯碳化物（CFCs，chlorofluorocarbons）** | 紫外線增加 → **皮膚癌、白內障** |
| 沙漠化 | **森林濫伐、過度開發、過度放牧** | 生物多樣性減少 |

- **京都議定書**管制人為溫室氣體，以 **CO₂** 為主；**一氧化碳不是溫室氣體**（114-3 題）；四氯化碳等破壞臭氧層物質由蒙特婁議定書管制
- 「無鉛汽油就不會造成空汙」錯：仍有 CO、NOₓ、碳氫化合物
- 氣候變遷對健康：熱傷害（見 [[environmental-injury#heat-injury]]）、病媒傳染病擴散（登革熱）、空汙與過敏性疾病、極端天氣災害

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確 | 為什麼 |
|---|---|---|
| 曝氣可降低 pH、淨化除濁 | **提高 pH**；除濁靠混凝沉澱過濾 | CO₂ 逸出使 pH 上升 |
| 曝氣增加一氧化碳 | 增加**溶氧** | |
| 淨水順序先沉澱再凝集 | **凝集 → 沉澱 → 過濾 → 消毒** | |
| 焚化是最終處置、最經濟 | **中間處理**、成本高 | 灰渣還要掩埋 |
| 海洋處理屬中間處理 | **最終處置** | |
| 感染性廢棄物室溫可放 7 日 | 室溫 **1 日**；0–5 ℃ 7 日 | 貯存標準第 8 條 |
| 可燃感染性廢棄物用黃色容器焚化 | **紅色**焚化；黃色是滅菌 | |
| 室內 CO₂ 0.1–0.2% 就頭痛 | **1–3%** | 0.1% 是品質標準上限 |
| 增加光線或溼度可預防 SBS | **增加通風** | 稀釋室內汙染物 |
| AQI 包括二氧化碳 | **不包括** | CO₂ 是溫室氣體 |
| AQI 101–150 對所有族群不健康 | 對**敏感族群**；所有族群是 151–200 | |
| 水汙染越嚴重 BOD 越低、DO 越高 | **BOD 越高、DO 越低** | |
| 痛痛病是砷、烏腳病是硝酸鹽 | 痛痛病**鎘**、烏腳病**砷**；硝酸鹽是藍嬰症 | |
| 溫室效應主因是氟氯碳化物 | **CO₂**；CFCs 破壞臭氧層 | |
| 酸雨主因是二氧化碳 | **硫氧化物、氮氧化物** | |
| 土壤汙染是物理性公害 | **化學性** | |
| 食品包裝要標示製造方法 | 不需要 | 食安法第 22 條 |
