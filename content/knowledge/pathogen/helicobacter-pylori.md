**幽門螺旋桿菌**能在強酸的胃裡長期存活，是**慢性 B 型胃炎**、**消化性潰瘍**與**胃癌**最重要的病因，世界衛生組織在 1994 年把它列為**第一級致癌物**。台灣胃癌約八到九成與它有關，國民健康署自 **2026 年(115 年)1 月 1 日**起提供 **45–74 歲**民眾**終身一次**公費糞便抗原檢測(國健署)。

## 重點摘要 {#summary}

- 幽門螺旋桿菌能在胃酸中長期存活，是**慢性 B 型胃炎**、**消化性潰瘍**與**胃癌**最重要的病因，也是**第一級致癌物**。
- 定殖的關鍵是**尿素酶**；可用**尿素呼氣試驗**偵測。
- 與**胃 MALT 淋巴瘤**有關(B 細胞、低惡性度，**除菌即可治療**)；與食道癌、大腸癌、膽囊炎**無關**。
- 三合一療法：**omeprazole + clarithromycin + amoxicillin**。
- 國健署自 115 年 1 月 1 日起提供 45–74 歲民眾終身一次公費糞便抗原檢測。

### 國考常考點 {#exam-points}

- 與**消化性潰瘍**最有關聯的微生物：**幽門螺旋桿菌**；胃癌與幽門桿菌有關(**不是** HPV、CMV、大腸桿菌)。
- 在胃內定殖的關鍵：**尿素酶**；可用**尿素呼氣試驗**偵測。
- 幽門桿菌**不是**人畜共通傳染病。
- 與幽門桿菌有關：**B 型慢性胃炎**、**消化性潰瘍**、**急性胃炎**；**A 型**慢性胃炎是自體免疫、會造成惡性貧血；胃食道逆流與它無關。
- 胃 **MALT 淋巴瘤**：與慢性胃炎有關、**B 細胞**淋巴瘤、低惡性度，除菌可治療。
- 三合一療法：**omeprazole＋clarithromycin＋amoxicillin**，不含 erythromycin。
- 幽門桿菌與**食道癌、大腸癌、膽囊炎**無關。

## 病原特性 {#helicobacter-pylori}

| 特性 | 說明 |
|---|---|
| 形態 | **革蘭氏陰性**、**螺旋狀**(彎曲)桿菌，一端有多條**鞭毛**，可穿過胃黏液層 |
| 氧氣 | **微需氧** |
| **尿素酶** | 大量尿素酶把尿素分解成**氨**與二氧化碳，氨**中和胃酸**、在胃壁周圍形成保護 → 能在胃內**定殖**的關鍵，也是**尿素呼氣試驗**與快速尿素酶試驗的原理 |
| 其他毒力因子 | 黏附素、空泡毒素(VacA)、細胞毒素相關蛋白(CagA，與胃癌風險有關) |
| 宿主 | **人類**是主要宿主，**不是**人畜共通傳染病 |

## 傳染途徑 {#transmission}

- **人傳人**，經**口－口**(共用餐具、咀嚼餵食)或**糞－口**途徑；多在**兒童期**從**家人**感染。
- 預防：使用**公筷母匙**、不共杯共食、不嚼食餵小孩、飯前便後洗手、飲水煮沸(國健署)。
- 家人有胃癌或感染者，其他家人也可以檢測。

## 引起的疾病 {#diseases}

| 疾病 | 重點 |
|---|---|
| **慢性胃炎** | 屬**B 型慢性胃炎**，好發於**胃竇**(幽門部)；**A 型**慢性胃炎是**自體免疫**造成，位於胃體與胃底，破壞壁細胞 → 缺乏內在因子 → **惡性貧血**，胃泌素反而升高 |
| **消化性潰瘍** | 大多數**十二指腸潰瘍**與多數胃潰瘍與它有關(另一主因是 NSAIDs)；**除菌**可大幅降低潰瘍復發 |
| 急性胃炎 | 初次感染可引起 |
| **胃癌** | 長期感染 → 萎縮性胃炎 → 腸上皮化生 → 胃腺癌([[cancer]]) |
| **胃 MALT 淋巴瘤** | 黏膜相關淋巴組織淋巴瘤，屬**B 細胞**、低惡性度淋巴瘤；早期可**只靠除菌治療**就緩解([[lymphoma-myeloma]]) |

- 與**大腸癌、食道癌、膽囊炎、胃食道逆流**沒有直接因果關係；食道癌的危險因子是吸菸、喝酒、檳榔、熱食等。
- 會造成 **Guillain-Barré 症候群**的是**空腸曲狀桿菌**，不是幽門桿菌([[gram-negative-bacteria#campylobacter-jejuni]])。

## 診斷 {#diagnosis}

| 檢查 | 類型 | 重點 |
|---|---|---|
| **碳十三尿素呼氣試驗**(UBT) | 非侵入性 | 喝下標記的尿素，細菌尿素酶分解後由呼氣測到標記的二氧化碳；準確度高，也用來**確認除菌成功** |
| **糞便抗原檢測** | 非侵入性 | 國健署公費篩檢使用；也可用於除菌後追蹤 |
| **快速尿素酶試驗**(CLO test) | 胃鏡切片 | 切片放入含尿素與酸鹼指示劑的試劑，變色＝陽性 |
| 組織切片、培養 | 胃鏡切片 | 培養可做抗藥性檢測 |
| 血清抗體 | 抽血 | 只代表**曾經**感染，除菌後仍可能陽性，**不能**用來確認除菌 |

- 呼氣試驗與糞便抗原檢測前，**氫離子幫浦抑制劑**要停約 **2 週**、**抗生素與鉍劑**要停約 **4 週**，否則可能偽陰性。
- 除菌治療結束後至少 4 週再檢查確認是否根除。

## 治療 {#treatment}

- **三合一療法**(國考經典)：**氫離子幫浦抑制劑**(omeprazole 等)＋**clarithromycin**＋**amoxicillin**(青黴素過敏改 metronidazole)，療程 **7–14 天**；**不含** erythromycin。
- 台灣 clarithromycin 抗藥率上升，現行常用 **14 天**療程，或含**鉍劑的四合一療法**(PPI＋鉍劑＋tetracycline＋metronidazole)，也可依抗藥性檢測選藥(國健署篩檢指引)。
- 抗生素機轉：clarithromycin 抑制蛋白質合成([[protein-synthesis-inhibitors#macrolides]])、amoxicillin 抑制細胞壁([[beta-lactams]])。
- 護理衛教
  1. **按時服完全部療程**（漏服會增加抗藥性與失敗率）
  2. metronidazole 服藥期間禁酒
  3. 鉍劑使舌頭與糞便變**黑色**
  4. 治療後要回診**確認除菌**
