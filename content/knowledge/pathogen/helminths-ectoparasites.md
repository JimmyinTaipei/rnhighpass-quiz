**蠕蟲**是多細胞寄生蟲，分成**線蟲**(圓筒狀、雌雄異體)、**吸蟲**(扁葉狀，多需螺類當中間宿主)、**絛蟲**(扁帶狀、分節)。蠕蟲感染常造成**嗜伊紅性白血球增多**。**體外寄生蟲**(疥蟲、蝨)寄生在皮膚表面，蚊、蚤、蜱、恙蟎等節肢動物則是重要**病媒**。驅蟲藥與疥瘡用藥見 [[antiparasitics]]。

|---|---|---|---|---|
| **蟯蟲** | 吃進蟲卵(手、衣物)，**自體再感染** | 盲腸；夜間**肛門搔癢** | **透明膠帶**肛門黏貼 | mebendazole、pyrantel |

| 鞭蟲 | 吃進蟲卵 | 大腸；直腸脫垂 | 糞便蟲卵 | mebendazole |
| 糞小桿線蟲 | 幼蟲經皮膚、自體感染 | 小腸；免疫低下時過度感染 | 糞便幼蟲 | ivermectin |
| 犬蛔蟲 | 吃進狗貓糞便中的蟲卵 | 幼蟲在肝、肺、眼**移行** | 血清學 | albendazole |
| 廣東住血線蟲 | 生食**蝸牛、蛞蝓** | **嗜伊紅性腦膜炎** | 腦脊髓液 | 支持療法 |

| 絲蟲 | 蚊子叮咬(淋巴絲蟲)、蚋(蟠尾絲蟲) | 象皮病、**河盲症** | 血液抹片(夜間) | ivermectin、DEC |

| 頭蝨 | 頭部接觸、共用梳子帽子 | 頭皮 | 看到蟲或蟲卵 | permethrin 洗髮劑 |

## 線蟲 Nematodes {#nematodes}

### 蟯蟲 Enterobius vermicularis {#enterobius-vermicularis}

- **兒童**最常見的腸道寄生蟲；成蟲住在盲腸，**雌蟲夜間爬到肛門周圍產卵** → **肛門搔癢**、睡不安穩；抓癢後手指沾到蟲卵再吃進去(**自體再感染**)，也經衣物、寢具傳給家人。
- 診斷用**透明膠帶肛門黏貼法**，在**清晨起床後、排便與洗澡前**採檢(晚上洗澡後採檢不對)；一般糞便檢查不容易找到蟲卵。
- 治療：**全家一起服藥**，2 週後再服一劑；剪短指甲、飯前便後洗手、內衣褲與床單熱水清洗([[antiparasitics#anthelmintics]])。
- 過去國小新生健康檢查項目包括蟯蟲檢查(108-2_PC_076 答案)。

### 蛔蟲 Ascaris lumbricoides {#ascaris-lumbricoides}

- 最大的人體腸道線蟲；吃進受污染蔬菜或土壤中的**蟲卵**，幼蟲在小腸孵出後穿過腸壁、經血液到**肺**，再沿氣管上行被吞下，回小腸長成成蟲(**肺移行**，可有咳嗽與嗜伊紅性白血球增多)。
- 大量感染造成營養不良、**腸阻塞**、鑽入膽道。

### 鉤蟲 Hookworm {#hookworm}

- 絲狀幼蟲在潮濕土壤中，經**赤腳皮膚**鑽入(局部皮膚炎)，經肺移行後在小腸以口器咬住黏膜**吸血** → **缺鐵性貧血**(最常見的表現)、營養不良。
- 預防：**不要赤腳**在田地、泥土上活動。

### 鞭蟲 Trichuris trichiura {#trichuris-trichiura}

- 吃進蟲卵，寄生在大腸；大量感染時腹瀉、血便、兒童**直腸脫垂**。

### 糞小桿線蟲 Strongyloides stercoralis {#strongyloides-stercoralis}

- 幼蟲經皮膚感染，能在體內**自體感染**持續數十年；使用**類固醇**或免疫低下時可能**過度感染**，造成致命的散播性感染與革蘭氏陰性菌敗血症。

### 犬蛔蟲 Toxocara canis {#toxocara-canis}

- 人(多為兒童)吃進狗貓糞便污染土壤中的**蟲卵**，孵出的**幼蟲**在人體無法長成成蟲，而是**移行**到肝臟、肺臟、眼睛造成病變(內臟與眼幼蟲移行症)；**糞便中找不到蟲卵**，以血清學診斷。

### 廣東住血線蟲 Angiostrongylus cantonensis {#angiostrongylus-cantonensis}

- 老鼠是最終宿主，**蝸牛(非洲大蝸牛)、蛞蝓**是中間宿主；人**生食或吃到未煮熟的螺類**、受螺類黏液污染的生菜而感染。
- 幼蟲移行到腦部 → **嗜伊紅性腦膜炎**(劇烈頭痛、頸部僵硬)；台灣**有病例報告**；糞便中找不到蟲卵。
- 預防：不生食螺類、蔬菜徹底清洗、處理螺類後洗手。

### 旋毛蟲 Trichinella spiralis {#trichinella-spiralis}

- 生食或吃**未煮熟的豬肉、野生動物肉**，幼蟲在**橫紋肌**內形成囊體 → 發燒、**肌肉痛**、眼瞼水腫、嗜伊紅性白血球增多。
- 診斷靠**肌肉切片**與血清學，**不需要**糞便檢查。

### 絲蟲 Filariae {#filariae}

- **淋巴絲蟲**(班氏絲蟲)：**蚊子**叮咬傳播，成蟲阻塞淋巴管 → 淋巴水腫、**象皮病**；台灣(金門等地)過去曾流行，已根除；微絲蚴夜間出現在周邊血液。
- **蟠尾絲蟲**：黑蠅(蚋)叮咬，非洲與中南美洲流行，造成**河盲症**；首選 **ivermectin**。

## 吸蟲 Trematodes {#trematodes}

### 中華肝吸蟲 Clonorchis sinensis {#clonorchis-sinensis}

- 生活史：蟲卵 → 淡水**螺**(第一中間宿主) → **鯉科淡水魚**(第二中間宿主)；人**生食或吃未煮熟的淡水魚**感染。
- 寄生在**膽管**；多數輕微，長期大量感染造成膽管炎、膽結石，與**膽管癌**最有關。
- 台灣**仍有病例**(過去苗栗、美濃等地盛行)；**praziquantel** 可治療；感染者不一定出現嚴重病變。

### 衛氏肺吸蟲 Paragonimus westermani {#paragonimus-westermani}

- 生食或醉浸的**淡水蝦、蟹**；寄生在肺部 → 慢性咳嗽、**咳血**、鐵鏽色痰，容易被誤認為結核病。

### 血吸蟲 Schistosoma {#schistosoma}

- 在淡水中的**尾動幼蟲**直接**鑽入皮膚**；成蟲住在靜脈叢。
- **日本血吸蟲**、**曼森血吸蟲**：腸系膜靜脈 → 蟲卵造成肝臟纖維化、**門脈高壓**。**埃及血吸蟲**：膀胱靜脈叢 → 血尿，與**膀胱癌**有關。
- 國考答案：日本血吸蟲**不需經血液循環到肺**就能到達寄生部位(蛔蟲、鉤蟲、糞小桿線蟲的幼蟲都有肺移行)。
- **游泳癢**：**非人類(鳥類)血吸蟲**的尾動幼蟲鑽入皮膚後死亡，造成搔癢性皮疹。
- 台灣的日本血吸蟲株只感染動物。

## 絛蟲 Cestodes {#cestodes}

### 帶絛蟲 Taenia {#taenia}

| 種類 | 感染來源 | 重點 |
|---|---|---|
| **有鉤絛蟲**(豬肉絛蟲) | 生食含囊尾蚴的豬肉 → 成蟲寄生**小腸** | 頭節有**吸盤與兩圈小鉤**；若吃進**蟲卵**(自己的或他人糞便污染)，幼蟲可在人體組織存活成**囊尾蚴** → **腦囊尾蚴病**(癲癇)；台灣曾有病例 |
| 無鉤絛蟲(牛肉絛蟲) | 生食牛肉 | 頭節只有吸盤；人體**不會**發生囊尾蚴病 |
| **亞洲絛蟲** | 生食**豬、野生動物的內臟**(肝臟) | 台灣原住民地區曾盛行 |

### 其他絛蟲 Other cestodes {#other-cestodes}

- **廣節裂頭絛蟲**：生食淡水魚(或鮭魚)；最長的絛蟲，與宿主搶**維生素 B12** → 巨母紅血球性貧血。
- **包蟲**(棘球絛蟲)：狗是最終宿主，人吃進蟲卵 → 肝臟、肺臟**包蟲囊**；手術時囊液外漏可引起過敏性休克。
- **短小包膜絛蟲**：唯一不需中間宿主、可直接經糞口傳染的絛蟲，兒童常見。

## 體外寄生蟲與病媒 {#ectoparasites}

### 人疥蟎 Sarcoptes scabiei {#sarcoptes-scabiei}

- 雌蟲在皮膚角質層挖**隧道**產卵；**夜間劇癢**，好發**指縫**、手腕、手肘、腋下、腹股溝、外生殖器等**皺褶處**，頸部以下為主。
- 經**皮膚直接接觸**與衣物、寢具傳染，常見於**護理之家等人口密集機構**；**動物疥蟲**也可能短暫感染人。
- **潛伏期**：初次感染 **2–6 週**(國考多寫約 **4 週**)，再感染 1–4 天；疥蟲**離開人體**只能存活約 **2–4 天**，40℃ 無法殺死疥蟲(疾管署；中國醫大附醫衛教)。
- 照護：**接觸隔離**(手套＋隔離衣)、**同住者同時治療**、**頸部以下全身塗藥**(不只塗病灶)、衣物床單 **60℃ 以上熱水** 10 分鐘或烘乾機、無法清洗的物品**密封 2 週**。詳細用藥與塗藥方法見 [[antiparasitics#scabicides]]。
- 疥瘡**不需要**用殺蝨劑洗頭或清除塵蟎；**塵蟎**是過敏原，不是寄生蟲。

### 蝨 Pediculus {#pediculus}

- **頭蝨**：學童常見，經頭部接觸、共用梳子帽子傳染；頭皮搔癢，髮根有黏附牢固的**蟲卵**；用 permethrin 洗髮劑，7–10 天後再用一次，細齒梳梳除，同住者一起檢查。
- **體蝨**：生活在衣物縫中，衛生差、擁擠環境；會傳播**流行性斑疹傷寒**、**回歸熱**、戰壕熱。
- **陰蝨**：性接觸傳染。

| **三斑家蚊**、環紋家蚊(夜間) | **日本腦炎** |

| 體蝨 | 流行性斑疹傷寒、回歸熱 |
| 硬蜱 | **萊姆病**、SFTS、克里米亞－剛果出血熱 |
| **恙蟎幼蟲** | **恙蟲病** |
| 蒼蠅(機械性) | 霍亂、傷寒、桿菌性痢疾 |
| 老鼠(宿主，非節肢動物) | **漢他病毒**、鉤端螺旋體病 |

- **不經病媒**：腮腺炎、SARS、小兒麻痺、炭疽、水痘。
- **布氏指數**：每調查 **100 戶**住宅中，發現有病媒蚊幼蟲孳生的**陽性容器數**，用來評估登革熱病媒蚊密度；清除積水容器是最重要的防治(之後整理在病媒傳染病頁)。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **蟯蟲**：透明膠帶試驗在**清晨尚未起床時**採檢；兒童常抓屁股。
- 赤腳到田裡玩泥巴、**貧血** → **鉤蟲**；鉤蟲成蟲感染最常見**貧血**。
- **旋毛蟲病**診斷**不需要**糞便檢體；**犬蛔蟲**幼蟲在人體**移行到肝、肺**，糞便找不到蟲卵。
- **廣東住血線蟲**：吃進含幼蟲的**陸螺、蛞蝓**；成蟲**不在**人腦；台灣**有**病例。
- **中華肝吸蟲**：生食**淡水魚**(鯉科)；與**膽管癌**最有關；台灣仍有病例、有藥可治。
- 生食淡水蝦蟹 → **衛氏肺吸蟲**；**游泳癢** → **非人類血吸蟲**；日本血吸蟲不需經肺。
- **有鉤絛蟲**幼蟲(囊尾蚴)**會**在人體造成病害、會侵入**腦部**；生食野生動物內臟 → **亞洲絛蟲**。
- 蟠尾絲蟲河盲症首選 **ivermectin**。
- **疥瘡**：接觸隔離要戴手套**並穿隔離衣**；家人一併治療；熱水與烘乾機都可用；密封 2 週；抗疥藥要塗**全身**(不只紅斑處)；常見於人口密集機構、**夜間**劇癢；40℃ 殺不死疥蟲；疥蟲離體**不會**活到 2–3 週。
- 病媒：**萊姆病**是蜱不是蚊子；**登革熱**是斑蚊不是三斑家蚊；**茲卡**是斑蚊不是蜱；**SARS** 不經蚊子；**回歸熱**與**流行性斑疹傷寒**是體蝨。
- **布氏指數**以**每 100 戶**計算陽性容器數；埃及斑蚊**白天**叮咬。
