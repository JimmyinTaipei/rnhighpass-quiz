**念珠菌**是口腔、腸道、陰道與皮膚的**正常菌叢**，也是最常見的**伺機性真菌**：使用抗生素、類固醇、化學治療、糖尿病、愛滋或留置導管時，從黏膜的鵝口瘡、陰道炎到致命的**念珠菌血症**都可能發生。真菌總論見 [[fungi]]，用藥見 [[antifungals]]。

## 白色念珠菌 Candida albicans {#candida-albicans}

| 特性 | 說明 |
|---|---|
| 分類 | **真核生物**，屬**酵母菌**；以**出芽**繁殖，可延長成**假菌絲**，也能形成真菌絲(雙型性)；白色念珠菌是**二倍體** |
| **萌芽管試驗** | 放入血清 37℃ 2–3 小時長出萌芽管 → **白色念珠菌**(與杜氏念珠菌)，可快速與光滑、克魯斯、熱帶念珠菌區分 |
| **念珠菌呈色培養基** | 依菌種代謝不同呈現不同顏色(白色念珠菌為**綠色**)，可看出**混合菌種**感染；培養基含抗細菌抗生素；**不能**測藥物感受性 |
| 致病因子 | **黏附**組織、分泌**蛋白酶**與磷脂酶、**表現型轉換**(酵母與菌絲互換)、形成**生物膜**(附著導管)；**不會**合成黑色素(會合成黑色素的是隱球菌) |
| 染色 | 革蘭氏陽性、PAS 染色 |

- 在口腔、腸道、陰道發現念珠菌可能只是正常菌叢；在**尿道**(正常無菌部位)培養出才代表感染(國考答案；有導尿管者常只是移生，要結合症狀判斷)。

## 念珠菌引起的疾病 {#diseases}

| 疾病 | 表現 | 誘因與重點 |
|---|---|---|
| **口腔念珠菌感染**(**鵝口瘡**) | 舌頭、頰黏膜**白色乳酪狀斑塊**，**刮不掉**、刮除後底部發紅出血 | **口腔最常見的真菌感染**；嬰兒、假牙、**吸入型類固醇**、化學與放射治療、愛滋；用 **nystatin 含漱後吞服**([[antifungals#nystatin]]) |
| 食道炎 | 吞嚥疼痛 | 愛滋病人(CD4 低)；口服 fluconazole |
| **念珠菌陰道炎** | 外陰**搔癢**、灼熱、排尿痛，**濃稠白色乳酪狀(豆腐渣樣)分泌物**、陰道壁白色附著物，**無明顯異味** | **抗生素**、**口服避孕藥**、**類固醇**、懷孕、**糖尿病**；治療時停用這些誘因；陰道塞劑或單次口服 fluconazole；一般性伴侶不需治療 |
| 皮膚念珠菌 | 皺褶處(乳房下、腹股溝)、**尿布疹**：鮮紅糜爛斑塊，周圍有**衛星狀**小丘疹 | 保持乾燥、外用抗黴菌藥 |
| 甲溝炎 | 指甲周圍紅腫 | 手常泡水 |
| 念珠菌尿 | 尿液混濁、乳白色 | 糖尿病、長期導尿管、抗生素 |
| **念珠菌血症、侵襲性念珠菌症** | 抗生素治療無效的發燒、敗血症；可擴散到眼(眼內炎)、腎、心臟瓣膜 | **中心靜脈導管**、全靜脈營養、廣效抗生素、加護病房、腹部手術；**擴散性念珠菌症**主要發生在**血液惡性疾病**、嗜中性白血球低下並**持續使用免疫抑制劑**者 |

- **最常造成真菌性腦膜炎**的是**隱球菌**，不是念珠菌([[fungi#cryptococcus-neoformans]])。
- 陰道炎鑑別(比較表見 [[sexually-transmitted-infections#vaginitis]])：念珠菌是**白色乳酪狀**；**陰道滴蟲**是**黃綠色泡沫狀**、有異味、子宮頸**草莓狀**紅點([[protozoa#trichomonas-vaginalis]])；細菌性陰道炎是灰白色、**魚腥味**。

## 非白色念珠菌 Non-albicans Candida {#non-albicans-candida}

- **克魯斯念珠菌**：對 **fluconazole 天生抗藥**，不建議用 fluconazole。
- **光滑念珠菌**：對 fluconazole 感受性較差，常用 echinocandin。
- **耳念珠菌**(*Candida auris*)：多重抗藥、能在醫院環境長期存活，造成院內群聚，需接觸隔離與嚴格環境清潔。
- 近平滑念珠菌：常與導管、靜脈營養有關。

## 治療與照護 {#treatment}

- 口腔：nystatin 懸浮液(**含漱後吞服**，100,000 units/mL 給 250,000 units ＝ **2.5 mL**)、clotrimazole 口含錠、fluconazole。口腔疼痛時可先用 xylocaine 再用 nystatin。
- 陰道：clotrimazole 或 miconazole 陰道錠、nystatin 陰道栓劑、單次口服 fluconazole。
- 念珠菌血症：**echinocandin** 為首選，**移除中心靜脈導管**、做**眼科檢查**，血液培養陰性後再治療至少 2 週([[antifungals#echinocandins]])。
- 預防：使用**吸入型類固醇後漱口**；化學與放射治療期間規則口腔護理；控制血糖；**合理使用抗生素**；保持皮膚皺褶與會陰乾燥、穿棉質透氣內褲。

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **口腔內最常見的真菌感染**是**念珠菌**；吸入型類固醇用後要**漱口**避免念珠菌感染。
- 白色念珠菌：**正常菌叢**、常見口腔與陰道黏膜感染、**酵母菌型態**、會形成**萌芽管**；**不是**最常造成真菌性腦膜炎的真菌。
- 會產生**萌芽管**：**白色念珠菌**(光滑、克魯斯、熱帶念珠菌不會)。
- 白色念珠菌是**二倍體**；呈色培養基中為**綠色**、可鑑定混合感染，但**不能**測藥物感受性。
- 致病因子：黏附、蛋白酶、表現型轉換；**合成黑色素不是**。
- 在**尿道**發現念珠菌表示已受感染。
- **擴散性念珠菌症**：**惡性血液疾病並持續使用免疫抑制劑**的病人。
- **克魯斯念珠菌**不建議用 fluconazole。
- 念珠菌陰道炎：治療需停用口服避孕藥、抗生素與類固醇；分泌物濃稠白色乳酪狀。
- 口腔念珠菌感染含漱：**nystatin**，含漱後吞服。
:::
