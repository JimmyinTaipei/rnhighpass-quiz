病人安全的重點是**用系統改善來預防錯誤**，不是找人處罰。醫院要有**通報制度**讓員工敢報，並依衛生福利部每兩年公布的**年度病人安全工作目標**推動改善。本頁整理 **TPR 通報系統的原則**、**事件怎麼分類**，以及 **111–116 年度九大目標**。

## 重點摘要 {#summary}

- 病人安全重點是**用系統改善預防錯誤**；通報 **不懲罰、保密、共同學習**；TPR 匿名、自願。
- **跡近錯失**：錯誤未到達病人；**警訊事件**：非預期死亡或永久性功能喪失。
- TPR 分類：傷害行為事件、治安事件、公共意外事件。
- 年度目標每**兩年**公布一次；重大醫療事故 7 個工作日通報、45 日內做 RCA。

### 國考常考點 {#exam-points}

- 通報目的：**預防錯誤再發生**、**不懲罰、保密、共同學習**；TPR **匿名、自願、保密、不究責、共同學習**。
- **跡近錯失**＝錯誤未到達病人；**警訊事件**＝非預期死亡或永久性功能喪失(自殺、手術部位錯誤、嬰兒失竊)。
- TPR 分類：**傷害行為事件**(攻擊、自殺、自傷)、**治安事件**(偷竊、騷擾、失蹤)、**公共意外事件**(火災、天災、系統當機)。
- 年度目標每**兩年**公布一次，現行九大目標；115–116 年新增手術室人員管理、醫療暴力預警、員工疫苗。
- 重大醫療事故要在 **7 個工作日**內通報、**45 日**內完成 RCA(醫預法)。

## 病人安全通報的精神 {#reporting-principles}

- **台灣病人安全通報系統(TPR)**由衛生福利部委託**醫策會**規劃(2003 年起)，原則是**匿名、自願、保密、不究責、共同學習**。口訣：匿、自、保、不、共。
- **建立通報系統的主要目的是預防錯誤再發生**、改善系統，**不是釐清責任歸屬、懲罰個人，也不是當作醫療糾紛的證據**。
- **非懲罰性文化**：醫療異常多半源自系統或流程設計缺陷；懲處個人會導致隱匿與漏報。醫院應營造**不苛責**的通報制度，鼓勵通報**重大事件**，也鼓勵通報**輕微傷害與跡近錯失**。
- 法律保護：依醫預法第 33 條，醫院要建立病人安全管理制度；**通報人身分要保密**，不得解聘或給予不利待遇；病安事件通報、分析及預防管控措施**不得作為醫療爭議本案訴訟的證據**或行政處分的基礎，見 [[legal-liability-disputes]]。
- 重大事件要做**根本原因分析(RCA)**，找系統性原因並提出改善方案。

## 病人安全事件怎麼分類 {#event-classification}

依**傷害是否發生在病人身上、嚴重程度**分：

| 類別 | 意義 | 例子 |
|---|---|---|
| **跡近錯失**(Near miss) | 錯誤在**影響到病人之前**就被攔截或剛好沒發生，**未接觸病人** | 核對醫囑發現藥物配錯，退回藥局；準備打胰島素時，家屬質疑「我媽媽沒有糖尿病」而停手 |
| **無傷害事件**(No harm event) | 錯誤**已經發生在病人身上**，但**沒有造成傷害** | 誤服錯誤的藥但未造成不良反應 |
| **不良事件**(Adverse event) | 醫療處置過程(不是疾病本身)造成病人**非預期傷害** | 給藥錯誤導致低血糖 |
| **警訊事件**(Sentinel event，又稱哨兵事件) | **非預期的死亡**，或**非自然病程**造成的**永久性功能喪失**；也包括**病人自殺**、**拐盜嬰兒**、**輸血或使用不相容血品導致溶血反應**、**病人或手術部位辨識錯誤**等事件 | 手術部位錯誤、病人自殺(包括未遂)、嬰兒失竊(即使找回) |

- **病人跌倒但沒受傷**不是警訊事件(屬一般事件或無傷害事件)。
- 警訊事件發生後要做 **RCA**。
- 以上通報後仍要先處理病人：看到病人臉色發黑、氧氣面罩沒開，**護理長要立刻調正氧氣流量並通知醫師**；糾正、教導、考核是事後的事。順序是 **病人安全與救命 ＞ 檢討教育 ＞ 行政處置**。

## 通報的分級與病人自殺的處置 {#reporting-levels}

- **強制性通報**：嚴重、可預防的醫療不良事件，例如傳染病流行、中毒、非尋常原因死亡、麻醉死亡、輸血或用藥錯誤致死等重大事件。2024 年醫預法施行後，**重大醫療事故**(手術病人或部位錯誤、遺留異物、不相容輸血、給藥錯誤、設備使用錯誤)改為法定通報，見 [[legal-liability-disputes]]。
- **自主性通報**：輕微或無傷害的事件，例如**跡近錯失**。TPR 本身是**自願、匿名**的學習系統。
- **病人自殺或意外死亡**時，除**保留現場**外，處理順序是：**① 通知當班主管並報警 → ② 通知家屬 → ③ 書寫護理紀錄**(客觀記載發現時間、現場狀況、處置、使用的藥品、家屬反應，不寫主觀推測)；現場與相關物品都要保留。

## TPR 的事件類別 {#tpr-categories}

TPR 把通報事件分為 **13 類**：

| 類別 | 範圍 |
|---|---|
| 藥物事件 | 給藥過程的異常 |
| 跌倒事件 | 意外跌落到地面或其他平面 |
| 手術事件 | 手術前、中、後的異常 |
| 輸血事件 | 從開立備血醫囑到輸血的異常 |
| 醫療照護事件 | 醫療、治療與照護措施的異常 |
| 公共意外事件 | 醫院建築、通道、火災、天災、有害物質外洩、資訊系統當機等 |
| **治安事件** | **偷竊、騷擾、病人失蹤、侵犯、他殺**等 |
| **傷害行為事件** | **言語衝突、身體攻擊、自殺或企圖自殺、自傷**等 |
| 管路事件 | 管路滑脫、自拔、錯接、阻塞、未開啟 |
| 院內不預期心跳停止事件 | 非原疾病病程可預期的心跳停止 |
| 麻醉事件 | 麻醉過程相關 |
| 檢查／檢驗／病理切片事件 | 相關過程的異常 |
| 其他事件 | 以上以外 |

- 例：住院病人持刀傷害護理師、病人打護理師 → 通報**傷害行為事件**。
- 醫療暴力：醫院要建立通報機制，發生滋擾醫療秩序或妨礙醫療業務的案件時，依標準流程通報**衛生局與警察局**，並做風險評估與預警(115–116 年度目標二)。

## 醫院醫療品質及病人安全工作目標 {#national-goals}

衛生福利部**每兩年**公布「醫院版」年度目標。**111–112、113–114、115–116 年度都是同樣九大目標**，只是參考做法逐版增修：

| 目標 | 重點 |
|---|---|
| 一、促進醫療人員間**團隊合作及有效溝通** | 訊息傳遞機制、團隊合作訓練、交接班、困難溝通情境的病人辨識 |
| 二、營造**病人安全文化**、建立醫療機構**韌性**、落實**病人安全事件管理** | 鼓勵員工提出顧慮、**保護醫療人員免遭暴力**、鼓勵通報 |
| 三、**提升手術安全** | 手術辨識、輸備血安全查核、麻醉整合、預防不預期傷害(115–116 年新增**手術室人員管理**) |
| 四、**預防病人跌倒**及降低傷害程度 | 跌倒風險評估、跌倒後檢視、出院跌倒風險評估與衰弱指導 |
| 五、**提升用藥安全** | 用藥整合、**高警訊藥品**、需控制流速或共用管路的輸液 |
| 六、**落實感染管制** | 員工健康管理、抗生素管理、**組合式照護**、環境清潔、醫材消毒滅菌 |
| 七、**提升管路安全** | 正確置放、管路照護與傷害預防 |
| 八、改善**醫病溝通**並鼓勵**病人及家屬參與** | 民眾參與管道、醫病共享決策、照顧者知能 |
| 九、**維護孕產兒安全** | 產科風險管控、孕產婦與新生兒安全 |

**修訂重點(新舊並列)**

| 年度 | 主要新增 |
|---|---|
| 113–114 | 刪除疫情相關文字；目標二加強韌性、**病人參與**、保護醫療人員免遭暴力，新增醫療資訊風險管理；目標三增加術後止痛機器使用與複雜手術術前評估；目標六配合公告新增**單次使用醫材**重處理指引 |
| 115–116 | 目標一強化**訊息確保傳遞**與**人機協作**，新增**生命徵象監測儀器及維生設備警報系統**的安全管理，**臨時辨識碼**用於身分不明的急診危急傷患；目標二響應 **WHO 世界病人安全日**、因應火災新增風險辨識、**醫療暴力風險評估與預警管理**、重視資訊科技對病安的影響；目標三新增**手術室人員管理**與 ERAS 術前準備；目標六新增**員工疫苗接種**、資訊系統管理、監測特定族群抗生素抗藥性；目標七避免 guide wire 滑入體內；目標八加強醫護溝通技能訓練 |

- 手邊文件涵蓋 111–116 年度；更早年度的題目，當年的目標項目可能與現行不同。題庫保留舊題，但**以現行年度目標為準**。
- 年度目標是**主管機關的指引**，不是法律；通報機制與醫療事故通報則由醫預法規範。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 通報系統的目的是釐清責任或作為糾紛證據 | **預防錯誤再發生** | 非懲罰性、學習導向 |
| TPR 是實名、強制通報 | **匿名、自願** | 五大原則 |
| 異常多為個人疏失，應予懲處 | 多源於**系統**，用 RCA 找原因 | 懲處會造成漏報 |
| 護理師核對後把錯誤藥物退回藥局是無傷害事件 | **跡近錯失** | 錯誤沒到達病人 |
| 病人跌倒沒受傷是警訊事件 | **不是**警訊事件 | 警訊事件指死亡或永久性功能喪失 |
| 病人持刀傷害護理師通報「治安事件」 | 通報**傷害行為事件** | TPR 分類(治安事件指偷竊、騷擾、失蹤等) |
| 巡房看到病人缺氧，先教導護理師 | **先救人**(調氧氣、通知醫師) | 病人安全優先 |
