衝突題分三類：**判斷衝突是哪一種**(類型、原因、階段)、**判斷處理行為是哪一種**(Thomas 五種)、**變革的步驟與角色**(Lewin)。

## 衝突的觀念 {#concept}

- **衝突**：敵對、對立或想法牴觸，是不一致、不協調的現象，結果可能是**建設性**或**破壞性**。
- **觀念演變**：傳統認為衝突降低績效、應完全避免；現代認為衝突是**自然現象**，透過協調反而能增強組織力量。**護理長的態度是運用衝突解決策略，把衝突控制在適當的程度**，不是一味壓下、大事化小，也不是什麼都往上推給督導。
- 三種看法：**傳統主義**(衝突有害，要消除)、**行為主義**(接受並設法化解)、**交互作用主義**(衝突絕對必要，太少時要刺激它出現)。

## 衝突的類型 {#types}

| 層次 | 類型 | 意義與例子 |
|---|---|---|
| **個人內在衝突** | **雙趨衝突** | 兩個選項**都想要**，魚與熊掌：同時要完成碩士班進修與評鑑任務、難以取捨 |
| | **雙避衝突** | 兩個選項**都想迴避**，兩害相權：明天要交兩科報告、時間只夠做一科 |
| | **趨避衝突** | **同一個選項**既吸引人又讓人想迴避：想升遷又怕責任與壓力 |
| | 依原因分：角色衝突、動機衝突、倫理上的爭論 | 角色衝突：接受兩種不同的指示 |
| **人與人、團體間** | **任務衝突** | 對工作內容與目標看法不同：行政者想縮短住院天數、病人想多住 |
| | **關係衝突** | 因情緒或人際事件 |
| | **程序衝突** | 完成工作的方法、責任歸屬與資源分配 |
| **團體間衝突** | 部門之間 | 藥劑部與護理部主管為年度**預算**協調對立 |
| 組織間衝突 | 兩個不同機構之間 | |

**衝突的原因**(Daft 與 Marcic)：**稀少資源**、**管轄權混淆**、**溝通阻斷**、**個性(價值觀)衝突**、**權力與地位差異**、**目標不一致**。

- 例：醫師要等抽血報告才處置，家屬希望先緩解氣喘與水腫 → **雙方目標不一致**。
- 預防衝突：多協調溝通、增加成員**參與**、建立**申訴管道**。

## 衝突的過程 {#process}

| 版本 | 階段 |
|---|---|
| **Robbins 五階段**(題庫常用) | **潛在對立**(只有可能引發衝突的前置條件，如溝通障礙、組織結構) → **認知與個人化**(感知到衝突並產生**情緒**，知覺與感受衝突) → **意圖** → **行為**(衝突公開化) → **結果**(建設性或破壞性) |
| 捷徑的五期 | 前驅期 → 感知期 → 感覺期(不信任、生氣) → 顯示期(行為：競爭、辯論、退縮、攻擊或尋求解決) → 再生期(結果) |

- 題目看到「**知覺衝突且產生情緒反應**」→ **認知與個人化**階段。
- 在**意圖及行為**階段衝突已經顯性化，最適合運用衝突處理技巧、避免**非功能性衝突**擴大。

## Thomas 五種處理行為 {#thomas}

依**獨斷性**(關心自己目標)與**合作性**(關心他人)兩個維度分類。

| 行為 | 獨斷 | 合作 | 結果 | 適用時機 |
|---|---|---|---|---|
| **競爭(支配)** | 高 | 低 | 贏—輸 | 目標最重要、雙方地位不平等、有職位權力 |
| **合作(整合)** | 高 | 高 | **雙贏** | 雙方有足夠時間、良好溝通與訓練；護理行政者提出共同目標 |
| **妥協** | 中 | 中 | 各得一部分 | 雙方都有退讓餘地、資源有限 |
| **逃避(迴避)** | 低 | 低 | 雙輸 | **衝突不重要**、時機不當或**需要一段平靜時間**、可**短期使用**；情緒激動時「冷處理」並收集資料再反應 |
| **順從(安撫)** | 低 | 高 | 輸—贏 | 保持人際關係比結果重要 |

- 記憶：競爭＝鯊魚、合作＝貓頭鷹、妥協＝狐狸、逃避＝烏龜、順從＝玩具熊。
- 「以**權力壓制**雙方」是強制(競爭)手段，只壓抑表面，不處理根源，是**較不適當**的作法。
- 緩解原則：**審慎選擇**要處理的問題、評估當事人、**分析原因與根源**、尊重對方、不隨意批評、對事不對人、保持**雙向溝通**。Gillies 指出最常用於協商的是**面對面(confrontation)**策略，能表達感受與經驗、釐清情境。
- **Douglass 衝突解決模式**：題庫 109-2 把「**團體互動**」當作最優先的步驟，作答依官方答案。

## 組織變革 {#change}

- **Lewin 三階段**：**解凍**(打破現狀、建立改變動機) → **改變**(實施新作為) → **再凍結**(把新行為鞏固為制度與規範)。提出者是 **Lewin(路因)**，不是 Pareto、Parkinson 或 Rogers(創新擴散)。
- **變革的角色**：**改變推動者**(Change agent，發起、規劃與帶領變革者)與**改變標的**(Change target，態度、行為或流程被要求改變的對象)。例：護理部計畫讓門診護理師參與社區醫療，**門診護理師是改變標的**，護理部是推動者。
- **面對變革的第一步**：和問題解決一樣，先**收集資料、分析並確立可能出現的問題**；之後才設定目標、擬定方案(教育訓練、人力配置)、執行與評價。
- **抗拒**的處理方向：增加參與、充分溝通說明、教育訓練、給予適應時間，見 [[hr-management-recruitment]] 與 [[clinical-ladder-training]] 的教育訓練原則。

## 危機處理 {#crisis}

- **危機**：組織(如病房、護理部)像人一樣需要維持動態平衡，遇到無法解決的問題就失衡，即危機。危機管理與品質管理的相同任務都是**危機確認與預防**。
- **危機的分類**：情境危機、成長危機、社會危機(地震、火災、天災、謀殺)、組織危機。醫院常見危機：**天災、惡意危機(惡毒謠言)、技術失敗、人為疏失、挑戰(示威、醫療糾紛、政府處罰)、重大傷害**。
- **外在因素與內在因素**：**大量傷患擁至、發生醫療糾紛、媒體負面報導**是**外在**因素；**財務結構不良**是**內在**因素。
- **處理的步驟**：危機處理的護理過程順序是**評估 → 診斷 → 計畫 → 處置 → 評值**；危機管理的階段是**偵測 → 防範 → 控制 → 回復 → 學習**(學習放在回復之後)。個案危機的第一步是**評估**對壓力事件的感受與對生活的影響。
- **不同層級醫院的策略**：診所採**全員參與任務分工**計畫；地區醫院採**任務編組分工**計畫；**醫學中心採常態固定編組分工計畫**(舊題 106-1，考選部以教材分類為準)。
- **危機前**：訂定周延應變計畫、組織編制與任務分配、**定期演練檢討**；熟悉護理相關法令與醫院危機事件**報告機制**；建立異常事件通報系統。
- **危機期間**：迅速掌握狀況、解決最重要的問題，運用 **80/20** 掌握重要的少數；依應變計畫處理，沒有計畫就**立即成立危機應變小組**由領導者指揮；**設立指揮中心**、**評估風險危害程度**、**安排一位發言人統一對外**；**最不當的是把重心放在追究責任與指責人**；危機處理要**時效與集權**，**不需要全體員工共同討論**。大量傷患湧入急診，護理長**立即指派護理師任務**(集權式領導)，見 [[leadership-power-styles#styles]]。
- **危機後**：善後重建、檢討改進；大型災難後可用 **PDCA** 持續改善，見 [[quality-improvement-tools#pdca]]。
- 護理主管的職責：熟悉法令與危機報告機制、要求護理紀錄**內容品質**、非上班時間仍維持緊急聯絡與動員機制、不能只靠學校教育而不辦危機訓練。災害應變的實務見 [[hospital-safety-environment]]。

## 個人的挫折反應 {#frustration}

- 個體遇到挫折(如晉升護理長失敗)會有不同反應：**攻擊反應**(把敵意與憤怒向外宣洩，例如在網路上抨擊甄選不公)、**退行性行為**(退回幼稚的行為)、**折衷或妥協**(修改目標)、**固著行為**(重複無效的舊方法)。
- 管理者要提供**正向的溝通管道**與心理輔導，避免爭議擴大；同儕支持見 [[organizational-communication#skills]]。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 想升遷又怕壓力是雙趨衝突 | **趨避衝突** | 同一選項有利有弊 |
| 兩件都想做但時間有限是雙避衝突 | **雙趨衝突** | 兩者都有吸引力 |
| 兩部門主管預算爭執是組織間衝突 | **團體間衝突** | 同一機構內 |
| 知覺並產生情緒是潛在對立階段 | **認知與個人化** | 階段定義 |
| 衝突處理策略用在結果階段才有效 | **意圖與行為階段** | 衝突已顯現且可介入 |
| 逃避可以達到雙贏 | **合作**才是雙贏 | 逃避是雙輸 |
| 衝突要儘量大事化小，或一律交給督導 | **運用策略把衝突控制在適當程度** | 現代衝突觀 |
| 以權力壓制衝突是適當的 | **不適當**，治標不治本 | 強制 |
| 完全避免衝突是目標 | 衝突可能有建設性 | 現代觀念 |
| 變革第一步是教育訓練 | **收集資料、確立問題** | 流程 |
| Lewin 提出創新擴散 | 創新擴散是 Rogers | 學者 |
| 危機發生時請全體同仁共同討論 | 由**危機小組**迅速決策、設指揮中心、單一發言人 | 時效與集權 |
| 財務結構不良是外在危機因素 | **內在**因素 | 來源 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 個人內在衝突：**雙趨**(兩好)、**雙避**(兩壞)、**趨避**(一件事有好有壞)；人際：**任務、關係、程序**衝突；部門間＝**團體間衝突**。
- 衝突原因：稀少資源、管轄權混淆、溝通阻斷、個性、權力地位、**目標不一致**。
- 階段：潛在對立 → **認知與個人化(知覺＋情緒)** → 意圖 → 行為 → 結果。
- Thomas：**合作＝雙贏**、**逃避＝低獨斷低合作(冷處理、收集資料)**、競爭＝贏輸、順從＝輸贏、妥協＝折衷。
- **Lewin**：**解凍 → 改變 → 再凍結**；改變標的 vs 改變推動者；變革先**確立問題**。
:::
