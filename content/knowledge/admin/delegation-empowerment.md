授權題最穩的主軸是**「授權不授責」**：權限與執行可以授出去，**最終的成敗責任仍在主管身上**。組織結構與集權、分權的優缺點見 [[organization-structure#centralization]]；激勵與心理賦權見 [[motivation-theories#techniques]]。

## 授權 {#delegation}

- **授權**：主管把部分職務與權限交給員工，是**授與性權威**，應為一種**法定(正式)的行為**；它建立在主管對自己領導技巧與對部屬能力的**信賴關係**上。授權**不是最高管理者的特權**，各階層主管都可以。
- **授權的功用**：加強組織的結構與力量、**減輕上級負擔**並加強領導、**發展人員能力(培育員工)**、**拓展主管的影響力**；但**不能卸除主管自己的責任**。

**授權的過程**：**界定可授權的範圍** → **評量員工特性**(意願與訓練是否充分) → **公開授與權責** → **要求員工負責**。

**授權的七項原則**(捷徑)

| 原則 | 意思 |
|---|---|
| **依工作範圍** | 授權內容要與員工職責有關，先考慮專長與能力 |
| **功能性職權** | 適合授權的是**例行事務或專門性工作**，有明文規定可援例，員工能獨立判斷 |
| **金字塔數量(逐級授權)** | 由最高主管向下**逐級**授權，層次越多，工作範圍與職權越清楚 |
| **指揮統一** | 一位員工只接受**一位主管**的指揮，**不可重複授權**(不可同一權限授予兩人以上) |
| **絕對性職責** | 員工要向主管**報告績效**；員工出問題，主管仍要負相關責任 |
| **職權與職責均衡** | 負多少責，就要有相當的權 |
| **持續的責任** | 主管授權後，他對那項工作所負的責任**並未減少** |

- 另外要**公開授權**，讓其他員工知道被授權者的任務目標與權責。
- **授權不是只限於例行性工作**：也可適度授予有挑戰性、發展性的任務(題庫說「只限於例行性工作」是錯的)；但例行性、明確性高的事務最適合授權。

**可以授權與不可授權**

| 適合授權 | 不可或不宜授權 |
|---|---|
| **單位護理人員的排班**(例行、規則明確) | **人事相關事務**：**加薪、裁員、升遷**、人事考核 |
| 例行與專門性事務 | **追回遺失的麻醉藥物**(重大管制藥品異常，涉及法律責任，應親自處理並通報) |
| 籌辦忘年會、員工活動(**工作範圍原則**) | **擬定單位年度計畫**(管理者的核心規劃職責)；**提振單位士氣**(領導能力，非單一任務) |

**授權的情境判斷**

- **麻醉藥品授權三班組長保管並清點，數量出問題**：護理長是單位的管理者，**應負最後管理責任**；組長與取用者只負執行的責任。
- **授權前先評估被授權者的能力**，缺乏技能就**先提供教育訓練**；授權後仍要**追蹤**，不是「絕對信任不追蹤」，也**不可同時授權兩位**做相同任務，更不是私下拜託。
- **督導把護理專案授權給 N1 護理師**：**不適當授權**(任務與能力、資歷不相符)；另一種常見授權錯誤是**授權不足**(給的權力或任務太少)。逐級授權是正確的授權方式，不是錯誤類型。
- **部屬承諾後說工作繁瑣、想換別人**(例：籌辦忘年會)：先**了解困難並從旁協助**，維護其責任感與成長機會，而不是直接收回、另指派他人。
- **護理部主任未經督導長同意，直接請護理長負責專案**：違反**單一隸屬關係(指揮統一)**。
- **受授權者的信賴關係**是授權的基礎；「授權給能力不足但有意願的部屬是一種鼓勵」是錯誤的。

## 授權、分權與賦權的比較 {#compare}

| 名詞 | 意義 |
|---|---|
| **授權** | 把權力下放給員工，但通常是**較不重要的瑣事** |
| **分權** | 組織為發揮低層的主動性與創造性，把決策權分給下屬組織，最高層只保留少數關係全局的重大決策權；例：由**單位護理長做預算計畫** |
| **賦權**(賦能) | 含**授權**的權力，再加上**授能**：讓員工獲得訓練與機制，有更多自主和行動權 |

- **集權**：授權程度極低，決定權集中在高層；優點是**精簡組織、避免重複浪費、減少工作重複及成本**，部門間衝突較少，**決策效率化**、易管理，**緊急情況**適用；**職權和職責階層完整化**是**分權**的優點，不是集權的。
- **分權**：優點是**培養人才**、單位主管**自主權大**、問題在現場**省時有效率**、員工覺得自由受尊重、權力**相互制衡**；「分權者對分配後的職責負有責任」不正確，**責任無法隨權力下放而移轉**。
- 集權或分權的選擇因素與優缺點的完整比較見 [[organization-structure#centralization]]。
- 醫院發生**緊急事件**，為講求時效採**集權式**結構；**扁平化組織應增加授權**；**金字塔型組織的職權由上往下遞減**。
- 組織規模越大，通常配合**分權**的需要(決策者貼近現場)；但「可以聽到不同意見」不是選擇分權的理由。

## 賦權與心理賦權 {#empowerment}

- **賦權領導**：領導者**協助成員提升自我效能感，並增進自我管理能力**(不是道德領導、轉型領導或策略領導)。
- **賦權的功用**：加強組織結構與力量、減輕上級負擔、發展人員能力、提高工作效率、提升員工自我效能、增進自我管理能力。
- **心理賦權(Spreitzer，1995)的四個構面**：**工作意義**(Meaning)、**能力或自我效能**(Competence)、**自主性**(Self-determination)、**影響力**(Impact)。
  - **護理長在會議向同仁說明進行專案改善的必要性與意義** → **工作意義**構面。
  - 指定資歷較淺的 N1 當圈長(超過能力範圍)、要求定期回報進度(監控管控)、叫小組自己找單位協商(缺乏資源支持)，都**不是**心理賦權的策略。
- 心理賦權也是一種**激勵方式**：藉由管理者適時授與權力，產生內在任務性的激勵，提升自我效能。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 授權是最高管理者的特權 | 各階層主管都可授權 | 授權的定義 |
| 授權後可以減輕主管的責任 | **授權不授責**，成敗責任仍在主管 | 持續的責任 |
| 麻醉藥品授權組長，出問題由組長負最後責任 | **護理長**負最後管理責任 | 授權不授責 |
| 授權後要絕對信任、不必追蹤 | 要**追蹤評估** | 絕對性職責 |
| 同時授權兩位資深護理師相同任務 | **不可重複授權** | 指揮統一 |
| 授權只限例行性工作 | 也可授予挑戰性任務 | 授權原則 |
| 加薪、升遷、裁員可以授權 | **不可授權** | 人事事務 |
| 督導授權給 N1 負責專案是授權不足 | **不適當授權** | 能力不符 |
| 授權給能力不足但有意願的部屬是鼓勵 | 要**考量能力**並先訓練 | 量力授權 |
| 賦權領導是道德領導 | 賦權＝提升**自我效能與自我管理** | 定義 |
| 要求專案小組定期回報是心理賦權 | 屬**監控** | Spreitzer 構面 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **授權不授責**：責任(Accountability)留在主管；**職權可授，責任不可授**；護理長仍負麻醉藥品的最後管理責任。
- 授權原則：**逐級、公開、不可重複、指揮統一、職權與職責均衡**；先評估能力、提供訓練、授權後要追蹤。
- **可授權**：排班等例行事務；**不可授權**：加薪、裁員、升遷、年度計畫、重大危機處理。
- **賦權＝授權＋授能**；**心理賦權四構面**：**意義、能力、自主、影響**；賦權領導提升**自我效能**。
- **集權**：精簡、減少重複、緊急；**分權**：培養人才、自主、**階層職權職責完整**。
:::
