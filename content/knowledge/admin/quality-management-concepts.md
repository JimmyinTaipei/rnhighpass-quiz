這一頁是品質管理的**觀念地圖**：品質觀念怎麼演進、護理品質怎麼分**結構、過程、結果**三個面向去量、品質改善活動有哪些特性。工具與方法(PDCA、柏拉圖、魚骨圖、RCA、FMEA、BSC)見 [[quality-improvement-tools]]；病人安全通報見 [[patient-safety-reporting]]。

## 護理品質與品質保證 {#qa}

- **護理品質保證**(QA)：依訂定的**護理標準**，**連續、客觀**地評估護理的**結構、過程與結果**，確保病人獲得一定水準的服務；它是有系統的審核工作，找出**既存與可能發生的問題**，追蹤解決並**定期反覆評估**，目的是**減少或防止問題發生**。
- QA 是依標準做**評核**並找出不良；它屬於較**被動**的控制，已被**以預防為主的 TQM／QI** 取代。
- **ANA 品質保證模式**(1967 年發表)的步驟：**確認價值** → 設定**結構、過程、結果**的標準與準則 → **獲取測量方法** → **評定**實際服務與標準的**差異** → 選擇並實施**改進措施** → **改進護理服務**。
  - 評量方式有兩種：**回顧性評量**(出院後檢閱病歷)與**同時性評量**(住院期間即時評量)。
- **QUACERS**(阿丹兒 Adair)：**Qua**(品質保證)、**CE**(成本效益)、**R**(危機管理)、**S**(員工需要)；是把**危機管理**納入的品質管理模式，常被用在品管圈。
- **羅斯麥迪可斯模式**(Rush Medicus Model，RMM)：以**病人為中心**的品質評值方式，含擬定護理計畫、確保生理與心理社會需要、評價護理目標、遵守病房常規保護病人、行政部門的支援等六大目標。
- **護理標準**：事先設立，要**可預測、可衡量、可達成**；**不是永久不變**，價值、科技、政策與機構改變時要**修正**，達成後要再提高。用途包括臨床服務指引、品質保證、教學、行政、研究、成本效益。

## 品質觀念的演進與學者 {#evolution}

**順序**：**品質控制(QC，事後檢驗)** → **品質保證(QA，過程預防、符合標準)** → **全面品質管制(TQC，費根堡姆)** → **全面品質管理(TQM，顧客導向、全員參與、持續改善)**，記成「**控 → 保 → 全管制 → 全管理**」。

| 學者或名詞 | 重點 |
|---|---|
| **戴明**(Deming) | **PDCA 循環**、品質十四要點 |
| **石川馨**(Ishikawa) | **魚骨圖(特性要因圖)**創始人、提倡**全公司品質管制**(CWQC)，被稱為**品管圈之父** |
| **朱蘭**(Juran) | 品質三部曲(計畫、控制、改善) |
| **費根堡姆** | 提出**全面品質管制**(TQC) |
| **TQM** | 以**顧客(病人)滿意**為目標；由**全體成員參與**、共同負責、不斷改善；用來提升流程效率、革除浪費；**不是追求主管滿意** |

### CQI 的特性 {#cqi}

**持續性品質改善**(CQI)：以**顧客為導向**、**全員參與**、重視**系統與流程**而非個人責任、**持續**不間斷、**前瞻與預防**，由**第一線人員**(由下而上)組成團隊推動，**不是由管理者單向由上而下主導**。休氏循環(計畫、執行、評值、標準化)與 FOCUS-PDCA 是它的方法，見 [[quality-improvement-tools#pdca]]。

## Donabedian：結構、過程、結果 {#donabedian}

Donabedian(1966)把醫療品質分成三個面向。判斷口訣：**資源與人力＝結構；執行的照護行為＝過程；病人最終的狀態＝結果**。

| 面向 | 看什麼 | 護理例子 |
|---|---|---|
| **結構面**(Structure) | 提供照護的**人力、設備、環境、制度、資格** | **護病比**、護理人員**人數、編制與資歷**(2 年以上占 60%、持護理師證書比率)、**主管輪值制度**、**設備數量**(加護病房生理監測儀)、**護理技術指引含無菌原則**、洗手設備、病人浴廁急救鈴與防滑設施、可執行細胞治療的醫師比率、教育訓練計畫的完整度 |
| **過程面**(Process) | **護理人員實際執行**照護的行為、是否符合標準 | **三讀五對**、發藥流程、**洗手遵從率**、**手部衛生正確率**、導尿技術正確性、接觸嬰兒前洗手、**侵入性檢查前病人辨識**、手術流程、衛教指導完整率、**護理紀錄完整性**、手術前預防性抗生素給予比率、手術同意書填寫完整率、換藥正確性 |
| **結果面**(Outcome) | 照護**之後**病人健康與滿意度的改變 | **跌倒率與跌倒傷害率**、**壓力性損傷(壓瘡)率**、**泌尿道感染率**、**血流(血液管路)感染率**、**死亡率**、**病人滿意度**、給藥異常發生率、臨床路徑成效 |

- **護病比是結構面**；**病人滿意度是結果面**；**手術流程、洗手遵從率是過程面**；**護理師編制是結構面**。
- 常見改寫：「提供照護時所執行的活動合乎標準」是**過程標準**；「機構設備設施符合病人需要」是**結構標準**；「監測感染率、跌倒傷害率」是**結果標準**，**沒有「測量標準」**這種面向。
- 過程評值的優點是能提供**立即、早期的回饋**，缺點是外在變數多、資料較不穩定；早期(1987 年前)的醫院評鑑多是**結構面**。
- 護理過程的測量工具(了解即可)：史拉特量表、病人照顧品質量表(QualPaCs)、護理稽核(nursing audit，以護理行政、教育、臨床照護、護理品管為範疇)。

### 效率標準與效能標準 {#efficiency}

| 標準 | 重點 | 例子 |
|---|---|---|
| **效率**(efficiency) | **資源投入與使用**(把事情做對) | 評估投入的**人力需求量**、**財力的充足性** |
| **效能**(effectiveness) | **目標達成與結果**(做對的事) | 評估投入人力**所達成的目標**、財力投入的**執行結果** |

## 控制的類型 {#control}

控制是把實際績效與標準比較並修正的過程。

| 依時間分類 | 時機 | 例子 |
|---|---|---|
| **事前控制**(前饋) | 活動**開始前**預防 | **預算編列**、人員甄選、標準訂定 |
| 同步(過程)控制 | **進行中** | 監督病人辨識、給藥流程 |
| **事後控制**(回饋) | **結束後**檢討 | 顧客(病人)反應、滿意度調查 |

| 依品質面向分類 | 說明 | 例子 |
|---|---|---|
| **結構控制** | 對人力、設備等組成的控制 | 評鑑要求各病房應有洗手設備 |
| **過程控制** | 對活動流程與作業步驟的控制 | **病人辨識**、三讀五對 |
| **結果控制** | 對最終成果的控制 | 感染率、滿意度 |

- **策略控制適用高階主管**；基層主管負責第一線**作業控制**。
- 控制的原則：成果要能**量化**；把**會產生重大影響的活動**當重點；訂定**可容忍範圍**；過程中發現重大差距要**即時修正**。

## 品質改善主題的選擇 {#topic-selection}

選主題要看**問題的重要性與影響**：優先考慮**發生頻率高**、**風險高**、**成本高**、容易發生問題的活動(「三高一問題」)，並依**柏拉圖 80/20** 先處理影響最大的少數項目。

- **不是**單純挑最容易或最困難的、成本最低的、延續去年的、或風險低的項目。
- 重大災難或事件**事後**要推動**持續改善**，用 PDCA；**事前**預防風險用 FMEA；單一嚴重事件的事後調查用 RCA，見 [[quality-improvement-tools#rca-fmea]]。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 品質管理是追求主管滿意 | 追求**顧客(病人)滿意** | TQM |
| 戴明提出全公司品質管制 | 那是**石川馨**(CWQC)；戴明是 **PDCA** | 學者 |
| 品質發展順序 QC→TQC→QA→TQM | **QC → QA → TQC → TQM** | 演進 |
| 護病比、人數是過程面指標 | **結構面** | 資源與人力 |
| 跌倒率、壓瘡率是過程面 | **結果面** | 照護後的狀態 |
| 洗手遵從率、手術流程是結果面 | **過程面** | 執行行為 |
| CQI 由管理者由上而下主導 | 由**第一線由下而上** | 全員參與 |
| 預算編列是事後控制 | **事前控制** | 活動前預防 |
| 病人辨識是結構控制 | **過程控制** | 執行時的規範 |
| 顧客反應是過程控制 | **結果(事後)控制** | 照護後的回饋 |
| 評估投入人力所達成的目標是效率標準 | **效能標準** | 看目標達成 |
| 選改善主題以最容易、最低成本為優先 | 以**高頻率、高風險**為優先 | 效益大 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 演進：**QC → QA → TQC → TQM**；TQM 以**顧客滿意**、全員參與；**戴明＝PDCA**，**石川馨＝魚骨圖、CWQC、品管圈之父**。
- **QUACERS**＝品質保證＋成本效益＋危機管理＋員工需要；把**危機管理**納入。
- **Donabedian**：**結構**(人力、設備、護病比、資格)、**過程**(執行行為、洗手遵從率、三讀五對、病人辨識)、**結果**(感染率、跌倒率、壓瘡率、死亡率、滿意度)。
- **效率**＝資源投入；**效能**＝目標達成。
- **預算＝事前控制**；病人辨識＝**過程控制**；顧客反應＝**結果控制**；策略控制是高階主管。
- **CQI**：由下而上、全員參與、重系統不重個人、前瞻預防。選主題優先**發生頻率高、高風險**。
:::
