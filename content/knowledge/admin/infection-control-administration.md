這一頁只講感染管制的**行政角度**：醫院要設哪些組織、護理人員發現傳染病**怎麼通報**、通報時限與隔離的責任歸誰。感染鏈、手部衛生、傳播途徑防護、法定傳染病名單與各疾病內容，已經整理在 [[infection-control]]、[[notifiable-diseases]] 與各疾病頁，這裡用連結帶過，不重複。

## 醫院的感染管制組織與制度 {#hospital-system}

依《**醫療機構執行感染管制措施及查核辦法**》(依傳染病防治法第 32 條第 2 項訂定)，醫院要有：

| 項目 | 規定 |
|---|---|
| **感染管制會(感管會)** | 由醫療機構**主管或副主管擔任召集人**，擬定感染管制政策、督導，定期開會並留紀錄 |
| **專責單位與人員** | 設感染管制**專責單位**(固定辦公空間、組織圖、職責分工)，並置依醫療機構設置標準規定的感染管制人員 |
| **監測與群突發處理** | 建置**醫療照護相關感染**個案、群聚、群突發事件的監測與處理機制；群聚時要作**調查處理報告**向感管會報告並追蹤到結束；機制包含標準作業流程，並**定期演習** |
| **抗生素管理** | 由感染症專科醫師或感染管制專責醫師負責，監測、審查、稽核與藥敏；定期向感管會報告 |
| **抗藥性細菌** | 對特定抗藥性細菌訂**標準作業程序**；高風險病人在顧及隱私下於病歷、病床周遭**標示**，提醒防護 |
| **洗手與環境** | 訂洗手標準作業程序，有充足設備與查核；照護環境、衛材、器械、儀器面板**定期清潔並消毒**；宣導手部衛生、**咳嗽禮儀**、戴口罩 |
| **員工保護** | **員工保健計畫**(預防接種、體溫監測、胸部 X 光等)；訂定員工暴露血液、體液、**針扎**的預防、追蹤與處置標準作業程序；對所有執行業務的人員辦**感染管制教育訓練** |
| **大流行應變** | 訂應變計畫：病人就診動線、**PPE 及穿脫程序**、不明原因發燒病人處理、隔離與接觸者追蹤、廢棄物動線；**防護裝備要有物資管理計畫並儲備安全存量** |

- **查核**：中央或地方主管機關查核；**地方主管機關至少每 2 年**查核轄區內醫療機構一次。查核範圍包括組織與人力、感染監測通報與處理、抗藥性管制、傳染病防治配合措施、員工保護、安全乾淨的照護環境、教育訓練。有缺失**限期改善**，屆期未改善依法處罰。
- 國家年度目標也有「**落實感染管制**」(員工健康管理、抗生素管理、**組合式照護**、環境清潔、醫材消毒滅菌)，見 [[patient-safety-reporting]]。

## 護理人員的通報責任 {#reporting-duty}

| 情況 | 規定(傳染病防治法) |
|---|---|
| **醫師**發現傳染病或疑似傳染病 | 立即採**感染管制措施**，並向當地主管機關報告(第 39 條) |
| **醫師以外的醫事人員**(含護理人員)發現 | 應**立即報告醫師**，或依規定報告當地主管機關(第 40 條)；**醫事機構要指定專責人員**督促所屬人員依規定辦理 |
| 通報時限 | **第一類、第二類 24 小時內**；**第三類 1 週內**；第四類、第五類依中央公告(第 39 條)；HIV 依專法 **24 小時內** |
| 對外說明個案病情 | 醫師要**先向當地主管機關報告並獲證實**才能說明 |
| 接獲通報後 | 地方主管機關迅速檢驗、調查來源；病人與相關人員**不得拒絕、規避或妨礙**(第 43 條) |
| **隔離治療** | **第一類**傳染病病人，**在指定隔離治療機構**隔離治療；第二、三類**必要時**才隔離；第四、五類依中央公告的防治措施(第 44 條) |

- 分類原則：中央主管機關依**致死率、發生率與傳播速度**等危害風險高低分第一到五類(第 3 條)；名單與時限整理在 [[notifiable-diseases#categories]]。例如**結核病是第三類**、**登革熱是第二類**、**庫賈氏病**是第四類(1 個月內通報)。
- 疾病的傳播途徑：**腮腺炎**經飛沫，**不是**病媒傳染；**登革熱、日本腦炎、斑疹傷寒**經病媒；COVID-19 以**飛沫與空氣(氣膠)**為主要途徑。**空氣傳染**典型是**麻疹、水痘、結核病**；**腦膜炎(腦膜炎雙球菌)與流感**常規屬**飛沫**防護。細節見 [[infection-control#transmission-based-precautions]]。
- 舊題 110-2 問「何者不是藉由空氣傳染」，選項腦膜炎與流感其實都屬飛沫，考選部公告答案是腦膜炎；考場遇到這種題以公告答案為準，學理上要記**空氣：麻疹、水痘、結核**。

## HIV 感染者的隱私與通報 {#hiv}

依《人類免疫缺乏病毒傳染防治及感染者權益保障條例》：

- 醫事人員發現感染者要在 **24 小時內**向地方主管機關通報(第 13 條)；通報對象包括**未發病者、發病者、18 個月以下疑似感染的嬰幼兒、疑似感染的孕產婦**。
- 感染者就醫時**應告知**醫事人員已感染 HIV(緊急或隱私未受保障時除外)；感染者提供事實後，醫事機構**不得拒絕提供服務**(第 12 條)。
- 主管機關、醫事機構與醫事人員因業務知悉感染者姓名、病歷等資料，**除依法律規定或基於防治需要外，不得洩漏**(第 14 條)。所以**未經病人同意不可主動告知其照顧者**診斷與照護事項，這是保密原則(見 [[nursing-personnel-act#duties]])。
- 護理指導：HIV 主要經**血液、體液與垂直傳染**，**日常共同生活**(共用餐具、擁抱、同住)**不會**傳染；性行為要全程使用保險套，**口交也不是安全性行為**；飲食提供**高熱量高蛋白**、避免生食；更多內容見 [[hiv-aids#nursing]]。

## 病室清潔與被服 {#cleaning}

- 病室清潔用**濕式清潔**，**由上而下、由乾淨到髒(最小污染區到最大污染區)**；抹布與拖把**不可抖動**；病床、床旁桌用**適當的消毒液**擦拭，不是只用清水。
- 使用過的被服以**高溫清洗**：水溫 **≥71℃**，至少清洗 **25 分鐘**(疾管署《醫療機構環境清潔消毒感染管制措施指引》)；卸下被服的過程**盡量避免抖動**，以免產生氣溶膠。
- 沾血液的紗布屬**感染性事業廢棄物**，分類與容器見 [[hospital-safety-environment]]。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 護理師發現疑似傳染病，自己決定通報時限 | **立即報告醫師**，醫師依類別時限通報 | 傳染病防治法第 39、40 條 |
| 第三類傳染病 24 小時內通報 | **1 週內**(HIV 依專法 24 小時) | 第 39 條 |
| 雙手沾血液可用酒精性乾洗手 | 有可見髒污或沾血液體液要用**肥皂與水**洗手 | 乾洗手無法去污 |
| 腰椎穿刺或放導管穿隔離衣、戴護目鏡即可，不必口罩 | **手套、口罩、隔離衣、護目鏡**(防飛濺) | 標準防護 |
| 腮腺炎是病媒傳染 | **飛沫**傳染 | 病媒傳染如登革熱、日本腦炎 |
| 照顧者不需經病人同意即可得知 HIV 診斷 | **未經同意不得洩漏** | HIV 條例第 14 條 |
| 病室清潔從最髒的地方開始 | **由乾淨到髒、由上而下** | 避免交叉污染 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 感管會召集人是**醫院主管或副主管**；醫院要有**專責單位與人員**；地方主管機關**至少每 2 年**查核感染管制。
- 護理人員發現傳染病：**立即報告醫師**；通報時限：**第一、二類 24 小時、第三類 1 週**；HIV **24 小時**。
- **第一類**傳染病在**指定隔離治療機構**隔離治療。
- 空氣傳染：**麻疹、水痘、結核**；飛沫：腮腺炎、百日咳、流感、腦膜炎；病媒：登革熱、日本腦炎、斑疹傷寒、瘧疾。
- 針扎處置、員工暴露事件的 SOP、員工預防接種都屬**員工保護**，見 [[hospital-safety-environment]]。
- HIV：**不得洩漏**、**不可拒絕提供服務**，日常接觸不傳染。
:::
