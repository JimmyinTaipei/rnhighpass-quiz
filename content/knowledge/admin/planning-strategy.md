規劃是管理程序的第一步，**核心觀念是決策**。這一頁的題目多半是**名詞辨別**(願景、使命、理念、價值觀)、**5W1H 找缺漏**、**SWOT 內外部有利不利歸類**，以及**規劃層級對應哪一級主管**。決策與問題解決見 [[decision-making]]，目標管理與時間管理見 [[objectives-time-management]]。

## 規劃的意義、內容與目的 {#concept}

- **規劃**：深思熟慮的過程，基於事實與資訊，經過評估後，訂定**未來具體行動方法與步驟**；也就是訂出目標，並評估如何完成。**規劃的核心觀念是「決策」**(不是分析資料、簡化流程或開源節流)。**規劃是決策的過程，計畫是規劃的結果**。
- Gillies 的管理過程中，**規劃**包含：制定**標準**、擬定**政策**、**作成決策**、**編列預算**等；**設定評估內容屬於控制**，**工作設計屬於組織**。
- **規劃的內容**用 **5W1H**(6W)表示：**What** 做什麼行動、**Why** 為何要做、**When** 何時完成、**Where** 在何處或由哪個部門、**Who** 由誰負責或執行、**How** 如何實施。
- **規劃的目的與功能**：提供部屬努力的**方向**、**協調一致**、**降低不確定性**、**減少重複與多餘的行動**(不是增加工作步驟)、**作為控制績效的基礎**、增加達成目標的機會、發揮管理績效。個人承諾度、組織彈性不是規劃直接帶來的功能；規劃太硬性反而降低彈性。
- **規劃的原則與特性**：**具體可行、切合實際**；有**時效**、有**合理性**(理性客觀分析，不可只憑直覺)、**繼續性與連續性**、**經濟性**、系統性、具體性、**彈性**、實用性、綜合性。

**5W1H 找缺漏**：把題目的目標逐字對照，缺哪一個就選哪一個。

| 目標敘述 | 有什麼 | 缺什麼 |
|---|---|---|
| 為提升護理品質，培養 3 位 N3 護理師**短期**出國完成專科培訓 | Why(提升品質)、What、Who、Where(出國) | **When**：只有「短期」沒有明確完成期限 |
| **本年度**各病房病人服務滿意度提升到 90% | When(本年度)、Where(各病房)、What、Who | **Why**：沒說為什麼要提升 |
| 醫院為提升護理品質，培養 5 位 N2 完成進階至 N3 | Why、Where(醫院)、Who、What | **When**：沒有期限 |

## 規劃的類型與層級 {#types}

| 分類方式 | 類型 | 負責的主管 | 特色 |
|---|---|---|---|
| 依**廣度(層級)** | **策略性規劃** | **高階**(護理部主任) | 應用於整個組織、建立全面目標；長期、方向性、涵蓋廣；包含組織目標、政策、願景使命理念的調整 |
| | **功能性(戰術性、部門)規劃** | **中階**(督導) | 各**部門**的目標與規劃，中程 |
| | **操作性(作業性、執行)規劃** | **基層**(護理長) | 說明如何達成全面目標；短期、特定、經常性；作業規劃與程序 |
| 依**時間** | 長期、中期、短期規劃 | | 時間切點各行業不同 |
| 依**重複性** | **專案規劃**(不重複、較複雜)；**例行規劃**(重複，如程序) | | |
| 其他 | **偶發性規劃** | | 為**突發事件或危機**預備的備用應變方案 |
| | 方案規劃 | | 針對單一專案或活動的詳細規劃 |

- **規劃的權變因素**：管理**階層**越高越偏長期、策略性；**組織生命週期**；**環境不確定程度**高時用彈性的、方向性、短期規劃；未來承諾的期限越長，規劃時間越長。
- **規劃的過程**(四大步驟)：依宗旨**擬定目標** → **分析現況與未來趨勢**(預測環境、評估資源) → **研擬規劃草案**(選擇可行方案) → **規劃評值**。
- 評估資源：有形(土地、設備、經費、時間、法規)、無形(組織氣氛、員工素質、價值觀)、環境因素。
- **提供護理服務時訂定優先次序**：先處理**對生命有威脅**且影響重大者，其次是破壞性改變、影響正常發展者。
- **評值的標準**：**效率標準**(對人力物力財力的有效利用，即**投入**成本的評值)、**效能標準**(目標有效達成，投入後的**結果**)、**速度標準**(是否按時執行)。例：病人壓瘡發生率降到 0.005% 是**效能(效果)目標**；經費執行率、系統建置落後率、職前教育完成率是**效率或過程**指標。

## 願景、使命、價值觀與理念 {#vision}

| 名詞 | 意義 | 關鍵字 |
|---|---|---|
| **願景**(vision) | 組織**未來想達成的最終目標**，是**未來的藍圖與展望**；有效的願景要簡單易懂、與任務與價值觀相符、為眾人共識 | **未來**五年成為以社區為導向的優質區域醫院 |
| **使命**(mission) | 組織**存在的理由與意義**、應負的責任，是全體的中心目標；具涵蓋性與長期穩定，不隨情況機動改變 | 為何存在、基本任務 |
| **價值觀**(value) | 組織領導者所重視的**信念或態度**，作為指導員工的準則；是組織成員共同信念，不是每位員工各自設定 | 共同信念與行為準則 |
| **理念**(philosophy) | 長期思考與實踐形成的**觀念**，反映願景與價值觀 | 基本信念 |

- 討論理念時，最不可或缺的兩個考量是**願景與價值**。進行組織設計前較恰當的順序：**願景、理念、使命、目標** → 環境評估 → 人力資源評估 → 政策過程評估。
- **舊題 114-1**：「有關使命的敘述」選項定義邊界重疊，考選部公告**送分**。
- **規劃層次由高到低**(常見說法)：使命／願景 → 哲學 → 目標 → 策略 → 政策 → 程序 → 規則。

## 策略性規劃與 SWOT {#swot}

- **策略性規劃的步驟**：**確認組織的使命與目標 → SWOT 分析 → 制定策略 → 執行策略 → 評估結果**。SWOT 在**制定策略之前**，評估結果在**執行之後**。
- **某護理機構根據內外在環境調整願景、價值觀、理念與使命** → **策略性規劃**。

| SWOT | 範圍 | 意義 | 例子 |
|---|---|---|---|
| **優勢 S** | **內部**有利 | 組織相對的長處與競爭優勢 | 已協助培訓許多照護人力 |
| **劣勢 W** | **內部**不利 | 組織的短處或資源不足 | **經費不足**尚未投資；財務、效率、員工素質問題 |
| **機會 O** | **外部**有利 | 環境趨勢或有利的改變 | 看好**人口老化與少子化**趨勢、財團**邀請合作** |
| **威脅 T** | **外部**不利 | 外在的競爭或不利改變 | **國際集團已與當地業者合作**，競爭者先進入市場 |

- 判斷順序：**先分內部(S、W)或外部(O、T)，再分有利(S、O)或不利(W、T)**。機構的財務、效率、員工素質都是**內部**的，不是威脅。
- SWOT 也可用在**生涯規劃**，了解自己。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 規劃的核心觀念是分析資料、簡化流程或開源節流 | **決策** | 規劃就是選擇的過程 |
| 規劃的目的包括增加工作步驟 | 減少重複、降低不確定 | 提升效率 |
| 規劃可以憑直覺、不必連貫 | 理性分析、連續 | 規劃原則 |
| 願景是組織存在的主要目的 | 那是**使命**；願景是未來展望 | 定義 |
| 願景是成員的共同信念 | 那是**價值觀** | 定義 |
| 使命可以隨情況機動改變 | 使命長期穩定 | 定義 |
| 組織目標與政策是基層人員共同規劃的長程計畫 | **高階**主管負責策略性長程規劃 | 層級 |
| 作業規劃與程序由護理部主任規劃 | **護理長**規劃 | 層級 |
| 策略性規劃屬中程計畫 | 屬**長程**、高階 | 層級 |
| SWOT 的優勢是外部有利因素 | **內部**有利 | 內外部 |
| 機構財務、效率、員工素質是威脅 | 是內部的優勢或劣勢 | 內外部 |
| 策略性規劃先制定策略再做 SWOT | **先 SWOT 再制定策略** | 步驟 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 規劃是管理第一步，**核心＝決策**；目的：方向、協調、降低不確定、減少重複、控制基礎；**不增加工作步驟**。
- **5W1H** 缺漏題：看有沒有 **Why、When**；「短期」「本年度」要分清是否真有期限。
- **層級**：高階＝策略性(長程)；中階＝功能性／部門(中程)；基層＝操作性／作業(短程)。**偶發性規劃**＝應變備案。
- **願景**＝未來藍圖；**使命**＝存在理由；**價值觀**＝共同信念；**理念**＝基本觀念。
- 策略性規劃：使命與目標 → **SWOT** → 策略 → 執行 → 評估；**SWOT 內部(S、W)外部(O、T)**。
- **效能**＝目標達成(結果)，**效率**＝資源投入與使用。
:::
