工具題是**「情境 → 選工具」配對題**：先判斷這一步是**找原因**、**抓重點**、**收集資料**、**看趨勢**還是**排時程**，再對照下表。觀念與 Donabedian 見 [[quality-management-concepts]]。

## PDCA 與 FOCUS-PDCA {#pdca}

| 階段 | 做什麼 | 跌倒改善的例子 |
|---|---|---|
| **P**lan 計畫 | 分析問題、**擬定計畫與對策**(包含依原因決定行動方案) | 擬定改善老人跌倒的計畫 |
| **D**o 執行 | **貫徹**計畫與措施 | 實施跌倒預防措施 |
| **C**heck 查核 | **稽核、評值**成效 | **查核跌倒評估的落實度、浴廁扶手使用率**、滿意度分析 |
| **A**ct 處置 | 依查核結果**修正、標準化、持續改善** | 把有效做法制度化 |

- **FOCUS-PDCA**：**F**ind 找出要改善的過程、**O**rganize 組成了解此過程的小組、**C**larify 釐清現況、**U**nderstand 了解變異原因、**S**elect 選擇改善方案，之後進入 **PDCA**。**A 是 Act**(持續修正)，不是「尋找協助」。
- **問題解決的第一步**是**定義問題**，找出現況與預期的**差距**(例：抽血等候時間太長，先量化排隊情形)，而不是直接加人力、補償病人或馬上腦力激盪執行。
- **資料分析階段**要做的事：依人事時地物整理資料、依時間排序找關聯、用魚骨圖整理因果；**擬定對策、挑最省錢又容易的方案**是下一階段的事。
- **事後持續改善**用 PDCA；見 [[quality-management-concepts#topic-selection]]。

## 品管圈 {#qcc}

- **品質管制圈**(QCC)：同一工作單位的基層人員**自主**組成的**小團體**，以科學方法推動品質活動；石川馨被稱為品管圈之父。
- **基本條件**：小團體(成員約 **2–10 人**)、成員同單位、**自願**、定期開會、設**組長**；多個圈時設**指導員**。
- **步驟**：找問題 → 收集資料 → 分析問題 → 找解答(**BEST**：考慮**預算**、**有效率**、**員工需要**、**不花太多時間**) → 評估結果 → 提出報告。
- 品管圈遵循 **PDCA**，從**計畫**開始；**數據不是唯一的控制指標**，定性資料也重要。
- 功能：提高士氣與認同、增加溝通管道、達到高品質服務。

## 品管七大手法(傳統) {#seven-tools}

| 工具 | 用途 | 一句話判斷 |
|---|---|---|
| **查檢表**(核對表、稽核表) | 簡單的**資料收集**與現場查核，把步驟列出、統計結果 | **落實洗手、現場稽核、收集事實** |
| **魚骨圖**(特性要因圖、因果圖) | 腦力激盪，**列出所有可能原因**與結果的關係 | **分析原因**；用於「發想與列舉」 |
| **柏拉圖**(Pareto) | 依發生**次數**由大到小排列＋累積百分比，**80/20 原理**找出**關鍵少數**的重要導因 | **找出重要導因、抓重點、異常事件的主要原因** |
| **管制圖** | 依時間繪製，有**中心線與上下管制界限**，看製程**是否在控制範圍內、是否穩定** | **監測指標(如給藥異常率)是否異常**；不是用來找導因 |
| **直方圖**(柱狀圖) | 看資料的**分布與變異**，比較數量大小 | |
| **趨勢圖**(推移圖、折線圖) | 看資料隨**時間**的變化趨勢 | |
| 散布圖 | 看**兩個變數**是否有相關 | |

- 另有**流程圖**(作業順序與步驟)、**甘特圖**(專案進度與時程，**不是**分析原因的工具)。
- **魚骨圖列原因、柏拉圖挑重點**：先用魚骨圖發想，再用柏拉圖聚焦。
- **柏拉圖的錯誤說法**：「以查核表**刪除極端案例**」，那不是柏拉圖也不是查核表的功能。
- 找跌倒率超標的**導因**：魚骨圖、查檢表、柏拉圖都適用，**管制圖不適用**(它只監測趨勢與穩定度)。

## 新七手法 {#new-seven}

偏重**文字與邏輯整理**(定性)：**關聯圖**、**親和圖**、**系統圖(樹狀圖)**、**矩陣圖**、**過程決策計畫圖(PDPC)**、**箭線圖**、**矩陣數據分析**。

| 手法 | 用途 |
|---|---|
| **關聯圖** | 用箭頭畫出問題與原因的關係，適合複雜問題 |
| **親和圖** | 把相似原因歸類，適合沒有經驗、不清楚的問題 |
| **系統圖(樹狀圖)** | 把要素或目標逐層展開，例如**分析病人跌倒的因素**、有系統列出因果箭頭 |
| **矩陣圖** | 把成因排成矩陣找關聯，評估與擬定策略 |
| **箭線圖** | 規劃進度與時程 |

- **柏拉圖屬於傳統七手法，不是新七手法**。傳統偏**數據與定量**，新七手法偏**邏輯與定性**。
- 品管圈用查核與問卷找出血液管路感染的根本原因後，要找**改善策略**，用關聯圖、親和圖、系統圖、矩陣圖。

## 根本原因分析(RCA)與失效模式分析(FMEA／HFMEA) {#rca-fmea}

| 比較 | RCA | FMEA／HFMEA |
|---|---|---|
| 時機 | **事後**(已發生的事件)，**回應式**(reactive) | **事前**，**前瞻式**(proactive)，**預防** |
| 做法 | 用系統化程序找出**近端與遠端**的**根本原因**，擬定改善對策 | 預測流程中**可能的失效模式**與其影響，**排出優先順序**，事前修正或控管 |
| 對象 | **重大事件**，如警訊事件、風險評估**一至二級**嚴重的事件；輕微(三至四級)事件不必 | 高風險流程(如給藥、手術流程) |
| 組成 | **小組**(熟悉流程的跨領域人員) | 團隊逐項檢視 |
| 原則 | **對事不對人**，檢討系統與流程 | 預防失誤 |

- RCA 要穿透**近端原因**找**根本原因**。法定的時程：重大醫療事故通報後 **45 日**內完成根本原因分析與改善方案，見 [[legal-liability-disputes#dispute-act]]。
- 「事前分析」選 **FMEA**；PDCA、個案報告都不是事前分析。
- **跌倒原因分類**：病人夜間如廁**無人扶持** → **人力問題**；不是技術問題或設備問題。**護理師忘記告知禁食導致手術延期** → **過程**(投入過程不當)的問題。

## 精實管理(Lean) {#lean}

- 核心是**以病人需求為核心**，**定義價值**、**消除浪費**(等待、搬運、無效動作)、讓流程**順暢**，**精簡流程**，讓護理人員有更多時間做**直接照護**。
- 五大原則：定義價值、識別價值溪流、創造順暢流程、建立**拉動式**服務、追求完美。
- **精實不等於精簡人力**，也**不是增加步驟**或單純降低成本；精簡人力反而會傷害品質與安全。

## 平衡計分卡(BSC) {#bsc}

Kaplan 與 Norton 發展，把組織**願景與策略**轉化為可衡量的指標與行動，是**績效評核指標的管理工具**，也可當**與員工溝通策略**的工具。

| 構面 | 看什麼 | 護理例子 |
|---|---|---|
| **財務面** | 營運績效、成本、生產力 | 護理成本控管、占床率、收入 |
| **顧客面** | 顧客價值與滿意度、市占率、延續率 | **病人抱怨次數**、滿意度調查 |
| **內部流程面** | 流程的**時間、品質、成本** | 給藥錯誤率、跌倒發生率、等待時間 |
| **學習與成長面** | 員工能力、資訊能力、組織支持 | 教育訓練時數、離職率、士氣 |

口訣：**財、顧、內、學**。**沒有「品質構面」**；SWOT(優勢劣勢機會威脅)與目標管理(目標設定、行動計畫、自我控制、成果評值)不是 BSC。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| PDCA 的 Do 是擬定計畫 | Do 是**執行**；擬定計畫是 Plan | 階段 |
| 查核落實度與扶手使用率是 Act | 是 **Check** | 查核評值 |
| FOCUS-PDCA 的 A 是尋找協助 | **Act** | 持續修正 |
| 先加人力或補償病人來解決抽血排隊 | 先**定義問題**、量化差距 | 第一步 |
| 管制圖可找出跌倒導因 | 管制圖看**穩定度**，不是找原因 | 用途 |
| 柏拉圖屬於新七手法 | 屬**傳統七手法** | 新七手法是關聯、親和、系統等 |
| 魚骨圖用來挑出最重要導因 | **列舉**原因；挑重點是**柏拉圖** | 發想與聚焦 |
| 甘特圖可分析原因 | 管理**進度** | 用途 |
| RCA 是預應式(事前)分析 | **事後、回應式**；事前是 FMEA | 時機 |
| RCA 用於三至四級輕微事件 | 用於**嚴重事件** | 風險分級 |
| 精實就是精簡人力 | 以**病人需求**消除浪費 | 精實 |
| BSC 有品質構面 | **財務、顧客、內部流程、學習與成長** | 四構面 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **PDCA**：P 計畫(含擬定對策)、D 執行、**C 查核**、A 修正標準化；**第一步是定義問題**。FOCUS 的 **A 是 Act**。
- **品管圈**：小團體、同單位、自願、組長；**BEST** 找對策；**數據非唯一指標**。
- **查檢表**＝收集資料與現場稽核；**魚骨圖**＝列原因；**柏拉圖**＝80/20 找重要導因；**管制圖**＝監測是否在控制範圍；**甘特圖**＝進度。
- **新七手法**(關聯、親和、系統、矩陣、PDPC、箭線、矩陣數據)**不含柏拉圖**；**系統圖**可分析跌倒因素。
- **RCA＝事後、小組、對事不對人、嚴重事件**；**FMEA＝事前預防**。
- **精實**＝以病人為核心消除浪費，**不是裁員**。**BSC**＝財務、顧客、內部流程、學習與成長，病人抱怨次數屬**顧客面**。
:::
