績效考核在管理程序中負責「**控制**」的功能。國考主要考三件事：**目的與原則**、**標準與方法的配對**、**偏誤的情境判斷**(題數最多)。工作說明書與工作評價見 [[hr-management-recruitment#job-analysis]]。

## 重點摘要 {#summary}

- 績效考核屬管理程序的**控制**功能；目的是獎懲晉升、回饋成長、溝通，**不是開除**。
- 原則：依職責與機構目標、員工要清楚、最初考核者是直屬主管、結果要面談回饋。
- 方法：檢查表、重要事件法、目標管理法、**360 度**。
- 常見偏誤：**月暈**(偏高)、**觸角**(偏低)、中央趨勢、近因、霍桑。

### 國考常考點 {#exam-points}

- 考核目的：**獎懲晉升調職**、**回饋成長**、**溝通**、**建立績效標準**、規劃教育訓練；**不是開除**。
- 原則：依**職責**與機構目標、員工要**清楚**、可**修正**、**最初考核者是直屬主管**、結果要**面談回饋**。
- **絕對標準**＝對照固定標準(檢核表)；**相對標準**＝員工之間排名。
- **檢查表**＝只看有無；**重要事件法**＝記錄事實；**目標管理法**＝共同設定目標；**360 度**＝多方來源。
- **信度**＝穩定一致(項目多、語句清楚)；**效度**＝測量正確(針對職責)。
- 偏誤：**月暈**(以偏概全，偏高)、**觸角**(偏低)、**向日葵**(顯示領導，全部高分)、**膨脹壓力**(怕負面反應)、**中央趨勢**(都給中間)、**霍桑**(被觀察就表現較好)、**近因**(只看近期)。

## 績效的意義與考核目的 {#purpose}

- **績效的意義**：從**國家社會**的角度是就醫可近性、公平性、服務一貫性；從**醫療機構經營者**的角度是**資源是否有效運用**、整體營運能否達成預期目標。
- **考核範圍**：工作內容與標準、工作成果與生產力、主管期望目標；應涵蓋專業行為、人格特質與工作成效，並與各層級人員的**職責**配合。

| 考核的目的 | 說明 |
|---|---|
| **獎懲、晉升、調整職務與薪酬的依據** | 結果可以用在人事決定 |
| 回饋、激勵 | 肯定優秀者，對怠惰者**正式警惕** |
| 改進與成長 | 提供知識、技能、態度改進的機會，發掘才能 |
| **增進主管與部屬溝通**，對目標有共識 | |
| **建立工作績效的標準** | |
| 規劃**在職教育與訓練** | 資料可訂訓練目標 |
| **檢驗甄選新進人員的方法是否有效** | 列為考核的合理目的 |
| 作為控制組織能否達成目標的方法之一 | |

- **不是**以「**開除不適任員工**」為主要目的；考核重視**發展導向**(培訓、獎勵)而非懲罰。

## 績效考核的原則與要素 {#principles}

1. 考核項目要配合**醫院目標與理念**，也要**依職務說明書與職責**設計，不是依個人職涯目標。
2. **每位員工都清楚**考核的項目、內容與過程，鼓勵員工**參與**。
3. 考核表要**省時、精確、項目完整**；**不同職位或職階**(護理師、組長、護理長)要用**相符的評核表**，不是所有人一份相同的表才公平。
4. 考核需要**標準作業程序**與評分基準，維持客觀公正。
5. 考核的**過程與內容要能定期檢討修正**，不是為了一致就不能改。
6. **最初的考核者必須是被考核者的直屬主管**。
7. 考核結果要**與部屬回饋面談**，不是隱私機密；評估者要懂得使用評量工具。
8. 考核結果可作為獎懲、晉升、調整職務的依據。

**考核檢討(面談)**：最後一步是主管與員工的**檢討會議**，重點是**雙向溝通**——澄清工作目的、**指出優缺點但不誇大**、促進工作滿足感、**建立新目標**。指引：環境舒適、有人代班不受打擾、事先計畫並強調重點、用**正面**語言、**謹慎且有建設性**地批評、**不應有令人意外的內容**，雙方在考核表上簽名。

## 考核的標準 {#standards}

| 標準 | 意義 | 例子 |
|---|---|---|
| **絕對標準** | 用**預先設定的固定標準**衡量個人表現，**不與他人比較** | 護理長依護理部的**標準檢核表**，依權數或分數計分；醫院訂定標準來考核員工；評等量表、檢查表、重要事件、目標管理 |
| **相對標準** | 員工**彼此比較**、排出順序，必有最好與最差 | **所有人員的考評成績排列比較**；人員比較法、排序法、強迫分配法 |
| 客觀標準 | 以預先設定達成工作目標的標準評核，較客觀 | |

- 絕對標準適合表現差異不大的小單位，缺點是**評分容易偏高**；相對標準易區分優劣，但會增加同儕競爭壓力。

## 考核的方法 {#methods}

| 方法 | 做法 | 優點 | 缺點 |
|---|---|---|---|
| **評語法**(論述) | 評核者寫下部屬的優缺點與能力表現 | 可仔細說明 | 費時、欠客觀 |
| **圖形評分(評等量表)法** | 對各項績效設計**分數或等級** | **容易測量、省時** | 項目不易區分 |
| **檢查表(核對表)法** | 列出期望的行為，評核者只勾**「是／否」或「有／無」** | **針對事實**、適用**大量受評者**、簡易判斷 | **無法表現好壞的程度與頻率**；要分辨每個項目達到的程度，應改用評等量表或行為錨定評等法 |
| **重要事件記錄法** | 記下員工成功或失敗的**具體事實** | 最適合**明確記錄員工表現的事實**；促使主管多接觸部屬 | 費時，需平時持續記錄 |
| **目標管理法**(MBO) | **主管與部屬共同設定**工作目標，期末討論成敗再訂新目標 | 較客觀、部屬自己參與評值 | 目標設定溝通耗時 |
| **360 度考核** | 資訊來自**直屬主管、員工自己、同儕、部屬及外部顧客**，多元觀點 | 角度全面、降低單一主管的偏誤 | 收集費時、易受人情影響 |
| 人員比較法(排序) | 同組員工互相比較排名 | 能排出順序 | 無法看出絕對水準，屬相對標準 |
| **績效查核法** | 依預先列好的項目勾選「達成／未達成」，常用於**技術操作**查核 | 標準統一、簡便 | 同檢查表 |

題型對應：

- 「只指出**有無**此行為，不判斷好壞程度」→ **檢查表**；
- 「**明確記錄員工表現的事實**」→ **重要事件法**；
- 「主管與同仁**共同設定**明年 N3、N4 人數增加 20%，並策劃訓練」→ **目標管理法**；
- 「直屬主管、員工、同儕與外部顧客」→ **360 度**(不是年度考評，那是**時間週期**；也不是部屬考評，那是**單一視角**)。

**信度與效度**

| 概念 | 意義 | 提高的做法 |
|---|---|---|
| **信度**(reliability) | 測量結果**穩定、一致** | **增加考核項目**、**語句敘述清楚**、**結構簡單** |
| **效度**(validity) | 測量**正確**、確實測到要測的 | **針對職責做測量**(內容效度)，這**不屬於增加信度**的方法 |

## 考核的偏誤 {#biases}

護理管理者要努力克服偏見，常考六種(加上近因與寬嚴)。**先看是「高估」、「低估」還是「集中給分」，再看原因**。

| 偏誤 | 意義 | 典型情境 |
|---|---|---|
| **光圈效應**(**月暈效應**，halo) | 依據員工**某一方面**的優點，推論其他方面也不錯，**評得過高** | 同儕相處融洽所以給高分；**自願幫護理長處理交辦事務得到賞識，卻忽略分內工作**；某項特質討人喜歡 |
| **觸角效應**(horns) | 因**某一缺點或事件**，**評得過低**，與月暈相反 | **考核前不久與護理長爭執**，結果得乙等；考核前一週犯了一個錯誤 |
| **向日葵效應**(sunflower) | 考核者**為了顯示自己領導有方、單位無弱兵**，對**所有部屬都給高分** | 護理長為表示單位沒有弱兵而給員工高評價 |
| **膨脹壓力** | 怕**低分帶來負面反應**(打擊士氣、起衝突、被部屬負評)，評分逐漸偏高 | 對表現不佳的護理師刻意給高分，**避免對方對自己有負面評價**；擔心打擊士氣而普遍評分偏高 |
| **中央(集中)趨勢** | 把所有人都評在**平均**，**不給極高或極低** | 考核者不了解工作標準，無法判斷績效 |
| **霍桑效應** | 人知道自己**被觀察**，行為就改變(多半是表現更好) | 護理師知道護理長在進行年度考績，**刻意表現得比平常好**；注意這是**受評者**的行為改變，不是評核者的偏誤 |
| **近因效應** | 只憑**最近一段時間**的表現評定整年 | 以考核前一個月的表現代表全年 |
| 寬大／嚴苛偏誤 | 整體給分偏高／偏低 | |

- **向日葵**與**膨脹壓力**都是「偏高」，區別在**動機**：想展現自己的領導成效是**向日葵**；怕得罪人、怕負面反應是**膨脹壓力**。
- **因應月暈效應**的作法：**開放員工互相評值並作為考核參考**(多源評估、360 度)；維持原樣、把不滿的人調職、請大家聚餐都不能解決問題。建立客觀的紀錄與標準也能降低偏誤。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 考核結果不可作為獎懲與晉升的依據 | **可以** | 考核的目的 |
| 考核過程不可修正以維持一致 | **應定期檢討修正** | 環境與法規會變 |
| 所有人用同一份評核表才公平 | **依職階與職責**設計 | 職責不同 |
| 考核是隱私，不讓部屬知道結果 | 要**面談回饋** | 促進成長 |
| 考核內容要配合個人職涯目標 | 配合**機構目標與職務說明書** | 考核的依據 |
| 考核的目的是開除不適任員工 | **發展為主** | 不是主要目的 |
| 檢查表法可以分辨達到的程度 | **只判斷有無** | 程度要用評等量表 |
| 護理長對所有人給高分是月暈效應 | **向日葵效應**(顯示領導) | 動機不同 |
| 因考核前爭執而給低分是月暈效應 | **觸角效應** | 低估 |
| 針對職責做測量可以提高信度 | 那是**效度** | 信度看穩定一致 |
