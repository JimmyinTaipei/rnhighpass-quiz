溝通題的分數幾乎都在兩件事：**判斷溝通方向**(上行、下行、平行、斜行、葡萄藤)和**溝通模式與障礙的名詞**。判斷方向只看兩件事：**誰對誰**，以及**雙方是否同一層級、同一部門**。

## 重點摘要 {#summary}

- 溝通方向：同層級 = **平行**；跨部門跨層級 = **斜行**；**葡萄藤**為非正式謠傳。
- 模式：**SMCR**(來源、訊息、管道、接收者)；**ISBAR**(介紹、狀況、背景、評估、建議)。
- 溝通態度：**直言型**(我訊息)、提示型、諒解型、警告型。
- 溝通障礙：心理、語意、方法、情緒、資訊超載；社群溝通不談病人可辨識資訊。

### 國考常考點 {#exam-points}

- **SMCR**＝來源、訊息、管道、接收者(Berlo，線型單向，無回饋)；環型加信號、噪音、回饋。**ISBAR**＝介紹、狀況、背景、評估、建議。
- **方向判斷**：同層級＝**平行**；跨部門跨層級＝**斜行**；**葡萄藤**＝非正式謠傳。實習老師與護理長、護理長與值班醫師＝**斜行**；護理部與藥劑部、護理長與病房主任＝**平行**。
- **溝通態度**：**直言型**(我訊息，說出影響)、提示型(提醒承諾)、諒解型(體諒但說出看法)、警告型。
- **溝通障礙**：心理(先入為主、感情欠佳)、語意、方法、情緒、**資訊超載**。
- 社群：**不匿名**、不談病人可辨識資訊、不提供線上診斷、刪除不當留言。

## 溝通的特質與模式 {#models}

**特質**：溝通是一種**過程**、會受**噪音**干擾、是**訊息的傳遞**、可以運用**語言與非語言**訊息。組織溝通還具有**持續性**(每次溝通會延續上一次溝通的感受與關係)；其他如不可逆性(說出的話無法收回)、交易性(雙方同時發送與接收)是另外的特性，不要和持續性混淆。

| 模式 | 提出者 | 要素與特色 |
|---|---|---|
| **線型溝通模式**(SMCR) | **David Berlo，1960** | 溝通品質繫於四要素：**來源(Source)、訊息(Message)、管道(Channel)、接收者(Receiver)**；**單向**傳遞，**缺少回饋** |
| **環型溝通模式** | Shannon 與 Weaver，1949 | 四要素之外加上**信號、噪音、回饋**；回饋用來修正訊息、去除噪音 |
| **螺旋型溝通模式** | Dance，1967 | 溝通過程不斷解析與反應，促進雙方溝通能力 |
| **結構化溝通 ISBAR** | | 標準化、簡潔、完整、及時，提升醫療照護品質 |

**ISBAR**：**I**ntroduction **自我介紹**(我是誰、確認病人身分)、**S**ituation **狀況**(病人發生了什麼事)、**B**ackground **背景**(臨床相關資料)、**A**ssessment **評估**(目前資料顯示的問題)、**R**ecommendation **建議**(還需要做什麼)。**S 不是 Share**。

**良好溝通管道的要件**：訊息是**必須的**(避免資訊充塞)、組織成員**容易取得**、訊息**直接且正式**傳達；題庫把「要傳達的訊息是**即時**的」當作錯誤敘述。

## 組織內的溝通途徑 {#channels}

| 類型 | 意義 | 例子 |
|---|---|---|
| **上行溝通** | 員工以報告、建議向**主管**反映意見，提供參與機會，符合民主精神 | 護理人力不足，護理長主動**找督導長請求支援** |
| **下行溝通** | 依組織系統由**上而下**傳達政策、指示 | 主管對下屬發布命令、公告 |
| **平行(橫向)溝通** | **同一階層**或職位相當者間的溝通，常發生在**不同命令系統**之間，彌補上下行的不足 | **病房會議討論業務**；護理人員之間協商排班；**護理部與藥劑部**為藥品包裝方式協調；**護理長與病房主任(醫師)**之間 |
| **斜行溝通** | **不屬同一組織層級**的單位或個人，跨部門又跨層級 | **實習老師與護理長**溝通學生實習目標；**護理長與值班醫師**直接溝通；護理部督導與資材局基層人員聯繫；**不同層級單位人員間** |
| **非正式溝通** | 基於成員的知覺與動機，經由社會關係進行，超越部門、單位與層級，又稱**傳言**或**群集性連鎖** | |
| **葡萄藤式溝通** | 訊息在組織中**亂竄**，網狀、迅速擴展，通常是**非官方消息**，最後可能完全被扭曲 | **年終獎金辦法尚在討論，護理師間已傳出「年資 2 年以上才有」** |

- 判斷關鍵
  1. **同層級** = 平行
  2. **下對上** = 上行；**上對下** = 下行
  3. **不同部門且不同層級** = 斜行
  4. **私下流傳、未證實的消息** = 葡萄藤
- 管理者要建立透明順暢的正式溝通管道，減少謠言。
- **溝通的媒介**：面對面、電話、書面、演說簡報、**電子網路溝通**(不受**時間、距離、假日、人數**限制，且傳輸**速度最快**)。

## 溝通技巧與態度 {#skills}

- **基本溝通技巧**：**傾聽**、反應、鼓勵、針對問題、**澄清**、**說話有條不紊**、提供相關訊息、人格化、知識傳授
  1. **有效溝通是與對方討論問題而非爭辯**
  2. 傾聽不只是點頭微笑，是**主動傾聽**；回應要主動適度，不是被動
  3. 並非任何議題都可隨時隨地溝通，要選**適當的時機與場合**
  4. **中斷別人說話並不斷表達自己的想法**，違反**傾聽**
- **面質**(confrontation)與**磋商**(negotiation)也是溝通技巧。
- **溝通態度的類型**

| 類型 | 做法 |
|---|---|
| **基本型** | 表達直接，想到什麼說什麼 |
| **詢問型** | 用詢問的方式讓對方明白可能的後果 |
| **提示型** | 提醒對方現在的行為**違背了過去的承諾**，要求兌現 |
| **直言型** | **直接表明**對方的行為對組織已經產生不良影響；常用**我訊息**(說事實、感受、影響與期望) |
| **警告型** | 警告對方行為可能導致**嚴重後果** |
| **諒解型** | **體諒**對方的立場，同時說出自己的看法 |

  - 例：護理長說「你沒請假私下換班，造成我管理困擾，讓我有不被尊重的感覺，請以後遵守換班規定」→ **直言型**。
- **同儕情緒支持**：新進護理師因病人病逝而哭紅眼眶，同事**彈性支援照護讓其抒發情緒**最適切；不是叫她不要把情緒帶到工作場合、只建議上課或鼓勵正向思考。
- 其他：**周哈里窗**(開放我、盲目我、隱藏我、未知我；「開放我」越大，溝通越容易)；**交流分析**(Berne，人格狀態分父母型、成人型、兒童型)。

## 溝通障礙 {#barriers}

| 障礙 | 例子 |
|---|---|
| **心理障礙** | 溝通者**排斥改變**、雙方**感情欠佳**、**先入為主**、未完全了解內容 |
| **語意障礙** | 說話太快或太慢、敘述冗長、言詞不當、重點不清 |
| **溝通方法障礙** | 肢體語言與內容不符、溝通方法選擇不當 |
| **情緒障礙** | 未達有效溝通前就有強烈情緒反應 |
| **資訊超載** | 護理長**一次交代太多任務** |
| 時間壓力 | 準備時間太短 |
| 領導型態與環境因素 | 護理行政主管的領導型態；環境吵雜、外務干擾 |

## 社群網站的溝通原則 {#social-media}

- **不適當**：**使用匿名**貼文(發表專業相關內容應公開真實身分、對言論負責)；在臉書或部落格**討論所照顧的病人**並公布可辨識病人的資訊(不得公布任何可辨識的訊息，經過去識別化亦要小心)。
- **適當**：不回應個人的醫療問題，建議當事人去醫療機構就醫；談論公事即使沒洩漏病人隱私，也可能洩漏**工作上的秘密**；應**檢查並刪除不適當的留言**。
- 病人隱私與倫理見 [[nursing-ethics-principles#confidentiality]]；電子資訊安全見 [[nursing-information-systems#security]]。
- **其他保密情境**：急診收治被強暴少女而記者追問，護理師**不可一一回答記者的問題**，媒體由醫院發言人統一處理；追蹤檢查結果要**直接向病人本人詢問**，不透過配偶。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| ISBAR 的 S 是 Share | **Situation** | 縮寫 |
| SMCR 的要素是來源、訊息、溝通者、接收者 | **來源、訊息、管道、接收者** | Berlo |
| 護理長與值班醫師溝通是平行溝通 | 跨部門又跨層級是**斜行溝通** | 題庫答案 |
| 護理長與病房主任(醫師)溝通是上行溝通 | **平行溝通** | 同層級主管 |
| 護理部與藥劑部協調是斜行溝通 | **平行溝通** | 同階層部門 |
| 年終獎金謠傳是平行溝通 | **葡萄藤式溝通** | 非正式 |
| 組織溝通是持續性，指溝通雙方同時發送及接收訊息 | 那是**交易性**；持續性＝延續上一次的感受與關係 | 特性 |
| 傾聽就是點頭微笑 | **主動傾聽**、澄清、摘述 | 溝通技巧 |
| 感情欠佳、先入為主、拒絕改變屬語意障礙 | **心理障礙** | 溝通障礙 |
| 護理長一次交代太多任務是心理障礙 | **資訊超載** | 溝通障礙 |
| 社群貼文可以匿名 | 專業貼文應**公開身分** | 社群原則 |
