護理資訊系統題的原則只有一句：**資訊系統是輔助工具，能減少間接護理時間、讓流程更安全，但不能取代護理人員親自探視與評估**，而且**一定要保護病人資料的機密性**。病歷與個資的法律面見 [[medical-records-consent]]。

## 重點摘要 {#summary}

- 護理資訊系統是**輔助工具**：簡化紀錄、減少間接護理時間，但**不能取代**探視評估、衛教與三讀五對。
- 資訊安全：離開即登出、**專人專用帳號**、不借帳號；三原則為機密、完整、可用。
- 電子病歷有稽核軌跡；異常事件檢討用**非懲罰性**方式，檢討系統與流程。

### 國考常考點 {#exam-points}

- NIS＝護理科學＋電腦科學＋資訊科學；功能：收集、儲存、處理、顯示、傳遞資料、減少通報時間；目的：**簡化紀錄、減少間接護理時間、數據監測自動化**。
- 資訊系統**不能取代**探視評估、衛教與三讀五對。
- **資訊安全**：離開即登出、**專人專用帳號**、不借帳號(含急救)、不下載帶回家、不隨意列印；三原則**機密、完整、可用**。
- **電子病歷**有稽核軌跡；影響因素人、事、物、時間(**教育訓練不足＝事**，**抗拒＝人**)。
- 異常事件檢討用**非懲罰性**方式，檢討系統與流程。

## 護理資訊系統(NIS)的基本概念 {#concept}

- **定義**：結合**護理科學、電腦科學與資訊科學**，用以處理、溝通與整合護理活動中的資料、資訊與知識，作為病人、護理人員與其他醫療人員做健康決策的依據。
- **必須包含**資訊結構、資訊過程、資訊技術；**建構過程與護理過程相似**(分析、設計、執行、評估，類似評估、診斷、計畫、執行、評值)。
- **功能**：可收集大量資料、儲存大量資料、快速正確處理資料、利用光筆擷取資料、快速顯示資料、輸送傳遞訊息、減少通報時間。
- **目標**：擬定正確新穎的護理計畫並改善護理資源運用、執行護理活動、**自動化作業**(如心跳、血壓監測自動化)、預先發現問題並減少護理記錄時間、早做準備與修正護理計畫。
- **助益**
  1. **服務**：提升品質、提供標準化照顧
  2. **管理**：提升效率，協助分析單位護理成本、護理人員能力、人力分配、安排在職教育
  3. **教學**、**研究**
  4. **應用範圍**：臨床、行政、教育與研究
- **發展護理資訊系統的目的**：改善護理資源運用、**簡化護理紀錄程序**、使數據監測自動化；**不是減少直接護理時間**。它是**減少間接護理時間(文書)，增加直接護理時間**。

**資訊系統的效益與界限**

| 正確的說法 | 錯誤的說法 |
|---|---|
| 協助監控**病床數與住院天數**；評估病人所需護理措施、改善護理資源運用；用電子病歷提升紀錄的完整性與持續性；**減少護理紀錄重複抄寫時間**；增進護理管理效率 | **自動記錄病情變化，無須探視或評估病人**；資訊化衛教後**不用花時間衛教**；條碼辨識病人可以**省略三讀五對**；處理護理資訊**不須擔心資料保密性** |
| 條碼辨識與電子化提升安全 | 條碼只是**輔助**，不能取代三讀五對基本流程 |

**影響 NIS 發展的因素**(人、事、物、時間)

| 因素 | 例子 |
|---|---|
| **人** | 使用者對系統**抗拒**、資訊素養不足、學習意願 |
| **事** | **系統上線時教育訓練不足**、功能設計不符需求、缺乏評估機制、流程整合欠佳 |
| **物** | 電腦硬體不足、網路不穩、軟體常當機 |
| **時間** | 開發與推動時程過於緊迫、工作繁重無法排開時間參訓 |

## 資訊科技與病人安全 {#safety}

運用資訊科技促進病人安全的典型例子：**條碼辨識藥物與病人(條碼給藥 BCMA)**、**電子化醫囑(CPOE)**、**臨床決策支援系統(CDSS)線上查詢藥物交互作用**、把藥物資訊列印在藥袋標籤。

- **「張貼標示禁止查詢病人隱私」不是運用資訊科技**，是紙本公告與行政規範；若要用資訊科技保護隱私，應採**電子權限控管**與**操作稽核軌跡**。

## 電子病歷 {#emr}

- **完全電子病歷的優點**：資料可在同體系**共享**、維持資料**一致性**，資料**結構化**、可促進醫學研究，**不必有紙本病歷**、可減少醫院的成本。
- **「流程管制與修改方便，且不會留有紀錄」是錯的**：電子病歷有**稽核軌跡**，所有存取、修改、刪除都會留下時間與操作者紀錄，以保障真實性、完整性與法律效力。
- 病歷保存年限與管理見 [[medical-records-consent#retention]]。

## 資訊安全的使用原則 {#security}

資訊安全三原則：**機密性**(confidentiality)、**完整性**(integrity)、**可用性**(availability)。

| 做法 | 對或錯 | 原因 |
|---|---|---|
| **離開護理工作車或電腦時**，隨時**登出或關閉畫面** | 對 | 防止未授權讀取 |
| **使用自己的身分(帳號)進入**，使用後立即登出 | 對 | **專人專用**，可追溯 |
| **忙碌時請他人用自己的帳號代為記錄**；**急救時暫用他人帳號**；**借用醫師帳號瀏覽病人病況** | **錯** | 紀錄的法律責任與不可否認性 |
| **隨意列印病人資料**，或**完成紀錄後盡量列印作佐證** | 錯 | 減少紙本、避免外洩，要列印就依規定保管與銷毀 |
| **下載資料回家整理個案報告** | 錯 | 違反個資法與院內規定 |
| **幫同事打下班卡** | 錯 | 偽造出勤紀錄 |
| **確認照護紀錄簽章後再下班** | 對 | 紀錄即時、完整與責任歸屬 |

## 病人安全事件的檢討 {#incidents}

- **異常事件檢討要採非懲罰性文化**，重點在**系統與流程**。例：糖尿病病人訂的素食送錯，營養部門的處理——應仔細檢討送錯的導因、檢討知識技能是否足夠、加強伙食準備正確性的稽核；**找出犯錯者並將他調到其他單位是最不適當的**，會造成通報隱瞞。
- **跌倒原因歸類**：病人夜間如廁、無人扶持，屬**人力問題**；不是技術或設備問題。分析原因的工具與 RCA 見 [[quality-improvement-tools#rca-fmea]]；通報與目標見 [[patient-safety-reporting]]。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 發展 NIS 的目的是減少直接護理時間 | 減少**間接**護理時間 | 增加直接照護 |
| 資訊系統自動記錄，就不用探視評估病人 | **不可取代**親自評估 | 專業判斷 |
| 條碼系統可以減少三讀五對流程 | 只是輔助 | 病人安全 |
| NIS 處理的資訊不須擔心保密性 | **要加強保密與權限控管** | 個資 |
| 電子病歷修改不會留下紀錄 | 有**稽核軌跡** | 完整性 |
| 忙碌或急救時可借用他人帳號 | **嚴禁** | 不可否認性 |
| 系統上線教育訓練不足屬於人的因素 | 屬於**事**的因素 | 因素分類 |
| 抗拒使用系統屬於事的因素 | 屬於**人**的因素 | 因素分類 |
| 檢討送錯餐要找出犯錯者調離 | **非懲罰性**、改善系統 | 避免隱匿 |
