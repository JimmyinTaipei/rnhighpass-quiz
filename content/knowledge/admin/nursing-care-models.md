照護模式題是**關鍵字配對 + 依人力選模式**。看到「專人發藥、專人換藥(以工作為中心)」是功能性，「**組長**帶一組」是成組，「**住院到出院由同一位護理師計畫**」是全責，「**護佐、照服員搭配護理師**」是技術混合。人力需求的計算見 [[nursing-workload-productivity]]，人力彈性運用見 [[nurse-staffing-policy#shortage]]。

## 各模式的特色 {#models}

| 模式 | 做法 | 優點 | 缺點 | 關鍵字 |
|---|---|---|---|---|
| **個案護理**(case method) | **一位護理師在當班**負責**一位病人所需的全部護理**，是最古老的方式；常見於**加護**單位 | 照護完整 | 人力需求多；**不是貫穿整個住院期間**；護理沒有連續性 | 當班負責 1–2 位病人所有護理；**適用護生實習** |
| **功能性護理**(functional) | **以工作為中心**，把工作依技術與任務切分，由護理長分派每日每人工作，每人只負責一部分 | **分工清楚**、熟能生巧、**節省人力與經費**、作業快、以最少人力提供最起碼護理 | 缺乏**整體性、個別性、連續性**，病人被切割；護理人員易工作疲憊、缺乏成就感；組織上屬獨裁方式 | 專人給藥、專人換藥、專人量生命徵象 |
| **成組護理**(team) | **專業護理人員與輔助人員**組成小組，由**組長**帶領，**組長負責工作的分派、指導、計畫與評值** | 使不同背景、技術的人員有效運用；**團隊導向**，分權的一種形式 | 人員分散、花錢、較浪費時間 | 組長帶資深、資淺護理師、護生、護佐共同照顧一組病人 |
| **全責護理**(primary) | 病人**從入院到出院**由**全責(主責)護理師**負責評估、聯繫、擬定計畫、執行與評值；非上班時間由**協同護理師**依計畫執行 | **連續性、協調性、整體性、個別性**；**責任感、自主性、工作滿意度**增加；病人安全感增加 | **經費耗費大、需要合格人力多**；適合護理人員均為正式有執照的機構 | 24 小時負責、住院到出院固定一位 |
| **綜合護理**(modular) | 針對全責護理的缺點修飾：**成組護理的小組**一起護理 **8–12 位病人**，保有全責護理自主負責的精神 | 兼具兩者優點 | | 護理長為諮詢者、協調者、激勵者 |
| **技術混合**(skill mix) | **護理師搭配受過訓練的護佐、護理佐理員或照顧服務員**，由輔助人員協助日常生活與基礎照護 | 授權非專業工作，**減輕護理師負荷**，發揮人力效益 | | 輔助人員＋護理師 |

- **功能性護理是唯一以「工作」為中心的模式**；**個別性護理不是功能性護理的優點**。
- **全責護理的特性**是個別性、連續性、整體性、協調性，**不是功能性護理**；全責護理**人事成本較高、照護品質較好**；**人員專精、快速完成工作**是功能性護理的優點，不是全責護理。
- 全責護理由**責任(主責)護理師**對病人負照護全責，**擬定並決定照護計畫**；當班護理師只依計畫執行，**不是當班護理師或小組長決定**(小組長決定是成組護理的特色)；全責護理也強調出院準備與連續性。
- **主護護理**與**全責護理**在題庫常指同一類；**個案護理**才是「當班照顧病人所有需求」。
- 護理型態不同，需要**不同類別與比率**的護理人員，所以**人力規劃要先選定護理型態**。

## 依情境選模式 {#choose}

| 情境 | 適合的模式 | 理由 |
|---|---|---|
| 護理人力招募不足、占床率居高不下 | **功能性護理** | 用最少人力最快完成常規工作 |
| **新進護理師多**，用工作與技術需求分配 | **功能性護理** | 分工、標準化 |
| 急診湧入大量病人，病房護理人員被派去支援，**依工作性質固定分工** | **功能性護理** | 大量傷患、時效 |
| **臨床經驗 3 年以上的護理師只有 3 人**，其餘 1 年以下 | **成組護理** | 資深當組長，資深帶資淺 |
| 護理師**皆 3 年以上**、無新進人員、人力符合護病比 | **全責護理** | 需要高度自主與足夠人力 |
| 傳染病大流行期間的**隔離病房** | **全責護理**(題庫答案) | 由固定護理師整合護理活動，減少人員進出與穿脫防護裝備 |
| 由護佐或照服員協助護理師執行日常生活照護 | **技術混合** | |
| 單位護理人員不足，要減輕護理師非專業事務 | **技術混合** | 輔助人力 |

## 個案管理與其他方式 {#case-management}

1980 年代美國實施 **DRGs** 後，醫院更重視成本效益，發展出**個案管理、臨床路徑、分層執行、參與管理**，見 [[nursing-budgeting-drg#drg]]。

| 方式 | 重點 |
|---|---|
| **個案管理**(case management) | **依疾病分類提供一套預期的照護處置**，使病人在**預期時間與給付範圍內**接受治療，可**縮短住院天數、節省醫療成本**；**個案管理者是資源協調者**；依 DRGs 與病人分類系統做問題解析，由**跨專業團隊**共同照護；提供**持續性、連貫性**的照護 |
| **臨床路徑** | 適用**預後可預期、標準化**的常見單純疾病，例如自然產、子宮肌瘤手術 |
| **分層執行** | 依護理人員的**技術與角色**分工，由護理人員提供病人完整的護理 |
| **參與管理** | 護理人員工作時能參與**不同層次的決策** |

- **個案管理的適用對象**：**高醫療費用**、**重複住院**、病情複雜、需跨團隊(如**換肝手術**術後)的病人；單純、住院天數固定的(自然產、子宮肌瘤手術)用臨床路徑即可。
- 個案管理**不是**專為醫師或專為護理師設計，是跨專業的；計畫要**定期檢討修正**。**個案管理者可由護理師、社工師、心理師等擔任**；社區精神照護常用個案管理者。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 個別性護理是功能性護理的優點 | 是**缺點** | 工作切割 |
| 全責護理人員對工作更專精、較能迅速完成 | 那是**功能性護理** | 以工作為導向 |
| 當班小組長決定照護計畫是全責護理 | **成組護理**；全責護理由**責任護理師**決定 | 計畫責任 |
| 當班護理師設計照護計畫是全責護理 | 當班(協同)護理師依主責護理師計畫執行 | 角色分工 |
| 個案護理貫穿整個住院期間 | 只負責**當班**；貫穿整個住院的是**全責護理** | 定義 |
| 全責護理無法提供出院後服務 | 強調連續性與出院準備 | 特性 |
| 人力不足時用全責護理 | **功能性護理** | 全責需人力多 |
| 資深人員少、新進多時用全責護理 | **成組護理** | 資深帶領 |
| 技術混合是不同職級護理師搭配 | **護理師與輔助人員(護佐、照服員)** | 定義 |
| 個案管理專為護理師設計、無須檢討 | **跨專業**，要定期檢討 | 定義 |
| 自然產產婦適合個案管理 | 適用**臨床路徑**；個案管理對象是高成本、複雜者 | 對象 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **功能性**＝工作為中心(專人給藥、換藥)，省人力、分工清楚，**缺整體性與個別性**；**成組**＝組長帶領團隊；**全責**＝住院到出院同一位負責，連續、整體、個別，成本高、人力多。
- **個案護理**＝當班負責病人所有護理；**綜合護理**＝成組小組＋全責精神；**技術混合**＝護理師＋護佐或照服員。
- 依人力選模式：**人力不足、新進多、大量傷患支援 → 功能性**；**資深少、新進多 → 成組**；**人力足、皆資深 → 全責**；**隔離病房 → 全責**。
- **個案管理**：預期照護、縮短住院天數、控制成本、資源協調者、**高成本、重複住院、複雜病人**；單純疾病用**臨床路徑**。
:::
