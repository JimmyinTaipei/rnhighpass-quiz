管理理論的題目全是**配對**：**哪一位學者、哪個時期、哪個觀念**，或是**情境對應哪個理論**。先背時期順序，再背每個理論的一句話。領導與激勵理論另見 [[leadership-theories]]、[[motivation-theories]]。

## 三個時期的比較 {#periods}

| 時期 | 年代 | 重點 | 代表 | 組織觀 |
|---|---|---|---|---|
| **古典(傳統)時期** | 約 1887–1930 | **結構、效率、權威、規章**；視人為「經濟人」，靠金錢誘因；封閉系統；強調**科學概念**(如時間動作研究) | Taylor、Fayol、Weber | 重工作 |
| **新古典(修正)時期** | 約 1931–1960 | **人性、人群關係、心理需求、非正式組織**；「社會人」；**行為科學學派**；重視**績效**，但用提升滿意度達成 | 霍桑實驗、Maslow、McGregor | 重人 |
| **現代(新近、新進發展)時期** | 1961 起 | **開放系統、權變、環境**；依情況的變化適度調整才能永續經營 | 系統理論、權變理論、Z 理論、L 理論 | 重系統與環境 |

- **傳統與修正理論的差異**：修正理論**受到人類行為思潮的影響**；傳統理論**不是不講究科學**(泰勒就強調科學方法)；兩者也**不是**帶動系統理論的原因，系統理論屬現代時期。
- **近代理論強調開放系統與權變**；**設計組織結構以發揮效能**是古典理論；**民主式參與**是新古典理論，不是古典。
- **管理科學學派(計量學派)**：用**數學與統計模型**處理決策，強調效益量化，如用電腦資訊系統與數字做決策。
- **舊題 114-1 的錯誤選項**：「Z 理論是行為科學學派的代表」(Z 理論屬新近發展時期)；「戴明是管理程序學派代表」(管理程序學派是 Fayol)。

## 古典時期的三個學派 {#classical}

| 學派 | 代表 | 重點 | 護理上的應用 |
|---|---|---|---|
| **科學管理** | **Taylor(泰勒)，科學管理之父** | 每個工作要素都發展**科學標準方法**取代經驗法則；**科學選用並訓練員工**；管理者與員工合作；分工與責任均等；**時間與動作研究**；表現好給較高報酬(**差別計件工資**、提案獎勵金)，但高估薪資、忽略社會滿足 | **護理技術標準化**；**專業分工**；視病人為機器、強調生理照顧；**標準化作業** |
| **管理程序** | **Fayol(費堯)，管理程序學之父** | 管理由**規劃、組織、命令、協調、控制**五成分構成；**十四項原則**：分工、權責相稱、紀律、**指揮統一**、目標一致、個人利益服從共同利益、合理待遇、集權、層級、秩序、公平、職位安定、進取、團體精神 | 對護理部組織架構與政策影響最大：政策、升遷、獎懲、休假輪班制度 |
| **層級結構(官僚)** | **Weber(韋伯)，古典組織學之父** | 理論基礎是**法定(合理合法)權力**；**層級體系**、**專業分工**、**依法行事**(規章)、**對事不對人(非個人化)**、公開考選、嚴格獎懲；傾向**集權**；**高度結構化**；可存在於各種規模的組織 | 護理法規、倫理、護理常規、入院通知、同意書、考核制度 |

- **官僚理論不是惡質的管理模式**，**不重視人性化**；它強調制度凌駕於人。
- 例：**推行護理工作標準化、參照時間與動作研究** → **科學管理**；**層級分明、每人一位直屬主管、權責對等** → 古典行政(Fayol／Weber)，**不是**科學管理；**依護理人力狀況彈性調整護理管理模式** → **權變**；**電腦化、數字會說話** → 管理科學。
- **主管給明確工作規則、嚴格訓練督考、提案越多獎金越多** → **古典時期**的觀點。

## 新古典(修正)時期 {#neoclassical}

| 理論 | 重點 |
|---|---|
| **霍桑實驗**(Mayo 梅歐) | 研究工作條件與績效的關係，發現**非正式團體**對員工工作態度有控制力；**組織是社會系統**；**人格尊重、以人為中心**；抱怨可減少不滿、提高士氣；被關注會改變行為(**霍桑效應**)。工作的**物質條件**影響不如社會心理因素 |
| **馬斯洛需求層級**(人本心理學之父) | 由低而高：生理、安全、愛與歸屬、自尊、自我實現；見 [[motivation-theories#maslow]] |
| **X、Y 理論**(McGregor) | 人性假設與管理方式，見下 |

**X 理論與 Y 理論**

| | X 理論 | Y 理論 |
|---|---|---|
| 人性觀 | 悲觀、**人性本惡**，厭惡工作、逃避責任、缺乏野心，**樂於被督促、嚮往安全感** | 樂觀、**人性本善**，**天生喜歡工作**、自動自發、**在合適情況下會尋求並接受責任**、人都有潛力、創造力 |
| 管理 | **嚴格管制、外在控制的評值、監督、懲罰警戒**，權威專制，功能性護理，護理部訂定各種規則 | **民主、參與式管理、授權、鼓勵多於懲罰、計畫方案有彈性、依個別差異激勵**、內在自我控制、安排具挑戰性的工作 |
| 例子 | 護理紀錄不完整次數最多的人要清潔置物櫃；遲到扣當月績效 | 護理長認為護理人員天性喜歡工作、願意學習，使用激勵方式引導 |

- 「人都需要指導」「人都是不成熟的」是 **X 理論**；「人性本善」「人都有工作需求」「參與式管理」是 **Y 理論**。
- 對**自動自發、有創意的員工**(Y 理論)，管理者最適當的是**依特質安排具挑戰性工作**。

**行為科學學派的代表**：馬斯洛需求層次理論、麥克葛羅格 X 與 Y 理論(不是 Adam Smith 的 L 理論，也不是 Morse 與 Lorsch 的權變理論)。**Mayo 發現非正式組織普遍存在，會影響正式組織的領導**；Maslow 的理論不是「只滿足高層次需求就不用管低層次」；Y 理論強調個人目標與組織目標的整合。

## 新進(現代)發展理論 {#modern}

| 理論 | 重點 | 護理例子 |
|---|---|---|
| **系統理論** | 組織是**開放系統**，不斷從環境取得資源、轉成輸出再回到環境，維持動態平衡；成分為**輸入、轉化(過程)、輸出、回饋**；組織各部門是次級系統；**輸出提高、輸入不變，生產力提高**(生產力＝輸出 ÷ 輸入) | 內科部、外科部、護理部是醫院的次級系統；**疾病史屬輸入**；在職教育屬轉化；病人**滿意度、疼痛減輕、避免合併症**屬輸出；排班、檢驗報告傳遞、護理時數與人力計算 |
| **權變理論**(**Fiedler**；另有 Morse 與 Lorsch) | 又稱**情境管理**；沒有一體適用的最佳管理方式，要依**內外部情境**調整；**調整組織內部結構時，必須同時考慮外在因素** | **護理人力的調配與支援**：緊急時各單位互相支援、人力不足時**聘用部分工時人員或照顧服務員** |
| **Z 理論**(**Ouchi 大內**，1981) | 結合日式與美式管理：**參與式(集體)決策**、**團體價值觀與文化**、**集體責任**、長期(終身)雇用、全面關懷、緩慢考評與升遷、**非高度專業化的歷程**；**不是快速升遷、不是高度專業化** | **全方位品質管理與品管圈**；病房會議討論後**組成小組做改善專案**；全員參與降低跌倒率 |
| **L 理論**(Adam Smith) | 主張人有自己的想法，工作交辦後憑自由意志運作得宜，**不需特別干預**；是**放任式** | 護理主管的任務只在傳遞訊息 |

- **Gillies 護理管理系統**：護理長以**在職教育**強化護理技能，是**轉化過程**。
- Z 理論的美式 A 型：個人責任、快速升遷、高度專業化；日式 J 型：集體責任、終身雇用；Z 型兼具參與式決策與集體責任。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 傳統管理理論不講究科學概念 | 泰勒強調**科學方法** | 時間動作研究 |
| 修正理論較不重視績效 | 一樣重視，用提升滿意度達成 | 行為科學 |
| 近代理論強調設計組織結構發揮效能 | 那是**古典**；近代是開放系統與權變 | 時期 |
| 古典理論強調民主式參與 | 是**新古典** | 時期 |
| 層級分明、權責對等是科學管理 | 屬**管理程序／官僚**學派 | Fayol／Weber |
| 官僚理論是惡質的管理模式 | 是理性、合法的權威模式 | 韋伯 |
| 官僚體系較少結構化 | **高度結構化** | 規章與層級 |
| 官僚模式重視人性化 | **非人性化**、對事不對人 | 特徵 |
| 霍桑研究的結論是物質條件影響極大 | **非正式團體**與社會心理因素影響大 | 實驗結論 |
| Z 理論強調快速升遷與高度專業化 | **緩慢升遷、非專業化歷程** | 日式特徵 |
| 疾病史屬於輸出 | 屬**輸入** | 系統理論 |
| 輸出不變、輸入提高可提升生產力 | **輸出提高、輸入不變** | 生產力＝輸出 ÷ 輸入 |
| L 理論是行為科學學派 | 屬新進發展理論 | 分類 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 時期：**古典(結構、效率)** → **新古典(人性、非正式組織)** → **現代(開放系統、權變)**。
- **Taylor**＝科學管理、標準化、時間動作、獎懲；**Fayol**＝管理程序、五功能、十四原則；**Weber**＝官僚、層級、法規、對事不對人。
- **霍桑實驗(Mayo)**＝非正式團體、人群關係；**Maslow**＝需求層級；**McGregor**＝X(監督控制)、Y(授權參與)。
- **系統**＝輸入、轉化、輸出、回饋，生產力＝輸出/輸入；**權變(Fiedler)**＝情境管理、人力調配支援；**Z(Ouchi)**＝集體決策、團體價值、集體責任；**L**＝放任。
:::
