組織題大多是「**給一個情境，判斷是哪種結構**」。先抓關鍵字：**依專業分部門＝功能式**、**同時有兩個主管＝矩陣式**、**層級少幅度大＝扁平式**、**顧問、專家只提供建議＝直線幕僚**。授權、賦權與護理照護模式會在後續頁面整理。

## 正式組織與非正式組織 {#formal-informal}

| 比較 | 正式組織 | 非正式組織 |
|---|---|---|
| 形成 | **依工作需要設計**的架構，明文規定權責 | 成員因**興趣、情感、價值觀或利害關係**自發結合，如一起旅遊、唱歌的同仁 |
| 領導 | 官方指派 | **沒有官方決策者**，領袖自然形成 |
| 特性 | 需**明文規定**組成 | 不需明文規定，但會對正式組織產生**影響力**(輿論、同儕壓力)，成員也會交流經驗、增加工作知能 |

管理者要**善用**非正式組織的優點(歸屬感、溝通)，引導它與正式組織目標一致。

## 組織結構類型 {#types}

| 類型 | 特徵 | 護理與醫院的例子 | 優缺點 |
|---|---|---|---|
| **功能式** | 把**相似專業或功能**的人集中在同一部門 | 院長之下設**內科部、外科部、營養部、護理部**；集結研究人才成立**育成中心** | 專業分工、資源共享；易有本位主義 |
| **直線式** | **單一指揮系統**，權力由上而下，命令統一 | 主任→督導→護理長→護理師 | 權責明確 |
| **直線幕僚式** | 直線主管有**指揮權**，**幕僚(顧問、專家)只有建議、諮詢與服務**，沒有直接命令權 | 護理部**延聘學者擔任顧問**協助指導護理研究 | 兼顧專業與指揮 |
| **矩陣式** | 功能部門(垂直)＋專案或產品(水平)，成員有**雙重指揮與隸屬** | **加護中心護理師**在人事、排班、考核屬護理部，在病人照顧政策受加護中心主任領導；護理長原本做護理部品管，同時參與醫品部的 RCA 專案；督導長同時參與品管中心 | 彈性高、跨部門合作；最大缺點是**違反單一指揮**，易有**角色衝突**、雙重領導 |
| **扁平式** | **層級少、管理幅度大**，較開放、**偏分權**，溝通快 | 把副主任、督導長與護理長職權合併，成為「主任─護理長─護理師」 | 適合**成員成熟度與自主性高**、規模較小或業務單純的單位；營運成本比高聳式**低**；較易留任人才 |
| **高聳式**(金字塔型) | **層級多、管理幅度小**，偏集權 | | 權責明確、作業標準化、較**不易反映基層意見**、溝通鏈長 |
| **科層式**(官僚式) | 高度分工、標準化規範、層級嚴密、集權 | 大型穩定的機構 | **最不容易**迅速反映同仁意見 |
| **簡單式** | 高度集權、低複雜度與低公式化 | **規模小、複雜度低的護理之家** | 彈性高，不適合大型機構 |
| **專案式** | 為特定目標組成的**臨時性**組織 | 跨專業專案 | |
| **委員會式** | 多人共同討論、**集體決策** | 品管、教育、人事、研究委員會 | 集思廣益；常耗時、責任不易歸屬 |
| 部門式(事業部制) | 一級單位**彼此獨立**，依產品、服務對象或地區劃分 | | |

**護理部常見委員會**：**教育委員會**(規劃在職教育、培訓專業知識與技能)、**品管委員會**(品質監測、指標改善)、**人事委員會**(任免、升遷、考核)、**研究委員會**(學術研究、專案審查)、護理標準委員會(制定護理標準)。在護理品管委員會下，**制定護理技術**屬**護理標準組**。

- 「受評單位在**一個部門領薪**、**另一個部門接受業務指揮**」就是**矩陣式**。
- 緊急狀況要講求時效，用**集權式**指揮較適合(見下節)。

## 管理(管轄、控制)幅度 {#span}

- **管理幅度**：一位主管能有效督導的**直屬部屬或單位數**，例如**護理督導長負責督導的單位數**。
- 幅度決定**層級數**與各層級**人員配置的數量**；幅度**大 → 層級少 → 扁平**，幅度**小 → 層級多 → 高聳**。
- 不是在看成員關係的複雜度(那不是幅度)，也不是在看標準化程度(那叫**規範化**)，或集權狀況(叫**集權化**)。

| 管理幅度可以**較大**的情況 | 管理幅度宜**較小**的情況 |
|---|---|
| 工作**例行、標準化**程度高 | 工作**重要**(失敗代價高)，要密切監督 |
| 外在環境**穩定** | 外在環境**複雜多變** |
| 主管**充分授權**、能力強 | 工作性質**變化大** |
| 部屬**經驗豐富、能力強** | 部屬能力有限、成熟度低 |

- **舊題 112-1**：題目「可依單位績效高低調整組織控制幅度」考選部公告的答案是(A)，其中(B)「工作人員能力有限，控制幅度不宜擴大」也符合一般教科書的原則，作答以**官方答案**為準，但原則本身要記。
- **扁平化的組織應增加授權**，因為主管無法兼顧所有事務。

## 組織設計原則 {#principles}

- **古典組織理論的四大要件**：**部門分工**、**命令傳達管道(指揮鏈)**、**管轄幅度**、**組織結構**。
- **單一指揮(指揮統一、單一隸屬)原則**：**每位成員只向一位主管負責**，有明確的工作職掌與呈報系統。違反的例子：**護理部主任未經督導長，直接請護理長負責專案**(越級)、教育與行政兩位副主任同時指揮一位督導、重複授權。
- 授權時符合統一指揮的做法：由上而下**逐級**授權，**公開**授權；教育副主任授權給甲督導及其所屬護理長辦理在職教育。
- 其他原則：**權責相稱**、專業分工、階層鏈、**保持彈性**(隨環境調整)、**維持平衡**(各部門權責與規模協調)。
- **護理主任告知教學督導培養臨床教師**(preceptor)，是**指揮路線**的原則。

## 集權與分權 {#centralization}

兩者由**授權程度**決定：授權程度極低、決定權集中在高層是**集權**；決定權下移到較低層是**分權**。

| 比較 | 集權 | 分權 |
|---|---|---|
| 優點 | **精簡組織、避免重複浪費**(人員與設施可精簡)；**決策效率化**、易管理；部門間**衝突較少**；指令統一，**緊急情況**適用 | 鼓勵並**培養人才**；各階層主管有**較大自主權**；決策者**接近問題現場**，解決省時有效率；員工覺得**自由、被尊重**，士氣與滿意度高；權力**相互制衡**；**降低人員流動率** |
| 缺點 | 基層缺乏彈性、反應慢、打擊士氣、決策負荷集中在高層 | 各單位看法不一，協調成本高；需注意權責劃分與控制 |
| 例子 | 醫院**緊急事件**採集權指揮(如醫院緊急應變的指揮系統)；財務、人事功能 | **單位護理長做預算計畫**；病人護理、醫療作業、物品預算 |

- **選擇集權或分權的考慮因素**：**規模**(大型組織配合分權的需要)、產品組合、市場分布、**功能性質**(病人護理、預算偏分權；財務、人事、緊急狀況偏集權)、**工作性質**(例行有規律者集權，無一定範圍者授權基層)、**人員性質**(教育程度高、專業獨立判斷者分權，如護理人員；護佐、工友可集權)、**外界環境**(受外部力量影響大則集權，如軍醫院)。
- 「**職權和職責的階層完整化**」是**分權**的優點，不是集權的；**金字塔型組織的職權由上往下遞減**(越高越大)。
- 「**增加人員流動率**」不是分權的優點。

## 組織文化 {#culture}

- **組織文化**：成員**共同體驗、共享**的**價值觀、信念、氣氛、創造力與行為規範**，使組織有別於其他組織的特質。
- 常見分法：精神層(價值觀、信念)、行為與制度層(氣氛、規範)、物質與符號層(標語、儀式)。
- **組織經費**屬財務資源，**不是**組織文化的內涵。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 依人員專業劃分部門是直線式 | **功能式** | 專業分工 |
| 病房護理長同時受護理部與專案主任指揮是幕僚式 | **矩陣式** | 雙重指揮 |
| 聘學者當顧問是矩陣式 | **直線幕僚式** | 幕僚只有建議權 |
| 扁平式組織營運成本較高 | 較**低** | 管理層級少 |
| 科層式最能反映同仁意見 | **最不易** | 層級多、集權 |
| 工作越重要，幅度應越大 | 幅度**越小** | 要密切監督 |
| 環境越複雜，幅度越大 | 幅度**越小** | 非例行事務多 |
| 充分授權，管轄幅度應越小 | 幅度**可越大** | 主管負擔減輕 |
| 集權的優點是職權職責階層完整化 | 那是**分權**的優點 | 比較 |
| 分權會增加人員流動率 | 通常**降低** | 自主與尊重 |
| 非正式組織需要明文規定、有官方領導者 | **自發形成**，無官方決策者 | 定義 |
| 組織文化包括組織經費 | 不包括 | 屬財務資源 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **功能式**：依專業、功能分部門(內科部、外科部、護理部)；**矩陣式**：**雙重指揮**，缺點是違反單一指揮；**直線幕僚**：顧問無指揮權；**扁平式**：層級少、幅度大、偏分權、成本低。
- **管理幅度**決定層級與配置；**工作越標準、環境越穩定、授權越多、部屬能力越強 → 幅度越大**；工作越重要或越複雜 → 越小。
- 古典組織四大要件：**部門分工、命令傳達管道、管轄幅度、組織結構**；**單一指揮**＝只向一位主管負責，越級指派違反。
- **集權**：精簡、效率、衝突少、**緊急情況**；**分權**：培養人才、自主、貼近現場、降低流動率；扁平化要**增加授權**。
- 非正式組織：自發形成、無官方領導者，**對正式組織有影響力**。
- 組織文化＝價值觀、氣氛、創造力、行為規範，不含經費。
:::
