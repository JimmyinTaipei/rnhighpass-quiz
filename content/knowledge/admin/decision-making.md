決策是**從發現問題到執行解決方案**的過程，每一項管理工作(規劃、組織、領導、控制)都含有決策。決策題要記的是**順序**、**模式的名稱與定義**，以及**判斷情境用哪一種**。

## 決策與問題解決的過程 {#process}

- **問題**：實際情況與預期情況之間的**差距**。
- **決策的標準順序**(題庫選項)：**界定問題 → 確立決策準則 → 列舉可行方案 → 分析方案利弊 → 執行方案**，最後**評估成效**。先有準則才能比較方案。
- **捷徑的版本**：發現問題(界定問題、找出原因) → 樹立目標 → **選擇解決方案**(最困難的步驟) → 決策制訂 → 執行 → **評值**。
- **Sullivan(2008)七步驟**：**確認問題** → 收集資料 → 分析資料 → 訂定方案 → 選擇方案 → 執行方案 → 評估結果。**第一步都是確認(界定)問題**。例：近一週管路滑脫人數增加，護理長第一步是**界定問題、找出原因**；而不是評估決策效能、找替代政策或計畫活動步驟。
- **策略階段**：決策者個人或組織**未來欲達到的目標或期望**。

**問題解決的原則**

| 原則 | 說明 |
|---|---|
| **先處理對組織利益影響最大的問題** | 再抽絲剝繭列出子問題 |
| 主管可把**部分**問題分配給部屬 | 讓部屬了解組織目標、增加自主；不是所有大小問題都分派，重大或策略性問題主管自己處理 |
| 大而複雜的問題宜**諮詢機構內外專家** | 不要為了怕影響聲譽而避免找專家 |
| 解大問題可**忽略某些細節**，求最佳途徑 | **沒有十全十美**的解決方法(滿意原則)；不必什麼小事都用嚴格的科學方法 |
| 要有足夠的空間與自主權 | 影響解決的品質 |

- **較好的解決方案**(Keeney，1994)：**符合組織目標**、**應用較少資源**、**確定性高**、**冒險性低**。
- 做決策的注意事項：權衡主要關係人的權益，**以決策倫理為基礎**；不是以個人價值觀引導，遇困難也不是馬上放棄，推行時**目標是方向**不能隨意調整，過程要維持控制與評估。
- **問題解決過程的正確做法**：團隊腦力激盪產生方案、**評估各方案優缺點**再選擇；解決時要回應同仁疑問；評值後即使達標也要回饋、必要時調整步驟，不是「達成目標就不用調整」。
- **問題解決方法**：**經驗談**(把過去單位發生的疏失列入新進人員訓練)、錯誤試驗法(代價高、護理少用)、科學實驗法(受倫理限制)。
- **層級**：**病人問題解決是護理長(第一線)層級的決策**；大量傷患應變、單位間人力調度、醫療糾紛處理是中高階管理者的範疇。
- **增進個人決策技能**：尋求合適的諮詢資源、用陌生的眼光看事情、學習掌握重要資訊；不是完全採用別人意見或複製自己過去的經驗。
- **問題的類型**：單純性問題(基層)、非結構性複雜問題(中階)、結構性複雜問題(高階，長遠目標，如在偏遠地區建立急診醫療網)。

## Vroom-Yetton 決策模式 {#vroom-yetton}

依「**誰提供意見、誰握有最後決定權**」分類(Vroom 與 Yetton，1973)：

| 型態 | 做法 | 例子 |
|---|---|---|
| **獨裁型 AI** | 主管用手邊資料**自己決定** | |
| **獨裁型 AII** | 主管向部屬取得所需資訊，**自己決定** | |
| **諮商型 CI** | 主管與有關部屬**個別商量**，取意見後**自己決定** | 病房集體院內感染，護理部主任與督導**個別討論**後，決定要求護理長提出改善方案 |
| **諮商型 CII** | 主管與**全體部屬共同商量**，取整體意見後**自己決定** | 護理長先提出**初步方針**，請同仁表示意見，再由護理長決策(參與式領導) |
| **團體型 GII** | 主管與全體部屬**共同討論、評估**，**最後達成一致** | 委員會、名義團體、德爾菲 |
| **授權型** | 主管把**決策的責任與權限**授予部屬，事先說明限制範圍 | |

- 判斷關鍵：**最後決定的是誰**。主管做最後決定＝獨裁或諮商；全體達成共識＝團體型。

## 決策的模式與策略 {#models}

**決策過程的四種應用模式**(依捷徑的定義)：

| 模式 | 重點 |
|---|---|
| **理性模式** | 決策者**完全理性**，了解所有方案與預期結果後選擇(追求最佳) |
| **政治模式** | 可考慮的方案與後果**有限**，要**與相關人員、團體協調**後決策，傾向參考過去作法、避免大變動 |
| **行為模式** | 依決策者的**喜好**決策(有限理性、追求滿意) |
| **規範模式** | 依**過去經驗**決策 |

- 例：護理部主任聽完報告後，指示「不要與去年差異太大，也不要太多不可預測」，並要求形式經過**大家互相協調同意**才完成 → **政治的決策理論**。

**決策策略**

| 策略 | 意義 |
|---|---|
| **樂觀性(最大極限)** | 預期**最好**的狀況發生，選擇能得最大利益的方案 |
| **最小極限(悲觀)** | 預料**不利後果**，在所有不利情況中選擇**危害最小**的方案 |
| **最少缺憾** | 在最好與最壞之間選較**中庸**的方式，最不具挑戰性 |
| **滿意性** | 在占優勢時足以應付**最低標準**即可 |
| 按兵不動 | 快速變動的危機或嚴重目標衝突時，靜觀其變 |
| 預先警戒 | 零和衝突，預測對方行動，求最大獲利或最小損失 |

**決策者的思考方式**：**邏輯思考**(推理判斷後下結論)、**直覺思考**(不受固定規則約束，直接反應)、**理性思考**(審慎思考)、**創意思考**(想像力、多元結論)。

## 直覺決策 {#intuition}

- 在**時間緊迫、資料不足、情況變化快或目標不清**時，主要靠直覺思考；例：值班護理長發現樓梯間冒煙有火花，緊急辨識問題、解除危機。
- **培養直覺**(Klein)：靠**充實的知識**與**豐富的經驗**，不是靠財富或溝通能力；直覺**不是超能力**，是經驗與準備的產物，可以**透過不斷練習**累積培養；新進人員也可以用情境模擬與經驗傳承。
- 臨床上直覺決策與理性決策互補：緊急情境用直覺，常規規劃與政策用理性。

## 決策陷阱：先入為主 {#traps}

防範**先入為主(錨定)**的做法：**不要在最先的想法裡打轉**、**開放心胸多方收集資料**、**請教專家時不先說出自己的想法**。錯誤做法：先徵詢別人而完全不自己思考、使用單一一致的模式探討問題。

## 團體決策技術與決策工具 {#tools}

| 工具 | 特色 | 類型 |
|---|---|---|
| **腦力激盪法** | 短時間內自由聯想、**暫不批評**、重量，發展新方案；意見可被修正整合 | **非量性**、團體決策 |
| **名義(記名式)團體法** | 成員**先各自獨立**提出想法，再公開討論、澄清，最後**投票或排序**選出方案；例：護理長用 LINE 群組徵詢意見、引導討論並排定最佳方案 | 非量性、團體決策 |
| **德爾菲(Delphi)法** | **匿名**、**多回合問卷**、**專家**意見逐步收斂；決策者不與成員面對面；時間有彈性、可省會議支出；適合情況不明、要找問題所在 | 非量性、團體決策 |
| **決策矩陣** | 把方案與影響因素排成矩陣，**設定權重與準則評分**，選**得分最高**者 | **量性** |
| **決策樹** | 以樹枝分叉計算各結果的**機率與期望值** | 量性 |
| 模擬法、排列法、作業研究 | 需數學模型與計算 | **量性** |

- 腦力激盪與德爾菲都屬**團體決策**，不是個人、諮商或獨裁決策。
- 決策矩陣**是量性方法**；只列優缺點的是優缺點分析，不是決策矩陣。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 為了找完美方案，有時間壓力也不輕易決策 | 求**滿意解** | 沒有十全十美 |
| 主管親自解決所有問題以縮短時間 | 適度**授權**、重大問題才親自處理 | 授權原則 |
| 避免外部專家以免影響聲譽 | 大而複雜問題**諮詢專家** | 問題解決原則 |
| 主管須注意所有小細節 | 抓**最大影響**的問題 | 優先順序 |
| 問題發生立刻單刀直入最大問題 | 先**界定問題、收集資料** | 流程 |
| 決策第一步是收集資料或訂定方案 | **確認(界定)問題** | 順序 |
| 先列舉方案，再訂決策準則 | **先確立準則** | 準則是比較依據 |
| 請同仁個別商量再自己決定是團體型 | **諮商 CI** | 最後仍主管決定 |
| 直覺是超能力、新進人員不宜培養 | 經驗累積，可練習培養 | Klein |
| 決策矩陣是非數量方法 | **量性**(加權評分) | 定義 |
| 德爾菲是面對面討論 | **匿名、多回合問卷** | 定義 |
| 決策陷阱要先徵詢別人，不要自己思考 | **先獨立思考**再請教 | 避免被引導 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 決策：**界定問題 → 確立準則 → 列方案 → 分析利弊 → 執行 → 評估**；第一步永遠是**界定問題**。
- 問題解決原則：優先處理**影響組織利益最大**的問題；大問題**諮詢專家**、可忽略細節；好方案**符合目標、較少資源、確定性高、冒險性低**。
- **Vroom-Yetton**：獨裁(AI、AII)、**諮商 CI(個別)、CII(團體)**、團體 GII、授權；看**誰做最後決定**。
- 模式：**理性**(最佳)、**政治**(協調、漸進)、行為(喜好)、規範(過去經驗)；策略：**最小極限＝危害最小**、樂觀性＝最大利益。
- **直覺決策**：緊急、資料不足；靠**知識＋經驗**，可練習培養。
- **腦力激盪、名義團體、德爾菲**＝非量性團體決策；**決策矩陣、決策樹**＝量性。
:::
