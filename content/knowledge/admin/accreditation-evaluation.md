評鑑題的重點很集中：**評鑑怎麼分類**、**實地訪查用什麼方法(PFM、追蹤查證)**、**護理部的某項工作屬於護理評鑑的哪個範疇**。品質指標與 Donabedian 見 [[quality-management-concepts]]。

## 重點摘要 {#summary}

- 評鑑由**中央主管機關**辦理(醫療法第 28 條)；醫院評鑑分**三類**(醫學中心、區域、地區)，教學醫院評鑑**二類**。
- 實地訪查用 **PFM(以病人為焦點的方法學)**：決定優先查證重點、案例追查、系統追查、交叉查證；追蹤病人的實際就醫歷程，不審核健保給付。
- **護理評鑑三方向**：適切的護理照護、舒適的醫療環境及照護、人力素質及品質促進(在職教育與技術稽核屬後者)。
- 115 年度基準：2 篇 15 章 124 條；重點條文為防火安全、**護病比**、感染管制。

### 國考常考點 {#exam-points}

- 評鑑**中央主管機關**辦理(醫療法第 28 條)；醫院評鑑**三類**(醫學中心、區域、地區)、教學醫院評鑑**二類**。
- **PFM**(追蹤方法學)：**決定優先查證重點、案例追查、系統追查、交叉查證**；追蹤病人的**實際就醫歷程**，**不審核健保給付**。
- 護理評鑑三方向：**適切的護理照護、舒適的醫療環境及照護、人力素質及品質促進**；在職教育與技術稽核＝**人力素質及品質促進**。
- 115 年度基準：**2 篇 15 章 124 條**；**重點條文**＝防火安全、**護病比**、感染管制；評量等級**符合／待改善**。

## 評鑑的法源與類別 {#types}

- **醫療法第 28 條**：**中央主管機關**應辦理**醫院評鑑**；直轄市、縣(市)主管機關對轄區內醫療機構業務，要定期督導考核。
- **評鑑的申請類別**(捷徑)：

| 類別 | 內容 |
|---|---|
| **醫院評鑑** | 含**醫學中心、區域醫院、地區醫院**三類 |
| **教學醫院評鑑** | 含**醫師及醫事人員類教學醫院**、**醫事人員類(非醫師)教學醫院**二類 |

- **結果**：舊制為**合格、不合格**兩種。**「醫院評鑑分 5 類、教學醫院評鑑分 3 類」是錯誤說法**。
- 評鑑的重要性：**提升護理及醫療品質**、幫助護理行政人員有組織有系統地規劃護理業務、讓護理人員更清楚臨床工作的重點與方向，對教學醫院而言也有助於**保障臨床實習品質**。
- 評鑑的目的是提升醫療照護品質與病人安全，**不是**了解病人量與健保支付點數，**審核申報健保給付也不是評鑑實地訪查的範疇**(那是健保署的權責)。
- **醫學中心全日平均護病比**標準是**9 人以下**(不是 10)，見 [[nurse-staffing-policy#two-ratios]]。

## 以病人為焦點的查證方式(PFM) {#pfm}

- **評鑑改革方向**：從**簡化、優化、日常化**著手；**優化**就是導入**以病人為焦點的查證方式**(patient focus method，PFM，即追蹤方法學 tracer)。目標是落實以**病人照護及安全**為主體的評鑑，並降低干擾醫院日常作業。
- **PFM 的要素**：**決定優先查證的重點**、**規劃路徑**、**PFM 案例追查**、**PFM 系統追查**、**交叉查證**。
- **追蹤的做法**：以實地訪查，**追蹤病人接受醫療服務的過程中實際經歷的照護、治療與服務**；關心專業人員如何與病人溝通，也看醫院行政系統的完整性。它**不是**關心醫院的營運盈虧。
- **應用題**：一位腦部手術後 7 天剛從加護病房轉出的病人，有尾骶骨壓傷、傷口感染、無人照顧等問題。評鑑委員會依個案問題追蹤相關單位：**加護病房預防壓傷的標準流程與執行狀況**、**供應中心器械消毒流程**(傷口感染)、**開刀房手術中的病人安全防護**；**病房的儀器保養計畫屬一般設備維護**，不是這位病人的追蹤重點。
- 評鑑委員到病房訪談，想了解單位有哪些**品質監測指標**、如何**落實監測機制**，並觀察紀錄內容與病人需求的關聯 → 評量的是**護理照護品質**。

## 115 年度醫院評鑑基準(區域醫院、地區醫院適用) {#criteria}

| 項目 | 內容 |
|---|---|
| 法源 | 衛福部依**醫療法第 28 條**辦理，訂有「評鑑及教學醫院評鑑作業程序」與「醫院評鑑基準及評量項目」 |
| 架構 | **2 篇、15 章、124 條**(篇、章、條、項、款、目六個層級) |
| 第 1 篇 經營管理 | 醫院經營策略、員工管理與支持制度、**人力資源管理**、病歷資訊與溝通管理、**安全的環境與設備**、病人導向之服務與管理、**風險與危機管理** |
| 第 2 篇 醫療照護 | 病人及家屬權責、**醫療照護品質與安全管理**、**醫療照護之執行與評估**、特殊照護服務、**用藥安全**、麻醉與手術、**感染管制**、檢驗病理與放射 |
| 評量等級 | **符合**(同條文所有符合評量項目均達成)、**待改善**(1 項以上未達成) |
| 條文分類 | **可免評條文**(依服務項目可選擇免評)、**必要條文**(基本的醫事人員人力標準)、**重點條文**(規範醫院**防火安全、護病比及感染管制**等標準)、**試評條文** |
| 與護理相關的條文例 | 第 2.3 章含「**適當的護病比**」(重點條文)、護理過程完整、護理照護計畫、交班與持續性照護 |

- 基準的評量等級現行是「符合、待改善」；捷徑與舊題所說的評鑑結果「合格、不合格」是評鑑成績核算的結論，兩者不要混淆。

## 護理評鑑(Nursing audit) {#nursing-audit}

- **護理評鑑**依三個方向規劃：**①適切的護理照護、②舒適的醫療環境及照護、③人力素質及品質促進**。重點在**行政作業、一般病房作業、特殊病房作業及病人安全業務**，目的是具體表現出護理四大範疇：**護理行政、護理教育、臨床照護與護理品管**。
- **範疇歸類的判斷**：護理部門實施**護理人員在職教育與護理技術稽核** → **人力素質及品質促進**；不是「適切的護理管理」(組織、排班、權責)、「舒適的醫療環境及照護」(設施、環境)、「完備的醫療體制」。
- **控制的技巧**：**親身觀察**(導入追蹤評量法)、**計畫評核術 PERT**(把目標分成次目標，建立活動網，估計時間)、運用品質管理工具。**控制的重點是會產生重大影響的活動**，例如病人安全業務中的給藥過程與檢體採集運送流程。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 醫院評鑑分 5 類，教學醫院評鑑分 3 類 | 醫院評鑑 **3 類**(醫學中心、區域、地區)，教學醫院評鑑 **2 類** | 申請類別 |
| 醫院評鑑著重病人量與健保支付點數 | 重視**品質與病人安全** | 評鑑目的 |
| 實地訪查要審核申報健保給付 | **不是**評鑑範疇 | 健保署權責 |
| 追蹤查證關心醫院的營運盈虧 | 關心**照護歷程、專業人員溝通與行政系統完整性** | PFM |
| 病房儀器保養計畫是某位病人的追蹤重點 | 應追蹤與該病人問題相關的流程 | 追蹤個案 |
| 在職教育與技術稽核屬適切的護理管理 | 屬**人力素質及品質促進** | 護理評鑑範疇 |
| 醫學中心全日平均護病比 ≦ 10 | **≦ 9** | 設置標準 |
| 評鑑由地方主管機關辦理 | **中央主管機關**辦理(地方負責督導考核) | 醫療法第 28 條 |
