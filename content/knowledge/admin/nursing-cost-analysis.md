護理成本題分成三塊：**成本怎麼分類**、**怎麼控制**、**會算**(人力成本與損益平衡點)。分類題的陷阱在「同一個項目可以從不同角度歸類」，計算題的陷阱在**單位換算**與**分母**。預算與 DRGs 見 [[nursing-budgeting-drg]]。

## 成本的概念 {#concept}

- **成本**：為達成某個目的所**犧牲的資源價值**，而且要能用**貨幣**衡量(例如耗用的材料、人工小時、其他服務量)。
- **醫院與製造業的差別**：醫院成本以**人事成本占最大比例**(不是材料或配銷)；醫療的**投入與產出關係不明確**，產品是「服務過程」，不容易標準化與衡量品質。
- 成本控制**不是為了賺更多錢**，更不能為了省錢犧牲照護品質與病人安全。

## 成本怎麼分類 {#classification}

同一筆費用可以依**不同角度**歸類，題目會問「屬於哪一類」，要先看題目用的是哪個角度。

| 分類角度 | 類別 | 判斷方式 | 護理例子 |
|---|---|---|---|
| **能否直接歸屬** | **直接成本** | 能**明確追溯**到特定病人、服務或單位 | **護理人員薪資**、**執行護理時耗用的衛材**、(臨床科的)醫師薪資 |
| | **間接成本** | 全院或多單位**共同負擔**、要**分攤** | **水電空調費**、**行政管理費**、**教育訓練費**、資訊室費用、行政作業用的電腦設備 |
| **隨服務量變動** | **固定成本** | 短期內**不隨服務量**增減 | **基本薪資**、**建築物折舊**、**設備儀器費用或折舊**、房屋租金 |
| | **變動成本** | 隨服務量**成正比**增減 | **醫療衛材與耗材**、藥品、病人伙食 |
| | 半變動(混合)成本 | 一部分固定、一部分隨量變動 | 兼職人員薪資、含基本費的水電費 |
| **單位主管能否控制** | **可控制成本** | 主管可由**日常決策**影響 | **加班費**、會議與人員訓練費、護理用品消耗 |
| | **不可控制成本** | 不在單位主管的決定範圍 | 機器折舊與故障、全院分攤的水電費 |
| **是否為日常營運** | **營運成本** | 與醫療服務及日常運作有關 | 人事、藥品、衛材、**管理費用**、水電維護 |
| | **非營運成本** | 與籌資、投資有關 | **利息支出**(財務費用)、投資損失 |
| **用途** | 人事、材料、設備、管理研發等成本 | | 護理部**人事成本最高** |

重點與易混處：

- 衛材：**直接**成本，也是**變動**成本；**水電費**：**間接**成本，在考題裡又被當作**不可控制**或**變動**(隨服務量)成本，看題目問什麼角度。
- **教育訓練費**：對護理單位是**間接成本**(題庫 109-1、111-2 的答案)，同時又屬**可控制成本**。
- **護理人員薪資**：對單位是**直接成本**，也是**固定成本**，對護理長通常**不可控制**(由全院薪資制度決定)；**加班費**才是護理長可控制的。**不要把「人員薪資」當變動成本**。
- **汰舊換新的設備**屬**資本支出**，列為**間接**成本。
- 門診量、手術量是**服務量**，不是成本項目。
- 侵入性檢查與治療是單位的**收入**項目，不是成本。

## 護理成本控制 {#cost-control}

**程序**：訂定**標準與預算** → **執行** → 衡量**實際績效** → **比較**出差異 → **糾正或修正**(糾正是糾正未來行動，對事；修正是修訂計畫；對人則進入績效評核)。預算本身就是很好的控制工具。

**成本分析的基本條件**：**健全的組織結構**、**適當的會計制度**、**正確的統計資料**，以及**主管階層的配合**。題庫把「基層員工的配合」當作**控制與執行**的關鍵，而不是做成本**分析**的條件(110-2)。

**適當的做法**

| 做法 | 理由 |
|---|---|
| **簡化工作流程**、作業改善 | 縮短流程、減少延誤與人力耗用 |
| **護理作業資訊化**(如電子護理紀錄) | 減少文書時間與謄寫錯誤 |
| 節約**水電與空調** | 基本營運節流 |
| 衛材**適量庫存**、**精準管理**，**零存貨(JIT)**也算合理 | 避免資金積壓、過期壞損 |
| **正確計價**、防止**漏帳** | 確保應收費用不流失 |
| **彈性調動人力**支援其他單位 | 提高人力使用效率 |
| **計算各項護理活動所需人力** | 讓人力配置有依據 |
| 掌握每月**護病比**、衛材領用量 | 管理人力與耗用 |
| 縮短**不必要的住院天數** | 節省醫療資源，也降低院內感染風險 |
| **ABC 分析(80/20)**：先處理影響最大的少數項目 | 資源有限，抓重點 |
| 開拓**護理收費**的新項目(護理成本分析結果支持) | 傳統護理費併在病房費中，看不出資源差異 |

**不適當的做法**(最常當錯誤選項)：

| 錯誤做法 | 為什麼不行 |
|---|---|
| **使用已報廢的儀器** | 危害病人安全、造成糾紛 |
| **減少護理人員數** | 傷害品質與安全，離職率上升，隱性成本更高 |
| **增加衛材庫存量**、多領衛材存放單位 | 資金積壓、過期浪費 |
| **把所有護理業務委外承包** | 只有不產生附加價值、累積性的業務才適合外包；核心照護不能 |
| **為了占床率讓病人多住幾天** | 浪費資源、增加感染風險 |
| 只有護理長負責成本管控 | 成本管控要**全員參與** |
| **預算刻意超估**以備不時之需 | 預算講求合理與真實，不可浮報 |

**成本效益分析**：當成本金額已知、但要比較的標準金額難以衡量時，用它把各活動帶來的利益表達出來，輔助管理者判斷；做起來需要健全的組織、會計制度與統計資料。

## 護理人力成本計算 {#labor-cost}

核心就是先求**單位時間的人力成本**，再乘以**活動所用時間**。**先統一單位**(小時或分鐘)。

| 要算什麼 | 公式 |
|---|---|
| **每小時人力成本** | **月薪(或每月人力成本) ÷ 每月工作小時數** |
| **某項活動的人力成本** | **每小時成本 × 活動時間(小時)**；分鐘要先換算，例如 40 分鐘＝40/60 小時 |
| **每日人力成本** | **年薪 ÷ 全年實際工作天數**；實際工作天數＝365 − 所有休假日(週休、公休、國定假日、在職教育假、事病假) |
| 病人一天的護理人力成本 | **各班護理時數合計(換成分鐘) × 每分鐘人力成本** |

**例題**

1. 月薪 45,000 元、月工作 180 小時，寫護理紀錄 90 分鐘：時薪＝45,000 ÷ 180＝250 元，成本＝250 × 1.5＝**375 元**。
2. 每月人力成本 60,000 元、月工作 150 小時，更換胸腔引流瓶 40 分鐘：時薪＝400 元，成本＝400 × 40/60≈**267 元**。
3. 年薪 80 萬元，休假合計 52＋52＋14＋9＋3＋5＝135 天，實際工作天數＝365−135＝230 天，每日人力成本＝800,000 ÷ 230≈**3,478 元**。
4. 某病人白班 2 小時 30 分、小夜 1 小時、大夜 30 分，每分鐘成本 5 元：(150＋60＋30)×5＝**1,200 元**。

## 損益平衡點(BEP) {#bep}

- **定義**：**總收入＝總成本**，**無盈餘也無損失**的狀態；**收入高於損益平衡點才有盈餘**，低於就虧損。它不是「收入比支出多 1 萬」，分母也不是總成本。
- **邊際貢獻**＝單價 − 單位變動成本，意思是每多提供一單位服務，能拿來回收**固定成本**的金額。

| 要求的值 | 公式 |
|---|---|
| **損益平衡的服務量(件數、人數)** | **固定成本 ÷ (單價 − 單位變動成本)**＝固定成本 ÷ 單位邊際貢獻 |
| **損益平衡的營業額** | **固定成本 ÷ 邊際貢獻率**；邊際貢獻率＝(收入 − 變動成本) ÷ 收入 |
| **達到目標利潤的服務量** | **(固定成本 ＋ 目標利潤) ÷ (單價 − 單位變動成本)** |
| 還本年數(購買設備) | **設備成本 ÷ 每年淨收益**；每年淨收益＝(收費 − 單次成本) × 每年使用次數 |

**例題**

1. 年收入 1,000 萬、變動成本 600 萬、固定成本 400 萬：邊際貢獻率＝(1,000−600)÷1,000＝40%，BEP 營業額＝400 ÷ 0.4＝**1,000 萬元**(此時剛好不賺不賠)。
2. 固定成本 50,000 元、單價 250、單位變動成本 150：BEP＝50,000 ÷ 100＝**500 件**；若要賺 100,000 元，件數＝(50,000＋100,000) ÷ 100＝**1,500 件**。
3. 住宿機構每位住民月收費 32,000 元、毛利率 60%，每月固定支出 70 萬：單位貢獻＝32,000×0.6＝19,200 元，需要 700,000 ÷ 19,200≈36.46，**人數要無條件進位，所以 37 人**。
4. 復健機器 54 萬元，每月 500 人次，每次成本 20 元、健保給付 50 元：還本＝540,000 ÷ ((50−20)×500×12)＝**3 年**。

- **損益表**說明某特定期間的**盈虧金額**，是了解經營成果的依據。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 人員薪資是變動成本 | **固定**成本 | 不隨短期服務量變動 |
| 水電費是護理長可控制成本 | 屬**不可控**、**間接**成本 | 全院分攤 |
| 教育訓練費屬直接成本 | **間接**成本(同時可控制) | 無法歸屬單一病人 |
| 醫療衛材是固定成本 | **變動**成本 | 隨病人數成正比 |
| 利息支出是營運成本 | **非營運**成本 | 籌資產生 |
| 減少人力、增加衛材庫存、延長住院可以控制成本 | 都會傷害品質或增加浪費 | 成本控制以病人安全為前提 |
| 預算要超估以備不時之需 | **合理、真實**編列 | 避免資源誤置 |
| 損益平衡點是固定成本÷總成本 | 固定成本 ÷ **(單價−單位變動成本)** | 公式 |
| 收入大於損益平衡點表示虧損 | **有盈餘** | 定義 |
| BEP 人數算到 36.46 就選 36 | **無條件進位到 37** | 人數不可分割，且不能虧損 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **直接成本**：護理人員薪資、護理耗用衛材；**間接成本**：水電、行政管理、教育訓練、行政設備。
- **固定成本**：薪資、折舊、租金、儀器設備；**變動成本**：衛材、藥品。**加班費**是護理長可控制成本。
- 成本控制**以病人安全與品質為前提**：資訊化、簡化流程、適量庫存、調動人力是對的；減人、囤積、用報廢儀器、全部外包、超估預算是錯的。
- 人力成本＝**單位時間成本 × 時間**，**先換算單位**；每日人力成本的分母是**實際工作天數**。
- BEP 件數＝**固定成本 ÷ (單價−單位變動成本)**；BEP 營業額＝固定成本 ÷ 邊際貢獻率；人數**無條件進位**。
:::
