這一頁是護理行政的**起點**：行政與管理的差別、管理過程有哪些步驟、**一件事屬於規劃、組織、領導還是控制**，以及護理專業形象與我國衛生行政體系。理論演進見 [[management-theories]]；規劃見 [[planning-strategy]]。

## 行政與管理 {#concept}

| 比較 | 行政 | 管理 |
|---|---|---|
| 本質 | 有**決策性**、有創意的方法與知識，步驟經過有系統的分析研究 | 是一種**實際的行動**、一種程序 |
| 範圍 | **範圍廣、層級高**，通盤籌劃 | 範圍較小、層級較低 |

- **護理行政**：如何辦好護理業務並領導護理工作人員的方法與知識，對護理組織內的**人、財、事、物**做科學、系統的分析研究，以達到護理應有的品質。**Douglass(道格拉斯)**：護理行政是周詳完整的管理學識，包括**目標的設立、政策與方案的擬訂、護理準則的制訂、權力與影響力的應用**。
- **管理**：「在合適的時候做合適的事」，是引導一群人朝向組織目標的過程。
- **病室管理**：管理病室內有關的人與物的行政業務，組成要素包括護理長、病人、護理工作人員、與病室行政有關的人與物，及環境因素。

## 管理功能與管理過程 {#process}

**Gulick(顧力克)的 POSDCoRB**

| 字母 | 意義 |
|---|---|
| **P** | **Planning** 規劃 |
| **O** | **Organizing** 組織 |
| **S** | **Staffing** 人員管理(用人) |
| **D** | **Directing** 指揮與監督 |
| **Co** | **Coordinating** 協調聯繫 |
| **R** | **Reporting** 報告 |
| **B** | **Budgeting** 預算 |

- 「R」是 Reporting，不是 Report 或其他；P 不是 Process、O 不是 Output、D 不是 Development。

**Gillies(季麗絲)的護理管理過程**：**資料收集 → 規劃 → 組織 → 人員管理 → 領導 → 控制**。她用**系統理論**說明：

| 系統成分 | 內容 |
|---|---|
| **輸入** | 資料、人員、機器、物料、病人、病史 |
| **轉化(過程)** | 規劃、組織、人員管理(招募與甄選、**績效考核**)、領導、控制；**在職教育**、護理評估與措施 |
| **輸出** | 病人照顧、品質、**病人滿意度**、疼痛減輕、避免合併症、人員成長與研究 |
| **回饋** | 結果與環境的反應，用來控制與評價 |

**管理過程的分類判斷**(題庫常考)

| 工作內容 | 屬於 |
|---|---|
| 設定目標、擬定政策、制定標準、**編列預算**、作成決策 | **規劃** |
| 建立組織結構、劃分權責、**訂定工作說明書與職責** | **組織** |
| 招募、甄選、排班、考核人員 | 人員管理 |
| **溝通、激勵**、應用領導與影響力 | **領導** |
| 設定標準、衡量績效、修正偏差；**降低離職率**、品質監測 | **控制** |

- **Douglass 的管理過程題**：包括**擬定政策與方案**、**建立護理標準**、**應用領導與影響力**；「確認基層人員需求」和「進行現況分析」不是核心範疇。
- **護理行政管理的趨勢**：文書電腦化、資訊傳遞迅速、人員專業化、**管理人性化**、經營企業化與效益合理化、研究多元化、決定科學化、**工作人員成組化**；**不是**考評專制化或文書人工化。
- **護理理念的演進**(Bevis 四階段)：苦行僧主義 → 浪漫主義 → 實用主義 → 存在主義(尊重個人、整體護理)。
- **我國醫療保健環境的特色**：就醫便利、醫療費用相對低廉、全民健保掌握醫院大部分經濟來源。

## 護理長的角色 {#roles}

護理長的角色功能有 Mintzberg 的**人際、資訊、決策**三類十種角色，以及 Quinn 的**競合價值架構**(指導者、促進者、生產者、創新者…)。例：護理長調配單位人力、物力、時間與經費是**資源分配者**；規劃病房活動、指派人員並有效授權是**指導者**。判斷表見 [[leadership-power-styles#roles]]。

## 護理專業形象 {#image}

建立與維護護理專業形象的做法，要分清楚是**哪一種作為**：

| 作為 | 例子 |
|---|---|
| **行銷護理專業形象** | 利用護師節**邀請總統或衛福部長出席**、廣邀媒體報導 |
| **更正被扭曲的專業形象** | 檳榔西施穿護理師制服的新聞，護理界發表**聲明**呼籲勿穿 |
| **鼓勵進修、培養專業能力** | 每 6 年繼續教育才能換照；護理專業進修 |
| 提升專業文化素養 | 倫理與人文涵養 |

- **展現專業價值**：以**實證**說明護理專業意見，協助醫療團隊做正確判斷；不是靠名片列學位頭銜、要求其他單位配合，或人力不足仍配合開病房。
- **對形象不良的行為**：將病人臉部傷口照片放上個人臉書。倫理與隱私見 [[nursing-ethics-principles]]。
- 衛福部**護理改革中長程計畫**的策略：製作專業形象文宣、收集護理感人故事、要求媒體劇情**符合護理專業形象**、公開**導正有違形象的報導**、辦理護理公益活動。

## 我國衛生行政組織 {#health-admin}

- **衛生福利部**：我國**最高衛生行政機關**(2013 年由行政院衛生署升格改制)，掌理全國衛生行政與醫療保險規劃，對地方衛生機構負業務指導、監督與協調。**國民健康署**是衛福部所屬機關，不是最高機關；**勞動部**主管勞動條件與職業安全衛生。
- **直轄市、縣(市)衛生局**執行地方衛生行政；直轄市各區設**衛生所**，金馬設衛生院。
- **醫院評鑑**由**中央主管機關**辦理(醫療法第 28 條)，見 [[accreditation-evaluation]]。
- **醫院組織**一般採正式、階層式的官僚化結構，有業務部門化、行政管理階層化、單一主管、職權劃分、分工合作五項功能；護理部可分**主任、副主任、督導、護理長、副護理長**五級；護理部目標包括**服務、教學、研究**，最大目標是服務病人。結構型態見 [[organization-structure]]。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| POSDCoRB 的 P 是 Process、O 是 Output | **Planning、Organizing** | 縮寫 |
| 降低離職率屬於領導 | 屬於**控制** | 指標監測與矯正 |
| 訂定工作說明書屬於規劃 | 屬於**組織** | 權責劃分 |
| 編列預算屬於控制 | 屬於**規劃**(也是事前控制) | Gillies 規劃內容 |
| 在職教育是輸入或輸出 | **轉化過程** | 把人力資源轉成能力 |
| 病人滿意度是過程 | **輸出** | 結果 |
| 邀請首長出席護師節是更正被扭曲的形象 | **行銷護理專業形象** | 主動宣傳 |
| 護理界發表聲明呼籲勿穿制服是行銷 | **更正被扭曲的形象** | 針對扭曲 |
| 國民健康署是最高衛生行政機關 | **衛生福利部** | 國健署是所屬機關 |
| 行政管理趨勢是考評專制化、文書人工化 | **人性化、資訊化** | 趨勢 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- **POSDCoRB**：Planning、Organizing、Staffing、Directing、Coordinating、**Reporting**、Budgeting。
- Gillies：資料收集、規劃、組織、人員管理、領導、控制；系統模式**輸入 → 轉化 → 輸出 → 回饋**。
- 規劃(目標、政策、標準、預算、決策)；組織(結構、工作說明書)；領導(溝通、激勵)；**控制(離職率、績效、品質)**。
- 形象：**行銷** vs **更正扭曲** vs **鼓勵進修**；以**實證**展現專業價值；病人影像不上社群。
- 最高衛生行政機關＝**衛生福利部**；衛生局＝地方；衛生所＝區。
:::
