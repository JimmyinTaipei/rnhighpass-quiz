人力資源管理(HRM)是把護理人員當作**組織最重要的資源**，用有策略、前瞻的方式規劃、配置、培育與留住。本頁先講概念，再依流程講**招募甄選**、**工作分析與說明書**、**工作設計**。人力需求怎麼算、排班與護病比見 [[nurse-staffing-policy]]。

## 重點摘要 {#summary}

- HRM 的核心是**選、用、育、留**；視員工為資產，強調參與。
- **招募**是吸引，**甄選**是選出最能勝任者；工作分析是第一步，說明書談職責職權，規範談資格。
- 工作設計：**擴大化**(水平增量)、**豐富化**(垂直、自主)、**輪調**、**再設計**。
- 專科護理師**不能獨立開立醫療處方**。

### 國考常考點 {#exam-points}

- HRM：**選、用、育、留**；友善安全的工作環境與福利屬**留才**。HRM 視員工為**資產**、強調**參與**。
- **招募**＝吸引，**甄選**＝選出最能勝任者；內部招募(省錢、士氣、熟悉)，外部招募(來源多樣)。
- 流程：**確認職缺** → 市場供需 → 計畫 → 管道分析 → 招募 → 效益評估。
- **回顧式面談**談過去經驗，**前瞻式**談假設情境。
- 工作分析是第一步；**說明書**談職責職權，**規範**談資格；**工作評價**決定相對價值。**工作分級法**＝排列順序。
- 工作設計：**擴大化(水平增量)**、**豐富化(垂直、自主)**、**輪調(職稱不變)**、**再設計(重新定義)**。
- 說明書不寫**婚姻、家庭背景、經濟能力**。
- 專科護理師**不能獨立開立醫療處方**。

## 人力資源管理的概念 {#concepts}

- **人事管理**(傳統)重視任用、安排、調配、訓練；**1980 年代後**興起的**人力資源管理**把「人」視為**資產**，主動、有策略地做整合規劃。
- HRM 的對象是組織內**所有可支配的員工**，過程包括**人力評估、配置、招募、甄選、培育、核心能力訓練、人員發展與生涯規劃**；依據是組織的**目標與結構、任務與規模**，也就是**先有任務規模，才決定人力**，不是用現有人力決定任務規模。
- **四大功能**(選、用、育、留)：

| 功能 | 內容 |
|---|---|
| **選才** | 招募、甄選、聘用 |
| **用才** | 適才適所的配置、授權、績效考核 |
| **育才** | 職前訓練、在職教育、臨床進階 |
| **留才** | 薪資福利、**友善與安全的工作環境**、職場保護、員工協助 |

| 比較 | 人事管理 | 人力資源管理 |
|---|---|---|
| 員工的定位 | 偏向成本與生產工具 | **資產**，但仍需投入招募、培訓與薪酬預算(**不是「沒有成本問題」**) |
| 勞資關係 | 從屬、控制 | **夥伴**、平等和諧 |
| 管理方式 | 透過績效考核鞭策、被動遵循法規 | 強調**人力開發**與**員工主動參與**組織經營 |

- **護理人力資源管理的目標**：建立符合法規要求的制度、**提高護理生產力**、**提升工作與生活品質**。**培訓與考核護生**屬護理教育，**經營目標**屬策略管理，都不是 HRM 的目標或核心重點；**績效考核、教育訓練、薪資制度**是 HRM 的核心。
- **行為規範的設計原則**：**合理合法、普遍適用、具體簡潔、一致**；**不能給「個別彈性」**(會造成雙重標準)。

## 招募與甄選 {#recruitment}

| 名詞 | 意義 |
|---|---|
| **招募**(Recruitment) | **吸引**符合條件的人來應徵 |
| **甄選**(Selection) | 從合格的應徵者中**選出最能勝任者**(履歷、筆試、性向測驗、面試等) |
| 聘用 | 決定錄用後辦理進用與簽約 |

**招募流程**(依考題與課本整理)：

1. **確認職缺需求**(評估缺額與需求人數；招募計畫的**第一步**)。
2. **了解市場人力供需**，**掌握護理部人力需求並做供需分析**。
3. **擬定招募計畫**(方向、對象、選人標準)。
4. **分析各種招募管道的特色與效益**。
5. **實際招募**。
6. **招募效益評估**(活動結束後短期內做，不是半年後)。

- 招募方向、管道與效益指標由**護理部主管與人力資源室共同**討論決定；護理很專業，不能只靠人資管理師。
- 招募前先建立人事資料檔案、擬定計畫與選人標準；選人除了知識技能，也要看**理念與價值觀是否與醫院契合**。

| 招募方式 | 優點 | 缺點 |
|---|---|---|
| **內部招募** | **節省經費**(廣告費)、**激勵士氣**、**熟悉背景與能力** | 容易引起組織內的競爭或鬥爭 |
| **外部招募** | **來源多樣**、帶來**新觀點與新刺激** | **成本高**、職前訓練時間較長 |

**甄選面談的類型**

| 類型 | 做法 |
|---|---|
| **回顧式面談**(行為描述面談) | 請應徵者談**過去**的具體經驗(例如「實習中印象最深刻的照護經驗」)，用過去行為預測未來表現 |
| **前瞻式面談**(情境式面談) | 設定**未來假設情境**，問「如果遇到會怎麼處理」 |
| 自傳式面談 | 談個人成長背景、學歷、經歷 |

- **法律界線**：依就業服務法第 5 條，雇主不得以種族、性別、年齡、**婚姻**、容貌、身心障礙等理由**歧視**，也不得要求提供**非就業所需的隱私資料**。所以**婚姻狀況、家庭背景、經濟能力**不可以放進工作說明書。

## 工作分析、工作說明書與工作評價 {#job-analysis}

**順序：工作分析 → 工作說明書與工作規範 → 工作評價。**

| 項目 | 內容 |
|---|---|
| **工作分析** | 明確了解工作的特質(任務、責任、內容)與條件(知識、技能、個人特徵)；是工作評價的**第一步** |
| **工作分析的方法** | **問卷法**(結構式問卷)、**查檢表法**與**工作抽樣法**(在特定時段實地查核)、**工作日誌法**(員工逐筆記載每日工作)，也可用觀察與訪談 |
| **工作說明書**(Job description) | 描述特定工作的**責任、職權範圍**與擔任該工作的必備條件；做新進員工的工作指引與績效考核依據。內容含**工作識別**(職稱)、**工作摘要**(目的、職責)、**工作資格**、**工作環境與時間**(例如**須輪值晚夜班**) |
| **工作規範**(Job specification) | **任職資格**：學歷(護理學歷)、**護理師或護士證照**、專長訓練、知識技能 |
| **工作評價**(Job evaluation) | 有系統評價各職務的性質，決定各職務的**相對價值**，作為**薪資結構**、**工作簡化**、人員**調派**與考核標準的依據(目的**不是為了提高薪資**) |

**工作評價的方法**

| 方法 | 類型 | 特色 |
|---|---|---|
| **工作分級法**(排列法 job ranking) | 質性 | 把職務依階層或複雜度**直接排列順序**，例如主任→副主任→督導→護理長→副護理長→護理師；簡單省時，但只能顯示順序，**無法衡量價值** |
| **工作分類法**(job classification) | 質性 | 依資格與性質給予職務**分級** |
| **因素比較法**(factor comparison) | 量性 | 依工作因素(身體與心理需求、知識技能、責任、工作情況)比較，同時分析職務層級與薪資 |
| **點數系統法**(point system) | 量性 | 把每個因素分級並給**點數與權數**，廣泛使用 |

- **工作說明書不能用來懲戒員工**；它是規範職責、招募基準與績效考核的依據。
- 工作項目與說明越完整，招募與選才越能找到符合需求的員工。

## 工作設計 {#job-design}

| 方式 | 方向 | 意義 |
|---|---|---|
| **工作擴大化** | **水平**(同層級) | 增加同層級工作的**範疇與數量**，減少單調 |
| **工作豐富化** | **垂直** | 給**更多自主權、責任與決策參與** |
| **工作輪調** | **水平調動**，**職稱不變** | 定期改變職務或單位，擴大視野、增加經驗，降低單調與倦怠 |
| **工作再設計** | 整體 | 利用**工作分析**，**重新定義**工作或職務的職責與職權、工作內容與方法 |

- 工作擴大化是為了減少單調，**不是為了節省人事成本**；員工仍然需要新進訓練與在職教育，不是「從做中學」就夠。

## 專科護理師的角色 {#nurse-practitioner}

- 專科護理師是**進階護理角色**，包括**病人管理**、**參與學術研究**、**制定護理標準**等；**不能獨立開立醫療處方**。
- 依《專科護理師於醫師監督下執行醫療業務辦法》，可做的醫療業務包括：**預立醫療流程**相關醫囑**表單的開立**、檢驗檢查的初步綜合判斷、醫療諮詢、製作病歷與手術麻醉紀錄、協助精神醫療治療、石膏固定及拆除，以及附表所列的**侵入性處置**；**監督醫師要在 24 小時內**核對並簽署預立醫療流程的執行。
- 法律面見 [[nursing-personnel-act#nurse-practitioner]]。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 以現有人力決定組織的任務規模 | **先有任務規模，再配置人力** | HRM 的依據 |
| 人力資源管理的員工沒有成本問題 | 資源也要**投入預算** | 招募、培訓、薪酬 |
| 培訓與考核護生屬護理 HRM 目標 | 屬**護理教育** | 護生不是正式聘僱 |
| 行為規範要有個別彈性 | **一致、普遍適用** | 公平 |
| 外部招募的優點是節省經費、激勵士氣 | 這些是**內部招募**的優點；外部是**來源多樣** | 比較 |
| 招募效益評估隔半年做 | **活動後短期內** | 及時 |
| 回顧式面談問假設情境 | 問**過去**經驗；假設情境是**前瞻式** | 定義 |
| 工作說明書寫婚姻狀況與經濟能力 | **不可以**，涉及就業歧視與隱私 | 就業服務法第 5 條 |
| 工作評價是為了提高薪資 | 是決定**相對價值**，作薪資、調派的依據 | 目的 |
| 主任→副主任→督導的排列是點數法 | **工作分級(排列)法** | 只排順序 |
| 輪調是工作擴大化 | **水平調動、職稱不變**才是輪調 | 定義 |
| 專科護理師可以獨立開處方 | 在**醫師監督**下，依**預立醫療流程**執行 | 辦法第 6 條 |
