倫理題的做法：**先找關鍵字，再對應原則**。「尊重決定、知情同意」是**自主**；「避免風險、危害」是**不傷害**；「最大利益、促進福祉」是**行善**；「資源分配、弱勢、公平對待」是**公平正義**；「資料不外洩」是**保密與隱私**。預立醫療決定、安寧緩和與腦死判定等法規，已整理在 [[end-of-life-care#law]] 與 [[end-of-life-care#brain-death]]，本頁不重複。病歷與知情同意見 [[medical-records-consent]]。

## 倫理四大原則 {#four-principles}

| 原則 | 意義 | 關鍵字 | 情境判斷 |
|---|---|---|---|
| **自主**(autonomy) | 尊重有能力者的**自我決定權**，在**充分知情**下選擇、也可拒絕 | 知情同意、尊重選擇 | **意識清楚的腎衰竭病人因路程太遠堅持出院**，尊重他的決定屬自主；**家屬在病人具決策能力時代為拒絕截肢**，違反自主；人體試驗事前說明並取得書面同意符合自主 |
| **不傷害**(non-maleficence) | 避免或預防對病人造成**不必要的傷害** | 風險、危害 | **昏迷病人家屬要灌自備的草藥**，護理師拒絕灌食，是不傷害；尊重末期病人**拒絕無效的維生治療**，不違反不傷害 |
| **行善**(beneficence，施益) | **積極促進**病人的福祉與最大利益 | 最大利益、福祉 | 化療前醫師**考量病人治療的最大利益**；**向 40 歲婦女說明子宮頸抹片的重要性** |
| **公平正義**(justice) | **公平**對待病人、**合理分配**資源，照顧弱勢 | 資源分配、公平 | 提供病人**居家附近透析室的完整訊息**，使其公平取得醫療資源；社區中某**弱勢族群嬰兒死亡率特別高**，應**優先處理** |

**倫理規則**(行為規範)：**誠實**(據實告知、不隱瞞)、**忠誠**(守信)、**尊嚴**、**保密**(不洩漏病人資料)、**隱私**。

### 保密與其例外 {#confidentiality}

- 保密是倫理與法律的基本要求。
- **例外**：法律強制通報時**不違反**保密。例如**法定傳染病**(如愛滋病)依傳染病防治法向衛生主管機關通報、**兒少保護**與家暴通報、避免病人或第三人**重大危害**。所以「醫師把愛滋病病人資料向衛生局報告違反保密」是**錯誤**說法。通報的實務見 [[infection-control-administration]]。
- 在社群媒體討論臨床案例要**去識別化**。**把病人的臉部傷口照片放上個人臉書**，違反隱私，也損害專業形象。

### 公平正義與倫理觀 {#ethics-views}

| 倫理觀 | 重點 | 例子 |
|---|---|---|
| **功利論**(功利主義、目的論) | 以**結果**判斷，追求**最大多數人的最大利益** | 「以社區**大多數民眾的利益為優先**，弱勢族群問題排後面」是功利主義，**不是**社會正義 |
| **義務論**(形式論) | 依**行為本身**是否合乎義務或規則，不看結果 | |
| **利己主義** | 以**自己的利益**為判斷標準 | |
| **社會正義** | **健康平權**，關注並**優先**照顧弱勢，改善資源分配 | 弱勢族群嬰兒死亡率特別高→應**優先處理** |

## 台灣護理倫理規範 {#code}

- **性質**：護理師護士公會全聯會於 2006 年(民國 95 年)通過，現行為 **2023 年版**，內容包含智慧化執業環境、正向執業環境、職業傷害預防等議題。
- **概念架構**：**核心價值**(同理、自主、利他、當責、專業、賦能)、**倫理原則**(自主、不傷害、行善、公平正義)、**倫理規則**(誠實、尊嚴、忠誠、保密、隱私)；並以**四種關係**訂定條文：

| 關係 | 條文重點(整理) |
|---|---|
| **護理人員與照護對象** | 以人為中心的照護、文化敏感度、尊重個別性與尊嚴、**知情自主決策**、最大利益、**維護隱私並保密**、**倡議病人安全文化(近錯與異常要通報)**、研究中保護受試者、整合資源提供連續性照護 |
| **護理人員與執業** | 持續進修、維持**個人身心健康與執業行為的合法性**、在法令與能力範圍內執業、對不安全或不倫理的執業提出建議、災難與傳染病爆發時採用安全防護、營造**友善的正向執業環境**、避免職業傷害與職場霸凌、團隊合作 |
| **護理人員與專業** | 發展並實踐核心價值、以實證為依歸、參與專業團體與政策、發展標準、傳承教學，**不應以執業身分替營利商品代言促銷** |
| **護理人員與社會** | 秉持**社會正義**、承擔社會責任、關注弱勢族群與健康不平等、推動醫療照護安全文化、**災難與疫情的演練**、倡議健康人權 |

**情境判斷**

- 助人專業的倫理守則包括：尊重個案**價值觀與信仰**、**隱私保密**、關心**大眾健康與社會需要**；**「善用社交關係與服務對象互惠」是錯的**，護病關係要維持**專業界線**，不是私人社交或互惠。
- **護理長穿制服為嬰兒奶粉代言**：**不違法，但違背護理專業倫理**(規範明列不應以執業身分為營利商品代言)；不是觸犯護理人員法而被罰鍰，也不值得鼓勵。
- 護理師**非執勤時間對路倒者提供緊急協助**、積極參與國際護理活動、推廣病人安全文化，都是**提升**專業形象；放病人傷口照片到臉書則是損害。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 尊重意識清楚病人的決定是符合保密原則 | **自主原則** | 決定權在病人 |
| 答應病人不告知家屬，符合正義原則 | 屬**保密/自主** | 與資源分配無關 |
| 強制病人留院透析是符合施益原則 | **違反自主** | 具決策能力者有權拒絕 |
| 家屬拒絕手術是不傷害原則的問題 | 家屬代決違反**自主** | 病人具意思能力 |
| 通報愛滋病資料違反保密原則 | 法定通報是**保密的例外** | 傳染病防治法 |
| 以大多數人利益為優先是社會正義 | 那是**功利主義** | 社會正義優先弱勢 |
| 弱勢族群問題複雜，所以排後面 | 應**優先處理** | 專業職責 |
| 善用社交關係與服務對象互惠 | 維持**專業界線** | 利益衝突 |
| 護理長穿制服代言奶粉是觸犯護理人員法 | **不違法但違背倫理** | 法無處罰規定 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 四原則：**自主**(知情同意、尊重決定)、**不傷害**(避免危害)、**行善**(最大利益)、**公平正義**(資源分配、弱勢優先)；倫理規則含**誠實、保密、隱私、尊嚴、忠誠**。
- **法定傳染病通報**是保密的**例外**；病人影像不可上社群，要去識別化。
- **功利主義**＝最大多數人的最大利益；**社會正義**＝優先照顧弱勢。
- 台灣護理倫理規範(2023)：核心價值**同理、自主、利他、當責、專業、賦能**；四種關係(照護對象、執業、專業、社會)；**不應以執業身分替營利商品代言**。
- 護病關係是**專業關係**，不可用社交關係互惠。
:::
