激勵題有兩個大宗：**Maslow 需求層級的情境配對**與 **Herzberg 激勵或保健因素的分類**。其他理論記「學者＋一句話」就夠。X 理論、Y 理論見 [[management-theories#neoclassical]]，領導風格見 [[leadership-theories]]。

## 重點摘要 {#summary}

- 激勵理論分**內容理論**(Maslow、Herzberg、ERG)、**過程理論**(期望、公平、目標設定)、**增強理論**。
- **Maslow**：生理 → 安全 → 愛與歸屬 → 自尊 → 自我實現，薪資福利最先。
- **Herzberg**：**激勵因素**(成就、讚賞、升遷、責任)與**保健因素**(薪水、環境、人際、政策、福利)。
- **公平理論**：與同儕比較投入產出；**期望理論**：結果的吸引力。
- 懲戒步驟：勸導、口頭、書面、短期停職、長期停職、免職。

### 國考常考點 {#exam-points}

- **內容理論**(Maslow、Herzberg、ERG、成就動機)；**過程理論**(期望、公平、目標設定)；**增強理論**(依結果修正行為)。
- **Maslow**：生理 → 安全 → 愛與歸屬 → 自尊 → 自我實現；**薪資福利先**；公開表揚＝自尊；互相支援＝歸屬；警衛巡邏＝安全；晉升＝成就感。
- **Herzberg**：**激勵因素**(成就、讚賞、工作本身、升遷、責任)；**保健因素**(薪水、環境、人際、政策、福利、旅遊、宿舍)。
- **Jaques**：W＞C＞P＝**被剝削**；P＞C＝W＝**罪惡感**；P＞W＞C＝**心理壓力**；C＝W＞P＝**衝突疏離**。
- **公平理論**＝與同儕比較投入產出；**期望理論**＝結果的吸引力。
- 懲戒步驟：勸導、口頭、書面、短期停職、長期停職、免職。

## 激勵理論怎麼分類 {#classification}

| 類型 | 問的問題 | 理論 |
|---|---|---|
| **內容理論**(What) | **什麼需求**激勵人？找出影響行為原動力的特殊需求 | **Maslow 需求層級**、**Herzberg 雙因子**、**ERG**(Alderfer：生存、關係、成長)、McClelland 成就動機 |
| **過程理論**(How) | 行為**如何被激發、引導、維持與終止** | **期望理論**(Vroom)、**公平理論**(Adams)、認知評價理論、**目標設定理論**(目標特定理論) |
| **增強理論**(Skinner) | 行為會依**隨之而來的結果**(正負增強、懲罰)而修正 | 增強理論、工作設計理論 |

- 公平理論、期望理論與目標理論**屬過程理論**，不是內容理論。

## Maslow 需求層級 {#maslow}

由低到高：**生理** → **安全** → **愛與歸屬** → **自尊** → **自我實現**。低層級需求滿足後才在意更高層級；已滿足的需求不再具有激勵作用。**Maslow 被稱為人本心理學之父**(1954 年提出)。

| 層級 | 組織與護理例子 |
|---|---|
| **生理** | **薪資福利**(基本待遇)、**用餐地點、員工廁所位置**；足以應付基本需要的待遇 |
| **安全** | 職位保障、工作環境穩定、**大小夜班有警衛巡邏**、隔離裝備與正確穿脫演練；**照顧 SARS 或 AIDS 病人時，護理人員首要是安全需求** |
| **愛與歸屬** | 同事互相支援扶持、**相約出遊**、快樂聚會、加入單位 LINE 群組 |
| **自尊** | **公開表揚**(票選最佳服務並張貼姓名照片)、加績效點數、公開稱讚 |
| **自我實現**(成就感) | **晉升制度**、在職教育與生涯規劃講座、具挑戰的任務；對資深護理人員，部屬的自我實現是激勵要務 |

- **新進人員報到最優先**：介紹**用餐地點與廁所**(生理)，其次隔離裝備演練(安全)，再來 LINE 群組(歸屬)，最後是在職教育說明(自尊或自我實現)。
- **護理主管應優先注意的需要**：**薪資福利**(生理與安全)，再是升遷、專業成長、成就感。
- 題目問「**未提及**哪一層」：逐句對照情境，沒有出現的那層就是答案。例：月薪 38,000(生理)、警衛巡邏(安全)、相約出遊(歸屬) → 未提及**自尊**；高薪(生理)、快樂聚會(歸屬)、表揚加績效點(自尊) → 未提及**安全**。

## Herzberg 雙因子理論 {#herzberg}

| 因子 | 別名 | 作用 | 內容 |
|---|---|---|---|
| **激勵因素**(satisfiers) | 滿足因素，以**工作本身**為中心 | **產生滿意**、積極工作，減少倦勤與異動 | **成就感**、**讚賞(表揚優秀員工)**、**工作本身**、**升遷(明確升遷機會、通過送審晉升)**、**責任**、成長、工作中受肯定 |
| **保健因素**(hygiene) | 不滿足因素、維持因素，環繞**工作條件** | 不足會**不滿**，充足也只是消除不滿，不能激勵 | 管理政策、**薪水(加薪)**、**人際關係**、**工作環境與氣氛**、**員工旅遊**、**分配宿舍**、監督、工作的安全感、福利 |

- 兩理論相通：Maslow 的**低層級需求**類似 Herzberg 的**保健因素**，**高層級需求**相當於**激勵因素**。主管激勵部屬時，除了改善保健因素，更要加強**激勵因素**。
- 減少護理人員倦勤與異動，用激勵因素的措施：**提供明確升遷機會**；**檢討主管領導方式、上班天數、友善工作環境**都屬保健因素(題庫 113-2 的分類；捷徑把上司的領導方式列在激勵因素，若題目同時出現，以**升遷、成就、表揚**最穩)。
- 「工作時受肯定」屬激勵因素，辦公室氣氛佳、酬勞高、工作條件良好屬保健因素。

## 能力—生產力—報酬(Jaques) {#jaques}

Jaques 認為**能力 C**、**生產力 W**、**報酬 P** 三者的關係決定工作滿意度，Gillies 引述；Livy 的研究：所得與期望差距在 ±3% 內滿意，±10% 或超過期望感到不安，超過 20% 可能離開。

| 關係 | 員工感受 |
|---|---|
| **C＝W＝P** | 平衡，**合理的報酬** |
| **P＞C＝W** | 報酬超過能力與生產力 → **罪惡感** |
| **C＝W＞P** | 報酬不及能力與生產力 → **衝突**、逐漸**疏離**工作與組織目標 |
| **P＞W＞C** | 報酬超過生產力、生產力超過能力 → **能力不足而心理壓力** |
| **W＞C＞P** | 報酬低於能力、能力低於生產力 → **被剝削、懲罰感**，不滿 |
| **P＞C＞W** | 報酬超過能力、能力超過生產力 → 有能力者**無法發揮潛能**而焦慮不安 |

- 例：醫院以 N1 的薪資聘 N2 護理師做 N4 的工作 → 生產力超過能力與報酬 → **被剝削、懲罰感**。

## 其他激勵理論 {#others}

| 理論 | 重點 |
|---|---|
| **公平理論**(Adams) | 員工把**自己的投入與產出比率**拿去和**他人(同儕)比較**；覺得公平才有激勵，不公平就改變行為。例：激勵來自感受到自己的報酬與同儕一樣 |
| **期望理論**(Vroom，1964) | 行為意願取決於對**結果的期望程度**(結果對本人的吸引力) |
| **認知評價理論** | 內在酬賞(工作本身趣味)重要；外在酬賞(升遷加薪)可能降低內在激勵 |
| **目標設定理論** | 員工為特定目標努力是動力；**特定、困難的目標**績效較高 |
| **增強理論** | 透過適當獎懲影響行為 |
| **Likert 系統四** | **參與性行政管理**；主管有高度溝通技巧、互信、群體參與、設定實際目標；開放、忠誠、支持部屬的環境工作滿意度最高 |
| **心理賦權**(Spreitzer，1995) | 授與權力使員工產生內在任務激勵、提升自我效能，見 [[delegation-empowerment#empowerment]] |

## 激勵技巧、氛圍與懲戒 {#techniques}

- **Steven**：激起部屬的**願望**、讓部屬對前途充滿**希望**、**支持**部屬的想法與做法。
- **Hamilton** 的十三點，例如：設定目標、鼓勵部屬說出需要、有效溝通、改善工作環境、發展團隊精神、**鼓勵部屬參與決策**、記得**部屬的成長與自我發展**也是激勵。
- **Marquis 與 Huston 創造激勵氛圍的策略**：**說明工作期望**、**讓部屬參與決策**、**了解需求並提供協助**、**提供具挑戰性的任務與成長機會**；**主管承擔所有工作**不是激勵策略。
- 實務：釐定目標、有效溝通(面對面與文字)、重視需要、**充分授權**(例：請各督導協助外科系護理長完成年度中心目標)、適時適量回饋、培養學習風氣。
- **懲戒的步驟**：**勸導 → 口頭譴責 → 書面警告 → 短期停職 → 長期停職 → 免職**。

**依員工能力與意願選擇管理策略**(題庫用語)

| 員工情況 | 策略 |
|---|---|
| **能力低、意願低** | **移轉策略**(114-1 答案) |
| **能力低、意願高** | **發展策略**(訓練與培養) |
| **能力高、意願低** | **激發策略**(107-1 答案；提高工作動機，鼓勵參與、雙向溝通) |
| 能力高、意願高 | 增強策略 |

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 公平、期望與目標理論是內容理論 | **過程理論** | 分類 |
| 內容理論試圖解釋行為如何被激發、維持與終止 | 那是**過程理論** | 定義 |
| 加薪、員工旅遊、分配宿舍是激勵因素 | **保健因素** | Herzberg |
| 通過送審晉升、表揚優秀員工是保健因素 | **激勵因素** | Herzberg |
| 新進人員報到最優先介紹在職教育 | 先**生理**(用餐、廁所) | Maslow |
| 公開張貼票選最佳護理師是愛與歸屬 | **自尊** | Maslow |
| 同事互相支援是自尊需求 | **愛與歸屬** | Maslow |
| 警衛巡邏屬生理需求 | **安全** | Maslow |
| 只滿足高層級需求就不必考慮低層級 | 要**由低到高** | Maslow |
| 主管為避免加重負荷應承擔所有工作 | 要**適度授權** | 激勵氛圍 |
| 激勵來自報酬與同儕一樣是期望理論 | **公平理論** | Adams |
