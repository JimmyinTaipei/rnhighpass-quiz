領導理論按發展順序分成**特質 → 行為 → 情境(情勢) → 現代**。考題都是「**給情境，判斷是哪一型**」，所以每個理論只要記**兩個維度或四個型態**，以及**適用對象**。權力與領導型態(獨裁、民主、放任)見 [[leadership-power-styles]]。

## 重點摘要 {#summary}

- 領導理論發展順序：**特質 → 行為 → 情境 → 現代**；考題多為給情境判斷型。
- **管理方格**：(9,9) 團隊最理想、(1,1) 無為、(1,9) 懷柔、(9,1) 業績中心、(5,5) 中庸。
- **情境領導**依成熟度：告知、推銷、參與、授權；**Fiedler** 看關係、任務結構與職位權力。
- **交易型**是角色澄清與獎勵交換；**轉換型**是願景、激勵、超越自我。

### 國考常考點 {#exam-points}

- **管理方格**：X＝關心工作、Y＝關心人；(1,1) 無為、(1,9) 懷柔、(9,1) 業績中心、(5,5) 中庸、**(9,9) 團隊(最理想)**；屬**行為理論**。
- **情境領導**＝依**成熟度**：告知(低)、**推銷(能力低意願高)**、**參與(能力高意願低)**、授權(高)。
- **Fiedler**：關係、任務結構、職位權力；極有利或極不利→任務導向。
- **路徑—目標**：指導(新進)、支援(友善關心)、參與(討論)、**成就(培育未來領導者)**。
- **交易型**＝角色澄清與獎勵交換；**轉換型**＝願景、激勵、超越自我；特質理論＝天賦特質。

## 領導的概念 {#concept}

- **領導**：影響人們**自願**努力以達成群體目標的行動，是一種學習的過程，強調人際關係、影響他人的自願行為，並有助達成群體目標。領導包含**領導者、被領導者、情境**三方面，不是單方面的領導者行為。
- 護理領導：以人際關係與創造力、影響力改變護理人員的行為，在意願下共同達成護理部目標。
- **柯林斯領導能力五級**
  1. 第一級：高度才能者（個人績效好）
  2. 第二級：貢獻個人能力於團隊
  3. 第三級：統籌人力與資源有效率完成目標
  4. 第四級：激起熱情、給予願景
  5. **第五級**：以謙虛個性與專業堅持，建立持久卓越績效

## 特質理論 {#trait}

- 焦點是領導者的**天賦能力**(偉人理論)：身材、勇氣、聰明、專業能力、表達力、人際關係、精力與果斷等特質，決定誰是有效的領導者。
- 它說的是「**領導者是什麼樣的人**」，不是領導行為。

## 行為理論 {#behavior}

| 理論 | 重點 |
|---|---|
| **管理方格**(Blake 與 Mouton，1964) | 二維：**X 軸＝關心工作(生產)**，**Y 軸＝關心人**；各分 9 級共 81 種，基本五型見下 |
| **工作中心式與員工中心式**(密西根大學) | **員工中心式**的單位生產力較高；工作中心式嚴密監督、任務結構化 |
| **兩構面理論**(俄亥俄州立大學，1945) | **關懷**(尊重、信任、相互了解)與**定規**(規章與程序)；較理想是**高關懷、多定規** |
| **連續構面理論**(Tannenbaum 與 Schmidt，1958) | 依部屬參與決策的程度，從主管獨斷到與部屬共享決策權，是一條連續線 |

**管理方格五型**(括號為「關心工作，關心人」)

| 型 | 名稱 | 特徵 |
|---|---|---|
| (1,1) | **無為型**(貧乏型、放任型) | 對工作與人都不太關心，**得過且過** |
| (1,9) | **懷柔型**(鄉村俱樂部型) | 只重視人際關係與舒適氣氛 |
| (9,1) | **業績中心型**(職責管理、任務型) | 要求**任務、效率**，**較少顧及人員需要** |
| (5,5) | **平衡型**(中庸型) | 平衡完成工作與維持士氣 |
| **(9,9)** | **理想型**(團隊型) | 經由成員努力完成工作，使組織目標與成員目標高度一致，**最理想** |

- 管理方格的兩個構面是**生產(工作)與員工(人)**，**不是**關懷與法規、關係與目標、績效與酬勞；它**屬於行為理論**；依方格位置可以幫助領導者發展合適的領導行為。
- **舊題 106-2** 的錯誤選項：「X 軸是領導者對員工的關心程度」。**X 軸是關心工作，Y 軸才是關心人**。

## 情勢(權變)理論 {#situational}

### 情境領導理論(Hersey 與 Blanchard) {#hersey}

依**部屬的成熟度**(能力與意願)調整領導行為的**任務導向**與**關係導向**。決定領導型態的要素是**員工成熟度**，不是溝通、直覺或組織型態。

| 型態 | 領導行為 | 部屬成熟度 |
|---|---|---|
| **告知型**(telling) | **高任務、低關係**：制訂規則，明確告訴部屬做什麼 | **低**：不能也不願負責，缺乏安全感或技術 |
| **推銷型**(selling) | **高任務、高關係**：提出決策並讓部屬澄清疑問，雙向溝通 | **低到中**：**能力不足但願意負責** |
| **參與型**(participating) | **低任務、高關係**：鼓勵雙向溝通與傾聽 | **中到高**：**有能力但不願負責**(缺乏安全感或動機) |
| **授權型**(delegating) | **低任務、低關係**：最少的指導與支持 | **高**：有經驗、能力、意願與自信 |

- 例：工作 1.5 年、剛晉升 N1、整體性照護在指導下能完成 → **推銷型**；大部分同仁資淺、能力不足但有意願 → 說明決策並讓同仁澄清疑問(**推銷型**)；**能力極強但意願低** → **激發**(題庫選項用「增強、發展、激發、移轉」命名管理策略，各策略對應的員工類型見 [[motivation-theories#techniques]])。

### Fiedler 權變理論 {#fiedler}

- Fiedler(1967)：領導效能取決於領導風格與情境的配合。**情境有利度**由三項決定：**領導者與成員的關係**、**任務結構**、**領導者的職位權力**。
- 情境**非常有利或非常不利**時，**任務導向**的領導績效較好；**中度有利**時，**關係導向**較好。若要讓領導有效，可以從**改變情境**開始。

### 路徑—目標理論(House 與 Mitchell，1974) {#path-goal}

領導者的任務是**設定達成任務的獎酬**、協助部屬**辨認達成任務與獲得獎酬的路徑**、替他們清除障礙，目的是**增加部屬的動機**。

| 領導行為 | 內容 | 適用 |
|---|---|---|
| **指導式** | 指派工作、澄清角色、程序與規則 | 任務不明確、**新進人員** |
| **支援式** | **關懷**部屬、友善、關心需求，營造友善氣氛 | 易引發不滿、單調、有壓力的工作，部屬缺乏自信 |
| **參與式** | 與部屬**共同討論**並採納建議 | 需要取得共識，部屬有專業且渴望參與 |
| **成就導向式** | 訂**挑戰性目標**、期望高標準 | **成就需求高**者，**培育有發展潛能的未來領導者** |

## 現代領導理論 {#modern}

| 類型 | 重點 |
|---|---|
| **交易型領導** | 清楚定義**角色、任務與獎勵制度**，以**角色澄清與工作要求**引導、激勵員工，讓員工認為付出與報償公平；含適時獎勵、例外管理 |
| **轉換型領導** | Bass 與 Burns(1985)：結合交易與魅力型；以願景與**激勵**支持員工，使員工**超越自我**，為組織帶來創新；**最能激勵部屬不斷提升自我能力**。以組織目標激勵、讓部屬發揮才智、感覺被尊重與認同，就是轉換型 |
| **魅力型領導** | 依靠**個人魅力、自信與特別的想法**，領導者本人是模仿的典範 |
| **分享型領導** | 讓組織中許多人**共同分享**責任，如自我導向團隊、兩人共同領導 |

- **轉換型領導的構成要素**：影響力(理想化影響)、**啟發力**(智力激發、鼓舞)、**激勵**，個別關懷(Bass 的 4I：理想化影響、鼓舞性動機、智力激發、個別關懷)；**生產力不是構成要素**。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 管理方格的構面是關懷與法規 | **關心生產(工作)與員工(人)** | 理論定義 |
| 管理方格 X 軸是對員工的關心 | X＝**工作**，Y＝人 | 軸向 |
| (9,1) 是團隊管理式 | (9,1)＝**業績(職責)中心**；(9,9)＝團隊 | 型態 |
| 情境領導依主管直覺或組織型態決定 | 依**員工成熟度** | 理論核心 |
| 資淺、有意願的同仁用告知型 | **推銷型** | 能力低、意願高 |
| 高能力、低意願的員工用授權型 | **參與型(激發)** | 授權是高能力高意願 |
| Fiedler 的情境變數是成熟度 | **關係、任務結構、職位權力** | 理論定義 |
| 友善、關心需求是參與型(路徑—目標) | **支援型** | 定義 |
| 培育未來領導者適合支援型 | **成就導向型** | 挑戰目標 |
| 以角色澄清與工作要求激勵是轉換型 | **交易型** | 交換關係 |
| 生產力屬轉換型領導的要素 | 不屬於 | 要素是影響、啟發、激勵 |
