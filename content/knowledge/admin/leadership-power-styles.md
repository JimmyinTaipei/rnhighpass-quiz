這一頁題數最多的是**權力來源**。解法是把題目情境對到七種權力，再分成**職位權力**(組織給的)與**個人權力**(自己有的)。領導理論見 [[leadership-theories]]。

## 重點摘要 {#summary}

- 七種權力：職位權力—**法統、獎賞、強制**；個人權力—**專家、參考**(另有資訊、連結)。
- **Douglass 領導型態**：集權(緊急)、民主(團體決定)、放任(資深熟練)、參與。
- 管理者靠職權、把事情**做對**；領導者靠個人特質、做**對的事**。
- **Mintzberg** 管理者角色：人際、資訊、決策三類。

### 國考常考點 {#exam-points}

- 職位權力＝**法統、獎賞、強制**；個人權力＝**專家、參考**(＋資訊、連結)。
- 調度人力、要求穿制服、要求休假＝**法統**；升遷加薪、頒獎＝**獎賞**；減薪降級解僱＝**強制(脅迫)**；請教專業技能＝**專家**；欣賞人格＝**參考**；爭取內外資源＝**連結**。
- 權力靠**依賴**；提高重要性、依賴性、不可取代性。
- Douglass：**集權(緊急)**、**民主(團體決定，如票選)**、**放任(資深熟練、交待後離去)**、**參與(初步方針→意見→主管決定)**。
- 管理者靠**職權**、把事情**做對**；領導者靠**個人特質**、做**對的事**。
- Mintzberg：**資源分配者**(決策)、**監督者、傳播者、發言人**(資訊)、聯絡者(人際)；Quinn：**指導者＝規劃＋授權**。

## 職權與權力 {#authority}

**職權**(authority)：在某一職位上由法律或規則**正式授予**的權力，分三種：

| 職權 | 內容 |
|---|---|
| **直線職權** | 主管對部屬的**指揮權**，可下達命令、執行決策；例：護理部主任→副主任→督導→護理長→護理人員 |
| **幕僚職權** | **提供建議、協助**他人執行職責，屬顧問性質，**沒有決定權**；護理的在職教育、人事、會計等 |
| **功能職權** | 機構明文規定，主管把部分例行或專門事務授權給相關人員；例：感染管制中心依規定負責全院感控政策 |

**權力**(power)：影響或改變他人行為的能力。French 與 Raven 的權力來源如下。

## 權力來源 {#power-bases}

| 類別 | 權力 | 意義 | 情境例子 |
|---|---|---|---|
| **職位權力**(與組織有關) | **法統(合法、法定)權** | 依**組織職位**可提出與工作有關的要求 | 占床率下降，護理長(在不違反勞基法下)**要求同仁休假、支援其他病房**；要求上班穿制服與識別證 |
| | **獎賞(獎勵、獎酬)權** | 用晉升、加薪、頒獎、讚美等**報酬**控制他人 | 頒「進步小天使」獎；工作完成後邀同仁**慶功歡唱**；升職加薪 |
| | **強制(脅迫)權** | 用**處罰或控制**，使人因害怕而服從 | **減薪、降級、解僱**；要求每月 4 小時義工，員工不滿仍配合 |
| **個人權力**(與個人特質有關) | **專家(專技)權** | 因**專業知識、特殊技術**而贏得尊敬與信從 | 新進護理師找護理長或臨床教師(preceptor)討論如何**精進臨床照護知識與技能**；高度專業知識贏得部屬尊敬 |
| | **參考(參照、榜樣)權** | 因**個人品德、魅力、待人接物**使人認同、效法 | 督導長待人接物頗獲好評，護理師主動找她諮詢**個人生涯規劃** |
| | **資訊權** | 擁有他人需要、有價值的**資訊** | 臨床護理專家在職教育提供特別資料 |
| | **連結(關係)權** | 在組織內外有**人脈連結**，能結合有影響力的人達成目的 | 護理主管能**儘早獲得內外部資源為部屬爭取福祉** |

- 職位權力：**法統、獎賞、強制**；個人權力：**專家、參考(加上資訊、連結)**。
- **專家權 vs 參考權**要看「為什麼尋求幫助」：**尋求知識技能**＝專家權；**因為欣賞其為人與魅力**＝參考權。
- **權力的運用**：權力在於**雙方的依賴關係**，不是你多我少的互斥關係。護理師想增加自己的權力，可以：增加對單位需求的**敏感性(重要性)**、具備他人沒有的能力(**依賴性**)、強化專業知識技能(**不可取代性**)。「權力最重要在於互斥關係」是錯誤的。

## Douglass 領導型態 {#styles}

Douglass(1984)把領導者運用影響力帶領人員的方式分四型：

| 型態 | 特徵 | 適用 | 例子 |
|---|---|---|---|
| **集權式(獨裁、專制)** | 領導者強力控制，所有決策由其決定，以命令下達 | **急需明確指令的緊急狀況**(大量傷患)、部屬多為新進人員或單位剛成立 | 瓦斯氣爆傷患湧入，院長到急診現場**坐鎮指揮、下命令、指派人員** |
| **民主式** | 領導者少發號施令，提供資料，政策經**群體討論與決定**；成員**主動參與**決策 | **需長期共事**的人群，如醫療組織 | 護理長請同仁**票選**最優良護理人員。民主式領導**較少借助職位權威**，多靠影響力、人際關係與溝通協調 |
| **放任式** | 個人或團體決定所有政策，領導者**很少參與** | 成員**高度自主、自動自發**(技術熟練的資深人員) | 10 位急診病患同時到達，護理師技術熟練且資深，護理長**交待任務後離去**；若用於新手團隊會混亂 |
| **參與式** | 領導者**提供初步方針**，部屬提出意見(腦力激盪)，**最後由管理者決定**；高關懷、高體制內涵 | 醫療體系、護理管理、技術熟練但**需增加動機**的成員 | 評鑑準備時請每位護理長**主動選擇**負責的部分 |

- 民主式與參與式的差別：民主式由**團體討論決定**(如票選、多數決)；參與式**最後由主管決定**。
- 捷徑提醒放任式通常不適用於健康照護機構，但題庫的考點是「成員資深、熟練且高度自主」時可用。

## 管理者與領導者 {#manager-leader}

| 比較 | 管理者 | 領導者 |
|---|---|---|
| 權力來源 | **職權**(組織任命、有正式職位) | **個人特質**與影響力，不一定有正式職位 |
| 重點 | 秩序、控制、維持平衡；**把事情做對**(do things right) | 願景、變革、創新、激勵；**做對的事**(do the right things) |

- 「領導者由組織任命、有正式職位」錯；「管理者擁有特定的影響力與權力」對。
- **非正式領導人物**：不一定是正式管理者，常在會議中發言容易得到眾人附和，**非正式團體**以他為中心。

## 管理者角色 {#roles}

**Mintzberg 十種角色**

| 類別 | 角色 | 例子 |
|---|---|---|
| **人際** | 頭臉人物(精神領袖，象徵與儀式性職責)、領導者、**聯絡者**(建立並維繫內外人際網絡) | |
| **資訊** | **監督者**(觀察、蒐集資訊)、**傳播者**(把資訊傳給同仁)、**發言人**(代表單位向外報告) | 護理長**觀察**同仁身心與工作表現＝監督者；護理長**傳達**院方活動訊息＝傳播者；護理部主任參加院務會議**代表護理部報告**＝發言人 |
| **決策** | 企業家、危機處理者、**資源分配者**、協商者 | 護理長調配單位**人力、物力、時間與經費**＝資源分配者 |

**Quinn 競合價值架構**(護理長的角色功能，題庫出現四種)：**指導者**(釐清目標與願景、**規劃、指派並授權**)、**促進者**(凝聚團隊、促進溝通、調解衝突)、**生產者**(以任務與績效為導向)、**創新者**(適應外部環境、推動變革)。模型另有協調者、監督者、導師、中介者。

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 提供技術指導是參考權 | **專家權** | 憑專業知識 |
| 欣賞督導長為人而請益是專家權 | **參考權** | 憑人格魅力 |
| 要求休假、支援其他病房是強制權 | **法統權** | 職位賦予的正當權限 |
| 主管提供資訊並做決策是強制權 | **資訊權** | 強制權是懲罰 |
| 慶功歡唱是專家權 | **獎賞權** | 正向報酬 |
| 權力最重要在互斥關係 | 在**依賴關係** | 權力運用 |
| 票選優良護理人員是參與式 | **民主式** | 團體決定 |
| 評鑑讓護理長主動選擇負責項目是放任式 | **參與式** | 有授權與引導 |
| 緊急傷患用民主式或參與式 | **集權式** | 需要即時指揮 |
| 民主式領導主要靠職位權威 | 較少用，靠影響力與溝通 | 型態特色 |
| 管理者做對的事，領導者把事情做對 | **相反** | 角色比較 |
| 代表護理部報告是精神領袖 | **發言人** | 資訊角色 |
