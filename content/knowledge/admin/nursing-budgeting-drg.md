預算題的核心是**把名稱和定義對起來**：看到「**參考過去**」是傳統預算、「**不參考過去、重新說明理由**」是零基預算、「**上級先訂最高金額**」是固定限額預算、「**設定終止日期**」是日落預算。成本分類與損益平衡見 [[nursing-cost-analysis]]。

## 預算的意義與目的 {#purpose}

預算是在特定期間內，把有限資源**依計畫分配**給各項活動，並**用數字表示**的收入與支出計畫。

- **目的與功能**：有效運用資源(依目標優先順序分配)、提供**績效評核的標準**、**協調與溝通**(上下與部門之間，了解目標、政策與成果)、作為**決策的基礎**，並**控制成本(不是單純減少成本)**。
- 預算**不是個別員工薪資發放的依據**(那依薪給制度與考核)。
- **編列原則**：依實際臨床需求與歷史資料**實事求是**，不可浮報或**刻意超估**。單位護理長自己做單位預算，是**分權**的應用。
- 護理主管應了解單位的**作業收入、成本總額與損益**，並具備成效分析與執行能力。

## 護理部編列的預算內容 {#content}

| 項目 | 說明 |
|---|---|
| **人事(人力)預算** | **占最大比例**；可依評鑑標準、護理時數、病人分類系統推算人力 |
| 設備預算 | 醫院設備、雜項設備 |
| **教育訓練**、**學術研究**、專案計畫 | 護理部可自行規劃的業務費用 |
| 獎勵辦法、電腦設備與應用系統 | |
| **品管預算** | |

- **藥品費用**由藥劑部門編列，**不屬於護理部預算**。
- **兩種常見的分類**要分清楚(題庫兩種都出現)：
  - **三分法**：**人事預算**、**營運預算**(日常消耗品、教育訓練、研討會、品管等)、**資本預算**。
  - **二分法**：**經常性(營運)預算**與**資本支出預算**。
- **資本預算**：重大設備、硬體建設等**金額大、使用超過一年**的支出，例如購置醫療設備、土地、房屋、儀器；**經常性預算**：人事費、業務費、消耗品，例如教育訓練費、**加班費**、文具紙張；購置設備屬**資本支出**，**不是**經常性支出。現金支出預算則是預估現金流入與流出。

## 預算的編列方式 {#types}

| 預算 | 怎麼編 | 判斷關鍵字 | 備註 |
|---|---|---|---|
| **傳統(增量)預算** | 以**過去**的業務與支出為基礎，微幅增減 | 「**參考過去**的業務與用途」 | 容易沿襲舊習 |
| **零基預算**(ZBB) | **不參考上期預算**，每年**從零開始**逐項說明必要性與成本效益 | 「重新編列」「每項都需說明理由」 | 優點：避免浪費、全盤檢討有溝通參與；缺點：**耗時耗力**；是**預算分權**的方式 |
| **績效預算**(計畫預算) | 以**目標**設定計畫，再把計畫分類算出成本；重視活動的規劃與成果評估 | 「依目標、計畫、績效」 | 捷徑把計畫預算與績效預算視為同一種，題庫也有分開列選項，**依題幹用詞判斷** |
| **固定限額預算** | **最高主管事先設定預算最高金額**，部屬在額度內提出申請 | 「**先訂最高金額**」 | 題庫中「固定預算」常指這種(例：護理長編列電動床維修費，答案是固定預算)；另有一種定義是依單一預計業務量編列的靜態預算 |
| **彈性預算** | 把費用分成固定與變動，**依實際業務量**調整預算額度 | 「依業務實際變化調整」；突發的**傳染病**採購防護用物 | 與固定預算相反 |
| **日落預算** | **先設定計畫終止日期**，到期自動失效，續辦要重新審查 | 「終止日期」「自動失效」 | |
| **開放式預算** | **不設金額上限** | | 不等於彈性預算 |
| 資本預算 | 重大設備與建設 | | 見上節 |

**零基預算的細節**

- 正確敘述：**每項預算都要說明理由**、**每年支出都會重新審視**、全盤檢討**提供溝通與參與機會**。
- 錯誤敘述：「主管可參考上期預算」(那是傳統預算)；「從零開始議價」「預算無上限」「依目標從零編列」都不是零基預算的意思。
- 適合**資源有限、需要重新分配**的機構。

**題型提醒**

- 「參考過去 → 傳統預算」、「不考慮過去重新編 → 零基預算」、「最高主管先設上限 → 固定限額預算」、「依業務量調整 → 彈性預算」、「終止日期 → 日落預算」。
- **舊題 108-1**：因應新型傳染病，護理部立即提出採購防護用物，這件事是**彈性預算**的例子；該題選項把它寫成**開放式預算**，所以不能選。

## 診斷關聯群 DRGs {#drg}

- **Tw-DRGs**：將**診斷相同(類似)、處置類似**的疾病歸為一組，再依年齡、性別、有無合併症或併發症、出院狀況細分，**同一組支付同一個定額**，又稱**包裹式給付**，屬**預付制**(事先訂好給付金額)。健保自 **99 年 1 月起分階段導入**。
- **正確特性**：**預先設定、固定的給付方式**；促使醫院**控制成本、提升效率**，減少不必要的手術、用藥與檢查。
- **可能的影響**：
  - 平均**住院天數縮短**；
  - 醫院會**增加向長期照護機構與居家護理的轉介**，使用量上升；
  - 需注意**過早出院**、**推諉重症病人**(人球)與**減少必要服務**的風險。
- **錯誤選項**：「不影響住院天數」、「縮短長照與居家服務的使用」、「增加作業服務成本」。
- 護理人力不足、服務品質下降的後果，要靠**護病比、品質指標**等機制監測，見 [[nurse-staffing-policy]]、[[quality-management-concepts]]。

## 預算相關名詞 {#terms}

| 名詞 | 意義 |
|---|---|
| **直接費用**／**間接費用** | 與服務直接相關(如護理人員薪資)／不能立即歸屬單一單位的共同費用 |
| **消耗性資材** | 用一次或幾次就丟棄(文具、表單、衛材) |
| **非消耗性資材** | 小額(桌椅、飲水機)；大額屬資本類(土地、儀器、建築) |
| **營運資金** | 維持現有業務的短期資金，如現金、應收帳款、庫存 |
| **換置資金** | 日後要更換資產(房舍、儀器)所需的資金 |
| **利潤** | 總收入扣除直接、間接費用、呆帳與折扣後剩下的部分，用於擴展與研發 |

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 預算是個別薪資發放的依據 | 是機構或部門的**資源規劃** | 薪資依制度與考核 |
| 護理長做預算應超估以備不時之需 | **實事求是**，不浮報 | 合理真實 |
| 零基預算可參考上期預算 | **不參考** | 定義 |
| 傳染病突發採購防護用物是開放式預算 | 屬**彈性預算**的例子 | 開放式是不設上限 |
| 最高主管先設上限是績效預算 | **固定限額預算** | 定義 |
| 設定終止日期的是固定限額預算 | **日落預算** | 定義 |
| 購置醫療設備是經常性支出 | **資本支出** | 金額大、年限長 |
| 藥品費用由護理部預算 | **藥劑部**編列 | 歸屬 |
| DRGs 不影響住院天數 | 會**縮短住院天數** | 預付制誘因 |

## 國考常考點 {#exam-points}

:::exam[國考重點]
- 預算目的：**有效運用資源、績效評核標準、協調溝通、決策基礎、控制成本**；**不能超估**。
- 護理部預算**人事預算最大**；藥品費用不屬護理部；教育訓練、學術研究、品管屬護理部業務費。
- **傳統**(參考過去)、**零基**(不參考、逐項說明理由、耗時)、**固定限額**(上級設上限)、**彈性**(依業務量)、**日落**(終止日期)。
- **資本預算**：重大設備、硬體建設；經常性預算：人事費、業務費、消耗品。
- **DRGs**：**預先設定的固定給付**、包裹式、預付制；縮短住院天數、轉介長照與居家增加。
:::
