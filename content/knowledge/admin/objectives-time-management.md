目標管理題有兩個重點：**MBO 的四要素與程序**，以及**目標寫得好不好(SMART)**。時間管理題則是**緊急與重要的排序**、**內在或外在因素**與 **80/20 原理**。規劃見 [[planning-strategy]]。

## 重點摘要 {#summary}

- **MBO**：Drucker、參與式、結果導向；程序為目標設定 → 行動規劃 → 自我控制 → 定期檢討。
- **SMART**：具體、可測量、可達成、相關、時限。
- 時間管理：**緊急且重要 → 重要但不緊急 → 緊急但不重要 → 不緊急不重要**。
- **80/20 原理**：重要少數(20%)產生 80% 成效。

### 國考常考點 {#exam-points}

- MBO：**Drucker**、**參與式**、**結果導向**、**Y 理論**；四要素**特定性(首要)、參與決策、明確期間、績效回饋**；程序**目標設定 → 行動規劃 → 自我控制 → 定期檢討**。
- 優點：分權、溝通、士氣、自我成長；缺點：**極重量化目標**。成功要件：溝通、激勵、授權、民主、合作、評估。
- **SMART**：具體、可測量、可達成、相關、**時限**；「6 個月內降到 0.10%」是好目標。
- 時間管理：**緊急且重要 → 重要但不緊急 → 緊急但不重要 → 不緊急不重要**；重要但不緊急占最多時間。
- 內在：拖延、計畫不周、不會拒絕、知識不足；外在：電話、會議、文書繁雜、家屬要床單。
- **80/20**：重要少數(20%)產生 80% 成效。會議：準時開始、重要議題排前、不超過 90 分鐘。

## 目標管理 MBO {#mbo}

- **定義**：Peter Drucker 於 1954 年提出。主管與部屬以**參與**的方式**共同訂定目標**，定期評估進度，是**以結果(成果)為導向**的系統管理方法，屬**參與式管理**。例：把院內感染率設為 5%，或把針扎事件、跌倒發生率訂在 2% 以下。
- **目的**：讓員工**參與決策**，提高對組織目標的接受度，產生激勵；把組織目標轉換成**可衡量的具體目標**，定期評估以控制成果。
- **理論基礎**：McGregor 的 **Y 理論**(所以 MBO 的人性預設與 X 理論不一致)、管理方格、Herzberg 雙因子與 Maslow 需求層次、期望理論、Likert 系統四。
- **目標管理關注的是組織目標與個人目標的結合**，不是只關注組織目標；個人目標與組織目標也不是各自獨立。

**四要素**

| 要素 | 說明 |
|---|---|
| **目標特定性**(具體可衡量) | **首要的基本要素**；不能只有簡短說明，要轉成可衡量的具體目標 |
| **參與決策** | 目標與衡量方法由**主管與部屬共同設定**，不是主管單方面決定 |
| **明確的期間** | 每個目標都有必須達成的**期限**，不可保持彈性不設限 |
| **績效回饋** | 執行過程中**主管定期評估並回饋**，讓部屬了解績效、加以修正 |

**程序**(捷徑)：**目標設定 → 規劃行動計畫 → 自我控制 → 定期檢討**；目標設定後的下一步是**計畫(行動規劃)**。

**目標管理的過程**：高層訂目標 → 各單位主管確定自己的角色 → 確立員工目標 → 了解組織目的與資源 → 評估整體目標進行情形；以組織策略由上往下層層發展各階層與個人的目標，使方向一致。

| 優點(成效) | 缺點 |
|---|---|
| 達成好的規劃功能、**加強控制**、人人參與易**發掘人才**、**促使員工自我成長**、**提高士氣**、**落實分權**、**促進溝通** | **極重視量化目標**、重量輕質、過度注重短期、書面作業多、設定目標時需要大量溝通 |

- **目標管理成功的要件**：**溝通**、**激勵**、**授權**(把權限與責任分授給各級主管)、**民主**(主管與員工共同決策)、**合作**、**評估**。**目標由主管與員工共同完成**，而不是主管單獨列出或依個人能力分配。
- 「落實**集權**概念」是目標管理**最不適當**的描述，它強調**分權**。
- **判斷題**：
  - 護理長與同仁**共同設定**明年度 N3、N4 人數增加 20% 並策劃訓練 → **目標管理法**。
  - 「**本年度**非計畫性拔管發生率 0%」 → 符合**明確期間**與**目標具體**，沒有人員參與與結果回饋的敘述。
  - 「提升護理師專案通過率；指導同仁每月 4 小時；3 個月後繳交進度報告」 → 包含目標設定、行動規劃、**定期檢討**，**沒有績效考核**。

## SMART 原則 {#smart}

| 字母 | 意義 | 例子 |
|---|---|---|
| **S**pecific | **具體**明確 | 「降低感染性垃圾 50 公斤」可以；「強化書寫紀錄能力」太抽象 |
| **M**easurable | **可測量** | 「提升滿意度」沒有數值，不可測量 |
| **A**chievable | **可達成** | 「滿意度提升到 100%」過於理想 |
| **R**elevant(Realistic) | **相關**(與價值觀、組織目標有關) | |
| **T**ime-bound | 有**時限** | 「**於 6 個月內**降低壓瘡發生率至 0.10%」同時具備時限與量化指標，是最佳目標 |

- 「R」是 relevant 或 realistic，不是 remarkable；「T」是時限，不是 transformable；「S」是 specific，不是 superb。
- **舊題 105-2**：「兩年後在上海成立 2 家醫美中心」，考選部公告答案是**具體性與可測量性**。

## 時間管理 {#time}

**時間管理的祕訣**：決定目標 → **身體力行**(依 SMART 設定目標) → 運用節省時間的技巧 → 手腦並用。

### 優先順序 {#priority}

| 順位 | 類型 | 說明 |
|---|---|---|
| 第一優先 | **緊急且重要** | 占最少時間，立即處理 |
| 第二優先 | **不緊急但重要** | 占**最多**時間；長遠規劃與預防，可以減少危機 |
| 第三優先 | 緊急但不重要 | 可授權、減少干擾 |
| 第四優先 | 不緊急也不重要 | 最後或儘量消除 |

- 例：護理師執行常規測量與給藥時，**丙病人主訴胸悶痛放射至肩部、臉色蒼白，醫囑要立即做 EKG** → **緊急且重要**，優先；甲病人要止痛劑、乙病人血糖或血壓高要處理，緊急程度較低；繼續常規作業排在後面。
- **黃金時段原理**：把最重要、最困難的工作放在自己**精神最好的時段**。

### 浪費時間的因素 {#waste}

| 外在因素(環境、他人) | 內在因素(自己) |
|---|---|
| **電話阻擾**、社交應酬、**會議**、資訊不足、溝通不良、缺乏回饋、政策與程序說明不清、處理危機、工作伙伴能力不足、檔案系統不良、**文書工作繁雜**、開門政策、被臨時的工作中斷(如**家屬要乾淨床單**) | **拖延**、**計畫不周全**、未訂定目標與方針、**未能授權**、**不知如何拒絕**、猶豫不決、無法做決定、**缺乏專業知識技術**(如發藥時不知藥物作用，要**在電腦系統上查詢**)、**組織能力不好**、能力不足、常看手機訊息 |

- 找出自己浪費時間的主因並控制內在因素，才能管理外在因素。
- **時間自我管理策略**：**充分授權**、**減少開會並縮短會議時間**、用**甘特圖**計畫與監督工時、學會**拒絕**、檔案管理、避免**時間陷阱**(活動輪迴、拖延、突如其來的訪客與電話、沒有建設性的會議)。

### 80/20 原理(巴瑞多／柏拉圖) {#pareto}

- 義大利經濟學家 **Vilfredo Pareto** 提出：原因與結果、投入與收穫**不平衡**；**重要的少數(20%)**帶來**80%** 的成效，**瑣碎的多數(80%)**只帶來 20% 的成效，所以注意力放在能產生 80% 成效的 20% 活動上。
- 在時間管理的意思：真正**緊急且重要**的事通常只占少數。
- **錯誤說法**：「把握關鍵多數，就可獲得重要少數」(相反)、「投入越多時間成果越大」、「掌握 80% 的時間能解決 20% 的問題」、「掌握那 20% 的原因就能解決**全部**問題」。柏拉圖圖表的用法見 [[quality-improvement-tools#seven-tools]]。

### 成功會議的原則 {#meeting}

**開會的流程**

1. **計畫**：目的、議程、議題、參加人員
2. **通知**：目的、時間地點、人員、議程
3. **準備**：資料備齊
4. **正式開會掌控議程**
   1. **主席準時開會**，不必等遲到者
   2. **重要議題排前面**，需費時討論的排後
   3. **會議不超過 90 分鐘**，會前說明散會時間
   4. 引導討論、制止離題
5. **總結與記錄**：複述決議，記載分派的工作、人員與完成時間

## 常見錯誤選項 {#pitfalls}

| 錯誤說法 | 正確做法 | 為什麼 |
|---|---|---|
| 目標管理是過程導向的管理 | **結果(目標)導向** | 重視成果 |
| 目標管理的人性預設與 X 理論一致 | 與 **Y 理論**一致 | 理論基礎 |
| 目標管理只關注組織目標 | **結合**組織與個人目標 | 參與式 |
| 目標由主管決策即可 | **共同參與**設定 | 四要素 |
| 達成時間保持彈性 | 要有**明確期間** | 四要素 |
| 目標管理要落實集權 | **分權** | 優點 |
| 極重視量化目標是優點 | 是**缺點** | 重量輕質 |
| 「提升滿意度」是具體可測量的目標 | 缺少數值 | SMART |
| 優先順序：緊急但不重要在重要但不緊急之前 | **重要但不緊急**優先於緊急但不重要 | 矩陣 |
| 文書工作繁雜、電話中斷是內在因素 | 屬**外在**因素 | 時間浪費因素 |
| 拖延、不會拒絕、計畫不周全是外在因素 | 屬**內在**因素 | 時間浪費因素 |
