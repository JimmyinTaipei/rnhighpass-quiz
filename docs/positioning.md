# 知識庫定位與製作原則

> 狀態：2026-10-03 與使用者問答後確認。之後每一輪知識庫製作、每一次介面改動都以這份為準；要改，先改這份。
> 語法與建置細節見 `content/knowledge/README.md`；進度見 `docs/knowledge-progress.md`；批次順序見 `docs/knowledge-roadmap.md`。

## 一、定位

**中文、台灣版、以護理為核心的考點連結平台。** 參考對象是 AMBOSS、Medscape、MSD Manual、UpToDate：以知識為主，頁與頁之間互相連結。目前台灣沒有同類的中文平台。

- **免費優先。** 主要內容都免費；以後如果有付費，只用在「更舒適的使用體驗」，不把知識鎖起來。
- **以舒適使用為優先**：好找、好讀、手機也能用。

## 二、受眾與用途

| 優先 | 誰 | 什麼時候用 |
|---|---|---|
| 1 | 在校護理系學生(各年級) | 期中期末考前查特定章節；實習時查常見、常考的疾病、技術與器材 |
| 1 | 國考生 | 準備國考時確認特定章節、看考點與相關考題 |
| 2 | 想打好基礎的學生 | 從重點往下展開背景知識(生理、生化、機轉) |

原則：

- **國考題數拿來排序和挑重點，不拿來決定收不收。** 國考很少考、但課本有、臨床常用的內容也要收，例如導尿步驟、實習常見的急重症器材。
- 一般學生不會從頭讀到尾，所以每一頁都要能**單獨看懂**，再用連結串起來。例如讀糖尿病時，頁內就有藥理重點卡；想學更多，點進藥物頁。

## 三、進入路徑(讀書流)

1. **科目 → 章節 → 考點地圖 → 知識頁**：上課、期中期末、國考複習(已有)
2. **系統 → 主題 → 知識頁**：查資料(知識庫首頁，**目前以系統為主**)
3. **搜尋**(已有)
4. **題目詳解 → 複習知識點**(已有)

系統頁預設**依主題分組**，每組照「生理 → 疾病 → 藥物 → 檢驗 → 技術」排，一組就是一條讀書路線，解決「不知道從哪篇開始」。保留「依類型｜依考題數」切換。(待做，見 roadmap)

## 四、分類三軸

| 軸 | 內容 | 例子 |
|---|---|---|
| 器官系統 | 疾病、藥物、檢驗、解剖&生理；兒科疾病、婦科疾病也放這裡，用「小兒」對象標記與 `alsoIn` | 心血管、呼吸、神經… |
| 跨系統 | 腫瘤、感染、**急重症**(新) | 癌症、病原體、呼吸器、ECMO |
| 護理專業 | 基護(含護理技術)、社區、行政、精神 | 給藥、長照、排班、治療性溝通 |

- **產科**維持現在的產科分類；分娩、產後、新生兒放產科與兒科，不另外開「人類發展」(使用者 2026-10-03：先不做)。
- **護理技術**(`procedure`)：有**獨立入口**列出全部技術，同時掛在相關系統下。`system` 選國考最常考的科目：導尿、給藥放 fundamentals；抽痰放 respiratory，`alsoIn: [fundamentals]`。
- **器材與管路**(`device`，新)：急重症常見、學校少教的器材，例如呼吸器、中心靜脈導管、動脈導管、胸管、CRRT、IABP、ECMO。主分類 `critical-care`。器材的操作步驟寫在技術頁，器材頁連過去。

## 五、內容深度：三層

1. **重點**：國考與期中期末的最低標準，一直顯示。
2. **想打好基礎**：預設收合，補「看懂重點需要的背景」。使用者可以在設定頁切換成收合、全部展開或隱藏。
   - 例：藥物抑制 Topoisomerase I → 收合區塊說明 Topoisomerase I 與 II 的差別、在細胞週期的角色。
   - 例：Statin 抑制 HMG-CoA reductase → 收合區塊說明血脂代謝與這個酵素的角色。
3. **完整頁面**：收合區塊裡的「看完整頁面 →」。

基礎科目的深度：

- **解剖&生理要有深度**：骨骼解剖、肌肉解剖等值得開獨立頁。
- **病理總論開獨立頁**：發炎、細胞傷害與死亡、修復、循環障礙。
- 藥理機轉層級(例：Topoisomerase)放在「想打好基礎」就好，不另外開頁，優先度低。
- 基礎內容是為了**看懂重點**，不要變成負擔。

## 六、頁面版型

### 知識頁頁首

1. 標題、類型、系統
2. 「考題」區塊：相關題數、練相關題、「出現在 ChXX」(收合前手機顯示 1–2 項、電腦顯示一列，其餘展開才顯示)
3. **重點摘要**：第一個 H2 `## 重點摘要 {#summary}`，淡底卡片，是**頁面唯一的重點區塊**。內容是 3–5 點重點條列，加上子段落 `### 國考常考點 {#exam-points}`(畫面上不顯示這個子標題，條列直接接在重點後面；保留它只是為了嵌入藥物重點時能排除國考點)。考前只看這一區也有用
4. 內文 → 頁尾 `## 相關考題 {#questions}` → 參見 → 參考資料

頁尾不再另外放「國考常考點」H2(2026-10 已合併上來)；段落中間跟該段緊密相關的 `:::exam` 提示框保留。frontmatter `summary` 只給預覽卡用，不顯示在本文。

不在頁首顯示「XX 考題」的標籤膠囊；「草稿・待審閱」只給管理者看。

### 寫作格式：分層列點

- 編號依層級顯示成 **1. → a. → i.**。
- **一個列點只寫一件事**；原因、處理方式、時機、來源各自一點。
- 括號裡又有括號、一句話超過兩個分號時，就該拆成下一層。
- 段落文字只用在需要解釋因果的地方(例如病理生理)，而且要短。

改寫前：

> 支架置放後需持續服用雙重抗血小板(aspirin + P2Y12 抑制劑；ACS 預設至少 12 個月，之後長期單一抗血小板；為減少出血，ACS 做 PCI 且能耐受 ticagrelor DAPT 者 1 個月後可停 aspirin 改 ticagrelor 單一治療，高出血風險者 1 個月後可改單一抗血小板(來源：2025 ACC/AHA 急性冠心症指引)；詳見 雙重抗血小板治療(DAPT))；不可自行停藥(支架內血栓 → 再梗塞)。病人想停藥時，先傾聽原因、個別化說明，不要責備或恐嚇。

改寫後：

```markdown
支架置放後需持續服用雙重抗血小板治療(DAPT)

1. [[antiplatelets#dapt|DAPT]] 組成：aspirin + P2Y12 抑制劑
2. 使用與調整時機(2025 ACC/AHA 急性冠心症指引)
   1. ACS：預設至少 12 個月，之後長期單一抗血小板
   2. 為減少出血：ACS 做 PCI 且能耐受 ticagrelor DAPT 者，1 個月後可停 aspirin，改 ticagrelor 單一治療
   3. 高出血風險者：1 個月後可改單一抗血小板
3. 不可自行停藥
   1. 原因：支架內血栓 → 再梗塞
   2. 病人想停藥時：先傾聽原因、個別化說明，不要責備或恐嚇
```

新頁一律照這個格式寫；舊頁另開一輪只改結構、不改內容。

## 八、資料來源原則

沿用既有規則(記憶：知識庫授權規則、來源與新舊指引規則)，並補充：

- 每項事實在當行標注來源；台灣醫學中心衛教單張、政府資料(國健署、疾管署、衛福部、全國法規)優先。
- **課本與原文書**：只用來核對與補深度，不複製表達。舊版原文書(例：Williams Obstetrics)適合用在穩定的內容(解剖、妊娠生理、產程機轉)；處置與數值以新指引為準。兩者不同時，舊考點保留，並標注新指引。掃描檔用 macOS Vision OCR。
- 圖片只用 PD、CC0、CC BY。

## 九、之後要做的功能(依序)

1. 系統頁依主題分組(解決「不知道從哪篇開始」)
2. 知識庫首頁「依科目｜依系統」切換(目前以系統為主)
3. 個人化：收藏/書籤、閱讀進度、個人筆記/螢光筆(Supabase)
4. 三種模式：
   1. 一般瀏覽
   2. 期中期末：選日期與科目範圍，期間只顯示這些科目與對應卡片，有閱讀/做題進度；到期自動回到一般瀏覽
   3. 國考：全科進度(進度怎麼算之後再訂)
5. 視覺打磨：系統頁改版之後，用 impeccable 或 design-critique 檢查系統頁、知識頁、手機版，只採用不違反 `[data-ui="apple"]` token 的建議
