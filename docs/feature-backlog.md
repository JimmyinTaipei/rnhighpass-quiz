9. 資料庫顯示的題目，要可以自行選擇年份
10. 開頭 XX題相關考題 與 結尾的相關考題要合併 連我自己都不清楚區別
11. 部分前面的AI圖要替換，但是要先請AI整理建議替換的圖片，以及要替換的圖片要生成prompt跟示意圖

14. 資料庫的內容跑Google cloud Batch，還沒想好流程，目前額度夠，但是天數要注意，儘量這禮拜解決好
15. 也很不急，新增OSCE區，可以有個技術checklist、AI製作的示意動畫影片
16. 確認網頁修改內容，回填到資料庫、護理題庫的流程
17. 收藏可以收藏知識庫的頁面甚至小到收藏知識庫內的 一、二、 的子標題
18. 手機版的全部、疾病 的選擇 要改成點擊可展開的列表（我不太會形容）
19. 搜尋要可以用ID搜尋題目，以及要新增搜尋的功能（但我說實在還沒有很好的想法）
