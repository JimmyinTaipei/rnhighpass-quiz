# UI 對照庫

> 建立日期：2026-11-02
> 入口：本機 dev 的 `/dev/ui`，例如 `http://localhost:3000/dev/ui`
> 用途：保留可操作的樣式參考，未來新增設計也放在這裡；目前先收錄下拉選單，科目與梯次已選用原生白底，可搜尋清單保留供未來適合的操作使用
> 預覽不讀取帳號資料、不記錄作答、不變更正式搜尋；正式部署環境此路徑回傳 404

## 下拉選單與套用按鈕

四款都以同一組科目／梯次資料比較，選單與套用按鈕採相同控制高度；可切窄版、停用狀態及實際套用預覽選擇

| 樣式 | 入口 | 設計方向 | 取捨 |
|---|---|---|---|
| 原生白底 | `/dev/ui?style=outlined` | 獨立白底欄位、細框線，搭配白底套用按鈕 | 開啟後使用裝置原生選單，展開樣式依系統而異 |
| 柔和填色 | `/dev/ui?style=soft` | 灰底圓潤欄位、淡藍主要按鈕 | 邊界較輕，需要留出欄位間距 |
| 整合工具列 | `/dev/ui?style=toolbar` | 選單與動作集中在一組連續工具列 | 窄版改為垂直排列，適合一組共同套用的條件 |
| 可搜尋清單 | `/dev/ui?style=searchable` | 展開後可打字找選項，選取後收合 | 互動較多，手機不呼叫系統原生選取器 |

可搜尋清單使用原生 details 與單選欄位，補上選取後收合、搜尋、Esc、點外部關閉及返回觸發項目的焦點處理

## 新增樣式時

1. 在 `src/lib/ui-library.ts` 的 `SELECT_STYLES` 新增穩定 ID、名稱、差異方向、說明與取捨
2. 在 `src/components/dev/SelectLibrary.tsx` 的範例控制與按鈕中加入該款外觀；若是新的互動模式，獨立成小元件
3. 保留同一組範例內容、寬／窄版與停用狀態，避免只比較顏色或用無法操作的假控制項
4. 使用者選定後才將需要的部分移至共用正式元件；對照庫依使用者要求持續保留

## 驗證與待驗收

- 四種入口已通過本機 HTTP 渲染檢查，前三款有三個具名 select，第四款有三個可搜尋 details 選單
- TypeScript、修改檔案的 ESLint 及既有搜尋回歸檢查通過
- Safari 可讀取預覽控制項與原生展開清單；畫面擷取仍受 ScreenCaptureKit 錯誤限制，互動與窄版視覺的最終選型由使用者實際比較
- 2026-11-02 使用者選定原生白底，已套用搜尋頁科目與梯次；可搜尋清單暫不全站套用
- 正式元件為 `src/components/ui/NativeSelect.tsx`，與對照庫共用 `src/lib/ui.ts` 的 `nativeSelectClass`
