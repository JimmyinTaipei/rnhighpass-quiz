### 課本現況摘記(寫頁時再逐段讀)

1. **鼻胃管位置確認**(下冊技術 12-1，書頁約 90)：課本列三法：反抽胃液並以酸鹼試紙測 pH(課本寫「最精確」，數值 OCR 為 1～3.5，**寫頁時看原頁確認**)、打入約 10～20 mL 空氣在胃部聽診氣泡音、管端放入水中看有無連續氣泡
2. **Braden 量表**(上冊表 8-8，書頁約 405)：六個項目；分級 ≤ 9 極高度、10～12 高度、13～14 中度、15～18 輕度、19～23 沒有危險(課本引 WoundSource 2021)
3. **壓力性損傷分期**(上冊表 8-9)：依 **NPIAP 2016**：第一至四期、無法分期、深部組織損傷；課本有 NPIAP 授權的圖，**不可重製**
4. 病歷保存與醫囑(上冊 Ch4)：寫頁時對照醫療法第 68、70 條原文(見第二節)
