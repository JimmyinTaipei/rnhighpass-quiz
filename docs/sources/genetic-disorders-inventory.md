# 遺傳疾病盤點(第 5 輪 C 組用)

> 2026-10-14 整理。使用者要求：把散在各科、跟遺傳有關的疾病(以單基因為主，加少數很常見的多因子遺傳)一起整理，補上「依遺傳模式分類」的架構
> 盤點方法：全庫 8,960 題的題幹與選項做關鍵字比對(不只看標籤，因為很多題沒有遺傳疾病的標籤)；原始命中清單在 `多保命護理分章/analysis/genetic_hits_2026-10-14.json`，開工時要重跑一次並逐題確認
> 已排除的誤判(2026-10-14 補標時逐題確認)：「SMA」是 mycoplasma、plasma 等字的一部分；「雷特」是巴瑞特食道與妥瑞氏症(Tourette)；「Down」是日落症候群(sundown)；「Turner」是闌尾炎與胰臟炎的 Turner 徵象
> 標籤已在 5-0a 合併成一個疾病一個標準名，見 [../tag-merge-round5.md](../tag-merge-round5.md)
> 題數是「題幹或選項提到」的題數，含已被其他頁收錄的題目

## 頁面分工

| 頁 | 寫什麼 | 不寫什麼(連到哪) |
|---|---|---|
| `physiology/genetic-inheritance`(總覽頁) | 基因與染色體基礎、各遺傳模式規則與譜系判讀、機率計算、外顯率與表現度、基因印記、粒線體遺傳、多因子遺傳、**全部遺傳疾病依模式分類的總表**(每列：疾病、缺陷基因或產物、一句特徵、連到哪頁)、遺傳諮詢與優生保健 | 產前篩檢流程(第 16 輪產科)、新生兒篩檢細節(已在 pediatric-endocrine) |
| `disease/chromosomal-disorders` | 三體症(21、18、13)、性染色體異常(透納氏、柯林菲特氏)、微缺失(貓哭、迪喬治、小胖威利與天使症)、X 染色體脆折症、Barr body、核型與 FISH | 唐氏症的產前篩檢(第 16 輪產科)、迪喬治的免疫部分(已在 primary-immunodeficiency) |
| `disease/single-gene-disorders` | 依模式分節：體染色體隱性、體染色體顯性、X 性聯隱性與顯性、粒線體；每個疾病寫遺傳、機轉、關鍵表現、護理或衛教重點 | 血液疾病的治療細節(第 12 輪)、已有頁的疾病只寫遺傳並連過去 |

篇幅太長時，single-gene-disorders 可拆成「代謝異常(體染色體隱性為主)」與「其他單基因疾病」兩篇，寫的時候再決定

## 題目歸屬規則

1. 問遺傳模式、帶因、再發機率、染色體核型 → 本輪的遺傳頁
2. 問治療、輸血、凝血因子、鐵螯合、急性處置 → 留給該疾病的系統輪(血液第 12 輪)，本輪頁面連過去
3. 問產前篩檢方法(羊膜穿刺、絨毛取樣、母血篩檢) → 第 16 輪產科
4. 已被其他頁收錄的題目不重複收，只加連結
