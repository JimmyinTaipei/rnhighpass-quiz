# 知識庫表格閱讀與收藏

2026-11-01：本輪完成知識庫表格整張滑動、放大閱讀、收藏及獨立網址；2026-11-01 使用者驗收後恢復知識庫表頭底色、內容維持白底，舊比較表移除灰白交錯列；不合併兩套內容，不把知識庫表格加入 `/tables` 清單

## 閱讀方式

- 所有欄一起左右滑動，不再固定第一欄；溢出時保留「左右滑動」提示
- 知識庫保留有底色的表頭、白底內容；舊比較表同樣保留表頭色，移除灰白交錯列。保留 Markdown 對齊、粗體與連結
- 依第二次手機驗收回饋，取消表格本身的點擊與 Enter 放大操作。手機只保留原生左右滑動與表內連結；桌機以獨立「放大閱讀」按鈕開啟
- 支援 hover 的精準指標：收藏星號恆常顯示，未收藏為灰色空心、已收藏為黃色實心；僅「放大閱讀」在滑鼠移入表格或鍵盤聚焦時顯示。控制固定在有底色表頭右側：桌機星號透明無框、放大按鈕灰底，手機星號保留灰底，不再放在表格外上方；表頭恢復原本 0.5rem 垂直 padding，控制外觀約 28 px，不為操作增加表頭高度。最後一欄只預留水平空間，hover 僅改透明度、不改尺寸；手機星號透過透明延伸維持約 44 px 點擊高度
- 獨立頁的收藏移到頁標題右側，表格上方不另占一排
- 手機／觸控：表頭直接顯示收藏星號，放大按鈕隱藏，不依賴 hover 或先打開滿版才能收藏；保留右下角「左右滑動 →」提示，滑動後淡出
- 手機文章及外圍閱讀區統一白底，與桌機文章相同；桌機維持既有卡片版型
- 桌機放大以原生 dialog 處理焦點與背景隔離；開啟後若縮窄視窗，閱讀器仍以 `dvh` 與安全區支援滿版，但手機端不提供開啟動作
- 開啟時鎖背景，關閉回原位置及原表格／觸發按鈕；從知識面板開啟時，Esc 只關表格，不關面板
- 表格內知識連結的預覽會放進 dialog，避免被原生 modal 的背景隔離擋住；前往知識段落時關閉表格

## 穩定識別與資料

- 現有 2,097 張表格初次補上持久 ID、可讀標題，402 篇文章僅加入容器與一處外層提示框 fence 調整；表內文字不變
- 初次遷移工具：`node scripts/identify-knowledge-tables.mjs` 預設 dry-run，`--write` 才寫入；已標記的表格不重編 ID。新表格建議手動取可讀且唯一的 ID
- 建置工具檢查全站唯一 ID、非空標題及容器恰好一張表；所有 Markdown 表格都需包容器，缺標記直接失敗
- 索引放在 `public/knowledge-data/table-index.json`，只含 ID、標題、文章來源與段落 ID，避免額外增加 Worker 的打包大小；全文仍從來源文章讀取
- 同一張表在原文、嵌入、彈窗、獨立頁與收藏中都使用相同 ID；插入、搬動或改寫內容時保留 ID
- 獨立網址：`/tables/knowledge/[tableId]`，使用靜態頁，提供來源文章連結及收藏
- 收藏：`kind="table"`；`user_table_favorites` 儲存 `user_id`、`table_id`、`created_at`，採本人 RLS；不對舊 `tables_` 建外鍵
- 存入時檢查表格仍存在；原文移除後仍可取消收藏。「我的題本 › 表格」按最近收藏排序，失效項目顯示移除提示
- 儲存採樂觀更新、失敗回復；同一收藏請求進行中禁止重複送出；未登入點收藏顯示登入提示

## 使用者手動驗收

建議先開 `/learn/antivirals`，這頁有多張寬表格；收藏後到 `/mistakes?tab=tables`

1. 手機左右滑一張寬表格，第一欄也跟著移動；整個頁面不應橫向溢出
2. 手機輕點非連結的表格儲存格不應開啟視窗或跳頁，也不應產生載入提示；表格只左右捲動，右下角溢出提示可見，滑動後淡出
3. 手機直接點表頭星號收藏，去「我的題本 › 表格」開啟同一張表，重新整理後收藏仍在；取消後清單同步移除
4. 電腦收藏星號始終可見，收藏後為黃色實心；移入表格時，在星號左側出現灰底放大按鈕，表頭高度與控制位置不變。Tab 可顯示並操作按鈕，Esc 關閉後焦點返回放大鈕
5. 電腦從章節開知識面板，再用按鈕放大表格；按關閉或 Esc 後保留原面板
6. 檢查知識庫表頭有底色、內容白底、粗體、欄位對齊及表內連結；手機點知識連結應能看到預覽並前往文章
7. 登出後仍可放大，收藏提示登入；另用不同帳號確認收藏互不顯示
8. Safari／Android Chrome 實機確認文章白底、表頭星號、斜向滑動與長按選字。瀏覽器自動化與實機互動本輪未驗證，由使用者操作驗收

## 後續合併順序

1. 舊比較表已先移除灰白交錯列並保留表頭底色；後續再共用閱讀外框，先保留兩種來源
2. 「比較表」清單加入知識庫表格，標示來源、連到穩定網址
3. 建立重複表對照，選一個主題試辦並人工確認內容差異
4. 逐批指定唯一內容來源，知識文章及題目改共同引用，保留舊網址與收藏 ID 對照
5. 確認引用、收藏、編輯及匯出後才移除重複版本
