## 一、summary 草稿

### 藥理（9 篇）

**sulfonylureas 磺醯脲類**
```yaml
summary: |
  促進胰臟 β 細胞分泌胰島素(關閉 K-ATP 通道);需要 β 細胞還有功能，第一型無效。
  分泌不受血糖高低控制 → 口服藥中低血糖風險最高，體重增加。
  一般飯前約 30 分鐘服用;老人與腎功能不佳者特別注意低血糖。
```

**meglitinides Meglitinide 類**
```yaml
summary: |
  機轉同磺醯脲類(促進胰島素分泌)，但作用快、時間短，主要降低餐後血糖。
  餐前 0–30 分鐘服用，不吃飯就不吃藥。
  仍可能低血糖(比磺醯脲類少)與體重增加。
```

**metformin 雙胍類**
```yaml
summary: |
  第二型糖尿病傳統第一線用藥;主要減少肝臟糖質新生，降低空腹血糖。
  不刺激胰島素分泌 → 單用不會低血糖，體重中性或略降。
  最常見腸胃不適 → 隨餐或飯後服用;長期注意維生素 B₁₂ 缺乏。
  罕見乳酸中毒:eGFR < 30 禁用，含碘顯影劑檢查前後暫停。
```

**tzd TZD 類**
```yaml
summary: |
  活化 PPAR-γ → 增加肌肉、脂肪、肝臟對胰島素的敏感性(對抗胰島素阻抗)。
  單用低血糖少;起效慢，需要數週。
  體液滯留、水腫、體重增加 → 心衰竭禁用;骨折風險增加，需監測肝功能。
```

**alpha-glucosidase-inhibitors α-葡萄糖苷酶抑制劑**
```yaml
summary: |
  抑制小腸 α-葡萄糖苷酶 → 延緩澱粉與雙醣吸收，主要降低餐後血糖。
  隨餐第一口服用。
  常見脹氣、排氣增加、腹瀉。
  併用其他藥發生低血糖時要給葡萄糖，不能給蔗糖。
```

**sglt2-inhibitors SGLT2 抑制劑**
```yaml
summary: |
  抑制腎臟近曲小管的 SGLT2 → 葡萄糖從尿液排出，作用不依賴胰島素。
  單用低血糖少;體重、血壓下降，對心衰竭與慢性腎臟病有保護效果。
  副作用:生殖泌尿道黴菌感染、脫水、血糖正常的酮酸中毒;生病、脫水時暫停。
```

**dpp4-inhibitors DPP-4 抑制劑**
```yaml
summary: |
  抑制分解腸泌素的 DPP-4 酵素 → 自身 GLP-1 增加 → 血糖高時才促進胰島素分泌、抑制升糖素。
  口服;單用低血糖少、體重中性、腸胃副作用少。
  降血糖效果溫和;不與 GLP-1 受體促效劑併用。
```

**glp1-receptor-agonists GLP-1 受體促效劑**
```yaml
summary: |
  模擬腸泌素 GLP-1:血糖依賴性促進胰島素分泌、抑制升糖素、延緩胃排空、增加飽足感。
  多為皮下注射;單用低血糖少，體重明顯下降。
  最常見噁心、嘔吐、腹瀉;甲狀腺髓質癌或 MEN2 病史禁用;不與 DPP-4 抑制劑併用。
```

**insulin 胰島素製劑**
```yaml
summary: |
  直接補充胰島素;用於第一型、妊娠、DKA/HHS、手術與重症、口服藥控制不佳時。
  依作用時間分速效、短效(RI)、中效(NPH)、長效、預混;只有 RI(與部分速效)可靜脈注射。
  主要副作用:低血糖、體重增加、注射部位脂肪增生、低血鉀。
  混合抽藥時先抽清(RI)、後抽濁(NPH)。
```

### 檢驗（5 篇）

**blood-glucose 血糖**
```yaml
summary: |
  測量當下血液中的葡萄糖濃度(靜脈血漿或指尖微血管血)。
  空腹 ≥ 126 mg/dL，或飯後 2 小時、隨機(有症狀時)≥ 200 mg/dL 為糖尿病;空腹 100–125 為前期。
  低血糖:< 70 mg/dL。單位換算 mg/dL ÷ 18 = mmol/L。
```

**hba1c 糖化血色素**
```yaml
summary: |
  葡萄糖黏在紅血球血紅素上形成，反映過去約 2–3 個月的平均血糖(紅血球壽命約 120 天)。
  < 5.7% 正常、5.7–6.4% 糖尿病前期、≥ 6.5% 糖尿病。
  HbA1c 每上升 1%，平均血糖約增加 30 mg/dL。
```

**ogtt 口服葡萄糖耐受試驗**
```yaml
summary: |
  喝下定量葡萄糖後定時測血糖，評估身體處理葡萄糖負荷的能力;比空腹血糖更敏感。
  非懷孕成人用 75 g:第 2 小時 < 140 正常、140–199 葡萄糖耐受不良、≥ 200 糖尿病。
  也用於篩檢妊娠糖尿病(一階段或二階段法)。
```

**ketones 酮體**
```yaml
summary: |
  胰島素不足或飢餓時脂肪大量分解，肝臟產生酮體當替代燃料。
  酮體是酸，堆積造成陰離子間隙增加的代謝性酸中毒(DKA);丙酮由肺呼出 → 水果味口氣。
  血酮(β-OHB)≥ 3.0 mmol/L 符合 DKA 標準;尿酮試紙測不到 β-OHB，以血酮較準。
```

**uacr 尿液白蛋白/肌酸酐比值**
```yaml
summary: |
  隨機(最好晨起第一次)尿液同時測白蛋白與肌酸酐，用比值抵銷尿液濃淡。
  白蛋白尿是糖尿病腎病變最早可偵測的指標。
  < 30 mg/g 正常、30–299 中度增加(舊稱微量白蛋白尿)、≥ 300 重度增加;3–6 個月內 3 次有 2 次異常才算持續。
```

```
:::basics[為什麼第一型糖尿病無效？]
第一型糖尿病的 β 細胞被自體免疫破壞，幾乎不能製造胰島素。磺醯脲類是「催促」β 細胞把胰島素放出來，本身不是胰島素;β 細胞不在了，就沒有東西可以催。第二型病程久了 β 細胞功能逐漸衰退，藥效也會跟著變差。
:::
```

### metformin 雙胍類

```
![[glucose-homeostasis#hepatic-glucose|basics]]
```
（158 字。內容說明肝醣分解與糖質新生，並對應 metformin。）

```
:::basics[為什麼腎功能差容易乳酸中毒？]
metformin 不經肝臟代謝，以原型由腎臟排出;腎功能下降時藥物在體內蓄積。它抑制肝臟糖質新生，而乳酸是糖質新生的原料之一，肝臟用掉的乳酸變少，乳酸就容易堆積。含碘顯影劑可能造成急性腎損傷，所以檢查前後要暫停。
:::
```
⚠「乳酸是糖質新生的原料，所以抑制糖質新生會使乳酸堆積」是為了說明機轉而補的一句。頁面上寫的是原料包含乳酸（`glucose-homeostasis#hepatic-glucose`），以及「腎功能下降 → 蓄積 → 乳酸中毒」，但沒有把兩者連起來。請確認這個連結的說法可以接受。

### alpha-glucosidase-inhibitors α-葡萄糖苷酶抑制劑

```
:::basics[醣類要分解成單醣才能吸收]
澱粉與雙醣(蔗糖、麥芽糖)必須被小腸絨毛刷狀緣的 α-葡萄糖苷酶分解成單醣(如葡萄糖)才能吸收。這類藥擋住這一步，醣類吸收變慢，餐後血糖就不會衝高;沒被吸收的醣到了大腸被細菌發酵，所以會脹氣、排氣增加。
低血糖時給蔗糖沒用，因為蔗糖也要靠這個酵素分解;葡萄糖本身就是單醣，可以直接吸收。
:::
```
