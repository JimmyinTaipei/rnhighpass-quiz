## ace-inhibitors ACE 抑制劑(8 條)

可選段落:summary、mechanism、agents、indications、adverse-effects、interactions、nursing

### b01 → adverse-effects   (信心:中 16.8 副作用與禁忌;備選:summary 13.6、agents 12.1、mechanism 10.9)  <!--h:fb3ec6-->
> - 機轉：「抑制 angiotensin I 轉換成 angiotensin II」→ captopril 等 **-pril**;**Angiotensin II 與醛固酮都下降**，**bradykinin 增加**(「減少 bradykinin 濃度」是錯的)。

### b02 → mechanism   (信心:中 15.3 作用機轉;備選:adverse-effects 11.0、indications 9.5、agents 7.0)  <!--h:9694aa-->
> - ACEI 用於心衰竭：降低血管阻力、減少鈉水滯留、抑制交感活性;**losartan 不是 ACEI**(是 ARB)。

### b03 → adverse-effects   (信心:中 14.9 副作用與禁忌;備選:nursing 11.0、mechanism 10.0、summary 7.4)  <!--h:f6a872-->
> - **乾咳**是 ACEI(captopril)的典型副作用——bradykinin 堆積。

### b04 → adverse-effects   (信心:中 13.7 副作用與禁忌;備選:mechanism 10.5、summary 8.5、interactions 7.7)  <!--h:64bda7-->
> - ACEI 造成**高血鉀**，不是低血鉀;ACEI 與醛固酮拮抗劑都是高血鉀的原因。

### b05 → indications   (信心:高 23.8 適應症;備選:summary 11.4、adverse-effects 8.6、nursing 5.5)  <!--h:b1bfc3-->
> - 慢性腎臟病/糖尿病：ACEI **可減少蛋白尿**，是糖尿病高血壓病人較適合的藥。

### b06 → adverse-effects   (信心:中 7.6 副作用與禁忌;備選:nursing 5.5、agents 4.0、mechanism 3.1)  <!--h:3d7332-->
> - **孕婦禁用** captopril(ACEI 與 ARB 皆禁);孕期可用 labetalol、nifedipine、methyldopa、hydralazine。

### b07 → interactions   (信心:中 7.8 交互作用;備選:indications 5.7、adverse-effects 4.8、nursing 4.6)  <!--h:54bb84-->
> - ACEI 會使**血鋰濃度上升**(與 NSAIDs、thiazide 同)。

### b08 → adverse-effects   (信心:中 12.2 副作用與禁忌;備選:mechanism 10.1、interactions 4.6、summary 4.0)  <!--h:a080a4-->
> - 腎素抑制劑是 **aliskiren**，不是 ACEI。

### b01 → summary   (信心:中 13.8 重點摘要;備選:adverse-effects 11.4、nursing 9.9、agents 6.7)  <!--h:1cb07d-->
> - **Prazosin 初次服用易姿態性低血壓(首劑現象)→ 低起始劑量、睡前服用**。

### b02 → agents   (信心:中 11.5 代表藥物;備選:summary 10.9、indications 7.6、adverse-effects 7.0)  <!--h:1826fd-->

### b03 → indications   (信心:高 30.8 適應症;備選:agents 21.4、summary 15.2、adverse-effects 4.2)  <!--h:77e21c-->
> - Prazosin 可用於**嗜鉻細胞瘤**引起的高血壓;嗜鉻細胞瘤**切除後**常低血壓，不需再用 α 阻斷劑。

### b04 → mechanism   (信心:中 17.7 作用機轉;備選:adverse-effects 13.5、summary 2.4、agents 2.4)  <!--h:b535be-->
> - Prazosin 仍可能**反射性心搏過速**(atenolol 則不會)。

### b05 → indications   (信心:高 24.4 適應症;備選:summary 3.6、agents 2.4、mechanism 1.2)  <!--h:efc3f5-->
> - 膀胱過動急迫性尿失禁用 oxybutynin，不是 doxazosin。

## arni 血管收縮素受體-腦啡肽酶抑制劑(5 條)

可選段落:summary、mechanism、agents、indications、adverse-effects、interactions、nursing

### b01 → mechanism   (信心:高 26.3 作用機轉;備選:summary 18.2、interactions 9.6、adverse-effects 9.3)  <!--h:f357ba-->
> - ARNI = **sacubitril(腦啡肽酶抑制劑)+ valsartan(ARB)**;作用是**增加利鈉胜肽**並阻斷 RAAS。

### b02 → mechanism   (信心:中 8.5 作用機轉;備選:summary 7.3、adverse-effects 7.0、interactions 7.0)  <!--h:9774f6-->
> - **與 ACEI 間隔 36 小時**、不可併用 → 血管性水腫。

### b03 → summary   (信心:高 18.8 重點摘要;備選:adverse-effects 13.0、interactions 6.3、nursing 5.5)  <!--h:85e9a9-->
> - 常見副作用：**低血壓、高血鉀、腎功能變差**;懷孕禁用。

### b04 → nursing   (信心:高 18.6 護理重點與衛教;備選:summary 10.3、mechanism 5.3、indications 3.0)  <!--h:01119a-->
> - 使用 ARNI 後 **BNP 上升**，追蹤改用 **NT-proBNP**。

### b05 → summary   (信心:高 21.9 重點摘要;備選:mechanism 15.6、indications 13.9、interactions 11.7)  <!--h:b8a94e-->
> - 心衰竭「四大支柱」：**ARNI(或 ACEI/ARB)、β 阻斷劑、MRA、SGLT2 抑制劑**——都能降低死亡率;loop 利尿劑與 digoxin 只改善症狀/住院。

## beta-blockers β 阻斷劑(11 條)

可選段落:summary、mechanism、agents、classification(H3)、individual-agents(H3)、labetalol-pregnancy(H3)、indications、adverse-effects、interactions、nursing

### b01 → adverse-effects   (信心:中 12.4 副作用與禁忌;備選:classification 11.9、summary 9.9、mechanism 9.0)  <!--h:b057d4-->
> - **氣喘病人避免 propranolol / 非選擇性 β 阻斷劑**(阻斷 β2 → 支氣管收縮);「氣喘病人可以用 propranolol」是錯的。

### b02 → nursing   (信心:高 23.6 護理重點與衛教;備選:summary 13.7、adverse-effects 9.0、mechanism 7.8)  <!--h:bd64d1-->
> - 服 propranolol 的護理：**確認有無氣喘、給藥前量心跳**;低血鈉、脫水不是它的副作用。

### b03 → individual-agents   (信心:高 21.6 個別藥物特色;備選:summary 15.0、adverse-effects 14.1、indications 12.6)  <!--h:ee8043-->
> - **Propranolol 會遮蔽低血糖、傾向使血糖下降(不會使血糖上升)**;可通過血腦障壁、治療甲狀腺亢進、抑制腎素分泌。

### b04 → classification   (信心:中 10.0 依選擇性分類;備選:individual-agents 10.0、adverse-effects 8.0、nursing 5.9)  <!--h:5ff311-->
> - **Labetalol 同時阻斷 α 與 β**;**carvedilol 是 β 阻斷劑兼 α1 阻斷**(用於心衰竭)。

### b05 → labetalol-pregnancy   (信心:中 10.5 Labetalol 與孕婦;備選:individual-agents 8.7、indications 8.5、interactions 8.5)  <!--h:589b26-->
> - **Atenolol 不會引起反射性心搏過速**(反而心搏過緩);amlodipine、prazosin、hydralazine 會。

### b06 → mechanism   (信心:中 22.6 作用機轉;備選:individual-agents 16.5、classification 6.4、summary 4.2)  <!--h:ede1d0-->
> - Class II(propranolol)**降低第 4 期去極化**、減少竇房結自律性;**sotalol = Class III 兼 β 阻斷**。

### b07 → individual-agents   (信心:高 13.1 個別藥物特色;備選:classification 5.9、indications 2.9、nursing 2.9)  <!--h:c62f82-->
> - 半衰期：**nadolol 最長**，esmolol 最短。

### b08 → individual-agents   (信心:高 24.3 個別藥物特色;備選:summary 16.6、mechanism 11.2、classification 10.3)  <!--h:4b3b18-->
> - **Timolol**：非選擇性 β 阻斷，**減少房水分泌**，**不是縮瞳劑**;氣喘禁用、給藥前評估心搏徐緩。

### b09 → indications   (信心:中 32.1 適應症;備選:mechanism 26.0、summary 11.0、adverse-effects 10.3)  <!--h:4d44fd-->
> - 心絞痛用 propranolol 是**降低心肌耗氧**，不是擴張動脈;與硝酸鹽合用可抵銷反射性心跳加快。

### b10 → individual-agents   (信心:中 23.5 個別藥物特色;備選:nursing 21.6、indications 16.0、summary 15.9)  <!--h:1d7ad0-->
> - Propranolol 用於甲狀腺風暴、食道靜脈曲張、靜坐不能;小兒使用注意**心跳過慢**。

### b11 → mechanism   (信心:高 34.5 作用機轉;備選:summary 13.6、adverse-effects 8.2、interactions 5.2)  <!--h:98d61f-->
> - 拮抗劑不會造成受體去敏感化;長期使用受體上調，**不可驟停**。

### b06 → summary   (信心:中 20.1 重點摘要;備選:interactions 15.0、indications 11.5、adverse-effects 10.4)  <!--h:c1bac3-->
> - Verapamil 可治療 PSVT;verapamil/diltiazem **與 β 阻斷劑併用 → 心搏過緩、傳導阻滯**。

### b07 → indications   (信心:高 31.6 適應症;備選:interactions 6.2、dhp 5.5、nursing 4.5)  <!--h:507652-->
> - 醫囑判讀：**S.L. = 舌下含服**;SL Q6H PRN if SBP > 170 = 收縮壓 > 170 時給一次，再次給藥至少間隔 6 小時。

### b08 → indications   (信心:高 35.7 適應症;備選:dhp 19.1、mechanism 10.4、summary 9.7)  <!--h:e85a13-->
> - 變異型心絞痛(冠狀動脈痙攣)首選 CCB;nimodipine 用於蜘蛛網膜下腔出血。

> - 心電圖**U 波** = 低血鉀 → 注意**毛地黃中毒**;「T 波升高表示低血鉀」錯(高尖 T 波是高血鉀)。

### b05 → toxicity   (信心:中 17.1 毛地黃中毒;備選:summary 15.2、pediatric 10.8、education 7.1)  <!--h:43b85a-->
> - 中毒症狀：**腹瀉、噁心嘔吐、黃色視覺**、心搏過緩;「紅色視覺」「便祕」錯;常見原因之一是心搏過緩。

### b06 → toxicity-management   (信心:高 41.4 中毒處理;備選:toxicity 23.0、indications 17.3、summary 14.8)  <!--h:58077b-->
> - 中毒時**低血鉀要補鉀**、房室阻斷用 **atropine**;毛地黃中毒的心室性心律不整/VF 首選(傳統答案)**phenytoin**。

### b07 → toxicity   (信心:中 18.3 毛地黃中毒;備選:interactions 16.0、toxicity-management 15.0、indications 10.4)  <!--h:6f3401-->
> - 與 thiazide 併用**不能**避免中毒;甘草 + 毛地黃 → **低血鉀**。

### b08 → pharmacokinetics   (信心:高 17.3 藥動重點;備選:pediatric 7.4、agents 5.4)  <!--h:0ce284-->
> - 醫囑判讀：125 mcg ÷ 0.25 mg 錠 = **半顆**;**QOD = 隔天一次**;S.L. = 舌下。

### b09 → pediatric   (信心:高 78.1 兒童給藥;備選:education 7.2、pharmacokinetics 6.8、toxicity-management 5.0)  <!--h:051237-->
> - 漏服：未超過給藥間隔中點可補服(BID 約 6 小時內)，超過就跳過、下一劑照原時間，**不可加倍**(題目解析有 4 或 6 小時兩種寫法，見 [[#pediatric]])。

### b10 → toxicity   (信心:高 10.6 毛地黃中毒;備選:interactions 4.4、education 4.4、mechanism 1.8)  <!--h:7fa57b-->

## infective-endocarditis 感染性心內膜炎與心臟發炎疾病(12 條)

可選段落:infective-endocarditis、ie-causes(H3)、ie-mechanism(H3)、ie-manifestations(H3)、ie-diagnosis(H3)、ie-treatment(H3)、prophylaxis(H3)、rheumatic-heart-disease、myocarditis、pericarditis、cardiac-tamponade(H3)

### b01 → ie-mechanism   (信心:高 37.0 致病機轉;備選:ie-causes 22.5、rheumatic-heart-disease 9.3、ie-manifestations 7.3)  <!--h:f8ebc8-->

### b02 → ie-manifestations   (信心:高 89.3 臨床表現;備選:ie-diagnosis 28.0、ie-mechanism 19.6、rheumatic-heart-disease 9.8)  <!--h:b2a9df-->

### b03 → ie-manifestations   (信心:高 17.3 臨床表現;備選:ie-treatment 9.3、rheumatic-heart-disease 6.7、ie-mechanism 5.6)  <!--h:8ea9a8-->
> - 常見**腦栓塞**、心雜音；二尖瓣贅生物易造成全身栓塞。

### b04 → ie-causes   (信心:高 27.5 致病菌與危險因子;備選:prophylaxis 4.7、rheumatic-heart-disease 4.7、ie-diagnosis 3.9)  <!--h:a66273-->
> - 懷疑心內膜炎要問**心臟血管手術史**。

### b05 → ie-mechanism   (信心:高 46.2 致病機轉;備選:rheumatic-heart-disease 8.8、ie-causes 7.5、prophylaxis 6.5)  <!--h:bec1ba-->
> - 亞急性細菌性心內膜炎屬**第三型過敏反應**(免疫複合物)。

### b06 → rheumatic-heart-disease   (信心:高 98.3 風濕熱與風濕性心臟病;備選:pericarditis 15.8、ie-diagnosis 15.4、ie-causes 12.8)  <!--h:6ef99e-->
> - 風濕熱：**5–15 歲**；**咽喉**鏈球菌感染後；主要表現**心臟炎**；最常侵犯**二尖瓣**；**ESR 上升**；**ASLO** 協助診斷；皮下結節**無痛**；是**自體免疫、非細菌性**發炎。

### b07 → rheumatic-heart-disease   (信心:高 95.8 風濕熱與風濕性心臟病;備選:ie-manifestations 7.2、myocarditis 5.0、pericarditis 3.5)  <!--h:1233b7-->
> - 瓊斯氏主要標準不包括**白血球增多**與**凝血時間延長**；風濕熱沒有**結膜炎**與**四肢末梢脫皮**(那是川崎氏症)。

### b08 → rheumatic-heart-disease   (信心:高 57.7 風濕熱與風濕性心臟病;備選:prophylaxis 15.4、ie-treatment 11.9、ie-diagnosis 7.7)  <!--h:8246ac-->
> - 風濕熱治療：**抗生素**；心衰竭時**低鹽**；**不要**多做體能活動；病理為**阿孝夫氏小體**。

### b09 → rheumatic-heart-disease   (信心:高 57.5 風濕熱與風濕性心臟病;備選:ie-causes 7.4、pericarditis 5.1、prophylaxis 5.1)  <!--h:8b8f31-->
> - 兒童最常見的後天性心臟病：**川崎氏症**；IVIG 降低冠狀動脈瘤。

### b10 → myocarditis   (信心:高 50.8 心肌炎;備選:pericarditis 12.3、rheumatic-heart-disease 9.2、ie-mechanism 3.4)  <!--h:c3987f-->
> - 心肌炎最常見原因：**病毒**；**不做阻力運動**；心肌炎是擴張性心肌病變常見的原因。

### b11 → pericarditis   (信心:高 54.1 心包膜炎與心包填塞;備選:rheumatic-heart-disease 7.1、myocarditis 7.0、cardiac-tamponade 5.6)  <!--h:90c568-->
> - 心包膜炎胸痛**平躺加重、坐起前傾減輕**；可用 aspirin；縮窄性心包炎最常見病因是**結核**。

### b12 → cardiac-tamponade   (信心:高 72.5 心包填塞;備選:pericarditis 16.3、rheumatic-heart-disease 3.2、myocarditis 1.9)  <!--h:2ebe20-->
> - 心包填塞：**低血壓、頸靜脈怒張、心音低沉**、**奇異脈**、CVP 上升；**脈搏壓變窄**、收縮壓不會上升、摩擦音不會增強。

## inotropes 強心劑與升壓劑(7 條)

可選段落:summary、mechanism、agents、dopamine(H3)、dobutamine(H3)、milrinone(H3)、norepinephrine(H3)、epinephrine(H3)、others(H3)、indications、cardiogenic-shock(H3)、other-shock(H3)、adverse-effects、extravasation(H3)、interactions、nursing、administration(H3)、calculation(H3)、monitoring(H3)

### b01 → dopamine   (信心:高 43.8 Dopamine(劑量依賴效應);備選:interactions 15.3、summary 11.7、adverse-effects 11.0)  <!--h:f30349-->
> - **Dopamine 劑量**：低劑量(< 3)→ **增加腎血流量**;中劑量(3–10，如 **6**)→ **增加心肌收縮力**;高劑量(> 10)→ **末梢血管收縮**。「初時應以高劑量」「中劑量使血管收縮」「高劑量增加收縮力」都錯。

> - **Dobutamine** 主要作用於 **β₁** 受體 → 增加收縮力與心輸出量，用於急性鬱血性心衰竭與心因性休克;它**不具 β₂ 選擇性**(與 terbutaline、salbutamol 區別)。

### b03 → mechanism   (信心:高 39.1 作用機轉;備選:milrinone 24.4、summary 20.8、interactions 13.9)  <!--h:c9a2c5-->

### b04 → dopamine   (信心:高 30.4 Dopamine(劑量依賴效應);備選:mechanism 18.4、cardiogenic-shock 14.8、dobutamine 12.1)  <!--h:a799f9-->
> - 低血壓治療：**β₁「拮抗劑」會降低心輸出量**(錯誤選項);α₁ 促效劑增加周邊阻力;中劑量 dopamine 可同時增加心輸出量與阻力。

### b05 → administration   (信心:中 10.6 給藥;備選:calculation 10.6、dopamine 4.0、norepinephrine 3.6)  <!--h:a17936-->
> - Dopamine 800 mg 計算、醫囑缺速率要確認。

### b06 → cardiogenic-shock   (信心:中 26.8 心因性休克與急性心衰竭;備選:dobutamine 23.4、monitoring 20.3、milrinone 19.1)  <!--h:6834d7-->
> - 心因性休克：dobutamine 增加收縮力、利尿劑降前負荷、**嗎啡也會降低前後負荷**、NTG 擴張血管減輕負荷;**IABP** 增加冠狀動脈血流、降低後負荷;**不使用電毯加溫**。

## lipid-profile 血脂檢查(9 條)

可選段落:origin、cholesterol(H3)、triglyceride(H3)、lipoproteins(H3)、reference-range、friedewald(H3)、targets(H3)、metabolic-syndrome(H3)、high、high-ldl(H3)、high-tg(H3)、high-hdl(H3)、low、interference、nursing

### b01 → high-hdl   (信心:中 12.3 HDL-C 偏高;備選:targets 11.3、lipoproteins 10.9、high-ldl 10.8)  <!--h:2736c5-->

### b04 → cholesterol   (信心:高 20.6 膽固醇;備選:low 12.1、high-tg 10.9、high-ldl 8.9)  <!--h:fdc45d-->

### b05 → metabolic-syndrome   (信心:高 32.0 代謝症候群判定(國健署);備選:targets 14.3、high-ldl 12.9、low 12.6)  <!--h:7a58a2-->

### b06 → interference   (信心:中 29.2 干擾因素;備選:nursing 22.8、high-tg 10.9、reference-range 10.2)  <!--h:f3229f-->

### b07 → high-hdl   (信心:中 11.0 HDL-C 偏高;備選:lipoproteins 9.7、low 8.7、interference 7.3)  <!--h:ebc59f-->
> - 停經後 **HDL 下降**、LDL 上升;規律運動使 **LDL 下降、HDL 上升**。

### b08 → high-ldl   (信心:高 23.1 LDL-C / 總膽固醇偏高;備選:high-tg 9.0、low 8.6、metabolic-syndrome 7.5)  <!--h:a9d459-->
