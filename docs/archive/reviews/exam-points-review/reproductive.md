## perinatal-infections 周產期感染(10 條)

可選段落:prenatal-screening、torch、group-b-streptococcus、prom-chorioamnionitis、puerperal-infection、perineal-care(H3)、mastitis、neonatal-infections、pregnancy-vaccines

### b01 → prenatal-screening   (信心:高 34.3 孕期感染篩檢;備選:torch 12.4、group-b-streptococcus 7.0、neonatal-infections 5.6)  <!--h:3676a2-->
> - 首次產檢要篩 **HIV**；第一孕期健保檢驗包括 **B 肝、德國麻疹抗體、愛滋、梅毒**；**乙型鏈球菌在 35–37 週**。

### b02 → group-b-streptococcus   (信心:高 82.6 B 族鏈球菌;備選:neonatal-infections 24.6、prenatal-screening 24.3、prom-chorioamnionitis 17.1)  <!--h:e54350-->
> - B 族鏈球菌：婦女生殖道**常在菌**；孕婦多無症狀；陽性者**待產時**給抗生素(產前 4 小時)，**不需剖腹產**、孕期不必先治療；新生兒經產道感染可能**敗血症**，多在出生 **7 天內**發病。

### b03 → torch   (信心:高 39.1 TORCH 感染;備選:neonatal-infections 14.5、puerperal-infection 9.2、prom-chorioamnionitis 7.6)  <!--h:67cfe2-->
> - TORCH 不包括麻疹；新生兒 **IgM** 上升表示子宮內感染；弓形蟲會經胎盤感染胎兒。

### b04 → prenatal-screening   (信心:高 42.0 孕期感染篩檢;備選:torch 14.5、neonatal-infections 14.4、group-b-streptococcus 10.6)  <!--h:319c6f-->
> - HIV 母子垂直感染預防：孕期抗病毒藥、**剖腹產**(病毒量高時)、新生兒口服預防藥；**不哺餵母乳**。

### b05 → prom-chorioamnionitis   (信心:高 29.3 早期破水與絨毛膜羊膜炎;備選:puerperal-infection 13.1、neonatal-infections 5.5、group-b-streptococcus 4.2)  <!--h:3abb72-->
> - 早期破水：首要監測**體溫**；減少內診；監測白血球與 CRP。

### b06 → puerperal-infection   (信心:高 50.5 產褥感染;備選:prom-chorioamnionitis 13.7、group-b-streptococcus 9.8、neonatal-infections 7.2)  <!--h:0606be-->
> - 產褥感染：陰道內細菌(如 B 族鏈球菌)；每天水分 **2,500–3,000 mL**；子宮內膜炎是**發燒、惡露惡臭、子宮軟、復舊不全、下腹壓痛**。

### b07 → mastitis   (信心:高 54.4 乳腺炎;備選:puerperal-infection 9.9、prenatal-screening 9.1、group-b-streptococcus 6.2)  <!--h:0daddc-->
> - 乳腺炎：**金黃色葡萄球菌**；多在產後 2–3 週後、單側；**持續哺乳**；抗生素 24–48 小時改善但要吃完療程。

### b08 → neonatal-infections   (信心:高 19.0 新生兒感染;備選:torch 3.7、prenatal-screening 2.9、group-b-streptococcus 2.9)  <!--h:01e29a-->
> - 新生兒感染用藥：**penicillin G** 最適合；鵝口瘡用 nystatin。

### b09 → neonatal-infections   (信心:高 47.2 新生兒感染;備選:prom-chorioamnionitis 1.7、perineal-care 1.7)  <!--h:4b2230-->
> - 臍帶：**75% 酒精**由根部環狀擦拭；**不用 95% 酒精**、不用優碘；不覆蓋；自然脫落。

### b10 → perineal-care   (信心:高 28.4 會陰傷口護理;備選:puerperal-infection 3.1、prom-chorioamnionitis 1.4)  <!--h:e0fc55-->
> - 會陰坐浴 41–43°C 促進血液循環；烤燈使血管**擴張**。

## sexually-transmitted-infections 性傳染病(11 條)

可選段落:overview、treponema-pallidum、syphilis-stages(H3)、syphilis-diagnosis(H3)、syphilis-treatment(H3)、congenital-syphilis、neisseria-gonorrhoeae、chlamydia、pelvic-inflammatory-disease、herpes-warts、vaginitis、nursing

### b01 → treponema-pallidum   (信心:高 45.8 梅毒螺旋體 Treponema pallidum;備選:syphilis-treatment 18.4、congenital-syphilis 16.3、overview 14.2)  <!--h:c91268-->
> - 梅毒：**性行為**為主，也可經胎盤；**早期傳染性最強**；**無法人工培養**；**青黴素**是首選；**沒有疫苗**。

### b02 → syphilis-stages   (信心:高 102.5 梅毒分期;備選:overview 31.5、congenital-syphilis 22.7、syphilis-treatment 14.6)  <!--h:c3025e-->
> - **一期**：**無痛**硬性下疳；**二期**：**全身皮膚黏膜紅疹**(手掌腳底丘疹)、扁平濕疣、掉髮、喉嚨痛、關節痛；**三期**：**梅毒腫**(不只在生殖器)、**主動脈炎**(血管滋養管 → 主動脈瘤)、神經性梅毒。

### b03 → overview   (信心:中 31.0 總覽;備選:treponema-pallidum 24.3、herpes-warts 18.7、syphilis-stages 8.9)  <!--h:4ebf02-->
> - 梅毒病理不是嗜酸性球浸潤；性病淋巴肉芽腫有星狀膿瘍；尖形濕疣與 HPV 有關。

### b04 → congenital-syphilis   (信心:高 32.5 先天性梅毒;備選:syphilis-diagnosis 3.9、nursing 3.7、herpes-warts 3.4)  <!--h:4b76b0-->
> - 孕婦梅毒篩檢是**第一孕期與第三孕期(29 週以上)**，不是 35 週；**懷孕初期也會傳給胎兒**。

### b05 → congenital-syphilis   (信心:高 71.2 先天性梅毒;備選:syphilis-stages 15.2、treponema-pallidum 11.3、nursing 6.5)  <!--h:1404db-->
> - 先天性梅毒：早期是皮膚病灶(具傳染力)、肝脾腫大、黃疸、貧血、病理性骨折；**軍刀狀脛骨是晚期**。照護時穿隔離衣戴手套，但**鼓勵家人擁抱**。

### b06 → neisseria-gonorrhoeae   (信心:高 78.7 淋病雙球菌 Neisseria gonorrhoeae;備選:overview 30.6、pelvic-inflammatory-disease 14.9、chlamydia 12.1)  <!--h:f8e6ab-->
> - 淋病雙球菌：革蘭氏陰性、有內毒素、可造成皮疹與關節炎；**沒有疫苗**；新生兒點抗生素眼藥膏預防**淋病性結膜炎**；產後收集子宮頸分泌物培養。

### b07 → chlamydia   (信心:高 50.7 披衣菌感染;備選:overview 23.0、neisseria-gonorrhoeae 7.5、vaginitis 7.2)  <!--h:cde1e2-->
> - 披衣菌：**絕對細胞內寄生**；**基體**具感染力；檢體要含細胞；治療不用 gentamicin，**性伴侶要治療**。

### b08 → pelvic-inflammatory-disease   (信心:高 87.3 骨盆腔炎;備選:neisseria-gonorrhoeae 27.3、chlamydia 19.4、vaginitis 13.1)  <!--h:b9caa9-->
> - 骨盆腔炎：多為**混合感染**(淋病、披衣菌)；**最常見合併症是不孕**；下腹兩側痛、子宮頸移動性疼痛；**不要會陰或陰道灌洗**；暫停性生活、安全性行為衛教。

### b09 → herpes-warts   (信心:高 42.9 生殖器疱疹與尖形濕疣;備選:overview 14.9、pelvic-inflammatory-disease 9.1、chlamydia 8.5)  <!--h:274710-->
> - 生殖器疱疹：主要是 **HSV-2**，不是水痘帶狀疱疹病毒；新生兒經陰道感染；可哺乳；**無法根治**。

### b10 → herpes-warts   (信心:中 21.6 生殖器疱疹與尖形濕疣;備選:overview 16.1、syphilis-stages 2.5、treponema-pallidum 0.8)  <!--h:5b85ac-->
> - 尖形濕疣：**HPV 6、11**，不是 16、18。

### b11 → vaginitis   (信心:高 92.0 陰道炎比較;備選:overview 31.9、pelvic-inflammatory-disease 22.8、neisseria-gonorrhoeae 19.0)  <!--h:d22a48-->
> - 念珠菌陰道炎：乳酪狀白色分泌物，要停用避孕藥、抗生素、類固醇；滴蟲：泡沫狀黃綠惡臭、草莓狀子宮頸、metronidazole 期間**禁酒**、**伴侶同治**；萎縮性陰道炎是**雌激素**缺乏。
