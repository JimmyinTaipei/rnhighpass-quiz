## pediatric-respiratory-infections 兒童呼吸道與耳鼻喉感染(11 條)

可選段落:anatomy、tonsillitis、otitis-media、ear-drops(H3)、ear-surgery(H3)、sinusitis、croup-epiglottitis-bronchiolitis、febrile-seizure、family-centered-care

### b01 → anatomy   (信心:高 13.7 嬰幼兒呼吸道的特徵;備選:otitis-media 7.2、febrile-seizure 4.0、croup-epiglottitis-bronchiolitis 3.1)  <!--h:8ffca3-->
> - 嬰幼兒易中耳炎：**耳咽管短、寬、水平**。

### b02 → tonsillitis   (信心:高 70.5 扁桃腺炎與扁桃腺切除術;備選:croup-epiglottitis-bronchiolitis 10.7、otitis-media 8.6、sinusitis 8.3)  <!--h:68ffeb-->
> - 扁桃腺炎：細菌以**鏈球菌**最常見；**急性發炎期不宜手術**；血液惡性疾病、活動性結核是禁忌，一年發作 7 次以上是適應症。

### b03 → tonsillitis   (信心:高 98.6 扁桃腺炎與扁桃腺切除術;備選:ear-surgery 9.7、otitis-media 6.3、sinusitis 5.4)  <!--h:1f404b-->
> - 扁桃腺切除術後：**頻繁吞嚥或清喉嚨＝出血警訊**；側臥或俯臥；**避免用力咳嗽**與擤鼻；冰領(交感性反應)；吃**冰淇淋、布丁、果凍**，不喝西瓜汁、番茄汁、柑橘、檸檬汁、熱食。

### b04 → otitis-media   (信心:高 86.1 中耳炎;備選:croup-epiglottitis-bronchiolitis 18.0、tonsillitis 16.6、sinusitis 12.5)  <!--h:e733c9-->
> - 中耳炎：拉耳朵、躁動、發燒、淋巴結腫大；**鼓膜破裂後疼痛減輕**；可致**傳導性聽力喪失**、乳突炎；**不會**狗吠式咳嗽、吞嚥困難；抗生素**不可症狀改善就停**；經耳咽管、外耳道或血行感染。

### b05 → ear-drops   (信心:高 31.2 耳內給藥;備選:otitis-media 9.3、febrile-seizure 4.1、croup-epiglottitis-bronchiolitis 4.0)  <!--h:e5162d-->
> - 耳內給藥：**3 歲以下往下往後**、3 歲以上與成人**往上往後**；患耳朝上，維持 5–15 分鐘；A.D. 是右耳。

### b06 → ear-surgery   (信心:高 56.9 中耳手術後;備選:tonsillitis 8.5、otitis-media 6.4、croup-epiglottitis-bronchiolitis 4.3)  <!--h:6f8a56-->
> - 中耳手術後：觀察顏面神經、軟質飲食、避免頭部突然轉動、**打噴嚏咳嗽要張口**、避免潛水與搭飛機。

### b07 → sinusitis   (信心:高 51.8 鼻竇炎;備選:tonsillitis 15.7、croup-epiglottitis-bronchiolitis 6.8、otitis-media 4.0)  <!--h:f97f2c-->
> - 鼻竇炎：抗生素至少 7 天；鼻噴劑**不可隨時使用**；慢性鼻竇炎多因急性未治好；術後**半坐臥**、冰敷、口呼吸、不擤鼻。

### b08 → croup-epiglottitis-bronchiolitis   (信心:高 58.2 哮吼、會厭炎與細支氣管炎比較;備選:otitis-media 14.6、tonsillitis 6.4、febrile-seizure 4.1)  <!--h:4a23c2-->
> - 哮吼：**副流感病毒**、6 個月–3 歲、**狗吠式咳嗽、聲音沙啞、吸氣性喘鳴**；不需抽痰；不是 A 群鏈球菌。

### b09 → croup-epiglottitis-bronchiolitis   (信心:高 51.5 哮吼、會厭炎與細支氣管炎比較;備選:otitis-media 7.7、febrile-seizure 5.7、anatomy 5.1)  <!--h:ebbb22-->
> - 會厭炎：**Hib**、流口水、吞嚥困難、發聲困難、三腳架姿勢；**沒有持續性咳嗽**、沒有口腔潰瘍；不用壓舌板；備妥插管。

### b10 → croup-epiglottitis-bronchiolitis   (信心:高 70.3 哮吼、會厭炎與細支氣管炎比較;備選:anatomy 4.9、otitis-media 4.2、ear-drops 2.8)  <!--h:857814-->
> - 細支氣管炎：**RSV**、1 歲以下、冬春、**飛沫與接觸傳染**、呼吸性酸中毒；嬰兒抽痰前後給氧。

### b11 → febrile-seizure   (信心:高 35.5 熱性痙攣;備選:otitis-media 4.8、croup-epiglottitis-bronchiolitis 3.1、tonsillitis 1.2)  <!--h:5c257c-->
> - 熱性痙攣：側臥、不塞東西、**不用酒精拭浴**、不需終身服藥。

## pneumonia 肺炎(17 條)

可選段落:types、pathology、manifestations、severity(H3)、diagnosis、treatment、complications、aspiration、vap-prevention、nursing、chest-physiotherapy(H3)

### b01 → types   (信心:高 27.2 分類;備選:pathology 17.3、manifestations 15.2、nursing 10.8)  <!--h:0db68b-->
> - 社區型肺炎最常見的致病菌：**肺炎鏈球菌**；兒童細菌性肺炎最常見的致病原不是黴漿菌。

### b02 → manifestations   (信心:高 36.6 臨床表現;備選:types 6.2、pathology 6.2、diagnosis 4.3)  <!--h:ca1e7f-->
> - 鐵鏽色痰：**肺炎鏈球菌肺炎**；粉紅色泡沫痰：肺水腫。

### b03 → types   (信心:中 48.5 分類;備選:pathology 38.5、diagnosis 11.1、manifestations 9.5)  <!--h:7efbd3-->
> - 非典型肺炎：**黴漿菌、披衣菌、退伍軍人菌**(不包括李斯特菌)；黴漿菌肺炎的病理是**間質**有淋巴球浸潤，不是大葉性肺炎。

### b04 → manifestations   (信心:中 12.1 臨床表現;備選:pathology 11.3、nursing 9.8、types 9.4)  <!--h:66faf9-->
> - 細菌性肺炎：**高燒 > 39°C**、痰量多且黏稠、嗜中性球上升、需要抗生素；**傳染力在各型肺炎中最低**，不需呼吸道隔離。

### b05 → pathology   (信心:高 42.4 病理;備選:manifestations 5.7、aspiration 3.9、treatment 2.7)  <!--h:9e8f23-->
> - 大葉性肺炎消解期**巨噬細胞與纖維芽細胞最多**。

### b06 → manifestations   (信心:高 58.3 臨床表現;備選:complications 32.3、pathology 10.2、treatment 3.7)  <!--h:35f7d2-->
> - 實質化：**觸覺震顫增強**、叩診**濁音**、**支氣管語音響亮**；肋膜積液：濁音、呼吸音減弱、肋膜橫膈角變鈍。

### b07 → complications   (信心:高 35.9 併發症;備選:manifestations 6.1、vap-prevention 1.6、pathology 1.5)  <!--h:e78ee9-->
> - 肺膿瘍：呼吸音減弱，可有肋膜摩擦音；膿胸在**肋膜腔**。

### b08 → diagnosis   (信心:高 16.7 診斷;備選:nursing 11.1、manifestations 9.5、aspiration 5.5)  <!--h:70c18e-->
> - 必要檢查：**胸部 X 光＋痰液檢查**；疑似細菌性肺炎入院**最優先收集痰液培養**。

### b09 → manifestations   (信心:高 41.2 臨床表現;備選:severity 12.8、pathology 6.5、aspiration 4.1)  <!--h:f5898d-->
> - 肺炎的症狀包括**意識混亂**；低血氧最早的精神變化是**躁動不安**。

### b10 → treatment   (信心:高 27.5 治療;備選:nursing 4.5、manifestations 3.7、types 2.6)  <!--h:988fd0-->
> - 抗生素有效：**體溫下降、濃痰減少**。

### b11 → nursing   (信心:高 29.3 護理措施;備選:manifestations 4.7、treatment 3.7、chest-physiotherapy 2.9)  <!--h:d9453e-->
> - 促進痰液清除：**增加飲水量**；**不要限制水分**；教導有效咳嗽。

### b12 → nursing   (信心:高 32.1 護理措施;備選:aspiration 6.5、pathology 2.3、manifestations 2.3)  <!--h:79678d-->
> - 右上肺葉肺炎：**不要右側臥**(健側在下)。

### b13 → treatment   (信心:高 14.5 治療;備選:types 4.5、nursing 3.3、aspiration 1.6)  <!--h:03012c-->
> - MRSA 肺炎不能用 **daptomycin**。

### b14 → aspiration   (信心:高 61.2 吸入性肺炎;備選:nursing 15.2、vap-prevention 10.0、types 7.4)  <!--h:0d7cfa-->
> - 吸入性肺炎預防：進食後**不可立即平躺**；有氣管內管者灌食時**不要放氣囊**；進食時不與病人閒聊；嬰兒餵食後**右側臥**。

### b15 → vap-prevention   (信心:中 22.6 呼吸器相關肺炎的預防;備選:aspiration 18.9、types 4.2、severity 3.7)  <!--h:3b1b7e-->
> - 氣管內管氣囊壓力**不是 35 mmHg**；灌食時床頭抬高 30–45 度。

### b16 → chest-physiotherapy   (信心:高 43.7 胸腔物理治療;備選:aspiration 11.5、nursing 11.5、treatment 4.8)  <!--h:6adbff-->
> - 胸腔物理治療：先噴霧再引流叩擊；飯前 1 小時或飯後 2 小時；叩擊不是每部位 10–15 分鐘；出現呼吸窘迫要停止。

### b17 → nursing   (信心:高 23.7 護理措施;備選:aspiration 2.8、pathology 2.7、types 2.0)  <!--h:ebe394-->
> - 肺炎病人蛋白質：50 公斤約 **75–100 公克**。

## tuberculosis 結核病(10 條)

可選段落:mycobacterium-tuberculosis、pathology、transmission、clinical-features、diagnosis、infection-tests(H3)、treatment、isolation、children-bcg、public-health、nursing

### b01 → pathology   (信心:高 71.5 病理變化;備選:infection-tests 2.8、children-bcg 2.8、treatment 2.0)  <!--h:74e88b-->
> - **岡氏複合體**＝**原發性**結核；**乾酪樣肉芽腫**；**波特氏病**＝脊椎結核；縮窄性心包炎最常見病因是結核。

### b02 → mycobacterium-tuberculosis   (信心:高 52.0 結核分枝桿菌 Mycobacterium tuberculosis;備選:infection-tests 6.6、diagnosis 3.7、pathology 2.9)  <!--h:7ed89a-->
> - 組織傷害主因是**宿主免疫反應**(第 IV 型過敏)；抗酸性細胞壁富含**分枝菌酸**。

### b03 → isolation   (信心:高 27.4 感染管制與隔離;備選:transmission 12.5、children-bcg 5.0、public-health 2.5)  <!--h:d7d734-->
> - **空氣傳染**，採**空氣傳染防護措施**；「直接接觸傳染」是錯誤敘述。

### b04 → diagnosis   (信心:高 36.5 診斷;備選:mycobacterium-tuberculosis 14.3、infection-tests 5.3、public-health 3.4)  <!--h:eb48b6-->
> - 確診最準確：**痰液培養**；適合的診斷檢查：**痰液耐酸菌染色抹片**(不是革蘭氏染色)。

### b05 → transmission   (信心:高 30.2 傳染途徑;備選:infection-tests 7.7、diagnosis 6.3、children-bcg 6.2)  <!--h:a06236-->
> - **潛伏結核感染者沒有傳染力**，痰塗片與培養皆陰性。

### b06 → clinical-features   (信心:高 28.9 臨床表現;備選:infection-tests 1.5、treatment 1.5)  <!--h:b39730-->
> - 活動期徵象：**夜間盜汗**；初期最常見症狀：**乾咳**。

### b07 → infection-tests   (信心:高 68.7 結核感染檢驗;備選:children-bcg 13.6、public-health 9.3、diagnosis 6.7)  <!--h:4460b0-->
> - **PPD**：前臂中段內側皮內注射，48–72 小時判讀硬結；**陽性不需再打卡介苗**，要照胸部 X 光或驗痰；**IGRA 不是所有年齡都適用**(2 歲以上)。

### b08 → children-bcg   (信心:高 16.2 兒童結核與卡介苗;備選:infection-tests 4.5、mycobacterium-tuberculosis 2.6、public-health 2.6)  <!--h:645578-->
> - 卡介苗：**出生滿 5 個月(5–8 個月)**接種；**愛滋寶寶不可接種**。

### b09 → public-health   (信心:高 44.8 公共衛生與防治;備選:treatment 9.1、children-bcg 6.7、diagnosis 6.3)  <!--h:3b1d17-->
> - 結核病為**第三類**法定傳染病；**多重抗藥性結核 24 小時內**通報。

### b10 → public-health   (信心:高 25.8 公共衛生與防治;備選:nursing 4.4、children-bcg 3.4、isolation 3.2)  <!--h:72747b-->
> - 初段預防：**環境通風**；次段預防：接觸者主動照胸部 X 光。
