## loop-diuretics 亨利氏環利尿劑(7 條)

可選段落:summary、mechanism、agents、indications、pharmacokinetics、adverse-effects、interactions、nursing、administration(H3)、monitoring(H3)、education(H3)

### b01 → summary   (信心:高 24.5 重點摘要;備選:mechanism 17.1、adverse-effects 9.5、indications 5.1)  <!--h:a079ba-->
> - Furosemide 分類 → **亨利氏環利尿劑**，作用於上升支粗段的 **Na⁺-K⁺-2Cl⁻**(不是鈉-氫交換、不是遠曲小管)。

### b02 → mechanism   (信心:高 30.3 作用機轉;備選:summary 16.0、indications 11.8、adverse-effects 10.0)  <!--h:4dcb58-->
> - **利尿效果最強**、可**治療高血鈣** → furosemide(thiazide 反而升高血鈣)。

### b03 → interactions   (信心:中 12.2 交互作用;備選:indications 11.4、mechanism 8.5、agents 7.4)  <!--h:b9415f-->
> - **耳毒性** → loop diuretics;**加重 gentamicin 的耳毒性** → furosemide。

### b04 → education   (信心:高 18.9 衛教;備選:administration 5.1、adverse-effects 4.8、summary 4.0)  <!--h:a7e3ef-->
> - Furosemide **會造成低血鉀**(「造成血鉀過高」錯);護理指導是**適量攝取含鉀食物**，「避免含鉀食物」錯。

### b05 → education   (信心:高 18.7 衛教;備選:agents 4.5、administration 4.5、indications 2.6)  <!--h:51ee72-->
> - 長期服用 furosemide + warfarin → **高鉀、限(穩定)維生素 K** 飲食。

### b06 → mechanism   (信心:高 16.4 作用機轉;備選:indications 4.2、administration 4.2、agents 2.6)  <!--h:1ae1a1-->
> - CABG 術後或心因性休克時，furosemide 的目的 → **降低前負荷**。

### b07 → education   (信心:中 9.9 衛教;備選:adverse-effects 8.6、indications 6.1、agents 3.6)  <!--h:a5efc9-->
> - 肝昏迷(肝性腦病變)**不是**用利尿劑排氨，而是 lactulose;食道靜脈曲張出血也不用 furosemide。

## potassium 血清鉀(13 條)

可選段落:origin、distribution(H3)、function(H3)、balance(H3)、reference-range、ecg、high、high-cardiac(H3)、high-noncardiac(H3)、high-symptoms(H3)、low、low-cardiac(H3)、low-noncardiac(H3)、low-symptoms(H3)、interference、pseudohyperkalemia(H3)、other-interference(H3)、nursing、collection(H3)、iv-replacement(H3)、hyperkalemia-treatment(H3)、hypokalemia-treatment(H3)、diet(H3)、drug-relations

### b01 → balance   (信心:中 19.2 進出：什麼時候鉀會進入/離開血液;備選:low-noncardiac 16.7、pseudohyperkalemia 14.8、low-cardiac 13.9)  <!--h:e9be78-->
> - 正常值 **3.5–5.0 mEq/L**;2.9、2.7 = 低血鉀(常見原因：**嘔吐**、排鉀利尿劑;衛教：**攝取富含鉀之食物**)。

### b02 → ecg   (信心:高 59.9 心電圖變化;備選:low-symptoms 29.0、drug-relations 20.6、function 15.5)  <!--h:78f193-->
> - **高血鉀心電圖**：**T 波高尖**、P 波變平、QRS 變寬、房室阻斷;「T 波低而寬」錯。**低血鉀**：T 波變平、ST 下降、**U 波** → 注意**毛地黃中毒**。

### b03 → function   (信心:高 36.7 功能：為什麼這個數值這麼重要;備選:ecg 10.3、low-cardiac 7.5、high-cardiac 7.1)  <!--h:a8de3b-->
> - 細胞外 K⁺ 增加 → **靜止膜電位減小**;大量 K⁺ 使心房到心室的傳導被阻斷。

### b04 → high-noncardiac   (信心:高 54.0 非心臟原因;備選:hyperkalemia-treatment 28.0、high-cardiac 25.3、low-noncardiac 21.6)  <!--h:46983c-->
> - **高血鉀導因**：ACEI、醛固酮拮抗劑、**代謝性酸中毒**、溶血、組織破壞(燒傷早期、腫瘤溶解);「**胰島素分泌過多**」、thiazide、代謝性鹼中毒 → **低**血鉀。

### b05 → hyperkalemia-treatment   (信心:高 100.7 高血鉀的緊急處理;備選:low-cardiac 19.5、high-noncardiac 10.4、diet 9.7)  <!--h:8d2bd7-->
> - 高血鉀處置：**Kayexalate/Kalimate(口服或灌腸)**、**RI + 50% 葡萄糖靜注**、**碳酸氫鈉**、**緊急透析**;錯誤選項：中長效胰島素 + 5% 葡萄糖、0.3% NaCl、多吃香蕉柳丁。

### b06 → iv-replacement   (信心:高 39.7 靜脈補鉀(KCl)規則;備選:hyperkalemia-treatment 10.2、high-noncardiac 4.4、collection 2.6)  <!--h:79a07b-->
> - **KCl 絕不可 IV push**;醫囑沒寫途徑或寫 IV push → 向醫師**澄清途徑(與劑量)**。

### b07 → hyperkalemia-treatment   (信心:中 31.5 高血鉀的緊急處理;備選:high-noncardiac 28.4、diet 15.9、hypokalemia-treatment 14.0)  <!--h:5d31dc-->
> - 腎衰竭/少尿期、急性腎絲球腎炎少尿期 → **限制高鉀食物**(香蕉);「給高鉀飲食預防低血鉀」錯。

### b08 → diet   (信心:高 59.0 飲食衛教;備選:high-noncardiac 26.7、drug-relations 12.3、iv-replacement 11.9)  <!--h:0496b5-->
> - 預防腎功能不全高血鉀：**避免熱量不足或長期飢餓**;雞精、低鈉鹽、果乾都是高鉀。

### b09 → high-noncardiac   (信心:中 20.1 非心臟原因;備選:low-noncardiac 20.1、hyperkalemia-treatment 6.1、high 5.1)  <!--h:7efc12-->
> - **Conn 氏症、庫欣氏症 → 低血鉀**;**愛迪生危機 → 高血鉀、低血鈉**;嗜鉻細胞瘤 5P 不包括高血鉀。

### b10 → low-symptoms   (信心:高 30.2 臨床表現;備選:iv-replacement 18.6、high-noncardiac 13.2、low-noncardiac 10.6)  <!--h:1f33f4-->
> - **DKA**：補足體液、**確認尿量後再補鉀**;低血鉀會誘發**肝性腦病變**。

### b11 → low-symptoms   (信心:高 24.3 臨床表現;備選:ecg 8.9、high-symptoms 7.4、low-cardiac 6.7)  <!--h:c02fe2-->
> - 高、低血鉀都會出現：**噁心、心律不整**。

### b12 → hypokalemia-treatment   (信心:高 32.7 低血鉀的處理;備選:drug-relations 16.1、low-symptoms 14.4、iv-replacement 11.2)  <!--h:cd16af-->
> - 排鉀利尿劑病人出現肌肉無力、心悸 → **不要鼓勵多下床**，監測心律、評估電解質、補鉀食物。

### b13 → high-noncardiac   (信心:高 29.3 非心臟原因;備選:hyperkalemia-treatment 8.0、iv-replacement 7.4、distribution 4.1)  <!--h:428459-->
> - 換血用 **72 小時內**的新鮮血，避免高血鉀。

## potassium-sparing-diuretics 保鉀利尿劑(7 條)

可選段落:summary、mechanism、agents、indications、heart-failure(H3)、other-uses(H3)、adverse-effects、interactions、nursing

### b01 → heart-failure   (信心:中 9.1 心衰竭;備選:nursing 8.7、agents 6.9、interactions 4.7)  <!--h:3284dd-->
> - **Spironolactone 會造成高血鉀**，「可能造成血鉀過低」**錯**(兒科先天性心臟病題常考)。

### b02 → nursing   (信心:高 14.4 護理重點與衛教;備選:interactions 5.2、summary 2.9、mechanism 1.5)  <!--h:a2402e-->
> - Spironolactone 衛教：**注意鉀離子濃度、不宜吃芭樂(高鉀)**;「多吃柑橘」錯。

### b03 → mechanism   (信心:高 30.1 作用機轉;備選:summary 14.2、agents 5.5、interactions 4.4)  <!--h:645ab9-->
> - **醛固酮拮抗劑作用在集尿管**(不是近曲小管);拮抗的是**礦物皮質素(醛固酮)受體**，不是糖皮質素受體。

### b04 → mechanism   (信心:中 15.6 作用機轉;備選:agents 14.1、summary 10.4、other-uses 8.3)  <!--h:8bd28f-->
> - 醛固酮受體拮抗劑、**常用於治療心衰竭** → eplerenone(干擾：chlorothiazide、furosemide、tolvaptan)。

### b05 → agents   (信心:中 9.8 代表藥物;備選:summary 9.6、adverse-effects 8.1、heart-failure 6.8)  <!--h:47c695-->
> - 能降血壓但**不抑制睪固酮/不造成男性女乳** → **eplerenone**。

### b06 → adverse-effects   (信心:中 12.3 副作用與禁忌;備選:agents 11.5、other-uses 8.9、summary 8.3)  <!--h:945d69-->
> - **高血鉀的藥物導因** → ACEI、醛固酮拮抗劑(thiazide、代謝性鹼中毒則造成低血鉀)。

### b07 → adverse-effects   (信心:高 13.3 副作用與禁忌;備選:agents 4.1、summary 2.4、mechanism 2.4)  <!--h:66a4b5-->
> - Triamterene、acetazolamide 可產生代謝性酸中毒。

## thiazide-diuretics Thiazide 類利尿劑(6 條)

可選段落:summary、mechanism、agents、indications、pharmacokinetics、adverse-effects、interactions、nursing

### b01 → indications   (信心:高 14.3 適應症;備選:agents 9.9、summary 6.4、adverse-effects 2.9)  <!--h:ec33af-->
> - **高血壓第一線單方初始治療** → hydrochlorothiazide(干擾選項：atropine、amiodarone、dopamine)。

### b02 → mechanism   (信心:中 18.5 作用機轉;備選:indications 15.2、adverse-effects 13.0、agents 7.6)  <!--h:01f1c2-->
> - **Thiazide 會「減少」尿鈣 → 可減少尿路結石與骨質疏鬆**;loop 反而**增加**鈣排泄(可治療高血鈣)。

### b03 → adverse-effects   (信心:中 11.8 副作用與禁忌;備選:mechanism 11.8、interactions 11.2、summary 7.2)  <!--h:4d409d-->
> - 「毛地黃與 thiazide 併用可避免毛地黃中毒」**錯**：thiazide 造成低血鉀，反而**增加**中毒風險。

### b04 → mechanism   (信心:中 10.6 作用機轉;備選:adverse-effects 8.1、agents 7.6、indications 7.2)  <!--h:52573a-->
> - 「使用 thiazide 會造成高血鉀」**錯**：thiazide 是**排鉀型**;高血鉀的藥物原因是 ACEI、醛固酮拮抗劑。

### b05 → adverse-effects   (信心:中 9.2 副作用與禁忌;備選:interactions 8.9、indications 5.4、summary 5.1)  <!--h:fdcece-->
> - Thiazide、ACEI、NSAID 都會**使血中鋰鹽濃度上升**。

### b06 → mechanism   (信心:中 10.3 作用機轉;備選:indications 10.3、summary 6.5、agents 2.2)  <!--h:023f8c-->
> - 腎因性尿崩症可用 thiazide 加限鹽。

## urinary-tract-infection 泌尿道感染(13 條)

可選段落:types、causes、diagnosis、treatment、pyelonephritis、cauti、catheter-care(H3)、children、prevention、urine-acidification(H3)

### b01 → causes   (信心:高 31.3 病因與危險因子;備選:cauti 19.8、pyelonephritis 15.3、children 13.4)  <!--h:b0d372-->
> - 最常見致病菌：**大腸桿菌**(婦女、幼兒、導尿管相關都是)；常見途徑是**上行性感染**。

### b02 → causes   (信心:高 32.8 病因與危險因子;備選:types 10.0、children 7.6、diagnosis 6.4)  <!--h:12ba2c-->
> - **男性尿道較長，較不易感染**；前列腺肥大會造成尿液滯留而易感染。

### b03 → types   (信心:高 37.6 分類;備選:children 9.9、pyelonephritis 9.2、treatment 8.9)  <!--h:00767b-->
> - **腎絲球腎炎不屬於泌尿道感染**；尿道炎、膀胱炎是**下**泌尿道感染，腎盂腎炎是**上**泌尿道感染。

### b04 → diagnosis   (信心:高 27.3 診斷;備選:pyelonephritis 11.8、types 7.5、children 5.0)  <!--h:822165-->
> - 確立診斷：尿液培養 **≥ 10⁵ CFU/mL**；混濁尿、尿中白血球上升可能是感染。

### b05 → diagnosis   (信心:高 37.6 診斷;備選:prevention 11.2、children 4.6、catheter-care 4.6)  <!--h:d2fbf4-->
> - 中段尿：**先解掉前段**再接中段；消毒由前往後；不需 120 mL，也不可放 4 小時以上。

### b06 → pyelonephritis   (信心:高 69.2 急性腎盂腎炎;備選:diagnosis 20.1、types 13.5、treatment 9.4)  <!--h:331912-->
> - 急性腎盂腎炎：**肋骨脊柱角壓痛**、發燒、**ESR 與 CRP 上升**；急性期**大量攝取液體**，不限制水分；CRP、ESR 不是腎衰竭指標。

### b07 → diagnosis   (信心:高 27.4 診斷;備選:types 2.5、treatment 2.5、causes 2.2)  <!--h:fe7aa4-->
> - 老人：**體溫正常不能排除感染**。

### b08 → treatment   (信心:中 31.2 治療;備選:children 25.9、prevention 7.2、types 4.9)  <!--h:f4e2f2-->
> - 抗生素要**吃完療程**，症狀改善或不發燒**不能停藥**；完成後回診複檢尿液。

### b09 → prevention   (信心:高 61.5 護理指導：預防復發;備選:children 6.7、diagnosis 6.6、catheter-care 4.2)  <!--h:313890-->
> - 預防：多喝水(每日 2,000–3,000 mL 以上)、不憋尿、由前往後擦拭、**淋浴代替盆浴**、**性行為前後排尿**、穿寬鬆棉質內褲。

### b10 → urine-acidification   (信心:高 87.4 酸化尿液與蔓越莓;備選:children 9.7、catheter-care 6.3、causes 2.8)  <!--h:456c2b-->
> - 飲食：國考答案是吃**酸灰性食物**(肉、蛋、燕麥、玉米、梅子、李子、蔓越莓)，**避免牛奶、柑橘**與碳酸飲料；蔓越莓汁是**酸化**不是鹼化尿液。

### b11 → cauti   (信心:高 24.3 導尿管相關泌尿道感染;備選:catheter-care 13.3、causes 9.3、types 6.8)  <!--h:5e1211-->
> - 導尿管相關感染與留置天數有關、需治療；**每天膀胱灌洗不能降低感染**。

### b12 → children   (信心:高 52.9 兒童泌尿道感染;備選:treatment 9.5、causes 8.5、types 7.8)  <!--h:1dc3b3-->
> - 嬰兒泌尿道感染：**不明原因發燒、食慾不振、餵食困難**；VUR 第 3 級每 3 個月追蹤尿液培養至少 1 年。

### b13 → causes   (信心:高 38.8 病因與危險因子;備選:children 11.9、types 11.6、treatment 9.8)  <!--h:debc6f-->
> - K 他命造成**間質性膀胱炎**；鹿角結石與泌尿道感染有關，位置在**腎盂**。
