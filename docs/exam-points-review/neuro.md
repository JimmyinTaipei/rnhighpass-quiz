## cns-infections 中樞神經系統感染(12 條)

可選段落:csf-physiology、csf、pathogens、meningococcal、manifestations、lumbar-puncture、treatment、bacterial-treatment(H3)、viral-treatment(H3)、encephalitis-abscess、nursing

### b01 → csf   (信心:高 62.7 腦脊髓液判讀;備選:csf-physiology 25.1、lumbar-puncture 6.1、pathogens 3.4)  <!--h:54aaca-->
> - 腦脊髓液由**脈絡叢**產生；正常**清澈**、壓力 **70–180 mmH₂O**、蛋白質 **15–45 mg/dL**、葡萄糖約**血糖的 60–80%**。

### b02 → csf   (信心:高 53.4 腦脊髓液判讀;備選:pathogens 14.8、nursing 8.9、bacterial-treatment 8.3)  <!--h:e8dd13-->
> - **細菌性**：**混濁、蛋白質明顯上升、葡萄糖明顯下降**、嗜中性球多；腦室引流感染也是葡萄糖減少。

### b03 → csf   (信心:高 63.8 腦脊髓液判讀;備選:pathogens 36.2、viral-treatment 29.6、nursing 11.5)  <!--h:48a7e0-->
> - **病毒性(無菌性)**：**清澈**、壓力**正常或稍上升**、淋巴球、葡萄糖**正常**(葡萄糖 30 mg/dL 不符合)；治療是**支持療法**，**不給抗生素**，**多數無後遺症**；最常見病因是**腸病毒**與**腮腺炎病毒**。

### b04 → pathogens   (信心:高 44.5 致病原;備選:bacterial-treatment 9.6、nursing 7.9、lumbar-puncture 6.8)  <!--h:8e9297-->
> - 新生兒細菌性腦膜炎：**大腸桿菌**(與 B 族鏈球菌)；幼童：國考答案是**流感嗜血桿菌**。

### b05 → meningococcal   (信心:高 54.8 流行性腦脊髓膜炎;備選:nursing 14.2、pathogens 10.4、csf 5.5)  <!--h:ded316-->
> - 腦膜炎雙球菌：有莢膜、**飛沫**傳染、**出血性皮疹**；**不是人畜共通**。

### b06 → csf   (信心:中 34.3 腦脊髓液判讀;備選:pathogens 34.3、lumbar-puncture 13.4、bacterial-treatment 8.4)  <!--h:076605-->
> - 新型隱球菌：**鴿糞**、**莢膜多醣體抗原**快速診斷、造成黴菌性腦膜炎；免疫正常者也可能感染。

### b07 → manifestations   (信心:高 72.5 臨床表現;備選:meningococcal 12.8、nursing 9.1、lumbar-puncture 2.9)  <!--h:01fe76-->
> - 腦膜刺激：**Kernig**(屈髖屈膝 90 度後伸直小腿有阻力疼痛)、**Brudzinski**(屈頸時髖膝屈曲)、**頸部僵硬**、角弓反張；**Ortolani、Homan 不是**。

### b08 → manifestations   (信心:高 22.1 臨床表現;備選:nursing 8.7、lumbar-puncture 6.5、csf-physiology 5.0)  <!--h:3caaa1-->
> - 3 歲兒童顱內壓升高**不會有前囟門膨出**。

### b09 → nursing   (信心:高 50.2 護理措施;備選:manifestations 10.1、lumbar-puncture 9.6、bacterial-treatment 7.7)  <!--h:18ebcb-->
> - 腦膜炎合併顱內壓升高：**不要背部叩擊、抽痰、頭低腳高**；預防便秘、高纖飲食；環境要**安靜**，不要增加刺激。

### b10 → lumbar-puncture   (信心:高 124.5 診斷：腰椎穿刺;備選:manifestations 19.5、nursing 14.5、meningococcal 9.2)  <!--h:47a04c-->
> - 腰椎穿刺：**L3–L4**(或 L4–L5)；**顱內壓升高時不宜**；採**側臥屈曲**，**不是俯臥**或頭高腳低；最常見合併症是**頭痛**不是腰痛；國考答案是穿刺後**仰臥平躺 4–6 小時**、多喝水；操作防護要**手套、口罩、隔離衣、護目鏡**。

### b11 → encephalitis-abscess   (信心:高 52.3 腦炎與腦膿瘍;備選:csf 30.4、csf-physiology 8.4、meningococcal 8.3)  <!--h:0e5429-->
> - 日本腦炎：**三斑家蚊**；不需要隔離病人的血液與分泌物；腦脊髓液**蛋白質上升**。

### b12 → pathogens   (信心:高 33.4 致病原;備選:meningococcal 4.5、bacterial-treatment 4.4、csf 3.6)  <!--h:c25cd3-->
> - 嗜酸性腦膜炎：**廣東住血線蟲**，吃生**陸螺、蛞蝓**感染。

## nsaids-acetaminophen 非類固醇抗發炎藥與乙醯胺酚(6 條)

可選段落:summary、mechanism、agents、indications、aspirin-dose(H3)、adverse-effects、gi(H3)、renal(H3)、cardiovascular(H3)、bleeding(H3)、other-effects(H3)、aspirin、reye-syndrome(H3)、salicylate-toxicity(H3)、aspirin-interactions(H3)、acetaminophen、nursing

### b01 → summary   (信心:中 36.1 重點摘要;備選:mechanism 29.0、gi 23.1、bleeding 19.2)  <!--h:325255-->
> - NSAIDs 抑制 **COX**，減少**前列腺素**；**celecoxib** 阻斷前列腺素生合成、**出血機會最低**、**不會**抑制血小板凝集。

### b02 → aspirin-dose   (信心:中 33.6 Aspirin 的劑量與作用;備選:aspirin-interactions 29.0、summary 27.4、salicylate-toxicity 26.9)  <!--h:de68fd-->
> - Aspirin：**抗發炎所需劑量最高**；**不是止血藥**；與 **warfarin** 併用增加危險；**ibuprofen** 會減弱其抗血栓作用；副作用有嘔吐、**耳鳴**、幻覺，**不會代謝性鹼中毒**。

### b03 → reye-syndrome   (信心:中 39.7 雷氏症候群;備選:summary 34.7、acetaminophen 20.3、indications 17.6)  <!--h:226f0f-->
> - **雷氏症候群**：兒童病毒感染後用 aspirin；**登革熱、血友病、鐮狀細胞貧血的疼痛**都不用 aspirin；**川崎病**例外使用高劑量 aspirin。

### b04 → renal   (信心:高 28.5 腎臟;備選:acetaminophen 17.6、agents 5.2、summary 3.0)  <!--h:b10d73-->
> - 長期止痛藥 → **止痛劑腎病**(腎小管與間質壞死)。

### b05 → gi   (信心:高 17.9 腸胃道;備選:mechanism 5.7、agents 5.7、summary 3.5)  <!--h:07e93f-->
> - NSAIDs 引起的胃潰瘍 → **misoprostol**。

### b06 → acetaminophen   (信心:高 61.9 Acetaminophen;備選:agents 12.8、nursing 9.8、aspirin-dose 9.6)  <!--h:0d698c-->
> - **Acetaminophen**：用藥前了解**肝臟病史**；扁桃腺切除術後**按時**服用；它**不是** NSAIDs。

## opioids 鴉片類止痛藥(9 條)

可選段落:summary、mechanism、agents、fentanyl-patch(H3)、indications、adverse-effects、overdose、toxicity(H3)、withdrawal(H3)、dependence-terms(H3)、special-populations、interactions、nursing、nursing-administration(H3)、controlled-drugs(H3)、nursing-education(H3)

### b01 → summary   (信心:中 22.8 重點摘要;備選:mechanism 20.9、adverse-effects 11.3、agents 11.2)  <!--h:d0504d-->
> - 嗎啡作用在 **μ 受體**；會產生**欣快感**；**pentazocine** 以 κ 受體為主。

### b02 → adverse-effects   (信心:高 39.3 副作用;備選:summary 18.5、toxicity 10.2、nursing-administration 8.0)  <!--h:c38674-->
> - 常見副作用：**便秘、呼吸變慢、噁心、尿瀦留、低血壓、縮瞳**；**不是腹瀉、高血壓、心跳過快**。

### b03 → toxicity   (信心:高 25.6 急性中毒;備選:adverse-effects 16.8、summary 14.9、special-populations 7.7)  <!--h:439d3d-->
> - 中毒：**針狀瞳孔、嗜睡昏迷、呼吸抑制、心跳變慢**；解毒劑 **naloxone(Narcan)**。

### b04 → withdrawal   (信心:中 28.5 戒斷症狀;備選:summary 27.2、toxicity 6.2、adverse-effects 4.7)  <!--h:0800ed-->
> - 戒斷：流鼻水、嘔吐、顫抖、腹瀉；**不會體溫過低**。

### b05 → fentanyl-patch   (信心:高 65.8 Fentanyl 貼片;備選:agents 24.9、summary 10.6、dependence-terms 5.5)  <!--h:ecfaa6-->
> - **Fentanyl 貼片**：**強效**(不是弱效)、**每 72 小時**更換、**手掌壓 30 秒**、換不同部位、不可多貼一天、**避免泡熱水**、不需貼在疼痛處。

### b06 → agents   (信心:高 29.3 代表藥物;備選:adverse-effects 11.8、indications 10.4、dependence-terms 8.5)  <!--h:d20a74-->
> - **Codeine**：成癮、止咳，止咳劑量比止痛劑量低，會便秘不是腹瀉。止咳且不成癮的是 **dextromethorphan**。

### b07 → agents   (信心:中 33.2 代表藥物;備選:dependence-terms 25.1、mechanism 15.7、summary 6.4)  <!--h:99d207-->
> - **Methadone**：**口服**，可減少共用針頭的感染；仍會呼吸抑制與戒斷。

### b08 → special-populations   (信心:高 61.6 特殊族群;備選:adverse-effects 14.5、summary 10.5、agents 8.9)  <!--h:981971-->
> - 待產用 **meperidine**：注意嗜睡、尿瀦留、噁心，**監測胎心率變異性**；呼吸 < 10 次用 **naloxone**。臨終與兒童**避免 meperidine**。

### b09 → adverse-effects   (信心:高 16.1 副作用;備選:mechanism 3.2、agents 3.2、nursing-administration 3.2)  <!--h:f52cd4-->
> - **Morphine 不能緩解膽道痙攣**(傳統觀念會加重)。
