## conflict-change-management 衝突處理與組織變革管理(5 條)

### b01 → types   (信心:高 43.4 衝突的類型;備選:pitfalls 28.8、thomas 5.5、process 3.0)  <!--h:285d05-->
> - 個人內在衝突：**雙趨**(兩好)、**雙避**(兩壞)、**趨避**(一件事有好有壞)；人際：**任務、關係、程序**衝突；部門間＝**團體間衝突**。

### b02 → types   (信心:高 41.1 衝突的類型;備選:thomas 9.0、concept 5.1、pitfalls 4.8)  <!--h:553dcc-->
> - 衝突原因：稀少資源、管轄權混淆、溝通阻斷、個性、權力地位、**目標不一致**。

### b03 → process   (信心:中 19.2 衝突的過程;備選:pitfalls 19.2、thomas 3.9、types 3.3)  <!--h:811ca3-->
> - 階段：潛在對立 → **認知與個人化(知覺＋情緒)** → 意圖 → 行為 → 結果。

### b04 → thomas   (信心:高 24.8 Thomas 五種處理行為;備選:pitfalls 9.7、change 4.9、frustration 3.8)  <!--h:409cf7-->
> - Thomas：**合作＝雙贏**、**逃避＝低獨斷低合作(冷處理、收集資料)**、競爭＝贏輸、順從＝輸贏、妥協＝折衷。

### b05 → change   (信心:高 30.5 組織變革;備選:pitfalls 17.9、thomas 1.1、crisis 1.1)  <!--h:af2812-->
> - **Lewin**：**解凍 → 改變 → 再凍結**；改變標的 vs 改變推動者；變革先**確立問題**。

## decision-making 決策與問題解決(6 條)

可選段落:process、vroom-yetton、models、intuition、traps、tools、pitfalls

### b01 → process   (信心:高 26.5 決策與問題解決的過程;備選:pitfalls 17.8、tools 5.8、vroom-yetton 3.8)  <!--h:a7b5d3-->
> - 決策：**界定問題 → 確立準則 → 列方案 → 分析利弊 → 執行 → 評估**；第一步永遠是**界定問題**。

### b02 → process   (信心:高 57.1 決策與問題解決的過程;備選:pitfalls 31.8、models 4.8、tools 4.0)  <!--h:87930f-->
> - 問題解決原則：優先處理**影響組織利益最大**的問題；大問題**諮詢專家**、可忽略細節；好方案**符合目標、較少資源、確定性高、冒險性低**。

### b03 → vroom-yetton   (信心:高 31.5 Vroom-Yetton 決策模式;備選:pitfalls 7.7、tools 5.7、models 2.5)  <!--h:56a148-->
> - **Vroom-Yetton**：獨裁(AI、AII)、**諮商 CI(個別)、CII(團體)**、團體 GII、授權；看**誰做最後決定**。

### b04 → models   (信心:高 49.6 決策的模式與策略;備選:process 7.9、intuition 5.5、pitfalls 2.2)  <!--h:315d04-->
> - 模式：**理性**(最佳)、**政治**(協調、漸進)、行為(喜好)、規範(過去經驗)；策略：**最小極限＝危害最小**、樂觀性＝最大利益。

### b05 → intuition   (信心:高 33.1 直覺決策;備選:pitfalls 11.0、models 5.1、process 3.3)  <!--h:262d1b-->
> - **直覺決策**：緊急、資料不足；靠**知識＋經驗**，可練習培養。

### b06 → tools   (信心:高 24.7 團體決策技術與決策工具;備選:pitfalls 8.6、vroom-yetton 8.4、process 5.9)  <!--h:8d2da0-->
> - **腦力激盪、名義團體、德爾菲**＝非量性團體決策；**決策矩陣、決策樹**＝量性。

## delegation-empowerment 授權、賦權與分權(5 條)

可選段落:delegation、compare、empowerment、pitfalls

### b01 → pitfalls   (信心:中 23.7 常見錯誤選項;備選:delegation 19.2、compare 6.6、empowerment 2.1)  <!--h:a15498-->
> - **授權不授責**：責任(Accountability)留在主管；**職權可授，責任不可授**；護理長仍負麻醉藥品的最後管理責任。

### b02 → delegation   (信心:高 29.3 授權;備選:pitfalls 18.4、compare 6.2、empowerment 1.7)  <!--h:e46d70-->
> - 授權原則：**逐級、公開、不可重複、指揮統一、職權與職責均衡**；先評估能力、提供訓練、授權後要追蹤。

### b03 → delegation   (信心:高 26.2 授權;備選:pitfalls 15.1、compare 3.9)  <!--h:711f73-->
> - **可授權**：排班等例行事務；**不可授權**：加薪、裁員、升遷、年度計畫、重大危機處理。

### b04 → empowerment   (信心:中 22.1 賦權與心理賦權;備選:pitfalls 16.6、compare 7.2、delegation 4.5)  <!--h:592725-->
> - **賦權＝授權＋授能**；**心理賦權四構面**：**意義、能力、自主、影響**；賦權領導提升**自我效能**。

### b05 → compare   (信心:高 30.0 授權、分權與賦權的比較;備選:delegation 4.7、pitfalls 2.5、empowerment 1.1)  <!--h:664f93-->
> - **集權**：精簡、減少重複、緊急；**分權**：培養人才、自主、**階層職權職責完整**。

## turnover-absenteeism 人員流動、缺勤與職業倦怠(5 條)
